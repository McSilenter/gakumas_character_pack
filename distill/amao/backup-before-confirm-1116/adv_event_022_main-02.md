# 活动 022 / main-02 第2话（adv_event_022_main-02）

- 她的台词：18 行（含用匿名标签说的 0 行）；其中 0007、0010、0012 是睡着时的梦话，0026～0047 中她的 11 行是回想（ことね入学当天）
- 出场的人：ことね（38）、麻央（18）、莉波（3）
- 场景：麻央的房间（现在）；回想里是入学当天傍晚，学园内
- 世界线：活动 022；制作人在制作的偶像：看不出

## 发生了什么
麻央睡着，说梦话叫“ママ”，说“想成为偶像”。第2话中间插入ことね的回想：入学当天ことね丢了钱包，麻央看见她在找，说“义を見て為さざるは勇なきなり”，坚持帮她一起找，说“不想让入学第一天的回忆变坏”，被问为什么如此，答“我是王子”。回到现在，麻央醒来谢谢ことね换毛巾，听到柠檬水是莉波教的，说“我也能喝苦药”。

## 行为模式
- 看到有人为难 → 主动搭话，对方推辞也不退，用格言和“王子”身份说服（0026～0035、0046）
- 事情未解决 → 让对方先回，自己继续找（0043、0044）
- 被人照顾醒来 → 道谢（0053）
- 被知道了弱点（苦药） → 立即辩解自己能喝（0059）

## 关系

- 莉波：由ことね提到，莉波替她给了照顾说明（0057）。
