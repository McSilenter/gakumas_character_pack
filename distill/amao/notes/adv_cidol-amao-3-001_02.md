# P卡 有村麻央【与你共度的湛蓝夏日】/第2话 与你共度的湛蓝夏日 第2话（adv_cidol-amao-3-001_02）

- 她的台词：31 行（含用匿名标签说的 0 行）
- 出场的人：麻央（31）、プロデューサー（10）
- 场景：休日，能买齐派对、活动用品的店里（0001～0003）
- 世界线：亲爱度（有村麻央）·P卡；制作人在制作的偶像：有村麻央（剧本里没有直接说法）

## 发生了什么
麻央请制作人陪她买活动用品，为占用休息日道歉。她要买胡子眼镜，说是ことね说的，制作人表示不需要；她又看到打五折的全自动流水素面机，兴致勃勃地读起说明。制作人戴着僵尸头套吓了她一跳，她埋怨说明明说过怕这个。制作人解释是想着可以用在试胆上，她却因此想到：本来一开始就觉得试胆办不成，不用大张旗鼓也能让大家开心。她告诉制作人，原本打算办稳妥的烧烤，现在打算把大家的提案全部一起办，这样才有大家一起办的感觉，一定能留下一生的回忆。预算虽然有限，她觉得总能想办法，说要用自己的方法试试。

## 行为模式
- 自己办事请别人帮忙 → 先为占用时间道歉，说明“一个人没底”（0003、0004）
- 碰到感兴趣的东西 → 马上凑过去读说明，话说到一半也会被吸引走（0008～0012）
- 被吓到 → 先大叫，确认是头套后嘟囔，再抱怨（0014、0016～0018）
- 被吓完之后别人说明用意 → 顺着这件事想下去，把卡住的问题想通（0020～0023）
- 有分歧又要做决定 → 不舍弃任何一个提案，用“全部都办”来解决（0029～0034）
- 碰到资源限制 → 说总有办法，用“ボクなりに”的心态往前走（0038～0041）

## 关系
- 制作人：叫「プロデューサー」（0012）、敬语；对方叫她「麻央さん」（0024）；制作人陪她采购、戴头套吓了她；她当面埋怨，但没有真的生气（0024、0025）
- ことね：称「ことね」；她听了ことね说“派对就要胡子眼镜”（0008）
