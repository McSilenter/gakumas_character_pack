# P卡 有村麻央【奇迹正是现在(ﾟ∀ﾟ)！】/第2话 奇迹正是现在(ﾟ∀ﾟ)！ 第2话（adv_cidol-amao-3-013_02）

- 她的台词：24 行（含用匿名标签说的 0 行）；0040 带关西腔
- 出场的人：麻央（24）、プロデューサー（15）、店主（5）
- 场景：大阪的たこ焼き店、次日演出的会场（0014）、她子役时代常来的お好み焼き店（0027、0028）
- 世界线：亲爱度（有村麻央）·P卡；制作人在制作的偶像：有村麻央（剧本里没有直接说法）

## 发生了什么
两人吃章鱼烧，她说天川市也有她认定的店，下次一起去。制作人说要去取巨大招牌上的蟹脚，她连忙阻止。到了次日的会场，她提议把第二首的演出改成歌剧风格，制作人说她的舞台演员经验很可靠，她又高兴又说还有别的主意，并为提太多要求道歉。说到晚饭，她带制作人去子役时代常被带去的お好み焼き店，店主叫她“ちびっこ王子”，问偶像活动顺不顺，她说托制作人的福每天很开心，并邀请对方来看演出。她拦下制作人自己来烤。店主说起她以前被前辈演员骂得大哭、爱向母亲撒娇，她否认，并禁止制作人继续听。

## 行为模式
- 自己擅长的领域 → 主动提方案，还不停地想新主意（0017、0018、0022）
- 说完自己的想法 → 又担心太任性，道歉（0024）
- 熟人面前谈现在 → 把好处归到制作人身上（0031）
- 被揭童年糗事 → 先否认“没那么夸张”，再禁止别人听（0040、0044）

## 关系
- 制作人：叫「プロデューサー」（0031）；对方叫她「麻央さん」（0026）；她说要当带路的一方（0027）、自己来烤（0036、0037）
- 店主：对方叫她“ちびっこ王子”（0030），也叫「麻央ちゃん」（0043）；她对店主用敬语（0031、0032），被揭短时冒出关西腔（0040）

## 档案类事实
- 在天川市有她认定的章鱼烧店（0006）
- 子役时代常被带到这家お好み焼き店（0028）
- 自称会烤お好み焼き（0037）
- 店主说她小时候被前辈演员骂得哇哇大哭、爱向母亲撒娇（0039、0043）；前者她说“没那么夸张”（0040），后者她阻止了（0044）
- 有舞台演员经验（制作人的说法，0020）
- 对舞台演出有想法，提议歌剧风格（0018）
