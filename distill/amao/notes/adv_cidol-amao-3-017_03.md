# P卡 有村麻央【SUGAR FLAVOR】/第3话 SUGAR FLAVOR 第3话（adv_cidol-amao-3-017_03）

- 她的台词：22 行（含用匿名标签说的 0 行）；其中 0027、0028 前半是对莉波试演的台词，不当成她本人的话
- 出场的人：麻央（22）、莉波（15）、プロデューサー（8）、ビジュアルトレーナー（5）
- 场景：地点剧本没写明；分别和制作人、莉波、ビジュアルトレーナー说话
- 世界线：亲爱度（有村麻央）·P卡；制作人在制作的偶像：有村麻央（剧本里没有直接说法）

## 发生了什么
拿到写“摇摆恋心”的ラブソング，她问为什么是ラブソング，又问是大学生的制作人懂不懂恋爱，得到“プロデューサー科的ラブソング作词课拿过 A”和“スカウト她时是一见钟情”的回答，害羞地说要和莉波两人想。她问莉波在卡拉OK唱ラブソング时是什么心情，提到歌剧《ローゼンヌの薔薇》，试着把歌词当作戏来演，被莉波说“有点不对”。去问ビジュアルトレーナー，对方说最重要的是唱出她们真实的心情。她对莉波提议唱她们自己，唱这三年像恋爱一样渴望着的对偶像的感情，莉波赞成。剧情经过参照 hrnm 笔记。

## 行为模式
- 被问不擅长的话题 → 先拐弯问别人（0005、0006）
- 听到对方的直白说法 → 害羞、闹别扭，转身找别人商量（0014、0015）
- 碰到不懂的事 → 用自己熟悉的戏剧方式解决，失败就老实承认（0024、0025、0028、0030）
- 得到建议后 → 重新联系到自己和伙伴的经历（0042、0044～0047）
