# S卡 3-0005【次の桜の季節には。】 / 第3话 各自的方法（adv_csprt-3-0005_03）

- 她的台词：10 行（含匿名标签 0 行）
- 出场的人：麻央（10）、莉波（10）
- 场景：樱花开始飘落的时候，地点未明说；两人都是宿舍的人（莉波 0002「寮のみんなで」）
- 世界线：S卡【次の桜の季節には。】；制作人在制作的偶像：看不出

## 发生了什么
樱花开始落了，莉波提议和宿舍的大家去赏花，麻央答应去叫后辈。莉波随后问麻央能不能帮忙生徒会，麻央拒绝：自己是想站在聚光灯下发光的类型，从小就是这样；她尊敬为大家做生徒会工作的莉波，但自己有自己的方式。莉波接受，说自己喜欢支援想当偶像的人，麻央说被莉波帮助过的人一定很多。

## 她的关键台词
- 0003「……お花見か。いいね。／じゃあ、後輩たちに声をかけておくよ。」——赞成赏花，主动承担联络后辈
- 0006「生徒会――／ボクが？」——被邀请时吃惊
- 0008「……いやいや、ボクは向いてないよ。」——干脆地说不适合
- 0010「……ボクってさ、なんだかんだ／脚光を浴びていたいタイプなんだ。」——说出自己想站在聚光灯下的类型
- 0011「スポットライトを浴びて、大勢の／お客さんの前で輝きたい。」——具体说出想要的状态
- 0012「子供の頃から、ずっとそうだった。」——说这是从小的愿望
- 0013「みんなのために生徒会をしてる／莉波のことは、尊敬しているよ。」——先表达对莉波的尊敬
- 0014「けど、ボクには――／ボクのやり方があるから。ごめん。」——拒绝并道歉，说自己有自己的方式
- 0019「ああ。莉波に助けられた子は、／たくさんいると思うよ。」——肯定莉波的作用

## 行为模式
- 被邀请但不想做 → 明确拒绝，说清理由，不贬低对方，并在拒绝时先表达尊敬和道歉（0008、0010、0013、0014）
- 对方的志向和自己不同 → 承认差异，肯定对方的做法（0013、0019）
- 对后辈的活动 → 主动承担联络（0003）

## 关系
- 莉波：称「莉波」；莉波称她「麻央」，认为她被大家仰慕、可靠（莉波 0007）。她尊敬莉波为大家做生徒会（0013）

## 档案类事实
- 想站在聚光灯下，在很多观众面前发光，自称从小就是这样（0010、0011、0012）
- 不愿加入生徒会，原因是想走自己的路（0008、0014）
