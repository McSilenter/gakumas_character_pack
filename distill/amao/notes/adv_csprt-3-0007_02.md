# S卡 3-0007【まるで王子様みたいな】 / 第2话 王子的指引方向（adv_csprt-3-0007_02）

- 她的台词：9 行（含匿名标签 0 行）
- 出场的人：リーリヤ（10）、麻央（9）
- 场景：学园内的走廊，リーリヤ迷路，要去トレーニングルーム；时间是快迟到的时候
- 世界线：S卡【まるで王子様みたいな】；制作人在制作的偶像：看不出

## 发生了什么
麻央遇到在学园里迷路的リーリヤ。她听说リーリヤ要去トレ……，误听成トイレ，指了路，被纠正是トレーニングルーム。麻央告诉她那在训练楼，这里是本校舍，是完全不同的地方，因为她赶时间，提出背她去，被拒绝后改说自己带路护送。

## 她的关键台词
- 0005「ん、リーリヤ？」——看到熟人先轻声叫名字
- 0007「こんなところで、／なにをしているんだい？」——询问对方在做什么
- 0009「……ああ、たしかに。／慣れないうちは迷うよね。」——理解对方迷路，不责备
- 0010「どこへ行くつもりだったの？」——询问目的地
- 0012「ん、トイレか。／この廊下の突き当たりを右に――」——把话听成トイレ，马上指路
- 0014「トレーニングルームは、／トレーニング棟だね。」——被纠正后立刻改正
- 0015「ここは本校舎だから、／ぜんぜん別の場所だよ。」——说明位置
- 0017「ふむ、急ぎなら、／ボクが背負って行こうか。」——提出背着对方
- 0019「そうか。それじゃあ、トレーニング棟／までボクがエスコートするよ。」——被拒绝后改成护送

## 行为模式
- 看到后辈迷路 → 理解而不责备，问目的地（0009、0010）
- 听错话 → 很快指路；被纠正后改口（0012、0014）
- 对方赶时间 → 提出背她，被拒绝就换成护送，自称「ボク」（0017、0019）

## 关系
- リーリヤ：称「リーリヤ」；リーリヤ称「麻央センパイ」（リーリヤ 0006）。关照后辈

## 档案类事实
- 学园有本校舍和训练楼（トレーニング棟），トレーニングルーム在训练楼（0014、0015）
