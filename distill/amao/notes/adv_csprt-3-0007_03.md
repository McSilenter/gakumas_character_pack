# S卡 3-0007【まるで王子様みたいな】 / 第3话 大家都有自己的烦恼（adv_csprt-3-0007_03）

- 她的台词：8 行（含匿名标签 0 行）
- 出场的人：リーリヤ（11）、麻央（8）
- 场景：リーリヤ在练习到很晚，天色变暗；之后要回寮
- 世界线：S卡【まるで王子様みたいな】；制作人在制作的偶像：看不出

## 发生了什么
麻央看到リーリヤ练习到很晚，称赞她，劝她天暗了回寮。リーリヤ说大家都在前进只有自己落后，有人已经有制作人。麻央说她才 1 年级，是探索可能性的时期，制作人总会出现。麻央也说自己会焦虑，今年是 3 年级，还有长不高之类。得知リーリヤ觉得她完美，麻央道谢，说在后辈面前至少要保持完美的王子形象。

## 她的关键台词
- 0005「や、感心だね。／こんな時間まで練習なんて。」——夸奖她练习到很晚
- 0007「けど、もうだいぶ暗くなってきたから、／寮に戻ろうか。」——温和地劝回去
- 0010「キミはまだ1年生だ。焦らずに、／自分の可能性を模索する時期だよ。」——对焦虑的后辈说现在是探索可能性的时期
- 0012「大丈夫。キミのことを見てくれる／プロデューサーはきっと現れるさ。」——安慰，说制作人一定会出现
- 0014「ボクだって、焦ることはあるよ。／今年で3年生だから、なおさらね。」——坦白自己也会焦虑，因为是 3 年级
- 0016「ん、ボクもまあ、いろいろあるのさ。／……せ、背が伸びなかったり。」——说出长不高这类烦恼，结巴
- 0018「……ありがとう。／そうだね、せめて後輩の前では、」——被说完美后道谢，接着说在后辈面前
- 0019「ボクらしく、完璧な王子様で／いないとね――」——说在后辈面前要维持完美的王子形象

## 行为模式
- 看到后辈勤奋 → 先夸，再让她注意时间、回寮（0005、0007）
- 后辈焦虑 → 说明时期，保证会有制作人，并说出自己的焦虑作为共鸣（0010、0012、0014）
- 被说完美 → 道谢，并表明在后辈面前要保持王子形象（0018、0019）

## 关系
- リーリヤ：称「キミ」，温和关照；リーリヤ觉得她是完美的王子（リーリヤ 0017）

## 档案类事实
- 今年 3 年级，也有焦虑（0014）
- 烦恼之一是个子没有长高（0016）
- 在后辈面前要做完美的王子（0019）
