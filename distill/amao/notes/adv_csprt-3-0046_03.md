# S卡 3-0046【これが私達の、3年間】 / 第3话 把接力棒传下去（adv_csprt-3-0046_03）

- 她的台词：9 行（含用匿名标签说的 0 行）
- 出场的人：莉波（10）、麻央（9）
- 场景：两人在练习，跳完一遍后讨论；莉波说录了像（0006）
- 世界线：S卡【これが私達の、3年間】；制作人在制作的偶像：看不出

## 发生了什么
麻央和莉波跳完一遍，麻央问感想，莉波说有在意的地方但不确定对不对，不习惯指出问题。麻央说这就是练习的目的，自己也不习惯；莉波提议一起看录像。两人说既然要教后辈就得好好指出问题。麻央想起教自己的前辈站上舞台时，看到前辈的笑容就想唱这首歌，莉波说演出后两人聊过要加油，要把这种心情传给后辈。麻央说从前辈那里接过了接力棒，要好好传下去。

## 她的关键台词
- 0001「ふぅ……ひと通り踊ったわけだけど、／どうだった？」——跳完先问对方的意见
- 0005「そのためにやってるんじゃないか。／ボクだって慣れてないよ。」——不习惯指出问题，但认为这正是练习的目的
- 0007「……確かに、自分の振りなら、／どこが悪いかすぐわかるけど。」——承认自己的动作自己最容易判断
- 0011「そうだね。／ボクたちの役目だからね。」——认定教后辈是她们的责任
- 0012「ボクに教えてくれた先輩が、／ステージに立ったとき……」——说起教自己的前辈
- 0013「先輩の笑顔を見て、この曲を／絶対に歌いたいって思った。」——这首歌是被前辈的笑容点燃的
- 0017「そう……ボクたちは、／先輩からバトンをもらったんだ。」——把传承比作接力棒
- 0018「もらったバトンを、／しっかり渡そう。」——决心传下去

## 行为模式
- 被问不会做的事 → 说“我也不习惯”，然后以练习的目的为由推进（0005）
- 谈到责任 → 用“役目”来定位，并回到自己受到的影响（0011～0013）
- 想表达决心 → 用比喻（接力棒）并向对方发出邀请式的句子“渡そう”（0017、0018）

## 关系
- 莉波：本话两人都没有直接叫对方的名字（同卡第1话 0019 麻央称“莉波”，0018 莉波称“麻央”）。莉波说两人演出后聊过“やるぞー”（0014）；麻央用“ボクたち”称两人（0011、0017）。
- 前辈：教过她的前辈，在舞台上的笑容让她想唱这首歌（0012、0013）。

## 档案类事实
- 教过她的前辈站上舞台时，她看到那笑容，决定要唱好『Campus mode!!』（0012、0013）。
- 自称“ボク”（0005）。
