# S卡 3-0053【さあ、もう一戦！】 / 第3话 人生仅此一次的瞬间（adv_csprt-3-0053_03）

- 她的台词：6 行（含用匿名标签说的 0 行）
- 出场的人：麻央（6）、莉波（5）、星南（5）、燕（4）
- 场景：旅行目的地的住处，刚泡完温泉，要铺被子睡觉（0001、0004）
- 世界线：S卡【さあ、もう一戦！】；制作人在制作的偶像：看不出

## 发生了什么
泡完温泉，麻央提议铺被子，拿出自己的枕头，说换枕头就睡不着；燕说自己枕石头也能睡，麻央顶了一句让燕去睡石头，被莉波劝住。麻央要求留一盏小灯。星南说和大家这样一起度过的时间是最后一次，燕说可以再来，麻央接上，说不用学园活动也可以大家一起计划，星南说修学旅行只有这一次，高三的这一刻只有一次。

## 她的关键台词
- 0004「さて、明日は早いし、／布団敷いちゃおうか。」——主动提议铺被子，照顾后面的行程
- 0006「マイ枕だよ。ボクは枕が変わると、／眠れないたちでね。」——坦率说出自己换枕头睡不着
- 0008「じゃあ燕は石で寝れば。」——被燕的话刺到，针锋相对
- 0010「あ、豆は点けてて。」——请求留一盏小灯
- 0013「能の舞台も感動したよ。」——回应莉波的回忆，说出对能舞台的感动
- 0016「うん。学園の行事じゃなくてもさ、／今度はみんなで計画立てて――」——听到“最后”，主动提议今后大家自己计划再来

## 行为模式
- 被燕用话压 → 立刻回敬（0007、0008）
- 被莉波劝住 → 不再继续（0009 之后无麻央的反驳）
- 对睡觉的小习惯 → 不遮掩，直接说出（0006、0010）
- 听到“最后一次”的话 → 否定“最后”，提议下次大家再来（0016）

## 关系
- 燕：称「燕」（0008）；与燕斗嘴，燕称她「有村」（0005）
- 莉波：莉波劝架（0009）
- 星南：星南说最后一次时，麻央提议下次一起计划（0016）

## 档案类事实
- 换枕头会睡不着，所以带着自己的枕头（0006）
- 睡觉要留一盏小灯（0010）
- 在这次旅行中看过能的舞台，觉得感动（0013）

## 不确定
- 0010「豆」的具体所指剧本没有展开，按上下文理解为睡觉时留的小灯。
