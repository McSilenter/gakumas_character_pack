# S卡 3-0061【みんなの意見を聞かせて♪】 / 第3话 面食王子（adv_csprt-3-0061_03）

- 她的台词：11 行（含用匿名标签说的 0 行）
- 出场的人：麻央（11）、星南（9）
- 场景：买完必要的备品后，和星南走在路上；附近新开了一家章鱼烧店（0001、0007、0008）
- 世界线：S卡【みんなの意見を聞かせて♪】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
麻央买完需要的备品，对帮忙的星南道谢。星南说是自己说想确认宿舍状况才跟来的。麻央先叮嘱她不要问ことね在宿舍的私生活，接着闻到章鱼烧的味道。麻央说那是“有实力的店”，列出酱汁香味、点单后现烤等理由，说自己对面粉类食物比较讲究。星南产生兴趣，决定一起去吃，麻央说要教她最好吃的吃法，并邀她出发。

## 她的关键台词
- 0001「――必要な備品はこれで全部かな。／手伝ってくれて感謝するよ、会長。」——称星南「会長」，礼貌地道谢
- 0005「……寮での、／ことねの私生活について以外で。」——先把ことね的私生活排除在可问范围外
- 0009「あれは……デキる店だ！」——闻到章鱼烧味后突然兴奋，判断是好店
- 0011「漂ってくる香ばしいソースの香り……／注文が入ってから焼くスタイル……」——根据香味和做法逐条判断
- 0012「ボクの目に狂いはない。／あれは本物だ！」——断言自己的判断
- 0014「ふっ、ボクは、／粉物には少しうるさいんだ。」——被问是否喜欢章鱼烧时，说自己对粉物比较讲究
- 0017「今から並ぶと帰りが遅くなるけど、／キミは大丈夫なのかい？」——在兴奋中仍然替对方考虑时间，称「キミ」
- 0020「せっかくだから、最高に美味しい／食べ方を教えるよ。さあ、行こうか！」——主动提出教最好的吃法

## 行为模式
- 涉及ことね的私生活 → 事先叮嘱，让对方不要问（0005）
- 遇到喜欢的食物 → 冷静的语气一下转为兴奋，列依据断言（0009、0011、0012）
- 被指出和平时不同 → 轻笑承认，说“少しうるさい”（0014、0019）
- 对方有兴趣 → 先确认对方方便，再主动当向导（0017、0020）

## 关系
- 星南：称「会長」（0001）、「キミ」（0017）；星南称他「あなた」（星南 0013、0018）。星南对他说“いつもクールなあなた”（星南 0018）；他对星南的认可表示高兴（0019）
- ことね：他叮嘱不要问她的私生活（0005）；星南说自己不会公私混同（星南 0006）

## 档案类事实
- 对粉物（面粉类食物，如章鱼烧）比较讲究（0014）
- 会闻香味和做法来判断店的好坏（0011）
- 他教过星南宿舍的事，路上已经说过（0004）
