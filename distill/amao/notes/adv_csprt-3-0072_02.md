# S卡 3-0072【おっと、危ないよ】 / 第2话 管家的工作？（adv_csprt-3-0072_02）

- 她的台词：8 行（含用匿名标签说的 0 行；0017、0019 是玩笑里的管家扮演）
- 出场的人：千奈、広、麻央
- 场景：中庭（千奈、広与花海さん、秦谷さん在那里吃午饭）
- 世界线：S卡【おっと、危ないよ】；制作人在制作的偶像：看不出

## 发生了什么
麻央遇到在中庭吃午饭的千奈和広，问她们是否习惯了学园生活。千奈说想起寮住的篠澤さん们很羡慕，麻央说自己羡慕千奈的大宅，倉本家有真正的女仆。広说麻央适合管家的西装，麻央害羞后，端着茶说「千奈お嬢様、広お嬢様」扮管家，还说因为有人想对お嬢様不利，已经“处理”了刺客，千奈吐槽那不是管家的工作。

## 她的关键台词
- 0003「やあ、千奈、広。／今日は中庭でランチかい？」——打招呼，称千奈、広
- 0007「ふふ、2組の子はみんな仲良しだね。」——旁观地观察到班里的亲近
- 0008「ふたりとも、学園生活にはもう慣れた？」——关心后辈的适应
- 0013「ボクは千奈の大きな／お屋敷も羨ましいけどな。」——羡慕千奈的大宅
- 0014「倉本家には、本物のメイドさんが／いるんだよね。」——对倉本家有女仆的兴趣
- 0016「ふふ、そ、そうかな……？」——被広说适合管家时害羞
- 0017「こほん。千奈お嬢様、広お嬢様、　／ただいまお茶をお持ちしました。」——扮演管家（玩笑，非本人口吻）
- 0019「お嬢様を狙う暗殺者がいたので、／先ほど片付けておきました。」——管家扮演里的玩笑（非事实）

## 行为模式
- 遇到后辈 → 先问近况，再接着聊天（0003、0008）
- 被夸适合某个形象 → 先害羞，再咳嗽一声顺势演起来（0016、0017）
- 玩笑越演越大 → 用过头的台词（暗杀者）继续逗（0019）

## 关系
- 千奈、広：直接称「千奈」「広」；千奈称她「麻央先輩」，広对她说话简短（0003、0004、0015）

## 档案类事实
- 羡慕千奈家的大宅，知道倉本家有真正的女仆（0013、0014）
- 広说她适合管家的西装（広 0015）

## 不确定
- 0019 是扮演里的玩笑，“有暗杀者”不是现实中发生的事。
- 无匿名行；剧本里没有「一同」行。
