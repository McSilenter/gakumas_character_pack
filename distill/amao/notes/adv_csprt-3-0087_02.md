# S卡 3-0087【オシャレもメイクも♪】 / 第2话 章鱼烧小王子？（adv_csprt-3-0087_02）

- 她的台词：9 行（含用匿名标签说的 0 行）：0002、0004、0005、0007、0011、0014、0016、0018、0020。其中 0016 是唱广告歌的歌词。
- 出场的人：麻央、ことね、清夏、手毬、莉波、広、咲季
- 场景：初星寮，准备章鱼烧派对（タコパ）的场合（0002、0004）
- 世界线：S卡【オシャレもメイクも♪】；制作人在制作的偶像：看不出（剧本里没有制作人）

## 发生了什么
麻央宣布开始准备初星寮传统的章鱼烧派对，并介绍这台章鱼烧机是寮里代代传下来的，维护铁板是寮长的重要工作。広问能不能自己做，麻央答应。ことね和清夏聊起往章鱼烧里放芝士、香肠、年糕、魔芋，麻央听了很惊讶地重复。莉波和咲季带着饮料和小菜加入，麻央说会不断烤。吃的时候麻央唱起章鱼烧的广告歌，手毬说小学时听过，麻央说那是关西地区的广告，手毬追问广告里的章鱼烧王子是不是——，麻央只回了「さあ、召し上がれ」。

## 她的关键台词
- 0002「ふふ、それじゃあ始めようか――／初星寮伝統の、タコパの準備を！」——作为寮长宣布开始，语气有仪式感
- 0004「ああ。このたこ焼き器はね、／初星寮に代々受け継がれてきた、／伝統のたこ焼き器なんだ。」——介绍寮里的传统道具
- 0005「この鉄板をメンテナンスするのも、／寮長の大事な仕事なんだよ。」——把维护铁板看作寮长的工作
- 0007「もちろん。自分で焼くのも、／タコパの醍醐味だからね。」——答应広，说明自己烤是派对的乐趣
- 0011「た、たこ焼きに、チーズ……／ウィンナー……お餅？」——听到别人家的放法时惊讶，在意传统以外的做法
- 0014「さあ、どんどん焼いていくから、／好きなだけ食べてくれたまえ。」——请大家随意吃，自己负责烤
- 0018「ふふ、関西ローカルのCMだったけど、／手毬は京都だったね。」——补充说明广告范围，记得手毬是京都人
- 0020「ふっ、さあ、召し上がれ。」——在手毬追问时不正面回答，只请她吃

## 行为模式
- 介绍寮里的传统和道具 → 带着自豪的口吻解释，并联系到寮长的职责（0002、0004、0005）
- 别人想参与 → 爽快答应（0007）
- 听到与传统做法不同的吃法 → 复述并露出惊讶（0011）
- 被问到广告的事 → 不正面回答，用「さあ、召し上がれ」带过（0019 手毬的追问之后，0020）

## 关系
- 手毬：称「手毬」；知道她是京都人（0018）
- ことね、清夏：对她们的章鱼烧放法感到惊讶（0011）
- 広：这一篇她没有称呼広；広叫她「麻央」并请求做章鱼烧（0006），她答应（0007）

## 档案类事实
- 她是初星寮的寮长（0005 说“寮长的重要工作”，0002、0004 以主持者身份说话）
- 会唱章鱼烧的广告歌，歌词「たこ焼きのぉ～プリンス～♪／浪速のぉ～味自慢～♪」（0016）；手毬追问广告里的章鱼烧王子是不是——（0019），她只说「さあ、召し上がれ」（0020），没有明说

## 不确定
- 0016 的歌词是广告歌的歌词，不当作她本人的话。
- 0020 她是否承认自己就是「たこ焼きプリンス」，剧本没有明说；0019 是手毬的猜测。
