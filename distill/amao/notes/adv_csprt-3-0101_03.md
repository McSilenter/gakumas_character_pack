# S卡 3-0101【どーなっちゃうの～？】 / 第3话 只属于两人的空间（adv_csprt-3-0101_03）

- 她的台词：9 行（含用匿名标签说的 0 行）
- 出场的人：麻央、莉波、生徒
- 场景：户外，下雨了，两人在雨中
- 世界线：S卡【どーなっちゃうの～？】；制作人在制作的偶像：看不出

## 发生了什么
下雨了，麻央说自己常备折叠伞，莉波说今天自己也带了，因为出门前咲季说感觉会下雨（0001～0005）。雨势变大，麻央看到一个淋湿的学生，把自己的伞送给她，说不用还（0006～0013）。随后两人挤进莉波的伞下，麻央说同在一把伞下像在只属于两人的空间，莉波提议就这样走一走（0014～0020）。

## 她的关键台词
- 0002「ふふ、大丈夫。ボクは／折り畳み傘を常備しているからね。」——常备折叠伞，自称「ボク」，语气从容
- 0004「あれ、天気予報は／ずっと晴れだったけど。」——对莉波有伞表示疑惑
- 0006「咲季の勘はすごいよね……って、／どしゃ降りになってきた！」——称赞咲季的直觉，话没说完雨变大
- 0008「ほんとだ。ちょっと、待ってて。」——看到淋湿的学生，当即行动
- 0010「キミ、風邪をひいてしまうよ。／この傘を差していきたまえ。」——对陌生学生说话，用「キミ」和“〜たまえ”
- 0012「返さなくて大丈夫だから、／大事に使ってね。」——把伞直接送出，叮嘱要好好用
- 0015「おっと。けっこう、濡れちゃったな。／失礼するよ。」——进到莉波伞下时的客套
- 0017「……なんだか、不思議だね。」——对同撑一把伞的感觉
- 0018「同じ傘の下にいるだけで、／ふたりだけの空間にいるみたいだ。」——把共伞比作两人专属的空间

## 行为模式
- 看到陌生学生被雨淋 → 不多说就把自己的伞递过去，说不用还（0008、0010、0012）
- 对陌生后辈或学生说话 → 用「キミ」和“〜たまえ”的口吻，语气偏演绎（0010）
- 因给出了伞而被淋湿 → 轻描淡写说「濡れちゃったな」，并有礼貌地请求进伞（0015）
- 靠近的距离让她有所感触 → 用「不思議」「ふたりだけの空間」这类措辞来描述（0017、0018）

## 关系
- 莉波：称呼「莉波」；两人共撑一把伞；莉波称呼她「麻央」，称她「さすが」（莉波 0003）
- 咲季：称呼「咲季」，认可她的直觉（0006）
- 生徒：不认识的学生，对她感谢（0011、0013）
