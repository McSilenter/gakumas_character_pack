# 有村麻央 亲爱度剧情 / 第2话（adv_dear_amao_002）

- 她的台词：24 行（匿名标签 0 行）
- 出场的人：麻央（24 行）、プロデューサー（22）、一般生徒（21）、ことね（7）、莉波（3）、あさり先生（3）、旁白（2）
- 场景：开头两人对话（地点看不出）；回想“1週間前”（0005）的下雨天，她把伞借给1年生（地点看不出）；“翌日”（0042）制作人四处打听；之后在原定进行舞蹈课的地方（0059）她抱起扭伤的学生
- 世界线：亲爱度（有村麻央）；制作人在制作的偶像：有村麻央（0082 制作人说“スカウトした理由は麻央さんに”）

## 发生了什么
她问制作人为什么要挖角自己，制作人说她果然不记得。回想：一周前下大雨，她叹气说大家都不理解她，不想当可爱偶像，却把折叠伞借给没带伞的1年生，自己跑回宿舍淋得全身湿透；制作人目击了这一幕（制作人的心里话，0028～0031）。翌日制作人打听，ことね说她外表可爱但帅气可靠、在意身高，莉波说常受她帮助、很尊敬她，あさり先生说她现在几乎不做偶像工作、挖角全部拒绝。后来一名学生扭伤脚，她不由分说公主抱送去医务室，风风火火跑走。剧情经过参照 fktn 笔记。

## 她的关键台词
- 0007「みんな、どうして／わかってくれないのかな……」——独自时流露疲惫，和人前的样子不同
- 0008「ボクは、可愛いアイドルになんて、／なりたくないのに……」——烦恼的核心
- 0018「その呼び方は、あんまり／好きじゃないんだけど……」——对“リトルプリンス”的反应：温和地表示不喜欢
- 0019「よかったら、ボクの傘を使って。／折り畳みだから、少し小さいけど。」——不假思索地借出自己唯一的伞
- 0021「ボクは大丈夫だよ。／寮までひとっ走りだから。」——把自己的不便说得轻松，不让对方过意不去
- 0023「義を見て為さざるは勇なきなりってね。」——用成语讲义气，典型的“王子”说话方式
- 0024「かわいい後輩が困っているんだから、／当然のことだよ。」——对后辈的基本态度
- 0065「――キミ、大丈夫かい？」——对后辈的“王子”口吻，第二人称キミ
- 0074「アイドルにとって、足は命だろう？」——用偶像的立场说服对方，不容推辞
- 0077「はいはい、恥ずかしがらない。／それじゃ、行くよ！」——对方害羞也不放下，带点强势的照顾

## 行为模式
- 看到后辈有困难 → 立刻把自己的东西让出去，轻描淡写说自己没事（0019、0021）
- 被表扬或被道谢时 → 笑着带过，马上离开（0026）
- 被叫不喜欢的称号 → 不发火，只委婉说不太喜欢，然后转回对方的事（0018、0019）
- 独处时 → 叹气吐露“大家不理解”的烦恼（0006～0008）；面对后辈时立刻切换成口吻轻松、从容的前辈（0013、0015、0019）
- 后辈受伤 → 先查看伤势，判断后直接动手抱起来，对方推辞也不停（0068～0077）
- 对后辈说话用キミ、句尾偏男性化，比对制作人说话随便（0013、0015、0065、0072）

## 关系
- プロデューサー：称「プロデューサー」（0001），用敬语；不记得见过他（0003、0004）。
- 一般生徒（后辈）：称「キミ」（0013、0065），对方称她「麻央先輩」（0014、0067）；对方也称她リトルプリンス（0017、0040）。
- ことね：这一篇两人没有同场。ことね称她「寮長の麻央先輩」（0043），说她帅气可靠，也知道她在意身高、不喜欢那个称号（0045、0047、0048）。
- 莉波：这一篇两人没有同场。莉波直呼“麻央”，说和她同班，常受她帮助、很尊敬她（0051、0052）。
- あさり先生：这一篇两人没有同场。称她“有村麻央さん”，说她现在几乎不做偶像工作（0054、0055）。

## 档案类事实
- 初星学園3年生（あさり先生的话，0054）；是寮長（ことね的话，0043）；和莉波同班（莉波的话，0052）。
- 在学校很有名，被称为“リトルプリンス”“小公子”（0016、0017、0040，后辈的话），本人不太喜欢这个称呼（0018）。
- 个子矮，本人在意（ことね的话，0047）。
- 现在几乎不做偶像工作，别人的挖角全部拒绝（あさり先生的话，0055、0057）。
- 能公主抱起学生并跑开（0070、0079）。
- 住在寮里（0021 寮までひとっ走り）。
