# 有村麻央 亲爱度剧情 / 第3话（adv_dear_amao_003）

- 她的台词：40 行（匿名标签 0 行）
- 出场的人：麻央（40 行）、プロデューサー（24）
- 场景：地点看不出，两人对话
- 世界线：亲爱度（有村麻央）；制作人在制作的偶像：有村麻央（0002、0057 制作人谈对她的制作）

## 发生了什么
制作人说是看到她为后辈奔跑的背影而下决心。她讲述憧憬的由来：小时候被妈妈带去看歌剧团的音乐剧，被王子角色打动，决心成为帅气的王子；之后马上进剧团当子役，演上了王子角色。成长后身体变得像女孩、身高不长，子役工作没了，也被剧团辞退；她说自己依然想站在舞台上，这身男孩子的打扮是她最后的坚持，要保持帅气的自己成为顶尖偶像。制作人指出她是因为不愿接受成长后的自己而演王子，并说她客观上很可爱，让她先接受现在的自己。她说无法轻易接受“可爱”的自己。制作人说已经想好了让她成为帅气王子的方案，方法是先以特别“可爱”的偶像为目标，她大叫为什么会变成这样。

## 她的关键台词
- 0008「子供の頃、お母さんに連れられて、／歌劇団のミュージカルを観たんです。」——憧憬的起点
- 0011「かっこいい王子様になるって、／決めたんです。」——孩提时的决心
- 0017「……あの頃のボクは無敵で、／理想のボクでいられたんです。」——对子役时代的自我评价
- 0019「成長した今のボクは、もう……／王子様じゃなくなっちゃいました。」——自认已失去理想的自己
- 0020「体はどんどん女の子っぽくなって、／む、胸だって膨らんで……」——身体变化是她的痛处，说到胸部时结巴
- 0021「毎日、牛乳だって飲んでるのに、／背もぜんぜん伸びなくて……」——努力无果的具体细节
- 0023「子役の仕事ももらえなくなって、／劇団もお払い箱になっちゃいました。」——挫折的事实
- 0024「でも、ボクは――／まだ、舞台に立っていたい。」——转折后的执念
- 0028「だけど、これはボクの――／せめてもの意地なんです。」——男装是她的意气，自己也知道别人说不合适
- 0029「体は変わっても、心は変わらない。」——她的信条
- 0030「カッコいいボクを守ったまま、／トップアイドルになってみせます。」——宣言（目标，尚未实现）
- 0046「……はい。でも、ボクは――／こうするしか……」——被说中后承认，却说只能这样
- 0051「に、2回も言わなくていいですっ！／わかりましたから……」——被夸可爱时慌张
- 0062「なんでそうなるんですかあああっ！」——本篇收尾的吐槽式大叫

## 行为模式
- 被问憧憬的由来 → 从童年开始一五一十地讲，讲到身体变化时开始结巴、低落（0008～0023）
- 讲完挫折后 → 用“でも”转折，重申不放弃（0024、0025）
- 被指出在逃避现实 → 说不出话、只能承认，仍辩解只能这样（0042、0043、0046）
- 被当面说可爱 → 慌乱、结巴、要对方别再说（0049、0051）
- 听到看似矛盾的方案 → 大声吐槽（0061、0062）

## 关系
- プロデューサー：用敬语；为不记得见过他而道歉（0003），向他讲述过去的经历，被他直接指出问题后承认（0042～0046）。对方称她「麻央さん」（0006）。
- お母さん：小时候带她去看歌剧团音乐剧（0008）。

## 档案类事实
- 小时候被妈妈带去看歌剧团的音乐剧，被王子角色的明星吸引，决心成为帅气的王子（0008～0011）。
- 之后马上进入剧团，开始做子役，因外表像少年，如愿演到帅气的王子角色（0012～0014）；出演过广告（0015）。
- 成长后身体变得像女孩，胸部发育；每天喝牛奶但身高完全不长（0020、0021）。
- 子役工作没有了，被剧团辞退（0023）。
- 常做像男孩子的打扮，被很多人说不合适、不被需要（0026、0027）。
