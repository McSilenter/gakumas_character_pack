# 有村麻央 亲爱度剧情 / 第4话（adv_dear_amao_004）

- 她的台词：33 行（匿名标签 0 行）
- 出场的人：麻央（33 行）、プロデューサー（25）
- 场景：地点看不出，接第3话的对话（0001 接上话的反应）
- 世界线：亲爱度（有村麻央）；制作人在制作的偶像：有村麻央（0048～0049、0058 制作人谈她的偶像形象）

## 发生了什么
她生气地以为制作人和别人一样要她放弃王子，制作人否认，说刻意演可爱和演王子本质相同，希望她在舞台上展现真实的自己。她承认勉强立人设使笑容僵硬、歌舞也无法专注，但仍不想放弃憧憬。制作人说不必放弃，但要喜欢上自己；她被“讨厌自己的人当不了偶像”说动，表示会努力。制作人提出，把内在的高贵、凛然、帅气自然发挥出来，就能成为兼具可爱和帅气的“无敌の王子様系アイドル”。她被这个词打动，笑着答应，说要成为那样的偶像，再次请他多关照。

## 她的关键台词
- 0002「結局、あなたもみんなと／同じことを言うんですね！」——一听到相关话题就认定对方和别人一样
- 0005「ほら、やっぱり――／……え、違う？」——急着下结论，被否定后愣住
- 0016「……そう、なんでしょうね……／認めますよ、それは。」——不情愿但坦率地承认
- 0017「無理にキャラを作っているから、／笑顔もぎこちなくて――」——自我分析
- 0020「ボクはまだ、憧れを捨てたくない。／カッコイイ王子様になりたいんです。」——底线
- 0028「……そう、ですよね……／そんな当たり前のこと、ボクは……」——被点醒，反省自己
- 0031「ボクは――／今のボクを、好きになれますか？」——向制作人寻求确认，本篇的转折
- 0034「今のボクを好きになれるように、／努力してみます。」——打算（尚未做到）
- 0039「素のボクは、ちんちくりんで、／全然カッコいいって感じじゃないし。」——对素颜自己的评价很低
- 0050「無敵の王子様系アイドル……！」——听到这个词的反应
- 0052「それは、たしかに――／くすぐられるワードですね。」——被帅气的词打动，会得意地笑
- 0055「可愛くて、カッコイイ、／無敵の王子様系アイドルに――」——宣言目标（接 0054）

## 行为模式
- 听到疑似否定自己理想的话 → 立刻生气顶回去，打断对方（0001～0003）
- 对方讲道理且说中时 → 话变短，低声承认，再主动补充自己的问题（0008、0014、0016～0018）
- 被说“不用放弃” → 先愣住反问（0022）
- 需要被肯定时 → 直接问对方，用“ボクは”的句子开口（0031）
- 听到帅气的称号 → 忍不住“ふふふ”笑起来，马上有了干劲（0050～0055）

## 关系
- プロデューサー：称「プロデューサー」（0030、0056），用敬语；从生气到依赖其判断，主动问他自己能否喜欢上现在的自己（0031），最后再次说请多关照（0056）。

## 档案类事实
- 自认勉强立人设导致笑容僵硬，歌舞无法全力集中，全部空回转（0017、0018）。
- 用“ちんちくりん”形容素颜的自己（0039）。
- 对“无敌”“王子”这类词有反应（0050～0052）。
