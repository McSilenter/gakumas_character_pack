# 有村麻央 亲爱度剧情 / 第6话（adv_dear_amao_006）

- 她的台词：36 行（匿名标签 0 行）
- 出场的人：麻央（36 行）、ことね（21）、プロデューサー（17）
- 场景：她和制作人商量宣材写真的发型（0034）；地点看不出（杂志来自学园图书馆，0017）
- 世界线：亲爱度（有村麻央）；制作人在制作的偶像：有村麻央（0051 ことね称他“麻央先輩のプロデューサーさん”）

## 发生了什么
她为宣材写真找新发型，翻的却是从学园图书馆借来的辣妹盛发杂志，被制作人叫停，让她先想清楚想给粉丝看什么样的自己。ことね碰到两人，听说她想挑战可爱风格，大力赞成，还说她一直穿得像王子一样是“变な格好”，太可惜。她接受ことね帮忙，途中怀疑ことね在拿她玩。定下以放下刘海的样子为基础后，她向ことね道谢；ことね要拍照发给寮里的大家，她拼命阻止。剧情经过参照 fktn 笔记。

## 行为模式
- 想尝试新事物 → 自己先查资料，但判断不了资料好坏，当真地吃惊（0001、0002、0006、0012、0021）
- 说出想变可爱 → 话没说完就开始怀疑是不是奇怪（0038、0040）
- 被后辈说破穿着 → 不反驳，只是受打击地重复对方的话（0044）
- 拿不定主意时 → 问制作人的意见（0061），得到肯定才决定（0064）
- 被后辈捉弄 → 平静地指出（0058）；对方要把可爱的样子散播出去 → 彻底慌乱阻止（0070、0072）
- 对后辈的口吻：“ああ”“だ”“ね”，比对制作人随意（0034、0036、0047、0066）；一到制作人又变回敬语（0061）

## 关系
- プロデューサー：称「プロデューサー」（0004、0030），用敬语；向他请教，让他评价自己（0061～0063）。对方称她「麻央さん」（0003）。
- ことね：直呼「ことね」（0032、0058），对方称「麻央先輩」（0031）。接受她的帮助并道谢（0053、0066）；被她说打扮奇怪时受打击（0044）；不愿让她把照片发给寮里的人（0070）。

## 档案类事实
- 从子役时代起一直是同样的发型（0008、0048）；头发短，马上留长不现实，发型变化也少（0010、0056）。
- 不擅长判断时尚资料，一度把辣妹盛发杂志当作参考（0006、0012、0015、0018）。
