# 有村麻央 亲爱度剧情 / 第12话（adv_dear_amao_012）

- 她的台词：57 行（匿名标签 0 行）
- 出场的人：麻央（57 行）、ことね（23）、リーリヤ（16）、プロデューサー（11）、女の子A（5）、女の子B（3）
- 场景：迷你ライブ结束后，和粉丝互动（0001～0014）；回寮路上看到リーリヤ跑步（0037～0040）；回到寮碰到ことね，她自己说现在是夜里（0078）
- 世界线：亲爱度（有村麻央）；制作人在制作的偶像：有村麻央（0015、0031 制作人为她安排迷你ライブ）

## 发生了什么
迷你ライブ后她认真地和粉丝握手、签名、合照，『プリンス麻央イリュージョン』进展顺利，她很开心。分开回寮的路上，她看到1年生リーリヤ跑步练到很晚，リーリヤ出声后她赶上前询问（0041、0042、0044），便劝她还是1年生别勉强，リーリヤ说想成为偶像，她道歉说年级无关，只提醒天黑后练习危险。リーリヤ说自己没有才能所以要努力，她说能一直朝憧憬努力就是了不起的才能，又答说想成为“ボクらしい王子様”。在寮遇到ことね，她听说ことね也要参加N.I.A，提出替她打扫值日、当练习搭档，却被ことね说作为3年生不该顾后辈、还问是不是没把ことね放在眼里。她道歉，说ことね也是对手，两人约定全力竞争。她说被对手提醒、松懈的心情绷紧了，最后说“ライバルに教えられる”（对应第11话 0044 制作人的话，0115 带着“プロデューサー”这个称呼）。剧情经过参照 fktn、kllj 笔记。

## 行为模式
- 面对粉丝 → 笑着接受所有请求，用キミ、句尾轻松（0004、0008、0010、0013）
- 看到后辈过度努力 → 先担心，以“还是1年生”劝阻；被对方的决心打断 → 立刻道歉收回，只留下安全提醒（0050～0057）
- 对后辈的烦恼 → 不否定，用自己的价值观鼓励（0064～0066）
- 听到后辈参加比赛 → 第一反应是问能帮什么（0087、0089、0090）
- 被后辈尖锐指出 → 沉默后道歉，承认对方是对手，并道谢（0101、0104、0106、0107、0114）
- 自己累时 → 只在心里承认，对制作人说没事（0033、0037）

## 关系
- プロデューサー：称「プロデューサー」（0013、0036），用敬语，打趣他的表情（0023）；对方称她「麻央さん」（0015）。
- リーリヤ：直呼「リーリヤ」（0042、0061），称「キミ」（0051）；对方称「麻央センパイ」（0056）。关心其身体，尊重其决心（0050～0059）。
- ことね：直呼「ことね」（0076），也称「キミ」（0107）；对方称「麻央寮長」（0077）、「麻央先輩」（0094）。主动提出帮忙，被拒后接受为对手（0087～0112）。
- 粉丝：女の子B 自称初星学園中等部的池田まな（0009），她问是否也想进アイドル科（0010）。
