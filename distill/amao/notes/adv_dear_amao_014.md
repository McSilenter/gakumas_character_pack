# 有村麻央 亲爱度剧情 / 第14话（adv_dear_amao_014）

- 她的台词：46 行（匿名标签 0 行）
- 出场的人：麻央（46 行）、プロデューサー（22）、四音（16）
- 场景：『QUARTET』前（0001），等待莉波所在小组的オーディション（0038）；结果出来后四音现身（0045）；地点看不出
- 世界线：亲爱度（有村麻央）；制作人在制作的偶像：有村麻央（0012、0083 制作人的话）

## 发生了什么
下一场是『QUARTET』。她问莉波赢白草四音有没有希望，制作人说实力差距大；她说仍相信莉波。制作人调查了四音，她吓一跳，想起挖角时他连子役时代的影像都看过。听他夸四音，她话说一半收住。她得知四音小时候也在剧团，了解自己的子役时代，说“有村あきら”是自己子役时代的芸名，她却完全不记得四音。结果莉波败给四音。四音出现嘲弄莉波，她先按捺，说比赛输了无可奈何，但不容许愚弄莉波的努力。四音说她也一样，她回答自己放弃了成为歌剧明星的路转做偶像，但不是放弃梦想，要成为顶尖偶像实现成为王子的梦想。四音说要彻底粉碎她的梦想。她对制作人说绝对不会输。

## 行为模式
- 听到不利消息 → 先确认情况，然后说相信朋友（0004、0007、0008）
- 被制作人的调查吓到 → 惊讶后，顺势说他是唯一这样了解自己的人（0011、0015～0018）
- 听他称赞别的偶像 → 话说一半收回（0025）
- 朋友被羞辱 → 不暴怒，先把比赛和愚弄区分开，再明确说不容许（0056～0058）
- 被否定梦想 → 冷静地承认事实，再说明自己的立场（0063、0065～0072）

## 关系
- プロデューサー：称「プロデューサー」（0004、0080），也称「キミ」（0025）；有时不用敬语（0011）；信任他的调查，认可他比别人更了解自己（0015～0018）。对方称她「麻央さん」（0027）。
- 莉波：直呼「莉波」（0003、0058），相信她的胜利（0008）；因她被羞辱而愤怒（0058）。
- 四音：称「白草四音」（0046）、「四音」（0053）、「キミ」（0063）；对方称「有村麻央さん」（0045）。说自己完全不记得她（0030）；被挑衅后放话要实现梦想（0063～0072）。

## 档案类事实
- 子役时代的芸名是“有村あきら”（0029，第13话 0081 四音也这样叫她）。
- 子役时代在当地相当有名，カステラ的广告播得挺多（0032、0033）。
- 放弃了演员（役者）/成为歌剧明星的路，转做偶像（0036、0065、0066）。
- 子役时代的影像制作人全看过，包括难以到手的（0016）。
- 看过四音的ライブ映像（0022）。
