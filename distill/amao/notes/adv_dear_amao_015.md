# 有村麻央 亲爱度剧情 / 第15话（adv_dear_amao_015）

- 她的台词：55 行（匿名标签 0 行；0039 前半是朗读制作人写的留言）
- 出场的人：麻央（55 行）、四音（17）、莉波（10）、プロデューサー（10）、旁白（1）
- 场景：开头“数日前”（0001）莉波败北后（地点看不出）；之后是『QUARTET』当天（0020）
- 世界线：亲爱度（有村麻央）；制作人在制作的偶像：有村麻央（0020、0028 制作人的话）

## 发生了什么
回想：莉波说自己输了很不甘心，她说莉波的表演很棒，看的人都看在眼里；莉波看穿她想替自己报仇，劝她偶像要为支持自己的粉丝唱歌，她表示同意。『QUARTET』当天制作人交给她写满粉丝和后辈留言的色纸，她发现角落里的字是制作人写的，笑着道谢。四音称她“偽物の王子様”，她说否认不了，因为还没成为真正的王子。四音讽刺她那袖子过长的宽大衣服是在期待长高，她承认，并说这衣服是憧憬的形象，一度变成诅咒，但制作人解开了诅咒；这也是她无法切割的一部分，要穿着它继续演王子，直到有一天成为真正的王子。四音提到“お友達の3年生”，她说莉波没有被踩碎，第二次侮辱友人不能忍，要正面击溃四音。剧情经过参照 hrnm 笔记。

## 行为模式
- 朋友失败 → 先说对方的好，用“看的人都看到了”安慰，结果的部分说得小心（0006～0008）
- 被朋友看穿情绪 → 愣住，马上接受朋友的话（0014、0017）
- 收到留言 → 惊喜（0030、0032），发现制作人的字时笑出来（0039、0044），大方道谢，然后说要赢（0034、0045、0046）
- 被叫假货、被讽刺身高 → 不否认，正面承认，再讲述自己的立场（0049、0050、0056～0075）
- 朋友被提及 → 语气从平静变成狠话（0084～0090）

## 关系
- 莉波：直呼「莉波」（0002、0006），对方叫她“麻央”“まーお♪”（0003、0012）。称她“ボクの友人”（0089）；相信她会再站起来（0087、0088）。被她看穿了想报仇的心思（0013～0017）。
- プロデューサー：称「プロデューサー」（0035），用敬语；认得他的字（0038）；对四音时称他“あの人”，说他解开了自己的诅咒（0062、0063）。对方称她「麻央さん」（0025）。
- 四音：称「白草四音」（0048、0089）；对方称「有村麻央さん」（0047）。
- ことね、リーリヤ：在留言色纸上看到两人的名字或字（0033）。

## 档案类事实
- 穿着袖子过长的宽松衣服（四音的话，0054）；四音问她是不是期待长高，她承认（0055、0056）。这衣服是她小时候憧憬的舞台王子的形象（0058、0059）。
- 粉丝和后辈写了留言色纸（0028、0029，制作人的话）。
- 莉波是她的朋友（0089），也是3年生（第14话 0048 四音的话）。
