# 有村麻央 亲爱度剧情 / 第17话（adv_dear_amao_017）

- 她的台词：32 行（匿名标签 0 行）
- 出场的人：麻央（32 行）、プロデューサー（14）、莉波（8）
- 场景：观众很多的一场ライブ结束后（0001～0004），地点看不出，不在学园内（0022 莉波说回学园后）
- 世界线：亲爱度（有村麻央）；制作人在制作的偶像：有村麻央（0052 制作人说会一直支持她成为想成为的偶像）

## 发生了什么
大获成功的ライブ后，她说最初的迷你ライブ只有几个客人，感谢粉丝和制作人把她带到这里。莉波来祝贺，她说替莉波报了仇，又马上说不相干；莉波说下一次『H.I.F』不会放弃，她说可以陪练。她对制作人说和莉波是“戦友”，说“亲友”有点不好意思，两人这三年同样受过苦，想法和偶像立场都不同，但待在一起莫名舒服。她讲起今年春天赏樱时的对话：她说想像春樱一样绚烂绽放、美丽地凋零，莉波说想在不同季节展现不同的魅力、一直当偶像。她问制作人怎么想，制作人说都可以，她说自己的想法可能有些变了，也许不断变化成长的偶像也不错。

## 行为模式
- 被称赞成就 → 归功于粉丝和制作人，自己道谢（0005、0006）
- 想说的话不好意思 → 说一半改口（0014、0027）
- 被问起和朋友的关系 → 用“戦友”这种帅气的词，再解释（0025～0030）
- 对制作人偶尔大人的说法 → 吐槽（0033）
- 谈到未来 → 说想法可能变了，用商量的语气（0046～0049）

## 关系
- 莉波：直呼「莉波」（0011、0013），对方叫“麻央”（0010、0012）；称“戦友”（0025），说“亲友”不好意思（0027）；提出陪她练习（0023）；两人想法不同但待在一起舒服（0029、0030）。
- プロデューサー：称「プロデューサー」（0005、0045），也称「キミ」（0033），用敬语；对方称她「麻央さん」（0007）。说他也是学生（0033）。

## 档案类事实
- 最初的迷你ライブ客人只有几个（0002）。
- 今年春天，和莉波赏樱时谈过想成为的偶像：她说想像春樱一样华丽地绽放、美丽地凋零，莉波说想一直当偶像（0035～0040）。
- 想法变得认为不断变化、成长的偶像也不错（0046～0049）。
- 莉波是戦友（0025）；两人三年来同样受苦（0028）。
- 下一场比赛是『H.I.F』（0016，莉波 0017 说不会放弃）。
