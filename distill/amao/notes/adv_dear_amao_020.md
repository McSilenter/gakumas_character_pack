# 有村麻央 亲爱度剧情 / 第20话（adv_dear_amao_020）

- 她的台词：41 行（含匿名 0 行）
- 出场的人：麻央、プロデューサー
- 场景：她的 live 结束后，和制作人谈话（具体地点剧本没写）
- 世界线：亲爱度（有村麻央）；制作人在制作的偶像：有村麻央（0051「あなたをプロデュースさせて／貰えて」）

## 发生了什么
live 成功后，制作人告诉她后辈们自发帮忙发传单、整理队伍，说是她平时的行为和温柔高贵的心打动了大家。她心情复杂，说自己帮助别人原本是为了演理想中的王子，是为了自己。制作人说即使最初如此，现在已经成了她的本质，并提起当初是因为她在雨天把伞给后辈才打动自己。她接受了“演王子的自己也是真的自己”。看到制作人穿的粉丝 T 恤袖口写着『The Little Prince』，她说以前不喜欢这个称呼，现在挺喜欢了，并解释理由。制作人说要让她比现在更喜欢自己，让她成为『一番星』，她和他约定。

## 她的关键台词
- 0004「まだお客さんが数人だった頃の、／最初のミニライブが懐かしいですね。」——回想起步期。
- 0016「もともと、理想の王子様を／演じるためにやっていたことだから、」——坦白帮助别人的最初动机是演王子。
- 0017「ぜんぜん、気高くなんてない。／自分のためにしてたことなんです。」——被夸时否认“高贵”，自我贬低（这是这时的自评，紧接着被制作人回应并被她自己部分接受）。
- 0025「王子様の役を演じるボクも、／ホントのボクなんだ……」——转折点：接受演出来的自己也是真的。
- 0039「リトルプリンスって呼び名、／前は好きじゃなかったけど……」——这个称呼的过去态度（以前）。
- 0040「今は結構、気に入ってるんです。」——现在的态度。
- 0041「後輩たちが、ボクのことを慕って／付けてくれた名前だから。」——喜欢这个称呼的第一个理由。
- 0044「ふふっ、トップスターを目指すボクに／ぴったりの名前じゃないですか。」——第二个理由，带自信的玩笑。
- 0046「ずっと憧れだったものが、／自分を縛る鎖になったり、」——对过去的总结。
- 0047「嫌いだって目を背けていたものが、／本当に大切なものだったり。」——同上。
- 0049「受け入れて、ボクらしく、／変わっていこうと思うんです。」——之后的打算（不是已完成的变化）。
- 0056「あの頃のボクは、ずっと、／ボクのことが嫌いでした。」——说出以前讨厌自己。
- 0058「キミが掴んで、／助け出してくれました。」——把得救归功于制作人（接 0057）。
- 0069「ボクのこと、もっともっと、／好きにならせてください。」——主动提出请求，把约定续下去。

## 行为模式
- 被夸“温柔高贵” → 先高兴，马上说复杂，坦白动机不纯（0013～0017）
- 听到别人说最初动机不重要 → 沉默后笑着接受，用自己的话重新说一遍（0020、0024、0025）
- 对曾经讨厌的称呼 → 现在换成自己的解释，用外语、书名的知识把它变成自信的玩笑（0039～0044）
- 制作人做傻事（穿粉丝 T 恤喊到嗓子哑）→ 吐槽，笑着说他（0032、0067）
- 被承诺“更喜欢自己” → 先一愣确认，再道谢，用「約束」定下来（0062、0066、0068、0069）

## 关系
- プロデューサー：称「プロデューサー」（0052、0066）、「キミ」（0058）；对方称「麻央さん」（0001）。对他坦白内心，感谢他救了自己，并主动要他继续兑现约定。
- 后辈们：制作人说她们称「麻央先輩」且自发帮忙（0009）；她说这个称呼是后辈仰慕她而取的（0041）。

## 档案类事实
- 刚起步时的迷你 live 只有几个观众（0004）。
- 她帮助别人最初是为了演理想中的王子（0015～0017，本人说）。
- 以前讨厌自己，无法成为理想王子时很痛苦（0056、0057）。
- 「リトルプリンス」这个称呼以前不喜欢，现在喜欢；她说是后辈们起的（0039～0041）。
- 她说『The Little Prince』的法语是『Le Petit Prince』，『星の王子さま』的原题（0042、0043）。
- 粉丝俱乐部为这场 live 做了印有她形象的 T 恤，制作人穿着（0026、0027）；袖口有『The Little Prince』字样（0036）。
- 目标是トップスター（0044）；制作人要让她成为『一番星』（0063）。
- 制作人当初是因为雨天她把伞给后辈而发掘她（0022、0023，制作人说）。
