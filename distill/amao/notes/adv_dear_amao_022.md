# 有村麻央 亲爱度剧情 / 第22话（adv_dear_amao_022）

- 她的台词：29 行（含匿名 0 行）。0048、0049 和第21话 0086、0087 文字相同，是回放式的插入，行数照算。
- 出场的人：麻央、プロデューサー、十王社長、ことね、手毬、リーリヤ、清夏、燕、星南、莉波
- 场景：后辈们祝贺她（地点剧本没写）；之后十王社長和制作人的谈话；之后麻央和制作人碰面（地点剧本没写）
- 世界线：亲爱度（有村麻央）；制作人在制作的偶像：有村麻央（0030 社長说要他卸任她的担当，0064「約束したじゃないですか。」）

## 发生了什么
宿舍后辈们祝贺她要加入 100プロ，ことね叫她「麻央ちゃん先輩」，她要求在人前不要这样叫，手毬问能不能也这样叫，她说可以。她说受到认可的不只是自己，社长也认可了制作人；大家提议办派对，她一度推辞，又谢谢大家的心意。之后十王社長告诉制作人，因为他还是学生、经验不足，要他卸任，由 100プロ 的制作人接手，毕业后再说。第二天她高兴地说昨晚和母亲打电话，母亲很开心，也感谢制作人；制作人告诉她要卸任的事，她说不行，提起约定，最后用「ばか」「ボケナスのドアホ」「アホンダラ」大骂他。（剧情经过参照 ttmr 笔记）

- 0065「可愛くて、カッコイイ、／無敵の王子様にしてくれるって！」——拿约定质问。

## 行为模式
- 被后辈亲昵称呼 → 嘴上提醒人前不行，实际允许（0007、0010）
- 被祝贺 → 道谢，把功劳分给制作人（0013、0014）
- 大家要为她庆祝 → 先推辞、替别人担心，被说服后说高兴（0017、0024）
- 对家人 → 差点说成亲昵的叫法，马上改成「母」（0053）
- 听到被抛下的消息 → 先否定，拿约定质问，然后情绪决堤骂出来，被制止也不停（0063～0065、0076、0077、0080）

## 关系
- プロデューサー：称「プロデューサー」（0051）；对方称「麻央さん」（0059）。把他的卸任当成背弃约定，骂他。
- 母亲：称「母」，差点说成亲昵的叫法（0053）；母亲为她当职业偶像高兴，也感谢制作人（0054、0056）。
- 后辈：ことね称「麻央ちゃん先輩」（0002）、「麻央先輩」（0008）；手毬称「有村先輩」（0004）；清夏称「まおっち先輩」（0011）；リーリヤ称「麻央センパイ」（0001）。她称「ことね」（0020）。
- 十王社長：她称「十王社長」（0014），认为社长也认可了制作人。

## 档案类事实
- 她是 3 年生（0007，本人说）。
- 母亲和她通电话，她辞演员后母亲一直担心（0053、0055）。
- 母亲做的明石焼き她说很好吃（0058）；她转述母亲的话，说制作人来兵庫时要请吃饭（0057）。
- 社长的条件：制作人还是学生、经验不足，由 100プロ 的制作人接手，他毕业后才可能重新担任（0030、0032、0038、0041、0046，社长说；0066、0067，制作人转述）。
