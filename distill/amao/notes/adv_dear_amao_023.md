# 有村麻央 亲爱度剧情 / 第23话（adv_dear_amao_023）

- 她的台词：41 行（含匿名 0 行）。0001、0002 是心里话；0089 是回放（文字和第4话 0031 相同）。
- 出场的人：麻央、四音、プロデューサー、あさり先生、？？？（＝四音）、月花、メイド
- 场景：商店街（0035）的店里；她带四音去的芭菲店（0031）；另一边是制作人在找她
- 世界线：亲爱度（有村麻央）；制作人在制作的偶像：有村麻央（0020 あさり先生说「担当アイドル」，指有村）

## 发生了什么
大骂制作人之后，她反省自己感情用事，决定去道歉，却撞见四音在店里付不了钱被当作吃霸王餐，替她垫付了章鱼烧的钱。她带四音去芭菲店，四音说自己因月花住到家里才跑出来，并提议和她组 unit 把月花拉下极月的顶点，她没兴趣，反过来要四音听自己发牢骚。四音说学生制作人一脚踢开就好，说出当年当童星时和她共演过一次、当时她说要成为トップスター和王子様；还说听到她不当童星时很高兴，看到她转去当偶像却火大。她接着四音的话说“像是看到你自己吧”，说四音也有憧憬的人，说到一半点明这是在说她自己。想起和制作人的约定后，她向四音道谢，拒绝组 unit，劝四音好好喜欢自己，然后说要去「殴り込み」。

## 她的关键台词
- 0001「（……ボクとしたことが、／感情的になってしまったな……）」——心里话，事后反省。
- 0004「……謝ろう。」——自己做出道歉的决定。
- 0034「それ、去年のプロフィールだろ。／今は更新されてるよ。」——对喜欢甜食的公开改口，轻松带过。
- 0050「悪いけど、スカウトは／間に合っていてね。」——带点王子腔调地拒绝。
- 0052「……ま、キミでもいいや。／ちょっと、ボクの話を聞いてくれよ。」——对同辈不客气地拉来倾诉。
- 0062「……相談する相手を間違えたよ。」——四音说制作人是工具时的回应。
- 0076「キミ自身を見ているようだった？」——把四音的恨意反过来点破。
- 0078「四音、キミとボクは案外、／似たもの同士なのかもしれないね。」——承认和对手相似。
- 0083「そんな自分のことを、否定して、／どんどん嫌いになってしまって。」——描述憧憬够不着的痛苦。
- 0086「……ボクの話だよ。」——转折：刚才说的是她自己。
- 0098「だったら、キミ自身のことを、／ちゃんと好きになるといい。」——把制作人对她说的道理说给四音（劝告）。
- 0099「……なんて、ボクが偉そうに／言えた立場じゃないけど――」——马上自嘲。
- 0101「ああ。ちょっと――／殴り込みにね。」——下一步的打算，带笑的强硬。

## 行为模式
- 情绪爆发之后 → 独自反省，先觉得自己不对，也觉得对方该反省，然后决定去道歉（0001、0002、0004）
- 看到认识的人出丑、有麻烦 → 先替她解围，再用这份人情让她听自己说话（0009、0054）
- 被对手挑衅 → 用吐槽、反问拆台，不被带着走（0037、0041、0046、0048）
- 被对手说出恨意 → 接过对方的话，用「キミ」点破，说到最后摊开说是在说自己（0076、0078、0080～0084、0086）
- 想通之后 → 拒绝对方、感谢对方、再给一句带自嘲的忠告，马上行动（0093、0095、0097～0099、0101）

## 关系
- プロデューサー：这一话没有当面对话（0088、0090 是回放）；她嘴上说他也该反省（0002），想起约定后决定去行动（0091）。
- 四音：称「四音」（0009）、「キミ」（0035）；四音称她「有村麻央」（0010）、「あなた」（0036）、「有村あきら」（0063）。虽然是对手，她替四音解围，也愿意和四音倾诉，感谢她。
- 月花：这一话她没有称呼月花，只说「お姉さん」（0041）指月花。

## 档案类事实
- 四音说麻央从前的公开资料（プロフィール）写着甘い物は苦手；麻央说那是去年的，现在已更新（0033、0034）。
- 这家店她和制作人来过，季節のフルーツのスペシャルパフェ是她的推荐（0031、0032）。
- 四音说：自己当童星时和她共演过一次，当时麻央是有名的童星，并对她说过要成为トップスター和王子様（0066、0068、0070）。她说不记得了（0067）。
- 四音称她「有村あきら」（0063）；这是她童星时期的艺名，第14话 0029 她本人这样说过。
- 她是因为想成为憧憬的样子却够不着，才讨厌自己、不能正视粉丝和偶像的（0082～0084、0086，本人说）。

## 不确定
- 「？？？」0005、0007、0008 按 0009、0010 是四音，不算她的台词。
- 0088～0090 是回放：0088、0089 和第4话 0026、0031 文字相同；0090 制作人那句在第4话 里没有（第4话 0031 后接她的沉默 0032），应是选项后的话没写进剧本，这里按回放出现。
- 0063 四音说出「有村あきら」的语气，这一话没有展开解释。
- 0080 她说四音也有憧憬的人，是她的推断，四音没有承认（0081、0085）。
- 0101「殴り込み」按第24话 是去 100プロ 找十王社長，这一话本身只说了这句话。
