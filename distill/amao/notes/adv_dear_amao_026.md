# 有村麻央 亲爱度剧情 / 第26话（adv_dear_amao_026）

- 她的台词：25 行（含匿名 0 行）
- 出场的人：麻央、プロデューサー、十王社長
- 场景：她和制作人碰面（地点剧本没写）；之后和十王社長当面谈
- 世界线：亲爱度（有村麻央）；制作人在制作的偶像：有村麻央（0043「俺が、麻央さんのプロデューサー」）

## 发生了什么
制作人带着章鱼烧来和解，她为骂人道歉。制作人说她应该飞向职业的世界，当时自己本该立刻回答唯一能和她追同一个梦的是自己；她听了笑了，说想和他一起飞，什么都不放弃。制作人提出作战：十王社長只看结果，就用结果证明。之后当着社長的面，她前言撤回，接受 100プロ 的 scout，但带条件；她和制作人向社長提出要在『H.I.F』优胜，社長说不可能赢星南，但优胜的话自己没有损失；他没有明说答应，制作人道谢（0057、0058）。两人当面宣告会赢。

- 0006「キミがボクのこと、考えてくれたのは、／わかっていたんですけど。」——承认知道他的用心。

- 0019「キミとだから、吹き荒ぶ嵐の中だって、／飛んでいける。」——把决心和他绑定。
- 0021「キミも、全部諦めない。」——他也是她“全要”的一部分。
- 0022「全部、ボクらしく獲りに行く。」——打算，宣言。
- 0023「ボク、けっこう欲張りなんですよ。」——自我定义。
- 0033「……まあ、理解は、しますよ。／納得はできませんけど。」——理性上懂，情感上不接受。
- 0038「前言撤回。君子豹変。／100プロのスカウト、お受けします！」——说变就变的灵活。
- 0045「『H.I.F』で優勝します。」——当面宣告。
- 0062「勝ちますよ。絶対に。」——同上。

## 行为模式
- 冷静下来之后 → 道歉，承认对方的好意（0005、0006）
- 听到他要一起追梦 → 沉默后笑着接，说自己也想（0016～0018）
- 听到作战 → 立刻改变先前的决定，向社長提条件（0033、0038、0040）
- 面对否定和嘲讽 → 不争论，只用结果说话（0045、0053、0062）

## 关系
- プロデューサー：称「キミ」（0006、0018）、「プロデューサー」（0013）；对方称「麻央さん」（0012）。说他是最棒的制作人（0034）。
- 十王社長：这一话里对他的语气是敬语且强硬（0045、0053）。社長称「君達」（0047、0055）。
- 星南：这一话她没有称呼星南。

## 档案类事实
- 她说自己对粉物很挑剔（0002）。
- 她自称贪心（0023）。
- 制作人说她在宿舍迎新派对上策划了泳池、试胆、BBQ、卡拉OK、流水素面全部都要（0025、0026）。
- 约定内容：在『H.I.F』优胜，由结果证明制作人是最合适的人选（0042、0043、0045、0052～0057）。

## 不确定
- 0045 说的是哪一届『H.I.F』，这一话没有说夏或冬；第27话 0012、0013 她说是冬季，第21话 0005 她自己提过夏季。
- 【译文】0038「君子豹変。」译文“大丈夫能屈能伸”，和原文意思（立即改变态度）不一样。
