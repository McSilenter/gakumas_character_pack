# 有村麻央 亲爱度剧情 / 第29话（adv_dear_amao_029）

- 她的台词：45 行（含匿名 0 行）。0070 是心里话。
- 出场的人：麻央、広、千奈、清夏、リーリヤ、一同、プロデューサー
- 场景：她和后辈的合同训练（地点剧本没写）；之后向制作人报告
- 世界线：亲爱度（有村麻央）；制作人在制作的偶像：有村麻央（剧本里没有直接说法）

## 发生了什么
她开始和后辈们一起训练。先和千奈、広：她说教别人是最好的学习，称赞千奈网节目的反应是只属于她的魅力，広的神秘感让粉丝增多；训练时太投入，把两人练到极限，道歉说一投入就看不到周围。之后清夏、リーリヤ发现她倒在地上，她说只是在放松。她请清夏教足尖的表现，自己差点抽筋被扶住，リーリヤ的训练成长让她吃惊。最后向制作人报告，说每个人都放出不同颜色的光，以读过的蛍石打比方，说要接受大家的光用自己的方式闪耀。（kcna、kllj、shro、ssmk 笔记有其他偶像的视角）

## 她的关键台词
- 0006「ふふ、誰かに教えることは、／一番の勉強になるからね。」——对教的态度。
- 0007「ボクもキミたちから、／たくさん学ばせてもらうよ。」——对后辈放低姿态。
- 0017「ボクにも、星南や燕にもない、／千奈だけの魅力だよ。」——具体指出别人的长处。
- 0035「……ご、ごめん。ボク、熱中すると、／周りが見えなくなる癖があって。」——自述毛病。
- 0051「劇団にもバレエを習ってる子は／けっこういたけど、／清夏のが一番綺麗だよ。」——夸人时带着自己的经历。
- 0053「なにか綺麗に見せるコツがあるのかな？」——三年级也直接向后辈请教。
- 0061「リーリヤ、どうしたの？／――おいで。」——无意识的王子腔调。
- 0070「（そのひたむきなキミの心が、きっと、／ファンの心に火を灯すんだろうね）」——心里话。
- 0076「みんな、違う色の光を放ってる。」——课题的结论。
- 0078「蛍石は、中に含まれる元素によって、／輝く色を変えるそうです。」——用读到的知识打比方。
- 0080「ボクらしく、輝いてみせますよ。」——宣言。

## 行为模式
- 指导后辈 → 先说自己也要学，具体指出每个人的魅力（0006、0007、0017、0019、0020）
- 指导太投入 → 把别人练到极限，被指出时结巴道歉（0034、0035）
- 被人发现躺在地上 → 说只是在放松，装没事（0046、0048）
- 夸后辈 → 用具体比较，把对方夸到害羞（0051、0052）
- 想学别人的东西 → 直接问诀窍，自己照做到抽筋（0053、0055、0057）
