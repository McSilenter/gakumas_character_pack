# 有村麻央 亲爱度剧情 / 第30话（adv_dear_amao_030）

- 她的台词：30 行（含匿名 0 行）
- 出场的人：麻央、莉波、美鈴、プロデューサー、手毬
- 场景：『選抜試験』之后和莉波谈话；和手毬、美鈴的训练；之后和制作人谈写真集
- 世界线：亲爱度（有村麻央）；制作人在制作的偶像：有村麻央（剧本里没有直接说法）

## 发生了什么
『選抜試験』后莉波慰问她，她说比夏季『H.I.F』时整体水平上升，作为高年级不能输，也提到正和一年级的孩子们一起练习。莉波说没有和我的训练吗，她笑着说很清楚莉波的魅力，随时可以陪练。莉波说自己因为她的『FINALE』和优胜 live 又想起想当偶像的心情。她和手毬、美鈴练习，听到手毬舞台上的歌，感叹像在削魂。美鈴问“憧憬看不见、一直追的光消失时怎么办”，她答要自己点亮光，心里还有光，也说曾经迷失、有人给了找到心中之光的契机。制作人提出做写真集，要呈现现在的憧憬和理想形象，这也是冬季『H.I.F』的策略，她说很期待。（剧情经过参照 hmsz、ttmr 笔记）

## 她的关键台词
- 0004「ああ。夏の『H.I.F』のときより、／全体のレベルが上がってる。」——对竞争环境的判断。
- 0005「上級生として、／負けるわけにはいかないね。」——高年级的自觉。
- 0017「……あはは。／莉波のアイドルとしての魅力は、／よくわかってるからね。」——对最亲的同级轻松带过。
- 0032「ふふ、ライブのときの手毬、／すごくカッコいいよ。」——当面夸后辈。
- 0045「……すごいな。／ステージでの手毬の歌い方って、／まるで魂を削ってるみたいだ。」——对后辈的感想。
- 0056「ボクは……光を、灯すよ。」——对美鈴问题的回答。
- 0057「もし目の前が真っ暗になっても、／ボクの中に、まだ光はあるから。」——信念（假设语气）。
- 0059「見失ったときもあったよ。」——紧接着美鈴的「強いんですね」，坦白自己也迷失过。
- 0060「ボクの中の光を見つける、／きっかけをくれた人がいたんだ。」——这个人没有点名。
- 0075「アイドル有村麻央のことを、／ボク自身がより深く理解できる。／……そういうことですね。」——用自己的话确认制作人的用意。

## 行为模式
- 被同级试探“有没有和我的训练” → 笑着带过，说随时可以（0015、0017、0019）
- 被后辈认真地问难题 → 沉默之后短句回答，再坦白自己也曾迷失（0055～0060）
- 夸人后对方当真 → 只能愣住笑（0040、0043）
- 听到制作人的策略 → 先复述理解，确认（0074、0075）

## 关系
- 莉波：称「莉波」（0002）；莉波称「麻央」（0001）。莉波说最了解她偶像魅力的是自己（0026）。
- 手毬：称「手毬」（0032）、「キミたち」（0049）；手毬称「有村先輩」（0027）。这里手毬称「有村先輩」，不是第22话 问过的另一称呼。
- 美鈴：这一话她没有点名称呼美鈴，只说「ふたり」「キミたち」（0048、0049）；美鈴称「有村先輩」（0051）。
- プロデューサー：称「プロデューサー」（0061）；对方称「麻央さん」（0062）。

## 档案类事实
- 她说这次训练是制作人的课题，和一年级的孩子一起（0008、0009；0007 莉波说一年级）。
- 她（和莉波）都参加了『選抜試験』（0001、0002）。
- 写真集：制作人提议，要呈现她现在的憧憬和理想形象；此前的 self-image 收在『Fluorite』的衣装里（0062、0068、0071，制作人说）。
- 莉波说她的『FINALE』和优胜 live 让自己想起想当偶像的心情（0023、0024，莉波说）。
