# 有村麻央 亲爱度剧情 / 第36话（adv_dear_amao_036）

- 她的台词：29 行（含匿名 0 行）
- 出场的人：麻央、学園長、星南
- 场景：『H.I.F』本战结束后的『一番星』授与式（0006）的舞台
- 世界线：亲爱度（有村麻央）；制作人在制作的偶像：有村麻央（0034 她感谢「共に夢に翔けてくれた、／プロデューサー」）

## 发生了什么
学園長宣布『Hatsuboshi IDOL FESTIVAL』优胜者是有村麻央。现任『一番星』星南祝贺并道谢，说谢谢她来迎接自己。她回忆入学式时星南以首席身份在这里开 live，同样是一年级却像完美的明星，一直是憧憬的星，说抱歉来晚了，终于站到星南身边。星南把『一番星』交给她，让她对粉丝说话。她报上 3 年 1 组，感谢粉丝、工作人员、教练老师、父母、对手、战友和制作人，说自己成为了『一番星』，说『一番星』的光在每个想当偶像的人心中，有时会被现实压垮而看不见，请大家不要忘记。（星南部分的经过参照 jsna 笔记）

## 行为模式
- 站上最高点 → 第一件事回想对方，说来晚了（0015、0020、0022、0023）
- 获奖感言 → 按顺序感谢所有人，把制作人放在最后（0029～0034）
- 自己的胜利 → 变成对所有人的话（0040、0046、0047）

## 关系
- 星南：称「キミ」（0015）；星南称「麻央」（0012）、「あなた」（0025）。一直是憧憬的星，现在她站在身边。
- プロデューサー：这一话没有对话，演讲里感谢（0034）。

## 档案类事实

- 她是初星学園 3 年 1 組（0028）。
- 入学式那天星南以首席身份开过 live，地点是这里（0015）。
- 她称自己是被父母养育的（0031）。
