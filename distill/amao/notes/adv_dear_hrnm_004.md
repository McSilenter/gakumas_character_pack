# 姫崎莉波 亲爱度剧情 / 第4话（adv_dear_hrnm_004）

- 她的台词：31 行（匿名标签 0 行）
- 出场的人：莉波（41 行）、麻央（31）、プロデューサー（13）
- 场景：教室（0002 制作人说“まだ教室にいるはず”），麻央和莉波在聊天，制作人来送课表、在旁边听到了（0001～0005、0072）
- 世界线：亲爱度（姫崎莉波）；制作人在制作的偶像：姫崎莉波（0001「姫崎さんにレッスンのスケジュールを」、0080）

## 发生了什么
莉波说今早睡过头，麻央说对认真的她来说是少见的失误；莉波反说麻央更认真，宿舍后辈的请求全都接下，麻央说自己又不像莉波在生徒会（0003～0010）。麻央说莉波最近印象变了、有点成熟，然后问起“例のプロデューサー”怎么样，说若是马虎的制作人自己不会原谅，不过能发掘莉波，至少有眼光（0011～0026）。听说莉波在上“当姐姐”的课、把制作人当弟弟对待，麻央跟不上；听到给制作人做饭、打电话叫起床、整理领带，麻央说要去和她的制作人“谈谈”，被莉波拦住（0030～0055）。听莉波解释后，麻央说既然是莉波选的人，一定可信，有事找她商量，她会保护莉波（0058～0061）。麻央说被后辈请去当舞蹈搭档，离开时撞见了偷听的制作人，道了歉（0063～0066）。

## 她的关键台词
- 0004「ふうん、しっかりもののキミにしては、／珍しい失敗だね。」——对朋友的评价：可靠的人
- 0008「ボクは莉波みたいに、／生徒会に入ってるわけじゃないからね。」——被说揽下所有请求时的回应
- 0013「なんだか、大人びた感じがするよ。」——注意到朋友的变化
- 0017「そういえば、例のプロデューサーとは／どうなんだい？」——关心朋友的制作人
- 0023「もしいい加減な／プロデューサーだったら――」——护着朋友
- 0024「ボクが許さないから。」——同上
- 0026「少なくとも、素質を見抜く目はある、／プロデューサーなんだろうけど。」——也承认对方有眼光
- 0037「……ま、まってまって、莉波。／ちょっと理解が追いつかないよ。」——对“当姐姐的课”一头雾水
- 0054「ちょっと、キミのプロデューサーと／話をつけてくるよ……」——觉得朋友被利用时马上要出面
- 0059「莉波が選んだんだから、／きっと、信頼できる人なんだろうね。」——以对朋友的信任为准
- 0061「まあ、なにかあったら相談してよ。／ボクが守ってあげるから。」——保护者的姿态
- 0063「おっと、そろそろ行かないと。後輩に／ダンスパートナーを頼まれていてね。」——又被后辈托事

## 行为模式
- 朋友有了变化 → 留意到并直说（“印象が変わった”“大人びた”）（0011、0013）
- 朋友身边出现新的人 → 先问情况，表明若对方不靠谱自己不会放过（0017、0023、0024）
- 听到朋友似乎在为别人付出太多 → 立刻要去找对方“谈判”（0054）
- 朋友说是自己愿意的 → 收回，转为相信朋友的选择，并说有事就来找她、她会保护（0058～0061）
- 撞到人 → 马上道歉（0066）
- 说话：「ボク」「キミ」，语尾“～だね”“～かい？”（0004、0017、0030）

## 关系
- 莉波：叫「莉波」（0010、0019、0037）、「キミ」（0004）；莉波叫她「麻央」（0006、0053）。莉波说她更认真、宿舍后辈的请求全都接下（0006、0007）；她关心莉波的制作人，说会保护莉波（0061）。莉波的制作人在 0085 心里说“姫崎さんは、いい友人がいるようだ”。她知道莉波以前的组合里是妹妹位置（0042）。
- 莉波的制作人：没有当面称呼；对莉波称他「例のプロデューサー」「キミのプロデューサー」（0017、0054）。最后撞见时对他说“すみません”（0066）。

## 档案类事实
- 莉波说她把宿舍后辈的请求全都接下（0007，莉波的话）。
- 她没有加入生徒会（0008）。
- 被后辈请去当舞蹈搭档（0063）。
- 知道莉波以前所在组合里是“妹ポジション”（0042）。
