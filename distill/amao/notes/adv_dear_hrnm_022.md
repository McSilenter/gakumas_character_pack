# 姫崎莉波 亲爱度剧情 / 第22话（adv_dear_hrnm_022）

- 她的台词：12 行（匿名标签 0 行）
- 出场的人：莉波（48 行）、プロデューサー（19）、カナ（14）、麻央（12）
- 场景：莉波见过以前的伙伴カナ之后，在洗衣服的地方碰到麻央（0027“キミも洗濯かい？”）；具体地点剧本没写明。『H.I.F』之前（0030、0050）
- 世界线：亲爱度（姫崎莉波）；制作人在制作的偶像：姫崎莉波

## 发生了什么
麻央看到莉波，问她也是来洗衣服的吗，说这个季节洗的衣服多；莉波说为了『H.I.F』练习也变苦了（0027～0030）。莉波说麻央憧憬的偶像形象一直没变，麻央说自己要成为王子様，想在大舞台上迷住观众、沐浴喝彩和聚光灯（0033～0035）。莉波说麻央从1年生起就一直追着同一个憧憬，麻央道谢，说自己其实一直在迷茫，并问莉波也有理想的偶像形象吧、是不是还模糊（0036～0041）。听莉波说起憧憬“歌のお姉さん”、看了麻央她们的舞台而想“我也要”，麻央说这是很有莉波风格的美好憧憬，大家憧憬的形式各不相同，不必感到自卑（0042～0048）。最后麻央说一起加油，虽然在『H.I.F』里是对手（0050）。

## 行为模式
- 被称赞“一直不变” → 先道谢，再坦白自己其实总在迷茫（0038）
- 朋友情绪低落 → 不追问原因，把话题引到对方的理想上，并替对方说出“还模糊”的感觉（0039、0041）
- 朋友对自己的憧憬没自信 → 肯定“很有你的风格”，用“大家都不同”来消除自卑（0046～0048）
- 收尾 → 轻快地说“一起加油”，并点明是对手（0050）

## 关系
- 莉波：叫「莉波」（0027、0039）；莉波叫她「麻央」（0028、0031、0036）。莉波说她从1年生起就一直追同一个憧憬（0037），她安慰莉波不必自卑（0048），并说两人在『H.I.F』里是对手（0050）。
- 燕、星南：她称「燕」「星南会長」，说大家的憧憬形式各不相同（0047）。

## 档案类事实
- 憧憬是成为王子様（0034）；想在大舞台上迷住观众、沐浴喝彩和聚光灯（0035）。
- 莉波说她从1年生起就一直追着同一个憧憬（0037，莉波的话）；她自己说一直在迷茫（0038）。
- 要参加『H.I.F』，和莉波是对手（0050）。
