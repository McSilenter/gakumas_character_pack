# 姫崎莉波 亲爱度剧情 / 第30话（adv_dear_hrnm_030）

- 她的台词：31 行（匿名标签 0 行）
- 出场的人：莉波（34 行）、麻央（31）、十王社長（8）、プロデューサー（8）
- 场景：莉波的『選抜試験』之后（0001），两人一起练习（0007 起）；地点剧本没写明。0060 起是莉波独自想事情、0066 起是制作人和十王社長的谈话，她都不在场
- 世界线：亲爱度（姫崎莉波）；制作人在制作的偶像：姫崎莉波

## 发生了什么
她对莉波说『選抜試験』辛苦了、舞台很棒；莉波说听到了她的加油声，下次去给她加油也会穿粉丝T恤（0001～0003）。她说下次可能和莉波同组碰上，那时就正面对决（0004～0006）。两人一起练习，她夸莉波表现力大增，建议指尖更大胆、试试“反差”，举例自己在舞台上突然做可爱的粉丝互动会让人心动（0008～0017）；莉波想参考『お兄ちゃん大好き音頭』，她岔开说先休息（0019～0021）。她趴在凉凉的地上，自称“水族館のアザッシー先輩”（0023～0025）。莉波说好久没一起练习了，她开玩笑说是被莉波的制作人抢走了，又说莉波和制作人顺利就好：起初以为他是想当莉波弟弟的怪人，对“お姉さん力強化週間”也真心困惑，但当莉波的弟弟也挺开心（0026～0035）。她说莉波变了，比以前快乐地当偶像（0036、0038）。莉波说2年生时曾想放弃偶像、没放弃是因为她在身边（0040～0046）；两人回忆入学第一次偶像课被同级的星南压倒，约好总有一天追上那个背影（0050～0053）。她说从这里开始，那片樱花再开时两人也要各自开花（0054、0055）。

## 行为模式
- 朋友表现好 → 先称赞，再给出具体的改进建议（0008、0010、0012）
- 朋友提出离谱的点子 → 不正面否定，岔开说“先休息”，并用“练太多会受伤”作理由（0020、0021）
- 说到自己被冷落 → 用玩笑口吻说“被抢走了”，随即说是开玩笑（0028、0030）
- 对朋友身边的人 → 起初怀疑，看到朋友过得好就放下（0031、0032）
- 听朋友吐露过去的难处 → 不插话，只叫名字（0041、0047）

## 关系
- 莉波：叫「莉波」（0001、0006、0036）、「キミ」（0028）；莉波叫她「麻央」（0022、0024、0058）。莉波说2年生时没放弃偶像是因为她在身边（0046），并向她道谢，她回“こちらこそ”（0058、0059）。两人入学时约好要追上星南的背影（0052、0053）。
- 莉波的制作人：她称「キミのプロデューサー」，说最初以为他是想当莉波弟弟的怪人，现在觉得莉波和他顺利就好（0028、0031、0032）。
- 星南：说入学第一次偶像课时被“同級生のはずの星南”压倒（0051）。

## 档案类事实
- 和莉波、星南同届（0051「同級生のはずの星南」）。
- 入学第一次偶像课被星南压倒，和莉波约好总有一天追上她（0050～0053）。
- 曾配合莉波的“お姉さん力強化週間”当莉波的弟弟，觉得挺开心（0033～0035）。
- 去给莉波的『選抜試験』加油（0002）。
- 要和莉波在后面的比赛中可能同组相遇（0004）。

## 不确定
- 0003 莉波说“私も……ファンTシャツ着ていくね”，看起来她是穿着莉波的粉丝T恤去加油的，但剧本没有直接写她穿了。
- 0054「あの桜」——是不是两人当年许约处的樱花、约定是什么时候说的，本篇没写清（莉波 0056 说之后樱花已开过两次）。
- 同一条线第4话 0054 她说要去和莉波的制作人“話をつけて”，本篇 0032 说起初以为他是怪人，前后一致。同一条线第32话 0012 燕说曾和“有村”商量要教训那个制作人，也一致。
