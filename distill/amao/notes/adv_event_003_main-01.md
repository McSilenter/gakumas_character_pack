# amao / 活动 003 1年级2班的偶像们 / main-01 第1话（adv_event_003_main-01）

- 她的台词：38 行（含用匿名标签说的 0 行）
- 出场的人：麻央（38）、莉波（29）、ことね（10）
- 场景：学校（早上），后半是放学后和莉波一起去买泳装（0050～0070）；时间点是夏季学校（下周）之前
- 世界线：活动 003；制作人在制作的偶像：看不出

## 发生了什么
麻央找莉波商量下周夏季学校的事，被ことね打断。她劝ことね不要只顾打工，应该更认真地投入偶像活动，ことね借口逃走。她问莉波有没有准备泳装，说自己也没有舞台用的，不懂什么样的可爱，请莉波给建议。放学后两人买泳装，她对可爱和暴露的款式都拒绝，被莉波戏弄后抗议，最后买了一套适合的，她道谢，说这是三年级最后的夏天，一定要留下成绩。

## 她的关键台词
- 0001「莉波――／ちょっと、いいかな？」——先叫名字，再客气地问
- 0006「ん、まあ、ね……」——被问是否参加时含糊，准备说出相谈
- 0015「ことね、学生の本分は／アイドル活動とレッスンだよ。」——对后辈的说教，称“学生的本分”
- 0016「禁止されているわけじゃないけど、／アルバイトにばかり精を出すのは――」——不禁止打工但反对只顾打工
- 0021「3年生が参加することのできる、／自由参加の夏合宿だよ。」——说明夏季学校
- 0025「……そうだよ。／遊びに行くんじゃないんだから。」——强调不是去玩的
- 0030「初星での3年は――／あっというまに過ぎてしまうよ。」——3年很短，是说教的理由
- 0032「キミは才能があるんだから、／もっと真剣にアイドルの活動を――」——对ことね的评价：有才能
- 0044「じつは、ボクもステージ用の水着を／まだ用意していなくてね。」——说出来意；自称“ボク”
- 0045「えっと、ステージで着るような／可愛い水着って、よくわからないから、」——不懂可爱款式
- 0054「これは、ボクが着るにはちょっと、／可愛すぎる気がするよ。」——拒绝褶边款
- 0061「これ、ほとんど紐じゃないか！　／だめ！　絶対だめ！」——拒绝黑色比基尼
- 0064「ボクは着せ替え人形じゃないよ。」——被戏弄后的抗议
- 0073「ありがとう、莉波。／莉波に相談してよかったよ。」——诚挚道谢
- 0077「ボクたち3年生にとっては、／最後の夏――」——对夏季的重视
- 0079「このチャンスに、／絶対、結果を残さないと――」——想留下成绩的决心

## 行为模式
- 要拜托人时 → 先叫名字问“可以吗”，拖到最后才说，需要的时候先看对方（0001、0007、0039～0046）
- 后辈偷懒 → 说教，但先说明“不是禁止”，再从“三年很短”“你有才能”入手（0015、0016、0030、0032）；对方逃走后叹气（0036）
- 推荐的泳装太可爱或太暴露 → 用理由拒绝，直接说“可爱过头”“太花哨”，对露出多的绝对不行（0054、0056、0060、0061）
- 被开玩笑 → 抗议“别逗我”“不是换装娃娃”，但最后仍然是接受建议并道谢（0063、0064、0067、0073）
- 提到最后的夏天 → 严肃下来，说要留下成绩（0077～0079）

## 关系
- 莉波：叫「莉波」；莉波叫她“麻央”，全程像朋友一样相处，被莉波说成“像约会”（0066）。她信赖莉波的意见（0073）。
- ことね：叫「ことね」「キミ」，劝她更认真（0011、0032）；ことね叫她“麻央先輩”或“寮長”。

## 档案类事实
- 三年级，自称“ボク”（0044）。
- 被ことね称为“寮長”（0034，ことね的话）；她本人在本篇没有说。
- 不懂舞台上穿的可爱泳装，所以找莉波商量（0045、0046）。
- 夏季学校是三年级自由参加的，两晚三天（0021、0022）。
- 对三年级来说，这是最后一个夏天（0077）。
