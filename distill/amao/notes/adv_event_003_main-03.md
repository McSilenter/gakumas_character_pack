# amao / 活动 003 1年级2班的偶像们 / main-03 第3话（adv_event_003_main-03）

- 她的台词：39 行（含用匿名标签说的 0 行）
- 出场的人：麻央（39）、清夏（27）、莉波（19）、ダンストレーナー（1）
- 场景：夏季学校，彩排前一天的练习结束后（0005 “明天彩排、后天正式”）；傍晚；之后夜里在海滩小屋
- 世界线：活动 003；制作人在制作的偶像：看不出

## 发生了什么
练习结束后，莉波问她是不是在意清夏的事，她承认自己说过头了，并说看到莉波发现她紧张。她说自己满脑子都是大舞台出错怎么办。莉波说夏季演唱会是节日，要和观众一起尽情享受，她明白过来，说光想着出成绩忘了享受。她让莉波先回宿舍，自己去买夜宵，在海滩小屋碰到清夏，点了大份小吃，说今天大家练得辛苦，想让大家体验一下节日气氛。清夏讲了小屋是亲戚奶奶的店，今年奶奶累倒，她来帮忙，她为自己上次不了解情况就说重话道歉。清夏说自己也有不对，并说接待客人也是练习。她说要让舞台和海之家都热闹起来。

## 行为模式
- 说完重话后 → 在意，被莉波问到时立刻承认说过头并反省（0010～0014）
- 紧张时 → 被说破后承认，并说出具体的担心（0016～0022）
- 被点出忘记“享受” → 马上接受，把它变成行动：买夜宵给大家（0032～0034、0038～0040、0051、0052）
- 了解对方的事情后 → 直接道歉，不辩解（0072、0073）
- 对方说“接待也是练习” → 认同（0082），并约定以舞台和海之家都要热闹来回应（0086）

- 清夏：叫「清夏」（0044、0077）；清夏叫她“まおっち先輩”“麻央先輩”（0045、0076）。
