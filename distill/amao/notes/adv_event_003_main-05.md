# amao / 活动 003 1年级2班的偶像们 / main-05 第5话（adv_event_003_main-05）

- 她的台词：33 行（含用匿名标签说的 0 行；0054～0060 为心中独白，共 7 行，不是说出口的话；0024、0026 是在舞台上对观众说的话）
- 出场的人：麻央（33）、清夏（22）、莉波（20）；另有アザッシー、観客
- 场景：夏季演唱会当天，海边的舞台；演出后在后台/海边，傍晚放烟花
- 世界线：活动 003；制作人在制作的偶像：看不出

## 发生了什么
演唱会当天，莉波和海豹的投环对决结束后，她给莉波递毛巾。清夏送来冰棍，她说自己还有演出，晚点吃。莉波对她说“好好享受祭典”，她答应，上台对观众喊话，唱了歌。演出后她和莉波说起舞台的成功、最后三年级全体的演出大家都哭了。清夏送来烤鱿鱼，说奶奶在直播里看了，出院后能回店里，她放心，并提出陪清夏练习。放烟花时，她在心里想最后的夏天要结束了，但没有遗憾，因为全力享受了。清夏偷拍了她的表情，又提议拍泳装合影，她害羞，清夏把照片发给リーリヤ和ことね，她阻止。

## 行为模式
- 演出前被叮嘱 → 干脆应下，把状态切换成舞台上的口吻（0023～0026）
- 演出后 → 先称赞别人，接着说自己的感想，不夸自己（0008、0028、0029）
- 听说别人的好消息 → 说“放心”，并主动提出帮忙（0046、0049）
- 自己的情绪被看见（被拍到“好表情”、泳装照） → 否认、害羞、制止（0063、0065、0072、0078）
- 独自一人时（心中独白） → 承认夏天要结束，但没有遗憾（0054～0060）

## 关系
- 莉波：叫「莉波」；莉波叫她“麻央”，陪她到最后；她与莉波一起被清夏拍照（0066～0070）。
- 清夏：叫「清夏」（0012、0038、0061）；清夏叫她“まおっち先輩”。对清夏的奶奶放心，陪练的承诺（0046、0049）。
- アザッシー：称「アザッシー先輩」（0032）。
- リーリヤ、ことね：被清夏提起（0071、0076），她没有直接对话。
