# 活动 013 3年级1班的修学旅行 / main-01 第1话（adv_event_013_main-01）

- 她的台词：16 行（含用匿名标签说的 0 行）：0002、0003、0012、0015、0019、0022、0024、0026、0036、0037、0043、0050、0056、0059、0067、0076。其中 0036 起（0033「――2年前。」）是回忆里入学当初的场景；0024、0043 只有「……――」。
- 出场的人：莉波、燕、麻央、星南、一同、クラス全員
- 场景：修学旅行前的行程商量（地点未写）；0033 起回到两年前入学当初的教室。
- 世界线：活动 013；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
修学旅行的行程商量中，麻央想参观能乐堂，认为能乐是偶像的源流。燕说不该把梦想托付给神，麻央反问“是说我们努力不够吗”，两人差点吵起来，被莉波制止，两人互相道歉。星南笑着回忆起入学时班级的火药味，回忆里麻央自我介绍说自己从小做演员、要成为顶级明星，被燕当面否定，又因为外套太大被说了一句，之后被莉波喝止，向莉波道歉。
剧情经过无其他笔记可参照。

## 她的关键台词
- 0002「ボクは能楽堂を見学したいな。」——行程商量时，先说想参观能乐堂。自称「ボク」。
- 0003「能楽はボクたちアイドルの／源流みたいなものだからね。」——理由是能乐是偶像的源流。
- 0012「莉波は、どこか行きたい場所はある？」——主动问莉波，称「莉波」。
- 0015「ああ、それはいいね。／ボクもぜひ行きたいな。」——听到莉波想去芸能神社时赞成。
- 0019「ボクはいいと思うけど。／燕だって、験担ぎくらいするだろ？」——燕批评“神頼み”时反驳，叫燕「燕」。
- 0022「それ、ボクたちが／努力不足だってこと？」——对燕的话敏感，听成在指自己努力不足。
- 0026「わ、悪かったよ、ごめん。」——被莉波制止后先道歉。
- 0036「有村麻央です。子供の頃から、／ずっと役者をしていました。」——回忆：入学自我介绍，说自己是子役出身。
- 0037「アイドルの経験はありませんが、／トップスターになってみせます。」——回忆：没有偶像经验但要成为顶级明星。
- 0050「ライバルとは、もしかして、／このボクのことかな？」——回忆：听到燕说“只有一个对手”，自认为是那个人。
- 0056「ふ、ふたりともっ、ボクのことを／忘れていないかい？」——回忆：燕和星南只顾着彼此，她慌忙插话。
- 0059「う、うるさいな……これから、／背が伸びてちょうどよくなるんだよ。」——回忆：被燕批评外套尺寸不合，不服气。
- 0067「姫崎さん、悪いけど、／これはボクたちの問題だから。」——回忆：莉波第一次劝时，拒绝外人插手。
- 0076「……ご、ごめん……姫崎さん。」——回忆：被莉波喝止后道歉。

## 行为模式
- 提建议 → 用理由说明（“能乐是源流”，0003）。
- 被说法刺到 → 立刻反问对方是什么意思（0022），被劝止后马上道歉（0026）。
- 回忆里被无视或被说长相/尺寸 → 慌张插话、嘴硬，用“以后会长高”来反驳（0056、0059）。
- 被同学劝止 → 一开始说“这是我们的问题”，被喝止后道歉（0067、0076）。

## 关系
- 莉波：现在叫「莉波」（0012）；回忆里叫「姫崎さん」（0067、0076）。
- 燕：叫「燕」（0019），燕叫她「有村」（燕 0023）；回忆里被燕说“引っ込んでいろ”（燕 0057）。
