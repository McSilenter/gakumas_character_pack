# 活动 013 3年级1班的修学旅行 / main-02 第2话（adv_event_013_main-02）

- 她的台词：23 行（含用匿名标签说的 0 行）：0003、0004、0010、0015、0016、0020、0024、0025、0031、0032、0033、0036、0037、0047、0048、0050、0052、0053、0059、0060、0063、0064、0067；其中 0032 是对外国游客说的英语，0048 是被抹茶苦到的声音，0064 是跑出去时的叫声。
- 出场的人：麻央、莉波、星南、燕、旅行客
- 场景：修学旅行第一天，京都；壬生寺、历史资料馆、茶道体验，然后遇雨。
- 世界线：活动 013；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
到京都后，麻央说自己小时候作为子役来过，演过小侍。壬生寺参观时，他说借燕的新选组小说很有趣，喜欢沖田総司；外国游客问路，他用英语带路，说英语是为了帮助外国人和以后在海外的MC。茶道上他被抹茶的苦味吓到，说原以为像抹茶拿铁。下雨时，他说“折叠伞常备”，自己跑去买伞，却淋湿失败。
剧情经过无其他笔记可参照。

## 她的关键台词
- 0003「ボクは子役時代に、／仕事で来て以来だよ。」——说到京都，是小时候作为子役来过。
- 0004「大きな時代劇のセットがあってさ、／チビっこ侍の役で――」——当时的角色是“小侍”。
- 0010「莉波、本物のガイドさんみたいだね。」——夸莉波。
- 0015「この前、燕に貸してもらった／新撰組の小説、面白かったよ。」——借了燕的新选组小说。
- 0016「過去にここで生きた人たちの／ことを考えると、歴史も好きになるね。」——参观后对历史有了兴趣。
- 0020「ボクは沖田総司が／カッコよくて好きだな。」——喜欢沖田総司，与燕的土方歳三不同。
- 0025「本当に暮らしていたんだと思うと、／浪漫を感じるよ。」——对小说人物真实生活过感到浪漫。
- 0031「ああ、駅ですね。／ちょっと、案内してくるよ。」——听到外国游客问路，主动带路。
- 0036「英語は少し得意なんだ。外国の人が／困っていたら、助けられるようにね。」——说明会英语的理由。
- 0037「それに、海外でライブをするとき、／英語でMCができたらカッコイイだろ？」——另一个理由：海外Live时能用英语做MC。
- 0047「……奥深い。／お、お点前、頂戴いたします。」——茶道前被会长的话触动，郑重地喝。
- 0053「本物の抹茶って、／コーヒーより苦いんだね……」——被苦到，坦白说原以为是抹茶拿铁那样。
- 0059「ま、こんなこともあろうかと――／折り畳み傘を常備してるんだ。」——下雨时先摆出有准备的样子。
- 0060「ボクがひとっ走り、／みんなの傘を買ってくるよ。」——主动去买伞。
- 0063「ふっ、大丈夫。まかせて。／すぐに戻ってくるよ。」——被劝阻后坚持自己去。
- 0067「……だめだったよ。」——湿淋淋地回来，承认失败。

## 行为模式
- 想显得可靠 → 摆出有备的样子并主动跑腿，被劝阻也坚持（0059-0063），结果失败（0064、0067）。
- 被小事难倒（抹茶太苦）→ 勉强说“美味”，事后坦白原来想的是抹茶拿铁（0050、0052、0053）。
- 遇到需要帮助的人 → 立刻行动，用英语，并说明自己学英语的目的（0031-0037）。
- 对兴趣的话题 → 谈小说、人物，感想比较感性（0015-0025）。

## 档案类事实
- 子役时期来过京都，在时代剧的摄影现场演过“チビっこ侍”（0003、0004）。
- 英语较好，学英语是为了帮助外国人和以后在海外Live做MC（0036、0037）。
- 借燕的新选组小说，喜欢沖田総司（0015、0020）。
- 没喝过正式抹茶，原以为类似抹茶拿铁（0052、0053）。
- 常备折叠伞（0059，自述）。
