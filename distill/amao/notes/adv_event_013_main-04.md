# 活动 013 3年级1班的修学旅行 / main-04 第4话（adv_event_013_main-04）

- 她的台词：30 行（含用匿名标签说的 0 行）。其中 0033、0034、0036、0037、0044、0046、0048、0049、0050、0051、0055、0058 是她讲述中重现的去年『H.I.F』之后的回忆场景里说的话；0030、0031 是回忆里的内心独白；0059～0064 是回到现在、向在场的人讲述回忆的话
- 出场的人：麻央、星南、燕、莉波（学園長 0029 只在回忆里出现；一同 0028 不计）
- 场景：修学旅行夜晚的宿舍，燕、莉波、麻央在等会长（星南）打完电话回来，打发时间轮流讲怪谈；后半是麻央讲的去年『H.I.F』之后的回忆
- 世界线：活动 013；制作人在制作的偶像：看不出

## 发生了什么
燕、莉波、麻央在等星南讲电话回来，轮流讲怪谈，麻央被吓得直叫但嘴硬说不怕。轮到麻央时，她说让自己觉得害怕的是去年的『H.I.F』，随后展开回忆：星南被宣布为『一番星』，麻央在台下被压倒，之后向她道贺，却被问「王子様。あなたは――／追いかけてきてくれる？」，当时没能回答。回到现在她说这一直是后悔。星南回来问在聊什么，燕抢着说是在讲要在『H.I.F』击败她，麻央顺着说「ま、そーいうこと」。

## 她的关键台词
- 0006「ぜ、ぜんぜん怖くないよ！」——被燕的怪谈吓到后立刻逞强否认
- 0027「ボクが、怖いって思ったのは、／去年の『H.I.F』――」——把“最可怕的事”说成去年的『H.I.F』，引出回忆
- 0031「（ただ圧倒されて――／輝く『一番星』を見上げていたんだ）」——回忆里的内心独白：当时在观众席被星南的舞台压倒、只能仰望（回忆中）
- 0034「『一番星』おめでとう。本当に、／素晴らしいステージだったよ。」——回忆里主动向星南道贺并真诚夸奖（回忆中）
- 0036「……あんまり、嬉しそうじゃないね。」——回忆里看出星南并不开心（回忆中）
- 0049「もう、スターであることを、／やめてしまったんだ。」——回忆里被问到从小憧憬的人是否仍在闪耀时的回答（回忆中）
- 0050「ずっとずっと、／輝き続けてほしかったのに……」——说出对那位憧憬的人的期望，说到一半自觉失言（0051「――あ。」）（回忆中）
- 0063「ボクはきっと、キミに追い付くよって、／言えればよかった。」——对星南当时的提问没能回答的遗憾，想说的话
- 0064「今でも、後悔してる。」——这件事至今仍是后悔
- 0072「ま、そーいうこと。」——燕替她圆场后顺势接话，承认（或顺着说）要在『H.I.F』击败星南

## 行为模式
- 被吓到时 → 发出惊叫，但被问就嘴硬说不怕（0004、0006、0017、0019）
- 被点名讲怪谈、自己不擅长时 → 先推说不熟悉，想了想又说「あるにはある」，然后讲了自己真正在意的事（0024、0025、0027）
- 说到憧憬的人已不再是偶像时 → 话说到一半才意识到说漏了，停住（0049、0050、0051）
- 对星南的提问（「追いかけてきてくれる？」）→ 当时答不出，事后一直后悔，想说的是「追上你」（0059、0062、0063、0064）
- 星南回来而话题尴尬时 → 听到燕替她圆场，吃惊（0071）后立刻顺着接话（0072）

## 关系
- 星南：回忆里叫她「星南」（0033），她叫麻央「麻央」；麻央现在称她「会長」（0061）；星南在回忆里称她「王子様」（0057）。麻央把星南的舞台当作仰望对象，也想追上她
- 燕：叫她「有村」（0005、0023）；燕替她把话题圆成对星南的挑战（0070）
- 莉波：不称呼名字，只在 0007 提到手毬（见不确定）

## 档案类事实
- 去年『H.I.F』时麻央在观众席看了星南的舞台（0030）
- 麻央有从小就憧憬的人，那个人已经不再是「スター」（0045、0049）
- 对怪谈不熟（0024）；被吓到时反应很大（0004、0017、0019）

## 不确定
- 0049「スター」的指代：译文是“偶像”，原文是「スター」（明星），那位憧憬的人具体是谁看不出
- 0033～0058 是否全部是回忆里实际说过的话，还是复述时的再现，剧本没有明确标记；0059 起明显是现在向在场的人讲述
- 0072「ま、そーいうこと。」是否表示她真的认同“在『H.I.F』击败星南”这个说法，还是只是顺水推舟，看不出
- 「一同」0028：“……っ！？”，是在场的人听到她说起『H.I.F』时的反应，是否含她，待统一判定
- 【译文】0049 译文“我已经，不再是偶像了”：原文「もう、スターであることを、／やめてしまったんだ」是在说那个人不再当“スター”，译文丢了主语，容易被读成麻央自己
