# 活动 013 3年级1班的修学旅行 / main-05 第5话（adv_event_013_main-05）

- 她的台词：11 行（含用匿名标签说的 0 行）
- 出场的人：麻央、莉波、星南、燕（千奈 0002～0005、美鈴 0008 只在开头的电话/联络场面；一同 0080 不计）
- 场景：修学旅行中，先是在买伴手礼的店里，之后在供奉演艺之神的神社的绘马处
- 世界线：活动 013；制作人在制作的偶像：看不出（星南在 0024 说自己正在培育学生会一年级的孩子们）

## 发生了什么
麻央和莉波在店里选伴手礼，麻央给リーリヤ、ことね、宿舍的大家各挑了东西，差点要买新选组刀造型的耳勺。到了神社，星南说希望后辈们在『H.I.F』大放异彩，麻央则说自己许的是后辈成为出色偶像，以及在『H.I.F』夺冠成为『一番星』，并说这是对神明和自己的宣言。接着她对星南说「あのときの返事、／待たせてしまったね」，宣布这次一定要追上她。剧情经过参照 hmsz 笔记。

## 她的关键台词
- 0011「……あ、ご当地ロボだ。／これはリーリヤのお土産にしよう。」——选伴手礼时想到リーリヤ，找适合她的东西
- 0012「ことねはアルバイトで疲れてるから、／温泉成分入りの入浴剤がいいかな。」——考虑ことね打工很累，选入浴剂
- 0014「見て、莉波――／新撰組の刀の耳かきがあるよ！」——看到喜欢的东西兴奋，喊莉波过来看
- 0015「菊一文字、カッコイイなぁ。／これは寮のみんなに――」——对刀形的东西觉得帅气，想送给宿舍的大家
- 0056「ん？　ボクは、後輩のみんなが／立派なアイドルになれますようにって。」——许愿内容首先是后辈们
- 0057「それから、『H.I.F』で優勝して、／『一番星』になりますって。」——在神明面前说要在『H.I.F』夺冠成为『一番星』，用“なります”断言
- 0059「ああ。これは、お祈りじゃなくて、／神様と自分への宣言だよ。」——说明这是宣言而不是祈祷
- 0062「あのときの返事、／待たせてしまったね。」——回应上一话（main-04）回忆里星南的提问，直接对星南说
- 0063「今度こそ、ボクはキミに／追い付いてみせるよ。」——向星南宣言要追上她

## 行为模式
- 买伴手礼 → 想到不同的人，按对方的情况挑（リーリヤ→当地机器人，ことね→入浴剂，寮的大家→耳勺）（0011、0012、0015）
- 看到喜欢的东西 → 兴奋地叫身边的人来看（0014），被莉波劝“买之前再考虑”（0016）
- 对愿望 → 不说“希望能～”，说“会～”，当作对神明和自己的宣言（0057、0059）
- 对星南的旧问题 → 选在神社这个场合主动回答，说“让你久等了”（0062、0063）

## 关系
- 星南：称「星南」（0060），对她用「キミ」（0063）
- 莉波：叫她「莉波」（0014）；莉波会劝她（0016）
- リーリヤ、ことね、咲季她们（莉波 0013 提到咲季）：她给リーリヤ（0011）和ことね（0012）挑东西；叫「寮のみんな」（0015）

## 档案类事实
- 麻央喜欢新选组刀（菊一文字）造型的东西，觉得帅气（0014、0015）
- 麻央住宿舍（寮）（0015）
- 麻央知道ことね在打工并且很累（0012）
