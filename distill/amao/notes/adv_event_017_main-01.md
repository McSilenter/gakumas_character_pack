# 活动 017 / 第1话（adv_event_017_main-01）

- 她的台词：7 行（含用匿名标签说的 0 行）
- 出场的人：莉波、星南、燕、麻央（ダンストレーナー 0015）
- 场景：舞蹈课的场所，麻央在练习，莉波、燕在旁看，星南后来出场，莉波提出拍3年级PV的请求
- 世界线：活动 017；制作人在制作的偶像：看不出

## 发生了什么
麻央在练习课题曲的舞步，被舞蹈教练称赞“变好了”，她回答体力有信心，还能再来。莉波佩服她已能完美跳出课题曲。莉波向大家提出请求，要拍以3年级“日常”为主题的PV，由莉波拿摄影机拍。麻央问是不是“我们的PV”，问为什么由莉波拍，同意并说这是让人认识自己的机会。燕先表示不协助，麻央问“那燕不协助吗”，被燕说“别急着下结论”。

## 她的关键台词
- 0014「ワン、ツー、スリー……／ワン、ツー、スリー……」——练习中数拍子
- 0016「はいっ、体力には自信あります。／まだまだいけますよ！」——被问是否再来一组时的回答，对教练用敬语
- 0027「ボクたちのPV？」——听到莉波的请求后，立刻领会
- 0032「カメラは、広報部の人じゃなくて、／莉波が回すの？」——确认由莉波拍
- 0035「ま、それはそうかもね。」——听到“日常要由熟人拍”的理由后同意
- 0038「ボクはかまわないよ。アイドルとして、／知ってもらうチャンスだし。」——表明协助，理由是让人认识自己的机会
- 0043「じゃあ、燕は協力しないの？」——听到燕说“偶像没有日常”后追问

## 行为模式
- 被教练问是否还能练 → 用敬语回答并强调体力有自信（0015、0016）
- 听到请求 → 迅速复述要点以确认（0027、0032）
- 同意的理由 → 用“对偶像来说是被人知道的机会”来判断（0038）
- 同伴的话听来是拒绝 → 直接追问（0043）
