# 活动 017 / 第2话（adv_event_017_main-02）

- 她的台词：14 行（含用匿名标签说的 0 行）
- 出场的人：莉波、麻央、星南、燕、後輩、手毬、咲季
- 场景：清晨的初星学园；莉波在拍摄记录偶像「日常」的 PV，先拍麻央的一个早晨。
- 世界线：活动 017；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
麻央在早晨遇到晨跑的手毬和咲季，夸她们早起。莉波用旁白的方式拍摄麻央的早晨：早餐、饭后的黑咖啡，麻央想端起咖啡时呛咳了。之后麻央看到抱着重球的後輩，丢下拍摄去帮忙搬到操场，还说对困难的人不分普通科还是偶像科。最后莉波称她是「初星の王子様」。剧情经过参照 ttmr、hski 笔记。

## 她的关键台词
- 0001「――おはよう、ふたりとも。／早朝ランニングとは感心だね。」——用「ボク」的口吻自然称赞后辈，带前辈姿态。
- 0008「ふふ、食後は目覚ましに／ブラックコーヒーを一杯飲むのが、／ボクのこだわりでね。」——自称「ボク」，说起自己的讲究。
- 0010「……莉波。変なナレーションを／入れないでくれるかい？」——被莉波加旁白时无奈地抗议，语气仍柔和。
- 0012「と、取り繕ってはいないよ……」——被说不要太掩饰时结巴着否认。
- 0023「大丈夫？　ボール、重そうだけど。」——看到後輩吃力，先开口问。
- 0027「困っている子に、／普通科もアイドル科もないよ。」——对後輩说帮忙不分科别，表明立场。
- 0029「それじゃ、莉波。／悪いけど、また教室で！」——为了帮人立刻离开拍摄，约好教室再见。

## 行为模式
- 早晨遇到后辈（手毬、咲季）→ 先出声夸奖（0001）
- 莉波的旁白说到自己的习惯、被要求不要掩饰 → 嫌旁白怪、否认「取り繕ってはいない」（0010、0012）
- 想对着镜头喝黑咖啡 → 呛咳（0013）
- 看到有人拿着重物 → 不管拍摄，先问「大丈夫？」再提出帮忙，对方推辞时用「普通科もアイドル科もない」说服（0023、0025、0027）

## 关系
- 莉波：叫「莉波」；对她的旁白会吐槽（0010），有事时说「悪いけど」后离开（0029）。
- 後輩：被称为「麻央寮長」（0024）；麻央主动帮忙搬球（0025）。
- 手毬、咲季：夸她们「ふたりとも」「感心」（0001）。

## 档案类事实
- 早餐是香蕉、牛奶、水煮蛋，多半还有麦片（0006）。
- 注意卡路里，但早餐算「わりと普通」（0007）。
- 饭后喝一杯黑咖啡提神，是她的「こだわり」（0008）。
- 她是宿舍长（寮長），莉波的旁白说「寮長として、／下級生の子を見守っている」（0005），後輩叫她「麻央寮長」（0024）。
- 日常重视不过度的日程、每天不缺席练习（0017）。
- 口头说话的自称是「ボク」（0007、0008）。

## 不确定
- 0008 她说黑咖啡是自己的讲究，莉波在 0009 说是加很多砂糖和牛奶；麻央本人没有直接回应这点（0010 只是嫌旁白怪），0013 喝咖啡时呛咳。如何理解待定，不作结论。
- 0013 是被拍摄时的表演还是日常，剧本没写明。
