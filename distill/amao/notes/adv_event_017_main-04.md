# 活动 017 / 第4话（adv_event_017_main-04）

- 她的台词：32 行（含用匿名标签说的 0 行）；其中 0042、0043、0044、0046、0047、0048、0050、0051、0052、0071、0072 是括号里的内心独白（不出声的想法）；0067 是无字的沉默「……――」
- 出场的人：麻央、星南、莉波、燕
- 场景：休息日，天川市的游乐园；三年级四人先坐旋转木马、过山车，傍晚参加两人组的解谜逃脱游戏（僵尸主题），麻央与星南一组。
- 世界线：活动 017；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
四人在游乐园玩。麻央对尖叫类项目自称拿手，坐旋转木马时以「王子」身份对莉波扮演护送；过山车上被燕指出闭着眼，她说自己眯着眼。解谜游戏分组后她与星南单独一组，心里觉得尴尬，并回想起起初把星南当竞争对手、后来觉得追不上，也觉得星南像自己憧憬的人。星南说自己忘了「完璧な十王星南」在玩，并提到麻央坚持扮演王子，麻央听后建议她把素的笑容也带到舞台上，说那样大家会更喜欢她。

## 她的关键台词
- 0005「ふふ、いいね。／ボク、絶叫系は結構得意だよ。」——听到过山车时说自己拿手尖叫系，口吻是「ボク」。
- 0011「ふふ……莉波姫、城までお連れします。／ボクの腰につかまってください。」——对莉波扮王子，称她为「莉波姫」。
- 0023「ボクはずっと両手離しだったよ。」——坐完过山车后夸耀自己。
- 0025「と、閉じてないよ……／ちゃんと薄目を開けてたからね。」——被燕说闭眼，勉强辩解。
- 0031「そ、そんなことないよ。／どうせ、かぶり物だろ？」——被问是否怕僵尸，嘴上否认。
- 0042「（星南とふたりきり……／ちょっと、気まずいな……）」——内心：和星南单独一组感到尴尬。
- 0046「（……最初は、ライバルだと思ってた。／だけど――）」——内心：最初把星南当竞争对手。
- 0048「（その背中を追いかけることも、／追いかける資格もなくなってしまった）」——内心：觉得失去了追赶星南的资格。
- 0051「（ステージで輝く一番星が、／ボクには、ひどく眩しくて――）」——内心：舞台上的星南太耀眼。
- 0052「（……ずっと、目をそらしてきたんだ）」——内心：一直在避开视线。
- 0058「……そうだね。ボクは、／生徒会のメンバーじゃないし。」——回答星南说很少两人单独玩时说出原因。
- 0077「アイドルが大好きな素のキミも、／とても魅力的だと思うし、」——对星南的建议：素的她也很有魅力。

## 行为模式
- 被指出怕或闭眼等软处 → 马上否认，并找借口（「薄目を開けてた」「かぶり物だろ」）（0025、0031）
- 面对莉波 → 以王子姿态玩扮演（0009、0011）
- 与星南单独相处 → 嘴上正常说话、内心回想过去的心结（0041～0052）
- 被星南问「どうしたの」 → 用「謎解きを考えていてね」带过，没有说出内心的话（0053、0054）
- 听到星南说完心里话 → 说「かなわない」，随后用「アドバイスをさせてもらうよ」说出建议，并预先说明可能不敬（0072～0074）
- 说完建议后 → 用「さ、次の謎を解きに行こう」转回游戏（0081）

## 关系
- 星南：叫「星南」「会長」，对话时称「キミ」（0076、0077）；内心把她看作最初的竞争对手、舞台上耀眼的人，也像憧憬过的人（0046、0050、0051）；说对『H.I.F』上争夺『一番星』的她提建议可能不敬（0073）。
- 莉波：叫「莉波」，扮演时称「莉波姫」（0011）；莉波称她「王子様」（0012）。
- 燕：燕叫她「有村」（0004）；被燕说闭眼（0024）。

## 档案类事实
- 不是生徒会成员（0058）。
- 自称拿手尖叫类项目（0005）。
- 说自己对僵尸之类说反正是かぶり物，被燕怀疑怕这类东西（0030、0031）。
- 有曾经憧憬的「あの人」，觉得星南有些地方像她（0050）。
- 星南在『H.I.F』上争夺『一番星』，麻央说自己与她是同在『H.I.F』竞争的关系（0073）。
