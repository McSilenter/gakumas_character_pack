# 活动 018 / 第2话（adv_event_018_main-02）

- 她的台词：16 行（含用匿名标签说的 0 行）
- 出场的人：清夏、麻央、広
- 场景：三人组合的练习中（练习室，剧本里没写明）；休息时谈清夏的膝盖，然后広提出演唱会点子。
- 世界线：活动 018；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
练习中麻央提议休息，并说要把舞步难度降低一点。清夏以为自己跳得不好，広问是不是膝盖，麻央说一起练了一段时间，这点能看出来，并说如果受伤就不是参加组合的时候。清夏解释膝盖已经没事，剩下是心理问题，正在请咲季和リーリヤ帮忙适应。麻央听完后说不要勉强、重质不重量，并要清夏不要再道歉，互相帮助。之后広提出在演唱会加演戏剧，由麻央和清夏主演、她写剧本，麻央觉得有趣。

## 她的关键台词
- 0002「少し休憩を入れようか。」——看出同伴的状态，先提议休息。
- 0006「振りを調整しよう。／もう少し、難易度を下げたい。」——不点名地提出降低舞步难度。
- 0010「しばらく一緒にレッスンをしてるんだ。／それぐらい分かるよ。」——被问到怎么知道膝盖的事，说因为一起练过一段时间。
- 0012「もし怪我をしているなら、／ユニットに参加している場合じゃ――」——说受伤的话就不是参加的时候，话说到一半被打断。
- 0015「……そういうこと、だったのか。」——听清夏说完后理解。
- 0020「話は分かった。／無理をするのはよくない。」——接受清夏的说明，不赞成勉强。
- 0021「レッスンは慎重にやっていこう。／量よりも質を大事にするイメージでね。」——给出练习方针。
- 0024「それと、清夏。／もう謝るのはナシだ。」——禁止清夏再道歉。
- 0026「助け合っていこう。／もちろん、広も一緒にね。」——提出互相帮助，把広也算进来。
- 0036「……なるほど、ライブで演劇か。／たしかに、面白いアイデアかも……」——听了広的点子后表示感兴趣。
- 0038「でも、共通する部分もある。／清夏ならできるんじゃないか？」——清夏反对时，劝她尝试。

## 行为模式
- 同伴状态不对 → 先提议休息或调整方案，不先问责（0002、0006）
- 同伴表示是自己不够好 → 说明是因为注意到身体状态，并说受伤的话需要重新考虑参加（0010、0012）
- 听到对方的说明后 → 接受，调整为谨慎的练习方针（0015、0020、0021）
- 同伴道歉 → 说「気にすることはない」，并要求以后不要道歉（0023、0024）
- 听到新点子 → 先重复确认，再肯定，并为同伴找依据说服（0033、0036、0038）

## 关系
- 清夏：叫「清夏」；清夏叫她「まおっち先輩」；她留意清夏的膝盖，要求清夏别再道歉（0010、0024）。
- 広：叫「広」；広说她「元子役」（0034）；麻央说「もちろん、広も一緒にね」（0026）。

## 档案类事实
- 広说她曾是子役（元子役），演技和表现力在学园也是数一数二（0034、0035，広的话）。
- 与清夏、広练习的组合已经一起练了一段时间（0010）。
- 被広提出演戏剧时，她表示面白（0036）。
