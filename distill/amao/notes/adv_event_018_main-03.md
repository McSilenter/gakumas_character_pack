# 活动 018 / 第3话（adv_event_018_main-03）

- 她的台词：13 行（含用匿名标签说的 0 行）
- 出场的人：清夏、広、麻央
- 场景：大阪；刚到后先去演播厅做彩排（明天在这里演出），彩排后去逛大阪（美国村一带的店）。
- 世界线：活动 018；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
三人乘新干线抵达大阪，清夏和広想先去观光，麻央提醒先去演播厅彩排。在演播厅，她说明天观众会把场地挤满，建议提前想象那个场面，彩排要当作正式演出，并从确认站位开始。彩排结束后三人逛街，她答应带她们去想去的地方，看清夏给広选衣服时觉得很合适，提醒広不要花太多。清夏让她试穿连衣裙时，她说太可爱而找借口说有推荐的店，逃开了。

## 她的关键台词
- 0005「こらこら、まずはライブスタジオで／リハーサルだよ。」——观光气氛中把话题拉回彩排。
- 0008「ふたりとも、目が輝いているね。」——看着她们对演出和观光都兴奋。
- 0014「明日は観客でスペースがいっぱいになる／から、狭く感じるかもしれないよ。」——说明明天的场地情况。
- 0016「その光景をイメージしておけば、／本番でも動揺しないんじゃないかな？」——建议提前想象明天的场面。
- 0017「リハーサルは本番のつもりでやること。／それが成功の鍵になるよ。」——给彩排定下态度。
- 0028「はいはい、連れて行ってあげるよ。」——広说想去的地方很多，她爽快答应。
- 0031「自分に似合うものを見つけるのが／得意なんだろうね。」——评价清夏。
- 0035「広には派手すぎないかい？」——对清夏选的连帽衫提出担心。
- 0042「使いすぎないようにするんだよ。」——对広说要买就别花过头。
- 0045「ボ、ボクには可愛すぎないかい！？」——被叫试穿连衣裙时慌乱拒绝。
- 0047「――そ、そうだ！／こっちにおすすめの店があってね！」——硬把话题转开，逃走。

## 行为模式
- 后辈兴奋忘了正事 → 用「こらこら」拉回，随后承认她们的期待（0005、0008）
- 彩排前 → 先讲场地和心态，给出具体做法，再从站位开始（0014～0019）
- 同伴想去观光 → 先完成工作，再答应带路（0005、0028）
- 看到同伴买东西 → 先肯定合适，再提醒别花过头（0038、0042）
- 被要求穿可爱的衣服 → 慌乱说「可愛すぎないかい」，被追问时硬转话题逃开（0045、0047）

## 关系
- 清夏：叫「清夏」；清夏叫她「まおっち先輩」，强行让她试穿，她逃（0043～0047）。
- 広：叫「広」；広说「麻央、頼りになる」（0018），她提醒广别花太多（0042）。

## 档案类事实
- 大阪是她的地盘，她带两人观光（0028，与第1话 0018 说大阪差不多是老家一致）。
- 不好意思穿可爱的连衣裙（0045）。
- 明天的演出在这个演播厅，观众会挤满场地（0012、0014）。

## 不确定
