# 活动 018 / 第4话（adv_event_018_main-04）

- 她的台词：15 行（含用匿名标签说的 0 行）；其中 0009、0010、0017、0020、0025、0027 是戏剧『堕天使と人間の王子』里扮演王子时说的台词（不是她本人的话）；0012 是括号里的内心话
- 出场的人：清夏、麻央、広、一同、旁白（无名）
- 场景：大阪的演唱会正式演出；组合三人在演唱会中插入一段戏剧。
- 世界线：活动 018；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
演唱会进行中，清夏宣布惊喜，麻央说要插一段小戏剧，広介绍剧名《堕天使と人間の王子》，麻央和清夏主演。麻央扮王子，对失去翅膀的堕天使（清夏）说是被她的内心吸引。故事本该结束，麻央说事情没那么顺利，把広也拉进戏里扮公主，三人一起幸福。戏后麻央说这是她和清夏商量好的惊喜，剧本是広写的，她们为了引出広的魅力，追加了一点剧情。最后麻央感谢观众，接着唱下一首。

## 她的关键台词
- 0003「ボクたちのちょっとした演劇を／挟ませてもらおうと思ってるんだ。」——以自己的口吻向观众预告演出。
- 0009「ボクは翼があるから、天使だから、／キミに惚れたのではない。」——戏剧台词：扮演王子。
- 0010「キミの心にこそ、／ボクは惹き込まれたのさ。」——戏剧台词：扮演王子。
- 0012「（ふふっ、清夏は流石だな。／照れる演技が上手い）」——内心话：在戏里观察清夏的演技。
- 0025「ボクは王子だからね、／ふたりとも幸せにしてみせるよ。」——戏剧台词：王子要让两人都幸福。
- 0027「――もちろん。」——戏剧台词：回应广的提问。
- 0033「サプライズだよ。／ボクと清夏で相談していたんだ。」——戏后向広说明戏份追加是事前商量的。
- 0035「ちなみに、この演劇の脚本は、／広が書いてくれたんだ。」——向观众介绍剧本是広写的。
- 0037「だからボクたちも、広の魅力を／引き出してあげたいと思ってね。」——说明追加剧情的理由。
- 0038「蛇足かもしれないけど、／少しだけ話を追加させてもらったよ。」——说明加戏。
- 0042「フフ、ボクは欲張りなんでね。」——戏后被说三人一起不健全，笑着回应。
- 0046「ありがとう。／それでは次の曲に移らせてもらうよ。」——结束戏剧，转入下一首。

## 行为模式
- 站上舞台 → 保持王子的口吻，用「ボク」「キミ」说话（0003、0009、0010）
- 剧情按剧本结束后 → 用「そうは問屋が卸さない」把剧情转向追加部分（0017）
- 对広的追加 → 事前与清夏商量，演完后说明用意（0033、0037、0038）
- 被调侃 → 不害羞，用「欲張りなんでね」顺势回应（0042）
- 观众面前 → 简短感谢，推进到下一首（0044、0046）

## 关系
- 清夏：叫「清夏」，台词内演王子和堕天使；私下一起商量了惊喜（0033）。
- 広：叫「広」；戏中叫她「姫」（0020）；说想引出她的魅力（0037）。

## 档案类事实
- 在大阪的演唱会上，三人表演戏剧《堕天使と人間の王子》，她演王子（0004、0009）。
- 自称「ボクは欲張り」（0042，说话时在戏后的现实对话里）。

## 不确定
- 0012 是括号里的内心话，是演戏中的内心活动还是戏外观察，剧本没有区分。
- 0017「そうは問屋が卸さない」之后的内容（把広拉进来）是扮演王子的台词还是她本人的转折，剧本没有标注；0033 说明这是事前商量，所以按戏剧台词算。
- 0042「ボクは欲張りなんでね」是戏后接 0041 的话，是不是仍然是王子口吻，原文没有标明。
