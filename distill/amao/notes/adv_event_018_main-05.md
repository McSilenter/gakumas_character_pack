# 活动 018 / 第5话（adv_event_018_main-05）

- 她的台词：21 行（含用匿名标签说的 0 行）；0048「……すぅ、すぅ。」和 0056「むにゃ……」是睡着时的声音
- 出场的人：清夏、広、麻央、一同
- 场景：大阪演唱会结束后，三人在她推荐的章鱼烧店庆功；后半麻央睡着，清夏和広继续聊。
- 世界线：活动 018；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
演唱会成功后，広让麻央带头用章鱼烧干杯，她照做。清夏一口吃烫到，她说「言わんこっちゃない」，介绍这家店是自己特别中意的，并说要请客。広说感谢，说麻央和清夏是她的王子，她回答护送公主是王子的特权，并说这次演出有広的点子和清夏的商量功劳。広说出自己已大学毕业和接近她们的真正理由时，麻央说不会鄙视她，反而理解了，因为一开始觉得她主动搭话有点不可思议。之后麻央睡着了。

## 她的关键台词
- 0002「た、たこ焼きで？／ああ、まあいいけど。」——被要求用章鱼烧干杯时一时意外，然后答应。
- 0003「コホン……じゃあいくよ？／ライブの成功を祝して、」——清清嗓子带头干杯。
- 0006「あっ、一口でいったら――」——看到清夏一口吃章鱼烧，想提醒。
- 0008「――言わんこっちゃない。」——清夏烫到后的反应。
- 0010「この光景を見てるのに！？」——広说也该一口吃，她吃惊。
- 0014「ボクは粉物にはうるさくてね、／ここは特にお気に入りなんだ。」——说自己对面食挑剔，这里是特别中意的店。
- 0015「ふたりには感謝してもしきれないし、／ここは奢らせてもらうよ。」——表示感谢，请客。
- 0022「ふふ、お姫様をエスコートするのは、／王子様の特権だからね。」——回应広的王子说法，仍以王子口吻。
- 0023「演劇を久々にやりたいと思っていたから／王子様役、楽しかったよ。」——说自己也想再演戏剧。
- 0025「ボクと清夏の演技力を活かすアイデアを／出してくれた広のおかげだし、」——把演出成功归功于広的点子。
- 0026「広にサプライズしたいと相談してくれた／清夏のおかげでもある。」——也归功于清夏。
- 0028「うん、その通りだ。／この3人でライブができてよかったよ。」——对三人一起完成演出的总结。
- 0044「するわけないだろ。／それよりも、納得したよ。」——广问是不是鄙视，她否认并说理解了。
- 0045「ちょっと不思議ではあったんだ。／ボクとも清夏とも、あまり話したことが／ないのに、声をかけてくれたことが。」——说出之前觉得广主动搭话有点不可思议。

## 行为模式
- 被突然委托（带头干杯） → 先意外，咳一声后接下来（0002、0003）
- 后辈要出状况 → 先出声提醒，事后说「言わんこっちゃない」（0006、0008）
- 被道谢 → 以王子口吻回应，再把功劳分给广和清夏（0022、0025、0026）
- 听到对方的坦白 → 先吃惊，问怎么了，然后否认鄙视并说理解了（0033、0044、0045）
- 请客 → 以感谢为理由主动提出（0015）

## 关系
- 広：叫「広」；広叫她「麻央」，说她是「わたしの王子様」（0018）；睡前被広说「ずっと頑張ってた」（0050）。
- 清夏：叫「清夏」，称功劳也归于她（0026）；清夏说很尊敬麻央前辈（0054）。

## 档案类事实
- 对面食（粉物）很挑剔，这家章鱼烧店是特别中意的（0014）。
- 想再演戏剧（0023）；曾是子役这件事被広一开始就知道，她说稍微一查就能知道（0039、0040）。
- 引率三年级的项目对她来说也辛苦：清夏、広说她一直在努力、没有露出不耐烦（0050～0052，二人的话）。
- 之前与広、清夏都没怎么说过话（0045）。

## 不确定
- 0048、0056 是睡着的声音，不算有意义的台词。
- 0022 的「お姫様をエスコートするのは、／王子様の特権だからね。」，是接广「王子様」的话还是接清夏的话，上文 0020、0021 是清夏的话，原文顺序是 0017～0021 之后；按王子口吻读。
- 0031「大卒」是広的话，本篇麻央只在 0033 反应「突然……」，没有对大学毕业本身发表看法。
