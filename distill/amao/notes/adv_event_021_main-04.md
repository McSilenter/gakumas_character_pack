# 活动 021 / main-04 第4话（adv_event_021_main-04）

- 她的台词：11 行（含用匿名标签说的 0 行）
- 出场的人：燕（25）、星南（14）、麻央（11）、莉波（3）、学園長（1）、旁白（1）
- 场景：开头旁白「星南と燕が2年生の時――」，是2年级时『H.I.F』结果公布后（回想）
- 世界线：活动 021；制作人在制作的偶像：看不出

## 发生了什么
『H.I.F』结果公布后，星南成为一番星，燕得了第二。麻央去向燕搭话，被拒绝，她仍说燕的表演很棒，并告诉燕已经拿到第二，该为此骄傲。燕反驳学园第二名没有价值，麻央说自己连决赛也没能上，没有资格说什么，但仍表示燕的舞台很出色。麻央提到“次は、星南を超える”是燕的口头禅，燕说不可能，她说自己还没放弃，还有一年。

## 她的关键台词
- 0016「燕、お疲れ様。」——主动去慰劳
- 0018「――ライブ、かっこよかったよ。」——直接肯定燕的舞台
- 0023「結果、さっき届いてたよ。」——告诉燕结果已经出来
- 0024「3年生を上回って、キミは2位に／なった。それは誇るべき結果のはずだ。」——坚持这是值得骄傲的
- 0027「……本選にすら上がれなかったボクが、／キミになにか言う資格はない。」——先低姿态说明自己的位置
- 0028「でも、ひとつだけ言えることはある。」——转折：仍要说
- 0029「キミのステージも、／本当に素晴らしかったよ。」——对燕的评价
- 0031「次は、星南を超える。／……キミの口癖だろ――」——用燕自己的口头禅鼓励
- 0035「……そうなのかもしれないね。／でも、ボクは……まだ諦めないよ。」——对“实力差距”的回应
- 0036「あと1年ある。」——还有一年
- 0038「燕……」——燕哭泣前的呼唤

## 行为模式
- 对方被胜负击垮、拒绝搭话 → 仍去搭话，先慰劳，再直接肯定舞台（0016～0018）
- 被反驳“没有价值” → 不反驳价值观，而是承认自己没资格，再补一句舞台好（0027～0029）
- 对方断言没有胜算 → 不否认差距，但说自己不放弃，还有一年（0035、0036）

## 关系
- 燕：称「燕」「キミ」（0024），燕称她「有村」（0017）。她知道燕的口头禅（0031）。
- 星南：呼「星南」（0031）。
