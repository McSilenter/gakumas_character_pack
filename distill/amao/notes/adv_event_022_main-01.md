# 活动 022 / main-01 第1话（adv_event_022_main-01）

- 她的台词：24 行（含用匿名标签说的 0 行）；其中 0002～0004、0011～0014 是括号里的内心话
- 出场的人：ことね（28）、麻央（24）、ダンストレーナー（3）
- 场景：先是练习室（跳舞练习），之后下雨，麻央倒在某处被ことね发现，回到自己的房间
- 世界线：活动 022；制作人在制作的偶像：看不出

## 发生了什么
麻央在夏天『H.I.F』前拼命练习，被トレーナー劝停，仍想继续，累得发出喘息，并在心里想“如果成不了偶像就什么都没有”。之后ことね发现她发烧，把她带回房间，麻央说“会传染给你”“不能添麻烦”，还是被带着休息。她说自己是独生子女，羡慕有姐妹的人，因此被ことね说“风邪的时候大家都是小孩”。离开前她要求开着小灯。

## 她的关键台词
- 0002「（夏の『H.I.F』は、3年生のボクに／与えられた最後のチャンス――）」——内心话：这是最后的机会
- 0004「（初星の先輩たちのように、／ステージで輝くアイドルに――）」——想成为的样子
- 0006「大丈夫です。もう少し続けます。」——被劝停时的回应
- 0011「（休んでなんて、いられない……／ボクにはもう後がないんだ）」——内心话：没有退路
- 0012「（アイドルになれなかったら、／ボクにはもう……なにもないんだ）」——内心话：不当偶像就一无所有
- 0014「（ボクは、アイドルになれるのかな？）」——内心话：不安
- 0022「少し……根を詰めすぎてしまってね、／クールダウンしてるだけさ。」——对ことね淡化情况
- 0027「ひとりで……大丈夫だよ……／迷惑をかけるわけには――」——不愿麻烦别人
- 0044「咲季のところとか、ことねとか、／姉妹って、ちょっと羨ましいなあ。」——因为是独生子女而羡慕
- 0048「……情けないな。／模範となるべき3年生が、／体調管理もできないなんて……」——自责
- 0051「ボクは子供じゃないよ。」——对“唱摇篮曲”的反应
- 0054「あ、豆は点けてて……」——要求开着小灯

## 行为模式
- 被劝停训练 → 回答“没事，再练一会儿”，被劝后说“はい”但仍心里不甘（0006、0009、0011）
- 身体不适被发现 → 说成“冷却”，淡化，不要别人添麻烦（0022、0027、0030）
- 被照顾 → 先自责“情けない”，作为3年级的责任感（0048）
- 被当小孩对待 → 说“我不是小孩”，但在黑暗处要求开灯（0051、0054）
- 没有对着人说的心里话 → 括号内说，都是焦虑和孤立感（0002～0004、0011～0014）

## 关系
- ことね：称「ことね」，也称「キミ」（0030）。ことね称她「麻央先輩」。
- 咲季：和ことね一起被她举为有姐妹的例子（0044）。
- ダンストレーナー：称她「有村」，劝她休息（0005、0007）。

## 档案类事实
- 自称「ボク」（0002）
- 夏天的『H.I.F』是3年级最后的机会（0002）
- 是独生子女，在家一个人玩、练习演戏（0042、0043）
- 房间里有“グングン背伸ばしマシン”（ことね看到，0037）
- 睡觉时不关小灯（0054，“豆”应为小灯）

## 不确定
- 0054「豆は点けてて」的“豆”：应指小灯（豆電球），剧本没有进一步说明。
- 0011～0014 内心话里“なにもない”是否是她自己的核心恐惧，剧本只有这一段。
