# 活动 022 / main-05 第5话（adv_event_022_main-05）

- 她的台词：38 行（含用匿名标签说的 0 行）；其中 0032～0034、0038～0041、0048～0052 是括号里的内心话，0046、0047 是旁白式叙述（标签为麻央）
- 出场的人：麻央（38）、ことね（31）
- 场景：吃完午饭的お好み焼き店；之后是live house，星南的live
- 世界线：活动 022；制作人在制作的偶像：看不出

## 发生了什么
吃完パフェお好み焼き，她被ことね发现爱甜食，说这是怕让粉丝失望的秘密，请ことね保密。后来到了会场，她想起笔记里的门票，在心里问星南是否想对现在的自己说什么。她承认3年级后是第一次来看星南的live，之前一直找借口逃避。看完星南的表演后，她说自己没有勇气一个人来，说以后不再逃避，要看着星南也看着自己。

## 行为模式
- 被发现秘密 → 先说“既然被你看到了就说吧”，再解释理由并请求保密（0005、0006、0025、0026）
- 被说“展现素的一面” → 沉默，之后只说“请保密”（0020、0024、0025）
- 面对星南 → 心里承认逃避，嘴上不说，被ことね说“享受live”后答应（0038～0045）
- 想说真话 → 看完live后对ことね道谢并说出勇气不足，之后立下决心（0056、0060～0065）

## 关系
- ことね：称「ことね」，今天的“エスコート”对象。向她说出爱甜食和不敢一个人来的两个秘密（0006、0060）。
- 星南：称「星南」「キミ」（心里话 0040、0052）。她是要挑战的对象，也是自己逃避的对象（0040）。
