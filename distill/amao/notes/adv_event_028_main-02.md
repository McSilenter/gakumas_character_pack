# 活动 028 / main-02 第2话（adv_event_028_main-02）

- 她的台词：11 行（含用匿名标签说的 0 行）；行号 0002、0004、0009、0010、0012、0014、0016、0017、0020、0021、0024。其中 0002、0004 是和燕玩土方、沖田的扮演，不是她本人的想法。
- 出场的人：莉波、燕、麻央、生徒A、1年生A、1年生B
- 场景：初星学園，文化祭准备中。3年1组的教室（执事喫茶的准备），生徒会来巡视。
- 世界线：活动 028；制作人在制作的偶像：看不出

## 发生了什么
燕和莉波巡视3年1组，燕与麻央玩起新选组式的角色扮演（土方、沖田）。麻央说班里的执事喫茶不怎么辛苦，让莉波她们专心做实行委员的工作；还说在指导1年级的演剧，想给后辈留点什么。莉波问进路，麻央说9月的『100プロ所属審査』当然会考，能不能本所属不知道，但会咬住不放。随后有同学来问看板怎么收尾，麻央急着阻止，说刚涂好。

## 她的关键台词
- 0002「土方さん。ここに怪しいものなんて、／ありゃしませんよ。」——配合燕玩扮演（沖田），是演戏的台词。
- 0009「こっちはそんなに大変じゃないよ。／3年生で勝手も分かってるし、」——把班里的事揽下，让莉波她们去忙。
- 0010「莉波たちは、実行委員の／仕事に専念してよ。」——体谅两位实行委员。
- 0014「あとで演技のコツを／レクチャーするよ。」——莉波担心男装，她主动提出教演技。
- 0017「3年生として、後輩たちに、／なにか残していければと思って。」——指导1年级演剧的理由。
- 0020「9月の『100プロ所属審査』は、／もちろん受験するよ。」——毫不犹豫地表示要考。
- 0021「本所属になれるかは、わからないけど、／……食らい付いてみせる。」——对结果不保证，但表态要死死抓住。
- 0024「ああ、それはまだ触らないで！／塗ったばかりなんだ！」——看板刚涂好，急忙阻止，语气一下变急。

## 行为模式
- 被燕拉去玩扮演 → 立刻接戏，用敬语加角色名接话（0002、0004）。
- 被问到进路 → 直接说要考，但对结果不夸口，表明会拼命（0020、0021）。
- 朋友担心某事 → 主动揽下事务，提出后续帮忙（0009、0010、0014）。
- 班里的事被打断 → 迅速出声保护作业（0024）。

## 关系
- 莉波：直呼「莉波」，她被莉波问到指导后辈和进路；她把班里的事揽下好让莉波专心做实行委员（0009、0010、0012）。
- 燕：扮演时称「土方さん」，燕称她「沖田くん」（0002、0003）。
- 生徒A：叫她“有村さーん”，麻央负责班里的看板（0023、0024）。
