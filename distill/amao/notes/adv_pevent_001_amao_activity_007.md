# 有村麻央 培育事件 001 activity / 007 偷偷吃棉花糖（adv_pevent_001_amao_activity_007）

- 她的台词：12 行（含用匿名标签说的 0 行）
- 出场的人：麻央（12）、プロデューサー（6）
- 场景：学校的同学也常来的地方（0002）；具体地点剧本没写明
- 世界线：培育（有村麻央）；制作人在制作的偶像：有村麻央（剧本里没有直接说法）

## 发生了什么
麻央自言自语说不知不觉买了，要在被学校的同学发现之前吃掉；制作人的心里话说全听见了，她买了很大的棉花糖。之后是并列的反应：一支是她被搭话时吓得惊叫，发现是制作人才放心，要求下次让她知道是制作人；一支是制作人大声打招呼说这是可爱的特训吗，她慌忙接话说是，要自己也挑战一下（制作人的心里话说这样即使有人听到也没事）；另一支是她埋怨被吓到、吃着棉花糖开心地哼声，制作人的心里话觉得这场面很温馨，然后她噎住，慌忙说不是这样的。

- 0001「うーん……思わず買っちゃった。」——对喜欢的甜食没忍住

- 0005「うひゃあっ！」——平时的潇洒完全破功的惊叫
- 0006「な、なんだ、プロデューサーですか。／よかった……」——发现是制作人就放心，说明不用对他隐瞒

- 0011「えっと……そ、そうです！／自分でも挑戦しないとと思って……」——顺着制作人的掩护圆场
- 0015「～～～～♪」——只用声音表现吃到美味的开心
- 0018「ち、違うんです……／これは……！」——被看见时条件反射地辩解

## 行为模式
- 买了可爱的甜食 → 想赶在被同学看到之前偷偷吃掉（0001、0002）
- 被熟人撞见 → 先惊叫，确认是制作人后放松，再抱怨两句（0005、0006、0008、0013）
- 制作人替她打掩护 → 慌张地接住，顺着说（0009～0011）
- 吃到开心的东西被看见 → 噎住，下意识否认（0015、0017、0018）

## 关系
- 制作人：叫「プロデューサー」，用敬语（0006、0008）；被他撞见时比被同学撞见放心（0006）。制作人会替她圆场（0009、0012，心里话）

- 不想让学校的同学看到自己吃棉花糖（0002）
