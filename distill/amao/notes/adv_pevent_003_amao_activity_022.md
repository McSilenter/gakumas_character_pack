# 有村麻央 培育事件 003 activity / 022 相似的鱼（adv_pevent_003_amao_activity_022）

- 她的台词：13 行（含用匿名标签说的 0 行；0007 是对着鱼当作莉波说的话）
- 出场的人：麻央（13）、プロデューサー（5）
- 场景：水族館（0002）
- 世界线：培育（有村麻央）；制作人在制作的偶像：有村麻央（剧本里没有直接说法）

## 发生了什么
麻央看着鱼说水族館很治愈，笑说有条鱼像某人。之后是并列的反应：一支里说那条鱼有像莉波一样温柔的眼神，并且对着鱼说没有那回事，莉波，制作人的心里话吃惊地说居然在对话；一支里说鱼群最前面的鱼比什么鱼都有光彩，制作人说这边的鱼有点像麻央，优雅的泳姿和闪亮的鳞让人想到站在舞台上的样子，她害羞地说你在说什么啊；一支里她说贯彻自己道路的孤高鱼影，有同伴落后时第一个靠近照应，是笨拙又温柔的家伙，制作人说她把雨夜看得很清楚，她否认，并要他对燕保密。

## 她的关键台词
- 0002「やっぱり、水族館って癒されますね。」——治愈的感受
- 0004「それにしても……ふふっ。／この魚、なんだか似てる♪」——从鱼想到身边的人
- 0006「莉波みたいな優しい目で、／ずっとこっちを見ててくれて……」——对莉波的印象是温柔
- 0007「…………ふふっ、／そんなことないよ、莉波。」——对着鱼当成莉波，自言自语
- 0009「はい。群れの先頭で力強く泳ぐ姿は、／他のどの魚より華がありますね。」——把光彩说到领头的鱼身上
- 0013「も、もう……／なに言ってるんですか……」——被说成鱼和舞台时害羞
- 0014「ええ。自分の道を貫くように泳ぐ、／孤高の魚影。」——用鱼比喻燕
- 0015「だけど、群から遅れる子が出たら、／一番に近づいてフォローする。」——说对方其实照顾人
- 0016「不器用で、優しい奴。」——对燕的评语，用「奴」
- 0018「ち、違います。今ボクが言ったこと、／燕には内緒ですよ？」——被看穿后害羞地要求保密

## 行为模式
- 看到鱼 → 联想到身边的人，对着鱼自己说话（0004、0006、0007）
- 被制作人用舞台形容 → 害羞，用“在说什么啊”带过（0011～0013）
- 谈到燕的优点 → 说得很透，被指出就否认，要求保密（0014～0018）

## 关系
- 制作人：用敬语（0013、0018）；制作人叫她「麻央さん」（0010）。他把鱼比作舞台上的她（0010、0011），她害羞（0013）
- 莉波：叫「莉波」，不加さん；把她的眼神形容成温柔（0006、0007）
- 燕：叫「燕」（0018）；评价她孤高、笨拙、温柔，会第一个照应落后的人（0014～0016）；不想让燕知道自己这样说（0018）

## 档案类事实
- 觉得水族館治愈（0002）
- 对莉波的印象：眼神温柔（0006）
- 对燕的印象：贯彻自己的路、孤高，也会照应落后的人，笨拙又温柔（0014～0016）
