# 雨夜燕 亲爱度剧情 / 第13话（adv_dear_atbm_013）

- 她的台词：45 行（含用匿名标签说的 0 行）；其中 0039、0081 是括号里的心里话（标签是燕）
- 出场的人：燕、プロデューサー、月花、美鈴、観客
- 场景：开头她在找跑掉的美鈴（制作人说今天暖和、美鈴去午睡了，0002）；之后N.I.A的一场试镜结果发表现场，她去侦察月花（0054 起）
- 世界线：亲爱度（雨夜燕）；制作人在制作的偶像：雨夜燕

## 发生了什么
燕要指导美鈴却总被她逃掉，又因为之前的约定不能发火，很头疼（0001～0008）。制作人说美鈴很在意賀陽燐羽的转学、建议先听她说，她同意（0009～0014）。她找到美鈴，点破美鈴在意燐羽，告诉她燐羽会出场N.I.A、要她也出场；美鈴说想和燐羽和好，她建议像当初和自己那样提出有条件的比赛，但说美鈴实力还不够、燐羽比轻敌的自己难对付得多（0016～0032）。她说学生会有义务证明初星是偶像学校的顶点、她想让美鈴夺冠，要美鈴接受她的课程，美鈴答应（0034～0038）。她提出要侦察月花，理由是知道月花的强、不想再因轻敌而输（0048～0052）。看到月花第一名后，她说不甘心但月花现在比她高，终于理解制作人要她看外面的理由，并说曾把月花作为“帅气”粉丝服务的参考（0060～0065）。月花来搭话，她说挑战书是那个笨蛋暴走写的并道歉，但不撤回；月花说她能成为鹰、过去她眼里只有星南是枷锁，她说月花只是垫脚石，两人互相放狠话（“自己去死”“我会杀了你”）后一起大笑（0071～0098）。剧情经过参照 hmsz 笔记。

## 行为模式
- 后辈逃课 → 怪别人不拦，但自己发不了火（因为约定），转而头疼怎么办（0003、0005～0008）
- 被建议先了解对方想法 → 接受（0014），之后还拿这句话反过来用（0050）
- 指导后辈 → 先点破对方的真正心事，再给具体办法，强调实力还不够、说明共同利益，最后命令式地要求对方接受课程并保证让她成长（0016～0037）
- 面对强敌 → 不再轻敌，主动要求侦察；看到实力后坦率承认对方更强、理解制作人的用意（0048、0051、0052、0060、0061）
- 被对手挑衅 → 用更夸张的狠话回敬，互相放话后一起大笑（0087、0089、0093、0095、0097）
- 别人替她惹了麻烦 → 向受影响的人道歉，但不撤回（0073、0076）

## 关系
- 美鈴：叫她「秦谷」，对她说「お前」；美鈴叫她「副会長」（0030）。主动点破美鈴在意燐羽（0017），建议有条件的比赛（0026），要美鈴接受她的课程（0037），美鈴答应（0038）；心里话里觉得美鈴今天格外坦率（0039）
- 燐羽：称「賀陽」；说燐羽是美鈴的前组合成员（0011），燐羽很难对付（0031）
- 月花：叫她「月花」「貴様」（0087、0095）；月花叫她「燕」「お前」。两人很久没见（0071）。月花说她变了、有成为鹰的才能、过去的枷锁是眼里只有星南（0077、0082～0084）。她称月花为垫脚石，互放狠话后一起大笑
- 制作人：叫「貴様」；在月花面前称他「そこの馬鹿」（0073）；月花称他是她的「飼い主」（0085）
