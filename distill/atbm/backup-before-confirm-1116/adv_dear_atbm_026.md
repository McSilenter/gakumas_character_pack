# 雨夜燕 亲爱度剧情 / 第26话（adv_dear_atbm_026）

- 她的台词：35 行（含用匿名标签说的 0 行）
- 出场的人：燕、プロデューサー、星南、ことね、学園長
- 场景：夏季『H.I.F』当天（0001）的会场：赛前、各人的 live、结果公布后
- 世界线：亲爱度（雨夜燕）；制作人在制作的偶像：雨夜燕

## 发生了什么
『H.I.F』当天，制作人说赛前评价是星南七、燕三，燕说要让大家刮目相看；她说舞蹈明显强化了，向制作人道谢，并说『H.I.F』经历过很多次、知道如何发挥实力（0001～0020）。星南和ことね来打招呼，星南称ことね为担当偶像，说是燕指明了道路、ことね牵着她的手，要用最好的表演回报；燕宣告『一番星』会是自己（0021～0037）。燕的 live 后宣言“下一个『一番星』是我”，但星南的表演之后燕沉默，学园长宣布夏季『一番星』是十王星南（0040～0048）。制作人道歉说是自己的战略失误，燕说不是他的错、是星南太强，说心情复杂：为星南的光芒高兴，也为自己的无力恼火，并向制作人道歉没能把胜利带回来（0049～0060）。制作人提起最初“做不到就以死谢罪”的约定，燕慌忙说冬季还有机会；制作人改说冬季做不到就作为制作人负责，燕说要成为冬季『一番星』，让他再也说不出离开她身边的话（0061～0074）。剧情经过参照 fktn、jsna 笔记。

## 她的关键台词
- 0005「七が星南で、三が私か。／……フン、目にものを見せてやる。」——不利的评价激起斗志
- 0008「ああ、分かっている。／1年生が相手でも、なめてはいない。」——不轻视后辈
- 0011「貴様のアドバイスのおかげだ。／感謝する、プロデューサー。」——坦率道谢
- 0016「『H.I.F』は、これまでに何度も／経験してきた舞台だ。」——资历
- 0019「フッ、貴様は大船に乗った気でいろ。」——自信满满地让制作人放心
- 0036「悪いが、『一番星』になるのは、／この私だ！　叩き潰してくれる！」——对星南的宣战
- 0046「言われなくとも、分かっている。」——看完星南的表演后已预感结果
- 0053「十王星南が、強かったのだ。」——败后不推责
- 0058「その星南に歯が立たなかった／己の不甲斐なさに苛立っている。」——坦白复杂的心情
- 0060「……貴様に、勝利を、／持ち帰ってやりたかった。」——为没能给制作人带来胜利而歉疚
- 0066「バ、バカなことを言うな！」——制作人提起“以死谢罪”时慌张
- 0074「貴様が私の隣から離れるなんて、二度と／言えないようにしてやるからな！！」——不愿制作人离开

## 行为模式
- 被看低 → 「フン」一声，转为斗志（0005）
- 赛前 → 冷静评估对手（不轻视一年级），再表明自信（0008～0010、0016～0019）
- 输了 → 先沉默，然后替制作人开脱、把胜因归给对手，再坦白自己的复杂心情并道歉（0044、0052～0060）
- 制作人要为失败承担极端后果 → 慌乱阻止，把话题拉回“下一次还有机会”（0063、0066～0067）
- 制作人说会负责 → 「貴様は、そういうやつだったな」接受，并用更强的目标回应（0071～0074）

## 关系
- 制作人：她叫「プロデューサー」「貴様」；制作人叫她「雨夜さん」。她感谢制作人的建议（0011），败后替他开脱（0052），为没带回胜利道歉（0060），不愿他离开自己身边（0074）
- 星南：她叫「星南」「十王星南」；星南叫她「燕」，说燕为自己指明了道路（0030）。星南现在是ことね的制作人（0023「愛しの担当アイドル」）。她把星南当作要超越的顶级偶像（0073）
- ことね：她叫「藤田」「お前」；说知道ことね在星南的觉醒中出了力（0028）；ことね叫星南「会長」，说今天要赢星南（0027）

## 档案类事实
- 夏季『H.I.F』的『一番星』是十王星南（0047～0048）；燕没赢
- 赛前评价约为星南七、燕三（0004～0005）
- 她说『H.I.F』这个舞台已经历过很多次（0016）
- 舞蹈强化后她说跳得更利落、柔韧（0010）
- 星南担当ことね（0023）；ことね、花海姐妹也参加了这次『H.I.F』正赛（0006、0025）
- 制作人在最初说过不能让她成为『一番星』就以死谢罪（0061～0062，与第1话 0082～0083 一致）；本话改为冬季『H.I.F』做不到就作为制作人负责（0069～0070）
- 下一个目标：冬季『H.I.F』的『一番星』（0067、0073）

## 不确定
- 0044 她的沉默与 0046「言われなくとも、分かっている。」：她“明白”的内容（自己输了）是推断，剧本没明说。
- 0070 制作人说的「責任を取ります」具体怎样负责没说；0074 她理解为制作人会离开她身边。
- 0038～0039 是ことね的 live 台词，各人表演的顺序和细节剧本省略。
- 【译文】0016「これまでに何度も」译作“无数次”，略有夸张，影响不大。
