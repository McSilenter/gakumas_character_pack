# 十王星南 亲爱度剧情 / 第6话（adv_dear_jsna_006）

- 她的台词：25 行（含用匿名标签说的 0 行）
- 出场的人：星南、燕、プロデューサー
- 场景：燕来找会长星南「直訴」（0001、0002），地点没写；星南的直播对谈之后（0006）
- 世界线：亲爱度（十王星南）；制作人在制作的偶像：十王星南（0036「私のプロデューサー」）

## 发生了什么
燕对星南说有话要讲，星南说早就猜到第一个来直诉的会是燕。燕质问星南最近的一系列活动：和新生的无聊聊天直播、挑战不擅长的料理出丑、玩对战游戏流泪，最后还要在杂志上登泳装照，大喊「けしから～～～んっ！」。星南问那样粉丝会生气不看杂志吗，燕说会买、还会熟读采访，被星南称为「私の大ファン」后否认，说两人是宿命的对手、今年一定要追上星南。燕说以前的十王星南绝不会向粉丝展示狼狈的样子，自己心目中的十王星南是全校的模范、高洁的学生会长兼完美无缺的偶像，要星南别让她失望。星南说会接受这些话，但不改方针；燕怀疑是那个制作人灌输了不好的想法，星南指出燕连见都没见过他，问燕是不是在嫉妒，燕否认。星南说是按自己的意志前进，誓言要成为顶级偶像，请燕生气、幻灭都行，但要看到最后；燕担心她在想什么奇怪的事，星南说不是燕想的那样。

- 0004「貴様が最近始めた一連の活動……／あれはどういうことだ？」——当面质问
- 0007「苦手な料理に挑戦して恥をかいたり、／対戦ゲームに挑戦して涙を見せたり、」——对星南的活动一一列举，看得很仔细
- 0009「けしから～～～んっ！」——对泳装照的强烈反应
- 0012「いや買う。買うし、／インタビューも熟読するがな……」——嘴上反对，却说会买、会熟读采访
- 0014「だ、誰が貴様のファンかっ！」——被称为粉丝时慌忙否认
- 0015「言ったはずだ！　私と貴様は、／宿命のライバルなのだと！」——自认是星南的宿命对手
- 0016「今年こそ必ず、／貴様の背に追いついてみせると！」——宣言今年要追上星南（宣言）
- 0020「以前の十王星南なら／決してしなかったはずだ！」——对星南变化的抗拒
- 0022「私が目指す十王星南は、全校生徒の／模範であり、道を照らすしるべであり。」——她心中的十王星南形象
- 0023「高潔なる生徒会長にして／完全無欠のアイドルなのだ！」——接上一行，理想化的星南像

- 0033「やはり！　あのプロデューサーに／よからぬことを吹き込まれているのか？」——把星南的变化归咎于制作人

- 0039「なっ……バカなことを！」——被问是不是嫉妒时否认
- 0058「……おい……妙なことを／考えているんじゃあるまいな？」——察觉星南话里有决心，担心她

## 行为模式
- 对星南的做法不满 → 直接找上门“直诉”，把看到的活动逐条列出来质问（0001、0004～0009）
- 被问到作为粉丝的真心 → 先老实说会买、会熟读，被点破是粉丝就慌忙否认，并改说是宿命的对手（0012～0016、0028）
- 星南做出违背她理想形象的事 → 搬出“以前的十王星南”和自己的理想像来要求对方（0020～0024）
- 找不到星南变化的理由 → 归咎于星南身边的制作人，即使没见过他也不承认他（0033、0037）
- 被点破嫉妒 → 慌忙否认（0039）
- 察觉对方下了重大决心 → 立刻担心对方在想奇怪的事（0058）

## 关系
- 星南：她叫星南「会長」（0001）、「貴様」（0004）、「十王星南」（0024）；星南叫她「燕」（0002、0010）、「私の大ファン」（0013）。她自称是星南的「宿命のライバル」（0015），否认是粉丝（0014、0028），但会买星南的杂志、熟读采访（0012）；把星南理想化为全校模范、完美无缺的偶像（0022、0023）
- プロデューサー（星南的制作人）：她称为「あのプロデューサー」「あのような者」（0033、0037）；星南说燕没见过、也没和他说过话（0035）。燕不承认他、说他配不上十王星南（0037）

## 档案类事实
- 自称和星南是宿命的对手，今年一定要追上星南（0015、0016，宣言）
- 会买星南登的杂志并熟读采访（0012）
- 没见过、也没和星南的制作人说过话（0035，星南的话）
- 认为星南应该是全校的模范、高洁的学生会长和完美无缺的偶像（0022、0023）

## 不确定
- 0012「いや買う。買うし、」说的是“粉丝会买”还是燕自己会买，主语不明；0013 星南把它当作燕本人的话（「私の大ファンが／そう言うなら」）。
- 0058 燕所说的「妙なこと」具体指什么（引退？）没写，0059 星南只说不是燕想的那样。
- 【译文】0036「私のプロデューサーを／嫌いすぎではないかしら？」意思是“你是不是太讨厌我的制作人了”，译文“我的制作人／是不是有点太讨厌我了？”主宾搞反了。
