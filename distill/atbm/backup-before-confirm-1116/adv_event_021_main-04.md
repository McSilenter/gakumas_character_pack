# 活动 021 / main-04 第4话（adv_event_021_main-04）

- 她的台词：25 行（含用匿名标签说的 0 行）；其中 0040～0043、0045、0046 是她的独白，不是对话中的发言
- 出场的人：燕（25）、星南（14）、麻央（11）、莉波（3）、学園長（1）、旁白（1）
- 场景：开头旁白「星南と燕が2年生の時――」，是2年级时『H.I.F』结果发表后（回想）；0047 起回到现在，星南接完电话回来
- 世界线：活动 021；制作人在制作的偶像：看不出

## 发生了什么
回想里学园长宣布一番星是星南，燕以第二名收场。她对来搭话的麻央说别管我，说自己全力以赴还是没赶上，学园第二名没有价值。麻央劝她，她说星南已完成，没有胜过她的想象，并哭了。独白里讲她一直追着星南的背影。回到现在，星南回来问她怎么了，她说只是在想以前的事，被星南拉着走。

- 0017「……有村か。／悪いが、今の私に関わるな。」——拒绝麻央
- 0019「私は全力で挑んだ。／今度こそやつを超えると決意した。」——这次的决意
- 0021「だが……届かなかった。」——结果
- 0025「誇る、だと？　ふざけるな！／学園No.2に、価値なんてない！」——对麻央说“该骄傲”的反驳
- 0026「価値があるのは、『一番星』だけだ。」——价值观：只有一番星有价值
- 0033「十王星南というアイドルは、／今回の『H.I.F』で完成した。」——判断星南已完成
- 0037「私は、貴様のように強くはなれん。」——对麻央“不放弃”的回应
- 0039「……う、うう……うぅっ……！」——哭泣
- 0042「その姿に、ただ憧れた。／絶対に超えてやると誓った。」——独白：憧憬与誓言
- 0046「一番星には、届かない。」——独白的结论
- 0050「……いや、何でもない。／少し、昔のことを考えていただけだ。」——被问时的掩饰

## 行为模式
- 败北后被人搭话 → 先拒绝，再说出结果，用价值观驳回对方的安慰（0017～0026）
- 被说“下次超过星南”这口头禅 → 断言做不到，并告诉对方她没看见差距（0031～0034）
- 被星南问怎么了 → 说只是想起以前的事，转而问接下来的安排（0050、0051）
- 被拉走 → 说“待て”，叫她别拉手（0055）

## 关系
- 麻央（有村）：称「有村」，被称「燕」（0016）。燕说“我没有你那样的坚强”（0037）。
- 星南：独白里追着她的背影、憧憬并发誓要超越（0040～0042）。现在称「星南」（0055）。
- 莉波：在这篇里在场（0014、0015 是沉默）。

## 档案类事实

- 自己认为该次的表演没有遗憾（0020）
- 口头禅“下次要超过星南”（麻央说，0031）
