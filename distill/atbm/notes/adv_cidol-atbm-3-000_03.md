# P卡 雨夜燕【用理论武装】 / 第3话 用理论武装 第3话（adv_cidol-atbm-3-000_03）

- 她的台词：20 行（含用匿名标签说的 0 行）
- 出场的人：燕（20 行）、プロデューサー（10）
- 场景：在一个能看到“壮观”景色的地方（0001，具体是哪里剧本没写）；时间点在她于试镜中赢了十王星南之后、接下来的舞台之前（0002、0014、0015）
- 世界线：亲爱度（雨夜燕）·P卡；制作人在制作的偶像：雨夜燕（0006、0007 制作人说新曲『理論武装して』和她的试镜）

## 发生了什么
她看着眼前的景色说壮观，制作人说这是赢了十王さん的她相称的景色；她说接下来只剩向自己的粉丝宣告胜利（0001～0003）。制作人说有一点不安：『理論武装して』是为赢十王さん做的新曲，带着那份心情的试镜是最好的表演，但她已经赢了，还能不能再拿出那样的表演（0004～0010）。她说这是愚问：必须向所有人证明自己配做十王星南的对手（0011、0012）。她说刚才是试镜所以只想着赢星南，但之后的舞台上有粉丝在等她，回应粉丝期待是偶像该尽的职责，一定会拿出比试镜更好的表演（0014～0017）。制作人问她是要兼顾想赢十王さん的心情和为粉丝唱的心情吗，她说做不到的话她当偶像就没有意义；她承认会有人觉得盯着星南的她有魅力、也存在用背影说“跟我来”的偶像，但那和她的偶像像矛盾，她的 live 应该献给支持她的人，“是我想这么做”（0018～0024）。制作人说她顽固、又说“这一点我很喜欢”，她慌了，转而要制作人好好看着她，说会让 live 成为最棒的（0025～0030）。

## 她的关键台词
- 0003「フッ……後は私のファンに向けて、／勝利宣言をするだけだな。」——赢了之后首先想到的是对粉丝宣告
- 0005「ほう、貴様にしては珍しいな。／言ってみろ。」——制作人少见地示弱时，愿意听
- 0012「私が十王星南のライバルに相応しいと、／誰に対しても証明する必要がある。」——赢一次不够，还要证明自己配做对手
- 0015「この先のステージでは、／ファンが私を待っている。」——把粉丝放在眼前
- 0016「ファンの期待に応えるのが、／アイドルの果たすべき役割だ。」——她的偶像观
- 0019「それができないのなら、／私がアイドルでいる意味はない。」——把“兼顾胜负心和粉丝”当成做偶像的意义
- 0022「だが、それは私の持っている／アイドル像と矛盾する。」——明确拒绝制作人第2话提出的“用背影带领”的偶像像
- 0023「私のライブは、私を応援してくれる者に／捧げるものであるべきだ。」——live 为支持者而做
- 0024「――私が、そうしたいのだ。」——不是义务，是自己的意愿
- 0026「フン、私は雨夜燕だぞ？／何でも貴様の言いなりにはならん。」——自报全名强调自我，不全听制作人的
- 0028「突然何を言っているんだ貴様は！？」——被说“喜欢”时慌乱
- 0029「ええい！／とにかく、ちゃんと私を見ておけよ！」——慌乱后用命令口气把话题拉回

## 行为模式
- 取得胜利 → 不停在胜利上，马上想向粉丝交代、继续证明自己（0003、0012）
- 制作人表示不安 → 先说「愚問だな」，再给出清楚的理由（0011、0012、0014～0017）
- 与制作人的方针不合 → 先承认对方说法有一定道理，再说明和自己的偶像像矛盾，最后归结为“我想这样做”（0020～0024）
- 被说顽固 → 以「私は雨夜燕だぞ？」顶回去，不是事事听制作人的（0026）
- 被直接说“喜欢”→ 大声反问、用「ええい！」转移话题，改成命令对方看着自己（0028～0030）

## 关系
- プロデューサー：她称「貴様」（0005、0026、0028）；制作人称她「雨夜さん」（0009、0025）。她听取制作人的不安，但在偶像像上坚持自己（0022～0026）；被制作人说「そういうところ、好きですよ。」（0027）时慌乱（0028）。
- 十王星南：她提到时称「十王星南」（0012）、「星南」（0014、0020）。她在试镜中赢了星南（0002、0009 制作人的话；0014），仍认为要向所有人证明自己配做星南的对手（0012）。

## 档案类事实
- 她在试镜中赢了十王星南，用的是新曲『理論武装して』（0002、0006、0009，制作人的话；0014）。
- 她的偶像观：回应粉丝的期待是偶像应尽的职责；live 应献给支持她的人（0016、0023）。
- 她认为“用背影示意跟我来”的偶像像与自己的偶像像矛盾（0021、0022）。
