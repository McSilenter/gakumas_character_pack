# P卡 雨夜燕【Campus mode!!】 / 第3话 Campus mode!! 第3话（adv_cidol-atbm-3-012_03）

- 她的台词：25 行（含用匿名标签说的 0 行）
- 出场的人：燕（25 行）、プロデューサー（14）
- 场景：live 开演前（0001「さあ、ついにライブだな。」、0037「そろそろ時間ですね。」），能看到很多观众的地方（0002）；时间点在她赢了白草月花之后（0007）
- 世界线：亲爱度（雨夜燕）·P卡；制作人在制作的偶像：雨夜燕（0003 她说眼前的光景是制作人「プロデュースの成果」，0023 制作人说一直把她作为悪役系アイドル推广）

## 发生了什么
live 开演前，制作人说人好多，她说这是制作人的制作成果；制作人说这些人是被她吸引来的，她纠正说是“我和你一起创造的光景”（0001～0006）。制作人提醒赢了白草月花也不能松懈，她说向应援她的粉丝传达感谢的这场 live 才是正式的，连希望月花站在这里的人也要让他们满意，这是胜者的责任（0007～0010）。她说拯救悲伤的人是她理想的偶像，也知道“用歌救人”说得傲慢、救人没那么容易，但还是想成为那样，问制作人会不会笑她；制作人说现在的她比谁都帅（0013～0021）。制作人说从发布『理論武装して』起一直把她作为悪役系アイドル推广，今天起改为ダークヒーロー系アイドル；她沉默后大笑，说正合心意，承认自己的做法不正统、全是为了贯彻自我，而且加了“ダーク”更帅（0022～0031）。她说会在体现制作人方针的同时，作为初星的代表展示『Campus mode!!』的魅力、把曲子里的心意传给后辈，然后上台，说要用她的『Campus mode!!』改变大家的世界（0033～0039）。

## 她的关键台词
- 0003「何を他人事のように言っている？／貴様のプロデュースの成果だろう。」——把功劳归给制作人
- 0005「違うな。／私と貴様で生み出した光景だ。」——把成果看作两人共同的
- 0008「分かっている。応援してくれたファンに／感謝を伝えるこのライブこそ、本番だ。」——赢了对决之后，粉丝面前的 live 才是正式的
- 0009「この場に月花が立つことを望んでいた／連中すらも、満足させてやる。」——连对手的粉丝也要顾及
- 0010「それが勝者の責務だからな。」——她对胜利的看法
- 0013「悲しんでいる者を救うのが、／私が理想とするアイドルだからな。」——她理想的偶像
- 0015「歌で人を救うなんて、傲慢なことを／言っているのは分かっている。」——自知理想说出来显得傲慢
- 0017「だが、そういうふうに在りたいと、／思ってしまったのだ。」——仍然想成为那样
- 0018「私を笑うか？／プロデューサー。」——少见地向制作人确认
- 0028「クックック……／ハーッハッハッハ！！」——听到“ダークヒーロー系”后的大笑
- 0030「確かに、私の在り方は真っ当ではない。／すべて我を通すためにやっている。」——对自我的认识
- 0031「何より、ダークとついている方が、／カッコいいからな！」——喜欢“帅气”的直白理由
- 0036「そして、この曲に込められた想いを、／後輩たちに受け継いでいくのだ。」——把传统曲的心意传下去
- 0039「私の『Campus mode!!』で、／みんなの世界を変えてやる！」——上台前的宣言

## 行为模式
- 被制作人把功劳推给她 → 不独占，纠正为“我和你一起”（0003、0005）
- 赢了之后 → 想的是粉丝、连对手的支持者也要满足，视为胜者的责任（0008～0010）
- 说出自己的理想 → 先承认这理想傲慢、不容易，再说仍想这样，并问对方会不会笑（0013～0018）
- 收到新的“人设”提案 → 沉默片刻后大笑接受，用“这样更帅”作为理由（0027～0031）
- 上台前 → 用「行ってくるぞ、プロデューサー！」打招呼，再立下宣言（0038、0039）

## 关系
- プロデューサー：她称「貴様」（0003、0033），也称「プロデューサー」（0018、0038）；制作人称她「雨夜さん」（0004、0014）。她认为这场 live 的光景是两人共同创造的（0005）；向制作人坦白理想并问会不会笑她（0018），被说“比谁都帅”后只回「――そうか。」（0021）。
- 白草月花：她提到时称「月花」（0009）；制作人称「白草月花」（0007）。她已经赢了月花（0007，制作人的话），仍想让希望月花站在这里的人也满意（0009）。

## 档案类事实
- 她在对决中赢了白草月花（0007，制作人的话）。
- 她理想的偶像是“拯救悲伤的人”（0013）。
- 制作人从『理論武装して』发布起把她作为悪役系アイドル推广，这一话起改为ダークヒーロー系アイドル（0022、0023、0026，制作人的话），她接受（0029）。
- 她喜欢“ダーク”这类显得帅气的字眼（0031）。
