# P卡 雨夜燕【互噬】 / 第2话 互噬 第2话（adv_cidol-atbm-3-018_02）

- 她的台词：20 行（含用匿名标签说的 0 行）
- 出场的人：プロデューサー（21 行）、燕（20）
- 场景：新曲『クライアイ』完成后的练习（0001～0004 完成，0005 起练习，0027 练习结束）；地点剧本没写
- 世界线：亲爱度（雨夜燕）·P卡；制作人在制作的偶像：雨夜燕（0003 制作人说她必须唱好这首曲子，0038 制作人说会发参考视频给她）

## 发生了什么
曲子完成，她说想快点让星南听；制作人说那得先唱好，于是开始练习（0001～0004）。几小时后她已经唱得很好，但她自己说这样恐怕到不了星南的心里，制作人也同意：粗犷地倾泻激情是她的唱法，但这首曲子需要的不是这个（0005～0009）。她问怎么办，制作人说她的唱法常把反骨心推到前面，而『クライアイ』是把她想和十王さん一直竞争下去的心意写成的曲子，问其中的感情是什么；她说是想帮她、想给她指路的心情，制作人说那就是爱（0010～0017）。她说虽然有话想说但算了，问要怎么唱才能传达那份“爱”，肯定不是唱得温柔就行；制作人故作停顿后说“一起想吧”，她骂别制造无谓的停顿，被说有综艺才能（0018～0026）。练习结束后她说找新唱法很难；制作人提议用展现成熟色气的唱法，理由是这首曲子是带着对十王さん的爱、作为对手的宣战布告，宣战布告需要更有余裕、像招手一样——她接口说“也就是妖艳”，制作人称赞这个说法（0027～0035）。她觉得这样能更好地引出『クライアイ』的魅力，制作人说会发参考的偶像视频，她道谢，说开始觉得有意思了，雨夜燕这个偶像还有成长空间（0036～0041）。

- 0007「だが……これではおそらく、／星南の心には届かない。」——自己察觉唱法不对
- 0010「貴様も分かっているようだな。／ならば、どうすればいい？」——直接问下一步
- 0016「あいつを助けたい。／道を示してやりたいという気持ちだ。」——说出这首曲子里对星南的感情
- 0018「……言いたいことはあるが、まあいい。」——被说“那就是爱”时不反驳
- 0020「単に、優しく歌えばいいというものでも／ないのだろう？」——不满足于简单答案
- 0024「何もないなら無駄に間を作るな！」——吐槽制作人的故弄玄虚
- 0026「あるとしたら、貴様のせいだ！！」——被说有综艺才能时
- 0034「――妖艶さ、といったところか。」——替制作人把意思说出来
- 0039「ああ、助かる。」——坦率道谢
- 0040「クク……なんだか楽しくなってきたな。」——遇到新课题时的兴奋
- 0041「雨夜燕というアイドルには、／まだまだ伸びしろがあるらしい。」——用全名称呼自己，乐观看待成长

## 行为模式
- 自己唱得已经被夸 → 仍自己指出“到不了对方心里”，不满足（0006、0007）
- 被问到真实感情 → 直接说出“想帮她、给她指路”（0016）
- 被别人用“爱”概括 → 有异议但不纠缠，转去问做法（0018、0019）
- 被制作人戏弄 → 大声吐槽，把账算到制作人头上（0024、0026）
- 听到新的唱法方向 → 自己找一个词概括（「妖艶さ」），再判断能否发挥曲子魅力（0034、0036）
- 面对新课题 → 觉得有意思，以“还有成长空间”看待（0040、0041）

## 关系
- プロデューサー：她称「貴様」（0010、0026）；制作人称她「雨夜さん」（0003、0006、0011）。她和制作人一起摸索唱法，被戏弄会吐槽，被帮忙会道谢（0024、0039）。
- 十王星南：提到时称「星南」（0002、0007）、「あいつ」（0016）；制作人称「十王さん」。她想让星南听这首曲子、想帮她、给她指路（0002、0016）；制作人说这首曲子写的是她想和十王さん一直竞争的心意，是带着爱的宣战布告（0014、0015、0032，制作人的话）。

## 档案类事实
- 新曲名『クライアイ』（0014、0036）。
- 制作人说她的唱法常把反骨心一类的感情推到前面（0011，制作人的话）。
- 制作人认为这首曲子适合展现成熟色气的唱法，她概括为「妖艶さ」（0030、0034）。

## 不确定
- 0004 与 0005 之间是练习，0006 制作人说她「たった数時間で」就唱好了，剧本没有旁白交代经过。
- 0018「……言いたいことはあるが、まあいい。」她想说什么（是否否认“爱”的说法）剧本没写。
- 0016「あいつ」指星南，是从上下文（0015 制作人问『クライアイ』里的感情）推断的。
