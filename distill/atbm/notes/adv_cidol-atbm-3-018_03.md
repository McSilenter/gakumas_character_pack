# P卡 雨夜燕【互噬】 / 第3话 互噬 第3话（adv_cidol-atbm-3-018_03）

- 她的台词：19 行（含用匿名标签说的 0 行）
- 出场的人：燕（19 行）、プロデューサー（16）
- 场景：面向粉丝唱『クライアイ』的 live 开演前（0004、0032）；时间点在她为星南开的那场 live 之后（0024）；地点剧本没写
- 世界线：亲爱度（雨夜燕）·P卡；制作人在制作的偶像：雨夜燕（0005、0006 制作人说想让粉丝也听这首曲子，0033 制作人对她说「どうか俺たちの心に届けてください。」）

## 发生了什么
她找制作人商量：『クライアイ』之前是给十王星南的曲子，但接下来要在粉丝面前表演；制作人说这么好的曲子只用一次太可惜，想让粉丝也听（0001～0006）。她同意，说那就要改变定义：这不只是星南的曲子，也是粉丝的曲子；制作人问能做到吗，她说向粉丝传达爱就行了吧，那是她一直在做的事（0007～0010）。她说为星南写的歌词当作鼓舞粉丝的歌词看也不觉得违和，大概是下意识反映了愿望：既然是偶像，表演就该面向粉丝，所以也许从一开始就设想到了这种展开（0013～0017）。制作人说她总是看着支持她的粉丝、是骄傲的偶像、打心底尊敬她，她慌了让他住口（0018～0023）。她问制作人为星南开那场 live 时是不是规矩地回避了，制作人说是、其实很想看；她说这次看也无妨，因为他也是她的粉丝之一，会回应他的期待（0024～0027）。制作人难得兴冲冲地说要去观众席，说是最喜欢的偶像的 live，她结巴了；开演前她问有什么要说的，制作人请她把最棒的『クライアイ』传到“我们”心里，她说「――任せておけ。」（0028～0035）。

## 她的关键台词
- 0001「プロデューサー、相談がある。」——主动找制作人商量
- 0007「……そうだな。私もそう思う。／であれば、定義を変える必要がある。」——同意后马上想到要重新定义
- 0008「これは、星南のためだけの曲ではない。／ファンのための曲である、と。」——把曲子的对象扩展到粉丝
- 0010「ファンへの愛を伝えればいいのだろう？／いつもやっていることだ。」——把向粉丝传达爱看作日常
- 0014「違和感を覚えないとはな。／無意識に望みを反映していたらしい。」——发现歌词里的下意识
- 0016「私がアイドルである以上、／そのパフォーマンスは／ファンに向けられるべきだ。」——她的偶像观
- 0019「本気で思っているのか？」——被夸时先怀疑
- 0022「な、なんだ急に！／調子が狂うからやめろ！」——被说尊敬时的慌乱
- 0024「……ところで、星南に向けたライブの／時は、律儀に席を外していたのだろう？」——记得制作人上次的回避
- 0026「今度は、観ていても構わんぞ。」——允许制作人看
- 0027「貴様も、私のファンのひとりだからな。／その期待には応えてやる。」——把制作人也算作粉丝
- 0029「フン、珍しくウキウキだな。」——注意到制作人的兴奋
- 0031「……そ、そうか。」——被说“最喜欢的偶像”时的反应
- 0035「――任せておけ。」——上台前的回答

## 行为模式
- 曲子的用途改变 → 自己主动来商量，并提出“重新定义”（0001、0003、0007、0008）
- 被问能否做到 → 以“这是我一直在做的事”回答（0010）
- 回看自己写的东西 → 从中读出下意识的愿望，并归结到“偶像应面向粉丝”（0013～0017）
- 被当面夸、被说尊敬或喜欢 → 先怀疑、再结巴或叫对方住口（0019、0022、0031）
- 想让制作人来看 → 用“你也是粉丝之一”做理由（0026、0027）
- 开演前 → 主动问对方有什么话，听完简短回答「任せておけ」（0032、0035）

## 关系
- プロデューサー：她称「プロデューサー」（0001）、「貴様」（0027）；制作人称她「雨夜さん」（0002、0011、0033）。她把制作人称作“我的粉丝之一”（0027），这次允许他看 live（0026）；制作人说打心底尊敬她（0021）、她是“最喜欢的偶像”（0030），她都慌了（0022、0031）。
- 十王星南：提到时称「十王星南」（0003）、「星南」（0008、0024）。『クライアイ』原本是写给星南的曲子（0003），之前她为星南开过一场 live（0024）。

## 档案类事实
- 『クライアイ』原本是为十王星南写的曲子，这一话起也作为面向粉丝的曲子表演（0003、0004、0008）。
- 她为星南开的那场 live，制作人回避没看（0024、0025）。
- 她认为既然是偶像，表演就应面向粉丝（0016）；向粉丝传达爱是她一直在做的事（0010）。

## 不确定
- 0016 一行里有两个换行，按原文照录。
- 0017「私はこの展開を想定していたのだろう。」是她对自己下意识的推测（「きっと」「だろう」），不是确定的说法。
- 0024 为星南开的那场 live 的情节不在本篇；亲爱度第24话 0008、0009 她让制作人不要看那场只献给一个人的 live，与本篇“制作人回避了”一致。
