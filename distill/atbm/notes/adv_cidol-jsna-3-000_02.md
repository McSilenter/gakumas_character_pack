# P卡 十王星南【小小的野心】 / 第2话 小小的野心 第2话（adv_cidol-jsna-3-000_02）

- 她的台词：16 行（含用匿名标签说的 0 行）
- 出场的人：星南（17 行）、燕（16）
- 场景：星南一个人反复练新曲的地方（0001）；地点剧本没写明
- 世界线：亲爱度（十王星南）·P卡；制作人在制作的偶像：十王星南（本篇制作人没有出场）

## 发生了什么
星南一遍遍练新曲，她从很早就在看，开口说“差不多该停了吧”（0001～0004）。星南请她说感想，她坦率说是很棒的歌、完成度很高，但正因如此不懂为什么还要继续无用的练习；她知道星南最近很忙（0007～0013）。星南为让她担心道歉，她慌忙否认在担心（0014、0015）。星南说这是对自己特别的曲子、是“トップアイドルが歌う曲”，现在还不够，问她怎样才能更好；她说没想到星南会向她求教，又抱怨星南和“くだらん男”做无聊的活动，被星南打断（0016～0025）。她说星南最近只在意“上”，应该看看“下”，王者是从高处往下看的（0026～0028）。星南把这理解为“有观众更接近实战”，以副会長的名义要她紧急召集生徒会听新曲；她说自己不是这个意思，是应该意识身边的对手，最后骂星南不听人说话（0029～0033）。

## 她的关键台词
- 0002「いい加減にしたらどうだ？」——看不下去，开口劝停
- 0004「ああ、かなり前からな。」——承认自己看了很久
- 0008「率直に言って、素晴らしい歌だったぞ。」——对对手坦率称赞
- 0010「さすがの完成度だった――が、／だからこそわからん。」——称赞后马上转入疑问
- 0012「最近、貴様が忙しく／しているのは知っている。」——留意着星南的近况
- 0015「べっ、別に貴様の心配などっ……！」——被说担心时慌忙否认
- 0023「……貴様が私に助言を求めるとはな。／ふん、あまり幻滅させるなよ。」——被求教时的反应
- 0024「それもこれも、くだらん男と／くだらん活動をしているから……」——对星南的活动和身边的人不满
- 0026「まったく……最近の貴様は、／『上』ばかりが気になるようだな。」——指出星南的问题
- 0028「王者とは、／遥か高みから見下すものだろう。」——说出她心中“王者”的样子
- 0031「も、もっと身近にいる／ライバルを意識すべきだと――」——真正想说的是要星南意识到身边的对手
- 0033「人の話を聞かないやつめ！」——被误解后发火

## 行为模式
- 看到对手勉强自己 → 先在旁边看很久，再开口劝停（0002、0004）
- 被问感想 → 先坦率称赞，再说出疑问（0008、0010）
- 被说成在担心对方 → 结巴着否认（0014、0015）
- 被对手求教 → 先说意外、嘴上不饶人，接着顺带抱怨，再认真给建议（0023～0028）
- 建议说得绕 → 被对方误解后慌着解释真意，最后发火（0030、0031、0033）
- 称星南为“貴様”，语尾用“～ぞ”“～な”“～まい”（0008、0012、0013）

## 关系
- 星南：叫「貴様」（0012、0023、0026）；星南叫她「燕」（0003、0022）、「副会長」（0032）。她称赞星南的歌，留意星南最近很忙，被说担心就否认（0012～0015）；她想让星南意识到“身边的对手”（0031）。
- “くだらん男”：她说星南在和“くだらん男”做无聊的活动（0024），指的是谁剧本没写明。

## 档案类事实
- 生徒会的副会長（0032，星南的称呼）
- 自称「私」（0023）

## 不确定

- 0031 她说的“身近にいるライバル”是否指她自己，剧本没明说。
