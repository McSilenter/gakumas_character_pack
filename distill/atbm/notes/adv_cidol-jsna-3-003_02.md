# P卡 十王星南【幸福千层酥】 / 第2话 幸福千层酥 第2话（adv_cidol-jsna-3-003_02）

- 她的台词：27 行（含用匿名标签说的 0 行）
- 出场的人：燕（27 行）、星南（21）
- 场景：星南的生配信，在寮的共有スペース的キッチン（0003）
- 世界线：亲爱度（十王星南）·P卡；制作人在制作的偶像：十王星南（本篇制作人没有出场）

## 发生了什么
星南在配信中宣布要做バレンタインチョコ，嘉宾是她，要看平时严厉的她做出怎样可爱的巧克力；她这时才知道内容，大叫被骗了（0001～0012）。她说让自己做情人节巧克力太不搭，星南念出观众留言“とっても可愛い『素』の燕ちゃん”，她认出这么叫她的只有姫崎，喊着要大家记住（0014～0020）。她说既然站在这里就要完成工作，开始做巧克力；星南又说要边做边聊恋バナ，她说“破廉恥”拒绝，被追问喜欢的类型后还是认真想了：了解偶像和初星学園、理解她、能补足不知变通的她、有出色之处让她从心里尊敬的人（0022～0036）。星南说这全都符合自己，问她是不是喜欢自己，她骂“馬鹿者”，说星南哪里理解她了（0037～0041）。被星南说嘴坏才让后辈害怕后，她反问星南喜欢的类型，听到“拥有我没有的魅力的可爱孩子”，说那是星南喜欢的偶像，要她当着全校学生好好回答（0042～0048）。

- 0014「どこがだっ！？　私に作れというのか、／バレンタインのチョコレートを！？」——不敢相信要自己做巧克力
- 0015「似合わないだろう！　／ミスマッチにもほどがある！」——认为自己和可爱的事不搭
- 0019「私をそう呼ぶ者は／この学園でひとりだけだぞ姫崎ぃ！」——认出留言的人

- 0027「で、できるかっ！　そんなっ……！　／破廉恥なっ！」——对恋バナ的反应
- 0030「まったく……私の好みのタイプだと？／すこし待て、考えてみよう。」——嘴上抱怨，还是认真想
- 0033「その上で、私をよく理解してくれる者。」——喜欢的类型之一
- 0034「融通が利かない私を／補ってくれるような者。」——承认自己不知变通
- 0035「なにか優れている部分があって、／私が、心から尊敬できるような者。」——喜欢的类型之一
- 0040「冗談も休み休み言ってくれ。／貴様のどこが、私を理解しているんだ。」——否认是星南
- 0041「馬鹿は嫌いだと、／いつも言っているだろう馬鹿め。」——用骂人收尾
- 0045「恋バナだ。好きなタイプ。まさか、／私だけにさせるつもりじゃあるまいな。」——反过来逼问星南
- 0048「十王星南！　全校生徒が聞いているぞ、／キッチリ答えてもらおうか！」——要星南正面回答

## 行为模式
- 被突然安排“可爱”的事 → 大叫被骗、说不搭（0012、0014、0015）
- 被叫可爱的昵称 → 立刻认出是谁叫的，放狠话（0019、0020）
- 已经站上台 → 再不情愿也说“仕事は果たす”，开始干活（0022～0024）
- 被问恋爱话题 → 先说“破廉恥”，被追问时还是认真列条件（0027、0030～0036）
- 被说喜欢星南 → 骂“馬鹿者”“馬鹿め”否认（0038、0041）
- 被说嘴坏 → 咂嘴，转而反攻对方（0043、0045）
- 对方回答敷衍 → 当面指出，要求好好回答（0047、0048）

## 关系
- 星南：叫「会長」「貴様」「十王星南」（0012、0040、0043、0048）；星南叫她「燕」（0028、0037），在配信中介绍她是“副会長”（0007）。她说被星南骗了（0012）；星南说她列的喜欢类型全都符合星南，她否认（0038～0041）。星南说她嘴坏所以后辈怕她（0042）。
- 莉波（姫崎）：没有出场；她认定写下“可愛い『素』の燕ちゃん”留言的是姫崎，说这么叫她的人学园里只有一个（0019）。

## 档案类事实
- 生徒会副会長（0007，星南的话）
- 学园里只有姫崎叫她「燕ちゃん」（0019，她自己的说法）
- 喜欢的类型：了解偶像和初星学園、理解她、能补足不知变通的她、有让她从心里尊敬之处的人（0032～0035）
- 自认“融通が利かない”（0034）
- 说自己一直说讨厌笨蛋（0041）
- 星南说后辈怕她是因为嘴坏（0042，星南的话）
- 自称「私」（0014、0033）

## 不确定
- 0017、0018 星南念的留言是否真的来自姫崎，只是她的判断（0019）。
- 她做巧克力的过程本篇没写，48 行后结束。
- 【译文】0027「で、できるかっ！」是“这种事我怎么做得出来！”的拒绝，译文“能、能做到吗！”译成了疑问。
