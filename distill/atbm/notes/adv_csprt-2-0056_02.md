# S卡 2-0056【スパルタ＆スパイス】 / 第2话 不搭的伙伴（adv_csprt-2-0056_02）

- 她的台词：12 行（含用匿名标签说的 0 行）
- 出场的人：燕、広
- 场景：具体地点剧本里没写；她对広说明身体状况的场面
- 世界线：S卡【スパルタ＆スパイス】；制作人在制作的偶像：看不出

## 发生了什么
燕向広指出缺乏基础体力、没有肌肉脂肪、骨架纤细、食量小，说这样的身体不适合当偶像。広说燕很温柔，请求燕指导，理由是靠自己当不了偶像，并说燕是学园里仅次于星南的第二强偶像。燕承认，说很快就会超过星南，问広为何执着于偶像，広说因为最不适合。広又说燕也不适合当偶像，燕吃惊后承认，嘴上说不想被相提并论，还是答应帮她。

## 她的关键台词
- 0001「いいか、篠澤。／お前にはまず基礎体力がない。」——开头先点名，直接指出问题
- 0002「しかも、筋肉も脂肪もついておらず、／骨格も華奢で、食も細い。」——把広的身体特征一条条列出
- 0003「――アイドル向きではない身体だ。」——对身体条件的结论，毫不留情
- 0005「……私を優しいと評する1年は／お前ぐらいだぞ。」——被说温柔，意外，并说只有広这么评价
- 0010「フン、その通りだ。／星南もじきに追い越すがな。」——承认自己是第二强，同时说自己很快会超过星南
- 0011「お前を指導するのは構わんが……／1つだけ聞かせろ。」——答应的前提：先回答一个问题
- 0012「お前はなぜアイドルにこだわる？／他に突出した才能を持っているだろう。」——问広为什么执着于偶像，认为她有别的更突出的才能
- 0014「フッ、まともとは思えん理由だ。／……まあ私も人のことは言えんがな。」——对"最不适合"的理由评价为不正常，同时承认自己也一样
- 0016「なん……だと……！？」——被说"燕也不适合"后的震惊
- 0018「むぅ……確かにな。」——想了想后承认
- 0020「お前と一緒にされたくはないが……／まあいい。手伝ってやろう。」——嘴上不想被相提并论，还是答应帮忙

## 行为模式
- 指出别人的问题 → 点名后具体列出，下结论毫不留情（0001～0003）
- 被说温柔 → 意外，说只有広这么说（0005）
- 被请求 → 先提出条件（回答一个问题）再答应（0011）
- 被指出自己的短处 → 先震惊，想了想后承认（0016、0018）
- 答应帮忙 → 嘴上不情愿，实际答应（0020）

## 关系
- 広：称「篠澤」，叫她"お前"。这一篇里燕被広说成"同伴"，她勉强接受（0001、0020）。
- 星南：称「星南」，说自己很快会超过她（0010）。

## 档案类事实
- 承认自己是学园里仅次于星南的第二强偶像，并说很快会超越星南（0010）
- 自己也是"不太符合世间一般印象的偶像"（0014、0018）
- 认为只有広会评价她温柔的一年级学生（0005）

## 不确定
- 0005「……私を優しいと評する1年は／お前ぐらいだぞ。」是燕的自述，是否属实剧本不能确认。
