# S卡 3-0061【みんなの意見を聞かせて♪】 / 第2话 说教要适度（adv_csprt-3-0061_02）

- 她的台词：11 行（含用匿名标签说的 0 行）
- 出场的人：燕（11）、莉波（9）
- 场景：地点没写明；两人在检查申请书，等千奈们回来（0001、0002）
- 世界线：S卡【みんなの意見を聞かせて♪】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
燕检查完申请书，说没问题。他对生徒会一年级的工作方式感到吃惊，说之后要说教她们。莉波劝他不要太严，他说姫崎太宽松，引导后辈是前辈的责任。莉波说大家也在努力时，他说这早就知道，接着说了倉本、花海、秦谷各自的优点，说她们有值得期待的地方。最后被问到“说了什么”时，莉波改口，而燕没有追问。

## 她的关键台词
- 0001「――申請書のチェック、終わったぞ。／問題ない。」——简短报告，没有多余的话
- 0004「無論、悪い意味でな。／後で説教しなければならん。」——说“吃惊”是坏的意思，并宣告之后要说教
- 0006「姫崎は甘すぎる。未熟な下級生を／導くのは、上級生の務めだぞ。」——主张前辈有责任引导后辈
- 0010「そんなことは百も承知だ。」——被说后辈在努力时，说自己早就知道
- 0012「倉本も花海も、仕事に時間はかかるが、／懸命に取り組み、必ず最後までやる。」——举出倉本、花海的优点
- 0013「秦谷も、怠けているように見えるが、／実は周りをしっかりフォローしている。」——看得出秦谷表面上懒，其实在照顾周围
- 0015「そして全員、生徒のために自分の／できることをするという心構えがある。」——认可三人的心态
- 0016「仕事ぶりはともかく、／見所はある連中だ。」——总结，嘴上仍然说“仕事ぶりはともかく”
- 0018「ん？　何か言ったか？」——莉波小声说的话没听清（或装作没听清）

## 行为模式
- 看到后辈的不足 → 公开说要说教，并认为这是前辈的责任（0004、0006）
- 被说“她们也在努力” → 不反驳，说早就知道，然后具体地列出各人的优点（0010、0012、0013）
- 夸奖后辈 → 绕开直接夸奖，用“見所はある連中”这类话（0016）
- 被说“该当面说” → 不接，问“何か言ったか？”（0017、0018）

## 关系
- 莉波：称「姫崎」（0006）；觉得她对后辈太宽松（0006）。本篇莉波没有直接称呼他
- 倉本、花海、秦谷：称「倉本」「花海」「秦谷」；总称“生徒会1年組”“未熟者ども”（0003、0008）。其实认可她们的努力和心态（0012～0016）

## 档案类事实
- 他在检查申请书（0001）
- 他认为倉本和花海做事花时间但会做到最后（0012）；认为秦谷其实在照顾周围（0013）

## 不确定

- 0018「ん？　何か言ったか？」是真的没听清还是装作，剧本没写。
