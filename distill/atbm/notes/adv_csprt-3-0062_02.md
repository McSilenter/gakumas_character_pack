# S卡 3-0062【よくやったな、倉本。】 / 第2话 唯有毅力值得称道（adv_csprt-3-0062_02）

- 她的台词：12 行（含用匿名标签说的 0 行）；0013、0014、0015 是括号内的心里话
- 出场的人：燕（12）、千奈（8）
- 场景：千奈的课程（レッスン）现场，有走路（ウォーキング）、唱歌、摆姿势的练习（燕 0001、0004、0006、0008、0016）
- 世界线：S卡【よくやったな、倉本。】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
燕说今天是会长拜托他看千奈的课程，预告自己很严格。千奈在唱歌时咬舌、在没有脚步动作的地方摔倒、摆出奇怪的姿势，他一一指出。他想今天到这里为止时，千奈自己要求再来一次。他心里想本以为她很快就会放弃，但毅力确实有，星南关注她大概是这方面。他让她从走路重做，之后说“还差得远，再来一次”，要她做到能做才能回去。

## 她的关键台词
- 0001「今日は会長から、倉本のレッスンを／見るよう頼まれた。」——说明自己是受会长委托来的
- 0002「知っての通り、私は厳しいぞ。／覚悟するように。」——预告自己的严格
- 0004「倉本！　歌っている途中で噛むな！／滑舌は基本中の基本だぞ！」——指出咬舌，并给出理由
- 0006「倉本！　な、なぜ、そこで転ぶ！？／足の動きがないところだぞ！？」——对摔倒出乎意料，动摇
- 0011「まったく、なっとらんな……／まぁ、今日はこのあたりで――」——批评之后想收尾
- 0013「（……すぐに折れるかと思ったが）」——心里话：本来预想她会很快放弃
- 0014「（根性だけは間違いなく、ある）」——心里话：认定她有毅力
- 0015「（星南が気に掛けるのは、／こういうところか……）」——心里话：把星南的关注和毅力联系起来
- 0016「――フン。いい表情だ。／もう一回、ウォーキングからいくぞ！」——嘴上不夸，说“いい表情”并继续
- 0020「クックック……／今日はできるまで帰れると思うなよ！」——笑着宣告今天做不到不能回去

## 行为模式
- 看到失误 → 立刻叫出名字，指出具体错误，有时因出乎意料而慌（0004、0006、0008）
- 后辈主动要求继续 → 心里评价（毅力），嘴上只说“いい表情”并继续（0013～0016）
- 后辈做出来了但还不够 → 说“まだまだ”，再来一次（0018）
- 心里的认可不直接说出口，用严格的要求代替（0014、0016、0020）

## 关系
- 千奈：称「倉本」；觉得她毅力足够（0014）
- 星南：称「星南」（0015，心里话）；对外称「会長」（0001）。他受星南之托来看课程

## 档案类事实
- 他今天受会长之托看千奈的课程（0001）
- 他自己说“私は厳しい”（0002）

## 不确定
- 0020「クックック」后面的“できるまで帰れると思うなよ”是认真的要求还是夸张的口吻，剧本只给了这一句。
- 与第 1、3 话没有对不上的地方。无【冲突】。
