# S卡 3-0079【やっと見つけたぞ！】 / 第2话 午睡与偶尔的训练（adv_csprt-3-0079_02）

- 她的台词：8 行（含用匿名标签说的 0 行）
- 出场的人：燕、星南、美鈴
- 场景：レッスン（燕 0005「さっそくレッスンを始めるぞ」）；地点看不出
- 世界线：S卡【やっと見つけたぞ！】；制作人在制作的偶像：看不出（制作人未出场）；燕、星南在指导美鈴

## 发生了什么
美鈴难得老实来上课，燕觉得少见，美鈴说自己也会上课。训练开始后燕承认美鈴实力不错。星南说想让她在躍動感上多花心思，燕认为这不是对一年级生该有的要求，应该先打好基础。两人就育成方式争论，燕让美鈴给意见时美鈴已经不在，燕大喊找她，美鈴说要去午睡。剧情经过参照 hmsz 笔记。

## 她的关键台词
- 0001「秦谷が素直にレッスンに来るとは、／珍しいこともあるものだ。」——对美鈴老实来上课感到意外
- 0005「いちいち突っ込んでいたらキリがない。／さっそくレッスンを始めるぞ。」——不追究，直接开始
- 0007「フン、素行はさておき、／実力は確かだな。」——承认美鈴的实力，同时保留对品行的不满
- 0011「待て、会長。それは1年生に求める／レベルじゃないだろう。」——制止星南的高要求
- 0012「まずは基礎をしっかり固めることに／集中させたほうがいい。」——主张先打基础
- 0015「貴様のやり方はいつも性急なのだ！／育成はすぐに結果が出るものではない！」——批评星南性急，说育成不会马上出结果
- 0017「ええい、埒が明かんな。／秦谷はどう思う？　――ん、秦谷？」——争论没结果，问美鈴，发现她不在
- 0019「秦谷はどこに行ったァ！？」——又一次大喊

## 行为模式
- 后辈出乎意料地守规矩 → 说“少见”，但立刻开始工作（0001、0005）
- 看到后辈实力 → 肯定实力，同时不忘品行问题（0007）
- 星南提高要求 → 当面反对，从后辈的阶段出发主张打基础（0011、0012、0015）
- 争论无果 → 问当事人的意见，发现人不见了又大喊（0017、0019）

## 关系
- 美鈴：称「秦谷」（0001、0017、0019）；美鈴称她「燕先輩」（0002）。
- 星南：称「会長」，对她用「貴様」（0011、0015）；星南在本篇没有叫她的名字。

- 燕认为育成不会马上出结果（0015）。
