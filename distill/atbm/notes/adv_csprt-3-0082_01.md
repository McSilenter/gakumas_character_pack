# S卡 3-0082【なぜこんなところにッ！？】 / 第1话 共鸣的粉丝之魂（adv_csprt-3-0082_01）

- 她的台词：9 行（含用匿名标签说的 0 行）；0008 是内心想法
- 出场的人：リーリヤ、燕、一同
- 场景：有『スター・サムライ』扭蛋（ガシャポン）的地方，燕在找试作机アストラル的塑料模型（0003）；具体地点看不出；燕变装（リーリヤ 0009）
- 世界线：S卡【なぜこんなところにッ！？】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
燕在找试作机アストラル的塑料模型，听到旁边的动静，发现是リーリヤ，惊讶（内心）。两人都装作偶然来，燕问リーリヤ手里的大量扭蛋，被反问为什么变装，她说偶像私下也不能大意。燕发现那是『スター・サムライ』，リーリヤ说她懂，燕说“少し”，并说有几个ムサシ，愿意给她。

## 她的关键台词
- 0003「さて、試作機アストラルのプラモデル、／まだ残っていたらいいのだが……」——一个人说话，在找模型
- 0008「（か、葛城！？／なぜこんなところにいる！？）」——内心惊讶
- 0010「き、奇遇だな、葛城！／なんとなく立ち寄ってみたのだが！」——慌张地说自己是随便来的
- 0012「では、その手に持っている／大量のカプセルはいったい……？」——对リーリヤ的扭蛋提出疑问
- 0014「ア、アイドルたるもの、プライベートで／油断してはならんのだ！」——对变装给出的理由
- 0015「……む？　もしや、そのガシャポン、／『スター・サムライ』か？」——认出了作品
- 0017「いやまあ、少しだけな。」——被问是否懂时说“只是少许”，保留
- 0019「フッ、ムサシならいくつか持っている。／望むなら、くれてやろう。」——主动提出给ムサシ

## 行为模式
- 意外撞见后辈 → 内心惊慌，但嘴上装作“随便来”，句尾仍用硬话（0008、0010）
- 被问到变装的原因 → 用“偶像私下不可大意”的原则回答（0014）
- 谈到自己熟悉的作品 → 先试探，后来拿出自己的收藏（0015、0017、0019）
