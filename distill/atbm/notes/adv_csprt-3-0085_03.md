# S卡 3-0085【自分と向き合う時間だ】 / 第3话 无论对手是谁（adv_csprt-3-0085_03）

- 她的台词：10 行（含用匿名标签说的 0 行）
- 出场的人：燕、咲季
- 场景：训练的地方，使用机器训练（0002 提到最新的机器）；时间看不出
- 世界线：S卡【自分と向き合う時間だ】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
咲季问燕对自己的训练菜单怎么看，燕说是充分使用最新机器的科学训练方式。咲季问是不是不合口味，燕说很合理，请她让自己参考，并说自己总是拘泥于老办法。咲季说之前教的座禅很有收获，建议互相取长补短，燕同意。训练结束后燕说两人互相取长补短，可能塞得太满。咲季说和燕一起训练能感到成长，燕说有同感，咲季说两人或许合得来。燕说“有共同要击败的对手”，咲季说试镜中是对手，燕说“你这个一年级生真狂妄”，咲季回答无论对手是谁都会全力挑战。剧情经过参照 hski 笔记。

## 她的关键台词
- 0002「最新のマシンを惜しみなく活用した／科学的なトレーニング方式だな。」——客观描述咲季的菜单
- 0004「いや、とても理に適っている。／ぜひ参考にさせてくれ。」——否认不合口味，明说想参考
- 0005「私はどうにも古い修行法にこだわって／しまうところがあるからな。」——承认自己拘泥于老办法
- 0009「そうだな。／お前の言う通りだ。」——接受咲季取长补短的提议
- 0012「少し、詰め込みすぎたかもしれんな。」——结果可能塞得太满
- 0014「私も同じ気持ちだ。／咲季がいると、励みになる。」——认同咲季，说有咲季在是激励
- 0016「フッ、そうかもな。」——对咲季说“相性好”的反应，没有否定
- 0017「共に、倒すべき相手がいる。／ならば、力を合わせるのも悪くない。」——说有共同要击败的对手，合作也不错
- 0019「ほう、この私に勝てる気でいるのか？／1年のくせに生意気だな。」——对咲季的“竞争对手”宣言做出挑衅式的回应

## 行为模式
- 看到不同于自己的训练方式 → 承认优点，表示想参考（0004、0005）
- 对方提议取长补短 → 同意，事后承认做过头（0009、0011、0012）
- 对方表达好意 → 同样回应，但不过分表露（0014、0016）
- 对方宣告对立 → 以“狂妄”回应，维持前辈的姿态（0019）

## 关系
- 咲季：称「咲季」，对她用「お前」（0009、0014）；咲季称她「雨夜先輩」（0001、0013）。燕说有咲季在是激励（0014），同时当她是竞争对手（0019）。

## 档案类事实
- 燕自己总是拘泥于传统的修行方法（0005）。
- 咲季的训练是充分使用最新机器的科学训练方式（0002）。

## 不确定
- 0017「倒すべき相手」是谁，剧本没说。
- 0019 的“この私に勝てる気でいるのか？”是反问/挑衅，不是真的询问。
