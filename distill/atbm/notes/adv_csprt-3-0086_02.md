# S卡 3-0086【貸せ、手本を見せてやる！】 / 第2话 超大圣代挑战！（adv_csprt-3-0086_02）

- 她的台词：9 行（含用匿名标签说的 0 行）；0020 是内心想法
- 出场的人：星南、燕、カフェの店員
- 场景：咖啡店（出场有カフェの店員，端上巨大的パフェ）；时间看不出
- 世界线：S卡【貸せ、手本を見せてやる！】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
店员端来巨大的圣代，燕感到吃惊，星南说这是“高中生期间想做的事”的第二件。燕想知道热量，星南说不想调查。燕让星南感谢自己，星南道谢。星南要先拍照，说用某个应用是最新潮流，燕问她为什么用传闻口气。星南很香地吃，燕说自己撑不住，对太甜的东西不擅长。星南把剩下的接过去，燕在心里想要监督她的饮食。

## 行为模式
- 对方有憧憬的愿望 → 用“让我得到感谢”的口吻接受并配合（0007）
- 对方说话有不自然之处 → 马上指出（0011、0013）
- 自己撑不住 → 直说“已到极限”，并坦白不擅长（0016、0018）
- 对方吃得过多 → 心里决定监视，而不是当面说（0020）
