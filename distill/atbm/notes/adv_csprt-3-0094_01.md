# S卡 3-0094【上かッ！！】 / 第1话 救助小猫（adv_csprt-3-0094_01）

- 她的台词：11 行（含用匿名标签说的 0 行）：0001、0003、0004、0005、0008、0009、0013、0014、0015、0017、0018
- 出场的人：佑芽、燕、猫
- 场景：学园的敷地内（0013 “擅自闯进学校”）；燕正要去参加生徒会的会议（0001）
- 世界线：S卡【上かッ！！】；制作人在制作的偶像：看不出（剧本里没有制作人）

## 发生了什么
燕正要去生徒会会议，听到佑芽喊她闪开。她找不到人，但感觉到气息，喊出「上かッ！！」，躲开了从头顶掉下来的佑芽。佑芽夸她躲得帅，燕责问她为什么会从头顶掉下来，佑芽说是救了一只下不来树的猫。燕说猫擅自闯进来还求救很麻烦，并开始教训佑芽别乱来，万一受伤会影响偶像活动。猫叫了一声后，燕说这次就先放过，以后要注意，佑芽因猫帮她挡了说教而心里感谢。
剧情经过参照 hume 笔记。

## 她的关键台词
- 0001「さて、この後は生徒会の／会議に出席せねば……」——自言自语，说明接下来的安排，表现出以生徒会为先
- 0004「いない……？／いや、確かに気配を感じる……」——看不到人，仍然凭气息判断
- 0005「――上かッ！！」——判断出从上方来，并躲开
- 0008「花海……貴様……」——被夸后先叫姓，语气严厉
- 0009「なにをどうしたら、私の頭上から／降ってくるような状況になるのだッ！」——质问原因
- 0013「猫、か。かってに敷地に入ってきて、／助けを求めるとは、迷惑なやつだ。」——对猫的评价是“麻烦”
- 0014「花海、貴様も無茶な真似はやめろ。／猫を助けるためとはいえ、」——批评佑芽的乱来，同时承认动机是救猫
- 0015「もしケガでもしたら、アイドル活動に／支障をきたす。もっと考えて行動を――」——说教的理由是怕影响偶像活动
- 0017「む……ま、まあ、今回は／この辺りにしておいてやろう。」——猫叫之后中断说教
- 0018「以後、気をつけるように。」——收束，要求以后注意

## 行为模式
- 有人喊小心 → 凭气息判断方位，立刻反应（0003～0005）
- 被夸 → 不接受，转为质问原因（0008、0009）
- 看到后辈乱来 → 先指出，说教的理由落在“影响偶像活动”上（0014、0015）
- 猫叫了一声 → 说教变短，用「今回は／この辺りにしておいてやろう」收尾（0016 之后的 0017、0018）

## 关系
- 佑芽：叫「花海」，对她用「貴様」（0008、0014）；佑芽叫她「副会長」（佑芽 0002、0007）
- 猫：把它当“麻烦的家伙”（0013），但被它叫了之后就放过佑芽（0017）

## 档案类事实
- 她是生徒会的副会长（佑芽 0002、0007 叫她「副会長」；0001 说要出席生徒会的会议）
- 她能凭气息感知上方有人落下，躲开了（0004、0005）

## 不确定
- 0017 中断说教，和猫的叫声（0016）是否直接有关，剧本只写了顺序，没有明说原因。
