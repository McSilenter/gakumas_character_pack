# S卡 3-0110【イクラ～♪　ウニ～♪】 / 第1话 回转寿司奥妙无穷（adv_csprt-3-0110_01）

- 她的台词：10 行（含用匿名标签说的 0 行）
- 出场的人：莉波、燕
- 场景：回转寿司店
- 世界线：S卡【イクラ～♪　ウニ～♪】；制作人在制作的偶像：看不出

## 发生了什么
燕第一次来回转寿司，请莉波教规矩（0002、0003）。她问转盘上的盘子能不能拿，又指着水龙头发问，被说明是倒茶的（0005、0007）。她烦恼要点哪一套，莉波说想点3份イクラ，她觉得过分（0009～0011）。她点了玉子、比目鱼，说小肌也好吃，被称为内行，又问莉波推荐，听到炸鸡和乌冬面惊讶，莉波说配菜别有风味，她表示佩服（0013～0020）。

## 她的关键台词
- 0002「ほう、これが回転寿司か。」——看到回转寿司时的感叹
- 0003「興味はあったんだが、／じつは初めてでな。／姫崎、作法を教えてくれ。」——坦率说是第一次，请求教规矩，称呼「姫崎」
- 0005「……なるほど。回っている皿は、／とってもいいのか？」——确认转盘上的盘子是否能取
- 0007「なるほど。この蛇口は――？」——对不明白的东西直接发问
- 0009「季節の五貫盛り、軍艦三貫セット／悩ましいな……」——为点什么烦恼
- 0011「ひ、姫崎、さすがに無法すぎないか？」——对莉波打算点3份イクラ，认为过分
- 0013「そうだな。私はギョクとヒラメ、／コハダも旨そうだな。」——说出自己的选择
- 0015「なにか姫崎のおすすめはあるか？」——请教推荐
- 0017「唐揚げに、うどんだと……？／寿司屋なのに？」——对寿司店的配菜感到惊讶
- 0020「……な、なるほど。／奥が深いのだな……」——接受莉波的说明，佩服

## 行为模式
- 初次接触的事物 → 坦率承认没做过，请懂的人教，并反复确认细节（0003、0005、0007）
- 看到违反自己预期的做法 → 直接指出“过分”（0011）
- 被说明后 → 以「なるほど」接受，并表示佩服（0005、0007、0020）
- 自己的选择 → 简明地说出具体品目（0013）

## 关系
- 莉波：称呼「姫崎」；莉波称她「燕ちゃん」，称她是内行（莉波 0014）；在回转寿司上听莉波的指教

## 档案类事实

- 点了玉子、比目鱼，觉得小肌也好吃（0013）
