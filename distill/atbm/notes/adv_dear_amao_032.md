# 有村麻央 亲爱度剧情 / 第32话（adv_dear_amao_032）

- 她的台词：10 行（匿名标签 0 行）
- 出场的人：麻央（41 行）、ことね（19）、プロデューサー（13）、燕（10）
- 场景：『選抜試験』结果出来后，她来和麻央说话（0001）；地点剧本没写明。之后制作人和麻央谈写真集、宿舍的ことね一段她都不在场
- 世界线：亲爱度（有村麻央）；制作人在制作的偶像：有村麻央

## 发生了什么
她对麻央说看来『選抜試験』顺利突破了，麻央说这次很严，她表示同意（0001～0003）。她说星南成为トップアイドル后初星的学生们都燃起来了，这大概正是星南所愿（0004、0005）。麻央注意到她袖子上的刺绣，说“你还戴着啊”，她说是“験担ぎ”，戴着时感觉状态好（0006～0010）。麻央说要在本战服装上也给她缝上、比如黑色帅气的锹形虫，她骂“馬鹿者”（0011～0013）。麻央说下次见面就是本战、不会输，她叫了声“有村”，说那件夹克很适合麻央（0014～0016）。

## 她的关键台词
- 0001「――有村。『選抜試験』は、／無事に突破したようだな。」——用姓称呼、语气老成
- 0003「……ふっ、まったくだ。」——同意试验严格
- 0004「星南がトップアイドルになって、／初星の生徒たちに火がついた。」——她看到的局面
- 0005「この状況こそ、／星南の願ったことなのだろうな。」——推想星南的心愿
- 0009「ふん……まあ、験担ぎだな。」——对戴着刺绣的掩饰式解释
- 0010「これを付けているときは、／調子がいい気がするんだ。」——承认刺绣对自己有意义
- 0013「誰が付けるか、馬鹿者。」——被开玩笑时的回击
- 0016「似合っているぞ、そのジャケット。」——临别时直率的夸奖

## 行为模式
- 见到对手 → 先确认对方的成绩，语气平淡（0001）
- 被点破珍惜别人给的东西 → 先“ふん”一声，再用“験担ぎ”解释，但也承认戴着状态好（0009、0010）
- 被开玩笑 → 用“馬鹿者”顶回去（0013）
- 对方宣战后 → 不接战话，先叫名字，再夸对方的衣服（0015、0016）
- 说话：「～だな」「～ぞ」「馬鹿者」等硬派口吻（0001、0009、0013、0016）

## 关系
- 麻央：叫「有村」（0001、0015）；麻央叫她「燕」（0006、0014）。她袖上的刺绣被麻央说“まだ付けててくれたんだ”（0008），麻央说要在她的本战服装上也缝上（0011）；麻央说不会输，她夸麻央的夹克（0014、0016）。
- 星南：叫「星南」（0004、0005）；认为初星学生燃起斗志的局面正是星南所愿（0005）。

## 档案类事实
- 袖子上有一个刺绣，她说是“験担ぎ”，戴着感觉状态好（0006～0010）。
- 麻央说配合她的形象，黑色、帅气的东西（例如锹形虫）合适（0012，麻央的话）。

## 不确定
- 0008 麻央说“まだ付けててくれたんだ”、0011 说“本戦の衣装にも付けてあげるよ”，看起来刺绣是麻央给她做的，但剧本没明说，也没说是什么图案、什么时候给的。
- 0014 麻央说“次に会うのは、本戦だね”，似乎她也进了本战，但她自己没说是否突破了『選抜試験』。
