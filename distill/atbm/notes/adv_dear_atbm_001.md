# 雨夜燕 亲爱度剧情 / 第1话（adv_dear_atbm_001）

- 她的台词：40 行（含用匿名标签说的 0 行）
- 出场的人：燕、プロデューサー、千奈、星南
- 场景：学生会（她在处理报告书、预算案、定期公演日程，0002、0006、0008；制作人说是来找“生徒会”以外的她个人，0014）
- 世界线：亲爱度（雨夜燕）；制作人在制作的偶像：雨夜燕（本话她答应接受制作，0076～0078）

## 发生了什么
燕在学生会处理事务：给千奈的报告书贴满便签、修正部活预算案的错误，向星南报告（0002～0008）。制作人来访，自报是制作科的学生，提出要制作她；她一口回绝，说他是想搭她实力的便车（0019～0026）。制作人夸她美，她有点动摇但仍拒绝，问他能做什么；制作人说要让她成为『一番星』，她斥为大言壮语、要他出去（0033～0043）。制作人转而说对她失望、说她满足于“学园No.2”、自称No.2只证明她不是一番星，还说她从没赢过；她激动反驳，又一时语塞（0048～0064）。制作人告别时她叫住他，说第一次有人敢嘲弄她、对他的制作产生兴趣，答应接受，但说不信任他，要他用今后的表现证明价值（0069～0087）。

## 她的关键台词
- 0019「断る。」——对制作邀请一口回绝
- 0026「私の実力にただ乗りしようという／魂胆が見え見えだぞ。」——认为来制作她的人是想搭便车
- 0033「み、見る目はあるようだな。／だが、不要な手を借りるつもりはない！」——被夸时结巴动摇，但立刻嘴硬
- 0041「大言壮語もいいところだ！／まるで信用ならん！」——对“让你成为一番星”的反应
- 0057「貴様……私を愚弄するか！？」——被说满足于No.2时动怒
- 0061「星南を超え、『一番星』になる！／1年生の時から公言していることだ！」——目标从1年生起就公开说
- 0064「そ、それは……」——被指出“一次都没赢过”时语塞
- 0073「私をコケにしたのは貴様が初めてだ。」——被激怒反而产生兴趣
- 0080「血を見ることになるぞ。」——夸张威胁式的说法
- 0086「だが、私は貴様を信用してはおらん。／今後の働きで、価値を証明してみせろ。」——接受但不信任，要对方证明
- 0087「これからよろしく頼むぞ、／プロデューサー？」——第一次称他「プロデューサー」

## 行为模式
- 有人提出要制作她 → 先断然拒绝，怀疑对方想利用她的实力（0019、0023、0025、0026）
- 被直接夸奖 → 结巴着承认对方“有眼光”，但马上回到拒绝（0028、0033）
- 被说满足现状、被戳到痛处 → 激动地大声否认，搬出自己公开的目标；被追问事实时语塞（0053、0057、0060、0061、0064）
- 被人激将、被看轻 → 反而产生兴趣，主动叫住对方，接受挑战（0069、0072～0076）
- 接受合作时 → 附上威胁和条件（“敢敷衍就见血”“用表现证明价值”），对对方说的狠话回以「良い度胸だ」（0079、0080、0085、0086）

## 关系
- 制作人：先叫他「貴様」（0011、0034 等）、骂他「愚か者」（0025）；最后叫「プロデューサー」（0087）。制作人叫她「雨夜燕さん」「雨夜さん」（0016、0027）。从拒绝到被激将后接受，但明说不信任他（0086）
- 星南：叫她「会長」（0006）、「星南」（0022、0061）；星南叫她「燕」（0007、0009）。她赞同星南说的“我和燕收到的制作邀请多得是”（0021、0022）
- 千奈：叫她「倉本」（0002）；给千奈的报告书贴满便签并说要教她写文件的基础（0002、0004）

## 档案类事实
- 在学生会处理报告书检查、部活预算案修正、定期公演日程等事务，星南说她工作快（0006～0008）
- 叫星南「会長」（0006）
- 收到过很多制作人的邀请（0072；星南也说 0021）
- 从1年生起公开宣称要超越星南、成为『一番星』（0061）
- 制作人说她“一次都没赢过”（0063），她没有否认，只是语塞（0064）
- 自称“已经是学园No.2的偶像”（0023）

## 不确定
- 0063 是制作人的说法「これまで一度も勝てなかった」，对象应是星南，剧本没明说；她的反应是语塞（0064），没有正面承认。
- 0088、0089 标签是プロデューサー，没有括号，内容像心里话，与燕无关，不影响计数。
