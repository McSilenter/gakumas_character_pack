# 雨夜燕 亲爱度剧情 / 第3话（adv_dear_atbm_003）

- 她的台词：41 行（含用匿名标签说的 0 行）
- 出场的人：燕、プロデューサー、星南
- 场景：学园内。先是和制作人谈发声课（0001 起）；之后是她和星南两人谈话的回想（0034～0055，按制作人 0029 所说，她曾在屋顶发呆）；然后向制作人转述（0056 起）
- 世界线：亲爱度（雨夜燕）；制作人在制作的偶像：雨夜燕

## 发生了什么
燕问为什么排了发声基础课，制作人说要矫正高音不稳的缺点；她吃惊他怎么知道，又说他看得太仔细（0003～0010）。制作人说她致命的缺点是做不出“可爱”，她承认自觉不合适；被夸凛々しく美丽、被说闹别扭和害羞的样子可爱时连连否认（0012～0018）。她难得坦率地说“请多关照”，被制作人说反常，制作人追问她在屋顶的烦恼，她才说出来（0022～0033）。回想中，她和星南谈到今年毕业、从中等部偶像课程起已经6年，她说毕业后当然在100プロ继续当偶像；星南说毕业后要辞去偶像当制作人，她惊愕、指责星南想赢了就跑（0034～0055）。向制作人转述后，她说即使是正论也不想星南辞职；听制作人说星南等于在说“这里没人能超越我”，她认定自己被小看了（0062～0070）。她接受制作人“夺走一番星让星南不甘心”的提议，宣言要打败星南、阻止她引退（0073～0078）。剧情经过参照 jsna 笔记。

## 行为模式
- 被指出自己不知道的缺点 → 先怀疑“我有这种缺点？”，接着因为对方观察太细而慌张，最后为了制作还是接受（0005、0007、0010）
- 被夸可爱、被说在闹别扭或害羞 → 立刻大声否认；被夸凛々しく美丽时小声说「そ、そうか……」（0014、0016、0018）
- 被戳穿有心事 → 先说没事，被抓到证据后骂对方，然后叮嘱“别告诉别人”才说出来（0026、0030、0032、0033）
- 被对手抢先宣告要退出 → 惊愕、认为是“赢了就跑”（0046、0049、0050、0053）
- 难过的事被换个角度解读成“被小看” → 情绪从失落转为愤怒和斗志，把“阻止对方引退”变成要赢的理由（0062、0063、0068～0070、0077、0078）
- 认同制作人的提议时 → 用「貴様にしては良い案だな」这种带刺的方式夸（0073）

## 关系
- 制作人：叫他「貴様」、「プロデューサー」（0077）；在星南面前评价他有制作能力、热情是真的、但脑子有问题（0039）；说他不像正常人（0032）。本话开始会把烦恼说给他听（0033），最后说「勝つぞ、プロデューサー。」（0077）
- 星南：叫她「貴様」（0042、0050）、「あの女」（0069）、「慢心女」（0078）；星南叫她「燕」。两人同年、今年一起毕业（0034）。星南说燕认可那位制作人很少见（0040）。得知星南要当制作人后惊愕、不想她辞职，转而要赢她（0049～0078）

## 档案类事实
- 3年生，今年毕业；从中等部偶像课程起在这里6年（0034、0035）
- 毕业后打算在100プロ继续当偶像（0037）
- 缺点（制作人说的）：一定音高以上的高音不稳（0004）；做不出“可爱”（0011），她自觉不适合（0012）
- 星南告诉她：毕业后辞去偶像、当制作人，想培养超越自己的偶像（0045、0055）
- 她不想星南辞去偶像（0063），目标变为夺走一番星、阻止星南引退（0072～0078）
