# 雨夜燕 亲爱度剧情 / 第6话（adv_dear_atbm_006）

- 她的台词：42 行（含用匿名标签说的 0 行）
- 出场的人：燕、プロデューサー、美鈴
- 场景：H.I.F 选拔考试输给美鈴之后（接第5话）；先和美鈴对话，再和制作人两人谈。具体地点剧本没写
- 世界线：亲爱度（雨夜燕）；制作人在制作的偶像：雨夜燕

## 发生了什么
燕不敢相信自己输给了星南以外的人、而且是1年生（0001～0003）。美鈴说没想到差距这么小，燕说自己可是“学园No.2”的雨夜燕，又说美鈴总在偷懒、不可能练过，美鈴说有练、用自己的方式（0006～0012）；制作人说再说下去就难看了，美鈴要她守约（0014、0016）。她拒绝安慰，说现在无法原谅自己；制作人说她只是没尽全力、轻视别人，她反过来指责制作人也有责任，制作人随即承认是他请美鈴来挑战的（0019～0031）。她骂他是不是傻、哪有给自己的偶像下套的制作人；制作人道歉，说是想粉碎她扭曲的自尊，说她无意识中依赖“学园No.2”这个头衔、一输就没了（0033～0053）。她拼命否认，随后自问一直是否抓着幻想，最终承认：追着星南的背影，发现自己没有星南的光芒，就假装在追、其实放弃了，只看着下面安心（0047～0062）。制作人要她别熄灭对自己软弱的愤怒；她骂他是世界最差的制作人，但承认他说得对，宣言要抛开一切从头来过，这次真正成为十王星南的对手，并要他支持自己（0063～0077）。剧情经过参照 hmsz 笔记。

## 行为模式
- 意外落败 → 先不敢相信，搬出头衔，再找理由否定对方的实力（0001～0003、0008、0011、0013）
- 被安慰 → 拒绝，把矛头先指向自己（0019）
- 被指出轻敌 → 反咬对方也有责任（0027、0028）
- 得知被自己人设计 → 先目瞪口呆，再大骂，但在意的是“你的评价也会掉”（0032～0034、0036、0038）
- 被戳破内心 → 先连声否认；被追问动摇的理由时说不出话，随后自己剖析、承认逃避，并对自己发怒（0047、0049、0051、0054～0062）
- 承认对方说得对时 → 先骂对方，再说「だがまあ……貴様の言う通りだ。」（0068、0071）
- 跌到谷底后 → 用新的宣言重新立目标，并把对方拉进来一起（0072、0073、0077）

## 关系
- 美鈴：叫她「お前」（0011），本话没有叫她名字；美鈴叫她「副会長」（0005）。先不肯承认输给她，被制作人制止（0011～0015）
- 制作人：叫他「貴様」；得知选拔对决是他安排的（0031），骂他「世界最悪のプロデューサー」（0068），被他回谢后吼“不是在夸你”（0069、0070）。最后承认他说得对，要他「私を支えろ！」（0077）
- 星南：本话不在场。她承认追着星南的背影时发现自己没有星南的光芒，就放弃了（0059、0060）；宣言要真正成为「十王星南のライバル」（0073），称她「あいつ」（0077）

## 档案类事实
- 3年生（0003「同じ3年生ならまだしも」；制作人 0056「ただの3年生です」）
- 第一次输给星南以外的人，对手是1年生的美鈴（0002、0003）
- 制作人坦白：请美鈴向她挑战的是他（0031）
- 她自己说：察觉自己没有星南那样的光芒后，假装在追、其实放弃了，只看着下面安心（0059～0061）

## 不确定
- 0016 美鈴说「約束は守ってくださいね？」，指第5话 0045～0047 的约定（偶尔休息学生会工作、什么都听），本话没写她怎么兑现。
- 0059～0061 的剖白是被制作人一步步引导出来的结论；“察觉没有星南的光芒”是什么时候、因为什么，剧本没写。
