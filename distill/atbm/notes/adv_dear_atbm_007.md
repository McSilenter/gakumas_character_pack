# 雨夜燕 亲爱度剧情 / 第7话（adv_dear_atbm_007）

- 她的台词：24 行（含用匿名标签说的 0 行）
- 出场的人：燕、プロデューサー、美鈴、リーリヤ、星南、清夏、莉波、佑芽、千奈、手毬
- 场景：她输给美鈴的事在学园里传开之后（0001）；学生会（0015～0035）；之后美鈴带她去“喜欢的地方”，有风、有树荫（0036、0037、0044）
- 世界线：亲爱度（雨夜燕）；制作人在制作的偶像：雨夜燕

## 发生了什么
燕输给美鈴的事成了全校话题（0001，旁白）。学生会里大家一言不发，燕问怎么这么安静，说大概也猜得到大家在想什么；星南、莉波私下说她好像不怎么在意，甚至比平时温和（0015～0021）。美鈴说想去偷懒一下，燕只叮嘱别太晚；美鈴邀她一起，她说偶尔该喘口气，向会长请假，跟着去了（0024～0032）。在美鈴喜欢的地方，她说风很舒服，坦言多亏美鈴和制作人，向美鈴说「お前はすごいアイドルだよ」并道歉自己看不起她（0036～0041）。制作人从树荫里冒出来，提出“雨夜燕的十王星南对手化计划”（ツバイバル・プラン），第一步是先赢会长一次，建议故意报名星南要出演的live的试镜来直接对决（0042～0062）。她说他强硬，也说输给美鈴之后挑战星南会被很多人说愚蠢，但说正式比赛是H.I.F、这正好当前哨战，要他安排和星南对决的场合（0063～0068）。剧情经过参照 hmsz、ttmr 笔记。

## 行为模式
- 大家因为她落败而尴尬 → 她主动开口，平静地点破“我大概猜得到”（0015、0018、0021）
- 后辈要偷懒 → 这次不训斥，只叮嘱别太晚，并接受一起去喘口气（0026、0030、0032）
- 心情平复后 → 坦率承认别人的帮助、向看不起的人道歉，但先说一句「悔しいが」（0039、0041）
- 制作人突然出现或乱起名 → 大声吐槽，被无视继续讲时更急（0043、0045、0047、0049、0051、0056）
- 被问要不要放弃挑战 → 先哼一声，然后把挑战定位成前哨战、主动要求安排（0065～0068）

## 关系
- 美鈴：叫她「秦谷」（0041、0064），对她说「お前」（0039、0041）；美鈴叫她「副会長」（0022、0069）。准她偷懒、接受她的邀请一起去散心（0026、0030），向她道歉认错（0041）；被美鈴说“看起来感情很好”时否认（0047）。周围的人吃惊她们“变得要好了”（一同 0035）
- 星南：叫她「会長」（0032）、「星南」（0064、0068）；星南私下说她似乎不太在意（0016）。决定在live试镜中挑战星南（0067、0068）
- 莉波：莉波叫她「燕ちゃん」（0019），莉波说她比平时温和（0017）；本话她没有叫莉波
- 制作人：叫他「貴様」（0045）、「プロデューサー」（0039、0068）；吐槽他神出鬼没、乱起名，但接受他的计划（0063、0068）
