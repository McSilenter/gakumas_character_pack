# 雨夜燕 亲爱度剧情 / 第8话（adv_dear_atbm_008）

- 她的台词：40 行（含用匿名标签说的 0 行）
- 出场的人：燕、プロデューサー、星南
- 场景：学园内；星南和制作人谈话（她只听到最后，0022）；之后是课程后（0027、0028）她和制作人谈话
- 世界线：亲爱度（雨夜燕）；制作人在制作的偶像：雨夜燕

## 发生了什么
星南质问制作人为何让燕报名她要出的试镜，说燕不可能向她挑战，又说制作人的制作惨不忍睹、对他失望（0001～0017，燕不在场）。燕只听到最后一句，幸灾乐祸，要他做点像样的制作；制作人说正经的制作人帮不了她，她也认同（0018～0026）。练习后她问自己有没有成为帅气的偶像、能不能赢星南，自己先说还不够；她说星南也是帅气路线，但要正面交锋“吃掉”对方的长处，让观众记住雨夜燕更强，并说自己好像也是很厉害的偶像（0029～0042）。应制作人要求，她讲起过去：两家从以前关系就好，从小来往；小时候的星南是个废柴、动不动就哭，什么领域她都比星南强，可星南总是自信满满；得知星南的自信来自偶像实力，她就想粉碎那份自信，于是开始当偶像（0044～0056）。她说只是为了打败星南开始、拖拖拉拉一直做到现在，自己只是个不死心的女人；制作人说她其实憧憬十王星南，她吃惊否认又说不出话（0058～0071）。制作人说她是因为憧憬、过度神圣化星南才一直输，要她先封印憧憬、用正确的眼光看对手，她答应（0072～0084）。剧情经过参照 jsna 笔记。

## 行为模式
- 看到制作人被别人批评 → 嘲笑他“活该”，顺势要他做正经的制作（0022、0024）；被他反驳后马上认同（0026）
- 想确认自己的进步 → 直接问制作人；对方语气一转，她自己先说出“还不够”（0029、0031、0033）
- 对手和自己路线相似 → 不避开，决定正面硬碰、吃掉对方的长处（0035～0037）
- 谈自己的过去 → 爽快答应，用自嘲的口吻（「くだらん動機だろう？」「諦めが悪いだけの女」）讲（0044、0058、0064）
- 被说出不愿承认的感情（憧憬） → 先结巴惊叫，否认到一半说不出话（0066、0067、0069、0071）
- 被提出具体建议 → 问理由，理解后说「承知した」（0080、0082）

## 关系
- 星南：叫她「あいつ」（0035、0045 等）、「星南」；从小来往、两家关系好（0045）。小时候她照顾星南、各方面都比星南强（0050、0051）；为了粉碎星南的自信才当偶像（0054、0055）。她称星南是“初星学园史上最高的『一番星』”（0039）。制作人说她憧憬星南（0065），她没能否认（0071）
- 制作人：叫他「貴様」；会向他确认自己的状态（0029、0031），讲自己的过去给他听（0044）

## 档案类事实
- 雨夜家和十王家以前就关系好，她和星南从小来往（0045）
- 她说小时候的星南是个废柴、爱哭，没有她照顾什么都做不了；任何领域她都比星南强（0047、0050、0051）
- 当时星南在十王家的教育下以偶像为目标（0053）
- 她当偶像的起因：想粉碎星南的自信、嘲笑她，认为星南能做到的自己不可能做不到（0054～0056）
- 她说自己只是为了打败星南开始当偶像，拖拖拉拉地一直做下来（0059、0060）
- 她评价星南是“初星学园史上最高的『一番星』”（0039）
- 制作人说星南在初星学园是别格、和她方向相似（0034）
