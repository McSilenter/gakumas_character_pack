# 雨夜燕 亲爱度剧情 / 第9话（adv_dear_atbm_009）

- 她的台词：33 行（含用匿名标签说的 0 行）
- 出场的人：燕、星南、プロデューサー
- 场景：试镜当天（0001，旁白）；看完星南的表演后、上场前（0002～0018）；结果发表后（0019 起）
- 世界线：亲爱度（雨夜燕）；制作人在制作的偶像：雨夜燕

## 发生了什么
试镜当天，燕看了星南的表演说「流石だな」，说这样才配当她的对手、才值得超越（0002～0006）。她承认可能只是在逞强，说原来绝对不能输的战斗是这么紧张，心态不同世界都变了；问制作人输了怎么办，制作人说“请赢”，她说他严格，但回应期待是偶像的职责，说「行ってくる」上场（0008～0018）。结果1位雨夜燕、2位十王星南（0019～0021，旁白）。她对星南大笑说我赢了；星南认输，并对制作人说错的是自己（0026～0030）。制作人说是她自己的力量，她骂他别谦虚，说赢星南是“我们的力量”、早就认可他是制作人了（0032～0036）。星南说燕因为憧憬自己才一直飞不起来、今后会成为顶级偶像、才能远超自己；她对星南看透一切似的话动怒，说“我所憧憬的十王星南”不要说放弃自己的话，要星南再赢她一次再说满足于偶像（0039～0054）。星南说毕业后辞去偶像的打算不变，但不会就这样输着结束，她说多少次都奉陪（0056～0059）。最后她向制作人道谢，说一个人做不到，说自己是他的担当偶像（0063～0069）。剧情经过参照 jsna 笔记。

## 行为模式
- 看到对手完美的表现 → 先承认对方厉害，再把它变成“值得超越”的斗志（0002、0005、0006）
- 上场前紧张 → 在制作人面前坦白可能在逞强、问输了怎么办；被要求“请赢”反而定下心，以“回应期待”为由上场（0008、0010、0014、0016～0018）
- 获胜时 → 先说不出话、喃喃“做到了”，见到对手就大笑宣告胜利（0022、0024、0028）
- 制作人把功劳全推给她 → 骂他别谦虚，说是“我们”的力量（0032、0033）
- 被问是否信任对方而害羞时 → 「ま、まあな。」含糊承认（0038）
- 对手贬低自己、说要放弃 → 愤怒，搬出“我憧憬的你”要求对方别看轻自己，要对方再赢她一次（0049、0051、0053、0054）
- 想道谢时 → 先吞吞吐吐（「……その、何だ。」），然后说清楚原因和谢意（0063～0065）

## 关系
- 星南：叫她「星南」「十王星南」（0053）；星南叫她「燕」、最后称「私のライバル」（0059）。她首次在试镜中赢了星南（0020、0021）；对星南亲口说出「私の憧れた十王星南」（0051）；星南说不会就这样输着结束，她说多少次都奉陪（0057、0058）
- 制作人：叫他「貴様」「バカモノ」（0032）「プロデューサー」（0061）；说早就认可他为制作人（0036），把胜利称为“我们的力量”（0033），向他道谢（0064、0065），自称是他的担当偶像（0069）

## 档案类事实
- 试镜结果：1位雨夜燕、2位十王星南（0020、0021，旁白）——在这条线里第一次赢星南
- 星南说毕业后辞去偶像的打算不变，但不会输着结束（0056、0057）
- 星南说她“也是偶像力量100000以上的逸材”（0046）
- 她把“回应期待”看作偶像的职责（0017）
