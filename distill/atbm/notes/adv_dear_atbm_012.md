# 雨夜燕 亲爱度剧情 / 第12话（adv_dear_atbm_012）

- 她的台词：28 行（含用匿名标签说的 0 行）
- 出场的人：星南、燕、プロデューサー、佑芽
- 场景：她和星南在谈『N.I.A』的事（0001～0005）时佑芽跑来；后面谈生徒会的应对。学生会相关的场合，具体地点剧本没写
- 世界线：亲爱度（雨夜燕）；制作人在制作的偶像：雨夜燕

## 发生了什么
燕告诉星南要出场N.I.A和白草月花一对一，说自己也是刚知道，两人都说她的制作人不得了（0001～0005）。佑芽跑来说极月学园发出了宣战布告（0006～0014）；制作人现身说明这是把她和月花的对决变成“极月vs初星”的娱乐主题，是极月方面的独断，并转达学园长的话：除了她赢下一对一，还要带后辈在N.I.A夺冠（0018～0032）。星南接下后半，她说那是学生会的事、她也会帮忙（0034、0035）。星南说对手是比自己更高的顶级偶像、她也难赢，她说一番星这么软弱，世评月花也许更高但实力她不输，大笑说要打垮月花（0037～0042）。星南提出生徒会主办课程活动、重点培养学生会后辈；制作人介绍极月的三个棘手偶像（藍井撫子、从初星1年3组转学的賀陽燐羽、月花的妹妹白草四音），她说燐羽实力有保证、惊讶月花有妹妹（0052～0072）。星南请她培养美鈴，她不解“要我培养赢了我的人”，制作人替她答应，并用“十王能做到的你做不到吗”激她，她答应培养美鈴，要让美鈴打垮极月的王牌、在N.I.A夺冠（0078～0089）。剧情经过参照 jsna、hume 笔记。

## 行为模式
- 制作人又擅自行动 → 和别人一起抱怨他，但不阻止（0005、0049）
- 后辈慌张跑来 → 先问怎么了，然后自顾自接着说（0007、0009）；发现说的不是一件事时反问（0011）
- 星南示弱、说她赢不了 → 不接受，反而批评星南软弱，并宣言要赢（0039～0042）
- 被要求做意料之外的事（培养赢过她的后辈） → 先惊叫不解；被制作人用“十王能做到的事”激将后，豁出去答应（0079、0080、0084、0086、0088）
- 面对强敌信息 → 表现出兴趣，评价对手实力（0065、0070）

## 关系
- 星南：星南叫她「燕」；她称星南为“初星的『一番星』”（0039）。星南说她总是把自己估得太高（0046）；星南请她培养美鈴（0078）
- 佑芽：叫她「花海」（0007）；佑芽叫她「副会長」（0006）
- 美鈴：称「秦谷」（0088）；答应培养她（0088、0089）
- 燐羽：称「賀陽」（0069），认可其实力（0070）
- 月花：称「やつ」（0040），要打垮她（0041）
- 制作人：叫「貴様」（0024、0049、0084）；被他抢先替自己回答时大叫（0084）

## 档案类事实
- N.I.A 中和白草月花一对一的事，她也是刚知道（0003）
- 极月学园：961プロ出资的少数精英学校，月花名义上在籍（星南，0015、0016）
- 学园长的指示：她赢下和月花的对决，并带后辈在N.I.A夺冠（制作人转达，0031、0032）
- 学生会后辈：倉本（千奈）、花海（佑芽）、秦谷（美鈴）三人（0056）
- 极月的三个棘手偶像：藍井撫子（藍井家的千金）、賀陽燐羽（从初星1年3组转学）、白草四音（月花的妹妹，极月的王牌）（0066～0073）
- 她之前不知道月花有妹妹（0072）
- 她负责培养美鈴，星南培养佑芽和千奈（0078、0088）

## 不确定

- 0044、0045 制作人分析她的自信来自“把星南当顶级偶像，成为其对手的自己也等同顶级偶像”，是制作人的说法。
- 0016 星南说月花「一応、あの白草月花も／在籍中ということになっているわね。」，只是名义上在籍，和第11话第0042行她说“极月学园方面”一致。
