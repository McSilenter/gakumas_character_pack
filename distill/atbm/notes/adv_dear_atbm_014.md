# 雨夜燕 亲爱度剧情 / 第14话（adv_dear_atbm_014）

- 她的台词：33 行（含用匿名标签说的 0 行）
- 出场的人：燕、プロデューサー、四音、美鈴
- 场景：她给美鈴上课（0001～0020）；她自己的live结束后，隔壁会场有N.I.A试镜，遇到四音（0021～0049）；之后听后辈的试镜结果和四音的动作（0056 起）
- 世界线：亲爱度（雨夜燕）；制作人在制作的偶像：雨夜燕

## 发生了什么
燕严厉训练美鈴，制作人劝她口气柔和些，她说他和星南都太宽松；美鈴说是自己请燕先輩严格指导的（0001～0013）。制作人插嘴指点唱法后，美鈴一次就改好，她惊讶、骂“狂妄的后辈”，继续上课（0016～0020）。她自己的live结束，说今天也是好live，说身体管理没有懈怠（0022、0024）。听说隔壁会场N.I.A试镜第1名是白草四音，她主动上前祝贺，四音冷淡地说没理由被敌人称赞；她说果然是月花的妹妹、言行和实力都像，四音说“和月花姉様无关”、要潰掉她，她慌忙道歉说是失言（0030～0049）。她承认自己不对，推测有名的姐姐也许让四音心情复杂（0051～0055）。后辈结果：千奈胜撫子、美鈴胜燐羽、佑芽输给四音，她说2胜1败、削弱了极月的势头（0059～0064）。制作人说四音选了和她同一枠，还把她严厉指导美鈴的样子剪辑后在SNS传播、损她评价；她得知制作人知情却在泡茶，大骂（0066～0078）。剧情经过参照 hmsz 笔记。

## 行为模式
- 指导后辈 → 用强硬命令的口吻，认为宽松会让人松懈（0001、0002、0008）；后辈表现好时会坦率说完美，再嘴上骂一句（0018、0020）
- 有人劝她温和 → 不接受，反指对方太宽松（0008）
- 遇到敌方的偶像 → 把对方也看成业界同伴，主动搭话、道贺，想了解对方的想法（0030～0037）
- 无心的话伤了别人 → 立刻慌忙道歉，事后自己承认不对，再试着体谅对方的处境（0045、0047、0051、0055）
- 听到后辈的结果 → 紧张地追问，冷静总结得失（0057、0063、0064）
- 被敌人用手段攻击 → 惊怒；发现制作人知情不管 → 大声吐槽（0072、0074、0076、0078）

## 关系
- 美鈴：叫她「秦谷」；本话美鈴称她「燕先輩」（0010、0015），之前几话美鈴称「副会長」。美鈴主动请她严格指导（0010），她嘴上说美鈴狂妄但继续教（0020）
- 星南：她说星南对后辈太宽松（0008）
- 四音：叫她「白草四音」（0035），四音叫她「雨夜燕」「あなた」。主动道贺，却因说“果然是月花的妹妹”惹恼四音，被宣告要潰掉她（0041～0049），她道歉
- 佑芽、千奈：称「花海」（0064）；为佑芽输了觉得可惜
- 制作人：叫「プロデューサー」（0005）、「貴様」（0008、0034、0074）；援引他说的“了解对手想法能成长”（0034）

## 档案类事实
- 正在严格训练美鈴，美鈴说是自己请求的（0010）
- 美鈴说和燐羽约定过（0012）
- 赛程紧（制作人说“相当紧的日程”，0023），她说没有懈怠身体管理（0024）
- 后辈的试镜结果：千奈胜藍井撫子、美鈴胜賀陽燐羽、佑芽输白草四音（0059～0061，旁白）
- 四音选了和她同一枠参加下一场试镜（0066）；她和月花原是特别枠（0067）
- 四音一方把她严厉指导美鈴的样子拍下、剪辑后在SNS传播（制作人的话，0070、0071）；藍井（撫子）特地来初星拍视频（0075）
- 制作人说四音在采访里被问到姐妹关系时笑着无难地回答（0053、0054）
