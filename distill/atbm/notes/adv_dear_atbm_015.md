# 雨夜燕 亲爱度剧情 / 第15话（adv_dear_atbm_015）

- 她的台词：36 行（含用匿名标签说的 0 行）
- 出场的人：燕、プロデューサー、四音
- 场景：先是她和制作人看SNS和排名（0001～0029）；然后是『QUARTET』当天，上场前遇到四音（0030 起）
- 世界线：亲爱度（雨夜燕）；制作人在制作的偶像：雨夜燕

## 发生了什么
燕发现照理应该被炎上的自己排名反而上升，问制作人用了什么魔法；制作人在她的宣传用SNS账号上打出“鬼教官偶像诞生”，她怒斥他煽动炎上（0001～0009）。制作人说那种视频只会让正经偶像掉排名，她先附和“我又不是正经偶像”再自己吐槽（0012～0014）；制作人说视频并不违背她的形象、看得出她以偶像为傲，她也反省自己对美鈴说话太重、今后要注意（0020～0027）。『QUARTET』当天她叫住四音，说炎上营销是四音被她的制作人利用了，四音一时动摇（0031～0037）。她称赞四音技术一流、一定很努力，问为何用卑鄙手段、为什么当偶像；四音说是为了让月花姐姐受辱、先潰掉要和月花一对一的她（0039～0048）。她劝四音堂堂正正以偶像身份比，四音不听（0049～0051）。她问制作人怎么看四音，说想问的是心：四音把偶像和粉丝都当成工具、不想打动任何人，这让她在意；说四音虽是敌人也是业界后辈，偶像不会抛弃任何人，决定用表演来比（0055～0068）。

## 行为模式
- 制作人擅自给她加“属性” → 大声抗议；但看到结果有效会冷静问原因（0007、0009、0011）
- 被引导说出奇怪的结论 → 先顺着说，再自己吐槽（0013、0014）
- 看到自己被剪辑的视频 → 没有只怪别人，而是反省自己说话太重、决定以后注意（0023、0024、0027）
- 面对用卑鄙手段的对手 → 先认可对方的技术和努力，再直接问动机，劝她堂堂正正（0039、0040、0042、0043、0050）
- 对手不听劝 → 沉默（0052），之后不谈技术、关心对方的“心”，决定用表演去传达（0058～0061、0068）

## 关系
- 制作人：叫他「プロデューサー」（0003、0054）、「貴様」；骂他擅自运营SNS（0007、0009），但接受他关于“说话方式”的意见并反省（0027）
- 美鈴：称「秦谷」；说美鈴像门帘一样把重话放过去，但她今后会注意用词（0024）
- 四音：叫她「白草四音」「貴様」「やつ」（0059）；指出炎上是四音被利用（0034），认可其技术与努力（0040），问她为何当偶像（0043）。四音说当偶像是为了让月花姐姐受辱（0045）。她把四音看成业界后辈，说偶像不会抛弃谁（0063、0064）

## 档案类事实
- 她有宣传用的SNS账号（0006），制作人在上面打出『鬼教官アイドル爆誕』（0007）
- 炎上之后她的排名反而上升（0001、0010）
- 她说对美鈴的用词可能太严厉，今后要注意（0023、0024）
- 『QUARTET』：本话中她参加的N.I.A场次（0028、0030）
- 四音说自己当偶像是为了让月花姐姐受辱，先潰掉要和月花一对一的她（0045～0048）
- 制作人评价四音：歌、舞、视觉都一流，但无法同时发挥，很笨拙（0056、0057）
- 她的偶像观：偶像不管对方是谁都不抛弃；偶像要用表演一决胜负（0064、0068）
