# 雨夜燕 亲爱度剧情 / 第18话（adv_dear_atbm_018）

- 她的台词：26 行（含用匿名标签说的 0 行）
- 出场的人：燕、月花、プロデューサー
- 场景：N.I.A 最后和月花一对一的当天、上场前（0001、0025、0026）
- 世界线：亲爱度（雨夜燕）；制作人在制作的偶像：雨夜燕

## 发生了什么
决战当天月花来找她，她说正在集中、没余力看后辈们的比赛（0001～0004）。她承认实绩差太多、观众几乎都认为月花会赢，说这是自己的现状，月花这堵墙确实很高，但今天要超越月花，并告诉月花什么才是真正的偶像（0006～0011）。她说偶像是用表演拯救人的人，连自己妹妹都救不了的人她不承认是顶级偶像；月花说自己的表演是为了让粉丝开心、对不是粉丝的愚妹没兴趣，她回说连最亲近的人都变不成粉丝、可见月花的底（0013～0019）。月花说她赢了就考虑她的话，两人互相下战书（0021～0024）。上场前她出神，问制作人怎么看；制作人说她心中的偶像像英雄，但各人做法不同，她说也许想改变他们的自己是错的，但该做的不变（0028～0037）。制作人说要把自己的偶像形象强加于人，就要做到鲜烈、压倒、让人忘不掉，她的live有改变人的力量；她说听了他的话迷茫就消失，问他信不信自己会赢，他说相信，她说“笨蛋”，要证明他担当的偶像是人人渴慕的真正偶像（0040～0052）。

## 行为模式
- 决战前 → 拒绝分心，专注于眼前（0002、0004）
- 被问是否知道自己处于劣势 → 承认差距、但不当作借口，说只是“现在的位置”，并宣言要超越（0006～0010）
- 和对手价值观冲突 → 用自己的偶像观（用表演拯救人）正面批评对方，不退让（0013、0014、0019）
- 被制作人指出“每个人的偶像方式不同” → 承认自己可能错了，但说行动不变（0035～0037）
- 迷茫时 → 向制作人征求意见、确认他是否相信自己；得到肯定后用骂他“笨蛋”的方式回应，转成决心（0032、0039、0046、0048、0050～0052）

## 关系
- 月花：叫她「月花」「貴様」「白草月花」（0023）；月花叫她「燕」「お前」「雨夜燕」（0024）。她批评月花对四音的态度（0014、0019），两人互下战书（0023、0024）
- 四音：本话不在场；她称月花的「自分の妹」（0014），想改变「やつら」（0036，指月花和四音）
- 制作人：叫他「プロデューサー」（0030）「貴様」「バカなやつ」（0050）；说他的话能让她不再迷茫（0046），问他是否相信她会赢（0048），自称「バカな貴様の担当アイドル」（0051）

## 档案类事实
- 今天是 N.I.A 最终、决定“极月vs初星”的一对一（制作人，0026）
- 她认为观众几乎都认为月花会赢，实绩差距很大（0006、0007）
- 她的偶像观：偶像是用表演拯救人的人（0013）
- 月花的偶像观（对照）：表演是为了让粉丝开心，粉丝是渴慕她、没有她就活不下去的人（0016、0017）
- 制作人说她心中的偶像像英雄（0033）、她的live有改变人的力量（0044）
