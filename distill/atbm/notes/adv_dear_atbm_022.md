# 雨夜燕 亲爱度剧情 / 第22话（adv_dear_atbm_022）

- 她的台词：39 行（含用匿名标签说的 0 行）
- 出场的人：燕、プロデューサー、ことね
- 场景：接第21话末尾，ことね找到燕和制作人（地点剧本没写）
- 世界线：亲爱度（雨夜燕）；制作人在制作的偶像：雨夜燕

## 发生了什么
ことね慌张地来问燕是否知道星南要引退，燕说早些时候就听说了、劝过但星南没改主意，又说星南是从她这里逃走了（0001～0011）。ことね说不想放弃、请燕协助，燕还没回答，制作人就替她答应了（0012～0019）。燕说星南已作为制作人向前看，ことね反驳那不是真心，燕看出ことね是星南的粉丝（0024～0033）。制作人说连青梅竹马的心都救不了还算什么偶像，提议举办只为星南一人的 live，展示数值以外的魅力（『スター性』）；燕同意不只是憧憬星南的技术（0035～0056）。ことね说自己也能做，制作人便提出两人用 live 对决决定谁来救星南的心，燕起初反对，被问是否愿把这个角色让给ことね后，答应为“成为星南的英雄”而对决（0057～0074）。制作人说想帮人的心情会强化她，像四音那时一样；燕决定先照制作人的指示做（0075～0094）。

## 她的关键台词
- 0007「止めたに決まっている。／だが、あいつは考えを曲げなかった。」——说明自己劝过但没成功
- 0011「いいわけがないだろう！／だが、あいつは私から逃げたんだ！」——不甘心与被抛下的愤怒
- 0026「あいつはもうアイドルではない。／プロデューサーとして前を向いている。」——此时的消极判断，随后被ことね反驳
- 0031「……そうか。／星南のファンだったな、お前は。」——看穿ことね
- 0034「しかしだな……／私に何ができると言うのだ？」——失去方向时的自我怀疑
- 0045「ああ、／アイドルパワーとかいう戯言のことか。」——对星南“能看见数值”的说法不以为然
- 0049「私とて、別に星南のアイドルとしての／技術だけに憧れたわけではない。」——承认憧憬星南，而且不只是技术
- 0073「星南のヒーローになる役目を懸けて、／ライブをしようじゃないか！」——用“英雄”定位自己的目标
- 0075「――それで、どう戦う？／今の藤田はかなり厄介だぞ。」——一旦决定就立刻转入作战思考
- 0088「だが、『N.I.A』のライブでは、／星南の心を救えなかった。」——回顾上次的不足
- 0094「……分かった。／まずは貴様の指示に従おう。」——接受制作人的方针

## 行为模式
- 自己受挫时被追问 → 用“我劝过了”“她逃了”掩饰不甘（0007、0011）
- 制作人擅自替她决定 → 先大声抗议「なぜ貴様が答える！？」「勝手に話を進めるな」，但不真正拒绝（0017、0019、0066）
- 被激将（是否愿意把角色让给别人）→ 迟疑后豁出去答应（0068～0073）
- 一旦答应 → 马上问怎么打、对手多强、条件是什么（0075、0081、0083）
- 对“数值”之说 → 先嘲讽为戯言，被制作人说“数值不是一切”后同意（0045、0048）

## 关系
- 星南：她叫「星南」「あいつ」；制作人称星南是她的「幼馴染」（0037、0069），并说她是星南最大的粉丝（0092）。她说星南从她这里逃了（0011），但仍想当星南的英雄（0073）
- ことね：她叫「藤田」「お前」（0001、0031）；ことね叫她「副会長」，叫星南「会長」，激动时说漏「星南ちゃん」（0029）。她看出ことね是星南的粉丝（0031），并接受和ことね的 live 对决（0073）
- 制作人：她叫「貴様」「プロデューサー」；制作人叫她「雨夜さん」，说话尖锐（0035、0037），她最后同意照制作人的指示做（0094）

## 档案类事实
- 星南的引退她早些时候就听说了，劝过但星南没改主意（0005、0007）
- 星南说过自己能把偶像的能力看成数值，她称之为「アイドルパワーとかいう戯言」（0044～0045）
- 她憧憬星南，不只是憧憬技术（0049）
- 制作人说星南是她的青梅竹马（0037）
- 制作人说想帮助别人的心情会强化她，四音那次的 live 有说明不了的魅力（『スター性』）（0084～0087）
- 她和ことね将用 live 对决，决定谁去救星南的心（0063～0073，约定，本话未举行）

## 不确定
- 0015 她的沉默后由制作人代答（0016），她当时的真实想法没写。
- 0042 制作人说星南判断赢不了燕才专心当制作人，是制作人的推测；0043 燕本人对此存疑。
- 0088「『N.I.A』のライブでは、／星南の心を救えなかった」——第19话里星南的反应（祝贺、托付）是否就是这里说的“没救到”，本话没细说。
