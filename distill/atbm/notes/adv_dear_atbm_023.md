# 雨夜燕 亲爱度剧情 / 第23话（adv_dear_atbm_023）

- 她的台词：58 行（含用匿名标签说的 0 行）；0097～0100 是括号里的心里话
- 出场的人：燕、月花、プロデューサー、ことね、四音、星南
- 场景：先是和制作人商量 live 构成（地点没写）；然后到极月学園（0037）找月花；最后是和ことね的 live 对决（地点没写）
- 世界线：亲爱度（雨夜燕）；制作人在制作的偶像：雨夜燕

## 发生了什么
燕和制作人商量给星南的 live：歌单定为『理論武装して』『初』，最后一首新曲，歌词要燕参与写，主题是把对星南的爱写成语言；演出方面燕自己压低成本拍板（0001～0025）。燕说歌词总缺点什么，整理星南对自己的意义（朋友、学生会伙伴、追赶的对手、憧憬的偶像），却说不出自己想怎么做，制作人建议她向外看（0026～0036）。燕去极月学園找月花，月花说星南已经到极限、跟不上她们；燕先说就算星南不在也要继续当偶像，随即改口说还不能放弃，骂月花眼光是节穴，说星南的真价不止于此、丢下星南不是她憧憬的偶像（0050～0078）。之后和ことね的对决：制作人说由两人自己判定胜负、ことね先上；燕在心里惊叹ことね的 live，然后用自己的 live 赢了，ことね承认落败，把救星南的任务托付给燕（0079～0120）。剧情经过参照 fktn 笔记。

## 行为模式
- 被要求写感情露骨的歌词 → 支支吾吾，被说“不是害羞的时候”就嘴硬说「分かっている」（0018～0020）
- 拿不定主意 → 先把对方对自己的意义一条条列出来，再问自己想怎么做（0029～0034）
- 被对手（月花）贬低重要的人 → 先顺着说出消极结论，随即翻转，激烈反驳（0064～0072）
- 发现制作人事先安排好 → 嘴上骂「プロデューサーめ」，但照样行动（0041）
- 对手表现出色 → 心里坦率承认，当面先称赞，再宣告不会输（0097～0103）
- 赢了之后 → 简短确认胜利，郑重接下对方的心意（0110、0118）

## 关系
- 星南：她说星南是从小一起的重要朋友、一起运营学生会的伙伴、一直追赶的对手、憧憬的偶像（0029～0031）；她不愿放弃当星南的对手（0059）
- 月花：她叫「月花」「貴様」，骂月花「貴様の目は節穴だ」（0069）；月花叫她「燕」「お前」，说是从“飼い主”（制作人）那里听说她会来（0040）。最后她向月花道谢（0078）
- 四音：她叫「四音」，说「頑張っているようだな」（0043）；四音抱怨因为她每天被月花逼着上地狱般的课程（0044）
- ことね：她叫「藤田」「お前」；赞赏ことね的 live（0102），赢了之后接受ことね的托付（0118）。ことね叫她「副会長」
- 制作人：她叫「貴様」「プロデューサー」；一起商量 live，制作人说自己当审查员不公平所以不当（0085）

## 档案类事实
- 她和星南小时候憧憬初星学园的偶像，比赛谁把『初』唱跳得好；入学后在大家面前表演时，同班同学被两人的水平吓到（0006～0009）
- 给星南的 live 歌单：『理論武装して』『初』，最后一首新曲（0003～0012）
- 她没写过歌词（0015）；新曲歌词她要参与（0014）
- 月花说四音变成这样是因为她（0076）；四音现在每天被月花带着上课程（0044～0045）
- 和ことね的 live 对决她赢了（0107、0110）

## 不确定
- 0062～0063 星南的台词与第19话 0045～0046 相同，是燕在回忆里想起的话，不是星南当场在说。
- 0064「ただ進み続けるだけだ。」和 0065「たとえ星南がいなくても、／私はアイドルで在り続ける。」是对月花 0060 问题的回答，紧接着 0067～0068 自己翻转，这两句不是她的最终立场。
- 0029～0034 她整理星南意义的话是对制作人说的还是独白，剧本没标括号；0028 先说「少し、時間をくれないか？」。
