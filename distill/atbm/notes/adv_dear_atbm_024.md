# 雨夜燕 亲爱度剧情 / 第24话（adv_dear_atbm_024）

- 她的台词：50 行（含用匿名标签说的 0 行）
- 出场的人：星南、燕、プロデューサー、ことね
- 场景：制作人布置好的、只有星南一名观众的 live 舞台（0003、0010）
- 世界线：亲爱度（雨夜燕）；制作人在制作的偶像：雨夜燕

## 发生了什么
制作人布置好只为星南一人的 live，燕向他道谢；ことね把星南带来，说自己的心意也托付给了燕（0001～0016）。燕对星南宣布这场 live 只献给她，唱完新曲『クライアイ』后，星南说感受到燕非常喜欢她这个偶像（0017～0031）。燕说想要星南继续当偶像只是自己的任性；她自问没有星南是否就会放弃当偶像，回答“不是”，她有在『N.I.A』找到的理想——成为英雄一样的偶像，会继续当偶像；接着又说自己看得到真正的星南，逼问星南是否还想当偶像、还想成为顶级偶像（0032～0048）。星南承认对偶像有遗憾，但说能力值已到上限、追不上燕；燕说如果能力值决定结果，她就该输给月花，星南承认今天的表演有数值测不出的魅力（0050～0061）。燕说已有在没有星南的世界活下去的觉悟，但作为最早的粉丝仍相信星南的可能性；又说明之前说的“背负你的重担”是“一起”的意思（0062～0087）。星南坦白不想被燕抛下、想当燕的对手，燕说站在身边不需要理由，星南最后宣布撤回引退（0088～0110）。剧情经过参照 jsna 笔记。

## 行为模式
- 为重要的人做了大事 → 当面不提辛苦，只用「見ものだな」之类的挑衅口吻（0024）
- 劝说别人时 → 先承认自己的愿望只是任性、尊重对方的选择，再说出“我看得到真正的你”去点破（0034、0042～0045）
- 对方用“数值/能力”说服自己 → 用自身的实例反驳，斥为「バカバカしい」（0053、0055）
- 话被误解 → 先嫌对方误会得蠢，再解释本意（0082～0087）
- 对方说出自卑的理由 → 骂「バカモノ」，再用简短的话表明友情（0104～0105）
- 说直白的评价时不加修饰（「私よりも――弱い。」0079）

## 关系
- 星南：她叫「十王星南」「星南」「貴様」，骂「バカモノ」（0104）；星南叫她「燕」「あなた」。她自称星南最早的粉丝（0065），承认过去把星南神圣化（0075），说现在的星南比她弱（0079），说站在身边不需要理由、因为是朋友（0105）。本话结尾星南撤回引退（0110）
- 制作人：她叫「プロデューサー」，为布置 live 向他道谢（0004）；制作人叫她「雨夜さん」，说想看她和星南在『H.I.F』正赛竞争（0006）
- ことね：没有直接对话；ことね对星南说已把心意托付给燕（0014）

## 档案类事实
- 她的新曲叫『クライアイ』（0027）
- 她的梦想是和星南在职业世界里竞争并超越星南（0032）
- 她的理想偶像像是“像英雄一样的偶像”，是在『N.I.A』找到的答案（0038～0039）
- 她说从小一直看着星南（0047），自称星南最早的粉丝（0065）
- 星南说燕在偶像以外的领域比自己厉害得多（0101，星南的看法）
- 星南撤回引退（0110）

## 不确定
- 0008「だが、このライブは目を瞑っておけ。」是对制作人说的，意思像是“这场你就别看了”，与 0005～0006 制作人说想看的话接不太上，含义不确定。第28话 0067～0068 她对制作人说过让他闭眼、制作人答耳朵还听得见，可见是字面上要制作人别看（只献给星南一人）。
- 0068～0069 星南说「昔のあなたが願った通り――」「アイドルから解放されたところだった」，0073 说燕没忘记不是偶像的自己：燕过去曾希望星南不当偶像？本话没有解释，是之前剧情的事（未在本组核对）。
- 0074「その私も、結局は貴様という／アイドルに憧れてしまった。」中的“その私”指 0073 记得“不是偶像的星南”的自己，上下文的确切所指需结合前面的剧情。
- 0062 与 0040 的关系：她既说没有星南也要当偶像，又说相信星南的可能性；两者并列，不是推翻。
