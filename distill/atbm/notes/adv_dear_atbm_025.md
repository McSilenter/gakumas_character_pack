# 雨夜燕 亲爱度剧情 / 第25话（adv_dear_atbm_025）

- 她的台词：31 行（含用匿名标签说的 0 行）
- 出场的人：燕、プロデューサー、星南
- 场景：夏天『H.I.F』临近时，燕和制作人商量训练方针（地点没写）；之后是「十王星南、アイドル復帰記念ライブ」（0037）
- 世界线：亲爱度（雨夜燕）；制作人在制作的偶像：雨夜燕

## 发生了什么
『H.I.F』临近，燕说状态万全，问剩下的时间做什么，是否也该像星南（和ことね一起）那样强化『スター性』（0001～0006）。制作人说她的能力值还没到上限，让她重点练舞蹈，因为她走『カッコいい』路线、身材好、歌唱本已很强；燕问清理由后同意（0007～0026）。燕看出制作人在犹豫，说自己信任他、也请他信任自己，自己的舞蹈还会进步（0027～0036）。星南的复出纪念 live 是邀请格上偶像的联合演出，星南向全校宣言“以『一番星』为目标吧”；燕沉默后放声大笑，说星南终于成了顶级偶像，被制作人说她很高兴时否认（0037～0056）。燕承认胜率下降、星南加入了『愛嬌』（她推测是跟ことね学的），自己竟也觉得可爱；最后说本来就打算当挑战者，要去夺星（0057～0066）。剧情经过参照 jsna 笔记。

- 0003「万全だ。／調整を怠る私ではない。」——自信、自律
- 0006「私も、『H.I.F』で使えるような／『スター性』を身に着けるべきか？」——主动征求方针
- 0021「理屈は分かるが……／ボーカルでも同じではないのか？」——接受前先追问理由
- 0028「なにか、迷っているな？」——察觉制作人的犹豫
- 0030「私は貴様を信じている。」——对制作人的信任
- 0032「だから、貴様も私を信じろ。」——要求对等的信任
- 0051「やはり来たか、十王星南！／そうでなくては面白くない！」——对手复活时的兴奋
- 0054「見たか、全人類！！／これが十王星南だ！！」——为星南骄傲到对“全人类”喊话
- 0056「……う、嬉しくはない！／面白くなったと思っているだけだ！」——嘴硬否认高兴
- 0063「不覚にも、可愛いと思ってしまった。／この私が……」——对星南新魅力的反应
- 0065「元より、そのつもりだ。／『一番星』はあいつなのだから。」——自认挑战者

## 行为模式
- 接到方针 → 先问“为什么是这个”、提出替代方案，听完道理再接受（0017、0021、0026）
- 察觉对方不安 → 主动说“我信你，你也信我”（0028～0033）
- 被称赞身材 → 「む……そうか？」略显意外（0023）
- 对手变强 → 先沉默，然后大笑、兴奋；被点破高兴就否认，改口说只是有趣（0047～0056）
- 局势不利 → 冷静承认（「……だろうな。」）并分析原因，再重新定位为挑战者（0058～0066）

## 关系
- 制作人：她叫「プロデューサー」「貴様」；制作人叫她「雨夜さん」。她说相信制作人、要制作人也相信她（0030、0032）
- 星南：她叫「十王星南」「あいつ」「貴様」；对星南复出的表演兴奋，说星南终于成为顶级偶像，配得上当她的对手（0052～0053），并承认被星南的可爱打动（0063）
- ことね：她叫「藤田」；说星南在和藤田一起强化『スター性』（0005），推测星南的『愛嬌』是跟藤田学的（0062）

## 档案类事实
- 制作人说她在练 Visual、走『カッコいい』路线（0018）；身材好、跳舞显眼（0022）；歌唱已经非常好（0024）
- 制作人说她的能力值还没到上限（0012）
- 『H.I.F』前的方针：重点练舞蹈（0007、0025～0026）
- 星南的复出纪念 live 是邀请格上偶像的联合 live（0038），星南压倒了她们（0059，燕的话）

## 不确定
- 0062 星南的『愛嬌』是跟ことね学的，是燕的推测。
- 0052「貴様は、ついになったのだな……／トップアイドルに！」是对星南当场表演的评价（是否成为真正意义上的顶级偶像是她的感慨）。
- 0047 她长时间的沉默，含义要看 0049 之后的大笑。
- 【译文】0065「元より、そのつもりだ。」意思是“本来就打算当挑战者”（接 0064 制作人说再次成为挑战者），译文“我本来就没打算作壁上观”偏离原意；0065 后半「『一番星』はあいつなのだから」译成“称号还归她所有”大体对。
- 【译文】0028 译文“你还有茫什么不放心的地方吧”有错字，原文「なにか、迷っているな？」。
