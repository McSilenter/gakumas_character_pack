# 雨夜燕 亲爱度剧情 / 第28话（adv_dear_atbm_028）

- 她的台词：43 行（含用匿名标签说的 0 行）
- 出场的人：燕、プロデューサー
- 场景：冬季『H.I.F』即将开始时，燕和制作人开会回顾至今的经过（地点没写）
- 世界线：亲爱度（雨夜燕）；制作人在制作的偶像：雨夜燕

## 发生了什么
冬季『H.I.F』将要开始，燕说这是自己最后一次『H.I.F』，一定要打倒星南成为『一番星』（0001～0003）。制作人从头回顾：他进入制作人科后看了燕的 live，此后满脑子都是她；听说她拒绝所有制作邀请，于是暗中观察她的校园生活、学生会工作和课程，燕骂他是跟踪狂（0005～0032）。燕说当时觉得自己不需要制作人，来找她的人都只看『学園No.2』的招牌；制作人当初用强硬的话激她，她以为来了个大蠢货（0016～0038）。两人接着回顾：定下“成为帅气的偶像”的方针，让美鈴把骄傲起来的她打垮，她说扭曲的“壳”被打碎、重新造出新的“牙”；之后用ツバイバル・プラン赢了星南，在『N.I.A』和月花交手，想起了“成为英雄一样的偶像”的原点；为星南办 live，夏季『H.I.F』输掉，此后一直在强化『スター性』（0039～0081）。制作人说她现在成长得很出色，燕说这次一定要成为『一番星』（0082～0085）。

- 0050「……歪んだかたちで凝り固まっていた／『殻』を、粉々にされた。」——对美鈴那次挫败的总结

- 0077「だが、それでこそ十王星南だ！／この私のライバルに相応しい！」——输了也为对手骄傲

## 行为模式
- 制作人说出离谱的内幕 → 大声吐槽（「ただのストーカーではないか！！」「どの口が言っているんだ！？」），但最后承认他的算计奏效（0025、0032、0038）
- 被制作人直白地表达好感 → 「そ、そうか……」「う、うむ……」结巴（0013、0019）
- 回顾挫败 → 用比喻（壳、牙）总结，把挫败当作重建的契机（0050～0051）
- 回顾失败 → 先承认对手的光芒，再转为“这才配做我的对手”（0076～0077）
- 被提醒前路不确定 → 简短「分かっている」接受，然后号召出发（0081、0085）

## 关系
- 制作人：她叫「貴様」「プロデューサー」，骂他「ストーカー」（0025）、「口の減らんやつ」（0069）；制作人叫她「雨夜さん」。制作人进入制作人科后看了她的 live 就一心想制作她（0010～0012，制作人的话）
- 美鈴：她叫「秦谷」；制作人说安排美鈴打垮了骄傲的她，美鈴挑衅她是本性（0042、0046～0047）
- 星南：她叫「星南」「十王星南」，称为「私のライバル」（0072、0077）
- 月花：她叫「月花」，提到在『N.I.A』交手（0059）

## 档案类事实
- 冬季『H.I.F』是她最后一次『H.I.F』（0002）
- 制作人入制作人科后看了她的 live（0010），听说她拒绝了所有制作邀请（0015）；她说当时觉得不需要制作人，来找她的人都只看『学園No.2』的招牌（0016～0017）
- 制作人在接近她前暗中观察过她的校园生活、学生会工作、课程（0020～0024，制作人的话）；制作人说她直觉敏锐（0026）
- 制作的最初方针是“成为帅气的偶像”（0040）
- 制作人安排美鈴打垮骄傲的她；之后她失去『学園No.2』的招牌，评价一落千丈（0041～0042、0052）
- 用ツバイバル・プラン（制作人起的名字）挑战并赢了星南（0053～0055）
- 『N.I.A』和月花交手，想起原点：成为英雄一样的偶像（0059～0063）
- 夏季『H.I.F』输了，之后一直强化『スター性』（0075～0079）
