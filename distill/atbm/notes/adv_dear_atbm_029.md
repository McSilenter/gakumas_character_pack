# 雨夜燕 亲爱度剧情 / 第29话（adv_dear_atbm_029）

- 她的台词：33 行（含用匿名标签说的 0 行）
- 出场的人：プロデューサー、燕
- 场景：前半「夏が終わり、秋が訪れた頃」（0001）开始『スター性』课程时的谈话；0064 起回到两个多月后，冬季『H.I.F』的『選抜試験』即将开始（0069）
- 世界线：亲爱度（雨夜燕）；制作人在制作的偶像：雨夜燕

## 发生了什么
秋天开始强化『スター性』时，燕问具体做什么、是否把“想救人”的心情转向审查员；制作人说审查员不是要救的对象，夏季『H.I.F』她其实没发挥出『スター性』，需要找到新的『スター性』（0002～0020）。制作人说『スター性』是存在感、压倒性的魅力，条件有三：强烈的个性、自信、物语；前两项她已具备（帅气的暗黑英雄系偶像、对自己的方式有自豪），第三项是“背负着什么站上舞台”（0021～0040）。燕问只是想赢星南不行吗，制作人说她已经救了星南，她想赢星南的真正理由是想救她，她的本质不是为战斗而存在的偶像；燕说“所以夏天才输了”（0041～0047）。燕苦思不得，要制作人给答案，制作人说别人给的答案无法让她押上一切，只给提示“你的整个人生都是武器”（0050～0063）。回到现在：燕说当时想扇他那张得意的脸，制作人说她找到的答案和他预想的完全不同；『選抜試験』就要开始，制作人要她压倒全场（0064～0074）。

## 行为模式
- 面对新课题 → 先试着套用已有的成功方法，被否定后追问定义（0006～0007、0021）
- 抽象概念 → 用自己看过的具体场面去理解（0024～0025）
- 被指出本质 → 沉默良久，然后自己说出结论（0044、0047）
- 想不通 → 大声崩溃，转而逼问制作人；被拒绝后让步，只要提示（0051～0061）
- 被制作人说“意外” → 立刻回嘴骂对方眼光差（0068）
