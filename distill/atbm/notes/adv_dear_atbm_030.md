# 雨夜燕 亲爱度剧情 / 第30话（adv_dear_atbm_030）

- 她的台词：41 行（含用匿名标签说的 0 行）；0009～0052 是「秋が深まってきた頃」（0008）的回想
- 出场的人：燕、プロデューサー、星南
- 场景：『選抜試験』合格之后和制作人谈话（地点没写）；中间回想深秋时燕留下来处理『H.I.F』改革计划修正提案，星南陪她（0009～0011，地点没写）
- 世界线：亲爱度（雨夜燕）；制作人在制作的偶像：雨夜燕

## 发生了什么
燕以压倒性成绩通过『選抜試験』，却说还缺点什么，这种程度的光芒在星南面前会黯淡（0001～0005）。她回想深秋时：她留下写对『H.I.F』改革计划的修正提案，说要早点提，否则学生的意见会被无视；星南问她是不是对『H.I.F』的大改革不满，说看脸就知道、因为是青梅竹马（0008～0022）。燕先说那是星南成为顶级偶像带来的好变化、不可能不满，被星南说像在说服自己后，承认只是感伤，对待了很久的学园急速变化感到寂寞（0023～0031）。她列出想感谢的人（学园、老师、训练师、同学、对手、粉丝、“那个大笨蛋”），说作为偶像只有用 live 报恩这一个方法，要在『H.I.F』成为『一番星』证明感谢之大，并向星南道谢、确认两人的约定（0033～0052）。回到现在，她说要为培育自己的初星学园报恩而唱；制作人说『スター性』归根到底是反差：她台上粗犷、平时认真诚实、照顾后辈、尊敬老师和训练师，学园的人都知道，所以她背负的物语会发光；燕说被他这么一说迷茫就消失了（0053～0070）。剧情经过参照 jsna 笔记。

## 她的关键台词
- 0005「星南に勝つためには、／この程度の輝きでは霞んでしまう。」——赢了仍不满足
- 0013「早めに提案をしておかないと、／生徒たちの意見が無視されてしまう。」——作为学生会成员替学生着想
- 0016「なんだいきなり。アニメで見る面倒臭い／恋人みたいなことを……」——用动画的比喻吐槽星南
- 0028「不満などあるはずもない。」——先否认（随后改口）
- 0030「……不満ではない。ただの感傷だ。／長く過ごした学園だからな。」——承认真实情绪
- 0031「すべてが急速に変わっていくことに、／寂しさを覚えていただけだ。」——对变化的寂寞
- 0035「お世話になった教師や、」——对老师用敬意的说法
- 0040「……そして、あの大馬鹿者に、」——把制作人列入感谢对象，却用骂称
- 0046「ライブで恩を返す。」——她找到的答案
- 0048「『一番星』に輝くことで、／この感謝の大きさを証明する！」——把感谢和胜利连在一起
- 0054「私は、私を育ててくれた初星学園に、／恩を返すために歌う！」——她的新“物语”
- 0070「貴様にそう言われると、迷いが消える。」——对制作人的信赖

## 行为模式
- 被说中心事 → 长时间沉默，先摆出大道理否认，被识破后才承认是“感伤”“寂寞”（0020～0031）
- 想到要感谢的人 → 一一列举，对老师、训练师用敬语（「お世話になった」「指導してくださった」），对制作人却用「大馬鹿者」（0034～0040）
- 找到答案 → 立刻变成宣言，并向帮了忙的人道谢（0045～0050）
- 制作人点评时 → 「身も蓋もないな」「……フン」冷淡回应，最后坦白信赖（0058、0063、0070）

## 关系
- 星南：她叫「星南」「貴様」；星南叫她「燕」「あなた」，自称「幼馴染」（0021），说她最重视初星学园的传统（0022）。她向星南道谢（0050），确认两人的约定（0051～0052）
- 制作人：她叫「貴様」，在背后称「あの大馬鹿者」（0040）；说被他一说迷茫就消失（0070）
- 老师、训练师：她说「お世話になった教師」「指導してくださったトレーナー陣」（0035～0036）；制作人说她尊敬老师和训练师（0061）

## 档案类事实
- 她以压倒性成绩通过『選抜試験』（0001、0003）
- 『H.I.F』在进行大改革，她写了修正提案（0011、0019）；星南说『H.I.F』的变化是因为星南成为了顶级偶像（0026，燕的话）
- 星南说她是最重视初星学园传统的人（0022）
- 她说在学园待了很久（0030）
- 制作人说她台上粗犷，平时认真诚实、照顾后辈、尊敬老师和训练师，学园的人都知道（0060～0062）
- 她的冬季『H.I.F』“物语”：为培育自己的初星学园报恩而唱（0054）
