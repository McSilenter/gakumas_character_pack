# 雨夜燕 亲爱度剧情 / 第31话（adv_dear_atbm_031）

- 她的台词：31 行（含用匿名标签说的 0 行）
- 出场的人：燕、麻央、莉波、プロデューサー
- 场景：『選抜試験』合格后与制作人谈话；之后在一处能俯瞰初星学园大部分设施的地方找到麻央（0024）；最后在教室见到莉波（0048）
- 世界线：亲爱度（雨夜燕）；制作人在制作的偶像：雨夜燕

## 发生了什么
制作人祝贺燕通过『選抜試験』，提醒她对学园的感谢不会让她的『牙』变钝，要她不忘对自身弱小的愤怒，同时兼顾“牙”和“感谢”；随后通知下一场『選抜試験』的对手是有村麻央（0001～0020）。燕找到在高处看学园景色的麻央，麻央说快毕业了、想把景色记住，这次要赢、进正赛；燕说赢星南的是自己（0021～0031）。麻央说入学时和燕、星南较劲，很快认清差距、把两人当特别的存在而躲开，现在终于追上；燕说看得出她不再迷茫，感谢她三年来共同进步，并宣告会全力击溃她、因为她是自己的对手（0032～0045）。燕从麻央那里得知莉波已在今天的『選抜試験』确定进正赛，到教室祝贺；莉波哭着说是燕在文化祭时推了她一把，燕说期待在正赛交手（0046～0059）。莉波回忆一年级时燕和麻央总吵架，要她真生气才停，燕装作不记得，说三年了麻央也成熟了，被莉波说不坦率；最后燕答应正赛见（0060～0074）。剧情经过参照 amao、hrnm 笔记。

## 行为模式
- 听到对手的名字 → 先评估对方的成长、表示「相手にとって不足なし」（0017～0020）
- 面对同学的告白 → 先说“看得出来”，再坦率感谢，然后宣战，感谢和不让步同时存在（0036～0043）
- 得知同伴的好消息 → 特地去找本人祝贺，并约定在正赛见（0049～0053、0059）
- 对方哭了 → 慌张（0055）
- 被提起自己以前的毛病（总和麻央吵架）→ 装作不记得，把改变说成是对方成熟了（0069～0071），被说「素直じゃない」时只回「フン」（0065、0072）

## 关系
- 有村麻央：她叫「有村」「貴様」；麻央叫她「燕」「キミ」。两人同班（0019），三年间互相竞争；她感谢麻央并称其为对手（0039、0043）。莉波说一年级时她和麻央总吵架（0067）
- 姫崎莉波：她叫「姫崎」「お前」；莉波叫她「燕ちゃん」。莉波说文化祭时是燕推了她一把（0057）；她说期待正赛交手（0059）
- 星南：赢星南仍是她的目标（0030）；麻央说入学时把燕和星南当成“特别的两个人”（0033）
- 制作人：她叫「貴様」；制作人叫她「雨夜さん」，说前面提过要她不忘对自身弱小的愤怒（0007）

## 档案类事实
- 她和有村麻央同班（0019）；她、麻央、莉波都是三年级、快毕业了（0018、0023、0039）
- 一年级时她和麻央经常吵架，莉波真生气才能制止（0067～0068，莉波的话）
- 莉波在当天的『選抜試験』确定进入正赛（0052）
- 莉波说文化祭时燕推了她一把（0057，莉波的话）
- 她下一场『選抜試験』的对手是麻央（0016）
