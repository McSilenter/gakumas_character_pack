# 雨夜燕 亲爱度剧情 / 第33话（adv_dear_atbm_033）

- 她的台词：55 行（含用匿名标签说的 0 行）；0043「一同」不计入
- 出场的人：燕、ことね、星南、美鈴、千奈、佑芽、手毬、燐羽、一同
- 场景：冬季『H.I.F』正赛前的休息期，燕在初星学园里四处走（0056～0057）：课程室（0002）、新生徒会处理文件的地方、遇到ことね的地方，最后和星南看傍晚的星（0115 星南提到夕暮れ时的星）
- 世界线：亲爱度（雨夜燕）；制作人在制作的偶像：雨夜燕

## 发生了什么
燕去课程室看准备『SyngUp!』解散 live 的美鈴、手毬、燐羽；她替转学到极月的燐羽办了在这里练习的手续。美鈴说这次不参加『H.I.F』，燕说也想和她较量、原本暗中打算雪耻；美鈴说把对『H.I.F』的心意托付给燕，燕说会背负她们的心意站上正赛（0001～0028）。燕看新生徒会（千奈、佑芽）处理文件，看出有篠澤代写的笔迹也不责怪，嘱咐她们分清可以改变和不能改变的东西（初星的传统），说自己喜欢这所学园、快要离开了，拜托新生徒会（0029～0052）。遇到ことね，燕说自己已不是副会长，正趁休息在学园里走走；她称赞ことね成了出色的偶像，坦白一直羡慕ことね——星南总是关注ことね，她以前不太信星南的眼光，现在承认星南是对的、ことね也是自己的对手；ことね说那场救星南的 live 自己很想站上去，宣告正赛不会输（0053～0095）。星南从背后吓她不成，燕说雨夜家的教育让她对气息敏感，只是察觉不到制作人；她向星南宣告要赢、拿『一番星』表示对学园的感谢；星南提起燕小时候讲过“傍晚最先出现的星是金星”，说个子高的燕或许够得到那颗星，燕说当然够得到（0096～0119）。剧情经过参照 ttmr、hmsz、fktn 笔记。

## 行为模式
- 后辈挑衅 → 低声骂「クソガキ」，但很快接下对方的心意（0017、0025～0026）
- 看到后辈做事出错 → 忍不住大声纠正、亲自检查，确认没问题就放心，不追究代写（0031、0035～0042）
- 离别在即 → 把想法说成嘱托交给后辈（0045～0050）
- 坦白本音前 → 先宣布「今から本音を言う」（0074）；话被误解成恋爱 → 慌张否认，再条理分明地解释（0080～0084）
- 承认自己错了时 → 直接说「私が間違っていて」，并用「認めよう」郑重认可对方（0084～0085）
- 被问起自己说过的温情往事 → 装作不记得（「さあ……どうだったかな。」0116），被调侃时先骂「バカモノ」再给出肯定回答（0118～0119）

## 关系

- 手毬：叫她「雨夜先輩」，为燐羽和 live 的事道谢（0005～0006），说美鈴的话是掩饰害羞（0023）
- 燐羽：已转学到极月；燕为她办了在初星练习的手续（0008～0009）
- 千奈、佑芽（新生徒会）：她叫「倉本」「花海」「お前たち」；千奈叫她「雨夜先輩」，佑芽叫她「燕先輩」。她嘱托新生徒会守护学园的传统（0046、0050）
- 篠澤：她从笔迹看出篠澤代写，说她也是新生徒会成员（0039～0041）

- 制作人：没有出场；她对星南称制作人是气息消失的高手、「ストーカー」（0101、0103）
