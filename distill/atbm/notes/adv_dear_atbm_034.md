# 雨夜燕 亲爱度剧情 / 第34话（adv_dear_atbm_034）

- 她的台词：46 行（含用匿名标签说的 0 行）
- 出场的人：燕、四音、プロデューサー、月花
- 场景：冬季『H.I.F』正赛当天的会场，上场之前（0002、0032、0052）
- 世界线：亲爱度（雨夜燕）；制作人在制作的偶像：雨夜燕

## 发生了什么
月花来看『H.I.F』，说要找好苗子、顺便见证燕和星南的决战；燕说状态万全，问起四音，月花说四音是燕的粉丝（0001～0010）。四音躲开月花出现，否认是粉丝，抱怨被月花赖在家里、每天地狱般训练；燕说她是真的在努力、前几天亲眼看到了（0011～0024）。四音问燕能否赢星南，燕说面前的人赢过你姐姐，却也承认这是最后一次『H.I.F』、难得紧张；四音说会场大多是别人的粉丝、燕还是『無冠』，但会场里一定也有被燕救过的粉丝，燕向她道谢，说因此觉得自己的路没走错（0025～0049）。制作人问她怎么不和星南说话，她说没什么可聊、只剩用实力较量；她说在休息期间走遍学园和很多人谈过，明白这不只是她的战斗，而是“我们的物语”（0050～0066）。燕说知道制作人让她休息后一直不安，叫他尝尝被动摇的滋味，并说会让他的选择变成正确答案；制作人说明白了她最近的光芒来源：她想救的是他，燕承认这是她刚察觉的“最后的钥匙”（0067～0085）。

## 行为模式
- 嘴硬的后辈（四音）否认自己的努力 → 不争辩，直接用亲眼所见肯定她（0021～0022）
- 被问能否赢 → 先用强势的话让对方安心，被看穿后坦白紧张（0026～0027、0031～0032）
- 被指出劣势（无冠、观众多是别人的粉丝）→ 承认「耳が痛いな」，再说现在只看『一番星』（0040～0042）
- 得到鼓励 → 坦率道谢并说会回应期待（0046～0049）
- 一贯被制作人吓、被看透 → 这次反过来点破制作人的不安，得意地笑，然后安慰并承诺（0069～0076）
- 被说中自己想救人 → 不否认，承认是刚察觉的（0084）

## 关系
- 四音：她叫「四音」「お前」；四音叫她「あなた」「雨夜、燕」（0034）。月花说四音是她的粉丝（0009），四音否认（0011）；四音告诉她会场里有被她救过的粉丝（0044），她道谢（0046）
- 月花：她叫「月花」；月花叫她「燕」「お前」，来见证她和星南的决战（0004）
- 星南：赛前没有交谈，她说只剩用实力较量（0053～0054）
- 制作人：她叫「貴様」；制作人叫她「雨夜さん」「あなた」。她点破制作人在让她休息后的不安（0069～0070），说会让他的选择成为正确答案（0076）；制作人说她想救的是他，她承认（0083～0084）

## 档案类事实
- 冬季『H.I.F』是她最后一次『H.I.F』（0032）
- 四音说她仍是『無冠』，在正赛选手中不起眼（0039）
- 四音说月花赖在自家、每天带她做地狱般的训练（0018）；燕听说四音的粉丝在增加（0019）
- 她在休息期间走遍学园，和很多人谈过（0056）
- 她的“物语”：托付给她的心意、期待她的粉丝、挡在前面的对手、引导她的人——“我们的物语”（0062～0066）
- “最后的钥匙”：她想救制作人（0083～0085）
