# 雨夜燕 亲爱度剧情 / 第36话（adv_dear_atbm_036）

- 她的台词：31 行（含用匿名标签说的 0 行）
- 出场的人：燕、星南、学園長
- 场景：冬季『Hatsuboshi IDOL FESTIVAL』结束后的『一番星』授予仪式（0006）
- 世界线：亲爱度（雨夜燕）；制作人在制作的偶像：雨夜燕

## 发生了什么
学园长说『H.I.F』从今冬起成为诞生『一番星』的世界级活动，宣布优胜者雨夜燕，并叫上现任『一番星』十王星南（0001～0011）。燕对星南说「私の勝ちだな」，星南认输、祝贺她，说今天的燕比谁都耀眼；燕说本想看星南懊恼的样子，星南却像很高兴，星南说比起懊恼更觉得竞争很快乐（0012～0020）。燕说下次轮到星南追她，星南说今后作为 100プロ的对手偶像互相提高（0021～0024）。燕接过『一番星』的证物，说感到分量；星南把剩下不多的在学期间托付给她，说她现在最帅（0025～0032）。燕以『一番星』身份致辞：感谢粉丝、制作人、同学、后辈、训练师、老师、工作人员和学园，承认过去只想着超越星南、视野狭窄，宣告要从初星飞向世界、毕业后成为职业偶像，心与学园同在，让学园的偶像们追随她的背影（0033～0053）。剧情经过参照 jsna 笔记。

## 行为模式
- 赢了重要的对手 → 简短宣告胜利，想看对方懊恼（0014、0018）；对方表现出快乐时 → 顺势把关系翻转为“你来追我”（0021）
- 接过荣誉 → 先感到分量，再联想到对方一直背负着它（0027）
- 公开致辞 → 一一列出感谢对象，结尾改用「ありがとうございました」的敬语（0035～0041）
- 胜利时 → 也公开承认过去的不成熟和遗憾，再转为宣言（0043～0048）
- 被夸 → 「当然だ」坦然接受（0032）

## 关系
- 星南：她叫「星南」「貴様」；星南叫她「燕」「あなた」。星南认输、祝贺她（0015～0017），说竞争很快乐（0020），今后作为 100プロ的对手偶像互相提高（0023），把剩下的在学期间托付给她（0028）
- 制作人：没有出场；致辞中她说「私を叱咤したプロデューサー」（0036）
- 学园的偶像们：她称「貴様ら」，让他们追随自己（0051～0053）

## 档案类事实
- 冬季『H.I.F』优胜者是雨夜燕，她成为『一番星』（0007～0008、0033）
- 『H.I.F』从今冬起改为诞生『一番星』的世界级活动（0002～0003，学园长的话）
- 她毕业后成为职业偶像（0049）；星南说今后两人是 100プロ的对手偶像（0023）
- 她说过去只想着超越星南、视野狭窄，对此仍有遗憾（0044～0045）
- 下一届『H.I.F』她已不在学园（0042）
