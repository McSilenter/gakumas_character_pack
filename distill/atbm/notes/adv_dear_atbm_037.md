# 雨夜燕 亲爱度剧情 / 第37话（adv_dear_atbm_037）

- 她的台词：44 行（含用匿名标签说的 0 行）
- 出场的人：燕、プロデューサー
- 场景：冬季『H.I.F』夺冠后，燕和制作人两人谈话（地点没写）
- 世界线：亲爱度（雨夜燕）；制作人在制作的偶像：雨夜燕

## 发生了什么
制作人在哭，燕神情爽朗，说自己成了『一番星』，誓言是制作人实现的，这样他就不用死了；制作人问她是不是因此才想救他，她说他输了真会那么做（0001～0011）。制作人说誓言已经实现、自己的任务结束，100プロ发来邀约，那里有比学生的他更有经验的制作人，她可以选；燕说「では、決まりだな」，说制作人永远是她的（0012～0025）。她说想和他一起走，是他把困在“壳”里的她救出来，她能想起想成为英雄般的偶像，是因为他是她的英雄，所以这次她想救他；制作人说今天的她确实是他的英雄、是顶级偶像（0026～0038）。燕说这只是起跑线，自己一直“无冠”，必须证明自己是顶级偶像——为了和星南竞争、为了学园、也为了他的梦想（0036～0046）。制作人为一直以来的任性道歉（只说一次）、说今后还会任性，但要让她成为世界第一的偶像；燕问做不到怎么办，否决“用一生来赎罪”，改为让他唱『ハッピーミルフィーユ』，最后说要一起走到顶点（0047～0073）。

## 行为模式
- 胜利时 → 不哭，反倒问对方为何哭，并把功劳归给对方（0003、0005、0008）
- 对方提出要退出 → 先听完、确认自己能选，再用霸道的「私のモノだ」表达挽留（0020～0023）
- 对方不自信地确认 → 「泣くなと言っている」，然后把真心话一口气说出来（0025～0032）
- 被夸已经是顶级偶像 → 说“只是手搭上了那个领域”，转为今后要证明（0039～0041）
- 对方“只道歉一次”“还要继续任性” → 大声吐槽（0052～0055）
- 谈到“做不到的惩罚” → 否决一生赎罪，因为那样她可能会觉得不坏；改提让对方难堪的惩罚，看到对方不情愿就拍板（0063～0069）

## 关系
- 制作人：她叫「貴様」「プロデューサー」「私のヒーロー」（0046）；制作人叫她「雨夜さん」「あなた」。她说是制作人把困在壳里的她救出来、他是她的英雄（0029～0031），这次换她救他（0032）；选择毕业后也继续由他制作（0023、0028）。制作人说今天的她是他的英雄（0033）
- 星南：她说今后要证明自己，也是为了和星南竞争（0042）
