# 藤田ことね 亲爱度剧情 / 第31话（adv_dear_fktn_031）

- 她的台词：23 行（含用匿名标签说的 0 行）
- 出场的人：ことね、燕、プロデューサー
- 场景：ことね 拿下『舞道場』之后（0002）；燕说她在アリーナ和星南一起看了今天的ライブ（0031），本话的对话地点没写明
- 世界线：亲爱度（藤田ことね）；制作人在制作的偶像：藤田ことね（0019「プロデューサーの出した課題」、0011）

## 发生了什么
ことね 拿下『舞道場』，正要回答制作人“偶像重要的东西”时，燕叫着「藤田！！」出现。燕说她和星南一起在アリーナ看了ライブ，星南哭了、来不了，要 ことね 在她离开前忍住眼泪。她说看了今天的ライブ明白了，收回前言：ことね 不需要斗争心，藤田ことね不是那种偶像——今天的 ことね 干劲高、没有斗争心也没有包袱，只是很开心，让人看着心情明亮、忍不住笑。她问 ことね 偶像是什么，ことね 说是「仕事」「天職」，当偶像是为了钱、粉丝和称赞，比赛只是手段。她又问对手是十王星南也没兴趣吗，ことね 说被星南认作宿命的对手是人生最开心的事、这个位置不让给任何人，但上了台就会忘掉一切、只看得见粉丝，让所有人开心、让对手也成为粉丝，就是她的胜利。燕说这就是 ことね 的胜负，「納得した」，说 ことね 也有她自己的斗争心——或者说是贪婪的欲望；ことね 在台上把所有感情都投向观众，倾注给粉丝的热量和对宿命对手一样多，和这样的偶像较量不可能不燃起来，她明白了星南的心情，说对手无可挑剔，将以挑战者的身份参加这次决斗。

## 行为模式
- 看了对方的实际表现、发现自己判断错了 → 直接说「前言を撤回する」，不找借口（0036、0037）
- 想弄清对方的立场 → 用「問おう」开头直截了当地发问，并追问最关键的一点（0044、0054～0056）
- 对方说出与自己不同的价值观 → 不否定（0054「文句などあるものか。」），听完说「納得した」，再用自己的语言重新概括（0069～0075）
- 遇到值得一战的对手 → 斗志高涨，并以挑战者自居（0076、0078、0079）
- 别人的私事（星南哭了）→ 简短如实转告（0033）
- 说话方式：硬派古风口吻（〜とも、〜ん、「此度」「臨もう」）（0031、0033、0079）
