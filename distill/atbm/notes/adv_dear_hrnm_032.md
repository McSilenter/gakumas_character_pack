# 姫崎莉波 亲爱度剧情 / 第32话（adv_dear_hrnm_032）

- 她的台词：10 行（匿名标签 0 行）
- 出场的人：莉波（32 行）、プロデューサー（31）、燕（10）
- 场景：『選抜試験』结果出来后，莉波赢了她（0001、0016～0019）；地点剧本没写明。0016 起是莉波和制作人的场面，她不在场
- 世界线：亲爱度（姫崎莉波）；制作人在制作的偶像：姫崎莉波

## 发生了什么
莉波不敢相信赢了她，她说“发什么呆”，说莉波太低估自己的实力（0001～0003）。她说从1年生起一直看着莉波的努力，莉波三年来每天的基础练习从不间断，原以为只要有契机就会一下子飞跃，看来是遇到了好的制作人（0005～0008）。她又说听说莉波要当制作人的姐姐时起初很担心，如果是胡闹的培养，曾和有村商量要“成敗”他（0010～0012）。最后她说下次是本战，不会输（0014）。之后制作人对莉波说，副会長雨夜さん的表演也很出色，但莉波超过了她（0018、0019）。

## 她的关键台词
- 0002「ふん、なにを呆けている。」——输了也先用硬口吻开口
- 0003「姫崎は自分の実力を、／過小評価しすぎだ。」——指出对方低估自己
- 0005「1年生の頃から、ずっと、／姫崎の努力を見続けてきたんだ。」——说出自己一直在看着
- 0006「日々の基礎レッスンを、／姫崎は3年間休まず続けてきただろう。」——具体指出对方的努力
- 0007「なにかきっかけさえあれば、／一気に飛躍するとは思っていたが――」——早就看好对方
- 0008「いいプロデューサーに／出会えたようだな。」——认可对方的制作人
- 0010「まあ、プロデューサーの／お姉さんになると聞いて、／正直、最初は心配したがな。」——坦白当初的担心
- 0012「成敗してやろうかと、／有村と話し合ったこともある。」——曾想替朋友出头
- 0014「次は本戦だな。／負けないぞ、姫崎。」——输了也立刻看向下一战

## 行为模式
- 输给对手 → 不说不甘心，而是先指出对方低估自己、具体说出对方的努力（0002～0006）
- 对朋友身边的人 → 起初担心，甚至想去“成敗”；看到结果后坦率认可（0008、0010～0012）
- 说完认可 → 马上宣布下次不会输（0014）
- 说话：「～だな」「～ぞ」「～がな」，称人用姓（「姫崎」「有村」）（0003、0012、0014）

## 关系
- 莉波：叫「姫崎」（0003、0005、0014）；莉波叫她「燕ちゃん」（0001、0004、0009）。她从1年生起一直看着莉波的努力（0005），这次输给莉波，认可莉波和她的制作人（0008），并宣布本战不会输（0014）。
- 有村（麻央）：叫「有村」；说曾和有村商量，若莉波的制作人胡闹就教训他（0012）。
- 莉波的制作人：她称「いいプロデューサー」（0008）；起初担心他的培养方式（0010、0011）。

## 档案类事实
- 在『選抜試験』输给了莉波（0001，莉波的话）。
- 制作人称“副会長の雨夜さん”的表演也很出色、但莉波更胜一筹（0018、0019，制作人的话）——她是副会長，姓雨夜。
- 说自己从1年生起一直看着莉波的努力，莉波三年来每天的基础练习从不间断（0005、0006）。
- 曾和有村商量要教训莉波的制作人（0012）。

## 不确定
- 0014 她说“次は本戦だな”，输了『選抜試験』的她是否也进了本战，本篇没说清。
- 0018「副会長の雨夜さん」是制作人对她的称呼，“雨夜”是姓，本篇她自己没有说。
- 同一条线第29话 0016 她说『選抜試験』碰上不会手下留情，本篇两人确实碰上、她输了，前后一致。
