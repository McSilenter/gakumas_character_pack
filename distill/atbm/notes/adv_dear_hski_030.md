# 花海咲季 亲爱度剧情 / 第30话（adv_dear_hski_030）

- 她的台词：43 行（含用匿名标签说的 0 行）；行号 0001、0002、0003、0009、0010、0011、0016、0017、0019、0021、0022、0024、0025、0026、0027、0029、0030、0031、0032、0034、0035、0036、0038、0040、0042、0043、0044、0045、0048、0049、0050、0052、0053、0054、0056、0057、0058、0060、0063、0065、0066、0068、0069。其中 0036 是介绍自己演唱咲季的曲子（演唱本身没有写出）。
- 出场的人：燕、咲季、プロデューサー、一同
- 场景：初星学園的练习室，同盟成立后的第一次特训。
- 世界线：亲爱度（花海咲季）；制作人在制作的偶像：花海咲季

## 发生了什么
她接受了咲季的挑战，咲季向制作人汇报。她对制作人说，自己只是因为信任咲季才答应，不打算被他制作；制作人说自己的制作对象一生只有咲季一个。她确认同盟条件：到第三次『選抜試験』之前，之后在最后一次决斗。接着她让咲季展示实力，说自己有可以教的东西，亲自唱了咲季的『Wildest Flower』。她讲，那首歌已经成了「私らしい」的版本：把细致的技术和粗犷并存，再摆出架势；咲季说出「楽曲に拠らない個性」，她认可。她用佑芽的表演举例，说「自分の魅力を知れ」，因为咲季已有自己的特质，要自己去找到。

## 她的关键台词
- 0003「私にとって人生最後の『選抜試験』！！／雨夜燕が相手になってやる！」——接受挑战，要作为对手奉陪。
- 0010「私はあくまで、咲季を信頼して／話に乗っただけだ。」——对制作人声明自己是信任咲季才加入的。
- 0011「貴様にプロデュースされてやるつもりは／ない。」——不打算被制作人制作。
- 0017「さすがは咲季のプロデューサー。／なかなかいかれているじゃないか。」——听到制作人只做咲季一人后，称他“有点疯”。
- 0022「同盟期間は、／3回目の『選抜試験』直前まで。」——确认同盟期间。
- 0024「最後の『選抜試験』で／決闘というわけだ。問題ない。」——最后一次『選抜試験』要决斗。
- 0027「ずっと気になっていた。／骨のあるやつが入ってきたとな。」——说出自己一直关注咲季。
- 0038「どうだ？　言っておくが、／完成度の低さは勘弁してくれ。／はじめて歌った曲なんだ。」——演唱咲季的曲子后，说明那是第一次唱。
- 0043「いまの『Wildest Flower』は、／『私らしい』ものになっていたはずだ。」——告诉咲季，现在的唱法是「私らしい」。
- 0044「丁寧な技術と荒々しさを同居させ、／見得を切る。」——概括自己的个性：精细的技术和粗犷并存，再见得を切る。
- 0049「私が伝えたかったのはまさしくそれだ。／いまの賀陽燐羽からでは、／決して学べないものでもある。」——说这是现在的燐羽学不到的东西。
- 0050「で、星南は……ひとに教えるのが／あまり上手くないからな。」——评论星南教学的缺点。
- 0066「ようは……誰にも真似できない、／花海咲季ならではのもの。」——指出重点是“只有咲季才有的东西”。
- 0069「――自分の魅力を知れ、花海咲季。」——给出建议：知道自己的魅力。

## 行为模式
- 同盟谈妥后 → 明确划线：信任咲季，不接受被制作人制作（0009～0011）。
- 对制作人的回击 → 听到“只做咲季一人”，反而称赞（0016、0017）。
- 指导 → 不讲抽象的话，直接唱给对方听，然后问咲季看没看过自己的ライブ，再让对方自己看出来（0036～0043）。
- 被说中 → 用「言語化が上手いな」确认（0048）。
- 被纠正名称（「うめチャレンジ」）→ 一时语塞，道歉后继续（0060、0063）。
- 话说到只能由对方自己找的东西时 → 停下，不继续教，只给出一句提示（0068、0069）。

## 关系
- 咲季：称“咲季”，一直用“貴様”；咲季称她「燕先輩」（咲季 0004）。
