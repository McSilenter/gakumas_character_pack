# 花海咲季 亲爱度剧情 / 第31话（adv_dear_hski_031）

- 她的台词：11 行（含用匿名标签说的 0 行）；行号 0004、0076、0079、0080、0082、0084、0085、0087、0088、0091、0092。其中 0004 是咲季转述她给的建议，由咲季回想中出现（回忆）。
- 出场的人：咲季、プロデューサー、燕
- 场景：前半（0001～0075）是咲季和制作人讨论自己的魅力；0076 起是第三次『選抜試験』的决斗前，咲季与燕见面。
- 世界线：亲爱度（花海咲季）；制作人在制作的偶像：花海咲季

## 发生了什么
咲季向制作人转述燕的建议（要认识自己的魅力），制作人建议重学自己的旧曲。决斗当天，她对咲季说“这一天终于来了”，咲季说同盟已在刚才解除，现在是决斗时。她说按理自己应该说「この期に及んで、交わす言葉などない」，但又觉得无趣；咲季说同样的心情，却还有话要说。她说即便败给自己咲季也会被选入本战，所以还有「次」；本战是绝对不能输的对手，因此“再也不能照顾你了”，咲季答应在决斗后一起做最后的收尾。她抱怨这很烦，但“有用”，说完让咲季全力以赴。

## 她的关键台词
- 0004「――自分の魅力を知れ、花海咲季。」——咲季回想中的建议（来自第30话末），回忆里出现。
- 0076「――ついにこの日が来たな。」——决斗那天的第一句话。
- 0079「はは……なあ、咲季。本当なら、／私はこう言うべきなんだ。」——说按理应该这样开口。
- 0080「この期に及んで、交わす言葉などない。／いざ勝負、と、な。」——她认为应该有的“决斗前的话”。
- 0082「ううむ……無粋だ。主義に反する。／貴様が最高の特訓相手だったせいだぞ。」——嫌自己无趣，把责任推给咲季是“最好的特训对手”。
- 0084「ここで私に敗れても、／貴様は本戦に選抜されるだろう。」——指出即使自己赢了，咲季也会被选入本战。
- 0085「なんとも無粋なことに、／我々には『次』がある。」——所以他们之间还有「次」。
- 0087「今度こそ『次』などない……／絶対に負けられない相手への挑戦だ。／もはや貴様を見てはやれん。」——本战才是不能输的对手，因此决斗后不能再照看她。
- 0091「あぁ、嫌だ嫌だ。厄介なことに、／どう考えても有用だ。やるしかない。」——对决斗后的最后收尾，嘴上嫌弃但接受。
- 0092「フン……お互い特訓の総仕上げだ。／全力で来い！　咲季！」——给咲季的最后一句：作为特训的总结，全力来。

## 行为模式
- 面对要决斗的对手 → 想按美学说“没有可说的话”，但被对方说“还有要说的”，就承认这话无趣、顺着对方（0079～0082）。
- 对后辈直说事实 → 先给出对方的位置（会被选上），再讲自己的立场（本战才是目标）（0084～0087）。
- 接受对自己有利的合作提议 → 用“嫌弃但有用”的口吻（0091）。
- 决斗开始 → 用号令式的语气叫名字（0092）。

## 关系
- 咲季：称“咲季”，称“貴様”；咲季称她「燕先輩」（咲季 0089、0093）。
- 彼此“最好的特训对手”（0082，咲季 0083「そっくりそのままお返しします」）。

## 档案类事实
- 同盟在第三次『選抜試験』前解除，两人在决斗中对战（咲季 0077、0078）。
- 她认为咲季即便输了也会被选入本战（0084）。

## 不确定
- 0004 的台词原话出自前一话末尾（030 0069）。这里是咲季转述，行号 0004 的说话人标为「燕」，算她的台词；是否是回忆插入，剧本没有明说。
- 0087「今度こそ『次』などない」的“今度”指本战，与 0085「我々には『次』がある」前后对应。
