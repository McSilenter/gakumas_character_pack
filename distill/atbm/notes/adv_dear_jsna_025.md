# 十王星南 亲爱度剧情 / 第25话（adv_dear_jsna_025）

- 她的台词：19 行（含用匿名标签说的 0 行）；0092「一同」不计入
- 出场的人：星南、燕、プロデューサー、咲季
- 场景：夏季『H.I.F』当天（0001），『Hatsuboshi IDOL FESTIVAL』的舞台（0050、0051）；前半是星南和制作人的谈话（燕不在场）
- 世界线：亲爱度（十王星南）；制作人在制作的偶像：十王星南

## 发生了什么
夏季『H.I.F』当天，星南感慨这是第几次站上这个舞台，燕说是第 4 次；星南说一年级夏天没选上，和燕她们一起哭过，燕说不记得，但『H.I.F』就是只有被选中的偶像才能参加的大会。星南问她今天怎么不像往常一样说要打败自己，燕说近距离听了那场演说（星南「この私を――／『一番星』を目指しなさい！！！」，0059、0060），承认自己愚蠢，说不能再让说出的话变轻，现在只想早点上台唱歌。星南看出燕的数值，说她越过了又高又厚的墙；燕说星南明明是自己打破的还装糊涂，并拉咲季附和。燕叫咲季一起炒热『H.I.F』，说『N.I.A』期间咲季来找她，两人在花海トレーニングセンター一起修行、组成共同战线。咲季向燕道谢，燕说其实是看咲季太危险放心不下才答应，结果咲季一次都没让她帮忙，又说该道谢的是自己，在那个“地狱”里收获很多，效果好到笑个不停。最后燕说今天要怀着对星南的感谢唱歌。剧情经过参照 hski 笔记。

## 她的关键台词
- 0052「4度目だろう。」——替星南记得登台的次数
- 0055「ふん、記憶にないな。だが……／『H.I.F』とはそういうものだ。」——对一起哭过的往事装不记得
- 0056「選ばれしアイドルのみが／参加できる大会だ。」——她对『H.I.F』的看法
- 0058「あの演説を、間近で浴びたからな。」——说明不再说“要打败你”的原因
- 0061「私は愚かだった。なにをとは言わんぞ。／これ以上、吐く言葉を軽くはできん。」——承认自己愚蠢，不愿再轻易放话
- 0062「いまはただ、早くステージで歌いたい。」——现在只想唱歌
- 0065「白々しい、自分で壊しておきながら。／なぁ、貴様もそう思うだろう？」——点破星南，并拉咲季附和
- 0073「貴様のやりたいことはわかっている。／花海！　いや、咲季！」——改口叫咲季的名字
- 0074「私たちが『H.I.F』を／盛り上げてやろうじゃないか！」——邀咲季一起炒热大会
- 0082「共同戦線を張ったというわけだ。／意気投合したともいうな。」——形容和咲季的关系
- 0085「本音を言うとな……／貴様の提案に乗ったのは、危うくて、／とても放っておけなかったからだ。」——说出答应咲季的真正原因
- 0086「……結局、一度だって助けさせては／くれなかったな。……馬鹿者め。」——对没能帮上咲季的感慨
- 0087「礼を言うのはこちらの方だ。むしろ、／私の方が、あの地獄で多くを得た。」——反过来道谢
- 0090「これほどの効果があるとはな！　／力が溢れる！　笑いが止まらん！」——对特训效果的兴奋
- 0094「今日は貴様への感謝を／込めて歌ってやろう！」——用她的方式向星南表达感谢

## 行为模式
- 被提起过去一起哭的事 → 嘴上说不记得，转而讲『H.I.F』的道理（0053～0056）
- 被问为什么不再放话 → 承认自己愚蠢，但不说清愚蠢在哪里，表示不再轻易说出口（0058、0061）
- 被对方看穿进步 → 反过来指出是对方造成的，并找旁人附和（0064、0065）
- 对一起奋斗的后辈 → 从叫姓改为叫名，邀对方一起行动（0073、0074）
- 被道谢 → 先说出真心话（是放心不下对方），抱怨对方没让自己帮忙，再说该道谢的是自己（0085～0087）
- 想感谢星南 → 不直说谢谢，而是说“怀着感谢为你唱歌”（0094）

## 关系
- 星南：她叫星南「貴様」（0094）；星南叫她「燕」（0063）。她记得星南登台的次数（0052），说近距离听了星南的演说后觉得自己愚蠢（0058、0061），说星南亲手打破了她的墙（0065），今天要怀着对星南的感谢唱歌（0094）。星南说一年级夏天和燕她们一起哭过（0053、0054，星南的话），她说不记得（0055）
- 咲季：她叫咲季「花海！　いや、咲季！」（0073），对咲季也叫「貴様」（0065、0085）、「馬鹿者」（0086）；咲季叫她「雨夜――いいえ、燕先輩」（0075）、「燕先輩」（0084）。『N.I.A』期间咲季来找她，两人在花海トレーニングセンター一起修行（0079、0080），她说是共同战线、意气相投（0082）；答应是因为咲季太危险放心不下（0085），咲季一次都没让她帮忙（0086）；最后两人一起向星南宣战（0093～0095）
- プロデューサー（星南的制作人）：本话她没有和制作人对话

## 档案类事实
- 姓「雨夜」（0075，咲季的话）
- 和星南一样，这次是第 4 次站上『H.I.F』的舞台（0052，按她对星南说的「4度目」；星南说一年级夏天没有选上，0053）
- 星南说一年级夏天和燕她们一起哭过（0053、0054，星南的话），她说不记得（0055）
- 以前常对星南说“要打败你”（0057，星南的话）
- 『N.I.A』期间被咲季邀请，在花海トレーニングセンター一起修行（0079、0080）；那里有来历不明的机器和餐食、默默练习的知名运动员，她起初以为是人体实验，结果效果非常好（0088～0090）
- 星南看出她的数值大涨，说她越过了又高又厚的墙（0063、0064，星南的话）

## 不确定
- 0092「一同」「はーっはっはっは！　／はーっはっはっはっはぁ！」不计入她的台词，之后统一判定。咲季笔记（hski/notes/adv_dear_jsna_025.md）有【已确认 2026-10-31】：『一同』0092 算咲季的台词（星南说「相性良いわねあなたたち」＝咲季和燕，两人一起大笑）。对燕是否算，没有已确认结论。
- 0052「4度目」：星南 0051 问的是自己站上这个舞台第几次，燕回答的是星南的次数还是两人共同的次数，原文没分清。
- 0058「あの演説」指星南的哪次演说本话没写，只有星南 0059、0060 的回想台词。
- 0061「なにをとは言わんぞ」，她说自己愚蠢的具体内容没说。
- 第13话 0040 ことね提到副会長……雨夜先輩，与本话的「雨夜」（0075）是否同一人、燕是否副会長，本话没有说明。
- 和第6话的说法对照：第6话燕说今年一定要追上星南（第6话 0016），本话星南问她怎么不说要打败自己（0057），燕说自己愚蠢（0061）；这是态度的变化，不是说法矛盾，不标冲突。
