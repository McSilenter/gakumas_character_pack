# 倉本千奈 亲爱度剧情 / 第22话（adv_dear_kcna_022）

- 她的台词：25 行（含用匿名标签说的 0 行）
- 出场的人：燕（25 行）、千奈（19）、莉波（9）、星南（6）、佑芽（3）、美鈴（2）、一同（1）
- 场景：千奈向「生徒会の皆さま」报告（0001），被点名的有莉波、她（雨夜先輩）、佑芽（花海さん）、美鈴（秦谷さん）、星南（0002、0003）；地点剧本没写明
- 世界线：亲爱度（倉本千奈）；制作人在制作的偶像：倉本千奈（0013、0014 千奈说竞选是制作人想出的『H.I.F』对策）

## 发生了什么
千奈宣布要竞选初星学园次期生徒会长，她沉吟不语，莉波问她是否反对（0004～0011）。她说正要决定，问千奈这是不是制作人的主意，千奈承认后她说那就反对，因为生徒会长必须真心为学园和学生着想（0012～0017）。但她马上说千奈不是会靠算计行动的人，要把制作人和千奈本人分开考虑，问千奈是不是出于自己的意志；千奈说是，也有觉悟，她便说没有理由反对，还提议全体生徒会成员支持千奈竞选（0018～0028）。星南说她对千奈太宠，她否认，说只是觉得1年生参选会很辛苦；星南指出上级生公开帮忙会被说成是被安排的，她承认露骨的支援反而有反效果（0029～0039）。千奈说只要不显眼的支援，她说这样就好，千奈也变得精明了（0044、0045）。她讲解选举流程，千奈连选举管理委员会是什么都不知道，她喘着气讲到千奈懂为止（0048～0056）。剧情经过参照 hmsz、hume 笔记。

## 她的关键台词

- 0012「それをこれから決める。――倉本。／生徒会選挙への立候補。」——不急着表态，先要确认
- 0013「プロデューサーの案ではないのか？」——首先怀疑是制作人的主意

- 0018「――と、言いたいところだが。」——把刚说的反对收回一半
- 0019「倉本は……／打算で動くような者ではない。」——对千奈为人的判断
- 0020「貴様のプロデューサーは論外だが、／本人の資質とは切り離して考えよう。」——对制作人很不客气，但不把账算到千奈头上
- 0023「倉本。貴様は自分自身の意志で、／『生徒会長になる』と言っているのか？」——她真正要确认的问题
- 0028「倉本の選挙活動、生徒会メンバー全員で／サポートをするというのはどうだ！」——同意之后马上提出全员支援

- 0035「……違うと言っている。」——被夸温柔时否认
- 0045「それでいい。／ちゃっかりしてきたじゃないか。」——认可千奈的精明
- 0054「貴様が理解できるまでしてやるぞ！　／生徒会選挙の説明をな！」——被问到基础问题，决定讲到懂为止

## 行为模式
- 遇到她认为涉及原则的事 → 先沉吟，问清是谁的主意，按原则说反对（0010～0017）
- 但会把人和她不认可的背后推手分开看，再当面确认本人的意志；确认了就立刻转为支持，甚至提出比别人更大的帮忙（0018～0028）
- 被说“宠后辈”“温柔” → 否认，用“只是觉得会很辛苦”来解释（0032、0033、0035）
- 被指出做法会有反效果 → 咂嘴，但接受（0039）
- 后辈连基础都不懂 → 先嫌“从这里开始吗”，然后不厌其烦讲到对方懂，讲完喘气（0053～0055）
- 说话：叫人「貴様」，～だ～だな～ぞ「論外だ」等硬派口吻（0017、0020、0033、0054）

## 关系
- 千奈：叫「倉本」（0012、0019、0023、0055），也叫「貴様」（0020、0023、0054）；千奈叫她「雨夜先輩」（0002、0040、0052、0056）。她说千奈不是靠算计行动的人（0019），确认了千奈的意志后支持她竞选（0027、0028）；星南说她太宠千奈、只是嘴上严（0030、0031），莉波说她是温柔的前辈（0034），她都否认（0032、0035）。
- 千奈的制作人：称「プロデューサー」（0013）、「貴様のプロデューサー」，说他「論外」（0020）。
- 星南：本篇她没有称呼星南；星南叫她「燕」（0030）。星南驳回了她全员支援的提议，她接受了（0029～0039）。
- 莉波：本篇她没有称呼莉波；莉波叫她「燕ちゃん」（0011、0064），替她向千奈道歉说她说话绕弯（0021）。

## 档案类事实
- 她在生徒会（千奈向「生徒会の皆さま」报告时点名了她，0001、0002）。
- 她认为初星学园生徒会长必须是真心为学园和学生着想的人（0015、0016）。
- 她对生徒会选举流程很熟：次日选举管理委员会成立并公布投票日，接着是给预定参选者的说明会（0049、0050）。
- 她说1年生参选会很辛苦（0032、0033），千奈是1年生。
