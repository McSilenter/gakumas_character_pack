# 紫雲清夏 亲爱度剧情 / 第32话（adv_dear_ssmk_032）

- 她的台词：13 行（含用匿名标签说的 0 行）
- 出场的人：清夏、リーリヤ、燕、プロデューサー、旁白、ファンA～D
- 场景：『選抜試験』结果出来、『REVERSI』（清夏和リーリヤ）赢了她、确定『H.I.F』本战出场之时（0001～0008）；她在 0025 之后不再出场（之后是『REVERSI』2ndライブ）；地点没写
- 世界线：亲爱度（紫雲清夏）；制作人在制作的偶像：紫雲清夏（0007～0008 制作人祝贺清夏和リーリヤ本战出场）

## 发生了什么
她在『選抜試験』上输给了清夏和リーリヤ的『REVERSI』，不敢相信自己会输给星南以外的人（0001～0004）。清夏得意地问她怎么样，她认输，说没想到清夏强化的不是ボーカル或ビジュアル而是舞蹈，听清夏说想成为用舞蹈给人勇气的偶像，说清夏判若两人（0013～0017）。她对リーリヤ说自己小看了她、擅自判断她没有和清夏并肩的才能，但今天她确实在发光（0018～0020）。她承认『REVERSI』的实力，同时宣布『H.I.F』优胜的会是自己，说期待再战（0022～0025）。制作人说她到本战前一定会进一步成长（制作人 0026）。

- 0003「……馬鹿な。」——输了之后的第一反应
- 0004「この私が、星南以外に負けるだと！？」——没想到会输给星南以外的人
- 0012「……紫雲、葛城。」——沉默之后郑重叫两人
- 0014「……私の負けだ、紫雲。」——干脆认输
- 0015「まさかボーカルやビジュアルではなく、／ダンスを強化してくるとはな。」——分析对手的策略
- 0017「……見違えたな。」——对清夏变化的评价
- 0018「そして、葛城。／私はお前を見くびっていた。」——承认判断错误
- 0019「紫雲の隣に並び立つほどの才覚はない。／勝手にそう判断していたが……」——说出原来的看法
- 0020「今日のお前は、確かに光り輝いていた。」——认可リーリヤ
- 0022「……フッ、認めよう。／お前たち『REVERSI』の実力を。」——认可对手
- 0023「その上で、宣言する。／『H.I.F』で優勝するのは、／この私だ。」——认输后立刻宣战
- 0025「再戦を楽しみにしている。」——期待再战

## 行为模式
- 意外输掉 → 先震惊、不敢相信（0003、0004），沉默一阵后郑重认输（0011～0014）
- 认输时 → 具体指出对手赢在哪里（0015），对对手的变化给出评价（0017）
- 自己看错了人 → 当面承认小看了对方、说出原先的判断，再给出肯定（0018～0020）
- 认可对手之后 → 紧接着宣布本战会赢的是自己，期待再战（0022～0025）

## 关系
- 清夏：叫「紫雲」（0012、0014、0019）；清夏叫她「副会長」（清夏 0013），用敬语（清夏 0024）。认输，说清夏判若两人（0014、0017）；第31话制作人说清夏夏季『選抜試験』输给了她，本篇是清夏的复仇（第31话 0090）
- リーリヤ：叫「葛城」（0012、0018），称「お前」（0018、0020）。承认曾小看她（0018、0019），说今天的她确实在发光（0020）；リーリヤ回答是清夏引导了自己（リーリヤ 0021）
- 星南：叫「星南」（0004）；本以为只会输给星南（0004）。制作人提到本战还有会长、现『一番星』十王星南（制作人 0027）

## 档案类事实
- 在『選抜試験』上输给『REVERSI』（0014、0022）
- 她认为自己只会输给星南（0004）
- 宣布『H.I.F』优胜的会是自己（0023）
- 被清夏称为「副会長」（清夏 0013）；第31话制作人介绍她是学园No.2、生徒会副会长（第31话 0087）

## 不确定
- 0004 是否意味着她以前只输给过星南，本篇没明说，只能看出她不认为会输给星南以外的人。
- 她是否进入『H.I.F』本战（0023 宣布要优胜、制作人 0026 说她本战前会成长），本篇没写明她的出场资格。
