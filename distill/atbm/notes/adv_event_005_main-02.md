# 活动 005 / main-02 第2话（adv_event_005_main-02）

- 她的台词：8 行（含用匿名标签说的 0 行）
- 出场的人：星南、莉波、燕、千奈、学園長（只在 0027～0031）
- 场景：生徒会成员在去招募新生的路上聊起招募对象，后到千奈面前
- 世界线：活动 005；制作人在制作的偶像：看不出

## 发生了什么
星南说第二位新成员已有人选，一位是ことね，燕说认识她：以前ことね想未经许可打工，被他提醒后来找他商量过中等部学生打工的事。星南因他没告诉自己而不满，他说这种事不能随便对别人说。他听到ことね是『一番星』的后继者候补时很意外。后来星南向千奈提出“成为我的人”，他吐槽“怎么可能听得懂”。

## 她的关键台词
- 0007「……藤田か。」——听到ことね的名字，就认出是认识的人
- 0009「中等部の生徒がアルバイトをする方法に／ついて、以前相談を受けたことがある。」——说明认识ことね的原因
- 0011「なにを怒っているんだ……」——星南质问为什么没告知，他不懂她为何生气
- 0012「無許可で働こうとしていたあいつを／注意した流れで相談されたんだよ。」——解释是提醒她之后她才来商量的
- 0013「軽々しく人に話すようなことじゃない。」——认为这种商量不该随便告诉别人
- 0015「だから私が藤田について言えるのは、／感心な働き者だというくらいだな。」——只给出一个评价，不泄露更多
- 0016「しかし……成績は悪かったはずだが。／あいつが『一番星』の後継者候補……？」——对ことね被选为后继者候补感到疑惑
- 0046「伝わるわけないだろうが。」——对星南的含糊邀请直接吐槽

## 行为模式
- 被追问曾保守的事 → 先反问对方为何生气，再说明保密的理由（0011～0013）
- 评价别人 → 不随便透露细节，只说有根据的一句（“勤奋”）（0015）
- 对他人被选中的理由有疑问 → 直接拿事实（成绩）质疑（0016）
- 星南说话过于含糊 → 立刻吐槽（0046）

## 关系
- 星南：不直接叫名字（本篇没有直接称呼）；对她说话直率，不留情面（0011、0046）。
- ことね：叫「藤田」（0007、0015）；说她“あいつ”（0012、0016）；对她印象是“感心な働き者”但成绩不好。
- 莉波：本篇没有直接对话。

## 档案类事实
- 与藤田ことね有过交流：中等部生徒打工的相谈，发生在提醒她无许可打工之后（0009、0012）。
- 判断ことね“成绩应该不太好”（0016，“はずだが”，是推测语气）。

## 不确定
- 0009「中等部の生徒」与星南说的“1年1组”，本篇没有说明ことね当时处于中等部还是高中部，剧本里的时间点不明。
- 0016 的『一番星』指星南的称号，【译文】译作“启明星”。
