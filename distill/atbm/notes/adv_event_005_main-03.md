# 活动 005 / main-03 第3话（adv_event_005_main-03）

## 发生了什么
燕对星南的说明太少表示无语，认为千奈根本没明白制作的事。星南说要从原『SyngUp!』的成员里选，他同意只凭实力的话是当然的选择，但对她们有不好的印象，两人为此有对话。他以为会选手毬，又提到燐羽，星南选了美鈴，他觉得美鈴给人的印象比较朴素。美鈴与星南对话时，他吐槽星南说明太差、太抽象。剧情经过参照 hmsz 笔记。

- 0004「プロデュースの件、倉本にはまったく／伝わっていないんじゃないか？」——指出千奈根本没懂
- 0009「まったく……／目星くらいは付けているのだろうな？」——催星南说出下一个人选
- 0014「……そうきたか。」——听到要选原『SyngUp!』成员的反应
- 0015「1年生の中から実力だけで選ぶなら、／当然の選択だろうな。」——承认从实力看这个选择是对的
- 0016「実力だけで選ぶなら。」——强调"只凭实力的话"这个条件
- 0018「いまさら説明の必要があるか？」——星南问他有什么话时，不想再说
- 0024「それほどか？」——对星南对三人的评价提出质疑
- 0028「やはり、月村手毬か？　中等部ナンバー／ワンアイドルという触れ込みの。」——推测星南会选手毬
- 0033「あの『燐羽様』には、根強い固定ファン／が付いているようだが……ダメだろう。」——提出燐羽，又自己否定
- 0038「秦谷美鈴か……他のふたりと比べると、／地味な印象だが……」——对星南的选择表示意外
- 0056「下手すぎる……抽象的すぎる……／説明が……」——看到星南对美鈴的说明，小声评价

## 行为模式
- 对星南的做法 → 点出问题（说明不足）但说话用疑问句，而不是直接命令（0003、0004）
- 不完全赞同的选择 → 先承认条件成立，再用重复的短句强调"只凭实力的话"这个前提（0015、0016）
- 想把话说清楚时 → 不再解释，反问星南"还需要解释吗"（0018）
- 自己猜人选 → 按名气推测，被星南否定后换第二个，并自己判断不行（0028、0033）
- 看到星南重复犯同样的毛病 → 低声吐槽（0056）

## 关系
- 星南：不直接叫名字；对她的计划逐条质疑，但接受她的选择（0015、0038）。
- 莉波：本篇没有直接对话。
- 手毬、燐羽、美鈴：叫「月村手毬」（0028）、「燐羽様」（0033，引用粉丝的叫法）、「秦谷美鈴」（0038）。
