# 活动 005 / main-04 第4话（adv_event_005_main-04）

- 她的台词：10 行（含用匿名标签说的 0 行）
- 出场的人：星南、咲季、燕、莉波；清夏、リーリヤ、ことね、手毬各一句
- 场景：初星学园，生徒会三人去看一年级的教室，在校内遇到一年级生；具体地点剧本没写
- 世界线：活动 005；制作人在制作的偶像：看不出

## 发生了什么
星南说去看一年级教室时，燕问目标是谁，听到她要用"眼"看，嘲讽她"又开始了"，让她来看自己，被她一口回绝，他只能"什……"。星南与咲季对话后，他说不知道她们聊了什么，但觉得咲季有潜力，建议招募，被拒后笑了一声。莉波说咲季像星南，他补充"说话方式、喜欢说大话，和以前的你一模一样"。剧情经过参照 ttmr、hski 笔记。

## 她的关键台词
- 0004「目当ては？」——问星南招募的目标
- 0009「……また始まった。貴様に本当に／そんな特技があるのなら、」——对星南自称有"眼"的反应
- 0010「私を視るといい。プロデュースしたくて／たまらなくなるんじゃないか？」——挑衅星南
- 0012「なっ……！？」——被星南一口回绝
- 0019「……ふん。／わかり切ったことを言うな、馬鹿者。」——被星南说成"对手"，没有否认，只骂她说得理所当然
- 0027「さっぱりわからんな。／未熟者の集まりにしか見えん。」——对一年级生的评价
- 0065「花海となにを話してきたのか／知らんが――」——不问具体内容，先表态
- 0066「あいつは見所があると思うぞ。／スカウトしたらどうだ？」——建议招募咲季
- 0069「……フッ。」——被星南说"她是敌人"之后的笑
- 0072「言葉の選び方。大きな口を叩くところ。／昔の貴様にそっくりだろうが。」——指出咲季与星南相似的地方

## 行为模式
- 星南夸耀自己的能力 → 先嘲讽，再用"看我"反过来挑战（0009、0010）
- 被星南说成"对手" → 不否认，用"别说得那么理所当然"回应（0019）
- 对别人有判断时 → 直接说"不知道你们聊了什么，但我认为有潜力"，并给出具体建议（0065、0066）
- 星南拒绝建议，说是"敌人" → 笑而不辩（0069）
- 对星南的相似处 → 用具体的例子（说话方式、爱说大话）（0072）

## 关系
- 星南：叫她「貴様」（0009、0072）；骂她「馬鹿者」（0019）；承认她们是对手关系。
- 莉波：叫「姫崎」（见 main-01，本篇没有叫）；与莉波在评价咲季上一起发言（0072、0073）。
- 咲季：叫「花海」（0065）、「あいつ」（0066）；认为她"有潜力"。

## 档案类事实
- 说一年级生"看起来只是一群不成熟的人"（0027）。
