# 活动 005 / main-05 第5话（adv_event_005_main-05）

- 她的台词：13 行（含用匿名标签说的 0 行）
- 出场的人：星南、佑芽、燕、莉波
- 场景：初星学园的走廊，星南为夏天的H.I.F物色新生
- 世界线：活动 005；制作人在制作的偶像：看不出

## 发生了什么
星南为招募烦恼，燕问她是不是想让自己培养的偶像赶上夏天的H.I.F。星南发现佑芽后在走廊冲出去，他训斥她在走廊跑。他后来赶上，听到佑芽是补欠合格，劝星南别冲动，因为补欠意味着现在比那些人还差。看到佑芽在裙子下倒立，他骂她，星南决定后，他回答"随你"。剧情经过参照 hume 笔记。

## 她的关键台词
- 0002「なにを悩んでいる？　／今年の1年生は素晴らしいんだろう？」——星南说困扰时，拿她自己的话反问
- 0005「夏のH.I.Fで活躍させたいなどと／考えているのではあるまいな？」——猜出星南的真正意图
- 0008「夏に間に合いそうなのは、それこそ／花海、月村、秦谷くらいだろう。」——列出能赶上夏天的人
- 0010「わかったわかった。しかし藤田の／勧誘は難航している、と。」——补上ことね，然后点出招募难航
- 0013「そうそういてたまるか、そんなもの。」——不信有这样的人
- 0016「ろ、廊下を走るな馬鹿者！　生徒会長／が直々に校則を破ってどうする！！」——星南突然跑起来，立刻训斥
- 0041「お、おい……いまの発言を聞いて／まだ迷っているのか？」——听到补欠，不相信星南还在犹豫
- 0043「現時点でやつら以下だということだぞ！／早まるな！　考え直せ！」——劝阻，理由是现在比其他人差
- 0055「スカートで逆立ちをするな馬鹿者！」——佑芽演示倒立时的训斥
- 0065「……好きにしろ。」——放弃劝阻

## 行为模式
- 听到星南说烦恼 → 先用对方自己的话反问，再推测真正的意图（0002、0004、0005）
- 星南违反校规 → 立刻指责"会长亲自违规"（0016）
- 星南想做出冲动的决定 → 用事实（补欠 = 现在比别人差）劝，多次叫她"考え直せ"（0041～0043）
- 对后辈的不规矩 → 直接训斥（0055）
- 劝不动 → 一句"随你"（0065）

## 关系
- 星南：叫她「貴様」不出现在本篇；用「馬鹿者」骂她（0016）；星南最后问他有无意见（0063）。
- 莉波：本篇莉波叫他「燕ちゃん」（0017）。
- 佑芽：本篇没有直接对话，训斥她的行为（0055）。

## 档案类事实

- 他自己也跟着星南在走廊跑（莉波说"燕ちゃんも"，0017）。
