# 活动 013 3年级1班的修学旅行 / main-02 第2话（adv_event_013_main-02）

- 她的台词：14 行（含用匿名标签说的 0 行）：0005、0013、0014、0017、0018、0019、0021、0023、0038、0044、0057、0066、0068、0069
- 出场的人：莉波、麻央、星南、燕、旅行客
- 场景：修学旅行第一天，京都；壬生寺、历史资料馆、茶道体验，之后遇雨。
- 世界线：活动 013；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
到京都后，燕走在最前面催大家，被星南说“比平时更兴奋”。到壬生寺她说一直想拜观却没有机会，聊到借给麻央的新选组小说，她说土方歳三的生平，麻央说喜欢沖田総司，她不退让。参观后她问麻央感想。茶道上她说茶室像是她们的舞台。下雨时她看着麻央去买伞失败，说“早就说过”，让麻央擦头发，免得感冒。
剧情经过无其他笔记可参照。

## 她的关键台词
- 0005「みんな、なにをしている、／早く行くぞ。」——到京都后催促大家。
- 0013「俄然、楽しみだな。／拝観したいとは思っていたのだが、」——对壬生寺的期待。
- 0014「なかなか、機会がなくてな。」——一直想来，却没有机会。
- 0018「先人たちが生きたのと、／同じ場所の空気を吸って――」——说明来此地的意义：吸同一处的空气。
- 0019「鬼の副長、土方歳三の苛烈な／生き様に思いを馳せるのだ。」——对土方歳三的敬意。
- 0021「いや、沖田総司もカッコイイが、／やはり土方歳三が……」——麻央说喜欢沖田総司，她承认其魅力但仍偏向土方。
- 0023「嗚呼、素晴らしかったな。／なあ、有村？」——参观后感叹，并向麻央征求同感。
- 0038「やるな、有村。」——麻央用英语带路后的称赞，称「有村」。
- 0044「茶室は、私たちにとっての／ステージのようなものだな。」——对星南的话做出自己的比喻。
- 0057「けっこう、勢いがあるな。」——下雨时观察雨势。
- 0066「有村ーーーーーーーーっ！」——麻央跑出去后大喊。
- 0068「……まったく。／言わんことではない。」——麻央失败后，说“早就说了”。
- 0069「ほら、さっさと髪を拭け。／風邪をひくぞ。」——嘴上严厉，行动上照顾麻央。

## 行为模式
- 有期待的事 → 走在前面催大家，兴奋得与平时不同（0005，星南 0006）。
- 谈兴趣话题 → 滔滔而谈；对方不同意时承认对方的好，但仍坚持自己的偏好（0019、0021）。
- 看到同伴的举动 → 简短地夸（0038）。
- 同伴失败 → 先喊名字，然后嫌弃一句，再给出实际的照顾（0066-0069）。

## 关系
- 麻央：叫「有村」（0023、0038、0066、0069）；麻央借她的小说，也谈到她的喜好（麻央 0015）。
- 莉波：这一篇没有直接叫；莉波说“あんな燕ちゃん、珍しい”（莉波 0007）。
- 星南：附和星南关于茶道的话（0044）。

## 档案类事实
- 一直想拜观壬生寺，没有机会（0013、0014）。
- 喜欢土方歳三，借出过新选组小说给麻央（0019；麻央 0015）。
- 对茶道的看法：茶室是她们的舞台（0044）。

## 不确定
- 0023「嗚呼、素晴らしかったな。」的参观对象是壬生寺还是历史资料馆，下一行 0026 莉波才提资料馆，所以 0023 多半指壬生寺，但剧本没有明说。
