# 活动 013 3年级1班的修学旅行 / main-03 第3话（adv_event_013_main-03）

- 她的台词：8 行（含用匿名标签说的 0 行）：0003、0007、0011、0014、0016、0017、0074、0075
- 出场的人：莉波、星南、燕、麻央
- 场景：修学旅行第一天晚上，旅馆房间；中间（0023-0073）是莉波1年级时被星南招募的回忆，燕不在。
- 世界线：活动 013；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
晚饭后，燕找麻央打乒乓球，看到莉波拿出梅干、海苔あられ、鱿鱼丝说“这是点心吗”。星南说去做生徒会工作，燕劝她旅行中别工作，又对莉波说也在新干线上做生徒会工作，应该多给1年级学生分担，因为莉波也处在重要的时期。回忆之后，燕说莉波被招募进生徒会是会长的慧眼，她总能指出自己和星南没发现的地方。
剧情经过无其他笔记可参照。

## 她的关键台词
- 0003「有村、向こうに卓球台があったぞ。／勝負するか？」——看见卓球台，立刻想到和麻央比试。
- 0007「梅干し、海苔あられ、スルメイカ……／お菓子……なのか？」——对莉波拿出的“点心”表示疑惑。
- 0011「旅先だぞ。たまには、仕事のことは／忘れたらどうだ？」——劝星南旅行中别工作。
- 0014「姫崎も新幹線で生徒会の／仕事をしていただろう。」——提到莉波在新干线上的生徒会工作。
- 0016「1年生にも、もっと仕事を／割り振ったほうがいいと思うぞ。」——主张把工作更多地交给1年级学生。
- 0017「姫崎も今が大事な時期だろう。」——说明理由：莉波现在是重要时期。
- 0074「姫崎のスカウトは、／会長の慧眼だったな。」——称赞星南招募了莉波。
- 0075「私たちでは気付かないような／ところをいつも指摘してくれる。」——说明莉波的价值：能指出自己和星南看不到的地方。

## 行为模式
- 看到游戏设施 → 马上邀麻央比试（0003）。
- 不认识的东西 → 直接问“这是点心吗”（0007）。
- 同伴过度工作 → 直接劝对方休息（0011），并替另一人（莉波）着想，提议多分工（0014-0017）。
- 评价别人 → 举具体的作用来夸（0074、0075）。

## 关系
- 麻央：叫「有村」（0003）。
- 星南：对她用平语并劝她，叫「会長」（0074）；也说“私たち”把自己与星南并列（0075）。
- 莉波：叫「姫崎」（0014、0017、0074）。

## 档案类事实
- 乒乓球：旅馆里发现卓球台，想比试（0003）。
