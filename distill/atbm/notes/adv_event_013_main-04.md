# 活动 013 3年级1班的修学旅行 / main-04 第4话（adv_event_013_main-04）

- 她的台词：13 行（含用匿名标签说的 0 行）。其中 0001～0003 是她讲的怪谈（0002 是怪谈里声音的台词）
- 出场的人：燕、麻央、莉波、星南（学園長 0029 只在麻央的回忆里出现；一同 0028 不计）
- 场景：修学旅行夜晚的宿舍，在等会长（星南）电话打完回来之前，大家轮流讲怪谈
- 世界线：活动 013；制作人在制作的偶像：看不出

## 发生了什么
燕先讲了个宿舍走廊上传来“炸猪排、想吃油脂”的怨念声的怪谈，吓到麻央，之后依次点名莉波和麻央讲。她说修学旅行之夜就该讲怪谈，是为了打发等会长的时间。麻央说起去年『H.I.F』的回忆时，她安静听着（0065 沉默）。星南回来问在聊什么时，她抢着说是在说要在『H.I.F』击败星南。

## 她的关键台词
- 0005「なんだ有村、そんなに怖かったか？」——对被吓到的麻央直接发问，称「有村」
- 0010「修学旅行の夜といえば、／怪談に決まっている。」——断言修学旅行的夜晚就是怪谈
- 0012「会長が戻ってくるまでの暇潰しだ。／怖い話のひとつくらいあるだろう？」——说明讲怪谈是为了等会长，并催促莉波
- 0020「な、なかなかシュールな／怪談話だったな……」——对莉波的SSD怪谈的评价，有些被打败
- 0021「……会長はまだ、か。」——挂心星南
- 0026「……うん？」——听到麻央说起「あるにはある」时留意
- 0070「ふっ、『H.I.F』で、必ず貴様を／仕留めるという話をしていたのだ。」——替麻央和莉波圆场，把话题说成要在『H.I.F』击败星南

## 行为模式
- 想营造气氛 → 用断言（～に決まっている）强行推进游戏（0010）
- 等待星南回来的时间 → 看似打发时间，实际会留意“会长还没回来”（0012、0021）
- 面对对方的怪谈出乎意料 → 先愣了一下，然后点评为“超现实”（0020）
- 麻央的回忆让场面尴尬、莉波答不上来时 → 抢先用「貴様」「仕留める」把话题改成宣战（0070）

## 关系
- 星南：叫她「会長」（0012、0021）；对她说话用「貴様」（0070）；0070 是在对她放话要击败她
- 麻央：叫她「有村」（0005、0023）
- 莉波：叫她「姫崎」（0008）
