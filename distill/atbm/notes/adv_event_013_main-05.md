# 活动 013 3年级1班的修学旅行 / main-05 第5话（adv_event_013_main-05）

- 她的台词：17 行（含用匿名标签说的 0 行）
- 出场的人：燕、莉波、麻央、星南（千奈 0002～0005、美鈴 0008 只在开头的联络场面；一同 0080 不计）
- 场景：修学旅行中，先在店里（燕在星南旁边），之后在供奉演艺之神的神社的绘马处
- 世界线：活动 013；制作人在制作的偶像：看不出（星南在 0024 说自己正在培育学生会一年级）

## 发生了什么
在店里，燕看出星南没有认真选伴手礼，问她有什么心事，星南说是培育学生会一年级的难处。燕说那是她不擅长的事，也说她自负，又提醒她下次『H.I.F』必须以完美状态应战，还说她的对手不止燕一个。到了神社，莉波和麻央宣言要追上星南后，燕说自己的愿望是星南在下一届『H.I.F』前惊人成长，因为不击败全盛时期的她就毫无意义。剧情经过参照 hmsz 笔记。

## 她的关键台词
- 0018「どうした。土産はいいのか？」——注意到星南没在选东西
- 0020「……ふん。気もそぞろだな。／悩み事か？」——一眼看出星南心不在焉
- 0023「……あたりまえだ。／何年の付き合いだと思っている。」——被问“你看得出啊”时，用“多少年的交情”回应
- 0027「当然だろう。／似合わぬことをするからだ。」——对星南说培育很难的回答：谁让你做不适合你的事
- 0029「いくら貴様といえど、／自惚れがすぎるぞ。」——批评星南一边活动一边照顾别人是自负
- 0036「他人の面倒にかまけるのは勝手だが、／貴様自身はどうなんだ？」——允许她管别人，但追问她自己的状态
- 0037「次の『H.I.F』、完璧な貴様と／戦えるんだろうな？」——要求在『H.I.F』与完美状态的星南对战
- 0042「貴様のライバルは、／私だけではないぞ。」——提醒星南的对手不止她一个
- 0072「次の『H.I.F』までに、十王星南が／圧倒的に成長していることだ。」——燕许的愿
- 0074「最高の状態の貴様を倒さなければ、／なんの意味もないからな。」——说明愿望的理由

## 行为模式
- 看出星南状态不对 → 先用问句点出（0018、0020），被承认后只用“多少年的交情”回答（0023）
- 星南吐露烦恼 → 先不安慰，直接说“你不适合”，批评自负（0027～0029）
- 对星南的关心 → 转成对「H.I.F」的要求，不直接说担心（0036、0037）
- 星南保证后 → 说「ふん、ならば構わん」然后补一句“对手不止我”（0040～0042）
- 听到莉波、麻央的宣言 → 评价莉波“变得能说会道了”（0070），再说出自己的愿望（0071、0072）

## 关系
- 星南：叫她「貴様」（0029、0037、0042）、「十王星南」（0072）；认识很多年（0023）；星南叫她「燕」（0022）
- 莉波：叫她「姫崎」（0070）
