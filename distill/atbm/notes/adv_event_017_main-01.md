# 活动 017 / 第1话（adv_event_017_main-01）

- 她的台词：9 行（含用匿名标签说的 0 行）
- 出场的人：莉波、星南、燕、麻央（ダンストレーナー 0015）
- 场景：舞蹈课的场所，麻央在练习；莉波向大家提出拍3年级PV的请求
- 世界线：活动 017；制作人在制作的偶像：看不出

## 发生了什么
看到麻央用功练习，燕说是为夏天的『H.I.F』气合十足，并说想引出会长（星南）的全力，竞争对手越多越好，并告诉莉波她也是对手之一。莉波提出拍PV的请求，燕觉得意外，又质疑日常有没有需求；被问到是否协助时，她先说“偶像常在战场，没有日常”，被麻央追问后说是因为受过莉波照顾，所以要给不成熟的新生一个教训：偶像的日常都是舞台。

## 她的关键台词
- 0018「ふっ、夏の『H.I.F』に向けて、／気合いが入っているな。」——看到麻央用功，联想到夏天的『H.I.F』
- 0020「会長の本気を引き出すには、／ライバルは多ければ多いほどいい。」——对竞争对手增加的看法
- 0021「姫崎。お前も、ライバルのひとりだぞ。」——对莉波说她也是竞争对手
- 0025「珍しいな。姫崎が頼みごととは。」——对莉波的请求感到稀奇
- 0036「レッスン風景ならわかるが、私たちの／日常など、そんなに需要があるか？」——怀疑日常的需求
- 0042「アイドルは常在戦場――／ゆえに日常など存在しない。」——自己的立场：偶像没有日常
- 0044「早とちりするな、有村。」——被麻央问“不协助吗”时的回应
- 0045「普段から世話になっている、／姫崎の頼みごとだからな。」——协助的理由：平时承蒙莉波照顾
- 0046「覚悟の甘い新入生に――／アイドルは日常のすべてが／ステージなのだと教えてやろう。」——协助的目的：教新生什么是偶像

## 行为模式
- 看到别人用功 → 想到夏天的『H.I.F』，高兴（莉波 0019 说她“嬉しそう”）（0018、0020）
- 对别人的请求 → 先质疑需求和立场，然后因私人关系答应，并给出自己的理由（0036、0042、0045、0046）
- 被误会 → 立刻纠正（0044）

## 关系
- 莉波：叫「姫崎」（0021、0025、0045）；莉波叫她「燕ちゃん」；承认她是“平时照顾我的人”
- 麻央：叫「有村」（0044）
- 星南：称「会長」（0020）；希望引出她的“本气”；星南认同燕的话（星南 0048）

## 档案类事实
- 燕在为夏天的『H.I.F』气合十足（0018，说的是麻央，也是自己的立场）
- 燕认为偶像的日常全是舞台（0046）
- 燕说平时受姫崎照顾（0045）
