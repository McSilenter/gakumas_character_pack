# 活动 017 / 第3话（adv_event_017_main-03）

- 她的台词：6 行（含用匿名标签说的 0 行）
- 出场的人：星南、麻央、莉波、ことね、燕
- 场景：休息日；偶像周边店，随后是ことね打工的汉堡店。
- 世界线：活动 017；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
燕和星南、麻央、莉波一起在休息日出行。她说三年级后日程难协调，批评星南在去游乐园前买太多周边，并说自己收集了星南的所有种类ブロマイド。午饭时听麻央推荐章鱼烧店，之后一行去了ことね打工的汉堡店。吃饭时她指出星南嘴角沾了酱汁，最后说这段时间是难得的青春体验。

## 她的关键台词
- 0006「3年生になると、スケジュールを／合わせるのも難しいからな。」——解释大家很久没聚的原因。
- 0013「あとで遊園地に行くのに、／買いすぎだ、馬鹿者。」——对星南买太多周边直接责备，用「馬鹿者」。
- 0017「ふっ、無論、私は全種類、／集めているがな。」——自己却收集了星南所有种类的ブロマイド。
- 0020「ふむ。有村お墨付きの粉物か。／それなら間違いないな。」——听麻央推荐章鱼烧店后的评价。
- 0051「口元にソースが付いてるぞ。」——提醒星南嘴角沾了酱汁。
- 0068「……そうだな。この時間は、／得難い、貴重な青春の経験だ。」——接星南关于时间所剩不多的话，说现在是难得的经验。

## 行为模式
- 同伴买太多 → 用「馬鹿者」责备，随后暴露自己收集了全部（0013、0017）
- 麻央推荐店 → 认可对方的口碑再决定（0020）
- 看到同伴失态 → 不调侃，直接说明（0051）
- 星南说起时间有限 → 用「そうだな」赞同并认为这是珍贵的经验（0068）

## 关系
- 星南：本篇里星南没有叫她的名字；她对星南说话直接，用「馬鹿者」（0013）；收集星南的ブロマイド（0017）。
- 麻央：叫她「有村」（0020）。
- 莉波：本篇没有直接称呼。
