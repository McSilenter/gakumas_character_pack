# 活动 017 / 第4话（adv_event_017_main-04）

- 她的台词：7 行（含用匿名标签说的 0 行）
- 出场的人：莉波、星南、麻央、燕
- 场景：休息日，天川市的游乐园；三年级四人玩旋转木马、过山车，傍晚是两人组的僵尸主题解谜游戏，她与莉波一组。
- 世界线：活动 017；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
燕在游乐园看到过山车，叫麻央去坐。到旋转木马时，她对星南说自己也懂骑马，提出比谁更快。过山车后她指出麻央全程闭着眼。听到僵尸主题的解谜游戏，她问麻央是不是怕这种东西。猜拳分组后她与莉波一组，催莉波快走。

## 她的关键台词
- 0004「有村、ジェットコースターがあるぞ。」——向麻央指出过山车。
- 0014「乗馬の心得なら、私もあるぞ。／どちらが速いか、勝負するか？」——看星南选马后提出比赛。
- 0020「おおおおおおおおおおっ！？」——木马上的叫声。
- 0024「有村は目を閉じていただろう。／ちゃんと見ていたぞ。」——揭穿麻央过山车上闭眼。
- 0027「次は何に乗る？」——游玩中先开口问下一个项目。
- 0030「ほう、楽しそうだな。しかし、／有村は……怖いのは苦手か？」——听了谜题游戏的介绍，先说有趣，再向麻央提出怕不怕。
- 0038「早く行くぞ、姫崎。／この勝負、早い者勝ちだ。」——催莉波，把解谜看作比赛。

## 行为模式
- 看到游乐设施 → 先向麻央搭话（0004）
- 听到「马」 → 以「乗馬の心得」参与，转为比赛（0014）
- 看到别人的软处 → 当场说出自己看到的事实（0024）
- 面对解谜游戏 → 把它当作胜负，催同伴快走（0038）

## 关系
- 麻央：叫「有村」（0004、0024、0030）；会指出她的弱点。
- 星南：和星南比骑马的速度（0014）；星南回应「負けないわよ」（0015）。
- 莉波：叫「姫崎」（0038）；与莉波同组。
