# 活动 019 / 巡演活动 名古屋篇 第1话（adv_event_019_main-01）

- 她的台词：8 行（含用匿名标签说的 0 行）
- 出场的人：咲季、星南、莉波、燕、ことね、手毬、一同
- 场景：学园内，星南把咲季叫来，莉波和燕也在；之后咲季又把ことね和手毬叫来。
- 世界线：活动 019；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
燕向咲季说明名古屋公演原定领队突然不能参加，又说自己这边（生徒会）也有别的活动无法亲自处理。咲季接下代理领队后，燕对星南说咲季果然像某人，被星南否认。咲季说要自己选成员，燕同意，但要求先通知对方，问她打算带谁。剧情经过参照 ttmr、hski 笔记。

## 她的关键台词
- 0012「知っているなら話が早い。」——咲季说明了解计划后立刻接上。
- 0013「次に控えているのが、／名古屋での公演なのだが……」——说明具体是哪场公演。
- 0014「リーダーを務める予定だった生徒が、／急遽参加できなくなってしまった。」——说明问题所在。
- 0019「我々が何とかするのが筋なんだろうが、／生徒会も別のイベントが／入ってしまっていてな……」——承认本应由三年级处理，但生徒会没有余力。
- 0028「会長、私たちの言ったとおりだったな。」——咲季接下后，对星南说话。
- 0029「こいつはやはり、／誰かさんと似ているよ。」——对星南说咲季像「誰かさん」。
- 0036「ああ。／だが先方へは事前に共有しておきたい。」——同意咲季选成员，但要求先通知对方。
- 0037「誰を連れて行くつもりだ？」——问咲季人选。

## 行为模式
- 说明问题 → 条理清晰，先说结论（领队缺席），再说为什么自己人没法做（0013、0014、0019）
- 对方接受后 → 转向同伴说果然如她们所说（0028）
- 同意对方的做法 → 附上自己这一方必须的条件（事先共有）（0036）
- 想了解细节 → 直接问「誰を連れて行くつもりだ」（0037）

## 关系
- 星南：叫「会長」（0028）。
- 咲季：叫「こいつ」（0029），说话时直接，不用敬语；咲季叫她「雨夜先輩」（0003）。
- 莉波：莉波在旁补充说明。

- 与星南议论过咲季，说「私たちの言ったとおり」（0028）。
