# 活动 021 / main-01 第1话（adv_event_021_main-01）

- 她的台词：25 行（含用匿名标签说的 0 行）
- 出场的人：燕（25）、星南（24）、莉波（12）
- 场景：开头（0001～0011）是看星星的场景，之后（0013～）在生徒会室，夜晚已晚
- 世界线：活动 021；制作人在制作的偶像：看不出

## 发生了什么
开头她给星南讲解“一番星”，被说“个子高的话能够到星星”，回以“不可能”。之后她在生徒会室醒来，发现自己居眠り，责问为何不叫醒她。看出星南脸色不好，她提出代做业务，星南拒绝，两人互相争着要对方休息。莉波下令禁止两人生徒会业务，燕起初说没有两人不行，被“请依靠我们”说服。

## 她的关键台词
- 0002「あれは一番星だな。」——开头场景中向星南说明
- 0005「夕暮れ時、最初に見える星のことだ。／一般的には金星を指す。」——给出事实性解释
- 0011「――無理に決まっているだろう。」——对“够得到星星”的回答
- 0018「なぜ起こしてくれなかった！？」——居眠り醒来后的第一反应
- 0023「……星南、本当に大丈夫か？／少し顔色が悪いように見えるぞ。」——注意到星南的状态
- 0028「残っている業務はなんだ？／後は私が代わりにやっておこう。」——主动代做业务
- 0030「それを言うなら、私も副会長として、／会長を支えるのは当然の義務だ。」——自己是副会长，以义务回应
- 0037「そう簡単に休めたら苦労はせん。」——对“该休息”的回答
- 0051「それを理由に、他の役員に仕事を／押し付けるのは道理が通らん。」——不愿把工作推给他人
- 0059「なにかあったらすぐに言え、姫崎。」——最后答应时对莉波说

## 行为模式
- 看到别人不对劲 → 先指出事实（脸色），然后主动提出代劳（0023、0028、0040、0041）
- 自己被要求休息 → 讲“道理”和“义务”不接受（0030、0036、0050、0051）
- 被“请依靠我们”说服 → 沉默，之后叮嘱对方有事马上说（0057、0059）
- 被发现居眠り → 先责问为何不叫醒（0018）

## 关系
- 星南：称「星南」，用「貴様」称之（0021、0040）。
- 莉波：称「姫崎」（0045、0059）；莉波称她「燕ちゃん」。
- 自己是副会长（0030）。

## 档案类事实
- 副会长（0030）
- 周末有杂志拍摄和采访（0033）
- 开头场景里能解释“一番星”是黄昏时最先看见的星，通常指金星（0005）
- 个子高（星南说，0009）

## 不确定
- 0001～0011 看似梦中场景，剧本没明说；0010、0011 的“バカモノ”“無理に決まっている”是否为梦里的她，不明。
