# 活动 021 / main-02 第2话（adv_event_021_main-02）

- 她的台词：29 行（含用匿名标签说的 0 行）
- 出场的人：燕（29）、星南（28）、ダンストレーナー（2）
- 场景：学园内，之后咖啡馆
- 世界线：活动 021；制作人在制作的偶像：看不出

## 发生了什么
生徒会业务被禁止，燕想去上レッスン，却被ダンストレーナー告知她和星南本周被禁止レッスン。她怀疑莉波私物化生徒会，对星南说回家写书法。被星南邀去咖啡馆后，两人聊起咖啡，燕嘲笑星南小时候爱哭，被星南反击揭出她模仿「星南ちゃんダンス」炫耀。争吵后两人和解，星南提议去燕家，燕同意，说“久しぶりにアレを見るのも悪くない”。

## 她的关键台词
- 0001「暇だ……」——被禁止业务后的第一句
- 0003「生徒会業務がしばらく禁止なら、／レッスンをしようと思ったのだが……」——空出来的时间也想拿去练习
- 0008「姫崎め、私たちがいない隙に、／生徒会を私物化しているようだな……」——对莉波的玩笑式怨言
- 0014「今頃、花海が机や扉を破壊し、／倉本が書類にでたらめを書き、／秦谷はサボっているに違いない。」——对生徒会的担忧
- 0019「今日はさっさと家に帰って、／書でもしたためるとしよう。」——空闲时想写书法
- 0026「今度、有村にも勧めてやろう。」——觉得咖啡好喝，想推荐给麻央
- 0033「貴様が私も飲みたいと言い出して、／泣き出した時の話だろう？」——取笑星南小时候
- 0036「あの時の顔は見ものだったなぁ、／――泣き虫星南ちゃん？」——继续逗她
- 0046「あ、あれは……みんながやってみろって／言ったから、仕方なく、だな……！」——被揭短时的辩解
- 0053「プライベートで貴様と話すのは、／久しぶりだからな。」——为刚才的争吵道歉并说明原因
- 0057「久しぶりに、アレを見るのも悪くない。」——同意星南去自己家

## 行为模式
- 被剥夺工作 → 先抱怨“无事可做”，然后想找替代的事做（0001、0003、0010、0019）
- 取笑对方得意时 → 被反击后慌张辩解（0043～0046）
- 争到头 → 对方叫停时马上道歉（0051、0052）
- 对生徒会事务 → 想象同伴会出问题，但被星南说服后接受（0013～0018）

## 关系
- 星南：用「貴様」称星南，叫她“泣き虫星南ちゃん”（0036）。认为私下对话久违（0053）。
- 莉波（姫崎）：称「姫崎」（0008）。
- 麻央（有村）：称「有村」（0026）。
- 花海、倉本、秦谷：用姓称呼，认为会出问题（0014）。

## 档案类事实
- 喜欢书法（“書でもしたためる”，0019）
- 喜欢咖啡，但平时不怎么喝（0025、0028）
- 小时候就喝黑咖啡（星南说，0029）
- 在小时候的“星南ちゃんダンス”被星南说模仿炫耀过（星南说，0044）；她自称是被大家要求才做的（0046）
- 她家里有「アレ」（内容未明说），想给星南看（0057）
