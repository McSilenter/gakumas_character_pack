# 活动 021 / main-03 第3话（adv_event_021_main-03）

- 她的台词：35 行（含用匿名标签说的 0 行）
- 出场的人：燕（35）、星南（28）
- 场景：燕的家，看初星毕业生联合live的录像
- 世界线：活动 021；制作人在制作的偶像：看不出

## 发生了什么
燕给星南泡茶，两人看录像。星南在她家翻出荧光棒和星南自己的周边，她大声责备。星南问她怎么看自己的完美形象与实际的落差，她回答星南平时是ぽんこつ，但这并不否定偶像的她；她知道星南的努力，也知道她爱哭、莽撞、スカウト很差，正因为如此才评价偶像的星南。星南离开接电话后，她发现了夹着的一张照片，是星南第一次成为「一番星」时的照片，感叹已过了一年。

- 面对星南的变化 → 用理屈说明，随后承认感情未必一致（0034～0043）
- 一个人时（星南出去） → 内心独白，注意到旧照片（0059～0063）
