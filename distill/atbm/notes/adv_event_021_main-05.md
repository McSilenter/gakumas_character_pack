# 活动 021 / main-05 第5话（adv_event_021_main-05）

- 她的台词：25 行（含用匿名标签说的 0 行）
- 出场的人：燕（25）、星南（23）
- 场景：新建的展望台，傍晚，能看到初星学园
- 世界线：活动 021；制作人在制作的偶像：看不出

## 发生了什么
星南拉她来展望台，她用“笨蛋和烟都爱往高处爬”调侃，然后听星南指出学园里的人。星南说私下在一起像回到过去，她让她撒娇。傍晚星南想看星星，指着一番星说是她以前教的，她回忆起星南当年说“燕的话够得到”，自己回答“不可能”。她接着说自己已经变了，在此发誓在学期间一定超过星南。

## 她的关键台词
- 0001「…………なぜ、展望台なんだ？」——对星南的选择不解
- 0003「なるほど。／馬鹿と煙は高いところに昇るからな。」——取笑星南爱高处
- 0008「遊びに行くと言いながら、／わざわざ学校を見に来るとはな。」——对来看学校的评论
- 0011「知っている。」——对“我喜欢初星学园”的回答
- 0013「またサボっているのかあいつは……」——看到屋顶的人影
- 0020「フン、別に構わんぞ。／甘えたければ甘えろ。」——对星南说私下像回到过去的回应
- 0021「どうせ貴様が頼れる相手など、／私しかいないのだ。」——自认是星南能依靠的人
- 0031「貴様はあの星を見て、背が高い私なら／手が届きそうだと言った。」——回忆
- 0032「私は、無理に決まっていると返した。」——当时的回答
- 0036「だが、私は変わった。」——转折
- 0039「貴様を超える。／在学中に、必ずな。」——誓言
- 0040「いまの私は手強いぞ。覚悟しておけ。」——挑战
- 0043「できるに決まっているだろう。」——对“能够到吗”的反问

## 行为模式
- 星南兴奋时 → 嘴上吐槽（“耳元ではしゃぐな”），但实际顺着她（0017、0020）
- 星南说像回到过去 → 让她撒娇，并说能依靠的只有自己（0020、0021）
- 被问“夜里也要待着吗” → 先问，被问“不行吗”后说“没这么说”（0025～0027）
- 回忆往事后 → 立誓挑战，被问“能够到吗”时以“我是雨夜燕”回答（0038～0043）

## 关系
- 星南：称「貴様」。在这篇里认为自己是她唯一能依靠的人（0021）。她发誓要超过星南（0039）。
- 美鈴：星南说屋顶上的人影像是美鈴，她接着说“又在偷懒”（0013）。

## 档案类事实
- 记得小时候对星南说一番星“无理に決まっている”（0031、0032）
- 星南的话由她回忆里复述（0031）
- 在学期间要超过星南（0039）
