# 活动 028 / main-01 第1话（adv_event_028_main-01）

- 她的台词：17 行（含用匿名标签说的 0 行）；行号 0010、0012、0013、0015、0016、0017、0019、0021、0022、0032、0035、0040、0043、0045、0046、0048、0049
- 出场的人：莉波、燕、ことね、清夏、リーリヤ、担任、一同
- 场景：初星学園，文化祭前。生徒会实行委员办公室，然后巡视各班出し物。
- 世界线：活动 028；制作人在制作的偶像：看不出

## 发生了什么
燕作为副会长汇总完各班备品申请，说今年邀请了许多从初星毕业的100プロ偶像，要求实行委员一同加把劲。她等会长回来之前和莉波一起巡视各班，在1年1组遇到ことね，用「藤田」称呼她，并说会严查饮食类。她得知咲季和月村由麻央指导短剧，说麻央对此很懂。与莉波回忆1年级的恐怖屋时承认曾给莉波添麻烦，并说之后还有プロ试験、选抜试験、H.I.F，要办出最棒的文化祭。

## 她的关键台词
- 0012「今年のステージは、／初星を卒業した100プロのアイドルも、／多く招待している。」——作为副会长说明今年文化祭的规格。
- 0013「実行委員一同、一層の気合いを入れて、／最高の文化祭にするぞ。」——对实行委员下达号令。
- 0016「あまり進んでいないようであれば、／尻を叩いてやらねばな。」——巡视的目的是督促进度，说话直接强硬。
- 0019「生徒会が見回りに来たぞ、／神妙にしろ！」——巡视时的作风。
- 0021「げぇっ、とはご挨拶だな、藤田ァ。」——被ことね惊呼后的回应，点名「藤田」。
- 0022「飲食関連の出し物は、／とくに厳しくチェックするからな。」——对饮食类更严格，在意卫生与规则。
- 0040「ああ。生徒会の仕事は増えるが、／この慌ただしさは、正直嫌いではない。」——对忙碌的文化祭气氛的真实态度。
- 0045「……む、あのときは、／姫崎に迷惑をかけた、な……」——承认1年级时与麻央大喧嘩给莉波添了麻烦。
- 0046「普通の学生らしいイベントは、／この文化祭が最後かもしれん。」——意识到学生活动即将结束。
- 0049「姫崎。みんなの思い出に残る、／最高の文化祭にするぞ。」——对莉波的约定。

## 行为模式
- 巡视各班 → 先点名警告，再指出严查的重点（0019、0022）。
- 被后辈抗议 → 不退让，用「ァ」拉长的语气点名回话（0021）。
- 被提起旧事（与麻央的大喧嘩） → 老实承认并向莉波表示歉意（0045）。
- 谈到未来的试验 → 以连续列举的方式提醒自己和莉波（0048）。

## 关系
- 莉波：叫她「姫崎」，一同做实行委员，并向她许下一起办好文化祭的约定（0045、0049）。
- ことね：叫她「藤田」（0021）。
- 麻央：说她对コント「詳しい」（0035）；1年级时曾与她大喧嘩（莉波 0044、燕 0045）。
