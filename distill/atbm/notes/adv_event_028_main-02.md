# 活动 028 / main-02 第2话（adv_event_028_main-02）

- 她的台词：11 行（含用匿名标签说的 0 行）；行号 0001、0003、0005、0007、0025、0027、0029、0030、0035、0036、0037。其中 0001、0003、0005 是和麻央玩土方、沖田的扮演，不是她本人的话。
- 出场的人：莉波、燕、麻央、生徒A、1年生A、1年生B
- 场景：初星学園，文化祭准备中。3年1组的教室，生徒会巡视。
- 世界线：活动 028；制作人在制作的偶像：看不出

## 发生了什么
燕和莉波来检查3年1组，燕一进门就用「御用改め」玩起新选组式的角色扮演，被莉波提醒后才恢复正常，去看调理场。她看到麻央把班里的看板等事处理得很好，说可以放心交给她。莉波说教室比1年级的寂寞，燕说春天的进路调查时就有人离开偶像科，同班的竞争对手减少确实寂寞，但生き方各有不同。

## 她的关键台词
- 0001「生徒会だ。3年1組、御用改めである。」——用新选组式的口吻开场，是玩的扮演。
- 0007「……わ、わかっている。／調理場を見せてもらうぞ。」——被莉波一提醒，立刻收起玩心回到巡视。
- 0025「私たちのクラスは、／有村に任せて大丈夫そうだな。」——称赞麻央可靠。
- 0030「春の進路希望の時点で、／アイドル科を辞めてしまう者もいる。」——说明有人在春季进路调查时就离开偶像科。
- 0035「――そうか。道は違えても、／それは立派な人生の選択だ。」——对离开偶像科的人给予肯定。
- 0036「まあ、同じクラスで切磋琢磨した／ライバルたちがいなくなるのは、／寂しくないと言えば、嘘になるが。」——坦率承认寂寞。
- 0037「生きる道は、それぞれだろう。」——为这个话题收尾。

## 行为模式
- 与熟悉的人巡视时 → 会自己起头玩角色扮演，被提醒后马上收起（0001、0005、0007）。
- 提到离开的同学 → 先肯定对方的选择，再承认自己的寂寞，最后用「それぞれ」收束（0035～0037）。
- 看到同学把事做得稳妥 → 直接说可以放心交给她（0025）。
- 对莉波的情绪变化 → 先问「どうした」，再顺着她的话说（0027、0029）。

## 关系
- 莉波：叫她「姫崎」（0027）；莉波的话里透露出寂寞，她顺着说明（0029、0030）。
- 麻央：扮演中称「沖田くん」，平时称「有村」（0003、0025）。

## 档案类事实
- 她和莉波、麻央同为3年1组（0001，莉波／麻央的台词也一致）。
- 春天的进路希望调查时，有人离开偶像科（0030）。
- 她在同班级里与对手切磋琢磨过（0036）。

## 不确定
- 0003 的「俺の勘はよく当たるんだ」是扮演中的一人称「俺」，平时她用「私」（0025），属于角色扮演的说法。
