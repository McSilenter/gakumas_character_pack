# 活动 028 / main-03 第3话（adv_event_028_main-03）

- 她的台词：27 行（含用匿名标签说的 0 行）；行号 0002、0005、0008、0009、0010、0013、0014、0019、0021、0022、0026、0030、0034、0040、0044、0046、0047、0050、0052、0054、0062、0064、0066、0072、0073、0074、0078
- 出场的人：莉波、燕、星南、千奈、広、佑芽、美鈴、一同
- 场景：文化祭前夜的初星学園校舍，作业到夜里。先是星南交接钥匙，然后教室送夜食、参观プラネタリウム，最后只剩她和莉波。
- 世界线：活动 028；制作人在制作的偶像：看不出

## 发生了什么
燕要留到夜里监督作业落后的班级，收下星南的钥匙，并说倉本们已熟悉工作，文化祭后可以把工作交接给他们，对星南说「お疲れ様、会長」。她给大家带来饮料，对来道歉的千奈说落后的班级不只她们，要大家做出悔いなし的文化祭。体验完広的プラネタリウム后，只剩她与莉波，回忆1年级时留校作业的事。莉波说出对未来的迷茫，她说自己要在9月的プロ試験里决定本所属，又说看着莉波的努力所以相信她能行，但决定在于莉波本人。剧情经过参照 hmsz、hume 笔记。

## 她的关键台词
- 0005「ふっ、気にするな。／ライブで初星の文化祭を、／大々的に宣伝してきてくれ。」——对星南的道歉不在意，把宣传托付给她。
- 0010「文化祭が一段落すれば、／あとの仕事は引き継がせよう。」——已在考虑生徒会工作的交接。
- 0014「お疲れ様、会長。」——对星南的提问，以犒劳作为回答。
- 0022「一生の思い出に残る文化祭だ。／悔いの残らんようにやれ。」——对作业落后的学生的叮嘱。
- 0044「歴代の『一番星』のライブを／映し出すとは、／なかなか凝った演出だったな。」——看完プラネタリウム后的评价，注意到演出的内容。
- 0047「……1年生の頃は、私たちも、／夜まで残って作業をしていたな。」——和莉波回忆1年级。
- 0064「ああ。9月のプロ試験で、／本所属を決めるつもりだ。」——明确表示要靠9月的プロ試験得到本所属。
- 0066「姫崎は、どうするんだ？」——反问莉波的进路。
- 0073「私は姫崎の努力を、ずっと見てきた。／だから、姫崎ならなれると思う。」——对莉波的肯定。
- 0074「――とはいえ、決めるのは姫崎だ。」——肯定之后不替对方做决定。

## 行为模式
- 同伴道歉 → 说「気にするな」，转而交代对方真正要做的事（0005）。
- 学生为作业延误道歉 → 说明原因不止她们，并要求以不留遗憾为目标（0021、0022）。
- 同伴说出迷茫 → 先沉默（0062），再引用事实（看着其努力）给出肯定，最后明确决定权在对方（0072～0074）。
- 被莉波的话触及未来 → 用「……――」沉默回应（0054、0062、0078）。

## 关系
- 星南：称「会長」（0014）；星南叫她「燕」（0001）。
- 莉波：称「姫崎」，她看着莉波的努力，相信她能行（0073）。
- 千奈：千奈为作业迟了道歉，她回答别的班级也迟了（0020、0021）。
- 倉本：燕提到倉本们已熟悉工作，打算交接（0009、0010）。
