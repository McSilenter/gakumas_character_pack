# 活动 028 / main-05 第5话（adv_event_028_main-05）

- 她的台词：23 行（含用匿名标签说的 0 行）；行号 0018、0021、0022、0027、0029、0038、0040、0042、0043、0045、0046、0047、0048、0050、0052、0054、0055、0057、0068、0070、0073、0076、0077
- 出场的人：莉波、燕、咲季、星南、父、母、一同
- 场景：文化祭当天，她在自己的舞台结束后遇到莉波；星南宣布初星アイドルコンテスト；之后是后夜祭的特别演唱会。
- 世界线：活动 028；制作人在制作的偶像：看不出

## 发生了什么
燕看到1年生的宣传，称赞她们。她刚结束自己的舞台，对莉波说是抱着吃掉压轴的星南的心情唱的。星南突然宣布飞入参加的コンテスト后，她说会长的一时兴起让人头疼，然后劝莉波参加，理由是今天100プロ的スカウト来了很多，莉波每天坚持练习，并问她是不是喜欢偶像、想不想成为偶像，最后叫她问自己的魂：「お前は今、どうしたいんだ」。事后她说莉波的演出很好；莉波说要考9月的试验，燕说「ライバルが増えるな。／星南にも、私にも。」。剧情经过参照 hski 笔记。

## 她的关键台词
- 0018「ふっ、1年生もなかなかやるな。」——看到后辈的宣传，认可她们。
- 0021「ああ、ラストに控える星南を、／喰ってやるつもりで歌ったからな。」——说自己唱歌时对星南的竞争心。
- 0022「最後の文化祭に相応しい、／最高のライブを届けることができた。」——对自己舞台的评价。
- 0038「……まったく。会長の／思い付きにも困ったものだな。」——对星南的突发企划无奈。
- 0043「アイドル姫崎莉波を、／アピールするチャンスだぞ。」——用スカウト到场作理由劝莉波上台。
- 0045「なにを言っている。姫崎は毎日、／レッスンを続けてきただろう。」——反驳莉波的推辞，指出她每天练习。
- 0050「アイドルが、好きなんだろう？」——问她的出发点。
- 0055「姫崎、お前の魂に問う！／お前は今、どうしたいんだ！？」——逼问她的真正意愿。
- 0057「……お前はちゃんと持っているよ。／アイドルになる資格を。」——断言莉波具有成为偶像的资格。
- 0073「……ただの星南の気まぐれだ。」——被莉波问到舞台是否为自己准备时的回答，口气保留了余地。
- 0077「ライバルが増えるな。／星南にも、私にも。」——听到莉波要考试后的回应。

## 行为模式
- 对后辈的成果 → 简短认可（0018）。
- 对星南的突然决定 → 无奈叹气，随即顺势利用它推莉波一把（0038、0040～0043）。
- 对莉波的推辞 → 用事实反驳（每天的练习），再用连续两个问句让对方说出愿望（0045、0050、0052）。
- 被道谢 → 以「ただの星南の気まぐれだ」把功劳推给星南（0073）。

## 关系
- 莉波：称「姫崎」，推她上台，并说她拥有成为偶像的资格（0040、0057）。
- 星南：称「会長」（0038）、「星南」（0073、0077）。
- 咲季：未直接对话，只在 0018 对1年生们的评价。

## 档案类事实
- 她在文化祭上有自己的舞台，在星南之前（0021、0022）。
- 今天100プロ的スカウト大批来了会场（0042）。
