# 雨夜燕 培育事件 001 activity / 002 今天的题目是？（adv_pevent_001_atbm_activity_002）

- 她的台词：12 行（含用匿名标签说的 0 行）
- 出场的人：燕（12 行）、プロデューサー（6）
- 场景：地点剧本没写明；她打算这天用毛笔写字（0003）
- 世界线：培育（雨夜燕）；制作人在制作的偶像：雨夜燕（剧本里没有直接说法；0011、0015 制作人以制作人身份谈自己的座右铭）

## 发生了什么
她突然问制作人有没有座右铭，说今天想用毛笔写点什么，但想不出题材，想参考他的座右铭（0001～0005）。之后是三种并列的反应（制作人的回答应是选项）：制作人说是「はじめたときの気持ちを忘れない」，她说以他来说是个不错的座右铭（0006～0009）；制作人的座右铭是“面临大事也保持冷静”一类，他说制作人需要冷静，她说有点对他刮目相看（0010～0013）；制作人说是表达自己对制作坚定信念的原创座右铭，她说虽然有很多想说的，但他的信念传达到了（0015～0017）。三种反应最后她都说写好了送给他，让他挂在房间里或显眼的地方（0009、0014、0018）。

## 她的关键台词
- 0001「貴様に、／座右の銘はあるのか？」——开门见山地发问
- 0004「『これ』という題材が思いつかん。」——坦白自己想不出题材
- 0008「ふっ、貴様にしては、／良い座右の銘だな。」——夸人时带「貴様にしては」的保留
- 0013「ふっ、少し見直したぞ。」——认可对方时以「少し」收着说
- 0017「……色々と言いたいことはあるが、／貴様なりの信念は伝わってきた。」——先保留吐槽，再承认对方的信念
- 0018「書き上げたらくれてやる。／目立つ場所にでも飾っておけ。」——把自己的字当礼物，用「くれてやる」「飾っておけ」的高姿态说法

## 行为模式
- 想做事但缺灵感 → 直接找制作人要材料，说明理由（0001、0003～0005）
- 听到认可的东西 → 先「ふっ」，再带保留地夸（「貴様にしては」「少し」）（0008、0013）
- 对方的东西有可吐槽之处但态度真诚 → 先说「色々と言いたいことはある」，再承认对方的心意（0017）
- 表示好意 → 用「くれてやる」这类居高临下的说法送东西（0009、0014、0018）

## 关系
- プロデューサー：她称对方「貴様」（0001、0005）。主动问他的座右铭作为写字的参考，听完后表示认可，并说要把写好的字送给他（0008、0013、0017、0018）。

## 档案类事实
- 她会用毛笔写字，这一天想写点什么（0003）。

## 不确定
- 0006～0009、0010～0014、0015～0018 应是制作人回答（选项）后的三种并列反应；0010 前制作人说出的座右铭本身剧本里没有，只能从她的「大事に直面しても／落ち着いていること、だったか」推知意思。
