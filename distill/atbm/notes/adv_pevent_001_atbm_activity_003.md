# 雨夜燕 培育事件 001 activity / 003 忍者是何者（adv_pevent_001_atbm_activity_003）

- 她的台词：11 行（含用匿名标签说的 0 行）
- 出场的人：燕（11 行）、プロデューサー（11）
- 场景：外面（0001 她说为了转换心情出来了），附近有餐厅、电影院（0003、0006）；具体地点剧本没写明
- 世界线：培育（雨夜燕）；制作人在制作的偶像：雨夜燕（剧本里没有直接说法）

## 发生了什么
她出来转换心情，却不知道做什么好（0001）。制作人提议吃饭，说附近的餐厅全都掌握，她吃惊之余说现在不饿（0002～0005）；制作人又提议看电影、说现在去马上就能看，她说他真是什么都查了，简直像忍者（0006、0007）。之后应是几种并列的反应：制作人说了什么俏皮话后，她追问他是伊賀、甲賀还是風魔流派，叫他「自称忍者殿」，制作人心里后悔不该随口乱说，她说知道是玩笑、只是逗他（0008～0012）；制作人说自己只是擅长情报收集、管理和事前疏通、行动轻快，必要时秘境也去，她喊“你果然是忍者吧”（0013～0016）；制作人反过来说她和风知识、名家出身、偶像身份正适合当掩护，怀疑她是雨夜流忍术的继承人，她说胡说，却又说姑且问问父母，制作人心里担心现在说是玩笑会被骂（0017～0022）。

## 她的关键台词
- 0001「気分転換に外に出たが……／さて、どうしたものか。」——出来了却没有计划
- 0004「す、すべて……？」——被制作人掌握全部餐厅吓到
- 0007「……本当になんでも調べているな。／まるで忍者だ。」——对制作人的周到半佩服半吐槽
- 0009「流派は伊賀か？　それとも甲賀か？／いや、風魔もありうるな。」——顺着话头认真列举忍者流派，显出对这类题材的熟悉
- 0010「さあ、答えてみるがいい。／自称忍者殿？」——反过来调侃制作人
- 0012「フン、分かっている。／からかっただけだ。」——承认是在捉弄对方
- 0016「貴様、やはり忍者ではないのか！？」——对制作人的能力大惊小怪
- 0020「何を馬鹿なことを言っている。／そんなわけがないだろう。」——先否定荒唐说法
- 0021「……一応、両親に聞いてみるか。」——否定之后又半信半疑，打算问父母

## 行为模式
- 对方准备过于周全 → 先吃惊，再找理由推掉（「今は空腹ではない」）（0004、0005）
- 对方开玩笑 → 顺着玩笑认真地追问细节，摆出居高临下的口吻捉弄回去，最后说「からかっただけだ」（0008～0010、0012）
- 被说出荒唐的推测 → 嘴上断然否定，心里却当了真、打算去确认（0020、0021）

## 关系
- プロデューサー：她称对方「貴様」（0016），调侃时叫他「自称忍者殿」（0010）；制作人称她「雨夜さん」（0018）。她对他的情报收集能力感到吃惊，也会拿来开玩笑（0004、0007、0010、0016）。
- 両親：她说要姑且问问父母自己是不是忍术继承人（0021）。

## 档案类事实
- 制作人说她有和风知识、出身名家（0017，制作人的话）。
- 她提到要问「両親」（0021）。

## 不确定
- 0002～0005、0006～0007 之后的 0008～0012、0013～0016、0017～0022 应是选项后的并列反应；分段是推测。0008「面白いことを言う」前制作人说了什么剧本里没有，推测是自称忍者一类的话。
- 0021 她是真的半信半疑，还是顺着玩笑说，读法两可；制作人 0022 的心里话把它当成她当真了。
- 【译文】0012「フン、分かっている。」译成“哼，算你识相。”，原文是“哼，我知道（你在开玩笑）”的意思。
