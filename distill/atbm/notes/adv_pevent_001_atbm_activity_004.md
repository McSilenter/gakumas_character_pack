# 雨夜燕 培育事件 001 activity / 004 甜味的诱惑（adv_pevent_001_atbm_activity_004）

- 她的台词：13 行（含用匿名标签说的 0 行）
- 出场的人：燕（13 行）、プロデューサー（12）
- 场景：地点剧本没写明；她把前一天在スタジオ收到的慰问品带来（0003）
- 世界线：培育（雨夜燕）；制作人在制作的偶像：雨夜燕（剧本里没有直接说法；0011、0020、0021 制作人管理她的卡路里和课程）

## 发生了什么
她把一盒どら焼き送给制作人，说是前一天在スタジオ收到的慰问品（0001～0003）。之后是几种并列的反应：制作人问真的可以吗、她应该不讨厌どら焼き，她说“我可是偶像，你该明白”，又急着说自己没吃（0004～0007）；制作人说开玩笑的，看就知道她体重没变，她先说那就好，又说这样反而让她觉得危险；制作人说一个どら焼き的热量可以调整，让她别忍着，她就说那就收下（0008～0013）。另一种反应里她先喊“你有没有听人说话”，制作人解释一个的卡路里不难调整、忍耐的压力才是问题，她认同后要了こしあん的，并催他快吃（0014～0019）。还有一种反应里制作人说明天有较严格的课，为维持最佳体重今天要多摄取卡路里，她说没听说过有这种课，制作人说刚刚才定的，她说他真是绕圈子，催他快分一个给自己（0020～0025）。

## 她的关键台词
- 0001「そうだ、／貴様にこれをくれてやる。」——送东西也用「くれてやる」
- 0006「……私はアイドルだぞ。／察しろ。」——以偶像身份为由克制甜食，不明说
- 0007「わ、私は食べていないぞ！」——急着撇清
- 0010「ならばいい……いや、よくない！／それはそれで身の危険を感じる！」——先松口气再对制作人“看得出体重”反应过来
- 0017「……たしかに、／貴様の言うことは一理ある。」——被讲通道理就认同
- 0018「では、こしあんの方をもらおうか。」——一认同就点明自己要的口味
- 0024「……まったく、回りくどい奴だ。」——看穿制作人借口背后的体贴
- 0025「さっさとひとつよこせ。」——接受好意时仍用命令口吻

## 行为模式
- 面对甜食 → 以「アイドル」身份克制，送给别人，不明说想吃（0001、0006）
- 被怀疑偷吃 → 慌忙否认（0007）
- 制作人用数据或道理说明可以吃 → 认同「一理ある」后就接受，还会挑口味（0013、0017、0018）
- 察觉制作人为让她吃而编了理由 → 吐槽「回りくどい」，但直接要过来（0022、0024、0025）

## 关系
- プロデューサー：她称对方「貴様」（0001、0014、0017）；制作人称她「雨夜さん」（0009、0020）。她把收到的点心送给他，最后在他的劝说或体贴的借口下一起吃（0013、0018、0025）。对他说看得出她的体重这件事有点警惕（0010）。

## 档案类事实
- 她前一天在スタジオ收到了どら焼き作为慰问品（0003）。
- 她因为是偶像而克制吃甜食（0006）。
- どら焼き她要了こしあん的（0018）。
- 制作人说她的体重没有变化（0009，制作人的话）。
