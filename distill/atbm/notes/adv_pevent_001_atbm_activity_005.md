# 雨夜燕 培育事件 001 activity / 005 推荐的店铺是？（adv_pevent_001_atbm_activity_005）

- 她的台词：11 行（含用匿名标签说的 0 行）
- 出场的人：燕（11 行）、プロデューサー（8）
- 场景：商店街（0001）
- 世界线：培育（雨夜燕）；制作人在制作的偶像：雨夜燕（剧本里没有直接说法；0011 制作人说要为宣传形象找模型）

## 发生了什么
她问制作人常不常来商店街，听他说只在有需要时来，就主动说要给他介绍店（0001～0003）。之后是几种并列的反应：她刚要推荐茶わん蒸し好吃的店，制作人却按“马上能吃”“性价比”“能用来开会”三类要求推荐，她说他真是不值得介绍，但还是说要从知道的店里想想符合的（0005～0009）；制作人要去模型店，她激动地以为他也喜欢机器人动画，听说是为了确定宣传形象要模型，泄气地说“这样啊”，还是给他带路（0010～0013）；制作人要卖食材和便当的店，又陆续加上日用品、医药品、衣物，她说超市不太熟但想到一家，最后忍不住叫他直接去购物中心（0014～0019）。

## 她的关键台词
- 0003「ならば、／どんな店があるか紹介してやろう。」——主动提出带路，用「してやろう」的口吻
- 0005「ふむ。それなら、／茶わん蒸しが美味しい、あの店を……」——第一个想推荐的是吃的店
- 0008「……貴様は本当に、／紹介しがいがないな。」——对制作人功利的要求泄气
- 0009「少し待て。私の知る店の中から、／該当するものを考える。」——嘴上抱怨但还是认真回应
- 0010「も、模型店！？／まさか貴様も、ロボットアニ……」——以为找到同好而激动
- 0012「…………そうか。」——期待落空的沉默
- 0013「模型店はこっちだ。／ついてこい。」——失望后照样带路
- 0019「……もう、／ショッピングモールに行ってこい！」——条件越加越多时吐槽

## 行为模式
- 熟悉的地盘 → 主动当向导（0003）
- 对方提出很功利、条件很多的要求 → 吐槽，但仍认真去想（0008、0009、0015）；条件再加 → 直接吐槽回去（0019）
- 听到可能和自己爱好相关的事 → 脱口而出、抢先期待（0010）；落空后短暂沉默，然后照常行事（0012、0013）

## 关系
- プロデューサー：她称对方「貴様」（0008、0010）。主动给他介绍商店街，对他务实的提问方式有点扫兴，但都认真回应（0003、0008、0009、0013）。

## 档案类事实
- 她熟悉商店街的店，有一家她觉得茶わん蒸し好吃的店（0003、0005）。
- 她对超市不太熟（0015）。
- 听到模型店时，她脱口说出「ロボットアニ……」，显出对机器人动画的兴趣（0010）。
