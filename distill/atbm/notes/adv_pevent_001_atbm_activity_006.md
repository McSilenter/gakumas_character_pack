# 雨夜燕 培育事件 001 activity / 006 君子不立『昆虫』之下（adv_pevent_001_atbm_activity_006）

- 她的台词：15 行（含用匿名标签说的 0 行）
- 出场的人：燕（15 行）、プロデューサー（8）
- 场景：散步途中的森林一带（0001、0010「森の歩き方」）；她以前来过这里（0004）
- 世界线：培育（雨夜燕）；制作人在制作的偶像：雨夜燕（剧本里没有直接说法；0014 制作人说考虑到在森林拍外景）

## 发生了什么
散步来到这里，她说没想到是这个地方：她不讨厌自然和散步，但以前在这里遇到过巨大的虫子，嘴上说不是怕虫，却提议这次走别的路（0001～0006）。之后是几种并列的反应：她喊制作人有没有听她说话，制作人说避开虫子聚集处就能降低遭遇率、要顺便教她森林的走法，她仍说自己不怕虫，但“为了以后”听一听（0007～0012）；她说那种生物不可能习惯，制作人说可能有森林外景、多少习惯一下比较好，她认同后说就这样走下去（0013～0017）；她选了另一条路，制作人说那边灌木多、虫子更多，提议往回走去虫子少的步道，她说好，出发（0018～0023）。

## 她的关键台词
- 0003「いや、自然に囲まれるのも、／歩くのも嫌いではない。」——先说明不讨厌自然和散步
- 0004「だがその……以前、／ここで巨大な虫と遭遇してな。」——吞吞吐吐说出不想来的原因
- 0005「べ、別に苦手というわけでは／ないのだが……」——结巴着否认怕虫
- 0006「今回は、別の道を行かないか？」——否认的同时提出绕道
- 0012「後学のため、聞いておこうか。」——把求教包装成“为了日后学习”
- 0013「あ、あんな生物に／慣れるわけないだろう！」——情急之下露出真心
- 0016「……たしかに、一理あるか。」——被工作上的理由说服
- 0017「よし！／このまま行くぞ！」——认同后鼓起劲来硬着头皮走
- 0020「な、なに……！？」——听说那边虫更多时慌了

## 行为模式
- 碰到怕的东西 → 嘴上反复说「別に苦手というわけでは」，行动上却想办法躲开（0005、0006、0011）
- 制作人给出对付的方法 → 用「後学のため」的名义接受教导（0012）
- 制作人以工作（外景）为理由 → 认同「一理ある」并硬着头皮面对（0014～0017）
- 选错了路被指出 → 慌张，然后接受制作人的替代方案（0020、0023）

## 关系
- プロデューサー：她称对方「貴様」（0007）。在怕虫这件事上嘴硬，但接受他的建议和安排（0012、0016、0023）。

## 档案类事实
- 她不讨厌被自然包围和散步（0003）。
- 她以前在这里遇到过巨大的虫子（0004）。
- 她嘴上否认，但很怕虫：说那种生物不可能习惯（0005、0011、0013）。
