# 雨夜燕 培育事件 001 activity / 008 要看什么电影呢？（adv_pevent_001_atbm_activity_008）

- 她的台词：10 行（含用匿名标签说的 0 行）
- 出场的人：燕（10 行）、プロデューサー（9）
- 场景：街上（0001「せっかく街に出たのですから」），之后要去映画館（0009）
- 世界线：培育（雨夜燕）；制作人在制作的偶像：雨夜燕（剧本里没有直接说法）

## 发生了什么
制作人提议难得上街去看电影，她说不坏，问现在在上映什么（0001～0003）。之后是三种并列的反应（制作人介绍的片子应是选项）：机器人片——宇宙来的生命体ウィステリア侵蚀地球、谜之机器人ジューオー登场、「勇気と絆で超合体」，她「ククク」地说相当令人心动，一定要看（0004～0009）；美少女怪盗トンカトレット和财阀千金偶像侦探的片子，她说内容荒唐，但好歹是偶像作品、也许能参考，就决定看这个（0010～0014）；动物动画片，她说没怎么看过、也许是好机会，决定看这个（0015～0019）。

## 她的关键台词
- 0002「ふむ、悪くないな。」——对提议的平常接受方式
- 0008「ククク……／なかなか心躍る映画ではないか。」——听到机器人合体题材时兴奋的笑法
- 0009「これは必ず観なければ。／映画館へ行くぞ！」——兴奋时立刻拍板
- 0012「……とんでもない内容だな。」——对荒唐设定的吐槽
- 0013「だが、一応はアイドル作品。／参考になるかもしれんな。」——从偶像工作的角度找看的理由
- 0018「あまり観たことはないが、／いい機会かもしれんな。」——对不熟悉的类型也愿意尝试

## 行为模式
- 听到机器人、合体、热血的题材 → 「ククク」地笑、立刻要看（0008、0009）
- 题材荒唐但和偶像有关 → 吐槽后以“能当参考”为由接受（0012、0013）
- 不熟悉的类型 → 当作机会尝试（0017、0018）

## 关系
- プロデューサー：他提议、介绍片子，她做决定，口吻是「映画館へ行くぞ」「向かうぞ」的带队式（0009、0014、0019）。这一话没有称呼对方。

## 档案类事实
- 听到机器人合体题材的电影，她非常兴奋，说一定要看（0008、0009）。
- 动物动画电影她不太看（0018）。

## 不确定
- 0004～0009、0010～0014、0015～0019 应是选项后的三种并列反应。
- 0008「ククク」是兴奋的笑还是故作反派式的笑，读法两可。
