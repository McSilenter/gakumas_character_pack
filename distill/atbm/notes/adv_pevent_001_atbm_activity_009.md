# 雨夜燕 培育事件 001 activity / 009 我的伙伴其名为……！（adv_pevent_001_atbm_activity_009）

- 她的台词：13 行（含用匿名标签说的 0 行）
- 出场的人：燕（13 行）、プロデューサー（9）
- 场景：地点剧本没写明；她的休息日（0001「オフの日なのに」），她在确认合同并签字（0001、0003）
- 世界线：培育（雨夜燕）；制作人在制作的偶像：雨夜燕（剧本里没有直接说法；0001 制作人请她在休息日确认合同内容）

## 发生了什么
制作人为在她休息日请她确认合同道歉，她说是紧急案件就没办法、别在意，签好了确认字（0001～0003）。制作人注意到她的万年筆是新的，她说旧的用了多年坏了，这支是新的「相棒」，名叫「龍翔黒綺」，又名『フリーゲン・シュバルツドラッヘ』，自己都觉得命名完美（0005～0010）。之后是并列的反应：制作人在心里想名字很有个性、本人满意就好，嘴上夸“如飞龙般描绘美丽的黑”是出色的命名，她说他能懂这种品味、让她刮目相看，打算下次也告诉星南、星南一定会吃惊（0011～0016）；另一种是制作人提议用「双燕舞華」这个名字——相棒是自己的半身，两者成为『双燕』在空中描绘华美轨迹——她给它配上『ツヴィリング・ブルームシュヴァルベ』的读法，说以他来说是好名字，决定这支万年筆就叫「双燕舞華」（0017～0022）。

## 她的关键台词
- 0002「急な案件だったのだろう？／ならば仕方ない、気にするな。」——对休息日被打扰很宽容
- 0006「ああ。長年使い続けたせいか、／壊れてしまってな。」——旧笔用了多年
- 0007「これは新しい相棒、／名は龍翔黒綺だ。」——给文具起名、称为「相棒」
- 0009「……またの名を、フリーゲン・／シュバルツドラッヘ！」——汉字名配德语读法的命名习惯
- 0010「……ふっ、我ながら、／完璧な命名だな。」——对自己的命名很得意
- 0014「このセンスが分かるとは……／見直したぞ！」——命名品味被理解时很高兴
- 0016「この素晴らしい名に、驚くだろうな！」——想向星南炫耀
- 0020「双燕舞華……ツヴィリング・／ブルームシュヴァルベか。」——立刻给别人起的名字也配上德语读法
- 0022「よし！／この万年筆の名は、双燕舞華だ！」——采纳制作人起的名字

## 行为模式
- 休息日被工作打扰 → 理解对方难处，不计较（0002）
- 对珍惜的物品 → 称为「相棒」，起汉字名并配上德语式的另一个名字（0007、0009）
- 自己的品味被认可 → 「見直したぞ」，并想告诉朋友（0014～0016）
- 对方给出合她品味的名字 → 「貴様にしては」地夸，然后爽快采用（0021、0022）

## 关系
- プロデューサー：她称对方「貴様」（0021）；制作人称她「雨夜さん」（0013）。在命名这件事上被他的认可或提议打动（0014、0021、0022）。
- 星南：她打算下次把这个名字告诉星南，觉得星南会吃惊（0015、0016），直呼「星南」。

## 档案类事实
- 她用万年筆签字；旧的万年筆用了多年后坏了，买了新的（0006）。
- 新万年筆她起名「龍翔黒綺」，又名『フリーゲン・シュバルツドラッヘ』（0007、0009）；另一种反应里改叫制作人起的「双燕舞華」（ツヴィリング・ブルームシュヴァルベ）（0020、0022）。
- 她喜欢给物品起汉字名配德语读法的名字，并觉得这种命名很完美（0009、0010）。

## 不确定
- 0006～0010、0011～0016、0017～0022 之间的分段是推测；0007 与 0008 都在报名字，可能是两种并列的反应。
- 0017～0018 制作人说「おふたり」成为『双燕』，指的是她和万年筆两者，还是别的，剧本里没说清。
- 【译文】0021「ふっ、貴様にしては、／良い名ではないか。」译成“哼，在你看来，这名字不错吗。”，原文是“以你来说，这名字不错嘛”的夸奖。
