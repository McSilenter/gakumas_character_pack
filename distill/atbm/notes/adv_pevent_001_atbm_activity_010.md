# 雨夜燕 培育事件 001 activity / 010 睡眠不足的理由是？（adv_pevent_001_atbm_activity_010）

- 她的台词：12 行（含用匿名标签说的 0 行）
- 出场的人：燕（12 行）、プロデューサー（8）
- 场景：地点剧本没写明，是人多显眼的地方（0016「ここでは目立ってしまいますから」）
- 世界线：培育（雨夜燕）；制作人在制作的偶像：雨夜燕（剧本里没有直接说法）

## 发生了什么
她打了个哈欠，制作人问是不是睡眠不足，她说因为爱好熬了点夜，这种时候很羡慕时间比从家里通学更灵活的寮生（0001～0004）。之后是几种并列的反应：她对（制作人应是提议住寮的话）回答「却下だ」；制作人问对寮有什么不满，她说没有不满，通学会轻松、设备齐全、有村管理得也很好、住着应该不差，但虽说是寮长，听有村指挥就是让她不爽，制作人心里想她认可对方实力却不愿承认、和有村还是老样子（0005～0010）；她说剧情太精彩反复看了好几遍，没想到在那个时机主角机强化，制作人心里想这是昨天机器人动画的事、她真的很喜欢（0011～0013）；制作人提议活动身体提神，她说不坏，制作人说换个地方、在公众面前挥竹刀太显眼，她骂为什么她的运动就限定成挥竹刀（0014～0020）。

## 她的关键台词
- 0003「……趣味のせいで、／少し夜更かしをしてな。」——承认为爱好熬夜
- 0004「こういうとき、実家通いより／時間の融通がきく、寮生が羨ましい。」——说出自己从家里通学
- 0005「却下だ。」——对提议一口回绝
- 0008「……有村の管理も見事だし、／居心地も悪くないだろう。」——客观承认对手的能力
- 0009「だが！　寮長とはいえ、／有村の指示で動くのは、なにか癪だ！」——认可之后仍不愿受她指挥
- 0011「ああ……あまりの展開に、／何度も見返してしまった。」——谈起爱好时的投入
- 0012「……まさか、あのタイミングで／主役機のパワーアップとはな……」——回味机器人动画的情节
- 0020「なぜ私の運動が、竹刀の素振りに／限定されているんだ、馬鹿者！」——对被定型的吐槽

## 行为模式
- 被问到疲态 → 老实说出原因（爱好熬夜）（0003）
- 被提议做她不愿意的事 → 先断然「却下」，被追问时先列出客观优点，再说出情绪上的理由（0005、0007～0009）
- 说到喜欢的动画 → 沉浸地回味情节（0011、0012）
- 被制作人用固定印象调侃 → 骂「馬鹿者」（0020）

## 关系
- 有村：她用姓「有村」称呼；承认她作为寮长的管理很出色，但听她指挥就是不爽（0008、0009）。制作人的心里话说她认可对方实力却不愿承认、两人还是老样子（0010，制作人的心里话）。
- プロデューサー：她骂他「馬鹿者」（0020）。这一话没有用「貴様」称呼他。

## 档案类事实
- 她从家里通学（实家通い），不住寮（0004）。
- 她因为爱好熬夜（0003）；看机器人动画看得入迷、反复看（0011～0013，0013 是制作人的心里话说是前一天的机器人动画）。
- 有村是寮长（0009）。
- 她平时会挥竹刀（0019、0020 的上下文）。
