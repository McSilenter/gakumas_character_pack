# 雨夜燕 培育事件 001 activity / 011 突击，女仆咖啡厅！（adv_pevent_001_atbm_activity_011）

- 她的台词：15 行（含用匿名标签说的 0 行；0005 可能是制作人想象中她会说的话，见「不确定」）
- 出场的人：燕（15 行）、プロデューサー（9）
- 场景：メイドカフェ店内（0001、0013）
- 世界线：培育（雨夜燕）；制作人在制作的偶像：雨夜燕（剧本里没有直接说法）

## 发生了什么
在メイドカフェ里，她说原本不知道是什么样，结果表演完成度高、接待和料理都无可挑剔，真是百闻不如一见（0001～0003）。之后是几种并列的反应：制作人说老实讲，原以为会被她以“那种不知羞耻的地方怎么能去”拒绝，她承认确实有过想法，但看到这么完美的『可愛い』就没有意见，「良いものは良い」，制作人心里想这很像她（0004～0010）；她说一定要拍合照、会是好纪念，打算请下一位来的女仆一起拍，店里突然吵起来，制作人心里看出是女仆们在猜拳争和她合照，她说很期待（0011～0017）；说到女仆体验，她说不是没兴趣，但这么可爱的衣服自己……，制作人开玩笑要替她报「ピュアピュア／ラブリーメイドコース」，她喊别擅自报名；制作人说体验最重要是有没有兴趣，她说那下次有机会体验看看（0018～0024）。

## 她的关键台词
- 0002「パフォーマンスの完成度も高く、／接客や料理も申し分ない。」——从表演和服务的角度评价
- 0003「まさに、／百聞は一見に如かず、だな。」——用成语总结体验
- 0005「メイドカフェに行かないか、だと？／そんな破廉恥な所に行けるか！」——制作人预想中的她的反应（可能不是当场说的）
- 0007「……まあ、／たしかに思うところはあった。」——承认原先对メイドカフェ有过想法
- 0008「だが、ここまで完璧な『可愛い』を／見せられては、文句などない。」——被高完成度的『可愛い』说服
- 0009「良いものは良い、そういうことだ。」——她的评价标准
- 0017「ああ、楽しみだな！」——对合照很期待
- 0019「興味がないとは言わんが、／私にこんな可愛い服は……」——对可爱衣服有兴趣但觉得不适合自己
- 0021「か、勝手に申し込むなァ！」——被擅自安排时慌张
- 0024「……そうだな。／今度の機会に、体験してみるか。」——被劝后决定下次尝试

## 行为模式
- 原本有成见的东西亲眼看到质量高 → 坦然改观，以「良いものは良い」为准（0001～0003、0007～0009）
- 评价表演类事物 → 着眼于完成度、接待、料理等专业面（0002）
- 对可爱的服装 → 承认有兴趣，但犹豫是否适合自己（0019）；被制作人以“有兴趣就试试”劝 → 打算下次尝试（0023、0024）

## 关系
- プロデューサー：他预料到她原先的反应，她坦白承认；被他的玩笑捉弄会喊住他（0006、0007、0021）。这一话没有称呼对方。
- 制作人的心里话说女仆们在猜拳争和她合照（0014、0015，制作人的心里话），她本人没察觉原因（0013）。

## 档案类事实
- 她来过メイドカフェ，评价很高（0002、0003）。
- 她承认原先对メイドカフェ“有过一些想法”（0007）；制作人原以为她会说那是不知羞耻的地方而拒绝（0005、0006）。
- 她对女仆体验、可爱的衣服有兴趣，但觉得自己不适合（0019）；说下次有机会体验（0024，打算）。

## 不确定
