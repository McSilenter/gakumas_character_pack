# 雨夜燕 培育事件 001 activity / 013 喜欢来河岸边吗？（adv_pevent_001_atbm_activity_013）

- 她的台词：11 行（含用匿名标签说的 0 行）
- 出场的人：燕（11 行）、プロデューサー（7）
- 场景：室外、能边看自然边走的地方（0001、0006）；话名是河岸边，剧本正文没提到河
- 世界线：培育（雨夜燕）；制作人在制作的偶像：雨夜燕（剧本里没有直接说法；0008、0011 制作人在这里构思企划）

## 发生了什么
她说外面的风很舒服，问制作人常来这里吗（0001～0003）。之后是几种并列的反应：制作人说累了会来这里放松，她说能理解，边看自然边走能治愈心灵，提议今天也走走、让他陪到最后（0004～0007）；制作人说边看自然边想企划会有好点子、已经成了常客，她问他包里的ノートPC是不是为此，听他说有时间就想想企划，说今天她也来帮忙，带他去能坐的地方（0008～0013）；制作人说这里是喜欢的地方但最近工作太忙没怎么来，她说他眼下的黑眼圈就是这个原因吧，正是好机会，让他去那边能躺的地方休息一下（0014～0018）。

## 她的关键台词
- 0001「……外の風が気持ちいいな。」——放松时的感受
- 0003「貴様は、／ここによく来るのか？」——主动关心对方的习惯
- 0006「自然を見ながら歩くのは、／心が癒されるからな。」——喜欢在自然中散步
- 0007「では、今日も歩くとするか。／貴様も、最後まで付き合え。」——邀约也用命令口吻
- 0012「ふっ、ならば今日は、／私も手伝ってやろう。」——主动帮忙，用「やろう」的高姿态
- 0016「……目の下にクマがあるのは、／そういう理由か。」——注意到对方的疲态
- 0018「向こうに、横になれる場所がある。／貴様も、少しは身体を休めろ。」——以命令式关心对方

## 行为模式
- 知道对方喜欢某事的理由 → 表示理解并邀对方一起（0005～0007）
- 看到对方在工作 → 主动说要帮忙（0012、0013）
- 察觉对方过劳 → 观察到细节（黑眼圈），用命令口吻让对方休息（0016～0018）

## 关系
- プロデューサー：她称对方「貴様」（0003、0007、0018）。这一话她主动照顾他：陪他散步、帮他想企划、让他休息（0007、0012、0018）。

## 档案类事实
- 她觉得边看自然边走能治愈心灵（0006）。

## 不确定
- 0004～0007、0008～0013、0014～0018 应是选项后的并列反应。
- 0007「今日も歩く」的「も」，是指她常来还是指制作人常来，读不准。
