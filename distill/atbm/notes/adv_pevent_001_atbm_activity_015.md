# 雨夜燕 培育事件 001 activity / 015 被揭露的粉丝之魂（adv_pevent_001_atbm_activity_015）

- 她的台词：14 行（含用匿名标签说的 0 行；0005 是模仿制作人口吻说的，见「不确定」）
- 出场的人：燕（14 行）、プロデューサー（10）
- 场景：カラオケ（0001）
- 世界线：培育（雨夜燕）；制作人在制作的偶像：雨夜燕（0014 制作人说「プロデューサーは、／担当アイドルの一番のファン」，0004 他穿戴的是「燕」应援周边）

## 发生了什么
她确认两人是来唱卡拉OK的，然后质问制作人那身打扮是怎么回事；制作人一副“有什么问题吗”的样子报出「燕応援団法被、燕愛用筆型サイリウム、／秘書燕眼鏡」，她骂他别用那种调调回答（0001～0006）。之后是几种并列的反应：制作人说周边企划在进行中、这是草案样品、自己觉得做得不错，她刚说不知道这个企划，又追问“我ながら”，得知是他自己做的、为省经费，她说够了，但不许他穿成这样出门（0007～0013）；制作人说制作人是担当偶像的头号粉丝、这是粉丝的战斗服，她听到「一番のファン」动摇，说那就算了，但绝对不许穿出门（0014～0018）；制作人说在考虑MV里加入粉丝表演、想让她看看，她让他先停下那多余又利落的荧光棒动作，说下次再看，今天老实点，在旁边那样动她没法专心唱歌，制作人心里说可惜（0019～0024）。

## 行为模式
- 遇到离谱的事 → 先确认前提，再质问（0001、0003）
- 对方一本正经地说离谱的话 → 吐槽语气（0006）
- 被说是“头号粉丝” → 结巴、动摇，然后「良しとするか」地接受（0016、0017）
- 接受之余仍划底线：不许穿出门（0013、0018）
- 对方的提议妨碍当下的事 → 推到下次，让他今天安分（0022、0023）

## 关系
- プロデューサー：她称对方「貴様」（0003），骂他「馬鹿者」（0006）。对他做“燕”应援周边又羞又恼，听到他自称头号粉丝就软化（0016、0017）。
