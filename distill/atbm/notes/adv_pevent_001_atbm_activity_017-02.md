# 雨夜燕 培育事件 001 activity / 017-02 Fighting Game！（adv_pevent_001_atbm_activity_017-02）

- 她的台词：12 行（含用匿名标签说的 0 行）
- 出场的人：燕（12 行）、プロデューサー（9）
- 场景：剧本没写明地点；接 017-01，是在玩那台竹刀动作游戏（0003、0004 制作人的心里话提到头目、游玩次数）
- 世界线：培育（雨夜燕）；制作人在制作的偶像：雨夜燕（剧本里没有直接说法）

## 发生了什么
她又被头目打败，但说已经记住它的动作，下次一定拿下（0001、0002）。制作人在心里想她在进步、但赢那个头目很难，已经玩了二十多次，要不要在陷进去之前叫停（0003、0004，制作人的心里话）。之后是几种并列的结局：她说来做个了断，赢了，得意地说自己认真起来这种程度不在话下，制作人心里觉得她一脸做成了的好表情、劝她玩是对的，她说照这个势头通关（0005～0011）；她说来做个了断，输了，制作人说这头目太强、这次就到这里吧，她同意，但说下次一定打倒它、让它洗好脖子等着（0012～0017）；制作人说连续游玩让她集中力快耗尽，再挑战也赢面很低，她说虽然不甘心但他说得对，这次先撤，下次一定赢（0018～0021）。

## 她的关键台词
- 0001「ま、またやられた……！」——屡败
- 0002「だが、奴の動きは覚えた！／次で仕留める！」——失败后立刻分析、再战
- 0006「か、勝った……！」——赢的那一刻
- 0008「ふっ、私が本気になれば、／この程度、造作もない！」——赢了就嘴硬地夸自己
- 0011「さあ、この調子でクリアするぞ！」——乘胜追击
- 0017「だが、次は必ず倒す！／首を洗って待っているがいい！」——输了不服、放狠话
- 0020「……悔しいが、／貴様の言うとおりだな。」——承认对方的判断
- 0021「今回はここで退こう。／だが、次は必ず勝つ！」——撤退但不认输

## 行为模式
- 屡次失败 → 不放弃，记住对手的动作再挑战（0001、0002、0005）
- 赢了 → 「ふっ」地说本气就不在话下，想继续推进（0008、0011）
- 输了或被劝停 → 接受当下停手，但一定宣言下次要赢（0016、0017、0021）
- 制作人用理由说明（集中力耗尽、胜率低）→ 不甘心但认同（0018～0020）

## 关系
- プロデューサー：她称对方「貴様」（0020）；制作人称她「雨夜さん」（0007、0015）。他在一旁陪着、适时叫停，她听从他的判断（0015、0016、0020）。

## 档案类事实
- 她挑战那台游戏的头目超过二十次（0004，制作人的心里话）。
