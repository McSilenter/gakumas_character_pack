# 雨夜燕 培育事件 001 activity / 018-02 挑战，百番赏！（adv_pevent_001_atbm_activity_018-02）

- 她的台词：10 行（含用匿名标签说的 0 行）
- 出场的人：燕（10 行）、プロデューサー（8）
- 场景：剧本没写明地点；接 018-01，在抽「くじ」（0001、0012）
- 世界线：培育（雨夜燕）；制作人在制作的偶像：雨夜燕（剧本里没有直接说法）

## 发生了什么
她和制作人都没抽中一等奖，她说不能就这样结束、再抽一次（0001～0003）。之后是几种并列的结局：她说「よく言った！」、叫制作人跟上，抽中了一等奖，说去领奖、让他在这里等，制作人心里想没想到她这么高兴、努力配合值得了（0004～0008）；她同样说「よく言った！」、叫他跟上，结果抽出五等、三等，没有一等，制作人那边也没有，抽签也卖完了，她喊「無念だ」，制作人说同感、下次赢回来（0009～0014）；制作人说再抽下去损失太大，她说“即使如此”还想坚持，被制作人叫了一声名字后，不甘心地说撤退（0015～0018）。

## 她的关键台词
- 0001「くっ！／一等は当たらなかったか！」——毫不掩饰想要一等奖
- 0003「このままでは終われん！／もう一度引くぞ！」——不服输、要再来
- 0004「よく言った！／ついてこい、プロデューサー！」——对制作人愿意陪她再抽的赞许（称他「プロデューサー」）
- 0005「あ、当たった……！／一等だ！」——中奖的惊喜
- 0007「景品をもらってくるから、／ここで待っていろ！」——兴奋地去领奖
- 0013「くっ……無念だ……！」——落空的不甘
- 0016「だが、それでも……！」——被劝停仍想坚持
- 0018「くっ……／無念だが撤退する……！」——最终接受撤退

## 行为模式
- 没抽中想要的东西 → 不认输、要再挑战（0001、0003）
- 制作人愿意一起 → 「よく言った！」、带头前进（0004、0009）
- 达成 → 兴奋，命令他等着自己去领（0005、0007）
- 被理性劝停 → 先抵抗，再以「無念だが撤退」接受（0016、0018）

## 关系
- プロデューサー：她这一话称他「プロデューサー」（0004、0009）；制作人称她「雨夜さん」（0006、0017）。他陪她一起抽，也在合适时叫停，她最终听从（0014～0018）。制作人在心里说努力配合有了回报（0008，制作人的心里话）。
- 与 018-01 相比：018-01 她嘴上说对奖品没兴趣（018-01 0009、0014），这一话她毫不掩饰地想要一等奖（0001、0003）。这是同一事件的前后两话，属同一条线，但不是说法矛盾，是她态度露底，不标冲突。

## 档案类事实
- 在一种结局里她抽中了「くじ」一等奖（0005）；另一种里只抽到五等、三等（0010）。

## 不确定
- 0004～0008、0009～0014、0015～0018 应是并列的几种结局；0004 与 0009 是同一句。「よく言った」前制作人说了什么（应是愿意一起再抽）剧本里没有。
