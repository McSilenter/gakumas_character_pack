# 雨夜燕 培育事件 001 activity / 020 饭团是什么口味？（adv_pevent_001_atbm_activity_020）

- 她的台词：12 行（含用匿名标签说的 0 行；0012 是括号里的心里话）
- 出场的人：燕（12 行）、プロデューサー（5）
- 场景：剧本没写明地点；能坐下来慢慢休息的地方（0001），制作人带了便当（0002）
- 世界线：培育（雨夜燕）；制作人在制作的偶像：雨夜燕（剧本里没有直接说法；0011 制作人说梅干有助消除疲劳）

## 发生了什么
她说这一带能放松，制作人拿出自备的便当请她吃，她说他还是周到得吓人（0001～0003）。之后是几种并列的反应：她看到饭团说以他来说是别致的心思，制作人说饮料也奢侈地用了玉露，她说真是无微不至，作为今天的回礼下次她来准备便当（0004～0008）；她说选梅子算他懂，正要说饭团和梅干两种和食文化融合，制作人却说梅干里的柠檬酸最适合消除疲劳，她在心里想这家伙真不会看气氛（0009～0012）；她说饭团的王道是梅或鲑，制作人请她“就当上当”吃一个，她说既然这么说就吃，吃完说不难吃，但饭团还是梅或鲑，制作人心里看她吃光了，觉得她应该喜欢（0013～0017）。

## 她的关键台词
- 0003「……相変わらず、不気味なくらいに／なんでも用意しているな。」——对制作人的周到半吐槽半佩服
- 0005「ほう、／貴様にしては洒落た趣向だな。」——夸奖时加「貴様にしては」
- 0007「至れり尽くせりだな。」——认可对方的款待
- 0008「今日の礼だ。今度は私が、／弁当を用意してやる。」——要回礼
- 0009「ふっ、梅を選ぶとは、／分かっているじゃないか。」——对梅子饭团的偏好
- 0010「お握りと梅干し。ふたつの和食文化が／融合し、さらなる高みに……」——对和食的讲究和夸张表述
- 0012「（……本当にこいつは、／空気が読めん男だな）」——心里吐槽制作人（心里话）
- 0013「……お握りといえば、／王道の梅か鮭だと思うが？」——对饭团的王道观
- 0016「……ふんっ！　不味くはないが、／やはりお握りは梅か鮭だな。」——吃完也不改口

## 行为模式
- 受到周到款待 → 嘴上说「不気味」，但认可并表示要回礼（0003、0007、0008）
- 谈到喜欢的和食 → 兴致高地展开讲究，被扫兴时心里吐槽（0010、0012）
- 面对不熟悉的口味 → 先坚持王道，被劝后接受尝试，吃完仍嘴硬（0013、0015、0016）

## 关系
- プロデューサー：她称对方「貴様」（0005），心里叫他「こいつ」（0012）。这一话她接受他的便当并说下次回请（0008）；对他不懂气氛心里吐槽（0012）。

## 档案类事实
- 饭团她认为王道是梅或鲑（0013、0016），对梅子饭团表示认可（0009）。
- 她说下次自己准备便当作为回礼（0008，打算）。
- 制作人准备了玉露（0006）。

## 不确定
- 0004～0008、0009～0012、0013～0017 应是选项后的并列反应；0004「このお握りは……」看到的饭团是什么口味剧本里没写。
- 0016 后制作人心里说她吃光了、应该喜欢（0017，制作人的心里话），她本人只说「不味くはない」。
