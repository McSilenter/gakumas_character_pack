# 雨夜燕 培育事件 001 school / 005 三座『白』城（adv_pevent_001_atbm_school_005）

- 她的台词：10 行（含用匿名标签说的 0 行；10 行全部是括号里的心里话）
- 出场的人：歴史教師（13 行）、燕（10）
- 场景：历史课上（0001～0003 歴史教師提问）
- 世界线：培育（雨夜燕）；制作人在制作的偶像：雨夜燕（剧本里没有直接说法；制作人不在场，0004 她想起和制作人聊过这个话题）

## 发生了什么
歴史教師在课上问被称为『白鷺城』的城叫什么，她在心里想起和制作人聊过这个话题（0001～0004）。她的回答剧本里没有，之后是三种并列的结果：答对姫路城，老师说明白漆喰的外观让人联想到白鷺，她心里高兴答对了，想着总有一天要亲眼去看（0005～0010）；答成上野城，老师说那是『白鳳城』、由藤堂高虎改修，她心里懊恼记错了，又想有机会一定去看那座藤堂高虎改修的城（0011～0016）；答成犬山城，老师说那是『白帝城』、云海时像浮在空中，她心里懊恼记错，又觉得很浪漫、一定要去看（0017～0023）。

## 她的关键台词
- 0004「（たしか、プロデューサーと／この話をしたな）」——想起和制作人聊过（心里话）
- 0008「（ふっ、正解できたな！）」——答对时心里得意（心里话）
- 0010「（いつか、実際に／見にいってみたいものだ）」——想亲眼去看（心里话）
- 0014「（くっ、間違えて覚えていたか）」——答错时心里懊恼（心里话）
- 0015「（それにしても、／あの藤堂高虎が改修した城か）」——对历史人物的兴趣（心里话）
- 0023「（なんとも浪漫があるな。／ぜひとも見てみたい！）」——被“浮在空中的城”打动（心里话）

## 行为模式
- 课上被问到 → 联想起和制作人聊过的话题（0004）
- 答对 → 心里「ふっ」地得意（0008）；答错 → 心里「くっ」地懊恼（0014、0021）
- 无论对错 → 都会被答案里的城本身吸引，想着有机会亲自去看（0010、0016、0023）

## 关系
- プロデューサー：不在场；她在心里想起和他聊过白鷺城的话题（0004）。

- 她和制作人聊过白鷺城的话题（0004）。
