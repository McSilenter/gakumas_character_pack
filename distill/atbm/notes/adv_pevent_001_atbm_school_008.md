# 雨夜燕 培育事件 001 school / 008 非正非负的数字（adv_pevent_001_atbm_school_008）

- 她的台词：9 行（含用匿名标签说的 0 行；9 行全部是括号里的心里话）
- 出场的人：数学教師（15 行）、燕（9）
- 场景：数学课上，做了很久计算题后的小问答（0001、0002）
- 世界线：培育（雨夜燕）；制作人在制作的偶像：雨夜燕（剧本里没有直接说法；制作人不在场，0005 她想起和制作人聊过这个话题）

## 发生了什么
数学教師出了个小问题：『0』是偶数还是奇数，她心里想起和制作人聊过这个，准备作答（0001～0006）。她的回答剧本里没有，之后是三种并列的结果：答对，老师说「さすがだな、雨夜」并说明 0 是 2 的倍数所以是偶数，她心里得意，想着下次也出给星南（0007～0013）；答错，老师说明定义，她心里说在擅长的科目答错是何等失态、要重新学（0014～0018）；答错（以为 0 非正非负所以不是偶数也不是奇数），她心里懊恼自己凭印象而不是定义作答，要重新学（0019～0024）。

## 她的关键台词
- 0005「（たしか、プロデューサーと／この話をしたな）」——想起和制作人聊过（心里话）
- 0011「（フッ、正解できたな！）」——答对时得意（心里话）
- 0013「（……今度、星南に出してやろう）」——想拿这题考星南（心里话）
- 0017「（くっ、得意教科の問題を／外すとは、なんたる失態……！）」——答错时对自己严格（心里话）
- 0018「（二度と間違えないように、／勉強しなおさなくては！）」——立刻决定补课（心里话）
- 0023「（偶数の定義ではなく、／イメージで答えてしまうとは……）」——反省自己凭印象作答（心里话）

## 行为模式
- 课上被问 → 联想起和制作人聊过的话题（0005）
- 答对 → 心里「フッ」地得意，并想拿去考朋友（0011、0013）
- 擅长科目答错 → 心里称之为「失態」，马上决心重学（0017、0018、0024）；会反省错误的原因（0023）

## 关系
- 数学教師：叫她「雨夜」，说「さすがだな」（0007）。
- 星南：她想下次把这题出给星南（0013），直呼「星南」。
- プロデューサー：不在场；她在心里想起和他聊过这个话题（0005）。

## 档案类事实
- 数学是她的「得意教科」（0017、0024）。
- 她和制作人聊过 0 是偶数还是奇数的话题（0005）。

## 不确定
- 她的回答本身剧本里没有，0007～0013、0014～0018、0019～0024 是按答案分开的三种结果。
- 本篇她的台词全部是心里话。
