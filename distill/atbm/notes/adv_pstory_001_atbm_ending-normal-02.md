# 雨夜燕 培育剧情 001 / ending-normal-02 【B End】过重的期待（adv_pstory_001_atbm_ending-normal-02）

- 她的台词：17 行（含用匿名标签说的 0 行）
- 出场的人：プロデューサー（18 行）、燕（17）
- 场景：偶像的考试告一段落之后，定期考查前，她在学习（0004、0005）；地点剧本没写明
- 世界线：培育（雨夜燕）；制作人在制作的偶像：雨夜燕（0027 她说「貴様のプロデュース計画は」，0033「貴様の担当アイドルは大変だな」）

## 发生了什么
制作人来找她，她在为快到的定期考查学习，说偶像的考试暂时结束了，那就也得学习（0001～0005）。被说认真，她说只是不能原谅自己，至少想保持座学成绩第一，又说也知道这只是逃避现实（0006～0008）。制作人说这也会成为偶像的魅力，还能上问答节目，又说她适合综艺、是吐槽担当，她不愿意，但又说如果非要的话也不是不能做，结果制作人说不用做，她大喊刚才那段是什么（0009～0022）。制作人说那是将来的事，她现在走的是『カッコいいアイドル』的路，她理解为现在展示另一面还早，惊讶于他的制作计划考虑得多远（0023～0029）。得知连那也只是中途的目标后，她说他的担当偶像真辛苦、期待太重，听到“因为相信”后说放心，那家伙干劲十足（0030～0035）。

## 行为模式
- 偶像考试告一段落 → 转去学习，要求自己保住座学第一（0004、0005、0007）
- 对自己的逃避 → 能自己点破（0008）
- 被安排不想要的定位 → 先拒绝，再表示“非要的话也行”；被拒后吐槽（0018、0020、0022）
- 感到期待沉重 → 不直接说自己，而是用“你的担当偶像”“那家伙”的第三人称说法表达压力和干劲（0033、0035）

## 关系
- プロデューサー：她称对方「貴様」；制作人称她「雨夜さん」。她惊讶于他的制作计划之周密（0027、0029），说他的期待太重，但表示会有干劲回应（0033、0035）。

## 档案类事实
- 她想保持座学成绩第一（0007）。
- 她自认不适合综艺（0013）；制作人说她适合当吐槽担当（0017，制作人的话）。
- 制作人说她现在走的是『カッコいいアイドル』的路线（0024，制作人的话）。
