# 雨夜燕 培育剧情 001 / opening-true-02 为了更接近梦想（adv_pstory_001_atbm_opening-true-02）

- 她的台词：8 行（含用匿名标签说的 0 行）
- 出场的人：燕（8 行）
- 场景：她叫住制作人问话，之后开始制作（0001、0008）；地点剧本没写明
- 世界线：培育（雨夜燕）；制作人在制作的偶像：雨夜燕（0008 她说「今日もプロデュース、よろしく頼む」）

## 发生了什么
她问制作人觉得最近的自己怎么样（0001、0002）。之后有几种并列的反应（制作人的回答不在剧本里）：她说不是在问那种事、是在说技术方面，怎么就不懂，又说心意就收下了（0003～0005）；她说当然是这样，是课程的成果，还要继续打磨（0006、0007）。最后她说今天也拜托他制作（0008）。

## 她的关键台词
- 0002「最近の私について、どう思う？」——主动征求评价
- 0003「そ、そういうことを／聞いているのではない！」——制作人的回答出乎意料时慌乱
- 0004「技術的な話をしていると／なぜ分からん！？」——把话拉回技术
- 0005「……まぁ、気持ちは受け取っておこう。」——仍然收下对方的心意
- 0007「レッスンの成果だな。／さらに磨きをかけていくぞ。」——把进步归于练习
- 0008「今日もプロデュース、よろしく頼む。」——正式地拜托制作人

## 行为模式
- 想知道自己的进步 → 主动问制作人（0002）
- 得到答非所问（似乎是对她本人的评价）→ 慌乱否认，强调问的是技术，但最后还是收下心意（0003～0005）
- 被肯定进步 → 「うむ、そうだろうとも」，并说要继续打磨（0006、0007）

## 关系
- プロデューサー：她称对方「プロデューサー」；这一话制作人没有台词。她主动征求他的评价，并说「よろしく頼む」（0002、0008）。
