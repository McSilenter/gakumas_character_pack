# P卡 秦谷美鈴【Campus mode!!】 / 第3话 Campus mode!! 第3话（adv_cidol-hmsz-3-005_03）

- 她的台词：26 行（含用匿名标签说的 0 行）
- 出场的人：美鈴、プロデューサー
- 场景：『N.I.A』优胜后的优胜 Live 开场前，能看见会场里的观众（0001、0006～0007、制作人 0017）
- 世界线：亲爱度（秦谷美鈴）·P卡；制作人在制作的偶像：秦谷美鈴

## 发生了什么
优胜 Live 就要开始，她说疲劳已经消除、状态万全，多亏制作人想尽办法。她看着会场说自己的粉丝有这么多；制作人说这不是第一次了吧，她说是第一次——不是『SyngUp!』的粉丝，而是只属于她的粉丝。制作人说里面也有『SyngUp!』、賀陽さん、月村さん的粉丝，今天还有在『N.I.A』被她打败的所有偶像的粉丝；她恍然，说最支持自己的人也不一定只支持自己。她说想让所有偶像粉丝只看着她，制作人说今天是绝好机会，她「はいっ！」，要用秦谷美鈴涂满会场所有偶像粉丝的心。她说制作人教过她要带着强烈的心意唱：『SyngUp!』唱『Campus mode!!』时怀着「わたしたち3人の歌で、／夢に向かって飛んでいこう」，今天不同——秦谷美鈴的『Campus mode!!』是「穏やかなる下剋上の歌」、追越太阳的飞翔之歌、让忘记梦想的人重新振作的「魔性の歌」，请会场的大家成为她的俘虏、一起飞。

## 行为模式
- 大舞台前 → 平静地说状态万全，把功劳归给制作人（0003～0004）
- 看到满场粉丝 → 感动于“只属于我的粉丝”（0007～0010）
- 被指出粉丝并非只支持她 → 立刻接受，转为“那就让所有人只看我”（0013～0021）
- 上台前 → 用一连串意象给自己的歌下定义，对观众说「わたしの虜に」（0028～0036）

## 关系
- プロデューサー：她叫「プロデューサー」「あなた」，制作人叫她「秦谷さん」。她说状态万全是他想尽办法的结果（0004），他教过她要带着强烈的心意唱（0027）。
- 『SyngUp!』、賀陽燐羽、月村手毬：制作人说会场里也有她们的粉丝（制作人 0011～0012）。『SyngUp!』唱『Campus mode!!』时的心意是「わたしたち3人の歌で」一起飞向梦想（0029～0030）。
- 粉丝：她第一次看到只属于自己的粉丝（0009～0010），想让所有偶像粉丝只看她（0021）。

## 档案类事实
- 她在『N.I.A』优胜，开优胜 Live（0001；制作人 0017）
- 她把这次当成第一次拥有只属于自己的粉丝（0009～0010）
- 『SyngUp!』唱『Campus mode!!』时怀着「わたしたち3人の歌で、／夢に向かって飛んでいこう」的心意（0029～0030）
- 她的个人版『Campus mode!!』：「穏やかなる下剋上の歌」「飛翔の歌」「魔性の歌」（0032～0034）
- 制作人教她要带着强烈的心意唱（0027）
