# P卡 秦谷美鈴【Star-mine】 / 第3话 Star-mine 第3话（adv_cidol-hmsz-3-010_03）

- 她的台词：37 行（含用匿名标签说的 0 行）
- 出场的人：美鈴、星南、佑芽
- 场景：接第2话，学生会的房间
- 世界线：亲爱度（秦谷美鈴）·P卡；制作人在制作的偶像：秦谷美鈴

## 发生了什么
误会解开，她向星南道歉，但请星南今后避免和她的制作人单独谈话——「大切な先輩を、／嫌いには……なりたくないんです」。星南羡慕制作人被担当偶像这么仰慕，她说他是最好的制作人，「誰にも……渡しません」。她问临时组合的成员，佑芽举手想和她组，她说会很开心；星南说也算上自己，成员就是这三人。星南问她意下如何，她沉默后说回答前要先道歉：星南以前问她为什么加入学生会，她现在回答——是想夺取学生会、当成『SyngUp!』的「たまり場」：自己是「不良」，需要睡得舒服的据点；进学生会也能制造和闹翻的朋友见面的理由；一边「ほどほど」地做会计监察，一边物色下任会长候选人、讨好对方，让对方把明年的干部任命权交给她。佑芽理解成“想让好朋友明年进学生会”，说很好，她说那佑芽当了会长就拜托了。她说自己是带着不纯的动机加入的，也小看了『一番星』十王星南，以为随时能赢；星南说隐约察觉到了。她说想法变了：学生会的大家都是出色的偶像、值得尊敬的前辈、不让她轻易赢的强敌，为小看大家道歉；如果被原谅，想参加临时组合，能和「初星学園の太陽」十王星南一起唱是「光栄です。とても」。三人组成临时组合，她说有种奇妙的「馴染む感覚」，请两人多关照，「ほどほどに、がんばりましょうね」。

## 行为模式
- 误会解开 → 道歉，但仍明确要求对方今后别和她的制作人单独相处（0002～0004）
- 被夸有个好制作人 → 「最高のプロデューサー」「誰にも……渡しません」（0008～0009）
- 要和人深入合作前 → 先坦白自己过去不纯的动机和对对方的轻视，再道歉（0023～0051）
- 坦白坏心眼 → 用平静的语气讲出“乗っ取って”“不良”“取り入って”，毫不掩饰（0030～0038）
- 承认对手强 → 用最高的敬语表达（「光栄です。とても」）（0053～0054）
- 加入新的团体 → 说「ほどほどに、がんばりましょう」（0060）

## 关系
- 十王星南：她称「星南会長」「星南先輩」（0028、0059）、「大切な先輩」（0004）、「初星学園の太陽」（0053）。她请星南别和她的制作人单独谈话（0003～0004）；坦白曾小看『一番星』十王星南，以为随时能赢（0045～0046），现在尊敬她（0049～0054）。星南说隐约察觉（星南 0047），把她的话当成「秦谷美鈴にとって最大の賛辞」（星南 0055）。
- 花海佑芽：她叫「佑芽さん」，佑芽叫她「美鈴ちゃん」。佑芽想和她组组合（佑芽 0012），她说会很开心（0013）；佑芽把她的阴谋理解成好意（佑芽 0041～0042），她说佑芽当会长时拜托了（0043）。
- プロデューサー：「最高のプロデューサー」「誰にも……渡しません」（0008～0009）。
- 学生会的成员：她说都是出色的偶像、值得尊敬的前辈、难对付的强敌（0048～0050）。
- 「仲違いした友達」：她进学生会时和朋友闹翻了，想借学生会制造见面理由（0034），没点名。

## 档案类事实
- 她在学生会担任「会計監査」（0036）
- 她加入学生会的动机：把学生会变成『SyngUp!』的据点、有睡得舒服的地方；制造和闹翻的朋友见面的理由；物色下任会长、拿到明年的干部任命权（0030～0038）
- 她自称「不良」（0033）
- 她曾小看『一番星』十王星南，以为随时能赢（0045～0046），现在改变了想法（0048～0051）
- 临时组合成员：她、星南、佑芽（星南 0017、0057）
- 星南被佑芽称为「学園一のアイドル」（佑芽 0019）

## 不确定
- 0034「仲違いした友達」：没点名，从前情推测是手毬或燐羽（或两人），本篇没写。
- 0045～0046「いつでも勝てるだろう」与亲爱度第26话 0027『尊敬する先輩』：P 卡这一篇的时间点看不出，她对星南的态度从轻视变为尊敬是在本篇；不同时间点的态度不同，不算冲突，记下供参考。
- 0058「馴染む感覚」：为什么觉得熟悉（像『SyngUp!』的三人？），她没说明。
- 第1话 0024 说她“加入学生会的事已经解决”，本篇的“以前星南问她为什么加入学生会”（0027）是什么时候，剧本没写。
