# P卡 秦谷美鈴【「我要说了哦。」】 / 第3话 「我要说了哦。」 第3话（adv_cidol-hmsz-3-020_03）

- 她的台词：34 行（含用匿名标签说的 0 行）
- 出场的人：美鈴、プロデューサー
- 场景：接第2话的合作广告拍摄，她穿着拍摄用的连衣裙来见制作人（0001～0004、0020）；地点看不出
- 世界线：亲爱度（秦谷美鈴）·P卡；制作人在制作的偶像：秦谷美鈴

## 发生了什么
她穿着拍摄用的衣服（连衣裙）来找制作人，说已经得到许可，问合不合适（0001～0004）。制作人说这衣服就是为她而生的，想做同样设计的 Live 衣装；她说有点太夸衣服了，但看得出这是他最高级的夸奖，就算了（0005～0008）。制作人说衣装能用作 Live 衣装的话看过广告的粉丝会高兴，她说想要配这件衣服的曲子，制作人说认真考虑（0009～0012）。她说宇宙第一美的偶像就在身边，他脑子里却总是制作，「妬けてしまいます」；制作人说着迷是因为那是她的制作，她「ふぅん」一声，再问一次：这件连衣裙是不是比泳装更适合她（0013～0021）。制作人内心觉得这是答错很危险的题，回答两件都最好、没法比；又问她为什么会有“自己不适合泳装”这种不可能的想法（0022～0028）。她长时间沉默后说「ここだけの話」：作为偶像她对自己的外貌有「そこそこ」的自信，但离她最近的偶像在她主观里有宇宙第一的迷人外貌，这是她唯一的「コンプレックス」（0029～0039）。制作人内心惊讶、并想对方大概也这样想她（0040～0041）。她说多亏他，这种想法淡了很多：不管和谁比、别人说什么、她自己怎么想，都有人相信秦谷美鈴才是最好的，挑战这份工作真好（0042～0047）。制作人说现在这一刻他不会输给专业摄影师，想拍一张，她说请拍下他「一番の被写体」（0048～0051）。

## 她的关键台词
- 0003「着てきちゃいました。／もちろん、許可はいただいています。」——穿着拍摄服装来给他看
- 0008「あなたにとって最上級の誉め言葉なのは／明らかなので……／まあ、いいとしましょう。」——读懂制作人的夸法
- 0014「宇宙一、美しいアイドルが／となりにいるのに……」——接用第2话制作人的话自称
- 0016「……妬けてしまいます。」——对他满脑子都是制作“吃醋”
- 0018「……………………ふぅん。」——不太满意的回应
- 0021「水着よりも……わたしに似合っていると／思いませんか？」——给制作人出难题
- 0030「ここだけの話ですよ。」——要说心里话前的铺垫
- 0032「自分の容姿にはそこそこの自信を／持っているんです。」——对外貌的自评
- 0035「わたしの主観では、それこそ宇宙一と／いっても過言ではないほどに……」——对身边那位偶像外貌的评价
- 0039「わたしにとって、唯一の……／コンプレックスです。」——她唯一的心结
- 0043「あなたのおかげで……／ずいぶん薄まりました。」——心结因制作人变淡
- 0046「秦谷美鈴こそが最高だと、／そう信じてくれる方がいる。」——被制作人信任的意义
- 0047「この仕事に挑戦して、よかったです。」——对这次工作的总结
- 0051「撮ってください。／あなたにとって、一番の被写体を。」——让制作人拍她

## 行为模式
- 穿上好看的衣服 → 主动来给制作人看、问合不合适（0003～0004）
- 制作人夸的是衣服 → 先挑剔一句，再体谅地接受（0007～0008）
- 制作人满脑子工作 → 说「妬けてしまいます」，然后出“答错就危险”的二选一题（0014～0021、0022～0023 制作人）
- 被问到心结 → 长时间沉默，先说「ここだけの話」，再坦白（0029～0039）
- 坦白心结后 → 不沉在里面，转为感谢对方让心结变淡（0042～0047）

## 关系
- プロデューサー：他叫她「秦谷さん」（0048）。她对他满脑子工作“吃醋”（0016）；向他坦白唯一的心结（0030～0039）；说多亏他心结变淡，有人相信秦谷美鈴是最好的（0043～0046）；让他拍「一番の被写体」（0051）。制作人内心说她偶尔会出答错很危险的题（0022～0023）。
- 「一番身近にいるアイドル」：她说在她主观里此人外貌是宇宙第一（0034～0036），是她唯一的心结（0039）；没点名。制作人内心猜对方也对她有类似想法（0041）。

## 档案类事实
- 她对自己的外貌有「そこそこ」的自信（0032）
- 她唯一的「コンプレックス」：离她最近的偶像外貌比她迷人（0034～0039）
- 她以为自己不适合泳装（制作人 0028 的说法）
- 制作人想做和这件衣服同样设计的 Live 衣装；她想要和衣服相配的曲子（0006、0011）

## 不确定
- 0034「一番身近にいるアイドル」没点名；在她的剧情里可能是手毬，本篇没说。
- 0003 的「その衣装」/0020「このワンピース」是不是广告拍摄用的衣服，剧本只说「許可はいただいています」，看起来是拍摄用的连衣裙。
- 【译文】0009「ライブ衣装に採用できたなら」译成“如果这套泳装能作为演出服装被采用”，原文没有“泳装”；她此时穿的是连衣裙（0020），要做成 Live 衣装的是这件衣服。
