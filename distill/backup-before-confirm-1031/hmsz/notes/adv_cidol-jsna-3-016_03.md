# P卡 十王星南【ENDLESS DANCE】/第3话 ENDLESS DANCE 第3话（adv_cidol-jsna-3-016_03）

- 她的台词：8 行（含用匿名标签说的 0 行）；『一同』0042 不计
- 出场的人：星南、佑芽、美鈴、プロデューサー、一同
- 场景：三人演唱会（『ENDLESS DANCE』）前的练习日；地点剧本没写
- 世界线：亲爱度（十王星南）·P卡；制作人在制作的偶像：十王星南（也是美鈴和佑芽的制作人，0025 星南称她们为「私の担当アイドルたち」），美鈴是配角

## 发生了什么
星南宣布下一场演出是星南、佑芽、美鈴三人的三人同台演出（スリーマンライブ），曲子是『ENDLESS DANCE』，并叮嘱美鈴这次要认真练习。美鈴称星南为「星南プロデューサー」，郑重保证在下次演出结束之前绝不翘练习。星南惊讶，美鈴和佑芽都说发生了很棒的事，要保密。然后两人说出之前星南向制作人讲过的句子，星南发现是制作人泄露的，制作人说想看她的表情。最后佑芽和美鈴一起拿星南的话开玩笑，星南说要接受严格的指导。

## 她的关键台词
- 0013「……星南プロデューサー。／言っておくことがあります。」——称星南为「星南プロデューサー」，以郑重的口吻开口
- 0015「お約束します――」——郑重的承诺
- 0016「次のライブが終わるまで、／決してレッスンをサボらないと。」——保证不翘练习（星南听了觉得不可能）
- 0019「まあ、ふふ……確かに言いましたよ。／レッスンをサボりませんと。」——被怀疑听错时笑着确认
- 0021「とても……いいことがあったんです。／……秘密ですが。」——不说原因，给出「秘密」
- 0022「ね、佑芽さん♪」——和佑芽一起保守秘密，两人默契
- 0028「ふふ……『マイペースを崩さないで／済むよう、環境を整えてあげるのも／……プロデューサーの仕事』。」——把星南向制作人说过的话（jsna-3-016_02 里的句子）原样说出来，并未解释
- 0039「『星々を統べる至高の／トップアイドル』が力になりますよ？」——反用星南对她的评价来调侃

## 行为模式
- 要作出承诺时 → 先改口称对方「星南プロデューサー」，再说「お約束します」（0013～0016）
- 被怀疑 → 笑着确认自己说过，不解释原因（0019、0021）
- 有两个人知道的秘密 → 和佑芽一唱一和（0021～0023）
- 取笑星南 → 引用对方的话，不加评论（0028、0039）

## 关系
- 星南：叫「星南プロデューサー」（0013）；星南叫「美鈴」（0012）
- 佑芽：叫「佑芽さん」（0022、0037）；佑芽叫「美鈴ちゃん」（0023）；两人共享一个秘密

## 档案类事实
- 美鈴一向会翘练习（星南 0012「美鈴もよ。お願いだから今回ばかりは、／真面目にレッスンをして頂戴。」，星南的话）
- 美鈴这次保证到演唱会结束之前不翘练习（0016）

## 不确定
- 0021「いいこと」是什么没说；0026、0028 她和佑芽说出了星南在 016_02 向制作人说过的话（016_02 里 0020～0021、0047 的句子），但她们怎么知道的，剧本里只有制作人 0032「教えてあげたら」，没有说具体怎么传达的。
- 0028 美鈴引用的「マイペースを崩さないで／済むよう、環境を整えてあげるのも／……プロデューサーの仕事」，在 jsna-3-016_02 0020～0021 是星南的原话，这里是她转述，不是她的主张。
