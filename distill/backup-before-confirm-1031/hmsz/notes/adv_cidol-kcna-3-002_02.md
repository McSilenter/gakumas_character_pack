# P卡 倉本千奈【变装狂想曲】/第2话 变装狂想曲 第2话（adv_cidol-kcna-3-002_02）

- 她的台词：4 行（含用匿名标签说的 0 行）；『一同』0004 不计
- 出场的人：千奈、佑芽、広、美鈴、プロデューサー、手毬、一同
- 场景：千奈家（倉本家）举办的万圣节练习派对，示范演出之前
- 世界线：亲爱度（倉本千奈）·P卡；制作人在制作的偶像：倉本千奈，美鈴是配角

## 发生了什么
千奈邀请大家到家里举办万圣节练习派对，美鈴称赞千奈的服装很合适。千奈请大家给演出提建议，美鈴说今天可能有比自己更合适的人。広和佑芽说制作人提到会有厉害的艺术家做示范，大家猜是星南或制作人本人。制作人宣布惊喜嘉宾登场，来的是手毬，手毬说既然接了工作，就会让所有人享受。美鈴在手毬出场前说自己开始紧张了。

## 她的关键台词
- 0008「ふふ……素敵な衣装ですね。／とっても似合っていますよ。」——先夸千奈的服装，称赞直接、语气温和
- 0012「もちろん。／ですが……今日に限っては、」——被请求提建议时，先答应，再留余地
- 0013「わたしよりも適任が／いるかもしれません。」——不自夸，暗示今天有更合适的人
- 0032「ふふ……どきどきしてきました。」——在示范演出开始前说自己紧张起来

## 行为模式
- 被请求提建议 → 先说「もちろん」，再说今天可能有比自己更适合的人（0012、0013）
- 别人在猜谁是嘉宾 → 不加入猜测，直到登场前才说「どきどき」（0032）
- 见到别人的新打扮 → 首先夸，并用「似合っていますよ」确认（0008）

## 关系
- 千奈：千奈叫她「秦谷さん」（0009、0015）；她没有直接叫千奈的名字
- 手毬：本篇她与手毬没有对话；手毬登场在 0037，她事先说有更合适的人（0013）指的是谁，剧本没写
