# 秦谷美鈴 亲爱度剧情 / 第15话（adv_dear_hmsz_015）

- 她的台词：32 行（含用匿名标签说的 0 行）
- 出场的人：美鈴、プロデューサー、佑芽、千奈
- 场景：和燐羽的对决（选拔）临近，她和制作人开作战会议（0001～0004、0011～0012）；地点看不出
- 世界线：亲爱度（秦谷美鈴）；制作人在制作的偶像：秦谷美鈴

## 发生了什么
和燐羽的对决临近，制作人说要开会，她笑他这次也成了「のんびり屋さん」，像担当偶像了；制作人说秦谷美鈴的制作就该悠闲。她泡上茶，“慢慢地”开始作战会议。制作人报告她的『N.I.A』排名稳步上升（选拔获胜、官方粉丝俱乐部成立），她说「意外とがんばっていたんですね、／わたしたち」。但排名第一的是燐羽：在極月学園的宣传攻势下，燐羽在选拔中接连压倒性获胜，被称为『初星潰し』，她的朋友（佑芽）也被打败了，下一个目标就是她。被问能不能赢，她笑说不知道，因为很久没看过燐羽认真唱歌了；燐羽不止于此，她是『SyngUp!』里最早实现梦想的「わたしたちの太陽」，她不许任何人、包括制作人小看燐羽。她最后一次看燐羽认真唱歌是中等部一年级末；如果对手是那时的燐羽，会是「きわどい勝負」。制作人说现在的她赢不了的话顶级偶像也赢不了，她说他会说话，请他提心吊胆地看着「秦谷美鈴の……下剋上」。

## 行为模式
- 制作人难得悠闲 → 调侃他像担当偶像（0005～0007）
- 开会、谈正事 → 先泡茶，「ゆるりと」开始（0011～0012）
- 听到对手（燐羽）强大 → 「あらあら」「すごいですね」，不慌，先称赞（0021）
- 被问胜算 → 笑着说不知道，理由是没见过对方的全力（0034～0036）
- 有人（即使是制作人）可能小看旧队友 → 明确说「許しません」（0040）
- 面对真正的强敌 → 不说大话，坦白「必勝をお約束できません」，请制作人看着自己挑战（0053～0055）
- 被夸 → 「まあ……お上手ですね」（0051）

## 关系
- 賀陽燐羽：她叫「りんちゃん」（0021）、「賀陽燐羽」（0012、0038）、「あの子」（0035）。燐羽现在『N.I.A』排名第一（0020）。她说燐羽是『SyngUp!』里最早实现梦想的「わたしたちの太陽」（0038～0039），不许别人小看她（0040）；最后一次看燐羽认真唱歌是中等部一年级末（0042）。这次对决是她先挑战的（0032），她视为「下剋上」（0055）。
- プロデューサー：她叫「プロデューサー」，调侃他像自己（0007）；制作人说「のんびりがいいんです。／秦谷美鈴のプロデュースは」（0009）。她请他提心吊胆地看着自己（0054），这和第13话 0020 她对手毬说的『ハラハラしながら、／見守っていますね』用词相同。
- 花海佑芽：她称为「わたしのお友達」（0027），被燐羽打败（0028、0030）。

## 档案类事实
- 『N.I.A』排名稳步上升：选拔获胜、官方粉丝俱乐部成立（0013～0016，制作人说的）
- 燐羽现在『N.I.A』排名第一，被称为『初星潰し』，打败了好几个初星偶像（0020～0026）
- 佑芽被燐羽打败（0027～0030）
- 她最后一次看燐羽认真唱歌是中等部一年级末（0042）

## 不确定

- 0039「一番最初に自分の夢を叶えた」：燐羽实现了什么梦想，本篇没写。
- 0036、0042：她说燐羽从中等部一年级末起就没认真唱过，原因本篇没写。
