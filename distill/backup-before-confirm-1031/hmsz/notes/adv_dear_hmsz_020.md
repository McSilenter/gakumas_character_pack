# 秦谷美鈴 亲爱度剧情 / 第20话（adv_dear_hmsz_020）

- 她的台词：32 行（含用匿名标签说的 0 行）
- 出场的人：美鈴、燐羽、手毬、プロデューサー
- 场景：她的优胜 Live 结束、『N.I.A』落幕之后（0001～0002）；学园借给制作人的教室（0017、0051）
- 世界线：亲爱度（秦谷美鈴）；制作人在制作的偶像：秦谷美鈴

## 发生了什么
『N.I.A』以她的优胜 Live 落幕。她用「ごきげんよう」问候制作人，说『N.I.A』是很好的大会，离梦想的地方近了一大步。正要开总结会时，手毬和燐羽也在教室里，燐羽宣布这里从今天起是元『SyngUp!』的据点。她高兴地说两人和好了，燐羽说一点都没有，只是把不当偶像的事稍稍推迟；手毬得意自己赢了燐羽，她劝手毬：超过一个“阴了的太阳”没什么好炫耀的，真正的下克上要让燐羽再升到「わたしたちが憧れた……遥か高み」。燐羽说她和制作人下次要参加『H.I.F』，自己要“妨碍”——方法是在極月学園训练手毬；手毬高兴地答应，她「むぅっ」地不快，燐羽说就是想看这张脸。两人走后，她替“我的伙伴们”向制作人道歉，说会收拾教室，并感谢制作人的一切：这次的制作、手毬的事、安排和燐羽谈话的机会。制作人说约好了要帮她舒适地走，她说一直和他一起悠闲地、慢慢地走上来了。制作人说『一番星』的光渐渐看得见了，她说那位让她们立志当偶像的、像太阳的歌姬也被称作『一番星』，制作人说是燐羽的姐姐；她说那人引退后大家的憧憬转到燐羽身上，燐羽受伤改变了，但她以为大家的关系会一直持续，现在终于明白：走不同的路，也仍是伙伴。她说『一番星』对她们是特别的称号，一定要献给制作人；制作人说『H.I.F』会更激烈，她说「はい、期待されました」，让他准备好一起打哈欠。

## 行为模式
- 手毬炫耀赢了燐羽 → 「いけませんよ」劝阻，把话题引向让燐羽恢复（0028～0031）
- 燐羽挑衅 → 「まあ」从容反问（0037）
- 手毬被燐羽带走、高兴地和燐羽亲近 → 不说话，只「むぅっ」地不高兴（0045）
- 伙伴们给制作人添麻烦 → 替她们道歉，主动收拾（0052～0053）
- 被帮了很多 → 一件件说出来郑重道谢（0054～0058）
- 被期待 → 「はい、期待されました」，用自己的方式回应，结尾回到“悠闲”（0079～0080）

## 关系
- 月村手毬：她叫「まりちゃん」（0028、0057）。手毬炫耀赢了燐羽，她劝阻（0028～0031），手毬接受（手毬 0032）。手毬答应去極月学園接受燐羽的特训，她不高兴（0045）。
- 賀陽燐羽：她叫「りんちゃん」（0058）、「燐羽」（0069～0070）、「あなた」（0037）；燐羽叫她「美鈴」（燐羽 0035、0047）。燐羽说没和好、只是推迟不当偶像（燐羽 0020～0021），要在『H.I.F』“妨碍”她——训练手毬（燐羽 0036～0038），燐羽说想看她不快的表情（燐羽 0046）。她称燐羽为「陰った太陽」，要燐羽重新升起（0029～0031）；说燐羽在大家的憧憬转到她身上后受伤、改变了（0069～0070）。
- 『SyngUp!』：她称手毬和燐羽为「わたしの仲間たち」（0052），说走不同的路仍是伙伴（0074）。燐羽说这间教室成了元『SyngUp!』的据点（燐羽 0017）。
- プロデューサー：她叫「プロデューサー」「あなた」，感谢他的一切（0054～0058），说和他一起悠闲地走了上来（0061～0063），要把『一番星』献给他（0076）。制作人叫她「秦谷さん」。
- 燐羽的姐姐（本篇没写名字）：「あの太陽のような歌姫」，被称作『一番星』，是她们立志当偶像的契机，后来不当偶像了（0066～0069；制作人 0068 说是燐羽的姐姐）。

## 档案类事实
- 在『N.I.A』优胜，办了优胜 Live（0001、0005）
- 下一个目标是『H.I.F』（燐羽 0035；制作人 0077）
- 她们立志当偶像的契机是一位像太阳的歌姬，被称作『一番星』，是燐羽的姐姐，后来不当偶像了（0066～0069）
- 那位歌姬引退后，「わたしたちの憧れ」转到燐羽身上，燐羽因此受伤、改变（0069～0070）
- 学园借给制作人的教室，被燐羽宣布为元『SyngUp!』的据点（燐羽 0017；制作人 0051）
- 想把『一番星』的称号献给制作人（0075～0076）

## 不确定
- 0066～0069：那位歌姬的名字本篇没写，只由制作人说是燐羽的姐姐。（手毬 conflicts.md 6、8f 的结论是手毬当偶像的契机就是賀陽継、継应当就是燐羽的姐姐，本篇和它不矛盾，但本篇自己没点名。）
- 0069「わたしたちの憧れは燐羽に移り」与第10话 0043～0044『いえ……憧れた、と、／思い込んでいたんです。』『あれは憧れではなかったと思います。』：第10话她说自己对那位偶像其实不是憧憬（而是不甘心），本篇她用「わたしたち」说“我们的憧憬”转到了燐羽身上。「わたしたち」是否包括她自己、两种说法是否对得上，请确认（我没有标成冲突，因为“我们”可能只是笼统地说『SyngUp!』）。
- 0031「わたしたちが憧れた……遥か高み」：按手毬 conflicts.md 8n 的结论，第23话 0020 的「私たち」是『SyngUp!』；本篇这里没点名，从上下文看也是三人，但本篇没写明。
- 0070「燐羽は傷つき」：燐羽怎么受伤的，本篇没写（第16话 0058～0065 有她对燐羽烦恼的说法）。
- 【译文】0076「あなたにきっと、／捧げてみせます」：原文是“献给您”，译文写成“夺回来给您看”，多了“夺回”的意思。
