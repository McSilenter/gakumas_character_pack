# 秦谷美鈴 亲爱度剧情 / 第28话（adv_dear_hmsz_028）

- 她的台词：31 行（含用匿名标签说的 0 行）；另有『一同』齐声 1 行（0047），未计入
- 出场的人：美鈴、プロデューサー、手毬
- 场景：夏季『H.I.F』之后，为（冬季）『H.I.F』开的会议，她泡茶招待（0003～0005、0020、0037）；地点看不出
- 世界线：亲爱度（秦谷美鈴）；制作人在制作的偶像：秦谷美鈴（制作人 0010「俺の担当アイドルは、／秦谷美鈴ただひとりです」）

## 发生了什么
她说是午睡的好天气，制作人要开『H.I.F』会议，她高兴地泡茶，拿出手毬最爱的豆沙包，手毬说重要时期不吃。制作人对手毬说制作她只是暂时的，担当只有秦谷美鈴一人，照顾手毬是因为美鈴需要状态万全的手毬；她说「困ったひと」，转头向手毬炫耀制作人这么喜欢她。制作人说夏季『H.I.F』十王星南三连冠、已被称为顶级偶像，不超越她就——她接上「『一番星』にはなれません」，称星南是「お邪魔な先輩」。她说方针无非是『選抜試験』赢、本战赢，想直接午睡，被制作人拦住；制作人自夸能制作她很了不起，她「えらい、えらい」地夸他。制作人说受不了世间认为她和手毬不及星南，三人齐声说出「早く復讐しましょう」。她认为在『H.I.F』大舞台上当着全校学生击败星南最解气；制作人提议复仇分两步，第一步效仿星南与传说偶像共演、在头衔上和星南并列。她先说「素敵な方針」，随即「お断りします」：她发誓要献上『一番星』、实现制作人让她成为顶级偶像的梦想，要在『H.I.F』一次实现才浪漫，而且那种做法成不了顶级偶像。手毬赞同，要制作人「美鈴のために」重新做计划，她请制作人为她「たくさん悩んで」。

## 行为模式
- 开会 → 先说是午睡的好天气，但对会议也「心躍る」，主动泡茶、拿点心（0001、0004～0005）
- 制作人说担当只有她 → 「困ったひと」，转向手毬炫耀被喜欢（0014～0016）
- 方针显而易见 → 一句话总结，提议午睡，抗拒额外的事（0027～0032）
- 制作人自夸 → 用「えらい、えらい」哄他（0035）
- 制作人的提案不合她的心意 → 先称赞再干脆拒绝，用对他的誓言和「ロマンチック」作理由，再补一个实际理由（0059～0069）
- 拒绝后 → 不自己出方案，请制作人「たくさん悩んで」（0073）

## 关系
- プロデューサー：她叫「プロデューサー」「あなた」，制作人叫她「秦谷さん」。制作人说担当只有她（制作人 0010～0013），她向手毬炫耀（0016）。她说曾向他发誓献上『一番星』、实现他让秦谷美鈴成为顶级偶像的梦想（0062～0064）；拒绝他的方案，让他「たくさん悩んで」（0073）。
- 月村手毬：她叫「まりちゃん」，手毬叫她「美鈴」（手毬 0044、0070）。她给手毬准备最爱的豆沙包（0005），向手毬炫耀制作人（0015～0016）。手毬说制作人「美鈴みたいなこと言ってる」（手毬 0044），并支持她拒绝方案，要制作人「美鈴のために」重订计划（手毬 0070～0071）。
- 十王星南：她叫「星南会長」（0056）、「お邪魔な先輩」（0022）。星南夏季『H.I.F』三连冠（制作人 0020），通过与传说偶像共演被称为顶级偶像（0056）。三人要向她「復讐」（0047）。
