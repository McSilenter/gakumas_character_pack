# 倉本千奈 亲爱度剧情 / 第24话（adv_dear_kcna_024）

- 她的台词：7 行（含用匿名标签说的 0 行）；0070「一同」不算她的
- 出场的人：千奈、香名江、プロデューサー、広、佑芽、美鈴
- 场景：初星学园，千奈为生徒会选举集合同伴；之后是在一起的介绍
- 世界线：亲爱度（倉本千奈）；制作人在制作的偶像：千奈（0017～0019，千奈称他为「先生」）

## 发生了什么
香名江建议千奈以刘邦的三杰为模板集合不同类型的同伴。千奈先找了广、佑芽，都答应。接着邀请美鈴，美鈴说很光荣，但有条件：千奈当上生徒会长后，把生徒会的人事权交给她。千奈猜她想让朋友进生徒会，便答应。千奈向香名江和制作人介绍同伴，广、佑芽、美鈴各说了自己的角色，美鈴自称「項羽」。

## 她的关键台词
- 0047「まあ……ふふ……次期生徒会長候補の／倉本さんに誘っていただけるなんて。」——被邀请时用郑重的话回应
- 0048「とても光栄です。ただ、／ひとつだけ……条件があるんです。」——先礼貌接受，再提条件
- 0049「生徒会メンバーを選定・任命する／権利は、生徒会長にあるそうですね。」——先确认规则，再提出要求
- 0050「倉本さんが生徒会長になったら、／生徒会の人事権をわたしにください。」——条件是人事权
- 0051「そうしてくれたなら、秦谷美鈴は……／倉本千奈会長に、忠誠を誓います。」——以「忠诚」换人事权，说得郑重
- 0056「ありがとうございます。／……約束ですよ。」——得到答应后追加一句「约束」
- 0062「倉本千奈次期会長に忠誠を誓った、／初星学園の項羽・秦谷美鈴です。」——被要求自我介绍时顺着千奈的三杰玩笑，称自己是「項羽」

## 行为模式
- 受邀 → 先称谢、说光荣，再提出一个具体条件（0047、0048）
- 提条件前 → 先确认规则或权限再要（0049、0050）
- 对方答应 → 用「約束ですよ」把口头答应固定下来（0056）
- 顺着对方设定的比喻 → 给自己找一个角色，并加上「忠誠を誓った」说法（0062）

## 关系
- 千奈：称「倉本さん」（0047、0050）、「倉本千奈会長」（0051）；千奈称她「秦谷さん」（0046）
- 広、佑芽：同为千奈的仲间（0058）；对她们没有直接对话
- 香名江：香名江称「秦谷」没有出现，只在 0065 对「個性的な臣下」做整体评价

## 档案类事实
- 要求生徒会的人事权（0050）
- 这条线里她成为千奈选举阵营的一员（0058、0059，千奈的话）
