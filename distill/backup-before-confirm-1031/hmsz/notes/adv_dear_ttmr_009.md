# 月村手毬 亲爱度剧情 / 第9话（adv_dear_ttmr_009）

- 她的台词：26 行（含用匿名标签说的 0 行）；其中「一同」0066、0067 两行照手毬笔记的已确认结论算她（手毬和美鈴两人）
- 出场的人：手毬、美鈴、プロデューサー、一同
- 场景：手毬的演出（打赌那一场）之后，手毬与美鈴在会场的见面；0001～0030 是演出前后手毬与制作人的对话，她不在场
- 世界线：亲爱度（月村手毬）；制作人在制作的偶像：手毬

## 发生了什么
手毬的演出结束，美鈴出现，说完全不能安心，担心得提心吊胆。她问制作人有没有想法，制作人说胃都要被拧断。她沉默之后说看明白了，那份全力就是手毬的步调。她为之前给手毬带来的不自由道歉，两人和好，并承认已经不能一起唱歌。两人互相数落对方，最后「一同」说でも――楽しかった。美鈴把「大切な仲間」交给制作人，说怕她飞得太高会自毁，制作人说愿意一起走到破灭，美鈴更不安，问手毬真的是这个人吗。

## 她的关键台词
- 0031「まりちゃん！」——一看到手毬就喊她的名字
- 0034「ちっとも安心できません！　／すごくハラハラしました！」——直接说完全不能安心，比平时的语气激烈
- 0035「わたし……まりちゃんが／倒れちゃうんじゃないかって……」——说出具体的担心
- 0046「……あれが……あの全力が……／まりちゃんのマイペースなんですね。」——看懂了手毬的「步调」就是拼命
- 0048「ごめんなさい。／わたしたちは、ずっと……」——为过去道歉，说「わたしたち」
- 0049「あなたに不自由な思いを／させてしまっていた。」——承认自己和同伴曾经让手毬不自由
- 0052「仲直り、してくれますか？」——直接问是否和好
- 0054「わたしたち……／もう、一緒には、歌えないんですね。」——接受不能再同台的事实
- 0057「甘えても、いいと思います。」——对手毬「怕被宠」说出自己的看法
- 0063「気持ちを伝えるのが下手で、／いつも先走って、空回りして……」——列举手毬让自己困扰的地方，对称于手毬的数落
- 0066「でも――」——（「一同」，已确认算她）与手毬同声说出，承认互相给对方添了麻烦之后的转折
- 0067「楽しかった。」——（「一同」，已确认算她）与手毬同声说出，两人对以前时光的共同结论
- 0069「わたしの大切な仲間は、鳥籠を壊して、／飛んでいってしまいました。」——用比喻说手毬已经离开
- 0072「あなたに託しても、よろしいですか？」——把手毬交给制作人
- 0077「……まりちゃん、／本当に……この人でいいんですか？」——听了制作人的话之后向手毬确认

## 行为模式
- 看到别人的拼命 → 先激烈地说不能安心，然后自己思考，接受对方的做法（0034～0046）
- 道歉与和好 → 先说「ごめんなさい」，把责任说成「わたしたち」，再问「仲直り」（0048～0052）
- 被手毬说「怕被宠」 → 仍然说甘えてもいい，被指出「そういうところ」（0057、0058）
- 被数落 → 同样回敬一长串手毬的缺点，再两人一起说「楽しかった」（0062～0067）
- 把重要的人托付给别人 → 用比喻说明担心，然后问托付给你也可以吗（0069～0072）
- 听到过分认真的承诺 → 更不安，转而向手毬确认（0076、0077）

## 关系
- 手毬：称「まりちゃん」（0031、0046、0077）；手毬称「美鈴」（0032）；两人在这篇和好（0050～0053）
- プロデューサー：称「プロデューサー」（0037、0068），把手毬托付给他（0072）；制作人回答「一緒に破滅するところまで」（0074），她反应是更不安（0076）
