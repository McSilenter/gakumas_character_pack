# 活动 013 3年级1班的修学旅行 / main-05 第5话（adv_event_013_main-05）

- 她的台词：1 行（含用匿名标签说的 0 行）
- 出场的人：星南、燕、莉波、麻央、千奈、美鈴（「一同」0080 不计）
- 场景：3年1班修学旅行中（活动名），星南在旅行途中打电话给留在学园的千奈、美鈴，后半是旅行中的神社、土产店；美鈴只在电话里出现。
- 世界线：活动 013；制作人在制作的偶像：看不出。星南称自己是"みんなのプロデューサー"（0006），管理生徒会的一年级生（0024）。

## 发生了什么
星南旅行中把生徒会的事交给千奈，说要亲自给佑芽和美鈴打电话，因为她要亲眼看着每一个人。她接着打给美鈴，询问美鈴今天的课程，美鈴接起电话，说着"おはようございます、会長。ふぁ……"，星南察觉她又在午睡。后半是星南和燕、莉波、麻央在土产店和神社的对话，内容与美鈴无关。

## 她的关键台词
- 0008「…………おはようございます、会長。／ふぁ……」——接起星南的电话，长长的停顿之后先说"早安"，随后打哈欠；星南当即听出她在睡午觉

## 行为模式
- 被来电叫醒 → 沉默片刻，用早安问候，没有找借口（0008）

## 关系
- 星南：叫「会長」（0008）；星南叫「美鈴」，说她"またお昼寝してたわね"（0009）。星南把美鈴当作自己制作的对象，要"ひとりひとりを、しっかり見たい"（0006、0007）。

## 档案类事实
- 美鈴在这条线里属于星南制作的生徒会一年级生（星南 0006、0007、0024），经常午睡（星南 0009「また」）。
