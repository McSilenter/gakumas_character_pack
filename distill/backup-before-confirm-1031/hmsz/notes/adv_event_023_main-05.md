- 她的台词：18 行（含用匿名标签说的 0 行）：0005、0009、0012、0013、0026、0028、0031、0032、0033、0035、0036、0037、0039、0043、0045、0047、0050、0051（其中 0031 是无字的沉默「――――」）

- 场景：美鈴的生日当天，学园内；先是佑芽、千奈、広送礼物，手毬在门外等，再进去送礼物，最后広和美鈴换地方谈

## 发生了什么
佑芽、千奈、広为美鈴庆生，送上枕头，美鈴说自己是软枕派，大家猜对了。手毬紧张地站在外面，被広鼓励后进去，送上自己唱生日歌和摇篮曲的CD。美鈴沉默片刻，然后说「夢が……叶いました」，会在睡前反复听，手毬吐槽希望她听了快点睡。之后美鈴把広叫到别处，広递交「报告书」，说自己是「だぶる・すぱい」，美鈴说计划很顺利，向广道谢。

## 她的关键台词
- 0005「皆さん、ありがとうございます。」——被祝贺时的招呼，对一群人用敬语
- 0013「やわらかめ派です。」——回答枕头偏好：软枕
- 0028「…………これは、CD？」——拆开礼物时的反应
- 0032「まりちゃんが……／わたしのためだけに……」——说出自己被触动的点：手毬只为自己
- 0033「子守歌を歌ってくれて……／しかも、それをCDにしてくれた……？」——不敢相信地确认
- 0035「とってもっ！」——紧接着爆发的喜悦，句子被截断
- 0037「……夢が……叶いました。」——对礼物的评价：梦想实现了
- 0039「寝る前には必ず聴きますね。／何度も、何度も。」——说要睡前反复听
- 0043「ありがとうございます。／一生忘れられない誕生日になりました。」——对手毬的总结
- 0050「ふふ……うまくいきましたね。」——和広单独谈话时，说计划进展顺利
- 0051「篠澤さん。／あらためて、あなたに感謝を。」——郑重向広道谢

## 行为模式
- 被很多人同时祝贺 → 礼貌简短地道谢，对猜枕头偏好的玩笑表示感兴趣（0005、0009）
- 手毬送出自己想要的东西 → 先沉默，再重复确认对方为自己做了什么，然后喜悦爆发（0031～0037）
- 对方吐槽她 → 不退让，继续说自己的用法（反复听），之后用「一生忘れられない」收尾（0039、0043）
- 和广单独谈时 → 变得像共谋者，语气轻松，说「うまくいきましたね」（0050）

## 关系
- 手毬：称「まりちゃん」（0032）；手毬称她「美鈴」；手毬为她制作CD，她说「夢が……叶いました」
- 広：称「篠澤さん」；広称她「美鈴」，两人在 0049～0054 表现为配合的「だぶる・すぱい」，美鈴向广道谢
