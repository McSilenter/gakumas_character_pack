# 活动 025 / main-01 第1话（adv_event_025_main-01）

- 她的台词：6 行（含用匿名标签说的 0 行）：0005、0027、0030、0038、0040、0042（其中 0005、0040 是无字的沉默「………」）
- 出场的人：燕、莉波、千奈、佑芽、星南、美鈴（一同 0051 齐声，不计）
- 场景：学生会室，第一次学生会工作进度确认会议（0002）
- 世界线：活动 025；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
莉波召开第一次学生会进度确认会议，燕逐一检查。佑芽没回收文件，千奈说是因为佑芽在帮自己。轮到美鈴，燕问会计资料和预算分配，美鈴说读过了、已汇总。燕发现里面有午睡经费，美鈴说被发现了；莉波解释自己拜托美鈴先整理别的资料。燕责备她随便应付，她说是认真的，之后燕说会议后要给她灌输预算的重要性，她说「期待」。最后燕担心毕业后的学生会，千奈宣称三人会消除大家的疑虑。

## 她的关键台词
- 0027「資料は一読いたしました。／配分についてまとめてあります。」——被燕问有没有看资料时，交代已读且已汇总，说明她在做事
- 0030「まあ、ばれてしまいましたか。」——被发现预算里的午睡经费后的反应，没有慌张，也没有道歉
- 0038「適当ではありません。本気です。」——被说随便应付，明确说是认真的
- 0042「ふふ。楽しみです。」——被威胁要受预算教育时，笑着说期待

## 行为模式
- 被追问做了什么 → 简洁交代已做的部分，有条理（0027）
- 做了出格的事被发现 → 说被发现了，不否认也不辩解，之后坚持我是认真的（0030、0038）
- 被说教、被威胁 → 沉默一下，再笑着说「期待」（0040、0042）

## 关系
- 燕：燕称她「秦谷」（0024、0037）；她对燕的训斥不顶嘴，会用笑来化解
- 莉波：莉波称「美鈴ちゃん」，替她解释她被拜托去整理其他资料，也说她「忙しいのに」读了资料（0031～0036）
- 佑芽、千奈：本篇没有直接对话
- 星南：本篇没有直接对话

## 档案类事实
- 她在学生会里负责预算分配的计划，已读姬崎准备的会计资料，并整理了分配方案（0025～0027）
- 她把午睡经费放进预算分配里（0029、0030）
- 莉波事先拜托她整理其他资料（0032）

## 不确定
- 0038「本気です」：指午睡经费是认真的，还是指整份分配是认真的，本篇没明确；0037 燕说的「適当に見繕う」指的是什么应该是那份预算
- 0005 的沉默：与其他三人同样沉默，原因没写（气氛紧张的会议开场）
