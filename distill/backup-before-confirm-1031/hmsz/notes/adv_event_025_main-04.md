# 活动 025 / main-04 第4话（adv_event_025_main-04）

- 她的台词：10 行（含用匿名标签说的 0 行）：0007、0011、0023、0025、0026、0028、0033、0040、0047、0063（一同 0030、0034、0035、0066、0071 齐声，不计）
- 出场的人：千奈、佑芽、美鈴、星南、莉波、燕
- 场景：休息日，一年级三人为前辈们举办的答谢派对（厨房使用许可已取得，0008），先汇报工作改善，再办章鱼烧派对
- 世界线：活动 025；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
千奈邀请星南、莉波、燕，燕对派对有戒心，美鈴请她不要那么警惕。三人先汇报业务改善，演示新的偶像专用日程APP。燕说美鈴竟然会帮别人的工作，美鈴说如果是为了支持信赖的会长，那对她来说不是工作，而是兴趣。随后大家一起向前辈道谢，宣布办章鱼烧派对，是美鈴的主意，各种馅料依前辈们的喜好准备。燕被劝着夸了一句「よくやったな」，千奈开始烤章鱼烧。

## 她的关键台词
- 0007「そんなに警戒しないでください。」——对燕的戒备，用一句话轻轻挡回去
- 0023「お互い、助け合って進められます。」——介绍日程APP的好处，强调互相帮助
- 0025「信頼する会長を支えるためであれば、／それはわたしにとって仕事ではなく、」——说明自己愿意帮别人的工作的理由：为了信赖的会长
- 0026「趣味のようなものです。／ほどほどにがんばりますよ。」——把支持千奈说成兴趣，同时保留「ほどほど」
- 0028「生徒会の職務については、以上です。」——汇报结束，简洁收尾
- 0047「ぜひ、後輩の手作りたこ焼きを／召し上がってください。」——请前辈品尝，称自己和同伴为「後輩」
- 0063「明石焼き用のお出汁やソーセージ、／ツナマヨやキムチーズもありますよ。」——介绍馅料，显示她对派对内容很熟悉

## 行为模式
- 被怀疑会搞出名堂 → 请对方不要那么警惕，不多解释（0007）
- 被指出做了额外的事 → 把原因说成为了信赖的人，所以不算工作，再补一句「ほどほどに」（0025、0026）
- 到派对环节 → 点出具体的馅料，把自己想出来的主意放进细节里（0063）
- 向前辈们道谢时 → 与其他两人分别点名对象（美鈴对莉波，0033）

## 关系
- 千奈：称她为「会長」，说是「信頼する会長」（0025）；千奈称秦谷さん
- 佑芽：佑芽称「美鈴ちゃん」，说章鱼烧是她的主意，也说向她学了烤法（0043、0046）
- 燕：燕称「秦谷」（0024），对她的表现持审视态度（0027）；她请燕不要警惕
- 莉波：她点名向莉波道谢（0033）；莉波爱吃下酒菜类，准备了明太子、年糕（0054～0055，佑芽、莉波的话）
- 星南：星南称章鱼烧是她的主意给她们的惊喜（0044）

## 档案类事实
- 章鱼烧派对是她的主意（0043，佑芽的话）；她教了佑芽烤法（0046，佑芽的话）
- 她会准备明石烧用的高汤、香肠、金枪鱼蛋黄酱、芝士泡菜等馅料（0063）
- 她把帮助自己信赖的会长说成「兴趣」（0025、0026）
