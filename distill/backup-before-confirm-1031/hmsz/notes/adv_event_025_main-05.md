# 活动 025 / main-05 第5话（adv_event_025_main-05）

- 她的台词：12 行（含用匿名标签说的 0 行）：0002、0006、0008、0009、0014、0015、0026、0031、0037、0038、0040、0043（一同 0047 齐声，不计）
- 出场的人：佑芽、千奈、美鈴
- 场景：章鱼烧派对结束后的收拾时间，学生会一年级三人
- 世界线：活动 025；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
派对结束，三人收拾完，千奈道谢，说多亏两人成功。美鈴说「汚名返上、名誉挽回、できましたね」，并向千奈道谢。佑芽说通过这次变得更要好了，美鈴说一起做事并不是第一次，却觉得不可思议。千奈说想到明年，要在春天之前成为可靠的学生会长，美鈴说前辈们已把初星学园托付给她们，并答应继续帮忙。佑芽提议互相直呼名字，美鈴说想暂时保持现状，因为还有不在场的新学生会同伴。三人决定办第二届章鱼烧派对，先邀请広。

## 她的关键台词
- 0002「はい。すべて元の場所に戻しました。」——被问收拾完了没有时的简洁回答
- 0006「どういたしまして。倉本さんこそ、／お疲れさまでした。」——被道谢后，回敬千奈也辛苦了
- 0008「汚名返上、名誉挽回、できましたね。」——总结这次派对的结果
- 0009「ありがとうございます、倉本さん。」——向千奈道谢，称「倉本さん」
- 0014「わたしもです。不思議ですね……」——回应佑芽的变得要好，自己也有同样的感觉
- 0015「この3人で一緒に仕事をしてきたのは、／はじめてではないのに。」——说明不可思议的原因：这三人一起做事已不是第一次
- 0026「初星学園を……／託されてしまいましたから。」——说明为什么不能再依赖前辈，用「しまいました」带点无奈
- 0031「もちろんです。」——答应继续支持千奈，简短而肯定
- 0037「素敵なお考えだと思います、佑芽さん。／ですが……ふふ。」——先肯定佑芽用名字称呼的提议，再笑着加转折
- 0038「それ、もうすこし、／取っておきたいです。」——想把互相直呼名字的事先留着
- 0040「この場にはいない、新しい生徒会の／仲間たちがいるからですよ。」——理由是还有不在场的新学生会同伴，不想抢先
- 0043「では……やりますか？　／第2回たこ焼きパーティーを。」——提议办第二届章鱼烧派对，把话题带向新同伴

## 行为模式
- 被道谢 → 先回「どういたしまして」，再回敬对方（0006）
- 感到亲近 → 承认不可思议，用已有的经验对比（0014、0015）
- 被提议更亲近的称呼 → 先肯定，再笑着婉拒，说明理由是不想漏掉还没加入的人（0037～0040）
- 被托付责任 → 说「託されてしまいましたから」，语气不排斥，但带点无奈（0026）
- 婉拒之后 → 立刻提出另一件事来填补，把话题带向大家一起做的事（0043）

## 关系
- 千奈：称「倉本さん」（0006、0009）；千奈称「秦谷さん」（0003）。她把千奈当作要支持的会长
- 佑芽：称「佑芽さん」（0037）；佑芽称美鈴ちゃん；佑芽提议互称名字时，她婉拒
- 広：本篇只在 0045 千奈提到「篠澤さん」，她没有对此发言

## 档案类事实
- 这三人一起做事已不是第一次（0015，她的话）
- 她们已被前辈们托付了初星学园（0026）
- 她把已经毕业的前辈留下的位置当作自己的责任，但不是轻易接受（0026「しまいました」）
