# P卡 花海咲季【雨后的鸢尾花】 / 第2话 雨后的鸢尾花 第2话（adv_cidol-hski-3-012_02）

- 她的台词：21 行（含用匿名标签说的 0 行）；另有『一同』1 行（0047），不算进行数
- 出场的人：咲季、ことね、手毬、一同
- 场景：她邀手毬、ことね一起自主练习结束时（0001～0002）；地点没交代
- 世界线：亲爱度（花海咲季）·P卡；制作人在制作的偶像：花海咲季（0025「プロデューサーの提案なの。」）

## 发生了什么
自主练习结束，她向陪练的手毬和ことね道谢；手毬说最近她又做饭又按摩，教唱歌不算什么，ことね说教跳舞也是，算互相帮忙。她说大家最近超要好，ことね吐槽刚才还为无聊的事吵架：她说要给手毬做炸里脊（ヒレカツ），手毬突然生气，说几个月才吃一次的炸猪排非厚切里脊肉（ロースカツ）不可，还讲了吃法。她说原来这么讲究，答应完全照要求做，手毬激动地叫她「私の親友」；她说既然是谢礼，对方不高兴就没意思，「1食だけ……特別よ」。手毬问她为什么突然邀她们一起练，她说是制作人的提议：她适合和实力派合练，有能双赢的对象就该互相利用；手毬说自己正合适，她称手毬「中等部ナンバーワン」，又说ことね也是，和ことね练习时有和佑芽一起练时的那种感觉，「あなたはすごいやつよ」，ことね心里乐坏了。她说三人是互相竞争的对手，手毬说不是伙伴、ことね说是敌人，她说就算不是伙伴、就算是敌人也最喜欢她们，提议暂时组成共同战线；三人约定考试前先当好朋友，她让ことね领口号，最后一起喊。

## 行为模式
- 受人帮助 → 当场直接道谢，接着说“今后也拜托了”（0002、0007）
- 和朋友为小事闹别扭 → 听完对方的讲究后让步，答应照办，但说“只此一顿”（0016～0020）
- 被问到动机 → 直说是制作人的提议，并照搬“互相利用”的说法，不加修饰（0025～0027）
- 夸人 → 用“和佑芽一起练时的感觉”“我说的就没错”来夸，自己的标准放在前面（0032～0033）
- 和对手的关系 → 明确说是对手，同时毫不犹豫地说喜欢她们，提出暂时合作（0037～0044）

## 关系
- 手毬：叫「手毬」；称她「中等部ナンバーワン」（0029）；给她做饭、按摩（0004，手毬说）；为炸猪排吵架又和好，手毬叫她「私の親友」（0018）；她说是竞争对手、又说最喜欢（0037、0040）
- ことね：叫「ことね」；说和她练习有和佑芽一起练的感觉、「あなたはすごいやつよ」（0032～0033）；让她领口号（0044）
- 佑芽：未出场；她拿和佑芽一起练习的感觉当尺度（0032）
- プロデューサー：未出场；合练是他的提议（0025～0027）
