# 花海咲季 亲爱度剧情 / 第4话（adv_dear_hski_004）

- 她的台词：27 行（含用匿名标签说的 0 行）；另有「一同」1 行（0024）未计入
- 出场的人：咲季、プロデューサー、ダンストレーナー、一同
- 场景：和舞蹈教练开完训练计划会议之后，接着在同一处吃午饭（0001、0018～0020）
- 世界线：亲爱度（花海咲季）；制作人在制作的偶像：花海咲季

## 发生了什么
她和制作人、舞蹈教练一起商定训练计划，教练称赞她「さすが元アスリート」、连教练的知识都有，她谦虚地请对方继续严格指导。会后她心情很好，说锻炼自己、朝目标前进非常快乐，又拿出自己定的饮食菜单给制作人看。她带了亲手做的便当邀制作人一起吃，内容是豆子、胡萝卜、青椒做的绿色泥和蒸鸡胸肉泥，还配了一种饮料，制作人吃得很勉强；她完全没察觉，以为自己是「気が利く」的偶像。她说姐妹俩一直吃她做的饭，因此一直出成绩，今后也会给佑芽做饭，因为佑芽既是对手也是妹妹、比谁都重要。最后她以为制作人在嫉妒佑芽，说也会给他做便当。

## 她的关键台词
- 0007「いえ、まだまだです。これからも／ご指導をお願いします！」——对教练用敬语、态度谦虚
- 0012「そりゃあねぇ～、／好きでやってることだもの。」——训练是她喜欢的事
- 0014「すぅ～～っごく、楽しいじゃない？」——锻炼自己、朝目标前进让她快乐
- 0016「そうよね！　ふふっ……わたしは、／アイドルとしては痩せすぎらしいから、」——身材方面的自我认识
- 0026「どう？　美味しそうでしょ～？　／わたしの手作りなのよ！」——对自己的料理毫无怀疑
- 0029「マメとニンジンとピーマンのペースト。／佑芽の大好物なのよ～、これ♪」——便当内容
- 0035「そう言うだろうと思って！　はいっ！／気が利くアイドルよね、わたしって。」——自认很贴心
- 0040「ええ、わたしたち姉妹は、ずーっと／わたしの手料理を食べてきたの。」——一直给姐妹俩做饭
- 0043「え？　ストイック？　なにが？」——完全没意识到自己的饭有多“苦行”
- 0048「ライバルで、妹だもの。／誰よりも大切にするわ。当然でしょ？」——对妹妹的态度：对手也要比谁都珍惜
- 0052「プロデューサーのぶんのお弁当も、／ちゃーんと作ってあげる！」——把对方的反应误读为嫉妒，主动要给他做

## 行为模式
- 面对教练等长辈、专业人士 → 改用敬语，谦虚求教（0003、0007）
- 谈到训练 → 情绪高涨，说这是“喜欢的事”“很快乐”（0009～0014）
- 招待别人吃自己做的东西 → 自信满满，察觉不到对方的勉强，反而追问「どうかした？」（0026、0031、0033）
- 被说“严于律己” → 不明白哪里严格，对她来说这是理所当然的（0042～0043）
- 被问为什么要照顾对手 → 理所当然地说“因为是妹妹”（0047～0048）
- 看到对方在意妹妹 → 往“嫉妒”方向理解，主动示好（0050～0052）

## 关系
- ダンストレーナー：她叫「トレーナー」，用敬语，请对方今后继续指导；对方称她「期待の新入生」（0003～0007）
- プロデューサー：她邀他一起吃便当，以为他嫉妒佑芽，说也给他做一份（0020、0050～0052）
- 佑芽：一直吃她做的饭；她说要让佑芽在最好的环境里茁壮成长，「誰よりも大切にする」（0029、0046、0048）

## 档案类事实
- 教练称她「元アスリート」，有教练程度的训练知识（0006）；制作人笔记也说她的知识量不输教练（0054）
- 自己定饮食菜单；据说作为偶像太瘦了（0016～0017）
- 会做饭，便当是亲手做的：豆子、胡萝卜、青椒泥（佑芽最爱吃），蒸鸡胸肉泥（0026、0029～0030）
- 姐妹俩一直吃她做的饭，今后也打算继续给佑芽做（0040、0045～0046）
- 喜欢锻炼、朝目标努力的过程（0012～0014）

## 不确定
- 0024「一同」「いただきます！」：在场的是她和制作人（教练已离开），先不算她的，待统一判定。
- 0035～0037 她递出的饮料是什么，剧本没写；制作人反应「の、飲み物……？」，看得出也不寻常。
- 0034、0038 制作人说“好吃”“营养均衡”，从语气看是勉强的客套；她的料理是否真的难吃，剧本没直接说，制作人笔记 0054 的「料理上手……でもある」也带停顿。
