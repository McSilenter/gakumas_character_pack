# 花海咲季 亲爱度剧情 / 第16话（adv_dear_hski_016）

- 她的台词：27 行（含用匿名标签说的 0 行）；另有「一同」1 行（0053）未计入
- 出场的人：咲季、燐羽、佑芽、プロデューサー、一同
- 场景：『QUARTET』试镜（演出）结束后，她赢了燐羽（0005、0011）
- 世界线：亲爱度（花海咲季）；制作人在制作的偶像：花海咲季

## 发生了什么
她赢了燐羽，和佑芽欢喜地会合，佑芽说她替自己报了仇，她说「あなたのお姉ちゃんよ！」。她问制作人有什么感想、有没有重新迷上她，制作人说「最初から咲季さんだけです」，她得意地说早就知道。燐羽出现，她说“可惜没能剥掉我的镀金”；燐羽问她为什么能赢，她坦承燐羽歌舞和偶像所需的一切能力都远在她之上、照常理她没有胜算，但她正在抓住的某种东西燐羽似乎没有，并说燐羽「アイドルじゃない」。她说未来的顶级偶像不会输给不是偶像的人，而且说了要替妹妹报仇，不能违背和妹妹的约定，无论对手是谁都不能输。燐羽说明白了、说「羨ましい」，说没有镀金的她更好，然后亲了她一下，叫她「咲季お姉ちゃん♡」离开；她惊慌失措，佑芽对制作人说讨厌那个人。

## 行为模式
- 赢了 → 先找妹妹分享，再向制作人讨要夸奖与“惚れ直し”（0001～0015）
- 对手被打败后来问原因 → 先说说不清，再诚实地承认对方全面更强，然后给出直觉式的判断，说之前先声明“不想凭模糊的根据下结论”（0020～0032）
- 解释自己为什么不能输 → 拿出“未来的顶级偶像”和“对妹妹的约定”（0034～0040）
- 被突然亲近（亲吻） → 完全慌乱、说不出话（0048～0051）

## 关系
- 佑芽：赢后第一时间一起欢喜，「あなたのお姉ちゃんよ！」；为了对妹妹的约定不能输（0001～0007、0038～0039）。佑芽对制作人说讨厌燐羽（0055）
- プロデューサー：她追问「ちゃんと惚れ直した？」，他答「最初から咲季さんだけです」，她说「知ってたけどね」（0013～0015）
- 燐羽：她承认燐羽能力远在自己之上，却说燐羽「アイドルじゃない」；燐羽说「羨ましい」，说没有镀金的她更好，亲了她，叫她「咲季お姉ちゃん♡」（0022～0032、0045～0052）

## 档案类事实
- 她在『QUARTET』中赢了燐羽（0005、0011）
- 她认为燐羽作为偶像所需的一切能力都比她强（0023）
- 她自称「未来のトップアイドル」（0034）
