# 花海咲季 亲爱度剧情 / 第25话（adv_dear_hski_025）

- 她的台词：35 行（含用匿名标签说的 0 行）；另有「一同」1 行（0013）未计入
- 出场的人：咲季、星南、燐羽、プロデューサー、一同
- 场景：她老家的「花海トレーニングセンター」（预开放期间），她、燐羽、星南和制作人在这里合宿；中段跳到合宿开始几天后（0001～0005、0053）
- 世界线：亲爱度（花海咲季）；制作人在制作的偶像：花海咲季

## 发生了什么
她带燐羽、星南和制作人来到老家的花海トレーニングセンター，说预开放期间所有设施都能用，又承认自己也是第一次进这栋楼，结果是制作人带路。她宣布先开会，第一个议题是「佑芽のさらなる／強化・育成プラン」，燐羽说输给佑芽要复仇却先商量怎么强化佑芽是脑子有问题，她说「だってわたし、お姉ちゃんだもの！」。她和星南一拍即合：佑芽要在冬季『H.I.F』和她们这些复仇者对战，需要的不是继承自十王星南的曲子，而是『花海佑芽の楽曲』；并决定让佑芽见更多职业偶像实力者。接着燐羽按事先约定给她上歌唱课，星南也请燐羽指导，燐羽要星南反过来指导她们，她也拜托星南亲自指导。合宿几天后，星南感谢她让自己还有成长空间，她说同盟不必道谢、自己也受益；被说学得快，她说擅长学新东西「ただ――」，星南打断说能增加手牌就是她的才能，她笑着说佑芽也遇上了好制作人。大家认为光靠数值不够，她把问题交给制作人，制作人让她参加职业偶像云集的试镜『VisuaL master』；她问刚起步的自己要怎么赢，说自己一点都没振作、自信碎了、一直在对他示弱，制作人拿她“把他的选择变成正确答案”的承诺回应，她说「……ずるいわ。」，答应下来，并要他到试镜当天每晚都听她诉苦。

## 行为模式
- 被人说“输了还帮对手变强很奇怪” → 一句“我是姐姐”就回绝，毫不动摇（0016～0017）
- 讨论佑芽的培养 → 和佑芽的制作人星南一唱一和，主动提出要给佑芽新曲（0028～0031、0037～0039）
- 被别人道谢 → 说同盟者不必道谢，再补上自己也受益（0059～0060）
- 被夸学得快 → 承认擅长，但马上想补一句“只是……”（0063）
- 对方才能被看清时 → 笑出来，把夸奖转成对佑芽的祝福（0066、0068）
- 被派一个过高的目标 → 先怀疑、先说出自己的软弱（0093～0097）；对方搬出她自己的承诺 → 嘴上说「ずるい」，还是答应，同时提出要对方陪她的条件（0102～0106）

## 关系
- プロデューサー：她把关键决策交给他（「さあプロデューサー！　／あなたの出番よ！」0077）；对他坦白「あなたに弱音ばかり」，要他每晚听自己诉苦（0097、0105～0106）。制作人说他想定的突破远没达到，但她答应过把他的选择变成正确答案（0098～0101）
- 星南：直呼「星南」；和她一起讨论佑芽的培养、意见完全一致（燐羽说「……息ぴったり。」0040）；她请星南直接指导自己（0050）；说佑芽遇上了好制作人，星南回「……あなたほどじゃないわ。」（0068～0069）。星南叫她「咲季」
- 燐羽：燐羽叫她「咲季お姉ちゃん」，她招呼燐羽「自分の家だと思って過ごして！」（0006～0007）；事先拜托燐羽给她上歌唱课（0042）；燐羽说她学得快「美鈴並み」（0061）
- 佑芽：合宿第一议题就是强化佑芽；她要给『一番星』佑芽新曲、让她见更多职业偶像（0012～0039、0074～0075）

## 档案类事实
- 花海トレーニングセンター是她老家的偶像专用最新培育设施，处于预开放期间；她自己也是第一次进去（0003～0008）
- 燐羽提到「お父さんへの挨拶も終わったし」，合宿开始前和（应是她的）父亲打过招呼（0011）
- 她擅长学新东西；燐羽说她学得快「美鈴並み」，星南说她像海绵一样吸收（0061～0063）
- 佑芽在『H.I.F』唱的是星南亲传的『ENDLESS DANCE』（0028）
- 下一个目标是冬季『H.I.F』；在『H.I.F選抜試験』之前，制作人让她参加职业偶像云集的试镜『VisuaL master』，形式接近『N.I.A』的『QUARTET』（0029、0079、0087～0091）
- 她称自己「駆け出しアイドル」（0093）
- 『H.I.F』之后她一直在制作人面前示弱，自称没有振作（0096～0097）

## 不确定
