# 花海咲季 亲爱度剧情 / 第27话（adv_dear_hski_027）

- 她的台词：47 行（含用匿名标签说的 0 行）；另有「一同」1 行（0006，省略号）未计入
- 出场的人：咲季、プロデューサー、星南、一同
- 场景：她和星南各自的演出（试镜）结束后；星南穿着演出服跑来，之后她回到制作人身边（0002～0003、0015）
- 世界线：亲爱度（花海咲季）；制作人在制作的偶像：花海咲季

## 发生了什么
星南穿着演出服冲来，两人互相确认都赢了，星南说『H.I.F』要焕然一新、要一起把可爱的『一番星』锻炼得更强再去挑战，然后匆忙离开。她回到制作人身边说「……今度は勝ったわ。」，看穿他一直担心又相信她赢，要他借胸口给她哭，说接住偶像的眼泪也是制作人的工作；制作人说她从那以后每天都在哭。她说自己现在仍认为必须堂堂正正、否则对赢过的对手失礼，有自信又没自信，所以装作有自信去挑战。她说不知道为什么能赢：合宿让她成长了，但仍不及同台的前辈，前辈们也都有比她更强的“粉丝这块外接肌肉”。制作人说因为她最有魅力，她的演出像让人沐浴在花海咲季的精神和人生里；她说现在的自己和他梦想中的花海咲季完全不同，制作人说『彼女』只存在于没遇到他的世界里，今天强而又弱的花海咲季比谁都有魅力。制作人说她已不是无敌的花海咲季，但比相遇时更是「不屈のアイドル」，不屈是倒下折断还继续前进；她问「こんなわたしで……／……本当に、いいの？」，听到“选你真好”后说他是「奇特なやつ」，宣布要成为把折断的心也燃起来、只有她能成为的不屈的顶级偶像。

## 行为模式
- 赢了之后 → 先平静报告，再立刻看穿制作人的心情（0017～0024）
- 想哭、想被安慰 → 用命令语气说出来，并把它说成“制作人的工作”（0028～0029）
- 被问为什么一直哭 → 说“我早就预告过要尽情依靠你”（0031）
- 没有自信时 → 装作有自信，照样堂堂正正去挑战，因为对赢过的对手要负责（0034～0038）
- 赢了却不知道为什么 → 列出自己的成长和不足，老实说不明白（0041～0049）
- 被说“现在的你最有魅力” → 先拿“不是你梦想的那个我”“粉丝会怎么想”来确认；对方说她弱气，她说“因为在你面前”（0060～0068）
- 被全面肯定 → 先「――もうっ！」、说对方是怪人，然后高声宣布新目标（0078～0083）

## 关系
- プロデューサー：称「わたしのプロデューサー」，自称「あなたの担当アイドル」（0021～0022）；在他面前每天哭、要他借胸口，不再逞强（0028～0031、0067～0068）；他说她比相遇时更是「不屈のアイドル」，「あなたを選んでよかった」，她说他是「奇特なやつ」（0070、0076、0079）
- 星南：两人都赢了，她说「慌ただしい先輩ね。」（0008）；星南邀她一起把『一番星』锻炼得更强再挑战（0013～0014）
- 前辈职业偶像们：她说他们实力和粉丝都胜过她（0046～0049）
- 赢过的对手（「あいつら」）：她说必须做个可爱帅气的偶像，否则对他们失礼（0035～0036）

## 档案类事实
- 她在这次（职业偶像参加的）比赛中获胜；星南在她自己的挑战中也获胜（0004～0005、0017）
- 『H.I.F』之后她每天都在制作人面前哭（0030～0031）
- 她一直认为必须堂堂正正，否则对赢过的对手失礼（0033～0036）
- 合宿中受燐羽、星南指导，用了最新器材和科学方法，制作人给了她新曲（0044）
- 她在『N.I.A』找到的武器是粉丝给的力量（「外付けの筋肉」）（0047～0048）
- 她的新目标：「不屈のトップアイドル」（0083）
