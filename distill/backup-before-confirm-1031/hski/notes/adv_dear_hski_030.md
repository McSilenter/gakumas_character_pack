# 花海咲季 亲爱度剧情 / 第30话（adv_dear_hski_030）

- 她的台词：21 行（含用匿名标签说的 0 行）；另有「一同」1 行（0014「！？」）未计入
- 出场的人：燕、咲季、プロデューサー、一同
- 场景：接第29话，燕接受结盟；之后她向制作人报告，三人确认同盟条件，燕看她的演出并示范（地点没交代）（0001～0006、0030）
- 世界线：亲爱度（花海咲季）；制作人在制作的偶像：花海咲季

## 发生了什么
燕接受她的挑战，她说「相手にとって不足なし！」，改口叫「燕先輩」。她得意地向制作人报告说服成功，被夸“交给你是对的”就傻笑。燕说只是信赖咲季、不打算被制作人制作，制作人说他一生只制作花海咲季一人，燕说不愧是咲季的制作人、够疯，她又陶醉傻笑，被燕叫她振作。同盟期到第3次『選抜試験』前为止，之前一起特训、最后一次试验决斗；燕说一直在注意她，说来了个有骨气的人，她说自己也一直在注意这位出色的前辈。燕看完她的全部实力后示范了雨夜燕版的『Wildest Flower』，她震惊，问和自己有何不同，领悟到是「楽曲に拠らない個性」。燕提到佑芽『ENDLESS DANCE』的幕间特技时，她纠正说正式名称是『うめチャレンジ』、粉丝都知道，请别再弄错。燕说她已经有独属于花海咲季的东西，建议她「自分の魅力を知れ」。

## 她的关键台词
- 0004「相手にとって不足なし！／よろしくお願いします、燕先輩！！」——接受对决，改称「燕先輩」

- 0008「えへへぇ～♡　あなたの信頼には／応えないといけないもの～♡」——被制作人信任而得意
- 0018「ふぇへへぇ……♡／それほどでもありますけどぉ～♪」——制作人被夸“不愧是咲季的制作人”时陶醉
- 0028「わたしもです。素晴らしい先輩がいると／気になっていました。」——对燕的敬意
- 0033「伸びる余地があるでしょうか？」——向前辈请教
- 0039「……わたしと、／なにが違うんでしょうか？」——看到同一首歌被唱出不同味道
- 0047「楽曲に拠らない個性……！」——自己把燕要说的话总结出来
- 0051「なにを言っているかわからないときが／よくあります。」——对星南教法的吐槽
- 0059「『うめチャレンジ』です。」——纠正对佑芽特技的称呼
- 0062「ファンなら常識なので、／二度と間違えないでくださいね。」——以佑芽粉丝的立场较真
- 0064「あれがアイドル・花海佑芽の個性……／なんですね。」——把佑芽当作“个性”的范例来理解

## 行为模式
- 被认可、被信任 → 毫不掩饰地傻笑，语尾拉长加♡（0008、0018）
- 制作人被别人夸 → 比自己被夸还高兴（0017～0018）
- 对前辈 → 用敬语，坦率请教自己还有没有提升空间、差在哪里（0033、0039）
- 对方的话还没说完 → 先把要点用一句话总结出来（0047，燕说「……言語化が上手いな。」0048）
- 有人说错佑芽相关的事 → 立刻严肃纠正，以“粉丝常识”要求对方别再错（0059～0062）

## 关系
- 燕：称「燕先輩」，用敬语（0004、0028）；燕叫她「咲季」「貴様」「花海咲季」（0001、0069）；燕说只是信赖咲季才结盟（0010）；燕说一直注意她这个「骨のあるやつ」，她也说一直注意这位前辈（0027～0028）；燕给她示范并建议「自分の魅力を知れ」（0036、0069）
- プロデューサー：她向他报功，被信任时傻笑（0006～0008）；制作人对燕说「俺がプロデュースするのは、／生涯でただひとり、花海咲季だけです。」（0013）
- 星南：她说星南常常说话让人听不懂，燕说星南不擅长教人（0050～0051）
- 佑芽：她是佑芽的粉丝，知道佑芽特技的正式名称『うめチャレンジ』（0059～0062）
