# 花海佑芽 亲爱度剧情 / 第13话（adv_dear_hume_013）

- 她的台词：17 行（含匿名标签 0 行；其中 0009 是回想）
- 出场的人：佑芽、プロデューサー、咲季、燐羽、一同
- 场景：咲季对燐羽的对战日（『N.I.A』期间），前半是佑芽和制作人赛前的对话，0035 起是赛后
- 世界线：亲爱度（花海佑芽）；制作人在制作的偶像：佑芽

## 发生了什么
咲季和燐羽的对决日。佑芽相信姐姐会赢，制作人却担心：燐羽已具备制作人想让佑芽达到的“压倒性的数值”。结果是咲季赢了。燐羽问她为什么能赢，咲季说“你的各项能力都比我强，我本来没胜算”，但认为燐羽“不是偶像”，并说自己是未来的顶级偶像，不能输给不是偶像的人，何况答应了妹妹要报仇。燐羽听完说“明白了”，亲了佑芽，叫咲季「咲季お姉ちゃん」。咲季一时惊慌，佑芽说“我讨厌那孩子”。

## 她的关键台词
- 0009「お姉ちゃんが仇を討ってあげる！」——回想：佑芽在谈到姐姐时再现的画面，原话与 adv_dear_hume_012 0051 逐字相同（0010 接「昔から……あたしと約束したときは、／負けたことないんです。」）
- 0035「佑芽！！　見ててくれた！？」——赢了先问妹妹有没有看见
- 0041「さあ……上手く言葉にできないわ。」——被问怎么赢的，先说无法语言化
- 0044「アイドルに求められるすべての能力が、／わたしより、ずっと上。」——先承认对手在全部能力上都胜过自己
- 0045「この勝負、きっと……／わたしに勝ち目なんてなかった。」——承认按能力她没有胜算
- 0047「あなたには……アイドルにとって、／大切なものが……ない気がする。」——给出赢的理由：对手缺少偶像最重要的东西
- 0051「アイドルじゃない。」——更直接的判断，同一话里称对方不是偶像
- 0053「わたし、／未来のトップアイドルだもの。」——自称“未来的顶级偶像”
- 0058「妹との約束を、／破るわけにはいかないわ。」——另一个理由：对妹妹的承诺
- 0059「負けられないのよ。／誰が相手だろうとね。」——收尾

## 行为模式
- 被问获胜原因 → 先承认自己比不过对方，再说出自己认为对方缺少的东西，最后用“我是顶级偶像”和“对妹妹的约定”收（0041～0059）
- 对对手的评价 → 能力承认上对方更强，但说话不留情面，“アイドルじゃない”（0044、0051）
- 被对手亲佑芽 → 完全失语，只发出「なっ、な、な、なぁっ……！？」（0068）

## 关系
- 佑芽：称「佑芽」；佑芽说“咲季赢了就像我说的”，赛后说她“超帅”（0036）
- 燐羽：本篇咲季没有称呼她的名字；燐羽叫她「咲季お姉ちゃん」（0069）
- 制作人：本篇咲季没有对他说话
