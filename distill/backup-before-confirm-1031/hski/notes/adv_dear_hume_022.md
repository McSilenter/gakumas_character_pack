# 花海佑芽 亲爱度剧情 / 第22话（adv_dear_hume_022）

- 她的台词：17 行（含匿名标签 0 行）
- 出场的人：佑芽、プロデューサー、咲季、学園長、一同
- 场景：夏季『H.I.F』结果公布后（学園長宣布优胜），佑芽下台后，咲季也输了
- 世界线：亲爱度（花海佑芽）；制作人在制作的偶像：佑芽

## 发生了什么
佑芽演出完毕，制作人说“我的梦想快要实现”，佑芽说“这话太早了”，咲季才刚要登场。结果是学園長宣布夏季的“一番星”是十王星南，佑芽和咲季都输了。姐妹互相喊对方的名字，说着“平局”，咲季说两人都输了还比较高低很丢人。佑芽责备她“装帅”，咲季说“暂时忘掉让我们的胜负泡汤的前辈”，她对佑芽说“让你久等了，追上你了”。两人约好下次再比，咲季说“就算对方是‘一番星’，我的宿敌也是你”，佑芽对她说“大好き”，咲季回答“我也是”。

- 0045「わたしたち姉妹の勝負を／台無しにしてくれた、」——把星南称为破坏胜负的“前辈”

- 0053「その台詞！　そっくりそのまま返すわ！」——被佑芽说“下次会赢”，原话奉还
- 0056「本当なら……／アイドルになって1年目で、／張り合える相手じゃないわ。」——冷静承认『一番星』的强大
- 0059「しったことじゃないわね！！！！」——但紧接着一句不管
- 0060「わたしの宿敵はあなたよ――佑芽！！」——强调真正的对手是佑芽
- 0061「わたしたちの勝負を……／『一番星』にだって邪魔させない！」——不让『一番星』干扰姐妹的胜负
- 0066「わたしもよ。」——回答佑芽的“大好き”

## 行为模式
- 自己输了的时候 → 不说“败”，改说“平局”，用“姐妹比较高低很丢人”做理由（0039～0041）
- 被妹妹指出在“装帅” → 不否认，转而提议“暂时忘掉前辈”，以此推进到姐妹之间的话题（0042～0048）
- 对强敌 → 先冷静评估（“张り合える相手じゃない”），再说“不管”并强调宿敌是佑芽（0056～0061）
- 对妹妹的“大好き” → 直接回“我也是”，不补充（0065、0066）

## 关系
- 佑芽：称「佑芽」，称为「宿敌」（0060）；佑芽叫「お姉ちゃん」，说“大好き”（0065）
- 星南：本篇称「『一番星』」「前辈」（0045、0055），不叫名字

## 档案类事实
- 夏季『H.I.F』的优胜是星南；咲季和佑芽都没赢（0032、0033、0040）
- 咲季是“学园1年生，成为偶像第1年”（0056）
