# 十王星南 亲爱度剧情 / 第30话（adv_dear_jsna_030）

- 她的台词：12 行（含匿名标签 0 行）
- 出场的人：星南、咲季、ことね、千奈、愁佳、？？？（0042，愁佳）、一同
- 场景：『VisuaL master』比赛后，星南与咲季的对话（0001～0020）；之后“翌日”，星南与ことね、千奈、愁佳（0021 起）
- 世界线：亲爱度（十王星南）；制作人在制作的偶像：星南

## 发生了什么
星南在『VisuaL master』里赢了咲季。咲季认输，叫她「十王星南」，星南让她直接叫「星南」。咲季说从星南身上看到了佑芽，怕妹妹说自己“浮气”。星南说自己也从咲季那里得到了影响，咲季说“这才是我憧憬的人，打倒你才有价值”。次日的场景里咲季不在，ことね说佑芽要和咲季一起特训，今日姐妹在房间里共处。

## 她的关键台词
- 0001「――十王星南！」——叫全名开场
- 0002「あなたの勝ちよ。これからは／『VisuaL master』と／呼ぶべきかしら？」——输后直接认输，用称号开玩笑
- 0004「『H.I.F』までの間違いではなくて？」——反驳星南“卒业前叫『一番星』”的说法
- 0006「ふふっ……／へこたれている余裕なんてないもの。」——输了也没有消沉的余地
- 0007「いつだってベストを尽くす。／それが花海咲季のやり方よ！」——自己的做法
- 0009「星南。」——第一次直接叫「星南」（在星南说“叫星南就好”之后）
- 0010「あなたの中に、佑芽が見えた。」——说明为什么看得入迷
- 0012「妹に怒られちゃうわ。／お姉ちゃんの浮気者、って。」——幽默地担心妹妹吃醋
- 0016「わたしからも？」——听到星南也受她影响时，惊讶发问
- 0019「――それでこそ、わたしの憧れ。」——星南的话让她再次确认星南是她的憧憬
- 0020「倒し甲斐があるわ！」——憧憬与对手同时成立

## 行为模式
- 输了之后 → 马上承认，用玩笑缓和，然后说“没有消沉的余裕”（0002、0006、0007）
- 被星南邀请叫名字 → 一句「星南。」直接改口（0008、0009）
- 被星南说“我也受你影响” → 先反问（0016），再把话收到“正因为如此值得打倒”（0019、0020）
- 对妹妹 → 从星南的演出里看见佑芽，并用“浮气”开玩笑（0010～0012）

## 关系
- 星南：之前称「十王星南」（0001），被星南要求后改叫「星南」（0009）；星南叫她「咲季」，认为她“生意気な後輩”（0005、0008）
- 佑芽：称「佑芽」，称自己为“お姉ちゃん”，但此处不直接对话（0010～0012）

## 档案类事实
- 她在『VisuaL master』输给了星南（0002、0005）
- 星南说“之前也说过叫星南就好”（0008），两人以前就这样说过
- 她把星南称为“わたしの憧れ”（0019）
