# 活动 012 手毬与广的日常 / main-04 樱花飞舞的起跑线 第4话（adv_event_012_main-04）

- 她的台词：32 行（含用匿名标签说的 0 行）
- 出场的人：咲季、清夏、リーリヤ、佑芽
- 场景：三人开始一起练习的那一天（0001）；后面包括リーリヤ发烧的日子（0077～0082）
- 世界线：活动 012；制作人在制作的偶像：看不出

## 发生了什么
她宣布今天起三人一起练习，リーリヤ惊讶；她是因为要帮清夏解决问题，所以把リーリヤ带来（0001～0005）。清夏抗议没告诉她，她说“没说过”，“你早晚得下决心，リーリヤ也一定察觉了”（0009～0016）。清夏向リーリヤ坦白后，咲季说：问题要拆开，一个个解决（0021～0023）。清夏还是跳不了，咲季让她休息，说要找トレーナー（0026～0028）。佑芽来挑战，她把对手改成リーリヤ（0033～0037）。清夏因此呕吐感，她道歉说自己应该先发现（0042）。后来リーリヤ发烧，她和清夏谈：リーリヤ需要有人支撑，自己不可能一直看着她（0083～0085）；清夏说自己不会再说谎，她只说了“清夏”（0092）。

- 0001「――と、いうわけで！／今日から3人でレッスンするわよ！」——不经解释就宣布

- 0009「言ってないもの。」——被问“为什么没告诉我リーリヤ在”时的回答
- 0011「いつまでも誤魔化せるわけないでしょ。／そろそろ覚悟を決めなさい。」——逼清夏面对
- 0015「わたしですら分かることが、／あの子に分からないわけないでしょ。」——判断リーリヤ已察觉
- 0021「リーリヤ、一気に全部解決するなんて／難しいことはわたしにもできないわ。」——明说自己的能力有限
- 0023「問題点はね、分解するの。／それを1個ずつ解決していく。いい？」——解决问题的方法
- 0030「いちいち落ち込まなくていいの。／……まったく。」——对清夏的内疚直接制止
- 0034「――わたしの弟子のリーリヤと！」——把佑芽的挑战交给リーリヤ
- 0037「わたしに挑みたければ、／リーリヤに勝ってからにしなさい！」——用对决让弟子有训练机会
- 0042「……ごめんなさい。／わたしが、先に気づくべきだったわね。」——为清夏的状况道歉
- 0083「……清夏。あの子は、誰かが／支えてあげないといけないわ。」——担心リーリヤ
- 0085「わたしは、ずっとあの子のことを／見ていられるわけじゃない。」——自己不可能一直守着她
- 0089「嘘をつくのは、得意でしょう？」——对清夏的质问，引出清夏“我只是逃，不是为了战斗而撒谎”（0091）

## 行为模式
- 想解决同伴的问题 → 先自己定方案，不等对方同意，也不先通知相关人（0001～0011）
- 对方内疚 → 制止，不让其沉下去（0030）
- 自己有疏忽 → 马上道歉（0042）
- 想让弟子拥有更多经验 → 把佑芽的挑战改给リーリヤ（0034、0037）
- 看到别人弱点 → 想到“谁来接着支撑”，把责任交给清夏（0083～0085）

## 关系
- 清夏：用「清夏」称呼，一方面强硬（0011），一方面道歉（0042）；清夏对她说“あたしは咲季とは違う”（0090，非她的话）。
- リーリヤ：称「弟子」（0034）。
- 佑芽：她说“来了啊，佑芽”，愿意马上对决（0033）。

## 档案类事实
- 为解决清夏的问题，找トレーナー商量（0028）。
- リーリヤ叫她“弟子”（0003）。
