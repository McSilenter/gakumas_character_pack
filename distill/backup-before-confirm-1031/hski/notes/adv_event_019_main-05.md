# 活动 019 / main-05 巡演活动 名古屋篇 第5话（adv_event_019_main-05）

- 她的台词：22 行（含用匿名标签说的 0 行）
- 出场的人：咲季、ことね、手毬、ウェイトレス
- 场景：名古屋公演结束后的第二天早上，酒店大厅准备回去，之后在咖啡店吃モーニング
- 世界线：活动 019；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
ことね行李变多，她说是在酒店大厅买土产，ことね买给妹妹们；她为取消ことね的游玩计划道歉，ことね要她说谢谢，她说了并称公演大成功（0002～0010）。手毬整理行李，发现美鈴放的检查表，她猜到是美鈴（0017～0020）。三人去咖啡店庆祝；她点特殊的『店舗限定特製コラボモーニング』，原来联名对象是她的父亲，她要和父亲的菜单决胜，还想把赢的那个提议为『初星モーニング』，被两人止住（0047～0060）。

## 她的关键台词
- 0002「ホテルのロビーで／お土産買い込むからじゃない。」——用道理回答，被ことね嫌弃“正论”
- 0006「……改めて、ごめんなさいね。／妹ちゃんたちにも伝えておいて。」——为让ことね取消游玩计划道歉，想到向她的妹妹们转达
- 0009「……そうね。ありがとう、ことね。／おかげでライブも大成功だったわ！」——被要求后坦率道谢并总结成果
- 0014「こういうのは前日に軽く／まとめておくものよ？」——对别人不收拾行李的提醒，被手毬反驳
- 0018「忘れ物をしないように、ってこと？／結構マメなのね。」——猜是手毬自己写的检查表
- 0020「……もしかして、美鈴かしら？」——很快想到是美鈴写的
- 0027「そう？　わたしは最初から、／なんの心配もしていなかったわよ。」——对公演没有担心
- 0029「わかってるわよ。／もう……根に持つわねぇ。」——被手毬要求反省无谋计划，不服但承认
- 0032「ライブも成功させられたんだもの。／今日は特別。」——对饮食管理的例外，说好了今天
- 0043「ちゃんと消費できるんでしょうね、／そのカロリー。」——一边被食物吸引，一边在意热量
- 0052「あ、コレ？　ふふ～、コラボの相手、／わたしのお父さんなの。」——说出联名者是父亲
- 0055「さあ、お父さん――／わたしのメニューと勝負よ！」——对父亲也要比
- 0059「勝った方のメニューを、／初星モーニングとして学園に提案――」——兴奋之下提出的计划，被同伴马上阻止

## 行为模式
- 被说“正论烦人”或被批评 → 不辩解，坦然接受或轻轻抱怨（0002、0029）
- 为牺牲了别人的计划愧疚 → 道歉，并想到让对方向家人转达；被提醒后说谢谢（0006、0009）
- 难得放松 → 说“今天特别”，但进餐前仍会问卡路里能不能消耗（0032、0043）
- 遇到父亲相关的东西 → 兴奋，将其视为对手来“勝負”（0054、0055）
- 一高兴就提出宏大的方案（学校モーニング），不顾同伴的反应（0058、0059）

## 关系
- ことね：互相放松的交谈；她对ことね的妹妹们记挂在心（0004、0006）
- 手毬：手毬提醒她不要再提无谋的计划（0028）；她很快猜到检查表是美鈴写的（0020）
- お父さん：在父亲考案的特製メニュー面前，说“勝負よ”（0052～0055）

## 档案类事实
- 父亲是名古屋一家店的联名菜单（店舗限定特製コラボモーニング）的考案者，她早就期待着吃（0052～0054）
- 平时控制饮食，这天的モーニング算“特别”（0032、0043）

## 不确定
