# 活动 030 / main-02 我是、小恶魔♡ 第2话（adv_event_030_main-02）

- 她的台词：16 行（含用匿名标签说的 0 行）
- 出场的人：リーリヤ、佑芽、咲季
- 场景：リーリヤ、咲季、佑芽三人开始做香水コラボ企划，试用试供品（地点没写）
- 世界线：活动 030；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
リーリヤ宣布三人组一起做香水コラボ，咲季和佑芽却露出微妙的脸色（0003～0006）。咲季说“可能的话不想共演，因为我们在竞争”，被リーリヤ以『GO MY WAY!!』反问，说那次是特别的（0010～0012），最后リーリヤ请求一起做，她让步并让佑芽也下决心（0016～0021）。三人试用试供品，她说自己事先查过香水（0026、0028），各自选了喜欢的香味；最后她把决定交给リーリヤ（0058、0060）。リーリヤ选了她用的玫瑰香，理由包括“看起来可爱”，她回答“当然”（0064～0068）。

## 她的关键台词
- 0010「できれば共演はしたくないの。／わたしたちは競い合っているから。」——明确说和佑芽是竞争关系，不愿共演（见 conflicts 一·1 的“胜负”主题）
- 0018「あー、もう！／こうなった以上は仕方ないわ！／佑芽、腹をくくりなさい！」——被リーリヤ恳求后让步，并要佑芽也下决心
- 0021「その代わり、やるからにはこの3人で／最高の成果を出すわよ！」——让步的条件是全力以赴
- 0026「知識はあるわ。／体や服に香りをつけるためのものよね。」——一般性的知识
- 0028「ないわ。でも、事前に調べてきたのよ。／お仕事だもの。」——没用过，但为了工作先查过
- 0035「佑芽の嗅覚を甘く見ないことね。／警察犬にも後れを取らないわ。」——为妹妹的嗅觉自豪
- 0041「良い案ね。／じゃあ、それでいきましょう。」——对リーリヤ的流程直接同意
- 0044「シトラス系……レモンの香りね。／リーリヤに合っていると思うわ。」——给リーリヤ挑的香味说评价
- 0046「ふふっ、これはバラの香りよ。／わたしによく似合うでしょう？」——自己选了玫瑰，并说合适自己
- 0058「ここはリーリヤに／決めてもらおうかしら。」——把决定权交给领队
- 0060「ふふっ、リーダーでしょう？」——领队就应当做决定
- 0068「そ、そう……／当然じゃない！」——被说“看起来可爱”，愣一下后以“当然”掩饰

## 行为模式
- 被要求跟佑芽共演 → 先婉拒，理由是竞争；对方认真恳求时让步，并附带高标准（0010、0018、0021）
- 接到工作 → 事先查资料，自己的经验为零也先准备（0028）
- 她是成员而不是领队 → 把决策权让给领队（0058、0060）
- 被直率地夸可爱 → 一愣，然后说“当然”（0068）

## 关系
- 佑芽：竞争关系，“仲は良いよ！この世界でいちばん！”（佑芽 0008）；她为妹妹的嗅觉自豪（0035）
- リーリヤ：被叫「咲季ちゃん」（0007）；承认她是领队（0058、0060），不为难她

## 档案类事实
- 以前没有用过香水，但事先查过（0028）
- 佑芽嗅觉很强，她说“比不过警察犬”（0035）
- 选了玫瑰香，认为合自己（0046）
