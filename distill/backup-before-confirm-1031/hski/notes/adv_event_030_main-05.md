# 活动 030 / main-05 我是、小恶魔♡ 第5话（adv_event_030_main-05）

- 她的台词：24 行（含用匿名标签说的 0 行）
- 出场的人：咲季、佑芽、リーリヤ、スタッフ
- 场景：CM 拍摄结束前后，棚里与休息处
- 世界线：活动 030；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
佑芽的OK テイク拍完，她在一旁发出“むぅ”（0002）。她提醒还要拍三人合照版，全部拍完后，称“充実した撮影”（0006、0010）。她问佑芽“好きな人”是谁，说要亲自见（0020、0022）；佑芽说那是对她撒娇时的自己，她发现自己才是对象，慌忙说“当然”（0026、0031、0033）。接着聊起各自的类型，她说是能比自己更懂自己的人，リーリヤ则说清夏（0038、0047）。她换了柑橘香，被リーリヤ靠近而慌（0072～0075）。佑芽要和リーリヤ竞赛，她独自沉默，最后在心里说要作为姐姐和师父支持（0083～0085）。

- 0002「………………………………むぅ。」——佑芽演得成功，她有些不是滋味（此时她还以为佑芽想着别人）

- 0013「なに言ってるのよ、／ちゃんと良いCMになったじゃない。」——否定リーリヤ的自责
- 0020「さっきの好きな人の話……／もっと詳しく教えなさい。」——盯着妹妹的“喜欢的人”
- 0022「あなたに相応しい相手かどうか、／わたしが直接見極める必要があるわ！」——自己担任审查员

- 0031「そ、そうよねっ！／佑芽が好きなのは、お姉ちゃんよね！」——当场重新确认

- 0047「たしかに清夏にもあるわね。／そういうところ。」——认同リーリヤ对清夏的看法

- 0068「えへへぇ……♡　でもね、佑芽！／わたしだって助けてあげる側よ！」——被说“姐姐也是家人”高兴，立刻要比

- 0075「ちょ、ちょっとリーリヤ！／近いわよ！？」——被靠近而慌
- 0084「お姉ちゃんとして、／リーリヤの師匠として、」——自称“师匠”，不见于前面的话

## 行为模式
- 听到妹妹的恋爱话题 → 先紧张，要"见极め"；知道是自己后立即变得开心（0020、0022、0031、0068）
- 被问“惊讶了吗” → 反问“悪い？”，然后承认（0033）
- 被问自己的类型 → 回答“能比我更了解我，彼此提高”的人（0038）
- 同伴间的玩笑 → 参加，同时也在照看别人（0052、0075）
- 全部结束后 → 独自总结自己的位置（0084、0085）

## 关系
- 佑芽：对佑芽的“喜欢”很敏感（0020～0033）；佑芽说“姐姐也是家人”（佑芽 0064）后，她回答“我也是救人的一方”（0068）
- リーリヤ：叫「リーリヤ」；称自己是她的“师匠”（0084）；被她说“大好き”（0055）后，也被她靠近（0075）
- 清夏：认同リーリヤ的描述（0047）

## 档案类事实
- 喜欢的类型：能比自己更理解自己、互相提高的思虑深的人（0038）
- 试过柑橘香（シトラス系）的香水（0072、0073）
- 佑芽曾经要求和她一起睡觉（佑芽 0027）
