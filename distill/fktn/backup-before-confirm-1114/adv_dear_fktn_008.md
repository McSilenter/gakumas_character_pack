# 藤田ことね 亲爱度剧情 / 第8话（adv_dear_fktn_008）

- 她的台词：50 行（含用匿名标签说的 0 行）；0042、0043、0054、0055、0069 是括号里的心里话
- 出场的人：ことね、プロデューサー
- 场景：ファーストライブ当天（0001 旁白「ファーストライブ当日。」），上台前和演出结束后；地点剧本没写
- 世界线：亲爱度（藤田ことね）；制作人在制作的偶像：藤田ことね（0060「あたしのプロデューサー」）

## 发生了什么
ファーストライブ当天，ことね 说学园生活第4年才终于等到，很开心；她说刚才还紧张得僵硬，三年来的各种心情在脑子里打转，出场临近时这些心情没有消失，而是收在了心里。演出后她说练了很多，因为某人反复说她「下手」；还说技术进步是因为宿舍的前辈们教了诀窍，和前辈们搞好关系是对的；班上同学也帮她宣传了很多。她惊讶于自己这个没有实绩的「底辺アイドル」初ライブ竟然满座，制作人说是把她可爱的外貌和舞蹈放在前面做了PV上网公开，生徒会長在SNS上介绍后成了大话题。她嘴上说只是一时的话题，心里非常高兴，说像做梦一样，听到之后能接到更好的工作、酬劳大幅提高就欢呼。制作人反省没能预料到这么火、没做增加粉丝的准备，显得很失落；她说没人能预料到，为这种事反省对拼命努力的自己和为她努力的制作人都失礼，让制作人振作起来。最后她说要给努力的制作人奖励，害羞地提出「デートしましょう！」。

## 行为模式
- 大场面前 → 承认刚才很紧张，但把紧张说成“收在心里”，上台前精神饱满地打招呼（0005～0008、0011）
- 被夸表现 → 得意，同时拐弯抱怨对方以前说她差（0014、0015）
- 回顾成功 → 把功劳分给教她的前辈和帮她宣传的同学，记着要道谢（0018、0019、0021）
- 意外受关注 → 嘴上说只是一时的，心里狂喜（0041～0044）
- 听到好处 → 马上问酬劳（0046），高兴时说「しゅきぃ～♡」（0048）
- 对方失落 → 先调侃对方难得消沉，心里吐槽对方太喜欢担当偶像，然后认真讲道理让对方振作（0053～0060）
- 主动示好 → 心里非常害羞，咳嗽一声后鼓起劲说出口（0068～0071）

## 关系
- プロデューサー：她叫「プロデューサー」（0011），调侃时「プロデューサぁ～」（0053），称「あたしのプロデューサー」（0060）；制作人叫她「藤田さん」（0002、0063）。本话她反过来安慰失落的制作人（0056～0062），并以奖励为名约制作人约会（0066、0071）
- 寮の先輩方：教了她唱歌的诀窍，她说和她们搞好关系是对的，要回头道谢（0018、0019）
- クラスのみんな：帮她宣传了很多初ライブ（0021）
- 生徒会長（她称「会長」0037）：在SNS上介绍了她的PV，她不明白会长为什么会看她的PV（0036、0037）

## 档案类事实
- ファーストライブ是在学园生活第4年（0003）；她说有三年份的心情（0006）
- 初ライブ前紧张，临出场时平静下来（0005～0008）
- 宿舍的前辈们教了她唱歌的诀窍（0018）；班上同学帮她宣传（0021）
- 自称没有实绩的「底辺アイドル」（0028）
- 初ライブ满座（0026）；制作人把突出她可爱外貌和舞蹈的PV放上网，生徒会長在SNS上介绍后成了大话题（0031、0033、0036）
- 制作人说此后能接更好条件的工作、酬劳大幅提高（0045～0047）

## 不确定

- 0003「学園生活4年目」和 0006「3年ぶん」：她在学园的第几年、年级，本话没说明，只照字面记。
