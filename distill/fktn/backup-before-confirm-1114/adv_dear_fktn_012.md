# 藤田ことね 亲爱度剧情 / 第12话（adv_dear_fktn_012）

- 她的台词：31 行（含用匿名标签说的 0 行）
- 出场的人：ことね、星南、プロデューサー
- 场景：她说精神已完全恢复之后（0001，接第11话借款的事）；地点剧本没写
- 世界线：亲爱度（藤田ことね）；制作人在制作的偶像：藤田ことね（0012 星南「あなたのプロデューサー」，0011 制作人「藤田ことねのファーストライブ」）

## 发生了什么
ことね 宣布精神完全恢复、问下一步，制作人说要她见一位重要人物，来的是星南，她吓得大叫「十王会長」，星南要她叫「星南」，她说太不敢当。星南说制作人为了初ライブ因她的宣传而成话题的事来找过她，结论是她要协助 ことね 的制作。制作人让 ことね 说出对星南的认识：她说会长多次挖角她，她当成玩笑拒绝后，会长想给她钱，非常可疑，还闯进教室、出现在打工的地方、等她出来；星南都承认，只否认自己是春天在宿舍附近徘徊的可疑人物。制作人说星南的挖角是认真的、和他一样看中了她的才能，她半信半疑；星南这才意识到自己不擅长挖角，ことね 大声说非常不擅长、那种方式谁会跟着走，星南答佑芽、美鈴、千奈，她说别把她和那些家伙相提并论。星南说如果当初 ことね 答应，她什么都愿意做，但她查到 ことね 的处境时制作人已经救了 ことね，自己只能做点宣传，并道歉；ことね 也为误会道歉，重新说请多关照。星南说她和学生会协助 ことね 的制作，并要 ことね 暂时和她一起行动——因为制作人要出差、把 ことね 托付给了星南。ことね 问出差是否很快回来，制作人说几天回不来，她说会等着，请他尽早回来。剧情经过参照 jsna 笔记。

- 0038「めちゃめちゃ下手でしたよ！！！」——对学生会长也直接吐槽

## 行为模式
- 突然见到地位高的人 → 惊叫，用全称「十王会長」，对方要求改称呼就说「恐れ多くて無理」（0006、0007、0009）
- 被要求说出对某人的印象 → 照实一条条说，包括对方的可疑行为（0018、0019、0022、0023）
- 得知自己的印象是误会 → 先不敢相信、追问是否当真（0034、0035），再毫不客气地吐槽对方的方式（0038、0039）
- 被拿来和别人比 → 抗议（0041）
- 对方道歉 → 马上说自己才该道歉，承认误会，重新打招呼（0050～0052）
- 制作人要离开 → 不问理由（「なら、聞きません」），但确认是否很快回来，说会等着（0066～0071）

## 关系
- 星南：她叫「十王会長」（0007）、「会長」（0018、0048）；星南叫她「ことね」（0005、0036），要她叫「星南」、说两人是朋友（0008），她说「恐れ多くて無理」（0009）。以前她把星南的多次挖角当成玩笑拒绝，觉得星南可疑（0018、0019）；本话误会解开，她道歉，互道「よろしく」（0050～0053）。星南和学生会将协助她的制作，制作人出差期间她要跟星南一起行动（0059、0062、0065）
- プロデューサー：她叫「プロデューサー」（0002、0010、0071）；制作人叫她「藤田さん」（0017）。制作人说他和星南一样认真看中了她的才能（0032、0033）。制作人要出差、原因不能细说，她不追问，说会等他回来（0067～0071）
- 佑芽、美鈴、千奈：星南说被那种挖角方式带走的（或跟着她的）是这三人，她叫她们「あいつら」，不愿被归为一类（0040、0041）

## 档案类事实
- 借款问题后，她宣布精神完全恢复（0001）
- 星南曾多次挖角她，她当成玩笑拒绝；星南还想给她钱、闯进她的教室、出现在她打工的地方、等她出来（0018、0019、0022、0023，星南都承认 0021、0025）
- 春天宿舍附近有过可疑人物徘徊，星南否认是她（制作人所说 0026，星南 0027）
- 星南后来自己查到了她的处境，那时制作人已经帮了她（0045、0046）；星南为初ライブ做了宣传（0011、0047）
- 星南和学生会将协助她的制作，以和学生会成员的合同宣传企划为主（0059、0061）
- 制作人要出差，几天回不来，原因不能细说；出差期间把她托付给星南（0064、0065、0067、0069）

## 不确定

- 0013 星南说和制作人「色々……話をして」，谈了什么本话没说（第13话星南说是一场比试，见 adv_dear_fktn_013 0018）。
- 0058 星南结巴的原因（是否意识到自己也是她的“心累原因”），属推测，参照 jsna 笔记。
- 【译文】0065「その間、彼女に／藤田さんのことを託しました。」译成“这段时间，我把她托付给藤田同学了”，主宾颠倒；原文是把藤田（ことね）托付给她（星南）。（与 jsna 笔记一致）
