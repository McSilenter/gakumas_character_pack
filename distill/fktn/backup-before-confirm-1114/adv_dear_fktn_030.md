# 藤田ことね 亲爱度剧情 / 第30话（adv_dear_fktn_030）

- 她的台词：51 行（含用匿名标签说的 0 行）；0081、0083 是她复述制作人说过的话
- 出场的人：ことね、燕、プロデューサー
- 场景：接上一话结尾燕闯进来（0001、0002 与 adv_dear_fktn_029 0114、0115 相同），燕走后她和制作人谈；『舞道場』临近（0093），本话没写地点
- 世界线：亲爱度（藤田ことね）；制作人在制作的偶像：藤田ことね（0063「担当アイドル」、0080「あなたのプロデューサー」）

## 发生了什么
燕向她提出决斗，她慌了，说燕对她来说不是敌人、是很照顾她的最喜欢的前辈（0001～0008）。燕说一直看着她、为她担心，她在定期公演出成绩、在『N.I.A』打败白草月花优胜，还激励了消沉的十王星南、促成顶级偶像诞生，这些都是燕该做却没做到的，所以要赢她找回骄傲（0010～0029）。她接受了决斗，说最喜欢的前辈愿意当她的对手很光荣；燕警告她别尊敬有敌意的人，说她的缺点是缺乏斗争心，还说沉迷恋爱更是免谈，要她注意身体（0030～0040）。燕走后，她说燕的忠告很用心、正是她喜欢的地方；果たし状上写着在最后的『選抜試験』里对齐日程比拼（0041～0047）。她说不可能拒绝，因为她懂燕的心情：如果换成她不知道星南的烦恼、由别人激励了星南，她一定会被嫉妒压垮，做不到燕那样（0051～0056）。她说自己最喜欢的偶像是十王星南，但雨夜燕是不输给顶级偶像的超厉害偶像，夏季『H.I.F』上一眼就觉得输了，没法把她当中间目标，非常害怕（0067～0077）。制作人提醒她找到『アイドルとして大切なもの』，问站在台上看着粉丝时会不会觉得这是中间目标；她吐槽提示给得太多，然后说偶像没有中间目标、在粉丝面前唱全都是大一番，现在该做的是在『舞道場』全力夺下奖金、和观众尽情享受演出，要带着『Yellow Big Bang！』上台（0080～0096）。

## 行为模式
- 被尊敬的前辈当成敌人 → 先慌张辩解对方不是敌人、自己喜欢对方（0006～0008），听完理由后接受，并说光荣（0030～0033）
- 被认真称赞 → 低声说「褒めすぎ」（0013）
- 别人的嫉妬或敌意 → 设身处地去想，承认自己可能更糟（0051～0056）
- 被指出缺点 → 反复念叨、自虐，求制作人一起烦恼（0060～0064）
- 害怕时 → 直说害怕（0077）；制作人给提示后，自己说出答案，把重心放回粉丝和自己的工作上（0089～0096）
- 下定决心时 → 仍用奖金、「金貨たち」之类的钱的说法来说（0093、0094）

## 关系
- 燕：她叫「雨夜先輩」（0007、0018）、「雨夜燕先輩」（0072）；燕叫她「貴様」「藤田ことね」（0001、0015）。燕说她是可爱的后辈，一直在为她担心、看着她（0010、0017），这次因自尊向她决斗（0029）；她说燕是很照顾自己的最喜欢的前辈（0008、0043），也说燕是不输顶级偶像的偶像（0072、0073）
- 星南：她叫「星南先輩」（0052），说自己最喜欢的偶像是十王星南、是她梦想的起点和特别的人（0068～0070）
- 制作人：她叫「プロデューサー」（0044、0067）；制作人叫她「藤田さん」（0080）。果たし状砸到了制作人脸上，她问他没事吧（0044）；她把燕的事和自己的害怕都对制作人说，制作人用提问引导她找到答案（0084、0085），她说「ヒント出しすぎ」（0087）

## 档案类事实
- 燕说她在定期公演出了成绩、在『N.I.A』打败白草月花优胜（0016，燕的话）
- 燕说她激励了消沉的十王星南，成了顶级偶像诞生的契机（0019、0020，燕的话）
- 燕说她是勤劳的人，环境不好、走着艰难的路仍不失笑容、体贴别人（0011、0012，燕的话）
- 燕说她的缺点是缺乏斗争心（0036，燕的话）
- 和燕的决斗：在最后的『選抜試験』对齐参加日程比拼（0047）
- 最喜欢的偶像是十王星南，星南是她梦想的起点（0068～0070）
- 她对夏季『H.I.F』上燕的演出一眼就觉得输了（0074、0075）
- 她要在『舞道場』表演『Yellow Big Bang！』（0096）
