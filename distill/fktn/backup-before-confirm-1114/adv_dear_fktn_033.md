# 藤田ことね 亲爱度剧情 / 第33话（adv_dear_fktn_033）

- 她的台词：41 行（含用匿名标签说的 0 行）
- 出场的人：星南、ことね、麻央、莉波
- 场景：她在六大オーディション达成『二冠』之后（0001），本话没写地点和时间
- 世界线：亲爱度（藤田ことね）；制作人在制作的偶像：藤田ことね（本话制作人未出场；0054 莉波说「ことねちゃんのプロデューサーさん」）

## 发生了什么
她达成六大オーディション『二冠』，跑向星南，却因星南情绪太高而吓得逃开（0001～0007）。星南激动地说初星在校生拿下六大中的5个是学园史上第二次壮举；她说星南从一开始就在哭，自己只是眼眶湿了、在这里不能哭（0012～0018）。她说她和星南共4个、咲季拿了『歌道場』1个，差一点就全制霸了；星南说那就由她来完成，正要说「なぜなら」时，她请星南别说「那句话」，说自己是憧憬星南才当偶像的，和制作人约定过要摘到星、实现梦想（0022～0034）。星南改口称她为「宿命のライバル」，约她一起炒热初星学园最大的祭典，她也以「宿命のライバル、十王星南さん」回应（0035～0040）。麻央、莉波来祝贺，她感谢两人在合同训练和应援团上的帮忙；两人说是她的制作人交给她们应援团的工作，对她们也是双赢（0041～0066）。麻央说她太谦虚，她说两人都是超厉害的偶像、最喜欢的前辈，这不会变；麻央和莉波争说自己才是她最喜欢的前辈，星南不甘心（0067～0085）。她笑着说星南和朋友在一起时原来是这样，羡慕麻央、莉波，希望和星南同一年级，说两人好好说话还不到一年，想多了解彼此、好到能随便吵架，想和星南成为朋友；星南说「なりましょう」，在决定学园第一偶像的颁奖典礼上（0086～0104）。剧情经过参照 amao、hrnm、jsna 笔记。

## 行为模式
- 对方情绪比自己更高 → 反而退一步、冷静下来（0005～0007）
- 情绪高涨（「気が大きくなってる」）时 → 会对憧憬的人开平时不开的玩笑（0020～0023）
- 被抬到“继承者”的位置 → 不让对方说出口，拿出自己的起点（憧憬）和与制作人的约定来回应（0030～0034）
- 被称赞成就 → 把功劳归给支持她的人，说前辈怎样都是她喜欢的前辈（0043～0045、0067、0070～0072）
- 被人争着说是“她最喜欢的前辈” → 笑着看，不选边（0086、0100）
- 对憧憬的人 → 坦白说想要更近的关系：同年级、能随便吵架、成为朋友（0089～0101）

## 关系
- 星南：她叫「星南先輩」「星南せんぱぁ～～～～～～～～い♡」（0003、0007），正式时称「十王星南さん」（0039）、「あなた」（0032）；星南叫她「ことね」（0004、0010）、「藤田ことねさん」（0037）。两人互称「宿命のライバル」（0037、0039）。她说两人认真说话还不到一年（0097），想和星南成为朋友，星南答应（0101、0102）
- 麻央：她叫「麻央先輩」（0043）、「麻央せんぱぁ～～～～～～い♡」（0075）；麻央叫她「ことね」（0041、0076）。麻央说她是那样的孩子、所以想支持她（0073、0074），说她是「甘えん坊」（0076）
- 莉波：她叫「莉波先輩」（0043）；莉波叫她「ことねちゃん」（0042）。莉波托她向制作人转达谢意（0048），她答应（0049）
- 制作人：本话没出场；她说和制作人约定要摘到星、实现梦想（0033、0034）；麻央称赞她的制作人「切れ者」（0059）
- 咲季：她说咲季拿下了『歌道場』（0022）

## 档案类事实
- 达成六大オーディション『二冠』（0001）
- 六大中初星在校生共拿下5个：她和星南共4个，咲季1个（『歌道場』）（0012、0022）；星南说这是学园史上第二次（0013）
- 麻央、莉波接受了她的制作人委托的「応援団」工作：配信应援示范视频、到现场应援，帮忙攻略六大オーディション（0054～0057）；她的曲子都很重视 Call & Response（0055，麻央的话）
- 她和麻央、莉波一起进行过合同训练（0045、0065）
- 麻央称她为「黄金世代筆頭」（0065）
- 她说自己和星南认真说话还不到一年（0097）
- 星南约定在决定学园第一偶像的颁奖典礼上成为朋友（0102、0103）

## 不确定
- 0029 星南的「なぜなら」后面要说什么、她不让说的『その言葉』（0031）是什么，本话没写出。
- 0038「初星学園最大のお祭り」是不是指『H.I.F』，本话没写名称。
- 0103 是“到颁奖典礼时成为朋友”还是“在颁奖典礼上成为朋友”，两种读法。
- 0089～0092 按上下文麻央、莉波和星南同一年级，剧本没直接说。
- 0062 星南自称「藤田ことね教の枢機卿」，指什么本话没解释。
- 本线第12话星南说过两人是朋友（adv_dear_fktn_012 0008），当时她回答叫名字太惶恐（adv_dear_fktn_012 0009）；本话她说想成为朋友（0101）。从她这边看前后一致；jsna 笔记从星南的角度把这两处标成了【冲突】。
