# 提炼：O3-pstory（40 篇，世界线：培育（藤田ことね），培育剧情 001 / 002 / 003）

**出处写法**：为了好读，出处里的 stem 省掉了共同的部分，写成「剧本号 段名 行号」。完整 stem = `adv_pstory_<剧本号>_fktn_<段名>`。例：`001 ending-true-01 0004` = adv_pstory_001_fktn_ending-true-01 第 0004 行。

**世界线说明**：本组全部属于“培育（藤田ことね）”。制作人是玩家，制作的就是她。培育剧情 001、002、003 是三个不同剧本，并列存在，彼此不算冲突。同一剧本里的分支（001 的 opening-normal/opening-true、after-step 的 normal-01～03、考试结果 normal-01～04、结局 A～E End 和 True End；002 的 a/b、-02/-03）都是并列的可能，不是先后发生。大部分篇目内部还有“制作人选项 → 2～3 段并列反应”，选项内容没写进剧本，下文不替制作人认定选了什么。

- 001（30 篇）：开场 → 练习中（after-step-1、after-step-2）→ 期中考试前后 → 最终考试前后 → 结局（A～E End、True End）。这一剧本里有“她前阵子状态很糟、正在恢复”的设定（after-step 系列）。
- 002（9 篇）：目标“称霸『N.I.A』”（标题）。有ランキング、オーディション、『H.I.F』、『一番星』，有十王星南出场。
- 003（2 篇）：『選抜試験』；只有两段很短的打招呼。

本组她的台词共 543 行（三人以外的出场者：星南 3 篇、学園長 1 篇）。没有一字不差的重复行，没有「一同」。

## 3. 人物关系
