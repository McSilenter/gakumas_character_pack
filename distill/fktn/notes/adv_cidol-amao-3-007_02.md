# P卡 有村麻央【Campus mode!!】 / 第2话 Campus mode!! 第2话（adv_cidol-amao-3-007_02）

- 她的台词：19 行（含用匿名标签说的 0 行）
- 出场的人：麻央（38 行）、プロデューサー（22）、ことね（19）
- 场景：麻央练习『Campus mode!!』振付的レッスン（0002、0013）；具体地点剧本没写明
- 世界线：亲爱度（有村麻央）·P卡；制作人在制作的偶像：有村麻央

## 发生了什么
制作人为了让麻央的振付更完美，给她安排了レッスンパートナー，叫进来的是她（0016、0021、0022）。她自称被叫来当麻央的练习对象，又自报是“麻央先輩のライバル”（0024、0025）。制作人说明是要麻央来教她『Campus mode!!』，因为教人能学到更多；制作人说她虽是1年生但舞蹈才能相当好，和麻央关系也好（0027～0037）。她说能跟麻央学振付还能拿钱，是最棒的打工（0034、0035）。麻央起初用“羽ばたく”“ハチドリのように”这类抽象说法教，她听不懂抱怨；制作人提醒后麻央改成具体指示，她照做，被夸可爱时害羞，被要求一直保持姿势时喊腿要抽筋（0046～0069）。结束时她道谢，说自己也很有收获，请以后有事再找她（0070～0073）。

## 行为模式
- 对前辈 → 语尾拉长、带♪和「っ」，用撒娇式的敬语说话（0022、0024、0034）
- 有钱可拿的事 → 当面直说“最棒的打工”，高兴之情不加掩饰（0035）
- 听不懂的指示 → 一边吐槽“ワケわかんね～”一边照样试着做（0047、0049）
- 被当面夸奖 → 害羞，说话吞吞吐吐（0063、0064）
- 身体撑不住时 → 直接喊出来，用“つーかぁ”这种口语（0069）
- 收尾 → 道谢并主动说下次再找自己（0070～0073）

## 关系
- 麻央：叫「麻央せんぱーいっ♪」（拖长音的叫法）、「麻央先輩」（0022、0024、0070）；麻央叫她「ことね」（0023、0039、0063）。她自称“麻央先輩のライバル”（0025）；制作人说她和麻央关系好（0037）。
- プロデューサー：本篇她和制作人没有直接对话；制作人称她「藤田さん」（0027、0036），叫她来当麻央的练习对象（0021）。
