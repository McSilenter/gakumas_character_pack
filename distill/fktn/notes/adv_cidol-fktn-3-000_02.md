# P卡 藤田ことね【世界第一可爱的我】 / 第2话 世界第一可爱的我 第2话（adv_cidol-fktn-3-000_02）

- 她的台词：22 行（含用匿名标签说的 0 行；0006、0007 是她念新曲的歌词）
- 出场的人：咲季、ことね
- 场景：ことね一个人听新曲、看歌词发愁，咲季过来（0015～0016）；地点剧本没写
- 世界线：亲爱度（藤田ことね）·P卡；制作人在制作的偶像：藤田ことね（本篇制作人没出场，按清单）

## 发生了什么
ことね在练新曲，只有 D 段不知道怎么唱：别的地方能带着“看看可爱的我”的心情唱，可念到歌词『できるできるできる、そうだ』『信じてくれる人がいる』时就是对不上（0004～0008）。咲季叫她没理，被大喊一声吓了一跳（0009～0014）。她让咲季说感想，咲季说这是只有她唱得了的歌，她说自己是世界第一可爱，可就是没法把自己放进歌里（0019～0021）。咲季说写歌的人相信她是世界第一可爱，她缺的是比谁都强的自我赞美（0030～0035）；她吐槽咲季对自己的印象，咲季说“爱自己到让人无语，胆怯时也爱那样的自己”，她承认没错（0038～0041）。她明白过来：自己以为必须配合明快的曲子、不能胆怯，其实不是这样，于是打起精神去练（0042～0045）。剧情经过参照 hski 笔记。

## 她的关键台词
- 0004「このDメロだけ、どーやって／歌えばいーのかわっかんねー。」——一个人时说话很随便（～わっかんねー）
- 0005「他のとこは、可愛いあたしを見てーって／いくらでも気持ち入れられんだけど……」——“可爱的我”这部分她很容易投入
- 0008「そー簡単にできないってぇ……／いまいちシンクロできないぃ……」——对“相信我的人在”这种歌词难以共鸣
- 0014「さ、咲季ぃ～～！／びっくりしたじゃん！」——被吓到时对咲季的口吻
- 0020「そこまで言う～？　確かにあたしは、／世界一可愛いけどさぁ～。」——被夸时顺势自夸
- 0029「おい。」——咲季说自己比她更可爱时的短吐槽
- 0033「…………知ってる。」——承认自己知道写歌的人（制作人）相信她
- 0038「咲季の中で、／あたしのイメージどーなってんだよ！」——对同学吐槽时的男孩子气口吻
- 0041「……違わない。……そっか……」——承认“胆怯时也爱自己”的说法
- 0042「明るい曲に合わせなきゃって……／弱気になっちゃダメだって……」——说出原来的误区
- 0043「きっと、そうじゃなかった。／……わかった気がする。」——转折：不用硬配合明快的曲子
- 0045「……よっし。『あたしの歌』の／レッスンやるかぁ～～！」——想通后马上切换到干劲

## 行为模式
- 一个人烦恼时 → 嘟囔、说话粗（わっかんねー、できないぃ），对别人叫她也听不见（0001～0010）
- 被同学夸 → 不否认，顺势说“我确实世界第一可爱”，然后才说真正的烦恼（0020、0021）
- 对方说自己比她更可爱 → 一个字「おい」吐槽（0029）
- 被说中心事 → 停顿后简短承认（0033、0041），然后自己把道理说出来（0042、0043）
- 想通之后 → 立刻给自己打气去练习（0045）

## 关系
- 咲季：她叫「咲季」（0014），咲季叫她「ことね」并自称「お姉ちゃん」（咲季 0009）。对咲季说话随便、会吐槽（0029、0038）；咲季点醒她，她坦率承认（0041）。咲季要求开演唱会时叫她（咲季 0044），她没有回应这句，直接说去练习（0045）。
- プロデューサー（未出场）：咲季说写这首歌的人相信她世界第一可爱（咲季 0030），她答「知ってる」（0033）。

## 档案类事实
- 新曲 D 段歌词有『できるできるできる、そうだ』『信じてくれる人がいる』（0006、0007）
- 咲季对她的印象：爱自己到让人无语，胆怯的时候也爱那样的自己（咲季 0039）；她承认（0041）

## 不确定
- 0033「…………知ってる。」承认的是“写歌的人相信她世界第一可爱”还是“这首歌寄托了这种愿望”，两者都说得通。
- 咲季 0030 说的「この曲を作った人」是谁剧本没点明；从第1话看曲子是制作人为她准备的，但作词作曲者是不是制作人本人看不出。
- 「一同」行：无。
