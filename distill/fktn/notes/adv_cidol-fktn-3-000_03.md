# P卡 藤田ことね【世界第一可爱的我】 / 第3话 世界第一可爱的我 第3话（adv_cidol-fktn-3-000_03）

- 她的台词：26 行（含用匿名标签说的 0 行）
- 出场的人：ことね、プロデューサー
- 场景：新曲即将首次发表（お披露目）之前（0002）；地点剧本没写
- 世界线：亲爱度（藤田ことね）·P卡；制作人在制作的偶像：藤田ことね

## 发生了什么
新曲发表前，ことね说希望大家喜欢、买很多，又特地确认这首歌会不会一般发售（0004～0006）。制作人说学园学生的乐曲发售有几道门槛，但这次会正式流通销售，也会有她期待的版税，她欢呼起来（0007～0011）。被说“一如既往地冷静”时，她笑着说心里其实超紧张，并坦白自己基本胆怯、却又很喜欢自己，一直觉得这样摇摆不行，所以硬要配合积极的曲子而白费力（0012～0018）。制作人说不用配合曲子，随心唱就是正确答案（0019～0023）；她自己接着说出：胆怯、紧张、满脑子版税，都可以原样放进歌里（0024～0026）。她宣布要尽情唱出“我这么可爱，胆怯和贪财都可爱”，让粉丝买周边和 CD、在卡拉 OK 学她唱，喊着“大赚一笔”出发（0029～0036）。

- 0011「このために学園に入った／までありますよあたし！」——夸张地说为这个才进学园，金钱动机直说不讳
- 0013「えへへへ……／や～、内心超どきどきですってぇ。」——被说冷静时笑着承认紧张
- 0015「あたしって、基本弱気なんですよね。／だけど自分のことは大好きで……」——自我剖析：胆怯又爱自己
- 0017「ずっと、それじゃダメだと／思ってたんです。それで……」——过去的看法（随后被制作人和她自己推翻）
- 0018「ポジティブな曲に合わせなきゃって、／空回りしちゃってました。」——说出之前的误区
- 0021「言い方！？　ひっど！！」——被制作人说“没指望你有高超技巧”时的吐槽
- 0025「弱気なのも、内心ドキドキなのも、／印税のことばっかり考えてるのも。」——把自己的缺点一一列出
- 0026「ぜんぶそのまま、歌に込めていい。」——转折后的结论：原样接受自己
- 0030「ぜんぶぜんぶ可愛いんだぞ！　って、／思いっきり歌ってきます！」——带着自我肯定上台的宣言
- 0034「大儲けですよ、プロデューサー！」——最后还是落到赚钱上

## 行为模式
- 有新工作 → 先关心能不能发售、有没有版税，确认有就毫不掩饰地欢呼（0006、0010、0011）
- 被说“冷静” → 笑着否认，说心里很紧张（0012、0013）
- 状态好的时候 → 主动坦白自己的弱点和之前的误区（0015～0018）
- 制作人说话带刺 → 立即吐槽「言い方」，然后照样接住他的意思（0021、0024～0026）
- 想通后 → 把“可爱”和“赚钱”的目标都大声说出来，给自己打气出发（0029～0036）

## 关系
- プロデューサー：她叫「プロデューサー」（0034）；他叫她全名「藤田ことね」（0020）。她向他坦白自己胆怯又爱自己的矛盾（0015、0016）；他说话直到她喊过分，但她能顺着他的话自己得出答案（0021、0024～0026）。

## 档案类事实
- 制作人说学园学生的乐曲发售有几道门槛；这次的曲子会一般流通、发售，她会拿到版税（制作人 0007～0009）
- 她说“为了这个才进的学园”（指版税、赚钱，夸张说法）（0011）
- 自我评价：基本胆怯，但很喜欢自己，摇摆不定（0015、0016）
- 她想让粉丝买她的周边和 CD、在卡拉 OK 唱她的歌（0032、0033）

## 不确定
- 0011「このために学園に入った／までありますよあたし！」的「までありますよ」是“甚至可以说”的夸张说法，不一定是她入学的真实理由。
- 制作人 0012「……いつもながら、／落ち着いていますね。」紧接在她狂喜之后，像是反话；她的回应（0013）当成真话来接，读法存疑。
