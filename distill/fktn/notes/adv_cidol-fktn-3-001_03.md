# P卡 藤田ことね【Yellow Big Bang！】 / 第3话 Yellow Big Bang！ 第3话（adv_cidol-fktn-3-001_03）

- 她的台词：42 行（含用匿名标签说的 0 行）
- 出场的人：ことね、プロデューサー
- 场景：レッスン中，她刚表演完一段（0001～0005）；地点剧本没写
- 世界线：亲爱度（藤田ことね）·P卡；制作人在制作的偶像：藤田ことね

## 发生了什么
ことね在练习里表演完，说自己找到答案了；制作人让她说清和上次演唱会有什么不同（0002～0005）。她说不同的是“心情”：上次她拼命练习、做出了“藤田ことね史上最高”的表演，却被说期待落空，苦恼之后才明白自己太拼命、没有余裕，忘了无论多累多消沉、多大的危机，她自己都得开心地唱跳，否则就不是藤田ことね的演唱会（0007～0019）。她说粉丝是来和可爱的ことね一起享受的，只是认真、漂亮地唱跳会让他们失望（0020～0023）。制作人夸她明白了就能马上做出来，她说那本来就是她做得到的事，又把“把粉丝想成钱和宝石”当作享受演唱会的秘诀说出来，被制作人叮嘱采访时绝对别说（0024～0033）。说着说着她忽然意识到，自己能开心当偶像是靠粉丝，她一直从大家那里得到元气，所以才想让粉丝更开心，结果太拼命而白费力，是本末倒置（0034～0044）。她说下次想开一场从粉丝那里得到更多元气、让全场都超有元气的演唱会（0047～0049）。

## 她的关键台词
- 0003「つかみましたよ！　／これがあたしの答えです！」——接第2话“快要抓住”
- 0011「藤田ことね史上最高の／パフォーマンスができたんです！」——对上次演唱会的自我评价
- 0013「なのに期待外れだった――って／どーゆーことなんだよぉ～！」——苦恼时的粗口吻
- 0015「必死すぎて、／余裕なかったっぽいです、あたし。」——找到的原因
- 0018「あたし自身が楽しく／歌って踊らなくちゃ――」——她的原则：自己先开心
- 0019「藤田ことねのライブじゃあ、／ありませんもんねっ♪」——用全名称呼自己的演唱会
- 0021「可愛い可愛いことねちゃんと／一緒にライブを楽しみに来てたんです。」——自称「ことねちゃん」，理解粉丝要的是什么
- 0029「応援してくれているファンの皆様を、／おカネや宝石だと思いこむコトです！」——“秘诀”：把粉丝想成钱和宝石
- 0031「顔が金貨になったファンたちがぁ……／きらきらきらきら～～～～～☆」——拜金的玩笑式说法
- 0038「ファンの人たちのおかげじゃんって。」——突然意识到的转折
- 0040「あたしはいつも、／みんなから元気をもらって、」——她和粉丝的关系：从粉丝那里得到元气
- 0044「いや～、本末転倒ってやつですネ。／反省反省～。」——反省时也用轻松语气
- 0049「そんなライブがしたいです！」——下一步的愿望（打算，尚未实现）

## 行为模式
- 自认找到答案 → 先表演给制作人看，被问时得意地「よくぞ聞いてくれました」开讲（0003、0006）
- 被夸 → 「えへへ～♪」并说本来就会（0025）
- 讲到真心话 → 用拜金玩笑包装（0029、0031），说完又停下来，认真说出真正的感激（0034～0041）
- 反省 → 以“本末倒置、反省反省～”轻轻带过，再说出下一步想做的事（0044～0049）

## 关系
- プロデューサー：她叫「プロデューサー」（0002）；他叫她「藤田さん」（0024）。她把“秘诀”当成只告诉他的秘密（0027），他叮嘱她别在采访里说（0032），她拖长音答应（0033）。
- 粉丝：她意识到自己能开心当偶像是靠粉丝，一直从粉丝那里得到元气（0037～0041）。

## 档案类事实
- 她说上次演唱会前练了很多，做出了“藤田ことね史上最高”的表演（0010、0011）
- 她享受演唱会的“秘诀”：把粉丝想成钱和宝石（0029～0031）；制作人叫她采访时别说（制作人 0032）
- 她说自己一直从粉丝那里得到元气才能唱跳（0040、0041）

## 不确定
- 0025「元々できてたことですからネ！」指的是“自己开心地唱跳”本来就做得到（以前的演唱会有、上次没有，呼应第2话 0040），还是指别的，语义上大致如此但不完全确定。
- 0029 的“秘诀”是半开玩笑还是真实习惯，剧本没交代；制作人当真了叫她别在采访说（0032）。
- 「一同」行：无。
