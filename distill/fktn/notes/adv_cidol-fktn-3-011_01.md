# P卡 藤田ことね【雨后的鸢尾花】 / 第1话 雨后的鸢尾花 第1话（adv_cidol-fktn-3-011_01）

- 她的台词：28 行（含用匿名标签说的 0 行；0004、0009、0010、0028、0031、0033～0037 是她在讲梦的内容，梦里的事不当成这条线的事实）
- 出场的人：ことね、プロデューサー
- 场景：早上她向制作人打招呼（0001、0002）；地点剧本没写
- 世界线：亲爱度（藤田ことね）·P卡；制作人在制作的偶像：藤田ことね

## 发生了什么
早上ことね心情很好地向制作人打招呼，说昨晚做了个很真实的梦，梦见自己参加夏天的『H.I.F』（0001～0004）。制作人说是好兆头，她惊讶他还没听内容就知道，他说不是好梦她会保密，她说“你真了解我”（0005～0008）。她说梦里她顺利通过选拔、正要挑战正赛时醒了，醒后心情还很舒畅，想带着这股劲去面对现实的『H.I.F』，又问自己最近是不是太得意（0009～0013）。制作人说摆脱了一切心事的她正是最佳状态的天才偶像，对上顶级偶像也没问题，她高兴得一早情绪高涨（0014～0018）。制作人想听梦的细节作为制作参考，她说“不过是梦”，又打趣他是不是想分析她（0019～0025）。被问梦里的制作人是谁，她说不太清楚，像是同一个又有点不同；她说最大的不同是梦里的她组了组合，三个人挑战『H.I.F』，吵了很多次架，终于到了能够到『一番星』的地方，并想那两人后来怎样了、有没有优胜（0026～0037）。制作人僵住，说没想过她组组合，想和梦里的制作人讨论；她看出他在和梦里的制作人较劲，他否认，让她详细说（0038～0047）。

## 行为模式
- 心情好 → 拖长音、加♪地打招呼，主动说起好事（0001、0003）
- 被说中心思或被夸 → 撒娇式回应“你真懂我”“就知道你会这么说”（0008、0017）
- 自己说完好事 → 先自嘲“是不是太得意”（0013）
- 别人认真对待她的小事 → 先说“不过是梦”，再调侃对方（0021、0025）
- 察觉制作人反常 → 直接问他怎么了、是不是在较劲（0039、0043）

## 关系
- プロデューサー：她叫「プロデューサー」（0001、0039）；他叫她「藤田さん」（0002）。她觉得他很了解她（0008）；他夸她是最佳状态的天才偶像（0014～0016）；她看出他和梦里的制作人较劲（0043）。
- 梦里的组合伙伴：她称「あいつら」，醒后还在想她们后来怎样（0036、0037）；是谁本篇没说（第2话 0004、0005 提到咲季、手毬）。

## 档案类事实
- 目标是夏天的『H.I.F』（0004、0012）
- 制作人说她已经摆脱了所有心事、是最佳状态（制作人 0014、0015）
