# P卡 藤田ことね【全力以赴！】 / 第2话 全力以赴！ 第2话（adv_cidol-fktn-3-016_02）

- 她的台词：22 行（含用匿名标签说的 0 行）
- 出场的人：ことね、プロデューサー
- 场景：接第1话，她和制作人商量“让咲季和手毬的粉丝喜欢上藤田ことね的大作战”（0001、0002）；地点剧本没写
- 世界线：亲爱度（藤田ことね）·P卡；制作人在制作的偶像：藤田ことね

## 发生了什么
ことね宣布开始“让咲季和手毬的粉丝爱上藤田ことね大作战”，要提出这个主意的制作人好好想作战，不许甩手（0001～0004）。制作人说她刚才还苦恼，马上就能积极起来，这是她的优点；她说别一脸欣慰，自己早就习惯危机了（0005～0009）。制作人问人在什么时候喜欢上别人，她答“拿到报酬的时候”，制作人说本想说“发现对方优点的时候”，她问“就像刚才发现了我优点的制作人？”，他说是，她高兴他秒答（0010～0017）。她推出：两人的粉丝很了解两人的优点，所以要吸收两人的优点，但用对方的强项去比她赢不了（0019～0025）。制作人说她的舞和歌都进步了，对方粉丝一定会觉得“藤田ことね，有两下子”，她说信任太重（0026～0030）。她再要作战，制作人说两人的优点不只是偶像的本领，要她借机重新看看；她说身边的人坦率夸很难为情，承认作战可能有效，但觉得超级难为情（0031～0039）。

## 行为模式
- 被难题打击后 → 很快转为积极，宣布“作战”开始（0001、0002、0008）
- 被问抽象问题 → 先给出和钱有关的答案（0011）
- 制作人说出好话 → 立刻把话题绕到“你喜欢我”上来确认，被肯定就开心（0015～0017）
- 被高度信任 → 说“信任太重”（0030；adv_cidol-fktn-3-000_01 0035 她也说过“爱太重”）
- 要坦率夸身边的朋友 → 觉得难为情（0034、0039）

## 关系
- プロデューサー：她叫「プロデューサー」（0003、0038）；他叫她「藤田さん」（0006、0010）。他说她很快就能积极起来是优点（0006），她害羞地吐槽（0007）；她要他好好出主意（0004、0031）。
- 咲季、手毬：她称两人「あいつら」（0019、0025）；承认在两人的强项上比不过（0025）；要坦率夸她们难为情（0034）。
