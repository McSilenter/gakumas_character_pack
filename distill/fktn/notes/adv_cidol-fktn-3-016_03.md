# P卡 藤田ことね【全力以赴！】 / 第3话 全力以赴！ 第3话（adv_cidol-fktn-3-016_03）

- 她的台词：17 行（含用匿名标签说的 0 行）
- 出场的人：咲季、ことね、手毬
- 场景：三人共演的练习结束后（0001）；咲季唱的是『がむしゃらに行こう！』（0004）；地点剧本没写
- 世界线：亲爱度（藤田ことね）·P卡；制作人在制作的偶像：藤田ことね（本篇制作人没出场，按清单）

## 发生了什么
练习后咲季问自己的『がむしゃらに行こう！』怎么样，手毬说声音不错但不如自己，ことね接着说很可爱但不如自己（0003～0007）。咲季说想把两人能学的都学来，ことね夸她什么都能马上模仿的灵巧是武器、是了不起的才能（0009～0015）。咲季说是不是因共演加深了羁绊，ことね和手毬都否认（0017～0019）。手毬说自己是在观察两人的魅力，好让她们的粉丝也喜欢自己；咲季说手毬迷上自己，ことね和手毬一起吐槽咲季没距离感（0022～0028）。ことね笑着说大家想的都一样：她也在学两人厉害的地方，因为两人是超厉害的偶像，她想让来看演唱会的人开心（0030～0036）。两人反过来夸她，她说被夸起鸡皮疙瘩但还是道谢，并说既然这么难为情就要回本，号召三人让演唱会大成功；咲季、手毬也宣战，她回“那是我的台词”，说最喜欢两人这样（0037～0048）。剧情经过参照 ttmr 笔记。

## 行为模式
- 夸同学 → 先用“当然不如我”的句式（0007），后来认真说出对方的优点（0014、0015）
- 被说关系变亲密 → 立刻否认（0018），但会和另一人一起吐槽第三人（0028）
- 发现对方和自己想法一样 → 笑出来，然后坦白自己的动机（0029～0036）
- 被同学夸 → 说起鸡皮疙瘩，但照样道谢（0042）
- 难为情之后 → 用“要回本”转成干劲，带头号召（0043、0044）
- 对朋友 → 说话粗（おまえら、ばーっか），最后却直说“最喜欢”（0047、0048）

## 关系
- 咲季：她叫「咲季」（0035）；夸她模仿得快、灵巧是才能（0014、0015）；吐槽她没距离感（0028）。咲季说学了她“什么曲子都能唱跳得可爱”的地方（咲季 0041）。
- 手毬：她叫「手毬」（0035）；和她一起吐槽咲季（0028）；手毬说她不顾形象的地方很好（手毬 0039）。
- 两人合称「おまえら」（0032、0042、0044、0048）；她说两人是超厉害的偶像（0033），最后说最喜欢两人这样（0048）。

## 档案类事实
- 她在共演练习中有意学习咲季、手毬的长处（0032～0036）
- 咲季说她什么曲子都能唱跳得可爱（咲季 0041）；手毬说她“なりふり構わない”（手毬 0039）
