# P卡 花海咲季【雨后的鸢尾花】 / 第2话 雨后的鸢尾花 第2话（adv_cidol-hski-3-012_02）

- 她的台词：13 行（含用匿名标签说的 0 行）；0034、0035 是括号里的内心话（心声，不是对人说的）
- 出场的人：咲季（21 行）、ことね（13）、手毬（12）、一同（1）
- 场景：咲季邀请手毬、ことね来的自主练习结束后（0001、0002）；时间在『試験』之前（0043 “試験で会うまでは”）
- 世界线：亲爱度（花海咲季）·P卡；制作人在制作的偶像：咲季（0025 咲季说“プロデューサーの提案”）

## 发生了什么
咲季邀请手毬、ことね练习后，三人闲聊。手毬、ことね说咲季照顾了她们（做饭、按摩），所以教歌教舞不算什么。咲季问大家是否最近关系变好，ことね指出刚才还在为炸猪排吵架。后来咲季说明合练是制作人的提议，要互相利用。她夸ことね有和佑芽练习时的感觉“すごいやつ”，ことね心里高兴。三人约定到考试前是“共同战线”，咲季叫ことね起头喊口号。剧情经过参照 ttmr、hski 笔记。

## 行为模式
- 被直接夸奖 → 嘴上只说“ありがと”，把真正的高兴放在内心（0034～0036）
- 被说“关系好” → 用具体的刚吵过的事反驳（0009）
- 被点名做事 → 先问“为什么是我”，再答应并做（0045、0046）
- 关系定位 → 在“敌人”和“暂时的伙伴”之间，用轻松的语气来划线（0039、0043）

## 关系
- 咲季：叫「咲季」（0003 暗含）；咲季叫她「ことね」（0030、0044）；咲季说“あなたはすごいやつよ”（0033）
- 手毬：叫「手毬」（0003）；手毬说“私たちは仲間じゃない”（0038）

## 档案类事实
- 手毬、ことね被咲季邀请进行自主练习，手毬教歌、ことね教舞（0005、0006）
- 咲季说ことね让她想起和佑芽一起练习时的感觉（0032，咲季的话）
- 被咲季评为“すごいやつ”（0033）
