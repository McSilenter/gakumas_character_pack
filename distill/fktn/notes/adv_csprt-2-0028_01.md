# S卡 2-0028【りっぱなすすき！】 / 第1话 芒草礼物（adv_csprt-2-0028_01）

- 她的台词：11 行（含用匿名标签说的 0 行；0008 是像旁白一样说出来的描述，0004 是惊吓时的反应）
- 出场的人：ことね、佑芽
- 场景：打工回来的路上，有芒草的地方（0001、0003），时间像是秋天（0003「秋っぽいな～」）。
- 世界线：S卡【りっぱなすすき！】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
ことね打工后很累，但觉得今天赚得多，心情不错。她看到芒草，觉得有秋天的感觉，突然被一个人影吓到，原来是佑芽。佑芽在为姐姐挑最好的芒草，仔细比较长度和毛茸茸程度。ことね旁观，佑芽选定一根后也给了ことね一根，ことね先高兴地道谢，然后喊了一句"遊ぶかぁぁ！！"。剧情经过参照 hume 笔记。

## 她的关键台词
- 0001「は～！　バイトつっかれた～！」——打工后的疲惫，直白
- 0002「んっふふふ♪　今日は結構／稼げちゃったんじゃないの～？」——对当天收入暗自得意
- 0003「お、ススキが生えてんじゃん！／秋っぽいな～。」——注意到芒草，说有秋天感觉
- 0004「うひっ！？／な……っ……オ、オバ……！？」——被突然出现的人吓到，话没说完
- 0006「う、佑芽……？」——认出是佑芽后的惊讶
- 0008「突然出てきた佑芽に／びっくりさせられてる。」——用说明口气陈述自己的惊吓
- 0010「で、そっちは？」——对方道歉后直接问她在干什么
- 0012「ススキをぉ～、えらぶぅ～？」——一字一顿地重复，对"挑芒草"的怀疑
- 0016「ふぅ～～ん………………」——旁观佑芽认真挑选，兴趣不高的回应
- 0019「わ～～～～っありがとぉ！」——拿到芒草后先道谢
- 0020「…………って、遊ぶかぁぁ！！」——沉默后吐槽

## 行为模式
- 打工后 → 抱怨累，但很快因收入好而高兴（0001、0002）
- 被突然吓到 → 发出怪声、话说到一半，然后确认对方是谁（0004、0006）
- 别人的做法她不理解 → 重复对方的话、用拖长的语气表示怀疑（0012、0016）
- 收到礼物 → 先开心道谢，一会儿后吐槽（0019、0020）

## 关系
- 佑芽：称呼「佑芽」（0006）；佑芽叫她「ことねちゃん」（佑芽 0007、0018）。ことね被佑芽吓到后，也接受了佑芽给的芒草（0019）。

## 档案类事实
- 在打工，且当天收入不错（0001、0002）
- 对"秋天"的感受来自芒草（0003）

## 不确定
- 0004 的「オ、オバ……！？」是什么词剧本没写完；中文译文写成"老婆婆"，原文只有「オバ」，可能是「オバケ」之类，不能确定。【译文】
- 0020「遊ぶかぁぁ！！」译文作"喂，别玩了啦"，原文意思更像"谁要玩这个"，所指是对佑芽把芒草当玩具的吐槽还是对礼物的吐槽，剧本没写。【译文】
- 0008 是她说出来的台词还是旁白，剧本里 name 标的是ことね。
