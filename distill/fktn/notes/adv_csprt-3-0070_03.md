# S卡 3-0070【おい、来てやったぞ！】 / 第3话 关心的副会长（adv_csprt-3-0070_03）

- 她的台词：11 行（含用匿名标签说的 0 行）
- 出场的人：ことね、燕
- 场景：ことね打工结束后（店里，具体地点剧本没写）
- 世界线：S卡【おい、来てやったぞ！】；制作人在制作的偶像：看不出

## 发生了什么
ことね打工结束，累得瘫下来，但觉得赚得不少。燕在等她，说是偶然，递给她饮料。燕提起中间考试的红点，ことね吃惊为什么知道；燕说担心她的不止自己，问有没有困扰、愿意商量。ことね先推辞（说燕已经在打工上帮过她），在燕说不用客气后坦白下周有再考试，若再红点就要补习，请燕帮忙看功课，并把客人给的联名周边送给燕。燕收下，约她明天去图书室。

## 她的关键台词
- 0001「あぁぁあああ～～づがれたぁぁ～～っ！／でも、結構働いたし稼げたな～♡」——下班后的疲惫，同时盘算打工收入
- 0003「うわっ！？　って、副会長！？／終わるまで待っててくれたんですか？」——发现燕在等，直接问
- 0005「ありがとうございます～♡／疲れてたから、甘いの嬉しいです～！」——收下饮料，直白说开心
- 0007「ぎくっ……………………！！」——被说到学业问题时的反应
- 0009「な、なんで知ってるんですかぁ！」——对考试红点被知道的惊慌
- 0012「いやいや副会長には、バイトの件とか、／便宜を図ってもらってるんで――」——先客气推辞，提到燕在打工上给过方便
- 0014「……実は、再テストが来週あって。」——放弃推辞，坦白
- 0015「今度赤点だと補習なんですっ！！！／良ければ勉強見てくれませんか……？」——主动请求燕帮忙看功课
- 0016「お礼になるかわかんないんですけどぉ、／お客さんからもらったこれ、あげます！」——用手上的东西作回礼
- 0020「（ふっふっふ、副会長好きそうだから、／いつか渡そうと思ってたんだよね～♪）」——内心话，说明早就想把这个送给燕

## 行为模式
- 被说到不想听的事 → 先装作僵住（「ぎくっ」），再问对方怎么知道（0007、0009）
- 被对方提出帮忙 → 先以“已经受到照顾”推辞，再一转头直接求助（0012、0014、0015）
- 请别人帮忙 → 拿出准备好的东西作回礼（0016、0020）

## 关系
- 燕：称「副会長」，说话敬语；燕在她下班后等待、关心她的学业，她求助并送了周边（0003、0015、0016）

## 档案类事实
- 中间考试红点，下周有再考试，再红点要补习（0014、0015；红点是燕在 0008 说的）
- 打工上得到过燕的方便（0012）
- 客人给了她一件联名周边，她想送给燕（0016、0020）
