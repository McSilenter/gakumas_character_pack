# 雨夜燕 亲爱度剧情 / 第22话（adv_dear_atbm_022）

- 她的台词：21 行（含用匿名标签说的 0 行）
- 出场的人：燕、プロデューサー、ことね
- 场景：接第21话结尾，ことね找到在训练的燕（第21话 0076～0081），本话地点没再写
- 世界线：亲爱度（雨夜燕）；制作人在制作的偶像：雨夜燕

## 发生了什么
ことね慌张地来问燕是否早就知道星南要引退，燕说前阵子听说了，也阻止过但星南不改主意。ことね说这不像燕、质问燕就这样算了吗，说自己不想放弃，想让会长继续当偶像，请燕合作。制作人代燕答应，提出让星南回归偶像。燕说星南现在的梦想是让『一番星』成为顶级偶像的称号、自己让给培养的偶像，ことね断言那不可能是真心话，说出「星南ちゃん」不会说把顶级偶像让给别人；被燕说是星南的粉丝时先慌了，随后承认，并说不会输给燕。制作人提出举办只为星南一人的演唱会，ことね抢着说这个任务自己也能做、要让她来；制作人于是提出让燕和ことね用演唱会对决，看谁能拯救星南的心，ことね当即答应，还说不会输给犹豫的人。燕最终接受。

## 行为模式
- 重要的人要离开偶像 → 不接受，四处找人，主动请别人合作（0002、0012、0014）
- 对方表现得消极 → 直接说“不像你”，追问对方是否甘心（0009、0010）
- 听到不认同的说法 → 先断然否定，再承认其中有真的部分（0027、0028）
- 心事被戳穿（是星南的粉丝）→ 先慌张支吾，然后自暴自弃地承认，并把话题转成竞争宣言（0032、0033）
- 看到机会 → 抢着自荐，“这个我也能做”（0058、0060）
- 对手犹豫 → 用挑衅推对方一把（0071）

## 关系
- 燕：她叫燕「副会長」（0002、0009）；燕叫她「藤田」（0001）、「お前」（0031）。她质问燕、请燕合作，后来在“谁来拯救星南的心”上和燕对决（0063～0065）。制作人在第21话的内心独白里说她和燕从中等部时代起关系就很深（第21话 0080）
- 星南：她平时叫「会長」（0010、0012、0044），激动时叫「星南ちゃん」（0029）。燕说她是星南的粉丝，她承认（0031、0033）；想让星南继续当偶像（0012）
- プロデューサー（燕的制作人）：本话她没有称呼他；接受他提出的对决（0061～0065）

## 档案类事实
- 是星南的粉丝（0031 燕的话，0033 本人承认）
- 想让星南继续当偶像（0012）
- 听星南说过能用数值看到偶像的能力（0044）
- 制作人说她经过『N.I.A』成长了（0076，制作人的话）
- 要和燕在演唱会上对决，看谁能拯救星南的心（0063～0065，约定，本话尚未举行）
