# 雨夜燕 亲爱度剧情 / 第33话（adv_dear_atbm_033）

- 她的台词：24 行（含用匿名标签说的 0 行）
- 出场的人：燕、ことね、星南、美鈴、千奈、佑芽、手毬、燐羽
- 场景：初星学園内，燕在制作人给的休假中巡视学园（0056、0057），遇到ことね，地点没写；『H.I.F』本战之前，燕快毕业（0058）
- 世界线：亲爱度（雨夜燕）；制作人在制作的偶像：雨夜燕（0056「今、プロデューサーにオフを／言い渡されていてな。」）。ことね在这条线里的制作人是星南（0072「プロデュースしてくれた星南先輩。」）

## 发生了什么
ことね遇到燕，照旧叫「副会長」，被燕说已经不是副会长后改叫「雨夜先輩」。听燕说快毕业了，她低声附和。燕说听说她拿了『舞道場』，她说也会出场『H.I.F』本战，要在本战还上次的债，正因为那次的不甘心才走到这里。燕笑了，她以为被小看，燕却说她成了出色的偶像，说从中等部起就照顾她的打工许可申请等事。ことね说夏天前的自己只是个差生，能走到这里是多亏从中等部照顾她的燕、制作她的星南、关心她的麻央和莉波、还有同级生们。燕坦白羡慕她，因为星南一直只关注她；ことね一瞬间误会燕对星南有特别的感情，被燕否认。燕承认星南的眼光是对的，认她为自己的对手，ことね道谢，然后说燕赢了她、举行拯救星南的演唱会时自己被排除在外，没看那场演唱会，但因为比过所以知道是燕的光芒打动了「星南ちゃん」，正因如此，她想站上那个舞台；最后宣告本战不会输。剧情经过参照 ttmr、hmsz、hume 笔记。

## 行为模式
- 被纠正称呼 → 马上改口，并顺势问对方在做什么（0055）
- 说到输过的对手 → 宣告要在下一次报仇，并把不甘心说成成长的动力（0062、0063）
- 对方笑了 → 立刻怀疑自己被小看（0065）
- 被当面夸奖 → 措手不及，只能“啊，是”（0067）
- 谈到自己的成长 → 先贬低过去的自己（「劣等生」），再逐一点名感谢帮过自己的人（0070～0073）
- 听到暧昧的话 → 马上往恋爱方向想歪（0079）
- 被认可后 → 先道谢，然后说出被排除在外的不甘，最后转成对决宣言（0087～0095）

## 关系
- 燕：她叫燕「副会長」（0053）后改为「雨夜先輩」（0055、0071、0086）；燕叫她「藤田」（0054、0060）、「お前」（0068）、「貴様」（0085）。燕说从中等部起就照顾她的打工许可申请等事（0068），本话燕认她为对手（0085）；她说燕从中等部起就照顾她（0071），宣告本战不会输（0095）
- 星南：本话她叫「星南先輩」（0072、0079），说到动情处改口「星南ちゃん」（0091）；说星南是制作她的人（0072）。燕说星南一直只关注她（0078、0081）
- 麻央、莉波：叫「麻央先輩」「莉波先輩」，说两人一直关心她（0073）
- 同级生们：她说也多亏了同级生们（0073）
