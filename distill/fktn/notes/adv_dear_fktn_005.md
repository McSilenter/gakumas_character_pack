# 藤田ことね 亲爱度剧情 / 第5话（adv_dear_fktn_005）

- 她的台词：35 行（含用匿名标签说的 0 行）；0005、0006 是她转述制作人以前说过的话；0056、0063、0064 是括号里的心里话
- 出场的人：ことね、プロデューサー
- 场景：给孩子们的きぐるみショー（玩偶装表演）结束后（0001、0009），之后制作人送她回宿舍的路上（0012）
- 世界线：亲爱度（藤田ことね）；制作人在制作的偶像：藤田ことね

## 发生了什么
制作人找来的工作是给孩子看的きぐるみショー，演完她一身汗，质问制作人这哪里是“对你有益的工作”。制作人在送她回宿舍的路上解释：工作是通过学园接的、做好有评价，而且含有动作、演技、舞蹈、唱歌，对还不习惯舞台的她有用；她一度觉得可能是好经验，马上又说「騙されませんよっ」，抱怨工作太累、制作人斯巴达。制作人夸她穿着玩偶装也跳得利落、很快记住动作和台词，她很高兴，说身体久违地轻松，还要制作人多夸她。制作人接着说她“非常可爱、有才能、唱歌很差”，她抗议最后一句多余，说不用说也知道。制作人说休养后她的表现大幅改善，唱歌却还是差，并说她需要得到与实力相符的评价；她心里认为那只是制作人太喜欢她。最后她答应明天也努力工作，心里想反正又是奇怪的工作，但工作就是工作，会好好做。

## 她的关键台词
- 0003「じゃなくてえッ！？」——习惯性地打完招呼后自己吐槽，转入质问
- 0009「今日のお仕事、子供向けの／きぐるみショーだったんですケド！？」——对工作内容不满
- 0021「劣等生でしたからねー。」——自称以前是差生
- 0024「だ、騙されませんよっ！」——差点被说服后又反弹
- 0028「うげー……スパルタぁ……この前は、／優しかったのにぃ。」——抱怨制作人变严格
- 0032「こんなに身体が軽いの、／ひっさしぶりでぇ！」——休养后身体轻松
- 0036「あ、褒められるのはうれしーので、／どんどんお願いします！」——坦率要夸奖
- 0040「いやぁ～！　エヘヘ……そんなハッキリ／言われると、照れちゃいますよぉ～♪」——没等对方说完就当成夸奖
- 0046「最後の一言要ります！？」——对“唱歌差”的吐槽
- 0047「言われなくてもわかってますぅ～～～！」——自己也知道唱歌不好
- 0052「あたしのことホントに／好きなんですかぁ！？」——被说唱歌差时反问制作人是否真的喜欢自己
- 0064「（仕事は仕事。／ちゃーんとやりますよーっと）」——心里话，嘴上抱怨但仍认真对待工作

## 行为模式
- 对安排不满 → 先习惯性地打招呼，再自己打断转成质问，并原封不动搬出对方以前的话来对质（0002～0007）
- 被讲道理 → 一时被说服（「いい経験になった……のかも？」），接着又警觉「騙されませんよっ」（0022、0024）
- 被夸 → 马上高兴，嘴上说「別に」，又直白地要求多夸（0031、0035、0036）
- 对方话没说完 → 抢先当成夸奖而害羞（0039、0040）
- 被指出缺点 → 抗议，但承认自己知道（0046、0047）
- 对不想做的工作 → 心里抱怨，但认定“工作就是工作”而好好去做（0062～0064）

## 关系
- プロデューサー：她叫「プロデューサー」（0002），撒娇时拖成「プロデューサぁ～」（0051）；制作人叫她「藤田さん」（0001）。她抱怨制作人「スパルタ」、和「この前」相比不温柔（0028）；仍把制作人的评价理解成制作人太喜欢她（0052、0056）

## 档案类事实
- 做了给孩子看的きぐるみショー工作，工作是通过学园接的，做好有评价（0009、0014、0015）
- 自称以前是「劣等生」（0021）
- 制作人说她还不太习惯舞台（0020）
- 休养后身体久违地轻松，穿玩偶装也跳得利落；很快记住了舞蹈动作和台词（0030～0034）
- 唱歌不好：制作人说（0041、0045、0050），她自己说「言われなくてもわかってますぅ」（0047）
- 喜欢被夸（0036）
- 住宿舍，制作人送她回「寮」（0012）

## 不确定
- 0005、0006 是她原样搬出制作人以前的话（和第3话 0048、0049 制作人说的一致），计入她的台词。
- 0039 制作人说到「あなたは――」就被她打断，0040 她已当成夸奖在害羞，中间可能有省略。
- 0053 制作人说「あなたは……」后，0054 她只有「！！」，0055 制作人接「他人からも、自分自身からもです」——中间少了一句（可能是“被低估了”之类），剧本没写，不能确定制作人说了什么。
- 0043「初めて会ったときから……／何度も何度も言いますよねぇ、それ。」——她说制作人从初次见面起就反复说这句，但第1话剧本里制作人没有说过“唱歌差”这类话；不算冲突（第1话之后的交流剧本没全写），记在这里。
- 【译文】0041「あなたは――とても可愛く、／才能があり、歌が下手です。」中的「歌が下手」译成“唱歌不好”，没问题；0053～0057 译文把 0057 补成“是我们的目标”，原文只是「実力通りの評価を／受けられるようになること。」，属补译。
