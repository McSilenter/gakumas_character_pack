# 藤田ことね 亲爱度剧情 / 第6话（adv_dear_fktn_006）

- 她的台词：42 行（含用匿名标签说的 0 行）；0065 是括号里的心里话
- 出场的人：ことね、プロデューサー、副会長、麻央、莉波
- 场景：宿舍，早上的工作是打扫宿舍（0001「朝の仕事は～、寮のお掃除ぃ～っと。」）
- 世界线：亲爱度（藤田ことね）；制作人在制作的偶像：藤田ことね

## 发生了什么
ことね 的新工作是打扫宿舍，她抱怨又是体力活。打扫时她向麻央寮長、莉波、副会長打招呼，副会長说大家都佩服她做事仔细，要她继续努力，她对着副会長用「あざッす」应答，对方走后小声抱怨别突然出现。制作人来问工作情况，说选这份工作是因为能练体力、校内评价容易上升，以及工资高、有救济苦学生的用意；她一听工资高就改口说「信じてました」。制作人布置课题：一个月内认识宿舍所有学生并和她们交流，她说早就做到了，解释是为了实现梦想，前辈们都很厉害、同级生将来也可能变厉害，被喜欢能有好处、减少人际麻烦，又不花钱。制作人说她将来会是出色的偶像，但成不了世界第一的歌姬或舞者，提出要以成为最让人“想一起工作”的偶像为目标，说这是成为大富翁的捷径。她问制作人自己是不是说过梦想，制作人说她好几次差点说出口；她心里认为制作人是太喜欢她才看走眼。最后制作人说下一个工作是演唱会，她非常兴奋。

## 行为模式
- 遇到宿舍里的前辈、寮长、副会長 → 主动大声打招呼，对前辈顺口夸奖，对有威严的人用短促体育系应答（0004、0008、0010、0012、0014）
- 有压力的人离开后 → 才小声吐槽（0015）
- 抱怨工作 → 一听到有利（工资高）就马上改口称赞对方（0022～0025）；被指出变脸快就笑着说「気のせい」（0027）
- 处理人际关系 → 有意识地分层：能合得来的交朋友，难相处的至少打招呼，前辈尽量讨好（0035～0038）；理由是对梦想有用、减少麻烦、不花钱（0044～0049）
- 不想直说自己的野心 → 话说到一半改口，换成“梦想”这个说法（0043、0044）
- 被夸在舞台外的表现 → 不太当回事，觉得那不算数（0052）
- 被说中心思 → 先问自己是否说过，再试探对方「ヒきました？」（0061、0063），心里归结为对方太喜欢自己（0065）

## 关系
- プロデューサー：她叫「プロデューサー」（0025），抱怨时拖成「プロデューサぁ～」（0003）；制作人叫她「藤田さん」（0016）
- 麻央：她叫「麻央寮長」（0004）；麻央叫她「ことね」（0005）。她祝麻央晨练加油（0006）
- 莉波：她叫「莉波先輩」（0008）；莉波叫她「ことねちゃん」（0007）
- 副会長：她叫「副会長」（0010）；副会長叫她「藤田」「貴様」（0011）。副会長夸她打扫仔细（0013）；她当面恭敬，走后说「急に出てくんなよナ～」（0015）
