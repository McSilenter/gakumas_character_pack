# 藤田ことね 亲爱度剧情 / 第7话（adv_dear_fktn_007）

- 她的台词：43 行（含用匿名标签说的 0 行）
- 出场的人：ことね、プロデューサー
- 场景：演唱会工作定下之后、初ライブ之前（0001、0003）；地点剧本没写
- 世界线：亲爱度（藤田ことね）；制作人在制作的偶像：藤田ことね

## 发生了什么
制作人告诉 ことね 演唱会工作定了，但照现在这样初ライブ会失败，原因是她唱歌差、没到偶像的标准。她反问那为什么接演唱会，说自己被骂唱歌差已经好多年，能进步早就进步了。制作人说阻碍她进步的原因之一（过劳）已经去掉，剩下一个是“自信”：她认定自己的歌不值得称赞。制作人又说演唱会不是只听歌的地方，而是用自己的一切传达魅力的地方，她已经有这样的力量，只是唱歌差；她总结为“就算唱得差也要堂堂正正放开唱”，但又说这很难，自己一直是劣等生。制作人心里决定每天真心多夸她，好让她有自信（制作人的心里话，0050、0051）。被夸外貌和舞蹈后她干劲十足，宣布演唱会前每天进行唱歌特训，并请制作人一直在身边看着、像现在这样夸她；她说自己不相信自己，但相信救了她的制作人。最后她说一定让初ライブ成功，因为她要成为顶级偶像、成为大富翁。

## 行为模式
- 被直接指出缺点（唱歌差）→ 先叫苦，再反问、平语爆发，搬出多年被骂的经历（0008、0010～0015）
- 被说缺乏自信 → 承认，并把原因归结为“事实上就是差”（0022、0025、0026）
- 被夸有力量 → 先说「おだてて」不敢信（0037）；听到“但唱歌差”就吐槽制作人总是先捧后摔（0039）
- 理解了建议 → 自己用粗白的话总结一遍（0041、0042），但坦白做起来难（0045、0046）
- 被夸外貌、舞蹈 → 自己也认（「学園では／一番可愛い」），接着讨要更多夸奖（0047～0049、0052、0054）
- 有了干劲 → 主动定下每天特训，并请对方陪着、夸着自己（0058～0061）
- 没法相信自己时 → 改为相信帮过自己的人，借此撑住（0062、0063）

## 关系
- プロデューサー：她叫「プロデューサー」（0039、0058），撒娇时「プロデューサぁ～」「ぷろでゅーさー」（0054、0056）；制作人叫她「藤田さん」（0003、0028）。她说不相信自己但相信「あたしを助けてくれたプロデューサー」（0063），请制作人一直在身边看着、夸自己（0059、0060）

## 档案类事实
- 唱歌差，自己说被人说「歌が下手」叱责了好多年（0015）；制作人说她的歌没达到偶像标准（0009）
- 休养后身体状态比以前好很多（0017）
- 自称一直是劣等生（0046）
- 喜欢跳舞、觉得自己擅长（0047，对什么问题的回答见「不确定」）；觉得自己可能是学园里最可爱的（0048）
- 宣布演唱会前每天进行唱歌特训（0058）
- 目标：成为顶级偶像、成为大富翁（0066）
- 制作人心里说她作为偶像还不习惯被夸（0050，制作人的心里话）
