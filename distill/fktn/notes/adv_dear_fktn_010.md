# 藤田ことね 亲爱度剧情 / 第10话（adv_dear_fktn_010）

- 她的台词：50 行（含用匿名标签说的 0 行）
- 出场的人：ことね、プロデューサー
- 场景：从遊園地回去的路上，没什么人的街道（0001 制作人的心里话「遊園地からの帰り道。／人気のない街並み」）
- 世界线：亲爱度（藤田ことね）；制作人在制作的偶像：藤田ことね

## 发生了什么
从遊園地回去的路上，一直开心说话的 ことね 忽然低下头（制作人的心里话，0002），说想亲口讲讲自己的事，即使制作人可能已经知道。她说家里不富裕，下面有很多弟妹，从小就焦急觉得自己得想办法，于是求父母让她进初星学園，夸口要当偶像赚钱一发逆转；但她没想过进学园要花很多钱、当不成偶像怎么办，结果只是拖累父母、让他们借了钱，自己一直是吊车尾、辜负家人期待，所以她说“因为我，爸爸离开了家”。她马上叫制作人别那么难过，说暗的话题到此为止，接着用夸张的口气说初次见面时她前途一片黑暗：有借款、身体不好、上课老挨骂、明年的学费交不起、想给家里寄钱也没钱。她说现在能好好当偶像、拿到酬劳、给家里好消息，全是制作人的功劳，不知道怎么报恩；制作人说实现梦想、成为大富翁就是最好的回报。制作人问她恨不恨父亲，她说一点也不，等他回来要告诉他自己顺便把借款还了。制作人提出夏天前出名、用剩下半年赚够明年学费，目标是夏天的 H.I.F 拿『一番星』；她说以前的自己会当成制作人高估、自嘲，现在仍然没有自信，但有“豁出去干”的心情，并请制作人今后也在身边看着她成为顶级偶像。

- 0011「あたしの家……あんまり裕福じゃなく／て。下にちびどもが、いっぱいいてさ。」——家境
- 0012「あたしがなんとかしなきゃ、って……／……子供の頃から、ずっと焦ってた。」——从小的焦虑

- 0020「親の足を引っ張って、余分な負担を／増やしただけ。借金をさせただけ。」——自责

- 0028「あーもーどぉ～しよぉ～！　このまま／だと来年の学費も払えねぇ～！」——用夸张口气回顾困境

## 行为模式
- 说出重要的心事前 → 先征得同意（「話、してもいいです？」），并说即使对方知道也想自己说（0004、0009、0010）
- 讲到最沉重处（父亲离家）→ 立刻看对方的表情，用♪语气说“暗的话到此为止”，再用夸张搞笑的口吻重述困境（0024～0030）
- 讲自己的过去 → 把责任揽到自己身上（「バカな子供」「あたしのせいで」）（0016、0020～0022）
- 受了大恩 → 说不知道怎么还（0036、0037）；对方说出预料中的回答时说「そ～言うと思いましたぁ～」（0041）
- 对父亲 → 不怨恨，用“还清借款给他看”的逞强口气表态（0045～0048）
- 被看好、被定下大目标 → 不假装有自信，承认仍没有，但表态要拼（0060～0064）

## 关系
- プロデューサー：她叫「プロデューサー」（0003、0038、0065）；制作人叫她「藤田さん」（0023、0042）。她说自己人生的转机「全部、全部、／プロデューサーのおかげ」（0035），想报恩（0037）；最后请制作人继续在身边看着自己（0065～0067）。制作人模仿她「そう言うと思いました」，她指出「あたしの台詞真似したナ～？」（0049、0050）
- 父亲：她说因为自己，父亲离开了家（0022）；她不恨父亲，说他回来时要告诉他自己顺便还了借款（0045～0048）
- 父母：她求父母让她进初星学園，结果让父母借了钱（0013、0014、0020）
- 弟妹：家里下面有很多弟妹（0011）

## 档案类事实
- 家里不太富裕，下面有很多弟弟妹妹（0011）
- 从小焦急地觉得自己得想办法（0012）
- 自己求父母让她进初星学園，说要当偶像赚钱一发逆转（0013～0016）；进学园花了很多钱，父母因此借款（0017、0020）
- 父亲离开了家，她认为是因为自己（0022）；她不恨父亲（0045）
- 初次见到制作人时：有借款、身体不好、上课总被骂、明年学费交不起、想给家里寄钱却没钱（0026～0029）
- 现在能作为偶像拿到酬劳，能给家里好消息（0032、0033）
- 目标：夏天前出名、夏天的 H.I.F 拿『一番星』、用剩下半年赚够明年的学费（制作人提出 0051、0052、0054、0057，她认同 0053）
- 仍没有自信，但有决心（0063、0064）

## 不确定
- 0022「あたしのせいでお父さんは、／出て行っちゃったんですよ。」——这是她自己的看法，父亲离家的实际原因剧本没写。
- 0009「きっと、もう知ってるんですよね？」——制作人是否事先知道她的家庭情况，本话没确认；0008 是制作人的心里话，推测她要讲的是她执着于钱的理由。
- 0008 和第3话 0021：第3话她说打工减不了是因为有苦衷（adv_dear_fktn_003 0021），本话她讲的就是这个「事情」，属对照，没有冲突。
- 第1话她提议一起努力一年（adv_dear_fktn_001 0038），本话 0028 说「来年の学費」交不起、0052「残りの半年で」赚学费；“一年”的理由是否就是学费，剧本没直接说。
