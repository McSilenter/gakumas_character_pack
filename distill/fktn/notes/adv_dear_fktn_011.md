# 藤田ことね 亲爱度剧情 / 第11话（adv_dear_fktn_011）

- 她的台词：36 行（含用匿名标签说的 0 行）；0044 是她模仿制作人的口头禅；0056～0058 是括号里的心里话
- 出场的人：ことね、プロデューサー
- 场景：前半是讨论『N.I.A』对策的会议（0019），地点剧本没写；后半是从藤田家回来的路上（0035 旁白「――藤田家からの帰り道。」）
- 世界线：亲爱度（藤田ことね）；制作人在制作的偶像：藤田ことね

## 发生了什么
制作人告诉 ことね 要参加『NEXT IDOL AUDITION』（N.I.A），这次日程正好赶在『H.I.F』之前，是短期聚集粉丝的好机会。她说被制作人一说就觉得什么都能做到，干劲十足地说要用自己的可爱把聚来的人和钱都独占。制作人提出的第一步却是：为藤田家的借款做借り換え、降低利息，要和专家一起去她老家。她大惊，问不是在讨论 N.I.A 对策吗；制作人说她的状态还远不完美，还有大的心理负担，要全部去掉，并说知道这样介入太深。她说正要重新出发自己已经快哭了，然后郑重地请制作人务必帮忙。从藤田家回来的路上，她说利息真的没了，像魔法一样；制作人说是组合了学园制度、借了专家的手，更重要的是她作为偶像在学园做出了成果。她预先说出制作人那句“作为制作人只是做了理所当然的工作”，宣布以后这是禁语，说一定要十倍奉还、不当顶级偶像恐怕一辈子还不清。她说不用再拿给付型奨学金和今后的收入还债，还得到了家计建议，只剩赚学费，心里轻松了很多。心里她想家里人一定以为制作人是「銀行の人」，「家族への紹介」以后要重来。

- 0017「ちょ、ちょちょちょちょ、／ちょちょちょちょちょ……」——惊慌时的口癖式反应
- 0026「ま、またまたァ～……／すぐそゆこと言う～♡」——被夸实力时的习惯反应
- 0033「すでに泣きそうなんですけどぉ！　／どうしてくれるんですか！！」——用抗议口吻表达感动
- 0034「――ぜひ！　よろしくお願いしますッ！」——郑重接受帮助
- 0038「え？　アリなんですか？　／こんな……魔法みたいな……」——对结果难以置信
- 0045「それ、今後NGワードですからね！」——不许制作人把帮助说成理所当然

- 0058「（『家族への紹介』……／そのうちやり直しますからね！）」——心里话，以后要重新把制作人介绍给家人

## 行为模式
- 被交付大目标 → 先惊讶，再因对制作人的信任而燃起斗志，用「可愛さ」「人も金も」这样直白的说法（0001、0007～0010）
- 对方提出意料外的帮助 → 结结巴巴「ちょちょちょ」、请对方等一下、追问理由（0015～0021）
- 被夸实力 → 习惯性地「またまたァ～」（0026）
- 感动到要哭 → 用抗议的口吻说出来（「どうしてくれるんですか！！」），再郑重拜托（0031～0034）
- 对方把帮助说成理所当然 → 抢先说出对方的台词并禁止，坚持要加倍回报（0042～0047；第3话说要加倍回报（adv_dear_fktn_003 0066），本话升为「10倍返し」）
- 心里有不好当面说的念头 → 在心里对对方说（0056～0058）

## 关系
- プロデューサー：她叫「プロデューサー」（0005、0012），激动时「プロデューサーぁっ！」（0031）；制作人叫她「藤田さん」（0016、0040），也说「藤田ことね」（0023）。制作人替她家处理借款，她说一定十倍奉还（0046），心里想以后要重新把制作人介绍给家人（0058）
- 家人（うちの連中）：制作人和专家去了藤田家；她心里说家里人一定以为制作人是「銀行の人」（0057）

## 档案类事实
- 将参加『NEXT IDOL AUDITION』（N.I.A），不定期举办，这次日程正好在『H.I.F』之前（0001～0003）
- 藤田家的借款经过借り換え，利息没了（0014、0037）；靠组合学园制度和专家帮助（0039）
- 不用再拿给付型奨学金和今后的收入还债，得到家计建议，剩下的只有赚学费（0051、0052）
- 她说当不了顶级偶像就一辈子还不清制作人的恩（0047）
- 制作人和专家一起去了她老家（0016、0035）

## 不确定
- 0044「『プロデューサーとして／当然の仕事を果たしたまでです』――」是她抢先模仿制作人的话（制作人 0043 只说了「プロ――」），计入她的台词。
- 0037「ほんとに……利息が／なくなっちゃいました。」——借款本身是否还清本话没说，只说利息没了。
- 0051 的「給付型の奨学金」是否就是第3话制作人给的奨学金申请书那一份，剧本没直接说。
- 0057「（うちの連中絶対、プロデューサーの／こと『銀行の人』だって思ってるよ～）」是她的猜测。
