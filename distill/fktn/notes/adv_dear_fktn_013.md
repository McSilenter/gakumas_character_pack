# 藤田ことね 亲爱度剧情 / 第13话（adv_dear_fktn_013）

- 她的台词：35 行（含用匿名标签说的 0 行）
- 出场的人：星南、ことね、プロデューサー
- 场景：制作人出差期间（0001）；地点剧本没写
- 世界线：亲爱度（藤田ことね）；制作人在制作的偶像：藤田ことね（0030 制作人「藤田さんには『N.I.A』を通して」、0015 星南「あなたのプロデューサー」）

## 发生了什么
制作人出差期间，ことね 问星南知不知道出差的事，星南先纠正称呼，她从「星南会長」改成「星南先輩」。星南说是秘密，又说制作人是了不起的人，让她放弃了得到 ことね——两人比了一场“谁更爱、更能引导藤田ことね”；ことね 不想听，说别在本人不在的地方搞这种恶心的比赛，又说制作人有多厉害她最清楚，星南叫她相信着等。星南问她怎么看制作人的方针（通过『N.I.A』提升实力、拿『一番星』、用剩下的半年赚学费）；星南说 ことね 是她的希望、『一番星』的继承人候选，但那是明年以后的事，今年她不会让出胜利。制作人说 ことね 顺利成长就有足够胜算，会以1年生拿下『一番星』、一路成为顶级偶像（场面见「不确定」）。ことね 说制作人太喜欢她才看走眼，但她已决定相信制作人；星南问她为什么不说要打败自己，她说因为太重：她是十王星南的「古参ファン」，从小星南在电视上跳舞时就知道她，看过星南中等部时做下積み、升上高等部后迅速崛起、打败厉害的前辈成为『一番星』，十王星南早在发光之前就是她的星星。她说说这话很重、很可怕，但还是宣布要打败星南、成为『一番星』；星南问明年不行吗，她说那时星南已经毕业不在了。星南接受挑战，说会用自己的一切迎战。剧情经过参照 jsna 笔记。

## 行为模式
- 被要求改称呼 → 不肯直呼名字，一步步折中（「会長」→「星南会長」→「星南先輩」）（0001、0003、0005）
- 对方要讲自己不想听的事 → 抢先打断、吐槽「気持ち悪い」，再三说不想听（0017、0019、0020、0022）
- 别人夸制作人 → 说自己最清楚（0023、0024）
- 被高度评价（1年生拿『一番星』）→ 惊叫，再归结为制作人太喜欢她看走眼（0045、0050、0051）；但随后表明已决定相信制作人（0053）
- 要说出重大的话 → 先停顿，说明为什么难以开口（「重い」「怖い」），讲完自己的心路，再明确说出口（0054、0056、0058～0073）
- 对长期仰望的人 → 一直隐藏自己是粉丝，到必须宣战时才说出（0060、0062）

## 关系
- 星南：她叫「会長」（0001）、「星南会長」（0003）、「星南先輩」（0005、0066、0073）；说到过去时称「十王星南」「ちっちゃい星南ちゃん」（0060、0063、0070）。星南叫她「ことね」（0002、0078）。她自称是十王星南的古参粉丝，从星南小时候上电视跳舞起就一直看着（0060～0068），说十王星南是「あたしの星」（0070）；本话向星南宣战，要打败她成为『一番星』（0073），星南接受（0078）
- プロデューサー：她叫「プロデューサー」（0001、0050）；制作人叫她「藤田さん」（0030、0044）。她说制作人的厉害她最清楚（0024），决定相信制作人（0053）；对制作人说她会以1年生拿『一番星』，她仍说是制作人太喜欢她看走眼（0048～0051）

## 档案类事实
- 她是1年生（制作人所说 0048「彼女は、1年生で／『一番星』を獲ります。」）
- 自称十王星南的古参ファン，一直隐藏；从小星南在电视上跳舞时就知道她，看过星南中等部时做下積み、高等部后崛起、打败前辈成为『一番星』（0060、0062～0068）
- 星南今年毕业，所以她要在今年打败星南（0077）
- 目标：通过『N.I.A』提升实力，拿『一番星』，用剩下半年赚学费（制作人所说 0030、0031）
- 星南说她是星南的希望、『一番星』的继承人候选（0034，星南所说）

## 不确定
- 0008、0009、0030、0031、0043～0049 的说话人是プロデューサー，但制作人此时在出差（0001）；这些是回忆、转述还是别的场面，剧本没交代（jsna 笔记也记了同样的疑问）。0045 她对 0044 的反应「はぇぇッ！？」说明她听到了这些话，在什么场合听到不清楚。
- 0018 星南说的「勝負」具体内容她不让讲（0019～0022），本话没说清。
- 第8话她说初ライブ是学园生活第4年（adv_dear_fktn_008 0003），和本话 0048「1年生」：如果中等部算在学园生活内，两者不矛盾；剧本没明说，不标冲突，留待确认。
- 0062「古参って、数年前とかじゃないですよ。」——具体从几岁开始关注星南没说。
- 0052 星南「そう……よね。」是否附和她的“看走眼”说法，语气不明（参照 jsna 笔记）。
