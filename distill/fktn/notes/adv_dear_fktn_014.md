# 藤田ことね 亲爱度剧情 / 第14话（adv_dear_fktn_014）

- 她的台词：24 行（含用匿名标签说的 0 行）；0017、0018 是括号里的心里话
- 出场的人：星南、ことね
- 场景：星南的房间，制作人出差期间的会议（0001、0002）
- 世界线：亲爱度（藤田ことね）；制作人在制作的偶像：藤田ことね（0049 星南「これはプロデューサーの／意志でもあるの。」）

## 发生了什么
制作人不在，教室用不了，会议改在星南的房间开，ことね 问为什么不用生徒会室，星南说她不是学生会成员、不能公私混同，她吐槽把学生会变成偶像事务所的人还说这种话。进门后星南锁了门，ことね 发现星南房里有摆放偶像周边的「祭壇」，全是她自己的周边，心里对制作人喊“果然不是误会吧”，担心能不能平安回去。星南说学生会主导在卖随机封入生写真的卡包，第1弹是倉本千奈，正在策划第3弹做藤田ことね；她感叹制作人和星南联手就会变成这样。星南接着讲『N.I.A』的对手：極月学園最强，藍井撫子、白草四音是目前的优胜候补，極月学園大力宣传、在关键オーディション派出多名精锐并带着粉丝；即将举行的公开オーディション『QUARTET』已是極月的魔城。ことね 说参加的人真可怜，星南却要她去把对手打散，说这也是制作人的意志，要追上『一番星』至少得做到这一步；对手一个和她同等、一个远在她之上，又是完全的客场。她说给她无理要求的人变成两个了，最后喊「やってやりますよチクショー！！！」。剧情经过参照 jsna 笔记。

## 她的关键台词
- 0001「あの～……なんでミーティングの／場所が、星南先輩の部屋なんですかね。」——对会议地点的疑问
- 0005「生徒会をアイドル事務所化している人が／なんか言ってる……」——对星南的吐槽
- 0007「……いちいち言動が不審なんだよナ～。」——仍觉得星南可疑
- 0014「あたしのグッズばっか／なんですけどォ！？」——发现祭坛上全是自己的周边
- 0017「（プロデューサー！　やっぱり誤解じゃ／なかったんじゃねーの！？）」——心里话，对上一话“误会解开”的怀疑
- 0018「（あたしこの家から／無事に帰れんのかな……）」——心里话
- 0024「うわー……プロデューサーと／星南先輩が組むと……こーなるんだぁ。」——对两人联手的感叹
- 0032「おぉ～……星南先輩、／ちょっとプロデューサーみたいっすね。」——对星南用「っす」
- 0041「うわ露骨……絶対勝てないじゃん……／そんなの……」——对極月做法的反应
- 0044「コワ～。参加する人、気の毒っすね～。」——以为与己无关
- 0057「うお～～無茶振りしてくるやつが／ふたりになったぁ～～！　や……」——制作人和星南两人都给她难题
- 0058「やってやりますよチクショー！！！」——自暴自弃式地接下挑战

## 行为模式
- 对星南的怪异举动 → 当面小声吐槽或心里吐槽（0005、0007、0009、0017），但仍按星南说的做（0019、0020）
- 和星南说话 → 用“～っすね”这类随意的敬语（0032、0044）
- 以为事情与己无关 → 轻松地说风凉话（0044）；得知是自己要上 → 呆住、惊叫（0047、0048）
- 被交付难题 → 先确认条件（0053），抱怨，再大声接下（0057、0058）

## 关系
- 星南：她叫「星南先輩」（0001、0024、0032），惊慌时又叫「会長」（0011）；星南叫她「ことね」（0004、0045）。她仍觉得星南言行可疑（0007、0017），看到满是自己周边的祭坛很害怕（0014、0018）；星南给她讲对手、要她去『QUARTET』打败对手，她说「無茶振りしてくるやつ」变成两个（0057）
- プロデューサー：不在场。她在心里对制作人喊话（0017），把星南和制作人一起看作给她出难题的人（0024、0057）

## 档案类事实
- 学生会主导在卖随机封入偶像生写真的卡包，第1弹倉本千奈，正策划第3弹做藤田ことね（0021～0023）
- 星南房里有摆着她周边的「祭壇」（0013、0014）
- 『N.I.A』最大的障碍是極月学園，藍井撫子、白草四音是目前的优胜候补（0029～0031）
- 她将参加公开オーディション『QUARTET』，是完全的客场；对手一个和她同等、一个远在她之上（0042、0046、0054、0055）
- 她听说过極月学園把初星学園视为对手（0036）
- 星南说她不是学生会成员（0004）
