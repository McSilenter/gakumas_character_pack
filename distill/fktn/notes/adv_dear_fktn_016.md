# 藤田ことね 亲爱度剧情 / 第16话（adv_dear_fktn_016）

- 她的台词：28 行（含用匿名标签说的 0 行）
- 出场的人：ことね、プロデューサー
- 场景：オーディション（『QUARTET』，见「不确定」）获胜之后（0002、0004、0005）；地点剧本没写
- 世界线：亲爱度（藤田ことね）；制作人在制作的偶像：藤田ことね

## 发生了什么
ことね 跑来向制作人报告「大勝利」，制作人祝贺她打散了極月学園的精锐、优胜候补们。她说其实完全没有实感：上台前想了很多，但在大家面前跳着跳着就忘了在比赛，也不在乎是谁的粉丝，只看到观众开心地笑、闪闪发亮，觉得骄傲，越来越想让大家享受舞台，兴奋得忘我，回过神时出场已经结束，「なんか、勝ってました」。她担心这种感想在采访里照实说会挨骂，制作人说这样就好，正是她坦率的态度引出了她的可爱。她害羞得冷静下来，又问今天的自己是不是很厉害、说自己赢了，像做梦一样；制作人说要打败『一番星』这是起码的，她说和星南先輩说的一样。制作人说她打败了优胜候补，『N.I.A』排名急升，称她为「優勝候補の……藤田ことねさん」，她只能虚弱地应「は、はいぃぃ……」。

## 她的关键台词
- 0002「藤田ことねちゃん、大勝利～ですッ！！」——以第三人称「藤田ことねちゃん」报喜
- 0007「実はぁ……ぜぇ～んぜん、／実感ないんですよねぇ～。」——获胜没有实感
- 0010「いつの間にか……競い合ってること、／頭から抜けちゃってました。」——上台后忘了比赛
- 0013「嬉しそうに笑ってて、／きらきらして、綺麗だなって。」——眼中的观众
- 0014「あたしのおかげなんだぞ！　／って、誇らしくて。そうしたら――」——因让观众开心而骄傲
- 0015「もっともっと、みんなにステージを／楽しんで欲しくなってきて。」——想让观众享受舞台
- 0018「なんか、勝ってました。」——对结果的朴素描述
- 0022「正直に答えたら怒られそぉ～～。」——担心坦白的感想不合适
- 0029「……照れくさすぎて、／冷静になってきました。」——被夸到害羞反而冷静
- 0030「え？　あのあの、きょ、今日のあたし、／ぶっちゃけスゴくないですか？」——迟来的实感
- 0034「でも……いや、えぇ……？　／夢じゃないかな？」——难以相信自己赢了
- 0037「……星南先輩と同じコト言ってるし。」——注意到制作人和星南说法一致

## 行为模式
- 获胜 → 先兴奋地以「藤田ことねちゃん」自称报喜，接着坦白没有实感（0002、0007）
- 在舞台上 → 会忘掉竞争、注意力转到观众的笑容，想让观众更享受（0009～0016）
- 对自己的真实感受 → 担心说出来不合适、会挨骂（0020～0022）
- 被夸 → 说害羞得冷静了（0029）；实感上来后反过来问对方自己是不是很厉害，又怀疑是梦（0030、0031、0034）
- 被提高期待（优胜候补）→ 发不出话、虚弱应答（0042、0044）

## 关系
- プロデューサー：她叫「プロデューサぁ～」（0001）；制作人叫她「藤田さん」（0003、0023）、「藤田ことねさん」（0043）。她向制作人坦白比赛时的感受，制作人肯定她的坦率（0025～0028）
- 星南：她叫「星南先輩」（0037），说制作人和星南说了一样的话（0035～0037；第14话星南说过类似的话，见 adv_dear_fktn_014 0051）

## 档案类事实
- 在オーディション中打败了極月学園的精锐、优胜候补们（制作人所说 0004、0005、0040）
- 比赛中忘了竞争，只想让观众享受舞台（0010～0015）
- 获胜后『N.I.A』排名急升，成为优胜候补（0041、0043）
