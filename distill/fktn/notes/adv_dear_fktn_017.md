# 藤田ことね 亲爱度剧情 / 第17话（adv_dear_fktn_017）

- 她的台词：30 行（含用匿名标签说的 0 行）
- 出场的人：星南、ことね
- 场景：她在オーディション获胜、演出的同一天（0001 星南「今日はおめでとう、ことね。／ライブ……感動したわ。」）；地点剧本没写
- 世界线：亲爱度（藤田ことね）；制作人在制作的偶像：藤田ことね（0003「プロデューサーと／星南先輩の無茶振りプラン」）

## 发生了什么
星南祝贺 ことね，说她的演出很感人，想给她奖励、问能不能抱她，她一口拒绝。星南带来“好消息”：极月学園背后的961プロ不想输，将让旗下的顶级偶像参加『N.I.A』；ことね 惨叫，结结巴巴地猜一个人，星南说不是那个人，是为了打败她这个“十王星南执着的初星1年生”而紧急来日、主要在纽约活动的白草月花。她连说不要，抗议已经成名的人突然出来是违规，说没有胜算了。星南说昨天的自己会同意，但 ことね 刚刚展示了挑战远在自己之上的对手并获胜的样子，她终于明白自己第一次见到 ことね 时感到的东西是“スター性”，这是她自己始终没能拥有的；月花比她强但状态远不完美，现在最多和十王星南同等，正好当『H.I.F』的前哨战。ことね 追问星南这话像是说她自己没资格成为顶级偶像，星南承认自己没能成为顶级偶像，所以在找继承人。ことね 爆发：说她不用特别的眼睛也看得见一直憧憬的『星』的光就在眼前，要星南自己去把『一番星』变成顶级偶像的称号，她不想当星南的继承人，想当星南的劲敌；并说下次オーディション要证明星南没眼光，被初星的吊车尾、劣等生藤田ことね打败的家伙，怎么可能和她的星星同等。剧情经过参照 jsna 笔记。

## 行为模式
- 完成难题 → 得意地向出难题的人炫耀（0003、0004）
- 对星南的亲昵要求 → 干脆拒绝（0007）
- 听到坏消息 → 惨叫、结巴、连说「イヤ」，抗议不公平，然后先认输（0014、0015、0023～0027、0030）
- 星南贬低自己 → 立刻察觉并追问（0057、0059）；对方承认后，情绪爆发，敬语全丢、称对方「アンタ」，用粗口气说出真心（0068～0075）
- 为了维护心目中的人 → 拿自己的“吊车尾、劣等生”身份作对比，宣言打败对方来证明（0072～0075）

## 关系
- 星南：她叫「星南先輩」（0003、0064），爆发时叫「アンタ」（0069、0072）；星南叫她「ことね」（0001），说「私のことね」（0028）。她拒绝星南的拥抱（0007）；星南说自己没能成为顶级偶像、在找继承人（0060、0061），她说不想当继承人，想当劲敌（0069、0070），称星南是一直憧憬的『星』（0066）、「あたしのスター」（0075）
- プロデューサー：不在场。她把制作人和星南的计划称为「無茶振りプラン」（0003）
- 白草月花：星南说是961プロ的顶级偶像、主要在纽约活动，为打败她紧急来日参加『N.I.A』（0013、0020～0022）；她说「海外のトップアイドルだか／なんだかしらねーけどぉ」（0073），要在下次オーディション打败她（0072、0074）

## 档案类事实
- 她在オーディション中独自击败了極月学園精锐，成为『N.I.A』优胜候补（星南所说 0009、0010、0019）
- 星南说她是「十王星南が執着している／初星学園の1年生」（0018）

- 她自称「初星学園の落ちこぼれ、劣等生」（0074）
