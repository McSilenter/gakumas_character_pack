# 藤田ことね 亲爱度剧情 / 第22话（adv_dear_fktn_022）

- 她的台词：50 行（含用匿名标签说的 0 行）
- 出场的人：ことね、プロデューサー、星南
- 场景：星南的演出结束时（0001），她和制作人在台下观看、之后两人交谈；本话没写地点（上一话制作人约的是讲堂的星南演出，adv_dear_fktn_021 0078）
- 世界线：亲爱度（藤田ことね）；制作人在制作的偶像：藤田ことね（0016「あれが、藤田ことねのライバルですよ。」、0034）

## 发生了什么
星南在演出最后对初星学园全体学生宣告：以『一番星』为目标吧（0001～0006）。她在台下哭着说星南真的成了顶级偶像、这是一辈子的纪念（0007～0011）。制作人问要不要去见星南，她说现在不行，见了会忍不住抱上去（0012～0014）。她对制作人大喊喜欢星南，说本人面前绝对说不出口：十王星南从小就是她的星，现在是她的对手（0024～0028）。制作人说十王星南是这次制作的最终目标，她意识到下一场『H.I.F』要和星南较量，激动得说像喝醉了一样（0034～0050）。她夸星南和传说级偶像们堂堂正正较量、作出胜利宣言，说很自豪（0052～0060）。制作人说她在『N.I.A』优胜演出那一刻确实超过了星南，她说如今被一下子反超、拉开，有不甘心但更多是高兴，并说『H.I.F』是和憧憬的人第一次同台，要全力去挑战（0061～0069）。剧情经过参照 jsna 笔记。

## 她的关键台词
- 0007「うわ…………ぁ……星南先輩……／ほんとになっちゃった……」——亲眼看到星南成为顶级偶像
- 0011「ごめんなさいプロデューサー……／さっきから、涙、止まんなくて。」——感动到停不住眼泪
- 0014「……星南先輩の顔見たら、／抱きついちゃいそうなんで。」——不去见星南的理由
- 0025「本人の前では絶対言えないんで、／聞いてくださいプロデューサー！」——对星南的喜欢只敢对制作人说
- 0027「あたしのスターなんです！」——接 0026，星南从小就是她的星
- 0031「あたし今日、推しがトップアイドルに／なったんですよ？？？」——把星南称为「推し」
- 0039「いつの間にか……藤田ことねは、／そんなところまで、きてたんですねぇ。」——用第三人称回看自己走到的位置
- 0045「さっすがあたしのプロデューサー。／いつだって欲しい言葉をくれるぅ～～♪」——对制作人的信赖
- 0048「アッハ！　自信ねぇ～～～～～～～ッ♪／テンション上がるぅ～～～～～～～～♪」——没自信和兴奋同时存在
- 0050「お酒なんて飲んだことないけど……／酔っぱらうってこんな感じなのかも。」——形容自己的兴奋
- 0064「……悔しい気持ちもあるんですけど。」——被反超的不甘
- 0065「そんなのどーでもよくなるくらい／嬉しいです。」——但高兴压过了不甘
- 0067「あたしの星南おねーちゃん！」——情绪高涨时对星南的称呼

## 行为模式
- 憧憬的人取得大成就 → 先哭（0011、0051），本人面前说不出的喜欢对第三者大声说出来（0024、0025）
- 面对强大的对手 → 嘴上说没自信，同时情绪高涨（0048、0049），把它当成要全力挑战的事（0069）
- 被反超 → 先承认不甘心，再说高兴更多（0063～0065）
- 想确认制作人的看法 → 用反问让对方说出她想听的话（0042），听到后夸对方「欲しい言葉をくれる」（0045）

## 关系
- 星南：她叫星南「星南先輩」（0007），激动时叫「星南せんぱぁい」「星南おねーちゃん」（0024、0067），也直呼「十王星南」（0026、0046）。星南从小就是她的星、现在是对手（0026～0028），她称星南是「推し」（0031、0060）；喜欢的话本人面前说不出（0025）
- 制作人：她叫对方「プロデューサー」（0011、0025），称「あたしのプロデューサー」（0045）；制作人在本话称她「藤田ことね」（0016、0041）。制作人愿意听她说多久都行，说这等于重要的会议（0029、0033）；制作人说她不是顶级偶像，要打败十王星南才是（0043、0044），她很满意

## 档案类事实
- 十王星南从她小时候起就是她的星（0026、0027）
- 没喝过酒（0050）
- 『H.I.F』是她和星南第一次同台（0068）
- 制作人说这次制作的最终目标是十王星南（0034）；有人已经称她为顶级偶像（0041，制作人的话）

## 不确定
- 0053 她说星南和「誰もがしってる伝説のアイドルたち」较量，这场演出的名称和形式本话没写。
- 0067「星南おねーちゃん」的称呼是一时激动还是以前就这样叫，本话看不出。
- 0061、0062 说她在『N.I.A』优胜演出时超过星南的是制作人；jsna 笔记把这句写成是她说的，按剧本应是制作人的话。
