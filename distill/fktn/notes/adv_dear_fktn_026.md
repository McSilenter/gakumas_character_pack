# 藤田ことね 亲爱度剧情 / 第26话（adv_dear_fktn_026）

- 她的台词：42 行（含用匿名标签说的 0 行）；0008～0012 是括号里的心里话（说话人标签是ことね），照算
- 出场的人：ことね、プロデューサー
- 场景：夏季『H.I.F』败退的第二天早上（0001、0002；0003「オハヨーございマース」），本话没写地点
- 世界线：亲爱度（藤田ことね）；制作人在制作的偶像：藤田ことね（0004、0052）

## 发生了什么
『H.I.F』败退第二天，她和制作人见面，心里觉得很尴尬，想着昨晚第一次看到制作人那样的哭脸（0008～0012）。制作人说自己只是装作若无其事，她以为心里话说出了声，制作人说只是猜的（0013～0016）。制作人说要切换心情，她说努力，喊了声「切り替えた――ふり！」（0018～0020）。她说下一个目标是冬季『H.I.F』，要向十王星南复仇、优胜、成为『一番星』、当上顶级偶像，但不知道该怎么做，因为以前调整到最佳状态的方针也没赢（0022～0029）。制作人说多数情况下制作是从最佳状态起步的，这次才是例外，接下来就普通地多上课、多工作；并定下中间目标：在『选抜試験』之前靠偶像工作赚100万日元，顺利的话剩下的借金也能还清（0030～0057）。她说制作人还是很会让她来劲，制作人说从找到她那天起练习了很多次（0059、0060）。最后她要制作人约定：如果她达成中间目标，就叫一次她的名字；制作人先答应了不管什么都会实现（0062～0073）。

## 行为模式
- 尴尬的场面 → 嘴上打招呼语调怪（「オハヨーございマース」），心里吐槽（0003、0008～0011）；被说中心事时埋怨对方「タチ悪い」（0016）
- 被要求切换心情 → 不假装做得到，说「努力はします」，然后说是“装作切换”（0019、0020）
- 不知道答案 → 直说不知道，并把为什么不知道讲清楚（0026～0029）
- 面对很大的数字目标 → 先怀疑自己做不到（0051），一听能还清借金就立刻来劲（0057、0058）
- 想提私人请求 → 先吊胃口、确认对方答应，再说出来，最后要约定（0063～0073）

## 关系
- 制作人：她叫「プロデューサー」（0062）；制作人叫她「藤田さん」（0004、0021）。她请求达成中间目标后制作人叫一次她的名字（0071、0072），对应上一阶段她给自己定的目标（adv_dear_fktn_021 0036）。制作人说从找到她那天起就反复练习怎么让她来劲（0060）
- 星南：本话称「十王星南」（0022），是冬季『H.I.F』的复仇对象

## 档案类事实
- 夏季『H.I.F』败退（0001）
- 下一个目标是冬季『H.I.F』（0022）
- 中间目标：在『選抜試験』之前靠偶像工作赚100万日元（0045、0046，制作人提出）
- 她还有剩余的借金（0057，制作人的话：顺利的话能还清）
- 制作人说以前的方针是休养、消除疲劳、减少烦恼，调整到最佳状态（0027、0028 她的话；0031 制作人说这次是例外）
