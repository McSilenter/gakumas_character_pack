# 藤田ことね 亲爱度剧情 / 第29话（adv_dear_fktn_029）

- 她的台词：59 行（含用匿名标签说的 0 行）；0093～0095 是括号里的心里话（标签是ことね），照算；0032、0033 是她即兴哼唱的“钱之歌”
- 出场的人：ことね、プロデューサー、手毬、燕、あさり先生、清夏、莉波、麻央
- 场景：本话没写地点；『選抜試験』即将开始之前（0040 手毬的话），分成几段：她和制作人会议、她拿到报酬计算单、被手毬・清夏围观、报酬计算的第二天（0064「昨日チャージしたばかり」）和制作人谈六大オーディション、最后燕闯进来
- 世界线：亲爱度（藤田ことね）；制作人在制作的偶像：藤田ことね（0095 她心里说「担当アイドル」）

## 发生了什么
她问制作人怎么积累成功体验，中间插入一段制作人向莉波、麻央提出合同训练和某个企画、两人答应的场面（0001～0011）。制作人把她到目前为止的偶像活动报酬算出来给她，她激动到呛咳，得知这些钱会打进她的存折后高兴得哼起钱之歌（0013～0033）。手毬说她浮躁到智商下降，她反击，自称「暫定年収！　148万2600円」的可爱偶像，要比钱包；清夏的钱包输给了她的2万300日元，但手毬打电话问了千奈，转述千奈不带钱包、光电视酬劳就超过一个被遮挡的金额，她崩溃大叫（0034～0061）。她哭着找制作人要再充一次自我肯定感，制作人让她这次靠自己——挑战六大オーディション（0062～0072）。あさり先生解释六大オーディション是学外顶级偶像的登龙门，全部制霸会得到特别的称号（0074～0078）。她先吃惊，接着说要挑战十王星南、拿一两个头衔不在话下，被制作人看穿是空元气；制作人让她参加重视舞蹈的『舞道場』，她心里吐槽参加的都是舞蹈高手、又感叹制作人信任她，嘴上要制作人推她一把（0080～0097）。听到『舞道場』的奖金，她两眼放光，说真刀真枪的比赛不是她的风格，但有奖金就另当别论，自称『賞金稼ぎ』ことねちゃん（0098～0108）。最后燕闯进来，向她提出决斗，说自己才是『十王星南のライバル』（0109～0115）。剧情经过参照 ttmr 笔记。

## 行为模式
- 看到钱、收入 → 情绪暴涨到失态（呛咳、哼歌、怪笑），说自己无敌（0016～0033）
- 心情好时被人挖苦 → 不当回事，反而炫耀（0039～0045）；但被更强的对象一比就马上崩溃，跑去找制作人要安慰（0060～0067）
- 被交付超出预期的挑战 → 先吃惊吐槽（0079～0083），再答应、放狠话（0084～0086），被看穿是空元气就老实承认（0088）
- 心里吐槽制作人太信任她 → 嘴上则是“我会干，但没自信，请推我一把”（0093～0097）
- 有奖金 → 弱气一扫而空、真正拿出气势（0100～0106，0103 制作人的话）

## 关系
- 制作人：她叫「プロデューサー」（0001、0080），撒娇时叫「ぷろでゅしゃぁ」（0062）；制作人叫她「藤田さん」（0068）。制作人说她是「お金を愛する／現金なアイドル」（0024），她说不太像夸奖但说制作人懂她（0026、0027）。她心里说制作人还是那样信任担当偶像（0094、0095）
- 手毬：手毬说她智商下降、元劣等生的猴子，叫她「ことね」（0035～0040、0055）；她回嘴，叫手毬「オマエ」（0042），比钱包时得意，被千奈的结果击垮（0060）
- 清夏：清夏问她钱包里有多少钱，比输了（0046～0049）
- 千奈：她称「千奈ちゃん」（0090），把千奈称为「その御方」，说拿千奈来比是犯规（0053）
- 佑芽：『舞道場』的预计参加者之一，她叫「佑芽」（0090）
- 燕：她叫「雨夜先輩」（0112）；燕叫她「藤田」「貴様」，向她提出决斗、自称『十王星南のライバル』（0110～0115）

## 档案类事实
- 制作人给她算出到目前为止的偶像活动报酬，会打进她的存折（0015、0021、0022）
- 她自称「暫定年収！　148万2600円」（0043）；当时钱包里有2万300日元（0048）
- 六大オーディション：学外、被称为顶级偶像登龙门的6个大型选拔，全部制霸者会得到特别称号（0075～0077，あさり先生的话）
- 她要参加的是重视舞蹈表演的『舞道場』（0089、0091，制作人的话）；预计参加者有千奈、佑芽等舞蹈高手（0090）；奖金金额被遮挡（0098）
- 她自认是可爱系偶像，觉得真刀真枪的比赛不是她的风格（0104）
- 手毬说她是「元劣等生」（0040，手毬的话）
