# 藤田ことね 亲爱度剧情 / 第32话（adv_dear_fktn_032）

- 她的台词：60 行（含用匿名标签说的 0 行）
- 出场的人：ことね、プロデューサー、燕
- 场景：她在『選抜試験』中赢了和燕的决斗之后（0012、0014），『選抜試験』全部结束（0019）；本话没写地点
- 世界线：亲爱度（藤田ことね）；制作人在制作的偶像：藤田ことね（0031「あなたのプロデュースに夢中で」）

## 发生了什么
她问燕有没有看她的演出，燕夸她，说输给后辈还被后辈顾虑就没面子了，要她挺胸高兴；她说被夸不好意思，最后大声说「あたしの――勝ちです！！」，燕说本战再见（0001～0016）。她回到制作人那里，制作人说『選抜試験』全胜、进入本战没问题；她说从夏季『H.I.F』败退到现在终于回来了，要再次挑战两个人的梦（0017～0027）。她说多亏制作人，身体完全好了、不用担心任何事，能像大家一样普通地上课、选拔、演出，这份恩情一辈子都还不完（0033～0037）。她说不管对手多强、多憧憬，为了两人的梦都会伸手去抓；上了台会忘掉一切，但积累的东西不会消失（0038～0049）。制作人说其中混了不纯的东西，她说那就是她，梦、希望和欲望让她发光，要制作人多夸她（0050～0054）。制作人说她是「現金なアイドル」，她抗议这不算夸；制作人拿出六大オーディション『美道場』的资料，说星南拿下了『VocaL master』『VisuaL master』成了『二冠』，问她想不想要同样的头衔和『美道場』的奖金，她喜出望外答应挑战（0055～0073）。制作人问她金钱问题已解决、为何还被钱驱动，她说赚得越多越觉得钱越多越好，钱能避开很多不幸、守护家人、增加人生选择，存折数字增加让她感到工作被认可，她每天多次刷新记账软件，说钱是被全人类喜欢的超厉害偶像（0076～0089）。制作人说很高兴了解她的欲望，原想让她成为亿万富翁偶像但梦想太小了，她的欲望已经快被粉丝发现、反而增加了魅力；她说『美道場』要用「あの曲」，制作人说那是她的粉丝都喜欢的曲子，她说现在唱一定是世界第一（0090～0101）。

## 行为模式
- 被尊敬的人认真夸奖 → 难为情、谦让（0005、0010），对方要求时才把胜利说出口（0012～0014）
- 对制作人表达感激 → 说得很郑重（0033～0037），但马上转成要夸奖（0054）
- 被指出动机不纯 → 不否认，坦然说这就是她（0050～0052）
- 遇到觉得做不到的任务 → 先吐槽、列理由推辞（0062～0065），被和星南同样的头衔和奖金一说就答应（0071、0073）
- 被问为什么还爱钱 → 详细地、毫不掩饰地讲她对钱的喜欢和理由（0079～0089），然后担心对方会不会觉得她过分（0091）

## 关系

- 制作人：她叫「プロデューサー」（0017、0026），也叫「あなた」（0033）；制作人叫她「藤田さん」（0018、0076）。她说两人有共同的梦（0027、0041），感激制作人让她能普通地做偶像（0033～0037）；制作人说和她一起赚钱很开心（0093）
- 星南：本话没出场；她称星南为「宿命のライバル」「大好きな憧れのアイドル」（0039），看到星南『二冠』的报道更喜欢她了（0068）
