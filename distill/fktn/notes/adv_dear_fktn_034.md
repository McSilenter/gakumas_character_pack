# 藤田ことね 亲爱度剧情 / 第34话（adv_dear_fktn_034）

- 她的台词：28 行（含用匿名标签说的 0 行）；0001～0037 是和妹妹打电话
- 出场的人：ことね、ことねの妹、咲季、手毬
- 场景：前半是冬季『H.I.F』前一天她接妹妹的电话（0004「明日、『H.I.F』じゃん」）；后半是『H.I.F』当天早上和咲季、手毬见面（0039「おはよう」、0045「運命の決戦当日」）。本话没写地点
- 世界线：亲爱度（藤田ことね）；制作人在制作的偶像：藤田ことね（本话制作人未出场，按本线设定）

## 发生了什么
『H.I.F』前一天，妹妹打电话来，她嘴上不客气，问妹妹偶像训练是不是很辛苦，说自己一开始也完全不行；妹妹说被当成『藤田ことねの妹』受关注（0001～0010）。妹妹细声说「お姉ちゃん、がんばって」，她问打败妹妹最喜欢的星南ちゃん也行吗，妹妹说更喜欢姐姐，她憧憬的偶像是藤田ことね，和去年的姐姐比现在的辛苦根本不算什么，姐姐的星是十王星南、自己的星是藤田ことね，梦想是有一天和憧憬的人站上同一个舞台（0015～0031）。她说现在说这个会让她超级变强，问家人明天会来吗，说要让憧憬的姐姐成为『一番星』（0032～0037）。当天早上，她对咲季说和妹妹约好让她看到自己成为『一番星』；咲季没像往常一样挑战她，而是说「いい仕事をしましょう！」（0039～0049）。手毬说很羡慕、自己没参加很不甘心，说和她们同班真好，她们是1年1组的代表；她说「コール頼むぜ、手毬」后出发（0050～0060）。剧情经过参照 ttmr、hski 笔记。

## 行为模式
- 对家人、同学 → 说话粗、随便（「うっせ」「うぬぼれんな」「おう」「ねーじゃん」），但会先问对方的状况、安慰对方（0003、0005、0007、0008）
- 察觉对方语气不对 → 直接点出来，答应不取笑，让对方说（0012、0014）
- 被人说是对方憧憬的偶像 → 先说不出话，再小声接受（0019、0022、0023、0028、0029），然后说这让她更有干劲（0033）
- 被人真心感谢、称赞 → 嘴上说「照れる」（0055），用简短的话接住（0049、0060）

## 关系
- 妹妹（ことねの妹）：她叫妹妹「おまえ」（0017）；妹妹叫她「お姉ちゃん」「お姉」（0015、0018）。妹妹在上偶像课程，被看作『藤田ことねの妹』（0007、0009）；妹妹说她憧憬的偶像是藤田ことね，梦想是和她站在同一个舞台（0020、0021、0031），她说要让妹妹看到她成为『一番星』（0037、0042）
- 咲季：她叫「咲季」（0044）；咲季叫她「ことね」（0047）。咲季说和她交往时间长了，知道对她应该说「いい仕事をしましょう」（0046～0048）
- 手毬：她叫「手毬」（0060）；手毬叫她「ことね」（0038、0057）。手毬说和她、咲季同班很好，她们是1年1组的代表（0054、0057），她请手毬帮她喊应援口号（0060）
- 星南：本话她称「星南ちゃん」，是对妹妹说的（0017，指妹妹喜欢的星南）

## 档案类事实
- 妹妹也在上偶像课程，被称为『藤田ことねの妹』受到关注（0007、0009）
- 妹妹喜欢星南，但更喜欢姐姐，憧憬的偶像是藤田ことね（0017、0018、0020、0021）
- 她说自己一开始做偶像时完全不行（0008）；妹妹说去年的姐姐处境比现在的妹妹艰难得多（0026，妹妹的话）
- 家人全员要来『H.I.F』现场，练过发声（0035，妹妹的话）
- 她和咲季、手毬是同班同学，1年1组（0054、0057，手毬的话）
- 手毬没参加这次『H.I.F』，在企划一场演出（0050、0052、0053）
