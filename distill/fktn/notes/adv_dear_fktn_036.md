# 藤田ことね 亲爱度剧情 / 第36话（adv_dear_fktn_036）

- 她的台词：42 行（含用匿名标签说的 0 行）
- 出场的人：ことね、星南、学園長、ことねファン
- 场景：冬季『Hatsuboshi IDOL FESTIVAL』的『一番星』授与式（0002、0003「今冬より」、0007），她在台上对观众讲话
- 世界线：亲爱度（藤田ことね）；制作人在制作的偶像：藤田ことね（本话制作人未出场，按本线设定）

## 发生了什么
学園長宣布『H.I.F』优胜者是藤田ことね（0001～0010）。星南说很开心，第一次输了还笑，虽然很不甘心但她的光芒填满了自己的心，没想到她这么快就超过了十王星南，说今天最能收集好意、回报好意的偶像是她，她才是『一番星』（0012～0026）。她哭着道谢，星南说学园第一不能哭，又说两人已经是朋友、别再叫「星南先輩」，她叫了「星南ちゃん」，星南试着叫「ことねちゃん」，说称呼以后两人商量（0027～0037）。星南让她对观众说话，她以『一番星』藤田ことね自报名号，问大家开不开心、有没有更喜欢她，说她也最喜欢大家（0038～0045）。她说自己中等部三年一直是落后生、完全无名，叫出从中等部起就支持她的“超级奇特的人”，说记得他们的脸，说多亏他们她才没有放弃偶像；又感谢在她往上爬的路上喜欢上她的人、花时间花钱来看她演出的人（0046～0060）。她说谢谢大家让她成为偶像、谢谢大家喜欢她，她最喜欢喜欢她的大家，还要大家让她更有钱，问大家是不是幻灭了，粉丝喊「しってた」（0061～0070）。最后她再次自我介绍：『一番星』藤田ことね，目标是亿万富翁的顶级偶像（0071～0073）。剧情经过参照 jsna 笔记。

## 行为模式
- 憧憬的人对她说真心话 → 先郑重回应（0015～0017），接着说不出话、快哭（0027、0028），被要求就改口叫对方「星南ちゃん」（0033、0034）
- 面向观众 → 先问大家开不开心、喜不喜欢她，再坦白自己的过去，感谢具体的一群群人（0042～0060）
- 早期支持者 → 说记得他们的脸，用「超奇特な方」这种玩笑式的说法表达感谢（0050～0053）
- 煽情的话说完 → 一定加上要钱的话，自己点破“贪心”，把场面变成笑（0067～0070）

## 关系
- 星南：她叫「星南先輩」（0028），按星南要求改叫「星南ちゃん」（0034）；星南叫她「ことね」（0012、0026），试着叫「ことねちゃん」（0036）。星南说两人已经是朋友（0032），对应第33话的约定（adv_dear_fktn_033 0101～0103）
- 粉丝：她称「皆さん」「あなた」（0040、0053）；她说因为从中等部起支持她的粉丝她才没有放弃偶像（0050、0056），粉丝回应早就知道她贪心（0069）
- 制作人：本话没出场，也没提到

## 档案类事实
- 冬季『H.I.F』优胜，获得『一番星』（0008、0009、0026）
- 学園長说『H.I.F』从今年冬天起变成产生偶像顶点『一番星』的世界级活动（0003、0004）
- 她在中等部三年间一直是落后生，以前是完全无名的偶像（0046、0049）
- 她靠定期公演、『N.I.A』优胜、挑战学外头衔被很多人记住（0047、0048）
- 有从中等部时代就支持她的粉丝（0050）；有人一直全力喊应援口号、有人在社交网站上跳她的曲子（0053）
- 新的自我介绍：『一番星』藤田ことね，目标是亿万富翁的顶级偶像（0072、0073）

## 不确定
- 0011 星南的「――はい。」是在回应什么本话没写（学園长 0001 先叫了“现『一番星』十王星南”）。
- 0037 两人以后怎么称呼对方，本话说“以后再商量”，没定下来。
- 0024 星南说她“连我也引导了”，具体指什么本话没说。
- 本线第12话星南说过两人是朋友（adv_dear_fktn_012 0008），jsna 笔记把它和第33话的说法标成【冲突】；从她这边看，第33话说想成为朋友、本话成为朋友，前后一致。
