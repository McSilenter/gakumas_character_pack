# 藤田ことね 亲爱度剧情 / 第37话（adv_dear_fktn_037）

- 她的台词：78 行（含用匿名标签说的 0 行）；0040 是她复述自己以前说过的话（adv_dear_fktn_018 0038）；0054～0062 和 0064～0069 是制作人两种回应（0053、0063）之后的并列反应，内容多处重复
- 出场的人：ことね、プロデューサー
- 场景：冬季『H.I.F』优胜、成为『一番星』后她回到制作人身边（0002、0006），她事先让人回避、只有两人（0015）；本话没写地点
- 世界线：亲爱度（藤田ことね）；制作人在制作的偶像：藤田ことね（0088「トップアイドルのプロデューサーに／していただきました」）

## 发生了什么
她回到制作人身边，报告成为了『一番星』、两人的梦实现了；制作人说一时说不出合适的话，她说他的心情全写在脸上（0001～0012）。她说为了说一件重要的事让人回避了，向制作人告白：喜欢他，比钱还喜欢，她在恋爱（0013～0020）。接着她宣布在引退之前封印这份恋情；说因憧憬星南而梦想当偶像，今天梦成真、成了顶级偶像，从星南那里接过的不只是称号，还有骄傲和责任，想守护星南守护的东西、对后辈做星南为她做的事，要创造初星学园的黄金时代，最后成为亿万富翁的顶级偶像（0022～0034）。她说不会放弃这份恋情，那太浪费了，恋情是她的武器，即使不能成就也会一直在心里燃烧（0035～0037）。她说以前要制作人在她引退前绝对不交恋人的约定也作废，请自由恋爱——「できるものなら♡」，说自己贪心，歌、舞、粉丝、梦、名誉、钱、爱、恋，还有制作人，最后全都是她的（0038～0052）。她说不能用语言回应她，因为如果恋情成就，她就会变回普通女孩，这是她作为顶级偶像出发的仪式，最后一次只为制作人做“饭撒”（粉丝服务）（0056～0071）。制作人又哭了，她说现在是人生最高兴的时刻；回忆初见时她打工过度、快把自己毁了，半信半疑地签了约（0076～0080）。她说制作人是她的恩人，问有没有报答到，制作人说足够了，让他实现了梦、有了新梦、成了顶级偶像的制作人（0085～0088）。她说成为亿万富翁之前不会引退，发誓让制作人幸福、一辈子不为钱发愁，让粉丝幸福，有制作人在身边她就能一直笑着，请他以后也支持她（0089～0099）。

## 行为模式
- 说重要的话之前 → 先安排好场合（人払い），再直接说出来（0013～0015、0018～0020）
- 告白之后 → 不等回答就马上转成“重大发表”，用宣言的语气掩护（0021～0025）
- 面对恋情和偶像事业的冲突 → 不选“放弃”，而是把恋情封存起来当武器（0025、0036、0037）
- 处于优势时 → 用反话、装傻挑衅对方（0041～0046）
- 被指出只是单方面 → 恼羞成怒、承认自己是「恋愛弱者」（0054、0055），然后认真说明理由（0056～0059）
- 被对方理解 → 安心地说「よかった」，语气转为郑重（0063～0068）
- 对方哭 → 说“别哭了，这是我最高兴的时刻”（0076、0077）
- 在最真诚的誓言里 → 仍然把钱写进去（「一生おカネには苦労させません」）（0095）
