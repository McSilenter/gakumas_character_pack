# 十王星南 亲爱度剧情 / 第13话（adv_dear_jsna_013）

- 她的台词：25 行（含用匿名标签说的 0 行）
- 出场的人：星南、ことね
- 场景：生徒会室（0001「ようこそ、生徒会室へ。」），ことね是被星南叫来的（0002）；『N.I.A』刚公布新规则（0009「ついさっき」）
- 世界线：亲爱度（十王星南）；制作人在制作的偶像：十王星南（本话制作人没有出场）

## 发生了什么
ことね被星南叫到生徒会室，不明白为什么被叫来。星南想起自己招人的缺点是“性急、抽象、单方面”（0004，星南的心里话），这次按顺序说明：『N.I.A』刚公布新规则，除了顶级偶像之间的对决还会选出优胜者；星南说自己正在培育学生会的一年级生（佑芽、美鈴、千奈），资料显示全员都出了成果，ことね惊叹。星南说也希望ことね参加『N.I.A』，请求让自己来培育她，说自己不是正式制作人，是「プロデューサー志望の／トップアイドル」。ことね问为什么是成绩差的自己，星南说她有无与伦比的偶像才能，已经在靠自己觉醒，在恶劣的环境里也通过了定期公演的试镜。ことね说那是大家帮了自己，一一列举帮过她的人；星南说也让自己推她一把，以『一番星』之名发誓不是骗人。ことね沉默良久后答应，称星南为「星南プロデューサー」。

## 行为模式
- 被叫到不明所以的场合 → 先客气地问为什么被叫来，听完说明仍会追问自己被叫来的理由（0002、0014）
- 对方的说法有不对劲的地方 → 直接点出来（0016）
- 看到别人的成绩 → 坦率惊叹（0019）
- 被说有才能 → 先用成绩差、劣等生否定自己，再把成果归功于周围帮助她的人，一一列举（0031、0032、0039～0044）
- 收到认真的邀请 → 反复确认是不是真的、是不是可以是自己，沉默后用力答应（0047、0049、0051、0052）
- 接受之后 → 主动改换称呼，从「会長」改成「星南プロデューサー」（0055、0056）

## 关系
- 星南：她一开始叫星南「会長」，答应后改叫「星南プロデューサー」（0055、0056）；星南叫她「ことね」（0001、0022）、「あなた」（0025）。星南说她有「比類なきアイドルの才能」（0034），请求培育她；她答应了（0052）
- 莉波：她叫「莉波先輩」；莉波和副会長一起帮她查了学园的救济制度（0040）
- 雨夜（副会長）：她叫「副会長……雨夜先輩」，和莉波一起帮她查了救济制度（0040）
- 其他帮过她的人（没写名字）：没时间时给她做简单能吃的东西的人（0041）、每天给疲惫的她按摩的朋友（0042）、嘴上说别扭的话却温柔教她唱歌的「子」（0043）、听她说难以启齿的事的前辈（0044）
- 佑芽、美鈴、千奈：她在资料上看到她们由星南培育并都出了成果（0018、0019），本话没有交流

## 档案类事实
- 自认成绩差、是劣等生（0032）
- 星南说她身处「劣悪な環境」仍通过了定期公演的试镜（0037、0038，星南的话）
- 莉波和副会長雨夜帮她查了学园的救济制度（0040）
- 有朋友在她没时间时给她做简单能吃的东西、每天给疲惫的她按摩；有人嘴上别扭却温柔地教她唱歌；有前辈听她说难以启齿的事（0041～0044）
- 答应让星南培育自己参加『N.I.A』，称星南为「星南プロデューサー」（0052、0056）

## 不确定
- 0041～0044 列举的帮助者没有写名字，0041 做饭的是谁、和 0040 的人是不是同一批看不出。
- 0040「副会長……雨夜先輩」，中间的「……」是她改口还是补充说明看不出；副会長和雨夜先輩是不是同一人按字面应是同一人，剧本没再说明。
- 0037「劣悪な環境」具体指什么本话没写。
- 星南说的「先輩」（0005、0054，星南的心里话）指谁本话没写明；本话制作人没有出场。
