# 十王星南 亲爱度剧情 / 第23话（adv_dear_jsna_023）

- 她的台词：32 行（含用匿名标签说的 0 行）
- 出场的人：星南、ことね、プロデューサー、ことねの妹たち
- 场景：前半是星南和制作人谈话（ことね不在场，0002 提到会议地点是生徒会室）；0033 起ことね来找星南，地点没写；0049 后是在ことね家（0045「うちで」）的祝贺派对结束后；『H.I.F』正式比赛之前（0005、0081）
- 世界线：亲爱度（十王星南）；制作人在制作的偶像：十王星南（0023「トップアイドルの／プロデューサー」、0072「私のプロデューサー」）

## 发生了什么
ことね向星南说了家里的事，星南想在『H.I.F』正式比赛前尽快解决。制作人的心里话交代了ことね的烦恼：藤田家有借款、父亲失踪，她为了帮家里打很多工、一直很累，在大家帮助下已改善到最佳状态的前一步（0011～0014）。制作人用充足的预算找到了她父亲的所在，但劝星南先别告诉ことね是怎么找到的，免得她有负担。之后ことね兴高采烈地来报告父亲回来了，说有很多想不通的地方、打算之后好好追问，但总之平安就好，并邀请星南参加家里的『N.I.A』优胜＆藤田家重聚祝贺派对。派对后星南感谢她亲手做的菜和妹妹们，ことね说该道谢的是自己，然后直接问父亲的事是不是多亏了星南，要她老实回答；星南承认是制作人找到的，请她现在先忘掉。ことね说既然是憧憬的偶像、尊敬的前辈、信赖的制作人的指示就会听，但要星南在『H.I.F』结束后接住她保留的这份心情，并宣告当天会以最佳状态的藤田ことね迎战。

## 行为模式
- 有好消息 → 立刻跑去向星南报告，用拉长的甜腻语气（0033～0037）
- 事情有说不通的地方 → 不肯糊弄过去，打算追问，但先为结果安心（0039～0043）
- 别人对她过分感激 → 先吐槽“有点恶心”，再反过来说该道谢的是自己（0065～0067）
- 察觉有人在背后帮了她 → 直接当面问，要求老实回答（0069、0071）
- 被请求先别背负人情 → 爽快答应，理由是信任对方；但要求事后一定接受她的心情（0076、0079～0082）
- 情绪安定之后 → 把心情转化为对比赛的宣战（0084～0086）

## 关系
- 星南：她叫星南「星南ぷろでゅ～さぁ」（0033）、「星南プロデューサー」（0047、0068）、「星南先輩」（0068）、「あなた」（0069）、「あたしのスター」（0085）；星南叫她「ことね」（0034、0074）。她说星南是憧憬的偶像、尊敬的前辈、信赖的制作人（0079）；邀请星南参加家里的派对，亲手做菜招待（0047、0051）。看穿星南在父亲的事上帮了她（0069），同意先保留这份心情到『H.I.F』之后（0076、0081、0082）
- プロデューサー（星南的制作人）：本话她没有和他直接对话；他叫她「藤田さん」（0004、0021），找到了她父亲的所在（0021）；他心里认为她很聪明，迟早会发现（0031）
- 父亲：她叫「お父さん」；父亲失踪后回来了（0011，制作人的心里话；0037），她觉得父亲绝对瞒着什么，打算追问（0040、0042）
- 妹妹们：她叫「うちのちびども」「あいつら」（0058、0060）；妹妹们受她的影响很喜欢『星南ちゃん』（0059）

## 档案类事实
- 藤田家有借款，父亲曾失踪（0011，制作人的心里话）
- 为了帮家里打很多工，一直很疲劳；在大家帮助下情况改善（0012、0013，制作人的心里话）
- 向星南说了家里的情况（0009，星南的话；0036）
- 父亲回来了（0037）；父亲的所在是星南的制作人用预算找到的（0021、0072）
- 有几个妹妹，她叫她们「ちびども」；妹妹们受她影响喜欢星南（0058、0059；0056 妹妹们叫星南「せなちゃん」）
- 家里办了『N.I.A』优胜＆藤田家重聚祝贺派对，她亲手做菜招待星南（0046、0051）
- 称星南是憧憬的顶级偶像、尊敬的前辈、信赖的制作人（0067、0079）
