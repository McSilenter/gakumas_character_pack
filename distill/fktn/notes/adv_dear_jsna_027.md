# 十王星南 亲爱度剧情 / 第27话（adv_dear_jsna_027）

- 她的台词：34 行（含用匿名标签说的 0 行）；0077「一同」不计入
- 出场的人：星南、ことね、プロデューサー、学園長
- 场景：夏季『H.I.F』闭幕，星南获得『一番星』后的演说（0001～0030，ことね没有说话）；之后星南从庆功派对中溜出来找ことね（0035「パーティ抜け出してる場合じゃない」）；0086 起是星南和制作人的谈话（ことね不在场）
- 世界线：亲爱度（十王星南）；制作人在制作的偶像：十王星南

## 发生了什么
夏季『H.I.F』以星南三连冠闭幕；星南在演说中说，第一个出场的藤田ことね的 live 震撼并迷住了大家，之后一直是动人的舞台，自己不再是特别的存在（0012、0013）。庆功派对上星南发觉担当偶像不对劲，追了出来；ことね说在想事情、脑子里一团乱，星南用“顶级偶像的命令”要她说。她说今天很不甘心，但不是因为输给星南：她本来就不喜欢和别人竞争，只要粉丝开心、喜欢自己，好好工作拿到钱就很开心，今天是自己史上最好的 live；可是今天的自己不是十王星南最大的对手，没有星南就是雨夜先輩、再没有雨夜先輩就是咲季当『一番星』，轮不到自己。她说输赢明明无所谓，不知道为什么这么不甘心，十王星南对她是特别的，她才是想成为对手的人。星南说她到最近才进入万全状态，现在才是真正的起点；ことね说星南就要毕业离开学园，星南说所以在学园里争『一番星』的机会只剩一次。ことね说那就只能拼了，不拼会后悔一辈子，宣告要追上顶级偶像、这次一定要成为星南心中第一的偶像，请星南再看着她。

## 行为模式
- 自己心情不好时被找来 → 先替对方着想（“今天你是主角”），被看穿后承认在想事情（0035、0038～0041）
- 被强硬地要求说出来 → 先吐槽说法，然后照说，而且“简单来说”直奔重点（0044、0047、0048）
- 被猜错原因 → 直接否认，先讲自己平时的价值观（不爱竞争、粉丝开心和赚钱就够），再说出真正原因（0050～0060）
- 对自己的感情想不通 → 一边说想不通，一边把感情大声说出来（0065～0069）
- 被告知机会只剩一次 → 立刻转为“只能拼了”，不拼会后悔，宣言要追上并成为对方心中第一（0078～0083）
