# 十王星南 亲爱度剧情 / 第36话（adv_dear_jsna_036）

- 她的台词：18 行（含用匿名标签说的 0 行）；她在台上的话是在『一番星』授予仪式上公开说的（面向会场）
- 出场的人：星南、ことね、学園長
- 场景：『Hatsuboshi IDOL FESTIVAL』的『一番星』授予仪式（0001～0006；0002「今冬より生まれ変わった」）
- 世界线：亲爱度（十王星南）；制作人在制作的偶像：十王星南（本话制作人没有出场）

## 发生了什么
『H.I.F』优胜者是十王星南，ことね作为特别颁奖嘉宾登台。她问星南吃惊吗，说没告诉她：听说星南连冠时会由颁奖人授予奖杯，担当偶像们商量后报名参加了选拔；大家都满心想当『一番星』，但如果要把最后的『一番星の証』交给星南，她想由自己来，不想让给任何人。星南说自己也想从她手中接过。她以「十王星南さん」称呼，祝贺四连冠；说夺走这枚勋章才是报恩，她是这样想着来挑战的，把至今的偶像人生全部砸上去也够不到，于是又重新憧憬了一次，说这才是她的明星、她们的『一番星』，催星南向全世界致辞。

## 行为模式
- 想给重要的人惊喜 → 事先瞒着对方，和同伴商量后主动报名（0013～0017）
- 对重要的角色 → 坦白“不想让给任何人”（0020、0021）
- 正式场合 → 改用「十王星南さん」和敬语，郑重祝贺（0026、0027）
- 输给憧憬的人 → 不掩饰没能赢，转而说“又重新憧憬了一次”，把对方捧为“我的明星”“我们的『一番星』”（0031～0034）
- 自己说完 → 把舞台让给对方，催对方致辞（0035）

## 关系
- 星南：她叫星南「星南先輩」（0013、0016）、「あなた」（0019、0035）、「十王星南さん」（0026）、「あたしのスター」（0033）、「あたしたちの『一番星』」（0034）；星南叫她「ことね」（0012）。她自称星南的担当偶像之一（0017），想由自己把最后的『一番星の証』交给星南（0019～0021），星南说也想从她手中接过（0024）。她说夺走勋章才是报恩，没能做到，于是重新憧憬星南（0030～0032）
- 其他担当偶像：她说担当偶像全员商量后报名了颁奖人选拔，大家都想当『一番星』（0017、0018）

## 档案类事实
- 担任『H.I.F』『一番星』授予仪式的特别颁奖嘉宾（0010），是担当偶像们商量后她报名选拔的（0017）
- 『H.I.F』正赛中没能赢过星南（0031；星南四连冠，0027）
- 说夺走『一番星』的勋章是她对星南的报恩，并为此挑战（0030）
- 输了之后说又重新憧憬了星南一次（0032）

## 不确定

- 0023 星南说「本戦に選抜されたあなたには／言い出せなかった」，ことね在正赛中的名次本话没写。
