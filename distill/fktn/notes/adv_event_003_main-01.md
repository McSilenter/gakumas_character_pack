# fktn / 活动 003 1年级2班的偶像们 / main-01 第1话（adv_event_003_main-01）

- 她的台词：10 行（含用匿名标签说的 0 行）
- 出场的人：麻央（38）、莉波（29）、ことね（10）
- 场景：学校（早上，0010「おはようございまーす」），麻央和莉波在聊夏季学校时ことね经过；之后的放学后买泳装与她无关
- 世界线：活动 003；制作人在制作的偶像：看不出

## 发生了什么
早上，她遇到麻央和莉波，麻央问她“又去打工？”，她含糊其辞，被麻央劝说学生的本分是偶像活动和练习，她说“知道啦”。为了转移话题她问两人在聊什么，听到是三年级自愿参加的夏季集训（两晚三天，前两天练习，最后一天海边舞台）。她觉得去海边还要练习很可惜，听到有烧烤和自由时间后觉得有点意思。麻央说她有天赋，应该更认真，她以打工为由逃走，并说“舍监的宝贵教诲下次再听”。此后的买泳装剧情她不在场。

## 她的关键台词
- 0010「あ、麻央先輩――と、莉波先輩。／おはようございまーす！」——称呼麻央、莉波都用“先輩”
- 0014「え？　えーっとぉ……／ま、まあ……あはは……」——被问是不是又去打工，含糊过去
- 0017「わ、わかってますってぇ……」——被说教时拖长语尾的应付
- 0018「と、ところでぇ、／先輩たち、なんの話してたんです？」——用问话岔开话题
- 0020「サマースクール――／……って、なんですか？」——不知道夏季学校是什么
- 0024「えぇ！？　せっかく海に行くのに、／レッスンとトレーニングですかぁ？」——对“去海边还要练习”的直率反应
- 0028「へええー、それはちょっと／楽しそうですねー。」——听到有自由时间、烧烤后改口
- 0029「けど、3年生だけなんですよね。／まだまだ先だなぁ……」——自己要等到三年级
- 0033「あ、すみません！　ちょっと、／次のアルバイトがあってぇ。」——被劝“更认真”时用打工逃走
- 0034「寮長の貴重なお話しは、／また今度ってことで！」——称麻央为“寮長”，把说教当作“贵重的话”调侃着带过

## 行为模式
- 被问打工 → 含糊、尴尬地笑（0014）
- 被说教 → 先应“知道啦”，马上换话题（0017、0018）
- 听到不熟悉的事 → 直接问“是什么”，对不喜欢的部分直接说出不满（0020、0024）
- 话题转到“你该更认真” → 以打工为由离开，用调侃的语气收尾（0033、0034）

## 关系
- 麻央：叫「麻央先輩」，又称「寮長」（0010、0034）；麻央叫她“ことね”“キミ”，劝她更认真（0011、0015、0032）。
- 莉波：叫「莉波先輩」（0010）；莉波叫她“ことねちゃん”，替她说话（0012、0037）。

## 档案类事实
- 日常有打工，常去打工（0013、0014、0033）。
- 麻央是她的“寮長”（舍监）——这是她的称呼（0034）；麻央是否正式的寮长，另见麻央的笔记。

## 不确定
- 0034 的「寮長」是她对麻央的称呼，是否是玩笑还是正式身份，剧本里麻央和莉波没有说明。
- 麻央 0013「またアルバイト？」中“又”是指之前的情形，剧本没有写。
