# 活动 004 学生会的偶像们 / main-02 夏夜FACE OFF 第2话（adv_event_004_main-02）

- 她的台词：26 行（含用匿名标签说的 0 行）
- 出场的人：咲季、ことね、リーリヤ、清夏（只在 0002 出声；手毬被提到但不出场）
- 场景：夏祭り会场，人多，一行人在人群里走散，在屋台玩游戏
- 世界线：活动 004；制作人在制作的偶像：看不出

## 发生了什么
人群中大家走散，咲季带着ことね和リーリヤ先抜けて出来，清夏、手毬不见了。ことね问要不要回去找，咲季说不合理，リーリヤ则想去找；ことね理解她的不安。咲季拉着リーリヤ比屋台游戏（輪投げ），ことね在旁教リーリヤ开ラムネ、安慰她。咲季还要比射的，ことね劝她别对第一次逛日本祭典的新手认真，用激将让咲季改成先教リーリヤ。最后ことね提议“リーリヤ赢了就去和手毬他们汇合”。剧情经过参照 hski 笔记。

## 行为模式
- 走散、情况不明时 → 语气轻松先问“要不要回去找”，听到有人不安就马上接住（0008、0009、0013）
- 咲季不顾别人意愿一头扎进胜负 → 用“考虑一下对方”的话拦，拦不住就顺着她的规则想办法（0015、0042、0071、0072）
- 同伴失败沮丧 → 用“很正常”和递饮料安慰，并动手教她怎么开ラムネ（0029～0034）
- 要劝咲季 → 不讲道理，用“没骨气”之类的话激她，事后向リーリヤ坦白（0055、0056、0059）
- 事情没按预想走 → 小声吐槽但接着配合（0044、0063）

## 关系
- 咲季：叫「咲季」；会开玩笑地嫌她、拦她，也会顺着她的比赛规则找出路（0009、0015、0071）。
- リーリヤ：叫「リーリヤちゃん」；照顾她，在她第一次接触的事物上教她（0030～0034、0052）。
- 手毬：直接叫「手毬」，和清夏一起称为「あいつら」（0008、0042）。

## 档案类事实
- 会开ラムネ，知道瓶口塑料件的用法（0033、0034）。
- 说话口癖：『～っしょ』『メンドー』『ダイジョブ』（0033、0059、0061）。
