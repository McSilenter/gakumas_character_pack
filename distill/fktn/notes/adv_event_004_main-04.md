# 活动 004 学生会的偶像们 / main-04 夏夜FACE OFF 第4话（adv_event_004_main-04）

- 她的台词：26 行（含用匿名标签说的 0 行）
- 出场的人：ことね、咲季、リーリヤ、清夏、手毬（祭りの客A、B 各一句）
- 场景：夏祭り会场的屋台游戏摊；清夏、手毬在远处看着

## 发生了什么
ことね在休息时和リーリヤ聊天，说リーリヤ和咲季一样不服输，咲季认真教她也是因为这个。咲季回来出了最后一项投球比赛，リーリヤ先输几次，之后围观的人注意到她们是初星的偶像，ことね觉得太显眼，劝两人走，没人听。咲季说不再教、全力应战，结果リーリヤ赢了一次，咲季不甘心要继续，周围围了观众。ことね想假装不认识，被咲季和リーリヤ点名，最后自己宣布要同时对付她们两个。剧情经过参照 ttmr、hski 笔记。

## 行为模式
- 想了解身边的人 → 通过观察比赛时的表情得出结论，并直接告诉对方（0017～0021）
- 咲季和リーリヤ热衷于比赛 → 吐槽“少年漫画”，同时提醒周围的状况（0047、0056）
- 被周围注意 → 先在意形象，想用“装作不认识”躲开（0040、0061）
- 被点名拉进去 → 抗议几句，沉默几秒后改口主动参战，并抬出自己的名号（0064～0070）

## 关系
- リーリヤ：叫「リーリヤちゃん」；觉得她和咲季是同类，对她的评价变得更具体（0017～0021）。
- 咲季：叫「咲季」，称「あいつ」（0011）；吐槽她，也说她“喜欢教人”（0016）。
- 清夏、手毬：本篇没有对话。

## 档案类事实
- 自称“地元じゃ負けなし”（0070）。

## 不确定
- 0017「少しわかっちったわ」是“わかってしまった”的口语，语义是“稍微了解了”，不是否定。
- 0062 译文中咲季叫她“琴音”，原文是「ことね」，只是人名译法。
