# 活动 004 学生会的偶像们 / main-05 夏夜FACE OFF 第5话（adv_event_004_main-05）

- 她的台词：13 行（含用匿名标签说的 0 行）
- 出场的人：清夏、咲季、ことね、リーリヤ、手毬
- 场景：夏祭り会场，屋台对决结束之后，到去河边放烟花
- 世界线：活动 004；制作人在制作的偶像：看不出

## 发生了什么
清夏、手毬现身，ことね埋怨她们一直躲着看。大家按“赢的人可以提一个愿望”说话，咲季给リーリヤ提了要求，リーリヤ想和两人做朋友，被ことね和咲季说“已经是朋友了”。ことね收到摊主送的烟花，宣布自己赢来的愿望是去河边放烟花；手毬说要回去，被リーリヤ邀请后改口答应。咲季也答应参加，ことね喊众人出发。剧情经过参照 ttmr、hski 笔记。

## 她的关键台词
- 0003「す、清夏……手毬……／今ごろ現れやがってぇぇぇ～～。」——对迟到的两人抱怨，语气夸张
- 0005「ちょっとじゃないだろぉ～。／ずっとだろぉ～。」——指出清夏的“稍微看了一下”不属实
- 0020「あたしもドサクサで／勝ってんだよなぁ～。」——说自己在混战中也赢了一次
- 0021「……じゃあ、1回ずつ言うこと聞く？」——由比赛结果提出“各自一个愿望”
- 0027「まぁだ勝負するのかよ～。／んで、リーリヤちゃんのお願いは？」——吐槽咲季，同时把话头交给リーリヤ
- 0032「うんうん。咲季もたまには／いいこと言うじゃん♪」——咲季说“不用特意许愿”时，认同并调侃
- 0033「もう友達だもんなー。」——直接对リーリヤ说已经是朋友
- 0047「おーい！　ものどもーっ！／花火げっとだーっ！」——带着得意的口气宣布拿到烟花
- 0049「屋台の人がさあ、／いいもん見せてもらったってくれた。」——说明烟花是摊主因为“看了好东西”送的
- 0050「あたしの勝ち分のお願いは……／河原で打ち上げだっ！」——用自己的愿望定下去河边放烟花
- 0055「あれ？　手毬、／リーリヤちゃんの言うことは聞くんだ？」——抓住手毬改口的瞬间
- 0057「むっふっふ。／いいこと聞いちゃった～。」——抓到手毬的把柄后得意
- 0066「咲季ー！／清夏ーっ！」——放烟花前招呼两人

## 行为模式
- 迟到的同伴出现 → 先夸张地发火，再用追问戳穿对方说得不实（0003、0005）
- 比赛有了结果 → 想把结果变成大家都能参与的规则（各自一个愿望），自己的愿望用来凑大家一起玩（0021、0050）
- 朋友说出不安的愿望（想做朋友） → 轻描淡写地说“已经是朋友了”，不多做煽情（0033）
- 抓到别人嘴硬的地方 → 点出来，然后得意（0055、0057）
- 事情谈妥 → 马上招呼大家出发（0066）

## 关系
- リーリヤ：叫「リーリヤちゃん」；把她当成已经是朋友的人（0027、0033、0055）。
- 咲季：叫「咲季」；和她一起讲“偶尔说点好话”，且被她点名需要听从（0032、0062）。
- 清夏：叫「清夏」，被清夏叫作「ことねっち」（0038，译文作“琴音”）；对迟到有怨气（0003）。
- 手毬：叫「手毬」；抓她嘴硬的地方（0055）。

## 档案类事实
- 自己在混战里赢了一次游戏（0020）；烟花是摊主送的（0049）。

## 不确定
- 0036 清夏说“我不是说过不做朋友吗～？”，0038 清夏又说“说的是ことねっち”；ことね在 0033 却说“もう友達だもんなー”。清夏这几句指的是之前哪一次对话，本篇未交代，是否指ことね说过“不做朋友”本篇无法判断。
- 0021 愿望的规则是ことね提议，0027 咲季的“再比一次”、0062 咲季说“ことねも1回勝ってるし”，规则是否包括所有赢家，剧本没有写明。
