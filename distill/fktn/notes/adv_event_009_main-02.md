# fktn / 活动 009 莉莉娅与清夏的日常 / main-02 蛋糕系起的友情圣诞节 第2话（adv_event_009_main-02）

- 她的台词：17 行（含用匿名标签说的 0 行）；其中 0009、0017、0031、0035、0037 是心里话（括号内独白）
- 出场的人：佑芽（13）、ことね（17）、リーリヤ（12）、清夏（11）、広（10）、千奈（5）、ケーキ屋の店主、美鈴 各 1
- 场景：补习结束后的校内，ことね向“常在一起的三人组”邀请打工；后半是リーリヤ和清夏在别处的对话
- 世界线：活动 009；制作人在制作的偶像：看不出

## 发生了什么
ことね向千奈、佑芽、広邀请打工。千奈因圣诞节要在家开派对而拒绝，広想参加却当场倒下，自己放弃；佑芽自告奋勇代替，说想和ことね更亲近。她担心佑芽不会做蛋糕，但还是决定一起干。她说一组的人都问遍了，她和佑芽商量下一个人选，美鈴当场表示冬天不想工作。结尾的リーリヤ与清夏对话是在另一处，ことね不在场。剧情经过参照 hmsz、hume 笔记。

## 她的关键台词
- 0004「おっ、いつもの3人組じゃん。／次はあいつらに声かけてみるかぁ～。」——看见千奈、佑芽、広，决定下一个邀请对象
- 0005「……ぶっちゃけあんまり話したこと／ないから、ちょっと不安だけど。」——坦白对这三人不熟，有点不安
- 0009「（い、家でパーティ……／すげえワードだぁ……）」——心里话；对千奈的“家里办派对”感到惊讶
- 0017「（これでいつも通りって、／どーゆーこと！？）」——心里话；对広倒下被当作日常感到震惊
- 0023「……まあ、実際そうだね～。／あたしは慣れてるけど、結構きついし。」——赞同佑芽说“对広来说难”，并说自己习惯打工
- 0027「えっ、マジ？／やってくれるなら助かるけど、いいの？」——对佑芽主动代替先确认对方意愿
- 0031「（……あれ？　こいつ／本当に大丈夫か？）」——心里话；听到佑芽没做过蛋糕后担心
- 0035「（根拠がなんもねえ～～～！）」——心里话；千奈的“一定没问题”没有依据
- 0037「（……ま、でも、せっかくやるって／言ってくれたし、一緒に頑張るかぁ）」——心里话；虽担心，仍决定接受佑芽的好意
- 0038「つーわけで、ひとり確保したから、／あとひとりだけど……どうするかぁ。」——报告进度，转入找最后一人
- 0046「よぉーしぃ、／この際、手当たり次第に行くぞ～！」——再次不挑人，全力找人

## 行为模式
- 向不熟的人开口 → 先坦白自己有点不安，但还是上去邀请（0004、0005）
- 对方说出意外的话 → 心里吐槽，嘴上不说（0009、0017、0031、0035）
- 有人愿意帮忙 → 先确认对方是否真心愿意，再接受（0027、0029）
- 对帮忙的人有疑虑 → 疑虑放在心里，嘴上说“一起加油”（0031、0037）
- 人手仍不够 → 马上转向“手当たり次第”，不再挑人（0046）
