# fktn / 活动 009 莉莉娅与清夏的日常 / main-04 蛋糕系起的友情圣诞节 第4话（adv_event_009_main-04）

- 她的台词：28 行（含用匿名标签说的 0 行）；其中 0011、0020、0074、0077 是心里话（括号内独白）
- 出场的人：ことね（28）、佑芽（23）、リーリヤ（24）、ケーキ屋の店主（2）
- 场景：蛋糕店的打工当天，厨房里做蛋糕的现场；リーリヤ躲到别处（0040～0049）

## 发生了什么
店主讲解做法时，リーリヤ很熟练，佑芽却把鲜奶油做成黑色，ことね让佑芽学习リーリヤ。佑芽说姐姐咲季要来买，慌着请教リーリヤ，一口气提了很多问题，リーリヤ慌乱地躲去洗手间。ことね安抚佑芽，去找リーリヤ，主动说“我来帮你沟通”，并说自己也想和她更亲近。回来后リーリヤ教佑芽挤奶油，成功了，佑芽还喂她试吃。剧情经过参照 hume 笔记。

## 她的关键台词
- 0007「おっ、リーリヤちゃん。／さっすが、慣れてるね～。」——夸リーリヤ熟练
- 0013「なんでホイップクリームが真っ黒に／なるのかなぁ、佑芽ちゃん？」——对佑芽的失误只带着笑意的追问
- 0015「店長さんの指示通りに作れぇ～～～！」——要求佑芽老实按指示做
- 0020「（リーリヤちゃん……口数少ないなぁ。／緊張してるっぽい？）」——心里话；注意到リーリヤ话少
- 0025「ケーキなんてアイドルの食べ物／じゃないとか言ってたくせに……」——对咲季的态度前后不一吐槽
- 0044「ま、ちょっと一気に質問しすぎて、／リーリヤちゃんも混乱しちゃってたね。」——给佑芽解释，不责备任何一方
- 0046「だーいじょうぶだって。／ちょっとここで待ってな。」——让佑芽放心，自己去找人
- 0052「ぜんぜん気にしてないって。／リーリヤちゃんに助けてもらってるし。」——对逃走的リーリヤ说不在意
- 0056「じゃあ、あたしがサポートするからさ。／そしたら、話せるよね？」——主动提出做桥梁
- 0058「もっとあたしのこと、頼っていーから。／だって、あたしたち友達だよね？」——对リーリヤ说“友达”，请她依赖自己
- 0060「あたしも同じだから。」——回应リーリヤ之前说的想更亲近
- 0064「てか、ゴメンね♪　／――清夏じゃなくて。」——开玩笑，指找到她的是自己而不是她想求助的清夏
- 0077「（これはこれで、悪くないか）」——心里话；对时间超出预期的结果仍满意

## 行为模式
- 同伴失误 → 笑着点破并要求按指示做（0013、0015）
- 有人受挫 → 先解释原因，保护双方的面子，再亲自去处理（0044、0046）
- 去安慰躲起来的人 → 先说“不介意”和对方的贡献，再提出自己做桥梁（0052、0056、0058）
- 想拉近关系 → 把自己的心情说成“同じ”，用玩笑缓和（0060、0064）
- 事情拖长 → 嘴上抱怨时间，心里觉得还不错（0073、0074、0077）
- 对咲季 → 吐槽“シスコン”，不是当面说（0025、0026）

## 关系
- リーリヤ：称“リーリヤちゃん”；说“あたしたち友達だよね？”（0058）；知道她会喊“清夏ちゃん”（0064）
- 佑芽：称“佑芽ちゃん”（0013）；对她的失误吐槽，也在她难受时安慰（0013、0044、0046）
- 咲季：本篇只在佑芽的话里出现，ことね称之为“あのシスコン”（0026）

## 档案类事实
- 她说咲季曾说过“ケーキなんてアイドルの食べ物じゃない”（0025，对应 009-01 咲季 0038）
- 咲季是“シスコン”（0026）
