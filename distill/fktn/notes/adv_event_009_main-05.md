# fktn / 活动 009 莉莉娅与清夏的日常 / main-05 蛋糕系起的友情圣诞节 第5话（adv_event_009_main-05）

- 她的台词：27 行（含用匿名标签说的 0 行）；其中 0027、0032、0040、0073、0074、0078 是心里话（括号内独白）
- 出场的人：ことね（27）、佑芽（15）、リーリヤ（17）、清夏（11）、咲季（6）、ケーキ屋の店主（4）
- 场景：初星学园圣诞活动当天的蛋糕摊位（0001）
- 世界线：活动 009；制作人在制作的偶像：看不出

## 发生了什么
摊位客人很多，ことね提醒佑芽声音太大、リーリヤ声音太小，让两人深呼吸。咲季来买佑芽做的蛋糕，ことね拿“蛋糕不是偶像的食物”开咲季的玩笑。清夏来买蛋糕，ことね在旁边看着她和リーリヤ的对话，被清夏看出“目が泳いでる”。结束后店主留了三个蛋糕，三人一起吃，リーリヤ约佑芽下次做点心。最后发工资时ことね兴奋得喊“大胜利”，佑芽说第一次看她这么高兴。剧情经过参照 hski、hume 笔记。

## 她的关键台词
- 0003「だから売りがいがあるんでしょ？／売上次第で給金プラスだってー♪」——对客人多的反应，用奖金激励同伴
- 0005「声がでかすぎるっ！　／あと風情がない！」——给佑芽指出问题
- 0007「声がちいさぁいっ！　／もっと自信もって！」——给リーリヤ指出相反的问题
- 0013「ねえ、咲季？　アイドルの食べ物／じゃないって話は……？」——拿咲季自己的话开玩笑
- 0024「シスコンだな～、相変わらず。」——对咲季的评价
- 0027「（カップルかよ……会話がよぉ……）」——心里话；吐槽リーリヤ和清夏的对话
- 0032「（そ、そんな生活でこんな体型を／維持してんのぉ！？）」——心里话；对清夏吃很多却保持体型感到震惊
- 0039「そ、そんなことはないよ～？」——被清夏说“很辛苦吧”时，嘴上否认
- 0040「（いや、確かにわりと／大変だったかも！）」——心里话；承认其实很辛苦
- 0050「そ、そんなに真っ直ぐ言われると、／照れるナ～。」——听到リーリヤ坦率的话害羞
- 0066「探せばいるかもしれないけど、／立派なアイドルになってからだナ～。」——对佑芽“当兼职蛋糕师的偶像”的想法说先当出色的偶像
- 0074「（でもまぁ、ふたりが仲良くなれて／よかったかな……）」——心里话；总结这次打工的收获
- 0079「いよっしゃ～！！／あたし大勝利！　やってよかった～！」——看到工资时的喜悦

## 行为模式
- 同伴各有缺点 → 向两人分别指出相反的问题，再让他们深呼吸（0005、0007、0008）
- 被问到辛苦不辛苦 → 嘴上说没有，心里承认“有点辛苦”，被看穿后转移话题（0039～0042）
- 看到亲密的互动 → 在心里吐槽，不当面说（0027、0032、0033）
- 被直率的话 → 害羞，嘴上说“照れるナ～”（0050）
- 讲到金钱 → 明显高兴，直接表达（0003、0077、0079）
- 目标是偶像 → 用“先成为出色的偶像”拉回话题（0066）

## 关系
- 咲季：称“咲季”（0013）；吐槽她是“シスコン”（0024）
- 清夏：被她叫“ことねっち”（0034、0041、0051）；本篇ことね没有直接叫她的名字
- リーリヤ：本篇没有直接叫她的名字；对她和佑芽变亲近感到欣慰（0074）
- 佑芽：称“佑芽”（0042）；觉得佑芽比自己更辛苦（0042）

## 档案类事实
- 她把打工当作赚钱手段，拿到工资非常高兴（0003、0077、0079）
- 自己做的蛋糕自认好吃（0061）
- 说“立派なアイドルになってから”才考虑别的（0066）
