# 活动 016 / 第1话（adv_event_016_main-01）

- 她的台词：12 行（含用匿名标签说的 0 行）
- 出场的人：咲季、佑芽、ことね、手毬（店員 0021）
- 场景：前半是咲季和佑芽在商店街买东西、抽奖（ことね不在）；0036 旁白「翌日」之后，咲季把抽到的スポセン门票分给ことね、手毬
- 世界线：活动 016；制作人在制作的偶像：看不出
- 说明：ことね只在「翌日」之后出现（0038 起）

## 发生了什么
抽奖得到スポセン的门票后，第二天咲季拿着票说要送大家“日头的感谢”，ことね和手毬反应冷淡，手毬怀疑是新作SSD试饮。咲季说是商店街抽奖得来的，ことね认出是现在很受欢迎的スポセン，意外咲季会邀请她们。ことね犹豫后提出，想带最大的妹妹一起去，因为她要照顾弟妹，没法出去玩，也从不说想去；咲季爽快同意，约定下周的周六或周日。

## 她的关键台词
- 0038「……はぁ？」——被咲季说“送你们好东西”时的第一反应
- 0043「ん？　……おおーっ、ここって、／今すっげー人気のスポセンじゃん！」——知道スポセン现在很火，立刻兴奋
- 0044「でも、めずらしー。／咲季が遊びに誘ってくれるなんて。」——对咲季邀请自己觉得稀奇
- 0048「咲季ちゃんさー。ちょーっと、／相談があるんだケド……」——提出请求前先铺垫
- 0050「うちのちびを一緒に連れて／行ってあげたいんだ。」——想带最大的妹妹
- 0053「スポセンとか、ぜったい、／行きたいに決まってんだケド、」——想象妹妹一定想去
- 0054「下のちびどもの面倒見てるから、／なかなか遊びに行けなくて。」——妹妹要照顾更小的弟妹，所以没法玩
- 0055「あたしに遠慮して、普段そーゆーの、／全然言わない子だからさ……」——妹妹顾虑姐姐，不说想去
- 0056「その、迷惑かけちゃうかもだけど……」——怕给咲季添麻烦
- 0059「咲季～、ありがとな～！」——咲季答应后道谢

## 行为模式
- 听到出乎意料的邀请 → 先露出怀疑的语气，然后看到内容后兴奋（0038、0043、0044）
- 想为家人求情 → 先沉默一下，再叫名字，说“有个商量”，然后详细说明妹妹的处境（0047、0048、0050～0056）
- 提出请求时 → 先说自己的难处，再说“可能会添麻烦”（0056）
- 被爽快答应 → 拖长语调道谢（0059）

- 手毬：不直接对话；手毬 0045 与她一起评论日程
