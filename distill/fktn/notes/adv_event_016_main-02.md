# 活动 016 / 第2话（adv_event_016_main-02）

- 她的台词：29 行（含用匿名标签说的 0 行）。其中 0075 是括号里的内心独白
- 出场的人：ことね、咲季、手毬、ことねの妹
- 场景：约定的日子，在スポセン（综合运动娱乐设施）里；先是几人玩击球机、体育项目，之后ことね和咲季坐着休息聊天
- 世界线：活动 016；制作人在制作的偶像：看不出

## 发生了什么
ことね带着妹妹到了スポセン，让她向咲季和手毬打招呼，妹妹很有礼貌，被ことね调侃“猫かぶってんなー”。妹妹想试击球机，手毬主动说教她，ことね交给手毬，自己跟咲季学挥棒。休息时，ことね问咲季姐妹吵不吵架，咲季回答“靠比赛分胜负，所以不会吵”，然后沉默，说佑芽进了学生会交到很多朋友，自己有些失落。ことね看出咲季“寂しい”，劝她坦率说，被拒绝，心想“真是个麻烦的姐姐”。

## 行为模式
- 带妹妹出门 → 调侃妹妹的拘谨，同时把妹妹的事交给可靠的人（0007、0012、0034）
- 朋友要强时 → 先问，不逼；说“我们是朋友”促她开口（0056、0058）
- 看出别人的心情 → 直接说出“你是不是寂しい”，然后以自己的立场（弟妹成长）劝（0064、0067、0068）
- 朋友拒绝坦率 → 不再强求，在心里叹气（0071、0075）
- 对设施不懂时 → 坦白说“规则全不懂”（0021）

## 关系
- 咲季：叫「咲季」「咲季ちゃん」（0063）；咲季叫她「ことね」；在她面前吐露了对佑芽的失落
- 手毬：叫「手毬」（0018、0032）；把妹妹托付给她
- ことねの妹：ことね叫她「ちび」（0007）

## 档案类事实
- ことね有妹妹，会叫她「ちび」，关系好（0007、0050）
- ことね不会规则（高尔夫、射箭）（0021）
- ことね问咲季姐妹之间会不会吵架（0051）；她自己家的情况本篇没有说
