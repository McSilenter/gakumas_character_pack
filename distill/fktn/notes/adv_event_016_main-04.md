# 活动 016 / 第4话（adv_event_016_main-04）

- 她的台词：23 行（含用匿名标签说的 0 行）
- 出场的人：咲季、ことね、手毬、ことねの妹
- 场景：在スポセン午饭后，在フットサル（五人制足球）场，咲季提出3对1比赛
- 世界线：活动 016；制作人在制作的偶像：看不出

## 发生了什么
午饭后，咲季提议三个人加上妹妹，以3对1对战，输了就请饮料。ことね认为咲季那边必赢，咲季给出让步；ことね觉得手毬提议“引住咲季，耗她的体力”很意外，大家按此作战。咲季得了数分后，妹妹提出了作战，ことね借口“再等一下”拖住咲季，抢到球；之后用手毬的喊叫声吓咲季，让妹妹进球。最后ことね这边胜了。比赛后，ことね向咲季道谢，说“你要是认真是能赢的吧”，咲季说自己是全力进攻，并说和妹妹玩让她想起小时候和佑芽玩的时候。

## 她的关键台词
- 0003「どっちかってゆーと、／うどんメインのよーな気もするケド。」——手毬说“沙拉乌冬”时的吐槽
- 0008「いやいや。試合にならないでしょ。／咲季のいるチームが絶対勝つって。」——不认为比赛成立
- 0014「おーっし、アイドルに／二言はないな？」——咲季给出让步和奖励后，确认她说话算话
- 0018「普通ならそーなんだけど……／咲季が相手となると、油断できない。」——对咲季实力的评价
- 0021「意外だなー……／手毬がチームプレイの提案なんて。」——对手毬的提案感到意外
- 0023「うっし、とりあえずは、／手毬の作戦でいってみますか。」——接受手毬的方案
- 0026「華麗にドリブル……と見せかけてぇ、／――手毬にパス！」——比赛中的做法
- 0035「くっそー。せめて1点は返したいなー。」——被压制后的愿望
- 0042「悪い、咲季。／もーちょっとだけ待って――」——为了拖住咲季，假装请她等待
- 0044「ひひっ、ボールいただきー。」——抢到球
- 0063「……咲季、ありがと。」——比赛后向咲季道谢
- 0065「そーじゃなくて。咲季、／その気になれば、勝てたでしょ。」——说明她道谢的是咲季的做法，看出咲季没有用全力

## 行为模式
- 面对压倒性的对手 → 先吐槽“没法比”，再确认对方的承诺（奖励），然后考虑对策（0008、0014、0016、0018）
- 同伴提出作战 → 对对方提案的意外直接说出，但接受并执行（0021、0023）
- 作战时 → 用假动作和“再等一下”拖住对方，趁机抢球（0026、0042、0044）
- 比赛结束 → 不是为饮料道谢，而是为对手的“放水”道谢，直接说出“你其实能赢”（0063～0065）

## 关系
- 咲季：叫「咲季」（0024、0042）；咲季叫她「ことね」（0025）
- 手毬：叫「手毬」（0026、0046）；对她的提案感到意外
- ことねの妹：妹妹在作战时提出方案（妹 0036），ことね 0037 回应

## 档案类事实
- ことね的运动也相当擅长（手毬 0012 说“私もことねも、運動は結構得意”）
- ことね会假装请对手等待来拖住对方（0042）
- ことね看出咲季的放水（0065）
