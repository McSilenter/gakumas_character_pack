# 活动 016 / 第5话（adv_event_016_main-05）

- 她的台词：15 行（含用匿名标签说的 0 行）。0032、0033 的「一同」不计（0032 是唱歌词）
- 出场的人：咲季、ことね、佑芽、ことねの妹、手毬（一同 0032、0033）
- 场景：在スポセン玩完之后，外面有免费live舞台；之后咲季回宿舍遇到佑芽
- 世界线：活动 016；制作人在制作的偶像：看不出

## 发生了什么
玩完后，咲季为妹妹夹到了娃娃（给弟妹们），ことね向两人道谢。看到初星学生在免费live舞台上唱歌，咲季劝ことね去跳，让妹妹看看她当偶像的样子；ことね说穿着便服不好意思，被咲季以“让妹妹看到帅气的一面是姐姐的责任”说服。ことね拉手毬下水，三人上台唱歌。唱完，妹妹说“最可爱”，ことね害羞。之后是咲季和佑芽的对话。

## 她的关键台词
- 0004「よかったなー。あたしじゃ、／何回やってもとれなかったし。」——妹妹得到娃娃，说自己拿不到
- 0007「ふたりとも、今日は／ほんっっっとーに、ありがとな。」——对咲季、手毬郑重道谢
- 0013「おー、ほんとだ。／初星の制服……2年生かな？」——看到台上的初星学生
- 0016「ええっ！？」——被咲季要求上台跳舞
- 0018「いや、あそこで踊るのは、／恥ずかしいってぇ……」——不好意思的理由
- 0020「そーだけどサァ、／ステージ衣装じゃないし……」——被说和学园的野外舞台一样后，另找理由
- 0022「……う～、わかったよ。」——被说服
- 0024「ちび、お姉ちゃんたちの、／スペシャルライブだ。」——向妹妹宣布
- 0027「そーだよ。もちろん。／あたしひとりじゃ、寂しいし……」——拉手毬一起
- 0029「それにさー。めっちゃ歌の／上手い奴がいたほうがー、」——拉手毬的理由
- 0034「……ど、どうだった？」——唱完后问妹妹感想
- 0036「……～っ、そ、そっかー……？」——听到“世界第一可爱”后害羞

## 行为模式
- 受到帮助 → 直白地道谢，语气加重（0004、0007）
- 被劝上台 → 先“诶？”，用害羞和便服推脱，被“让妹妹看到帅气的一面是姐姐的责任”说服（0016～0022）
- 决定要做之后 → 对妹妹以“姐姐们的特别live”宣布，并拉同伴下水（0024～0030）
- 被妹妹夸“可爱” → 害羞地回应（0036）

## 关系
- 咲季：叫「咲季」；咲季叫她「ことね」，鼓励她上台
- 手毬：0027 回应手毬“我也要上台？”，拉她一起
- ことねの妹：叫她「ちび」（0024）；妹妹称她“世界一可爱”（妹 0035）

## 档案类事实
- ことね自己夹不到娃娃，咲季帮忙夹到（0004）
- ことね不好意思在便服的状态下跳舞（0018、0020）
- ことね认为有会唱歌的手毬观众会更激动（0029、0030）
- ことね认得初星学生的制服（0013）

## 不确定
- 「一同」0032「ひとつーの夢、叶うまで／負けなーい――」：是歌词，三人合唱；0033「ありがとうございましたー！」是齐声，是否含她，待统一判定（咲季、手毬也在台上）
- 0013「2年生かな？」是根据制服判断，具体依据没有写
