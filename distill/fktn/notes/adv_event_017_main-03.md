# 活动 017 / 第3话（adv_event_017_main-03）

- 她的台词：9 行（含用匿名标签说的 0 行）
- 出场的人：星南、麻央、莉波、ことね、燕
- 场景：休息日的汉堡店，ことね在这里打工，莉波一行来用餐。
- 世界线：活动 017；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
ことね在打工的汉堡店接待客人，先发现是星南，又发现莉波、麻央、燕也在。她向星南解释上次自己被吓到是因为星南点了30个汉堡，说这次她来真的很开心。星南想点菜单上写着0元的「ハッピーウインク」，ことね不知如何回答，被麻央替星南点了套餐带过去。

## 她的关键台词
- 0030「いらっしゃいま……って、星南会長！？」——接待客人时发现是星南，吃惊到话说到一半。
- 0032「莉波先輩と麻央先輩！？／副会長も……」——看到其他人也来了，吃惊地一个一个叫出来。
- 0033「みんなで来てくれたんですかぁ？」——语气转为拉长尾音的开心。
- 0035「あ、あのときはびっくりしたんですよ。／……ハンバーガー30個も頼むし。」——解释上次反应不同的理由。
- 0036「星南会長も来てくれて、／ふつーに嬉しいですよ？」——直接说星南来很高兴。
- 0038「こほん。ご注文は、どうされますか？／今ならフェアメニューがお得で――」——咳一声切换为店员口吻，推销优惠套餐。
- 0041「……え？」——被星南点 Happy Wink 吓到。
- 0043「え、ええっとぉ……」——不知怎么回答时的迟疑。
- 0045「は～い。ご注文、／ありがとうございまーす。」——麻央点了套餐后，爽快接下。

## 行为模式
- 被熟人撞见在打工 → 先惊讶，再转为开心（0030、0032、0033）
- 被问到和上次反应不同 → 说明当时是被吓到，然后直白地说现在「ふつーに嬉しい」（0035、0036）
- 对被点单的奇怪要求 → 无法立即回答，用「え」「ええっとぉ」支吾（0041、0043）
- 想回到工作时 → 用「こほん」切换到店员的语气（0038）

## 关系
- 星南：叫「星南会長」，用敬语；对她的光临直接说开心（0030、0036）。
- 莉波：叫「莉波先輩」（0032）。
- 麻央：叫「麻央先輩」（0032）；麻央替星南点了套餐，她爽快接下（0045）。
- 燕：叫「副会長」（0032）。

## 档案类事实
- 在汉堡店打工（0030、0038）。
- 店里有「フェアメニュー」（0038）。
- 上次星南来时点了30个汉堡，她被吓到（0035）。

## 不确定
- 0036 的「ふつーに」是表示「当然」还是「普通地」，两种读法都可，不作结论。
