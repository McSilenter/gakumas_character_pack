# 活动 019 / 巡演活动 名古屋篇 第1话（adv_event_019_main-01）

- 她的台词：6 行（含用匿名标签说的 0 行）；『一同』4 行（0041、0046、0060、0061）按规定不计入，见「不确定」
- 出场的人：咲季、星南、莉波、燕、ことね、手毬、一同
- 场景：学园内，咲季刚接下名古屋公演代理领队后把ことね和手毬叫来，说去名古屋、2 泊 3 日，明天出发。
- 世界线：活动 019；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
咲季接下代理领队后，说要带『友達』去名古屋，ことね和手毬被叫来，听说后惊叫。ことね抱怨突然、自己有安排，咲季说"不行就找别人"后，ことね和手毬一起喊"去"。ことね说酬劳也有，没有不去的理由，让手毬别计较咲季说的「友達」，并考虑调整打工等日程。咲季说"明天出发"，所有人惊呼。剧情经过参照 ttmr、hski 笔记。

## 她的关键台词
- 0042「そんな急に言われても！／こっちにも予定とかあるしッ！」——被咲季突然说去名古屋，直接表达为难。
- 0049「ちゃんとギャラも出るし～？／行かない理由、ないよねー♪」——咲季说"不行就找别人"后，抓住酬劳作为理由，语气转为轻快。
- 0052「まぁまぁ。言わせときゃいーじゃん？」——手毬质疑咲季用词时，替咲季打圆场。
- 0053「……っと。そーと決まったら、／予定調整しないとなー。」——决定后马上切到实务。
- 0055「とかー、もろもろー。／2泊3日でしょ？」——手毬问是否要调整打工时，回答「之类的」，并确认日程。
- 0058「オッケー。／で？　いつ出発？　来週の金曜？」——接受后直接问出发时间，猜是下周五。

## 行为模式
- 被突然通知 → 先说「こっちにも予定とかあるし」，不掩饰为难（0042）
- 咲季示弱式地说"找别人" → 抓住酬劳为理由，马上变得积极（0049）
- 同伴挑咲季的毛病 → 用「言わせときゃいーじゃん」平息，不深究（0052）
- 决定后 → 立刻处理日程细节，问日期（0053、0055、0058）

## 关系
- 咲季：此篇没有直接称呼她；对咲季说话轻松，替她解围（0052）。
- 手毬：手毬问她是否是打工，她答「之类的」（0054、0055）。

## 档案类事实
- 有打工之类的日程需要调整（0053～0055）。
- 把酬劳当作去不去的理由之一（0049）。
