# 活动 019 / 巡演活动 名古屋篇 第3话（adv_event_019_main-03）

- 她的台词：23 行（含用匿名标签说的 0 行）；0031、0054 是括号里的内心话；『一同』0062、0063 按规定不计入，见「不确定」
- 出场的人：咲季、ことね、手毬、一同
- 场景：去名古屋的电车上（到站前），之后是到达后的住处（三人同房，2 泊 3 日）。
- 世界线：活动 019；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
电车上咲季自言自语是在给佑芽做训练的后续辅导，ことね和手毬说她是妹控，咲季回答因为自己是姐姐，ことね问她不辛苦吗，咲季说一点也不。到了住处，ことね发现三个人住一间房，咲季说只是没说，手毬说怎么都行。三人商量演出：咲季整合意见，ことね觉得是多亏了咲季，询问自己独唱前奏前留的时间；咲季解释是为了让手毬恢复体力和让ことね发挥舞蹈与粉丝互动。最后手毬发现房间只有两张床。剧情经过参照 ttmr、hski 笔记。

## 她的关键台词
- 0002「……なー咲季ー。／さっきからなにしてんの？」——对咲季的自言自语直接发问。
- 0008「あぁ……いつものやつ……」——听到佑芽的事，已经习以为常。
- 0016「しんどくない？」——问咲季这样为妹妹做事辛不辛苦。
- 0018「……あっそ。」——咲季回答一点也不后，不再多问。
- 0021「はいはい、くねくねはいいから。／もう駅着くぞ、降りるぞー。」——咲季得意忘形时，叫她下车。
- 0025「3人同室とか聞いてないんだけど！？」——发现同房后马上抗议。
- 0027「言えよ！　先に！！」——咲季说「没说过」后顶回去。
- 0031「（このふたりと同室で2泊3日って！／正気かよ～～～！！）」——内心：对同住三天两夜的震惊。
- 0041「咲季のおかげ……な気はする。」——讨论顺利时，把功劳归给咲季。
- 0044「いやそれをナチュラルにやってたから／すげーって話なの……」——咲季说没做什么时，指出她做得自然才厉害。
- 0050「こんなに時間作ってもらって、／本当によかったの？」——担心自己独唱前奏前被分配了这么多时间。
- 0054「（……案外ちゃんと／見てるんだなぁ、うちらのこと）」——内心：意外咲季好好观察着她们。
- 0055「……ひひっ。さすが、／お姉ちゃんは伊達じゃないってか？」——调侃咲季，用她的口头禅。

## 行为模式
- 看到咲季的怪行为 → 直接问她在干什么，不客气（0002）
- 听到咲季照顾佑芽的事 → 先说「いつものやつ」，再问辛不辛苦，被说不辛苦后不再追问（0008、0016、0018）
- 被没提前告知的安排 → 当场抗议，要求以后先说，内心却在慌（0025、0027、0031）
- 讨论顺利时 → 认可咲季的作用，指出她做得自然才厉害（0041、0044）
- 被安排了较多时间 → 先担心「本当によかったの？」，被说明后答应，内心承认咲季有观察，再用玩笑回应（0050、0053～0055）

## 关系
- 咲季：此篇里叫她「咲季」；对她既抗议又承认她的作用（0025、0041、0044）；用「お姉ちゃん」调侃她（0055）。
- 手毬：叫「手毬」；手毬说「いいよ、なんでも」时她惊讶（0032、0033）。

## 档案类事实
- 独唱部分前有较长的前奏时间（0049）。

- 在咲季看来，之前就知道咲季为佑芽做训练和卡路里计算（0008、0009）。
