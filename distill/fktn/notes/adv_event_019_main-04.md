# 活动 019 / 巡演活动 名古屋篇 第4话（adv_event_019_main-04）

- 她的台词：22 行（含用匿名标签说的 0 行）；0006、0007 是括号里的内心话；0014～0061 是演唱会上的 MC，其中 0014 起是向观众讲述前一晚的事；『一同』0012、0013、0061 按规定不计入，见「不确定」
- 出场的人：咲季、ことね、手毬、一同
- 场景：开头（0001～0013）是前一晚住处床位的回想，由 0014 以后在舞台上的 MC 讲述；之后是名古屋演唱会的 MC，最后进入下一首曲子。
- 世界线：活动 019；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
回想里：单人间也没有，三人里有两个人要同床。ことね和手毬都内心抗拒，ことね提议用猜拳，却发现咲季已经秒睡。舞台上的 MC 里，ことね向观众讲述那晚的事，三人互相爆料：手毬撒娇、脚冰凉，ことね说梦话称自己是「お姉ちゃん」，咲季睡相差又早睡。最后三人说起这次的经历是满溢的青春成分，偶尔才好，并说要把这份能量分享给观众，咲季预告下一首曲子。剧情经过参照 ttmr、hski 笔记。

- 0008「……こ、ここは公平に、／じゃんけんとかで決める？」——提议用猜拳决定谁同床。

- 0018「ひどい繋がりで言えばぁ……／咲季の寝相も……ねぇ？」——借咲季说被踢过分的话题，爆咲季的睡相。
- 0023「いやいやぁ。／飛びっきりのがあるよ、咲季ちゃ～ん。」——咲季要大家爆羞耻的事时，主动说有一个。

- 0026「これがもうすっごい甘えん坊で！／すーぐピタってくっ付いてくんの。」——爆手毬撒娇。
- 0033「うぇえ！？　ま、マジ？／……なんて言ってた？」——被手毬说她说了梦话，慌忙追问。
- 0036「うああああ！／そ、その寝言は確かにハズい……！」——听到自己梦话的内容，承认害羞。
- 0038「真面目に解説すんな～～～～ッ！！」——咲季要向观众说明她有妹妹时，立刻制止。
- 0041「いいねぇ、ノった！／あたしと手毬で咲季の足持ち上げて～。」——手毬提议爆咲季被叫醒的事，立刻附和。

- 0053「あーゆーのはたまにで十分。／……むしろ、たまにがいいわ。」——总结：偶尔才好。
- 0058「受け取り拒否は厳禁♪／一緒に青春を感じて、盛り上がって、」——MC：让观众一起感受青春。
- 0059「最っ高の思い出を／持ち帰ってくださーい！」——MC：邀请观众带着回忆回家。

## 行为模式
- 遇到尴尬的住宿问题 → 内心慌张，嘴上提出猜拳这样的公平方案（0006～0008）
- 被要求在大家面前讲自己的羞耻事 → 抢先爆别人的事，把话题引到手毬身上（0023～0028）
- 自己的羞耻事被说出来 → 先吃惊、追问内容，听到后承认害羞（0033、0036）
- 涉及家人（妹妹）的话题被公开 → 立刻制止（0037、0038）
- 事后评价 → 用玩笑和「あーゆーのはたまにで十分。」总结，既承认有趣，也不愿反复（0043、0046、0052、0053）
- 在舞台上 → 用轻快口吻 MC，对观众提出请求（0058、0059）

## 关系
- 咲季：叫「咲季」「咲季ちゃ～ん」（0023）；爆她的睡相，和手毬一起准备把她抬起来（0018、0041）。
- 手毬：叫「手毬」；爆她撒娇和冰凉的脚，手毬则爆她的梦话（0026、0028、0034、0035）。

## 档案类事实
- 习惯与人并排睡（0006）。
- 睡觉时会说梦话，内容是「お姉ちゃん頑張るからなぁ。／いい子にしてろよ～」，还会摸身边人的头，自己不记得（0034、0035，手毬的话）。
- 有妹妹（0037，咲季的话；0038 她阻止解说）。
- 前一晚与手毬同床（0025）。
