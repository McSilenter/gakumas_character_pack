# 活动 019 / 巡演活动 名古屋篇 第5话（adv_event_019_main-05）

- 她的台词：19 行（含用匿名标签说的 0 行）；『一同』0025、0049、0060 按规定不计入，见「不确定」
- 出场的人：咲季、ことね、手毬、一同、ウェイトレス
- 场景：名古屋公演结束后的第二天早晨，先在酒店收拾行李（手毬还没收拾完），之后在名古屋的咖啡店吃早餐。
- 世界线：活动 019；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
返程前，ことね抱怨回去的行李比来的时候多，咲季说是因为买了很多给妹妹们的土产。ことね说因为取消了陪妹妹们玩的计划，咲季为此道歉，ことね说妹妹们是理解后送她出门的，反过来要咲季说谢谢，咲季道谢并说演唱会大成功。三人逗手毬没收拾完行李，发现美鈴留下的核对清单。随后三人庆祝，到咖啡店吃名古屋早餐，咲季点了她父亲设计的联动菜单，提出把胜者的菜单当作「初星モーニング」提案，另外两人制止。剧情经过参照 ttmr、hski 笔记。

## 她的关键台词
- 0001「なーんで行きより荷物増やして／帰るハメになるんだろうなー。」——开场就抱怨行李。
- 0003「……雑談にド正論返されると／めっっちゃ腹立つな……！」——被咲季一本正经地回答后，不满。
- 0005「まぁ、うん。遊んであげる予定、／キャンセルさせちゃったし。」——承认土产是因为取消了和妹妹们玩的计划。
- 0007「いやいや。あいつらも納得して／送り出してくれたんだし、いーよ。」——咲季道歉时说妹妹们已经理解。
- 0008「むしろそこは、ありがとうって／言ってくれないとなぁ……♪」——半开玩笑地索要感谢。
- 0010「うむ！　ならばよしっ！」——咲季道谢后满意。
- 0013「名古屋のモーニング行きたいって／言ったのお前だろー？」——催手毬收拾，提到是手毬想去的早餐。
- 0021「へ～……案外上手くやってんじゃん、／おふたりさん♪」——看到美鈴的核对清单，调侃手毬和美鈴。
- 0026「ほんっと、弾丸だったなー。／よく成功させられたわ……」——回顾这次行程。
- 0030「にしても、本当にいいの？／名古屋の喫茶店で朝食って……」——对咲季同意吃名古屋早餐表示担心。
- 0039「いっただっきまーす！／あむ……んん～！　うっま～～～♪」——吃早餐时的反应。
- 0044「まあまあ。昨日めっちゃ運動したし／問題ないっしょ～！」——咲季问热量能不能消耗时，轻松回答。
- 0050「ちょ、ちょ、ちょっと待てええ！／なんだそのメニュー！」——看到咲季的联动菜单后大惊。

## 行为模式
- 被讲道理 → 嘴上抱怨「腹立つ」，但接受（0003、0005）
- 对方道歉 → 说妹妹们已经理解，反过来索要一声「ありがとう」，得到后马上满意（0007～0010）
- 同伴磨蹭 → 用「言ったのお前だろー？」这样的说法催促，提到对方想去的店（0011、0013）
- 看到别人有照顾她的人 → 笑着调侃（0021）
- 面对美食 → 先担心吃不完，随后直接开吃称赞（0038、0039）
- 咲季的出乎意料之举 → 惊呼并叫停（0050）

## 关系
- 咲季：叫「咲季」；咲季叫她「ことね」，称她的妹妹们「妹ちゃんたち」（0004、0006）；咲季向她道歉并感谢（0006、0009）。
- 手毬：叫「手毬」，用「お前」（0013）；调侃手毬与美鈴「案外上手くやってんじゃん」（0021）。

## 档案类事实
- 在酒店大堂买了很多给妹妹们的土产（0002、0004，咲季的话；0005 她认可）。
- 因为工作取消了陪妹妹们玩的计划（0005）。
- 妹妹们理解后送她出门（0007）。
- 昨天（演出）运动量很大（0044）。
