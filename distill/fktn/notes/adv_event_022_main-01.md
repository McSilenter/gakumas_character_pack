# 活动 022 / main-01 第1话（adv_event_022_main-01）

- 她的台词：28 行（含用匿名标签说的 0 行）；其中 0032～0037 是括号里的内心话
- 出场的人：ことね（28）、麻央（24）、ダンストレーナー（3）
- 场景：雨天，选拔试验之前；麻央倒在某处（0015～0021），ことね扶她回宿舍的房间（0035 说“寮長”的房间）
- 世界线：活动 022；制作人在制作的偶像：看不出

## 发生了什么
ことね被雨淋湿后发现麻央发烧倒在那里，麻央说是练过头在冷却。ことね摸到发烧，扶她回屋，让她好好休息。她心里想着麻央房间收拾得很整齐，又看到“グングン背伸ばしマシン”决定当作没看见。她用习惯的方式照顾麻央，聊到各自家里的姐妹情况，说“风邪的时候大家都是小孩”。离开去便利店前，被麻央要求开着小灯。

## 她的关键台词
- 0016「選抜試験まえの大事な時期だし、／風邪ひかないように気を付けねーと。」——自己也处于选拔试验前
- 0023「いやいや、そんなわけ……／ほら、ちょっと熱あるじゃないですか。」——不接受“只是冷却”的说法
- 0025「絶対、風邪ですって！／こんなとこで寝てちゃダメです、／ひとまず部屋に戻りましょう。」——立刻判断并带回屋
- 0028「今そーゆーのいいんで、／ほら、起きますよ。」——对麻央的客气强硬处理
- 0031「本格的な風邪になる前に、／治しちゃったほうがいいんですよ。」——对“会传染”的回答
- 0037「（『グングン背伸ばしマシン』……？／み、見なかったことにしとこ……）」——看到麻央房间的器具，选择装没看见
- 0041「ちびどもがけっこー風邪ひくんで、／看病は慣れてるんですよ。」——习惯看病的理由
- 0045「まあ、お姉ちゃんするのも、／けっこー大変ですけどねー。」——对“姐妹令人羡慕”的回答
- 0052「風邪のときはみんな子供ですって。」——对“我不是小孩”的回答
- 0055「……りょーかいです。」——答应开着小灯

## 行为模式
- 看到别人状态不对 → 不听客气话，马上摸额头判断并带回屋（0023、0025、0028）
- 对方客气或逞强 → 用“现在那些就不用了”之类直接的话挡回（0028、0031、0049）
- 心里有想法 → 括号里吐槽，嘴上不提（0032～0037）
- 看病 → 具体的步骤（补水、保湿、睡觉、毛巾、药和润喉糖）（0038、0039、0047）
- 对方说出弱点（想要小灯） → 不追问，直接答应（0054、0055）

## 关系
- 麻央：称「麻央先輩」，麻央称她「ことね」，也称「キミ」。她认为麻央是“しっかりもの”（0032）和“寮長”（0035）。
- 莉波先輩：回乡不在宿舍（0034）。
- 咲季：麻央把“咲季のところ”和她一起举为有姐妹的例子（0044）。
