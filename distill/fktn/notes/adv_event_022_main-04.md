# 活动 022 / main-04 第4话（adv_event_022_main-04）

- 她的台词：39 行（含用匿名标签说的 0 行）
- 出场的人：ことね（39）、麻央（33）
- 场景：购物中心，休日，上午到中午；午饭在麻央预约的お好み焼き店
- 世界线：活动 022；制作人在制作的偶像：看不出

## 发生了什么
ことね与麻央在购物中心玩，麻央要“エスコート”她。ことね说平时休日都在打工，最近靠星南会长帮忙减少了。她说自己来这里是看服饰参考流行，麻央很佩服；ことね带麻央逛服装店，让麻央试穿各种风格，后半变成コスプレ。午饭在麻央预约的お好み焼き店，ことね说自己家里有弟妹，一直是最大的，没有年长的朋友，麻央给她的感觉正是那样，但又与星南会长等人不同。麻央说她这么想很高兴。

## 行为模式
- 被夸 → 先否认（0027）
- 想让对方尝试 → 先用“信じてください”说服，之后变成玩（0033、0034、0036、0044）
- 被问家里 → 具体说弟妹的情况，调停吵架的是自己（0059、0061、0062）
- 说到对前辈的真正感觉 → 吞吞吐吐，先补“尊敬してる”再说区别（0064～0069）

## 关系
- 麻央：称「麻央先輩」；对她的定位是“年上的友达”那种感觉（0065、0066），区别于星南会長、副会長、莉波先輩，这些人是“先輩として尊敬”（0068、0069）。
- 星南会長：帮她减少打工（0008）。
