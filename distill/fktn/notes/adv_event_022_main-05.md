# 活动 022 / main-05 第5话（adv_event_022_main-05）

- 她的台词：31 行（含用匿名标签说的 0 行）；其中 0017 是括号里的内心话
- 出场的人：麻央（38）、ことね（31）
- 场景：吃完午饭的お好み焼き店，之后是星南live的会场（live house）
- 世界线：活动 022；制作人在制作的偶像：看不出

## 发生了什么
吃完パフェお好み焼き，ことね知道麻央喜欢甜食，麻央说这是秘密，因为怕让粉丝失望。ことね说“又帅又喜欢甜食的王子完全可以”，还说想让粉丝也看到平时的麻央，麻央请她保密。随后两人去live house看星南的live，ことね说星南会长很厉害。看完后，麻央说其实没有勇气一个人来，并说不再逃避。ことね说“现在的麻央先輩 很帅”。

## 她的关键台词
- 0004「でも、意外でした。麻央先輩、／甘いモノけっこー好きなんですね。」——发现麻央爱甜食
- 0008「なんで、秘密にしてるんですか？」——追问隐瞒的理由
- 0013「カッコよくて、スイーツ好きな王子様、／全然アリアリの有村ですし、」——直接肯定
- 0017「（完璧な王子様のイメージ、／あんまりないと思うけどナー）」——内心话：对麻央的真实印象
- 0019「麻央先輩、もっと素の部分とか、／見せてもいいんじゃないですか。」——建议展现素的一面
- 0022「普段の麻央先輩も、／大好きですし。」——表明自己的喜欢
- 0027「秘密かぁ……／んー、ちょっともったいないですけど、／わかりました。」——答应保密
- 0031「そんなイベントでメイン張るなんて、／星南会長スゴすぎですってぇ。」——对星南的佩服
- 0043「ライブ、楽しみましょう。」——麻央露出落寞时的话
- 0053「星南会長のライブパフォーマンス、／もうサイッコーでしたねー♪」——看完后的感想

- 0067「今の麻央先輩、／めちゃカッコイイです。」——听到麻央的决心后

## 行为模式
- 听到隐藏的一面 → 先惊讶，随后说“完全可以”，再提议展示给粉丝（0011～0014、0019、0023）
- 被要求保密 → 觉得可惜但答应（0027）
- 对方露出落寞 → 不追问，只说“享受live吧”（0042、0043）
- 对方道谢或表态 → 把功劳还给对方，并直接夸（0058、0059、0067）

## 关系
- 麻央：称「麻央先輩」。说“普段の麻央先輩も大好き”（0022）。麻央说“ボクとことねの秘密だよ”（0026）。
- 星南会長：佩服（0031），说她是“メイン”（0031）。

## 档案类事实
- 吃过パフェお好み焼き，觉得像可丽饼，很好吃（0003）
- 知道麻央喜欢甜食这一秘密，答应保密（0004、0026、0027）
- 照顾过“わがままプリンス”麻央（0018）
