# 活动 026 / main-05 ライブツアーイベント特別編 GO MY WAY!! 第5话（adv_event_026_main-05）

- 她的台词：19 行（含用匿名标签说的 0 行）：0001、0003、0006、0008、0010、0011、0012、0013、0014、0015、0018、0019、0022、0034、0039、0041、0043、0049、0050（不含一同 0002、0007、0020、0025、0048、0051）
- 出场的人：ことね、咲季、佑芽、手毬
- 场景：演唱会当天，演出开始前的后台（0001～0025），演出后的休息处（0026～）
- 世界线：活动 026；制作人在制作的偶像：看不出

## 发生了什么
演出前，ことね看着热烈的会场感叹，发现咲季、佑芽跟着打call。她说自己看到会场的狂热还是会发抖，前辈们太耀眼，不知道自己能不能成为那样的偶像。佑芽、咲季说能，ことね觉得自己也能成了，三人鼓劲上场。演出结束后手毬来了，说看了她们的演出，「不错」。ことね累瘫，佑芽说想翻唱765プロ全部曲目，ことね吓得跳起来，被两人用『GO、前へ』回敬，她半推半就地说了一句「はりきってゆきましょう」，又立刻否认。手毬最后说『私たちの番』看来快到了。剧情经过参照 hski、hume 笔记。

## 行为模式
- 看到同伴行为（打call） → 立刻吐槽，再问对方是否紧张（0003、0006）
- 压力大的时候 → 先坦白自己在发抖，再说前辈太耀眼，最后问“我们也能吗”（0011～0015）
- 被同伴肯定 → 马上说"觉得能成了"，并说这就是团队一体感（0018、0019）
- 面对太大的目标 → 惊得跳起来，担心被说得意忘形（0039、0041、0043）
- 被同伴的口号带着走 → 半推半就地跟着说，然后自己吐槽（0049、0050）
