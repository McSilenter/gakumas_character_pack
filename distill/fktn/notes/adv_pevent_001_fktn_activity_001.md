# 藤田ことね 培育事件 001 activity / 001 话题素材（adv_pevent_001_fktn_activity_001）

- 她的台词：9 行（含用匿名标签说的 0 行）
- 出场的人：ことね、プロデューサー
- 场景：地点、时间剧本都没写；制作人和她谈她トーク方面的成绩不好（0001～0002）
- 世界线：培育（藤田ことね）（培育事件 001 activity）；制作人在制作的偶像：藤田ことね（剧本里没有直接说法，从制作人替她想トーク的对策看得出）

## 发生了什么
制作人听说她トーク的成绩不好，她转述得到的评价：反应不错，但还要多拿出反差（0001～0002）。制作人提议用“知道意外的小知识”来做反差，她问那是什么样的（0003～0004）。之后是三种并列的反应，对应制作人讲的三条小知识（选项不在剧本里）：登竜門的由来（0005～0009）、海里取不出昆布高汤的原因（0010～0013）、一万日元重一克（0014～0017）。

## 她的关键台词
- 0002「リアクションはいいケド、／もっとギャップも出して～って。」——转述别人对她トーク的评价：反应好，缺反差
- 0007「ええっ！？　なんで？／鯉って竜になるんですかぁ？」——对传说较真地追问“为什么”
- 0009「そこまで教えてくれないと／豆知識じゃないですよ～。」——制作人答不出为什么，她嫌不够格当小知识
- 0012「って、生きてる間とか言われると／生々しいんですケド～。」——听到“活着的时候”马上吐槽
- 0013「でもコンブだしならよく使うし、／ちょーどいいかも？」——用“自己常用昆布高汤”来判断这条知识合不合用
- 0017「へへへ～、1回でいいから／持ってみたいなァ～、1億円……」——一听到一亿日元就陶醉

## 行为模式
- 听到不合常理的说法 → 直接追问为什么，对方答不上就说不算数（0007、0009）
- 听到别人措辞里怪的地方 → 先“へ～”接住，再用“って、”吐槽（0011、0012）
- 判断一条知识有没有用 → 拿自己的生活经验对照（0013）
- 话题扯到钱 → 先确认数量，接着笑着说想摸一次（0016、0017）

## 关系
- プロデューサー：这一话里她没有称呼他；他叫她「藤田さん」（0001、0014），还说她是「お金が好きな藤田さん」（0014），她没有否认，直接接着对一亿日元着迷（0016～0017）。

## 档案类事实
- 她说昆布高汤自己经常用（0013）
- 制作人说她喜欢钱（0014，制作人的话）

- 0016「それって……重いんですかね？」：她是真不清楚十公斤算不算重，还是在打趣，语气看不准。
