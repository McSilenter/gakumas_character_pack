# 藤田ことね 培育事件 001 activity / 004 现在，正在打工？（adv_pevent_001_fktn_activity_004）

- 她的台词：13 行（含用匿名标签说的 0 行）
- 出场的人：ことね、プロデューサー
- 场景：地点、时间剧本都没写；她在为下一份打工选哪个发愁（0001～0003）
- 世界线：培育（藤田ことね）（培育事件 001 activity）；制作人在制作的偶像：藤田ことね（0010 制作人说要给她排满レッスン和工作）

## 发生了什么
她在烦恼下一份打工做什么，还问制作人觉得哪个好（0001～0004）。之后是几种并列的反应（制作人的回答不在剧本里）：她突然“はっ！”地意识到什么，制作人说她刚才没发觉，她辩解说一直以来都在打工，接着说如果他坚持，自己就等着下一份工作（0005～0008）；她说当然要能赚很多的打工，制作人说那就从明天起排满レッスン和工作，她这才想起好像说过不再打工了，请他手下留情（0009～0012）；她说自己并不讨厌挑打工，再问哪个好，制作人说现在应该有比打工更重要的事，她承认，又说一直在打工，所以心里静不下来（0013～0017）。

## 她的关键台词
- 0003「いやぁ、次どんなバイトしよっかなぁ／って思って。」——习惯性地在想下一份打工
- 0005「はっ！！！！！」——被点醒时的大惊
- 0007「だ、だってぇ～……／今までずっとやってきましたしぃ。」——为自己的习惯辩解：一直都在打工
- 0009「そりゃあもちろん、たぁくさん／稼げるバイトでーす♪」——选打工的标准是赚得多
- 0011「あっ……そ、そ～いえば、／もうやらないって言ったカモ……」——想起自己说过不再打工
- 0013「バイト選ぶのって、あたし／嫌いじゃないんですよね～♪」——挑打工这件事本身她喜欢
- 0017「でもずっとやってたから、／ソワソワしちゃうんですよねぇ～……」——不打工反而坐立不安

## 行为模式
- 闲下来时 → 习惯性地物色下一份打工，被提醒才想起已经说过不做了（0003、0005、0011）
- 被指出做了不该做的事 → 先辩解“一直都这样”，再退一步（0007、0008、0016）
- 制作人用“排满日程”反将一军 → 慌忙改口，请他手下留情（0010～0012）

## 关系
- プロデューサー：她叫「プロデューサー」（0004）；他叫她「藤田さん」（0002）。她拿打工的事问他意见；他每次都把话题拉回到偶像活动上，她最后都承认（0010、0015、0016）。

## 档案类事实
- 她说自己一直以来都在打工（0007、0017）
- 她说过不再打工了（0011，她自己的话「もうやらないって言ったカモ」，语气不确定）
- 挑打工她不讨厌，标准是赚得多（0009、0013）

## 不确定
- 0005「はっ！！！！！」之前制作人说了什么剧本里没有，从 0006、0011 看可能是提醒她已经不打工了，属推测。
- 0008「どーしてもっていうなら、／次のお仕事、待ってますからっ！」的「次のお仕事」应是制作人拿来的工作（相对于打工），读法有一定把握但不完全确定。
- 【译文】0008 译成“如果真的不行的话，我会等下一个工作的！”，原文「どーしてもっていうなら」是“如果你非要这么说的话”。
- 【译文】0012「お手柔らかにお願いしまぁす。」是“请手下留情”，译文作“请多多关照”，意思偏了。
- 「一同」行：无。
