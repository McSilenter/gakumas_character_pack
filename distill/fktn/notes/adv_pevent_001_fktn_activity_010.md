# 藤田ことね 培育事件 001 activity / 010 肖像画（adv_pevent_001_fktn_activity_010）

- 她的台词：15 行（含用匿名标签说的 0 行）
- 出场的人：ことね、プロデューサー
- 场景：地点、时间剧本都没写；她看着ちびども画的她的画傻笑，被制作人看到（0001～0004）
- 世界线：培育（藤田ことね）（培育事件 001 activity）；制作人在制作的偶像：藤田ことね（0013 她请制作人做她的ソロ衣装时参考这些画）

## 发生了什么
她对着一张画傻笑，制作人问那是什么，她说他偷看，然后说是ちびども给她画的（0001～0004）。之后是几种并列的反应（制作人的话不在剧本里）：她得意地说“对吧～”，说想着要回报他们点什么，想到还是得让他们看看当偶像的自己，于是拜托制作人（0005～0009）；她说ちびども画了很多适合她的舞台服装，以后要全部穿给他们看，请制作人做ソロ衣装时参考这些画（0010～0013）；她说ちびども一直支持她，明明她以前很不行，所以在高等部一定要让他们看到自己作为偶像在大家面前唱歌（0014～0016）。

## 她的关键台词
- 0001「へへへぇ……／ふへぇぇ……」——看着孩子们的画忍不住傻笑
- 0004「これぇ、ちびどもがあたしを／描いてくれたんです～～♪」——拿到ちびども的画很开心
- 0008「やっぱりアイドルのあたしを／見せてやらなきゃな～って。」——想用当偶像的自己来回报ちびども
- 0012「これから、ぜんぶぜんぶぜ～んぶ／着てやりますから！」——要把孩子们画的衣服全部穿给他们看
- 0013「だからソロ衣装は、／これを参考にしてくださいねっ♪」——把孩子们的画当作自己衣装的参考
- 0014「ずっと応援してくれてるんですよ～。／あたし、ダメダメだったのに……」——提到自己过去不行，ちびども一直在支持
- 0015「だから高等部では、ぜ～～～ったいに／見せてやるんですッ！」——高等部的目标：让他们看到自己
- 0016「あたしがアイドルとして、／みんなの前で歌うトコロ！」——想让他们看到的是自己作为偶像在大家面前唱歌

## 行为模式
- 被看到自己出神傻笑 → 先说对方偷看，再高兴地拿出来炫耀（0003、0004）
- 收到亲近的人的心意 → 想着要回报，而回报方式是让他们看到当偶像的自己（0006、0008、0012）
- 谈到ちびども的支持 → 会提到自己过去“ダメダメ”，并以此为动力立下目标（0014～0016）

## 关系
- プロデューサー：她叫「プロデューサぁ～」（0009，拖长的叫法）；这一话里他没有称呼她。她请他做ソロ衣装时参考ちびども的画（0013）。
- ちびども：她这样叫画画的孩子们（0004）；她说他们一直支持她（0014），她想回报他们（0006）。

## 档案类事实
- ちびども给她画了画，画了很多适合她的舞台服装（0004、0011）
- 她说ちびども一直在支持她，而她以前“ダメダメ”（0014）
- 她说在高等部一定要让ちびども看到她作为偶像在大家面前唱歌（0015、0016）
