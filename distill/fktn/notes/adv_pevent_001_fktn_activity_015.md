# 藤田ことね 培育事件 001 activity / 015 尽管吩咐（adv_pevent_001_fktn_activity_015）

- 她的台词：13 行（含用匿名标签说的 0 行）
- 出场的人：ことね、プロデューサー
- 场景：制作人请客的店里，可以点餐（0002～0003）；她说这里贵、量少（0005），店名和时间剧本没写
- 世界线：培育（藤田ことね）（培育事件 001 activity）；制作人在制作的偶像：藤田ことね（剧本里没有直接说法，0003 制作人说是对她平时努力的奖励）

## 发生了什么
她在店里惊叹，确认是不是真的什么都能点，制作人说是她平时努力的奖励（0001～0003）。她高兴地开始挑（0004）。之后是几种并列的反应（制作人的话不全在剧本里）：她说平时不来这种地方，又贵量又少，以前打工结束后也没有开着的店——制作人心里想这和她的想法完全相反——她说今天要吃喜欢的（0005～0009）；她看中一款超辣草莓蛋糕，很在意，制作人说确实在意但点了可能会不幸，她同意换别的（0010～0013）；她发现制作人只点咖啡，说那样自己不好意思点，制作人说不用在意，她马上说那就不在意了，制作人心里想她决定得真快（0014～0018）。

## 她的关键台词
- 0002「プロデューサぁ～。／ほんとに何頼んでもいいんですかぁ？」——被请客时先确认“真的什么都行”
- 0005「来ないですよぉ～。／高いし量は少ないしぃ。」——用价钱和分量衡量店
- 0006「それにバイト終わりで開いてる／とこなんてなかったしぃ。」——过去的生活：打工结束时店都关了
- 0008「でもぉ、今日は／好きなの食べちゃいます♪」——难得被请就放开吃
- 0011「この超激辛ショートケーキ、／すっっごぉ～く気になるんですケド。」——会被奇怪的东西吸引
- 0015「それだと頼みにくく／なっちゃうじゃないですかぁ～。」——别人只点便宜的，她就不好意思点
- 0017「じゃあ気にしませんっ♪」——对方说不用在意，就马上照做

## 行为模式
- 被请客 → 先确认真的随便点，然后开心地挑（0002、0004、0008）
- 看待高价的店 → 说贵、量少，平时不会来（0005）
- 对方只点很少 → 会在意不好意思点；对方说别在意就立刻放开（0014～0017）
- 被奇怪的菜单吸引 → 说很在意，但被劝一句就换掉（0011～0013）

## 关系
- プロデューサー：她叫「プロデューサー」（0014），拖成「プロデューサぁ～」（0002、0010）；这一话里他没有称呼她。他请客作为对她努力的奖励（0003）。0007、0018 是制作人的心里话。
