# 藤田ことね 培育剧情 001 / opening-true-01 为了更接近梦想（adv_pstory_001_fktn_opening-true-01）

- 她的台词：5 行（含用匿名标签说的 0 行）
- 出场的人：ことね（5 行）、プロデューサー（3）
- 场景：培育开场，她在看存折（0001）；地点看不出
- 世界线：培育（藤田ことね）（培育剧情 001，opening-true）；制作人在制作的偶像：藤田ことね

## 发生了什么
制作人看到她在看存折（0001）。她得意地笑，说余额不错、当偶像真好（0002）。之后的反应有几种：制作人说也送上制作人的祝贺，她道谢说更有干劲了（0003、0004）；她吐槽制作人开始说和铺垫完全无关的话，制作人说是学新技能、增加存折余额的事，她说那答案只有一个，当然要做（0005～0008）。

## 她的关键台词
- 0002「いい感じですねぇ～～むふふふ。／アイドルやっててよかったぁ～～♪」——看着余额说当偶像真好
- 0004「わ、ありがとうございまっす！　／さらにやる気が湧いてきましたぁ～！」——收到“祝贺”后的反应
- 0005「うわ、前振りとぜんぜん関係ない話が／始まりましたね。」——吐槽制作人转话题
- 0007「そういうことでしたら、答えは1つ！」——一听和钱有关就答应
- 0008「もちろんやらせていただきますッ！」——爽快接下

## 行为模式
- 存折余额增加 → 当面得意，说“当偶像真好”（0002）
- 被提议学新东西 → 先吐槽话题突兀，一听能增加存款就立刻答应（0005～0008）

## 关系
- プロデューサー：本篇她没有称呼制作人；制作人称她「藤田さん」（0001）。制作人用“增加存折余额”来提出新的练习（0006）。

## 档案类事实
- 她有存折，余额让她觉得当偶像真好（0001、0002）

## 不确定
- 0003～0004 和 0005～0008 看起来是制作人选项后的并列反应；0003“お祝い”具体是什么（钱、礼物）没写。
- opening-true-01／02 标题相同（“为了更接近梦想”），判断是 True 路线开场的并列变体；和 opening-normal 是不同路线的开场。
