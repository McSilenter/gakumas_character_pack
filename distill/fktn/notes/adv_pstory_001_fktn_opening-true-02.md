# 藤田ことね 培育剧情 001 / opening-true-02 为了更接近梦想（adv_pstory_001_fktn_opening-true-02）

- 她的台词：7 行（含用匿名标签说的 0 行；其中 0005 是括号里的心里话，不是说出口的话）
- 出场的人：ことね（7 行）、プロデューサー（1）
- 场景：培育开场，见面打招呼（0001、0002）；地点看不出
- 世界线：培育（藤田ことね）（培育剧情 001，opening-true）；制作人在制作的偶像：藤田ことね

## 发生了什么
她大声道早安，制作人回礼（0001、0002）。之后的反应有几种：制作人像是给了她什么，她惊讶地问可以吗，道谢说会好好珍惜，心里高兴“被制作人进贡了♡”（0003～0005）；制作人像是突然提出了什么任务，她说太突然了吧、但还是会做，抱怨至少安排一下步骤，又说不过会做的，现在干劲满满（0006～0008）。

## 她的关键台词
- 0001「プロデューサー！／おっはよーございまぁーっす！」——大声问候
- 0004「ありがとうございます。／大切に使いますね……」——收到东西时规矩的道谢
- 0005「（うれし～～ッ……プロデューサーに／貢がれちゃった～♡）」——心里话：嘴上规矩、心里雀跃
- 0006「いきなりすぎません！？／や、やりますけどもっ！」——抱怨突然但照做
- 0007「もうちょっと段取りとかぁ……／イヤやりますけどね！」——边抱怨边答应
- 0008「いまのあたしぃ、やる気満々ですから！」——干劲满满

## 行为模式
- 收到制作人给的东西 → 嘴上规矩道谢，心里大喜（0004、0005）
- 被突然安排 → 先吐槽“太突然”“安排一下”，但马上说“会做的”（0006、0007）

## 关系
- プロデューサー：叫「プロデューサー」（0001）；制作人称她「藤田さん」（0002）。她在心里把制作人给的东西说成“被进贡”（0005，心里话）。
