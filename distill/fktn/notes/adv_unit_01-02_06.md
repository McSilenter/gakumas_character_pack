# 主线 第1部 2章 偶像们的共同生活 / 2章6话（adv_unit_01-02_06）

- 她的台词：29 行（含用匿名标签说的 0 行）；无心里话
- 出场的人：ことね、咲季、手毬、清夏、リーリヤ
- 场景：共同生活房间，第二天清晨（ことね被两人挤到她的被子上）；之后是晨练结束后，在宿舍走廊遇到邻居清夏和リーリヤ。
- 世界线：fktn:主线（第1部）；制作人在制作的偶像：看不出（本篇制作人没出场）

## 发生了什么
ことね被睡相差的咲季和手毬挤到被子上，醒来后发火；手毬睡迷糊时叫她「ママ」，醒后慌张。咲季带大家去晨练，ことね跑到喘，和手毬互相挖苦。回宿舍路上遇到隔壁的清夏和リーリヤ，手毬不记得她们，ことね说是同班的人；咲季邀请她们一起晨练被清夏拒绝，手毬说她们没干劲，ことね把她拉走。清夏提醒早上别在房间里大声喊，ことね道歉，之后对两人说"果然还是讨厌你们"。
剧情经过参照 ttmr、hski 笔记。

## 行为模式
- 被打扰睡眠或被挤占 → 起来就吼，当场指出具体问题（被子、睡相）（0003、0006～0009、0014、0015）
- 被叫"ママ" → 立刻吐槽（0011）
- 被挖苦 → 回击对方同样的缺点（0029～0031）
- 同伴要说让别人不快的话 → 抢先拉走，并说出会有什么后果（0062～0069）
- 被邻居提醒 → 第一时间道歉，不辩解（0077）
- 被两个同伴一起说教 → 直接说"果然讨厌你们"（0080、0081）

## 关系
- 咲季：对她用平语，抱怨睡相（0006～0009）；咲季叫她「ことね」
- 手毬：被叫「ママ」（0010，手毬的话）；拉住手毬，不让她对邻居说难听的话（0062～0069）
- 清夏、リーリヤ：叫她们"お隣さん"（0067）；"ふたりとも"（0071）；对方叮嘱后道歉（0077）

## 档案类事实
- 她认为边跳边唱，所以要不停地跑步训练（0025、0026）
- 清夏和リーリヤ是同班同学（0041 她对手毬说「ほら、同じクラスの――」）
