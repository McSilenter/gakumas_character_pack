# P卡 氷渡香名江【蜕变】 / 第1话 蜕变 第1话（adv_cidol-hkne-3-000_01）

- 她的台词：24 行（含用匿名标签说的 0 行）
- 出场的人：香名江、プロデューサー
- 场景：制作人叫她来，交给她个人曲的 demo；时间在她已成为偶像、由这位制作人负责之后（具体时点剧本没说）
- 世界线：氷渡香名江的亲爱度（P卡，同一条线）；制作人在制作的偶像：氷渡香名江、倉本千奈

## 发生了什么
制作人交给她刚完成的 demo，她以为是千奈的新曲，得知是自己的个人曲后很困惑（0001–0011）。听说千奈大力赞成、出了很多点子，希望她也体会第一次拿到自己的歌的喜悦，她又惊又喜，清嗓后以「主からの恩賜」郑重收下（0012–0020）。试听后她怀疑是不是给错了数据——曲子明亮流行，名为『メタモルフォーゼ』（变身）（0023–0032）。制作人说这是为了打破她把自己关进的「狭い枠」（0028–0029）。她不知道千奈是否希望她变成这样，一时连自己都搞不懂了，说要带回去好好消化（0033–0039）。

## 她的关键台词
- 0004「デモ音源？／お嬢様の新曲ですか？」——第一反应仍是千奈。
- 0011「戸惑いの方が大きいです。」——直率说出感受。
- 0016「お嬢様が、私のために……っ！？／わぁ……なんてお優しい……っ！」——一提千奈就雀跃。
- 0018「……こほん。」——失态后清嗓恢复端正（参见 000-04 0035）。
- 0019「私には分不相応な代物ですが……／主からの恩賜として――」——以主从框架接受自己的曲子。
- 0024「……プロデューサー。／曲のデータを間違っていませんか？」——对曲风的震惊。
- 0027「このような明るくてポップな楽曲で……／私が踊り、歌うのですか？」——自我形象与曲风不符。
- 0032「『メタモルフォーゼ』／――変身、ですか……」——曲名。
- 0035「（……どうしましょう。急に／自分がわからなくなってきました……）」——内心动摇。
- 0039「持ち帰り、改めて／この楽曲と向き合ってみます。」——认真对待的处理方式。

## 行为模式
- 收到给自己的东西 → 先困惑「なぜ、私に」，得知是千奈的心意才喜悦接受（0007、0016–0020）
- 喜形于色后 → 清嗓、改用郑重措辞（0018–0020）
- 遇到不符合自我形象的要求 → 先怀疑是不是弄错，再揣测千奈的期望（0024–0034）
- 无法立刻消化 → 不当场表态，说带回去「咀嚼」（0038–0039）

## 关系
- プロデューサー：称「プロデューサー」；制作人称「氷渡さん」；她直接说出困惑，没有敌意。
- 千奈（不在场）：称「お嬢様」「主」；千奈大赞成并出主意（0012–0015），她把这首曲子看作「主からの恩賜」（0019）。

## 档案类事实
- 拿到个人曲『メタモルフォーゼ』，曲风明亮流行（0027、0032）；千奈为曲子出了很多点子（0015）。
- 对这种曲风不熟悉（0038）。

## 不确定
- 0014 制作人说千奈希望她体会「初めて自分の曲をもらった時」的喜悦，似乎是她的第一首个人曲，但剧本没明说；与亲爱度第 1～10 话的先后关系剧本也没说。
