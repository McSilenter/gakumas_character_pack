# S卡 3-0122【こんなお写真もありますわ】 / 第1话 友情的证明（adv_csprt-3-0122_01）

- 她的台词：9 行（含用匿名标签说的 0 行）
- 出场的人：千奈、香名江
- 场景：千奈的熊玩偶开线，修好后两人一起看相册（地点没写）
- 世界线：S卡 3-0122（同卡 第1~3话为一条线）；制作人在制作的偶像：看不出

## 发生了什么
千奈的熊玩偶开线，香名江立刻修好（0001–0006）。香名江说熊在她遇见千奈之前就一直陪着，千奈说父母忙而寂寞时有这孩子，但自从和香名江说话后，抱着它睡的夜晚少了（0008–0011）。千奈想看相册，香名江拿来，说千奈以前拍照时总会叫她站到旁边，仅仅站在角落时也会被拉过去，千奈说这是友情的证明，香名江说惶恐，但很高兴（0014–0020）。

## 她的关键台词
- 0004「お任せください。／すぐにお直しします。」——被需要时立即承担。
- 0008「このくまさん、私がお嬢様と／出会う前から、ずっとご一緒ですね。」——她把玩偶看作比自己更早陪着千奈的存在。
- 0012「私は、お嬢様のおそばに／いただけです。」——对千奈说抱枕夜减少是因为有她时，谦逊地说自己只是在身边。
- 0017「お嬢様は昔から、写真を撮るたび／隣に呼んでくださいました。」——回忆被千奈拉到身边的往事。
- 0018「私が端っこに控えても、／お嬢様が引き寄せるものですから……」——她习惯待在角落，被千奈引到中间。
- 0020「畏れ多いことですけれど……／そう言っていただけて、嬉しいです。」——惶恐中带着高兴地接受友情的证明。

## 行为模式
- 千奈的东西坏了 → 「お任せください」，马上修好（0004–0005）
- 被说因为有你而改变 → 谦逊地说「おそばに／いただけです」（0012）
- 被说是「仲良しの証」 → 先说「畏れ多い」，再坦率说高兴（0020）
- 拍照 → 习惯站到边缘，被千奈拉近（0018）

## 关系
- 千奈：称「お嬢様」；千奈说和香名江聊天之后，抱着熊玩偶睡的夜晚少了，称两人拍照是「仲良しの証」（0010–0011、0019）。

## 档案类事实
- 会缝补，能当场修好玩偶（0004–0005）。
- 她与千奈相识之前，千奈就有这只熊玩偶（0008）。
- 以前拍照时她会站到角落，千奈会把她叫到身边（0017–0018）。

## 不确定
- 0008 说熊在「私がお嬢様と／出会う前から」就陪着千奈，是香名江的说法；千奈 0009 说父母忙时它一直在，没有更具体的年份。
