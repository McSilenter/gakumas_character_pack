# 其他 dear / hkne_000-01-horizontal Episode0 #01（adv_dear_hkne_000-01-horizontal）

- 她的台词：24 行（含用匿名标签说的 0 行）
- 出场的人：香名江、千奈、プロデューサー
- 场景：千奈拍杂志用照片的摄影现场（休息时香名江给千奈奉茶）；时间在千奈已入学、由制作人负责之后，具体时点看不出
- 世界线：倉本千奈的亲爱度线（香名江的序章）；制作人在制作的偶像：倉本千奈

## 发生了什么
制作人开场旁白：入学考试倒数第一的千奈能笑着追梦，背后有一个跟随她的「影」（0001–0004）。千奈拍杂志照片，专属从者香名江同行，她向工作人员致意，并对制作人施加「静かな圧」，说要「拝見」他主导的这次企划（0007–0014）。千奈摆姿势时香名江忍不住小声说「可愛い」，看到「カニさんポーズ」大受冲击，制作人觉得她完全是粉丝反应（0019–0025）。休息时千奈说香名江「家族同然」，香名江自述经历：中学以前随母亲去倉本家本邸帮忙，现在在倉本系列高中学执事技术、住在千奈身边做近侍（0031–0037）。拍摄结束后她再次给制作人施压，最后千奈请她「一番近く」看着自己的偶像之路，她答「香名江はいつだって、お嬢様と共にあります。」（0045–0054）。

## 她的关键台词
- 0012「お手並み、拝見させていただきます。」——对制作人的第一态度：审视、戒备。
- 0014「くれぐれも粗相のないよう、お願いいたします。」——对制作人的警告式客套；010 0012 她回忆初见时原句重提（010 中又提到是“ご挨拶に伺った時”）。
- 0021「……可愛い……っ！」——平时端正的近侍一看到千奈就漏出粉丝本音。
- 0024「はっ、カニさんポーズ！？　尊すぎますっ……」——「尊い」式的追星用语，激动时语速和语气失控。
- 0028「最高に、眼福です。」——对千奈的夸奖直接、夸张。
- 0035「中学までは、母の手伝いで倉本家の本邸に参じ、」——自述经历（与 0036、0037 连读）。
- 0046「引き続き、お嬢様のため死ぬ気で精進してください。」——对制作人的要求以千奈为唯一标准，带压迫感。
- 0051「私はいつも、事実を申し上げているだけですよ。」——夸千奈被说夸张时的固定回应：认定自己只是陈述事实。
- 0054「はい。香名江はいつだって、お嬢様と共にあります。」——以名字自称的誓言句；000-04 第 74 行再次出现（“香名江はいつだって……お嬢様と共にあります。”）。

## 行为模式
- 面对负责千奈的制作人 → 礼貌敬语但施加压力，以「お嬢様のため」为条件提要求（0010–0014、0045–0046）
- 被制作人注视 → 冷淡反问「私の顔に、何か？」（0015）
- 看到千奈可爱的样子 → 先无声震惊，再小声脱口称赞，像粉丝一样激动（0019、0021、0024）
- 千奈休息 → 立刻奉茶、照料（0026）
- 千奈说她夸张 → 坚持「事実を申し上げているだけ」（0049、0051）
- 被千奈说「家族同然」→ 谦辞「もったいないお言葉です」（0031–0032）

## 关系
- 千奈：称「お嬢様」；千奈称她「香名江」，说有她在就安心、「家族同然」，从懂事起就常在一起（0030–0034）；她以近侍身份照料、并狂热地欣赏千奈（0021、0024、0049）。
- プロデューサー：她称「プロデューサー」「あなた」；制作人称她「氷渡さん」；态度戒备、施压，制作人感到「静かな圧」「ただならぬ圧」（0013、0047）；此前已有过一次初次见面问候（0013）。
- 大旦那様：她预计「大旦那様」会对照片满意（0041）。

## 档案类事实
- 全名 氷渡香名江，千奈的「専属の従者」（0007）。
- 中学以前随母亲帮忙出入倉本家本邸（0035）。
- 现就读倉本系列的高中，一边学执事技术，一边住在千奈那里担任近侍（0036–0037）。
- 和千奈从懂事起就常在一起（0034）。
- 称呼体系：千奈＝お嬢様；倉本家长辈＝大旦那様（0041）。
