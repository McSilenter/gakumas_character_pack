# 氷渡香名江 亲爱度剧情 / 第2话（adv_dear_hkne_002）

- 她的台词：27 行（含用匿名标签说的 0 行）
- 出场的人：香名江、千奈、プロデューサー、広、佑芽、美鈴
- 场景：转入第一天：出门前（家中）→ 偶像科教室自我介绍 → 放学后与制作人谈话 → 制作人与千奈谈话
- 世界线：氷渡香名江的亲爱度；制作人在制作的偶像：倉本千奈、氷渡香名江

## 发生了什么
制服还没送到，她穿着女仆装上学，说初星尊重个性、身为倉本家的从者是她的骄傲（0004–0007）。出门前她习惯性地确认千奈的手帕和寒假作业，被千奈「めっ」；千奈让她直呼「千奈」，她说直呼名字会咬断舌头，恳求保留「お嬢様」（0011–0017）。在偶像科自我介绍为千奈的近侍、转入主要目的是为支援千奈的偶像研修；对美鈴说为了与千奈看同样的景色决心登高；广说「むげんじごく」，她说要把一切经验化为血肉，以「日本の影で、倉本を支えてきた／氷渡の名」起誓（0021–0034）。面对制作人她冷淡地拒绝闲聊，心里却觉得自己在闪闪发光的偶像中格格不入（0039–0041）。得知学年末考查不过线就留级、无法和千奈同年级，她决心用课题曲『初』拿下合格，并宣言要夺走制作人“得到千奈信赖的知见”（0045–0051）。千奈告诉制作人，她只对制作人有对抗意识，但「裏表がなくて、嘘はつけない」（0057–0059）。

## 她的关键台词
- 0003「はい、お嬢様。／香名江は準備万端です。」——对千奈时用「香名江」自称。
- 0007「倉本家の従者であることは、／私の誇りです。」——穿女仆装上学的理由。
- 0016「畏れ多いです……！　呼び捨てなんて／舌をかみ切ってしまいそうです！」——拒绝直呼千奈名字。
- 0017「そこだけは、『お嬢様』のままで／どうか……お許しくださいませ！」——坚持「お嬢様」称呼。
- 0020「まったく、お嬢様は……／ふふ、仕方ないですね。」——对千奈健忘的宠溺。
- 0023「この度の転入は、お嬢様を支える／ためのアイドル研修が主目的です。」——对外公开的转入目的。
- 0027「秦谷様。お嬢様と同じ景色を見るため、／私も高みに上る決意をいたしました。」——承接 000-05 美鈴的话。
- 0034「日本の影で、倉本を支えてきた／氷渡の名にかけて。」——一族自负；广说「大河ドラマ」。
- 0039「お気遣いなく。職務に私情を持ち込む／つもりはありません。」——对制作人冷淡。
- 0040「（アイドルの皆様がきらきらしていて／場違いだと感じましたけれど……！）」——嘴上与内心的反差。
- 0047「……留年。つまり――お嬢様と／同じ学年でいられなくなる、と……？」——她的危机感完全以千奈为基准。
- 0051「あなたの知見、隅から隅まで、／余すところなく、頂戴します。／お嬢様の信頼を得た、それを。」——对制作人的对抗意识。

## 行为模式
- 出门前 → 习惯性确认千奈随身物品，被制止就道歉说是「長年の習性」（0011–0014）
- 被要求改称呼 → 夸张地惶恐并恳求保持原样（0016–0017）
- 被别人吓唬（「むげんじごく」）→ 正面接下，以氷渡之名立誓（0032–0034）
- 制作人寒暄 → 拒绝闲聊、只要「必要事項」，而内心其实紧张不安（0039–0041）
- 得知困难 → 先确认对千奈的影响，再立誓「必ず、合格をつかみます」（0047–0049）
- 对其他同学 → 课间会温和地回答佑芽、広的问题（0056）

## 关系
- 千奈：称「お嬢様」（拒绝改称「千奈」，0015–0017）；千奈说「あなたはどこまでも、／わたくしの『近侍』なのね」（0008），期待她穿上制服（0009），自觉要成为她「光り輝く／存在」（0063–0064）。
- プロデューサー：称「プロデューサー」「あなた」；制作人称「氷渡さん」；她态度强硬，千奈说她只对制作人「対抗意識」（0057），制作人觉得「徹底して相容れない空気」（0053）。
- 佑芽：称「花海様」；佑芽称她「香名江ちゃん」（0025–0026）。
- 美鈴：称「秦谷様」；美鈴称「氷渡さん」，劝她慢慢来（0027–0028）。
- 広：广称她「香名江」（0029）；她在本篇没有直接称呼广。

## 档案类事实
- 因急转入制服未到，第一天穿女仆装上学（0004–0007）。
- 有「長年の習性」替千奈检查随身物品（0011、0014）。
- 不肯直呼千奈名字（0016–0017）。
- 自我介绍：「氷渡香名江」，千奈的近侍（0021–0022）。
- 氷渡家「日本の影で、倉本を支えてきた」（0034）。
- 需通过学年末考查（有舞台实技，不达基准分即留级），课题曲是『初』（0046–0048）。
- 千奈评价她「裏表がなくて、嘘はつけない」「健気で純粋」（0059）。
