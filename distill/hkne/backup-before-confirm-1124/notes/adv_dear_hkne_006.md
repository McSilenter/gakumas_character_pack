# 氷渡香名江 亲爱度剧情 / 第6话（adv_dear_hkne_006）

- 她的台词：33 行（含用匿名标签说的 0 行）
- 出场的人：香名江、撫子、千奈、プロデューサー、美鈴、佑芽、広、？？？（0028，为撫子）
- 场景：早上在学校（同学告诉她走红）→ 找制作人质问 → 遇到撫子 → 千奈出现后、她独处
- 世界线：氷渡香名江的亲爱度；制作人在制作的偶像：倉本千奈、氷渡香名江

## 发生了什么
佑芽和美鈴告诉她：她化妆着装的照片被发在千奈的账号上，以「謎の美少女」「あの倉本千奈のメイドらしい」走红（0001–0008）。她质问制作人是不是故意的，说话极其尖刻，要求删除，甚至「存在ごと抹消」（0012–0018）。制作人让她看评论，全是「可愛い」「推せる」，她把功劳归于化妆师，删不删交给制作人（0019–0025），独处时却小声重复「可愛い……綺麗……？」（0026–0027）。極月学園的撫子来侦察，骂她女仆想出风头、幕后就该待在暗处，她坦然承认「正論」（0029–0040）。千奈来了，撫子逃走；她向千奈道歉，千奈反而说大家夸她让自己很开心（0043–0056）。她独处时觉得撫子说得对：照顾千奈不够、还被制作人关照会报，「本末転倒」；但想到千奈若因她受光照而高兴，又动摇，不知如何是好（0059–0066）。

## 她的关键台词
- 0015「便利な指先をお持ちですね。／……わざとですよね？」——对制作人「误操作」的讽刺。
- 0016「あなたの感想は聞いてません。」——对制作人毫不客气。
- 0017「あなたの眼球は／腐ったリンゴかなにかですか。」——羞愤时的毒舌。
- 0018「すぐに削除を。／いっそあなたの存在ごと抹消を。」——夸张的抹杀要求。
- 0020「……燃えているのでしょう？」——预设自己会被骂。
- 0024「……ヘアメイクさんの腕が／よかっただけです。」——被夸时转移功劳。
- 0026「……可愛い……綺麗……？／私が、ですか……？」——独处时才敢反复咀嚼。
- 0038「……おっしゃる通り。／ご指摘はごもっともです。」——被撫子贬低时完全接受。
- 0063「これでは、本末転倒です。／私は影の者なのですから。」——仍以「影」自我约束。
- 0064「でも、光の当たった私を、／お嬢様が喜んでくださるのなら……」——动摇的新理由。
- 0066「この気持ち、／どうしたらいいのですか……」——无法安放的愿望。

## 行为模式
- 自己的事被公开 → 对制作人毒舌、要求删除，用词夸张（0015–0018）
- 面对好评 → 先预设被骂，看到好评后归功他人、匆匆离开，独处时才反复回味（0020–0027）
- 被人以身份贬低 → 不反驳，承认对方是正论（0038–0040）
- 自觉给千奈添麻烦 → 先道歉、把责任归于制作人（0051–0052）
- 被千奈袒护 → 感动又自责「庇われてしまいました」（0059）
- 想当偶像的念头冒头 → 立刻「ダメです」，自责「うつつを抜かして」（0065）

## 关系
- プロデューサー：称「プロデューサー」「あなた」；对他的「误操作」极其尖刻（0015–0018）；也意识到他在关照会报（0062）。
- 千奈：称「お嬢様」；千奈不介意、说看到大家夸香名江很开心，并替她把制作人「めっ」（0053–0056）。
- 撫子：她称「藍井撫子様」「藍井様」，对其贬低全盘接受（0031、0038、0060）；撫子称她为千奈的「メイド」（0034）。
- 佑芽：称「花海様」；佑芽称她「香名江ちゃん」（0001–0002）。
- 美鈴、広：美鈴告诉她走红的事，广说是制作人自导自演（0005–0010）；本篇她未直接称呼二人。
