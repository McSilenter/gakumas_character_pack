# 氷渡香名江 亲爱度剧情 / 第7话（adv_dear_hkne_007）

- 她的台词：48 行（含用匿名标签说的 0 行）
- 出场的人：香名江、プロデューサー、千奈、ダンストレーナー、学園長
- 场景：梦中舞台 → 醒来（家中）→ 千奈在厨房尝试做饭 → 舞蹈课 → 考查前一天与制作人谈话 → 考查当天早上
- 世界线：氷渡香名江的亲爱度；制作人在制作的偶像：倉本千奈、氷渡香名江

## 发生了什么
她梦到和千奈同台、被学园长判合格，醒来后骂自己「不忠な夢」、念「煩悩退散」，却心跳不止（0001–0013）。千奈为了体会女仆工作的辛苦尝试煎蛋失败，向她道歉，她更加不知所措（0014–0025）。舞蹈课上训练员说她比以前更僵硬，问她是否在迷茫（0026–0028）。考查前一天，制作人说考查与千奈的演出时间冲突，并问她是想支持千奈还是想独占千奈，说她有只有她能做的事——偶像（0032–0059）。独处时她承认千奈成为『一番星』那天的寂寞，以及“成为偶像就能看到同样的景色”的愿望，却又以近侍身份否定（0060–0069）。考查当天早上千奈第一次拒绝她的打理，让她以自己为先，她感到被留下，脚步动不了；制作人发现联系不上她（0070–0081）。

- 0011「煩悩退散……！／煩悩退散ですっ……！」——口头禅再现（参见 005 0078）。
- 0036「進級して、／お嬢様の支援をするため……ですが。」——表面的目标。
- 0044「あれは、奇跡の1枚です……」——不承认自身素质。
- 0047「お嬢様のために割ける時間が／減ってしまいます。」——拒绝成为偶像的主要顾虑。
- 0049「お気持ちだけで十分です。／あなたにはご自身の職務がありますし。」——仍不愿让制作人分担。
- 0063「嬉しいのに、胸が苦しくて……／離れてしまうようで、寂しくて……」——明确说出 000-04 那天的感受。
- 0064「でも、アイドルになれば、／同じ景色を、一緒に見られ――」——说到一半自己打断。
- 0066「近侍である私が、そんな無礼な願望を／抱いてはなりません。」——身份对愿望的压制。
- 0069「私は、お嬢様を支える者として、／伴走すればよいのです。」——为自己找的退路。
- 0075「初めて、断られてしまいました……」——千奈第一次拒绝她的照料。
- 0076「お嬢様がこのまま自立されたら、／従者もアイドルも半端な私は……」——身份危机。

## 行为模式
- 愿望在梦里或想象中出现 → 惊醒后自责「不忠」，念「煩悩退散」（0007–0011）
- 千奈做她的工作并道歉 → 「とんでもございません」，接手收拾，内心更乱（0021–0025）
- 心里迷茫 → 表现在舞蹈上，动作变僵（0026–0027）
- 被问到真实动机 → 先反问「どういう意味ですか？」，再以时间和千奈为由推辞（0038、0046–0049）
- 独处整理情绪 → 先承认愿望，再用身份和「未熟者」否定（0060–0069）
- 被千奈拒绝照料 → 陷入「半端」感，逃避（脚走不动）（0075–0079）

## 关系
- 千奈：称「お嬢様」；千奈想体会她的辛苦、向她道歉（0018–0022），考查当天要她「自分のことを優先なさい」，第一次拒绝了她的早间打理（0072–0074）。
- プロデューサー：称「あなた」；制作人问她是想「支えたい」还是「独り占めしたい」（0051），说愿意不眠不休补上千奈那边的时间（0055）；她仍推辞（0049、0054）。
- ダンストレーナー：指出她「前よりもぎこちない」（0026）。

## 档案类事实
- 千奈的演出她一向不缺席随行，但这次和自己的考查冲突（0033）。
- 每天早上为千奈打理、准备随身物品（台本、饮料、润喉糖）（0070–0071、0073）。
