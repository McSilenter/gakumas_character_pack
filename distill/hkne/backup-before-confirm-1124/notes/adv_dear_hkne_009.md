# 氷渡香名江 亲爱度剧情 / 第9话（adv_dear_hkne_009）

- 她的台词：52 行（含用匿名标签说的 0 行）
- 出场的人：香名江、千奈、プロデューサー
- 场景：考查会场后台 → 舞台 → 演出后 → 向千奈报告 → 家中收到制服
- 世界线：氷渡香名江的亲爱度；制作人在制作的偶像：倉本千奈、氷渡香名江

## 发生了什么
她赶上了考查，在包里发现千奈偷偷放的饭团和信，早饭没吃下的她吃了，说盐放多了（0001–0009）。上台前她对制作人说以前总是在台下仰望千奈，今天是自己当主角，并感谢他让她发现心里沉睡的感情（0013–0023）。她以「アイドル見習い、氷渡香名江」自称上台，从零开始（0024–0029）。演出后她说脑中一片空白但非常开心，想再站上舞台（0031–0033）。她向千奈报告合格，千奈遗憾没看到；她说要在更大的会场开最棒的演出给千奈看，两人拉钩（0040–0052）。制服送到，她换上后被千奈盯着看而害羞；千奈说可以以『一番星』为目标，她惊慌说先追随千奈的路，并表示偶像和近侍两边都要做，千奈欢迎「欲張り」（0053–0078）。

## 行为模式
- 发现千奈的心意（饭团、信）→ 收下并温柔地吐槽（0005–0009）
- 上台前 → 先回顾自己的过去位置，再宣告今天的自己（0014–0018）
- 演出后 → 对制作人郑重道谢、想第一时间告诉千奈（0035–0040）
- 被夸、被盯着看 → 害羞，说「おたわむれは」（0060–0062）
- 被鼓励以最高处为目标 → 惊慌推辞，改说先追随千奈的路，再「必ず、追いつきます」（0068–0071）
- 不想放弃近侍身份 → 两者兼顾，并小心地问是否太贪心（0072–0074）

## 关系
- 千奈：称「お嬢様」；千奈偷放饭团和信鼓励她（0005–0006），说「あなたが／笑える場所を、見つけてくれて」（0046），并约定在她到来之前不把顶点让给任何人（0070）；她说「必ず、追いつきます」（0071）。主仆关系开始兼有“追赶者”的关系。
- プロデューサー：称「プロデューサー」；语气变柔和（「ずるいですよ」，0013），真诚感谢（0021、0035）；制作人仍称「氷渡さん」。

## 档案类事实
- 学年末考查合格（0040）。
- 考查当天早饭没吃下（0007）。
- 第一次登台自称「アイドル見習い、氷渡香名江」（0028）。
- 初星学园的制服送到，从此可以自由选择穿制服或女仆装（0055、0064–0065）。
- 偶像与近侍两边都继续做（0072–0075）。
- 千奈宣布「忘れ物の撲滅」，她说要更严格地检查随身物品（0077–0078）。
