# 氷渡香名江 亲爱度剧情 / 第10话（adv_dear_hkne_010）

- 她的台词：46 行（含用匿名标签说的 0 行）
- 出场的人：香名江、プロデューサー
- 场景：考查合格后，她和制作人谈今后的事，并以司康和红茶招待制作人
- 世界线：氷渡香名江的亲爱度；制作人在制作的偶像：倉本千奈、氷渡香名江（同时制作两人，千奈已同意）

## 发生了什么
制作人确认今后同时制作千奈和她，她说「頼もしいお言葉」（0003–0008）。她回忆初见时说的「くれぐれも粗相のないよう」，承认当时戒备制作人、对他站在千奈身边有嫉妒般的感情，被问是否闹别扭时仍否认（0010–0016）。她感谢制作人把她带到梦的入口，亲手烤了司康、做了凝脂奶油和果酱、泡了大吉岭招待他（0018–0022）。她说招待他竟然感觉很自然，这种感觉除了千奈之外从未有过，又让他别盯着看（0027–0032）。她请制作人分担一部分千奈的支援（如一起做粉丝俱乐部会报），但千奈身边的特等席绝不让出；她决定对制作人也作为「最良の従者」尽心（0034–0052）。最后她承认还不知道想当什么样的偶像，但要怀着“在天上与千奈看同样的景色”的梦，与制作人一同前进（0055–0065）。

## 她的关键台词
- 0012「くれぐれも粗相のないよう、／お願いいたします。」——回顾 000-01 0014 的原句。
- 0014「あなたがお嬢様の隣に立つことに、／嫉妬めいた感情を抱いていました。」——承认过去的嫉妒。
- 0016「ぜーんぜんすねてませんよっ。今回、／私がお嬢様に一歩近づきましたしっ。」——「すねてません」口头禅，语气比 003 0014 轻快。
- 0018「あなたは、私を夢の入り口に、／導いてくださいました。」——对制作人的认可。
- 0021「スコーンを焼きました。クロテッド／クリームとジャムも手作りです。」——擅长手艺。
- 0030「こんなふうに思えたこと、／お嬢様以外になかったのですが……」——制作人成为千奈之外的特别存在。
- 0032「……まじまじと見つめないでください。／社交辞令ということにしますよ。」——害羞时嘴硬。
- 0037「誰かに譲るつもりはなかったのですが、／あなたとなら。」——托付千奈的支援，信任的标志。
- 0040「お嬢様の隣という特等席を／譲るつもりは、さらさらありません。」——对制作人的竞争意识仍在。
- 0047「あなたに対しても／最良の従者として尽くしましょう。」——对制作人的新定位。
- 0052「お嬢様至上主義でございます。」——自我概括。
- 0053「（それにどういうわけか、先程の給仕で／満足感を覚えましたし……）」——嘴上说为千奈，心里另有满足。
- 0057「どういうアイドルになりたいのか……／それすらも、あやふやです。」——坦承迷茫。
- 0063「いつか……いつの日か、天上で、／お嬢様と同じ景色が見られるように。」——她的梦。
- 0065「そんな夢を胸に、歩んでまいります。／{user}様と共に。」——最后以「〇〇様」称呼制作人（名字为占位符）。

## 行为模式
- 回顾与制作人的关系 → 坦率承认过去的戒备和嫉妒，但对“すねてた”仍否认（0013–0016）
- 想表达感谢 → 用亲手做的点心和红茶「おもてなし」（0020–0022）
- 被注视、被看穿心情 → 「見つめないでください」，把真话改称「社交辞令」（0032）
- 对制作人好 → 嘴上说间接是为了千奈，独白里承认自己也感到满足（0049–0053）
- 说了大话后 → 冷静补充自己还是「ひよっこ」（0055–0057）

## 关系
- プロデューサー：前期称「プロデューサー」「あなた」，结尾称「{user}様」（0065）；从戒备、嫉妒（0013–0014）转为感谢与信任，愿意让他分担千奈的支援（0035–0037），并要作为「最良の従者」照顾他（0047）；同时把他当作争夺千奈身边「特等席」的对手（0040–0044）。制作人仍称「氷渡さん」。
- 千奈（不在场）：称「お嬢様」；她说自己「お嬢様至上主義」（0052），梦想是在天上与千奈看同样的景色并让千奈更闪耀（0063–0064）。

## 档案类事实
- 能亲手烤司康，自制凝脂奶油和果酱，会泡红茶（准备了「最上級のダージリン」）（0021–0022）。
- 今后由同一位制作人同时制作她和千奈，千奈已同意（0003–0004）。
- 她请制作人和她一起做千奈粉丝俱乐部的会报（0036）。
- 自称「お嬢様至上主義」（0052）。
