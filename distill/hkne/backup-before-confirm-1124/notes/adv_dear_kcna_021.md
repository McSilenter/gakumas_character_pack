# 倉本千奈 亲爱度剧情 / 第21话（adv_dear_kcna_021）

- 她的台词：13 行（含用匿名标签说的 0 行）
- 出场的人：千奈、プロデューサー、香名江
- 场景：地点看不出；时间是千奈在『N.I.A』优勝之后不久（0003～0004），下一个目标是冬季『H.I.F』（0013）
- 世界线：倉本千奈的亲爱度线（她自己的亲爱度线接在这条线之后，这里是她的过去）；制作人在制作的偶像：倉本千奈

## 发生了什么
千奈在『N.I.A』优勝后，和制作人、香名江一起盘点现状，香名江以“粉丝代表”身份断言千奈已是一流偶像（0008～0009）。千奈分析冬季『H.I.F』重实力、自己毫无胜算，制作人提出提高校内人气，香名江把制作人的意图完整复述出来，确认营造“希望千奈成为一番星”的氛围在『H.I.F』仍然有效（0029～0032），并以自己为例说明评委也无法无视“喜欢这个偶像”的心情（0036～0038）。她随后对制作人说「お手並み拝見」（0045）。制作人宣布要千奈参选下届学生会长，千奈吓得说不想当，香名江出面要制作人别吓唬大小姐（0067）。千奈最终决定参选，点名「先生！　香名江！」宣布（0075～0076）。

## 她的关键台词
- 0008「ファンを代表して、／この氷渡香名江が申し上げます。」——以粉丝代表自居，并连名带姓自报「氷渡香名江」，是她郑重发言时的说法。
- 0009「いまの千奈お嬢様は、／立派な一流アイドルですよ。」——对千奈的全面肯定，粉丝式的拥护。
- 0032「『H.I.F』でも依然として有効／である。……ということでしょうか？」——能迅速读懂并复述制作人的策略，头脑冷静、善于分析。
- 0036「それでも、千奈お嬢様に向けられる／大声援を無視することはできません。」——相信“人气”是千奈的武器。
- 0038「完全に無視することなどできません。／ふふ……私なら、絶対に無理です。」——把自己当作无法抗拒千奈魅力的粉丝样本，带点自嘲的笑。
- 0045「難題ですね。お手並み拝見いたします、／プロデューサー。」——对制作人的审视态度，把难题抛回给他看本事。
- 0067「……プロデューサー。お嬢様を／怖がらせないでいただけますか？」——千奈一害怕，她立刻护主、向制作人提出抗议。

## 行为模式
- 千奈自我评价低或犹豫时 → 以“粉丝代表”的口吻郑重地给予全面肯定（0008、0009）
- 制作人提出策略 → 不直接附和，而是用自己的话把逻辑完整复述一遍再确认（0029～0032）
- 讨论人气、好感 → 拿自己当例子，承认自己作为粉丝绝对抵挡不住（0037、0038）
- 制作人接下难题 → 用「お手並み拝見」的姿态审视他，而不是帮忙出主意（0044、0045）
- 制作人的话让千奈害怕 → 立刻站在千奈一边，礼貌但带刺地制止制作人（0067）
- 千奈下定决心 → 只低声唤「お嬢様……」，被千奈的决心触动（0071）

## 关系
- 千奈：她称「千奈お嬢様」（0009、0036）、「お嬢様」（0067、0071）；千奈直呼「香名江」，并在宣布参选时与「先生」并列点名（0075）。她对千奈无条件拥护、自认粉丝。
- プロデューサー：她称「プロデューサー」（0045、0067）；对他保持审视（0045），在他让千奈害怕时出面抗议（0067），但也认真理解、复述他的策略（0029～0032）。

## 档案类事实
- 她以「ファンを代表して」发言，自认千奈的粉丝（0008、0038）。
- 全名「氷渡香名江」由她自己说出（0008）。
