# 倉本千奈 亲爱度剧情 / 第23话（adv_dear_kcna_023）

- 她的台词：4 行（含用匿名标签说的 0 行）
- 出场的人：千奈、プロデューサー、燕、香名江、莉波、星南
- 场景：地点看不出；生徒会选举说明会之后、立候补演说之前（0001～0002）；0033～0043 是千奈回想雨夜燕给的提示
- 世界线：倉本千奈的亲爱度线（她的过去）；制作人在制作的偶像：倉本千奈

## 发生了什么
千奈已经想好了立候补演说的内容，当场在制作人和香名江面前试讲，香名江一再称赞（0014、0021）。千奈说演说不是背下来的、只是把心意说出口，香名江对制作人说“这就是倉本千奈お嬢様”（0028）。千奈根据燕给的“項羽与劉邦”的提示，决定集结一同作战的伙伴，并请制作人和香名江做她“最初的伙伴”（0055～0057）。香名江回答「香名江はいつだって、／お嬢様と共にあります」（0058）。

## 她的关键台词
- 0014「ご立派です、お嬢様。」——对千奈的标准称赞句。
- 0021「素晴らしかったです、お嬢様。」——听完演说的即时称赞。
- 0028「ご覧ください、プロデューサー。／これが倉本千奈お嬢様です。」——向制作人“展示”千奈，带着自豪与对制作人的居高临下。
- 0058「香名江はいつだって、／お嬢様と共にあります。」——以自称「香名江」宣誓追随；这句与她 Episode0 #01（adv_dear_hkne_000-01-horizontal）第54行只差换行，Episode0 #04 第74行也有几乎相同的一句，是她的招牌誓言。

## 行为模式
- 千奈做出好表现 → 简短郑重地称赞（ご立派です／素晴らしかったです＋お嬢様）（0014、0021）
- 千奈的长处显露时 → 转向制作人炫耀“这就是我家大小姐”（0028）
- 千奈请求支持 → 不谈条件，用自称「香名江」立刻表示永远同在（0058）

## 关系
- 千奈：称「お嬢様」「倉本千奈お嬢様」（0014、0028）；千奈直呼「香名江」，把她和「先生」并列请为最初的伙伴（0019、0055～0057）。
- プロデューサー：称「プロデューサー」（0028）；对他是向其展示千奈的姿态。

## 档案类事实
- 她以第三人称「香名江」自称宣誓追随千奈（0058）。
