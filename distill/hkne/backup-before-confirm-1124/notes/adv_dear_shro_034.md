# 篠澤広 亲爱度剧情 / 第34话（adv_dear_shro_034）

- 她的台词：5 行（含用匿名标签说的 0 行）
- 出场的人：広、星南、owl、千奈、香名江（owl 的「？？？」0050 不算她的）
- 场景：『H.I.F』本战前（0019「本戦でまみえる前に」、0041），与千奈、香名江在会场擦肩而过
- 世界线：篠澤広的亲爱度；制作人在制作的偶像：篠澤広（0006「素敵なプロデューサー」）

## 发生了什么
千奈对広说“稍后见”，带着香名江离开（0001）。香名江向広宣布这次是敌人，请她有觉悟（0003–0005）。広与千奈说着“都是一个人什么也做不到”，香名江说两人又回到了平常的气氛（0008–0012）。之后広和星南对话，owl 出现（0017 起），这部分与香名江无关。

## 她的关键台词
- 0003「――篠澤様。」——先郑重叫住広，然后才切入正题。
- 0004「生徒会選挙では／お世話になりました、が。」——先感谢，再用「が」转折，礼数与对抗并存。
- 0005「今回は敵同士です。お覚悟を。」——明确划清立场：这一次是敌人。
- 0012「おふたりとも……いつもの雰囲気に／戻ってしまわれましたね。」——看着千奈和広的对话，无奈地点出她们回到了日常节奏。
- 0002「はい、お嬢様。」——被千奈叫走时的应答。

## 行为模式
- 比赛前遇到對手 → 先表达上次的谢意，再宣告「敌同士」（0004、0005）
- 千奈和広气氛放松 → 无奈地指出两人又回到日常（0012）
- 千奈叫她走 → 立即应「はい、お嬢様。」（0002）

## 关系
- 広：称「篠澤様」；有生徒会選挙时「お世話になりました」的往来，这次是对手（0004、0005）。広对她没有直接称呼，用「千奈にも、心強い仲間がいた」概括（0007）。
- 千奈：称「お嬢様」；千奈叫她「香名江」（0001、0002）。

## 档案类事实
- 在生徒会選挙中，她受過広的照顾（0004）。
- 在这场比赛里，她站在千奈一方（0005、0007）。

## 不确定
- 0004「お世話になりました」是香名江受了谁的照顾（广本人还是广一方），原文没有展开；只能理解为她对広说的感谢。
- 0007 広说千奈「心強い仲間」，没有明指是香名江，从 0001 之后的接续推断指她。
