# 氷渡香名江 培育事件 001 activity / 006 审问下午茶时间（adv_pevent_001_hkne_activity_006）

- 她的台词：17 行（含用匿名标签说的 0 行）
- 出场的人：香名江、プロデューサー
- 场景：饭桌上（0011 说「長い昼食」）；她向制作人“审问”他如何制作千奈
- 世界线：培育（氷渡香名江）；制作人在制作的偶像：氷渡香名江，且曾制作倉本千奈（0003、0009）

## 发生了什么
她要制作人毫无保留地讲出让千奈“開花”的制作心得（0001–0004）。分支一：制作人说光芒是千奈自己的，她说这种事她早知道，太阳般的千奈的魅力她最清楚；制作人用同样逻辑说作为偶像的千奈他最清楚，她沉默后说这顿午饭要吃很久了（0005–0011）。分支二：她说千奈总是累得遍体鳞伤地回来，她多少次想“闇討”——改口“抗議”——制作人；但又说明白事情原委，看到千奈一脸完成感说还要努力，没有近侍能阻止；只是千奈身边的位置不会让（0012–0018）。分支三：制作人拿出千奈的课程和彩排资料，她一边说自己肯定更了解千奈，一边看到没见过的耀眼表情而动摇，问要拿什么交换这份资料（0019–0023）。

## 她的关键台词
- 0004「お嬢様を開花させたその知見……／残さずお話しください。」——想学制作人的手法。
- 0007「太陽の如きお嬢様の魅力は、おそばで／見てきた私が一番知っていますので。」——“最了解千奈的是我”的自负；千奈＝太阳。
- 0011「……どうやら、／長い昼食になりそうですね？」——被反将一军后的挑衅。
- 0013「そのお姿を見るたび、プロデューサーを／なんど闇討……抗議しようと思ったか！」——说漏嘴式的过激发言。
- 0017「そんな姿を見せられて、／止められる近侍はおりません。」——理解并接受千奈的努力。
- 0018「ですが、お嬢様の隣は渡しません。／そのことを、お忘れなきように。」——对制作人的宣战。
- 0022「（……っ！？　え、こんな表情、／見たことが……まぶしいっ……）」——第一次看到她不知道的千奈。
- 0023「……プロデューサー。このデータ、／何を差し出せばいただけますか。」——为千奈的资料愿意付出代价。

## 行为模式
- 有人声称比她更了解千奈 → 沉默后转为挑衅、准备长期争论（0009–0011）
- 千奈因训练吃苦 → 心里怪制作人，但理解并尊重千奈的意志（0012–0017）
- 看到不知道的千奈 → 内心震动，马上想据为己有（0022–0023）

## 关系
- プロデューサー：称「プロデューサー」「あなた」；对他既想学又竞争，明言「お嬢様の隣は渡しません」（0013、0018、0023）。
- 千奈：称「お嬢様」；她认为千奈像太阳；千奈训练后总是「ボロボロ」回来，仍说「もっと／頑張りますわ」（0007、0012、0016）。

## 档案类事实
- 自认最了解千奈的魅力（0007、0021）。
- 千奈每次训练后都很累，她一直看在眼里（0012、0016）。

## 不确定
- 【译文】0009 是制作人台词，译文“看着我们家仓本同学”多出“我们家”，原文只是「そばで見てきた俺」，不影响她的部分。
- 标题是“下午茶”，但 0011 原文说「昼食」，场景以原文为准。
