# 氷渡香名江 培育事件 001 activity / 007 大小姐的选择（adv_pevent_001_hkne_activity_007）

- 她的台词：15 行（含用匿名标签说的 0 行）
- 出场的人：香名江、プロデューサー
- 场景：店里（可点芭菲、つくねハンバーグ、调和果汁）；制作人请她吃饭作为慰劳

## 发生了什么
制作人请她随便点，她反而犹豫，一听可以选千奈喜欢的菜，便认真追问（0001–0005）。分支一：她吃千奈喜欢的酸奶芭菲，分析酸甜平衡，说要做得比这个更让千奈满意——验证最适合的酸奶、水果产地直送（0006–0011）。分支二：吃つくね汉堡排，她说若自己做会用炭火串烤，制作人反对，她提议“勝負”，随后说是玩笑但值得验证（0013–0019）。分支三：听说可以调果汁、可乐加红茶的「コー茶」，她惊讶，说在千奈喝之前要把所有组合都试毒一遍（0023–0026）。

## 她的关键台词
- 0002「そう言われましても、／迷ってしまいますね……」——被问自己想要什么就犹豫。
- 0004「お気に入り……／くわしくお聞かせください。」——千奈相关立刻认真。
- 0008「デザートの参考にします。」——吃东西也在为千奈做功课。
- 0010「いえ。無論、こちらの商品よりも、／気に入っていただけるようにします。」——要做得比店里好。
- 0017「勝負しますか？」——好胜。
- 0019「冗談です。ですが、あなたの意見が／正しいか、試す価値はありますね。」——半开玩笑半认真。
- 0026「……お嬢様がお口にされる前に、／あらゆるミックスを毒見します。」——“试毒”式的保护。

## 行为模式
- 被要求为自己选 → 犹豫；以千奈为基准就能决定（0002–0004）
- 吃到好吃的 → 分析口味、想着如何为千奈重现并超越（0007–0011、0014）
- 制作人反对她的做法 → 提议比试，再用「冗談です」收回一半（0016–0019）
- 遇到奇怪的新东西 → 先替千奈试（0025–0026）

## 关系

- 千奈：称「お嬢様」；她为千奈做甜点、试毒（0008、0026）。
