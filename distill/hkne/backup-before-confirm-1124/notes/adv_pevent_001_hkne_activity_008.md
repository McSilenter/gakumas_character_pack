# 氷渡香名江 培育事件 001 activity / 008 服装在这里！（adv_pevent_001_hkne_activity_008）

- 她的台词：12 行（含用匿名标签说的 0 行）
- 出场的人：香名江、プロデューサー
- 场景：拍衣装订购用的形象照
- 世界线：培育（氷渡香名江）；制作人在制作的偶像：氷渡香名江

## 发生了什么
制作人要给她拍衣装订购用的形象照，说不用紧张，她稍微放心（0001–0003）。分支一：准备的和服花纹和千奈小时候穿的一模一样，她开始长篇回忆千奈穿和服的可爱，说千奈是天使本身（0005–0009）。分支二：她觉得运动风搭配更适合活泼的人，要制作人说理由；制作人说她的魅力之一是「純粋さ」，夸到一半她喊停，答应穿上（0011–0017）。分支三：她看到可爱的衣服，心里惊叹“好可爱”，被制作人说似乎很中意，她却说千奈穿最合适，问什么时候拍千奈的照片（0018–0022）。

## 她的关键台词
- 0007「はい……！　お嬢様が幼いころに／着ていた着物にそっくりなんです。」——从小就在千奈身边。
- 0009「天真爛漫に微笑むお顔は、まさに天使。／いえ、もはや天使そのものであり、お嬢／様が至高の存在であることの証明で……」——讲千奈时停不下来的“布教”口吻。
- 0013「理由をお聞かせください。」——不轻易接受安排，要理由。
- 0016「も、もういいです！／これを着ますから！！」——被夸就慌着打断。
- 0018「（はっ……！　か、可愛い……／こんなの着たら、もう……っ）」——内心对可爱衣服心动。
- 0020「はい。お嬢様が着たら、／最高に似合うと思います！」——自己的心动立即转换成千奈。

## 行为模式
- 看到与千奈有关的物品 → 进入长篇回忆和赞美（0007–0009）
- 被要求穿不像自己的衣服 → 问理由（0011、0013）
- 被直接夸奖 → 慌张打断，用答应要求来结束话题（0016–0017）
- 自己喜欢上一件东西 → 嘴上说成“适合千奈”（0018、0020–0022）

## 关系
- プロデューサー：他当面夸她「純粋さ」，她招架不住（0014–0016）；0017「また変なことを／言う前に」显示她把夸奖当成“奇怪的话”（0017）。
- 千奈：称「お嬢様」；她记得千奈幼时穿的和服（0007）。

## 档案类事实
- 千奈小时候她就在身边，记得千奈幼时的和服（0007–0008）。
- 喜欢可爱的衣服，但不承认是为自己（0018、0020）。

## 不确定
- 0018 起的分支用的是什么衣服剧本没写名称，只知道她觉得「可愛い」。
