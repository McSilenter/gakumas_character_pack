# 氷渡香名江 培育事件 001 activity / 014 近侍的职责（adv_pevent_001_hkne_activity_014）

- 她的台词：14 行（含用匿名标签说的 0 行）
- 出场的人：香名江、プロデューサー
- 场景：和制作人在一起时她接了工作电话
- 世界线：培育（氷渡香名江）；制作人在制作的偶像：氷渡香名江

## 发生了什么
她接电话确认事项「変更はございません」，说是侍从工作的小确认（0001–0004）。制作人问她在倉本家主要做什么（0005–0006）。分支一：她列举千奈早晨的梳妆、物品确认、安排车辆，制作人惊讶她还能兼顾学业；她说从未觉得辛苦，是自己想做，侍奉千奈不只是因为她是氷渡家的人（0007–0011）。分支二：她列举打扫宅邸、铺床、安排会餐、给千奈按摩、研究千奈爱吃的、设定千奈节目录像……被指出全是千奈的事，她说身为近侍理所当然（0013–0017）。分支三：她说那既是近侍职责也是个人爱好，会员激增，最近感受到“会員No.9”的分量，宣传千奈的出色也是重要的「お仕え」（0019–0022）。

## 她的关键台词
- 0002「……はい。変更はございません。／何かありましたら、すぐに連絡を。」——工作电话的语气，简短干练。
- 0008「お嬢様の朝のお支度、持ち物の確認、／車の手配、他には……」——近侍的日常职责。
- 0010「苦に思ったことなどありません。／私がやりたくて、やっているのです。」——自愿侍奉。
- 0011「お嬢様にお仕えするのは、氷渡家だから／というだけではありませんよ。」——家族身份之外的个人意志。
- 0015「お嬢様の好物研究、お嬢様が出演される／番組録画設定、お嬢様の……」——列举到全是千奈。
- 0017「お嬢様の近侍ですから、当然です。」——毫不自觉。
- 0020「会員も激増し、近頃は会員No.9の／重みを感じております。」——粉丝俱乐部会员 No.9。
- 0022「お嬢様の素晴らしさを発信すること。／これも重要な『お仕え』です。」——把应援也当作侍奉。

## 行为模式
- 和人在一起时有工作电话 → 先致歉再接，简洁处理（0001–0002）
- 被问自己的工作 → 列举起来停不下，内容都是千奈（0008、0014–0015）
- 被说辛苦 → 否认，强调是自己想做的（0010）

## 关系
- プロデューサー：称呼本篇未出现；向他说明自己在倉本家的职责。
- 千奈：称「お嬢様」；侍奉千奈“不只因为是氷渡家”（0011）。

## 档案类事实
- 在倉本家的职责：千奈早晨梳妆、随身物品确认、安排车辆（0008）；打扫宅邸、铺床、安排会餐、给千奈按摩、研究千奈爱吃的东西、设定千奈出演节目的录像（0014–0015）。
- 氷渡家侍奉倉本家（0011 暗示），但她侍奉千奈也出于自愿（0010–0011）。
- 千奈粉丝俱乐部会员 No.9；把这当作职责也当作个人爱好；会员激增（0019–0020）。制作人听粉丝说对“运营”很满意（0021）。
- 同时兼顾学业（0009，制作人语）。
