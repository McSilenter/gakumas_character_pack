# 氷渡香名江 培育事件 001 activity / 017-02 幻之蜜瓜包（adv_pevent_001_hkne_activity_017-02）

- 她的台词：13 行（含用匿名标签说的 0 行）
- 出场的人：香名江、プロデューサー
- 场景：排队买「幻のメロンパン」（接 017-01）
- 世界线：培育（氷渡香名江）；制作人在制作的偶像：氷渡香名江

## 发生了什么
队伍很长、每人限购一个，她问是不是该放弃（0001–0005）。分支一：她决定继续，买到了，高喊「やりました、お嬢様！」；制作人把自己买的那个给她，说千奈的伴手礼已有，她却没有自己的份，她说只要一半，并小声道谢（0006–0012）。分支二：继续排队但卖完，她引马基雅维利“与其不行动而后悔，不如行动后后悔”，说中途放弃会更后悔，发誓雪耻（0013–0018）。分支三：制作人建议改买「奇跡のチーズケーキ」给千奈，她不甘心地同意，发誓下次为千奈一定买到（0020–0024）。

## 她的关键台词
- 0004「……諦めた方がいいのでしょうか。」——会征求制作人意见。
- 0007「か、買えた……やりました、お嬢様！」——成功时第一个想到千奈。
- 0009「え……この幻のメロンパンは、／あなたが購入したものでは？」——没想到会有自己的份。
- 0011「では、半分だけ……」——接受好意也只拿一半。
- 0012「その……ありがとう、ございます。」——难为情的道谢。
- 0015「……行動せずに後悔するより、／行動して後悔する方が賢明である。」——引用名言（制作人点出是马基雅维利）。
- 0018「ですが、負けっぱなしでは／終わりません。必ず雪辱を果たします。」——好胜。
- 0024「次こそは、お嬢様のために／必ず手に入れてみせます……っ！」——为千奈不服输。

## 行为模式
- 犹豫时 → 先问制作人，然后果断「参りましょう」（0004、0006）
- 被给予只属于自己的东西 → 意外，只取一半，难为情地道谢（0009–0012）
- 失败 → 用历史名言自我开解，并立誓雪耻（0015–0018）

## 关系
- プロデューサー：称「あなた」；他特地为她准备了一份，她别扭地道谢（0009–0012）；他能接住她的引用（0016）。
- 千奈：称「お嬢様」。

## 档案类事实
- 会引用历史人物名言（马基雅维利，0015–0016）。
- 不服输，失败后发誓雪耻（0018、0024）。

## 不确定
- 0006 与 0013 是同一句「承知です、参りましょう。」，分别开启“买到”“卖完”两个分支，属结果分支。
- 0011「半分だけ」是只收下一半还是要和制作人分着吃，剧本未说明。
