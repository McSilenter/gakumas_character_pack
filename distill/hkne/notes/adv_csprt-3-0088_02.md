# S卡 3-0088【思い出の宝箱だ、ね】 / 第2话 偶像的光辉（adv_csprt-3-0088_02）

- 她的台词：5 行（含用匿名标签说的 0 行）
- 出场的人：千奈、広、香名江
- 场景：模仿秀之后，千奈说広要留宿（0003）
- 世界线：S卡 3-0088（同卡 第1话、第2话为一条线）；制作人在制作的偶像：看不出

## 发生了什么
千奈告诉香名江，広要在家里留宿，香名江说可以继续看之前的特训（0001–0004）。広和千奈说模仿之后更懂得了对方的魅力（0005–0010）。香名江说「これがアイドルの輝き」，并托広照顾千奈；広也托她照顾自己，她答应（0011–0015）。広提议下次模仿香名江的可爱之处，千奈说需要成套的衣服（0018–0020）。

## 她的关键台词
- 0004「それなら先ほどの特訓の続きが／また見られそうですね。」——对两人的模仿特训也有兴趣。
- 0011「…………これがアイドルの輝き、／なのですね。」——看着两人，说出自己对偶像光辉的感受。
- 0012「篠澤様。千奈お嬢様を、どうか……／よろしくお願いいたします。」——郑重地把千奈托付给広。
- 0015「お任せください。」——接受広把篠澤広也拜托了。

## 行为模式
- 看到两人相互理解 → 沉默后说出「アイドルの輝き」，然后托付千奈（0011、0012）
- 被托付时 → 简短地回「お任せください」（0015）

## 关系
- 広：称「篠澤様」；把千奈托付给她，也接受她的托付（0012、0014、0015）。
- 千奈：称「千奈お嬢様」「お嬢様」（0002、0012）。
