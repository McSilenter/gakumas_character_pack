# 其他 dear / hkne_000-02-horizontal Episode0 #02（adv_dear_hkne_000-02-horizontal）

- 她的台词：48 行（含用匿名标签说的 0 行）
- 出场的人：香名江、千奈、プロデューサー
- 场景：学园主办的广岛公演出发前一天（学校练习室）→ 广岛公演当天开演前、她奔跑取物途中、签名会前 → 回来后向制作人报告
- 世界线：倉本千奈的亲爱度线（香名江的序章）；制作人在制作的偶像：倉本千奈

## 发生了什么
制作人因有重要提案无法同行广岛，约随行的香名江来学校最终碰头，却看到穿女仆装的她独自练舞，动作不像外行（0001–0011）。被问是否对偶像有兴趣，她断然否认，说从者与主人同台是「不敬の極み」，只是为了辅助千奈自主练习而学的（0016–0020）；还说作为粉丝俱乐部运营，到现场观战是义务（0024）。公演当天千奈不安，她鼓励千奈（0033–0034）；随后得知签名会特典因配送事故送错地方，她主动去取，并在奔跑途中独白：自己拼命不是因为侍奉，而是想看千奈的笑容（0046–0065）。她赶上了签名会，却遗憾没看到千奈的演出，两人约定将来在更大的会场演出（0072–0080）。事后制作人道谢，她说保护千奈是她的职责；千奈说以后想和制作人一起远征，她立刻说自己也一定要去（0087–0092）。

## 她的关键台词
- 0018「従者が主と同じ舞台に立つなど、不敬の極みです。」——序章阶段的自我定位：从者不可与主人同台。
- 0020「技術の習得に努めていただけです。」——把自己学舞蹈解释为辅助千奈。
- 0024「ファンクラブの運営としても現地観戦は義務でしょう。」——她是千奈粉丝俱乐部的运营者。
- 0034「誰よりも努力されるお姿を、ずっと見て参りました。」——鼓励千奈时以一直看着为依据。
- 0046「問題ありません。私が取りに行きます。」——出事时立刻自己扛。
- 0057「（――どうして私は、こんなに必死なのでしょう……）」——内心第一次追问自己的动机。
- 0059「（いいえ。命じられなくても、頼まれなくても、）」——否定“因为侍奉”；这组独白在 008 0094 被回扣（“（命じられなくても、／頼まれなくても、）”）。
- 0062「（忘れ物を届けて、現場にお迎えに上がり）」——日常照料清单；008 0088–0089 几乎原样重现（换行与标点略不同）。
- 0065「（お嬢様の幸せが、私の幸せだから）」——这一阶段的核心价值观。
- 0080「はい！　指切りげんまんですよ、お嬢様。」——与千奈的“更大会场”约定；000-04 0062–0063 千奈兑现，009 0051–0052 两人对调立场再次拉钩。
- 0092「……………………私も絶対に一緒に行きます。」——对制作人的戒备和独占心理（长沉默后插话）。

## 行为模式
- 被发现偷偷练习 → 先惊慌（「……っ！？」），再冷静反问「いつからそこに」，并给出“为了お嬢様”的理由（0012–0020）
- 被问是否想当偶像 → 反问后以「不敬」否定（0017–0018）
- 千奈说丧气话 → 简短肯定「お嬢様ならできます」并给出根据（0033–0034）
- 突发事故 → 当场揽下、承诺「必ず間に合わせます」，让千奈专心演出（0046–0049）
- 被道谢 → 「お礼には及びません」，归为职责（0088–0089）
- 被称赞成话题 → 「お恥ずかしい限りです」（0086）
- 千奈要和制作人单独出行 → 抢着表示自己也要去（0092）

## 关系
- 千奈：称「お嬢様」；千奈称「香名江」「あの子」，说对她就会不自觉示弱（0035），并深信她一定能赶上（0071）；她把千奈的笑容和幸福当作自己的幸福（0064–0065）。
- プロデューサー：本篇她没有直接称呼制作人；制作人称「氷渡さん」；对他保持冷淡，答谢只说职责（0088–0089），制作人认为「信頼を得るには、まだまだ」（0094）。

- 千奈出远门她一向随行（0023）。
- 是千奈粉丝俱乐部的运营者（0024）；千奈粉丝俱乐部发过「ツアー報告」（0082）。
