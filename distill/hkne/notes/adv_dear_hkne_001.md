# 氷渡香名江 亲爱度剧情 / 第1话（adv_dear_hkne_001）

- 她的台词：22 行（含用匿名标签说的 0 行）；其中 0015、0017、0023、0049–0050 是千奈叙述中插入的回想
- 出场的人：千奈、プロデューサー、香名江、倉本爺
- 场景：初星学园，寒假的某一天（千奈找制作人商量）→ 制作人约见香名江 → 拜访倉本爺 → 转入考试合格后
- 世界线：氷渡香名江的亲爱度（接在千奈的线之后）；制作人在制作的偶像：倉本千奈，本篇开始同时制作氷渡香名江

## 发生了什么
千奈请制作人让香名江转入偶像科：香名江其实对偶像兴致勃勃（跳舞很好、看到衣装两眼发光、做家务时哼歌），只是自己没察觉；而如果千奈下命令，她会照做，那就成了女仆的工作（0003–0028）。制作人也早想让她当偶像（0030–0033）。千奈讲出香名江的献身：中学三年夏天帮零合格率的千奈特训，自己却因此没准备倉本系列校的特待选考论文，以及小时候向祖父「直訴」等（0045–0052）。制作人约见香名江，提议她参加偶像科转入考试，并以“对千奈有利”的名义说服倉本爺（0060–0071）。香名江说当年也犹豫过追随千奈进初星普通科，但选了一族的人上的学校；她以一生支持千奈为由，决心「不退転」地通过考试（0073–0082）。合格后制作人提出负责她，她质问「なぜですか」，只同意「期間限定」、要把制作人的知见全部夺过来，并附条件：若因她怠慢千奈，就报告大旦那様（0087–0095）。

## 她的关键台词
- 0015「わぁ♪　ふりふりが可愛いっ。／お嬢様、お姫様みたいです……！」——（回想）看到衣装时的雀跃。
- 0017「ひとつの夢～♪／叶うまで負けない～♪」——（回想）做家务时哼歌；004 0070 她在舞台试音时唱的也是「ひとつの夢～」。
- 0049「――特待選考ですか？／少々、段取りを誤ってしまいまして。」——（回想）把为千奈牺牲轻描淡写成自己失误。
- 0073「ええ。お嬢様を追って、初星学園の／普通科に入るか迷いましたが……」——升学时的抉择。
- 0074「従者の心得を学ぶため、／一族の者が通う学校を選びました。」——就读倉本系列高中的理由。
- 0081「生涯に亘り、お嬢様を支えると／心に誓っておりますので。」——接受转入的唯一理由。
- 0082「不退転の覚悟で、／転入を認めさせてみせます。」——决心强，用词硬。
- 0087「……あなたが、私を？／なぜですか。」——对制作人负责自己的怀疑。
- 0089「……期間限定でしたら、構いません。／あなたの知見、すべて奪ったところで、／完了とさせてもらいます。」——把被制作当作“夺取知见”的手段。
- 0092「倉本の大旦那様へ報告し、／相応の処置を求めます。」——以倉本家为后盾施压。
- 0095「すべてはお嬢様のため。くれぐれも／勘違いのないように、プロデューサー。」——划清界限；句式与 000-01 第 14 行“くれぐれも粗相のないよう”相呼应。

## 行为模式
- 被突然提议转入偶像科 → 先吃惊（「藪から棒に」），再按能否更近地支援千奈来判断，很快接受（0063、0078–0079）
- 为千奈做出牺牲 → 事后轻描淡写成自己的失误，转而祝贺千奈（0049–0050）
- 接受制作人负责 → 设定期限和条件、搬出大旦那様，确保千奈不受影响（0089–0092）
- 对制作人的好意 → 强调「すべてはお嬢様のため」，防止对方误会（0095）

## 关系
- 千奈：称「お嬢様」；千奈称她「香名江」「あの子」「メイドの『氷渡香名江』」，想报恩、想让她拥有自己的梦，说「香名江だけは、特別」（0042、0054–0056）；千奈说自己能遇到制作人也多亏她（0043）。
- プロデューサー：称「プロデューサー」「あなた」；制作人称「氷渡さん」；接受其制作但不信任，设条件监督（0087–0095）；制作人自评「信頼もされていない」（0097）。
- 倉本爺（大旦那様）：称她「氷渡の娘」（0066）；她以向「倉本の大旦那様」报告来约束制作人（0092）。
- 両親：对她转入为了千奈而欣然同意（0085）。

## 档案类事实
- 氷渡一族世代侍奉倉本家，但不是强制的，她可以自由选择（0041）。
- 中学三年夏天，千奈立志进偶像科时合格率为零，她不顾自己帮千奈做考试特训（0045–0046）。
- 她选择升入能学执事实务的倉本系列校；因花太多时间在千奈身上，没能准备特待选考的论文（0047–0048）。
- 千奈入学后她仍把自己的事放在第二位；千奈小时候「お爺様への直訴」时她就帮过千奈（0051–0052）。
- 曾犹豫过追随千奈进初星学园普通科，最后选了「一族の者が通う学校」（0073–0074）。
- 转入考试任何时候任何人都可挑战，但合格者稀少；她靠自己通过（0035、0083）。
- 3学期起成为偶像科学生（0084）。
- 父母对转入欣然同意（0085）。
- 对衣装会两眼发光，做家务时会哼歌（0014–0017）。
