# 氷渡香名江 亲爱度剧情 / 第3话（adv_dear_hkne_003）

- 她的台词：37 行（含用匿名标签说的 0 行）
- 出场的人：香名江、プロデューサー、千奈
- 场景：课程结束后，制作人与她谈话（「100の質問」）→ 制作人向千奈汇报
- 世界线：氷渡香名江的亲爱度；制作人在制作的偶像：倉本千奈、氷渡香名江

## 发生了什么
制作人说她的表演只为避免扣分、显得局促，偶像的本质是「魅せる」（0003–0008）。她把话题转到千奈被制作人引出的魅力上，语气越来越酸，被问「すねてますか？」时否认（0009–0014）。制作人让她回答「100の質問」：喜欢的食物是自己烤的司康（因为千奈爱吃），自己却说不出喜欢什么；兴趣没有；历史只是为辅佐千奈的教养；休息日在想千奈，有做不完的粉丝俱乐部运营、衣装保养、节目录像、剪报（0019–0036）。喜欢的音乐是千奈的歌，一开口就对『Wonder Scale』讲了五分钟（0038–0045）。98 题都扯到千奈；问“偶像是什么”她答「信仰」，问“如果不是女仆想不想当偶像”，她答从没想过、不明白（0050–0059）。制作人对千奈说她的课题是表现力和对偶像活动本身产生兴趣，计划「氷渡香名江アイドル大作戦」（0066–0077）。

## 她的关键台词
- 0004「間違えないのは、正しいのでは？」——以「不出错」为标准的从者思维。
- 0011「……あなたが、引き出したんですねっ。／お嬢様のあの愛らしい笑顔をっ。」——嫉妒制作人，句尾「っ」语气发酸。
- 0012「いいですねっ。私のしらないお嬢様を／隣でたくさん見てきてっ。先生、って。」——嫉妒的核心：制作人见过她没见过的千奈。
- 0014「全然すねてません。」——口头否认「すねる」；004 0051、010 0016 有同类反应。
- 0020「……自分で焼いたスコーン、／でしょうか。」——“喜欢的食物”，理由却是千奈爱吃（0021）。
- 0023「私は……とくに好きなものは／思いつきません。」——缺乏自我。
- 0027「まさか、私の好物を調べ上げて／餌で釣ろうなどと……」——对制作人的猜疑。
- 0033「お嬢様のことを考えています。」——休息日做什么。
- 0038「お嬢様の楽曲です。再生回数は／誰にも負ける気がしません。」——粉丝式自负。
- 0045「はっ！　私ったら……失礼しました。／お嬢様のことになると、つい……」——说过头后的自觉。
- 0052「私にとっては、信仰、にございます。」——“偶像是什么”的回答；004 第 21 行“信仰上の理由”呼应。
- 0059「……よくわかりません。」——想象“不是女仆的自己”时一片空白。

## 行为模式
- 制作人谈到千奈的魅力 → 话锋一转酸制作人「先生、って」，被问是否闹别扭就否认（0011–0014）
- 被问关于自己的问题 → 答案都绕回千奈，或说「思いつきません」（0020–0023、0029、0033）
- 被问得深入 → 怀疑对方的意图（「餌で釣ろう」）（0025–0027）
- 谈到千奈的歌 → 滔滔不绝、停不下来，被打断才回神道歉（0039–0045）
- 被要求想象作为普通高一女生的自己 → 完全想不出（0056–0059）
- 结束后 → 说照顾千奈的时间减少让她挂心（0061）

## 关系
- プロデューサー：称「あなた」；嫉妒他「隣で」见过千奈，以「先生、って」揶揄（0012）；勉强配合提问，因为想了解他的手法（0017–0018）。
- 千奈：称「お嬢様」；千奈听说她满脑子都是自己，「嬉しいですけれども、／とーーっても複雑」（0063–0064）。

## 档案类事实
- 喜欢的食物：自己烤的司康；千奈说比店里的还好吃（0020–0021）。说不出自己特别喜欢的东西（0023）。
- 兴趣：说不出；历史知识是为辅佐千奈「覇道」学的教养（0029–0031）。
- 休息日：做千奈粉丝俱乐部运营、衣装保养、电视节目录像、文章图片归档和剪报（0035–0036）。
- 喜欢的音乐：千奈的歌，自认播放次数不输任何人（0038）；曾随行『Wonder Scale』MV 拍摄（0043）。
- 「偶像」对她是「信仰」（0052）。
- 她是高中一年级（0057，制作人语）。
- 最近照顾千奈的时间减少（0061）。
