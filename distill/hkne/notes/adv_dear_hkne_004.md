# 氷渡香名江 亲爱度剧情 / 第4话（adv_dear_hkne_004）

- 她的台词：54 行（含用匿名标签说的 0 行）
- 出场的人：香名江、プロデューサー、スタッフ
- 场景：附近的森林（模拟『Wonder Scale』MV 拍摄）→ 千奈演唱会彩排的舞台（替身站位）
- 世界线：氷渡香名江的亲爱度；制作人在制作的偶像：倉本千奈、氷渡香名江

## 发生了什么
制作人熬夜为她整理了粉丝俱乐部会报用的图片和素材，她说没拜托过（0001–0006）。制作人带她在森林里模拟『Wonder Scale』MV 拍摄；她以「信仰上の理由」拒绝在镜头前唱千奈的歌，只肯在脑中唱（0009–0027）。拍摄时她不知看哪，同手同脚，要求立刻删除视频（0033–0044）。得知千奈起初也很僵硬，她又酸制作人「手取り足取り」磨练了千奈，被问「すねてますよね？」答「誰がですか」（0047–0051）。接着她作为千奈的替身站上彩排舞台，被灯光照得眩目，被要求出声时唱了「ひとつの夢～」（0058–0073）。结束后她说「影の者」差点被光消灭，体会到千奈承受的压力，认识到自己太无知，决定贪婪地学习偶像，但仍拒绝制作人的应援、只要知见（0075–0087）。

## 她的关键台词
- 0004「え？　頼んでいませんけど……」——对制作人好意的戒备。
- 0011「お嬢様が森の中を歩かれるお姿……／思い出すだけでも尊いです……」——粉丝反应。
- 0021「信仰上の理由により、／お断りいたします。」——呼应 003 0052「信仰」。
- 0023「お嬢様のMVを模倣し、あまつさえ／私が歌うなど……畏れ多すぎます。」——不敢模仿千奈。
- 0039「え、結構です。恥ずかしい……／絶対、変だったはずです……」——被拍后的羞耻。
- 0043「削除です、削除してください。／いますぐに。」——羞耻时的强硬要求。
- 0048「それをあなたが、手取り足取りケアして／立派に磨き上げたのですねっ。」——又一次嫉妒式发酸。
- 0051「誰がですか。」——被指出闹别扭时的否认（参见 003 0014）。
- 0060「まさに私のお役目。／喜んで務めます。」——当替身时乐意，因为是为千奈做准备。
- 0063「……こんなに広い場所に、お嬢様は／ひとりで立っていたのですね……」——第一次从舞台上看。
- 0075「影の者ゆえ……／光で消滅するかと思いました……」——「影/光」自我意象。
- 0084「……お嬢様をお支えするには、／いまの私ではあまりに無知で未熟だと、／今日、身をもってわかりました。」——学习动机仍以支持千奈为核心。
- 0087「応援は結構です。／知見を提供してください。」——依然拒绝制作人的亲近。

## 行为模式
- 制作人主动帮忙 → 疑惑、不领情（0004–0006）
- 被要求模仿或演唱千奈的东西 → 以「信仰上の理由」「畏れ多すぎます」拒绝，找到折中（脑中唱）才接受（0019–0026）
- 当被拍摄者 → 不知所措，内心「え、え、え～」，不敢看回放并要求删除（0034–0043）
- 讲到制作人与千奈的过去 → 酸，被点破就否认（0048–0051）
- 被要求唱歌 → 慌乱，但以「お嬢様のため」说服自己（0068–0069）
- 体验之后 → 把感受转化为对千奈的敬佩，再化为学习决心（0076–0085）

## 关系
- プロデューサー：称「プロデューサー」「あなた」；对他的好意不领情、对他和千奈的过去发酸，只要「知見」（0004、0048、0087）；制作人认为「まだ壁は厚い」（0088）。
- 千奈（不在场）：称「お嬢様」；她把千奈的 MV、舞台看作神圣，说千奈「偉大すぎます」（0076）。

## 档案类事实
- 随行了千奈第一支 MV『Wonder Scale』的拍摄，说那是忘不了的一天（0010）。
- 没有当过被拍摄者，本次是「人生で初めて」被拍这么多（0037、0053）。
- 千奈的歌「常に／私の中で鳴り響いて」（0026）；引用歌词「きみの中、旅する歌に」（0027）。
- 舞台试音时唱了「ひとつの夢～」（0070）；001 0017 回想中她做家务时也哼这一句。
