# 倉本千奈 亲爱度剧情 / 第34话（adv_dear_kcna_034）

- 她的台词：4 行（含用匿名标签说的 0 行）
- 出场的人：千奈、プロデューサー、香名江
- 场景：比赛当天早上，千奈出门前的梳妆（0001～0018），之后制作人来接（0019）；比赛是冬季『H.I.F』（篇中没直接说名称，从「勝つところを」0018、「優勝候補」0061 和她 Episode0 #04 的对应场面看是『H.I.F』当天）
- 世界线：倉本千奈的亲爱度线（她的过去）；制作人在制作的偶像：倉本千奈

## 发生了什么
大赛当天早上，香名江为千奈做出门前的梳妆，千奈道谢，香名江说能以非专业造型师的身份负责这么重要的日子的晨间准备，是她的光荣（0001～0004）。千奈说正因为是重要的日子才要交给最能让自己安心的人，并说“和你一起度过的早晨，是我闪闪发光的武器”（0005～0013）。香名江被说得心慌，请千奈别让她动摇、手会不稳（0015）。千奈说已为“家人”准备了最好的座位，要她在身边见证自己获胜（0016～0018）。之后制作人来接千奈，两人做『ふにゃっ／きりっ』切换练习，香名江不再出场。

## 她的关键台词
- 0001「――さ。お待たせしましたお嬢様。／あとは仕上げだけです。」——亲手为千奈梳妆，日常侍奉的场面。
- 0003「……光栄でございます。／今日はお嬢様にとって大切な日。」——被道谢时以「光栄」回应，把服侍当作荣誉。
- 0004「プロのスタイリストでもない私が、朝の／お支度を担当させていただけるなんて。」——自我定位谦卑，同时流露出被信任的喜悦。
- 0015「もう、あまり動揺させないでください。／手元がくるってしまいます。」——被千奈直白的感情打动时的反应：带点嗔怪地承认动摇。

## 行为模式
- 被千奈道谢 → 以「光栄でございます」作答，把服侍当荣誉（0003）
- 被交付重要任务 → 先强调自己并非专业、受之有愧（0004）
- 千奈说出真心的感谢和重视 → 不正面接话，以“别让我动摇、手会抖”的说法掩饰感动（0015）

## 关系
- 千奈：称「お嬢様」（0001、0003）；千奈直呼「香名江」，说她是「一番安心できる人間」（0006），并把她算作「家族」，为她准备了最好的座位（0016～0017）。
- プロデューサー：本篇无交集。

## 档案类事实
- 大赛当天早上由她负责千奈的晨间梳妆，到会场后才交给专业人员（0004、0007～0008）。
- 她不是专业造型师（0004）。
- 千奈把她当家人，并为她准备了观赛的最好座位（0016～0017）。
