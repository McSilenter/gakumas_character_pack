# 氷渡香名江 培育事件 001 activity / 011 两人总是形影不离（adv_pevent_001_hkne_activity_011）

- 她的台词：14 行（含用匿名标签说的 0 行）
- 出场的人：香名江、プロデューサー
- 场景：街上，与制作人同行，遇到一对跑闹的小姐妹
- 世界线：培育（氷渡香名江）；制作人在制作的偶像：氷渡香名江

## 发生了什么
她提醒制作人让开，避免撞到跑过的孩子（0001–0004）。制作人说那是这一带有名的好姐妹，总是妹妹拉着姐姐出去玩；她说只是想起了小时候的自己和千奈，虽然没那样到处跑，但身影重叠（0005–0010）。分支一：制作人说“就是说你们像那对姐妹一样总在一起、很要好”，她慌称没说过那种僭越的话，被他笑后要他收起「薄ら笑い」（0011–0014）。分支二：制作人说妹妹像千奈，她笑着同意，说千奈从小就像太阳；被要求讲趣事，她郑重拒绝，心想这份回忆是自己独有的宝物（0015–0020）。分支三：制作人说照顾妹妹不摔倒的姐姐像她，她沉默后只说「知りません」（0021–0025）。

## 她的关键台词
- 0001「……プロデューサー、／脇に寄ってください。」——注意周围、照应身边的人。
- 0008「少し……幼い頃の私と／お嬢様を思い出しただけです。」——童年就与千奈在一起。
- 0012「そ、そんな畏れ多いことは／言っていません！」——不肯把自己与千奈说成平等的“要好”。
- 0014「～～っ！！　今すぐ！／その薄ら笑いをやめてください！」——被调侃时的激烈反应。
- 0017「お嬢様は、幼い頃からずっと、／太陽のような存在でしたから。」——千奈＝太阳。
- 0019「丁重にお断りいたします。」——敬语式的拒绝。
- 0020「（……この思い出は、／私だけの宝物ですから）」——回忆不与人分享。
- 0025「……知りません。／自分で考えてください。」——被夸体贴时的回避。

## 行为模式
- 走路时 → 留意周围并提醒同行者（0001）
- 被说和千奈“关系好” → 以身份「畏れ多い」否认，被笑就恼（0012–0014）
- 被问私人回忆 → 有礼貌地拒绝，内心珍藏（0019–0020）
- 被夸“看不见处的体贴” → 沉默，然后推开话题（0023–0025）

## 关系
- プロデューサー：称「プロデューサー」；他调侃和夸她时她都以拒绝或回避应对（0014、0019、0025）。
- 千奈：称「お嬢様」；从小在一起，像被拉着走的一方；回忆是「私だけの宝物」（0008–0010、0020）。

## 档案类事实
- 幼时就和千奈在一起，但没有像那对小姐妹那样跑来跑去（0008–0009）。
- 千奈从小就是「太陽のような存在」（0017）。

## 不确定
- 0010「あのふたり」应是指那对姐妹（与自己和千奈重叠）；也可理解为反过来，语义不影响。
