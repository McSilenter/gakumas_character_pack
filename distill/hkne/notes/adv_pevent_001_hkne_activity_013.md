# 氷渡香名江 培育事件 001 activity / 013 拍肩背后的真相（adv_pevent_001_hkne_activity_013）

- 她的台词：14 行（含用匿名标签说的 0 行）
- 出场的人：香名江、プロデューサー
- 场景：看不出具体地点；她追问制作人千奈给他捶肩的事
- 世界线：培育（氷渡香名江）；制作人在制作的偶像：氷渡香名江，曾制作倉本千奈（0002）

## 发生了什么
她问制作人：千奈为答谢制作而提出给他捶肩是不是真的，并追问一次（0001–0005）。分支一：制作人说本想马上让千奈停下，但看着她小手拼命捶就说不出口；她说「わかります」，那副样子是犯规，换作她也说不出（0006–0010）。分支二：制作人说拒绝了，她斥责拒绝千奈的提议是不敬，宣布要从头讲千奈的好，理解之前别想走（0012–0017）。分支三：制作人说想拒绝时千奈露出悲伤眼神；她说没辜负千奈的心意是对的，但不能让千奈做这种事，今后由她连千奈那份一起给他捶，逼他答应（0019–0024）。

## 她的关键台词
- 0003「……肩たたきのお申し出を／いただいたのは本当ですか？」——盘问。
- 0005「……本当、ですか？」——追问的压迫感。
- 0010「あの愛くるしい姿は反則……／同じ立場だったら、私も言えません。」——在“千奈可爱”上与制作人完全一致。
- 0014「……お嬢様の申し出を断るなど、／不敬にもほどがあります！」——接受了不行，拒绝了也不行。
- 0017「全て理解するまで、／帰れると思わないように。」——讲千奈讲到对方懂为止。
- 0021「ですが、お嬢様にそのようなことを／させるわけにはいきません。」——主仆分际。
- 0022「今後はお嬢様の分まで私が／たたきますので、お声がけください。」——自己顶上，替千奈服侍。
- 0024「……また、お嬢様に／肩たたきをさせる気ですか？」——用反问逼人就范。

## 行为模式
- 听说制作人从千奈那里得到特殊待遇 → 先盘问确认（0003、0005）
- 对方被千奈的可爱打动 → 立即共鸣（0008、0010）
- 对方拒绝了千奈的好意 → 认为是不敬，开始长篇说教（0014–0017）
- 千奈要做“不该由主人做”的事 → 自己代劳（0021–0022）

## 关系
- プロデューサー：称「あなた」；本篇里对千奈的看法与他「ここまで意見が一致したのは、／初めて」（0011，制作人内心）；要替千奈给他捶肩（0022）。
- 千奈：称「お嬢様」；她认为不该让千奈做服侍别人的事（0021）。

## 档案类事实
- 千奈曾为答谢制作提出给制作人捶肩（0002–0003、0007）。
