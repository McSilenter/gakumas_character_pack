# 氷渡香名江 培育事件 001 activity / 019 放松身心的野餐（adv_pevent_001_hkne_activity_019）

- 她的台词：13 行（含用匿名标签说的 0 行）
- 出场的人：香名江、プロデューサー
- 场景：户外野餐（午饭），制作人带了便当
- 世界线：培育（氷渡香名江）；制作人在制作的偶像：氷渡香名江，并曾为倉本千奈做便当（0007、0013）

## 发生了什么
她说早说的话她会准备便当，制作人说今天是她的放松日（0001–0003）。分支一：便当是鸡胸、糙米、西兰花、小番茄、猕猴桃，她赞营养均衡；听说千奈也给好评，她心里在意制作人的调味得到千奈好评，说要“全力”品尝他的手艺（0005–0011）。分支二：便当有花式饭团和章鱼香肠，制作人说因为千奈喜欢；她说宅邸里很少做这种，想象千奈的可爱时语气发酸，被问是否闹别扭，否认说也没想过要做（0012–0017）。分支三：制作人准备了あさり先生推荐的限定便当，自己只有饭团；她要来盖子把便当分一半给他，逼他吃（0018–0024）。

## 她的关键台词
- 0002「……言っていただければ、／お弁当くらい用意したのですが。」——习惯由自己准备。
- 0006「驚きました。／完璧な栄養バランスですね。」——用营养管理的眼光评价。
- 0009「（しかも評判だった……と？／プロデューサーの味付けが……？）」——在千奈的口味上较劲。
- 0011「……いいえ、あなたの手料理、／全力で味わいます……っ。」——竞争心转成“研究”。
- 0014「お嬢様が……ちなみにお屋敷では、／あまりこういう料理はお出ししません。」——倉本家的饮食风格。
- 0015「飾りおにぎりに喜ぶお嬢様……／さぞお可愛かったでしょうねっ。」——吃醋时句尾「っ」。
- 0017「すねてませんっ。／作ろうとも思ってませんしっ。」——否认闹别扭，嘴硬。
- 0021「……ふたをください。行儀は／よくないですが、半分に分けます。」——照顾人优先于礼仪。
- 0023「……早く。それとも、／口に直接入れられたいですか？」——强硬式的关心。

## 行为模式
- 有人为她准备东西 → 先说“本该由我准备”（0002）
- 得知制作人的料理受千奈好评 → 心里不服，转为认真品尝研究（0008–0011）
- 想象制作人看到她没见过的千奈 → 语气发酸，被点破就否认「すねてません」（0015–0017）
- 发现对方自己没有份 → 不由分说分一半，用强硬话逼对方接受（0019–0023）

## 关系
- プロデューサー：称「プロデューサー」（内心）「あなた」；在千奈的饮食上视他为对手；也会照顾他，把便当分他一半（0009、0011、0021–0023）。
- 千奈：称「お嬢様」；千奈吃过制作人做的便当并给好评（0007）。
- あさり先生：只在制作人台词中出现（0018）。

## 档案类事实
- 倉本家宅邸很少做花式饭团、章鱼香肠这类料理（0014）。
- 关心营养均衡（0006）。
