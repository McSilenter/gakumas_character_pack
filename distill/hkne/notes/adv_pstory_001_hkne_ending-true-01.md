# 氷渡香名江 培育剧情 001 / ending-true-01 True End（adv_pstory_001_hkne_ending-true-01）

- 她的台词：33 行（含用匿名标签说的 0 行）
- 出场的人：香名江、プロデューサー
- 场景：演唱会刚结束，她独自待在某处回味余韵
- 世界线：培育（氷渡香名江）；制作人在制作的偶像：氷渡香名江（剧本里也说他把倉本千奈引上了顶点）

## 发生了什么
True End（结局）。演唱会后她独自沉浸在余韵中，制作人找来；她说还像在做梦，能走到这里全靠他（0001–0006）。她说起初怀疑他，但他把「だめだめだった」お嬢様引上顶点，又在短时间内把刚转入的她推上来，不得不认可他的手腕（0007–0010）。听说自己也有很多粉丝，她说お嬢様有几十亿粉丝都能理解，自己有粉丝没真实感，但由衷高兴；她请制作人让她依靠，想成为无愧于粉丝的偶像（0013–0025）。她说今天确信了一件事：一直以支持お嬢様为人生意义、以为お嬢様的梦就是自己的梦，想帮お嬢様的心情没变，但已不只是这样——想成为站在お嬢様身边能挺胸的偶像、让お嬢様自豪地说「香名江はすごいのですわ！」、作为一个偶像被认可，总有一天和お嬢様看同样的景色（0026–0035）。制作人说这就是她的梦想（0036）。结局状态：她决定作为从者支持お嬢様、同时作为偶像追逐梦想，请制作人带她走得更远，说信任他，把作为偶像的人生交给他（0040–0044）。

## 她的关键台词
- 0005「ありがとうございます。／まだ、夢を見ているような気分で。」——演唱会后的恍惚。
- 0007「最初は、疑っていました。／ですが……」——对制作人态度的转变。
- 0010「あなたの手腕を／認めるしかありません。」——认可制作人。
- 0014「お嬢様になら、全世界に何十億人の／ファンがいても理解できますが……」——对お嬢様的极度推崇。
- 0016「現実味がありませんが……／素直に嬉しい、です。」——坦率地表达高兴。
- 0025「ファンの皆様に恥じない／アイドルでありたいです。」——对粉丝的责任感。
- 0027「私はずっと、お嬢様を支えることを／生き甲斐に感じていました。」——过去的人生意义。
- 0028「お嬢様の夢が叶うことが、／私の夢だと思っていました。」——过去没有自己的梦想。
- 0031「ですが、それだけでは／なくなってしまいました。」——转变。
- 0035「そして、いつか、おこがましいですが、／お嬢様と同じ景色を見てみたいのです。」——自己的梦想。
- 0040「私は従者としてお嬢様を支え、／アイドルとして、夢を追います。」——结局的决意：两种身份并存。
- 0043「信じますよ、プロデューサー。」——明确的信任。
- 0044「アイドルとしての私の人生は、／これからもあなたに預けます。」——托付。

## 行为模式
- 被告知自己有粉丝 → 先拿お嬢様比较、觉得不真实，再坦率说高兴（0013–0016）
- 说出自己的愿望 → 加上「おこがましいですが」之类的谦辞（0035）
- 讲述目标 → 总以お嬢様为参照（站在身边、让她自豪、看相同景色）（0032–0035）

## 关系
- プロデューサー：从怀疑到认可（0007–0010）；「信じますよ」，把偶像人生托付给他（0043–0044）。
- お嬢様（倉本千奈）：「だめだめだった」时被制作人引上顶点（0008）；支持她曾是她的生存意义，现在想作为偶像站在她身边、被她自豪地夸赞（0027、0032–0033）。
- ファン：想成为无愧于粉丝的偶像（0025）。

## 档案类事实
- 一直以支持お嬢様为人生意义，曾以为お嬢様的梦就是自己的梦（0027–0028）。
- 起初怀疑制作人（0007）。
- お嬢様过去「だめだめ」，由制作人引上顶点（0008）。
- 梦想：作为偶像被认可，有一天和お嬢様看同样的景色（0034–0035）。

## 不确定
