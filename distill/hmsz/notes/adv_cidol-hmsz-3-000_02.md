# P卡 秦谷美鈴【月之龟】 / 第2话 月之龟 第2话（adv_cidol-hmsz-3-000_02）

- 她的台词：21 行（含用匿名标签说的 0 行）
- 出场的人：美鈴、プロデューサー
- 场景：午间，她给制作人送便当（0001～0002）；晴天（制作人 0008）；地点看不出
- 世界线：亲爱度（秦谷美鈴）·P卡；制作人在制作的偶像：秦谷美鈴

## 发生了什么
她给制作人送来今天的便当，制作人说太丰盛会吃胖，她让他多吃。她约制作人下午练习结束后谈新曲的事，制作人惊讶她晴天也去练习——平时她只在阴天练，他天天被训练师们训。她说「お疲れ様です」，又说每天练习也没问题。制作人说她这么积极通常是为了自己方便去干涉别人，她抗议「まるでわたしが、／自分勝手で迷惑な人のようです」。她说只是想唱好新曲，让来 Live 的粉丝有一辈子忘不掉的体验，在他们的人生里留下大大的爪痕，让他们在所有娱乐中一直选秦谷美鈴，迷上她到曾经珍惜的东西都失色——「ささやかで、／可愛らしい願い」。制作人说一点都不小、说法很吓人，别在采访里说，她「……まあ。」。

## 行为模式
- 照顾制作人 → 送丰盛的便当，让他多吃（0002、0005）
- 被指出平时偷懒、让制作人挨骂 → 轻描淡写地说「お疲れ様」，转而说自己每天练也行（0012～0013）
- 被说成“为自己方便去干涉别人” → 抗议，问制作人把她当成什么人（0016～0020）
- 说起对粉丝的愿望 → 用温柔的语气说出很强的独占欲，再说成「ささやか」「可愛らしい」（0021～0028）

## 关系
- プロデューサー：她叫「プロデューサー」，制作人叫她「秦谷さん」。她给他做便当（0002）。制作人说她平时只在阴天练习、他天天被训练师训（制作人 0010～0011），还说她积极时多半是为了干涉别人（制作人 0014～0015）。
- 粉丝：她希望粉丝为她着迷、一直选择她（0022～0027）。

## 档案类事实
- 她给制作人做便当，很丰盛（0002；制作人 0004）
- 她平时只在阴天练习，制作人因此常被训练师们训（制作人 0010～0011）
- 制作人说她以前积极的时候，多是为了自己方便去干涉别人（制作人 0014～0015）
- 她对粉丝的愿望：留下一辈子忘不掉的体验、让他们一直选择她、迷上她（0023～0027）
- 制作人叫她别在采访里这么说（制作人 0029～0030）
