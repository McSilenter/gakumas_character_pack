# P卡 秦谷美鈴【月之龟】 / 第3话 月之龟 第3话（adv_cidol-hmsz-3-000_03）

- 她的台词：22 行（含用匿名标签说的 0 行）
- 出场的人：美鈴、プロデューサー
- 场景：重要 Live 的前一天深夜，制作人打电话给她（0001～0004）
- 世界线：亲爱度（秦谷美鈴）·P卡；制作人在制作的偶像：秦谷美鈴

## 发生了什么
深夜制作人打来电话，说明天是重要的 Live，想聊一聊。她误以为他终于懂了她对他的期待，请他别害羞、说什么烦恼她都会听到最后。制作人问：之前难得积极练习，Live 临近却又开始偷懒，为什么？她说新曲已经能好好唱了，所以决定到 Live 当天悠闲地养精蓄锐。制作人说下次做这种决定当天就要商量，他还以为她瞒着生病或受伤；她郑重道歉，说下次一定商量。她说这很怀念：组合刚成立时，Live 前夜和一个不安睡不着的伙伴聊到深夜，第二天两人一起大迟到，现在是美好的回忆。制作人说被两人放鸽子的那位大概是噩梦，让她挂电话早睡。她说要好好休息，用新曲填满大家的心，道了晚安。

## 行为模式
- 制作人深夜来电 → 先往暧昧的方向误会、调侃（0006～0011）
- 被问为什么又偷懒 → 理直气壮地说已经练好了、要养精蓄锐（0016～0017）
- 被指出让人担心（以为她生病受伤） → 立刻正式道歉、承诺以后商量（0020～0021）
- 想起过去 → 讲组合时代和伙伴的小事，觉得是好回忆（0023～0027）

## 关系
- プロデューサー：她叫「プロデューサー」，两人互用敬语（本篇主要在电话里）。制作人担心她隐瞒伤病（制作人 0019），她认真道歉（0020～0021）。
- 组合时代的伙伴：组合刚成立时，有一个 Live 前夜不安睡不着的伙伴，她陪着聊到深夜，第二天两人一起大迟到（0024～0026）；制作人说还有一个被放鸽子的伙伴（制作人 0028）。

## 档案类事实
- 她练好新曲后，到 Live 前就不再练、悠闲地养精蓄锐（0016～0017）
- 组合刚成立时，Live 前夜她陪一个睡不着的伙伴聊到深夜，第二天两人一起大迟到（0024～0026）
- 制作人要她以后这种决定当天就商量（制作人 0018），她答应了（0021）

## 不确定
- 0025「不安で眠れないという仲間」是谁没点名（组合推测是『SyngUp!』，按前情可能是手毬或燐羽）；0028 制作人说「仲間ふたりに遅刻された人」，即组合至少三人，被放鸽子的那位也没点名。
- 0007～0008：她「わかってくださった」的“期待”是什么，制作人说她「妙な誤解」（0009），剧本没说清楚，是她的玩笑。
