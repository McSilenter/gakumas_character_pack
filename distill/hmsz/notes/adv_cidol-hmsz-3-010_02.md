# P卡 秦谷美鈴【Star-mine】 / 第2话 Star-mine 第2话（adv_cidol-hmsz-3-010_02）

- 她的台词：17 行（含用匿名标签说的 0 行）
- 出场的人：美鈴、星南、佑芽
- 场景：接第1话，学生会的房间
- 世界线：亲爱度（秦谷美鈴）·P卡；制作人在制作的偶像：秦谷美鈴

## 发生了什么
星南说制作人来商量，想让以个人活动为主的她也积累组合实绩。她问用意，星南反问她现在还想重组『SyngUp!』吗；她说「――――いいえ」：她和那孩子约好「一緒にトップアイドルになろう」，三个人朝梦想前进的日子很幸福，但现在她是个人偶像秦谷美鈴，不组组合，重要的伙伴也还是重要的、能在一起。星南说制作人想有机会时办一场『SyngUp!』一夜限定的复活 Live，为此不能让她作为中等部第一组合积累的经验生锈，所以想不时让她组『臨時ユニット』，请正在制作有前途的一年级生的星南帮忙。她说「なんて……あのひとらしい」，猜是想给她惊喜。佑芽说第一次看到她这么开心的表情、她很喜欢制作人吧，她「…………はい。／大好きです」，又说可能和佑芽想的不一样，被佑芽调侃后说只是想让那个人也变得「わたしなしでは生きていけないように」，佑芽「わァ……」。

## 行为模式
- 听到关于自己的安排 → 先问用意（0004）
- 被问要不要重组旧组合 → 明确说不，再说明现在的身份和对伙伴的看法（0007～0012）
- 知道制作人在背后为她着想 → 沉默很久，然后说「あのひとらしい」，露出开心的表情（0017、0025～0027；佑芽 0028～0029）
- 被问喜不喜欢制作人 → 停顿后直接说「大好きです」，再说明“不是你想的那种”，最后说出很重的占有欲（0031～0039）

## 关系
- プロデューサー：她称「プロデューサー」「あのひと」。他想办『SyngUp!』一夜限定复活 Live，为此请星南帮忙让她组临时组合（星南 0014～0024），她说「なんて……あのひとらしい」（0026）、「大好きです」（0032），想让他离不开自己（0039）。
- 『SyngUp!』：三人朝梦想前进的日子很幸福（0009）；她不想重组（0007），但伙伴依然重要（0011～0012）。
- 「あの子」：她和「あの子」约好「一緒にトップアイドルになろう」（0008），没点名。
- 十王星南：转告制作人的想法（星南 0014～0024），说她们的关系很好（星南 0013）。
- 花海佑芽：佑芽说第一次看到她这么开心的表情（佑芽 0028～0029），追问她对制作人的感情（佑芽 0030、0038）。
