# P卡 秦谷美鈴【Superlative】 / 第2话 Superlative 第2话（adv_cidol-hmsz-3-014_02）

- 她的台词：20 行（含用匿名标签说的 0 行）
- 出场的人：プロデューサー、美鈴
- 场景：接第1话，制作人午睡醒来（0001～0004）
- 世界线：亲爱度（秦谷美鈴）·P卡；制作人在制作的偶像：秦谷美鈴

## 发生了什么
制作人醒来，谢她的毯子。她问做了好梦吗，制作人迷迷糊糊地说梦见她在 Live 上唱摇篮曲。她说真是奇怪的梦，又笑他梦见担当偶像，问「わたしに恋してしまったんですか？」；制作人说没问题、别在意，她说他「本当にすげない方」，或者是掩饰害羞。制作人说从梦里得到了 PV 的灵感：连粉丝的梦都能掌握的秦谷美鈴。她说「素敵なフレーズ」，陶醉地说「全人類の夢を掌中に……／宙でまどろむ、上位の存在」，制作人问「邪神ですか？」，她抗议是 PV 形象，说该问清楚他到底怎么看她；但随即笑说『神』这个比喻不错，最好的偶像对粉丝来说和神差不多，就以引人入梦的「かみさま」的心情去唱。

## 她的关键台词
- 0005「どういたしまして。／いい夢は、見られましたか？」——照顾后的问候
- 0013「夢に見るほど担当アイドルを／意識してしまうだなんて。」——调侃
- 0014「もしかして……／わたしに恋してしまったんですか？」——同上
- 0017「本当にすげない方。それとも……／照れ隠しでしょうか。」——被冷淡回应时
- 0019「ふふ……わたしが子守唄を歌っている／映像にするおつもりですか？」——调侃
- 0023「ああ……全人類の夢を掌中に……／宙でまどろむ、上位の存在……」——她的想象
- 0025「PVのイメージ案ですっ！？」——被说成邪神的抗议
- 0027「もう……プロデューサーがわたしを／どう思っているのか、」——不满
- 0030「『神』というのは……良きたとえです。」——接受比喻
- 0031「もっとも素晴らしいアイドルとは、／ファンにとって、」——她的偶像观（前半）
- 0032「それと変わらぬものでしょうから。」——同上（后半）
- 0034「人々を深き夢にいざなう、／かみさまになったつもりで。」——唱法的方向

## 行为模式
- 制作人说梦见她 → 立刻调侃“爱上我了吗”（0013～0014）
- 被冷淡回应 → 说他「すげない」，再替他解释成「照れ隠し」（0017）
- 听到喜欢的方向 → 陶醉地展开宏大的意象（0022～0023）
- 被吐槽 → 先抗议，转念接受，把吐槽变成自己的东西（0025～0034）

## 关系
- プロデューサー：她叫「プロデューサー」，制作人叫她「秦谷さん」。她给他盖毯子（制作人 0004 道谢），调侃他梦见自己是不是爱上她（0014）。制作人想做「ファンの夢さえも掌握する」的秦谷美鈴的 PV（制作人 0021），说她的表达「恐ろし気」（制作人 0026）。

## 档案类事实
- 制作人梦见她在 Live 上唱摇篮曲（制作人 0008）
- PV 的概念：连粉丝的梦都能掌握的秦谷美鈴（制作人 0021）
- 她认为最好的偶像对粉丝来说和神没什么两样（0031～0032）
