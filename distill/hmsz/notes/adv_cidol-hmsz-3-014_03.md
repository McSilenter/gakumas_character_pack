# P卡 秦谷美鈴【Superlative】 / 第3话 Superlative 第3话（adv_cidol-hmsz-3-014_03）

- 她的台词：27 行（含用匿名标签说的 0 行）
- 出场的人：美鈴、プロデューサー
- 场景：上午稍晚，制作人找到她（0001～0003）；之后两人边走边谈，去录音室（0029～0030）
- 世界线：亲爱度（秦谷美鈴）·P卡；制作人在制作的偶像：秦谷美鈴

## 发生了什么
制作人找到她，交给她完成的 PV；她看了说超出想象，这样就能把粉丝的梦变成自己的。制作人说 PV 发表当天有一场 talk show，她说「面倒なお仕事」，制作人说她的父母也会来。她问他是不是认识自己的父母，制作人说签约当天就去见过了，作为制作人是理所当然的；她说做到这一步的只有他，「好ましいような……恐ろしいような」，然后提议趁机来个「両家の顔合わせ」，说自己正在和制作人的家人商量这件事——「担当アイドルとして、当然のことです」。制作人说可怕、绝对不是理所当然，她原话奉还。制作人说她总是超出预料，「やりたい放題」「欲望に忠実」，她说被夸了很高兴。制作人带她去录音室录新歌来提高 PV 完成度，说投入工作把别的都忘掉吧；她说他想让她发泄欲望，但「抱いた望みは……／すべて叶えなくては」，秦谷美鈴很贪心，想要的一定到手，要用他给的形象把大家的梦变成自己的——「最初の犠牲者は……／あなたですよ」，今夜梦里见。

## 行为模式
- 拿到满意的成果 → 坦率地说超出想象，马上联想到“把粉丝的梦变成我的”（0006～0007）
- 被安排麻烦的工作 → 先说「面倒」（0009）
- 得知制作人背后做了超出常理的事 → 先说“又高兴又害怕”，再做出更出格的事回敬，并用他的原话「当然のこと」（0015～0023）
- 被说“为所欲为、忠于欲望” → 当成夸奖（0027～0028）
- 制作人想让她“忘掉别的” → 拒绝，强调愿望要全部实现，自称「強欲」（0035～0041）

## 关系
- プロデューサー：她叫「プロデューサー」「あなた」，制作人叫她「秦谷さん」。制作人签约当天就去见了她的父母（制作人 0013），她说「好ましいような……恐ろしいような」（0016），并说正在和他的家人商量「両家の顔合わせ」（0018；0020 说在和他的家人商量）。他说她「やりたい放題」「欲望に忠実」（制作人 0027），她说他是第一个“牺牲者”（0042）。
- 她的父母：会来 talk show（制作人 0010），制作人签约当天见过（制作人 0013）。
- 制作人的家人：她说正在和他们商量（0020）。

## 档案类事实
- 制作人在和她签约的当天就去见了她的父母（制作人 0013）
- 她之前不知道制作人见过她父母（0011～0012）
- 她提议「両家の顔合わせ」（0018），说正在和制作人的家人商量（0020）
- PV 发表当天有 talk show，她的父母会来（制作人 0008～0010）
- 她自称「強欲」，抱持的愿望要全部实现（0037、0039）
- 为提高 PV 完成度去录音室录新歌（制作人 0030～0031）

## 不确定
- 0018「両家の顔合わせ」、0020「そういう相談を進めている」：是认真的还是玩笑，剧本没交代；制作人当真吓到（0019、0021、0024）。和亲爱度第27话 0029 她说调查过制作人的兄弟姐妹可以对照，但两者是否有关剧本没写。
- 0013 制作人签约当天见过她父母：亲爱度第35话 0041 制作人说『あなたのご両親から習ったんです』，可能与此有关，剧本没把两处连起来。
