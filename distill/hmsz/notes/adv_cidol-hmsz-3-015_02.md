# P卡 秦谷美鈴【ENDLESS DANCE】 / 第2话 ENDLESS DANCE 第2话（adv_cidol-hmsz-3-015_02）

- 她的台词：28 行（含用匿名标签说的 0 行）
- 出场的人：美鈴、プロデューサー
- 场景：接第1话的访谈，制作人接着问她对十王星南的看法（0001）；地点看不出
- 世界线：亲爱度（秦谷美鈴）·P卡；制作人在制作的偶像：秦谷美鈴

## 发生了什么
制作人问她怎么看十王星南，她先“找个借口”：她对『先輩』这个词印象不好，因为她们在中等部太显眼，一些学姐看不顺眼，当时也有过讨厌的事（0002～0006）。制作人说想到内部升学组至今还怕『SyngUp!』，就不敢听往事，她说那就下次再讲（0008～0009）。她承认春天时的自己轻视包括星南会长在内的所有高年级生，进学生会后反省了，大家都是可爱、迷人、有看头的学姐（0009～0013）。说到『一番星』，她说要超越有点难；她说星南每天都在变成更出色的偶像，最近把自己的人格魅力放进了 Live（0015～0020）。她说星南本人说是在观察、参考周围的偶像，但她的印象不同：闭上眼能在星南身上看到无数初星偶像的光芒，其中有她、佑芽、历代『一番星』，也浓浓地混着賀陽継（0023～0033）。星南为什么能做到她不感兴趣，只觉得高兴；如果能打败这样的星南、亲手粉碎『一番星』的继承者，心情会非常畅快（0028～0036）。制作人心里觉得可怕又斗志高涨，她说很期待下次和星南共演（0037～0039）。

## 她的关键台词
- 0003「わたし、『先輩』という言葉に、あまり／良いイメージがなかったんです。」——对学姐学长的旧印象
- 0004「わたしたち……中等部では、よくも／悪くも、目立っていましたから。」——中等部时期『SyngUp!』很显眼
- 0006「当時は、嫌なこともありました。」——中等部时受过学姐的排挤，轻描淡写带过
- 0009「では、またの機会に。そういうわけ／なので……春ごろのわたしは、」——制作人说怕听，她就顺势不讲
- 0010「星南会長に限らず、上級生全体を／低く見ていたところがあります。」——坦白以前轻视高年级生
- 0012「ええ……本当に。生徒会に入って、／失礼な考えを反省したんです。」——进学生会后改观
- 0015「……追い抜くのは、／ちょっぴり大変そうです。」——对『一番星』的评价（制作人理解为她标准下的极高夸奖，0016）
- 0026「無数の初星アイドルたちの輝きが、／あの方の中に見えるんです。」——她眼中的星南
- 0029「興味はありません。／ただ、嬉しく思います。」——不关心原因，只为有更强的对手高兴
- 0033「賀陽継さんも……色濃く混ざっていて。」——星南身上有継的影子
- 0035「『一番星』を受け継ぐものを／この手で砕いてしまえたなら。」——好胜、带攻击性的一面
- 0036「とても……／清々しい気持ちになれそうです。」——同上，用很平静的语气说

## 行为模式
- 被问到别人 → 先“找借口”交代自己的立场和过去的偏见，再说正面评价（0002～0013）
- 对方表示不想听沉重的往事 → 立刻收住，「またの機会に」（0009）
- 夸强者时用很克制的说法（「ちょっぴり大変そう」），实际评价极高（0015、0016 制作人）
- 对手变强 → 不追究原因，只觉得高兴，并想象亲手打败对方的快感（0028～0036）
- 说可怕的话时语气平静温和，制作人听了害怕（0034～0037）

## 关系
- 十王星南：她叫「星南会長」「あの方」，也直呼「十王星南」（0010、0017、0031）。春天时也轻视她，进学生会后改观（0010～0012）；觉得她每天都在变强，最近把人格魅力放进 Live（0017、0020）；把她看成初星偶像的“群体”，想亲手打败她（0031～0036）；期待下次共演（0039）。
- 学生会的学姐们：她说都是「可愛らしくて、魅力的で……／見所のある先輩ばかり」（0013）。
- 中等部时的「一部の先輩方」：看『SyngUp!』不顺眼，当时有过讨厌的事（0005～0006）。
- 倉本千奈、姫崎莉波：她直呼全名，举作星南参考的偶像（0021）。
- 花海佑芽：「佑芽さん」，她说星南的光芒里也有佑芽（0032）。
- 賀陽継：她叫「賀陽継さん」，说星南身上浓浓地混着継（0033）。
- プロデューサー：他叫她「秦谷さん」（0030）；他说她不喜欢胜负（0030），她没有正面回应，转而说想打败星南。
