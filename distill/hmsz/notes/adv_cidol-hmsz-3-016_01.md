# P卡 秦谷美鈴【VEIL】 / 第1话 VEIL 第1话（adv_cidol-hmsz-3-016_01）

- 她的台词：21 行（含用匿名标签说的 0 行）
- 出场的人：美鈴、プロデューサー
- 场景：夏季『H.I.F』临近（0001），她正在“自主休养”（逃课休息）中（制作人 0005）；地点看不出
- 世界线：亲爱度（秦谷美鈴）·P卡；制作人在制作的偶像：秦谷美鈴

## 发生了什么
制作人问她夏季『H.I.F』的练习顺不顺利，她说一如既往，「ご存じのくせに」（0001～0004）。制作人说她现在正在自主休养，训练员照例发来大量「こらっ！」「サボるな」的消息；她说有了她还和别的女性联系，要他删掉联系方式（0005～0009）。制作人说那是工作对象、玩笑归玩笑，她反问「冗談？　なんのことです？」（0010～0012）。制作人提议反正要偷懒，不如一起做新曲的订货资料；她说他强硬、但不讨厌这一点，推测这是秋天以后的新曲（0013～0019）。制作人说不急，要慢慢做，因为这首曲子会成为偶像秦谷美鈴的代名词；她惊讶一向严守日程的制作人会这么说，随即说必须诞生能在偶像业界历史上留下巨大爪痕的至高名曲（0020～0029）。她说既然是为她而作的歌，基本印象是「全宇宙を支配する、夜空の歌」，宣布开始愉快的会议（0031～0034）。

## 她的关键台词
- 0004「ふふ、ご存じのくせに。」——明知道她在偷懒还问
- 0008「わたしというものがありながら、／他の女性と連絡を取り合うなんて。」——借题发挥的“吃醋”
- 0009「連絡先、消しましょう。ね？」——同上，把训练员的催促岔开
- 0012「冗談？　なんのことです？」——不承认是玩笑
- 0014「強引な方。嫌いではありませんよ、／そういうところ。」——对制作人强硬作风的态度
- 0023「いつもスケジュールに厳しい／プロデューサーから、時間を気にしない／なんてお言葉が飛び出すなんて。」——她眼中的制作人
- 0028「アイドル業界の歴史に／大きな爪痕を刻み付けるような――」——野心
- 0031「『秦谷美鈴の代名詞』……／わたしによる、わたしのための楽曲。」——对新曲的期待
- 0033「きらびやかな星々を、広大な銀河を、／全宇宙を支配する、夜空の歌。」——她给新曲的基本印象
- 0034「さぁ……／楽しいミーティングの時間ですよ、／プロデューサー。」——兴致勃勃地主导

## 行为模式
- 被提到逃课、训练员的催促 → 不辩解，转成“你和别的女性联系”的吃醋话岔开（0007～0009）
- 制作人说“玩笑归玩笑” → 装作不是玩笑（0012）
- 被制作人强行拉去做事 → 说他强硬、但不讨厌（0014）
- 听到“为她量身打造的代表曲” → 立刻来劲，说出很大的野心和具体意象，主动开始会议（0026～0034）
- 从时间点推测制作人的安排（0017～0019）

## 关系
- プロデューサー：他叫她「秦谷さん」（0001）。她说他「強引な方」、不讨厌（0014），一向对日程严格（0023）；对他和训练员联系“吃醋”（0008～0009）。
- トレーナー：经常给制作人发消息催她别偷懒（制作人 0006）；她称之为「他の女性」（0008）。

## 档案类事实
- 夏季『H.I.F』临近（制作人 0001）
- 她经常“自主休养”逃练习，训练员常给制作人发消息（制作人 0005～0006）
- 制作人一向对日程严格（0023）
- 制作人要和她一起做新曲的订货资料，这首歌要成为「アイドル・秦谷美鈴の／代名詞」，不急着做（制作人 0016～0025）；不是为夏季『H.I.F』，她推测是秋天以后（0018～0019）
- 她给新曲的基本印象：支配星星、银河、全宇宙的夜空之歌（0033）

## 不确定
- 0012「冗談？」是真不认为是玩笑还是继续开玩笑，看不出。
- 0006 发消息的训练员是谁没交代；0008 她把对方说成「他の女性」，只能看出是女性。
