# P卡 秦谷美鈴【VEIL】 / 第3话 VEIL 第3话（adv_cidol-hmsz-3-016_03）

- 她的台词：21 行（含用匿名标签说的 0 行）
- 出场的人：美鈴、プロデューサー
- 场景：新曲做好后，她唱给制作人听（0001～0003）；地点看不出
- 世界线：亲爱度（秦谷美鈴）·P卡；制作人在制作的偶像：秦谷美鈴

## 发生了什么
她唱完新曲问制作人怎么样，制作人说“没有唱不好的曲子”是真的，高难度的曲子她已经唱到能马上作为新曲发表的完成度（0001～0003）。她说这孩子比想的还淘气，但已经亲近起来了；又说这还不是完成吧，制作人说和秦谷美鈴本人一样（0005～0008）。她问制作人现在的自己实力如何，制作人说放进顶级偶像们激烈竞争的领域也通用；她叹气说「圧倒することは……／できないんですね」，说那样的话差得远，连打哈欠都不行了（0009～0016）。制作人看她并不焦急，说她似乎隐约看到了前方；她说还不知道，也没必要急着看清，现在她该看的只有「となりを走る大切なライバル」，移开视线就是「浮気」（0018～0022）。制作人说这样的姿态很好，不忘初心、不急不躁、「ほどほど」地走向顶点；她说正因为他这么说，她才能安心把自己托付给他，又笑问这份心情也算出轨吗（0023～0026）。制作人说这首支配一切听众的夜空之歌就是秦谷美鈴，迷茫时就唱它；她说一定会，这是和他一起装满梦想与欲望做出的「愛おしい子」，现在还没完成，要一层一层慢慢揭开「ヴェール」（0027～0035）。

## 她的关键台词
- 0005「ふふ、思った以上に／やんちゃな子でしたが……」——把曲子当成孩子
- 0007「ですが、これで完成ではない……／そうでしょう？」——自己先说出“还没完成”
- 0010「いまのわたしの実力は、／どの程度のものでしょうか？」——主动问自己的定位
- 0013「はぁ……圧倒することは……／できないんですね。」——“能通用”不能让她满足，要压倒
- 0016「それでは……とてもとても。／あくびなんて、できません。」——用“没法打哈欠”表示还要努力
- 0020「慌てて目を凝らす必要もないと／思うんです。」——不急于看清前路
- 0021「いま、わたしが見るべきなのは……／となりを走る大切なライバルだけ。」——眼里只有身边的对手
- 0022「目をそらしたら、浮気でしょう？」——用“出轨”比喻对对手的专一
- 0025「そう言ってくれるあなただから……／安心して、わたしを託せます。」——对制作人的信赖
- 0026「ふふ……この気持ちも、／浮気でしょうか？」——同上，带玩笑
- 0032「あなたと共に、夢と欲望を詰め合わせて／作った、愛おしい子。」——对新曲的感情
- 0035「ヴェールを脱いでいきましょう。」——曲名『VEIL』的由来式表达

## 行为模式
- 被评价“能通用” → 不满足，叹气说做不到压倒就不行，自己的标准是压倒（0013、0015 制作人）
- 虽不满但不焦急：不急着看清前路，眼前只专注于对手（0017 制作人、0020～0021）
- 用恋爱词汇（「浮気」）比喻对对手和对制作人的感情，半开玩笑（0022、0026）
- 被制作人肯定“慢慢来” → 表示安心托付（0024～0025）
- 把歌曲拟人为「やんちゃな子」「愛おしい子」（0005、0032）

## 关系
- プロデューサー：他叫她「秦谷さん」（0018）。她主动问他对自己实力的看法（0009～0010）；说正因为他不催她，才能安心托付自己（0025）；新曲是两人一起“装满梦想与欲望”做出来的（0032）。他内心说她不满的样子很像她（0015）。
- 「となりを走る大切なライバル」：她说现在只看这个对手（0021），没点名。

## 档案类事实
- 新曲（秦谷美鈴的代名词、夜空之歌）完成，她很快唱到能发表的完成度（制作人 0002～0003、0027）
- 制作人认为现在的她放进顶级偶像的竞争中也通用，但还不能压倒（制作人 0011～0014）
- 制作人的方针：不忘初心、不急不躁、「ほどほど」地走向顶点（制作人 0024）
- 制作人说迷茫时就唱这首歌，那就是秦谷美鈴（制作人 0028～0029），她答应（0030～0031）

## 不确定
- 0021「となりを走る大切なライバル」没点名；在她的剧情里很可能是手毬，但本篇没说。
- 0035「ヴェール」是比喻新曲的未完成部分，与卡名『VEIL』呼应；曲子正式名称本篇没写。
- 0016「あくびなんて、できません」——是说没空偷懒还是说不能放松，语气上偏玩笑，确切意思难定。
