# P卡 秦谷美鈴【「我要说了哦。」】 / 第1话 「我要说了哦。」 第1话（adv_cidol-hmsz-3-020_01）

- 她的台词：21 行（含用匿名标签说的 0 行）
- 出场的人：美鈴、プロデューサー
- 场景：傍晚，她睡醒（0001～0003）；制作人在一旁看宣传册（0014～0015）；地点看不出
- 世界线：亲爱度（秦谷美鈴）·P卡；制作人在制作的偶像：秦谷美鈴

## 发生了什么
她打着哈欠醒来说“早上好，真是美好的早晨”，制作人说已经快傍晚了；她说不知不觉就到黄昏才是理想的一天（0001～0006）。制作人说这想法对忙碌的人是一种救赎，她高兴地说他渐渐懂了，邀他下个休息日也一起度过；制作人说她最近工作太多，请好好休息，她说能这样美好对话的制作人一定只有他（0007～0013）。她问他刚才在看什么，是南国岛屿的宣传册；她说刚约好休息日就打算丢下担当偶像去旅行，「羨ましいです」（0014～0018）。制作人说她也要去，叫她准备护照，她沉默很久后问「いいのでしょうか」；制作人说日程已经调好，不会是只为工作就回来的匆忙行程（0019～0025）。听到“工作”她愣住：是初星学園和大型服装厂商的大型合作企划，她被选为第一弹（0026～0029）。制作人慌忙说工作后会让她好好休养，她说会进行这么容易误会的对话的制作人一定只有他，「ぷいっ」（0030～0033）。

## 行为模式
- 睡到傍晚 → 不当回事，说“不知不觉到了黄昏”才是理想（0002～0005）
- 制作人认同她的悠闲观 → 高兴，主动约休息日一起过（0008～0009）
- 看到制作人计划旅行 → 撒娇式抱怨被丢下，说羡慕（0016～0018）
- 以为是两人旅行 → 长时间沉默、不敢相信（0022～0023）
- 发现是工作 → 反复确认「仕事？」，然后把刚才夸他的句子改成抱怨，「ぷいっ」地扭头（0026～0033）

## 关系
- プロデューサー：他叫她「秦谷さん」（0003）。她说能和她美好对话的制作人只有他（0012～0013）；邀他休息日一起度过（0009），他答应（0010）；被“工作”骗了一下后闹别扭（0031～0033）。
