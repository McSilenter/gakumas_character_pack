# P卡 秦谷美鈴【「我要说了哦。」】 / 第2话 「我要说了哦。」 第2话（adv_cidol-hmsz-3-020_02）

- 她的台词：22 行（含用匿名标签说的 0 行）
- 出场的人：美鈴、プロデューサー
- 场景：泳装广告拍摄现场，上午的拍摄结束、下午还有（0001～0004）；夏天的海边（0019、0038）
- 世界线：亲爱度（秦谷美鈴）·P卡；制作人在制作的偶像：秦谷美鈴

## 发生了什么
上午拍摄结束，制作人夸她表现好，她问「本当にそう思っていますか？」（0001～0003）。制作人说一定能拍出无可挑剔的泳装广告，她说这次大型合作企划对初星学園很重要，应该有更合适的偶像吧（0004～0006）。制作人愣住，说没想到会对她说“请拿出自信”，她说不是没有自信，只是觉得这次也许有更合适的人（0007～0013）。制作人说没有，正因为她是最好的人选才被选为第一弹；她说对方要的是有清新健康美的偶像，纤细白皙的她形象不符，和夏天的海也不搭（0014～0019）。制作人说完全不是，就算不搭，她也比完全符合要求的偶像更好；她说那只是他太喜欢她了，制作人说不对，「秦谷美鈴は、全宇宙でもっとも／美しいアイドルです」（0020～0026）。她结巴着说他居然能一点不害羞说这种话，制作人说说明 1+1=2 没什么可害羞，世上知道这个真相的人还不多，要由他们来启蒙（0027～0030）。她确认是偶像活动的事后叹气说白害羞了；接着说没想到他这么深地信任她，感觉不坏，看来是自己启蒙不够，说相信他，要用秦谷美鈴的魅力启大家的蒙（0031～0038）。

## 她的关键台词
- 0003「……本当にそう思っていますか？」——少见的不自信
- 0006「もっと……適任のアイドルが／いたのではないでしょうか？」——同上
- 0012「自信がないわけでは……ありません。」——被说“拿出自信”时否认
- 0018「華奢で色白なわたしとは、／イメージが違います。」——对自己外形的认识
- 0019「夏の海との相性も……よくないです。」——同上
- 0023「わたしのことを……／好きすぎるだけです。」——把夸奖归结为制作人偏爱
- 0025「むっ。」——被否定“喜欢她”时不高兴
- 0027「……よ、よくもそんな台詞を……／かけらも照れずに言えますね。」——被直白夸奖时害羞
- 0033「はぁ……恥じらって損をした気分です。」——知道是“工作上的话”后泄气
- 0035「悪くない気分です。」——被深深信任的感受
- 0037「あなたを信じます、プロデューサー。」——接受
- 0038「夏の海が舞台でも……／秦谷美鈴の魅力で、／皆さんの蒙を啓いていきましょう。」——重新振作，接制作人的“启蒙”说法

## 行为模式
- 面对和自己形象不合的工作（清新健康、夏天的海）→ 少见地不自信，说“应该有更合适的人”，但被点破时否认没自信（0003～0013）
- 被夸 → 先归结为“你太喜欢我了”（0022～0023）；被否认后反而「むっ」（0025）
- 被极端直白地夸美 → 结巴、害羞，说对方毫不害臊（0027）
- 发现对方说的是工作 → 叹气说白害羞了，但随后坦率承认被信任的感觉不坏（0033～0035）
- 被信任 → 接过对方的说法（「啓蒙」）表示要用自己的魅力去做（0036～0038）

## 关系
- プロデューサー：他叫她「秦谷さん」（0001）。他说她是最好的人选、比完全符合要求的偶像更好、「全宇宙でもっとも／美しいアイドル」（0016、0021、0026）；她以为是他太喜欢她（0023），后来说没想到他这么深地信任她，「あなたを信じます」（0034、0037）。制作人说没想到会对她说“请拿出自信”（0009～0010）。

## 档案类事实
- 初星学園和大型服装厂商的合作企划第一弹是泳装广告，她被选中（0005；制作人 0004、0016）
- 对方的要求是有清新健康美的偶像（0017）
- 她自认「華奢で色白」，觉得和夏天的海不搭（0018～0019）

## 不确定
- 0009 制作人说的『この台詞』指 0010「自信を持ってください。」——意思是平时她从不缺自信，本篇里她为什么这次没自信，只说了形象不合（0017～0019）。
