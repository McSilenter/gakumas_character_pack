# P卡 月村手毬【究竟从何时起】/第3话 究竟从何时起 第3话（adv_cidol-ttmr-3-016_03）

- 她的台词：16 行（含用匿名标签说的 0 行）
- 出场的人：手毬、美鈴、千奈
- 场景：千奈别墅的特训第一天，晚饭之后（美鈴做了晚饭）
- 世界线：亲爱度（月村手毬）·P卡；制作人在制作的偶像：月村手毬（制作人本篇没有出场），美鈴是配角

## 发生了什么
美鈴问手毬和千奈晚饭怎么样，说晚饭用的是老家寄来的当地食材，手毬说是在美鈴家吃过的味道。美鈴宣布特训期间由自己做饭，理由是要和手毬的制作人对抗，证明自己能做出美味又营养均衡的菜单，也证明自己不是「うっすら邪悪」。手毬说厨艺与性格无关，要用歌证明，并谈到新曲想怎么唱。千奈夸手毬是真正的偶像，美鈴说藐视对手和尊重对手可以并存，被手毬吐槽。千奈夸美鈴也是真正的偶像，美鈴说千奈是第一个让她感到败北感的人。

## 她的关键台词
- 0004「ええ……実家から地元の食材を送って／もらったんです。」——手毬问晚饭是否是她做的，她回答食材来自老家
- 0007「特訓中は、わたしが食事を作ります。／楽しみにしていてください。」——宣布自己负责特训期间的饭
- 0009「まりちゃんのプロデューサーに／対抗するためです。」——说明认真的原因：与手毬的制作人较劲
- 0011「わたしにも美味しくて栄養バランスの／良い献立が作れるというところを。」——要证明自己的料理水平
- 0013「『うっすら邪悪』などではない／ということを。」——把手毬上一话说的评价放在心里，要用料理证明
- 0018「それしかありませんか。」——手毬说“用歌证明”，她短促地确认没有别的办法
- 0020「清々しいメロディでしたね。」——听了手毬的新曲示范后的感想
- 0032「まあ、倉本さん。相手を下に見る／ことと、敬意を払うことは、」——对千奈夸手毬谦虚，提出另一个看法
- 0033「矛盾なく両立するものだと……／そう思いますよ。ね、まりちゃん。」——把自己的价值观说成理所当然，再向手毬求同意
- 0037「……わたしが敗北感を覚えたのは、／あなたがはじめてです。」——直接对千奈承认败北感，并说是第一次

## 行为模式
- 被问到厨艺 → 说食材来自老家，并说自己做得不错（0004、0005）
- 想证明自己 → 把目标说成与手毬的制作人较劲，且要同时证明不“邪恶”（0009～0013）
- 被说“用歌来证明” → 用一句话确认（0018），随后转到听新曲的感想（0019、0020）
- 说出带有强势的价值观 → 向手毬求同意（0033），被手毬吐槽
- 被千奈用不自觉的方式夸奖 → 直接说“败北感”，承认她比自己强（0035～0037）

## 关系
- 手毬：叫「まりちゃん」（0001、0009、0033）；手毬叫「美鈴」（0003、0024）；手毬吃过美鈴家的饭（0006）
- 千奈：叫「倉本さん」（0001、0032）；千奈叫「秦谷さん」（0014、0035）；美鈴说对千奈感到败北感（0037）
- プロデューサー：叫「まりちゃんのプロデューサー」（0009），把他当对抗对象

## 档案类事实
- 美鈴会做饭，做过特训的晚饭（0001～0005）
- 老家会寄当地食材（0004）
- 手毬在美鈴家吃过相同味道的饭（手毬 0006）
- 美鈴介意手毬说过的「うっすら邪悪」（0013、千奈 0014）
- 第一个让美鈴感到败北感的人是千奈（0037）
- 美鈴认为「相手を下に見る」与「敬意を払うこと」可以并存（0032、0033）

## 不确定
- 0017 手毬说「だから歌で証明しよう」，要证明的是美鈴“不邪恶”还是别的，剧本语境不完全明确（手毬笔记同）。
- 0037「敗北感」是对千奈的什么，剧本没写；0038 手毬说「こういうところ、／ちょっと勝てないよね。」，0040 不回答（手毬笔记同样记为不确定）。
- 0032、0033 美鈴“藐视对手”的说法是指她自己的看法还是泛指，剧本没写。
