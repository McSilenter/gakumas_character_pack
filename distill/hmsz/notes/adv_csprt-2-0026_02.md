# S卡 2-0026【ぐつぐつ、いいにおい♪】 / 第2话 明天见（adv_csprt-2-0026_02）

- 她的台词：7 行（含用匿名标签说的 0 行）
- 出场的人：莉波、美鈴
- 场景：厨房，和莉波一起做饭；结束时（0019 莉波「明日は生徒会の集まりもあるし」）
- 世界线：S卡【ぐつぐつ、いいにおい♪】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
莉波让美鈴削土豆皮，自己切洋葱。美鈴削得很快，还挖掉了芽，莉波心里吃惊。美鈴看到洋葱已经切成末，说莉波擅长做饭。莉波问她是不是常做饭，她说和食在老家常做。莉波提议下次一起做和食，请她教，她答应。分完饭后，她说今天很开心，两人说明天见（0001～0020）。

## 她的关键台词
- 0004「め？」——莉波说「じゃがいもは芽を……」时她不明白，反问
- 0007「あ……／みじん切りが、もうこんなに……」——对莉波的速度吃惊
- 0008「莉波先輩は、お料理が得意なんですね。」——夸莉波
- 0011「和食でしたら実家でも／よく作っていたので。」——说明自己的做饭经验
- 0015「ええ、わたしでよければ。」——接受莉波教她做和食的请求
- 0017「ありがとうございます。／今日は楽しかったです。」——把「楽しかった」说出口
- 0020「はい……また明日。」——最后的告别，留一点余韵

## 行为模式
- 看到对方的手艺 → 先吃惊，然后坦率夸奖（0007、0008）
- 被夸 → 用「和食でしたら実家でも／よく作っていたので。」说明，不自夸（0011）
- 被请求教人 → 用「わたしでよければ」答应（0015）
- 结束时 → 明确道谢并说出感受（0017），告别语简短（0020）

## 关系
- 莉波：她称「莉波先輩」，莉波称「美鈴ちゃん」；莉波想和她一起做和食、向她请教（0008、0013、0014）

## 档案类事实
- 她会削土豆皮，也会去芽（0005，莉波的心声；0004 她问「め？」）
- 她在老家常做和食（0011）
- 莉波说明天有生徒会的集会，两人说「また明日」（0019、0020）；她是否也参加没有明说

## 不确定
- 0004「め？」她是不知道要挖芽还是没听清，剧本没写；0005 莉波的心声说她已经取了芽。
- 0019「生徒会の集まり」她是否也参加，莉波没明说，只说「また明日、だね」。
- 无【冲突】。
