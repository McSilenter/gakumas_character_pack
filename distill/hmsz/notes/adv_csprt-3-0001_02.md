# S卡 3-0001【何やってるんだろう、】 / 第2话 手毬的友情状况（adv_csprt-3-0001_02）

- 她的台词：7 行（含用匿名标签说的 0 行）：0001、0002、0006、0009、0015、0019、0020；全部是括号内心话、「！？」或沉默，没有对话
- 出场的人：手毬、美鈴、ことね
- 场景：学校，早上（ことね 0003「はよーっす」手毬 0004「朝から」）；美鈴在远处看着手毬和ことね，听不清她们说话（0015）
- 世界线：S卡【何やってるんだろう、】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
美鈴看到手毬，心想自己和她对上眼的话她会为难。她看到ことね来和手毬打招呼，心想手毬在班上交到朋友了，松了口气。ことね给手毬便当，手毬给ことね钱，美鈴听不清她们在说什么，感到不满。手毬说ことね爱钱，ことね说超喜欢，手毬说「しょうがないやつ」。美鈴沉默一阵后发出「むぅっ」（0001～0020）。

## 她的关键台词
- 0001「（あっ……まりちゃん）」——在远处看到手毬，叫的是「まりちゃん」
- 0002「（……わたしと顔を合わせたら、／きっと……困ってしまいますよね）」——认为自己出现会让手毬为难，所以不上前
- 0006「（……よかった。まりちゃん、／クラスで友達ができたんですね）」——看到手毬在班上有朋友，真心放心
- 0015「（……なにを話しているんでしょう……／むぅぅ……よく……聞こえません）」——想听她们说什么却听不见，表现出在意
- 0020「………………………………むぅっ。」——看到手毬和ことね亲近后的沉默和「むぅっ」，是嫉妒或不满的流露

## 行为模式
- 看到关系不好的手毬 → 不上前，在远处观察，想着不要让对方为难（0001、0002）
- 看到手毬有了新朋友 → 先为她高兴，随后看到两人亲近又不满（0006、0009、0019、0020）
- 在意却听不清时 → 皱着不满，不上前确认（0015）

## 关系
- 手毬：她称「まりちゃん」；她认为自己出现会令手毬为难，也担心手毬在班上有没有朋友（0001、0002、0006）
- ことね：她没和ことね说话；ことね叫手毬「てっまりー」（0003）；她对ことね的反应只有放心和不满（0006、0020）

## 档案类事实
- 她把「クラスで友達ができた」说给自己听，说明她是在远处看着手毬和ことね（0006、0015）；两人是不是同班，本篇没明说

## 不确定
- 0006「クラスで」是不是指美鈴自己所在的班之外的班，剧本没明说；从 0001～0006 的距离感推测。
- 0009「！？」是对手毬给ことね钱的反应，推测而非明写。
- 本篇没有任何她的口头台词，全部是内心话和沉默。
- 无【冲突】。
