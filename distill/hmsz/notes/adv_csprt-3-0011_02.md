# S卡 3-0011【私の目に狂いはない】 / 第2话 难以驾驭的孩子（adv_csprt-3-0011_02）

- 她的台词：7 行（含用匿名标签说的 0 行）：0002、0003、0008、0010、0012、0017、0018（0010 是沉默）
- 出场的人：星南、美鈴
- 场景：没写明（美鈴被星南叫醒，0001），白天
- 世界线：S卡【私の目に狂いはない】；制作人在制作的偶像：看不出（制作人未出场；剧本里是星南自称制作人带着她，0006、0007、0015）

## 发生了什么
星南叫醒睡着的美鈴，美鈴说感觉会长好像在生气。星南说美鈴的实力和潜在能力都没问题，但没看出是这样的孩子，问她当初为什么答应自己的邀请，是不是期待十王星南的制作能力。美鈴否定，沉默，随后说说话很麻烦。星南说不问了，代之以自己作为制作人更努力，直到美鈴愿意主动说。美鈴称「星南会長」，感谢星南对现在的自己的评价（0001～0019）。

## 她的关键台词
- 0002「……ふわ……ぁ…………／まあ、どうしたのですか、会長。」——被叫醒后第一句话就是问「どうしたのですか、会長」，反应平静
- 0003「なんだか、／怒っているような気配がします。」——察觉到星南的不快，凭气氛判断
- 0008「いいえ。そうではなく…………」——被问是不是为了星南的制作能力而答应邀请，直接否认
- 0012「話すのが……面倒です。」——不愿说明原因，理由是「話すのが……面倒です」，直白
- 0017「星南会長。」——在星南说完后，郑重地称「星南会長」，转入致谢
- 0018「いまのわたしを評価してくださった／こと……感謝しております。」——感谢星南评价现在的自己，不提理由，只说感谢

## 行为模式
- 被追问理由而不想说 → 沉默，然后说「面倒です」，不编理由（0010、0012）
- 对方放弃追问并表示会努力 → 郑重道谢（0017、0018）
- 被叫醒 → 先问对方发生什么，并能察觉对方的情绪（0002、0003）

## 关系
- 星南：称「会長」「星南会長」，星南称「美鈴」。星南自称美鈴的制作人，说会为了让她主动开口而继续努力；美鈴对星南的态度是感谢，但不说答应邀请的理由（0006、0007、0015、0016、0018）

## 档案类事实
- 她是星南亲自邀请（スカウト）的人，并答应了（星南 0006）
- 她回答「そうではなく」，答应的理由不是对星南的制作能力的期待（0007～0008）
- 她自己说话「面倒」（0012）

## 不确定
- 0018「いまのわたしを評価してくださった／こと」所指：星南在 0004、0005 说「実力も、潜在能力も、／申し分ない」，这与「いまの」是否对应，本篇没明说。
- 她为什么答应星南的邀请，她没有说。
- 星南以制作人身份带着美鈴；这是星南的角色，玩家制作人在本篇没有出场，看不出玩家制作的是谁。
- 无【冲突】。
