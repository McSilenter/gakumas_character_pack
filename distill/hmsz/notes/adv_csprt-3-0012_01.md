# S卡 3-0012【また、あんなに無理をして】 / 第1话 适当地、迈步前行（adv_csprt-3-0012_01）

- 她的台词：12 行（含用匿名标签说的 0 行）：0003、0005、0006、0007、0008、0009、0011、0014、0015、0017、0019、0021（0003、0006、0008 是括号内心话，0007、0019 是沉默）
- 出场的人：美鈴、佑芽、手毬
- 场景：学校的走廊到舞蹈练习室（0015「ちょうどそこに、／ダンスレッスン室が」）
- 世界线：S卡【また、あんなに無理をして】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
美鈴看到手毬在拼命练习，心想「また、あんなに無理をして」。佑芽问怎么了，美鈴说没事，心里想现在的自己没有阻止手毬的权利，沉默后忽然喊住佑芽，邀她陪自己去自主练习。她说突然想练舞，正好旁边有练习室，进去后发现手毬在里面，手毬哼了一声。美鈴说「ゆっくりと、ほどほどに」，开始练习（0001～0021）。

## 她的关键台词
- 0003「（……まりちゃん。／また、あんなに無理をして……）」——看到手毬拼命练习，称她「まりちゃん」，担心她又勉强自己
- 0006「（そう……いまのわたしに……／彼女を止める権利なんて……）」——认为自己现在没有资格阻止手毬，说明关系已经破裂
- 0008「（んん～～～～～～～～～～～っ！）」——沉默后在内心大喊，下了决心
- 0011「いまから、わたしの自主レッスンに／付きあっていただけますか！？」——突然邀佑芽陪自己自主练习，是为了接近手毬的行动
- 0014「突然、いますぐに、ダンスのお稽古を／したくなりまして……」——给出突然想练舞的借口
- 0015「まあ、ちょうどそこに、／ダンスレッスン室が…………」——说「ちょうどそこに」，借助正好有练习室这个巧合
- 0019「……なにか？」——手毬瞪她时，只问「なにか？」，装作不知
- 0021「……さあ、レッスンをはじめましょう。／ゆっくりと、ほどほどに。」——说「ゆっくりと、ほどほどに」，实际是在对手毬做示范

## 行为模式
- 看到手毬勉强自己 → 不直接去阻止，因为觉得自己没有权利，转而以自己的行动给出另一种做法（0006、0011、0021）
- 临时想出行动时 → 找一个借口（突然想练舞）拉别人配合（0011、0014）
- 被手毬冷待 → 只问「なにか？」，不被激怒（0019）

## 关系
- 手毬：她称「まりちゃん」；手毬看到她时只有冷淡的「ふん」，她仍装作若无其事并在手毬的视线里说「ほどほどに」（0003、0018～0021）
- 佑芽：称「佑芽さん」，佑芽称「美鈴ちゃん」。她把佑芽拉来自主练习（0004、0009～0016）

## 档案类事实
- 她认为现在的自己没有阻止手毬的权利（0006）
- 佑芽对她突然提出自主练习很惊讶（佑芽 0013、0016）

## 不确定
- 0021「ゆっくりと、ほどほどに」是说给佑芽还是说给手毬，剧本没明说。
- 0006「いまのわたしに……／彼女を止める権利なんて」的原因（两人的隔阂）本篇没写。
- 无【冲突】。
