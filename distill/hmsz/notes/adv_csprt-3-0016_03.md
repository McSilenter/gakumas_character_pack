# S卡 3-0016【1人たりとも欠ける事なく】 / 第3话 罪魁祸首是美铃（adv_csprt-3-0016_03）

- 她的台词：3 行（含用匿名标签说的 0 行）：0005、0009、0014
- 出场的人：千奈、広、佑芽、美鈴
- 场景：学校，早上（佑芽 0002「朝から」）
- 世界线：S卡【1人たりとも欠ける事なく】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
千奈向佑芽求救，说班上出了大事。广说犯人是美鈴，美鈴说好像是我。广解释说自从和美鈴要好后，班里的人都变得健康，受伤也少了。美鈴说自己劝大家不要勉强，努力没有白费。但千奈说班上大家的体重都增加了，因为美鈴做的点心太好吃。美鈴为好意带来的结果道歉，佑芽决定启动一年二班减肥计划（0001～0020）。

## 她的关键台词
- 0005「ふふ……はい、わたしみたいです。」——被说是犯人时笑着承认「わたしみたいです」，不辩解
- 0009「皆さんが無理をしないように、／お話しをした甲斐がありました。」——说明自己的做法：为了让大家不要勉强而谈话，「甲斐がありました」
- 0014「よかれと思ってしたことでしたが……／申し訳ありません。」——得知点心让大家变胖，先说是出于好意，再道歉

## 行为模式
- 被当面指为原因 → 笑着承认，没有抵赖（0005）
- 自己的好意造成了麻烦 → 先说原本的好意，然后道歉（0014）

## 关系
- 広：広称她「美鈴」，说她不是错的（広 0015）
- 千奈：千奈称「秦谷さん」，说她的点心太好吃（千奈 0012）
- 佑芽：对她没有直接对话
