# S卡 3-0028【一時休戦です】 / 第2话 久违的感觉（adv_csprt-3-0028_02）

- 她的台词：11 行（含用匿名标签说的 0 行）：0002、0005、0007、0008、0011、0013、0014、0016、0017、0019、0020
- 出场的人：美鈴、手毬
- 场景：地点没写明；标「～一時休戦中～」（0001），手毬穿着泳装（0011），美鈴提到游泳（0016）
- 世界线：S卡【一時休戦です】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
休战期间，美鈴问手毬最近怎么样、早上能不能自己准备。手毬嫌她把自己当小孩，美鈴说「わたしがいなくなったせいで……」，接着说「ふとってしまったんじゃないですか？」，看着穿泳装的手毬指出她胖了。手毬恼火，美鈴说在自己不知道的地方变胖是不允许的，提出用游泳和饮食让她按自己的节奏减肥，一切交给自己。手毬说这种软绵绵的感觉才像在和美鈴说话，美鈴说自己也有久违了和「まりちゃん」说话的感觉（0001～0020）。

## 她的关键台词
- 0002「最近はどうですか？　ちゃんと朝、／ひとりで準備ができていますか？」——休战一开口就是照顾手毬早上起居的口吻
- 0005「まあ……それが本当なら、／どれだけ心が楽になることか。」——手毬说没什么可担心的，她回以不信，带着挖苦
- 0008「ふとってしまったんじゃないですか？」——直接指出手毬胖了
- 0011「水着姿で、言い逃れはできませんよ。」——用眼前的证据堵住对方的狡辩
- 0014「あってはならないことです。」——对在自己不知道的地方变胖断然说不允许
- 0016「水泳と食事で、無理なくマイペースに、／ダイエットしましょう。」——马上给出具体方案
- 0017「すべてわたしに任せてください……／トップアイドルになりたいのなら。」——要手毬全部交给自己，理由是手毬想成为顶级偶像
- 0020「まりちゃんと話してる／って感じがします。」——承认和手毬这样拌嘴久违，是她想要的感觉

## 行为模式
- 手毬说不用你担心 → 不接受，用带刺的话把问题摆到桌面上（0005、0007、0008）
- 被手毬顶嘴说和你没关系 → 不退让，说成「不允许」，不讲理由，随即转成具体的解决方案并要求全权负责（0013、0014、0016、0017）
- 被手毬说这种软绵绵的感觉才像美鈴 → 不辩解，顺着说自己也有同感（0019、0020）

## 关系
- 手毬：她称「まりちゃん」（0020）；手毬称「美鈴」。休战中，她仍像以前一样管着手毬的生活，手毬嫌被当小孩（0003、0004），但没有真的赶她走（0018）

## 档案类事实
- 她认为手毬的体重管理是自己的责任，「わたしの知らないところで／ふとるなんて」不可接受（0013、0014）
- 她以前早上会过问手毬能不能自己准备（0002）
- 她把手毬想成为顶级偶像当作理所当然的前提（0017）

## 不确定
- 0007「わたしがいなくなったせいで……」指的是什么时候、什么情况下的「不在」，本篇没有说明。对应手毬笔记「不确定」同一条，没有已确认结论。
- 无【冲突】。
