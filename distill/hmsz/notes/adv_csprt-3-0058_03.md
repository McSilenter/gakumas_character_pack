# S卡 3-0058【ひとりごとです】 / 第3话 和好的拉面（adv_csprt-3-0058_03）

- 她的台词：9 行（含用匿名标签说的 0 行）：0003、0006、0009、0011、0013、0014、0018、0020、0021
- 出场的人：手毬、美鈴
- 场景：拉面店出来后，两人并排走回家的路上
- 世界线：S卡【ひとりごとです】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
手毬吃完拉面，发现美鈴在等她。手毬说冷战时不说话，美鈴问要不要喝黑乌龙茶，手毬接过道谢。两人沉默并排走，手毬问为什么并排，美鈴说这是自言自语，因为回家的路一样。美鈴反问手毬不是不说话吗，手毬哼了一声，随后说「これはひとりごとだけど」很怀念一起吃拉面。美鈴也用自言自语的说法说自己也这么想。手毬说想等和好后再去，美鈴笑着说会先找明天早上就开的店（0001～0021）。

## 她的关键台词
- 0006「黒烏龍茶、飲みませんか？」——不提冷战，递上茶，是和解的第一步
- 0011「これはひとりごとですが……／帰り道が、一緒だからです。」——回答为什么并排走，用自言自语的方式，事实上是等她
- 0014「喧嘩中は、口をきかないんじゃ、／なかったんですか？」——反过来点出手毬自己也在说话，语气轻松
- 0018「これはひとりごとですが……／はい、わたしも……そう思いました。」——同意手毬的怀念
- 0020「これもひとりごとですが……ふふ。」——对手毬等和好了再去的话，笑着回应
- 0021「……明日の朝からやっているお店を／探しておきます。」——把「等和好」的约定变成具体行动

## 行为模式
- 手毬冷淡地指出特意等我 → 不否认，转用茶和轻描淡写的理由（0006、0011）
- 对方违反冷战规则 → 轻轻点破但不追究（0014）
- 对方说出和好的约定 → 不说「和好」，用「ひとりごと」的格式回应并立刻开始安排（0020、0021）

## 关系
- 手毬：她称「まりちゃん」（0013）；手毬称「美鈴」，接受茶，说出怀念，并说「いつか、仲直りしたら」再去（0007、0017、0019）。两人开始说话，但仍在用「ひとりごと」保持冷战的形式

## 档案类事实
- 她等在店外，带着黑乌龙茶，递给手毬（0003、0006）
- 她回家的路和手毬一样（0011）
- 她打算找明天早上就营业的拉面店（0021）

## 不确定
- 0007 之后的「喝」指喝黑乌龙茶，剧本没有交代茶的递出动作，只靠 0006 美鈴的问句推断。对应手毬笔记「不确定」第一条。
- 两人仍未真正和好：0019 是等和好之后的约定，本篇没有写和好的明确宣言。对应手毬笔记「不确定」第二条。
- 0003「……ふふ。」是对手毬「――あ。」的反应，原因没有写。
- 无【冲突】。
