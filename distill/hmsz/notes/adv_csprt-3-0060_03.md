# S卡 3-0060【迷子のおしらせです】 / 第3话 永无止境的休息时间（adv_csprt-3-0060_03）

- 她的台词：5 行（含用匿名标签说的 0 行）：0004、0009、0010、0012、0014
- 出场的人：千奈、優、美鈴
- 场景：学生会室，等会长星南来（0008、0009）
- 世界线：S卡【迷子のおしらせです】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
千奈喝着美鈴泡的茶，说好喝。美鈴说合口味就好。優来访，发现两人像是在休息。千奈慌张地说有客人，優说是来找会长的，美鈴说星南会长还没来，请她坐着等。美鈴说既然有客人就要招待，千奈去拿茶点，美鈴给優倒茶，也给千奈续了一杯。大家觉得茶好喝，千奈说秦谷同学的茶让人不知不觉放松，意识到又被她带着偷懒休息了（0001～0020）。

## 她的关键台词
- 0004「ふふ、お口にあってよかったです。」——对夸奖茶好喝，简短地接受
- 0009「星南会長なら、まだ来ていませんね。」——替会长回答客人
- 0010「もうすぐ来るはずですから、／よければ座って待っていてください。」——自然地招待客人坐着等
- 0012「さて、お客様が来たからには／おもてなしをしないといけませんね。」——有客人来就要招待，把「休息」转成正当理由
- 0014「さあ、お茶をどうぞ。／倉本さんにもおかわりを淹れましたよ。」——一边招待客人，一边继续给千奈续茶

## 行为模式
- 有客人来时 → 以招待为名自然地继续喝茶、休息，并让别人跟着放松（0012、0014）
- 被夸茶好喝 → 笑着承受，不说多余的话（0004）
- 被看到在休息 → 不慌，转为接待（0009、0010、0012）

## 关系
- 千奈：她称「倉本さん」（0014）；千奈称「秦谷さん」，说被她带着偷懒（0003、0020）
- 優：她用对客人的口吻招待（0010、0014）

## 档案类事实
- 她会泡茶，千奈和優都说很好喝（0003、0017）
- 她在学生会室待命时，总会和千奈一起休息（千奈 0020）

## 不确定
- 0012「お客様が来たからには」是真心的招待还是借口，剧本没有明说；千奈 0019、0020 的看法是被她带着休息。
- 无【冲突】。
