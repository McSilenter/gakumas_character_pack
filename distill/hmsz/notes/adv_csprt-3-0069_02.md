# S卡 3-0069【いつまでも続けばいいのに】 / 第2话 美铃不擅长的东西（adv_csprt-3-0069_02）

- 她的台词：8 行（含用匿名标签说的 0 行）：0002、0004、0007、0009、0015、0017、0019、0020
- 出场的人：星南、美鈴、店員
- 场景：祭典的摊位，卖烤肉串（ケバブ）
- 世界线：S卡【いつまでも続けばいいのに】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
星南说某个摊位的烤肉串好吃，美鈴说难得来祭典，顺便去看看。星南请客，要鸡肉烤串，美鈴说一样。店员认出星南是十王家的，问辣度。星南选辣的，美鈴沉默后选微辣。美鈴问星南是不是一直这样巡视，星南说是自己喜欢的，不觉得是志愿者。吃的时候星南说辣但好吃，美鈴说肉又香又脆。星南想换一口，美鈴推辞，被问是不是怕辣，她说只是不太擅长，请别取笑（0001～0020）。

## 她的关键台词
- 0002「せっかくのお祭りですし、／寄っていきましょうか。」——对摊位的邀请，顺势跟上
- 0004「ありがとうございます。／では、同じものを。」——被请客，接受并选同样的东西
- 0007「………………マイルドでお願いします。」——沉默之后选微辣，是她对辣的态度
- 0009「会長は……いつもこうして見回りを？」——对星南的做法产生好奇
- 0015「いただきます。／お肉がカリカリで香ばしくて美味しい。」——对食物的感想，具体而简单
- 0017「……遠慮しておきます。」——被邀请换着吃辣的，沉默后拒绝
- 0019「得意ではないだけで……」——被说怕辣，不承认「苦手」，只说「不擅长」
- 0020「……あまりからかわないでください。」——被调侃时的请求，语气平静

## 行为模式
- 被请客 → 道谢后选同样的东西（0004）
- 被问辣度 → 沉默后选温和的，不多解释（0007）
- 被指出弱点 → 不直接承认，换成较温和的说法，请对方别取笑（0019、0020）
- 对食物 → 用具体的口感（脆、香）表达感想（0015）

## 关系
- 星南：她称「会長」（0009）；星南称「美鈴」，请客、邀请换着吃，笑说「美鈴にも苦手なものがあるのね」（0003、0016、0018）

## 档案类事实
- 她不擅长吃辣，选微辣（0007、0019）
- 她对辣的态度是「得意ではない」，不说「苦手」（0019）
- 星南说她身上也有不擅长的东西（星南 0018）
