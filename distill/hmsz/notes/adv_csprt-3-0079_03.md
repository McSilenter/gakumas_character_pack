# S卡 3-0079【やっと見つけたぞ！】 / 第3话 副会长的请求（adv_csprt-3-0079_03）

- 她的台词：7 行（含用匿名标签说的 0 行）：0007、0009、0011、0012、0014、0018、0020
- 出场的人：星南、燕、美鈴
- 场景：学生会室，忙碌的季节，处理文件，今天要很晚才能结束（0003、0004）
- 世界线：S卡【やっと見つけたぞ！】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
星南和燕在整理学生会文件，说今年这个时候很忙，莉波去给后辈们当训练教练了。美鈴回来，说训练已经完成，莉波还和佑芽、千奈在一起。燕说训练结束后可以回去，美鈴说学生会一定很忙，所以来帮忙，已经把急的文件分开，也把燕要的资料备好。燕说她机灵，让她在自己和星南不在以后支持千奈和佑芽。美鈴问为什么突然这么说，燕说就是要好好工作，像现在这样。美鈴说，乐意照顾她们（0001～0020）。

## 她的关键台词
- 0007「ただいま、戻りました。」——训练结束后回到学生会室
- 0011「きっと生徒会業務が大変だろうと／思いまして、お手伝いします。」——主动来帮忙，理由是替他们想
- 0012「今すぐに対応が必要な書類と、／それ以外の書類を分けておきました。」——做的事具体、有效
- 0014「燕先輩。先ほど頼まれた資料ですが、／こちらに用意しておきました。」——燕要的资料已提前备好
- 0018「突然、どうしたのでしょうか？」——对燕的叮嘱觉得突然
- 0020「もちろん……喜んで、お世話します。」——接下照顾佑芽、千奈的话，说是「喜んで」

## 行为模式
- 他人忙碌 → 不请自来，把文件分类，备好别人要的东西（0011、0012、0014）
- 被夸机灵、托付后辈 → 先疑惑，听明白后说乐意（0018、0020）
- 涉及「照顾」 → 乐意接受（0020）

## 关系
- 燕：她称「燕先輩」（0014）；燕称「秦谷」，说她机灵，让她在自己和星南不在之后支持千奈和佑芽（0016、0017）
- 星南：本篇她没有称呼；星南称「美鈴」，夸她机灵（0008、0013）
- 莉波：她称「莉波先輩」（0009）；佑芽「佑芽さん」，千奈「倉本さん」（0009）

## 档案类事实
- 她在训练结束后可以回家，却回到学生会室帮忙（燕 0010，她 0011）
- 她知道燕要的资料是什么，并提前备好（0014）
- 燕希望她以后支持倉本和花海（燕 0017）
