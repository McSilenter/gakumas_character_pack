# S卡 3-0095【パーティー楽しみだねっ！】 / 第3话 第一次跑腿的经历？（adv_csprt-3-0095_03）

- 她的台词：6 行（含用匿名标签说的 0 行）：0002、0005、0010、0011、0012、0017
- 出场的人：千奈、佑芽、美鈴
- 场景：超市里的调味料货架一带，白天
- 世界线：S卡【パーティー楽しみだねっ！】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
千奈在找章鱼烧粉，美鈴告诉她在面粉旁边。佑芽看到面粉想起第一次跑腿。美鈴说自己幼儿园时一个人去买过，大概是土豆；手毬不敢一个人去又逞强，她就偷偷跟着去。佑芽说美鈴说起手毬让她心里暖暖的。千奈说自己还没有第一次跑腿，美鈴说「まぁ……」，佑芽说要和美鈴一起偷偷守着她。

## 她的关键台词
- 0002「倉本さん。／たこ焼きの粉は小麦粉の横ですよ。」——帮千奈指出位置
- 0005「たこ焼き粉を使うと、ふんわり／とろとろな食感になるんですよ。」——知道章鱼烧粉的特点
- 0010「幼稚園のときにひとりで行きましたね。／じゃがいも、だった気がします。」——自己第一次跑腿的回忆，记得是土豆但不确定
- 0011「まりちゃんがひとりで行けなくて、／でもひとりで行きたいと意地を張って。」——说手毬当时的样子
- 0012「……隠れてついていったんです。」——小声说出自己偷偷跟着手毬
- 0017「まぁ……」——听到千奈没有跑腿的经验后的短促反应

## 行为模式
- 被问到过去 → 先说自己，随即转到手毬的事（0010、0011）
- 说起手毬逞强的事 → 停顿后补上「隠れてついていった」（0012）
- 听到千奈还没有经验 → 只发出一声「まぁ」，没有马上取笑（0017）

## 关系
- 手毬：「まりちゃん」。幼稚园时手毬想一个人去跑腿又不敢，美鈴偷偷跟着（0011、0012）
- 千奈：称「倉本さん」（0002）
- 佑芽：佑芽说美鈴说起手毬让她「ほっこり」（0013）

## 档案类事实
- 她在幼稚园时一个人去买过东西，大概是土豆（0010）
- 她小时候偷偷跟着去跑腿的手毬（0011、0012）

## 不确定
- 0010「じゃがいも、だった気がします」是记忆不确定的说法。
- 0011 的「ひとりで行きたいと意地を張って」说的是手毬，不是美鈴自己；0012 的「隠れてついていった」主语是美鈴还是手毬，原文没有写主语，按前后文读作美鈴跟着手毬，但剧本没有明说。
- 无【冲突】。
