# 有村麻央 亲爱度剧情 / 第30话（adv_dear_amao_030）

- 她的台词：12 行（含用匿名标签说的 0 行）；0035 只有「……――」，计入清单统计
- 出场的人：麻央、莉波、手毬、美鈴、プロデューサー
- 场景：初星学园。先是麻央和莉波在『選抜試験』之后聊天；0027 起是麻央和手毬、美鈴的合同练习（冬季『H.I.F』之前）；0061 起是麻央与制作人商量写真集（场景切换，剧本没写明是否是回忆）
- 世界线：亲爱度（有村麻央）；制作人在制作的偶像：有村麻央（0061～0079），美鈴是配角

## 发生了什么
麻央和莉波谈起选拔考试，莉波说在生徒会里和千奈、佑芽、美鈴一起工作，受她们优点的影响。之后手毬和美鈴来参加麻央的合同练习。美鈴说手毬的唱法最好别太参考，被手毬拿来夸耀，麻央夸手毬在演唱会上很帅。练习中麻央称赞手毬的歌像在削磨灵魂，美鈴说那还不够，初中时期的手毬更让人头疼。麻央问她们为什么不参加冬季『H.I.F』，美鈴说有更要优先做的事，并问麻央：当憧憬消失时会怎么办。麻央回答自己会点亮光。最后场景切换到麻央和制作人谈写真集。

## 她的关键台词
- 0031「……まりちゃんの歌い方は、／あまり参考にしないほうが、／いいと思いますけど。」——手毬说有自信后，她小声提出反对
- 0041「有村先輩。まりちゃんは褒めると、／すぐ真に受けるので。」——称麻央为「有村先輩」，替手毬补一句，带点照顾和调侃
- 0046「あんなものじゃ、ありませんよ。」——麻央说手毬像在削磨灵魂时，她说那还不够
- 0047「中等部の頃のまりちゃんは、／本当に……大変でした。」——提起手毬初中时期的情况
- 0050「今のわたしたちには、／先にやるべきことがあるので。」——被问为什么不参加冬季『H.I.F』，只说有更要优先的事
- 0052「――先輩は、憧れが、／見えなくなってしまったとき、」——突然问麻央，开头先停顿
- 0053「ずっと追いかけていた光が、／消えてしまったとき――」——把假设说得更具体
- 0054「――どうしますか？」——直接问麻央的做法
- 0058「……強いんですね、有村先輩は。」——听到麻央的回答后，承认对方强

## 行为模式
- 手毬被夸而得意 → 用冷静的话补一句，让她别太当真（0031、0041）
- 手毬被夸「削魂」 → 说出更严重的前史，但不展开（0046、0047）
- 被问不参加比赛的原因 → 只说有更要优先的事，不说具体（0050）
- 想知道前辈的看法 → 选个合适时机，先叫「有村先輩」再提一个具体的假设问题（0051～0054）
- 对方给出坚定的回答 → 承认「強いんですね」，不再追问（0058）
- 手毬拿被夸来炫耀时 → 沉默（0035）

## 关系
- 手毬：叫「まりちゃん」（0031、0041、0047）；手毬叫她「美鈴」（0034、0042）；手毬说「子供扱いしないで」（0042）
- 麻央：叫「有村先輩」（0041、0051、0058）；麻央叫她「美鈴」「ふたり」（0048），对她使用较平和的前辈口吻
- 莉波：莉波叫她「美鈴ちゃん」，说自己在生徒会和千奈、佑芽、美鈴一起工作过（0011）

## 档案类事实
- 莉波说美鈴是生徒会的人，一起工作（0011，莉波的话）
- 美鈴说中等部时期的手毬「本当に……大変でした」（0047）
- 美鈴和手毬没有参加冬季『H.I.F』（麻央 0048 的问话，美鈴 0050 没有否认，说有更优先要做的事）
- 麻央认为美鈴和手毬的实力在初星是顶尖的（0049，麻央的话）

## 不确定
- 0046「あんなものじゃ」指手毬的歌法比麻央所说的「魂を削ってる」还要厉害，具体指什么没写（0047 接的是中等部时期）。
- 0050「先にやるべきこと」是什么没写。和 ttmr/conflicts.md 8j 的“手毬没参加冬季 H.I.F，原因不清楚”一致，这里美鈴也一起不参加，原因同样没说。
- 0052～0054 美鈴问麻央的“憧れが見えなくなったとき”，是在指谁没写，也没写美鈴是否想到了自己或手毬。
- 0035 只有省略号「……――」，是沉默还是别的，剧本没写。
- 0061 起的制作人与麻央对话与前面的场景之间没有交代（可能是麻央回想起“给契机的人”，0060），美鈴不在其中。
