# 雨夜燕 亲爱度剧情 / 第5话（adv_dear_atbm_005）

- 她的台词：13 行（含用匿名标签说的 0 行）
- 出场的人：燕、プロデューサー、美鈴、星南、佑芽、千奈
- 场景：初星学园（生徒会周边，美鈴在午睡的地方），『H.I.F』选抜试验前后
- 世界线：亲爱度（雨夜燕）；制作人在制作的偶像：燕（0008「雨夜さん。／次の試験に向けて対策を立てましょう。」）；美鈴是被借力的配角

## 发生了什么
制作人想打碎燕过度自信的状态，便去找正在午睡的美鈴（0016）。制作人拜托她在选抜试验的直接对决中赢过燕，并以以后不会再因为偷懒被燕说为条件（0037）。美鈴觉得有趣，答应了。随后她当着燕的面提出：如果她赢了，希望能偶尔休息生徒会的工作，燕答应并说赢了什么都听她的。选抜试验结果：美鈴第1位、燕第2位。

## 行为模式
- 被陌生人（制作人）叫醒并被拜托 → 先有礼貌地打招呼，再问「何の得が」，有好处才听（0024、0034、0038）
- 被说中偷懒的麻烦 → 不直接承认，只说「そこまでは思っていません」（0036）
- 当着燕的面 → 把制作人的拜托说成自己的挑战，不提制作人（0042、0044）
- 对方放话 → 不争辩，只说「では……遠慮なく」，用结果回答（0049、0051）
