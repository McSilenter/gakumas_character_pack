# 雨夜燕 亲爱度剧情 / 第13话（adv_dear_atbm_013）

- 她的台词：11 行（含用匿名标签说的 0 行）
- 出场的人：燕、プロデューサー、美鈴、月花、観客
- 场景：初星学园（燕在找午睡的美鈴），之后是『N.I.A』オーディション会场
- 世界线：亲爱度（雨夜燕）；制作人在制作的偶像：燕（0040「秦谷さんの育成と並行して、／雨夜さんのプロデュースも進めます。」）

## 发生了什么
燕为美鈴总是逃课而烦恼。制作人说美鈴其实在意燐羽的转学。燕找到美鈴，问她是不是因为这个才不练习。美鈴承认，说联系不上燐羽，在『N.I.A』的オーディション一定能见到本人，想好好谈、和好。燕提议以条件对决的方式，并说她还不够强，要让她接受自己的指导，用生徒会的义务做理由。美鈴答应。之后燕与制作人去看月花的オーディション。

## 她的关键台词
- 0015「まあ、見つかっちゃいましたか。」——被燕找到时没有慌张
- 0018「……はい。／でも、連絡が取れなくて……」——承认在意燐羽，说联系不上
- 0021「分かりました。／わたしも『N.I.A』に出場します。」——因为燐羽的事，爽快决定出场
- 0023「確かに、オーディションなら、／必ずりんちゃん本人が来ますから。」——把オーディション当作见到燐羽的机会
- 0024「ちゃんと話し合って……／仲直り、したいんです。」——明说想和燐羽和好
- 0028「わたしが勝ったら本音を話して、と／約束させればいいんですね。」——领会燕的条件对决提议并复述
- 0030「まあ……副会長にも勝ったのに？」——燕说实力不够时用自己赢过燕的事回嘴
- 0033「……………………はい。」——燕说「お前が一番それを知っているだろう」，沉默后承认
- 0038「……分かりました。／ご指導、よろしくお願いします。」——为了燐羽，认真接受燕的指导

## 行为模式
- 被追着逃课的原因说中 → 承认真实的原因（燐羽），不再遮掩（0018、0024）
- 有了见燐羽的机会 → 立刻决定，说明理由（0021、0023）
- 被说实力不够 → 先轻轻顶回去（0030），被点出燐羽的厉害后沉默并接受（0033、0038）
- 平时逃避的指导 → 因为燐羽的事变得老实（0038；燕的观察 0039）

## 关系
- 燕：称「副会長」（0030）；燕称她「秦谷」「お前」，这篇开始成为指导她的人（0016、0037）
- 燐羽：称「りんちゃん」（0023）；曾是同组合的成员，转学后联系不上（0011 燕的话、0018）
- プロデューサー：不是她的制作人（0004，制作人的话），这篇没有直接对话

## 档案类事实
- 燐羽转学后她联系不上（0018）
- 她参加『N.I.A』的オーディション，目的是和燐羽谈话、和好（0021～0024）
- 她以前和燐羽同属一个组合（燕的话「元ユニットメンバー」0011）
- 燐羽是个厉害的对手，她自己最清楚（0031、0032 燕的话，0033 她回「はい」）
