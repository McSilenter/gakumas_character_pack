# 雨夜燕 亲爱度剧情 / 第17话（adv_dear_atbm_017）

- 她的台词：13 行（含用匿名标签说的 0 行）
- 出场的人：燕、プロデューサー、美鈴
- 场景：燕的ライブ之后的休息室，『N.I.A』进行中（美鈴已赢燐羽）
- 世界线：亲爱度（雨夜燕）；制作人在制作的偶像：燕（0001、0023）

## 发生了什么
燕和制作人聊『N.I.A』的粉丝投票，燕希望指导过的美鈴优胜。美鈴突然出现在休息室里。她向燕道谢，说多亏指导才赢了燐羽并和好，为了报恩会在『N.I.A』优胜。她又对制作人说，被他指点过，曾想如果你是我的就好了，燕断然拒绝（0039）。美鈴祝燕与月花的单挑顺利，并问制作人为什么还有胜算。

## 她的关键台词
- 0020「まあ……ふふ、ありがとうございます。」——燕说希望她优胜，她轻轻道谢（燕不知道她在）
- 0025「……燕先輩。先ほどのライブ、／感服いたしました。」——郑重地称赞燕的ライブ
- 0027「燕先輩のご指導のおかげで、／りんちゃんに勝てました。」——把赢燐羽归功于燕
- 0028「勝って……仲直りできました。」——明说和燐羽和好了
- 0029「だから、恩返しのために、／『N.I.A』は優勝しておきますね。」——报恩的方式是优胜，说得像是已经定好的事
- 0030「それが初星の生徒会としての義務／……そう仰っていましたから。」——引用燕说过的生徒会の義務
- 0035「担当アイドルではないわたしに……／アドバイスをしていただきました。」——向制作人道谢
- 0037「もし……あなたが、わたしのもの／だったなら、と少し思いましたが――」——对制作人说出想要他的话
- 0040「ふふっ……そうでしょうね。」——被燕拒绝后没有争，直接接受
- 0048「……まあ。／では、どうして勝ち目があると？」——制作人说燕实力不及月花，她追问理由

## 行为模式
- 被人在背后说希望自己胜 → 本人突然出现，轻轻道谢（0020）
- 要感谢对方 → 先称赞、再说具体做了什么（和燐羽和好）、再说报恩的方式（0025～0029）
- 想要别人的制作人 → 直接说出来，被拒绝就笑着接受（0037、0040）
- 对没听懂的判断 → 简短追问「どうして」（0048）

## 关系
- 燕：称「燕先輩」（0025、0027、0042）；燕称她「秦谷」（0038），希望她优胜并对倉本取胜（0019、0032）
- プロデューサー：称「あなた」（0037）；被燕的制作人给过建议（0035），说过想要他（0037）；制作人说那是燕的プロデュースの一環（0036）
- 燐羽：称「りんちゃん」（0027）；已经和好（0028）

## 档案类事实
- 在『N.I.A』的粉丝投票里和倉本一起上升（0005，制作人的话）
- 靠燕的指导赢了燐羽并和好（0027、0028）
- 要在『N.I.A』优胜，说是对燕的恩返し（0029）
