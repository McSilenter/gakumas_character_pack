# 秦谷美鈴 亲爱度剧情 / 第1话（adv_dear_hmsz_001）

- 她的台词：30 行（含用匿名标签说的 0 行）
- 出场的人：美鈴、プロデューサー
- 场景：春天，阳光照进来的茶道室；制作人事先调查过她，前来招募（0001～0002）
- 世界线：亲爱度（秦谷美鈴）；制作人在制作的偶像：秦谷美鈴（本篇是招募她的经过）

## 发生了什么
制作人来茶道室招募她，看她闭目静坐、气氛超然，一时不敢搭话。她先开口自我介绍，听到邀请后先客气地说自己回应不了期待。她提出条件：要能理解、接纳她的人，于是出题问制作人她刚才在做什么——答案是「午睡」（制作人的回答没写进剧本，她说「正解です」）。制作人表示不责备、装作没看见，她称两人是「共犯」。她说出自己的想法：勉强逞强到达的地方不会舒适，「ほどほどがいい」。制作人说她会按自己的步调走到顶点，愿意帮她舒适地走下去；她说本来想从此一个人走，但和他也许能「もう一度、やり直せる」，郑重接受了邀请。

## 她的关键台词
- 0006「はじめまして、秦谷美鈴と申します。」——初次见面用很郑重的敬语自报姓名
- 0010「わたしでは、あなたの期待に／応えられないと思いますよ。」——对邀请先客气地推辞
- 0014「わたしを理解して、受け入れて／くれる方となら、ご一緒したいです。」——提出合作条件：理解并接纳她
- 0019「ちょっぴり、お昼寝していたんです。」——在没人来的茶道室偷偷午睡，这是她的“考题”答案
- 0023「まあ……では、共犯ですね。」——制作人默许她偷懒后，把对方拉成“共犯”，带点调皮
- 0026「だけど……背伸びをして、無理をして、／そうしてたどりついた場所が、」——表明价值观的前半
- 0029「ほどほどがいい。そう思います。」——核心价值观：适可而止
- 0032「はい……そのつもりです。」——被说“终会登上顶点”时坦然承认，有登顶的志向
- 0035「ここからはひとりで。／そう思っていたのですが。」——原本打算一个人走下去
- 0036「あなたとなら……／もう一度、やり直せるかもしれません。」——“重新来过”，暗示有过一次失败的过去
- 0039「いつか、高いところで／あくびをしましょう。」——她式的目标宣言：悠闲地登顶

## 行为模式
- 初次见面、被搭话 → 用郑重的敬语自我介绍，语气平静从容，口头的「まあ」开场（0005～0008）
- 被邀请、被寄予期待 → 先客气地降低对方期待，再提出自己的条件（0009～0010、0014）
- 想试探对方 → 出题考对方是否“理解”自己，答案是她在偷懒（0015～0019）
- 对方默许她的懒散 → 高兴地把对方当成同伙，开轻松的玩笑（0021、0023）
- 谈到努力和目标 → 承认自己也在努力，但否定勉强、逞强，主张「ほどほど」（0024～0029）
- 被说中有登顶的志向 → 不谦虚，直接说「そのつもりです」（0032）
- 被夸、被认真对待 → 「まあ……」「ふふ」，说既高兴又难为情（0012）

## 关系
- プロデューサー：她叫「プロデューサー」，用敬语；本篇第一次见面，经过“考题”后接受了招募，称两人是「共犯」（0021、0023、0037）。制作人对她说话也用敬语。

## 档案类事实
- 全名秦谷美鈴（0006）
- 会在没人来的时间到茶道室午睡（0018～0019）
- 自称学园的学生都朝高目标努力，她自己也是（0024～0025）
- 价值观：勉强逞强到达的地方不会舒适，「ほどほどがいい」，承认很少有人认同（0026～0029）
- 有登顶的打算（0032），想「のんびり、着実に」地走（0038）
- 本来打算从此一个人走下去（0035），“重新来过”说明之前有过一段经历（0036）
- 一人称「わたし」（0010 等）

## 不确定
- 0017「正解です。」：制作人的回答没写进剧本；从 0019 看答案是“午睡”，但制作人原话不知道。
- 0036「もう一度、やり直せる」：要重来的是什么（偶像活动？组合？）本篇没说。
- 0008「まあ。」之前制作人提出邀请的原话不在剧本里。
