# 秦谷美鈴 亲爱度剧情 / 第3话（adv_dear_hmsz_003）

- 她的台词：31 行（含用匿名标签说的 0 行）
- 出场的人：美鈴、プロデューサー
- 场景：她刚唱完、向制作人展示实力之后（0001～0002）；地点看不出
- 世界线：亲爱度（秦谷美鈴）；制作人在制作的偶像：秦谷美鈴

## 发生了什么
她向制作人展示现在的实力，制作人说比去年视频里更进步，她的歌让人心情平静。她说那是有意投入心意唱的，是「地道な努力」的成果，又自己笑问制作人是不是在想“明明是偷懒鬼”。制作人说她其实很努力（虽然练习量确实少），她说好久没人这么说她了；她接受了“不要在约定时间失踪”的要求。制作人说他的工作是给她准备好走的路，作为其中一环提议强化歌唱力，理由是可能输给假想敌月村手毬。她沉默良久，反问制作人是不是了解现在的手毬；制作人说手毬正在焦躁空转、自我毁灭，但万一她发挥出全部实力——她打断说「言われるまでもありません」，说出三人一起成为顶级偶像是她一直的梦想，表示必须超过「夢で見たあの月村手毬」。她接受制作人的指引，但对明天开始的歌唱特训仍回答「明日、空が曇ったなら」。

## 她的关键台词
- 0002「これが、いまのわたしの実力です。」——主动展示实力，自信
- 0009「そう感じていただけるよう……／想いを込めて、歌いましたから。」——让人平静是她有意追求的歌唱效果
- 0012「ふふ……サボり魔のくせにって、／思いましたか？」——先自嘲，把别人可能的吐槽说出来
- 0014「わたしが……がんばっている……／――久しぶりに言われました。」——很久没人说她努力，有触动
- 0028「まあ、まあ……まるでわたしが／素行の悪い問題児のよう。」——被说素行差时的典型反应
- 0035「……それは、とても……素敵ですね。」——对制作人“为她准备舒适道路”的方针由衷认同
- 0040「わたしが、まりちゃんに負ける……？」——听到可能输给手毬，难以置信
- 0047「そう、だから……わたしが……／止めてあげないと。」——确认要阻止手毬
- 0052「言われるまでもありません。」——对手毬真正实力的了解，语气少见地强硬
- 0053「ずっと、夢だったんです。将来……／3人で、トップアイドルになるのが。」——说出梦想
- 0055「夢で見たあの月村手毬を、／追い抜かないといけないんですね。」——目标：超过手毬的“全力”
- 0061「はい。明日、空が曇ったなら。」——即使有了干劲，仍坚持“阴天才上课”的约定

## 行为模式
- 被夸奖 → 「まあ、ありがとうございます」「嬉しいです」坦然接受，并说明自己的用心（0005、0008～0009）
- 预料到对方会吐槽她懒 → 自己先笑着说出来（0012）
- 被指出练习量少、行为不端 → 轻松承认（「少ないですよね」），对合理的要求会说「かしこまりました」接受（0017、0022）
- 被说是问题儿童 → 「まあ、まあ」装作委屈，然后反问对方打算怎么制作她（0028、0031～0032）
- 有人说她会输给手毬 → 先长时间沉默，再连续反问，语气变强（0039～0041、0048）
- 对方点出手毬的真正实力 → 立刻承认，说出梦想，转为认真（0052～0055）
- 有了干劲后 → 仍维持自己的步调，用天气当条件（0061）

## 关系
- プロデューサー：她叫「プロデューサー」，用敬语；制作人叫她「秦谷さん」。认同他“准备舒适道路”的方针，把「道案内」交给他（0035、0058）。
- 月村手毬：她叫「まりちゃん」（0040），也叫「あの子」（0041、0048），称全名「月村手毬」（0055）。制作人称手毬为她的「仮想敵」「ライバル」（0038、0042）。她认为现在的手毬不会赢她，但承认手毬全力发挥时的实力（0048、0052），要阻止手毬（0047），梦想是三人一起成为顶级偶像（0053）。

## 档案类事实
- 歌声让人心情平静，她说这是有意投入心意唱出来的（0007～0009）
- 练习量比其他偶像少，但不像周围人想的那么少（0016～0018）
- 经常在约定时间失踪（0020，制作人说的）
- 去年有她的表演视频，制作人看过（0004）
- 梦想：将来三人一起成为顶级偶像（0053）

## 不确定
- 0055「夢で見たあの月村手毬」：「夢で見た」是指她在梦里见到的手毬，还是指“梦想中（三人一起登顶时）的手毬”、即全力发挥的手毬，原文不好断定；译文写作“梦里见到的，那个真正的月村手毬”。
- 0053「3人」：本篇没点名，结合第2话 0027～0030 应是她、手毬、燐羽，但本篇没明说。
- 0054「――……わたし。」：话说了一半，是怎样的语气（下决心？）看不出。
- 【已确认 2026-10-31】先有她和手毬两个人『一緒にトップアイドルになろう』的约定，燐羽是后来加入的，之后成了三个人的梦（conflicts 三·2）。
