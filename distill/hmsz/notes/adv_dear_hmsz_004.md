# 秦谷美鈴 亲爱度剧情 / 第4话（adv_dear_hmsz_004）

- 她的台词：29 行（含用匿名标签说的 0 行）
- 出场的人：美鈴、プロデューサー、あさり先生
- 场景：休息日上午，晴天；制作人在教室摊开资料工作（0006、0018、0036）
- 世界线：亲爱度（秦谷美鈴）；制作人在制作的偶像：秦谷美鈴

## 发生了什么
休息日，制作人在查“求雨”和“让天变阴的咒法”的资料（为了让她上课），被あさり先生吐槽。她上午就来了，说难得的休息日睡觉太可惜。她说自己喜欢照顾亲近的人，今早帮朋友打扫了房间，但大家都很能干，不够尽兴，所以想照顾制作人；制作人说偶像休息日就该休息，她说静不下来。教室刚打扫过，她便提出去打扫制作人的家、烧洗澡水做晚饭等他回来，被严词拒绝。她说自己偶尔会忍不住想宠人，可是「まりちゃん」和「りんちゃん」都不在，自己不知怎么办。制作人让她帮忙整理资料，她很高兴；听说上午是在为了减少她的练习量而做高效训练计划，她说“为了我……”，愿意帮忙，并让制作人也「のんびり、着実に」走，「わたしのとなりで」。

## 她的关键台词
- 0019「まあ、まるでわたしが／いつも寝坊をしているみたいに。」——被调侃时的典型反应
- 0021「せっかくのお休みなのですから……／寝ているのは惜しいじゃありませんか。」——平时爱睡，休息日反而精神
- 0025「わたし、親しい方の／お世話をするのが好きなんです。」——喜欢照顾亲近的人
- 0027「皆さん、しっかりした方ばかりで……／物足りなかったんです。」——对方太能干她反而不满足
- 0035「そういうのではないんです。／…………御存知のくせに。」——被装傻时带点埋怨
- 0041「お風呂を沸かして夕食を作り……／帰りを待っています。」——照顾欲过头的提议
- 0043「まあ、プロデューサー……／意外とわがままなんですね。」——被拒绝时反说对方任性
- 0046「誰かを甘やかしたくて／仕方なくなるんです。」——说明自己“想宠人”的冲动
- 0047「なのに、まりちゃんも、／りんちゃんもいなくって……」——以前照顾的对象是手毬和燐羽
- 0058「そんなことはありません。わたしが／好きで手伝っているのですから。」——帮忙是出于喜欢
- 0060「わたしのとなりで。」——要制作人和她并肩慢慢走

## 行为模式
- 休息日 → 反而早起、闲不住，想找人照顾（0020～0021、0033）
- 想照顾的对象太能干、没事可做 → 觉得「物足りなかった」「残念です」，转而找别的对象（0027～0028、0037～0039）
- 照顾欲 → 提议越界的照顾（打扫对方家、烧洗澡水、做晚饭）（0039、0041）
- 被拒绝 → 不生气，反过来说对方「わがまま」「情の薄い方」（0043、0045）
- 想宠人却没对象 → 想起手毬和燐羽，露出寂寞（0046～0048）
- 有人为她做事 → 「わたしのために……」，主动说要帮忙（0055～0056）
- 别人皱眉、为难 → 笑着指出（0023）

## 关系
- プロデューサー：她叫「プロデューサー」，用敬语；制作人叫她「秦谷さん」。想照顾他、宠他，被拒绝后开玩笑地说他薄情（0028、0045）；得知他在为自己工作后主动帮忙，要他走在自己身边（0058～0060）。
- 月村手毬：她叫「まりちゃん」（0047）；以前是她照顾、宠溺的对象之一，现在不在身边。
- 賀陽燐羽（推测）：她叫「りんちゃん」（0047），和手毬并列，以前是她照顾的对象之一，现在不在身边。
- 朋友们：今早帮朋友打扫了房间，但大家都很能干（0026～0027）。
