# 秦谷美鈴 亲爱度剧情 / 第5话（adv_dear_hmsz_005）

- 她的台词：33 行（含用匿名标签说的 0 行）
- 出场的人：美鈴、プロデューサー
- 场景：连日阴天的时期（0001、0062）；地点看不出
- 世界线：亲爱度（秦谷美鈴）；制作人在制作的偶像：秦谷美鈴

## 发生了什么
最近一直阴天，她遵守约定每天上课，嘴上抱怨忧郁，还吓唬制作人“阴天也不一定不偷懒”。制作人提出要给她办个人 Live，为此她要学会“独唱偶像的唱法”。制作人指出她原来的组合『SyngUp!』是以月村手毬为主轴、另外两人支援的形式，她说那是很和谐的组合，支撑手毬、一起唱歌是幸福。制作人说她用自己的感情唱得很好，但问她想放进歌里的只有“给大家安宁”“想慢慢走”吗；她说自己不像「あの子」那样用激烈的感情唱歌。制作人断言『SyngUp!』是一群「熱く傲慢で自分本位」的同类，她领悟到制作人是要她连“不好的想法”也放进歌里。被追问想让观众有什么感受，她先说安稳、甜美的睡意，再沉默后说出真心：想用自己填满观众的心，让他们没有她就活不下去。制作人被吓到，她反说是他引导的，坦然说这就是本心，决定不再客气，带着这份心情唱。

- 0024「それを支え、ともに歌うのが……／……幸せでした。」——在组合里支撑手毬是她的幸福
- 0032「おっしゃる意味がわかりません。／わたしは、あの子のように、」——自认和手毬类型不同（接 0033）
- 0043「悪い想いも……込めてしまえと／おっしゃるのでしょう？」——领会制作人的意图
- 0047「穏やかで、やすらかな心地に。／甘やかに、まどろむような心地に。」——表面上想给观众的感受
- 0050「心を……わたしで埋め尽くしたい。」——说出本心
- 0051「わたしがいないと……／生きていけないようにしたいです。」——占有欲很强的本心
- 0053「なっ……なんですか、その反応は。／自分で促したくせに。」——少见的慌乱
- 0055「これがわたしの本心です。」——坦然承认
- 0056「文句は、わたしの／プロデューサーへどうぞ。」——把责任推给制作人，俏皮
- 0060「皆さんの心が……わたしで／満たされますように、と。」——带着本心唱歌的决意

## 行为模式
- 遵守了约定、被感谢 → 不直接接受，反过来开玩笑吓对方（0004～0005）
- 被指出自己的问题 → 先确认对方意思，「と、いうことでしょうか？」（0013～0014）
- 对方话里有话 → 「ふふ……」笑着把对方的意思挑明（0020～0022）
- 被说得不太好听 → 「気のせいでしょうか……」委婉追问，「まあ、やっぱり」接受（0039、0041）
- 被追问真正的想法 → 先说体面的答案，被追问后沉默很久，再说出强烈的本心（0047～0051）
- 说出本心后对方反应夸张 → 一时慌乱，然后坦然承认，并把责任推给“我的制作人”（0053～0056）
- 被推了一把 → 「遠慮はしません」，下定决心（0058）

## 关系
- プロデューサー：她叫「プロデューサー」，称他为「わたしの／プロデューサー」（0056）；制作人叫她「秦谷さん」。制作人引导她说出本心，她接受了他的指导（0057～0059）。
- 月村手毬：用「あの子」指她（0032、0044）。『SyngUp!』以手毬为主轴（0016，制作人说的），她认为支撑手毬、一起唱歌是幸福（0024）；她觉得手毬是用激烈感情、毫无保留地唱歌的人（0032～0033、0044）。
- 『SyngUp!』的队友们：她认为组合很和谐（0017），说自己「仲間を失った」（0021）。

## 档案类事实
- 中等部时所属的组合叫『SyngUp!』，以月村手毬为主轴、其他两人支援（0015～0016，制作人说的，她确认「はい」0017）
- 组合运转了 3 年，各自分工（0019，制作人说的）
- 制作人计划给她办个人 Live（0009）
- 她想让观众感到安稳、甜美的睡意（0047），本心是想用自己填满观众的心，让他们离不开她（0050～0051）

## 不确定
- 0035～0036：制作人「あなたがステージに懸ける想いは……」之后断掉，她「……！」，接着制作人说的是『SyngUp!』的成员都很「熱く傲慢で自分本位」（0037～0038），中间可能有没写进剧本的话。
- 0018～0019：制作人说组合是「ぎりぎりのバランスで」成立的，她没回应；她自己认为「調和の取れた」（0017）。两种看法并存，不算冲突。
- 【译文】0033「激しい想いで歌うタイプでは／ないように思います。」：原文主语是她自己（我不是那种类型），译文写成“我觉得你并不像是那种用激烈情感歌唱的类型”，主语错成了“你”。
