# 秦谷美鈴 亲爱度剧情 / 第6话（adv_dear_hmsz_006）

- 她的台词：46 行（含用匿名标签说的 0 行）
- 出场的人：美鈴、プロデューサー
- 场景：月村手毬个人 Live 当天，出发前和看完之后（0002～0003、0024）
- 世界线：亲爱度（秦谷美鈴）；制作人在制作的偶像：秦谷美鈴

## 发生了什么
月村手毬个人 Live 的日子到了，她说仍然完全没能和「まりちゃん」说上话，但当然要去看。制作人准备了最前排的座位，她大为感激，说选了他真好。出发前互相检查装备，她带着手毬的团扇、原创荧光棒、签名法被，自称「一番のファン」；制作人原本想“侦察敌情”，她说作为粉丝享受也可以。看完后两人都紧张得像要折寿，她吃了制作人给的胃药才平静下来。她说手毬一直是那样危险、让人放不下，但每次都让她心动，今天也很精彩；所以才必须阻止那种勉强自己、走向毁灭的歌。可是看着手毬拼命唱歌，她开始怀疑那是不是手毬的「マイペース」，和自己慢慢走是同样的理由，于是心生想应援的心情，很痛苦，向制作人求助。制作人说把想法全放进歌里，她说刚刚手毬就示范过，决定用同样的方法、在超过对方的舞台上、用自己的歌传达。

## 行为模式
- 有人替她安排周到 → 夸张地感激（「あなたを選んで、本当によかった」），被说太重后改为简单道谢（0007～0011）
- 去看手毬的 Live → 以粉丝身份全副武装（团扇、荧光棒、签名法被）（0015～0019）
- 看手毬冒险的表演 → 极度紧张、身体反应（喘气、要吃胃药）（0026～0031）
- 心里矛盾 → 先说出原来的立场，再一层层否定（「はずなのに」），最后直说痛苦、求助（0038～0052）
- 得到建议后 → 先怀疑能否传达，自己否定这份怀疑，转为决意（0054～0060）

## 关系
- プロデューサー：她叫「プロデューサー」，称赞他可靠，说选了他真好（0007～0009）；迷茫时向他求助（0052）。制作人叫她「秦谷さん」（0062）。
- 月村手毬：她叫「まりちゃん」（0004），也称「あの子」「彼女」（0043、0046、0048）。现在完全说不上话（0004），但去看她的个人 Live，自称「一番のファン」（0019）。认为她「危なっかしくて、放っておけなくて」，但每次都被她打动（0034～0036）；原本坚决要阻止她，本篇开始动摇，产生了想应援的心情（0038～0050）；最后决定在超过她的舞台上用同样的方法传达自己的想法（0057～0058）。制作人称手毬为「我らが敵」（0023）。
