# 秦谷美鈴 亲爱度剧情 / 第7话（adv_dear_hmsz_007）

- 她的台词：23 行（含用匿名标签说的 0 行）
- 出场的人：手毬、美鈴、ことね、リーリヤ、清夏、咲季、プロデューサー
- 场景：月村手毬个人 Live 结束后，她带着制作人去见手毬（0008）
- 世界线：亲爱度（秦谷美鈴）；制作人在制作的偶像：秦谷美鈴（0004、0066）

## 发生了什么
Live 后她带着制作人去见手毬，向手毬介绍他是「わたしの……プロデューサー」，说只想说一句话。手毬问她 Live 是不是很好，说没有「あなたたちが」也唱完了，已经不是全力唱到力竭的自己，靠的是特训和同班同学们的支持；她对这些一直沉默。手毬称同学是「頼れる仲間」，同学们（リーリヤ、清夏、ことね、咲季）却纷纷抱怨手毬让人担心，她笑说「仲間じゃないみたいですよ？」。听到手毬当天睡过头、前一晚到处打电话，她叫了一声「まりちゃん？」，宣布「予定変更」：她生气了，说燐羽在会怎么说，被手毬打断后说那就由她来骂——手毬总是任性暴走、让人担心，如果只是给她一个人添麻烦多少都可以。手毬说第一次听她说这种话；她说早该用自己的话好好生气。最后她邀请手毬来看自己的 Live、听自己的歌，手毬答应一定去。

## 行为模式
- 手毬炫耀、宣告自己的成果 → 不回应，一直沉默（0011、0014、0026）
- 别人当众数落手毬 → 先轻轻调侃，再在听到让人担心的细节后变得严肃（0031、0039）
- 真的生气 → 用敬语平静地宣布「怒ってます」，不提高声音，但不让对方打岔（0044、0047、0051）
- 想借别人（燐羽）的立场说话被挡回 → 改成以自己的名义说（0045～0047、0050～0051）
- 骂完之后 → 反省自己以前没这样做，转为真诚邀请（0055～0060）

## 关系
- 月村手毬：她叫「まりちゃん」（0039、0058），手毬叫她「美鈴」（0002、0043）。本篇是第一次当面说话（第6话 0004 她说完全说不上话）。手毬对她宣示自己已不需要旧队友；她生气地训了手毬，手毬说「はじめて聞いた。／美鈴が、私に、そんなこと言うの。」（手毬 0054）。她邀请手毬来看自己的 Live，手毬答应（手毬 0062～0063）。
- 賀陽燐羽：她叫「りんちゃん」（0045），想借燐羽说话，被手毬以「いない人の話はしないで」挡回（手毬 0046），手毬称燐羽「あいつ」（手毬 0050）。
- プロデューサー：她向手毬介绍是「わたしの……プロデューサー」（0004）。
- 手毬的同学们（リーリヤ、清夏、ことね、咲季）：本篇她没有直接和她们说话，只借她们的话调侃手毬（0031）。

## 档案类事实
- 以前没有用自己的话对手毬生过气（0055～0056；手毬 0054「はじめて聞いた」）
- 她要办 Live，邀请手毬来看（0059～0060）
