# 秦谷美鈴 亲爱度剧情 / 第8话（adv_dear_hmsz_008）

- 她的台词：29 行（含用匿名标签说的 0 行）
- 出场的人：美鈴、プロデューサー、ダンストレーナー、ボーカルトレーナー、ビジュアルトレーナー
- 场景：她的 Live 临近；制作人被三位训练师“围攻”后回来，门没锁，她已经在里面等着（0026～0028）
- 世界线：亲爱度（秦谷美鈴）；制作人在制作的偶像：秦谷美鈴

## 发生了什么
三位训练师开了第3回『秦谷美鈴のプロデューサーちゃんを詰める会』：她们对她进步之快很吃惊，又因为她平时不来上课想骂她，最后把气撒在制作人身上，要他保证让她改正素行。制作人筋疲力尽地回来，发现门没锁，她在里面说「おかえりなさい」，质问他是不是和美女们吃饭去了，说丢下担当偶像和别的女性吃饭「不誠実」。听完解释后她承认误会，摸着制作人的头说辛苦了，感谢他总是为自己费心。她说如果他是「わたしたち」的制作人，未来是否会不同，随即说这是无意义的话。她澄清：这几天每天上课，不是因为 Live 近了或有了干劲，而是听到令人怀念的歌声想起了从前——慢悠悠的她总被同伴拉着、催着快走，本该觉得麻烦却很开心。她说制作人不是同伴或朋友的替代，而是制作人，现在的她有他在，会把 Live 办得比当年的自己更好。

## 行为模式
- 看到制作人和别的女性出门 → 进屋等他，半开玩笑地质问“出轨”，用“担当偶像”的身份争宠（0030～0037、0040）
- 误会解开 → 痛快承认误会，转为安慰（摸头「よしよし」）（0039、0042）
- 被照顾、被为她费心 → 郑重道谢（0044、0047）
- 不小心说出对过去的遗憾 → 马上道歉、收回（0048～0050）
- 被误会动机（以为她有干劲了） → 特意澄清真正的原因（0051～0056）
- 制作人自嘲当不了替代品 → 明确定位他是“制作人”，表达信赖（0062～0064）

## 关系
- プロデューサー：她叫「プロデューサー」，以“担当偶像”自居，对他和别的女性吃饭表现出不满（0034～0035）；称他「有言実行」（0047）；说他不是同伴或朋友的替代，现在的她有他在（0062～0064）。制作人叫她「秦谷さん」。
- 旧组合的同伴（她称「仲間」「わたしたち」）：总是拉着、催着慢吞吞的她，她嘴上嫌麻烦，其实很开心（0057～0059）。
- 训练师们：本篇她没和训练师说话；训练师们因她不来上课想骂她，但被她的进步震住（ボーカルトレーナー 0009、0015）。

## 档案类事实
- 平时几乎不上课，但进步惊人（训练师 0008～0009、0015）
- 最近几天每天参加课程，原因是听到怀念的歌声、想起从前（0052～0056）
- 慢吞吞的她以前总被同伴拉着走，觉得很开心（0057～0059）
- 会摸人的头说「よしよし」（0042～0043）
