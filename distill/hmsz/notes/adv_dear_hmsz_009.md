# 秦谷美鈴 亲爱度剧情 / 第9话（adv_dear_hmsz_009）

- 她的台词：42 行（含用匿名标签说的 0 行）
- 出场的人：美鈴、手毬、プロデューサー
- 场景：她个人 Live 当天，开演前被制作人叫醒、演出结束后（0002、0007、0016）
- 世界线：亲爱度（秦谷美鈴）；制作人在制作的偶像：秦谷美鈴

## 发生了什么
Live 当天她在睡觉，被制作人叫醒。她说知道今天是自己的 Live、是和手毬约好来看的重要日子；这份从容不是余裕，而是知道放松才能唱出自己。演出后她问心意是否传到，制作人说“灵魂都在震颤”，她说「ほどほどに」努力有了回报；制作人看穿她想被夸，她说把看穿的事说出来效果减半，又说既然以后夸她努力的人会越来越少，就请他多夸夸她（制作人的回应没写进剧本，她答「はい！」）。手毬来到后台，说在最前排看到了、感受到了她的心情，坚持用语言说出「がんばったね」。她先否认，说只是听了手毬的歌想这么做而已，被手毬要求承认后才说「……うん」，哭了起来，说「まりちゃんなんか……嫌いです」，手毬回「私は好きだけど」，她慌了。她嗔怪制作人看着担当偶像哭还笑，制作人说果然有认可她努力的人，她说「ふたりめ」，并说今天也许是人生最好的一天。

## 她的关键台词
- 0008「まりちゃんが観にきてくれると／約束した、大切な日です。」——Live 对她的意义
- 0011「余裕……とは、すこし違います。／知っているだけです。」——从容的理由
- 0012「肩の力を抜いた方が、／わたしらしく歌えると。」——她对自己的歌唱方式的认识
- 0021「わたしなりに……ほどほどに……／がんばった甲斐が、ありました。」——承认努力，但仍加「ほどほどに」
- 0027「だめですよ、プロデューサー。／察したことを明かしてしまっては。」——想被夸却不肯直说
- 0032「そのぶん、褒めていただけますか？」——直接要求被夸
- 0048「わたし……そんなこと／ありません。」——被手毬夸努力时先否认
- 0049「まりちゃんの歌を聴いて……／そう、したくなった、だけで。」——努力的动机是手毬
- 0052「……うん。」——对手毬不用敬语，承认努力
- 0057「知りません……！　／まりちゃんなんか……嫌いです。」——哭着嘴硬
- 0060「ふぇっ！？」——被手毬说“喜欢”时慌乱
- 0065「担当アイドルの涙を見て／笑うなんて、趣味が悪いです。」——掩饰害羞，反过来怪制作人
- 0068「ふたりめ、です。」——认可她努力的第二个人
- 0070「わたし……今日が、／人生最高の日かもしれません。」——本篇情绪顶点

## 行为模式
- 重要的日子 → 依然先睡觉，被叫醒后从容，说明放松才能唱好（0001～0012）
- 想被夸 → 不直接说，等对方察觉；被戳破时说「だめですよ」，然后干脆直说「褒めていただけますか？」（0026～0032）
- 被说努力（尤其是被手毬） → 先否认、把功劳推给对方，被逼着承认后情绪决堤，哭着说反话（0048～0057）
- 被直白示好 → 慌得说不出话（「ふぇっ！？」「ちょ、ちょっと……！」「ああ、もう」）（0060～0063）
- 哭的样子被看到 → 转头埋怨对方「趣味が悪い」（0064～0065）
- 对手毬 → 用「うん」等不带敬语的回答（0052、0055）；对制作人始终用敬语

## 关系
- 月村手毬：她叫「まりちゃん」，手毬叫她「美鈴」。手毬守约来看 Live，坐最前排（手毬 0036），用语言对她说「がんばったね」（手毬 0046）；她被认可后哭着说「嫌いです」，手毬说「私は好きだけど。美鈴のこと。」（手毬 0059）。她对手毬说话时第一次出现不带敬语的「うん」（0052、0055）。
- プロデューサー：她叫「プロデューサー」，要他多夸自己（0032）；称自己是他的「担当アイドル」（0065）。制作人叫她「秦谷さん」，最后在报告里写「本当に……／よくがんばりましたね」（0072）。

## 档案类事实
- 重要的日子前也会睡觉，认为放松才能唱出自己的歌（0001、0011～0012）
- 这次 Live 是和手毬约好来看的（0008）
- Live 后被手毬夸「がんばったね」，哭了（0052～0057）
- 她说努力的动机是听了手毬的歌（0049）
- 说今天也许是人生最好的一天（0070）

## 不确定

- 0068「ふたりめ、です。」：认可她努力的“第二个人”，从上下文看第二个是手毬，第一个可能是制作人（第3话 0013～0014 制作人说她『がんばっている』，她说『久しぶりに言われました』），但剧本没明说。
