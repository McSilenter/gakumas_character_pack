# 秦谷美鈴 亲爱度剧情 / 第10话（adv_dear_hmsz_010）

- 她的台词：50 行（含用匿名标签说的 0 行）
- 出场的人：美鈴、手毬、プロデューサー
- 场景：她和手毬搬进同一间宿舍（相部屋）之后，制作人帮忙搬完家（0002～0003）
- 世界线：亲爱度（秦谷美鈴）；制作人在制作的偶像：秦谷美鈴（0074）

## 发生了什么
制作人帮她和手毬搬家，还办好了合住的手续。制作人说她们终于和好了；手毬说合不来的地方还是合不来，她说两人谈过了，决定就这样合不来地在一起，还说手毬讲过“没有我就活不下去”，手毬坚决否认。手毬说这次明白了自己一个人什么都做不成，又说那些「薄情なやつら」已经不是伙伴；她说以后有她在，饭、打扫、打扮什么都替手毬做。手毬嫌她把自己当小孩，要她陪自己自主训练，她一口拒绝，送手毬出门后去准备饭。她对制作人说这都是托他的福，然后第一次讲起自己当偶像的理由：和手毬同一天看了同一场 Live，以为自己憧憬那位偶像，其实是不甘心——好朋友的心被夺走了；她着迷的是憧憬太阳的手毬的侧脸，希望手毬、乃至全场都看着她。她说自己终究不是太阳，就想当手毬的翅膀，那也失败、分开了；手毬仍仰望天空、不看她，所以她决定自己去比太阳更高的地方。她重新说出梦想：成为顶级偶像，用自己涂满手毬所仰望的太阳和天空，让全世界只看着她。她请制作人今后继续协助，称他「わたしだけの、プロデューサー」。

- 0024「いくらでも迷惑を掛けてくださいね。」——对手毬的包容
- 0025「食事も、掃除も、身支度も……／なんだってやってあげますから。」——照顾欲
- 0030「それは嫌です。」——拒绝陪练，干脆
- 0038「またこんな気持ちになれるなんて……／……思いませんでした。」——对现状的感激
- 0041「まりちゃんと同じ日に、／同じライブを観て。」——当偶像的起点

- 0046「大好きな友達の心が、／奪われてしまったように感じて。」——真正的动机：嫉妒、不甘
- 0049「太陽に憧れる彼女の横顔にこそ、／見惚れていました。」——她着迷的是手毬
- 0050「わたしを見て欲しいと、願ったんです。」——愿望的核心
- 0055「ならばせめて、／彼女の翼になってあげたいと。」——在组合时的定位

## 行为模式
- 手毬否认说过的话 → 笑着坚持「確かに聞きました」，不跟她争（0013、0015）
- 手毬遇到困难、失去帮手 → 马上说“有我在”，主动揽下所有照顾（0023～0025）
- 被要求做她不想做的事（陪练） → 不找借口，直接「それは嫌です」（0030）
- 对方去努力 → 送行后自己开始做家务（0033～0034）
- 讲自己的过去 → 先说表面的说法（憧憬），再自己修正成真实的感情（不甘心、嫉妒）（0042～0046）
- 说梦想 → 用太阳、天空、翅膀的比喻，语气平静但内容极端、独占（0047～0066）
- 被理解、被接纳 → 再说一次「あなたを選んで、本当に、よかった」（0072）

## 关系
- 月村手毬：她叫「まりちゃん」（0006、0033），手毬叫她「美鈴」（手毬 0008）。两人已经和好、合住一间宿舍（0003、0007），关系是「合わないままで……／一緒にいよう」（0011）。她要照顾手毬的一切，手毬嫌她「子ども扱い」（手毬 0026）。她说当年是被手毬憧憬太阳的侧脸吸引，希望手毬看着自己（0049～0050），想当手毬的翅膀但失败了（0055～0056），现在要超过手毬仰望的太阳（0060～0065）。
- プロデューサー：她叫「プロデューサー」，说一切都托他的福（0036）；请他今后也协助（0070），称他「わたしだけの、プロデューサー」（0074）。手毬称他「美鈴のプロデューサー」（手毬 0005）。
- 手毬的同学们：她说「頼りになる仲間も、今後は／協力してくれないそうですしね」（0019），手毬接「あんな薄情なやつら」（手毬 0020）。

## 档案类事实
- 和手毬合住一间宿舍，手续是制作人办的（0003）
- 当偶像的契机：和手毬同一天看了同一场 Live（0041～0042）
- 她说那不是憧憬，而是好友的心被夺走的不甘（0043～0046）；她着迷的是手毬的侧脸，希望手毬和全场都看着她（0049～0051）
- 曾想当手毬的「翼」，失败后分开（0055～0056）
- 梦想：成为顶级偶像，用自己涂满手毬所仰望的太阳和天空，让全世界只看着她（0063～0066）
- 说要替手毬做饭、打扫、打理身边事（0025、0034）
- 不愿陪手毬自主训练（0030）

## 不确定

- 0041「同じライブ」、0042「同じアイドル」：那位偶像是谁本篇没写。
