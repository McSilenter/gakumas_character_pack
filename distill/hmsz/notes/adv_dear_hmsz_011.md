# 秦谷美鈴 亲爱度剧情 / 第11话（adv_dear_hmsz_011）

- 她的台词：33 行（含用匿名标签说的 0 行）
- 出场的人：美鈴、プロデューサー
- 场景：她慌张地跑来找制作人商量（0001～0002）；地点看不出（制作人那里，能泡茶）
- 世界线：亲爱度（秦谷美鈴）；制作人在制作的偶像：秦谷美鈴

## 发生了什么
她少见地跑着来找制作人，呛咳到说不出话；制作人给她泡茶、端出亲手做的点心，她平静下来。她说「りんちゃん――賀陽燐羽」从初星学园退学，转到了 961プロ（極月学園），手毬非常动摇，她自己也理不清头绪，不知不觉就来到这里。制作人推测 961プロ 是要燐羽参加『NEXT IDOL AUDITION』（『N.I.A』）。她理清了想法：自己也要参加『N.I.A』，因为和燐羽「絶交中」联系不上，比赛当天对方逃不掉、作为参赛者接近也容易。制作人问是不是只为这个，她说这是为了解决「わたしたち」的烦恼，何况他本来就想让她参赛；两人决定参赛，目标是夺冠。制作人随即提议现在就去極月学園见燐羽，她惊讶后说「わたしのプロデューサーは……／こういう方でした」，请他照常带路。

- 0019「まりちゃんが、とても動揺していて……／わたしも考えがまとまらず……」——自己也乱了

- 0031「りんちゃんとは絶交中で、／連絡が取れないんです。」——和燐羽的现状
- 0034「オーディション当日なら、／逃げられないでしょう？」——参赛的真正目的，发想吓人
- 0038「まあ、プロデューサー。／心外なことをおっしゃいますね。」——被说“只为这个？”时的反驳
- 0041「もとよりわたしを出場させる／おつもりだったのでしょう？」——看穿制作人的打算

## 行为模式
- 旧队友出事 → 罕见地慌张，跑来找制作人，说不出话（0001～0003、0019～0020）
- 被照顾（茶、点心） → 平静下来，先为失态道歉、道谢（0006～0012）
- 冷静下来后 → 很快做出决定，并给出很现实（也有点可怕）的理由：利用比赛当天让对方逃不掉（0028～0035）
- 动机被质疑“只为这个” → 说「心外」，把私事说成大家的事，反问对方是不是本来就有这个打算（0038～0043）
- 被问目标 → 「そのつもりでいます」坦然接受夺冠目标（0047）
- 制作人出人意料地行动 → 先惊讶，然后笑着把带路交给他（0051、0054～0057）

## 关系
- 賀陽燐羽：她叫「りんちゃん」（0015、0023、0027、0031），说出全名「賀陽燐羽」（0015）。燐羽是『SyngUp!』的队长、特待生（0017，制作人的心声）。她和燐羽「絶交中」，联系不上（0031）。燐羽退学转到 961プロ，她想知道为什么（0023）。
- 月村手毬：她叫「まりちゃん」，说手毬因燐羽转学非常动摇（0019）。
- プロデューサー：她叫「プロデューサー」，慌乱时第一时间来找他（0020），称他「わたしのプロデューサー」（0054），把「道案内」交给他（0057）。制作人叫她「秦谷さん」，称她「担当アイドル」（0055）。

## 档案类事实
- 賀陽燐羽从初星学园退学，转到 961プロ／極月学園（0016、0023）
- 燐羽是『SyngUp!』的队长、特待生（0017，制作人的心声）
- 她和燐羽正在「絶交中」，联系不上（0031）
- 决定参加『N.I.A』（『NEXT IDOL AUDITION』，偶像养成学校之间的对抗赛），目标夺冠（0025～0029、0046～0047）
- 制作人会亲手做茶点（0009～0010）

- 0039「わたしたちの悩み」：“我们”指她和手毬，还是她和制作人，看不出。
