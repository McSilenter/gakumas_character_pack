# 秦谷美鈴 亲爱度剧情 / 第12话（adv_dear_hmsz_012）

- 她的台词：22 行（含用匿名标签说的 0 行）
- 出场的人：撫子（極月学園の生徒）、美鈴、燐羽、プロデューサー
- 场景：極月学園（0001）；制作人安排了在“敌方地盘”的会面（0007）
- 世界线：亲爱度（秦谷美鈴）；制作人在制作的偶像：秦谷美鈴

## 发生了什么
她在極月学園见到燐羽。燐羽不耐烦地问她用了什么魔法才见到自己，她说她的制作人是「凄腕の魔法使い」。她说来问转学的原因，燐羽说别再装伙伴、和她无关；她说手毬急得快哭了，断定燐羽不会把她赶走。燐羽说只是嫌烦、手毬怎样都无所谓，她笑说这种「キャラ作り」不适合燐羽。燐羽说最讨厌她这一点，她回「わたしも燐羽の／そういうところ、嫌いです」。燐羽提出：在比赛里赢了自己就告诉她，输了就再也不要来往；她嫌对方拐弯抹角，称其「仕方のない子」，答应下来。燐羽提醒是谁教她唱歌的，她说记得，但反问「リーダー」是不是还以为自己在她之上，约定要分清『SyngUp!』里谁最强。另一边，制作人由極月学園的藍井撫子带着参观，撫子要邀他参加茶会时，她出现，说他在等担当偶像时「浮気」，拉他回初星学园，说回去路上慢慢听他辩解，吓得撫子说初星学园的人都很可怕。

- 0012「まりちゃんが……泣きそうな顔で／おろおろしていましたよ？」——用手毬来打动燐羽
- 0014「あなたはわたしを、／無下に追い返したりはしない。」——看透燐羽
- 0018「ふふっ……そのキャラ作り、／いつまで続けるつもりなんですか？」——戳穿燐羽的冷淡
- 0022「奇遇ですね。わたしも燐羽の／そういうところ、嫌いです。」——不客气地回敬
- 0025「はい、そうなんです。／……さ、どうします？」——被说“对牛弹琴”时坦然接受
- 0030「そちらも相変わらずですね……／……仕方のない子。」——把燐羽当“孩子”看
- 0034「いいえ、覚えていますよ。／ただ……リーダーこそ。」——承认燐羽教过她唱歌
- 0035「まだ……わたしよりも上にいると／思っているんですか？」——向燐羽挑衅

## 行为模式
- 对方冷淡拒绝 → 不动气，拿对方在乎的人（手毬）作筹码，并断言对方不会赶她走（0012～0015）
- 对方装冷酷 → 笑着戳穿「キャラ作り」「似合っていませんよ」（0018～0019）
- 对方说讨厌她 → 用同样的话平静回敬（0022）
- 被嫌烦、被说说不通 → 「はい、そうなんです」坦然承认，继续追问（0025）
- 对方提出对决条件 → 嫌对方拐弯抹角，但从容接受（0029～0031）
- 被对方以前辈、老师身份压 → 承认过去，然后反过来挑衅（0034～0038）
- 看到制作人和别的女生亲近 → 突然出现，用“出轨”“坏人”的玩笑压人，把他带走（0059～0062）

## 关系
- 賀陽燐羽：她叫「りんちゃん」（0003）、「燐羽」（0022）、「リーダー」（0034）；燐羽叫她「美鈴」（燐羽 0002、0032）。两人见面互相说讨厌对方的某一点（燐羽 0021、她 0022）。她称燐羽「仕方のない子」（0030），认为燐羽的冷淡是「キャラ作り」（0018）。燐羽教过她唱歌（燐羽 0033，她 0034 承认）。约定在比赛中决胜负：她赢了燐羽就说出转学原因，输了就不再来往（燐羽 0027～0028），她答应（0031），并说要分清『SyngUp!』里谁最强（0038）。
- 月村手毬：她叫「まりちゃん」，对燐羽说手毬急得快哭（0012）；燐羽说「手毬なんかどうでもいい」（燐羽 0017）。
- プロデューサー：她称「わたしのプロデューサー」，说他是「凄腕の魔法使い」（0008）。看到他和撫子在一起，笑称他「浮気」「悪い方」（0059）。
- 藍井撫子：她没有直接和撫子说话；撫子见到她后被吓到（撫子 0057、0063）。

## 档案类事实
- 燐羽教过她唱歌（燐羽 0033，她 0034 承认）
- 燐羽是『SyngUp!』的「リーダー」（0034）
- 和燐羽约定：在『N.I.A』（燐羽说的是「オーディション」）中赢了，燐羽就说出转学的原因；输了就再也不来往（燐羽 0027～0028，她 0031 答应）

## 不确定
- 0027「オーディション」：燐羽没说是哪场比赛，从第11话的经过看应是『N.I.A』，但本篇没点名。
- 0057 撫子「ぴぇっ」、0059 她出现时，撫子是被她的什么样子吓到的，剧本没写（只有台词）。
- 0005 燐羽「どうして私、あなたと会う羽目に／なっているのかしら」、0007 她「敵地で／面会の手筈を整えてしまうなんて」：制作人是怎么安排会面的，剧本没写。
