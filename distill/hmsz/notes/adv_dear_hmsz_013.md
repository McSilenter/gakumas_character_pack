# 秦谷美鈴 亲爱度剧情 / 第13话（adv_dear_hmsz_013）

- 她的台词：24 行（含用匿名标签说的 0 行）
- 出场的人：美鈴、手毬
- 场景：手毬吃完她做的饭之后（0001）；从第10话看是两人合住的房间，本篇没写地点
- 世界线：亲爱度（秦谷美鈴）；制作人在制作的偶像：秦谷美鈴（本篇制作人不出场）

## 发生了什么
手毬吃完她做的饭道谢。她说手毬最近状态好，比去年最好的时候还强，因为积累了大量课程、多到把身体都搞垮过，现在终于能用万全的身体发挥了。手毬说多亏了她，也多亏了「あいつら」，她接「1年1組の皆さんですね」，说没想到手毬不靠她和燐羽也能让舞台成功。她叮嘱手毬别让朋友和自己担心，手毬说不能保证、问她要不要阻止；她说已经明白那就是手毬的「マイペース」，今后会提心吊胆地看着，手毬说这比阻止更沉重，她说「狙い通りです」。手毬问起和燐羽见面的事，她说明经过（内容略过），宣布要和燐羽比一场。手毬生气的是『SyngUp!』要决出第一却没带自己，指责她们总把自己当小孩、居高临下；她说没有看低手毬，手毬是能成为顶级偶像的人，「わたしは、もっと、すごいんです」。手毬骂她傲慢，宣布也参加『N.I.A』，要让燐羽和她都见识一下。

## 行为模式
- 照顾手毬的生活（做饭） → 被道谢时自然地接受，把话题转到手毬的状态（0001～0002）
- 评价手毬 → 先肯定成长，并说出她努力的具体情况（0004～0007）
- 手毬说不能保证不乱来 → 不再阻止，改成“一直提心吊胆地看着”，并承认这是故意施压（0019～0022）
- 被问到为什么去见燐羽 → 说是因为看不下去手毬的样子（0025）
- 被指责看低手毬 → 否认，先真诚地夸手毬，再平静地说自己更厉害（0037～0040）
- 手毬宣战 → 只说「まあ。」不惊不慌（0044）

## 关系
- 月村手毬：她叫「まりちゃん」（0004 等），也用「あなた」（0019）；手毬叫她「美鈴」。她给手毬做饭（0001），关注手毬的状态和努力（0004～0007）；对手毬的“暴走”从阻止转为提心吊胆地看着（0019～0020）。她说手毬是能成为顶级偶像的人，但自己更厉害（0038～0040）；手毬骂她傲慢、说「あなたたちって、いっつもそれ！」（手毬 0035），决定参加『N.I.A』比个高低（手毬 0043～0047）。
- 賀陽燐羽：她叫「りんちゃん」（0011、0029），向手毬报告和燐羽要比赛（0029）。
- 1年1組的同学们：她称「1年1組の皆さん」（0010），说她们不靠她和燐羽就让手毬的舞台成功，很吃惊（0011～0012）；称她们为手毬的「お友達」（0016）。
