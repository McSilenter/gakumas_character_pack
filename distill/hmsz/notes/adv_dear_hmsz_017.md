# 秦谷美鈴 亲爱度剧情 / 第17话（adv_dear_hmsz_017）

- 她的台词：30 行（含用匿名标签说的 0 行）
- 出场的人：手毬、美鈴、プロデューサー
- 场景：『N.I.A』中，手毬在选拔中赢了燐羽之后，来她这里报告（0001～0003、0053）；最终日之前（0076～0077）
- 世界线：亲爱度（秦谷美鈴）；制作人在制作的偶像：秦谷美鈴（0039）

## 发生了什么
手毬兴奋地跑来报告赢了燐羽，她说当然亲眼看到了，恭喜手毬「よく……がんばりましたね」；又说这是手毬拼命上课、到处折腾人、按自己的步调跑来的结果，「1年1組の皆さんを犠牲にした／甲斐がありましたね」，被手毬说话里带刺，她提醒要一个个当面道谢。手毬向她和制作人道谢，提议让制作人以个人名义制作「私たち3人」，制作人累得说到极限了；她说「その人は……わたしだけの／プロデューサーなんですから」，被手毬意味深长地「ふーん」，她慌了说要生气了。制作人说没有制作人还能维持组合 3 年真了不起，她说是因为有「素敵なリーダー」。制作人去休息后，她告诉手毬：手毬和燐羽今天的对话被传到网上，制作人刚才一直在奔走、视频都删掉了，但看过的人的记忆删不掉；燐羽的粉丝很感谢手毬拼命挽留了「燐羽様」。手毬担心燐羽会不会继续当偶像，她说能说的话都说尽了，剩下能做的只有唱歌；称手毬是「わたしのライバル」，约定在『N.I.A』最终日的决战中办一场让所有人憧憬的 Live，把燐羽的梦想夺回来。

- 0011「1年1組の皆さんを犠牲にした／甲斐がありましたね。」——祝贺里夹着讽刺
- 0014「ひとりずつ、直接言わないと／伝わりませんよ。」——教手毬当面道谢
- 0032「まあっ、まるでわたしたちが／問題児であるかのように。」——对制作人诉苦的反应
- 0039「その人は……わたしだけの／プロデューサーなんですから。」——对制作人的独占
- 0041「な、なんですか、その言い方。」——被手毬看穿后慌乱
- 0043「も、もう！　／怒りますよ、まりちゃん！」——害羞时的“生气”
- 0047「素敵なリーダーが、いましたから。」——称赞燐羽
- 0056「ふふ……本音でお話、できましたね。」——笑看手毬的窘态
- 0062「すでに見てしまった人の記憶は／消せませんが。」——补刀
- 0069「歌うことだけ。」——剩下能做的事

## 行为模式
- 祝贺手毬 → 先郑重恭喜、夸努力，再夹一句讽刺（0004～0011）
- 手毬说感谢别人 → 提醒要一个个当面说（0014）
- 被别人当作问题儿童 → 「まあっ、まるでわたしたちが」装作委屈（0032）
- 别人想“分享”她的制作人 → 笑着宣示「わたしだけの」，被调侃后慌乱、脸红式地说要生气（0038～0043）
- 手毬出糗 → 笑着说她说出了真心，再补刀（0056、0062）
- 手毬不安 → 不安慰空话，指出能做的事（唱歌），并把对方定位为“我的对手”来鼓舞（0068～0073）

## 关系
- 月村手毬：她叫「まりちゃん」「あなた」；手毬叫她「美鈴」。手毬赢了燐羽后先来向她报告、道谢（手毬 0001～0002、0016～0017）。她称手毬为「わたしのライバル」（0073），手毬「えっ」之后高兴地答「うんっ！」（手毬 0074～0075）。两人约定在最终日决战（0076～0078）。手毬看穿她对制作人的独占欲，她慌了（0040～0043）。
- プロデューサー：她称「わたしだけの／プロデューサー」（0039）。制作人说同时制作『SyngUp!』的两个人太累了（0030～0031），并说照顾手毬是为了她（0025～0026）。她告诉手毬制作人为删除流出视频奔走（0050～0051）。
- 賀陽燐羽：她称「素敵なリーダー」（0047）、「りんちゃん」（0064）、「燐羽」（0080）。燐羽的粉丝称燐羽「燐羽様」（0065，她转述）。她要和手毬一起把燐羽的梦想夺回来（0080）。
- 1年1組的同学们：她说手毬「犠牲にした」她们（0011）。

## 档案类事实
- 手毬在『N.I.A』里赢了燐羽，她在场看到了（0003；手毬 0002）
- 『SyngUp!』没有制作人，维持了 3 年（制作人 0045），她说因为有优秀的队长（0047）
- 手毬和燐羽的对话被传到网上，制作人删掉了所有视频（0050～0051、0059）
- 燐羽的粉丝感谢手毬挽留了燐羽（0064～0065）
- 『N.I.A』最终日她要和手毬决战（0076～0077）

## 不确定
- 0030～0031：制作人说「もしも『SyngUp!』をふたり同時に／プロデュースしたら」，从 0023～0026 看制作人实际上也在帮手毬（处理炎上、与别校的纠纷），但是不是正式担任手毬的制作人，剧本没交代。
- 0050～0053：手毬和燐羽说了什么不在本篇，她只说「本音でお話、できましたね」（0056）。
- 0080「燐羽の夢」：燐羽的梦想是什么，本篇没写。
