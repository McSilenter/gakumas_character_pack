# 秦谷美鈴 亲爱度剧情 / 第18话（adv_dear_hmsz_018）

- 她的台词：16 行（含用匿名标签说的 0 行）
- 出场的人：手毬、美鈴、プロデューサー
- 场景：『N.I.A』最终日（『FINALE』）前，制作人开会讨论对付手毬的对策，手毬在场（0001～0006）；地点看不出
- 世界线：亲爱度（秦谷美鈴）；制作人在制作的偶像：秦谷美鈴

## 发生了什么
制作人要讨论『FINALE』中如何对付强敌月村手毬，手毬却也在场，说之后要和她去买东西，她确认「はい、そうなんです」，并让手毬捂住耳朵听“悄悄话”。制作人说『FINALE』剩下手毬、她和白草四音，燐羽辞退了；她推测是和 961プロ 的契约，问燐羽的粉丝把票投给谁。制作人说手毬的票大涨，她笑说偶像的粉丝像本人，爱「『燐羽様』」的人很讲义气；手毬最近状态绝佳，她说是「がんばってサポートした成果」。制作人说手毬本来实力忽高忽低，手毬（捂着耳朵）抗议被说坏话，她请制作人继续。她说状态好的手毬真的很厉害，能唱到最后的话连『一番星』也不会输；她说月村手毬的魅力终于传达给大家了，摸着手毬的头说「可愛く素敵な……わたしのライバル」，正因如此「勝ちますよ」，『SyngUp!』第一是她。

## 行为模式
- 手毬在场碍事 → 不赶她，用哄小孩的方式让她捂耳朵（0014）
- 谈论对手 → 情报冷静分析（燐羽辞退、粉丝流向），同时真心夸对手（0019～0024、0034～0035）
- 对手的状态好 → 把功劳说成自己支援的成果，开心（0027）
- 手毬抗议 → 不理会，催制作人继续（0032）
- 夸完对手 → 摸对方的头，然后平静宣告自己会赢（0040～0043）

## 关系
- 月村手毬：她叫「まりちゃん」，手毬叫她「美鈴」。两人约好之后去买东西（手毬 0011，她 0013 确认）。她把手毬当成对手兼要照顾的孩子：让她捂耳朵（0014），摸她的头（手毬 0041），称她「可愛く素敵な……わたしのライバル」（0040）；说手毬状态好时连『一番星』也赢不了她（0035），但自己会赢（0042～0043）。
- プロデューサー：她叫「プロデューサー」，开会时让他继续说（0016、0032）。
- 賀陽燐羽：她推测燐羽辞退『FINALE』是和 961プロ 的契约（0019）；燐羽的粉丝称燐羽「燐羽様」（0024）。

## 档案类事实
- 『FINALE』是赌上优胜 Live 的公开选拔（手毬 0003）；剩下月村手毬、秦谷美鈴、白草四音 3 人，賀陽燐羽辞退（0017～0018，制作人说的）
- 燐羽辞退后前三名票数大涨，尤其是手毬（0021～0022，制作人说的）
- 她说自己（和制作人）一直在支援手毬（0027）
- 之后和手毬约好去买东西（0011～0013）
