# 秦谷美鈴 亲爱度剧情 / 第21话（adv_dear_hmsz_021）

- 她的台词：29 行（含用匿名标签说的 0 行）
- 出场的人：美鈴、手毬、プロデューサー、燐羽（回放）
- 场景：『Hatsuboshi IDOL FESTIVAL』（『H.I.F』）本战当天，她上场前（0001、0012～0013）
- 世界线：亲爱度（秦谷美鈴）；制作人在制作的偶像：秦谷美鈴

## 发生了什么
『H.I.F』本战当天，她又在睡觉，被制作人叫醒，故意说「朝、目が覚めたら……／プロデューサーが、／すぐそばにいてくださいました」，看制作人慌张来缓解紧张。她说当然知道今天是本战、马上轮到自己，而且「とても……緊張しています」。插入第20话燐羽邀手毬去特训的片段（0017～0019）后，她说这是和跟燐羽一起特训过的手毬的重要再战，而且和制作人约好要献上『一番星』。制作人说那是『SyngUp!』的目标、賀陽継曾持有的称号，手毬进来接话说现在是十王星南的称号。手毬说来确认她醒着、也想在上场前看看她的脸；她说请尽管看，这是今天要战胜手毬、成为『一番星』的偶像的脸。手毬提醒夺冠热门不止她们俩，她说「眼中にありません」——好不容易手毬看向自己了，不会分心看别的偶像，满身破绽也要挑战、要赢，还拉制作人同意；制作人说这是反派台词，她说前辈们一定觉得他们是狂妄的后辈和她的制作人。她向手毬夸「素敵でしょう、／わたしのプロデューサーは」，手毬说她在秀恩爱、自己才不会；她说要把这句话录下来。手毬说今天也只看着她唱，两人约定各自办一场精彩的 Live。

## 行为模式
- 被叫醒 → 用让人误会的说法逗制作人，看他慌张来放松（0008～0011）
- 被说不紧张 → 否认，说自己很紧张（0016）
- 手毬提醒她注意其他对手 → 断然说不放在眼里，理由是只想看手毬（0035～0038）
- 自己的态度被说是大意、破绽 → 不否认，干脆说带着破绽也能赢（0039～0040、0061）
- 被说像反派 → 拉制作人下水（「まるで自分はそうではないかの／ようなお言葉」）（0043～0045）
- 在手毬面前 → 直白地炫耀制作人（0052）；手毬说“我才不会”时抓话柄（0058）

## 关系
- 月村手毬：她叫「まりちゃん」「あなた」，手毬叫她「美鈴」。手毬来确认她醒着、上场前看她的脸（手毬 0027～0030）。她说手毬好不容易看向她了，她不看别的偶像（0037～0038）；手毬答应今天也只看着她唱（手毬 0062）。手毬说她「惚気」（手毬 0055）。
- プロデューサー：她叫「プロデューサー」，称「わたしのプロデューサー」（0052）。和他约好献上『一番星』（0021～0022）。她用逗他的方式缓解紧张（0011）。手毬说制作人越来越像担当偶像（手毬 0048）。
- 賀陽燐羽：她叫「りんちゃん」（0020），燐羽给手毬做了特训（0017～0020）。
- 前辈们：她说前辈们一定觉得她和制作人是狂妄的后辈和她的制作人（0044～0045）。

## 档案类事实
- 『H.I.F』本战当天，上场前还在睡觉（0002）
- 『一番星』曾是『SyngUp!』的目标、賀陽継持有的称号，现在是十王星南的（制作人 0023，手毬 0025）
- 她的目标是在『H.I.F』战胜手毬、成为『一番星』（0032）
- 这是手毬第一次参加『H.I.F』（手毬 0063）

## 不确定
- 0017～0019：和第20话 0040～0044 燐羽、手毬的台词一样，是插入的回放；是谁的回忆剧本没写（从 0020 看像是她在想）。
- 0016「とても……緊張しています」：是真话还是逗制作人，看不出。
- 0023 制作人说『一番星』是賀陽継「かつて持っていた称号」，和第20话 0066～0068（像太阳的歌姬、燐羽的姐姐也被称作『一番星』）放在一起，第20话那位歌姬应当就是賀陽継；但两篇都没有在同一句里把名字和“燐羽的姐姐”连起来。
