# 秦谷美鈴 亲爱度剧情 / 第22话（adv_dear_hmsz_022）

- 她的台词：40 行（含用匿名标签说的 0 行）
- 出场的人：美鈴、プロデューサー、あさり先生、学園長
- 场景：『H.I.F』当天，演出结束、十王星南被宣布为「夏の一番星」之后（0001～0004）；紧急会议，地点看不出
- 世界线：亲爱度（秦谷美鈴）；制作人在制作的偶像：秦谷美鈴

## 发生了什么
学园长宣布夏天的『一番星』是十王星南。制作人要开紧急会议，她却先问制作人「大丈夫ですか」：他们输了，傲慢的言行只有在有实力时才被允许，没拿出结果，积累的傲慢会反弹到自己身上，她担心优秀的制作人在不习惯的状况下受伤。制作人反问她才是要不要紧，她说高兴他担心自己，又说自己并不是不败的精英——从进入初星学园中等部起，一直过着输的日子。制作人猜到她的意思，说那是极傲慢的想法；她承认：『SyngUp!』的太阳『一番星』賀陽継，和她的妹妹、组合伙伴賀陽燐羽，是她要跨越的墙，从入学（还没上过任何课）时就是。她说每天都在输，用篠澤的话说是「ままならない日々」，但她不是以苦为乐的人，一直很不甘心，和今天此刻一样。那种心情不是败北感，而是浓稠滚烫的东西在胸中翻涌、积存；她不发泄，因为那会减少，这份「どろどろ」是实现愿望必需的。制作人说她只是把怨恨锁进了宝箱，她说不能让朋友和重要的对手担心，不会让人看到眼泪；被问“对制作人也是吗”，她说现在有他在，就只对他特别分享这份黑色的心情。之后插入あさり先生关于“败北后的会议是照顾担当偶像的心”的话。最后她说托他的福心里像雨过天晴、架起了彩虹，「一緒に、この恨みを晴らしましょうね」，制作人心里怀疑这样真的好吗。

- 0026「このふたりが……わたしにとって、／超えるべき壁だったんです。」——一直以来的目标
- 0029「ご質問への回答は……／もちろん、『はい』です。」——入学时就以她们为目标，傲慢地承认

## 行为模式
- 输了 → 不表现出受打击，先关心对方（0005～0012）
- 被关心 → 「嬉しいです」坦然接受，再把话题转到自己的过去（0015～0020）
- 对方猜中她的傲慢想法 → 「お察しの通りです」，毫不掩饰（0022～0023、0029）
- 不甘心时 → 不发泄，不哭给人看，把它当成能量积存起来（0040～0045、0049～0050）
- 被问“对制作人也不哭吗” → 沉默后，决定只对制作人分享（0052～0054）
- 分享完之后 → 心情转晴，把“恨”变成和制作人一起的目标（0058～0061）

## 关系
- プロデューサー：她叫「プロデューサー」「あなた」，输了先担心他（0006～0012）；她不在人前流泪，但现在有他在，所以只对他分享「黒い気持ち」（0050～0054），感谢他让自己心情放晴（0058～0060），要和他一起「この恨みを晴らしましょう」（0061）。制作人叫她「秦谷さん」。
- 賀陽継：她称「わたしたち『SyngUp!』の／太陽だった、『一番星』賀陽継」（0024），是她从中等部入学起要跨越的「とても高い壁」（0026、0030）。
- 賀陽燐羽：她称「その妹で、／ユニットの仲間だった賀陽燐羽」（0025），也是她要跨越的墙（0026）。
- 篠澤（広）：她提到「篠澤さん流にいうのなら」「ままならない」，说自己和她不同，不是以苦为乐的人（0032～0033）。
- 朋友们和「大切な敵」：她不想让他们担心，不在他们面前流泪（0049～0050）。

## 档案类事实
- 『H.I.F』夏季的『一番星』是十王星南（学园长 0001～0002），她这次输了（0008）
- 从初星学园中等部入学起就一直在“输”（0019～0020）
- 賀陽継是『SyngUp!』的太阳、『一番星』，賀陽燐羽是她的妹妹（0024～0025）
- 从入学时（还没上过任何课时）起就把継和燐羽当成要跨越的墙（0026～0029）
- 一直很不甘心，不发泄，把这份「どろどろ」当成实现愿望必需的东西（0034、0041～0045）
- 不在朋友和对手面前流泪，除非「余程のこと」（0049～0050）
- 对制作人特别分享自己的「黒い気持ち」（0053～0054）

## 不确定
- 0019「初星学園の中等部に／入学してから、ずぅ……っと。」、0020「負け続ける日々でした。」与第19话 0005『中等部ナンバーワンになった／あの日』：一边说中等部以来一直在输，一边像是说她中等部时成为过第一（第19话那句没有主语）；第25话 0034 又说手毬才是被称为中等部 No.1 的偶像。已在第25话笔记标【冲突】，这里只记出处。
- 0024「わたしたち『SyngUp!』の／太陽だった、『一番星』賀陽継」与第15话 0039（燐羽是『わたしたちの太陽』）、第20话 0029（燐羽是『陰った太陽』）：“太阳”在不同篇里指継和燐羽两个人。第20话 0069 说継引退后憧憬转到燐羽身上，可能就是这样衔接的，但剧本没明说。
- 0055～0057：あさり先生的话插在中间，是制作人回想起的建议还是当场，剧本没写；0062 制作人心里问「あさり先生……本当に、／これで良かったんですか」，看起来是事先得到的建议。
- 0058「あなたのおかげで」：中间制作人做了什么（0054 之后）剧本没写，可能有没写进剧本的对话或选项。
- 【已确认 2026-10-31】「太陽」一开始指継，継引退后指燐羽（conflicts 三·4）。
