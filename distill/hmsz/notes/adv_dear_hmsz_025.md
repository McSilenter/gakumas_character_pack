# 秦谷美鈴 亲爱度剧情 / 第25话（adv_dear_hmsz_025）

- 她的台词：45 行（含用匿名标签说的 0 行）
- 出场的人：美鈴、プロデューサー、燐羽、出会った頃の燐羽（回想）
- 场景：集训期间她问制作人自己是不是走偏了；之后两人先回天川休养，「数日後」再谈（0048、0051）
- 世界线：亲爱度（秦谷美鈴）；制作人在制作的偶像：秦谷美鈴

## 发生了什么
她郑重地问制作人「わたし、迷走していますか？」，制作人简短地回答了（回答没写进剧本），她谢他“简短的好回答”，要他在自己发火前解释。制作人说照这样特训，冬季『H.I.F』赢不了，她也同意：失去自己理想的偶像样子，就不能称为偶像。她问为什么不早点指出，制作人说因为她走偏时会拼命上课，她连声「まあ？」逼近，要他慎重回答。制作人解释：和伙伴们特训提升了基础能力；而且他现在等于同时制作她和手毬两个问题儿童，这次特训对手毬效果极好，已经让手毬走上正轨。她慰劳制作人，听他说手毬比预想的厉害，她笑说「まりちゃんはすごいんです」，手毬曾被称为中等部 No.1 偶像，是唯一一个她允许在自己前面唱歌的偶像，请他别再小看。制作人累得快哭，她说他作为秦谷美鈴的制作人做得最好，接下来轮到自己了；制作人说今后专心制作她一个人，首先回天川好好休息，她「大賛成」。几天后，两人都恢复了。她说刚和手毬、燐羽通过电话，转达燐羽「子守は任せておいて」，又怀疑制作人什么时候和燐羽变亲近，叮嘱他别靠近「りんちゃん」——燐羽有个「とんでもない悪癖」（插入刚认识时燐羽「ちゅっ♡」的回想），要保持两米以上距离。她以为要开会，制作人却说看来她还在走偏，提议「今日もだらだらしましょう」，请她教他怎么无所事事；她说今天真奇妙，「――喜んで」，邀他去中庭晒太阳。

## 行为模式
- 察觉自己有问题 → 主动、郑重地问制作人（0001～0003）
- 被直接说中 → 用客气的反话道谢，然后笑着要求解释，带压力（0004～0005）
- 制作人的理由让她不满 → 连声「まあ？」逼近，「わたしは、まだ、冷静ですが」（0013～0016）
- 得知制作人为手毬操劳 → 慰劳他（0027、0040～0041）
- 别人低估手毬 → 笑着反问“你现在才知道？”，郑重要求不再小看（0031～0036）
- 制作人和燐羽有交流 → 「ふーん」，借“燐羽有恶习”为由让他保持距离（0059～0071）
- 被提议休息、无所事事 → 立刻高兴地赞成，并主动安排（晒太阳）（0049～0050、0081～0083）

## 不确定
- 【冲突】「中等部ナンバーワン」是谁：本篇 0034 她说手毬是「中等部ナンバーワンアイドル。／そう呼ばれていた子ですよ。」；第19话 0005 她说『中等部ナンバーワンになった／あの日ですら……ここまででは。』，那句没有主语，最自然的读法像是她自己成为中等部第一的那天（也可能是指『SyngUp!』或手毬成为第一的那天）。另外第22话 0019～0020 她说从中等部入学起『負け続ける日々でした』。三处放在一起，中等部第一到底是谁、她自己算不算，对不上，请确认。
- 0003～0004：制作人对「わたし、迷走していますか？」的回答没写进剧本（她说是「短くていいお返事」，从 0006～0007 看是肯定的回答）。
- 0058 燐羽「プロデューサーに、／子守は任せておいてって伝えて。」：是电话里的声音、还是她回想刚才电话的内容，剧本没标（0057 她说「さきほど電話をしたばかりです」）。「子守」指照看手毬，从上下文推测。
- 0068『出会った頃の燐羽』：插入的回想；「悪癖」具体是什么（亲人？）她说「わたしの口からは……／言えない」（0069），剧本没明说。
- 0048「天川」：是什么地方（学园所在地？），本篇没解释。
- 0075 制作人说「まだ迷走が／続いているようですね」，指她还想开会、不够悠闲，是制作人的看法。
