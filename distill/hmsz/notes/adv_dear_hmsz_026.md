# 秦谷美鈴 亲爱度剧情 / 第26话（adv_dear_hmsz_026）

- 她的台词：53 行（含用匿名标签说的 0 行）
- 出场的人：美鈴、プロデューサー
- 场景：接第25话结尾，两人在晒太阳、闲聊的休息日（0001、0071），地点看不出（第25话说去中庭）
- 世界线：亲爱度（秦谷美鈴）；制作人在制作的偶像：秦谷美鈴

## 发生了什么
她和制作人一起晒太阳，想起两人初次见面：那天制作人一直静静等她睡醒，制作人说她身上有数据看不出的存在感，决心无论如何都要挖她。听到制作人说「秦谷美鈴のプロデューサーですから」，她忽然明白了自己「迷走」的真相：急急忙忙的样子不是她心中的偶像，也不是被制作人相中的她；原因在制作人——他一直给她很好的制作，她想作为回报献上『一番星』却没做到，所以才焦躁。她向制作人道歉“没能守约”，说这不是「くらい」的小事，比他想的痛得多，现在还痛，想听他说温柔的话。制作人先说了不合要求的话（没写进剧本），戳了她额头，又提醒她靠得太近会被拍成绯闻；然后说她没有违约，只是「少々遅れているだけ」，焦躁全是白费，可以停下。她笑他没法把漂亮话说到最后，两人「似た者同士」，决定不再焦急、慢慢履行约定。制作人说猎物已升级为「トップアイドル」，她说学内的对手只有月村手毬一人，但为了向他献上星星、在高处打哈欠，要让所有初星偶像屈服。制作人提议『選抜試験』前开一场「ごくごく普通のライブ」，她要借此纠正“秦谷美鈴在夏季『H.I.F』被挫了锐气”的看法，最后又提议换个地方再睡一觉。

## 行为模式
- 闲适的时候 → 回忆两人初次见面，感谢制作人的眼光（0003～0006、0010）
- 想通了自己的问题 → 当场说出，并把“原因”归到制作人身上来吊他胃口，再说其实是他制作得太好（0013～0024）
- 没能兑现对制作人的承诺 → 直接道歉，承认很痛，并主动要求他安慰（0031、0036～0039）
- 制作人的话不合她的要求 → 指出「リクエストと違いますよ？」，被戳额头时抗议（0040～0041）
- 被提醒距离太近 → 少见地慌张道歉（0044）
- 制作人说好话却没说到最后 → 吐槽，再笑着接受「お互い様」（0050、0052）
- 恢复状态后 → 说出傲慢的大目标（让所有初星偶像屈服），但用“在高处打哈欠”这样的悠闲说法（0056～0058）
- 被认为输了、锐气受挫 → 想用一场「ほどほど」的演出纠正，重点在“我的鼻子不会折”（0066～0069）
- 话题结束 → 提议换个地方再睡（0072）

## 关系
- プロデューサー：她叫「プロデューサー」「あなた」，制作人叫她「秦谷さん」（制作人 0045）。初次见面时他等她睡醒（0006）、决心挖她（制作人 0009）；她感激他「素敵なプロデュース」（0023）、给她铺好的路（0024），想献上『一番星』作回报（0025）。她因为没能兑现而痛苦（0037～0038），向他索要温柔的话（0039）；他说她没违约、只是迟到（制作人 0046）。她说两人是「似た者同士」（0052），要为他「星を捧げる」（0056）。
- 月村手毬：她说学内的对手「あくまで月村手毬ただひとり」，其他偶像不放在眼里（0055～0056）。
- 尊敬する先輩：她说只是输给尊敬的前辈一次（0027），从前情看指夏季『H.I.F』输给十王星南（第22话），本篇没点名。

## 档案类事实
- 初次见面时她在睡觉，制作人静静等她醒来（0004～0006；制作人 0007～0009）
- 制作人认为她有数据看不出的偶像存在感（制作人 0008）
- 她自认被说成「傲岸不遜な秦谷美鈴」（0034，她自己的说法）
- 她的「迷走」原因：想把『一番星』献给制作人作回报，没做到而焦躁（0025～0026）
- 学内她认定的对手只有月村手毬（0055）
- 她在夏季『H.I.F』败北（0066）
- 下一步：『選抜試験』之前开一场普通的 Live（制作人 0060～0064；她 0065）
- 制作人说今后的目标（猎物）是「トップアイドル」（制作人 0054）

## 不确定
- 0039～0041：她要温柔的话，制作人说了什么、为什么戳她额头没写进剧本；0042「まあ。」之后制作人说「撮影されたら、スキャンダルに／なりかねない距離」（0043），推测她靠得很近，剧本没写动作。
- 0027「尊敬する先輩」、0029「高い壁」没点名；按前情，前者像十王星南、后者像賀陽継（第22话 0024～0026），属推测。
- 0028「中間目標」指什么（『H.I.F』？『一番星』？）没说明。
- 0060『選抜試験』：本篇第一次在她的线里出现，是什么考试、何时举行没交代。
- 0054 制作人说猎物「より豪華になりました。／トップアイドルと呼ばれるほどに」：指具体某个偶像（星南？）还是“顶级偶像”这个目标，看不出。
- 【译文】0069 原文「わたしの鼻は、／折れることなどないのだと。」（我的鼻子不会被折断——呼应 0066「鼻柱を叩き折られた」），译文写成“啊、真遗憾。我的脚明明就好好的呢。”，完全不对。
