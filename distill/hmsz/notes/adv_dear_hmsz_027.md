# 秦谷美鈴 亲爱度剧情 / 第27话（adv_dear_hmsz_027）

- 她的台词：63 行（含用匿名标签说的 0 行）
- 出场的人：美鈴、プロデューサー
- 场景：第26话说的「ごくごく普通のライブ」刚结束（0001～0004）；之后她带制作人去两人初次见面的「お昼寝部屋」（0008～0010）
- 世界线：亲爱度（秦谷美鈴）；制作人在制作的偶像：秦谷美鈴

## 发生了什么
她开完「ごくごく普通のライブ」，制作人说她把全校学生的心都涂成了漆黑、被秦谷美鈴填满。她邀制作人去一个地方——两人初次见面的「とっておきの、お昼寝部屋」，说想在安静的地方谈谈彼此。制作人说两人已经做了达成目标所需的自我开示，她承认「契約ありき」的适度距离也不错，但「気が変わった」，想要更多的他；制作人用公事化的说法答应，她纠正他应该说「あなたのことを教えてください」。制作人问她成为偶像前是什么样子，她先说自己查过制作人的兄弟姐妹，又说自己有一个很可爱的『お姉ちゃん』——就是月村手毬：秦谷家和月村家父母很要好，两人从懂事前就像姐妹一样长大。小时候她早熟、被「冷え冷えとした全能感」折磨、对世界冷眼相看，比现在坏七倍；圆滚滚、爱哭爱闹的手毬让她第一次体会到『挫折』和『やりがい』，学会谦虚，一直在身边吵吵闹闹地温暖她，让她一点点变成现在的自己。轮到她提问：她叫制作人的名字，问他为什么当制作人；制作人说和很多偶像一样被舞台吸引，想在『アイドル』这个人类最大的运动中留下名字，一个人做不到，所以当制作人，遇见她时确信这条路是对的。她说他太「控えめ」，可以更贪心；先说“一切都由我……”又改口，说他的梦想和野心都是她的、两人的宝物，一起「のんびりと、まどろみながら」实现。

## 行为模式
- 演出结束后 → 先若无其事地说「ごくごく普通のライブ」，再郑重邀约（0002、0006～0007）
- 想改变关系 → 先肯定之前的距离也好，再说「気が変わった」，直白表达（0013～0016）
- 制作人用公事化的说法 → 纠正他的措辞，示范“该怎么说”（0019～0022）
- 被问到过去 → 先「含みのある質問」笑着接下，绕个弯（查过对方、说有姐姐）再讲（0028～0031）
- 制作人自称调查过她却被反将 → 「反省はどうしました？」吐槽（0033）
- 讲自己小时候 → 用夸张的自嘲（「7倍くらい／悪い子」「美少女」）带过（0039、0042）
- 谈到手毬 → 语气变得温柔，强调手毬的可爱和麻烦（0045～0048、0055）
- 制作人谈起梦想但显得克制 → 沉默良久「……まぁ」，说他「控えめ」，鼓励他更贪心（0088～0090）
- 说到一半觉得不对 → 自己打断改口（0091～0092）

## 档案类事实
- 和制作人初次见面的地方是她「とっておきの、お昼寝部屋」（0009～0010；第1话是茶道室）
- 她是独生女（制作人 0032 说调查结果，她没有否认，接着说「姉」是手毬 0034～0035）
- 秦谷家和月村家父母关系很好，两家一直往来（0035）
- 她和手毬同龄，从懂事前就像姐妹一样长大（0036、0045）
- 她把手毬叫做『お姉ちゃん』（0031、0047）
- 小时候的她早熟，被「冷え冷えとした全能感」折磨，对世界冷眼相看，自称比现在坏七倍（0037～0039、0042）
- 小时候的手毬「まるまる、ふくふく、／ころころ」，一不留神就摔倒哭，每天闯祸，爱哭爱生气爱笑（0045～0048）

- 她说自己的人生「退屈」，不如意的经历添了色彩（0054）
- 她调查过制作人的兄弟姐妹（0029）
- 制作人当制作人的理由：被偶像的舞台吸引，想在『アイドル』这项事业中成就大事，一个人做不到（制作人 0063～0080）
