# 秦谷美鈴 亲爱度剧情 / 第33话（adv_dear_hmsz_033）

- 她的台词：44 行（含用匿名标签说的 0 行；其中 0006 是括号里的心声）
- 出场的人：美鈴、プロデューサー
- 场景：和愁佳的非正式 Live 的第二天（0004「昨日……」、0037「昨日の非公式ライブ」），地点看不出
- 世界线：亲爱度（秦谷美鈴）；制作人在制作的偶像：秦谷美鈴（制作人 0051「俺の担当／アイドルは、あくまでひとりだけ」）

## 发生了什么
她表情变来变去，被制作人问起，说昨天发生了太多事，又高兴又不安，还有说不出的心情（心声：不知道手毬那么在意自己）。她告诉制作人手毬说要去 100プロ，问他怎么看；对话内容她说是「秘密」。制作人说进 100プロ 主流出道对手毬是妥当的选择，与『H.I.F』结果无关；她问「わたしも、でしょうか？」，制作人说她在职业领域也完全行得通，已经证明了。她说他「嫌なひと」，原来让她们挑战顶级偶像就是为了把她们“卖个好价”；制作人说今年的首席拿定了，100プロ 若收下手毬他也能轻松些，她说「そんなに上手くいくでしょうか」。她承认这次对她和手毬都是很大的成长机会；她指出制作人嘴上说运气好、脸上却不甘心，制作人说本以为能赢，她说「わたしもです」。制作人说不会让她“跑起来”，她笑说他很会平息她的怒气。她说经过夏季『H.I.F』和昨天的 Live，觉得自己的梦想比想象中更无边无际，但相信和他一起一定能到达：先在『H.I.F』当着全校从十王星南手中夺下『一番星』、完成复仇，实现他的梦想。制作人问宿命对手呢，她说手毬在群星中看着自己，她也要以同等热量回看，大会的主角是秦谷美鈴和月村手毬，星南是配角，「わたしが」决定的；她要求制作人对手毬的制作也不许偷懒，制作人说担当只有一个人，但两边都会全力，她说「やっぱり」——100プロ 里不会有人愿意接手手毬，因为有他在。最后她说『H.I.F』只是开始：旁边有拼命奔跑的手毬，牵着的手的那头有他，抬头有彩虹阶梯，一起「大切に……うららかに」地往上走，那条路一定是幸福的。

## 行为模式
- 心里乱时 → 表情藏不住；被问起就坦白“说不清”，但仍请对方听（0003～0008）
- 涉及手毬的私密对话 → 「秘密です」不告诉制作人（0013）
- 听到手毬可能离开、自己也可能被推向职业圈 → 先试探「わたしも、でしょうか？」，再说制作人「嫌なひと」（0018～0022）
- 制作人嘴上说好、表情不甘 → 点破，然后自己也承认（0031～0033）
- 被制作人哄好 → 笑着说他擅长平息自己的怒气（0035～0036）
- 体会到上面还有更高的人 → 不泄气，说梦想更远了但两人一定能到（0037～0041）
- 宣布目标 → 用“我决定的”这样的傲慢说法定下主角（0049）
- 关心手毬 → 不直接说，而是命令制作人不许对手毬偷懒，并预言手毬会继续由他制作（0050、0057～0058）

## 关系
- プロデューサー：她叫「プロデューサー」「あなた」，制作人叫她「秦谷さん」。她说他「嫌なひと」（0020）、「わたしの怒りを鎮めるのが／お上手」（0036），相信两人一定能到达（0041），要实现他的梦想（0044）。「手をつないだ先に、あなたがいる」（0063）。
- 月村手毬：她叫「まりちゃん」「あの子」「月村手毬」。心声说不知道手毬那么在意自己（0006）。她把手毬视作宿命对手，要以同样热量回看（0047～0048），大会主角是她们两人（0049）；她要求制作人认真制作手毬（0050），说手毬是「必死に走るあの子」（0063）。
- 十王星南：『H.I.F』上要当着全校从她手中夺走『一番星』、完成复仇（0042～0043），但定为「脇役」（0049）。

## 不确定
- 0006 是括号里的心声，不是说出口的话。
- 制作人 0032「勝てると思っていましたから」、她 0033「わたしもです」：意味着和愁佳的 Live 没有赢（与第32话手毬 0018『また負けた……！』一致），但第31话没有宣判结果、愁佳还道了歉（第31话 0069～0076）；具体结果剧本没写明。
- 0034「走らせるつもりはありませんよ」：指不会逼她急着赶路（呼应第26话『せかせかと急ぐ姿』），推测。
- 0021～0022：她说制作人「最初からそれが狙い」是要把她们「高く売り込む」，制作人没有否认（0023～0024），是她的解读。
- 0044「今度こそ」：指夏季『H.I.F』没能兑现（第26话 0031），推测。
- 【译文】0023「本年度の首席はいただきです。」：「首席」是年度第一（首席），译文“头号黑马”意思不对。
