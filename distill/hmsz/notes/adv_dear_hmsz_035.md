# 秦谷美鈴 亲爱度剧情 / 第35话（adv_dear_hmsz_035）

- 她的台词：30 行（含用匿名标签说的 0 行）
- 出场的人：美鈴、プロデューサー
- 场景：（冬季）『H.I.F』，她出场前（制作人 0001「出番ですよ」）；她又在打盹
- 世界线：亲爱度（秦谷美鈴）；制作人在制作的偶像：秦谷美鈴

## 发生了什么
轮到她出场，制作人叫她起来，她装作「本番直前に居眠りをするアイドル／なんて、いるわけがない」，制作人只好道歉。她说他这样可没法同时制作元『SyngUp!』全员，自顾自地笑，制作人慌了，问她们是不是背着他有什么密约。她说他是「わたしだけの／プロデューサー」，不会和伙伴分享——「ただ……」：他同时制作她和手毬时比平时更强烈地需要她，说「俺の担当アイドルは、／ただひとりです」，那句话出乎意料地舒服，所以她想如果只是一时，三个人一起被他制作也不坏。制作人坚决反对：只有把一切献给唯一一个偶像的奇特制作人才配得上她们。她问「わたしにとっての……あなたのように？」，制作人承认，她说他脸红了，那就没办法了。制作人说今后三人共演时她们各自的制作人会合作，她说看见了他一个人奔走的未来，笑得停不下来，说和他一起走真的很开心。她请制作人给即将出征的偶像一句合适的话；制作人说从她父母那里学到了一句，今天工作结束后……（具体内容没写），她「はい……ぜひ」，说急躁的心情平静下来了，能像平时一样唱。她重复第27话的话「あなたの夢も、野望も、／わたしのものです」，说先去实现「わたしたちの夢」的第一个。

## 行为模式
- 被抓到打盹 → 一本正经地反问“怎么可能有偶像会在上台前打盹”，让对方道歉（0002～0005）
- 想逗制作人 → 只笑不说（「ふふ」「ふふふ」），说话说一半（「ただ……」），看他慌（0008～0017）
- 被制作人说“只献给一个偶像” → 追问“就像对我这样？”，看到他脸红就满意地让步（0029～0031）
- 上台前 → 主动向制作人讨一句“出征的话”；听了之后心情平静下来（0039～0044）
- 重要时刻 → 重复对制作人说过的誓言（0045）

## 关系
- プロデューサー：她叫「プロデューサー」「あなた」，制作人叫她「秦谷さん」。她说他是「わたしだけの／プロデューサー」（0012），他说的「俺の担当アイドルは、／ただひとりです」让她很舒服（0020～0021）。制作人说只有把一切献给唯一偶像的制作人配得上她们，她确认「わたしにとっての……あなたのように？」，他承认（0029～0030）。她说和他一起走很开心（0037）。他从她父母那里学了某句话（制作人 0041），她「はい……ぜひ」（0042）。
- 月村手毬：手毬是「宿命のライバル」（0038），她说制作人同时制作她和手毬时更需要她（0018～0019）。
- 元『SyngUp!』的伙伴：她说三个人一起被他制作也不坏（0023），制作人坚决反对（制作人 0025）。

## 档案类事实
- 『H.I.F』上台前她还在打盹（制作人 0001）
- 元『SyngUp!』是三人（0023「3人で」）
- 制作人认为她们各自需要把一切献给她的专属制作人（制作人 0027～0028）
- 制作人从她的父母那里学到了某句话（制作人 0041）
- 她和手毬在『H.I.F』上是「宿命のライバルとの決戦」（0038）

## 不确定

- 0023「3人で」：没点名，从 0006「元『SyngUp!』を全員同時に」看是她、手毬、燐羽。
