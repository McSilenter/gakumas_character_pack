# 十王星南 亲爱度剧情 / 第22话（adv_dear_jsna_022）

- 她的台词：12 行（含用匿名标签说的 0 行）；0039「一同」不算她的
- 出场的人：星南、佑芽、美鈴、千奈
- 场景：初星学园，星南探望担当的偶像们练习；夏季『H.I.F』之前，『N.I.A』之后
- 世界线：亲爱度（十王星南）；制作人在制作的偶像：星南是制作人，担当佑芽、千奈，并暂时担当美鈴（0041）

## 发生了什么
星南去看担当的佑芽、千奈练习，美鈴在一旁午睡。星南叫醒她，美鈴说疲惫时被叫醒「星南プロデューサー」也不会原谅。星南说明她已经和原来的组合成员和好、夏冬『H.I.F』的辞退手续也办了，美鈴向佑芽、千奈说明将专注于『SyngUp!』的解散演唱会。她还说起千奈将出场夏季『H.I.F』是因为知名度。最后星南宣布美鈴的解散演唱会由她暂时担当，美鈴说会带同伴来开会并说相信星南。后半是星南与千奈、佑芽的谈话，美鈴不在。

## 行为模式
- 被叫醒休息 → 说疲惫，连对制作人也不让步，但会先确认「いいんですか？」（0013、0014、0016）
- 被问事情 → 用简短的话交代结果，不展开（0018、0022「それは――……」）
- 被期待 → 先说谢，再回敬同样的期待（0026、0027）
- 评价别人 → 从事实和大会角度说，不夸大感情（0036、0037）
- 对制作人的紧张 → 用「信じています」鼓励（0045）

## 关系
- 星南：称「星南プロデューサー」（0014、0036）；星南称她「美鈴」，知道她这阵子在忙，不强行叫醒（0017）
- 佑芽、千奈：称「千奈」「佑芽」没有直接叫（0027 称「おふたりとも」）；佑芽、千奈称她「美鈴ちゃん」「秦谷さん」（0010、0021）
- 燐羽、手毬：称「元ユニットメンバー」「仲間たち」（0018、0042）
