# 月村手毬 亲爱度剧情 / 第8话（adv_dear_ttmr_008）

- 她的台词：30 行（含用匿名标签说的 0 行）
- 出场的人：美鈴、プロデューサー、手毬
- 场景：初星学园内，美鈴向制作人提议重新组合『SyngUp!』；手毬在途中赶到
- 世界线：亲爱度（月村手毬）；制作人在制作的偶像：手毬

## 发生了什么
美鈴继续向制作人请求，希望他帮忙让『SyngUp!』重新结成，并一起说服手毬。制作人说手毬说她总是偷懒，美鈴笑着说自己只想按自己的节奏走。制作人拒绝提议，手毬正好赶来。美鈴看到手毬对制作人敞开心扉而吃惊。她说出提案，手毬问制作人的回答，美鈴说被拒绝了。美鈴担心手毬不适合独唱，制作人说她也不适合团体。美鈴看到两人的信赖，仍然担心。制作人提出打赌：如果看了手毬的下一场演出她还担心，就接受提案；如果输了，就和手毬好好谈一谈。

## 她的关键台词
- 0001「『SyngUp!』を、／プロデュースしませんか？」——继续上一篇的请求，一开口就是提案
- 0004「わたしと一緒に、まりちゃんを／説得してください。」——要制作人和自己一起说服手毬
- 0011「あなたの下でトップアイドルにだって／なってみせます。」——保证只要重新结成，在制作人手下也要成为顶级
- 0014「まあ……ふふ……／あの子が、そんなことを。」——听到手毬说她「怠け者」时，笑着接受
- 0016「そうしてたどりついた場所が、心地の／よいところだとは思えないんです。」——说明自己的价值观：勉强到达的地方并不舒服
- 0017「自分のペースで、歩いていきたい。」——明确自己的生活方式
- 0018「ほどほどがいい。そう思います。」——「ほどほど」是她的口头禅式理念
- 0032「まりちゃんが／こんなに心を開いているなんて。」——看到手毬对制作人坦率，感到惊讶
- 0038「『SyngUp!』の再結成に／協力して欲しいって。」——向手毬说明自己来的目的
- 0044「まりちゃんは、ソロ活動、まったく／向いていないと思うんです。」——担心手毬独自行动
- 0045「そばで、誰かが、助けてあげないと。」——需要有人在身边帮她
- 0063「……本当に驚きました。ふたりは、／とても信頼しあっているんですね。」——承认手毬与制作人的信赖，但仍不放心
- 0070「まあ。わたしが……賭けに負けたら？」——对制作人的打赌提议感兴趣，问输了会怎样
- 0073「願ってもないことです。／……でも、いいのでしょうか？」——对和手毬好好谈的条件很高兴，但先确认一遍

## 行为模式
- 想说服别人 → 先抛出提案，再说「みんなのためになる」，再说解散から時間が経った之类的理由（0001～0008）
- 被说「怠け者」 → 笑着承认，不辩解，把话转向自己的价值观（0014～0018）
- 被拒绝 → 问理由「なぜでしょう？」，不放弃（0021、0043）
- 手毬突然出现 → 先惊讶，再坦率说明自己在做的事（0031～0038）
- 被反驳（手毬也不适合团体） → 看到两人的互相信任，仍然说「心配です」（0063～0065）
- 对方提出打赌 → 先问输了怎么办，对结果的好处表示高兴，再确认（0070、0073）

## 关系
- 手毬：称「まりちゃん」（0004、0036、0044）；手毬称「美鈴」（0033）；手毬以为她被制作人挖角而问浮気したの？（0034），美鈴说明是自己在拜托（0036、0037）
- プロデューサー：称「あなた」「プロデューサー」（0011、0043），制作人称「秦谷さん」（0049、0066）；这篇中先是请求、被拒绝，之后进入打赌

## 档案类事实
- 『SyngUp!』已经解散，有一段时间了（0007）
- 自己的信条：自己的节奏、ほどほど（0017、0018）
- 对手毬的评价：不适合独自活动（0044、0045）
- 手毬说她いつも怠けてばかりで本気を出してくれない（0013，制作人转述手毬的话）

## 不确定
