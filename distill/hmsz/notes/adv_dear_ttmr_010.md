# 月村手毬 亲爱度剧情 / 第10话（adv_dear_ttmr_010）

- 她的台词：18 行（含用匿名标签说的 0 行）
- 出场的人：手毬、美鈴、プロデューサー
- 场景：美鈴与手毬搬到同一间宿舍房间之后（制作人帮忙搬家），之后手毬与制作人的对话（美鈴0048 离开）
- 世界线：亲爱度（月村手毬）；制作人在制作的偶像：手毬（0005、0035）

## 发生了什么
制作人帮美鈴和手毬搬家。美鈴说如果制作人愿意，希望自己也能和手毬一起被制作，手毬强烈反对。两人互相说「讨厌」，美鈴嘲笑手毬自理能力。两人问制作人到底哪个更好，制作人说作为偶像，美鈴现在更强，但想制作的是手毬。手毬得意地对美鈴说「真遗憾」，美鈴笑着应对，说去新房间睡一觉，说「これがわたしの全力」，在梦想的地方等手毬。美鈴离开后手毬向制作人说出成为偶像的理由。

## 她的关键台词
- 0003「ありがとうございました。」——对制作人帮忙搬家郑重道谢（0002～0004 合起来）
- 0004「相部屋の手続きでお世話になった／のに、荷物運びまでさせてしまって……」——对制作人的歉意
- 0009「まりちゃんと一緒に、／プロデュースしていただきたいです。」——说想和手毬一起被制作
- 0013「ふふふ……声が小さくて、／聞こえませんでした。」——手毬支吾时故意装作没听见
- 0015「わたしも、まりちゃんのすぐ怒って／ごまかすところ、嫌いです。」——手毬说「嫌い」，她同样回敬
- 0017「ひとりで身支度できるようになって、／えらいえらいですね。」——用夸奖的方式取笑手毬，被说「子供扱い」
- 0021「ふふふ、そうですよ。／プロデューサーが原因なのですから。」——被问和好之事，笑着把原因推给制作人
- 0023「わたし。」——手毬问我和谁更好时，抢着只说一个字
- 0027「まあ、嬉しい。」——制作人说她现在更强，她坦率地表示高兴
- 0043「そ、そうですね……ふふっ。」——被手毬宣布制作人一开始就选我时的反应，说话有些停顿
- 0045「わたしは、新しいお部屋で／ひと眠りしてきます。」——不争，转身去睡觉
- 0047「これがわたしの全力なんです。／無理せずゆっくりと歩いて……」——被说偶尔自主训练时的回答，讲自己的步调
- 0048「夢の場所で、待っています。」——对手毬留下的话，指的是共同的目标

## 行为模式
- 手毬发脾气 → 故意装作听不见、用夸奖取笑，让手毬更气（0013、0017）
- 被说「嫌い」 → 同样回敬一句（0015）
- 被问二选一 → 抢先报上自己「わたし」，听到好评就说「嬉しい」（0023、0027）
- 输了对比 → 笑着说「そうですね」，然后借口去睡觉退场（0043、0045）
- 被指责偷懒 → 不辩解，用「全力」「ゆっくり」说自己的步调，并留下「夢の場所で、待っています」（0047、0048）

## 关系
- 手毬：称「まりちゃん」（0009、0015、0044）；手毬称她「美鈴」（0010）；两人互相说「嫌い」，但已经和好、同住一间房（0004，0052～0054 手毬的话）
- プロデューサー：称「プロデューサー」（0007、0044）；制作人称「秦谷さん」，承认打赌输给她们（0005）。她两次请求被制作，一次在这里提出（0009）

## 档案类事实
- 和手毬搬到同一间房（相部屋）（0002、0004）
- 打赌结果是制作人输（0005）
- 制作人评价：作为偶像，现在是美鈴更强（0031、0032）
- 喜欢睡觉，睡觉场所是新房间（0045）
- 手毬说她「悪気とかぜんぜんない」地说话（0050，手毬的话）
