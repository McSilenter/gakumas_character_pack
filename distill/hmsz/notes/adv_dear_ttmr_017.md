# 月村手毬 亲爱度剧情 / 第17话（adv_dear_ttmr_017）

- 她的台词：28 行（含用匿名标签说的 0 行）；0019 是手毬在她回忆中说的话，不算她的
- 出场的人：美鈴、手毬、燐羽
- 场景：『N.I.A』期间，三人重聚谈『SyngUp!』的约定（剧本没写明地点）
- 世界线：亲爱度（月村手毬）；制作人在制作的偶像：手毬（本篇制作人不在场）

## 发生了什么
燐羽、手毬为约定是不是被打破吵架，美鈴在中间听着。燐羽说她从不违约，约定是成为中等部第一的组合；手毬说约定是一起成为顶级偶像，指着的是高等部校舍。美鈴说自己记得手毬指着高等部校舍，但自己理解的约定是三个人在『H.I.F』优胜，一起成为顶级是她和手毬两人的约定。三人记得都不同。手毬说如果燐羽继续当偶像就原谅她，燐羽答应再做一次太阳的模仿。美鈴说自己现在是排名第1，问燐羽是否要直接对决，被拒绝。美鈴说『FINALE』是她和手毬的对决，并说要弄清三人中谁最强。

## 她的关键台词
- 0001「まあ……それで……／結局、どうなったんですか？」——一开场就问事态结果，像是在听两人闹剧的后续
- 0009「まあ、まあ……ふふふ……／懐かしいですね、この感じ。」——看到两人吵架时觉得怀念
- 0010「ふたりとも？　ちゃんと話して／くれないと、わかりませんよ。」——要两人把话说清楚
- 0018「まりちゃんは、あのとき。／初星学園の方を指さして――」——回忆具体情景，站在手毬一边的证词
- 0033「まりちゃんが高等部の校舎を指さして／いたのは、間違いありませんよ。」——对燐羽明确指出她记错了
- 0037「この3人で『H.I.F』に出場し、／優勝しよう――と。」——说出自己对约定的理解，与另外两人不同
- 0039「『ふたりの約束』だと思っていました。」——「一緒にトップアイドルになろう」是她与手毬两人的约定
- 0042「何年も前の記憶なんて、／そんなものですよ。」——三个人记得都不同时，一笑置之
- 0046「まあ、りんちゃん。／もう約束を果たせませんね。」——顺着手毬一边说燐羽没有实现约定
- 0063「いまのランキング1位はわたしです。／しますか？　直接対決――初星潰しを。」——对燐羽提议直接对决
- 0067「わたしたちの太陽が戻ってきそうで……／本当によかったです。」——真心为燐羽回来而高兴
- 0073「この3人の中で、誰が一番上なのか。」——要在三人之间分出高低
- 0074「二度と……よそ見ができないように。」——对手毬说的话，期待她只看自己

## 行为模式
- 朋友吵架 → 先问结果，笑着说「懐かしい」，再用「ちゃんと話して」引导（0001、0009、0010）
- 证实某件事 → 先说自己亲眼看到的细节，再下结论（0018、0033）
- 三人的记忆不同 → 说何年も前の記憶なんて、そんなもの，不争对错（0042）
- 想让对方上场 → 提出直接对决（0063）
- 说到真心的话 → 先说为同伴回来高兴，再转到对手毬的竞争宣言（0067～0074）

## 关系
- 手毬：称「まりちゃん」（0018、0033、0069）；手毬称「美鈴」（0003）；0071「やっと……こっちを見てくれた」说明她希望手毬把自己当对手
- 燐羽：称「りんちゃん」（0032、0046、0065）；燐羽称她「美鈴」（0002），说要和她比赛时美鈴に勝つには、アイドルに戻って、リハビリしないと（0064）

## 档案类事实
- 『SyngUp!』的三人在中等部时成了中等部第一的组合（0022，燐羽的话）
- 约定的版本：燐羽中等部一番；手毬三人でトップアイドル（高等部校舍）；美鈴三人で『H.I.F』に出て优胜，且「一緒にトップアイドルになろう」是她与手毬的两人约定（0036～0039）
- 『N.I.A』的排名她现在是第1（0063）
- 对燐羽还有很多想法，现在不说（0065、0066）
