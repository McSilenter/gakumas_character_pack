# 活动 002 初星温泉～纷飞的凛冽寒风～ / main-03 第3话（adv_event_002_main-03）

- 她的台词：23 行（含用匿名标签说的 0 行）
- 出场的人：千奈、美鈴、佑芽、広
- 场景：学校里，上课间的休息时间，教室附近；佑芽把逃课的美鈴带回来（0001～0004）。
- 世界线：活动 002；制作人在制作的偶像：看不出（这一篇没有制作人出场）。

## 发生了什么
佑芽把偷偷不见了的美鈴带回教室，美鈴说佑芽跑得快，自己很久没跑这么多了。千奈提醒不要在校内跑。广问她为什么逃课，美鈴说有朋友在别的班，现在在吵架，想悄悄去看看，结果被外面暖和的天气吸引，睡了午觉；千奈指出理由和睡午觉没关系，美鈴也承认。美鈴说自己其实是不良，千奈说要做朋友，又叮嘱要守约守时，美鈴向她道谢。周围的同学远远地围着他们，美鈴说大家怕她。佑芽问起她中等部时代的偶像组合（穿成套的青色服装、被人敬畏）的传闻，美鈴承认；问到用应援扇敲粉丝的传闻，美鈴立刻否认。同学们慢慢凑近，千奈邀请美鈴做朋友，美鈴回答“こちらこそ”。

## 她的关键台词
- 0004「連れ戻されました。」——被佑芽抓回来，说得像别人的事一样平静
- 0005「佑芽さんは、とても足が速いですね。／こんなに走ったのは、久しぶりです。」——被追着跑过一次后的感想，夸对方，自己只是说"久しぶり"
- 0010「他のクラスに、友達がいるんです。」／0012「ですけど、いま、喧嘩をしていまして。／こっそり様子をうかがいに……」——被问逃课的理由，说是朋友在吵架想去看看；但没有说名字
- 0015「外が暖かそうな陽気でしたので……／つい寄り道をしてしまいました。」——把理由转向天气，接着千奈指出无关
- 0020「実はわたしもお話ししながら、あんまり／関係ないなって思っていました。」——被千奈说"理由和午睡没关系"时，坦白自己说着说着也觉得没关系
- 0024「わたし……／こう見えて、不良なんです。」——用"不良"来形容自己，语气平淡
- 0032「心配してくださって……／ありがとうございます。」——千奈叮嘱守约守时，美鈴道谢，并摸了千奈的头（千奈 0033 抗议）
- 0039「わたしを……／怖がっているんだと思います。」——周围同学不敢靠近，她解释为"怕我"
- 0041「ふふ……これでもわたし、／有名な不良なんですよ。」——被千奈说"看起来很温柔"后，笑着强调自己出名
- 0044「はい、本当です。」——被问到中等部时代是不是某个厉害偶像组合的成员，直接承认
- 0046「えっ？　／………う、嘘ではない、ですね。」——被问到青衣服、被敬畏或被怕的传闻时，一愣，吞吞吐吐地承认
- 0052「わたしはやってません！」——被问是否用应援扇敲粉丝，立刻大声否认，这是这一篇里少见的急口
- 0054「あのときは……とても大変で……」——被说那个伙伴很野蛮时，没有否认事件本身，只说"那时很辛苦"
- 0062「……………………こちらこそ。」／0063「よろしくお願いします、皆さん。」——被邀请做朋友时的长停顿，之后接受

## 行为模式
- 被追问逃课理由 → 给出一个半真半假的理由，接着承认其实不相关（0010～0015、0020）
- 被千奈责备或叮嘱 → 不反驳，一直用敬语回话；对认真关心自己的话表示感谢（0008、0031、0032）
- 被问到过去的传闻 → 能承认的承认（0044），夸张的传闻（敲粉丝）才大声否认（0052）
- 被邀请做朋友 → 先沉默或拖长回答（0027、0062），然后用正式的客套接受（0063）
- 说自己"不良"时语气轻松，被周围当真怕时也不在意（0024、0039、0041）

## 关系
- 佑芽：叫「佑芽さん」（0005）；佑芽叫「美鈴ちゃん」；被佑芽追着跑。
- 千奈：叫「倉本さん」（0031）；被千奈叫「秦谷さん」，千奈要和她做朋友（0026、0061），美鈴对此回答「こちらこそ」（0062）。
- 広：被叫「美鈴」（0022 広）；美鈴没有直接对她说话。
- 那位在别的班、正在吵架的朋友：没有名字（0010、0012）。

## 档案类事实
- 中等部时代是"很厉害的偶像组合"的成员（佑芽 0043 问，美鈴 0044 承认）；组合穿成套的青色服装，被人尊敬或害怕（佑芽 0045，美鈴 0046 承认）。组合名没有出现。
- 传闻中有"用应援扇打粉丝出了问题"一事，她说"不是我做的"（0051、0052）。
- 有朋友在别的班，现在在吵架（0010、0012）。
- 很久没有跑这么多了（0005）。

## 不确定
- 0010、0012 说的"别的班的朋友"是谁没写；0020 自己承认和午睡无关，所以"在吵架"这个说法是否属实，剧本没有交代（和主线 SyngUp! 的关系见别的条线，这里不并入）。
- 0044、0046 说的"偶像组合"没有写名字；是否就是 SyngUp! 这条线以外无法在这一篇里确认。
- 0052「わたしはやってません！」的"やってません"只否认了自己，0054「あのときは……とても大変で……」暗示这件事真的发生过，由谁做的没写（広 0053 说"美鈴の仲間"野蛮）。
- 0027「…………………は、はぁ。」是对千奈"做朋友"的反应，是拒绝、困惑还是不习惯，没写。
