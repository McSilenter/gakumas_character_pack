## 发生了什么
美鈴悄悄告诉広：1组的人已经和好，关系变得很好。広问她为什么着急，美鈴说"很不甘心"：那孩子在别的班和别人亲近起来，却还在和自己吵架。美鈴说自己也要和 2组的人好好相处，因为她们总是给班里添麻烦。两人想办法办班级联欢会，要悄悄准备，被佑芽和千奈追来听到。美鈴问为什么每次都被找到，佑芽说是记住了她的味道。最后大家决定一起准备，美鈴负责做点心。

## 行为模式
- 有气恼的事 → 不对全班说，找一个让她安心的人悄悄商量（0001、0023 广问）
- 被问内心 → 先说不甘心，再补充"那孩子"和"还在吵架"，不说名字（0015～0018）
- 被说幼稚 → 不反驳，转到"我们给大家添麻烦"这个理由（0022、0024）
- 被抓到秘密 → 反应是提问而不是辩解（0036、0037）
- 事情变成全员活动 → 立刻认领具体的任务（做点心），用"共同作业"总结（0047、0049、0052）
