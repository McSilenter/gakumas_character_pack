# 活动 005 / main-03 第3话（adv_event_005_main-03）

- 她的台词：14 行（含用匿名标签说的 0 行）；其中 0045、0055 只有「？」，0065 只有省略号
- 出场的人：星南、燕、莉波、美鈴
- 场景：星南、燕、莉波刚把千奈招进生徒会之后（星南 0001、莉波 0005），商量下一个要招的人，然后找到美鈴当面招揽；具体地点剧本没写。
- 世界线：活动 005；制作人在制作的偶像：看不出。星南在做"疑似事务所"式的生徒会制作（美鈴 0058、0060、0062）。

## 发生了什么
星南说下一个要招的是『一番星』后继者候选，从中等部第一的组合『SyngUp!』的前成员里选。三人讨论：手毬才能出色但不选，燐羽有固定粉丝但难培养，星南选了美鈴，理由是实力和潜力极高、而且是『SyngUp!』里唯一素行看起来好的。星南当面对美鈴说"决定是你了"，说话抽象，美鈴听不懂，要求再慢慢解释一次。星南说是希望她加入生徒会，美鈴说"好麻烦的邀请"；星南补充要带她到顶点，美鈴终于听懂是"让星南会长制作自己"，问了人数有没有限制，沉默之后说"我加入生徒会"，向星南道谢。

## 她的关键台词
- 0043「……なにが、でしょうか？」——星南宣布"决定是你了"，她完全听不懂，用敬语反问
- 0047「はじめまして、十王星南会長。／秦谷美鈴と申します。」——初次见面，礼貌地自报姓名，知道对方是会长
- 0050「申し訳ございません。もう一度、／ゆっくりと……ご説明いただけますか？」——听不懂星南的抽象说法，直接请对方再慢慢讲
- 0052「まあ……なんて……面倒そうなお誘い。」——听到"加入生徒会"后的第一感想，语气平淡，直说"麻烦"
- 0057「ははあ……ようやくわかりました。」／0058「生徒会に入れば、わたしを星南会長に／プロデュースしていただける、と。」——理解后立刻把话归纳成"生徒会入れば星南会長がプロデュース"
- 0060「星南会長は、初星学園の未来を担う／若い人材を集めて……育てている。」——复述并确认星南的做法
- 0062「その……疑似事務所。……人数に、／制限などはあるのでしょうか？」——先问"人数有没有限制"，没有问自己的待遇
- 0066「入ります、生徒会。」——沉默很久后一句话决定，不拖泥带水
- 0068「いいえ、星南会長。／お礼を言うのはこちらの方です。」／0069「……ありがとうございました。」——星南道谢，她反过来向星南道谢

## 行为模式
- 听不懂对方的抽象说法 → 不装懂，先反问“なにが”，再请对方重说一次（0043、0050）
- 被邀请做麻烦的事 → 直接说"面倒そう"，不绕弯（0052）
- 弄懂之后 → 马上用一句话归纳，再确认细节（0057～0062）
- 做重要决定时 → 先问一个关于人数的问题，沉默很久，然后一句话答应（0062、0065、0066）
- 被道谢 → 反过来说该说谢谢的是自己（0068、0069）

## 关系
- 星南：叫「星南会長」（0047、0058），初次见面；星南让她叫"星南"就好（星南 0048），她仍叫「会長」。星南叫「美鈴」。
- 燕、莉波：只出现在场；燕评价她"他のふたりと比べると、地味な印象"（燕 0038），她没有回应。

## 档案类事实
- 星南（燕、莉波的对话）说：美鈴原是『SyngUp!』的一员，该组合被称为"中等部ナンバーワンユニット"，有三个人（星南 0012、0013、0025）；成员有月村手毬、リーダー賀陽燐羽、美鈴（0028、0032、0038）；组合因"仲違い"解散（0025）。
- 星南对美鈴的评价：实力和潜力极高，是『SyngUp!』里唯一素行看起来好的（星南 0040、0041）；燕觉得她比另外两人地味（燕 0038）。
- 星南说有些学生对『SyngUp!』有不好的印象（星南 0022）。
- 星南 0047～0048 是两人第一次见面，美鈴这条线上之前没有见过星南。

## 不确定

- 0069「ありがとうございました」是对星南的招揽还是别的事，没有说明；0068 说"お礼を言うのはこちらの方"，具体理由也没写。
