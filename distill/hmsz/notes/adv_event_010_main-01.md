# 活动 010 星南与燕的日常 / main-01 情人节协奏曲 第1话（adv_event_010_main-01）

- 她的台词：6 行（含用匿名标签说的 0 行）
- 出场的人：佑芽、千奈、美鈴、広、司書、莉波
- 场景：学校（教室一带），情人节前两天（佑芽 0003「明後日のバレンタイン」）；0029 起是图书馆里的広、之后莉波发现焦味。
- 世界线：活动 010；制作人在制作的偶像：看不出（这一篇没有制作人出场）。

## 发生了什么
佑芽和千奈聊情人节的巧克力：千奈要给爷爷自己做，佑芽每年和姐姐交换。美鈴笑着加入，被问起时说中等部时在组合内部互相送巧克力，手毬最初会因怕胖而拒绝，但每年都会收下，也会偷偷往她的鞋柜里放巧克力。佑芽追问为什么是鞋柜，场景转到图书馆的広借书做巧克力，最后莉波发现焦味。

## 她的关键台词
- 0020「……ふふ、おふたりとも、／なんの話をしているんですか？」——笑着插进两人的对话，开头先笑一声
- 0022「……バレンタイン、ですか。」——重复这个词，停了一拍
- 0024「中等部の頃は、渡し合っていましたね。／ユニットのメンバー同士で。」——被问是否送人，说中等部的时候在组合里互相送
- 0025「まりちゃん、太るからって、／最初は断るんですけど……」——说起手毬，一开始会因为怕胖拒绝
- 0026「……毎年、／ちゃんと受け取ってくれるんです。」——紧接着补充手毬每年都会收下
- 0027「まりちゃんも、下駄箱にこっそり、／チョコを入れてくれていて……ふふ。」——手毬也会悄悄把巧克力放进她的鞋柜，说完笑出来

## 行为模式
- 听到有人谈论自己熟悉的话题 → 笑着靠过去问，再用回忆回答（0020～0024）
- 说到与手毬的往事 → 说得很具体（怕胖、每年收下、鞋柜里的巧克力），语气温和，句尾拖长、带笑（0025～0027）

## 关系
- 手毬：叫「まりちゃん」（0025、0027）。这一篇里手毬不在场，她只说手毬中等部时的行为。
- 佑芽、千奈：叫千奈「秦谷さん」→ 千奈叫她「秦谷さん」（千奈 0021）；佑芽叫「美鈴ちゃん」（0023）。

## 档案类事实
- 中等部时，组合内部成员互相送情人节巧克力（0024）。
- 手毬会因为"会变胖"先拒绝，但每年都会收下（0025、0026）。
- 手毬也会悄悄把巧克力放进美鈴的鞋柜（0027）。
- 组合名在这一篇里没有出现，只说"ユニットのメンバー同士"。

## 不确定
- 0024 的"ユニット"是否是 SyngUp!，这一篇没写；成员有多少人也没说（0024 只说"ユニットのメンバー同士"）。
- 0027「まりちゃんも、下駄箱にこっそり、／チョコを入れてくれていて」的"も"：字面是手毬也（除了收下她的巧克力之外）把巧克力放进美鈴的鞋柜；前面只说手毬"受け取ってくれる"（0026），没有明说美鈴给手毬的巧克力是怎么给的。adv_event_010_main-05 里美鈴给手毬递的是低糖质的巧克力（0039），与怕胖的说法一致，没有提到鞋柜。
