# 活动 014 学生会1年级的日常 / main-01 第1话（adv_event_014_main-01）

- 她的台词：8 行（含用匿名标签说的 0 行）：0003、0019、0043、0044、0047、0048、0049、0052
- 出场的人：佑芽、千奈、広、美鈴
- 场景：初星学园的学生会室（推测，剧本未明写），白天；佑芽闯进来报告消息
- 世界线：活动 014；制作人在制作的偶像：看不出

## 发生了什么
佑芽冲进来说在教师办公室前听到学校要办班级对抗赛，其实是全班参加的运动会，还会全国电视转播。千奈和広都说自己不擅长运动，很绝望。得知获胜的班级可以全班办演唱会、大出风头后，美鈴说奖励很诱人，大家会认真，自己想退出。佑芽揭穿美鈴其实运动很强（摸她的肌肉），美鈴装傻否认并慌张。最后広表示这次不能搞砸。

## 她的关键台词
- 0003「まあ、佑芽さん。いつもながら／ダイナミックな登場ですね。」——对闯入的佑芽用敬语、带点调侃地招呼，称「佑芽さん」
- 0019「あぁ……なんて……面倒そうな響き。」——听到运动会第一反应是嫌麻烦
- 0043「あぁ……それは……ずいぶんと／甘い飴を用意したものです。」——冷静地评价学校用奖励吊大家胃口
- 0044「みなさん、本気で挑むでしょうね。／わたしは遠慮したいですが。」——预判别人会认真，自己想置身事外
- 0047「まあ、なんのことでしょう？」——被佑芽说穿运动强时装糊涂
- 0048「毎日レッスンを／サボってばかりのわたしが……」——自称总是翘课（偷懒），用来否认
- 0052「きゃ……も、もう！　佑芽さん！？」——被摸肌肉时慌张，语气罕见地乱

## 行为模式
- 听到麻烦的集体活动 → 先说「面倒そう」，表示想退出，但同时能冷静看出别人会认真（0019、0044）
- 被指出自己的长处（运动强）→ 用「まあ、なんのことでしょう？」和自嘲偷懒来撇清（0047、0048、0049）
- 被身体接触、被戳破 → 语气短暂失去从容（0052）

## 关系
- 佑芽：称「佑芽さん」；佑芽称她「美鈴ちゃん」（0045），知道她运动很强，还会碰她的手臂（0046、0050、0051）
- 千奈、広：本篇没有直接对话

## 档案类事实
- 佑芽说她运动非常擅长、肌肉好（0046、0051）；她本人否认，自称每天偷懒不练习（0048）

## 不确定
- 她是真的运动强还是只是佑芽的说法：佑芽断言（0046、0051），她自己否认（0047～0049），本篇没有证实
