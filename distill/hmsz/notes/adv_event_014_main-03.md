# 活动 014 学生会1年级的日常 / main-03 第3话（adv_event_014_main-03）

- 她的台词：17 行（含用匿名标签说的 0 行）：0003、0005、0016、0026、0027、0029、0030、0033、0034、0035、0037、0047、0067、0068、0069、0070、0072
- 出场的人：広、美鈴、佑芽
- 场景：次日（0001「翌日」），教室一类的地方，放学前（0023 说放学后练习）；千奈在 0008 被点名，但本篇没有台词
- 世界线：活动 014；制作人在制作的偶像：看不出

## 发生了什么
次日広把睡着的美鈴叫醒，向大家说明自己在运动会上一定会拖后腿，所以要做能做的事：练习、研究战胜1班的办法，并让咲季示范拔河。美鈴答应稍微练一下，但声明别指望她。広说明自己害怕拖累朋友，转述了佑芽大家一起痛苦、一起懊悔的看法。広拜托美鈴也一起努力，美鈴说对运动会提不起劲，但铁人偶像赛的搭档是自己，所以会「适当」练习。

## 她的关键台词
- 0003「……まあ、篠澤さん。／どうなさったんですか？」——被叫醒后仍用敬语，称「篠澤さん」
- 0027「……すこしだけ、なら。」——被佑芽拉进拔河练习时的勉强同意
- 0029「どういたしまして。／でも……これが精一杯です。」——被道谢后立刻给自己的投入设上限
- 0030「あまり……／わたしに期待しないでください。」——反复强调不要期待自己
- 0034「篠澤さんが、運動会でなにか／失敗をしたとして。」——开始安慰広，是她关心对方的表现
- 0035「あなたのせいで負けたなんて、／思いません。きっと、皆さんも。」——明确说不会怪広，也替其他人说话
- 0047「元アスリートらしい……／とても現実的な考え方ですね。」——听到佑芽的意见后的评价，说明她知道佑芽是前运动员
- 0067「なんと言われようと……／運動会にやる気なんて出せません。」——对运动会的干劲，立场不变
- 0069「ペアは、わたしです。」——主动指出自己是広的搭档，成为她改口的理由
- 0072「はぁ…………／なんて懐かしくて、迷惑な気分。」——答应后的感想，既怀念又嫌麻烦

## 行为模式
- 被人恳求做集体练习 → 先说「すこしだけ」「精一杯」划定上限，再答应（0027、0029、0030）
- 看到有人因担心拖累别人而苦恼 → 先问理由，再说明大家不会怪她，语气温和（0033～0035）
- 被说不努力的话→ 仍说对运动会没干劲，但以搭档是自己为由答应适度练习（0067～0070）
- 自己主动让步之后 → 叹气并用「迷惑」包装心情（0072）

## 关系
- 広：称「篠澤さん」；広称她「美鈴」，说她「本気を出したらすごい」（0031），拜托她一起练习（0065）
- 佑芽：佑芽称她「美鈴ちゃん」（0025）；她在 0047 评价佑芽的想法为现实
- 千奈：本篇没有对话

## 档案类事实
- 被広和佑芽认为认真起来就很厉害（0031，広的话；她没有反驳）
- 铁人偶像赛（アイアンアイドルレース）的搭档是她和広（0068、0069）
