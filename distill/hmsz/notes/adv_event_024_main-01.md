# 活动 024 / main-01 第1话（adv_event_024_main-01）

- 她的台词：6 行（含用匿名标签说的 0 行）：0006、0011、0012、0042、0046、0049
- 出场的人：星南、佑芽、千奈、美鈴（一同 0018、0022、0053 不计）
- 场景：2 月，『渋谷サウンドフェス』开始前（0001～0015）；之后回溯到 4 月，第一次正式训练日（0016 起）
- 世界线：活动 024；制作人在制作的偶像：星南是美鈴和佑芽的制作人（0009「プロデューサー・十王星南が、／手塩にかけて育てたあなたたち」，0011 美鈴称星南「プロデューサー」）

## 发生了什么
2月，星南对美鈴和佑芽说『渋谷サウンドフェス』就要开始，两人说随时可以。星南回想一年前：4月第一次正式训练，美鈴没来，佑芽、千奈说她在午睡。佑芽很快把美鈴带回来，美鈴说佑芽是找自己的专家，随即说要回去午睡。星南问她，她说因为知道今天开始训练所以躲起来，被找到了。星南说问题儿童更值得培养，要求大家开始训练。

## 她的关键台词
- 0006「いつでもいけます。」——被问是否准备好，回答干脆
- 0011「お任せください、プロデューサー。」——对星南称「プロデューサー」，回应得很正式
- 0012「あなたの担当アイドルが、／会場を虜にしてきます。」——以星南的担当偶像自居，宣称要让会场倾倒
- 0042「はい……佑芽さんは、／わたしを捕まえる専門家ですね。」——被带回后，对佑芽的评价，没有生气
- 0046「ふああぁ……／それでは、お昼寝に戻ります。」——被抓回来后还是想回去午睡
- 0049「はい……ですから雲隠れを試みました。／ふふ、見つかっちゃいましたが。」——坦白自己是因为要开始训练才躲起来，带着笑

## 行为模式
- 被追问缺席原因 → 直接承认是故意躲，没有借口（0049）
- 被抓回来 → 不抗拒，也不道歉，评论抓她的人，然后想回去睡（0042、0046）
- 回到现在的正式场合 → 切换为「お任せください」的从容语气，把自己说成星南的担当（0006、0011、0012）

## 关系
- 星南：称「プロデューサー」（0011）；星南称她「美鈴」，视她为问题儿童，但觉得值得培养（0051）
- 佑芽：称「佑芽さん」；佑芽称「美鈴ちゃん」，是总能找到她的人（0026、0037、0044）
- 千奈：千奈称「秦谷さん」，说她是1年2班的头号不良生徒（0029）

## 档案类事实
- 在1年2班被千奈、佑芽认为是午睡、缺席的常客（0024、0029、0040）
- 4月第一次训练日她午睡缺席，躲了起来（0024、0049）
- 星南的说法：美鈴外表看起来品行端正（0032）；本性是问题儿童（0050、0051）
