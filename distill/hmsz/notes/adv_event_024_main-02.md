# 活动 024 / main-02 第2话（adv_event_024_main-02）

- 她的台词：25 行（含用匿名标签说的 0 行）：0009、0011、0012、0013、0017、0019、0020、0024、0028、0030、0032、0033、0035、0037、0039、0042、0043、0044、0045、0047、0052、0054、0055、0057、0059
- 出场的人：美鈴、佑芽、星南、莉波
- 场景：9 月下旬（0001），学生会室，之后数日后在资料室一类的地方（0025 起）；文化祭企划
- 世界线：活动 024；制作人在制作的偶像：星南是美鈴、佑芽的制作人（本话没有直接写，沿用 main-01）

## 发生了什么
9月下旬，莉波整理了各班文化祭的摊位内容，星南说这次学生会的企划交给佑芽和美鈴。美鈴说学生会的大家对自己很重要，愿意做，又为自己总是缺乏主动性道歉，星南说燕听到可能会哭。美鈴说这次不能依赖千奈。数日后，两人被收集来的点子压得定不下来，美鈴提议翻看历年文化祭摊位记录，找到一个体验型解谜戏剧的企划，认为符合绝无仅有的特别回忆。美鈴说最后也由我们两个人做，佑芽同意。

## 她的关键台词
- 0011「いいえ……いまや生徒会の皆さんは、／わたしにとって大切な方々。」——被问是否嫌麻烦，回答学生会的人对自己很重要
- 0012「力になれるのなら、嬉しいです。／ぜひ、やらせていただきます。」——主动接下企划，用敬语和「嬉しい」表达
- 0013「申し訳ございません。／いつもながら……主体性のない後輩で。」——自评缺乏主体性，是道歉兼自嘲
- 0017「……大げさです。」——被说燕会哭时害羞
- 0019「もう、佑芽さん。／からかわないでください。」——被佑芽说害羞时的反应
- 0024「はい……ほどほどに。」——对佑芽的「がんばろうね」，仍保留「ほどほど」
- 0033「案を出してくださった本人は、／楽しんでくれるでしょうが。」——整理征集来的点子时指出问题：只对提出者有趣
- 0037「きっと佑芽さんと同じです。／先輩方に託された仕事ですから。」——说不会优先自己的想做的事，因为这是前辈托付的工作
- 0043「地道に動いてみましょうか。」——主张脚踏实地，先去查资料
- 0059「最後まで、ふたりで作りましょう。」——决定不借别人的手，两人做到底

## 行为模式
- 被托付工作 → 先礼貌地确认「面倒」与否，再说因为对方重要所以愿意做，同时自嘲主体性不足（0011～0013）
- 被调侃害羞 → 说「大げさです」「からかわないでください」，语气轻（0017、0019）
- 事情卡住 → 先整理现状，再提出翻看过去记录这类稳妥的办法（0030～0032、0043～0047）
- 找到可用的企划 → 先认可，再指出怎么改编能用，同时问是否要找别人帮忙（0052、0054、0055）
- 在佑芽开口前 → 自己把话说出来（0057、0059）

## 关系
- 星南：星南称她「美鈴」；她对星南的态度恭敬，听到「燕会哭」时害羞（0016、0017）
- 佑芽：称「佑芽さん」；佑芽称「美鈴ちゃん」，两人合作企划，她说话时多次顺着佑芽的节奏
- 手毬：佑芽问她想不想和「手毬ちゃん」办歌唱比赛，她说和佑芽一样，这是前辈交的工作（0036、0037）
- 千奈：称「倉本さん」，说这次不能依赖她（0020）

## 档案类事实
- 她把学生会成员视为重要的人（0011，本话学生会指星南、莉波、燕等人，剧本只点了星南和燕的名）
- 她说自己是个缺乏主体性的后辈（0013）
- 文化祭的企划由她和佑芽负责，参考了历年文化祭的资料（0007、0044、0045）
- 佑芽的话：她可能想和手毬一起办歌唱大赛（0036，佑芽的猜测，美鈴没有承认）
