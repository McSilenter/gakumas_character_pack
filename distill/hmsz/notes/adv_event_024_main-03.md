# 活动 024 / main-03 第3话（adv_event_024_main-03）

- 她的台词：11 行（含用匿名标签说的 0 行）：0003、0004、0008、0015、0017、0018、0019、0022、0030、0041、0043
- 出场的人：佑芽、千奈、美鈴、燕、星南（一同 0020、0026 齐声，不计）
- 场景：11 月（0001），学生会室附近，杂志编辑部的邮件采访作业交稿
- 世界线：活动 024；制作人在制作的偶像：星南是美鈴、佑芽的制作人（本话未直接写，沿用 main-01）

## 发生了什么
11月，佑芽、美鈴、千奈互相看星南布置的邮件采访作业。佑芽的内容是对咲季的感情，千奈写了关照自己的人。美鈴说她写的是学生会前辈们，递出稿子，大家看完全体沉默，佑芽和千奈劝她不要交给星南，说燕会生气。燕出现，三人被骂；美鈴说一起被骂不是也挺开心吗？星南说稿子虽需修改，但都写得好。燕让美鈴留下说教。结尾佑芽说美鈴和毕业的前辈们起了冲突，星南说马上去。

## 她的关键台词
- 0004「フリートークの欄には、／少々悩んでしまいましたが。」——自由谈话部分写得有些费神
- 0017「生徒会へのインタビュー企画ということ／でしたので……」——解释为什么写学生会的前辈们：这是面向学生会的采访
- 0018「いつもお世話になっている／生徒会の先輩方のことを。」——写的内容是照顾自己的学生会前辈
- 0022「はい……ぜひ、先輩方に／読んでいただきたいんです。」——被问是否要交给星南时，明确想让前辈们读
- 0030「申し訳ございません……でも、／こうやって一緒に叱られるの……／楽しくはありませんか？」——被燕骂时道歉，却说一起被骂也有乐趣，语气与前面的一致
- 0041「やりましたね。」——听到星南认可，简短的欢喜
- 0043「まあ……」——被燕要求居残时的反应，只有叹词

## 行为模式
- 被问作业完成没有 → 先答「もちろん」，同时说某部分有些头疼（0003、0004）
- 被朋友们看到稿子露出惊慌 → 不明白原因，平静地确认想让前辈们读，继续坚持（0021、0022）
- 被批评时 → 先道歉，再用一句「楽しくはありませんか？」把气氛转成与朋友共享（0030）
- 被点名居残 → 只说「まあ…」，没有争辩（0043）
