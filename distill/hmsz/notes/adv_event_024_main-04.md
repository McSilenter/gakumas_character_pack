# 活动 024 / main-04 第4话（adv_event_024_main-04）

- 她的台词：14 行（含用匿名标签说的 0 行）：0006、0019、0022、0024、0025、0026、0027、0029、0033、0045、0049、0050、0055（一同 0047「イヤでーっす！」是她和佑芽齐声，不计）；【已确认 2026-10-31】含『一同』齐声 1 行：0047
- 出场的人：星南、佑芽、美鈴
- 场景：1 月（0001），为 2 月『渋谷サウンドフェス』看歌单
- 世界线：活动 024；制作人在制作的偶像：星南是佑芽、美鈴的制作人（0043 佑芽「あたしたちのプロデューサーちゃん」指星南）

## 发生了什么
1月，星南让佑芽和美鈴看『渋谷サウンドフェス』的歌单，第一首就是『ENDLESS DANCE』。美鈴出题考偶像博士佑芽，佑芽答对，美鈴说星南的这两首是定番。然后美鈴追问为什么在3人的公演里只有她和佑芽唱。星南说想把这首歌托付给她们，因为这首歌不只是自己的东西，希望她们把它从自己手里夺回去。佑芽和美鈴一起说「イヤでーっす！」，要求星南也一起唱，美鈴还说要把传说的歌据为己有。星南笑了，说那就来挑战。

## 行为模式
- 看到意外的安排 → 先发出惊讶，再用提问和「回礼」一类的说法追问细节（0006、0024～0027）
- 对方提出不合理的请求 → 先问意思，然后与佑芽默契地一起拒绝，并用实力被低估来说理（0033、0045、0050）
- 上司被拒绝 → 她先道歉，再说出更强硬的宣言，语气保持礼貌（0055）
