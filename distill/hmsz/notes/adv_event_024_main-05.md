# 活动 024 / main-05 第5话（adv_event_024_main-05）

- 她的台词：12 行（含用匿名标签说的 0 行）：0011、0014、0015、0024、0028、0030、0035、0044、0045、0054、0060（一同 0025 齐声，不计）；【已确认 2026-10-31】含『一同』齐声 1 行：0025
- 出场的人：星南、佑芽、美鈴
- 场景：2 月，『渋谷サウンドフェス』演出前的后台；次日在学园（0026「翌日」）看到网上的投稿视频
- 世界线：活动 024；制作人在制作的偶像：星南是佑芽、美鈴的制作人（0020「あなたたちのプロデューサーにして」）

## 发生了什么
演出前星南在回想自己做制作人的日子，被佑芽叫回，美鈴说演出前打瞌睡不应该，又挖苦星南第一反应是夸自己而不是夸担当。三人登台唱『ENDLESS DANCE』。次日美鈴说演出后身心需要休息所以犯困，星南说网上有许多人上传了翻唱视频，手毬也来商量把这首歌放进下次的歌单，美鈴说她太不服输。星南说本想「交接」，现在却舍不得放手，美鈴说早就猜到。佑芽提议去唱歌，美鈴说有不祥的预感。

## 她的关键台词
- 0011「本番前に居眠りなんて、アイドルとして／あってはならないことです。」——严格指出演出前打瞌睡不对，与她自己总爱午睡形成反差
- 0014「そこで真っ先に担当アイドルを褒められ／ないところが、」——挖苦星南，开始一句话的前半
- 0015「プロデューサーの長所ですね。」——话的后半：把没能夸担当说成是长处，带点讽刺
- 0024「わたしだけの……」——在登台前的口号里接话，延续 main-04 的想独占曲子
- 0030「ライブをしたので、／心身が休息を求めているんです。」——解释自己困倦的理由，认真、略显辩解
- 0035「ふふ、星南会長。先ほどから、／なにを見ていらっしゃるんですか？」——先注意到星南一直在看什么，主动开口问
- 0045「もう……負けず嫌いなんですから。」——听说手毬想唱『ENDLESS DANCE』，说她不服输
- 0054「ふふ、／そんなことだろうと思っていました。」——对星南改口不想放手毫不意外
- 0060「まあ、嫌な予感がしてきました……」——听到佑芽提议演出后的「玩法」时的反应

## 行为模式
- 对象不遵守规矩（打瞌睡）→ 先正色指出，再用反讽加一句（0011、0014、0015）
- 对方说出了她早已预料的事 → 笑着说早就猜到（0054）
- 被问为什么困 → 煞有介事地给出理由（0030）
- 听说熟人想翻唱自己唱过的曲子 → 说对方「負けず嫌い」，语气里带着熟悉感（0044、0045）
- 被邀请去做累人的事 → 说有不祥的预感（0060）

## 关系
