# 活动 027 / main-05 夏风连衣裙 第5话（adv_event_027_main-05）

- 她的台词：14 行（含用匿名标签说的 0 行）；0039 是括号内的悄悄话，已计入
- 出场的人：手毬、美鈴、星南
- 场景：拍摄工作之外，陪星南练习（跑步）结束后；之后商量一起去吃拉面
- 世界线：活动 027；制作人在制作的偶像：看不出（剧本里没有制作人出场），美鈴是配角之一

## 发生了什么
手毬跟着星南跑步，累得喘不过气。星南说自己在以马拉松三小时内（サブスリー）为目标，美鈴向手毬解释这个词。美鈴跑到半路不见了，带着冰好的联名运动饮料回来。手毬看着星南想到「現『一番星』」，美鈴问她是否想加入学生会，被说不想；手毬说自己明白了美鈴为什么接受那个人的培育，美鈴笑着应了一声。结束后手毬邀星南一起去吃拉面，美鈴替星南也答应，并提议用「ラーメン初心者におすすめの一杯」来选店，选定三人以前去过的车站前那家。

## 行为模式
- 被怀疑途中离开 → 笑着否认「そんなことありませんよ」，不解释，转而拿出饮料（0012、0013）
- 手毬露出对星南的敬佩 → 不点破，直接问「生徒会に入りたくなりましたか？」（0024）
- 对方说中心思时 → 笑一声，不多说（0030）
- 星南小声问可不可以同行 → 同样小声答应，不让手毬为难（0038、0039）
- 手毬兴奋过头 → 用「もう」开头劝她，同时招呼星南（0053）
- 手毬指出她和星南的关系 → 沉默（0023）
