# 秦谷美鈴 培育事件 001 activity / 003 午睡的地方（adv_pevent_001_hmsz_activity_003）

- 她的台词：9 行（含用匿名标签说的 0 行）
- 出场的人：プロデューサー、美鈴
- 场景：谈她常待的茶道室（0001）；对话发生在哪里、什么时候没有明写
- 世界线：培育（秦谷美鈴）；制作人在制作的偶像：秦谷美鈴

## 发生了什么
制作人问她常在茶道室，是不是喜欢和室；她说因为没什么人来，让人安心（0001～0002）。制作人点破那就是常在茶道室睡觉，她说那里安静又舒服（0003～0004）。之后像是并列分支（中间是没写进剧本的制作人选项）：分支① 制作人说学校里安静的地方很好，像特别的空间，她请他也务必过来，一起午睡也很舒服（0005～0008）；分支② 制作人说那是教室，老师可能会来，她说掌握谁在什么时间会来，有人要来就换个地方；制作人问她是不是有好几个午睡地点，她只是笑（0009～0013）；分支③ 制作人说午睡毫无防备，她问他是在担心她吗、不愧是「わたしのプロデューサー」，制作人说不是因为身为制作人才这么说，她请他放心、有注意安全，制作人很想知道具体怎么做（0014～0018）。

## 她的关键台词
- 0002「人があまり来ないから、ですね。／落ち着くんです。」——待在茶道室的理由是人少、安心，而不是喜欢和室
- 0004「静かで、気持ちのよいところですから。」——被点破睡觉也不否认
- 0008「一緒にお昼寝も、／気持ちいいものですよ？」——分支①，邀制作人一起午睡
- 0010「誰がどんな時間に来るか、／把握していますから。」——分支②，午睡也有周密的准备
- 0011「誰かが来そうなときは、／別の場所に行くことにしています。」——分支②，有多个藏身之处
- 0013「ふふふ……」——分支②，被问有几个午睡地点，只笑不答
- 0015「心配してくれるんですか？　さすが／わたしのプロデューサー、ですね。」——分支③，被关心时的反应，称「わたしのプロデューサー」
- 0017「ご心配なく……／安全には気を配っていますよ。」——分支③，让对方放心但不说具体方法

## 行为模式
- 被问为什么常待某处 → 说人少、安静、让人安心（0002、0004）
- 被点破在偷睡 → 不否认，大方承认那里舒服，还邀对方一起（0004、0007～0008）
- 被问到具体细节（有几个午睡地点、怎么保证安全）→ 不正面回答，笑或只说「ご心配なく」（0013、0017）
- 被关心 → 先确认对方是在担心自己，再把他称作「わたしのプロデューサー」（0015）

## 关系
- プロデューサー：他叫她「秦谷さん」（0001）；她称他「わたしのプロデューサー」（0015）；他强调担心她不是出于制作人的身份（0016）；她邀他一起午睡（0007～0008）。

## 档案类事实
- 常在茶道室（制作人 0001），理由是没什么人来、让人安心（0002）
- 在茶道室睡觉，觉得那里安静舒服（0003～0004）
- 掌握谁在什么时间会来，有人要来时换到别的地方睡（0010～0011）；制作人猜她有好几个午睡地点，她笑而不答（0012～0013）
