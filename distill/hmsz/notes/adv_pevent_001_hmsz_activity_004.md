# 秦谷美鈴 培育事件 001 activity / 004 去看展览吧（adv_pevent_001_hmsz_activity_004）

- 她的台词：14 行（含用匿名标签说的 0 行）
- 出场的人：美鈴、プロデューサー
- 场景：她想出门的一天（0001），为了学校的作业去看展览（0002）；地点在商量中
- 世界线：培育（秦谷美鈴）；制作人在制作的偶像：秦谷美鈴

## 发生了什么
制作人问她今天想出门去哪里；她说有作业，要去美术馆或博物馆调查感兴趣的展览，难得有机会，想让制作人来决定去哪里，问他知不知道在办什么展览（0001～0004）。之后像是并列分支（中间是没写进剧本的制作人选项，像是他提出的展览）：分支① 书法展：制作人说她字漂亮，以为她练过毛笔、硬笔，她说没挑战过展出作品那样大胆的运笔，但答应去看、说很期待（0005～0008）；分支② 有和服、和纸的展览：她说听起来很有意思，畅想慢慢看沉静的展品、遐想文化的深奥，最后买把扇子当纪念（0009～0013）；分支③ 制作人提的是百货店：她说那既不是美术馆也不是博物馆，但个人非常感兴趣，提议先去看文化展览，回程在百货店午睡（0014～0018）。

- 0011「落ち着いた展示を／ゆっくりと見回って……」——分支②，喜欢沉静、慢节奏
- 0013「お土産に扇子を買いましょう。」——分支②，畅想到买纪念品
- 0016「個人的にはとても／興味をそそられます。」——分支③，对偏离作业的提议也感兴趣
- 0018「その帰りに、百貨店で／お昼寝していきましょう。」——分支③，作业和午睡两头都要

## 行为模式
- 自己的事 → 交给制作人决定，并问他的意见（0003～0004）
- 被夸字漂亮 → 谦虚地说没挑战过大胆的运笔，但不推辞（0007～0008）
- 对方提和风、传统的东西 → 很快进入状态，一句接一句地畅想（0010～0013）
- 对方的提议偏离正题 → 先指出偏了，再说自己很感兴趣，把正事和想做的事（午睡）安排在一起（0014～0018）

## 关系
- プロデューサー：她请他决定去哪里（0003）；他叫她「秦谷さん」，夸她字漂亮（0006）。
