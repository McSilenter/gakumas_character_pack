# 秦谷美鈴 培育事件 001 activity / 011 和制作人的日常（adv_pevent_001_hmsz_activity_011）

- 她的台词：8 行（含用匿名标签说的 0 行）
- 出场的人：プロデューサー、美鈴
- 场景：谈学校作业（0001～0002）；地点看不出
- 世界线：培育（秦谷美鈴）；制作人在制作的偶像：秦谷美鈴

## 发生了什么
她说有一份只给有制作人的学生的作业，要把和制作人的日常写成报告，问写什么（0001～0003）。之后像是并列分支（中间是没写进剧本的制作人选项）：分支① 制作人提议写课程（レッスン），说次数少是个难点但老师想听的应该是这个，叮嘱要写「ちゃんとやっている」，她说不用担心、会照实写，制作人心想应该没问题、大概（0004～0008）；分支② 制作人说课程内容训练员会报告，提议写休日的事，她说要写她照顾制作人的事，制作人要求提交前先给他看（0009～0013）；分支③ 制作人提议坦率写两人的关系，她说写信赖关系，内容是他「放っておいてくれる」，制作人说写法要下点功夫（0014～0017）。

## 她的关键台词
- 0002「はい……プロデューサーが／ついている生徒だけの課題です。」——有制作人的学生才有的作业
- 0007「まあ……心配はいりませんよ。／ありのままを書きますから。」——分支①，「照实写」反而让人不安
- 0012「プロデューサーの／お世話をさせていただいたことを。」——分支②，休日写的是她照顾他
- 0015「わたしとプロデューサーの／信頼関係について、ですね。」——分支③，把两人的关系叫作信赖关系
- 0016「では、わたしのことを／放っておいてくれる……と。」——分支③，信赖的内容是不管她

## 行为模式
- 被叮嘱写得好看一点 → 说「ありのまま」写，不顺着对方的意思修饰（0006～0008）
- 被问休日的事 → 想写自己照顾了他（0012）
- 谈两人关系 → 把「放っておいてくれる」当成对他的信赖，说得一本正经（0015～0016）

## 关系
- プロデューサー：她把两人的关系称为「信頼関係」，内容是他「放っておいてくれる」（0015～0016）；休日她照顾他（0012）；他担心她写出来的内容，要求先看（0013、0017）。

## 档案类事实
- 学校有只给有制作人的学生的作业，要写和制作人的日常报告（0001～0002）

## 不确定

- 0004「回数が少ないのがネックですが」指什么的次数少（像是课程），制作人前面的提议没写全，看不准。
