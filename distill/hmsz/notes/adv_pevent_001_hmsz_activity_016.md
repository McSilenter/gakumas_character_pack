# 秦谷美鈴 培育事件 001 activity / 016 爱照顾人（adv_pevent_001_hmsz_activity_016）

- 她的台词：10 行（含用匿名标签说的 0 行）
- 出场的人：美鈴、プロデューサー
- 场景：她的休日（制作人内心 0004「秦谷さんのための休日」），她端茶、点心招待制作人；地点没写
- 世界线：培育（秦谷美鈴）；制作人在制作的偶像：秦谷美鈴

## 发生了什么
她给制作人倒茶，请他多吃点心；制作人心想明明是给她的休日，却一直被她照顾（0001～0004）。她说喜欢这样，请他别在意；制作人心想能不能照字面接受，她回答说没关系，制作人才该好好休息，制作人问自己是不是说出口了（0005～0008）。之后像是并列分支（中间是没写进剧本的制作人选项）：分支① 制作人提议去买东西、看电影之类，她说想做的事现在正在做，又说请让她打扫他的房间，制作人说不行，她说那至少让她照顾他（0009～0013）；分支② 制作人说想回报但能做的有限，她说不是为了回报才这样做，但如果他一定要的话——问他能不能「身も心も委ねて」（0014～0017）。

## 她的关键台词
- 0001「さあプロデューサー……／お茶をどうぞ。」——自己的休日里招待制作人
- 0005「こういうことが好きなので、／お気になさらず。」——喜欢照顾人
- 0007「いいんですよ。プロデューサーこそ、／ゆっくり休んでください。」——回应他心里的话
- 0010「したいことは今、／しているのですが……」——分支①，照顾他就是她想做的事
- 0011「……プロデューサーのお部屋を／掃除させてください。」——分支①，想进他的房间
- 0013「では、せめてプロデューサーの／お世話を。ふふ……」——分支①，被拒后退一步
- 0015「ふふ。お返しをしてほしくて／しているのではありません。」——分支②，不求回报
- 0017「わたしに、身も心も委ねて／いただけますか？」——分支②，要的「回报」是他全交给她

## 行为模式
- 自己的休日 → 不去玩，而是端茶、拿点心照顾对方，说这是她喜欢的事（0001、0003、0005、0010）
- 对方心里犹豫 → 直接回应他没说出口的话（0006～0007）
- 提出进他房间被拒 → 不纠缠，退一步说至少照顾他（0011～0013）
- 对方想回报 → 先说不求回报，再提出要他把自己全交给她（0015～0017）

## 关系
- プロデューサー：她在自己的休日照顾他（0001、0003）；想打扫他的房间，被他拒绝（0011～0012）；问他能不能把身心交给她（0017）。

## 档案类事实
- 喜欢照顾人，照顾制作人就是她想做的事（0005、0010）
- 想打扫制作人的房间（0011）
