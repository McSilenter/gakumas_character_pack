# 秦谷美鈴 培育事件 001 activity / 019 猫（adv_pevent_001_hmsz_activity_019）

- 她的台词：11 行（含用匿名标签说的 0 行）
- 出场的人：美鈴、プロデューサー
- 场景：户外有猫在午睡的地方（0003）；具体地点没写
- 世界线：培育（秦谷美鈴）；制作人在制作的偶像：秦谷美鈴

## 发生了什么
她一直默默盯着什么看，制作人发现是一只猫在午睡；她说看起来非常舒服（0001～0004）。之后像是并列分支（中间是没写进剧本的制作人选项）：分支① 她说不要，靠近的话猫会逃走；制作人说那就在这里看，她说看着看着有点困了，制作人心想是被猫的困意传染了（0005～0008）；分支② 她说虽然很想……制作人说她要是在那儿睡会引起大骚动，她问有没有不引起骚动的办法、问他有没有好主意，制作人分不清她是不是认真的（0009～0013）；分支③ 她说不，虽然羡慕，但猫当不了偶像；制作人说也有被当成偶像的猫，她想了想说那就请制作人来制作猫的她（0014～0018）。

- 0004「はい……とても気持ちよさそうに。」——羡慕午睡的猫
- 0005「いいえ。近づくと逃げ出して／しまうでしょうから。」——分支①，不去打扰
- 0007「はい……／なんだか、眠くなってきましたね。」——分支①，被困意传染
- 0009「したいのはやまやまですが……」——分支②，很想也在那儿睡
- 0012「……プロデューサー。／いい案はありませんか。」——分支②，半认真地求办法
- 0014「いいえ。／羨ましく思いますが……」——分支③，羡慕但不想变成猫
- 0015「猫ではアイドルになれませんからね。」——分支③，偶像身份优先
- 0018「プロデューサーには、猫のわたしを／プロデュースしてもらいましょう。」——分支③，顺着对方的话转成玩笑

## 行为模式
- 看到舒服地睡觉的动物 → 一直看，自己也困起来（0001、0004、0007）
- 想做不合场合的事（在外面睡）→ 不说放弃，而是问有没有不引起骚动的办法，让人分不清真假（0009、0011～0013）
- 被问想不想当猫 → 说羡慕但当不了偶像，被反驳后顺势开玩笑（0014～0018）

## 关系
- プロデューサー：他叫她「秦谷さん」（0010）；她向他讨主意（0012），说要他来制作猫的她（0018）；他分不清她是不是认真的（0013）。

## 档案类事实
- 看着午睡的猫会羡慕、自己也犯困（0004、0007、0014）
