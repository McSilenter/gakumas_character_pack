# P卡 有村麻央【SUGAR FLAVOR】 / 第3话 SUGAR FLAVOR 第3话（adv_cidol-amao-3-017_03）

- 她的台词：15 行（含用匿名标签说的 0 行）
- 出场的人：麻央（22 行）、莉波（15）、プロデューサー（8）、ビジュアルトレーナー（5）
- 场景：地点剧本没写明。前段麻央和制作人谈曲子（她不在场），之后她和麻央两人讨论，再去请教ビジュアルトレーナー
- 世界线：亲爱度（有村麻央）·P卡；制作人在制作的偶像：有村麻央（0013 制作人说是自己スカウト了麻央）

## 发生了什么
制作人说这首表现“揺れる恋心”的ラブソング是为了展现麻央的新魅力；麻央说要和她两人一起想（0001～0016）。麻央问她平时在カラオケ唱ラブソング是什么心情，她说大概是恋爱中女孩的心情，但唱卡拉OK时可能没想那么多；又说『SUGAR FLAVOR』是她和麻央的曲子，必须认真面对（0017～0020）。她提议参考麻央常看的以爱情为主题的戏，麻央提出把歌词当作戏来演，她说这适合麻央，提议练练看（0022～0026）。麻央对她演了一段，她说“有点不对”，又提议去请教看起来懂恋爱的人（0027～0035）。ビジュアルトレーナー说最重要的是唱出她们真实的心情；麻央提出唱她们自己——3年来像恋爱一样渴望着的对偶像的感情，她赞成，说要把只有她们能唱的ラブソング传达给大家（0039～0050）。

## 她的关键台词
- 0018「ええっと、そうだねえ……／恋する女の子の気持ち……？」——被问时边想边答
- 0019「でも、カラオケで歌うときは、／そこまで考えてないかも。」——坦白自己没深想过
- 0020「『SUGAR FLAVOR』は、／麻央と私のための曲だから、／しっかり向き合わないと。」——认真对待两人的曲子
- 0022「麻央は、よくお芝居観に行くでしょ？」——从麻央的兴趣出发想办法
- 0026「麻央には向いたやり方かもね。／ちょっと、練習してみよっか。」——肯定麻央的方法、提议马上试
- 0029「うーん。ちょっと、違うかも。」——对麻央的演技直说不对
- 0031「恋、かぁ……難しいよね。」——不对之后和麻央一起犯难
- 0035「恋に詳しそうな人に、／アドバイスしてもらおっか。」——主动提议找人请教
- 0048「……うん、それ、いいかも。」——赞成麻央的想法
- 0049「私たちにしか歌えない、／私たちのラブソング――」——接着麻央的话说出两人的方向
- 0050「みんなに届けよう。」——把两人的歌指向粉丝

## 行为模式
- 被问到自己不擅长思考的事 → 边想边答，最后坦白没想那么多（0018、0019）
- 面对两人的工作 → 说“しっかり向き合わないと”，认真起来（0020）
- 一起想办法时 → 从对方的兴趣、长处出发提议，并提议立刻试（0022、0023、0026）
- 对方的尝试不对 → 温和但直接地说“ちょっと、違うかも”（0029）
- 卡住时 → 提议去找人请教（0033～0035）
- 对方提出好方向 → 赞成，并把它说成两人共同的目标（0048～0050）

## 关系
- 麻央：叫「麻央」（0020、0022、0026）；麻央叫她「莉波」（0017、0044）。两人一起为『SUGAR FLAVOR』想办法，她说这是“麻央と私のための曲”（0020）；麻央说两人3年来一直渴望着当偶像（0046、0047）。
- ビジュアルトレーナー：她提议去请教（0035）；本篇她没有和训练员直接对话。
- プロデューサー：本篇她和制作人没有同场对话。

- 和麻央一起唱『SUGAR FLAVOR』（0020）
