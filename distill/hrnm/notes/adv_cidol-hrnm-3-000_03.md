# P卡 姫崎莉波【clumsy trick】 / 第3话 clumsy trick 第3话（adv_cidol-hrnm-3-000_03）

- 她的台词：22 行（含用匿名标签说的 0 行）；其中 0033 是括号里的心里话
- 出场的人：莉波（22 行）、プロデューサー（10）、スタッフ（1）
- 场景：live 正式开始前，能看到观众的地方（0001、0028）
- 世界线：亲爱度（姫崎莉波）·P卡；制作人在制作的偶像：姫崎莉波

## 发生了什么
开场前她看到满场观众，说虽然紧张但很幸福，希望来的人也觉得这是为自己写的歌（0001～0007）。沉默之后她道歉，承认刚才是逞强，其实害怕：这首歌是她的心情结晶、就是她本身，怕传达不了、不被接受（0009～0015）。制作人说不安和害怕都不用藏，放进歌里唱，这首歌唱的就是迈不出第一步的人（0016～0023）。她想通了：现在不安的样子就是真实的自己，坦率唱就好（0024～0026）。制作人被工作人员叫走后，她说要把心情送到舞台上，末尾在心里补了一句“要传达给你”（0030～0033）。

## 她的关键台词
- 0004「きみが私のためにプロデュース／してくれた、最初の曲――」——这首歌对她的意义
- 0005「こんなに大勢のお客さんの前で／歌えるなんて、すごく幸せだよ。」——先说幸福
- 0007「この曲は自分のための曲だって、／思って欲しいなって。」——对观众的愿望
- 0010「……ごめん、{user}くん。／強がっちゃったけど、」——自己拆穿逞强
- 0011「……やっぱり、／ちょっと、怖いんだ。」——承认害怕
- 0012「この曲は、私の気持ちの結晶で、／私そのものだから――」——为什么怕
- 0015「こんな不安な気持ちじゃ、／うまく歌えない、よね……」——向他求证
- 0025「今、受け入れてもらえるか、／不安に思ってるのが、ありのままの私。」——接受不安
- 0031「私の素直な気持ち、／ステージで届けてくるよ。」——上台前的决意
- 0033「（――きみに届くように）」——心里话，没说出口；真正想传达的对象

## 行为模式
- 大场面前 → 先说漂亮话给对方听，之后在他面前主动承认是逞强（0005～0007、0010、0011）
- 害怕时 → 能把害怕的原因说清楚，并问对方“这样不行吧”（0012～0015）
- 被告知不用藏 → 重新理解后自己复述一遍，变成自己的话（0024～0026）
- 对他的心意 → 说出口的是对观众，后半句只放在心里（0031～0033）

## 关系
- 制作人：叫「{user}くん」（0010、0030），也说「きみ」（0004）。本话制作人没有叫她的名字。只有对他才说出“其实害怕”（0010、0011）；舞台要送达的对象，她心里加上了他（0033）。

## 档案类事实
- 她说这首歌是制作人为她做的第一首（0004）
- 上台前会害怕歌不被接受（0013）

## 不确定
- 0004 的“最初”是指制作人为她做的第一首，还是她的第一首 solo，原文只说「最初の曲」。
