# P卡 姫崎莉波【与你共度的湛蓝夏日】 / 第3话 与你共度的湛蓝夏日 第3话（adv_cidol-hrnm-3-001_03）

- 她的台词：28 行（含用匿名标签说的 0 行）
- 出场的人：莉波（28 行）、プロデューサー（9）
- 场景：水族馆那天，海边，有夕阳（0001、0018）
- 世界线：亲爱度（姫崎莉波）·P卡；制作人在制作的偶像：姫崎莉波

## 发生了什么
看海时她请求再待一会儿（0003），说看着大海觉得自己渺小，最近状态不好，可能是因为三年级最后的夏天在着急，本想找他商量（0006～0009）。她说他好像早就看穿了，他答从小就认识她（0010、0011）。她笑着说今天尽情撒娇了，是“姐姐”当久了的反作用（0012、0013）。她说今天是宝物一样的日子，长大也不会忘（0017～0020）。他送了海豚钥匙扣，她很开心，又说自己总是收他的东西（0025～0031）。她逗他说长大了，让姐姐心跳了，他招架不住，她说这点没变，稍微安心了（0032～0036）。

- 0003「……もう少しだけ、ダメかな？」——舍不得结束

- 0007「なんかね、最近調子が出なくて。」——说出烦恼
- 0008「3年生、最後の夏だから／焦っているのかな……」——她猜的原因
- 0012「ふふっ。だから／今日はたくさん甘えちゃった。」——承认撒娇
- 0013「…………お姉さんの反動が／きちゃったのかな。」——“姐姐”这个角色的累
- 0018「この海みたいにキラキラした／宝物みたいな一日だったなぁ……」——珍惜这一天
- 0020「きっと、大人になっても。」——对未来的话
- 0031「…………本当、きみからは／もらってばかりだなぁ。」——感慨

- 0036「ちょっと安心しちゃった。／……なんてね。」——说完收回
- 0037「――ありがとう。宝物にするね。」——收礼

## 行为模式
- 心里有烦恼 → 本想找他商量，到了海边才说出来（0007～0010）
- 说了软弱的话 → 用笑和“姐姐”的说法收尾（0012、0013）
- 害羞或说了真心话 → 转去逗对方，再用「なんてね」收回（0033、0036）
- 收到礼物 → 先问能不能打开，再直说高兴（0023、0025、0029）

## 关系
- 制作人：叫「{user}くん」（0016），也说「きみ」（0031、0033）；制作人叫她「姫崎さん」（0011、0021）。她对他自称「お姉さん」（0033）。他说从小就认识她（0011）。她说他长大了，又说不好意思的样子没变（0033、0035）。
