# P卡 姫崎莉波【欢迎来到初星温泉】 / 第2话 欢迎来到初星温泉 第2话（adv_cidol-hrnm-3-004_02）

- 她的台词：25 行（含用匿名标签说的 0 行）
- 出场的人：莉波（25 行）、プロデューサー（9）
- 场景：周末森林浴的地方，有河（0009、0020）
- 世界线：亲爱度（姫崎莉波）·P卡；制作人在制作的偶像：姫崎莉波

## 发生了什么
午餐她做的便当被他称赞，她说是想让他也放松（0001～0007）。她说自然的声音让她想起老家，感到怀念，提议散步（0008～0013）。在河边她发现小鱼，叫他看，又提醒他别掉下去（0014～0018）。她说小时候可能会在河里玩，但现在这个时节水冷会感冒，说要玩的话得准备大毛巾，两人说下次吧（0021～0026）。她说来这里是对的，心都被治愈了（0027、0028）。走远后看到建筑，他一查是温泉，她惊讶（0031～0034）。

## 行为模式
- 被称赞做的饭 → 先说放心了，再说“是想让你放松”（0002、0003）
- 看到小生物 → 叫对方看，同时提醒小心（0014、0015、0018）
- 对方提议孩子气的事 → 提实际问题，但也接着说要准备什么（0023、0024）
