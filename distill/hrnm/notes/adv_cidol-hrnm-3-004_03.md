# P卡 姫崎莉波【欢迎来到初星温泉】 / 第3话 欢迎来到初星温泉 第3话（adv_cidol-hrnm-3-004_03）

- 她的台词：22 行（含用匿名标签说的 0 行）；其中 0004、0005、0020、0021 是括号里的心里话
- 出场的人：莉波（22 行）、プロデューサー（8）
- 场景：第 2 话发现的温泉，泡汤中（0002）；两人的位置关系见不确定
- 世界线：亲爱度（姫崎莉波）·P卡；制作人在制作的偶像：姫崎莉波

## 发生了什么
泡着汤她舒服地感叹，想起现在没有别的客人，试着喊他，他答应，说是包场状态（0002～0007）。她说碰巧来到真好，温泉很棒（0009～0013）。他说她真喜欢温泉，她说最喜欢，又问他放松了没有（0014～0016）。他说和她悠闲度过也算放松，她害羞，心里想这人太狡猾，随后说还会再约他（0017～0023）。他说明天起一起加油，让更多粉丝知道她的魅力（0025、0026），她说自己也会加油，要成为能治愈大家的姐姐，当然也包括他（0028～0030）。

## 行为模式
- 放松时 → 主动搭话，先问对方在不在（0006）
- 被他无心的话说中 → 说不出话，心里说他狡猾，然后转成一句“还要约你”（0019～0023）
- 谈到工作和未来 → 说要成为治愈大家的姐姐，最后加上他（0029、0030）

## 关系
- 制作人：叫「{user}くん」（0006、0023），也说「きみ」（0016、0030）；制作人叫她「姫崎さん」（0014、0018）。她说要继续约他（0023）。
