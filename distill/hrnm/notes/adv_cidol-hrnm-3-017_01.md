# P卡 姫崎莉波【荆棘之路】 / 第1话 荆棘之路 第1话（adv_cidol-hrnm-3-017_01）

- 她的台词：28 行（含用匿名标签说的 0 行）；其中 0022、0023、0026、0027、0029～0032 是括号里的心里话；0033 是哼唱（“……～♪”）
- 出场的人：莉波（28 行）、プロデューサー（12）
- 场景：レッスン中（0003）；0021～0034 是她回想去他房间看病的场面（0022）
- 世界线：亲爱度（姫崎莉波）·P卡；制作人在制作的偶像：姫崎莉波

## 发生了什么
他来到レッスン现场，为最近没常来道歉，她问他背着“姐姐”在准备什么，他说有保密义务（0001～0009）。他说不会累倒，话没说完想起自己以前倒下过，痛苦地说想揍以前的自己（0011～0015）。她说起那件事，说最初两人都在摸索（0016～0020）。回想中她进了他的房间做粥，心里慌，又说是为了以姐姐身份照顾弟弟（0021～0023）；看到他排满的日程，想起小时候迷路第二天他病倒，自己带了点心冰激凌，后来被妈妈骂（0026～0032）。回到现在，他说再也不会犯，她要他约定身体不舒服之前就休息（0035～0040）。

## 行为模式
- 他太拼 → 用姐姐口吻叮嘱、要他做约定（0010、0039、0040）
- 冲动做了什么 → 心里慌，然后找“作为姐姐”的理由（0022、0023）
- 照顾他 → 想起小时候照顾的事（0029～0032）

## 关系
- 制作人：叫「{user}くん」（0002、0034），也说「きみ」（0035、0038）；他叫她「姫崎さん」（0001、0018）。她对他自称「お姉さん」（0007、0040），回想里称他「弟くん」（0023）。他说当时在考虑怎么当她的弟弟（0018）。

## 档案类事实
- 制作人在两人刚开始时病倒过，她去他房间照顾并做粥（0016、0021～0025）
- 小时候森林迷路那天（她说夏祭的日子）第二天，他病倒，她带了点心和冰激凌，后来被妈妈骂了（0029～0032）

## 不确定
- 0021～0034 回想部分的时间剧本没标，按 0016 的话理解是之前倒下的那次。
- 0029 她心里说是夏祭的日子；3-013 第 3 话 0032 她说是花火大会那天，没有当成冲突。
