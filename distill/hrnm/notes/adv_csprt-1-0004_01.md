# S卡 1-0004【頼れる先輩お姉さん】 / 第1话 曾经的回忆（adv_csprt-1-0004_01）

- 她的台词：12 行（含用匿名标签说的 0 行）；其中 0001、0002、0014、0015、0016 是演练用的台词（对想象中的对象道谢），不是她本人此刻的话
- 出场的人：莉波、ビジュアルトレーナー
- 场景：造型（ビジュアル）课上的演技练习（0003、0006）
- 世界线：S卡【頼れる先輩お姉さん】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
莉波在练习演绎“送手帕来的人”的道谢台词，训练师说稍微有点生硬，说可能是太在意「妹っぽさ」，让她先放下自己的情况，想着亲近的人再试一次。莉波想了亲近的人后重说一遍，被训练师称赞展现了她的优点，她道谢后轻轻笑了。

## 她的关键台词
- 0001「あのっ……ハンカチ、届けてくれて／ありがとうございますっ！」——练习台词（第一次），带有“妹妹”意识的生硬演法
- 0004「っ……すみません。」——被指出不足时马上道歉
- 0007「は、はいっ。」——被说“一起想办法”后紧张应答
- 0009「妹っぽさ……それは。」——被点到“妹っぽさ”时欲言又止
- 0013「親しい人……／親しい……ん。」——认真想亲近的人，想了又想
- 0014「あの……ハンカチ、届けてくれて／ありがとうございます。」——练习台词（第二次），以亲近的人为对象
- 0016「ぜひ、お礼をさせてください。」——练习台词结尾，比第一次更自然
- 0019「あ、ありがとうございます！」——被称赞后道谢
- 0020「……ふふ。」——事后轻笑

## 行为模式
- 被指出不足 → 立刻道歉，被说“不用道歉”后接受并继续（0004、0007）
- 被点到触及自己情况的话题 → 语气停住（0009）
- 被要求想象亲近的人 → 认真思考后重做，效果变好（0013、0014-0016）
- 被称赞 → 礼貌道谢，之后轻声一笑（0019、0020）

## 关系
- ビジュアルトレーナー：对她用敬语；训练师叫「あなた」，说“你的情况我知道”（0010）
- 其他：无
