# S卡 2-0026【ぐつぐつ、いいにおい♪】 / 第2话 明天见（adv_csprt-2-0026_02）

- 她的台词：13 行（含用匿名标签说的 0 行；0005 是括号里的心里话）
- 出场的人：莉波、美鈴
- 场景：做饭的厨房，接上一话；做完后互相道别（0016～0020）。
- 世界线：S卡【ぐつぐつ、いいにおい♪】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
莉波让美鈴削土豆皮，自己切洋葱，提到土豆要去芽，发现美鈴已经削得很快、芽也处理干净了。美鈴看到洋葱已被切成很多碎，说莉波擅长做饭。莉波说不知道是否擅长但喜欢，并问美鈴是否常做饭，美鈴说和食在家里常做。莉波提议下次一起做和食，请她教自己。做完后两人互相道谢，莉波说明天学生会有集会，所以明天见。剧情经过参照 hmsz 笔记。

## 她的关键台词
- 0001「じゃあ、／じゃがいもの皮を剥いてくれる？」——分配工作，请美鈴削皮
- 0003「あ、じゃがいもは芽を……」——提醒去芽，话说到一半
- 0005「（剥くの早い！／それにちゃんと芽も取ってる）」——心里惊叹美鈴的手艺
- 0006「ううん、なんでもない。」——把原来要提醒的话收回
- 0009「得意かはわからないけど、／料理は好きかな……？」——被说擅长时不肯定，只承认"喜欢"
- 0010「美鈴ちゃんは料理よくするの？／じゃがいも剥くの上手だよね！」——反问并夸奖
- 0013「じゃあ今度は和食を／一緒に作るのはどうかな？」——提议下次一起做和食
- 0014「色々教えてほしいなって。」——说明想请美鈴教自己
- 0018「こちらこそだよ。／今日は付き合ってくれてありがとう。」——对美鈴的"今天很开心"回应
- 0019「明日は生徒会の集まりもあるし、／また明日、だね。」——道别时提到明天的学生会集会

## 行为模式
- 想提醒别人时 → 先开口，发现对方已经做对，就收回（0003、0005、0006）
- 被夸 → 不直接肯定，转为"喜欢"并反夸对方（0009、0010）
- 觉得对方有长处 → 马上提议下次由对方教（0013、0014）
- 道别 → 对等回谢，带上明天的安排（0018、0019）

## 关系
- 美鈴：称呼「美鈴ちゃん」（0010、0016）；美鈴叫她「莉波先輩」（美鈴 0008）。两人约定下次一起做和食，明天见（0013、0019）。

## 档案类事实
- 会切洋葱切得很碎（美鈴 0007 观察）
- 说自己"料理は好き"但不确定是否擅长（0009）
- 明天有生徒会的集まり（0019），她与学生会有关
- 想学和食（0013、0014）

## 不确定
- 0019 的"生徒会の集まり"是两人都出席还是只有莉波，剧本没写；「また明日」是约在集会上见，还是别的，也没明说。
