# S卡 2-0082【ふたりで衣装作り】 / 第2话 万圣节快乐！（adv_csprt-2-0082_02）

- 她的台词：6 行（含匿名标签 0 行）；其中 0019、0020 是括号里的心里话；0001 是万圣节的「トリック・オア・トリート」招呼
- 出场的人：莉波（6）、咲季（6）、佑芽（5）、ことね（2）、リーリヤ（1）、清夏（1）
- 场景：万圣节当天，要求吃糖的活动（莉波 0009 提到生徒会的活动）；具体地点未明说
- 世界线：S卡【ふたりで衣装作り】；制作人在制作的偶像：看不出

## 发生了什么
莉波向ことね要糖，拿到她和弟妹一起烤的饼干。莉波之后慰问咲季帮忙生徒会活动，咲季说自己想和佑芽一起做搭配。佑芽拿到很多糖，邀咲季比谁拿得多，两人开始较劲。莉波看着觉得她们关系好，心想要给汐莉看僵尸的照片。剧情经过参照 hski、hume 笔记。

## 她的关键台词
- 0001「トリック・オア・トリート。／お菓子をくれないと、／悪戯しちゃうよー。」——万圣节招呼，语气是轻松玩笑的
- 0003「わ、ありがとう。上手に焼けてるね。」——收到饼干后称赞
- 0009「咲季ちゃん、お疲れ様。／生徒会のイベント、／手伝ってくれてありがとう。」——慰问并感谢帮忙生徒会活动的后辈
- 0015「わ、佑芽ちゃん。すごいねぇ。」——对后辈的成果反应惊讶
- 0019「（ふふ、仲いいなぁ……）」——心里话，看着姐妹较劲时觉得她们关系好
- 0020「（……汐莉、元気かな。／あとでゾンビの写真、見せよっと）」——心里话，想到汐莉，打算给她看僵尸的照片

## 行为模式
- 对方给了东西 → 先出声感叹，再具体称赞（0003）
- 后辈帮了忙 → 先说「お疲れ様」再道谢（0009）
- 看到姐妹争胜负 → 不插话，在旁边笑着看，心里想到家人（0019、0020）

## 关系
- ことね：对她没有称呼，只是接过她的饼干（0003）
- 咲季：称「咲季ちゃん」，感谢她帮忙生徒会活动（0009）；咲季的回答里没有称呼她
- 佑芽：称「佑芽ちゃん」；佑芽称她「莉波先輩」（佑芽 0011）
- 汐莉：只在心里提到，想给她看僵尸的照片（0020）
