# S卡 3-0005【次の桜の季節には。】 / 第3话 各自的方法（adv_csprt-3-0005_03）

- 她的台词：10 行（含匿名标签 0 行）
- 出场的人：麻央（10）、莉波（10）
- 场景：樱花开始飘落的时候，地点未明说；提到「寮のみんな」
- 世界线：S卡【次の桜の季節には。】；制作人在制作的偶像：看不出

## 发生了什么
莉波提议在樱花落尽前和宿舍的大家赏花，麻央答应联络后辈。莉波接着请麻央帮忙生徒会，说麻央受大家仰慕又可靠，适合；麻央拒绝。莉波接受，说自己喜欢偶像，当然想当偶像，但也喜欢支援想当偶像的人，所以希望能帮上大家，被麻央说帮过很多人，她高兴地回应。

## 她的关键台词
- 0002「ぜんぶ散っちゃう前に、／寮のみんなでお花見でもしようか。」——提议和宿舍的大家赏花
- 0004「……ありがとう。あ、そうだ――／麻央、ちょっと相談があるんだけど。」——道谢后切入正题
- 0005「その、もしよかったら、／生徒会を手伝ってくれないかなぁ。」——委婉地邀请对方
- 0007「うん、麻央はみんなに慕われてるし、／頼りになるし、向いてると思うんだ。」——说明为什么邀请麻央
- 0009「そうかなあ……」——被拒绝时没有强求
- 0015「……そっか。うん、わかったよ。」——接受拒绝
- 0016「私はアイドルが好きだから、／もちろんアイドルになりたいけど、」——说自己喜欢偶像，想当偶像
- 0017「アイドルを目指す子たちを／応援するのも好きなんだよね。」——也喜欢支持志向偶像的人
- 0018「だから、少しでもみんなの／役に立てれば嬉しいなって思うんだ。」——说明做生徒会的原因
- 0020「えへへ、そうだといいな。」——被夸后不好意思地回应

## 行为模式
- 想请人帮忙 → 先说「もしよかったら」，再给出对方适合的理由（0005、0007）
- 被拒绝 → 不强求，说「わかった」，之后说出自己的想法（0009、0015、0016）
- 被夸 → 笑着回应「そうだといいな」（0020）

## 关系
- 麻央：称「麻央」，认为她受人仰慕、可靠；麻央称她「莉波」，尊敬她做生徒会（0007；麻央 0013）

## 档案类事实
- 做生徒会工作，喜欢偶像，想成为偶像，也喜欢支持想当偶像的人（0016、0017、0018；麻央 0013）
- 提议在宿舍的大家一起赏花（0002）
