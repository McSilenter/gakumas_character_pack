# S卡 3-0034【二人ならあっという間だね】 / 第1话 彼此喜欢的地方（adv_csprt-3-0034_01）

- 她的台词：12 行（含用匿名标签说的 0 行）
- 出场的人：莉波（12）、麻央（8）
- 场景：和麻央一起去洗衣服的路上（0003）；提到寮（0017）；具体地点剧本没写明
- 世界线：S卡【二人ならあっという間だね】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
莉波遇到麻央，说自己也要洗衣服，两人同行。她给麻央看新买的秋季房间服，聊起各自的新买的东西，并介绍自己有时用香薰蜡烛，还有用电来化蜡发香的机器。麻央叮嘱她不要熬夜，莉波说喜欢麻央爱照顾人的地方，随后想起忘带洗衣液，请麻央先走。

## 她的关键台词
- 0001「あれ、麻央だ。」——发现麻央时的招呼，直呼「麻央」
- 0005「見て見て！　新しい秋物の／ルームウェア買っちゃった。」——兴奋地展示新买的秋季房间服
- 0007「そうなの。着るの楽しみなの。／洗濯、失敗しないようにしないとね。」——说期待穿新衣服，并自言自语要小心别洗坏
- 0008「麻央は最近何か買い物した？」——把话题转向对方
- 0011「私はアロマキャンドルを／たまに使ってるよ。」——说自己偶尔使用香薰蜡烛
- 0014「電気の力でキャンドルを溶かして／香りをたたせる機械があるの！」——兴奋地介绍电力化蜡发香的机器
- 0017「ふふっ、そうやって寮のみんなに／優しく言ってるんだね。」——对麻央的叮嘱，推测她对寮里的大家都这样温柔
- 0018「麻央のそういう面倒見のいいところ／私、好きだなぁ。」——直接说喜欢麻央爱照顾人的地方
- 0019「あ！　洗剤忘れたから取りに戻るね！／先に行ってて！」——忘了洗衣液，匆忙请麻央先走

## 行为模式
- 看到熟人 → 先惊讶地招呼，并提出一起行动（0001、0003）
- 有新东西 → 兴致勃勃地展示，再把话题抛给对方（0005、0008）
- 被提醒后 → 先笑，再顺势把对方的优点说出来（0017、0018）
- 说完好话后 → 立刻借忘带东西离开，没给对方回应的间隔（0019）

## 关系
- 麻央：她称「麻央」，麻央称她「莉波」；一起洗衣服，互相说出喜欢对方的地方（0018，麻央的 0020）

## 档案类事实
- 莉波新买了秋季的毛绒房间服（0005、0006）
- 莉波偶尔使用香薰蜡烛，知道用电化蜡发香的机器（0011、0014）
- 麻央说莉波的房间有好闻的香味（麻央的 0012），莉波认为是蜡烛的香味（0013）
- 莉波住在寮里还是别处，剧本没有明写，0017 她说的是「寮のみんな」。
