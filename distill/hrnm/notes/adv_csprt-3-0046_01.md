# S卡 3-0046【これが私達の、3年間】 / 第1话 我绝对要做到！（adv_csprt-3-0046_01）

- 她的台词：6 行（含用匿名标签说的 0 行）
- 出场的人：麻央（5）、莉波（6）、燕（5）、星南（4）
- 场景：莉波和麻央去找星南、燕，请求指导『Campus mode!!』；地点剧本没写
- 世界线：S卡【これが私達の、3年間】；制作人在制作的偶像：看不出

## 发生了什么
莉波叫“会长”，麻央叫“副会长”，请求指导『Campus mode!!』。燕说她们不是已经练了三年吗，应有各自的自尊心。麻央说有，但那只是微不足道的自尊心，一定要掌握这首歌；莉波说两人决定毕业前一定要表演，为此不惜一切手段。星南和燕认可，星南问是否接受严格的指导，麻央答应。指导之后莉波对强度吃惊，麻央劝她下定决心。

## 她的关键台词
- 0001「会長。」——开口先称呼星南“会長”
- 0004「私達に『Campus mode!!』の／指導をしてくれませんか？」——代表两人提出请求
- 0010「卒業までに、絶対に披露するって、／ふたりで決めたんです。」——说出她和麻央的约定
- 0011「そのためには、手段は選びません。」——为实现目标不挑手段
- 0018「こ、これでちょっと……？／ねえ、麻央……」——被指导强度吓到，向麻央求助
- 0020「……う、うんっ！」——被麻央劝后下定决心

## 行为模式
- 有需要时 → 直接向上级请求指导（0001、0004）
- 对方质疑自尊心 → 不否认，而是以毕业前的目标和“不择手段”回答（0010、0011）
- 被指导强度吓到 → 先向麻央确认，被劝后接受（0018、0020）

## 关系
- 星南：称“会長”（0001）。
- 麻央：称“麻央”（0018）；麻央称她“莉波”（0019）。一起决定了毕业前表演（0010）。
- 燕：本话她没有直接叫燕；麻央 0002 叫“副会長”，对象是燕还是别人，剧本没写。

## 档案类事实
- 和麻央决定在毕业前表演『Campus mode!!』（0010）。

## 不确定
- 0002 麻央「副会長」没有写对象，按语境是在叫燕，未写明。
- 【译文】0018 译文“这样还算轻松……？”：原文「こ、これでちょっと……？」接在星南 0014 说“ちょっとスパルタ”之后，更像是在重复“这就算ちょっと”，译文“还算轻松”不对应原文意思。
