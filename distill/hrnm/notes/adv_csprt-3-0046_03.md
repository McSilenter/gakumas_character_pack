# S卡 3-0046【これが私達の、3年間】 / 第3话 把接力棒传下去（adv_csprt-3-0046_03）

- 她的台词：10 行（含用匿名标签说的 0 行）；0010 是替麻央把话说完的引述式说法
- 出场的人：莉波（10）、麻央（9）
- 场景：两人在练习，跳完一遍后讨论；莉波录了像（0006）
- 世界线：S卡【これが私達の、3年間】；制作人在制作的偶像：看不出

## 发生了什么
麻央跳完一遍问感想，莉波说有在意的地方但不确定，不习惯指出问题。麻央说这就是练习的目的，莉波提议一起看录像。两人说既然要教后辈就得好好指出问题，麻央说起教自己的前辈，莉波回忆演出后两人说过要加油，说要把这份心情传给后辈，不想让后辈觉得这首歌“不过如此”。麻央说要好好把接力棒传下去，莉波回应。

## 她的关键台词
- 0003「気になるところはあるんだけど、／それが正しいのかわからなくて……」——有想法但不确定自己的判断是否正确
- 0004「こうやって指摘するの、／あんまり慣れてないから。」——不习惯指出别人的问题
- 0006「録画してるから、／それ見ながら、一緒に振り返らない？」——提出一起看录像来解决
- 0008「他人の振りは、個性があって／いいなって思っちゃうでしょ？」——说出指出别人问题的困难：别人的动作有个性，容易觉得好
- 0010「『下級生に教えるんだから／ちゃんと指摘できないとダメ』でしょ？」——接上麻央的“でも……”，说出两人的共识
- 0014「ライブのあと、ふたりで話したよね。／やるぞーって。」——想起演出后两人的约定
- 0015「その気持ち、後輩の子たちに／伝えないと。」——把前辈给的心情传给后辈
- 0016「私たちの憧れたこの歌が、／こんなものかって思われたくないもの。」——不想后辈觉得这首歌“不过如此”
- 0019「うん。」——对麻央“好好传下去”的回应

## 行为模式
- 不确定自己的判断 → 说出顾虑，同时提出不依赖直觉的办法（录像）（0003、0006）
- 自己与对方都不擅长 → 先承认，再从“为了后辈”的角度接上对方的话（0004、0010）
- 谈到目标 → 用“不想被觉得不过如此”表达（0016）

## 关系
- 麻央：本话两人没有直接叫对方的名字（同卡第1话 0018 她称“麻央”，0019 麻央称“莉波”）。两人在演出后聊过要加油（0014）。
- 后辈：想把心情传给后辈（0015、0016）。

## 档案类事实
- 有录像的习惯/手段，用来回看（0006）。
- 和麻央在演出后聊过“やるぞー”（0014）。
