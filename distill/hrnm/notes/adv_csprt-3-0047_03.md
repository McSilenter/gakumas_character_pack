# S卡 3-0047【バレンタイン♡会議中ーっ！】 / 第3话 巧克力要送给谁呢？（adv_csprt-3-0047_03）

- 她的台词：8 行（含用匿名标签说的 0 行）
- 出场的人：佑芽（10）、莉波（8）、麻央（2）
- 场景：佑芽尝莉波做的巧克力；0019、0020 转到麻央
- 世界线：S卡【バレンタイン♡会議中ーっ！】；制作人在制作的偶像：看不出

## 发生了什么
佑芽吃了莉波做的巧克力，问为什么每个味道都不同。莉波说总是纠结哪个味道好，比如草莓给千奈，抹茶给美鈴，并让佑芽保密，想给学生会的大家惊喜。佑芽说她很关注大家，莉波说如果是那样很高兴。佑芽又吃到外表偏苦、内里很甜的巧克力，莉波说做得特别甜，希望是连黑咖啡都变甜的巧克力。佑芽说羡慕收到这份巧克力的人，那一定是很棒的人；莉波略显慌张，场景随后转到麻央打喷嚏。

## 她的关键台词
- 0003「うーん、どの味がいいかな～って／いつもすごく悩んじゃうの。」——每次都要为口味纠结
- 0004「イチゴは千奈ちゃん、抹茶は美鈴ちゃん／……みたいに考えながら作るんだけど。」——按收到的人选口味
- 0006「うん、あ！　このことは内緒ね♪／びっくりさせたいから。」——想给人惊喜
- 0009「ふふ。そうかな？／もしそうだったら嬉しいな。」——被说关注大家时的谦虚而高兴
- 0012「あ――それはね。／うんと甘くしてるの。」——解释巧克力内里特别甜
- 0013「ブラックコーヒーさえも甘くしちゃう。」——对巧克力效果的描述
- 0014「そんなチョコになったらいいなって。」——希望做成这样的巧克力
- 0017「そ、そうかな……？」——被说笑容美好时的反应

## 行为模式
- 被问做法 → 以“收到的人”为出发点解释（0003、0004）
- 说漏嘴 → 立即补一句“保密”，理由是想给惊喜（0006）
- 被夸 → 谦虚，同时表示高兴（0009）
- 被问到特别的一份 → 讲出对巧克力的想象，被说笑容美好时慌张（0012～0014、0017）

## 关系
- 佑芽：本话她没有直接叫佑芽；佑芽称“莉波先輩”（0007）。
- 千奈、美鈴：称“千奈ちゃん”“美鈴ちゃん”（0004）；为她们按口味做巧克力。
- 生徒会的大家：想给他们准备惊喜（0005、0006，佑芽 0005 的话她以“うん”确认）。

## 档案类事实
- 做了多种口味的巧克力，按收到的人决定口味（0003、0004）。
- 也为学生会的成员准备（0006 确认并要保密）。
