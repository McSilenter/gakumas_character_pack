# S卡 3-0051【新生活のはじまりだね】 / 第3话 当花再次绽放之时（adv_csprt-3-0051_03）

- 她的台词：8 行（含用匿名标签说的 0 行）
- 出场的人：麻央（12）、莉波（8）
- 场景：刚结束偶像课程之后（0001、0003），提到“あの桜”（0018）
- 世界线：S卡【新生活のはじまりだね】；制作人在制作的偶像：看不出

## 发生了什么
莉波刚上完偶像课程，觉得和中学的音乐课完全不同，听麻央说之后会更严格，担心自己跟不上。她说大家都很厉害，特别是十王星南，像电视上的真正偶像。莉波见麻央说不想输，说她帅气，并说自己看了大家后失去了自信。麻央鼓励后，莉波高兴地应和。

## 她的关键台词
- 0001「……ふぅ。アイドルのレッスンって、／あんな感じなんだね。」——对课程的感想
- 0002「中学の音楽の授業とは、／全然違うなぁ。」——与中学音乐课做比较
- 0005「も、もっと厳しく……／私、ついていけるかなぁ。」——听说会更严格，说出不安
- 0008「……うん。みんなすごかったけど、／特にあの――」——话说到一半，提起让她印象深刻的人
- 0010「同じ1年生なのに、テレビで観てた／本物のアイドルみたいだった――」——形容星南像电视上看到的真正偶像
- 0013「有村さん、カッコいいなぁ。」——对麻央“不输”的话，直接赞叹
- 0015「私なんて、みんなを見て、／自信なくしちゃってたから……」——对比自己，承认失去了自信
- 0020「うんっ、そうだね！」——被鼓励后，积极应和

## 行为模式
- 面对新环境 → 比较过去的经验，坦率说出不同（0001、0002）
- 听到之后会更严格 → 直接说担心跟不上（0005）
- 看到更厉害的人 → 记住对方并用直观的比喻形容（0010）
- 看到别人有斗志 → 直接称赞，并对比自己的不自信（0013、0015）
- 被鼓励 → 立刻应和（0020）

## 关系
- 麻央：称「有村さん」（0013）；觉得她帅气。麻央用「ボクたち」邀她一起开花
- 星南：未直接称呼，只说“特にあの――”，麻央接着说出「十王星南」（0008、0009）；莉波对她的印象是同为一年级却像真正的偶像（0010）

## 档案类事实
- 中学上过音乐课（0002）
- 在电视上看过星南（0010）
