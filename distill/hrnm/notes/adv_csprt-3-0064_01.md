# S卡 3-0064【いつも頑張ってるね。】 / 第1话 请把它忘掉……！（adv_csprt-3-0064_01）

- 她的台词：9 行（含用匿名标签说的 0 行）
- 出场的人：清夏（11）、莉波（9）
- 场景：地点没写明；0001～0016 是清夏找她安慰的那一次，0017 起是之后见面，清夏提到「昨日のこと」（0018）
- 世界线：S卡【いつも頑張ってるね。】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
清夏跑来说被老师骂了，要求安慰。莉波摸摸她，说“悲しかったんだね”。清夏说难为情，莉波问她讨厌吗，得到“不是讨厌”。莉波说清夏一直在努力，希望大家笑，这很棒，所以没关系。清夏发现自己在流泪，用借口遮掩。之后莉波再见到她，问是否好些了，被要求忘记昨天的事，莉波说她很可爱，不想忘。

## 她的关键台词
- 0002「わわわっ、ど、どうしたの！？」——突然被要求安慰时慌张，随后接受
- 0005「ん～、そっか。」——听完原因，没有评判
- 0006「よしよし。／悲しかったんだね。」——直接用动作安慰，并说出对方的感受
- 0009「嫌？」——清夏说难为情时，不收手，只问是否讨厌
- 0011「清夏ちゃんは、いつも頑張ってるね。／えらいえらい。」——认可清夏一直在努力
- 0013「清夏ちゃんは、みんなに笑顔で／いてほしいんだよね？」——说出清夏的愿望
- 0014「とっても素敵なことだと思うよ。／だから、大丈夫。」——肯定这个愿望，让清夏安心
- 0017「あ、清夏ちゃん。／おはよう、元気になった？」——再次见面时，先问是否好了
- 0019「えっ？　どうして？／とっても可愛かったのに……」——被要求忘记，不明白为何

## 行为模式
- 被突然撒娇/求安慰 → 吃惊后马上配合，用摸头和一句话安慰（0002、0006）
- 对方说难为情 → 不立即停手，问“讨厌吗？”，确认对方的意愿（0009）
- 想让对方安心 → 说出对方没说出口的愿望，并肯定（0013、0014）
- 被要求忘记 → 不明白，说“很可爱”（0019）

## 关系
