# S卡 3-0101【どーなっちゃうの～？】 / 第3话 只属于两人的空间（adv_csprt-3-0101_03）

- 她的台词：9 行（含用匿名标签说的 0 行）
- 出场的人：莉波、麻央、生徒
- 场景：户外，下雨了，两人在雨中
- 世界线：S卡【どーなっちゃうの～？】；制作人在制作的偶像：看不出

## 发生了什么
下雨了，莉波说自己今天也带了伞，因为出门前遇见咲季，咲季说感觉会下雨（0001～0005）。看到一个淋湿的学生时她叫了一声麻央，麻央已经把自己的伞送给对方（0007～0013）。她请麻央进自己的伞，说和朋友共伞是小学毕业后第一次，麻央说像只有两人的空间，她表示赞同，并提议就这样走一走（0014～0020）。

## 她的关键台词
- 0001「……あ、雨。」——最先发现下雨
- 0003「さすがだね。でも――／今日は私も持ってきてます。」——称赞麻央常备折叠伞，随后微微得意地说自己今天也带了
- 0005「出かける前に咲季ちゃんと会ってね、／今日は降る気がします、って。」——因咲季的提醒才带伞，称呼「咲季ちゃん」
- 0007「――あ、あの子。／濡れちゃってる。」——先注意到淋湿的学生
- 0009「あ、麻央――」——想叫住麻央时，麻央已经去送伞
- 0014「ほらほら、早く入って。／濡れちゃうよー。」——催麻央进伞，语气轻松
- 0016「ふふ、友達と相合い傘なんて、／小学生のときぶりかも。」——说和朋友共伞是「小学生のときぶり」，用「かも」留余地
- 0019「ふふ、そうだね。」——赞同麻央说的两人空间
- 0020「ねえ、このまま、／ちょっと歩こっか？」——主动提议在雨中走一走

## 行为模式
- 看到陌生人淋雨 → 先注意到并出声提示（0007）；对方被麻央抢先处理后，招呼麻央进自己的伞（0009、0014）
- 对方称赞或感叹 → 用「ふふ」附和（0019）
- 气氛变得亲近时 → 主动提出继续一起行动（0020）

## 关系
- 麻央：称呼「麻央」，认为她「さすが」，称她为「友達」（0016）；麻央称呼她「莉波」
- 咲季：称呼「咲季ちゃん」；听了她的预感才带伞（0005）

## 档案类事实
- 今天带了伞，是因为出门前咲季说感觉会下雨（0003、0005）
- 和朋友共撑一把伞，上一次可能是小学毕业时（0016）

## 不确定
- 0016「小学生のときぶりかも」里「小学生のとき」指小学生时期还是小学毕业，原文只说「小学生のときぶり」，语气为「かも」。
