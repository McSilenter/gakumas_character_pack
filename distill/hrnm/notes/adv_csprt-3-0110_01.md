# S卡 3-0110【イクラ～♪　ウニ～♪】 / 第1话 回转寿司奥妙无穷（adv_csprt-3-0110_01）

- 她的台词：10 行（含用匿名标签说的 0 行）
- 出场的人：莉波、燕
- 场景：回转寿司店
- 世界线：S卡【イクラ～♪　ウニ～♪】；制作人在制作的偶像：看不出

## 发生了什么
莉波和燕来吃回转寿司，燕说是第一次，请莉波教她规矩（0002、0003）。莉波教她用触摸屏点单，可以拿转盘上的盘子，盘子颜色决定价格，水龙头是倒茶用的（0004～0008）。莉波说想点イクラ，打算点3份，燕觉得过分（0010、0011）。莉波问燕点什么，燕点了玉子、比目鱼等，被称为内行（0012～0014）。莉波推荐店里的炸鸡和乌冬面，说在回转寿司吃配菜别有一番滋味（0016～0019）。

## 她的关键台词
- 0001「ん～、ひさしぶりの、／お寿司だ～♪」——开场的期待，拉长音
- 0004「まかせて。回転寿司は、／タッチパネルで注文するんだよ。」——被请教后爽快答应
- 0006「うん。好きなのをとって。／お皿の色で値段が変わるんだ。」——解释规则
- 0008「それ、お茶のやつだから！」——燕问蛇口时赶紧说明
- 0010「ふふ、私はイクラにしようかな。／3つ頼んじゃおっと♪」——说出自己想点的东西，并打算点3份
- 0012「え、そ、そうかなぁ……／燕ちゃんは？　一緒に注文しちゃうよ。」——被说“無法”后有点慌，随即把话题转给燕
- 0014「お、燕ちゃん、通だねえ。」——燕点了玉子、比目鱼，称赞内行
- 0016「ふふ、このお店はね、／唐揚げとうどんが美味しいんだ。」——被问推荐时的回答
- 0019「回転寿司で食べるサイドメニューは、／また格別なんだよ。」——说明配菜的魅力

## 行为模式
- 被请教自己熟悉的事 → 爽快答应，逐条教（0004、0006、0008）
- 被指出做得过头 → 有点不好意思，马上转而问对方（0012）
- 被对方惊讶 → 反而带点得意地补充经验（0018、0019）
- 称呼燕为「燕ちゃん」，语气亲近（0012、0014、0018）

## 关系
- 燕：称呼「燕ちゃん」；燕称她「姫崎」；她在这里扮演教燕规矩的一方

## 档案类事实
- 熟悉回转寿司的点法（0004、0006）；说想点イクラ（0010）
- 觉得这家店的唐揚げ和うどん好吃（0016）
- 喜欢在回转寿司吃配菜（0019）

## 不确定
- 0010「3つ頼んじゃおっと♪」是她的打算，不是已经点了；燕 0011「無法すぎないか」是对此的反应。
