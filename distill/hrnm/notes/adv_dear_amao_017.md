# 有村麻央 亲爱度剧情 / 第17话（adv_dear_amao_017）

- 她的台词：8 行（匿名标签 0 行）
- 出场的人：麻央（32 行）、プロデューサー（14）、莉波（8）
- 场景：麻央演出结束后，莉波跑来祝贺（0010、0012）；地点剧本没写明，莉波说“学園に戻ったら”（0022），说明不在学园内
- 世界线：亲爱度（有村麻央）；制作人在制作的偶像：有村麻央

## 发生了什么
麻央的演出大获成功后，莉波跑来祝贺，说真是很棒的演出（0010、0012）。麻央说替她报了仇，又自己改口说跟这没关系；莉波说输了虽然不甘心，但那是实力比拼（0014、0015）。麻央问起下一次『H.I.F』，她说当然不会放弃：在舞台上闪耀的麻央让她重新想起，能让大家笑起来的偶像很美好（0016～0020）。她说回学园后马上要努力练习，麻央说可以陪她（0022、0023）。之后麻央对制作人说两人是“戦友”，并讲起春天赏樱时两人谈过的理想偶像（0025～0040）。

## 她的关键台词
- 0010「麻央～！」——跑来时叫麻央
- 0012「麻央、おめでとう！／ほんとに素敵なライブだったよ！」——全心祝贺朋友
- 0015「負けたのは悔しいけど、／実力勝負だからね。」——承认不甘，也接受结果
- 0017「うん、もちろん、諦めないよ。」——对下一次『H.I.F』表态
- 0018「だって、あんな素敵なライブ、／見せられちゃったんだもん。」——不放弃的理由来自麻央的舞台
- 0019「ステージで輝く麻央が、／思い出させてくれたんだ。」——被朋友的舞台激励
- 0020「みんなを笑顔にしてくれる――／アイドルって、素敵だなって。」——她觉得偶像美好之处
- 0022「学園に戻ったら、さっそく、／レッスン頑張るよっ！」——把重新振作落到行动打算上

## 行为模式
- 朋友成功 → 第一时间跑来、直接祝贺（0010、0012）
- 被提起自己的失败 → 说不甘心，但归结为“实力比拼”，不怨谁（0015）
- 看到别人精彩的舞台 → 被激励，重新确认自己为什么喜欢偶像，并马上说要去练习（0018～0022）

## 关系
- 麻央：叫「麻央」（0010、0012、0019）；麻央叫她「莉波」（0011、0013）。她祝贺麻央、说麻央的舞台让她想起偶像的美好；麻央提出陪她练习（0023）。麻央向制作人形容两人是“戦友”，说叫“親友”有点难为情，两人三年来同样苦过来，想法和偶像立场不太一样，在一起却莫名舒服（0025～0030，麻央的话）。
- プロデューサー：这一篇里莉波和制作人没有直接对话。

## 档案类事实
- 决定不放弃下一次『H.I.F』（0016、0017）。
- 据麻央说，今年春天两人边看樱花边谈过想成为怎样的偶像：莉波说即使花落变成葉桜、变成桜紅葉，也想展现不同的魅力，一直当偶像下去（0035、0039、0040，麻央转述）。
- 据麻央说，她和麻央三年来“同じように苦しんできました”（0028，麻央的话）。

## 不确定
- 0015「負けたのは」指的是第15话里她输掉的那场（第15话 0004），本篇没说比赛名。前后说法一致。
- 0039、0040 是麻央转述的莉波的话，不是她本人这一篇说的。
