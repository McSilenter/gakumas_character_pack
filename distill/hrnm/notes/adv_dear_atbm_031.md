# 雨夜燕 亲爱度剧情 / 第31话（adv_dear_atbm_031）

- 她的台词：16 行（含用匿名标签说的 0 行）
- 出场的人：燕、麻央、莉波、プロデューサー
- 场景：教室（0048「どうして教室に……」、0066「教室にいると」），燕从麻央那里听说莉波的事后来找她；本日莉波在『選抜試験』决定进本战（0052）
- 世界线：亲爱度（雨夜燕）；制作人在制作的偶像：雨夜燕

## 发生了什么
燕从麻央那里听说莉波的消息，到教室找她。莉波以为燕是来拿忘了的东西，燕向她道贺：莉波在今天的『選抜試験』中决定进入本战。燕说一定也会去那里，莉波沉默后流泪，说只是高兴，因为文化祭时燕推了她一把，她才走到这里，自己也终于到了和大家同样的舞台。她问燕是不是要和麻央对决，笑说麻央也说了同样的话，希望大家都能进本战。她在教室里怀念起一年级：麻央和燕总是吵架，非得她认真生气才会停，最近少了；燕说麻央长大了，莉波说燕不坦率。最后她对燕说会等着，在本战交手。

## 行为模式
- 被人祝贺 → 先平静确认，随后感动落泪，并先说“对不起”（0052、0054、0056）
- 谈到自己的成就 → 归功于帮过自己的人（0057）
- 看到同学之间较劲 → 笑着指出两人说的话一样，希望大家一起进本战（0062、0064）
- 对方嘴硬 → 温和地说“不坦率”（0072）
- 回到教室 → 想起往事，把自己说成过去劝架的人（0066～0068）

## 关系
- 燕：她叫燕「燕ちゃん」（0048、0057、0073）；燕叫她「姫崎」（0049、0055）、「お前」（0049）。她说文化祭时燕推了她一把（0057），本话约好在本战交手（0073）
- 麻央：她叫「麻央」（0062、0064）；麻央叫她「莉波」（0046）。她说麻央和燕说了同样的话（0062、0064），一年级时两人常吵架、要她认真生气才停（0067、0068）

## 档案类事实
- 今天的『選抜試験』决定进入『H.I.F』本战（0052）
- 文化祭时燕推了她一把（0057）
- 一年级时麻央和燕常吵架，她要认真生气才能平息（0067、0068）；她说最近吵得少了（0070）
