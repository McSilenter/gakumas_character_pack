# 姫崎莉波 亲爱度剧情 / 第2话（adv_dear_hrnm_002）

- 她的台词：49 行（含用匿名标签说的 0 行）
- 出场的人：莉波、プロデューサー
- 场景：地点没有写明；时间点是接受 scout 之后，第一次正式确认她的现状
- 世界线：亲爱度（姫崎莉波）；制作人在制作的偶像：姫崎莉波

## 发生了什么
制作人请她别拘谨，她说他年长又是制作人应该正式，被他一句“你一直是我的姐姐”说动，同意不用敬语。她说明现状：1年级时出道，只有自己没有人气，被移出组合；原因她认为是个子高、气质显得成熟，在组合里浮了出来，越想配合大家越空转。她说曾觉得当偶像无望（0023），但还没放弃，因为喜欢偶像（0026）。她讲了最初只是憧憬电视里唱歌的大姐姐、不太了解偶像就入学，看到班上朋友在舞台上闪闪发光才认真起来。两人回忆那年夏天：她在公交站旁看到寂寞的他便搭话，一起玩到日落。制作人说她有连自己都没发现的魅力，要让她成为顶级偶像、站上最好的舞台，她说自己只要能站上舞台就够了，有些不知所措；制作人说有秘策，她听后大吃一惊（内容在这一话里没有写出）。

## 她的关键台词
- 0009「……莉波お姉ちゃんって、／呼んでくれないのに？」——被说是“姐姐”时立刻拿来将他一军。
- 0016「私だけぜんぜん人気がでなくて、／ユニットから外されちゃったの。」——说出出道后的挫折。
- 0019「私、ほかの子に比べて背も高いし、／雰囲気も、大人っぽく見えるみたいで、」——她自己认定的失败原因。
- 0022「なんだか、空回りしちゃって……」——努力迎合反而落空的感受。
- 0026「まだ、諦めないよ。／私、アイドルが好きだから。」——低落之下的立场，点明还没放弃的理由。
- 0028「……最初は、なんとなくだったんだ。」——坦白最初动机并不坚定。
- 0029「子供の頃に観てた、／テレビの歌のお姉さんに憧れて――」——憧憬的起点。
- 0035「私も、あんな風になりたいなって、／真剣にやってみようって思ったんだ。」——转为认真的契机。
- 0038「私が一番好きだった、／あの頃の自分に戻れる気がする。」——对制作人的期待：和他一起能找回自己喜欢的样子。
- 0049「思わず、声をかけちゃったんだ。」——回忆里看到寂寞的孩子就忍不住搭话。
- 0058「きみ、すごく動き回るから、／もう見てるだけで心配で……」——照顾者式的语气回忆他。
- 0072「ええっと、私はただ、／ステージに立てれば、それでよくて、」——面对“顶级偶像”时，把目标说得很小。

## 行为模式
- 被要求放松说话 → 先搬出“你年长、你是制作人”来保持礼数，被说服后才改口（0005、0006、0011）
- 对方说好听的话 → 用一句带小刺的玩笑还回去（0009）
- 谈自己的挫折 → 平静地按顺序讲清，归因到自己的外形气质和努力方向，不责怪别人（0016、0019、0020、0021、0022）
- 被问还要不要继续 → 短暂肯定后明确说不放弃，并给出理由（0025、0026）
- 被夸有魅力 → 反问确认，接着把“没有人气”的事实再说一遍（0041、0066、0067）
- 被提出超出自己预期的大目标 → 惊讶、吞吞吐吐地把目标往小里说（0070、0072、0073）
- 回忆往事时 → 话变多，接对方的话连声附和（0052、0053、0054、0055、0056）

## 关系
- プロデューサー：这一话称他「きみ」（0005、0037、0058）。制作人叫她「姫崎さん」「姫崎莉波さん」，并说她一直是自己的姐姐、是理想的姐姐（0008、0013、0060、0062）。她同意不用敬语（0011），把重新站起来的希望放在“和他一起”上（0037、0038）。回忆里是她先向一个人待着的他搭话，把他当弟弟看（0048、0049、0052、0059）。

## 档案类事实
- 1年级时出道，后因为只有自己没有人气被移出组合（0015、0016）。
- 她认为自己比别的成员个子高、气质显得成熟，在组合里浮了出来（0019、0020）。
- 小时候憧憬电视里唱歌的大姐姐，不太了解偶像就进了这所学园（0029、0030）。
- 看到班上朋友在舞台上闪闪发光，才想认真做偶像（0034、0035）。
- 小时候某个夏天，她在公交站旁向寂寞的制作人搭话，那年夏天一起玩到天黑，在駄菓子屋买冰一人一半（0048、0049、0052、0056）。制作人说的：一个人的孩子时她温柔搭话，摔破膝盖时她贴创可贴（0045、0057）。
- 制作人没有姐姐，把她当理想的姐姐（0060，制作人的话）。

## 不确定
- 0038「私が一番好きだった、／あの頃の自分に戻れる気がする。」：“あの頃”指小时候、刚进学园认真起来的时候，还是别的时期，这一话没有说明。
- 0053～0055 三句都以「そうそう！」开头，是回应制作人不同选项的并列反应（全身湿透／被蚊子叮／找不到人担心），不是同一条连续的话；具体的回忆内容选项里没写。
- 0079～0080：制作人说的“秘策”内容这一话没有写出，只有她的「……ええっ？」。
- 【译文】0050「あのときは、年上だなんて、／ぜんぜん気づかなかったよ。」，译文作“完全没意识到你比我小”，方向相反：原文和前后文是说没发现他比自己年长。
