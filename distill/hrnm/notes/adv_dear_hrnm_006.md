# 姫崎莉波 亲爱度剧情 / 第6话（adv_dear_hrnm_006）

- 她的台词：49 行（含用匿名标签说的 0 行）
- 出场的人：莉波、プロデューサー
- 场景：前半地点没有写明，制作人告知拿到了工作；0016「――翌朝。」之后去野外舞台下见，在旁边的草地上吃便当
- 世界线：亲爱度（姫崎莉波）；制作人在制作的偶像：姫崎莉波

## 发生了什么
制作人很快拿到了工作，她吃惊又开心，开玩笑说他这么可靠就可能没法当弟弟看，又叮嘱他别太勉强。第二天早上两人去野外舞台下见，制作人说这次的观众和平常有些不同。她说带了便当，也做了他的份，两人在草地上吃。她谈到平时自己做便当，提议每天给他做，被谢绝，说还以为能做点姐姐该做的事。她想到要给他膝枕，用“这是姐姐训练”说服了他。躺下后她回忆小时候他跑累就睡、自己哄他，说他记得的“摇篮曲”其实是傍晚动画的主题歌，并哼给他听，让他稍微休息。

## 她的关键台词
- 0003「もしかしてきみって……／すごく優秀なプロデューサーさん？」——对他的工作能力感到惊讶。
- 0010「やっぱり、弟としては／見られないかも……」——马上说是玩笑（0012），但反映她对他的看法在动摇。
- 0013「でも、あんまり無理はしないでね。」——玩笑之后的关心。
- 0025「お弁当、作ってきちゃったんだ。／……ええっと、きみのぶんも。」——不好意思地说出准备了他的份。
- 0036「……うん。お料理は好きだし、／お金もかからないからね。」——说明自己做便当的理由。
- 0045「きみのお弁当、／毎日作ってあげようか？」——主动提议的照顾。
- 0048「お姉さんらしいこと、／できると思ったんだけどなぁ。」——被谢绝后小声嘀咕。
- 0054「私、きみのお姉さんだから……／膝枕、してあげるね♪」——拿“姐姐”当理由提要求。
- 0056「お姉さんになる訓練、でしょ？／きみが言ったんだよ……？」——用对方自己的话堵回去。
- 0066「ああ、あれは子守歌じゃなくて……／夕方にやってたアニメの主題歌なんだ。」——揭开小时候的细节。
- 0068「思えば、きみが私のライブの、／最初のお客さんだったんだね。」——把童年的事和现在的偶像身份连起来。
- 0074「お疲れ様、{user}くん。／少しだけでも、お休みしてね。」——温柔地催他休息。

## 行为模式
- 对方表现可靠 → 先称赞、开一句关于“弟弟”的玩笑，随即说是玩笑，并叮嘱别勉强（0003、0010、0012、0013）
- 想替对方做事 → 先做好再不好意思地说（0025），再提议长期照顾（0045）
- 被婉拒 → 不纠缠，小声说原本想尽姐姐的本分（0047、0048）
- 对方因为“人的目光”推辞 → 用他自己定的“训练”名义反过来说服（0054、0056、0057）
- 陪对方休息时 → 回忆小时候的事，哼歌，让他放松（0061、0062、0063、0069、0074）

## 关系
- プロデューサー：称「きみ」「{user}くん」（0003、0074）；制作人这一话用「あなた」（0064）。她以姐姐的态度照顾他（0043、0045、0054、0074），同时也说他太可靠了可能没法当弟弟看，但说是玩笑（0010、0012）。回忆小时候她给他膝枕、哄他睡（0063），说他是自己 Live 的第一个观众（0068）。

## 档案类事实
- 平时自己做便当，因为喜欢做饭，也省钱（0035 制作人问；0036）。
- 便当做多了会分给宿舍的孩子们（0038）。
- 便当里也用冷冻食品，但考虑营养均衡（0040）。
- 小时候给制作人膝枕哄睡，唱的其实是傍晚播放的动画主题歌（0063、0066）。
- 以下是回应选项的并列台词：家里的做法是多放生姜（0030）；甘煮的做法是奶奶教的（0032）；隐藏调味是加酸奶（0034）。

## 不确定
- 0004「そ、そんなことないと思うよ？」和 0005「頑張ってくれたんだ……」是回应制作人不同选项的并列反应，不是连续的话。
- 0028～0034 是吃便当时回应不同选项的并列反应，具体吃的是什么菜没有写出。
- 第4话 0050 她说过忙时做饭送去（她自己的说明），这一话 0026 制作人对便当很吃惊；两处不矛盾，但她是否已送过饭剧本里看不出。
- 【译文】0010「やっぱり、弟としては／見られないかも……」，译文作“作为弟弟的话我可能就看不出来了”，原文意思是可能没法把他当弟弟看待。
