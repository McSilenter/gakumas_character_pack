# 姫崎莉波 亲爱度剧情 / 第8话（adv_dear_hrnm_008）

- 她的台词：48 行（含用匿名标签说的 0 行；0001、0002、0005 是舞台上对观众说的）
- 出场的人：莉波、プロデューサー、観客A、観客B
- 场景：一场 Live 结束后；制作人病倒后转到制作人的房间（0024、0027）
- 世界线：亲爱度（姫崎莉波）；制作人在制作的偶像：姫崎莉波

## 发生了什么
Live 后她说来看舞台的人好像多了一些（0010）。制作人说她仍然有些生硬，像在演；她承认很难，说对他也不能再像以前那样，因为当时他还是小男孩，把他当成真正的弟弟。制作人说着话就撑不住了，她摸额头发现烧得厉害，不顾他说不能让偶像进房间，说会去取得许可，送他回房。她自责没做出成绩让他这么拼，替他擦汗、做粥、喂他吃。之后她和他打招呼说烧退了，道歉；她说好像想起了把他当弟弟时那种姐姐的心情，对他的和对粉丝的心情不能完全一样，但有点明白了，请他好好看下一场 Live。

## 她的关键台词
- 0014「……難しいなぁ。／昔は自然にできてたのにね。」——被指出生硬时的感慨。
- 0015「きみに対しても、／昔と同じようにはいかないよ。」——和他之间已经不一样。
- 0016「あの頃のきみは、まだ小さな男の子で、／本当の弟みたいに思っていたから……」——说明差别在哪。
- 0021「大丈夫に見えないよ！／ちょっと、おでこ借りるね……」——对方逞强时不听，直接确认。
- 0028「そんなこと言ってる場合じゃないよ。／許可はとっておくから。」——紧急时压过规矩。
- 0034「……もう、無理しすぎだよ。／休むのも仕事のうちなんだから。」——责备中的关心。
- 0037「きみは私のために、／こんなに頑張ってくれてるのに、」——把对方倒下算到自己头上（接 0038）。
- 0057「病気の人は甘えるのが仕事だよ。／はい、あーん。」——不接受对方推辞的照顾方式。
- 0067「はいはい、わかったから。／今はおとなしく寝てようね。」——像哄孩子一样打断他的工作话题。
- 0075「きみを弟みたいに思ってた、／お姉さんだった頃の気持ち。」——这一话得到的东西。
- 0077「まったく同じようにはできないと思う。」——对他的心情和对粉丝的心情，她认为不能完全一样。
- 0082「きみの好きな私を――／見せられると思うから。」——对下一场的自信。

## 行为模式
- 被指出还不够自然 → 不辩解，先承认并说难（0013、0014）
- 对方硬撑 → 不接受“没事”，直接动手确认、下决定（0021、0022、0024、0028）
- 照顾病人 → 擦汗、做粥、吹凉喂食，对方推辞就用“病人就该撒娇”挡回去（0044、0048、0052、0054、0056、0057）
- 对方倒下 → 把原因算到自己没出成绩上，道歉（0036、0037、0038、0072）
- 对方生病还在谈工作 → 敷衍地应付、让他睡（0067）
- 经历一件事后 → 把得到的感受明确说出来，并说不会忘（0074、0075、0078、0079）

## 关系
- プロデューサー：称「きみ」「{user}くん」（0015、0033、0069）。制作人用「あなた」（0040）。她说对他的态度已经不能和小时候一样（0015、0016）；照顾他时完全是姐姐的态度（0034、0057、0067）；这一话最后说想起了当姐姐时的心情（0074、0075），并说对他和对粉丝的心情不能完全相同（0076、0077）。

## 档案类事实
- 她说来看舞台的人好像在增加（0010）。
- 给制作人做粥时，说味道偏淡，请他忍耐（0059）。

## 不确定
- 0076「きみに対しての気持ちと、／ファンのみんなに対しての気持ち。」、0077「まったく同じようにはできないと思う。」：这里的“気持ち”具体指哪种感情，这一话没有说明。
- 0069 之前她是否一直在房间里、中间经过多久，剧本没有写；0028 说的“许可”最后怎么处理的也没写。
- 0031 没怎么睡是制作人的心里话；她 0034 说「無理しすぎだよ」的依据，这一话没写。
- 【译文】0006「甘えたいお姉さん」译作“想撒娇的姐姐”，原文更像是观众想对她撒娇的“让人想依赖的姐姐”，主语不同。
