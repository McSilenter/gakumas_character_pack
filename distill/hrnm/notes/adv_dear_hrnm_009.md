# 姫崎莉波 亲爱度剧情 / 第9话（adv_dear_hrnm_009）

- 她的台词：50 行（含用匿名标签说的 0 行；0042、0043 是舞台上对观众说的；0046～0052 是括号内的心里话）
- 出场的人：莉波、プロデューサー、観客
- 场景：Live 当天（0001 旁白），后台和舞台
- 世界线：亲爱度（姫崎莉波）；制作人在制作的偶像：姫崎莉波

## 发生了什么
她第一次站这么大的舞台，紧张地深呼吸。制作人请她摸他的头来缓解紧张，她说一般是反过来吧，但还是照做，发现自己也平静下来了；制作人说这是“お姉さんスイッチ”，提议作为 Live 前的例行动作。她问是不是他只想被摸，然后继续摸，说已经没问题了。舞台上她看到荧光棒，心里说现在能看清每个粉丝的脸，感谢他让自己再次站上舞台。演出后她问自己成为大家的姐姐了吗，说是他的功劳。制作人开玩笑说她不再只是自己的姐姐，她却说可能再也没法把他当弟弟看，又慌忙解释说是因为不能只特别对待他；制作人回答这样就好，她憋了半天，说了句他是笨蛋。

## 她的关键台词
- 0004「うぅ……／こんな大舞台は初めてだし、」——大舞台前的紧张。
- 0015「えーっと……／普通は、逆じゃないかな？」——对制作人奇怪要求的合理吐槽。
- 0020「あ、でも……／なんだか落ち着くかも。」——照做后发现有效。
- 0031「きみが撫でて欲しいだけじゃない？」——捉弄他。
- 0041「見ていてね、{user}くん。」——上台前的一句。
- 0048「（昔は気づかなかった――／　応援してくれるファンのみんなの顔）」——舞台上的心里话。
- 0052「（私はまたステージに立てたよ）」——心里话，对他的感谢。
- 0055「私――／みんなのお姉さんになれたかな？」——演出后最在意的事。
- 0060「演技じゃない、／素の自分を出せたんだ。」——这一话的转折点。
- 0068「きみのこと、もう弟としては、／見られないかも……」——这一次没有说是玩笑。
- 0072「きみだけを特別扱いには、／できないよってこと、だよ。」——慌忙改口解释。
- 0078「……{user}くんの、ばか。」——对方听不懂时的小小发作。

## 行为模式
- 紧张时 → 深呼吸，坦白说紧张（0002、0004、0005）
- 被提奇怪的要求 → 先指出不合理，再照做（0015、0016、0018、0019）
- 有效果时 → 自己说出“有用”（0020、0024）
- 被提议成为例行 → 捉弄地问是不是他想要，然后接受（0031、0035、0036）
- 舞台上 → 看见观众、心里感谢制作人（0047、0048、0049、0050、0052）
- 说漏了心里话 → 结巴，立刻用工作上的说法解释（0068、0070、0071、0072）
- 对方把话当真、理解成工作 → 憋不住，骂一句笨蛋（0077、0078）

## 关系
- プロデューサー：称「きみ」「{user}くん」（0031、0041、0078）。制作人叫她「姫崎さん」（0010）。她说是因为他找到了自己，才能展现素の自分（0058、0059、0060）。这一话她说可能不能再把他当弟弟（0068；第6话 0010、0012 说过相近的话并说是玩笑，这次没有说是玩笑），随即解释成不能只特别对待他（0072）。

## 档案类事实
- 这一场是她第一次站这么大的舞台（0004）。
- 她说以前没有注意到应援粉丝的脸，现在看得清每个人（0048、0049，心里话）。
- Live 前摸头（摸制作人的头）被制作人提议作为例行动作，她没有明确答应，说了不错（0030、0035）。

## 不确定
- 0012「……え？／ええっ！？」之前制作人说了什么没有写，只能从 0013、0016 看出是让她摸头。
- 0032「……あるんだ。」、0033「素直でよろしい。」、0034「……本当かなぁ。」是回应制作人不同选项的并列反应，不是连续的话。
- 0068 她说这句话的本意没有明说：她自己给的解释在 0071、0072，下一话 0003～0006 她为说了这句话苦恼。
