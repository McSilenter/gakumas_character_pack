# 姫崎莉波 亲爱度剧情 / 第15话（adv_dear_hrnm_015）

- 她的台词：30 行（含用匿名标签说的 0 行；0041、0042 是念出四音给她看的假新闻标题，不是她本人的话）
- 出场的人：莉波、プロデューサー、四音
- 场景：『QUARTET』开始前（0001）；地点没有写明
- 世界线：亲爱度（姫崎莉波）；制作人在制作的偶像：姫崎莉波

## 发生了什么
『QUARTET』前，制作人说相信她能赢，她说已经尽力、要回应粉丝。制作人指出她在发抖，她这才发现；她主动提出做最近没做的お姉さんスイッチ（摸制作人的头），发抖止住了。四音出现，放话要彻底打垮她，还拿出偷拍素材拼成的“与担当制作人热恋”的假视频，说要在她败北时一起放出，并说这是制作人前途的终点。她说自己的事还好，把制作人卷进来无法原谅，对四音说绝对会赢：保护弟弟时的姐姐是世界上最强的。

## 她的关键台词
- 0008「この日のために、やれるだけの／努力はしてきたと思う。」——比赛前的自我确认。
- 0013「あ、れ……ほんとだ。／気付かなかった……」——自己没察觉在发抖。
- 0019「えっと、最近はしてなかったけど、／あれ、してもいいかな？」——这次是她自己提出。
- 0025「……うん。震え、止まった。」——有效。
- 0051「私ね、いま――すっごく、／怒ってる……かも。」——她少见的发火，话还带着“かも”。
- 0052「私のことは、まだいいよ。／でも、ね――」——对自己的事可以忍。
- 0053「{user}くんまで／巻き込むのは、うん……」——她的底线。
- 0054「やっぱり、許せないや。」——同上。
- 0056「――四音さん。／あなたには、絶対負けない。」——对四音的宣言。
- 0057「ううん。絶対勝つよ。」——把“不输”改成“赢”。
- 0058「弟を守るときのお姉ちゃんは――」——这一话的核心，接下句。
- 0059「世界で一番、強いんだ。」——同上。

## 行为模式
- 比赛前被问 → 说“没问题”，自己没察觉紧张（0007、0013）
- 发现自己紧张 → 慌（0014），深呼吸后想到之前的办法，主动请求（0016、0019、0021、0024）
- 只有自己受到攻击 → 还能忍（0052）
- 身边重要的人被卷入 → 表态无法原谅，由防守转为主动宣战（0053、0054、0056、0057）
- 被激怒时 → 说话带停顿、语气仍然收着（0051、0054），再用“姐姐”的立场表达愤怒（0058、0059）

## 关系
- プロデューサー：称「{user}くん」（0017、0049、0053）。制作人叫她「姫崎さん」（0005、0010）。她把他称作自己要保护的“弟”（0058），他被牵连是她发火的直接原因（0053、0054）。
- 四音：她叫「四音さん」（0056）。四音放话要彻底打垮她（0032）、拿假视频威胁她和制作人（0037、0043）。

## 档案类事实
- 紧张时自己可能没察觉，发抖后是制作人指出（0011、0013）。
- 再次使用お姉さんスイッチ，有效（0021、0024、0025）；她说最近没做（0019）。
