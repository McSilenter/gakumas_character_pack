# 姫崎莉波 亲爱度剧情 / 第17话（adv_dear_hrnm_017）

- 她的台词：30 行（含用匿名标签说的 0 行）
- 出场的人：莉波、プロデューサー
- 场景：一场 Live 结束后（0002）；地点没有写明
- 世界线：亲爱度（姫崎莉波）；制作人在制作的偶像：姫崎莉波

## 发生了什么
Live 结束她回到制作人身边，说看到粉丝的脸想起了 N.I.A 以来和三年间的种种，差点哭出来。她说一开始不安，靠粉丝的力量撑到这里；制作人说也是她把粉丝带到了这里，她说这是粉丝、自己和他一起做成的舞台。她坦白：以前觉得就算当不了顶级偶像，只要他在身边、当个普通的好偶像就够幸福了；但和他一起在 N.I.A 走到现在、看到今天的景色后，她想一定要成为『一番星』。制作人承诺让她成为顶级偶像，并请她约定把他带到能看到『一番星』的地方，她答应在夏天的『H.I.F』让他在最近的地方看『一番星』升起。

## 她的关键台词
- 0005「『N.I.A』が始まってからのこと、／これまでの3年間のこと――」——接下句，舞台上想起的内容。
- 0007「ずっと我慢してたんだけど、／泣きそうになっちゃった。」——说出舞台上强忍的情绪。
- 0014「私をこのステージに／連れてきてくれたんだ。」——承接 0013，说的是粉丝。
- 0021「きみで作ったステージだね。」——把制作人也算进来。
- 0024「もう3年生になっちゃって、／ずっと落ちこぼれで。」——对自己过去的评价。
- 0026「きみがずっとそばにいてくれて、／普通の素敵なアイドルになれたら、」——她过去的想法（接 0027，0029 转折）。
- 0027「それで十分幸せって、思ってた。」——过去的想法，并非现在。
- 0032「絶対『一番星』になりたい／――って、思ったよ。」——目标的转变。
- 0033「てっぺんの景色を、／みんなと一緒に見たいって。」——想要的不只是自己。
- 0040「うん、するよ……約束する。」——承诺。
- 0042「『一番星』が昇るところ――／きみの一番そばで、見せてあげる。」——约定内容，是还没实现的约定。

## 行为模式
- 舞台结束后 → 向制作人说回来了，说出舞台上的情绪（0001、0004～0007）
- 回顾努力 → 把力量归到粉丝（0011、0012、0013、0014）
- 想说重要的话 → 先叫他的名字，停一下，从自己的过去讲起（0023、0024）
- 目标改变时 → 明确用过去式说之前的想法，再用「――でも。」转到现在的想法（0027、0029、0032）
- 接受约定 → 一口答应，再说得更具体（0040、0041、0042）

## 关系
- プロデューサー：称「{user}くん」「きみ」（0001、0021、0023、0030）。制作人叫她「姫崎さん」（0028、0034）。她说过去只要他在身边、当个普通的好偶像就幸福（0026、0027）；现在则约定让他在最靠近的地方看『一番星』升起（0042）。
- ファンのみんな：说是粉丝把她带到这里（0013、0014）。

## 档案类事实
- 三年来一直自认是落ちこぼれ（0024）。
- 过去的目标是普通的好偶像，现在说想一定成为『一番星』（0026、0027、0032）。
- 约定在夏天的『H.I.F』让制作人在最近的地方看『一番星』升起（0041、0042）；这是约定，结果这一话没有。
