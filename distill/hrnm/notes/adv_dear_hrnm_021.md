# 姫崎莉波 亲爱度剧情 / 第21话（adv_dear_hrnm_021）

- 她的台词：30 行（含用匿名标签说的 3 行：0001、0002、0003，标签 ？？？，回想；0004 是唱歌）
- 出场的人：莉波（27）、莉波の妹（15）、プロデューサー（8）、？？？（5，其中 0001～0003 是她，0053、0054 按上下文是カナ）
- 场景：开头是回想（0001～0003）；之后她在唱歌，制作人在旁（0004～0019）；接着她一个人时和妹妹通电话（0024 起）；『N.I.A』之后、夏季『H.I.F』之前（0014、0049）
- 世界线：亲爱度（姫崎莉波）；制作人在制作的偶像：姫崎莉波（剧本里没有直接说法）

## 发生了什么
回想里，她问一个哭泣的孩子为什么哭，说要给他唱歌（0001～0003）。她唱歌时制作人说她的歌声有了自信，并说胜过白草月花不是侥幸，夏季『H.I.F』有足够胜算（0005、0013～0019）。她一个人时说实在想象不出自己赢星南会長，又马上告诉自己不能在气势上输（0020～0023）。妹妹汐莉打来电话，担心她很久没打电话，说起父亲用她的声音当闹钟、做周边分给邻居，她大叫别这样，又说听了高兴（0024～0041）。妹妹说姐姐变成“大家的”姐姐有点寂寞，她说这话和制作人一样，笑了（0042～0046）。她告诉妹妹再下周有重要的舞台和配信，让转告父母，挂断后说必须加油（0049～0052）。这时有人叫她“リナぽよ”，她认出是カナぽよ（0053～0055）。

## 行为模式
- 被肯定成长 → 害羞后承认（0006、0010），但一说到胜利就归于对手状态和粉丝（0015、0016）
- 一个人时泄气 → 说出没信心，马上用“背负大家的心意”拉回来（0021～0023）
- 家人说担心 → 先道歉，用训练忙解释（0028、0048）
- 家人的宣传让她难为情 → 大叫阻止，又承认高兴（0037、0039、0041）
- 被说“变成大家的姐姐很寂寞” → 不解释，轻轻笑（0044、0046）

## 关系
- 妹妹（汐莉）：她叫「汐莉ちゃん」（0024、0026）；妹妹叫她「お姉ちゃん」（0025）。这一话里有一阵子没打电话，被说担心，她道歉（0027、0028、0048），主动告诉妹妹重要舞台的配信（0049、0050）。
- 父母：她问父亲是否安好（0031），让妹妹转告父母看配信（0050）。
- プロデューサー：独白里叫「{user}くん」（0020、0023），对妹妹说时叫「プロデューサーくん」（0046）；制作人叫她「姫崎さん」（0005）。
- カナ：她叫「カナぽよ」（0055）；对方叫她「リナぽよ」（0054）。
- 星南：她称「星南会長」（0021），是还想象不出能胜过的对象。

## 档案类事实
- 有妹妹汐莉（0024、0025）；母亲寄来蜂蜜腌的梅干（0029 妹妹的话，0031 她说有在吃）。
- 父亲看她的ライブ配信，做团扇等周边分给邻居，用她的応援ボイス、お目覚めボイス当闹钟（0032～0036，妹妹的话）。
- 参加『N.I.A』最初害怕，后来觉得挑战了真好（0011、0012）。
