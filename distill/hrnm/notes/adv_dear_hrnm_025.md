# 姫崎莉波 亲爱度剧情 / 第25话（adv_dear_hrnm_025）

- 她的台词：57 行（含用匿名标签说的 0 行）
- 出场的人：莉波（57）、プロデューサー（37）、莉波の妹（22）
- 场景：她的老家（0001 起），制作人赶来的当天，午饭（0001、0034）到晚饭后（0067、0086）
- 世界线：亲爱度（姫崎莉波）；制作人在制作的偶像：姫崎莉波

## 发生了什么
她给没吃东西的制作人做姫崎家的乌冬，问他大学的学分要不要紧（0001、0002、0008）。妹妹不承认“弟弟”，她说成为粉丝的姐姐和年龄无关，妹妹生气跑开，她嘟囔是不是反抗期（0013～0023）。午后制作人说要干活回报；她在一旁听到妹妹问他懂姐姐什么，他说魅力不能用“お姉さん”一句话概括，也不能说出口（0034～0056）。制作人修了庭院和屋顶，她留他住下，晚饭吃寿喜烧，两人在玩“お姉ちゃんしりとり”，她说别玩了（0062～0085）。洗碗时她讲父亲原想让她继承酒蔵，听到想当偶像后说做最喜欢的事吧，还帮着说服了母亲；又说约好了成为トップアイドル回乡开凯旋ライブ，却输了，向他道歉（0091～0099）。她说回来后一直在想为什么想当偶像，说自己喜欢偶像，但不知道这份心情是不是真的，这样的心情没法笑着上台，她需要时间想一想（0103～0116）。

## 行为模式
- 有人来家里 → 先招待、让对方吃住（0001、0002、0065、0067）
- 被问起和制作人的关系 → 用“制作人、也是弟弟”回答，不觉得奇怪（0013、0018、0019）
- 听到别人谈论自己 → 在一旁听，只在心里反应（0047、0051、0053）
- 被当面称赞 → 喊着不好意思要对方停下（0085）
- 失败后 → 先向为她付出的人道歉，再说想一想（0098、0099、0115、0116）
- 迷茫时 → 不靠别人答案，要求时间自己想（0103、0116）

## 关系
- プロデューサー：她叫「{user}くん」（0002、0008），也称「きみ」（0030）；介绍为「私のプロデューサーさんで、／弟くん」（0013）。制作人称她「姫崎さん」（0042、0048）。她招待他、担心他的大学（0008），最后向他道歉，并说要时间（0098、0099、0115、0116）。
- 妹妹（汐莉）：她称「汐莉」（0006、0021）；妹妹叫她「お姉ちゃん」（0012）。妹妹闹脾气时她说是不是反抗期（0023）。
- 父亲：称「お父さん」（0065、0092）。讲起父亲严格但在关键时刻支持她（0092～0095）。

## 档案类事实
- 父亲从以前就比较严格，想让她继承酒蔵的工作（0092、0093）；她鼓起勇气说想当偶像后，父亲说去做你最喜欢的事，并帮她说服了母亲（0094、0095）。
- 和父亲约好要成为トップアイドル、回乡开凯旋ライブ（0096、0097）。
- 会做乌冬，出汁的底是速食的，汐莉很喜欢（0001、0006）。
- 父亲约一周后出院（0091）。
- 成为偶像的原因：想成为让大家笑的歌のお姉さん，想成为在舞台上发光的初星前辈那样（0105、0106）；一度想放弃，那时遇到了制作人（0107、0108）。
- 制作人在上大学、有学分（0008、0009）。
