# 姫崎莉波 亲爱度剧情 / 第26话（adv_dear_hrnm_026）

- 她的台词：52 行（含用匿名标签说的 0 行）
- 出场的人：莉波（52）、プロデューサー（35）、莉波の妹（7）、父（2）
- 场景：老家的早上（0002～0013）；之后去两人初次相遇的地方（0031 起）；回家（0081 起）；父亲的病房（0091 起）
- 世界线：亲爱度（姫崎莉波）；制作人在制作的偶像：姫崎莉波

## 发生了什么
她在和晨练一样的时间醒来，发现制作人做好了早饭（0002～0008）。制作人问今天怎么过，她提议去两人初次相遇的地方，妹妹喊着约会被她否认（0016～0030）。两人回顾变化了的地方，谈到当年的事；她说再次见面没想到，“请当我姐姐”让她困惑，然后说这是两人的做法（0032～0059）。她告诉他，相遇那天自己其实也在哭：汐莉刚出生，觉得父母不理她；但他看起来更寂寞，为让他笑而唱了歌（0060～0066）。她问：如果退学在这里一起过怎么办，他说也不错，还说可以在她老家开事务所；她问他没想过她会放弃当偶像吗，他说从没想过，因为她最喜欢偶像（0068～0078）。回家后她去换他的被褥，发现了夢ノート（0087～0090）。同时制作人到病房对她父亲说有事相求（0091～0096）。

## 行为模式
- 没有练习的早上 → 还在练习的时间醒来（0002）
- 被照顾 → 先说谢谢，又说你是客人（0011）
- 想说要紧的话 → 先绕到回忆，说“如果”（0060、0068～0070）
- 自己难过但别人更难过 → 把自己放后面，唱歌让对方笑（0063～0065）
- 寂寞时 → 唱那首歌（0066）
- 妹妹起哄 → 马上否认（0030）

## 关系
- プロデューサー：她叫「{user}くん」（0005、0008、0068），称「きみ」（0026）；制作人叫她「姫崎さん」（0014、0056）。她说“这是我们的做法”（0058），告诉他那天的往事（0060～0066），用“如果”试探他（0068～0076）。
- 妹妹（汐莉）：她叫「汐莉ちゃん」（0030、0061）；妹妹叫她「お姉ちゃん」（0082）。
- 父母：相遇那天正是汐莉刚出生，她觉得父母不理她（0061、0062）。

## 档案类事实
- 初次相遇是在暑假（0026）；那天她自己也在哭，因为汐莉刚出生，觉得父母不理她（0060～0063）。
- 寂寞时至今仍唱那首歌（0066）。
- 和他一起吃过点心铺的冰棍，分成两半；小时候吃梅子醋渍的零食，舌头变红被妈妈骂（0033、0035；0034 是制作人说的）。
- 醒来的时间和早朝レッスン一样（0002）。
- 小时候唱给他的歌，她自己说很笨拙（0043）。
- 制作人在学园的名册上找到她的名字（0047，制作人的话）；父亲说他春天曾来打招呼（0092，父亲的话）。
