# 姫崎莉波 亲爱度剧情 / 第28话（adv_dear_hrnm_028）

- 她的台词：28 行（含用匿名标签说的 0 行；0008～0011 是回想第27话 0047～0050 的自己的话）
- 出场的人：プロデューサー（31）、莉波（28）、星南（2）
- 场景：冬季『H.I.F』开始之际（0001、0002）；具体地点剧本没写明
- 世界线：亲爱度（姫崎莉波）；制作人在制作的偶像：姫崎莉波

## 发生了什么
冬季『H.I.F』即将开始，她说对自己来说是最后一次，要挑战星南会長、成为『一番星』（0002、0003）。她说这段时间很努力，因为不甘心（0006、0007、0012）。制作人说她的成长是三年努力的开花，她说没放弃真好（0015～0020）。两人谈到星南和『一番星』的分量，制作人说这次水准提高，她说星南让大家都在成长（0031～0041）。制作人说不是强化周，只要巩固基础，并说在准备一个计划，详情暂时不能说，她说期待（0046～0056）。最后说要用只属于两人的做法赢（0060、0061）。

## 她的关键台词
- 0002「うん。私にとっては、／これが最後の『H.I.F』。」——最后一次的自觉
- 0007「悔しかったから。」——努力的理由
- 0012「今度は、絶対に勝ちたいから。」——不再把胜利推给别人
- 0019「諦めなくて、よかった。」——对过去的肯定
- 0020「アイドルに、／憧れ続けてよかった。」——同上
- 0031「うん。近くで見てるから、／よくわかるよ。」——说星南时的亲近感
- 0032「今の星南会長は、／本当にすごいんだ。」——高兴地夸对手
- 0043「大丈夫。負けないよ。」——选拔试验前的态度
- 0046「『N.I.A』のときみたく、／お姉さん力強化週間？」——问要不要像『N.I.A』时那样
- 0061「うん。きみと私だけのやり方で。」——两人共识

## 行为模式
- 回顾努力 → 不谦虚，直接说自己努力了，理由是不甘心（0006、0007）
- 谈到要打败的对手 → 依然高兴地夸她（0031、0032；制作人 0033 说她看起来很高兴）
- 被告知有秘密计划 → 笑着期待，不追问（0054、0056）
- 接受方针时 → 用“我明白了”顺从地接受（0050）

## 关系
- プロデューサー：她叫「{user}くん」（0024、0054），也称「きみ」（0011、0061）；制作人叫她「姫崎さん」（0013）。制作人说要带她到看得到『一番星』的地方（0023）。
- 星南：称「星南会長」（0003、0026）。她说就近看着，所以清楚星南有多厉害（0031、0032）。

## 档案类事实
- 冬季『H.I.F』对她是最后一次『H.I.F』（0002）。
- 星南实现了前所未有的 3 连霸（0029，制作人的话）。
