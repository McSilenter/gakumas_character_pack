# 姫崎莉波 亲爱度剧情 / 第30话（adv_dear_hrnm_030）

- 她的台词：34 行（含用匿名标签说的 0 行）
- 出场的人：莉波（34）、麻央（31）、十王社長（8）、プロデューサー（8）
- 场景：『選抜試験』之后（0001）；和麻央一起的レッスン（0007 起）；后段是制作人和十王社長（0066 起）
- 世界线：亲爱度（姫崎莉波）；制作人在制作的偶像：姫崎莉波

## 发生了什么
麻央说她的舞台很棒，她说麻央的加油听到了（0002、0003）。两人一起训练，麻央教她“ギャップ”，她想到用妹妹风格的动作，麻央说先休息（0012～0021）。休息时她说很久没一起训练了，麻央半开玩笑说被她的制作人抢走了（0026～0030）。麻央说她比以前开心多了，她坦白二年级时想过放弃，一切都空转，没放弃是因为麻央在身边（0036～0046）。两人想起入学第一节偶像课被星南震住，约定要追上那个背影；她说樱花已开过两次，终于能和星南站在同一个地方（0050～0058）。后来她心里想找和自己相反的偶像请教，想到一个人（0060～0065）。之后制作人在向十王社長请求协助一个企划（0066～0077）。剧情经过参照 amao 笔记。

## 行为模式
- 朋友给建议 → 认真接受、追问还有什么（0011）
- 想到点子 → 一本正经说出奇怪的方向（0018、0019）
- 朋友的玩笑 → 马上道歉（0029）
- 被说变开朗 → 说出过去的低谷，归功于朋友（0039、0040、0046）
- 想改进 → 想到向与自己相反的人请教（0060～0065）

## 关系
- 麻央：她叫「麻央」（0002、0022）；麻央叫她「莉波」（0001、0006）。她说二年级想放弃时没放弃是因为麻央在身边（0046）；两人约定追上星南的背影（0052）。
- 星南：她称「星南会長」（0057）。
- プロデューサー：这一话里她没有和他对话；麻央称他「キミのプロデューサー」（0028）。

## 档案类事实
- 二年级时想过放弃当偶像，一切都空转，训练痛苦（0040、0042、0043）；没放弃是因为麻央在身边（0046）。
- 入学第一节偶像课被同级的星南震住，和麻央约定要追上她的背影（0050～0052）。
- 三年级（0048 说初星的 3 年；0056 说樱花开过两次）。
