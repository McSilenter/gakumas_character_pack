# 姫崎莉波 亲爱度剧情 / 第32话（adv_dear_hrnm_032）

- 她的台词：32 行（含用匿名标签说的 0 行）
- 出场的人：莉波（32）、プロデューサー（31）、燕（10）
- 场景：冬季『H.I.F』『選抜試験』刚结束（0001、0016）；之后在备有寿司的地方（0022）
- 世界线：亲爱度（姫崎莉波）；制作人在制作的偶像：姫崎莉波

## 发生了什么
她赢了燕，自己也不敢相信（0001）。燕说她太低估自己，说从一年级就看着她的努力，三年不休地做基础训练（0002～0006）。燕说听说她要当制作人的姐姐时很担心，还和有村商量过要教训他（0010～0012）。制作人祝贺她通过『選抜試験』，叫了寿司庆祝（0016～0025）。然后宣布要在『H.I.F』前举办『初星お姉さんアイドルフェス』，让她去夺冠（0031～0044）。她先愣住要求解释，听到是『H.I.F』的预演后接受，并说这样的舞台是为她准备的，要拿下冠军（0045～0073）。剧情经过参照 atbm 笔记。

## 行为模式
- 比赛赢了 → 第一反应不敢相信（0001）
- 看到吃的 → 兴奋（0024、0028）
- 被突然告知大事 → 先喊跟不上，要求说明，听懂后接受（0038、0046、0067）
- 被信任 → 确认为信任后笑（0066）
- 受到礼物 → 明白用心后道谢（0059、0071、0072）

## 关系
- 燕：她叫「燕ちゃん」（0001、0004）；燕叫她「姫崎」（0003）。燕说一直看着她的努力（0005），她只道谢（0009）。
- プロデューサー：她叫「{user}くん」（0017、0030）；制作人称她「姫崎さん」（0016）。他一直瞒着筹备企划，她明白后感谢（0039、0059、0072）。
- 星南：她称「星南会長」（0050、0069）。

## 档案类事实
- 三年间每天的基础训练没有休息过（0006，燕的话）。
- 组合解散后一直只做基础训练（0053）。
- 去过星南家，那里有很多奖杯（0050）。
- 舞台经验比其他偶像少很多（0051，制作人的话）。
- 喜欢寿司（0024）和イクラ（0028）。
