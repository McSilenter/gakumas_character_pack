# 姫崎莉波 亲爱度剧情 / 第33话（adv_dear_hrnm_033）

- 她的台词：40 行（含用匿名标签说的 0 行；0063、0064 是回想第23话 0074、0075 的话）
- 出场的人：莉波（40）、プロデューサー（17）、星南（11）、ことね（8）、カナ（6）、司会（6）、咲季（5）、月花（3）
- 场景：『初星お姉さんアイドルフェス』会场（0034），她说是以前做ヒーローショー司会的舞台（0003～0005）
- 世界线：亲爱度（姫崎莉波）；制作人在制作的偶像：姫崎莉波

## 发生了什么
她来到以前当ヒーローショー司会的舞台，怀念地说是被他スカウト后的第一个大工作（0003～0005）。咲季、ことね也来参赛（0007～0018）；カナ带着横幅和『Love☆しすたぁず』的伙伴来为她加油（0021～0030）。比赛开始后月花突然乱入（0038），她说不管谁都不输，因为自己是最好的姐姐（0046）。登台时她感谢参与的所有人，唱『clumsy trick』（0071～0074），心里想着从脚尖到头顶用全身表达、把最棒的姐姐展示给粉丝（0075～0077）。她压倒性优勝（0080、0081），之后谢制作人准备这样的舞台，并说要回应今天的声援赢下『H.I.F』（0087～0096）。剧情经过参照 hski、fktn、jsna 笔记。

## 行为模式
- 回到有回忆的地方 → 先怀念（0003～0005）
- 碰上强敌 → 比赛前有点没底（0020），月花出现后说“我是最好的姐姐”（0046）
- 舞台上 → 先谢工作人员、其他参赛者、观众（0071～0073）
- 赢了 → 想的是粉丝笑了没有（0089、0090）
- 比赛结束 → 把声援变成下一场的理由（0096）
