# 姫崎莉波 亲爱度剧情 / 第35话（adv_dear_hrnm_035）

- 她的台词：44 行（含用匿名标签说的 0 行；0042、0051～0055、0061、0062、0064 是回想里的旧话）
- 出场的人：莉波（44）、プロデューサー（15）、星南（9）、麻央（4）
- 场景：『H.I.F』本戦当天，她上场前（0021、0065）
- 世界线：亲爱度（姫崎莉波）；制作人在制作的偶像：姫崎莉波

## 发生了什么
麻央说输赢都不留怨，她只应了一声（0005、0006）。她问星南成为一番星看到的是什么景色，星南说是很美的景色，但她看不到和自己一样的（0010～0019）。上场前她和制作人说话，说『一番星』背负憧憬、祈愿和泪水，说トップアイドル肯定有痛苦，但仍想看『一番星』的景色，和他一起（0028～0039）。其间穿插回想（0041～0043、0050～0055）；她说能相遇是偶像之神的奇迹，他说奇迹是她起的（0044～0049）。她谢他选择了自己（0057、0058），问他记不记得那个约定（0059），回想那句“我成了『一番星』时”（0061～0064）。她说该上场了，约他一起看一番星的景色（0065～0067）。制作人在心里写下了当天的夢ノート，内容是她成了『一番星』（0070～0072）。剧情经过参照 jsna 笔记。

## 她的关键台词
- 0010「一番星になって見る景色は、／どんな景色ですか？」——问憧憬的对象
- 0013「あなたの見ている先が、／私にも見えるのかなって。」——问这个问题的原因
- 0024「私と{user}くんの／歩んできた、これまでを信じてるから。」——上场前的底气
- 0033「アイドルたちの憧れを、祈りを、／涙を背負って――」——她对『一番星』的理解
- 0034「一番強く、輝き続けるんだ。」——同上
- 0036「一番近くで、あの人の／背中を見てきたからわかる。」——对星南的了解
- 0038「私は、『一番星』の景色を、／見てみたいと思う。」——不回避苦的愿望
- 0039「――きみと一緒に。」——她想看的是两人一起
- 0046「アイドルの神様がくれた、／奇跡だと思った。」——对重逢的看法
- 0058「ありがとう。」——对他的感谢
- 0067「一番星の景色、一緒に見よう。」——上场前最后一句

## 行为模式
- 大舞台前 → 不再说害怕，而是把想法说给对方听（0028～0039）
- 接受困难 → 先说苦，再说“即便如此也想看”（0035、0037、0038）
- 想感谢时 → 单独分出一句（0057、0058）

## 关系
- 麻央：她叫「麻央」（0002）；麻央叫她「莉波」（0001）。她回应很简短（0006）。
- 星南：她称「星南会長」（0009、0028）；星南叫她「莉波」（0007）。
- プロデューサー：她叫「{user}くん」（0024、0026），也称「きみ」（0039）；制作人称「姫崎さん」（0047）。

## 档案类事实
- 最后的回想说约定是“在夏季的H.I.F 成为『一番星』时提一个愿望”（0061、0062，第10话 0081、0082 的原话）。
- 她一直在星南身边看着背影（0036）。
