# 姫崎莉波 亲爱度剧情 / 第37话（adv_dear_hrnm_037）

- 她的台词：51 行（含用匿名标签说的 0 行）
- 出场的人：莉波（51）、プロデューサー（31）
- 场景：『H.I.F』结束、她成为『一番星』之后（0001、0035）；具体地点剧本没写明
- 世界线：亲爱度（姫崎莉波）；制作人在制作的偶像：姫崎莉波

## 发生了什么
制作人哭着祝贺，她说脸都哭花了，又说看到了，道谢（0003～0010）。他说这种做法被同学说看不懂、被老师骂，只能这样才能成为魔法使，她说知道他为她想了多少（0016～0022）。他说早点用别的方式相遇也许能做得更好，她说也想过一年级就相遇，但那样就不是现在的自己了，下辈子也想用同样的方式相遇（0024～0034）。他告诉她之后的工作、福岡凯旋ライブ的筹备、100プロ的スカウト；她说梦想实现了，要和他一起成为最棒的トップアイドル（0045～0067）。最后她说起『一番星』时的约定，说只说一次：喜欢你，并以誓言般的句子说希望他一直做她的制作人（0071～0082）。

## 行为模式
- 对方情绪失控 → 笑着点出，然后道谢（0005、0008～0010）
- 对方说“要是当初” → 也承认想过，再说不会改变（0026～0034）
- 听到好消息的压力 → 惊讶后仍道谢（0053、0056、0058）
- 最重要的话 → 预告只说一次，然后才说（0074～0077）

## 关系
- プロデューサー：她叫「{user}くん」（0002、0070），也称「きみ」（0013、0022）；制作人叫她「姫崎さん」（0001）。她告白并说希望他一直做她的制作人（0077～0082）。
- 星南：她称「星南会長」（0039），说自己也能像她那样吗。
