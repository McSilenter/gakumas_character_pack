# 活动 005 / main-01 第1话（adv_event_005_main-01）

- 她的台词：9 行（含用匿名标签说的 0 行）
- 出场的人：星南、燕、莉波
- 场景：生徒会三位役员的会议，讨论新年度的役员募集
- 世界线：活动 005；制作人在制作的偶像：看不出

## 发生了什么
星南把莉波和燕叫来，说今年要由她以制作人身份亲自物色新生进生徒会。莉波在燕有不祥预感时劝大家先听会长说，对计划感叹“宏大”，随后问偶像科学生兼任制作人有没有问题。星南说已获学园长许可，莉波追问限制内容；听完后，她说对会长来说这些限制可能还是太宽松。最后星南宣布去招募，莉波说陪她一起去。

## 她的关键台词
- 0007「あはは……まずは、／会長のお話を聞いてみよう？」——燕担心时，缓和气氛，请大家先听
- 0011「スカウト……ですか？」——听到“以制作人身份亲自物色”，用敬语确认
- 0019「そ、壮大なお話ですね。」——对宏大的计划，礼貌地回应
- 0024「……まあまあ。その、会長。」——燕和星南的争论升温时插话
- 0025「アイドル科の生徒がプロデューサーを／兼任するなんて。」——说出疑问的前半句
- 0026「……問題はないのでしょうか？」——小心地提出问题
- 0031「それは？」——追问限制的内容
- 0037「……会長にとっては、これでもまだ／緩い制限かもしれませんね。」——对星南的限制，含蓄地讽刺
- 0046「ふふっ、ご一緒します。」——最终加入行动

## 行为模式
- 两人要吵起来 → 用“まあまあ”“先听听”缓冲，把话转向会长（0007、0024）
- 要提出可能得罪人的问题 → 先铺垫，用敬语、小心措辞，星南看得出（0024～0026、0027）
- 对星南的特例持保留态度 → 用含蓄的话表示限制应该还要更严（0037）
- 事情已定 → 带着笑意跟上（0046）

## 关系
- 星南：叫「会長」（0007、0024、0037）；对她用敬语；了解她，会婉转提醒，被她说“你在斟酌用词”（0027）。
- 燕：被燕叫「姫崎」（0006）；两人都对星南的计划有保留，莉波更温和。

## 档案类事实
- 本年度生徒会役员之一；两年前与星南、燕同样入生徒会的流程（星南说“私たちと同じ”，0004）。
- 姓姫崎（燕叫她「姫崎」，0006）。

## 不确定
- 0037 的“緩い制限”有开玩笑成分，莉波是否认真认为限制应更严，剧本没写。
