# 活动 005 / main-05 第5话（adv_event_005_main-05）

- 她的台词：6 行（含用匿名标签说的 0 行）
- 出场的人：星南、佑芽、燕、莉波
- 场景：初星学园的走廊，星南为夏天的H.I.F物色新生
- 世界线：活动 005；制作人在制作的偶像：看不出

## 发生了什么
星南发现佑芽后冲出去追，莉波叫住也在跑的燕。星南与佑芽对话，莉波问她是不是要招这个孩子，并问才能是否很高；听了佑芽的倒立、空翻表演，她担心地说"好危险"。最后她说"是"，同意星南邀请佑芽。剧情经过参照 hume 笔记。

## 她的关键台词
- 0007「さすがにそれは……もちろん、／1年生にもすごい子たちはいますけど。」——对"夏天用新生"的想法有保留，又承认新生有厉害的人
- 0017「燕ちゃんも！　／廊下は走らないで～！」——叫燕也不要在走廊跑
- 0035「会長、もしかして……その子を？」——星南追上佑芽后，问是否要招她
- 0045「高かったんですか？」——听星南说"才能"，追问是否很高
- 0059「あ、あぶないよ……？」——看到佑芽倒立、空翻，担心
- 0064「はい。」——星南问有没有意见，同意

## 行为模式
- 想说否定的话时 → 先说"さすがに……"，再补上承认对方的话（0007）
- 同伴也犯了同样的错 → 同时提醒，用"ちゃん"称呼燕（0017）
- 看到有危险的举动 → 小声担心，用对后辈的口气（0059）
- 被问意见 → 简短同意（0064）

## 关系
- 星南：叫「会長」（0035）。
- 燕：叫「燕ちゃん」（0017）；与燕一同被星南问有无意见（0063～0065）。
- 佑芽：本篇无直接称呼，用"あぶないよ"对她说话（0059）。
