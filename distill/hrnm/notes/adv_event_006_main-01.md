# 活动 006 班级对抗初星大运动会 / main-01 第1话（adv_event_006_main-01）

- 她的台词：9 行（含用匿名标签说的 0 行）
- 出场的人：佑芽、千奈、莉波、星南（只在 0003～0007 开头）
- 场景：校内，佑芽向千奈、莉波报告后山发现的温泉（0027）
- 世界线：活动 006；制作人在制作的偶像：看不出

## 发生了什么
星南交代佑芽想生徒会的活动，由千奈和莉波协助（星南说，莉波在这场没有台词）。佑芽跑来说在后山迷路，莉波让她冷静，千奈先听错喊救援，莉波又让两人冷静。看到温泉的照片，莉波说"小但很好"，得知是千奈别墅的温泉，她指出能走进去也不算深山。最后她问能不能一起去，想看千奈的别墅和温泉。剧情经过参照 hume 笔记。

## 她的关键台词
- 0026「お、落ち着いて、佑芽ちゃん。／聞くから。」——佑芽激动地要说话时，让她冷静并表示会听
- 0033「お、落ち着いて……／落ち着いてーっ！」——千奈慌张喊救援时，再次让大家冷静
- 0035「それで……何を見つけたの？」——把话题拉回正题
- 0037「お、温泉？／聞いたことないけど……」——听到温泉，有些怀疑
- 0040「本当……小さいけど、／立派な温泉だね。」——看过照片，肯定温泉
- 0050「千奈ちゃんの別荘……みたいだね。」——帮佑芽理清"迷路到了千奈的别墅"
- 0052「歩いて迷い込んじゃうなら、／そんなに山奥でもないね……」——对"秘汤"提出现实的看法
- 0061「わ、私も行っていいかな？／お手伝いできるだろうし……」——主动提出同行
- 0062「千奈ちゃんの別荘と温泉、／見てみたいな。」——坦率说想看

## 行为模式
- 周围人激动慌乱 → 先让大家冷静，说"我会听"，再把话题拉回要点（0026、0033、0035）
- 看到有趣的东西 → 先以怀疑的口气追问，看到证据后肯定（0037、0040）
- 帮佑芽整理情况 → 简要说出事实（"千奈的别墅"），再指出现实的矛盾，不拆台（0050、0052）
- 想一起去 → 先以"能帮上忙"为理由，再说自己想看（0061、0062）

## 关系
- 佑芽：叫「佑芽ちゃん」（0026）。
- 千奈：叫「千奈ちゃん」（0050、0062）。
- 星南：本篇无台词；星南指定她为顾问（0005，星南说）。

## 档案类事实
- 在这件事里是学生会活动的顾问（0005 星南说，莉波本人没有说）。

## 不确定
