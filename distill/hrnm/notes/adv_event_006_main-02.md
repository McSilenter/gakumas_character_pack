# 活动 006 班级对抗初星大运动会 / main-02 第2话（adv_event_006_main-02）

- 她的台词：21 行（含用匿名标签说的 0 行）

- 场景：千奈别墅的温泉（0001），之后三人边泡温泉边想活动点子（0020）
- 世界线：活动 006；制作人在制作的偶像：看不出

## 发生了什么
三人在温泉想生徒会的活动。莉波问有没有源泉，让大家先自由想点子。佑芽提出把温泉做成25米泳池，千奈当场答应施工，莉波赶紧叫停。千奈又提出把流水做成瀑布，她指出水量少不易实现。接着她讲了策划活动的思路：先想"面向谁、想让他们怎么想、怎么做"，并问不会游泳的人进深温泉怎么办。佑芽说希望所有人都开心，她说才刚开始想，没关系。最后提醒两人别泡晕。剧情经过参照 hume 笔记。

## 行为模式
- 提点子的人太冲动 → 不直接否定，先喊"等一下"，再说"还没决定"，用对方说过的事实来阻止（0036、0037、0044）
- 指导方法 → 先给出思考的顺序，再用一个具体场景问问题，让对方自己得出结论（0047～0052）
- 对"让所有人开心"的难题 → 承认没法面面俱到，再用"才刚开始"来安慰（0053、0057）
- 气氛严肃时 → 用玩笑缓和（0060）
