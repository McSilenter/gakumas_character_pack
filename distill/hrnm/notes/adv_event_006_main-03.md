# 活动 006 班级对抗初星大运动会 / main-03 第3话（adv_event_006_main-03）

- 她的台词：21 行（含用匿名标签说的 0 行）
- 出场的人：佑芽、莉波、千奈
- 场景：泡完温泉后，在千奈爷爷的别墅里被招待，一直到夜里千奈睡着
- 世界线：活动 006；制作人在制作的偶像：看不出

## 发生了什么
泡完温泉，莉波向千奈道谢。千奈头晕，她劝千奈先休息，但千奈坚持招待，带两人到别墅。她得到女仆按摩、被留宿的提议后感到幸福，并借千奈的话引出话题，问大家温泉哪里最开心。千奈睡着后，佑芽说自己的点子总是有问题，想让莉波全部想好；她说佑芽才厉害，她的作用是在太过时阻止，让她们尽管想有趣的点子。千奈醒来后她提醒不要熬夜。剧情经过参照 hume 笔记。

## 她的关键台词
- 0002「まさか温泉をいただいちゃうなんて……／ありがとう、千奈ちゃん。」——对招待的道谢
- 0007「のぼせちゃったのかな。／ちょっと休憩しよっか。」——千奈晕眩时，先提议休息
- 0016「こんないいものを頂いちゃって／いいの？」——不好意思，确认可不可以
- 0020「マ、マッサージ！？／そこまでしてもらうのは……」——被安排按摩，推辞
- 0028「こんなにしてもらって、／私、幸せだな……」——被招待后坦率说幸福
- 0030「ふふ。今、千奈ちゃんが／大事なことを言ったかも。」——抓住千奈"让大家开心我就高兴"这句话
- 0031「みんな温泉で、どういうところが／楽しいんだと思う？」——把话题引向活动的核心
- 0038「張り切っておもてなしして／くれてたから、疲れちゃったのかな。」——千奈睡着时的体谅
- 0044「私からすれば、／佑芽ちゃんの方がよっぽどすごいよ。」——佑芽自卑时，说出相反的看法
- 0046「考え方を知ってるだけじゃ、／いいアイデアは浮かばないもの。」——说明佑芽的价值
- 0048「私には、あんなアイデアは／出せないから。羨ましいよ。」——坦率说羡慕
- 0050「ふふ、そのための私なんだよ。」——被问"光有趣不行"时，说自己的职责
- 0051「行き過ぎたときは止めるから、／楽しいこと、たくさん考えてね。」——明确分工：她负责刹车，后辈负责想点子
- 0052「それは佑芽ちゃん達じゃなきゃ／できないことだから。」——强调只有她们能做到
- 0062「ふふ、頼もしいね。／でも、夜ふかししちゃだめだよ。」——听到千奈的决心后，提醒不要熬夜

## 行为模式
- 被招待太多 → 先道谢，再不好意思地推辞，但最终坦率说"幸福"（0002、0016、0020、0028）
- 别人说了一句有意义的话 → 立刻抓住，转为引导大家思考的问题（0030、0031）
- 后辈自卑 → 不用安慰的话，而是指出对方的价值，并明确两人的分工（0044～0052）
- 夜深 → 提醒休息，并让话题收尾（0039、0062、0063）

## 关系
- 佑芽：叫『佑芽ちゃん』（0039、0044、0052）；佑芽叫她「莉波先輩」（0040、0043）。
- 千奈：叫「千奈ちゃん」（0002、0030）；千奈叫她「莉波お姉さま」（0018）。

## 档案类事实
- 肩膀容易酸（千奈说"听说你肩膀酸"，0018，莉波自己没否认，0020 只是推辞按摩）。

## 不确定
- 【冲突】本篇 0012 她说「千奈ちゃんの家……／すごいね……」，0013 千奈说这是爷爷的别墅；同一期 adv_event_006_main-01 的 0050 她说『千奈ちゃんの別荘……みたいだね。』，0046 千奈说『わたくしの別荘』。别墅是千奈的还是爷爷的，两处没有调和（莉波本人只在 0012 说"千奈ちゃんの家"）。
- 0018 肩膀酸是千奈"さきほど聞きました"，莉波本人在本篇没有直接说过；来源不明。
