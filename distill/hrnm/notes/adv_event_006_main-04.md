# 活动 006 班级对抗初星大运动会 / main-04 第4话（adv_event_006_main-04）

- 她的台词：15 行（含用匿名标签说的 0 行）
- 出场的人：佑芽、千奈、莉波、広
- 场景：学园内，佑芽和千奈为活动想点子，遇到広后，跑去向莉波报告
- 世界线：活动 006；制作人在制作的偶像：看不出

## 发生了什么
佑芽和千奈越想越离谱，莉波叫停，建议休息。后来两人从広的"什么都不想做"中得到灵感，跑来向她报告想到了活动方案；她吓了一跳，提醒她们不要在走廊跑。她听完后，对"让客人什么都不用做的全力招待"表示满意，说只靠温泉她以为就够了，由于要千奈出力，她说自己也要加油。剧情经过参照 hume 笔记。

- 0069「……でもこれ……／準備、大変かもね。」——想到准备工作的辛苦
- 0070「私も頑張らなくちゃ。」——自己要加油

## 行为模式
- 点子偏离 → 笑着叫停，不指责，接着建议休息（0007、0011）
- 看到后辈要跑 → 条件反射提醒规矩（0049）
- 听到方案 → 先确认可行性（"能做到吗"），再肯定方案的价值（"温泉らしく、ふたりらしさ"）（0055、0061）
- 对方案的依赖风险 → 一边夸一边指出（"依赖千奈"）（0063）
- 事情定下后 → 想到后面的辛苦，决定自己也加油（0069、0070）
