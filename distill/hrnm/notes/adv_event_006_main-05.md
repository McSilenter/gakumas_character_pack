# 活动 006 班级对抗初星大运动会 / main-05 第5话（adv_event_006_main-05）

- 她的台词：14 行（含用匿名标签说的 0 行）；0078「一同」不计，见“不确定”
- 出场的人：佑芽、広、千奈、莉波
- 场景：千奈家的别墅，活动『初星温泉　～木枯らしに散る～』当天，之后是活动结束后的收尾
- 世界线：活动 006；制作人在制作的偶像：看不出

## 发生了什么
活动当天，她迎接广，让她先泡温泉。活动结束后，她让佑芽和千奈看问卷，两人看到好评，她说大成功，称赞两人，又说自己只是帮忙，并转告会长也夸奖，下次可能还会委托她们。佑芽担心想不出好点子，她说她们已经知道做法了，之前的点子也许下次能用。大家去泡温泉前，她带头喊"辛苦了"。剧情经过参照 hume 笔记。

## 行为模式
- 后辈们的成果 → 先让她们自己读问卷，等她们反应过来后再宣布"大成功"（0048、0056）
- 被感谢 → 说"我只是帮忙"，把功劳归给后辈（0060）
- 后辈担心下次 → 说明"已经掌握方法"和"可以重用点子"这两个具体的理由（0067、0068）
- 要结束一天 → 带头做总结（0043、0077）
