## 发生了什么
広发现去加纳赶不上情人节，改成印尼，莉波劝她，说授课、训练都有，带回来也麻烦；问她是否一定要从可可豆做起，她说想让朋友惊讶，莉波提出百货店也有，她请莉波一起去。莉波分担了重量。翌日広一个人从可可豆开始做，四小时后莉波来看，她手掌发红，做出来的巧克力沙沙的，说失败了，请莉波一起做。两人做出了成品，広说这次很开心。

## 行为模式
- 同伴提出夸张计划 → 先认同事实，再逐项用现实条件劝阻（授课、训练、搬运），最后给出替代方案（0003、0006～0013）
- 同伴拒绝帮忙 → 不勉强，留余地：“有困难再商量”（0028～0031）
- 同伴逞强受伤 → 先担心身体（手掌红了），再问做了多久（0047、0049）
- 试吃不好吃的东西 → 不当场评价，尴尬地沉默（0052、0054、0056）
- 同伴请求 → 立刻答应，不追问（0021、0063）
