# 活动 010 星南与燕的日常 / main-05 情人节协奏曲 第5话（adv_event_010_main-05）

- 她的台词：9 行（含用匿名标签说的 0 行）：0002、0003、0007、0009、0023、0024、0043、0045、0063
- 出场的人：莉波、広、星南、佑芽、千奈、美鈴、手毬、ことね、咲季、一同
- 场景：情人节节日（バレンタインフェス）当天早上，学园内；后来是舞台前。
- 世界线：活动 010；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
节日当天早上，莉波问広什么时候送巧克力，広说在找时机，莉波觉得她想得太复杂。星南来后给広借舞台一曲的空档，莉波替她高兴，并问星南是否已把巧克力送给ことね，得知还没找到人。后来她叫広去舞台、给她打气，并在広送友チョコ时说巧克力是広从可可豆做起的（0062 広说莉波帮了忙）。
剧情经过参照 ttmr 笔记。

## 她的关键台词
- 0002「んー、晴れてよかったぁ。／今日は一日、忙しくなりそう。」——节日当天开口先说天气，语气轻松。
- 0003「広ちゃん、チョコはいつ渡すの？」——主动问広的计划。
- 0007「……うーん。難しく／考えすぎじゃないかなぁ。」——広担心时机时，温和地指出她想太多。
- 0009「会長、おはようございます。」——对星南用敬语，称「会長」。
- 0023「よかったね。／最高のサプライズ演出だよ。」——为広高兴，并夸这是最棒的惊喜演出。
- 0024「そういえば、会長。あのチョコ、／ことねちゃんにあげたんですか……？」——想起星南的巧克力，顺着话题问。
- 0043「広ちゃん、みんな来てるよ。」——到时间提醒広，朋友们到了。
- 0045「がんばってね。」——上台前简短打气。
- 0063「広ちゃんが、カカオ豆から／作ったんだよ。」——向大家介绍，把功劳归给広。

## 行为模式
- 朋友烦恼 → 先问具体问题（0003），再用“想得太复杂了吧”这种柔和的话缓和（0007）。
- 朋友得到好机会 → 先说“よかったね”再夸（0023）。
- 到关键时刻 → 报告情况、简单打气，不多话（0043、0045）。
- 朋友做出成绩 → 在大家面前替对方说明努力（0063）。

## 关系
- 広：叫她「広ちゃん」（0003、0043）；広叫她「莉波」（0046），她帮広做巧克力（0062 広所说）。
- 星南：叫她「会長」（0009、0024），用敬体；星南直接叫她「莉波」（0008）。
- ことね：称「ことねちゃん」（0024）。
