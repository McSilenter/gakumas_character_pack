- 她的台词：25 行（含用匿名标签说的 0 行）：0001、0005、0006、0008、0010、0013、0014、0018、0025、0034、0035、0039、0047、0048、0049、0062、0063、0064、0066、0071、0072、0074、0075、0079、0082。其中 0034 起（0033「――2年前。」）到 0079 是回忆里入学当初的场景；0039、0047、0048、0049、0062、0063 是括号里的心声，0071 是出声前的停顿（只有「………………い、」）。
- 出场的人：莉波、燕、麻央、星南、一同、クラス全員
- 场景：修学旅行前的行程商量（教室一类的地方，地点未写）；0033 起回到两年前入学当初的教室。
- 世界线：活动 013；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
修学旅行的行程商量，莉波征求大家的意见：麻央想去能乐堂，燕想去壬生寺，莉波自己想去清水寺和芸能神社。燕说不该把梦想托付给神，麻央反问是不是说他们努力不够，两人快吵起来，莉波让他们“要吵去外面”。星南笑着回忆起入学时班级的火花四溅，进入回忆：莉波在自我介绍后被班上的敌对气氛吓到，决定自己出面，最后大喊“适可而止”，说让粉丝开心才是偶像，大家道歉，她成为级长。回到现在，她说“好丢人”。
剧情经过无其他笔记可参照。

## 她的关键台词
- 0001「それじゃあ、とりあえず、／みんなの意見を聞かせて。」——开场主持，先让大家说意见。
- 0006「星南会長は、どこか、／行きたい場所ってありますか？」——注意到会长没说，专门问她；称「星南会長」，用敬体。
- 0013「……そうだねぇ。定番の清水寺とか、／あ、芸能神社には参拝したいかな。」——被问自己的愿望，想去的是清水寺和芸能神社。
- 0014「今年こそ、アイドルとして羽ばたけ／ますようにって、お願いするんだ。」——说出愿望：今年一定要作为偶像飞起来。
- 0018「う、うん……それはそうだね。」——被燕说“夢は自己の手で掴むもの”后，先承认对方的话。
- 0025「……麻央。燕ちゃんも。／喧嘩するなら、お外でね。」——两人快吵起来，说话很轻，但直接制止。
- 0035「ア、アイドルは未経験ですけど、／一生懸命がんばりますっ！」——回忆：入学自我介绍，说自己是未经验者，会拼命努力。
- 0048「（アイドル科って、もっとキラキラした／感じだと思ってたのに……）」——回忆心声：与想象中的偶像科不同。
- 0063「（……っ、私が、なんとかしなきゃ！）」——回忆心声：决定自己出面。
- 0066「み、みんな、仲良くしたほうが、／いいんじゃないかなー……って。」——回忆：第一次开口只敢小声地劝。
- 0072「いい加減にしなさーーーーいっ！」——回忆：被无视后爆发。
- 0074「お客さんを……ファンの人を／楽しませるのがアイドルでしょ。」——回忆：用“偶像的本分”劝大家。
- 0079「……こほん。よろしい。」——回忆：大家道歉后收场。
- 0082「……そ、そんなこともありましたね。／恥ずかしい……」——被提起往事，害羞。

## 行为模式
- 会议/商量 → 先让每个人说，再顾及没开口的人（0001、0005、0006）。
- 同伴快吵起来 → 用“喧嘩するなら、お外でね”这类轻口吻直接制止，不提高声音（0025）。
- 回忆里面对敌对的班级 → 先在心里着急，鼓起勇气劝；被无视后爆发，之后用“偶像应该让粉丝开心”作为道理（0063-0075）。
- 被提起自己强势的往事 → 害羞地敬体回应（0082）。
