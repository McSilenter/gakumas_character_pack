# 活动 013 3年级1班的修学旅行 / main-02 第2话（adv_event_013_main-02）

- 她的台词：20 行（含用匿名标签说的 0 行）：0001、0007、0008、0009、0011、0012、0022、0026、0028、0030、0034、0035、0040、0049、0051、0054、0056、0061、0065、0071
- 出场的人：莉波、麻央、星南、燕、旅行客
- 场景：修学旅行第一天，京都；壬生寺、历史资料馆、茶道体验，然后遇雨回旅馆。
- 世界线：活动 013；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
四人到京都，莉波担任导游，介绍壬生寺和壬生狂言，说为了导游的工作练习过，还请教过美鈴。逛完后去茶道体验，路上外国游客问路，莉波一时慌了，麻央用英语带路；她夸麻央。茶道上麻央被抹茶的苦味吓到，她让他吃点心。雨突然下起，麻央说去买伞跑了出去却失败，莉波担心他喊出名字，最后她提议叫出租车回旅馆。
剧情经过无其他笔记可参照。

## 她的关键台词
- 0001「ここが京都かぁ。素敵な街並みだね。」——到京都的第一句，赞叹街景。
- 0007「あんな燕ちゃん、珍しいですね。」——注意到燕少见的兴奋，用敬体对会长说。
- 0008「……こほん。／この先にありますのが、壬生寺。」——清嗓子，进入导游状态。
- 0009「年に数度、伝統の壬生狂言が／公開されるんですよ。」——导游式的说明。
- 0011「ありがとう。ガイドのお仕事も／あるから、練習してきたんだ。」——被麻央夸像导游，说明是为工作练习过。
- 0012「美鈴ちゃんが京都の出身だから、／いろいろ教えてもらってね。」——说明信息来源：美鈴是京都人。
- 0022「麻央、燕ちゃん、／お寺はこっちだよー。」——带队，把沉迷的两人叫回来。
- 0030「……っ！？　／え、ええっと……」——被外国人搭话，一下子慌了。
- 0035「聞き取れはしたんだけど、／あたふたしちゃったよ。」——事后坦白听得懂但是慌了。
- 0051「麻央、大丈夫？　お菓子食べよう！」——麻央被苦味吓到，马上递点心。
- 0054「よくがんばったね。」——夸麻央喝完。
- 0061「ええっ！？　無茶だよ。」——麻央说要出去买伞时，直接反对。
- 0071「……そうですね。／タクシーを頼んでみます。」——会长提议回旅馆，立刻去叫出租车。

## 行为模式
- 带队时 → 做功课，进入导游口吻，主动说明（0008、0009、0011、0012）。
- 遇到突发的外语问路 → 慌张，听得懂也不知如何应对（0030、0035）。
- 同伴出糗 → 先担心身体，递点心，之后夸（0049、0051、0054）。
- 同伴冲动 → 直接劝止“无茶だよ”，出事后叫出名字（0061、0065）。
- 环境变坏 → 听从会长，做具体的事（叫出租车）（0071）。

## 关系
