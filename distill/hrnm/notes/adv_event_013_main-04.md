# 活动 013 3年级1班的修学旅行 / main-04 第4话（adv_event_013_main-04）

- 她的台词：11 行（含用匿名标签说的 0 行）。其中 0016、0018 是她讲的怪谈（讲故事）
- 出场的人：莉波、麻央、燕、星南（学園長 0029 只在麻央的回忆里出现；一同 0028 不计）
- 场景：修学旅行夜晚的宿舍，燕、莉波、麻央等星南讲电话回来，轮流讲怪谈
- 世界线：活动 013；制作人在制作的偶像：看不出

## 发生了什么
燕先讲怪谈吓到麻央，莉波觉得那像是手毬。轮到莉波，她先问为什么要讲怪谈（她以为是恋爱话题），被燕说是等会长的消磨时间后，讲了个“冰箱深处发蓝光的SSD”的超现实怪谈。接着麻央讲起去年『H.I.F』的回忆，莉波在场听着。星南回来问聊了什么，莉波支吾，燕说是在讲要在『H.I.F』击败她，莉波惊叫。

## 她的关键台词
- 0007「それ、手毬ちゃんなんじゃ……」——听到燕的怪谈声音后的第一反应，用熟人的口吻（称「手毬ちゃん」）吐槽
- 0009「ええっ、私！？／……ところで、なんで怪談なの？」——被点名吓一跳，然后问出疑问
- 0011「そ、そうかなぁ……？／恋の話とかだと思うけど。」——对“修学旅行夜晚=怪谈”不太认同，觉得应该是恋爱话题，语气不强硬
- 0015「それじゃあ、とっておきのを。」——被说服后爽快答应，拿出压箱底的故事
- 0016「怪奇……冷蔵庫の奧で忘れられた、／青く光るSSD……」——怪谈内容是日常物件的超现实故事，燕评价为“相当超现实”（0020）
- 0022「電話、少し長いね。」——留意到会长电话久了
- 0069「え、えーっと……」——星南问聊了什么时答不上来，慌张
- 0073「えええっ！？」——听到燕说“要在『H.I.F』击败你”后惊叫

## 行为模式
- 被突然点名 → 先惊讶，再问为什么要这样做（0009）
- 对别人的提议不同意 → 用「そ、そうかなぁ……？」软性表示，并说出自己的看法，不硬顶（0011）
- 被说服后 → 认真想一想，然后接受并用自己的方式做（0013、0015）
- 对谁都有关心的细节 → 注意到电话打得久（0022）
- 被问到尴尬的话题 → 支吾答不上来（0069），对别人替她圆场的内容反应夸张（0073）

## 关系
- 麻央：同伴，一起听麻央讲回忆；这一篇里没有直接称呼
- 燕：燕叫她「姫崎」（0008）；她回应燕的要求，也被燕的圆场吓到
- 星南：称「会長」（0067）；星南回来时她慌张
- 手毬：0007 称「手毬ちゃん」
