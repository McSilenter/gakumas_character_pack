# 活动 013 3年级1班的修学旅行 / main-05 第5话（adv_event_013_main-05）

- 她的台词：15 行（含用匿名标签说的 0 行）
- 出场的人：莉波、星南、燕、麻央（千奈 0002～0005、美鈴 0008 只在开头的联络场面；一同 0080 不计）
- 场景：修学旅行中，先在买伴手礼的店里，之后在供奉演艺之神的神社的绘马处，她负责介绍神社
- 世界线：活动 013；制作人在制作的偶像：看不出（星南在 0024 说自己正在培育学生会一年级的孩子们）

## 发生了什么
莉波和麻央在店里选伴手礼，她考虑给学生会的大家买金平糖，劝麻央买耳勺前再想想。到了神社，她介绍这里供奉演艺之神、可以挂绘马，问会长想许什么愿。听麻央宣布要追上星南后，她说自己也是同样的想法：虽然不像麻央那样有自信，但想和会长堂堂正正对决，把现在的全力给会长看。剧情经过参照 hmsz 笔记。

## 她的关键台词
- 0010「生徒会のみんなへのお土産は、／金平糖にしようかなぁ。」——选伴手礼时先想到学生会的大家
- 0013「入浴剤は、咲季ちゃんたちも／喜んでくれそうだね。」——麻央选入浴剂后，想到咲季她们会喜欢
- 0016「ま、麻央……！？／買う前によく考えよう？」——麻央想买新选组刀耳勺时慌张劝阻
- 0047「ここが、芸能の神様の／祀られている神社です。」——担任向导，介绍神社
- 0051「会長は、なにか神様に／お願いしたいこと、ありますか？」——主动问星南想许什么愿
- 0058「なれますように、じゃなくて、／なります、なんだ。」——听麻央的愿望后注意到她用的是断言
- 0066「私は麻央みたいに、自信はないです。／でも、会長と真っ向勝負したい。」——承认没有麻央那样的自信，但想正面对决
- 0067「会長が、私のこと、／敵って言ってくれたから――」——想正面对决的理由：会长说过她是对手
- 0068「ずっと会長の近くに居て、ずっと、／あなたのステージを観てきた。」——一直在会长身边看她的舞台
- 0069「今の私の全力、会長にぶつけます！」——宣言要把现在的全力对会长展现
- 0065「私も、同じです。会長。」——接在麻央宣言之后，表示自己也一样

## 行为模式
- 选礼物 → 先想到的是学生会和同伴（金平糖、入浴剂会让咲季她们喜欢）（0010、0013）
- 同伴冲动要买东西 → 慌张但温和地劝“买之前再想想”（0016）
- 想了解对方 → 用敬语主动发问（0051）
- 听到别人有力的宣言 → 注意到措辞的不同并点出来（0058），再说出自己的立场，先承认自己不如对方有自信，再说出愿意拼（0065、0066、0069）
- 说出对星南的态度 → 用“被说过是敌人”和“一直看着她的舞台”作为理由（0067、0068）

## 关系
- 星南：称「会長」（0051、0065）；星南曾说过她是“敌人”（0067）；她一直待在星南身边看她的舞台（0068）
- 麻央：叫她「麻央」（0016、0055）；以同伴身份回应她的宣言
- 咲季：叫「咲季ちゃん」（0013）
- 燕：被燕评价“姫崎もなかなか言うようになった”（0070）
