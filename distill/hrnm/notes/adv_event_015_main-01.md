# 活动 015 / 巡演活动 广岛篇 第1话（adv_event_015_main-01）

- 她的台词：22 行（含用匿名标签说的 0 行）。其中 0045、0046、0050 是括号里的内心独白
- 出场的人：莉波、リーリヤ、千奈
- 场景：莉波向千奈提出一起去广岛办unit live的场面，之后リーリヤ出场；具体地点看不出，时间点在广岛live的筹备前（0049「明日の放課後に、／さっそく作戦会議を始めよっか。」）
- 世界线：活动 015；制作人在制作的偶像：看不出

## 发生了什么
莉波邀请千奈参加3年级的「引率プログラム」，两位1年级生和她一起在广岛办一场从选曲到演出都自己创作的unit live。她对千奈说，是因为知道千奈很努力，生徒会的企划里也受过千奈的点子帮助。第三位成员是在布告栏前看招募海报的リーリヤ，莉波主动向她搭话；リーリヤ犹豫后说有兴趣，莉波邀她加入。莉波在内心想，1年级时自己没勇气，错过了参加，3年级的自己要好好带后辈。

## 她的关键台词
- 0003「3年生の引率プログラムで、／1年生の子をふたり／連れて行くことになってるんだ。」——说明邀请的背景：3年级生要带两位1年级生
- 0008「うん。千奈ちゃんがいいんだ。」——被问为什么选她，直接回答
- 0010「千奈ちゃんがすごく頑張ってること、／ちゃんと知ってるよ。」——选她的理由：知道她的努力
- 0012「セットリストから演出まで、／自分たちで考えて創るライブなの。」——说明这次live的性质
- 0013「生徒会の企画でも、千奈ちゃんの／アイデアに助けられてるし、」——举出在生徒会企划里受到千奈的帮助
- 0014「一緒にいろいろ考えてくれたら、／嬉しいなぁって。」——希望的不是千奈照做，而是一起想
- 0025「声をかけちゃいました♪」——说明她主动搭话的リーリヤ
- 0041「リーリヤちゃん、興味があるなら、／よかったら、一緒にどうかな？」——看出リーリヤ有兴趣，主动邀请
- 0045「（見守ろうかと思ったけど、／声をかけてよかったな……）」——内心：本来想在一旁看着，但搭话是对的
- 0046「（私が1年生のときは、勇気がなくて、／参加しそびれちゃったから――）」——内心：自己1年级时因为没有勇气没参加
- 0050「（3年生の私が、しっかり／後輩たちを引っぱらないとね……！）」——内心：3年级生要带好后辈

## 行为模式
- 想拜托后辈 → 具体说出“为什么是你”的理由，而且是对方自己做到的事，再说自己希望一起想（0008、0010、0013、0014）
- 看到有兴趣却犹豫的后辈 → 先注意到，打算在旁边看，最后还是主动搭话（0037、0041、0045）
- 搭话吓到对方 → 马上道歉（0036）
- 对后辈的责任 → 用“3年级生的我”来要求自己（0050）
- 事情谈成后 → 当场定下“明天放学后开作战会议”（0049）

## 关系
- 千奈：叫她「千奈ちゃん」（0008），千奈称她「莉波お姉さま」（0001）；生徒会共事（0013）
- リーリヤ：叫她「リーリヤちゃん」（0033），リーリヤ称「姫崎センパイ」（0035）；对她主动搭话

## 档案类事实
- 莉波是3年级，参加「引率プログラム」，带两位1年级生去广岛办live（0003、0004）
- 莉波1年级时因为没有勇气，错过了同样的活动（0046）
- 莉波和千奈在生徒会一起工作（0013）
