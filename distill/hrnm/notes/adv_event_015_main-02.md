# 活动 015 / 巡演活动 广岛篇 第2话（adv_event_015_main-02）

- 她的台词：24 行（含用匿名标签说的 0 行）
- 出场的人：莉波、千奈、リーリヤ
- 场景：筹备广岛live的作战会议，三人在商量set list、unit曲的分担、MC和广岛观光
- 世界线：活动 015；制作人在制作的偶像：看不出

## 发生了什么
三人商量set list，莉波想放『初』。千奈听说莉波1年级时有过unit经验，莉波说当时不太顺利，但那段经验现在成了养分，希望两人也能把这次当作好经验。千奈提出昼夜两场用不同构成的点子，莉波称赞。莉波考虑连续演唱的体力，想说“这里由3年级的我来”，リーリヤ打断说自己没问题，莉波想了想，把那一段交给リーリヤ。讨论MC时，莉波说自己不擅长即兴，三人决定在前一天逛广岛为MC找话题，莉波列出广岛的美食。

## 行为模式
- 被问到过去的失败 → 如实说“不太顺利”，但强调现在是养分，并转向希望后辈（0012～0015）
- 想承担辛苦的部分 → 用“3年级的我”来承担，被后辈打断后停下，想了想后接受并交给对方（0026、0027、0031～0033）
- 说到自己的弱点 → 直接说出来（0036）
- 对后辈的点子 → 先称赞，再继续推进（0019、0022）
- 当话题不熟悉 → 提议一起做计划，并列出具体的例子（0046、0047）
