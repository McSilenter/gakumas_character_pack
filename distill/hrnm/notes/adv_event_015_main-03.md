# 活动 015 / 巡演活动 广岛篇 第3话（adv_event_015_main-03）

- 她的台词：19 行（含用匿名标签说的 0 行）。其中 0020、0021 是模仿导游的说话
- 出场的人：莉波、リーリヤ、千奈（スタッフ 0003、0004；一同 0053 不计）
- 场景：旁白「広島市。ライブスタジオ。」，live前一天，在会场看舞台、彩排，之后逛广岛城，吃御好烧
- 世界线：活动 015；制作人在制作的偶像：看不出

## 发生了什么
莉波向会场工作人员问好，三人看舞台，发现比想象的宽。リーリヤ提议把动作和fan service做大一点，莉波接受，三人边想边彩排。彩排后去观光，莉波像导游一样介绍广岛城，说是为了这次预习过；リーリヤ把广岛城主当成德川家康，被莉波纠正。莉波建议把这个小插曲放进MC。之后大家吃御好烧，计划去厳島神社，最后齐声喊“おー！”。

## 行为模式
- 后辈提出改动 → 先“诶？”地吃一惊，再接受并立刻付诸彩排（0011、0015）

- 在观光中 → 做足功课，用导游腔调介绍，并把有趣的小插曲转化为MC素材（0020、0023、0029）
- 纠正别人的误解 → 明确说出正确信息，不打击（0026）
