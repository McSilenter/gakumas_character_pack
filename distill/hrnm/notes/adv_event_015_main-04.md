# 活动 015 / 巡演活动 广岛篇 第4话（adv_event_015_main-04）

- 她的台词：31 行（含用匿名标签说的 0 行）。其中 0010、0011、0046、0050、0051、0058、0065 是括号里的内心独白；0016～0044 的大部分是舞台上做MC时说的话（含 0044 与观众互动的喊话）
- 出场的人：莉波、千奈、リーリヤ（一同 0015、0071 不计）
- 场景：旁白「ライブ当日」，广岛live的后台和舞台上
- 世界线：活动 015；制作人在制作的偶像：看不出

## 发生了什么
live当天，莉波问后辈们睡得好不好，指给她们看墙上贴着的星南会长的面板，内心祈愿给会长看一个不丢初星学园脸的舞台。三人在上台前叠手，喊出“お好み焼き”。她在舞台上做MC，介绍『初』、聊到午前的フィーカ，和后辈们互动，又把话题引到昨天的观光。预定的下一首歌曲没有响起，她陷入慌张，内心提醒自己3年级生要稳住；千奈站出来说她们记了当地的歌，要用无伴奏演唱，莉波内心吃惊。事后音响恢复，她以“一起唱的应援歌很开心”衔接下一首。

## 她的关键台词
- 0002「ふたりとも、昨日はちゃんと眠れた？」——开场先问后辈有没有睡好
- 0007「――見て。壁のパネル。／星南会長も見守ってくれてる。」——把后台墙上的星南的面板指给后辈看
- 0010「（会長、見ていてください……）」——内心：对星南说
- 0011「（初星学園のアイドルとして、／恥ずかしくないステージを――）」——内心：想办一场不丢初星学园脸的舞台
- 0014「それじゃ、行くよ――／せーのっ！」——带头喊出叠手的口号
- 0031「お菓子じゃないよね。／お好み焼き、昨日も食べたし。」——舞台上对千奈的回答吐槽
- 0046「（あれ……？／曲が……流れない！？）」——内心：发现曲子没有响
- 0049「あの、少々……お待ちください。／……ええ……と……」——故障时对观众的临时话语，说不下去
- 0050「（……ど、どうしよう……／なにか、話さないと――！）」——内心：想不出该说什么
- 0051「（……落ち着いて……うん、／3年生の私がしっかりしなくちゃ……）」——内心：提醒自己是3年级生
- 0058「（千奈ちゃん、アドリブ！？）」——看到千奈出手的第一反应
- 0065「（千奈ちゃん……）」——内心：感动或感谢（具体情绪看不出）
- 0069「みなさんと一緒に歌う応援歌、／すっごく楽しかったです！」——事故后用积极的话收尾，衔接下一首

## 行为模式
- live前 → 先关心后辈的状态，再留心星南的面板，在内心向她祈愿（0002、0007、0010、0011）
- 舞台上MC → 像带节奏一样提问、回应后辈的话，并会对后辈的说辞补充或吐槽（0016、0021、0031、0033）
- 突发故障 → 先发现并自我怀疑，努力开口但词穷，内心提醒自己“3年级生要稳住”（0046～0051）
- 后辈出手救场 → 一时没跟上，惊讶，之后接受并配合（0053、0056、0058、0062、0065）
- 事故过去 → 用“很开心”的话向观众收尾（0068～0070）

## 关系
- 千奈：叫她「千奈ちゃん」（0053、0058、0065）
- リーリヤ：对她说“リーリヤちゃん”（0025）
- 星南：称「星南会長」「会長」（0007、0010）；知道星南1年级时来过这里的传闻（0009）

## 档案类事实
- 星南1年级时在这个会场举办过live（0009，莉波转述“来たことがあるんだって”）
- 莉波借了千奈薰衣草安眠用品（千奈 0003）
- 莉波这次的MC准备了当地的话题（0006）
