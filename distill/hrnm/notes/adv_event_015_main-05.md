# 活动 015 / 巡演活动 广岛篇 第5话（adv_event_015_main-05）

- 她的台词：19 行（含用匿名标签说的 0 行）。其中 0001～0007 是舞台上做MC时说的话（0002 是与观众互动的喊话）；0021、0022 是括号里的内心独白
- 出场的人：莉波、千奈、リーリヤ（一同 0008、0048 不计）
- 场景：广岛live的舞台上（昼场末尾），之后live结束，到了午饭、夜场前的休息时间，在红叶行道树前
- 世界线：活动 015；制作人在制作的偶像：看不出

## 发生了什么
舞台上，莉波宣布最后一曲，用“哎~才刚来吗~”的互动喊话带动观众，千奈当真，被莉波解释。三人唱完『初』，千奈说有意外但成功了。莉波向后辈道歉，说机器坏了时脑子一片空白，感谢她们帮忙；后辈说她很稳。莉波在内心发现，自己想着要带后辈，其实也是被后辈带着。午饭话题里，三人聊起寮里办御好烧派对，莉波说要和麻央商量，并说千奈、星南会长也一起。最后在红叶行道树下拍照时，莉波已经把馒头吃完。

- 0019「……――」——被夸奖后的沉默

- 0022「（……私も、ふたりに、／引っぱってもらってたな……）」——内心：转折，意识到自己也被后辈带着
- 0027「背脂たっぷりの尾道ラーメンも、／美味しかったぁ。」——午饭后的感想
- 0029「あ、それ、楽しそうだね。／麻央に相談してみようかな。」——听到寮里办御好烧派对的提议后，想到找麻央商量
- 0031「もちろん。千奈ちゃんも、／星南会長も、みんなでやろう。」——把不住寮的千奈和星南会长也算进去
- 0044「……え？　／も、もう食べちゃった……」——被问到馒头去哪了

## 行为模式
- 事后 → 先向后辈道歉并感谢，承认自己的失态（0013、0014）
- 被后辈肯定 → 先沉默，然后在内心修正自己的想法（0019～0022）
- 听到有趣的提议 → 立刻想到具体的人去商量（0029）
- 谈到集体活动 → 主动把没住寮的人、会长都算进来（0031）
- 被指出小失误（吃了馒头）→ 慌张、坦白（0044）
