# 活动 017 / 第1话（adv_event_017_main-01）

- 她的台词：25 行（含用匿名标签说的 0 行）。0002～0013 是纪录片式采访场面里她回答问题的话（提问写在旁白里，0013 没说完）
- 出场的人：莉波、星南、麻央、燕（ダンストレーナー 0015）
- 场景：开头（0001～0013）是旁白加采访回答；之后在舞蹈课（レッスン）的场所，麻央在练习，莉波、燕在旁，星南出场（0029）后，莉波提出请大家协助拍摄3年级的PV
- 世界线：活动 017；制作人在制作的偶像：看不出

## 发生了什么
开头是采访式的片段，莉波回答早餐吃得多、主食是米饭（老家寄米）、爱吃乌冬，对“レッスン是否严格”回答是现在能全力投入很开心，最后被问到“对你来说偶像是什么”时话被打断。接着她看麻央练习，与燕聊起夏天的『H.I.F』，被燕说是“竞争对手之一”，然后向大家提出请求：广报部的后辈想做以3年级的“日常”为主题的PV，由她拿摄影机拍。麻央、星南同意，燕先说“偶像没有日常”，然后因是莉波的请求而答应。星南说自己的日常可能不有趣，莉波说她知道会长偶尔露出的淘气一面，想拍出来。

- 0006「実家からお米が送られてくるので、／主食はパンよりもご飯です。」——采访：老家寄米，主食是米饭

- 0022「……う、うんっ！」——被燕说是“竞争对手之一”时的反应
- 0024「ちょっと、みんなに協力して／ほしいことがあるんだ。」——向大家提出请求
- 0034「スタッフさんのこだわりで、／日常を撮るには、普段から一緒にいる／友達のほうがいいって。」——说明为什么由她来拍

## 行为模式
- 被采访 → 具体地讲自己的日常（米饭、乌冬），再谈现在能全力练习很开心（0003～0010）
- 被燕称为“竞争对手”→ 先愣一下，再用“う、うんっ！”回应（0021、0022）
- 提出请求 → 先叫对方名字，再说“有想让大家协助的事”，并详细说明来龙去脉和报酬（0023、0024、0026、0028、0031、0034）
- 想把人好的一面拍出来 → 用“我知道”开头，具体说出对方的例子（0053、0055、0057）

## 档案类事实
- 莉波早餐吃得多，是因为每天做激烈运动，不吃够热量会累（0003）
- 莉波做饭看想吃的东西和手头的材料（0005）
- 老家寄米来，主食吃米饭多于面包（0006）
- 莉波爱吃速食乌冬，常吃（0007）
- 莉波是3年级，PV是由广报部的后辈拜托（0026、0028）
- PV有少许报酬（ギャラ）并借摄影机（0031）
