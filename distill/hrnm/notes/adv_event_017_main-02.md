# 活动 017 / 第2话（adv_event_017_main-02）

- 她的台词：30 行（含用匿名标签说的 0 行）；其中 0004、0005、0009、0015、0016、0031、0032、0037、0055、0056、0059、0060、0065、0066、0067 是拍摄 PV 时的旁白式解说（对着镜头的解说词），0054 是无字的沉默
- 出场的人：莉波、麻央、星南、燕、後輩、手毬、咲季
- 场景：清晨的初星学园；她在拍摄记录偶像「日常」的 PV，依次拍麻央、星南（生徒会室）、燕。
- 世界线：活动 017；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
莉波在拍摄主题为偶像「日常」的 PV，用旁白介绍麻央的早晨。麻央离开去帮後輩搬球后，她继续拍摄星南的晨间工作并采访，燕也进入画面。她给每个人加上简短的人物介绍，并说本周末要跟拍大家休息日的样子。剧情经过参照 ttmr、hski 笔记。

## 她的关键台词
- 0004「――有村麻央の朝は早い。」——用旁白口吻开始拍摄，是她这一篇的拍摄方式。
- 0009「ブラックコーヒーには、／お砂糖とミルクをたっぷり入れるのが、／寮長のこだわりだ。」——在麻央说「ブラックコーヒー」的话后，接着用旁白指出实际会加糖和牛奶。
- 0011「ふふ、ごめんね。でも、／普段の麻央を見せてほしいから、／あんまり、取り繕わないで。」——道歉的同时说明自己拍摄想要「普段」的样子。
- 0035「ふふ、朝は会長も、／少しは気を緩めてるかなーって。」——半开玩笑地说选早晨拍是想拍会长松懈的样子。
- 0041「初星学園の生徒会って、普段は／どんなお仕事をしているんですか？」——以采访者的口吻向会长提问。
- 0050「星南会長は、初星学園のことが、／本当に好きなんですね。」——听完会长的话后，总结出她对学园的感情。
- 0060「普段は厳しいけど、／本当は優しくて、後輩思いで――」——介绍燕时，说她严格的外表下是温柔、为后辈着想。
- 0064「これがいいんです。テーマは、／アイドルの『日常』なので。」——会长觉得单调时，她坚持这样拍，理由是主题是「日常」。
- 0065「今週末は休日のみんなに／密着させてもらいます。」——预告下一步的拍摄计划。
- 0066「ステージでは見られない、／星南会長や燕ちゃんの素顔、」——说出这次想拍的东西：舞台上看不到的素顔。

## 行为模式
- 拍摄时 → 用「――有村麻央の朝は早い。」「アイドル、有村麻央は――」这样的旁白句式介绍对方（0004、0031、0037、0055）
- 被拍摄对象表现得像在摆姿势 → 笑着道歉，但要求「取り繕わないで」（0011）
- 星南或其他人对拍摄提出异议 → 讲出主题理由后坚持原方案（0063、0064）
- 对前辈（星南）用敬语和「会長」，对同级的燕叫「燕ちゃん」（0033、0058）

## 关系
- 麻央：叫「麻央」，旁白里说她是「寮長」（0005）、「初星の王子様」（0032）；会开她的玩笑（0009），被抗议后道歉（0011）。
- 星南：叫「会長」「星南会長」，敬语（0033、0040、0050）；旁白里介绍她是「初星の『一番星』」（0037）。
- 燕：叫「燕ちゃん」，对她说「おはよう」（0058）；介绍她是「副会長」（0059）。

## 档案类事实
- 在为一支以偶像「日常」为主题的 PV 做拍摄（0057、0064）。
- 本周末打算跟拍大家的休息日（0065）。
