# 活动 017 / 第3话（adv_event_017_main-03）

- 她的台词：9 行（含用匿名标签说的 0 行）；0001 是旁白式的拍摄标题
- 出场的人：星南、麻央、莉波、ことね、燕
- 场景：休息日；偶像日常『休日編』的拍摄，四人逛偶像周边店，午饭在ことね打工的汉堡店。
- 世界线：活动 017；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
莉波在拍摄『休日編』，感谢星南、麻央、燕协助。逛完周边店后问午饭去哪，星南说想去「ことねバーガー」，莉波补充说就是ことね打工的汉堡店。到店后她开心地吃汉堡，看到星南沾到酱汁，说从没见过会长这样松懈，并希望大家能知道会长的这一面。最后星南向她道谢。

## 她的关键台词
- 0001「――アイドルの日常『休日編』。」——用旁白口吻拍摄的标题。
- 0002「みんな、今日は／協力してくれてありがとう。」——开头先向三人道谢。
- 0012「星南会長、本当にアイドルが／大好きなんですね。」——看到星南买了很多周边后说出感想。
- 0018「……そうなんだ。ところで、／お昼はどこで食べますか？」——燕说收集了所有种类后，她带过去并转到午饭。
- 0028「ことねちゃんがアルバイトしてる、／ハンバーガーのお店、ですね。」——听星南说「ことねバーガー」后，补充出实际是哪家店。
- 0048「ん～、おいしい～。／久し振りに食べたよぉ。」——吃汉堡时开心的反应，说好久没吃到。
- 0053「ふふ、油断した会長、／初めて見ました。」——看到星南沾到酱汁时说出的话。
- 0056「普段の会長のこんな魅力も、／みんなに知ってもらえたらいいな。」——希望大家也能看到会长的这一面，也是拍摄的目的。

## 行为模式
- 听到不明白的店名 → 想办法把它对上实际店面，再确认（0023、0028）
- 燕说自己收集了全种类 → 先接一句「……そうなんだ」，马上转话题（0018）
- 会长失态 → 笑着说「初めて見ました」，并想把这一面拍给大家（0053、0056）

## 关系
- 星南：叫「星南会長」，用敬语（0012、0053）。
- 麻央：叫「麻央」；有话说时直接问午饭（0018）。
- 燕：此篇她没有直接称呼燕；燕说收集了全种类，她回「……そうなんだ」（0017、0018）。
- ことね：叫「ことねちゃん」（0028）。
