# 活动 017 / 第4话（adv_event_017_main-04）

- 她的台词：15 行（含用匿名标签说的 0 行）
- 出场的人：莉波、星南、麻央、燕
- 场景：休息日，天川市的游乐园；三年级四人玩旋转木马、过山车，傍晚是两人组的僵尸主题解谜游戏，她与燕一组。
- 世界线：活动 017；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
莉波带三年级的大家来游乐园。她提议过山车晚点坐，先坐旋转木马，在木马上被麻央扮演的王子护送，她配合着回话。过山车后说下落时抓了星南的手觉得害羞。解谜游戏要两人组队，她用猜拳决定分组，她与燕一组、麻央与星南一组，约好稍后在舞台前集合。

## 她的关键台词
- 0001「そんなわけでー。3年生のみんなで、／天川市の遊園地に来ましたっ！」——拍摄式的开场白。
- 0006「ええっと、ジェットコースターは、／後にしたほうが……」——听到先去过山车时婉转地反对。
- 0010「麻央、カッコイイよ！」——看到麻央选了白马，直接称赞。
- 0012「はい、王子様。」——配合麻央扮演，回答「王子様」。
- 0016「どの馬もスピードは変わらないよー……」——对星南和燕要比速度的吐槽。
- 0022「落ちるとき、星南会長の手、／握っちゃいました……恥ずかしい。」——坐完过山车后的坦白。
- 0026「なんだか、時間、／あっというまに過ぎちゃうね。」——说起玩的时间过得快。
- 0033「それじゃ、グーパーで／チームを決めようか。」——提议用猜拳分组。
- 0037「それじゃ、あとでステージ前で／待ち合わせね。」——约定集合地点。

## 行为模式
- 过山车被提到 → 不直接拒绝，说「後にしたほうが」（0006）
- 麻央做王子扮演 → 夸「カッコイイ」，并陪着叫「王子様」（0010、0012）
- 星南和燕要比速度 → 小声吐槽每匹马速度都一样（0016）
- 玩完过山车 → 老实说抓了星南的手，觉得害羞（0022）
- 需要分组 → 她来提议猜拳并宣布结果（0033、0034）

## 关系
- 麻央：叫「麻央」；在木马上回答她的「莉波姫」时叫她「王子様」（0012）。
- 星南：叫「星南会長」（0022、0034）。
- 燕：叫「燕ちゃん」（0034、0039）；与燕同组，催她时说「待って、燕ちゃん～」（0039）。

## 档案类事实
- 木马「ひさしぶり」，很久没坐了（0008）。
- 不太想先坐过山车（0006）；过山车下落时抓了星南的手（0022）。
