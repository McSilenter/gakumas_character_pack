# 活动 017 / 第5话（adv_event_017_main-05）

- 她的台词：38 行（含用匿名标签说的 0 行）；0001 是内心想法，0066～0070 是回答「あなたにとって、アイドルとは？」的采访式独白
- 出场的人：莉波、燕、麻央、星南、？？？、ナレーション
- 场景：休息日，天川市的游乐园；解谜游戏中的休息处，随后是逃脱成功与去看舞台上的演出。
- 世界线：活动 017；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
莉波与燕在解谜游戏的途中休息，她对燕说，这一周拍大家的『日常』让她更喜欢大家和偶像，并说出最近失去自信：星南说她是对手，自己却原地踏步，担心喜欢偶像的心情比别人弱；现在明白那是想多了。随后麻央和星南被僵尸追着跑回来，大家逃脱成功。接着去看前辈的演出，她要拍应援的样子，却被麻央接过摄像机，说要拍她的日常，接下来一周大家一起拍她。最后她回答偶像对她是什么。

## 她的关键台词
- 0001「（……麻央が会長とあんなふうに／話してるの、初めて見た……かも）」——内心：看到麻央和会长的相处感到新鲜。
- 0016「みんなのこと、アイドルのこと、／もっと好きになれたよ。」——说这一周的拍摄让自己更喜欢大家和偶像。
- 0018「……最近ね、ちょっと、／自信なくしてたんだ。」——向燕坦白最近失去自信。
- 0019「星南会長が、私のこと、／ライバルって言ってくれたのに。」——说失去自信的背景。
- 0022「アイドルを好きな気持ちが／弱いのかなって――」——说自己担心喜欢偶像的心情比别人弱。
- 0025「でも、今はね。／そんなのは思い過ごしだった。」——说现在明白那是想多了。
- 0027「ステージの上じゃなくても、／キラキラ輝くみんなが好き。」——说明她喜欢的是不在舞台上也闪闪发光的大家。
- 0031「私たちは、日常もステージも、／ずっとアイドルなんだ。」——得出的结论。
- 0033「うん。そうだね。／あたり前だったんだ。」——被燕说是理所当然后接受。
- 0042「やっっったぁーーーーっ！／脱出成功だね！」——逃脱成功时的欢呼。
- 0060「……ええっ！？　／わ、私はいいよー。」——被说要拍她时推辞。
- 0067「ステージの上で、キラキラ輝く星。」——回答偶像是什么的前半。
- 0070「そんな――『憧れ』です。」——回答的结尾。

## 行为模式
- 心里有事时 → 先用「あ、ううん……／ちょっと、あっちで休もうか。」把话题带开（0003）
- 对燕说心里话 → 先说这一周的收获，再坦白不安，再说想通了的结论（0015～0033）
- 被燕说是理所当然 → 接受，说「あたり前だったんだ」（0032、0033）
- 麻央和星南被追回来 → 招呼她们到安全地带，成功后欢呼并向大家道谢（0041、0042、0047）
- 要拍别人时被反过来要拍自己 → 推辞「私はいいよー」，被围堵后发出「……～っ！」（0060、0064）

## 关系
- 燕：叫「燕ちゃん」，说出自己的不安，并且燕在听（0003、0018～0024）；燕被她称作星南的「幼馴染み」（0010）。
- 麻央：叫「麻央」，说麻央在前进（0020）；被麻央接过摄像机（0057～0063）。
- 星南：叫「星南会長」，说星南说过她是对手（0019）；称星南也在闪闪发光（0028）。

## 档案类事实
- 这一周在拍大家的『日常』（0015）。
- 最近失去自信，觉得自己原地踏步，燕和麻央在前进（0018～0020）。
- 喜欢在舞台上闪闪发光的偶像，也喜欢不在舞台上也闪闪发光的大家（0026、0027）。
- 对她来说，偶像是「ステージの上で、キラキラ輝く星」，也是日常里追梦的身影，即「憧れ」（0067～0070）。
- 知道去年毕业于初星、隶属『100Pro』的组合（0050）。
