# 活动 019 / 巡演活动 名古屋篇 第1话（adv_event_019_main-01）

- 她的台词：6 行（含用匿名标签说的 0 行）
- 出场的人：咲季、星南、莉波、燕、ことね、手毬、一同
- 场景：学园内，星南把咲季叫来，莉波和燕也在；之后咲季又把ことね和手毬叫来。
- 世界线：活动 019；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
莉波向咲季说明三年级带队演出（引率プログラム）的名古屋公演缺了领队，不想取消演出，在找代理领队。咲季自己领会是在找她，爽快接下，莉波高兴道谢，说就觉得咲季会答应。咲季被燕说咲季像某人时不明所以，莉波让她别在意。咲季问成员的事，莉波说因为各种状况暂时是白纸。剧情经过参照 ttmr、hski 笔记。

## 她的关键台词
- 0010「咲季ちゃんは、／3年生の引率プログラムって知ってる？」——先问咲季是否知道这个计划。
- 0015「楽しみにしてくれているファンのことも／考えると、中止にはしたくなくて……」——说明不想取消的原因。
- 0016「そこで、代理のリーダーを／探しているの。」——说明找代理领队。
- 0027「ありがとう！　咲季ちゃんなら、／きっと引き受けてくれると思ってたよ。」——咲季接下后道谢，并说早就觉得她会答应。
- 0032「ああ、ごめんね。／気にしないで。」——咲季追问是在说什么时敷衍带过。
- 0034「ううん。事情が重なって／いったん白紙になっちゃったから……」——回答咲季问的成员。

## 行为模式
- 向后辈说明请求 → 先问对方知不知道，再说困难，最后说在找谁（0010、0015、0016）
- 同伴说出会让对方疑惑的话 → 道歉并让对方别在意，不解释（0032）
- 后辈接受 → 先道谢，再说自己早料到（0027）

## 关系
- 咲季：叫「咲季ちゃん」；咲季叫她「姫崎先輩」（0003）。
- 星南、燕：一起向咲季说明；燕对她说「会長」不在她的对话里，莉波本篇没直接叫两人（但咲季叫燕「雨夜先輩」，0003）。

## 档案类事实
- 重视期待着的粉丝，不想取消演出（0015）。
- 名古屋公演的成员当前是白纸（0034）。

## 不确定
