# 活动 021 / main-01 第1话（adv_event_021_main-01）

- 她的台词：12 行（含用匿名标签说的 0 行）
- 出场的人：燕（25）、星南（24）、莉波（12）
- 场景：生徒会室，夜晚已晚；之前（0001～0011）有一段星星的对话，从上下文看像是燕居眠时的梦（见不确定）
- 世界线：活动 021；制作人在制作的偶像：看不出

## 发生了什么
燕在生徒会室醒来，莉波、星南都在。燕和星南都因为レッスン、偶像工作和生徒会业务忙到很晚，莉波担心两人休息不够，一再询问周末是否休息。两人互相要对方休息、自己代对方干活，莉波于是宣布两人暂时禁止生徒会业务，由她来处理。星南和燕起初反对，被她说“大变的时候请依靠我们”后勉强同意。

## 她的关键台词
- 0017「あ、燕ちゃん。起きた？」——最先招呼醒来的燕，称呼「燕ちゃん」
- 0025「うーん、たしかに……！／寝不足ですか？」——附和燕，也看出星南脸色不好
- 0031「……というか、おふたりとも／土日はお休み取れてますか……？」——追问两人的休息情况
- 0035「だったら、ちゃんと休んで、／それに備えないとダメなのでは……？」——指出该休息才能应付周末工作
- 0043「――燕ちゃん、星南会長。」——两人争着让对方休息时出声打断
- 0046「ふたりとも、ちゃんと休んで。／生徒会業務は、しばらく禁止です！」——明确下令，禁止生徒会业务
- 0049「ふたりがいなくても大丈夫です！／私が何とかしますから！」——主动承担
- 0055「大変な時は、私たちを頼ってください。」——拿“依靠我们”说服两人
- 0060「うん。／なにかあったら、ちゃんと頼るから。」——对燕“有事马上说”的回答
- 0061「ゆっくり休んでね、ふたりとも。」——收尾

## 行为模式
- 两人互相逞强 → 先温和地提问、列出事实，之后在争执中果断打断下令（0031、0035、0043、0046）
- 被反驳“没你们不行” → 用“我来想办法”和“请依靠我们”回应（0049、0054、0055）
- 对方答应 → 以“有事会依靠你们”回答，语气转柔（0060、0061）

## 关系
- 燕：称「燕ちゃん」，燕称她「姫崎」（0045）。
- 星南：称「星南会長」（0043）；星南称她「莉波」（0047）。
- 在这篇里她站在照顾两个人的位置，并承诺到时会依靠对方（0060）。

## 档案类事实
- 是生徒会成员，能接手燕和星南的业务（0046、0049）
