# 活动 025 / main-01 第1话（adv_event_025_main-01）

- 她的台词：10 行（含用匿名标签说的 0 行）：0001、0002、0009、0031、0032、0033、0035、0036、0057、0058（不含一同 0051）
- 出场的人：燕、千奈、莉波、佑芽、星南、美鈴
- 场景：学生会的会议室，前辈们毕业前的交接期（0033「引き継ぎのタイミング」）

## 发生了什么
莉波宣布召开第1次学生会工作进度确认会议，会场一片沉默。星南和燕斗嘴，莉波劝两人不要吵架。燕检查文件，指出佑芽忘了回收、美鈴的预算资料里写了“午睡经费”。莉波替美鈴解释，是自己先拜托她整理别的资料，并说要在交接时好好整理，燕说以后要叫上自己帮忙，莉波道谢。燕担心后辈们，问莉波是不是真的可以毕业，莉波说「なるようになるよ！」。剧情经过参照 hmsz、hume 笔记。

## 她的关键台词
- 0002「第1回、生徒会作業進捗確認会議を、／開催します……」——主持会议，语气小心翼翼
- 0009「ストップストップ。／ふたりとも、喧嘩はダメだよ？」——用「ストップ」劝星南和燕
- 0031「燕ちゃん！　ごめんなさい。」——燕发现“午睡经费”时先道歉
- 0032「美鈴ちゃんには先に、／別の資料整理をお願いしていたの。」——说明美鈴资料不完整是因为自己拜托了别的事
- 0033「引き継ぎのタイミングで／整理しなきゃって思っていて……！」——解释自己的原本打算
- 0035「ありがとう……！　助かるよ。」——燕提出帮忙后的道谢
- 0036「美鈴ちゃんも忙しいのに、／会計の資料まで読んでくれてたんだね。」——肯定美鈴额外读了资料
- 0057「も、もぅ……心配性だなぁ。／千奈ちゃんたちなら、きっと…………」——对燕的担心，安抚后辈们
- 0058「なるようになるよ！」——被燕追问是否能毕业时的回答

## 行为模式
- 两个人起冲突 → 说「ストップストップ」，再劝「喧嘩はダメ」（0009）
- 后辈被指责 → 主动揽下责任，解释清楚事情经过（0031～0033）
- 被帮忙 → 道谢，并立刻夸后辈（0035、0036）
- 对方过度担心 → 说对方心配性，用「なるようになる」的乐观回应（0057、0058）
