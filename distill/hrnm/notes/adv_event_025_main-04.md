# 活动 025 / main-04 第4话（adv_event_025_main-04）

- 她的台词：9 行（含用匿名标签说的 0 行）：0004、0015、0038、0048、0054、0056、0058、0067、0074（不含一同 0030、0034、0035、0066、0071）
- 出场的人：千奈、佑芽、美鈴、星南、莉波、燕
- 场景：休息日的派对会场，后辈们准备的章鱼烧派对（0044）
- 世界线：活动 025；制作人在制作的偶像：看不出

## 发生了什么
后辈们邀请星南、莉波、燕参加慰劳派对。莉波说自从拿到企划书起就一直期待。后辈们汇报业务改善，莉波赞同那款日程APP，说组合活动的学生也会受益。千奈宣布这是章鱼烧派对，莉波很惊讶，看到馅料里有明太子和年糕很开心，被佑芽、千奈说中喜好，笑着回忆以前一起吃过章鱼烧。最后她劝吵起来的星南和燕，叫燕评价后辈们，燕说「よくやったな」，莉波催着开始烤。剧情经过参照 hmsz、hume 笔记。

## 她的关键台词
- 0004「パーティーの企画書をもらった／ときから、今日を楽しみにしてたよ。」——表达对派对的期待
- 0015「うんうん！　ユニット活動している子も／絶対助かると思う！」——赞同日程APP，想到正在做组合活动的学生
- 0038「たこ焼きパーティー！？」——听到派对内容时的惊讶
- 0048「わぁ～、早く食べたいなぁ。」——看到馅料后期待
- 0054「まぁまぁ……ふたりとも……／あ！　明太子もお餅もある～！」——劝星南和燕不要吵，随即注意到喜欢的馅料
- 0056「え？　なんでしってるのかな……？」——佑芽说出她喜欢的口味时的惊讶
- 0058「あぁ！　そうだったね。／あのときもたこ焼き、食べたよね。」——想起以前告诉千奈的时候也吃过章鱼烧
- 0067「燕ちゃん。」——叫燕，催她评价后辈
- 0074「そろそろ焼こうよ！　ねっ♡」——等不及要开始烤

## 行为模式
- 看到后辈们的成果 → 先高兴，再说出会带来什么好处（0004、0015）
- 星南和燕为一件事争起来 → 用「まぁまぁ」打断，并把话题引到眼前的馅料（0054）
- 被人说中喜好 → 先吃惊，等对方提醒才想起来（0056～0058）
- 想让别人得到肯定 → 叫燕的名字，让她评价后辈（0067）
