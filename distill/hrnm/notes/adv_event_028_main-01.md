# 活动 028 / main-01 第1话（adv_event_028_main-01）

- 她的台词：17 行（含用匿名标签说的 0 行）；行号 0003、0004、0005、0006、0007、0008、0009、0011、0018、0025、0038、0039、0041、0042、0044、0047、0050。其中 0003、0008、0009 是心里的独白（括号内）。
- 出场的人：燕、莉波、ことね、清夏、リーリヤ、担任、一同
- 场景：初星学園，文化祭前。放学前拿到进路希望调查票，之后与燕一起以生徒会实行委员身份巡视各班。
- 世界线：活动 028；制作人在制作的偶像：看不出

## 发生了什么
担任发下进路希望调查票，莉波在心里回顾9月『100プロ所属審査』的规则：合格则本所属，没过也可以仮所属继续上课，但能否本所属是另一回事。之后她和燕巡视1年级的出し物，和ことね、清夏、リーリヤ聊天，得知咲季和月村由麻央指导演剧和短剧。两人回忆1年级时的恐怖屋，燕说这可能是最后一次普通学生的活动，莉波附和，并答应燕要办出最棒的文化祭。

## 她的关键台词
- 0007「受からなかったとしても、／100プロに仮所属して／レッスンは続けられる。けど……」——独白里说到没通过也能继续，但话转向「けど……」，流露不安。
- 0008「（本所属できるかどうかは、別の話）」——心里清楚仮所属不等于本所属。
- 0009「（私の未来を決める、大事な――）」——拿着进路调查票时的想法，话没说完。
- 0011「今年は例年よりも、／にぎやかな文化祭になりそうだね。」——对文化祭的期待。
- 0018「ミニライブに寸劇とコントも楽しめる、／初星学園ならではの定番だよね。」——熟悉学园的文化祭传统。
- 0039「文化祭前の雰囲気って、／なんだかうきうきするよね。」——喜欢文化祭前的气氛。
- 0044「燕ちゃんと麻央が大喧嘩して、／大変だったけどね。」——回忆1年级恐怖屋时，委婉地提起燕与麻央吵架。
- 0047「……そうだね。」——燕说这可能是最后的普通学生活动时的回应，语气低沉。
- 0050「――うん。」——应下燕的号召，要办出「みんなの思い出に残る」文化祭。

## 行为模式
- 一个人拿着与未来有关的文件 → 在心里把规则逐条梳理，最后落在「別の話」的担忧上（0004～0009）。
- 与后辈交谈 → 先夸具体的东西（舞台装饰），用温和的疑问句式（0025）。
- 话题涉及快要结束的学生生活 → 回应变短，只说「そうだね」「うん」（0047、0050）。
- 回忆往事 → 记得细节（恐怖屋、お化けの仮装），并带着温和的吐槽（0041、0042、0044）。

## 关系
- 燕：称「燕ちゃん」（0044）；燕叫她「姫崎」，一起担任生徒会实行委员，并肩巡视（0045、0049）。
- 麻央：直呼「麻央」，1年级时曾与燕大喧嘩（0044）。

## 档案类事实
- 初星学園的学生可以在9月参加『100プロ所属審査』，合格则本所属；机会一年两次，9月和1月（0004～0006）。
- 没通过也可以仮所属并继续上课（0007）。
- 1年级时的文化祭是恐怖屋，大家扮成お化け（0041、0042）。
- 与燕一起巡视、负责文化祭的实行工作（0011、0049；燕 0013 提到「実行委員一同」）。
