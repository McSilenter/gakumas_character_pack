# 活动 028 / main-02 第2话（adv_event_028_main-02）

- 她的台词：21 行（含用匿名标签说的 0 行）；行号 0006、0008、0011、0013、0015、0018、0019、0022、0026、0028、0031、0032、0033、0034、0038、0039、0040、0041、0042、0045、0046。其中 0039～0042、0045、0046 是心里的独白。
- 出场的人：莉波、燕、麻央、生徒A、1年生A、1年生B
- 场景：初星学園，文化祭准备中。3年1组教室，之后是放学后的走廊／教室一带（1年生在找レッスン室）。
- 世界线：活动 028；制作人在制作的偶像：看不出

## 发生了什么
莉波和燕巡视3年1组，看到燕和麻央玩新选组的扮演，她出声提醒认真点。她向麻央道歉，把执事喫茶交给了她。她问麻央的进路，麻央说要考『100プロ所属審査』。看着比1年级少的教室，莉波说有点寂寞，讲了曾经的同组组长转去普通科、想当演出工作人员的事。随后她独自想到每天的自主练习、堆积的工作和进路调查票，看到1年生因为练习室被占用而离开，她一时说不出话。

## 她的关键台词
- 0006「ふたりとも、真面目にやるよー。」——燕和麻央玩扮演时出言提醒。
- 0008「ごめんね、執事喫茶のほう、／麻央に任せきりで。」——对麻央抱歉，不想把事全推给别人。
- 0019「……そうだ。麻央は、／進路希望、どうするの？」——她主动问麻央的进路，对自己的进路也在意。
- 0028「……うん。1年生の教室と比べると、／少し寂しいなって。」——坦率说出3年生教室的寂寥。
- 0031「1年生の頃に同じユニットの／リーダーだった子も、」——说起已离开偶像科的前同组组长。
- 0034「演出のスタッフになって、／アイドルを支えるんだって。」——转述对方的选择，对她来说是被留下的人讲述的事。
- 0039「（……毎日の自主レッスン）」——开始独白，想到每天坚持的自主练习。
- 0040「（どうして、続けてるんだろう。／ライブの予定もないのに……）」——对自己继续练习的理由感到疑惑。
- 0042「（進路の調査票も……）」——进路问题压在心里。

## 行为模式
- 朋友玩闹偏离正事 → 用「ふたりとも」轻声提醒（0006）。
- 被问起和别人的进路相关的话题 → 先问对方，再沉默（0019、0022）。
- 聊到离开的同学 → 先说对方的选择，再不自觉地以「アイドルは好きだから」转述对方的心情（0031～0034）。
- 独处时 → 在心里一件件数手上的事，没有给出答案（0039～0042、0046）。

## 关系
- 麻央：直呼「麻央」，把执事喫茶交给她，对她在指导1年级一事点头（0008、0015、0018）。
- 燕：燕叫她「姫崎」，并问她「どうした」（0027）；这一篇里她没有称呼燕。
- 前同组组长（没有名字）：1年级时同一个组合的队长，现转到普通科（0031、0032）。

## 档案类事实
- 1年生时所在组合的队长转入普通科，准备进专门学校，将成为演出工作人员（0031～0034）。
- 她每天做自主练习，但最近没有ライブ的预定（0039、0040）。
- 积压了工作，要在明天前汇总文化祭的要望书；进路调查票还没交（0041、0042）。
- 她要给麻央演技指导，将穿男装演执事（0013、0014 麻央）。
