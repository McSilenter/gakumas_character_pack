# 活动 028 / main-03 第3话（adv_event_028_main-03）

- 她的台词：32 行（含用匿名标签说的 0 行）；行号 0015、0018、0023、0028、0031、0033、0037、0039、0042、0043、0045、0048、0049、0051、0053、0055、0056、0057、0058、0059、0060、0061、0063、0065、0067、0068、0069、0070、0071、0075、0076、0077
- 出场的人：莉波、燕、星南、千奈、広、佑芽、美鈴、一同
- 场景：文化祭前夜的初星学園校舍，作业到夜里。先在教室送夜食，然后参观広她们做的プラネタリウム，之后与燕留在安静的校舍里说话。
- 世界线：活动 028；制作人在制作的偶像：看不出

## 发生了什么
莉波带了亲手做的饭团给留下赶工的大家，燕带来饮料。她提到佑芽和美鈴还担任谜解活动，随后与燕一起体验広的プラネタリウム，赞叹星空和一番星的演出。之后只剩她和燕时，她说准备期比本番更快乐，脱口说希望这段时间一直持续，又立刻说“文化祭本身也很期待”。她说自己1年级时想早点当3年生、早点当职业偶像，但3年过得太快；燕问她的进路，她说在迷茫，不确定自己有没有资格当职业偶像。燕说一直看着她的努力，她道谢，并约好办一个好的最后的文化祭。剧情经过参照 hmsz、hume 笔记。

## 她的关键台词
- 0015「みんなー、夜食のおにぎり、／作ってきたよー。」——主动为留下来的大家带来亲手做的夜食。
- 0042「……一番星。／すごく綺麗……だね。」——看到プラネタリウム里的一番星时的感叹。
- 0051「文化祭の当日よりも、／準備してるときのほうが、／楽しかったりするよね。」——说出自己更喜欢准备期。
- 0053「……この時間が、／ずっと、続けばいいのに……」——脱口而出希望时间停住。
- 0056「……あ、ええっと、違くて、／文化祭はすごく楽しみなんだけど。」——立刻补充，避免被误会不期待文化祭。
- 0058「1年生の頃は、／早く3年生になりたいって、思ってた。」——对比过去的期待和现在。
- 0061「でも、初星での3年間は、／ほんとにあっというまで――」——3年过得太快，话没有说完。
- 0067「……迷ってるんだ。」——被燕问进路时的回答。
- 0070「プロのアイドルになる資格、／私にあるのかなって。」——自己对职业偶像资格的疑问。
- 0071「こんな曖昧な気持ちのまま、／本物のアイドルになれるのかなって。」——自己「曖昧な気持ち」是她迷茫的原因。
- 0077「最後の文化祭、いい思い出にしようね。」——最后的约定。

## 行为模式
- 看到别人在赶工 → 做好吃的带过去并介绍口味（0015、0018）。
- 自己说出了过于消极的话 → 立即补一句「違くて」，再缩小为「ちょっと、思っただけ」（0053、0056、0057）。
- 被问到进路 → 先承认「迷ってる」，再讲和进路指导老师谈过的话，最后讲出心里的疑问（0067～0071）。
- 被朋友肯定 → 简短道谢后转向下一个话题（0075～0077）。

## 关系
- 燕：称「燕ちゃん」，燕叫她「姫崎」；莉波问燕是否去100プロ，并为她的决定说「きっと決まると思うよ」；被燕问到时说出自己的迷茫（0063、0065、0067）。
- 佑芽、美鈴：称「佑芽ちゃん」「美鈴ちゃん」（0023）。
- 千奈：千奈称她「莉波お姉さま」（千奈 0016）。

## 档案类事实
- 做了梅干し、おかか、高菜、明太子的饭团（0018）。
- 1年级时想早点成为3年生、站上舞台、成为职业偶像（0058～0060）。
- 与进路指导老师谈过话，对方让她好好考虑成为研修生之后的事（0068）。
- 1年级时也在晚上留下做过文化祭的作业，带过点心、放过喜欢的偶像的歌（0048、0049）。
