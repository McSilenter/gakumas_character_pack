# 姫崎莉波 培育事件 001 activity / 002 装饰（adv_pevent_001_hrnm_activity_002）

- 她的台词：12 行（含用匿名标签说的 0 行）
- 出场的人：莉波（12 行）、プロデューサー（4）
- 场景：在挑搭配衣装的小物（0003），有可买的商品（0008、0015），具体地点和时间点剧本没写

## 发生了什么
衣装定了，搭配的小物还定不下来，她请制作人一起选（0001～0004）。后面是三种并列的反应：制作人选眼镜，说可能有助于演出姐姐感，她拿不准，但因为是他说的决定买来试试（0005～0008）；选耳环，她觉得成熟漂亮、和上品的衣装相配，给自己鼓劲（0009～0012）；选了她觉得有点孩子气的东西，制作人说反差能衬托成熟气质，她笑他像商品广告词，答应先搭着试试（0013～0016）。

## 她的关键台词
- 0003「衣装は決まったんだけど、／あわせる小物が決まらなくて……」——在小物上犹豫
- 0004「一緒に選んでくれると嬉しいな。／どれがいいと思う？」——直接请他一起选
- 0005「メガネ？／わ、私に似合うかなぁ……」——对新造型没把握
- 0007「そうなのかな……／きみがいうならそうかも。」——他说的她就愿意信
- 0008「じゃあ買ってみようかな！／後で感想を聞かせてね。」——决定试，并要他的感想
- 0009「イヤリング……大人っぽくて素敵だね。」——对成熟感的东西有好感
- 0012「衣装に負けないように、／私もがんばらなくちゃ……！」——不想输给衣装
- 0013「ちょっと、子どもっぽくない……？」——担心显得孩子气
- 0015「ふふっ。今の、商品の横に／書かれてそうな言葉だったな。」——轻轻吐槽他的说法
- 0016「うん、わかった。／1回、試しにあわせてみるね。」——吐槽完还是照他说的试

## 行为模式
- 拿不定主意 → 找制作人一起选，要他的意见和感想（0004、0008）
- 被推荐不习惯的造型 → 先怀疑适不适合自己，然后因为“是你说的”愿意试（0005、0007、0008）
- 听到对方说得太像套话 → 笑着点破，但不否定，照样接受（0015、0016）
- 碰到好衣装 → 想的是自己要配得上（0012）

## 关系
- 制作人：这一话里说「きみ」（0007）。这一话里制作人没有叫她的名字，用敬语。她很听他的意见，也会开他的玩笑（0007、0015、0016）。

## 档案类事实
- 担心显得孩子气，对成熟感的小物有好感（0009、0013）
