# 姫崎莉波 培育事件 001 activity / 014 圆珠笔（adv_pevent_001_hrnm_activity_014）

- 她的台词：12 行（含用匿名标签说的 0 行）
- 出场的人：莉波（12 行）、プロデューサー（6）
- 场景：两人一起上街买制作人的圆珠笔（0004、0005），时间点剧本没写
- 世界线：培育（姫崎莉波）；制作人在制作的偶像：姫崎莉波（剧本里没有直接说法）

## 发生了什么
制作人说圆珠笔在学园小卖部买就行，她说圆珠笔也相当于名片，要讲究，而且总是他陪她放松，偶尔也该为他的事上街（0001～0004）。后面并列的反应：她要去文具区，他说逛街不一定是文具，她说有目的才重要（0005～0008）；他不想增加她的负担，她说这不算负担，反问他是不是觉得和她出门是负担，他说每次都很开心，她说自己也一样（0009～0013）；他说之前看到她用过（从 0015、0018 看，大概是选了和她一样的，见下面的不确定）后印象很深、一直想问，她有点慌，意识到这样就是一样的了，笑了（0014～0018）。

## 她的关键台词
- 0002「だーめ。ボールペンも名刺代わり。／こだわったほうがいいよ？」——小东西也讲究
- 0003「それに、いつも私の息抜きに／付き合ってもらってるし。」——知道他总陪自己
- 0004「たまには、きみの用事で／街に出てもいいと思うな。」——想回报
- 0007「だめだよ。目的があることが／大事なんだから。」——逛街的小原则
- 0010「負担に思うようなことじゃないよ。／それとも……」——顺势反问
- 0011「きみは私とお出かけするの、／負担に思ってた？」——借机确认他的心情
- 0013「でしょう？／私も、同じ気持ちだよ♪」——直白回应
- 0017「そ、そうだったの？／じゃあ、そうしようか……」——被他一直记着的事打动，有点慌
- 0018「……それってお揃いってことだよね。／えへへ……」——为一样的东西高兴

## 行为模式
- 对方敷衍小事 → 用“不行”拦下，讲要讲究的道理（0002）
- 欠了对方人情 → 找机会回报，还把它说成顺便（0003、0004）
- 对方担心给她添麻烦 → 反问“你是不是觉得和我出门是负担”，让对方说出来（0009～0011）
- 对方记着自己的小事 → 慌，然后为“一样”偷偷高兴（0017、0018）

## 关系
- 制作人：这一话里说「きみ」（0004、0011）；制作人叫她「姫崎さん」（0009），用敬语。她平时靠他陪着放松（0003），和他出门她是开心的（0012、0013）。

## 档案类事实
- 她常让制作人陪自己放松（0003，她自己说的）
- 她说圆珠笔也相当于名片，应该讲究（0002）

## 不确定
- 0014 前制作人说的话不在剧本里，从 0015、0016、0018 看，他大概想要和她用过的笔同款，具体哪款没说。
- 0017 的そうしようか 就是“买同款”的意思，但也是推断。
- 【译文】0018 お揃い 译成“情侣款”，原文只是成对、一样的，并没有说情侣。
