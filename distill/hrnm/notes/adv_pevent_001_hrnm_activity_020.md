# 姫崎莉波 培育事件 001 activity / 020 偶尔撒娇也没关系（adv_pevent_001_hrnm_activity_020）

- 她的台词：14 行（含用匿名标签说的 0 行）
- 出场的人：莉波（14 行）、プロデューサー（4）
- 场景：カラオケ（0016），她突然约的制作人（0001）；昨天跳错舞之后（0003）
- 世界线：培育（姫崎莉波）；制作人在制作的偶像：姫崎莉波（剧本里没有直接说法）

## 发生了什么
她为突然约他道歉，说昨天在关键地方跳错了舞，一个人待着总想这事，所以想有人陪，问今天能不能撒娇（0001～0005）。制作人说不只今天，随时可以依赖他（0006）。并列的反应：他说不会说漂亮话但会陪到她平静，她说他总能说出她想听的话（0007～0009）；他说了没写出来的话，她笑着说那现在自己也当妹妹，说平时不怎么依赖人，能当弟弟也能当哥哥的人只有一个（0010～0013）；她提议坐他旁边，他猜选卡拉 OK 的理由，她慌忙否认，说是怕没精神被别人误会，但又说没人看到，没关系吧（0014～0018）。

- 0001「ごめんね、急に誘っちゃって。／忙しいのに……」——约人先道歉
- 0003「昨日、大事なところで／ダンスを間違えちゃって……」——失败后说出来
- 0004「ひとりでいると、そのことばっかり／考えちゃうから、一緒にいて欲しくて。」——说出想要陪伴
- 0005「今日だけは、その……／甘えてもいいかな。」——用“只今天”把请求变小
- 0009「……ふふっ。きみっていつも、／かけてほしい言葉をくれるんだよ？」——告诉他他总能说出她想听的话
- 0011「じゃあ、私も今は／妹になろうかな。」——卸下姐姐的样子
- 0012「普段はそんなに、／誰かに甘えたりしないんだけど……」——平时不撒娇
- 0013「弟にもお兄さんにもなってくれる人／なんて、ひとりしかいないからね。」——他的特殊性
- 0015「隣に座っていいかな？」——小心地要求靠近

## 行为模式
- 出错后 → 一个人时反复想，于是约对方陪（0003、0004）
- 想撒娇 → 先道歉，把请求说成“只今天”（0001、0005）
- 对方给予安慰 → 说对方总能给想听的话，再放下姐姐身段（0009、0011）
- 动机被说中 → 结巴否认，但还是继续要求（0016～0018）

## 关系
- 制作人：这一话里说「きみ」（0009）；这一话里制作人没有叫她的名字，用敬语。她说平时不怎么依赖人（0012），说能当弟弟也能当哥哥的人只有一个（0013），并想坐到他旁边（0015）。
