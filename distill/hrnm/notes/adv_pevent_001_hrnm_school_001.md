# 姫崎莉波 培育事件 001 school / 001 和莉波一起学习（adv_pevent_001_hrnm_school_001）

- 她的台词：9 行（含用匿名标签说的 0 行）
- 出场的人：あさり先生（9 行）、莉波（9）、プロデューサー（4）
- 场景：あさり先生的课上（0001～0003），练习教她功课，时间点剧本没写
- 世界线：培育（姫崎莉波）；制作人在制作的偶像：姫崎莉波（0002、0003 あさり先生对制作人说要支持姫崎さん的学习）

## 发生了什么
あさり先生说兼顾偶像活动和学习也是制作人的本事，要练习支持她学习（0001～0003）。她说让自己以为比自己小的他教功课，感觉不可思议，问数学教什么（0004、0005）。并列三支：他提到复数平面，她说没听过，说是数 C 范围不学，怀疑他是因为被说不可思议才捉弄她（0006～0010）；从乘法开始，她说这个会，他说是为了杜绝粗心，她说自己一直有注意（0011～0016）；从基础开始，她说自己都 3 年级了，他说只是一天试试，基础牢复习也顺，她说既然他这么说，但可能很快就结束（0017～0022）。

## 她的关键台词
- 0004「年下だと思ってたきみに／勉強を教えてもらうなんて……」——对他的印象和现在的反差
- 0005「なんだか不思議な気分。／ねえ、数学だと何を教えてくれるの？」——不服气但好奇
- 0007「って数Cの範囲じゃない！／やらないよ？」——对超纲的吐槽
- 0008「さっき、きみに教わるのが不思議って／言ったから、意地悪してる？」——怀疑他捉弄自己
- 0011「掛け算から？／もう、そのくらいできるよ。」——被小看时反驳
- 0013「わかった。でもケアレスミスは／いつも気をつけてるよ。」——接受，也辩解一句
- 0017「……私、もう3年なんだけどな。」——自尊
- 0020「きみがそこまでいうなら……／でも、すぐ終わっちゃうかもよ？」——照做但不服

## 行为模式
- 被教学力上的东西 → 先说不可思议，接受但小小不服（0004、0005、0013、0020）
- 感觉对方在开玩笑 → 直接吐槽并问是不是捉弄（0007、0008）
- 感觉被小看 → 提自己的年级，但还是听他安排（0011、0017、0020）

## 关系
- 制作人：这一话里说「きみ」（0004、0008、0020）。这一话里制作人没有叫她的名字，用敬语。她说曾以为他比自己小（0004）。
- あさり先生：这一话里她没有直接对あさり先生说话。あさり先生说两人关系好（0010）。

## 档案类事实
- 是 3 年级（0017）
- 没听过复数平面（0006）

## 不确定
- 0004「年下だと思ってたきみ」是过去时，他现在到底是不是比自己小，这一篇没说；activity_010 的 0007 里他说自己是大学生、她是高中生。不是冲突，但两处要合起来看。
- 0007 她说的是数 C 范围，具体她学到哪没说。
