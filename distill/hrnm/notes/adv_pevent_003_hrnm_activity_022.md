# 姫崎莉波 培育事件 003 activity / 022 有在意的东西吗？（adv_pevent_003_hrnm_activity_022）

- 她的台词：16 行（含用匿名标签说的 0 行）
- 出场的人：莉波（16 行）、プロデューサー（4）
- 场景：有很多鱼的地方，从这里起是商店区（0001、0002），看内容像水族馆，这一篇里没有水族館的字样；时间点剧本没写
- 世界线：培育（姫崎莉波）；制作人在制作的偶像：姫崎莉波（剧本里没有直接说法）

## 发生了什么
她说可爱的鱼很多、很治愈，到了商店区，问制作人有没有在意的东西（0001～0005）。并列三支：周边店，她也在意，说海豚、鲸鱼都很可爱，制作人提到寿司布偶，她想买イクラ和铁火卷当伴手礼，说肚子饿了（0006～0010）；咖啡厅，她也在意，说除了海豚鲸鱼菜单还有水母乌冬、海蛞蝓面包，他提议去吃，她赞成（0011～0015）；她说也看到了，里面有アザッシーさん的手办，水的颜色会变成海蓝色，他说要买，她也买来送大家（0016～0020）。

## 行为模式
- 逛东西 → 问对方在意什么，然后说自己也在意（0005、0006、0011、0016）
- 买东西 → 想到要给大家带（0009、0020）
- 看到可爱或有趣的 → 兴奋地一个个说出来（0007、0013、0016～0018）

## 关系
- 制作人：这一话里说「きみ」（0005）；这一话里制作人没有叫她的名字，用敬语。她和他的兴趣点相同（0006、0011、0016）。

## 档案类事实
- 觉得海豚、鲸鱼可爱（0007）；想买寿司布偶当伴手礼（0009，打算）

## 不确定
- アザッシーさん 是什么，这一篇没说。
- 0016～0020 的商品是什么：0016 手办在里面，0017 お湯の色 会变，大概是入浴用品，原文没这样写。
- 【译文】0016、0018 的アザッシーさん 译成“海豹仔”，原文只是名字，这一篇没说它是什么动物。
