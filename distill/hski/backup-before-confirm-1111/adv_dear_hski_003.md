# 花海咲季 亲爱度剧情 / 第3话（adv_dear_hski_003）

- 她的台词：49 行（含用匿名标签说的 0 行）
- 出场的人：咲季、プロデューサー
- 场景：去往并到达作为活动据点的教室（相当于“事务所”）（0002、0012）
- 世界线：亲爱度（花海咲季）；制作人在制作的偶像：花海咲季

## 发生了什么
制作人带她去作为活动据点的教室，她把它比作「765プロ」那样的“两个人的偶像事务所”，很来劲。到了教室，她主动说要亲口说出自己的弱点：她记性好、学什么都很快上手、一路被夸，但总会很快学到顶，然后在某一天突然停止成长，无论什么竞技最后都只是「そこそこ止まり」。她说自己体格也不占优，知道高中阶段行不通、当不了世界第一，所以去找了新的梦想，并问制作人是否失望。她再次要制作人看着她的眼睛回答为什么选她，制作人的回答（剧本没写）让她又傻笑起来；她追问是不是认为她是妥协才当偶像，激动地说过去的每个梦都是认真的。制作人说那么新的梦也不会是妥协，想培养屡败屡起的「不屈のアイドル」；她说制作人是个怪人，宣告要让他看「偽物の天才」实现梦想。

## 她的关键台词
- 0005「そっかぁ～、わたしたちふたりの／『アイドル事務所』ってわけね。」——把据点当成两人的事务所
- 0011「自分の口で言っておきたいから。」——明知对方调查过，仍要亲口说出自己的事
- 0015「このわたし、花海咲季の／弱点を教えてあげるわっ！」——连说弱点都用得意的口气
- 0023「どんな習い事も、遊びも、スポーツも、／すぐに上達して、勝ち続けてきた。」——过去的经历
- 0032「毎日成長を実感できていたのに、／ある日を境にぴたりと止まるの。」——她的弱点：成长突然停止
- 0035「最終的なわたしは、そこそこ止まりの／選手でしかない。どんな競技でもね。」——对自己才能上限的清醒认识
- 0039「世界一にはなれないって、／思い知ったから。」——放弃之前的竞技之路的理由
- 0041「――失望した？」——难得露出的不安
- 0058「あるわけないじゃない！　ぜんぶ！　／ぜんぶ！　本気だったわ！」——不容许别人说她不认真
- 0060「何度も負けて、諦めてきたけど――／それだけは嘘じゃない。ほんとうよ。」——承认多次失败、放弃，但每次都是认真的
- 0066「ええ、よーくわかったわ。／プロデューサーが変わり者だって。」——被打动后用调侃掩饰
- 0068「偽物の天才が、／夢を叶えるところをねっ！」——自称“假天才”的宣言

## 行为模式
- 有了新的据点、新的开始 → 立刻代入「未来のトップアイドル」的叙事，觉得燃（0006～0007）
- 说自己的弱点 → 先长篇自夸，被催才进入正题；但内容本身毫不粉饰（0022～0035）
- 讲到担当偶像“一切”时 → 意识到说法暧昧，慌忙补充「悩みとか、／得意不得意とか」（0018～0019）
- 说完伤疤 → 问「失望した？」试探对方（0041）
- 被夸得超出预期 → 傻笑、乱叫「もぉぉ～」，又说被夸惯了但“这次不一样”（0049～0053）
- 被怀疑（或自己担心被认为）是妥协 → 激烈否认，强调每次都是认真的（0056～0060）
- 被打动 → 不直说感动，转成调侃对方「変わり者」，再用宣言回应（0066～0068）

## 关系
- プロデューサー：她叫「プロデューサー」，说「あなたは、／わたしのプロデューサーなんだから」（0017）；对他说出自己的弱点和过去，追问他选她的理由；最后称他「変わり者」（0066）。制作人称她「咲季さん」。

## 档案类事实
- 从小记性非常好，学东西、游戏、运动都进步很快，一路赢、一路被夸（0022～0024）
- 被称为「神童」（她自己说）（0028）
- 成长会在某个时间点突然停住，无论什么竞技最后都只到「そこそこ」水平（0031～0035）；制作人的笔记称为「超早熟型」（0070）
- 体格不占优势（0037）
- 高中没有继续以前做的运动（制作人说，她确认）（0036～0037）
- 因为当不了世界第一而放弃，「新しい夢を探した」，即偶像（0039～0040）
- 过去「何度も負けて、諦めてきた」（0060）
- 自称「偽物の天才」（0068）
- 知道「765プロ」（0003）
