# 花海咲季 亲爱度剧情 / 第20话（adv_dear_hski_020）

- 她的台词：52 行（含用匿名标签说的 0 行）
- 出场的人：咲季、プロデューサー
- 场景：『N.I.A』（「この大会」）中赢了佑芽的那场演出之后，她回到制作人身边（0001、0016）
- 世界线：亲爱度（花海咲季）；制作人在制作的偶像：花海咲季

## 发生了什么
她演出回来对制作人说「ただいま」，说这是迄今最多的人为她应援；大会以来一直为投票数忽喜忽忧，以为明白粉丝在增加，其实完全没明白。她说演唱中一直想哭，现在也是；粉丝是外接肌肉、勇气之源、实力的指标，她稍稍明白了什么是顶级偶像。她说不久前还是敌人的人今天也喊她「咲季様」、给了她赢佑芽的力量，她能赢比自己强的对手是靠粉丝和让她遇到粉丝的制作人；制作人说这些都是她实力的一部分，她坚持道谢。她说通过这次大会找到了“劣势下也能和强敌战斗的武器”，但又不安：输给佑芽一次就再也站不起来，紧绷的弦会断、武器会碎。制作人直说总有一天会输，重申自己“最终赢过所有偶像就好”的想法；她说自己输了会惨不忍睹，问他那时会不会救她。制作人说她说丧气话时最帅，站不起来就爬着前进才是花海咲季，万一她真在那里结束，他就和她一起结束，因为没有比她更好的偶像。她说他的信任太重，原来自己是这样的人；两人都说“幸好你不是敌人”，她说他最先遇到的偶像是她真好，称他「ベストパートナー」，说「もう……逃がさないんだからねっ！」。

## 她的关键台词
- 0001「プロデューサー……ただいま。」——演出后回到制作人身边
- 0009「ぜんぜんわかってなかったわ――」——对粉丝的认识被刷新
- 0011「……泣きそうだった。／ライブ中、ずーっと。……いまも。」——情绪最直白的一次
- 0013「トップアイドルってなんなのか、／少しだけ……わかった気がする。」——通过粉丝对顶级偶像有了新认识
- 0017「そうよ。わたしが格上のライバルたちに／勝てたのは……ファンのおかげ。」——把胜利归功于粉丝
- 0022「……お礼くらい言わせなさい。」——不让对方把功劳推回来
- 0025「見てなさい！　何倍にもして、／お返ししてやるんだから！」——对粉丝的回应方式
- 0029「格上のライバルたちと、劣ったままで／闘える武器を見つけたと思う。」——她的“武器”
- 0036「確信があるの。一度でも負けたら、／ずっと張り詰めていた糸が切れるって。」——对自己脆弱处的清醒认识
- 0049「糸が切れて心が砕けて、／目から光が消えちゃうんだから！」——用夸张自信的口吻说丧气话
- 0053「……あなたは、助けてくれる？」——第一次直接求救式的提问
- 0067「…………っとに。／信頼が重いったら。」——被深深信任时嘴上抱怨、实际接受
- 0068「自分でも知らなかったわ――……／わたしって、そんなやつなのね。」——从制作人眼里重新认识自己
- 0072「あなたと最初に出逢ったアイドルが、／わたしでよかった。」——庆幸自己是制作人最先遇到的偶像
- 0073「プロデューサー。あなたは、／わたしのベストパートナーよ。」——对制作人的定位
- 0074「覚悟しなさい！／もう……逃がさないんだからねっ！」——用强势口吻收尾，表示要一直绑住对方

## 行为模式
- 演出成功后 → 先说感受（想哭），再整理出自己的理解（0003～0013）
- 被说“功劳都是你自己的” → 坚持要道谢，再对粉丝喊话要加倍回报（0019～0025）
- 被看穿不安 → 承认，具体说出“输一次就断”的恐惧（0033～0037）
- 被直说“总有一天会输” → 先抗议，然后用夸张自信的口吻说自己输了会多惨，再小声问对方会不会救她（0041～0053）
- 被深深信任 → 说“太重了”，然后坦率回应、把对方定为最佳搭档，用强势口吻收尾（0067～0074）

## 关系
- プロデューサー：她回来说「ただいま」；把胜利归于粉丝和他；问他自己倒下时会不会救她；他说万一她结束就一起结束，她说「信頼が重い」，称他「ベストパートナー」，说不会让他逃（0001、0018、0053、0063～0074）
- 粉丝：她称「わたしのファンたち」，说要加倍回报；被叫「咲季様～」（0014、0024～0025）

## 档案类事实
- 这次演出是迄今为她应援的人最多的一次（0003～0004）
- 粉丝叫她「咲季様」（0014）
- 她认为赢强敌靠的是粉丝和制作人（0017～0018）
- 通过『N.I.A』找到了劣势下也能战斗的“武器”（0029）
- 她确信只要输给佑芽一次，紧绷的弦就会断（0035～0036）
- 制作人的想法：输多少次都没关系，最终赢过所有偶像就好；她称之为「ふざけたこと」（0043～0045）
- 她说他最先遇到的偶像是她（0072）

## 不确定
- 0015「あいつら……ちょっと前まで、／敵だったくせに。」：“敌人”指谁（别的偶像的粉丝？竞争对手本人？）不明。
- 0053～0054：她问完「助けてくれる？」后自己「なっ……」，中间制作人说了什么或做了什么没写进剧本。
- 0072 说制作人「最初に出逢ったアイドル」是她，可能意味着她是制作人的第一个担当，剧本没明说。
- 【译文】0072「あなたと最初に出逢ったアイドルが、／わたしでよかった。」译成“最初遇到的偶像是你，真是太好了”，主宾颠倒，原意是“你最先遇到的偶像是我”。
