# 花海咲季 亲爱度剧情 / 第21话（adv_dear_hski_021）

- 她的台词：61 行（含用匿名标签说的 0 行）
- 出场的人：咲季、プロデューサー、佑芽（只在回想中）
- 场景：『H.I.F』当天，她上台前（0001～0003、0074）；她是第一个出场（0003）
- 世界线：亲爱度（花海咲季）；制作人在制作的偶像：花海咲季

## 发生了什么
『H.I.F』当天，制作人说今天是她成为『一番星』的日子，她说正有此意，自己第一个出场，要一上来就决定胜负。她说『H.I.F』是她梦想开始的特别舞台：去年夏天、前前届『H.I.F』上诞生的『一番星』让她憧憬、立志当偶像；很多粉丝说十王星南的名曲是『Choo Choo Choo』，但震撼她灵魂的是优胜演出上的『ENDLESS DANCE』，那个舞台是偶像花海咲季的起点。今天既是和『花海咲季の根源』的战斗，也是兑现和佑芽约定（第19话的回想）的日子，更是她和制作人一起挑战憧憬的大舞台的日子，她称他为最好的搭档。她回想初遇（第1话的回想）、被看穿烦恼、觉得「このひととなら」；制作人说她什么都能一个人做，自己曾怀疑存在的意义，她说没有他就没有现在的她，在『N.I.A』里一定会输、碎掉。她一条条列出他为她做的事——吃她的便当说好吃、准备歌和服装和舞台、一直相信她、一起定计划上课参加试镜和演出，说两人一起培养了偶像花海咲季，艰辛的路一直很快乐，最重要的是因为和他在一起，「誰かじゃイヤよ。あなたじゃないと。」。制作人说哪有上台前给制作人打气的偶像，她说就在你眼前，要他看着她去抓住「わたしたちの星」。

## 行为模式
- 大舞台当天 → 兴奋、积极，宣布要一开始就决胜（0003～0004）
- 想起梦想的起点 → 细致地讲出具体的曲名和感受（0007～0019）
- 制作人自我怀疑 → 说「ばかね」，然后一条条列出对方为自己做的事来否定他（0041～0066）
- 被设想“没有相遇”的情况 → 直接拒绝去想（0046～0047）
- 说出很肉麻的话后 → 补一句“这种理所当然的事不会再说第二遍”（0071）
- 上台前 → 反过来给制作人打气（0067～0075）

## 关系
- プロデューサー：她称他「最高のパートナー」，说不会让他逃；回顾两人一路走来，说没有他就没有现在的她，「誰かじゃイヤよ。あなたじゃないと。」；上台前反过来给他打气（0031～0032、0035～0075）。制作人说自己曾为存在意义烦恼（0041～0042）
- 佑芽：今天也是兑现和佑芽约定的日子（0021～0028）
- 十王星南：去年夏天的『H.I.F』上诞生的『一番星』，她憧憬对方而立志当偶像（0010～0016）

## 档案类事实
- 立志当偶像的契机：去年夏天前前届『H.I.F』上诞生的『一番星』（十王星南），尤其是优胜演出上的『ENDLESS DANCE』（0010～0016）
- 制作人说她入学半年前开始偶像训练（0008）
- 知道十王星南第一次成为『一番星』时唱的是『Choo Choo Choo』（0013～0014）
- 『H.I.F』当天她第一个出场（0003）
- 她说两人一起：制作人吃她的便当说好吃、为她准备歌和服装、给她舞台、一起定训练计划、开会、上课、参加试镜、演出（0057～0062）
- 她说自己没有制作人就赢不了『N.I.A』，那天也赢不了佑芽（0048～0049），即她在『N.I.A』优胜
- 定期公演和『N.I.A』时制作人一直在她身边（0069）

## 不确定
- 0021～0027（含佑芽 0026～0027）是第19话 0019～0027 的回想；0036、0038 是第1话 0002、0060 的回想。
- 0010「去年の夏にあった、／前々回の『H.I.F』よ。」：本篇的『H.I.F』在夏天（第19话 0020 说下次是夏天的大舞台），若『H.I.F』每年一次，去年夏天应是“上一届”而不是“前前届”，剧本没交代『H.I.F』的举办频率，待确认。
- 和前面说法的关系：第8话 0058～0060 说选偶像是因为体格不好也能冲世界第一、作为偶像也许能赢佑芽；第10话 0063～0068 说追求世界第一是为了把佑芽那句话变成真的；本篇说立志当偶像是因为憧憬『一番星』。几处理由不同，可能是互补，也可能需要统一，待确认。
- 0069「定期公演」：前面这条线（第1～20话）没写到定期公演的场面，具体是什么没交代。
- 【译文】0037「すぐに悩みを見抜かれて。」译成“自从被你轻易看穿了谎言”，原文是“烦恼”不是“谎言”。
