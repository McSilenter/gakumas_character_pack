# 花海咲季 亲爱度剧情 / 第37话（adv_dear_hski_037）

- 她的台词：40 行（含用匿名标签说的 0 行）
- 出场的人：咲季、プロデューサー
- 场景：冬季『H.I.F』优胜当天，她来到两人初次相遇的地方找制作人，周围没有人（0001～0005、0016）
- 世界线：亲爱度（花海咲季）；制作人在制作的偶像：花海咲季

## 发生了什么
她到两人初次相遇的地方找到制作人，说“就知道你在这”。两人说从那时起都变了，她说心和身体都像换了个人，也一定有变坏的地方；制作人说她以前那么健康，现在养成了熬夜的习惯，她说偶像的工作也有晚上的，制作人又说别在直播中打瞌睡，她说他最近太爱捉弄她，迟早报复。制作人说早就被她“报复”了，两人都哭得脸很难看，她说幸好没人。她说其实没什么实感，只记得大家看着她的脸。制作人说有和她竞争过的运动员们托他带话；她说在舞台上看到了熟悉的面孔，大家都变得很出色，让她来了劲，以为她们是来骂她「よくも勝負から逃げやがったな」的。制作人转交一张只在中间写了一句“共同意见”的色纸，她看完又哭笑起来，说眼泪停不下来。制作人说今天哭没关系、明天开始要收敛，她接着说自己是顶级偶像了，相遇时还是新手偶像和新手制作人，现在已不能说那种话，作为『一番星』、学园顶点有该尽的责任；梦想实现了但没有结束，她答应过要打头阵，自称「不屈のトップアイドル・／花海咲季」，邀制作人一起去看『一番星』之后的世界。

## 行为模式
- 找制作人 → 知道他会在哪里，制作人装作意外时她说他心口不一（0001～0005）
- 被捉弄 → 先「むっ」，说“我会报复的，做好准备”（0012～0013）
- 回顾自己 → 承认变化里也有变坏的部分，不只说好的（0008）
- 面对过去的对手 → 先想到对方会怨她“逃避比赛”，用这种自嘲的方式应对（0033～0035）
- 情绪满溢 → 哭笑交加，坦白停不下来（0042～0043）
- 实现梦想后 → 马上想到新立场的责任和下一个目标，不停留（0046～0056）

## 关系
- プロデューサー：她到初遇之地找他；说他最近太爱捉弄她（0012）；两人一起哭（0016～0017）；她说相遇时是「駆け出しアイドルと、／駆け出しプロデューサー」（0047）；最后邀他一起去看『一番星』之后的景色（0055～0056）
- 以前一起竞争过的运动员们：她们来看了她的演出，托制作人带了一张色纸；她称她们「あいつら」「どいつもこいつも」，说她们都很出色，以为会被怨“逃避比赛”（0027～0035）

## 档案类事实
- 两人初次相遇的地方是一个平时没什么人的地方（具体没说）（0005、0016）
- 制作人说她以前很健康，现在养成了熬夜的习惯（0009）
- 以前和她竞争过的运动员们来看了『H.I.F』，托制作人转交一张色纸，中央写了一句共同的话（内容剧本没写出来）（0027～0039）
- 她现在是『一番星』、学园顶点（0049）

## 不确定
- 0041 她沉默的那一行应是在看色纸，色纸上写了什么剧本没写出来。
- 0014～0015 制作人「見せてくれましたね――」后她「……………………うん。」，中间他想说什么没说完。
- 0035 她以为运动员们会说「よくも勝負から逃げやがったな」，和第8话说的“快输就逃到别的竞技”（勝ち逃げ）相关，见 conflicts 一·1。
- 0009 熬夜习惯：第26话她说平时9点前就睡、第33话也是佑芽通话时她总在睡；这里说现在养成了熬夜习惯，是前后变化（制作人说「できてしまいましたね」），不当冲突，先记下。
- 【译文】0032「気合入った。」译成“我也很开心”，原文是“来劲了、鼓足了干劲”。
