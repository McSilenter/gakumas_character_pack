# P卡 花海咲季【Fighting My Way】 / 第2话 Fighting My Way 第2话（adv_cidol-hski-3-000_02）

- 她的台词：27 行（含用匿名标签说的 0 行）
- 出场的人：咲季、プロデューサー
- 场景：制作人把新曲的试听音源和歌词交给她（地点没交代）（0001、0010）
- 世界线：亲爱度（花海咲季）·P卡；制作人在制作的偶像：花海咲季

## 发生了什么
她听了试听音源，说可爱又帅气、让人心跳，正适合自己，急着要唱，要了歌词。看了歌词她越看越不对，质问「なによこの歌詞は！」；制作人说是“不服输到要死的偶像的歌”，很像她。她说太合适了反而唱不了：投入感情唱，越用心软弱的自己越会露出来，像赤身唱歌，她必须是无敌的花海咲季、只想展示强大的自己。制作人问“为了赢也不行吗”，说这是让花海咲季不输给任何人、成为无敌顶级偶像的歌；她说「…………面白いじゃない。」，说他真会让她上钩，答应为了赢什么都挑战，虽然不知道能不能做到、非常害羞，也要在新曲演出上「はだかになってみせる」。

## 行为模式
- 拿到新东西 → 马上试，喜欢就直说、急着用（0002～0009）
- 歌词说中了自己 → 先承认「ぴったり」，再生气地说太合适了才唱不了（0013～0018）
- 被要求展露软弱 → 拒绝，理由是必须是无敌的花海咲季、只能展示强的一面（0020～0025）
- 对方把事情和“赢”挂钩 → 立刻改变态度「面白いじゃない」，明知被激将也接受（0026～0033）
- 下决心时 → 同时老实说出不安和害羞（0034～0035）

## 关系
- プロデューサー：她说他「わたしを乗せるの、本当に上手」（0031）；他写的歌词被她骂「バカぁ」，但最终接受了他的说法（0017、0028～0035）
