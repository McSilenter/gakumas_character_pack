# P卡 花海咲季【Fighting My Way】 / 第3话 Fighting My Way 第3话（adv_cidol-hski-3-000_03）

- 她的台词：22 行（含用匿名标签说的 0 行）
- 出场的人：咲季、プロデューサー
- 场景：新曲演出上台前，她发现佑芽来看演出（0001～0002）
- 世界线：亲爱度（花海咲季）·P卡；制作人在制作的偶像：花海咲季

## 发生了什么
上台前她慌张地说佑芽来看演出了；制作人说是她自己邀请的，她说当然，她不可能不叫妹妹来。但她苦恼的是，这首歌满满装着她对妹妹的复杂感情，要被佑芽本人听到了，抱怨“所以我才说那歌词不妙”。制作人两次说“没办法了”，她说烦死了，自己知道，这只是下决心用的例行程序；又命令制作人说一句让她燃起来的台词。制作人说真实的她胆小、好面子、总在逞强，但很帅，是他自豪的偶像；她傻笑起来，说那当然，自己是未来的顶级偶像花海咲季，要随心唱出不屈和胜利。

## 她的关键台词
- 0001「……プロデューサー、どうしよう。」——上台前的慌张
- 0002「妹が……佑芽が……／わたしのライブを観にきてるわ……！」——佑芽来了
- 0005「わたしがあの子をライブに／呼ばないはずがないじゃない。」——一定会邀妹妹
- 0007「わたしの妹への複雑な想いが／たっぷり込められた歌を――」——新曲里有她对妹妹的复杂感情
- 0011「それがどうしたってのよ。／大事なのはいまどうするかでしょ。」——被指出自作自受时的回应
- 0013「うぅぅぅ……実は情けないお姉ちゃん／なんだってばれたらどうしよう……」——最怕的是被妹妹发现自己没用
- 0016「わかってるわよ！　これはあくまで、／覚悟を決めるためのルーティンだから！」——慌张是下决心的例行程序
- 0018「…………プロデューサー、／なにかいい台詞を言いなさい。」——要制作人鼓励
- 0019「わたしが燃えるようなやつよ。」——指定鼓励的种类
- 0027「えへへぇ……♡」——被夸后傻笑
- 0028「そ、それほどでも……あるけどぉ～！」——典型的接受夸奖方式
- 0032「未来のトップアイドル、花海咲季よ！」——自我宣言
- 0033「心のままに、／不屈と勝利を歌ってくるわ！」——决定不加掩饰地唱

## 行为模式
- 上台前紧张 → 慌张地找制作人说出来，但自己知道这只是“下决心的例行程序”（0001～0016）
- 被指出是自己造成的 → 「それがどうした」，把重点转到“现在怎么办”（0010～0011）
- 需要鼓励 → 直接命令制作人说一句能让她燃起来的话（0018～0019）
- 被说“胆小、好面子、逞强”但“帅气” → 只听见夸奖，傻笑「それほどでも……あるけどぉ～！」（0023～0028）
- 被夸之后 → 马上恢复自信，以「未来のトップアイドル」自称上台（0031～0033）

## 关系
- 佑芽：她邀佑芽来看演出，说不可能不叫她（0003～0005）；新曲里装满了她对妹妹的复杂感情，她最怕被佑芽发现自己其实是「情けないお姉ちゃん」（0007、0013）
- プロデューサー：她命令他说鼓励的话；他说真实的她「弱気で／見栄っ張りで強がってばかり」但很帅，是「自慢のアイドル」（0018～0026）

## 档案类事实
- 新曲演出时，她邀请了佑芽来看（0002～0005）
- 新曲（按卡名应是『Fighting My Way』）里装满了她对妹妹的复杂感情（0007）
- 她说上台前慌张是“为了下决心的例行程序”（0016）
- 她自称「未来のトップアイドル、花海咲季」（0032）
