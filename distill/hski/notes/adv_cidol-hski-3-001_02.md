# P卡 花海咲季【Boom Boom Pow】 / 第2话 Boom Boom Pow 第2话（adv_cidol-hski-3-001_02）

- 她的台词：28 行（含用匿名标签说的 0 行）
- 出场的人：咲季、プロデューサー、佑芽
- 场景：接第1话课后，佑芽说“禁断之恋”；后半是第二天早上（0001～0002、0014）
- 世界线：亲爱度（花海咲季）·P卡；制作人在制作的偶像：花海咲季

## 发生了什么
听佑芽说制作人对她有「禁断の恋」，她慌乱否认“怎么可能”，看向制作人时他笑着挥手，佑芽说从没见过他那么高兴，她怪佑芽乱说，心里更乱。制作人其实是在近处观察她、构思新的制作计划。第二天早上她一脸困倦，制作人说一向严格管理身体的她很少这样，她小声说「あなたのせいでしょ」；她问「わたしのこと、好きなの？」，制作人说当然、越来越喜欢，她先傻笑，又说「じゃ、じゃなくって！」。她说整晚认真烦恼，因为是第一次遇到这种事，结论是：她要用自己的全部来做偶像，别的事没法认真。她说他很清楚她不能对人说的秘密——花海咲季只是早熟的偶像，和佑芽比没什么才能；所以要全力做计划、上课、唱跳，一点点缩小才能差距，挺胸做那个仰慕她的孩子可靠的姐姐。所以「いまはまだ、ごめんなさい」，等她引退后再来求婚。

## 行为模式
- 被人说有人喜欢她 → 结巴大声否认，否认到最后声音变小；之后整晚睡不着（0003～0005、0015～0018）
- 在意的事 → 第二天直接当面问清楚（0021）
- 被说喜欢 → 先忍不住傻笑，再强行拉回正题（0023～0024）
- 处理感情问题 → 认真想一晚，给出“以偶像为先”的结论，并用自己的秘密和妹妹说明理由（0025～0038）
- 拒绝时 → 不是断然拒绝，而是“现在还不行、引退后再来”，带着♡（0039～0041）

## 关系
- プロデューサー：她以为他在恋爱意义上喜欢她，问「わたしのこと、好きなの？」，他说「惚れ込んでいますよ」（0021～0022）；她说他很清楚她不能对人说的秘密（0030）；她说“现在还不行，引退后再求婚”（0039～0041）。制作人内心说是在观察她、构思计划（0012～0013）
- 佑芽：佑芽说制作人对她有「禁断の恋」，她怪妹妹乱说（0001～0010）；她努力是为了做「わたしを慕うあの子の、／頼れるお姉ちゃん」（0038）

## 档案类事实
- 制作人说她一向严格管理身体状况（0016）
- 她说除了偶像，别的事都没法认真（0029）
- 她“不能对人说的秘密”：花海咲季只是早熟的偶像，和佑芽比没什么才能（0030～0032）
- 她努力的目的是一点点缩小和佑芽的才能差距、做仰慕她的妹妹可靠的姐姐（0034～0038）
- 她说这种事（以为被告白）是第一次（0026）

## 不确定
- 0022 制作人「惚れ込んでいますよ」是作为制作人对偶像的意思（第3话他说明），她当时理解成恋爱。
- 0026「こういうの……はじめてだったから」——“这种事”是指被告白还是指为这种事烦恼，原文没说清。
- 0030「誰にも言えないわたしの秘密」和亲爱度第3话（很快学到顶、そこそこ止まり）、第8话（超早熟的她和大器晚成的妹妹）说的弱点一致；和“赢没赢过妹妹”的问题相关时见 conflicts 一·1。
