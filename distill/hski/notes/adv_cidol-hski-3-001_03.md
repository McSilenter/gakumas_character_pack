# P卡 花海咲季【Boom Boom Pow】 / 第3话 Boom Boom Pow 第3话（adv_cidol-hski-3-001_03）

- 她的台词：23 行（含用匿名标签说的 0 行）；其中 0015～0016 是她回想自己第2话说过的话（回想）
- 出场的人：咲季、プロデューサー
- 场景：接第2话之后，制作人说有东西要给她（地点没交代）（0001）
- 世界线：亲爱度（花海咲季）·P卡；制作人在制作的偶像：花海咲季

## 发生了什么
制作人说有东西要给她，她以为是礼物，得意地说他还没放弃自己、爱上担当偶像可是制作人失格。制作人说不彻底爱上偶像就做不好制作，她愣住，追问是不是“作为制作人和偶像”的意思，制作人说当然。她沉默，脑中回放自己说过的「プロポーズしてきなさいっ♡」，羞得叫出声，说怎么可能没事，质问那之前一直在旁边看她是怎么回事；制作人说是在构思下一个制作计划，再次认识到她的魅力，要给她的是让全世界知道她魅力的计划书。她“姑且”问自己的魅力是什么，制作人一口气说出：满溢的自信和背后的心思，美丽、华丽、凛然、可怜，好面子、窝囊、土气、踏实，聪明、热情、专注，谁看了都会喜欢；她中途几次想打断，最后说「プロデューサーって、／本当……わたしのこと好きよね。」，反问他其实是不是在搞「禁断の恋」。

## 行为模式
- 以为对方迷恋自己 → 得意地训诫对方“这样不行”，实际很高兴（0003～0006）
- 发现是误会 → 先要求对方别若无其事地转话题，确认后沉默、回想自己说过的话，羞得叫出来（0010～0019）
- 尴尬之后 → 把责任推给对方的行为，质问“那之前是怎么回事”（0020）
- 被一连串夸（含缺点）→ 中途想打断，最后半认真地说“你真喜欢我”，再拿“禁断之恋”回击（0028～0036）

## 关系
- プロデューサー：他说「アイドルに、とことん惚れ込まないと、／良いプロデュースはできませんよ」（0007），之前一直在她身边是为了构思计划（0021）；他把让世界知道她魅力的计划书交给她（0024）；她说「本当……わたしのこと好きよね」（0034）

## 档案类事实
- 制作人列出的她的魅力：溢出的自信和背后的心思，美丽、华丽、凛然、可怜，好面子、窝囊、土气、踏实，聪明、热情、专注（0026～0031，制作人的话）
- 制作人拿出了让她的魅力传遍世界的计划书（0024）；按卡名应与『Boom Boom Pow』有关，本篇没说曲名

## 不确定
- 0015～0016 是第2话 0040～0041 她自己说过的话，在本篇作为回想重现，标签是咲季，计入她的台词。
- 0035「……実はしてるんじゃないの～？」、0036「禁断の恋。」是开玩笑还是半认真，原文看不出。
- 本篇没出现曲名『Boom Boom Pow』，计划书和这首曲子的关系只能按卡名推。
