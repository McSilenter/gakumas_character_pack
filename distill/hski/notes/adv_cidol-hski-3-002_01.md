# P卡 花海咲季【冠菊】 / 第1话 冠菊 第1话（adv_cidol-hski-3-002_01）

- 她的台词：19 行（含用匿名标签说的 0 行）
- 出场的人：咲季、プロデューサー
- 场景：暑假前（或暑假中）和制作人商量暑假计划（地点没交代）（0004～0009）
- 世界线：亲爱度（花海咲季）·P卡；制作人在制作的偶像：花海咲季

## 发生了什么
制作人说要和她比试，她马上答应问比什么，结果是比“暑假计划”。她说今年夏天课程、工作、活动都很忙，不好好计划撑不过去；制作人说偶像活动的日程交给他，要比的是暑假中的“休养计划”。她说休息日在房间里全力休息不行吗，制作人说那很像她，但不是最好的，休息也需要变化，就像菜单一样；她说「痛いところをついてくる」，自从给妹妹以外的人做便当后就深有体会，于是接受挑战。她又说计划实施时他当然要陪她，制作人说休息日没必要和制作人过，她说两人的比试当然要一起过休日，「諦めて責任を取りなさい」。最后她得意地说要想夏天风格的休假方式——然后承认这是她的弱项，什么都想不出来。

- 0020「プロデューサー、／『夏休みの休養計画』で勝負よ！」——接受挑战
- 0022「ところで……もちろん計画の実践には、／あなたが付き合ってくれるのよね。」——理所当然地要求对方陪
- 0026「もうその気になっちゃったんだから、／諦めて責任を取りなさい。」——不讲理的要求方式

- 0030「夏らしい休みの過ごし方……／なんっにも思いつかないわ！」——完全想不出

## 行为模式
- 听到“比试” → 不问内容先答应（0001～0002）
- 被建议改变习惯 → 先说“不行吗”、不太明白；对方用她熟悉的事（做菜、便当）比喻，她立刻接受（0012～0019）
- 定下比试 → 要求对方一起参加实践，对方推辞就说“这是我们俩的比试”“你要负责”（0022～0027）
- 碰到不擅长的事 → 用得意的语气坦白“这是我的弱项”（0029～0030）

## 关系
- プロデューサー：比试“暑假休养计划”；她要求他陪她一起过休息日，说「諦めて責任を取りなさい」（0020～0027）
- 妹妹以外的人：她现在也给妹妹以外的人做便当（0018）

## 档案类事实
- 她今年夏天课程、工作、活动都很忙（0007）
- 她的休息方式是休息日在房间里全力休息（0012）；制作人说这很像她（0013）
- 她现在给妹妹以外的人也做便当（0018）
- 她说“有夏天感觉的休假方式”是她的弱项，什么都想不出（0029～0030）
