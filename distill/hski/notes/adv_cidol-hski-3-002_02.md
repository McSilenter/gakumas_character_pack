# P卡 花海咲季【冠菊】 / 第2话 冠菊 第2话（adv_cidol-hski-3-002_02）

- 她的台词：25 行（含用匿名标签说的 0 行）
- 出场的人：咲季、プロデューサー
- 场景：休养日早上的碰头地点，然后去制作人选的休闲运动设施，玩到傍晚（0001～0002、0006、0036）
- 世界线：亲爱度（花海咲季）·P卡；制作人在制作的偶像：花海咲季

## 发生了什么
她比约定早到，制作人也提前10分钟来了，说今天要赢，她说「面白いじゃない」。制作人带她去的是自己动手运动的休闲运动设施，不是体育场，也不是像她老家那样的高端训练设施；她说为这一天调整好了状态。到了之后她兴奋地说是最棒的游乐场、想全部玩一遍，又说全玩不可能，今天要把载具类全部玩完，理由是先玩没体验过的、了解自己擅长不擅长，以后不管被挑战什么运动都能赢；制作人猜她要带妹妹来，她笑说猜对了。她说竞速她全胜、开载具真好玩，想总有一天开真的摩托或汽车，接着要玩赛格威、射箭，玩不够。制作人说这场比试看来是他赢了，她说比试还没结束；制作人说时间晚了、她的计划留到下次，她说不，要他跟她走，「あなたに最高の休日を／プレゼントしてあげるわ」。

## 行为模式
- 约好的事 → 提前到；对手说要赢 → 「面白いじゃない」（0002～0004）
- 遇到新场所 → 兴奋地想全部试，但马上排优先顺序（0016～0020）
- 玩 → 也当成为下一场比试做准备，先找出自己擅长与不擅长（0022～0023）
- 想到新玩法 → 马上想带妹妹来（被制作人猜中）（0024～0025）
- 被宣布输了 → 说“还没结束”，当场把对方带去自己的计划（0034～0040）

## 关系
- プロデューサー：两人比“暑假休养计划”；他带她来休闲运动设施，她玩得很开心；他说自己赢了，她要把“最棒的休日”送给他（0033～0040）
- 佑芽（妹妹）：制作人猜她想带妹妹来，她说猜对了（0024～0025）

## 档案类事实
- 她的老家是类似高端训练设施的地方（她问「うちの実家みたいなところ？」，制作人说「高度なトレーニング施設でもなく」）（0009～0010）
- 她以前不知道有这种轻松玩运动的休闲设施（0012）
- 她在载具竞速里全胜，想总有一天开真的摩托或汽车（0026～0027）
- 她玩了载具类、赛格威，还要玩射箭（0020、0028）

## 不确定
- 0026「レース」具体是什么载具（卡丁车等）剧本没说。
- 0009 说的「うちの実家」是不是亲爱度线里的花海トレーニングセンター，本篇没说；在亲爱度第25话，那栋建筑是新建的，她第一次进去。
