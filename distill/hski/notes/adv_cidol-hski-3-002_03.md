# P卡 花海咲季【冠菊】 / 第3话 冠菊 第3话（adv_cidol-hski-3-002_03）

- 她的台词：23 行（含用匿名标签说的 0 行）
- 出场的人：咲季、プロデューサー
- 场景：接第2话当晚，她带制作人去一个能看星星、又赶得上宿舍门禁的地方（0001～0002、0008）
- 世界线：亲爱度（花海咲季）·P卡；制作人在制作的偶像：花海咲季

## 发生了什么
她带制作人到一处看星星的地方，说这里赶得上宿舍门禁，看到他困惑的样子很得意，说喜欢让什么都看穿的制作人吃惊。她指出夏季大三角的织女星、天津四、牛郎星，说一年只能见一次的两人她才不同情，要是她是织女，天河都游过去，问制作人「痛快でしょ？」。看到流星，她说许了愿：希望她的对手们都健康；制作人说什么都没许，梦想和愿望都要让她来实现，她说「叶えてあげるわ。いくらでも。」，当作今天让她放松了一天的谢礼。她宣布这次“暑假休养计划”比试算平手，夏天结束前再比一次。

## 她的关键台词
- 0002「ここなら寮の門限に／間に合うでしょ？」——她住宿舍、有门禁
- 0005「なんでもお見通しのプロデューサーを／驚かせるの、好きなのよね～。」——喜欢让制作人吃惊
- 0006「してやったり、って気分になる。」——得逞的快感
- 0008「――星が綺麗に見えるでしょ。」——她的计划是看星星
- 0011「えーっと、あれがベガ、デネブ……／アルタイルで夏の大三角形。」——认得夏季大三角
- 0013「1年に一度しか会えないふたり……／同情なんてしてあげない。」——对七夕故事的态度
- 0014「わたしが織姫なら、天の川くらい／泳いで渡ってみせるわ。」——自己会主动越过阻碍
- 0016「痛快でしょ？」——要对方认同她的做法
- 0021「わたしのライバルたちが、／健康でありますように、ってね。」——许的愿是对手健康
- 0026「叶えてあげるわ。いくらでも。／どんな願いだって。」——对制作人的承诺
- 0028「『夏の休養計画』勝負――／今回は引き分けにしておいてあげる。」——不认输，定为平手
- 0029「夏が終わらないうちに、／もう一度勝負するわよ！」——约下一次

## 行为模式
- 能让总是看穿一切的制作人吃惊 → 很得意（0004～0006）
- 听到悲剧性的故事 → 不同情，说换成自己会主动克服障碍（0013～0014）
- 许愿 → 许的是对手们健康（能继续较量），而不是自己（0021）
- 对方把愿望托付给她 → 爽快地说“多少都给你实现”，并说是谢礼（0025～0027）
- 比试结果对自己不利 → 宣布平手，约定再比（0028～0029）

## 关系
- プロデューサー：她喜欢让他吃惊（0005）；他说梦想和愿望都要她来实现，她说「叶えてあげるわ。いくらでも。」（0025～0026）
- 对手们：她的愿望是「わたしのライバルたちが、／健康でありますように」（0021）

## 档案类事实
- 她住宿舍，有门禁（0002）
- 她认得夏季大三角（织女星、天津四、牛郎星），知道织女、牛郎的故事（0011～0012）
- 她在流星上许的愿是对手们健康（0021）

## 不确定
- 0012「ベガが織姫で。／アルタイルが彦星だったかしら。」用「かしら」，说明她记得不太确定。
- 卡名「冠菊」（一种烟花）在本篇三话里都没出现。
- 0028 她说「『夏の休養計画』」，第1话是『夏休みの休養計画』，只是说法略有不同。
