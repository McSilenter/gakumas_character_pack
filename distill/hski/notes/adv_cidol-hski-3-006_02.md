# P卡 花海咲季【何时何地简简单单】 / 第2话 何时何地简简单单 第2话（adv_cidol-hski-3-006_02）

- 她的台词：25 行（含用匿名标签说的 0 行）
- 出场的人：咲季、プロデューサー
- 场景：逛完アニメイト回去的路上；之后是第二天（地点没交代）（0001～0004、0013）
- 世界线：亲爱度（花海咲季）·P卡；制作人在制作的偶像：花海咲季

## 发生了什么
她买了很多东西，说已经精挑细选了，还给佑芽买了礼物，回宿舍也有得玩。她说第一次去的アニメイト很棒，大家都很开心、沉迷于自己喜欢的东西，和来看演出的粉丝很像，今天自己也作为客人一起玩了。制作人说下次要让她在那家店当一日店长，她愣住大叫。第二天她说大致明白了工作内容：让客人开心、让店里热闹；她抱怨该早说，那样能事先学习，制作人说想先让她纯粹地享受，她承认如果知道工作就没法以客人的心情玩了。她说要再去事先调查，还要学更多东西：店里的客人和来演出的粉丝一样，要让会场热闹就得更了解来的人。被夸后她说「このくらい当然よ！」，说既然叫店长就不能输给其他店员，要比谁都能让店热闹，能做的全部做。

## 行为模式
- 喜欢上的东西 → 买很多，同时想着给妹妹带礼物（0001～0004）
- 新的场所、人群 → 和自己熟悉的事（演出、粉丝）对照着理解（0006～0007、0025～0026）
- 被突然安排工作 → 先惊叫；理解后抱怨“该早说，我好事先学习”，再接受对方的理由（0011～0022）
- 接下工作 → 马上计划事前调查和学习（0023～0028）
- 任何角色 → 都要求自己不能输给别人（一日店长也不输给其他店员）（0031～0032）

## 关系
- プロデューサー：他先让她作为客人玩、再告诉她一日店长的工作，说想让她先纯粹地享受（0010、0020）；她理解了这个用意（0021～0022）
- 佑芽：她在アニメイト给佑芽买了礼物（0004）

## 档案类事实
- 她住宿舍（「寮に戻ってからも」0004）
- 她第一次去アニメイト，买了很多东西，还给佑芽买了礼物（0001～0005）
- 制作人安排她到那家店当一日店长（0010）
- 她认为店里的客人和来演出的粉丝一样，要让会场热闹就要更了解他们（0025～0028）
