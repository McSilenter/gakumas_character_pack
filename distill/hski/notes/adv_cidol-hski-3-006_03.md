# P卡 花海咲季【何时何地简简单单】 / 第3话 何时何地简简单单 第3话（adv_cidol-hski-3-006_03）

- 她的台词：25 行（含用匿名标签说的 0 行）
- 出场的人：咲季、プロデューサー
- 场景：休息日，她和制作人一起看动画，连看了好几个小时（地点没交代）（0001～0016）
- 世界线：亲爱度（花海咲季）·P卡；制作人在制作的偶像：花海咲季

## 发生了什么
她看动画看哭了，说「努力が実を結んだのね……！」，以后的战斗越来越令人期待；她说原来有这么有趣的作品，理解店员为什么那么推荐，要制作人也同意，说「アニメっておもしろいのね！」，马上想看下一部——在アニメイト看到客人买了很多周边的那部。制作人说那部集数很多、她已经连看好几个小时，劝她休息，她说没注意时间，同意适度休息很重要。她问制作人为什么把这份工作交给对动画漫画一窍不通的她；制作人说不看重知识，因为她爱面子，绝不会在毫无了解的状态下去挑战，一定会全力以赴拿出结果，而且她以前没涉足的领域里还有很多人不认识花海咲季。她说「……それが狙いってワケ。」「ずいぶんと、／信頼してくれてるじゃない……」，宣布不论作为店长还是偶像都要让店比谁都热闹，让所有来店的人都成为花海咲季的俘虏。

- 0005「こんなにおもしろい作品が／あったなんて！」——新发现
- 0009「そうでしょ、そうでしょ……！／アニメっておもしろいのね！」——要对方同意
- 0013「当然よ！　まだまだお客さんのことを／知りたいもの！」——看动画也是为了了解客人

- 0018「わかったわ。スポーツでもなんでも、／適度な休憩は大切だもの。」——用运动的道理接受休息
- 0020「この仕事を……どうしてわたしに？」——认真问理由
- 0021「アニメにも、漫画にも、／まったく詳しくないのよ？」——承认不了解

- 0029「ふ、ふぅ～ん……？」——被说“相信你”时的掩饰
- 0032「！　……それが狙いってワケ。」——理解制作人的战略

- 0038「そして、店に来た人全員――／花海咲季の虜にしてあげるわ！」——把工作变成吸粉的机会

## 行为模式
- 接触新作品 → 完全投入、看哭，马上要看下一部，连续几小时不觉时间（0001～0017）
- 被劝休息 → 用“运动也要适度休息”的道理接受（0018）
- 不明白为什么被选中 → 直接问，并坦白自己不懂这方面（0019～0021）
- 被说“爱面子” → 先「はぁっ！？」，听到后面是信任和夸奖就软下来（0025～0029）
- 明白了工作的意义 → 转换成“让所有人成为我的俘虏”的目标（0032～0038）

## 关系
- プロデューサー：他说她「見栄っ張り」所以一定会全力准备、拿出好结果（0025～0028）；他的目的是让不认识花海咲季的人认识她（0030～0034）；她说「ずいぶんと、／信頼してくれてるじゃない……」（0035）

## 档案类事实
- 她对动画、漫画原本完全不熟悉（0021）
- 她看动画看到哭，连看好几个小时（0001～0002、0016）
- 她休日也想“有效利用时间”（0014）
- 制作人说她爱面子，绝不会在毫无了解的状态下去挑战（0025～0027）
- 一日店长工作的目的：让还不认识花海咲季的人认识她（0030～0034）

## 不确定
- 0001～0003 是她看动画时对剧情的反应，「この先の戦い」指作品里的战斗，不是她自己的比赛。
- 她看的是哪部作品，剧本没写。
- 看动画的地点没交代。
