# P卡 花海咲季【Campus mode!!】 / 第2话 Campus mode!! 第2话（adv_cidol-hski-3-008_02）

- 她的台词：36 行（含用匿名标签说的 0 行）
- 出场的人：咲季、プロデューサー、女の子
- 场景：前半制作人告诉她『Campus mode!!』的第一份工作（0001～0030）；后半是在中学办完小型演唱会之后（0031～）
- 世界线：亲爱度（花海咲季）·P卡；制作人在制作的偶像：花海咲季

## 发生了什么
穿上『Campus mode!!』的她干劲十足，说现在什么难关试镜都能赢，结果制作人说第一份工作是去中学开小型演唱会，她失望地说本以为要穿着“战斗服”去比拼。她猜这是为了靠脚踏实地增加粉丝、在年轻人的SNS上扩散，制作人说理由更简单：偶像重要的工作是散播『憧れ』，并提起她说过憧憬『Campus mode!!』的偶像（0019，她自己那句话的回想）。她明白现在轮到自己对孩子们做前辈们做过的事，向制作人和学园前辈道歉，说那态度配不上这身服装，表示要让全校学生都憧憬她。演出后一个女孩说想成为像咲季那样的偶像，她高兴得叫出来；她问制作人自己今天是否成了孩子们“憧れのアイドル”，说其中也许有人第一次看的偶像演出就是她，也许有人会进初星学园，感觉像多了100个妹妹，作为她们的姐姐不能出丑，「きっとこれが……／アイドルの感覚なのね」。

## 行为模式
- 工作和期待的“比赛”不符 → 当面抱怨，再自己找策略上的解释（0008～0014）
- 被点出工作的意义 → 马上理解、道歉，并把它说成“让所有人都憧憬我”（0021～0030）
- 被孩子憧憬 → 毫不掩饰地狂喜，接着认真思考自己对她们的责任（0036～0048）
- 理解陌生的关系时 → 套用“姐姐和妹妹”的框架（0045、0047）
