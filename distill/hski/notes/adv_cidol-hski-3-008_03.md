# P卡 花海咲季【Campus mode!!】 / 第3话 Campus mode!! 第3话（adv_cidol-hski-3-008_03）

- 她的台词：29 行（含用匿名标签说的 0 行）
- 出场的人：咲季、プロデューサー
- 场景：她穿『Campus mode!!』上台前（或演出中）从台上／台侧看观众席，和制作人说话（0001～0007、0029～0030）；『N.I.A』期间（0012）
- 世界线：亲爱度（花海咲季）·P卡；制作人在制作的偶像：花海咲季

## 发生了什么
她让制作人看观众席：前几天开过小型演唱会的学校的孩子们来了，真的成了她的粉丝；那边是她刚入学时在学园野外舞台唱歌时支持她的人，那边是第一次礼堂演出时热烈响应的人。她说花海咲季每上一个台阶，支持的声音就一点点增加；第一次读粉丝来信的日子一辈子忘不了；参加『N.I.A』后粉丝一下子多了，回忆越来越多，力量会涌上来，不是错觉——肌肉没变多、身体没变软，技术也停滞，简直是龟速前进，却还是不可思议。她说过偶像是她能冲世界第一的竞技，去年的她这么想：体格小不容易成为劣势、技术熟练速度一直受考验、美貌能派上用场；现在她仍认为偶像是竞技，但意思已经变了很多，「アイドルって……奥が深いわ」。制作人说这还只是开始，她说知道，为了看到更远处，必须让大家更喜欢她，然后向观众宣告要用『Campus mode!!』把最好的回忆烙进他们的记忆。

## 行为模式
- 面对粉丝 → 一群群认出来、记得每群人是在哪一步开始支持她的（0002～0009）
- 回顾自己 → 不夸大实力的进步，直说肌肉、柔软度、技术都没怎么长，再说说不清的力量来自粉丝（0014～0017）
- 看法变了 → 不否认原来的说法（偶像仍是竞技），而是说意思变了（0018～0024）
- 被说“这才刚开始” → 立刻接住，把目标往前推（0026～0028）

## 关系
- プロデューサー：她让他一起看观众席，对他说出看法的变化（0001～0025）；他说「まだまだ序の口ですよ。」（0026）
- 粉丝：中学的孩子们、入学时野外舞台的支持者、第一次礼堂演出的观众（0002～0007）；她称观众「あなたたち」（0029）

## 不确定
- 0022「去年のわたしは」：“去年”指她决定当偶像、入学之前的时候，说明本篇是她入学的第二个年度、或入学当年跨过了新年，剧本没交代；可作为年龄和入学时间存疑的时间线证据。
- 想当偶像的理由存疑的新证据：0020～0021 说偶像是体格小不吃亏、技术和美貌能占优的竞技，和亲爱度第3话（体格不占优、当不了世界第一）、第8话（体格不好也能冲世界第一）的说法一致方向，并列。
- 0018「そう言ったでしょう」：她什么时候对制作人说过，本篇没说。
- 0016「技術だって伸び悩んで」和亲爱度第7话 0066 等处“没成长”的自我评价方向一致，是她的主观说法。
