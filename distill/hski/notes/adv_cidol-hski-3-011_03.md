# P卡 花海咲季【樱花相册】 / 第3话 樱花相册 第3话（adv_cidol-hski-3-011_03）

- 她的台词：43 行（含用匿名标签说的 0 行）
- 出场的人：咲季、プロデューサー
- 场景：休息日（0002），第2话的第二天（0004「昨日」）；中午她亲手做了午饭（0037）；地点没交代
- 世界线：亲爱度（花海咲季）·P卡；制作人在制作的偶像：花海咲季

## 发生了什么
休息日她宣布要和制作人谈个痛快，因为昨天回想过去的对话有了很多发现：他太喜欢她、还时不时逗她取乐。制作人笑着道歉，说她那种坦率是很大的魅力、作为制作人想确认一下，她一听就高兴地原谅了（制作人心里说「そういうところです」）。她说认识这么久，彼此应该积了很多话要说；制作人说她有不满就立刻超大声说出来，肚子里没什么存货，她差点认了，又说有：她的制作人好像有很多事瞒着她——比如常常和她父母见面开“报告会”。制作人承认是真的，说不是隐瞒、只是没说，她骂「変わらないわよバカぁ！」，要把隐瞒的事全谈清楚。谈完她说很充实、报了一箭之仇，作为谢礼做午饭给他；制作人说厨艺进步了，她说给妹妹以外的人做饭的机会多了、有过差评，不甘心就认真练了。制作人说「そういうところなんですよ」，宣布接下来30秒不再隐瞒：制作人不能太喜欢负责的偶像，不能让偶像察觉沉重的执着，偶像和制作人必须对等。她说这是P科的教导吧、但已经太迟了，他最喜欢她早就暴露了；制作人说那种程度暴露也无妨，她呆住追问什么意思，他说30秒到了。最后他说她讲过“契约结束也不放手”，他也是同样的心情，今后也请多关照；她憋了一声后回「こちらこそ！」，说不管两人相遇的季节再来多少次，「あなたは永遠に、／わたしのプロデューサーよ！」。

## 行为模式
- 发现对方的“小动作” → 不藏着，找个日子当面追问，说成要“谈个痛快”（0002～0007、0024～0032）
- 被夸坦率、可爱 → 当场高兴、原谅对方，于是又被对方说“就是这种地方”（0010～0013、0042～0044）
- 不满 → 立刻、大声地说出来（0019～0020、0029～0031）
- 做饭被批评 → 不甘心，认真练到被夸（0039～0042）
- 自己占上风时被对方意味深长的话打乱 → 呆住、结巴追问（0060～0064）
- 被对方认真表态 → 先憋住一声，再用更大的宣言回应（0067～0071）

## 关系
- プロデューサー：她称他「わたしのプロデューサー」（0024、0071）；骂他「バカぁ」（0031）；给他做午饭（0037）；她认定他从一开始就最喜欢她（0057～0059）；他说“契约结束也不放你走”的心情和她一样（0065～0067）
- 父母：制作人常和她父母见面开报告会，她之前不知道（0027～0028）
- 佑芽（妹）：未出场；她以前主要给妹妹做饭（0040）

## 档案类事实
- 制作人经常和她父母见面，开“报告会”（0027～0028）
- 她给妹妹以外的人做饭的机会多了，有过差评，不甘心就认真练了，制作人说厨艺进步了（0038～0042）
- 休息日中午她给制作人做了午饭（0002、0037）

## 不确定
- 0027 父母和制作人见面的事：亲爱度第10.5话说制作人在招募她当天和她父母熟了，可以接上；和第10话『父母几乎不回家』的存疑（同第32话母亲当训练师）有关，本篇父母能“经常”和制作人见面，也算一条材料，不当冲突。
- 0040「不評だったことがあって」：谁给的差评没说；亲爱度第4话制作人吃她的便当很勉强，可参照。
- 0068「―――――――――――――ぅ。」是她憋住的声音，算进行数。
- 0050～0055 制作人说的「P科の教え」（0052 是她的推测，制作人答「ええ」）。
