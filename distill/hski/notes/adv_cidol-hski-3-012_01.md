# P卡 花海咲季【雨后的鸢尾花】 / 第1话 雨后的鸢尾花 第1话（adv_cidol-hski-3-012_01）

- 她的台词：38 行（含用匿名标签说的 0 行）
- 出场的人：咲季、プロデューサー
- 场景：她做好改良版的饭给制作人吃；地点没交代
- 世界线：亲爱度（花海咲季）·P卡；制作人在制作的偶像：花海咲季

## 发生了什么
她端出「花海咲季特製、／トップアイドル養成ごはん改」，说外观、气味、口感、营养都完美，有30种变化，还会按吃的人定制，这份是专为制作人做的。制作人说味道很棒，她松了口气，说怕不合口味一直提心吊胆，又猜他想说“以前让我吃了一堆改良前的菜”。制作人问为什么一下子改进这么多，她说上周早上醒来时忽然想到，想让「あいつら」、也让他吃到好吃的饭；她试做了很多次，刚才也给同学们吃了，大受好评，连手毬都难得地向她道谢，本来就是朋友，感觉更要好了。制作人说她的缺点越来越少；她看出他有心事，要他说、禁止说“这不是该对负责偶像说的事”。制作人说课上做了“让负责偶像组组合”的模拟，再次认识到她极适合组合活动；她猜中他在想“是不是组合更适合她、能走得更高”，说要骂他：要他相信他选的独唱偶像花海咲季、相信他的制作，就算是“和可靠伙伴组成组合的花海咲季”她也要赢给他看。制作人想起明知她有组合适性、仍只招募她一个人的理由（他说了什么剧本没写），她慌了，说早就猜到会是这样，然后说「――わたしも。」「あなたを独占したい。」，要他今后也只制作她一个人。

## 行为模式
- 拿出用心做的东西 → 先大张旗鼓地介绍，被夸后才承认一直在担心（0002～0013）
- 察觉对方有心事 → 主动追问，先把对方推托的话禁掉（0026～0029）
- 对方怀疑“别的路会不会更好” → 斥责他，要他相信自己和他自己的判断，并宣称连假设中的自己也要打败（0035～0042）
- 对方说出意外的真心话 → 先慌乱，装作早就猜到，再小声说出同样的心意（0047～0052）

## 关系
- プロデューサー：她给他做专属菜单（0008）；叫他「プロデューサー」，自称他的「担当アイドル」（0029）；要他相信他选的「ソロアイドル・／花海咲季」（0039）；说想独占他、要他只制作她一个人（0050～0052）
- 手毬：说本来就是朋友，吃了她的饭难得向她道谢，感觉更要好了（0023～0024）
- クラスメイトたち／「あいつら」：她把改良版的饭也给同学们吃了，大受好评（0021～0023）

## 不确定
- 0047～0050：制作人说出“只招募你一个人的理由”的内容剧本没写（选项或省略），从她 0049「――わたしも。」、0050「あなたを独占したい。」看，制作人的话大意是想独占她，但这是推测。
- 0021「あいつら」指谁：接下来说给同学们吃过、提到手毬，像是指同学们（含手毬），剧本没明说；手毬是不是她的同班同学也没明说。
