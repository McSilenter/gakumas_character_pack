# P卡 花海咲季【雨后的鸢尾花】 / 第3话 雨后的鸢尾花 第3话（adv_cidol-hski-3-012_03）

- 她的台词：22 行（含用匿名标签说的 0 行）
- 出场的人：咲季、プロデューサー
- 场景：她的练习结束后，制作人特地来接她（0001～0002）；地点没交代
- 世界线：亲爱度（花海咲季）·P卡；制作人在制作的偶像：花海咲季

## 发生了什么
练习结束，制作人来接她，说想谈谈。她说练习很顺利，舞蹈和唱歌突飞猛进，手毬和ことね也是，自己大大成长、还附送更强的对手，太让人兴奋，都多亏他提议合练，“完全是我喜欢的制作计划”。制作人说想多少利用一下她的组合适性，没想到效果这么好；她看他的脸，问是不是又在烦恼。制作人说有快溢出来的想法，虽然违反P科的教导，问她能不能听；她得意地说他终于明白隐瞒没用了，作为他的负责偶像什么都听。制作人说这不是烦恼而是炫耀：进P科前翻学生名册时有无数选择，「『花海咲季を選んだ俺』が、最強です。」她说他越来越像她了。制作人说和她在一起很骄傲、每天都快乐；她说她也是，明明尽是困境，回头看却全是笑着的记忆；模拟根本不用做，现实已经说明了「『あなたにプロデュースされている／わたし』こそが、最強よ。」谁都、连神也不许说不是；最后说要一起继续证明两人这一对是世界最强。

## 行为模式
- 对手变强 → 当成附送的好事，兴奋（0006～0007）
- 看到制作人表情不对 → 立刻追问是不是在烦恼（0012）
- 对方终于肯说心里话 → 得意，说“隐瞒是没用的”（0015～0017）
- 被对方用她式的自信表白 → 先说“越来越像我了”，再用同样的句式更大声地回过去（0024～0035）

## 关系
- プロデューサー：他来接她（0002）；她说合练计划是她喜欢的（0008～0009）；自称「あなたの担当アイドル」（0017）；说他越来越像她（0025）；把两人称为「あなたとわたしのペア」（0035）
- 手毬、ことね：未出场；她说她们也在飞速成长，是越来越强的对手（0005～0007）
