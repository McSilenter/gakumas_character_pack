# P卡 花海咲季【全力以赴！】 / 第2话 全力以赴！ 第2话（adv_cidol-hski-3-015_02）

- 她的台词：27 行（含用匿名标签说的 0 行）
- 出场的人：咲季、プロデューサー
- 场景：为和手毬、ことね共演的演出做准备（0002）；地点没交代
- 世界线：亲爱度（花海咲季）·P卡；制作人在制作的偶像：花海咲季

## 发生了什么
她问制作人为了在下次演出赢手毬和ことね该做什么，制作人说要把要唱的『がむしゃらに行こう！』磨得更锋利。她说这首已经学会，但制作人认为她还能更好？制作人说这首不是只为她写的，甚至和她“聪明地尽力”的作风相去甚远；她问是不是说和花海咲季不合，制作人说只看一面是，但她还有另一面：明知胜算低、怕比试也笑着挑战，比谁都拼命。她说也许吧，但她的那种拼命是难看的垂死挣扎、没有未来，不是好的「がむしゃら」。制作人说不让任何人看到满身泥泞爬行的样子，就是花海咲季这个偶像；她说在妹妹面前、在粉丝面前，她想当帅气的姐姐。制作人说那是众所周知的魅力，但她藏起来的样子——发抖、握着断剑、伏地哭泣——也有魅力，要动员全部魅力成为无敌偶像。她说要不是他说的根本不值一听，就算是他也没法轻易点头，因为怕被幻灭、有粉丝不想看软弱的她；然后说「だから――――……」，要把难看的、没给任何人看过的软弱的自己、「メッキの剥げた花海咲季」放进这首拼命的歌里，既然他说那有魅力。她说好像以前说过类似的话，制作人说不一样、比那时前进了一步。她决定把这首不是为她写的歌变成她的歌，对手毬、ことね和初星学园的偶像们说「この楽曲、花海咲季がいただいたわ！」。

## 她的关键台词
- 0002「次のライブで、手毬とことねに／勝つために、」——共演也是比赛
- 0006「すでに習得済みの楽曲だけど……／わたしなら、さらに上を目指せる。」——自信
- 0013「花海咲季と相性の悪い曲だっていうの？」——敏感地反问
- 0018「見苦しい悪あがきで、ジリ貧で、／未来がないもの。」——对自己“拼命”的否定评价
- 0021「ええ……妹の前では、ファンの前では、／かっこいいお姉ちゃんでありたいもの。」——不示弱的理由
- 0027「あなたの言葉じゃなかったら、／一考にも値しない意見よ。」——只信他
- 0029「幻滅されるの、怖いもの。」——承认害怕
- 0030「弱くて見苦しいわたしなんて、／見たくないファンが、いるもの。」——对粉丝的顾虑
- 0032「がむしゃらな歌に、乗せてみる。」——决定
- 0033「かっこ悪くてみっともないわたしを。／誰にも見せてこなかった、弱い／わたしを。メッキの剥げた花海咲季を。」——要展示的是藏起来的自己
- 0035「なんだか、前にも似たようなことを／言った気がするわ。」——自己也察觉到重复
- 0039「わたしの曲にしちゃいましょう！／だってわたしにぴったりだもの！」——把别人的歌变成自己的
- 0041「この楽曲、花海咲季がいただいたわ！」——宣战式的收尾

## 行为模式
- 被说“这首歌和你不搭” → 先敏感地反问，听完另一面后贬低自己的拼命是“难看的挣扎”（0013～0019）
- 被要求展示软弱 → 说出怕被幻灭、怕粉丝失望的真实理由，但因为是他说的，最后决定试试（0026～0034）
- 下决定时 → 用「……決めたわ。」开头，马上转成强势宣言，并向对手们“宣战”（0037～0041）

## 关系
- プロデューサー：她说他的话才值得考虑（0027）；因为他说软弱的她也有魅力，她决定展示（0034）
- 佑芽（妹）、粉丝：她想在两者面前都当「かっこいいお姉ちゃん」（0021）
- 手毬、ことね、初星学園のアイドルたち：演出上的对手，她向她们宣布拿下这首歌（0002、0040～0041）

## 档案类事实
- 下次演出她要唱『がむしゃらに行こう！』，这首她已经学会，不是专为她写的歌（0005～0006、0009、0038）
- 她想在妹妹和粉丝面前当帅气的姐姐（0021）
- 她怕被幻灭，认为有粉丝不想看软弱难看的她（0029～0030）

## 不确定
- 0035「前にも似たようなことを／言った気がするわ」：像是指【Fighting My Way】第2话她决定在新曲演出上『はだかになってみせる』的那次，本篇没明说。
- 0031「だから――――……」后面接 0032，中间不缺内容。
- 【译文】0011～0012 原文「咲季さんの、クレバーに／ベストを尽くすスタンスとは」「かけはなれた歌かもしれない」是“和你聪明地尽力的作风相去甚远”，译文“在捷径上狂奔的风格”意思有出入；0015～0016 译文加了“即使畏惧较量／你却从未逃避过挑战”，原文是「勝負を恐れながらも笑って挑む」（怕比试也笑着挑战）。
