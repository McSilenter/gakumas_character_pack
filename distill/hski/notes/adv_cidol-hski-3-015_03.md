# P卡 花海咲季【全力以赴！】 / 第3话 全力以赴！ 第3话（adv_cidol-hski-3-015_03）

- 她的台词：10 行（含用匿名标签说的 0 行）
- 出场的人：ことね、手毬、咲季
- 场景：三人共演演出的彩排（0002、0024）；她唱完回到两人身边
- 世界线：亲爱度（花海咲季）·P卡；制作人在制作的偶像：花海咲季（制作人本篇未出场）

## 发生了什么
她在彩排里全力热唱，手毬说难以置信、没有职业自觉，ことね说体力怪物咲季这点程度不会累，手毬却说也要为月村手毬的骄傲唱得比咲季更厉害，并说自己能顺利练出体力、保持最好状态，是靠咲季和她做的饭。ことね也说咲季连竞争对手都照顾得无微不至，没有她自己不知会怎样，「咲季と会えて、よかった。」（不好意思当面说）。她唱完回来，问两人觉得她压倒性的彩排如何，看到两人的表情发问。手毬说要用歌声让得意忘形的1年目偶像知道厉害，她说「面白い挑発じゃない、手毬！」；ことね也说要用超可爱的舞蹈打败超嚣张的咲季，她反而高兴地说今天怎么了、这么大放送真少见。ことね说挑衅被当成了福利，手毬说她就是那种人。手毬对她说「いつもありがとう、／一緒に走ってくれて。」，她不太明白，还是回「どういたしまして」，说今天的演出不只献给粉丝，也献给她们俩，要拼命地唱、跳，让她们开心。

## 行为模式
- 彩排也不留力，全力热唱（0001～0004，手毬、ことね说）
- 被对手下战书 → 高兴，当成难得的“大放送”（0029、0032～0033）
- 被认真道谢却不明所以 → 照样大方接受（0037～0038）

## 关系
- 手毬：叫「手毬」；手毬说体力和状态多亏她和她做的饭（0011～0012），向她挑衅（0028），又道谢「いつもありがとう、／一緒に走ってくれて。」（0037）
- ことね：叫「ことね」；ことね叫她「咲季」，背后说她连对手都照顾、「咲季と会えて、よかった。」（0013～0017），当面却挑衅她（0030～0031）
- 两人是她的对手，她把这场演出也献给两人（0039）
