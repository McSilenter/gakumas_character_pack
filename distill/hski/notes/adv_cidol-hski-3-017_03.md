# P卡 花海咲季【Wildest Flower】 / 第3话 Wildest Flower 第3话（adv_cidol-hski-3-017_03）

- 她的台词：24 行（含用匿名标签说的 0 行）
- 出场的人：咲季、燐羽、星南
- 场景：她在唱未完成的新曲时，星南和燐羽来了（0001～0004）；和作曲家开会之前（0006）；地点没交代
- 世界线：亲爱度（花海咲季）·P卡；制作人在制作的偶像：花海咲季（制作人本篇未出场）

## 发生了什么
她唱完未完成的新曲说“不对”，星南和燐羽来了，她说正好、请她们帮忙参谋，说明情况后说想在和作曲家开会前定下方针。星南说以这首为基础改成适合现在的她很好，她变了、曲子也该变，这条路会成为故事传达给粉丝。燐羽说用不着重做，硬把它变成自己的歌就行；她说说得轻巧，星南说「これだから『SyngUp!』は……」，燐羽抗议别把她和那些人混为一谈。她说燐羽也有道理：把不是为自己写的歌当成自己的歌来唱，是每个偶像都在做的事。燐羽说独占已有曲子的诀窍是让别的偶像再也不敢唱，她说现在没在说这个。她道谢说多亏两人方针定下了、明白了自己真正想做的：这首未完成的曲子本该是『あいつ』唱的，她要夺过来变成自己的，让制作人、她们、粉丝和「花海咲季に！！」知道这是她的歌；变成自己的之后再挺胸要求改得更适合她。燐羽说像样了，星南说开会时要给作曲家看现在的她，所以要好好学会这首曲子；她请两人帮忙，说新曲完成之时，粉丝、制作人、她们，「全員まとめて、このわたしのものよっ！」。

## 行为模式
- 卡住时 → 抓住身边的人直接请教（0004～0007）
- 听到粗暴的建议 → 先吐槽“说得轻巧”，再承认有道理，转成自己的话（0014～0020）
- 对方跑题、说得太狠 → 直接打断（0024）
- 想清楚后 → 用“夺取”“变成我的”的强势说法，把要说服的对象一路列到自己（0029～0036、0042～0044）

## 关系
- 星南：直呼「星南」（0004）；支持她以原曲为基础改编（0008～0011），提醒她要先学会这首（0039～0040）
- 燐羽：直呼「燐羽」（0004）；燐羽叫她「咲季お姉ちゃん」（0003）；她吐槽燐羽的建议又承认一理（0014～0017），拦住燐羽跑题（0024）
- 两人：她请两人帮忙练这首曲子（0041），把她们也算进“全员都是我的”（0043～0044）
- プロデューサー：未出场；她要让他也知道这是她的歌（0033）

## 档案类事实
- 新曲以原定的未完成曲子为基础，她要先把它唱成自己的，再要求改得更适合她（0029～0036）
- 和作曲家开会前，她请星南、燐羽帮忙定方针、练歌（0006、0041）
