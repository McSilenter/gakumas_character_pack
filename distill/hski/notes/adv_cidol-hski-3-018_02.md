# P卡 花海咲季【荆棘之路】 / 第2话 荆棘之路 第2话（adv_cidol-hski-3-018_02）

- 她的台词：31 行（含用匿名标签说的 0 行）
- 出场的人：咲季、プロデューサー
- 场景：『H.I.F』之前，制作人提出增加休息日（0001～0002）；地点没交代
- 世界线：亲爱度（花海咲季）·P卡；制作人在制作的偶像：花海咲季

## 发生了什么
制作人说要增加休息日，她说『H.I.F』前提议减少练习真像他，马上表示服从：她本来就为了完成高强度练习需要高质量休养，有计划地全力休息才高效成长，身体休息已经足够，他说的是“心的休养”吧；制作人说她又把制作人的台词说完了。她说心的休养日不能照平常的过法，全力发呆很有意义，但既然身体休息够了，可以往“享受”方向转，和他商量。制作人建议增加她喜欢的瑜伽、散步，她说好，学喜欢的科目也是奖励；制作人说可以再偏向玩，她说那就玩游戏，想玩的游戏要空出整块时间全力玩。她说入学初星学园后爱好大大增加：动画、漫画、游戏、瑜伽、香薰，契机有朋友的影响、有联动；最初是觉得既然作为“花海咲季”这种娱乐站在娱乐界，就得学很多娱乐，但第一次接触的作品太有趣，那些想法全吹飞了，「世界には……／こんなにも楽しいものがあったのね。」她说对偶像来说人生全部是武器，心的休养得到的东西以后一定有用，一石二鸟。制作人想知道作品名、和她一起玩，她说有能多人玩的、一起玩吧。她又说想去看演出——他好像故意避开了；制作人说心的休养该和工作分开，她说没有和偶像无关的娱乐，最近几乎每晚听秦谷美鈴入睡，広喜欢的偶像要唱『ガラクタロード』，时间合适就和2組的人一起去看。最后说好好休息、尽情享受、大量学习，以最佳状态前进。

## 行为模式
- 制作人提出意外的安排 → 先点出“这时候提真少见”，立刻服从并把理由自己说完（0002～0008）
- 安排休息 → 也要计划、也要全力，分清“身体”和“心”的休养（0005～0013）
- 谈娱乐 → 从功利出发，承认后来是真心喜欢，最后又归结到“人生全部是武器”（0024～0029）
- 制作人避开工作相关的事 → 看穿他的用意，仍坦白说想去看演出，并说明理由（0034～0040）

## 关系
- プロデューサー：她服从他的休养安排（0004）；邀他一起玩多人游戏（0031）；看穿他故意不提演出（0034）
- 秦谷美鈴：她最近几乎每晚听美鈴的歌入睡（0038）
- 広：広喜欢的偶像要唱『ガラクタロード』（0039）
- 2組の子たち：她打算和她们一起去看演出（0040）
- 朋友：爱好增加有朋友的影响（0023）
