# P卡 花海咲季【荆棘之路】 / 第3话 荆棘之路 第3话（adv_cidol-hski-3-018_03）

- 她的台词：22 行（含用匿名标签说的 0 行）
- 出场的人：咲季、プロデューサー
- 场景：她唱完『ガラクタロード』（或其中一段）后问制作人感想（0001）；地点没交代
- 世界线：亲爱度（花海咲季）·P卡；制作人在制作的偶像：花海咲季

## 发生了什么
她唱完问制作人如何，制作人说看出她想做什么了：马上在用最近体验得到的新手牌。她说最直接的参考是和広她们去看的演出：现场听『ガラクタロード』，觉得这首扩展性很高，原来可以唱得那么可爱；100プロ的偶像每个人都在唱自己的『ガラクタロード』，那她就唱花海咲季的，把人生放进去，造出只属于她的武器。制作人说听着像被温柔地鼓励，她说那是他给她的手牌；说听得出她真心享受，她说放进了第一次玩某个游戏时的心情；说有进攻的一幕，她说是拜某位传奇玩家为师修行『ザ・クイーン・オブ・あにまるズ』的经验，这些是游戏制作者和玩家们给的手牌。她说星南说过手牌多是花海咲季的武器，问这样用对不对；制作人说有一种很受欢迎的游戏类型『デッキビルダー』，把游戏中得到的手牌有效组合成强力牌组，她说「わたしみたいなゲームね！」。制作人说她积累的经验成了无数手牌，让花海咲季发光；她说以为自己是一直逃避的人生，原来不是一无是处？制作人说她的人生没有一步是绕远路，她说「あなたがそうしたのよ。」：佑芽给了她最强的王牌，而他相信她收集的所有牌，那她要回应他的信任，组一副最强牌组，名字是「トップアイドル・花海咲季よ！！」。

## 行为模式
- 被制作人说中意图 → 笑着承认，然后一条条说明每个灵感的来源（0004～0017）
- 被夸某个部分 → 说出那部分来自谁（他、游戏制作者、玩家）（0012、0017）
- 用了新办法 → 会问“这样用对吗”，确认后马上来劲（0018～0022）
- 被肯定过去 → 先半信半疑地说“原来不是一无是处？”，再把功劳给对方并发誓回应（0025～0030）

## 关系
- プロデューサー：她说温柔的部分是他给的手牌（0012）；他相信她收集的所有牌，她要回应他的信任（0029～0030）
- 広：和広她们一起去看了演出（0005）
- 星南：她引星南说的“手牌多是花海咲季的武器”（0018）
- 佑芽：给了她「最強の切り札」（0028）

## 档案类事实
- 她和広她们一起去看了100プロ偶像唱『ガラクタロード』的演出（0005～0008）
- 她唱的是自己版本的『ガラクタロード』（0009）
- 她拜某位传奇玩家为师，修行过游戏『ザ・クイーン・オブ・あにまるズ』（0016）
- 她觉得『デッキビルダー』类游戏像自己（0020～0022）
- 她说佑芽给了她最强的王牌（0028）
