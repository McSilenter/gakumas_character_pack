# P卡 花海咲季【Agitato】 / 第1话 Agitato 第1话（adv_cidol-hski-3-022_01）

- 她的台词：25 行（含用匿名标签说的 0 行）
- 出场的人：咲季、プロデューサー
- 场景：她和制作人的会议（0001）；地点没交代
- 世界线：亲爱度（花海咲季）·P卡；制作人在制作的偶像：花海咲季

## 发生了什么
会议一开始她就说制作人有重要的事要讲，制作人问她怎么知道，她说学园里在传『大型タイアップ企画』，他不可能不出手。企划是和化妆品厂商的联动，制作人说日程会很紧，她说没问题，最近休养得多、体力充足；她看资料觉得企划已推进很多，制作人说竞标已经赢了，她说就知道、还是那么性急。她读出要求：小恶魔主题的服装、以『夜の街』为舞台的广告，对方要兼具『フレッシュな健康美』和『小悪魔の色気』两种相反魅力的偶像；制作人说正是她，她傻笑「わかっているじゃな～い♡」。制作人拿出设计师做的服装，说『黒』和『赤』是最衬她的颜色之一，所以用法更考验品味；她说他对她的服装总是很严格，他认可的服装她很喜欢，尤其是心形尾巴，甚至觉得本来就长在她身上。她说所有工作都全力以赴、不搞特殊待遇，但被期待就更闪耀也是花海咲季的特性，要拿出超出大家期待的「小悪魔アイドル・花海咲季」，接下新作香水的「ミューズ」，迷倒观众。

## 她的关键台词
- 0004「ふふっ……わかるわよ。／だってあなたのことだもの。」——对制作人的了解

- 0011「最近は休養を多めに取っているし、／たっぷり体力が残っているもの。」——近况
- 0014「そんなことだろうと思ったわ。／相変わらずせっかちなんだから。」——对他的性急习以为常
- 0016「『フレッシュな健康美』と／『小悪魔の色気』……／相反する魅力を兼ね備えたアイドル。」——这次的要求
- 0018「えへへ……わかっているじゃな～い♡」——被说正合适就高兴
- 0024「ふふふっ……プロデューサーったら、／いつもわたしの衣装に厳しいものね。」——对他的了解
- 0026「そんなあなたが納得した衣装だもの。／うんっ、とっても気に入ったわ♪」——信任他的眼光
- 0028「もともとわたしに生えていた／ような気さえしてきたわ。」——喜欢心形尾巴
- 0030「花海咲季にとって、すべての仕事は／全力で臨むもの。特別扱いなんて／するつもりはない。だけど……」——工作观
- 0031「期待されればその分輝くのも、／また、花海咲季の特性よ！」——被期待就更亮
- 0033「皆さんの期待を上回る、／小悪魔アイドル・花海咲季を／お出ししなくちゃ！」——要超出期待
- 0034「プロデューサー！／新作フレグランスのミューズ！　／このわたしが引き受けたわ！」——接下工作

## 行为模式
- 制作人还没开口 → 她先猜中要谈什么，并说出理由（0001～0006）
- 被说日程紧 → 一句「問題ないわ」，拿近况作根据（0010～0011）
- 看资料 → 自己读出企划要点，猜到他已经抢先办好（0012～0016）
- 被说正合适 → 傻笑着说“你很懂嘛”（0017～0018）
- 被期待 → 把它说成自己的“特性”，宣言要超过期待（0030～0035）

## 关系
- プロデューサー：她说「だってあなたのことだもの」，知道他会去抢大工作、性急、对她的服装严格（0004～0006、0014、0024）；信任他认可的服装（0026）

## 档案类事实
- 她接下和化妆品厂商联动的新作香水广告，做「ミューズ」；服装是小恶魔主题、黑色系，带心形尾巴；广告以『夜の街』为舞台（0008、0015～0016、0020～0027、0034）
- 制作人说『黒』和『赤』是最衬她的颜色之一（0022）
- 她最近休养得多、体力充足（0011）
