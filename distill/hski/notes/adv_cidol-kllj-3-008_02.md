# P卡 葛城リーリヤ【极光】/第2话 极光 第2话（adv_cidol-kllj-3-008_02）

- 她的台词：29 行（含用匿名标签说的 0 行）
- 出场的人：咲季、リーリヤ、プロデューサー
- 场景：咲季应邀来到リーリヤ约定的地方（夜里，只写“约定的场所”）
- 世界线：亲爱度（葛城リーリヤ）·P卡；制作人在制作的偶像：葛城リーリヤ

## 发生了什么
リーリヤ在ライブ失败后找她，问怎样才能变成她那样。她说没想到会被这么说，自己尊敬リーリヤ，不需要变成她（0011～0014）。她说在同班时多次看到リーリヤ重新站起来，觉得“不会折断”（0018～0021）。她说リーリヤ像“那孩子”，并自报“花海咲季，未来的トップアイドル”，让リーリヤ也说出口（0034、0042～0047）。离开前对制作人的感谢说“只是真心话”（0055）。

## 行为模式
- 被求助 → 先问发生了什么，再说出观察到的事实，而不是套话（0003、0018～0021）
- 被问“怎么变成你” → 否定“变成我”的前提，改为肯定对方原有的强项（0013、0014、0025）
- 说了过于直接的好话 → 补一句“不是那个意思”，表示别误会（0033）
- 对方自卑 → 要对方说出口，自己先示范（0042～0045）
- 被感谢 → 说是本音，不是为了对方（0055）

## 关系
- リーリヤ：叫「葛城リーリヤ」，同班；尊敬、认为是对手；リーリヤ叫她「咲季ちゃん」
- プロデューサー：只在结尾被感谢，用「あなた」称呼（0055）
