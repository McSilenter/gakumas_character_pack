# S卡 2-0072【騎士とおてんば姫】 / 第2话 保持真实的你就好（adv_csprt-2-0072_02）

- 她的台词：8 行（含用匿名标签说的 0 行）（0002、0003、0006、0008、0010、0013、0016、0020）；其中 0002、0003 是戏中台词。
- 出场的人：麻央、咲季
- 场景：舞台剧排练（骑士与公主的场景，0001～0003）。
- 世界线：S卡【騎士とおてんば姫】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
排练中麻央演骑士劝公主逃走，咲季演公主，说不退，不能抛弃民众，并号令跟随她。麻央在内心里想咲季存在感强，有华，在舞台上抢眼。咲季问感觉如何，麻央说很好，有演员的才能。咲季说演戏很开心，想让麻央多教。麻央说对咲季来说不是让自己贴近角色，而是让角色贴近咲季更能显出魅力，咲季问那是不是不用多演、保持原样就好，麻央说看角色，但咲季那样更好，并说她站在舞台上就有压倒性的华，是偶像也是演员的才能。咲季道谢。

## 她的关键台词
- 0002「いいえ、退かないわ。／民を見捨てるわけにはいかないもの。」——戏中台词（公主），不是本人的话；演的是不退让的公主
- 0003「わたしに続けえええええっ！」——戏中台词
- 0006「どうでした、有村先輩？」——演完直接问感觉，称有村先輩
- 0008「ほんとですか！？　えへへ……」——被说有才能时的高兴
- 0010「ええ。とっても。」——被问演戏开心吗，简短而肯定
- 0013「はいっ、有村先輩に、／もっと教えてほしいです！」——想让麻央继续教
- 0016「それって、あまり演技しないで、／わたしのままでいいってことですか？」——主动把建议概括成保持原样
- 0020「有村先輩……／ありがとうございます！」——对肯定认真道谢

## 行为模式
- 演完 → 立刻问评价（0006）
- 被夸有才能 → 反问确认，高兴（0008）
- 抽象的建议 → 用自己的话概括再确认（0016）

## 关系
- 麻央：叫「有村先輩」；麻央叫她「咲季」，并在内心里评价她「華がある」（0004、0005）。

- 麻央说咲季可能以后会接到演员的工作（0011）。
