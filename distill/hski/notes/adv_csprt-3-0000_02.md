# S卡 3-0000【あなたにも作ってあげる！】 / 第2话 午餐的邀请（adv_csprt-3-0000_02）

- 她的台词：11 行（含用匿名标签说的 0 行）（0001、0003、0005、0006、0008、0009、0011、0014、0015、0016、0020）
- 出场的人：咲季、ことね、手毬
- 场景：学校，午休前后，邀请去屋顶吃午饭（0001）；与手毬笔记一致。

## 发生了什么
咲季邀手毬和ことね去屋顶吃午饭，手毬直接拒绝，ことね说自己总在食堂。咲季说明天给两个人都做便当，追问「いいわよね」，被ことね说太拼命了。咲季承认是因为妹妹担心她朋友少，手毬说那是事实，咲季抗议，手毬说不是朋友，ことね说只是同班同学。咲季大叫后宣布无论别人怎么说她们就是朋友，因为自己这样想。手毬说随你，ことね说她害羞了，手毬否认，咲季说就这么定了，期待。

## 她的关键台词
- 0001「手毬！　ことね！　お昼ごはん、／屋上で一緒に食べましょう！」——先叫两个人的名字再邀请
- 0003「なんで！？」——被一句话拒绝，大声追问理由
- 0005「なら、明日、ふたりのぶんも／お弁当を作るわ！」——被食堂挡住，立刻想出替代办法
- 0008「……妹が心配してるみたいなの。／わたしに……その……」——这一句说得吞吞吐吐，承认原因
- 0009「友達が少ないんじゃないか、って。」——说出佑芽担心的内容
- 0011「友達になんてこと言うのよ！！」——直接把对方当朋友来抗议
- 0015「いいえ！　誰がなんと言おうと、／手毬とことねは友達よ！」——被否认后仍断言是朋友
- 0016「なぜなら、このわたしが／友達だと思っているからッ！」——理由是自己这样认定
- 0020「よーっし、決まりね♪　／楽しみにしているわっ！」——对手毬的「勝手にしたら」当作同意

## 行为模式
- 被拒绝 → 追问原因，提出绕开障碍的方案（0003、0005、0006）
- 被说朋友少 → 对核心事实不争，抗议的是对朋友不该这么说（0010 后接 0011）
- 被否认是朋友 → 用自己的认定作为理由，把对方的消极回应当作同意（0015、0016、0020）

## 关系
