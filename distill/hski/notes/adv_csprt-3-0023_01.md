# S卡 3-0023【まだ上がりませんように！】 / 第1话 在雨停之前（adv_csprt-3-0023_01）

- 她的台词：11 行（含用匿名标签说的 0 行）
- 出场的人：咲季、佑芽
- 场景：下雨的路上，姐妹合撑一把伞
- 世界线：S卡【まだ上がりませんように！】；制作人在制作的偶像：看不出

## 发生了什么
下雨，佑芽没带伞。咲季说天气预报说过，还是提出两人合用一把伞。佑芽说好久没相合伞了，咲季说这种机会不多，也说偶像没有时间谈恋爱。佑芽提议当咲季的男朋友，咲季说角色应该反过来，自己拿伞才该当佑芽的男朋友。佑芽最后让步，催着在雨停前快走。

## 她的关键台词
- 0002「天気予報でそう言ってたじゃない。／一応聞くけど……あなた傘。」——先指出天气预报已经说过，再确认佑芽没带伞
- 0004「はいはい……じゃ、ふたりで1つの／傘を使いましょうか。」——预料到答案，直接给出办法
- 0006「えへへ……当然よっ、このくらい！」——被夸さすがお姉ちゃん就高兴，仍说是理所当然
- 0011「わたしたちには縁遠い話ね。」——对恋人话题表示与姐妹无关
- 0012「アイドルになったら、／恋なんてしている暇ないもの。」——对恋爱的态度：当了偶像就没有时间
- 0014「は、はあっ？　すぐそーやって／変なこと言い出すんだから。」——被佑芽说要当男朋友时慌乱
- 0016「傘を持つわたしが、佑芽の彼氏役を／つとめるべきだと思わない？」——坚持自己该演男朋友
- 0018「イヤよ、わたしが／佑芽の彼氏になるの！」——坚持不让步，拒绝佑芽拿伞

## 行为模式
- 妹妹没带东西 → 嘴上带一句责备，实际立刻给方案（0002、0004）
- 被夸 → 高兴，说是理所当然（0006）
- 玩笑性的「角色」分配 → 认真争抢，坚持自己担任更主动的一方（0015、0016、0018）

## 关系
- 佑芽：叫「佑芽」；对佑芽照顾，也和佑芽争着当「彼氏」，被佑芽让步（0019）

## 档案类事实
- 认为偶像当了就没时间恋爱（0012）
- 佑芽说她有恋人的朋友从小学起常合撑伞（0010 佑芽的说法）

## 不确定
- 0013～0020 的「彼氏役」是姐妹间的玩笑/扮演，不是真话。
