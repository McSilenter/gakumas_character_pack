# S卡 3-0023【まだ上がりませんように！】 / 第3话 如果我们互换身份（adv_csprt-3-0023_03）

- 她的台词：10 行（含用匿名标签说的 0 行）
- 出场的人：咲季、佑芽
- 场景：大雨天，在房间里（0004「部屋で休みなさい」）
- 世界线：S卡【まだ上がりませんように！】；制作人在制作的偶像：看不出

## 发生了什么
因为大雨取消了姐妹的购物约定，佑芽闹别扭，咲季劝她。咲季说佑芽当偶像之后变得会打扮了，佑芽说是受朋友影响。佑芽说有时想和姐姐换身体，用姐姐的身体穿更适合的可爱衣服自拍。咲季听了先问为什么，听完后说如果换了，自己也要用佑芽的身体拍很大胆的泳装照。

## 她的关键台词
- 0001「う～め、／いい加減、機嫌直しなさいよ。」——对闹别扭的佑芽直接说别再闹
- 0003「こんな大雨じゃ、危なくて／外になんて出られないでしょ。」——取消的原因是安全
- 0006「ふふ……あなた、アイドルになってから／……おしゃれになったわよね。」——注意到佑芽的变化
- 0008「前は服なんて、興味なかったでしょ。」——记得佑芽以前不关心服装
- 0010「あなたも可愛いわよ。／わたしの妹だもん。」——干脆夸佑芽可爱，理由是是我的妹妹
- 0013「…………………………なんで？」——听到想和姐姐换身体，长长沉默后问原因
- 0016「……なんだ、そんな理由。もしもそんな／不思議現象が起こったら……」——听到只是为自拍就放心
- 0019「す～っごく似合う、ダイタンな／水着写真を撮りまくってあげる！」——假设换身体时，要用佑芽的身体拍大胆的泳装照

## 行为模式
- 妹妹闹别扭 → 以安全理由说明，再改变话题，用夸奖哄（0003、0006、0010）
- 听到异想天开的话 → 先怀疑，再以同样荒唐的设想回应（0013、0016、0018、0019）
- 夸妹妹时用我的妹妹做理由（0010）

## 关系
- 佑芽：叫「佑芽」；佑芽想和她互换身体（0012），她以回敬玩笑回应；佑芽叫她「お姉ちゃん」，被说「えっち」（0020）

## 档案类事实
- 佑芽当偶像之前对服装没有兴趣（0008 咲季）；当了偶像后变得更会打扮（0006）
- 两人曾约好一起去买衣服（0002 佑芽，0005 佑芽「服選ぶの」）

## 不确定
- 0018、0019 是假设身体互换的想象发言，不是现实。
