# S卡 3-0029【夏を満喫するわよ！】 / 第2话 尽情享受！玩水时间（adv_csprt-3-0029_02）

- 她的台词：13 行（含用匿名标签说的 0 行）
- 出场的人：咲季、ことね、手毬
- 场景：初星学園的河边，玩水（0001）
- 世界线：S卡【夏を満喫するわよ！】；制作人在制作的偶像：看不出

## 发生了什么
咲季在河边宣告自己有随时接受水战的准备，话没说完就被ことね偷袭。她说偷袭不算，不受偷袭就能躲开水枪，得意说自己是最会玩水的偶像，叫两人一起上。随即被手毬从背后攻击，ことね喊「でかした」。咲季抗议背后偷袭，手毬说二人一起上、从哪来都行是她自己说的，两人夹击，咲季喊着「覚えてなさい」。

## 她的关键台词
- 0001「初星学園に水遊びができる河原が／あること！　もちろん知っていたわ！」——事先把学园周边设施都掌握了
- 0002「つまり！　いつ何時水遊びで／勝負を挑まれても――」——念着口上要讲到随时接受挑战
- 0005「ふ、不意打ちですってぇ～！？／こ、口上の途中で攻撃するなんて！」——口上被打断，抗议对方在讲话时攻击
- 0006「ことねぇ～ッ！　／アイドルの矜持がないの！？」——要求对手遵守礼仪，用偶像的矜持责备
- 0008「と、と、とっ！　不意を突かれなきゃ、／こんな、ものぉ！」——不被偷袭就能躲开
- 0010「ふっふっふ～……きっとわたし、／世界で一番水遊びが強いアイドルね！」——躲开几发就自封世界第一
- 0011「さあ！　ふたりがかりでも構わないわ！／どこからでもかかって――」——大度地说二对一也行、从哪里来都行
- 0016「ず、ずるいわよ！　背後からなんて！」——被背后偷袭后立刻说卑鄙
- 0020「こんなときだけ息ぴったりね！　／覚えてなさい～！？」——被二人夹击后，抱怨对方默契，放狠话

## 行为模式
- 比赛类事情 → 先做宣告和口上，被打断就抗议规则（0002、0005、0006）
- 小有成绩 → 马上自封第一，并放话二对一也行，结果自己的话被拿来用（0010、0011、0017 手毬）
- 输了 → 抱怨对方卑鄙，放「覚えてなさい」的狠话（0016、0020）

## 关系
- ことね：叫「ことね」；被ことね偷袭，叫她「アイドルの矜持がないの」（0006），ことね答「そんなものはなぁ～い」
- 手毬：叫「手毬」；手毬配合ことね从背后攻击，咲季说她们「こんなときだけ息ぴったり」（0020）

## 档案类事实
- 初星学園里有可以玩水的河边（0001）
