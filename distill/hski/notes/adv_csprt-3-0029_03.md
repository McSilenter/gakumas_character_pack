# S卡 3-0029【夏を満喫するわよ！】 / 第3话 炫耀好感情（adv_csprt-3-0029_03）

- 她的台词：10 行（含用匿名标签说的 0 行）
- 出场的人：咲季、ことね、手毬、佑芽（0019，电话里）
- 场景：咲季和佑芽通电话（0001、0006），ことね、手毬在她身旁，看不出具体地点
- 世界线：S卡【夏を満喫するわよ！】；制作人在制作的偶像：看不出

## 发生了什么
咲季在电话里向佑芽炫耀自己的一天：自主练习后和要好的朋友在河边玩水。手毬插话说不是朋友也不亲密，咲季叫她走开。咲季继续说「好友」邀请了她去玩，ことね问自己是不是亲友，咲季说「大好きだけど？」。ことね害羞后，调侃地装作亲友说今晚一起睡，咲季嫌她恶心，说这种演技骗不了妹妹，结果佑芽误会，咲季惨叫。

## 她的关键台词
- 0002「それから仲の良い友達と、／河原で水遊びをしたの。」——向佑芽炫耀有关系好的朋友
- 0004「ちょっと手毬、余計なこと言わないで。／あっち行ってなさい。」——手毬否认朋友关系时，为了不让炫耀穿帮，直接让她走开
- 0006「ごめん佑芽、なんでもない。え？　／川遊び？　それはね～。」——对佑芽掩饰，再回到炫耀
- 0007「実はわたし、気が滅入ることがあって／落ち込んでいたんだけど……」——炫耀的说辞里编了落寞的情节（电话中的说法）
- 0008「そしたらわたしの親友が、学園の／河原で遊ぼうよ～って言ってくれて。」——说「亲友」邀她去玩（指ことね）
- 0010「大好きだけど？」——ことね问我是你的亲友吗，毫不犹豫地答「很喜欢」
- 0016「うわっ！　なっ、なによことね！　／……気色悪いわね。」——ことね靠过来演亲友，直接说恶心
- 0018「そんなわざとらしい演技で／わたしの妹が騙せるわけ……」——说这种演技骗不了佑芽
- 0020「ああああああああ！／変な誤解されちゃったじゃない～～～！」——佑芽误会后慌张惨叫

## 行为模式
- 想在妹妹面前赢 → 夸大炫耀，同伴拆台就直接让她走开（0004）
- 被直接问到感情 → 毫不犹豫、大方地说「大好き」，对方害羞她却不当回事（0010）
- 做作的肉麻 → 嫌恶，直接说「気色悪い」（0016）

## 关系
- 佑芽：叫「佑芽」；通话中炫耀友情，也担心被误会（0019 佑芽叫「お姉ちゃんのえっちぃ！」，0020）
- ことね：叫「ことね」；0008 称她为「親友」，0010 对親友だった？答「大好きだけど？」
- 手毬：叫「手毬」；手毬说「友達じゃないし仲良くないけど」（0003），咲季让她走开（0004）

## 档案类事实
- 当天做了自主练习，之后在河边玩水（0001、0002）

## 不确定

- 0001 起的台词是对着电话里的佑芽说的；佑芽的话（电话那头）只有 0019 出现。
