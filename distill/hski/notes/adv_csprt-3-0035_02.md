# S卡 3-0035【ゆっくりと過ごしましょう】 / 第2话 姐妹的学习时间（adv_csprt-3-0035_02）

- 她的台词：10 行（含用匿名标签说的 0 行）
- 出场的人：咲季、佑芽
- 场景：休日的上午，咲季的房间一类的地方，看不出具体地点
- 世界线：S卡【ゆっくりと過ごしましょう】；制作人在制作的偶像：看不出

## 发生了什么
佑芽说今天两人都休息，想一起过，咲季欢迎，并出题问休日上午姐姐做什么，佑芽答是学习。咲季说正确，随即开始学习指导。学习结束后，咲季问佑芽有没有想过将来。佑芽说努力练习、胜过姐姐，咲季说不会让她赢，又问赢了之后呢，佑芽说赢了再想。咲季说是最让她高兴又最头疼的回答。

## 她的关键台词
- 0002「あら、いらっしゃい。／ついさっきぶりね。」——刚分开不久又见面，以玩笑回应
- 0005「大歓迎よ。ふふ～ん、／なかなかいい心がけね。」——欢迎佑芽，但话里是会被拉去学习
- 0007「あなたのお姉ちゃんは、休日の午前中、／いつもなにをしているでしょう～？」——用问答方式让佑芽自己说出「学习」
- 0009「さすがわたしの妹ね。／第一問、見事正解よ。」——佑芽答对后得意，转入学习
- 0014「はい、どういたしまして。／お疲れ様。よくやったわね。」——学习结束后犒劳佑芽
- 0016「…………ねぇ、佑芽。あなた……／将来について、考えたことはある？」——沉默后认真问佑芽对将来的想法
- 0018「させないわよ。でも、もしも……／それが叶ったら？　その先は？」——先说不会让佑芽赢，再认真追问
- 0020「そう。最高に嬉しくて――……／悩ましい回答ね。」——对赢了再想的回答，说既高兴又头疼

## 行为模式
- 休日 → 上午学习是固定行程（0007、0008）
- 妹妹来找 → 欢迎，同时顺势开始学习（0005、0009、0010）
- 谈到将来 → 变得认真，沉默之后发问（0016、0018）
- 听到妹妹要胜过自己 → 说不会让你赢，同时因被当作目标而高兴（0018、0020）

## 关系
- 佑芽：叫「佑芽」；佑芽把胜过お姉ちゃん当目标（0017、0019），她对此既高兴又烦恼（0020）
