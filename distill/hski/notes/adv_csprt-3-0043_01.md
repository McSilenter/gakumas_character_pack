# S卡 3-0043【待ちなさーい！】 / 第1话 跑步对决！（adv_csprt-3-0043_01）

- 她的台词：9 行（含用匿名标签说的 0 行）
- 出场的人：清夏、咲季
- 场景：寒冷的天气，出去跑步；比赛在操场（0010「グラウンド10周」）
- 世界线：S卡【待ちなさーい！】；制作人在制作的偶像：看不出

## 发生了什么
清夏觉得冷，想跑步取暖，遇到咲季，咲季问能否同行。接着咲季提议比赛，清夏说又来了咲季的「勝負癖」。规则是操场10圈，先到者胜。咲季说勝てると分かっていないと挑まない，评价清夏的体态很美。结果清夏明显落后，咲季说这样没法比，清夏认输。

## 她的关键台词
- 0003「あら、清夏じゃない。奇遇ね。」——遇见就打招呼
- 0006「それならちょうどいいわね。／わたしも同行していいかしら？」——顺势提出同行
- 0008「そうだ！／せっかくなら、わたしと勝負しなさい！」——一起行动就想到比赛
- 0010「ルールはグラウンド10周！／先にゴールした方が勝ちよ！」——立刻给出明确规则
- 0012「当然よ！　勝てると分かっていたら／勝負なんて挑まないわ！」——被提醒别小看对方的体力，回答是因为确信会赢才挑战
- 0014「そう？　正当な評価だと思うけれど。／あなたの体、美しいもの。」——被说意外她评价自己时，直接夸对方身体很美
- 0017「ちょっと、どうしたの清夏！？／それじゃわたしに勝てないわよ！？」——对手落后时担心地说这样赢不了
- 0019「まったくもう……／勝負にならないじゃない。」——因为对手差距太大而不满

## 行为模式
- 遇到熟人一起运动 → 立刻提出比赛，并给规则（0008、0010）
- 被提醒对手不弱 → 说只挑战能赢的对手，同时认可对方（0012、0014）
- 对手落后太多 → 不得意，反而觉得没劲（0017、0019）

## 关系
- 清夏：叫「清夏」；清夏叫她「咲季っち」，说她有「勝負癖」（0009）；咲季认可她的体（0014），清夏被说得怀疑「狙われてる？」（0015）
