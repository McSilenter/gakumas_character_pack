# S卡 3-0052【合格おめでとう！】 / 第2话 悠闲谈心时光（adv_csprt-3-0052_02）

- 她的台词：11 行（含用匿名标签说的 0 行）
- 出场的人：咲季、佑芽
- 场景：佑芽的房间（0002「あたしの部屋へ」），两人都休息的日子
- 世界线：S卡【合格おめでとう！】；制作人在制作的偶像：看不出

## 发生了什么
咲季来到佑芽的房间，佑芽说今天比赛和学习都休息，整天一起度过。咲季说拿她没办法，只此一次。佑芽说看到咲季的日程全是工作，会一次次提同样的请求。咲季表示反省，说偶像的日程很苛刻，说休息日要好好休息，借用佑芽的床睡觉。佑芽叫她别把休息当睡觉，想聊天。咲季接受，说和佑芽一起度过更能恢复心灵疲劳，整天聊天。

## 她的关键台词
- 0001「佑芽！　お姉ちゃんが来てあげたわ！」——到场时自称「お姉ちゃん」，口气像是施恩
- 0005「まったくしょうがない妹ね～♡　／今回だけよ。」——嘴上说拿妹妹没办法、只此一次，语气开心
- 0009「……反省してるわ。」——被指出日程全是工作后，承认自己没顾好休息
- 0011「常にベストコンディションを維持する／のが花海咲季なのに……」——自我要求是总保持最佳状态
- 0012「ルーティンを優先して、回復を／おろそかにするようじゃ、本末転倒。」——反省把例行训练放在恢复之前是本末倒置
- 0014「というわけでベッド借りるわね。／おやすみ――……」——决定休息，立刻借床睡觉
- 0017「えっ？　だって睡眠が一番、／効率よく回復するから……」——对休息等于睡觉被指出时的理由是效率
- 0019「それもそうね……起きてあなたと過ごす／方が、心の疲れは取れそうだもの。」——想通后改变，认为和佑芽一起度过更能恢复心灵疲劳
- 0020「今日はず～っと／お喋りしましょう、佑芽。」——整天聊天

## 行为模式
- 被指出过劳 → 承认并反省，再用自己的标准重新定义休息（0009～0013）
- 休息 → 立刻变成睡觉，以效率为理由（0014、0017）
- 被妹妹提醒「一起」的价值 → 立刻接受，改变安排（0019、0020）

## 关系
- 佑芽：叫「佑芽」；佑芽多次以同样的请求让她休息（0007、0008）；她把和佑芽一起度过看作恢复心灵（0019）

## 档案类事实
- 日程里工作很多（0007 佑芽，0010 咲季「アイドルのスケジュール／って、過酷なのね」）
- 睡眠是她认为最有效率的恢复方式（0017）
