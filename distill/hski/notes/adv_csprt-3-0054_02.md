# S卡 3-0054【相手にとって不足なしよ！】 / 第2话 有趣的东西就是有趣！（adv_csprt-3-0054_02）

- 她的台词：12 行（含用匿名标签说的 0 行）
- 出场的人：咲季、リーリヤ
- 场景：休日，两人一起玩格斗游戏（0019 咲季「貴重な休日」），看不出具体地点
- 世界线：S卡【相手にとって不足なしよ！】；制作人在制作的偶像：看不出

## 发生了什么
リーリヤ称赞咲季进步很大，咲季得意地说是练习和学习的结果：记住所有角色的招式、特点、连招、站位、流行战术，在攻防中读对手。她说格斗游戏很像体育竞技，电子竞技这个称呼说得好。リーリヤ说没想到咲季这么喜欢，因为咲季好动明朗，她以为会更喜欢在外面运动。咲季说室内外无所谓，有趣的就是有趣。最后咲季宣布闲聊结束，两人一起玩这款名作。
