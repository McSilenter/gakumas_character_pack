# S卡 3-0054【相手にとって不足なしよ！】 / 第3话 传奇猛犸同学（adv_csprt-3-0054_03）

- 她的台词：12 行（含用匿名标签说的 0 行；0020 是括号里的心声）
- 出场的人：咲季、リーリヤ
- 场景：和リーリヤ打格斗游戏，看不出具体地点
- 世界线：S卡【相手にとって不足なしよ！】；制作人在制作的偶像：看不出

## 发生了什么
咲季说自己上手之后才明白リーリヤ强得离谱。リーリヤ谦虚，咲季说强者谦虚不好，说自己昨天才升到「ぞうさんランク」，叫她给自己看排名。咲季强行看到，发现是「伝説のマンモスさんランク」，震惊。她问以后要不要叫她传说的猛犸同学，リーリヤ恳求别这样叫。咲季道歉，以为リーリヤ不想炫耀实力。リーリヤ说是怕咲季在外面这样叫后固定下来，咲季心里不明白为什么会困扰。

- 0013「……これからは伝説のマンモスさん／って呼んだ方がいい？」——震惊之后的玩笑，想把这个名号当绰号

## 行为模式
- 觉得对手谦虚 → 直接说强者谦虚不好，要求出示证据（0004、0007）
- 对手超过预期 → 震惊后立刻想用绰号称呼（0010、0013）
- 被恳求停止 → 立即道歉，但按自己的理解解释，没有理解真正原因（0016、0017、0020）
