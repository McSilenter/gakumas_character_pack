# S卡 3-0085【自分と向き合う時間だ】 / 第3话 无论对手是谁（adv_csprt-3-0085_03）

- 她的台词：10 行
- 出场的人：咲季、燕
- 场景：训练场，咲季和燕一起做互相融合的训练
- 世界线：S卡【自分と向き合う時間だ】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
咲季让燕看自己的训练菜单，燕说是用最新机器的科学训练，很合理，想参考。咲季说座禅对自己很有益，并提议互相吸取各自菜单的优点。训练做完，两人都有点喘，燕说放得太多了。咲季说和燕一起练能感受到成长，燕也说有她在是激励，咲季说两人相性可能不错。燕说有共同要打倒的对手，合作也不错；咲季提醒试镜时是对手，燕笑她以为能赢；咲季说无论对手是谁都全力挑战。

## 她的关键台词
- 0001「――どうでしょうか、雨夜先輩。／わたしのトレーニングメニューは。」——请前辈评价自己的菜单
- 0003「趣味に合いませんか？」——担心前辈的喜好
- 0006「前に教えていただいた座禅は、／とても学びになりました。」——对座禅表示感谢
- 0008「それぞれのメニューの良いところを／取り入れていくのはどうでしょう？」——提议折中，而不是争论谁的方法好
- 0013「でも、雨夜先輩と一緒にトレーニングを／していると、成長を実感します。」——坦率说明和前辈一起练的价值
- 0015「もしかしてわたしたち、／相性が良いのかもしれません。」——直接说相性好
- 0018「オーディションでは／ライバル同士ですよ。」——合作之余提醒是对手
- 0020「はい！　アイドルですから！　／相手が誰だろうと全力で挑みます！」——面对前辈的挑衅，宣告无论对手是谁都全力挑战

## 行为模式
- 遇到不同方法 → 不排斥，提议取长补短（0006～0008）
- 被前辈说「生意気」 → 不退缩，用「アイドルですから」回应（0019、0020）
- 关系亲近时 → 仍提醒试镜是对手（0018）

## 关系
- 燕：叫「雨夜先輩」（0001、0013）；燕叫她「咲季」，说有她在是励み（燕 0014），称她「1年のくせに生意気」（燕 0019）
