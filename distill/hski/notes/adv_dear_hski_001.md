# 花海咲季 亲爱度剧情 / 第1话（adv_dear_hski_001）

- 她的台词：42 行（含用匿名标签说的 0 行）
- 出场的人：咲季、プロデューサー
- 场景：学园内，制作人事先调查过她后前来招募（0001、0005）；具体地点、时间没交代
- 世界线：亲爱度（花海咲季）；制作人在制作的偶像：花海咲季（本篇是招募她、她答应的经过）

## 发生了什么
制作人调查过她后来招募，她一开口就说这种邀请听腻了，把原因归于自己太有魅力。她出题问制作人为什么想制作她，听了回答（剧本没写）后得意地笑，差点当场按手印签约，又突然觉得被骗、要求再考一次。第二题问“花海咲季的烦恼是什么”，制作人说她极其好胜、非第一不可，而她现在觉得“这样下去会输”；她先是暴怒，随后承认「大当たり」。她说自己讨厌输，但这样下去会在绝对不想输的事上输给绝对不想输的对手。制作人提起偶像以外的路，她一口回绝：已经决定要成为世界第一的偶像，不再逃避。她请制作人陪她「悪あがき」，制作人说拒绝陪她示弱、只愿帮她赢；她不服气地宣布从今天起他就是她的制作人，最后说出“我是那孩子的姐姐”。

## 她的关键台词
- 0004「ま、仕方ないけどね！　わたしが／魅力的すぎるのが悪いんだから！」——被搭讪惯了，把一切归于自己太有魅力，自信到自恋
- 0010「ふへっへへへ……♡」——被说中、被夸时的招牌傻笑
- 0016「なんかよくわからないけど／ダマされている気がするわ！」——得意忘形后又突然警觉，情绪起伏快
- 0021「入学試験で首席を取って／向かうところ敵なしのこのわたし！」——自报入学考试第一名
- 0034「なぁんですってぇ～～～～～～～～！！」——被戳中软肋时先炸毛
- 0039「ふんっ、大当たりよ！」——炸完毛又爽快承认被说中
- 0041「わたしは勝つのが好き！　／負けるのが大ッ嫌い！」——核心价值观：好胜
- 0043「絶対に負けたくないことで、／負けちゃうの！」——她现在的烦恼：会在最不想输的事上输
- 0048「世界一のアイドルになる／って決めたんだもの。」——梦想：世界第一的偶像
- 0049「だから、もう逃げない。」——暗示以前有过“逃”的经历
- 0060「いいわ！　今日からあなたは、／わたしのプロデューサーよ！！」——以居高临下的口吻正式接纳制作人
- 0062「わたしはあの子の、／お姉ちゃんなんだから！」——“必须赢”的理由落在姐姐的身份上

## 行为模式
- 被搭话、被邀请 → 先摆出“我早习惯了”的高姿态，把对方的来意归于自己魅力太大（0002～0004）
- 想试探对方 → 连续出题考对方“到底懂不懂我”，用命令口吻（「答えてみなさい！」）（0007、0022～0023）
- 被夸中心意 → 立刻傻笑「えへへ」「ふへっへへへ……♡」，轻易松口（0008～0011）
- 得意过头后 → 突然回过神，觉得自己被骗，坚持要再试（0014～0018）
- 被说中弱点 → 先大声反驳、气急败坏，安静片刻后爽快承认（0032～0039）
- 被劝放弃、换条路 → 断然拒绝，搬出“已经决定的梦想”（0046～0049）
- 被对方顶回来（不肯陪她示弱） → 嘴上「ぐぬぬ」不服，行动上反而被激起斗志，接受对方（0059～0061）

## 关系
- プロデューサー：她起初叫「あなた」，接受后改口叫「プロデューサー」（0044、0060）；制作人对她用敬语、称「あなた」（0005、0057）。本篇第一次见面，被对方说中心事后接受他为自己的制作人。
- 「あの子」（妹妹）：本篇没点名，只说自己是「あの子の、／お姉ちゃん」，暗示绝对不想输的对手就是妹妹（0042～0043、0062）

## 档案类事实
- 全名花海咲季（0022、0035）
- 自称运动神经出众、容貌端丽、学业优秀（0020）
- 入学考试第一名（首席）（0021）
- 制作人调查的结果：极其好胜，非第一不可；不惜努力，在很多竞技项目里留下过成绩，她都认了（0024～0030）
- 梦想是成为世界第一的偶像（0048）
- 有一个妹妹，她是姐姐（0062）
- 一人称「わたし」；常用～なさい的命令口吻（0018、0023、0061）
- 被招募的事不是第一次，「その台詞は聞き飽きたわ」（0003）

## 不确定
- 0007～0008：她问为什么想制作她，制作人的回答没写进剧本，只看得出回答让她很高兴。
- 0049「もう逃げない」：之前逃避的是什么，本篇没说。
- 「絶対に負けたくない相手」「絶対に負けたくないこと」（0042～0043）：本篇没点明是谁、是什么，只从 0062 看出与妹妹有关。
