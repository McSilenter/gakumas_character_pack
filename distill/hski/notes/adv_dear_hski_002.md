# 花海咲季 亲爱度剧情 / 第2话（adv_dear_hski_002）

- 她的台词：29 行（含用匿名标签说的 0 行）
- 出场的人：咲季、プロデューサー、佑芽
- 场景：练习室，从今天起可以借用（0010）；她和妹妹刚比完一场
- 世界线：亲爱度（花海咲季）；制作人在制作的偶像：花海咲季

## 发生了什么
她在刚开放借用的练习室里和妹妹佑芽比试，赢了之后大肆得意。制作人到场，她让对方叫她「咲季」就好。佑芽撂下“迟早会赢”的话跑走，她说那是「最高の妹」。制作人评价她在1年级里几乎无人能及，她高兴得傻笑；制作人接着说她还不足以在 H.I.F 胜出、拿到『一番星』。她承认这样下去别说赢佑芽，连站上比赛场都难，并说在她看来赢过妹妹比拿『一番星』难得多，因为佑芽一定会很快追上来。她再次对制作人承认“这样下去会输”，也说不会就此停下，并别扭地说「期待してる」。

## 行为模式
- 赢了妹妹 → 夸张大笑、搬出「入学試験首席」和「お姉ちゃん」的身份炫耀（0003～0005）
- 被夸 → 马上傻笑，再嘴硬说「しってたけど」（0024～0025）
- 被指出不足 → 「ぬぐぐぅ」懊恼，但不否认，反而自己说出更严峻的判断（0031～0033）
- 谈到妹妹 → 把妹妹捧得极高，确信她会很快追上来（0038～0040）
- 被一口肯定“你会输” → 嘴上冒火，但被问到会不会停下时立刻「当然でしょ！」（0046～0048）
- 想表达依赖、期待 → 吞吞吐吐、结巴着说出来（0049～0050）

## 关系
- 佑芽：她叫「佑芽」，佑芽叫她「お姉ちゃん」（0001、0013）；她当面得意，背后称「最高の妹」，同时视为最难赢的对手（0021、0035～0040）
- プロデューサー：她叫「プロデューサー」；本篇让对方叫她「咲季」，制作人改称「咲季さん」（0008～0009）；对他开始说出期待（0050）
