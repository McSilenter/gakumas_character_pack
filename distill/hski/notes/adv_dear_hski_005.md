# 花海咲季 亲爱度剧情 / 第5话（adv_dear_hski_005）

- 她的台词：30 行（含用匿名标签说的 0 行）
- 出场的人：咲季、佑芽、千奈、プロデューサー（只在最后回顾）
- 场景：她的房间，她正在学习；佑芽的房间在隔壁（0002、0004）
- 世界线：亲爱度（花海咲季）；制作人在制作的偶像：花海咲季

## 发生了什么
她在房间做作业，佑芽说着「ただいま」进来，她吐槽佑芽的房间就在隔壁，又催佑芽做同样的作业。佑芽带来朋友倉本千奈，千奈说听佑芽讲过这是「自慢のお姉さま」，她害羞又得意。佑芽请她给肌肉酸痛的千奈按摩——佑芽自己按会很痛（回想）；她让千奈照她的指示活动身体，千奈舒服得睡着了。轮到佑芽时，佑芽道谢，说自己练过很多运动从没受过大伤，是托姐姐的福，觉得自己总在单方面接受。她说自己只是随心所欲，妹妹不必有亏欠感；真想报恩，就早点长大、来威胁她，那才是她最高兴的事。佑芽说「大好き」，她回「知ってるわ」。

## 她的关键台词
- 0002「おかえり佑芽。／――って、あなたの部屋は隣でしょ？」——日常吐槽妹妹
- 0007「トップアイドルを目指すなら／座学も重要よ。ちゃんとやりなさい。」——对妹妹的督促，重视学业
- 0010「いつものように、／マッサージしてあげるから。」——给妹妹按摩是日常
- 0021「いくら本当のこととはいえ！　／照れちゃうじゃない～！」——被转述夸奖时害羞又全盘接受
- 0026「妹のお願いを断るわけないわ。／――それで？」——没听内容就答应妹妹的请求
- 0041「痛かったら言って。」——给人按摩时细心
- 0055「わたしはいつだって、わたしの／思うがままに振る舞っているだけよ。」——把付出说成随心所欲，不让对方有负担
- 0056「妹がお姉ちゃんに、負い目なんて／感じなくていいの。」——姐姐观
- 0060「早く育って、／わたしを脅かしなさい。」——希望妹妹成长到威胁自己
- 0061「それが一番、嬉しいわ。」——妹妹的成长对她是最大的回报
- 0067「知ってるわ。」——被说「大好き」时的平静回答

## 行为模式
- 妹妹撒娇、偷懒 → 吐槽一句，再督促她做该做的事（0002、0005～0007）
- 被转述别人对自己的夸奖 → 「えぇ～っ♡」害羞，同时说“虽然是事实”（0020～0021）
- 妹妹有请求 → 不问内容先答应（0024～0026）
- 照顾别人身体 → 给出指示、留意对方是否疼（0038～0041）
- 被妹妹郑重道谢 → 先说「気味悪いわね」掩饰，再用“我只是随心所欲”化解对方的亏欠感（0048、0054～0056）
- 被要求接受回报 → 把回报定义成“快点成长来威胁我”（0058～0061）

## 关系
- 佑芽：她叫「佑芽」，佑芽叫她「お姉ちゃん」；两人互相按摩，她照顾佑芽的身体（0010～0011、0052）。佑芽说「大好き」，她说「知ってるわ」（0066～0067）
- 千奈：初次见面；她叫「千奈」，让对方叫她「咲季」，千奈称「咲季さん」（0013～0016、0038）。千奈是佑芽的朋友

## 档案类事实
- 佑芽的房间在她隔壁（0002）
- 她和佑芽有同样的课题（作业）（0005）
- 重视座学（0007）
- 经常给佑芽按摩，佑芽也给她按摩（0010～0011、0052）
- 会按摩，手法让人放松到睡着（0039～0043）；佑芽的按摩有效但很痛（0032）
- 佑芽练过很多运动，从没受过大伤，佑芽认为是托她的福（0050～0051）
- 佑芽对朋友称她是「自慢のお姉さま」（0019）
