# 花海咲季 亲爱度剧情 / 第7话（adv_dear_hski_007）

- 她的台词：48 行（含用匿名标签说的 0 行）
- 出场的人：咲季、プロデューサー、佑芽
- 场景：佑芽的首次演出（ファーストライブ）会场，她和制作人去观看，到得太早（0004、0006）
- 世界线：亲爱度（花海咲季）；制作人在制作的偶像：花海咲季

## 发生了什么
她拉着制作人跑去看佑芽的首次演出，到得太早，期待得心都要炸开，同时又为被佑芽抢先而不甘心。她问自己的首次演出呢，制作人说按计划还要再等；听说佑芽似乎也有了制作人，她嘟囔“竟然没经过我同意”。演出大获成功，她小声说「やるじゃない」，然后要制作人如实回答她和佑芽谁更强，制作人说佑芽在所有方面都超过了她。她道谢，说没有动摇，这种事经历过无数次，该来的总会来；又说今天大家都喜欢上了佑芽，连自己都笑了，「あれがアイドルなのね」。被问打算怎么办，她说照常按两人一起定的最佳计划练，不会乱加特训；但最后还是问出“这样下去我能赢吗”，又说入学以来自己一点都没成长，最终鼓起干劲说要拼到底。

- 0011「両方よ！　ねえプロデューサー！」——期待和不甘同时存在，毫不掩饰
- 0020「むぅ……わたしに無断で／そんなヤツが……」——对妹妹的制作人抱有姐姐式的戒心
- 0025「…………やるじゃない。」——认可妹妹的演出
- 0028「わたしと佑芽、どちらが上？」——主动要听最残酷的答案
- 0032「ウソついてたら、／ぶっ飛ばしてたわ。」——要求制作人对她诚实
- 0035「何度も何度も／……繰り返してきたことだもの。」——被妹妹追上的经历不是第一次
- 0046「――――あれがアイドルなのね。」——从妹妹的演出里看到偶像是什么
- 0058「それを続けるよりも／効果のある特訓なんてないわ。」——不因焦虑乱改计划，理性
- 0064「……ベストな日々を過ごした先で、／わたしは勝てるの？」——藏在冷静下的不安
- 0070「やるだけやってやろーじゃないっ！」——把不安转成斗志

## 行为模式
- 妹妹的大日子 → 比谁都着急，提前很久到场（0001～0007）
- 被妹妹抢先 → 大声说不甘心，同时也真心期待（0008～0011）
- 想知道自己的真实位置 → 直接逼问，并要求对方不许说谎；听到坏消息先道谢（0028～0032）
- 被问是否动摇 → 说不动摇、早就习惯，用“我早说过”来接住（0034～0037）
- 看完对手的精彩表现 → 坦率承认「素敵なライブだった」（0045～0047）
- 被问会不会加练 → 理性回答按最佳计划走，不乱来（0052～0058）
- 不安压不住时 → 沉默很久后才小声问出口，然后再给自己打气（0062～0070）

## 关系
- 佑芽：为妹妹的首次演出拼命期待，又不甘心被抢先；看完说「やるじゃない」，承认被感动（0007～0009、0025、0045～0047）
- 佑芽的制作人（据制作人推测有了）：她觉得「わたしに無断で」（0018～0020）
- プロデューサー：她要他如实说出谁更强，说撒谎就揍他（0028～0032）；称训练计划是“一起考虑的”（0056～0057）

## 档案类事实
- 佑芽先于她举行了首次演出（0004、0008）；她的首次演出按计划还要再等（0012～0015）
- 制作人认为佑芽在上次试镜中很显眼，应该已经有了制作人（0017～0019）
- 制作人判断：作为偶像的心技体、华和气场，佑芽全面超过她（0029～0030）
- 被妹妹追上的事经历过很多次（0035～0036）
- 训练计划是她和制作人一起定的“最适合她的计划”（0056～0057）
- 日常作息：回去洗澡、拉伸、吃饭、睡觉、起床、练习（0053～0054）

## 不确定
- 0066～0068：0066 她说「ちっとも……成長していないのに？」，0067「それは…………」、0068 又转为「そうね……」，中间制作人的回应没写进剧本，可能是选项后的反应。
- 0066「入学してから、今まで……／ちっとも……成長していないのに？」是她的自我感觉；第5话 0069、第6话 0071 的制作人笔记写她「着実に」成长，第6话 0039～0040 她自己说练了两个月后成长才停，说法有出入，属她主观判断还是剧情对不上，待确认。
- 【译文】0035 译文“我早就习惯了”是译者补的，原文只说“是反复了无数次的事”。
