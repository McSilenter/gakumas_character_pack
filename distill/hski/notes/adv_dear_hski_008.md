# 花海咲季 亲爱度剧情 / 第8话（adv_dear_hski_008）

- 她的台词：51 行（含用匿名标签说的 0 行）
- 出场的人：咲季、プロデューサー
- 场景：早上，她在晨练（跑步）中，制作人一早来陪（0001～0006）；和佑芽的下一场比试临近
- 世界线：亲爱度（花海咲季）；制作人在制作的偶像：花海咲季

## 发生了什么
她早上练习时，制作人照例一早来陪，她说放学后再陪就行，又看穿制作人想趁休息时谈话。制作人指出她最近很焦虑，她说和佑芽的比试近了，自己却一点都没成长。制作人问她“赢过妹妹”指什么，说自己的“赢”是把她培养成无敌的顶级偶像，中途输一次不要紧；她大怒，说他答应过帮她赢。她喊出自己作为偶像已经被佑芽超过、哪怕一次都不想输给妹妹。制作人说她缺的正是“绝对不想输的、比自己强的对手之间的真剑胜负”，质问她说过的“明知会输也不逃”是不是谎话。她于是全盘托出：其实她一次都没赢过妹妹，超早熟的她和大器晚成的妹妹，每次快输就逃到别的竞技，是「勝ち逃げ」的卑鄙者；选偶像也是因为体格不好也能冲世界第一、也许能赢佑芽；她害怕让妹妹失望。制作人再次说要让她成为无敌的顶级偶像，她道歉、说很怕很想逃，但想到佑芽一定也是这种心情，最终说「もう逃げないわ」。

## 行为模式
- 制作人为她辛苦 → 体谅对方，说不用那么早来（0005～0006）
- 预料到对方会提的建议 → 先发制人堵住（0009、0017）
- 被说“输一次也没关系” → 激烈发怒，搬出对方的承诺（0028～0031）
- 被逼问为什么软弱 → 一口气说出最不想说的真相和恐惧，最后反问「今度こそ見損なったでしょ！」（0051～0064）
- 对方不嫌弃、继续相信她 → 先道歉，坦白害怕，然后从妹妹的角度找到勇气（0069～0075）
- 下定决心后 → 立刻恢复强势口吻「言われるまでもないわっ！」，用“我是姐姐”收尾（0077～0078）

## 关系
- プロデューサー：知道他每天一早来陪；把从没对人说过的真相讲给他听，问他是否看不起自己；他坚持相信她后，她道歉并下决心（0005～0011、0052～0075）
- 佑芽：一次都不想输给她，怕被她失望；第一次想到佑芽一直以来也是这种心情（0038、0062、0072）

## 档案类事实
- 早上自己练习（0001～0002）；制作人通常一早就来陪，她说放学后再来就行（0005）
- 自称和制作人相处已有一段时间（0011）
- 自述「本当は一度だって／妹に勝ったことがない」（0052）
- 自认超早熟，妹妹是大器晚成（0053）
- 过去每次快要输给妹妹，就转去别的竞技（0054）
- 选偶像作为下一个梦想的理由：体格不好也能冲世界第一，作为偶像也许能赢佑芽（0058～0060）
- 害怕让妹妹失望（0062）
- 认为只要输给妹妹一次就再也站不起来（0074）

## 不确定
- 【冲突】0052「わたしはねえ！　本当は一度だって／妹に勝ったことがないのよ！」，和本线前面她赢佑芽的场面对不上：第2话 0001“わたしの勝ちよ、佑芽！”、第6话 0001“今回もわたしの勝ちよっ！”。同一篇 0055 又说自己是「勝ち逃げしてきた」（赢了就跑、没输过），0038、0074 也说「一度だって負けたくない」「一度でも負けたら」，与“一次都没赢过”字面上相反。
- 和第3话的说法有出入：第3话 0037～0039 说放弃以前的运动是因为体格不好、知道当不了世界第一，0060 说“何度も負けて、諦めてきた”；本篇 0054 说是每次快输给妹妹时逃到别的竞技，0058～0060 又补充了“想赢佑芽”的动机。是说法补充还是对不上，待确认。
- 0064～0065：她说「どう！　今度こそ見損なったでしょ！」后惊讶「――っ！？」，制作人做了什么没写进剧本。
- 【已确认 2026-11-11】三·1：按建议：表面理由（体格小也能争世界第一）→ 藏着的理由（想赢佑芽）→ 憧憬星南 → 选学校的现实考虑，按这个顺序写。
