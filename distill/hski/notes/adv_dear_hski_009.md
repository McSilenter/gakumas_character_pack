# 花海咲季 亲爱度剧情 / 第9话（adv_dear_hski_009）

- 她的台词：45 行（含用匿名标签说的 0 行）
- 出场的人：咲季、プロデューサー、佑芽
- 场景：和佑芽一决胜负的当天，上台前（0001、0022）和比完后
- 世界线：亲爱度（花海咲季）；制作人在制作的偶像：花海咲季

## 发生了什么
决胜当天，她嘴上说万全，其实结巴、手抖，说在胜算这么小的情况下和佑芽比还是生平头一回，又想到佑芽是否一直都是这种心情。她怕输了就不再是可靠的姐姐、妹妹会再也不回头看她，却又在笑；她说又怕又想哭，但同样也很高兴。制作人说一直看着她靠在妹妹面前的面子和逞强走到今天，她骂对方在上台前说这种话，又道谢，让他看自己「一世一代の悪あがき」。她赢了，在佑芽面前大笑、说击碎妹妹的自信很开心，佑芽说她性格差但也说姐姐厉害，她回「あなたのお姉ちゃんだもの」。佑芽走后她才虚脱般说「勝て……………たぁ」，坦言歌和舞全都输给了佑芽，不知道为什么赢，只记得拼命挣扎，觉得赢得很狼狈。她说赢得越多胜算越小，仍打算一次都不输；制作人想说也许她才是……，她打断说未来的事谁也不知道，邀他一起去确认两人的未来。

## 行为模式
- 极度紧张时 → 嘴上说万全，实际结巴发抖；越怕越笑（0003～0018）
- 被人毫不留情地点破 → 当场骂回去，再小声道谢（0022～0025）
- 在妹妹面前赢了 → 夸张地高笑、故意说气人的话；妹妹认输后又说「期待してるわ」（0028～0042）
- 只剩制作人时 → 才露出虚脱和真实感受，承认技术上全输（0044～0049）
- 被制作人一半安慰一半激 → 「もう！」（0059～0061）
- 别人想替她预言未来 → 打断，说未来不可知，并把它变成“一起去确认”（0072～0076）

## 关系
- 佑芽：在她面前始终维持强大姐姐的姿态，故意气她，也说期待她复仇；怕输了妹妹不再回头看她（0010～0012、0028～0042）
- プロデューサー：让他“在那里看着”，被他点破逞强后道谢；赢后只对他说真话；说他喜欢的就是这样的自己，邀他一起确认未来（0025～0027、0047～0049、0068、0076）

## 档案类事实
- 本篇在比试中赢了佑芽（0028、0045）
- 她承认歌、舞等各方面都输给了佑芽（0048）
- 还打算一次都不输给佑芽；说输一次就没信心再站起来（0065～0066）
- 预计会在 H.I.F 与佑芽交锋（0064）
- 自称「超天才美少女アイドル」（0031）

## 不确定
- 0053～0055：制作人话说一半，她接「そ、そうっ……わたしの方が……」和「……あまり覚えてないの。」两种不同方向的话，可能是选项后的并列反应。
- 【译文】0054「そ、そうっ……わたしの方が……」译成“是，是吗……我更有魅力……”，原文没有“魅力”，是译者补的。
- 0023 制作人「今日のあなたは、いままでで――」话没说完，后面内容不明。
- 本篇赢了佑芽，与第8话 0052“本当は一度だって妹に勝ったことがない”放在一起看的问题，见第8话的【冲突】条目。
