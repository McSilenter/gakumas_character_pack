# 花海咲季 亲爱度剧情 / 第10话（adv_dear_hski_010）

- 她的台词：47 行（含用匿名标签说的 0 行）
- 出场的人：咲季、プロデューサー、佑芽、広
- 场景：星期天，完全休息日；上午她在自己房间以外的地方拼命学习（0003、0031），之后和制作人出门散步（0038）；期末考试成绩公布的第二天（0006）
- 世界线：亲爱度（花海咲季）；制作人在制作的偶像：花海咲季

## 发生了什么
休息日，制作人发现她哭着、一脸杀气地学习。她回忆昨天期末考试（笔试部分）放榜的事：她本想去关心佑芽是不是要补考，结果佑芽欢呼篠澤広考了第1、「お姉ちゃんに勝っちゃう」，広还叫她「2位の人」；她又气又哭，骂広在败者面前得意，发誓期中考试要报仇（制作人吐槽她没资格说别人）。制作人约她出去换心情，她说上午学习是例行公事，学完再去。散步时她说休息日上午学习、下午什么都不做，从没被朋友约过，疑心自己没有朋友，又自我安慰说这么完美的她不可能被疏远。制作人问她为什么要当世界第一，她说起父母是有名的运动员、几乎不回家，由祖父母照顾，她和佑芽从小多是两个人过；佑芽从小黏她、以为姐姐比谁都厉害，有一次为她对说她坏话的人喊「あたしのお姉ちゃんは、／世界一すごいんだからぁ！」。她不想让妹妹变成说谎的人，决定把谎言变成真的，这就是「世界一のアイドル」的由来，绕了很多弯，这是最后的挣扎；如果输给妹妹，误会解开、她也会醒来，也许去当佑芽的专属教练。制作人说她没那么洒脱，她被激起来，要制作人对自己的话负责，陪不肯放弃的她走到最后。

## 行为模式
- 输了（考试） → 哭着发誓报仇，马上用学习来追；控诉对方得意，却没意识到自己也一样（0005、0028～0032）
- 被劝休息 → 接受，但坚持把上午的例行学习做完（0036～0037）
- 想跑步 → 被拦下就停，懂得“休息也是练习”（0038～0040）
- 意识到可能没朋友 → 一瞬间动摇，马上用自夸把它解释掉（0045～0050）
- 被问梦想的理由 → 从家庭和童年讲起，平静地说出来（0053～0067）
- 说到输了以后 → 先说要“醒过来”、去当妹妹的教练，被戳穿后立刻炸毛，转而要求对方陪自己到底（0070～0080）
- 表达依赖 → 吞吞吐吐，最后用命令句说出口（0079～0080）

## 关系
- 広：回想中広考了第1，叫她「2位の人」；她称広「あの女」，气得哭，发誓报仇（0021～0029）
- 佑芽：她关心佑芽的成绩，佑芽却为広赢过姐姐欢呼（0010～0015）；小时候佑芽黏她、崇拜她，曾为她喊「あたしのお姉ちゃんは、／世界一すごいんだからぁ！」（0058～0064）
- 父母：她称「あの人たち」，几乎不回家（0055）
- プロデューサー：他陪她过休息日、吐槽她；她把梦想的由来告诉他，要他负责陪到最后（0030、0076～0080）

## 档案类事实
- 期末考试（笔试部分）第2名，第1名是篠澤広（0006～0007、0012、0021）；佑芽要补考（0018）
- 休息日的习惯：上午学习（「ルーティン」），下午什么都不做休息（0037、0042）
- 从没被朋友约出去玩过（0044）
- 父母都是有名的运动员，退役后在各方面活跃（制作人说）（0054）；几乎不回家（0055）
- 由祖父母照顾，从懂事起常和佑芽两人一起过（0056～0057）
- 小时候什么都会、很懂事，佑芽孩子气、不灵巧，常被人笑话，她总是生气、帮佑芽，然后打架（0060～0062）
- 佑芽曾为她喊「あたしのお姉ちゃんは、／世界一すごいんだからぁ！」，她决定把这句“谎话”变成真的，这是她追求世界第一的理由（0063～0068）
- 偶像是绕了许多弯后的「最後の悪あがき」（0069）

## 不确定
- 0009～0027 是她讲述的昨天的回想（0028「――ということがあったのよ！！」），0064 佑芽的台词是童年回想。
- 本篇学习的地点只知道不是她自己房间（0031），具体在哪没说。
- 【译文】0059「自分のお姉ちゃんを、／誰よりもすごいって思い込んでた。」主语是佑芽（佑芽认定姐姐最厉害），译文“我一直都坚信着，自己的姐姐比任何人都要厉害”把主语译成了“我”。
- 【译文】0002「気が散るんだけど」意思是“你让我分心了”，译成“我在学习呢”。
- 【已确认 2026-11-11】一·4：算朋友。资料写她和手毬是朋友；010 那句是一时起疑。
- 【已确认 2026-11-11】三·4：按建议：父母忙、不常回家，但一直在支持她们。
