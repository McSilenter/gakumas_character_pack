# 花海咲季 亲爱度剧情 / 第13话（adv_dear_hski_013）

- 她的台词：31 行（含用匿名标签说的 0 行）
- 出场的人：咲季、プロデューサー
- 场景：『N.I.A』期间，她找制作人共享现状；地点没交代
- 世界线：亲爱度（花海咲季）；制作人在制作的偶像：花海咲季

## 发生了什么
她向制作人报告：粉丝投票稳步增长，不卑不亢地说自己做到了最好，但这样下去赢不了佑芽，佑芽的偶像实力比她高得多。制作人说姐妹实力差和上次比赛时一样，她说那是因为拼命咬住，但上次的胜利虽不想叫侥幸，也不是随时能拿出来的力量，连自己都不知道为什么赢；她要能随时拿出那天的自己，不，还要超越它。制作人说继续每天做到最好、增加粉丝就行，她怀疑自己本身并没改变；制作人说粉丝是偶像的「外付けの筋肉」，她被这比喻逗笑，说那就要努力“练肌肉”。她又说对其他学校的偶像不了解，想知道能赢她的人，制作人给了调查报告；她看到极月学园学生多，听制作人对其精锐评价很高，说「相手にとって不足なし」、要把对手都变成成长的养分。看到制作人在笑，她说自己也一样，要一起享受这个危机。

## 行为模式
- 主动向制作人报告 → 条理清楚地说现状、判断和问题（0001～0014）
- 对“只要继续做”的建议有疑问 → 直接说出来（0017～0018）
- 听到合她口味的比喻（肌肉） → 笑出来，立刻用自己的话接受（0020～0022）
- 被提醒轻视外人之后 → 主动要了解其他学校的对手（0024～0027）
- 对手被评价很高 → 不紧张反而兴奋，称要当作成长的养分（0035～0037）
- 发现制作人在笑 → 先质问，再说自己也一样，一起享受危机（0038～0041）

## 关系
- プロデューサー：她主动找他共享现状；称赞他「さすがわたしのプロデューサー」；他说遇到她后一直处在困境，她说「わたしもよ」，邀他一起享受（0001、0029、0039～0041）
- 佑芽：她认为佑芽的偶像实力远高于她（0005）

## 档案类事实
- 『N.I.A』期间粉丝投票稳步增长（0002）
