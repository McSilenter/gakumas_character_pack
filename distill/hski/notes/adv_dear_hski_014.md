# 花海咲季 亲爱度剧情 / 第14话（adv_dear_hski_014）

- 她的台词：30 行（含用匿名标签说的 0 行）
- 出场的人：咲季、燐羽、佑芽、プロデューサー、？？？
- 场景：『N.I.A』的某场试镜（同时有演出）会场，她和制作人去看佑芽（0001、0011）
- 世界线：亲爱度（花海咲季）；制作人在制作的偶像：花海咲季

## 发生了什么
她拉制作人去看佑芽的演出，说既作为偶像粉丝享受超可爱的佑芽、又作为偶像享受最强的对手，「一粒で二度おいしい」，是引以为傲的姐妹关系。制作人提醒佑芽今天未必能上台，她断言佑芽不可能输给她以外的偶像，说这不是大意而是「愛する者への信頼」。结果佑芽输了，赢的是前『SyngUp!』队长、原初星学园1年3组的賀陽燐羽。她让制作人先回去，去找佑芽；佑芽强装兴奋夸对方，她骂佑芽输给别人还高兴，说空元气没意义，告诉佑芽输一次哭一次她都不会失望，提醒『FINALE』的约定，给她擦鼻涕眼泪，说要替她报仇。燐羽出现，说自己是佑芽的粉丝、来安慰她，又说之后不再参加试镜；她瞪着燐羽要求一决胜负，燐羽说讨厌她这种人、说她没什么才能还说不负责任的话。佑芽替姐姐顶回去后，燐羽改变主意，说再参加一次试镜，叫她「咲季お姉ちゃん」，说要在妹妹面前剥掉她的镀金。

## 她的关键台词
- 0005「まだまだ甘いわね。いちアイドルファン／として、超可愛い佑芽を堪能する。」——以粉丝身份看妹妹

- 0009「いいでしょ～、自慢の姉妹関係なの。」——为姐妹关系自豪
- 0014「フッ……天地がひっくり返っても／あり得ないわ！」——不信妹妹会输给别人
- 0016「聞く必要なし！　これは油断じゃない。／――愛する者への信頼よ！！」——对妹妹的绝对信任
- 0020「えぇえぇえぇ～～～～～～～～～ッ！？」——妹妹输了时的震惊
- 0025「宿命のライバルを／復活させてから帰るわ。」——去安慰妹妹的说法
- 0030「わたし以外のやつに負けて、／はしゃいでいるんじゃなぁ～～～いっ！」——不许妹妹装作没事
- 0032「空元気じゃ意味ないでしょ。」——看穿空元气
- 0035「ばかね、何年姉妹やってると／思ってるの？」——以多年姐妹的身份安慰妹妹
- 0037「失望なんてするわけない。」——回应妹妹的担心
- 0041「ほら、鼻かんで。涙を拭いて。」——照顾妹妹
- 0043「お姉ちゃんが仇を討ってあげる！」——替妹妹出头
- 0061「賀陽燐羽！　わたしと勝負しなさい！／佑芽の仇を討ってやるわ！」——当面挑战

## 行为模式
- 谈到妹妹 → 同时以粉丝和对手的身份为她兴奋，夸耀姐妹关系（0005～0009）
- 有人暗示妹妹会输给别人 → 不听、断然否定，称之为信任（0012～0016）
- 妹妹输了强装没事 → 先骂她“输给别人还高兴”，戳穿空元气，再告诉她不会失望，像照顾小孩一样给她擦脸（0026～0041）
- 妹妹被人打败 → 当场以姐姐身份宣布报仇，直接向对手下战书（0043、0061）

## 关系
- 佑芽：她说既是粉丝也是对手、「自慢の姉妹関係」；佑芽输后，她不许佑芽强颜欢笑，说「失望なんてするわけない」，要替她报仇（0005～0009、0030～0043）。佑芽说不想让姐姐看到自己沮丧（0034），又对燐羽喊「あたしのお姉ちゃんは…………／あなたなんかに絶対負けないっ！」（0065）
- 燐羽：她称对方全名「賀陽燐羽」（0023、0061）；燐羽说讨厌她这种人、说她「たいした才能もないくせに」，叫她「咲季お姉ちゃん」，说要「妹の前で、メッキを剝がしてあげる」（0062～0071）
- プロデューサー：她让他先回去，自己去安慰妹妹（0024）

## 档案类事实
- 佑芽在『N.I.A』的一场试镜中输给了賀陽燐羽（0017～0018、0023）
- 制作人介绍：燐羽是初星学园中等部第一组合『SyngUp!』的前队长、原初星学园1年3组（0021～0022）
- 燐羽说自己现在是极月学园胜场最多的人（0058）
- 她和佑芽约好在『FINALE』直接对决（0038～0039）
