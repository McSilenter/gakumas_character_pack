# 花海咲季 亲爱度剧情 / 第15话（adv_dear_hski_015）

- 她的台词：18 行（含用匿名标签说的 0 行）
- 出场的人：咲季、プロデューサー
- 场景：她向制作人宣布要挑战的试镜『QUARTET』，上台前（0001～0002、0021）
- 世界线：亲爱度（花海咲季）；制作人在制作的偶像：花海咲季

## 发生了什么
她宣布要挑战的试镜是『QUARTET』，见制作人反应平淡，以为他还在气她擅自定下比赛。制作人说一开始就没生气，反而佩服她，这正是她缺的「格上のライバル」。被制作人称「燐羽様」，她吃醋地喊“难道你也是那家伙的粉丝”。她说比佑芽弱的自己要赢赢过佑芽的对手，明知不利，可上次那么严重的手抖今天却没有；她说制作人讲的“粉丝是外接肌肉”也许真是力量来源。她要制作人好好看她的演出、重新迷上她，说要用意气、面子、实力和「外付けの勇気」替妹妹报仇。

## 她的关键台词
- 0004「……なに？　まだ勝手に／勝負を決めてきたこと、怒ってるの？」——自己也知道擅自定了比赛
- 0007「そ、そ～お？　えへへ……なんで／褒められてるのかわからないけど。」——不明就里地被夸也高兴
- 0010「相手にとって不足なし！　でしょ？」——把强敌当成正合心意的对手（第13话也说过）
- 0013「まさかプロデューサーまであいつの／ファンなんじゃないでしょうね！」——对制作人称对手「様」的反应
- 0014「許さないわよ！　わたしという／ものがありながら！」——吃醋式的说法
- 0016「佑芽より弱いわたしが、／佑芽に勝った相手に勝つ。」——清楚自己的处境
- 0018「なのにどうしてかしら……あんなに／ひどかった手の震えが、今日はないの。」——和第9话对比
- 0020「確かにこれは……力の源なのかもね。」——接受粉丝是力量来源
- 0021「わたしのライブ、よーく見て、／惚れ直しなさいプロデューサー。」——对制作人的命令口吻
- 0022「意地と見栄と実力と……／外付けの勇気でぇっ！」——她的武器清单
- 0023「妹の仇を討ってくるわ！」——上台的动机是替妹妹报仇

## 行为模式
- 自己擅自做了决定 → 察觉对方反应冷淡，就主动问“还在生气吗”（0003～0004）
- 被夸但不知道原因 → 照样傻笑接受（0007）
- 制作人对别的偶像表示敬意 → 吃醋，「わたしという／ものがありながら！」（0012～0014）
- 面对不利的比赛 → 冷静承认劣势，同时察觉自己状态反而很好（0016～0018）
- 上台前 → 命令制作人看着自己，说要让他「惚れ直し」（0021）

## 关系
- プロデューサー：她擅自定了比赛，担心他生气；不许他当对手的粉丝；要他看演出、重新迷上她（0004、0013～0014、0021）
- 燐羽：称「あいつ」；以替妹妹报仇为由挑战她（0013、0023）
- 佑芽：她说自己比佑芽弱（0016）

## 档案类事实
- 她要挑战的试镜是『QUARTET』，对手是燐羽（0002、0009）；这场比赛是她自己擅自定下的（0004）
- 她说自己比佑芽弱（0016）
- 这次上台前手不抖了（0018，对比第9话 0007）

## 不确定
- 0012～0015：0015「ふふっ、当然よね。」和 0012～0014 的吃醋反应方向不同，可能是制作人不同选项后的并列反应。
- 【译文】0019「ファンは外付けの筋肉だって／あなたは言ってたけど。」译文多出“但事实真是这样吗？”，原文没有这层质疑。
