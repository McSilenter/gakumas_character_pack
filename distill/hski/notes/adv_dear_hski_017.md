# 花海咲季 亲爱度剧情 / 第17话（adv_dear_hski_017）

- 她的台词：21 行（含用匿名标签说的 0 行）
- 出场的人：咲季、佑芽、プロデューサー、燐羽（只在回想中）
- 场景：她一场演出结束后回到制作人那里，佑芽在等（0001～0006）；后半她向制作人讲述刚才的事（0033）
- 世界线：亲爱度（花海咲季）；制作人在制作的偶像：花海咲季

## 发生了什么
她演出回来，制作人说有重要的客人在等，原来是还在生气的佑芽。佑芽说她被别人叫「お姉ちゃん」时一脸陶醉，之后一直发呆；她辩解是在意之前被说的话（燐羽那句「メッキなんてない方が素敵」的回想），却不肯说出内容，佑芽更觉可疑。她问怎样才能消气，佑芽说按约定在『FINALE』和她比、赢了就原谅；她说“就这点事？”，还说自己赢了赢过佑芽的人，所以姐妹实力差距很大；佑芽说现在的自己不同了，她说那就用实力证明，姐姐接受挑战。之后她向制作人坦白自己摆了姐姐架子，问他怎么看；制作人说数据显示佑芽只有在和她比时会变得更强，她喊「知ってる～～～～～～～～～～～～！」，说那正是佑芽的好处，下一个目标是『FINALE』。

## 行为模式
- 妹妹闹别扭 → 先喊冤，再想办法哄（0007～0018）
- 被问到让她心动、难为情的事 → 不肯说（0013～0016）
- 和妹妹约战时 → 故意摆姐姐架子挑衅，激她拿出实力（0022～0029）
- 事后冷静下来 → 向制作人承认自己摆了架子，征求意见（0033～0034）
- 听到对自己不利的分析 → 一边哀叫「知ってる」，一边说那正是妹妹的好处（0038～0039）

## 关系
- 佑芽：佑芽因燐羽叫她「お姉ちゃん」、她又一直发呆而吃醋生气；她哄妹妹，约定『FINALE』决胜，赢了妹妹才原谅她（0007～0032）
- プロデューサー：她回来时说「ただいま」；事后把和妹妹的对话讲给他听、问他意见（0001、0033～0034）
- 燐羽：燐羽那句话让她一直在意，但她不肯说出来（0013～0016）

## 档案类事实
- 制作人的数据：佑芽只有在和她比时会变得更强，她早就知道（0035～0038）
- 下一个目标是『FINALE』（0040）
