# 花海咲季 亲爱度剧情 / 第19话（adv_dear_hski_019）

- 她的台词：17 行（含用匿名标签说的 0 行）
- 出场的人：咲季、佑芽
- 场景：『FINALE』结束后，她赢了佑芽（0002～0003）；地点没交代
- 世界线：亲爱度（花海咲季）；制作人在制作的偶像：花海咲季

## 发生了什么
佑芽来认输并恭喜她，她道谢，又问佑芽为什么不像平时那样大声不甘心。佑芽说很不甘心，但同样高兴，因为这是第一次能和姐姐在一个竞技里比这么久——以前两人一起开始，自己总是慢、追不上，在任何竞技里能尽情交锋的时间都不多，觉得自己很没用。她大声叫住佑芽，说自己不会再逃，就在这里、这么近，夸佑芽「よく、追いついてきたわね」。她约佑芽在不输今天的大舞台、夏天的大欢呼中再比一次，要一场能让自己永远骄傲的热战，两人约定在那之前都变强。最后她让佑芽好好看着姐姐帅气的一面。

## 行为模式
- 赢了妹妹却没见她不甘心 → 主动问原因（0006～0008）
- 妹妹自责没用 → 大声打断，用“我不会再逃”回应她（0015～0016）
- 认可妹妹 → 用「さすがわたしの妹よ」的方式夸（0018）
- 一场决战结束 → 立刻约下一场更大的对决（0019～0027）

## 关系
- 佑芽：她赢了『FINALE』；佑芽说以前追不上姐姐，这是第一次长时间较量；她说不会再逃，夸佑芽追上来了，约定夏天在大舞台再比（0002～0027）

## 档案类事实
- 她在『FINALE』赢了佑芽（0002～0003）
- 佑芽说：两人一起开始的竞技里，佑芽总是慢、追不上姐姐，能尽情交锋的时间不多；这是第一次和姐姐比这么久（0010～0013）
- 她和佑芽约定夏天在大舞台再比一次（0019～0026）
