# 花海咲季 亲爱度剧情 / 第22话（adv_dear_hski_022）

- 她的台词：39 行（含用匿名标签说的 0 行）
- 出场的人：咲季、佑芽、プロデューサー、学園長
- 场景：『H.I.F』当天，她第一个出场的演出刚结束，之后观看佑芽的演出和结果发表（0001、0008～0012、0018）
- 世界线：亲爱度（花海咲季）；制作人在制作的偶像：花海咲季

## 发生了什么
她演出回来，说倾尽了花海咲季的一切，能在粉丝面前挺胸说尽力了，感觉超越了极限，这样都赢不了就绝对赢不了。被制作人叫住后，她说高兴太早，『H.I.F』才刚开始，邀他一起为接下来出场的妹妹应援。看着佑芽的演出，她说「すごいわ……佑芽……」「――わたしのアイドル。」「あなたの勝ちよ。」；学园长宣布夏之『一番星』是花海佑芽。她和佑芽相拥，祝贺妹妹，说这是生来第一次这么开心，把至今遇到的所有偶像算上，花海佑芽是第一名。佑芽哭了，她说赢了还哭不像话，又说佑芽不知不觉长得比她高、力气比她大、跑得比她快；佑芽求她别这么说，说花了15年终于追上，「あたしを置いていかないで！！」。她说就算比妹妹小，自己也是佑芽的姐姐，不会让她一个人。她问佑芽喜不喜欢偶像，佑芽说有了自己的梦想、要凭自己的意志成为顶级偶像；她说从演出里全都感受到了，祝福「アイドル・花海佑芽の誕生」。

## 她的关键台词
- 0003「ええ！　／花海咲季のすべてを出し切った。」——对自己演出的评价
- 0006「もしもこれで勝てないのなら、／もう絶対勝てないって！」——自认已到极限
- 0008「ごめんなさい、喜ぶのは早いわね！／『H.I.F』は、／はじまったばかりだもの。」——得意马上收住，提醒自己比赛未完
- 0012「見て！　あれがわたしの妹よ！！」——在台下为妹妹骄傲
- 0016「――わたしのアイドル。」——把妹妹称为“我的偶像”
- 0017「あなたの勝ちよ。」——在结果发表前就认输
- 0025「こんなに楽しい気分になったのは、／生まれてはじめて！」——妹妹的演出让她前所未有地快乐
- 0029「花海佑芽が、一等賞よ！」——输了之后对妹妹的最高评价
- 0033「こーら。だめじゃない。／わたしに勝っておいて泣くなんて。」——输了还安慰赢了的妹妹
- 0038「いつの間にか、あなたはわたしの背を／追い越していたわね。」——感慨妹妹长大（个子比她高）
- 0048「妹よりもちっちゃくったって、／わたしは佑芽のお姉ちゃんよ！」——承认个子比妹妹小，但姐姐身份不变
- 0049「あなたをひとりになんて……／させないわ。」——回应妹妹“别丢下我”
- 0051「――アイドルは好き？」——问妹妹是否喜欢偶像
- 0061「アイドル・花海佑芽の誕生を！」——祝福妹妹作为偶像真正诞生

## 行为模式
- 演出结束 → 说出全力以赴的实感，然后马上收住，转去为对手（妹妹）应援（0003～0011）
- 看到妹妹出色的表现 → 发自内心地赞叹，在结果出来前就自己承认输了（0013～0017）
- 输给妹妹 → 在妹妹面前不表现出不甘，全心祝贺、夸到极致（0020～0029）
- 妹妹哭了 → 用姐姐的口吻哄，说起妹妹长大的事（0033～0041）
- 妹妹怕被丢下 → 立刻说「当たり前じゃない」，强调自己仍是姐姐（0047～0049）

## 关系
- 佑芽：她称佑芽为「わたしのアイドル」，在佑芽夺冠后说「花海佑芽が、一等賞よ！」；佑芽说花了15年追上她，求她别丢下自己，她说不会让佑芽一个人；祝福「アイドル・花海佑芽の誕生」（0016、0029、0044～0061）
- プロデューサー：她邀他一起为佑芽应援（0011）

## 档案类事实
- 『H.I.F』中她第一个出场，自认为倾尽全力、超越了极限（0003～0005、0009）
- 夏之『一番星』是花海佑芽（0018～0019），即她输给了佑芽
- 佑芽比她高，力气比她大，跑得比她快（0038～0041、0048）
- 佑芽说花了15年追上姐姐（0044）
- 佑芽有了自己的梦想：凭自己的意志成为顶级偶像（0053～0056）

## 不确定
- 0044 佑芽说「15年かかって」，第23话 0037 她也说“15年ぶんのわたし”；姐妹俩同为1年级（第2话 0023，第5话 0005 同样的作业），年龄和年级的关系剧本没交代。
