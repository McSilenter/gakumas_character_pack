# 花海咲季 亲爱度剧情 / 第23话（adv_dear_hski_023）

- 她的台词：52 行（含用匿名标签说的 0 行）
- 出场的人：咲季、プロデューサー
- 场景：『H.I.F』结果发表、她祝福佑芽之后，她一个人待着的地方，制作人找来（0001～0005）
- 世界线：亲爱度（花海咲季）；制作人在制作的偶像：花海咲季

## 发生了什么
制作人说找了她很久，她说他撒谎，明明一直躲着守望她，问自己刚才是否把姐姐的样子撑到了最后；制作人说当然，因为她一句谎话都没说。她说不会让妹妹一个人、为佑芽成为真正的偶像打心底高兴，都是真的；接着说今天她用尽全力、借了制作人和粉丝的力量向星星伸手，「届かなかったわね」，第一次输给妹妹，差距那么高那么远，然后大喊「悔しい！！！」，随即说抬起头再跑一次，这次作为挑战者追妹妹。制作人内心独白：他从一开始就预见她总有一天会输，事先准备了为“没有制作人的花海咲季”压倒性胜出、赌上自己存在意义的计划，也就是不去帮她、让她化作火球燃尽、留下传说一起结束的路线。她说自己没事——其实不太没事——如他所说她不洒脱，身体在吼着前进，15年的自己在喊别放弃，问「わたしの相棒」会不会陪她到最后。制作人宣布废弃全部计划；她说早已感受到他的心意和烦恼，握住他的手，请他待在身边、比以前更近地帮她，说不会再在他面前逞强。她说他当初梦想中孤高、苛烈、不屈无敌的花海咲季，她已经成不了了，但被他制作的这个她才是最强的她，承诺把他的选择变成正确答案，两人一起培育新的花海咲季。

## 行为模式
- 输了之后 → 在妹妹面前撑住，独处时才问制作人自己是否撑住了（0004～0005）
- 说出失败 → 平静说完，然后大喊不甘心，紧接着就要求自己“抬头再跑”（0014～0021）
- 被担心 → 说“没事”，又老实补一句“其实不怎么没事”（0030～0031）
- 预想中“输了就完蛋”的自己没出现 → 承认自己不洒脱，身体和心都要她继续（0033～0039）
- 制作人选择放弃原计划来帮她 → 说早就感受到他的烦恼，主动握手，明确请求依靠，不再逞强（0062～0069）
- 意识到自己不是对方最初设想的样子 → 不道歉，而是宣称现在的自己才最强，并承诺证明他的选择正确（0071～0077）

## 关系
- プロデューサー：她看穿他一直在暗中守望；称他「わたしの相棒」「パートナー」；他废弃原计划后，她握住他的手，请他「ずっとそばで……／わたしを助けて」，说不会再在他面前逞强，两人一起培育新的花海咲季（0002～0003、0040、0064～0083）。制作人内心独白显示他原本计划不帮她、让她燃尽（0023～0057）
- 佑芽：她为佑芽成为真正的偶像高兴，决定作为挑战者去追妹妹（0009、0021）

## 档案类事实
- 『H.I.F』中她输给佑芽，她说这是第一次输给妹妹（0014～0015）
- 她说“15年的自己”在喊别放弃（0037）
- 制作人原本的计划是“为没有制作人的花海咲季也能压倒性胜出”的路线，本篇宣布全部废弃（0029、0060）
- 她承诺把制作人的选择变成正确答案（0077）

## 不确定
- 0023～0057 是制作人的内心独白，她没听见；她 0063「あなたの気持ちも、悩みも……」说感受到了，但具体知道多少不明。
- 0061～0062：制作人说废弃计划后，她先问「そう……それで？」，又说「もうプロデュースされているじゃない。」，中间可能有没写出的选项或动作。
- 0015「はじめて――……妹に負けちゃった。」和第8话 0052“本当は一度だって妹に勝ったことがない”的关系，见第8话【冲突】条目。
- 【译文】0005「お姉ちゃんらしく／振る舞えていたかしら」译成“有把姐姐的样子伪装到最后吗”，原文没有“伪装”的意思（制作人随后说她没说一句谎话）。
- 【译文】0067「わたしを助けて」译成“继续支持我”，弱化了“救我、帮我”的意思；这和制作人 0057「『彼女を助けない』」形成对照，译文没体现。
