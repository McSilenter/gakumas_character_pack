# 花海咲季 亲爱度剧情 / 第28话（adv_dear_hski_028）

- 她的台词：50 行（含用匿名标签说的 0 行）
- 出场的人：咲季、プロデューサー、星南
- 场景：为冬季『H.I.F』开会（地点没交代），『選抜試験』开始前（0002、0048）
- 世界线：亲爱度（花海咲季）；制作人在制作的偶像：花海咲季

## 发生了什么
她招呼制作人为冬季『H.I.F』开会，自己先回顾：夏季『H.I.F』她输给佑芽，佑芽超过她、成为真正的偶像，还击败星南当上『一番星』；制作人说佑芽已被世界偶像粉丝视为踏入顶级偶像领域，她得意地说「自慢の妹よ！」，又说不能默默看着，因为她是姐姐也是对手。她回顾和星南、燐羽结盟特训、星南复权为顶级偶像，问自己现在有没有资格再挑战『一番星』，被说弱气时说「あなたの前だもの」。制作人说她已能和职业偶像抗衡、不输历代『一番星』，但仍不是优胜候补，她自己也说世间看作佑芽和星南的一对一。被说“你看起来很开心”，她说又怕又痛苦、一不留神就会哭，但已经不迷茫：有他、有粉丝、有她的承诺，她凭自己的意志决定要赢过已经不存在的『無敵の花海咲季』，只能笑着前进。她又把选拔试验当成最好的冲刺训练，制作人说她又把制作人的台词说完了。制作人说要锻炼『無敵の花海咲季』没有而她有的东西，她猜是“最好的搭档——你”，制作人说某种意义上是，脸红了，她也害羞；制作人揭晓是两人一起培养的、已和当初计划完全不同的曲子『Wildest Flower』，她说这是她之为她、和他同在的证明，是『不屈の花海咲季』的歌，要带着它再挑战顶点。

## 行为模式
- 开会 → 自己主持，先做“局势确认”，包括自己输掉的事（0004～0008、0034～0035）
- 提到妹妹的成就 → 先骄傲地傻笑，再马上转为“不能只看着”的竞争心（0011～0014）
- 在制作人面前 → 直接说出不安、要他告诉自己实情（0020～0023）；但对局势的冷静判断往往自己先说出来（0028、0032～0033）
- 被说“看起来很开心” → 否认，说又怕又苦，但不迷茫，理由一条条列出（0036～0044）
- 制作人还没说完 → 她把制作人要说的话抢先说完，被指出就说“这是理所当然的前提”，再把话头交回去（0048～0056）
- 猜谜 → 立刻给答案；猜的答案让对方脸红时，她自己也害羞起来（0061～0066）

## 关系
- プロデューサー：称「わたしの相棒」「最高のパートナー」（0047、0062）；在他面前不逞强（0022）；兑现“把你的选择变成正确答案”的承诺（0041）；他说要用自己的制作让她赢（0046）
- 佑芽：「自慢の妹」，也是对手（0011～0014）；她说佑芽击败星南成为『一番星』（0008）
- 星南：同盟者，已复权为顶级偶像（0017～0019）；本篇只有 0016 一句（回想式插入）

## 档案类事实
- 夏季『H.I.F』她输给佑芽；佑芽也击败星南，成为『一番星』（0005～0008）
- 制作人说佑芽已被视为踏入顶级偶像领域（0009～0010）
- 星南已复权为顶级偶像（0019）
- 制作人说她已能和职业偶像抗衡，不输历代『一番星』，但不是冬季『H.I.F』的优胜候补；世间视为佑芽和星南的一对一（0025、0030～0033）
- 她的曲子『Wildest Flower』是她和制作人一起培养的，和当初计划准备的曲子已完全不同；她称之为『不屈の花海咲季』の歌（0068～0071）
- 冬季『H.I.F』之前有『選抜試験』（0048）
