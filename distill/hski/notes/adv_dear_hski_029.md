# 花海咲季 亲爱度剧情 / 第29话（adv_dear_hski_029）

- 她的台词：46 行（含用匿名标签说的 0 行）
- 出场的人：咲季、プロデューサー、燕
- 场景：前半是练完『Wildest Flower』后和制作人的对话；后半是她去找雨夜燕提出结盟（地点没交代）（0001～0004、0049）
- 世界线：亲爱度（花海咲季）；制作人在制作的偶像：花海咲季

## 发生了什么
她唱完经作曲家进一步打磨的『Wildest Flower』，制作人说她完美掌握，她说还不认为这就完成了；制作人说偶像的歌没有真正的完成，梦结束后也会继续活下去，她说他总是一边夸一边抬高门槛，干劲更足了，问该为“正在成长的这孩子”做什么。制作人说在实战中尽情唱，她说那就是3次的『選抜試験』；制作人说只是突破试验到不了“我们的目标之星”，她又高兴又不甘心。制作人说继续プロジェクト『星屑』就好，同盟的本质是走投无路的实力者暂时结盟；她说星南刚成为顶级偶像、燐羽在为『SyngUp!』的解散演出奔走，不适合做试验期间的同盟者。制作人提示新成员是她「心から尊敬している先輩」，她立刻明白，只担心说服困难，又被一句提示点通，并说他提示给太多了、想多享受和他的对话。她向雨夜燕提出结盟，燕拒绝：星南输给花海后自己连『学園No.2』都不是了，要重新磨牙、没空当可靠前辈。她说燕看起来很开心，说初星学园里最理解燕心情的一定是她，替燕说出“你身上没什么可得的、滚吧”，说燕是温柔的人会选择措辞。燕问有什么好处，她说花海家和初星学园已正式合作、器材会搬进学园、招募先行体验的偶像，又说这些都是附赠：她要的是本战前能尽情试实力的、可以成为假想『一番星』和假想顶级偶像的强敌，「欲しくはありませんか？　／都合のいい強敵が。」；燕接受挑战，说要在人生最后一次『選抜試験』当她的对手。

## 行为模式
- 被夸完成度高 → 道谢，但说还没完成（0005）
- 被抬高要求 → 指出对方的套路，然后说“有意思、更有干劲了”（0008～0010）
- 被提示 → 一点就通；提示太直白时反而抱怨不能多享受对话（0039～0047）
- 说服别人 → 先猜中对方的拒绝（「そういうと思いました。」0050），再点破对方心情（0056～0064），然后摆出对方能得的实利，最后说那只是附赠、说出真正的要求（0066～0084）
- 对前辈 → 用敬语、称「雨夜先輩」，说话直率但不失礼（0050、0073）
- 面对比自己强的人 → 要对方当自己的“强敌”，同时说这对对方也有用（0079～0084）

## 关系
- プロデューサー：她说他总是边夸边加码（0008）；享受和他的对话，嫌他提示给太多（0047）；她自称和他是「駆け出し同士の／ペア」（0035）
- 燕：她称「雨夜先輩」、用敬语（0050、0073）；燕称她「貴様」「生意気な後輩」，最后叫她「咲季」（0085）；燕说是「修行仲間のよしみ」才听她说（0051）；制作人说燕是她「心から尊敬している先輩」（0038），她没否认；她说初星学园里最理解燕心情的是自己（0060），说燕「優しい方」（0064）
- 星南、燐羽：星南刚成为顶级偶像，燐羽在为『SyngUp!』的解散演出行动，她判断两人不适合当选拔试验期间的同盟者（0029～0030）

## 档案类事实
- 『Wildest Flower』经过和作曲家的会谈进一步打磨，她已掌握（0003～0004）
- 冬季『H.I.F』的『選抜試験』共3次（0013）
- 她在合宿后赢了『VisuaL master』（0022）
- 燐羽在为『SyngUp!』的解散演出而行动（0029）

- 燕说星南输给花海（佑芽）后，自己连『学園No.2』都不是了；这次是燕人生最后一次『選抜試験』（0052、0087）
