# 花海咲季 亲爱度剧情 / 第33话（adv_dear_hski_033）

- 她的台词：36 行（含用匿名标签说的 0 行）；其中括号内心独白 8 行（0011、0030、0031、0035～0039）
- 出场的人：佑芽、咲季
- 场景：佑芽从海外远征回国，来见她；后半在她的房间待了一整天，晚上留宿（0002、0040、0046）
- 世界线：亲爱度（花海咲季）；制作人在制作的偶像：花海咲季

## 发生了什么
佑芽回国，扑上来抱她，说想她、出生以来第一次和姐姐分开这么久；她心里大喊「わたしもよ！」，嘴上说佑芽爱撒娇，又说不是打过电话了吗，佑芽说想听声音时她总在睡觉，她说有时差没办法，然后夸佑芽辛苦了『一番星』的第一份工作。佑芽说和「100プロ」的前辈们海外远征处处是敌意、被打得落花流水，她问有没有回敬，佑芽说作为初星学园代表狠狠回了一击，她大夸「よくやったわ～～～！」；她提醒佑芽向星南道谢，因为有星南的『勝利宣言』，现役『一番星』出去必然成为靶子。她心里想：如果没遇到制作人，自己会以怎样的心情看着佑芽活跃，一定会用同样的表情说同样的台词，也会在没有那些曲子的情况下把思念化作火焰歌唱。她们在她房间聊天、互相按摩了一整天，佑芽说终于从偶像花海佑芽变回姐姐的妹妹；她说不能说懂『一番星』的重担，但让佑芽放松，同意佑芽留宿「特別よ。」。佑芽问顶级偶像是什么，说出了学园才知道世界那么大、顶点的人那么多，自己的梦想还有后续；她沉默很久只说「そう。」，被佑芽连叫三声「お姉ちゃん」后，说撒娇方式和小时候一样，深吸一口气大喊「すぐ追い抜くから、／待っていなさい！！！」；佑芽说和以前反过来了，以『一番星』身份接受她的挑战。

## 行为模式
- 妹妹撒娇 → 心里比妹妹还激动，嘴上维持“真拿你没办法”的姐姐口吻（0008～0012）
- 妹妹抱怨 → 先讲道理（时差），再给补偿（夸奖）（0013～0016）
- 妹妹说被打败 → 不安慰，先问有没有还击，得到肯定就大力夸（0025～0028）
- 妹妹的成就 → 联想到“没有制作人的自己”，认为那样的自己也会同样迎接妹妹、继续歌唱（0030～0039）
- 自己没经历过的事 → 不说懂，只让对方放松（0044～0045）
- 妹妹说出更远的梦想并等她回应 → 长时间沉默，被叫几声后接住，深吸一口气大声宣战（0060～0068）

## 关系
- 佑芽：她叫「佑芽」，佑芽叫她「お姉ちゃん」；这是两人生来第一次分开这么久（0009）；分开期间打电话，但有时差、佑芽想通话时她总在睡（0013～0015）；她夸佑芽『一番星』的初工作（0016）；让佑芽留宿「特別よ」（0047）；最后她向『一番星』佑芽宣战，佑芽说「いつもと逆だ」，叫她「花海咲季」接受挑战（0067～0072）
- 星南：她让佑芽向星南道谢，说星南有『勝利宣言』（0020～0022）
- プロデューサー：本篇不在场；她在内心想如果没遇到他会怎样（0030～0031）

## 档案类事实
- 佑芽作为『一番星』的第一份工作，是和「100プロ」的前辈们海外远征，期间和她只能打电话（0013～0018）
- 这是她们出生以来第一次分开这么久（佑芽说「生まれてはじめてかも」）（0009）
- 她作息早，佑芽想通话时她总在睡（有时差）（0014～0015）
- 她们在她的房间聊天、互相按摩一整天，佑芽留宿（0040、0046～0047）
- 佑芽说十王社长说现在是顶级偶像群雄割据的时代（0056）

## 不确定
- 「100プロ」是什么（事务所名？）本篇没解释；【译文】0018 译成「10OPro」，原文是「100プロ」。
- 0020 星南的『勝利宣言』内容本篇没说。
- 0030～0039 她想象“没遇到制作人的自己”，0037 列出的曲子和 0038「心強いあの子たちなしで……」指没有这些曲子的那个自己；和第27话制作人说的『彼女』（只存在于没遇到制作人的世界里）相呼应。
- 「お姉ちゃんの部屋」在哪里（宿舍还是家里）本篇没说。
- 【译文】0038「心強いあの子たちなしで」译成“不再依靠那些坚强的自己”，原文「あの子たち」指上面列的曲子，译文改成“自己”，有偏差。
