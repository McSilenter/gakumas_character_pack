# 花海咲季 亲爱度剧情 / 第35话（adv_dear_hski_035）

- 她的台词：35 行（含用匿名标签说的 0 行）
- 出场的人：咲季、プロデューサー
- 场景：冬季『H.I.F』当天，上台前和制作人两人的对话（0001～0002、0054～0055）
- 世界线：亲爱度（花海咲季）；制作人在制作的偶像：花海咲季

## 发生了什么
制作人说终于到这一天了，她说是「わたしたちが、夢を叶える日」。制作人沉默，说在回想和她相遇至今的事，她说平常这是她的台词、今天被抢先了，然后问他和她一起的日子怎么样。制作人说她两次改写了他的梦：第二次是宣布放弃全部计划的那天，第一次是初次见面那天。她说这段对话已经重复好多次，每次回想都有新发现：现在她知道了当时他的手在抖、声音比平时僵硬，他并不是她刚认识时以为的完美制作人。制作人承认自己只是想让担当偶像看好他而拼命逞强、执念“有一点点”强的普通制作人，她追问到底多强，听到“用全身表达都不够”后笑出来，问执念从哪来；制作人说初见时她比预想更爱逞强、更恳切、更拼命，他“亲手培养顶级偶像”的梦被花海咲季涂满了。她说所以自己成了他「生涯でただひとりの、担当アイドル」；制作人说同行会说那是失言、让偶像背上多余的负担，她说不对，那是让偶像发光的「期待」。她说要为让他做梦负责，不再逞强、不再挣扎，过去所有的花海咲季、唱过的歌、粉丝的心意全都在这里，要他看着顶级偶像诞生。

## 她的关键台词
- 0002「わたしたちが、夢を叶える日よ。」——把『H.I.F』当作两人的梦
- 0007「いつもはわたしの台詞なのに、／今日は先に言われちゃった。」——平时由她回顾过去
- 0009「そうね、許してあげる。じゃあ聞くわ。／わたしとの日々、どうだった？」——主动问对方感想
- 0017「何度目かしら、このやり取り。／もちろん、覚えているわ――……」——两人常回顾初遇
- 0018「何度も、何度も……思い出して。／そのたびに、発見があるの。」——反复回想初遇
- 0019「いまならわかる。／あなたの手が震えてたこと。」——看清当时制作人的紧张
- 0022「わたしが、会ったばかりのころに／思っていたような、／完璧ですごいプロデューサーじゃあ、」——对制作人认识的变化（接 0023）
- 0023「なかったわね。」——同上
- 0029「ほんとにぃ～？　ほんとうは？」——追问、逗对方
- 0035「予想よりも、素敵だった？」——自信地替对方接话
- 0040「生涯でただひとりの、担当アイドルに／なっちゃったんだ。」——接受自己在他心中的位置
- 0043「違うわ。」——否定“那是负担”
- 0045「アイドルを輝かせる、／期待っていうのよ。」——把对方的执念解释为“期待”
- 0047「夢を見せた責任、とってあげる。」——反过来负起责任
- 0048「もう強がりじゃない。／悪あがきでもない。」——这次上台的心态
- 0051「妹に負けて泣き続けた花海咲季も。」——把输掉哭泣的自己也算进去
- 0053「ぜんぶここにある！」——全部过去都带上台
- 0055「トップアイドルの誕生を！！」——上台宣言

## 行为模式
- 上台前 → 主动问对方和自己共度的日子如何（0009）
- 回顾初遇 → 每次都有新发现，现在能看出对方当时的紧张，并直接说出来（0017～0023）
- 对方说“只有一点点”→ 拉长音追问“真的吗？”，逼出实话后笑（0027～0031）
- 对方自责给她负担 → 一口否定，把它重新解释成让偶像发光的力量（0041～0045）
- 被寄予厚望 → 说“由我来负责”，把过去所有的自己（包括输掉哭泣的自己）列出来，一起带上台（0047～0055）

## 关系
- プロデューサー：她说初识时以为他是完美厉害的制作人，现在知道他当时手在抖、声音僵硬，并不完美（0019～0023）；他说她两次改写了他的梦（0012～0016、0037）；她说自己成了他「生涯でただひとりの、担当アイドル」（0040，对应第30话 0013 制作人的话）；她说要为“让你看到梦”负责（0047）

## 档案类事实
- 冬季『H.I.F』当天上台前（0001～0002）
- 初次见面时制作人手在抖、声音比平时僵硬（她现在回想才发现）（0019～0020）
- 制作人在初见前做过很多调查（0034，制作人的话；和第1话一致）
- 两人常重复“还记得初次见面那天吗”的对话（0017）
- 她说不会再逞强、也不再是挣扎（0048）

## 不确定
- 0010～0011 制作人「あなたは――……」后她问「あら、どういう意味？」，中间像是制作人有没写出来的说法或表情。
- 0050「あなたと共に不敗を歩んだ花海咲季も。」——「不敗」指哪段时期本篇没说（她在夏季『H.I.F』输过），按上下文像是指和制作人一起在『N.I.A』等一路赢下来的那段。
- 0019～0020 初见时制作人手抖、声音僵硬：第1话剧本里没有写到（查过第1话原文没有相关描写），是她现在的回想说法，不算矛盾。
