# 花海咲季 亲爱度剧情 / 第36话（adv_dear_hski_036）

- 她的台词：33 行（含用匿名标签说的 0 行）
- 出场的人：咲季、佑芽、学園長
- 场景：冬季『Hatsuboshi IDOL FESTIVAL』结束后的『一番星』授予仪式，舞台上（0001～0008）
- 世界线：亲爱度（花海咲季）；制作人在制作的偶像：花海咲季

## 发生了什么
学园长宣布『H.I.F』今冬起焕然一新，成为诞生『一番星』的世界级大会，宣布优胜者花海咲季，并请现任『一番星』佑芽上台。她对佑芽喊「わたしの勝ちよ！！」放声大笑，佑芽喊不甘心、说下次会赢，她回「次も勝つわ！」，然后小声说「やっと。……言えたわ。」，为来晚了道歉；佑芽说一点都没等，让她看顶点的风景。她说要一直一起跑、每天竞争欢笑，说「夢みたい」；佑芽说她实现了梦想，称她「あたしの『一番星』」，她回「わたしのアイドル」。佑芽让她忍住眼泪尽胜者的责任，她作为『一番星』花海咲季向观众致谢，回顾春天怀着希望和憧憬入学、得到师长同伴和对手、一路走来，说梦想实现了；接着转身向初星学园的偶像们挑衅：不会有人只会老实祝福击败最强『一番星』的王者吧，说听得见大家的咬牙切齿，「それでこそ、わたしのライバルよ！」，邀所有人为学园王者之位一次次竞争、一起挑战全世界的偶像，「お姉ちゃんが先陣を切るわ！！！」。

## 行为模式
- 赢了妹妹 → 当面大笑炫耀；妹妹说下次赢，她说下次也赢（0014～0018）
- 炫耀之后 → 马上小声说出真心话、为让妹妹等她道歉（0019～0020）
- 被妹妹提醒忍住眼泪 → 恭敬地「はい、承りました」，切换成对观众的正式发言（0033～0044）
- 正式感谢之后 → 立刻转为挑衅，主动煽动所有偶像来挑战她（0045～0052）
- 站在顶点 → 把其他偶像也当作“妹妹”般领头（「お姉ちゃんが先陣を切る」0055）

## 关系
- 佑芽：她赢了现任『一番星』佑芽（0008～0014）；佑芽说「次は勝つ！」，她回「次も勝つわ！」（0017～0018）；她为来晚了道歉，佑芽说一点也没等（0020～0021）；佑芽称她「あたしの『一番星』」，她称佑芽「わたしのアイドル」（0031～0032）
- 初星学园的偶像们：她称为「わたしのライバル」，邀所有人为学园王者之位竞争、一起挑战世界（0046～0053）
- 观众：她以『一番星』身份致谢，说大家的声援让她们发光（0036～0040）

## 档案类事实
- 冬季『H.I.F』优胜者是花海咲季，她成为『一番星』（0007～0008、0037）
- 学园长说『H.I.F』从今冬起变为诞生『一番星』的世界级大会（0002～0003）
- 她在春天入学初星学园（0041）
- 她说梦想实现了（0044）
