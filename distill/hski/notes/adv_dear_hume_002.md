# 花海佑芽 亲爱度剧情 / 第2话（adv_dear_hume_002）

- 她的台词：25 行（含匿名标签 0 行）
- 出场的人：佑芽、咲季、プロデューサー
- 场景：学园里去“事务所”教室的路上和那间教室（入学式后不久）
- 世界线：亲爱度（花海佑芽）；制作人在制作的偶像：佑芽

## 发生了什么
制作人带佑芽去活动据点教室，咲季冲出来自我介绍，说要考察制作人，不认可他制作佑芽。她要求制作人讲佑芽的制作计划，制作人却拿出了一份格式和咲季父母相同的资料——他去爱知见过了佑芽的父母。咲季被噎住，撂下一句“今天先放过你”后离开，佑芽和制作人庆祝“击退姐姐”。

## 她的关键台词
- 0013「待ちなさい！！」——突然登场的第一句
- 0017「そう……佑芽のお姉ちゃんにして／学園一の美少女にして学年首席。」——报家门，先说“佑芽的姐姐”，再夸自己是美少女、年级第一
- 0018「未来のトップアイドル・花海咲季とは、／このわたしよっ！」——自称“未来的顶级偶像”
- 0026「咲季よ。紛らわしいから／名前で呼びなさい。」——要求制作人叫名字，不叫「花海さん」
- 0030「わたしの大切な妹を任せられるか、／厳しくチェックしなくちゃ。」——要考察制作人的理由
- 0032「あら、佑芽。自分が選んだ／プロデューサーを信じられないの？」——用佑芽的话让她同意考察
- 0040「わたしに佑芽の／プロデュース計画を聞かせなさい。」——给制作人的考题
- 0053「これ、うちの両親が使ってる／フォーマットじゃない！」——发现资料格式是父母用的，才明白制作人去见过他们
- 0067「今日のところは引き下がってあげるわ！／覚えてなさい～～～～～～～！」——被噎住后的退场台词

## 行为模式
- 想考察对方时 → 先用“信不信任自己选的人”这样的话让妹妹点头，再提出考题（0032、0034、0037）
- 被对方超出预期的准备压住时 → 先惊呼，再追问“怎么知道的”，最后用“今天先放过你”收场（0045、0049、0050、0066、0067）
- 对妹妹的事 → 说“大切な妹”（0030），也会因为佑芽同制作人亲近而不甘（0023）

## 关系
- 佑芽：称「佑芽」；佑芽叫她「お姉ちゃん」（0015），说她是“宿敌”“最高のお姉ちゃん”（0073、0074）
- プロデューサー：她称他「あなた」，被要求之后叫「咲季さん」（0027，制作人用）

## 档案类事实
- 咲季自称学年首席、学园第一的美少女（0017）
- 咲季家的父母有专用的资料格式，父母有公式 web 站点可预约会面，在爱知（0053、0058、0060，0058、0060 是佑芽/制作人的话）
- 咲季的父母把格式提供给制作人，要求今后使用（0054）
