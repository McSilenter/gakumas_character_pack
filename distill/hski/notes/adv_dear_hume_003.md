# 花海佑芽 亲爱度剧情 / 第3话（adv_dear_hume_003）

- 她的台词：12 行（含匿名标签 0 行）
- 出场的人：佑芽、プロデューサー、咲季
- 场景：学园的レッスン室（今天起可以借用，0005），佑芽和咲季刚比完；入学后数日
- 世界线：亲爱度（花海佑芽）；制作人在制作的偶像：佑芽

## 发生了什么
佑芽和咲季在刚借到的レッスン室里比赛，佑芽输了。咲季向制作人追问上次没说完的事：资料里是不是有她父母的意见，制作人说计划书给父母看了，当场就引起了关于育成方针的激烈讨论。咲季说“那两个人是亲ばか”，要求制作人用全力的计划培养佑芽，否则不配当她的对手。后半是佑芽和制作人的谈话，咲季不在场。

## 她的关键台词
- 0005「今日からレッスン室を／借りられるというから――」——说明为什么两人在比赛
- 0007「思い知ったかしら、／アイドルとしての力の差を。」——赢了佑芽之后，点出这是“作为偶像的实力差”
- 0010「ふふふっ――その意気、その意気。／頑張りなさい、佑芽。」——佑芽说“总有一天追上你”，咲季既不否定，反而给她鼓励
- 0012「さて、妹が可愛く黙っちゃった／ところで。――プロデューサー。」——把话题转向制作人
- 0016「結局、うちの両親の／意見が入っているってことなの？」——追问资料里是否有父母的意见
- 0020「迷惑を掛けたみたいね。／……親ばかなのよ、あの人たち。」——听到父母当场争论后，替父母道歉并吐槽
- 0023「へえ、それはいいわね。／うん……面白くなってきた。」——听说计划得到提升后高兴
- 0025「渾身のプランで／佑芽を鍛え上げなさい！」——要求制作人拿出全力
- 0026「そうじゃなきゃ、／わたしの相手にはならないわ！」——理由是“否则佑芽当不了我的对手”

## 行为模式
- 胜了妹妹之后 → 不只是炫耀，也马上说“加油”（0007、0010）
- 听到有利于妹妹的消息 → 明显更开心，还提高对制作人的要求（0023、0025、0026）
- 谈起父母 → 用「親ばか」带过，带着一点不好意思（0020）

## 关系
- 佑芽：称「佑芽」；佑芽叫她「お姉ちゃん」，说“绝对要追上你”（0008、0009）
- 制作人：叫「プロデューサー」；对他的态度比上一话缓和，转为要求（0012、0025）

## 档案类事实
- 她的父母是元プロアスリート（0021，制作人的话）；父母夫妻吵架的光景佑芽能想象（0019，佑芽的话），咲季称他们「親ばか」（0020）
- 她和佑芽以比赛决胜负的习惯依旧（0005～0009）
