# 花海佑芽 亲爱度剧情 / 第6话（adv_dear_hume_006）

- 她的台词：8 行（含匿名标签 0 行）
- 出场的人：佑芽、プロデューサー、咲季
- 场景：『選抜試験』当天，佑芽演出后的会场（0025 以后）
- 世界线：亲爱度（花海佑芽）；制作人在制作的偶像：佑芽

## 发生了什么
佑芽在『選抜試験』上拿了第一名，制作人说“不用拿咲季当基准”，佑芽却还觉得离姐姐很远。咲季出现，说制作人说得对，让佑芽把握自己的实力，否则对今天的对手失礼。她随后说自己也要上场，让佑芽好好看着她的舞台。之后佑芽向制作人说出：想作为偶像赢姐姐，姐姐就是她心中世界第一的偶像，制作人同意了。

## 她的关键台词
- 0041「プロデューサーの言うとおりよ。」——站在制作人一边，不是替妹妹说好话
- 0043「何度も言わせないでくれる？　／佑芽は、とっても成長してるわ。」——“成长了”她已经说过很多次
- 0044「自分の力量ぐらい、／ちゃんと把握しておきなさい。」——要求佑芽正确认识自己
- 0045「でなきゃ――／今日戦った相手に失礼でしょ？」——理由是对手，不是安慰
- 0051「まだまだ、／このわたしには及ばないけどねっ♪」——夸完就补上“还不及我”
- 0053「そういうの、愚問って言うのよ。／――そろそろ出番ね。」——佑芽问她有没有参加选拔试验，她以“愚问”回答并宣布出场
- 0054「見てなさい、佑芽。／あなたが目指す、わたしのライブを！」——自己是佑芽的目标，要让她看

## 行为模式
- 妹妹自我评价过低 → 直接纠正，理由是“尊重对手”（0043～0045）
- 夸奖之后 → 加一句“还不及我”，保持比对手强一档（0050、0051）
- 被问到不言自明的事 → 用「愚問」堵回去，立刻转为出场（0053、0054）

## 关系
- 佑芽：称「佑芽」；佑芽把她当“世界第一的偶像”（0068）
- 制作人：称「プロデューサー」，认同他的话（0041）

## 档案类事实
- 她参加了『選抜試験』（0052、0053，从“愚問”推断）
- 她认定自己是佑芽的目标（0054）
