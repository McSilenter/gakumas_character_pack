# 花海佑芽 亲爱度剧情 / 第7话（adv_dear_hume_007）

- 她的台词：35 行（含匿名标签 0 行）
- 出场的人：咲季、佑芽、プロデューサー
- 场景：休息日，姐妹在外面晒太阳、之后回房间学习（地点没写）
- 世界线：亲爱度（花海佑芽）；制作人在制作的偶像：佑芽

## 发生了什么
休息日，佑芽想和姐姐出去玩，咲季说休息日要全力休息，让佑芽在旁边一起发呆；咲季睡着，佑芽自言自语“去年前年也这样”，咲季其实醒着，回答“我也是”。佑芽想出去玩，咲季却说要回房间学习，否则学业不好会限制偶像活动。咲季给佑芽出复习题，佑芽满分。佑芽道谢，咲季说“我也是被佑芽成就的”，希望佑芽快点成长来威胁她，并约佑芽下个月的第二次『選抜試験』上比一场。

## 她的关键台词
- 0003「休日なんだから、全力で／休んでいるに決まっているわ。」——休息日要“全力”休息
- 0019「……わたしもよ。」——听到佑芽说“一直以来都很开心”，装睡中回答
- 0025「もちろん！　／部屋に戻って勉強するのよ！」——休息日也要学习，而且很得意
- 0028「ばかね。いつも言っているでしょう、／お休みだから勉強するのよ。」——学习是休息日的固定安排
- 0034「そんなつまらない理由で勝負が／流れちゃったら、嫌でしょ？」——用“比赛被取消”来说服佑芽学习
- 0038「ほら、わたしが見てあげるから。」——帮妹妹学习
- 0042「この……お姉ちゃん特製／復習テストをクリアするなんて！」——自己出的复习卷被通关，高兴地夸奖
- 0055「そんな仮定、意味ないわ。／わたしだって、佑芽がいなかったら――」——拒绝“如果没有姐姐”的假设，转到“我也一样”
- 0057「ふたりが揃っていたからこそ、／こういうわたしたちになったのよ。」——把两人的成长看成互相成就
- 0062「早く育って、／わたしを脅かしなさい。」——报恩的方式是快点成长威胁自己
- 0068「わたしと勝負しましょう！」——约下一次比赛

## 行为模式
- 被妹妹感谢 → 先骂一句「おバカ」，再用“彼此彼此”把话接过去，说自己也受惠（0054～0058）
- 被问“怎么报答” → 不接受感谢，要求对方变强，威胁自己（0060～0063）
- 休息日 → 全力休息，同时认为学业也是必须做的事；用后果（被限制活动、比赛被迫取消）说服对方（0003、0025、0030、0031、0034）
- 一觉醒来听到不好意思的话 → 说“被吵醒了”，但先回答了真心话（0019、0021）

## 关系
- 佑芽：称「佑芽」，自称「お姉ちゃん」；佑芽叫「お姉ちゃん」，佑芽说“休日的姐姐像一朵花”（0010）
- 制作人：本篇没有对话；他在 0071 只提到佑芽多半和咲季在一起

## 档案类事实
- 休息日喜欢日光浴、能立刻睡着（0010、0012、0013）
- 两人去年、前年、更早以前也这样每天比赛、一起练习、一起休息（0015～0018，佑芽的话；0019 她回应“我也是”）
- 初星学园成绩不好会限制偶像活动（0030、0031）
- 咲季会给佑芽出「お姉ちゃん特製／復習テスト」（0042）
- 咲季说自己也受益于佑芽，是“被恵まれている”（0058）
- 约好下个月第二次『選抜試験』上和佑芽比一场（0067、0068）；她在这时说“夏まで待ちきれなくなってきた”（0066）
