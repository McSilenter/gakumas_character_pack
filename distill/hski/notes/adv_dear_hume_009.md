# 花海佑芽 亲爱度剧情 / 第9话（adv_dear_hume_009）

- 她的台词：17 行（含匿名标签 0 行）
- 出场的人：佑芽、プロデューサー、咲季
- 场景：与咲季的比赛当天（0001～0044 佑芽上场前，0045 起是比赛结果后）。从上一话看是“第二次『選抜試験』”，本篇没有明说
- 世界线：亲爱度（花海佑芽）；制作人在制作的偶像：佑芽

## 发生了什么
佑芽在比赛前鼻血、紧张又兴奋，第一次觉得“可能能赢姐姐”。比赛结果是佑芽和咲季平局。佑芽心情复杂，咲季说不用现在决定该高兴还是难过，等回去睡一觉再想。咲季说自己两者都有：被妹妹追上很不甘心，妹妹成长很高兴。咲季祝贺佑芽，并说下一次决胜会在『H.I.F』。

## 她的关键台词
- 0045「やるじゃない、佑芽！」——比赛一结束先夸
- 0046「このわたしと引き分けるなんて！！」——结果是平局，这里用“连我也……”来夸
- 0048「――なんて顔してるのよ。」——看到妹妹难过/困惑的脸，一句话就转为开导
- 0053「なら、それでいいじゃない。」——佑芽说“什么都不知道了”，她说那就这样
- 0055「喜ぶべきか悔しがるべきかなんて、／いま決めなくったっていいわ。」——不必立刻给情绪下结论
- 0060「ああ～っ！　妹に追いつかれて、／悔しい～～～～～～～～～っ！」——先喊自己的不甘
- 0061「佑芽の成長が、／嬉しいぃ～～～～～～～～っ！！」——紧接着喊对佑芽成长的高兴
- 0062「あとは秘密っ！／と、そんな感じね♪」——不全说出心里话
- 0063「――というわけで。／おめでとう、佑芽。よくやったわね。」——正式祝贺
- 0068「覚悟しておきなさい。／もう一度、引き離してやるんだから！」——宣布下一次会再甩开佑芽

## 行为模式
- 比赛结束且结果平局 → 先夸，再根据对方的表情调整，把情绪的结论推给“洗澡、睡觉、冷静之后”（0045～0057）
- 要安慰对方时 → 先拿自己的真话示范（“悔しい”和“嬉しい”都有），再说一句“其余保密”（0059～0062）
- 对下一次比赛 → 立刻转为挑战（0066～0068）

## 关系
- 佑芽：称「佑芽」；佑芽叫「お姉ちゃん」，说“追上姐姐是开心，又没赢成是不甘心”（0050、0051）
- 制作人：本篇没有对话

- 下一次分出胜负的舞台预计是『H.I.F』（0066、0067）
