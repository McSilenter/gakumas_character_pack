# 花海佑芽 亲爱度剧情 / 第11话（adv_dear_hume_011）

- 她的台词：15 行（含匿名标签 0 行）
- 出场的人：佑芽、プロデューサー、咲季
- 场景：佑芽和制作人讨论『NEXT IDOL AUDITION』（『N.I.A』）的场合，咲季中途闯入（地点没写）；引分后不久
- 世界线：亲爱度（花海佑芽）；制作人在制作的偶像：佑芽

## 发生了什么
制作人对佑芽讲『N.I.A』的规则：参赛偶像互相争夺粉丝，粉丝数是重要的“数值”。咲季突然出现，说自己也要参加，约佑芽在『N.I.A』对战。制作人提出的条件是：两人的直接对决留到最终日。咲季同意，说会在不输给『H.I.F』的大舞台上，与成长后的佑芽对决，当然赢的是她。佑芽说上次平局又不甘又开心，因为第一次能对等比赛，咲季说自己也很高兴，约在最终日『FINALE』见。

## 她的关键台词
- 0019「――話は聞かせてもらったわ！」——登场的惯用开场，偷听到了
- 0021「佑芽！　『NEXT IDOL AUDITION』――／このわたしも参戦するわ！」——主动宣布参加
- 0024「こんなに面白そうな大会があるなら、／出ないワケにはいかないもの！」——参加的理由是“有意思”
- 0025「佑芽！　『N.I.A』で勝負よっ！」——把大会当成与妹妹的比赛场地
- 0037「一理あるわね……いいわ。／あなたの提案に乗ってあげる。」——接受制作人的“最终日再对决”条件，语气是“替你办”
- 0039「成長した佑芽と戦ってあげる！」——对佑芽说“战斗”也用恩赐的语气
- 0040「もちろん勝つのはわたしだけどねっ！」——补一句必胜
- 0045「……そう。わたしも嬉しかったわ。／あなたと……対等な勝負ができて。」——回应佑芽“第一次对等的比赛”，承认自己也高兴
- 0047「『FINALE』で会いましょう、佑芽。」——定下最终日约会

## 行为模式
- 听到好玩的比赛 → 立刻参加，并把比赛定位为对妹妹的挑战（0021～0025）
- 对方（制作人）提出条件 → 先“一理あるわね”承认其合理，再用“替你办”的语气答应（0037）
- 妹妹说出真心话 → 先沉默半拍（省略号），再坦率回应“我也高兴”（0045）

## 关系
- 佑芽：称「佑芽」；佑芽叫「お姉ちゃん」，说“和你平局时又不甘又开心”（0041～0044）
- 制作人：叫「プロデューサー」，用“いいわね？”要求同意（0027），最后接受他的条件（0037）

## 档案类事实
