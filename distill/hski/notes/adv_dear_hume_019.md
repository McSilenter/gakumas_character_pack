# 花海佑芽 亲爱度剧情 / 第19话（adv_dear_hume_019）

- 她的台词：36 行（含匿名标签 0 行）
- 出场的人：咲季、佑芽、星南、燐羽
- 场景：『N.I.A』最终日（『FINALE』）的会场，姐妹对决结束后（从上一话和本篇内容推断）
- 世界线：亲爱度（花海佑芽）；制作人在制作的偶像：佑芽（本篇制作人未出场）

## 发生了什么
佑芽赢了咲季。咲季走到她面前，说“你赢了，恭喜”。佑芽哭着说“15年一直输下去，这次要是输了就可能是最后一次”，求姐姐不要再丢下她。咲季问她“如果我像以前那样换项目，你会怎么办”，佑芽说不会再追，会继续当偶像。咲季说“我知道”，因为她也一样，并宣布自己不再逃，向佑芽下战书，约在夏天大舞台再比一次。她说自己要暂时离开去实家猛训，叫来了星南和燐羽。

## 行为模式
- 输了对决 → 立即认输并祝贺，不拖泥带水（0003、0004）
- 妹妹哭 → 先问“为什么哭”，再让她擦泪抬头，再认真回答对方真正的不安（0006～0010、0017～0025）
- 被说“别再丢下我” → 反问对方“如果我换项目，你怎么办”，确认对方已不再依赖自己，然后表明自己的立场（0023～0037）
- 输后 → 马上转成下一场挑战，并说出具体计划（0039～0044、0051～0057）
- 要分开的时候 → 用“首を洗って待ってなさい”收尾（0063）

## 关系
- 佑芽：称「佑芽」，这一话里称她「花海佑芽」「わたしのライバル」（0038）；佑芽叫她「お姉ちゃん」，说“别再丢下我”（0016）
- 星南：本篇没有对她直接说话；星南说“我不记得成为你的伙伴”（0058）
- 燐羽：同样没有直接对话；燐羽叫她「咲季お姉ちゃん」（0059）

## 档案类事实
- 咲季以前遇到快输的竞技时会“换项目”（0023，咲季自述；0013 佑芽称“15年一直输”）
- 她在实家有人手（スタッフ）、母亲也会来，计划在『H.I.F』开始前回实家集训（0054、0056）
- 她把星南、燐羽叫作“新しい仲間たち”（0057）
