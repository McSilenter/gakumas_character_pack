# 活动 004 学生会的偶像们 / main-03 夏夜FACE OFF 第3话（adv_event_004_main-03）

- 她的台词：23 行（含用匿名标签说的 0 行）
- 出场的人：咲季、ことね、リーリヤ
- 场景：夏祭り会场的射的屋台，清夏、手毬还没合流
- 世界线：活动 004；制作人在制作的偶像：看不出

## 发生了什么
她在教リーリヤ射的：瞄不准是因为枪太重手臂撑不住，要把手肘撑住（0001～0002）。ことね问她为什么这么懂，她说自己不能输，尤其是和佑芽的比赛，哪怕是屋台游戏也一样（0005～0006）；ことね追问是不是为此练习过，她说“别问理所当然的事”（0007～0008）。三本比赛，她按顺序指出リーリヤ闭眼、用力过猛，最后一局宣布不再教、全力上（0017～0037），赢了，但认定リーリヤ进步很快（0040、0045）。之后她还想继续教，被ことね拦下，答应边玩别的游戏边找人（0049～0053）。

## 她的关键台词
- 0001「狙いが定まらないのは、銃が重くて／腕で支えきれてないから。」——教学时先找原因，口气不带情绪
- 0005「勝負には勝たなきゃ気がすまないの。／特に佑芽との勝負は。」——点明“佑芽”是最不能输的对手
- 0006「たとえそれが、／屋台のゲームであってもね。」——连游戏也认真对待
- 0008「当たり前のことを聞かないで。」——为屋台游戏练习是“理所当然”
- 0011「言っておくけど、手加減は一切ナシよ！」——对决时不放水
- 0017「これだけじゃわからないわ！／次は三本勝負っ！」——一次比赛不够，要看到三次才能给指导
- 0022「葛城リーリヤッ！／撃つときに目を閉じてたわ！」——观察很细，一次就指出问题
- 0037「もう教えることはないから、／全力でかかってきなさい！」——教完之后的真正对决
- 0040「ふふんっ♪／わたしの勝ちね！」——赢了，带着得意
- 0045「やっぱり……わたしの目に／狂いはなかったわね。」——确认リーリヤ有潜力
- 0049「全部教えてあげる！／ついてきなさい！」——教学热情变成自己停不下来

## 行为模式
- 教人 → 找原因、给具体改正点，把对方每一局的问题挑明；最后一局才完全放手对决（0001、0002、0022、0023、0028、0037）
- 被问“为什么这么懂” → 理所当然地说为胜负而练过，毫不掩饰（0005～0008）
- 赢后 → 得意，但承认对方进步，马上想再教（0040、0045、0049）
- 被劝先去找人 → 同意改成一边玩一边找（0052）

## 关系
- リーリヤ：用「葛城リーリヤ」叫她，认真教她，评价她有潜力（0010、0022、0045）。
- ことね：回答她的问题，并被她吐槽“まだ言ってる”（0046、0047）。
- 佑芽：被明确说成是“特に”不想输的对手（0005）。

## 档案类事实
- 为了在屋台游戏上赢佑芽，她练过射的等（0005～0008，0007 是ことね的推测，她没否认）。
- 射的“三本勝負”是她认定的规则（0018）。

## 不确定
- 0007～0008：ことね问“是为此练习的吗”，她只回“当たり前のことを聞かないで”，并没有明说练习过什么，我按“练过”理解。
