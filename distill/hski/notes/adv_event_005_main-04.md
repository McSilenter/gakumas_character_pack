# 活动 005 / main-04 第4话（adv_event_005_main-04）

- 她的台词：16 行（含用匿名标签说的 0 行）
- 出场的人：星南、咲季、莉波、燕、ことね、清夏、リーリヤ、手毬（0021～0025 路过，只有手毬等人打招呼，没有和咲季对话）
- 场景：学园内的走廊，星南、莉波、燕在找后继者，路过的一年级里星南叫住咲季
- 世界线：活动 005；制作人在制作的偶像：看不出（没有制作人出场）

## 发生了什么
星南在三年级的陪同下看新生，一年级路过时她没打招呼，却叫住咲季（0031）。星南说她比入学式时成长了，又假设她成长止步会怎样，最终说她“很快会遇到绝对越不过的墙”（0033～0043）。咲季问她“你说的是我吗”，对『一番星』竟如此无礼表示意外，反问星南自己会怎么办（0040、0044、0045）。星南说止步的偶像没有未来（0046、0047）。她拿出学园小册子上星南的话，说自己曾以此为目标，现在觉得失望（0048～0052）。接着她当场宣布要打破那堵墙、自己代替“过去的星南”给星南做模范（0055～0059），星南回「やってみなさい」（0060）。

## 她的关键台词
- 0032「こんにちは、十王星南会長。／わたしに御用？」——被前辈叫住，客气但没有退缩
- 0034「そうでなきゃ困るわ。／毎日レッスンしているんだもの。」——成长是理所当然
- 0040「まるで予言者みたいなことを言うのね。／わたしがそうなるっていうの？」——被预言“成长止步”，当作可检验的说法
- 0044「『一番星』がこんなに無礼なやつだった／なんて、知らなかったわ。」——对星南直接说无礼
- 0045「逆に聞くけど、／あなただったらどうするの？」——把问题抛回对方
- 0050「これが初星学園のアイドルなんだって、／目標にしていたのに。」——星南曾是她的目标
- 0051「がっかり。」——说出失望
- 0055「わたしがあなたに、／お手本を見せてあげるわ！」——接受挑战并翻转角色
- 0057「絶対に越えられない壁とやらを、／ぶっ壊してやると言っているの！」——对“越不过的壁”的宣战
- 0059「わたしにアイドルを教えてくれた、／かつてのあなたの代わりにね。」——星南曾教会她“アイドル”

## 行为模式
- 被地位更高的人预言失败 → 先问“你在说我吗”，不当真地吐槽，再把问题反问（0040、0044、0045）
- 被打击时 → 拿对方过去的言论当武器，说“失望”（0048～0052）
- 说出失望后 → 立即转为“我来做你的模范”，把失望变成斗志（0054～0059）

## 关系
- 星南：叫「十王星南会長」（0032）、叫“一番星”（0044、0058）；同时是她过去的目标，现在被她说“不再是模范”（0050～0052）。星南事后对燕、莉波说她“生意气”“无礼者”（0061、0064），这些话咲季不在场。
- 一年级同学（ことね、清夏、リーリヤ、手毬）：只是路过，咲季没有和他们说话。

## 档案类事实
- 入学式上与星南见过面（0033 星南说「入学式で会った時」）。
- 把初星学园的小册子上星南的话当作目标（0048～0050）。
- 她每天做レッスン（0034）。

## 不确定
- 0060 起是星南的话；0061 起是星南对燕、莉波说的，咲季不在场。
- 0059「かつてのあなた」：“教过她アイドル”的是小册子上的星南还是星南本人，本篇没有展开。
- 与 conflicts 的联系：0044、0058 的『一番星』指星南（符合手毬 conflicts 8c 的结论）。
