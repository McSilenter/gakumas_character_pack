# 活动 009 莉莉娅与清夏的日常 / main-05 蛋糕系起的友情圣诞节 第5话（adv_event_009_main-05）

- 她的台词：6 行（含用匿名标签说的 0 行）
- 出场的人：ことね、佑芽、リーリヤ、清夏、咲季、ケーキ屋の店主
- 场景：初星学园的圣诞活动，蛋糕摊位（0001）
- 世界线：活动 009；制作人在制作的偶像：看不出

## 发生了什么
佑芽和リーリヤ、ことね在摊位上卖蛋糕。咲季来看佑芽（0010），佑芽问她要不要买自己做的蛋糕，她立刻说“当然”（0011、0012）。ことね问她“蛋糕不是偶像吃的东西吗”，她说“这是特别的，因为是佑芽做的”（0013、0014）。她在食事区吃了，说「美味しいわ」（0019）。佑芽把成功归功于リーリヤ，咲季看到两人关系好，说心情复杂（0020～0023）。ことね评价她“相変わらずシスコン”（0024）。

## 她的关键台词
- 0010「佑芽、来たわよ！／頑張ってるみたいじゃない。」——专程来看佑芽
- 0012「もちろんよ！」——佑芽问买不买，立刻答应
- 0014「これは特別よ。／佑芽が作ったケーキだもの。」——自己的原则对佑芽例外
- 0016「あっちの食事スペースで、／さっそくいただいてもいいかしら？」——急着吃
- 0019「うん、美味しいわ！」——尝后的评价
- 0023「な、なんか仲良くなってるわね……？／何かしら、この気持ち。複雑だわ……！」——妹妹和别人变亲密时的复杂情绪

## 行为模式
- 与佑芽相关 → 自己的原则（不吃蛋糕）立刻让步，被指出时用「特別」解释（0012～0014）
- 看到妹妹和别人变亲密 → 自己察觉到“复杂”的感情，说出口（0023）

## 关系
- 佑芽：叫「佑芽」；佑芽叫她「お姉ちゃん」（0011）。她吃了佑芽做的蛋糕，给予好评。
- リーリヤ：本篇没有对话；佑芽与她关系好令她心情复杂（0020～0023）。
- ことね：ことね指她是シスコン（0024），她没有回应。

## 档案类事实
- 平时不吃蛋糕（见 009 main-01 0038），这次为佑芽特别吃（0014）。本表只按本篇的 0014「特別」记。
