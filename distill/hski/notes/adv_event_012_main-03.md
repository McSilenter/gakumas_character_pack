# 活动 012 手毬与广的日常 / main-03 樱花飞舞的起跑线 第3话（adv_event_012_main-03）

- 她的台词：21 行（含用匿名标签说的 0 行）；0002～0019 现在时间，0063～0077 回想，0080～0084 回到现在的对话
- 出场的人：清夏、咲季、リーリヤ、ダンストレーナー、ことね
- 场景：现在是排练途中清夏休息；回想是清夏入学后跳舞出问题的经过（0022「――入学当初。」之后）
- 世界线：活动 012；制作人在制作的偶像：看不出

## 发生了什么
现在：清夏舞蹈练习时感到不适，咲季问体调，说症状恶化最要避免（0002、0008）。她笑着说想起清夏瞒着症状的那时，那时连リーリヤ都没告诉（0010～0015）。清夏接着回忆自己入学后逐渐无法跳舞，直到“某个东西折断了”（0023～0055）。回想中咲季来找她，说“你的眼神是骗子的眼睛，全部说出来”（0063～0069）。咲季说自己觉得清夏是有张力的对手，所以想帮助（0073～0077）。リーリヤ说“你真温柔”，她说“当然，因为我们是朋友”（0082～0084）。

## 她的关键台词
- 0002「――清夏。体調は？」——开口先问体调
- 0008「でも、リーリヤの言う通りよ。／症状が悪化するのだけは避けたいもの。」——支持リーリヤ的“别勉强”
- 0012「懐かしいと思ったのよ。／清夏がその症状を隠していた時のこと。」——笑的原因是想起旧事
- 0015「わたしはともかく、リーリヤにも／相談していなかったんだから。」——对清夏连リーリヤ都没说感到惊讶
- 0066「あなたの目。」——回想：盯着清夏的眼睛
- 0067「嘘つきの目だわ。」——回想：一眼看出清夏在隐瞒
- 0069「話しなさい――全部。」——回想：直接要求坦白
- 0073「良い体をしているし、／ダンスなら、このわたし以上――」——回想：承认清夏的舞蹈实力
- 0074「モチベーションも高い。／張り合いのあるライバルだったわ！」——回想：把清夏视为对手
- 0077「折れる人間はたくさん見てきたけど、／きっかけが見えなかったから。」——回想：之前见过很多人“折”，所以对清夏的变化好奇
- 0081「力になりたいと思ったのよ。」——回想：帮助的理由
- 0083「ふん、当然じゃない。／だって、わたしたちは――」——被说温柔时先说“当然”
- 0084「――友達だもの！」——用“朋友”收尾

## 行为模式
- 同伴不舒服 → 先问体调，把恶化的风险放在最优先（0002、0008）
- 发现隐瞒 → 直接指出“你在说谎”并要求全部说出（0066～0069）
- 被说善意 → 先说“当然”，用“友達”解释（0083、0084）

## 关系
- 清夏：叫「清夏」；回想里把她当对手，评价舞蹈在自己之上（0073、0074）。
- リーリヤ：与她一起担心清夏；0007 清夏吐槽“それリーリヤが言う！？”，她接着支持リーリヤ的话（0008）。

## 档案类事实
- 见过很多“折断”的人（0077）。
- 自认舞蹈不及入学时的清夏（0073「ダンスなら、このわたし以上――」，被截断）。
