# 活动 012 手毬与广的日常 / main-05 樱花飞舞的起跑线 第5话（adv_event_012_main-05）

- 她的台词：12 行（含用匿名标签说的 0 行）
- 出场的人：リーリヤ、清夏、佑芽、咲季
- 场景：迷你演唱会前一晚（0005、0032）；然后是演唱会直前（0047）
- 世界线：活动 012；制作人在制作的偶像：看不出

## 发生了什么
前一晚，清夏和リーリヤ谈约定。佑芽想去观看，被咲季拒绝：他们是工作，别的学生有课（0030～0033）。佑芽问为什么她愿意这么帮这两个人，她说“有一点像”，被追问像谁就说“さあ、誰かしらね”（0040～0046）。演唱会前，咲季看到两人的脸变了，说“别拖后腿”，并让她们跟着自己（0048～0056）。清夏说两个人合起来不会输给咲季（0059）。

## 她的关键台词
- 0031「どうしたの？　佑芽。」——妹妹来时的语气温和
- 0033「駄目よ。わたしたちは仕事だけど、／他の生徒は授業があるでしょう。」——不因为是佑芽而破例
- 0035「ライブなら他にもあるわよ？」——劝妹妹别执着
- 0039「ふふ、佑芽はリーリヤと／仲が良いものね。」——知道佑芽和リーリヤ要好
- 0044「……少しだけ、似ていると思ったのよ。」——帮助这两人的理由
- 0046「……さあ、誰かしらね。」——不说似谁
- 0051「……わたしが知らない間に、／覚悟が決まった顔になってるわね。」——一眼看出两人变了
- 0054「いいじゃない。／足を引っ張ったら許さないわよ！」——赞许，同时施压
- 0056「ちゃんとついてきなさい！」——开演前仍旧是带头的口吻

## 行为模式
- 妹妹提出不合理的请求 → 用工作和课业的规则拒绝，再给替代（0033、0035）
- 被追问动机 → 说出一半就停，不说对象（0044、0046）
- 开演前 → 一边看出同伴的变化，一边用“不许拖后腿”鼓励（0051、0054、0056）

## 关系
- 佑芽：称「佑芽」；佑芽称「お姉ちゃん」，说她“对别人这么投入”很意外（0043）。
- リーリヤ、清夏：叫「ふたりとも」；承认她们的变化（0051）。

## 档案类事实
- 这次演出是临时组合，只有这一次（0037「臨時ユニットだもの」）。
- 她明说帮清夏、リーリヤ的原因是“有一点像”某个人（0044、0046），对象没说明。
