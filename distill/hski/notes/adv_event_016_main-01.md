# 活动 016 / main-01 第1话（adv_event_016_main-01）

- 她的台词：29 行（含用匿名标签说的 0 行）
- 出场的人：佑芽、咲季、手毬、ことね、店员
- 场景：商店街，姐妹一起买东西，福引；次日（0036「――翌日。」）是在学园里邀ことね、手毬
- 世界线：活动 016；制作人在制作的偶像：看不出（没有制作人出场）

## 发生了什么
姐妹一起买东西。咲季问佑芽生徒会开不开心，听到她被先辈和広、千奈、美鈴照顾，说“那就好”，并叮嘱别偷懒レッスン（0005～0010）。两人在福引上比运气，咲季抽中3等「スポセン」的10张票，赢了佑芽（0016～0021）。她心里想要“预习新游戏”（0025），把一半票给佑芽，让她跟生徒会的朋友去玩，自己另有同伴（0027～0033）。第二天她叫ことね、手毬来，ことね说想带妹妹，她立刻答应（0037、0057）。手毬问自己算不算在内，她奇怪“那还用说”（0063～0065）。

## 她的关键台词
- 0005「……生徒会は、楽しい？」——用平常的口吻问佑芽
- 0009「……そう。よかった。／みんなと上手くやってるのね。」——听到妹妹被照顾，放心
- 0010「生徒会の活動も大事だけど、／レッスンはサボっちゃだめよ。」——给妹妹的叮嘱
- 0016「望むところよ！　運勝負だって、／ぜぇ～～ったい負けないんだから！」——连运气也要赢
- 0025「（むっ、新しい遊戯が増えているわね／……また予習が必要かしら）」——心声：为了赢，先预习
- 0027「佑芽、半分あげるわ。」——赢来的票主动分一半给妹妹
- 0029「ええ。たまには生徒会の友達と／羽を伸ばして遊んできなさい。」——鼓励妹妹和新朋友玩
- 0032「悪いわね。お姉ちゃんはもう、／遊びに行くメンバー、決まってるの。」——自己不去的理由
- 0037「あなたたち、日頃の感謝をこめて、／いいものをあげるわ！」——邀同伴时的说法是“感谢”
- 0042「違うわよ。これ、／商店街の福引きでもらったの。」——否认是SSD试饮
- 0046「たまには、気分転換もいいでしょ。／スポセンはトレーニングにもなるし。」——邀请的理由
- 0057「もっちろん、OKよ！」——ことね提出带妹妹，立刻接受
- 0058「妹ちゃんに、お姉さんらしいこと、／しっかりしてあげなさい。」——对ことね说“做姐姐该做的事”
- 0065「……？　あたりまえじゃない。／もしかして、来週だと都合悪い？」——手毬担心被排除，她完全没想到

## 行为模式
- 与佑芽一起 → 语气柔和，先关心，再叮嘱レッスン（0005～0010）
- 比赛 → 福引之类的运气也要认真，赢了才满意（0016、0020）
- 把东西分给人 → 先分给佑芽，自己则找其他朋友（0027～0033）
- 同伴提出请求 → 不问细节就答应（0057）
- 同伴担心被落下 → 一脸疑惑，没察觉对方的担心（0063～0065）

## 关系
- 佑芽：称「佑芽」，对佑芽生徒会的生活既放心又有一点点落寞（见 016 main-02）；佑芽叫「お姉ちゃん」（0011）。
- ことね：称「ことね」，ことね叫她「咲季ちゃん」「咲季」（0048）。
- 手毬：被手毬认为是"新作SSDの試飲"（0041）；叫「手毬」（0063）。

## 档案类事实
- 最近因佑芽进了生徒会、两人时间合不上（0003）。
- 福引中抽到スポセン的3等票10张（0020、0021）。
- 佑芽加入生徒会（0003、0005）。
- 与佑芽之前去过スポセン并对决（0023）。
