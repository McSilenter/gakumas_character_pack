# 活动 016 / main-02 第2话（adv_event_016_main-02）

- 她的台词：30 行（含用匿名标签说的 0 行）
- 出场的人：咲季、ことね、手毬、ことねの妹
- 场景：スポセン（体育综合游乐场）；咲季、ことね、手毬、ことね的妹妹来玩
- 世界线：活动 016；制作人在制作的偶像：看不出

## 发生了什么
她初次见到ことね的妹妹，礼貌地自我介绍（0009）。她在ことね想要玩什么的话题上自告奋勇教人（0022），ことね的妹妹想打击机，手毬接手教，她教ことね（0036～0037）。ことね夸她教得好，她说为了教佑芽，读过运动理论、学过指导（0042～0045）。ことね问她与佑芽吵不吵架，她说“靠比赛分高下，所以不会吵”（0052、0053）。她沉默，说出佑芽进生徒会交了很多朋友而自己有些寂寞（0059～0069）。ことね建议“直接说嘛”，她拒绝，说不能让佑芽看到“弱弱的姐姐”（0071～0074）。

## 她的关键台词
- 0003「なに？　ひょっとして、／子供相手に緊張してるの？」——开手毬的玩笑
- 0009「ことねの友達の花海咲季よ。／今日はよろしく。」——对ことね的妹妹的自我介绍
- 0022「わたしが教えてあげるわ。／任せておきなさい。」——遇到不会的游戏，主动当老师
- 0037「ボールをしっかり見て――／思いっきりスイング！」——教人的口令简洁
- 0043「佑芽を鍛えるために、／最新のスポーツ理論の本を読んで、／コーチングの勉強もたくさんしたもの。」——教法的来源是为了佑芽
- 0053「わたしと佑芽は勝負で白黒つけるから、／喧嘩にはならないのよね。」——姐妹不吵架的原因
- 0057「……なんでもないわ。」——被看出沉默时先否认
- 0060「友達もいっぱいできたみたいで、／毎日、すっごく楽しそうなの。」——说起佑芽
- 0062「ええ。佑芽に友達ができたのは、／もちろん、喜ばしいことよ……」——先说“喜ばしい”，话尾却收了
- 0066「…………そうなのかしら。」——被问“是不是寂寞”，没有立刻否认
- 0069「……わかっているわ。／寂しいって思ってる自分に、／なんだかショックを受けたの。」——最想的是自己意外地感到寂寞
- 0073「そんな弱いお姉ちゃんを、／佑芽に見せるわけにはいかないもの。」——不能让妹妹看到弱的姐姐
- 0074「むしろ、佑芽のほうが／寂しがるべきじゃない。」——嘴硬

## 行为模式
- 教人 → 先看球再挥拍，口令短；对方做得好就明确夸（0037、0039、0044）
- 话题触及自己的软肋（佑芽离开自己） → 先沉默、说“没事”；被朋友催问才说（0055～0062）
- 被问是不是寂寞 → 先反问、再承认“可能”，然后对“寂寞的自己”感到意外（0065、0066、0069）
- 被建议向妹妹示弱 → 拒绝，以“姐姐的体面”（0072、0073）

## 关系
- ことね：被ことね叫“咲季ちゃん”；向她说出寂寞（0059～0069），ことね的评价是“麻烦的姐姐”（0075，心声，非她的话）。
- 手毬：开玩笑逗她（0003）。
- 佑芽：既为妹妹的成长高兴，又因为寂寞而困惑（0062、0069、0074）。

## 档案类事实
- 为了教佑芽读过运动理论书，学过指导（0043）。
- 小时候和佑芽吵过架（0052「うんと小さい頃はしてたかも」），之后用比赛决胜负（0053）。
- 福引得来的票她分了一半给佑芽（0070 回顾）。
