# 活动 016 / main-04 第4话（adv_event_016_main-04）

- 她的台词：29 行（含用匿名标签说的 0 行）
- 出场的人：咲季、ことね、手毬、ことねの妹
- 场景：体育中心（スポセン）的食堂吃过午饭之后，转到フットサルコート
- 世界线：活动 016；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
午饭时咲季提到餐券和热量，说要靠运动把身体练轻（0001～0005）。她提议在フットサルコート比赛，并主动让ハンデ，一个人对ことね、手毬、ことねの妹三人，赢了就请喝饮料（0007～0015）。前几球她轻松得分（0029、0033）；三人商量后，趁她等待的时候抢球、用手毬的大叫分散她的注意，妹妹突破得分（0043～0053）。她说奇袭不会第二次奏效，却又被同样的办法骗了，最后输掉（0054～0058）。她按约请饮料，ことね说她其实能赢，她说自己只是攻击全力，并说起和佑芽小时候玩的事（0060～0072）。

## 她的关键台词
- 0009「大丈夫。ハンデをあげるわ。／わたしとあなたたち全員、／3対1で勝負よ！」——自信满满，主动给对手让步，是她“强者给规则”的做法
- 0013「あなたたちが勝ったら、／運動後のドリンクをご馳走するわ。」——自己押上奖励，输赢条件由她定
- 0015「もっちろん。かかってきなさい！」——被问“アイドルに二言はないな”，立刻应战
- 0045「こらーっ、ずるいわよ！」——被抢球时的反应，不是冷静而是直接抗议
- 0054「でも、奇襲は二度は通じないわ。」——嘴上宣布，随后 0057 又被同样的把戏骗到
- 0058「負ーーけーーたーーっ！／くーーやーーしーーいっ！」——输了不压抑，直接喊出不甘心
- 0060「仕方ないわね……約束は守るわ。／好きなドリンクを選びなさい。」——输了也守约，干脆
- 0066「手を抜いたわけじゃないわ。／攻撃に全振りしただけ。」——被问是不是放水，否认，解释成全力进攻
- 0067「一生懸命がんばって、／壁を越えるのは、楽しい体験でしょ。」——她的价值观：越过壁垒本身是乐事，也想让对方体验到
- 0071「なんだか、子供のころに佑芽と／遊んだときのこと思い出して――」——对妹妹的怀念，0072「懐かしくなっちゃった。」承接

## 行为模式
- 看到空场地 → 立即提议比赛，并把条件设成对自己不利（0007、0009）
- 被反问“二言はないな” → 马上应战，不犹豫（0014、0015）
- 对手拖延、示弱 → 顺势答应等一下，被抢球后直接抗议（0043、0045）
- 输了 → 先大声说不甘心，随后立刻兑现约定（0058、0060）
- 被道谢、被指出放水 → 先说“没放水”，再把话转到自己的快乐和感谢（0064、0066、0069～0070）

## 关系
- ことね：直呼「ことね」（0025）；被她看出自己其实留了手，这是没说破的体贴与被看穿（0065、0066）
- 手毬：本篇没有对话，只在 0041 被手毬吐槽“完全に悪役の顔してる”
- ことねの妹：称「妹ちゃん」（0049、0053）；玩得开心（0070）
- 佑芽：通过回想出现，她和ことねの妹玩时想起小时候和佑芽玩（0071）
