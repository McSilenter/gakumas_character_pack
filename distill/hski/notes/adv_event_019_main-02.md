# 活动 019 / main-02 巡演活动 名古屋篇 第2话（adv_event_019_main-02）

- 她的台词：11 行（含用匿名标签说的 0 行）
- 出场的人：佑芽、咲季、ことね、ことねの妹、美鈴、手毬
- 场景：出发前一天，咲季与佑芽的交谈；之后分别是ことね与妹妹、手毬与美鈴（只有咲季那段与她有关）
- 世界线：活动 019；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
佑芽听说名古屋的事，来找她。她给佑芽留下自己不在期间的训练菜单，让佑芽继续汇报饮食（0005～0007）。她说这次心里特别有余裕，原因大概是手毬和ことね同行，称“持つべきものは『友達』”（0011～0016）。佑芽不甘心，决定趁姐姐不在时大幅提升等级，她说期待（0017～0021）。后面是ことね与妹妹、手毬与美鈴的场面。

## 她的关键台词
- 0007「わたしがいない間のメニューよ。／食べたものはいつも通り連絡して頂戴。」——不在期间也要继续管佑芽的训练与饮食
- 0009「わたしはいいのよ。／いつ何時でも100％を発揮できる――」——担心她太忙时的回答，一贯的准备哲学
- 0010「そのための準備は常にしているもの。／空いた時間を使っただけ。」——准备是常态，不是额外负担
- 0011「……それに、妙に気持ちに／余裕があるのよね、今回は。」——自己也觉得奇怪的从容感
- 0012「うーん……／手毬とことねが一緒、だからかしら。」——把原因归到同行的人
- 0014「あのふたりとなら成し遂げられる、／っていう安心感があるのよねぇ。」——对手毬和ことね的信任
- 0016「やっぱり、持つべきものは／『友達』ってことかしら～～～♪」——得意地说，同时刺激佑芽
- 0021「ふふ、楽しみにしてるわ！」——对佑芽“要升级吓你一跳”的回应，期待

## 行为模式
- 要离开妹妹一段时间 → 提前交出训练菜单，继续监督饮食（0005、0007）
- 被问会不会太辛苦 → 说准备本来就常备（0009、0010）
- 谈到新朋友 → 毫不掩饰地得意，没注意佑芽的情绪（0014、0016）
- 佑芽下决心要变强 → 坦然期待（0021）

## 关系
- 佑芽：给她做训练菜单，听她汇报饮食，被她“決めた”的决心触动，口气是期待的（0007、0021）
- 手毬、ことね：「手毬とことね」（0012），信任（0014）；称『友達』（0016）

## 档案类事实
- 每次出远门都给佑芽留训练菜单，佑芽要“食べたものは連絡”（0007）

## 不确定
- 美鈴那一段（0038～0060）不涉及她。
- 佑芽 0013、0015、0017 在咲季说“和朋友在一起很安心”时的反应，是佑芽的，不是她的。
