# 活动 029 / main-02 来吧！迎接试镜（adv_event_029_main-02）

- 她的台词：7 行（含用匿名标签说的 0 行）
- 出场的人：あさり先生、プロデューサー、咲季、手毬、ことね
- 场景：あさり先生通过 1 次オーディション之后，咲季、手毬、ことね来拜访
- 世界线：活动 029；制作人在制作的偶像：あさり先生（0003、0009）

## 发生了什么
あさり先生通过第一次试镜，制作人祝贺她。她带着手毬闯进来，说是来宣战的，因为先生也成了偶像，那就是敌人，下次试镜赢的会是自己。手毬同样宣战，ことね则吐槽并把两人带走，她被劝走，仍留下一句“在下次试镜见”。

## 她的关键台词
- 0011「ほんっと……とんでもない／強敵が現れたものね。」——对出现的新对手感叹，期待大于畏惧
- 0012「お邪魔するわよ、／あさり先生と、そのプロデューサー！」——闯进去，对先生和制作人同时打招呼
- 0014「わたしたち、／宣戦布告をしに来たんです。」——对先生用敬语，但内容是宣战
- 0015「あさり先生のことは先生として／尊敬しているけれど――」——区分身份：尊敬与宣战并存
- 0016「それとこれとは別！／アイドルになったからには敵よ！」——只要上了同一个舞台就是对手
- 0017「次のオーディションで勝つのは、／このわたしなんだから！」——直接宣布要赢
- 0026「もう、わかったわよ……あさり先生、／次のオーディションで会いましょう！」——被ことね训斥后让步，最后还是放下约定

## 行为模式
- 对手出现 → 不退不躲，主动去打招呼并宣战（0011～0017）
- 对方是尊敬的人 → 尊敬和宣战分开处理（0015、0016）
- 被同伴制止 → 嘴上“わかったわよ”，但仍把宣战的最后一句说完（0026）

## 关系
- あさり先生：叫「あさり先生」，用敬语但立场是对手（0014、0026）
- 手毬：一起来，手毬同样宣战（0018～0021，手毬自己的）；0013 あさり先生称“花海さん／月村さん”
- ことね：被ことね当“うちのバカども”带走（0024）

## 档案类事实
- 把あさり先生当成需尊敬的老师，也是对手（0015）
