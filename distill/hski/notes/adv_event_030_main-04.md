# 活动 030 / main-04 我是、小恶魔♡ 第4话（adv_event_030_main-04）

- 她的台词：19 行（含用匿名标签说的 0 行）
- 出场的人：咲季、リーリヤ、佑芽、スタッフ
- 场景：CM 拍摄当天，摄影棚
- 世界线：活动 030；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
拍摄当天，先拍三人各自的版本。リーリヤ演小恶魔不顺利，她自己先拍，一次就OK（0020～0022）。她看到苦战的リーリヤ，建议她把拍摄当做コスプレ，演一个角色，使リーリヤ成功（0028～0042）。佑芽也不顺利，リーリヤ让她想象“诱惑对象”，佑芽想到某个“好きな人”，她说“佑芽に好きな人なんて――”被佑芽的“いけそう”打断，二人谈着进入拍摄，她对被排除在外抱怨（0066～0077）。

## 她的关键台词
- 0011「そうね、佑芽。／どっちが良いCMを撮れるか勝負――」——习惯性想和佑芽比
- 0012「――と言いたいところだけど、／今日は一時休戦。協力しましょう。」——自己收回，说今天暂停竞争，协助リーリヤ
- 0020「この甘く華やかな香りで……／あなたも、わたしに囚われちゃう？」——CM 拍摄里的台词（演技），一次OK
- 0024「苦戦しているようね、リーリヤ。」——看到リーリヤ辛苦，主动上前
- 0028「そうね……あなたなら、／キャラを演じてみるのはどうかしら？」——给演技建议，结合对方的兴趣
- 0030「だって、あなたコスプレが／趣味なんでしょう？」——知道リーリヤ的爱好，直说
- 0035「小悪魔キャラになりきって、／相手を誘惑するのよ！」——总结方法
- 0042「リーリヤ！　お疲れ様！／とっても素敵だったわよ！」——成功后马上夸
- 0051「でも！　ちゃ～んとコンセプトに／合わせないと、ダメでしょ？」——肯定佑芽的“强”，同时指出要符合概念
- 0055「苦手なのよね～。／この子、おままごととかで／お母さん役はできなくて……」——解释佑芽不擅长扮演的原因
- 0066「佑芽に好きな人なんて――」——听到“好きな人”，强烈想否认
- 0077「もぉぉぉおお～～～！／ふたりだけで話を進めないで、／ちょうだぁ～～～いっ！」——被排除在外，直接发牢骚

## 行为模式
- 竞争对手同在一个现场 → 想比，但以同伴的工作为优先，改成“一时休戦”（0011、0012）
- 同伴遇到困难 → 给具体建议，利用对方的爱好（0028～0035）
- 对妹妹 → 清楚她的弱点，直接解释（0051、0055）
- 听到妹妹有“喜欢的人” → 反射性否认，但被话题带走而被撇下（0066、0074、0077）

## 关系
- リーリヤ：知道她的爱好是コスプレ（0030）；成功后称赞（0042）
- 佑芽：对她的演技很了解，指出她不擅长扮演母亲（0055）；听到佑芽想到“喜欢的人”时动摇（0066）

## 档案类事实
- 知道リーリヤ有コスプレ的爱好（0030）
- 佑芽小时候玩过家家总演父亲，不会演母亲（0055、佑芽 0056）
