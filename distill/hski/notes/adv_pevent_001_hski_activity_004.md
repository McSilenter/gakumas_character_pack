# 花海咲季 培育事件 001 activity / 004 咲季与难题（adv_pevent_001_hski_activity_004）

- 她的台词：11 行（含用匿名标签说的 0 行）
- 出场的人：咲季、プロデューサー
- 场景：培育中的活动事件（activity），不固定时间点；她在做作业，之后本打算和制作人开会（0002）；地点没交代；制作人的选项不在剧本里，0005 起是几种并列的反应
- 世界线：培育（花海咲季）；制作人在制作的偶像：花海咲季

## 发生了什么
她被作业里的一道题卡住，本想快快做完去开会，让制作人再等等。按制作人的话有几种反应：他说学习和偶像活动一样重要，她说对，作为姐姐要能教佑芽，干劲来了，5分钟做完；他（大概）提出帮忙，她坚决不要，说必须自己做、全部弄懂，为了教佑芽（制作人心想动力源头果然在这里）；她说“应该能做到”，做不出来就发火，说解不出这种题一定是哪里出错了。

## 她的关键台词
- 0004「ごめんなさい、宿題片付けるまで／もう少し待っててっ！」——让对方等时会道歉
- 0006「そう！　お姉ちゃんとして、／佑芽に教えられるようにしないと！」——学习的动力是教妹妹
- 0008「やる気出てきた！／あと5分で終わらせるから！」——一提佑芽就来劲
- 0009「だぁ～～めよ！／それじゃ意味ないもの！」——拒绝走捷径
- 0010「ちゃんと自分でやって、／全部理解しておかなきゃっ！」——要彻底弄懂
- 0011「佑芽に教えるためにっ！」
- 0015「こんな問題が解けないなんて、／なにかの間違いよっ！」——做不出来时不服气地发火

## 行为模式
- 学习卡住 → 以“要教佑芽”为理由给自己打气（0006～0008）
- 有人要代劳 → 拒绝，坚持自己弄懂（0009～0011）
- 怎么都做不出 → 不认输，说是题有问题，发起脾气来（0013～0015）

## 关系
- 佑芽：她学习是为了作为姐姐能教佑芽（0006、0011）
- プロデューサー：让他等时道歉（0004）；制作人心里说「モチベーションの源泉はそこか」（0012）

## 档案类事实
- 她认真做作业，目的之一是能教佑芽功课（0004、0006、0010～0011）
