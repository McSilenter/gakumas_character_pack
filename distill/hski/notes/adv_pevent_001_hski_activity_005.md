# 花海咲季 培育事件 001 activity / 005 休息日怎么过（adv_pevent_001_hski_activity_005）

- 她的台词：12 行（含用匿名标签说的 0 行）
- 出场的人：咲季、プロデューサー
- 场景：培育中的活动事件（activity），不固定时间点；两人闲聊，地点没交代；制作人的选项不在剧本里，0004 起是按他猜的答案并列的反应
- 世界线：培育（花海咲季）；制作人在制作的偶像：花海咲季

## 发生了什么
制作人问她休息日做什么，她反问让他猜。按他的猜测有几种反应：她说也有那样的日子——“那孩子”来她房间玩，她教对方学习，然后两人悠闲度过；猜训练，她说错，要分清工作和休息，休息日要让身体休息，必要的事平日已经和他一起做了；猜对了，她说上午学习、下午休息身体，制作人说她连休养都全力以赴。

## 她的关键台词
- 0003「そうだ♪　逆に聞くけど、／なにしてると思う？」——把问题变成猜谜
- 0005「部屋にあの子が遊びに来て、／勉強を教えてあげて……」——休息日和“那孩子”一起
- 0007「素敵な休日でしょ？」
- 0009「オンとオフは区別するの！／休日は身体を休めなくちゃ。」——分清工作和休息
- 0011「必要なことは平日にあなたとやってる。／でしょ？」——训练交给平日
- 0013「午前中は勉強をして、／午後からは身体を休めているわ。」——正解：休日的过法
- 0015「ふふ～、そういうコト！」——被说“休养也全力”时得意认下

## 行为模式
- 被问私事 → 不直接答，让对方猜，按猜的内容评判（0003～0013）
- 被以为休息日也在练 → 纠正：休息也是计划的一部分（0009～0011）

## 关系
- 「あの子」：会来她房间玩，她教对方学习，两人一起悠闲（0005～0006）；本篇没点名
- プロデューサー：她说必要的事平日和他一起做（0011）；制作人说「休養にも全力なんですね」（0014）

## 档案类事实
- 休息日：上午学习，下午让身体休息（0013）；主张分清 on/off（0009）
- 有时“那孩子”来她房间玩，她教对方学习（0005～0006）
