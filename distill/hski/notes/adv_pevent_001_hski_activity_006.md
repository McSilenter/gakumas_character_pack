# 花海咲季 培育事件 001 activity / 006 咲季的野心（adv_pevent_001_hski_activity_006）

- 她的台词：12 行（含用匿名标签说的 0 行）
- 出场的人：咲季、プロデューサー
- 场景：培育中的活动事件（activity），不固定时间点；两人闲聊，地点没交代；制作人的选项不在剧本里，0005 起是几种并列的反应
- 世界线：培育（花海咲季）；制作人在制作的偶像：花海咲季

## 发生了什么
她提议在日本最高的地方开演唱会——富士山。按制作人的反应有几种：他赞同，她就说今年的目标是富士山、让他开始准备（制作人心想得先查查能不能办）；他说要有许可，她说只要红到能拿到许可就行，对他怀疑的表情说说到做到、一定让他吃惊；她想到要告诉“大家”先做肌肉训练，两人今年起也要去登山练习（制作人心想她的粉丝都会变强壮）。

## 她的关键台词
- 0001「ねえプロデューサー！／日本一高い場所でライブなんてどう？」——“日本第一”的发想
- 0004「富士山！／どう？　どう？」
- 0006「じゃあ準備はじめておいてね。／今年の目標は富士山！」——一拍即合就定为目标
- 0009「ようは、許可が出るくらい／人気になればいいってことよね？」——把障碍转成努力目标
- 0011「なぁ～に、その顔。／わたしはやるといったらやるわよ！」——说到做到
- 0012「見てなさい！　あなたを驚かせて／やるんだからっ！」
- 0013「そうだわ。みんなに筋トレしておいて／って言っておかないと。」——连粉丝都要锻炼
- 0014「わたしたちも、今年から／登って練習しておきましょう！」——马上落实到训练

## 行为模式
- 想到大目标 → 当场定下期限，交代对方准备（0006）
- 遇到现实障碍 → 不放弃，换算成“变得多红就行”（0009）
- 被怀疑 → 宣言“说到做到”，要让对方吃惊（0011～0012）
- 计划演出 → 从体力、训练角度去准备（0013～0014）

## 关系
- プロデューサー：她把准备工作交给他（0006）；他的反应偏现实（0007、0010）
- 粉丝：她口中的「みんな」，制作人心里说是她的粉丝（0013、0015）

## 档案类事实
