# 花海咲季 培育事件 001 activity / 008 好想大扫除～（adv_pevent_001_hski_activity_008）

- 她的台词：12 行（含用匿名标签说的 0 行）
- 出场的人：咲季、プロデューサー
- 场景：培育中的活动事件（activity），不固定时间点；两人闲聊，地点没交代；制作人的选项不在剧本里，0005 起是几种并列的反应
- 世界线：培育（花海咲季）；制作人在制作的偶像：花海咲季

## 发生了什么
她叹气说这周一定要打扫房间，乱了会积压压力，想一下子收拾干净。按制作人的话有几种反应：他说压力不好、现在就去打扫，她说干就干，又说制作人不用来；他提到佑芽（大概是让佑芽帮忙），她说别说傻话，作为姐姐怎么可能，被他看出“那乱着也无所谓吗”的表情，说不是，回去一定打扫；他说别攒着做，她不耐烦地说知道了。

## 她的关键台词
- 0001「はぁ～っ。今週は絶対、／部屋の掃除をしないと……」——房间正乱着
- 0003「散らかってるとストレスが／たまるじゃない？」
- 0005「そうよ、よくないの！／活動にも影響するわ！」——把生活小事和活动挂钩
- 0007「やってやろうじゃない！」
- 0008「……って、プロデューサーは／こなくていいわよ！」——不让制作人进自己房间
- 0009「佑芽？／バカ言わないでよ。」
- 0010「お姉ちゃんとして！／できるわけないじゃない！」——不肯在妹妹面前丢姐姐的面子
- 0012「散らかってるのはいいのかって顔ね！／よくないっ！」——读出对方的表情抢先反驳
- 0017「わーかってるってばーっ！」——被反复叮嘱时的不耐烦

## 行为模式
- 被提议让佑芽帮忙 → 以“作为姐姐”为由拒绝（0009～0010）
- 看出对方心里在吐槽 → 先说出来再反驳（0011～0012）
- 被反复唠叨 → 一次比一次不耐烦（0015、0017）

## 关系
- 佑芽：不能让妹妹帮自己收拾，是“姐姐”的面子（0009～0010）
- プロデューサー：拒绝他跟去打扫（0008）

## 档案类事实
- 这时她的房间乱着，打算回去打扫（0001、0013）

## 不确定
