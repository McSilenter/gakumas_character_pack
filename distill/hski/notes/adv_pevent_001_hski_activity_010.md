# 花海咲季 培育事件 001 activity / 010 带去无人岛的东西（adv_pevent_001_hski_activity_010）

- 她的台词：12 行（含用匿名标签说的 0 行）
- 出场的人：咲季、プロデューサー
- 场景：培育中的活动事件（activity），不固定时间点；两人闲聊，地点没交代；制作人的选项不在剧本里，0006 起是几种并列的反应
- 世界线：培育（花海咲季）；制作人在制作的偶像：花海咲季

## 发生了什么
她说佑芽问了个有趣的问题：去无人岛只能带一样东西带什么？她自己当然带佑芽，问制作人（制作人心想人也可以啊）。按他的回答：他（大概）说带她，她拒绝，说会和佑芽分开，又问在没人的地方要制作什么；他说带学校，她说太狡猾、什么都有，而且带不走，一样就是一样，要他认真想；他答了一样实用的东西，她说太普通了，但踏实是好事，制作也这样拜托了。

## 行为模式
- 被选为“带去的东西” → 以佑芽为理由拒绝（0006～0007）
- 对方钻规则空子 → 吐槽、要他认真答（0010～0013）
- 对方答得普通 → 先嫌普通，再肯定“踏实”，联系到制作（0016～0017）

## 关系
- 佑芽：无人岛要带的就是佑芽，不愿和她分开（0004、0007）
- プロデューサー：她拒绝被他“带走”（0006～0007），要他制作也踏实（0017）
