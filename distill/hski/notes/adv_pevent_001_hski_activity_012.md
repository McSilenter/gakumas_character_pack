# 花海咲季 培育事件 001 activity / 012 全力唱歌吗？（adv_pevent_001_hski_activity_012）

- 她的台词：12 行（含用匿名标签说的 0 行）
- 出场的人：咲季、プロデューサー
- 场景：培育中的活动事件（activity），不固定时间点；休息日两人去卡拉OK（0001、0011）；制作人的选项不在剧本里，0005 起是几种并列的反应
- 世界线：培育（花海咲季）；制作人在制作的偶像：花海咲季

## 发生了什么
休息日来卡拉OK，她说没想到休息日也要唱歌；制作人说不是练习、放轻松，她说在他面前才不会随便唱，这就是偶像。按制作人的反应有几种：他坚持（还真替她点了歌），她说来玩也还是这么强硬；他说自己来唱、降低门槛，她说难得来卡拉OK，让他全力唱，很期待；她说不是练习也喜欢唱歌，喜欢的事就要全力做，制作人说那就不多说了，她道谢、挑起歌来。

## 她的关键台词
- 0001「まさか休みの日まで歌うとは／思ってなかったわね……」
- 0003「あなたの前で気の抜けた歌い方／なんてしないわよ。」——在制作人面前不松懈
- 0004「それがアイドルってものでしょ？」
- 0008「遊びに来ても強引さは／かわらないのね……」——对制作人的评价
- 0011「せっかくのカラオケなんだから、／全力で歌ってみせてよ。」——要求对方也全力
- 0012「ふふ、素直に楽しみだわ♪」
- 0013「レッスンじゃなくても、／歌うのは好きだもの。」——喜欢唱歌本身
- 0014「好きなことは全力でやってこそ、／でしょ？」——全力的原则

## 行为模式
- 被说“放轻松” → 不肯在制作人面前随便唱，自认偶像就该这样（0002～0004）
- 对方要唱 → 要求他也全力，真心期待（0011～0012）
- 喜欢的事 → 不分练习与否都全力做（0013～0014）

## 关系
- プロデューサー：她说他来玩也很强硬（0008）；在他面前不肯松懈地唱（0003）

## 档案类事实
- 不是练习也喜欢唱歌（0013）
