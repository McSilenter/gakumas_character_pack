# 花海咲季 培育事件 001 activity / 013 吃沙拉吧（adv_pevent_001_hski_activity_013）

- 她的台词：11 行（含用匿名标签说的 0 行）
- 出场的人：咲季、プロデューサー
- 场景：培育中的活动事件（activity），不固定时间点；两人外出吃饭，有几家店可选（0005），具体地点没交代；制作人的选项不在剧本里，0005 起是几种并列的反应
- 世界线：培育（花海咲季）；制作人在制作的偶像：花海咲季

## 发生了什么
她说饿了，制作人让她随便选，她选沙拉吧；制作人问只吃这个吗。按他的话有几种反应：她说别的店甜食多、咖喱脂肪多，想去别处会说的，沙拉吃到饱反而开心，要全部吃一遍；制作人说自己也吃沙拉（理由是平时蔬菜吃得少、吃到饱少见），她说他理由真多、其实不用迁就她，那就开吃；她说不是在忍耐，就是喜欢 PFC 平衡的饮食（制作人心想真是了不起的女高中生，不，偶像的苗子）。

## 行为模式
- 选吃的 → 按营养（甜食、脂肪）判断，选沙拉，而且真心高兴（0003～0009）

- 对方迁就自己 → 察觉、说不用在意，听了理由也就接受（0010～0014）
