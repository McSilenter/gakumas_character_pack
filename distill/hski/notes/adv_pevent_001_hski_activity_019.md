# 花海咲季 培育事件 001 activity / 019 又赢了的咲季（adv_pevent_001_hski_activity_019）

- 她的台词：12 行（含用匿名标签说的 0 行）
- 出场的人：咲季、プロデューサー
- 场景：培育中的活动事件（activity），不固定时间点；她刚和佑芽比过一场；地点没交代；制作人的选项不在剧本里，0005 起是几种并列的反应
- 世界线：培育（花海咲季）；制作人在制作的偶像：花海咲季

## 发生了什么
她得意地笑，说又赢了和佑芽的比赛，今天也一如既往（制作人心想还没被追上，趁现在……），要制作人说点什么。按他的话有几种反应：他夸她，她说还不会输，为了把佑芽甩得更远，下周也要比；他提醒佑芽进步很快，她说知道、多夸夸她也行吧，但承认他说得对，佑芽也在大幅成长，不能输；他（大概）说两人关系好，她说关系是好，但现在不同，要他给些更让人有干劲的话，比如“你很努力了”，再来一次。

## 她的关键台词
- 0002「また佑芽との勝負に勝っちゃったわ！／今日もまた、あいかわらず！」——和佑芽的胜负一直在继续
- 0004「プロデューサー！／なにか言うことがあるでしょ？」——主动讨夸
- 0005「ふっふん♪／まだ負けてなんかやらないわ。」——“还”不会输
- 0006「さ、佑芽をさらに！／引き離すために！」
- 0008「わかってるわよ、そんなこと！／もっと褒めたってよくない？」——被泼冷水先不满
- 0009「……でも、あなたの言う通りよ。」——随后认下
- 0010「佑芽だってすごく伸びてる。／負けてられないわっ！」——清楚妹妹在追赶
- 0011「仲はいいけど、今は違うでしょう！」——比赛时姐妹情放一边
- 0013「そういうのちょうだいっ！／さ、もう一度っ！」——要夸奖当动力

## 行为模式
- 赢了佑芽 → 得意，要制作人说话（夸她）（0001～0004）
- 被提醒佑芽在追 → 先抗议“多夸我”，再承认事实、转成干劲（0008～0010）
- 赢了也不停 → 立刻定下下一场、要把差距拉大（0006～0007）

## 关系
- 佑芽：她又赢了和佑芽的比赛；佑芽成长很快，她要拉开差距；两人关系好，但比赛时是另一回事（0002、0006、0010～0011）
- プロデューサー：她要他夸、给有干劲的话（0004、0012）；制作人心里说「まだ、追いつかれはしていない」（0003）

## 档案类事实
- 她和佑芽经常比赛，本篇她又赢了（0002）

## 不确定
- 0002「今日もまた、あいかわらず！」、0005「まだ負けてなんかやらないわ」是“一直赢佑芽”的说法，和亲爱度线的勝ち逃げ相关（见 conflicts 一·1）；本篇是培育线，不算冲突。
