# 花海咲季 培育事件 003 activity / 022 游泳就要向鱼学习！（adv_pevent_003_hski_activity_022）

- 她的台词：11 行（含用匿名标签说的 0 行）；0001、0003、0004、0005、0006、0008、0010、0013、0014、0015、0017
- 出场的人：咲季（11 行）、プロデューサー（7 行）
- 场景：培育中的活动事件（activity），在水族馆（0014）看鱼；0005 之后有三种并列走向（0006～0010、0011～0014、0015～0018），是制作人不同选项后的分支
- 世界线：培育（花海咲季）；制作人在制作的偶像：花海咲季

## 发生了什么
她认真看着一条鱼游泳（0001、0003），赞叹动作精炼、有生物的跃动感（0004），想能不能用在舞蹈上（0005）。之后三种走向：她同意身体构造差太多，制作人提蛙鞋，她说想要的是跃动感，需要别的办法，交给制作人去查（0006～0010）；制作人建议先看看别的鱼，她要看遍水族馆的鱼（0011～0014）；她拜托制作人（帮忙想办法），制作人提醒现在加新元素课程会很辛苦，她说克服这点是她的工作（0015～0018）。

## 她的关键台词
- 0004「無駄のない、洗練された動き……／まさに生物の躍動感ね。」——从鱼的游泳里看出「躍動感」
- 0005「あの動き、／ダンスの参考にできないかしら？」——什么都想拿来用在舞蹈上
- 0008「取り入れたいのは、あくまで生物の／躍動感だもの。別の方法が必要だわ。」——分清要学的是本质而不是形
- 0010「ええ、お願いするわ。／任せたわよ、プロデューサー！」——把调查交给制作人
- 0014「そうと決まったら、早速行きましょう！／水族館中の魚を見てやるわ！」——决定了就马上行动、要做到彻底
- 0017「そこをなんとかするのは、／わたしの仕事でしょう？」——辛苦的训练由她自己扛

## 行为模式
- 看到好的动作 → 想怎么用到自己的舞蹈上（0005）
- 被提议照搬形式 → 指出要的是本质，换别的方法（0006、0008）
- 被提醒训练会很苦 → 「わたしの仕事でしょう？」（0017）
- 决定了 → 马上行动，要做到全部（0014）

## 关系
- プロデューサー：称「プロデューサー」；把查资料、沟通交给他（0010、0015、0018）
