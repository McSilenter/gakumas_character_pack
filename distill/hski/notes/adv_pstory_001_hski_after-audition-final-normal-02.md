# 花海咲季 培育剧情 001 / after-audition-final-normal-02 考试的结果是…（adv_pstory_001_hski_after-audition-final-normal-02）

- 她的台词：22 行（含用匿名标签说的 0 行）
- 出场的人：咲季、プロデューサー
- 场景：最终考核刚结束、正式 live 之前，结果第二档（0002「合格です。素晴らしい結果でしたね。」）；地点没交代
- 世界线：培育（花海咲季）；制作人在制作的偶像：花海咲季

## 发生了什么
成绩很好，她说对现在的自己算是妥当。制作人叫她（像是看出她藏着心情），她说不是藏，是没整理好、先搁置；名次很微妙，是前列也是好结果，但又高兴又不甘又不安，还有松了口气的自己；总之先集中在 live 上，痛快唱跳完再烦恼。另一段里被问是不是不满，她说当然，任何竞技第一以外都是输——又说要是能这么自信满满地说就好了，老实说拿到高名次她挺高兴，而对这样的自己既不满又不安，不像要当世界第一偶像的花海咲季；制作人说这很像她的烦恼，她说只有她的制作人会这样一句话结束话题，于是不烦了。最后她说“你当我是谁”，要制作人好好看 live。

## 行为模式
- 心情复杂时 → 先搁置，把精力放到眼前的 live（0006～0013）
- 被问是否不满 → 先说大话，随即自己承认真实想法（0014～0018）
- 制作人一句话带过烦恼 → 半嗔半认地接受，立刻切换回干劲（0019～0021）
- 被确认有没有信心 → 「わたしを誰だと思っているの？」，自报全名（0022～0024）
