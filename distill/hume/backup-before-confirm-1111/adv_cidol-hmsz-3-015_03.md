# P卡 秦谷美鈴【ENDLESS DANCE】 / 第3话 ENDLESS DANCE 第3话（adv_cidol-hmsz-3-015_03）

- 她的台词：9 行（含匿名标签 0 行）；另有『一同』1 行（0002）未计入台词行数，见「不确定」
- 出场的人：美鈴、佑芽、星南
- 场景：练习中休息的时候（0001 星南“すこし休憩にしましょう”）
- 世界线：亲爱度（秦谷美鈴）·P卡；制作人在制作的偶像：美鈴

## 发生了什么
练习休息时，星南说美鈴这么有干劲很少见。美鈴说她被制作人的策略“成功地骗到了”，约定在三人共演 live 之前每天都练习。佑芽高兴说喜欢和美鈴一起练习。美鈴接着讲制作人如何用各种办法调动她，又说“实质上约定了”制作人会永远是自己一个人的制作人；佑芽问“约定了？”，星南小声吐槽，佑芽让她别出声。最后佑芽对美鈴说“你真的很喜欢制作人”，美鈴害羞地承认他是重要的人。

- 0038「プロデューサーさんのこと、／大好きなんだなぁって。」——和 Star-mine 第2话同样的判断，再说一次

## 行为模式
- 朋友约定要认真练习 → 比朋友本人还高兴，马上说自己喜欢和她一起练（0007、0010、0011）
- 听朋友炫耀（惚气）→ 当真地听、追问（0019、0030），同时拦着别人拆穿（0033）
- 看到朋友比平时多话 → 说出来，然后下结论“她真的很喜欢”（0035、0037、0038）

## 关系
- 美鈴：称「美鈴ちゃん」（0010）；美鈴称「佑芽さん」，说“それでこそ佑芽さんです”（0012）；一起练习、一起合作演出
- 星南：称「星南先輩」（0033）；用丁寧体说话（0035）；星南叫她「佑芽」（0034）

## 档案类事实
- 她喜欢和美鈴一起练习，觉得能进步（0010、0011）
- 次回的 live 是她、美鈴、星南共演（美鈴 0009 “わたしたちが共演するライブ”；星南 0024 “おふたりとの共演”）
