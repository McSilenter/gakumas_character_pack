# P卡 花海咲季【Boom Boom Pow】 / 第1话 Boom Boom Pow 第1话（adv_cidol-hski-3-001_01）

- 她的台词：12 行（含匿名标签 0 行）；另有『一同』1 行（0007）未计入台词行数，见「不确定」
- 出场的人：咲季、佑芽、プロデューサー（一同 1 行）
- 场景：早饭桌（0005 咲季“一緒に朝ごはん食べる？”）和之后的练习结束时；具体地点剧本没写
- 世界线：亲爱度（花海咲季）·P卡；制作人在制作的偶像：咲季

## 发生了什么
制作人突然提出想暂时和咲季一起生活，咲季叫他一起吃早饭，佑芽也在。咲季的新作食物糊里有南瓜、芹菜、胡萝卜，制作人答中了，佑芽才发现制作人在场并大惊。制作人说自己有事情，请姐妹自然聊天。之后练习结束，佑芽对咲季说制作人整个练习期间一直盯着她看，还猜“制作人对お姉ちゃん产生了禁断之恋”。

## 她的关键台词
- 0008「おいしー♪　お姉ちゃん、／いつもありがとう！」——姐姐做饭，她直接道谢
- 0014「えっすごい！　あたし、／ぜんぜんわかりませんでした――」——制作人答中了食材，她自己完全没猜出
- 0015「って、なんでプロデューサーさん／がいるんですか！？」——等到这时才发现制作人坐在桌边
- 0017「えっ……えぇ～～っ？　／そっ、それって……もしかして……」——听到“想和咲季在一起”马上往恋爱方向猜
- 0026「お疲れ様、お姉ちゃんっ！」——练习结束时的招呼
- 0030「レッスンの間中、／じーっとお姉ちゃんを見て。」——观察到制作人一直看着咲季
- 0031「腕組みしながら、／うんうんって満足そうにしてたよ。」——细节观察
- 0035「プロデューサーさんは、／お姉ちゃんに……しちゃったのかも……」——提出自己的猜测
- 0036「禁断の恋を！！」——结论

## 行为模式
- 被问到看不懂的东西 → 坦率说完全不懂（0014）
- 桌边多了个人 → 吃到一半才突然注意到并喊出来（0015）
- 看到某人对姐姐的异常关注 → 向姐姐汇报自己观察到的细节，再往恋爱方向下结论（0028～0036）

## 关系
- 咲季：称「お姉ちゃん」（0008、0026）；咲季本篇没有叫她的名字（0027 只说“あなたもね。”）；姐妹同桌吃早饭，同一场练习
- プロデューサー：称「プロデューサーさん」（0015、0028）；对咲季的制作人，不是自己的制作人（0015 她不知道他为什么在）

## 档案类事实
- 今天早饭里有新作的“フードペースト”，食材是南瓜、芹菜、胡萝卜（咲季 0010～0013，制作人答中）；佑芽 0014 说自己完全没猜出来
- 佑芽和咲季一起上同一场练习（0025～0027：咲季说“今日のレッスンはおしまい！”，佑芽“お疲れ様、お姉ちゃんっ！”，咲季“あなたもね。”）
