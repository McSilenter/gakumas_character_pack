# P卡 花海佑芽【The Rolling Riceball】 / 第3话 The Rolling Riceball 第3话（adv_cidol-hume-3-000_03）

- 她的台词：22 行（含匿名标签 0 行）
- 出场的人：佑芽、プロデューサー
- 场景：新曲首次上台的 live 当天，在初星学园（0028），姐姐在最前排看（0029）
- 世界线：亲爱度（花海佑芽）·P卡；制作人在制作的偶像：佑芽

## 发生了什么
live 当天，制作人担心得没精神，佑芽说新曲总算赶上了，真的很险。她说一直在等这一天：学新歌很开心、每天的レッスン很开心、期待在舞台上唱和大家的反应，想把自己感受到的快乐传给会场里的所有人，现在的她做得到。制作人泼冷水说“是错觉吧”，与会场全员共鸣是偶像 live 的理想形，是顶级偶像的领域；她抗议“被水管喷了”，说他认为新手偶像做不到，制作人说万一真做到了会很可怕。她说马上给他看证据：这里是初星学园，很多偶像在看，姐姐也在最前排看，所以她要去向全校学生下战书。
