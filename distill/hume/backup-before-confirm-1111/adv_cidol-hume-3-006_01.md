# P卡 花海佑芽【Campus mode!!】 / 第1话 Campus mode!! 第1话（adv_cidol-hume-3-006_01）

- 她的台词：21 行（含匿名标签 0 行）
- 出场的人：佑芽、プロデューサー
- 场景：『N.I.A』期间（0015），她刚输了一场之后；地点看不出
- 世界线：亲爱度（花海佑芽）·P卡；制作人在制作的偶像：佑芽

## 发生了什么
佑芽哭着向制作人求助，说自己作为偶像的实力完全不够：她输了，而且是在和姐姐打平之后输的，这样会连姐姐的格都被看低，所以很不甘心。制作人马上答应“想办法”，她惊讶他答得太快。制作人给她初星学园传统曲『Campus mode!!』的衣装，说这是初星偶像的必杀技、只有被选中的人才能在舞台上唱；她在定期公演优胜、有和咲季打平的实力，已经有资格被这么称呼，和宿命对手决战时要唱的只能是这首。她想起自己是“和姐姐对等的超厉害新人偶像”，燃起来，说要学会花海佑芽的『Campus mode!!』。

## 行为模式
- 输了 → 少见地哭着求助，但不甘心的焦点是“连累姐姐被看低”（0001～0010）
- 以为要恳求 → 对方马上答应，反应不过来（0013）
- 听到“必杀技”“被选中的人”之类的词 → 立刻兴奋（0022、0024、0031）
- 被提醒自己的成绩 → 慢慢想起来，重新说出“我和姐姐对等”（0025～0028）

## 关系
- 制作人：称「プロデューサーさん」；输了就去找他哭诉（0001），他马上答应想办法（0012 制作人）；制作人说几乎没有新人偶像赢得了她（0006 制作人）
- 咲季：和姐姐打平过（0008）；怕自己输了害姐姐的评价下降（0009）；『Campus mode!!』是给宿命对手决战用的曲（0030 制作人）

## 档案类事实
- 『N.I.A』期间，在和姐姐打平之后输了一场（0007、0008）
- 制作人说她在定期公演优胜过（0025 制作人）
- 『Campus mode!!』是初星学园传统曲、初星偶像的必杀技，只有被选中的人能在舞台上唱（0017、0021、0023 制作人）
- 要习得『Campus mode!!』作为『N.I.A』对策（0032 制作人）
