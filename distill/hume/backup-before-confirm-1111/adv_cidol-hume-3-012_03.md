# P卡 花海佑芽【Star-mine】 / 第3话 Star-mine 第3话（adv_cidol-hume-3-012_03）

- 她的台词：25 行（含匿名标签 0 行）
- 出场的人：佑芽、星南、美鈴、プロデューサー
- 场景：接 012_02，前半仍是三人谈话（0001～0054）；0055 起她把这段经过讲给制作人听（场景转换剧本没标）；地点看不出
- 世界线：亲爱度（花海佑芽）·P卡；制作人在制作的偶像：佑芽（0001 星南「佑芽の悩み」，0060 制作人叫她「佑芽さん」）

## 发生了什么
星南确认她的烦恼是“想被制作人看成可爱的”，她说说出口很难为情，美鈴说想让亲近的人如愿看待自己是理所当然的心情。星南建议直接向本人要求，她当场练习了一遍，害羞得喊停；星南又小声教她一句“时髦的换说法”，她照着说“请成为我的人”，自己大叫太色了，美鈴责备星南，星南说这是她スカウト了佑芽和美鈴时的決め台詞。美鈴说要打动人心光靠对话不够、要靠行动，打动人心是偶像最擅长的事；星南领会，提议以制作人为观众，三人开一场迷你 live，积累组合舞台的经验，美鈴也答应。她说当然要做，又突然说加入生徒会、和两人在一起真好，说三人虽然是 solo 偶像也要一起开很多 live。之后她把这一切讲给制作人听，制作人赞成，要把这三人的 live 办成惯例；她说有预感和这三人一起唱会变得更强更可爱。制作人问她把来龙去脉全说出来好吗，她这才发觉，求他别笑。

## 行为模式
- 别人给建议 → 马上当场试说一遍（0012～0014、0018～0020），说完自己害羞叫停（0015、0021）
- 被邀请一起做事 → 立刻答应（0048），并突然表达感谢，说不出理由（0049～0052）
- 向制作人汇报 → 一口气全讲出来，连“想被他看成可爱”的动机也说了，被点破才发觉（0055、0060～0064）

## 关系
- 星南：称「星南先輩」（0009、0053）；星南教她直接要求、教她決め台詞（0011、0017 星南），提议三人开迷你 live（0038 星南）；她说加入生徒会、和两人在一起真好（0049、0050）
- 美鈴：称「美鈴ちゃん」（0009、0044）；美鈴说想被亲近的人如愿看待是理所当然（0006、0007 美鈴）；她说「さすが美鈴ちゃん！」（0027）
- 制作人：称「プロデューサーさん」；想让他觉得自己可爱（0014）；他赞成三人 live、要办成惯例（0056、0057 制作人）；他点破她全说出来了（0060、0061 制作人）

## 档案类事实
- 她是生徒会成员，说加入生徒会真好（0049）
- 她、星南、美鈴都是 solo 偶像（0053），三人约定一起开很多 live（0054）；制作人同意把三人 live 办成惯例（0057 制作人）
- 星南说 0020 那句是她スカウト成功时的決め台詞（0023 星南）
