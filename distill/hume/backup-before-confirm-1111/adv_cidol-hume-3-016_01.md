# P卡 花海佑芽【ENDLESS DANCE】 / 第1话 ENDLESS DANCE 第1话（adv_cidol-hume-3-016_01）

- 她的台词：27 行（含匿名标签 0 行）
- 出场的人：佑芽、プロデューサー
- 场景：和制作人的例会（0004「このミーティング」）；地点看不出
- 世界线：亲爱度（花海佑芽）·P卡；制作人在制作的偶像：佑芽（0009 制作人给她安排下次 live）

## 发生了什么
她兴冲冲地来开会，说最喜欢这个会，因为制作人总是提出让人兴奋的点子。制作人说下次 live 要她和几位偶像共演，她猜是千奈和広，答案是十王星南和秦谷美鈴，三人唱同一首曲、用対バン形式；她非常兴奋，期待和两人比。随后她沉默下来，问制作人怎么看星南和美鈴；制作人说两人在学内外都是近乎最高评价的偶像：『一番星』星南除了实战经验支撑的实力，还有数据显示不出的不可思议的魅力；美鈴有让观众着迷的魔性，放着不管也会成为顶级偶像——她越听越不甘心，大喊打断。她学美鈴犯困的口吻、学星南的说话方式，想展示“魔性的魅力”“『一番星』的偶像光环”，被制作人说“和平时一样是有趣又可爱的魅力”“『一番星』才不说那种莫名其妙的话”。制作人说小技巧的模仿再现不了偶像真正的魅力，她说那就沉下心来模仿，叫他三天后来，让他见识“真正的偶像”。

## 行为模式
- 听到要和厉害的人对决 → 马上兴奋（0013～0016）
- 制作人当面夸别的偶像 → 先附和“我懂”，再越来越不甘心，最后大喊打断（0029、0033、0035）
- 想证明自己也有那种魅力 → 当场模仿对方（0037～0043）；被说不像 → 不服，改成“认真模仿”，自己定下期限（0045～0051）

## 关系
- 制作人：称「プロデューサーさん」；说最喜欢和他开会（0004、0005）；他夸星南、美鈴时她不甘心、吃醋（0033、0035）；他叫她「佑芽さん」（0003）
- 星南：称「星南先輩」（0022）；承认星南的魅力“我懂”（0029）；模仿星南（0042、0043）
- 美鈴：称「美鈴ちゃん」（0022、0030）；模仿美鈴（0037～0040，制作人 0039 认出来）
- 千奈、広：以为共演对象是两人（0011）

## 档案类事实
- 下次 live 和星南、美鈴共演，三人唱同一首曲，対バン形式（0012、0014 制作人）
- 制作人说星南、美鈴都是和她「関係が深い超実力者」（0017 制作人）

## 不确定
- 0037～0040 是模仿美鈴、0042、0043 是模仿星南，不是她平时的说话方式。
- 0019 沉默、0022 发问的原因剧本没直说；从 0029～0035 看是听制作人夸两人而不甘心或吃醋，与 012_02 的 0005 相似。
- 共演唱的曲本篇没写（016_03 里她学的是『ENDLESS DANCE』）。
- 星南仍是『一番星』（0026 制作人），本篇在亲爱度线上的时间点没交代。
