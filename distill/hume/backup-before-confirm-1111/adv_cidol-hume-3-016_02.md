# P卡 花海佑芽【ENDLESS DANCE】 / 第2话 ENDLESS DANCE 第2话（adv_cidol-hume-3-016_02）

- 她的台词：23 行（含匿名标签 0 行）
- 出场的人：佑芽、プロデューサー
- 场景：016_01 的三天后（0001「～3日後～」），她把练好的曲唱给制作人听；地点看不出
- 世界线：亲爱度（花海佑芽）·P卡；制作人在制作的偶像：佑芽（0037 制作人「我が最強の担当アイドルさん」）

## 发生了什么
三天后制作人来了，她唱了『Choo Choo Choo』。制作人愣住，说不只是成形，很厉害，问三天就学会了？她看出制作人脸上写着“能做到的话平时也这样啊”，说其实早就在练，因为觉得帅。制作人说和十王星南的歌、舞都不像，但有逼近本人的魅力，不是单纯的模仿，学到了偶像的本质——不只从星南，也从美鈴。她说她尽力模仿了星南没有多余、让人着迷的漂亮动作，美鈴把人紧紧吸进去的歌声，还有两人 live 里说不尽的魅力、让粉丝沉浸到看见幻影的那种感觉；是一边回想模仿姐姐、一下子进步的时候一边做的；只学到一小部分，效果却这么大，比以前更喜欢两人了。制作人说比以前更怕她了，她抗议；制作人说“依靠你了，我最强的担当偶像”。

## 行为模式
- 说要做到的事 → 按期限做到，并主动问评价（0006～0009、0017）
- 看懂制作人的表情 → 把他心里的话替他说出来（0014）
- 学别人 → 不只学形，而是抓对方的魅力；用“模仿姐姐时进步”的感觉去学（0023～0029）
- 学到对方的长处 → 更喜欢对方（0032、0033）

## 关系
- 制作人：称「プロデューサーさん」；他说比以前更怕她（0035 制作人），又说「頼りにしていますよ、／我が最強の担当アイドルさん。」（0037）
- 星南、美鈴：分析两人的魅力（0023～0027），说更喜欢两人了（0032、0033）
- 咲季：以前模仿姐姐时会一下子进步（0029）

## 档案类事实

## 不确定
- 『Choo Choo Choo』是谁的曲剧本没写；0018 制作人说“和十王星南的歌、舞都不像”，像是星南的曲，没明说。
