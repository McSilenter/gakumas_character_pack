# P卡 花海佑芽【ENDLESS DANCE】 / 第3话 ENDLESS DANCE 第3话（adv_cidol-hume-3-016_03）

- 她的台词：12 行（含匿名标签 0 行）
- 出场的人：美鈴、星南、佑芽
- 场景：星南、美鈴教她『ENDLESS DANCE』的练习中，休息时（0001）；地点看不出
- 世界线：亲爱度（花海佑芽）·P卡；制作人在制作的偶像：佑芽（本篇制作人没出场，从 016_01 接下来看）

## 发生了什么
练习间歇，美鈴夸她已经记住『ENDLESS DANCE』，星南说这次学得快，平时要更久；她说因为两人寸步不离地教她，又高兴又开心。星南说最近的她特别坦率可爱，她说有些感触，比以前更喜欢两人了；星南说咲季知道了会吃醋，愿意把自己的经验全部传给她，她道谢。美鈴提醒星南把她培养得这么强，会威胁到『一番星』之位，星南说正合我意，尽管放马过来。美鈴说星南应该也明白佑芽刚才做了什么——模仿了谁和谁学会了『ENDLESS DANCE』；美鈴说还认识另一个做过同样事的人，“她”被大家害怕，现在有点懂大家的心情了，星南说她也是，但还是那句话：放马过来。美鈴对佑芽说期待共演，她说不会输，说能遇到美鈴和星南真好，今后要一直竞争下去。
