# P卡 花海佑芽【纯白画页与水彩绘就的主角】 / 第2话 纯白画页与水彩绘就的主角 第2话（adv_cidol-hume-3-017_02）

- 她的台词：19 行（含匿名标签 0 行）
- 出场的人：佑芽、広、千奈、プロデューサー
- 场景：『H.I.F』结束、合宿开始后（0001 制作人）；前半是和制作人（0001～0014），后半（0015 起）她和広、千奈在一起，千奈和広肌肉酸痛动不了（0019 千奈）；地点看不出
- 世界线：亲爱度（花海佑芽）·P卡；制作人在制作的偶像：佑芽（0002 制作人开始她的新曲练习）

## 发生了什么
制作人说时候到了，开始新曲练习，她完全忘了，被提醒后马上说要开始。制作人说已经请作曲家来看合宿末尾的“那场 live”，作为新曲升级的反馈；她惊叫要用未完成的歌上阵，制作人说这是展示最新花海佑芽的最佳选择，也是胜率最高的计划，因为这次的对手很强；她说那就必须用新生『花海佑芽』的曲挑战，要再破一次壳。后半她向広、千奈说正在赶练新曲，広说羡慕她总被制作人出难题，她得意地说不给你。三人趁千奈、広肌肉酸痛，继续聊“偶像花海佑芽、篠澤広、倉本千奈”来研鑽：広夸千奈从出道 live 起就让人满足，千奈说是周围人的功劳，她以千奈粉丝俱乐部一员的身份说“绝对不止如此”，要千奈教她诀窍，好“用学来的魅力打倒千奈”；千奈说 live 是表现自己的世界、邀请和引导粉丝。她夸広的歌舞没有多余、像达人的演武，要広教她，好“把広打趴下”；広说想象最强的自己，让不成器的现在的自己去接近。最后她说聊偶像真开心。

## 行为模式
- 被交代的事忘光 → 一提醒就马上切换、干劲十足（0003、0006、0007）
- 被出难题（用未完成的歌上台） → 先惊叫，听完理由就燃起来（0010、0013、0014）
- 向朋友请教 → 直说是为了“用学来的东西打倒你”（0032、0044）；对方也同样回敬 → 高兴地说正合我意（0055）

## 关系
- 広：称「広ちゃん」（0044），用常体；広叫她「佑芽」（0016 広），羡慕她被制作人出难题，她得意“不给你”（0017）；她夸広的表演像达人演武（0041）
- 千奈：称「千奈ちゃん」（0022、0032）；自称千奈粉丝俱乐部的一员（0026）；千奈叫她「花海さん」（0054 千奈）
