# P卡 花海佑芽【Agitato】 / 第1话 Agitato 第1话（adv_cidol-hume-3-022_01）

- 她的台词：25 行（含匿名标签 0 行）
- 出场的人：佑芽、プロデューサー
- 场景：制作人向她提案的时候，制作人说“明知现在是辛苦的时期”（0001）；十王星南快毕业的时候（0019）；地点看不出
- 世界线：亲爱度（花海佑芽）·P卡；制作人在制作的偶像：佑芽（0037 制作人「我が担当アイドル」）

## 发生了什么
制作人说明知现在是辛苦时期也有个提案，她没听内容就说“做”，因为是制作人为她提的，一定是好事。制作人问她知不知道初星学园的『大型タイアップ企画』，她听说第一弾是和大型服装厂商；第二弾选了花海佑芽，对象是超有名的化妆品厂商。她很吃惊：在初星学园说到化妆品就是星南，还以为人家要的是成熟漂亮的偶像。制作人说是他在コンペ赢了，在星南快毕业时拿到化妆品案子意义很大；他边放她的 live 视频边口头讲 CM 构想，说和她签约以后从没觉得会输コンペ。新香水的缪斯要兼有“清新的健康美”和“小恶魔的色气”，她说正是我；CM 是穿可爱的小恶魔衣装在夜晚街头跳舞，背景放她的歌。对方对“非常健全的小恶魔”深表认同，但对“小恶魔的色气”都很怀疑——制作人还说过那方面放弃也完全没问题；她非常不甘心，制作人说同感，要她在拍摄时让对方刮目相看。她问制作人相信她能做到吗，制作人说当然，一开始就说过要用压倒性的美貌赢，确信她终将成为世界上最美的偶像；她沉默片刻，说“是啊”，重新接下这份工作，说要再接近他的理想一步。

- 0002「はいっ、やりま～す♪」——不听内容先答应
- 0004「プロデューサーさんが、／あたしのために提案してくださるん／ですから。」——理由
- 0005「いい話に決まってますよ！　／さっそく説明をお願いします。」——同上
- 0013「けっ、化粧品！？　／あたしがですか～っ！？」——意外
- 0015「だって……初星学園で／化粧品といったら、星南先輩ですし。」——拿星南比较
- 0016「大人っぽくて綺麗なアイドルが／求められているのかなって。」——同上
- 0027「まさにあたしですね！！」——自信
- 0034「なんですとぉ！？」——听说对方怀疑她的色气
- 0039「プロデューサーさんは……／あたしができるって／信じてくださいますか？」——问制作人信不信她
- 0043「――そうでしたね！」——想起来了
- 0044「あらためて。／このお仕事、お引き受けします。」——重新接下
- 0046「あなたの理想に近づきます！」——目标是他的理想

## 行为模式
- 制作人提案 → 不听内容先答应，理由是“为我提的一定是好事”（0002、0004、0005）
- 被分到意外的工作 → 先拿学园里最合适的人比较，问为什么是自己（0013～0017）
- 被看低（色气） → 不甘心（0034、0036），问制作人信不信她（0039）；得到肯定 → 重新郑重接下，把目标定为“接近他的理想”（0043～0046）

## 关系
- 制作人：称「プロデューサーさん」（0039），0046 称「あなた」；无条件相信他的提案（0004、0005）；制作人说和她签约后コンペ从没觉得会输（0022 制作人），说她终将成为世界上最美的偶像（0041 制作人）
- 星南：她说初星学园说到化妆品就是星南（0015）；制作人说星南快毕业了（0019 制作人）

## 档案类事实
- 初星学园『大型タイアップ企画』第二弾选了她，对象是超有名化妆品厂商，当新香水的缪斯、拍 CM（0010、0012 制作人、0025）
- 第一弾是和大型服装厂商的タイアップ（0008）
- CM 内容：穿可爱的小恶魔衣装在夜晚街头跳舞，背景放她的歌（0028 制作人）
- 制作人通过コンペ赢下这个案子（0018 制作人）

## 不确定
- 0001 制作人说的「いまが大変な時期」是什么时期，剧本没写。
- 0019 制作人「十王星南が卒業しようという／このタイミングで」：星南快毕业了；亲爱度 036 冬季『H.I.F』后的授与式上她提到星南毕业，本篇应在那前后，具体先后看不出。
- 0040 制作人「最初から掲げていたでしょう。／圧倒的な美貌で勝つと。」——亲爱度 010 是在第 2 次『選抜試験』之后才定下“最高的歌唱、舞蹈、美貌”的方针，不是第 1 话起；“最初から”可能只是泛指，不判冲突，留给人看。
- 0022 制作人「あなたと契約をしてから」——制作人和她“签约”的具体形式剧本没写。
- 0042 她沉默后 0043「――そうでしたね！」是想起了什么，剧本没写（从 0040、0041 看是制作人一开始的方针）。
