# P卡 花海佑芽【Agitato】 / 第3话 Agitato 第3话（adv_cidol-hume-3-022_03）

- 她的台词：19 行（含匿名标签 0 行）
- 出场的人：プロデューサー、佑芽
- 场景：CM 拍摄结束后（0001）；地点看不出
- 世界线：亲爱度（花海佑芽）·P卡；制作人在制作的偶像：佑芽（0019 制作人带她去吃饭要先取得咲季许可）

## 发生了什么
拍摄结束，制作人说“小恶魔的色气”完全出来了，到最后还在苦战、临场突然做到，说她果然强于正式场合。她说不只是她自己的力量：拍摄前意识到制作人的话，还有准备好的作战——企划一定下来，她就找了一位擅长凛然表情的“某个朋友”，对方说“要挑战大工作是吧，没办法，教你”，教了她诀窍：拍摄中一直意识到这是重要工作、和比赛一样，同时在脑海一角念着“肚子饿了……”。制作人大笑，说那色气原来是饿肚子的表情；她说为此特地没吃饭。制作人说那可不行，拍完一起去吃饭——当然先取得咲季的许可；她很期待。制作人说 5 年、10 年后她会有不输真正恶魔的大人魅力，以前这是他梦想的理想的花海佑芽，但今天看了她改变了想法：现在的小恶魔魅力也能对理想的顶级偶像一箭还击。她说只有肚子饿的时候才能用；制作人要她快点做到随时能用，一起带到未来；她说要追上未来，让他说“现实比理想更有魅力”。

## 行为模式
- 被夸临场强 → 把功劳分给制作人的话和事前准备（0007～0009）
- 遇到不擅长的表现 → 提前去问擅长的朋友，照教的“作战”执行（0011～0016）
- 为了工作 → 不惜饿着肚子去拍（0018）
- 制作人说出对她的理想 → 反问“现在的我也不错吧”，宣言要让他说现实胜过理想（0026、0033、0034）

## 关系
- 制作人：称「プロデューサーさん」（0008），0033 称「あなた」；他说她「本番に強い」（0005 制作人）；他说拍完一起吃饭，先取得咲季许可（0019 制作人）
- 『とある友達』：擅长凛然表情，教了她诀窍（0011、0012）
- 咲季：制作人带她吃饭要先取得咲季的许可（0019 制作人）

## 档案类事实
- CM 里的“小恶魔的色气”其实是饿肚子的表情，她拍摄前没吃饭（0016、0018）
- 制作人带她去吃饭要先取得咲季许可（0019 制作人）

## 不确定
- 0011『とある友達』是谁剧本没写名字。
- 0019 制作人「もちろん咲季さんに許可を取って。」——为什么吃饭要咲季许可（是不是咲季管她的饮食），剧本没写；亲爱度 021 说姐姐不在时由母亲和工作人员照顾她的饮食，本篇和那边的关系看不出。
- 0021～0028 制作人改变了对“理想的花海佑芽”的看法；与亲爱度 010 的“常胜不败的顶级偶像”是什么关系，本篇没提。
