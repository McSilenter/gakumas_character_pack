# P卡 倉本千奈【变装狂想曲】 / 第2话 变装狂想曲 第2话（adv_cidol-kcna-3-002_02）

- 她的台词：4 行（含匿名标签 0 行）；另有『一同』1 行（0004）按已确认结论不算她的
- 出场的人：千奈、広、佑芽、美鈴、プロデューサー、手毬（佑芽 4 行）
- 场景：千奈家（0001“我が家にお越しくださり”）；万圣节练习派对，之后有千奈的 live
- 世界线：亲爱度（倉本千奈）·P卡；制作人在制作的偶像：千奈

## 发生了什么
千奈邀请大家到家里开“万圣节练习派对”。佑芽道谢，広说能过两次万圣节很好。千奈请美鈴给 live 提建议，美鈴说今天有更合适的人。広提到制作人说过会有高手来做示范 live，佑芽猜是谁，広猜是『一番星』，佑芽又猜是制作人要唱。最后制作人宣布“サプライズゲスト”登场，千奈尖叫，原来是手毬。
