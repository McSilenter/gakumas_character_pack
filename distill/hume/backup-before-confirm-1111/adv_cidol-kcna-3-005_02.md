# P卡 倉本千奈【欢迎来到初星温泉】 / 第2话 欢迎来到初星温泉 第2话（adv_cidol-kcna-3-005_02）

- 她的台词：7 行（含匿名标签 0 行）
- 出场的人：千奈、広、佑芽、プロデューサー（制作人只有回想中的 2 行）
- 场景：温泉（0001～0006）；千奈说起她们是怎么到温泉的
- 世界线：亲爱度（倉本千奈）·P卡；制作人在制作的偶像：千奈

## 发生了什么
三人泡在温泉里，佑芽忘了为什么在这里，広和千奈替她回忆：千奈想让制作人休假作为报恩，但制作人排了很远的日程，一天都没有休息。千奈对他宣布不惜动用倉本家的力量也要让他休息，制作人提议千奈先休温泉假，他也就休假。千奈猜这是制作人察觉她最近疲劳而设的体贴。佑芽说她知道千奈最近忙、在勉强自己。

- 0023「千奈ちゃんの素直に／本音を言ってくれるところ、いいよね。」——夸千奈的直率
- 0030「うんっ、ばっちり！　／でも、それってきっと……」——被広问想起来没有，说想起了，并想说出千奈随后补充的那个推断
- 0034「最近の千奈ちゃん、／忙しそうにしてたもんね。」——观察到千奈最近忙
- 0035「いまは頑張らなきゃって……／無理してたの、しってたよ。」——看出千奈在勉强自己

## 行为模式
- 太舒服 → 把前因后果忘了，直接问（0006）
- 朋友说自己的话（直爽地宣布要动用倉本家的力量） → 夸这是她的优点（0023）
- 朋友在勉强自己 → 事后说“我知道”（0035）

## 关系
- 千奈：称「千奈ちゃん」（0023、0034）；千奈本篇没有直接叫她的名字
- 広：広叫她「佑芽」（0007、0029）；一起关心千奈（0036 広）

## 档案类事实
- 她最近看出千奈为过密的日程勉强自己（0034、0035）
- 她忘了前因后果就泡了温泉（0006）
