# S卡 3-0003【お姉ちゃんに任せなさい！】 / 第2话 久违的外出（adv_csprt-3-0003_02）

- 她的台词：11 行（含用匿名标签说的 0 行）
- 出场的人：佑芽（11 行）、咲季（9 行）
- 场景：学园外的街上（入学后第一次和咲季出来逛）
- 世界线：S卡【お姉ちゃんに任せなさい！】；制作人在制作的偶像：看不出

## 发生了什么
佑芽说和姐姐一起逛街好久不见了，咲季说入学后是第一次（0001、0002）。佑芽说“お姉ちゃんって、あんまり学園の外に出ないもんね”，问姐姐为什么今天要来（0003、0004）。咲季说想先掌握自己住的街上有什么（0005）。佑芽带路，猜姐姐会喜欢体育用品店，咲季说最好的都已经在用了（0007、0008）。佑芽联想到学园的训练设备和家里用的全都有，咲季说这是入学理由之一（0009～0011）。咲季很快把地理记住，佑芽急了，说这样“歩いてるだけでデートが終わっちゃう”（0012～0014）。最后咲季说想看衣服，让佑芽选可爱的衣服给她（0017～0020）。

## 她的关键台词
- 0001「へへー、お姉ちゃんと街に出るの、／なんだか久しぶりな気がするね。」——和姐姐一起出门觉得高兴
- 0003「お姉ちゃんって、あんまり／学園の外に出ないもんね……」——了解姐姐的习惯
- 0006「そういうことなら案内するよ！／どこに行きたい？」——马上主动带路
- 0010「よく考えると、色々揃ってるよね。／うちで使ってたやつ、全部あるもん。」——学园的训练设备和“うち”用的东西全都有
- 0013「はーい、お姉ちゃん。あたしは、／いま、とっても焦っていまーす。」——用举手发言的方式说自己很着急
- 0014「このままだとホントに／歩いてるだけでデートが終わっちゃう！」——姐姐只顾记路，她担心约会变成走路
- 0016「……お姉ちゃんの／彼氏になる人は大変だあ……」——对姐姐不懂约会感叹
- 0018「お姉ちゃんが女の子みたいなこと／言い出した！？」——被姐姐说想看衣服吃惊

## 行为模式
- 姐姐说想了解街道 → 马上带路，并猜姐姐喜欢的店（0006、0007）
- 姐姐的做法让约会变成走路 → 用半开玩笑的方式把着急说出来（0013、0014）
- 姐姐的行为反常（想看衣服） → 直接说“像女孩子”，不绕弯（0018）

## 关系
- 咲季：称「お姉ちゃん」；咲季说“住んでいる街に何があるのかくらい、把握しておこうと思って”（0005）、命令佑芽“お姉ちゃんに似合う／可愛い服を選びなさいっ！”（0019、0020）

## 档案类事实
- 入学之后，两人这是第一次一起去街上（咲季 0002）
- 咲季不常出学园（佑芽 0003）
- 佑芽对街比较熟，提出带路（0006）
- “学園のトレーニング設備は、うちで使ってたやつ、全部ある”（佑芽 0010）；咲季回答“それが／入学を決めた理由の1つよ”（咲季 0011）
- 咲季用的运动用品都是最好的（咲季 0008）

## 不确定
- 0010 的「うち」是指家里，剧本没写具体；与 3-0023_02 0008（咲季“うちにだって、ここまでの／トレーニング設備は揃ってないわ！”，大意是家里没有这么齐）说法有出入；两篇是不同的卡，不算冲突，只留记录。
- 咲季 0005 的“住んでいる街”：咲季所指是学园所在的街还是别的，本篇没说。
