# S卡 3-0004【ぐぬぬぬぬ…………！】 / 第3话 花海姐妹的假日（adv_csprt-3-0004_03）

- 出场的人：佑芽（11 行）、咲季（9 行）

## 发生了什么
咲季在休养日找到偷偷溜出来的佑芽（0001～0004）。佑芽解释自己体力过剩，想稍微训练一下（0005～0007）。咲季说“なにも違わない”（0008），佑芽道歉，请求在说教前先做拉伸（0009、0010）。咲季无奈，佑芽提议顺便做按摩，咲季同意（0011～0013）。做完后佑芽说舒服，谢谢姐姐，咲季说“你也提高了”（0014～0016）。佑芽说朋友会说她按摩“痛い”，咲季说“少しは痛いかもね。身体がかたいと特に”，要她以后继续练习能因人而异地做（0017～0019）。佑芽称咲季为“お姉ちゃん師匠”（0020）。

## 她的关键台词
- 0002「げげっ！？　お姉ちゃん！？／どうしてここにぃ！？」——被发现偷训练时的慌张
- 0006「あまりにも体力があり余ってて……／そわそわしてきちゃって！」——解释自己体力过剩
- 0007「ほんのチョッピリだけ、／トレーニングしようかな～って。」——把偷练说成“只一点点”
- 0010「お説教の前に……ストレッチだけ、／ストレッチだけやらせて。」——挨骂前先提出拉伸
- 0012「そうだっ。せっかくだから、ここで／マッサージもやっていこうよ。」——顺势提议按摩
- 0015「いつもありがとう、お姉ちゃん！」——按摩后道谢，说“いつも”
- 0017「本当！？　友達には、／痛いって言われちゃうんだけど……」——被夸后追问，并说出朋友的反应
- 0020「はいっ、お姉ちゃん師匠！　／あたし、がんばりまーっす！」——把姐姐叫“师匠”，决心练习

## 行为模式
- 休养日里忍不住训练，被发现 → 先承认、道歉，然后用“只做拉伸”换取缓冲（0005～0010）
- 被姐姐说教 → 转而提出两个人都能做的事（按摩）（0012）
- 被夸技术进步 → 先确认“真的？”，再说出朋友评价“痛い”（0017）
- 姐姐给出练习的建议 → 以“师匠”回应，干劲十足（0019、0020）

## 关系
- 咲季：称「お姉ちゃん」（0002）、「お姉ちゃん師匠」（0020）；咲季说“妹の行動くらい／お見通し”（咲季 0003）

## 档案类事实
- 佑芽在休养日也想训练，体力有余（0006、0007）
- 佑芽会做拉伸和按摩，和咲季互相做（0010、0012）；朋友说过她的按摩“痛い”（0017）
- 咲季说“あなたも腕を上げたわね”（咲季 0016），“身体がかたいと特に”痛（咲季 0018）

## 不确定
- 0014、0015 按摩时谁给谁做：0014「きっもちよかったぁ～！」＋0015「いつもありがとう、お姉ちゃん！」，像是咲季给她按；咲季 0016 的“あなたも腕を上げたわね”像是佑芽也给咲季按过。剧本没写动作，只是推测，不下结论。
- 0017「友達には、／痛いって言われちゃうんだけど……」是指她给朋友按摩，朋友没有具体指名。
