# S卡 3-0023【まだ上がりませんように！】 / 第1话 在雨停之前（adv_csprt-3-0023_01）

- 她的台词：9 行（含用匿名标签说的 0 行）
- 出场的人：咲季（11 行）、佑芽（9 行）
- 场景：下雨的室外，两人合撑一把伞；时间看不出
- 世界线：S卡【まだ上がりませんように！】；制作人在制作的偶像：看不出

## 发生了什么
下雨了，佑芽发现下雨了，咲季问她有没有带伞，佑芽说没带（0001～0003）。咲季让两人撑一把伞，佑芽道谢（0004、0005）。佑芽说相合伞好久不见（0007），咲季说这种机会不多（0008、0009）。佑芽说有恋人的朋友从小学起就常这样（0010），咲季说那与她们无缘，当了偶像没空恋爱（0011、0012）。佑芽提议今天她来当姐姐的男朋友（0013），咲季说角色分配反了，该她来当佑芽的男朋友（0014～0016）。佑芽说“那就这样”，然后催快走，“雨が上がっちゃう前にっ♪”（0019、0020）。

## 她的关键台词
- 0003「……持ってきてない。」——被问有没有带伞，老实说没带
- 0005「さっすがお姉ちゃん！　／いつもありがとう～！」——姐姐提出共伞，马上道谢，说“いつも”
- 0010「そうかも。恋人がいる友達は、／小学生の頃からよくしてたけど……」——相合伞的经验是从有恋人的朋友那里知道的
- 0013「じゃあ～、今日はあたしが、／お姉ちゃんの彼氏役をやってあげよ～♪」——想出“当姐姐的男朋友”的玩笑
- 0017「え～？　あたしが、／傘を持って彼氏役をするよ～。」——姐姐要抢角色，她先不让
- 0019「そこまで言うなら……／それでいいよ。」——姐姐坚持，她让步
- 0020「あっそれよりほら、早く行こう！／――雨が上がっちゃう前にっ♪」——说要趁雨没停赶紧走

## 行为模式
- 忘带伞 → 老实说“没带”，接受姐姐的帮助并道谢（0003、0005）
- 突然想到好玩的点子 → 马上说出口（“当男朋友”），被反对就争一下，姐姐坚持就让步（0013、0017、0019）
- 事情定下后 → 转到下一个行动（早点出发），并表达想趁雨还没停（0020）

## 关系
- 咲季：称「お姉ちゃん」（0005）；咲季回应“当然よっ、このくらい！”（咲季 0006），要当佑芽的“彼氏”（咲季 0018）

## 档案类事实
- 佑芽说“恋人がいる友達は、小学生の頃からよくしてた”（0010）
- 咲季说“アイドルになったら、恋なんてしている暇ない”（咲季 0012），佑芽没有对这句话表态
- 佑芽没带伞（0003）；咲季看过天气预报（咲季 0002）

## 不确定
- 0013～0020 的“彼氏役”是姐妹间的玩笑/扮演，不是本人真话。
- 0020 她说“雨が上がっちゃう前にっ”，是希望趁雨没停快走（标题是“まだ上がりませんように！”），原文没有解释理由。
