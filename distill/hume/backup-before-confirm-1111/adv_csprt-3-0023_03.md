# S卡 3-0023【まだ上がりませんように！】 / 第3话 如果我们互换身份（adv_csprt-3-0023_03）

- 她的台词：10 行（含用匿名标签说的 0 行）
- 出场的人：咲季（10 行）、佑芽（10 行）
- 场景：大雨的日子，咲季让她在房间休息（咲季 0004），具体地点看不出
- 世界线：S卡【まだ上がりませんように！】；制作人在制作的偶像：看不出

## 发生了什么
咲季让佑芽别闹别扭（0001），佑芽说本来约好了两人去买东西（0002）。咲季说大雨太危险，让她在房间好好休息（0003、0004）。佑芽失望，说本来期待和姐姐一起选衣服（0005）。咲季说她成为偶像后变得会打扮了，之前对衣服没兴趣（0006、0008），佑芽说也许是朋友的影响，大家都很可爱（0009）。咲季说“あなたも可愛いわよ。わたしの妹だもん。”（0010）。佑芽说最近偶尔想和姐姐互换身体，穿上比自己更适合的可爱衣服，自拍很多（0011～0015）。咲季说如果真发生就用佑芽的身体拍大胆的泳装照（0018、0019），佑芽喊“えっちぃ”（0020）。

## 她的关键台词
- 0002「だって……せっかくふたりで／買い物に行くって約束したのに。」——因为约好的外出被取消而闹别扭
- 0005「はぁ～い。ちぇ～、お姉ちゃんと／服選ぶの楽しみにしてたのにな。」——听话但嘟囔
- 0009「……そうかも。友達の影響かなー。／みんな可愛い子ばっかり。」——承认自己变得会打扮，归因于朋友
- 0012「お姉ちゃんと身体が／入れ替わったらなぁ――って。」——最近偶尔想和姐姐互换身体
- 0014「お姉ちゃんの身体で、あたしよりも／ずーっと似合う可愛い服を着て、」——换身体的理由：姐姐的身体更适合可爱的衣服
- 0015「たくさん自撮りしたい♪」——想多自拍

## 行为模式
- 约好的事被取消 → 闹别扭，说出期待，但接受理由，说“はぁ～い”（0002、0005）
- 被说变得会打扮 → 先不好意思（0007），然后承认并归因于朋友（0009）
- 被姐姐夸可爱 → 道谢，然后说出平时藏着的小想法（0011、0012）

## 关系
- 咲季：称「お姉ちゃん」（0005、0012、0014）；咲季说“あなたも可愛いわよ。わたしの妹だもん。”（咲季 0010）
- 朋友们：佑芽认为“みんな可愛い子ばっかり”（0009）

## 档案类事实
- 佑芽成为偶像后变得会打扮：咲季说“前は服なんて、興味なかった”（咲季 0008），佑芽同意“……そうかも”（0009）
- 佑芽觉得自己的朋友“みんな可愛い子ばっかり”（0009）
- 佑芽想过和姐姐身体互换，以便在姐姐的身体上穿可爱的衣服自拍（0012～0015）；这是她的“想象/愿望”，不是真发生的事

## 不确定
- 0012～0015 的“身体互换”是想象；咲季 0018、0019 的回答也是假设，不是现实。
- 0014「あたしよりも／ずーっと似合う」所指的“身体”是姐姐的，意思是姐姐的身体更适合可爱衣服；原文没有解释“似合う”的标准。
