# S卡 3-0032【プロデュースって大変ね】 / 第2话 可靠前辈的烦恼（adv_csprt-3-0032_02）

- 她的台词：7 行（含用匿名标签说的 0 行）
- 出场的人：星南（12，其中 0009、0010、0013 是内心独白）、佑芽（7）、咲季（1）
- 场景：早晨，星南看佑芽的自主训练（跑步）；之后佑芽请星南示范今天课上要跳的舞（0016）
- 世界线：S卡【プロデュースって大変ね】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
星南说今早要看佑芽的自主训练（0001）。佑芽出发，发现星南也跟着跑，星南让她用平时的步速（0003、0004）。佑芽说对学园第一的偶像不会客气，速度很快，星南吃惊，用力撑着不露出疲态（星南 0006、0009、0010）。跑完后佑芽请星南示范今天课上要跳的舞（0014～0016），星南答应，咲季在后面说了一句“……ね？”，星南回答“ええ。”，感叹做佑芽“可靠的前辈”不容易（0018～0020）。

## 她的关键台词
- 0002「はい！　星南先輩！／じゃあさっそく、いってきまーす！」——被要求让人看自主训练，立刻出发
- 0005「はい！　学園一のアイドルに、／遠慮なんてしません！」——被说不用客气，就真的全力跑，还把星南称为“学園一のアイドル”
- 0007「星南先輩すごーい！　余裕そうですね！」——看不出星南已经撑不住，直接夸她
- 0011「これで朝のランニングは終わりです！」——报告结束
- 0014「えへへ……あの、星南先輩。／ダンスのお手本を見せてくれませんか？」——自己主动拜托前辈示范
- 0016「はいっ！　ぜひ！　今日のレッスンで、／踊らなくちゃいけなくて！」——说明请求的理由是当天课上要跳

## 行为模式
- 被说不用客气 → 照办，全力以赴（0005）
- 前辈看起来很轻松 → 当真，直接说“余裕そうですね”（0007）
- 刚跑完又有需要 → 马上向前辈提出请求（0014、0016）

## 关系
- 星南：叫“星南先輩”（0002、0003、0007、0014）；称她为“学園一のアイドル”（0005）；星南说佑芽是“元アスリート”（星南 0012）
- 咲季：本篇咲季只说了 0018 一句，佑芽没有直接回应

## 档案类事实

- 星南称她为“元アスリート”（星南 0012）
