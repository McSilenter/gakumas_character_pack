# S卡 3-0035【ゆっくりと過ごしましょう】 / 第1话 姐妹的阅读时光（adv_csprt-3-0035_01）

- 她的台词：9 行（含用匿名标签说的 0 行）
- 出场的人：咲季（10）、佑芽（9）

## 发生了什么
佑芽问咲季在读什么书，咲季说是营养学的书，因为给佑芽以外的人做饭的机会多了，在改进食谱（0002～0004）。佑芽说自己喜欢姐姐一直做的便当，并且答对了便当改进的地方是“歯ごたえ”（0005～0008）。佑芽向姐姐道谢，然后说自己在读朋友推荐的漫画，是恋爱喜剧，有点刺激的场面，读着心跳加速（0011～0016）。咲季说想读，佑芽叫她读，这样可以多聊（0017、0018），咲季说下个休养日读，佑芽说“约定だよ！”（0019、0020）。

## 她的关键台词
- 0002「ねぇ、お姉ちゃん、／なんの本を読んでるの～？」——主动问姐姐在读什么
- 0005「ふ～ん？　あたしはお姉ちゃんが作る／いつものお弁当が好きだな。」——喜欢姐姐一直做的便当
- 0007「歯ごたえでしょ？」——能答出便当的改进点
- 0011「お姉ちゃん、／いつも美味しい食事をありがとう。」——对姐姐做的饭直接道谢
- 0014「これ？　友達におすすめして／もらったマンガだよ。」——读的是朋友推荐的漫画
- 0016「読んでてドキドキするんだ。」——说自己的感受
- 0018「読んで読んで！　そしたら／もっと色々話せるし！」——想让姐姐读，好多聊
- 0020「約束だよ！」——确认约定

## 行为模式
- 想知道姐姐在做什么 → 直接问，并且知道姐姐的食谱改进方向（0002、0007）
- 看到姐姐有兴趣自己读的东西 → 推荐她读，理由是可以多聊（0018）
- 对方答应 → 确认“约定だよ！”（0020）

## 关系
- 咲季（姐姐）：叫“お姉ちゃん”（0002、0005、0011）；咲季叫她“佑芽”（咲季 0003）。咲季说“佑芽以外の子にも／食事を作る機会が増えてきた”（咲季 0003）。咲季说“あなたは？　なにを読んでいたの？”（咲季 0013）

## 档案类事实
- 喜欢姐姐做的便当（0005）；便当会不断改进，最近的是“歯ごたえ”，咲季说“あごと歯にもいい”（咲季 0010）
- 读朋友推荐的恋爱喜剧漫画（0014、0015）
- 和姐姐有休息日（咲季说“次の休養日”，咲季 0019）
