# S卡 3-0035【ゆっくりと過ごしましょう】 / 第2话 姐妹的学习时间（adv_csprt-3-0035_02）

- 她的台词：10 行（含用匿名标签说的 0 行）
- 出场的人：咲季（10）、佑芽（10）
- 场景：休息日的上午，佑芽去咲季那里（咲季 0002「あら、いらっしゃい。／ついさっきぶりね。」）；房间不明
- 世界线：S卡【ゆっくりと過ごしましょう】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
佑芽来找咲季，说今天两人都休息，想一起过（0004）。咲季说休息日上午她总是学习，佑芽答“勉強”，被说“さすがわたしの妹”，立即开始学习（0005～0011）。学习结束，佑芽道谢，说虽然不太喜欢学习，但成绩不好就不能做偶像（0012～0015）。咲季问她有没有想过将来，佑芽说“レッスンを頑張って、お姉ちゃんに勝つ！”，咲季说“させないわよ”，又问赢了之后呢，佑芽答“勝ってから考える！”（0016～0019）。

## 她的关键台词
- 0001「お姉ちゃーん、やっほー♪」——休息日主动来找姐姐
- 0004「今日はふたりともお休みだから、／一緒に過ごそうかなーって。……だめ？」——休息日想和姐姐一起过
- 0008「……べ、勉強…………」——知道姐姐休息日上午总是学习
- 0011「ええぇえぇ！？　／もう勉強はじまってるの～！？」——被突然拉进学习
- 0015「勉強はあんまり好きじゃないけど……／成績悪いとアイドル活動できないもん。」——不太喜欢学习，但为了偶像活动要学
- 0017「レッスンを頑張って、／お姉ちゃんに勝つ！」——被问将来时的回答
- 0019「勝ってから考える！」——被问赢了之后怎么办时的回答

## 行为模式
- 休息日 → 去姐姐那里，提出一起过（0004）
- 被拉去学习 → 惊叫，学完后道谢（0011、0013）
- 被问长远的将来 → 答的是眼前的目标，之后的事“勝ってから考える”（0017、0019）

## 关系
- 咲季（姐姐）：叫“お姉ちゃん”；咲季称自己为“あなたのお姉ちゃん”（咲季 0007），夸她“さすがわたしの妹ね。”（咲季 0009）
- 胜负方面原文：佑芽 0017「レッスンを頑張って、／お姉ちゃんに勝つ！」，咲季 0018「させないわよ。でも、もしも……／それが叶ったら？　その先は？」

## 档案类事实
- 休息日的上午姐姐总是学习（咲季 0007，佑芽 0008 答出）
- 勉强不太喜欢，但认为成绩差不能做偶像（0015）
- 目标：在练习中努力，赢姐姐（0017）；赢了之后的事还没考虑（0019）
