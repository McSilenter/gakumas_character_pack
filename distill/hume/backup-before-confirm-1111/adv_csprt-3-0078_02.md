# S卡 3-0078【レディ・セット、ゴー！】 / 第2话 喜欢的东西就是喜欢（adv_csprt-3-0078_02）

- 她的台词：11 行（含用匿名标签说的 0 行）
- 出场的人：佑芽（11）、麻央（9）
- 场景：图书室（麻央 0003「図書室では、お静かに。」）；时间看不出
- 世界线：S卡【レディ・セット、ゴー！】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
佑芽借了偶像基础方面的书，决定为了赢姐姐好好学习（0001、0002）。麻央提醒图书室要安静，说她在图书室很少见（0003、0005）。佑芽说，想赢姐姐，除了训练还要好好做偶像的学习（0006、0007）。她问麻央借了什么，麻央说是奇幻小说，她说知道，小学时姐姐常读给她听（0009～0011）。麻央说是小学生向的系列但从小喜欢，请她保密，说这样不帅（0012～0015）。佑芽说不会，说喜欢就说喜欢才帅，自己总说喜欢姐姐，也喜欢帅气的麻央先辈（0016～0020）。

## 她的关键台词
- 0001「『表現の基本』、『ポーズの基本』、／これだけ借りればいいかなぁ。」——借的书是偶像表现和姿势的基础
- 0002「よーっし、お姉ちゃんに勝つために、／いっぱい勉強するぞー。」——为了赢姐姐而学习
- 0006「はい。お姉ちゃんに勝つには、／トレーニングだけじゃなくて――」——麻央问为什么来图书室时的回答，前半
- 0007「しっかりアイドルの勉強も／しなくちゃって。」——承接 0006
- 0011「あ、これ知ってます！／小学校の頃、お姉ちゃんが、／よく読んでくれました。」——看到麻央的奇幻小说，想起姐姐小学时常读给她听
- 0017「好きなものは好きって言ったほうが、／ぜったいカッコイイと思います。」——对“喜欢小学生向的书不帅”的反驳
- 0019「あたしは、お姉ちゃんのこと、／いつも大好きって言ってますし。」——举自己作例子
- 0020「カッコイイ麻央先輩のことも、／大好きですよっ。」——直接说喜欢麻央

## 行为模式
- 为了赢 → 把训练之外的学习也算进去（0006、0007）
- 听到别人觉得“喜欢这个不帅” → 立刻反驳，并拿自己做例子（0016、0017、0019）
- 对前辈 → 直接说“大好き”（0020）

## 关系
- 麻央：叫“麻央先輩”（0004、0009、0020）；麻央叫她“佑芽”（麻央 0005）；麻央请她保密（麻央 0014）
- 咲季（姐姐）：0002「お姉ちゃんに勝つために」；0006「お姉ちゃんに勝つには」；0011「小学校の頃、お姉ちゃんが、／よく読んでくれました。」；0019「あたしは、お姉ちゃんのこと、／いつも大好きって言ってますし。」

## 档案类事实
- 在图书室借偶像基础的书学习（0001、0007）；麻央说她在图书室很少见（麻央 0005）
- 小学时姐姐常读奇幻小说给她听（0011）
- 她“いつも大好きって言ってます”对姐姐（0019）
