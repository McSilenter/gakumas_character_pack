# S卡 3-0081【メリクリ、おねーちゃん♪】 / 第2话 姐姐圣诞老人！登场！（adv_csprt-3-0081_02）

- 她的台词：10 行（含用匿名标签说的 0 行）
- 出场的人：咲季（10，扮演圣诞老人）、佑芽（10）
- 场景：圣诞节，咲季扮成“お姉ちゃんサンタ”送礼物（咲季 0001），地点没写；今年“今年も”（咲季 0003）
- 世界线：S卡【メリクリ、おねーちゃん♪】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
咲季扮成“お姉ちゃんサンタ”登场，佑芽欢迎（咲季 0001、0002）。咲季说今年也给佑芽准备了很多礼物：小型最新健身器材、护肤品、减少家务的便利用品（咲季 0003～0006）。佑芽高兴，咲季说连一半都没介绍，佑芽吃惊（0007～0009）。今年的主礼物是手编围巾，佑芽很高兴，说每年都期待姐姐手编的礼物（咲季 0011、0012、0013）。咲季说开始手编时还小，也送过织得不好的，佑芽说以前的礼物她也喜欢，礼物里满是姐姐的爱，让她身心一直温暖（0014～0018）。她说自己也准备了礼物（0020）。

## 她的关键台词
- 0002「来たなぁ～～～～～！／お姉ちゃんサンタ、いらっしゃい！」——迎接扮圣诞老人的姐姐
- 0007「本当にプレゼント、たくさんだぁ～！／ありがとっ、お姉ちゃんっ！」——礼物很多，直接道谢
- 0009「えぇぇ！？　そんなにあるんだ！？」——听到还有一半以上，惊讶
- 0012「わぁ～～！　お姉ちゃんの手編み！」——看到手编围巾
- 0013「毎年、手編みで作ってくれるの／いっつも楽しみにしてるんだ！」——每年都期待
- 0016「あたしは昔のプレゼントも／好きだけどな～！」——不觉得以前织得差的礼物不好
- 0017「どのプレゼントにも、お姉ちゃんの／愛情がたっぷり入ってて……」——礼物里有姐姐的爱
- 0018「そのおかげで、体も心も、／昔からずぅっとあたたかい。」——一直被温暖
- 0020「あたしもプレゼント考えてるから、／楽しみに待っててね！」——自己也在准备回礼

## 行为模式
- 收到礼物 → 直接道谢，并说出具体的感受（0007、0017、0018）
- 姐姐为旧礼物反省 → 反过来说旧礼物也喜欢（0016）
- 收礼后 → 马上说自己也有准备（0020）

## 关系
- 咲季（姐姐）：叫“お姉ちゃん”（0007、0012）；咲季 0001「お姉ちゃんサンタが／やってきたわよ！！！」；咲季 0014「手編みを始めたころは／まだ小さかったから……」，0015「いま思うと、へたくそなものを／渡したこともあったわね。反省だわ。」

## 档案类事实
- 每年从姐姐那里收到手编的礼物（0013）；咲季说“今年も”送礼物（咲季 0003）
- 以前姐姐织得不好的礼物，她也喜欢（0016）

## 不确定
- 咲季扮成圣诞老人（咲季 0001），她的台词是扮演中的话；佑芽的台词不是扮演（她配合叫“お姉ちゃんサンタ”，0002）。
- 咲季 0014 “手編みを始めたころ”具体是什么时候没有写。
- 【冲突】无。
