# S卡 3-0081【メリクリ、おねーちゃん♪】 / 第3话 来自目标的礼物（adv_csprt-3-0081_03）

- 她的台词：10 行（含用匿名标签说的 0 行）
- 出场的人：咲季（10）、佑芽（10）
- 场景：街上买完东西后，在路边的街头大屏幕前看星南的圣诞节直播；时间点是圣诞节前后
- 世界线：S卡【メリクリ、おねーちゃん♪】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
咲季说寄给老家的圣诞礼物都买齐了，佑芽说再加上咲季的限定周边就完美了，咲季说自己也准备了很多佑芽的周边（咲季 0001、0002～0004）。佑芽说宿舍的大家托她给爷爷们带话，是对分送的蔬菜的谢意，也一起寄（0005、0006）。她们看到街头大屏幕在转播星南的圣诞节演唱会，佑芽叫姐姐一起看，咲季说能在这里看到会长的演唱会很幸运（0008～0011）。看完后佑芽说太棒了，咲季说有很多值得学习的地方，作为粉丝和对手都是（0012～0014）。佑芽说“燃えるよね！”，最后说这是“一番星”送的圣诞礼物（0015～0020）。

## 她的关键台词
- 0002「うん！　あとはお姉ちゃんの限定／ファングッズを一緒に送れば、完璧！」——寄给老家的礼物里要加上姐姐的限定周边
- 0005「そだ、寮のみんなから、／お爺ちゃんたちへの／メッセージもあずかってたんだ！」——帮寮里的人给爷爷们带话
- 0006「おすそわけした野菜のお礼だって！／それもおくっちゃお～！」——是对分送的蔬菜的谢意
- 0009「星南先輩のクリスマスライブが／中継されてるっ！！」——发现大屏幕上是星南的圣诞节演唱会
- 0010「観ていこーよっ！／お姉ちゃんっ！」——叫姐姐一起看
- 0012「すっごかったあああ～～～！！！」——看完后的感想
- 0015「燃えるよね！」——对咲季“作为粉丝也作为对手”的回应
- 0018「お姉ちゃん。／星南先輩の今日のライブ！」——开头，引出最后的总结（咲季 0019 接）

## 行为模式
- 给老家寄东西 → 想到加上姐姐的周边（0002），并替寮里的人带话（0005、0006）
- 看到想看的 → 马上拉着姐姐去看（0008～0010）
- 看完强力表演 → 感叹后“燃えるよね！”，把它变成斗志（0012、0015）

## 关系
- 咲季（姐姐）：叫“お姉ちゃん”（0002、0010、0018）；咲季 0004「わたしも佑芽のグッズを／大量に用意しているわ！」；咲季 0001「実家に送るクリスマスプレゼントは／これでぜんぶ買えたわね。」
- 星南：叫“星南先輩”（0009、0018）；咲季叫她“会長”（咲季 0011）

## 档案类事实
- 给老家寄圣诞礼物（咲季 0001）；她在寮，宿舍的人收到过她们分送的蔬菜（0005、0006）
- 老家有“お爺ちゃんたち”（0005）
- 咲季有限定周边（0002 “お姉ちゃんの限定ファングッズ”）

## 不确定
