# S卡 3-0095【パーティー楽しみだねっ！】 / 第1话 同款环保购物袋（adv_csprt-3-0095_01）

- 她的台词：8 行（含用匿名标签说的 0 行）
- 出场的人：千奈、佑芽、美鈴
- 场景：去超市的路上（0019 “そろそろ着きますよ”）；时间看不出
- 世界线：S卡【パーティー楽しみだねっ！】；制作人在制作的偶像：看不出

## 发生了什么
千奈很期待去超市买东西（0001、0003）。佑芽想到文化祭买东西时千奈也带了环保袋（0007）。美鈴说她也带，因为常与“まりちゃん”去买东西（0012）。佑芽说姐姐有环保袋，自己没有（0013）。美鈴说今天可以看看（0014）。千奈提议给篠澤同学一起买同款，四个人一样（0016），佑芽赞成（0017）。

## 她的关键台词
- 0002「千奈ちゃん、楽しそうだね！」——看到千奈高兴，直接说出来
- 0007「そーいえば、文化祭の買い物のときも／エコバッグ持って行ってたよね？」——记得上次文化祭买东西时千奈带了环保袋
- 0009「エコバッグって、色んな種類が／あって面白いよね。」——觉得环保袋种类多很有趣
- 0013「いいな～！　お姉ちゃんはあるけど、／あたし持ってないんだよね～。」——说姐姐有环保袋，而自己没有
- 0017「いいね！　さんせー！」——马上赞成四人同款的提议
- 0020「よーし！　はりきって買い物行くぞ～！」——为买东西打气

## 行为模式
- 朋友提议大家买同款 → 立刻赞成（0017）
- 发现别人有、自己没有的东西 → 羡慕地说出来（0013）

## 关系
- 千奈：她叫「千奈ちゃん」（0002）
- 美鈴：她叫「美鈴ちゃん」（0011）；美鈴称“まりちゃん”（美鈴 0012），不是佑芽的话
