# 有村麻央 亲爱度剧情 / 第31话（adv_dear_amao_031）

- 她的台词：14 行（含匿名标签 0 行）
- 出场的人：麻央、佑芽、咲季（佑芽只在前半 0001～0019）
- 场景：前半是早晨跑步（0030 咲季“今朝、佑芽と走ってきた”、0031 麻央“早朝レッスン”）；后半是做『H.I.F』决起会的料理（0021～0024，用花海ファーム的蔬菜做“花海家特製スープ”），佑芽不在
- 世界线：亲爱度（有村麻央）；制作人在制作的偶像：麻央（本篇没有制作人出场）

## 发生了什么
麻央和佑芽一起跑完步，麻央累了，说自己体力不错但比不过佑芽。佑芽说自己喜欢跑步，小时候每天和姐姐在乡下的路上跑，姐姐一直跑在前面，摔倒时姐姐会立刻拉她。她说小时候只吵过架，因为什么都用比赛分胜负；追着姐姐的背影，好不容易并肩，姐姐又改了跑姿变得更快。麻央问现在是不是咲季更快，她说“たぶん？”，最近忙于课程没跑了，现在有比赛跑更投入的事——冬天的『H.I.F』，喊要优胜。之后场景转到咲季和麻央做料理（佑芽不在，不记）。

## 她的关键台词
- 0001「うおりゃああああああ！」——跑步时的吼声
- 0004「あたし、走るの好きなんです。」——开口介绍自己
- 0005「子供の頃は、お姉ちゃんと毎日、／田舎の道を走ってて。」——小时候和姐姐每天跑步
- 0006「お姉ちゃんはずっと、／あたしの前を走ってくれて――」——姐姐跑在前面
- 0007「でも、あたしが転んだときは、／すぐに手をとってくれる。」——摔倒时姐姐马上拉她
- 0011「なんでも勝負で決着つけちゃうので。」——吵架只在小时候，因为什么都用比赛分胜负
- 0012「ずっと、お姉ちゃんの背中を、／追いかけて――」——一直追着姐姐
- 0013「やっと並んで走れたーって思ったら、／フォームを変えて、また速くなって。」——刚并肩，姐姐就改变跑姿再次变快
- 0014「おかげで、あたしもどんどん、／速くなっちゃいましたけど。」——并不抱怨，反而说自己因此变快
- 0016「……うーん。たぶん？」——被问现在是否咲季更快，不确定
- 0018「――でも。今は駆けっこよりもっと、／夢中になれることがあるんです。」——现在更投入的是偶像
- 0019「冬の『H.I.F』、優勝するぞー！」——目标

## 行为模式
- 被说“比不过你” → 不谦逊也不骄傲，转头讲自己为什么喜欢跑步（0003、0004）
- 提到姐姐 → 总是同时说“她在前面”“拉我起来”“我追着她”，并没有怨言（0005～0007、0012～0014）
- 被问是否还输姐姐 → 先“うーん”，回答“たぶん？”，不下断言（0016）
- 说到现在的目标 → 转为大声宣布（0018、0019）

## 关系
- 麻央：本篇没有直接叫麻央；对麻央用丁寧体（0004 的“～です”）；麻央叫她「佑芽」（0003、0008），回“ボクも負けないよ。”（0020）
- 咲季：称「お姉ちゃん」（0005、0006、0007、0012）；本篇咲季出场时佑芽不在

## 档案类事实
- 喜欢跑步（0004）
- 小时候和姐姐每天在“田舎の道”跑步（0005）；姐姐跑在前面，摔倒时姐姐马上拉她（0006、0007）
- 喧嘩只在小时候，因为“なんでも勝負で決着つけちゃう”（0010、0011）
- 一直追着姐姐的背影；刚追上姐姐就“フォームを変えて、また速くなって”（0012、0013）；因此自己也变快（0014）
- 现在是否仍是咲季更快：她说“たぶん？”（0016）；最近因为课程忙，不跑“駆けっこ”了（0017）
- 目标是冬天的『H.I.F』优胜（0019）
- 咲季和麻央（0022、0023）：花海家特製スープ，用“花海ファーム”的蔬菜；这是咲季和麻央的话，不是她的
