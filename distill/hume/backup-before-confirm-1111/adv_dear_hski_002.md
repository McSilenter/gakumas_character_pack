# 花海咲季 亲爱度剧情 / 第2话（adv_dear_hski_002）

- 她的台词：7 行（含匿名标签 0 行）
- 出场的人：咲季、佑芽、プロデューサー（佑芽 7 行）
- 场景：レッスン室（咲季 0010“今日からレッスン室を／借りられるというから”）；入学后不久，咲季是 1 年生（制作人 0023“咲季さん以上の／1年生”）
- 世界线：亲爱度（花海咲季）；制作人在制作的偶像：咲季

## 发生了什么
咲季和佑芽在レッスン室做比赛，咲季赢，佑芽大喊不甘心。制作人出现，咲季让他叫自己“咲季”，因为姐妹同姓。佑芽向制作人宣战，说自己总有一天会赢，连制作人也不放过。制作人心里把佑芽记为“最大的ライバル”。咲季说佑芽是“最高の妹”，会很快追上来，对制作人承认“このままだと負ける”。

## 她的关键台词
- 0002「うぅ～～～、今日も負けたぁ！／悔しい～～～～～～～～ッ！」——被打败后的反应，直说悔
- 0011「さっそく勝負してたんですよ、／プロデューサーさん！」——对制作人解释她们在做什么
- 0013「ぐぬぬぅ～、お姉ちゃんめぇ。／勝ち誇りやがってぇ～～～！」——姐姐得意时的抱怨
- 0016「確かにいまのあたしじゃ、／お姉ちゃんには敵わないけどっ！」——承认现在比不过
- 0017「そのうち／ぜぇったい勝ってやるんだからぁ！」——宣战
- 0018「プロデューサーさんもですからねっ！／首を洗って待っててください！」——连姐姐的制作人也一并当对手
- 0019「覚えてろぉ～～～～～～～～！」——退场台词

## 行为模式
- 输了 → 当场大喊“悔しい”，对姐姐抱怨，但马上转为“以后一定赢”（0002、0013、0016、0017）
- 向第三者说明情况 → 称“勝負していた”，不隐瞒输（0011）
- 向对手阵营宣战 → 连姐姐的制作人也一起宣战（0018）

## 关系
- 咲季：称「お姉ちゃん」（0013、0016）；咲季叫她「佑芽」（0001），说“最高の妹よ”（0021）
- プロデューサー：称「プロデューサーさん」（0011、0018）；制作人称她「花海佑芽さん」（0006），心里记她为咲季“最大のライバル”（0014、0015）；她的制作人不是他
