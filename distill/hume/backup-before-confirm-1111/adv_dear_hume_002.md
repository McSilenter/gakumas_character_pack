# 花海佑芽 亲爱度剧情 / 第2话（adv_dear_hume_002）

- 她的台词：25 行（含匿名标签 0 行）
- 出场的人：プロデューサー、佑芽、咲季
- 场景：学园内，制作人带佑芽去作为“事务所”的活动据点教室（0001～0010）；时间在第 1 话认识后不久（0042 咲季「佑芽とは出会ったばかり」）
- 世界线：亲爱度（花海佑芽）；制作人在制作的偶像：佑芽（0019 咲季「あなたが佑芽のプロデューサーね！」）

## 发生了什么
制作人带佑芽去事务所，她不知道“事务所”是什么，坦言不了解偶像。正要开始时姐姐咲季闯进来，说不认可制作人制作佑芽，要“考验”制作人；佑芽一开始抗议姐姐过度保护，被姐姐一句“你不相信自己选的制作人吗？”就说服了。制作人拿出给佑芽的计划资料，咲季发现那是自家父母用的格式；原来制作人通过父母的官方网站预约，当天就去愛知见了她们的父母。佑芽非常感动，向姐姐炫耀“这就是我的制作人”，咲季撤退。最后佑芽说姐姐是她绝对想赢的人、宿敌，也是最棒的姐姐。

## 行为模式
- 被问到不懂的概念 → 不装懂，笑着道歉说不了解（0003、0005）
- 被姐姐激将（“你不信任自己选的人吗？”）→ 立刻上钩，从抗议转为同意（0031、0033、0035）
- 有人为自己付出努力 → 全身心地感动、道谢，并拿去向姐姐炫耀（0062～0065）
- 姐姐吃瘪退场 → 做鬼脸、大笑，说“我们把姐姐击退了”，把制作人当同伙（0068～0070）
- 说到姐姐 → 竞争对手和敬爱的姐姐两种感情同时说出（0073、0074）
- 对制作人用敬语，对姐姐用常体（0031、0064）

## 关系
- 咲季：称「お姉ちゃん」（0015）；咲季叫她「佑芽」（0032），说她是「わたしの大切な妹」（0030）。佑芽嫌姐姐过度保护（0031），但很容易被姐姐说服（0033～0035）；最后说姐姐是宿敌也是最好的姐姐（0073、0074）
- 制作人：称「プロデューサーさん」，用敬语；把制作人当成“我的制作人”向姐姐炫耀（0031、0065）；制作人叫她「佑芽さん」（0020）
- 父母：称「お父さん」「お母さん」（0057）

## 档案类事实
- 父母在愛知（制作人去愛知见了父母，0060）
- 父母有“官方网站”，制作人通过网站预约了面谈（0058、0059 制作人台词）
- 制作人说佑芽是「元アスリート」（0047 制作人台词）
- 父母有自己在用的计划资料格式（0053 咲季、0054 制作人）
- 不了解偶像、不知道“事务所”是什么（0003、0005）

## 不确定
- 关于父母：本篇只看得出父母在愛知（0060）、有官方网站（0058）、有固定的资料格式（0053）。父母的职业本篇没说；母亲是否是“駆け出しアイドルトレーナー”、父母是否几乎不回家，本篇都没有提到。0060 原文「あのすぐ後に、／わざわざ愛知まで行ったんですか！？」。
- 关于住处：父母在愛知、姐妹在初星学园，本篇没有说她们住宿舍还是别处。
- 0021「えへへ～っ、／たくさん自慢しちゃいました！」只说对姐姐炫耀过制作人，什么时候说的没写。
