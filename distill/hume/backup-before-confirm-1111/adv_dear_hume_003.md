# 花海佑芽 亲爱度剧情 / 第3话（adv_dear_hume_003）

- 她的台词：36 行（含匿名标签 0 行）
- 出场的人：佑芽、プロデューサー、咲季
- 场景：レッスン室，「今日から」可以借用的第一天（0005），姐妹刚比完
- 世界线：亲爱度（花海佑芽）；制作人在制作的偶像：佑芽

## 发生了什么
姐妹拿到レッスン室后马上比试，佑芽又输了，大喊不甘心。咲季追问计划资料，制作人说把和训练师做的计划书给父母看后，父母当场为女儿的培养方针激烈争论，佑芽说不在场也能看到父母吵架的画面。咲季要求制作人全力锻炼佑芽，否则不配当她的对手。姐姐走后，佑芽向制作人道歉“输了”，又问制作人调查了自己和姐姐后，会不会后悔、觉得姐姐更好。制作人说不后悔，她有不输姐姐的巨大潜力，最大的才能是“作为偶像拥有最高数值的肉体”（她先误会成色色的意思）。她承认自己练习时总被骂，听到“慢热、学得极慢”是父母说的，断定一定是爸爸说的。最后她说现在的自己远不及姐姐、可能没胜算，但已经相信制作人，要一起从最底层冲上去打倒最强的偶像。

## 她的关键台词
- 0001「うぅ～～～、今日も負けたぁ！／悔しい～～～～～～～～ッ！」——“今天也输了”，输给姐姐是日常
- 0009「そのうち絶対追いついて、／あたしが勝つんだからぁ！」——输了马上发誓要赢
- 0019「うわ……現場にいなくても夫婦喧嘩の／光景が見える見える……」——父母会为女儿的培养方针吵架，她很熟悉
- 0029「ごめんなさい……あたし……／負けちゃって。」——输了会向制作人道歉
- 0038「お姉ちゃんの方がよかった、って。」——对“被拿来和姐姐比”的不安
- 0050「え、えっちですよ！　／プロデューサーさん！？」——误会“肉体”的说法，慌张吐槽
- 0055「えへへ……たくさん鍛えましたから！／でも、レッスンでは怒られてばかりで。」——身体是练出来的，但练习总挨骂
- 0058「ぐぬぬ……／それ言ったの、絶対お父さんですね！」——认定说她坏话的是爸爸
- 0063「いまのあたしは……／お姉ちゃんの足元にも及びません。」——对和姐姐差距的认识
- 0069「補欠入学の劣等生に……」——自称“补欠入学的劣等生”
- 0072「そんな人、絶対他にはいません。／プロデューサーさんだけです。」——对制作人的信任
- 0074「一番下から大急ぎで駆け上って、／最強のアイドルをぶっとばすんです！」——要从最底层冲上去
- 0075「そしたらきっと――／人生最高にすかっとしますよ！」——对胜利的想象：人生最爽快

## 行为模式
- 输给姐姐 → 大声表达不甘心（「悔しい～」「ぐぬぬぅ～」），说粗一点的话（「勝ち誇りやがってぇ」），马上宣言下次要赢（0001、0008、0009）
- 被姐姐顺着鼓励 → 说不出话，只「むぅぅ……」（0010、0011）
- 输了之后单独面对制作人 → 道歉，并担心制作人会不会觉得“姐姐更好”（0029、0036～0038）
- 被说出不太好听的表达 → 字面理解、慌张误会，之后硬说「モチロンわかってましたよ」（0050、0052、0061）
- 被夸身体能力 → 害羞地说“因为锻炼了很多”，同时坦白练习总挨骂（0055）
- 被真诚信任 → 认真表白自己的劣势，然后转为非常高昂的“一起打倒姐姐”（0063～0075）

## 关系
- 咲季：称「お姉ちゃん」；姐姐总赢、得意（0007、0008），佑芽对她又不服又被她压住；把打倒姐姐当共同目标（0073）
- 制作人：称「プロデューサーさん」；从“会不会后悔选我”的不安转为「もう、とっくに信じてますよ。」（0068）的信任
- 父母：会因女儿的培养方针吵架（0018、0019）；她认为说她“慢热、学得慢”的是爸爸（0058）

## 档案类事实
- 入学后和姐姐在レッスン室比试，“今天也输了”（0001、0006）
- 制作人说父母是「元プロアスリート」（0021 制作人台词）
- 父母会就女儿的培养方针激烈争论（0018 制作人、0019 佑芽）；咲季说父母是「親ばか」（0020）
- 父母说她是スロースターター、学东西极慢（0056、0057 制作人台词）；她认为是爸爸说的（0058）
- 身体能力：制作人说她体力无穷、柔软性无比、肌肉强韧、肺活量巨大（0051 制作人台词）；她说是自己锻炼出来的（0055）
- 练习时总被骂（0055）
- 自称补欠入学的劣等生（0069）

## 不确定
- 0001「今日も負けたぁ！」的“今天也”是说入学后已经输过多次，还是一直以来都输，不清楚。
- 关于父母：制作人说是「元プロアスリート」（0021），这里的“前职业运动员”是父母两人还是其中一人不明；没有提到母亲是偶像训练师，也没提父母不回家。
- 0047 制作人「1つはその単じゅ……素直さですが。」（差点说出“单纯”）是制作人的话，不是她的。
