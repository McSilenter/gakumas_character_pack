# 花海佑芽 亲爱度剧情 / 第7话（adv_dear_hume_007）

- 她的台词：35 行（含匿名标签 0 行）
- 出场的人：佑芽、咲季、プロデューサー（只有结尾 0071、0072 的独白）
- 场景：休息日的早上（0001、0003），咲季在晒太阳的地方（具体地点看不出）；后半回到「部屋」学习（0025、0041）
- 世界线：亲爱度（花海佑芽）；制作人在制作的偶像：佑芽（0072 制作人「佑芽さんのことだ。」）

## 发生了什么
休息日，佑芽想和姐姐一起出去玩，姐姐却说休息日就要全力休息，叫她坐旁边一起发呆。佑芽说休息日的姐姐总是晒太阳像花一样，平时却很吵，姐姐很快睡着。佑芽看着她，自言自语说去年、前年、更早以前她们都是这样：每天比、一起练、一起休息，那时很开心，现在也是；姐姐其实醒着，说“我也是”。姐姐醒后说要回房间学习，佑芽大喊不要；姐姐提醒学业成绩差会限制偶像活动，佑芽说“我可能不行”，姐姐帮她复习，她终于全部做对姐姐特制的复习测验。之后她向姐姐道谢，说自己很幸运，制作人说她能成长是因为有姐姐，她也这么想；姐姐说彼此彼此，要还恩就快点长大威胁到她。姐姐提议在下个月第 2 次『選抜試験』上比一场，佑芽答应，宣言这次绝对赢。

## 行为模式
- 休息日 → 想找姐姐一起出去玩（0001、0006、0009）；姐姐要休息就算了，陪在旁边（0011）
- 以为对方睡着 → 说出平时不说的真心话；被听到后害羞抗议（0015～0022）
- 听到“学习” → 本能抗拒、撒娇（0026、0027）；被姐姐讲道理后道歉、示弱（0035、0036），再接受姐姐教（0039）
- 做完一件难事、安静下来时 → 突然认真地向姐姐道谢（0046～0053）
- 姐姐提出比试 → 立刻接下，用「次こそ！　絶対！」的强调句宣言（0069、0070）
- 对姐姐用常体、语尾「～」「よね」，撒娇感强（0010、0027、0029）

## 关系
- 咲季：称「お姉ちゃん」；咲季叫她「佑芽」，说她「おバカ」（0037）；姐妹从很多年前就每天一起竞争、练习、休息（0015～0017）；姐姐帮她补习功课（0038～0042）；她感谢姐姐，认为是姐姐让自己成长（0048～0053）；姐姐说“两人都在才成为现在的我们”（0057）
- 制作人：她向姐姐转述制作人的话（0051、0052），本篇几乎不出场

## 档案类事实
- 和姐姐很多年来都是每天比、一起练、一起休息（0015～0017）
- 讨厌学习，休息日不想学（0026、0027）；学业方面没自信（0036）
- 初星学园学业成绩差会限制偶像活动（0030、0031 咲季台词）
- 休息日的咲季爱晒太阳、发呆、睡觉，平时很吵（0003、0010、0011）
- 咲季给她做「お姉ちゃん特製／復習テスト」（0042 咲季台词），她全部答对（0043）
- 下个月有第 2 次『選抜試験』，姐妹约好在那里比（0067、0068 咲季，0069 佑芽）
