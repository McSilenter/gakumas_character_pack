# 花海佑芽 亲爱度剧情 / 第13话（adv_dear_hume_013）

- 她的台词：26 行（含匿名标签 0 行）；另有「一同」1 行（0070）未计入
- 出场的人：佑芽、咲季、プロデューサー、燐羽
- 场景：『N.I.A』期间，咲季和燐羽对决的当天（0001～0003），对决前和对决后
- 世界线：亲爱度（花海佑芽）；制作人在制作的偶像：佑芽

## 发生了什么
咲季要和燐羽比，替佑芽报仇。佑芽说本想自己先复仇，但姐姐为她出头的样子太帅，这次让姐姐先上；她说姐姐也会输，但从以前起和她约好的时候从没输过，所以一定会赢。制作人担心的是另一面：燐羽已经有“成长后的佑芽”那么高的数值，如果咲季还能赢，说明数值压不住咲季；她明白后还是坚持“姐姐绝对会赢”。结果咲季赢了，她兴奋地向制作人炫耀，对姐姐说太帅了，向燐羽得意“见识到姐姐的厉害了吧”。燐羽问咲季为什么能赢，咲季说燐羽各项能力都在自己之上，但“你不是偶像”，而且答应了妹妹要报仇，不能破约；佑芽听了尖叫。燐羽说“佑芽，你有个很棒的姐姐”，亲了佑芽一下（「ちゅっ♡」），叫着「咲季お姉ちゃん」离开。众人愣住后，佑芽对姐姐说：我最讨厌那家伙！

## 行为模式
- 姐姐为自己出头 → 把复仇的机会让给姐姐，因为“姐姐太帅了”（0004～0006）
- 被问到姐姐会不会输 → 先承认姐姐也会输，再举“和我约定时从不输”的经验，断言一定赢（0008～0011）
- 被讲道理动摇 → 憋着「んんんん～」想，最后还是凭信任断言（0029、0030）
- 姐姐赢了 → 向制作人和对手炫耀，好像是自己赢了（0031、0032、0037）
- 姐姐说出为她着想的话 → 发出♡的尖叫（0061）
- 被对手做出过分亲昵的举动（亲吻）→ 惊叫，然后对姐姐说“最讨厌那家伙”（0067、0072）

## 关系
- 咲季：称「お姉ちゃん」；绝对信任、崇拜，觉得为她出头的姐姐很帅（0005、0036）；咲季说「妹との約束を、／破るわけにはいかないわ。」（0058）
- 燐羽：称「燐羽ちゃん」（0002）；燐羽叫她「佑芽」（0064、0069），亲了她（0066）；她从生气对手变成“最讨厌”（0072）
- 制作人：称「プロデューサーさん」；和制作人看法不同时坚持自己，赢了向他炫耀（0030～0032）

## 档案类事实
- 姐姐（咲季）也会输，但从以前起和她约定的时候从没输过（0008、0010）
- 咲季在『N.I.A』的オーディション中赢了燐羽（0031、0035、0038）
- 制作人认为燐羽的实力约等于“成长后的佑芽”（0021、0022 制作人台词）
- 被燐羽亲了一下（0066），之后说最讨厌她（0072）

## 不确定
- 「一同」0070「…………………………………………」：燐羽亲了佑芽并离开后的沉默，在场的有佑芽、咲季、制作人。按交代不计入她的行数，待统一判定。（咲季那边的笔记已确认 0070 算咲季的台词，理由写的是“燐羽走后在场的她和佑芽愣住”。）
- 0009 标签是咲季「お姉ちゃんが仇を討ってあげる！」，夹在佑芽 0008 和 0010 之间，应是回想里的姐姐的话，不算佑芽的。
- 0010「昔から……あたしと約束したときは、／負けたことないんです。」与 010 的 0044“ときには負けることもあって。”并不矛盾（会输，但约定时不输）。和咲季那边“表面上从没输给妹妹，快输就换项目逃掉”的说法有关（“和妹妹约定时不输”），留待判定。
- 0066 燐羽「ちゅっ♡」亲在哪里（脸颊？），剧本没写。
- 【译文】0010 原文「あたしと約束したときは、／負けたことないんです。」是“和我约好的时候，（姐姐）从没输过”，译文“和我约定的事情，从未失约过”把“没输过”改成了“没失约过”，意思有偏差。
