# 花海佑芽 亲爱度剧情 / 第16话（adv_dear_hume_016）

- 她的台词：17 行（含匿名标签 0 行）
- 出场的人：黒井、佑芽、燐羽、プロデューサー
- 场景：前半是黒井（961プロ）和制作人的对话（0001～0027），佑芽不在场；后半是佑芽赢了燐羽的オーディション之后（0028 起），她的下一场 live 之前（0059）
- 世界线：亲爱度（花海佑芽）；制作人在制作的偶像：佑芽（0012 黒井「花海佑芽を連れて、／961プロへ来るがいい。」）

## 发生了什么
黒井祝贺制作人“姐妹都赢了燐羽”，邀请他带佑芽去 961プロ，制作人以“贵社不录用制作人”为由拒绝，又开出转会的高价，黒井说改天再谈（佑芽不在场）。另一边，佑芽赢了燐羽，得意地喊“我赢了”，却发现燐羽一点也不甘心，说讨厌燐羽这种地方；燐羽说自己不是偶像，输给偶像也无所谓，又说挺喜欢佑芽，之前说是她的粉丝是真的。燐羽说如果姐妹早点出现就好了，又说佑芽赢了自己、夺了粉丝、排名上升，现在也许够得着咲季了。佑芽说多亏燐羽，对讨厌的敌人这样说很奇怪，但还是道谢。燐羽托她照顾仍然仰慕自己的粉丝，她答应会好好保管，又说想要回去就回来当偶像来夺。燐羽说“你们姐妹真是最棒的”，又亲了她一下，叫她加油 live，她喊“燐羽ちゃんのえっち”。

## 行为模式
- 赢了 → 大声宣布，希望对方不甘心；对方无所谓就生气说“讨厌你这点”（0028～0031）
- 对讨厌的人受过的恩 → 觉得奇怪，但还是直率道谢（0043～0045）
- 被托付重要的东西 → 认真答应，再用玩笑式挑衅（“想要回去就回来当偶像”）表达期待（0050～0052）
- 被突然亲 → 语无伦次，大喊对方「えっち」（0057、0058、0060）

## 关系
- 燐羽：称「燐羽ちゃん」，常体；嘴上说讨厌（0031、0044），但道谢（0045），接下燐羽的粉丝（0050），希望她回来当偶像（0052）；燐羽说挺喜欢她、是她的粉丝（0034、0036），叫她们姐妹「最高」（0054），又亲了她（0056）
- 咲季：燐羽说她现在也许够得着咲季（0042）
- 制作人：本篇和她没有对话；黒井邀制作人带佑芽去 961プロ，制作人拒绝（0012、0013）

## 档案类事实
- 在『N.I.A』的オーディション里赢了燐羽（0001 黒井「まさか姉妹揃って／燐羽に勝つとは……」，0028、0029）
- 赢了燐羽、夺了燐羽的粉丝、排名上升（0041 燐羽台词）
- 受燐羽之托“保管”燐羽的粉丝（0049、0050）
- 又一次被燐羽亲了（0056～0058）
- 961プロ 的黒井想挖她和制作人，制作人拒绝（0012、0013）；制作人提到“毕业后进入 100プロ”（0022 制作人台词）

## 不确定
- 0038、0039 燐羽「あなたたち姉妹が、／もっと早く現れてくれていたら……」「よかったのに。」是什么意思，佑芽 0040 问了，燐羽没答。
- 0022 制作人「卒業後、100プロに入社したとして。」——与 014 的 0042“100プロ以上の環境”合看，100プロ 是将来的去处还是现在的所属，说法不太一致，请人看（不判冲突）。
- 【译文】0031 原文「あたし、燐羽ちゃんの／そういうところキラ～イ！」是“我讨厌燐羽这一点！”，译文“我超喜欢小燐羽／这一点呢！”意思正好相反。
