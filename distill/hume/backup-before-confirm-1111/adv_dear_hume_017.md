# 花海佑芽 亲爱度剧情 / 第17话（adv_dear_hume_017）

- 她的台词：24 行（含匿名标签 0 行）
- 出场的人：佑芽、咲季、プロデューサー
- 场景：『N.I.A』期间，她的 live 结束后的控え室（0005）；『N.I.A』最终日临近（0043）
- 世界线：亲爱度（花海佑芽）；制作人在制作的偶像：佑芽（0022 制作人「俺の担当アイドルは、／花海佑芽ただひとりです。」）

## 发生了什么
佑芽结束 live 回来，说因为姐姐来看了，要拿出现在的全力。控え室里堆满了『N.I.A』限定的花海咲季周边，是制作人送她的胜利礼物；同款很多，一部分是给帮忙训练的燐羽的报酬，还有制作人自己的。她惊讶制作人也喜欢姐姐，抗议“明明是敌人”；制作人说越调查越喜欢，她说“心情我完全懂”，但心里有点不舒服。制作人说担当偶像只有佑芽一人，她才满意，又问“比起姐姐更喜欢我吧？”，要制作人详细说明。咲季被发现在偷听，害羞地抱怨这些话让她不好出场；佑芽向制作人炫耀“姐姐可爱的地方”，说自己是姐姐粉丝俱乐部会员编号一位数。咲季夸她的 live，提起最终日的约定，她说那是“我第一次赢姐姐的日子”；咲季说不会让她赢，但承认她成了很厉害的偶像，感谢制作人，并宣言一次都不会输给她，因为自己是她的姐姐。

## 行为模式
- 姐姐来看 → 更加拼命表演（0003、0004）
- 收到喜欢的东西 → 大声欢呼、道谢（0008、0009）
- 别人也喜欢姐姐 → 一边认同“心情我懂”，一边吃醋、不舒服（0016～0020）
- 不安时 → 用“一応、聞きますけど”开头确认自己被更喜欢，得到肯定后要求对方详细说（0024～0027）
- 姐姐害羞 → 立刻向别人炫耀“姐姐可爱”（0036）；和制作人比谁更是姐姐的粉丝（0038）
- 谈到决战 → 用“第一次赢姐姐的日子”来说（0045）

## 关系
- 咲季：称「お姉ちゃん」；姐姐的头号粉丝（粉丝俱乐部会员编号一位数，0038）；姐姐来看她的 live（0003）；姐姐夸她「凄いアイドルになったわね。」（0047），宣言「一度だって負けてあげない。」（0055 咲季）
- 制作人：称「プロデューサーさん」；对制作人也喜欢姐姐吃醋（0016～0020），确认自己是唯一的担当（0022、0023），要制作人说她的魅力（0025～0027）
- 燐羽：制作人给燐羽的报酬是咲季周边（0011 制作人台词），她听了「え゛……」（0012）

## 档案类事实
- 是咲季粉丝俱乐部的会员，编号一位数（0038）
- 收到『N.I.A』限定的花海咲季周边作为胜利礼物（0007 制作人台词）
- 姐姐来看 live 时会更拼（0003、0004）
- 『N.I.A』最终日的对决是“我第一次赢姐姐的日子”（0045）

## 不确定
- 姐妹谁第一次赢了谁：佑芽 0045「あたしがはじめて……／お姉ちゃんに勝つ日！」——说明到这时她自认从未赢过姐姐；咲季 0055「佑芽……わたしはあなたに、／一度だって負けてあげない。」。与咲季亲爱度“表面上从没输给妹妹，其实快输就换项目（勝ち逃げ）”的说法相关，留待判定。
- 0012「え゛……」是对燐羽收咲季周边当报酬的反应，意味（惊讶？不情愿？）看不出。
- 0038 粉丝俱乐部是什么时候成立、谁办的，本篇没写。
