# 花海佑芽 亲爱度剧情 / 第20话（adv_dear_hume_020）

- 她的台词：50 行（含匿名标签 0 行）
- 出场的人：佑芽、プロデューサー
- 场景：『N.I.A』优胜 live 结束后（0001～0003、0046「優勝ライブ」），当天（0038「今日、勝ちました。」）
- 世界线：亲爱度（花海佑芽）；制作人在制作的偶像：佑芽

## 发生了什么
佑芽结束优胜 live 回来，制作人说她果然在赢了姐姐之后实现了突破。她说像重生了一样：眼前豁然开朗、身体轻、头脑清醒、胸口发热，这种感觉她知道，不是错觉。回顾姐姐的底力和魅力让她们多次不甘心，她说以后不会再那样输，“条件一样了”。制作人说这次的目标——在 N.I.A 把她培养成数值压倒性的偶像、优胜、赢咲季、再突破——全部达成，终于可以问那个问题（问题本身没写出）。她回答：在『H.I.F』优胜成为『一番星』；又改口说不是像以前那样追姐姐，而是她要成为姐姐的目标。她说自己是追着姐姐的背影成为偶像的，从出生起姐姐就是她的目标、梦想、一切，从没想过梦想实现后的事；今天赢了，赌上人生的梦实现了，结果是想做的事不断涌出来——想唱的歌、想穿的衣装、想做的工作，她最喜欢偶像。所以她想先“好好成为偶像”，找到了大家入学时就有的梦：梦想成为顶级偶像、目标『一番星』，然后再和姐姐比。她说姐姐现在正为打败她特训，那么厉害的姐姐拼命追她，让她又高兴又害怕又感动；她相信姐姐会追上来，绝对不输。最后她感谢制作人让她实现了梦想，下一个梦想是顶级偶像。

## 行为模式
- 被问到关键问题 → 先长时间沉默（0029），再给出答案，又马上自己修正说法（0030～0034）
- 讲内心变化 → 用身体感觉描述（眼前开阔、身体轻、胸口热）（0010、0011）
- 讲梦想 → 先回顾过去（追着姐姐），再承认没想过，然后一口气列出具体想做的事（0035～0047）
- 被姐姐追 → 高兴、害怕、感动同时出现，身体发抖（0059；009 也有类似反应）
- 阶段性结束 → 郑重感谢制作人并说「引き続き、よろしくお願いします！！」（0066～0068）

## 关系
- 咲季：从出生起是她的目标、梦想、一切（0036）；现在她要成为姐姐的目标（0034）；相信姐姐会追上来（0060、0061）；『一番星』对她来说比成为顶级偶像更重要，因为要和姐姐再战（0054、0056）
- 制作人：称「プロデューサーさん」，也称「あなた」（0066）；她说制作人一直担心“失去梦想的花海佑芽会怎样”（0040、0041）；说遇到制作人才实现了梦想（0066）

## 不确定
- 0028 制作人「ようやく……／この質問をすることができます。」后没写出问题，0029 她沉默，0030 回答的是目标；问题应是“你现在的梦想/目标是什么”之类，剧本没写。
- 姐妹成为偶像的理由：本篇 0035「あたしはお姉ちゃんの背中を／追って、アイドルになりました。」与 004 的 0014、001 的 0044 一致（为了姐姐）；本篇之后她自己的新理由是 0047「あたしは――アイドルが大好きですッ！」、0049「ちゃんとアイドルになりたいです。」。和咲季那边多种说法对照时请注意这是同一条线里的变化。
- 0056「あたしにとっては、きっと……／トップアイドルになるよりも大切です。」——“比成为顶级偶像更重要”的主语是今夏的『一番星』（和姐姐再战），与 0067「次の夢は、トップアイドル！」放在一起看略有张力，不判冲突。
- 【译文】0030 等处『一番星』译成『启明星』，这里按原文写『一番星』。
