# 花海佑芽 亲爱度剧情 / 第24话（adv_dear_hume_024）

- 她的台词：45 行（含匿名标签 0 行）
- 出场的人：佑芽、燐羽、手毬、千奈、広、星南（0024，回想）、佑芽が参考にした人物（0087）
- 场景：早上，她晨练刚结束（0001）；暑假刚结束（0070 手毬）；之后是出发去她愛知老家集训前的集合（0069 広）
- 世界线：亲爱度（花海佑芽）；制作人在制作的偶像：佑芽（0071 広「佑芽のプロデューサーががんばった。」）

## 发生了什么
晨练结束，燐羽来找她，说在等人，也有话要说。燐羽问她和托付给她的粉丝相处得好不好，她说 H.I.F 时粉丝很支持她；燐羽提出一堆细致要求，她说“这么担心就回来当偶像嘛”，燐羽说所以正在等手毬她们，她高兴地问什么时候。燐羽认真地要谈咲季，她却抢着说姐姐在 H.I.F 上星南亲传的『ENDLESS DANCE』像夏天的烟花，对她来说姐姐才是『一番星』，又抱怨星南得意的脸常出现在她梦里。燐羽说算了、看到她的傻脸下定了决心；她叫住燐羽，说自己正和星南一起给姐姐做新曲，作为给最喜欢的对手的礼物，一定能代替她成为姐姐的力量。燐羽问她看了那场仿佛要燃尽的舞台，就接受那样的姐姐吗；她说可以，自己也会同样燃烧到最后，唱完笑着下台，有雷鸣般的掌声就不会后悔，“因为是偶像”。燐羽说两人一点不像、很烦，回来当偶像后要先泼她冷水，然后离开。手毬赶来，她转达燐羽在老地方等，说两人吵架了，“刚刚才变要好”。広、千奈到齐，要去她老家愛知为『選抜試験』集训；她说为了得到许可出了很多课题，又说到了那边制作人会安排见有名的前辈偶像。她承认 N.I.A 见取り稽古时不太懂偶像、很可惜，但学会了模仿顶级偶像，当场模仿一位爱给人起“好吃外号”的顶级偶像，叫手毬「とりもも」、広「砂肝」、千奈「ぽんじり」。

## 行为模式
- 别人细细交代 → 嫌麻烦，直接说出对方真正想要的（回来当偶像）（0012）
- 听到好消息 → 马上问细节、开心期待（0014、0016）
- 一谈到姐姐 → 抢话、兴奋地夸个不停，跑题到别处（0019～0025），被提醒后才道歉（0027）
- 别人犹豫要不要说 → 主动说出自己的打算，让对方安心（0031～0035）
- 被问到沉重的问题（姐姐会燃尽）→ 安静地接受，用自己也会这样做来回答（0047～0052）
- 吵完架 → 笑着向别人说“吵架了”“刚刚才变要好”（0061、0063）
- 在同伴面前 → 开玩笑、模仿别人，给同伴起外号（0083～0093；模仿的是“某顶级偶像”的口吻，不是她本人说话方式）
- 对同学用常体、语尾「～」「だもん」「じゃん」（0012、0042、0055）

## 不确定
- 家在愛知：本篇 0069 広「これから佑芽の実家に行く。／『選抜試験』に向けて、／愛知で強化合宿。」，与 002 的 0060“あのすぐ後に、／わざわざ愛知まで行ったんですか！？”（父母在愛知）一致；019、021 的“老家”（咲季回去特训、母亲建的训练设施）是否就是这里，本篇没明说。
- 0024 星南「フッ、これが――／プロジェクト『星屑』の成果よ！」不在当前场景，应是她回想或想象的画面，剧本没标。
- 0083、0089、0090 是她模仿某顶级偶像的口吻（「フッ……いいだろう。」「これで失礼する。」等），0087 标签『佑芽が参考にした人物』是被模仿者本人的台词（回想），都不是她平时的说话方式。被模仿的是谁，本篇没写。
- 0045～0047 燐羽说姐姐的舞台「いまにも燃え尽きて／しまいそうだった。」，她 0048 接受，但燐羽一开始想对她说的“咲季的事”（0019、0026）最终没说出口，内容不明。
- 0057 燐羽说回来当偶像后要先泼她冷水——是否真的回来，本篇没写。
- 【译文】0083「刮目するがいい……とりもも。」中「とりもも」是鸡腿肉（与后面的「砂肝」「ぽんじり」同为烤鸡串部位），译成「小鸡仔」丢了“好吃的外号”的意思（0088）。
- 【译文】0072「課題がいっぱい出たぁ……」是“布置了好多课题（作业）”（集训获准的条件），译文“问题真是堆成山了”容易误解。
