# 花海佑芽 亲爱度剧情 / 第25话（adv_dear_hume_025）

- 她的台词：31 行（含匿名标签 0 行）；另有「一同」3 行（0014、0071、0083）未计入
- 出场的人：佑芽、花海社長、プロデューサー、広、千奈
- 场景：花海トレーニングセンター（0001），她说是「我が家」（0004）；合宿第一天，设施处于プレオープン阶段（0021、0073）
- 世界线：亲爱度（花海佑芽）；制作人在制作的偶像：佑芽（0011 広「佑芽のプロデューサー」）

## 发生了什么
広、千奈和制作人来到花海トレーニングセンター合宿，佑芽欢迎她们来“我家”，说邀请两人是制作人提的。広问制作人是不是喜欢自己，制作人说“当然”（指作为偶像），佑芽一阵慌乱。制作人说合宿主要目的是为『選抜試験』特训，佑芽模仿制作人的口吻介绍设施，说受燐羽影响最近爱模仿；她承认夏天输给了真正的顶级偶像和姐姐，制作人要她不止模仿，要在『選抜試験』前把东西变成自己的、超越本尊，千奈和広也是见取り稽古的对象。她领会了邀两人的用意：为了赢姐姐和星南，要全力学两人的长处。接着见到中心的主人——她父亲花海社長（年轻得被当成哥哥）。父亲拒绝制作人提的“让佑芽当公司宣传大使”，说自己人气和长相都更好，她顶嘴说宣传偶像设施当然该偶像来，又数落父亲老东家不给他指导工作、后辈没人入会、网上把她家叫「サイボーグ生産工場」、和名古屋名店的联名菜单被笑。制作人提议用观众投票、全国播放的コンペ决定宣传大使，広、千奈也参加，她兴奋地迎接合宿开始。

## 行为模式
- 被问到出乎意料的话（広问制作人是否喜欢她） → 「！？」、长叹，再把责任推给对方（0012、0016、0018）
- 想说明事情时 → 模仿别人的口吻说（这次学制作人），并说是燐羽带起来的爱好（0021、0022、0024）
- 被指出“只是像” → 先不甘心地叫，再把对方的话理解成自己该学的东西（0028、0035～0038）
- 和父亲说话 → 用常体，一边顶嘴一边把网上的坏评价全抖出来，最后说“我来努力挽回”（0055、0057、0058、0061～0065）
- 听说对手会变多、变强 → 越发兴奋（0078、0082）
