# 花海佑芽 亲爱度剧情 / 第26话（adv_dear_hume_026）

- 她的台词：48 行（含匿名标签 0 行）；另有「一同」2 行（0029、0070）未计入
- 出场的人：佑芽、広、千奈、花海社長、プロデューサー（只有 0017、0018，千奈转述时的画面）
- 场景：花海トレーニングセンター合宿中，体能训练后；后半是当晚（0081「今夜は」）和父亲谈话
- 世界线：亲爱度（花海佑芽）；制作人在制作的偶像：佑芽（0045 広「佑芽のプロデューサー」）

## 发生了什么
佑芽做着和広、千奈不同的激烈体能训练，第一次在训练里显得吃力，却说正合她意。她解释这是“见取り稽古”的延续：自己和顶级偶像之间还有技术差距，模仿不来的部分就用体能硬顶上；但她又说光堆数值赢不了コンペ、也赢不了冬天的『H.I.F』，宣布开始“倉本千奈和篠澤広的见取り稽古”。她判断コンペ会赢的是职业偶像前辈或千奈，広也同意。她说三人都从学园最底层起步、被叫作「落ちこぼれの補習組」，季节流转、夏天结束，她终于成为偶像了，三人又站在一起；提议像先走一步的人那样互相批评、交流、研鑽。父亲来了，说第一次见到和咲季分开还这么开心的她；她请父亲讲偶像，父亲却自嘲学偶像不到一年、只是元运动员的地方艺人（被她发现他エゴサ了）。她于是问出一直没问的话：自己是不是辜负了父母的期待，不当偶像是不是更好。父亲说本来就没期待，只期待自己和利害一致的伙伴，但支持佑芽和咲季；她说今后可以期待了，因为她是偶像。父亲以“元超级英雄”身份说没有无悔的引退，要尽情大闹、珍惜敌人、享受超越与被超越；她答应，说コンペ里父亲也是敌人。

## 行为模式
- 训练很苦 → 喘着气仍说「望むところだよ！」，觉得来这里就要做只有这里能做的特训（0005、0010、0011）
- 自己还做不到的东西 → 先想用最擅长的体能硬顶（0022～0025），再自己指出这不够，转去学身边人的长处（0032～0037）
- 评估胜负 → 直说自己赢面小、谁更强，不自欺（0038、0039、0047、0049）
- 被朋友夸 → 不接受“我早就很厉害”，强调大家都从底层起步、自己只早了一步（0050～0059）
- 面对父母 → 平时吐槽父亲，但在父亲低落时主动问出一直不敢问的“有没有辜负期待”（0082～0084）
- 听到不太对题的回答 → 小声疑问后「まあいっかあ！」放下，再宣战（0096～0098）

- 她和広、千奈三人都从学园最底层起步，被叫作「落ちこぼれの補習組」（0052、0053）

- 合宿里她做和広、千奈不同的激烈体能训练（0008 広）；制作人的方针是强化体能、掌握别的偶像学不来的杂技式舞蹈（0017、0018 制作人）
- 她说“见取り稽古的延续”是用体能代替还模仿不了的技术（0021～0025）

## 不确定
- 「一同」0029「はいっ！」：回答她 0028“是在夸我吧？”，应是広、千奈；0070「やろう！！！」：三人互相约定研鑽后的齐声。两行按交代都未计入，待统一判定。
- 姐妹成为偶像的理由／父母的期待：0083「あたし……お父さんやお母さんの期待、／裏切っちゃった？」、0084「本当は……アイドルじゃない方が、／よかった？」、父亲 0085「ばかだな。／最初から期待なんてしてない。」——父母原本是否希望她走别的路（例如运动），本篇没说。
- 父母：父亲 0074「勉強を始めて1年に満たない、／にわか専門家でよければ。」——父亲也在学偶像方面的东西，学了不到一年；021 的 0039 说母亲是女儿们以偶像为目标后才急忙开始学习的。两者不矛盾，留给人看。父亲 0078「愛知の人々が言うように」——父亲在愛知当地是地方艺人，与 024 的 0069（老家在愛知）相符。
- 0072 父亲「咲季と離れ離れなのに」：合宿期间咲季不在，027 的 0021 说合宿前她和制作人约定回学园前不和姐姐说话。这句也说明她平时和姐姐常在一起，但住处本篇没写。
- 年级／时间：0052～0055 只说夏天结束、入学以来季节流转，年级没写。
- 0017、0018 是千奈 0016「プロデューサーは、／こうおっしゃいました。」之后的制作人台词，是回想画面。
- 【译文】0082「じゃあ……代わりに……／ずっと聞けなかった話、するよ。」是“那（你今晚只能讲丧气话的话）我就换个话题，说一件一直没能问的事”，译文“你不说的话……”意思偏了，不影响大意。
