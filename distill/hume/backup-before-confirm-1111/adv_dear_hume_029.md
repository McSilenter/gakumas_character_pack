# 花海佑芽 亲爱度剧情 / 第29话（adv_dear_hume_029）

- 她的台词：32 行（含匿名标签 0 行）
- 出场的人：佑芽、燐羽、プロデューサー、咲季（只有舞台上的 0041）
- 场景：前半是她练『グースーピー』的地方；后半是三大マスターオーディション之一『VisuaL master』的会场，她和燐羽在看咲季（0025～0029、0041）
- 世界线：亲爱度（花海佑芽）；制作人在制作的偶像：佑芽

## 发生了什么
佑芽重练『グースーピー』，觉得很难唱：不久前还觉得是为她而生的歌。制作人说她成长得太快，“天真地追着姐姐背影的偶像之卵”已经不在了，就像小时候珍惜的鞋穿不下。她说仍最喜欢这首歌，不想把它收进宝箱锁在壁橱里，问该怎么办；制作人说要重新解释成现在的“花海佑芽らしい曲”“挑战花海咲季的曲”，并请来燐羽。燐羽拿来咲季出场的『VisuaL master』的票，说能看到咲季的新曲『Try it now』。她担心那首歌能不能成为姐姐的力量，燐羽说当然，那是“亲爱的妹妹送的礼物”；她说自己正和星南一起做姐姐的新曲，燐羽说里面也有自己的心意，她抗议燐羽独占功劳。咲季打败身经百战的职业偶像夺冠，燐羽说看她燃成那样，得快点去救她；佑芽说不需要，她会用自己的 live 无数次给姐姐点火，叫燐羽退下。燐羽揉她头发说“这才是我妹妹”，她说才不是。燐羽说她现在应该能唱『グースーピー』了，她请燐羽严格挑毛病，“要摆姐姐架子就好好摆”，向『グースーピー』宣战要马上和好。

- 0015「――それでも。あたしは……／この曲が大好きです。これからも／歌っていきたい素敵な曲なんです。」——不放弃这首歌
- 0016「宝箱に入れて、押し入れの奥に／しまい込んでしまいたくはないです。」——不愿把它只当回忆
- 0031「あの曲が、お姉ちゃんの力に／なってくれるかな。」——担心给姐姐的歌是否有用
- 0034「大好きなライバルのために、／愛をこめて、贈り物をするんだ。」——给姐姐做歌的心意
- 0037「あ～～っ！！　／手柄を独り占めしようとしてる！！」——对燐羽争功
- 0048「必要ないよ。」——拒绝燐羽“去救姐姐”的想法
- 0050「あたしのライブで、／何度だって火を点けるから！！！」——她对“燃尽的姐姐”的回答
- 0051「燐羽ちゃんは引っ込んでて。」——对燐羽不客气

- 0062「うん。お姉ちゃんぶるなら、／ちゃんとやってよね。」——反过来要燐羽“当好姐姐”
- 0064「すぐに仲直りしてやるからなぁ！！」——把歌当成吵了架的朋友

## 行为模式
- 练不好 → 先大声喊苦、抱怨，但马上说出仍喜欢、想继续唱，问“怎么办”（0005～0009、0015～0017）
- 看到姐姐的厉害舞台 → 激动到说不出话，附和“对吧对吧”（0042、0045）
- 别人说要去“救”姐姐 → 立刻拒绝，用“我来点火”代替“救”，把对方推开（0048～0051）
- 被燐羽当妹妹逗、揉头 → 嘴上大声否认，但还是请燐羽帮忙、要她严格（0054、0055、0060～0062）
- 对乐曲 → 当作有性格的朋友：吵架、和好（0063、0064）

## 关系
- 燐羽：称「燐羽ちゃん」，用常体；燐羽叫她「うーめ」（0022）、「佑芽」（0057），说「それでこそ私の妹よ。」（0053），揉她头发（0054）；她否认是妹妹，但请燐羽严格指导（0055、0060～0062）
- 咲季：称「お姉ちゃん」；她为姐姐担心“歌能不能成为力量”（0031），看了姐姐的舞台后说要用 live 无数次点燃她（0050）；燐羽称咲季「咲季お姉ちゃん」（0027、0039）
- 星南：称「星南先輩」，和她一起做姐姐的新曲（0033）
- 制作人：称「プロデューサーさん」；制作人说她长得太快，以前那个“天真追姐姐的偶像之卵”已经不在了（0010、0011 制作人）

## 档案类事实
- 现在唱『グースーピー』很难，以前觉得是为她而生的歌（0005～0009）
- 咲季出场三大マスターオーディション之一『VisuaL master』，打败身经百战的职业偶像夺冠（0025、0026、0043 燐羽）
- 咲季的新曲『Try it now』，燐羽说是“亲爱的妹妹送的礼物”（0029、0032 燐羽）
- 她说正和星南一起给姐姐做新曲（0033）
- 燐羽说自己只是后来插了几句嘴（0038 燐羽）

## 不确定
- 0033「あたしね、いま……星南先輩と一緒に、／お姉ちゃんの新曲を作ってるんだ。」用的是现在进行时，而同一篇 0029、0032 燐羽说『Try it now』当天就要被唱、是妹妹送的礼物。『Try it now』是否就是她和星南做的那首、她说的“正在做”是否另有一首，本篇看不出（024 的 0032 也说过和星南一起给姐姐做新曲）。燐羽 0036「私の想いが詰まった曲……」、0038「後からちょっと口出ししただけ」——谁参与了作曲也不明。
- 0041 咲季「楽しんでくれたかしら！　／このわたしのステージを！！」是舞台上对观众说的话，不是对佑芽。
- 0046、0047 燐羽“看她燃成那样得快点救她”、0049「閃光のように輝いて、／燃え尽きるべきだから？」，与 027 的 0074（制作人说咲季有短命偶像的危险魅力）相关。
- 0011 制作人「無邪気に姉の背を目指す、／アイドルの卵はもういない。」——“姐姐的背影”这个说法和姐妹成为偶像的理由（她追着姐姐当偶像）相关，只记原文。
- 0059「最新のお姉ちゃんを……／見せつけられちゃったからね。」——她把看了姐姐的舞台当成“现在能唱”的理由。
