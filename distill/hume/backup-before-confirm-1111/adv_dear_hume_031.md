# 花海佑芽 亲爱度剧情 / 第31话（adv_dear_hume_031）

- 她的台词：35 行（含匿名标签 0 行）
- 出场的人：佑芽、プロデューサー、咲季（只有 0028、0029，是制作人想象中的声音）
- 场景：她第一次演完『つよつよ最強エクササイズ』之后；冬季『H.I.F』前最后一次『選抜試験』之前（0055）
- 世界线：亲爱度（花海佑芽）；制作人在制作的偶像：佑芽

## 发生了什么
佑芽演完『つよつよ最強エクササイズ』，制作人却板着脸，她慌了，追问是好是坏、是不是自己做错了什么；制作人说是动摇得没表达好，表演非常出色。制作人原本把这首歌理解为“花海咲季送给花海佑芽的歌”，她却把它理解为“花海佑芽送给最强对手花海咲季的歌”，制作人拍膝叫好又说“被摆了一道”，她笑他很不甘心。制作人觉得她唱这首歌在『H.I.F』对决咲季简直像命运，她抢先说已经知道他要说什么、答案已经定了：所有的歌都是最喜欢的亲友，但挑战『H.I.F』想和『真っ白いページと水彩の主人公』一起；被问“即使违背咲季的意思？”，她说姐姐要她用最强的自己来挑战，那就如她所愿——这首歌会和她一起变强，是能唱到星星那里、连命运都不输的歌。她说没做什么值得道谢的事，只是凭自己的意志和直觉做了最好的选择，按原计划去赢。最后的『選抜試験』对手是千奈和広，她要让变厉害的两人看看“这就是现在的我”。

## 行为模式
- 制作人反应不明 → 连珠炮追问“好还是坏”，再怀疑自己做错事（0005～0013）
- 同一首歌 → 不按别人给的理解，而是反过来理解成“我送给姐姐的”（0019、0020）
- 预感到制作人要提方案 → 抢先说自己已决定，并给出选择和理由（0032～0034、0039～0047）
- 被问“和姐姐的意思相反也行吗” → 把姐姐的意思重新解释成支持自己的选择（0043～0045）
- 被道谢 → 推开，说只是按自己的意志和直觉选（0049、0050）

## 关系
- 制作人：称「プロデューサーさん」；他板脸时她慌（0005～0013），他不甘心时她笑（0024）；她先一步说出答案，制作人说“按原计划去赢”（0051～0053）
- 咲季：她认为姐姐要她“用最强的自己来挑战”（0044）；把『つよつよ最強エクササイズ』理解为自己送给姐姐的歌（0020）
- 千奈、広：最后『選抜試験』的对手，“变厉害了的两人”（0057、0058）

## 档案类事实
- 冬季『H.I.F』本战决定用『真っ白いページと水彩の主人公』挑战（0040）
- 把『つよつよ最強エクササイズ』理解为“花海佑芽送给最强对手花海咲季的歌”（0020）
- 最后一次『選抜試験』的对手是千奈和広（0055～0057）

## 不确定
- 0028「佑芽！　この曲で挑んできなさい！！！」、0029「最強のあなたに勝って、／わたしが頂点に立つわ！」：标签是咲季，但 0027 制作人说「咲季さんの勇ましい声が／聴こえてくるようです……」，是制作人想象的声音，咲季本人不在场。
- 0008「『この顔の意味』ですか……それは……」到 0009「ほっ……よかったーっ。」、0010 到 0011「ええぇーっ！？」之间接不上，应是制作人的选项（说明那张脸的意思）没写进剧本。
- 0049「お礼を言われるようなこと、／なにもしてないです。」前面没有制作人道谢的台词，应是选项没写进剧本。
- 0051、0053「当初のプラン」具体指什么（是 010 定的数值路线，还是用这首自由曲的计划），本篇没说。
- 【译文】0019「あたしはこうも解釈しました。」是“我（还）这样理解了”，和制作人的理解不同；译文“我也是这么理解的”像是赞同制作人，意思反了。
