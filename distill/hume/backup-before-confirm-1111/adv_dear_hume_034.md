# 花海佑芽 亲爱度剧情 / 第34话（adv_dear_hume_034）

- 她的台词：22 行（含匿名标签 0 行）；另有「一同」1 行（0005）未计入
- 出场的人：佑芽、ダンストレーナー、ビジュアルトレーナー、ボーカルトレーナー、花海姉妹の母、プロデューサー
- 场景：『Hatsuboshi IDOL FESTIVAL』当天清晨（0001），练习场所（看不出具体地点）
- 世界线：亲爱度（花海佑芽）；制作人在制作的偶像：佑芽

## 发生了什么
『H.I.F』当天清晨，佑芽『H.I.F』自由曲版的『真っ白いページと水彩の主人公』终于完成，训练师们松了口气。回顾过程：舞蹈训练师吐槽她挥バトン（指挥棒）时带着杀气，“你是偶像，不是格斗家”，要她把「舞」里「武」的气息去掉；她喊着“倾注爱意”出招，被骂“别想着你姐姐”；她抗议那只是最初期的事。训练师们说完成得晚不只因为她上手慢，也因为她怎么练都还能长，没人说得出“就这样完成吧”；学园里还因花海姉妹带动流行起晨练。训练师们说能和花海女史共事很幸运：日本最强的国民英雄、虽项目不同但被称为名训练师；母亲说作为偶像训练师她是后辈，请多指教。佑芽向母亲、训练师和工作人员道谢；训练师说她从一开始就很尊重一起做舞台的工作人员——虽然对偶像的敬意一般般，但那已是过去，说会为她加油。她把“万全的花海佑芽”交给制作人，制作人说“以最高的歌唱力、最高的舞蹈、最高的美貌，理所当然地赢——天下第一的挑战者！”，她说这句话很怀念，和当时有一点不同，是像现在的他们的鼓励，宣布会回应期待。

## 行为模式
- 被训练师纠正 → 立刻大声回应并重做（0009、0010）；被吐槽“想着姐姐出招” → 实际上一用力就喊「くらえ」（0017、0018）
- 被翻出过去的糗事 → 涨红脸抗议“那只是初期”（0021）
- 完成一件事 → 一个个点名向母亲、训练师、工作人员道谢（0026、0027、0045～0047）
- 被夸 → 「えへへ」谦虚；被指出缺点 → 「うぐっ」认下（0050、0052）
- 制作人用旧话鼓励 → 听出与当初的差别，并说出差别的意义（0059～0063）

## 关系
- 训练师们：ダンストレーナー叫她「花海」（0009），ビジュアルトレーナー叫她「佑芽ちゃん」（0023），ボーカルトレーナー叫她「花海さん」（0036）；她称「トレーナーさん」（0045），用敬语道谢；训练师们说教她很开心（0033）

## 档案类事实
- 『H.I.F』自由曲是『真っ白いページと水彩の主人公』，当天清晨才完成『H.I.F』版（0003、0004）
- 自由曲里有挥バトン的动作，她挥棒时带着杀气、像格斗（0009～0014、0020）
- 训练师说她从一开始就很尊重一起做舞台的工作人员（0048 ボーカルトレーナー），对偶像的敬意以前一般（0051 ダンストレーナー）
- 学园里因花海姉妹流行起晨练（0034 ダンストレーナー）
- 母亲：被称为「花海女史」（0038），「日本最強の国民的英雄」（0039 ダンストレーナー），虽项目不同但被称为「名トレーナー」（0040 ボーカルトレーナー）；母亲说作为偶像训练师自己是后辈（0043 母亲）；母亲自称「あたし」（0043）
- 制作人这次的鼓励：「天下一の挑戦者を！」（0060 制作人），前半句是 010 的 0075 的原话
