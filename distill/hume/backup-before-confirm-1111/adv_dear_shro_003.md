# 篠澤広 亲爱度剧情 / 第3话（adv_dear_shro_003）

- 她的台词：19 行（含匿名标签 0 行）
- 出场的人：広、千奈、佑芽、あさり先生、プロデューサー（佑芽 19 行）
- 场景：学园的教室（あさり先生 0001“授業を終える前に”）及课后；入学后不久（広 0028“1ヶ月だけのお試し契約”）
- 世界线：亲爱度（篠澤広）；制作人在制作的偶像：篠澤広

## 发生了什么
あさり先生的课结束，佑芽和千奈听说广有了制作人，佑芽惊讶，追问是怎样的人。广说“好き”，并说喜欢他对自己评价最低、像要随时放弃自己的目光，试用契约一个月后可能被抛弃。佑芽和千奈吓坏了。广说多亏佑芽，周课题“先週よりも健康になる”达成，因为饮食改善了；佑芽说谢谢要对做饭的姐姐说。广说本月课题是“立てるようになる”。佑芽不理解为什么片足站立10秒做不到。后半广让千奈示范站立，佑芽也觉得她站得漂亮、肌肉看不出来却很稳。

## 行为模式
- 朋友的恋爱发言 → 比朋友更激动，连声“うわーうわー”，自己也心跳（0014）
- 朋友说危险的事 → 先惊讶，后担心“そのプロデューサーさんで大丈夫なの？”并大喊“ちっとも大丈夫じゃないぃっ”（0026、0030、0033）
- 被道谢 → 害羞地笑，把功劳让给做饭的姐姐（0044、0045）
- 遇到自己能轻松做到的事别人做不到 → 一直发问“なんで？？？”，没有恶意（0049、0054、0056）
- 看到朋友的特长 → 直说“綺麗に見えるね”（0073）
