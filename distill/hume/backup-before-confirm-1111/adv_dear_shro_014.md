# 篠澤広 亲爱度剧情 / 第14话（adv_dear_shro_014）

- 她的台词：21 行（含匿名标签 0 行）
- 出场的人：佑芽、撫子、広（佑芽 21 行）
- 场景：『N.I.A』期间的比赛会场（撫子 0003 败给佑芽；広 0012 说要在『FINALE』优胜）
- 世界线：亲爱度（篠澤広）；制作人在制作的偶像：篠澤広

## 发生了什么
佑芽在オーディション里赢了撫子，高兴。广现身说是“敵情視察”，宣布自己要在『FINALE』优胜。佑芽愣了一下后欣喜，说广也是自己的对手。广说千奈也是，佑芽不知道，广给她看排名。佑芽说早就知道她们会追上来，想马上和广在オーディション对决。广说终于让佑芽用那种表情看自己，说若赢了会很开心并叹气。佑芽说无论如何也不想输给广，和输给姐姐一样。

## 行为模式
- 赢了 → 先高兴地大声说“勝ち”，对手撤退时也笑着再见（0002、0008）
- 得知朋友要挑战自己 → 沉默一下，然后爆发出欢喜（0013～0016）
- 得知朋友的实力上升 → “知ってたよ”“待ってたよ”，不惊讶，反而喜悦（0022～0024）
- 想要立刻对决 → 马上提出（0025）
- 面对朋友的“胜了也叹气” → 想象就想叫，决意不输（0036、0038、0039）
