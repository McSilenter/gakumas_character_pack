# 篠澤広 亲爱度剧情 / 第16话（adv_dear_shro_016）

- 她的台词：15 行（含匿名标签 0 行）
- 出场的人：佑芽、広（佑芽 15 行）
- 场景：『N.I.A』的オーディション或ライブ之后的会场（広 0004 气喘；佑芽 0001～0002）；『N.I.A』进行中
- 世界线：亲爱度（篠澤広）；制作人在制作的偶像：篠澤広

## 发生了什么
佑芽走向广，刚要说“あたしの負――”，却见广倒下，惊叫。广说“九死に一生を得た”，佑芽将她搬走。广说自己体力有所提高，但被佑芽这位强敌逼到极限。佑芽承认自己输了。广说自己想哭，佑芽和千奈是她第一次的朋友，佑芽是自己第一次看现场的本物偶像、憧憬、对手。佑芽无言后说“また、勝負しようね”。广问佑芽还记不记得约定，佑芽想起，广叹出一大口气，佑芽喊“こんにゃろ～”。

- 0030「こ、こんにゃろ～～～～～～～～～っ！」——被广叹气后的反应

## 行为模式
- 对手在眼前倒下 → 先惊叫，然后问“大丈夫”，并担心广（0003、0005、0009）
- 对手说得不吉利 → 吐槽“アイドルやってて、そんな台詞を聞くことになるとは”（0007、0011）
- 输了 → 平静承认“あたしの負けだね”，称赞对手（0014、0015）
- 对手哽咽 → 惊讶而不是回避，问“なんで！？”（0018）
- 被广以叹气应对 → 说“こんにゃろ～”（0030）

## 关系
- 広：称「広ちゃん」（0001、0005、0014）；広称她「佑芽」，说“わたしのはじめての友達”“憧れ”“ライバル”（広 0019～0023）
- 千奈：广提到她（広 0019）；本篇不在场
