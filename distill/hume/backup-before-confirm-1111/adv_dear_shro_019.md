# 篠澤広 亲爱度剧情 / 第19话（adv_dear_shro_019）

- 她的台词：7 行（含匿名标签 0 行）
- 出场的人：広、プロデューサー、千奈、佑芽（佑芽 7 行）
- 场景：オーディション会场的休息处（広 0001 刚赢；プロデューサー 0023“力尽きて、眠ってしまった”）；『N.I.A』的『FINALE』前后
- 世界线：亲爱度（篠澤広）；制作人在制作的偶像：篠澤広

## 发生了什么
广赢了，让制作人夸她，说父母来了会场。后半千奈和佑芽来到休息处，看到广睡着。千奈说想祝贺但改天。佑芽对制作人说，他的气质和广说的不一样，并复述广对他的描述“いまにも見限ってきそうな冷たい目。鬼みたいで、悪魔みたいで”。制作人说“誤解です。半分ほどは”，一露出这种眼神佑芽就大喊“聞いてたとおりの目になった～！”，被千奈制止，两人退出，嘱咐制作人转告广。

## 她的关键台词
- 0021「広ちゃん！　……あっ。」——见到广睡着
- 0025「だけど、どうしてもお祝いをしたくて。」——来的目的
- 0027「プロデューサーさん……広ちゃんから／聞いてたのと、雰囲気が違いますね。」——对制作人的第一印象
- 0029「いまにも見限ってきそうな冷たい目。／鬼みたいで、悪魔みたいで……」——复述广对制作人的描述
- 0032「ああぁ～～～～！／聞いてたとおりの目になった～～～！」——制作人表情一变，指着叫
- 0034「おっと危ない。じゃ、あたしたちは／これで失礼しまっす！」——被提醒别吵醒广后
- 0035「広ちゃんに伝えておいてください！」——嘱咐制作人转告

## 行为模式
- 见到睡着的朋友 → 叫了一声，随即收住（0021）
- 第一次面对制作人 → 直接说他与听说的不同，并复述朋友的描述（0027、0029）
- 对方露出被形容过的表情 → 兴奋地指出（0032）
- 被提醒 → 马上收敛，告辞（0034）

## 关系
- 広：称「広ちゃん」（0021、0035）
- 千奈：同行；千奈称她「花海さん」（千奈 0033）
- 広的制作人：称「プロデューサーさん」（0027）；制作人对她们称“花海さん”不出现

## 不确定
- 0035「広ちゃんに伝えておいてください！」之后广的传话内容是千奈 0036 “次こそは、負けませんわ！――と。”；佑芽自己要传的话本篇没说完。
- 0029「いまにも見限ってきそうな冷たい目。／鬼みたいで、悪魔みたいで……」是复述广在第3话的说法（広 第3话 0023 “いまにも見限ってきそうな眼差しが好き”），不是她自己的评价。
- 0023 制作人说广“力尽きて、眠ってしまった”，广 0017 说父母到了会场；佑芽、千奈是否知道广父母到场，本篇没说。
