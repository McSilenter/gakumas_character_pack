# 篠澤広 亲爱度剧情 / 第30话（adv_dear_shro_030）

- 她的台词：23 行（含匿名标签 0 行）
- 出场的人：広、プロデューサー、佑芽、千奈、一同（佑芽 23 行）
- 场景：广向佑芽、千奈讲述自己的ライブ（广 0036 起复述与制作人的对话）；冬『H.I.F』之前，『選抜試験』之后
- 世界线：亲爱度（篠澤広）；制作人在制作的偶像：篠澤広

## 发生了什么
广对佑芽、千奈转述制作人的话：“篠澤広・冥界ライブツアー”，以及“トップアイドルにだって通用する。そう信じていますよ”。佑芽在转述时把制作人的台词重复了一遍，一同尖叫，佑芽称赞广被信赖。佑芽说广的话缺少解释，她看了『選抜試験』的广的ライブ，像把真夏的太阳带进了真冬的舞台，问这个强烈印象从何而来。广说今天不说。佑芽宣布，夏『H.I.F』没能和广、千奈较量，『N.I.A』中被广完败，所以冬『H.I.F』要对广复仇，打倒千奈、星南、燕、姐姐，成为トップアイドル。广和千奈笑她，佑芽说被两人先走很寂寞。

## 行为模式
- 听恋爱般的故事 → 重复其中最甜的一句，并与千奈一起尖叫（0039、0040、0041）
- 觉得对方的说明不够 → 直接指出“解説が足りない”，自己说出看到的印象（0045～0049）
- 对手隐瞒秘密 → 不追问，反而半开玩笑（0054、0055）
- 宣战 → 先回顾过去未能较量的遗憾，再宣布复仇，范围是所有人（0060～0066）
- 被说“独自被抛下” → 说“さみしかったんだからね～？”（0073）

## 关系
- 広：称「広ちゃん」（0041、0045、0064）；広称她「佑芽」，说“さすが佑芽。本質をついてくる、ね”（広 0050）
- 千奈：称「千奈ちゃん」（0054、0065）；千奈称她「花海さん」（千奈 0053）
- 咲季、星南、燕：被列入“全員倒して”的名单（0065）

## 不确定
- 0039「トップアイドルにだって通用する。／そう信じていますよ――」：与制作人 0038 的台词逐字相同（只是句末标点不同），可能是佑芽在复述或模仿制作人，也可能是三人在转述；剧本没写明。0040「一同」「きゃあ～～～～～～～～～♡」之后佑芽 0041 才称赞广。
- 0040「一同」「きゃあ～～～～～～～～～♡」、0055「一同」「言えないくらい／恥ずかしいことなんだ～～～♪」：在场的是广、佑芽、千奈，先不算佑芽的台词，之后统一判定。0055 前后：佑芽 0054 叫“千奈ちゃん！”，千奈 0053 叫“花海さん！”。
- 0051～0052 广“ひみつ。今回だけは、言えない。”，0052 是括号内心话“（本気で競い合いたいから、ね）”，不是佑芽能听到的。
- 0062 佑芽说『N.I.A』里被广完败；同一条线第16话佑芽 0014 说“あたしの負けだね”，两处对得上；是哪一场オーディション本篇没说。
- 0061「夏の『H.I.F』では競えなかった」：广、千奈未能在夏『H.I.F』出场，与佑芽的关系本篇没有补充。
