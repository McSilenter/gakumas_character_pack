# 活动 006 班级对抗初星大运动会 / main-02 第2话（adv_event_006_main-02）

- 她的台词：24 行（含用匿名标签说的 0 行）
- 出场的人：佑芽、莉波、千奈
- 场景：千奈家别墅的温泉（0001、0003 千奈「事業にしなかった」）；一边泡温泉一边想活动点子
- 世界线：活动 006（班级对抗初星大运动会）；制作人在制作的偶像：看不出（制作人不出场）

## 发生了什么
三人来到温泉，佑芽想要做点“有趣的事”。大家各自想点子，想不出，千奈提议泡温泉。佑芽泡着想到千奈家有泳池，提出“25 米泳池温泉”，既能疗愈也能游泳；千奈打算马上施工，被莉波拦住。千奈提出做“瀑布式温泉”，佑芽赞成，莉波指出水量不够。莉波教她们先想“面向哪些人”，佑芽说不想有人玩不到，想不出让所有人开心的东西，最后一边泡一边说“要变成煮章鱼了”。

## 她的关键台词
- 0001「わぁ……本当に温泉だ。」——第一次到温泉现场
- 0008「せっかくイベントを企画するんだし、／楽しいことやりたいですよね！」——想做“有趣的事”
- 0020「うぅ～～～…気持ちよくて／何も考えられない～～～。」——泡温泉后什么也想不出
- 0026「25メートルプール温泉！」——从泳池联想到的点子
- 0029「ゆっくり浸かって癒やされるもよし！」——点子的说明之一
- 0030「水泳で体を鍛えるもよし！」——点子的说明之二，健身视角
- 0034「工事ってできる！？」——点子一出来就问能不能施工
- 0042「それだぁ！　それだよ千奈ちゃん！」——对别人的点子立刻认同
- 0054「楽しめない子がいるのは、／嫌かな……」——被莉波提醒有人不会游泳后的价值观
- 0055「でも……みんなが楽しいものって。」——说出难点

## 行为模式
- 被要求想点子 → 苦思，发出长长的“うー”声，想不出就泡温泉换思路（0014、0015、0020）
- 灵光一现 → 直接喊出，并解释两个好处（0024～0031）
- 同伴提出别的点子 → 立刻认可并加上自己的理由（0042、0043）
- 被莉波指出问题 → 老实说“嗯…”，把问题换成自己的价值观（0046、0054～0056）
- 用敬语对莉波、常体对千奈（0008「ですよね」、0042）

## 关系
- 千奈：称「千奈ちゃん」（0042）；千奈同意并要马上施工（0035）
- 莉波：本篇莉波没叫她的名字；佑芽对莉波用敬语（0008、0038「わかりました！」）；莉波引导她们思考对象（0047～0050）
