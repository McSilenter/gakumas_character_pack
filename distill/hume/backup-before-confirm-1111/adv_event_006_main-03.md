# 活动 006 班级对抗初星大运动会 / main-03 第3话（adv_event_006_main-03）

- 她的台词：19 行（含用匿名标签说的 0 行）
- 出场的人：莉波、千奈、佑芽
- 场景：千奈爷爷的别墅（0013 千奈「お爺様の別荘なのです」），泡完温泉后受款待，夜里（0035「夜はまだ始まったばかり」）
- 世界线：活动 006（班级对抗初星大运动会）；制作人在制作的偶像：看不出（制作人不出场）

## 发生了什么
千奈提供点心、茶、女仆按摩，还让大家留宿。莉波问大家泡温泉的乐趣在哪里，佑芽说游泳快乐的恐怕只有自己。千奈说着说着睡着了，佑芽觉得莉波很厉害，自己的点子问题太多，想让莉波全部包办；莉波说她和千奈的点子让人期待，自己的角色是在她们跑过头时拦住。佑芽听后决定继续想快乐的事，千奈其实醒着，也很受感动。

## 她的关键台词
- 0001「あーっ……気持ちよかったあぁぁ～。」——泡完温泉的直白感想
- 0014「わっ！　このお菓子、／すっごく甘い！」——被款待时坦率的感想
- 0027「お姉ちゃんと互角だぁ～……」——按摩舒服，拿姐姐（咲季）的按摩来比
- 0033「泳いで楽しい……のは／あたしだけかあ……」——承认游泳的乐趣不是所有人共有的
- 0040「……莉波先輩ってすごいですよね。」——对莉波称「莉波先輩」、用敬语
- 0041「あたしが考えたアイデア、／問題ばっかりで。」——承认自己的点子问题多
- 0043「いっそのこと、莉波先輩に／全部考えてもらった方が早いかも……？」——一时软弱地想把任务交给莉波
- 0049「でも、楽しいだけじゃ／ダメなんですよね？」——明白光有趣还不够
- 0054「……はい！　わかりました！」——被莉波说“只有你们才能做到”后重新振作
- 0055「すっごく楽しいこと、／もっと考えます！」——决定继续想有趣的点子

## 行为模式
- 被款待、被按摩 → 毫不拘谨地说舒服，并拿姐姐作比（0011、0014、0026、0027）
- 想不出好点子 → 先自我评价“全是问题”，一度想让前辈代劳（0041、0043）
- 被前辈肯定“只有你们能做到”→ 沉默复述后答“はい！”并更有干劲（0053～0055）
- 对千奈发现她醒着 → 惊讶，随后和她互相呼名鼓劲（0057、0060）

## 关系
- 莉波：称「莉波先輩」（0040、0043），用敬语；莉波叫她「佑芽ちゃん」（0039）；莉波夸她和千奈的点子让人期待（0044、0047）
- 千奈：称「千奈ちゃん」（0057、0060）；千奈叫她「花海さん」（0061）
- 姐姐：0027「お姉ちゃんと互角だぁ～……」——说的是按摩，姐姐会给她按摩的细节本篇没有说

## 档案类事实
- 游泳令她快乐：「泳いで楽しい……のは／あたしだけかあ……」（0033）
- 0027「お姉ちゃんと互角だぁ～……」是在按摩时说的，含义见“不确定”
- 对莉波用敬语、称先輩（0040）
