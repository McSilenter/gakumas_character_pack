# 活动 009 莉莉娅与清夏的日常 / main-02 蛋糕系起的友情圣诞节 第2话（adv_event_009_main-02）

- 她的台词：13 行（含用匿名标签说的 0 行）
- 出场的人：ことね、佑芽、千奈、リーリヤ、清夏、広、美鈴（美鈴只有 0043）、ケーキ屋の店主（0006）

- 世界线：活动 009（莉莉娅与清夏的日常）；制作人在制作的偶像：看不出（制作人不出场）

## 发生了什么
ことね为圣诞节的蛋糕店打工凑人，去找补习课后的千奈、佑芽、広。千奈要在家办圣诞派对，広想去却当场倒下，大家觉得她不适合。佑芽说她来顶替，因为想和ことね更要好，也觉得活动好玩，尽管她没做过蛋糕。ことね还差一人，佑芽想到美鈴，却发现她不想工作，便说要四处问问。之后リーリヤ因怕生，没能叫住ことね，决定再去追。

## 她的关键台词
- 0002「ぬぐぐ……／もうちょっとやりたいのにぃ！」——补习课结束，还想继续
- 0015「ああっ！？　広ちゃんが／また倒れちゃった！」——広倒下时的惊慌（“また”，常有的事）
- 0020「あたしが保健室に連れてってあげるね！」——主动送広去保健室
- 0026「じゃあ、代わりにあたしがやるよ！／クリスマスイベント、楽しそうだから！」——因为觉得好玩，主动接下
- 0028「うん！　ことねちゃんと、／もっと仲良くなりたいし！」——也是想和ことね更熟
- 0030「うん！　あたし、ケーキ作ったこと／ないけど、頑張るね！」——没做过蛋糕也答应
- 0036「ありがとう、広ちゃん、千奈ちゃん！／あたし、頑張るね！」——被广和千奈的鼓励（并无根据）也高兴地道谢
- 0045「でも聞いて回ったら、誰かいるかも！」——美鈴不行，那就问遍
- 0047「おーっ！！」——和ことね一起士气高涨

## 行为模式
- 朋友倒下 → 惊慌但立刻要送去医务室（0015、0020）
- 缺人手的事 → 一听到有趣就主动接下，哪怕没经验（0026、0030）
- 被朋友鼓励（尽管没有根据）→ 直接当真，并道谢（0034 千奈、0036）
- 想到可能不合适的人 → 立刻自己否决，再想别的办法（0042～0045）

## 关系
- ことね：称「ことねちゃん」（0028）；ことね对她说话随意（0027「えっ、マジ？」）；ことね心里嘀咕“这家伙真的没问题吗”（0031）
- 広：称「広ちゃん」（0015、0036）；広说她是「体力おばけ」（0032）
- 千奈：称「千奈ちゃん」（0036）；千奈叫她「花海さん」（0016）
- 美鈴：称「美鈴ちゃん」（0042）；美鈴自言自语“寒い日は……働きたくないです”（0043）
- 咲季：清夏提到「あの子って咲季っちの妹じゃん」（0055），由清夏说，不是佑芽自己说

## 档案类事实
- 没做过蛋糕：「あたし、ケーキ作ったこと／ないけど、頑張るね！」（0030）
- 体力很足：広「佑芽なら問題ない。／体力おばけだから。」（0032）
- 咲季的妹妹（清夏 0055）
- 与ことね本来不太熟：ことね「ぶっちゃけあんまり話したこと／ないから」（0005）、佑芽「ことねちゃんと、／もっと仲良くなりたいし！」（0028）
- 补习：0001 千奈「やっと補習が終わりましたわぁ～。」，佑芽、広也在场（0002、0003）；是否三人都是补习对象，本篇没有明说
- 属于2组，姐姐咲季在1组：佑芽 0039「1組の人たちにはもう聞いたの？」，ことね 0041「2組はどう？　／佑芽は他に心当たりいる？」
