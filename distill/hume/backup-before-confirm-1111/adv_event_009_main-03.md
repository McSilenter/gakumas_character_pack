# 活动 009 莉莉娅与清夏的日常 / main-03 蛋糕系起的友情圣诞节 第3话（adv_event_009_main-03）

- 她的台词：12 行（含用匿名标签说的 0 行）

- 场景：学园里，ことね和佑芽被リーリヤ叫住；之后店主来电（0041～0043，通过联络）

## 发生了什么
リーリヤ追上了ことね和佑芽，说想参加蛋糕店的打工。佑芽主动和她打招呼，说话时一点也不拘谨，对ことね“1组全灭”的说法也直接提出疑问，ことね承认忘了问清夏和リーリヤ。リーリヤ表示不介意，自嘲“影子很薄”，佑芽笑她有趣。三人确认打工，ことね问リーリヤ的动机，リーリヤ讲了对友人一起过圣诞的向往，也说想和ことね更要好，佑芽说“狡猾”，自己也想和她要好。

## 她的关键台词
- 0005「どうも、リーリヤちゃん！／何回か話したことあるよね！」——对话得不多的リーリヤ也主动打招呼，说“我们说过话”
- 0012「だから、これから仲良くなるんだよね！」——不熟只当作“还没开始”
- 0019「やったね、ことねちゃん！」——人手凑齐，替ことね高兴
- 0022「あれ、でも1組の人は全滅だって、／言ってなかったっけ？」——发现前后不一致就直接问
- 0025「ひどぉっ！？」——得知リーリヤ被忘了，替她抱不平
- 0033「あはははは！／リーリヤちゃん面白いね！」——リーリヤ的自嘲当成玩笑，高兴地笑
- 0039「ことねちゃん！／あたしも頑張るよ！」——要为活动出力
- 0045「まずは第一段階、クリアだね！」——应聘通过的说法
- 0062「ずるい～！　あたしも／リーリヤちゃんと仲良くなりたい！」——听到リーリヤ想和ことね要好，立即要求加入
- 0064「うん！　よろしくね、リーリヤちゃん！」——リーリヤ回话后爽快地结交

## 行为模式
- 只说过几句话的人 → 先打招呼，把“还没熟”当成“以后会熟”（0005、0012）
- 说法前后对不上 → 不假思索地问出口（0022）
- 别人自嘲 → 当成笑话大笑（0033）
- 听到别人想和谁要好 → 说“狡猾”，要求自己也算上（0062）

## 关系
- リーリヤ：称「リーリヤちゃん」（0005、0033、0062、0064）；リーリヤ叫她「佑芽ちゃん」（0006、0063）；两人不太熟（0009 リーリヤ「えっと、ちょっとだけ……？」）
- ことね：称「ことねちゃん」（0019、0039）；ことね觉得她“押しが強い”（0013）
- 清夏：本篇没有出场

## 不确定
- 0005「何回か話したことあるよね！」，0009 リーリヤ「えっと、ちょっとだけ……？」，0008 ことね「ふたりはあんま話したことないの？」：说过话的多少，两人说法有差，不算冲突。
