## 行为模式
- 姐姐炫耀自己玩得开心 → 先喊“なんだと”，再列出自己也有的快乐，不退让（0048、0053、0054）
- 姐姐把别的孩子比作“从前的自己” → 脸色一变，“ぐぬぬ”，骂姐姐是“ばか”（0059、0060）
- 吵到最后 → 转成自己的行动计划（用券和朋友去玩）（0061）
