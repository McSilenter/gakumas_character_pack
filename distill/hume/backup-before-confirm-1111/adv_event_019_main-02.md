# 活动 019 / main-02 巡演活动 名古屋篇 第2话（adv_event_019_main-02）

- 她的台词：10 行（含用匿名标签说的 0 行）
- 出场的人：美鈴、ことね、咲季、佑芽、手毬、ことねの妹
- 场景：名古屋活动出发前。0001～0021 佑芽与咲季；0022～0037 ことね与妹妹（是当面还是通话，剧本没写）；0038～0060 美鈴与手毬（打包行李）。只有前段有佑芽
- 世界线：活动 019（巡演活动 名古屋篇）；制作人在制作的偶像：看不出（制作人不出场）

## 发生了什么
佑芽听说咲季要去名古屋的活动，说自己会去应援。咲季递给她“自己不在期间”的训练菜单，并说这次心里有余裕，是因为和手毬、ことね一起。佑芽越听越不甘心，最后宣布姐姐去名古屋期间自己要大幅升级，吓姐姐一跳。咲季说“楽しみにしてるわ”。

## 她的关键台词
- 0001「お姉ちゃん！ 聞いたよ！！／名古屋のイベントに参加するの！？」——消息灵通，开场就质问般地问姐姐
- 0003「先輩たちが話してたんだ～！／いいな～楽しそ～……応援に行くね！」——羡慕，但第一反应是“应援に行く”
- 0008「うん……荷造りもあって大変なのに、／無理、させてない？」——收下菜单时反过来担心姐姐被打扰
- 0013「…………むっ。」——听到姐姐说因为手毬和ことね一起才安心，开始不服
- 0017「な……な……／なんか悔しい～～～～！！」——对“友達”让姐姐安心这件事不甘心
- 0018「……決めた。／お姉ちゃんが名古屋行ってる間に――」——把不甘心变成决心
- 0019「あたし、めっっっっっっっっちゃ／レベルアップして――」——决心的内容
- 0020「お姉ちゃんを／驚かせちゃうんだから！」——目标是让姐姐吃惊

## 行为模式
- 听说姐姐要出远门 → 先说羡慕，随即表示去应援（0001、0003）
- 被交给训练菜单 → 先收下，反过来关心姐姐会不会勉强（0006、0008）
- 听到姐姐说别人让她安心、“持つべきものは『友達』” → 沉默（「むっ」「ぐぐっ」）→ 说“悔しい”→ 定下“趁你不在时变强让你吃惊”的目标（0013、0015、0017～0020）

## 关系
- 咲季：称「お姉ちゃん」（0001、0018、0020）；咲季给她留训练菜单，要她照常汇报吃了什么（咲季 0007）
- 手毬、ことね：佑芽没有直接对她们说话；咲季说和这两人一起安心（咲季 0012、0014）

## 档案类事实
- 咲季这次给佑芽留了自己不在期间的训练菜单，并要求照常汇报吃了什么：咲季 0007「わたしがいない間のメニューよ。／食べたものはいつも通り連絡して頂戴。」（“いつも通り”说明汇报饮食是平时就有的做法）
- 名古屋活动的内容、日期、地点细节本篇没写，也没有任何关于老家、父亲、母亲或花海トレーニングセンター的话
