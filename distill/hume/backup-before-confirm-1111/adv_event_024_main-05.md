# 活动 024 / main-05 第5话（adv_event_024_main-05）

- 她的台词：16 行（含用匿名标签说的 0 行）；「一同」0025 另见“不确定”，不计
- 出场的人：星南、佑芽、美鈴、一同
- 场景：2月，『渋谷サウンドフェス』出场前的后台，之后（0026「――翌日。」）是次日，三人在外面，星南看着网上视频
- 世界线：活动 024；制作人在制作的偶像：星南是佑芽和美鈴的制作人（0018 佑芽「あたしたちのプロデューサーちゃん」，星南 0020「あなたたちのプロデューサー」）

## 发生了什么
出场前，星南在后台陷入回忆，佑芽叫她“もうすぐ出番ですよ”，三人一起出场唱『ENDLESS DANCE』。次日佑芽很兴奋，美鈴很困；星南发现网上有很多人唱『ENDLESS DANCE』，说是被佑芽的快乐表演影响，解开了曲子上的“呪い”。月村さん想在下次ライブ加入这首曲。星南说本想“継承する儀式”，却不想放手了，三人欣然。最后佑芽提议一起去唱歌。

## 她的关键台词
- 0010「もうすぐ出番ですよっ♪」——提醒星南出场
- 0017「そこがいいんですよ！」——星南 0016 觉得美鈴的话“褒められていない気がする”，佑芽反而说这样才好
- 0018「あたしたちのプロデューサーちゃんは、／普通のプロデューサーじゃ／ないんですから。」——对星南这位制作人的评价
- 0023「はい！　会場の皆さんに／ぶつけましょう。あたしたちの……」——出场前的号召
- 0029「ライブをすると、しばらくテンション／上がりっぱなしになっちゃうんだ。／美鈴ちゃんはなんで眠そうなの？」——说出自己ライブ后的状态
- 0042「えへへ～♪　それほどでも……／ありますけどぉ～♪」——被夸“解开了呪い”，先谦虚再认
- 0055「アイドルが好きな曲を歌わないなんて、／我慢できるわけないですよーっ。」——对星南“不放手”的看法
- 0058「おっ、じゃあ今日も教えてあげますね。／ライブ直後の遊び方を！」——要教星南放松
- 0062「これから一緒に歌いに行こ～～う♪」——提议去唱歌

## 行为模式
- 同伴/前辈发呆或走神 → 轻松提醒“出番”，不责备（0010）
- 被夸 → 先半谦虚，然后顺势“ありますけどぉ”，不推辞（0042）
- 兴奋过后 → 想继续玩（歌）并拉别人一起（0029、0058、0062）
