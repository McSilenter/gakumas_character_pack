# 活动 025 / main-03 第3话（adv_event_025_main-03）

- 她的台词：16 行（含用匿名标签说的 0 行）
- 出场的人：千奈、美鈴、佑芽
- 场景：休息日的作战会议（0001），三个一年级在讨论先辈慰劳会
- 世界线：活动 025；制作人在制作的偶像：看不出（制作人不出场）

## 发生了什么
佑芽宣布生徒会一年级的作战会议开始，请“次期生徒会長”千奈出议题。会议先讨论改善工作的办法，佑芽提议用スケジュールアプリ管理进度；然后讨论派对内容，佑芽提议组体操（美鈴认为那只是余兴），千奈提出用自己当偶像得到的报酬，亲手做饭招待前辈。佑芽赞同，说她进生徒会参加了各种企划后觉得“笑って進めた方が、みんなに楽しんでもらえる企画になる”。

## 她的关键台词
- 0001「あたしたち生徒会の一年生による！　／作戦会議をはじめまーっす♪」——自己担当开场
- 0002「次期生徒会長千奈ちゃん、／本日の議題をどうぞ！」——称千奈“次期生徒会長”
- 0006「うん！　素敵なパーティーにして、／先輩方に喜んでもらおうね！」——目标是让先辈开心
- 0011「うっ……」——被提醒“ふがいない仕事ぶり”时的痛处
- 0015「スケジュールアプリを使って、／仕事の進捗管理をするのはどうかな？」——自己的改进方案
- 0020「ありがとう～♪　／先輩方に提案できるように、／資料を準備するね！」——方案被接受后立即承担资料准备
- 0023「しちゃう？　3人で……組体操……」——仍想做组体操
- 0041「いいに決まってるよ！　／ね、美鈴ちゃん？」——千奈的提议一出，马上赞成并拉上美鈴
- 0053「あたしね、生徒会に入って、／色んな企画に参加して、思ったんだ。」——开始总结自己的体会
- 0054「笑って進めた方が、みんなに楽しんで／もらえる面白い企画になるって。」——她的做事原则

## 行为模式
- 被提醒自己做得不好 → 立刻露出“うっ”的痛处，但马上改谈改善案（0011、0013）
- 提出方案 → 用自己熟悉的做法（スケジュールアプリ）并接下具体工作（0015、0017、0020）
- 别人说出真诚的想法（千奈的手作料理）→ 毫不犹豫地赞成，并给予“いいに決まってる”（0037、0041）
- 讨论接近尾声 → 总结自己的信念：笑着做，企划才有趣（0052～0054）
