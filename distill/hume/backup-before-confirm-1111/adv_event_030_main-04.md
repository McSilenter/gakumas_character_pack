# 活动 030 我是、小恶魔♡ / main-04 第4话（adv_event_030_main-04）

- 她的台词：16 行（含用匿名标签说的 0 行）；其中 0044 是CM拍摄中的台词（演戏，不是她本人的话）
- 出场的人：リーリヤ、咲季、佑芽、スタッフ
- 场景：CM拍摄当天（0001「～撮影日、当日～」），摄影现场；先拍三人个别版，最后拍全员版
- 世界线：活动 030（我是、小恶魔♡）；制作人在制作的偶像：看不出（制作人不出场）

## 发生了什么
リーリヤ拍得不顺，咲季提议让她“演角色”，リーリヤ照做后过关。轮到佑芽，她把台词喊得很有力，被说“不太符合概念”。咲季说佑芽演不了妈妈，总是演爸爸；リーリヤ想到让佑芽想象被引诱的对象，佑芽理解成“好きな人”，说感觉能行，又突然害羞，咲季发现两人把她晾在了一边。

## 她的关键台词
- 0010「あたしたちもリーリヤちゃんを／サポートしないとね！」——先想到支持リーダー
- 0013「りょーかい！」——接受咲季“今天暂时休战”的提议
- 0044「この甘く華やかな香りで！／あなたもわたしに囚われちゃう！？」——（CM台词，演戏）有力的语气，被スタッフ叫停
- 0047「うぅぅ～～～……！！／なんかうまくいかないよ～！！」——失败后直接喊出来
- 0050「えへへ～、褒められちゃった。」——被リーリヤ夸“很强、很帅”后的反应
- 0056「いっつもお父さん役だったんだ！」——说出过家家时的角色
- 0063「あたしが誘惑する相手って……／つまり、好きな人ってこと！？」——抓住了想象的对象
- 0067「わかった！　いけそうな気がする！」——有了方法就马上说“能行”
- 0071「甘えて、誘惑する……うん。／イメージできてきた。」——自己整理出做法
- 0073「なんか、急に恥ずかしくなってきた！」——想到之后的害羞

## 行为模式
- 被要求“暂时休战” → 一句“りょーかい”接受（0011～0013）
- 演技不顺利 → 先喊出来，然后接受别人的建议（0047、0052）
- 被夸“强”（偏离概念） → 不介意，开心地收下夸奖（0049、0050）
- 听到具体的想象方法 → 马上抓住并自己延伸（“相手に甘える感じ”）（0063～0071）
- 开始实践前 → 突然害羞，但还是答应出发（0073、0076）
