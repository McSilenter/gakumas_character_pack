# 花海佑芽 培育事件 001 activity / 002 想跑步的佑芽（adv_pevent_001_hume_activity_002）

- 她的台词：9 行（含用匿名标签说的 0 行）
- 出场的人：佑芽、プロデューサー
- 场景：某天早上下雨之后（0003），地点看不出（室内，外面车流量大，0011 制作人）。0005～0007、0008～0010、0011～0014 是制作人不同回应后的三种并列走向
- 世界线：培育（花海佑芽）（培育事件 pevent_001）；制作人在制作的偶像：佑芽（0005、0008 制作人安排工作）

## 发生了什么
她坐立不安地哼哼，制作人问是不是身体不舒服；她说今天早上下雨没能跑步，问能不能出去跑一会儿（0001～0004）。
走向一：制作人说有时会有长时间不能动的工作，她说那现在就得习惯（0005～0007）。
走向二：制作人提议开下一个工作的会，她说好、也许能分散注意力（0008～0010）。
走向三：制作人说车多、大家会觉得奇怪，她懊恼；制作人改计划之后去河川敷，她高兴地道谢（0011～0014）。

## 她的关键台词
- 0001「むぐぐ……／うむむぅ……」——没运动就坐不住的哼哼
- 0003「今日の朝、雨が降ったせいで／ランニングできなくて……」——早上跑步是习惯
- 0004「ちょっと外を走ってきて／いいですかっ！」——想马上补跑
- 0007「じゃあ今から慣れておかないと／いけませんねっ！」——把“不能动”也当成要练习适应的事
- 0009「あ、それいいですねっ。／気が紛れるかも！」——用别的事分散想跑的念头
- 0012「それはそうですけど……／うぐぅ～っ！」——道理认了，身体还是想跑
- 0014「いいんですかっ！？／ありがとうございますっ！」——可以去河川敷跑时的高兴

## 行为模式
- 早上没能跑步 → 一整天浑身不自在，想马上补跑（0001、0003、0004）
- 被讲道理劝住 → 接受道理，转成“那就练习忍耐”或找别的事分散注意（0007、0009）；但会出声表示不甘（0012）
- 得到可以运动的安排 → 直率地高兴道谢（0014）

## 关系
- 制作人：本篇她没有直接称呼他；听从他的劝说，制作人为她改计划去河川敷（0013 制作人）

## 档案类事实
- 早上有跑步的习惯，下雨跑不了会难受（0003）
- 没运动时会坐立不安（0001、0004）

## 不确定
- 0002 制作人问是否身体不舒服，她没正面回答，直接说没跑步。
- 0013 去河川敷是去跑步还是别的，剧本没写，从语境推是让她跑。
