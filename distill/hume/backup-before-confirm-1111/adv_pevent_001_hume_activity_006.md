# 花海佑芽 培育事件 001 activity / 006 买东西（adv_pevent_001_hume_activity_006）

- 她的台词：14 行（含用匿名标签说的 0 行）
- 出场的人：佑芽、プロデューサー
- 场景：和制作人去购物（0001、0002 制作人），地点看不出。0006～0012、0013～0015、0016～0021 是制作人不同回答后的三种并列走向
- 世界线：培育（花海佑芽）（培育事件 pevent_001）；制作人在制作的偶像：佑芽（0008 制作人「普段がんばっているので」，0017 制作人说工作服）

## 发生了什么
她问今天是不是来购物，制作人让她猜买什么，她猜是绷带，说看到刚好用完了；制作人说制作人的工作用不到绷带（0001～0005）。
走向一：制作人说是给她买的、平时很努力、随便挑，她再三确认「なんでも」，兴奋地欢呼（0006～0012）。
走向二：制作人说补充需要的东西，她说自己最喜欢逛运动用品店（0013～0015）。
走向三：她问为什么，制作人说是买工作服，她问便服不行吗，明白是“像制服一样的东西”后说要认真挑（0016～0021）。

## 她的关键台词
- 0003「バンデージですね！／ちょうど切らしてると見ました！」——第一反应是运动用品
- 0007「…………あれ？／あたしに、ですか？」——没想到是买给自己
- 0009「な、なんでも……／いいんですかっ？」——被允许随便挑时的惊喜
- 0010「ほんとうに、なんでも！？」——再三确认
- 0012「おぉ～～～～～～～～～っ！」——兴奋
- 0015「あたし、スポーツ用品店を／見て回るのが大好きなんです！」——喜好
- 0018「私服じゃダメなんですか？」——对工作服没概念
- 0020「せんよう……／ユニフォームみたいなものですねっ。」——用运动的概念理解偶像的事
- 0021「わかりましたっ！／気合い入れて選びます！」——理解后马上有干劲

## 行为模式
- 猜别人要买什么 → 从运动用品去想（0003）
- 被送礼 → 先愣住确认是不是给自己，再兴奋地反复确认（0007、0009、0010）
- 遇到偶像工作上的新概念 → 换成运动里的说法理解（「ユニフォーム」，0020）

## 关系
- 制作人：称「プロデューサーさん」（0001）；制作人因为她平时努力要给她买东西（0008 制作人）

## 档案类事实
- 最喜欢逛运动用品店（0015）
- 她认为制作人用的绷带刚好用完了（0003），制作人否认工作上用绷带（0004 制作人）
- 还没有专用的工作服，之前想用便服（0017 制作人、0018）

## 不确定
- 0003「ちょうど切らしてると見ました」是说谁的绷带用完了（她的还是制作人的），从 0004 制作人回答看她以为是制作人要买，但读不准。
- 0011 制作人心里「なにを買うつもりなんだ……？」之后她选了什么剧本没写。
