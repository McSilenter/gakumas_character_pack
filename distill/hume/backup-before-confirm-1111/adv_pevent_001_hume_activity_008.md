# 花海佑芽 培育事件 001 activity / 008 同班同学（adv_pevent_001_hume_activity_008）

- 她的台词：10 行（含用匿名标签说的 0 行）
- 出场的人：プロデューサー、佑芽
- 场景：地点看不出；制作人问她和篠澤、倉本的关系（0001 制作人）。0003～0009、0010～0015、0016～0019 是三种并列走向
- 世界线：培育（花海佑芽）（培育事件 pevent_001）；制作人在制作的偶像：佑芽（0001 制作人「佑芽さんは」）

## 发生了什么
制作人说她和篠澤、倉本关系好，她说上课时总在一起（0001、0002）。
走向一：制作人问怎么变要好的，她说因为入学考试成绩都很差；但大家都在努力，约好三人都要出道成为偶像，她说要把大家都甩在后面（0003～0009）。
走向二：制作人说以后三人都出道、上谈话节目时把这段过去讲出来会是武器，她说好主意、要和大家练习谈话；制作人说还早（0010～0015）。
走向三：制作人说“曾经考试吊车尾的顶级偶像”是完美的故事，她说那大家必须一起成为顶级偶像（0016～0019）。

## 她的关键台词
- 0002「はいっ！／レッスンではいつも一緒です！」——和两人的关系
- 0004「入学試験の成績がダメダメ／だったからですね！」——三人要好的缘由，毫不避讳
- 0006「でも、みんなで／がんばってるんですよっ！」——不以此为耻
- 0007「3人ともデビューして、／アイドルになろうねって。」——三人的约定
- 0009「任せてくださいっ！／みんなゴボウ抜きですよ！」——干劲
- 0013「今度、みんなでトークの／練習しておきますねっ！」——马上想行动
- 0018「それならみんなでトップアイドルに／ならないといけませんね！」——目标拉到顶级偶像

## 行为模式
- 被问到不光彩的过去（入学考试成绩差）→ 直接、开朗地说出来，并接上“但我们在努力”（0004、0006）
- 听到好点子 → 马上说要去练（0012、0013）
- 被描绘远大故事 → 顺势把目标定为“大家一起成为顶级偶像”（0018、0019）

## 关系
- 篠澤（広）、倉本（千奈）：制作人用姓称呼（0001 制作人）；她说上课总在一起（0002），因入学考试成绩差而要好（0004），约定三人都出道（0007）。本篇她没有直接叫两人的名字
- 制作人：称「プロデューサーさん」（0012）

## 档案类事实
- 和篠澤、倉本关系好，上课总是在一起（0001 制作人、0002）
- 三人入学考试成绩都很差（0004），因此要好
- 三人约定都要出道成为偶像（0007）
- 文件名是“同班同学”

## 不确定
- 0004「入学試験の成績がダメダメ」是三人都差，还是她自己差，读起来是三人都差，但没逐个说。
- 文件名“同班同学”是中文译名；正文没说三人同班，只说上课在一起（0002）。
- 【译文】0001 trans 写成“琴音，你和篠澤还有倉本关系很好吧”，原文是「確か佑芽さんは、篠澤さんや／倉本さんと仲がよかったですよね。」，称呼对象是佑芽，不是ことね。
