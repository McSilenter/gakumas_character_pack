# 花海佑芽 培育事件 001 activity / 010 大海与高山（adv_pevent_001_hume_activity_010）

- 她的台词：12 行（含用匿名标签说的 0 行）
- 出场的人：佑芽、プロデューサー
- 场景：地点看不出；她向制作人做“海还是山”的调查（0001、0003）。0005～0008 是制作人答“山”的走向；0009～0012、0013～0016 是制作人答“海”或类似回答的走向（选项不在剧本里）
- 世界线：培育（花海佑芽）（培育事件 pevent_001）；制作人在制作的偶像：佑芽（同目录培育事件）

## 发生了什么
她突然问制作人海和山选哪个，说是采访、别多想（0001～0004）。
制作人答山时，她不甘心地哼哼；制作人问为什么，她说在和姐姐比谁那边人多，制作人心里无语（0005～0008）。
另一走向：她确认“真的吗”，笑着说果然是海，道谢后走了，制作人不知道到底是什么调查（0009～0012）。
再一走向：她说和自己一样、是海，欢呼，说制作人知道她喜欢哪边（0013～0016）。

## 她的关键台词
- 0001「プロデューサーさんっ！／海と山ならどっちですかっ！」——突然开始调查
- 0003「インタビューですっ。／深く考えずに答えてください。」——当“采访”
- 0005「山っ！？／うぐぐぐぐ～っ……」——对方选了另一边就不甘心
- 0007「どっちが多いか、お姉ちゃんと／勝負してるんです。」——和姐姐的胜负连调查都算
- 0010「にへへへ～♪／そうですよね、海ですよねっ。」——选海时高兴
- 0014「海！　海ですっ！／やりーっ！」——欢呼
- 0016「あたしの好きな方、／知ってたんですね！」——她喜欢海

## 行为模式
- 和姐姐比赛 → 连“海派还是山派”的人数也拿来比（0007）
- 对方选了自己那边 → 欢呼，觉得对方懂自己（0014～0016）；选了另一边 → 「うぐぐ」不甘心（0005）
- 做调查时 → 不先说明目的，问完就走（0003、0011）

## 关系
- 姐姐：称「お姉ちゃん」（0007）；和姐姐比海派、山派谁多（0007），从 0016 看她是海派，姐姐那边是山
- 制作人：称「プロデューサーさん」（0001、0015）

## 档案类事实
- 她喜欢海胜过山（0013、0014、0016）
- 和姐姐比“海和山哪边的人多”（0007）

## 不确定
- 姐姐是山派是从 0005 她对“山”不甘心推出来的，剧本没明说姐姐选山。
- 0009「ホントですかっ？」前制作人的回答不在剧本里，可能是答“海”。
