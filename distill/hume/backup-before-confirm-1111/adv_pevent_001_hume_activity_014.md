# 花海佑芽 培育事件 001 activity / 014 给咲季的礼物（adv_pevent_001_hume_activity_014）

- 她的台词：15 行（含用匿名标签说的 0 行）
- 出场的人：佑芽、プロデューサー
- 场景：和制作人去给姐姐买礼物（0001），地点看不出（有食品区，0020）。0006～0010（品牌）、0011～0015（花）、0016～0020（姐姐的果汁）是三种并列走向
- 世界线：培育（花海佑芽）（培育事件 pevent_001）；制作人在制作的偶像：佑芽（同目录培育事件）

## 发生了什么
她宣布要给姐姐买礼物，说制作人是大学生，请他用有品位的礼物让姐姐吃惊；制作人心里觉得她误解了大学生（0001～0005）。
品牌：她怀疑姐姐有没有兴趣，想到运动品牌姐姐会高兴，但制作人说那不会吃惊，她说不吃惊就不行、换别的（0006～0010）。
花：制作人提议以两人形象选花，她说绝对会吃惊，还期待自己会是什么花（0011～0015）。
姐姐的果汁：制作人说她来做姐姐的果汁姐姐会吃惊，她说之后肯定会被狠狠吐槽，但要挑战，去食品区（0016～0020）。

## 她的关键台词
- 0001「とゆーわけで、お姉ちゃんへの／プレゼントを買いますっ！」——给姐姐买礼物
- 0003「プロデューサーさんって、／大学生じゃないですか！」——她认为制作人是大学生
- 0004「センスのいいプレゼントで、／お姉ちゃんをビックリさせてください！」——要让姐姐吃惊
- 0006「ブランドですかー。／お姉ちゃん、興味あるかな。」——不确定姐姐对品牌有没有兴趣
- 0007「あ！　スポーツブランドなら／喜びそうです！」——姐姐喜欢运动品牌
- 0010「……驚かないならダメですよっ！／違うものにしましょう！」——重点是让姐姐吃惊
- 0013「いいと思いますっ！／ぜっっっっったいにビックリします！」——对“让姐姐吃惊”的方案很起劲
- 0015「あたしってどんな花なのかなー。／楽しみですっ♪」——期待自己的形象花
- 0018「多分、そのあとにものすごい／ツッコミが入りそうですねー。」——预料姐姐的反应
- 0019「でもやってみましょう！／チャレンジあるのみです！」——口头禅式的挑战宣言

## 行为模式
- 给姐姐送礼 → 把“让姐姐吃惊”放在第一位，不吃惊就换（0004、0010）
- 预料姐姐会吐槽 → 也还是去做（0018、0019）
- 新提议 → 「チャレンジあるのみです！」（0019）

## 关系
- 姐姐：称「お姉ちゃん」（0001、0006）；想用礼物让她吃惊（0004）；认为她喜欢运动品牌（0007）；料到她会对自己做的果汁狠狠吐槽（0018）；姐姐有自己的“果汁”（0016）
- 制作人：称「プロデューサーさん」（0003）；她认为制作人是大学生（0003），制作人心里没否认，只说她误解了大学生（0005 制作人）

## 档案类事实
- 她说制作人是大学生（0003），制作人心里「大学生を誤解している気がするが」（0005 制作人）
- 她不确定姐姐对（名牌）品牌有没有兴趣（0006），觉得运动品牌姐姐会喜欢（0007）
- 姐姐有招牌的果汁（0016「お姉ちゃんのジュース」），从 activity_007 看可能就是姐姐做的饮料（不同篇，未证实）

## 不确定
- 0016「お姉ちゃんのジュース」是姐姐做的那种饮料（activity_007 里姐姐做的发光饮料，那篇 0005 用的词是ドリンク）还是别的，本篇没说。
- 礼物的缘由（生日之类）本篇没说。
