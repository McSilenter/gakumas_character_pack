# 花海佑芽 培育事件 001 activity / 015 最喜欢的姐姐（adv_pevent_001_hume_activity_015）

- 她的台词：10 行（含用匿名标签说的 0 行）
- 出场的人：佑芽、プロデューサー
- 场景：地点看不出；她刚和姐姐拍了大头贴（0003）。0004～0008、0009～0012、0013～0016 是制作人不同回应后的三种并列走向
- 世界线：培育（花海佑芽）（培育事件 pevent_001）；制作人在制作的偶像：佑芽（同目录培育事件）

## 发生了什么
她哼着歌，制作人说她今天特别开心，她说和姐姐拍了大头贴（0001～0003）。
走向一：制作人心里说和比赛时的两人大不一样；她说因为是姐姐嘛，非常喜欢、也非常想打倒，是她引以为傲的姐姐（0004～0008）。
走向二：制作人提到两人平时在比胜负，她说那很正常、一直这样，输了不甘心但还是最喜欢姐姐（0009～0012）。
走向三：制作人说和姐姐同一个年级很少见，她说每年都被问是不是双胞胎，但也就大家吃惊一下，她完全不在意（0013～0016）。

## 她的关键台词
- 0003「えへへ～♪／お姉ちゃんとプリ撮ったんです。」——和姐姐拍大头贴
- 0005「はいっ！／だってお姉ちゃんですもん。」——理所当然地喜欢
- 0006「とっても大好きで、／と～～～～っても倒したい人！」——对姐姐的两面感情
- 0007「あたしの自慢の／お姉ちゃんですっ♪」——以姐姐为傲
- 0010「そんなの普通ですよ。／ずっとやってますし。」——胜负是日常
- 0011「負けるのは悔しいです！／でもお姉ちゃんは大好きです！」——输的不甘和喜欢并存
- 0014「毎年、聞かれるんですよね。／双子なのって。」——同年级被问是不是双胞胎
- 0016「ぜーんぜん、気になりません♪」——不在意

## 行为模式
- 和姐姐一起玩过 → 一整天哼歌、心情好（0001～0003）
- 被问和姐姐的胜负关系 → 说一直这样、很正常；把“想打倒”和“最喜欢”同时说出来（0006、0010、0011）
- 被问同年级的特殊处境 → 轻描淡写，说不在意（0015、0016）

## 关系
- 姐姐：称「お姉ちゃん」（0003、0007、0011）；「とっても大好きで、／と～～～～っても倒したい人！」（0006），「自慢の／お姉ちゃん」（0007）；平时一直在比胜负（0009 制作人、0010）；会一起拍大头贴（0003）
- 制作人：本篇她没有直接称呼；制作人心里说两人「裏表のない関係」（0012 制作人）

## 档案类事实
- 和姐姐一起拍大头贴（0003）
- 和姐姐同一个年级（0013 制作人），每年都被问是不是双胞胎（0014）；她完全不在意（0016）
- 和姐姐一直在比胜负（0010）

## 不确定
- 0014 只说每年被问「双子なの」，她没有正面说两人是不是双胞胎；0013 制作人「お姉さんと同じ学年というのは／珍しい」看起来是说姐妹不是双胞胎却同年级，但本篇没明说原因。
- 0014「毎年」从什么时候开始（小学起？）没说。
