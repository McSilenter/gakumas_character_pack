# 花海佑芽 培育事件 001 activity / 018-02 为了放松一下（adv_pevent_001_hume_activity_018-02）

- 她的台词：17 行（含用匿名标签说的 0 行）
- 出场的人：佑芽、プロデューサー
- 场景：卡拉 OK，制作人唱完一首之后（0001）；018 的分支 02。0004～0006 之后接 0007～0013、0014～0023 等并列走向（0006 与 0014 同句，是不同分支的起点）
- 世界线：培育（花海佑芽）（培育事件 pevent_001）；制作人在制作的偶像：佑芽（0012「あたしをプロデュース」）

## 发生了什么
制作人唱完，她说很帅；制作人让她唱，她提议合唱，说一起唱更开心（0001～0006）。
走向一：唱完她说不是很好吗，制作人说被她带着走了；她说是制作人有唱歌的才能，叫他进偶像科一起当偶像，随即想到那样就不能制作自己了，收回这话，请他以后继续关照（0007～0013）。
走向二：制作人呛到咳嗽，她慌了，叫他别说话、喝水，然后冷敷患处、贴扎；制作人说合唱下次，她说小气，强调约好了下次（0014～0023）。

- 0002「おおー……／かっこよかったですよ！」——夸制作人唱歌

- 0005「一緒に歌ったら／もっと楽しいですよっ！」——一起才开心
- 0009「いえいえいえ、これはきっと、／才能あるんですよ！」——把功劳推给制作人
- 0011「アイドル科に入って、／一緒にアイドル目指しましょう！」——邀制作人当偶像
- 0012「あ……でもあたしをプロデュース／できなくなるのかな……？」——想到会失去制作人
- 0013「やっぱり今の話はナシで！／これからもお願いしますっ！」——还是要他当自己的制作人
- 0018「喋ったら酷くなるから、／お水飲んでください！」——照顾
- 0019「あとは患部を冷やして……／テーピングですっ！」——用运动伤的处理方式应对咳嗽
- 0021「えーっ。／プロデューサーさんのケチー。」——撒娇式抱怨
- 0023「やーくーそーく、／しましたからねっ！」——强调约定

## 行为模式
- 一起玩 → 想拉对方一起（合唱），觉得一起才开心（0004、0005）
- 夸人 → 毫不保留，甚至劝对方当偶像；想到对自己不利就立刻收回（0011～0013）
- 对方身体不适 → 马上照顾，用运动伤的处理法（冷敷、贴扎）（0018、0019）
- 被推迟 → 说「ケチー」，再要对方确认约定（0021～0023）

## 关系
- 制作人：称「プロデューサーさん」（0012、0016、0021）；不想失去他当自己的制作人（0012、0013）；和他约好下次合唱（0022、0023）

## 档案类事实
- 学园有「アイドル科」（0011）
- 会用冷敷、贴扎处理问题（0019，她套用在咳嗽上）
