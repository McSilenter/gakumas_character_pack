# 花海佑芽 培育事件 001 activity / 019 佑芽的父母（adv_pevent_001_hume_activity_019）

- 她的台词：11 行（含用匿名标签说的 0 行）
- 出场的人：佑芽、プロデューサー
- 场景：地点看不出；制作人已经见过她的「お母さんたち」之后（0001）。0006～0011、0012～0015、0016～0020 是三种并列走向
- 世界线：培育（花海佑芽）（培育事件 pevent_001）；制作人在制作的偶像：佑芽（0004 制作人「佑芽さんのプロデューサー」）

## 发生了什么
她提起制作人见过了她的「お母さんたち」，制作人说没想到这么容易就见到；她说自己也惊讶，因为她们平时总是很忙（0001～0003）。制作人说大概因为自报是佑芽的制作人，她害羞地笑（0004、0005）。
走向一：她问制作人觉得怎么样，制作人说她们支持以偶像为目标的佑芽她们，还给了一大堆关于排日程的资料；她说平时可是很严厉的，惊叹制作人能跟上她们的话（0006～0011）。
走向二：制作人说果然出色、有很多值得学习的地方，她慌忙说严厉的地方不用学（0012～0015）。
走向三：制作人说虽有偶像和运动员的差别，她们作为一个领域的专业人士跟他谈，很有参考价值；她说自己只觉得在讲很难的东西，说能这么想的制作人也很厉害（0016～0020）。

## 她的关键台词
- 0001「そういえばプロデューサーさん、／お母さんたちに会ったんですよね。」——制作人见过了她家长
- 0003「実はあたしも驚いたんです。／いつも忙しそうにしてるのに……」——家长平时很忙
- 0005「そ、そうなんですかね……えへへ。」——听到家长因她才见制作人，害羞高兴
- 0009「えへへへへぇ……／普段は厳しいんですよ？」——家长平时严厉
- 0010「お母さんたちの話に／ついていけるなんてっ！」——家长的话题她跟不上
- 0014「ちょちょちょちょお～～っと！」——慌张
- 0015「厳しいところは真似しなくて／いいですからねっ！」——不想制作人学严厉的地方
- 0019「あたし、難しいこと言ってるなー／としか思ってなかったんで……」——她对家长专业话题的感受

## 行为模式
- 听到家长在支持自己 → 害羞地笑（0005、0009）
- 制作人说要向家长学习 → 慌忙阻止他学严厉的部分（0014、0015）
- 自己听不懂的专业话 → 坦白只觉得很难，转而夸制作人（0019、0020）

## 关系
- 「お母さんたち」：她这样称呼（0001、0010）；平时总是很忙（0003），平时严厉（0009），讲的东西她觉得难（0019）；据制作人说支持以偶像为目标的佑芽她们，给了制作人大量排日程的资料（0007、0008 制作人），以某个领域的专业人士身份跟他谈（0016、0017 制作人）
- 制作人：称「プロデューサーさん」（0001、0006、0020）；能见到她家长是因为自报是她的制作人（0004 制作人）

## 档案类事实
- 她称家长为「お母さんたち」（0001、0010），平时总是很忙（0003）、严厉（0009）
- 制作人见过她的家长（0001、0002）；家长给了大量关于排日程的资料（0008 制作人）
- 制作人说「アイドルとアスリートの違いは／あれど……」「一つの分野のプロとして」（0016、0017 制作人）——家长是运动（アスリート）方面的专业人士（制作人的说法）
- 家长支持「アイドルを目指す佑芽さんたち」（0007 制作人）——「たち」可能包括姐姐

## 不确定
- 「お母さんたち」是母亲一人加上别人（父母双方？家里其他人？）还是别的，本篇没说；有没有父亲出场也没写。前几批的花海社長、花海トレーニングセンター、花海女史等线索本篇都没出现，不能对上。
- 0016 只说“偶像和运动员的差别”，家长具体是运动员、教练还是经营者，本篇没说。
- 0007「佑芽さんたち」的「たち」是否指姐姐，本篇没点名。
- 【译文】0007 trans“我一直都在支持着以偶像为目标的佑芽她们哦”主语译成了“我”；原文「アイドルを目指す佑芽さんたちを／応援していましたよ。」是制作人转述家长在支持她们。
