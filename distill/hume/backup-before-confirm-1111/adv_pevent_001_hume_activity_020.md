# 花海佑芽 培育事件 001 activity / 020 替补合格（adv_pevent_001_hume_activity_020）

- 她的台词：12 行（含用匿名标签说的 0 行）
- 出场的人：プロデューサー、佑芽
- 场景：地点看不出；制作人问起她是补缺合格入学的（0001 制作人）。0004～0009、0010～0014、0015～0018 是三种并列走向
- 世界线：培育（花海佑芽）（培育事件 pevent_001）；制作人在制作的偶像：佑芽（0007、0012 制作人评价她的成长）

## 发生了什么
制作人问她是不是补缺合格，她爽快地说是，因为有人辞退入学才进来的，惊险过关（0001～0003）。
走向一：她问为什么问这个，制作人说不管是不是补缺，入学了就是偶像候补生，之后靠实力，是她的强项；她说不知道是不是强项，但干劲不输任何人（0004～0009）。
走向二：制作人说差点就诞生不了未来的顶级偶像，说看她现在的进步忍不住期待；她得意地说“果然我是好物件吧”（0010～0014）。
走向三：制作人说之后成绩大涨、让他们刮目相看，她说要让姐姐、考试的评审，所有人都大吃一惊（0015～0018）。

## 她的关键台词
- 0002「はいっ！　入学辞退した人が／いたので、入学できました！」——补缺合格的经过
- 0003「ギリギリセーフですっ！」——毫不在意地说出来
- 0008「得意……かどうかは／わかりませんけど。」——对自己的实力没把握
- 0009「やる気だけは、／誰にも負けないですっ！」——自认的长处
- 0011「えへへへぇ……／急にどうしたんですか？」——被夸时害羞
- 0014「やっぱりあたし、／いい物件でしたっ！？」——得意时的说法
- 0017「お姉ちゃんも、試験の審査員も、／みんなみんな……」——想让人刮目相看的对象，姐姐在最前
- 0018「びっくりさせてやりますっ！」——逆袭宣言

## 行为模式
- 被提到补缺入学 → 不当回事，开朗地说「ギリギリセーフ」（0002、0003）
- 被说实力是强项 → 先说不知道，再说干劲不输任何人（0008、0009）
- 被夸有前途 → 害羞后马上得意（0011、0014）
- 被鼓励逆袭 → 把姐姐和评审一起列为要让其吃惊的人（0017、0018）
