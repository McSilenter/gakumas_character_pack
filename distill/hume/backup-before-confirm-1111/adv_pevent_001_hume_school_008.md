# 花海佑芽 培育事件 001 school / 008 季语（adv_pevent_001_hume_school_008）

- 她的台词：8 行（含用匿名标签说的 0 行；8 行全是括号里的心声）
- 出场的人：国語教師、佑芽
- 场景：国语课上，老师点「花海」答季语题（0004 国語教師）。0007～0012（答对）、0013～0018、0019～0023（答错）是制作人代答后的三种并列走向（她心里求救，0006）
- 世界线：培育（花海佑芽）（培育事件 pevent_001）；制作人在制作的偶像：佑芽（0006 她心里向制作人求救）

## 发生了什么
国语老师讲季语和旧历，点她回答西瓜、十一月、夏天的天空哪个是秋天的季语（0001～0004）。她心里不知道，向制作人求救（0005、0006）。
答对的走向：老师解释西瓜好吃的八月在二十四节气里属于立秋；她心里说真复杂，但记住也许有用（0007～0012）。
答错的走向一（十一月）：老师说十一月有立冬，旧历是冬天；她心里说古代季节感觉和现在完全不同、西瓜是秋天好奇怪（0013～0018）。
答错的走向二（夏天的天空）：老师说本以为是明显的错误选项，还说「スイカ割り」是夏天季语、考试会考；她心里慌，又把西瓜是夏是秋搞混了（0019～0023）。
