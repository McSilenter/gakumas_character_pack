# 花海佑芽 培育事件 003 activity / 022 想和鱼儿一起游泳！（adv_pevent_003_hume_activity_022）

- 她的台词：12 行（含用匿名标签说的 0 行）
- 出场的人：佑芽、プロデューサー
- 场景：水族馆（0002）。0001～0005 共用，之后是三种并列走向：0006～0010（能和鱼一起游的泳池，大多在国外）、0011～0015（去海里体验潜水）、0016～0020（水族馆的宣传合作企划）
- 世界线：培育（花海佑芽）（培育事件 pevent_003）；制作人在制作的偶像：佑芽（0016、0018 制作人要替她向水族馆提企划）

## 发生了什么
她在水族馆看到很多有趣的鱼，对制作人说水族馆真有意思（0001、0002）。她说这里的鱼都游得很舒服，好羡慕，她也想进水槽一起游（0004、0005）。
走向一：她问“可以吗！？”（0006），制作人说这里不行，但有能和鱼一起游的泳池，大多在国外（0007、0008）；她说那等她去国外开 live 时带她去，为了和鱼游泳也要实现海外 live（0009、0010）。
走向二：制作人说去海里体验潜水能有类似的经历（0011），她说真的吗，想去海边（0012、0013），说和制作人一起去，像个小旅行（0014）；制作人说日程定了就通知她（0015）。
走向三：制作人说如果水族馆的宣传合作企划通过，也许能作为工作体验去游（0016），她说想做（0017）；制作人说去提案（0018），她说为了在和鱼的游泳比赛里不输，要特训（0019）；制作人提醒提的可是工作体验（0020）。

## 她的关键台词
- 0002「プロデューサーさん！／水族館って面白いですねっ！」——在水族馆兴奋
- 0005「いいな～。あたしも水槽に入って、／一緒に泳ぎたいな～。」——想和鱼一起游
- 0009「だったらっ！　あたしが海外で／ライブする時に連れていってください！」——把愿望和海外 live 连在一起
- 0010「よーし、魚たちと泳ぐためにも、／海外ライブ実現させるぞー！」——海外 live 的目标
- 0013「行きたい、行きたい！／海行きたいですっ！」——想去海边
- 0014「えへへ、プロデューサーさんと行く、／ちょっとした旅行みたいですね♪」——和制作人出去像旅行
- 0019「よ～し、魚たちとの泳ぎ勝負に／負けないために、特訓するぞっ！」——和鱼一起游也变成比赛

## 行为模式
- 看到别的东西舒服地动 → 自己也想加入（0004、0005）
- 有新愿望 → 马上和偶像目标挂钩（“为了这个也要实现海外 live”）（0009、0010）
- 能一起游泳的机会 → 擅自变成“和鱼比游泳”，要为不输而特训（0019）；被制作人提醒只是工作体验（0020）
- 和制作人一起出去 → 高兴地说像小旅行（0014）

## 关系
- 制作人：称「プロデューサーさん」（0002、0009、0014）；要他在海外 live 时带她去（0009）；说和他去像小旅行（0014）；制作人说要替她向水族馆提企划（0018）

## 档案类事实
- 她想和鱼一起游泳（0005）
- 她说要实现海外 live（0010）
- 她想去海边（0013）
