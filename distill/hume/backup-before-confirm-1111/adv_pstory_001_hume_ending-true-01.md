# 花海佑芽 培育剧情 001 / ending-true-01 True End（adv_pstory_001_hume_ending-true-01）

- 她的台词：32 行（含匿名标签 0 行）
- 出场的人：佑芽、プロデューサー
- 场景：她取得「大勝利」之后（0003），跑来向制作人报告；这是结局分支 True End；地点看不出
- 世界线：培育（花海佑芽）001；制作人在制作的偶像：佑芽（0024「あたしを勝てるようにしてくれて」，0028 当初请他制作自己）

## 发生了什么
她大喊着跑来，宣布“花海佑芽大胜利”。她说自己总是渴望胜利，今天久违地吃饱了，非常满足；（并列反应）又说一定很快又会饿，再来多少碗都不够。（并列反应）她说有人在最前排看着，等会儿要好好被夸。她郑重地说今天的胜利多亏了制作人；制作人说是她的实力，她说这份力量一个人也得不到——制作人、训练师、姐姐、同学和朋友，教她怎么努力的人和强大的对手，大家在才走到这里，其中制作人是特别的，谢谢他让她能赢。她问还记得初次见面吗：她非常强硬地上前说“请你制作我好吗”，制作人说当时吓了一跳，她说这是她人生最好的妙传。她说最喜欢制作人，从相遇那刻起就喜欢，现在是大大大大最喜欢，请今后也帮她，一直一起赢下去。

## 行为模式
- 赢了 → 全力跑来报告、欢呼（0001～0003），用“饿”“吃饱”“再来一碗”说对胜利的渴望（0006～0011）
- 胜利之后 → 郑重地把功劳归给身边的人，再单独感谢制作人（0016～0024）
- 回顾相遇 → 带点得意地说起自己当初强行接近（0026～0031），直接把“最喜欢”说出口（0032～0034）

## 关系
- 制作人：称「プロデューサーさん」（0001、0015、0035），也用「あなた」（0016）；她说初次见面时强硬地请他制作自己（0027、0028），他说当时吓了一跳（0030 制作人）；说从相遇那刻起就喜欢他（0033），他是特别的（0022）
- 咲季：称「お姉ちゃん」；列为帮她走到这里的人之一（0019）
- トレーナー、同学和朋友、强大的对手：同样列为帮她走到这里的人（0019～0021）

## 档案类事实
- 培育 001 线里，是她在初次见面时主动、强硬地请制作人制作自己（0026～0029）；她说这是人生最好的妙传（0031）
- 她说自己总是渴望胜利（0006），今天是「久しぶりに」吃饱（0007）
- 她有同学和朋友（0019）
