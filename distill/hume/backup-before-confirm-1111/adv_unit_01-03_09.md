# 主线 第1部 3章 我们是Re;IRIS / 3章9话（adv_unit_01-03_09）

- 她的台词：17 行（无匿名标签；另有『一同』0027 未计入，见「不确定」）
- 出场的人：ことね、手毬、佑芽、咲季、プロデューサー
- 场景：选拔考试前的特训期间；手毬教歌、之后ことね等人在场聊她
- 世界线：主线；制作人在制作的偶像：咲季、ことね、手毬（0066～0074 制作人发表 Re;IRIS 的团名）

## 发生了什么
特训开始，手毬指导她用腹肌控制呼吸，嫌她记性太差，决定自己示范。她称手毬「手毬先生」。咲季和ことね在旁聊手毬教得变好了、咲季的舞也进步了。ことね说这样下去选拔考试没问题，她说现在的我赢不了会长，一同惊讶。再被问，她说要抱着必胜的心去挑战，赢了就尽情高兴，输了就哭。咲季说这才是胜负。制作人到场发表团名『Re;IRIS』。

## 她的关键台词
- 0012「はい！　手毬先生！！」——对手毬的称呼，是教她的老师
- 0025「ううん、まだまだだよ！　いまのあたしの実力じゃ――」——被说选拔能过时，先否定
- 0026「十王会長には勝てっこない！」——直接说现在赢不了会长（接着一同惊讶）
- 0031「もっちろん！　あ、もちろん選抜試験は、会長との」——被问想赢会长吗时回答
- 0035「だから……選抜試験は、やっぱり勝負なんだよ！」——考试对她是胜负
- 0036「あたしと会長の、真剣勝負！！」
- 0048「どんなに勝ち目がなさそうでも、」——被ことね追问是否有底气，开始说自己的态度（接 0049）
- 0049「最初から負けるつもりで挑むのは嫌だ。」——一开始就想着输的挑战，她不做
- 0051「勝ったら思い～～っきり喜ぶんだっ。」——赢了就完全地高兴
- 0053「泣くよ。悔しいもん。」——被问输了会怎样，直接回答

## 行为模式
- 被说应该能过 → 先老实否定实力不够，但同时坦白想赢（0025、0026、0031）
- 被追问真的想赢吗 → 不改口，解释：不管多没胜算都以必胜的心挑战，赢就喜，输就哭（0047～0053）
- 自己的挑战被周围误解（手毬、ことね觉得「可能性を見せろ」只是让星南认可） → 仍按自己的理解，把考试当胜负（0033～0036）
- 被老师严厉 → 回答「はい！」，称老师（0004、0012）

## 关系
- 手毬：称「手毬先生」（0012）；手毬在 0002 对她很严厉，0005 内心觉得她记性太差
- ことね：称「ことねちゃん」（0047）；ことね问她是否把会长放在眼里（0043～0046），听了回答后没有叱责
- 咲季：咲季夸她「よく言ったわ、佑芽！」（0055），说「それが勝負よね」（0054）
- 星南：称「十王会長」（0026、0033）；她说星南会在最前排的位子观看（0033、0034）

## 档案类事实
- 星南说过会在最前排看她的考试（0033、0034）
- 输了会哭，因为悔しい（0053）
- 被手毬评价为物覚えが悪い（0005，手毬的内心话）
