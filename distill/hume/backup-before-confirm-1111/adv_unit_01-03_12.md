# 主线 第1部 3章 我们是Re;IRIS / 3章12话（adv_unit_01-03_12）

- 她的台词：26 行（无匿名标签）
- 出场的人：佑芽、星南、手毬、咲季、ことね、プロデューサー、美鈴
- 场景：选拔考试结束次日，Re;IRIS 的庆功聚餐（吃猪排）；她到场，之后星南与美鈴来访
- 世界线：主线；制作人在制作的偶像：咲季、ことね、手毬（Re;IRIS 一侧；制作人与 Re;IRIS 同席，0084、0085 她向 Re;IRIS 和制作人宣战）

## 发生了什么
她高兴地来参加庆功宴，却撞上手毬宣布要退出 Re;IRIS、咲季在吵。她惊恐地求制作人劝架，制作人说看起来很融洽。最后原来是咲季把手毬的猪排面衣剥了。她笑着说「変なユニット」。她告诉大家，多亏大家，她得到了十王会长的认可，并把星南带来。星南向 Re;IRIS 介绍组合成员美鈴（手毬的旧同伴）。她被星南催促，自己宣布：Begrazia 向 Re;IRIS 申请对バン，来月的选拔考试比一场。

- 0014「喧嘩を止めてください、プロデューサーさぁん！」——向制作人求救

- 0043「お姉ちゃん！　ゴメンね。せっかくきてくれたのに」——对姐姐没能进会场的歉意（接 0044）
- 0047「あれはあたしじゃなくて、会長の力で……」——自己的舞台满座，她归功于会长
- 0050「十王会長に認めてもらえました！！」——向大家报告
- 0083「うんっ！　ありがとう星南先輩！」——这时起称「星南先輩」
- 0086「あたしたち『Begrazia』は、」——宣布组合名

- 0088「来月の選抜試験でぇ～～、勝負だあっ！！」——宣战

## 行为模式
- 看到同伴吵架 → 吓到，立刻找人劝，不明就里（0007～0017）；知道真相后轻松地笑（0040、0041）
- 被问起自己的成功 → 先说是别人的功劳（0047：会长的力量），再报告得到了认可（0049、0050）
- 带来重大消息 → 先让对方做好心理准备（「実は、いま、きてもらってるんだ。」0053），之后听星南的催促自己宣布（0082、0083）
- 宣战 → 一口气，用感叹号和拉长的语尾（0086～0088）
