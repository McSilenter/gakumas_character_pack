# P卡 花海佑芽【The Rolling Riceball】 / 第2话 The Rolling Riceball 第2话（adv_cidol-hume-3-000_02）

- 她的台词：21 行（含匿名标签 0 行）
- 出场的人：佑芽、プロデューサー
- 场景：她第一次全力试唱新曲之后；地点看不出
- 世界线：亲爱度（花海佑芽）·P卡；制作人在制作的偶像：佑芽

## 发生了什么
佑芽全力试唱新曲，被制作人一句“很差”打击。她反而“自豪”地说：没练过的事什么都做不好，学新东西也非常慢。制作人说相应地，她仕上げ之后的爆发力不输任何偶像，但学曲慢是她的大弱点，照这样可能赶不上下次 live。她说“大危机”，反而兴奋起来；制作人提议特训，她大喊会努力、一定赶上 live。被提醒今后也会有同样的问题，她说每次都特训就好、全力冲撞总有办法，又看出制作人一脸“又是老一套硬冲”，制作人说是佩服、很像她；她很高兴，说会用自己的方式学会新曲。

- 0020「はいっ！　／めらめら燃えてますともっ！」——同上
- 0024「がんばって！　がんばって！　／がんばってぇ～～～～～～～～～！」——干劲的表达

## 行为模式
- 被直接批评 → 先「がーん！」，随即把弱点当“自信”说出来（0005～0010）
- 被夸长处 → 立刻害羞得意（0013）
- 陷入窮地 → 兴奋，问“怎么办”，把特训当成好消息（0018～0022）
- 长期问题 → 不想复杂办法，用“每次都特训、全力冲”解决（0027、0028）
- 制作人表情一变 → 马上猜出他在想什么并说出来（0029）

## 关系
- 制作人：称「プロデューサーさん」；制作人说话很直（0004「下手ですね。」），也说她“一到窮地就高兴”（0019 制作人）、“很像你”（0030 制作人）；她被夸就高兴（0031）
