# P卡 花海佑芽【Campus mode!!】 / 第3话 Campus mode!! 第3话（adv_cidol-hume-3-006_03）

- 她的台词：49 行（含匿名标签 0 行）
- 出场的人：佑芽、プロデューサー、広、千奈（0027～0036 回想）
- 场景：『N.I.A』优胜后的 live 开场前（0013、0016），她刚哭过（0001）；中间穿插和広、千奈的回想
- 世界线：亲爱度（花海佑芽）·P卡；制作人在制作的偶像：佑芽

## 发生了什么
上场前佑芽止住了眼泪，却说还没准备好，请再等一下；制作人说这是她第一次在 live 前没有笑容。她说背上很沉，这是生来第一次觉得“不能失败”，抱着“人生的集大成”去比赛，现在却比和姐姐的决战还紧张：来的不只是她的粉丝，还有没进『FINALE』的偶像的粉丝、燐羽托付给她的粉丝、期待花海咲季 live 的人，他们会带着各种心情看着赢了他们心爱偶像而优胜的她，绝不能让他们失望。制作人说她对偶像工作更真挚了，她说是千奈和広的功劳——她很快就明白粉丝为什么喜欢两人（広记得所有粉丝的脸和名字）。她说以为自己珍惜、喜欢粉丝，却觉得输给了两人；她一直只想着赢姐姐，也许不是正经的偶像；明白了也很难改，现在只是在模仿两人；她至今仍把粉丝当成“筋肉”——力量之源、一用力就回应、越多越强，是偶像花海佑芽的一部分，所以很重要，但和広、千奈不一样。制作人说不同也可以，“对粉丝的心意”没人知道正解，能确定的是受两人影响更在意粉丝的她变强了；“粉丝是自己的一部分”是好句子，不信就对粉丝说。她说好主意，心里舒畅了，带着歌、舞、MC 的一切去唱『Campus mode!!』。

## 行为模式
- 担子很重时 → 不笑，直说“背上很沉”“还要再等等”，列出台下每一类观众（0004～0018）
- 被夸成长 → 说“自己不清楚”，把功劳归给朋友（0021～0026）
- 自我检讨 → 拿朋友作比较，坦白“觉得输了”“只是在模仿”（0037～0043）
- 解释抽象的东西 → 用身体的比喻（筋肉、用力就回应）来说，说不清时边想边换说法（0045～0053）
- 被建议在 live 上直接说 → 先惊叫，随即说“好主意”（0068、0069）
