# S卡 3-0003【お姉ちゃんに任せなさい！】 / 第3话 躲避球对决！（adv_csprt-3-0003_03）

- 她的台词：5 行（含用匿名标签说的 0 行）
- 出场的人：咲季（9 行）、千奈（6 行）、佑芽（5 行）
- 场景：打躲避球的地方（学园内，看不出具体地点）
- 世界线：S卡【お姉ちゃんに任せなさい！】；制作人在制作的偶像：看不出

## 发生了什么
佑芽被咲季打中，咲季宣告躲避球也是她赢（0001、0002）。佑芽不甘心大喊（0003）。千奈说咲季为她赢了佑芽，称咲季“命の恩人”“咲季お姉さま”（0006～0015），咲季得意，说“佑芽，你的朋友是好孩子”（0011）。佑芽回答“そうでしょ～！”，同时吐槽“命の恩人ってなに！？”（0012）。咲季被叫“咲季お姉さま”很高兴（0016、0017），佑芽闷闷地发出“むむむ”，然后也对咲季说“お姉さまぁ～、もう一勝負いたしましょ～♡”（0018、0019）。咲季只沉默地省略号。

## 她的关键台词
- 0003「ぬぐぅ～～～～～～～～～～～～！！／ぐやしィ～～～～～！」——输给姐姐时直接表达不甘
- 0012「そうでしょ～！　／――千奈ちゃん命の恩人ってなに！？」——被姐姐夸朋友时得意，同时吐槽千奈的说法
- 0018「……むむむ……っ。／むむむむむ～～～！」——看到姐姐被千奈叫“お姉さま”而开心，发出不满的声音
- 0019「お姉さまぁ～、／もう一勝負いたしましょ～♡」——学千奈的叫法找姐姐再战

## 行为模式
- 输给姐姐 → 大声说不甘心（0003）
- 自己的朋友被姐姐夸 → 得意地接受，同时吐槽朋友的夸张（0012）
- 姐姐被别人崇拜、对方很开心 → 发出不满的声音，然后换成对方的叫法来找姐姐比赛（0018、0019）

## 关系
- 咲季：本篇她只说了“お姉さま”（0019）；咲季叫她「佑芽」（0002、0011）
- 千奈：称「千奈ちゃん」（0012）；千奈称她「花海さん」（0006）、称咲季「咲季お姉さま」（0015）

## 档案类事实
- 咲季在躲避球上赢了佑芽（咲季 0002「ドッジボール勝負も／わたしの勝ちよ！　佑芽！」、0004「球技でわたしに勝とうなんて、／100億年早いわぁ！」）。
- 佑芽有一位朋友千奈，咲季说“あなたの友達、いい子じゃない！”（咲季 0011），佑芽回答“そうでしょ～！”（0012）。

## 不确定
- 0019 她说「お姉さまぁ～」是在模仿千奈对咲季的叫法，还是单纯撒娇，剧本没有写明；0018 的「むむむ」的原因（是否因为姐姐被千奈崇拜）也没有写明；咲季 0020 只有省略号，是否接受再战剧本没写。
- 咲季 0002「ドッジボール勝負も／わたしの勝ちよ！」的“も”指前面还有别的胜负，本篇没说是哪些。
- 0013 千奈说“殺人ショットの脅威”，指的是佑芽的球；本篇没有写千奈为什么要和佑芽比。
