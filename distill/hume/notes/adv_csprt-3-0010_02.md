# S卡 3-0010【可愛いと可愛いで可愛い！】 / 第2话 午休的日常（adv_csprt-3-0010_02）

- 她的台词：6 行（含用匿名标签说的 0 行）
- 出场的人：千奈（9 行）、佑芽（6 行）、広（5 行）
- 场景：午休时的教室，之后打算去屋上吃饭（0019、0020）
- 世界线：S卡【可愛いと可愛いで可愛い！】；制作人在制作的偶像：看不出

## 发生了什么
午休，佑芽招呼广和千奈，说快点吃完饭去外面玩（0001、0002）。千奈说“心は元気、身体は筋肉痛”，广说“生きてるだけで辛い”，两人不想动（0005～0007）。佑芽提议打躲避球，千奈说自己发过誓不再和佑芽比球技，因为会死（0008～0010）。广听了反而想玩（0011～0015）。佑芽提议先吃饭，说天气好，在屋上吃，千奈赞成（0017～0020）。

## 她的关键台词
- 0001「広ちゃん！　千奈ちゃん！／――お昼休みだよっ！」——午休一开始就叫人
- 0002「早くご飯を食べて、外で遊ぼうっ！」——午休想吃快点去外面玩
- 0004「千奈ちゃんは元気じゃないの？」——不明白对方不玩的理由，直接问
- 0008「エ～、ドッジボールやろうよ～。」——提议打躲避球
- 0017「ふたりとも！　なにはともあれ、／ご飯にしようよ！」——争执时把话题拉回吃饭
- 0019「ん～、天気がいいから、屋上とか？」——选屋上吃饭

## 行为模式
- 午休 → 想快点吃完饭出去运动（0002、0008）
- 朋友身体累、不想动 → 先问，再提议球类，被拒后不强求，改说先吃饭（0004、0008、0017）

## 关系
- 広：称「広ちゃん」（0001）
- 千奈：称「千奈ちゃん」（0001、0004）；千奈称她「花海さん」，说“花海さんはいつも元気ですわね”（0003）

## 档案类事实
- 午休想“早くご飯を食べて、外で遊ぶ”（0002）
- 想打躲避球（0008）；千奈说不再与佑芽比球技（千奈 0009、0010）
- 午休想去屋上吃饭，因为天气好（0019）
