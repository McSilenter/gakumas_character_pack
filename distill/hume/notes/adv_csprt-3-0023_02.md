# S卡 3-0023【まだ上がりませんように！】 / 第2话 雨天的大好机会？（adv_csprt-3-0023_02）

- 她的台词：9 行（含用匿名标签说的 0 行）
- 出场的人：咲季（11 行）、佑芽（9 行）
- 场景：训练设施（有最新的训练机器）；雨天；时间看不出
- 世界线：S卡【まだ上がりませんように！】；制作人在制作的偶像：看不出

## 发生了什么
佑芽抱怨雨天不能在外面跑（0001、0002）。咲季说要往前看，下雨是试最新训练器械的大机会（0003～0005）。佑芽吐槽“这和下雨无关，是姐姐你喜欢吧”（0006）。咲季承认，并说家里也没有这么齐的设备（0007、0008）。佑芽被姐姐的开心感染，决定今天做机器训练（0009、0010），咲季让她等训练员来（0011～0013）。佑芽发现姐姐在准备摄像机（0014），咲季说是父亲让她拍视频、写意见报告（0015、0016）。佑芽说“又在做麻烦的亲子事”（0017）。咲季让她选机器，佑芽说“不懂”，咲季说要教她（0018～0020）。

## 她的关键台词
- 0002「思いっきり外を走れないの、／つまんないなぁ～。」——不能在外面跑觉得无聊
- 0006「それ雨とか関係なく、／お姉ちゃんが好きなだけじゃん！」——戳破姐姐的借口
- 0009「もう……そんなに嬉しそうにされたら、／こっちまでわくわくしてくるよ。」——被姐姐的兴奋感染
- 0010「よぉ～～しっ、決めたっ！／今日はマシントレーニングの日――」——马上做决定
- 0014「はぁ～い。あの……お姉ちゃん、／なんでカメラを準備してるの？」——听话，但注意到摄像机就问
- 0017「また親子でめんどくさそ～な／ことしてる～！」——对姐姐和父亲的做法吐槽
- 0019「えっ好みって言われても……／よくわからないし。」——对机器没有偏好，直说不懂

## 行为模式
- 因天气不能做喜欢的事 → 说无聊，被姐姐劝后很快转换心情（0001、0002、0009、0010）
- 姐姐的理由牵强 → 直接指出“只是你自己喜欢”（0006）
- 做决定很快；被拦住 → 应声“はぁ～い”，等待（0010、0012、0014）

## 关系
- 咲季：称「お姉ちゃん」（0006、0014）；咲季说“うちにだって、ここまでの／トレーニング設備は揃ってないわ！”（咲季 0008）
- 父亲（咲季的父亲）：佑芽说“また親子でめんどくさそ～な／ことしてる～！”（0017）；父亲让咲季拍视频写报告（咲季 0015、0016）

## 档案类事实
- 佑芽喜欢在外面跑，雨天觉得无聊（0001、0002）
- 她说父亲和咲季“又”做麻烦的事（0017），说明这类“亲子”的事不是第一次
- 她对训练机器没有偏好：“よくわからないし”（0019）
- 咲季说“お父さんに学園のトレーニング／設備の自慢をした”（咲季 0015）

## 不确定
- 0017「また親子で」的“親子”是咲季和父亲，还是包含她，原文没明说；从语境看是咲季与父亲。
- 咲季 0008 说家里没有学园这么齐的设备，与 3-0003_02 0010（佑芽“うちで使ってたやつ、全部あるもん”）、0011（咲季“それが／入学を決めた理由の1つよ”）说法不同。两篇是不同的卡，不算冲突，仅记录。
