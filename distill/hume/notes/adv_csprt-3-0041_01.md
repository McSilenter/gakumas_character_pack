# S卡 3-0041【キラキラして綺麗～っ！】 / 第1话 闪耀的灯饰（adv_csprt-3-0041_01）

- 她的台词：9 行（含用匿名标签说的 0 行）
- 出场的人：佑芽（9）、星南（6）、美鈴（5）
- 场景：生徒会的工作（美鈴 0011 做了会计工作）之后，晚上去车站前看灯饰；快到圣诞节（0018「おっきなクリスマスツリー」、0012「この時期に外で寝たら死んじゃうよ！」）
- 世界线：S卡【キラキラして綺麗～っ！】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
星南说车站前的灯饰展开始了，佑芽想去，连一向不积极的美鈴也说“悪くありません”（0001～0003）。星南说先把工作做完，佑芽说会“爆速”完成，还让美鈴也做（0005～0008）。工作完成时已入夜，美鈴说做会计作业后困了，佑芽说这个时期在外面睡会死（0009～0012）。三人到了灯饰前，佑芽说好漂亮，又发现大圣诞树，要大家过去，星南说“まったく、小さい子供のようね”（0014、0018～0020）。

## 她的关键台词
- 0002「え、そうなんですか！？／行ってみたい！」——听到灯饰展，马上想去
- 0004「美鈴ちゃんが珍しく乗り気だ！？／だったら、今から行きませんか！？」——抓住美鈴有兴致的机会，要立刻出发
- 0006「分かりました！／爆速で仕事を終わらせますねっ！」——被告知先做完工作，立刻接受并保证快
- 0008「美鈴ちゃんもやるんだよっ！？」——美鈴说“头加油”时，吐槽她也要做
- 0012「わー、美鈴ちゃん！／この時期に外で寝たら死んじゃうよ！」——美鈴犯困，赶紧叫醒
- 0014「わぁ～っ、綺麗ですね！」——到灯饰前的直接感叹
- 0018「見てください、あっち！／おっきなクリスマスツリーがあります！」——发现新东西就拉大家过去

## 行为模式
- 有想去的地方 → 马上说要去，并且催促（0002、0004）
- 被要求先完成工作 → 全力加速，并且要求同伴一起做（0006、0008）
- 同伴犯困 → 马上喊醒，用夸张的说法（0012）
- 看到新的好看的东西 → 马上拉大家过去（0018、0019）

## 关系
- 星南：本篇没有直接称呼；对星南用敬语（0002、0006、0014、0018）；星南说她“まったく、小さい子供のようね”（星南 0020）
- 美鈴：叫“美鈴ちゃん”（0004、0008、0012）；美鈴叫她“佑芽さん”（美鈴 0007）

## 档案类事实
- 在生徒会做工作（0005、0006、美鈴 0011）
- 喜欢灯饰（0002、0014）
