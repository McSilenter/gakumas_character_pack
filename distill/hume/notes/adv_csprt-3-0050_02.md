# S卡 3-0050【あなたたちのことが好き】 / 第2话 再多一点点（adv_csprt-3-0050_02）

- 她的台词：5 行（含用匿名标签说的 0 行）
- 出场的人：千奈（8）、広（7）、佑芽（5）
- 场景：三人一起出门的路上，最后提议去路边的公园（0020）；时间点是入学后一段时间
- 世界线：S卡【あなたたちのことが好き】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
佑芽说和这3个人一起玩好像很久没有了，千奈说上周还一起出过门（0001、0002）。佑芽说自己的感觉是很久，想每天和两人在一起，也想在工作以外一起（0003～0005）。広说她的爱很重，但“いいね”，千奈说入学以来一直是这3个人，広说是学园里最要好的组合（0006～0009）。広说最近大家都忙起来了，千奈说那是值得高兴的事，広说是多亏了两人（0012～0017）。佑芽提议去旁边的公园聊一会儿（0020）。

## 她的关键台词
- 0001「ん～！　この3人で遊ぶの、／すっごく久しぶりな気がする！」——感觉很久没有三个人玩了
- 0003「あたしの感覚では久しぶりなんだもん。／毎日ふたりと一緒にいたぁ～い！」——被指出上周才一起出门，仍然说想每天在一起
- 0005「お仕事以外でも～～～～！」——补充，希望工作以外也一起
- 0011「ね～♪」——认同“最要好的组合”
- 0020「……ね、そこの公園寄っていこうよ。／もうちょっとだけ、お喋りしよう。」——不想结束，提议再聊一会儿

## 行为模式
- 被指出事实与感觉不符（上周才玩过） → 坚持“我的感觉”，并说想每天在一起（0003）
- 一天快结束 → 不想分开，提议绕路再聊（0020）

## 关系
- 千奈、広：本篇没有直接称呼；広评价“佑芽の愛は重い。……いいね。”（広 0006）；千奈说“入学してからずっと……この3人で。”（千奈 0007）

## 档案类事实
- 和千奈、広经常一起工作（広 0004）和私下出门（千奈 0008）
