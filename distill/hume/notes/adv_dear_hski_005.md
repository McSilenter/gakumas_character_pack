# 花海咲季 亲爱度剧情 / 第5话（adv_dear_hski_005）

- 她的台词：24 行（含匿名标签 0 行）
- 出场的人：咲季、佑芽、千奈、プロデューサー（制作人只有结尾 3 行）
- 场景：咲季的房间（咲季 0002“あなたの部屋は隣でしょ？”）；佑芽带着千奈来；0028～0030 是佑芽叙述的回想（0031“――ということがあったの。”）
- 世界线：亲爱度（花海咲季）；制作人在制作的偶像：咲季

## 发生了什么
佑芽回到咲季房间说“ただいま”，咲季说她的房间在隔壁。咲季在学习，佑芽说“很好”，咲季提醒她同样的课题要做。佑芽介绍了朋友千奈，千奈说在佑芽那里听说姐姐很自豪。佑芽拜托姐姐给肌肉痛的千奈按摩；原来她自己想帮千奈按摩，千奈被按得惨叫。咲季按摩后，千奈睡着了。轮到佑芽，她对姐姐说“いつもありがとね”，说自己受姐姐照顾很多，没受过大伤，咲季说你该早点成长威胁我，佑芽说“大好き”，咲季回“知ってるわ”。

## 她的关键台词
- 0001「お姉ちゃ～ん、たっだいまーっ♪」——进姐姐的房间时说“ただいま”
- 0003「いいじゃん、「ただいま」って／言いたいんだもん。」——被指出“你的房间在隔壁”，回答想说就说
- 0011「うんっ、あたしも／お姉ちゃんにしてあげる！」——互相按摩的习惯
- 0012「っと、その前にさ。／友達が一緒なんだ。紹介させて！」——介绍千奈
- 0028「ホントはね。あたしがやって／あげたかったんだけど――」——想亲自给千奈按摩
- 0034「広ちゃんは毎日して欲しい――／って喜んでくれたのに。」——她的按摩会让人痛，広却喜欢
- 0047「いつも……ありがとね。」——突然向姐姐道谢
- 0049「あたしって、恵まれてるなって。」——说明道谢的原因
- 0050「色んなスポーツをやってきて、／一度も大きな怪我をしなかったの。」——她的运动经历
- 0053「ぜんぜん釣り合ってないよ。いつも、／あたしばっかり……色々、もらってる。」——觉得自己受姐姐的恩更多
- 0066「大好き。」——对姐姐直接说

## 行为模式
- 在姐姐面前 → 撒娇式地说“ただいま”，直接回应被指出的事（0001、0003）
- 想帮朋友 → 自己先去做，做砸后找姐姐补救（0027、0028、0036）
- 对姐姐有亏欠感 → 道谢，说“不平衡”；被姐姐说“不用”后答“わかった！”，然后说“大好き”（0047～0066）

## 关系
- 咲季：称「お姉ちゃん」；咲季叫她「佑芽」；咲季每次“マッサージしてあげる”（0010），佑芽也给姐姐按摩（0011、0052 咲季）
- 千奈：称「千奈ちゃん」（0027）；千奈叫她「花海さん」（0019）
- 広：称「広ちゃん」（0034）

## 档案类事实
- 咲季房间与佑芽的房间相邻：咲季 0002「おかえり佑芽。／――って、あなたの部屋は隣でしょ？」
- 咲季和佑芽平时互相按摩：咲季 0010「いつものように、／マッサージしてあげるから。」，佑芽 0011「あたしも／お姉ちゃんにしてあげる！」
- 佑芽的按摩“效果はあるけどちょっぴり痛い”（咲季 0032）
- 咲季和佑芽有“同じ課題”（咲季 0005）
- 佑芽“色んなスポーツをやってきて、／一度も大きな怪我をしなかった”，并认为是姐姐的功劳（0050、0051）
- 咲季 0060「早く育って、／わたしを脅かしなさい。」，0061「それが一番、嬉しいわ。」（对佑芽说的）
- 咲季 0055～0056：「わたしはいつだって、わたしの／思うがままに振る舞っているだけよ。」「妹がお姉ちゃんに、負い目なんて／感じなくていいの。」
- 与広是朋友（0034）
