# 花海咲季 亲爱度剧情 / 第33话（adv_dear_hski_033）

- 她的台词：36 行（含匿名标签 0 行）
- 出场的人：佑芽、咲季（佑芽 36 行）
- 场景：咲季的房间或宿舍一类处（佑芽 0040“お姉ちゃんの部屋でたくさんお喋りして”；0046 佑芽问“泊まっていい？”）；佑芽成为『一番星』、结束海外远征回国后；冬『H.I.F』之前
- 世界线：亲爱度（花海咲季）；制作人在制作的偶像：花海咲季

## 发生了什么
佑芽结束与100プロ前辈们的海外远征，回国就扑向咲季撒娇，说从没和姐姐分开过这么久，打电话也因为时差不够。咲季问海外远征如何，佑芽说在敌地很开心，被OB们瞪眼，被打得“ぼっこぼこ”，但也在那里“がつんとイッパツ入れてきた”。晚上两人聊天按摩，佑芽说回到了姐姐的妹妹，想留宿。随后佑芽问“トップアイドルって、なんなんだろう”，说学园之外有很多顶点，自己的梦想有“先”。咲季以“すぐ追い抜くから、待っていなさい”回应，佑芽以“かかってきなさい、花海咲季！！”应战。

- 0014「ぜんぜん足りない……／声が聞きたいとき……いっつも。／お姉ちゃんは寝てる時間なんだもん。」——为什么电话不够

- 0027「初星学園の代表として、／がつんとイッパツ入れてきたよ！」——说自己作为学园代表做了什么
- 0043「やっと、アイドル・花海佑芽じゃなくて／お姉ちゃんの妹に戻れたってコト。」——说“回到了姐姐的妹妹”
- 0051「トップアイドルって、なんなんだろう。」——问“トップアイドルって、なんなんだろう”
- 0057「学園の外に出たら……／世界は思っていたよりずっと広くて。／空は果てしなく高くて……」——说学园之外的世界
- 0059「あたしの夢には、先があったんだ。」——自己的梦想有了下文
- 0071「かかってきなさい、花海咲季！！」——对咲季的应战
- 0072「『一番星』花海佑芽が相手になるよ！！」——报上身份

## 行为模式
- 见到姐姐 → 用拟声和拥抱撒娇，说“会いたかった”（0001、0006、0007）
- 谈到远征 → 把被敌视、被打败也说成“最高の体験”（0019、0024、0025）
- 谈到自己的变化 → 把“アイドル・花海佑芽”和“お姉ちゃんの妹”分开说（0043）
- 被姐姐宣战 → 立刻切换成正面对抗的口吻（0069～0072）
- 想对姐姐倾诉 → 连叫三次“お姉ちゃん”催促（0061～0063）

## 关系
- 咲季：称「お姉ちゃん」；咲季称她「佑芽」，称她“甘えん坊”（咲季 0012）
- 星南：咲季提到“ちゃんと星南にお礼を言っておく”，佑芽答“心の底から感謝してる”（咲季 0022、佑芽 0023）
- 十王社長：佑芽转述其话（0056）
