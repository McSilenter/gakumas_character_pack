# 花海佑芽 亲爱度剧情 / 第5话（adv_dear_hume_005）

- 她的台词：43 行（含匿名标签 0 行）
- 出场的人：佑芽、プロデューサー、咲季
- 场景：姐妹又一次比试之后（地点看不出，应是练习场所）；时间在 004 之后，制定计划、练习了一段时间（0047、0038）
- 世界线：亲爱度（花海佑芽）；制作人在制作的偶像：佑芽

## 发生了什么
咲季又赢了，佑芽这次却照制作人的指示（禁止说“输了”）硬说“我没输”，咲季觉得反应和平时不同。制作人说她已经是“败北的专家”，从失败得到的经验少，要先改变习惯失败的意识；她说“第一次被骂得这么狠”。制作人感叹咲季成长快得可怕，她立刻附和，说姐姐在任何项目都一开始就好、进步快、被大家夸，却比谁都努力练习、从不松懈。被说“讲姐姐时总是很开心”，她说因为最喜欢姐姐，又嘀咕“明明是姐妹为什么这么不像”。制作人说两人很像、她也在急速成长、姐妹差距在缩小，她高兴得脸都绷不住。制作人说她正在“突破”，推动者是咲季；她说这种上了轨道的感觉自己一直都有，姐姐一直是她的榜样、憧憬、动力和引导者，并不觉得是什么爆发式成长。制作人决定进入下一阶段：让她去オーディション，和咲季以外的偶像比。

## 行为模式
- 被要求做违反自己原则的事（不认输）→ 虽然觉得不干脆，还是照制作人说的做，做完又向制作人确认“这样行吗”（0007、0009、0012、0018）
- 被说难听但有道理的话 → 夸张地抗议（「生まれて初めてです」「うわぁ～ん」），但不反驳内容（0015、0020、0022）
- 别人说姐姐厉害 → 立刻热烈附和，开始滔滔不绝地夸姐姐（0025～0028）
- 被说“和姐姐很像”→ 最高兴的夸奖，脸都笑开了（0035、0036）
- 禁止说“输”之后 → 每次说到“输”都在中间硬停，断句强调「負け！　ては！　いない」（0037、0051）
- 被说成有“突破”这种大事 → 先否认夸张，再用自己的话解释成“一直都有的感觉”（0046～0049、0063～0072）

## 关系
- 咲季：称「お姉ちゃん」；“几乎每天都输给她”（0011）；说她最喜欢姐姐（0030）；姐姐是榜样、憧憬、动力之源、引导者（0067）；咲季说她「前よりもずっと良くなってたわ。」（0003）
- 制作人：称「プロデューサーさん」；对制作人的指示照单全收（0020、0021）；感谢制作人的计划（0047、0048）；说对制作人和姐姐同样依赖（0057）

## 档案类事实
- 入学后几乎每天都和姐姐比、几乎每天都输（0011）
- 原本的信条：要承认失败，才能反省和改进（0012）
- 她眼中的咲季：任何项目一开始就好、进步快、被大家夸，却比谁都努力练习、从不松懈（0026～0028）
- 觉得自己和姐姐不像（0031）
- 一直有“跟着姐姐、顺着轨道成长”的感觉（0066～0072）

## 不确定
- 姐妹谁第一次赢了谁／勝ち逃げ：本篇佑芽讲的是“姐姐任何项目一开始就好、进步快、比谁都努力”（0026～0028），以及 0011「ほぼ毎日負けてるんですけど！」。看不到姐姐“快输就换项目”的说法；也和制作人 0024「彼女だけが100倍の速度で成長して／いるようにさえ見える。」有关。留待判定。
- 0031「……姉妹なのに、どうしてこんなに／似てないんだろう。」是自言自语还是说给制作人听，看不出。
- 【译文】0051 原文「実際、ぼっこぼこに負け／――ては！　いないですけど！」是“其实被打得落花流水——才！没有输呢！”（差点说出“输了”又改口），译文“其实并没有输得很惨——但是！也没有完全赢！”意思不对。
