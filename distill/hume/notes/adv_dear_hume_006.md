# 花海佑芽 亲爱度剧情 / 第6话（adv_dear_hume_006）

- 她的台词：53 行（含匿名标签 0 行）
- 出场的人：佑芽、プロデューサー、咲季
- 场景：『選抜試験』当天的会场（夏天大活动『Hatsuboshi IDOL FESTIVAL』参加权的实战形式考试，0007～0013），她的 live 前后
- 世界线：亲爱度（花海佑芽）；制作人在制作的偶像：佑芽

## 发生了什么
佑芽在会场看到其他参加者都气势十足，干劲高涨，却不记得今天是什么；制作人说是『選抜試験』，是争夺『Hatsuboshi IDOL FESTIVAL』参加权的考试，那里是和咲季决战的最好舞台。她原本因为不是和姐姐比而遗憾，这下绝对不能输，宣布即使自己是补欠入学的劣等生、对手都比自己强也要拿第一。live 后会场大欢呼，她在目前的参加者里排第一，兴奋地强调自己赢了那些“格上”的人，制作人却说早就相信她会赢。她仍想说“还比不上姐姐”，咲季出现说她成长了很多，要她认清自己的实力、否则对对手失礼，她终于说出“我变强了！”。咲季上台前说「愚問」（暗示她也参加了），佑芽看完说姐姐果然厉害，差点说“输了”又改口。最后她回答 004 的问题：想以偶像身份赢姐姐，别的项目不行；对她来说世界第一的偶像就是姐姐，赢了姐姐就是世界第一，赢了之后的事交给赢了之后的新自己。制作人这次认可了，说“就这样做吧”。

## 行为模式
- 不记得活动名称、规则 → 直接问，再凭模糊记忆想起来（0008、0011～0013）
- 知道比赛的意义（通往与姐姐的决战）→ 干劲瞬间升到最高，把自己的劣势一口气列出来再说“无所谓”（0018～0024）
- 赢了 → 想要别人一起惊讶、一起高兴，对方太冷静会抗议（0029～0033）
- 被夸成长 → 下意识拿姐姐当标准否认（0039）；被姐姐亲口肯定后才接受（0046～0049）
- 面对之前想不通的问题 → 自己反复想过、看过很多偶像的影像后，用很直的话给出答案，并且预先抢话说“你可能会说不行”（0058～0071）
- 被意外认可 → 连声「？？？」反问（0074、0075）

## 关系
- 咲季：称「お姉ちゃん」；她眼中世界第一的偶像（0068）；被姐姐肯定才相信自己的成长（0043～0049）；看完姐姐 live 承认“果然厉害”（0055）
- 制作人：称「プロデューサーさん」；004 的问题这次给出答案，被制作人认可（0058～0077）；「今後ともよろしくお願いします」（0079）

## 不确定
- 0073「どうですか！　まいりましたか！　／プロデューサーさん！」和 0074「えっ？？？？　いいんですか？？？」之间接不上，应是制作人的选项（认可她）没写进剧本。
- 姐妹成为偶像的理由：本篇佑芽说 0062「アイドルとして／あの人に勝ちたいです！」、0063「他の競技じゃダメなんです。」，和 004 的 0016（姐姐做别的项目她也会追）相比，本篇是她自己认定“只能是偶像”，属于同一条线里的变化（制作人 0076 也说“同样又不同”），不算冲突，但请统一判定理由的写法时注意。
- 0064 说的是「世界で一番のアイドル」，001 的 0059 是“学园第一的偶像”，004 的 0009 也是“学园第一”。目标从“学园一”变为“世界一”，是同一线里的发展还是说法不同，留给人看。
- 咲季是否参加了『選抜試験』：0053 咲季只说「愚問」，没直说，之后上台演出（0053、0054）。
- 0055「今日もあたしの――」后面被 0056 打断，原本要说的应是“今天也是我的（输）”。
