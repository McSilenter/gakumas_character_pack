# 花海佑芽 亲爱度剧情 / 第14话（adv_dear_hume_014）

- 她的台词：28 行（含匿名标签 0 行）
- 出场的人：佑芽、プロデューサー
- 场景：013 之后不久，『N.I.A』期间（与燐羽的再战之前，0018），地点看不出
- 世界线：亲爱度（花海佑芽）；制作人在制作的偶像：佑芽（0038 制作人「俺は、花海佑芽を、この先も／ずっとプロデュースしていきたい。」）

## 发生了什么
佑芽怒火冲天，说燐羽干了不得了的事、最讨厌她，要在オーディション里把她打飞报仇，因为赢不了燐羽也赢不了姐姐。制作人提出“见取り稽古”：之前她看燐羽的表演就短时间大幅成长，问她对别的偶像能不能做到，她说如果对方和燐羽一样厉害大概可以。制作人要在和燐羽再战前做 10 次左右，已经为她准备好关系者席、レッスン参观许可，甚至“轻量的比试”；她信息量太大不知道问什么，问是怎么做到的。制作人说见了国内所有大型事务所的社长，暗示将来可能转会去“撒娇”，大家都已经知道佑芽；她问“你撒谎了吗”，制作人说不全是谎话，想一直在最好的环境里制作她，如果有比 100プロ 更好的环境就一起转。她说他露出坏人的脸，这些阴谋等打败燐羽之后再说，将来的事等她赢了姐姐之后再说，她的一切都要从那之后才开始。

## 行为模式
- 被惹怒 → 大声说“最讨厌”“很生气”，然后马上把怒气转成“在比赛里打飞对方”（0001～0006）
- 有了目标 → 立刻问制作人“我该做什么”（0010）
- 听到能比试 → 本能地先答应，再想起要问正事（0028）
- 制作人用灰色手段 → 直问“撒谎了吗”，吐槽“坏人脸”，然后把话题拉回眼前目标（0035、0043～0047）
- 谈到将来 → 一律推到“赢了姐姐之后”（0046、0047）

## 关系
- 燐羽：称「燐羽ちゃん」（0001），也叫「あの人」「あの子」（0004、0008）；最讨厌、很生气，但视为必须打倒的关卡（0004、0008）；她看燐羽的表演而成长，想起来就不甘（0013～0015）
- 咲季：赢姐姐是一切的前提（0046、0047）
- 制作人：称「プロデューサーさん」；对制作人的手腕吃惊、吐槽，但信任；制作人说想一直制作她（0038），她把这话题推到赢姐姐之后（0045、0046）

## 档案类事实
- 被燐羽亲了之后（013）很生气，说最讨厌燐羽，要在オーディション里报仇（0001～0006）
- 看过燐羽的表演后短期内大幅成长（0013、0014 制作人台词）；能对厉害的偶像做“见取り稽古”（0017）

- 她说将来的事等赢了姐姐再谈（0046）
