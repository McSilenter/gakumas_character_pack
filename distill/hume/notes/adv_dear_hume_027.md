# 花海佑芽 亲爱度剧情 / 第27话（adv_dear_hume_027）

- 她的台词：70 行（含匿名标签 0 行）
- 出场的人：佑芽、プロデューサー
- 场景：花海トレーニングセンター合宿中；前半是コンペ前一天（0002、0008），后半（0050 起）是コンペ结束后
- 世界线：亲爱度（花海佑芽）；制作人在制作的偶像：佑芽（0014「あたしが担当アイドルなんですよ！」）

## 发生了什么
コンペ前一天，佑芽说本来对当家里的宣传大使没兴趣，但能和强敌比就燃起来了。制作人说要以“她的对手”的立场先做总结——他在这次コンペ里制作的是她父亲；她抗议制作人最近一直和父亲偷偷商量，“我才是你的担当偶像”，但想到第一次和制作人以偶像对决，又燃起来。制作人提起合宿前的约定（回学园前不和姐姐说话），她说现在懂了：是想让她看到姐姐以外的对手；千奈、広不知不觉成了厉害的偶像，和两人说话像互相展示宝物。制作人说要学十王星南作为制作人的长处——自己当担当偶像的对手兼范本，她说那她也要在这场对决里让他看看“你培养的偶像变得多厉害”。コンペ后她扑倒（タックル）制作人，当选宣传大使，说对手全员都是某人心中的第一，所以不谦虚。她说明白了父亲和制作人偷偷商量的是她和姐姐的事：制作人说『H.I.F』的咲季带着短命偶像特有的危险魅力，她也感觉到了，燐羽也问过她。她说当然接受，不能对追赶她的对手说“等一下”，只能再超越、比姐姐更炽热地燃尽——但发现不只是这样。制作人提醒她发过誓要成为姐姐的目标、对手能引导对手，她说像被大家训了一句“想起来”，想起看喜欢的偶像 live 就想 live、和对手竞争身体就发热、心里像添了柴，觉得不会燃尽；宣布要用 live 把千奈、広、星南全打飞，成为『一番星』，由她来点燃姐姐，无数次。

## 她的关键台词
- 0005「強敵と競い合うなら話は別です！　／すっごく燃えてます！」——有强敌就有干劲
- 0013「あたしのプロデューサーさんなのに……／最近ずーっと、ふたりで／こそこそ相談してるし……」——对制作人和父亲走得近不满
- 0014「あたしが担当アイドルなんですよ！」——强调自己的位置
- 0024「お姉ちゃん以外のライバルを／見せたかったんですね。」——读懂合宿的用意
- 0032「ふたりと話していると、宝物を／見せあっている気持ちになるんです。」——对千奈、広的感受
- 0036「誰がそんなこと言ったんですか！　／あたしがやっつけてあげます！」——替制作人出头（结果是制作人自己说的）
- 0047「あなたの育てたアイドルは、／こんなにすごくなったんだぞって。」——对制作人的回应
- 0056「とっても素敵なアイドルなんですから！／誰かにとっての一番なんですから！」——赢了也尊重对手、因此不谦虚
- 0077「いいに決まってます。あんなに綺麗で、／激しくて、素敵で……」——对“燃尽式”的姐姐的肯定
- 0080「ちょっと待ってなんて言えるわけない！」——不肯让对手等
- 0083「そうじゃなかったんですね。／それだけじゃ……なかったんですね。」——修正自己“只要燃尽就好”的想法
- 0097「心に薪をくべられたみたいに！／燃え尽きられる気がしなくなる！」——对手让她更燃、不会燃尽
- 0102「『一番星』になって、／あたしがお姉ちゃんを燃やします！」——新的宣言

## 行为模式
- 制作人和别人（父亲）走得近 → 直接吃醋抗议“我才是担当偶像”（0013、0014）；但听说能和制作人对决 → 马上转为兴奋（0018、0019）
- 回想制作人布置的规则 → 自己推出用意，并说出来确认（0021～0024、0069～0073）
- 听到有人贬低制作人 → 要替他“打倒”对方；得知是制作人自评后接受“那就没办法”（0036～0039）
- 赢了 → 不谦虚，理由是对手都很出色（0054～0058）；高兴到扑向制作人（0050～0052）
- 被提醒自己忘了的誓言 → 坦率承认“像被训了”，再把领悟说成具体的身体感受（0092～0097），最后落到宣战（0100～0103）

## 关系
- 制作人：称「プロデューサーさん」，也称「あなた」（0046、0047）；吃醋制作人和父亲商量（0013）；第一次和制作人以偶像身份对决（0018）；要让他高兴到黑眼圈和皱纹都消失（0048、0049）；制作人叫她「佑芽さん」（0025）
- 父亲：这次コンペ的对手之一，制作人制作的是父亲（0011 制作人）；她说父亲是「ついでに」的强敌（0004）
- 咲季：合宿期间约定不和她说话（0021）；『H.I.F』上「あんなにカッコよくあたしを／追い抜いていった宿敵」（0079）；她要再超越、要“点燃”姐姐（0081、0102）
- 千奈、広：称「千奈ちゃん」「広ちゃん」；“不知不觉成了厉害的偶像”（0028）；和她们的日子不输她和姐姐一起跑来的日子（0029、0030）
- 燐羽：燐羽问过她“那样的姐姐可以吗”（0076）
- 星南：已成为顶级偶像，她要打飞的对象之一（0100）

## 档案类事实
- 本来对当家里的宣传大使没兴趣（0003）；コンペ中当选花海トレーニングセンター的宣传大使（0060 制作人）
- 合宿前和制作人约定：回学园前不和姐姐说话（0021）
- 这次コンペ里制作人制作了花海社長（0011 制作人）
- 这是她第一次和制作人以偶像身份对决（0018）
- 制作人说『H.I.F』的咲季有「短命アイドル特有の、／あやうい魅力」，她也感觉到了（0074、0075 制作人）
- 她在『H.I.F』上被姐姐超越（0079）
- 新的目标：成为『一番星』，由自己来点燃姐姐（0102）

## 不确定
