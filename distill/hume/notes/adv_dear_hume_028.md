# 花海佑芽 亲爱度剧情 / 第28话（adv_dear_hume_028）

- 她的台词：47 行（含匿名标签 0 行；其中 0051、0052 两行标签是「佑芽」，咲季那边的笔记说配音是咲季的声音，见不确定）
- 出场的人：佑芽、プロデューサー
- 场景：为冬天『H.I.F』开的会议（0005、0006），合宿和コンペ结束后；地点看不出
- 世界线：亲爱度（花海佑芽）；制作人在制作的偶像：佑芽

## 发生了什么
佑芽气势十足地来开冬季『H.I.F』的会，被要求先冷静、复习现状。她说夏天『H.I.F』没能赢姐姐和星南（硬说“没输”），但不气馁，要再超越姐姐、打倒顶级偶像，成为『一番星』；她在花海トレーニングセンター和千奈、広、父亲等许多偶像较量、研鑽，做出新生的乐曲『真っ白いページと水彩の主人公』并赢了コンペ，发誓要无数次点燃姐姐——复习完反而更燃了。制作人列出要打倒的对手：宿命对手花海咲季为首，顶级偶像十王星南、学园 No.2 雨夜燕，她补上千奈和広；『選抜試験』就是她最好的冲刺练习。接着她说想做一件事，制作人先说出：『グースーピー』。她说那是“挑战花海咲季的曲”“花海佑芽らしい曲”，是姐姐为只看得到花海咲季、毫不尊重偶像的“偶像未满的偶像”写进心愿的歌，希望她真正成为偶像时高声唱；她已无法像当时那样唱，所以现在想唱，即使知道学得慢的自己该缩小课题。制作人说本就有此打算：数值以外要靠“那样的东西”。她说现在懂了——是一直从姐姐、朋友、前辈、制作人、粉丝那里得到的东西，是偶像的力量之源，这次要百倍奉还。

## 行为模式
- 被要求冷静 → 「全力で落ち着きます！」，复述现状越说越燃，结果更不冷静（0009、0022、0023、0026）
- 提到输给谁 → 先断开喊“没、输”，再小声承认“没赢”（0011）
- 制作人列对手 → 主动把朋友千奈、広也加进去（0032）
- 想做制作人计划外的事 → 先承认时间不够、自己学得慢，再说为什么非做不可（0053～0055）
- 被问到“那是什么” → 当场想通，把答案说成一串具体的人（姐姐、朋友、前辈、制作人、粉丝）（0065～0067）

## 关系
- 咲季：称「お姉ちゃん」；夏天没赢她（0010、0011）；要再超越她（0013）；『グースーピー』是姐姐为她写进心意的歌（0048）
- 星南：称「星南先輩」（0010）；要打倒的顶级偶像
- 千奈、広：称「千奈ちゃん」「広ちゃん」，也是对手（0032）
- 父亲：一起参加コンペ的对手之一（0016）
- 制作人：称「プロデューサーさん」；被他看穿想唱『グースーピー』（0045、0046）

## 档案类事实
- 夏天『H.I.F』没能赢姐姐和星南（0010、0011）
- 在花海トレーニングセンター特训，用新生乐曲『真っ白いページと水彩の主人公』赢了コンペ（0015～0019）
- 当前目标：超越姐姐、打倒顶级偶像，成为『一番星』（0013、0014）
- 冬季『H.I.F』的对手：花海咲季、十王星南、学园 No.2 雨夜燕（0030、0031 制作人），还有千奈、広（0032）
- 『グースーピー』：“挑战花海咲季的曲”“花海佑芽らしい曲”，姐姐为她写进心意（0047、0048）
- 自认学得慢（0055）

## 不确定
- 0051「花海佑芽が、真の意味でアイドルに／なったときにこそ……」、0052「高らかに歌ってほしい。」：标签是「佑芽」，按清单算她的；咲季那边的笔记写这两行的配音文件是咲季的声音，可能是插入的咲季原话（回想），也可能是她转述。若是咲季的声音，她的台词应是 45 行。留待确认。P卡 GUSUPI 第3话（adv_cidol-hume-3-009_03）的 0042 制作人转述过咲季的同一愿望。
- 0049 对过去自己的评价，与 P卡 GUSUPI 第1话（adv_cidol-hume-3-009_01）的 0027 制作人、0029～0033 咲季的说法一致。
- 夏天『H.I.F』姐妹胜负：本篇 0011 说“没输……没赢”；022 的 0038 她说是自己输了、0039 咲季说平手；025 的 0027 她说输给了顶级偶像和姐姐；027 的 0079 她说被姐姐超越。都是她自己的说法，本篇 0011 是 005 那个“禁止说输”的老习惯，不判冲突。
- 0062、0063 “那样的东西”具体是什么，制作人没说，0065～0068 是她自己的理解。
- 【译文】0010「あたしは夏の『H.I.F』で、／お姉ちゃんと、星南先輩に……」是“我在夏天的『H.I.F』上，对姐姐和星南前辈……（没赢）”，译文“我和姐姐在与星南前辈的比赛中……”把姐姐译成和她站在一边，意思错了。
