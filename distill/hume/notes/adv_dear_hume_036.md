# 花海佑芽 亲爱度剧情 / 第36话（adv_dear_hume_036）

- 她的台词：35 行（含匿名标签 0 行）
- 出场的人：佑芽、星南、学園長
- 场景：冬季『Hatsuboshi IDOL FESTIVAL』结束后的『一番星』授与式（0006）
- 世界线：亲爱度（花海佑芽）；制作人在制作的偶像：佑芽（0013 星南「あなたにも、／プロデューサーにもね。」）

## 发生了什么
学园长宣布『H.I.F』从今冬起成为产生偶像顶点『一番星』的世界级活动，优胜者是花海佑芽。现『一番星』十王星南说她完败给佑芽和她的制作人：佑芽一开始就深不见底，没想到会长这么大。佑芽感谢星南从她还被叫作「落ちこぼれの補習組」的时候就一直关照她——说过想制作她、邀她进生徒会、教了她多到讲到天亮的事；星南说不用说，看了 live 的所有人都感受到了。她接过从历代前辈传下、由十王星南锤炼的证明，面向观众宣言：她是赢了最强的对手们站在这里的，所以绝不谦虚，要尽情炫耀“我才是学园第一的偶像”。她提起前代星南代表初星学园向偶像业界、世界的偶像下战书，说自己是情报通，也知道后辈们“别留下这种乱来的炸弹就毕业啊会长”的悲鸣；宣布由她来继承这场无谋的战斗，持续证明『一番星』就是顶级偶像的称号，不让任何人说星南毕业后初星学园水平下降。她邀请观众和“你”一起和世界的偶像竞争、成长、燃烧，最后报上名号：「あたしこそが『一番星』花海佑芽！／初星学園の頂点にして――――」「世界最強のアイドルです！！！！！」

## 行为模式
- 在大舞台上接受荣誉 → 先郑重感谢引导过她的前辈，再转向观众宣言（0019～0024、0032～0037）
- 赢了 → 不谦虚，理由是对手都是最强的（0034～0036）
- 继承前人的重担 → 用玩笑点出大家的抱怨，再说“由我来接”（0041～0045）
- 宣言的最后 → 把观众拉进来一起燃烧，说“光靠话说不完，请听我唱”（0048～0054）

- 初星学园的偶像们、观众：她要继承星南的战斗、邀请大家一起成长（0043～0053）

## 不确定
- 『一番星』是谁：022 学园长宣布夏天的『一番星』是十王星南；本篇冬季『H.I.F』优胜者佑芽成为新『一番星』（0008、0033），星南被称为「現『一番星』」（0010）。
- 姐妹胜负：0034「最強のライバルたちに／勝って」——是否赢了咲季、咲季的名次，本篇没写（037 的 0005 她说和姐姐一句话都没说）。
- 0021 星南“想制作她”是星南的愿望，这条线里她的制作人是玩家；她是否进了生徒会本篇没写。
- 0049「あなたも！」对谁说（观众中的某人、屏幕前的人），剧本没写。
