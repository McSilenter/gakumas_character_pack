# 花海佑芽 亲爱度剧情 / 第37话（adv_dear_hume_037）

- 她的台词：48 行（含匿名标签 0 行）
- 出场的人：佑芽、プロデューサー
- 场景：『一番星』授与式之后，她找到独自在某处的制作人（0002「やっぱりここにいたんですね♪」）；地点看不出
- 世界线：亲爱度（花海佑芽）；制作人在制作的偶像：佑芽（0014「担当アイドルが『一番星』に／なったんですから」）

## 发生了什么
佑芽找到制作人，说和姐姐一句话都没说，但一定传达到了；制作人说那个人甩不掉，今后也要做好拼死缠斗的准备，她说正合我意。她问制作人为什么一个人孤零零地笑，原以为他会被制作人科的朋友围着祝贺；制作人说正和制作人科的人吵架，因为对方按最近的成绩反复改评价，他说了句“这组里只有我把担当偶像送进今年的『H.I.F』”，她说“那不就是嫌味”，并要他和同学好好相处；制作人说会去道歉，因为被『一番星』骂了。她感叹自己真的成了『一番星』。制作人说“世界最强的偶像”说得够大，她说制作人说过未来的她是常胜不败的顶级偶像，但现在还不是，要一直赢才配那么叫，所以想了别的决め台詞，担心被粉丝骂“别得意”；制作人说大受好评，因为说“世界第一”会引起反感，而“世界最强”听起来含着战斗能力、很野蛮——“能唱能跳能打”。她这才意识到，大叫会被当成可爱但野蛮的偶像，制作人笑到咳嗽，说生来第一次笑成这样。她说她要让全世界的人笑、觉得偶像好玩有趣，一直全力奔跑，给偶像们撒热与火焰，这就是她要成为的顶级偶像花海佑芽；让他别哭、笑。两人都流着泪说自己在笑。制作人说梦想实现时她会被那样称呼，她说会成为常胜不败的『一番星』、宣言过的偶像，“我就是世界最强的偶像花海佑芽”，今后也请多关照。

## 行为模式
- 制作人的行为奇怪 → 直接问原因，听完立刻吐槽，再像管孩子一样要他和同学和好（0012、0021～0030）
- 被夸大的称号 → 自己划界线：没连胜就不叫“常胜不败”，另想说法（0038～0041）；被指出另一层意思 → 大叫、慌乱，担心形象（0048～0057）
- 对方动情 → 先说出自己要成为什么样的偶像，再叫对方别哭；自己哭了也说“在笑”（0064～0073）
- 和姐姐 → 不说话也觉得“传达到了”（0005～0007）

## 关系
- 制作人：称「プロデューサーさん」；吐槽、管教他（0026、0030）；让他别哭（0069）；制作人说生来第一次笑成这样（0059 制作人）；两人一起流泪（0071～0073）
- 咲季：一句话都没说，但觉得传达到了（0005～0007）；制作人说她甩不掉，今后要缠斗（0008、0009 制作人），她说正合我意（0010）
- 制作人科的同学：制作人和他们吵架，她要他和好（0018～0030）

## 档案类事实
- 成为『一番星』（0032、0033）
- 授与式上用的决め台詞是“世界最强的偶像”，制作人说大受好评（0036、0043）；她自己没意识到其中的“野蛮”意味（0047～0053）
- 不用“常胜不败”是因为还没连胜，不配那么叫（0038～0040）
- 她要成为的顶级偶像：让全世界笑、让人觉得偶像好玩有趣，全力奔跑给偶像们撒热与火焰（0065～0068）
- 制作人是他那组制作人科里唯一把担当偶像送进今年『H.I.F』的（0024、0025 制作人）
- 新目标：常胜不败的『一番星』（0077）
