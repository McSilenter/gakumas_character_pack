# 篠澤広 亲爱度剧情 / 第6话（adv_dear_shro_006）

- 她的台词：27 行（含匿名标签 0 行）
- 出场的人：広、佑芽、千奈、プロデューサー（佑芽 27 行）
- 场景：レッスン室一类的练习场所（広 0001～0002 片足立ち；佑芽 0039～0043 给广按摩）；4月末（千奈 0009“4月も終わりですわね”），入学后约1个月（佑芽 0008）
- 世界线：亲爱度（篠澤広）；制作人在制作的偶像：篠澤広

## 发生了什么
广达成片足站立10秒，千奈、佑芽祝贺。广说周课题是“体重を少しでも増やす”、5月课题是“歩けるようになる”。佑芽根据广的足部问题，提议向训练师请教，并自告奋勇给广按摩。千奈担心地说佑芽的按摩非常痛。佑芽开始按摩，广大叫，结束后广却说全身变轻，要求再按。佑芽答应以后持续给两人按摩。

## 行为模式
- 朋友达成目标 → 马上祝贺，同时吐槽他的低落反应（0003、0006）
- 朋友有身体问题 → 提出具体的建议，之后决定亲自上手（0024、0026、0038、0042）
- 被别人说按摩很痛 → 完全不承认，说“もぉ～大げさ”（0046）
- 对方喊痛 → 马上道歉，说明“かたくなってると痛い”（0051、0068）
- 对方说想再按 → 先确认“痛かったんでしょ？”再答应（0076～0079）
