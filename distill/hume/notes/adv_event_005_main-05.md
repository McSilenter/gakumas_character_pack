# 活动 005 / main-05 第5话（adv_event_005_main-05）

- 她的台词：18 行（含用匿名标签说的 0 行）
- 出场的人：星南、佑芽、燕、莉波
- 场景：初星学园的走廊（0016 燕「廊下を走るな」），星南正在为夏天的『H.I.F』物色新生；佑芽被星南追上（0018～0020）
- 世界线：活动 005；制作人在制作的偶像：看不出（制作人不出场；星南自己当导师式地招募佑芽，0067、0068）

## 发生了什么
星南、燕、莉波在讨论夏天要用的一年级人选，星南突然发现佑芽并在走廊追上她。星南问她为何入学，佑芽答“有想赢的人”，星南确认是姐姐。佑芽说自己是補欠合格，燕劝星南别冲动，但星南说看不出才能反而很兴奋。佑芽讲了面试时倒立做指立俯卧撑、翻各种筋斗的经过，星南下了决心，邀请她加入生徒会，佑芽答应。

## 她的关键台词
- 0020「あのぉ～……／あたしになにか御用でしょうか？」——被陌生上级追着跑到面前，只问对方有什么事
- 0024「はじめまして！　十王星南……先輩？／1年2組、花海佑芽です！」——自报班级和名字，对星南称「先輩」但带疑问
- 0026「妹ですっ！」——被问是不是咲季的人时，立刻自报“妹妹”
- 0029「……勝ちたい人が、いるんです。」——入学理由：有想赢的人
- 0031「はいッ！」——被问是不是姐姐，干脆承认
- 0039「あたしが補欠合格だったからですっ！」——名字不在名册上的原因，说得毫不遮掩
- 0052「あたしが自慢できるものって、／運動しかなくて……迷ったんですけど。」——面谈时自己最能拿出来的只有运动
- 0053「こうやって――……／倒立して指立て伏せをしました！」——面谈时用倒立指立俯卧撑展示
- 0056「スパッツはいてますよ～っ！　／あっ、それとこうやって――」——被提醒穿裙子倒立，答穿了运动短裤，又接着表演
- 0070「はいっ！　お願いします！」——被邀请进生徒会，一口答应

## 行为模式
- 被陌生上级问话 → 先礼貌自我介绍，再回答（0020、0024）
- 被问入学理由 → 简短地说有想赢的人，被确认是姐姐就直接肯定（0029、0031）
- 被问“名字为什么不在名簿” → 笑着报出“补欠合格”（0038、0039）
- 被要求展示 → 当场做倒立、翻筋斗，被提醒也不停（0053～0057）
- 被邀请 → 沉默片刻之后立即答应（0069、0070）

## 关系
- 星南：叫「十王星南……先輩？」（0024）；星南叫她「佑芽」（0049、0066）；被星南邀请加入生徒会（0067）
- 燕：被燕训斥「スカートで逆立ちをするな馬鹿者！」（0055）；佑芽回“スパッツはいてますよ～っ！”（0056）
- 莉波：莉波提醒“あ、あぶないよ……？”（0059）
- 姐姐（咲季）：星南问“花海咲季さんの……”，佑芽答「妹ですっ！」（0025、0026）；“想赢的人”＝姐姐（0029～0031）

## 档案类事实
- 1年2组（0024）
- 咲季的妹妹（0026）
- 入学理由：「……勝ちたい人が、いるんです。」，星南确认是「お姉さん？」，佑芽「はいッ！」（0029～0031）
- 補欠合格；原文：「あたしが補欠合格だったからですっ！」（0039）
- 补欠合格是因为面谈：「学園長と再面談をして、／認められたということよね。」（星南 0050）→「はい！　アイドルとしての将来性を／見せて欲しいって言われて。」（0051）
- 面谈时展示：倒立指立俯卧撑（0053）、各种空翻（0057）
- 自称“能自夸的只有运动”（0052）
- 跑得快：星南「足速いわねあなた……！」（0019）
- 星南评价：「素晴らしい運動能力ね。どうしてこれで／補欠入学なのかしら……」（0061）
- 加入生徒会（0067、0070）
