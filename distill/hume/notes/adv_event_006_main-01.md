# 活动 006 班级对抗初星大运动会 / main-01 第1话（adv_event_006_main-01）

- 她的台词：35 行（含用匿名标签说的 0 行）
- 出场的人：佑芽、千奈、莉波、星南（星南只在开头 0003～0007）
- 场景：星南下达任务（0003～0007，地点未写）；之后佑芽在裏山迷路，发现温泉（0027「さっき裏山で遭難しちゃった」），再回到千奈、莉波身边
- 世界线：活动 006（班级对抗初星大运动会）；制作人在制作的偶像：看不出（制作人不出场）

## 发生了什么
星南让佑芽为生徒会想一个面向全校学生的活动，千奈和莉波协助。佑芽想不出来，在裏山迷路，找到一处小温泉，以为是秘境，兴冲冲拍了照回来报告。千奈和莉波误会成遇难（千奈叫救援），说清后，千奈指出那是自家别墅里的温泉，佑芽失望。千奈反而决定为生徒会提供温泉，莉波也想去看。

## 她的关键台词
- 0009「ぜ～～～んぜんっ！／思いつかないよぉ！」——被交代任务后坦率说想不出
- 0010「トレーニング合宿なら／たくさん思いつくんだけどなぁ～。」——想得到的都是训练方面的
- 0014「ま、迷っちゃった？／遭難しちゃった！？」——迷路后第一反应是遇难
- 0015「お、お、落ち着いて！／こういうときは、川に沿って進めば……」——自己慌了却对自己说“冷静”，并想到沿河走
- 0019「もしかして……あたし、／秘湯を見つけちゃった？」——把温泉当作自己的发现
- 0023「聞いて聞いて！／大発見！　大発見なんだよーーーーっ！」——兴奋地喊
- 0041「生徒会で開催するイベント、／この温泉を使ってできないかなって！」——把发现变成活动点子
- 0048「ええーーーーっっ！？／千奈ちゃんの温泉ってこと！？」——得知温泉在千奈家别墅，大吃一惊
- 0053「じゃあ仕方ない！／違うの考えますっ！」——失望后立刻转换，准备重新想
- 0058「やったぁっ！」——千奈提供温泉后的反应

## 行为模式
- 被交给不擅长的任务 → 先坦白想不出，用自己熟悉的训练来比（0009、0010）
- 迷路 → 先惊慌，自己说“冷静”，再想到可做的办法（0014、0015）
- 有了发现 → 马上拿给同伴看，边跑边喊，等不及对方说完（0022、0023、0025）
- 被指出自己的发现其实是别人家的 → 惊讶、失望，然后马上说“那想别的”（0048、0051、0053）
- 对他人的善意 → 直接高兴（0057、0058）
