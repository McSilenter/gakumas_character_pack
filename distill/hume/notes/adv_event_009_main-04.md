# 活动 009 莉莉娅与清夏的日常 / main-04 蛋糕系起的友情圣诞节 第4话（adv_event_009_main-04）

- 她的台词：23 行（含用匿名标签说的 0 行）
- 出场的人：ことね、佑芽、リーリヤ、ケーキ屋の店主（0001、0005）
- 场景：蛋糕店的后厨，打工当天（0001～0005）；之后リーリヤ躲到别处（0047～）
- 世界线：活动 009（莉莉娅与清夏的日常）；制作人在制作的偶像：看不出（制作人不出场）

## 发生了什么
三人在店主的指导下做蛋糕。リーリヤ熟练，佑芽把鲜奶油弄成黑色，说是加了“秘制调味”，被ことね责备。佑芽告诉ことね，姐姐说要来买，还发来消息，佑芽慌了，向リーリヤ连珠炮地提问，把她吓得躲去洗手间。ことね去安慰リーリヤ，之后リーリヤ教佑芽挤奶油，佑芽做成，拿给リーリヤ试吃。

## 她的关键台词
- 0003「頑張りますっ！」——打工开始时的第一句
- 0014「えっとぉ……隠し味を入れた方が、／美味しくなるかなぁ～って！」——把奶油做成黑色的理由
- 0016「ご、ごめんなさ～い！」——被ことね训后立刻道歉
- 0018「うん、リーリヤちゃんすごいよね！／あたしも上手にケーキ作りたいっ！」——别人比自己强，直接夸并想学
- 0023「ケーキ屋さんでバイトするって／お姉ちゃんに報告したんだけど、」——向姐姐报告了打工
- 0027「佑芽のお手製ケーキ、楽しみだわ！／……って書いてあったけど……」——转述姐姐的回信
- 0028「ど、どうしよう……！？／まだちゃんとケーキ作れないっ！」——收到期待后慌了
- 0038「お願い！　／あたし、お姉ちゃんを喜ばせたいの！」——想把蛋糕做好的原因是让姐姐高兴
- 0043「き、嫌われちゃったかなぁ！？／あたし、ちょっと焦っちゃって……」——意识到自己吓到了リーリヤ
- 0071「これであたしも、／ケーキ職人になれるよっ！」——做成之后夸张的高兴
- 0075「リーリヤちゃん、試食してみて！／はい、あ～ん！」——马上要把成果让教自己的人试吃

## 行为模式
- 被指出失误 → 用“加了秘制调味”之类的说法辩解，再道歉（0014、0016）
- 有想让姐姐满意的心 → 一着急，把一连串问题连珠炮抛给对方（0032～0038）
- 发现自己吓到对方 → 马上担心“被讨厌了”，道歉（0043、0045）
- 被教会 → 欢呼，立即回报对方（0070、0071、0075）

## 关系
- リーリヤ：称「リーリヤちゃん」（0018、0029、0036、0070、0075）；她请求リーリヤ教，リーリヤ逃走，后又教会她
- ことね：称「ことねちゃん」（0021）；ことね叫她「佑芽ちゃん」（0013）、「佑芽」（0054）
- 姐姐（咲季）：称「お姉ちゃん」（0023、0038）；0024「当日買いに来てくれるって！」；ことね原话：0025「ケーキなんてアイドルの食べ物／じゃないとか言ってたくせに……」、0026「あのシスコンめ……」

## 档案类事实
- 不会做蛋糕：奶油变黑（0013）；海绵蛋糕变干、奶油发粘、草莓溢出、形状怪（0032～0034）
- 姐姐说“蛋糕不是偶像吃的东西”（ことね转述 0025）；姐姐要来买（0024）
- 对姐姐：想让她高兴（0038）

## 不确定
- 0027「佑芽のお手製ケーキ、楽しみだわ！／……って書いてあったけど……」：这是佑芽念姐姐发来的文字（「って書いてあった」），不是佑芽模仿姐姐的口吻。
- 0025「ケーキなんてアイドルの食べ物／じゃないとか言ってたくせに……」是ことね的话，姐姐咲季何时说过本篇没有交代。
