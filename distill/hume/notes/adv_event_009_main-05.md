# 活动 009 莉莉娅与清夏的日常 / main-05 蛋糕系起的友情圣诞节 第5话（adv_event_009_main-05）

- 她的台词：15 行（含用匿名标签说的 0 行）
- 出场的人：ことね、佑芽、リーリヤ、咲季、清夏、ケーキ屋の店主
- 场景：初星学园的圣诞活动现场，摊位卖蛋糕（0001「初星学園、クリスマスイベント開催中」）
- 世界线：活动 009（莉莉娅与清夏的日常）；制作人在制作的偶像：看不出（制作人不出场）

## 发生了什么
活动当天，佑芽负责吆喝，声音太大被ことね说。姐姐咲季来买佑芽做的蛋糕，坐下吃后夸好吃；ことね问她“不是说蛋糕不是偶像吃的东西吗”，她说这个特别。清夏也来，リーリヤ和她说话。卖完后店主留了3块蛋糕，佑芽想拍照发给姐姐，并提议“兼职蛋糕店的偶像”，被ことね说要等成为独当一面的偶像；リーリヤ约她改天一起做点心，佑芽提出比赛。结算工资时佑芽说第一次看到ことね那么高兴。

## 行为模式
- 被姐姐夸 → 先把功劳给教自己的人（0019、0020）
- 对新的事觉得有趣 → 想和偶像联系起来，被劝退也接受，但留下“还想做”（0064、0067）
- 有人约她一起做 → 立刻答应，并提出比赛（0069、0071）
- 想和姐姐分享 → 拍照发给姐姐（0059）

## 关系
- 咲季：称「お姉ちゃん」（0011、0059）；咲季叫她「佑芽」（0010）；咲季说「これは特別よ。／佑芽が作ったケーキだもの。」（0014）；咲季对她和リーリヤ要好感到「複雑だわ」（0023）
- リーリヤ：称「リーリヤちゃん」（0020、0062、0064）；リーリヤ约她「一緒にお菓子作ろう？」（0068）
- ことね：ことね叫她「佑芽」（0042），ことね在本篇说“シスコンだな～、相変わらず”（0024）

## 档案类事实
- 咲季是她的姐姐，会来买她做的蛋糕（0010～0012）
- 咲季吃了她做的蛋糕，评价「うん、美味しいわ！」（0019）
- 她想继续做点心：0067「もうちょっとやりたくて。」
