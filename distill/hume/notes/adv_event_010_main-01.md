# 活动 010 星南与燕的日常 / main-01 情人节协奏曲 第1话（adv_event_010_main-01）

- 她的台词：11 行（含用匿名标签说的 0 行）
- 出场的人：千奈、佑芽、広、美鈴、司書、莉波；佑芽、千奈、美鈴在前半（0001～0028），后半（0029 起）是広、司書、莉波
- 场景：学园里，情人节前两天（0003「明後日のバレンタイン」）；后半在图书馆（広借书）和某处（莉波闻到焦味）
- 世界线：活动 010（星南与燕的日常）；制作人在制作的偶像：看不出（制作人不出场）

## 发生了什么
佑芽问千奈情人节要不要送人，千奈说要亲手给爷爷做巧克力。佑芽说每年和姐姐一起做巧克力并互赠；千奈学咲季的口气说“比谁的好吃”，佑芽说一点都不像，并说以前比过但完全赢不了，现在是让姐姐教她。美鈴加入，讲起中等部时在组合内互送，手毬每年都会收下，也会偷偷放进鞋柜，佑芽追问为什么放鞋柜。

## 她的关键台词
- 0003「明後日のバレンタイン、千奈ちゃんは／誰かにチョコあげるの？」——首先关心朋友送谁
- 0009「へえぇ～。千奈ちゃん、偉いね。」——听说千奈要亲手做，直接夸
- 0012「ふっふー、あたしはねー……／お姉ちゃん！」——送巧克力的对象第一个就是姐姐
- 0014「毎年、お姉ちゃんと一緒に／チョコを作ってー、交換するんだっ！」——每年和姐姐一起做并交换
- 0017「千奈ちゃん、ぜんぜん似てないよぉ～。」——千奈模仿咲季说话，她笑着说不像
- 0018「昔は勝負もしてたんだけど、／ぜんっぜんかなわないから、」——以前比过制作巧克力，完全赢不了
- 0019「今はお姉ちゃんに／教えてもらってるんだぁ。」——现在让姐姐教
- 0023「美鈴ちゃんは、誰かにあげるの？」——也问美鈴
- 0028「えっ、なんで下駄箱に！？」——被美鈴的话吸引，当场追问

## 行为模式
- 朋友说自己的计划 → 先夸、先听完（0009）
- 说到姐姐 → 马上回答“お姉ちゃん”，笑容满面，细说每年的习惯（0012、0014）
- 被拿姐姐开玩笑 → 笑着指出“不像”，并把胜负的经历说成已过去（0017～0019）
- 听到奇怪的细节 → 立刻追问为什么（0028）

## 关系
- 千奈：称「千奈ちゃん」（0001、0003、0017）；千奈叫她「花海さん」（0002、0011），模仿她姐姐时叫「佑芽」（0016，这一行是千奈在演咲季）
- 美鈴：称「美鈴ちゃん」（0023、0028）；美鈴讲手毬的往事
- 姐姐：称「お姉ちゃん」（0012、0014、0019）

## 档案类事实
- 每年和姐姐一起做巧克力并交换：「毎年、お姉ちゃんと一緒に／チョコを作ってー、交換するんだっ！」（0014）
- 与姐姐的制作巧克力：「昔は勝負もしてたんだけど、／ぜんっぜんかなわないから、」（0018）、「今はお姉ちゃんに／教えてもらってるんだぁ。」（0019）

## 不确定
- 0016「佑芽、どっちのチョコが美味しいか、／勝負よっ！」：说话人标签是千奈，0015「あ、それで、あれですわね！」是千奈在模仿咲季，0017 佑芽说“不像”，据此不是佑芽的话也不是咲季本人的话。
- 0018 的“昔”是几时、咲季是否真的每次赢，本篇只有佑芽的“完全赢不了”这一句。
