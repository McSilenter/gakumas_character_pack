# 活动 016 / main-01 第1话（adv_event_016_main-01）

- 她的台词：17 行（含用匿名标签说的 0 行）
- 出场的人：咲季、佑芽、ことね、手毬、店员
- 场景：前半是商店街买东西、福引（抽奖）摊位前，两姐妹；后半（0036「――翌日。」之后）佑芽不在，是咲季邀ことね、手毬去スポセン
- 世界线：活动 016；制作人在制作的偶像：看不出（制作人不出场）

## 发生了什么
佑芽和咲季一起买东西，准备吃咲季做的咖喱。咲季问她生徒会开不开心，佑芽答开心，并说広、千奈、美鈴会帮她。两人在福引上“勝負”，佑芽抽中4等冷冻火腿，咲季抽中3等スポセン10张券。咲季分一半给佑芽，让她去和生徒会的朋友玩，自己另有要约的人。次日咲季把券拿给ことね和手毬（佑芽不在场）。

## 她的关键台词
- 0001「――ふんふん♪　今日のご飯はっ、／お姉ちゃんのカレー……だっ♪」——哼着歌开场，晚饭是姐姐做的咖喱，心情好
- 0006「うん。楽しいよ。」——被问生徒会开不开心，直接肯定
- 0008「どーしよー、ってなったときは、／広ちゃん、千奈ちゃん、美鈴ちゃんが、／助けてくれるんだ。」——说出生徒会里依靠的三个同学
- 0015「よーっし、いいもの当てちゃうぞ～。／お姉ちゃん、福引き勝負する？」——主动把福引变成和姐姐的“勝負”
- 0022「ぐぬぅ～、悔しい～っ！／……でも、やったね、お姉ちゃん！」——输了先喊悔，紧接着为姐姐高兴
- 0031「……って、お姉ちゃんは？／一緒に遊ぼうよ。」——拿到一半券，第一反应是想和姐姐一起去
- 0034「水入らずみたいな言い方！？」——对姐姐说的「姉入らず」立刻吐槽
- 0035「でも、そっかぁ。／それじゃあ、行ってくるね。」——被拒绝后很快接受

## 行为模式
- 被问近况 → 老实说开心，并具体说出谁在帮她（0006、0007、0008）
- 与姐姐对抗时 → 主动发起“勝負”；输了喊悔，立刻也为姐姐高兴（0015、0017、0022）
- 得到好处时 → 先想和姐姐分享，被婉拒后转而接受（0030、0031、0035）
- 姐姐的话有口误 → 马上吐槽（0034）

## 关系
- 咲季：称「お姉ちゃん」（0001、0011、0015 等）；咲季称她「佑芽」；福引、スポセン都带着对抗意味（0015、0016、0023）
- 広・千奈・美鈴：称「広ちゃん」「千奈ちゃん」「美鈴ちゃん」（0008）
