# 活动 024 / main-02 第2话（adv_event_024_main-02）

- 她的台词：24 行（含用匿名标签说的 0 行）
- 出场的人：美鈴、佑芽、星南、莉波
- 场景：9月下旬，生徒会室，文化祭准备；0025「――数日後。」之后是佑芽和美鈴两人在讨论、翻资料
- 世界线：活动 024；制作人在制作的偶像：星南是佑芽和美鈴的制作人（见 024-01 0009）；本篇看不出

## 发生了什么
莉波汇报各班的文化祭内容，星南说这次交给佑芽和美鈴企划。两人收集了全校的意见，案子太多，反而定不下来。佑芽提出想做“その日限りの特別な思い出”，两人翻旧资料，佑芽找到过往的体验型谜解活动，大喊“これだ”。美鈴说要找擅长谜题的人帮忙，佑芽说“ねぇ、美鈴ちゃん”，美鈴先说“最後まで、ふたりで作りましょう”，佑芽答好。

## 她的关键台词
- 0021「うん。千奈ちゃん、／最近忙しそうだもんね……！」——体谅千奈忙，不去依赖
- 0022「あたしたちふたりで、／スッゴい企画を考えよう！」——对任务干劲十足
- 0027「アイデアがぁ……／まとまらないいいぃぃっ！！」——卡住时直接喊出来
- 0031「要望が集まりすぎて、／逆にまとまんなくなっちゃったぁ！」——说明难处
- 0034「『みんなが楽しめるもの』かって／いうと違うかもしれないぃ……」——判断标准是“大家都能玩”
- 0036「美鈴ちゃんこそ。手毬ちゃんと、／のど自慢大会に出場したい～って／言わないの？」——反问美鈴有没有想做的私人点子
- 0038「きっちり果たさないと！　だよね！」——把先辈托付的事当责任
- 0041「『その日限りの特別な思い出』が／生まれるような出し物がいいなっ！」——提出企划核心
- 0051「……こ……／これだあああぁぁぁ！！」——找到谜解企划时的欢呼
- 0056「――――――――ねぇ、美鈴ちゃん。」——察觉到要请外人帮忙，先叫美鈴
- 0058「いいよ。」——同意让美鈴先说

## 行为模式
- 被交付企划 → 先高兴地确认“いいんですかっ？”，然后拉着搭档一起干（0008、0022、0023）
- 想法太多定不下来 → 直接喊难，但不放弃，按“大家都能玩”的标准再整理（0027、0031、0034、0041）
- 搭档说“想让别人做自己的私心” → 反问对方，随即承认两人一样，都是先辈托付的事要办好（0036、0038）
- 找到合适的点子 → 喊出来，然后对搭档说“你来说吧”这种默契（0051、0056、0058）

## 关系
- 美鈴：称「美鈴ちゃん」（0018、0023、0036、0056）；美鈴称「佑芽さん」（0019、0037）
- 星南：星南 0007 对两人说「佑芽、美鈴。／今回はあなたたちが企画なさい。」，佑芽 0008 答「いいんですかっ？」；佑芽本篇没有直接称呼星南（星南称她「佑芽」）
- 千奈：称「千奈ちゃん」（0021）；美鈴 0020「今回、倉本さんには頼れません。」
- 手毬：称「手毬ちゃん」（0036）

## 档案类事实
- 佑芽对手毬：0036「手毬ちゃんと、／のど自慢大会に出場したい～って／言わないの？」，针对美鈴；佑芽自己想的是什么，美鈴 0035 说「いいんですか？／腕相撲選手権にしなくて。」，佑芽没有直接回答，0038 说「きっちり果たさないと！　だよね！」
- 谜解体验企划：0049「……ん？　なんだろ、これ。／オリジナル演劇……の、企画書と台本？」，0050「一度参加したら、二度と同じ演目に／参加できない、体験型謎解き……！」
- 美鈴 0037「きっと佑芽さんと同じです。／先輩方に託された仕事ですから。」

## 不确定
- 0035 美鈴「腕相撲選手権」是美鈴在暗示佑芽想做，佑芽 0036 没有承认；佑芽本人是否真想办腕相撲选手权，本篇没写。
- 0055 美鈴「こういう……謎作りが得意な方に。」没有点名，0056 佑芽「――ねぇ、美鈴ちゃん。」、0057 美鈴「わたしから言ってもいいですか？」都没说出名字，本篇没写这个人是谁。
