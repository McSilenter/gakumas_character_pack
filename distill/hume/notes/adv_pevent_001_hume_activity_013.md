# 花海佑芽 培育事件 001 activity / 013 报告作业（adv_pevent_001_hume_activity_013）

- 她的台词：10 行（含用匿名标签说的 0 行）
- 出场的人：佑芽、プロデューサー
- 场景：地点看不出；她的课题做不完，请制作人帮忙（0001）。课题是看偶像 live 写分析报告（0003 制作人）。0006～0009、0010～0014、0015～0019 是三种并列走向
- 世界线：培育（花海佑芽）（培育事件 pevent_001）；制作人在制作的偶像：佑芽（0006 制作人指导她的报告）

## 发生了什么
她道歉说课题怎么都做不完，制作人说没关系、集中完成（0001、0002）。制作人看出报告太偏感性、像感想文，她说想写得更像报告（0003～0005）。
走向一：制作人说缺分析、可以和别的 live 比较，她说“对比着看和体育一样”，突然觉得能写了（0006～0009）。
走向二：制作人指出同样的编舞在别处她没觉得可爱，问为什么，她想不通，说分析好难（0010～0014）。
走向三：制作人说先写结论，她问乐趣不是放最后比较好吗，制作人说报告不需要乐趣，她照着重写（0015～0019）。

## 她的关键台词
- 0001「すみません～～～～！／どうしても課題が終わんなくて～～！」——作业做不完
- 0005「もっとレポートっぽく／したいんですけど……」——知道自己写得不像报告
- 0008「見比べる……そっか！／スポーツと同じですねっ！」——用体育理解分析
- 0009「急にできる気がしてきました。／相談してよかったぁ～～～！」——一通就来劲
- 0012「たしかに……こっちのときだけ／かわいい！　って思ったんですよね。」——凭感觉看 live
- 0014「分析って難しいですねー……」——不擅长分析
- 0016「お楽しみは最後の方が／いいんじゃないんですか？」——按娱乐的思路写报告

## 行为模式

- 抽象的方法 → 换成体育里的类比就理解了（0008）
- 被问“为什么这样觉得”→ 说不出理由，觉得不可思议（0012、0013）

## 关系
