# 花海佑芽 培育事件 001 school / 005 N极与S极（adv_pevent_001_hume_school_005）

- 她的台词：8 行（含用匿名标签说的 0 行；8 行全是括号里的心声）
- 出场的人：理科教師、佑芽
- 场景：理科课上的小测验（0001 理科教師）。0006～0011（答对）、0012～0016、0017～0022（答错）是制作人代答后的三种并列走向（她心里向制作人求救，0005）

## 发生了什么
理科老师出题：叫你“朝 N 极走”，该往南还是往北（0001～0003）。她心里想 S 极 N 极是磁铁吧，指南针北是 N……向制作人求救（0004、0005）。
答对的走向：老师解释指南针 N 极所指的北其实是 S 极；她心里想指南针小学科学课之后就没用过，将来有用吗（0006～0011）。
答错的走向一：老师说 N 极在南极、S 极在北极；她心里说原来用磁铁想就行，但感觉会搞混（0012～0016）。
答错的走向二：老师又讲到地磁逆转，她心里说太难了、老师在说什么，打算之后问制作人（0017～0022）。
