# P卡 秦谷美鈴【Star-mine】 / 第3话 Star-mine 第3话（adv_cidol-hmsz-3-010_03）

- 她的台词：16 行（含用匿名标签说的 0 行）
- 出场的人：美鈴（37 行）、星南（16）、佑芽（7）
- 场景：与第1、2话同一场景，生徒会室一类的地方
- 世界线：亲爱度（秦谷美鈴）·P卡；制作人在制作的偶像：美鈴（0003 美鈴说“わたしのプロデューサー”）

## 发生了什么
误会解开后，美鈴要星南以后别再和制作人单独说话，星南答应，并羡慕美鈴被担当偶像如此爱慕。美鈴问“临时ユニット”的成员，佑芽举手想和美鈴搭档，星南自荐加入，认为与这两人共唱对自己有益。美鈴先坦白自己当初加入生徒会是为了把它变成 SyngUp! 的聚集处，还想把次期会长的人事权拿到手，也曾小看星南；现在觉得生徒会的人都难对付。星南回应这是“最大的赞辞”，三人决定组成“临时ユニット”。剧情经过参照 hmsz、hume 笔记。

## 她的关键台词

- 0006「担当アイドルに……こんなに／慕ってもらえるなんて。羨ましい。」——羡慕美鈴的制作人
- 0015「――よかったら、／私もまぜてくれるかしら？」——主动加入佑芽与美鈴的搭档
- 0017「『臨時ユニット』のメンバーは、／この3人にしようと思っているの。」——提出三人组
- 0018「とてつもない才に溢れるあなたたちと／共に歌うのは、私にとって有益だから。」——说明自己加入的理由是“对我有益”
- 0021「私にまったく臆さないのは、／あなたの長所ね、佑芽。」——评价佑芽毫不畏惧自己
- 0031「！？　たまっ……なんですって……！？」——听到“把生徒会变成聚集处”时吓到
- 0039「………………急に邪悪なたくらみを／吐露されても……困ってしまうわ。」——对美鈴突然说出企图的无奈
- 0047「……気付いていたわ。薄々ね。／どうしていま、そんなことを？」——美鈴说小看自己时，说自己稍微察觉到了，并问为何此时说
- 0055「……秦谷美鈴にとって最大の賛辞。／そう受けとっておく。」——美鈴说“太阳、光荣”后，把它当作最大的赞辞
- 0057「ええ、この3人で『臨時ユニット』を／結成するわ！」——宣布结成

## 行为模式
- 被后辈要求以后别和制作人单独说话 → 先应下“わかったわ”，再羡慕（0005、0006）
- 想加入一件事 → 先说出“有益”的理由，而不是情感理由（0018）
- 突然听到后辈的坦白 → 吓一跳，但随后说“稍微察觉到了”并追问动机（0031、0047）
- 被说小看自己 → 不生气，把动机之后的赞辞当作赞辞收下（0055）

## 关系
- 美鈴：叫「美鈴」（0001、0022）；美鈴叫她「星南会長」（0026）「星南先輩」（0028、0053 等）
- 佑芽：叫「佑芽」（0021）；佑芽想和她同台，说“学園一のアイドル”（0019）
- 美鈴的制作人：星南说“羨ましい”“すごいプロデューサー”（0006、0007）

## 档案类事实
- 在美鈴的认识里，生徒会的人是“素晴らしいアイドルで、尊敬できる先輩方”（0049，美鈴的话）；美鈴称她为“初星学園の太陽”（0053，美鈴的话）
- 她稍微察觉到美鈴曾小看过她（0047）
- 觉得与美鈴、佑芽共唱对自己有益（0018）
