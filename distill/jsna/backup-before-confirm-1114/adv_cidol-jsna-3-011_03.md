# P卡 十王星南【Star-mine】 / 第3话 Star-mine 第3话（adv_cidol-jsna-3-011_03）

- 她的台词：31 行（含用匿名标签说的 0 行）
- 出场的人：星南（31 行）、プロデューサー（16）
- 场景：能一眼望尽初星学園的地方（0003），她说今天天气也好（0001）；前一天她熬夜想组合（0025）
- 世界线：亲爱度（十王星南）·P卡；制作人在制作的偶像：十王星南（0042 制作人说“トップアイドル・十王星南が目指すのは”）

## 发生了什么
她说喜欢这里，因为能一眼望尽初星学園、装满回忆；制作人说最近也喜欢上了，她说自己最近更喜欢了，要继续积累新回忆、继续讨论（0001～0007）。她说的最强组合是秦谷美鈴、花海佑芽、十王星南三人；制作人猜她是看能力值从高往下选的，她说除掉了三年级，大致如此，还惊讶他看不见能力值却猜中（0008～0013）。制作人说两人都在生徒会、已经由她在制作，现实上可行；她察觉他评价不高，承认这组合安易、解决不了她的毕业问题、也没什么协同效应——但很强，三个超强偶像组在一起不就是最强吗（0014～0024）。她说熬夜想了很久，觉得即使算上 3 組、走到学园外，也能战到底、能瞄准顶级偶像（0025～0028）。制作人问组合名字，她说想过但决不说出口，给模拟上的组合起名让她觉得罪过；制作人就不问了，提议把这个最强组合当作十王星南的假想敌（0029～0039）。她说是强敌，不知能不能赢；制作人说必须赢，她接着说出“世界一のアイドル”，说就上他的“口車”，宣布模拟上的“私たち”从此刻起是她十王星南的敌人，要让对方知道谁才是真正的顶点（0040～0047）。

## 行为模式
- 喜欢的地方 → 说出理由，并问对方的感受（0003、0004）
- 选人 → 先看能力值，排除不现实的条件，结论直截了当（0011、0012、0022）
- 方案被看出评价不高 → 先自己列出全部缺点，再坚持“但是很强”（0016～0019）
- 被问到自己起的名字 → 坚决不说，并坦白理由（0033～0035）
- 被给了强大的假想敌 → 先说没把握，再被激起斗志，高声宣战（0040、0044～0047）
