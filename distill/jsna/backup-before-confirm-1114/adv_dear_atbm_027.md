# 雨夜燕 亲爱度剧情 / 第27话（adv_dear_atbm_027）

- 她的台词：17 行（含用匿名标签说的 0 行）
- 出场的人：燕、プロデューサー、星南
- 场景：夏季『H.I.F』之后；前半燕和制作人开会，后半燕把星南叫到某处（0035「わざわざこんなところに呼び出して。」），地点没写
- 世界线：亲爱度（雨夜燕）；制作人在制作的偶像：雨夜燕

## 发生了什么
燕和制作人决定冬季前强化『スター性』（制作人说明能力值是 Vocal、Dance、Visual 三要素的指标，星南称之为アイドルパワー，0014、0015）。之后燕把星南叫出来，确认撤回引退后“毕业后引退”的说法怎么办；星南说放心，不会再放弃偶像，会继续站在燕身边。燕说信不过，要她约定：冬季『H.I.F』燕赢了，星南毕业后就来当100プロ的偶像、和燕一直战斗下去。星南说燕的要求乱来，而且自己赢了的报酬等于没有；燕改口说星南赢了就什么都听她的，星南说那并不怎么让人高兴，并说终于明白燕为什么对美鈴变温柔了。最后她叹气接受：燕的演唱会给了她希望，帮了她的燕有权这样要求，把未来押在和燕的胜负上也不坏；说现在一胜一败，下次才是真正的胜负，决战在冬季『H.I.F』。

- 0058「ようやく分かったわ。／あなたが美鈴に優しくなった理由が。」——由燕的赌约推断出燕和美鈴之间的事
- 0062「私を助けたあなたには、／それぐらいのことを言う権利がある。」——接受燕的要求的理由

## 行为模式
- 被追问以前说过的话 → 先让对方放心，再明确表态（0041、0042）
- 对方提出不对等的约定 → 先吐槽、指出漏洞，对方改条件后又冷淡地评价，最后叹气接受（0050～0060、0063）
- 从对方的言行推出隐情 → 点破出来（美鈴的事），让对方尴尬（0058、0059）
- 接受挑战 → 用和对方对称的话（「私のライバル」）回应（0067、0068）

## 关系
- 燕：她叫燕「燕」（0035、0041、0064）、「あなた」（0042、0050）、「私のライバル」（0068）；燕叫她「星南」（0036）、「貴様」（0039）、「私のライバル」（0067）。她接受燕的赌约：冬季『H.I.F』燕赢了就毕业后去100プロ当偶像（0046、0063）
- 美鈴：叫「美鈴」（0058），猜到燕对美鈴变温柔的理由与赌约有关

## 档案类事实
- 表态不会再放弃当偶像（0041）
- 和燕约定：冬季『H.I.F』若燕赢，星南毕业后成为100プロ的偶像、和燕作为同事务所的对手继续战斗（0046～0048 燕的提议，0063 星南接受）；若星南赢，燕什么都听她的（0055）
- 她把和燕的胜负算作一胜一败（0064）
- 制作人说星南把 Vocal、Dance、Visual 三要素的指标称作アイドルパワー（0014、0015，制作人的话）
