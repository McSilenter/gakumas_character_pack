# 秦谷美鈴 亲爱度剧情 / 第30话（adv_dear_hmsz_030）

- 她的台词：13 行（含用匿名标签说的 0 行）；行号 0054、0056、0058、0059、0060、0061、0062、0063、0064、0066、0067、0069、0070
- 出场的人：美鈴、手毬、愁佳、owl、プロデューサー、星南、？？？（愁佳）、100プロの先輩、一同
- 场景：100プロ的设施里，愁佳的非公开演出（对バン）即将开始前，观众席旁。
- 世界线：亲爱度（秦谷美鈴）；制作人在制作的偶像：秦谷美鈴

## 发生了什么
制作人问美鈴愁佳是什么样的人时，星南出现，说愁佳是「私の心を折ったひと」。她说自己在去年的『H.I.F』赢了，从愁佳手里继承了『一番星』，原以为冬天会再战，但愁佳之后没再参赛；再见到时愁佳已是从100プロ出道的新人，成了「まばゆい巨星」，听一首歌就明白自己无论怎样努力也够不到。美鈴让她别说丧气话，她道歉并说不会再示弱；然后邀二人一起看接下来的舞台。剧情经过参照 ttmr、hmsz 笔记。

## 她的关键台词
- 0054「ええ……私の心を折ったひとだもの。／素晴らしいトップアイドルよ。」——回答美鈴：对方是自己心被折断的人，同时也是顶级偶像。
- 0056「もちろん。こんなに興味深い一戦は、／他にないわ。」——被问为什么来，回答是不愿错过这场对决。
- 0058「ええ。私が勝って、あのひとから／『一番星』を継承した。」——说明去年H.I.F自己赢了、继承了『一番星』。
- 0060「その後、彼女は、『H.I.F』に／参加することはなかった。」——对方此后再没参加过H.I.F。
- 0064「一曲、観ただけで悟ったわ。この先、／どんなに努力しても届くわけがない。／これがトップアイドルなんだって。」——自述看到愁佳演出后的挫折。
- 0066「フフ、ごめんなさい。もう大丈夫……／もう二度と、弱音は吐かない。／誰にだろうと負けはしないわ。」——对美鈴的劝告回答不会再示弱。
- 0067「いまの私は、／あなたたちの『一番星』だもの。」——自己现在是美鈴她们的『一番星』。
- 0070「トップアイドルのステージが。」——期待愁佳的舞台，称之为「かつて私をへし折った」的舞台。

## 行为模式
- 被后辈问到强者时 → 毫不掩饰地说“那个人把我的心折断了”，并认定对方是了不起的顶级偶像（0054）。
- 说到自己的败绩 → 按时间顺序讲清楚，再说明自己的判断（0058～0064）。
- 被后辈劝止 → 笑着道歉并立刻立誓（0066、0067）。
- 以后辈的『一番星』自居 → 用这个立场重新振作（0067）。

## 关系
- 美鈴：称「美鈴」；美鈴称她「星南会長」，说她是「わたしたちの標」（美鈴 0068）。
- 手毬：当手毬追问时作答（0058）。
- 愁佳：称「あのひと」「彼女」，不用名字（0058、0060、0062）。

## 档案类事实
- 去年的『H.I.F』赢了愁佳，继承『一番星』（0058）。
- 愁佳此后未再参加『H.I.F』，之后从100プロ出道（0060、0062）。
- 她在愁佳出道后观看过一首演出，觉得自己无论怎么努力都够不到（0064）。
- 来观看这场对决的原因是「こんなに興味深い一戦は、／他にない」（0056）。

## 不确定

- 0061～0063 说的“次に会ったとき”的时间与场合没有交代。
