# 亲爱度剧情（花海佑芽） / 第36话（adv_dear_hume_036）

- 她的台词：12 行（含用匿名标签说的 0 行）
- 出场的人：佑芽（35 行）、星南（12）、学園長（9）
- 场景：『Hatsuboshi IDOL FESTIVAL』决赛后的『一番星』授与式，会场有观众
- 世界线：亲爱度（花海佑芽）；制作人在制作的偶像：佑芽（0013 星南说“あなたにも、プロデューサーにもね”败给的是佑芽和她的制作人）

## 发生了什么
学園長宣布『Hatsuboshi IDOL FESTIVAL』优胜者是佑芽，并叫现任『一番星』星南上台。星南对佑芽说自己完败，回顾佑芽一开始就是“底が見えない”的偶像，没想到会长这么大。佑芽感谢她一路的关照，星南说不用说出口也传达到了所有看过佑芽演出的人，然后请佑芽在特等席接下『一番星』。之后是佑芽的就任发言，星南不再说话。剧情经过参照 hume 笔记。

## 她的关键台词
- 0011「――はい。」——被学園長叫到“現『一番星』”时，简单应声
- 0012「佑芽……」——走近佑芽，用名字叫她
- 0013「私の完敗よ。あなたにも、／プロデューサーにもね。」——明确承认败给佑芽与制作人两个人
- 0014「思えば……あなたは最初から、／底が見えないアイドルだった。」——回顾佑芽一开始就是看不到极限的偶像
- 0015「いったいこの子はどんなアイドルに／育つんだろうって、わくわくした。」——当时对佑芽成长的期待，是“わくわく”
- 0017「いくらなんでも、／こんなに大きく育つなんて。」——对佑芽成长之大的坦率惊讶（0016「……けどね。」是转折，这里的意思是“想不到会这么大”，不是批评）
- 0018「……驚いたわ。」——简短收尾
- 0025「言葉になんてしなくても、／あなたの気持ち、伝わっているわ。」——佑芽表示感谢后，说不必说出口
- 0026「今日、花海佑芽のライブを観た、／全員によ。」——把“传达到了”扩大到所有看过演出的人
- 0029「さあ……特等席で見せて頂戴。／新たな『一番星』の誕生を。」——请佑芽接任，并说要在最好的位置看

## 行为模式
- 被当面感谢 → 打断“说出口”的必要，说心意已经传达（0025、0026）
- 回顾对手／后辈的成长 → 以自己当时的期待和现在的惊讶来对照（0014、0015、0017、0018）
- 输了 → 直接说“完败”，同时承认制作人的功劳（0013）
- 交接仪式 → 以“特等席”的说法表达期待，而不是自己出风头（0029）

## 关系
- 佑芽：叫「佑芽」（0012）；0026 说“花海佑芽のライブ”；佑芽叫她「星南先輩」（0019）。佑芽说星南“あたしをプロデュースしたかったと言ってくださいました。生徒会に誘ってくださいました”（0021，佑芽的话）
- 制作人：0013 把胜负也算在制作人身上
