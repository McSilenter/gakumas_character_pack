# 活动 021 / main-04 第4话（adv_event_021_main-04）

- 她的台词：14 行（含用匿名标签说的 0 行）；其中 0044 是在回想里重复开头星星场景里的话
- 出场的人：燕（25）、星南（14）、麻央（11）、莉波（3）、学園長（1）、旁白（1）
- 场景：开头旁白「星南と燕が2年生の時――」，是2年级时『H.I.F』结果公布当天（回想）；0048 起回到现在，星南与燕在一起
- 世界线：活动 021；制作人在制作的偶像：看不出

## 发生了什么
回想里，学园长宣布本年度的『一番星』是星南。星南向莉波说，紧张一松手在发抖，体会到前辈们承受的重压，然后去接受采访。之后场景转为燕与麻央的对话，星南不在场；0044 是燕的回想中的星南的话。0048 起回到现在，星南接完确认电话回来，问燕怎么了，说想再去一个地方玩，拉着燕的手出发。

- 0011「これが……／初星学園、星々の頂点の気持ち。」——描述第一次成为頂点

## 行为模式
- 成功之后被问有没有什么 → 先说谢谢，被看出后坦率承认手在发抖（0005～0008）
- 重压 → 想到的是前辈们，然后说“追われ続けるもの”的心情（0009～0011）
- 想继续玩 → 直接说想去的地方并行动（0052、0054）

## 关系
- 莉波：称「莉波」，被称「星南会長」（0004）。她说莉波“什么都看得出来”（0007）。
- 燕：称「燕」。0044 回想与现在的 0048 相接。
