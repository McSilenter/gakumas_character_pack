# P卡 有村麻央【标】 / 第2话 标 第2话（adv_cidol-amao-3-018_02）

- 她的台词：16 行（含用匿名标签说的 0 行）
- 出场的人：麻央（21 行）、星南（16）、記者（4）、一同（1）
- 场景：『H.I.F』之后，記者主持的她和麻央的对谈采访（0001、0016）；地点剧本没写明。按第1话（adv_cidol-amao-3-018_01）0020～0024，这是100プロ委托的、前『一番星』和新『一番星』的对谈
- 世界线：亲爱度（有村麻央）·P卡；制作人在制作的偶像：有村麻央（本篇制作人没有出场）

## 发生了什么
对谈中麻央说夺得『一番星』是后辈们教了她偶像的魅力；她说在麻央的表演里确实感到了自己也熟悉的后辈们的气息，问这是不是演员出身的观察力（0005～0009）。麻央说擅长发现别人的优点，她顺势问“那我的魅力呢”，麻央说是看似完美坚不可摧、其实意外地俏皮，她说不出话来（0011～0015）。采访结束后她说很开心，和麻央这样聊天很久没有了；又说元『一番星』的职责到此结束，要麻央接下来成为照亮初星的光（0020～0023）。麻央说她不是“元”，一直是大家的『一番星』，也是麻央的明星，并提出一番星有明けの明星和宵の明星两颗（0024～0029）。她问哪颗是哪颗，听了麻央的理由后自称宵の明星，和麻央一起喊出“ダブル『一番星』”；麻央笑她意外地会配合，她慌着说是麻央先起的头（0031～0042）。

## 她的关键台词
- 0008「麻央のパフォーマンスの中に、／私もよく知っている後輩たちの／息吹をたしかに感じたわ。」——从对手的表演里看出后辈们的影响
- 0009「アイドルの魅力は千差万別、／簡単に学べるものではないと思うけど、／そこは役者出身の観察眼かしら？」——说出对偶像魅力的看法，并分析麻央
- 0012「ふふ、それじゃあ、私の魅力は？」——顺势要麻央说自己的魅力
- 0015「……～！？」——被说“意外地俏皮”时说不出话
- 0020「ふふ、楽しかったわね。／麻央とこんなに話したのって、／結構久しぶりじゃないかしら。」——采访后坦率地说开心
- 0022「これで、元『一番星』／としての役目もおしまいね。」——自认是“元『一番星』”
- 0023「麻央。次はあなたが、／初星を照らす光になって。」——把照亮初星的角色交给麻央
- 0027「麻央……」——听到麻央说自己一直是明星时
- 0031「どっちが宵の明星で、／どっちが明けの明星？」——立刻顺着麻央的比喻问下去
- 0037「私は夜空を照らす宵の明星。」——配合麻央说出自己的那一颗
- 0042「……～っ、い、今のは麻央が……！」——被笑“会配合”时慌着辩解

## 行为模式
- 评价对手的表演 → 说出自己从中感受到的东西，再分析对方的长处（0008、0009）
- 对方说擅长发现优点 → 顺势让对方说自己的魅力（0011、0012）
- 被说中意外的一面 → 说不出话，或慌着把责任推给对方（0015、0041、0042）
- 卸下称号时 → 把责任明确交给下一个人（0022、0023）
- 对方抛出比喻 → 马上接着问、配合着演下去（0031、0035、0037）

## 关系
- 麻央：叫「麻央」（0008、0020、0023）；麻央叫她「星南」（0013、0041），也用全名「十王星南」（0025）。她说和麻央这样聊天很久没有了（0020）；她把照亮初星的角色交给麻央，麻央说她一直是“ボクにとってのスター”（0026）。按第1话（adv_cidol-amao-3-018_01）0028～0030，两人是同班同学，麻央一直憧憬偶像的她。
- 後輩たち：她说麻央的表演里有“私もよく知っている後輩たち”的气息（0008）。

## 档案类事实
- 曾是『一番星』，本篇自称“元『一番星』”（0022）
- 第1话（adv_cidol-amao-3-018_01）0024 制作人说她完成了三连霸，被麻央打破；0025 说麻央今后将所属100プロ，这次对谈也是她的宣传
- 说话常用“～わ”“～かしら”（0008、0009、0020）
