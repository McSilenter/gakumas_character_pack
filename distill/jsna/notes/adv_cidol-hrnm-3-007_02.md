# P卡 姫崎莉波【Campus mode!!】 / 第2话 Campus mode!! 第2话（adv_cidol-hrnm-3-007_02）

- 她的台词：25 行（含用匿名标签说的 0 行）
- 出场的人：莉波（27 行）、星南（25）、プロデューサー（10）

## 发生了什么
莉波已经记熟『Campus mode!!』的振付，制作人请来她当特别讲师，理由是她是『Campus mode!!』的穿着者（0013～0021）。她祝贺莉波通过『N.I.A』的オーディション，说想支持重要的朋友，也想亲眼确认莉波的成长（0018、0024、0025）。她看了莉波后说偶像的气场变强了，夸制作人的制作准确；自己早注意到莉波有“お姉さんタイプ”的素质却没能这样自然地引出来，作为以制作人为目标的人感到惭愧，问是怎么制作的（0027～0035）。莉波说制作人当她的“弟弟”，她一时愣住，说这制作很独特，之后再详细问（0036～0041）。接着她严格地指导莉波，指出脚尖、手指，要莉波“像飞起的蜂鸟一样”、别用脑子想、把动作打进身体（0044～0051）；莉波心里说第一次见她这么严厉，但被她严格对待有点高兴（0053～0055）。最后她说该传达的都传达了，接下来看莉波自己（0056、0057）。

## 行为模式
- 见到努力的朋友 → 先祝贺、肯定，再说想亲眼确认对方的成长（0018、0025）
- 看到别人的制作成果 → 坦率夸奖，并承认自己没看出来，追问方法（0028～0035）
- 听到出乎意料的答案 → 一时语塞，把话推到“之后再详细问”，咳一声转回正题（0039～0042）
- 指导时 → 事先说会严格，指出具体部位，也用比喻，一再说“違うわ”（0044～0051）
- 指导结束 → 说该传达的都传达了，剩下看对方（0056、0057）

## 关系
- 莉波：叫「莉波」（0016、0022、0057）；莉波叫她「星南会長」「会長」，对她用敬语（0017、0023、0058）。她称莉波是“大切な友人”（0024），给莉波严格的指导；莉波心里说第一次见她这么严厉（0053）。
