# P卡 花海佑芽【ENDLESS DANCE】 / 第3话 ENDLESS DANCE 第3话（adv_cidol-hume-3-016_03）

- 她的台词：13 行（含用匿名标签说的 0 行）
- 出场的人：美鈴（16 行）、星南（13）、佑芽（12）、一同（1）
- 场景：三人练习『ENDLESS DANCE』的休息时间
- 世界线：亲爱度（花海佑芽）·P卡；制作人在制作的偶像：佑芽（本篇没有提到制作人，从所属判断）

## 发生了什么
星南宣布休息，美鈴称赞佑芽已记住『ENDLESS DANCE』。星南说这次比平时学得快，佑芽说因为星南和美鈴亲自教。佑芽说对两人的喜欢比以前更多，星南说“咲季会嫉妒”，并表示只要佑芽想学，会把经验全部传授。美鈴问星南这样培养佑芽，不怕被抢走『一番星』吗，星南说“求之不得”，叫三人都放马过来。美鈴说佑芽是靠模仿两个人学会的，并说以前也有人这样，被大家害怕。剧情经过参照 hmsz、hume 笔记。

## 行为模式
- 后辈长进 → 先指出具体的快，再顺势承诺把经验全给（0006、0016）
- 被问“怕不怕被超越” → 直接说“求之不得”，邀请挑战（0021、0023、0035）
- 对方提到“害怕”的心情 → 承认也有同感，但态度不变（0034）
- 被喜欢 → 开玩笑地想到另一人（咲季）的反应（0015）
