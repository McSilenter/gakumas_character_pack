# P卡 十王星南【小小的野心】 / 第2话 小小的野心 第2话（adv_cidol-jsna-3-000_02）

- 她的台词：17 行（含用匿名标签说的 0 行）
- 出场的人：星南（17 行）、燕（16）
- 场景：她一个人反复练新曲的地方，地点剧本没写明（0001）
- 世界线：亲爱度（十王星南）·P卡；制作人在制作的偶像：十王星南（剧本里没有直接说法；本篇制作人没有出场）

## 发生了什么
她一遍遍练新曲，嫌不行要再来；燕说看了很久，劝她适可而止（0001～0004）。她说本想保密，新曲还是被发现了，干脆问燕感想；燕说是很棒的歌、完成度很高，所以不懂她为什么还要继续“無駄なレッスン”（0005～0013）。她为让燕担心道歉，说这是对自己特别的曲子，想以更好的形式给大家听；又说这是“トップアイドル”唱的曲，现在还不够，向燕求教（0014～0022）。燕抱怨她和“くだらん男”做无聊的活动，被她打断催着给建议；燕说她最近只看“上”，该看看“下”（0023～0028）。她把这理解成“有观众更接近实战”，当场采纳，叫副会長紧急召集生徒会听她的新曲；燕说自己不是这个意思，骂她不听人说话（0029～0033）。剧情经过参照 atbm 笔记。

## 她的关键台词
- 0001「……ふぅっ。／これではダメね。……もう一度。」——对已完成的曲子仍不满意，反复练
- 0006「ついにバレてしまったわね……／私の新曲。」——被发现后半开玩笑
- 0014「ごめんなさい。／心配させてしまったようね。」——直接把燕的话理解为担心并道歉
- 0017「……私にとって、特別な曲だから。」——说明执着的理由
- 0020「トップアイドルが／歌う曲なんだそうよ。」——转述制作人对新曲的定位
- 0021「なら……これじゃあ、足りないわ。」——以此为标准判断自己还不够
- 0022「ねぇ、燕。この歌をさらに良くする／には、どうしたらいいかしら？」——主动向对手求教
- 0025「はいはい。ほら、そういうのいいから、／助言を頂戴。」——随口打发燕的抱怨
- 0029「――……それ、採用。観客がいた方が、／実戦に近いレッスンができるものね。」——按自己的理解采纳建议
- 0032「副会長、生徒会を緊急招集なさい！／全員に私の新曲を聴かせるわ！」——想到就立刻用会长身份下令

## 行为模式
- 作品已经很完整 → 仍以“顶级偶像的歌”为标准，认为不够而反复练（0001、0020、0021）
- 对方嘴硬地关心她 → 直接点破成“让你担心了”并道歉（0014）
- 想变得更好 → 毫不介意地向对手求教（0022）
- 对方唠叨抱怨 → 用“はいはい”打断，催回正题（0025）
- 听到建议 → 按自己的理解马上拍板执行，不等对方说完（0029、0032）

## 关系
- 燕：叫「燕」（0003、0022），叫「副会長」下令（0032）；燕叫她「貴様」（0012）。她把燕的话当成担心来道歉（0014），向燕求教（0022），随口打断燕的抱怨（0025），误会燕的建议后马上动员生徒会（0029、0032）。
- 生徒会：她要求紧急召集全体听新曲（0032）。

## 档案类事实
- 生徒会的人会听她的召集；燕是副会長（0032）
- 燕说她最近很忙（0012）
