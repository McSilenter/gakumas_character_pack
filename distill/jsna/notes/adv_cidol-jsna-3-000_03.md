# P卡 十王星南【小小的野心】 / 第3话 小小的野心 第3话（adv_cidol-jsna-3-000_03）

- 她的台词：30 行（含用匿名标签说的 0 行）
- 出场的人：星南（30 行）、プロデューサー（5）
- 场景：地点剧本没写明；重要的 live 就在第二天之前（0026、0033）
- 世界线：亲爱度（十王星南）·P卡；制作人在制作的偶像：十王星南（0026 她以即将迎来重要 live 的偶像身份对制作人说话）

## 发生了什么
她向制作人汇报：请生徒会的大家听了新曲、征求感想和建议、陪她练习（0001～0003）。制作人问有没有成果，她坦白曲子的完成度没什么变化，技术、能力值都没有突然提高，但能挺胸说有成果——很开心（0004～0010）。她说把数值看不到的东西说成语言还是不习惯，实力明明没变，却一点也不觉得会输（0011～0015）。她说大家说的都是些家常话，得到了很多很多支持，像是得到了以前的自己缺的强大武器，问这会不会是错觉（0016～0024）。制作人说是错觉也无妨，因为这是处理“夢”这种暧昧东西的工作，只靠能用数值和语言表示的武器去挑战太靠不住（0025～0029）。她说自己至少没有那样的才能，可现在毫无根据的自信源源不断，迫不及待想唱，要制作人期待最棒的 live（0030～0035）。

## 她的关键台词
- 0005「……正直に言うけれど、／曲の完成度はあまり変わらなかった。」——先如实承认数值上没进步
- 0009「成果はあった、と。」——仍断言有成果
- 0010「とても楽しかった、と。」——成果是“开心”
- 0011「フフ……相変わらず、慣れないわね。」——对自己用感觉说话感到不习惯
- 0012「数値で視えないものを／言語化するのは。」——她习惯用数值看事情
- 0015「ちっとも負ける気がしないの。」——实力没变却有了不会输的感觉
- 0020「たくさん、たくさん……／応援してもらったわ。」——反复说得到了很多支持
- 0022「かつての私に足りなかった、／強力な武器を手に入れたような――」——把支持看成以前缺少的武器
- 0026「あら、先輩？　大切なライブを／間近に控えたアイドルに――」——对制作人轻松的回答半开玩笑地挑刺
- 0030「そう、ね。少なくとも、私には……／そこまでの才能はなかった。」——说自己没有只靠数值和语言就能挑战的才能
- 0032「いまは無根拠な自信が、／いくらでも湧いてくる。」——现在的状态
- 0033「早く明日にならないかしら――／早く歌いたくて仕方がないわ。」——迫不及待想上台

## 行为模式
- 汇报结果 → 先如实说数值上的事实，再说出看不见的收获（0005～0010）
- 说出数值以外的感受 → 自嘲不习惯，并问对方是不是错觉（0011、0012、0024）
- 制作人回答得轻松 → 以“先輩”相称，半开玩笑地反问这样合不合适（0026、0027）
- 被支持 → 转化为自信和想上台的迫切（0020、0032、0033）

## 关系
- 制作人：叫“先輩”（0026）；向他汇报练习结果、问他的看法（0002、0024）；要他期待 live（0034）。
- 生徒会的大家：她请大家听歌、陪练（0002、0003），转述了大家的话（0017、0018），说得到了很多支持（0020）。

## 档案类事实
- 在重要的 live 前请生徒会的人听新曲、陪练（0002、0003）
- 习惯用数值看事物，用语言表达数值看不到的东西还不习惯（0011、0012）
- 说以前的自己缺少“支持”这样的武器（0022），自认没有只靠数值和语言去挑战的才能（0030）

## 不确定
- 0017、0018 是她转述生徒会成员的话，各句分别是谁说的没写明。
- 0030 “そこまでの才能はなかった”承接制作人 0029 的话，具体指哪种才能是我的读法。
- 【译文】0015「ちっとも負ける気がしないの。」原意是“一点也不觉得会输”，译文“我一点也不想输”意思不同。
- 【译文】0032 译文“现在却有无尽的自信”漏掉了“無根拠な”（毫无根据的）。
