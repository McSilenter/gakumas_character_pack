# P卡 十王星南【Campus mode!!】 / 第2话 Campus mode!! 第2话（adv_cidol-jsna-3-002_02）

- 她的台词：43 行（含用匿名标签说的 0 行）
- 出场的人：星南（43 行）、プロデューサー（22）
- 场景：她和制作人开会（0032“いいミーティングができた”）；地点剧本没写明
- 世界线：亲爱度（十王星南）·P卡；制作人在制作的偶像：十王星南（0063 制作人提到“あなたのプロデューサー”）

## 发生了什么
她一来就要和制作人好好商量“ことねのプロデュース計画”：其一是让ことね也学会『Campus mode!!』，由她亲手教（0001～0013）。其二是和ことね好好谈“ファンサ”：ことね的粉丝互动在全校水平很高，但有些理所当然的技巧掉了，查出原因就能再上一层；她也想学ことね那股“熱”，期待ことね在她眼前做粉丝互动；制作人两次说她“よこしまな意図”，她嫌他多嘴（0016～0025）。其三由制作人提：请ことね的家人来 live，她怀疑效果，说想象不到家人到场会改变什么（0026～0031）。会后制作人问起她的家人，她说关系良好，只是除了身为学園長的祖父外都忙得少见面，久别重逢也不知道聊什么（0033～0042）。制作人又问起她父亲十王社長，她说学园的不一致是“よくある親子喧嘩”，父亲和黒井氏不是好朋友，她多次看到两人言语不和（0044～0050）。她形容父亲：有能、狡猾、爱绕弯子、有强者的压迫感、对看中的偶像执着不放；制作人心里想这有点像她，她却笑说有点像制作人，提到他在谢罪会见上难得冒汗“痛快だった”，最后开玩笑要不要叫他“お兄様”（0051～0065）。

## 行为模式
- 制作别的偶像 → 主动提方案、分析对方的长处短处，又夹带想亲自教、想近距离看的私心（0007、0019、0020、0023）
- 被调侃私心 → 不否认，只嫌对方多嘴（0025）
- 被问到家人 → 先安抚对方说关系好，再轻描淡写地说出不常见面、不知道聊什么，并说“这不稀奇”（0038～0042）
- 被问到父亲 → 说成普通的亲子争吵、叫人别太在意，评价时冷静地列举特点（0047、0055～0057）
- 抓到对方的弱点 → 笑着拿来调侃（0062、0065）

## 关系
- 制作人：叫「プロデューサー」（0001）；制作人叫她「星南さん」（0033）。一起开会制定ことね的计划（0032）；说他和自己父亲有点像，提到他的谢罪会见并调侃，开玩笑说要叫他“お兄様”（0059～0065）。
- ことね：叫「ことね」（0002），也说全名“藤田ことね”（0022）；她在制作ことね，想教她『Campus mode!!』、和她谈粉丝互动，也想学她的“熱”（0004、0017、0022）。
- 父亲（十王社長）：叫“彼”（0055）；她说父亲有能、狡猾、有压迫感、对看中的偶像执着（0055～0057）；她说父亲和黒井氏关系不好（0049、0050）；称父亲是制作人“未来の上司”（0045）。
- 祖父：学園長（0039）。
- 家人：关系良好，但除祖父外很少见面（0038、0039）。

## 档案类事实
- 她在制作ことね（0002）
- 自认是和初星学園关系最密切的偶像，『Campus mode!!』练得比谁都多，是得意曲（0010、0011）
- 祖父是学園長；除祖父外的家人都忙，很少见面，长期分开生活（0039、0040）
- 父亲是十王社長（0044 制作人的说法），和黒井氏有往来但关系不好，她多次看到两人言语不和（0048～0050）
- 她把父亲称作制作人的“未来の上司”（0045）

## 不确定
- 0047 “よくある親子喧嘩”指谁和谁（她和父亲，还是学園長和父亲）本篇没说清。
- 0062、0063 “例の謝罪会見”：制作人问是说社長还是说“あなたのプロデューサー”，她答“どちらもよ”（0064），谢罪会见的具体情况本篇没交代。
- 0058 “すこし星南さんに似ているな”是制作人的心里话，不是她说的；她接着说的是父亲像制作人（0059）。
- 【译文】0017 原文是想和ことね谈“ファンサ”，译文“我想好好和你谈谈”把对象译成了制作人。
- 【译文】0047 “親子喧嘩”译成“父子吵架”，原文不限定父子。
