# P卡 十王星南【Campus mode!!】 / 第3话 Campus mode!! 第3话（adv_cidol-jsna-3-002_03）

- 她的台词：26 行（含用匿名标签说的 0 行）
- 出场的人：星南（26 行）、プロデューサー（14）
- 场景：live 开场前，看得到客席的地方（0001、0008）
- 世界线：亲爱度（十王星南）·P卡；制作人在制作的偶像：十王星南（0005 她说“私のプロデューサーなのだから”）

## 发生了什么
live 即将开始，她说大家一定等她等得不耐烦了；制作人说这里也有个兴奋的粉丝，她说他作为她的制作人应该紧张才对，制作人说必定成功的舞台不需要紧张（0001～0007）。她质问客席关系者席上的是什么——她的父母和祖父母全到了（0008～0011）。制作人说因为她说过不知道家人的应援有没有用，就试着预约，结果十王家全员到齐（0013～0019）。她问让“あの冷血漢”父亲全身穿戴十王星南周边的也是他吗，制作人说亲手递过去，父亲用像要让他退学的眼神淡淡地要求换成『Campus mode!!』版（0020～0026）。她说今天父亲的形象反复翻转，原来邀请他们就会来；她意外地有了干劲，这是和粉丝、学园学生都不同的感觉：痒痒的、害羞、自豪、安心（0027～0032）。她说这招以后也要用在自己的制作里，又说别得意、搞成惊喜这事她还在生气；在家人齐聚下开 live 真的很久没有了，她说要想起很久以前的初心去唱十王星南的『Campus mode!!』（0033～0040）。

## 行为模式
- 被制作人鼓舞 → 称赞他的手腕并当作学习（0007）
- 被瞒着安排惊喜 → 先质问、表示难以置信，再追问细节（0010、0016、0021）
- 得知家人特意来看 → 说话断断续续，再承认有干劲、列出复杂的感受（0028～0032）
- 有了收获 → 立刻想着用在自己的制作里（0033、0034）
- 被对方说中 → 叫对方别得意，嘴上说生气“多管闲事”（0036、0037）

## 关系
- 制作人：她说“私のプロデューサー”（0005）；制作人叫她「星南さん」（0019）。被他瞒着请来家人，嘴上生气，实则受到鼓舞（0030、0037）。
- 父亲：叫“お父様”（0020），又说“あの冷血漢”（0020）、“彼”（0027）；父亲穿戴她的周边，还要求换成『Campus mode!!』版（0021、0025 制作人的说法），她对他的印象反复翻转（0027）。
- 家人（父母、祖父母）：一起来看 live（0011），她说家人齐聚下开 live 真的很久没有了（0038）。

## 档案类事实

## 不确定
- 0016 原文用了三个问号“？？？”，是语气夸张的写法。
- 【译文】0032「くすぐったくて」译成“既害羞”，原意是痒痒的、难为情的感觉，与后面的“恥ずかしくて”重了。
- 前一话 adv_cidol-jsna-3-002_02 的 0038 她说和家人关系良好、只是很少见面；本篇 0020 称父亲“冷血漢”，两种说法语气不同，但不算矛盾，记一笔。
