# P卡 十王星南【Star-mine】 / 第2话 Star-mine 第2话（adv_cidol-jsna-3-011_02）

- 她的台词：32 行（含用匿名标签说的 0 行）
- 出场的人：星南（32 行）、プロデューサー（16）
- 场景：前一话讨论的第二天（0002“昨日の続き”）；地点剧本没写明
- 世界线：亲爱度（十王星南）·P卡；制作人在制作的偶像：十王星南（0044 制作人说“十王星南をスカウトした”）

## 发生了什么
她说等不及就来了，要继续昨天的讨论；制作人看出她睡眠不足，她承认因为太投入选成员而熬夜（0001～0009）。制作人在禁选十王星南的前提下选了花海咲季、月村手毬、藤田ことね，她抗议“ことね都在里面太狡猾”，又问为什么咲季又入选（0010～0015）。制作人说咲季是任何组合都想确定放进去的偶像，她带着醋意说他很中意咲季，指出咲季会要求伙伴同样拼命，未必合得来；制作人说初星学園没有偶像碰上咲季不会燃起来，她承认，因为大家都是下定决心才进学园的（0016～0023）。制作人说现在的她应该懂咲季的强，她说咲季是镜中的另一个自己、过去莽撞而青涩炽热的自己，曾经同族嫌恶，一转眼成了强敌（0024～0028）。她问问题多的月村手毬，制作人说越查越有魅力、和成员相性好，她说这是敌是友都棘手的组合；制作人说这样才好，她说今天的讨论很无聊，否认闹别扭，又问敏腕制作人此时会怎么做（0029～0041）。制作人说这个组合方案是她们入学前就考虑过的，但他没有选她们，而是“十王星南をスカウトした”；她短短应了一声，道谢说学到了，忍不住笑出来，愉快地说继续讨论（0042～0048）。

## 行为模式
- 有兴趣的事 → 熬夜投入，第二天迫不及待地来（0001、0007）
- 制作人称赞别的偶像 → 拖长语调表示不满，再挑对方的毛病；被说服后也坦然承认（0018～0023）
- 闹别扭 → 说讨论无聊，否认闹别扭，再拐弯问“敏腕制作人会怎么做”让对方哄（0037～0041）
- 被哄 → 先短短一声“そう”，再故作冷静地说学到了，最后忍不住笑出来、语气变得轻快（0045～0048）

## 关系
- 制作人：叫“先輩”（0001、0040）；制作人叫她「星南さん」（0005）。她因他偏爱咲季而闹别扭（0018、0037），被他一句“十王星南をスカウトした”哄好（0044～0048）。
- 花海咲季：称“花海咲季さん”（0015）、“あの子”（0019）；说咲季是镜中的另一个自己，曾对她同族嫌恶，如今是强敌（0026～0028）。
- 月村手毬：称“月村手毬さん”，说是问题多的偶像（0029）。
- ことね：叫「ことね」（0013）；ことね被制作人选进组合时抗议（0013）。

## 档案类事实
- 为讨论组合成员熬夜（0007）
- 对花海咲季：看作“向こう見ずだった頃の、青く熱い私”，曾同族嫌恶，现在视为强敌（0026～0028）
- 制作人说这个组合方案是入学前考虑的，但他选择了招募十王星南（0042、0044）

## 不确定
- 0042“入学前に検討していた”是谁入学前（咲季等人，还是制作人自己），原文没写主语；译文作“她们入学前”。
- 【译文】0045「…………そう。」后 0047 的笑声，译文写作“噗……呵呵”，只是语气差异，不影响理解。
