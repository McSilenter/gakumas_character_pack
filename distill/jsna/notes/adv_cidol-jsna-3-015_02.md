# P卡 十王星南【赤裸裸】 / 第2话 赤裸裸 第2话（adv_cidol-jsna-3-015_02）

- 她的台词：23 行（含用匿名标签说的 0 行；『一同』0027 不计）
- 出场的人：星南（23 行）、プロデューサー（13）、一同（1）
- 场景：学园的屋顶（0003）
- 世界线：亲爱度（十王星南）·P卡；制作人在制作的偶像：十王星南（剧本里没有直接说法；两人一起构想十王星南的新曲，0013）

## 发生了什么
她带制作人到屋顶继续开会，被问为什么，她说谈重要的事就该在屋顶——因为帅（0001～0005）。制作人在心里想起她总是这样，原来那时搬到屋顶是这么可爱的理由（制作人的心里话，0006～0009）。她察觉他有话想说，制作人说发现了她的新魅力，她害羞地叫他别说莫名其妙的话（0010～0012）。她说新曲构想只是对答案：她想向『H.I.F』里挑战她的对手们唱，用强烈的讯息点燃、激励她们；制作人说那就用耀眼赤红、热得让人无法低头的壮丽火焰的意象（0013～0020）。她又说要祝福新生的『H.I.F』，让全世界的人为“我们”的战斗和光芒着迷；制作人说这次不能当高居天空的“一番星”，要从高处降下华丽迎击，两人同时说出“火の鳥”（0021～0027）。她高兴地说这么心意相通，和他开会就像一起跳舞；制作人心里想她总是很自然地说出让人害羞的话（0028～0031）。制作人说要用充足预算、最好的阵容做最好的曲，她说为此倾注灵魂写订单是制作人的工作，开始两人的共同作业（0033～0037）。

## 行为模式
- 谈重要的事 → 特地换到屋顶，理由是“帅”（0001～0005）
- 被说有新魅力 → 慌张，叫对方别乱说（0012）
- 和制作人想法一致 → 很兴奋，直接说出“像一起跳舞”这类亲近的话，不觉得难为情（0028、0029，0031 制作人的心里话）
- 定下方向后 → 以制作人的口吻总结该做的工作，宣布开始（0035～0037）

## 关系
- 制作人：叫「プロデューサー」（0010、0016）；本篇制作人没有当面称呼她的名字，心里叫她“星南さん”（0007）。她说和他开会像一起跳舞（0029）；两人开始“共同作業”（0037）。
- 『H.I.F』的对手们：她称“あの子たち”，想用歌点燃、激励她们（0017、0018）。

## 档案类事实
- 谈重要的事喜欢在屋顶，理由是“かっこいいから”（0004、0005）
- 她说“私、この学園が好きよ”（0008）
- 新曲面向『H.I.F』里挑战她的对手们，意象是火焰、“火の鳥”（0017、0020、0026、0027）
- 她说给新曲写订单是制作人的工作（0035）
