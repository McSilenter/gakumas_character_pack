# P卡 十王星南【荆棘之路】 / 第2话 荆棘之路 第2话（adv_cidol-jsna-3-017_02）

- 她的台词：40 行（含用匿名标签说的 0 行；0023～0029 是她复述“彼女”在引退 live 上的 MC，0043～0045 是她模拟自己将来引退 live 的“排练”）
- 出场的人：星南（40 行）、プロデューサー（5）
- 场景：她喜欢的、风景很好的地方（0001、0003，0007 制作人说“お気に入りの場所”）；具体地点剧本没写明
- 世界线：亲爱度（十王星南）·P卡；制作人在制作的偶像：十王星南（剧本里没有直接说法）

## 发生了什么
她说风很舒服，毕业后就不能随意看这片景色，要趁现在好好欣赏；制作人说她明年以后大概也会随意来看，她说那就试试看（0001～0006）。她说想告诉制作人对她影响很大的“彼女”的话（0007～0012）。那天开引退 live 的“彼女”是 100プロ的顶级偶像，大家都惋惜落泪；她本来不是粉丝、也没直接说过话，只是为了学习去看，结果开场第一曲『ガラクタロード』吹散了所有人的眼泪，连想认真学习的她也笑了、看得出神（0013～0020）。她复述“彼女”的 MC：因为憧憬“那个人”而当偶像、拼命追着那个人走到这里，现在轮到自己对追随者说“往前走吧，接下来是你们的时代”（0021～0029）。她说感觉和“彼女”对上了眼，胸口发热，收到了浓密的讯息：顶级偶像在最后把梦想和憧憬撒向全世界后离去，将来她也一定会这样；追着顶级偶像背影的人又成为新的路标，她的终点一定会成为某人的开端（0030～0039）。制作人说现在就构想引退 live 太早了，没别人听，不如排练一下；她便说“致遥远未来的偶像们，以十王星南为路标走来的你——向着我的前方前进吧！！”（0040～0045）。

## 行为模式
- 珍视的地方 → 想到毕业，要趁现在好好看（0002～0004）
- 说重要的回忆 → 先坦白当初的真实动机（只是为了学习），再说出被打动的经过（0015～0020）
- 复述别人的话 → 一字一句地记得，像昨天的事（0022～0029）
- 从别人的故事得到启发 → 立刻转成自己的志向和偶像观（0033～0039）
- 被提议“排练” → 爽快答应，当场高声演出（0042～0045）

## 关系
- 制作人：她说有话想对他说（0010）；他说她明年以后也会来看景色、提议排练引退 live（0005、0041），她都爽快接下（0006、0042）。
- “彼女”（100プロ的顶级偶像）：她当初不是粉丝、没说过话，为学习去看引退 live，被打动，说“彼女”是引导十王星南的路标（0012～0016）。

## 档案类事实
- 今年毕业（0002 毕业后就不能随意看这景色；0005 制作人说“来年以降”）
- 那位 100プロ顶级偶像的引退 live：她为了学习去看，开场曲『ガラクタロード』，对她影响很大（0013～0018）
- 她想将来也像那位偶像一样，在最后把梦想和憧憬撒向世界，让自己的终点成为某人的开端（0034～0038）

## 不确定
- 0023～0029 是她复述“彼女”的 MC，不是她本人的话；0043～0045 是应制作人的提议做的“排练”，是她设想的将来引退 live 的台词。
- 0025“あのひと”是谁，本篇没说；下一话 adv_cidol-jsna-3-017_03 的 0020 她说是她的母亲。
- 【译文】0020「呆然と、陶然と」译成“茫然出神、陶然其中”，意思大致对；不影响理解，不另记。
