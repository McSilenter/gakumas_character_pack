# P卡 十王星南【Roar】 / 第3话 Roar 第3话（adv_cidol-jsna-3-021_03）

- 她的台词：24 行（含用匿名标签说的 0 行）
- 出场的人：星南（24 行）、プロデューサー（13）
- 场景：她在没约开会的日子来找制作人（0002）；地点剧本没写明
- 世界线：亲爱度（十王星南）·P卡；制作人在制作的偶像：十王星南（0029 制作人说希望飞向世界的她成为这样）

## 发生了什么
没有约会议，她却来了，说在意新曲后来怎样；制作人说她不是说相信制作人吗，她说之后一直没消息，连做事快的他都这样，难免担心（0001～0007）。制作人说刚收到 demo，她听后说是很能跳的曲子，配上歌词一下子变得有攻击性，与其说是狮子不如说是“狩りへと臨む獣の歌”，问他是怎么重新振作的（0008～0015）。制作人说找作曲家和 MV 工作人员商量，在现场放了她的“がおがお動画”，全员被“がおがお”诅咒，再也不是“王たる獅子のレガリア”的气氛；她惊讶自己的动物姿势有这么大的影响力（0016～0023）。专业创作者们苦思重新解释十王星南，最后成了这首；她问曲名，是『Roar』，说妖艳、可爱、柔韧地低吼、像跳舞一样狩猎，这就是他心中十王星南的レガリア（0024～0028）。制作人说希望从沉重王座解放、飞向世界的她是这样，她说得到了一把强力的“剣”，MV 也是另一件レガリア，问要付什么代价；制作人说在舞台上展现兽之王者的样子，她说交给她，她的猎物是包括他在内的所有粉丝，以及世界的顶级偶像们（0029～0037）。

- 0009「ぜひ！」——迫不及待
- 0011「いいじゃない～♪　／とってもダンサブルな曲ね――」——直率的喜欢
- 0014「狩りへと臨む獣の歌、かしら。」——对曲子的解读
- 0020「そういえば撮影していたわねあなた……／皆さんにあれを見せたの？」——得知视频被播放
- 0023「なんてこと……私のアニマルポーズに、／そこまでの影響力があるなんて……」——惊讶又带点得意
- 0027「妖艶に、愛らしく、／しなやかに、うなりをあげて、／踊るように獲物を狩る。」——理解新曲的形象
- 0028「これがあなたが想う、／十王星南のレガリア……」——接受制作人对她的评价
- 0030「これは……強力な『剣』を／創ってもらってしまったわね。」——高度评价
- 0033「対価はなにを支払えばいいかしら？」——用王的比喻回应
- 0036「私の獲物は、／あなたを含むすべてのファン。／そして――」——宣言
- 0037「世界のトップアイドルたちよ！」——目标是世界

## 行为模式
- 交给别人的事迟迟没消息 → 嘴上说相信，还是忍不住亲自来看（0003～0007）
- 听到新作品 → 先直率表示喜欢，再分析印象，然后问怎么做出来的（0011～0015）
- 自己的黑历史被拿去用 → 惊讶，转而当作自己的影响力（0020、0023）
- 收到制作人的心意 → 用王者的比喻回应，并以宣战的方式接下（0030、0033～0037）

## 关系
- 制作人：叫「プロデューサー」（0001）；制作人叫她「星南さん」（0002）。她说相信他但没消息会担心（0006、0007）；他为她做的曲是他心中的十王星南（0028、0029）；她说猎物包括他在内的所有粉丝（0036）。

## 档案类事实
- 新曲名『Roar』，很能跳、有攻击性，形象是“狩りへと臨む獣”（0011～0014、0026）
- 制作人在现场播放了她的“がおがお動画”（0019）
- 目标：包括制作人在内的所有粉丝，以及世界的顶级偶像们（0036、0037）

## 不确定
- 0026「曲名を教えて頂戴。／……そう、『Roar』というのね。」中间省略了制作人的回答，是她自己读到曲名还是制作人告诉她，剧本没写。
