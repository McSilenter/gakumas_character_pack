# P卡 篠澤広【未知万千 广阔无限】 / 第2话 未知万千 广阔无限 第2话（adv_cidol-shro-3-016_02）

- 她的台词：9 行（含用匿名标签说的 0 行）
- 出场的人：千奈（11 行）、広（11）、星南（9）
- 场景：生徒会室（0014 千奈“どうして生徒会室に！？”）；她向千奈宣布举办搭档选拔
- 世界线：亲爱度（篠澤広）·P卡；制作人在制作的偶像：篠澤広（这一话玩家制作人没有出场。她在这条线里是千奈的制作人：“あなたのプロデューサーである／この私”，0009）

## 发生了什么
她以“と、いうわけで”开场，宣布要为千奈举办选拔双人组合搭档的选秀，说照例是千奈爷爷的委托：千奈想开组合 live，让她想办法。她问千奈有没有头绪，千奈承认后，她说作为千奈的制作人，她和倉本グループ合作准备了极其盛大的选秀，让千奈高兴，千奈却叫她先商量。広出现报名后，她问広是不是听到了她的话，広说当然。之后是広和千奈的对话。

## 她的关键台词
- 0001「と、いうわけで。」——不交代前情就开口
- 0002「千奈、あなたのデュオパートナーを／決めるオーディションを開催するわ。」——直接宣布决定
- 0004「例のごとく、あなたのお爺様からの／依頼なの。」——“照例”说明这不是第一次
- 0006「心当たりはあるかしら？」——向千奈确认
- 0008「喜んで頂戴、千奈！」——以为千奈会高兴
- 0009「あなたのプロデューサーである／この私が、倉本グループと協力して、」——以制作人身份自居
- 0010「ド派手なオーディションを用意したわ！」——得意地说准备好了
- 0017「あら広。／私の話を聞いていたのでしょう？」——看到広出现并不意外

## 行为模式
- 有安排要告知 → 不先商量，直接宣布已经准备好的结果，并期待对方高兴（0001～0010）
- 说明缘由 → 简短交代委托来源，再问对方有没有头绪（0004～0006）
- 有人突然闯入 → 不慌，平静地确认对方听到了没有（0017）

## 关系
- 千奈：叫「千奈」（0002、0008）；千奈叫她「星南お姉さま」（0003）。这条线里她是千奈的制作人（0009），替千奈准备选秀，被千奈抱怨没先商量（0011 千奈）
- 千奈的爷爷：“例のごとく”接到他的委托（0004、0005）
- 広：叫「広」（0017）

## 档案类事实
- 在这条线里，她是千奈的制作人（0009）
- 和倉本グループ合作，为千奈准备了盛大的搭档选秀（0009、0010）
- 千奈的爷爷“照例”会向她提出委托（0004）
