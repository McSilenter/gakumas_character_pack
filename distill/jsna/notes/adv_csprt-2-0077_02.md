# S卡 2-0077【ずっしりスイカでりしゃす】 / 第2话 西瓜，与回忆（adv_csprt-2-0077_02）

- 她的台词：9 行（无匿名行）
- 出场的人：佑芽(11)、星南(9)
- 场景：西瓜劈之后，收拾场地并吃西瓜
- 世界线：S卡【ずっしりスイカでりしゃす】；制作人在制作的偶像：看不出
- 剧情经过参照 hume 笔记

## 发生了什么
两人收拾西瓜劈后的场地。星南感谢佑芽的邀请，说很开心。佑芽讲起小时候和姐姐比赛吐西瓜子的回忆。星南说自己曾把西瓜子种在燕家的院子里，只发了芽就枯了。佑芽提议在生徒会种点什么，请広指导，星南觉得生徒会菜园可能有趣。

## 她的关键台词
- 0001「スイカ割りって、片付けが大変なのね。」——对收拾场地的感想
- 0003「思いっきり力を入れないと／なかなか割れなかったものね。」——回顾劈西瓜时的用力
- 0005「誘ってくれて、ありがとう。」——向佑芽道谢
- 0008「私もよ。楽しかったわ。」——对"没想到会一起"同感
- 0012「可愛らしい思い出ね。」——听佑芽说和姐姐的回忆后的评价
- 0013「私はスイカの種を／燕の家の庭に植えたことがあったわ。」——自己的回忆
- 0015「いいえ、芽が出ただけで／成長せず枯れてしまったの。」——结果是只发芽就枯了
- 0016「でも、ワクワクして楽しかったわ。」——即使失败仍觉得有趣
- 0019「なるほど。生徒会で野菜菜園……／面白いかもしれないわね。」——对佑芽的提议表示认同

## 行为模式
- 玩完之后 → 先道谢并说"楽しかった"（0005、0008）
- 听到别人的回忆 → 用一句评价，再讲自己的类似回忆（0012、0013）
- 谈到失败的回忆 → 不惋惜，重点放在期待感（0016）
