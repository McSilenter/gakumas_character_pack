# S卡 3-0014【まじか。】 / 第2话 压力十足的劝说（adv_csprt-3-0014_02）

- 她的台词：13 行（标签「星南」，无匿名行）
- 出场的人：星南（13）、ことね（7）
- 场景：早上，星南把ことね逼到墙边（ことね 0004）；具体地点没写明。
- 世界线：S卡【まじか。】；制作人在制作的偶像：看不出

## 发生了什么
星南一早向ことね打招呼，ことね问为什么每次都被逼到墙边，星南说是自然引导对方行动的技巧，劝她也学学。她进入正题，要ことね和她组成组合，并说如果想以最短路程成为顶级偶像，就应当从一年级起体验大舞台，她自己在身边支持最好；说到一半发现自己兴奋过头，向ことね道歉并问是否跟上。听到“完全没有”后，她说自己太着急了，今天早上先到这里，总有一天会让ことね成为自己的人。

## 她的关键台词
- 0001「おはよう、ことね。いい朝ね。」——一早自然地打招呼，口吻轻松。
- 0005「相手の動きを自然に／誘導するテクニックよ。」——把逼人到墙边说成一种技巧，毫无愧疚。
- 0006「なかなか有用だから、あなたも／覚えておいて損はないわ。」——推荐对方也学这种技巧，没有察觉对方在抱怨。
- 0008「さて、本題だけれど――――」——转入正题，不顾ことね的话。
- 0010「あなた、私とユニットを組みなさい。」——命令式地要求组成组合。
- 0012「もちろん、私たちの／輝かしい未来の話よ。」——对“你在说什么”的回答：理所当然地说是两人光辉的未来。
- 0013「あなたが最短距離で／トップアイドルを目指すなら、」——以ことね的目标（成为顶级偶像）为前提来劝说。
- 0014「ぜひとも今年……1年生のうちから／大舞台を経験すべきよ。」——主张要在一年级就体验大舞台。
- 0015「そのためには、私がすぐそばで／サポートするのが一番――」——劝说的结论：由自己在身边支持最好。
- 0016「――と、ごめんなさい。つい、ひとりで／盛り上がってしまったわ。」——发现自己说过头后道歉。
- 0017「ひとまず……ここまでの話には、／付いてきているかしら？」——确认对方是否跟上。
- 0019「……どうやら、急ぎすぎたようね。／今朝は、ここまでにしておきましょう。」——得知对方完全没跟上后，承认自己太急，当天收手。
- 0020「……いずれ必ず、／私のモノにしてみせるわ。」——收手时宣告总有一天要得到对方，说得很干脆。

## 行为模式
- 想让对方入伙 → 先用“技巧”“理所当然”的口吻推进，再讲目标与理由（0005、0010、0012～0015）。
- 说到一半发觉自己兴奋过度 → 道歉并确认对方是否跟上（0016、0017）。
- 对方说完全没跟上 → 不责怪，承认自己太急，当天撤退，并宣告将来一定得手（0019、0020）。

## 关系
- ことね：称「ことね」「あなた」；ことね称她“会长”（本篇只用敬语，没有直接称呼）。星南想让ことね和自己组成组合，从她的发言看是单方面推进，ことね则不接受。
