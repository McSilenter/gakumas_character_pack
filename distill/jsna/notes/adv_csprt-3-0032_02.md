# S卡 3-0032【プロデュースって大変ね】 / 第2话 可靠前辈的烦恼（adv_csprt-3-0032_02）

- 她的台词：12 行（含用匿名标签说的 0 行）；0009、0010、0013 是括号内的内心独白
- 出场的人：星南（12）、佑芽（7）、咲季（1，0018）
- 场景：早上，佑芽的自主晨跑（0001、0011）；之后转到要示范舞蹈的场合（0014～0017）；具体地点剧本没写
- 世界线：S卡【プロデュースって大変ね】；制作人在制作的偶像：佑芽（制作人是星南本人，见第1话 0009、0013；本话她对佑芽以前辈身份相处）

## 发生了什么
星南说今早要看佑芽的自主训练，结果佑芽出发后星南也跟着跑，佑芽用平常的速度全力奔跑，星南吃惊，却强装从容。晨跑结束后佑芽请星南示范舞蹈，星南答应；咲季出现，星南与她对了一句「ね？」「ええ」，最后感叹要一直做佑芽的「頼れる先輩」很费力。
剧情经过参照 hski、hume 笔记。

## 她的关键台词
- 0001「佑芽！　今朝はあなたの／自主トレーニングを見せてもらうわ！」——宣布要看佑芽的自主训练，以前辈身份发号施令
- 0004「フッ、見せてもらうと言ったでしょう？／遠慮せず普段のペースで走りなさい。」——叫佑芽别客气，用平常步速跑
- 0006「えっ速……」——听到佑芽跑得很快时脱口而出的真话
- 0008「ふふっ……もちろんよ。／遠慮はいらないと言ったでしょう？」——嘴上从容，维持前辈的姿态
- 0010「（後輩の前で……無様な姿を／さらすわけにはいかないわ……！）」——内心独白：不能在后辈面前出丑
- 0012「さすが元アスリートね。あなたのこと、／すこし理解できた気がする。」——称赞佑芽是元运动员，说有一点理解了她
- 0013「（も、もう体力の限界よ。なんとか……／先輩としての面目を保てたかしら）」——内心独白：体力已到极限，在意是否保住了前辈的面子
- 0017「フフフ！　任せて頂戴！　さあ、／どんなダンスを見せて欲しいの？？？」——被请求示范舞蹈，仍然豪爽答应，句尾的「？？？」在原文里
- 0020「佑芽の『頼れる先輩』でいるのは……／なかなか……骨が折れそうね。」——最后向自己承认做「頼れる先輩」很辛苦

## 行为模式
- 被后辈的速度压过 → 嘴上说「もちろんよ」维持从容，内心喘着气撑着（0008、0009、0010）
- 体力已到极限时又被要求示范舞蹈 → 先愣一下（0015），再爽快答应（0017）
- 事后对自己坦白辛苦（0020）

## 关系
- 佑芽：她称「佑芽」，佑芽称她「星南先輩」；星南对佑芽的称赞是「元アスリート」（0001、0012）
- 咲季：0019 回应咲季那句「ね？」，没有称呼

## 档案类事实
- 佑芽是元运动员（0012，星南的说法）
- 佑芽称星南为「学園一のアイドル」（0005），星南自己没有说这个词
