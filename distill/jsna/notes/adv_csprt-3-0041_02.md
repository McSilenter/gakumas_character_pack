# S卡 3-0041【キラキラして綺麗～っ！】 / 第2话 给会长的礼物（adv_csprt-3-0041_02）

- 她的台词：7 行（含用匿名标签说的 0 行）
- 出场的人：美鈴（8）、星南（7）、佑芽（5）
- 场景：彩灯展示的会场，有小摊
- 世界线：S卡【キラキラして綺麗～っ！】；制作人在制作的偶像：看不出

## 发生了什么
三人在会场逛，看到有小摊。星南说去看看，并提出给两人买热红茶；美鈴想一起去，星南让她和佑芽等着。美鈴说想要绿茶，星南答应。佑芽和美鈴商量回礼，决定在和果子店给星南买馒头。星南回来后收到馒头，说自己平时不太吃零食，但还是收下。

## 她的关键台词
- 0003「ちょっとした屋台も出ているようね。／少し覗いていこうかしら。」——主动提出去看小摊
- 0005「ふたりの分も、温かい紅茶を買って／くるわ。」——主动请客
- 0008「大丈夫よ。／佑芽と一緒に待っていて。」——不让美鈴同去，自己去买
- 0010「ふふ、分かったわ。／少しその場で待っていなさい。」——接受美鈴改要绿茶的要求，对她们说话是带指示的口气
- 0019「あまり間食は取らないようにしている／のだけど……そういうことなら、」——说明自己平时不吃零食，但看重对方的心意
- 0020「ありがたく、いただくとするわ。」——收下回礼

## 行为模式
- 想请后辈 → 自己去买，不让她们一起去（0005、0008）
- 收到与自己习惯不合的东西（零食）→ 先说明习惯，再以“既然是心意”收下（0019、0020）
