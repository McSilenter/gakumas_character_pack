# S卡 3-0041【キラキラして綺麗～っ！】 / 第3话 想分享的风景（adv_csprt-3-0041_03）

- 她的台词：8 行（含用匿名标签说的 0 行）
- 出场的人：佑芽（7）、星南（8）、美鈴（5）
- 场景：彩灯展示的会场，三人在吃馒头
- 世界线：S卡【キラキラして綺麗～っ！】；制作人在制作的偶像：看不出

## 发生了什么
三人吃馒头，佑芽说平时不怎么吃但很好吃，星南说自己也一样，偶尔吃和果子也不错。佑芽拿姐姐的料理比喻，星南问是不是佑芽平时吃的运动员餐，是否好吃；佑芽邀她下次尝，她婉拒。准备回去时佑芽说想让姐姐也看到这景色，星南提议拍照分享；佑芽和美鈴去拍照，星南说看来一时回不去了，自己也想拍一张发给ことね。

## 她的关键台词
- 0002「私も同じよ。／でも、たまには和菓子も良いわね。」——与佑芽一样不常吃，但肯定偶尔吃的好处
- 0004「確かに、なんだか落ち着く味だわ。」——对馒头的感想
- 0006「……それってまさか、佑芽が普段から／食べているアスリート食のこと？」——对佑芽的“姐姐的料理”有疑问
- 0010「え、遠慮しておくわね……」——婉拒佑芽邀她吃运动员餐
- 0017「今からでも写真を撮って、／共有してあげたらどうかしら？」——为佑芽想让姐姐看风景的心情出主意
- 0020「……もうしばらくは帰れないみたいね。／私も、ことねに送ろうかしら……」——苦笑着看佑芽和美鈴去拍照，自己也想发给ことね

## 行为模式
- 被邀请尝试不太想吃的东西 → 婉拒，语气委婉（0008、0010）
- 后辈说想与家人分享美景 → 马上提出可行办法（0017）
- 大家都忙着拍照 → 带着无奈接受，并顺势想起要给ことね发（0020）
