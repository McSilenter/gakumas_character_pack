# S卡 3-0048【絶対にお渡ししますわっ！】 / 第3话 传家宝巧克力（adv_csprt-3-0048_03）

- 她的台词：11 行（含用匿名标签说的 0 行）
- 出场的人：星南（11）、千奈（9）
- 场景：星南和千奈在谈话，地点和时间剧本没写
- 世界线：S卡【絶対にお渡ししますわっ！】；制作人在制作的偶像：看不出

## 发生了什么
星南问千奈最近练习怎么样，千奈说有不足但和朋友一起开心，星南说那很好。星南问能否现在吃千奈给的巧克力，千奈说有点不好看，星南尝后说很好吃，感受到千奈的努力。随后星南说自己也做了要分给学生会成员的巧克力，递给千奈，千奈说要当传家宝，星南说其实希望她吃掉。

## 她的关键台词
- 0001「千奈。最近、レッスンはどう？」——主动关心千奈的练习
- 0004「そう。それはとても、素敵なことね。」——听到千奈和朋友一起开心后的肯定
- 0005「あなたにもらったチョコ、／いま食べてもいいかしら？」——想马上吃千奈给的巧克力
- 0009「……うん、とっても美味しいわ。」——尝后的感想
- 0011「そうね。千奈の努力を感じるわ。／ありがとう。」——不只评价味道，还点出对方的努力
- 0013「そんな千奈に、私からもプレゼントよ。」——回礼
- 0015「生徒会のメンバーに配ろうと思って、／私も作ってきたのよ。」——自己也做了要分给学生会成员的巧克力
- 0016「よかったら、もらってくれるかしら？」——用请求的语气递出
- 0018「そ、そんなに嬉しいものかしら？」——对千奈过度的高兴有些窘
- 0020「いえ、その、／食べてもらいたいのだけれど……」——希望对方把巧克力吃掉

## 行为模式
- 想了解后辈 → 从练习近况问起（0001）
- 收到礼物 → 马上提出要吃，吃后具体指出对方的努力（0005、0009、0011）
- 对方反应夸张 → 窘迫地回应，并说出自己真正的希望（0018、0020）

## 关系
- 千奈：称“千奈”；千奈称“星南お姉さま”（同卡第1话 0002、第2话 0005）。

## 档案类事实
- 自己做了巧克力，打算分给学生会成员（0015）。

## 不确定
- 0013「そんな千奈に」的礼物，0015 说是分给学生会成员而做的，是否对千奈另有特别含义，剧本没有写；第2话她说千奈“特别”（本卡第2话 0018）。
