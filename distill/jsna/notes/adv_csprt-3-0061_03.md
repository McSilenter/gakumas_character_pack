# S卡 3-0061【みんなの意見を聞かせて♪】 / 第3话 面食王子（adv_csprt-3-0061_03）

- 她的台词：9 行（含用匿名标签说的 0 行）；0015 是括号内的心里话
- 出场的人：麻央（11）、星南（9）
- 场景：麻央买完备品后，星南跟着他走在路上；附近新开了一家章鱼烧店（0001、0003、0008）
- 世界线：S卡【みんなの意見を聞かせて♪】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
星南陪麻央买备品，说是自己想确认宿舍的状况才跟来的。麻央叮嘱不要问ことね的私生活，星南说不会公私混同。麻央闻到章鱼烧的香味，称是“有实力的店”，星南对他这么喜欢章鱼烧感到意外。星南也产生兴趣，说既然来了就吃了再走，还说能让一向冷静的他说这么多，章鱼烧值得吃。

## 她的关键台词
- 0002「気にしないで頂戴。」——被道谢后轻轻带过
- 0003「寮の状況を確認したいと言って、／私が勝手に付いてきたのだから。」——明说是自己主动跟来的
- 0006「そ、そんなに釘を刺さなくても、／公私混同はしないわ。」——被叮嘱后有点慌，但明确表示不会公私混同
- 0013「あ、あなた、そんなに／たこ焼きが好きだったの？」——对麻央的热情感到意外
- 0015「（そんな、一部の生徒が卒倒しそうな／スマイルをするほど……？）」——心里话，对麻央的笑容感到惊讶
- 0016「私も興味が出てきたわ。／せっかくだし、食べていきましょうか。」——自己改变行程，提议一起吃
- 0018「いつもクールなあなたに、／そこまで言わせるたこ焼きには、／その価値があるわ。」——以“平时冷静的他说到这个程度”为依据，认定值得

## 行为模式
- 被提醒不要越界 → 立刻保证不会公私混同（0006）
- 看到对方出乎意料的一面 → 先惊讶，再产生兴趣，直接决定行动（0013、0015、0016）
- 评价一样东西 → 以自己对人的了解为依据（“いつもクールなあなた”）（0018）

## 关系
- 麻央：称「あなた」（0013、0018）；麻央称她「会長」「キミ」。她说想确认宿舍的状况，被麻央叮嘱不要问ことね的私生活（0003～0006）

## 档案类事实
- 星南为确认宿舍状况跟着麻央出来（0003）
- 星南说自己是“勝手に付いてきた”（0003）
