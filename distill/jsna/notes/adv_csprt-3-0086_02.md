# S卡 3-0086【貸せ、手本を見せてやる！】 / 第2话 超大圣代挑战！（adv_csprt-3-0086_02）

- 她的台词：10 行（含用匿名标签说的 0 行）
- 出场的人：星南、燕、カフェの店員
- 场景：咖啡店（出场有カフェの店員，端上巨大的パフェ）；时间看不出
- 世界线：S卡【貸せ、手本を見せてやる！】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
店员端来『ビッグウルトラギガスーパージャンボパフェ』。星南说这是“高中生期间想做的事”的第二件，调查热量的心情都没有，但自己一直憧憬和别人分着吃这种东西。燕让她感谢自己，她道谢，随后要先拍照，说最新的潮流好像是用某个应用，被燕问为什么用传闻口气，她说工作一忙就没机会拍私人的照片。她吃得很香，燕很快撑不住，她把剩下的接过去，说好像要迷上圣代了。

## 她的关键台词
- 0003「高校生のうちにやっておきたいこと、／ふたつめ――ドデカパフェよ。」——把圣代算作“高中生期间想做的事”的第二件
- 0005「調べる気も起きないわね……」——对热量不想深究
- 0006「でも、こういうものを分け合って食べる／ことに、憧れていたのよ。」——说明憧憬：和别人分着吃
- 0008「もちろんよ。ありがとう、燕。」——被要求感谢时痛快地道谢
- 0010「待って、まず写真を撮るわよ！」——先拍照再吃
- 0012「ええ！　最新のトレンドはこのアプリを／使うらしいわよ。」——拍照用的应用是听来的潮流
- 0014「仕事で忙しいと、プライベートの写真を／撮る機会がないのよね……」——说明为什么用传闻口气：工作忙，缺少拍私人照片的机会
- 0015「ん～、とっても美味しいわね、燕！」——直率地说好吃
- 0017「あら、早いわね。」——燕说撑不住时的反应
- 0019「じゃあ、残りは私がいただくわね！／ふふっ、パフェにハマりそう……♪」——接过剩下的，说好像会迷上圣代

## 行为模式
- 憧憬的体验 → 明确说出“一直憧憬”，并要求同伴一起（0003、0006）
- 被要求感谢 → 直接道谢（0007、0008）
- 被问到为什么用传闻口气 → 老实说是因为工作忙缺少机会（0013、0014）
- 同伴吃不下 → 平静地说“真快”，并把剩下的吃掉（0017、0019）

## 关系
- 燕：称「燕」（0008、0015）；燕在这一篇里让她感谢自己（0007），并在心里想要监视她的饮食（0020，燕的内心话）。

## 档案类事实
- 憧憬和别人分着吃大分量的东西（0006）。
- 工作忙，很少有拍私人照片的机会（0014）。
- 对潮流应用的了解来自传闻（0012）。
