# S卡 3-0086【貸せ、手本を見せてやる！】 / 第3话 青梅竹马约会挑战！（adv_csprt-3-0086_03）

- 她的台词：10 行（含用匿名标签说的 0 行）
- 出场的人：燕、星南
- 场景：看不出地点；燕说“日が暮れてきた”（0001）
- 世界线：S卡【貸せ、手本を見せてやる！】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
天快黑了，星南谢谢燕今天陪自己。燕说被她弄得连休息日都不得安宁，星南问是不是很开心，燕不作答。星南说多亏燕，“高中生期间想做的事”实现了三件，燕想到大头贴和圣代，问最后一件是什么。星南说就是现在，她最想做的是约会，和青梅竹马约会很青春。燕问她把约会当成什么，星南说是互相恋爱的人两人一起出去，但自己还不懂恋爱，不能做真正的约会，所以“拿燕将就了一下”。燕大怒，星南又说邀燕是对的，“果然喜欢你”。

## 她的关键台词
- 0002「燕。／今日は付き合ってくれてありがとう。」——诚恳地向燕道谢
- 0004「でも、楽しかったでしょう？」——追问燕的感受
- 0006「燕のおかげで、『高校生のうちにやって／おきたいこと』が3つも叶ったわ！」——说燕让三件愿望得以实现
- 0008「フフ……／それはね、今まさに叶っているわ。」——第三件事是现在在做的
- 0009「私が一番やっておきたかったのはね、／――デートよ！」——最想做的是约会
- 0011「ええ、幼馴染とデートなんて、／とても青春じゃない？」——把燕称为青梅竹马，约会是青春
- 0013「恋をしている者同士が、ふたりで／出かけることでしょう？」——给出自己对约会的定义
- 0015「でも、私はまだ恋を知らないから、／本当のデートはできないわ。」——说明自己还不懂恋爱，所以不能做真正的约会
- 0017「だから、燕で我慢してみたの。」——因此拿燕“将就”
- 0019「でも、燕を誘ってよかった。／やっぱりあなたのこと、好きよ。」——说邀燕是对的，直接说“好き”

## 行为模式
- 完成了心愿 → 向对方道谢，并把功劳给对方（0002、0006）
- 揭晓最后一件事 → 先卖关子，再直说（0008、0009）
- 被误会“是不是对我有意” → 明确说自己还不懂恋爱，但也直白地说喜欢对方（0015、0017、0019）
- 对方生气 → 不改口，而是追加肯定（0019）

## 关系
- 燕：称「燕」「あなた」（0002、0019）；称燕为「幼馴染」（0011）。她在这一篇里说“やっぱりあなたのこと、好きよ”（0019），同时说自己还不懂恋爱（0015）。

## 档案类事实
- 星南说自己“还不懂恋爱”（0015）。
- 星南称燕是青梅竹马（0011）。
- 这一天“高中生期间想做的事”实现了三件：大头贴、圣代（前两篇）和约会（0006、0007、0009）。

## 不确定
- 0017 的“燕で我慢してみた”是星南的说法，没有解释“我慢”的对象标准。
- 0019 的「好き」的含义，星南在 0015 说自己不懂恋爱；本篇没有进一步说明。
