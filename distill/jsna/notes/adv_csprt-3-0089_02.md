# S卡 3-0089【かかってらっしゃい！】 / 第2话 姐姐检查时间！（adv_csprt-3-0089_02）

- 她的台词：9 行（含用匿名标签说的 0 行）：0001、0002、0005、0007、0009、0011、0013、0015、0016
- 出场的人：星南、咲季、佑芽、千奈
- 场景：生徒会室的大扫除（0001）
- 世界线：S卡【かかってらっしゃい！】；制作人在制作的偶像：看不出（本篇没有明说；下一话 0089_03 里星南提到“由我来培育佑芽”）

## 发生了什么
星南宣布生徒会今天最大的工作是大扫除，并提醒大家别受伤。佑芽搬椅子时，星南让她用推车，说偶像要爱护手。星南接手咲季搬的货，让咲季擦桌子，咲季说搬重物习惯了，最后两人一起搬。千奈把纸箱要放到桌子上时，星南叫停，说桌子是否坏了，让她别碰，自己去拿替代的。咲季看着星南关照大家，最后说“还挺有两下子”。
剧情经过参照 hski、hume 笔记。

## 她的关键台词
- 0001「今日の生徒会、一番の大仕事――／生徒会室の大掃除よ！」——以会长身份宣布当天的主要工作
- 0002「1年生も入ってきて荷物も増えたし、／怪我しないように気を付けて頂戴。」——先提醒大家别受伤
- 0005「佑芽！　危ないから、／イスを運ぶときは台車を使いなさい。」——看到佑芽搬椅子立即叫住，给出具体做法
- 0007「アイドルなんだから、／手を大切にしなさい。」——用“你是偶像”作为让她爱护手的理由
- 0009「咲季、そこの荷物を運ぶのは代わるわ。／代わりに雑巾で、机を拭いてくれる？」——提出代替咲季搬重物，同时给她另一件事做
- 0011「いいのよ。任せて頂戴。」——咲季说习惯了之后仍然坚持代劳
- 0013「フフ、優しいのね。ありがとう。」——咲季提出一起搬时，笑着道谢
- 0015「千奈、ストップ。／そのテーブル、壊れていない？」——发现千奈要搬东西到不稳的桌子上，立刻叫停
- 0016「危ないから触らず置いておいて。／すぐに代わりを持ってくるわ。」——指示不要碰，自己去取替代品

## 行为模式
- 看到后辈搬东西或做可能受伤的事 → 立刻出声叫停并给替代做法（0005、0009、0015、0016）
- 后辈说“习惯了/没问题” → 仍然说「いいのよ。任せて頂戴。」，坚持代劳（0010、0011）
- 对方主动提出帮忙 → 笑着道谢，接受（0012、0013）
- 提醒的理由常常是安全和偶像的身体（0002、0005、0007）

## 关系
- 佑芽：直接叫「佑芽」；以“偶像要爱护手”提醒她（0005、0007）
- 咲季：叫「咲季」；让她改做擦桌子，她回绝后一起搬，星南说「優しいのね」（0009、0013）
- 千奈：叫「千奈」；叫停她搬东西到不稳的桌子上（0015）

## 档案类事实
- 她是生徒会长（生徒会室的大扫除由她宣布，佑芽称她「星南会長」，0018）
- 生徒会室的物品因1年级新生进来而变多了（0002）
