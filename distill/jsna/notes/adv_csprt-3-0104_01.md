# S卡 3-0104【インタビューお願いします】 / 第1话 去挑战顶点吧！（adv_csprt-3-0104_01）

- 她的台词：13 行（含用匿名标签说的 0 行）
- 出场的人：星南、優
- 场景：優对星南做关于『H.I.F』的采访（具体地点看不出）
- 世界线：S卡【インタビューお願いします】；制作人在制作的偶像：看不出

## 发生了什么
優来采访星南，先问这次『H.I.F』的目标。星南答是『一番星』，即『H.I.F』四连霸（0003、0004）。被问压力，她说有，但现在觉得舒服，想打倒她的偶像们会全力来挑战，没有比这更高兴的，自己也不打算让步（0005～0008）。她说想让大家知道初星学园有很多出色的偶像，这是代表学园的『一番星』的职责（0011、0012）。她解释『一番星』是背负那个时代初星学园的称号，一举一动关乎学园评价，相信只有有此觉悟的人才会来挑战（0014～0017）。最后向粉丝说状态万全，敬请期待（0020）。

## 她的关键台词
- 0004「それはもちろん『一番星』――／つまり『H.I.F』4連覇よ。」——毫不犹豫地把目标定为四连霸
- 0006「ええ、もちろんプレッシャーはあるわ。／でもそれが、今は心地がいいの。」——承认有压力，同时说这压力现在令她舒服
- 0007「十王星南を打倒しうるアイドルたちが、／全身全霊で挑んでくる――」——说挑战者会全力而来，用自己的全名说
- 0008「これほど喜ばしいことはないわ。／もちろん、譲るつもりはないけれど。」——把被挑战当作喜事，同时表明不会让步
- 0011「初星学園には素晴らしいアイドルが／たくさんいると知ってほしい。」——想让更多人知道初星学园的偶像
- 0012「それが初星学園の代表である『一番星』／の務めでもあると思っているの。」——把宣传学园看作『一番星』的职责
- 0014「そうね。／軽々しく捉えてほしくはないわ。」——不希望『一番星』被轻视
- 0015「『一番星』というのは、／その時代の初星学園を背負う称号。」——她对『一番星』的定义
- 0016「その一挙手一投足が、学園そのものの／評価になってしまう。」——『一番星』的责任在于一举一动关乎学园评价
- 0017「その覚悟を持った者だけが、／私に挑んでくると信じているわ。」——对挑战者抱有期待，用「信じている」
- 0020「コンディションは万全よ、／期待していてちょうだい！」——对粉丝的回应，自信的语气

## 行为模式
- 被问目标 → 直接回答『一番星』『H.I.F』4連覇，并解释含义（0004、0015）
- 被问压力 → 先承认“もちろんある”，再说成是让她舒服的东西（0006）
- 被夸奖受关注 → 说「光栄」，并转向想让大家知道学园的好（0010、0011）
- 谈到『一番星』的分量 → 语气变得郑重，希望不要被轻视（0014）
- 面向粉丝 → 简短自信地说状态万全，请期待（0020）
- 句尾常用“〜わ”“〜の”“〜ちょうだい”

## 不确定
- 0004 说“4連覇”，是目标还是已有的头衔，原文只说目标是『一番星』即『H.I.F』四连霸；“现任『一番星』”是从 0012「代表である『一番星』」推出。
- 【译文】0006 译文“有压力才有动力”，原文是「プレッシャーはあるわ。／でもそれが、今は心地がいいの。」（有压力，但那现在让人觉得舒服），意思不完全相同。
