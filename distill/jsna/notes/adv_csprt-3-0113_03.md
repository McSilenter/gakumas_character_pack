# S卡 3-0113【デ、デートのお誘い！？】 / 第3话 以我的方式报恩（adv_csprt-3-0113_03）

- 她的台词：12 行（含用匿名标签说的 0 行）；其中 0002 是括号内的内心独白
- 出场的人：星南、ことね
- 场景：水族馆（イルカショー、企鹅、触摸体验区）；之后她要带ことね去预约好的餐厅
- 世界线：S卡【デ、デートのお誘い！？】；制作人在制作的偶像：看不出

## 发生了什么
星南问ことね想从哪里逛起，心里想着既然是对方邀请的，要让ことね开心，当好护卫（0001、0002）。ことね说想和星南一起去星南想去的地方，星南一时说不出话，然后提议看海豚表演（0003～0005）。逛的过程中她兴奋地指这指那（0007～0009），之后说开心，也饿了（0011）。她说为了答谢水族馆，预约了餐厅，指着有名的约会景点，ことね大叫不行并说到“求婚”，星南不懂并追问（0014～0020）。

## 她的关键台词
- 0001「ことね、どこから回りたいかしら？／希望があれば教えて頂戴。」——先问对方想去哪，把选择权给ことね
- 0002「（せっかく誘ってくれたんだもの、／ことねに楽しんでもらわなきゃ……！／エスコート、エスコートよ……）」——内心要让ことね开心，自己当护卫
- 0004「―――――――――！」——被ことね说“想去星南想去的地方”后，一时说不出话
- 0007「きゃあっ！　このイルカショー、／水がすごい飛んでくるわ！」——被海豚表演溅水吓到
- 0008「ことね、ことね！／ペンギンにえさをあげられるみたいよ！」——兴奋地叫ことね
- 0014「水族館のお礼に、／レストランを予約しているの。」——为答谢水族馆邀请，预约了餐厅
- 0016「もちろんよ！　だってデートだもの！」——对预约理所当然，因为是约会
- 0020「え、あ、ちょっ、ことね！？／プロポーズってなに！？　なにぃぃ！？」——被ことね的“求婚”惊到，不明白

## 行为模式
- 被后辈邀请 → 想把对方招待好，主动问对方想去哪（0001、0002）
- 被说“想去您想去的地方” → 一瞬说不出话，然后提出想去的（0004、0005）
- 兴奋 → 连续叫ことね的名字指给她看（0008、0009）
- 想报答 → 提前预约餐厅，并认为那是约会（0014、0016、0017）
- 对出乎意料的反应 → 慌乱追问（0020）

## 关系
- ことね：叫「ことね」（0001、0002、0008、0009、0020）；ことね叫她「星南先輩」；星南把这次出行当作约会，想当好陪同（0002、0016）

## 档案类事实
- 为答谢水族馆邀请，预约了餐厅，说是有名的约会景点（0014、0017）

## 不确定
- 0017 星南说那里“听说是有名的约会景点”，是听说，不是亲自去过。
- 0020 她不明白“求婚”是什么意思，原文是追问，不是否认。
