# 有村麻央 亲爱度剧情 / 第36话（adv_dear_amao_036）

- 她的台词：9 行（匿名标签 0 行）
- 出场的人：麻央（29 行）、学園長（9）、星南（9）
- 场景：冬季『Hatsuboshi IDOL FESTIVAL』结束后的『一番星』授与式（0001～0006）；麻央说这里就是入学式那天她开演出的地方（0015）
- 世界线：亲爱度（有村麻央）；制作人在制作的偶像：有村麻央

## 发生了什么
学園長宣布『H.I.F』优胜者是有村麻央，并叫到“現『一番星』――十王星南”（0007～0011）。她祝贺麻央，并感谢麻央“来迎接我”（0012～0014）。麻央说入学式那天身为首席的她在这里开演出，同为1年生却是完美的明星，一直是近在眼前又遥远的憧憬之星；麻央道歉说来晚了，终于站到了她身边（0015～0023）。她把『一番星』交给麻央，说从今天起你就是『一番星』，请把声音传达给粉丝（0024～0026）。之后麻央发表获奖感言。

## 她的关键台词
- 0011「はい！」——作为现任『一番星』被点名时应答
- 0012「おめでとう、麻央。」——先祝贺胜者
- 0013「そして、ありがとう。」——接着道谢
- 0014「迎えにきてくれて。」——感谢的理由，接上麻央“带你出来”的约定
- 0017「……そうだったわね。」——听麻央说起入学式那天
- 0021「……麻央。」——听到麻央说一直憧憬自己时
- 0024「――受け取って。」——交出『一番星』
- 0025「今日から、あなたが『一番星』よ。」——正式让位
- 0026「さあ、ファンのみんなに、／あなたの声をとどけてあげて。」——把舞台交给新的『一番星』

## 行为模式
- 输给对手 → 先祝贺、再道谢，把对方的胜利当作“来迎接我”（0012～0014）
- 听对方倾诉多年的憧憬 → 只轻声回应、叫名字，不多说（0017、0021）
- 交接位置时 → 简短明确地说“收下”，并把注意力引向粉丝（0024～0026）

## 关系
- 麻央：叫「麻央」（0012、0021）、「あなた」（0025）；麻央称她「キミ」，说她入学时是首席、是同为1年生的完美明星、一直是麻央憧憬的星（0015～0020）。她感谢麻央来迎接她，把『一番星』交给麻央（0014、0025）。

## 档案类事实
- 在『H.I.F』之前是“現『一番星』”（0010，学園長的话）；本篇把『一番星』交给麻央（0024、0025）。
- 据麻央说，她是入学时的“首席”，入学式那天在这个地方开过演出（0015，麻央的话）；和麻央同届（0019“同じ1年生なのに”，麻央的话）。

## 不确定
- 0014「迎えにきてくれて」应是接第27话 0047、0048（麻央说要把她从塔上带出来，她回“王子様”）和第35话 0004 的说法，本篇没明说。同一条线前后一致。
- 第24话 0037 十王社長称她“今やトップアイドル”、第27话她是『H.I.F』优胜者，本篇她以“現『一番星』”身份交出称号，几篇之间不矛盾。
