# 雨夜燕 亲爱度剧情 / 第8话（adv_dear_atbm_008）

- 她的台词：10 行（含用匿名标签说的 0 行）
- 出场的人：燕、プロデューサー、星南
- 场景：星南来找制作人谈话，地点没写；之后是燕的训练（0027～）
- 世界线：亲爱度（雨夜燕）；制作人在制作的偶像：雨夜燕

## 发生了什么
星南听说制作人故意让燕参加自己也要出场的试镜（オーディション），来找制作人问为什么。她认定这是制作人的主意，因为燕赢不了她、不会主动挑战她；制作人说那只是燕的思维定式，现在不一样了。星南说想相信，但燕输给美鈴后又做这种鲁莽的挑战，评价只会再降，说制作人的做法惨不忍睹、对他失望。燕听到了最后部分，说活该。之后燕向制作人讲了和星南的过去：两家从小交好，幼时的星南是「ぽんこつ」、爱哭却总是自信满满，燕为了打碎这份自信开始当偶像；制作人指出燕其实憧憬着星南。

## 她的关键台词
- 0001「こんにちは、プロデューサー。」——主动来找燕的制作人，礼貌打招呼
- 0003「聞いたわ。私の出るオーディションに、／あえて燕を被せたって。」——消息灵通，开门见山
- 0007「あなたの差し金でしょう。／燕が、私に挑むわけないのだから。」——断定燕不会主动挑战自己
- 0009「私には勝てないから。」——毫不犹豫地说出燕赢不了自己
- 0011「今は違うと言うの？」——对制作人的反驳追问
- 0013「その言葉を信じたいけれど、」——表示想相信，但接着说出顾虑
- 0014「美鈴に負けた上に、この無謀な挑戦で、／燕はさらに評価を落とすでしょう。」——担心燕的评价，把这次挑战看成鲁莽
- 0015「あなたのプロデュースは、／今のところ目も当てられないわ。」——直接批评燕的制作人
- 0017「あなたには……失望したわ。」——对制作人表示失望

## 行为模式
- 听说和燕有关的安排 → 亲自去找燕的制作人当面问理由，而不是先问燕（0003、0005、0006、0007）
- 判断燕的能力 → 断言燕赢不了自己，同时担心燕的评价下降（0009、0014）
- 对方给出和她判断相反的说法 → 先说想相信，再列出现实理由，最后直接说失望（0013～0017）

## 关系
- 燕：她叫燕「燕」（0003、0007）；燕叫她「星南」（0018）、「あいつ」（0035）。她断定燕不会也赢不了自己（0007、0009），同时在意燕的评价（0014）。燕对制作人说两家从小交好、从小认识（0045），制作人说燕憧憬星南（0065）
- 美鈴：星南提到燕输给了「美鈴」（0014）
- プロデューサー（燕的制作人）：她叫他「プロデューサー」（0001）、「あなた」（0015）；制作人叫她「十王さん」（0002）。她批评他的制作惨不忍睹、对他失望（0015、0017）

## 档案类事实
- 和燕两家从以前就关系好，从小就认识（0045，燕的话）
- 幼时的星南是「ただのぽんこつ」，动不动就哭，燕说不帮她她什么都做不成，却总是自信满满（0047、0050、0052，燕的话）
- 当时星南在十王家的教育下以偶像为目标（0053，燕的话）
- 燕说星南是初星学園史上最高的『一番星』（0039，燕的话）；制作人说十王星南在初星学園是别格、和燕的方向相似（0034，制作人的话）
