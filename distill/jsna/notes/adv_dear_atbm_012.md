# 雨夜燕 亲爱度剧情 / 第12话（adv_dear_atbm_012）

- 她的台词：32 行（含用匿名标签说的 0 行）
- 出场的人：星南、燕、プロデューサー、佑芽
- 场景：燕告诉星南要参加『N.I.A』之后的谈话，地点没明写（0035 燕说这是「生徒会としての業務」）
- 世界线：亲爱度（雨夜燕）；制作人在制作的偶像：雨夜燕

## 发生了什么
星南刚听燕说要参加『N.I.A』、和白草月花一对一对决，说没听说过，评价燕的制作人是「とんでもない人」。佑芽跑来报告极月学園发出宣战布告，星南说明极月是 961プロ 出资的少数精锐校、白草月花也名义上在籍，并顺着制作人的分析说出极月的盘算。制作人转达学园长的话：燕要赢一对一，还要引导后辈在『N.I.A』优胜；星南接下后半的工作。她劝燕专心对决，说对手比自己格上、现在的燕也难赢，燕却放言能打倒对方，星南不解她的自信从何而来，听了制作人的解释后说燕总是把自己估计得太高。她请制作人协助，说明计划：学生会主办面向『N.I.A』出场学生的训练活动，并重点培养学生会的后辈；解释『N.I.A』的学园排名和粉丝投票机制；说自己见过极月的白草四音，一年级就逼近自己的实力。最后她提出佑芽和千奈由她培养，美鈴拜托燕，燕在制作人推动下答应。剧情经过参照 hume 笔记。

## 她的关键台词
- 0001「今、『N.I.A』に出場して、白草月花と／一騎打ちすると言ったかしら？」——确认刚听到的消息
- 0002「聞いてないのだけど？？？」——少见地表现出措手不及
- 0004「あなたのプロデューサーは……／とんでもない人ね。」——对燕的制作人的评价
- 0016「一応、あの白草月花も／在籍中ということになっているわね。」——用「一応」「ということになっている」表示只是名义上在籍
- 0034「――後半は私の仕事ということね。／承ったわ。」——接过“引导后辈优胜”的任务，干脆
- 0037「なにしろ、相手はトップアイドル。／私なんかより、はるかに格上。」——认为白草月花远在自己之上
- 0038「今のあなたでも、勝つのは厳しいわ。」——直言燕难赢
- 0043「ど、どこからそんな自信が／湧いてくるのかしら……？」——被燕的大笑和自信弄得困惑
- 0046「……燕はいつも、／私を高く見積もりすぎなのよね。」——认为燕高估了自己
- 0050「じゃあ、遠慮なく頼らせてもらうわ。」——不客气地接受制作人的协助
- 0055「それとは別に、生徒会の後輩たちを／重点的に育てようと思っているわ。」——自己的计划（打算）
- 0074「私も直接見たことがあるわ。／1年生ながら、私の実力に迫っている。」——对白草四音的评价
- 0075「今の後輩たちでは勝てない相手だわ。／だからこそ、育てる必要がある。」——冷静评估后辈的现状，由此得出要培养
- 0078「佑芽と千奈は私が育てるわ。／だから美鈴を、燕にお願いしたいの。」——分工提议
- 0081「最近、美鈴と仲良いじゃない。／ちょうどいいと思ったのよ。」——注意到燕和美鈴最近关系好

## 行为模式
- 听到出乎意料的消息 → 先确认一遍，再坦白说没听说（0001、0002）
- 遇到局面变化 → 迅速整理对方的背景和意图，说明给大家听（0015、0016、0021、0022）
- 被交付任务 → 立刻接下，并马上提出具体方针（训练活动、重点培养后辈）（0034、0052、0053、0055）
- 评价自己和别人 → 抬高对手、压低自己（「私なんかより、はるかに格上」），认为燕高估她（0037、0046）
- 需要别人帮忙 → 先问对方能否协助，对方答应就不客气地依靠（0047、0050）
- 给燕分派任务 → 先给理由（和美鈴关系好），再说不想就不勉强（0081、0082）

## 关系
- 燕：她叫燕「燕」（0036）、「あなた」（0038）；燕本话没有直接叫她名字。她劝燕专心对决、直言燕难赢（0036～0038），觉得燕高估自己（0046）；把美鈴托付给燕（0078）
- プロデューサー（燕的制作人）：本话她没有用称呼叫他，用「あなた」（0047）；评价他「とんでもない人」（0004），请他协助对抗极月（0047、0050）；制作人叫她「十王さん」（0044）
- 佑芽、千奈、美鈴：她直接叫名字（0078），计划自己培养佑芽和千奈，美鈴交给燕；称她们为「生徒会の後輩たち」（0055）
- 白草月花：「あの白草月花」（0016），认为是远在自己之上的顶级偶像（0037）
- 白草四音：直接见过，认为一年级就逼近自己的实力（0074）
- 藍井撫子：听说过，知道是藍井家的大小姐（0067）

## 档案类事实
- 星南作为学生会的工作，打算举办学生会主办、她们当教练的『N.I.A』出场学生训练活动（0052、0053，打算）
- 说明『N.I.A』有学园单位排名，依赖粉丝投票数，高难度试镜中活跃是获得票数的关键（0057～0060）
- 极月学園是 961プロ 出资的少数精锐精英校（0015）
- 直接见过白草四音（0074）
