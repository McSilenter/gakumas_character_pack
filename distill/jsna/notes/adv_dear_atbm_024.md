# 雨夜燕 亲爱度剧情 / 第24话（adv_dear_atbm_024）

- 她的台词：53 行（含用匿名标签说的 0 行）
- 出场的人：星南、燕、プロデューサー、ことね
- 场景：制作人布置好的演唱会舞台，观众只有星南一人（0003、0010「ここは……ライブステージ？」）
- 世界线：亲爱度（雨夜燕）；制作人在制作的偶像：雨夜燕

## 发生了什么
星南被带到空无一人的舞台，ことね告诉她这是只给她一个人看的演唱会，请她看到最后。燕出现，说这场演唱会只献给她，星南说做这种事她的心意也不会变。燕唱完新曲『クライアイ』，星南说是好歌，感受到了燕的心意、说燕真的很喜欢自己这个偶像。燕说即使没有星南自己也会继续当偶像，但看得出星南还想当偶像、还不想放弃顶级偶像；星南沉默后承认对偶像有遗憾，又以能力值已到上限、追不上觉醒后的燕为理由。燕说能力值决定结果的话自己早输给月花了，星南承认燕的表演有数值测不出的魅力，说因为燕看到了希望。燕说现在的星南比自己弱，星南承认；燕解释以前说的「貴様の重荷を、私が背負ってやる、と。」（0081）是“一起”分担初星学園重压的意思，星南发现自己误会了、喊燕的话容易误会，随即承认那只是逃避、是拿燕的话当放弃的理由。她说出真心：想当制作人是真的，但不想辞去偶像，想成为顶级偶像，不想被燕甩在后面、不想输给燕；燕说待在身边不需要理由。最后她意识到自己想当燕的对手，道谢后宣布撤回偶像引退。

## 行为模式
- 别人为她准备了打动她的东西 → 先表态“不会变”，但对好东西仍然诚实称赞（0023、0028、0030）
- 真心被看穿 → 先沉默，然后部分承认，同时搬出能力值这种“客观理由”来守住决定（0049～0052）
- 理由被驳倒 → 承认对方说得对（0058、0059）
- 发现自己误会、被说愚蠢 → 先恼羞地怪对方说话容易误会，随即自己反省、承认是逃避（0086～0090）
- 说出真心时 → 连续用短句直说想要什么、不想要什么（0092、0093、0095、0098）
- 和燕比较 → 习惯性地说燕在偶像之外比自己强得多，害怕失去待在她身边的资格（0100～0103）

## 关系
- 燕：她叫燕「燕」（0018、0107）、「あなた」（0030、0052）；燕叫她「十王星南」（0017）、「星南」（0027）、「貴様」（0021）。她承认想当燕的对手（0106）；担心偶像也输就不能待在燕身边（0103），燕回答作为朋友待在身边不需要理由（0105）。燕自称她「最も古いファン」（0065）
- ことね：ことね叫她「会長」（0012）；本话星南没有对ことね说话（0016 只是困惑的反应）
- プロデューサー（燕的制作人）：本话没有对话；制作人布置了只给她一个人的舞台（0001、0003）

## 档案类事实
- 宣布撤回偶像引退（0110）；想当制作人也是真心（0092）
- 梦想是成为顶级偶像（0093）
- 说燕在偶像之外的领域比自己厉害得多（0101）
- 说以偶像为目标是她自己的意志（0072）
- 说“过去的燕希望”她从偶像中解放出来（0068、0069，她的说法）

## 不确定
- 0068「せっかく、昔のあなたが願った通り――」、0069「アイドルから解放されたところだった」：燕小时候希望她从偶像中解放出来，具体指什么剧本没写（第8话燕说过想打碎她的自信，是不是同一件事不确定）。
- 0067「見えてしまった」是带着苦笑的说法，表示看见希望反而不能放弃了，这是读法。
- 本话之后『H.I.F』如何、制作人的梦想怎么办，本话没写。
