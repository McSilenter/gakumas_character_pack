# 藤田ことね 亲爱度剧情 / 第13话（adv_dear_fktn_013）

- 她的台词：36 行（含用匿名标签说的 0 行；0075 是括号里的内心独白）
- 出场的人：星南、ことね、プロデューサー
- 场景：剧本里没写明地点；制作人出差期间（0001），ことね 和星南单独谈话；其间插入制作人的台词（0008、0009、0030、0031、0043～0049）
- 世界线：亲爱度（藤田ことね）；制作人在制作的偶像：藤田ことね（0030「藤田さんには『N.I.A』を通して」）

## 发生了什么
ことね 问星南是否知道制作人出差的事，星南先坚持要 ことね 叫她名字，最后接受了「星南先輩」，然后说出差的事是「秘密」。她称赞制作人了不起，因为制作人让她放弃了“得到”ことね，两人比的是谁更能爱、引导藤田ことね，ことね 嫌弃不想听。星南劝 ことね 相信制作人、等他回来。她问 ことね 怎么看制作人的方针（通过『N.I.A』拿『一番星』、在剩下半年赚学费），并表明：ことね 是她的希望、『一番星』的继承人候选，但那是明年以后的事，今年背负初星学園的是她十王星南，胜利不会让；她认为现在的 ことね 没有胜算，『N.I.A』是在夏天打败她以外的次善之策。制作人则断言 ことね 状态好就有足够胜算、会在一年级拿下『一番星』，星南反问是不是太小看她。ことね 吞吞吐吐，星南追问她为什么不说要赢十王星南；ことね 坦白自己从星南小时候上电视跳舞起就是她的古参粉丝，一路看着她，所以这话很重，但还是宣言要打败星南、成为『一番星』。星南在心里感到这份分量与 ことね 的境遇，问「来年じゃあ、ダメなのね」，听到自己毕业后就不在了，便以「私のすべてで」接下挑战，要 ことね 把制作人的大话变成现实。

## 行为模式
- 对方用职位或敬称叫她 → 坚持纠正成名字，对方退一步时也接受（0002、0004、0006）
- 被问到不能说的事 → 不找借口，直接说「秘密」，并拿制作人自己也说「言えない」来挡（0010、0012）
- 对方说不想听 → 照样说下去（0018、0021），以自己的节奏讲
- 谈到对手或后辈 → 给对方极高评价，同时毫不退让地宣称胜利属于自己（0034～0039）
- 认为对方该说出口的话没说 → 主动挑明、追问（0055、0057）
- 听到对方的真心话 → 先沉默、在心里掂量对方的处境（0074、0075），确认理由后正面接下挑战，并反过来激励对方（0076～0079）

## 关系
- ことね：她叫 ことね「ことね」（0002、0078）；ことね 先叫她「会長」「星南会長」，被她纠正后改叫「星南先輩」（0001、0003、0005），回忆时称「ちっちゃい星南ちゃん」（0063）。她视 ことね 为希望和『一番星』继承人候选（0034），协助其成长但不让胜利（0037、0038）；本话 ことね 坦白是她的古参粉丝并向她宣战，她接下挑战（0060～0078）
- プロデューサー：她叫对方「プロデューサー」（0012、0079）、「あなたのプロデューサー」（0015）。她说曾和制作人比试谁更能爱、引导 ことね，前半「接戦」，最后制作人让她放弃了 ことね（0016、0018、0021）；她称赞制作人「すごい人」（0015），但对制作人“ことね 一年级拿『一番星』”的断言称为「大言壮語」（0079），并认为被低估了（0046）

## 档案类事实
- 现任『一番星』：ことね 说她打败厉害的前辈们成了『一番星』（0067）；她自称今年背负初星学園的是她（0039）
- 小时候在电视上跳过舞（ことね 0063），她自己说「あの仕事」大家应该都忘了（0064）
- 中等部时代被毫不照顾地做下积工作，升入高等部后迅速崛起（ことね 所说 0065、0066）
- 将会毕业，明年就不在学园了（ことね 0077，她没有否认）
- 认为现在的 ことね 没有胜算；夏天有能打败她的机会（0040、0042「夏に私を倒す」）
- 和制作人之间进行过「勝負」，比谁更能爱、引导 ことね（0018）
