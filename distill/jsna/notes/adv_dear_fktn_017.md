# 藤田ことね 亲爱度剧情 / 第17话（adv_dear_fktn_017）

- 她的台词：45 行（含用匿名标签说的 0 行；0050～0054 是括号里的内心独白）
- 出场的人：星南、ことね
- 场景：剧本里没写明地点；ことね 的ライブ（攻破極月学園精锐聚集的「魔城」）当天（0001「今日はおめでとう」、0009）
- 世界线：亲爱度（藤田ことね）；制作人在制作的偶像：藤田ことね（0003「プロデューサーと／星南先輩の無茶振りプラン」）

## 发生了什么
星南祝贺 ことね 的ライブ成功，说要给奖励、问能不能抱她，被 ことね 拒绝。她告诉 ことね：極月学園（961プロ）不想输给初星学園，为打败“十王星南执着的一年级、独自击败極月学園的谜之新人”，961プロ的顶级偶像、主要在纽约活动的白草月花紧急来日参战『N.I.A』。ことね 嚷着这是犯规、没有胜算，星南说昨天的她会同意，但 ことね 刚刚展示了挑战远强于己者并获胜、身披偶像『格』的样子；她终于明白初见 ことね 时感到的是「スター性」——连她自己最终都没能具备的、顶级偶像都有的东西，所以 ことね 有资格挑战顶级偶像。她说白草月花比自己格上，但看起来远非万全；心里判断月花受了伤，又打住了念头；她说现在的月花至多和十王星南同格，正适合当『H.I.F』的前哨战。ことね 追问她这话像在说自己没资格当顶级偶像，星南承认自己没能成为顶级偶像，所以在找能托付初星学園、能让『一番星』成为顶级偶像称号的继承人。ことね 怒斥「自分でやれ」，说不想当她的继承人、想当她的对手，要在下次试镜证明她看走了眼，星南沉默不语。

## 行为模式
- 欣赏的人取得成果 → 毫无保留地称赞，并想用拥抱之类的亲密方式表达（0001、0005、0006）；被拒绝也只受挫一下就继续（0008）
- 带来坏消息时 → 以戏剧化的说法铺垫，然后反问对方「さぁ……どうするの？」（0009～0029）
- 对方说没胜算 → 拿对方刚刚的实绩反驳，并给出高度评价（0031～0047）
- 判断对手状态时 → 冷静观察（0049、0050），但对顶级偶像保持敬意，不把对对方不利的猜测说出口（0053、0054）
- 被追问自身的局限 → 先沉默，然后承认（0060），并说明自己把希望寄托在继承人身上（0061～0063）
- 被后辈当面顶撞、拒绝当继承人 → 无言（0071）

## 关系
- ことね：她叫 ことね「ことね」（0001、0058），称「私のことね」（0028）；ことね 叫她「星南先輩」（0003、0064），本话后半怒吼时改叫「アンタ」（0069、0072），并称她「あたしのスター」（0075）。她想拥抱 ことね 被拒（0006、0007）。她承认一直在 ことね 身上看到スター性（0045），想让 ことね 当继承人；ことね 拒绝当继承人，说想当她的对手（0069、0070），她沉默（0071）
- 白草月花：961プロ的顶级偶像，主要在纽约活动（0013、0021、0022）；她说月花比她格上（0049），内心判断月花受伤（0051），并对顶级偶像保持敬意（0054）
- プロデューサー：本话不在场；ことね 把这次的计划称为制作人和星南的「無茶振りプラン」（0003）

## 档案类事实
- 自己说没能成为顶级偶像（0060），没能具备「スター性」（0041、0044）
- 一直在找能托付初星学園的继承人（0061），想让『一番星』从学园第一变成顶级偶像的称号（0062、0063）
- ことね 听说她能“视”出偶像的实力和才能（0064「アイドルの実力とか／才能が視えるそうですね」）；本话她观察白草月花的状态（0049、0050）
- 她认为白草月花比自己格上（0049）
- 提到『H.I.F』，把对月花的比赛当成它的前哨战（0056）
- 她说極月学園即961プロ（0012）
