# 姫崎莉波 亲爱度剧情 / 第12话（adv_dear_hrnm_012）

- 她的台词：30 行（匿名标签 0 行）；0033～0037 是括号里的内心话
- 出场的人：莉波（46 行）、星南（30）、プロデューサー（29）、千奈（5）、旁白（1）
- 场景：莉波在给千奈掏耳朵（0001、0013），她撞见（0008～0012），制作人也在场（0017）；地点剧本没写明。0064「数日後」起是莉波和制作人的场面，她不在场
- 世界线：亲爱度（姫崎莉波）；制作人在制作的偶像：姫崎莉波

## 发生了什么
她撞见莉波给千奈掏耳朵、千奈叫莉波“お姉さま”，沉默一下、清清嗓子才问在做什么（0008～0012）。莉波说这周是“お姉さん力強化週間”，制作人说明是让莉波对朋友们也表现得像姐姐；她理解为是为参加『N.I.A』的练习（0014～0023）。莉波问她要不要也试试，她慌忙以生徒会長的身份拒绝，莉波说是开玩笑（0027～0031）；她心里承认有一点动心，并觉得最近莉波成长显著，那位制作人引出了连她都没看出的莉波的魅力，不可小看（0033～0037）。莉波问她不参加『N.I.A』吗，她说这次要专心准备下一次『H.I.F』（0039、0040）。她说意外莉波会参加『N.I.A』、以为莉波不擅长竞争，问是不是制作人劝的；莉波说决定是自己的，可能是最后的机会，她说会支持（0044～0051）。最后她提醒莉波：极月学園的最大出资方是恶名昭著的961プロ，传闻要在『N.I.A』里打压对手学校的偶像，务必小心（0053～0062）。

## 行为模式
- 撞见出格的场面 → 先沉默、清嗓子，再结巴地问（0008～0012）
- 被邀请做有失身份的事 → 慌忙用“生徒会長”的体面推掉，但心里承认有点动心（0028、0029、0033）
- 看到后辈变化 → 在心里分析，并把功劳归给对方的制作人，承认自己没看出来（0034～0037）
- 后辈做出意外的决定 → 先问是不是被人劝的，听到是本人意志后表示支持（0047～0051）
- 掌握对后辈有用的情报 → 主动提起、说明来由，并叮嘱小心（0053～0062）

## 关系
- 莉波：叫「莉波」（0010、0044、0062）；莉波叫她「星南会長」「会長」（0011、0039）。她以为莉波不擅长竞争（0046），听了莉波的决心后说会支持（0051），并提醒莉波小心961プロ（0062）。
- 莉波的制作人：心里称「そのプロデューサー」，觉得他引出了连自己都没看出的莉波的魅力，不可小看（0036、0037）；这一篇没有直接对他说话。
- 千奈：这一篇她没有对千奈说话（千奈在莉波腿上睡着了，0026）。

## 档案类事实
- 是生徒会長（0029）。
- 这次不参加『N.I.A』，要专心准备下一次『H.I.F』（0040）。
- 知道极月学園是多家事务所出资设立的偶像养成校，最大出资方是961プロ，并听说961プロ要在『N.I.A』里打压对手学校的偶像（0056～0061）。
