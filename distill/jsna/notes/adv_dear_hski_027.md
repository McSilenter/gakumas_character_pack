# 花海咲季 亲爱度剧情 / 第27话（adv_dear_hski_027）

- 她的台词：10 行（含用匿名标签说的 0 行）；行号 0001、0003、0004、0007、0009、0010、0011、0012、0013、0014
- 出场的人：咲季、星南、プロデューサー、一同
- 场景：咲季和星南的ライブ结束后，会场的后台一带。她穿着衣装赶来，之后离开；其余是咲季和制作人的谈话。
- 世界线：亲爱度（花海咲季）；制作人在制作的偶像：花海咲季

## 发生了什么
星南穿着舞台装跑来，说自己先结束所以赶来了。她对咲季说「勝ったようね」，咲季回「あなたも」。之后两人沉默。星南说自己忙着特训，要做的事堆积如山，所以要走了；她笑着说从第一次登台后没这么开心过，宣布『H.I.F』将重生，要把「私たちの可愛い『一番星』」鍛得更强，一起挑战。她之后不出场。

## 她的关键台词
- 0001「――咲季！！！！」——一见面就大喊咲季的名字。
- 0003「私の方が先に終わったから！　／大急ぎで駆け付けたのよ！」——说明自己是赶过来的。
- 0004「――勝ったようね。」——第一句话就确认咲季获胜。
- 0007「用は済んだし、もう行くわ。」——事情办完就离开。
- 0009「自分の特訓にかまけていたせいで、／やるべきことが山積みなの。」——解释为何慌忙：自己的特训让事情堆积。
- 0011「こんなに楽しいのは、はじめて／ステージに立ったあの日以来。」——说出此刻的心情：非常开心。
- 0012「咲季！　これから『H.I.F』は／生まれ変わるわ！」——宣布『H.I.F』即将重生。
- 0013「私たちの可愛い『一番星』を、／さらに強く鍛え上げて――」——要把『一番星』进一步锻炼强。
- 0014「ともに挑みましょう！」——邀请咲季一同挑战。

## 行为模式
- 比赛一结束 → 立刻穿着衣装赶去对方那里，先确认胜负（0001～0004）。
- 做完确认 → 不久留，抛下一句话就走（0007）。
- 心情高涨时 → 笑，把自己的感受和“接下来的事”连起来说（0010～0014）。

## 关系
- 咲季：称「咲季」；与咲季一起把佑芽称作「可愛い『一番星』」（0013）。
- 佑芽：这里指「私たちの可愛い『一番星』」（0013），剧本没有直说名字。
