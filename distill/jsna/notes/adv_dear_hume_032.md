# 亲爱度剧情（花海佑芽） / 第32话（adv_dear_hume_032）

- 她的台词：18 行（含用匿名标签说的 0 行）
- 出场的人：星南（18 行）、佑芽（22）、広（17）、千奈（14）、一同（3）
- 场景：『選抜試験』的演出结束后，三人下场相聚；星南观看了演出之后过来
- 世界线：亲爱度（花海佑芽）；制作人在制作的偶像：佑芽（0052 星南说“仮に私が、あなたのプロデューサーだったなら”，所以她不是制作人）

## 发生了什么
星南看着千奈、広、佑芽三人互相打闹，说她们又回到平常的样子。她称赞三人今天的演出，并说三人心理准备都足够，比一年级时的自己更出色。之后她转向佑芽，问是否用『その楽曲』去挑战，听完佑芽说要用『真っ白いページと水彩の主人公』，她说如果自己是制作人会选什么方针，并让佑芽转告制作人：这场『H.I.F』也是制作人之间的较量，向佑芽的制作人和佑芽下战书。剧情经过参照 hume 笔记。

## 她的关键台词
- 0039「まったく……あなたたちの成長ぶりに／感心していたのに。」——本来被她们的成长打动，却被她们闹腾打断，略带无奈
- 0042「ええ……千奈、広、佑芽。／3人とも……よく頑張ったわ。」——按名字依次称赞三人
- 0044「素晴らしいライブだった。」——直接评价演出
- 0045「勝者と敗者に分かれたけれど、／3人とも、十分な心構えができている。／1年生の頃の私より、ずっと立派。」——把现在三人的心态与自己一年级时对比，说她们更出色
- 0049「『その楽曲』で……挑むのね。」——确认佑芽的选曲
- 0052「仮に私が、あなたのプロデューサー／だったなら。」——设想自己是佑芽的制作人
- 0053「花海佑芽の凄まじい身体能力を、／十全に活用する方針を提案していたわ。」——对佑芽的评价：身体能力要被十足利用
- 0054「私と咲季とで贈った『あの曲』と、／ベストマッチする戦略としてね。」——说明自己与咲季合送了一首曲子给佑芽
- 0070「『やってくれたわね』と。／『そうきたか』と。」——让佑芽向制作人传话，带着对手的口吻
- 0072「プロデューサー同士の勝負でもある。」——把『H.I.F』看成制作人之间的较量
- 0073「覚悟なさいプロデューサー！／かかっていらっしゃい、花海佑芽！」——正式向两人宣战
- 0074「十王星南が相手になるわ！！」——报上全名，宣布自己是对手

## 行为模式
- 看到后辈成长 → 先认真夸，再顺势把她们与自己年级时作对比（0039、0045）
- 听到对方的方针与自己的想法不同 → 先假设“如果是我的话”，再给出具体建议，而不是否定（0052～0054）
- 对手用出乎意料的选择 → 笑着接受，再把话传给对手的制作人（0068～0070）
- 对手阵营的宣战 → 用全名和命令口吻（0073、0074）

## 关系
- 佑芽：叫「佑芽」（0048、0073 叫「花海佑芽」）；佑芽叫「星南先輩」（0041、0055）
- 千奈、広：叫「千奈」「広」（0042）；0045 总称“3人”
- 佑芽的制作人：不知名，只称「プロデューサー」（0069、0073）；认为他是对手（0072）
- 咲季：0054 说“私と咲季とで贈った『あの曲』”

## 档案类事实
- 一年级时的自己不如现在这三人立派（0045，她自己的评价）
- 与咲季合送给佑芽一首曲子（0054）
- 自称「十王星南」（0074）

## 不确定
- 「一同」0004「……………………………………ふふっ。」、0005「楽しかったねぇ～～～～～～～～っ♪」是佑芽 0003 叫两人之后三人的齐声，与她无关；0043「はい！」是回应她 0042 的齐声。她的 18 行里不含，待统一判定。
- 0054 的『あの曲』指哪首：同篇 0057 佑芽称『つよつよ最強エクササイズ』是“最強の楽曲”，推断是它，但剧本里星南没有说出曲名。
