# 十王星南 亲爱度剧情 / 第2话（adv_dear_jsna_002）

- 她的台词：48 行（含用匿名标签说的 0 行）
- 出场的人：星南、プロデューサー
- 场景：她刚向制作人展示完实力之后（0001、0002），两人的第一次会议（0013）。剧本里没写明地点、时间
- 世界线：亲爱度（十王星南）；制作人在制作的偶像：十王星南（0007「担当アイドル」，0016「十王星南が抱える問題」）

## 发生了什么
她向制作人展示了实力，制作人说明白了她被称为学园第一的理由（0001～0003）。她让制作人叫她「星南」，理由是制作人本该用名字称呼担当偶像（0006、0007）。她说如果制作人说她“没有问题、照这样下去”，她会失望；她以「プロデューサー志望の後輩」的身份开始第一次会议（0011～0014）。制作人指出：她自去年在 H.I.F 优胜成为『一番星』后实力完全没有成长，她承认这是「致命的な問題」（0018～0021）。她说出自己的特技：从小看了很多偶像，一眼就能看穿偶像的实力和才能，祖父似乎也能看到；照镜子也会看到自己的能力值和剩余的潜力（0023～0035）。她从 3 岁起接受成为顶级偶像的精英教育，从没怀疑过，结果一年前到达了才能的极限，现在就是全盛期，再也不会成长（0036～0044）。她能看到的是 Dance、Vocal、Visual 三项的现值和极限值（0050、0051）；制作人提议“那就提升这三项以外的能力”，她说自己也希望如此，所以才不甘心地挣扎，但从没做过提升看不见的能力这种事（0057～0060）。制作人说边失败边前进、和别的偶像一样，她答应试试（0063、0064）。

## 行为模式
- 开始合作 → 先让对方改称呼、以制作人与担当偶像的规矩来定调（0006、0007）
- 期待被指出问题，而非被夸 → 预先说明“若只被说没问题会失望”，被指出致命问题时干脆承认（0012、0020、0021）
- 被怀疑特技的真伪 → 提出写出全校学生的能力值来证明（0027）；对方表现出兴趣时有点慌（0028），转而觉得和「先輩」的判断比较一下也有意思（0029）
- 谈自己的界限 → 用平静、断定的语气讲，但坦承不想让仰慕她的学生听到（0042、0045）
- 被提出从没想过的方向 → 先惊讶（0054），说自己也希望如此，再坦白不知道怎么做（0057、0059、0060），最后在“有希望”的前提下答应试试（0064）

## 关系
- プロデューサー：她叫对方「プロデューサー」（0017、0047、0063），也称「先輩」（0029）；以「プロデューサー志望の後輩」自居（0014）。制作人先叫她「十王さん」（0005），她要求后改叫「星南さん」（0008、0015）。她说制作人是第一个成功挖到她的人（0010）
- 祖父：她说祖父似乎也能看到能力值（0032）
- 仰慕她的学生们：她不愿让他们听到自己停止成长的事（0045）

## 档案类事实
- 去年在 H.I.F 优胜、成为『一番星』（制作人 0018，她未否认 0020）
- 特技：一眼看穿偶像的实力和才能（0025）；能看到 Dance、Vocal、Visual 三项的现值和成长到极限时的数值（0050、0051）；照镜子也看得到自己的（0034、0035）；说能写出全校学生的能力值（0027）
- 祖父似乎也能看到（0032）
- 从很久以前就一直在看很多偶像（0023）
- 从 3 岁起接受成为顶级偶像的精英教育（0036、0037）；自认在最好的环境中长大（0040）
- 一年前到达才能的极限，自认现在是全盛期、不会再成长（0041、0042）
- 制作人是第一个挖到她的人（0010）
- 制作人称她「星南さん」（0008）
