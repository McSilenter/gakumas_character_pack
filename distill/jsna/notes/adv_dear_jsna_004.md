# 十王星南 亲爱度剧情 / 第4话（adv_dear_jsna_004）

- 她的台词：40 行（含用匿名标签说的 0 行；0049、0050（0051 可能也是）是 ことね 播放的一小时前的录像里她的话，0053）
- 出场的人：星南、ことね、プロデューサー
- 场景：她主持的面向初星学園全校学生的直播对谈节目（0001～0003）
- 世界线：亲爱度（十王星南）；制作人在制作的偶像：十王星南（剧本里没有直接说法；制作人心里话 0075、0076 谈的是「十王星南の魅力」）

## 发生了什么
她开始直播，介绍今天和自己个人关注的期待一年级生对谈，ことね 登场（0001～0006）。她说终于能和 ことね 慢慢谈，很高兴（0007）。ことね 说收到“你是什么人”之类的严厉留言，她便向全校介绍 ことね 是她发掘的「初星学園の救世主」；ことね 当成玩笑，她就在全校面前发誓没有半句谎言，说相信 ことね 会成长为比谁都闪耀的星、总有一天代替她背负学园（0016～0026）。ことね 害羞地说第一次被这样夸、很高兴，她也说自己被弄得不好意思了（0029～0031）。被问做这个企划的理由，她说（是她个人的想法）想从一年级生身上学到现在的她没有的、数值表现不了的魅力（0035～0040）。ことね 说知道大家不知道的十王星南的魅力，播放了一小时前她紧张得发不好声的录像，她大慌，说视频直播是第一次、又是直播没台本，不能让大家幻灭，又怀疑是制作人干的（0047～0058）。ことね 说以前以为她是完美无缺的偶像，现在知道下了舞台也会变回普通人，因此更喜欢她了；她说自己只是努力那样做，因为她是偶像，并对“大家不知道的魅力是不是不当偶像时的自己”表示困惑（0059～0073）。剧情经过参照 fktn 笔记。

- 0021「なら、全校生徒の前で誓いましょう。／私の言葉に、一切の嘘がないことを。」——被当成玩笑时郑重发誓
- 0026「学園を背負って立つアイドルに／なってくれることをね。」——期待 ことね 代替她背负学园
- 0031「……そんな顔をされたら。／私まで照れてしまうわ。」——对方害羞时她也害羞
- 0039「数値では表せないなにか。私ですら／はっきりとは視えない、星の輝き。」——她想学的东西
- 0048「ちょっ、聞いてないのだけど？？？　／なに？？？」——被突袭时慌乱
- 0050「ハァ……だ、ダメね……／緊張で上手く声が……」——录像中，直播前紧张的样子
- 0055「動画配信は初挑戦だもの！？　／しかも生放送で、台本もなしで……！」——解释紧张的原因
- 0056「幻滅させるわけにはいかないから、／絶対に失敗できないし緊張するに……」——不能让人失望的压力
- 0064「そうあろうとしているだけよ。」——承认完美形象是努力维持的
- 0065「私は、アイドルだから。」——对偶像身份的自觉
- 0073「アイドルではないときの……私？」——对新发现的魅力感到困惑

## 行为模式
- 面对公众 → 用「ごきげんよう」开场，端庄地主持（0001、0002）；但事前私下会非常紧张（0049、0050）
- 看中的人被人怀疑 → 当众公开力挺，必要时郑重发誓（0017、0021）
- 被对方真诚的反应打动 → 自己也害羞起来（0031）
- 被突然揭穿私下的样子 → 结巴、问号连发，脱口说出真实原因，再急忙否认（「そうではなくて！」），把矛头转向制作人（0048、0052、0055～0058）
- 被说“原来你不完美” → 平静说那是努力维持的，因为自己是偶像（0063～0065）
- 被称赞不当偶像时的自己 → 不知该如何反应，带着疑问重复对方的话（0071～0073）

## 关系
- ことね：她叫「ことね」（0006、0052）；ことね 叫她「会長」（0041、0061）。她在全校面前称 ことね 是自己发掘的救世主，相信 ことね 会代替她背负学园（0017、0024～0026）；ことね 说更喜欢她了（0069），她不知所措（0071）
- プロデューサー：她怀疑播放录像是制作人干的（0058）；本话她没有当面称呼制作人
- 全校学生：直播的观众，她说不能让大家幻灭（0056）

## 档案类事实
- 做了面向全校的直播对谈节目，和期待的一年级生对谈（0001～0003）
- 视频直播是第一次挑战（0055）；ことね 说她做过很多大型演出和电视演出（0054）
- 直播前紧张得发不好声（录像 0049、0050，ことね 说是一小时前 0053）
- 说自己完美的形象是努力维持的，因为她是偶像（0064、0065）
- 想从一年级生身上学到数值表现不了的魅力（0036～0040）
- 期待 ことね 将来代替她背负学园（0025、0026）
