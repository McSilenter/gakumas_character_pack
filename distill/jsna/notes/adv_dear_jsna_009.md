# 十王星南 亲爱度剧情 / 第9话（adv_dear_jsna_009）

- 她的台词：52 行（含用匿名标签说的 0 行；0001～0006 是演出结束时她在台上对全校学生说的话）
- 出场的人：星南、プロデューサー
- 场景：第8话那场演出结束时（0001）及结束后和制作人的对话；会场是她熟悉的讲堂，主要观众是学园学生（0033）
- 世界线：亲爱度（十王星南）；制作人在制作的偶像：十王星南（0046 制作人评价她；0065、0066 制作人心里话「夢が叶った。」「彼女とともに／高みを目指そう。」）

## 发生了什么
演出结束时，她对全校学生喊出决定要说的话：「この私を――」「『一番星』を目指しなさい！！！」「あなたたちの夢は、ここにある！」（0001～0006）。之后她对制作人说一时得意忘形、话说得太大，因为自认演出是最好的、情绪太高（0007～0012）。制作人说这是在受邀偶像们面前最好的胜利宣言，她惨叫，说那几位她都是大粉丝，本来还想演出后直接去要签名，现在刚宣战完不能去，一定被讨厌了（0013～0020）。见制作人在笑，她问笑什么；制作人说成为顶级偶像后的对话竟是这样，她问「なれた、と、思う？」（0021～0025）。她说有手感，觉得自己的演出是第一，像和整个会场融为一体，是第一次的体验；但也说这不是打分的活动，只是表演赛性质，会场和观众对她压倒性有利，连最好演出的理由也说不清（0027～0035）。即便如此，面对说到顶级偶像谁都会想起的憧憬之人，她谁也没输，展示了配得上「最上位の偶像」的样子——一个曾感叹无才、决定引退的人（0036～0042）。她向制作人道谢，说全是对方的功劳；制作人说世界上最努力的偶像是十王星南，她说原来偶像出成果时要这样说，学到了，然后哭起来（0043～0049）。她说终于说出了一直说不出口的话——要志存高远、别以只能在学园登顶的她为目标；虽然形式很不一样，终于尽到了责任（0050～0055）。制作人问她不打算把顶点让给后辈吧，她说当然，自己是初星学園的顶点、一番星的顶级偶像十王星南（0058～0063）。

## 行为模式
- 情绪高涨时 → 会说出比预定更强势的话，事后害羞地辩解（0007、0010～0012）
- 面对尊敬的前辈 → 以粉丝自居，担心失礼、被讨厌，夸张地懊恼（0015～0020）
- 被问到成果 → 先说出手感，再冷静地列举有利条件把成果打折扣，最后仍承认没输（0027～0039）
- 成功时 → 把功劳归于制作人（0044）；被夸时以“学到了”接住，然后情绪决堤哭出来（0047～0049）
- 被提醒还不能放下担子 → 稍停顿后用力肯定，重新宣告自己的位置（0060～0063）

## 关系
- プロデューサー：她叫「プロデューサー」（0021、0043）；制作人叫她「星南さん」（0022）。她说一切都是对方的功劳（0044）；被对方笑时追问（0021）
- 受邀的偶像们（「伝説のアイドルの皆様」）：她是这些人的大粉丝，本想要签名（0015～0017），担心被讨厌（0020）
- 全校学生：她在演出结束时要她们以『一番星』为目标（0002～0006）；她说终于说出了「志を高く持ちなさい」（0052）
- 后辈们：她不打算把顶点让给她们（0059～0061）

## 档案类事实
- 演出结束时对全校学生宣言「『一番星』を目指しなさい！！！」（0004）
- 这场演出会场是讲堂，主要观众是学园学生，不打分，像表演赛（0031～0034）
- 是那些受邀的“传说偶像”的大粉丝，本想演出后要签名（0015～0017）
- 自认这场演出没输给任何人（0039）；第一次体验到和会场融为一体（0029、0030）
- 曾感叹无才、决定引退（0041）
- 一直想对学生们说“要志存高远，别以只能在学园登顶的我为目标”（0051～0053）
- 制作人说她是世界上最努力钻研的偶像（0046）

## 不确定
- 0041「引退を決意していた」与第1话她说毕业后不当偶像（adv_dear_jsna_001 0023）对应，本话说的是过去的决定，现在是否撤回本话没明说。
- 0023 制作人说她「トップアイドルになった」，0065 制作人心里话「夢が叶った」；她本人只说「なれた、と、思う？」（0025），没有自己断定（第10话她说「トップアイドルになった」）。
- 0054「だいぶ、違う形に／なってしまったけれど……」——和原先打算的哪里不同，按上下文是指本想说“别以我为目标”，结果变成了“以『一番星』为目标”，属推测。
