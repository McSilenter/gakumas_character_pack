# 十王星南 亲爱度剧情 / 第10话（adv_dear_jsna_010）

- 她的台词：42 行（含用匿名标签说的 0 行；0008、0009 是她复述自己演出结束时说的话）
- 出场的人：星南、プロデューサー
- 场景：生徒会室（0002）；她说今天应是休息日（0003），制作人说是她实现梦想的第二天（0005）
- 世界线：亲爱度（十王星南）；制作人在制作的偶像：十王星南（0051「十王星南を育てたあなた」）

## 发生了什么
制作人来到生徒会室，说看到她闷闷不乐；她说对方观察得真仔细，是第一个察觉的人（0001～0006）。她说演出最后那番话让粉丝们很高兴，这让她开心，但有些人得意过头，在网上和受邀的传说偶像们的粉丝大吵（0007～0019）。她慌得问该怎么办，担心粉丝对前辈们无礼；制作人说放着也不会出大事，出了事也会处理，她称赞对方可靠，说自己当了制作人也不觉得能做得像对方一样，并说总有一天会追上对方（0021～0029）。她说成为制作人的目标现在也没变，只是推到了很久以后；她说自己实现了梦想、成了顶级偶像，但这光辉是粉丝给的，素的能力值仍不达顶级偶像的标准，今后要不断被和最上位的偶像比较，粉丝对立、黑粉增加、期待压身，烦恼反而加深（0031～0042）。正因如此，她觉得有这些经历的「元トップアイドル」制作人，或许能成为不输给对方的制作人（0043～0045）。看到制作人动摇，她说「一度だけよ」，说出培育了她的制作人是她作为制作人的憧憬、梦想、目标，要在对方身边被培育、学会对方的一切，最后称对方「私の、トッププロデューサーさん」（0047～0056）。

## 她的关键台词
- 0006「……フフ、本当に、よく見ているわね。／気付いたのは、あなたが最初よ。」——对制作人的观察力的评价
- 0017「ネットで大喧嘩しているのよ～～～！」——粉丝闹事带来的慌乱
- 0022「私の大切なファンたちが、／目上の方々に大変な失礼を……！」——重视粉丝，也重视礼数
- 0025「――――頼りになるわねあなた……！」——对制作人的信赖
- 0029「いつか……追いついてみせるわ。」——以制作人后辈的身份立志
- 0031「もちろん、いまも変わらないわ。／だいぶ……先の話にはなったけれど。」——制作人目标不变，但推迟
- 0036「けれど……この輝きは、／あくまでファンからもらったもの。」——对自身成就的认识
- 0042「夢を叶えたというのに、私の悩みは／減るどころか深まるばかりよ。」——成功后的烦恼
- 0045「あなたに負けないプロデューサーに／なれるんじゃないか、って。」——新的目标形态
- 0049「フフ……わかってるくせに。／私の口から言わせたいの？」——掌握主动权的调侃
- 0052「プロデューサーとしての……／私の憧れで、夢で、目標なの。」——对制作人的感情
- 0056「私の、トッププロデューサーさん。」——对制作人的新称呼

## 行为模式
- 被对方察觉到心事 → 先称赞对方观察仔细，再说出烦恼（0006、0007）
- 自己的粉丝失礼 → 慌乱，向制作人求助（0021、0022）；对方给出可靠的答复后由衷称赞（0025）
- 谈到成就 → 把光辉归于粉丝，冷静指出自己能力值不足（0036～0038）
- 把烦恼转化为动力 → 把这些经历看作将来当制作人的资本（0043～0045）
- 对方动摇时 → 抓住主动权调侃（「わかってるくせに」「一度だけよ？」），再郑重说出心里话（0047～0052）

## 关系
- プロデューサー：她叫「プロデューサー」（0001、0021）、最后叫「私の、トッププロデューサーさん」（0056）；制作人叫她「星南さん」（0004），自称制作人的「先輩」、称她「後輩」（0027、0028）。她说对方是她作为制作人的憧憬、梦想、目标，要在对方身边学会对方的一切（0052～0054）
- 粉丝们：她称「私の大切なファンたち」（0022）；粉丝在网上和受邀偶像的粉丝吵架，她很担心（0016～0019、0022）
- 受邀的传说偶像们：她称「目上の方々」（0022）

## 档案类事实
- 休息日她在生徒会室，迎接制作人「ようこそ、生徒会室へ。」（0002、0003）
- 成为制作人的目标仍没变，只是推到了以后（0031）
- 自认实现梦想成了顶级偶像（0034、0035），但说素的能力值仍不达顶级偶像的标准（0037、0038）
- 粉丝在网上和受邀偶像们的粉丝吵架（0016～0019）
- 想成为有顶级偶像经历的制作人（0044、0045）
- 称制作人「私の、トッププロデューサーさん」（0056）

## 不确定
- 0032 制作人说「春とは大きく状況が／変わった」，暗示两人初见在春天，但她本人没提。
- 0049～0052 她说的「意味」到底是表白式的感情还是单纯对制作人职业的憧憬，按字面记为「プロデューサーとしての」憧憬（0052）。
- 【译文】0008「この私を――／『一番星』を目指しなさい！！！」译成“让我成为——『启明星』吧！！！”，原意是“以我——以『一番星』为目标吧”，译错。
