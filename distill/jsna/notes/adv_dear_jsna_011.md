# 十王星南 亲爱度剧情 / 第11话（adv_dear_jsna_011）

- 她的台词：40 行（含用匿名标签说的 0 行）
- 出场的人：星南、プロデューサー
- 场景：她收到白草月花的挑战书之后，找制作人商量（0001、0009）。地点、时间剧本没写
- 世界线：亲爱度（十王星南）；制作人在制作的偶像：十王星南（0033、0034 制作人决定接受挑战；0064 她称制作人「私のトッププロデューサーさん」）

## 发生了什么
她告诉制作人自己也要参加『NEXT IDOL AUDITION』，承认已被称为顶级偶像的她参加新人大赛，被说违规也无法反驳（0001～0006）。她拿出寄给她的挑战书：寄信人是 961プロ 的白草月花，被称为新时代的顶级偶像（0009～0012）。她说成为『一番星』前和月花共演过一次，当时月花是極月学園的学生、和她同级，彼此在意，算是对手（如果不是她自作多情）；之后月花转战海外大幅飞跃，而月花想和晚了三步才成为顶级偶像的她在『N.I.A』决胜负（0014～0022）。她说若无视挑战，『N.I.A』会变成顶级偶像的「虐殺ショー」，这多半是月花的独断，但月花说要出就一定会出，即使黑井阻止（0025～0029）。她说与其让初星学園的偶像被单方面蹂躏，不如自己出场（0032）。她承认成为顶级偶像的那场演出对她极其有利，靠的是地利和周密的事前准备，能力值仍不在顶级偶像之列，赢不了状态最好的白草月花，但这不是不挑战的理由，因为她是『一番星』（0038～0046）。她请制作人助她一臂之力；制作人说相信她终会成为世界第一的偶像，这是下一个梦想，她说对方贪心，但答应「任せて頂戴」（0048～0060）。最后她抢先说出制作人要说的台词，称对方「私のトッププロデューサーさん」（0062、0064）。

- 0039「十王星南にとって、きわめて有利な／ステージだったということもね。」——冷静看待自己的成就

- 0045「それでも、／挑まない理由にはならない。」——不退缩

- 0062「『軽く蹴散らしてしまいましょう』／――でしょう？　お見通しよ、先輩。」——抢先说出对方的台词

## 行为模式
- 做出有争议的决定 → 先自己承认问题所在，再拿出理由说明（0005、0006、0009）
- 谈到旧日对手 → 用「自惚れでなければ」保留，语气带着熟悉和一点无奈（0018、0023）
- 评估形势 → 把自己的有利条件和不足一一说清，承认赢不了，但以责任为由仍要挑战（0038～0046）
- 需要帮助时 → 直接开口请制作人借力（0048）
- 被托付更大的梦想 → 先叹对方贪心，然后爽快接下（0059、0060）
- 已经熟悉对方的思路 → 抢先说出对方要说的话，称「お見通しよ」（0062）

## 关系
- プロデューサー：她叫「プロデューサー」（0001、0048）、「先輩」（0062）、「私のトッププロデューサーさん」（0064）；制作人叫她「星南さん」（0003、0030）。她请对方借力（0048），接下对方“世界第一偶像”的新梦想（0055～0060）
- 白草月花：她叫「白草月花」（0011、0044）、「彼女」；成为『一番星』前共演过一次，当时同级、互相在意（0014～0016），她说若非自作多情就是对手（0018）。评价月花好战、一意孤行（0023、0029）。月花寄来挑战书要在『N.I.A』和她决胜负（0009、0022）
- 黒井：她叫「黒井さん」（0029）；制作人称「黒井理事長」（0007）
- 初星学園的偶像们：她出场是为了不让她们被单方面蹂躏（0032）

## 档案类事实
- 决定参加『NEXT IDOL AUDITION』（N.I.A）（0002、0022）
- 收到 961プロ 白草月花的挑战书（0009～0011）
- 成为『一番星』前和白草月花共演过一次；当时月花是極月学園的学生，和她同级（0014、0015）
- 白草月花之后转战海外，被称为新时代的顶级偶像（0012、0019）
- 她说自己是「三歩遅れて」成为顶级偶像的（0021）
- 认为成为顶级偶像的那场演出靠的是地利和周密的事前准备（0038～0041）
- 自认能力值仍不在顶级偶像之列，赢不了状态最好的白草月花（0042～0044）
