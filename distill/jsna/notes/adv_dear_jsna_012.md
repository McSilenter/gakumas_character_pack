# 十王星南 亲爱度剧情 / 第12话（adv_dear_jsna_012）

- 她的台词：15 行（含用匿名标签说的 0 行）
- 出场的人：学園長、星南、プロデューサー、黒井
- 场景：前半是制作人向学園長申请让她参加『N.I.A』（0001～0017，她不在场）；后半是制作人带回参赛许可、向她转达（0018 起）。地点剧本没写
- 世界线：亲爱度（十王星南）；制作人在制作的偶像：十王星南（0001 学園長「星南を『N.I.A』に／出場させる」，制作人提出 0004）

## 发生了什么
制作人去向学園長申请让她参加『N.I.A』，学園長爽快批准，说『N.I.A』是黑井和学園長的儿子背着他策划的，打算连同经过一起宣布她参赛；黑井气得大叫（0001～0013）。学園長说批评的矛头由黑井、学園長、十王社長和制作人四人承担（0015～0017）。制作人把许可带回来，她感谢制作人的献身，承诺以胜利回报（0018～0020）。制作人转达学園長的预测：会改规则，在『FINALE』另设顶级偶像的一对一对决，『N.I.A』另有优胜者；她复述原本的规则（粉丝投票排名、最终日上位者公开试镜决定优胜者、『FINALE』是最大看点），并确认两人之外会另有优胜者（0022～0032）。学園長嘱托她不仅要赢下对决，还要引导、培养学园的后辈在『N.I.A』夺冠，她应下（0033～0035）。她说要把自己在生徒会召集的有望偶像练好、送进『N.I.A』，请制作人帮忙；制作人说她正式转为制作人还早，她抢先说出对方会说的「『いまから学ぶことには意味がある』」（0037～0042）。制作人提议她今天就作为制作人去挖角藤田ことね，她笑说这比赢顶级偶像还难（0045～0048）。

## 行为模式
- 别人为她出力 → 郑重道谢，并以承诺回报（0019、0020）
- 听到形势变化 → 自己复述规则、整理出结论（0025～0032）
- 被托付责任 → 简短应下（0035）
- 熟悉制作人的思路 → 抢先说出对方要说的话（0041）
- 被提起过去失败的事（挖 ことね）→ 笑着自嘲比赢顶级偶像还难（0047、0048）

## 关系
- プロデューサー：她叫「プロデューサー」（0019、0036）；制作人叫她「十王星南さん」（0045）。她感谢对方的献身（0019），请对方帮忙培养生徒会的偶像（0039）
- 学園長：叫她「星南」（0001、0033），嘱托她培养后辈在『N.I.A』夺冠，她应下（0033～0035）。本话她没有称呼学園長
- 生徒会召集的有望偶像们：她为亲自制作而召集（制作人 0038），打算练好后送进『N.I.A』（0039）
- ことね：制作人提议去挖角，她说比赢顶级偶像还难（0046～0048）

## 档案类事实
- 获得参加『N.I.A』的许可（0018）
- 在生徒会召集有望的偶像，为了亲手制作她们（0037、0038）
- 学園長嘱托她引导、培养学园后辈在『N.I.A』夺冠（0033、0034）
- 制作人说她正式转为制作人还早（0040）
- 『N.I.A』原规则：粉丝投票改变排名，最终日由上位者的公开试镜决定优胜者，『FINALE』公开试镜和优胜演出是最大看点（她所述 0025～0028）
