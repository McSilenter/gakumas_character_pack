# 十王星南 亲爱度剧情 / 第13话（adv_dear_jsna_013）

- 她的台词：31 行（含用匿名标签说的 0 行；其中 0004、0005、0054 是括号里的心里话，标签为「星南」，照算）
- 出场的人：星南、ことね
- 场景：生徒会室（0001）；『N.I.A』新规则刚公布之后（0009）
- 世界线：亲爱度（十王星南）；制作人在制作的偶像：十王星南（剧本里没有直接说法；本话制作人不出场，她心里话称其「先輩」0005、0054）

## 发生了什么
她把 ことね 叫到生徒会室；ことね 问为什么叫她来，她心里回想自己挖角的缺点是「性急で、抽象的で、一方的」，于是按顺序说明（0001～0006）。她先说明『N.I.A』刚公布的新规则（顶级偶像的对决之外另选优胜者），再说自己正在制作生徒会的一年级生，让 ことね 看资料：花海佑芽、秦谷美鈴、倉本千奈都出了成果，她打算让她们参加『N.I.A』争取优胜（0009～0020）。她进入正题，希望 ことね 也参加『N.I.A』，请求让她来制作 ことね，说自己不是正式制作人，只是一个偶像、一个学生，但「プロデューサー志望の／トップアイドル」（0022～0029）。ことね 问为什么是成绩差的自己，她说答案一样：ことね 有无与伦比的偶像才能，而且已在自己觉醒，在恶劣环境里也通过了定期公演的试镜（0033～0038）。ことね 说是大家帮了她，列举了前辈和朋友们，她说也让她推 ことね 一把，以『一番星』之名发誓不是谎言，说「あなたがいいの」（0045～0050）。ことね 答应后，她心里欢呼「先輩！！！　や……／やったわ～」；ことね 称她「星南プロデューサー」（0052～0056）。剧情经过参照 fktn 笔记。

## 行为模式
- 有过失败教训的事 → 事前在心里复盘缺点，改成按顺序、拿资料说明（0004～0006、0011、0017）
- 被问“为什么是我” → 不改口，重复同一个评价，并举出具体实绩佐证（0033～0038）
- 对方提到别人的帮助 → 简短接受，然后请求让自己也加入（0045、0046）
- 被怀疑是否真心 → 用『一番星』之名发誓（0048）
- 表面从容（「フフ、決まりね」）→ 心里却兴奋得大喊（0053、0054）

- プロデューサー：本话不出场；她心里称「先輩」，想起对方的指点（0005），成功时心里向对方报喜（0054）
