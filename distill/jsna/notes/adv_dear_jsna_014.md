# 十王星南 亲爱度剧情 / 第14话（adv_dear_jsna_014）

- 她的台词：33 行（含用匿名标签说的 0 行）
- 出场的人：星南、プロデューサー、千奈、ことね、佑芽（另有旁白 1 行）
- 场景：挖角 ことね 成功之后（0001）；『N.I.A』已经开始（0024）。前段和制作人谈话，中段去花海家（佑芽家）的偶像训练设施强化合宿（0023～0043），后段合宿结束回来向制作人报告（0059 起）。地点细节剧本没写
- 世界线：亲爱度（十王星南）；制作人在制作的偶像：十王星南（0016「星南さんの言う、アイドルとしての／能力値を上げておきましょう。」；0036「私のプロデューサー」）

## 发生了什么
制作人祝贺她挖角 ことね 成功，她说多亏参考了「先輩」（0001、0002）。她认同 ことね 有她没有的东西，在身边就能有所收获；她察觉制作人另有打算，制作人提议提升她的能力值，她说已到上限、一直在学园接受最好的课程，制作人说那场演出后其实伸长了一点点，要用「いままでとは違う方法」（0005～0022）。她带 ことね、佑芽、千奈去强化合宿，说这是为了全体能力的底子、会在试镜前回来，并说是「私のプロデューサー」建议试试的（0023～0037）。合宿结束后，她逐一问成果：佑芽说效果很好，千奈说全身痛得不知道效果，ことね 说身体状态可能是人生最好，她说那就去对了（0050～0057）。回来后她向制作人报告能力值上升了「ほんのすこしだけ」，激动地说在学园外用没试过的训练，自己还能成长，0 和 1 的差别非常大，并归功于制作人（0060～0068）。她说之后再一并道谢；被提醒明天有和他校偶像共演的电视工作后答应早休息，最后说最近像回到新人偶像，每天早上都觉得昨天的自己不是对手（0070～0078）。剧情经过参照 fktn、hume、kcna 笔记。

## 行为模式
- 制作人提出建议 → 先认同表面的意图，再追问背后还有什么（0011、0012）
- 被提议做她认为不可能的事 → 先用事实反驳（已到上限、一直接受最好的课程），再问具体方法（0017、0020、0021）
- 带领后辈 → 直接宣布行程，被质疑时说明理由并保证不误正事（0023、0025、0026）；事后逐一点名问成果（0050、0052、0055）
- 得到小小的成果 → 先平静地报告，再压不住地重复、激动（0061、0063、0065）
- 得到帮助 → 把功劳归于制作人（0002、0068），感谢多到说要以后一起还（0070）

## 关系
- プロデューサー：她叫「先輩」（0002）、「プロデューサー」（0060、0068、0075）；在后辈面前称「私のプロデューサー」（0036）。制作人叫她「星南さん」（0001、0059）。她把挖角成功和能力值上升都归功于对方（0002、0068）
- ことね：她叫「ことね」（0023、0055）；ことね 叫她「星南プロデューサー」（0027）。她认为 ことね 拥有比谁都多的她所没有的东西（0005、0006）；带 ことね 去合宿（0023）
- 佑芽：她叫「佑芽」（0050），问特训成果
- 千奈：她叫「千奈」（0052），问特训成果

- 挖角 ことね 成功（0001、0002）
- 带 ことね、佑芽、千奈去花海家（佑芽家）的偶像训练设施强化合宿（0023、0032、0033）
