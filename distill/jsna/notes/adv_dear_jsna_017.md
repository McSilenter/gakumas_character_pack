# 十王星南 亲爱度剧情 / 第17话（adv_dear_jsna_017）

- 她的台词：33 行（含用匿名标签说的 0 行）
- 出场的人：星南、プロデューサー、千奈、佑芽
- 场景：『N.I.A』期间，她刚结束自己的场次、穿着舞台服装赶往佑芽试镜的会场（0001～0005）；接着是和佑芽、千奈的对话；最后她向制作人讲述这些（0044「――と、いうことがあったのよ。」）并开会（0068）。地点剧本没写
- 世界线：亲爱度（十王星南）；制作人在制作的偶像：十王星南（0065「俺の担当アイドルは、／十王星南ですから。」）

## 发生了什么
她穿着舞台服装就要赶往下一个会场，说换衣服会赶不上佑芽的试镜，这点距离跑过去更快，说「ここからが本番よ！」（0001～0008）。佑芽哭着说输了，她说对手是顶级偶像不必哭；佑芽说不管对手是谁都不想输，她说这种心情是佑芽的大武器，问和顶级偶像比的感想；佑芽说很开心、只要练习自己也能做到，要拿下这次优胜，她有点招架不住地说「頼もしいわね」（0009～0023）。千奈说赢了，她祝贺千奈成长、说自己很骄傲，说千奈正在克服基础能力低的弱点，是不输给佑芽和 ことね 的优胜候补，而且电视艺人「千奈ちゃん」的知名度已经超过她，在观众票影响审查的『N.I.A』里等于拿着最强武器（0024～0034）。千奈抱怨说都怪她，制作第一天、没上任何课就让第一份工作是电视出演，她承认回头看是「少々性急なプラン」（0035～0039）。她把这些讲给制作人听，承认因此课程落后，千奈的基础能力在合宿大幅改善，但和其他候补相比仍逊色，问制作人若按其方针千奈是否会是第一候补（0044～0050）。制作人称赞她的制作手腕，她高兴地追问具体哪里；制作人说她能以十王之名压住赞助商，她说倉本会長那边可是很辛苦的；制作人说不想被卷入，她讽刺地说「先輩のクレバーな判断」很值得参考（0052～0059）。她问制作人谁会优胜，列出千奈、白草四音、佑芽，制作人说现在想的只有她、他的担当偶像是十王星南；她结巴后清嗓子，说那就开始『一番星』十王星南的会议（0060～0068）。剧情经过参照 hume、kcna 笔记。

## 她的关键台词
- 0005「この距離なら走った方が早いわ。」——为赶上后辈的试镜不顾形象
- 0008「ここからが本番よ！」——迎接紧张的日程
- 0010「佑芽、泣く必要はないわ。／相手はトップアイドルだもの。」——安慰输了的佑芽
- 0013「……その気持ちは、／あなたの大きな武器ね。」——肯定佑芽的不服输
- 0021「……そ、そう。頼もしいわね。」——对佑芽过于直觉的回答有点招架不住
- 0025「おめでとう、千奈。……成長したわね。／私も鼻が高いわ。」——为千奈骄傲
- 0033「もはや、私以上だもの。」——承认千奈的知名度超过自己（承接 0032）
- 0038「思い返してみれば、／少々性急なプランだったわね。」——承认自己的制作有欠妥之处
- 0050「あなたの方針なら、千奈が／第一の優勝候補だったかしら？」——向制作人请教
- 0053「そ、そう？　……具体的には？」——被夸时想多听
- 0056「倉本会長のことなら、これでも／すごく大変だったと言っておくわ……！」——和赞助商打交道的辛苦
- 0059「……あらそう。先輩のクレバーな判断、／とっても参考になるわ。」——讽刺
- 0066「…………そ、そう。」——被制作人说“只想着你”时的反应
- 0068「『一番星』十王星南の／ミーティングをね！」——转回自己是偶像的身份

## 行为模式
- 自己的偶像要上场 → 不换衣服直接跑去，把她们放在优先位置（0003、0005）
- 后辈输了 → 先安慰（对手是顶级偶像），再肯定其心态，再问从中学到什么（0010、0013、0014）
- 后辈赢了 → 祝贺并具体指出进步和优势（0025、0029～0034）
- 被指出自己的制作失误 → 先轻描淡写（「少々」），再在制作人面前承认具体的负面影响（0038、0047～0049）
- 被夸 → 结巴着追问具体哪里好（0053）
- 被制作人坦率表明重视 → 结巴、清嗓子，把话题转到正事上（0066～0068）

## 关系
- プロデューサー：她叫「プロデューサー」（0001）、「先輩」（0059）；制作人叫她「星南さん」（0052），称她是自己的担当偶像（0065）。她向对方请教制作方针（0050），被称赞制作手腕时很高兴（0053）；对方不肯帮忙应付倉本会長时讽刺对方（0059）
- 佑芽：她叫「佑芽」（0003、0010）；佑芽叫她「星南せんぱぁ～～～～～～い！」（0009）。她安慰并肯定输了的佑芽（0010、0013）
- 千奈：她叫「千奈」（0025）；千奈叫她「星南お姉さま」（0024、0035）。她夸千奈是优胜候补（0030）；千奈抱怨她的计划太急（0035～0037），她承认（0038）
- 倉本会長：她说在倉本会長那边费了很大劲（0056）

## 档案类事实
- 『N.I.A』期间同时制作佑芽、千奈、ことね，赶场看她们的试镜（0003、0030）
- 千奈制作第一天、没上课就安排了电视出演作为第一份工作，她承认计划太急（千奈 0036、0037，她 0038）
- 认为电视艺人「千奈ちゃん」的知名度已超过她（0032、0033）
- 制作人说她除挖角外的制作业务都做得很好，能以十王之名压住赞助商（0054、0055）
- 和倉本会長打交道很辛苦（0056）
- 制作人说「俺の担当アイドルは、／十王星南ですから。」（0065）
