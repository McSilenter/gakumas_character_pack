# 十王星南 亲爱度剧情 / 第18话（adv_dear_jsna_018）

- 她的台词：22 行（含用匿名标签说的 0 行）
- 出场的人：ことね、星南、プロデューサー
- 场景：她和顶级偶像一对一对决正式开始前（0004、0052「本番直前」）；ことね、千奈的试镜应已结束（0005）。地点剧本没写
- 世界线：亲爱度（十王星南）；制作人在制作的偶像：十王星南（0004 制作人说接下来是顶级偶像之间的对决；0021 ことね 称「星南先輩のプロデューサー」）

## 发生了什么
对决开始前她坐立不安，制作人以为她紧张，她却在担心 ことね 和千奈的试镜结果；被说是担心后辈，她纠正说是担心「担当アイドル」（0001～0010）。她不敢去看结果，叫制作人别笑；制作人说理解、但希望她集中在正式演出（0011～0015）。这时 ことね 出现，制作人说把『N.I.A』的优胜者叫来了，然后离开（0016～0019）。ことね 说她的制作人很有气场，她说那叫「なんでもお見通しで／不気味」（0021、0022）。ことね 报告优胜，她祝贺并说这样就能一起开优胜演出，ことね 说前提是她要赢，她说一定赢，『一番星』不会输给顶级偶像（0029～0034）。ことね 坦白自己第一个喜欢的偶像是「十王星南ちゃん」，从很早就是粉丝，每周看比她大两岁的小偶像唱跳，节目结束后、漫长的下积み时代、成为『一番星』的瞬间都看着（0037～0046）。她惊觉 ことね 当偶像也许是因为自己，ことね 叫她别露出那种表情，说多亏遇见十王星南才成了这么好的偶像，现在可以当她的对手了（0047～0051）。她说正式演出前别让她哭；ことね 叫她「あたしのスター」为她加油，她回「観ていなさい、私のスター。」，说要让对方看着她的对手战胜顶级偶像（0052～0057）。剧情经过参照 fktn 笔记。

## 行为模式
- 自己的大战之前 → 担心的却是自己制作的偶像的结果，不敢去看（0001、0005、0012）
- 被误会成担心“后辈” → 纠正为「担当アイドル」，强调制作人的立场（0008）
- 制作人一切都安排好 → 嘴上说「不気味」，其实是佩服（0022、0027）
- 得到好消息 → 简短祝贺，马上想到一起登台（0030、0031）
- 被问能否赢 → 用『一番星』的名号断言必胜（0033、0034）
- 被意外表白 → 连连「えっ？」，然后想到自己可能影响了对方的人生而愕然（0039、0047、0048）
- 被感动得快哭时 → 半嗔怪地说别让她哭，再以对方的话回敬，转化为斗志（0052、0056、0057）

## 关系
- ことね：她叫「ことね」（0023、0030）、「私のスター」（0056）；ことね 叫她「星南先輩」（0021）、「星南プロデューサー」（0029）、「プロデューサーちゃん」（0032）、「十王星南ちゃん」（0038）、「あんた」（0054）、「あたしのスター」（0055）。她称 ことね 为「担当アイドル」（0008）。ことね 坦白从小就是她的粉丝、她是 ことね 第一个喜欢的偶像（0038～0046），并要当她的对手（0051）；她自称「あなたのライバル」（0057）
- プロデューサー：她叫对方「アレ」，说什么都看穿、很「不気味」（0022、0027）；制作人叫她「星南さん」（0002）。制作人事先安排优胜者来给她打气（0018、0024～0026）
- 千奈：她担心 ことね 和千奈的试镜结果（0005）

## 档案类事实
- 和顶级偶像的一对一对决前，担心 ことね、千奈的试镜结果（0001、0005、0008）
- ことね 获得『N.I.A』优胜（0018、0029）
- 据 ことね：她是 ことね 第一个喜欢的偶像（0038）；比 ことね 大两岁，小时候作为小偶像在每周的节目里唱跳（0043），节目结束后有漫长的下积み时代（0045），后来成为『一番星』（0046）
- 她本人反问「じゃあ、あの番組を？」（0042），可知确有这样的节目
- 称 ことね「私のスター」（0056）
