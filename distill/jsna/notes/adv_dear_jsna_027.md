# 十王星南 亲爱度剧情 / 第27话（adv_dear_jsna_027）

- 她的台词：68 行（含用匿名标签说的 0 行）
- 出场的人：星南、ことね、プロデューサー、学園長
- 场景：夏季『H.I.F』颁奖与优胜演出（0001～0031）；之后庆功派对时她追出来找ことね（0035「パーティ抜け出してる場合じゃない」）；最后和制作人两人谈话；地点细节剧本里看不出
- 世界线：亲爱度（十王星南）；制作人在制作的偶像：十王星南（0087「私とあなたの／……最初の『H.I.F』」，0098 她说一直看着憧憬的他）

## 发生了什么
- 学园长宣布夏季『一番星』是十王星南；她在致辞中说赛前大家都以为她会顺利三连霸，但轮到她出场时，观众都在忘我地享受『H.I.F』，十王星南已不再是特别的存在，大家和她一样觉得谁赢都不知道（当然她自己一直打算赢）（0001～0019）。
- 她宣布野心——让『一番星』成为顶级偶像的称号、让『H.I.F』成为选出顶级偶像的大会——此刻已经实现；号召全校偶像科学生在冬季『H.I.F』再争『一番星』，并献唱优胜曲『赤裸々』。旁白：『H.I.F』以十王星南三连霸闭幕（0020～0031）。
- 庆功派对时她察觉ことね不对劲，追出来，用“顶级偶像的命令”让她说出来；ことね说不甘心的不是输给她，而是今天的自己不是十王星南最大的对手，想成为她的对手（0033～0069）。
- 她说ことね才刚到万全状态、从现在开始才是真正起点；ことね说她毕业就要离开学园，她说正因如此，在初星学园争『一番星』的机会只剩一次；ことね宣言要追上来，她说期待着“我的明星”（0070～0085）。
- 她问制作人今天自己怎么样，制作人说之前说 85 分是错的；她说偶像没有满分，明天的自己要超越今天，对手们一定会超越今天的她；制作人说她成了好制作人，她说因为一直看着憧憬的他（0086～0098）。
- 两人谈到下一个梦想“世界第一的偶像”，制作人说最好的舞台就在这里；她说下一个对手是成长后的黄金世代、数值远在她之上，又说因为他生出了新的梦想，并决定要在这所学园实现所有欲望后再毕业（0099～0119）。
- 剧情经过参照 fktn 笔记。

## 行为模式
- 公开致辞时 → 用敬体（です・ます）、第三人称「十王星南は」，先描述观众的心情，再宣布野心、向全校下战书（0003～0028）。
- 庆功场合察觉担当偶像异常 → 丢下派对去找她（0033～0037）。
- 想让对方说出心事时 → 先说「よかったら話して頂戴」，自己马上否定，改用“顶级偶像的命令”强硬地要求（0042、0043）。
- 后辈说出想成为她对手的心情 → 先「ばかね」，再用“才刚开始”“机会只剩一次”把不甘心转成目标（0070～0076）。
- 被制作人评分 → 自己先说“偶像没有满分”，把话题转向超越今天的自己（0090～0095）。
- 被制作人激出新梦想 → 嘴上抱怨“都怪你”，随即说要学他的贪心并下决心（0112～0119）。

## 关系
- 制作人：她称「プロデューサー」「あなた」（0099、0119）。她说两人一起的第一次『H.I.F』结束了（0087）；说自己能成为好制作人是因为一直看着憧憬的他（0098）；说他贪心、要学他（0116）。
- ことね：她称「ことね」「私のスター」（0033、0085）；ことね称她「星南プロデューサー」「星南先輩」「あたしのスター」（0034、0062、0083），说十王星南对自己是特别的、想成为她最大的对手（0060～0069）。她丢下派对去关心ことね，激励她以最后一次机会为目标（0036～0076）。
- 全校学生／黄金世代：她在致辞中称观众和学生「皆さん」，号召偶像科全体在冬季『H.I.F』再战（0026～0028）；说下一次的对手是成长后的黄金世代，数值远在她之上（0107、0108）。
- 学园长：宣布她是夏季『一番星』（0001、0002），她没有直接对学园长说话。

## 档案类事实
- 星南获得夏季『H.I.F』的『一番星』，『H.I.F』以她的三连霸闭幕（0002、0031）。
- 优胜演出曲是『赤裸々』（0030）。
- 星南将要毕业离开学园（ことね的说法，她认同）（0074、0075）；她说在初星学园和ことね争『一番星』的机会只剩一次（0076）。
- 这是她和制作人一起的第一次『H.I.F』（0087）。
- 她说制作人是她憧憬的人（0098）。
- 她决定要在学园实现所有欲望之后再毕业（0118）——是决心，不是已成事实。
