# 十王星南 亲爱度剧情 / 第28话（adv_dear_jsna_028）

- 她的台词：54 行（含用匿名标签说的 0 行）
- 出场的人：星南、プロデューサー、十王社長
- 场景：夏季『H.I.F』之后，出发去 100プロ 之前和制作人开会（0003），之后在 100プロ 见十王社長（0057）
- 世界线：亲爱度（十王星南）；制作人在制作的偶像：十王星南（0058 十王社長说看了「十王星南のプロデュースプラン」，0062 要他继续当星南的担当制作人）

## 发生了什么
- 她提出开冬季『H.I.F』的会议，制作人说该出发去 100プロ 了，她要求先稍微谈谈（0001～0005）。
- 她总结：夏季『H.I.F』三连霸、守住『一番星』，『H.I.F』正逐渐被称为决定顶级偶像的大会；担当偶像们都顺利，美鈴在准备『SyngUp!』解散演唱会，这件事很依赖制作人，她再次道谢（0006～0021）。
- 她断言照这样下去会输给自己培育的千奈、佑芽、ことね，但仍要全力锻炼她们、再迎战取胜，制作人说这是满分回答；她又说初星学园全体偶像都会来挑战，下次『H.I.F』形势不利（0022～0040）。
- 她提出另一个问题：也有人认为『H.I.F』终究是校内活动，称之为决定顶点的舞台太狂妄；制作人同意，并说她向世界夸下海口那天起就有义务证明自己是顶点、为学园留下遗产，她说觉得这局面很值得挑战、能和他一起挑战很幸福（0040～0054）。
- 在 100プロ，十王社長说看了十王星南的制作方案，她毕业后正式成为 100プロ 所属偶像，要制作人继续担任她的担当制作人，制作人答应（0057～0066）。
- 十王社長要她今后别再玩“制作人游戏”、专心偶像活动；她当场拒绝，说现在还不是 100プロ 的偶像，要在毕业前让他改变看法，证明自己走的路是正确的（0068～0079）。

## 行为模式
- 被提醒该出发时 → 还想先谈工作，理由是路上也能想（0003、0004）。
- 受了制作人帮助 → 正式道谢，并担心对方辛苦；对方说没事后就不再追问，认为继续担心是失礼（0015～0021）。
- 判断形势不利时 → 直说“会输”“不利”，但不示弱，转为具体行动（全力培育再迎战）（0026～0036）。
- 制作人同意批评她的意见 → 先「むっ」不满，被点出义务后立刻接话表明自己明白（0045～0050）。
- 被上位者要求放弃当制作人 → 当场用敬语明确拒绝，讲出理由并立下要证明的宣言，然后礼貌告辞（0070～0079）。

## 关系
- 制作人：她称「プロデューサー」「先輩」「あなた」（0001、0015、0054）；制作人称她「星南さん」（0003）。她依赖、感谢、尊敬他（0015～0018），说能和他一起挑战很幸福（0054）。十王社長要他继续当她的担当制作人，她认为确保他是最重要的事（0066、0067）。
- 十王社長：她称「十王社長」，用敬语（0057）；十王社長称她「十王星南くん」（0068）。十王社長要她毕业后加入 100プロ、别再当制作人，她当面拒绝并要在毕业前改变他的看法（0069～0077）。两人的其他关系本篇没有说明。
- 担当偶像们（美鈴、千奈、佑芽、ことね）：她称「私の担当アイドルたち」「あの子たち」，说她们都很顺利、已成长到能威胁她（0012～0025），要全力锻炼她们来打倒自己（0028）。
- 『SyngUp!』的成员：她称「『SyngUp!』の子たち」，问制作人是不是很辛苦（0019）。

## 档案类事实
- 星南在夏季『H.I.F』三连霸，守住『一番星』（0007）。
- 美鈴在准备『SyngUp!』解散演唱会，这件事星南很依赖制作人（0014、0015）。
- 十王社長说星南从初星学园毕业后将正式成为 100プロ 所属偶像，要制作人继续担任她的担当制作人（0061、0062）。
- 十王社長要她别再当制作人、专心偶像活动；她拒绝，说要在毕业前改变他的看法（0069～0073）。
- 她说自己是因为培育后辈、被后辈追赶、互相教学才变得更耀眼的（0074～0076）。
