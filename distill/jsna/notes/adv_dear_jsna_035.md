# 十王星南 亲爱度剧情 / 第35话（adv_dear_jsna_035）

- 她的台词：35 行（含用匿名标签说的 0 行）
- 出场的人：星南、プロデューサー、佑芽、ことね、千奈
- 场景：冬季『H.I.F』正赛当天，前半在担当偶像们的休息室开会（0005「控え室から出るまで」），之后回到制作人身边（0046「ただいま、先輩。」），上台之前
- 世界线：亲爱度（十王星南）；制作人在制作的偶像：十王星南（0053、0054 她说「担当アイドルが／涙をこらえられるように」「十王星南を送り出す、／素敵な激励をお願いね」）

## 发生了什么
- 正赛当天，她问三人状态，三人说最佳；她宣布从会议结束到走出休息室，她会忘记自己是偶像十王星南，作为她们的制作人挑战十王星南（0001～0007）。
- ことね说今天能和“作为制作人的星南先輩”说话只有现在；佑芽问如果自己成为『一番星』她能不能纯粹以制作人身份庆祝，她才明白三人都打算赢她（0011～0019）。
- 千奈、佑芽、ことね依次宣言要用各自的歌赢她（千奈说要以次期生徒会長身份赢；佑芽说从她那里学到偶像是什么；ことね说因为憧憬她才入学、被她救了才成为偶像），她逐一叫她们的名字，说她们的这些会让十王星南更耀眼；三人说求之不得（0020～0045）。
- 她回到制作人身边，说本想送出担当偶像，反而被她们推了一把，说她们也许有当制作人的才能；制作人让她先别哭，她请制作人给出鼓励的“示范”（0046～0056）。
- 制作人说她拿下三冠、提高了『一番星』和『H.I.F』的名声，她说多亏他的无理要求；她说这是全体初星偶像的功劳，十王星南也难免苦战（0057～0064）。
- 制作人说最后一批还不认可『一番星』价值的人也来了，她说“那几位”结束远征回国，十王四天王到齐了，还说这是很好听的外号；制作人说她毕业后不再叫『一番星』但责任还在，她说四连霸、引领大家到最后还不够，答应在舞台上拿出十王星南的答案，把学园生活和偶像人生都倾注进歌里（0065～0083）。
- 剧情经过参照 fktn、hume、kcna 笔记。

## 她的关键台词
- 0004「いい返事。当然ね、この私が／育てたアイドルたちだもの。」——以担当偶像为傲。
- 0006「私はアイドル・十王星南であることを／忘れる。」——把制作人身份和偶像身份切开。
- 0007「あなたたちのプロデューサーとして、／十王星南に挑むわ！」——以制作人身份挑战自己。
- 0019「私に勝つ気満々じゃない！」——发现后辈都要赢她。
- 0039「あなたたちのそれが、／十王星南を輝かせる……！」——后辈的挑战让她更耀眼。
- 0050「私の方が、背を叩いて／送り出されてしまったみたい。」——反被后辈鼓励。
- 0051「フフ……あの子たち、プロデューサーの／才能があるのかもしれないわ。」——夸后辈。
- 0055「お手本を見せてくれるでしょう、先輩。」——请制作人鼓励自己的撒娇方式。
- 0059「あなたが無茶ぶりをしてくれなければ、／ここまでの結果にはならなかったわ。」——把成果归功于制作人。
- 0062「初星アイドル全員の功績よ。」——把『一番星』的成就归于全体。
- 0069「これで……十王四天王が、／そろい踏みということかしら。」——她起的外号。
- 0071「皆さんは恥ずかしがっていたけれど、／素敵な異名でしょう？」——对自己的命名得意。
- 0078「4連覇を果たし、最後まで『一番星』／として皆を導き続けること……／きっとそれだけでは足りないわね。」——毕业前的责任感。
- 0083「すべてを込めて歌ってくるわ！」——上台前的决心。

## 行为模式
- 大赛当天面对担当偶像 → 先问状态，再宣布暂时“忘记自己是偶像”，以制作人身份站在她们一边（0002～0007）。
- 后辈话里有话 → 一时没听懂，明白后惊呼“你们要赢我”（0015～0019）。
- 后辈逐一宣战 → 只叫名字回应，最后说她们的挑战会让自己更耀眼（0026、0032、0037～0039）。
- 被后辈感动、快哭时 → 用“请你示范鼓励”的方式向制作人要鼓励（0050～0055）。
- 被夸成就 → 归功于制作人的无理要求和全体初星偶像（0059、0062）。
- 给别人起外号 → 明知对方难为情，仍觉得好听、得意（0069～0071）。

## 关系
- 千奈：她称「千奈」（0026）；千奈称她「わたくしのプロデューサー」（0020），以次期生徒会長身份宣战（0023）。
- 佑芽：她称「佑芽」（0032）；佑芽称她「プロデューサーちゃん」（0029），说从她那里学到偶像是什么（0027）。
- ことね：她称「ことね」（0037）；ことね称她「星南先輩」（0011），说因为憧憬她才进入初星学园、被她救了才成为偶像（0033、0034）。
- 三人整体：她说是自己培养的偶像（0004），以制作人身份挑战十王星南（0007），被三人推了一把送上舞台（0050）。
- 制作人：她称「先輩」「プロデューサー」（0046、0081）；制作人称她「後輩」（0047）。她请他鼓励自己（0054、0055），说成果多亏他的无理要求（0059）。
- “那几位”（十王四天王）：她说她们结束远征回国、观战，自己给她们起了“十王四天王”的外号，她们会难为情（0068～0071）。具体是谁本篇没有说名字。

## 档案类事实
- 冬季『H.I.F』正赛当天，她在休息室以制作人身份为ことね、佑芽、千奈送行（0005～0007）。
- 千奈的曲是『ときめきのソルフェージュ』，佑芽的曲是『つよつよ最強エクササイズ』，ことね的曲是『The Cute!!!』（0025、0031、0036）。
- ことね说因为憧憬星南才进入初星学园（0033）。
- 星南给某几位偶像起了“十王四天王”的外号，她们去了远征、此时回国观战（0068～0071）。
- 制作人说她拿下『三冠』，『一番星』这次终于成了顶级偶像的称号（0057、0061）。
- 她毕业后不再被称为『一番星』（制作人的说法）（0073）。

## 不确定
- 0003「一同」「ベストコンディションです！！」：不算她的台词，是回答她提问的一方；在场的是ことね、佑芽、千奈，没有已确认结论。
- 0068 的「あの方々」、0069 的『十王四天王』是谁，本篇没有说名字；第30话 0066 愁佳说过怕又被人说是四天王里最弱的，是否同一组人本篇没有说明。
- 0061 制作人说『一番星』「今度こそ」成为顶级偶像的称号，第27话 0023 星南在致辞中已说这个野心刚刚实现了；是说法逐步加强还是前后不一，本篇看不出，记下供参考（不算冲突）。
- 0077 制作人说「あなた自身の言葉です」，指她以前哪句话，本篇没有说明。
- 【译文】0071「皆さんは恥ずかしがっていたけれど」译成“她们虽然会难为情”，原文是过去时“她们之前很难为情”。
