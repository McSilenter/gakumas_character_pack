# 倉本千奈 亲爱度剧情 / 第27话（adv_dear_kcna_027）

- 她的台词：15 行（含用匿名标签说的 0 行）
- 出场的人：千奈（30 行）、星南（15）、燕（8）、佑芽（6）、莉波（6）、美鈴（4）、一同（3）、広（2）
- 场景：千奈当选次期生徒会长后，大家祝贺（0001～0002）；地点剧本没写明
- 世界线：亲爱度（倉本千奈）；制作人在制作的偶像：倉本千奈

## 发生了什么
千奈当选，她说投票日前一天差距已经大到她的应援 live 也追不回来（0005、0006）。佑芽说单挑她的千奈不输『一番星』，燕说她嘴硬才让佑芽来打圆场，她否认，然后承认千奈的 live 很好，说虽然局面对千奈有利，但千奈把舞台炒得不输给她（0014～0026）。美鈴说这就是『一番星』的嘴硬，她一时语塞，莉波劝她这是庆祝场合（0027～0029）。她正式叫「倉本千奈さん」，把生徒会和初星学园托付给千奈和伙伴们（0030～0033）。千奈宣布冬天的『H.I.F』要以『一番星』为目标，她问千奈明不明白这意味着什么；千奈说自知不自量力、目前达不到，但不会放弃（0047～0061）。她说看来让千奈误会了，和大家一起列举千奈的成绩，说已经不把千奈当新人，而是对手（0062～0070）。剧情经过参照 hmsz、hume 笔记。

## 行为模式
- 输了 → 先找理由（差距早已拉开、局面对对方有利），被点破嘴硬就慌忙否认，然后郑重承认对方好（0005、0006、0021～0026）
- 被调侃到无话可说 → 「クッ……！」，再清嗓子把场面转为正式（0028、0030）
- 交接时 → 改用全名加「さん」，郑重托付（0030～0033）
- 后辈宣布要挑战自己的位置 → 不先表态，问对方是否明白意味着什么（0048）
- 后辈自我评价太低 → 不安慰，而是说“已经不当你是新人”，把对方提升为对手（0062、0070）
- 说话：～わ～わね～かしら，笑声「フフ」（0005、0023、0026）

## 关系
- 千奈：叫「千奈」（0026），交接时叫「倉本千奈さん」（0030），也叫「あなた」（0025、0032、0070）；千奈叫她「星南お姉さま」（0024）。她承认输给千奈、把生徒会托付给千奈，并宣布把千奈当对手（0023、0032、0070）。
- 燕：燕叫她「会長」，也叫「貴様」，说她嘴硬、丢人（0019、0020）；她否认（0021）。本篇她没有称呼燕。
- 美鈴：美鈴调侃她是『一番星』的嘴硬（0027），她语塞（0028）。本篇她没有称呼美鈴。
- 莉波：莉波叫她「会長」，劝她这是庆祝场合（0029）；她顺着清嗓子转入正题（0030）。
- 佑芽：佑芽称她「星南先輩」（0015），说千奈不输『一番星』（0016）。

## 档案类事实
- 她在选举应援 live 的最终日和千奈对演，她说投票日前一天的差距已经追不回来（0005、0006）。
- 美鈴、佑芽称她『一番星』（0016、0027）。
- 燕、莉波称她「会長」（0019、0029）；她把生徒会托付给千奈（0032）。
