# 倉本千奈 亲爱度剧情 / 第36话（adv_dear_kcna_036）

- 她的台词：17 行（含用匿名标签说的 0 行）
- 出场的人：千奈（34 行）、星南（17）、学園長（9）、佑芽（1）、広（1）、美鈴（1）、手毬（1）、香名江（1）
- 场景：『Hatsuboshi IDOL FESTIVAL』结束后的『一番星』授予仪式，有来场观众（0001～0006）
- 世界线：亲爱度（倉本千奈）；制作人在制作的偶像：倉本千奈

## 发生了什么
学園長宣布『H.I.F』冠军是千奈，并叫她以“现『一番星』”的身份上台（0007～0011）。她说千奈守住了和她的约定，千奈说还没有，要作为下任会长、新的『一番星』从现在起去履行（0012～0016）。她说本来想在千奈快哭时说她，结果自己先要哭了；千奈说会替她擦眼泪，就像她以前为千奈做的那样，她说怀念（0017～0022）。她说一直希望千奈有一天超过她，没想到这么快、这么强，然后说现在不是感慨的时候，要完成最后的职责，把『一番星』交给千奈（0023～0029）。她说毕业后可能在校外竞争，到时候要千奈做好觉悟；千奈说初星学园的『一番星』不会输给トップアイドル，她说这才像样，让千奈去对会场的观众说话（0031～0036）。剧情经过参照 ttmr、hmsz、hume 笔记。

## 行为模式
- 被后辈超越 → 先说对方守了约定，再承认自己快要哭了，说一直希望对方超越自己（0012、0019、0023）
- 情绪涌上来时 → 自己说“现在不是感慨的时候”，转回该尽的职责（0025、0026）
- 交接完 → 立刻把对方当成将来的竞争对手，说「覚悟なさい」（0031、0032）
- 后辈说出强硬的话 → 「それでこそ」表示认可（0035）
- 说话：～ね～わ～なさい「頂戴」，笑声「フフ」（0017、0022、0027、0032）

## 关系
- 千奈：叫「千奈」（0012、0023、0027），也叫「あなた」（0018、0029），交接后称「『一番星』」（0035）；千奈叫她「星南お姉さま」（0013、0033）。她把『一番星』交给千奈，说一直希望千奈超越自己（0023、0029）；千奈说她以前为千奈擦过眼泪（0021）。

## 档案类事实
- 学園長称她为「現『一番星』」（0010，学園長的话）；她把『一番星』交给了千奈（0027～0029）。
- 她说自己毕业后可能在校外和千奈竞争（0031）。
- 千奈说她以前为千奈擦过眼泪（0021，千奈的话），她说怀念（0022）。
