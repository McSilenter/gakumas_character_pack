# 篠澤広 亲爱度剧情 / 第23话（adv_dear_shro_023）

- 她的台词：44 行（含用匿名标签说的 0 行；0058、0060 是她讲述在学園長室的经过时插入的回忆场面）
- 出场的人：星南、広、学園長
- 场景：広『N.I.A』优胜、星南夏季『H.I.F』优胜之后（0001、0002）；広来找星南，之后两人换到屋顶谈（0019、0020）；0056～0061 是星南讲述的学園長室的情形
- 世界线：亲爱度（篠澤広）；制作人在制作的偶像：篠澤広（本篇制作人未出场）

## 发生了什么
她祝贺広『N.I.A』优胜，広回贺她夏季『H.I.F』优胜，又说她看上去很高兴；她说在『H.I.F』本战上一个「生意気な後輩」给她做了示范，教会她任何墙都能打破，自己的计划因此大变（0001～0008）。広宣布要在下次『H.I.F』打倒她、想向作为制作人培养千奈她们的她请教，她说很高兴，培养后辈是十王星南的责任，但自己不会输给任何人，「かかっていらっしゃい」（0010～0017）。她把広带到屋顶，说重要的话在屋顶谈才帅（0019、0020）。她建议広优先强化歌唱力，理由是広的潜在能力里「Vocal」最高、最容易成长（0021～0033）。広说会参考这种「オカルトっぽい」依据，她有点僵，広说自己求的不是神而是『一番星』，她说那就更要帮広（0042～0047）。她突然运气，说是在模仿広以前展示的アイドルパワー控制，练不会，去学園長室演示请教被笑，所以来问広；広说不知道，但更喜欢她了（0048～0066）。最后的建议是锻炼数值无法表示的偶像力量，像夏季『H.I.F』上逼得她走投无路的咲季的底力、広在『N.I.A』优胜ライブ上的『神格』；问怎么做，她笑说要是知道就不辛苦了，反而希望広给她示范（0067～0079）。

## 行为模式
- 被后辈宣战 → 高兴，夸对方「律儀」，答应帮忙，同时明确宣布自己不会输（0012、0015、0017）
- 谈重要的事 → 换到屋顶，讲究“帅”（0019、0020）
- 给建议 → 先给结论，再问能否触及对方的潜在能力，然后用自己的特技说明理由（0022、0030、0032）
- 被说成“玄学”→ 僵笑一下，但接受对方的说法（0043、0044）
- 有不会的事 → 不顾形象地向后辈、学園長请教，被笑也认真（0050～0058）
- 说不出答案时 → 大笑承认不知道，反过来期待对方示范（0077～0079）

## 关系
- 広：叫「広」（0001、0017）；広叫她「星南」。祝贺広『N.I.A』优胜（0001），以前辈和“如果我是你的制作人”的立场给建议（0015、0028），也把広当作要打败自己的对手（0017）；向広请教アイドルパワー的控制（0052、0053）；在『N.I.A』优胜ライブ上看到広的『神格』（0072、0073）。広说更喜欢她了（0065）
- 学園長：在学園長室演示请教，学園長大笑说她的魅力已经在提升，她坚持说没有（0055～0061）
- 咲季：说夏季『H.I.F』上咲季那股莫名的底力把自己逼到绝境（0070）
- 千奈等：広说她作为制作人在培养千奈她们（0013）
- 「生意気な後輩」：在『H.I.F』本战上教会她任何墙都能打破（0004、0005），本篇没点名

## 档案类事实
- 夏季『H.I.F』优胜（0002，広的话）
- 在『H.I.F』上被咲季逼到绝境（0070）
- 作为制作人在培养千奈她们（0013，広的话）
- 认为培养后辈是自己的责任（0015）
- 有能看出偶像潜在能力的「特技」，有人不相信（0032、0035）
- 喜欢在屋顶谈重要的事，觉得帅（0020）
- 看了広的『N.I.A』优胜ライブ（0072）
- 试着练広的“アイドルパワー控制”没练成（0052、0053）

## 不确定
- 0004「生意気な後輩」是不是 0070 提到的咲季，本篇没有明说。
- 0006「大幅に予定が変わってしまった」是什么预定，本篇没说。
- 0055～0061 是她讲述的学園長室情形（回忆插入），学園長说她的魅力在上升（0059）是玩笑还是认真，不清楚。
- 第22话広回忆里的「アイドルパワー」一事，本篇她自己提起（0052），作为发生过的事来讲。
