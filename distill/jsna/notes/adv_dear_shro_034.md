# 篠澤広 亲爱度剧情 / 第34话（adv_dear_shro_034）

- 她的台词：24 行（含用匿名标签说的 0 行）
- 出场的人：広、星南、owl、千奈、香名江、？？？（0050，随后 0051～0053 表明是 owl）
- 场景：『H.I.F』本战当天、开赛前（千奈 0013「決戦前」，她 0019「本戦でまみえる前に」，她 0062「今日」）；広送走千奈和香名江后，她在等広（0017、0018），她打招呼说「おはよう」（0017）；地点没写
- 世界线：亲爱度（篠澤広）；制作人在制作的偶像：篠澤広（0006 広「わたしには、／素敵なプロデューサーがいる」；本篇制作人未出场）

## 发生了什么
千奈和香名江离开后，她在等広，说想在本战交手前和広谈谈，先道谢（0017～0020）。第一是広给了她超越极限的提示——広做出“はあああ”的动作，她说就是那个；但她也坦白实际效果不知道，自己的数值依然没变，不过已经不再烦恼，只管全力跑下去，向包括広在内的出色对手们学习（0023～0032）。広说她现在比以前更有自信和魅力、像トップアイドル，她高兴地说感谢反而更多了，又列举広『N.I.A』优胜、前几天和千奈的对バン上的精彩ライブ让『H.I.F』更热闹（0033～0041）。広说那是千奈的功劳、千奈就是她们这一代的学生会长，她认同千奈有“女王之器”，但说赢的会是自己（0042～0049）。owl 出现插话，她认出声音，见広对 owl 的态度和对自己完全不同而惊讶，用敬语和 owl 寒暄，问 100プロ的希望之星为何在此，owl 说来看去年打败自己的她输掉；她反问是否认为今天有人能赢自己（0050～0062）。之后是 owl 对広的激励，她没有再说话。

- 0019「ええ。本戦でまみえる前に、／あなたと話しておきたくて。」——开战前特意来找对手
- 0020「――ありがとう。」——先道谢
- 0023「まずは……この私に、限界を超える／ヒントを与えてくれたこと。」——承认从后辈那里得到提示
- 0029「もちろんよ――／と、言いたいところだけれど。」——不硬撑，转为坦白
- 0030「実際のところは、どうかしらね。／依然として、私の数値は変わらない。」——承认数值没变
- 0031「それでも、もう、悩むことはないわ。／全力で走り続けるだけよ。」——放下烦恼的宣言

- 0036「お礼をしている最中なのに、感謝の／気持ちが増えてしまったじゃない。」——被夸后的喜悦
- 0048「ええ……途方もなく大きくて、／愛らしい、女王の器。けれど……」——对千奈的评价
- 0049「勝つのは私よ。あなたにも、／誰にも、負けはしない。」——不输的宣言
- 0055「ひ、広……？　私への態度と……／ずいぶん違うのね……？」——看到広对 owl 恭敬而吃惊

- 0062「今日、私に勝てるアイドルがいると、／そうお思いですか？」——面对挑衅的反问

## 行为模式
- 大赛前 → 主动去找对手，先郑重道谢，再宣战（0019、0020、0049）
- 被问起效果时 → 先摆姿态，随即坦白实际情况（数值没变），再给出自己的结论（0029～0031）
- 被后辈夸 → 坦率高兴，说感谢变得更多了（0035、0036）
- 别人夸第三者（千奈）→ 先认同并给出评价，再用「けれど」转回自己会赢（0048、0049）
- 被前辈挑衅“未必” → 用敬语、保持礼貌，但反问对方是否真觉得有人能赢自己（0057、0059、0061、0062）
- 看到后辈对别人比对自己恭敬 → 吃惊地追问（0055）

## 关系
- 広：叫「広」（0017、0055）；広叫她「星南」（広 0018、0033）。感谢広给了自己超越极限的提示、让『H.I.F』更热闹（0023、0039～0041），把広列为要学习的对手（0032），同时宣布不会输给広（0049）。広说她现在像トップアイドル（広 0033、0034）；広对 owl 用敬语、对她不用，她为此吃惊（0055）
- 千奈：对广说千奈是“途方もなく大きくて、愛らしい”的女王之器（0048）；広说千奈是她们这一代的学生会长（広 0047）。前几天千奈和広的对バン（0040）
- owl：称「owl先輩」（0057），用敬语，说「相変わらずですね」（0059）；称 owl 是「100プロのホープ」（0059）；owl 称她「星ぇ～南」「トップアイドル十王星南サマ」（owl 0056、0058），说去年被她打败（owl 0060）

## 档案类事实
- 她坦白自己的数值依然没有变化（0030）
- 去年打败了 owl（owl 0060）
- 以前和 owl 认识，称 owl 为前辈，说“好久不见”（0057、0059）
- owl 说初星学园最强偶像是十王星南（owl 0063）

## 不确定
- 0023 的「限界を超える／ヒント」是広 0025 的“はあああ”动作（第23话她提过想学広的アイドルパワー控制，那一篇是她讲述的经过）；它的实际效果她自己说不知道（0030）。
- 0030「私の数値」是什么数值、此前怎么说的，本篇没交代。
- 0057「いまは……／owl先輩、と、お呼びすれば？」——“いまは”暗示以前另有称呼，本篇没说是什么。
- 0060 owl「去年私を負かした」是哪场比赛，本篇没写。
