# 亲爱度剧情（月村手毬） / 第27话（adv_dear_ttmr_027）

- 她的台词：9 行（含用匿名标签说的 0 行）
- 出场的人：手毬（37 行）、美鈴（17）、星南（9）、燐羽（2）
- 场景：手毬与極月学園的再战演出之后，休息室旁的走廊（燐羽说美鈴在控え室等）
- 世界线：亲爱度（月村手毬）；制作人在制作的偶像：手毬（制作人不在场，0033 手毬说“プロデューサーに追い詰められた”）

## 发生了什么
手毬被燐羽送走后，星南叫住她，称赞她与極月学園再战的演出“見事だった”，并为『H.I.F』那天手毬的歌驱散了自己的迷惘道谢。手毬说自己什么也没做，表示谢谢、并且宣布要把『一番星』变成自己的、用歌打倒星南。星南回应“かかってきなさい”，说会在顶点等她。之后手毬与美鈴的对话里星南不在场。剧情经过参照 ttmr、hmsz 笔记。

## 她的关键台词
- 0004「――――月村さん。」——在走廊叫住手毬
- 0006「見せてもらったわ、あなたのライブを。／極月学園との再戦を。」——说明自己看了手毬与極月学園的再战
- 0007「見事だった。」——直接而简短的称赞
- 0012「けれど、一言だけ伝えさせて頂戴。／――ありがとう。」——为叫住对方道歉，同时坚持要说一句谢谢
- 0014「『H.I.F』のあの日、あなたの歌は、／会場すべてを包み込んで……」——说起『H.I.F』当天手毬的歌的效果
- 0015「私の迷いを晴らしてくれた。／十王星南を、がむしゃらな挑戦者へと／戻してくれたわ。」——承认当时自己有迷惘，手毬让她回到“がむしゃらな挑戦者”
- 0020「かかってきなさい、／初星学園の黄金世代。」——手毬宣布要打倒她时，接下挑战，并用“黄金世代”称呼
- 0021「頂点で待っているわ！！」——以站在顶点的姿态等对手

## 行为模式
- 想表达感谢的时候 → 先为占用对方时间道歉，再坚持“只说一句”（0011、0012）
- 对手宣战 → 不退缩，用邀请式的命令句接下（0020、0021）
- 对对方的评价 → 具体指出对方做了什么（演出、歌包住会场）而不是泛泛夸奖（0006、0014）

## 关系
- 手毬：叫「月村さん」（0004）；手毬叫她「十王会長」（0005）
- 其他：这一篇里没有对美鈴或燐羽说话
