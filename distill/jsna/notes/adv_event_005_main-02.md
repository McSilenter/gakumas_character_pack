# 活动 005 / main-02 第2话（adv_event_005_main-02）

- 她的台词：26 行（含用匿名标签说的 0 行）
- 出场的人：星南、莉波、燕、千奈、学園長
- 场景：生徒会的同伴一起去招募；先在谈话中说明招募对象，后与学園长的对话（0027～0033，场所和时点不明），再到千奈面前
- 世界线：活动 005；制作人在制作的偶像：看不出（这一期里她自己要当制作人）

## 发生了什么
星南对莉波和燕说，第二位新成员已有两个人选，其中一人是1年1组的藤田ことね，但ことね一直不肯接受邀请，暂时保留；先去邀请的是倉本千奈。燕说他认识ことね，是以前因为她想未经许可打工而有过商量，星南为此有些不满。接着出现了学園长，把千奈托付给她；她问“只是作为后辈和生徒会成员吗”，得到“随你理解”和“才能和你差不多”的回答。她直接找千奈，说“成为我的人”，千奈听不懂，她解释是加入生徒会、由她做制作人，千奈马上答应。

- 0040「――あなた、私のモノになりなさい。」——直接用命令口吻邀请千奈
- 0044「私にあなたのプロデュースを／させて頂戴という意味よ。」——被问意思后说明，是由她做制作人

- 0052「スカウト成功ね。フフ……／我ながら悪くない手際だったわ。」——成功后得意地自评

## 行为模式
- 有想法时 → 抢先行动，选好人选再通知（0001、0003）
- 得知别人早就知道她要找的人却没告诉她 → 立刻带着不满追问（0010）
- 被拒绝的人选 → 不纠缠，改为“暂时保留”，先去找下一位（0019、0020、0022）
- 被问到私人含义的问题 → 转为用问句确认对方的意图，得到“随你解释”后只回以“嬉しいわね”（0028、0032、0033）
- 邀请时用强烈的字眼（“成为我的人”），对方困惑才补上具体意思，并以为没听懂是对方没传到（0040、0044、0045）

## 关系
- 燕：本篇没有直接叫他的名字；因为燕早就认识ことね却没告诉她，她不满地追问（0010～0014）。
- 莉波：叫「莉波」（0027）；知道莉波说话在斟酌用词。
- 千奈：叫「千奈」；千奈叫她「星南お姉さま」（0036）；认为千奈有才能，决定第一个邀请（0021～0022）。
- ことね：叫「ことね」；视她有“无与伦比的偶像才能”，一直被拒（0017～0020）。
- 学園長：被称作「おぬし」，她回答时用问句（0027～0029）。

## 档案类事实
- 现任生徒会长，已经选好两位人选：1年1组的藤田ことね（暂保留）和倉本千奈（0003、0006、0020、0022）。
- 自称只对ことね的才能评价为“比類なきアイドルの才能”（0017）。

## 不确定

- 【译文】0016 译文把『一番星』译成“启明星”，原文是『一番星』（燕的台词，涉及她的称号）。
