# 活动 005 / main-03 第3话（adv_event_005_main-03）

- 她的台词：39 行（含用匿名标签说的 0 行）
- 出场的人：星南、美鈴、燕、莉波
- 场景：千奈已加入生徒会之后（0001～0006），三人商量下一个招募对象，之后她当面招揽美鈴；地点剧本没写
- 世界线：活动 005；制作人在制作的偶像：看不出（这一期里她自己当制作人，美鈴 0058 说"让星南会長プロデュース"）

## 发生了什么
她问燕和莉波有没有看到自己的制作人表现，燕说因为说明太少，千奈根本没听懂，莉波说招募成功了就是好的开始。她接着说下一个要从原『SyngUp!』里选，燕、莉波、她三人逐个排除：手毬才能出色但不是她；燐羽有固定粉丝，但很难培养成后继者；她选的是美鈴，理由是实力、潜力极高，又是组合里唯一看起来素行良好的。她当面对美鈴说"决定是你了""让你成为我的东西"，美鈴听不懂，她改说"希望你加入生徒会"，美鈴说"好麻烦的邀请"，她再说"引导你到顶点"，最后美鈴理解后答应入会，她表示又一次招募成功。

## 行为模式
- 招募成功 → 马上向同伴要评价，并立刻推进下一个（0002、0008、0071、0072）
- 同伴指出问题（说明不足、选人的理由） → 不辩解，不直接回应说明不足，而是直接继续讲自己的判断依据（0003～0011、0020～0023）
- 评价被她看重的人 → 同时给出才能和问题，不把问题当作决定因素（0022、0023、0025）
- 当面招募 → 先抛出"决定是你了"这种抽象的话，对方听不懂后才改成具体的话，再次听不懂就补上目的（0042～0054）
- 对方沉默后同意 → 平静接受并道谢，然后自夸（0067、0070～0072）

## 关系
- 燕：叫「燕」（本篇没有直接称呼）；与燕商量选人，对她的追问（0024、0028）都直接回答。
- 莉波：回应她的"会長"（0006）。
- 美鈴：叫「美鈴」（0042、0048、0067）；让她叫自己「星南」（0048），美鈴实际叫她「星南会長」；认为她实力和潜力极高（0040）。
- 手毬、燐羽：评价手毬为"素晴らしい才能の持ち主"但不选，燐羽"难培养"（0029～0034）。

## 档案类事实
- 自称对『SyngUp!』"仅次于当事人"的了解（0021）。
- 这一期里的生徒会规模："最多也就再增加几个人"（0064）。
- 她说过，招募的对象叫"後継者候補"，目标是『一番星』的接班人（0011）。
