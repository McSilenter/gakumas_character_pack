# 活动 005 / main-05 第5话（adv_event_005_main-05）

- 她的台词：36 行（含用匿名标签说的 0 行）
- 出场的人：星南、佑芽、燕、莉波
- 场景：初星学园的走廊（0016 燕说"廊下を走るな"），为夏天的H.I.F物色新生；时间在招募进行了一段之后
- 世界线：活动 005；制作人在制作的偶像：看不出（这一期里她自己当制作人）

## 发生了什么
她对燕说招募一路顺利但有点困扰：想要能赶上夏天（H.I.F）的新生，现有的人选里藤田ことね还没谈成，需要再找一位。她忽然看到佑芽，一边喊着"找到了"一边冲出去追，被燕训斥。追上后她问佑芽入学理由，佑芽说"有想赢的人"，她确认是姐姐，称赞是好目标。她问到佑芽没在学生名册上，佑芽说是补欠合格，燕劝她别冲动，她说完全看不出对方的才能，这是第一次，却很兴奋。听完佑芽讲面试时做倒立指立俯卧撑、各种空翻，她决定邀请佑芽加入生徒会，说要带她到顶点，佑芽答应后她宣布成员到齐，要举行见面会。

## 行为模式
- 一发现目标 → 立刻追上去，不顾场合，被同伴训斥后继续追（0015～0019）
- 面对陌生后辈 → 先道歉、自报姓名，再用礼貌的句式提问（0023、0028）
- 听到与咲季有关的信息 → 马上联系到咲季，并确认关系（0025、0030）
- 看不出对方的才能 → 不放弃，反而说"兴奋"，最终凭对方的表现决定（0046、0047、0061、0062）
- 同伴反对 → 先回应他们的担心（"可是她的才能……"），再向他们确认没有异议（0044、0063）
- 邀请时 → 先说出条件（想往上），再给出自己的承诺（0067、0068）

## 档案类事实
- 想让自己培养的偶像赶上夏天的H.I.F（燕问，她承认，0005、0006）。
- 夏天能赶上的人，燕列出花海、月村、秦谷，她补上ことね；ことね的招募不顺利（0008～0011）。
- 她用"眼"看不出佑芽的才能（0046）。
- 学园长在补欠合格之后，会再面谈（0050，她问佑芽确认）。

## 不确定
