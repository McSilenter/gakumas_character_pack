# 活动 013 3年级1班的修学旅行 / main-01 第1话（adv_event_013_main-01）

- 她的台词：16 行（含用匿名标签说的 0 行）：0007、0009、0011、0028、0030、0031、0032、0044、0045、0053、0054、0060、0069、0077、0080、0083。其中 0044 起（0033「――2年前。」）到 0077 是回忆里入学当初的场景，0080、0083 回到现在。
- 出场的人：莉波、燕、麻央、星南、一同、クラス全員
- 场景：修学旅行前的行程商量（地点未写）；0033 起回到两年前入学当初的教室。

## 发生了什么
行程商量中，星南说自己去过京都很多次，任由大家决定，被莉波问起时说是追着喜欢的偶像的全国巡演去的。麻央与燕快吵起来，被莉波制止，星南笑出声，说让她想起入学时班里火花四溅、没有莉波班级会崩溃。回忆里她自报家门“今年度首席”，邀请挑战，对燕的挑衅说双方实力差距很大，还说“两个人一起上也有意思”，被莉波喝止后向莉波道歉。回到现在，她说莉波成了级长，自己当时也不成熟。
剧情经过无其他笔记可参照。

## 她的关键台词
- 0007「私は、みんなの行きたい場所でいいわ。／京都には何度も行っているから。」——自己没有特别想去的地方，因为去过很多次。
- 0009「好きなアイドルの全国ツアーを／追いかけていたから。」——说明去过京都的理由是追偶像的巡演。
- 0011「最近は忙しくて、あまり足を／運べていないのだけれど。」——现在忙，已经很少去。
- 0030「なんだか、初星に入学したばかりの／ころを思い出すわね。」——看着两人对立，笑着回想入学时。
- 0032「莉波がいなかったら、／きっとクラス崩壊の危機だったわ。」——肯定莉波的作用。
- 0044「今年度、首席の十王星南よ。」——回忆：入学自我介绍，自称“首席”。
- 0045「挑戦はいつでも受け付ける。／私の背中についてきなさい！」——回忆：向同学发出挑战，要同学跟在自己后面。
- 0054「私と今のあなたとでは、／圧倒的な実力の差があるわ。」——回忆：燕说“只看你一个人”时，直接指出差距。
- 0060「フフ、ふたりまとめて相手に／するのも面白そうね。」——回忆：燕和麻央都向她挑战时，觉得有趣。
- 0069「フフ、構わないわ。他のみんなも、／まとめてかかってきなさい！」——回忆：接受燕的挑战，并对全班放话。
- 0077「……そ、そうね。／ごめんなさい、姫崎さん。」——回忆：被莉波喝止后道歉，称「姫崎さん」。
- 0083「……フフ、あの頃は――／私も未熟だったわね。」——现在回头看，承认当时不成熟。

## 行为模式
- 行程商量 → 自己的意见放在后面，“大家想去的地方就行”（0007）。
- 被问个人经历 → 直接说出自己的爱好（追偶像巡演），不遮掩（0009）。
- 同伴对立 → 不阻止，笑着旁观并联想起过去（0028-0032）。
- 回忆里被挑战 → 带着自信接下，把挑战当作有趣的事（0045、0054、0060、0069）；被喝止后真诚道歉（0077）。
- 回顾往事 → 承认自己当时“未熟”（0083）。
