# 活动 013 3年级1班的修学旅行 / main-02 第2话（adv_event_013_main-02）

- 她的台词：14 行（含用匿名标签说的 0 行）：0002、0006、0027、0039、0041、0042、0043、0045、0046、0055、0058、0062、0070、0072
- 出场的人：莉波、麻央、星南、燕、旅行客
- 场景：修学旅行第一天，京都；壬生寺之后是历史资料馆，然后茶道体验，之后遇雨。
- 世界线：活动 013；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
到京都后，星南说这里无论来多少次都是好地方，看着平时少见地兴奋的燕笑了。参观后她问下一站是不是茶道体验。茶道上，她用优雅的举止喝茶，被莉波夸，她说自己学过一点，并说茶道的待客之心与偶像相通：用心让眼前的客人快乐，在舞台上献上最好的表现。下雨时她担心麻央的冲动，劝他别去，之后提议提前回旅馆，说这样的麻烦和大家一起也很开心。
剧情经过无其他笔记可参照。

## 她的关键台词
- 0002「ええ、何度足を運んでも、／いい場所ね。」——对京都的感想，呼应上一话说自己去过很多次。
- 0006「フフ、燕ってば、／いつになくはしゃいでいるわね。」——看到燕兴奋，带着笑意说出来。
- 0027「フフ、すっかり堪能したわね。／次は……茶道の体験コース？」——总结前面的参观，确认下一站。
- 0039「美味しく頂戴いたしました。」——喝完茶后的正式致谢。
- 0041「ありがとう。茶道は少しだけ、／嗜んでいたの。」——被夸所作漂亮，说自己学过一点。
- 0042「目の前のお客さんに楽しんで／もらえるように心を尽くす。」——说茶道的精神。
- 0043「茶道のおもてなしの心は、／アイドルに通じるところもあるわね。」——把茶道和偶像联系起来。
- 0045「そうね。ステージの上で、／最高のパフォーマンスを届ける。」——附和燕的“茶室是舞台”，补充偶像一侧。
- 0046「それが、アイドルと茶道に／共通する精神よ。」——总结共通精神。
- 0058「盆地だから、天気も／変わりやすいのかしら。」——下雨时冷静地分析。
- 0062「風も強いし、やめたほうが――」——麻央要去买伞，劝阻，话说一半。
- 0070「……これは、予定を切り上げて、／旅館に戻ったほうがよさそうね。」——判断后提议回旅馆。
- 0072「フフ、こんなトラブルも、／みんなと一緒だと、楽しいわね。」——对遇雨的意外，当作快乐的事。

## 行为模式
- 同伴兴奋 → 在一旁笑着观察并说出来（0006）。
- 被夸 → 说“学过一点”，随即把话引到更大的想法（茶道与偶像）（0041-0046）。
- 同伴冲动 → 先劝阻，劝阻无效后冷静收场（0062、0070）。
- 突发的麻烦 → 做出决定（取消行程回旅馆），然后说“和大家一起很开心”（0070、0072）。
