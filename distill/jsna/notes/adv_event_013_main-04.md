# 活动 013 3年级1班的修学旅行 / main-04 第4话（adv_event_013_main-04）

- 她的台词：19 行（含用匿名标签说的 0 行）。其中 0032～0057 共 15 行（0032、0035、0038、0039、0040、0041、0042、0043、0045、0047、0052、0053、0054、0056、0057）是麻央回忆里的场景（去年『H.I.F』结束后）；0066、0068、0074、0075 是现在的场景
- 出场的人：星南、麻央、燕、莉波（学園長 0029 只在回忆里出现；一同 0028 不计）
- 场景：现在是修学旅行的夜晚，星南在外面接电话，其他人在宿舍讲怪谈；她的大部分台词出自麻央讲的去年『H.I.F』之后的回忆，她当时刚被宣布为『一番星』
- 世界线：活动 013；制作人在制作的偶像：看不出

## 发生了什么
麻央讲的回忆里，星南刚成为『一番星』，面对向她道贺的麻央，说自己高兴，却感到重压，并说“让人持续憧憬比成为『一番星』更难”。她问麻央从小憧憬的人是否仍在闪耀，听到对方已不再当明星后，说站在顶端的人光芒太耀眼，有时反而让人看不见星辰本身，并问麻央（称「王子様」）是否会追上来。现在的场景里，她打完电话回来，问大家聊了什么，听到燕说在讲要在『H.I.F』击败她，沉默了一下后说「とても楽しみね」。

## 她的关键台词
- 0035「……ありがとう、麻央。」——回忆里对麻央的道贺，语气低沉（回忆中）
- 0039「嬉しいわ、もちろん。」——被指出不太高兴时，先肯定“当然高兴”（回忆中）
- 0040「幼い頃から憧れた、『一番星』に、／ようやくなれたんだもの。」——说出从小憧憬『一番星』并达成（回忆中）
- 0041「でも……そうね。／重圧は感じるわ。」——转折，承认感到重压（回忆中）
- 0042「私は誰もが憧れる、完璧な／アイドルでいなければならない。」——对自己的要求：必须是完美的、被所有人憧憬的偶像（回忆中）
- 0043「憧れで在り続けることは、『一番星』に／なるよりずっと難しい。」——成为『一番星』之后，更难的是持续成为憧憬（回忆中）
- 0054「だけど、眩い光は、ときに、／星そのものを見えなくしてしまう。」——站在顶端的人，光芒太耀眼，反而让人看不见星辰本身（回忆中）
- 0057「王子様。あなたは――／追いかけてきてくれる？」——向麻央（称「王子様」）发出追赶她的请求（回忆中）
- 0066「お待たせ。ごめんなさい、／電話が長引いてしまって……」——现在的场景，礼貌地道歉
- 0075「フフ、それはとても楽しみね。」——听到燕的“击败”宣言，沉默后（0074）笑着说期待

## 行为模式
- 被道贺却被指出不太高兴时 → 先肯定“当然高兴”，再说出重压（0039、0041）
- 谈到自己的位置 → 用“～なければならない”表述对自己的要求（0042、0053）
- 被问对方的憧憬之人时 → 问对方“那个人现在还在闪耀吗”，听到答案后把话题延伸到自己（0047、0052～0056）
- 想要对方来追自己 → 不直接说“来追我”，用「王子様」和疑问句「追いかけてきてくれる？」表达（0056、0057）
- 听到有人要击败自己 → 先沉默，再笑着说期待（0074、0075）
