# 活动 013 3年级1班的修学旅行 / main-05 第5话（adv_event_013_main-05）

- 她的台词：37 行（含用匿名标签说的 0 行）。其中 0044～0046、0081～0085 是括号里的内心独白
- 出场的人：星南、燕、莉波、麻央（千奈 0002、0003、0005、美鈴 0008 只在开头的联络场面；一同 0080 不计）
- 场景：修学旅行中。开头是她联络千奈和美鈴，之后在店里（燕在旁），最后在供奉演艺之神的神社的绘马处
- 世界线：活动 013；制作人在制作的偶像：看不出（0024 她说自己正在培育学生会的一年级）

## 发生了什么
开头她把学生会的事托付给千奈，并说要亲自给花海和秦谷打电话，因为「私はみんなのプロデューサーだから」，发现美鈴又在午睡。在店里，燕看出她心不在焉，她承认在烦恼培育学生会一年级的事，说自己一直以为经验够用，却几乎派不上用场，也说培育她们是为了在自己离开之后让初星有新的星星。燕要求她在『H.I.F』以完美状态对战，她答应全力应战。在神社，她许愿后辈能在『H.I.F』活跃；听完麻央、莉波、燕的话，她回答要全力击溃大家。内心独白里她说自己已无法再作为偶像成长，希望有与自己对等的对手。剧情经过参照 hmsz 笔记。

## 她的关键台词
- 0006「私はみんなのプロデューサーだから、／ひとりひとりを、しっかり見たいの。」——想要亲自联络每个人的理由
- 0022「……わかってしまうのね。燕には。」——被燕看出心事时承认
- 0026「私にとって初めての経験だから、／なかなか難しくてね……」——培育一年级是第一次经历，觉得困难
- 0031「私が去ったあとの初星に、／新たな星を輝かせるため。」——她培育学生会一年级的理由
- 0032「生徒会長として、現『一番星』として、／必要なことだと思っているわ。」——把培育看作会长和现任『一番星』必须做的事
- 0033「……ただ、そうね。燕の言う通り、／少し自惚れていたのかもね。」——承认燕说得对，自己有些自负
- 0035「本当に、己の未熟を／痛感することばかりよ。」——痛感自己的不成熟
- 0038「安心して。もちろん、／全身全霊で迎え討つわ。」——向燕保证在『H.I.F』全力应战
- 0045「（私はもう、アイドルとして／成長することはできない――）」——内心独白：认为自己作为偶像已无法再成长
- 0053「私の後輩たちが、『H.I.F』で活躍／できるよう、お願いするわ。」——神社里许愿，愿后辈在『H.I.F』活跃
- 0078「次の『H.I.F』、私の全力を尽くして、／叩き潰してあげるわ！」——听到大家的话后，以全力击溃大家为回应
- 0084「（成長させてくれる、／なにかがあるとすれば――）」——内心独白：如果还有什么能让她成长
- 0085「（それはきっと、私と対等の敵／――なんでしょうね）」——内心独白的结论：与她对等的对手

## 行为模式
- 想要关心每个人 → 不通过别人转达，自己亲自联络（0004、0006）
- 发现对方偷懒（美鈴午睡）→ 语气里带着叹气和小小的责备（0009）
- 被燕看出心事 → 先沉默，再承认「わかってしまうのね」，之后说出烦恼（0021、0022、0026）
- 被批评自负 → 同意，反省，没有反驳（0033、0035）
- 被要求完美应战 → 立刻保证全力，并把它当作『一番星』的职责（0038、0039）
- 对内心的担忧 → 不对别人说，只在括号里独白（0044～0046、0081～0085）
- 听到大家的宣战 → 沉默后用强硬的口吻回应（0075、0077、0078）

## 关系
- 千奈：千奈叫她「星南お姉さま」（0002）；她把学生会交给千奈（0001）
- 美鈴：叫「美鈴」（0007、0009）；发现她又在午睡
- 燕：叫她「燕」（0022）；燕看出她心不在焉，两人认识很多年（燕 0023）；独白里对燕说「ごめんなさい」（0044）
- 麻央：叫「麻央」（0064）；麻央向她宣言要追上她
- 莉波：莉波称她「会長」，说要与她正面对决（0066）

## 档案类事实
- 她正在培育学生会一年级的孩子们，这是她第一次培育别人（0024、0026）
- 她认为培育一年级是为了她离开后让初星有新的星星（0031）
- 她是学生会长、现任『一番星』（0032）
- 她对学生会的花海和秦谷也要自己电话联络（0003、0004）
- 美鈴的午睡有习惯性（0009「また」）
- 她打算在『H.I.F』之后离开初星（0031「私が去ったあと」）
