# 活动 017 / 第1话（adv_event_017_main-01）

- 她的台词：10 行（含用匿名标签说的 0 行）
- 出场的人：莉波、星南、燕、麻央（ダンストレーナー 0015）
- 场景：舞蹈课的场所，莉波向大家提出拍3年级PV的请求；星南在 0029 起出场
- 世界线：活动 017；制作人在制作的偶像：看不出

## 发生了什么
莉波提出想请大家协助拍广报部后辈托的PV，主题是3年级的“日常”。星南解释这是给新生看的学园宣传短片，去年也拍过，关注度高，并说自己当然协助，希望未来的考生了解初星的好处。燕说“偶像没有日常”，星南承认燕说得对：对她来说偶像和日常分不开，拍她的日常可能不有趣。莉波说她知道会长偶尔露出淘气的一面，星南吃惊。

## 她的关键台词
- 0029「新入生向けに、初星学園を／アピールするPR動画ね。」——很快理解PV的目的
- 0030「去年も作っていたけれど、／けっこう注目度の高いPVよ。」——补充去年也有，注目度高
- 0037「あくまで、初星学園の生徒が、／普段どう過ごしているかを／見せたいのだと思うわ。」——解释PV想表现的内容
- 0039「私も、もちろん協力するわ。」——表明协助
- 0040「未来の受験生に、初星のいいところを／知ってもらいたいもの。」——协助的理由：让未来的考生了解学园
- 0048「……でも、たしかに、／燕の言う通りかもしれないわね。」——认可燕的话
- 0049「私にとって、アイドルであることは、／日常と切り離せないものだから、」——说明为什么认同
- 0050「普段の私を撮っても、／あまり面白くないかもしれないわ。」——担心自己的日常不有趣
- 0054「……？」——听到莉波说“我知道”时的疑惑
- 0056「お、お茶目？　私が……？」——听到被说“淘气”时的吃惊

## 行为模式
- 听到企划 → 马上说出企划的目的与背景，补充去年的情况（0029、0030）
- 被问是否协助 → 立即说“当然”，并给出理由（0039、0040）
- 被燕反驳时 → 先承认“或许燕说得对”，再解释原因（0048～0050）
- 被说有“淘气”的一面 → 吃惊并反问（0054、0056）

## 关系
- 莉波：莉波称她「星南会長」；本篇里她没有直接叫莉波
- 燕：叫她「燕」（0048），认可她的意见
- 麻央：本篇里没有直接称呼

## 档案类事实
- 星南说去年也拍过新生向PV（0030）
- 星南认为对她来说偶像与日常分不开（0049）

## 不确定

- 0048 的“燕の言う通り”指燕 0042「アイドルは常在戦場――／ゆえに日常など存在しない。」
