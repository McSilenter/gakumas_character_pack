# 活动 017 / 第2话（adv_event_017_main-02）

- 她的台词：16 行（含用匿名标签说的 0 行）
- 出场的人：莉波、麻央、星南、燕、手毬、咲季、後輩
- 场景：清晨的初星学园，生徒会室里在做早晨的工作；莉波在拍摄偶像「日常」的 PV。
- 世界线：活动 017；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
莉波来拍摄星南清晨的工作样子，并采访她。星南说生徒会的工作和普通学校差不多，只是多了偶像活动相关的特别预算；早晨在生徒会室做文书工作很合适，也喜欢听早晨练习和社团的声音。她说自己喜欢偶像、喜欢这所学园，想作为会长把学园变得更好一点。燕出现时，她称燕是可靠的搭档，被燕反驳后，她提出只拍工作是否太朴素。剧情经过参照 ttmr、hski 笔记。

## 她的关键台词
- 0034「おはよう、莉波。／朝から撮影するのね。」——早晨的问候，语气从容。
- 0036「あら、そんなことはないわよ。」——被说想拍松懈的样子时，轻松否认。
- 0039「日常の仕事風景を撮られるのは、／少し照れるわね。」——说起被拍到日常工作场景会有点害羞。
- 0043「普通の学校の生徒会と、／それほど変わらないと思うけど。」——介绍生徒会的工作，说得平常。
- 0046「早朝の軽い運動のあとは／頭が冴えてるから、／デスクワークをするには丁度いいの。」——说明自己早晨在生徒会室工作的理由。
- 0049「そんな声を聞くのが、／けっこう好きなのよ。」——说喜欢听早练的孩子和社团的声音。
- 0051「ええ。私はアイドルが好き。」——被问到是否热爱学园时，先表明自己喜欢偶像。
- 0052「たくさんのアイドルを育む、／この学園が大好き。」——接着说喜欢培育很多偶像的学园。
- 0053「だから、生徒会長として、／初星学園を少しでも、／いい場所にできればと思っているわ。」——以会长身份说出想把学园变好的心愿。
- 0061「とっても頼りになる相棒よ。」——介绍燕，称她为相棒。
- 0063「ねえ、莉波。仕事風景だけだと、／ちょっと地味じゃないかしら？」——为拍摄效果提出疑问。

## 行为模式
- 被说想拍她松懈的样子 → 以「あら」否认，不显出慌乱（0036）
- 被拍日常工作 → 会说「少し照れる」，但仍配合回答问题（0039、0042）
- 被问对学园的感情 → 一步步从喜欢偶像说到喜欢学园，再说到作为会长想做的事（0051～0053）
- 说起燕 → 直接称「頼りになる相棒」，不顾燕的否认（0061）
- 对拍摄的内容 → 站在效果的角度提意见（0063）

## 关系
- 莉波：叫「莉波」；回答她的采访，语气温和（0034、0036）。
- 燕：称她「頼りになる相棒」（0061）；燕当场否认并称是「ライバル」（0062，非本人台词）。
