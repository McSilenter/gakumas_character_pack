# 活动 017 / 第3话（adv_event_017_main-03）

- 她的台词：36 行（含用匿名标签说的 0 行）
- 出场的人：星南、莉波、麻央、燕、ことね
- 场景：休息日；莉波拍摄偶像日常『休日編』，四人先逛偶像周边店，午饭去ことね打工的汉堡店。
- 世界线：活动 017；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
莉波约星南、麻央、燕在休息日一起玩，星南说好久没有大家一起出来，想当作回到一年级尽情玩。逛完偶像周边店后（星南买了很多推しのグッズ），午饭她提议去「ことねバーガー」，其实是ことね打工的汉堡店；她点了菜单上写着0元的 Happy Wink，被麻央替她点了套餐带过去。吃汉堡时嘴角沾了酱汁被燕指出，她被调侃后说放学后和大家一起去快餐店曾是小小的梦想，并说像这样闲聊的时间或许所剩不多，最后向莉波道谢。

## 她的关键台词
- 0009「今日は1年生に戻ったつもりで、／めいっぱい遊びましょう。」——想把今天当作回到一年级尽情玩。
- 0011「推しのグッズ、／たくさん買ってしまったわ。」——承认在偶像周边店买了很多自己「推し」的东西。
- 0016「ちゃんと、初星学園公認のグッズよ！」——自己的纪念照片也是学园认证的商品，说得有点得意。
- 0025「ことねバーガーよ！」——说出想去的店，其实是ことね打工的汉堡店。
- 0026「初めてお店のハンバーガーを食べてね、／すっごく、美味しかったの！」——说起第一次吃店里汉堡的感想。
- 0040「この、ハッピーウインクをひとつ、／頂けるかしら？」——在柜台点菜单上的 Happy Wink。
- 0054「た、食べ慣れていないのよ……／しょうがないじゃない？」——吃汉堡沾了酱汁被调侃，辩解说不习惯。
- 0059「放課後とかに、みんなで／ファーストフードのお店に寄るの、／ちょっとした夢だったのよ。」——说出一个小小的梦想：放学后和大家去快餐店。
- 0061「もう、あまり残されて／いないのかもしれない。」——说像这样闲聊的时间或许已经所剩不多。
- 0066「でも、アイドルが歌うのは、／普通の人の気持ち。」——说偶像歌唱的是普通人的心情。
- 0067「それを忘れてしまっては、ファンの方の／共感を得ることはできないわ。」——忘记这点就无法得到粉丝的共鸣。

## 行为模式
- 想去自己想去的店 → 先用「……あの、みんなで行きたいお店が／あるのだけど……いいかしら？」征求大家同意，再说出店名（0021、0025）
- 被指出「ことねバーガーなんてお店はない」 → 没有辩解，转而说「あそこよ、早く行きましょう！」催大家走（0029）
- 在店里被ことね的反应和上次不同 → 说「反応が違う気がするわ」（0034）
- 被指出失态、被调侃 → 先说「ハッ、私としたことが」，再说「しょうがないじゃない？」，接着说「からかわないで」（0052、0054、0057）
- 被调侃后 → 转而说起「ちょっとした夢だった」，由玩笑转到对时间有限的感慨（0058～0061）

## 关系
- 莉波：叫「莉波」；最后感谢她安排这一天（0008、0069、0070）。
- 麻央：麻央替她点餐、带她去座位（0044、0046）；她在被带走时还想点 Happy Wink（0047）。
- 燕：燕提醒她嘴角有酱汁（0051）；燕提到买太多周边（0013）。
- ことね：叫「ことね」；说「あら、奇遇ね」（0031）；ことね提到她上次点了30个汉堡（0035）。

## 档案类事实
- 去年获得『一番星』，有纪念ブロマイド，是学园认证的商品（0015、0016）。
- 买了很多「推し」的周边（0011）。
- 以前来过ことね打工的店吃过汉堡，上次点了30个（0026、0035 是ことね的话）。
- 第一次吃照烧味汉堡（0050）。
- 不习惯吃汉堡（0054）。
- 放学后和大家去快餐店曾是她的小小梦想（0059）。
- 一年级的时候四人曾一起去看前辈们的演唱会（0005）。
