# 活动 017 / 第4话（adv_event_017_main-04）

- 她的台词：27 行（含用匿名标签说的 0 行）
- 出场的人：星南、麻央、莉波、燕
- 场景：休息日，天川市的游乐园；三年级四人玩旋转木马、过山车，傍晚是两人组的僵尸主题解谜游戏，她与麻央一组。
- 世界线：活动 017；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
四人到游乐园。星南说学园常在这里办活动和演出，坐旋转木马时说比老家的马小，应下燕比速度的挑战，坐完过山车说好玩。解谜游戏她与麻央一组，两人单独相处时，她说起很少和麻央单独玩，说自己必须是大家的「一番星」、是偶像的模范，却不觉得窘迫，今天却忘了完美的自己、毫无顾虑地玩耍。麻央给她建议后，她道谢。

## 她的关键台词
- 0003「イベントやライブなんかで、／よくお世話になるわね。」——说学园常在这个游乐园办活动和演出。
- 0013「実家の馬より、少し小さいのね。／どれにしようかしら……」——看旋转木马的马，拿老家的马作比较。
- 0015「フフ、負けないわよ。」——应下燕的比赛挑战。
- 0021「んー、ジェットコースター、／楽しかったわね！」——坐完过山车后的感想。
- 0028「夕方から、遊園地の敷地を使った、／謎解きゲームがあるそうよ。」——提出傍晚的解谜游戏。
- 0035「よろしく、麻央。／頼りにしているわ。」——分组后对麻央说话。
- 0057「麻央とふたりで遊ぶことって、／あんまりなかったわね。」——对麻央说起很少两人单独玩。
- 0059「――楽しいわね。」——说出当下的心情。
- 0062「私はみんなの『一番星』だから――／アイドルの模範でなければならない。」——说明自己对自身立场的看法。
- 0064「でも、それが窮屈とは思わない。」——紧接着否认觉得束缚。
- 0065「アイドルは私の人生のすべて、／そのことに誇りを持っているわ。」——表明对偶像的态度。
- 0069「完璧な十王星南であることを忘れて、／無邪気に楽しんでる私がいる。」——说今天忘了完美的自己，玩得毫无顾虑。
- 0070「私を慕ってくれる後輩たちの前では、／絶対に見せられない姿ね。」——说这样的样子不能让后辈看到。

## 行为模式
- 被燕提出比赛 → 笑着应战（0014、0015）
- 面对游戏的项目 → 先从场地的情报、分组等方面给出提议（0028、0040、0045、0049）
- 两人单独时 → 用「そういえば」引出很少两人单独玩，然后慢慢说出自己的想法（0056～0070）
- 说自己的立场 → 先说必须是模范，再马上补一句不觉得窘迫，最后说出今天不是完美的自己（0062、0064、0069）
- 被建议 → 简短地说「ありがとう」（0080）

## 关系
- 麻央：叫「麻央」；说她「麻央が、王子様であることを／貫こうとしているように。」（0066）；这次与她单独玩觉得开心（0057、0059）。
- 莉波：莉波叫她「星南会長」（0022）；星南和燕、莉波一起行动。
- 燕：燕提出比速度，她应战（0014、0015）。

## 档案类事实
- 学园的学生常在这个游乐园办活动、演出（0003）。
- 老家有马（0013）。
- 自己的人生全部是偶像，并以此为荣（0065）。
- 说自己要在舞台上、作为生徒会长、私人生活中都是「模範」（0062、0063）。
- 称麻央贯彻着「王子様」（0066）。
