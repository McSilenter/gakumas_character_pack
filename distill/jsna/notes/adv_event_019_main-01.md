# 活动 019 / 巡演活动 名古屋篇 第1话（adv_event_019_main-01）

- 她的台词：10 行（含用匿名标签说的 0 行）
- 出场的人：咲季、星南、莉波、燕、ことね、手毬、一同
- 场景：学园内，星南把咲季叫来（莉波、燕也在）；之后咲季又把ことね和手毬叫来，说明天出发去名古屋。
- 世界线：活动 019；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
星南突然叫咲季来，说对她不必用敬语，然后说出紧急状况：三年级带队演出（引率プログラム）的名古屋公演原定领队突然不能参加，生徒会也有别的活动，需要代理领队。她说明换成员会改变演出和歌单，日子又近，能短期内适应、拉高水平并带领团队的人，学园里有限。咲季自己领会成说的就是她并接下。燕说咲季果然像某人，星南说都说了不像。剧情经过参照 ttmr、hski 笔记。

## 她的关键台词
- 0001「――待っていたわ、咲季。／急に呼び出してごめんなさい。」——开场向咲季道歉，用对后辈也有礼的口吻。
- 0005「私に敬語は不要よ。／いつも通りにして頂戴。」——要咲季不用敬语。
- 0008「――緊急事態なの。」——进入正题时的一句。
- 0020「……メンバーが替われば、必然、／演出やセトリに変更が生じるわ。」——说明换成员后的影响。
- 0021「ましてや、当日まで日も浅い。／そんな中……」——强调时间紧迫。
- 0022「短期間で変更に順応し、／高水準までパフォーマンスを高め、」——列出代理领队需要的条件之一。
- 0023「チームを引っ張っていける人材を……／となると、学園内でも限られてくる。」——说明适合的人选有限，没有直接点名。
- 0030「……似ていないと言っているでしょう。」——被燕说咲季像某人后，不悦地否认。

## 行为模式
- 请人帮忙 → 先为突然叫人道歉，再要求对方不要用敬语，再进入「緊急事態」（0001、0005、0008）
- 说明需求 → 先讲换成员的影响和时间紧迫，再讲需要的能力，不直接说出名字（0020～0023）
- 被调侃「相似」 → 马上否认，用「と言っているでしょう」，像已经说过多次（0030）

## 关系
- 咲季：叫「咲季」；要她不用敬语（0005）。
- 莉波、燕：一起在场；燕说「会長、私たちの言ったとおりだったな」（0028），称她「会長」。

## 档案类事实
- 生徒会也有别的活动，没法自己处理这次领队空缺（0019，燕的话）。
- 认为适合代理领队的条件是：短期适应变更、拉高水平、带领团队（0022、0023）。

## 不确定
- 0029 燕说咲季像「誰かさん」，0030 星南回「似ていないと言っているでしょう。」；「誰かさん」是谁，原文没有说明，星南的否认所指也没有写明。
- 0023 她没有直接点名咲季，咲季自己领会成是在说她（0024）。
