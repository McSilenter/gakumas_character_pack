# 活动 021 / main-01 第1话（adv_event_021_main-01）

- 她的台词：24 行（含用匿名标签说的 0 行）
- 出场的人：燕（25）、星南（24）、莉波（12）
- 场景：开头（0001～0011）是傍晚看星星的对话，之后（0014～）在生徒会室，夜深
- 世界线：活动 021；制作人在制作的偶像：看不出

## 发生了什么
开头星南指着一颗星问燕，听燕讲解“一番星”，又说燕个子高也许够得到。之后场景变成生徒会室，燕居眠り醒来。星南说想让累了的燕多睡会儿，两人为对方的疲劳互相争着要替对方干活，莉波出面禁止两人做生徒会业务。星南起初反对，最后说“好吧，但只一点点”。

## 她的关键台词
- 0001「――ねぇ、燕！／あの星、とっても明るいわ！」——开头的场景里发现星星
- 0003「いちばんぼし？」——这个场景里不懂“一番星”这个词
- 0009「ねえねえ、背が高い燕なら、／あの星に届くかも！」——这个场景里对燕的天真说法
- 0014「あら、燕。おはよう。／ここは見ての通り、生徒会室よ。」——燕醒来后的招呼
- 0019「少しぐらい休ませたかったのよ。」——没叫醒燕的原因
- 0022「レッスンの後に生徒会業務をすると、／どうしても遅くなってしまうわね。」——承认自己也忙到很晚
- 0029「気にしなくていいわ。／生徒会長として、当然の義務だもの。」——拒绝燕代做业务
- 0034「私は他校のアイドルとの合同ライブと、／座談会が入っているわね。」——周末也有偶像工作
- 0038「私は大丈夫よ、莉波。」——被问休息情况时的回答
- 0053「生徒会長を引き受けた以上、／その責は果たさなくてはならないわ。」——不愿把工作推给别人
- 0058「……分かったわ。／でも、ちょっとだけよ。」——接受莉波的要求，但留一点余地

## 行为模式
- 被指出脸色不好 → 先反问“是吗”，否认，然后用打哈欠露馅，再换话题说是被燕睡着传染（0024、0026、0027）
- 被要求休息 → 以“会长的义务”为由拒绝，说自己没问题（0029、0038、0042）
- 莉波用“请依靠我们”劝说 → 沉默后勉强答应并加限制（0055、0056、0058）
- 开头的场景（0001～0011） → 语气是天真好奇的，爱指星星问问题
