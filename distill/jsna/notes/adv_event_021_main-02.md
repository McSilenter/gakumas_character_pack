# 活动 021 / main-02 第2话（adv_event_021_main-02）

- 她的台词：28 行（含用匿名标签说的 0 行）
- 出场的人：燕（29）、星南（28）、ダンストレーナー（2）
- 场景：生徒会业务和レッスン被禁止的一周；学园内，之后在咖啡馆
- 世界线：活动 021；制作人在制作的偶像：看不出

## 发生了什么
燕发现自己和星南被生徒会下令这周不能做レッスン。星南对莉波接管生徒会不担心，邀请无事可做的燕去咖啡馆。两人聊起咖啡，星南说燕小时候就能喝黑咖啡，两人互相翻对方小时候的丑事。后来她提议去燕家玩，燕答应，说想“看那个”，星南很高兴。

- 0011「そうね。こんなにスケジュールが／空くなんていつ以来かしら。」——难得的空闲
- 0016「莉波に任せると決めた以上、／心配はしないことにしているの。」——信任莉波
- 0017「困った時はちゃんと私たちを頼ると／言っていたでしょう？」——引用莉波的话说明信任

## 行为模式
- 被揭小时候哭鼻子 → 否认“没哭，只是涙目”，被追击就拿燕的旧事反击（0034、0037、0040、0044）
- 争到不利时 → 自己出面说“不要再吵了”收场（0051）
- 对忙碌之外难得的空闲 → 高兴，提议去咖啡馆或燕家（0011、0020、0023、0055）
- 放手交给别人 → 以信任为由不去担心（0016、0017）

## 关系
- 燕：称「燕」。从小学起就是熟人（0031），燕叫她“泣き虫星南ちゃん”（0036）。她说这是久违的私下对话（0054）。
- 莉波：称「莉波」。对她的强硬下令服气（0009）。

- 小学时与燕办过学习会（0031）
