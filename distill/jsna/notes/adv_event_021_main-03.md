# 活动 021 / main-03 第3话（adv_event_021_main-03）

- 她的台词：28 行（含用匿名标签说的 0 行）
- 出场的人：燕（35）、星南（28）
- 场景：燕的家（房间里有周边），看初星毕业生联合live的录像
- 世界线：活动 021；制作人在制作的偶像：看不出

## 发生了什么
星南来到燕家，两人看初星毕业生联合live的录像，她还拿着荧光棒应援。她说这场live在当时的她心中是偶像的理想，但时代变了，她选择的是把自己的能力值最大化。她问燕为什么看到自己不完美的一面也不幻灭，燕说正因为知道她的努力和缺点才评价她。她被说得很高兴，接到学园长的电话出去，之后燕发现了一张夹着的照片。

## 她的关键台词
- 0003「あら、グッズが増えているわね。／確か、ロボットアニメだったかしら？」——注意到燕房间的变化
- 0005「確か、シル……シル……ええと、そう、／しる……おしるこスター……？」——说不对燕喜欢的作品名
- 0012「せっかくなら楽しんでみたいじゃない。／ほら、燕もペンライト持って。」——要连录像也享受
- 0014「そこのベッドの下よ。／私のグッズがたくさんあったわね。」——揭穿燕藏着她的周边
- 0021「アイドルの理想、そのものだった。」——这场live当年对她意味着什么
- 0023「そうよ。理想は人によって違うもの。」——回应燕的“理想”
- 0025「私は私の能力値を最大化させる方向性を／選び続ける。……それだけよ。」——自己的路线
- 0032「私が世間の評価ほど完璧ではないことを／燕はよく知っているでしょう？」——自己清楚形象与实际有落差
- 0033「それなのに、燕はずっと、私の一番の／ファンでいてくれる。」——对燕态度的疑问
- 0037「それが分かっているのに、／幻滅しないのは、どうして？」——追问理由
- 0055「フフ。／嬉しいこと、言ってくれるじゃない。」——听完燕的回答后
- 0056「……あら、学園長からだわ。／ちょっと出てくるわね。」——接到学园长电话

## 行为模式
- 看录像 → 兴奋，喊着“いえーい♪”，叫燕也一起拿荧光棒（0010、0012）
- 说到理想 → 先讲当年的憧憬，再讲自己的选择（0020～0025）
- 提到自己不完美 → 主动问燕为什么不幻灭（0030～0037）
- 被燕认可 → 嘴上略带逞强（0051），随后笑着说“嬉しいこと”（0055）

## 关系
- 燕：称「燕」。认为燕是“一番のファン”（0033）。燕称她「貴様」，并说她是「一番星」（0026）。
- 学園長：来电，出去接（0056）。
- 先辈们：说“你喜欢的先辈”（燕，0018），她认可（0019）。

## 档案类事实
- 初星毕业生联合live对当时的她是理想（0020、0021）
- 方向是最大化自己的能力值（0025）
- 录像里有已经引退的先辈（0019）
- 燕的床下有她的周边（0014）
- 看到燕房间里的新周边，说不对作品名（0003、0005、0006）

## 不确定
