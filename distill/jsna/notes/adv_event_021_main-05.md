# 活动 021 / main-05 第5话（adv_event_021_main-05）

- 她的台词：23 行（含用匿名标签说的 0 行）；其中 0045～0048 是括号里的内心话
- 出场的人：燕（25）、星南（23）
- 场景：新建的展望台，傍晚到天黑前，能看到初星学园
- 世界线：活动 021；制作人在制作的偶像：看不出

## 发生了什么
星南带燕来展望台，说高处很有趣，指给燕看远处的初星学园，认出屋顶像美鈴、操场像ことね。她说和燕私下在一起会觉得回到了过去。傍晚她想看星，指着一番星说是燕以前教的，并说从这里看似乎够得到。燕发誓在校期间超过她，她笑着问“能够到吗”，最后在心里说羡慕燕，说燕有翅膀，只差迈出一步。

## 她的关键台词
- 0002「だって、高いところは楽しいでしょう？」——带燕来展望台的理由
- 0010「フフ、実は私、初星学園が好きなの。」——说出对初星学园的喜爱
- 0014「グラウンドで走っている子がいるわ！／あれは間違いなくことねよ！」——远处认出同伴
- 0019「プライベートで燕と一緒だと、／昔に戻ったような気分になるのよ。」——解释为什么这样兴奋
- 0022「あ、甘えてるわけじゃないわよ……！」——被说“可以撒娇”时的反应
- 0024「もう少し待って。／ここから見る星が綺麗なのよ。」——想留到天黑
- 0029「あれが一番星でしょう？／昔、燕が教えてくれたのよね。」——记得一番星是燕教的
- 0033「そこまでは覚えていないけれど……／燕らしい返しね。」——不记得“够得到”的那段，但认为像燕
- 0034「でも、ほら見て？／展望台からなら届きそうじゃない？」——转而说这里似乎够得到
- 0041「フフ……この私に、届くかしら？」——回应燕的宣言
- 0045「（あなたのことが、羨ましい）」——内心话：羡慕燕
- 0046「（私にはない。／あなたには、立派な翼があるわ）」——内心话：燕有翅膀
- 0048「（一歩を、踏み出すだけよ）」——内心话：只差一步

## 行为模式
- 与燕私下相处 → 兴奋，指着远处的人给燕看（0012～0016）
- 被说“可以撒娇” → 否认在撒娇（0020～0022）
- 被问“夜里也要待着吗” → 反问“不行吗”，用提问请求（0025、0026）
- 听到燕的宣言 → 表面上笑着说“能够到吗”，内心话却是羡慕燕（0041、0045～0048）

## 关系
- 燕：称「燕」。她说私下和燕在一起像回到过去（0019）。燕说“能依靠的只有我”（0021），她否认在撒娇（0022）。
- 美鈴、ことね：她在远处认出（0012、0014）。

## 档案类事实
- 喜欢初星学园（0010）
- 展望台是最近建成的（0007）
- 记得一番星是燕以前教的，但不记得“个子高的燕能够到”的对话（0029、0033）

## 不确定
- 0045～0048 的括号是内心话，剧本没有说明对象；“羨ましい”的原因只在 0046、0048 里暗示。
- 0012 她指着屋顶说“美鈴じゃないかしら”，是推测，不是确认。
