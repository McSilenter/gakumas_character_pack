# 活动 024 / main-01 第1话（adv_event_024_main-01）

- 她的台词：26 行（含用匿名标签说的 0 行）：0002、0003、0004、0007、0008、0009、0010、0015、0017、0019、0021、0023、0025、0027、0028、0030、0032、0036、0038、0039、0045、0047、0048、0050、0051、0052（0015 是括号内的心里话；不含一同 0018、0022、0053）
- 出场的人：星南、佑芽、千奈、美鈴
- 场景：2月，『渋谷サウンドフェス』开演前（0001～0003）；随后回溯到4月，第一次正式训练日，集合地点看不出（0016、0017）
- 世界线：活动 024；制作人在制作的偶像：星南自称是制作人，佑芽、美鈴是她的担当偶像（0009、0012）

## 发生了什么
2月，星南对佑芽和美鈴说『渋谷サウンドフェス』就要开始，叫她们尽情展示成果。回忆回到4月：星南宣布从今天起正式开始训练，发现美鈴没到。佑芽和千奈说美鈴在午睡，是班上的头号不良学生，星南大吃一惊。佑芽很快把美鈴抓回来，美鈴承认自己是故意躲起来，星南惊讶后说“问题儿童才更有培育价值”，要大家重新开始训练。剧情经过参照 hmsz、hume 笔记。

- 0015「（ふふっ。頼もしくなったわね。／本当に……この1年で――）」——心里话，回想这一年
- 0027「気にしてほしいのだけど！？」——对佑芽说美鈴不会在意迟到时的反应
- 0028「というかあなたたちの落ち着きぶり……／まさか、普段から……？」——从佑芽、千奈的镇定推测美鈴平时就这样
- 0032「そんな……あんなに品行方正そうな／外見なのに……？」——对美鈴是不良学生感到意外

- 0051「――いいわ！　問題児だからこそ、／プロデュースし甲斐があるというもの！」——对问题学生的态度：越难越有培育价值
- 0052「逃がさないわよ美鈴！　さあみんな！／今度こそレッスンをはじめましょう！」——重整队伍，开始训练

## 行为模式
- 集合时有人缺席 → 先确认联络是否到位，再问是不是身体不适缺席或早退（0021、0023）
- 听到缺席理由是午睡 → 先跟着接受，一秒后吃惊反问（0025）
- 同伴说“那个人不在意” → 以“请她在意”回敬（0027）
- 发现美鈴的本性 → 受到冲击，然后立刻转为“更有培育价值”（0050、0051）
- 差点顺着美鈴说话 → 马上收住，转为训诫（0047、0048）
