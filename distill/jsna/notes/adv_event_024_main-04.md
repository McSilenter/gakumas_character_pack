# 活动 024 / main-04 第4话（adv_event_024_main-04）

- 她的台词：25 行（含用匿名标签说的 0 行）：0002、0003、0004、0009、0010、0011、0014、0015、0023、0030、0031、0034、0035、0036、0037、0038、0039、0041、0048、0054、0057、0058、0059、0060、0061（不含一同 0047）
- 出场的人：星南、佑芽、美鈴
- 场景：1月，『渋谷サウンドフェス』（2月）前，训练时给两人看歌单（具体地点没有明说）
- 世界线：活动 024；制作人在制作的偶像：星南是佑芽、美鈴的制作人（0043 佑芽称「あたしたちのプロデューサーちゃん」）

## 发生了什么
星南让佑芽、美鈴看『渋谷サウンドフェス』的歌单，第一首就是她自己夺冠时唱的『ENDLESS DANCE』。美鈴问她为什么放进来、为什么只有两人唱，星南回答她不唱，想把这首归还给全体偶像，要她们从自己手里夺回来。佑芽和美鈴同声拒绝，说她低估了担当偶像，要星南一起唱，并宣称会夺回这首歌。星南笑出来，说那就来挑战十王星南的『ENDLESS DANCE』。剧情经过参照 hmsz、hume 笔记。

- 0002「さあ、佑芽、美鈴。」——开头叫两人看歌单
- 0010「1曲目から、一気に会場のボルテージを／上げようと思って。」——解释把『ENDLESS DANCE』放第一首的理由
- 0011「問題があるかしら？」——对佑芽的反应不明白，问是否有问题
- 0014「……大げさ。フフ……」——被佑芽夸大地介绍这首歌时的反应
- 0023「……なんだか恥ずかしくなってきたわ。」——被美鈴、佑芽当面说起自己的往事时害羞
- 0030「ええ、歌わない。」——回答“您不打算唱吗”
- 0031「あなたたちに託したいの。／『ENDLESS DANCE』を。」——说明想法：把歌托付给后辈
- 0034「あの曲は、初星学園のアイドルが／歌うために作られた楽曲。」——这首歌本来是为初星学园的偶像作的
- 0036「なのに、あの優勝ライブ以降……／誰も歌わなくなった。」——问题所在：无人再唱
- 0037「『ENDLESS DANCE』は、／十王星南に独占されてしまったの。」——这首歌被自己独占
- 0039「あなたたちに、奪い返して欲しいのよ。／――私から。初星学園の宝を。」——对后辈的真正要求
- 0048「ええっ……？」——被两人同声拒绝的惊讶
- 0059「――あぁ、可笑しい。」——被两人的回答逗笑
- 0060「生意気な後輩ね。／なら、挑んでいらっしゃい。」——接受挑战
- 0061「十王星南の／『ENDLESS DANCE』に！！」——挑战的对象是她自己的这首歌

## 行为模式
- 被追问设计理由 → 说明用意（炒热开场），并问有没有问题（0010、0011）
- 被当面夸 → 先说「大げさ」，一边笑，随后说「恥ずかしくなってきたわ」（0014、0023）
- 要把重要的事托付给后辈 → 先讲清楚道理（歌是学园的，被自己独占，毕业后会怎样），再提出要求（0034～0039）
- 被后辈反驳 → 吃惊，再被逗笑，最后接受并转为挑战（0048、0057～0061）

## 关系
- 佑芽、美鈴：叫「佑芽」「美鈴」；两人叫她「星南先輩」（佑芽）、「星南会長」（美鈴）（0051 佑芽台词、0029 美鈴台词）
- 佑芽：称赞佑芽对偶像更熟悉（0015）

## 档案类事实
- 『ENDLESS DANCE』是星南成为『一番星』那天在优胜演唱会上唱的曲子（0013 佑芽台词）
- 星南说这首曲子是为初星学园的偶像演唱而创作，自己的优胜演唱会之后没有人再唱过（0034、0036）
- 星南即将毕业（0038）
- 本篇的歌单安排：第一首是『ENDLESS DANCE』，她自己不唱（0010、0030）

## 不确定
- 一同 0047「イヤでーっす！」：佑芽、美鈴齐声回绝星南，星南不是其中之一，不算。
- 0013 佑芽说『Choo Choo Choo』与 0021：『ENDLESS DANCE』是“优胜演唱会”的曲子，『Choo Choo Choo』是「本戦」的曲子（0019、0021），两首的关系只是佑芽、美鈴的说法，不是星南本人所说。
