# 活动 024 / main-05 第5话（adv_event_024_main-05）

- 她的台词：32 行（含用匿名标签说的 0 行）：0002、0003、0004、0005、0006、0007、0009、0012、0013、0016、0019、0020、0021、0022、0033、0034、0036、0037、0039、0040、0041、0043、0046、0047、0048、0049、0051、0052、0053、0056、0057、0059（0002～0007 是括号内的心里话；0033 是无字的沉默；不含一同 0025）
- 出场的人：星南、佑芽、美鈴
- 场景：2月，『渋谷サウンドフェス』开演前（后台），次日（地点没有明说）
- 世界线：活动 024；制作人在制作的偶像：星南是佑芽、美鈴的制作人（0020）

## 发生了什么
2月，演出前星南在回想自己当制作人的日子，被佑芽叫醒，美鈴说演出前打盹不可以。星南自称可能是制作人的天才，美鈴说她第一个想到的不是夸偶像。星南说自己也是初星学园的偶像，带两人上场。次日，星南在看大家唱『ENDLESS DANCE』的视频，说被佑芽的表演解开了歌的诅咒，月村同学也想把它放进歌单。她感谢两人，承认自己已经不想放手，并说从两人身上学到的更多。结尾佑芽邀请她们一起去唱歌。剧情经过参照 hmsz、hume 笔记。

## 她的关键台词
- 0003「（手探りではじまった、／プロデューサーとしての日々）」——心里话：当制作人一开始是摸索着走过来的
- 0004「（アイドルを導く責任は重く、／なにひとつ計算通りにはいかなくて）」——心里话：责任重，没有一件事按计划进行
- 0006「（担当アイドルたちのおかげで、／いまは胸を張れる）」——心里话：靠担当偶像们才有今天的底气
- 0013「あぁ……私って、プロデュースの天才／だったのかもしれないって。」——被叫醒后的解释，自夸为制作人天才
- 0016「褒められていない気がするわね。」——对美鈴“首先想不到夸偶像是优点”的反应
- 0020「私は、十王星南。／あなたたちのプロデューサーにして、」——自我介绍
- 0021「初星学園のアイドルよ！」——制作人兼偶像的身份
- 0034「えっ、あ、ごめんなさい。／聞いていなかった、なにかしら？」——看视频入神，没听到问话
- 0041「あなたの楽しそうなパフォーマンスが、／楽曲にかかっていた呪いを解いた。」——对佑芽表演的评价
- 0048「十王星南が独占していた宝物が、／みんなの手に戻ってきたの。」——这首歌回到大家手中
- 0052「『ENDLESS DANCE』を／継承する儀式。／そう思っていたはずなのに……」——本来把它当作交接仪式
- 0053「手放すつもりがなくなってしまったわ。」——承认自己已经不想放手
- 0057「つくづく思うわ。あなたたちを／導いているつもりでいて……／学ぶことの方が遥かに多いと。」——自认从后辈身上学到的更多

## 行为模式
- 自己的成果被认可 → 自夸，被损一句也笑着接受（0013、0016、0019）
- 对重要的场面 → 用自己的头衔提气后立刻下达「最初から全力」（0020～0022）
- 看到喜欢的东西 → 入神到没听见别人叫（0033、0034）
- 自己当初的决定被现实改变 → 老实承认变化（0052、0053）
- 感谢后辈 → 直接说「ありがとう。あなたたちのおかげよ」（0049）

## 关系
- 佑芽：叫「佑芽」；认为佑芽的表演解开了歌的诅咒（0040、0041）
- 美鈴：叫「美鈴」；美鈴称她「星南会長」，以及「プロデューサー」（0035 美鈴台词、0011 美鈴台词）；美鈴说「そんなことだろうと思っていました」（0054）
- 月村さん：叫「月村さん」；月村来找她商量想把『ENDLESS DANCE』放进下次歌单（0043、0044）

## 档案类事实
- 星南自认「プロデュースの天才／だったのかもしれない」（0013，半开玩笑）
- 她把自己看作“制作人，也是初星学园的偶像”（0020、0021）
- 最喜欢的乐曲是『ENDLESS DANCE』（0047）
- 她会看网上上传的歌曲视频，也有自己的过往视频在被观看（0036、0050、0051）
