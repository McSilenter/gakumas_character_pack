# 活动 025 / main-04 第4话（adv_event_025_main-04）

- 她的台词：9 行（含用匿名标签说的 0 行）：0003、0013、0019、0044、0053、0060、0068、0073、0075（不含一同 0030、0034、0035、0066、0071）
- 出场的人：千奈、佑芽、美鈴、星南、莉波、燕
- 场景：休息日的派对会场，后辈们准备的章鱼烧派对（0044）
- 世界线：活动 025；制作人在制作的偶像：看不出

## 发生了什么
星南、莉波、燕被后辈们邀请参加慰劳派对。后辈们先汇报业务改善，介绍日程APP，星南觉得学园里也会有人想用，夸佑芽准备得周全。千奈宣布章鱼烧派对，星南明白了为什么在休息日被叫来。听到燕吃抹茶甜品的事，星南说自己不知道。馅料按各人喜好搭配，星南得到红茶口味的推荐。星南劝燕评价后辈，燕说「よくやったな」，星南也夸这是出色的工作，并叫千奈开始烤。剧情经过参照 hmsz、hume 笔记。

## 她的关键台词
- 0003「こちらこそ、ありがとう。」——后辈们致谢时的回应
- 0013「へぇ。このアプリケーション、／学園でも使いたいわね。」——看了日程APP后的反应
- 0019「ちゃっかりしているわね。」——知道公司是佑芽父母经营后的评价
- 0044「フフッ、だから休日に呼ばれたのね。」——明白了在休息日被叫来的原因
- 0053「そんなことがあったの！？／聞いていないのだけど。」——听说燕在家庭餐厅的事，自己毫不知情
- 0060「ふふっ……中身の具材は、どれも私たち／の好みに合わせてくれているようね。」——注意到馅料是按她们喜好准备的
- 0068「後輩たちの仕事を、／評価してあげたらどうかしら？」——劝燕评价后辈
- 0073「素晴らしい仕事よ。／今日は楽しませてもらうわね。」——给后辈的评价并表示期待
- 0075「フフ……千奈。／待ち切れない先輩がいるみたいよ。」——提醒千奈莉波已等不及

## 行为模式
- 看到有用的东西 → 想到学园里谁会需要（0013）
- 后辈准备周到 → 以「ちゃっかりしているわね」评价（0019）
- 听到自己不知道的事 → 大声追问「聞いていない」（0053）
- 想让后辈得到认可 → 让燕来评价，自己再补一句夸奖（0068、0073）
- 有人等不及 → 以轻松的口气替对方向千奈转达（0075）

## 关系
- 千奈：叫「千奈」（0075）；千奈叫她「星南お姉さま」（0001 千奈台词）
- 燕：这一篇里星南没有直接叫燕的名字，对话中叫她评价后辈（0068）
- 莉波：没有直接叫名字（0075 称「待ち切れない先輩」）

## 档案类事实
- 星南不知道燕在家庭餐厅吃过抹茶甜品（0053）
- 红茶口味的章鱼烧是后辈推荐给她的（0062 千奈台词）
