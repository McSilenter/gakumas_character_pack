# 活动 028 / main-03 第3话（adv_event_028_main-03）

- 她的台词：7 行（含用匿名标签说的 0 行）；行号 0001、0003、0004、0006、0007、0011、0012
- 出场的人：燕、莉波、星南、広、佑芽、千奈、美鈴、一同
- 场景：文化祭准备期间，傍晚到夜里的初星学園校舍；她要离开去办演唱会，把校舍钥匙交给燕。
- 世界线：活动 028；制作人在制作的偶像：看不出

## 发生了什么
星南犒劳燕，得知燕要留到夜里监督进度落后的班级，把钥匙交给她，并为自己不能留下而道歉。她说要去用演唱会宣传初星文化祭，称这是生徒会最后的大工作。燕说倉本她们已经学会了工作，文化祭后可以交接。星南问燕自己是否做得好、有没有把学园变得更好；燕回答是，并说「お疲れ様、会長」。之后她不再出场。剧情经过参照 hmsz、hume 笔记。

## 她的关键台词
- 0001「お疲れ様、燕。今日は、／夜まで校舎に残るのよね。」——以犒劳开场，对燕的安排很了解。
- 0004「本当は私も残りたいのだけど、／ごめんなさい。」——因要出去宣传而不能留下，向燕道歉。
- 0006「ええ、任せて頂戴。」——接下宣传文化祭的任务。
- 0007「……生徒会としての、／最後の大仕事ね。」——意识到这是生徒会工作的收尾。
- 0011「……燕。私は、上手くできたかしら？」——在交接话题后向燕寻求确认。
- 0012「私の愛するこの初星学園を、少しでも、／素敵な場所にできたかしら？」——说明自己的在意之处：学园是「私の愛する」地方。

## 行为模式
- 把工作托付给别人 → 先道歉，再把要承担的新任务（宣传）说出来（0003、0004、0006）。
- 谈到任期的终点 → 对着熟悉的伙伴直接问自己做得如何，不自我评价（0011、0012）。

## 关系
- 燕：直呼「燕」，把钥匙和后续交给她；燕称她「会長」（0014）。
- 倉本：燕提到倉本们已熟悉工作，文化祭后会交接（燕 0009、0010）；星南本人没有说到。

## 档案类事实
- 她是生徒会会长（燕 0014 称「会長」），要在演唱会宣传文化祭（0006）。
- 她说「私の愛するこの初星学園」（0012）。
