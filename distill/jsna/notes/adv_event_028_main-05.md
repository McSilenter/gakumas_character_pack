# 活动 028 / main-05 第5话（adv_event_028_main-05）

- 她的台词：6 行（含用匿名标签说的 0 行）；行号 0030、0031、0033、0034、0035、0066
- 出场的人：莉波、燕、咲季、星南、父、母、一同
- 场景：文化祭当天的舞台上；演唱会休息时。
- 世界线：活动 028；制作人在制作的偶像：看不出

## 发生了什么
演唱会休息期间，星南在台上宣布追加的特别企划『初星アイドルコンテスト』，飞入参加，参加资格只有「アイドルであること」。她号召有自信的偶像来参加。莉波对这个意外的计划惊慌，燕说这是会长的一时兴起。之后莉波登台时，星南叫了她的名字「莉波」。剧情经过参照 hski 笔记。

## 她的关键台词
- 0030「みんな、盛り上がっているかしらー？」——对观众的开场喊话。
- 0031「ライブは一旦休憩だけど――／ここでサプライズの／特別企画を発表するわ！」——宣布惊喜企划。
- 0033「なんとなんと、飛び入り大歓迎の、／初星アイドルコンテストを開催します！」——宣布内容。
- 0034「参加資格は――／アイドルであること、以上！」——条件极简。
- 0035「自信のあるアイドルは、／どんどん参加してちょうだい。」——邀请有自信的人。
- 0066「……莉波。」——莉波下定决心登台时叫了一声她的名字。

## 行为模式
- 在舞台上 → 用提高情绪的口气吸引观众，条件说得很简单（0030～0035）。
- 莉波要上台时 → 只叫一声名字，没有多说（0066）。

## 关系
- 莉波：叫她「莉波」（0066）；莉波称她「星南会長」（莉波 0032）。
- 燕：燕说她的企划是「思い付き」（燕 0038），后来也说那个舞台是「ただの星南の気まぐれ」（燕 0073）；这些是燕的话。

## 档案类事实
- 在文化祭上追加了『初星アイドルコンテスト』（0033）。
- 她在演唱会中也是最后登场的人（燕 0021 说「ラストに控える星南」，是燕的话）。

## 不确定
- 0066 的「……莉波。」是在莉波的独白和登台之间，剧本没写明她的神情或所在位置。
- 0073 燕说「ただの星南の気まぐれ」，星南本人对此的想法这一篇没有。
