# 活动 030 / main-01 我是、小恶魔♡ 第1话（adv_event_030_main-01）

- 她的台词：20 行（含用匿名标签说的 0 行）；行号 0002、0004、0006、0008、0009、0011、0012、0014、0015、0017、0018、0019、0022、0024、0025、0027、0028、0029、0030、0032。其中 0009 是心里的话（括号内）。
- 出场的人：リーリヤ、星南、清夏、咲季、佑芽
- 场景：初星学園的生徒会室，只有星南和リーリヤ的段落（0001～0036）。
- 世界线：活动 030；制作人在制作的偶像：看不出

## 发生了什么
星南在生徒会室里等着，リーリヤ一到就叫出她的名字，吓了她一跳；她说是感觉到了「アイドルパワー」，其实只是在门前等着，心里觉得不好说破。她请リーリヤ担任初星学園大型タイアップ企画第2弹（超有名化妆品厂商的香水联名）的リーダー，第1弹她自己当リーダー并邀了美鈴和手毬。リーリヤ问为什么选她，她说因为听说她用香水、擦肩而过时有好闻的香味，还有圣诞蛋糕销售评价好，也要从学生的视点参与CM概念。リーリヤ担心时，她说这是作为偶像成长的机会。

## 她的关键台词
- 0002「来たわね、リーリヤ！」——一见面就用名字叫她。
- 0006「フフ……それはね、扉越しに、あなたの／アイドルパワーを感じ取ったのよ。」——用夸张的说法来解释自己预知。
- 0009「（本当は扉の前で待ち構えていただけ／なのだけど……言いづらいわね……）」——心里承认是在门前等着，觉得难以开口。
- 0012「アイドルとしての仕事を頼みたいの。」——直接说明叫她来的目的。
- 0015「第1弾は私がリーダーとして、／美鈴や手毬を誘ったのだけど、」——说明自己做过第1弹的リーダー。
- 0019「――リーリヤ、あなたに任せるわ！」——任命リーダー。
- 0024「ふふっ、そうでしょう？／あなたとすれ違った時に思ったのよ。」——说明选人的契机。
- 0028「商品のターゲットは学生。／初星学園の生徒としての視点を／取り入れるために、」——说明理由中学生视角的部分。
- 0032「確かに、難しい企画だとは思うけれど、／アイドルとして成長するチャンスよ？」——对犹豫的リーリヤ承认难度，同时推她一把。

## 行为模式
- 被后辈佩服 → 顺势接受，并在心里补一句真相（0008、0009）。
- 要交托重任 → 先说目的，再说自己做过第1弹，然后给出选人的具体依据（0012～0029）。
- 对方犹豫 → 承认任务难，但把它说成成长的机会（0032）。
- 用问句邀请对方发表意见 → 一次给多项任务（成员选定、概念）（0030）。

## 关系
- リーリヤ：叫她「リーリヤ」；リーリヤ叫她「会長」，把她当「一番星」佩服（0010、0007）。
- 美鈴、手毬：她曾作为リーダー邀请她们参加第1弹（0015）。

## 档案类事实
- 她是初星学園的生徒会会长（リーリヤ 0010「会長」）。
- 初星学園有大型タイアップ企画，与各种厂商联名；第1弹由她做リーダー，邀请美鈴和手毬，第2弹是化妆品厂商的香水联名（0014、0015、0018）。
- 第2弹的商品目标客户是学生（0028）。
