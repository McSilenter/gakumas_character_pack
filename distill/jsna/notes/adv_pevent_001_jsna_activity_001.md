# 十王星南 培育事件 001 activity / 001 星南的感谢（adv_pevent_001_jsna_activity_001）

- 她的台词：11 行（含用匿名标签说的 0 行）
- 出场的人：星南（11 行）、プロデューサー（9）
- 场景：她把制作人突然叫来、准备点单的店里（0001、0002）；店名剧本没写
- 世界线：培育（十王星南）；制作人在制作的偶像：十王星南（0017 制作人称她“担当アイドル”，0020 说一定把星南带到顶级偶像）

## 发生了什么
她突然叫制作人跟她来，要请他吃东西，理由是平时受他照顾、想稍微答谢（0001～0005）。制作人说只是做了制作人该做的事，她坚持说感谢他的プロデュース，还说回应偶像的心意也是制作人的职责（0006～0008）。之后是选项后的并列反应：一种是制作人调侃她今天“勧誘が上手”，她慌了，制作人建议把这样的真心多展现给粉丝和藤田さん，她起初犹豫，随后说会试着更多地以十王星南的身份说话（0009～0016）；另一种是制作人说被担当偶像这么说会更加把劲，她说并不是要回报，硬要说的话期待和以前一样的プロデュース，制作人说一定把她带到顶级偶像（0017～0020）。

## 她的关键台词
- 0005「少しくらい、お礼をさせてほしいのよ。」——主动答谢制作人
- 0007「そうだとしても、よ。私はあなたの／プロデュースに感謝しているの。」——不接受对方的谦让，直接说出感谢
- 0008「それに、アイドルの気持ちに応えるのも／プロデューサーの務めでしょう？」——用“制作人的职责”把对方说服，强势的请客方式
- 0010「なっ！？　どういう意味よ！」——被调侃时立刻慌乱反问
- 0016「……いえ、そうね。もう少し、／十王星南として話してみるわ。」——犹豫后接受建议，用全名称呼自己
- 0018「別に見返りを求めていたわけでは／なかったのだけれど……」——表示请客不图回报
- 0019「あえて言うなら、今まで通りの／プロデュースを期待しているわ。」——把期待说成“一如既往”，对制作人的信任

## 行为模式
- 想表达感谢 → 先不说明理由就把人带去，再以“请客”的形式答谢；对方谦让时用道理压过去（0001～0008）
- 被看穿、被调侃 → 先慌张反问，被讲道理后停顿片刻接受（0010、0015、0016）
- 对方说要更加努力回报 → 先否认图回报，再提出朴素的期待（0018、0019）

## 关系
- 制作人：叫「プロデューサー」（0001）；制作人叫她“星南さん”（0020）、称她“担当アイドル”（0017）。她明说感谢他的プロデュース（0007），期待他照旧制作（0019）。
- 藤田さん：制作人建议她也对“藤田さん”等人流露真心（0013），她本人在这一话没有提到这个人。

## 档案类事实
- 平时觉得受制作人照顾，请他吃东西答谢（0004、0005）
- 制作人认为她的真心（本心）是很强的武器，建议她多展现给粉丝（0011～0013，制作人的说法）
