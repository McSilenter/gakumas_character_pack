# 十王星南 培育事件 001 activity / 002 慰问品（adv_pevent_001_jsna_activity_002）

- 她的台词：11 行（含用匿名标签说的 0 行）
- 出场的人：星南（11 行）、プロデューサー（9）
- 场景：地点剧本没写明；她在挑给学生会成员的慰问品（0001）
- 世界线：培育（十王星南）；制作人在制作的偶像：十王星南（剧本里没有直接说法）

## 发生了什么
她要给学生会成员带慰问品，因为莉波和美鈴偶尔会带点心来，总是收下过意不去（0001～0003）。制作人说可以帮忙拿东西，她说不是要这个，而是想听他的意见（0004、0005）。之后是选项后的并列反应：制作人建议经典的曲奇，她担心太普通，听了“经典＝喜欢的人多、心意本身让人高兴”后决定这次选曲奇（0006～0010）；制作人建议配点心的红茶或咖啡，她赞同，还想到美鈴会带和果子，也许绿茶好（0011～0015）；制作人建议大量买零食（駄菓子），她问理由，听后说想试试“大人買い”（0016～0020）。

## 她的关键台词
- 0003「もらってばかりじゃ／申し訳ないじゃない？」——不愿只受别人的好意
- 0005「ありがとう。けれどそうではなく、／あなたから意見をもらいたいの。」——要的是制作人的意见，不是帮手
- 0007「私もそう思ったのだけれど……／さすがに定番すぎないかしら？」——担心太普通
- 0010「フフ……その通りね。／今回はクッキーにしておくわ。」——被说服后爽快决定
- 0015「あと、美鈴は和菓子も持ってくるし、／緑茶なんかがいいかしら。」——记得美鈴带的点心种类，按对方来搭配
- 0019「へえ……そういうものなのね。」——对没体验过的事感到新鲜
- 0020「大人買い、やってみようかしら。」——想尝试新做法

## 行为模式
- 收到别人的好意 → 想着回礼，不愿“只收不给”（0002、0003）
- 拿不定主意 → 找制作人要意见，自己先提出顾虑（太普通），被讲通后马上采纳（0005、0007、0010）
- 听到没经历过的事 → 先好奇再表示要试试（0019、0020）

## 关系
- 制作人：作为商量对象，她要的是他的意见（0005）。这一话里没有称呼他。
- 莉波、美鈴：她直呼名字；两人偶尔会带点心来，美鈴也会带和果子（0002、0015）。她想回礼。

## 档案类事实
- 莉波、美鈴偶尔给她（和学生会成员）带点心，美鈴也带和果子（0002、0015）
- 想给学生会成员带慰问品（0001、0003）
