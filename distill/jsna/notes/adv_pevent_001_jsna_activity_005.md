# 十王星南 培育事件 001 activity / 005 休息日的邀请（adv_pevent_001_jsna_activity_005）

- 她的台词：14 行（含用匿名标签说的 0 行）
- 出场的人：星南（14 行）、プロデューサー（7）
- 场景：地点、时间剧本没写明；和制作人聊休息日怎么过
- 世界线：培育（十王星南）；制作人在制作的偶像：十王星南（剧本里没有直接说法）

## 发生了什么
制作人问她休息日会不会和同学、朋友一起过，她说不太有，猜是大家觉得她忙、不好约她（0001～0003）。制作人建议她主动邀请，她问约做什么好（0004、0005）。之后是选项后的并列反应：她想起考试前有人办学习会，听说是带零食饮料互相教，说比想象中轻松、没有不做的理由，决定下次约人试试（0006～0010）；（买衣服的提议后）她说没和别人一起去过，衣服都自己挑，听制作人说让别人挑能发现新魅力，觉得有趣，还想反过来替对方挑衣服，说很有プロデュース的价值（0011～0016）；（另一项提议后）她担心突然邀请门槛太高，听说能一下拉近距离，就想趁机约ことね，被制作人提醒注意邀请方式，她结巴地反问什么意思（0017～0021）。

## 她的关键台词
- 0003「忙しいと思われているのかしら。／私って、誘いにくいみたい。」——自己猜测别人不约她的原因
- 0008「……もっと固い感じを想像していたわ。」——对普通学生的活动缺乏实感
- 0010「採用よ。今度、誰かを誘ってみるわ。」——像做决策一样说“采用”
- 0011「誰かと行く機会はなかったわね。／服を買う時は、自分で選んでいるし。」——买衣服一直是一个人
- 0016「フフフ……／プロデュースのし甲斐がありそうだわ！」——话题一转就变成プロデュース别人
- 0017「いきなり誘うには、ハードルが／高くないかしら……！？」——对邀请别人有顾虑
- 0019「！　確かに一理あるわ。／この機会に、ことねを――」——立刻想到ことね
- 0021「どっ、どういう意味かしら。」——被提醒时慌张

## 行为模式
- 被建议多和同学交往 → 认真当成课题，问具体做什么（0005）
- 听到可行的方案 → 用“採用”之类的词干脆拍板（0010）
- 想到替别人挑东西 → 兴奋地把它当成プロデュース（0015、0016）
- 遇到“拉近距离的机会” → 马上想到ことね；被点破 → 结巴（0019、0021）

## 关系
- 制作人：建议她和同学加深交往（0004）、提醒她约ことね时注意方式（0020）；叫她“星南さん”（0001）。这一话她没有称呼他。
- ことね：直呼名字；她想趁机约ことね（0019）。
- 同学、朋友：休息日很少一起过；她觉得自己被认为忙、难约（0002、0003）。

## 档案类事实
- 休息日不太和同学、朋友一起过（0002）
- 买衣服都是自己挑，没和别人一起去过（0011）
- 打算下次邀请同学办学习会（0010，打算）
