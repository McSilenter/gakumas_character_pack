# 十王星南 培育事件 001 activity / 006 小时候（adv_pevent_001_jsna_activity_006）

- 她的台词：13 行（含用匿名标签说的 0 行）
- 出场的人：星南（13 行）、プロデューサー（4）
- 场景：地点、时间剧本没写明；制作人问起她小时候
- 世界线：培育（十王星南）；制作人在制作的偶像：十王星南（剧本里没有直接说法）

## 发生了什么
制作人问她是不是从小受精英教育，她说从 3 岁起一直如此：有训练师、做正式的课程（配合孩子体力），每天拼命唱、跳，这是她能想起的最初记忆（0001～0006）。她说懂事时已经是偶像，从没想过每天只有课程和工作是辛苦的，现在大概也一样（0007～0009）。之后是选项后的并列反应：制作人说她是“生粋のアイドル”，她笑说希望如此（0010、0011）；她以为制作人早把她小时候出演的节目都看过，制作人说全看过、但工作以外的影像弄不到，她结巴着说如果对プロデュース有必要的话……只能给一点点（0012～0017）。

## 她的关键台词
- 0002「ええ、3歳の頃からずっとね。」——精英教育的起点
- 0005「毎日必死で……歌って、踊って……」——回忆小时候
- 0006「それが私が思い出せる、最初の記憶。」——最初的记忆就是训练
- 0007「物心が付いた頃には、／もうアイドルだったから。」——自认生来就是偶像
- 0008「レッスンや仕事ばかりの毎日が、／大変だという発想自体がなかったわね。」——不觉得辛苦
- 0009「……それはきっと、いまも変わらない。」——现在也是如此
- 0011「フフ……そうだと信じたいわね。」——被称作天生偶像时并不完全断言
- 0016「……あ、あなたがプロデュースに／必要だというのなら……」——对私人影像害羞，但以プロデュース为由答应
- 0017「……すこしだけよ？」——有限度地让步

## 行为模式
- 被问过去 → 平静地按顺序讲，讲到“最初的记忆”时停顿（0002～0006）
- 被夸“天生的偶像” → 笑着说“希望如此”，不完全承认（0011）
- 被要私人的东西 → 慌张，以“对プロデュース必要”为理由给一点（0016、0017）

## 关系
- 制作人：叫她“星南さん”（0010）。她默认他会把她当年的节目全看过（0012、0013），对他要私人影像感到害羞却答应给一点（0016、0017）。这一话她没有称呼他。

## 档案类事实
- 从 3 岁起接受精英教育：有训练师、做正式的课程（配合孩子体力）（0002～0004）
- 最初的记忆是每天拼命唱歌跳舞（0005、0006）
- 懂事时已经是偶像（0007）
- 不觉得每天只有课程和工作是辛苦的，现在也一样（0008、0009）
- 小时候出演过节目；制作人说都看过，但工作以外的影像弄不到（0012～0015）
