# 十王星南 培育事件 001 activity / 007 观察力（adv_pevent_001_jsna_activity_007）

- 她的台词：12 行（含用匿名标签说的 0 行）
- 出场的人：星南（12 行）、プロデューサー（6）
- 场景：地点剧本没写明；制作人说现在是休息（オフ）时间（0009）
- 世界线：培育（十王星南）；制作人在制作的偶像：十王星南（0007 制作人说不会“担当アイドルを差し置いて”去挖别人）

## 发生了什么
她一直默默盯着制作人，被问时说是在观察他，想从日常行为里抓到プロデュース的秘诀，已经有零散发现但还没有确证（0001～0005）。之后是选项后的并列反应：她想看他示范スカウト，制作人说不会放着担当偶像去做，她解释是把她当成别的女孩，笑着说务必拜托（0006～0008）；制作人说现在是休息时间看不出什么，她说正是自然状态才显出习惯了的意识，到目前已经学到很多（0009～0011）；她又默默盯着，制作人心里觉得很不自在，她说正因为是她认可的人才观察，今后也会尽情观察，叫他做好准备（0012～0017）。

## 她的关键台词
- 0003「見ての通り、プロデューサーの観察よ。」——坦然承认在观察
- 0004「普段の何気ない行動からプロデュースの／秘訣を掴めるかもと思って。」——想学プロデュース
- 0006「スカウトの実演を見てみたいわね……／私の前でやってみてくれないかしら。」——想看他怎么挖人
- 0008「私を別の子だと思って、という意味よ。／フフ……ぜひお願いしたいわ。」——让他把她当别人示范
- 0010「そんなことないわ。自然体にこそ／染みついた意識が出るものだもの。」——她的观察方法论
- 0014「いいえ、私が認めたあなただから／観察しているの。」——表明认可对方
- 0017「覚悟していてね？」——带笑的宣告

## 行为模式
- 想学某人的本事 → 一声不吭地长时间观察，坦然承认（0001、0003）
- 被说“现在看不出什么” → 用“自然状态才露真相”反驳（0010、0011）
- 对方不自在 → 不收手，反而说明是因为认可他，并宣告会继续（0014～0017）

## 关系
- 制作人：叫「プロデューサー」（0003）；制作人叫她“星南さん”，称她“担当アイドル”（0002、0007）。她说他是“私が認めたあなた”，要从他身上学プロデュース（0004、0014）。他回答若能帮上她，随她看（0018）。

## 档案类事实
- 想从制作人的日常行为里学プロデュース的秘诀（0004）
- 认为自然状态下最能看出一个人身上的意识（0010）
