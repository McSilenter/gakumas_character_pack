# 十王星南 培育事件 001 activity / 008 休息日去哪里（adv_pevent_001_jsna_activity_008）

- 她的台词：12 行（含用匿名标签说的 0 行）
- 出场的人：星南（12 行）、プロデューサー（6）
- 场景：休息日出门前，商量去哪里（0001、0013）
- 世界线：培育（十王星南）；制作人在制作的偶像：十王星南（剧本里没有直接说法）

## 发生了什么
她问制作人今天去哪里，说她把赌注押在他身上、会听他的，也期待他带她去哪儿（0001～0004）。之后是选项后的并列反应：（某种店的提议后）她说除了女仆咖啡厅没去过，但看出目的是观察接待、学让人开心的方法，说会全力享受（0005～0009）；制作人提议去看演唱会，她说看别人的演出能学到东西，连休息日都在学习，把命运托付给他真好（0010～0013）；制作人提议去看水石（赏石），说想给她偶像以外领域的刺激，她说不知道有这种东西，有兴趣，去看看（0014～0018）。

## 她的关键台词
- 0003「私はあなたに賭けたの。／あなたの言うことを聞くわ。」——把自己托付给制作人
- 0004「それに……どこに連れて行って／くれるか、楽しみだもの。」——期待
- 0007「接客を見て、楽しませ方を／学ぶんでしょう？」——看穿制作人的意图
- 0009「もちろん。全力で／楽しませてもらうわ。」——玩也要全力
- 0012「そうね。他人のライブは／勉強になるわ。」——把演出当学习
- 0013「それにしても休日も勉強なんて……／あなたに運命を託してよかったわ。」——为休息日也能学习而高兴
- 0018「別分野の刺激……興味があるわ。／行ってみましょう。」——对不熟悉的领域有兴趣

## 行为模式
- 让对方安排行程 → 以“押注在你身上”为由全盘交给他，自己只表示期待（0003、0004）
- 收到提议 → 先读出背后的学习目的，再表示会全力享受（0006～0009）
- 休息日也能学到东西 → 不嫌累，反而高兴（0013）
- 不知道的东西 → 坦率承认，有兴趣就去（0017、0018）

## 关系
