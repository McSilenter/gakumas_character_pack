# 十王星南 培育事件 001 activity / 012 住在宿舍吗？（adv_pevent_001_jsna_activity_012）

- 她的台词：9 行（含用匿名标签说的 0 行）
- 出场的人：星南（9 行）、プロデューサー（7）
- 场景：地点、时间剧本没写明
- 世界线：培育（十王星南）；制作人在制作的偶像：十王星南（剧本里没有直接说法）

## 发生了什么
制作人说她不住宿舍、从家里通学，问她有没有想过住宿舍；她说听别的孩子讲时偶尔会想，并反问作为制作人是不是希望她住（0001～0004）。之后是选项后的并列反应：制作人说她在宿舍走动会一直被注目，她说倒不如说是会在意有才能的孩子而分心（0005～0008）；制作人说也许会有发现，她说前辈这么说就为了以后学习试试，到时候要对ことね……制作人心里想她真执着（0009～0012）；制作人说没好处的话还是维持现状，她笑说他终究是为她的プロデュース着想，提议今天来讨论住宿舍的利弊（0013～0016）。

## 她的关键台词
- 0003「他の子の話を聞いていると、／たまにあるわ。」——偶尔会想住宿舍
- 0004「プロデューサーとしては、／寮に住んでほしいの？」——问他作为制作人的意见
- 0008「才能ある子たちが気になって／私の気が散りそうだわ。」——总在意有才能的孩子
- 0010「先輩がそういうなら、／後学のために試してみようかしら。」——称制作人“先輩”，以学习为由
- 0011「ふふ……そのあかつきには／ことねを……」——又想到ことね
- 0014「ふふ。あくまで私のプロデュース／のことを考えているのね。」——确认他把她的プロデュース放在第一
- 0016「じゃあ、今日は寮ぐらしのメリットと／デメリットを検討しましょうか。」——把话题变成正式讨论

## 行为模式
- 生活上的选择 → 先问制作人站在制作人的角度怎么想（0004）
- 被说会受注目 → 反过来说自己会去注意有才能的孩子（0008）
- 有机会接近ことね → 话里马上带出ことね（0011）
- 问题悬而未决 → 提议正式列出利弊来讨论（0016）

## 关系
- 制作人：叫「プロデューサー」（0004），也叫“先輩”（0010）；制作人叫她“星南さん”（0001）。她认为他始终为她的プロデュース考虑（0014）。
- ことね：直呼名字；说住宿舍的话要对ことね……（0011），制作人心里说她“ご執心”（0012）。

## 档案类事实
- 不住宿舍、从家里通学（0001，制作人的说法，她没有否认）
- 听别的孩子讲宿舍时偶尔会想住（0003）
- 在意有才能的孩子，住宿舍可能分心（0008）

## 不确定
- 0005～0008、0009～0012、0013～0016 应是选项后的并列反应，制作人选了什么剧本里没有。
- 0011「そのあかつきには／ことねを……」后半句没说完，要对ことね做什么不清楚。
