# 十王星南 培育事件 001 activity / 015 提不起干劲（adv_pevent_001_jsna_activity_015）

- 她的台词：11 行（含用匿名标签说的 0 行）
- 出场的人：星南（11 行）、プロデューサー（8）
- 场景：地点、时间剧本没写明
- 世界线：培育（十王星南）；制作人在制作的偶像：十王星南（剧本里没有直接说法）

## 发生了什么
她说制作人什么时候见都很沉着、精神很稳定，问他有没有控制心态的诀窍（0001～0004）。制作人说只是自己的方法（0005）。之后是选项后的并列反应：制作人说会忘掉工作学习尽情玩，她问那是不是连她也忘了，制作人说她玩的时候也这样做就好，她说这是坚强的秘诀，但他在身边的话她忘不掉（0006～0010）；制作人说躺在床上懒散，她说听起来很舒服，想试试，制作人提醒睡太多会后悔（0011～0014）；制作人说改家具摆设转换心情，她问一个人搬床和桌子不重吗，听说她做时只搬轻的，说那样半吊子不喜欢，想找人帮忙（0015～0019）。

## 她的关键台词
- 0001「あなたって、いつ会っても／落ち着いているわね。」——观察制作人
- 0004「なにかメンタルをコントロールする／コツでもあるの？」——想学
- 0007「それは、私のことも忘れる／ということ？」——在意自己会不会被忘掉
- 0010「でも今からやるとしても、そばに／あなたがいると忘れられないわ……」——他在身边就忘不掉工作
- 0013「気持ちよさそうね。／試してみようかしら。」——愿意尝试懒散
- 0018「それはなんだか中途半端に／なりそうで嫌ね。」——不喜欢半途而废
- 0019「誰かに手伝ってもらおうかしら……」——找人帮忙也要做完整

## 行为模式
- 觉得别人有长处 → 直接问诀窍（0001～0004）
- 听到“忘掉一切” → 先问连自己也忘吗（0007）
- 被建议做个折中版本 → 嫌半吊子，宁可找帮手做完整（0018、0019）

## 关系
- 制作人：她觉得他总是很沉着（0001）；在意他玩的时候会不会把她也忘了（0007）；说他在身边她就忘不掉（0010）。这一话她没有称呼他。

## 档案类事实
- 不喜欢把事情做得半吊子（0018）

## 不确定
- 0006～0010、0011～0014、0015～0019 应是选项后的并列反应，制作人选了什么剧本里没有。
- 0010「あなたがいると忘れられない」忘不掉的是工作学习还是别的，原文没明说。
- 【译文】0008「もし星南さんが遊ぶなら、／同じようにしてください。」是“星南你玩的时候也请这样（忘掉工作学习）”，译文“如果星南你也去玩的话，／我也会一样。”主语译反了。
