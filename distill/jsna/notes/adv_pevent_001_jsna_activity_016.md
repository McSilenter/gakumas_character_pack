# 十王星南 培育事件 001 activity / 016 前辈的教导（adv_pevent_001_jsna_activity_016）

- 她的台词：10 行（含用匿名标签说的 0 行）
- 出场的人：星南（10 行）、プロデューサー（8）
- 场景：地点剧本没写明；她说今天是放松日、没有训练（0004）
- 世界线：培育（十王星南）；制作人在制作的偶像：十王星南（0010 制作人说“十王星南のプロデュースで手一杯”）

## 发生了什么
她说今天有很多事想问“先輩”，指的是作为制作人的前辈：就算继续当偶像，这方面的知识也不吃亏，请他边闲聊边上课（0001～0004）。制作人说她有知识的话两人能想出更好的方案，但现在的她终究是偶像，别忘了；她说她也没打算中途放弃偶像，目标一致（0005～0008）。制作人说那就严格来（0009）。之后是选项后的并列反应：制作人说老实讲光プロデュース十王星南就忙不过来，她理解成“看着偷学”，说会比以前更仔细看他（0010～0013）；她对制作人的某个回答只说了“……そう。”，制作人说别误会，要教就不想半吊子，会编好课程，她说没打算这么正式，但他这样做的话她也会全力吸收（0014～0018）。

## 她的关键台词
- 0001「今日は先輩に訊きたいことがあるの。／いろいろと。」——以后辈身份请教
- 0003「ええ。アイドルを続けるとしても、／そちらの知識は損にならないでしょう？」——为将来学制作人的知识
- 0007「私だって、途中でアイドルを／放りだすつもりはないわ。」——表明不会中途放弃偶像
- 0008「目的は一緒、でしょう？」——强调和制作人目标一致
- 0012「見て、盗めということね？」——把拒绝理解成另一种教法
- 0013「わかったわ。これまで以上に、／あなたのことを見させてもらうわね。」——宣告会更仔细地观察
- 0014「……そう。」——简短，似乎有点失望
- 0018「あなたがそうしてくれるなら、／私も全力で吸収するわ。」——对方认真，她也全力

## 行为模式
- 想学制作人的知识 → 称他“先輩”，以闲聊为名请他上课（0001～0004）
- 被提醒“现在是偶像” → 明确表态不会中途放弃（0007、0008）
- 对方说没空教 → 理解成“看着偷学”，加强观察（0012、0013）
- 对方比她更认真 → 先说没想那么正式，再表示会全力吸收（0017、0018）

## 关系
- 制作人：称他“先輩”（0001），这里指制作人这一行的前辈（0002、0003）；制作人叫她“星南さん”（0005）。他提醒她现在是偶像，说光プロデュース她就忙不过来（0006、0010）；她要从他身上学（0013、0018）。

## 档案类事实
- 想学制作人方面的知识，认为即使继续当偶像也不吃亏（0003）
- 说没打算中途放弃偶像（0007）

## 不确定
- 0010～0013 与 0014～0018 应是选项后的并列反应；0014「……そう。」前制作人说了什么剧本里没有（从 0015「勘違いしないように」看，可能是近似拒绝的回答）。
- 0003「アイドルを続けるとしても」暗示她考虑过不继续当偶像，本篇没有展开。
