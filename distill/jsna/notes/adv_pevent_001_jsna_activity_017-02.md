# 十王星南 培育事件 001 activity / 017-02 集章活动（adv_pevent_001_jsna_activity_017-02）

- 她的台词：14 行（含用匿名标签说的 0 行）
- 出场的人：星南（14 行）、プロデューサー（8）
- 场景：商店街集章活动途中（0001、0004）
- 世界线：培育（十王星南）；制作人在制作的偶像：十王星南（剧本里没有直接说法）

## 发生了什么
集章集了不少，她说到这里已经能领参加奖，但剩下的印章很远、离开了商店街，要有花一整天的准备，让制作人来决定（0001～0005）。之后是选项后的并列反应：她说就知道他会这么说，集齐了最后一个；奖品是商店街能用的餐券，她说是巧妙的引流设计，说想参考、肚子也饿了，吃了再回去（0006～0011）；同样集齐后，制作人看官网说全勤奖已经发完，她大受打击，制作人说成了回忆，她笑说他真乐观（0012～0018）；制作人说这本来就是跨几天的活动、明天还有训练，今天到此为止，她说优先顺序很明确，剩下的下次休息日再来，叫他别忘了（0019～0022）。

## 行为模式
- 要花大量时间的选择 → 交给制作人决定，而且能预料他的回答（0005、0006）
- 玩的时候 → 也会从策划角度分析（0010、0011）
- 努力落空 → 真实地受打击，被对方的乐观带动笑出来（0016、0018）
- 被以训练为由叫停 → 认可优先顺序，但叮嘱别忘了约定（0021、0022）

## 关系
- 制作人：她让他做决定，说早料到他会那么说（0005、0006）；制作人叫她“星南さん”（0014）。叮嘱他别忘了下次一起来（0022）。这一话她没有称呼他。
