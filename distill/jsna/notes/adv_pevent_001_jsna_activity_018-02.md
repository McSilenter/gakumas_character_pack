# 十王星南 培育事件 001 activity / 018-02 驾驶汽车（adv_pevent_001_jsna_activity_018-02）

- 她的台词：19 行（含用匿名标签说的 0 行）
- 出场的人：星南（19 行）、プロデューサー（4）
- 场景：游戏中心，玩赛车游戏之后（0001、0020）
- 世界线：培育（十王星南）；制作人在制作的偶像：十王星南（剧本里没有直接说法）

## 发生了什么
她玩赛车游戏连终点都没到，抱怨别的车太快；制作人说撞了那么多次很难到终点，她说没想到开车这么难，问能不能再来一次（0001～0005）。之后是选项后的并列反应：她道谢说下次一定到终点，终于到了，虽然没拿第一，但记住了赛道、还有成长空间，说这种感觉很久没有了，不管什么事有进步都让人高兴（0006～0012）；同样道谢后又没到，她问车为什么不听话、是不是没开车天赋，制作人说真实道路没那么复杂，她说才能有没有都无所谓，做到为止要做多少次都行（0013～0019）；（另一回答后）她说难得来游戏中心，想挑战别的游戏，要制作人陪她（0020～0023）。

- 0001「嘘よ……ゴールすらできないなんて。」——不愿接受失败
- 0004「うっ……運転がこんなに難しいなんて／思っていなかったわ。」——承认难
- 0006「ありがとう。／次こそはゴールしてみせるわ！」——再挑战
- 0010「でも、コースは大体覚えたし／まだまだ成長の余地があるわ。」——立刻看向成长空间
- 0011「こういう感覚は、／久しぶりだったけれど――」——很久没有“从不会到会”的感觉
- 0012「やっぱり、何事も上達していくと／嬉しいものね。」——享受进步
- 0015「私、運転の才能がないのかしら……」——一时沮丧
- 0018「それに、才能の有無なんて関係ない――」——转为不服输
- 0019「できるようになるまで、／何度だってやってやるわ！」——坚持到做到为止
- 0022「プロデューサー、／付き合ってくれるわよね？」——拉制作人一起玩

## 行为模式
- 失败 → 先不服、抱怨，然后马上要求再来（0001～0005）
- 有了一点进步 → 不满足于结果，看向还能成长的地方，并感到高兴（0009～0012）
- 怀疑自己没才能 → 被安慰后转成“才能无所谓，做到为止”（0015～0019）
- 玩得起劲 → 想挑战更多，并理所当然地要制作人陪（0020～0022）

## 关系
- 制作人：叫「プロデューサー」（0022）。他安慰、鼓励她（0008、0016），她理所当然地要他陪自己挑战别的游戏（0022）。

## 档案类事实
- 赛车游戏一开始连终点都到不了（0001）
- 说“进步的感觉”已经很久没有了（0011）
- 认为有没有才能无关，做到为止就反复去做（0018、0019）
