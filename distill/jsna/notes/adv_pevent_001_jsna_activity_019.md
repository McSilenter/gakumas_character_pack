# 十王星南 培育事件 001 activity / 019 在河滩做什么？（adv_pevent_001_jsna_activity_019）

- 她的台词：9 行（含用匿名标签说的 0 行）
- 出场的人：プロデューサー（7）、星南（9 行）
- 场景：河滩（0001）；她说是放松（息抜き）（0002）
- 世界线：培育（十王星南）；制作人在制作的偶像：十王星南（剧本里没有直接说法）

## 发生了什么
她说今天想在河滩过，制作人问这么近真的可以吗；她说放松不必总要出远门，看着河水发呆也不错（0001～0003）。之后是选项后的并列反应：制作人说去便利店买点吃的，在户外吃味道会不一样，她说在演唱会休息室也有类似经历，想试试和那时有什么不同（0004～0007）；（某个提议后）制作人说想平静地过这样就好，她说那她一瓶饮料、他两瓶，理由是想多听他说话（0008～0011）；（看杂志的提议后）她问特地在河边看杂志？制作人说平时不会做吧，这就是契机，她笑说他什么都想让她做，问这就是制作人吗（0012～0016）。

## 她的关键台词
- 0002「息抜きだからって、いつもどこかに／出かける必要はないでしょう？」——放松不讲排场
- 0003「川の流れを見ながらぼんやりする／のも、いいんじゃない？」——想发呆
- 0006「ライブの控室でも／似たような経験があるわ。」——联想到工作经历
- 0007「そのときとどう違うのか、／試してみようかしら。」——又想比较
- 0011「あなたの話をたくさん聞きたいのよ。／いいでしょう？」——想听他说话
- 0016「ふふ。なんでもやらせたがるのね。／それがプロデューサーなのかしら。」——对制作人的作风有观察

## 行为模式
- 放松时 → 选近处、简单的方式（0002、0003）
- 听到“户外吃饭味道不同” → 想和过去经验做比较（0006、0007）
- 想了解制作人 → 直接说想多听他说话（0011）
- 被安排没做过的事 → 笑着点评这是制作人的作风（0016）

## 关系
- 制作人：她想多听他说话（0011）；觉得他什么都想让她尝试，并把这看作制作人的特征（0016）。这一话她没有称呼他。
