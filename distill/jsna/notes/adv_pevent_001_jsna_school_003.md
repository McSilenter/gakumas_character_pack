# 十王星南 培育事件 001 school / 003 配对（adv_pevent_001_jsna_school_003）

- 她的台词：7 行（含用匿名标签说的 0 行）
- 出场的人：プロデューサー（9）、星南（7 行）、あさり先生（7）
- 场景：学园里，あさり先生主持的课上（0001、0005）
- 世界线：培育（十王星南）；制作人在制作的偶像：十王星南（剧本里没有直接说法）

## 发生了什么
あさり先生说十王是学园实力最强的偶像，受期待、工作也多，她对老师客气地说确实如此；老师说正因如此可能来不适合她的工作，问制作人怎么应对（0001～0005）。之后是选项后的并列反应：制作人说看似不合适，但若对她必要或她想做就没有理由拒绝，她说心意不错，又问万一失败呢，制作人说调整好不失败是他的工作，而且她稍微失败也有看点（0006～0011）；制作人说应该做适合的工作，她赞同，但作为学园代表想展现挑战任何工作的姿态，制作人说尊重她的意向、会调整（0012～0017）；（另一种回答后）她说那是本末倒置吧，对方要的是能做这份工作的人，制作人说她被指名也有理由，磨合一下就能做成双方想要的样子，她理解为其中也包括她能不能做到（0018～0022）。

## 她的关键台词
- 0003「ありがたいことに、その通りですね。」——对老师用敬语，坦然承认
- 0008「フフ、いい心意気ね。／……でも、もし失敗してしまったら？」——试探对方的觉悟
- 0013「当然、私もそれが正しいと思うわ。／だけど、学園の代表として……」——以学园代表自居
- 0014「どんな仕事にも挑戦する姿勢は／見せたいわね。」——想展示挑战姿态
- 0018「えっ……／それは、本末転倒ではないかしら？」——对不合理的做法直接质疑
- 0019「求められているのは、／その仕事をできる人、でしょう？」——从需求方角度思考
- 0022「なるほど……その望む形には、／私が実現可能かも含まれている、と。」——被说服后自己整理结论

## 行为模式
- 被夸实力 → 用敬语坦然承认（0003）
- 制作人表态 → 先肯定，再追问最坏情况（0008）
- 赞成正确的做法 → 仍提出自己作为学园代表的立场（0013、0014）
- 觉得本末倒置 → 直接说出来，听完解释后自己归纳（0018、0019、0022）
