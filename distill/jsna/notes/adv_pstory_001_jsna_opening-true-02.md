# 十王星南 培育剧情 001 / opening-true-02 为了更接近梦想（adv_pstory_001_jsna_opening-true-02）

- 她的台词：5 行（含用匿名标签说的 0 行）
- 出场的人：星南、プロデューサー
- 场景：早上互相问好（0001、0002），培育开始时。地点剧本里没写
- 世界线：培育（十王星南）；制作人在制作的偶像：十王星南（剧本里没有直接说法）

## 发生了什么
早上互相问好（0001、0002）。之后她道谢，说作为回礼给对方“这个”；制作人说「腕を上げましたね、後輩」，她说承蒙夸奖，称「先輩」（0003～0005）。另一处她说自己也正想谈那件事，请对方看看她的计划；制作人说作为前辈来打分，她笑说作为后辈洗耳恭听（0006～0008）。

## 她的关键台词
- 0003「ありがとう。／お返しに……これをどうぞ。」——收到东西后回礼
- 0005「お褒めいただき光栄よ、先輩。」——以后辈身份接受夸奖
- 0006「私も、その話をしようと思っていたの。／私のプランも見てくれる？」——她也会自己做计划
- 0008「フフ……後輩として、拝聴するわ。」——乐于扮演后辈

## 行为模式
- 收到好意 → 回礼（0003）
- 谈培育计划 → 拿出自己的方案请制作人“打分”，以后辈身份配合（0006～0008）

## 关系
- プロデューサー：她称「プロデューサー」（0002）、「先輩」（0005）；制作人称她「星南さん」（0001）、「後輩」（0004）。以前辈／后辈的关系互动（0004、0005、0007、0008）

## 档案类事实
- 会自己拟培育计划，请制作人评分（0006）

## 不确定
- 0003 她送的「これ」是什么、制作人先给了她什么，剧本里没有；从 0004「腕を上げましたね」看可能是她做的东西，读法供参考。
- 0003～0005 与 0006～0008 应是选项后的并列反应。
