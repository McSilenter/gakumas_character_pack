# 倉本千奈 亲爱度剧情 / 第8话（adv_dear_kcna_008）

- 她的台词：45 行（含用匿名标签说的 0 行）
- 出场的人：千奈、プロデューサー
- 场景：她的首次 live 开演前（0001、0054、0059），她偷看过观众席（0004）；地点剧本没写明
- 世界线：亲爱度（倉本千奈）；制作人在制作的偶像：倉本千奈（0043、0046 她说「担当アイドル」，0051「先生がわたくしのプロデューサー／じゃなくなるなんて、嫌ですわ！」）

## 发生了什么
首次 live 快开始，制作人问她准备好没有，她得意地说完全没准备好，看了观众席肚子都疼了；但又说观众特地花时间花钱来看她，所以就算肚子疼、没自信，也不能让他们看到不争气的样子（0001～0008）。她回顾这半年一直是基础课，对被宠大的自己来说像地狱，唱歌跳舞这么简单的事要半年才做到（0011～0017）。她向制作人道谢，回顾爷爷要求半年内让她成为学园第一、做不到制作人就会被开除，而自己是学园最下位的劣等生，制作人总是温和地劝她别急、说在把她培养成出色的偶像前不会被开除（0020～0033）。然后她说自己看穿了：制作人从一开始就做好了半年被开除的觉悟，无视爷爷的要求，为她坚持稳健的培育（0035～0039）。她说自己很生气，因为制作人不了解自己的担当偶像：她不可能没有制作人还继续当偶像，她是任性的大小姐，不想制作人不再做她的制作人（0045～0051）。她宣言绝不让制作人被开除，要在这场 live 上让爷爷看到制作人的实力和成果，请制作人看着她成为出色的偶像（0053～0057）。

## 行为模式
- 紧张 → 先用得意的口吻说出示弱的话，然后从观众的角度给自己找出“不能退缩”的理由（0002～0008）
- 回顾过去 → 坦白说很辛苦，再承认自己的成长（0011～0017）
- 察觉对方为自己牺牲 → 先一条条说破，再抢先说出对方的说辞，表示“我很生气”（0035～0046）
- 表达依赖 → 用“任性大小姐”的说法理直气壮地说出不想失去对方（0047～0051）
- 依赖之后 → 转成行动宣言：由她来保住制作人（0052～0057）

## 关系
- 制作人：叫「先生」（0002、0020、0045）；制作人叫她「倉本さん」（0001），也称她「優秀な教え子」（0018）。她自称「この教え子」「担当アイドル」（0033、0046）。看穿制作人做好被开除的觉悟、为她坚持稳健的培育（0035～0038），说没有他就不能继续偶像活动，不想他不再当自己的制作人（0047、0048、0051），要在 live 上证明他的成果（0053～0055）
- 爷爷：她说爷爷要求半年内让她成为学园第一的偶像（0021），要在 live 上让爷爷看到制作人的实力（0054、0055）

## 档案类事实
- 首次 live 前，她说观众是花时间花钱来看她的（0005、0006）
- 从开始到这次 live 约半年，一直以基础课为主，从练基础体力开始（0011、0016、0026、0027）
- 制作人说她比预想的成长得快，是优秀的学生（0018）
- 自称「わがままお嬢様」（0050），自认被宠大（0012）
- 紧张时会肚子疼（0004）
