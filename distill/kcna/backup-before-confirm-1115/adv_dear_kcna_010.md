# 倉本千奈 亲爱度剧情 / 第10话（adv_dear_kcna_010）

- 她的台词：55 行（含用匿名标签说的 0 行）
- 出场的人：千奈、プロデューサー
- 场景：她提出要奖励（0001～0004），之后是第二天的休息日（0005），她 live 的疲劳还没消（0006）；地点剧本没写明
- 世界线：亲爱度（倉本千奈）；制作人在制作的偶像：倉本千奈（0036 制作人「担当アイドルに、ファン受けする趣味を／持ってもらおうかと。」）

## 发生了什么
她向制作人要首次 live 成功的奖励：明天休息日和她一起过，想出去玩（0001～0004）。第二天她 live 的疲劳没消、全身肌肉痛，感叹别的偶像定期做这么累的事，听说还有巡演，大叫会死的；又数起偶像休息少、课程严、竞争激烈，说当偶像前后都非常辛苦（0006～0021）。制作人问是否想放弃，她说完全没有，但反复在想：无知的自己轻率说出的梦想变成了大事，自己很幸运、处在能实现很多愿望的位置，所以责任也大，说“追梦真沉重”（0022～0030）。制作人提议做疲累时也能玩的事，拿出亲手做的羊毛毡挂件，说想让担当偶像有讨粉丝喜欢的爱好；她说他不解风情，但难得被他拜托，就答应了（0032～0039）。做的时候制作人把她的作品认成外星人、斗牛犬，她纠正说是小狗、是吉娃娃（0040～0058）。制作人说开始的契机轻一点也可以，问这半年是否快乐；她说辛苦的事绝对更多，但快乐的一瞬太美好，停不下来，说是制作人教了她这么“坏的游戏”（0045～0055）。她把挂件送给制作人，说自己运动不好、手笨、没耐性、爱撒娇，以前总是轻率开始又半途而废，昨天和今天却把轻率开始的事完成了；最后说不管选哪个计划都一定辛苦又快乐，因为是和最喜欢的先生一起（0059～0072）。

## 行为模式
- 有了成果 → 理直气壮地向制作人要奖励，要的是和他一起过休息日（0002～0004）
- 身体累垮 → 夸张地哀叹，把辛苦一条条数出来，但被问是否放弃时立刻否定（0006～0023）
- 安静下来 → 说出认真的反省：轻率的梦想、自己的幸运和由此来的责任（0024～0030）
- 制作人的提议带有工作目的 → 先嫌他不解风情，再因为“难得被拜托”答应（0037～0039）
- 被问“快乐吗” → 先说一半又改口说辛苦更多，再承认快乐的瞬间太美好（0050～0053）
- 完成了一件事 → 把成品当心意送给对方，并回顾自己“以前总半途而废”的过去（0059～0066）

## 关系
- 制作人：叫「先生」（0001、0029、0072）；制作人叫她「倉本さん」（0014、0045）。向他要和他一起过休息日的奖励（0003）；把当偶像的“坏游戏”归到他头上（0054、0055）；送他亲手做的挂件（0059、0060）；说「大好きな先生」（0072）

## 档案类事实
- 首次 live 后第二天全身肌肉痛（0006、0007）
- 有一天的休息日（0003），说是很久没休息了（0004）
- 第一次做羊毛毡挂件，做的是吉娃娃，送给了制作人（0043、0058～0060）；羊毛毡挂件是制作人教的，原本是制作人亲手做的（0033～0035）
- 自认运动不好、手笨、没耐性、爱撒娇，以前做事常半途而废（0040、0063、0064）
- 说这次是第一次把一件事做成（0062、0066）
- 说自己很幸运、处在能实现很多愿望的位置（0027）

## 不确定
- 0004 她说想出门，0005 之后第二天两人似乎没有出门而是在一起做手工，地点剧本没写。
- 0065「昨日も、今日も」、0066完成的事，按上下文分别指首次 live 和羊毛毡挂件，剧本没明说。
- 【译文】0055「こんなに悪い遊びを……／教えてくださったのですから。」译成“教会了我这么坏的游戏……/所以您才教我的。”，后半是误译，原文是“因为您教了我这么坏的游戏”，是接 0054「先生のせいですわね。」的理由。
