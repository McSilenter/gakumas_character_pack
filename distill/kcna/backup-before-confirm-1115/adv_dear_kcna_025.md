# 倉本千奈 亲爱度剧情 / 第25话（adv_dear_kcna_025）

- 她的台词：47 行（含用匿名标签说的 0 行）
- 出场的人：千奈（47 行）、星南（9）、プロデューサー（6）、燕（6）、莉波（5）
- 场景：先是她的参选演说（0001～0028），之后和制作人谈演说（0029～0041），再去见叫她过去的星南、莉波、燕（0039、0042）；地点剧本没写明
- 世界线：亲爱度（倉本千奈）；制作人在制作的偶像：倉本千奈（0029～0037）

## 发生了什么
她向全校发表参选演说：入学以来一直作为学生会一员看着学姐们为学园做事；现任会长星南是大家的榜样，今年夏天第三次成为『一番星』，是理想的会长，但她做不到、因为她是倉本千奈而不是十王星南（0001～0012）。她说当上会长会用自己的方式尽全力：通过偶像活动提高学园知名度，从入学考试最后一名的视角把学园理念和偶像科的苦乐讲给更多人听，并让星南的革新措施在来年后继续（0013～0022）。最后她宣言无论选举结果如何都会为学园尽力，不管谁当会长都乐意协助，请大家投她一票（0023～0028）。制作人说演说很好，但和之前练习的不一样；她说又忘词了，照心里想说的说了，讲着讲着发现这些承诺不当会长也做得到，就说出来了，制作人笑说很有她的风格（0029～0037）。她以为星南叫她去是要鼓励，说了选举活动的安排，又说千奈帝国有4名偶像、“谦虚有时是失礼”，宣布胜利已定（0039～0060）。星南、莉波、燕却向她道歉，说生徒会的3年生决定支援其他候选人，在选举里成为她的对手；她惊慌失措（0061～0073）。剧情经过参照 atbm、jsna 笔记。

## 行为模式
- 公开场合讲话 → 先肯定前辈的成就，再坦白自己学不来，然后说用自己的方式做（0006～0014）
- 讲着讲着发现真相 → 即使对自己不利（承诺不当会长也能做到），也照实说出、并宣言会协助任何人（0024～0026、0034～0036）
- 被指出失误 → 爽快承认、道歉，说出当时怎么想的（0032～0036）
- 伙伴多、形势好时 → 用刚学来的道理当理由，得意地宣布胜利（0054～0060）
- 信任的人突然站到对面 → 完全没料到，只会惊慌（0064、0066）

## 档案类事实
- 她入学以来一直是学生会的一员（0003）。
- 她入学考试是最后一名（0018）。
- 星南今年夏天第三次成为『一番星』（0008，她的话）。
- 她的公约：通过偶像活动提高学园知名度、讲学园理念和偶像科的体验、让星南的革新措施在来年后继续（0016～0022）。
- 她宣言无论选举结果如何都会为学园尽力、协助任何当选者（0024～0026，宣言）。
- 她的参选演说又忘词，内容和练习时不一样（0031～0033）。
- 星南说近年学生会选举越来越像活动，主要是她推动的；候选人和支援者会开 live（0049～0051，星南的话）。
- 生徒会的3年生（星南、莉波、燕）决定支援其他候选人（0065，星南的话）。
