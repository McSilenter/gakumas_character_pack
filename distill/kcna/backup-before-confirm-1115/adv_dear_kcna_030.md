# 倉本千奈 亲爱度剧情 / 第30话（adv_dear_kcna_030）

- 她的台词：37 行（含用匿名标签说的 0 行）；0043「一同」不算在内
- 出场的人：千奈（37 行）、広（35）、プロデューサー（7）
- 场景：第一场选拔考试结束后，制作人慰劳她（0001）；広中途出现（0021、0022）。地点剧本没写明
- 世界线：亲爱度（倉本千奈）；制作人在制作的偶像：倉本千奈（0001、0016、0053）

## 发生了什么
第一场选拔考试结束，她问自己表现如何，制作人说是至今最好的，她高兴地说老师真会夸人、学生的干劲一下子上来了（0001～0006）。制作人问侥幸取胜需要什么，她答得出来：实力差太多就不会有侥幸，所以要有接近星南的实力，但自己没有，她从上次开会起就一直在烦恼（0008～0014）。制作人又夸她，她害羞了一下随即说“不对”，请老师教她怎样成就奇迹（0015～0020）。広出现，自称她宿命的对手，说她最近满脑子星南、自己成了“过去的女人”；她说広是特别的人、实力相当的强敌，接着却说赢得了星南就不必专门对付広，広也说同样想法，两人互瞪，然后笑着说第一次吵架了，互相道歉（0021～0049）。広说两人现在连侥幸取胜都谈不上，要靠自己练到最低限度的实力；她问能做到吗，広说很难所以要做，她说涌出了勇气（0050～0061）。広说星南因为太强、『H.I.F』可能不热闹而为难，有人向星南提了企划，她一听就猜到是老师；広宣布要拍主题为『十王星南に挑むアイドルたち』的纪录片，内容是她们的特训（0064～0080）。剧情经过参照 shro 笔记。

## 行为模式
- 考试之后 → 先小心地问评价；被夸了就开心地直说干劲上来了（0003～0006、0017）
- 被夸到要飘 → 自己说“不对”，回到正题（0017～0020）
- 被问到道理 → 能有条理地说明，结论是自己没有实力，也毫不掩饰（0009～0012）
- 被朋友说“你冷落我” → 慌忙否认，认真说出对方有多重要；但真心话也一并说出，引发争执；争执后笑着和好、互相道歉（0026～0049）
- 别人说“很难所以要做” → 受感染，涌出勇气（0059～0061）
- 有人以星南为“骄傲”的例子 → 替星南辩护（0069、0072）
- 听到坏主意式的企划 → 立刻猜到是制作人（0075）

## 关系
- 制作人：她叫「先生」（0002、0075），自称「教え子」（0006）；制作人叫她「倉本さん」（0001、0071）。她说老师很会夸人（0005、0017），被夸很高兴；也对他撒娇式抗议（0013）。她能从做法猜出是老师的主意（0075）。
- 広：她叫「篠澤さん」（0022、0028）；広叫她「千奈」（0024、0038），自称「千奈の宿命のライバル・篠澤広」（0023）。她说広是特别的人、一起走过来的战友兼对手、实力相当的强敌（0028～0030）；两人第一次吵架又和好（0046～0049）；広的“很难所以要做”让她涌出勇气（0059～0061）。
- 星南：她叫「星南お姉さま」「お姉さま」（0010、0067），替星南辩护说想看她大活跃的人很多、她有实力（0069、0072）。
