# 活动 006 班级对抗初星大运动会 / main-01 第1话（adv_event_006_main-01）

- 她的台词：13 行（含用匿名标签说的 0 行）
- 出场的人：佑芽、千奈、莉波、星南（只在 0003～0007 开头交代任务，千奈不在该场景）
- 场景：校内，佑芽向千奈、莉波报告在后山发现的温泉（0027）
- 世界线：活动 006；制作人在制作的偶像：看不出

## 发生了什么
佑芽跑来说在后山迷路了，千奈先没反应过来，隔了一会儿才惊叫，说要马上叫救援，被佑芽反问"救谁"，她道歉自己太急。佑芽拿出温泉的照片，想用来办生徒会活动，千奈说那是自家别墅里的温泉。佑芽正准备放弃，她马上说不必，愿意提供温泉，并说要带路。剧情经过参照 hume 笔记。

## 她的关键台词
- 0024「花海さん！　ごきげんようですわ！」——看到佑芽时的招呼，称她「花海さん」
- 0028「まあ、遭難ですか！」——听到"遭难"，先带着礼貌的口气惊叹
- 0029「……ええっ！？　遭難！？」——隔了一会儿才反应过来
- 0031「た、大変ですわ！／すぐに救助を呼びませんと！」——第一反应是叫救援
- 0034「すみません……／早とちりをしてしまいました。」——被指出后立刻道歉
- 0043「これはうちの温泉ですわ。」——看到照片，平静地说这是自家的温泉
- 0046「この温泉、わたくしの別荘の／敷地内にある温泉です。」——补充说明位置
- 0054「いいえっ！／その必要はありませんわ！」——佑芽想放弃时，立刻阻止
- 0055「花海さんがうちの温泉を／見つけたのもなにかの縁！」——把偶然看作缘分
- 0056「イベントをするなら、／わたくし、温泉を提供いたします！」——主动提出提供温泉
- 0059「生徒会のためなら当然ですわ！」——对佑芽的惊喜，认为是应该的
- 0060「ご案内しますから、／わたくしについてきてください！」——带路

## 行为模式
- 听到紧急情况 → 反应慢半拍，然后过度反应（叫救援），事后立刻道歉（0028、0029、0031、0034）
- 看到对方为自己家里的东西而失望 → 马上说"不必"，主动提供，还把它说成缘分和"为了生徒会理所当然"（0054～0059）
- 提供帮助之后 → 立刻带路，不拖延（0060）

## 关系
- 佑芽：叫「花海さん」（0024、0055）；佑芽叫她「千奈ちゃん」（0048）。
- 莉波：莉波叫她「千奈ちゃん」（0050）；在她过度反应时由莉波让大家冷静。

## 档案类事实
- 家里的别墅敷地内有温泉（0043、0046）。
- 说话习惯：自称「わたくし」，句尾用「ですわ」（0031、0043、0056）。
- 已经是生徒会成员（"为了学生会"，0059；星南让佑芽、千奈、莉波组队，0005 是星南说）。

## 不确定
- 0028 与 0029 连续两次"遭难"的反应，前者像礼貌的应答，后者才是惊讶，剧本没有说明她中间的想法。
- 0043「うちの温泉」：温泉是她家所有，还是别墅附带，0046 才补充；"うち"与"わたくしの別荘"并用，没有矛盾。
