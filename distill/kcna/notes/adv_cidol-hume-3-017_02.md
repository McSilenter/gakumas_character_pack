# P卡 花海佑芽【纯白画页与水彩绘就的主角】 / 第2话 纯白画页与水彩绘就的主角 第2话（adv_cidol-hume-3-017_02）

- 她的台词：12 行（含用匿名标签说的 0 行）
- 出场的人：佑芽（19 行）、広（15）、千奈（12）、プロデューサー（8）、一同（2）
- 场景：『H.I.F』结束后的合宿（0001），三人在休息时互相研鑽；千奈和広都因肌肉痛动不了（0019）
- 世界线：亲爱度（花海佑芽）·P卡；制作人在制作的偶像：佑芽（0001～0014）

## 发生了什么
前半是制作人与佑芽谈新曲的练习，千奈不在场。0015 起，佑芽说明自己在急着练新曲，広羡慕她总是被制作人出难题，千奈提议利用肌肉痛的时间继续“偶像的话”。三人轮流互相问技巧：千奈说演唱会是表现自己世界、邀请粉丝、带路。广说她的技巧是想象最强的自己再拉近。最后千奈说用学到的力量打倒佑芽。剧情经过参照 hume 笔记。

## 她的关键台词
- 0018「わたくしたちも負けては／いられませんわ。」——听到佑芽被制作人加练新曲后，鼓劲
- 0019「この……わたくしと篠澤さんが筋肉痛で／動けない時間を有効に使って……」——提议利用肌肉痛时间
- 0024「わたくしだけの力ではありませんわ。／素晴らしいステージギミックを／用意していただきましたし――」——被夸演出时，归功于舞台装置
- 0025「周囲の皆さまが、／がんばってくださいましたもの。」——也归功于周围的人
- 0033「こんなに恐ろしい頼まれごとを／されたのははじめてですわ……」——佑芽要学她的魅力来打败她，她半开玩笑地称恐怖
- 0035「アイドルのライブとは、／みずからの世界を表現すること……／そう思っておりますわ。」——她对演唱会的理解
- 0036「わたくしのために用意された楽曲を、／わたくしの解釈で広げていって……」——具体做法：用自己的解释扩展曲子
- 0037「ファンの皆さまを招待し、／案内するのだと。」——把观众看作被邀请的客人
- 0040「綺麗なライブを見せてくださいますわ。」——称赞広的演出
- 0054「教わった力で、／花海さんを叩きのめしますわ～～～！」——在互相传授之后，宣布要用所学打败佑芽

## 行为模式
- 被夸 → 先归功于装置与周围的人，不独占（0024、0025）
- 被请教技巧 → 先说“不知道算不算技巧”，再说出自己的价值观（0034～0037）
- 被要求把自己的方法用来对付对方 → 半开玩笑地表示可怕，但仍然认真回答（0033）
- 轮到别人时 → 反过来夸对方的特点，再问对方的诀窍（0039、0040）
- 学到东西 → 立即表态要用它去赢（0054）

## 关系
- 佑芽：叫「花海さん」（0054）；佑芽叫「千奈ちゃん」（0022）；佑芽是她的粉丝俱乐部成员（0026，佑芽的话）
- 広：叫「篠澤さん」（0019、0039）；广叫她「千奈」
- 制作人：本篇前半佑芽与制作人谈话，她不在场

## 档案类事实
- 肌肉痛，因此与広暂时动不了（0019）
- 在广看来，千奈的演出从出道时就满足感高（0023，広的话）
- 她理解的演出：表现自己的世界、扩展为自己准备的曲子、邀请并带领粉丝（0035～0037）
