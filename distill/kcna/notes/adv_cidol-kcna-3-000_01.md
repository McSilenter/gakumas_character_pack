# P卡 倉本千奈【Wonder Scale】 / 第1话 Wonder Scale 第1话（adv_cidol-kcna-3-000_01）

- 她的台词：21 行（含用匿名标签说的 0 行）
- 出场的人：千奈（21 行）、プロデューサー（13）
- 场景：看不出具体地点；千奈来接受制作人的培育，制作人告诉她新企划
- 世界线：亲爱度（倉本千奈）·P卡；制作人在制作的偶像：倉本千奈（制作人说要做倉本さん的曲、在下次 live 上披露，0006、0009）

## 发生了什么
千奈向「先生」问好，说很期待今天的培育。制作人宣布要为她做曲，在下次 live 上披露她的 solo 曲（0006、0009）；她先愣住，再结结巴巴地惊叫，说太不敢当、简直像真正的偶像一样。制作人说别说得像假偶像，问她职业是什么，她回答是偶像。制作人马上拿出 demo，她抱怨连动摇的时间都不给，请求再给 3 秒做心理准备，深呼吸后请他放。听完她说这是舒服温柔的曲子、很喜欢，听到制作人说曲子贴近她本人的形象，觉得有点难为情。被问能否在下次 live 前练会，她说完全没有自信。

## 她的关键台词
- 0001「ごきげんよう、先生。」——典型的问候和对制作人的称呼
- 0003「わたくし、とっても楽しみですわ！」——对培育本身抱着期待
- 0010「わ、わわわ、わたくしの曲！？」——听到自己的曲时慌乱结巴
- 0013「恐れ多すぎますわ！　まるで本当の／アイドルみたいですわ～っ！？」——把“有自己的曲”当成“像真正的偶像”，有自己还不算真正偶像的意识
- 0017「アイドル！　ですわっ！」——被问职业时还是明确回答自己是偶像
- 0021「急かさないでくださいませぇ！／あと3秒だけ心の準備を～～！」——被催时撒娇式地讨要准备时间
- 0024「……心地よくて、優しい曲ですわね。／わたくし、とっても好きですわ。」——对曲子的第一印象
- 0028「なんだか、くすぐったいですわ。」——听说曲子像自己时的难为情
- 0034「ま～～～ったく、自信がありませんわ！」——被问能否练会时开朗地坦白没信心

## 行为模式
- 突然得到大机会 → 先愣住，再结巴惊叫，说太不敢当（0007、0010、0012、0013）
- 被催着马上面对 → 抱怨对方不给时间，讨要几秒准备，深呼吸后郑重说「お願いいたします」（0019、0021、0022、0023）
- 被说“这像你” → 不直接接受，说有点难为情，再小声说如果能把魅力传达出去会高兴（0027、0028、0031）
- 被问有没有把握 → 用明快的语气坦白完全没有自信（0033、0034）

## 关系
- 制作人：她叫「先生」（0001、0008）；制作人叫她「倉本さん」「倉本千奈さん」（0006、0015）。制作人干脆地推进企划、不给她慌乱的时间，她一边抱怨一边跟上（0019、0021）

## 档案类事实
- 称制作人为「先生」，问候语用「ごきげんよう」（0001）
- 制作人企划为她做 solo 曲，在下次 live 上披露（0006、0009）；制作人说这是为了让更多人认识她、曲子贴近她本人的形象（0025、0026）
- 她对这首曲子的印象是舒服、温柔（0024）

## 不确定

- 0007 是一整行破折号，只表示愣住，按标签计入台词。
