# P卡 倉本千奈【每天、都有新发现！】 / 第2话 每天、都有新发现！ 第2话（adv_cidol-kcna-3-001_02）

- 她的台词：20 行（含用匿名标签说的 0 行）
- 出场的人：千奈（20 行）、プロデューサー（13）
- 场景：看不出具体地点；两人在看制作人拍的照片，途中制作人又拍了一张
- 世界线：亲爱度（倉本千奈）·P卡；制作人在制作的偶像：倉本千奈（制作人说她的魅力，并把她称作很特别的偶像，0007、0009）

## 发生了什么
千奈看着制作人拍的照片，夸先生摄影也很厉害；制作人说因为是制作人，她说那是谦虚，在很厉害的制作人里，她的先生也是特别的。制作人回说她也是很特别的偶像，接连夸她上镜、姿态举止有真正的气品、外表可爱不输人气偶像，她越听越高兴，说太夸学生了。这时她发现制作人趁机拍了照，抗议不该突然袭击；看了照片后说是不太想给粉丝看的脸。制作人说自然的表情和动作也是很大的魅力，看着就有精神，粉丝也一定一样想。她说既然先生这么说，就让大家看看她有点丢人的、软趴趴的样子；制作人说正是这种地方，她却不明白是哪种地方。

## 她的关键台词
- 0002「先生は……カメラの腕前も／素晴らしいのですわね。」——自然地夸制作人
- 0006「わたくしの先生は特別なのだと。」——表达对制作人的特别信赖
- 0015「まぁ～～～～～～♪」——被连续夸奖时越来越高兴
- 0017「教え子を褒めすぎですわぁ～♡」——自称“教え子”，把制作人当老师
- 0020「ひ、ひどいですわ先生！　／不意を突くだなんて！」——被偷拍时抗议
- 0023「うっ……ファンの皆さまには、／あまりお見せしたくない顔ですわ……」——在意给粉丝看的形象
- 0029「……先生がそこまでおっしゃるなら。／皆さまにも見ていただきましょう。」——因为制作人的话改变主意
- 0030「わたくしの、ちょっぴり情けない／フニャッとした姿をッ！」——豁出去的说法
- 0033「そういうところって、／どういうところですのぉ～～～？」——不明白自己的魅力在哪

## 行为模式
- 制作人谦虚 → 不接受，反过来强调先生是特别的（0004、0005、0006）
- 被连续夸奖 → 先迟疑问“是吗”，接着「まぁ」越叫越高兴，最后说夸太多了（0008、0011、0013、0015、0017）
- 被偷拍到不好看的表情 → 抗议，看照片后说不想给粉丝看（0020、0022、0023）
- 制作人认真说那是魅力 → 被说服并大方答应公开（0029、0030）
- 被说“正是这种地方” → 不明白自己哪里有魅力，追问（0032、0033）

## 关系
- 制作人：叫「先生」（0002、0016）；制作人叫她「倉本さん」（0007、0024）。她说在制作人里她的先生是特别的（0006），自称教え子（0017）；制作人说她是很特别的偶像（0007）

## 档案类事实
- 制作人说她上镜（フォトジェニック）、姿势举止有真正的气品、外表可爱（0010、0012、0014）——制作人的评价
- 她自称是先生的「教え子」（0017）

## 不确定
- 0031 制作人说“まさに、そういうところです”，指的是她刚才那种豁出去又有点丢人的样子，具体指哪一点没明说。
