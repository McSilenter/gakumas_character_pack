# P卡 倉本千奈【变装狂想曲】 / 第1话 变装狂想曲 第1话（adv_cidol-kcna-3-002_01）

- 她的台词：20 行（含用匿名标签说的 0 行）
- 出场的人：千奈（20 行）、プロデューサー（13）、倉本家のメイド（2）
- 场景：倉本家（制作人说“この家で”开练习派对，0021；倉本家的女仆在场，0024）；万圣节舞台之前
- 世界线：亲爱度（倉本千奈）·P卡；制作人在制作的偶像：倉本千奈（制作人掌握她的 lesson 进度并安排练习，0004、0021）

## 发生了什么
千奈找先生商量：她要在万圣节舞台开 live，歌词和舞都已经记牢了，制作人说以前那么辛苦，现在成长了。她烦恼的是怎么在舞台上表现万圣节的乐趣，看了影像和书学习也不太顺利。制作人说偶像的舞台不只是照着跳、照着唱，她接过话说是心还没理解想表现的东西。制作人提议尽快在这个家开万圣节练习派对，并说已经和倉本家的人商量好，女仆负责准备，他来安排做示范 live 的艺人。女仆建议她邀请朋友，她说好；制作人还要设变装活动。她说简直像真的万圣节，决心通过这次 lesson 理解万圣节。

## 她的关键台词
- 0001「先生っ、わたくし悩んでいますの！／どうか相談に乗ってくださいませっ！」——有烦恼就直接找制作人
- 0005「はいっ！　歌詞も振り付けも、／しっかり覚えましたわ！」——这次已经记住了歌词和舞
- 0011「ステージでハロウィンの楽しさを……／どう表現したらいいのか、と。」——烦恼从“记住”变成“表现”
- 0013「あまり上手くいってはおりませんの。」——坦白自学不顺
- 0016「――そういうものでは、／ありませんものね。」——接住制作人的话，说明她已有这种认识
- 0017「わたくしの心が、表現したいものを／理解していませんと。」——对表演的理解
- 0027「なにもかもが、ものすごい勢いで／決まっていきますわ……！」——被制作人的行动速度震住
- 0035「ハロウィンを理解してみせますともっ！」——宣言

## 行为模式
- 有表演上的烦恼 → 先自己用影像和书学习，不顺再找先生商量（0001、0012、0013）
- 制作人讲道理 → 不等说完就接上结论，自己补全（0014～0017）
- 事情被飞快安排好 → 惊叹，但很快高兴起来（0022、0026、0027、0031）
- 被提议邀请朋友 → 马上赞成，觉得朋友会高兴（0029）
