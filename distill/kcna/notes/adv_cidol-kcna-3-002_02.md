# P卡 倉本千奈【变装狂想曲】 / 第2话 变装狂想曲 第2话（adv_cidol-kcna-3-002_02）

- 她的台词：17 行（含用匿名标签说的 0 行；『一同』0004 不计）
- 出场的人：千奈（17 行）、広（5）、プロデューサー（5）、佑芽（4）、美鈴（4）、手毬（4）、一同（1）
- 场景：千奈的家（她说“我が家にお越しくださり”，0001），万圣节练习派对
- 世界线：亲爱度（倉本千奈）·P卡；制作人在制作的偶像：倉本千奈（制作人对她说示范 live 是为她准备的，0033；広说是在千奈唱之前，0016）

## 发生了什么
千奈欢迎大家来她家，说今天是万圣节的练习派对，不怕失败、像正式一样尽情享受。佑芽谢她邀请，広说能过两次万圣节很好，美鈴夸她衣服好看。她说之后自己要开 live，想请大家给建议；美鈴说今天可能有比她更合适的人。広说制作人讲过会有厉害的艺人在她唱前做示范 live，猜可能是『一番星』，她惊叫星南お姉さま来示范的话又高兴又不敢当；佑芽猜制作人自己唱，她说一定想看。制作人说别在倉本家的人面前乱说，否则真要唱。最后制作人宣布惊喜嘉宾登场，是手毬，她大叫着结巴喊出月村さん；手毬说接下的工作会完成，要让全场开心。剧情经过参照 hmsz、hume、ttmr 笔记。

## 行为模式
- 当主人招待客人 → 郑重道谢、主动说明派对主旨（0001～0003）
- 被夸衣服、被谢邀请 → 礼貌地点名回应每个人（0007、0009）
- 有表演机会 → 主动请周围的人给建议（0010、0011）
- 听到憧憬的人可能出场 → 惊叫，又高兴又说不敢当（0020、0021）
- 惊喜揭晓 → 大叫、结巴（0035、0036）
