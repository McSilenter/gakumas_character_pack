# P卡 倉本千奈【变装狂想曲】 / 第3话 变装狂想曲 第3话（adv_cidol-kcna-3-002_03）

- 她的台词：22 行（含用匿名标签说的 0 行）
- 出场的人：千奈（22 行）、手毬（7）、プロデューサー（4）
- 场景：万圣节练习派对上，手毬的示范 live 刚结束，接下来轮到她唱
- 世界线：亲爱度（倉本千奈）·P卡；制作人在制作的偶像：倉本千奈（手毬对她说“あなたのプロデューサー”，0009）

## 发生了什么
手毬问示范 live 有没有参考价值，千奈说又帅又凛然、有趣又让人心跳，非常开心，但怪先生和月村さん把大家吓过头了。手毬说那正是万圣节的醍醐味，是她的制作人说的；她说先生真是个淘气鬼。手毬提醒下一个轮到她唱，她这才想起来，发现要在手毬的 live 之后唱，处境艰难。制作人说这是适度的紧张，她抱怨先生总是笑着给学生试炼，但还是结结巴巴地说要试试。制作人说期待不输手毬的 live，她惨叫门槛太高，说自己唱跳都远不及手毬；但接着说看了示范后明白了：在万圣节派对上唱歌重要的是和最喜欢的人们一起庆祝的热闹时光、很多点心和笑容，还有送出惊喜的恶作剧之心。剧情经过参照 ttmr 笔记。

## 她的关键台词
- 0004「わたくし、とっっても／楽しい気分になりましたわ～っ！」——对示范 live 的感想
- 0007「わたくしたちを驚かせすぎですわっ。」——对惊喜安排的抗议
- 0011「先生ったら……／もう……いたずらっ子なのですから。」——对制作人的亲昵责怪
- 0017「しらぬうちに……とんでもない逆境に／立たされていたようですわ……」——发现处境后的惊慌
- 0020「この教え子に、いつもそうやって……／笑顔で試練をぉ……」——说制作人“总是”这样给她试炼
- 0021「わ、わわわ、わたくし、／やってみますわっ！」——害怕也接下
- 0025「わたくし、歌もダンスも、／月村さんの足元にも及びませんのにぃ！」——对自己与手毬差距的认识
- 0026「――――ですけれどっ！」——从示弱转向
- 0031「はいっ！　それは、共にお祭りを祝う、／大好きな方々との騒々しい時間。」——她理解到的万圣节
- 0033「サプライズをお届けする／悪戯心ですわ～っ♪」——把“惊喜”收为自己的答案

## 行为模式
- 看完别人的表演 → 热情地具体称赞（0002～0004）
- 被惊喜吓到 → 事后用亲昵的口吻责怪制作人（0007、0011）
- 突然被放进困难处境 → 先惊慌、抱怨“总是这样”，然后结巴着说要试（0016、0017、0020、0021）
- 被设高门槛 → 先惨叫、承认差距，再用「ですけれど」转折说出自己的领悟（0024～0029）

## 关系
- 手毬：叫「月村さん」（0006、0025）；手毬叫她「あなた」（0012）。她说自己唱跳都远不及手毬（0025）；手毬问她领悟到了什么（0030）
- 制作人：叫「先生」（0006、0019）；制作人叫她「倉本さん」（0010、0022）。她说先生是淘气鬼、总是笑着给她这个学生试炼（0011、0020）

## 档案类事实
- 她自认唱歌和舞蹈都远不及手毬（0025）
- 她自称先生的「教え子」（0020）

## 不确定
- 0020 她说制作人“いつも”这样笑着给试炼，是她的感受。
