# P卡 倉本千奈【欢迎来到初星温泉】 / 第2话 欢迎来到初星温泉 第2话（adv_cidol-kcna-3-005_02）

- 她的台词：22 行（含用匿名标签说的 0 行）
- 出场的人：千奈（22 行）、広（8）、佑芽（7）、プロデューサー（3，都是她回想中的话）
- 场景：温泉里（佑芽问“なんで温泉に入ってるんだっけ”，0006）；中间夹着她回想和制作人的对话
- 世界线：亲爱度（倉本千奈）·P卡；制作人在制作的偶像：倉本千奈（她说先生被“倉本千奈のプロデュース”忙得不可开交，0018）

## 发生了什么
千奈、佑芽、広在泡温泉，佑芽忘了为什么来，広和千奈说明经过：三人为她的报答出主意，结论是让先生去温泉休假、消除疲劳。但制作人谢绝了，她说先生之后很长时间一天休息也没有，对身体不好，于是她下了决心：一定要让被她的制作忙坏的先生休息，为此连倉本家的力量也不惜动用，并当面这么宣告了。広说这点很像她、很喜欢，佑芽说喜欢她坦率说出真心话，她请她们别打断。她接着说，先生想了想，提出让她先去温泉休假，然后自己也休假。她说当然明白，那一定是先生察觉到她最近日程过密很累，为了让她休息的提议。佑芽、広说知道她最近在勉强自己、很担心，今天一起好好休息；她说就这么办，觉得很暖和，想让先生也体验。剧情经过参照 hume、shro 笔记。

## 她的关键台词
- 0002「生き返りますわ～～～～～～♡」——泡温泉的感想
- 0010「先生に、温泉休暇を／取っていただこうと！」——报答的点子
- 0014「先生ったら、ずーっと先まで、／1日もお休みがないそうなのです！」——制作人没有休息
- 0016「お身体によくないですわ！」——担心制作人的身体
- 0018「倉本千奈のプロデュースに、／忙殺されてしまっている先生を……」——意识到制作人为她忙碌
- 0020「倉本の力を使うことさえ／躊躇しませんわ、と。」——为了让他休息，宣告不惜动用倉本家的力量
- 0024「も、もう……話の腰を／折らないでくださいませ。」——被夸时害羞地打断
- 0031「もちろん、わかっておりますわ。／わたくしの先生ですもの。」——对制作人意图的理解
- 0033「わたくしを休ませるための／提案だったに決まっているのです。」——看穿提议是为了她
- 0040「ぜひ……先生にも、／味わっていただかないと。」——休息时还想着先生

## 行为模式
- 重要的人不休息 → 担心身体，下决心并当面宣告不惜一切也要让他休息（0014、0016、0017～0021）
- 被朋友夸“很像你” → 害羞地请她们别打断（0022～0024）
- 制作人换个方式让她先休息 → 明白那是体贴她的提议，接受（0031～0033、0038）
- 自己舒服时 → 想到要让先生也体验（0039、0040）

## 关系
- 制作人：叫「先生」（0010、0031）；回想中制作人叫她「倉本さん」（0027）。她说“わたくしの先生ですもの”，认为先生察觉到她累了（0031、0032）
- 佑芽：佑芽叫她「千奈ちゃん」（0023、0034），说知道她在勉强自己（0035）；这一话她没有称呼佑芽
- 広：広叫她「千奈」（0008、0022），说喜欢她这一点、担心她（0022、0036）；这一话她没有称呼広

## 档案类事实
- 她最近日程过密、很累（0032，她自己的推断；佑芽说她最近很忙、在勉强自己，0034、0035）
- 据她说，制作人之后很长时间一天休息都没有（0014）

## 不确定
- 0013、0026、0027 是她回想中制作人的话，不是温泉现场的对话。
- 0020 “倉本の力を使う”具体指什么没说；是她对制作人的宣告，并没有真的动用。
- 0033 先生的提议是为了让她休息，是她的推断（佑芽 0030 也说“それってきっと……”）。
