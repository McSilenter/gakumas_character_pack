# P卡 倉本千奈【雪融之时】 / 第2话 雪融之时 第2话（adv_cidol-kcna-3-009_02）

- 她的台词：40 行（含用匿名标签说的 0 行）
- 出场的人：千奈（40 行）、プロデューサー（6）
- 场景：看不出具体地点；接上一话，她向制作人讲自己过去的事
- 世界线：亲爱度（倉本千奈）·P卡；制作人在制作的偶像：倉本千奈（制作人说见过的倉本家的人都很尊重她，0005、0006）

## 发生了什么
千奈不知道讲什么过去的事，制作人请她讲家人：他见过的她的家人都很尊重她，忙中还常聚在一起为她开派对。她说以前不是这样的：父母、祖父母、亲戚都很忙，小时候几乎见不到，寂寞得哭过。制作人说小孩子这样很正常，她说普通孩子是这样，她不是：亲人都在倉本集团身居高位，要守护很多部下和他们的家人，不能因为她的任性妨碍他们的职责。她说现在能笑着说见不到父母祖父母不算什么，当时却做不到，哭闹了很多，但小小年纪也明白哭了也不会改变什么，父母不会来安慰她。哄她的是同龄的见习女仆，作为她的照顾人一直守护着任性的她，因为太可靠，她直到最近都以为对方比自己年长。她说是那个女孩直接去找爷爷谈判的：明明是世代侍奉倉本家、受过严格的守分寸教育的身份，为了她鼓起了勇气，那有多大的风险，对方一定比现在的她更清楚。结果一心工作的爷爷当天就辞去几个职务，变成现在这个非常疼孙女的爷爷，召集亲族命令今后要留出和家人在一起的时间，一年设几次亲族和伙伴聚会的场合，名目总是庆祝她这一点她觉得不太好。她说这是她能想起的最早的记忆，是重要的家人增加的那天的故事。

## 行为模式
- 被问起过去 → 先犹豫讲什么，被给了题目后条理清楚地从头讲起（0001、0002、0008～0011）
- 讲到难过的过去 → 不回避，承认哭过，并区分“现在能笑着说”和“当时做不到”（0012、0019～0021）
- 讲故事时话题跳跃 → 自己察觉并向听者道歉（0030、0031）
- 讲到别人为她冒险 → 强调对方的勇气和风险，把功劳归于对方（0032～0037）
- 对家人以她为名目的聚会 → 带点不好意思地说名目总是庆祝她（0043）

## 关系
- 制作人：叫「先生」（0008、0030）；制作人叫她「倉本さん」（0005）、「あなた」（0006）。她把最早的记忆讲给先生听（0044、0045）
- 父母：称「お母様」「お父様」（0023）；小时候几乎见不到（0010、0011）
- 爷爷：称「お爺様」（0032、0039）；以前一心工作，因见习女仆的直接谈判，当天辞去几个职务，变成很疼孙女的爷爷（0039、0040）
- 同龄的见习女仆（没有说名字）：她的照顾人，哄她、守护她，为她去找爷爷谈判（0026、0027、0032、0035）；称作「彼女」（0032）

## 档案类事实
- 父母、祖父母、亲戚都在倉本集团身居高位，很忙，她小时候几乎见不到，寂寞得哭过（0010～0012、0015）
- 她有一位同龄的见习女仆当照顾人；那人家里世代侍奉倉本家；她直到最近都以为对方比自己年长（0026～0029、0033）
- 那位见习女仆直接找爷爷谈判，爷爷当天辞去几个职务，召集亲族要求留出家人时间，一年设几次亲族和伙伴的聚会，名目多是庆祝她（0032、0039～0043）
- 她说这是她能想起的最早的记忆（0045）
