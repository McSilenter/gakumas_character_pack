# P卡 倉本千奈【雪融之时】 / 第3话 雪融之时 第3话（adv_cidol-kcna-3-009_03）

- 她的台词：23 行（含用匿名标签说的 0 行）
- 出场的人：千奈（23 行）、プロデューサー（13）
- 场景：看不出具体地点；接上一话，她讲完过去之后和制作人谈话
- 世界线：亲爱度（倉本千奈）·P卡；制作人在制作的偶像：倉本千奈（制作人说寻找倉本千奈魅力根源的尝试有了成果，0012、0013）

## 发生了什么
制作人夸她很会讲故事，千奈说先生一有机会就夸学生，会当真的；制作人说只说真话，她害羞地笑。她问只讲了丢人的过去，有没有帮上忙，制作人说有很大的成果：她出道很久以前就有可靠的粉丝，倉本千奈的偶像经历并不是不满一年。她说说过头了，她不像星南お姉さま那样多年积累了严格的 lesson；制作人说当代『一番星』是最锋利的偶像，但她的过去并不是单方面输了。她不敢相信自己有胜过星南的地方，制作人说她被很多人喜欢、被家人爱着长大，有回应期待的意志、总想尽到被爱的责任，这种高贵的精神正是身经百战的偶像。她说被这样评价就不能再说丧气话了，说遇到先生以后增加了很多新粉丝，和先生一样重要；偶像要对所有粉丝公平，但下一场 live 不为新粉丝、也不为最喜欢的先生，而是为从以前就在的粉丝——为家人唱，唱一首华丽、开朗、祝贺温暖重逢的歌。

## 行为模式
- 被夸 → 说先生总是夸学生，半开玩笑说会当真，然后害羞地笑（0002～0006）
- 被评价得很高 → 先说过头了，拿星南做比较来否定（0018、0019、0023）
- 制作人讲出具体理由 → 接受，说不能再说丧气话（0027、0028）
- 定下表演的意义 → 先讲原则（对所有粉丝公平），再说明这一次的例外和对象（0032～0035）

## 关系
- 制作人：叫「先生」（0007、0029），并称「あなた」（0029）；制作人叫她「倉本さん」（0021）、「あなた」（0015、0024）。她说遇到先生后有了很多新粉丝，说「大好きな先生」（0029、0030、0034）
- 星南（未出场）：叫「星南お姉さま」（0018、0023）；她认为自己没有胜过星南的地方（0023）；制作人称星南为当代『一番星』（0020）
- 家人：她把家人称作从以前就在的粉丝，下一场 live 为他们唱（0035）

## 档案类事实
- 制作人说她的偶像经历不满一年（0017，制作人以否定的形式说“1年未満……ではなかった”，字面指出道不到一年）
- 她说自己不像星南那样多年接受严格的 lesson（0018、0019）
- 遇到制作人以后增加了很多新粉丝（0030）
- 下一场 live（女儿节派对）要为家人唱（0035）

## 不确定
