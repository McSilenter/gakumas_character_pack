# P卡 倉本千奈【向天空约定】 / 第2话 向天空约定 第2话（adv_cidol-kcna-3-014_02）

- 她的台词：24 行（含用匿名标签说的 0 行）
- 出场的人：広（24 行）、千奈（24）
- 场景：看不出具体地点；広看出她在烦恼，来听她说
- 世界线：亲爱度（倉本千奈）·P卡；制作人在制作的偶像：倉本千奈（広说“千奈のプロデューサー”，0022）

## 发生了什么
広问千奈是不是在烦恼，说因为是朋友、一直看着她，有不对劲马上就知道；她说広的友情让人难为情，请広听她的烦恼。広总结：要以她的意见为基础做新曲订购资料，所以她得想好做什么曲；新曲在选举期间的那场 live 披露，日程超紧。她大叫正是如此，说资料一做好专业人员会火速制作，但她完全没自信在 live 前学会新曲。広说要一秒也不能耽误地把资料做出来；她说先生什么提示都不给。広说她的制作人和自己是同类，猜得出意图，但说出来就太直白了所以不能说，制作人大概也一样，希望她自己找到答案。広让她闭眼想象披露新曲的舞台上看到的光景，想象选举 live 和『H.I.F』，说和『N.I.A』不同、和平时不同，好好看眼前的人，剩下的只是把想法化为语言。她道谢，被问有没有灵感时说完全没有，但觉得能做到了：先生说新曲会成为强力武器、理由做了就知道，広也给了认真为她着想的建议，那就没有理由做不到；她说要马上在这里给出答案，请広帮她做资料。広答应，叫她“千奈会長”。剧情经过参照 shro 笔记。

## 行为模式
- 被朋友看穿烦恼 → 先难为情，再老实请对方听（0002、0004、0008）
- 处境被点明 → 大声认同，坦白没自信（0015～0018）
- 对方似乎知道答案 → 直接请对方告诉自己（0023）
- 没有灵感但收到大家认真的话 → 照实说没灵感，但以“大家认真为我着想”为理由断定自己能做到（0038～0044）
- 下定决心后 → 立刻行动并请朋友帮忙（0045、0046）

## 关系
- 広：叫「篠澤さん」（0002、0036）；広叫她「千奈」（0001）、最后叫「千奈会長」（0047）。広说因为是朋友一直看着她（0003），给她想象舞台的建议（0028～0034），答应帮她做资料（0047）
- 制作人（未出场）：她抱怨先生不给提示（0021），并转述先生的话作为信心来源（0040、0041）；広说她的制作人和自己是同类（0022）

## 档案类事实
- 新曲要在选举期间的 live 上披露，日程很紧（0012、0014）
- 资料做好后会有专业人员赶制新曲（0016）
