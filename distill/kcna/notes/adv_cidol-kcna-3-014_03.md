# P卡 倉本千奈【向天空约定】 / 第3话 向天空约定 第3话（adv_cidol-kcna-3-014_03）

- 她的台词：35 行（含用匿名标签说的 0 行）
- 出场的人：千奈（35 行）、プロデューサー（17）
- 场景：不是她的房间的某处（制作人说在这里见她很少见，她说平时在她房间开会，0008、0009）；她说等不到放学后就来了（0003）
- 世界线：亲爱度（倉本千奈）·P卡；制作人在制作的偶像：倉本千奈（制作人审阅她的新曲资料，0017～0019）

## 发生了什么
千奈跑来对先生说新曲方案做好了，又为等不及放学就来道歉；制作人说是夸她工作快，她说因为有可靠的亲友帮忙。制作人说在这里见她很少见，她说平时都在她房间开会、觉得新鲜；制作人说偶尔在这边谈也好，可以商量想对氷渡さん保密的事，她以为是什么秘密商量而心动，结果是和女仆们改善关系的事，她说和想的不同但也重要。制作人看完资料说很豪华、会是很好的曲子，她放下心来。被要求口头说明答案，她说听了広的建议后想象『H.I.F』舞台和选举 live，眼前浮现的是初星学园的大家、学生会的姐姐们；以前她是对着来看倉本千奈 live 的粉丝唱跳，这次舞台上很多是初星学园的人、是和平时不同的人，观众层不同、要瞄准的对象不同，这就是先生和広说不出口的直白结论；如果直接被告诉，她的心态会和现在不同。她想着要给学园的大家看什么舞台、要向照顾过她的姐姐们传达什么，和広一起想着就做出了这么多资料。制作人说会是今后大舞台的最强武器；她担心想做的太多准备很辛苦，制作人说正是全力使用倉本之力的时候，代大家说实现大小姐的任性是我们的喜悦；她说先生也说得像香名江一样，于是请他转达大家：拜托了。

## 行为模式
- 事情做成了 → 等不及约定时间就跑去报告，事后为此道歉（0001、0003）
- 被夸 → 把功劳归给帮忙的亲友（0005）
- 以为会听到浪漫的秘密 → 心动地追问，落空后仍认真看待对方的事（0013、0014、0016）
- 说明自己的结论 → 按“想象观众—对比过去—得出结论—理解别人为何不说”的顺序讲清楚（0024～0038）
- 担心准备辛苦被告知有倉本家支持 → 不再推辞，大方地请大家帮忙（0046、0051、0052）
