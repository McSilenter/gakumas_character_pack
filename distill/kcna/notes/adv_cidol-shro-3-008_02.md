# P卡 篠澤広【幸福千层酥】 / 第2话 幸福千层酥 第2话（adv_cidol-shro-3-008_02）

- 她的台词：9 行（含用匿名标签说的 0 行）
- 出场的人：広（12 行）、佑芽（11）、千奈（9）、プロデューサー（8）
- 场景：学内学生可自由使用的共用空间厨房（0009、0012）；広和制作人要当天开始料理特训
- 世界线：亲爱度（篠澤広）·P卡；制作人在制作的偶像：篠澤広（佑芽称“プロデューサーさん”，広称“プロデューサー”，0007、0010；制作人与広商量料理特训，0001～0005）

## 发生了什么
広要求当天就开始料理特训，制作人同意。千奈和佑芽出现，千奈说“话我们听到了”，佑芽宣布今天不许用共用厨房。制作人问理由，佑芽忘了，千奈说刚商量过，说到一半自己也忘了；広把两人叫过去，三人小声商量后千奈想起来，对制作人宣布她和佑芽“正在和篠澤さん吵架”。制作人指出她们刚才还亲密地密谈，千奈笑着装糊涂。広说吵架到明天、用料理比赛了结是“设定”，千奈说这次不会忘了。最后制作人说没别的地方，広提议去制作人家。剧情经过参照 hume 笔记。

## 她的关键台词
- 0008「話は聞かせてもらいましたわ――／篠澤さん。」——有气势地登场
- 0018「もう……花海さんたら。／先ほど打ち合わせをしたばかりですわ。」——先数落佑芽忘词
- 0020「……………………なんでしたっけ？」——随即自己也忘了
- 0023「……思い出しましたわっ。」——被広提醒后
- 0024「聞いてくださいませ、プロデューサー。／わたくしと花海さんは、なんと――」——郑重地宣布
- 0025「篠澤さんと喧嘩中なのです！」——宣布的内容
- 0027「うふふ、なんのことやら／わかりませんわ。」——被戳穿密谈后装糊涂
- 0032「もう忘れませんわ！」——听了“设定”后表决心

## 行为模式
- 参加朋友的计划 → 用夸张的台词登场、宣布（0008、0024、0025）
- 说到一半忘了 → 先数落别人，结果自己也想不起来，要広提示（0018～0023）
- 谎言被戳穿 → 笑着说“なんのことやら”装傻到底（0027）

## 关系
- 広：叫「篠澤さん」（0008、0025）；広叫她「千奈」（0021）。配合広的“吵架”设定，宣布与広吵架中（0025、0031 広）
- 佑芽：叫「花海さん」（0018、0024）；佑芽叫她「千奈ちゃん」（0017）。两人一起拦厨房
- 広的制作人：叫「プロデューサー」（0024）；制作人叫她「倉本さん」（0015）

## 档案类事实
- 学内学生可自由使用的厨房只有共用空间这一间（0012 佑芽）

## 不确定
- 拦厨房和“吵架”是谁安排的不清楚：0018 千奈说刚和佑芽商量过，0021 広把两人叫过去小声商量，0031 広说这是“設定”，0039～0040 広随即提议去制作人家。是不是広事先和她们串通、为了去制作人家，剧本没明说。
