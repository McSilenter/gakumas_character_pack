# P卡 篠澤広【褪色】 / 第3话 褪色 第3话（adv_cidol-shro-3-012_03）

- 她的台词：9 行（含用匿名标签说的 0 行）
- 出场的人：広（28 行）、佑芽（11）、千奈（9）
- 场景：看不出具体地点；広向千奈、佑芽讲自己和制作人之间的事，并转述制作人的话
- 世界线：亲爱度（篠澤広）·P卡；制作人在制作的偶像：篠澤広（佑芽称“広ちゃんのプロデューサーさん”，0004；千奈称“篠澤さんのプロデューサー”，0020）

## 发生了什么
広转述制作人的话（0001、0002），千奈发出陶醉的声音，佑芽说那简直是结婚的约定；広说自己非常高兴，千奈说“憧れますわぁ”。広说今天很紧张，因为有很多事一直没告诉两人，千奈说她能说出来自己很高兴、更喜欢篠澤了，并说今后也请多关照。千奈接着问広的制作人今后打算怎么做，広转述：要更多展现只有亲近的人才知道的各种篠澤広。千奈称赞这是很好的计划；但広接着转述要让粉丝体验刺激、一起提心吊胆，千奈说风向有点不对。最后広说现在满是热切的心情，想快点唱。剧情经过参照 hume 笔记。

## 她的关键台词
- 0003「ふわぁ～～～～～～～～～～～～～♡」——听到広转述的制作人的话时陶醉
- 0010「憧れますわぁ……」——对広和制作人的关系表示向往
- 0013「いいえ、いいえ――話してくださって、／嬉しかったですわ。」——広为隐瞒而紧张时，先否定她的顾虑
- 0014「篠澤さんのこと、／もっと好きになりましたもの。」——说出更喜欢広了
- 0018「これからも、／よろしくお願いいたしますわねっ♪」——确认今后的友谊
- 0021「いったいどうする／おつもりなのでしょう？」——关心広今后的方向
- 0028「まあ、それは素敵な計画ですわ！」——对“展示更多面的広”的计划立刻称赞
- 0033「あら……？　なにやら雲行きが……」——听到“刺激”的方针后察觉不对

## 行为模式
- 听到浪漫的话 → 发出陶醉的声音、说“憧れます”（0003、0010）
- 朋友坦白隐瞒的事而不安 → 连说“いいえ”否定对方的担心，说自己更喜欢她了（0013、0014）
- 朋友的新计划 → 先热情称赞，听到奇怪的方向后才小心地表示疑虑（0028、0033）

## 关系
- 広：叫「篠澤さん」（0014、0020）；广在这一话里称她和佑芽为“ふたり”（0012），没有叫她名字。広坦白很多瞒着的事后，她说更喜欢広了（0013、0014）
- 佑芽：同在场，一起回应広；这一话里没有称呼佑芽
- 広的制作人：称“篠澤さんのプロデューサー”（0020），对他的话陶醉、对他的计划先称赞后疑惑（0003、0028、0033）
