# P卡 篠澤広【奇迹正是现在(ﾟ∀ﾟ)！】 / 第2话 奇迹正是现在(ﾟ∀ﾟ)！ 第2话（adv_cidol-shro-3-014_02）

- 她的台词：6 行（含用匿名标签说的 0 行；不含一同0048，见「不确定」）
- 出场的人：広（23 行）、佑芽（7）、美鈴（7）、千奈（6）、プロデューサー（5）、一同（1）
- 场景：広和制作人远征大阪、live 前一天（0008、0023）；広在外面和学园里的2組同伴视频通话，千奈在通话的另一头
- 世界线：亲爱度（篠澤広）·P卡；制作人在制作的偶像：篠澤広（制作人说“担当アイドルの不安を消すのは、／プロデューサーの仕事”，0046）

## 发生了什么
広给2組的同伴打视频电话，千奈先问看不看得见她们。広说制作人带她去了很多地方，佑芽说是在炫耀约会，千奈说好羡慕。広说给大家买了一样的礼物（大阪限定的たこやきテクノドッグ），千奈说要一起戴上。広问明天 live 上能不能讲大家的事，千奈说当然可以；広说要向粉丝宣传テクノドッグ，千奈说広对粉丝的影响力无法估量。美鈴看出広在紧张，広承认有点不安，佑芽说旁边听着的制作人一定会想办法，千奈对制作人说“篠澤さん就拜托您了”。剧情经过参照 hmsz 笔记。

## 她的关键台词
- 0005「篠澤さん！　わたくしたちの姿、／見えていらっしゃいますか？」——通话接通后先确认画面
- 0012「うらやましいですわ～♪」——对“约会炫耀”的反应
- 0019「素敵ですわ！　／ぜひ、一緒に身につけましょう。」——听说礼物是成套的，提议一起戴
- 0024「もちろんですわ！」——広问能否在 live 上讲大家的事，马上答应
- 0030「篠澤さんの……ファンの皆さまへの／影響力は、はかりしれませんものね。」——认真地附和佑芽的话
- 0041「篠澤さんのこと、お任せいたします。」——把広托付给她的制作人

## 行为模式
- 朋友分享开心的事 → 直率地说羡慕（0012）
- 收到成套的礼物 → 想和大家一起戴（0019）
- 朋友问能不能做某事 → 毫不犹豫地答应（0024）
- 朋友不安 → 郑重地拜托她身边的制作人照顾她（0041）

## 关系
- 広：叫「篠澤さん」（0005、0030、0041）；这一话広没有单独叫她。同为2組的同伴（0001 広）；称赞広对粉丝的影响力（0030），把広托付给制作人（0041）
- 佑芽、美鈴：一起和広通话；这一话里她没有称呼两人
- 広的制作人：在通话中对他说“お任せいたします”（0041）

## 档案类事实
- 和広、佑芽、美鈴同在2組（0001 広“2組の／みんな”，通话对象是千奈、佑芽、美鈴，0005～0008）
- 広给她买了大阪限定的たこやきテクノドッグ，和大家成套（0017、0018）
