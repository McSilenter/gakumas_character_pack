# P卡 篠澤広【未知万千 广阔无限】 / 第2话 未知万千 广阔无限 第2话（adv_cidol-shro-3-016_02）

- 她的台词：11 行（含用匿名标签说的 0 行）
- 出场的人：千奈（11 行）、広（11）、星南（9）
- 场景：生徒会室（0014 千奈“どうして生徒会室に！？”）；星南向千奈宣布举办搭档选拔
- 世界线：亲爱度（篠澤広）·P卡；制作人在制作的偶像：篠澤広（这一话玩家制作人没有出场。千奈自己在这条线里的制作人是星南：星南说“あなたのプロデューサーである／この私”，0009）

## 发生了什么
星南对千奈说，要举办选拔她的双人组合搭档的选秀，起因是千奈的爷爷来委托，说千奈想开组合 live，让星南想办法；千奈被问有没有头绪，承认有。星南说作为千奈的制作人，她和倉本グループ合作准备了盛大的选秀，千奈大叫请先跟她商量。広突然出现，宣布报名当千奈的搭档，千奈“まぁっ♡”。広说难关正合她意，千奈笑说很有篠澤的风格。広说两人是宿命的对手、实力相当，千奈已是出色的偶像，那现在的自己也一样；千奈说虽然像自夸，但她最清楚自己的对手篠澤広是非常出色的偶像。

## 行为模式
- 被长辈或前辈先斩后奏 → 大叫“请先商量”，但不拒绝（0011、0012）
- 朋友主动要和自己组合 → 欢喜地“まぁっ♡”（0016）
- 朋友说两人实力相当 → 接受“对手”的说法，并用最大声的方式夸对方（0029～0031）

## 关系
- 星南：叫「星南お姉さま」（0003）；星南叫她「千奈」（0002、0008）。这条线里星南是她的制作人（0009），替她准备了选秀，她希望星南先和她商量（0011）
- 広：叫「篠澤さん」（0014、0021、0028），称“わたくしのライバル・篠澤広”（0031）；広叫她「千奈」（0013、0022）并说两人是“宿命のライバル”（0024）
- 爷爷：星南说是“あなたのお爺様”来委托的（0004）；千奈说自己有头绪（0007）

## 档案类事实
- 在这条线里，她的制作人是星南（0009 星南）
- 想开组合 live 的事传到了爷爷那里，爷爷向星南提出委托（0004～0007）
- 视広为自己的“ライバル”，认为広是非常出色的偶像（0031）
