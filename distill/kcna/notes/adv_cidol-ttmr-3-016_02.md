# P卡 月村手毬【究竟从何时起】 / 第2话 究竟从何时起 第2话（adv_cidol-ttmr-3-016_02）

- 她的台词：14 行（含用匿名标签说的 0 行）
- 出场的人：手毬、千奈、美鈴
- 场景：千奈的别墅，秘密特训的第一天（0001-0004）；别墅里有不输初星学園的レッスン施設（0009）
- 世界线：亲爱度（月村手毬）·P卡；制作人在制作的偶像：看不出（美鈴说和制作人商量过，0021，未说制作谁）

## 发生了什么
手毬被带到秘密特训地点，原来是千奈的别墅，千奈很兴奋地迎接并请两人在特训期间住下。美鈴说是以教千奈唱歌为交换请她协助，千奈得知要参加特训，还被要求三人互相教唱歌，慌张地说自己没有能教的。手毬和美鈴都称赞了她的歌，千奈害羞，最后元气地答应一起特训。剧情经过参照 ttmr、hmsz 笔记。

## 她的关键台词
- 0002「わたくしの別荘ですわ～～～～～♪」——揭晓特训地点，语气雀跃，口癖「ですわ」
- 0004「さっそく本日から、／お願いいたしますわね。」——以主人的口吻郑重迎接
- 0008「特訓中、この家の施設は、／ご自由にお使いください。」——慷慨提供自家设施
- 0014「月村さんと秦谷さん、おふたりとの／お泊まり会だなんて！」——为能和两人过夜而兴奋
- 0015「わたくし、嬉しくって……！　／楽しみにしておりましたの。」——坦率说自己早就期待
- 0017「はいっ！　やりましたわね、秦谷さん♪」——和美鈴击掌般的默契，说明她参与了邀请手毬的安排
- 0024「わ、わわ、わたくしが……／おふたりに歌を……？」——被要求教人时慌乱结巴
- 0025「教えられることなんてありませんわ！」——自我评价低，断然否定自己有可教的
- 0029「ま、まぁ……月村さんたら。」——被夸后害羞
- 0049「はいっ！」——被鼓励后爽快应下特训

## 行为模式
- 对喜欢的人到访 → 明显兴奋，用大量感叹和邀约招待（0002、0011、0013-0015）
- 被要求去教别人 → 先结巴慌张，断言自己没有可教的（0024、0025）
- 被当面夸奖 → 不正面接话，害羞地用结巴加「まぁ……」带过（0029）
- 对方说要特训加油 → 立刻用「はいっ！」响应（0049）

## 关系
- 手毬：叫「月村さん」，手毬叫她「倉本千奈」「あなた」；千奈盼着和她一起过夜（0003、0014）；手毬说喜欢她的ライブ，她害羞（0028、0029）
- 美鈴：叫「秦谷さん」；两人对邀请手毬的计划有默契（0017，美鈴0018说「作戦通り」）；美鈴称她「倉本さん」（0044）

## 档案类事实

- 她与美鈴有交换约定：协助特训，美鈴教她唱歌（0006）
