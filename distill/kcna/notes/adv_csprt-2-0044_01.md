# S卡 2-0044【ピューとシューの二重奏】 / 第1话 咕噜咕噜噗噗（adv_csprt-2-0044_01）

- 她的台词：13 行（含用匿名标签说的 0 行；0011、0015 为配合手毬扮演兔子「千奈ぴょん」时说的话，见不确定）
- 出场的人：千奈（13 行）、手毬（7 行）
- 场景：户外草地（道边的草），时间看不出。
- 世界线：S卡【ピューとシューの二重奏】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
千奈照着课上说的“像草笛一样吹气”的要求，拿草放在嘴边吹，结果草进了嘴，很苦。手毬看到，说“在吃叶子”，她辩解是意外。手毬说只有兔子才会吃道边的草，叫她“千奈ぴょん”，她配合扮演兔子，之后发现手毬改称呼，请求仍然叫她「千奈」，因为被手毬叫“千奈”觉得帅。手毬同意，说愿意陪她一起吹草笛。剧情经过参照 ttmr 笔记。

## 她的关键台词
- 0001「シュ～……む、難しいですわ～！／お口に当てて、ぷーっと吹く……」——一个人在练习，口癖「ですわ」。
- 0002「ふえぇぇぇっ口に草がぁ～～！／に、にがいですわ～～～！」——草进了嘴，苦得惊叫。
- 0005「ご、誤解ですわ！　授業で／草笛を吹くようなブレスと言われ――」——被撞见后赶紧解释原因是课上的要求。
- 0008「不慮の事故ですわ！！」——被说“还是吃了”后强调是意外。
- 0011「千奈だぴょん♪／葉っぱモグモグ、美味しいぴょん！」——被说像兔子后立刻配合扮演兔子。
- 0015「千奈ぴょん、にんじんは大好物ですわ！／お野菜好き嫌いするなんてそんな……」——继续用「千奈ぴょん」自称回答，认真地说不挑食。
- 0016「はっ――違いますわ！／わたくし、ですわ！！」——意识到自己用了新的自称，立刻纠正为「わたくし」。
- 0017「あの！　これまで通り、千奈と／呼んでいただけないでしょうかっ！」——正式请求手毬像以前一样叫“千奈”。
- 0019「月村さんから千奈、と呼ばれるのが／かっこよくて好き……なんですわ。」——说出理由：喜欢被手毬叫“千奈”，觉得帅气。

## 行为模式
- 被撞见出丑 → 慌张辩解，强调是误会和意外（0004、0005、0008）
- 被调侃 → 立即顺着对方的话演下去（0011、0015）
- 意识到自己说得太投入 → 马上收回，回到「わたくし」（0016）
- 有想坚持的事 → 用敬语郑重地请求，并直说理由（0017、0018、0019）

## 关系
- 手毬：叫「月村さん」（0004、0019）；手毬叫她「千奈」，这一篇里被叫“千奈ぴょん”；她请求手毬仍然叫「千奈」，说这样叫“かっこよくて好き”（0017、0019）。

## 档案类事实
- 课上有“像吹草笛一样的呼吸”的要求，她为此尝试吹草（0005）。
- 她说自己对胡萝卜是大好物，并说不会挑食蔬菜（0015，为扮演兔子时说的话）。

## 不确定
- 0011、0015 是配合手毬的“兔子”调侃做的扮演，0015「にんじんは大好物ですわ」是否也是她本人的真实喜好，剧本没有明说。
- 0019 她说被叫“千奈”觉得帅气，手毬此前是否一直叫她“千奈”，本篇没有交代。
- 无【冲突】。
