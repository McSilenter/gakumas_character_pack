# S卡 2-0052【あん・どぅ・とろわっ！】 / 第2话 向往的芭蕾舞（adv_csprt-2-0052_02）

- 她的台词：11 行（含用匿名标签说的 0 行；0014 为沉默「………………………………」）
- 出场的人：千奈（11 行）、清夏（8 行）
- 场景：做柔软练习的地方，接着第1话的情景。
- 世界线：S卡【あん・どぅ・とろわっ！】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
清夏向千奈推荐芭蕾拉伸，并展示视频。千奈说有视频的话自己也能做，由此猜清夏是不是喜欢芭蕾。清夏含糊地反问为什么，千奈说因为她知道芭蕾拉伸，并说自己对芭蕾有兴趣，最喜欢《天鹅湖》。清夏兴奋地聊起群舞和独舞，千奈沉默了一下，然后笑着说“果然是喜欢的”。清夏说被千奈带着说出来了。千奈请清夏看看自己的芭蕾拉伸是否做对，清夏答应。

## 她的关键台词
- 0003「動画を観ながらなら、／わたくしにもできそうですわ！」——看了清夏给的视频，觉得自己也能做。
- 0004「……もしかしてバレエ、／お好きなのですか？」——察觉到清夏对芭蕾的熟悉。
- 0006「バレエのストレッチをご存じだったので／もしかしたらと思いまして！」——说明理由：她知道芭蕾拉伸。
- 0007「実はわたくし、／バレエに興味がありますの！」——坦白自己对芭蕾有兴趣。
- 0009「あまり詳しくはないのですが、／一番好きなのは白鳥の湖ですわ！」——说自己不太懂，但最喜欢《天鹅湖》。
- 0010「明るく楽しい公演も好きですが、／やはり王道な演目は外せません！」——喜欢轻快的演出，但更看重经典曲目。
- 0011「繊細な感情表現から大胆な動きまで、／バレエは本当に素敵です！」——说出芭蕾的魅力。
- 0015「うふふ。／やっぱり、お好きなのですわね。」——听了清夏的热情之后，笑着确认清夏喜欢。
- 0017「もしよろしければ、わたくしがちゃんと／バレエストレッチができているか、」——请求清夏检查（上半句）。
- 0018「見ていただけませんか？」——请求清夏检查（下半句）。

## 行为模式
- 注意到对方细微的熟悉感 → 联想到对方的兴趣，并说明依据（0004、0006）
- 谈到自己有兴趣的事 → 先谦虚（“不太懂”），然后明确说出最爱（0009、0010、0011）
- 对方在含糊 → 不追问，等对方自己热情地说，然后笑着确认（0014、0015）
- 想继续一起做 → 郑重提出请对方检查（0017、0018）

## 关系
- 清夏：叫她以外的称呼在本篇没有出现；清夏叫她「ちなっち」（0016 清夏）；她察觉到清夏喜欢芭蕾，并拜托她看自己做拉伸。

## 档案类事实
- 她对芭蕾有兴趣，不太了解，但最喜欢《白鳥の湖》（0007、0009）。
- 她喜欢轻快的演出，也认为经典曲目不可缺（0010）。
- 她认为芭蕾从细腻的感情表现到大胆的动作都很棒（0011）。
