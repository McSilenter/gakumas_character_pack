# S卡 3-0003【お姉ちゃんに任せなさい！】 / 第3话 躲避球对决！（adv_csprt-3-0003_03）

- 她的台词：6 行（含匿名标签 0 行）
- 出场的人：咲季（8）、千奈（6）、佑芽（6）
- 场景：打躲避球（ドッジボール）的比赛之后；地点、时间看不出
- 世界线：S卡【お姉ちゃんに任せなさい！】；制作人在制作的偶像：看不出

## 发生了什么
咲季在躲避球比赛里赢了佑芽。千奈惊讶于咲季赢了，称赞她太厉害，说咲季是自己的救命恩人。咲季得意，佑芽问为什么是救命恩人，千奈说咲季把她从杀手般的投球里救了出来。咲季让千奈以后有无理的比赛就叫她，千奈叫她「咲季お姉さま」，咲季很高兴。剧情经过参照 hski、hume 笔记。

## 她的关键台词
- 0006「……は、花海さんに……／ドッジボールで勝っちゃいましたわ。」——对结果惊讶，称咲季为「花海さん」
- 0007「花海さんのお姉さま……／スゴすぎますわぁ……！」——称咲季「花海さんのお姉さま」，惊叹
- 0009「素敵ですわ！　最高ですわ！／かっこ可愛らしいですわ！！」——连续称赞，用「ですわ」
- 0010「命の恩人ですわぁ～～～♡」——夸张地称咲季是救命恩人
- 0013「わたくしを殺人ショットの脅威から／救ってくださった英雄ですわ！」——解释救命恩人的含义
- 0015「はいっ！　咲季お姉さま！」——接受咲季的提议，改叫「咲季お姉さま」

## 行为模式
- 对方出乎意料地强 → 惊叹并连串称赞，用词夸张（0006、0007、0009）
- 被问为什么说得这么夸张 → 认真地解释自己得救了（0013）
- 被对方提出照顾 → 立即回答，使用新称呼（0015）
- 自称「わたくし」，句尾用「ですわ」（0006、0013）

## 关系
- 咲季：先称「花海さんのお姉さま」，后称「咲季お姉さま」；咲季也很高兴被这样称呼（0007、0015）
- 佑芽：称「花海さん」（0006），指佑芽；佑芽称她「千奈ちゃん」（佑芽 0012）

## 档案类事实
- 她被「殺人ショット」似的投球威胁过（0013）；是哪个场合，本篇没说明

## 不确定
