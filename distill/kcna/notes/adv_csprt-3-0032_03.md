# S卡 3-0032【プロデュースって大変ね】 / 第3话 交给我吧（adv_csprt-3-0032_03）

- 她的台词：7 行（含用匿名标签说的 0 行）
- 出场的人：千奈（7）、星南（9）、学園長（4）
- 场景：与星南的个人レッスン前（0001、0003、0020）；地点剧本没写
- 世界线：S卡【プロデュースって大変ね】；制作人在制作的偶像：千奈（制作人是星南；0008、0009：学園長问倉本千奈的制作方针，星南答）

## 发生了什么
千奈高兴地向星南问好，说一直期待着个人レッスン，被星南夸可爱、坦率、好孩子，害羞起来。星南转述学園長那里的谈话：基础レッスン之外很快就要开始工作，千奈的爷爷还要她今夏在H.I.F成为『一番星』。千奈慌了，指出星南也一样不讲道理，并强调自己是入学试验最下位却要立刻去工作，对星南的“交给我”半信半疑。

## 她的关键台词
- 0001「ごきげんよう、星南お姉さま！」——见面的问候，称星南为「お姉さま」
- 0003「お姉さまとの個人レッスン、わたくし／ずっと楽しみにしておりました。」——说自己一直期待着与星南的个人レッスン
- 0005「えへへ……ど、どうしましたの、急に。／恥ずかしいですわ。」——被夸之后害羞，说「恥ずかしいですわ」
- 0016「お、おお、お姉さまはお爺様のことを／言えないと思いますわ！」——慌乱中反驳星南，说星南和爷爷一样不讲道理
- 0017「入学試験最下位のわたくしを、そんな！／いきなり！　お仕事に！？」——自称入学试验最下位，对立刻被安排工作感到惊慌
- 0019「ほんとですのぉ……？」——对星南说“交给我”半信半疑

## 行为模式
- 被直接夸奖 → 笑着害羞，问怎么突然这样（0005）
- 听到要立刻工作和『一番星』的要求 → 慌乱，连声结巴，并拿自己的成绩说事（0016、0017）
- 被保证「任せておきなさい」 → 仍然不放心，拖长语尾问（0019）

## 关系
- 星南：她称「お姉さま」「星南お姉さま」；星南称她「千奈」（0001、0002）；她期待与星南的个人レッスン（0003）
- 爷爷：她称「お爺様」，爷爷对她有『一番星』的期待（0015、0013）

## 档案类事实
- 千奈自称入学试验最下位（0017）
- 千奈的爷爷是倉本爺，向学園長提出要求（0012、0015）
- 千奈用「ですわ」「わたくし」的大小姐口吻说话（0001、0003、0005）
