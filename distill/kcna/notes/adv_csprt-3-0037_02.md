# S卡 3-0037【すっかり秋色ですわね！】 / 第2话 快乐的采购（adv_csprt-3-0037_02）

- 她的台词：11 行（含用匿名标签说的 0 行）
- 出场的人：千奈（11）、広（9）
- 场景：搬运文化祭用品的路上（0001、0003），有坡道（0016）；地点剧本没写明
- 世界线：S卡【すっかり秋色ですわね！】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
千奈拎着重物，觉得花海一定很轻松。広拎着一大堆胶带，说超过一公斤，当做肌肉训练，脸色似乎不好，千奈要帮她拿。広说要分一半给千奈，却发现千奈的袋子是空的，底部破了洞，胶带滚下坡去。千奈慌忙追赶，広一边说着快呀快呀，最后说买东西很开心。

## 她的关键台词
- 0001「うん、しょ……けっこう重いですわ。」——说东西挺重
- 0002「ふぅ……ふぅ……花海さんなら、／きっと軽々なんでしょうね。」——边喘边想到花海能轻松搬
- 0005「あぁっ！　篠澤さんの顔色が……！／わたくし、まだ持てますわ！」——看到広脸色不好，说自己还能拿
- 0008「もう……そうおっしゃらず。／協力して運びましょう。」——広婉拒时，邀她一起搬
- 0012「えっ？　まあっ、本当ですわ！」——被広指出袋子是空的后惊讶
- 0014「は、はわわわわ……！？」——发现袋子破洞后的慌乱
- 0015「追いかけましょう篠澤さん！」——马上提议去追胶带
- 0017「楽しそうにしている場合じゃ／ありませんわ～～～！」——责备広居然还在笑
- 0018「お待ちくださいませぇ～～～～～～！！」——追着滚动的胶带大喊

## 行为模式
- 发现对方吃力 → 立即关心并主动要求分担，即使自己也在喘（0005、0006）
- 对方婉拒 → 不放弃，改说“一起搬”（0008）
- 突发状况（袋子破洞） → 先惊讶、慌乱，然后立即行动去追（0012、0014、0015）
- 对方在享受 → 指出现在不是享受的时候（0017）

## 关系
- 広：她称「篠澤さん」；広称她「千奈」（広的 0009）
- 花海：她称「花海さん」，想象对方能轻松搬动（0002）

## 档案类事实
- 千奈拿的袋子是环保袋，底部有破洞（0006、0013 广的话）
