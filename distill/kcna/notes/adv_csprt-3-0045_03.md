# S卡 3-0045【はいっ、みんなも一緒に♪】 / 第3话 笑着说能做到的！（adv_csprt-3-0045_03）

- 她的台词：12 行（含用匿名标签说的 0 行）；0012 提到歌词，是转述歌词中的话
- 出场的人：千奈（12）、広（8）
- 场景：两人谈『Campus mode!!』，地点剧本没写
- 世界线：S卡【はいっ、みんなも一緒に♪】；制作人在制作的偶像：看不出

## 发生了什么
千奈对広说自己确信『Campus mode!!』是一首超级难的歌，広说自己也这么想，而且曲子本身就很难。千奈羡慕能在这种情况下感到开心的広，担心站上舞台唱歌的那天会不会来。広说她们也是初星学园的学生，既然入学就有可能，只是概率可能在小数点以下，千奈抱怨她“先抬后打”。随后千奈说歌词里也有“至少自己要相信我能行”，两人互相说对方能行，千奈说希望总有一天用歌声鼓励听歌的人，広说她说得大气，但一起加油。

## 她的关键台词
- 0001「篠澤さん、わたくし……／確信しましたわ……」——开场以敬称叫広，宣布自己的结论
- 0002「『Campus mode!!』って、／すご～～～く難しい曲ですわっ！！！！」——强调曲子很难
- 0005「この状況を喜べる篠澤さんが、／羨ましいですわ……」——羡慕広能高兴
- 0006「ステージで歌える日なんて、／本当に来るのでしょうか……」——对站上舞台的那天不安
- 0010「もうっ、上げて落とすのは／やめてくださいませっ！」——对広的“先抬后打”抗议
- 0011「でも……自分が信じないことには／始まらないですわね。」——抗议之后转为自己的结论：先要自己相信
- 0012「歌詞にもあるように、自分だけは／「できる！」と思いませんと！」——引用歌词中的话鼓励自己
- 0014「篠澤さんもきっと、できますわっ！」——把鼓励也给广
- 0018「わたくしたちの歌を聴いてくれた方を、／励ませるように！」——想要用歌声鼓励听歌的人

## 行为模式
- 遇到困难 → 先感叹、担心，然后自己想通“要先自己相信”，再把鼓励给对方（0005、0006、0011、0014）
- 被広“先抬后打” → 抱怨，但接着用歌词的话振作（0010～0012）
- 被曲子鼓励 → 直接说“被鼓励了”，并提出共同的目标（0015～0018）

## 关系
- 広：称“篠澤さん”；広称她“千奈”（0007、0013）。互相给对方“能行”的评价（0013、0014）。

## 档案类事实
- 把『Campus mode!!』视为超级难的曲子（0002）。
- 想在闪耀的舞台上唱歌，励志鼓励听众（0017、0018）。

## 不确定
- 0012 的「できる！」是否是歌词原文（她说“歌詞にもあるように”），剧本没有给出歌词全文。
