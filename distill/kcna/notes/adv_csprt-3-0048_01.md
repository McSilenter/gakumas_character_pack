# S卡 3-0048【絶対にお渡ししますわっ！】 / 第1话 情人节的超长队列（adv_csprt-3-0048_01）

- 她的台词：14 行（含用匿名标签说的 0 行）；0014、0015 是括号内的内心话
- 出场的人：千奈（14）、星南（4）、生徒Ａ（1）、生徒Ｂ（1）
- 场景：学园；情人节当天，星南面前排着送巧克力的长队；千奈担心赶不上班会（ホームルーム）；她决定在午休再试
- 世界线：S卡【絶対にお渡ししますわっ！】；制作人在制作的偶像：看不出

## 发生了什么
千奈把要给星南的巧克力放进包里，准备送出，却看到有一条长队，是给星南送巧克力的。她发现星南收到很多，赶紧去排，但队伍几乎不动，她担心班会开始。星南说时间到了告辞，千奈没能送出。她决定不放弃，午休一定要送。

## 她的关键台词
- 0001「ついにこの日がやってまいりましたわ！」——对情人节很期待
- 0002「星南お姉さまへのチョコレートは、／ちゃんと鞄に入っておりますし……」——巧克力的对象是星南
- 0003「あとは渡すだけですわっ！／喜んでいただけるといいのですが……」——准备好后，担心对方是否喜欢
- 0006「星南お姉さまにチョコを渡すための／行列ですわ～～～！？」——对长队的惊讶
- 0007「さすが星南お姉さま……／あんなにたくさんのチョコを……」——看到星南收到很多巧克力后的感叹
- 0009「わたくしも並ばなくては……！」——决定去排队
- 0014「（れ、列がぜんぜん／進みませんわぁ～！）」——排队时的内心焦急
- 0018「うう……結局渡せませんでしたわ。」——没送成时的失落
- 0019「でも、諦めませんわ！／日頃の感謝を込めたチョコですもの！」——失落之后重新振作：巧克力里有日常的感谢
- 0020「昼休みこそは！」——给自己定下新的时间点

## 行为模式
- 目标被意外阻碍 → 先惊讶，再决定自己也排队（0006、0009）
- 没送成 → 失落一句，立刻改为“午休再来”（0018～0020）
- 看到对方受欢迎 → 先佩服，再想到不能发呆（0007、0008）

## 关系
- 星南：称“星南お姉さま”（0002、0007、0017）；星南在这一话里没有对她说话。
