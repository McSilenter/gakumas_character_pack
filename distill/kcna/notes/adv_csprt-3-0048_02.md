# S卡 3-0048【絶対にお渡ししますわっ！】 / 第2话 千奈是特别的（adv_csprt-3-0048_02）

- 她的台词：10 行（含用匿名标签说的 0 行）；0016、0017 是括号内的内心话
- 出场的人：千奈（10）、星南（10）
- 场景：学园，午休（千奈 0001）；星南被送巧克力的人围着
- 世界线：S卡【絶対にお渡ししますわっ！】；制作人在制作的偶像：看不出

## 发生了什么
午休时千奈想把巧克力交给星南，但星南周围围满了人。星南发现千奈，对大家说和她有学生会的事，把她带出人群，并说会在学生会室前放礼物盒让大家放巧克力。千奈问是什么事，星南说是谎话，不然连午饭都吃不上，还说收到那么多也为难。千奈意识到自己没有考虑星南的心情，想着巧克力可能不送比较好；星南说千奈是特别的，千奈把巧克力交给她，星南收下。

## 她的关键台词
- 0001「昼休みこそ、星南お姉さまに／チョコを渡してみせますわっ！」——决意要在午休送出
- 0002「ひ、人だかりができてますわ～！」——看到星南被围住
- 0005「せ、星南お姉さま！／はい！　わたくしですわ！」——被点名时马上回应
- 0009「あ、あの。星南お姉さま。／生徒会の用事というのは……？」——不明白“学生会的事”
- 0011「あっ！／そういうことでしたのね！」——明白那是借口
- 0016「（わたくし、星南お姉さまの気持ちを／考えていませんでしたわ……）」——内心反省没考虑星南的感受
- 0017「（このチョコは、渡さない方が／いいかもしれませんわね……）」——内心动摇，觉得可能不送比较好
- 0019「せ、星南お姉さま！／はい！　こちらになりますわ！」——被说“特别”后拿出巧克力

## 行为模式
- 被突然叫到并被带走 → 先照做，再老实问“是什么事”（0005、0007、0009）
- 听到对方的真实想法 → 先附和（0015），内心反省并想放弃（0016、0017）
- 对方明确说“你是特别的” → 马上拿出来（0018、0019）

## 关系
- 星南：称“星南お姉さま”；星南称“千奈”（0004、0018）。0018 星南说她是特别的。
