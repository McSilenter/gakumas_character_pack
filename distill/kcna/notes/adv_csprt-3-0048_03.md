# S卡 3-0048【絶対にお渡ししますわっ！】 / 第3话 传家宝巧克力（adv_csprt-3-0048_03）

- 她的台词：9 行（含用匿名标签说的 0 行）
- 出场的人：星南（11）、千奈（9）
- 场景：星南和千奈在谈话，地点和时间剧本没写
- 世界线：S卡【絶対にお渡ししますわっ！】；制作人在制作的偶像：看不出

## 发生了什么
星南问千奈最近练习怎么样，千奈说还有很多不足，但和朋友们一起很开心。星南问能不能现在吃千奈给的巧克力，千奈说有点不好看但味道确认过了。星南说很好吃，千奈高兴努力没有白费，被夸得不好意思。星南说自己也做了要分给学生会成员的巧克力，递给千奈；千奈说像梦一样，要当传家宝，星南说希望她吃掉。

## 她的关键台词
- 0002「まだまだ……／至らないことばかりですわ。」——被问练习，先谦虚
- 0003「ですが……楽しく取り組んでおります。／お友達と一緒に。」——强调是和朋友一起所以开心
- 0007「す、少し不格好なのですが、／味は確かめたので、大丈夫ですわ！」——对不太好看的巧克力解释
- 0010「ほ、本当ですの！？／がんばった甲斐がありましたわ！」——因被说好吃而高兴
- 0012「そ、そんな……！／褒めすぎですわ～！！」——被夸后谦虚
- 0014「え……？　これは……チョコ？」——对突然收到的礼物吃惊
- 0017「ゆ、夢みたいですわ～！！」——收到星南的巧克力时的激动
- 0019「家宝にいたしますわっ！」——要把它当传家宝

## 行为模式
- 被问近况 → 先说不足，后说开心和朋友（0002、0003）
- 被称赞 → 先高兴，随后说“夸得太多”（0010、0012）
- 收到意外礼物 → 激动，把它说成“家宝”（0017、0019）；星南说希望她吃掉（0020），之后她的反应剧本没有写

## 关系
- 星南：称“星南お姉さま”（本话她没有直接叫，称呼取自同卡第1话 0002）；星南称“千奈”（0001）。
- 朋友们：和朋友一起练习，很开心（0003）。

## 档案类事实
- 现在的练习中有不足，但和朋友一起快乐（0002、0003）。
- 送星南的巧克力外形有点不好看，味道确认过（0007）。
