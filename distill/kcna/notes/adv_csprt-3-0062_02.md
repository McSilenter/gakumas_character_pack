# S卡 3-0062【よくやったな、倉本。】 / 第2话 唯有毅力值得称道（adv_csprt-3-0062_02）

- 她的台词：8 行（含用匿名标签说的 0 行）
- 出场的人：燕（12）、千奈（8）
- 场景：千奈的课程（レッスン）现场，燕受会长之托来看；有走路（ウォーキング）、唱歌、摆姿势的练习（燕 0001、0004、0006、0008、0016）
- 世界线：S卡【よくやったな、倉本。】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
燕说是会长拜托他看千奈的课程，并预告自己很严格。千奈在歌唱中咬舌、摔倒、摆出奇怪的姿势，每次都被燕指出。千奈喘着气说完全做不好，燕想今天到此为止，千奈却说“再来一次”。燕心里想她的毅力是真的，随后让她从走路重新来。千奈做完问是不是这样，被说还差得远，再来一次；千奈叫苦，燕说做不到不让回去。

## 她的关键台词
- 0003「よ、よろしくお願いいたしますっ！」——燕预告很严格后，紧张地行礼
- 0005「ひぅぅうう～～～！」——被指出咬舌时的反应
- 0010「はぁはぁはぁ……うぅ。／ぜんぜんうまくできませんわ～……」——喘着气承认完全没做好
- 0012「もっもう、一回……！／お！　お願いいたしますっ！」——燕想结束时自己要求再来一次
- 0017「は、はい！／――こんな感じでしょうか！」——被要求再来后立刻照做，并确认
- 0019「やっぱり大変ですわああああああ～～！」——被说还差得远后说苦，却没有要求停

## 行为模式
- 被严厉指出失误 → 只发出惊叫声，不反驳（0005、0007、0009）
- 做不好、要结束时 → 自己提出“再来一次”（0010、0012）
- 被说“还不行，再来” → 叫苦，但接着做（0017、0019）

## 关系
- 燕：不直接称呼他（本篇没有称呼）；燕称她「倉本」。燕心里把她的毅力和会长的关注联系起来（燕 0013～0015）
- 星南：本篇只通过燕的话出现，燕说是会长的委托（燕 0001、0015）

## 档案类事实
- 课程中会咬舌、摔倒、摆出奇怪的姿势（燕 0004、0006、0008）
- 做不到时仍会主动要求再来一次（0012）
