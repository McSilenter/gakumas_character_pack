# S卡 3-0063【推し活なひととき、だね！】 / 第1话 快乐的传教活动♪（adv_csprt-3-0063_01）

- 她的台词：10 行（含用匿名标签说的 0 行）
- 出场的人：千奈（10）、リーリヤ（8）、一同（2，0007、0010）
- 场景：リーリヤ的房间（千奈 0011「いきなりお部屋にお邪魔して」）
- 世界线：S卡【推し活なひととき、だね！】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
千奈带着琥珀糖的和果子来リーリヤ的房间做客，说是听说她喜欢和果子。リーリヤ拿出母亲寄来的瑞典糖果，两人一起吃。千奈问突然来房间是否打扰，被说没关系。千奈递上猫头鹰玩偶的兑换券，说是听紫雲说リーリヤ喜欢。千奈接着说“我也想看那部动画”，话没说完，リーリヤ就答应并提议周末，千奈高兴地答应。

- 0002「こちらこそありがとうございます！／お土産を持ってきましたわ！」——被道谢后回礼，立刻递出礼物
- 0004「和菓子もお好きだとうかがいまして、／琥珀糖のお菓子にしてみましたわ！」——事先打听了喜好，选了琥珀糖
- 0006「わぁ～～～～～～っ！／可愛らしいお菓子ですわ！」——对瑞典糖果直接惊叹
- 0009「んん～♡！　マシュマロ？　のような／不思議な食感で美味しいですわ～！」——吃到糖果的感想
- 0011「でも、いきなりお部屋にお邪魔して／よろしかったのでしょうか？」——担心突然拜访
- 0014「これ――紫雲さんに／お好きだとうかがいましたの。」——送兑换券，说明是从别人那里打听的

- 0020「――わぁぁっ！　はいっ！／とっても楽しみですわっ♪」——对邀约高兴

## 行为模式
- 拜访对方 → 事先打听喜好，带合适的礼物（0004、0014）
- 对方回礼 → 直接表达惊喜和感想（0006、0009）
- 有想请求的事 → 先担心打扰，再慎重地开口（0011、0017、0018）
- 被一口答应 → 立刻高兴地答应（0020）

## 关系
- リーリヤ：称「葛城さん」（0013、0014、0017）；リーリヤ称她「千奈ちゃん」。她上门拜访，对方很欢迎
- 紫雲：她从紫雲处听到リーリヤ的喜好（0014）；紫雲是谁剧本没明说
