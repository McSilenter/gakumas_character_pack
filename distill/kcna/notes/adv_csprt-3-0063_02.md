# S卡 3-0063【推し活なひととき、だね！】 / 第2话 期待的动漫鉴赏会（adv_csprt-3-0063_02）

- 她的台词：10 行（含用匿名标签说的 0 行）；0018 是括号内的心里话
- 出场的人：千奈（10）、リーリヤ（9）、清夏（1，0009）
- 场景：地点没写明；リーリヤ把玩偶等摆出来给千奈看，之后看动画（0002、0006、0011）
- 世界线：S卡【推し活なひととき、だね！】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
リーリヤ给千奈看拿到手的猫头鹰玩偶，千奈高兴，说玩偶能来到葛城身边很幸福。千奈担心リーリヤ为了摆得这么齐费了事，リーリヤ说想让她看全部，千奈说很高兴。清夏插话说リーリヤ从昨天就在准备。两人一起看动画，千奈感动得流泪，说被正义的主题引起思考，说这是“热い”的感情。リーリヤ讲得兴奋，千奈在心里觉得她很开心，然后听到续集的邀请，高兴地答应。

## 她的关键台词
- 0003「わぁ～！　引換券、集まりましたのね！／とってもかわいいですわ～～！」——认出是兑换券换来的东西
- 0005「ふふ。葛城さんのもとにくることが／できて、その子も幸せですわねっ！」——把玩偶拟人，为它“幸福”
- 0006「ですがこんなに並べてくださって、／お手を煩わせてしまったのでは……？」——担心给对方添麻烦
- 0008「いいえ！　びっくりだなんてそんな！／わたくしのために嬉しいですわ！」——被问是否吓到，说是为她准备的所以高兴
- 0015「うぅ～～……正義について、／とても考えさせられましたわ……！」——看完后说的感想
- 0016「これが“熱い”という感情……／涙が、止まりませんわ……！」——对“热血”的新鲜体验
- 0018「（うふふ……葛城さん、／とっても楽しそうですわ）」——心里话，看着リーリヤ兴奋讲解
- 0020「――はい！　はい！！／ぜひ観たいですわっ！」——对续集的邀请立刻回答两次

## 行为模式
- 被精心招待 → 先担心对方麻烦，听到是为自己后转为高兴（0006、0008）
- 看动画 → 投入，哭出来，并用自己的话说感想（0013、0015、0016）
- 看到同伴兴奋 → 不抢话，在心里感到温暖（0018）
- 被邀请继续 → 重复“はい”，明确表示想看（0020）

## 关系
- リーリヤ：称「葛城さん」（0005、0018）；リーリヤ称她「千奈ちゃん」。她觉得リーリヤ讲动画时很开心（0018）
- 清夏：本篇没有对话，清夏插话时她没有回应

## 档案类事实
