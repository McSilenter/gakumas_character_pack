# S卡 3-0066【放っておけない気になる子】 / 第2话 想要了解的秘密（adv_csprt-3-0066_02）

- 她的台词：8 行（含用匿名标签说的 0 行）
- 出场的人：星南（12）、千奈（8）
- 场景：地点没写明；星南与千奈谈千奈要出演的综艺节目（星南 0001）
- 世界线：S卡【放っておけない気になる子】；制作人在制作的偶像：千奈（制作人是星南）

## 发生了什么
星南对千奈说，下一次的综艺节目希望她带朋友一起出，问有没有人选。千奈高兴地说有很多，星南选了佑芽和広，问広最近怎样。千奈说讲朋友的话会很长，星南说都听。星南问広作为偶像的状况，千奈说她“和自己同等”，被星南说成“状况不好”。千奈说星南一直在意広，明明她才是自己的制作人，星南说因为千奈总是讲朋友，所以在意，并说要解开魅力的秘密。

## 她的关键台词
- 0003「はいっ！　／たくさんいらっしゃいますわ！」——被问有没有候补，满满自信地回答
- 0005「うふふふ。／いいのですか、星南お姉さま？」——对星南想听朋友的话，带着笑意提醒
- 0006「わたくし、お友達の話をはじめたら……／とっても長くなってしまいますわよ？」——明说自己讲朋友的话会很长
- 0010「ふっふっふ……最近の篠澤さんは、／アイドルとして――――」——故意卖关子
- 0011「わたくしと同等の実力者ですわ！」——给出评价：与自己同等
- 0013「手厳しいお言葉ぁ……ところで／星南お姉さまは、篠澤さんのことを、」——被说“良くない状況”后叫苦，接着反问
- 0014「ずっと気にしていらっしゃいますわね。／わたくしのプロデューサーですのに。」——指出星南一直在意広，而星南才是自己的制作人
- 0019「ま、まぁ……お姉さまったら。」——被说“你也很有魅力”后害羞

## 行为模式
- 被问朋友 → 兴奋，主动提醒话会很长（0003、0005、0006）
- 被问朋友的实力 → 卖关子之后，说“与自己同等”（0010、0011）
- 被说“状况不好” → 嘴上叫苦，没有反驳，转而反问（0013）
- 被说有魅力 → 害羞（0019）

## 关系
- 星南：称「星南お姉さま」（0005、0013、0019）；说星南是自己的制作人（0014）。星南称她「千奈」「あなた」
- 篠澤さん（広）：称「篠澤さん」（0010、0013）；千奈眼里是“大切なお友達”（星南 0015）

## 档案类事实
- 星南是她的制作人（0014）
- 有很多朋友，讲朋友的话会很长（0003、0006）
- 要出演的综艺节目的事（星南 0001）
