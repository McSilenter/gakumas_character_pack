# S卡 3-0067【わたしと美鈴、超仲良し】 / 第2话 如运动会一样的日常（adv_csprt-3-0067_02）

- 她的台词：10 行（含用匿名标签说的 0 行）
- 出场的人：佑芽（10）、千奈（10）
- 场景：体育祭结束之后的对话（佑芽 0001）；地点没写明
- 世界线：S卡【わたしと美鈴、超仲良し】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
佑芽说体育祭很开心，千奈说虽然很累、也输了，但是很棒的时间。千奈说全班为同一个目标努力很棒，佑芽说千奈懂了运动的乐趣，千奈回应也懂了运动的痛苦：自己拖累班级输下去的焦急，到现在腿还在抖。佑芽说正因有那种痛苦，喜悦和悔恨才变大，千奈说那和偶像一样。佑芽说偶像、舞台也是大家一起做的，千奈说那她们之后要一直继续这种日子，佑芽说很期待。剧情经过参照 hume 笔记。

## 她的关键台词
- 0002「はいっ！　すっごく疲れましたし……／負けてしまったのは残念でしたが……」——先说累和输了的遗憾
- 0003「とっても素敵な時間でしたわ！／花海さん……」——紧接着肯定这段时间，称「花海さん」
- 0004「クラス全員で、同じ目的へ向けて／がんばるって、素敵ですわね。」——最看重全班一起努力
- 0007「はいっ、ばっちり伝わりましたわ――」——回应佑芽“运动的乐趣”，先说传达到了
- 0008「スポーツの苦しさも！」——紧接着说也懂了运动的痛苦
- 0009「自分のせいで敗北に近づいていく／あの焦燥……いまだに足が震えますわ。」——自己拖累班级的焦急，至今腿在抖
- 0013「同じですわね……アイドルと。」——把运动的苦和乐与偶像联系
- 0018「まあ、でしたら……わたくしたちは、／これからずっと、続けていきますのね。」——从佑芽的话得出“我们会一直继续”
- 0019「この恐ろしくも素晴らしい、／体育祭のような日々を。」——把今后的日子比作体育祭

## 行为模式
- 回顾一件事 → 先说累和遗憾，再肯定它的美好（0002、0003）
- 对方想让她明白 → 承认明白，同时加上自己体会到的另一面（苦）（0007～0009）
- 对方给出道理 → 用自己的领域（偶像）去对应（0013）
- 对方说出结论 → 把它延伸到“今后的日子”，用比喻总结（0018、0019）

## 关系
- 佑芽：称「花海さん」（0003、0012）；佑芽称她「千奈ちゃん」。佑芽说她“也明白了运动的乐趣”（佑芽 0005）

## 档案类事实
- 在体育祭上输了（0002；输的是谁没写明，从 0004 与 0009 看是班级）
- 在体育祭中觉得是自己拖了班级的后腿，焦急，至今腿还在抖（0009）
