# S卡 3-0072【おっと、危ないよ】 / 第2话 管家的工作？（adv_csprt-3-0072_02）

- 她的台词：8 行（含用匿名标签说的 0 行）
- 出场的人：千奈、広、麻央
- 场景：中庭（千奈、広与花海さん、秦谷さん在那里吃午饭）
- 世界线：S卡【おっと、危ないよ】；制作人在制作的偶像：看不出

## 发生了什么
千奈听広讲佑芽便当里的蛇肉蒲烧，惊讶。麻央来打招呼，问学园生活是否习惯，千奈说每天都有发现很开心。她羡慕住宿舍的篠澤さん们，因为可以每天和朋友在一起。麻央说羡慕千奈的大宅，之后扮演管家，说已经处理了刺客，千奈吐槽那不是管家的工作。

## 她的关键台词
- 0002「まあ、そんなことが！？」——对広的便当话题的惊讶
- 0004「あ、麻央先輩。おはようございます。」——见到麻央就问候
- 0006「花海さんと秦谷さんと、／皆さんでお昼をいただきますの。」——说明今天和花海さん、秦谷さん一起吃午饭
- 0009「はい。初星での生活は、日々が発見で、／とーっても楽しいですわ！」——对学园生活的感受
- 0011「でも、わたくし、寮住まいの／篠澤さんたちが羨ましいですわ。」——羡慕寮生
- 0012「お友達と毎日、／一緒にいられるんですもの。」——羡慕的理由是可以每天和朋友在一起
- 0018「まあ、本物の執事さんのようですわ！」——麻央扮管家时的感叹
- 0020「そ、それは執事の仕事では／ありませんわ！」——吐槽“处理刺客”

## 行为模式
- 听到有趣的事 → 大声惊讶（0002）
- 被问近况 → 老实表达“每天是发现”（0009）
- 想到别人的好处 → 直接说出羡慕，不掩饰（0011、0012）
- 玩笑越过头 → 用“不是执事的工作”来吐槽（0020）

## 关系
- 麻央：称「麻央先輩」；麻央称她「千奈」（0004）
- 広：同在中庭吃午饭，広在聊天中说话（0001）
- 花海さん、秦谷さん：一起吃午饭的对象（0006）
- 篠澤さんたち：寮生，千奈羡慕（0011）

## 档案类事实
- 羡慕寮生，能每天和朋友在一起（0011、0012）；她是否住寮剧本没有明说
- 家有大宅，有真正的女仆（麻央台词 0013、0014）

## 不确定
- 0011 只说羡慕寮住まい的篠澤さんたち，没有说自己住哪里。
- 无匿名行；剧本里没有「一同」行。
