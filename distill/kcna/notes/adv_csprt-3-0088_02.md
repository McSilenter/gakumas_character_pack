# S卡 3-0088【思い出の宝箱だ、ね】 / 第2话 偶像的光辉（adv_csprt-3-0088_02）

- 她的台词：8 行（含用匿名标签说的 0 行）：0001、0003、0007、0008、0010、0016、0017、0020
- 出场的人：千奈、広、香名江
- 场景：千奈告诉香名江広要留宿的场合；地点剧本里看不出
- 世界线：S卡【思い出の宝箱だ、ね】；制作人在制作的偶像：看不出（剧本里没有制作人）

## 发生了什么
千奈向香名江报告篠澤さん要留下来过夜。香名江说刚才的特训似乎还能继续看到，広说刚才模仿很充实，让她明白了千奈的可爱。千奈回应这是自己的台词，并说靠临时抱佛脚学不来篠澤さん的魅力，两人说很开心。香名江把千奈托付给広，広也把自己托付给香名江。千奈见两人有了默契，要求加入话题，広提议下次模仿香名江可爱的地方，千奈说需要同款衣服。

## 她的关键台词
- 0001「香名江～♪　聞いてくださいませ～♪」——向香名江兴冲冲地报告，口吻和上一话相同
- 0003「うふふ……篠澤さんが、泊まって／いってくださるそうなのです。」——高兴地转述広要留宿
- 0007「それはこちらの台詞ですわ。／篠澤さんの魅力……」——回应広对自己的夸奖，说自己也有同样的感受
- 0008「付け焼き刃では到底、真似など／できないとわかりました。／ですけれど……」——承认模仿不到位，但话没说完，接着转折
- 0010「うんっ♪」——回应広的“开心”
- 0016「まぁっ、ふたりがいつの間にか／分かり合って……！」——发现香名江和広变得有默契
- 0017「わたくしもお話に／まぜてくださいませぇ～～～～！」——不甘被排除在外，要求加入
- 0020「素敵なアイデアですわ――／おそろいの服が必要ですわね♪」——広一提议立刻赞成，并想到要准备同款衣服

## 行为模式
- 有开心的事 → 先向香名江报告（0001、0003）
- 对方夸自己 → 回以同样的评价（0007）
- 发现别人之间的关系变好 → 惊喜，同时马上要求加入（0016、0017）
- 听到新点子 → 立即赞成，想到具体要准备的东西（0020）

## 关系
- 広：称「篠澤さん」（0003、0007）；两人觉得模仿时光开心（0009、0010）
- 香名江：称「香名江」；香名江称她「お嬢様」（0002）；香名江请広照顾她（0012）

## 档案类事实
- 広要在千奈家留宿（0003）
- 前一话的模仿行为被称为「特訓」（香名江 0004）
