# 有村麻央 亲爱度剧情 / 第29话（adv_dear_amao_029）

- 她的台词：8 行（匿名标签 0 行）
- 出场的人：麻央（45 行）、広（9）、千奈（8）、清夏（7）、リーリヤ（7）、一同（2）、プロデューサー（2）
- 场景：麻央为了制作人给的“課題”（0072），请千奈和広一起练习（0001～0041）；之后清夏和リーリヤ那一段她不在场。地点剧本没写明
- 世界线：亲爱度（有村麻央）；制作人在制作的偶像：有村麻央

## 发生了什么
她和広来和麻央一起练习，她郑重地打招呼，说能得到3年生前辈指导非常光荣（0001、0005）。麻央说也要向她们学习，说她们在宿舍被传会成为这次『H.I.F』的黑马，她吃惊（0008～0012）。麻央提到她出演的网络节目播放量很高，広补充说那是她接连给出奇迹般怪答案的偶像问答节目，她辩解自己只是认真回答（0013～0015）；麻央说她的反应有趣，是只属于她的魅力（0016、0017）。她向麻央介绍広被粉丝叫“女神様”（0021）。练习结束时她喘着说到极限了，最后向麻央道谢（0032、0040）。

## 她的关键台词
- 0001「麻央先輩、本日はどうぞ、／よろしくお願いします。」——郑重的开场问候
- 0005「いいえ。わたくしたちこそ、／3年生の先輩にご指導頂けるなんて、／とっても光栄ですわ！」——对前辈的指导表示荣幸
- 0008「まあ、わたくしたちから……？」——听前辈说要向她们学，感到意外
- 0012「そんな噂が！？」——对自己被议论吃惊
- 0015「わ、わたくし、／真面目に答えただけですわ～！」——对“珍回答”的辩解
- 0021「篠澤さんは、ファンの方々に、／女神様と呼ばれていますわ。」——替同伴说好话
- 0032「……ふぅ、ふぅ……／も、もう、限界ですわ～！」——练到极限时的叫声
- 0040「本日はご指導、／ありがとうございました、麻央先輩。」——结束时的礼貌道谢

## 行为模式
- 对前辈 → 用「わたくし」「ですわ」和「ご指導頂ける」等郑重敬语，开头结尾都礼貌问候（0001、0005、0040）
- 被说要向她学习、被议论 → 吃惊地反问（0008、0012）
- 被提起出糗的事 → 着急辩解自己是认真的，语尾拖长（0015）
- 同伴被提及 → 主动补充对方受欢迎的事（0021）
- 体力到顶 → 直接喊出来（0032）

## 关系
- 麻央：叫「麻央先輩」（0001、0040）；麻央叫她「千奈」（0013、0016、0017）。麻央称赞她反应有趣，是麻央、星南、燕都没有的、只属于她的魅力（0017）。
- 広：称「篠澤さん」（0021）；広叫她「千奈」（0014），并说她在问答节目上连发“珍回答”（0014）。

## 档案类事实
- 出演过网络上的偶像问答节目，播放数很高（0013，麻央的话）；広说她在节目里接连给出奇迹般的“珍回答”（0014），她说自己只是认真回答（0015）。
- 麻央说她和広在宿舍被传可能成为这次『H.I.F』的“台風の目”（0010、0011，麻央的话）。
- 麻央说她们比入学时进步很多（0036，麻央的话）。
