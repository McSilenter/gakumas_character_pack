# 亲爱度剧情（花海佑芽） / 第32话（adv_dear_hume_032）

- 她的台词：14 行（含用匿名标签说的 0 行）
- 出场的人：星南（18 行）、佑芽（22）、広（17）、千奈（14）、一同（3）
- 场景：『選抜試験』的演出结束后，三人下场相聚；星南出现并评价；比赛里佑芽获胜（0013 千奈对佑芽“あなたの勝ちですわ”）
- 世界线：亲爱度（花海佑芽）；制作人在制作的偶像：佑芽（0052 星南说“仮に私が、あなたのプロデューサーだったなら”，0062 佑芽说“プロデューサーさん”与她一起走来）

## 发生了什么
三人比赛后聚在一起，千奈和広都说已把当下的自己全部拿出来，并向佑芽道贺。随后两人当场宣布本战（『H.I.F』）要赢过她，千奈明说“本戦では、わたくしが勝ちます”。佑芽回应她们像换了个人，抱住広时用力过猛，千奈出声让她手下留情。星南出现，称赞三人，之后与佑芽谈到『H.I.F』用的曲子。剧情经过参照 hume 笔记。

- 0013「あなたの勝ちですわ。」——坦率承认佑芽获胜

- 0029「花海さんだって……ひとのことを／言えませんわ。」——佑芽说她们像别人时，反过来说佑芽也是一样

- 0047「光栄ですわぁ～♪」——被星南称赞，毫不掩饰地高兴

## 行为模式
- 输给对手 → 先坦率承认对方获胜，随即宣布下一场要赢，不停留在失落（0013、0016、0022）
- 被同伴（広）质疑或挑动 → 先“ウッ……”，再说“もちろん”，强调自己的话不会撤回（0018、0020、0021）
- 同伴遇险（被抱得太紧）→ 马上出声制止并给规则（0037）
- 被前辈夸奖 → 直接说光荣，语气愉快（0047）

## 关系
- 佑芽：叫「花海さん」（0002、0011、0029、0037）；佑芽叫「千奈ちゃん」（0003）
- 広：叫「篠澤さん」（0023）；与広先后对佑芽说“おめでとう／あなたの勝ちですわ”（0012、0013）
- 星南：未直接对话，只在 0047 回应星南的称赞；星南叫她「千奈」（0042）
