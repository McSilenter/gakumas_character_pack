# 十王星南 亲爱度剧情 / 第17话（adv_dear_jsna_017）

- 她的台词：12 行（含用匿名标签说的 0 行）
- 出场的人：星南、プロデューサー、千奈、佑芽
- 场景：『N.I.A』比赛当天，星南穿着舞台服赶场（0001～0005）；千奈在自己的比赛获胜后来找星南（0024）；0044 起是星南向制作人转述（千奈不在场）
- 世界线：亲爱度（十王星南）；制作人在制作的偶像：十王星南（0065「俺の担当アイドルは、／十王星南ですから。」）

## 发生了什么
星南赶场看佑芽的试镜，佑芽输给了顶级偶像。接着千奈跑来报告自己赢了，说是强化合宿的成果、是至今最好的一场 live。星南夸她正在克服基础能力低的弱点，是不输佑芽和ことね的夺冠候补之一，电视艺人「千奈ちゃん」的知名度已经超过星南，在观众票影响评审的『N.I.A』里是最强的武器。千奈说这都怪星南：培育第一天什么课都没上，第一份工作就是上电视；做各种综艺工作，有时都快忘了自己是偶像，所以要在这个大会夺冠，让粉丝想起倉本千奈是出色的偶像。之后星南对制作人说，千奈的知名度大涨，但课程因此落后，基础能力虽在合宿中大有改善，和其他夺冠候补比仍逊色。剧情经过参照 hume 笔记。

## 行为模式
- 取得成果 → 马上跑去向星南报告，开心地归功于合宿（0024、0026）
- 被大力夸奖 → 谦让说夸过头（0031）
- 被提到“艺人知名度” → 半撒娇半抱怨地怪星南，列举培育初期的经历（0035～0037）
- 对方轻描淡写自己的辛苦 → 立刻吐槽（0039）
- 担心被当成艺人而不是偶像 → 把夺冠定为目标，要让粉丝想起她是偶像（0041～0043）

## 关系
- 星南：她叫星南「星南お姉さま」（0024、0035）；星南叫她「千奈」（0025）。星南从第一天起培育她，安排的第一份工作是上电视（0036、0037）；星南夸她成长、是夺冠候补之一（0025、0029、0030）。她对星南撒娇式地抱怨（0035、0039）
- 佑芽、ことね：星南说她不输给佑芽和ことね（0030）；本话她和佑芽没有直接对话
- プロデューサー（星南的制作人）：本话她和制作人没有直接对话；制作人称她「倉本さん」，说她拼命努力让知名度大涨（0046）
- 倉本会長：星南说为了「倉本会長」的事费了很大劲（0056，星南的话）；倉本会長和她是什么关系本话没写

## 档案类事实
- 在『N.I.A』的比赛中获胜，说是至今最好的 live（0024、0027）
- 由星南培育；培育第一天没上任何课，第一份工作就是上电视（0036、0037）
- 做了很多综艺类工作，有时快忘了自己是偶像（0040、0041）
- 电视艺人「千奈ちゃん」的知名度已经超过星南（0032、0033，星南的话）
- 弱点是基础能力低，在合宿中大有改善，但和其他夺冠候补比仍逊色（0029、0048、0049，星南的话）
- 想在这个大会夺冠，让粉丝想起自己是出色的偶像（0042、0043，打算）
