# 倉本千奈 亲爱度剧情 / 第4话（adv_dear_kcna_004）

- 她的台词：45 行（含用匿名标签说的 0 行；其中 0001～0003、0007、0009、0011、0014～0016、0058、0059 是括号里的心里话）
- 出场的人：千奈、手毬、広、ダンストレーナー、プロデューサー
- 场景：初星学园的课程，跑步（0004～0031），之后在保健室醒来（0033、0034）；手毬说这是第一次课程（0050）
- 世界线：亲爱度（倉本千奈）；制作人在制作的偶像：倉本千奈（剧本里没有直接说法；0075、0076 只有制作人的记录）

## 发生了什么
她一边想着“一天普通完成课程”这个课题是什么意思，一边上课，结果整堂课一直在跑步，被舞蹈教练连连催促，心里叫苦“偶像不是唱歌跳舞的光鲜工作吗”，还自嘲说想当偶像的笨蛋就是自己（0001～0021）。好不容易跑到终点想向老师报告，却被告知那只是热身，正式课程才开始（0022～0031）。她在保健室醒来，手毬说她在课上倒下了，不肯报名字，说新生分内部升学组和没经验的外行，跟不上就尽早放弃（0033～0055）。她说生平第一次被人说得这么难听，但心里承认什么都反驳不了（0057～0059）。隔壁床的広说手毬是亲切的人，一直陪到她醒、给了很多提示，她笑着认同（0060～0074）。剧情经过参照 ttmr、shro 笔记。

- 0015「（歌って踊る煌びやかなお仕事／じゃなかったんですのぉ！）」——想象中的偶像和现实的落差
- 0018「軽い気持ちで『アイドルになりたい』／だなんて言い出したおばかさんは……」——自嘲的铺垫
- 0019「わたくしですわぁ～～～～～～～～～！」——自问自答式的自嘲
- 0024「そ、想像以上の／ハードトレーニングでしたわ。」——承认训练比想象的更辛苦
- 0026「先生～～っ！　わたくし、／なんとかやりとげましたわ！！！」——做到一点就想向制作人报告
- 0031「こんなの聞いて／おりませんわぁ～～～～～！？」——得知只是热身时的哀叫
- 0043「アイドルになれないと／おっしゃいますの？」——被说是外行时反问
- 0057「あんなにひどいことを言われたの、／生まれて初めてですわ……！」——生平第一次被这样说
- 0059「（なにも……言い返せませんでしたわ）」——心里承认对方说中了
- 0067「わかりますわ……心から……／わかりますわぁ……」——对同样倒下的広深有同感
- 0074「本当ですわ。／とても――親切な方でしたわね。」——听了広的话后改变对手毬的看法

## 行为模式
- 训练太苦 → 嘴上应「はいぃ」照做，心里大叫辛苦，用夸张的哀叹发泄（0006、0007、0011、0013）
- 现实和憧憬不符 → 觉得被骗，然后自嘲说是自己轻率想当偶像（0015～0019）
- 完成了一点 → 想马上向「先生」报告（0026）
- 被严厉地否定 → 当场受到冲击，但心里承认无法反驳，不硬顶（0057～0059）
- 别人提出另一种看法 → 想一想后接受，笑着改口（0068～0074）

## 关系
- 手毬：她不知道对方名字，问「どなた……ですの？」（0035）；手毬叫她「あなた」（0034）。先觉得被说得很难听，听了広的话后认为是亲切的人（0057、0069、0074）
- 広：叫「篠澤さん」（0062、0064）；広叫她「あなた」（0070）。两人都在课上倒下，她对広的话深有同感（0064～0067）
- 制作人：在课上想向「先生」报告（0026）；制作人本篇只有记录（0075、0076）
- ダンストレーナー：叫她「倉本」，严厉催促（0005、0012、0020）

## 档案类事实
- 第一次课程整堂课在跑步，那是热身，她跑完后在课上倒下，被送进保健室（0016、0027、0034）
- 生平第一次被人说得那么难听（0057）
- 她是高等部入学的未经验者；手毬说中等部升上来的学生三年前就开始接受偶像课程（0040～0042）
- 手毬说第一次课程较轻，最后没做完的只有两个人（0050、0051）
