# 倉本千奈 亲爱度剧情 / 第5话（adv_dear_kcna_005）

- 她的台词：30 行（含用匿名标签说的 0 行）
- 出场的人：千奈、プロデューサー
- 场景：第一次课程的第二天，她当天缺席（0002、0009），之后来见制作人（0001）；地点剧本没写明
- 世界线：亲爱度（倉本千奈）；制作人在制作的偶像：倉本千奈（剧本里没有直接说法；0043 制作人记录要支持她）

## 发生了什么
第一次课程后她全身肌肉痛，第二天缺席，来见制作人时说自己太不争气，担心制作人对她失望（0001～0006）。制作人说她运动不足很明显，早就料到她第二天会动不了，她说明知道还出那种课题，太坏心眼了（0007～0011）。她说体会到要成为出色的偶像首先得练体力，制作人补充还要练柔韧性（0014～0019）。被问到昨天是否很痛苦，她说无数次想过因为轻率说出的梦想吃这种苦，一直以为偶像是闪闪发光的工作，自己太傻，昨晚在床上一直烦恼、多次想放弃（0020～0030）。但她说不会放弃，因为体会到她憧憬的偶像比想象中更了不起，梦想和憧憬只有越来越大（0031～0034）。被问是不是为了梦想不怕辛苦的课程，她答不上来，还说自己有自信比学园里任何人都更是被宠着长大的，见制作人无语，又请他别嫌弃（0035～0041）。

## 她的关键台词
- 0004「我ながらふがいないですわぁ……」——对自己不争气的自责
- 0006「……先生、わたくしに、／失望してしまわれましたか？」——在意制作人是否失望
- 0011「いじわるですわ、先生！」——对制作人撒娇式的抗议
- 0015「なにはともあれ、／体力を付けねばなりませんっ！」——自己找出课题
- 0022「軽い気持ちで口にした夢のせいで、／こんなひどい目に遭うなんて、と。」——坦白昨天的想法
- 0024「わたくし、／本当におばかさんでしたわ。」——承认自己以前想得太简单
- 0029「こんなに辛くて、みじめな気持ち……／生まれて初めてでしたもの。」——生平第一次的挫折感
- 0030「身体が痛くて、動けなくて……何度も／やめたいと思いましたわ。――だけど。」——承认想过放弃，然后转折
- 0031「わたくし、やめませんわ！」——宣言不放弃
- 0033「想像していたよりも、ずっとずっと／素敵で、すごい方々だったと！」——吃了苦反而更憧憬偶像
- 0034「わたくし、夢と憧れが／膨らむばかりですわっ！」——梦想变大
- 0039「甘やかされて育ってきた／という自信がありますわ！」——不怕苦这一点不敢断言，坦然自认被宠大
- 0041「あ、呆れないでくださいませぇ～～！」——被无语时慌张

## 行为模式
- 自己表现差 → 先自责，再担心制作人是否对她失望（0004～0006）
- 得知制作人早有预料 → 说他坏心眼，但很快接受，转而说出自己体会到的课题（0010～0016）
- 被问到辛苦的经历 → 坦白说出想放弃的念头，再用「だけど」转向不放弃的理由（0021～0031）
- 吃到苦头 → 不是灰心，而是更佩服、更憧憬做到的人（0032～0034）
- 被问能否保证不怕苦 → 不说大话，老实承认自己被宠着长大（0036～0039）

## 关系
- 制作人：叫「先生」（0001、0006、0011）；制作人叫她「倉本さん」（0008、0020）。在意制作人是否对她失望（0006），会对他抱怨「いじわる」（0011），但听从他的指导（0019）

## 档案类事实
- 第一次课程后第二天全身肌肉痛、动不了，缺席了（0002、0003、0005）
- 制作人说她明显运动不足（0008）
- 她说以前以为偶像是闪闪发光的工作（0023）
- 第一次课程后那晚在床上一直烦恼，多次想过放弃，但决定不放弃（0028～0031）

- 制作人的方针：练体力，同时练柔韧性以防受伤（0015、0018）
