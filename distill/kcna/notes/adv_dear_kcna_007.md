# 倉本千奈 亲爱度剧情 / 第7话（adv_dear_kcna_007）

- 她的台词：45 行（含用匿名标签说的 0 行；其中 0005、0017～0019 是括号里的心里话）
- 出场的人：千奈、プロデューサー、手毬、佑芽
- 场景：前半她和佑芽、手毬谈杂志上的初星学园特辑（0001～0037），之后和制作人谈话（0038 起）；地点剧本没写明
- 世界线：亲爱度（倉本千奈）；制作人在制作的偶像：倉本千奈（0012 手毬「あなたのプロデューサーが／持ち込んだ企画だからでしょ。」，0078「倉本千奈を、立派なアイドルに！」）

## 发生了什么
佑芽看了杂志上介绍期待新生的初星学园特辑，她心里想爷爷高兴了是好事，嘴上说自己在优秀的人当中显得格格不入，很难为情；听佑芽说她上了封面，她大吃一惊，说自己是特辑里最弱的（0001～0011）。手毬说那是她的制作人带来的企划，借了倉本家的力量，问她没实力还被评价不觉得丢脸吗；她心里大叫这人哪里亲切，明明非常坏心眼（0012～0019）。她承认自己像有实力的人一样出风头不好，认为手毬生气是当然的；手毬却说封面很好，不会对做得比自己好的偶像说“别比我显眼”，又说偶像越显眼越招恶意，叫她快点长实力，做不到就退出；她说这些她都明白（0023～0037）。之后她请制作人让她参加选拔考试，理由是参加 H.I.F 是防止制作人被开除的最后机会；制作人说还太早不允许（0038～0048）。她说特辑让她太显眼，招来了“过度优待没实力的人”的批评，而在校内外受批评的是制作人；制作人说这是职责，她哭着说不甘心，想早点长实力让说制作人坏话的人刮目相看（0049～0064）。制作人说正因如此更不能急，按自己的步调来，并重复在把她培养成出色的偶像前不会被开除；她说相信，随后得知要办她的首次 live，非常兴奋（0065～0079）。剧情经过参照 hume、ttmr 笔记。

- 0010「特集されている生徒の中で、／一番の雑魚アイドルですのにっ！」——自称最弱的偶像

- 0024「他の皆様を差し置いて、わたくしが、／さも実力者であるかのように目立つのは、」——对自己出风头的看法
- 0026「同じ記事に掲載されたあなたが／お怒りになるのは、当然のことですわ。」——站在对方立场承认对方生气有理
- 0037「………そんなの、わかってますわ。」——对手毬的话不反驳
- 0041「H.I.Fに参加し、先生の解雇を防ぐ／最後のチャンスだからですわ！」——想上台的理由是保住制作人
- 0047「焦りますわ……だって、／このままでは先生が……」——着急的原因是制作人
- 0056「……先生なのです。」——指出受批评的是制作人
- 0059「仕方なくありませんわ！！！」——不接受制作人“没办法”的说法
- 0061「悔しいですわ……！」——不甘心
- 0063「先生を悪く言う人たちを／見返したいのです。」——想变强的新理由
- 0068「先生はクビになってしまいますのよ？／危機感を持って欲しいですわ。」——反过来要制作人有危机感
- 0075「ふぁぁぁ……わたくしの！／ファーストライブ！！！」——得知首次 live 时的兴奋

## 行为模式
- 自己被抬高 → 觉得难为情，先拿自己和优秀的人比，说自己不配（0006、0010）
- 被人尖刻地指责 → 心里大叫对方坏心眼，嘴上却认真承认对方说得有理，站在对方立场考虑（0017～0019、0023～0026、0037）
- 对方褒贬不一 → 直接问到底想说什么（0034）
- 制作人因自己受批评 → 不接受“没办法”，哭着说不甘心，把这变成想快点变强的动机（0059～0064）
- 制作人劝她别急 → 抱怨他太悠哉、要他有危机感，但对方重复承诺后说相信（0067、0068、0071）
- 听到期待已久的事 → 「ふぁぁぁ」地兴奋，马上答应（0075、0076、0079）

## 关系
- 制作人：叫「先生」（0038、0056、0071）；制作人叫她「倉本さん」（0043、0072）。担心制作人被开除、为他受批评不甘心（0041、0047、0060～0063）；选择相信他（0071）
- 手毬：她叫「あなた」（0013、0026）；手毬叫她「あなた」，也说「落ちこぼれ」「誰かさん」（0012、0022、0033）。心里认为手毬非常坏心眼（0019），嘴上承认对方的话有理（0026、0037）；对制作人说「わたくしを責めてくださったのは、／親切なおひとりだけでしたわ。」（0054），按上下文指手毬
- 佑芽：叫「花海さん」（0002）；佑芽叫她「千奈ちゃん」（0001、0007）。佑芽夸她的封面可爱（0007），还问手毬是不是喜欢她（0021）
- 爷爷：杂志让爷爷高兴，她觉得是好事（0005）；认为让爷爷接受（不参加 H.I.F）会很难（0049）
- 广（篠澤さん）：心里想起広说手毬亲切的话（0017），本篇広不在场

## 档案类事实
- 上了杂志初星学园特辑（介绍期待新生）的封面（0004、0007、0009）；手毬说这是她的制作人带来的企划，借了倉本家的力量（0012、0014）
- 特辑之后出现“过度优待没实力的人”的批评，按她的说法受批评的是制作人（0051、0055、0056）
- 她请求参加 H.I.F 选拔考试，被制作人拒绝（0039、0042、0043）
- 要办她的首次 live（0075），制作人说还是比较久以后的事（0077）
- 她和手毬不同班（0020 佑芽的话）

## 不确定

- 0074 和 0075 之间接不上，制作人具体提出首次 live 的话剧本里没有。
