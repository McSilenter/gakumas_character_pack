# 倉本千奈 亲爱度剧情 / 第9话（adv_dear_kcna_009）

- 她的台词：38 行（含用匿名标签说的 0 行）
- 出场的人：千奈、プロデューサー
- 场景：首次 live 结束后（0002），她先去见了爷爷再回到制作人这里（0036）；地点剧本没写明
- 世界线：亲爱度（倉本千奈）；制作人在制作的偶像：倉本千奈（0033「あなたのプロデュースに、感謝を。」，0040）

## 发生了什么
她问制作人首次 live 怎么样，被指出差点摔倒，她道歉；制作人说她马上站稳了，观众对她拼命的样子有好感，整体是很棒的 live，她害羞地高兴，又为失误多道歉，说 live 时一直很拼命，没余力看观众的脸（0001～0016）。制作人提起初次见面那天，说半年前她的实力很糟、现在成长了很多；她说是制作人指导的成果，又说制作人总是不带奉承和顾忌地真心夸她、直率地夸奖、批评、引导她，这救了她、推了她一把（0017～0031）。她叫出制作人的名字郑重道谢，请他不要说“契约结束了”，说自己回来前去见了爷爷：以前从没想过违抗爷爷，这次却让爷爷认可了她今后继续和制作人一起当偶像（0032～0040）。她说制作人今后也一直是只属于她的先生，又理直气壮地说自己实力只够勉强上台；制作人说她已经是出色的偶像了，她说以后不再称自己是劣等生、最底层偶像，那样对支持她的粉丝失礼，今天起她是“等级 1 的新人偶像”（0042～0053）。

## 行为模式
- 表演结束 → 马上问评价；被指出失误先道歉，被夸则「えへへ」害羞并追问哪里好（0002、0005、0009、0010、0013）
- 被直言批评 → 用吐槽的方式接住，不受伤（0021）
- 想道谢时 → 先替对方说出“只是做了工作”，再郑重说出对方对自己的意义（0029～0034）
- 担心失去重要的人 → 不等对方开口，先自己行动（去说服爷爷）再报告结果（0035～0040）
- 自我评价 → 从“理直气壮地说自己弱”转为为了粉丝不再自贬，但仍定位为新人（0045、0046、0050～0053）

## 关系
- 制作人：叫「先生」（0001、0034），0032 叫他的名字加「様」（「{user}様。」），0042 也叫『プロデューサー』；制作人叫她「倉本さん」（0007、0017）。说制作人总是真心夸她、直率地引导她，救了她（0026～0031）；说服爷爷让她继续和制作人一起当偶像，称他为「わたくしだけの先生」（0040、0043）
- 爷爷：叫「お爺様」，说他「優しく怖い」（0037）；以前没想过违抗他的意思，这次让他认可了自己继续和制作人当偶像（0037～0040）
- 粉丝：因为对支持她的粉丝失礼，不再自贬（0051）

## 档案类事实
- 首次 live 差点摔倒，很快站稳；制作人说整体很棒（0004、0006、0008）
- live 时一直很拼命，没余力看观众的脸（0014、0015）
- 制作人说半年前她作为偶像的实力很糟，现在成长了很多（0020、0022）
- live 后去见爷爷，让爷爷认可她继续和这位制作人一起当偶像（0036～0040）；以前从没想过违抗爷爷的意思（0037、0038）
- 决定不再称自己是劣等生、最底层偶像，自称「レベル1の駆け出しアイドル」（0050、0053）
