# 倉本千奈 亲爱度剧情 / 第11话（adv_dear_kcna_011）

- 她的台词：41 行（含用匿名标签说的 0 行）
- 出场的人：千奈、プロデューサー、メイド
- 场景：她和制作人谈下一个目标（0001～0018），之后谈粉丝俱乐部，女仆香名江在场（0019～0045），再回到和制作人的谈话；地点剧本没写明
- 世界线：亲爱度（倉本千奈）；制作人在制作的偶像：倉本千奈（0003「倉本さんの次の目標は『N.I.A』」）

## 发生了什么
制作人说她下一个目标是『N.I.A』最终日的『FINALE』优胜 live，她先觉得太冒险；制作人说她比预定成长得更快更强，有足够胜算，N.I.A 对他们很有利，她看到制作人的坏笑，说既然先生这么说她就相信（0001～0015）。制作人说顺利的话冬天的 H.I.F 也可能参加，她说梦越来越大（0016～0018）。说到她的粉丝俱乐部，原来倉本集团的人已经成立了非公式粉丝俱乐部，会员是祖父母、父母、亲族和关联公司的董事等，女仆香名江也是会员 No.9；香名江说亲族、家臣看了她的 live 都哭了（0019～0030）。香名江说只要她一声令下就能集齐超过出场条件的粉丝投票，她拒绝：命令别人喜欢自己就不算偶像，引用先生说倉本的名和权威是她的才能，行使它伴随着责任、不能滥用；她批准成立粉丝俱乐部，但粉丝要靠自己的偶像活动来增加，对正当的偶像活动的支援则感谢接受（0034～0043）。制作人夸她，她说再一次觉得自己的家世真狡猾，但被问是否内疚时说完全没有，会负起责任走自己的路（0046～0050）。制作人解释 N.I.A 有观众投票、更考验制作人，她高兴地说那她一定能优胜，因为她的先生是世界第一的制作人（0053～0059）。制作人说要注意的制作人是星南和黒井崇男，要用倉本集团全力支援的『961式プロデュース改』大量上电视；她说先生做坏脸也骗不了她，知道他在应付无法拒绝的支援，说会做好电视工作回报先生（0061～0078）。

## 行为模式
- 被给出很高的目标 → 先说太冒险，看到制作人有把握后就相信并立刻干劲十足（0005、0012～0018）
- 家人过度支持 → 先惊讶、害羞地说他们偏心（0026、0031），但涉及用权势拉票时马上拒绝，划清界线：正当的支援接受，靠命令得来的喜爱不要（0036～0043）
- 被问是否为家世内疚 → 承认“狡猾”，但不内疚，说要负起责任（0048～0050）
- 听不懂说明 → 笑着坦白听不懂，请对方说简单点（0055）
- 制作人摆出坏人脸 → 看穿背后的苦衷，向他道歉并表示要回报（0076～0078）

## 关系
- 制作人：叫「先生」（0005、0012、0076）；制作人叫她「倉本さん」（0003、0071）。相信他的判断（0013），说他是世界第一的制作人（0059，制作人心里话觉得这份信任耀眼，0060）；看出他在应付家里的支援而体谅他（0077）
- 香名江（标签『メイド』）：她叫「香名江」（0028）；香名江叫她「お嬢様」（0027、0044）。是非公式粉丝俱乐部会员 No.9，负责她和俱乐部之间的联络（0027）

- 星南：她叫「星南お姉さま」，知道星南是 N.I.A 值得注意的制作人之一（0062）
- 黒井崇男：极月学园理事长、961プロ社长（0063），她叫「黒井社長」（0073）
