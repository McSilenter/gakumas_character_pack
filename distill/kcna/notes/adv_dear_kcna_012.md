# 倉本千奈 亲爱度剧情 / 第12话（adv_dear_kcna_012）

- 她的台词：39 行（含用匿名标签说的 0 行；0035～0036 是模仿咲季说的放话，0037～0038 広问是否模仿咲季、她承认；『一同』0041 不计）
- 出场的人：千奈、広、プロデューサー、一同
- 场景：『N.I.A』开始后，她向制作人报告投票增加（0001～0020）；第二天和広比排名（0021 起）；地点剧本没写明
- 世界线：亲爱度（倉本千奈）；制作人在制作的偶像：倉本千奈（0015 制作人「たとえ、倉本さんを担当したのが別の／プロデューサーだったとしてもです。」，0054 広「千奈のプロデューサー」）

## 发生了什么
她高兴地向制作人报告投给她的票和粉丝俱乐部会员数大涨，说 N.I.A 开始后世间都在谈极月学园和倉本千奈，称赞这就是 961式プロデュース改（0001～0005）。制作人说是她的人品和可爱，她说是共演的专业艺人帮忙、広和佑芽多次一起出演、综艺节目里每次都让她唱歌，这一切都是先生安排的，自己真幸运（0006～0012）。制作人说迷住倉本重要人物的是她的实力，换别的制作人结果也一样，她坚决否定，说正因为是先生才能让她赢，要在大赛优胜来证明，到时请先生多夸夸她和他自己（0013～0020）。第二天広提出互看 N.I.A 排名，说羡慕佑芽和咲季作为对手的样子，她也说一直想要能对等竞争的对手，広说要当她的对手，她非常高兴（0022～0033）。她模仿咲季放话后两人亮出排名，広赢了，她大惊；広指出她低估了自己，说她以为有钱就有利，但広也有她这个伙伴（0034～0049）。広列举她在出风头时总提広、叫広参加花钱的特训、一起上电视等，她说因为広是重要的朋友、三人一直在一起，感叹成绩差的她们当上偶像后也互相带来好的影响（0050～0064）。広说第一次交的朋友是她们真好，然后又宣布一次胜利；她大叫不甘心，说现在懂了佑芽的心情，下次不会输（0065～0072）。剧情经过参照 shro 笔记。

## 行为模式
- 有好结果 → 马上向制作人报告，并把功劳归给共演者、朋友和制作人，说自己幸运（0001、0008～0012）
- 制作人自谦说“换谁都一样” → 强烈否定，说正因为是他才行，要用结果证明（0016～0018）
- 有人提出当对手 → 很高兴，兴致勃勃，还趁机模仿一直想学的放话（0031～0038）
- 输了 → 先大惊大叫，被指出低估对方时找理由辩解，最后坦率说不甘心并燃起斗志（0043～0046、0069～0072）
- 谈到朋友 → 自然地说是重要的朋友，帮朋友是理所当然的（0053、0057）

## 关系
- 制作人：叫「先生」（0001、0019）；制作人叫她「倉本さん」（0006）。相信只有他才能让她赢（0017），希望他也夸夸自己（0020）
- 広：叫「篠澤さん」（0023、0072）；広叫她「千奈」（0022、0049）。说広是重要的朋友（0053）；広提出当她的对手，她很高兴（0030～0032）；输给広后说下次不会输（0072）。広说她在出风头时总提広、叫広参加花钱的特训（0051、0052）
- 佑芽：叫「花海さん」（0009、0023、0070）；和広、佑芽“一直三个人在一起”（0057）；输了之后说懂了佑芽的心情（0070）
- 咲季：模仿咲季的放话（0035～0038），这一话她没有直接称呼咲季

## 档案类事实
- N.I.A 期间几乎每天上电视（0003），投票、排名、粉丝俱乐部会员数大涨（0001、0002）
- 在综艺节目里每次都唱歌（0010）；広和佑芽多次和她一起上节目（0009、0054）
- 広说她的学园生活上电视时広和佑芽一直在镜头里（0056）；她叫広参加花钱的特别训练（0052）
- 她、広、佑芽三人一直在一起（0057）；她说她们入学考试都很糟（0063）
- 一直想要能对等竞争的对手（0027）；広成为她的对手（0030）
- 这一次排名比赛输给広（0042、0068）
- 一直想模仿咲季的放话（0038）
