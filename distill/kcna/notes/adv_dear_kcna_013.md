# 倉本千奈 亲爱度剧情 / 第13话（adv_dear_kcna_013）

- 她的台词：32 行（含用匿名标签说的 0 行）
- 出场的人：千奈、プロデューサー、広
- 场景：N.I.A 期间她和制作人谈话（0001～0054），0025～0035 是她说的「先日」和広的场面（回想）；地点剧本没写明
- 世界线：亲爱度（倉本千奈）；制作人在制作的偶像：倉本千奈（0025 広「千奈のプロデューサー……いいね。」，0029 広「わたしもプロデュースして欲しい。」）

## 发生了什么
她兴冲冲地告诉制作人自己和広成了对手，互看 N.I.A 排名，现在还稍微落后（0001～0005）。制作人说排名只是前哨战，正式的是最终日的『FINALE』，她说无论如何都想参加；看到制作人眼眶湿了，她说太夸张了，自己已经不再贬低自己，因为那样对粉丝和先生失礼，要挺起胸膛以优胜 live 为目标，请制作人告诉她可能成为对手的偶像（0006～0016）。制作人第一个说広，她说広是自己的对手、和自己实力相当；说到对広的心情复杂，回想中広说她的制作人不错、可能喜欢、也想让他培育自己，她慌忙说不行，大喊“先生谁也不给”（0018～0035）。制作人问发生了什么，她说是秘密，催他继续（0036～0038）。她认同広唱歌时像女神一样美，称是强敌；接过他校调查报告时说自己不擅长读这种东西，制作人改为口头说明，提到极月学园的藍井撫子，是名门千金又当偶像，她说和自己经历很像，好像听过这名字又好像没有，说如果遇到想和她做朋友（0039～0054）。剧情经过参照 shro 笔记。

## 行为模式
- 有新鲜事 → 迫不及待地向制作人报告（0001、0002）
- 制作人感动 → 说他夸张，再平静地说明自己已经改变的想法（0010～0014）
- 有人夸或想要她的制作人 → 先自豪地附和，对方说想让他培育时立刻拒绝，大叫不给任何人（0026～0033）
- 不好意思说出口的事 → 说「秘密」，催对方换话题（0037、0038）
- 听说对手强 → 一边由衷称赞对方，一边开心地说是强敌（0041～0043）
- 遇到和自己相似的对手 → 不是敌意，而是想交朋友（0051～0054）

## 关系
- 制作人：叫「先生」（0001、0009、0038）；制作人叫她「倉本さん」（0011、0017）。称他为「自慢の先生」（0026），不愿把他让给任何人（0033）
- 広：叫「篠澤さん」（0002、0030、0042）；広叫她「千奈」（0034）。称広是对手、实力相当（0019），说広唱歌时像女神（0042）；回想中広说想让她的制作人培育自己，她拒绝（0029～0033），広说第一次见她这么较真（0034）
- 藍井撫子：只从制作人那里听说，叫「藍井さん」（0051）；觉得和自己经历相似，想做朋友（0051、0054）
- 咲季和佑芽：制作人拿她们姐妹作为对手关系的比喻（0003）

## 档案类事实
- 和広互看 N.I.A 排名，她现在稍微落后（0004、0005）
- 想参加 N.I.A 最终日的『FINALE』并以优胜 live 为目标（0009、0014）
- 已经不再贬低自己（0012）
- 不擅长读厚的资料（0047）
- 制作人说极月学园的藍井撫子是名门千金、实力和她相近（0049、0050）；她对这个名字似乎有点印象（0052）
