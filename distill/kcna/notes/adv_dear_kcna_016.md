# 倉本千奈 亲爱度剧情 / 第16话（adv_dear_kcna_016）

- 她的台词：27 行（含用匿名标签说的 0 行；0005 和 0031 是重现前面的场面：0004～0016 是她讲和撫子交涉的经过（回想），0030～0031 是她回想自己在台上说过的话）
- 出场的人：千奈、プロデューサー、撫子
- 场景：她赢过撫子的表演之后和制作人谈话（0001～0003、0016 起）；0004～0015 是回想和撫子交涉的场面；地点剧本没写明
- 世界线：亲爱度（倉本千奈）；制作人在制作的偶像：倉本千奈（0046 制作人「一流アイドルを目指して、／がんばりましょう。」）

## 发生了什么
她问制作人有没有看，制作人说她漂亮地赢了强敌；她说多亏先生，和藍井さん也成了朋友（0001～0003）。回想交涉时：她说一直觉得听过藍井的名字，经先生告诉才想起来，她的父亲、祖父和撫子的父亲、祖父关系很好，因为藍井家是倉本的子公司；撫子得知她是倉本会长的孙女后惨叫（0004～0015）。她说告诉对方家人们关系很好时对方很吃惊，买光的周边应该能送到粉丝手里，希望広的粉丝能恢复精神（0016～0019）。制作人心里想：只要她在，恶意就会淡去消失，这绝不只是家里权势的缘故（0020、0021，制作人的心里话）。制作人说她在台上突然做了预定外的 MC 让他捏把汗，原来她在台上说了“托大家的福可以挺起胸说自己是出色的二流偶像”；制作人说「二流」不是夸耀实力时用的词，她慌了，怕粉丝嫌弃（0024～0036）。制作人说粉丝们的反应是“现在确实还不是一流吧”，粉丝俱乐部里还兴起了“靠我们把千奈ちゃん变成一流偶像”的气氛；她说很感激但心情复杂，太依赖粉丝了（0037～0044）。制作人说被粉丝支持的力量就是她最大的武器，她宣言要制霸 N.I.A、成为一流偶像（0045～0048）。

## 行为模式
- 表演完 → 马上问制作人看没看到，把成果归功于制作人（0001、0003）
- 对立的对象 → 不是去压人，而是用“家人关系很好”的方式说出事实；把结果当成“交到了朋友”（0003、0009～0011、0016）
- 事情解决 → 首先想到的是粉丝能拿到周边、広的粉丝恢复精神（0017、0019）
- 被指出说错话 → 不明白自己做了什么，想起后得知用词不当就慌，担心粉丝的看法（0027、0029、0034～0036）
- 被指出实力不足 → 不受伤，反而高兴粉丝看得准（0040）
- 得到大量支持 → 感激又不安，怕自己太依赖别人（0043、0044）

## 关系
- 制作人：叫「先生」（0001、0022、0034）；制作人叫她「倉本さん」（0020，心里话）。把和撫子交朋友归功于他的建议（0003、0007）；察觉他很高兴（0022）
- 撫子：叫「藍井さん」（0003、0006）；她说两人成了朋友（0003）。撫子家是倉本的子公司，双方父亲、祖父关系很好（0009～0011）；撫子得知她是倉本会长的孙女后惨叫（0013、0015）
- 粉丝：粉丝俱乐部兴起“把千奈ちゃん变成一流偶像”的气氛（0041、0042）；她感激又觉得太依赖他们（0043、0044）
- 広：希望広的粉丝恢复精神（0019）

## 档案类事实
- 藍井家是倉本的子公司，双方的父亲、祖父关系很好（0009～0011）；撫子称她祖父为「くらもと会長」（0013）
- 在一场表演中赢了撫子（0002）
- 在台上即兴做了预定外的 MC，说自己是「立派な二流アイドル」（0024、0031）；制作人说「二流」不是夸耀实力时用的词（0033）
- 粉丝俱乐部里兴起“靠我们把千奈ちゃん变成一流偶像”的气氛（0041、0042）；制作人说粉丝的支持是她最大的武器（0045）
- 新目标：制霸 N.I.A，成为一流偶像（0048）
