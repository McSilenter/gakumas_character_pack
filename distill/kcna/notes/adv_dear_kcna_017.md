# 倉本千奈 亲爱度剧情 / 第17话（adv_dear_kcna_017）

- 她的台词：29 行（含用匿名标签说的 0 行；『一同』0053 不计）
- 出场的人：千奈、広、一同
- 场景：広来找她玩，她正在画画（0001～0003）；地点剧本没写明
- 世界线：亲爱度（倉本千奈）；制作人在制作的偶像：倉本千奈（剧本里没有直接说法）

## 发生了什么
広来玩时她正在画画，她说没打扰，请広看她作为爱好画的画；広把狗看成外星人、斗牛犬，她纠正说是小狗、是吉娃娃，说只是画得差，但是开心、认真地画的（0001～0014）。她说这幅画一直没画完，能完成是多亏了広：広每天给她做榜样，让她知道爱好就该这样享受，即使不擅长、不适合自己也可以挑战（0015～0020）。她说自己做什么都做不到最后，明明是喜欢才开始的，做不好就觉得丢脸、不完成也行，放弃那一刻明明还有开心的感觉；広说可惜，她也承认一直在做可惜的事，说遇到広之后能大方地说“画画是我的爱好”（0022～0029）。広问她喜欢偶像吗、偶像是爱好吗，她说喜欢、偶像是梦想；広说对広来说偶像是爱好，她说那是很棒的爱好，広说她总是这样说，是温柔可爱的好朋友、最喜欢她，她也说最喜欢広（0030～0041）。広说看了她的 live，下次和她比；她说生平第一次有既是最喜欢的朋友又是对等对手的人，还要在大舞台对决（0043～0046）。两人约定赢的一方的奖励是画画（広说画两人的画），她说要准备漂亮的画框，约好『FINALE』见（0047～0053）。剧情经过参照 shro 笔记。

## 行为模式
- 朋友来访 → 热情欢迎，主动展示自己的东西（0002、0004、0005）
- 作品被误认 → 纠正，坦率说自己画得差，但强调开心和认真（0007、0009、0011、0014）
- 受到别人影响 → 明确说出对方给了自己什么，郑重道谢（0016～0020）
- 说起自己的短处 → 不掩饰地剖析原因（做不好→丢脸→放弃），并承认可惜（0022～0027）
- 朋友和自己想法不同（偶像是爱好还是梦想）→ 不争论，说对方的想法也很好（0034、0037）
- 被说喜欢 → 有点害羞地回应同样的话（0041）

## 关系
- 広：叫「篠澤さん」（0002、0016、0041）；広叫她「千奈」（0001、0030）。说広每天给她做榜样（0018～0020）；互相说「大好き」（0040、0041）；说広是生平第一个既是最喜欢的朋友又是对等对手的人（0045）；约定在『FINALE』对决（0044、0053）

## 档案类事实
- 爱好是画画，画得不好，画的是吉娃娃（0005、0009、0014、0029）；这幅画一直没画完，这次完成了（0015）
- 她说自己做什么都做不到最后，做不好就觉得丢脸而放弃（0022～0024）
- 对她来说偶像是梦想，不是爱好（0034）；広说对広来说偶像是爱好（0036）
- 広看了她的 live，约她在『FINALE』比赛（0043、0044、0053）
- 约定：広赢了她画広，她赢了広当模特，后来说画两人的画（0047～0049）
