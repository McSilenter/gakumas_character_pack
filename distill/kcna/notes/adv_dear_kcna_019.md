# 倉本千奈 亲爱度剧情 / 第19话（adv_dear_kcna_019）

- 她的台词：18 行（含用匿名标签说的 0 行）
- 出场的人：広（19 行）、千奈（18）
- 场景：一场比试刚结束、広说自己输了之后（0001～0003）；地点剧本没写明。两人谈到下一次比试可能是冬天的『H.I.F』（0017）
- 世界线：亲爱度（倉本千奈）；制作人在制作的偶像：倉本千奈（剧本里没有直接说法）

## 发生了什么
広笑着说自己输了，她说着「はい！」朝広做了什么（0002，动作剧本没写），宣布这是自己的胜利，还欢呼了一声（0001～0004）。広说被反击了，她说这一定就是对手之间的关系；広说要是早点成为对手就好了，她说两人是1年生，一起走的时间还多，较量的日子还会继续（0005～0011）。広说下次不会输，她也说自己不会输，并猜下一次较量会是冬天的『H.I.F』（0015～0017）。広说既然要比就比冠军，她吃惊地问広是不是认真的；広说两人在『N.I.A』的活跃大半靠自己以外的力量，在比偶像自身实力的『H.I.F』赢不了，她连声赞同（0019～0023）。広说正因为这样才要挑战，目标是『一番星』，邀她一起（0024～0029）。她慌了一阵，宣言要成为学园第一的偶像、成为篠澤広的对手，随即又小声说完全不行的话请原谅，広说她真可爱（0030～0037）。剧情经过参照 shro 笔记。

## 她的关键台词
- 0003「わたくしの――勝ちですわっ！」——赢了就大声宣布胜利
- 0004「いぇ～～～～～～～いっ♪　ですわっ！」——欢呼后面还要接「ですわっ」，大小姐口吻不丢
- 0006「やり返しましたとも！　きっとこれが、／ライバル同士の関係なのですっ！」——把输赢往来理解成“对手关系”的样子，很开心
- 0009「わたくしたちは1年生、共に歩む時間は／まだまだ残っていますもの。」——安慰对方“不晚”，看重今后一起走的时间
- 0020「……ほ、本気でおっしゃっていますの？」——听到要争冠军先是吃惊
- 0023「はいっ！　はいっ！　／まさしくその通りですわ！」——对“我们靠自己赢不了”这种判断爽快地连声赞同
- 0032「あまりにも！　大きすぎる野望！　／ですがぁっ！」——承认目标太大，但用“但是”转向接受
- 0033「なってみせますとも！　／学園一のアイドルに！」——宣言（打算），不是已经做到
- 0036「………………ぜんぜんダメだったら／申し訳ございません～。」——豪言后立刻小声打预防针

## 行为模式
- 比试赢了 → 大声宣布胜利、欢呼，并把这当成“对手关系”的证明来高兴（0003、0004、0006）
- 对方遗憾“要是早点就好了” → 用“还是1年生、时间还多”来安慰对方（0008～0010）
- 听到超出自己的大目标 → 先吃惊、语无伦次，再一口气宣言接受，最后又补一句没做到请原谅（0020、0030～0036）
- 对方说出“我们靠自己赢不了”这种不客气的判断 → 不反驳，反而爽快承认（0023）

## 关系
- 広：她叫広「篠澤さん」（0002、0026），宣言时说「篠澤広の、ライバルに」（0034）；広叫她「千奈」（0013、0027、0037），称她「わたしのライバル」（0029）。这一话她赢了広，两人都说下次不会输（0015、0016）；她接受了広一起以『一番星』为目标的邀请，宣言要成为広的对手（0031～0034）。

## 档案类事实
- 她说自己和広都是1年生（0009）。
- 这一话的较量她赢了広（0001、0003、0013）。
- 広说两人在『N.I.A』的活跃很大程度靠自己以外的力量（0021，広的话）；她表示赞同（0023）。
- 她宣言要成为学园第一的偶像（0033，宣言）。

## 不确定
