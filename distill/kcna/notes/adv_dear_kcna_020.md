# 倉本千奈 亲爱度剧情 / 第20话（adv_dear_kcna_020）

- 她的台词：45 行（含用匿名标签说的 0 行）
- 出场的人：千奈（45 行）、プロデューサー（14）
- 场景：她在一场有很多观众的舞台唱完、回到制作人身边时（0001、0003、0005）；地点剧本没写明。制作人谈到『N.I.A』这次大会和之后的『H.I.F』（0019、0046～0048）
- 世界线：亲爱度（倉本千奈）；制作人在制作的偶像：倉本千奈（0010、0055）

## 发生了什么
她演出结束回来，说唱完之前忍住了，现在眼泪停不下来；那么多人在她的舞台上高兴，明明很开心却一直哭（0001～0008）。制作人说今天的记忆是她的宝物，她说毕业、退出偶像、变成老奶奶也不会忘记今天每一位观众的脸（0009～0016）。制作人问她通过『N.I.A』做了各种活动感觉如何，她说非常辛苦、给很多人添了麻烦，但很开心、学到很多，又一一感谢粉丝和在音乐、作词、编舞上出力的人，说粉丝才是她作为偶像的力量，自己一个人什么都做不到（0019～0039）。制作人说她果然有偶像的才能、学园长的眼光没错（0040、0041）。她说和朋友约好要成为『一番星』，问自己能不能做到；制作人说会苦战，这次大会她的活跃称得上准『一番星』（0044～0047）。她说『H.I.F』得靠本来的实力，制作人说支撑她的力量已经分不开，她想起课上学过“本来的实力”包含支撑自己的一切力量，于是说在『H.I.F』也能堂堂正正地战斗，最后自称“世界上最不成熟的一流偶像”（0048～0059）。

## 她的关键台词
- 0003「はい……歌い終わるまでは……／我慢できたのですが……」——唱完之前忍住眼泪，结束后才哭出来
- 0007「どうしましょう……！　／こんなにも嬉しいのに……」——高兴到哭，自己也不知所措
- 0013「遠い未来、わたくしが、しわくちゃの／お婆さまになっても！」——用很具体的远景说“永远不会忘”
- 0015「今日、一生懸命応援してくださった／皆さま、ひとりひとりのお顔……」——记住的是观众每一个人的脸
- 0024「と～～～～～っても大変でしたわ！」——辛苦也直率地拉长音说出来
- 0026「多くの方にご迷惑をお掛けして……／いつも申し訳なくて。ですけれど……」——总觉得给别人添麻烦，随后转到“但是很开心”（0027）
- 0036「ファンの皆さまこそが、倉本千奈が／振るう、アイドルとしての力だと。」——她对“偶像的力量”的看法
- 0039「ひとりでは、／なんにもできない自信がありますわ！」——把“一个人什么都做不到”说成“有自信”，带着得意的语气
- 0045「『一番星』になってみせると。／……できるでしょうか？」——说出和朋友的约定，又马上不安地问
- 0055「最高のプロデューサーが、／付いていますものっ！」——当面称制作人是最棒的制作人
- 0058「世界で一番未熟な――――」
- 0059「一流アイドルですわっ！」——和 0058 连起来，自称“世界上最不成熟的一流偶像”

## 行为模式
- 舞台上 → 忍住眼泪到唱完；回到制作人面前才哭出来（0003、0007、0008）
- 被问到感想 → 先坦白“辛苦、给人添麻烦”，再转到“开心、学到很多”，然后逐一感谢帮过她的人（0024～0034）
- 说到自己的力量 → 不讲个人实力，而是归功于粉丝和支持她的人，并且很自豪地承认一个人做不到（0036～0039）
- 被夸奖 → 觉得不可思议，说自己明明只露出了糟糕的地方（0042、0043）
- 说出大目标后 → 马上不安地问“能做到吗”（0018、0045）；制作人给出新的看法后，她自己接上课上学过的说法，转为自信（0052～0054）

## 关系
- 制作人：她叫「先生」（0001、0044），也当面说「最高のプロデューサー」（0055）；制作人叫她「倉本さん」（0002），谈她时用全名「倉本千奈」（0010、0046）。她把高兴到哭的样子直接给制作人看，也把和朋友的约定告诉他、问他自己能不能做到（0044、0045）。
- 朋友：她说和朋友约好要成为『一番星』（0044、0045），本篇没写是谁。
- 学园长：制作人说学园长的眼光是对的、没有老糊涂（0041，制作人的话），本篇没写学园长对她做过什么。

## 档案类事实
- 她通过『N.I.A』作为新人偶像做了练习、试镜、演出，还挑战了各种工作（0019～0022）。
- 制作人说这次大会里她的活跃称得上准『一番星』（0047，制作人的话），也说她和『N.I.A』相性非常好（0046）。
- 有人为她在音乐、作词、编舞上出力（0030）。
- 她说在课上学过“出道后的偶像的本来实力，包含支撑自己的一切力量”（0051、0052）。
- 她和朋友约好要成为『一番星』（0044、0045）。

## 不确定
- 0044「お友達」是谁本篇没写；结合第19话（広邀她一起以『一番星』为目标）可能是広，本篇没直接说。
- 这场舞台是哪一场（『N.I.A』里的哪一次），本篇没写明。
- 0041 学园长“眼光正确”具体指什么，本篇没交代。
- 0049 制作人说「すこし違います」，否定的是 0048“必须靠我本来的实力去战斗”的哪一部分，结合 0050～0052 读作：本来的实力本身就包含支撑她的力量，不是“没有支持也要靠自己”；但这是读法。
