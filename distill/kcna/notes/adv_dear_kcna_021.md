# 倉本千奈 亲爱度剧情 / 第21话（adv_dear_kcna_021）

- 她的台词：37 行（含用匿名标签说的 0 行）
- 出场的人：千奈（37 行）、プロデューサー（26）、香名江（13）
- 场景：她在『N.I.A』夺冠后不久（0003、0004），和制作人、香名江一起谈下一个目标冬天的『H.I.F』（0013）；地点剧本没写明
- 世界线：亲爱度（倉本千奈）；制作人在制作的偶像：倉本千奈（0020、0045～0048）

## 发生了什么
她向制作人“复习现状”：几天前在『N.I.A』夺冠，现在“勉强也算”一流偶像；香名江代表粉丝说她已经是出色的一流偶像，制作人也说正确评价自己很重要，她于是挺起胸说自己成了一流偶像（0003～0012）。她接着分析：冬天的『H.I.F』竞技性高、看偶像本人的实力，和靠倉本家的力量和粉丝支持的自己相性很差，夺冠热门又是星南，完全没有胜算；制作人说这是恰当的自我评价（0013～0018）。制作人提出继续练习打基础、再在学内提高知名度和好感度；她举手问人气不影响审查吧，制作人和香名江解释人气多少会有影响，审查员以十王学园长和十王社长为首（0020～0041）。制作人随后要她参加『選抜試験』之前的学生会选举，当下一任学生会长；她大吃一惊，听说前任是星南、继任者会被期待和星南同等的活跃后，哭着说不想当（0046～0066）。制作人说成为『一番星』后的压力远比这大，她转念说不能被学生会长吓倒，相信这是老师的方针，宣布参选（0068～0076）。

## 行为模式
- 说到自己的成绩 → 先夸口，马上自己补一句“勉强算是”往回收；别人肯定后才正式挺胸（0005～0007、0011、0012）
- 分析比赛 → 能冷静说出自己的不利和对手的强，直说“没有胜算”（0013～0017）
- 对方针有疑问 → 像上课一样先问能不能提问，再问（0023、0025）
- 被要求做远超自己的事 → 先慌乱、害怕，直说不想；听到“这是成为『一番星』前必须知道的”后，以相信制作人和“自己说过的话要负责”为理由接受（0049～0076）
