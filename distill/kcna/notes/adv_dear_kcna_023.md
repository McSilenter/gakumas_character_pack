# 倉本千奈 亲爱度剧情 / 第23话（adv_dear_kcna_023）

- 她的台词：34 行（含用匿名标签说的 0 行）
- 出场的人：千奈（34 行）、プロデューサー（15）、燕（8）、香名江（4）、莉波（1）、星南（1）
- 场景：她参加完学生会选举说明会回来，和制作人、香名江一起准备参选演说（0001、0002）；中间插入燕给她提示的一段，莉波、星南也在（0033～0043）。地点剧本没写明
- 世界线：亲爱度（倉本千奈）；制作人在制作的偶像：倉本千奈（0030、0061）

## 发生了什么
她说说明会回来了，演说内容已经想好；她说平时所有作业都拖到最后才完成，这次却早早准备好，因为选会长对学园的大家很重要，现任会长尽职大家才能快乐地过学生生活，所以要好好介绍自己、让大家认可后再选她（0001～0013）。制作人要她当场练习，她慌了一下还是讲了，制作人和香名江都说好（0015～0022）。她说没有背稿，只是把对学园大家的心情照原样说出来，制作人称她不愧是“谈话节目的天使”，她说这个称呼有点难为情（0024～0031）。中间插入燕的一段：燕说她当不成星南那样的会长、也不必，当“倉本千奈风格的会长”就好，并用项羽和刘邦的轶事作提示（0033～0043）。她对制作人说出方针：召集一起打选举的伙伴；她说自己不能像星南那样靠压倒性实力君临学园，没有伙伴帮忙什么都做不到，所以请老师和香名江当她最初的伙伴（0045～0057）。香名江说永远和她在一起，制作人问“我们是伙伴吧”，她说老师是老师、是制作人，这次是伙伴，问他能否答应自己的任性，制作人说乐意（0058～0063）。剧情经过参照 atbm 笔记。

## 她的关键台词
- 0005「ふっふっふ……あらゆる課題を／ぎりぎりで終わらせるわたくしですが。」——自曝作业总拖到最后
- 0006「今回ばかりは、／早々に準備を終えましたわ。」——这次例外，带着得意
- 0010「楽しく学生生活を送ることが／できているのは、当代の生徒会長が、」——她对学生会长职责的理解（和 0011 连着）
- 0013「納得した上で／選んでいただかなくては！」——希望大家认可后再投票，而不只是当选
- 0018「そっ……それは……それは……」——突然被要求当场练习时的慌乱
- 0025「いいえっ、わたくしにそんな記憶力など／ございませんわ。」——否认背稿，也自贬记性
- 0027「ただ、ただ……／そのまま口にしただけですわ。」——演说是把心情原样说出来
- 0031「ちょっぴり恥ずかしい呼び名ですわ……／こほん。」——被叫“谈话节目的天使”时害羞，用咳嗽岔开
- 0046「生徒会選挙を共に戦う、／心強い仲間を集めますわ！」——她定下的方针
- 0054「仲間に助けていただかないと、／わたくし、なんにもできませんわ。」——承认自己做不到，所以要找伙伴
- 0056「わたくしの、／最初の仲間になってくださいませ。」——请制作人和香名江当最初的伙伴
- 0061「はい……先生は、先生で、／プロデューサーで……／今回は、仲間ですわ。」——给制作人的身份再加上“伙伴”

## 行为模式
- 自己觉得重要的事 → 一反平时拖延的习惯，提前准备好（0005～0013）
- 被突然要求当场表现 → 先结巴慌乱，随即说“明白了”并照做（0016～0019）
- 被夸 → 先笑（0022），再谦虚地否认自己有过人之处，说只是照心情说出来（0025～0027）
- 被叫响亮的称号 → 害羞，咳一声转话题（0031）
- 定方针 → 从“自己一个人做不到”出发，选择找伙伴、请身边的人帮忙，并把这说成自己的“任性”来拜托（0050～0057、0062）
- 得到提示后 → 主动说明是谁给的提示，不独占功劳（0048）

## 关系
- 制作人：叫「先生」（0001、0032、0062）；制作人叫她「倉本さん」（0017、0044、0047）。她说老师既是老师又是制作人，这次请他当伙伴（0061）；制作人说她的方针最棒、很适合她（0047）。
- 香名江：她叫「香名江」（0019、0055）；香名江叫她「お嬢様」（0014、0021）、全称「倉本千奈お嬢様」（0028），说永远和她在一起（0058）。她请香名江当最初的伙伴之一（0055、0056）。
- 燕：她叫「雨夜先輩」（0048）；燕叫她「倉本」「貴様」（0033），给了她项羽和刘邦的提示（0038～0040）。
- 星南：她叫「星南お姉さま」（0050），说自己不能像星南那样靠压倒性的实力君临学园（0050、0051）；燕说她当不成星南那样的会长，也不必（0034、0035）。

## 档案类事实
- 她说自己所有作业都会拖到最后才完成（0005）。
- 她被称为“谈话节目的天使”（0030，制作人的话），她觉得这个称呼有点难为情（0031）。
- 演说没有背稿，是把心情照原样说出来（0025～0027）。
- 她的方针是召集一起打选举的伙伴（0046），最初的伙伴是制作人和香名江（0055、0056）。
