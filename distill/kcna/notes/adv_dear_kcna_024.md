# 倉本千奈 亲爱度剧情 / 第24话（adv_dear_kcna_024）

- 她的台词：24 行（含用匿名标签说的 0 行）；其中 0052、0053 是她的心里话（括号）；0070「一同」不算在内
- 出场的人：千奈（24 行）、香名江（21）、プロデューサー（7）、佑芽（6）、美鈴（7）、広（4）
- 场景：她开始召集选举伙伴，在参选演说的前一天（0067「明日の演説」）；地点剧本没写明。0022～0027 是制作人回想初见香名江的场面（0028 制作人心里话「あれから半年以上が経った」）
- 世界线：亲爱度（倉本千奈）；制作人在制作的偶像：倉本千奈（0018、0019）

## 发生了什么
她兴冲冲地说要召集伙伴；香名江提议效仿刘邦的“汉初三杰”召集不同类型的伙伴，自荐当内政的萧何，她说交给香名江就放心（0001～0008）。香名江说军师张良体弱、头脑好，两人都想到同一个人；说到大将军韩信，她第一个想到的是制作人，说他是她走偶像之路不可替代的人，制作人说会努力当她的韩信（0009～0019）。香名江提醒制作人背叛主君的韩信下场悲惨，制作人在心里回想初见香名江时被说要“看清你有没有资格引导大小姐”，大半年过去她的态度还是带刺（0020～0029，制作人的回想和心里话）。她去邀请広，広答应当张良；邀请佑芽，佑芽说本来就打算、要把政敌打飞，她慌忙制止，又被问选举是否在擂台上打而不敢断言（0032～0045）。邀请美鈴，美鈴的条件是她当会长后把学生会人事权交给自己；她在心里猜美鈴想让朋友进学生会，当场答应全部交给美鈴（0046～0056）。她把三人介绍给制作人和香名江，三人各自报上名号（美鈴自称项羽），她笑说韩信将军重复了，并招呼大家开会，准备明天演说后正式开始选举活动（0057～0069）。剧情经过参照 hume、hmsz 笔记。

## 她的关键台词
- 0001「さあっ、仲間集めですわ！／うふふ、どなたにお声がけしましょう。」——对找伙伴这件事兴致勃勃
- 0008「香名江なら安心して任せられますわ。」——对香名江的信任
- 0017「一番に思い付くのは――先生ですわ。」——“可靠的大将军”第一个想到制作人
- 0018「わたくしがアイドルの道を進むために、／掛け替えのない方ですもの。」——当面说制作人不可替代
- 0032「というわけで、篠澤さんっ。／わたくしの仲間になってくださいませ！」——直率地开口请求
- 0036「なんだかわたくし、いまなら／天下を狙えそうな気分ですわ！」——得到伙伴后马上得意起来
- 0041「ぼっこぼこにやっつけちゃダメですわ！／大事件になっちゃいますわ！」——吐槽、制止佑芽的过火发言
- 0045「戦いませんわ！　たぶん……きっと……／…………戦いませんわよね？」——被问住后自己也没把握
- 0053「（お友達を……／生徒会に入れたいのですわね）」——心里话：把美鈴的条件往好意的方向理解
- 0055「秦谷さんに、／人事をすべてお任せすると！」——没多问就把人事权全部许诺出去（和 0054 连着，是“当上会长后”的约定）
- 0063「うふふ、千奈帝国では韓信将軍が／かぶってしまいましたわ。」——把伙伴们称作“千奈帝国”，笑着接受混乱

## 行为模式
- 有人提好主意 → 立刻接受，并对提议人表示信任（0005、0008）
- 想到要依靠的人 → 第一个想到制作人，并当面说出他的重要（0017、0018）
- 请人帮忙 → 不绕弯子，直接说“请成为我的伙伴”（0032、0037、0046）
- 伙伴说出过火的话 → 认真地吐槽、制止；但被追问规则时自己也心虚（0041、0045）
- 对方提出条件 → 往善意的方向猜对方的动机，当场爽快答应（0052～0055）
- 身边的人多起来 → 情绪高涨，开玩笑（0036、0063），然后招呼大家开会推进下一步（0067～0069）

## 关系
- 香名江：她叫「香名江」（0057）；香名江叫她「お嬢様」「千奈お嬢様」（0002、0007）。香名江自荐当她的萧何，她说可以放心交给她（0007、0008）。香名江不是学园学生，不能陪她去找伙伴（0030）。
- 制作人：她叫「先生」（0017、0057），说他是她走偶像之路不可替代的人（0018）；制作人叫她「倉本さん」（0019）。
- 広：她叫「篠澤さん」（0032）、全名「篠澤広さん」（0058）；広叫她「千奈」（0035、0060），说被朋友拜托很开心（0033），当她的张良（0035）。
- 佑芽：她叫「花海さん」（0037）、全名「花海佑芽さん」（0058）；佑芽叫她「千奈ちゃん」（0038、0040），说本来就打算当她的伙伴（0038）。
- 美鈴：她叫「秦谷さん」（0046、0055）、全名「秦谷美鈴さん」（0058）；美鈴叫她「倉本さん」（0047、0050），以拿到人事权为条件向她宣誓忠诚（0050、0051、0062）。她答应了（0054、0055）。
- 香名江和制作人：制作人的心里话说两人像同事，但交流只限事务性对话，香名江的态度至今带刺（0028、0029，制作人的心里话）。

## 档案类事实
- 香名江是倉本家的侍从（0024），不是初星学园的学生（0030）。
- 她的选举伙伴：香名江（萧何）、広（张良）、佑芽（韩信）、美鈴（自称项羽），制作人也说要当她的韩信（0007、0019、0035、0060～0062）。
- 她答应美鈴：当上会长后把学生会人事权全部交给美鈴（0054、0055，约定）。
- 佑芽听高年级说初星学园的学生会选举不一般，会在电视上播（0043、0044，佑芽的话）。
- 制作人认识香名江已经半年以上（0028，制作人的心里话）。

## 不确定
- 0070「一同」「お～～～～～～～～～～～～っ！！」不算她的台词（这是她招呼大家之后的应和；hmsz 笔记【已确认】此行算美鈴的，她是否在内没有结论）。
- 0011～0013 她和香名江想到的“体弱、头脑好”的人，本篇没点名；后面広接下张良（0035），读作広，但 0011 时是否就指広，剧本没明说。
- 0052、0053 她猜美鈴想让朋友进学生会，这是她心里的推测，美鈴的真正意图本篇没交代。
- 0062 美鈴自称项羽（第23话燕的提示里项羽是刘邦的对手），她在 0063 只说韩信重复了，对项羽没有反应。
- 0022～0027 是制作人回想初见香名江的场面，不是这一话当下的对话；剧本没有直接标“回想”，依据是 0028 制作人心里话。
