# 倉本千奈 亲爱度剧情 / 第26话（adv_dear_kcna_026）

- 她的台词：37 行（含用匿名标签说的 0 行）
- 出场的人：千奈（37 行）、広（27）、美鈴（15）、佑芽（10）、プロデューサー（9）、旁白（1）
- 场景：得知学姐们成了对手之后，她和広、佑芽、美鈴商量应援 live 的安排（0001～0080）；地点剧本没写明。后半是应援 live 最终日、上台之前（0081）
- 世界线：亲爱度（倉本千奈）；制作人在制作的偶像：倉本千奈（0082～0095）

## 发生了什么
学姐们成为对手，她慌张地喊不得了，向“军师”広求秘策；広说让佑芽用铁球狙击星南，她说会是大惨事，佑芽还认真讨论，她要两人别当真（0001～0010）。美鈴问只是支援别人有那么可怕吗，她说应援 live 的热度差距一定会影响投票；広说规则里“在同一天的 live 最显眼”很重要，学姐们的日程已知，她以为是要避开那几天，広说她总是先这么说（0011～0020）。広在一周的 live 期间安排人员，第4到第6天全交给佑芽，她说太使唤佑芽、不知道怎么回报（0021～0041）。広问参加选举的成员是不是明年的学生会，她说只要大家愿意就是，并说请佑芽当下届副会长；美鈴提醒人事要先经过自己，她连忙征求同意，又小心地请美鈴继续当会计监查（0042～0058）。最终日広提议佑芽和她两人对星南、争取平局，她拒绝，说要一个人挑战星南，就算赢不了、选举变得不利，也要让大家在清楚比较之后选她或不选她；三人说早就知道她会这样说、早已选了她（0061～0080）。最终日上台前，制作人说这是和『一番星』的对演，选举的对手不是星南，可以在有利的状况下先赢一次；她看穿制作人早料到这个展开，最后说有自信、约定会赢（0081～0099）。剧情经过参照 hmsz、hume、shro 笔记。

## 行为模式
- 遇到意外 → 先大声慌张，再求助身边的人（0001、0002、0006）
- 伙伴说过火的玩笑 → 马上吐槽、制止（0008、0010）
- 面对强敌 → 第一反应是避开（0019）；但到了关键时刻会自己推翻“稳妥”的方案，选择正面挑战，宁可吃亏也要让大家在看清之后选择（0063～0071）
- 别人为她付出很多 → 担心对方太辛苦，想着怎么回报（0036、0040、0041）
- 被人提醒约定 → 马上认账，先征求对方同意（0050～0052）
- 制作人施加压力 → 先抗议，然后看穿他的意图，最后接下挑战并约定会赢（0083、0090～0092、0097～0099）

## 关系
- 広：她叫「篠澤さん」（0006）、「美少女軍師篠澤さん」（0036）；広叫她「千奈」（0003、0020、0047），自称千奈帝国的美少女军师（0004），负责安排 live（0021～0062），说她总会说出要正面挑战的话、早就选了她（0073、0076）。
- 佑芽：她叫「花海さん」（0036、0040、0048）；佑芽被安排连续 live 也很高兴（0035），她打算让佑芽当下届副会长（0048，打算）。
- 美鈴：她叫「秦谷さん」（0014、0052、0056），说美鈴一向无所畏惧（0014）；美鈴叫她「倉本さん」（0050），按第24话的约定要求人事先经过自己（0051），说她是自己看中的人（0058），称她才是下一代的学生会长（0077）。
- 星南：她叫「星南お姉さま」（0066、0069），称作“理想的学生会长”（0080），决定一个人去挑战她。
- 制作人：她叫「先生」（0083、0090、0097）；制作人叫她「倉本さん」（0082），说相信今天的她能做出不输星南的 live（0093、0094）。她能从制作人的表情看出他早料到局面（0090～0092）。

## 档案类事实
- 应援 live 期间是投票日前一天为止的一周（0021，広的话）；规则上“同一天的 live 里最显眼”很重要（0017，広的话）。
- 美鈴现在负责会计监查，她请美鈴继续担任（0056）；広说漏的话暗示佑芽现在是会计（0045、0046）。
- 她打算让佑芽当下届副会长，美鈴同意（0048、0053，打算）。
- 应援 live 最终日她一个人和星南对演（0066、0082，本篇写到上台前，结果未写）。
- 制作人说现阶段在『H.I.F』赢不了星南（0085，制作人的话）。
