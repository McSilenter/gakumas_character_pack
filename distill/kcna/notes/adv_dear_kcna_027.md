# 倉本千奈 亲爱度剧情 / 第27话（adv_dear_kcna_027）

- 她的台词：30 行（含用匿名标签说的 0 行）；0001、0002、0071「一同」不算在内
- 出场的人：千奈（30 行）、星南（15）、燕（8）、佑芽（6）、莉波（6）、美鈴（4）、広（2）
- 场景：学生会选举结束、她当选之后，大家为她庆祝（0001、0002）；地点剧本没写明。制作人在场（0061 她向「先生」确认），但本篇没有台词
- 世界线：亲爱度（倉本千奈）；制作人在制作的偶像：倉本千奈（剧本里没有直接说法；0010 她说先生为她增加了电视工作）

## 发生了什么
大家祝贺她当选；美鈴说结果是顺理成章，星南说投票前一天差距就已经不是自己的应援 live 能挽回的，燕说是压倒性的胜利（0001～0008）。她说这多亏了开应援 live 的伙伴、在好时机增加电视工作的老师、挡住倉本集团过度干涉的香名江，自己一个人绝对做不到，向大家道谢（0009～0013）。佑芽说她一个人挑战星南很棒、不输给『一番星』；燕说星南嘴硬才让佑芽来圆场，星南承认那是很好的 live，不输给自己（0014～0026）。星南把学生会托付给她和伙伴们，燕说她会是好会长，莉波说有她在的学园会温柔、让大家好过，她说一定做到、要让学园成为谁都能微笑的地方（0030～0044）。她向大家宣布要在冬天的『H.I.F』以『一番星』为目标，承认这话不自量力、以现在的她根本达不到，但说不管是不是会长、是不是偶像，都可以做梦、以顶点为目标，可以从轻松的心情开始，说这是老师教她的（0045～0061）。星南说“让你误会了”，燕说她自我评价太低，众人列举她的成绩——赢了佑芽拿下『N.I.A』冠军、学园最有名的电视艺人、在全校面前做出不输星南的舞台——说已经不把她当新人，而是对手；她吓得惊叫，随后说请多指教（0062～0074）。剧情经过参照 atbm、hmsz、hume、jsna 笔记。

## 行为模式
- 取得成果 → 先一个个点名感谢帮过她的人，强调自己一个人做不到（0009～0013）
- 被前辈托付 → 简短而认真地回答「はい」，再说出要做到的目标（0031、0034、0044）
- 宣布大目标 → 先自己承认不自量力、现在达不到，再说不能因此放弃；说理由时会当场改口，换成更普遍的理由（0047～0055）
- 讲道理时 → 会引用制作人教过的话，并向制作人确认（0059～0061）
- 被众人高看、被当成对手 → 先吓到惊叫，再礼貌地说请多指教（0072～0074）

## 档案类事实
- 她当选下一任学生会长（0002、0008、0032）。
- 选举期间制作人在好时机增加了她的电视工作（0010），香名江挡住了倉本集团的过度干涉（0011）。
- 她在应援 live 最终日一个人挑战星南，星南承认她的舞台不输自己（0015、0016、0026；星南说当时状况对她有利，0025）。
- 她宣布在冬天的『H.I.F』以『一番星』为目标（0047，宣言）。
- 佑芽说她赢了佑芽拿下『N.I.A』冠军（0066，佑芽的话）；広说她是初星学园最有名的电视艺人（0067，広的话）。
- 她说“梦想伴随责任，但可以从轻松的心情开始”是老师教的（0059～0061）。
