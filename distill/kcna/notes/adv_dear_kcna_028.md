# 倉本千奈 亲爱度剧情 / 第28话（adv_dear_kcna_028）

- 她的台词：46 行（含用匿名标签说的 0 行）；0036 是她应制作人要求故意装出来的“骄傲”高笑，不是她本来的态度
- 出场的人：千奈（46 行）、プロデューサー（16）、星南（5）
- 场景：她当选后来找制作人，说自己燃起来了（0001）；地点剧本没写明。0056～0061 星南的话是插入的回想（和第27话 0030～0033、0070 的话相同）
- 世界线：亲爱度（倉本千奈）；制作人在制作的偶像：倉本千奈（0003、0067）

## 发生了什么
她对制作人说燃起来了，制作人请她说明热情的理由，顺便回顾至今的制作（0001～0005）。她从入学考试最后一名、和老师命运般的相遇说起：知道制作人是受爷爷之托来的时很沮丧，后来他重新招揽她、说了她梦寐以求的话，她一生不会忘（0006～0016）。之后她和老师一起做偶像活动，为基础练习哭过、交了朋友、挑战定期公演，参加『N.I.A』并夺冠；她说这多亏『961式プロデュース改』、倉本集团的媒体宣传、粉丝和朋友前辈对手们，才被称为一流偶像，现在不谦虚也不骄傲，是“世界上最不成熟的一流偶像”（0017～0030）。制作人说想象不出她骄傲的样子、想看一次，她就装出高笑，被制作人大笑，她说太过分了（0031～0040）。她接着说现在的梦是学园顶点『一番星』，为此要突破『H.I.F選抜試験』、出场『H.I.F』、打倒所有对手、超越憧憬的星南（0043～0048）。制作人说她成长了，她说这是逞强，心里的倉本千奈正抱头哭着说怎么可能赢；但因为是下届会长、被星南亲自托付、被认可为对手，作为偶像必须回应期待，所以燃起来了，请老师教她赢的方法（0049～0065）。制作人说重新开始“『H.I.F』夺冠候补倉本千奈的制作”（0066、0067）。

## 行为模式
- 被要求说明理由 → 从最开头讲起，按时间顺序回顾（0005～0028），连制作人都在心里吃惊（0008，制作人的心里话）
- 讲到成绩 → 一一列出帮过她的人和力量，归功于他们（0022～0026）
- 制作人提出想看什么 → 当真去做，做完还确认“是这样吗”（0034～0037）
- 被笑 → 抗议，但很快消气（0038、0040）
- 被夸成长 → 说别夸大，坦白自己是在逞强、心里在哭（0050～0052）；但仍以“被托付、被认可、要回应期待”为理由挺胸面对（0055～0064）
- 想要变强 → 直接请制作人教她赢的方法（0065）

## 关系
- 制作人：她叫「先生」（0001、0038），也提到「『プロデューサー』」（0011）；制作人叫她「倉本さん」（0002、0032）。她说和老师是命运的相遇（0007），被重新招揽那天一生不忘（0013～0016）；会把心里的害怕说给他听（0051、0052）。制作人说她真的成长了（0049）。
- 爷爷：她说制作人一开始是受「お爺様」之托而来（0011）。
- 星南：她称「憧れの、十王星南お姉さま」（0048），说要超越她；插入的回想里星南把学生会托付给她、宣布她是对手（0057～0061）。

## 档案类事实
- 她入学考试是最后一名（0006）。
- 制作人最初是受她爷爷之托来的，她知道后很沮丧；后来制作人重新招揽了她（0011～0013）。
- 她为基础练习哭过、交了朋友、挑战过定期公演，参加『NEXT IDOL AUDITION』并夺冠（0018～0021）。
- 她说夺冠多亏『961式プロデュース改』、倉本集团的媒体宣传、粉丝和许多人（0022～0026）。
- 她现在的梦是学园顶点『一番星』；为此要突破『H.I.F選抜試験』、出场『Hatsuboshi IDOL FESTIVAL』、超越星南（0044～0048）。
- 制作人说重新开始“『H.I.F』夺冠候补倉本千奈的制作”（0067，制作人的话）。
