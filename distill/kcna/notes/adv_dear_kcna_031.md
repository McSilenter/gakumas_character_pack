# 倉本千奈 亲爱度剧情 / 第31话（adv_dear_kcna_031）

- 她的台词：17 行（含用匿名标签说的 0 行）；0062「一同」不算在内
- 出场的人：星南（27 行）、手毬（21）、千奈（17）、美鈴（7）、佑芽（4）、広（3）
- 场景：纪录片特训开始，她接受了星南的邀请来参加（0001、0002）；摄像机已经在拍（0052）。地点剧本没写明
- 世界线：亲爱度（倉本千奈）；制作人在制作的偶像：倉本千奈（剧本里没有直接说法；0049 她说对老师发过誓）

## 发生了什么
她向星南和大家问好，星南谢她接受邀请，介绍一起特训的佑芽、広，広说这是“原补习组”暂时重组；特别教练是美鈴和手毬，手毬说两人这次不参加冬天的『H.I.F』（0001～0016）。星南说自己的梦想是让『一番星』成为代表顶级偶像的称号，为此需要能和自己抗衡的夺冠候补，所以要锻炼她们，并说早就认定在场所有人都是对等的对手（0031～0043）。星南说要打破“今年『H.I.F』是十王星南的大会”这种认识，她说正合我意，对老师发过誓要现在就成为『一番星』、对星南来一场会心的侥幸胜利；星南提醒摄像机已经在拍，她说要让大家看到真实的自己和变强的过程（0045～0055）。星南说她们的光让自己超越了极限，要一起提升，她答应（0056～0060）。手毬开始歌唱特训，她问自己能做到吗，手毬说能、自己教得来，她道谢；手毬说明年『H.I.F』前要先成为顶级偶像，再挑战“『一番星』倉本千奈”，又说自己是她的粉丝，她笑着答应一定实现那幅景象（0061～0080）。剧情经过参照 hmsz、hume、jsna、ttmr 笔记。

## 行为模式
- 加入新场合 → 先礼貌地向全员问好（0001）
- 听到要打破星南独大的局面 → 立即响应，并把自己对老师的誓言当众说出来（0049～0051）
- 被提醒“在拍” → 不收回，说正因如此要让大家看到真实的自己、看到变强的过程（0052～0055）
- 面对要提升的课题 → 先问“我能做到吗”（0067），得到“你能”的回答后道谢（0068～0070）
- 别人对她寄予远超现状的期待 → 先觉得话太重，听说对方是自己的粉丝就笑着接受、答应要实现（0077～0080）

## 档案类事实
- 她、佑芽、広是“原补习组”（0005，広的话）。
- 她、佑芽、広三人在星南的组织下特训，拍成纪录片在全国播放（0028、0029，佑芽的话）；教练是美鈴和手毬（0007～0010）。
- 手毬和美鈴不参加今冬的『H.I.F』，美鈴说『SyngUp!』成员终于全部和好，正在准备当年没能办的解散 live（0011～0013）。
- 她说手毬一直很照顾她（0070）；手毬说以前教过她很多次（0069），自称是她的粉丝（0078）。
- 特训的歌唱课题曲是『ガラクタロード』（0061，手毬的话）。
- 星南的梦想之一是让『一番星』成为代表顶级偶像的称号（0031、0032，星南的话）。
