# 倉本千奈 亲爱度剧情 / 第32话（adv_dear_kcna_032）

- 她的台词：20 行（含用匿名标签说的 0 行）；0022 是纪录片节目视频里她对观众说的话（0018 制作人拿出视频之后），照算；0057「一同」不算在内
- 出场的人：広（22 行）、学園長（21）、千奈（20）、プロデューサー（11）、手毬（9）、佑芽（5）、旁白（1）
- 场景：三段：最后一场选拔考试刚结束，手毬评价她的歌（0001）；制作人向学園長报告、播纪录片视频（0018～0052，她不在场）；『H.I.F選抜試験』全部结束后，她和佑芽、広（0053）。地点剧本没写明
- 世界线：亲爱度（倉本千奈）；制作人在制作的偶像：倉本千奈（0026、0048）

## 发生了什么
最后一场选拔考试后，她问手毬自己的歌怎么样，手毬说合格、没想到进步这么多、可能比自己还好；她说一向严格、不对歌说谎的手毬这样说太狡猾了，手毬说只是作为教练和粉丝说实话，她说真是沉重的粉丝（0001～0011）。手毬说这样还够不着『一番星』、侥幸取胜还差一把，她说那一定是老师会想办法（0012～0017）。制作人向学園長报告：节目里有她，所有出演者的人气都会上升，她本人说只是在模仿以前帮过她的共演者；学園長说她作为艺人已经超过星南，还说倉本爷爷闹着要当『H.I.F』审查员被他劝退；制作人说最后的一把是倉本集团不计预算为她做的歌，并说相信最后她会想办法（0018～0052）。选拔全部结束，她们三人确定出场『H.I.F』（0053～0058）。広请她一定来看『H.I.F』前的 live，说最后会唱和她一起构思的新曲；她说一起出主意、写订单很开心，这是使用倉本力量的时候（0065～0078）。広问用了这些力量输给自己会不会不甘心、让自己变强真的好吗，她说条件对等赢了会很开心，对広来说偶像是兴趣所以広才出色，并问在人生的大关头模仿憧憬的偶像算不算狡猾；広笑着说不会客气，要她看着现在的自己——最喜欢她的、她的头号对手（0079～0090）。剧情经过参照 hume、shro、ttmr 笔记。

## 行为模式
- 被严格的人认真夸奖 → 感动又害羞，用“狡猾”“沉重的粉丝”这类话回嘴（0008～0011）
- 听说还差一步 → 不慌，第一个想到交给制作人（0016、0017）
- 有能力帮朋友 → 把家里的资源用在帮对手做最好的歌上，并享受一起构思的过程（0072～0078）
- 被问“帮对手变强真的好吗” → 说想在对等条件下赢，并把这比作模仿憧憬的偶像（0080～0083）
- 参加节目 → 据她说是模仿以前帮过她的共演者，让所有出演者人气上升（0026、0027，制作人转述）

## 关系
- 手毬：她叫「月村さん」（0002）；手毬叫她「千奈」（0001），作为教练和粉丝说她歌比自己还好（0007、0010）。她说手毬是“沉重的粉丝”（0011）。
- 広：她叫「篠澤さん」（0054、0062、0066）；広叫她「千奈」（0056、0065），说她是“最喜欢的你的头号对手”（0090）。她用倉本的力量和広一起做了広的新曲（0073～0078）。
- 佑芽：她叫「花海さん」（0054）；佑芽叫她「千奈ちゃん」（0055），说本战开始就是对手（0060）。
- 制作人：她说老师一定会想办法（0017）；制作人对学園長说相信最后她会想办法（0048）。
- 学園長（她不在场）：叫她「倉本千奈君」（0029），说她作为艺人会超过星南、渐渐有了威严（原文「貫禄」）（0028、0029）。
- 爷爷（不在场）：学園長说「倉本爺」闹着要当『H.I.F』审查员，被劝退（0031～0034，学園長的话）。

## 档案类事实
- 她是倉本集团会长的孙女（0028，学園長的话）。
- 手毬说她和広的歌进步很多、合格了（0004）。
- 她们三人（她、佑芽、広）通过选拔、确定出场『H.I.F』（0053、0057）。
- 制作人说节目里有她，所有出演者人气都会上升；她说只是模仿以前帮过她的共演者（0026、0027，制作人转述）。
- 她的『H.I.F』武器是倉本集团不计预算倾力制作的歌曲（0043、0044）。
- 广的新曲是広和她一起构思、一起写订单的，用了倉本的力量（0073、0074、0078），広会在『H.I.F』前的 live 最后和『H.I.F』上唱（0071）。
- 她说对広来说偶像是兴趣（0082）；広说对她来说偶像是梦想（0081）。

## 不确定
- 0057「一同」「『H.I.F』出場決定ですわ～～～～！」不算她的台词（ttmr 笔记【已确认】不算手毬的，理由是“補習組三人”；语尾「ですわ」像她的口吻，但她是否算在内没有结论）。
- 0083「憧れのアイドルの／真似」指模仿谁，本篇没说；结合第31话星南说要锻炼对手（第31话 0035、0036）可能是星南，但只是读法。
- 0078 读作她为広的新曲动用了倉本的力量（0076 広说她想了很多精巧的点子让星南头疼），歌曲具体是谁出钱、谁制作，本篇没明说。
- 0028 学園長的话「倉本グループ会長の孫娘と共演できる／トップタレントの真似」意思是她模仿的那些共演者本身就是顶级艺人，译文的理解有偏差。
- 【译文】0028 译文作“模仿了那些为了能和倉本集团会长的孙女共演的顶级艺人”，原文没有“为了”的意思。
