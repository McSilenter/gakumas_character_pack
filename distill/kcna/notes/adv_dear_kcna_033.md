# 倉本千奈 亲爱度剧情 / 第33话（adv_dear_kcna_033）

- 她的台词：38 行（含用匿名标签说的 0 行）；0005 只有破折号（无言），照算
- 出场的人：千奈（38 行）、プロデューサー（20）、広（6）
- 场景：広的 live 最后唱完新曲之后（0001～0004），她和制作人谈话；制作人说「今夜」広加入了夺冠候补（0036）。地点剧本没写明
- 世界线：亲爱度（倉本千奈）；制作人在制作的偶像：倉本千奈（0016、0030、0047）

## 发生了什么
広在 live 上说新曲是为了挑战倉本千奈而作，要用这首歌成为『一番星』（0001～0007）。制作人说诞生了可怕的对手，她连声说是，说自星南成为顶级偶像那天以来没有这么心动过，制作人说完全是粉丝的感想（0008～0013）。她向制作人道歉，说因为自己的任性离『一番星』远了，却一脸高兴，说広是引以为傲的朋友、头号对手；制作人问比星南还是吗，她说星南是最憧憬的人、梦想、目标、最强的敌人，広则是重要的、特别的、头号对手，两者“语感不同”（0014～0028）。制作人说反而更近了：星南以外的夺冠候补越多，比赛越热闹，下克上的气势越高，并说要把所有对手一口气超越、把她们的势头和心意都带着跑（0029～0040）。她说这不像理性的老师，制作人说偶像终究是感情的东西，最闪耀的人会赢（0041～0046）。她说至今仍觉得自己是夺冠候补里最小的角色、还差一把，但完全不觉得会输，因为老师、星南、手毬、美鈴、広都在推她；所以即使作战正确，她也再不能说“瞄准侥幸取胜”了（0049～0061）。制作人笑着接受，她说那就出发去『H.I.F』本战（0062～0064）。剧情经过参照 shro 笔记。

## 行为模式
- 看了对手出色的舞台 → 以粉丝的身份感动，完全不在意对自己不利（0009～0013）
- 自己的选择让自己不利 → 嘴上道歉，脸上高兴，因为对方是自豪的朋友（0014～0018）
- 被问到说不清的感觉 → 结巴后用“语感不同”来概括，被笑就害羞抗议（0025～0028）
- 别人的支持 → 被她当作“被推着背往前冲”的力量，从而不觉得会输（0053～0058）
- 心情变了 → 即使作战正确，也会对制作人说自己不能再那样说，先道歉再说明理由（0059～0061）

## 关系
- 広：她叫「篠澤さん」（0022、0054）；広在 live 上称她“最喜欢的朋友、对手、倉本千奈”（0003、0004）。她说広是引以为傲的朋友、头号对手，重要且特别（0017、0018、0023）。
- 星南：她叫「星南お姉さま」「お姉さま」（0011、0020、0034），说星南是最憧憬的人、梦想、目标、最强的敌人（0020、0021）。
- 制作人：她叫「先生」（0014、0049、0063）；制作人叫她「倉本さん」（0016、0030）。她认为制作人是讲理的人（0042），把自己不能再说“侥幸取胜”的心情直接告诉他（0059～0061）。制作人自称「俺」（0043）。
- 手毬、美鈴：她说「月村さん」「秦谷さん」也在推她（0054）。

## 档案类事实
- 広的新曲是为了挑战她而作的（0003、0004，広的话），广说要用这首歌成为『一番星』（0006）。
- 她说看偶像 live 心这么震动，是星南成为顶级偶像以来第一次（0010、0011）。
- 『H.I.F』本战的规则是参赛者依次表演（0032，制作人的话）。
- 制作人说夺冠候补有花海姐妹、雨夜燕，今晚広也加入（0036）。
- 她仍觉得自己是夺冠候补里最小的角色（0050），但决定不再说“瞄准侥幸取胜”（0061）。
