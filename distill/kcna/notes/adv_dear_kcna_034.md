# 倉本千奈 亲爱度剧情 / 第34话（adv_dear_kcna_034）

- 她的台词：42 行（含用匿名标签说的 0 行）
- 出场的人：千奈（42 行）、プロデューサー（18）、香名江（4）
- 场景：对她来说重要的一天的早上，香名江帮她打扮（0003、0004），之后制作人来接她（0019「おはようございます」「お迎えに上がりました」），正式演出之前（0053「本番直前」）。地点剧本没写明
- 世界线：亲爱度（倉本千奈）；制作人在制作的偶像：倉本千奈（0064）

## 发生了什么
香名江为她做早上的准备，说自己不是专业造型师却能担当，很光荣；她说正因为是重要的日子，才想交给最让她安心的人，到会场后再交给专业人员（0001～0008）。她对香名江说，走过的人生和经验是偶像的武器，粉丝的心意是偶像的光芒，和香名江一起度过的早晨对她来说就是闪光的武器，对顶级偶像也一定管用；香名江说别让她动摇、手会抖（0009～0015）。她说为家人准备了最好的座位，要香名江在最近的地方看她赢（0016～0018）。制作人来接她，说她今天格外凛然，她说现在是“次期会长模式”；制作人在心里说她已有不输星南的气场，问她是不是在勉强，她说当然在勉强，但这个假面也是她的一部分，会撑到最后（0019～0032）。制作人说平时可爱的她也是粉丝想看的样子，她承认疏忽了，说不把一切都拿出来对对手和粉丝都失礼（0033～0041）。制作人喊口令让她在“软乎乎”和“凛然”之间来回切换，她越切越乱，抗议老师在正式前做什么、自己又不是混合果汁，结果心情竟然平静下来，说自己真单纯（0042～0059）。制作人说兼具气场和亲和力的她是出色的夺冠候补、一流偶像，她说交给她、他引导培养的学生会做给他看（0060～0064）。

## 行为模式
- 重要的日子 → 把身边事交给最让她安心的人，并当面说出理由（0005～0008）
- 想感谢身边的人 → 用“偶像的武器”“光芒”这样的说法把对方的意义说出来，让对方动摇（0009～0015）
- 被问是否在勉强 → 坦白在勉强，但说那个假面也是自己的一部分，不是假的（0029～0032）
- 被指出遗漏 → 很快承认“一时疏忽”，接受对方的意见（0037～0041）
- 制作人让她做奇怪的事 → 照做，做乱了抗议，发现有效就坦然说自己单纯（0044～0059）
- 被寄予期待 → 用“交给我”回应，并以制作人的学生自居（0063、0064）

## 关系
- 香名江：她叫「香名江」（0002、0009）；香名江叫她「お嬢様」（0001、0003）。她说香名江是最让她安心的人（0006），称香名江为家人、为其准备最好的座位（0016）。香名江被她的话弄得动摇（0015）。
- 制作人：她叫「先生」（0020、0052），对他自称「教え子」（0064）；制作人叫她「倉本さん」（0019、0023）。她向他坦白在勉强（0029）；制作人在心里说她已有不输星南的气场（0027，制作人的心里话）。

## 档案类事实
- 这个重要日子的早上，香名江负责她的打扮，到会场后交给专业人员（0004、0007）。
