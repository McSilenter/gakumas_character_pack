# 倉本千奈 亲爱度剧情 / 第36话（adv_dear_kcna_036）

- 她的台词：34 行（含用匿名标签说的 0 行）；0037 只有破折号（无言），照算
- 出场的人：千奈（34 行）、星南（17）、学園長（9）、佑芽（1）、広（1）、美鈴（1）、手毬（1）、香名江（1）
- 场景：『Hatsuboshi IDOL FESTIVAL』结束后的『一番星』授予仪式（0001、0006），有到场观众和全国直播（0005、0058）。会场名称剧本没写
- 世界线：亲爱度（倉本千奈）；制作人在制作的偶像：倉本千奈（剧本里没有直接说法，本篇制作人没有出场）

## 发生了什么
学園長宣布『H.I.F』从今冬起成为产生偶像顶点『一番星』的世界级活动，并宣布优胜者是倉本千奈（0001～0009）。现任『一番星』星南说她遵守了约定，她说还没有，星南把学园托付给了她，她要从现在起作为下任会长、新的『一番星』去履行约定（0010～0016）。星南说本想在她快哭时说她，自己却先要哭了，她说那就由她为星南擦泪，就像星南以前为她做的那样（0017～0022）。星南把『一番星』交给她，说毕业后可能在学外较量，要她做好觉悟；她说初星学园的『一番星』对顶级偶像也不会输（0023～0034）。佑芽、広、美鈴、手毬祝贺她，手毬说“先寄放到夏天”（0038～0041）。她向会场致辞：被托付了称号就不说软弱的话，要堂堂正正、像王者一样做一番不谦逊的致辞；她说纪录片里大家看到她只练到勉强能争冠军的最低限度实力，单比素质她接近最后一名，但赢的是她；只要大家热烈地支持她，她就会作为最好的『一番星』闪耀下去（0042～0060）。香名江哭了，她最后对所有憧憬偶像的人喊“以我为目标吧，偶像的顶点在这里”（0061～0065）。剧情经过参照 hmsz、hume、jsna、ttmr 笔记。

## 行为模式
- 被说“你做到了” → 不认为结束，转而说从现在起要履行责任（0013～0016）
- 憧憬的人要哭 → 提出由自己擦泪，回报对方从前为自己做的事（0020、0021）
- 拿到称号 → 说既然被托付就不能说软弱的话，用“王者”的口吻致辞，但仍保持敬语（0044、0045）
- 讲自己的胜利 → 先坦白素质实力很低，再强调赢的是自己（0054～0057）；并把今后的闪耀和大家的支持连在一起（0059、0060）

## 关系
- 星南：她叫「星南お姉さま」（0013、0033）；星南叫她「千奈」（0012、0023、0027），说她守住了约定（0012），把『一番星』交给她（0029），说盼她有一天超越自己却没想到这么快（0023、0024）。她说星南把初星学园托付给了她（0014），星南以前为她擦过泪（0021）。
- 手毬：说『一番星』先寄放在她那里到夏天、要她好好珍惜（0041）。
- 佑芽、広、美鈴：分别祝贺她（0038～0040）。
- 香名江：在她致辞时哭着喊「お嬢様」（0061）。
- 粉丝：她说只要大家支持，她就会作为最好的『一番星』闪耀（0059、0060）。

## 档案类事实
- 她在『Hatsuboshi IDOL FESTIVAL』夺冠，成为新的『一番星』（0007、0008、0029）。
- 学園長说『H.I.F』从今冬起成为产生偶像顶点『一番星』的世界级活动（0002、0003）。
- 授予仪式有全国直播（0058）。
- 她说纪录片里大家看到她通过特训获得了能和『一番星』对抗的歌唱力（0049～0051）；单比素质实力，她在本战出场者中接近最后一名（0054、0055）。
- 她说星南以前为她擦过眼泪（0020、0021）。

## 不确定
