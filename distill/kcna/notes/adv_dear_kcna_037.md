# 倉本千奈 亲爱度剧情 / 第37话（adv_dear_kcna_037）

- 她的台词：51 行（含用匿名标签说的 0 行）；0061、0062 是回想中她初见制作人时说的话（与第1话 0042、0043 原文相同），照算
- 出场的人：千奈（51 行）、プロデューサー（28）
- 场景：『一番星』授予仪式和致辞之后，同一天（0004「今日はまだ終わっていませんよ」、0035「今日」）；她刚哭过（0021）。地点剧本没写明（0009 提到「控え室」，但是在说星南不会在休息室哭）
- 世界线：亲爱度（倉本千奈）；制作人在制作的偶像：倉本千奈（0022、0079）

## 发生了什么
她对制作人哀叹一时冲动说了不得了的话（指致辞），制作人提醒“『一番星』今天还没结束”，她想到星南不会事后胆怯、不会在休息室哭，决定自己也要堂堂正正（0001～0010）。她说今后作为学园代表要尽量让大家看帅气的倉本千奈，又说照样展示真实的自己，这有点矛盾但老师一定能办到；制作人说来不及了，刚才的对话全国直播了，从她哭的地方开始，她惨叫（0011～0026）。她说形象好像没怎么变，制作人说慌张的她和凛然的『一番星』都是大家爱的样子，她说老师这么说就接受（0027～0032）。制作人说她打败了星南，从现在起会有人叫她顶级偶像；她说不会特意否认，否认就是侮辱，但现在还说不出口，问这样是否不行，制作人说很像她、真挚不会降低偶像的格调（0035～0047）。她说明白老师想传达什么，请他再等一下，等她大声欢呼胜利的那天再实现老师珍视的梦想；制作人说不急，按最初的计划她现在还该在做基础练习，像是穿越到了两年后（0048～0058）。两人回想初次见面：她当时自称全校最后一名，制作人说那时真的很不行、但有让人喜欢的才能，那天短短的交谈就喜欢上了她；她说自己也是，那天轻松怀抱的梦想现在变得这么大（0059～0075）。制作人说她给未来的偶像们带来了梦想、责任重大，她说那就好好干，这是偶像的工作，今后也请多指教——“我的顶级制作人”（0076～0079）。

## 行为模式
- 公开场合说了豪言 → 事后在制作人面前哭、后怕；被提醒后拿星南作榜样，振作起来（0001～0010）
- 想要两全的事 → 承认矛盾，但相信制作人能办到，交给他（0013～0017）
- 发现丢脸的样子被播出 → 惨叫、抗议“请事先告诉我”，再沮丧地接受（0023～0028）
- 被别人用大称号称呼 → 不否认（否认是侮辱），但也不肯自己说出口，并向制作人确认这样是否可以（0040～0047）
- 察觉制作人的心思 → 说自己明白，并请他再等一下（0048～0053）
- 回顾过去 → 坦率承认当时不行；被直接附和就吐槽（0066～0069）
- 被赋予责任 → 当作“偶像的工作”积极接受（0076、0077）

## 关系
- 制作人：她叫「先生」（0002、0011、0034、0078），最后称他「わたくしの、トッププロデューサー」（0079）；制作人叫她「倉本さん」（0018、0035），也叫「『一番星』倉本千奈さん」（0004）。制作人说初次见面短短交谈就喜欢上了她（0072），她说自己也是（0074）。她说明白制作人想传达什么、请他再等等实现他的梦想（0048～0053）。她说刚相遇时想不到会和老师这样谈话（0059、0060）。
- 星南（不在场）：她拿星南作为“说了大话也不退缩”的榜样（0007、0008）；制作人说她打败了十王星南（0036）。

## 档案类事实
- 她在授予仪式后哭了，和制作人的对话全国直播了（0020～0022）。
- 制作人说今天她打败了十王星南，从此会有人称她为顶级偶像（0035～0039，制作人的话）；她不否认，但自己还说不出口（0041、0043）。
- 制作人说按最初的计划，她现在还该在做基础练习，像是到了两年后的世界（0055、0057，制作人的话）。
- 初次见面时她说自己的偶像实力是全校最后一名（0061、0062，回想）；制作人说那时真的很不行，但有让人喜欢的才能（0068、0071）。
- 她说那天以轻松的心情怀抱的梦想变得这么大（0075）。
- 制作人有一个“珍视的梦想”，她请他再等一下（0051、0052）。
