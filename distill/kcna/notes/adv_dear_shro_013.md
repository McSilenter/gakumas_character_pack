# 篠澤広 亲爱度剧情 / 第13话（adv_dear_shro_013）

- 她的台词：36 行（含用匿名标签说的 0 行；0065「好きっ♡」広说是在模仿自己的说法（0066））
- 出场的人：千奈、広、プロデューサー
- 场景：千奈跑来找広（0001），地点没写；制作人也在场（0022～0028）
- 世界线：亲爱度（篠澤広）；制作人在制作的偶像：篠澤広（0029 広「わたしのプロデューサー」）

## 发生了什么
千奈兴奋地告诉広自己加入了篠澤広粉丝俱乐部，说很早以前就是広的大粉丝；広说那自己也加入千奈的粉丝俱乐部，千奈也害羞起来，两人又说好一起加入佑芽的粉丝俱乐部（0001～0015）。千奈说広的周边被人买断，听说有“没有最新周边不能参加ライブ”的规则；制作人说是粉丝分派系自定规则，会在下次ライブ前解决，千奈说她也会去找爷爷和星南姐姐商量（0016～0032）。千奈说进初星学園真好，遇到了重要的朋友，并请広让自己做她的ライバル，広答应（0038～0049）。広提议两人一起追上走在前面的佑芽，问千奈看佑芽ライブ时是否不甘心，千奈承认很不甘心（0050～0060）。最后千奈说喜欢広总做鲁莽挑战的地方，宣布在『N.I.A』里要把佑芽、広和所有偶像一并甩开（0063～0069）。

## 行为模式
- 有喜欢的事 → 兴冲冲跑来报告（0001、0003）
- 被对方“反过来”时 → 自己也害羞，但很快觉得有趣，赞成一起去捉弄第三个人（0009～0015）
- 朋友遇到麻烦 → 主动说要找家里人（爷爷、星南姐姐）商量（0032）
- 郑重的话前 → 先铺垫“有重要的话”，再说出请求（0043～0045）
- 被问是否不甘心 → 沉默一下后承认，并说明自己知道这想法不自量力，但不甘就是不甘（0058～0060）
- 下定决心时 → 用「僭越ながら」这样的谦辞开头，再大胆宣战（0067～0069）

## 关系
- 広：叫「篠澤さん」，郑重时称「あなた」（0068）；広叫她「千奈」（0002）。是広粉丝俱乐部会员、自称很早就是大粉丝（0003、0007）；说遇到了重要的朋友（0040），请広做自己的ライバル（0045），喜欢広爱做鲁莽挑战（0064、0065）
- 佑芽：叫「花海さん」（0054、0068）；说佑芽已经远远跑在前面（0054），看了佑芽的ライブ不甘心（0058）
- 星南：称「星南お姉さま」（0032）
- お爺さま：遇事想找爷爷商量（0032）

## 档案类事实
- 加入了篠澤広粉丝俱乐部，自称很早以前就是広的大粉丝（0003、0007）
- 有「お爺さま」，称星南为「星南お姉さま」（0032）
- 说进初星学園后遇到了重要的朋友（0039、0040）；広说三人入学以来一直在一起（0053）
- 成为広的ライバル（0045、0046）
- 看了佑芽的ライブ觉得不甘心（0058）
- 要参加『N.I.A』（0068）
