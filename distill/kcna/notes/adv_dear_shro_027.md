# 篠澤広 亲爱度剧情 / 第27话（adv_dear_shro_027）

- 她的台词：33 行（含用匿名标签说的 0 行）
- 出场的人：千奈、広、プロデューサー
- 场景：千奈来访，广正贴在制作人身上搞“罰ゲーム兼ご褒美”（0001～0024），之后两人谈话；地点没写。时间点在広的优胜ライブ和一场シークレットライブ之后（0028、0030）
- 世界线：亲爱度（篠澤広）；制作人在制作的偶像：篠澤広

## 发生了什么
千奈进门看到広贴着制作人，慌张以为打扰了，听到「愛の巣」「ひどいこと」更惊慌，觉得自己果然碍事（0007～0025）。她说也看了広的ライブ，是制作人偷偷邀她去的シークレットライブ，说広在优胜ライブ后又成长了，“这才是我的ライバル”（0026～0031）。広说电视和网上天天都能看到她，可能已经比星南还有名，她先说“不敢当”，随即改口说以前的自己会这么说，宣布自己已经比星南お姉さま更有名了，不然当不了『一番星』，她的目标是学园第一的偶像，邀広一起（0034～0044）。她说看穿了広：正因为是鲁莽的挑战才要做；两人说起不在场的挚友在夏季『H.I.F』唱歌的样子，所以不能不战而退（0046～0054）。広说制作人给她『一番星』的概率是 2%，她得意地说星南お姉さま给自己的是 1.5%，随即叫着“输了”又说会追上来（0055～0062）。最后她说三人曾是「落ちこぼれトリオ」「補習組」，和広一起宣布“无谋挑战的开始”（0064～0066）。

## 行为模式
- 撞见朋友和制作人亲昵 → 慌张、反复说自己是不是碍事（0007、0008、0022、0025）
- 被夸有名 → 先条件反射地谦虚，随即自己推翻，堂堂正正地承认并宣布目标（0036～0040）
- 宣布大目标时 → 先说「僭越ながら」再说出口（0042、0043）
- 和朋友比较 → 得意地报出数字，发现输了就大叫，马上说会追上（0057～0062）
- 对朋友的心思 → 自信地说“我看穿了”（0048、0049）

## 关系
- 広：叫「篠澤さん」（0026、0044）；広叫她「千奈」，说她是第一个朋友、第一个ライバル（0067、0068）。称広为「わたくしのライバル」（0031），看穿広越难越要做的性格（0048、0049），两人都以『一番星』为目标（0043～0045）
- 広的制作人：用敬语，被他悄悄邀去看広的シークレットライブ（0029）；制作人叫她「倉本さん」（0009）
- 星南：称「星南お姉さま」；宣布自己比她更有名（0038、0039）；星南给她『一番星』的概率 1.5%（0058～0060）
- 不在场的「親友」：在夏季『H.I.F』上唱歌，激励了两人（0051～0054）
