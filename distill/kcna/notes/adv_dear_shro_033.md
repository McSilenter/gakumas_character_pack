# 篠澤広 亲爱度剧情 / 第33话（adv_dear_shro_033）

- 她的台词：25 行（含用匿名标签说的 0 行）
- 出场的人：千奈、広、プロデューサー、旁白
- 场景：『H.I.F』本战临近的某一天（0001），千奈新曲『ときめきのソルフェージュ』的发表ライブ全国直播（0002）；她在台上对观众讲话（0003～0029），広和制作人在后台之类的地方看（0032～0035），具体地点没写
- 世界线：亲爱度（篠澤広）；制作人在制作的偶像：篠澤広（0038 制作人「倉本千奈のライバル・篠澤広の歌」，0044「篠澤広を見せつけてやりましょう」）

## 发生了什么
她的新曲『ときめきのソルフェージュ』发表ライブ全国直播，唱完后她向观众讲话：自己的世界里住着支持她的人们，在初星学園和这些人度过的日子培育了现在的她（0003～0010）。她宣布今冬要挑战憧憬的十王星南お姉さま、『一番星』，接着说要讲会让参赛偶像和朋友生气的“不遜”的话（0011～0017）。她说自己的最大对手不是星南お姉さま，而是篠澤広：在学园里最久、最近一起钻研，在『NEXT IDOL AUDITION』打败她夺冠、让她第一次有了那种感情的人；她现在非常燃（0019～0029）。広说千奈当众说这种话太狡猾，脸都没法见人，请制作人补妆；会场响起等待広上台的欢呼，制作人说这是千奈懂挚友的喜好、是『H.I.F』前哨战，広说自己也燃起来了，准备在火中歌唱（0030～0047）。

## 她的关键台词
- 0005「本日も……倉本千奈の世界を、／歌で表現させていただきました。」——用“自己的世界”来说明歌唱
- 0007「倉本千奈を応援してくださる、／皆さまが住んでいます。」——她的“世界”里有支持她的人
- 0010「いまのわたくしを育んで／くださいました。」——把现在的自己归功于周围的人和学园的日子
- 0012「初星学園一のアイドル、／『一番星』に挑戦いたします！」——公开向星南挑战
- 0014「これから、わたくしは、／不遜なことを申し上げます。」——先声明自己要说冒犯的话
- 0020「憧れの十王星南お姉さまでは／ありませんわ。」——最大对手不是憧憬的人
- 0022「最初に見えるのは、いつもあなたの顔。」——想到『H.I.F』时最先浮现広
- 0023「――篠澤広さん。」——当众点名広
- 0025「初星学園で、アイドルとして、／もっとも長く、もっとも近くで、／共に研鑽してきたあなた。」——她眼中的広
- 0027「はじめての感情を／抱かせてくれたあなた。」——在『N.I.A』被広打败带来的情感
- 0029「燃えておりますわ～～～～～～～～～♪」——宣战时也带着♪的明亮语气

## 行为模式
- 在公开舞台上讲话 → 先感谢粉丝、制作方、前辈和朋友，把现在的自己归功于大家（0004～0010）
- 要说冒犯的话之前 → 先郑重声明“要说不遜的话、会让人生气”（0013～0017）
- 宣战 → 先挑战最高的目标星南（0011、0012），再点名真正的最大对手広，并说明理由（0019～0027）
- 被打败的经历 → 不说不甘心，而是说成“第一次有的感情”，转化为斗志（0026～0029）
- 认真的场合 → 依然用拖长音和♪结尾（0028、0029）

## 关系
- 広：本篇当众称「篠澤広さん」（0023），对广称「あなた」（0022、0025、0027）；広称她「千奈」（広 0018、0030、0045）。她说広是在学园里最久、最近一起钻研的人，在『NEXT IDOL AUDITION』打败她夺冠，是她最大的对手（0019～0027）。広说她当众这样讲是「ずるい」「はんそく」（広 0030），制作人说她懂挚友的喜好（制作人 0042）
- 星南：称「十王星南お姉さま」（0011、0020），是她憧憬的偶像，她公开挑战『一番星』（0011、0012），但说星南不是她的最大对手（0020）
- 粉丝和周围的人：她的“世界”里住着粉丝、制作舞台和乐曲的人、憧憬的前辈、重要的朋友（0007、0008）

## 档案类事实
- 新曲『ときめきのソルフェージュ』，发表ライブ全国直播（0002，旁白）
- 将在今冬『H.I.F』挑战星南（0011、0012）
- 在『NEXT IDOL AUDITION』上被広打败，広夺冠（0026）
- 以「倉本千奈の世界」来描述自己的歌（0005～0007）

## 不确定
- 0003～0029 是在ライブ的直播中对观众讲话（0002 旁白、制作人 0037 的欢呼声），広是在后台听还是在别处看，本篇没写明。
- 0027「はじめての感情」具体是什么感情，她没说明；中文译文补成“极其不甘、却又刻骨铭心的情感”，原文没有“不甘”之意。
- 【译文】0027 原文「はじめての感情を／抱かせてくれたあなた。」，译文“让我有生以来，第一次体会到这种极其不甘、／却又刻骨铭心情感的你！”添加了原文没有的“不甘”“刻骨铭心”。
