# 活动 006 班级对抗初星大运动会 / main-03 第3话（adv_event_006_main-03）

- 她的台词：23 行（含用匿名标签说的 0 行）；其中 0036 只是睡着的呼吸声「すぅ……すぅ……」
- 出场的人：佑芽、莉波、千奈
- 场景：泡完温泉后，千奈带两人去别墅招待（0009～0013），一直到夜晚；千奈在 0036 睡着
- 世界线：活动 006；制作人在制作的偶像：看不出

## 发生了什么
泡完温泉，莉波道谢，千奈说平时承蒙大家照顾，欢迎随时再来；然后她头晕站不稳，两人劝她休息，她仍坚持招待，带两人到别墅吃点心、喝茶。她得知莉波肩膀酸，安排女仆按摩，又提议今天留宿。莉波问大家觉得温泉哪里最开心，她回答"很舒服"。她说就算熬夜也要想，随后睡着。佑芽和莉波谈话时，她醒来说听到了，并表示明天会更努力。剧情经过参照 hume 笔记。

## 行为模式
- 对朋友表示感谢 / 被道谢时 → 说"承蒙大家照顾"，并主动邀请下次再来（0003、0004）
- 自己身体出状况（晕眩） → 坦率说出，但不愿意中断招待（0006、0009）
- 招待客人 → 记得对方说过的小事（肩酸），并主动安排，被推辞则说"重要的客人，请不要客气"（0017～0023）
- 想法被问到本质问题 → 一时答不出，只能说出最直接的感受（0032）
- 听到有感触的话 → 立刻表明感动并重新下决心（0056～0059）
