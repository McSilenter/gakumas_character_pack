# 活动 006 班级对抗初星大运动会 / main-04 第4话（adv_event_006_main-04）

- 她的台词：20 行（含用匿名标签说的 0 行）；0043「一同」不计，见“不确定”
- 出场的人：佑芽、千奈、莉波、広
- 场景：学园内（0049 莉波说"廊下は走っちゃだめ"，0051 她们走过来）；先是佑芽和千奈想活动点子，遇到広，再回去向莉波报告
- 世界线：活动 006；制作人在制作的偶像：看不出

## 发生了什么
她和佑芽轮流喊活动点子，点子越来越离谱（热汤忍耐比赛、在温泉里藏宝等），莉波叫停，她说是爷爷爱看的悬疑剧影响。想不出之后，两人决定为了信任她们的莉波一定要做出来。遇到広，她提出请広给建议；広说"什么都不想做"。她一度惊讶，随后想起莉波说的"面向谁、想让他们怎么想"，和佑芽一起想到"让客人什么都不用做、全力招待"。她们跑去告诉莉波，她说需要向爷爷商量但不需要工程，一定会说服他，并去找爷爷。剧情经过参照 hume 笔记。

## 行为模式
- 想点子时 → 一旦停不下来就越来越夸张，莉波叫停后，用外部影响（爷爷的剧）解释（0002～0008）
- 缺乏灵感 → 如实承认，但和佑芽一起把"为信任自己的人"当作动力（0013～0015）
- 找到可以请教的人 → 马上喊对方并建议大家一起问（0019、0022）
- 听到意想不到的回答 → 先吃惊，再抓住其中与莉波教的思路相连的部分，催佑芽（0028、0035、0036、0038）
- 点子要靠自家的资源时 → 先说必要的手续（和爷爷商量），再肯定地保证会做到（0056、0057、0066、0067）

## 关系
- 佑芽：叫「花海さん」（0022、0038）；佑芽叫她「千奈ちゃん」（0023）。
- 広：叫「篠澤さん」（0019、0022、0035）；広叫她「千奈」（0018）。
- 莉波：叫「莉波お姉さま」（0038、0048）。
- 爷爷：叫「お爺様」，招待要先和爷爷商量（0008、0056、0066）。

## 档案类事实
- 爷爷喜欢悬疑剧（0008）。
- 活动用的温泉要先和爷爷商量，但不需要工程（0056）。
- 家里的女仆会参与招待（莉波问"メイドさんたちも？"，0055）。
