# 活动 006 班级对抗初星大运动会 / main-05 第5话（adv_event_006_main-05）

- 她的台词：19 行（含用匿名标签说的 0 行）；0078「一同」不计，见“不确定”
- 出场的人：佑芽、広、千奈、莉波
- 场景：千奈家的别墅，活动『初星温泉　～木枯らしに散る～』当天，以及活动结束之后
- 世界线：活动 006；制作人在制作的偶像：看不出

## 发生了什么
活动当天，她作为主办者之一迎接广，为她准备点心和红茶；广夸点心好，她说是和女仆商量后选的，被广说"在努力"并说"来对了"后，她又惊又喜地道谢。活动结束，大家看问卷，结果大成功，她和佑芽感动地叫对方的名字，她说多亏莉波的指导，否则会变成25米泳池。莉波说会长也夸了，她后来提议大家一起去泡温泉，说自己一直向往庆功宴。剧情经过参照 hume 笔记。

## 行为模式
- 被客人夸奖 → 说明背后的用心（和女仆商量），再继续细致地招待（0032、0033）
- 被问辛苦与否 → 先坦承"忙"，再说"大家开心就没问题"（0035、0036）
- 被直接说"努力""来对了" → 沉默一下，不敢置信地确认，再用敬语道谢（0039～0042）
- 活动结束 → 坦率说累，看到成功时与佑芽用名字互相叫喊（0044、0057）
- 成功 → 把功劳让给莉波，并说具体的理由（"没有莉波就是25米泳池"）（0061、0062）
- 想庆祝 → 提出"一起泡温泉"，并说出自己对庆功宴的憧憬（0071～0075）
