# kcna / 活动 007 好姐妹？三人组的日常 / main-04 万圣节狂想曲 第4话（adv_event_007_main-04）

- 她的台词：33 行（含用匿名标签说的 0 行）；其中 0021 是心里话（括号内独白）；0007、0008 是打工时对游客说的招呼词
- 出场的人：千奈（33）、手毬（22）、広（8）
- 场景：游乐园里，傍晚前后，手毬唱歌聚集游客后三人发糖果；休息时在晚间演唱会舞台附近（0015、0021、0033）
- 世界线：活动 007；制作人在制作的偶像：看不出

## 发生了什么
手毬唱歌吸引来很多游客，千奈和広趁机发糖果和门票。傍晚她们休息，千奈担心晚上的演出。手毬买了茶请客，広睡着后，手毬问千奈为什么想当偶像。千奈说是被偶像的演唱会打动，起初只是轻率的心情，入学后认识到自己想得太简单，但现在想成为出色的偶像，为自己抱的梦想负责。千奈反问，手毬说理由和她一样，千奈本以为两人毫无相似处，为此高兴。手毬说她也有胜过自己的地方，千奈没听清想追问时发生了停电。剧情经过参照 ttmr 笔记。

## 行为模式
- 同伴体力不行 → 主动提议休息，并把后面的演出作为理由（0015、0017）
- 手毬递来茶 → 先惊讶、想付钱，被说请客后含糊道谢（0027、0029）
- 面对更大的舞台 → 承认害怕、觉得自己不配（0034、0035）
- 被问志向 → 老实讲出起初是轻率心情、后来认真的变化（0039～0045）
- 自己说了心里话，对方不肯回答 → 直接说“ずるい”抗议（0050）
- 发现共通点 → 把“遥远的人”的印象改写，开心地笑（0056～0059）

## 关系
- 手毬：称“月村さん”；原来觉得她是“遠い方”，听到她的志向后觉得“そっくり”（0056、0059）；手毬请客、帮忙守着広，千奈客气地道谢（0027、0029）
- 広：称“篠澤さん”；她睡着时向手毬说明“睡着了”（0031）

## 档案类事实
- 成为偶像的起因：看了一位出色偶像的演唱会，想像她那样闪耀（0039～0041）
- 开始时只是轻率的心情，进初星学园后才认识到想得太简单（0040、0043）
- 现在想成为出色的偶像，为自己抱的梦想负责（0045）
