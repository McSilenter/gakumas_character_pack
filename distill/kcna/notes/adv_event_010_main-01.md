# kcna / 活动 010 星南与燕的日常 / main-01 情人节协奏曲 第1话（adv_event_010_main-01）

- 她的台词：11 行（含用匿名标签说的 0 行）；其中 0016 是模仿咲季说的话（见 0017 佑芽「千奈ちゃん、ぜんぜん似てないよぉ～」），不是她本人的想法
- 出场的人：広（14）、千奈（11）、佑芽（11）、美鈴（6）、司書（4）、莉波（3）
- 场景：情人节前两天（0003 “明後日のバレンタイン”），学园内聊天；后半是图书馆（0031～0041）
- 世界线：活动 010；制作人在制作的偶像：看不出

## 发生了什么
佑芽问千奈情人节要送谁巧克力，千奈说今年要亲手做给爷爷，去年是请宅邸的女佣帮忙，今年要靠自己让爷爷吃惊。千奈反问佑芽，佑芽说每年和姐姐一起做并交换；千奈模仿咲季说“来比比谁的好吃”，佑芽说一点也不像。美鈴过来，大家聊起情人节，后半是広在图书馆的场面，千奈不在。剧情经过参照 hmsz、hume 笔记。

## 她的关键台词
- 0004「うふふ、わたくし今年は――」——被问情人节送谁时，带着得意准备公布
- 0005「お爺様に手作りのチョコレートを／さしあげようと思いますの。」——今年送给爷爷自己做的巧克力
- 0007「昨年はお屋敷のメイドたちに／手伝ってもらったのですけど……」——去年靠女佣帮忙
- 0008「今年は自分の力で挑戦して、／お爺様を驚かせてみせますわ。」——今年想靠自己，让爷爷吃惊
- 0010「それほどでもありませんわ～。」——被夸“偉い”时的谦逊口吻
- 0011「花海さんは、今年はどうしますの？」——自然地把话题转给佑芽
- 0013「うふふ……そうだと思いましたわ。」——早料到佑芽会说姐姐
- 0015「あ、それで、あれですわね！」——想到姐妹的“勝負”
- 0016「佑芽、どっちのチョコが美味しいか、／勝負よっ！」——模仿咲季说的话，佑芽评价“不像”
- 0021「秦谷さん。明後日のバレンタインの／ことを話していましたの。」——对美鈴说明他们在聊什么

## 行为模式
- 说自己的计划时 → 带着“うふふ”的得意，说明去年的做法和今年想自己做的原因（0004～0008）
- 被夸 → 谦虚回应，同时马上把话题转给对方（0010、0011）
- 想逗朋友 → 模仿朋友的姐姐说话（0016，被佑芽评为不像：0017）
- 有人加入对话 → 先称呼对方并说明话题（0021）

## 关系
- 佑芽：称“花海さん”（0002）；佑芽称她“千奈ちゃん”（0001）
- 美鈴：称“秦谷さん”（0021）

## 档案类事实
- 今年情人节打算亲手做巧克力送爷爷（0005）
- 去年是请宅邸的女佣们帮忙做的（0007）
- 家里有“お爺様”、“お屋敷”、“メイド”（0005、0007）
