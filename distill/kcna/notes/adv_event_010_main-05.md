## 发生了什么
节日当天，佑芽把和姐姐一起做的“完全营养食”巧克力送给千奈，千奈也回送了一份。两人都收到広“13时到舞台前来”的消息，千奈念出了消息。到了舞台前，千奈把広的歌当作“秘密演唱会”听，唱完后夸歌声动听。広随后拿出亲手从可可豆做起的友チョコ，千奈惊讶于“从可可豆做”这件事，大家也一起回送了友チョコ。

## 她的关键台词
- 0028「まあ、ありがとうございます！／とっても可愛らしいですわ。」——收到巧克力时先道谢再夸“可爱”，用「ですわ」的大小姐口吻。
- 0030「栄養も考えてくださったんですのね。／なにが入っているんですの？」——听说是完全营养食，先领情，再好奇地追问成分。
- 0032「ふふ、なんだかすっごく、／栄養がありそうですわ。」——听到佑芽列出大蒜、高丽参、蝮蛇粉后没有嫌弃，笑着顺着说“很有营养的样子”。
- 0033「わたくしも、はい、どうぞ。」——收到后立刻回送自己的巧克力，自称「わたくし」。
- 0037「あ、ほんとですわ。ええっと、／13時にステージ前に来て？」——和佑芽一起看広的消息，把内容念出来。
- 0052「篠澤さんの、シークレットライブ／ですわぁ～！」——看到広唱歌，兴奋地叫出“秘密演唱会”。称呼広为「篠澤さん」。
- 0057「篠澤さんっ、とーっても、／素敵なお歌でしたわ～！」——歌后直接、热情地夸奖。
- 0064「ええっ、そんなことできますの？」——听说巧克力是从可可豆做起，惊讶并直接问“这种事能做到吗”。
- 0067「ひええ～……」——听広说4小时一直在做、手都快断了，发出夸张的惊叹。
- 0071「あ、そうですわ！」——想起要回送友チョコ，立刻接上。

## 行为模式
- 收到别人的礼物 → 先道谢并夸可爱，再关心内容（0028、0030）。
- 听到听起来很猛的成分 → 不挑剔，笑着正面理解（0032）。
- 对方有心意，自己也准备了东西 → 马上回礼（0033、0071）。
- 看到好朋友表演 → 热情地当面夸奖，用感叹语气（0052、0057）。
- 听到出乎意料的努力 → 老实地惊讶并发问（0064、0067）。
