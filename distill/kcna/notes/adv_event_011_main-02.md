# 活动 011 琴音与麻央的日常 / main-02 交换祈愿 女儿节 第2话（adv_event_011_main-02）

- 她的台词：21 行（含用匿名标签说的 0 行）：0001、0003、0004、0008、0019、0025、0027、0028、0032、0048、0050、0051、0053、0055、0057、0058、0059、0061、0062、0063、0065
- 出场的人：千奈、麻央、手毬、運営スタッフ
- 场景：女儿节会场的准备现场，打合せ当天；之后（0046 起）是女儿节前一天，千奈追着不安的手毬出了レッスン室。
- 世界线：活动 011；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
千奈到了会场很兴奋，被手毬提醒是来工作的。运营方临时请三人演10分钟的ひな祭り演剧，千奈说自己完全没演过戏，知道麻央当过子役后放心，请麻央指导。到了演剧前一天，她看到手毬不安地离开练习室，追上去问。手毬说不擅长对应客人，千奈说自己也一样不安，但如果自己真有那种让人笑的力量，就想用它支持手毬；两人相互承诺危险时会互相帮助。
剧情经过参照 ttmr 笔记。

## 她的关键台词
- 0001「おお～！／ここがお祭りの会場ですのね！」——一到会场就兴奋。
- 0003「はっ！　そうでしたわ！」——被手毬提醒后马上反应，说明她容易高兴过头但很快能回到正题。
- 0019「わたくし、演劇はまったく／やったことありませんわ！」——毫无经验却说得很响亮，引来手毬吐槽“なんで自慢げなの”。
- 0027「そういうことであれば、／なんにも心配はいりませんわね！」——听说麻央当过子役，立刻觉得放心。
- 0028「ご指導、よろしくお願いいたしますわ！」——郑重地请麻央指导。
- 0050「月村さんがなんだか不安そうな表情で／レッスン室を出ていったので、」——说明自己追来的理由：看到手毬的表情。
- 0053「――不安、ですわよね。／お気持ち、とっても分かりますわ。」——听手毬说完先认同她的不安。
- 0055「皆さんそう言ってくださいますが、／正直、自信はないですわっ！」——被说擅长这类事时，坦白说自己没有自信（又被吐槽“なんで自慢げなの”）。
- 0058「その力で、月村さんのサポートを／したいと思っていますわ。」——如果自己真有那种力量，就想用来支持手毬。
- 0059「わたくしたち、お友達ですもの！」——把动机归为“朋友”。
- 0062「わたくしだって、／きっとピンチになりますもの。」——说明自己也会有需要帮助的时候，所以不是单方面照顾。
- 0065「はいっ！」——听到手毬说“一定会帮你”，干脆地接受。

## 行为模式
- 到新地方 → 先兴奋出声，被提醒后立即切换到工作状态（0001、0003、0004）。
- 完全没经验 → 大方说“从没演过”，转而依靠有经验的前辈（0019、0027、0028）。
- 发现朋友不安 → 主动追上去问，并先承认“我懂”，再说自己的做法（0050-0053）。
- 被夸“擅长” → 坦白说没自信，但愿意把别人说的力量用来帮朋友（0055、0057、0058）。
- 帮助别人 → 强调彼此互助，说自己也会有“ピンチ”的时候（0061、0062）。

## 关系
- 手毬：叫她「月村さん」（0048、0050、0058）；手毬提醒她别太兴奋，在她安慰后道谢（手毬 0060），说一定会帮她（手毬 0064）；千奈说“お友達”（0059）。
- 麻央：叫她「麻央先輩」，请她“ご指導”（0028）；知道她当过子役后放心（0027）。

## 档案类事实
- 完全没有演剧经验（0019）。
- 自己说对在客人面前的事没有自信，但周围人说她擅长（0055）。
