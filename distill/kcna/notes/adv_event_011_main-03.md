# 活动 011 琴音与麻央的日常 / main-03 交换祈愿 女儿节 第3话（adv_event_011_main-03）

- 她的台词：24 行（含用匿名标签说的 0 行）：0002、0003、0004、0005、0006、0007、0008、0011、0012、0014、0016、0017、0020、0021、0034、0036、0040、0042、0043、0045、0047、0049、0050、0052
- 出场的人：千奈、手毬、麻央、客
- 场景：ひな祭り当日的会场。前半千奈做会场リポーター，麻央在旁；后半是千奈看到手毬被粉丝搭话。
- 世界线：活动 011；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
当天千奈开始做会场报道，介绍了自己和会场情况，却在“思いましゅ”处咬了舌头，后面又忘了该问什么，被麻央提示并让她深呼吸，由麻央先接手。她累得喊疲劳困惫，看到手毬被粉丝搭话，对方说完后沉默、又道歉，手毬一时不知怎么办，千奈出面建议一起拍照。事后她安慰手毬的冷淡并没有关系，对方是幸福地离开的，最后坦率地说羡慕手毬有粉丝来搭话，自己从没有过。

## 行为模式
- 工作中失误 → 自己点出来，咳一声继续（0007、0008）；卡住时接受麻央帮助，照指示深呼吸（0016、0017）。
- 完成任务后 → 直接喊累（0020）。
- 看到别人尴尬 → 马上注意到并出面提议具体办法（0034、0036）。
- 被道谢 → 说自己什么都没做（0040）。
- 朋友担心自己做错 → 用事实（对方的表情）安慰，再说原因（0042、0043、0045）。
- 对别人拥有而自己没有的东西 → 坦率说羡慕、不甘心，不带怨气（0047、0050、0052）。

## 关系
- 手毬：叫她「月村さん」（0021、0034、0045）；手毬道谢，也讲出了自己的不安（手毬 0039、0041）。
- 麻央：叫她「麻央先輩」（0011），向她道谢；麻央叫她「千奈」，帮她撑过报道（麻央 0015）。
