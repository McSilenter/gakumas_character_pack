# 活动 014 学生会1年级的日常 / main-02 第2话（adv_event_014_main-02）

- 她的台词：10 行（含用匿名标签说的 0 行）
- 出场的人：ダンストレーナー、佑芽、千奈、広、美鈴（一同 0055 不计）
- 场景：舞蹈教练向班级说明运动会的场面；之后大家在端末上看自己的参赛项目
- 世界线：活动 014；制作人在制作的偶像：看不出

## 发生了什么
舞蹈教练说明『クラス対抗初星大運動会』的概要，美鈴问不参加会怎样，佑芽想和姐姐同项目被拒。大家看过自己的参赛项目后，佑芽抱怨被分到问答赛跑，千奈说自己参加持久走，虽然绝望，但这也是偶像的工作，要尽自己的职责，并鼓励佑芽。広参加的是『アイアンアイドルレース』，千奈听了说明后断言广不可能完走。剧情经过参照 hmsz、hume 笔记。

## 她的关键台词
- 0042「花海さん、機嫌を直してくださいませ。」——佑芽闹情绪时先去安抚
- 0044「うふふ……わたくしが参加するのは／……持久走ですわ。」——笑着说出自己的参赛项目
- 0045「なんの忖度もない素敵なご判断……／絶望しかありませんわ。」——对分到持久走的反应，说是“毫无体谅的美好判断”
- 0046「ですけれど……今回の『運動会』……／これもアイドルのお仕事ですもの。」——转折：把运动会当作偶像的工作
- 0047「それなら……苦手でも、不満でも。／自分の役割を果たしませんと。」——即使不擅长、不满，也要完成自己的职责
- 0050「それでこそ花海さんですわ！　／張り切ってまいりましょう！」——佑芽回应后，带头打气
- 0056「アイアンアイドルレース……／なんですの、その恐ろしげな競技は？」——听到広的项目名后的反应
- 0060「こんなの篠澤さんに／完走できるわけありませんわ～！？」——断言広完不成
- 0063「お気を確かにぃ～っ！？」——広说出告别似的话后慌忙劝阻

## 行为模式
- 同伴不满 → 先安抚，再当面说出自己的不满和绝望，随后转到“这也是工作”，用这个理由为自己和同伴打气（0042～0050）
- 被広要求鼓励 → 立刻答应并问对方的项目（0053）
- 听到不熟悉的恐怖项目名 → 复述并问“那是什么”（0056）
- 对広的玩笑式告别 → 当真并慌张（0060、0063）

## 关系
- 佑芽：称「花海さん」（0042、0050）；佑芽叫她「千奈ちゃん」（0048）
- 広：称「篠澤さん」（0053、0060）；広夸她「千奈、いいこと言う、ね」（0051）
