# 活动 015 / 巡演活动 广岛篇 第2话（adv_event_015_main-02）

- 她的台词：17 行（含用匿名标签说的 0 行）
- 出场的人：莉波、千奈、リーリヤ
- 场景：筹备广岛live的作战会议，三人在商量set list、MC和广岛观光
- 世界线：活动 015；制作人在制作的偶像：看不出

## 发生了什么
三人商量set list，千奈说『初』是练习过很多次的拿手曲，但三人一起唱是第一次。她提到听说莉波有unit经验，提出昼场和夜场用不同构成的点子（海鸥叫声变成乌鸦叫声，夏天的曲子变成万圣节的曲子），被莉波称赞。讨论MC时，她提议讲当地的话题，并提出前一天在广岛市内走动找话题，最后主动提出做观光路线。

## 她的关键台词
- 0002「『初』は何度も練習した、／大の得意曲ですわ。」——『初』是她的拿手曲
- 0004「最初に歌うのか、トリにするのか、／悩ましいですわね。」——考虑曲序
- 0007「考えることがたくさんですわー！」——要考虑的事很多
- 0010「そういえば、莉波お姉さまは、／ユニット経験がおありと聞きましたわ。」——提起莉波的unit经验
- 0017「たくさん、お勉強させてもらいますわ。」——对莉波的话的回应
- 0018「ウミネコの鳴き声と思わせて、／カラスの鳴き声に――」——自己的演出点子
- 0020「ええ。昼の部と夜の部で、／違う構成にすれば――」——点子的用意：昼夜不同
- 0023「えへへ。莉波お姉さまに／褒められてしまいましたわ。」——被称赞后开心
- 0038「ご当地のエピソードをお話しすれば、／みなさん喜んでくれると思いますわ。」——MC的提案
- 0043「でしたら、広島市内を歩き回って、／トークの種拾いをいたしましょう。」——找话题的办法
- 0048「有名な厳島神社や、／広島城もありますわ。」——补充观光景点
- 0053「では、みなさんの希望をすり合わせて、／観光ルートを作成いたしましょう。」——提出做观光路线
- 0054「わたくしにお任せくださいませ！」——主动接下任务

## 行为模式
- 遇到要考虑的事 → 一面叹“要考虑的事真多”，一面认真想具体方案（0004、0007）
- 想到点子 → 说出细节（海鸥→乌鸦），并说明目的“两场都来的观众也会开心”（0018～0021）
- 被称赞 → 直接表现高兴（0023）
- 话题卡住时 → 提出解决办法（走动找话题），并主动揽下做路线的工作（0043、0053、0054）
