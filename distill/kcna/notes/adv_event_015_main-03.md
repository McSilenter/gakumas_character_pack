# 活动 015 / 巡演活动 广岛篇 第3话（adv_event_015_main-03）

- 她的台词：13 行（含用匿名标签说的 0 行）
- 出场的人：莉波、リーリヤ、千奈（スタッフ 0003、0004；一同 0053 不计）
- 场景：旁白「広島市。ライブスタジオ。」，live前一天，在会场看舞台、彩排，之后逛广岛城，吃御好烧
- 世界线：活动 015；制作人在制作的偶像：看不出

## 发生了什么
三人到会场看舞台，千奈说有点紧张。リーリヤ提议把动作和fan service做大，千奈赞成。彩排结束后她累得说“我做完了”，被莉波提醒本番是明天。逛广岛城时，她夸莉波像真的导游；リーリヤ误会广岛城主是家康，她说大家对瑞典的城堡也不熟，安慰リーリヤ。吃御好烧时她说广岛的御好烧由店员来烤，最后劝リーリヤ吃多了就多走路。

## 行为模式
- 到了正式场所 → 坦白说紧张（0005）
- 听到后辈的提议 → 立刻明确赞成（0014）
- 事情做完 → 放松过头，被提醒才想起还有明天（0016、0018）
- 同伴感到羞耻 → 用“我们也一样”的对等例子去安慰（0031、0032）
- 注意到同伴的表情 → 直接说出来（0038）
- 同伴的爱好话题不熟悉 → 只复述作品名，不插嘴（0040）
