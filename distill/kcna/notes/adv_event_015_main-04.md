# 活动 015 / 巡演活动 广岛篇 第4话（adv_event_015_main-04）

- 她的台词：20 行（含用匿名标签说的 0 行）。0016 之后的大部分是舞台上做MC时说的话
- 出场的人：莉波、千奈、リーリヤ（一同 0015、0071 不计）
- 场景：旁白「ライブ当日」，广岛live的后台和舞台上
- 世界线：活动 015；制作人在制作的偶像：看不出

## 发生了什么
live当天，千奈说借了莉波的薰衣草安眠用品睡得很好，安慰紧张的リーリヤ，看到星南的面板后问星南是否也在这里办过live。上台前她提议叠手。舞台上，预定的曲子突然没响，莉波慌张时，千奈站出来说她们记了当地的歌，要用无伴奏的方式唱，请观众一起合唱。事后音响恢复，她对观众道谢。

## 她的关键台词
- 0005「大丈夫ですわ。この日のために、／練習してきたんですもの。」——安慰紧张的リーリヤ
- 0008「まあ、ほんとですわ。／星南お姉さまもここでライブを？」——看到星南的面板后发问
- 0012「――始まりますわ。／さ、手を重ねましょう。」——提议叠手
- 0018「わたくしたちにとって、とーっても、／思い出深い曲なんですの。」——舞台上介绍『初』
- 0023「言えばー？」——接リーリヤ的“说到点心”
- 0030「本場広島のお好み焼き、／とっても、美味しかったですわ。」——被问フィーカ时，回答的却是御好烧
- 0035「天守閣にのぼって、／壮観な眺めでしたわー。」——聊昨天去广岛城的事
- 0042「夏にぴったりな～？」——和观众互动，引出下一首歌名
- 0052「……こほん。どうやら、／トラブルのご様子ですが――」——故障时清嗓子站出来
- 0055「ご当地の歌を覚えてきましたの！」——宣布用当地的歌救场
- 0059「ほら、ふたりとも、／覚えてきたではありませんか。」——对莉波和リーリヤ暗示
- 0063「わたくしたちが、／アカペラで歌いますので、」——决定无伴奏演唱
- 0064「皆様も、どうか一緒にご唱和を。」——请观众一起唱
- 0066「皆様、お声を出してくださって、／ありがとうございました！」——事后向观众道谢

## 行为模式
- 同伴紧张 → 用“为这一天练习过”来安慰（0005）
- 想到该做的仪式 → 在开场前自然提议叠手（0012）
- 舞台上被点名发言 → 接话时会说出略微偏题的回答（0030）
- 发生突发故障 → 在同伴慌张时清嗓子站出来，宣布用学过的当地歌无伴奏唱，把观众拉进来（0052～0064）
- 事后 → 向观众致谢（0066）

## 关系
- 莉波：称「莉波お姉さま」（0003）；莉波叫她「千奈ちゃん」（0053）
- リーリヤ：对话中没有直接称呼，在舞台上接她的话
- 星南：称「星南お姉さま」（0008）

## 档案类事实
- 千奈借了莉波的薰衣草安眠用品，睡得很好（0003）
- 千奈说在广岛城登上天守阁，眺望很壮观（0035）
- 她们事先“学了”广岛的应援歌（0055、0059）

## 不确定

- 「一同」0015「お好み焼きーーーーっ！」、0071「聴いてください♪」：齐声，是否含她，待统一判定
- 0030 她的回答「お好み焼き」是想接上リーリヤ的“フィーカ”话题还是偏题，莉波 0031 用“お菓子じゃないよね”吐槽
