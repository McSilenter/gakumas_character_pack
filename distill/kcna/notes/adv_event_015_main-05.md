# 活动 015 / 巡演活动 广岛篇 第5话（adv_event_015_main-05）

- 她的台词：16 行（含用匿名标签说的 0 行）。0004、0006 是舞台上的话
- 出场的人：莉波、千奈、リーリヤ（一同 0008、0048 不计）
- 场景：广岛live的舞台上（昼场末尾），之后live结束，午饭、夜场前的休息时间，在红叶行道树前
- 世界线：活动 015；制作人在制作的偶像：看不出

## 发生了什么
舞台上，莉波用“哎~才刚来吗~”的互动喊话带动观众，千奈当真了，被莉波解释，说自己学到了。三人唱完『初』，千奈说有意外，但广岛公演大成功。莉波道歉，千奈说莉波MC做得很好，并说只要观众笑，live就成功。千奈提议去吃午饭，免得夜场声音出不来，聊起あなご饭、内脏天妇罗。リーリヤ想在寮里办御好烧派对，千奈说自己不住寮也想参加。最后在红叶树前，她发现莉波的馒头已吃完，提议用红叶叶子代替。

## 她的关键台词
- 0004「……え？　皆様、／いま来たばっかりですの？」——把舞台上的互动喊话当成真的
- 0006「まあ、そうでしたのね！／わたくし、学びを得ましたわ。」——被解释后高兴地说“学到了”
- 0010「広島公演、大っ成功でしたわ！」——live后的总结
- 0015「いーえっ。莉波お姉さまは、／立派にMCをこなしておられましたわ。」——对莉波的道歉否定，称赞她的MC
- 0018「ファンの皆様が笑顔なら、／ライブは大成功ですわ。」——对“成功”的标准：观众的笑容
- 0024「お腹を空かせていては、／夜の部で声が出ませんわ。」——提议吃午饭的理由
- 0026「あなご飯もホルモン天ぷらも、／最高でしたわー。」——对午饭的感想
- 0030「わたくしも、寮生ではありませんが、／参加したいですわ。」——想参加寮里的御好烧派对，说明自己不住寮
- 0043「……って、莉波お姉さま、／お饅頭はどうしましたの？」——发现莉波的馒头不见了
- 0046「こほん。それでは、／かわりに紅葉の葉っぱを持って――」——想出代替办法

## 行为模式
- 听到不懂的玩笑 → 当真地反问，被解释后“学到了”（0004、0006）
- 事情顺利后 → 总结成功，并说成功的标准是观众的笑容（0010、0018）
- 前辈道歉 → 立刻否认，具体称赞对方（0015）
- 有提议时 → 先想到下一步的体力管理（0024）
- 发现小失误 → 先惊讶，再清嗓子提出变通（0043、0046）
