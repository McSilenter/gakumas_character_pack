# 倉本千奈 培育事件 001 activity / 001 天鹅与偶像（adv_pevent_001_kcna_activity_001）

- 她的台词：12 行（含用匿名标签说的 0 行）
- 出场的人：千奈（12 行）、プロデューサー（3）
- 场景：剧本里看不出地点和时间点
- 世界线：培育（倉本千奈）；制作人在制作的偶像：倉本千奈（剧本里没有直接说法）

## 发生了什么
她对制作人说“偶像就像天鹅一样”，制作人问是什么意思，她自己却想不起来了（0001～0003）。之后是几种并列的反应：一种是她认同制作人的回答，说这是训练员讲的、自己很受感动——华丽的舞台背后有不懈的努力，自己总有一天也要成为天鹅（0004～0007）；一种是她觉得“没错，但好像哪里不对”，说那样的话就说明不了狗和猫为什么不一样，又不太确定地问“确实都是生物……是这样吗”（0008～0011）；一种是她听了某个说法吃惊，制作人问“意外吗”，她感叹天鹅看着完全不同原来是鸭子的同类，接着又问这和偶像有什么关系来着（0012～0015）。

## 她的关键台词
- 0001「先生。アイドルとは／白鳥みたいなものですわ。」——一开口就是郑重的“名言”，称制作人为「先生」
- 0003「どちらも……ええと……／なんでしたっけ？」——把听来的话的要点忘了
- 0005「トレーナーが言っておりました。／わたくし、感銘を受けましたわっ！」——话是从训练员那儿听来的，受了感动就拿来讲
- 0006「あの華やかな舞台の裏には、／たゆまぬ努力があるのだとっ……！」——她认同的偶像观：华丽背后是不懈的努力
- 0007「わたくしも、いつか……／いつか白鳥になりますわ～～っ！」——把感动直接化成自己的目标
- 0010「だってそれだと、犬や猫が／違う理由にならないですわ。」——对不合理的解释会认真地提出反驳
- 0014「まったく違うように見えて、／カモのお仲間だったのですね……」——对新知识老实地感叹
- 0015「……それがアイドルと、／どう関係するのでしたっけ？」——话题被岔开后又绕回原点，自己也糊涂了

## 行为模式
- 听到让她感动的话 → 马上转述给制作人，并说自己也要那样（0001、0005～0007）
- 被追问细节 → 想不起来，用“なんでしたっけ”老实承认（0003、0015）
- 觉得解释哪里不对 → 先表示同意，再说出“好像不对”的理由，最后又不确定地反问（0008、0010、0011）
- 听到意外的知识 → 吃惊地反问“そうなんですの”，再认真感叹（0012、0014）
- 说话 → 自称“わたくし”，用“～ですわ”“～ですの”“～かしら”一类语尾（0005、0011、0012）

## 关系
- プロデューサー：她称「先生」（0001）；本篇制作人没有称呼她。她把听来的话拿来和制作人讨论，对制作人的说法有时认同、有时提出疑问（0004、0008～0011）。
- トレーナー：她提到“偶像像天鹅”是训练员说的（0005），训练员没有出场。

## 档案类事实
- 她认同的偶像观：华丽的舞台背后有不懈的努力（0006）
- 立志总有一天成为天鹅那样的偶像（0007）

## 不确定
- 0004、0008、0012 之前应该各有一个制作人的选项（剧本里没有），三段是并列的反应；0010 里的“犬や猫”是在回应哪种说法（大概是“都是生物”），剧本里看不出。
- 【译文】0010「だってそれだと、犬や猫が／違う理由にならないですわ。」译作“狗和猫就不能成为理由了”，原文意思是“那样的话，就说明不了狗和猫为什么不一样（不是偶像）”，译文意思不清。
