# 倉本千奈 培育事件 001 activity / 002 家庭作业（adv_pevent_001_kcna_activity_002）

- 她的台词：12 行（含用匿名标签说的 0 行）
- 出场的人：千奈（12 行）、プロデューサー（4）
- 场景：休息日（0003「せっかくのお休み」），她在制作人面前做作业；地点剧本没写
- 世界线：培育（倉本千奈）；制作人在制作的偶像：倉本千奈（剧本里没有直接说法）

## 发生了什么
她对着作业苦恼地喊“不懂”，制作人在心里想“有那么难吗”（0001、0002，制作人的心里话）。她为难得的休息日却在做作业向制作人道歉，制作人夸她认真做作业，她答应努力，接着说有个小请求（0003～0005）。之后是并列的几种反应：一种是她大受打击，说“不是发过誓要两个人携手前进吗”，制作人心里想自己没那么说过；她又拜托制作人对大家保密（0006～0009）。一种是她说“除了答案以外都行”，又担心今天做不完；制作人说会好好支持、先做做看，她感动地表示要努力（0010～0013）。一种是她听了制作人的某句话，惊讶地说“真巧，和我一样”，接着慌了：那自己要怎么熬过作业（0014～0016）。

## 她的关键台词
- 0001「うーんうーん……／わかりませんわぁ～～～……」——做不出题时直接叫苦
- 0003「先生～。せっかくのお休みに／宿題なんて、申し訳ありません……」——占用制作人的休息日，先道歉
- 0005「はいっ！　……ですがその、／ちょっとお願いが……」——被夸后立刻答应，又小心地提出请求
- 0007「ふたりで手を取り合っていくと／誓ったではありませんか！」——被拒绝时搬出夸张的“誓言”（制作人心里说没这么说过，0008）
- 0009「みなさまには内緒で！／お願いいたしますわ～っ！」——请制作人帮忙的事不想让大家知道
- 0010「答え以外！」——退一步提出求助范围
- 0013「先生……！／わ、わたくし、がんばりますわ！」——被说会支持后很感动，马上表态努力
- 0016「……で、では、わたくしは／どうやって宿題を乗り切れば！」——发现指望不上时慌张

## 行为模式
- 学习遇到困难 → 毫不掩饰地叫苦，然后向制作人求助（0001、0005）
- 占用了制作人的时间 → 先道歉（0003）
- 请求被拒 → 用夸张的说法（“发过誓”）来争取，并恳求对别人保密（0006、0007、0009）
- 被说会支持 → 感动地喊「先生」并表示要努力（0012、0013）

## 关系
- プロデューサー：她称「先生」（0003、0013）；本篇制作人没有称呼她，心里话里叫她“倉本さん”（0002）。她把制作人当作可以求助的对象，被支持时很感动（0013）。
- みなさま：她要制作人对“大家”保密（0009），具体指谁剧本里没说。

## 档案类事实
- 学校作业对她来说很难，休息日也在做作业（0001、0003）
- 0015 她说“和我一样”，是哪一点一样剧本里没写（见「不确定」）

## 不确定
- 0005 和 0006 之间、0009 和 0010 之间、0013 和 0014 之间应该有制作人的选项（剧本里没有），三段是并列的反应。
- 0010「答え以外！」的意思读不准：可能是“（帮我）除了直接给答案以外都行”，也可能是回答制作人“要帮什么”的问题；剧本里看不出制作人前面说了什么。
- 0014、0015 她说“真巧，和我一样”，制作人说了什么（可能是自己也不擅长作业之类）剧本里没有，“一样”的内容看不出。
