# 倉本千奈 培育事件 001 activity / 003 如何增强体力（adv_pevent_001_kcna_activity_003）

- 她的台词：12 行（含用匿名标签说的 0 行）
- 出场的人：千奈（12 行）、プロデューサー（7）
- 场景：她和制作人一起外出（0008「こうして外出するのも」）；具体地点剧本没写
- 世界线：培育（倉本千奈）；制作人在制作的偶像：倉本千奈（剧本里没有直接说法）

## 发生了什么
她抱怨每天运动很累，制作人说她首先得增强体力；她说明白，但运动太累了，问有没有别的好办法（0001～0005）。之后是几种并列的回应：制作人说真正的偶像也要大量活动，像这样外出也是锻炼的一环，边玩边运动吧，她佩服制作人想得周到，答应边享受边运动（0006～0010）；制作人说她的饮食已经有严格的营养管理（意思是只能靠运动），她泄气地问那还剩什么，制作人提议去游泳换换心情，她听到泳池很高兴，期待和先生一起去（0011～0015）；制作人让她看跑步的数字，她发现自己能跑的距离变长了，制作人说一周后会更长，她说“那半年后……！”并表示要干（0016～0019）。

## 她的关键台词
- 0001「はうぅ～～～～。／毎日の運動は大変ですわぁ～～～～。」——对每天的运动直接叫苦
- 0004「ですが運動はとっても疲れます。」——明白道理，但老实说出累
- 0005「他にもいい方法は／ないものでしょうか？」——想找不那么累的办法
- 0007「うぅ……ごもっとも……」——被正论说服，不甘心地认同
- 0009「そ、そこまでお考えだったのですね。」——发现外出也是安排好的锻炼，佩服制作人
- 0014「プールですか！？／それはもう、ぜひ！」——一听是玩乐性质的运动就来劲
- 0015「先生とプール……／楽しみですわぁ……」——期待的是和先生一起
- 0017「……はっ！／走れる距離が長くなっています！」——看到数字上的进步而惊喜
- 0019「では半年後には……！／わたくし、やりますっ！」——看到成长后立刻燃起干劲

## 行为模式
- 被要求做辛苦的锻炼 → 先叫苦、想找别的办法，但被讲道理后会认同（0001、0004、0005、0007）
- 得知制作人的安排有用意 → 佩服并改口积极配合（0009、0010）
- 运动被包装成玩乐 → 立刻兴奋起来（0014、0015）
- 看到自己进步的具体数字 → 马上往更远的将来想，表态要努力（0017、0019）
