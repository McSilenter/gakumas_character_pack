# 倉本千奈 培育事件 001 activity / 004 千奈的目标（adv_pevent_001_kcna_activity_004）

- 她的台词：12 行（含用匿名标签说的 0 行）
- 出场的人：千奈（12 行）、プロデューサー（3）
- 场景：剧本里看不出地点和时间点
- 世界线：培育（倉本千奈）；制作人在制作的偶像：倉本千奈（剧本里没有直接说法；0013 她说制作人“接下了”她）

## 发生了什么
制作人问她作为偶像有没有当作榜样的人，她说当然是星南お姉さま，想成为像姐姐那样闪闪发光的偶像（0001～0003）。之后是并列的几种反应：一种是她高兴地附和制作人，说有先生这句话就有了百人之力，要以姐姐为目标迈进，制作人在心里想“虽然远得没有尽头……”（0004～0007，0006 是制作人的心里话）；一种是她自己说当然知道和姐姐有天壤之别，也许是天和地底之差，但为了先生不被炒掉，非实现不可（0008～0011）；一种是她说“只能成为那样”，不然对接下自己的先生交代不了（0012、0013）。最后制作人说总之努力吧，她说要拼上性命努力（0014、0015）。

## 她的关键台词
- 0002「アイドルとして、ですか？／もちろん星南お姉さまですわ！」——榜样毫不犹豫就是星南
- 0003「お姉さまのような、キラキラと／煌くアイドルになりたいのです！」——她的目标：像星南那样闪耀的偶像
- 0005「先生にそう言って／いただけたなら百人力ですわ！」——制作人的一句话就能给她很大底气
- 0008「もちろん、天と地ほどの／差があるのはわかっておりますわ。」——清楚自己和星南差距很大
- 0009「天と地の底かもしれません。」——把差距说得更夸张，自我评价很低
- 0010「ですが先生が／クビにならないためにも……」——努力的理由之一是不让制作人被解雇
- 0013「でないと、引き受けてくれた／先生に示しがつきません！」——觉得要对接下自己的制作人负责
- 0015「わたくし、命を削って／がんばりますわ～～っ！」——夸张的决心表态

## 行为模式
- 被问到目标 → 立刻说出星南，语气骄傲（0002、0003）
- 谈到自己和榜样的差距 → 坦白承认差距很大，甚至说得更夸张，但不因此放弃（0008、0009、0011）
- 想到制作人为自己付出 → 把“不辜负制作人”“不让制作人被解雇”当成努力的理由（0010、0013）
- 表决心 → 用很夸张的说法（0005、0015）

## 关系
- 星南：叫「星南お姉さま」「お姉さま」（0002、0003、0007）；把她当作偶像的榜样，想成为她那样的偶像（0003）。星南没有出场。
- プロデューサー：她称「先生」（0005、0010、0013）；本篇制作人没有称呼她。她觉得制作人是“接下了自己”的人（0013），担心自己不成功制作人会被解雇（0010）。制作人心里觉得她离星南还很远（0006，制作人的心里话）。

## 档案类事实
- 作为偶像的榜样是星南（0002）
- 想成为像星南那样闪耀的偶像（0003）
- 她自己认为和星南差距极大（0008、0009）

## 不确定
