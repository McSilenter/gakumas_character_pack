# 倉本千奈 培育事件 001 activity / 005 憧憬宿舍生活（adv_pevent_001_kcna_activity_005）

- 她的台词：12 行（含用匿名标签说的 0 行）
- 出场的人：千奈（12 行）、プロデューサー（5）
- 场景：剧本里看不出地点和时间点
- 世界线：培育（倉本千奈）；制作人在制作的偶像：倉本千奈（剧本里没有直接说法）

## 发生了什么
她感叹宿舍真好，制作人问她不住宿舍吗，记得她是和女仆们一起住在附近的别墅（0001～0003）。她说是的，因为自己一个人没法生活，但和大家一起住一定很开心（0004、0005）。之后是并列的几种反应：一种是她惊喜于制作人也这么想，憧憬和大家一起做饭、开睡衣派对，说每晚都不会腻，制作人劝她就算住进去也别每晚都开（0006～0009）；一种是她说住宿舍要做的事早就定了——睡衣派对，每晚聚在一起说秘密，制作人说和朋友熬夜确实好像很开心，她说一定会聊得热火朝天（0010～0013）；一种是她说不用麻烦先生，等到哪天确信自己能做到，要亲自向爷爷请求（0014～0017）。

## 她的关键台词
- 0001「寮……／寮っていいですわね。」——对宿舍生活的憧憬
- 0004「はい。それはもう。わたくし、／ひとりでは暮らせませんから！」——爽快承认自己一个人生活不了
- 0005「ですが皆さんと一緒に暮らすのは、／きっと楽しいですわ……」——憧憬和大家一起生活
- 0007「あぁ……皆さんとお料理したり／パジャマパーティをするのですわ。」——具体想象的宿舍生活
- 0010「それは決まっております！／パジャマパーティですわ！」——想做的事早有定论
- 0011「夜な夜な皆さんで集まって、／秘密のお話をするのです。」——想要和同伴说悄悄话
- 0014「いいえ、先生の／お手はわずらわせませんわ。」——不想把这件事推给制作人
- 0017「自分でお爺様に直訴／いたしますっ！」——打算靠自己去说服爷爷（是打算，还没做）

## 行为模式
- 说起憧憬的事 → 越说越具体、越说越兴奋（0007、0008、0010、0011、0013）
- 被说中自己的不足（不会独自生活） → 毫不掩饰地爽快承认（0004）
- 涉及家里的决定 → 不想麻烦制作人，打算等自己有把握时亲自去说（0014、0016、0017）

## 关系
- プロデューサー：她称「先生」（0014）；制作人叫她“倉本さん”（0002）。制作人知道她的住处（0003）；她不想在宿舍的事上麻烦制作人（0014）。
- メイドさんたち：制作人说她和女仆们住在一起（0003），她确认（0004）。
- お爺様：她打算将来亲自向爷爷请求住宿舍的事（0017）；从这句看，住不住宿舍似乎要爷爷同意，但剧本里没明说。
- 皆さん：她想和“大家”一起住、一起做饭、开睡衣派对（0005、0007、0011），具体指谁没说。

## 档案类事实
- 不住宿舍，和女仆们住在附近的别墅（0003 制作人的说法，0004 她确认）
- 自己说一个人没法生活（0004）
- 憧憬宿舍生活：和大家一起做饭、开睡衣派对、说秘密（0007、0010、0011）
- 有爷爷（「お爺様」，0017）
