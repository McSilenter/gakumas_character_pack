# 倉本千奈 培育事件 001 activity / 006 演技研究概论引言（adv_pevent_001_kcna_activity_006）

- 她的台词：11 行（含用匿名标签说的 0 行）
- 出场的人：千奈（11 行）、プロデューサー（6）
- 场景：剧本里看不出地点和时间点；她借的书是在图书馆找到的（0010）
- 世界线：培育（倉本千奈）；制作人在制作的偶像：倉本千奈（剧本里没有直接说法）

## 发生了什么
她拿着借来的书来找制作人，说太难了读不懂，书名她念成「演技研究キロン序説」（0001～0003）。制作人心里想这不是大学的论文集吗，嘴上说这本连大学生都难，完全是学术领域，不是课程用书，现在不用看（0004～0007，0004 是制作人的心里话）。她以为读了就能提高演技，庆幸差点走错路，向先生道谢（0008、0009）。并列的另一种反应：她说是在图书馆看到书上写着“演技”就借了，制作人问“就因为这个？”，她说自己没那么浅薄，还因为字很小，所以一定写得很详细……吧（0010～0013）。再一种：制作人告诉她这个字读『ガイ』，她先当是开玩笑，接着不安地问“真的吗”（0014～0017）。

## 她的关键台词
- 0001「先生！　本を借りたのですが、／難し過ぎて読めませんわ！」——读不懂就直接来找制作人
- 0003「演技研究キロン序説というものです！」——书名念成“キロン”；从 0015 看是把读作“ガイ”的字念错了，自己没察觉
- 0008「わたくしてっきり、これを読めば／演技がうまくなるものだと……」——单纯地以为读书就能变强
- 0009「あぶないところでしたわ！／先生、ありがとうございます……！」——被纠正后老实道谢
- 0010「図書館で見つけたのです！／演技と書かれていましたから！」——选书的理由很直接
- 0012「そんなに浅はかではありませんわ。／文字も小さかったからです！」——想辩解，补充的理由却同样单纯
- 0013「とても詳しく書かれているはず！／……ですわよね？」——说到最后自己也没底
- 0016「またまたぁ。」——被指出读错字时先不信
- 0017「……ほ、本当ですの？」——随即动摇

## 行为模式
- 想提升自己 → 会主动找资料，但只凭书名上的字眼和“字小=详细”来判断（0001、0010、0012）
- 被指出走了弯路 → 庆幸并向制作人道谢（0008、0009）
- 被说“就因为这个？” → 先辩解自己不浅薄，补充的理由同样单纯，最后自己也不确定（0012、0013）
- 被指出读错 → 先当成玩笑，再不安地确认（0016、0017）

## 关系
- プロデューサー：她称「先生」（0001、0009）；本篇制作人没有称呼她。遇到读不懂的书先来问制作人，听从制作人的判断（0001、0009）。

## 档案类事实
- 去图书馆借过一本演技研究的学术书，读不懂（0001、0010；制作人说是大学的论文集，0004 心里话）
- 把书名里一个读作“ガイ”的汉字念成了“キ”（0003、0015；是哪个字剧本里没写，译文作“概”）
