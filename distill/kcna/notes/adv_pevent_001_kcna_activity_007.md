# 倉本千奈 培育事件 001 activity / 007 想做的自学（adv_pevent_001_kcna_activity_007）

- 她的台词：10 行（含用匿名标签说的 0 行）
- 出场的人：千奈（10 行）、プロデューサー（7）
- 场景：剧本里看不出地点和时间点
- 世界线：培育（倉本千奈）；制作人在制作的偶像：倉本千奈（剧本里没有直接说法）

## 发生了什么
她对制作人说想自习，问做什么好；制作人问是课程方面的吗，她说是，因为和别人做一样的事就追不上（0001～0003）。制作人在心里想自习能做的有限，但想回应她的干劲（0004，制作人的心里话）。之后是并列的三种建议和反应：制作人建议学习功课，说成绩稳定才能安心专注课程，她说“原来如此，但是……”，接着央求“不是这样的，请理解我”（0005～0008）；制作人建议看某种参考（说那种举止不一定是正确答案但能作参考），她说每晚都看，制作人提醒别减少睡眠，她答应（0009～0012）；制作人让她什么都不做去睡觉，说她的体力跟不上干劲，“寝る子は育つ”，就当是训练，她不甘心地承认制作人说得对，说现在就睡（0013～0017）。

## 她的关键台词
- 0001「わたくし、自習がしたいのです！／なにがいいでしょうか？」——主动想多练，但要请制作人出主意
- 0003「はい！　ほかの人と同じでは／追いつけないですから！」——自觉落后，想靠额外努力追上
- 0005「へっ？／アイドルのではなく？」——被建议学功课时愣住
- 0008「そうではないのですっ！／わかってくださいませ～～っ！」——想要的是偶像方面的自习，撒娇似地央求
- 0010「わかりましたっ！／毎晩見ますわ！」——得到想要的建议就立刻热情投入
- 0013「な、なにもせずにですか……？」——被叫去休息时不敢相信
- 0016「うぅっ……悔しいですが／おっしゃる通りですわ。」——不甘心，但承认对方说得对
- 0017「わかりました……っ！／今は寝ますっ……！」——接受后马上照做

## 行为模式
- 觉得自己落后 → 主动想加练，向制作人要方法（0001、0003）
- 得到不合心意的建议（学功课） → 先说“原来如此”，再坚持说“不是这样”（0007、0008）
- 得到合心意的建议 → 马上表示每晚都做，容易做过头（0010、0011）
- 被说体力跟不上干劲、要她休息 → 不甘心但承认，照做（0014、0016、0017）

## 关系
- プロデューサー：本篇她没有称呼制作人；制作人叫她“倉本さん”（0014）。她向制作人要建议，即使不甘心也听从制作人的判断（0016、0017）。制作人心里想回应她的干劲（0004）。

## 档案类事实
- 她觉得和别人做一样的练习就追不上（0003）
- 制作人说她的干劲比体力走在前面（0014，制作人的说法）
