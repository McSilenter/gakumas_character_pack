# 倉本千奈 培育事件 001 activity / 009 下雨（adv_pevent_001_kcna_activity_009）

- 她的台词：12 行（含用匿名标签说的 0 行）
- 出场的人：千奈（12 行）、プロデューサー（3）
- 场景：下雨的前一天（0001「明日は雨が降るそうです」）；地点剧本没写
- 世界线：培育（倉本千奈）；制作人在制作的偶像：倉本千奈（剧本里没有直接说法）

## 发生了什么
她告诉制作人明天好像会下雨，说自己一下雨就兴奋，喜欢听着淅淅沥沥的雨声在窗边度过（0001～0003）。之后是并列的三种回应：制作人表示同感，说雨天有晴天没有的氛围，她激动地说“我懂”，期待起明天（0004～0007）；制作人请她教自己怎么享受雨天，她说在不同于平时的凉爽空气和不断的雨声中喝奶茶特别好喝，请先生也试试（0008～0011）；她听了制作人的某种回答后问“那到底是为什么”，制作人说因为上学时会淋湿，她马上提出到家里去接，坐车上学就不会淋湿（0012～0015）。

## 她的关键台词
- 0002「わたくし、雨が降ると／ワクワクしてしまうのです。」——喜欢下雨
- 0003「しとしとと降る雨の音を聞きながら、／窓辺で過ごすのが好きなのですわ。」——她享受雨天的方式
- 0006「先生……！／わかります、わかりますわぁ……！」——对方有同感时非常高兴
- 0007「ふふっ♪　なんだか明日が／楽しみになってまいりましたわ！」——分享喜好后心情更好
- 0009「いつもと違うひんやりした空気、／途切れない雨音……」——用细致的感受描述雨天
- 0010「その中で飲むミルクティーが／とってもおいしいのですわ！」——雨天喝奶茶的喜好
- 0011「先生も、どうぞ／お試しくださいませ！」——想把喜欢的东西分享给制作人
- 0014「ああ、それならお家まで／お迎えにあがります！」——对方有困扰就马上提出帮忙
- 0015「車でなら、濡れずに／登校できますわ！」——提出的办法是用车接，很自然

## 行为模式
- 说起自己喜欢的事 → 细致地描述感受，并邀请对方也试试（0003、0009～0011）
- 对方表示同感 → 激动地附和“我懂”（0006）
- 对方不喜欢自己喜欢的东西 → 先问理由，再想办法替对方解决（0012、0014、0015）

## 关系
- プロデューサー：她称「先生」（0001、0006、0011）；本篇制作人没有称呼她。她想和制作人分享雨天的乐趣，制作人有困扰时主动提出开车去家里接（0011、0014、0015）。

## 档案类事实
- 一下雨就兴奋，喜欢听着雨声在窗边度过（0002、0003）
- 喜欢在雨天喝奶茶（0010）
- 她说可以坐车去接制作人上学（0015），即她有车可以接送（谁开车剧本没写）
