# 倉本千奈 培育事件 001 activity / 010 想睡觉（adv_pevent_001_kcna_activity_010）

- 她的台词：10 行（含用匿名标签说的 0 行）
- 出场的人：千奈（10 行）、プロデューサー（5）
- 场景：两人见面时互道「おはようございます」（0001、0002）；制作人说她“下午”和花海さんたち有约（0004）；地点剧本没写；她说这是和先生一起的放松（0011）
- 世界线：培育（倉本千奈）；制作人在制作的偶像：倉本千奈（剧本里没有直接说法）

## 发生了什么
她迷迷糊糊地打招呼，打了个哈欠，为不雅道歉（0001～0003）。制作人提起她下午和花海さんたち有约，她承认是因为太期待了睡不着（0004～0006）。制作人说真像倉本さん，让她到时间前悠闲一下（0007）。她道谢，说如果睡着了请叫醒自己（0008）。之后是并列的两种反应：制作人说睡眠不足就玩不尽兴，她已经半睡着，含糊地说“好主意……但难得是和先生的……放松……先生，可以的话一起……”，然后睡着（0009～0012）；制作人说轻轻活动身体就能醒，她觉得难为情，请制作人多关照（0013～0015）。

## 她的关键台词
- 0003「ふぁぁっ……／すみません、はしたない……」——打哈欠后马上为不雅道歉
- 0006「……おっしゃるとおりですわ。／楽しみでなかなか寝付けず……」——承认因为期待而失眠
- 0008「ありがとうございます……／寝てしまったら起こしてください……」——困得厉害，放心地把自己交给制作人
- 0011「ですがせっかくの……先生との……／いきぬき……」——半睡中也不想浪费和先生一起的放松时间
- 0012「せんせい……よろしければ／ごいっしょに……ぐぅ……」——迷糊中邀请制作人一起，然后睡着
- 0014「うぅ、おはずかしい……」——被看到困倦的样子感到难为情

## 行为模式
- 有期待的约定 → 前一晚兴奋得睡不着（0006）
- 在人前失礼（打哈欠） → 马上道歉、觉得难为情（0003、0014）
- 困倦时 → 对制作人很放心，请对方叫醒自己，甚至迷糊中邀请对方一起（0008、0012）

## 关系
- プロデューサー：她称「先生」（0011）；制作人叫她“倉本さん”（0007）。制作人知道她下午的安排（0004），说她因期待睡不着“很像倉本さん”（0007）。她把这段时间称作“和先生的放松”（0011）。
- 花海さんたち：制作人提到她下午和花海さんたち有约（0004），她为此期待得睡不着（0006）。是谁剧本里没具体说。

## 档案类事实
- 有期待的事会兴奋得睡不着（0006；制作人说这“很像她”，0007）

## 不确定
- 0008 之后、0012 之后应该各有制作人的选项（剧本里没有），0009～0012 和 0013～0015 是并列的反应。
- 0012「ごいっしょに」是邀请制作人一起做什么（一起睡？一起去？）读不准，她说到一半就睡着了。
- 0004「花海さんたち」具体指谁（花海姓的哪位、还有谁），剧本里没写。
