# 倉本千奈 培育事件 001 activity / 011 轻飘飘千奈（adv_pevent_001_kcna_activity_011）

- 她的台词：11 行（含用匿名标签说的 0 行）
- 出场的人：千奈（11 行）、プロデューサー（6）
- 场景：基础训练做柔软体操的第二天（0003「昨日、基礎トレで」）；地点剧本没写
- 世界线：培育（倉本千奈）；制作人在制作的偶像：倉本千奈（剧本里没有直接说法）

## 发生了什么
她笑着说身体好轻，制作人问怎么这么有精神；她说昨天基础训练做了柔软体操，虽然很痛，但之后一直很舒服（0001～0004）。制作人在心里惊讶昨天的效果持续到今天（0005，制作人的心里话）。之后是并列的三种反应：制作人说效果持续到第二天很少见，她说那就每天都做，能这样的话痛也不难受（0006～0009）；她对制作人的某句话惊讶地说“明明这么舒服？”，制作人说肌肉放松了不容易受伤、运动本身也会觉得舒服，她说一定要体验看看（0010～0013）；她惊喜地问自己看起来有那么轻吗，制作人说这是好事请坚持，她说以前课前只做轻微的体操，今后要好好做柔软体操再上课（0014～0017）。

## 她的关键台词
- 0001「うふふふ……／なんだか体が軽いですわっ！」——身体变轻让她心情很好
- 0004「とても痛かったのですが、／それからずっと気持ちがいいのです。」——痛苦之后感受到效果
- 0008「であれば、柔軟体操を／毎日いたしますわ。」——一旦觉得有效就决定每天做
- 0009「こんな風になるなら、／痛くても辛くありませんからっ。」——为了结果愿意忍痛
- 0013「運動が……それはぜひ、／体験してみたいですわっ！」——听说运动也会变舒服，马上有兴趣
- 0014「そんなにも軽そうに見えますかっ！？」——被人看出变化而惊喜
- 0016「わかりましたわ。レッスン前に／軽い体操はしていましたが……」——说出以前的习惯
- 0017「これからは、じっくり柔軟体操を／して、臨みたいと思いますわっ！」——打算改进做法（是打算）

## 行为模式
- 亲身感受到训练的效果 → 立刻说要每天做，痛也愿意忍（0004、0008、0009）
- 听说别的好处（运动也会变舒服） → 马上想体验（0013）
- 被说状态好、要坚持 → 回顾自己以前的做法，表示今后要认真做（0016、0017）

## 关系
- プロデューサー：本篇她没有称呼制作人；制作人没有称呼她。制作人注意到她比平时更有精神（0002），她向制作人报告训练后的感受，听从制作人的建议（0016、0017）。

- 以前课前只做轻微的体操（0016）
