# 倉本千奈 培育事件 001 activity / 012 请允许我表示感谢！（adv_pevent_001_kcna_activity_012）

- 她的台词：12 行（含用匿名标签说的 0 行）
- 出场的人：千奈（12 行）、プロデューサー（6）
- 场景：剧本里看不出地点和时间点
- 世界线：培育（倉本千奈）；制作人在制作的偶像：倉本千奈（0001 她感谢制作人对“わたくしのプロデュース”）

## 发生了什么
她突然感谢制作人一直以来对自己的プロデュース，说想了又想要怎么答谢，提议给制作人捶肩（0001～0004）。之后是并列的三种反应：制作人接受了，说会用更好的プロデュース回报，她高兴地道谢，当场就要制作人把背转过来（0005～0009）；制作人推辞，说努力的是倉本さん、光让她付出不好，她说请不要在意，是自己想为制作人做（0010～0013）；制作人说等她考试合格的时候再接受答谢，在那之前希望她一直往前看，她感动地喊“先生”，说那就漂亮地合格，到时候全力给他捶（0014～0018）。

## 她的关键台词
- 0001「先生、わたくしのプロデュース、／いつもありがとうございます。」——郑重地向制作人道谢
- 0003「なにかお礼をと考えに考え……／思い至ったのです！」——认真想过要怎么报答
- 0004「肩たたきなど、いかがかと！」——想到的答谢方式很朴素
- 0009「もちろんですっ！／さあ、お背中をどうぞ！」——想到就马上要做
- 0010「ど、どうしてですかっ！？」——好意被推辞时着急
- 0013「わたくしがして差し上げたいのです。／お受け取りください！」——坚持是自己想做
- 0017「先生……！」——被制作人的话打动
- 0018「では見事合格し……その暁には／精一杯お叩きいたしますわっ！」——把答谢和合格的目标连在一起（是约定，还没实现）

## 行为模式
- 受到照顾 → 认真想办法答谢，想到就当场行动（0003、0004、0009）
- 好意被推辞 → 着急地追问理由，坚持说是自己想做（0010、0012、0013）
- 制作人把答谢和目标挂钩 → 感动，并把它当成努力的动力（0017、0018）

## 关系
- プロデューサー：她称「先生」（0001、0017）；制作人叫她“倉本さん”（0011、0015、0016）。她感谢制作人的プロデュース，想亲手答谢（0001、0013）；制作人说努力的是她、希望她一直往前看（0011、0016），她很感动（0017）。

## 档案类事实
- 想到的答谢方式是给制作人捶肩（0004）
- 制作人说等她“试験に合格”时再接受答谢（0015，制作人的说法）；她表示要合格（0018）
