# 倉本千奈 培育事件 001 activity / 014 工作服（adv_pevent_001_kcna_activity_014）

- 她的台词：13 行（含用匿名标签说的 0 行）
- 出场的人：千奈（13 行）、プロデューサー（6）
- 场景：两人要去买工作用的衣服（0001、0002）；地点剧本没写
- 世界线：培育（倉本千奈）；制作人在制作的偶像：倉本千奈（剧本里没有直接说法）

## 发生了什么
她向制作人确认今天真的要买衣服吗；制作人说接到工作时会需要，又说倉本さん平时的衣服也很好看，也许那样也行（0001～0003）。她连忙说一定要买“工作服”，但坦白自己挑衣服一向全交给女仆（0004、0005）。制作人提议难得这次不靠女仆来选，她慌了（0006、0007）。之后是并列的几种回应：制作人说一个人不放心就一起选，她惊喜地拜托先生，说自己没有自信（0008～0011）；制作人说一开始不用选得好，先享受吧，她坦白其实自己一直想试着选衣服，说“我来选”（0012～0015）；她对制作人的某句话愣了一下，制作人说那样的话今天不买就来不及，她着急起来，催先生快走（0016～0019）。

## 她的关键台词
- 0001「あ、あのっ。／今日は本当にお洋服を……？」——对买衣服这件事半信半疑又期待
- 0004「いえっ！　ぜひともお仕事着／というものを！」——很想要“工作服”
- 0005「ですがわたくし、服選びは／メイドに任せきりでして……」——坦白自己从没自己挑过衣服
- 0007「ええっ！／で、ですが……」——被要求自己选时慌张
- 0010「先生……ぜひ、ぜひとも／よろしくお願いいたしますわっ！」——制作人愿意陪着就放心
- 0011「わたくし、自信がありませんし……」——承认没有自信
- 0014「お洋服、選んでみたかったのですわ！」——说出其实一直想自己挑衣服
- 0015「先生っ！／わたくし、選びますっ！」——被鼓励后下决心自己选
- 0018「そ、それは大変です！／一刻も早く選ばなければ！」——一听有期限就着急

## 行为模式
- 要做以前没自己做过的事 → 先慌，承认没有自信（0007、0011）
- 制作人说会陪着 → 立刻放心，郑重拜托（0008～0010）
- 被说“不用一开始就做好，先享受” → 说出藏着的愿望，下决心自己做（0012～0015）
- 听说有时间限制 → 着急，马上拉着制作人行动（0017～0019）

## 关系
- プロデューサー：她称「先生」（0010、0015、0019）；制作人叫她“倉本さん”（0003）。制作人夸她平时的衣服好看（0003）；她在制作人陪伴和鼓励下决定自己挑衣服（0010、0015）。
- メイド：她的衣服一向由女仆挑选（0005）。

## 档案类事实
- 挑衣服一向全交给女仆（0005）
- 其实一直想试试自己挑衣服（0014）
- 制作人说她平时的衣服也很好看（0003，制作人的说法）
