# 倉本千奈 培育事件 001 activity / 015 咖啡挑战（adv_pevent_001_kcna_activity_015）

- 她的台词：12 行（含用匿名标签说的 0 行）
- 出场的人：千奈（12 行）、プロデューサー（5）
- 场景：她刚喝了一口黑咖啡（0003）；地点和时间点剧本没写
- 世界线：培育（倉本千奈）；制作人在制作的偶像：倉本千奈（剧本里没有直接说法）

## 发生了什么
她喝了黑咖啡，苦得一脸痛苦，制作人心里想“这表情真厉害”（0001、0002，0002 是制作人的心里话）。制作人说喝咖啡还是黑的太乱来了，她承认，说是因为先生在喝，想知道是什么味道（0003～0005）。她反问先生为什么喝这么苦的东西，制作人说“因为苦”，她大吃一惊，问大人是不是都喜欢难受的东西（0006～0009）。之后是并列的回应：她先答应照制作人的话做，马上又说自己长大了也不可能喝得了，制作人说口味会变、也许会喜欢上，她说自己长大了一定也继续喝ミルクセーキ（0010～0013）；她担心喝不了这个是不是就成不了大人，制作人说喝不了的人也很多，她松了口气，说真的太苦了（0014～0017）。

## 她的关键台词
- 0001「うぅ～～～～～～～…………」——被苦到说不出话
- 0005「先生が飲んでいたので、／どのようなお味かと思ったのですが……」——因为制作人在喝，好奇地尝试
- 0006「先生こそ、なぜこのような／苦いものを？」——不理解大人的口味
- 0008「苦いから飲むのですか！？／苦しくはないのですか！？」——对“因为苦才喝”大为吃惊
- 0009「大人の方は……皆さん、／苦しいのがお好きなのですかっ！？」——把一件事推到“大人都这样”
- 0011「って、大人になっても／飲めるようになるとは思えませんわ！」——自己吐槽自己刚才的答应
- 0013「わたくし、きっと大人になっても／ミルクセーキを飲み続けますわ！」——坚持自己的口味
- 0014「これが飲めないと、／大人にはなれないのでしょうか。」——认真地担心“成为大人”的条件
- 0016「ほっ……よかった。」——被告知没关系就放心

## 行为模式
- 制作人在做的事 → 好奇，自己也想试试（0005）
- 遇到无法理解的大人习惯 → 夸张地吃惊，反问“大人都这样吗”（0008、0009）
- 先顺着答应，随即自己反驳自己（0010、0011）
- 担心自己不符合“大人”的标准 → 认真地问，得到否定后松口气（0014、0016）

## 关系
- プロデューサー：她称「先生」（0005、0006）；本篇制作人没有称呼她。她对制作人喝的东西感到好奇（0005），把制作人当作“大人”的代表来提问（0009、0014）。

## 档案类事实
- 喝不了黑咖啡，觉得非常苦（0001、0017）
- 喜欢喝ミルクセーキ，说长大了也会继续喝（0013）
