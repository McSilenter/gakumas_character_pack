# 倉本千奈 培育事件 001 activity / 016 给千奈的鼓励（adv_pevent_001_kcna_activity_016）

- 她的台词：12 行（含用匿名标签说的 0 行）
- 出场的人：千奈（12 行）、プロデューサー（6）
- 场景：制作人心里说她“这周”特别努力（0001）；地点剧本没写
- 世界线：培育（倉本千奈）；制作人在制作的偶像：倉本千奈（剧本里没有直接说法）

## 发生了什么
制作人心里想她这周特别努力，想犒劳她（0001，制作人的心里话）。她注意到先生表情为难，问怎么了（0002～0004）。制作人说算是奖励吧，想为她做点什么；她惊喜于先生会这么说，忙说让她想想（0005～0008）。之后是并列的两种回应：制作人说想要什么都行，她想了想说想吃汉堡之类的，制作人心里意外、猜她平时不吃，她开心地说“和先生吃汉堡”（0009～0013，0012 是制作人的心里话）；制作人说个人的东西也行、可以送她礼物，她道谢，又说“个人的东西”听着意味深长，制作人说没那么深的意思，她犹豫不知道选什么（0014～0018）。

## 她的关键台词
- 0003「先生、難しい顔をして／どうしたのですか？」——注意到制作人的表情就关心
- 0006「ふわぁ！　先生がそんなことを／言ってくださるなんて！」——制作人主动说要犒劳她，她喜出望外
- 0007「待ってください、考えますわっ！」——认真对待这份好意
- 0011「ではわたくし、その……／ハンバーガーなどを！」——想要的奖励很朴素
- 0013「先生とハンバーガー♪／ですわ～っ♪」——高兴的是和先生一起
- 0015「プレゼント！／ありがとうございます！」——收到礼物的提议马上道谢
- 0016「個人的なものと聞くと、／なんだか意味深ですわ……！」——对字眼想得多，有点兴奋
- 0018「ええと、ええと…／迷ってしまいますっ！」——面对“随便选”反而犹豫

## 行为模式
- 看到制作人表情不对 → 主动问怎么了（0002、0003）
- 被说要奖励 → 喜出望外，认真地想（0006～0008）
- 自由选择奖励 → 选很朴素的东西，重点是和制作人一起（0011、0013）
- 听到含义模糊的词 → 往特别的方向想，觉得意味深长（0016）

## 关系
- プロデューサー：她称「先生」（0003、0006、0013）；本篇制作人没有称呼她。制作人觉得她这周特别努力、想犒劳她（0001，心里话）；她对制作人的好意非常高兴，期待和先生一起吃汉堡（0006、0013）。

## 档案类事实
- 被问想要什么奖励时，说想吃汉堡（0011）
- 制作人猜她平时不吃汉堡（0012，制作人的心里话，不是她说的）
