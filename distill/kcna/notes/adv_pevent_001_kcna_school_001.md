# 倉本千奈 培育事件 001 school / 001 和千奈一起学习（adv_pevent_001_kcna_school_001）

- 她的台词：11 行（含用匿名标签说的 0 行）
- 出场的人：千奈（11 行）、あさり先生（8）、プロデューサー（6）
- 场景：あさり先生说明偶像也要学习、有考试，让制作人和她一起学习（0001～0003）；具体地点剧本没写
- 世界线：培育（倉本千奈）；制作人在制作的偶像：倉本千奈（剧本里没有直接说法）

## 发生了什么
あさり先生说偶像也要学习，要制作人别让偶像拿不及格，今天一起学习（0001～0003）。千奈打招呼后不好意思地说自己学习也很差，问该从哪里做起（0004～0006）。之后是并列的三段：制作人说一步一步来，她答应并问是不是从加法开始，あさり先生说可以从再往后一点的地方开始（0007～0012）；她听了什么后吃惊地说“可是我……”，制作人说确认要达到什么水平也重要，就像她作为偶像的目标是十王会長一样，她恍然大悟，说要挑战（0013～0018）；她说害怕看分数，制作人说看清实力才知道该怎么努力，她说既然先生这么说，自己也拿出勇气（0019～0025）。

## 她的关键台词
- 0005「といってもわたくし、／お恥ずかしながら……」——先不好意思地打预防针
- 0006「お勉強もダメダメですの。／なにからすればよいのでしょう。」——坦白学习差，马上问从哪里开始
- 0010「ではまずは足し算から、ですか？」——认真地把起点定到加法，看得出她对自己水平的估计很低
- 0013「ええっ！／ですがわたくし……」——听到什么后退缩
- 0017「なるほど、わかりました！／わたくし、挑戦します！」——一和偶像目标联系起来就转为要挑战（是表态）
- 0019「うぅ……点数を見るのが／怖いですわ。」——害怕面对分数
- 0022「先生がそこまでおっしゃるなら。」——因为是制作人说的才接受
- 0023「わたくしも勇気を出しますわ！」——说要拿出勇气（是表态）

## 行为模式
- 要开始自己不擅长的事 → 先坦白自己不行，同时问从哪里做起（0005、0006）
- 被告知一步一步来 → 马上答应，并把起点想得非常低（0009、0010）
- 对一件事退缩时，被和偶像目标联系起来 → 立刻想通，说要挑战（0013、0015～0017）
- 害怕面对结果 → 说出害怕，制作人讲明道理后，因为信制作人的话而鼓起勇气（0019～0023）

## 关系
- プロデューサー：她称「先生」（0022）；本篇制作人没有称呼她的姓名。制作人把学习和她的偶像目标联系起来，她就接受（0015～0017）；あさり先生评价制作人很会让人起劲（0018）。
- あさり先生：本篇没有明确称呼她的话（0004 的「先生」指谁见「不确定」）；あさり先生也没有称呼千奈的姓名。あさり先生负责讲解和评价，说要是能两人三脚地进行最好（0012）。
- 十王会長：只出现在制作人的话里，说是她作为偶像的目标（0015）；她本人这一篇没有提这个名字，听后是恍然大悟的反应（0016、0017）。
