# 倉本千奈 培育事件 001 school / 002 挑战的准备（adv_pevent_001_kcna_school_002）

- 她的台词：8 行（含用匿名标签说的 0 行）
- 出场的人：千奈（8 行）、あさり先生（10）、プロデューサー（8）
- 场景：あさり先生提出“制作人该怎么引导偶像”的题目，让两人商量（0001～0004）；具体地点剧本没写
- 世界线：培育（倉本千奈）；制作人在制作的偶像：倉本千奈（剧本里没有直接说法）

## 发生了什么
あさり先生说偶像之路狭窄险峻，没有准备很难前进，让制作人和千奈商量该怎么引导（0001～0004）。她说被这么一问自己完全不知道，请制作人告诉她需要什么准备（0005、0006）。之后是并列的三段：制作人说先打好基础，她理解成就是和平时一样，制作人肯定（0007～0012）；制作人问她的目标，她答要成为星南お姉さま那样的偶像，再问怎么才能成为，她答成为『一番星』，话到这里制作人接着说“那么为此……”，あさり先生接上要一步步积累（0013～0019）；制作人问她出道时想要什么舞台，她说闪闪发光、在童话般的舞台上笑着唱歌，制作人说朝那个形象前进，她答应（0020～0026）。

## 她的关键台词
- 0005「準備……言われてみると、／わたくしはさっぱり。」——被问才发现自己完全没想过
- 0006「どんな準備が必要なのでしょうか。／教えてくださいませ！」——不懂就直接请教
- 0009「それはつまり……いつも通り／ということですね！」——把“打基础”理解成和平时一样
- 0014「星南お姉さまのようなアイドルに／なることです！」——被问目标时的回答
- 0016「それは……『一番星』になる／ことですわ！」——她对“怎样才能成为星南那样”的回答
- 0021「どんなステージ……／キラキラ輝いていますわ。」——想象自己的舞台
- 0022「おとぎ話のような舞台で、／笑顔で歌っていますの！」——她想象中的出道舞台的具体样子

## 行为模式
- 被问到没想过的问题 → 老实说不知道，请对方教（0005、0006）
- 听到抽象的建议 → 用自己的话归纳一下确认（0009）
- 被问目标 → 立刻答出星南，再被追问时答『一番星』（0014、0016）
- 被问想要的舞台 → 用现在进行的语气描述脑中的画面（0021、0022）

## 关系
- プロデューサー：本篇她没有叫出称呼，但向制作人请教（0006）；制作人叫她「倉本さん」（0013）。
- 星南：她叫「星南お姉さま」（0014），是她想成为的偶像；制作人接话时说的是「生徒会長」（0015）。
- あさり先生：本篇没有和她直接对答；あさり先生叫她「倉本さん」，说这种方针也许最适合精力充沛的她，还说自己眼前也浮现出那幅光景（0025、0026）。

## 档案类事实

- 她想象中的出道舞台：闪闪发光，在童话般的舞台上笑着唱歌（0021、0022）
