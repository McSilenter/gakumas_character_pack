# 倉本千奈 培育事件 001 school / 008 生日的悖论（adv_pevent_001_kcna_school_008）

- 她的台词：10 行（含用匿名标签说的 0 行；0005、0006、0011、0012、0017、0018、0023、0024 是括号里的心里话，没有说出口，说出口的只有 0004、0016）
- 出场的人：数学教師（14 行）、千奈（10）
- 场景：数学课上，老师讲悖论，点她回答 30 人的班里有两人同一天生日的概率（0001～0003）；具体地点剧本没写
- 世界线：培育（倉本千奈）；制作人在制作的偶像：倉本千奈（剧本里没有直接说法）

## 发生了什么
数学老师点她回答生日问题，她愣住，心里觉得同一天生日应该很少见，又想起先生好像说过什么，在心里喊先生（0001～0006）。之后的答案不在剧本里，是并列的三段：答对了，老师讲悖论，她心里想完全不明白为什么，但运气好（0007～0012）；答错，老师说答案约七成，并说可以用余事象来解，她念出这个词问是什么，心里想之后要问先生，下次不要错（0013～0018）；有人答了约 0 成，老师愣了一下后说答案是约七成，她心里想完全不明白老师在说什么，得更努力（0019～0024）。

## 她的关键台词
- 0004「……え？／えっと……」——被点名时的反应
- 0005「（お誕生日が同じだなんて、／　珍しいように思いますけれど……）」——心里话：她的直觉
- 0006「（先生がなにか言っていたかも／　しれません！　先生っ！）」——心里话：答不出时想到先生
- 0011「（どうしてそうなるのか、／　全然わかりませんが……）」——心里话：答对了也不明白
- 0012「（運がよかった！　ですわ！）」——心里话：把答对归为运气
- 0016「よじしょうとはいったい……」——听到术语念出来，写成平假名
- 0017「（これはあとで、先生に／　お聞きしなければっ！）」——心里话：不懂的打算之后问先生（是打算）
- 0018「（次は間違えないように、／　しっかり覚えましょう！）」——心里话：下决心记住
- 0023「（……なにを言ってるか／　全然わかりませんわ！）」——心里话：跟不上课
- 0024「（わたくし、もっと／　がんばらなければ……！）」——心里话：跟不上时的结论是要更努力

## 行为模式
- 课堂被点名答不出 → 表面只应一声，心里想起先生（0004～0006）
- 答对但不明白 → 不勉强弄懂，开心地当成运气好（0011、0012）
- 碰到不懂的词 → 打算之后问先生，并决心下次不错（0016～0018）
- 听不懂 → 不责怪别人，把话落到自己要更努力（0023、0024）

## 关系
- 数学教師：叫她「倉本」（0002）；本篇她没有称呼老师。
- 先生（大概是制作人）：她答不上来时在心里想到（0006），打算有不懂的去问（0017）。

## 档案类事实
- 课上听不懂时打算之后问先生（0017，是打算）

## 不确定

- 0016 把老师 0015 说的余事象写成平假名，是否表示她不认识这个词，只能从上下文推。
