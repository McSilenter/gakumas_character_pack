# 倉本千奈 培育事件 003 activity / 021 家庭餐厅大满足（adv_pevent_003_kcna_activity_021）

- 她的台词：17 行（含用匿名标签说的 0 行）
- 出场的人：千奈（17 行）、プロデューサー（2）
- 场景：ファミレス店内（0001）
- 世界线：培育（倉本千奈）；制作人在制作的偶像：倉本千奈（剧本里没有直接说法）

## 发生了什么
她得意地说知道这种店叫ファミレス，制作人说以为她不熟悉，她说其实和生徒会的大家来过，所以点菜也能自己来（0001～0004）。结果说菜单太多，问先生有什么推荐（0005）。之后是并列的三段：推荐ドリンクバー，她说自己也很喜欢，能边喝边和朋友聊天，说今天和先生一起愉快地聊（0006～0009）；她说这提议很棒，决定点オムライス，制作人问选哪种，她又定不下来（0010～0014）；看到巨大パフェ，她很在意，又担心吃不完，马上说不能挑战前就退缩，要挑战（0015～0019）。

- 0004「ですので、注文もひとりで……！」——想自己点菜（话没说完）
- 0005「うぅ、メニューが多いですわ……／先生のおすすめをうかがっても……？」——刚说完能自己来，马上求助
- 0006「ドリンクバー！／わたくしも大好きですわ！」——对ドリンクバー的喜欢
- 0008「ふふっ、こんな素晴らしいメニューを／先生と一緒に楽しめるなんて！」——高兴的是能和先生一起
- 0011「決めました……わたくし、／オムライスを注文いたします！」——下了决心
- 0014「うう……今度は、どれに／するか決められませんわ～～！」——刚决定完，又被种类难住
- 0018「……いえっ、挑戦する前から／ひるんでいてはいけませんわねっ！」——自己给自己打气
- 0019「わたくし、挑戦してみますわ！／この巨大パフェに……！」——把吃パフェ说成挑战（是打算）

## 行为模式
- 知道这类店的说法、来过这类店 → 得意地说出来（0001、0003）
- 说要自己来 → 碰到难处马上向制作人求助（0004、0005）
- 选择太多 → 定不下来（0013、0014）
- 面对量大的东西 → 先担心，随即对自己说不能退缩，决定挑战（0017～0019）

## 关系
- プロデューサー：她称「先生」（0005、0008、0009）；制作人叫她「倉本さん」，说以为她不熟悉这种店（0002）。她说能和先生一起享受很高兴（0008），约今天愉快地聊天（0009）。
- 生徒会の皆さん：她说和大家一起来过ファミレス（0003）。

## 档案类事实
