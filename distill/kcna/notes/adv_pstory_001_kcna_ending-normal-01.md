# 倉本千奈 培育剧情 001 / ending-normal-01 【A End】为了实现梦想（adv_pstory_001_kcna_ending-normal-01）

- 她的台词：27 行（含用匿名标签说的 0 行）
- 出场的人：千奈（27 行）、プロデューサー（14）、倉本家のメイド（1）
- 场景：千奈完全休息的日子，制作人应邀来见她，倉本家のメイド也在场（0002、0005、0008）；具体地点没有明说
- 世界线：培育（倉本千奈）；制作人在制作的偶像：倉本千奈（她说自己是制作人的担当偶像，0030；制作人说“今后也请多关照”，0040）

## 发生了什么
制作人听说有重要的事来见千奈，她却发现倉本家のメイド没把详情转告，害羞地说应该一开始就自己说（0001～0007）。她说今天完全休息，想和制作人不谈工作地见面；之后她高兴地说欢迎的准备已经万全（0008～0011）。制作人说很少有人想在工作之外见制作人，她说因为制作人是她的恩师、是她最喜欢的人（0012、0013）。制作人不知道工作之外聊什么，提议边看最新顶级偶像的影像边解说，被她喊着请远离工作（0015～0020）。她问制作人为什么进这所学园，制作人说是为了实现亲手培养顶级偶像的梦想；她说这是美好的梦想，但又说担当偶像是自己的话只会离梦想更远，要道歉（0021～0031）。制作人说入学时的她确实配得上最后一名，但现在想想，为了实现梦想，自己做了不坏的选择；她惊讶地追问这是不是在大大地夸她，制作人用“今后也请多关照”带过，她应了一半又抗议别糊弄过去（0032～0042）。

## 行为模式
- 想私下邀请制作人 → 因为害羞托人转达，结果没传到，事后反省应该自己说（0004、0006、0007）
- 制作人把话题拉回工作 → 喊着请他离开工作（0019、0020）
- 听到制作人的梦想 → 先肯定，再联想到自己实力不足，为拖累对方道歉（0027～0031）
- 被间接夸奖 → 惊讶地追问确认；对方岔开时，先习惯性地应下，再反应过来抗议（0038、0039、0041、0042）
