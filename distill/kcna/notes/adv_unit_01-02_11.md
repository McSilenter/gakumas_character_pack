# 主线 第1部 2章 偶像们的共同生活 / 2章11话（adv_unit_01-02_11）

- 她的台词：21 行（含用匿名标签说的 0 行）；其中 0059、0060 是喝饮料时的声音（呛咽、啜泣），没有成句的话
- 出场的人：千奈、手毬、咲季、ことね
- 场景：晨间自主训练后的训练场地，千奈也在自主训练；咲季、手毬、ことね在做冷身运动。
- 世界线：kcna:主线（第1部）；制作人在制作的偶像：看不出（千奈在这一话里是路过的人，不是被制作人制作的人）

## 发生了什么
千奈被手毬叫住，手毬问她是不是来自主训练，她说想稍微追上大家，却发现自己被几人围住，以为要被抢钱。手毬说只是想让她试喝东西，千奈见饮料闪闪发光很漂亮，听咲季说能滋养强身、消除疲劳、增强训练效果，就很感动地说"可以真的喝吗"，喝下后又咳又哭，最后说是充满干劲的味道，甚至想每天早上喝；咲季要从明天起也带她一份，她脸色发白，但还是请求拜托。

## 她的关键台词
- 0041「ひゃいっ！？」——被手毬突然叫住时的惊慌
- 0043「そ、そうですわっ！」——被问是否自主训练，慌忙回答，句尾用「わ」
- 0044「皆さんに少しでも追いつこうと思い……まし、て？」——说出自己自主训练的动机：想追上大家
- 0045「……なっ、なぜわたくし囲まれていますの！？」——发现被围住，自称「わたくし」
- 0046「お、お財布は持っていませんわっ。」——误以为是被勒索
- 0050「ふわぁ……きらきらしてキレイな飲み物ですわね～？」——对饮料外观的天真反应
- 0055「の、飲むだけでそんなにすごい効果が……ごくっ。」——被效果说服
- 0056「ほんとに、いただいてしまってよろしいの？」——客气地确认
- 0058「それでは遠慮なく――いただきますわッ！」——下决心一口喝下
- 0066「と、とっても……気合いが入るお味でしたわ。」——喝完后勉强用好话评价
- 0067「叶うならば、毎朝飲みたいくらいに！」——为了保住对方的面子甚至说想每天喝
- 0069「いいえ！　いいえっ！　これで効果があるならばっ！」——ことね说别勉强时，用效果为理由否认
- 0076「お、お願いしますぅぅ～～～～～っ！！」——被告知明天也有一份，脸色发白后仍说拜托

## 行为模式
- 被陌生的几个人围住 → 先往被抢劫上想，慌忙交出"没带钱包"（0045、0046）
- 听到对自己有训练效果的话 → 立刻被说服，客气地确认后一口喝下（0055～0058）
- 东西难以下咽 → 不当面说难喝，勉强说成"有干劲的味道"，甚至说想每天喝（0064～0067）
- 被劝别勉强 → 以"如果真有效果"的理由坚持不肯承认（0068、0069）
- 被好意追加 → 脸色发白，但仍然接受（0073～0076）

## 关系
- 手毬：被手毬叫成"2組の倉本さん"（0042，手毬的话），对手毬的提问有问必答
- 咲季：她接受咲季的饮料，咲季说明天也给她一份，她接受（0072、0076）
- ことね：ことね劝她"無理すんなよ"（0068），她拒绝（0069）

## 档案类事实
- 在2组，姓倉本（手毬的叫法，0042，手毬自己带着疑问「だっけ？」）
- 早上也在自主训练，目的是追上大家（0043、0044）
- 说话用「わたくし」「ですわ」「ますの」（0045、0050、0051）

## 不确定
- 0059、0060 只是喝饮料时的声音，没有成句的话，算她的台词。
- 0066～0067 是真的觉得有效，还是为了咲季的面子，剧本没有直接说明。
