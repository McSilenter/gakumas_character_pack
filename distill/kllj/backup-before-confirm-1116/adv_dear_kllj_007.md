# 葛城リーリヤ 亲爱度剧情 / 第7话（adv_dear_kllj_007）

- 她的台词：33 行（含用匿名标签说的 0 行）；其中 0030～0034 是回想（和第1话 0024～0025、第6话 0040～0042 的台词相同），插在清夏和制作人对话之间，不是这一场里她当面说的
- 出场的人：リーリヤ、清夏、プロデューサー
- 场景：人前练习的レッスン，制作人按她的提议请清夏来看她唱歌（0002～0005、0036～0039）；剧本里没有写地点和时间
- 世界线：亲爱度（葛城リーリヤ）；制作人在制作的偶像：葛城リーリヤ（0042「プロデューサーとして実感しています」，说的是她）

## 发生了什么
清夏应制作人邀请来看レッスン，发现唱歌的是她；她说因为想当偶像在努力，还不能像清夏那样唱得好，但想让清夏看看现在的自己，所以拜托了制作人（0006～0013）。她问清夏是不是已经不想当偶像了，清夏说也不是，只是对自己有点难，但喜欢偶像没变、会以朋友身份支持她（0015～0019）。她去准备时，清夏对制作人说自己不认真、没法像她那么投入；中间插入她以前对制作人说的话：邀请她一起当偶像的朋友是唯一无二的挚友，想让清夏看到现在的自己（0024～0034）。她唱完问清夏怎么样，清夏和制作人都夸她；她说有了一点自信、多亏制作人和清夏，被指出有失误后说下次要唱得更好（0048～0055）。清夏说她和以前判若两人，她说自己没才能，但制作人推着她，一点点往前；又谢谢清夏来，说明白了“想传达”的心意才是重要的，对制作人说已经没问题了（0058～0068）。她对清夏说没有放弃「約束」，清夏说不记得是什么约定、随即离开；她对制作人说相信清夏，又说自己和清夏的才能没法比，要在清夏回来之前追上一点（0072～0083）。剧情经过参照 ssmk 笔记。

## 她的关键台词
- 0008「……うん。／わたしが歌うんだ。」——对清夏用平语（对制作人一直用敬语）
- 0010「――うん。／アイドルに、なりたいから。」——向清夏表明自己的动机
- 0012「まだまだ、清夏ちゃんみたいに／上手にはできないけど……」——把清夏当作比自己强的人
- 0015「……清夏ちゃんは、やっぱり、／もうアイドルになる気はないの？」——试探清夏是否放弃偶像
- 0047「はいっ！　見ててね、清夏ちゃん。／葛城リーリヤ、歌います……！」——和上一次人前演唱（第5话 0060）对比，这次不再结巴到失措
- 0051「ほ、ほんとに？　よかったぁ……。／ちゃんと、歌えたんだ。」——成功后的安心
- 0052「ちょっとだけ、自信がつきました。／センパイと、清夏ちゃんのおかげです。」——把成果归于别人
- 0060「……わたしに、才能はないけど、／センパイが背中を押してくれるから、／ちょっとずつ前に進んでいけるんだ。」——对清夏说制作人的作用
- 0065「……届けたいっていう想いが、／大事なんだって、分かったんだ。」——这一话学到的东西
- 0072「……清夏ちゃん、わたし、／――約束、諦めてないから。」——两人之间的「約束」
- 0078「……はい。大丈夫です。／わたしは、清夏ちゃんを信じてるので。」——清夏回避后仍说相信
- 0080「清夏ちゃんと、わたしの才能は／……比べ物にならないから。」——认为清夏才能远在自己之上
- 0081「清夏ちゃんが戻ってくるまでに、／少しでも追い付かないと。」——认为清夏会回来、自己要先追上

## 行为模式
- 对清夏说话 → 用平语、叫「清夏ちゃん」；对制作人用敬语（0008、0013、0052）
- 想知道清夏的真实想法 → 直接但小心地问（「やっぱり」0015），听到含糊的回答没有追问，只说「見ててね」（0020）
- 唱完 → 先问对方的感想（0048），被夸后安心、归功于制作人和清夏（0051～0052）；被指出失误就承认并定下次的目标（0054～0055）
- 被夸变了 → 说自己还不成熟、没才能，把进步归于制作人推着自己（0059～0060）
- 清夏对「約束」装作不记得 → 当场沉默（0074），之后对制作人说相信清夏，转而要求自己更努力（0078～0081）

## 关系
- 清夏：她叫「清夏ちゃん」，用平语；清夏叫她「リーリヤ」。她说清夏唱得比自己好（0012）、才能远在自己之上（0080），想让清夏看到现在的自己（0013）。她对清夏说没有放弃「約束」，清夏说不记得（0072～0073）；她说相信清夏、要在清夏“回来”之前追上（0078、0081）。回想中说清夏是邀请她一起当偶像的唯一无二的挚友（0030～0034）
- プロデューサー：叫「センパイ」，用敬语；对清夏说制作人推着自己前进（0060）。制作人叫她「葛城さん」，对清夏说她是了不起的人（0042）

## 档案类事实
- 和清夏之间有一个「約束」，她说没有放弃（0072）；内容这一话没有说
- 认为清夏唱得比自己好（0012）、两人才能没法比（0080）
- 清夏说她容易怯场（「あがり症」，0037，清夏说的）
- 在清夏面前唱完，制作人说表演很棒，但有几处失误（0050、0053）
- 她说“想要传达”的心意是重要的（0065），对制作人说人前已经没问题了（0068）

## 不确定
- 0030～0034 是回想，台词与第1话 0024～0025、第6话 0040～0042 相同，是插在清夏和制作人对话之间的旁白式回放；按标签计入行数，但不是这一场里她当面说的话。
- 0078 和 0079 之间制作人的话没有写出（0079「……そうですね。」接的是制作人没写出的话），可能是选项。
- 0073 清夏说不记得「約束」，是真的忘了还是装作忘了，剧本没有说；她 0074 沉默、0078 说相信清夏。
- 0081「清夏ちゃんが戻ってくるまでに」——“回来”指回到偶像这条路，是按上下文读的，剧本没有明说。
- 0084～0085 是制作人的独白（没有括号）。
