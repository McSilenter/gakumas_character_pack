# 葛城リーリヤ 亲爱度剧情 / 第10话（adv_dear_kllj_010）

- 她的台词：44 行（含用匿名标签说的 0 行）
- 出场的人：リーリヤ、清夏、プロデューサー
- 场景：首场 live 的第二天（0003「昨日のライブ」），本来定为休息日，她在练习时制作人来了，之后清夏来找她（0001～0002、0016）；具体地点没有写
- 世界线：亲爱度（葛城リーリヤ）；制作人在制作的偶像：葛城リーリヤ（0077「わたしを選んでくれて」、0087 制作人说目标是顶级偶像）

## 发生了什么
休息日她忍不住来练习，说想趁还记得昨天 live 的感觉多练，保证不会像上次那样勉强（0001～0006）。她说 live 很开心、兴奋还没平息，想再站上那个舞台、下次唱得跳得更好，休息时脑子里也全是这些，回过神来已经在练了（0010～0014）。清夏来找她，夸 live 很棒；她说在台上找过、看到了清夏，还问清夏最后是不是哭了（0016～0030）。清夏说看了她的 live 还是放不下偶像，想站在她身旁飞得更高，并为之前假装不记得「約束」道歉，说其实记得但没有重新努力的勇气；她说明白、因为一直相信清夏（0032～0041）。她说自己的歌能改变别人，感谢清夏邀请自己当偶像，说是清夏牵着手、制作人推着背自己才到这里，所以清夏停下时她想这次轮到自己伸出手；她邀请清夏两人一起当偶像，两人重新说定「約束」（0046～0060）。清夏留下慰问品离开后，她对制作人说会一步步努力，感谢他选了自己、在黑暗中为迷路的自己引路，并宣言要成为顶级偶像（0071～0089）。剧情经过参照 ssmk 笔记。

## 她的关键台词
- 0003「昨日のライブの感覚を忘れないうちに、／もっと練習したかったんです。」——休息日也来练
- 0010「……ライブが、楽しかったんです。」——首场 live 的感受
- 0011「だから、興奮が収まらなくて。／あのステージに、もう1回立ちたい。」——想再上台
- 0024「探してたから。／清夏ちゃん、いないかなって。」——在台上找清夏
- 0026「気のせいだったら恥ずかしいけど、／最後の方、ちょっと泣いてなかった？」——会温和地点破清夏
- 0041「……うん、分かってる。／清夏ちゃんのこと、信じてたから。」——对清夏的信任
- 0047「まだまだ、未熟だけど……／わたしの歌は、誰かを変えられるんだ。」——第一次肯定自己歌声的力量
- 0050「……ありがとう、清夏ちゃん。／わたしを、アイドルに誘ってくれて。」——确认清夏是邀请她当偶像的人
- 0052「清夏ちゃんが手を引いてくれて、／センパイが背中を押してくれたから、」——两人在她心里的位置
- 0055「今度はわたしが、あなたに……／手を差し伸べるんだって。」——从被拉的一方变成伸手的一方
- 0057「――ねぇ、清夏ちゃん。／ふたりで一緒に、アイドルになろう？」——反过来邀请清夏，重复第1话里清夏当初的邀请
- 0059「――約束。」——重新约定
- 0078「どう頑張ればいいのかも分からなくて、／暗闇の中で迷子だったわたしを――」——回顾遇到制作人之前
- 0079「――センパイが、導いてくれました。／センパイがいる方に光が見えたんです。」——对制作人的感情
- 0089「わたしは、トップアイドルになります！」——第4话还对“顶级偶像”退缩，这次主动宣言

## 行为模式
- 被发现休息日偷偷练 → 道歉，但说明理由，保证不过度（0002～0006）
- 心里兴奋时 → 停不下来，回过神已在练（0013～0014）
- 对清夏 → 坦率说出“在找你”（0024），会笑着点破清夏哭了（0026）；清夏道歉时不责怪，说一直相信（0041）
- 朋友停下脚步时 → 认为这次轮到自己伸手，主动邀请（0054～0057）
- 对制作人道谢 → 郑重而夸张地说“在黑暗中看见光”（0078～0079）；被说夸张也坚持感谢（0082）
- 有人支持时 → 敢于说出更大的目标（0088～0089）

## 关系
- 清夏：她叫「清夏ちゃん」，平语，也称「あなた」（0055）；清夏叫她「リーリヤ」。她明确说是清夏邀请自己当偶像（0050）、清夏牵着她的手（0052）。清夏为假装忘了「約束」道歉，她说一直相信清夏（0038～0041）；她反过来邀请清夏一起当偶像，两人重新约定（0057～0060）
- プロデューサー：叫「センパイ」；感谢他选了自己、引导迷路的自己（0077～0079），说因为有他支持才能前进（0076）。制作人叫她「葛城さん」，说她才是自己的光（0080）

## 档案类事实
- 首场 live 很开心，想再上台、唱得跳得更好（0010～0012）
- 休息日也忍不住来练习（0001～0003、0014）
- live 当天回去后一放松就马上……（0020，话没说完，清夏说她回房时她已经睡了 0019）
- 邀请她当偶像的是清夏（0050）
- 遇到制作人之前不知道该怎么努力，像在黑暗中迷路（0078）
- 和清夏重新约定“两人一起当偶像”（0057～0060）
- 目标：顶级偶像（0089）

## 不确定
- 0005～0008：0006 保证不会过度练习，0007 道谢、0008「ほ、本当ですか？」之间制作人的话没有写出，可能是对不同选项的并列反应。
- 0019 清夏说“昨天回房间（她）已经睡了，醒来时（她）已经出门了”，两人是否同住一间宿舍，剧本没有直说。
- 0020「帰ったら／気が抜けちゃって、すぐ……。」话没说完，按 0019 读作“马上睡着了”。
- 0050 说是清夏邀请她当偶像，和第1话 0024～0026“被朋友邀请”一致；第1话没有说出朋友的名字。
