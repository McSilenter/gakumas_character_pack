# 葛城リーリヤ 亲爱度剧情 / 第16话（adv_dear_kllj_016）

- 她的台词：10 行（含用匿名标签说的 0 行）
- 出场的人：リーリヤ、プロデューサー
- 场景：「特別公開オーディション」（0011）合格之后，和下一场 live 上场前（0009、0018）；剧本里没有写地点和时间
- 世界线：亲爱度（葛城リーリヤ）；制作人在制作的偶像：葛城リーリヤ（0002 制作人祝贺她合格，0011～0014 为她的 live 做准备）

## 发生了什么
她跑来告诉制作人「やりました」，制作人祝贺她オーディション合格、表演出色（0001～0002）。她说好像发挥出了超过平时的力量，一定是粉丝的应援，当然也有センパイ；制作人说她能把粉丝的应援变成自己的力量（0003～0007）。制作人说合格后接下来是 live，她说开始紧张了（0008～0010）。制作人说要把从粉丝那里得到的力量化作感谢传达出去，她说要把现在能做到的最好的表演献给大家，喊着「葛城リーリヤ、行きます！」出发（0011～0018）。

## 她的关键台词
- 0001「センパイ……！／や、やりました……！」——合格后第一句
- 0003「なんだか……いつもの自分以上の／力を発揮したような気がします……。」——表现超出平时
- 0004「きっと……ファンのみんなが、／応援してくれたおかげです。」——归功于粉丝
- 0005「……もちろん、センパイも。」——补上制作人
- 0010「そ、そうですよね……。／本番……緊張してきました……。」——一想到正式演出仍紧张
- 0016「今のわたしにできる、最高の／パフォーマンスを、みんなに……！」——对粉丝的回报
- 0018「頑張ります……！／葛城リーリヤ、行きます！」——上场前的口号

## 行为模式
- 成功之后 → 先跑去告诉制作人（0001），把成绩归于粉丝和制作人（0004～0005）
- 想到下一场正式演出 → 立刻紧张（0010）；被提醒要“传达感谢”后转为积极（0013～0016）

## 关系
- プロデューサー：叫「センパイ」；把成功的功劳也分给他（0005）。制作人叫她「葛城さん」，说她能把粉丝的应援变成力量（0006）
- ファン：她说今天特别感到从大家那里得到了力量（0007），要用最好的表演回报（0016）

## 档案类事实
- 通过了「特別公開オーディション」（0002、0011）
- 合格后接下来是 live（0009，制作人说的）
- 能把粉丝的应援变成自己的力量（0006，制作人说的；她在 0007 认同）

- 0018 之后的 live 本身这一话没有写。
