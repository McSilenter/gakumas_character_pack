# 葛城リーリヤ 亲爱度剧情 / 第17话（adv_dear_kllj_017）

- 她的台词：25 行（含用匿名标签说的 0 行）
- 出场的人：リーリヤ、四音、プロデューサー
- 场景：live 结束后她回到制作人身边（0002～0004），随后四音出现（0012）；剧本里没有写地点和时间
- 世界线：亲爱度（葛城リーリヤ）；制作人在制作的偶像：葛城リーリヤ（0031 四音问制作人为什么选她，0034～0035、0044 制作人维护她）

## 发生了什么
live 结束，她回来说很累但尽力了；演出后她向大家说了谢谢，结果收到了更多的谢谢，很惊讶（0001～0011）。四音出现，她认出是“那时候的”人；四音说她还不放弃、可怜地抓着不放，她说不服输是自己的长处（0012～0016）。四音问她的自信从哪来，她说是センパイ和粉丝给的；四音说努力是白费、难道以为不放弃梦想就会实现，她说不是认为会实现，而是决定了跑到实现为止，自己已不再迷茫、不会被对方的话牵着走（0018～0029）。四音又说制作人没眼光，她一惊，制作人说“最后笑就行”；她于是说要成为顶级偶像，不管花多少年，证明センパイ选的偶像能闪耀（0030～0040）。制作人请四音离开、说不许再侮辱她，四音说下次见面会让她见识现实后离开（0042～0046）。她问下一个是不是『FINALE』，制作人说四音（極月学園 1 年级）也会出场，实力和人气都是真的；她说即使这样也不想输给只会往下看的人（0049～0054）。

## 她的关键台词
- 0006「ライブが終わった後に、みんなに、／ありがとうって言いました。」——兑现第15、16话“传达感谢”
- 0008「そうしたら、もっとたくさんの／ありがとうが……返ってきました。」——收到的回应
- 0016「……諦めの悪さが、取り柄ですから。」——对四音的回答，把“不服输”当长处
- 0019「……この自信は、センパイと、／ファンのみんながくれたものです。」——自信的来源
- 0021「……無駄なんかじゃ、ないです。」——不再只是道歉，开始反驳
- 0023「叶うと思っているわけじゃ、／ありません……。」——不说空话
- 0025「夢を叶えるまで走り続けると、／決めているからです。」——她的立场
- 0028「わたしは、もう迷いません。」——对第12话的回应
- 0029「あなたの言葉に、／振り回されたりもしない。」——对四音明确表态
- 0039「何年かかったとしても、いつか……／トップアイドルになって、証明します。」——长期的决心
- 0040「センパイが選んだアイドルは、／ちゃんと輝けるんだってことを！」——要证明的是制作人的眼光（呼应第14话 0052）
- 0054「下ばかり見ているような人に、／負けたく、ない……！」——对四音的评价和斗志

## 行为模式
- 演出后 → 汇报“累但尽力了”，对观众的回应感到惊讶、「えへへ」高兴（0005～0011）
- 再被四音贬低自己 → 不再道歉，平静地反驳，说清楚自己的理由（0016～0029）
- 被问“以为不放弃就能实现吗” → 不夸口，先否认，再说明自己的决定（0023、0025）
- 制作人再被贬低 → 先一惊（0033），被制作人安抚后不和对方争吵，转为宣言要用结果证明（0036～0040）
- 得知强敌 → 承认对方强，但说不想输（0053～0054）

## 关系
- 四音：她认出是「あの時の」人（0013），用敬语回应，称对方「あなた」（0029）。这一次她反驳四音、宣言要证明，说不想输给只往下看的人（0021～0029、0039～0040、0054）
- プロデューサー：叫「センパイ」，说自信来自他和粉丝（0019）；制作人叫她「葛城さん」，说“最后笑就行”（0035），对四音说不许再侮辱她（0044）
- ファン：live 后她向大家道谢，收到更多的谢谢（0006～0008）

## 档案类事实
- 这次 live 后向观众说了谢谢，收到更多感谢（0006～0008）
- 自称不服输（「諦めの悪さ」）是长处（0016）
- 自信来自制作人和粉丝（0019）
- 下一个参加的是『FINALE』（0049～0050）
- 白草四音是極月学園 1 年级，实力和人气都是真的，会参加『FINALE』（0050～0052，制作人说的）
- 决心不管多少年也要成为顶级偶像（0039）
