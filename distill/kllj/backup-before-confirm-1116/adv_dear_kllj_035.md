# 葛城リーリヤ 亲爱度剧情 / 第35话（adv_dear_kllj_035）

- 她的台词：40 行（含用匿名标签说的 0 行）；其中 0016～0017 是她转述朋友当年邀她的话
- 出场的人：リーリヤ、プロデューサー、清夏；另有「一同」2 行（0033、0065）
- 场景：『H.I.F』本战，她在找控え室（0001～0004），之后与清夏一起在正式上场前（制作人 0032「いよいよ本番ですね」）
- 世界线：亲爱度（葛城リーリヤ）；制作人在制作的偶像：葛城リーリヤ（0030 她说「これからもセンパイがわたしを／プロデュースしてくれるなら」）

## 发生了什么
她找不到控え室，センパイ问“有困难吗”并带她去，她说像第一次见面时一样，制作人说那时目的地是礼拜室（0001～0008）。制作人心里觉得她果然紧张（制作人心里话 0010），于是问她为什么来这所学园；她回答朋友邀她一起当偶像、一起上偶像学校，她没自信本想拒绝，但和朋友在这所学园看了一场ライブ，觉得很棒、想变成那样，所以现在在这里，要成为偶像和朋友一起挑战『H.I.F』（0011～0025）。制作人说她一定能赢，并说“请允许我再说一遍”，她回答「はい」，说如果センパイ今后继续制作她，她就会成为『一番星』（0026～0031）。上场前，她说终于有了实感：一开始什么都不会的自己，现在站在清夏身边，为约定一起奔跑，又作为对等的劲敌争『一番星』，这让她很高兴（0032～0038）。她说心在怦怦跳，但这是梦寐以求的舞台，想好好享受；制作人提起以前说过的“偶像最需要的才能”，她接上“拥有强烈的意志”（0039～0047）。她说起初没能完全相信センパイ的话，一直觉得自己哪有什么才能，但现在相信センパイ，是センパイ告诉她“她是偶像的天才”（0050～0053）。清夏说自己曾逃避受伤的创伤，是看了她的ライブ才想再努力（清夏 0056～0062）。最后她宣言要优胜兑现约定、成为那天憧憬的偶像、并赢过清夏成为『一番星』，清夏说『一番星』是自己的，两人说“一决胜负”“一起创造奇迹”（0066～0074）。剧情经过参照 ssmk 笔记。

## 行为模式
- 紧张时 → 话少、沉默（0009、0014；制作人心里话 0010）；被问起初心时，一句句慢慢说出来（0015～0025）
- 被制作人重复初见时的话 → 用当年的答案回应，但这次加上了现在的目标（0025、0031）
- 上场前 → 承认心在怦怦跳，但把它说成想享受的舞台（0040、0044）
- 制作人起个头 → 她接下去说出制作人教过的话（0047）
- 谈到才能 → 承认以前一直否定自己，现在因为相信センパイ而说自己是“偶像的天才”（0050～0053）
- 对最亲近的搭档 → 也明确说要赢过对方（0068、0071）

## 关系
- 制作人：叫「センパイ」（0003、0030、0052），用敬语；制作人叫她「葛城さん」（制作人 0013、0028），称「あなた」（制作人 0026、0048），自称「俺」（制作人 0064）。她说现在的情景像和センパイ初见时（0007）；以“センパイ继续制作她”为条件宣言成为『一番星』（0030～0031）；说起初没能完全相信センパイ的话，现在相信（0050～0052）
- 清夏：叫「清夏ちゃん」（0035、0068、0074）；清夏叫她「リーリヤ」（清夏 0057、0073）。“朋友”邀她一起当偶像、一起上偶像学校，一起看了这所学园的ライブ（0015～0020，未点名）；现在站在清夏身边、一起为约定奔跑、又是对等的劲敌（0035～0037）；宣言要赢过清夏成为『一番星』（0068）。清夏说是看了她的ライブ才想再努力（清夏 0059）

## 档案类事实
- 和制作人初见时她在找礼拜室（制作人 0008；她 0007 说像那时）
- 来初星学园的经过：朋友邀她两人一起当偶像、一起上偶像学校；她没自信本想拒绝，和朋友一起在这所学园看了一场ライブ后想变成那样（0015～0023）
- 当偶像的目标包括“成为那天憧憬的偶像”（0067）
- 她说一开始什么都不会（0035），一直觉得自己没有才能（0051）；现在说センパイ告诉她她是偶像的天才（0053）
- 制作人以前对她说过偶像最需要的才能是“拥有强烈的意志”（0045～0047）
- 清夏有受伤的创伤，曾逃避；看了她的ライブ才想再努力，靠她和制作人帮忙能跳了（清夏 0056～0061）

## 不确定
- 「一同」0033「ばっちりです！」、0065「はい！」不计入她的台词；从上下文看是她和清夏一起回应制作人（0032、0064），待统一判定。
- 0011～0031 的问答与第1话（adv_dear_kllj_001）0003、0008、0023～0032、0058 前后几乎一样（找路、被问为何来学园、她的回答、制作人说“葛城さん”后她答应），像是两人有意重演初见的对话；0028「改めて申し上げます」后制作人具体要说的话没写，0029 她直接答「はい」。
- 0015～0025 的「友達」没点名；按第29话、第33话的内容应是清夏，这是对照别的篇目的推测。
- 清夏 0061「ふたり」按上下文指她和制作人（照 ssmk 笔记）。
