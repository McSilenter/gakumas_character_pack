# kllj / 活动 001 1年级1班的偶像们 / main-02 第2话（adv_event_001_main-02）

- 她的台词：23 行（含用匿名标签说的 0 行）
- 出场的人：清夏、手毬、リーリヤ、咲季、ことね
- 场景：1年1組教室，放学后；清夏游说手毬参加班级联谊会
- 世界线：活动 001；制作人在制作的偶像：看不出

## 发生了什么
清夏邀请全班联谊会，手毬以想自主练习为由拒绝，清夏说服不了，リーリヤ主动说“我来说”。她对手毬说自己大概是班里实力最差的，怕在班级活动里拖后腿，所以会努力；又说以后可能和别的班对抗，输了会离梦想更远，很困扰。她想说“请手毬参加”，话说到一半卡住，随后出现一句“请不要拖后腿”（标签『リーリヤ？』，从上下文看是清夏在替她配音，没算她的）。她否认说过那句话并生气。手毬答应配合后，当面对她说不喜欢她，她只回了一声“诶？”。剧情经过参照 ttmr、hski 笔记。

## 她的关键台词
- 0027「わたしが……話す、から。」——主动接下说服手毬的任务
- 0035「……きっと、クラスで一番、実力が／ないの、わたしだと思うんです。」——自认班里实力最差
- 0039「それはできません。」——被手毬说“那就别当偶像”，立刻否定
- 0040「わたしは、トップアイドルに／なりたいんです。」——明说目标
- 0041「絶対になるって……／そう、決めたんです。」——决心的强度
- 0042「だから……たくさんがんばって、／足を引っ張らないようにします。」——对自己的弱点给出的对策是努力
- 0048「夢から遠ざかってしまうのは、／困ります。とても。」——输掉班级对抗会离梦想更远，所以在意班级
- 0050「えっと……わたしなんかが……／こんなことを言うのはおかしいって。」——说话时先自我贬低
- 0058「わ、わたしあんなこと言わない！」——被冒名说了重话时急着否认
- 0061「似てたから怒ってるのっ！」——对清夏的玩笑生气，理由是模仿得太像

## 行为模式
- 手毬语气强硬或带压迫感 → 发出“ひっ”之类的声音，先道歉再继续说（0030、0033）
- 要说自己的事时 → 先说自己不够格，再说为此要怎么做（0035、0037、0042）
- 被问到是否放弃偶像 → 干脆地拒绝，并说出“顶级偶像”的决心（0039～0041）
- 被催促、被说话慢 → 应“はい”后继续，说得结结巴巴（0051、0053）
- 被清夏开玩笑冒名 → 否认并生气（0058、0061）
- 被当面说“不喜欢你” → 只发出疑问声，没有反驳（0073、0074）

## 关系
- 清夏：叫她「清夏ちゃん」（0025）；清夏叫她“リーリヤ”；清夏让她来说后答应“交给你”（0028），玩笑冒名她时她生气（0058、0061）。
- 手毬：叫她「月村さん」（0033、0053）；手毬叫她“葛城”，最后说“我，不喜欢你”（0072、0074）。

## 档案类事实
- 自认是班里实力最差的（0035）。
- 想成为顶级偶像，并说已经下了决心（0040、0041）。

## 不确定
- 0054 标签是『リーリヤ？』，内容为“请不要拖后腿”，之后 0057、0059～0060 清夏被指说了过分的话并说是“アテレコ”，所以本份没有算作她的台词；本组清单把 0054 算在清夏名下，存疑。
- 【译文】0059、0060 的译文错位：0059 日文是说看她想委婉传达又为难，0060 日文是「以心伝心でアテレコしてみた。／似てたっしょ？」，译文没有对应。
