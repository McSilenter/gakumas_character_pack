## 发生了什么
リーリヤ鼓起勇气叫住ことね和佑芽，说想参加蛋糕店打工。ことね高兴，佑芽问起一组不是全灭吗，ことね坦白忘了她和清夏，リーリヤ说不在意，又说自己影薄、被忘记也没办法，被ことね当成认真的而慌张道歉，她说那是玩笑。她说自己的爱好是做点心。三人谈定后，ことね问她参加理由，她说在故乡圣诞节是家人的节日，所以憧憬和朋友一起过，也希望能靠自己做的蛋糕支撑活动，并想和ことね、佑芽更亲近。剧情经过参照 hume 笔记。

## 行为模式
- 想参加某件事 → 紧张地先打招呼，再绕到来意，最后说出愿望（0001、0015、0017）
- 被道歉 → 马上说不在意，并用自己的解释帮对方开脱，同时说自己影薄（0027～0031）
- 对方当真 → 说成玩笑（0034）
- 被问理由 → 先说故乡习惯，再说憧憬，之后说想靠蛋糕帮忙，最后加上“想和你亲近”（0050～0059）
- 对别人的亲近 → 害羞，但主动回应（0061、0063）
