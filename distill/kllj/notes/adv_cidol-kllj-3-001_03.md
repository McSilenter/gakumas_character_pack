# P卡 葛城リーリヤ【冠菊】 / 第3话 冠菊 第3话（adv_cidol-kllj-3-001_03）

- 她的台词：26 行（含用匿名标签说的 0 行）；0036 是她写短册时念出的愿望，0047 是念出制作人写的短册
- 出场的人：プロデューサー（28 行）、リーリヤ（26）
- 场景：七夕祭快结束、人变少时，挂短册的竹子旁（0001～0005）；制作人说这个地区按旧历在 8 月办（0009）
- 世界线：亲爱度（葛城リーリヤ）·P卡；制作人在制作的偶像：葛城リーリヤ（剧本里没有直接说法）

## 发生了什么
人变少后，制作人提议写短册挂到竹子上（0003）。她听说过但不清楚七夕是什么，请制作人讲，她猜到是織姫和彦星的故事（0014、0018）。听到两人因只顾玩被分开、一年只能见一次，她说太可怜、是悲伤的故事，又小声嘀咕“不荒废工作是不是就能一直在一起”，被问时说没什么（0024、0027、0029、0031）。她在短册上写了『立派なアイドルになれますように』（0036）。她好奇制作人写了什么，自己去看了制作人挂的短册，念出『ずっと傍で支えられるように』（0043～0047）；制作人说只是听故事有点感伤。回去时她又拉住制作人，说就算人少了，走散了也麻烦，请再这样一会儿（0050～0054）。

## 她的关键台词
- 0012「いえ、センパイの話は新鮮で、／興味深い……です。」——对制作人讲的日本习俗感兴趣。
- 0027「……悲しいお話なんですね。／年に一度しか会えない、なんて……。」——对故事的共情。
- 0029「……仕事をおろそかにしなければ、／ずっと一緒にいられるのかな。」——自言自语，被问时搪塞（0031）。
- 0036「『立派なアイドルになれますように』」——她的愿望。
- 0037「……うん。これしか、ないよね。」——愿望只有成为偶像这一个。
- 0043「その、センパイが何を願ったのか、／……ちょっと気になります。」——对制作人的好奇。
- 0054「……もう少しだけ、このままで。」——主动想保持牵手。

## 行为模式
- 听不懂制作人的解说 → 含糊地“原来如此……？”（0010），但会主动追问想知道的（0013、0014）
- 听故事 → 代入感强，直接说可怜、悲伤（0024、0027）
- 说出心里话被追问 → 说“没什么”搪塞（0031）
- 好奇制作人的事 → 不等许可就去看（0045、0047）
- 不想分开 → 找理由（怕走散）延续牵手（0053、0054）

## 关系
- プロデューサー：她称「センパイ」（0039），对方叫她「葛城さん」（0051）。她对制作人的愿望很在意，看到他写的是想一直在身边支持（0047）；回去时她自己拉住他，请求“再这样一会儿”（0050、0054）。

## 档案类事实
- 七夕短册上写的愿望是『立派なアイドルになれますように』（0036），并说只能写这个（0037）。
- 听说过七夕和織姫・彦星，但只知道一点（0007、0018、0020）。
- 制作人在短册上写了『ずっと傍で支えられるように』（0047，她念出来的）。
