# P卡 葛城リーリヤ【极光】 / 第1话 极光 第1话（adv_cidol-kllj-3-008_01）

- 她的台词：18 行（含用匿名标签说的 0 行）；0015、0016 是她的心里话（括号）
- 出场的人：リーリヤ（18 行）、プロデューサー（18）、テレビ（1）
- 场景：一场演出结束后（0003「今日は、ミスばかりでした」），电视里在播咲季登场的节目（0013）；地点没有交代
- 世界线：亲爱度（葛城リーリヤ）·P卡；制作人在制作的偶像：葛城リーリヤ（剧本里没有直接说法）

## 发生了什么
演出后她向制作人道歉，说一直失误、没能让粉丝满意（0001～0004）。制作人说确实不算好，但不必在意，下次做得更好；她说前辈每次她失败都这么说，从不批评她（0007、0008）。制作人说知道她尽了全力，她说再努力演出不好也没意义（0010）。制作人心里觉得她比平时更消沉（0011，制作人的心里话）。电视上介绍咲季是初星学園的新星，她心里想咲季好厉害、自己却……（0013～0016）。制作人问她是不是不甘心，她承认，又说像她这样的人不甘心是不自量力（0018）。制作人说看到同学飞跃而不甘心是成长，以前的她不会这样；她承认以前觉得那是遥远世界的事（0021～0024）。制作人说现在看得到背影了，她说看得到但追不上就没意义，并问这样下去真的可以吗、前辈怎么想（0026～0033）。制作人心里想她现在需要的不是自己的话（0034，心里话），建议她找花海さん谈谈（0035）。

## 她的关键台词
- 0004「来てくれたファンの皆さんを……／満足させることが、できませんでした。」——以粉丝满意为标准评价自己。
- 0008「……わたしがミスをしているのに、／叱ってくれません。」——对制作人不批评自己表示不满。
- 0010「どんなに頑張っても……ライブの出来が／悪かったら、意味ないです……。」——否定“努力本身”的价值，结果导向。
- 0015「（すごい、なぁ……咲季ちゃんは）」——心里话，对同学的羡慕。
- 0018「……はい。わたしなんかが、／おこがましい、ですよね……。」——承认不甘心，但又觉得自己不配有这种感情。
- 0024「遠く離れた世界の話だったから。」——以前觉得顶尖偶像是遥远世界。
- 0026「……たとえ背中が見えていたって、／追いつけないなら、意味がありません。」——对制作人的安慰提出反驳。
- 0030「本当に、このままでいいんでしょうか？」——对现状和制作人的方针产生怀疑（制作人心里说她少有地迷茫，0031）。

## 行为模式
- 演出失败 → 先向制作人道歉，用“没让粉丝满意”来责怪自己（0001、0004）
- 被安慰“不要在意” → 反而觉得不被批评不对，追问（0007、0008）
- 看到同学的成就 → 心里比较、自我贬低（0015、0016）
- 被说出不甘心 → 承认，但加一句“我这样的人太不自量力”（0018）
- 迷茫时 → 直接问制作人怎么想（0033）

## 关系
- プロデューサー：她称「センパイ」（0001），对方叫她「葛城さん」（0002）。她说前辈每次她失败都说同样的话、不批评她（0007、0008），这一篇对制作人的安慰连续反驳（0010、0026）；制作人心里认为她需要的不是自己的话，让她去找咲季（0034、0035）。
- 咲季：她在心里称「咲季ちゃん」（0015），被制作人建议去找「花海さん」谈时也称「咲季ちゃん」（0036）。制作人说咲季是她的同学（クラスメイト，0021），是开始看得见背影的对手（0037）。

## 档案类事实
- 和花海咲季是同班同学（0021，制作人说的）。
- 以前觉得顶尖偶像的世界是遥远的事，不会不甘心（0022～0024）。
- 这次演出一直失误（0003）。

## 不确定

- 0029 和 0030 之间、0033 之后可能有制作人的选项没写出。
