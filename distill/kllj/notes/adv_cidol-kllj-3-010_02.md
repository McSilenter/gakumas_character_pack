# P卡 葛城リーリヤ【樱花相册】 / 第2话 樱花相册 第2话（adv_cidol-kllj-3-010_02）

- 她的台词：39 行（含用匿名标签说的 0 行）；0013～0016、0022 是她的心里话（括号）；0005～0010、0026、0027、0036～0049 是不带括号的独白式叙述，其中 0001～0027 是回想的场面
- 出场的人：リーリヤ（39 行）、プロデューサー（12）、アイドル科の生徒A（3）、アイドル科の生徒B（1）、アイドル科の生徒C（1）
- 场景：回想中是自动贩卖机前（0005）；现在是和制作人回宿舍的路上（0052）
- 世界线：亲爱度（葛城リーリヤ）·P卡；制作人在制作的偶像：葛城リーリヤ（0021 制作人称她「担当アイドル」，0024「だからプロデュースをしているんです」）

## 发生了什么
回想：在自动贩卖机前，隔壁班的偶像科学生来搭话，她说前辈温柔、博学、什么都会，引导着自己（0001、0002）。她叙述这些人和手毬一样是内部升学组，比她实力强得多，关系说不上好，清夏一直不让她们接近自己（0005～0010）。她们说不明白为什么是她，她唱歌跳舞都不好、长得也不显眼；她心里承认无从反驳，却还是不甘心（0011～0016）。制作人出现，说是因为她有闪光点，自己相信她能成为顶级偶像所以才制作她，拉着她的手走了；她说前辈少有地强硬（0017～0027）。回到现在，她对制作人说他为她生气、说相信她，让她很高兴，悲伤消失了；制作人让她别再提，她说前辈害羞了（0028～0033）。随后她独白：自己没有才能是事实，前辈说的才能只有意志坚强这一点；努力也不知是否在前进，差点折断，但有人相信她的意志是才能，所以这不是放弃的理由；其实她没有前辈想的那么坚强（0036～0048）。她突然大声叫前辈，说有你在身边我才能挺起胸膛，宣布“我要成为偶像！”（0050～0054）。

## 她的关键台词
- 0002「優しくて、物知りで、何でもできて、／わたしを、導いてくれるんです。」——她眼中的制作人。
- 0007「わたしなんかよりも、ずっと。」——拿别人和自己比的习惯。
- 0015「（それなのに……やっぱり悔しいな）」——承认事实，仍然不甘心。
- 0028「――怒ってくれたことが、／嬉しかったんです。」——制作人为她生气让她高兴。
- 0036「わたしに、才能なんてない。」——独白，对自己的冷静评价。
- 0047「――諦める理由には、ならない。」——独白，结论。
- 0048「……本当は、センパイが思うほど、／わたしは強い人間じゃない。」——独白，坦承软弱。
- 0053「あなたが傍にいてくれる。／だからわたしは、胸を張れる。」——把制作人当作支柱。
- 0054「――わたし、アイドルになります！」——宣言（目标）。

## 行为模式
- 被人当面说没才能 → 心里承认无法反驳，但不甘心，不当场顶嘴（0013～0016）
- 有人替她出头 → 事后表达高兴，悲伤就消了（0028～0030）
- 看到制作人难为情 → 直接点破“前辈害羞了”（0033）
- 动摇时 → 用“有人相信我”来撑住自己，把对方的信任当作不放弃的理由（0044～0047）
- 下定决心 → 突然大声宣言，不太顾场合（0050、0054、0056）

## 关系
- プロデューサー：她称「センパイ」（0001），对方叫她「葛城さん」（0023）；独白和宣言中称「あなた」（0045、0053）。她对别人夸前辈（0001、0002）；前辈为她生气、拉着她的手离开，她说少有地强硬（0026、0027）、让她高兴（0028）；说有他在身边才能挺胸（0053）。
- 清夏：她叙述中称「清夏ちゃん」（0010）；清夏一直不让那些学生接近她。
- 手毬：她称「手毬ちゃん」（0006），说那些学生和手毬一样是内部升学组。
- 隔壁班的偶像科学生（A、B、C）：关系说不上好（0009），说她唱跳不好、不显眼（0012）。

## 档案类事实
- 隔壁班有和手毬一样的内部升学组学生，实力比她强（0005～0007）；她和她们关系不好，清夏会挡开她们（0009、0010）。
- 被人说唱歌跳舞都不好、外貌不显眼，她自己说无法反驳（0012～0014）。
- 她认为自己没有才能，前辈说的才能只有意志坚强一点（0036～0038）；说自己其实没有前辈想的那么坚强（0048）。
- 和制作人一起回宿舍（0052）。

## 不确定
- 0005～0010、0026、0027、0036～0049 没有括号，是她的叙述或独白，是否说出口看不出，按标签计入台词。
- 回想（0001～0027）是什么时候的事没写；0031 制作人说「あの時」，0032 说自己当时也不成熟。
- 0053、0054 是对制作人说出口的（0055 制作人有反应），0050 之前的独白他是否听到看不出。
- 【译文】0042「でも、それは前提だから。」意思是“但这是前提（理所当然的出发点）”，译文作“但是，这些都不重要”，意思不对。
