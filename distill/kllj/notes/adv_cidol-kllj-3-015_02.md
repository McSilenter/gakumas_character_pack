# P卡 葛城リーリヤ【Atmosphere】 / 第2话 Atmosphere 第2话（adv_cidol-kllj-3-015_02）

- 她的台词：19 行（含用匿名标签说的 0 行）
- 出场的人：プロデューサー（21 行）、リーリヤ（19）
- 场景：制作人给她看新曲服装的基础样式（0001）；地点没有交代
- 世界线：亲爱度（葛城リーリヤ）·P卡；制作人在制作的偶像：葛城リーリヤ（剧本里没有直接说法）

## 发生了什么
制作人拿来新服装的基础样式，她说像女神一样，喜欢这种风格（0002、0004）。制作人说只是把方针告诉设计师，她说前辈很了解她，她很高兴；制作人心里被她纯粹的信任打动（0006、0007，制作人的心里话）。制作人说『白線』『極光』的服装选黑色是表现她内心的坚强，这次用纯白表现她另一面——神秘性（0009～0015）。制作人说她的视觉表现在飞跃成长，她说自己能注意动作、姿势和饭撒的方式了，但“神秘”太夸张（0017～0020）。制作人说『北欧の雪妖精』就是指她，她嘴上说太夸张却笑了（0023～0026）。她兴奋地提出想要“杖”：把麦克风架装饰成杖，拿着跳舞像魔法使一样很帅；制作人让她冷静，她说「落ち着きました！！」（0029～0040）。

## 她的关键台词
- 0004「センパイ、すごいです！／わたし、こういうの好きです！」——对幻想风格的喜爱。
- 0006「それでも、センパイはわたしのことを／よく分かってくれてて、嬉しいです。」——对制作人的信赖。
- 0019「仕草とか姿勢とか、ファンサのやり方は／意識できるようになってきました。」——自己说出的进步。
- 0025「そんな、妖精だなんて、／言い過ぎですよ……えへへ……」——嘴上否认、其实高兴（制作人心里也这么看，0026）。
- 0029「わたし、杖が欲しいんです！」——主动提出的点子。
- 0036「魔法使いみたいになって、／とってもカッコいいと思うんです！」——幻想、中二风格的喜好。
- 0038「落ち着きました！！」——兴奋时的反应，明显没冷静下来。

## 行为模式
- 看到喜欢的风格 → 坦率说喜欢（0002、0004）
- 被夸大地称赞（神秘、妖精）→ 说“太夸张”，但笑出来（0020、0025）
- 有了点子 → 情绪高涨地一口气说出来，连珠炮一样（0027～0036）
- 被要求冷静 → 大声答“冷静了”（0038、0040）

## 关系
- プロデューサー：她称「センパイ」（0004），对方叫她「葛城さん」（0001）。她说前辈很了解她（0006）；制作人心里说她对自己是“无垢的信赖”（0007）；她的点子被采纳（0033、0034）。

## 档案类事实
- 『白線』『極光』的服装是黑色，制作人说是表现她内心的坚强；这次新曲的服装是纯白，表现神秘性（0009～0015）。
- 喜欢女神、幻想风格的服装（0002、0004）；觉得像魔法使一样很帅（0036）。
- 现在能有意识地注意动作、姿势和饭撒（ファンサ）的方式（0019）。
- 制作人说她的视觉表现在飞跃成长，原因是她定下了作为偶像的方针（0017、0018）。
- 制作人说『北欧の雪妖精』指的是她（0023）。
- 她提议把麦克风架装饰成杖，制作人采纳（0031、0033）。

## 不确定
- 『北欧の雪妖精』是已有的称号还是制作人这次定的方向，剧本没说清。
- 0007、0026 是制作人的心里话。
