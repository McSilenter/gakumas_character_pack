# P卡 葛城リーリヤ【怦然心动】 / 第1话 怦然心动 第1话（adv_cidol-kllj-3-017_01）

- 她的台词：26 行（含用匿名标签说的 0 行）
- 出场的人：リーリヤ（26 行）、プロデューサー（14）
- 场景：制作人找她谈话（0001）；地点没有交代
- 世界线：亲爱度（葛城リーリヤ）·P卡；制作人在制作的偶像：葛城リーリヤ（0003 制作人说决定制作她和紫雲さん的组合）

## 发生了什么
制作人说决定制作她和清夏的组合，想多了解两人（0003、0004）。她说关于自己前辈比她还清楚，关于清夏尽管问（0005、0006）。她说清夏是最喜欢的挚友、憧憬的对象，喜欢上偶像、想成为偶像的契机全是托清夏的福（0008～0011）。她夸清夏开朗、体贴，会听口拙的她说话，会把封闭在自己世界里的她带到外面、牵着她的手教她新世界（0014～0021）。被问缺点，她说不久前还以为没有，现在发现清夏是“骗子”，隐瞒很多事、想一个人努力，不依赖她（0024～0029）。制作人提到清夏隐瞒伤病阴影的事，她说自己明明是挚友，请前辈也留意清夏，说没事的时候多半有事（0030～0034）。她说前辈擅长“监视”，因为她擅自练习时总是马上被发现；制作人说那是根据过去数据推测，她说“更可怕了”（0036～0040）。

## 她的关键台词
- 0005「……わたしのことは、わたしよりも／センパイの方が詳しいと思いますけど、」——对制作人了解自己的信任。
- 0008「わたしにとっての清夏ちゃんは、／大好きな親友で、憧れの存在です。」——对清夏的定位。
- 0011「全部、清夏ちゃんのおかげなんです！」——成为偶像的契机归于清夏。
- 0019「自分の世界に閉じこもっちゃうわたしを／外に連れ出してくれるんです。」——自我认识：容易封闭在自己的世界。
- 0026「清夏ちゃんは、嘘つきなんです！」——对清夏隐瞒的不满。
- 0029「わたしを頼ってくれないんです……！」——希望被朋友依靠。
- 0034「大丈夫って言ってる時は、／だいたい大丈夫じゃないですから！」——对清夏的了解。
- 0040「……もっと怖いです、センパイ。」——对制作人的吐槽。

## 行为模式
- 谈到喜欢的人 → 滔滔不绝地夸，语气很热烈（0008～0021）
- 朋友对自己隐瞒 → 不满的点在“不依赖我”，而不是被骗（0028、0029、0032）
- 关心朋友 → 拜托别人也帮忙留意（0033）
- 和制作人熟络 → 会开玩笑、吐槽（0036、0040）

## 关系
- 清夏：她称「清夏ちゃん」（0006）；制作人称「紫雲さん」（0003）。她说清夏是最喜欢的挚友、憧憬的存在、喜欢偶像和成为偶像的契机（0008～0011）；不满清夏隐瞒伤病阴影、不依赖她（0028～0032）。
- プロデューサー：她称「センパイ」（0002），对方叫她「葛城さん」（0001）。她说前辈比她自己还了解她（0005），她擅自练习时总被前辈发现（0038）。

## 档案类事实
- 制作人决定制作她和清夏的组合（0003）。
- 喜欢上偶像、想成为偶像的契机都是清夏（0010、0011）。
- 自认口拙（0015），容易封闭在自己的世界里（0019）。
- 常擅自去练习，总是马上被制作人发现（0038）；制作人说是根据过去数据推测的（0039）。
- 清夏直到最近才说出伤病留下的阴影（0030，制作人说的）。
