# P卡 葛城リーリヤ【怦然心动】 / 第2话 怦然心动 第2话（adv_cidol-kllj-3-017_02）

- 她的台词：28 行（含用匿名标签说的 0 行）
- 出场的人：リーリヤ（28 行）、プロデューサー（21）、清夏（15）、一同（1）
- 场景：制作人给她看组合服装的设计（0001～0020）；之后两人试穿服装、看新曲歌词（0021～0065）；地点没有交代
- 世界线：亲爱度（葛城リーリヤ）·P卡；制作人在制作的偶像：葛城リーリヤ（和清夏的组合；剧本里本篇没有直接说法，第1话 0003 说过）

## 发生了什么
制作人给她看黑白两色的组合服装设计，她很兴奋，她的是白色（0003～0008）。制作人问她黑色那件（清夏的）怎么样，说她最懂怎样衬托清夏的魅力；她提出露腰、露出长腿，又慌忙说不是自己想看，接着提议发箍、腰带链条，制作人让她一项一项来（0013～0020）。试穿时她说很合身（0023）；制作人说清夏的服装参考了她的建议，她紧张地问清夏觉得怎样，清夏很喜欢，还猜中链条和发箍是她的主意（0025～0033）。清夏说关于她的事不会输给制作人，她说“不用较劲”（0035、0037）。她夸清夏很合适，也问前辈怎么看，被夸可爱时说“因为是前辈选的服装”（0039～0044）。新曲歌词完成，她察觉之前前辈问她清夏的事是为了作词，说歌词好难为情（0052～0061）。剧情经过参照 ssmk 笔记。

## 她的关键台词
- 0003「わぁ……！　白と黒の衣装！／とっても可愛いです！」——看到组合服装时的兴奋。
- 0015「ここで切って、おなか出しちゃうとか。／長い足もよく見えるようにしたいし……」——对清夏的魅力很有想法。
- 0016「……あ、その、わ、わたしが見たいわけ／じゃないですからね！？」——说漏后慌忙否认。
- 0027「うん。／ど、どう思った……？」——在意清夏的评价。
- 0037「張り合わなくていいから……！」——清夏和制作人为她“较劲”时的反应。
- 0044「えへへ……／センパイが選んだ衣装ですから。」——把被夸可爱归于前辈的眼光。
- 0061「だって、この歌詞、すごく恥ずかしい／気がするんですけど……！」——对写进彼此心情的歌词感到难为情。

## 行为模式
- 被问到朋友的魅力 → 一个接一个说出具体想法，停不下来（0014～0019）
- 说漏了自己的心思 → 急忙否认（0016）
- 自己参与的东西被当事人看 → 紧张地问对方感想，被肯定后松一口气（0027、0029）
- 被人夸 → 说“谢谢”很小声（0041），或者把功劳推给别人（0044）
- 察觉到前辈的用意 → “果然！”（0055）

## 关系
- 清夏：她称「清夏ちゃん」（0039），对方叫她「リーリヤ」（0030）。她为清夏的服装出主意，在意清夏的感想；清夏一下就猜中哪些是她的主意（0030～0033）。
- プロデューサー：她称「センパイ」（0042），对方叫她「葛城さん」（0001）。制作人请她为清夏的服装出主意（0012）；她问前辈的感想，被夸可爱（0042、0043）。

## 档案类事实
- 组合服装是黑白对比的设计，她是白色、带荷叶边裙和蝴蝶结（0003、0007、0008）；清夏是黑色。
- 清夏服装上的腰带链条、发箍是她的主意（0018、0019、0030～0032）。
- 新曲歌词是制作人请作词家写出两人对彼此的心情，之前问她清夏的事就是为了作词（0052～0056）。
