# P卡 葛城リーリヤ【Agitato】 / 第3话 Agitato 第3话（adv_cidol-kllj-3-022_03）

- 她的台词：17 行（含用匿名标签说的 0 行）
- 出场的人：リーリヤ（17 行）、プロデューサー（16）
- 场景：合作拍摄结束后，她和制作人约好去化妆品专柜（0001～0004）
- 世界线：亲爱度（葛城リーリヤ）·P卡；制作人在制作的偶像：葛城リーリヤ（0028 制作人说自己是她的粉丝，兼任制作人）

## 发生了什么
拍摄结束后，她对那家厂商的各种产品产生了兴趣，和制作人一起去化妆品专柜（0004、0005）。看到每类有几百种产品，她不知道选哪个，说自己不太擅长化妆，是清夏教她的（0010、0011）。制作人说只在プロデューサー科的课上学过基础，她想起拍摄时化妆用的产品，决定照着买（0012～0016）。她说想用自己的钱买代言的香水，虽然拿到了试用品，但这样好像能切身感受自己工作的成果（0017～0020）。制作人说自己也是用自己的钱买她的周边，她问那是出于兴趣收集吗，笑着说“那前辈是我的粉丝了”，制作人说当然，兼任制作人（0022～0028）。制作人说也想买那款香水试试，她说很高兴，邀他一起去收银台（0029～0033）。

## 她的关键台词
- 0005「宣伝した香水だけじゃなくて、／いろんな製品に興味が湧いたので……！」——工作带来的新兴趣。
- 0011「実は、お化粧はあんまり／得意じゃないので／清夏ちゃんに教えてもらってて……」——不擅长化妆，向清夏学。
- 0015「そ、そうだ！／撮影の時のメイクアップでは、／確かこれとこれを使ってました！」——想到办法时的反应。
- 0019「いえ、もらっているんですけど……／自分のお金で買ってみたいんです。」——想用自己的钱买代言产品。
- 0020「なんていうか……自分のお仕事の成果を／体感できるような気がして……」——对工作成果的感受方式。
- 0027「えへへ……／じゃあ、わたしのファンですね。」——得知制作人买她的周边后开心地调侃。
- 0032「……嬉しいです、センパイ。」——制作人要用她代言的产品让她高兴。

## 行为模式
- 工作结束后 → 对相关领域产生兴趣，主动去了解（0004、0005）
- 不懂的东西 → 坦白说不擅长，说是跟朋友学的（0011）；想到能参考的东西就照做（0015）
- 自己的工作成果 → 想用自己的钱买来切身体会（0019、0020）
- 得知制作人私下支持自己 → 笑着说“那就是粉丝了”（0027）

## 关系
- プロデューサー：她称「センパイ」（0001），对方叫她「葛城さん」（0002）。制作人说用自己的钱买她的周边，是她的粉丝兼制作人（0022、0028）；也要买她代言的香水（0029、0031），她很高兴（0032）。
- 清夏：她称「清夏ちゃん」（0011），教她化妆。

## 档案类事实
- 不太擅长化妆，是清夏教的（0011）。
- 拍摄后对那家化妆品厂商的各种产品产生兴趣（0005）。
- 拿到了代言香水的试用品，但想用自己的钱买（0018、0019）。
- 制作人说自己用自己的钱买她的周边，主张工作和私人分开（0022、0024）。
- 制作人在プロデューサー科的课上学过化妆的基础知识（0012）。
