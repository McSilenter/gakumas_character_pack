# P卡 紫雲清夏【怦然心动】 / 第3话 怦然心动 第3话（adv_cidol-ssmk-3-017_03）

- 她的台词：10 行（含用匿名标签说的 0 行）
- 出场的人：清夏（16 行）、プロデューサー（13）、リーリヤ（10）、一同（2）
- 场景：看不出具体地点；前半三人商量组合名，后半是『REVERSI』结成纪念 live 的舞台上（0038～0041）
- 世界线：亲爱度（紫雲清夏）·P卡；制作人在制作的偶像：紫雲清夏（清夏叫制作人「Pっち」，0001）

## 发生了什么
清夏提议组合名『ヴィ・ダンサル・エン・ドゥエット』，说到意思时由她来解释，大意是“我们跳舞，一支二重唱”。她说喜欢清夏的主意，但有点长。制作人提出『REVERSI』，她猜是因为两人的服装黑白；制作人说两人紧密相连、缺一不可，像表里一体。两人沉默后，她说“也许确实如此”、觉得『REVERSI』很好。清夏打趣制作人松了口气，她笑着附和。结成纪念 live 上她向观众宣布这是『REVERSI』的结成纪念 live。

## 行为模式
- 对朋友的提案 → 先说喜欢，再委婉地用“～かな？”指出问题（0010、0012）
- 别人的提案 → 先猜由来，听完解释后沉默想一下再接受（0019、0027、0029）
- 朋友打趣别人 → 笑着附和（0034）

## 关系
- 清夏：叫「清夏ちゃん」（0010）；这一话清夏没有叫她名字。替清夏解释组合名，说喜欢但太长（0008～0012）；接受两人“表里一体”的说法（0029）
- 清夏的制作人：用敬语回答（0019、0031）；这一话里没有称呼他

## 档案类事实
- 能解释清夏提的组合名的意思（制作人说是瑞典语，0009）（0008）
- 和清夏的组合名定为『REVERSI』，结成纪念 live 上唱新曲『ときめきエモーション』（0035、0039、0041）
