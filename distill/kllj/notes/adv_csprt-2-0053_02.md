# S卡 2-0053【ばたんきゅー】 / 第2话 关于『美好』的探讨（adv_csprt-2-0053_02）

- 她的台词：12 行（含用匿名标签说的 0 行）
- 出场的人：リーリヤ、広
- 场景：リーリヤ的房间（広在访问；0001 広说「お邪魔します」，0002 リーリヤ说请进）
- 世界线：S卡【ばたんきゅー】；制作人在制作的偶像：看不出

## 发生了什么
広来到リーリヤ的房间，リーリヤ说要去准备点心和茶。広看到房里的限定礼盒和故乡的照片，リーリヤ介绍说礼盒是想和清夏一起看完的，照片是爸爸寄来的。広用「風光明媚」夸照片，リーリヤ听不懂，広解释了词义。后来リーリヤ拿出从图书馆借来的训练书，说起「プロギング」，认为适合自己和広。

## 她的关键台词
- 0002「どうぞ。今お菓子とお茶、／用意するから、待っててください。」——招待客人的第一反应是准备点心和茶
- 0005「『ふわっとブレザーつむじちゃん』／3期の特典付き限定ボックスです。」——房间里有喜欢作品的限定礼盒
- 0006「今度のお休みに、清夏ちゃんと、／全24話の観賞会をしようと思って。」——下个休息日打算和清夏一起看完全24话；称清夏为「清夏ちゃん」
- 0008「はい。スウェーデンの、／森と湖の写真……。」——说明故乡的照片
- 0009「故郷を思い出せるようにって、／お父さんが送ってくれたんです。」——爸爸为了让她能想起故乡而寄来照片，称「お父さん」
- 0011「ふーこー……メイビー？」——不懂「風光明媚」，只能照着发音重复，英语说法夹杂其中
- 0013「そうなんだ……わたしの知らない、／素敵な日本語、いっぱいあるなあ。」——听了解释后感叹还有很多自己不知道的日语词
- 0014「これが、図書館で借りてきた、／トレーニングの本です。」——去图书馆借训练书
- 0017「あんまり無理をせずに、しっかり／体力作りができるから……」——挑选「プロギング」的理由：既不勉强又能扎实练体力
- 0018「わたしにも、篠澤さんにも、／ちょうどいいなって思って。」——是考虑了広的情况才选这个方法

## 行为模式
- 有客人来 → 马上去准备点心和茶（0002）
- 被问起房间里的东西 → 一样一样详细说明（0005、0006、0008、0009）
- 遇到不懂的日语词 → 照着发音重复，听了解释后感叹自己还有很多不知道的日语（0011、0013）
- 选训练方法 → 考虑对象（自己和広）的体力，选不勉强的方式（0017、0018）

## 关系
- 広：称「篠澤さん」，用敬体（0002、0018）。広叫她「リーリヤ」，向她道谢（0020）。
- 清夏：称「清夏ちゃん」，约好一起看观赏会（0006）。
- お父さん：寄来故乡照片的人（0009）。

## 档案类事实
- 家乡是スウェーデン，房间里有森林和湖泊的照片，是爸爸寄来的（0008、0009）
- 喜欢『ふわっとブレザーつむじちゃん』，有第3期特典付限定礼盒，打算和清夏一起看全24话（0005、0006）
- 有一些日语词不懂，如「風光明媚」（0011、0013）
- 从图书馆借过训练书，了解「プロギング」，说是起源于スウェーデン（0014、0016）

## 不确定
- 0016 的「らしいんですけど」是转述听来的，起源是否确切剧本里不能确认。
- 【译文】0011 译文“枫…官…鸣寐？”只是对发音的音译，原文是「ふーこー……メイビー？」，其中「メイビー」是英语 maybe 的发音，译文没体现。
