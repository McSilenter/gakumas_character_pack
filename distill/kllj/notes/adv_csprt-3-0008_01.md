# S卡 3-0008【おいしい顔、いただき～！】 / 第1话 小心突击拍照！（adv_csprt-3-0008_01）

- 她的台词：9 行（含匿名标签 0 行）
- 出场的人：清夏（11）、リーリヤ（9）
- 场景：两人看手机里的照片；地点、时间未明说
- 世界线：S卡【おいしい顔、いただき～！】；制作人在制作的偶像：看不出

## 发生了什么
清夏给リーリヤ看照片：入学前来日本买衣服时的，以及前阵子一起吃可丽饼时的。リーリヤ说清夏总是偷拍，清夏说她可爱，又拿出她来不及应对而表情奇怪的照片，リーリヤ要她删掉。清夏说只给她一个人看，リーリヤ说偶像要在意上镜，课上被说过，平时的照片也要意识。清夏说那就拍得可爱，リーリヤ说不是这个意思。

## 她的关键台词
- 0002「……これって、入学前に／日本に来たときの……？」——认出照片是入学前来日本时的
- 0006「……いつも、清夏ちゃんが／不意打ち、してくるから……。」——小声抱怨清夏总是偷拍
- 0009「……す、清夏ちゃん！／それは消して……！」——看到自己的怪表情，要求删除
- 0011「……だって、／は、恥ずかしいよ……。」——说出理由：害羞
- 0013「そ、そういう問題じゃなくて……！」——否定“只给你看”的辩解
- 0014「アイドルは写りも気にすること……！」——点出真正的理由：偶像要在意上镜
- 0016「こ、この前のレッスンで、／言われたでしょ……？」——提醒清夏课上被说过
- 0017「……だから、普段の何気ない写真でも／意識、しないと……。」——说平时的照片也要意识
- 0020「そ、そうじゃなくて……！」——想法被曲解时再次否认

## 行为模式
- 被偷拍或看到怪表情的照片 → 小声抱怨，要求删除，先说害羞（0006、0009、0011）
- 对方的辩解没击中要点 → 再说明真正的理由，用课上的内容说话（0013、0014、0016、0017）
- 说的话被曲解 → 否认却没有被听进去（0020）

## 关系
- 清夏：称「清夏ちゃん」，用普通话气说话（不使用敬语）；清夏称她「リーリヤ」，说她可爱，常偷拍她（0006；清夏 0007）

## 档案类事实
- 入学前来过日本，当时和清夏一起买了很多衣服并拍照（0002；清夏 0003）
- 前阵子和清夏一起吃过可丽饼并拍了照（清夏 0004）
- 课上被说过偶像要在意上镜（0014、0016）
