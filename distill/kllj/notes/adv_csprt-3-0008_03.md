# S卡 3-0008【おいしい顔、いただき～！】 / 第3话 Let’s可丽饼派对！（adv_csprt-3-0008_03）

- 她的台词：8 行（含匿名标签 0 行）
- 出场的人：清夏（9）、リーリヤ（8）
- 场景：清夏带她到一个地方准备做可丽饼（地点未明说，看起来是能做料理的场所）；时间看不出
- 世界线：S卡【おいしい顔、いただき～！】；制作人在制作的偶像：看不出

## 发生了什么
清夏催着リーリヤ跟她走，说是秘密。到了地方，清夏说今天要和她一起做可丽饼，作为每天努力练习的奖励，平时总是リーリヤ做，所以想给她做点什么。リーリヤ道谢，说很高兴。刚要开始，她发现清夏拿的是盐。

- 0010「……ご褒美……。」——复述「ご褒美」，似乎没想到
- 0013「……清夏ちゃん、ありがとう。」——道谢
- 0014「すっごく嬉しい……！」——直率说出开心

## 行为模式
- 被拉着走 → 先请对方等一下，再问理由（0002、0003）
- 被说是奖励 → 一时愣住，复述，然后道谢并说高兴（0010、0013、0014）
- 看到明显的错误 → 及时指出（0017）

## 关系
- 清夏：称「清夏ちゃん」；清夏称「リーリヤ」。说平时总是由她做可丽饼，清夏想回报（清夏 0011、0012）
