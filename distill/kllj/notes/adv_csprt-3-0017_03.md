# S卡 3-0017【ほら、一緒に持と♪】 / 第3话 最喜欢的早餐（adv_csprt-3-0017_03）

- 她的台词：9 行（标签「リーリヤ」，无匿名行）
- 出场的人：清夏（11）、リーリヤ（9）
- 场景：早上；清夏还在睡，リーリヤ叫她起床并做早餐；具体地点没写明。
- 世界线：S卡【ほら、一緒に持と♪】；制作人在制作的偶像：看不出

## 发生了什么
早上，リーリヤ叫清夏起床，清夏说昨天熬夜想再睡一会儿。リーリヤ说这样的人我不做早饭给你吃，清夏问是什么，她说是法式吐司，清夏立刻起床并请她也给自己做。リーリヤ答应马上做，结果做出了一座法式吐司的山，她说太高兴了不小心做多了。清夏说两个人多吃点，当作早上开派对。

## 她的关键台词
- 0001「……清夏ちゃん。」——先轻声叫名字。
- 0002「朝だよ、そろそろ起きて……。」——温和地叫醒对方。
- 0005「あっ……もう、清夏ちゃんってば……。」——对贪睡的清夏无奈，但口气柔和。
- 0006「そんな人には、／朝ごはん、作ってあげません。」——用不做早饭作为（半玩笑的）惩罚。
- 0008「うん、今日はね……」——吊胃口。
- 0009「フレンチトースト、だよ。」——说出早餐的菜单。
- 0014「もう……すぐ作るから、／ちょっとだけ、待っててね。」——被清夏的变脸逗得无奈，答应马上做。
- 0017「……う、嬉しくなっちゃって、つい……」——被指出做了一座山，承认自己因为高兴做过头。
- 0020「……うんっ！」——同意清夏“当作派对”的说法。

## 行为模式
- 叫不起贪睡的人 → 温和叫醒，不行就用“不做早饭”半开玩笑地威胁（0002、0006）。
- 对方马上反悔起床 → 无奈但立刻答应（0014）。
- 被指出做得太多 → 害羞地承认是因为高兴（0017）。
- 对方把过量转为愉快的话 → 开心接受（0020）。

## 关系
- 清夏：称「清夏ちゃん」（0001、0005）；清夏称她「リーリヤ」。リーリヤ会给清夏做早饭，清夏对她的法式吐司反应很大。

## 档案类事实
- 她会做早饭，这天做的是法式吐司（0009）。
- 做饭时因为高兴会做过量（0017）。
- 清夏昨天熬夜（清夏 0004）。

## 不确定
- 两人是否同住（因此能早上叫她起床），本篇没有明说，只能从对话推测。
