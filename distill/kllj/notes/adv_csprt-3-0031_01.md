# S卡 3-0031【花火、やりませんか……？】 / 第1话 夏日风物诗（adv_csprt-3-0031_01）

- 她的台词：13 行（标签『リーリヤ』，无匿名行）；其中 0006 是括号内的心里话，0001、0002、0007～0013 大多是她一个人的自言自语
- 出场的人：リーリヤ（13）、手毬（4）、子供（2）、子供の母（1）
- 场景：商店街，她在买菜（0001、0002）；之后想在“今晚”放烟花（0017）。
- 世界线：S卡【花火、やりませんか……？】；制作人在制作的偶像：看不出

## 发生了什么
リーリヤ在买做饭的材料，旁边有孩子向妈妈要烟花，妈妈说下次。她注意到烟花，想起这是日本夏天的活动，说不出名字，想了想觉得是“风物诗”。她看到孩子指的是手持烟花，买了下来，才发现不知道怎么放，也想不到谁能一起玩，清夏有事。这时遇到手毬，她眼睛一亮，问手毬今晚有没有时间，手毬说稍微可以，她就邀请一起放烟花。剧情经过参照 ttmr 笔记。

## 她的关键台词
- 0001「えっと……後は、じゃがいもと……／にんじんは、もうあるから……」——在商店街核对要买的东西，自言自语。
- 0006「（……花火、かぁ）」——心里话，注意到烟花。
- 0007「日本では、夏のイベントなんだよね。／なんだったっけ……ふうぶつし？」——知道烟花是日本夏天的活动，但想不起“风物诗”这个词，用疑问口气。
- 0011「か、買っちゃった……！」——自己也吃惊地买下手持烟花。
- 0012「やり方、よく分からないし……／一緒にやってくれる人、いないかな。」——买了才发现不会放，想找人一起。
- 0013「……清夏ちゃんは、用事あるんだ。／ど、どうしよう……。」——先想到清夏，但对方有事，慌了。
- 0015「月村さん……！」——遇到手毬，称「月村さん」。
- 0017「あの……！／今日の夜って、お時間ありますか！？」——用敬语、鼓起勇气问手毬今晚的时间。
- 0019「そ、それじゃあ……／一緒に、花火やりませんか……！？」——直接发出邀请，语气发颤。

## 行为模式
- 对没见过的日本习俗好奇 → 先观察孩子指的东西，再靠猜测去找，买了之后才发现不会用（0007～0012）。
- 想找人一起做 → 先想最亲近的人（清夏），没有机会就硬着头皮找别的熟人（0013、0015、0017）。
- 邀请别人 → 用敬语，说话断断续续，最后一句才提出具体邀约（0017、0019）。
- 日语词汇不确定时 → 用疑问口气说出来（0007）。

## 关系
- 手毬：称「月村さん」（0015），用敬语；手毬称她「リーリヤ」（手毬 0014），她邀请时手毬说“稍微有点时间可以”（手毬 0018）。
- 清夏：称「清夏ちゃん」（0013）；她第一个想到邀请清夏，但清夏有事。

## 档案类事实
- 她今天在商店街买做饭的材料，包括土豆、胡萝卜（0001）。
- 她知道烟花是日本夏天的活动，但说不出“风物诗”这个词（0007）。
- 她第一次买手持烟花，不知道怎么放（0011、0012）。
- 清夏今天有事（0013）。

## 不确定
- 0007「日本では」一句的前提（她是否不是日本人、从哪里来）剧本没有说明，只写了“日本では”。
- 0008～0010 是她一个人的自言自语，不是说给别人听的。
