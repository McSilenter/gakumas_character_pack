# S卡 3-0031【花火、やりませんか……？】 / 第3话 如果能一直持续（adv_csprt-3-0031_03）

- 她的台词：11 行（标签『リーリヤ』，无匿名行）
- 出场的人：リーリヤ（11）、手毬（8）
- 场景：放烟花接近结束，放线香花火（手毬 0002、0005）。具体地点剧本没写。
- 世界线：S卡【花火、やりませんか……？】；制作人在制作的偶像：看不出

## 发生了什么
手毬拿出线香花火，说比刚才的朴素但很漂亮，リーリヤ说这可能是她最喜欢的。火球掉下，最后一支结束，リーリヤ说这种心情应该叫做依依不舍。手毬说希望一直持续，リーリヤ问“是吗”，说因为知道会结束才觉得美，一直持续就变成日常了，偶像也许一样。手毬说如果努力成为偶像却很快结束，她会讨厌。リーリヤ说即便如此要做的事不变，为了让那一瞬间更长，会一直奔跑，手毬说自己也不会输。剧情经过参照 ttmr 笔记。

## 她的关键台词
- 0003「……そう、ですね。／これが一番、好きかもしれないです。」——说线香花火可能是她最喜欢的。
- 0004「……あ。／火の玉、落ちちゃった……。」——看到火球掉落，小声说。
- 0006「……こういう気持ちは、確か／名残惜しいって言うのでしょうか……。」——把当下的心情归到“名残惜しい”，但不太确定词义。
- 0008「……そう、でしょうか？」——手毬说希望一直持续，她委婉地提出疑问。
- 0010「……終わることを知っているから、／綺麗だと感じるのかもしれません。」——表明看法：正因为知道会结束才美。
- 0011「この輝きがずっと続いたら、／それが日常になってしまう、から……。」——解释理由：一直持续会变成日常。
- 0014「アイドルも……同じなのかも。」——把同样的道理放到偶像身上。
- 0016「……それでも、／わたしたちがやることは変わりません。」——手毬说怕很快结束后，她表明立场：做的事不变。
- 0017「その一瞬が少しでも長く続くように、／走り続けます。」——决心：为了让那一瞬间更长而一直奔跑。

## 行为模式
- 有不同看法时 → 先用疑问口气委婉提出，再慢慢说出自己的想法，说不好时先说“很难用语言表达”（0008～0011）。
- 谈到偶像 → 从眼前的烟花联系到偶像，但不是悲观，而是转成决心（0014、0016、0017）。
- 对方流露出不安 → 不安慰，只表明“我们要做的事不变”（0016）。
- 词义不确定的日语词 → 用“确か～でしょうか”的口气试着说出来（0006）。

## 关系
- 手毬：本话没有直接称呼，在第1、2话称『月村さん』，用敬语；手毬称她「リーリヤ」（手毬 0018）。她用“わたしたち”把手毬和自己并在一起（0016）。手毬最后说“私だって、負けないから”（手毬 0019）。

## 档案类事实
- 她最喜欢的烟花可能是线香花火（0003）。
- 她认为美是因为会结束（0010、0011）。
- 她想的是“偶像”也是如此，并决定一直奔跑（0014、0017）。

## 不确定
- 0009 之后，她说的“终わる”指烟花还是指偶像生涯，要看前后：0010、0011 说的是烟花，0014 才转到偶像。
- 0017 “その一瞬”具体指什么（偶像的活动期间？），原文没有明说。
- 0016「わたしたち」是否包括手毬，原文没有特别说明，按上下文理解为她和手毬。
