# S卡 3-0042【あったかいね】 / 第2话 初次相遇的那一刻（adv_csprt-3-0042_02）

- 她的台词：10 行（含用匿名标签说的 0 行）
- 出场的人：清夏（10）、リーリヤ（10）
- 场景：两人在一起学习（清夏 0004“勉強会”）
- 世界线：S卡【あったかいね】；制作人在制作的偶像：看不出

## 发生了什么
リーリヤ在现代文题目上卡住，先说再想想也许能懂，被清夏说可以多依赖后才讲出难点。清夏向她请教数学，她开始讲解；清夏喊累后，她指出才做了一点点。清夏说两人现在一起学习很不可思议，她也说没想过会住在日本、和清夏同校当偶像，当时的自己知道了会晕倒。清夏提到第一次见面时她和妈妈走散哭泣，她羞得请清夏别再提。

## 她的关键台词
- 0003「そう、なんだけど……／もうちょっと考えれば、分かるかも。」——有不懂的地方，先想自己再想想
- 0005「……えっと、じゃあ現代文なんだけど、／ここの問題の文章が難しくて……」——被劝后才说出难点
- 0008「えっと、それはまず数式を分解する／必要があって、その後は――」——数学题能马上讲解
- 0010「もう、清夏ちゃん。／まだちょっとしかやってないでしょ？」——对清夏的偷懒直接指出
- 0014「そう、だね。わたしも、日本に住む／なんて……思ってもいなかったから。」——没想到会住在日本
- 0015「しかも、清夏ちゃんと一緒の学校で、／アイドル目指してるなんて……」——和清夏同校、目标是偶像
- 0016「あの頃のわたしが知ったら、きっと／びっくりして倒れちゃうな。」——对那时的自己的玩笑式想象
- 0018「す、清夏ちゃん！／その話は、もうやめてよ……。」——对旧事（走散哭泣）害羞
- 0020「……もう、恥ずかしいってば。」——被说可爱后仍害羞

## 行为模式
- 遇到不懂的地方 → 想先自己想，被邀请才开口求助（0003、0005）
- 对方偷懒 → 直接指出“才做了一点点”（0010）
- 被提起旧事 → 慌忙阻止，最后承认害羞（0018、0020）
- 对方向她请教擅长的科目 → 很快开始讲解（0008）

## 关系
- 清夏：称“清夏ちゃん”；清夏称她“リーリヤ”。她把清夏当作同校一起做偶像的人（0015）。
