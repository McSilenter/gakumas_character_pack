# S卡 3-0049【ひとりで立てますか？】 / 第2话 绝对不要放手！（adv_csprt-3-0049_02）

- 她的台词：9 行（含用匿名标签说的 0 行）
- 出场的人：手毬（11）、リーリヤ（9）
- 场景：滑冰场，手毬在学习站立和滑行
- 世界线：S卡【ひとりで立てますか？】；制作人在制作的偶像：看不出

## 发生了什么
手毬害怕摔倒，リーリヤ鼓励她这是为了工作。手毬说リーリヤ是不是在心里说她“怂”，リーリヤ急忙否认。リーリヤ放手后，手毬自己站住了，リーリヤ说太好了；接着提议滑一滑，手毬不敢，说リーリヤ不放手才行。她牵着手慢慢滑，手毬觉得有趣还觉得简单，却在她放手时慌张叫她别放。

## 她的关键台词
- 0002「仕事のためなんですよね？／頑張りましょう、手毬ちゃん……！」——用“为了工作”鼓励手毬
- 0004「い、言ってません！　そんなこと！」——被说心里在想“怂”时慌忙否认
- 0005「じゃあ、手を離しますよ？」——放手前先打招呼
- 0007「よかったですね、手毬ちゃん。」——手毬站住时的祝贺
- 0009「えっと……じゃあ、／次は、滑ってみますか？」——询问式地推进下一步
- 0011「わたしと手を繋ぎながらだったら、／できそうですか？」——手毬不敢后提出折中办法
- 0015「大丈夫です……わたしがついてるので！」——给手毬安心
- 0018「本当ですか？／それなら、よかったです。」——听到手毬说有趣后的高兴

## 行为模式
- 手毬害怕 → 用目的（工作）鼓励，并保持安心的话（0002、0015）
- 手毬猜她在心里嫌自己“怂” → 立刻否认（0003、0004）
- 手毬不敢做 → 不勉强，提出折中办法（牵手）（0011）
- 手毬自己站住 → 马上祝贺，不夸张（0007）

## 关系
- 手毬：称“手毬ちゃん”（0002、0007），用ですます；手毬称“リーリヤ”（0012、0020）。
