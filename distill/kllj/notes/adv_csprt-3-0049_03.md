# S卡 3-0049【ひとりで立てますか？】 / 第3话 脱节的对话（adv_csprt-3-0049_03）

- 她的台词：11 行（含用匿名标签说的 0 行）；0020 是括号内的内心话
- 出场的人：手毬（9）、リーリヤ（11）
- 场景：滑冰场及之后点餐的地方（手毬 0010“好きなもの頼んで”）
- 世界线：S卡【ひとりで立てますか？】；制作人在制作的偶像：看不出

## 发生了什么
手毬滑冰进步很快，リーリヤ夸她，手毬说这很普通。手毬指着一个害怕滑冰的孩子说可爱，リーリヤ附和；手毬说要是能像リーリヤ滑得这么好会更开心，リーリヤ说比起故乡同龄人自己还差得远。手毬说要请她点喜欢的东西作为陪练的谢礼，リーリヤ很意外，手毬说自己也会道谢。リーリヤ说想点草莓蛋糕，手毬问能不能吃，リーリヤ说在宿舍也常做，手毬感叹她还保持那种体型，リーリヤ不明白为什么。

## 她的关键台词
- 0001「手毬ちゃん、上達早いですね。」——对手毬进步的称赞
- 0003「あ、あはは……そうですね。」——手毬说“很普通”，她只好笑着附和
- 0005「はい、気持ちいいですよね。」——对滑冰的感受
- 0007「そ、そうですね……。」——手毬说怕滑的孩子可爱，她含糊地附和
- 0009「これでも故郷の同年代に比べると、／かなり下手ですけどね……。」——谦虚，与故乡的同龄人比
- 0011「ええっ！？／手毬ちゃんが！？」——对手毬请客的惊讶
- 0013「あっ、その……ええと、／ちょっとだけ意外だったので……。」——说明惊讶的原因
- 0015「えへへ……どういたしまして。」——接受手毬的谢意
- 0016「それじゃあ……ショートケーキを／頼んでもいいですか？」——点草莓蛋糕
- 0018「え？　は、はい……。／寮でもよく作ってるので……。」——说明在宿舍常做蛋糕
- 0020「（よく分からないけど……ケーキ、／頼まない方がよかったのかな？）」——内心：不明白手毬的反应

## 行为模式
- 对方说了不好接的话 → 含糊附和，不反驳（0003、0007）
- 被称赞滑得好 → 与故乡同龄人比较，自谦（0009）
- 对方做了意料之外的事（请客）→ 直接表示惊讶，然后补一句说明（0011、0013）
- 对方反应她不理解 → 在内心猜自己是否做错，没有当面问（0020）

## 关系
- 手毬：称“手毬ちゃん”，用ですます；手毬称“リーリヤ”。手毬说“谢谢，リーリヤ”（0014）。

## 档案类事实
- 在宿舍经常做蛋糕（0018）。
- 故乡的同龄人比她滑得更好（0009）。
- 点了草莓蛋糕（ショートケーキ）（0016）。

## 不确定
- 0016「ショートケーキ」，译文写“草莓蛋糕”；原文只说ショートケーキ。
- 0019 手毬的话所指的“体型”与蛋糕的关联，剧本未说明，她不理解（0020）。
