# S卡 3-0054【相手にとって不足なしよ！】 / 第2话 有趣的东西就是有趣！（adv_csprt-3-0054_02）

- 她的台词：8 行（含用匿名标签说的 0 行）
- 出场的人：咲季（12）、リーリヤ（8）
- 场景：两人一起玩游戏，0019 咲季说“贵重的休息日”
- 世界线：S卡【相手にとって不足なしよ！】；制作人在制作的偶像：看不出

## 发生了什么
リーリヤ看到咲季进步很大，咲季说是因为练习和学习，格斗游戏很像体育竞技。リーリヤ说没想到咲季这么喜欢，因为一直觉得咲季是爱运动、活泼开朗的人，更喜欢在外面做的运动。咲季说无论室内室外，有趣的就是有趣。リーリヤ接受，两人开始玩。剧情经过参照 hski 笔记。

## 她的关键台词
- 0001「うわぁ～……咲季ちゃん、／すっごく上達したね。」——真诚佩服，惊讶
- 0008「……そんなに気に入って／もらえるなんて。」——没想到咲季这么喜欢
- 0010「……咲季ちゃんは、すごく運動が／得意な人で、活発で、明るくて。」——说出自己对咲季的印象
- 0011「外で運動する趣味の方が好みなんだろう／なって……意識があったから。」——说明自己有“咲季更喜欢户外”的先入观
- 0013「ふふ、それはそうなんだけど……／まだ、不思議な気持ちがあるんだ。」——承认咲季已经和自己玩了很多室内游戏，仍有不可思议的感觉
- 0016「あぁ………………」——被咲季的话触动
- 0017「そうだね。ほんとうに、そう。」——接受咲季“有趣就是有趣”
- 0020「うん……あらためて、よろしく――／咲季ちゃん。」——重新向对方打招呼，一起玩

## 行为模式
- 对方出乎意料的态度 → 坦率说出自己对对方的先入观（0010、0011）
- 被指出矛盾 → 笑着承认，说仍有不可思议的感觉（0013）
- 被简单明了的话说服 → 先发出叹息，再同意（0016、0017）
- 要一起玩时 → 用“重新请多关照”表达改变态度（0020）

## 关系
- 咲季：称「咲季ちゃん」（0001、0010、0020）；原以为咲季更喜欢户外活动，现在接受她喜欢游戏

## 档案类事实
- 把咲季看作擅长运动、活泼、开朗的人（0010）
