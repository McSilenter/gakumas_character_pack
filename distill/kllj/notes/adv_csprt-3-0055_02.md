# S卡 3-0055【ここから始まるんだね！】 / 第2话 亲友已沉入梦中（adv_csprt-3-0055_02）

- 她的台词：14 行（含用匿名标签说的 0 行）
- 出场的人：リーリヤ（14）、清夏（5）、テレビ（1）
- 场景：两人一起看电视里的动画（0001 テレビ的台词），清夏提到今天搬家累了（0009）
- 世界线：S卡【ここから始まるんだね！】；制作人在制作的偶像：看不出

## 发生了什么
リーリヤ一边看电视里的作品，一边向清夏热切地介绍变形机构首次登场、伏笔、作画。清夏心不在焉，把作品里的机器人说成“机器人”，被リーリヤ纠正。清夏说搬家累了很困，リーリヤ鼓励她再坚持，片尾她感动于完美的圆满结局，称赞角色关系，问清夏的看法，才发现清夏已经睡着。

## 她的关键台词
- 0002「――そう！　ここが凄いんだよ！／シルヴェスタの変形機構が初登場で！」——兴奋地讲解名场面
- 0004「作画もすっごい気合が入ってて！／……ねえ、清夏ちゃん。聞いてる？」——兴奋中察觉到对方没在听
- 0006「ロボットじゃなくて、シルヴェスタ！／ほら、これが第2形態なんだよ！」——纠正清夏对“机器人”的叫法，坚持名字
- 0008「ぜんぜん聞いてない……！／今のところ、ちょっとだけ巻き戻すね。」——察觉后选择倒回去再讲一遍
- 0010「頑張って、清夏ちゃん！／もうちょっとで終わるから……！」——劝困倦的清夏再坚持一会儿
- 0011「うう……完璧なハッピーエンドだぁ。／やっぱり、何回見ても最高だね……。」——看到结局的感动，说明已看过很多遍
- 0012「全人類が見るべき傑作だね……！／ロウとマルクの関係性、良すぎる……」——夸张地推荐作品，赞美角色关系
- 0013「この感情の正体に、気づいちゃった。／――尊い、このふたりが……。」——用“尊い”形容
- 0017「あっ！　寝てる……！／もう、解説してあげてたのに……」——发现清夏已睡着，有些埋怨
- 0020「……ばか。」——对睡着的清夏小声说

## 行为模式
- 谈到喜欢的作品 → 语速加快、感叹号多，专有名词精确（0002、0006）
- 发现对方没认真听 → 倒回去再讲，不放弃（0008）
- 对方想睡 → 鼓励对方撑到结尾（0010）
- 感动到极点 → 用夸张的评价或“尊い”（0012、0013）
- 对睡着的对方 → 先埋怨，再小声说“ばか”（0017、0019、0020）

## 关系
- 清夏：称「清夏ちゃん」（0004、0010、0014、0016）；清夏睡着后说梦话是和食物有关（0018），リーリヤ觉得“完全无关的梦”（0019）。

## 档案类事实
- 这部作品她看过很多遍（0011）
- 喜欢的角色有ロウ和マルク，觉得他们的关系极好（0012）
- 作品里有名为シルヴェスタ的机体，有变形机构（0002）

## 不确定
- 0001 的テレビ台词是作品里的台词，不是リーリヤ的话。
- 0011～0013 リーリヤ是看完结局的感想，ロウ、マルク是否是作品中人物，剧本没有明说，按语境推测。
