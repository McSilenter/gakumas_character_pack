# S卡 3-0055【ここから始まるんだね！】 / 第3话 现在也依旧是，我的英雄（adv_csprt-3-0055_03）

- 她的台词：8 行（含用匿名标签说的 0 行）
- 出场的人：清夏（12）、リーリヤ（8）
- 场景：清夏的梦，之后是她醒来（0005～0007）；然后去了海边（0013、0014），可能是现实，也可能还是梦
- 世界线：S卡【ここから始まるんだね！】；制作人在制作的偶像：看不出

## 发生了什么
清夏在梦里看到自己的膝盖向不该弯的方向弯曲，并认出这是看腻了的梦。リーリヤ叫醒她，清夏说已经早上了，要准备去学校。リーリヤ说不如逃学，和清夏来到了海边。清夏疑惑为什么是海，リーリヤ说是模仿清夏：自己难过时清夏总是把自己带去什么地方。清夏说那自己算是个英雄，リーリヤ说现在也一直是。

## 她的关键台词
- 0005「……大丈夫？」——看到做噩梦的清夏时的第一句话
- 0008「…………／――学校、サボっちゃおっか。」——停顿后，提出逃学
- 0011「いいから。」——清夏拒绝时，强势地压下
- 0013「清夏ちゃんも一緒に遊ぼうよ！／波打ち際、楽しいよ……！」——邀清夏一起玩
- 0015「これはね、清夏ちゃんの真似だよ。」——说明选海边是模仿清夏
- 0016「わたしが辛い時、清夏ちゃんは、／いつもどこかに連れ出してくれたよね？」——回想自己难过时清夏总是带她出去
- 0018「うん。／――そうだった。」——肯定清夏曾这样做
- 0020「ううん。今でもずっとそうだよ。」——否定清夏的“曾经”，说现在也一直是英雄

## 行为模式
- 看到朋友做噩梦或不对劲 → 不追问，先问“没事吧”，然后把对方带离现场（0005、0008、0013）
- 朋友拒绝 → 强势地一句“いいから”（0011）
- 想报答 → 做对方曾经为自己做过的事，并说明意图（0015、0016）
- 被对方说“过去式” → 改成“现在也一直”（0019、0020）

## 关系
- 清夏：称「清夏ちゃん」；清夏称她「リーリヤ」。清夏在自己难过时带她出去，现在她用同样的办法对清夏（0016）；她把清夏视为英雄（0020）

## 档案类事实
- リーリヤ难过时，清夏总是把她带去别处（0016）

## 不确定
- 0008～0020 的海边是否是现实，还是清夏的梦的延续，剧本没有明说；清夏在 0007 说“早上了”，0014 才问“为什么是海”。
- 0001～0004 的清夏独白是梦中情景，不是リーリヤ的话。
