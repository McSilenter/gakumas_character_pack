# S卡 3-0063【推し活なひととき、だね！】 / 第1话 快乐的传教活动♪（adv_csprt-3-0063_01）

- 她的台词：8 行（含用匿名标签说的 0 行）
- 出场的人：千奈（10）、リーリヤ（8）、一同（2，0007、0010）
- 场景：リーリヤ的房间（千奈 0011「いきなりお部屋にお邪魔して」）
- 世界线：S卡【推し活なひととき、だね！】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
千奈带着琥珀糖的和果子来リーリヤ的房间做客。リーリヤ拿出母亲寄来的瑞典糖果，两人一起吃，都觉得好吃。千奈问突然来房间好不好，リーリヤ说想“布教”。千奈拿出猫头鹰玩偶的兑换券，说是听紫雲说リーリヤ喜欢。リーリヤ说差一点就能兑换。千奈提出想看那部动画，リーリヤ立刻答应，约在这个周末。

## 她的关键台词
- 0001「ち、千奈ちゃん！　今日は／来てくれてありがとう……！」——开口就感谢，称「千奈ちゃん」
- 0003「わあ……！／すっごくキレイな和菓子だね！」——对礼物直接惊叹
- 0005「わ、わたしも。／最近お母さんが送ってくれた／……スウェディッシュキャンディ。」——收到礼物后也拿出自己的东西回礼
- 0008「――うん！　このシャリっとした食感、／優しい甘さがすごく美味しい……！」——细致地描述味道
- 0012「ぜんぜん大丈夫だよ！／わたしも布教したかったから！」——被问是否打扰时，说自己也想“布教”
- 0015「あ！　ミミズクのぬいぐるみが／もらえる引換券……！」——认出兑换券
- 0016「あと少しで引き換えできるんだ。／ありがとう、千奈ちゃん……！」——说明进度，道谢
- 0019「もちろんだよっ！／今週末とか、どうかなっ！」——千奈的话还没说完，就抢着答应并提出日期

## 行为模式
- 收到礼物 → 惊叹，再拿出自己的东西回礼（0003、0005）
- 被问是否打扰 → 否定并说出自己的期待（0012）
- 对方要说“想看动画” → 不等说完就接话，立刻定日子（0018、0019）

## 关系
- 千奈：称「千奈ちゃん」（0001、0016）；千奈称她「葛城さん」（千奈 0013、0014）。千奈来房间，她很开心
- 紫雲：千奈说从紫雲那里听来她的喜好（千奈 0014）；紫雲是谁剧本没明说

## 档案类事实
- 喜欢和果子（千奈 0004 说“和菓子もお好きだとうかがいまして”）
- 母亲最近寄来瑞典糖果（0005）
- 在集猫头鹰玩偶的兑换券，差一点就能兑换（0016）
- 想向千奈“布教”（推荐喜欢的东西）（0012）
