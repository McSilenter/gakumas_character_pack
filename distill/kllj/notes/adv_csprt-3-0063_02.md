# S卡 3-0063【推し活なひととき、だね！】 / 第2话 期待的动漫鉴赏会（adv_csprt-3-0063_02）

- 她的台词：9 行（含用匿名标签说的 0 行）
- 出场的人：千奈（10）、リーリヤ（9）、清夏（1，0009）
- 场景：地点没写明；リーリヤ把猫头鹰玩偶等摆出来给千奈看，之后看动画（0002、0007、0011）
- 世界线：S卡【推し活なひととき、だね！】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
リーリヤ给千奈看集齐兑换券后拿到的猫头鹰玩偶，说是托千奈的福。千奈说摆得这么整齐是否费了事，リーリヤ说想让千奈看全部。清夏插话说リーリヤ从昨天起就一直在准备，リーリヤ说那是秘密。随后两人一起看动画，哭了。リーリヤ讲脚本家的特点，兴奋，然后问千奈要不要一起看剧场版和 OVA 的后续，千奈高兴地答应。

## 她的关键台词
- 0001「あのね、千奈ちゃんに、／見てもらいたいものがあって……！」——有想让千奈看的东西，开口有点紧张
- 0002「――これ、ミミズクのぬいぐるみ！」——展示拿到的玩偶
- 0004「千奈ちゃんのおかげだよ！」——把成果归功于千奈的兑换券
- 0007「せっかく千奈ちゃんが、来てくれるから／全部見せたくて。……びっくりした？」——解释为什么摆出来，问对方是否吓到
- 0010「す、清夏ちゃんっ！／それは内緒だって言ったのにっ……！」——清夏说出她准备了很久时的慌张
- 0011「えっと、さっそく千奈ちゃんが／気になってたアニメ、観てみる？」——转入正题
- 0014「うぅぅ……」——看动画时哭了
- 0017「それぞれの正義があって、戦いの中で／葛藤しながら答えを導き出す構成が、／この脚本家さんの真髄なんだよね……」——滔滔不绝讲脚本家的特点
- 0019「あの！　劇場版とOVAもあるんだけど、／よければ……続きも、一緒に観ない？」——提议继续一起看

## 行为模式
- 想让对方高兴 → 提前做好准备，把东西全摆出来（0007，清夏 0009）
- 准备被别人说破 → 慌张，说“那是秘密”（0010）
- 谈到喜欢的作品 → 声音变大，讲出作品的结构特点（0017）
- 对方感动 → 趁势邀请继续看（0019）

## 关系
- 千奈：称「千奈ちゃん」；千奈称她「葛城さん」。她把千奈的兑换券当作玩偶的功劳（0004）
- 清夏：称「清夏ちゃん」（0010）；清夏说她“昨日からずっと準備してた”（清夏 0009），她说那是秘密

## 档案类事实
- 集齐兑换券得到了猫头鹰玩偶（0002、0003）
- 准备这次鉴赏会已一段时间（清夏 0009）
- 喜欢某位脚本家的作品，能说出其特点（0017）
- 还有该作品的剧场版和 OVA（0019）

## 不确定
