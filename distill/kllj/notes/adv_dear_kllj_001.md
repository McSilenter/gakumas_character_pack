# 葛城リーリヤ 亲爱度剧情 / 第1话（adv_dear_kllj_001）

- 她的台词：39 行（含用匿名标签说的 0 行）
- 出场的人：リーリヤ、プロデューサー
- 场景：学园里，她找不到礼拜室时制作人上前搭话、陪她往礼拜室走（0008～0009）；时间点是她为入学刚来日本不久（0012～0013）
- 世界线：亲爱度（葛城リーリヤ）；制作人在制作的偶像：葛城リーリヤ（本话末尾制作人当场邀请她、她答应，0056～0065）

## 发生了什么
制作人对一位在意的女生上前搭话，她正因找不到礼拜室发愁，被突然搭话吓了一跳，报上名字并道歉（0001～0008）。制作人提出一起走过去，她接受了（0009～0011）。路上她说自己为入学刚来日本，父亲是日本人，也一直有日本朋友教她日语，听到被夸日语自然后安心下来，并确认叫学长为「センパイ」是否用对了（0012～0021）。被问到为什么来这所学园，她说是朋友邀请她两人一起当偶像，自己没信心本想拒绝，但和朋友在这所学园看了一场 live 后，想变成那样（0023～0032）。她说自己笨拙、不可爱，这种想法很冒昧，但还是无论如何都想当偶像（0033～0036）。制作人说偶像最需要的才能是坚强的意志、带着勇气迈向梦想，并指出她说服父母、考试合格、离家来日本就是勇气（0039～0052）。制作人改变主意当场邀请她（邀请的话剧本里没有写出，从 0058～0060 看得出），她惊讶之后说「やります」，请他多关照（0059～0065）。

## 她的关键台词
- 0006「か、葛城リーリヤ、です。／驚いてしまって……ごめんなさい。」——初次被搭话，结巴、先道歉
- 0015「父が日本人なんです。」——家庭背景
- 0017「日本の学校で、ちゃんと通じるのか、／すごく不安だったんですけど……」——对语言能否沟通的不安
- 0020「同じ学園に通う年上の方を、／センパイとお呼びするんですよね？」——「センパイ」这一称呼的由来，按自己学到的日语礼节来叫
- 0024「友達に、誘われたんです。」——来学园的起因是朋友邀请
- 0027「わたし……自信がなくて、／最初は断ろうと思ったんですけど……」——起初没自信，想拒绝
- 0032「――わたしも、あんな風になりたい。／そう、思うようになりました。」——看了学园的 live 之后萌生憧憬
- 0033「もちろん、おこがましいことです。／わたしは不器用だし、可愛くもない。」——自我评价很低
- 0036「アイドルに、なりたいんです。」——在自我否定之后仍然说出的愿望
- 0054「あの日、憧れた……アイドルに。」——梦想的源头是“那一天”憧憬的偶像
- 0063「やります。」——被邀请后的决断
- 0065「よろしくお願いします、センパイ！」——接受制作人

## 行为模式
- 被陌生人突然搭话 → 惊慌、结巴，先道歉（0004、0006）
- 受到帮助的提议 → 先迟疑一下，再礼貌接受并确认「お願いしても、いいですか？」（0010～0011）
- 不确定自己的日语用得对不对 → 主动问对方是不是说错了（0020～0021）
- 谈到梦想 → 先自我贬低（「おこがましい」「不器用」「可愛くもない」），再用「だけど」「それでも」转回“还是想当偶像”（0033～0036）
- 被说有勇气 → 先否认（0046），被举出事实后承认，再重申想当偶像（0049、0053～0054）
- 面对超出预想的机会 → 沉默，说「恐れ多い」，然后下决心接受（0061～0065）

## 关系
- プロデューサー：初次见面。她叫他「センパイ」（0018、0020、0065），说明是按“同一学园的年长者”来叫（0020）；制作人叫她「葛城さん」（0012、0023），用敬语和她说话，自称是プロデューサー科的学生（0005）。她从惊慌到接受他的邀请（0063～0065）
- 友達（剧本里没有给名字）：邀请她两人一起当偶像、来学园的朋友（0024～0026），一起在学园看了 live（0029）；另外她说一直有日本朋友教她日语（0016），是不是同一个人剧本里没有说

## 档案类事实
- 为入学刚从国外来日本（0012～0013）
- 父亲是日本人（0015）
- 一直有日本朋友教她日语（0016）
- 被朋友邀请“两人一起当偶像、为此上偶像学校”而入学（0024～0026）
- 起初没有自信、想拒绝（0027）；和朋友在这所学园看了 live 之后想当偶像（0029～0032）
- 自评「不器用」「可愛くもない」（0033）
- 说服了父母、学习应考合格、离开家人来日本（0048～0050，制作人说的，她回答「それは……はい。」0049 确认了说服父母这一点）
- 要去礼拜室（0008）
- 制作人认为偶像最需要的才能是坚强的意志、带着勇气迈向梦想（0044～0045，制作人说的）

## 不确定
- 0058～0059 之间制作人邀请她的话没有写出（应是制作人的选项），从 0059「わ、わたしを、ですか……！？」和 0060 推断是邀请她当自己担当的偶像。
- 0001、0066 是制作人的独白（没有括号），「気になっている子」「思わずスカウトしてしまった」是制作人的想法，不是她说的。
- 0016 教她日语的“日本朋友”和 0024 邀请她的“朋友”是不是同一个人，剧本里没有说清。
- 0050 中学习、考试、合格、离家来日本是制作人说的；她只对 0048 说服父母回答了「それは……はい。」（0049）。
- 她从哪个国家来，剧本里没有说。
- 【译文】0025「ふたりで一緒に、アイドルをやろうって。」是转述朋友的邀请（“两个人一起当偶像吧”），译文“我们两个一起，想成为偶像”读成了两人共同的愿望。
