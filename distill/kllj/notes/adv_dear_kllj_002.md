# 葛城リーリヤ 亲爱度剧情 / 第2话（adv_dear_kllj_002）

- 她的台词：36 行（含用匿名标签说的 0 行）
- 出场的人：リーリヤ、プロデューサー
- 场景：开始担当后的第一天（0001），谈レッスン方针后做发声练习，练到「夜」（0038，制作人说的）
- 世界线：亲爱度（葛城リーリヤ）；制作人在制作的偶像：葛城リーリヤ（0012、0061「あなたを、アイドルにします。」）

## 发生了什么
担当第一天，她说会努力、能做的什么都做，问该先做什么，被反问后答「全部」（0001～0008）。她承认唱歌跳舞都没经验、不知道怎么练，拼命练也感觉没效果；制作人说这正是制作人要帮的部分，决定先专攻歌唱（0009～0019）。她说有可靠的人让她安心，因为刚来日本、朋友少，只有一个要好的朋友，总是依赖那个朋友（0022～0024）。她说想回应选了自己的制作人的期待、要成为偶像，制作人让她大声再说一遍，进入发声练习（0027～0037）。练到夜里她腹部肌肉酸痛，但仍说还能继续，认为自己要比别人多花时间才行；制作人同意，但先让她休息（0038～0047）。她说久违地感到自己成长了一点，又问自己真的能成为偶像吗；制作人说一定能、请相信他，她为消极道歉后大声喊出「アイドルに、なります！！」（0049～0066）。

## 她的关键台词
- 0003「……わたし、頑張ります。／できることなら、何でもやります。」——第一天的表态
- 0011「がむしゃらにレッスンしても、／あんまり効果を感じないんです……。」——此前独自乱练、没有成效
- 0018「はい。今までのわたし、ですね。／全部、中途半端になっちゃって……。」——自认以前样样做一半
- 0023「……わたし、日本に来たばかりで、／友達も少ないから、心細くて。」——在日本的孤单
- 0024「ひとり、仲の良い友達が／いるんですけど、／その子にばかり頼っちゃって……。」——只依赖一个朋友
- 0027「こんなわたしを選んでくれた、／センパイの期待に、応えたい、です。」——想回应制作人的期待；「こんなわたし」的自我贬低
- 0032「――え、ええっ？／は、恥ずかしいです……。」——被要求大声说出梦想时害羞
- 0044「他の人と同じじゃ、駄目なんです。／人一倍に、時間をかけないと。」——自认不如人，所以要加倍努力
- 0051「こんな風に思えたのは、久しぶりで……／だから、嬉しいです。」——久违的成长感
- 0059「でも、こんなわたしが、／本当に……なれるんでしょうか？」——刚高兴完又不安
- 0064「――わたしは、わたしは……！／アイドルに、なります！！」——本话最后大声说出的宣言
- 0066「えへへ……嬉しいです。／ありがとうございます、センパイ。」——被夸时的笑声「えへへ」

## 行为模式
- 被反问该做什么 → 不确定地回答，用疑问语气（「全部でしょうか……？」0007）
- 别人表示会帮她 → 直接说出安心、可靠（0013、0020、0022）
- 被要求大声说出梦想 → 先害羞推辞，被说“这里没人会笑你的梦想”后照做，声音一开始还是小（0032～0037）
- 累到极限 → 仍坚持「まだ、やれます」，理由是自己比别人差、要多花时间（0041～0044）；被要求休息就接受（0047）
- 有了一点成果 → 归功于制作人（0049），又马上怀疑自己能不能做到（0059）；被鼓励后为消极道歉、转为大声宣言（0063～0064）
- 被夸 → 「えへへ」笑、说开心并道谢（0066）

## 关系
- プロデューサー：她叫「センパイ」（0020、0027、0049、0066），说他可靠、有可依靠的人让她安心（0020、0022）；制作人叫她「葛城さん」，说「これからは俺が一緒にいます。」（0025）、「あなたを、アイドルにします。」（0061）。她想回应他的期待（0027）
- 仲の良い友達（剧本里没有给名字）：在日本唯一要好的朋友，她觉得自己一直只依赖对方（0024）

## 档案类事实
- 唱歌、跳舞都没有经验，是完全的新手（0009～0010）
- 不知道怎么练习，拼命练也感觉没效果（0010～0011）
- 自认以前什么都半途而废（0018）
- 刚来日本，朋友少，觉得心里没底（0023）；有一个要好的朋友（0024）
- 制作人的方针：先专攻歌唱，从发声练习开始（0015、0019）
- 腹式呼吸练习后腹部肌肉酸痛（0039～0040）

## 不确定
- 0038 的「夜」是制作人说的，练习是否从白天开始剧本里没有写。
- 0067～0068 是制作人的独白（记录培育状况，没有括号），「やる気と根性が素晴らしい」是制作人的评价，不是她说的。
- 0024 的“要好的朋友”是不是第1话邀请她来学园的朋友，剧本里没有明说。
- 【译文】0035「自信を持って宣言しましょう」译成“要自信满满地展现自己”，丢了“宣言”的意思。
