# 葛城リーリヤ 亲爱度剧情 / 第3话（adv_dear_kllj_003）

- 她的台词：29 行（含用匿名标签说的 0 行）
- 出场的人：プロデューサー、リーリヤ
- 场景：歌唱レッスン中（0001～0002 发声练习后的成果检查）；剧本里没有写地点和时间
- 世界线：亲爱度（葛城リーリヤ）；制作人在制作的偶像：葛城リーリヤ（0059～0060 制作人记录“今天的培育状况”，说的是她）

## 发生了什么
发声练习让她的音量稳定下来，她很开心；但制作人指出她的表情一直很僵（0001～0007）。被问到喜欢的偶像在台上是什么表情，她说是非常开心地笑着，自己也因此开心、得到了元气；制作人说这回轮到她给大家元气，提议练表情、唱歌时也有意识地笑（0009～0016）。她说笑很害羞，被夸笑容可爱时露出「えへへ」的笑，制作人说就是这个表情，她却说这只是「だらしない顔」（0017～0023）。她说没自信，但想接近那种闪闪发光的笑容，于是用力挤出“笑脸”，结果表情古怪，制作人忍不住笑出来（0026～0045）。她被他的笑带着也笑了，制作人说这次的笑容更好；她说大概明白了要自然、坦率的笑，打算偷偷对着镜子练（0046～0051）。

## 她的关键台词
- 0011「楽しそうに、笑っていました。／とっても、とっても、楽しそうに。」——憧憬的偶像在台上的样子
- 0012「わたしも楽しい気持ちになれました。／元気を、貰えたんです。」——偶像给了她元气
- 0017「え、笑顔、ですか。／なんだか、恥ずかしいです。」——对“笑”本身感到害羞
- 0019「…………か、かわいい？／わ、わたしが……？　えへへ……。」——被夸可爱时不敢相信又高兴
- 0021「え、ええっ？／これは、ただの、だらしない顔ですよ？」——把自己的自然笑容当成“松垮的脸”
- 0027「――でも、わたしは、／あのキラキラした笑顔に近づきたい。」——没自信但仍想接近憧憬
- 0036「す、すみません……。／見るに耐えない顔でしたか……？」——一被指出就道歉、往最坏处想
- 0046「そ、そんなに笑わないでください。／つられちゃいますから。」——被笑也不生气，自己跟着笑
- 0051「こっそり、練習してみます。／鏡の前で。」——打算私下练习

## 行为模式
- 被肯定成果 → 「えへへ」地高兴（0003）；听到“不过……”马上紧张追问（0005）
- 被问到憧憬的偶像 → 眼睛一亮（0010），说得很具体、很投入（0011～0012）
- 被夸可爱 → 先反问“我吗？”，然后忍不住笑（0019）；被说这就是好表情，又否认是好看的脸（0021、0023）
- 被要求刻意做表情 → 用力过猛，做出怪脸，自己不知道哪里不对（0031～0041）
- 被对方笑 → 不生气，说别笑了、自己也会被带着笑，随即笑出来（0046～0047、0049）
- 学到要点后 → 自己总结（0050），打算私下练习（0051）

## 关系
- プロデューサー：叫「センパイ」（0029、0041、0049、0055）；制作人叫她「葛城さん」，夸她笑容可爱（0018）、说她适合柔和的表情（0025）。被他笑了也没有不快，跟着一起笑（0046～0049）

## 档案类事实
- 她喜欢的（憧憬的）偶像在台上很开心地笑着，她从中得到了元气（0011～0012）
- 唱歌时表情一直很僵（0007，制作人说的）
- 刻意去笑时表情会变得古怪（0033～0037）
- 打算对着镜子练笑容（0051）

## 不确定
- 0059～0060 是制作人的独白（记录培育状况，没有括号），「彼女の笑顔は良い武器になる」是制作人的评价。
- 0043 制作人说她“某种意义上有给大家元气的才能”是开玩笑（指怪表情好笑），她回答方向不对（0044）。
- 0031、0039 两次挤出来的“笑脸”具体什么样，剧本只从制作人的反应看得出是古怪的（0033、0037、0040）。
