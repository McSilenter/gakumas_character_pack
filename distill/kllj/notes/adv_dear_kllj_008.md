# 葛城リーリヤ 亲爱度剧情 / 第8话（adv_dear_kllj_008）

- 她的台词：48 行（含用匿名标签说的 0 行）
- 出场的人：リーリヤ、プロデューサー、旁白（3 行）
- 场景：三段——①レッスン开始前，制作人告诉她首场 live 的日程定了（0001～0022）；②「レッスン終了、4時間後」（0023），制作人回学校取钥匙，发现她还在レッスン室独自练习，她说制作人「こんな遅くに」来（0032）；③「翌日」（0047），制作人带她去看学园偶像科学生的 live（0057「ライブ会場」）
- 世界线：亲爱度（葛城リーリヤ）；制作人在制作的偶像：葛城リーリヤ（0003「葛城さんのファーストライブです」）

## 发生了什么
制作人告诉她首场 live 的日程定了，她愣住，说自己还太早，紧张得结巴，说着「本番」就呆住了（0001～0022）。レッスン结束 4 小时后，制作人发现她还在レッスン室一个人练，嘴里说着这样不行、要更好、要把歌传到大家心里；她说坐不住、现在这样行不通，接着脚下一晃（0023～0037）。制作人让她回家，她说歌舞都还差得远；被问是不是很怕首场 live，她说身体会自己发抖，觉得现在开 live 还太早；制作人说明天放松一下，她道歉（0038～0046）。第二天制作人带她去看偶像科学生的 live，她说不相信制作人会休息、平时总是レッスン（0048～0051）。看完她很高兴，说好久没看 live，想起当初和清夏一起看学园 live 时单纯的憧憬，想站上那里、让大家有元气（0058～0079）。制作人说享受吧、这是第一次 live，她说这是自己追求的地方；她想看完回去练习被制止，听说明天起照常严格训练又高兴起来，说要为首场 live 成功努力（0083～0090）。

## 行为模式
- 突然被告知大事 → 先愣住（0004），再说自己还太早（0006），紧张得结巴、呆住（0012～0014、0022）；为紧张道歉（0015）
- 不安时 → 一个人超量加练到脚步不稳，嘴里不停责备自己（0026～0035）；被发现时先道歉（0037）
- 被劝休息 → 先说自己还差得远（0040），被直接问到恐惧时坦白（0042～0043）
- 看到台上的偶像 → 由衷赞叹，并把它和自己的初心连起来（0071、0076～0079）
- 被禁止加练 → 失望（0087）；得知明天起照常严格训练就高兴道谢（0089）
- 制作人说出和平时不一样的话 → 笑着说“果然是平时的前辈”“前辈也会开玩笑”（0064～0066）

## 关系
- プロデューサー：叫「センパイ」，说他平时“一是レッスン二是レッスン三还是レッスン”，不相信他会主动休息（0050～0051），发现他也会开玩笑（0066）；制作人叫她「葛城さん」，阻止她过度练习（0038～0039），带她去看 live（0056～0059）
- 清夏：她回忆最初是和清夏一起看学园 live、单纯地憧憬（0078）

## 档案类事实
- 首场 live 的日程定了（0003，制作人说的）；从这天起レッスン里也逐步加入舞蹈（0021，制作人说的）
- レッスン结束后独自在レッスン室加练到深夜，练到脚步不稳（0023～0037）
- 一想到首场 live 身体会发抖（0042）
- 想当偶像的契机：和清夏一起看学园的 live，单纯地憧憬（0078）
- 愿望：站上那个舞台，唱歌跳舞让大家有元气（0079）
- 好久没看 live 了（0060）
- 制作人买了 live 的票（0056）

## 不确定
- 0023、0047、0057 是没有标签的旁白（时间、地点提示），不是她的台词。
- 0024～0025 是制作人的独白（没有括号），说自己把家里的钥匙忘在学校；0091～0092 也是制作人的独白。
- 0064～0066 三句接得不顺（“今天不是来放松的吗？”“还是平时的前辈，安心了”“前辈也会开玩笑”），0074 和 0075 也类似，可能是对制作人不同选项的并列反应。
- 0032「こんな遅くに」是她说的；0023 旁白只写了“レッスン结束 4 小时后”，没有具体时刻。
