# 葛城リーリヤ 亲爱度剧情 / 第9话（adv_dear_kllj_009）

- 她的台词：29 行（含用匿名标签说的 0 行）
- 出场的人：リーリヤ、プロデューサー、旁白（1 行）
- 场景：「ファーストライブ当日」（0001），上台前和演出后在会场；具体地点没有写
- 世界线：亲爱度（葛城リーリヤ）；制作人在制作的偶像：葛城リーリヤ（0038「葛城さんの強い意志を見込んで／プロデュースを決めました。」）

## 发生了什么
首场 live 当天，她看到这么多观众，说心跳得厉害；她说一直以此为目标练习，这是梦里都见过的舞台，现在想享受它（0001～0009）。制作人说不会用“唱不好也没关系”来安慰她，她说明白，要把现在的全力展现给大家（0010～0012）。上台前她对制作人说「わたしは、アイドルになります！」「見ててください」（0017～0019）。演出后她问怎么样，说是自己的全力，又想起这里那里出了错；制作人说观众都在开心地笑，是她努力的样子传到了大家心里（0021～0028）。她说从台上看到清夏在观众席，问是否也传到了清夏心里（0029～0031）。制作人说自己曾觉得她面前的墙很高，但错了，她比想象中出色得多；她说多亏制作人，自己一个人什么都做不到，向他道谢，说今后也请多关照（0036～0049）。

## 她的关键台词
- 0005「そう、ですね……。／胸は、どきどきしてます。」——上台前承认紧张
- 0009「夢にまで見た舞台だから、／今は、楽しみたいと……思ってます。」——承接第8话的“享受”
- 0012「とにかく今の自分の精一杯を、／みんなに見せてきます。」——上台的态度
- 0017「――センパイ。／わたしは、アイドルになります！」——上台前的宣言
- 0019「――見ててください、わたしのこと。」——请制作人看着自己
- 0023「ああ、でも……あれも間違えたし、／これも間違えてたし……ううう……。」——演出后马上想到失误
- 0031「清夏ちゃんの心にも、／ちゃんと届いてくれたでしょうか？」——在意清夏
- 0044「それは、センパイのおかげです。／わたしひとりじゃ、何もできなかった。」——把成功归于制作人
- 0045「こんなわたしを、センパイが／ここまで連れてきてくれました。」——「こんなわたし」的自我贬低仍在
- 0048「はい……！／ずっと一緒に、頑張りましょう！」——对制作人的信赖

## 行为模式
- 上台前 → 承认紧张，但把目标放在“享受”“展现全力”（0005～0012）
- 制作人不说安慰话 → 她表示理解，自己说出该怎么做（0011～0012）
- 演出后 → 先问评价，说已尽全力，接着就数自己的错（0021～0023）；被指出失误马上道歉（0035）
- 被高度评价 → 归功于制作人、说自己一个人什么都做不了，郑重道谢（0044～0046）
- 心里惦记清夏 → 在台上就找到了清夏，下台后问心意有没有传到（0030～0031）

## 关系
- プロデューサー：叫「センパイ」；她说是制作人把自己带到了这里（0045），说今后也要一直一起努力（0048～0049）。制作人叫她「葛城さん」，说她比自己想的出色得多（0042）
- 清夏：她从台上看到清夏在观众席（0030，制作人说「あの子」也在 0029），在意心意有没有传到清夏心里（0031）。清夏本人没有出场

## 档案类事实
- 首场 live 举行，观众很多（0001、0003）
- 演出中有很多失误（0023、0034），但观众都在开心地笑（0026，制作人说的）
- 清夏来看了首场 live，在观众席（0029～0030）
- 首场 live 的舞台是她“梦里都见过的”（0009）

## 不确定

- 0013～0016：制作人叫她之后，她连说「はい？」「……はい！」「……分かりました！」，中间制作人的话没有写出（应是选项）。
- 0046～0049：0047「あはは、そうですよね……。／でも、これがわたしの気持ちだから。」、0048 前面制作人的话也没写出，几句可能是对不同选项的并列反应。
- 0019 之后到 0020 之间演出本身没有写出。
- 0050～0051 是制作人的独白（没有括号），“她是出色的偶像”是制作人的评价。
