# 葛城リーリヤ 亲爱度剧情 / 第11话（adv_dear_kllj_011）

- 她的台词：24 行（含用匿名标签说的 0 行）
- 出场的人：リーリヤ、プロデューサー
- 场景：制作人和她谈『NEXT IDOL AUDITION』（『N.I.A』）的方针（0001～0029），之后制作人给她拍照准备发 SNS（0032～0038）；剧本里没有写地点和时间
- 世界线：亲爱度（葛城リーリヤ）；制作人在制作的偶像：葛城リーリヤ（0020～0021 制作人为她安排活动日程、0040）

## 发生了什么
她确认下一个目标是『NEXT IDOL AUDITION』，为此要增加自己的粉丝（0001～0004）。她说想象不出自己的粉丝，会有很多有魅力的偶像参加，不知道会不会有人支持自己；制作人说至少眼前就有一个，她道谢说有了一点勇气（0005～0010）。制作人说『N.I.A』是全国规模的大会，她会被更多人看，她说光是想象就肚子痛（0011～0016）。她问怎么做才能有粉丝，制作人说照常拼命做就好；她说不太明白，但相信制作人的话，拼命是自己擅长的，虽然也只会这个（0019～0027）。制作人说她在稳步成长、现在能和其他偶像一较高下，她笑着说高兴时被制作人突然拍了照；她说发 SNS 可以，但不用突然拍，虽然害羞，为了让人成为粉丝也愿意（0028～0038）。

## 她的关键台词
- 0003「わたしのファンを／増やさないといけない……ですよね？」——自己说出目标的条件
- 0005「わたしの、ファン……。／なんだかイメージが湧きません……。」——对“有粉丝”没有实感
- 0007「その中で、わたしを応援してくれる／人がいるのでしょうか……？」——不安
- 0010「ありがとうございます。／少しだけ、勇気が出ました。」——被制作人一句话鼓舞
- 0016「は、はい……。／想像するだけでお腹が痛いです……。」——人前的不安仍在
- 0025「センパイの言葉なら、信じます。」——对制作人的信任
- 0026「一生懸命やるのは、得意です……！」——对自己长处的认知
- 0027「……それしか、できませんけど。」——马上加上自我贬低
- 0031「えへへ……嬉しいです。」——被夸时的笑
- 0035「それは構いませんけど、／いきなり撮らなくてもいいのに……。」——对制作人小小抱怨
- 0038「で、でも、／ファンになってもらうためなら……！」——为目标克服害羞

## 行为模式
- 面对更大的舞台 → 先想象不出、担心没人支持（0005～0007），想到人多就身体不适（0016）
- 得到制作人一句支持 → 马上振作（0009～0010）
- 听不懂制作人的方针 → 坦白说不太明白，但因为是制作人说的所以相信（0024～0025）
- 说出自己的长处 → 紧接着补一句“也只会这个”（0026～0027）
- 被突然拍照 → 惊叫（0033），轻轻抱怨（0035），害羞但为了目标接受（0037～0038）

## 关系
- プロデューサー：叫「センパイ」，说他的话就相信（0025）；制作人叫她「葛城さん」，说自己至少是她的一个粉丝（0008），会努力让更多人知道她的魅力（0040）。她敢对他的突然拍照小声抱怨（0035）

## 档案类事实
- 下一个目标是『NEXT IDOL AUDITION』（『N.I.A』），要增加粉丝（0001～0003）；『N.I.A』是全国规模的大会（0011，制作人说的）
- 一想到在众多人面前就肚子痛（0016）
- 自认擅长拼命努力，也只会这个（0026～0027）
- 制作人给她拍照，准备发到 SNS 让人认识她（0034）
- 能在人前唱歌了（0014，制作人说的）
