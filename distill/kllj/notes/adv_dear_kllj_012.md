# 葛城リーリヤ 亲爱度剧情 / 第12话（adv_dear_kllj_012）

- 她的台词：46 行（含用匿名标签说的 0 行）；其中 0078～0082 是她自己的心里话（括号），0040～0041、0083 是她的自言自语
- 出场的人：リーリヤ、四音、プロデューサー
- 场景：前半制作人和她看『N.I.A』的投票数（0001～0030）；后半「今日」她出演一个许多『N.I.A』上位偶像参加的活动（0031～0039），演出后被四音搭话（0042～0077）。剧本里没有写地点和时间
- 世界线：亲爱度（葛城リーリヤ）；制作人在制作的偶像：葛城リーリヤ（0064 四音说「あなたにも、プロデューサーが／ついているんですね」，她答是，0065）

## 发生了什么
制作人给她看投票数比昨天增加，最多的评价是“看她努力的样子能得到元气”，她高兴得「えへへ」（0001～0008）。制作人心里想她的票数比别的偶像少、先不告诉她；她却说猜得到他在想什么，自己知道排名很低，但比起不甘心，高兴更多，因为有这么多人喜欢、支持这样的自己（0009～0024）。制作人说对她来说粉丝不是数字，她说每一位都是重要的存在（0025～0027）。她出演一个有很多上位偶像参加的活动，上台前说这里不是自己该待的地方，演出后自言自语说完全不行（0031～0041）。白草四音过来问她名字，说没听说过、粉丝太少、今天拖了后腿、她没有才能该早点放弃；她一一道歉承认，但说即使这样也决定要当偶像（0042～0061）。四音又说她的制作人也没眼光、没才能、脑子也不好，她当场要求对方收回，说不能容忍说センパイ坏话、那不是事实；四音说两人层次不同后离开（0064～0077）。她心里想自己什么也没能反驳、无法证明；以前觉得自己没才能被说什么都无所谓，但因为自己而让センパイ受辱是不能容忍的，说「今のままじゃ、駄目だ」（0078～0083）。

- 0015「センパイが何を考えているのか、／当ててもいいですか？」——看穿制作人的沉默
- 0018「わたしの順位が低いことは、／もちろん知っています。」——自己早就看了排名
- 0020「それでも、わたしは……悔しさより、／嬉しさの方が、大きいんです。」——对排名低的态度
- 0023「こんなわたしのことを、／応援しようと、そう思ってくれた。」——对粉丝的感激
- 0026「……そう、ですよ？／ひとりひとり、大切な存在です。」——粉丝不是数字
- 0035「こんなところに／わたしがいてもいいのでしょうか……？」——在强者中间的自我怀疑
- 0041「センパイも、ガッカリしてるかな……。」——失败后先想到制作人
- 0055「……みんなの足を引っ張ったのは、／事実ですから。」——被指责时承认事实
- 0061「それでも、わたしは……／アイドルになるって、決めたんです。」——被说没才能也不退
- 0065「は、はい……！／とっても優しい人なんです。」——向外人介绍制作人
- 0071「センパイの悪口は、許せません。」——第一次对人强硬
- 0073「事実じゃないです。／だから……撤回してください。」——坚持要求收回
- 0080「（わたしには、才能がないから……／何を言われても、いいと思ってた）」——心里话：以前的想法
- 0082「（わたしのせいで、センパイが／　侮辱されるのは……許せない）」——心里话：转折
- 0083「だったら……今のままじゃ、駄目だ。」——由此下决心

## 行为模式
- 被夸“努力的样子给人元气” → 「えへへ」高兴（0008）
- 察觉制作人有话不说 → 主动点破，说自己早已知道（0015～0018）
- 面对数字上的劣势 → 把注意力放在“有人喜欢自己”上，不比较（0020～0024）
- 被人当面贬低自己 → 不反驳，道歉并承认是事实，但不放弃“要当偶像”（0050～0061）
- 被人贬低制作人 → 立刻变硬，要求对方收回、明确说不能容忍，被反驳也重复要求（0069～0073）
- 被压过之后 → 心里反省“说什么都没法证明”，把愤怒转成“现在这样不行”的决心（0078～0083）

## 关系
- プロデューサー：叫「センパイ」；对四音说他是非常温柔的人（0065），不能容忍别人说他坏话（0071）。她失败后担心他失望（0041），能看穿他的沉默（0015）。制作人叫她「葛城さん」，说自己也总从她那里得到元气（0007）
- 四音：初次见面（四音问她名字 0044）。四音用敬语但句句贬低她和她的制作人；她对贬低自己一一道歉，对贬低制作人要求收回（0050～0073）。这一话她没有称呼四音
- ファン：她说每一位粉丝都是重要的存在（0026）

## 档案类事实
- 『N.I.A』的投票数在一点点增加，但排名低（0001、0018）
- 粉丝最多的评价是“看她努力的样子能得到元气”（0005，制作人转述）
- 对她来说粉丝不是数字，每一位都重要（0025～0026）
- 出演了一个许多『N.I.A』上位偶像参加的活动，自己觉得完全不行（0031～0040）；四音说她拖了后腿，她承认（0052～0055）
- 被四音说没有才能、劝她放弃，她说自己知道，但已决定要当偶像（0059～0061）
- 以前觉得自己没才能、被说什么都无所谓（0080，她的心里话）；不能容忍因自己让制作人受辱（0082）

## 不确定
- 0009～0010、0013、0028 是制作人的心里话（括号）：票数比别的偶像少、先不说、反省自己总看数字，都是制作人的想法。
- 0078～0082 是她自己的心里话（括号），不是对人说出口的话；0083 没有括号。
- 0042 的四音没有自报姓名，这一话她的全名在第10.5话出现过（白草四音）；这一话里她是不是知道对方是谁，剧本没有写。
- 0036～0040 之间演出过程没有写出，“拖后腿”只有四音的说法（0052）和她自己的「ぜんぜん駄目だった」（0040）。
