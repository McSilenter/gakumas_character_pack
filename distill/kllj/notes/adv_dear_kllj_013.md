# 葛城リーリヤ 亲爱度剧情 / 第13话（adv_dear_kllj_013）

- 她的台词：24 行（含用匿名标签说的 0 行）；0001～0002、0029～0030 是她练习时的自言自语
- 出场的人：リーリヤ、プロデューサー、清夏
- 场景：三段——①レッスン中，制作人察觉她不对劲（0001～0028）；②制作人说过「今日はもう終わり」之后，她仍在练习被制作人撞见（0029～0041）；③她不在场，制作人去找清夏打听（0044～0056）。剧本里没有写地点和时间
- 世界线：亲爱度（葛城リーリヤ）；制作人在制作的偶像：葛城リーリヤ（0034 制作人说过今天的练习结束、0045 制作人以她的事来问清夏）

## 发生了什么
她一边喘一边自责「違う……違う違う違う」，要求自己动作更锐利、更流畅；制作人问有没有发生什么，她说没什么，拒绝休息，说就快抓住什么了（0001～0012）。她对制作人说自己以前误会了：输给别的偶像时心里总觉得没办法、大家都比自己强，但这样的心态赢不了『N.I.A』，所以要赢，下次オーディション一定合格（0015～0025）。制作人说今天到此为止之后，她还在一个人确认舞蹈动作，被制作人撞见；被问在焦虑什么，她说不想说，道歉后离开（0029～0041）。制作人去问清夏，清夏说也不知道，只知道她最近不对劲、大概在哪里偷偷练习，说她喜欢的动画电影昨天上映，邀她去被拒绝了，又说她现在的样子很像受伤前的自己，请制作人阻止她（0044～0056）。剧情经过参照 ssmk 笔记。

## 她的关键台词
- 0002「違う……違う違う違う。／もっと鋭く、もっとスムーズに……。」——独自练习时对自己的苛责
- 0006「……い、いえ？／特に何も、ないですけど……。」——隐瞒
- 0010「いえ……大丈夫です……！／まだ、やれます！」——拒绝休息
- 0012「もう少しで、何か……何か、／掴めそうなんです……！」——焦急
- 0016「わたし……勘違い、していたんです。」——要说出心态转变
- 0019「仕方ない……って。／みんな、わたしよりすごい人だから。」——以前输了时的想法
- 0021「でも、それじゃいけないんです。」——否定以前的自己
- 0024「……センパイ。／わたしは、勝ちます。」——第一次说出“要赢”
- 0025「次のオーディションも、／絶対に合格します。」——具体目标
- 0035「で、でも……もう少しだけ……！」——被叫停仍想继续
- 0039「……言いたく、ないです。」——第一次对制作人拒绝说明
- 0041「ごめんなさい……失礼します。」——道歉后离开

## 行为模式
- 心里有事 → 对制作人说“没什么”（0006），把精力全压在练习上（0002、0010～0012）
- 被劝休息 → 拒绝，说还能继续、快抓住什么了（0010～0012）
- 输给别人 → 以前觉得“没办法，大家都比我强”，这一话说这样不行，转为“要赢”（0018～0025）
- 被叫停后 → 背着制作人继续练（0029～0030），被发现时要求“再一会儿”（0035）
- 被追问原因 → 说不想说，道歉、离开（0039～0041）
- 清夏的说法：她连喜欢的动画电影都拒绝了去看（0050～0051，清夏说的）

## 关系
- プロデューサー：叫「センパイ」；这一话第一次对他隐瞒（0006）、拒绝说明原因（0039）。制作人叫她「葛城さん」，心里觉得她现在很危险（0043）
- 清夏：这一话两人没有同场。清夏对制作人说她最近不对劲、什么都不对制作人和自己说（0047、0052），拒绝了清夏看电影的邀请（0051），清夏担心她像受伤前的自己（0056）

## 档案类事实
- 喜欢某部动画，那部动画的电影昨天上映，她拒绝了清夏一起去看的邀请（0050～0051，清夏说的）
- 以前输给别的偶像时，心里觉得没办法、大家都比自己强（0018～0019）
- 这一话起说要赢『N.I.A』、下次オーディション一定合格（0022～0025）
- 制作人说过今天练习结束后，她还在偷偷练（0029～0034）

## 不确定
- 0013～0014、0028、0042～0043 是制作人的心里话（括号）：觉得她有违和感、鬼气逼人、一定发生了什么、她现在很危险，都是制作人的想法。
- 她焦急的原因这一话里没有说（她拒绝说明 0039）；按第12话应是四音贬低制作人一事，这一话本身没有提。
- 0044～0056 她不在场；清夏说的“受伤前的自己”（0056）指什么，这一话没有交代。
- 0050「リーリヤの好きなアニメの映画」没有给出动画的名字。
