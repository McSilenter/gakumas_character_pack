# 葛城リーリヤ 亲爱度剧情 / 第14话（adv_dear_kllj_014）

- 她的台词：50 行（含用匿名标签说的 0 行）；其中 0001～0004、0006～0008、0022 是她的心里话（括号）
- 出场的人：リーリヤ、プロデューサー、清夏、保健医
- 场景：「休日」（0001），「完全休養日」（0018，清夏说的）。她「こんな朝早く」（0011，清夏说的）出门，说去散步；之后在练习中扭伤脚，制作人在（大概是）レッスン室找到她（0026～0027），保健医来看；最后清夏赶来
- 世界线：亲爱度（葛城リーリヤ）；制作人在制作的偶像：葛城リーリヤ（0069「俺は葛城さんがトップアイドルに／なれると、信じています。」，0070「プロデューサーを、／――俺を、信じてください。」）

## 发生了什么
休息日她心里想：没才能的自己要超过别人就得更努力，为了证明，身体垮了也无所谓，并在心里向センパイ道歉（0001～0008）。清早她对刚醒的清夏说去散步就出门了，清夏随后想起她今天是完全休养日（0010～0019）。她一个人练到咳嗽、视线发晃，摔倒扭伤了脚，被找她的制作人发现，保健医诊断为脚踝扭伤、要静养一周（0020～0034）。制作人问她是不是说过今天休息，她道歉，说自己是坏孩子，但还是……；被要求作为惩罚说出原因，她说有人说センパイ没眼光、和自己一样没才能，自己却没能反驳，是因为自己实力不够，所以要早点让人看到センパイ发现的偶像拿出成果（0035～0052）。制作人说被嘲笑也不在乎、选她的是自己，偶像之路没有捷径、勉强反而绕远路，又说被无视指示很难过，请她相信自己；她道歉，说没考虑过センパイ的心情，说相信他（0054～0078）。清夏赶来，担心又生气地说她总是勉强、重伤可能让梦想无法实现；她道歉，说不会再一个人勉强，因为相信センパイ（0079～0096）。剧情经过参照 ssmk 笔记。

## 行为模式
- 心里认定“没才能”且有想证明的事 → 不顾休息日和指示，背着人加练，甚至觉得身体垮了也无所谓（0001～0008）
- 不想让人担心 → 对清夏撒谎说去散步（0012）
- 身体不适 → 仍要求自己更集中（0021～0022），直到受伤
- 被责问 → 先道歉、自称坏孩子（0037～0038），但马上又说“还是……”（0039）；被要求说明才说出原因（0043～0052）
- 制作人被侮辱 → 把原因归到自己实力不足，想尽快拿出成果来证明（0049～0052）
- 被说“我很难过”“相信我” → 意识到没考虑对方心情，道歉，说相信（0071～0075）
- 被朋友骂 → 不辩解，一再道歉，承诺不再一个人勉强（0085～0096）

## 关系
- プロデューサー：叫「センパイ」；这一话违背了他的指示，心里道歉（0008）。她说想证明“センパイ发现的偶像”能拿出成果（0052）；被他说难过、请相信自己后，说相信センパイ和他的话（0075）。制作人叫她「葛城さん」，说选她的是自己、不是她的错（0056），说自己也要成为配得上顶级偶像的制作人（0073）
- 清夏：她叫「清夏ちゃん」，平语；清晨两人在一处（清夏还在睡、说再睡一会儿 0013～0014），她对清夏说去散步（0012）。清夏帮制作人找她（0024～0025），之后又急又气地骂她总是勉强（0086），担心梦想会因受伤落空（0092）；她一再道歉，承诺不再一个人勉强（0094～0095）
- 保健医：诊断她脚踝扭伤（0031～0032）

## 档案类事实
- 休息日（完全休养日）清早偷偷去练习，扭伤脚踝，骨头没事，需要静养一周（0001、0018、0031～0032）
- 心里认为自己没才能，要超过别人只能更努力（0003～0004）
- 把四音（这一话没有说名字）贬低制作人的话告诉了制作人（0043～0045）
- 想尽快让人看到制作人发现的偶像拿出成果（0051～0052）
- 自称「悪い子」（0038）
- 对清夏说不再一个人勉强（0095）
