# 葛城リーリヤ 亲爱度剧情 / 第18话（adv_dear_kllj_018）

- 她的台词：13 行（含用匿名标签说的 0 行）
- 出场的人：リーリヤ、プロデューサー
- 场景：制作人告诉她要参加的オーディション是『FINALE』（0001～0002）；剧本里没有写地点和时间
- 世界线：亲爱度（葛城リーリヤ）；制作人在制作的偶像：葛城リーリヤ（0001「我々が参加する／オーディション」）

## 发生了什么
制作人说要参加的オーディション是『FINALE』，她确认白草四音也会出场，制作人说四音被传是这次的大热门（0001～0004）。她说自己看了四音的 live 视频，歌和舞都比自己好得多；说讨厌那个人，但尊敬她的技术，自己赢的可能性很低（0005～0009）。制作人说做的事和平常一样，她问平常那样能赢吗（0011～0012）。制作人说她也有胜过四音的地方：知道自己弱、知道自己不如人，所以比谁都努力，她的“平常”绝不普通；“你很弱，所以比谁都强”（0013～0022）。她道谢，说有了一点自信，会尽全力（0023～0024）。

## 她的关键台词
- 0003「あの人――白草さんも、／出場するんですよね？」——对四音的称呼
- 0005「……実は、白草さんのライブの動画を、／見てみたんです。」——会主动研究对手
- 0006「上手でした。歌も、ダンスも。／わたしなんかより、はるかに……。」——承认对手的实力
- 0007「……わたし、あの人が嫌いです。／でも、その技術は尊敬します。」——少见的直接说“讨厌”，同时尊重技术
- 0008「わたしが勝てる可能性は、／かなり低いんだと思います。」——冷静评估
- 0012「……いつも通りで、勝てるでしょうか？」——不安
- 0018「それが、わたしがあの人に／勝っている点、ですか……？」——对“弱所以强”的半信半疑
- 0023「……ありがとうございます。／少しだけ、自信が湧いてきました。」——被制作人鼓舞

## 行为模式
- 面对强敌 → 主动看对方的视频，承认对方比自己强得多（0005～0006）
- 对讨厌的人 → 明说讨厌，但把技术分开评价、表示尊敬（0007）
- 评估胜算 → 说得很低，但接着说「でも、それは――」（0008～0009）
- 被告知“照平常做” → 先怀疑能不能赢（0012），听到具体理由后道谢、有了一点自信（0018、0023）

## 关系
- 白草四音：她叫「白草さん」「あの人」（0003、0007），说讨厌她但尊敬她的技术（0007）。四音本人没有出场
- プロデューサー：这一话她没有直接称呼制作人；制作人叫她「葛城さん」，说她因为知道自己弱所以比谁都强（0016～0022）

## 档案类事实
- 要参加的オーディション是『FINALE』（0001～0002）；四音也出场，被传是大热门（0003～0004，制作人说的）
- 看了四音的 live 视频（0005）
- 讨厌四音，但尊敬她的技术（0007）
- 制作人认为她知道自己弱、不如人，所以比谁都努力，有时努力过头（0016～0017，制作人说的）
