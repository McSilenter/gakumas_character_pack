# 葛城リーリヤ 亲爱度剧情 / 第25话（adv_dear_kllj_025）

- 她的台词：39 行（含用匿名标签说的 0 行）；其中 0050、0053、0103 是括号里的心里话
- 出场的人：四音、リーリヤ、プロデューサー、旁白（0054）
- 场景：極月学園（四音 0007～0008、0057），前一话的第二天起四音指导她练习；中间跳到一个月后（旁白 0054）
- 世界线：亲爱度（葛城リーリヤ）；制作人在制作的偶像：葛城リーリヤ（剧本里没有直接说法）

## 发生了什么
她又来到極月学園请四音练习，四音说自己不是她的教练；被问怎么进来的，她说好像是センパイ和黒井理事長打过招呼，然后硬是拜托四音（0001～0012）。四音指出她基础薄弱、表演时只顾眼前、视野狭窄，她承认句句说中，并理解成要在表演中留出观察周围的余裕（0013～0026）。四音用她擅长的格斗游戏打比方，说十王星南是“传说猛犸段位”、她是“蚂蚁段位”，又要她提高自认“做得到”的部分的质量；她问四音为什么知道她擅长格斗游戏，四音说是听说的，她问“风先生”是不是她的粉丝，惹得四音发火（0029～0046）。四音一边骂一边条理清楚地教她，她心里觉得这人其实很会教（0047～0053）。一个月后，她说自己在劲敌那里完成修行、实力提升，向センパイ和「四音ちゃん」道谢；制作人说早就料到白草さん能准确指导她，并说四音曾经是好偶像、劝她别放弃自己的可能性（0055～0074）。她说自己的能力也许是“世界观”——把大家卷进以她为主角的故事的力量；四音说接近自己的看法，是一种カリスマ性、把人拉进自己世界的“魔性”，源于她天生美丽梦幻、不像日本人的容貌，制作人说这是视觉课磨练的结果（0075～0098）。她说自己在学校被说不起眼、土气，四音说那是因为不久前她在人前缩着、低着头（0094～0095）。四音说她在舞台上能营造梦幻氛围但不是随时都行，制作人说发动条件就是『燃えるシチュエーション』，她心里明白过来；她把这说成“能颠覆实力差距的最强能力”，又被四音当成挑衅（0099～0108）。她叫住要走的四音道谢，四音说别误会，下次要把她们碾碎（0111～0116）。

## 行为模式
- 被拒绝 → 不退，凭制作人的安排硬是拜托（0006、0009、0011）
- 被严厉批评 → 承认并试着归纳成具体课题（0022、0025）；被骂“垃圾”“蚂蚁段位”会惊叫，但接着说“原来如此”（0031、0037、0041）
- 对方说漏嘴 → 不设防地追问，甚至往好处想（以为“风”是她的粉丝），无意中惹恼对方（0042、0044、0046、0106）
- 对严厉的人 → 在心里看到对方的优点（0050、0053），之后当面道谢（0060、0113）
- 讲自己的进步、能力 → 用游戏、动画的说法（修業イベント、パワーアップ、最強の能力）（0055、0106）
- 被说长得好看 → 很惊讶，拿学校里的评价来反驳（0089、0094）
- 不会说清楚时 → 先试着说，再道歉“说不好”（0078～0080）

## 关系
- 白草四音：本篇她开始叫「四音ちゃん」（0060、0090、0111），对其仍用敬语；四音叫她「あなた」「図々しい女」，最后叫全名「葛城リーリヤ」（四音 0012、0114）。四音骂她“无能偶像”（四音 0023）但条理清楚地教她（四音 0049～0052），她心里觉得四音很会教（0053），并两次道谢（0060、0113）；她把自己说成在“劲敌”那里修行（0055），四音不认她是劲敌（四音 0058）
- 制作人：叫「センパイ」（0009、0060）；制作人叫她「葛城さん」（制作人 0056、0075）。制作人和黒井理事長打过招呼，让她能进極月学園（0009）
- 十王星南：四音称其为初星的『一番星』，作比较的顶端（四音 0033）；她本人没提

## 档案类事实
- 擅长格斗游戏（格ゲー），四音这样说、她本人也默认（四音 0032、0042）
- 在学校被说不起眼、土气（0094）
- 四音说她容貌美丽梦幻、不像日本人（四音 0088）；不久前在人前缩着、低着头（四音 0095）
- 一个月里在極月学園接受四音的指导（旁白 0054、0055）；制作人跟黒井理事長打过招呼（0009）
- 四音指出她基础薄弱、表演时只顾眼前（四音 0015、0018～0021），凭感觉做所以缺乏再现性（四音 0051）
- 她把自己的能力说成“世界观”，把大家卷进以她为主角的故事（0078～0079）；四音称之为カリスマ性、“魔性”（四音 0083～0084）；舞台上能营造梦幻氛围但不是随时都行（四音 0099～0100）
- 制作人说她的容貌、举止是视觉课磨练的结果（制作人 0098）

## 不确定
- 0009 她说是センパイ和黒井理事長打过招呼，用的是「みたいで」，她自己也只是听说。
- 0032 四音说「あなたが得意な格ゲー」，她在 0042 问对方为什么知道，没否认擅长；“擅长格斗游戏”这一事实的来源是四音的话。
- 0057 四音说「なぜ当然のようにいるんですか？」对象应是制作人（之后与制作人对话），不是她。
- 0050「（もしかして……この人……）」后面想说什么没说完，0053 才接上。
- 0102 制作人说的发动条件与第21话（adv_dear_kllj_021）0043 说法一致；本篇把这能力和四音说的“魔性”联系起来，是 0099～0103 的上下文读法。
