# 葛城リーリヤ 亲爱度剧情 / 第26话（adv_dear_kllj_026）

- 她的台词：36 行（含用匿名标签说的 0 行）
- 出场的人：リーリヤ、プロデューサー、清夏、ビジュアルトレーナー、旁白（0031）
- 场景：前半她向制作人交作业（0001～0031）；后半她练“必杀技”时清夏、制作人来了，之后ビジュアルトレーナー加入（0032 起）。地点本篇没写
- 世界线：亲爱度（葛城リーリヤ）；制作人在制作的偶像：葛城リーリヤ（剧本里没有直接说法）

## 发生了什么
她对センパイ说，得到四音的建议后一直在想怎么用这份力量，宣布要成为“结界系偶像”：展开结界，让被拉进她世界的观众勇气“＋10000补正”，称之为第二能力、必杀技『葛城結界』（0001～0013）。制作人心里想着答应过要多夸她、但槽点太多（制作人心里话 0016～0017），问 10000 的依据，她说数字大比较帅；她发现制作人用“温吞的眼神”看她，慌张地问自己哪里错了（0018～0022）。制作人说细节不同但和预想的答案接近，作业算完成，夸她做得好，她「えへへ」地笑，又追问“会多夸我吧”（0023～0030）；旁白说之后好好夸了她（0031）。之后她在练必杀技，对清夏说是“现实的事”，清夏吓了一跳；她向制作人说已经大致能想象展开结界了（0032～0043）。看清夏和制作人说悄悄话，她说“我不在时你们又变要好了”，制作人说不会抢走紫雲さん，她否认是那个意思（0047～0052）。制作人说要开始正式练习，ビジュアルトレーナー说有明确形象去练效果更好；她承认以前视觉课只是随便练，想到要学更有氛围的动作和ファンサ技术，说『葛城結界』要进化了，制作人说定下视觉方向就能提高结界的效果，她答应；トレーナー和清夏都听不懂两人在说什么（0055～0078）。剧情经过参照 ssmk 笔记。

- 0011「わたしの世界に惹き込んだ観客の勇気を／＋10000補正する効果があります！」——用游戏数值描述能力

- 0019「そ、それは……えっと……／数字が大きい方が、かっこよくて……」——被追问依据时的老实回答
- 0022「な、何か間違えてしまいましたか！？」——察觉制作人的眼神就不安
- 0026「えへへ……」——被夸时的笑
- 0029「たくさん、褒めてくれるんですよね？」——记着约定，主动讨夸奖
- 0036「ううん、現実の話だよ。」——认真地把“必杀技”当现实的事
- 0038「……もう、清夏ちゃんったら。／必殺技が本当に必殺なわけないのに。」——反过来觉得清夏想歪了
- 0050「わたしがいない間に、／また仲良くなったんだね……。」——看到两人亲近时的醋意

- 0063「……わたし、確かに今まで、なんとなく／ビジュアルレッスンをやってました。」——承认以前练得没有目标

- 0069「『葛城結界』が進化する！？」——把技术提升理解成“进化”

## 行为模式
- 想通一件事 → 兴冲冲地找制作人说（0001），用动画、游戏的词（结界、补正、必杀技、进化）包装（0006～0013、0069）
- 被追问细节 → 老实说出单纯的理由（0019）；察觉对方反应微妙就慌（0021～0022）
- 被夸 → 「えへへ」（0026），记着约定、主动要更多夸奖（0029）
- 别人把她的说法想歪 → 一本正经地纠正，反倒觉得对方奇怪（0036、0038）
- 看到制作人和清夏亲近 → 带醋意地说出来（0050）；被点破时急忙否认（0052）
- 被指出练习没有方向 → 承认（0063），随即自己想出需要的技术（0067）
- 被制作人当面夸可爱 → 惊叫（0073）

## 关系
- 制作人：叫「センパイ」（0001、0041），用敬语；制作人叫她「葛城さん」（制作人 0025、0053），自称「俺」（制作人 0045）。和制作人共享“结界”这套说法，旁人听不懂（ビジュアルトレーナー 0077、清夏 0078）；要制作人兑现夸奖的约定（0029）；制作人说她已经神秘、美丽、非常可爱（制作人 0072）
- 清夏：叫「清夏ちゃん」（0038）；清夏叫她「リーリヤ」（清夏 0033）。对清夏说话随意（0038）；看到清夏和制作人说悄悄话时说“又变要好了”（0050）
- 四音：叫「四音ちゃん」，说一直在想四音的建议（0002）；制作人说她的“必杀技”是受白草さん影响（制作人 0045）
- ビジュアルトレーナー：称「ビジュアルトレーナーさん」（0059），用敬语（0060）

## 档案类事实
- 她把自己的方向称为“结界系偶像”，必杀技叫『葛城結界』（0006、0013），名字还在想（0015）
- 喜欢大数字因为帅（0019）
- 平时就上视觉课，但以前练得没有明确形象（0060、0063）
- 打算学更有氛围的动作和ファンサ技术（0067）
- 制作人决定开始以确定视觉方向为目标的正式练习（制作人 0055、0074）

## 不确定
- 0031「その後、葛城さんをたくさん褒めた。」是无标签行，用的是制作人的口吻（称她葛城さん），按旁白算，不算她的台词。
- 0016～0017 是制作人的心里话。
- 清夏 0046「1か月も」是指她在四音那里练了一个月（第25话旁白 0054）还是别的，本篇没说明（ssmk 笔记同样存疑）。
- 0050 她说「また仲良くなった」，制作人回「紫雲さんは取りませんから」（0051）；她吃醋的对象是清夏还是制作人，本篇读不准，她只否认了「そういうこと」（0052）。
