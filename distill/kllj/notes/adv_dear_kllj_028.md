# 葛城リーリヤ 亲爱度剧情 / 第28话（adv_dear_kllj_028）

- 她的台词：49 行（含用匿名标签说的 0 行）
- 出场的人：リーリヤ、プロデューサー、清夏、星南（清夏 0017～0018、星南 0041～0042 像是回忆插入的片段）
- 场景：早上（0001「おはようございます」）关于冬『H.I.F』的ミーティング（制作人 0003）；地点本篇没写
- 世界线：亲爱度（葛城リーリヤ）；制作人在制作的偶像：葛城リーリヤ（0008、0010 她说センパイ发掘、制作了她）

## 发生了什么
制作人要开冬『H.I.F』的ミーティング，请她回顾现状，她像讲“前情提要”一样从头讲起：进初星学園、被プロデューサー科的センパイ发掘，基础练习、笑容练习、习惯人前的练习，第一次ライブ失误多但很开心、歌传到了最想传达的人心里（0005～0016）；接着讲『N.I.A』的营业、“稍微”乱来被センパイ骂、在『FINALE』和“宿命的劲敌”四音交战并“互相认可”、『N.I.A』优胜后夏『H.I.F』最后一名，说因为有センパイ所以不放弃，“我们的战斗才刚开始”（0020～0031）。制作人在心里对“稍微”“宿命的劲敌”“互相认可”都存疑（制作人心里话 0023、0025、0027），并说这不是被腰斩的漫画（0032）。她补充说和四音修行变强、决定和清夏组ユニット兑现约定（0036～0037）。制作人说要赢『H.I.F』三连霸的『一番星』十王星南，冬『H.I.F』已成为决定トップアイドル的大会、不再分个人和组合，以她现在的实力赢不了，只能创造奇迹，而最大的武器是和紫雲さん的ユニット本身（0038～0061）。她说自己只想着兑现约定，没想过这个组合能不能赢；制作人说定战略是制作人的事（0062～0068）。制作人说自己和紫雲さん的关系还浅，拜托她“拉清夏一把”，并说她的视觉等能力在飞速成长、不输舞蹈出众的清夏（0069～0079）。听制作人说出她对清夏说的「同じ夢を見てください」，知道是清夏去炫耀的，她喊「もう、清夏ちゃん！！」，最后说要牵着清夏的手在『H.I.F』优胜，在优胜ライブ的舞台上兑现约定，并说多亏センパイ自己变强了（0081～0090）。

## 行为模式
- 被要求回顾 → 用动画、漫画式的“前情提要”语气讲（0007～0031），把经历戏剧化（宿命的劲敌、互相认可）（0024、0026）
- 讲自己的失误、乱来 → 轻描淡写（0022）；讲败北 → 直面（0029），紧接着说不放弃（0030）
- 被吐槽 → 马上道歉（0033）
- 听到强敌、难关 → 害怕（0047、0052），但不退缩
- 被指出没想到的战略意义 → 坦白自己只顾着约定（0064～0065），把战略交给制作人（0068）
- 被说自己能力不输清夏 → 不敢相信（0080）
- 自己说过的羞人话被传出去 → 慌张、嗔怪清夏（0082、0084），随即转回正题、表决心（0085～0087）

## 关系
- 制作人：叫「センパイ」（0008、0030、0089），用敬语；制作人叫她「葛城さん」（制作人 0005、0066），自称「俺」（制作人 0070）。她说センパイ是プロデューサー科的、发掘了她并努力制作她（0008、0010）；不放弃的理由是有センパイ在（0030）；说多亏センパイ变强了（0090）
- 清夏：叫「清夏ちゃん」（0037、0084）。她回顾时说第一次ライブ的歌传到了最想传达的人心里（0016），之后插入清夏说“看了那样的ライブ，果然没法放弃”（清夏 0017～0018）；制作人心里话说那场ライブ改变了紫雲さん的心意（制作人 0019）。她答应“牵着清夏的手”去优胜（0086）；清夏把她的邀请台词拿去向制作人炫耀（制作人 0083），她嗔怪（0084）
- 四音：叫「四音ちゃん」，称其为“宿命的劲敌”，说在『FINALE』激战后互相认可了实力（0024、0026）；制作人心里存疑（0025、0027）
- 十王星南：称「十王星南会長」（0040），说上次的ライブ真的很厉害（0043）；制作人说她是『H.I.F』三连霸的『一番星』、一夜成为トップアイドル（制作人 0039、0044）

## 档案类事实
- 在初星学園被プロデューサー科的センパイ发掘（0007～0008）
- 起步时做发声、笑容、习惯人前等基础练习（0011～0012）
- 第一次ライブ在很多观众面前举行，失误多但很开心（0014～0015）
- 参加『N.I.A』，做了增加粉丝的营业，有过乱来被センパイ骂（0020～0022）；在『FINALE』和四音交战（0024），『N.I.A』优胜（0028）
- 夏『H.I.F』最后一名（0029）
- 和四音修行后，与清夏组成ユニット（0036～0037）
- 冬『H.I.F』：要战胜三连霸的『一番星』十王星南，不再分个人和组合部门（制作人 0039、0048）
- 制作人说她以视觉为首各项能力飞速成长，不输舞蹈出众的清夏（制作人 0078～0079）
- 她称十王星南为「会長」（0040）
