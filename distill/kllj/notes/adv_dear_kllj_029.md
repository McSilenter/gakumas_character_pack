# 葛城リーリヤ 亲爱度剧情 / 第29话（adv_dear_kllj_029）

- 她的台词：50 行（含用匿名标签说的 0 行）；其中 0082 前半「……ふたりは、どういう関係なの？」是她念观众的评论，不是她本人的提问
- 出场的人：リーリヤ、プロデューサー、清夏、旁白（0055）；另有「一同」1 行（0076）
- 场景：她和清夏的レッスン中，制作人带着摄影器材来（0003、0010～0011）；一周后（旁白 0055）在レッスン配信上与观众交流（0073 起）。地点是レッスン室（制作人 0015）
- 世界线：亲爱度（葛城リーリヤ）；制作人在制作的偶像：葛城リーリヤ（剧本里没有直接说法）

## 发生了什么
她和清夏在调整细节，说一开始因为单人和组合完全不同而困惑，练多了就习惯了（0001～0008）。制作人提议直播两人的练习：前几天发表了ユニット『REVERSI』，SNS 宣传视频反响好，但和别的『H.I.F』优胜候补比起来反应少，要让大家了解两人的关系、增加组合的粉丝（0010～0034）。她担心只是练习的直播会很无聊，制作人说很多人对“变得擅长的过程”有兴趣；她说被看练习有点害羞，但センパイ和清夏都这么说就努力（0036～0044）。练习中她请清夏再陪练一次，清夏担心过度练习，她说绝不勉强但想努力到极限、努力是自己的长处，清夏说“约定要实现吧，不用客气”（0045～0054）。一周后观众在增加，制作人说看到两人努力就会想支持、自己正是这样想才开直播，她「えへへ」地笑；她说评论给了自己力量，想向观众道谢，于是开了交流直播（0055～0072）。直播中清夏说两人是在她的故乡瑞典认识的幼驯染，她说不是骗人，讲了两人如何来初星、组ユニット，以及“两人一起成为偶像、总有一天一起站上那个舞台”的约定；清夏说那舞台是『H.I.F』的优胜ライブ，冬『H.I.F』优胜就是目标（0073～0095）。她说很多人会觉得这是鲁莽的挑战，她自己也一直觉得可能够不着，但那只是前提、不是放弃的理由，请大家继续看她们努力（0096～0103）。剧情经过参照 ssmk 笔记。

## 行为模式
- 面对新提案 → 先担心“会不会很无聊”（0036），说害羞（0043），但信赖制作人和清夏就答应（0044）
- 练习时 → 想多练一次，被劝时说不勉强但要努力到极限，把努力当作自己不能丢的长处（0046～0050）；对陪练的人道歉（0052）
- 得到粉丝支持 → 说从评论得到力量，主动提出向观众表达感谢（0066～0067）
- 被制作人说“看你们努力会想支持” → 「えへへ」（0064）
- 面向观众 → 紧张、结巴开场（0073～0074），之后用敬语郑重地讲两人的经历和约定（0087～0093）
- 谈目标的难度 → 先承认可能够不着（0096～0098），再说那是前提、不是放弃的理由（0099～0100）（与第19话 0038～0039 的思路相同）

## 关系
- 清夏：叫「清夏ちゃん」（0044、0046、0054）；清夏叫她「リーリヤ」（清夏 0042、0051）。两人组成ユニット『REVERSI』（制作人 0019、0076）；清夏说两人是在她故乡瑞典认识的幼驯染（清夏 0084～0085），她确认不是骗人（0086）；两人约定一起成为偶像、一起站上那个舞台（0091～0092），清夏说那是『H.I.F』的优胜ライブ（清夏 0094）。她请清夏陪练并道歉（0046、0052），清夏说不用客气（清夏 0053）
- 制作人：叫「センパイ」（0004、0062、0065），用敬语；制作人叫她「葛城さん」（制作人 0003、0019），自称「俺」（制作人 0063）。制作人来看练习她很高兴（0004）；制作人说看到她们努力会想支持（制作人 0061、0063）
- 粉丝、观众：说从评论得到力量（0066、0101），想表达感谢（0067、0077），请大家继续看她们努力（0102）
