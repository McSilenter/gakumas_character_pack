# 葛城リーリヤ 亲爱度剧情 / 第30话（adv_dear_kllj_030）

- 她的台词：25 行（含用匿名标签说的 0 行）；其中 0045 是她复述制作人以前说过的话（她 0047 说「センパイの言葉ですから」）
- 出场的人：プロデューサー、リーリヤ、清夏、ニュース
- 场景：レッスン配信让『REVERSI』上了网络新闻之后（ニュース 0001～0002、0004），三人一起看反响；地点本篇没写
- 世界线：亲爱度（葛城リーリヤ）；制作人在制作的偶像：葛城リーリヤ（剧本里没有直接说法）

## 发生了什么
『REVERSI』因レッスン配信走红、上了网络新闻，制作人念了几条好评，她「えへへ」说很高兴、有点不像自己（0001～0012）。清夏说照这势头说不定能优胜，她说没那么简单；制作人说『H.I.F』竞技性高、知名度不影响评审，她问那直播有什么意义，制作人说评审也是人、会受印象影响，她觉得有点像“钻空子”（0013～0025）。制作人说正攻法远不及十王さん的完成度，需要奇招，本质是让人了解两人的关系：知道两人的事，就会对『ときめきエモーション』里画的两人的故事产生共鸣，并把这叫作『REVERSI』的必杀技『約束の剣』，她说好帅，清夏不以为然（0026～0039）。制作人说偶像的本质不变，技术重要但光靠技术打动不了人，她接着说出“重要的是想传达的意志、展现全力的自己”，说因为是センパイ的话所以不会忘（0040～0048）。清夏说是从她那里得到了努力的勇气才会在这里；制作人列举她的武器（凛然的发声、柔和的表情、吸引人的美貌、逆境中强），说最强的武器仍是强烈的意志和鼓起勇气迈向梦想的才能，她说自己有勇气、是センパイ教她的（0049～0062）。制作人把“怕也向前走的样子让人想支持”说成『葛城結界』的原理，加上『約束の剣』和本番的『燃えるシチュ◎』就是起奇迹的条件，她兴奋地说明白了，清夏说完全不明白（0063～0073）。剧情经过参照 ssmk 笔记。

- 0045「大事なのは、届けようという意志。／精一杯の自分を見せること……ですか？」——复述制作人以前的话

## 行为模式
- 得到大量好评 → 「えへへ」地高兴，同时觉得不真实（0011～0012）
- 别人乐观 → 先提醒没那么简单（0014）；被说正攻法赢不了 → 接受（0027）
- 听到偏“策略”的做法 → 小声表示像钻空子（0025）
- 被问到制作人教过的东西 → 能准确复述，说那是センパイ的话所以不会忘（0045、0047）
- 被大夸 → 说“太夸了”（0058），但对“有勇气”这一点会肯定地接受，并归功于制作人（0062）
- 制作人用必杀技、结界之类的说法 → 兴奋、立刻接受（0037、0068、0070、0072），旁边的清夏跟不上（清夏 0039、0067、0073）

## 关系
- 制作人：叫「センパイ」（0047、0062、0072），用敬语；制作人叫她「葛城さん」（制作人 0041、0053）。珍视制作人说过的话（0047），说自己的勇气是センパイ教的（0062）；和制作人共享“必杀技”的说法（0037、0072）。制作人说她和“那时”相比成长到判若两人（制作人 0053）
- 清夏：叫「清夏ちゃん」（0052）；清夏叫她「リーリヤ」（清夏 0051）。清夏说是从她那里得到了努力的勇气才会在这里（清夏 0051），她只叫了一声清夏的名字（0052）
- 粉丝：对网上的好评很高兴（0011）

## 档案类事实
- 『REVERSI』因レッスン配信走红、上了网络新闻（ニュース 0001～0002、制作人 0006）
- 两人的曲子『ときめきエモーション』，描写两人的故事（制作人 0031、0033）
- 制作人把“让人了解两人关系、对曲子共鸣”称作『REVERSI』的必杀技『約束の剣』（制作人 0034～0035），说是想了一整晚（制作人心里话 0038）
- 制作人列举她的武器：凛然的发声、柔和的表情、吸引人的美貌、逆境中强，都是努力的成果（制作人 0056～0057）；最强的武器是强烈的意志、鼓起勇气迈向梦想的才能（制作人 0059～0060）
- 她认为自己有勇气，是制作人教她的（0062）
- 正攻法下远不及十王星南的完成度（制作人 0026）
