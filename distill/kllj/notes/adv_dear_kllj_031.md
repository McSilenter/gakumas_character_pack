# 葛城リーリヤ 亲爱度剧情 / 第31话（adv_dear_kllj_031）

- 她的台词：39 行（含用匿名标签说的 0 行）
- 出场的人：リーリヤ、清夏、プロデューサー、咲季；另有「一同」1 行（0072）
- 场景：她和清夏通过一轮『選抜試験』后制作人来报喜（0001），咲季闯入（0029）；后半她找到独自确认舞蹈的清夏（0041～0044），地点本篇没写
- 世界线：亲爱度（葛城リーリヤ）；制作人在制作的偶像：葛城リーリヤ（剧本里没有直接说法）

## 发生了什么
制作人祝贺她和清夏突破『選抜試験』，说有好消息和坏消息，她选先听坏消息：下一场『選抜試験』对手是花海咲季（0001～0008）。她说夏『H.I.F』的咲季真的在发光，最近还和会长一起练习，担心赢不了；制作人说咲季肯定会进本战，而缺少组合实绩的她们只能合格，好消息是赢下这场就能确定进本战（0011～0021）。她说和咲季同班，常一起练习，咲季是她——不，是她们的师父，正因此想赢、证明自己成长了（0024～0027）。咲季闯进来说听到了，她对咲季说尊敬对方，作为师父、朋友、偶像，但不能输，要打倒咲季进本战，咲季应战（0029～0039）。之后她找到独自练舞的清夏，问有什么烦恼，清夏说担心赢不了咲季、在拖她后腿（0041～0048）。她说现在最开心，因为能在清夏身边为约定奔跑：入学时就一直想这样，但那时实力配不上，努力追赶时清夏又放弃了偶像，所以现在像奇迹一样幸福（0050～0058）。清夏说自己也一样，她请清夏依靠她、说清夏不是一个人，清夏问能否接受真实的自己，她说当然，两人合力一定能赢咲季（0059～0067）。两人笑完才发现配信没关，一起惨叫（0068～0072）。剧情经过参照 ssmk、hski 笔记。

## 行为模式
- 好坏消息二选一 → 先听坏的（0006）
- 遇到强敌 → 先怕（0013、0017），再想起对方对自己的意义，转为“正因为尊敬才要赢、证明成长”（0026～0027）
- 当面对尊敬的对手 → 先郑重表达尊敬，再宣战（0033～0036），从敬语转成平语「勝負だよ」（0039）
- 朋友独自消失 → 去找，嗔怪找了很久（0043），直接问有没有烦恼（0045）
- 朋友说自己拖后腿 → 不讨论实力，讲自己的心情和过去，让对方知道现在对她有多珍贵（0051～0058），再请对方依靠自己（0061～0062）
- 被问能否接受真实的对方 → 毫不犹豫地说“当然”（0064）

## 关系
- 清夏：叫「清夏ちゃん」（0041、0050）；清夏叫她「リーリヤ」（清夏 0042、0059）。说入学时就想和清夏一起奔跑，但当时实力不够，追赶时清夏放弃了偶像（0054～0056）；现在在清夏身边是奇迹般幸福的时光（0057～0058）。请清夏依靠她和センパイ（0061～0062），接受真实的清夏（0064）
- 咲季（花海咲季）：叫「咲季ちゃん」（0008、0030），当面称「あなた」（0033）；咲季叫她「リーリヤ」（咲季 0031、0037）。同班，以前常一起练习（0024）；称咲季是她们的师父（0026），作为师父、朋友、偶像尊敬她（0033～0034），但要打倒她（0036）；咲季说一直在旁边看着她们成长（咲季 0031）
- 制作人：叫「センパイ」（0062），用敬语（0002、0006）；制作人叫她「葛城さん」（制作人 0001）
- 会长：提到咲季最近和会长一起练习（0012），没点名
