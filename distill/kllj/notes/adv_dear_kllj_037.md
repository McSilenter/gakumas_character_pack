- 她的台词：49 行（含用匿名标签说的 0 行）；其中 0074～0076 与 0071～0073 文字完全相同（见「不确定」）

- 场景：优胜ライブ结束后（清夏 0001，她 0003～0004）；先和清夏两人，之后她单独去见制作人（0021～0023）。地点本篇没写
- 世界线：亲爱度（葛城リーリヤ）；制作人在制作的偶像：葛城リーリヤ（0073 她说「わたしのプロデュース、／よろしくお願いします、センパイ！」）

## 发生了什么
优胜ライブ结束，她说像梦一样的舞台、一直没有实感，明明很开心却想哭，随即明白是因为梦结束了而寂寞（0001～0008）。清夏说她会有下一个梦，自己也有了新梦，以后朝各自的梦努力、互相帮助；她说和清夏一起努力的这半年一直很幸福（0009～0016）。清夏说“你有想告诉的人吧”，让她和制作人独处，她道谢后去找センパイ（0019～0022）。她告诉センパイ自己成为『一番星』了，说是センパイ把她带到这里，センパイ是配得上トップアイドル的最好的制作人；制作人道谢、流泪，她笑着说“最后笑就好是センパイ说的”，自己也被引得想哭（0028～0040）。她说一年前的自己听到会吓倒，又说也许一瞬间成了トップアイドル，但明天又会变回普通偶像，所以旅程还会继续（0043～0051）。她说梦想原本只是当偶像，都怪センパイ“唆使”才变成トップアイドル，要センパイ负责，问“会一直和我在一起吗”；制作人说当然、意思是还会找到下一个梦，她说“不对”，又说即使梦想结束也请和她在一起，制作人说人的梦想不会结束，她说“你明明懂却在装糊涂吧”（0052～0068）。制作人说等她哪天不再是偶像，换他来告诉她；她说明白了，直到那天到来，今后也请一直制作她（0069～0076）。剧情经过参照 ssmk 笔记。

## 行为模式
- 大事完成后 → 先没有实感、想哭，自己追问后才明白是寂寞（0004～0008）
- 被问下一个梦 → 简短地「うん」（0010），对一起走过的人说出“很幸福”（0015～0016）
- 见到制作人 → 先报告结果（0028），把功劳和荣誉都归给制作人（0030～0033）
- 制作人哭 → 笑着拿制作人以前的话回敬，接着自己也哭（0036～0040）
- 达成目标 → 马上说明天又是普通偶像、旅程继续（0048～0051）
- 想表达更深的心意 → 用“都怪センパイ”“请负责”撒娇式地绕着说（0053、0055），对方装糊涂时一次次追问、直接点破（0060、0062、0067～0068）
- 得到“以后再说”的答复 → 接受并把它变成新的约定（0071～0073）

## 关系
- 制作人：叫「センパイ」（0022、0030、0068），用敬语；制作人叫她「葛城さん」（制作人 0023、0065），后来称「あなた」（制作人 0069～0070）。她说是センパイ把她带到这里、センパイ是最好的制作人（0031～0033）；说梦想因センパイ从“当偶像”变成トップアイドル，要センパイ负责（0052～0055）；请センパイ一直和她在一起、即使梦想结束也是（0057、0064）；制作人以梦想不会结束来回避（制作人 0061、0066），她点破他在装糊涂（0068）；制作人说等她不再是偶像时换他来告诉她（制作人 0069～0070），她接受，请他今后一直制作她（0071～0073）。制作人看优胜ライブ时流泪（制作人 0037）
- 清夏：叫「清夏ちゃん」（0014、0025）；清夏叫她「リーリヤ」（清夏 0009、0019）。说和清夏一起努力的半年很幸福（0015～0016）；清夏说今后不能再看同一个梦，但能互相帮助（清夏 0013），并主动让她和制作人独处（清夏 0020）
