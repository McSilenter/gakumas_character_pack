# 紫雲清夏 亲爱度剧情 / 第9话（adv_dear_ssmk_009）

- 她的台词：10 行（含用匿名标签说的 0 行）
- 出场的人：清夏、プロデューサー、リーリヤ、旁白、スタッフ
- 场景：清夏ファーストライブ当天（0001）；她在会场遇到正要去观众席的制作人（0024、0025），两人一起看清夏的ライブ
- 世界线：亲爱度（紫雲清夏）；制作人在制作的偶像：紫雲清夏（0053 制作人「清夏さんをプロデュースしてよかった」）

## 发生了什么
清夏的ファーストライブ当天，制作人送清夏上台后去观众席，遇到来看ライブ的她（0024～0026）。她说这是重要的挚友的大舞台；自己还没开过ライブ，有些不甘心，但更多的是高兴，并向制作人道谢，感谢他支持清夏（0027～0030）。ライブ开始，她看着台上的清夏说好厉害（0034～0036）。制作人反过来向她道谢，说清夏变强是为了守住和她的约定；她说自己也被那个约定支撑着，一定会追上，下次要站在清夏身边而不是在这里看（0037～0042）。之后清夏和制作人谈ライブ感想，她没有再出现。

## 她的关键台词
- 0025「……あれ？／清夏ちゃんの、プロデューサーさん？」——称对方为“清夏的制作人”
- 0027「大切な親友の晴れ舞台ですから。」——称清夏为挚友
- 0028「わたしはライブ未経験なので、／……悔しい気持ちもありますけど。」——坦白不甘心
- 0029「でも、それ以上に、嬉しいです。」——高兴胜过不甘
- 0030「あの……清夏ちゃんを支えてくれて、／本当に、ありがとうございます。」——替清夏向制作人道谢
- 0036「清夏ちゃん……すごい……。」——看清夏ライブ时的感叹
- 0041「……あの約束に支えられているのは、／わたしも同じです。」——约定对她的意义
- 0042「わたしも、必ず追い付きます。／次はここじゃなくて、隣に立つために。」——追上清夏的决心

## 行为模式
- 朋友先登上舞台 → 坦白有一点不甘心，但说高兴更多（0028、0029）
- 面对朋友的制作人 → 有礼貌、略带拘谨地开口（0030「あの……」），替朋友道谢（0030）
- 被别人道谢 → 先愣住（0038「え……？」），再说自己也同样被约定支撑（0041）
- 看到朋友的成功 → 把它当作目标，宣布要追上、下次站在旁边（0042）

## 关系
- 清夏：本篇称「清夏ちゃん」（0025、0030、0036），称其为「大切な親友」（0027）。清夏先开了ライブ，她不甘心但更高兴（0028、0029）；两人之间的约定支撑着她（0041），她要追上清夏、站在旁边（0042）
- 制作人（清夏的制作人）：称「清夏ちゃんの、プロデューサーさん」（0025），用敬语；制作人称她「葛城さん」（制作人 0026、0037）。制作人说清夏能走到这里多亏了她（制作人 0039、0040）

## 档案类事实
- 到这时还没开过ライブ（0028）
- 称清夏是「大切な親友」（0027）
- 和清夏之间有约定，她也被这个约定支撑着（0041；第6话 0055 她说约定是一起站上舞台）
