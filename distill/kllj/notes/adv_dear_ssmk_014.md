# 紫雲清夏 亲爱度剧情 / 第14话（adv_dear_ssmk_014）

- 她的台词：22 行（含用匿名标签说的 0 行）
- 出场的人：清夏、四音、リーリヤ、プロデューサー、一同、友達A、友達B、クラスメイトA、クラスメイトB
- 场景：清夏一场不顺利的ライブ之后（清夏 0001）；清夏拒绝四音、制作人揭穿四音之后（0003～0049），她跑来找清夏；地点没写
- 世界线：亲爱度（紫雲清夏）；制作人在制作的偶像：紫雲清夏（0112 她称「清夏ちゃんのプロデューサーさん」）

## 发生了什么
清夏拒绝转学极月学园，制作人揭穿是四音散布传言孤立了清夏（0003～0049）。之后她跑来扑向清夏，骂清夏「ばか」，说清夏总是一个人扛、什么都不告诉她，勉强自己的是清夏不是她；清夏说不想让她看到软弱的一面，她质问这样隐瞒算什么挚友，清夏反驳她也总是乱来，两人争吵起来（0050～0068）。清夏说她相信的不是现在的自己，而是小时候练芭蕾时的『神童』，她否认，说她信的是清夏本人，脱口说出“清夏ちゃんはもっと、すごくて”时自己愣住了（0071～0083）。听清夏说一直逞强是不想让她失望，她明白过来，两人同时道歉，她说是自己的错（0084～0100）。之后清夏的朋友和同学来道歉；制作人说是她四处奔走解开了误会，她说证据是制作人收集的；清夏说以后不再隐瞒、全力依靠两人（0105～0122）。

## 行为模式
- 朋友一个人扛着不说 → 积到一定程度会爆发，直接骂「ばか」、质问是不是挚友（0053、0055、0061）
- 被反过来指出自己也乱来 → 先说“那是两回事”，坚持自己的拼命是为了追上对方（0064、0067）
- 被说“你信的不是现在的我” → 先激烈否认，说着说着发现自己的话正好印证了对方，愣住（0074、0075、0082、0083）
- 理解了对方的心情 → 立刻道歉、认为是自己的错（0094 一同、0099、0100）
- 被夸为朋友奔走 → 把功劳归给别人（0111、0112）

## 关系
- 清夏：叫「清夏ちゃん」（0050、0053、0075）；清夏叫她「リーリヤ」（清夏 0051、0060、0084）。不满清夏总一个人扛、不跟她说（0055），称两人是「親友」（0061）；清夏说她相信的是小时候练芭蕾、是『神童』时的清夏（清夏 0077、0078），清夏逞强是不想让她失望、不想被她讨厌（清夏 0085、0086）；两人吵架后同时道歉、和好（0094、清夏 0103）。清夏说以后会全力依靠她和制作人（清夏 0121、0122）
- 制作人（清夏的制作人）：称「清夏ちゃんのプロデューサーさん」（0112）。两人合作解开传言：制作人说她四处奔走解开误会（制作人 0111），她说证据是制作人收集的（0112）；看出制作人在闹别扭（0118）
- 清夏的朋友和同学：由于她的奔走，他们来向清夏道歉（0106～0111）

## 档案类事实
- 为清夏四处奔走、解开传言造成的误会（制作人 0111）
- 拼命练习是为了追上清夏（0067）
- 清夏说小时候练芭蕾、被称为『神童』（清夏 0078）；清夏说她一直相信那时的清夏（清夏 0077、0078）——这是清夏的说法，她本人先否认（0074、0075），随后自己愣住（0083）
