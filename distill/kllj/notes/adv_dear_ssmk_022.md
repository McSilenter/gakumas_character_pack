# 紫雲清夏 亲爱度剧情 / 第22话（adv_dear_ssmk_022）

- 她的台词：17 行（含用匿名标签说的 0 行）
- 出场的人：清夏、プロデューサー、リーリヤ
- 场景：トレーニングルーム（她 0040、制作人 0041）；清夏一段时间以来只做肌肉训练（清夏 0004、0043）
- 世界线：亲爱度（紫雲清夏）；制作人在制作的偶像：紫雲清夏（0010 制作人「決めたのは清夏さんですよ」、0057 让她监督清夏）

## 发生了什么
清夏厌倦了连日的肌肉训练，制作人说要用“干劲剂”，把她带来了（0001～0020）。制作人说今后一段时间她和清夏一起练习，她说想和清夏一起练，清夏只好答应认真做（0024～0037）。她问为什么在トレーニングルーム，听说是肌肉训练，主动说自己也想做；制作人说给她准备了适合她的菜单，作为陪清夏的回报，她道谢时一脸不甘，说觉得辛苦的训练才能成长，制作人说快乐努力最好（0040～0055）。制作人拜托她监督清夏别偷懒，她说清夏在抱怨的时候就会好好做，被说不愧是挚友，她说论了解清夏谁也不输（0057～0062）。她明白了清夏没参加夏『H.I.F』的原因，清夏说两人决定冬天前磨练舞蹈；她说很有觉悟，又问清夏“你还能坚持吧”，说自己也会在旁边一起努力（0064～0071）。

## 行为模式
- 被突然叫来 → 有些困惑、口吃（0020、0037），但说想和清夏一起练（0031）
- 听说训练辛苦无聊 → 反而想参加（0045）；只给她轻松的菜单时道谢但不甘心（0050、清夏 0051），理由是觉得辛苦的训练才能成长（0052）
- 被拜托监督清夏 → 笑着答应，并说清夏抱怨时反而会认真做（0058～0060）
- 被夸了解清夏 → 好胜地说这方面不输（0062）
- 清夏喊苦 → 先表示体谅，再问“还能坚持吧”，说自己也在旁边一起努力（0069、0071）

## 关系
- 清夏：叫「清夏ちゃん」（0020、0031、0060）；清夏叫她「リーリヤ」（清夏 0021、0030）。想和清夏一起练（0031）；自认最了解清夏（0060、0062）；清夏说她对自己很严（清夏 0070）；说要在清夏旁边一起努力（0071）
- 制作人（清夏的制作人）：对他用敬语（0037、0040、0050）；制作人称她「葛城さん」（制作人 0024、0036），说她是清夏的挚友、很了解清夏（制作人 0061），并为她准备了专门的训练菜单（制作人 0047）

## 档案类事实
- 认为辛苦的训练更能让人成长（0052）
- 制作人为她准备了适合她的训练菜单，作为陪清夏练习的回报（制作人 0047、0049）
- 从今天起一段时间和清夏一起练习（制作人 0024）
