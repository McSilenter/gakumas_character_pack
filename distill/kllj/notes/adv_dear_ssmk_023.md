# 紫雲清夏 亲爱度剧情 / 第23话（adv_dear_ssmk_023）

- 她的台词：27 行（含用匿名标签说的 0 行）
- 出场的人：リーリヤ、清夏、プロデューサー
- 场景：她和清夏一起练习的场所，清夏在做肌肉训练、她在练她的菜单（0001～0004）；地点没写
- 世界线：亲爱度（紫雲清夏）；制作人在制作的偶像：紫雲清夏（0011 制作人内心「葛城さんの担当ではないのに」）

## 发生了什么
她练菜单时摔倒，被制作人看到觉得难为情，说虽然辛苦但会努力；制作人内心觉得她连一半都没完成，但自己不是她的担当，不便多管，只说有事可以找他（0004～0013）。她独自叹气，清夏问她是不是沮丧，她说制作人特意做了菜单自己却完全做不好（0015～0018）。清夏说“你也来依靠我”，她坦白不知道该怎么努力、不知道这种方式对不对、感觉不到进步，请清夏帮她（0020～0030）。清夏提议让制作人也帮忙，她犹豫后说是清夏信任的人，于是拜托两人（0032～0038）。清夏用拟声词教她，她完全听不懂，清夏改用具体说法后，她做到了（0046～0061）。

## 行为模式
- 在别人面前出糗 → 笑着说难为情，再说会努力（0005、0007、0009）
- 做不好别人帮她准备的东西 → 自责，觉得辜负了对方（0017、0018）
- 被清夏说“也依靠我” → 先犹豫（0021），然后坦白迷茫，清楚地说出“帮帮我”（0025～0030）
- 要麻烦不是自己担当的制作人 → 有顾虑，以“清夏信任的人”为理由接受（0033、0037），对他用敬语（0038、0041）
- 被教得不清楚 → 不装懂，直接说听不懂（0048、0055），并给教她的清夏打气（0053）

## 关系
- 清夏：叫「清夏ちゃん」（0024、0030、0053）；清夏叫她「リーリヤ」（清夏 0016、0020）。清夏引用上次说的“全力依靠”，要她也依靠自己（清夏 0022、0023），她开口向清夏求助（0030）；清夏当她的教练（制作人 0064、清夏 0065）；对清夏的说明直说听不懂（0055）
- 制作人（清夏的制作人）：称「プロデューサーさん」（0017）、「清夏ちゃんのプロデューサーさん」（0033），用敬语；制作人称她「葛城さん」（制作人 0006），内心说不是她的担当（制作人 0011）。他做了她的训练菜单（0017），清夏提议后他也来帮她（制作人 0042、0043）

## 档案类事实
- 制作人（清夏的）不是她的担当（制作人 0011）
- 当时连训练菜单的一半都没完成（制作人 0010 内心）
- 自述只会努力，不知道该怎么努力、感觉不到进步（0026～0028）
- 清夏作为“教练”帮她练习（制作人 0064）
