# 紫雲清夏 亲爱度剧情 / 第32话（adv_dear_ssmk_032）

- 她的台词：16 行（含用匿名标签说的 0 行）
- 出场的人：清夏、リーリヤ、燕、プロデューサー、旁白、ファンA～D
- 场景：『REVERSI』在『選抜試験』上战胜燕、确定『H.I.F』本战出场（0001～0008）；之后是『REVERSI』2ndライブ（0038），清夏在台上讲述过去；她和制作人对话（0077～0084）之后来到清夏身边（0085，清夏 0086 吃惊）；地点没写
- 世界线：亲爱度（紫雲清夏）；制作人在制作的偶像：紫雲清夏（0033 制作人安排「清夏さんの秘密を告白する時間」）

## 发生了什么
她和清夏在『選抜試験』上赢了燕，确定『H.I.F』本战出场（0001～0010）。燕说小看了她、以为她没有能和清夏并肩的才能，但今天她确实在发光；她说是清夏引导了她，才能走到这里（0018～0021）。制作人提议本战前开2ndライブ、安排清夏坦白秘密，她吃了一惊（0031～0034）。2ndライブ上，清夏讲了在瑞典留学时和她相识、受伤回国、和她一起看『H.I.F』后约定一起入学并一起站上那个舞台（0044～0068），说到隐瞒的事时说不下去（0071～0075）。制作人对她说清夏能走到这里多亏了她、清夏变强是为了守住和她的约定，她说自己也被约定支撑，所以来到这里、为了站在清夏身边，随后到清夏身边说“没事，我也在，大家都是你的伙伴”（0076～0088）。清夏讲完心理阴影和克服的经过，观众鼓励清夏，她高兴得哭了（0090～0117）。

## 行为模式
- 赢了 → 先不敢相信（0002），然后和清夏一起高兴（0005、0010），接着就想练习（0029）
- 被强敌认可 → 用敬语回答，把功劳归给清夏（0021）
- 听到清夏要公开秘密 → 惊叫（0034）
- 清夏在台上说不下去 → 先察觉（0076），被制作人拜托后去到清夏身边，说“我也在”，提醒清夏观众是伙伴（0084～0088）
- 清夏得到观众鼓励 → 比清夏先哭出来（0115～0117）

## 关系
- 清夏：叫「清夏ちゃん」（0005、0021、0085）；清夏叫她「リーリヤ」（清夏 0086、0089、0116）。说是清夏引导她才走到这里（0021）；清夏在台上说在瑞典留学时交不到朋友，那时遇到她，假日和她玩（清夏 0047～0049）；两人一起看『H.I.F』后约定一起入学、一起站上那个舞台（清夏 0062～0068）；清夏说她一直相信自己，那份信任让清夏难受、假装忘了约定（清夏 0093、0094）。本篇她在台上撑住清夏（0087、0088），为清夏哭（0115）
- 燕：燕称她「葛城」，说小看了她、以为她没有和清夏并肩的才能，但今天她在发光（燕 0018～0020）；她用敬语回答（0021）
- 制作人（清夏的制作人）：制作人说清夏走到这里多亏了她，拜托她（制作人 0078、0083）；她答应（0084）

## 档案类事实
- 和清夏组成的『REVERSI』在『選抜試験』上赢了燕，确定『H.I.F』本战出场（制作人 0008、燕 0022）
- 清夏在瑞典留学时与她相识（清夏 0047、0048）
- 她来日本时和清夏一起看了『H.I.F』，清夏说她用闪闪发光的眼睛一直看着舞台（清夏 0062、0065）
- 两人的约定：一起进这所学园，总有一天一起站上那个舞台（清夏 0067、0068）
- 她被约定支撑，“为了站在清夏身边”来到这里（0081、0082）
