# 紫雲清夏 亲爱度剧情 / 第33话（adv_dear_ssmk_033）

- 她的台词：21 行（含用匿名标签说的 0 行）
- 出场的人：清夏、リーリヤ、プロデューサー
- 场景：2ndライブ之后（清夏 0003）。前半是清夏和制作人谈『一番星』（0001～0039），她不在场；后半清夏找她谈（0040 起），清夏说“正要睡觉了吧”（清夏 0078）、“深夜テンション”“近所迷惑”（清夏 0080）；地点没写
- 世界线：亲爱度（紫雲清夏）；制作人在制作的偶像：紫雲清夏（0031 制作人「清夏さんのプロデューサー」）

## 发生了什么
清夏被同学点醒：即使两人在『H.I.F』优胜，『一番星』也只有一人；清夏答应了制作人个人的“任性”，约定要成为『一番星』（0011～0039，她不在场）。清夏来对她说，优胜最优先，但自己想成为『一番星』，问她怎么想；她说自己当然也想，清夏是ユニット的伙伴也是对手，现在总被清夏拉着走，但一定要超过清夏（0040～0050）。她说有点意外，清夏不像执着『一番星』的性格，又说不用说出来、她明白；清夏说想让给了自己很多的“那个人”幸福，她笑问“是说恋爱中的少女很强吗”，说清夏这样跟直说差不多（0052～0064）。她说有点羡慕，如果自己更早遇到那个人会怎样，又说无论走哪条路都相信会通向约定，“一起向天空伸手吧”（0065～0071）。两人确认是伙伴也是对手、谁赢都不怨，她马上要去练习，大喊“要上了”，清夏说现在正要睡觉（0073～0080）。

- 0049「今は、清夏ちゃんに引っ張られてばかり／のわたしだけど……」——承认现在被清夏拉着走

- 0053「清夏ちゃんは、『一番星』にこだわる／性格には、見えないから。」——对清夏性格的看法
- 0056「……それぐらい、分かってるから。」——不用清夏说出口就明白
- 0061「ふふっ、恋する乙女は強いってこと？」——打趣清夏
- 0063「ほとんど言ってるのと同じだよ。」——点破清夏
- 0065「……ちょっとだけ、羨ましいな。」——坦白羡慕
- 0066「……もし、わたしの方が、あの人に／出会うのが早かったら、」——设想先遇到“那个人”
- 0070「どんな道を進んだとしても、／約束に続いてるって信じてる。」——相信都会通向约定
- 0071「一緒に、空に手を伸ばそう……！」——和清夏一起往上
- 0074「手を取り合いながら、競い合う。／……そういうことだよね？」——两人关系的定义
- 0079「うおおおおおお～！／やるぞ～！！」——决定后马上要练习的劲头

## 行为模式
- 被问是否想当『一番星』 → 明确说想，并说清夏是伙伴也是对手，宣布要超过清夏（0047～0050）
- 清夏有难以说出口的理由 → 说“不用说，我明白”（0055、0056），等清夏自己说出来后笑着点破、打趣（0061、0063）
- 自己的感受 → 坦白“有点羡慕”，并设想如果先遇到那个人会怎样（0065～0067）
- 确定目标后 → 马上要去练习，情绪高涨到大喊（0077、0079）

## 关系
- 清夏：叫「清夏ちゃん」（0041、0048、0053）；清夏叫她「リーリヤ」（清夏 0040、0046）。她说清夏是ユニット的伙伴也是对手（0048），现在被清夏拉着走，但一定要超过（0049、0050）；两人约定“携手竞争”、谁赢都不怨（0074、清夏 0075）；清夏说她会这么说是意料之中（清夏 0051）
- 清夏说的“那个人”（从上下文看是清夏的制作人）：清夏想让他幸福（清夏 0058～0060），她打趣清夏是恋爱中的少女（0061），说有点羡慕，设想自己如果更早遇到他会怎样（0065～0067）

## 档案类事实
- 想成为『一番星』（0047）
- 把清夏当作ユニット伙伴兼对手，要超过清夏（0048、0050）
- 和清夏约定一边携手一边竞争、谁赢都不怨（0074、清夏 0075）

## 不确定
- 0058～0060 清夏说的「あの人」本篇没点名；她 0066 也说「あの人」，从上下文看是指清夏的制作人，但没明说。
- 0065～0067 她“羡慕”的是什么（清夏有喜欢的人、还是清夏遇到了这样的制作人），以及“如果我更早遇到那个人”是什么意思，本篇没说清；清夏回答说可能和现在差不多（清夏 0068）。
- 0055～0056 她说“明白”的是清夏想当『一番星』的理由，清夏随后才说出来（0058～0060），她事先具体明白了什么，本篇没写。
