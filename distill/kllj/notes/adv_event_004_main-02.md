# 活动 004 学生会的偶像们 / main-02 夏夜FACE OFF 第2话（adv_event_004_main-02）

- 她的台词：21 行（含用匿名标签说的 0 行）
- 出场的人：咲季、ことね、リーリヤ、清夏（只在 0002 出声）
- 场景：夏祭り会场，人群中与清夏、手毬走散，在屋台玩游戏
- 世界线：活动 004；制作人在制作的偶像：看不出

## 发生了什么
人群中清夏拉着她的手后分开，她找不到清夏，想去找。咲季说回头找不合理，只想和她比赛，让她选游戏；她选了輪投げ，一个都没投进，输了。ことね教她开ラムネ，她第一次见到弹珠。咲季要接着比射的，她不知道射的是什么；ことね替她说话，咲季决定先教她再比，她向两人道谢并接受挑战。剧情经过参照 hski 笔记。

## 她的关键台词
- 0003「す、清夏ちゃん……！」——被冲散时第一反应是叫清夏
- 0007「清夏ちゃん、どこ……！？」——找不到清夏时的慌张
- 0012「わ、わたしは……／探しに行きたい、です。」——在咲季强势的主张下，仍说出想去找人
- 0021「そ、そんなこと言われても……」——被咲季要求立刻选游戏时的为难
- 0024「じゃあ…………わなげで…………」——被逼着选，小声选了輪投げ
- 0028「ひ……ひとつも入りませんでした……」——输得很彻底
- 0031「ありがとうございます……／これがラムネなんですね。」——对ことね道谢，是第一次见到ラムネ的反应
- 0036「こ、これ、ビー玉なんですか……！？」——对弹珠的惊讶
- 0039「あ、はい……／負けちゃいました。」——被咲季叫到，才想起输了的结果
- 0050「でも……しゃてきって、なんですか？」——不知道射的是什么
- 0058「あ、あの……わたしは大丈夫です。」——ことね激咲季时，她替咲季说话
- 0074「ふ、藤田さん……。／ありがとうございます……！」——感谢ことね替她争取汇合的机会
- 0075「あのっ……！／花海さん、よろしくお願いします！」——主动应战，鼓起勇气

## 行为模式
- 和朋友走散 → 立刻叫对方名字，想去找人，哪怕对方强势反对也会说出来（0003、0007、0012）
- 被强势要求立刻决定 → 先结巴为难，然后小声选一个（0021、0023、0024）
- 遇到没见过的事物（ラムネ、弹珠、射的） → 直接说不知道、问怎么用（0031、0032、0036、0050）
- 有人替她出头 → 反而担心对方被说得难受，说自己没关系（0058）
- 被帮助之后 → 用姓加「さん」认真道谢，并主动说“请多关照”（0074、0075）

## 关系
- 清夏：叫「清夏ちゃん」；走散后第一反应是找她（0003、0006、0007）。
- 咲季：叫「花海さん」（0075）；被她当作要赢的对手，也答应了她的教学（0065、0075）。
- ことね：叫「藤田さん」（0074）；被她安慰、教开ラムネ、帮着争取汇合（0030～0036、0074）。

## 档案类事实
- 第一次逛日本的祭典（ことね说，0052）；不知道ラムネ的开法、不知道射的（0032、0050）。
- 輪投げ一个也没投进（0028）。
