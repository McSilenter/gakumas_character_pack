# 活动 004 学生会的偶像们 / main-03 夏夜FACE OFF 第3话（adv_event_004_main-03）

- 她的台词：14 行（含用匿名标签说的 0 行）
- 出场的人：咲季、ことね、リーリヤ
- 场景：夏祭り会场的射的屋台，清夏、手毬还没汇合
- 世界线：活动 004；制作人在制作的偶像：看不出

## 发生了什么
咲季教她射的，她按咲季指出的问题（闭眼、用力过猛）一局一局改，说想赢了去和清夏汇合。第一局之后只中一次，后面越来越准，ことね夸她进步很快，但第三局仍然差一点输给咲季。比赛后咲季还要继续教，ことね提议先汇合，咲季改成边玩边找，她回答“请全部教我”。剧情经过参照 hski 笔记。

## 她的关键台词
- 0003「は……はいっ！」——被咲季教的时候照做
- 0012「勝ったら、清夏ちゃんと合流……」——自己把比赛目标放在汇合上
- 0013「が、頑張りますっ！」——表明要全力应战
- 0014「あぁ～……」——第一局失败时的反应（没有多说）
- 0024「わ、わかりました……」——被指出射击时闭眼，接受
- 0025「次は、もっと……当てます！」——听到指出的问题后，说下一次要更准
- 0027「さ、さっきより当たりました！」——自己确认进步，带着喜悦
- 0029「はいっ！／力まないように……ですね！」——记住了咲季教的要点并复述
- 0032「そ、そうですか？」——被ことね夸的时候不敢相信
- 0039「あとちょっとだったのに……」——输后的遗憾
- 0043「ほ、ほんとですか……？」——对ことね说她进步很快，追问确认
- 0054「はいっ！／全部教えてくださいっ！」——主动请咲季继续教，表明想学

## 行为模式
- 被指出缺点 → 老实回答“明白了”，并把要点用自己的话复述一遍（0024、0025、0029）
- 取得小进步 → 马上自己报告出来，语气带喜悦（0027）
- 被夸 → 先不敢相信，再追问是不是真的（0032、0043）
- 输了 → 不找借口，只说“差一点”（0039）
- 有人愿意继续教 → 主动答应继续，不避开比赛（0054）

## 关系
- 咲季：被她称为「葛城リーリヤ」；她接受咲季的指导，没有直呼其名（本篇没有叫咲季的台词）。
- ことね：被叫「リーリヤちゃん」；被她夸奖、照顾（0031、0042、0044）；她本篇没有直接称呼ことね。
- 清夏：目标是和她汇合（0012）。

## 档案类事实
- 射的第一局只中一次，后面逐局提高，最后第三局差一点赢（0015、0027、0039）。

## 不确定
- 0035「そ、そんな……でも……」与 0038「うっ……そんな……」，译文把前者译成“不可能”，原文语气更像“怎么会……可是……”，具体是否在谦虚推辞剧本没说明。
- 0014「あぁ～……」前后的比赛过程无台词，“只中一次”由ことね 0015 说出。
