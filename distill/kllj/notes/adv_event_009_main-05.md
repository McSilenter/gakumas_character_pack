## 发生了什么
她在摊位对客人声音太小，被ことね提醒。佑芽的蛋糕被咲季称赞，她对佑芽说“是你努力的成果”。清夏来买蛋糕，她在清夏面前说“宿舍里也做给你了”，叮嘱别吃太多。她对清夏说自己给ことね和佑芽添了麻烦，但和两人变亲近，所以参加很好。结束后在吃蛋糕时，她约佑芽下次一起做点心。剧情经过参照 hski、hume 笔记。

## 行为模式
- 被指出声音小 → 小声问效果，不自信，需要ことね鼓励（0006）
- 别人感谢自己 → 把功劳让回对方（0021）
- 对亲近的清夏 → 说话直接，有点唠叨：叮嘱别吃太多、指出她总是同样的话（0028、0030）
- 对清夏认真说出心里话 → 坦白添麻烦的同时，说“和两人变亲近所以参加很好”（0047、0048）
- 被调侃 → 叫清夏的名字害羞地阻止（0053）
- 被问未来想法 → 先认同“好玩”，再回到“要成为偶像”（0063）
- 自己主动提出邀请 → 对佑芽提出下次一起做点心（0068）

## 关系
- 清夏：称“清夏ちゃん”（0026、0053）；清夏称她“リーリヤ”（0031、0049）；在宿舍给清夏做点心（0028）
- ことね：称“ことねちゃん”（0047）；认为自己给她添了麻烦，也因她而和佑芽亲近（0047、0048）
- 佑芽：称“佑芽ちゃん”；功劳让回佑芽（0021），主动邀约（0068）
