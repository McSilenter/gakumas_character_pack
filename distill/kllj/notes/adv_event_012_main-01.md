# 活动 012 手毬与广的日常 / main-01 樱花飞舞的起跑线 第1话（adv_event_012_main-01）

- 她的台词：17 行（含用匿名标签说的 0 行）：0004、0006、0008、0010、0015、0017、0020、0024、0027、0033、0040、0042、0043、0044、0052、0053、0059
- 出场的人：咲季、清夏、リーリヤ
- 场景：为地域振兴活动的迷你Live做练习，レッスン结束时；中途聊起入学当初的事。
- 世界线：活动 012；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
练习结束后，リーリヤ还想再练，被咲季以“乱来只会增加受伤风险”为由制止，清夏也劝她。咲季订正说自己不会觉得她倒下是麻烦，因为她是临时团体的队长，但作为朋友会担心。之后三人聊起咲季变得更合群，回忆入学时班级气氛不好、咲季的练习让人佩服。リーリヤ说自己当时一直只能看着咲季的背影，也说咲季总在她们困难时帮忙。结束时咲季让她们全力休息。
剧情经过参照 hski 笔记。

## 她的关键台词
- 0004「はぁ、はぁ……／も、もう少しだけ、お願いします……！」——练习已到极限，还请求再多练一会儿，用敬体向咲季恳求。
- 0006「できてないところがあって……」——坚持的理由：有做不好的地方。
- 0008「じゃあ、わたしだけで……」——被咲季说“今天结束”后，退一步说自己一个人练。
- 0015「……えっと、イベント運営の人たちに、／一緒に踊る、咲季ちゃんたち……？」——被问“麻烦的是谁”时，认真地一个个想，列出的是运营方和同伴。
- 0020「う、うぅ……ごめんなさい。／気を付けます。」——被清夏说“粉丝会担心”后立刻道歉。
- 0027「……ありがとう、ふたりとも。」——听到咲季和清夏说会担心后，道谢。
- 0033「最初はクラスの雰囲気、／あんまりよくなかったもんね。」——回忆入学当初班级气氛不好。
- 0040「……うん。わたしも、／ついていけるかなって、不安だった。」——承认自己第一次看到咲季的练习时也不安。
- 0043「咲季ちゃんは、その人たちを／すぐに追い抜いていって……」——说咲季很快超过了内部进学组的人。
- 0044「わたしはずっと、その背中を、／見てるだけだったな。」——说当时自己只是看着咲季的背影。
- 0052「で、でも！　咲季ちゃんは／わたしたちを手伝ってくれてるし……」——清夏说咲季“协调性不足”时，慌忙替咲季辩护。
- 0053「困ってる時は、助けてくれる。」——补一句理由：咲季会在困难时帮忙。

## 行为模式
- 练习没做好 → 请求再练，被拒后退一步说“我一个人练”（0004、0006、0008）。
- 被指出会给别人添麻烦 → 想一想后回答具体的人，并马上道歉、改口“会注意”（0015、0020）。
- 被朋友关心 → 道谢（0027）。
- 别人开玩笑说咲季的坏话 → 急着插话替她说话（0052、0053）。
- 聊到过去 → 用“不安”“只能看着背影”表达自己和咲季的差距（0040、0044）。

## 关系
- 咲季：叫她「咲季ちゃん」（0024、0043、0052），对咲季用敬体请求（0004）；咲季叫她「リーリヤ」，管着她的身体（0009）。
- 清夏：这一篇没有直接叫她；清夏叫她「リーリヤ」（0005、0026）。
