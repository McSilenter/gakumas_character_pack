- 她的台词：22 行（含用匿名标签说的 0 行）：0004、0006、0017、0020、0022、0024、0035、0040、0045、0050、0054、0057、0059、0061、0063、0064、0066、0068、0069、0070、0072、0075
- 出场的人：清夏、咲季、リーリヤ、佑芽、一同

## 发生了什么
咲季宣布今天起三个人一起练习，リーリヤ不知道为什么清夏也在。清夏被咲季带到一旁争论，咲季说“リーリヤ也察觉到了”，清夏于是决定告诉リーリヤ（リーリヤ回答“嗯”）。练习中清夏跳不下去，咲季让她休息；佑芽来向咲季挑战，咲季让她先打败リーリヤ。清夏休息后，她向咲季确认迷你Live的曲子是咲季选的并道谢，又说自己要是早点向清夏伸手就好了，咲季说现在也不迟，清夏需要她的力量，她充满干劲地喊着要努力，结果发烧倒下了。
剧情经过参照 hski、hume 笔记。

## 行为模式
- 不明白状况 → 用问题直接问（0004、0006、0017）。
- 被挑战 → 紧张地接受，用“不会输”回应（0040）。
- 被朋友为清夏做事所感动 → 道谢，并指出对方的行为（0059、0061）。
- 感到自己没帮上忙 → 说出后悔（0064），被告知“现在也不迟”后立刻干劲十足（0069-0072）。
- 干劲上头 → 大喊、行动过度，最后发烧倒下（0072、0075，咲季 0077）。

## 关系
- 咲季：叫她「咲季ちゃん」（0059、0061），对咲季用敬体（0004）；咲季称她“弟子”（咲季 0003、0034），把清夏的事交给她（咲季 0083）。
- 清夏：叫她「清夏ちゃん」（0004、0045、0075）；清夏说“リーリヤが隣で頑張っててくれる”（清夏 0047）。
- 佑芽：叫她「佑芽ちゃん」（0040）；佑芽叫她「リーリヤちゃん」（佑芽 0039）。
