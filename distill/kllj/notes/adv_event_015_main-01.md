# 活动 015 / 巡演活动 广岛篇 第1话（adv_event_015_main-01）

- 她的台词：16 行（含用匿名标签说的 0 行）。其中 0029～0032 是括号里的内心独白
- 出场的人：莉波、リーリヤ、千奈
- 场景：莉波向千奈提出广岛unit live的场面之后，リーリヤ出场；她的回想/场面里在布告栏前看招募海报，具体地点看不出
- 世界线：活动 015；制作人在制作的偶像：看不出

## 发生了什么
莉波邀请的第三位成员是リーリヤ，她之前在布告栏前看招募的海报时被莉波搭话。她得知是3年级生和两位1年级生的unit live，心里想这是让别人看到练习成果的机会，但担心能不能好好和3年级前辈说话，想到可以和清夏一起，又觉得总是依赖清夏。被莉波叫了一声吓到后，她问引率的是不是姫崎センパイ，犹豫了一下，回答「興味、あります！」。之后向千奈问好。

## 她的关键台词
- 0022「……よろしく、お願いします！」——出场时的第一句，对莉波和千奈打招呼
- 0026「……か、かけられましたっ。」——被问起被搭话的事，生硬地照莉波的话回答
- 0029「（レッスンの成果を見てもらえる、／チャンスかも……だけど）」——内心：把它当作展示练习成果的机会，但立刻有保留
- 0030「（わたし、3年生のセンパイと、／ちゃんとお話しできるかな……？）」——内心：担心能不能和3年级的前辈好好说话
- 0031「（そうだ！／清夏ちゃんと一緒なら……）」——内心：想到和清夏一起
- 0032「（……でも、いつも清夏ちゃんに／頼ってばかり、だから……）」——内心：立刻否定，因为总依赖清夏
- 0034「ひゃあっ？」——被突然叫名字吓到
- 0038「ええと……は、はい。」——被问是否有兴趣，犹豫地承认
- 0043「……――」——决断前的沉默
- 0044「はい。興味、あります！」——说出自己的想法，加入
- 0048「こちらこそ、よろしくお願いします。」——对千奈的回应

## 行为模式
- 遇到机会 → 先想到“可以让别人看到成果”，但立刻想到自己的短处，担心和人说话（0029、0030）
- 不安时 → 先想到清夏，再因为总是依赖她而放弃（0031、0032）
- 被问到是否有兴趣 → 先犹豫，沉默一下，再明确说“有兴趣”（0038、0042、0043、0044）
- 被点名或突然被叫 → 吓一跳（0034）
- 对新认识的人 → 用敬语回应（0048）

## 关系
- 莉波：称「姫崎センパイ」（0035、0039）；莉波叫她「リーリヤちゃん」（0033）
- 千奈：莉波介绍时是班级不同的搭档；千奈叫她「葛城さん」（0047），她回应「こちらこそ、よろしくお願いします」
- 清夏：叫「清夏ちゃん」（0031），自己有总依赖她的自觉（0032）
