- 她的台词：17 行（含用匿名标签说的 0 行）
- 出场的人：莉波、リーリヤ、千奈（スタッフ 0003、0004；一同 0053 不计）

## 发生了什么
三人在会场看舞台，リーリヤ觉得能比想象的更宽地使用舞台，提议把动作和fan service做大，让最后一排的观众也看得见。逛广岛城时，她以为日本的城里住的是家康，被莉波纠正，说要更努力学习日本历史，被莉波建议放进MC，害羞。在城里她对日本刀和铠甲的展示很感兴趣，说起『スター・サムライ』。吃御好烧时说它是“日本的キッシュ”，吃多了。

## 行为模式
- 想到可以改进的地方 → 吞吞吐吐但具体地向前辈提议，并说明理由是“让最后一排也能看见”（0009～0013）
- 被纠正误解 → 一边吃惊一边反省，要多学习（0027、0028）
- 被要求在MC里讲自己的误解 → 害羞（0030）
- 遇到自己喜欢的话题（刀、『スター・サムライ』）→ 眼睛发亮，开始说明，被打断也不停（0038、0039、0041）
- 遇到新食物 → 用瑞典的食物来比喻（0043）
