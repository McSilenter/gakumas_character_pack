# 活动 015 / 巡演活动 广岛篇 第4话（adv_event_015_main-04）

- 她的台词：17 行（含用匿名标签说的 0 行）。0017 之后的大部分是舞台上做MC时说的话（0043 是与观众互动的喊话）
- 出场的人：莉波、千奈、リーリヤ（一同 0015、0071 不计）
- 场景：旁白「ライブ当日」，广岛live的后台和舞台上
- 世界线：活动 015；制作人在制作的偶像：看不出

## 发生了什么
live前十分钟，リーリヤ说自己紧张，被千奈安慰。她对live前叠手这件事说一直憧憬。舞台上，她介绍『初』是初星新生最先挑战的课题曲，聊到上午去了フィーカ，向莉波说明这是瑞典的习惯，被千奈用御好烧岔开；又说她以前以为日本的城都有家康住。预定的曲子没响时，她吃惊；千奈带头唱当地的歌后，她发现音响恢复。

## 行为模式
- 本番前 → 说出自己紧张，对叠手这样的小仪式表示憧憬（0004、0013）
- 说到擅长或熟悉的话题 → 一句一句地认真说明，不太停顿（0024～0029）
- 同伴偏题 → 圆场，不当面纠正（0032）
- 突发事态 → 先愣住（0057），被提示后迅速反应过来（0061），事后冷静指出故障已排除（0067）
