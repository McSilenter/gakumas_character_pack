# 活动 015 / 巡演活动 广岛篇 第5话（adv_event_015_main-05）

- 她的台词：11 行（含用匿名标签说的 0 行）。0003 是舞台上与观众互动的喊话
- 出场的人：莉波、千奈、リーリヤ（一同 0008、0048 不计）
- 场景：广岛live的舞台上（昼场末尾），之后live结束，午饭、夜场前的休息时间，在红叶行道树前
- 世界线：活动 015；制作人在制作的偶像：看不出

## 发生了什么
舞台上，莉波带头喊“哎~才刚来吗~”的互动，她跟着复述。live结束后，她说“よかった”，对莉波说她在故障时很冷静，自己能自由发挥是托她的福。午饭后她想在寮里办御好烧派对。在红叶行道树下，她说从没见过这么红的行道树，瑞典森林多是黄叶，提议拍照发到SNS，说是清夏说的。

## 行为模式
- 事后 → 简短说出“よかった”，再向前辈具体表达观察到的事和感谢（0011、0016、0017）
- 想到想做的事 → 小心翼翼地提出（0028）
- 感到新鲜 → 把眼前的景象和家乡对比（0034、0036）
- 提议时 → 先说“せっかくなので”，并说明理由来自清夏（0038～0040）
