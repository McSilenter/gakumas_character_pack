# 活动 020 / main-03 第3话（adv_event_020_main-03）

- 她的台词：26 行（含用匿名标签说的 0 行）
- 出场的人：清夏（38）、リーリヤ（26）
- 场景：购物中心，逛店（不买，看趋势）
- 世界线：活动 020；制作人在制作的偶像：看不出

## 发生了什么
两人在购物中心做橱窗购物。清夏推荐化妆品，リーリヤ听不懂；清夏讲了自己学会时尚的经过。选衣服时清夏说“想着喜欢的人来选”，还被リーリヤ追问喜欢的类型。清夏描述了理想对象后反问，リーリヤ也说有喜欢的人，结果是少女漫画原作动画『愛するキミをプロデュース』里的角色。

## 行为模式
- 遇到不熟悉的话题（化妆、时尚） → 谦虚回避，被信息量压倒后慌张（0009、0017、0019）
- 被指出不足 → 担心并认真想改进（0013、0025）
- 被问喜欢的人 → 认真回答，说的却是动画角色（0050～0060）
- 清夏随口说的话 → 当真并深入追问（0035、0041、0048）
- 动画话题上 → 兴奋，甚至说“不会给你”（0060、0063）

## 关系
- 清夏：称「清夏ちゃん」。向她学时尚（0019、0025、0029）。认为她擅长选自己不会穿的类型的衣服（0029）。

## 档案类事实

- 前几天和清夏一起看过这部动画（清夏说，0061）
