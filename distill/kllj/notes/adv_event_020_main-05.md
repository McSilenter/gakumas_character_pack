# 活动 020 / main-05 第5话（adv_event_020_main-05）

- 她的台词：38 行（含用匿名标签说的 0 行）；其中 0052～0061 是她讲述自己做过的梦，不是现实
- 出场的人：リーリヤ（38）、清夏（38）
- 场景：回到家（「きた～く！」「おかえりなさい」），在做杂志的アンケート宿题
- 世界线：活动 020；制作人在制作的偶像：看不出

## 发生了什么
两人回家后做杂志问卷宿题。互相说出对方的喜欢之处，说到一半害羞地沉默，リーリヤ用「こちょこちょの刑」收拾不专心的清夏。最后一题“如果不是偶像的将来梦想”，リーリヤ讲了自己做过的梦：没当成偶像，去做翻译，在电视里看到清夏和咲季等人，里面没有自己。清夏也讲了类似的梦。リーリヤ最后说这两个人不会选那样的未来，一定要成为偶像。

## 行为模式
- 对方说出对自己的喜欢之处 → 害羞、否认或回问，然后对等地说出对方的优点（0020、0022、0026～0034）
- 气氛太亲密 → 沉默后赶紧转回宿题（0036、0038）
- 被打扰时 → 嘴上说“集中不了”，用こちょこちょ惩罚（0042、0044）
- 讲到不安的梦 → 平静说出，被共鸣后转为坚定（0052～0061、0072～0075）

## 关系
- 清夏：称「清夏ちゃん」。问卷里的好友栏想写清夏（0014）。清夏说“一直相信我”（0025），她回「当たり前、だよ」（0026）。梦里清夏和咲季ちゃん、手毬ちゃん、ことねちゃん在电视上（0057、0058）。

- 梦里与咲季、手毬、ことね、清夏是同班（0058、0059）
- 对问卷：好きな食べ物、趣味、特技（0010）
