# 活动 030 / main-01 我是、小恶魔♡ 第1话（adv_event_030_main-01）

- 她的台词：30 行（含用匿名标签说的 0 行）；行号 0001、0003、0005、0007、0010、0013、0016、0020、0021、0023、0026、0031、0033、0034、0035、0036、0038、0041、0043、0045、0046、0048、0050、0052、0053、0055、0056、0057、0059、0061。其中 0035、0036、0045、0046、0055～0057 是自言自语。
- 出场的人：リーリヤ、星南、清夏、咲季、佑芽
- 场景：初星学園。先在生徒会室被星南叫去，之后在走廊遇到清夏，再找咲季，最后碰到佑芽。
- 世界线：活动 030；制作人在制作的偶像：看不出

## 发生了什么
リーリヤ被星南叫到生徒会室，被告知要担任初星学園大型タイアップ企画第2弹（化妆品厂商的香水联名）的リーダー，并负责选成员、一起想广告概念。她吃惊，问为什么是自己；星南先问她用不用香水，又说圣诞蛋糕销售评价好，并说这是成长的机会。她先说怕做不到，随后决定「やります」，说完又肚子痛。清夏已经被别的企划邀请，所以她去找咲季，咲季爽快答应；然后她遇到佑芽，邀请她一起做偶像的工作。

## 她的关键台词
- 0001「生徒会室って……ここ、だよね？」——一进场的自言自语，不确定自己来对地方。
- 0005「ま、まだ扉を開けてないのに、／なんで来たって分かったんですか？」——对星南的「预知」认真惊讶。
- 0007「す、すごい……！／これが、『一番星』……！」——立刻相信并佩服。
- 0021「そ、そんな大役……／どうしてわたしなんでしょうか？」——被任命リーダー时的不安。
- 0023「あ、はい。／母にもらったものを使ってます。」——说自己用的香水是母亲给的。
- 0031「わたしにできるでしょうか……？」——对难度的担心。
- 0034「――やります！／わたしに、任せてください……！」——被说是成长机会后立刻下决心。
- 0035「う、うぅ……。／おなか痛くなってきた……。」——决心后紧接着的身体反应。
- 0053「あ、でも、わたしがリーダーだから、／メンバー探しは、わたしに任せて！」——开始有当リーダー的自觉。
- 0061「わたしと一緒に、／アイドルのお仕事しない！？」——找到佑芽后直接邀请。

## 行为模式
- 被突然交托大任务 → 先惊叫，问为什么选自己，听到成长的机会后改口接下（0020、0021、0031、0033、0034）。
- 下决心之后 → 身体马上紧张（肚子痛），再给自己打气（0035、0036）。
- 同伴已有别的安排 → 惊讶，之后立刻另想办法找下一个人（0043、0045、0046）。
- 成了リーダー后 → 主动承担选人的事，自己想条件：关系好、分得出香味（0053、0056、0057）。
- 被星南的玩笑／夸张说法 → 当真地佩服（0005、0007）。

## 关系
- 星南：称「会長」（0010），对她的「一番星」佩服，敬语交谈。
- 清夏：称「清夏ちゃん」；想邀她一起，被已有别的企划而拒绝（0038、0041、0045）。
- 咲季：称「咲季ちゃん」，咲季答应参加（0050）。
- 佑芽：称「佑芽ちゃん」，邀请她一起做工作（0059、0061）。
- 手毬：提到从手毬那里听说过第1弹（0016）。

## 档案类事实
- 用的香水是母亲给她的（0023）。
- 星南说：她擦肩而过时有好闻的香味（星南 0024、0025）。
- 最近的圣诞蛋糕销售评价很好（星南 0027）。
- 她是这次香水联名（化妆品厂商）的リーダー，成员选定由她负责（星南 0019、0030）。
