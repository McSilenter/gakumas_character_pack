# 活动 030 / main-02 我是、小恶魔♡ 第2话（adv_event_030_main-02）

- 她的台词：34 行（含用匿名标签说的 0 行）；行号 0001、0002、0004、0006、0007、0009、0011、0014、0016、0020、0022、0023、0024、0027、0030、0032、0034、0036、0038、0039、0040、0043、0047、0049、0051、0056、0059、0061、0062、0063、0064、0066、0067、0070。其中 0040、0062 是心里的话（括号内）。
- 出场的人：リーリヤ、咲季、佑芽、一同
- 场景：初星学園的某个房间，三人围着化妆品厂商寄来的试用香水。
- 世界线：活动 030；制作人在制作的偶像：看不出

## 发生了什么
リーリヤ向咲季和佑芽宣布三人做香水联名，两人露出微妙的表情，她追问后得知两人不想共演，因为是竞争对手；她说想和两人一起工作，两人让步。三人试用试用品，各选了一款：她选柠檬（柑橘系），咲季选玫瑰，佑芽选桃子。咲季让她作为リーダー来决定，她选了玫瑰，理由是花语「情熱」和「愛情」适合两人，还有玫瑰香的咲季看起来很可爱，被佑芽说成在口说咲季。

## 她的关键台词
- 0002「この3人で、化粧品メーカーさんとの／香水コラボ企画を……やります！」——宣布成员和企划。
- 0004「なんで微妙な顔なの！？」——两人露出微妙的表情时的反应。
- 0011「でも、前に『GO MY WAY!!』／の企画、一緒にやってなかった？」——用过去的共演反驳两人的「不共演」说法。
- 0016「わたし、ふたりと一緒に、／お仕事したいです……！」——直接说出自己的愿望。
- 0023「今回、宣伝する香水の製品は、／わたしたちで決めていいみたいです。」——向两人说明企划的条件。
- 0030「わたしはいつも、母にもらった香水を／つけているんです。」——说起自己平常用的香水。
- 0039「最後に3人で話し合って、／宣伝する香水を決める……／というのは、どうですか？」——提出进行方式。
- 0040「（わたしがリーダーなんだから、／ちゃんと指示を出さないと……！）」——对自己リーダー角色的意识。
- 0062「（リーダーはこういう時、／決めないといけないんだ……！）」——被咲季要求决定时的领悟。
- 0066「バラの花言葉は「情熱」と「愛情」。／ふたりにぴったりだなと思って……」——选玫瑰的理由。
- 0067「それに、バラの香りを纏った／咲季ちゃんが、とっても／可愛く見えたから……」——选择理由里掺着对咲季的感受。

## 行为模式
- 被两人的冷淡反应打击 → 直接问「なんで」，再用事实反驳，最后说出自己的愿望（0004、0011、0016）。
- 想做好リーダー → 在心里提醒自己要下指示，并提出具体的进行方式（0039、0040）。
- 被指名决定 → 一时吃惊，把“リーダーは決める”当作职责接下，选的不是自己喜欢的香味，而是对两人合适的（0059～0066）。
- 自己的话被调侃成口说 → 慌张否认（0070）。

## 关系
- 咲季：称「咲季ちゃん」；咲季让她作为リーダー来决定（0058、0060）。
- 佑芽：称「佑芽ちゃん」；佑芽说她被咲季「口説いてる」（0069）。
- 母亲：香水是母亲给的（0030）。

## 档案类事实
- 平时一直涂母亲给的香水，是柑橘系的清爽香味，佑芽闻得出来（0030、佑芽 0031）。
- 她选的试用香水是柠檬香（0043、0056），咲季说适合她（咲季 0044）。
- 她以前与咲季、佑芽一起做过『GO MY WAY!!』的企划（0011）。
