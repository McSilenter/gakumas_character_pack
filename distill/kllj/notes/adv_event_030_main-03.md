# 活动 030 / main-03 我是、小恶魔♡ 第3话（adv_event_030_main-03）

- 她的台词：21 行（含用匿名标签说的 0 行）；行号 0003、0011、0013、0015、0016、0017、0018、0020、0022、0025、0028、0030、0032、0035、0038、0040、0041、0042、0044、0047、0048。其中 0016 是心里的话（括号内）。
- 出场的人：リーリヤ、咲季、佑芽、一同
- 场景：三人讨论广告概念的场所，之后是试穿小恶魔衣装的场面。
- 世界线：活动 030；制作人在制作的偶像：看不出

## 发生了什么
香水定为玫瑰后，三人讨论CM概念。咲季提议在玫瑰盛开的地方拍；リーリヤ默默思考，咲季看出来并让她说出来。リーリヤ意识到不需要一个人想，说出「小悪魔」的主意：香水的甜味让人想到甜蜜诱惑。咲季和佑芽觉得可爱，她说设计由设计师完成。到试穿衣装时她让两人摆姿势，想拍照留念，最后说出让两人抱在一起，被吐槽。

## 她的关键台词
- 0003「そ、そうだった……！／それも考えないと……！」——想起自己要想概念。
- 0013「あ、ごめんね……。」——被咲季发现她在发呆时的反应。
- 0016「（そっか……リーダーだからって、／ひとりで考える必要はないんだ）」——领悟到リーダー不必一个人想。
- 0017「えっと……わたしたちが選んだ香水は、／バラの華やかさの中に、甘い香りも／混じっているような感じがするから……」——开始说出自己的想法，从香味出发。
- 0018「この香水を宣伝するなら、／甘く誘惑するような感じかなって。」——提出概念。
- 0020「たとえるなら……小悪魔みたいな？」——给出具体形象。
- 0025「咲季ちゃんと佑芽ちゃんなら、／ぜったい似合うと思います……！」——对两人有信心。
- 0038「わたしはイメージを伝えただけで、／作ったのはデザイナーさんだから……」——被夸时先指出功劳属于设计师。
- 0044「ふたりの小悪魔衣装、せっかくだから／写真に残しておきたくて。」——想拍照留念的理由。
- 0048「じゃあ、ポーズなんだけど……／まずはふたりに抱き合ってもらって――」——说出的指示让两人吐槽。

## 行为模式
- 有想法却没说出口 → 被发现后道歉，再被鼓励才开口（0011、0013、0015～0017）。
- 提出自己的点子 → 用「たとえるなら」把抽象的感觉换成具体的形象（0017～0020）。
- 被夸 → 先把功劳说成别人的，再害羞地笑（0038、0040）。
- 想拍摄时 → 认真提出要求，越说越具体，说到离谱处才被打断（0042～0048）。

## 关系
