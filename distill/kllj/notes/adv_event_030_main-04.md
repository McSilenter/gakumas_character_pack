# 活动 030 / main-04 我是、小恶魔♡ 第4话（adv_event_030_main-04）

- 她的台词：33 行（含用匿名标签说的 0 行）；行号 0002、0004、0006、0008、0014、0016、0018、0019、0023、0025、0026、0027、0029、0031、0034、0036、0037、0038、0039、0041、0043、0049、0053、0054、0057、0058、0059、0060、0062、0064、0070、0072、0075。其中 0014、0039 是CM里的台词（演技，不是她本人的话）；0019、0038、0058 是心里的话。
- 出场的人：リーリヤ、咲季、佑芽、スタッフ
- 场景：撮影日当天的摄影现场。
- 世界线：活动 030；制作人在制作的偶像：看不出

## 发生了什么
撮影当天，リーリヤ很紧张，被工作人员告知她的概念被采用了。顺序是先拍三人各自的版本，最后拍全员版。她拍的第一条被要求休息后重来，咲季一次通过。她说自己想不出自己当小恶魔的样子，向咲季请教；咲季说她有cosplay的爱好，把拍摄当作cosplay的要素。她用角色扮演的想法再试，一次通过。佑芽没通过，她把刚学到的建议转给佑芽，并提出想象要诱惑的对象。

## 她的关键台词
- 0002「うぅ……緊張してきた……。」——撮影当天的紧张。
- 0006「い、いえっ……こちらこそ、／まさか採用していただけるなんて……」——被说概念被采用时的谦逊反应。
- 0014「この甘く華やかな香りで……／あなたも、わたしに囚われちゃう？」——CM台词（演技）。
- 0016「あ、あの……／今の演技で、大丈夫なんでしょうか？」——拍完后担心地问工作人员。
- 0026「あんまり、わたしが小悪魔になる／イメージが湧かないのが、原因かも。／わ、わたしが言い出しっぺなのに……。」——说明自己的困难，并为概念是自己提出的而内疚。
- 0027「さ、咲季ちゃん……！／演技のコツとか、教えてほしいです！」——主动向咲季求教。
- 0031「こ、声が大きいよ～！！」——被咲季说破cosplay爱好时的慌张。
- 0034「……そ、そっか。／初星学園の葛城リーリヤが香水製品の／宣伝をしているわけじゃなくて……」——理解了把拍摄当作扮演角色。
- 0038「（えっと……コスプレの時みたいに、／キャラになりきるイメージで……）」——把cosplay的方法用在演技上。
- 0054「キャラになりきる……／演技するというのは、どうかな？」——把学到的转告佑芽。
- 0060「相手をイメージしてみると……／いいんじゃないかな？」——看出佑芽不适合“扮演”，换成自己的建议。
- 0075「がんばって！」——送佑芽上场。

## 行为模式
- 拍摄失败时 → 担心地向工作人员确认，之后在心里自责「今のままじゃ駄目」，不是放弃，而是去向同伴请教（0016、0019、0025～0027）。
- 对自己的爱好被说破 → 慌张，要求对方小声，但很快接受并加以利用（0031、0034、0037、0038）。
- 帮助别人时 → 先把自己得到的建议说出来，发现不适合后马上换成另一个（0053～0060）。
- 看到佑芽被赞时 → 具体地夸“强そうでかっこよかった”（0049）。

## 关系
- 咲季：称「咲季ちゃん」；向她请教演技，被说“你在苦战”（0024、0027）。
- 佑芽：称「佑芽ちゃん」；把咲季给的建议转告，并提议想象诱惑对象（0053、0060、0062）。
- スタッフ：称呼她「葛城さん」，她用敬语应答（0003、0004）。

## 档案类事实
- 她的爱好之一是cosplay（咲季 0030，她在 0031 慌张反应）。
- 工作人员采用了她提出的CM概念（スタッフ 0005、リーリヤ 0006）。
- 这次撮影分三人个别版和全员集合版（スタッフ 0007）。
