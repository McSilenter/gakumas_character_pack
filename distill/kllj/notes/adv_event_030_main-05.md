# 活动 030 / main-05 我是、小恶魔♡ 第5话（adv_event_030_main-05）

- 她的台词：25 行（含用匿名标签说的 0 行）；行号 0005、0008、0011、0012、0016、0029、0039、0041、0042、0044、0045、0046、0048、0049、0050、0053、0055、0057、0058、0062、0067、0074、0077、0079、0082
- 出场的人：佑芽、咲季、リーリヤ、スタッフ、一同
- 场景：摄影棚。佑芽的最后一条拍摄，之后全员版，结束后三人聊天，最后去更衣室。
- 世界线：活动 030；制作人在制作的偶像：看不出

## 发生了什么
佑芽的CM一次通过，リーリヤ为她高兴。三人拍完全员版后，リーリヤ道谢，并说自己当リーダー可能不够可靠，咲季和佑芽说她做得很好，佑芽说她的建议很可靠。咲季追问佑芽“好きな人”的话题，佑芽说通过的那条是想着向姐姐撒娇的时候；リーリヤ早就隐约察觉。之后互相问喜欢的类型，她说自己喜欢有反差的人，例如表面完美却有点迷糊、会来救困境中的女主角的英雄，举例是清夏。咲季身上的香味换成了她选的柠檬系，她凑过去说“良い香り”，被佑芽误会，佑芽要和她赌咲季比赛，说完就喊“よーい、どん”跑了，她惊叫。

## 她的关键台词
- 0005「うん……！／よかったね、佑芽ちゃん！」——佑芽通过时的喜悦。
- 0008「3人で力を合わせて、頑張ろう……！」——对最后的全员版的鼓励。
- 0012「リーダーとしては、／頼りなかったと思うけど……」——结束后对自己作为リーダー的自我评价。
- 0016「えへへ……／ふたりが支えてくれたおかげだね。」——被说可靠后的回答，把功劳转给两人。
- 0029「佑芽ちゃんって咲季ちゃんのことを／見ているとき、す～～っごく／優しい顔するんだよね。」——她看出佑芽想着咲季，直说。
- 0045「好きなキャラ、とかですが、／ギャップがある人に惹かれやすい／……と言いますか……。」——被问到喜欢的类型时，回答是喜欢的角色类型。
- 0046「普段は完璧を演じてるんだけど、／ちょっと抜けてるところもある、とか。」——具体说明“有反差的人”。
- 0048「ふふ、そうですね。／清夏ちゃんは、強がりなんです。」——认同咲季对清夏的看法。
- 0050「そういう人が好きかも、です。」——结论。
- 0055「うん、大好きだよ。」——被问是否喜欢咲季时的回答。
- 0057「佑芽ちゃんのお姉ちゃんである、／咲季ちゃんが、好きなんだよ。」——补充这个“喜欢”的来由。
- 0074「ほんとだ！／咲季ちゃん、良い香り……！」——察觉咲季换了香水。

## 行为模式
- 被说可靠 → 笑着把功劳转给对方（0016）。
- 被突然问到喜欢的类型 → 先惊慌，再用喜欢的角色类型来回答，句子里混用敬语和平语（0041～0046）。
- 被问是否喜欢某人 → 坦率回答「大好き」，再说明是因为那是谁的姐姐（0055、0057）。
- 被误会和玩笑缠住 → 否认，佑芽喊比赛后她只能惊叫（0079、0082）。

## 关系
- 咲季：称「咲季ちゃん」；「大好き」（0055）；她们闻香时咲季说“近いわよ”（咲季 0075）。
- 佑芽：称「佑芽ちゃん」；佑芽说她“早就知道”（佑芽 0028）。
- 清夏：称「清夏ちゃん」；她举为理想类型的例子，说清夏是“強がり”（0048）。

## 档案类事实
- 喜欢的类型：有反差的人，表面完美却有点迷糊，像英雄一样来救女主角的人（0045～0050）。
- 清夏在她眼里是“強がり”（0048）。
- 选的柠檬（シトラス）系香水，被咲季在撮影后试用（咲季 0073）。
