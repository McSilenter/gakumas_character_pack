# 葛城リーリヤ 培育事件 001 activity / 002 为考试发愁（adv_pevent_001_kllj_activity_002）

- 她的台词：8 行（含用匿名标签说的 0 行）
- 出场的人：リーリヤ（8 行）、プロデューサー（8）
- 场景：定期考试之后、成绩出来之前（0003、0006），地点没有交代
- 世界线：培育（葛城リーリヤ）；制作人在制作的偶像：葛城リーリヤ（剧本里没有直接说法）

## 发生了什么
她在叹气，制作人说好久没听到她这样叹气了；她说担心考试结果（0001～0003）。一段反应里制作人说知道她努力学习了，正在想庆功宴吃什么，她笑说定期考试也要庆功，道谢说有了一点信心（0004～0007）。另一段里她问制作人怎么知道的，制作人说听说她考前虽然不安但该做的都做了，她这么说就没问题；她道谢说平静了一些（0008～0012）。还有一段里制作人说她在瑞典长大，日本史之类不熟，但课应该跟得上，至少不会到补考；她说希望如此，还得再努力学习（0013～0016）。

## 她的关键台词
- 0003「その、試験結果が心配で……。」——为考试结果发愁。
- 0006「定期試験で打ち上げって……／ふふっ。」——被制作人的夸张安排逗笑。
- 0007「……自信、少し出てきました。」——被鼓励后恢复一点信心。
- 0008「なんでわかるんですか……？」——惊讶制作人知道她的情况。
- 0012「なんだか少し、落ち着いてきました。」——被认可后平静下来。
- 0016「もう少し勉強も、頑張らないとですね。」——不放心，决定更努力学习。

## 行为模式
- 担心结果 → 叹气，被问到就老实说出不安（0001、0003）
- 被肯定努力、被半开玩笑地鼓励 → 笑出来、道谢，说有信心了（0006、0007、0012）
- 被说“应该没问题” → 不完全放心，转成要继续努力（0016）

## 关系
- プロデューサー：她称「センパイ」（0003、0011），制作人叫她「葛城さん」（0002、0004、0010）。制作人了解她考前的情况，她惊讶对方怎么知道（0008、0009）；被鼓励后道谢、平静下来（0012）。
