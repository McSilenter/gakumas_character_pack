# 葛城リーリヤ 培育剧情 001 / ending-true-01 True End（adv_pstory_001_kllj_ending-true-01）

- 她的台词：29 行（含用匿名标签说的 0 行）
- 出场的人：リーリヤ（29 行）、プロデューサー（8）
- 场景：当天的ライブ结束后，制作人在“这里”找到她（0001、0003、0031）；具体地点没有交代
- 世界线：培育（葛城リーリヤ）；制作人在制作的偶像：葛城リーリヤ

## 发生了什么
ライブ后制作人找到她，说猜她会在这里、因为忘不了吧（0001～0003）。她说一定会一直忘不了：在聚光灯和观众的笑容、欢呼中做出自己最好的表演，对不久前的她来说像梦一样（0004～0007）。她回顾自己决定当偶像进了这所学园，却完全不知道怎么做，只会说“会努力”；是センパイ教她怎么努力，在快停下时牵着她的手、告诉她通往偶像的路（0008～0013）。制作人谦让，她笑着说センパイ总说她太谦虚、要有自信，自己却也一样（0014～0018）。一段反应里她说最近有了一点自信，因为有人比她更相信她，所以今天让她来说（0019～0021）；另一段里她说如果センパイ不是她的制作人，她一定还毫无自信，这对センパイ是理所当然、对她却是奇迹，能走到这里全是因为センパイ在（0022～0027）。制作人害羞，说今天的ライブ远超期待，要一起以トップアイドル为目标；她答应后才反应过来，惊叫自己怎么能当トップアイドル、目标什么时候升这么高，请笑着的センパイ告诉她（0028～0037）。

## 她的关键台词
- 0004「……はい。きっと、／この先もずっと忘れられません。」——这次舞台对她的分量。
- 0007「少し前のわたしには、／夢みたいなお話です……。」——和不久前的自己对比。
- 0008「……アイドルになるって決めて、／この学園に入学したけど、」——入学的动机。
- 0009「どうしたらなれるのかなんて、／まったくわからなくて。」——起点：完全不知道怎么做。
- 0010「ただ、頑張りますって言うことしか／できなかったわたしに、」——过去的自己。
- 0011「センパイが、／頑張り方を、教えてくれました。」——制作人对她的意义。
- 0018「センパイだって、同じことしてます。」——难得地反过来指出制作人。
- 0019「センパイ。わたし、最近は少し、／自分に自信がついたんです。」——自信的变化（仍说“少し”）。
- 0020「わたし以上に、／わたしを信じてくれるから。」——自信的来源。
- 0025「センパイにとっては当然でも、／わたしにとっては、奇跡なんです。」——对相遇的看法。
- 0027「ぜんぶ……ぜんぶ、／センパイが、いてくれたからです。」——把一切归于制作人。
- 0035「……って、トップアイドル！？　／なんでわたしなんかが……」——高目标面前回到“我这种人”。

## 行为模式
- 舞台成功后 → 独自留在（与舞台相关的）地方回味（0003、0004）
- 回顾过去 → 用“不久前的我”作对比，把成长归功于制作人（0007、0010～0013、0027）
- 制作人谦让 → 笑着反过来指出对方也太谦虚（0015、0017、0018）
- 想表达感谢 → 主动说“今天让我来说”，说完承认害羞，但说想好好传达（0021、0029、0030）
- 被定下更高目标 → 先顺口答应，再惊慌“我这种人怎么行”（0034～0037）

## 关系
- プロデューサー：她称对方「センパイ」（0002、0011、0027），制作人叫她「葛城さん」（0001、0032），自称「俺」（0031）。她说センパイ教她怎么努力、牵着她的手（0011、0012），比她更相信她（0020），如果不是センパイ当她的制作人她一定还没有自信（0023、0024）；制作人提出一起以トップアイドル为目标（0033）。

## 档案类事实
- 她是决定要当偶像才进这所学园的，入学时完全不知道怎么才能成为偶像（0008、0009）。
- 她说那时只会说“会努力”，是制作人教她怎么努力（0010、0011）。
- 这次ライブ远超制作人期待（0031）。（培育 True End）
- 制作人经常说她太谦虚、要更有自信（0017）。
