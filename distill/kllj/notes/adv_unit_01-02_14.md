# 主线 第1部 2章 偶像们的共同生活 / 2章14话（adv_unit_01-02_14）

- 她的台词：10 行（含用匿名标签说的 0 行）；无心里话
- 出场的人：清夏、咲季、リーリヤ、手毬、ことね
- 场景：宿舍里，咲季和ことね的料理比赛现场，リーリヤ和清夏被ことね请来当评委。
- 世界线：kllj:主线（第1部）；制作人在制作的偶像：看不出（本篇制作人没出场）

## 发生了什么
リーリヤ被ことね请来和清夏一起当评委，表示会努力。咲季端出自信作后，清夏说像科幻电影里的东西，她劝清夏别这样说，自己先尝，说是奇特的味道。清夏毫不留情地批评咲季的料理，她两次叫住清夏，说太过分了。ことね的味噌汤端出后，她说看起来很好喝；咲季的菜被指出是味噌汤，她出面说自己觉得好喝、对身体好，但被清夏问每餐都吃吗时答不上来。
剧情经过参照 ttmr、hski 笔记。

## 她的关键台词
- 0004「……し、審査員、がんばります。」——被请来当评委，紧张地表态
- 0016「清夏ちゃん、ダメだよそんなこと言っちゃ……」——劝清夏别当面说失礼的话
- 0019「いただきます。わ……こういう味なんだ。」——先吃，不事先评判
- 0022「うん、大丈夫。なんていうか……すごく不思議な味？」——如实但克制的评价
- 0028「清夏ちゃん！！」——清夏说"好吃却不想再吃"时叫住她
- 0035「清夏ちゃん！！　言い過ぎだよ！！」——对清夏的批评进一步阻止
- 0047「わぁ……美味しそうなお味噌汁ですね。」——看到ことね的味噌汤的反应
- 0061「わ、わたしは美味しいと思います……！」——咲季被逼到窘境时，站出来说自己的感受
- 0062「すごく身体によさそうで……！」——补充好处，找出能称赞的地方
- 0064「……それは…………えっと……」——被问到每餐都吃是否愿意，答不上来

## 行为模式
- 被拜托做评判 → 紧张但表示尽力（0004）
- 同伴说话直白 → 小声劝阻，声音逐渐变大（0016、0028、0035）
- 面对不熟悉的味道 → 先尝一口，用"不思议"这类中性的词表达（0019、0022）
- 有人被批评到窘境 → 站出来说自己觉得好的部分，努力找可以夸的点（0061、0062）
- 被问到不好回答的问题 → 沉默、含糊（0064）

## 关系
- 清夏：叫「清夏ちゃん」（0016、0028、0035），反复劝阻；清夏叫她「リーリヤ」（0020）
- 咲季：敬语对咲季（0061）；想维护咲季，也无法回答清夏的追问（0064）
- ことね：对她请来的评委身份说"がんばります"（0004）

## 档案类事实
- 对食物不会立刻下判断，会先尝、再说感想（0019、0022）
- 对身体有益的食物评价较高（0062）
