# 篠澤広 亲爱度剧情 / 第20话（adv_dear_shro_020）

- 她的台词：63 行（含用匿名标签说的 0 行）
- 出场的人：広、プロデューサー
- 场景：制作人和広的父亲单独谈完之后（0004、0005），地点没写
- 世界线：亲爱度（篠澤広）；制作人在制作的偶像：篠澤広（0015）

## 发生了什么
制作人和広的父亲谈完累得不行，広从母亲那里听说：他在认识她之后不久就到过她家，当时自始至终没有说她能当偶像，父亲因此生气，之后一直不喜欢他（0004、0013～0015、0028～0033）。他转述父亲问的话和自己的回答：比起时间和才能的消耗，她“靠趣味赢过朋友”更重要，父亲表示同感，広笑了（0037～0044）。她察觉他还有话没说，要他叫她「広」，他叫了「広さん」（0047～0054）。之后的两段像是选项造成的并列分支：一段制作人说出“趣味のまま夢を見たっていい”，広骂他过分但答应一起做这个梦，并说要等当上学园第一才大声说出来（0055～0071）；另一段他不说，広说不用说她也明白，主动提出一起追他的梦（0072～0084）。最后他说身为她竟要共同实现自己的梦“太不自量力”，她说就该这样（0085～0090）。

## 她的关键台词
- 0003「うわ……ぁ……／わたしみたいなこと言ってる。」——制作人累得说出她的口头禅一样的话
- 0009「……プロポーズの許しを得てきた？」——开玩笑，对方回答“也许差不多”后她慌了（0010～0012）
- 0020「賛成してくれてなかったら、わたしは／初星学園に入学してないよ。」——她以此说明父母是同意的
- 0027「わたしを特別扱いするところ以外は、／好き。」——对父亲的态度
- 0044「笑っちゃった。／ふたりとも……わたしのこと、大好き。」——听完两人的对话的结论
- 0052「……広って、呼んで。」——要求改称呼
- 0058「わたしにとって……アイドルは、趣味。／いちばん向いてない、仕事。」——对偶像的定位，她说这点现在也没变（0059）
- 0066「よくばり、自分勝手、おらおら系。／わたしに無理難題ばかり言う。」——骂他
- 0067「なのに……困った。／それは、すごく、面白そう。」——越难越觉得有趣，骂完就是这句
- 0068「いい、よ。同じ夢を、見てあげる。」——接受分支里的答应
- 0071「一生懸命、大きな声で、言うね。」——承诺当上学园第一后才大声说出来（打算，未兑现）
- 0081「わたしの夢は……もう叶ってるから。／いまも、叶い続けてるから。」——另一分支：她把“拼命想当偶像的过程”本身当作已实现的梦
- 0084「それでもいいなら。それがいいなら……／わたしたちの趣味を、続けよう？」——另一分支的邀请

## 行为模式
- 想问又不直说 → 开玩笑试探，被顺着接话时反而自己慌（0009～0012）
- 察觉对方有话不讲 → 一个个追问，最后说“在我这里不用忍”（0036、0047～0049）
- 被叫篠澤さん、对话进入重要处 → 当场纠正要叫名字，对方只叫到「広さん」也接受（0051、0052、0054）
- 被提出很难的事 → 先骂，然后说这样才有意思，接着答应（0065～0068）
- 被他说不自量力 → 回答就该这样（0088、0089）
- 真心的愿望 → 不马上说破，约定条件后再说（0069～0071）

## 关系
- プロデューサー：她称「プロデューサー」（0001）；他称「篠澤さん」（0050），要求后改称「広さん」（0053）。她说他是「わたしのファンの人たちの中でも、／一番の変わり者」（0017）。她称自己是他的パートナー（0073）。本篇答应（分支一）或主动提出（分支二）和他一起追他的梦（0068、0082）
- 父亲：她称「パパ」（0004），说他那天和今天都说了很多嫌味话（0024），对她很温柔（0026），除了特别对待她这点都喜欢（0027）；从母亲处得知他从那时起讨厌制作人（0032）
- 母亲：「ママ」（0028），告诉了她制作人和父亲过去的事（0013～0015、0028）

## 档案类事实
- 父母是同意她入读初星学园的，让她什么都别顾虑、喜欢就去做（0020、0021）
- 父亲“理知的”“シニカル”是制作人的说法（0025）；对她很温柔（0026）
- 制作人在认识她不久后曾到她家访问（母亲转述）（0014、0015）；定期把近况报告发给她父亲（0033）
- 她认为偶像对自己是“趣味”，是“最不适合的工作”（0058）

## 不确定
- 0055～0071 和 0072～0084 看起来是选项造成的并列分支（制作人说出口／不说出口），0085 起汇合；两边的回应不能当成连续发生的事。
- 0010 制作人对“プロポーズ”的回应，他本人后面在 0046 又说「…………そうです。」，广 0047 说「違うんだ。」：这是她读对方表情，还是本有什么没写，本篇无法确定。
- 0016～0017「一番の変わり者」的“わたしのファンの人たち”是否把制作人算在内，是她的说法，不代表制作人自认。
- 【冲突】0055 制作人说「以前……『あなたは俺の夢の役には／立たない』と、そう言いましたね。」，而这条线上第5话 0073 这句话是她自己说的（她说自己大概派不上梦想的用场，0072 制作人说了他的梦想，0074 答以“也可以，因为是趣味”），第5话里制作人没有说过这句。培育剧情 001 的 ending-true-01 0039 里制作人说过相近的话，但培育各按自己的线看。留待统一确认。
- 【译文】0003 原文「わたしみたいなこと言ってる。」（说得像我一样），译文“我居然说了这样的话”主语弄错。
- 【译文】0048 原文「わたしに、なにか……／大事なお願いがある？」（你对我有什么请求吗），译文“我……有件重要的事情，想拜托你”主语反了，疑问也没了。
