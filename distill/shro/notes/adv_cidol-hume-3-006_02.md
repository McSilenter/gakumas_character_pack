# P卡 花海佑芽【Campus mode!!】 / 第2话 Campus mode!! 第2话（adv_cidol-hume-3-006_02）

- 她的台词：16 行（含用匿名标签说的 0 行）
- 出场的人：プロデューサー（21 行）、佑芽（21）、広（16）、千奈（11）、一同（1）
- 场景：前半是制作人与佑芽的谈话；0035 起広、千奈被叫来；『N.I.A』之前
- 世界线：亲爱度（花海佑芽）·P卡；制作人在制作的偶像：佑芽（0004、0058 広说“佑芽のプロデューサー”）

## 发生了什么
制作人对佑芽说单靠数值堆不垮咲季，要挑战“数值之外的偶像力”。接着広转述（0035 起）制作人对她和千奈的说明：风格、咲季那样的绝境爆发力之外，她和千奈有“输试镜却粉丝增加”的不可思议的力量。她概括方案：三人暂时一起活动，签名会、电视，增加知名度并获得新武器。広说这是“Win-Win”，如果人气上升，她们也能在『N.I.A』唱『Campus mode!!』，条件是在试镜中获胜。剧情经过参照 hume 笔记。

## 她的关键台词
- 0035「――というわけで、／わたしたちが呼ばれた。」——说明她和千奈被叫来的缘由
- 0040「たったいま、プロデューサー、／説明してくれてた、よ。」——佑芽问她懂不懂，她说制作人刚才已经说明
- 0042「トップアイドルが纏う、わたしは／すごいんだぞ、っていう風格。」——解释“数值之外的力”之一
- 0043「咲季が『絶対負けられない勝負』で／発揮する、あれ。」——另一种力，咲季在绝境时发挥的力量
- 0044「その、どっちでもないものが、／わたしと千奈にはあるんだって。」——她和千奈有第三种
- 0047「オーディションで負けてばっかり／なのに、なぜかファンが増えていく／不思議な力。」——这第三种力的内容
- 0053「知名度を上げてファンを増やしながら、／新しい武器の獲得に挑戦する。」——概括制作人的方案
- 0057「そう……わたしたちは、／Win-Winの関係。」——佑芽问是否只有自己得到帮助时，说是互利关系
- 0059「わたしたちの人気……ランキングが／もっともっと上がったら。」——说明三人合作的收益之一
- 0064「ちゃんとオーディションで勝てる／ようになるのが、条件。」——说明可以唱『Campus mode!!』的条件
- 0065「とっても高いハードル。」——对这个条件的评价

## 行为模式
- 被问不知道的事 → 转述当事者刚才已经说过的话，并逐条整理（0040～0054）
- 被问“这样好吗”（只有一方得益）→ 直接用“互利关系”回答，不多安慰（0057）
- 给出收益与条件 → 同时说出高门槛，不夸大（0064、0065）

## 关系
- 佑芽：叫「佑芽」（0039 佑芽叫“広ちゃん”）
- 千奈：与千奈一起被叫来；0044 把千奈和自己并称
- 制作人：叫「プロデューサー」（0040）；「佑芽のプロデューサー」（0058）

## 档案类事实
- 和千奈有“输试镜而粉丝增加”的特质（0047，转述制作人的话）
- 若人气上升，且在试镜中获胜，她们能在『N.I.A』唱『Campus mode!!』（0059、0064，0060 千奈）
- 方案内容：三人暂时一起活动、签名会、上电视（0051～0053）
