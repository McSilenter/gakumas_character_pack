# P卡 花海佑芽【GUSUPI】 / 第2话 GUSUPI 第2话（adv_cidol-hume-3-009_02）

- 她的台词：21 行（含用匿名标签说的 0 行）
- 出场的人：佑芽（26 行）、広（21）、千奈（8）、咲季（2）、一同（1）
- 场景：佑芽撞见咲季与制作人对话之后，找広、千奈商量
- 世界线：亲爱度（花海佑芽）·P卡；制作人在制作的偶像：佑芽（0023 她说“佑芽のプロデューサー”）

## 发生了什么
佑芽误会制作人和咲季在交往，慌忙叫来広和千奈。広先断定“不可能”，批评佑芽读了太多漫画，并代替平常的佑芽对今天的佑芽生气。佑芽冷静下来，広以“大人の女”的口吻劝告：偶像不需要恋爱，恋心与篠澤広无缘，恋爱就输了。她还让佑芽做自我分析，想弄清为何动摇。佑芽整理不出来。剧情经过参照 hski、hume 笔记。

## 她的关键台词
- 0016「それはありえない。」——佑芽说制作人可能在和咲季交往，立刻断言
- 0017「佑芽はえっちな／漫画の読みすぎだと思う。」——直接指出原因
- 0019「ちょっぴりえっちな内容だった。／禁断の恋とか、そういうのばかり。」——佑芽借她的漫画，她如实评价
- 0021「それはそれでいい、けど。／現実と混同するのはよくない。」——不否定爱好，但指出不应与现实混同
- 0024「いつもの佑芽の代わりに、／わたしが今日の佑芽に怒る。」——说明自己为何要训斥
- 0025「こら！」——短促地斥责
- 0030「佑芽は、恋愛のことになると、／直感と判断力がにぶる。要改善。」——总结佑芽的弱点
- 0033「ふふ。わたし、大人の女っぽい？」——被夸“靠谱”后，开玩笑地问
- 0038「アイドルに恋愛は不要。／アイドル活動に専念すべき。」——给出的建议
- 0043「しない。大人の女だから。／ふ、恋心……篠澤広とは無縁の言葉。」——被问是否会向往恋爱，答“不会”，自称无缘
- 0044「みんなに恋をさせるのがアイドル。／恋をしたら……負け、だね。」——她对偶像的看法
- 0048「しよう……自己分析。」——给佑芽的另一条建议

## 行为模式
- 同伴因误会失态 → 先断言不可能，随后逻辑地指出原因（漫画的影响）（0016、0017、0021）
- 说服同伴冷静 → 用代替“平常的佑芽”去斥责的方式，而不是安慰（0024、0025）
- 被夸 → 顺势摆出“大人”的架势继续扮演（0033、0038）
- 谈到恋爱 → 一口断言无缘、并以“恋爱就输”总结偶像的立场（0041、0043、0044）
- 给出建议时 → 附带具体的操作（“自己分析，直面自己的心”）（0048～0051）

## 关系
- 佑芽：叫「佑芽」；佑芽叫「広ちゃん」（0009、0027）；佑芽曾借漫画给她（0018）
- 千奈：叫「千奈」不在本篇；千奈称她“篠澤さん”（0032、0040）
- 咲季与佑芽的制作人：她说“咲季はそんなことしない。佑芽のプロデューサーもしない”（0023）

## 档案类事实
- 读过佑芽借的恋爱漫画，评价是“ちょっぴりえっち”（0018、0019，佑芽称“健全な恋愛漫画”）
- 主张“アイドルに恋愛は不要”，自称“恋心とは無縁”（0038、0043）
- 自称“大人の女”（0033、0043）
