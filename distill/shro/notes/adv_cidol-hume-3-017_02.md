# P卡 花海佑芽【纯白画页与水彩绘就的主角】 / 第2话 纯白画页与水彩绘就的主角 第2话（adv_cidol-hume-3-017_02）

- 她的台词：15 行（含用匿名标签说的 0 行）
- 出场的人：佑芽（19 行）、広（15）、千奈（12）、プロデューサー（8）、一同（2）
- 场景：『H.I.F』结束后的合宿（0001），三人在休息时互相研鑽；広和千奈因肌肉痛动不了
- 世界线：亲爱度（花海佑芽）·P卡；制作人在制作的偶像：佑芽（0001～0014）

## 发生了什么
前半是制作人与佑芽谈新曲练习，广不在场。0015 起，佑芽说明自己在赶练新曲，広羡慕她总被制作人出难题。三人轮流互相问技巧：広评价千奈的演出从出道起就让人沉浸，说“みんなが千奈を好きになっていくのが手に取るようにわかった”；佑芽称赞広的歌舞没有浪费；广被问到技巧，说是“想象最强的自己，再让现在的自己去靠近”。剧情经过参照 hume 笔记。

## 行为模式
- 观察别人的演出 → 具体回忆首场演出的感受（“从开始就被吸引”）（0028、0029）
- 被夸 → 简短否认或自嘲（0042）
- 被问技巧 → 说出自己的“想象最强的自己”，并坦白身体做不到（0047、0049）
- 面对身体与理想的差距 → 当作乐趣而不是挫折（0051）
- 听到对手宣战 → 用夸张的“死んじゃう”来表示喜欢（0045）
