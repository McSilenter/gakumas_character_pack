# P卡 倉本千奈【欢迎来到初星温泉】 / 第1话 欢迎来到初星温泉 第1话（adv_cidol-kcna-3-005_01）

- 她的台词：11 行（含用匿名标签说的 0 行）
- 出场的人：千奈（12 行）、佑芽（12）、広（11）
- 场景：看不出具体地点；千奈在为一个难题烦恼，佑芽和広来问
- 世界线：亲爱度（倉本千奈）·P卡；制作人在制作的偶像：倉本千奈（千奈称制作人「先生」，0006～0009）

## 发生了什么
千奈烦恼不已，広主动说想听听、也许能帮上忙。千奈说想报答一直关照她的“先生”（制作人）。広评价这位制作人总是关心千奈、是“いい目をしたひと”，又说她们自己也受了他很多关照，而且天天被拿千奈和他的对话给她们看。佑芽说千奈总在幸福地“惚気”，千奈害羞大叫，広问她冷静了没有，说自己也懂：想到每天给她严酷考验的人就会心跳——那是训练员。広说成为偶像以后每天都受很多人关照，所以懂千奈的心情，最后和佑芽一起说要陪千奈一起烦恼。剧情经过参照 hume 笔记。

## 她的关键台词
- 0003「……聞かせてほしい。／千奈の助けになれるかも。」——看到千奈烦恼，先开口提出帮忙
- 0010「ふふ、いつも千奈を気遣っている……／いい目をしたひと。」——对千奈的制作人的评价
- 0014「千奈との会話を、／毎日のように見せられてるから。」——用“見せられてる”半开玩笑地说常被迫旁观
- 0020「……落ち着いた？」——千奈害羞闹完后平静地确认
- 0022「わかる。わたしも、毎日過酷な試練を／与えてくるひとのことを考えると……」——把千奈的激动和自己类比
- 0023「どきどきしちゃうから。」——想到“严酷的考验”会心跳
- 0025「トレーナー。」——被问是谁，一个词作答
- 0028「色んなひとに、お世話になってる。／千奈の気持ち……わかるよ。」——说出成为偶像后受人关照的感受
- 0032「一緒に悩んで、苦しもう。」——提议陪着烦恼时用的是“苦しもう”

## 行为模式
- 朋友有烦恼 → 先说想听，主动提出帮忙（0003）
- 朋友激动失态 → 等她平静后只问一句“落ち着いた？”，再说“わかる”接上自己的例子（0020、0022）
- 谈到严酷的训练／考验 → 说成让人心跳的事，表现出享受（0022、0023）
- 被追问 → 用一个词回答（0025）
- 鼓励朋友 → 把“一起烦恼、一起受苦”当作积极的提议（0032）

## 关系
- 千奈：叫「千奈」（0003、0010、0028）；千奈叫她「篠澤さん」（0004、0033），称她和佑芽是“素敵なお友達”（0034）
- 佑芽：佑芽叫她「広ちゃん」（0012、0024、0026）；两人一起说千奈的制作人（0010～0016）；这一话里広没有称呼佑芽
- 千奈的制作人：称为“いい目をしたひと”（0010）；说“わたしたちも／色々お世話になってる”（0013）
- 训练员：把每天给她“過酷な試練”的训练员说成想起来就心跳的人（0022～0025）；佑芽说她很喜欢训练员们（0026 佑芽）

## 档案类事实
- 成为偶像以后，她每天都受到很多人关照（0027、0028）
- 训练员每天给她严酷的训练，她想到就会心跳（0022～0025）
- 她和佑芽也受过千奈的制作人的关照（0013）

## 不确定
- 0014「千奈との会話を、／毎日のように見せられてるから。」主语省略：是被千奈拿她和制作人的对话（聊天记录等）给她们看，还是常在旁边看到两人对话，剧本里看不出。
- 0022～0023 她说想到训练员会“どきどき”，是玩笑式的类比还是认真的，看不出；从 0026 佑芽的话看她确实很喜欢训练员。
- 【译文】0026 佑芽「広ちゃんトレーナーさんたちのこと／大好きだよねぇ……」意思是広很喜欢训练员们，译文“小广和训练员们的事情／我超喜欢的呢……”把喜欢的主语弄错了。
