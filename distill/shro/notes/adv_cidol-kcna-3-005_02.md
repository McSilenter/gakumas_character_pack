# P卡 倉本千奈【欢迎来到初星温泉】 / 第2话 欢迎来到初星温泉 第2话（adv_cidol-kcna-3-005_02）

- 她的台词：8 行（含用匿名标签说的 0 行）
- 出场的人：千奈（22 行）、広（8）、佑芽（7）、プロデューサー（3，都在千奈的回忆里）
- 场景：温泉，三人一起泡着；中间千奈回忆和制作人的对话
- 世界线：亲爱度（倉本千奈）·P卡；制作人在制作的偶像：倉本千奈（千奈说“倉本千奈のプロデュースに、／忙殺されてしまっている先生”，0018）

## 发生了什么
三人在泡温泉，佑芽说忘了为什么在这里，広笑她泡晕了，开始和千奈一起回顾：千奈想让制作人休温泉假当作报恩，制作人却说很久都没有一天休息。広说不愧是“いい目をしたひと”，过着幸福的生活。千奈说自己宣布不惜动用倉本的力量也要让他休息，広说这种地方很像千奈、她喜欢。制作人提议千奈先休温泉假，他也会休。千奈明白这是制作人察觉她最近太累而为她着想，広说自己羡慕过、但也担心，提议今天一起好好休息。剧情经过参照 hume 笔记。

## 她的关键台词
- 0003「ふぅ……あたたまる。」——泡温泉的感想，简短
- 0007「ふふ……佑芽、のぼせて記憶が飛んだ？」——拿佑芽忘事开玩笑
- 0008「わたしたちは、千奈の恩返しのために／案出しをして――」——开始替佑芽回顾经过
- 0015「さすが、いい目をしたひと。／幸せな生活をしてる。」——把“一天都没有休息”说成幸福的生活
- 0022「そういうところ、千奈らしくて好き。」——听到千奈不惜动用家里力量的宣言，直接说喜欢
- 0029「そしてこの状況に至る……／佑芽、思い出した？」——回顾结束后确认
- 0036「……羨ましかった、けど。／……心配だった。」——对千奈最近的过密日程，坦白两种心情
- 0037「今日は、一緒に、ゆっくり休もう。」——收尾时提议一起休息

## 行为模式
- 听说别人忙到没有休息 → 说成“幸福的生活”（0015）；对朋友的过密日程先说羡慕（0036）
- 但对朋友本人勉强自己 → 也说出担心，提议一起休息（0036、0037）
- 朋友忘事 → 用“ふふ”开个玩笑，然后耐心解释、最后再确认一次（0007、0008、0029）
- 喜欢朋友的某种做法 → 当场说“好き”（0022）

## 关系
- 千奈：叫「千奈」（0008、0022）；说喜欢她直率宣言的样子（0022）；对她最近的忙碌既羡慕又担心（0036）
- 佑芽：叫「佑芽」（0007、0029）；开她泡晕的玩笑，替她回忆经过
- 千奈的制作人：再次称为“いい目をしたひと”（0015，第 1 话 0010 也这样说过）

## 档案类事实
- 和千奈、佑芽一起泡温泉（0001～0004）
- 对忙到没有休息的生活和过密的日程表现出羡慕（0015、0036）

## 不确定
- 0015「幸せな生活をしてる。」是认真觉得幸福，还是玩笑，剧本里看不出；0036 她说对千奈的忙碌“羨ましかった”，两处方向一致。
- 【译文】0015「さすが、いい目をしたひと。」译成“不愧是眼光独到的人”，原文的“いい目をしたひと”在第 1 话（0010）译作“真是个好人”，两处同一说法译法不一，原意不明确，以原文为准。
