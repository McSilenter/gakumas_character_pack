# P卡 倉本千奈【向天空约定】 / 第2话 向天空约定 第2话（adv_cidol-kcna-3-014_02）

- 她的台词：24 行（含用匿名标签说的 0 行）
- 出场的人：広（24 行）、千奈（24）
- 场景：看不出具体地点；选举期间要开 live、新曲的订制资料必须马上做出来的时候（0009～0020）
- 世界线：亲爱度（倉本千奈）·P卡；制作人在制作的偶像：倉本千奈（広说“千奈のプロデューサー”，0022；千奈称制作人「先生」，0021、0040）

## 发生了什么
広看出千奈有烦恼，说因为是朋友、一直在看着她。千奈说要根据自己的意见做新曲的订制资料，新曲在选举期间的 live 上发表，日程极紧，她没自信在那之前学会新曲，制作人又什么提示都不给。広说千奈的制作人是“わたしの同類”，猜他的意图很容易，但直接说出来就没意思了，所以不说；制作人大概也是同样理由，希望千奈自己找到答案。她让千奈闭上眼，想象在选举 live、『H.I.F』正赛的舞台上看到的光景，说应该和『N.I.A』时、和平时不一样，仔细看眼前的人，把想法化成语言，说“这是我能说的极限”。千奈说完全没懂，但觉得能做到了，请她帮忙做资料，広答应，称她“千奈会長”，并说明年的生徒会大概也会这样继续手忙脚乱的日子。

## 她的关键台词
- 0001「千奈、悩んでる？」——主动开口
- 0003「友達だから。いつもよく見てるから。／様子がおかしくなったらすぐわかる。」——说明为什么看得出来
- 0005「ふふ……いま、自分でも言ってて／照れくさくなった。でも言う。」——承认害羞，但还是要说
- 0014「……超タイトスケジュール、だね。」——对紧迫日程平淡地确认
- 0019「おぉ……思いのほか深刻な状況だった。」——听完千奈的哀叹后的反应
- 0022「千奈のプロデューサーはわたしの同類。／その意図を推察するのはたやすい。」——自认和千奈的制作人是同类
- 0024「ん～……身もふたもない感じに／なっちゃうから、むり。」——拒绝直接给答案
- 0026「千奈には自力で答えに／たどりついてほしい。」——推测制作人的意图
- 0028「千奈……目をつむって。」——改用引导的方式
- 0034「あとは……想いを言葉にするだけ。／千奈なら、きっとできる。」——引导的落点，带着信任
- 0035「……これが、／わたしに言える……ぎりぎり。」——明说自己有意只说到这里
- 0047「……任せて、千奈会長。」——答应帮忙，叫千奈“会長”
- 0048「来年の生徒会は、こんなふうに、／ままならない日々が続きそう。」——对明年生徒会的展望

## 行为模式
- 朋友状态不对 → 主动去问，并直说“因为是朋友、一直看着你”；说完自己也害羞，但坚持说出口（0001～0005）
- 被求助要答案 → 不直接告诉，认为直说就没意思了，改为让对方闭眼想象、一步步引导，并说明自己只能说到这里（0024～0035）
- 推测别人的意图 → 以“同类”自居，从自己的角度推（0022、0025、0026）
- 被请求帮忙 → 简短答应“任せて”（0047）
- 面对忙乱的前景 → 用“ままならない日々が続きそう”平静地说出来（0048）

## 关系
- 千奈：叫「千奈」（0001、0006、0034），最后叫「千奈会長」（0047）；千奈叫她「篠澤さん」（0002、0036），说她的友情“くすぐったい”（0004）。主动关心、只引导不代答，相信她“きっとできる”（0034）
- 千奈的制作人：称“千奈のプロデューサー”，说他是自己的“同類”，推测他也希望千奈自己找到答案（0022～0026）

## 档案类事实
- 自称和千奈的制作人是“同類”（0022）
- 和千奈一起准备选举 live，并说起“来年の生徒会”（0012、0048）
- 提到『N.I.A』『H.I.F』本戦（0031、0032）

## 不确定
- 0047 称千奈“千奈会長”、0048 说“来年の生徒会”，可见千奈在参加生徒会选举，広会在明年的生徒会里；但两人的具体职位、选举结果这一话没写明（同线的亲爱度 adv_dear_kcna_026 笔记里，広问这次选举战的成员是否就是明年的生徒会，千奈说打算如此，两处一致）。
- 0022“わたしの同類”是指哪方面相似（性格、教人的方式等）没有说明。
- 【译文】0048 译文加了引号并作“明年的学生会看来也会，／延续这段不尽如人意的日常呢”，原文没有“也”，只是说明年的生徒会大概会像这样继续手忙脚乱的日子。
