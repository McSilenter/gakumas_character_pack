# P卡 倉本千奈【未知万千 广阔无限】 / 第3话 未知万千 广阔无限 第3话（adv_cidol-kcna-3-016_03）

- 她的台词：17 行（含用匿名标签说的 0 行）
- 出场的人：千奈（25 行）、広（17）、一同（1）
- 场景：组合 live 临近、练习终于赶上之后的休息日（0005、0008、0039）；有挂着布的墙的房间，具体地点看不出
- 世界线：亲爱度（倉本千奈）·P卡；制作人在制作的偶像：倉本千奈（这一话制作人没有出场，剧本里看不出）

## 发生了什么
两人的组合『ゆめぱしー』在 live 前终于赶上进度，広提议今天好好休息。千奈说之前约好要画两人的画，现在完成了，広说记得、为此拍了很多资料照片，还说当时有点害羞。两人举行“只有两个人的揭幕式”，広夸画好，说虽然不好意思但心里暖。千奈问这次不像外星人了吧，広问她是不是意外地记仇，千奈说别人说的话她都记得，用心画了这幅画。広说千奈的 live 也总是这样，看了会开心、像在和千奈说话；又说只画了自己大家会嫉妒，下次大家一起画，请千奈教她画法。最后两人说要把这样的心情也带给大家。

## 行为模式
- 准备告一段落 → 主动提议休息，理由是为了 live 成功（0008）
- 收到为自己做的东西 → 先简短夸“いい絵”，再说不好意思但心里暖（0025、0026）
- 对方暗暗提起旧账 → 立刻察觉，用问句轻轻点破（0029）
- 被特别对待 → 想到其他人，提议下次大家一起（0036、0037）
- 说到自己不会的事 → 直接请对方教（0037）

## 关系
- 千奈：叫「千奈」（0012、0029、0034）；千奈叫她「篠澤さん」（0011）。是组合搭档；收下千奈画的两人的画，说千奈的 live 让她开心、像在和千奈说话（0034、0035）
- “みんな”：担心只画了自己会被大家嫉妒，想下次和大家一起画（0036、0037）

## 档案类事实
