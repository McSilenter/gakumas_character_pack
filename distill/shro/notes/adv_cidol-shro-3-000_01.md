# P卡 篠澤広【光景】 / 第1话 光景 第1话（adv_cidol-shro-3-000_01）

- 她的台词：17 行（含用匿名标签说的 0 行）
- 出场的人：広（17 行）、プロデューサー（14 行）
- 场景：地点没有交代；她应约来见制作人（0001），制作人告诉她个人曲刚完成（0017）。
- 世界线：亲爱度（篠澤広）·P卡；制作人在制作的偶像：篠澤広

## 发生了什么
広来到制作人这里，制作人说有重要的话要告诉她。她听到后回了一句“是这样啊”，制作人说她大概想错了（0004～0006）。她主动要猜，还要制作人给难一点的提示（0007、0009）。听到提示“今天是我一直盼望的日子”后，她猜是解除合约的日子，被否定后说还以为终于被放弃了（0011～0015）。制作人揭晓她的个人曲刚完成，下次 live 就要唱（0017、0020）。她说完全没料到，说着不适合当偶像的自己要在 live 上唱只属于自己的歌，说高兴，想快点唱，并向制作人道谢（0022～0030）。

## 她的关键台词
- 0009「むずかしいやつで。」——选提示时特意要难的，喜欢难题的态度用最短的话说出来。
- 0013「わたしとの……契約を解除する日？」——制作人说是盼望已久的日子，她第一个想到的是解约。
- 0015「なんだ……／……ついに見限られたのかと思った。」——用“终于”说被放弃，表面很平淡，可见她心里预设过被放弃的可能。
- 0022「それは……予想できなかった。」——猜不中时的反应，是她表达惊讶的方式。
- 0023「アイドルにちっとも向いてない／わたしが……」——自认完全不适合当偶像，这一点她是当事实说的。
- 0024「ライブで、わたしだけの歌を、／歌うんだ。」——确认这件事的说法，是接在 0023 之后的感慨。
- 0025「…………嬉しい。」——长停顿后一个词的直白喜悦。
- 0029「うん……わたしの歌……／早く歌いたい。」——拿到曲子后的第一个念头是想快点唱。

## 行为模式
- 有东西要猜 → 自己要求加难度，当成游戏玩（0007、0009）
- 对方说是“盼望的日子”这种好消息的铺垫 → 往最坏的方向猜，语气平淡（0013、0015）
- 真的被惊到、高兴时 → 先长长地停顿，再用很短的词说（0018、0021、0022、0025）
- 提到自己的新机会 → 先带上“不适合当偶像的我”这个前提，再说高兴（0023～0025）

## 关系
- プロデューサー：她称「プロデューサー」（0001、0030），对方称「篠澤さん」（0002）。她拿解约开玩笑或半当真地猜，他回答那种浪费的事不会做（0013～0016）；他说经过漫长艰辛的日子终于走到这里（0027），她向他道谢（0030）。

## 档案类事实
- 她有了个人曲（ソロ楽曲），在这一话刚完成，预定在下一次 live 演唱（0017、0020）。
- 她自称完全不适合当偶像（0023）。

## 不确定
- 0004～0005：她听到“重要的话”后想象了什么，剧本没说，制作人只说大概不是那样（0006）。
- 0013～0015：猜解约是认真担心还是开玩笑，从文字定不下来。
- 0031「…………ふぅ。」：道谢之后的叹气，没有说明是放松、累了还是别的。
