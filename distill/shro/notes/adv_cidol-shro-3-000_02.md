# P卡 篠澤広【光景】 / 第2话 光景 第2话（adv_cidol-shro-3-000_02）

- 她的台词：34 行（含用匿名标签说的 0 行）
- 出场的人：広（34 行）、プロデューサー（18 行）
- 场景：地点没有交代；试听个人曲，然后看制作人准备的编舞视频（0002、0024）。中间在 0032 和 0033 之间有时间跳转。
- 世界线：亲爱度（篠澤広）·P卡；制作人在制作的偶像：篠澤広

## 发生了什么
広试听自己的个人曲，把制作人比作在她开口要之前就把想要的玩具买来的人，并说自己当偶像以来一直像这首曲子一样兴奋（0002～0011）。问她能否在下次 live 前练好，她笑着说好像不行，说这种笑是在模仿朋友（0016～0019）。理由是按她学舞的速度赶不上（0022～0023）。制作人让她先看编舞视频，视频是他自己跳的（0024～0027）；编舞和歌词她马上都记住了（0029、0031）。之后她“努力地长篇”分析自己不擅长跳舞的两个原因，结论是下次 live 只能跳由她做得到的动作组成的舞，再次先笑一下，这回说看来做得到（0037～0047）。她说制作人很了解自己，不用担心，说喜欢他这一点（0049～0052）。

## 她的关键台词
- 0005「わたしが欲しいおもちゃを、おねだり／する前に買ってくれる人。」——她对制作人的比喻，把曲子和想要的玩具等同。
- 0011「この曲みたいに……わくわくしてる。」——接 0009、0010：辛苦的练习、拼命唱跳，她一直是兴奋的。
- 0017「無理っぽい。」——笑着下否定结论的典型例子。
- 0019「友達の真似。……かわいい？」——她说笑着说否定结论是学朋友的，还反问可不可爱。
- 0034「……がんばって、／長く、話してもいい？」——说长话对她是要事先申请的事。
- 0036「たくさん話すと、疲れるから。／……すぅ。」——说话多也会累，长篇前先吸一口气。
- 0037「わたしがダンスを苦手な理由は2つ。／体力がないことと関節がかたいこと。」——冷静列举自己的短处。
- 0038「どちらもすこし改善された。いくつかの／曲は歌って踊れるようになった。」——也如实说已有的进步。
- 0044「次のライブで踊れるのは、わたしに／できる動きだけで構成されたもの。」——分析的结论，条理清楚。
- 0047「やれそう。」——同样先笑（0046），结论却相反，反过来吓了制作人一下。
- 0052「そういうところ……好き。」——直接说喜欢他了解自己这一点。

## 行为模式
- 被问能不能做到 → 先笑一声，再给结论，否定时也带笑（0016、0017、0046、0047）
- 要讲一大段 → 先征求同意，说明话多会累，吸一口气，然后条理分明地分点说（0034、0036、0037～0044）
- 记动作、记歌词这种靠脑子的事 → 看一遍立刻说记住了（0029、0031）
- 说起自己的不足 → 用分析的口吻，不带沮丧，同时指出改善之处（0037、0038、0041～0044）
- 想表达对他的好评 → 用比喻，说完还自我满意（0004～0006）
- 对方把事情准备到位 → 直接说出信任和喜欢（0049、0050、0052）

## 关系
- プロデューサー：她称「プロデューサー」（0001、0026、0049）；这一话制作人没有叫她的名字。他把编舞自己准备成视频（0026、0027），她看了视频后说看来做得到（0045～0047）；她说他很了解自己，什么都不用担心（0049、0050）。他对她笑着说否定结论的做法吐槽，说对心脏不好，让她别这样铺垫（0018、0048）。

## 档案类事实
- 学舞速度慢：她自己说按学舞的速度赶不上 live（0022、0023）。
- 不擅长跳舞的原因有两个：没体力、关节硬（0037）。两者都有一点改善，有几首曲子已能边唱边跳（0038）。
- 现阶段静止也做不了的姿势，要等关节变软才做得了，她说那是很久以后的事（0041～0043）。
- 编舞和歌词能马上记住（0029、0031）；制作人说她长处和短处都很惊人（0032）。
- 说话多会累（0036）。
- 笑着说否定结论是在模仿朋友（0019）。

## 不确定
- 0019：模仿的“朋友”是谁，这一话没有说。
- 0029、0031：两句「覚えた。」之前隔了多久剧本没写，看起来是当场记住，但不能确定。
- 0027：视频里跳舞的是制作人本人（0026 她说他跳得好，他回说是自己准备的）。
