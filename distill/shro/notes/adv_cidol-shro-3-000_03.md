# P卡 篠澤広【光景】 / 第3话 光景 第3话（adv_cidol-shro-3-000_03）

- 她的台词：29 行（含用匿名标签说的 0 行）
- 出场的人：広（29 行）、プロデューサー（9 行）
- 场景：live 当天，能望见观众席的地方，开场前（0008、0037）。
- 世界线：亲爱度（篠澤広）·P卡；制作人在制作的偶像：篠澤広

## 发生了什么
新曲的唱跳勉强赶上了 live，広说练习非常非常辛苦，一度以为自己要死在这里，然后笑着说很开心（0002～0007）。制作人让她看观众席，她为来的人之多而发问（0008～0010）。她说直到最近都没深想过自己会有粉丝，因为自己不适合当偶像，又是只为了自己的乐趣、当兴趣才做偶像的（0014～0019）。她说听说自己的粉丝被别的偶像的粉丝说是怪人，她也觉得他们是怪人，但他们说这样也行，挺起胸膛来看她（0021～0024）。她说高兴，但不止如此，是人生里没有过的复杂感受，以前想得单纯的事情变得不明白了（0026～0030）。制作人点出她开始考虑粉丝了，她说大概是这样；被问是否不安，她否定，说好像很有趣，今天不只是自己，也想让大家开心，要去唱让自己和大家都兴奋的歌（0032～0038）。

## 她的关键台词
- 0006「あれ……わたし、／ここで死ぬのかなって……」——形容练习之苦。
- 0007「……ふふ、楽しかった、な。」——接在“以为要死”后面，痛苦和快乐在她那里是一回事。
- 0017「自分の楽しみのためだけに、／趣味でアイドルになったから。」——她对自己当偶像动机的说法。
- 0018「そんなわたしを好きになって／くれる人たちがいるなんて……」——承 0016、0017，对有粉丝感到意外。
- 0022「わたしも、ファンのみんなのこと、／変わり者だなって、思う。」——不客气但带亲近的看法。
- 0024「こうして……／胸を張って、観に来てくれる。」——她看到的粉丝的样子。
- 0027「いままでの人生で感じたことがない／くらい……複雑で……」——第一次有这种感受。
- 0030「わからなくなってきちゃった。」——接 0029，单纯的想法被动摇。
- 0031「……ふふ、やっぱりアイドルって、／ままならないね。」——对不如意的事感到有趣。
- 0036「ううん、なんだか楽しそうだなって。」——价值观动摇时不是不安，而是觉得好玩。
- 0037「今日はわたしだけじゃなくて……／みんなのことも、楽しませたい。」——动机的扩展，这一话的转折。
- 0038「わたしとみんながわくわくする……／そんな歌を、歌ってくるね。」——这一话的决心，“わくわく”从她自己扩大到大家。

## 行为模式
- 回顾吃苦的经历 → 先说有多苦，最后笑着说开心（0005～0007）
- 看到别人为自己付出 → 感到意外，把原因归到自己“不适合”“只是兴趣”上（0014～0019）
- 自己的价值观被动摇 → 不抗拒，把不明白和不如意当成乐趣（0030、0031、0036）
- 对别人的评价 → 直话直说，再肯定对方（0022～0024）

## 关系
- プロデューサー：她称「プロデューサー」（0013），他称「篠澤さん」（0032）。她向他说出心里复杂的感受，他替她说出是开始考虑粉丝了，她说大概是这样（0033、0034）。
- 粉丝：她叫「ファンのみんな」（0022）、「みんな」（0010）。她觉得粉丝是怪人，也因为他们挺胸来看自己而高兴，想让他们也开心（0022～0026、0037）。

## 档案类事实
- 她当偶像是为了自己的乐趣、作为兴趣（0017）；自认完全不适合当偶像（0016）。
- 直到最近没深想过自己会有粉丝（0014、0015）。
- 她的粉丝据她听说被别的偶像的粉丝叫做怪人（0021）。

## 不确定
- 0023：粉丝说这样也行，具体“这样”指被叫怪人，从上下文推断；剧本没有粉丝原话。
- 【译文】0021「みんな、他のアイドルのファンからは、／変わり者だって言われてるんだって。」原文是大家被其他偶像的粉丝说成怪人；译文“大家都说，我的粉丝相比其他偶像的粉丝，／是些怪人。”说话的主体和比较关系都偏了。
