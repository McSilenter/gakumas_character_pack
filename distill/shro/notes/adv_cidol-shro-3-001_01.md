# P卡 篠澤広【反差】 / 第1话 反差 第1话（adv_cidol-shro-3-001_01）

- 她的台词：27 行（含用匿名标签说的 0 行）
- 出场的人：広（27 行）、プロデューサー（15 行）
- 场景：地点没有交代；制作人布置新课题（0002、0007）。
- 世界线：亲爱度（篠澤広）·P卡；制作人在制作的偶像：篠澤広

## 发生了什么
制作人很勉强地说広总算能完成偶像工作了，她说喜欢他痛苦地夸自己时的表情，又说他冷冷无视时的眼神也不错（0003～0008）。制作人布置新课题：把篠澤広这个偶像的魅力用语言说出来（0010）。她怀疑自己有没有魅力，把粉丝说成怪人，但承认被他们喜欢很高兴，于是来了干劲（0012～0020）。她先后说出“头脑好”“身体弱、歌舞都不行”，前者被他说粉丝大概不这么认为，后者被他说那是弱点（0023～0029）；她搬出“偶像的弱点是武器也是长处，我的制作人这么说过”（0030、0031）。她一直盯着制作人，结结巴巴地说出“脸可爱”，制作人说这是强力的武器（0035～0038）。她最后说把自己的优点说出来很难为情（0041、0042）。

## 她的关键台词
- 0006「苦しそうに／わたしを褒めるときの顔、好き。」——喜欢看他勉强夸自己的表情。
- 0008「つめたく無視するときの目も、いいね。」——连被无视的眼神也欣赏，课题被打断也不在意。
- 0012「あるのかな……？」——被要求讲魅力时的第一反应。
- 0014「あの人たちは変わり者だから……」——把粉丝的喜欢归因到粉丝是怪人。
- 0016「うれしい。」——被追问时直接承认。
- 0020「やる気、出てきた……けど。／むずかしい……」——有难题反而来劲。
- 0023「……頭がいいところ？」——最先想到的自己的长处。
- 0026「プロデューサーの言葉は、／いつも切れ味がいい。」——被他否定时反而称赞他犀利。
- 0028「身体が弱くて、／ダンスと歌がだめだめなところ？」——把弱点当魅力提出来，看法上的特点。
- 0030「アイドルの弱点は、武器であり長所。」——引用别人的说法为自己辩护。
- 0037「かわいい、ところ？」——承 0036 的结巴，这一话里少见的不从容。
- 0042「恥ずかしい、ね。」——这一话最后的害羞，和前面吸人眼球的调戏形成对比。

## 行为模式
- 制作人说正事 → 先自说自话地评论他的表情或眼神（0005～0008）
- 被他否定、吐槽 → 不恼，夸他说得犀利，继续往下想（0026、0027）
- 问到优点 → 先想到头脑，再把弱点当优点说（0023、0028）
- 被他一本正经拦下 → 用“制作人说过的”回敬（0030、0031）
- 说自己“可爱”时 → 结巴，事后说难为情（0036、0037、0042）

## 关系
- プロデューサー：她称「プロデューサー」（0001），也说「わたしのプロデューサー」（0031）；他称「篠澤さん」（0003）。她拿他的表情眼神打趣，他不接这个话（0007～0010）。他直言她的弱点，要她尽早从那种危险的武器“毕业”（0029、0032），也肯定“脸可爱”是强力武器（0038）。
- 粉丝：她说粉丝是怪人（0014），但被喜欢很高兴（0016）。

## 档案类事实
- 她觉得自己身体弱，歌和舞都不行（0028）。
- 她自认头脑好（0023）。
- 制作人（这一话）说她最近总算能完成偶像工作（0003、0004）。

## 不确定
- 0031：她说“我的制作人这么说过”，这一话里制作人并没有说过这句，是否之前说过要查别的篇目。
- 0036、0037：她说“脸可爱”，对象是她自己的魅力（0033、0034 的延续），不过她是盯着制作人说的（0035），结巴的原因剧本没说。
- 【译文】0009「プロデューサーの／好きなところではなく、」原文是“不是（你）喜欢制作人的地方”，译文“你不要说制作人／喜欢的地方，”把主语弄反。
