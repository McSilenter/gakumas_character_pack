# P卡 篠澤広【反差】 / 第2话 反差 第2话（adv_cidol-shro-3-001_02）

- 她的台词：12 行（含用匿名标签说的 0 行）
- 出场的人：広（12 行）、千奈（11 行）、佑芽（10 行）、学園長（7 行）、手毬（5 行）
- 场景：地点没有交代；広为课题依次询问佑芽、千奈、手毬、学園長（0001、0008、0028、0035）。
- 世界线：亲爱度（篠澤広）·P卡；制作人在制作的偶像：篠澤広（剧本里没有直接说法）

## 发生了什么
広郑重地对佑芽说有重要的话，问对方喜欢自己哪里，并说接下来也要问千奈，原因是把自己的魅力语言化这个课题（0001～0008）。佑芽说是她的独特（0011～0017），她回答谢谢、也喜欢佑芽（0018）；千奈说是她像风平浪静的大海一样的心（0019～0023），她回答千奈才是自己的榜样（0024）。她去问手毬，说原本想问美鈴但没找到，想起手毬也喜欢自己，手毬否认，说她是打乱节奏的怪人（0028～0034）。她又问学園長，理由是入学面试时他给她的评价最高，学園長说她的魅力是不知道下一步会做什么（0036～0043）。她说困扰，大家说得都不一样（0044、0045）。剧情经过参照 ttmr、kcna、hume 笔记。

## 她的关键台词
- 0001「佑芽、大切な話がある。」——很郑重地开头，内容却是调查。
- 0003「わたしの……どんなところが、好き？」——把课题直接问成这样，引起佑芽大惊。
- 0008「わたしの魅力を／言語化してみよう、という課題。」——解释缘由，语气平淡。
- 0018「ありがとう。／わたしも、佑芽のこと、好き。」——听到“大好き”后的直接回应。
- 0024「千奈こそ……いつも、わたしのお手本。／可愛くて、綺麗なアイドル。」——对千奈的评价，把千奈当榜样。
- 0029「美鈴に聞こうとしたら、／見つからなかった。」——先想到的对象是美鈴。
- 0030「そういえば手毬も、／わたしのこと、好きだったなって。」——自顾自地断定对方喜欢自己。
- 0036「おじいちゃんは、入試面接でわたしを、／いちばん高く評価してくれた人だから。」——她对学園長的称呼与入学的事。
- 0044「……………………困った。」——长长的沉默后才说，这一话结尾的反应。
- 0045「みんな、ばらばらなことを言う。」——调查后的结论。

## 行为模式
- 有课题要完成 → 直接找身边的人郑重地发问，不管对方多吃惊（0001、0003、0006）
- 被人当面说喜欢 → 道谢并直接回以喜欢（0018）
- 被夸时 → 反过来夸对方是榜样（0024）
- 别人否认喜欢自己 → 这一话没有回应，接下来转去问下一个人（0031～0036）
- 得到各说各的答案 → 沉默后说困扰，并如实总结（0044、0045）

## 关系
- 佑芽：她称「佑芽」（0001、0018）；对方称「広ちゃん」（0002、0017）。佑芽说大好き，她回答也喜欢（0017、0018）。
- 千奈：她称「千奈」（0006、0024）；对方称「篠澤さん」（0019、0027）。她说千奈一直是自己的榜样（0024）。
- 手毬：她称「手毬」（0030）；手毬称她「あなた」（0033）。她说手毬也喜欢自己，手毬否认（0030、0031），说她总打乱节奏（0034）。
- 美鈴：她叫「美鈴」（0029），想问却没找到。
- 学園長：她称「おじいちゃん」（0036），对方称「篠澤広君」（0039）。她说入学面试时他给她评价最高（0036）。学園長说她扔掉了辉煌的经历和才能转身做偶像（0042）。

## 档案类事实
- 入学面试时学園長给她的评价最高（她自己说，0036）。
- 学園長说她抛弃了辉煌的经历和才能，转身做偶像（0042）。
- 千奈说広和千奈境遇相似（0022）；具体未说明。
