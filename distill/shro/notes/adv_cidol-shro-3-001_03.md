# P卡 篠澤広【反差】 / 第3话 反差 第3话（adv_cidol-shro-3-001_03）

- 她的台词：30 行（含用匿名标签说的 0 行）。其中 0011、0030～0033 是转述别人的话，0005 是转述自己的提问。
- 出场的人：広（30 行）、プロデューサー（18 行）
- 场景：地点没有交代；她把调查资料拿给制作人看（0002、0003）。
- 世界线：亲爱度（篠澤広）·P卡；制作人在制作的偶像：篠澤広

## 发生了什么
広把向喜欢自己的人做的调查资料拿给制作人看，其中有叫『おじいちゃん』的文件，指的是学園長（0003～0007）。她说大家说得各不一样，困扰，问魅力是不是种类太多，并问制作人是不是也不明白；他说自以为明白，但难以用语言说明（0010～0015）。他说她肯定也问了亲戚和以前的朋友熟人，让她交出未提交的资料（0018～0021），她先说探听女孩子的秘密不好，他说只是想知道入学前的魅力，不用于偶像活动（0023～0025）。她转述以前的人说喜欢她冷、无机质、人情味淡，最棒的是像简素的电子表那样的功能美（0030～0033）。她说偶像前后的魅力各不相同，只有一点点相同，搞不懂（0038～0040）；他说或许这就是魅力，并按她要求说得长一点：冷又暖、无机质又有人情味、既是天才又非才（0041～0045）。她听后说这样的地方喜欢，如果能这样被认为就好了（0047、0048）。

## 她的关键台词
- 0004「わたしのことを好きそうな人たちに……／聞き取り調査をしてきたの。」——把魅力课题做成了调查。
- 0009「ふふ……そこがわたしの魅力らしい。」——把别人的评价当情报。
- 0012「困っちゃった。わたしの魅力……／種類ありすぎって、こと？」——困扰中带点自得。
- 0014「もしかして……わたしの魅力、／プロデューサーもわかってなかった？」——反问他。
- 0022「……わたしのこと、よくわかってるね。」——承认他猜中了。
- 0023「……でも。女の子の秘密を／探ろうとするのは、よくないと思う。」——不想被探究过去时的回避方式。
- 0026「……たぶん、参考にはならない、よ？」——她对过去评价的态度。
- 0030「つめたくて、無機質で、／人間性が薄くて……」——转述从前的人对她的喜爱之处。
- 0033「機能美です、って、言ってた。」——转述，接 0032 的电子表比喻。
- 0039「やっぱり、ばらばらで……／ちょっぴりだけ同じで……」——偶像前后的自己。
- 0040「よくわからない。」——她对这个课题的结论。
- 0044「もうちょっとがんばって、／言ってみよう。」——不满足于“搞不懂”这种过短的总结，让他说长一点。
- 0048「ふふ……／そう思ってもらえたら、いいな。」——听完他的总结后的回应。

## 行为模式
- 拿到课题 → 系统地调查、整理成资料，还会给资料命名（0003～0006）
- 被问到过去 → 先用玩笑话挡一下，对方说明目的后还是说出来（0023～0029）
- 他猜中自己的做法 → 承认他了解自己（0021、0022）
- 自己也得不出结论 → 如实说不明白（0040）
- 对方总结得太短 → 让他再努力说长一点（0043、0044）

## 关系
- プロデューサー：她称「プロデューサー」（0001、0014）；他称「篠澤さん」（0006）。他猜中她问了过去的朋友，她说他很了解自己（0020～0022）。他说想知道入学前的她的魅力，不用于活动（0024、0025）。两人一起看资料烦恼（0016、0017）。
- 学園長：她称「学園長のおじいちゃん」（0007）。

## 档案类事实
- 初星学園入学以前有喜欢她的人，他们说喜欢她冷、无机质、人情味淡，神秘、特别、惊人、独特（0028～0031）；最棒的是像简素电子表一样的功能美（0032、0033）。
- 入学前的事制作人想知道，但他说不用于偶像活动（0024、0025）。
- 制作人（这一话）说她是冷又暖、无机质又有人情味、既是天才又非才的人（0045）。

## 不确定
- 0047「……そういうところが好き。」谁喜欢谁定不下来：可能是对制作人说（第2话 0052、本线第1话等她说过同样的话），也可能接着 0048 的“被这么认为就好了”说的是粉丝。
- 0048：“被这么认为”的对象是谁（粉丝？他？）没有明说。
- 0011 的总结里，把佑芽、手毬、千奈说的放在一起，但调查对象以外的说法未列出。
- 【译文】0007「学園長のおじいちゃんのこと。」原文指学園長本人这位老爷爷；译文“是学院长的爷爷”读起来像学園長的祖父。
