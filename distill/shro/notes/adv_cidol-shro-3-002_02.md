# P卡 篠澤広【变装狂想曲】 / 第2话 变装狂想曲 第2话（adv_cidol-shro-3-002_02）

- 她的台词：34 行（含用匿名标签说的 0 行）
- 出场的人：広（34 行）、プロデューサー（10 行）；旁白 1 行（0022）
- 场景：地点没有交代；两人看制作人带来的万圣节资料和恐怖电影（0004、0005、0022）。
- 世界线：亲爱度（篠澤広）·P卡；制作人在制作的偶像：篠澤広（剧本里没有直接说法）

## 发生了什么
制作人带来了世界各地万圣节活动的视频、现成服装、恐怖电影和幕后花絮（0004、0005）。広选恐怖电影，邀他一起看，说本来去电影院或鬼屋也行，他觉得外出时看这么刺激的东西开玩笑吧，她说过度保护的制作人反对所以暂时放弃，并宣布总有一天要挑战，还要和他一起坐旋转过山车（0008～0014）。她看幕后花絮时对假血和特效化妆很感兴趣，又问为什么先看花絮，他的理由没说完，她说他太担心，说自己没事（0015～0021）。看恐怖片时她发出“呀”的声音，他说放心了、看来她完全不怕，她说作战失败（0023～0025）。她分享对恐怖的分析，又说有可靠的人在旁边也不会变得害怕，结论是这次万圣节不适合恐怖路线，因为给孩子们发糖不需要吓人的丧尸和幽灵（0026～0036）。他拿出现成的鬼怪服装，她发觉他从一开始就知道会这样，问他是不是那么想和自己一起看电影；他说对她来说自己想通的过程才重要；她笑了，说下次去电影院看（0038～0045）。

## 行为模式
- 遇到新领域 → 看幕后、看材料的真实度，做分析，得出若干条知见（0015～0017、0026～0028）
- 他出于担心反对 → 说他过度保护，表示只是现在放弃，说以后一定要挑战（0012、0013、0021）
- 想看他反应 → 假装害怕，失败后说作战失败（0023～0025）
- 发现他事先安排好 → 反过来把这说成是他想和自己一起（0040、0041）
- 自己想通了 → 给出明确结论和理由（0035、0036）

## 关系
- プロデューサー：她称「プロデューサー」（0001、0014），说他「過保護」（0012）、「心配性」（0021）。他称「篠澤さん」（0011、0042）。他不同意在外看刺激内容（0011），并提前准备好现成服装（0037、0038）。她提出以后要一起去鬼屋、坐过山车、去电影院，都是打算（0013、0014、0045）。

## 档案类事实
- 她想挑战鬼屋（这一话说本来也行）和旋转过山车（0010、0013）。
- 她说自己没事，制作人还是因担心不让看刺激内容（0011、0020、0021）。
- 学园万圣节活动的内容有给孩子们发糖（0036）。
