# P卡 篠澤広【变装狂想曲】 / 第3话 变装狂想曲 第3话（adv_cidol-shro-3-002_03）

- 她的台词：19 行（含用匿名标签说的 0 行）
- 出场的人：広（19 行）、プロデューサー（11 行）、学園長（4 行）、校内放送（2 行）
- 场景：学园的万圣节活动结束后，制作人和她谈话（0007、0008）。开头是她吓学園長的片段（0001～0004）和校内广播（0005、0006）。
- 世界线：亲爱度（篠澤広）·P卡；制作人在制作的偶像：篠澤広

## 发生了什么
広对学園長喊了一声“ばぁ！”，学園長大叫（0003、0004）；校内广播把她的制作人叫到学園長室（0005、0006）。制作人说学园的万圣节活动顺利成功，她说和孩子们愉快地交流了，多亏他的帮助（0008～0011）。他提到她和孩子们一起到处恶作剧，她说想让孩子们在今天玩得开心（0015、0016）。他说トリック・オア・トリート不能一上来就恶作剧，她笑着说喜欢他困扰的表情，然后道歉（0018～0020）。他转交学園長送来的蛋糕，带话说下次不会被吓到，她说这样啊，邀他一起吃（0021～0026）。听说孩子们也会来万圣节 live，她说活动还没结束，打算让孩子们尝尝被恶作剧的感受，也要在 live 上让被恶作剧添了麻烦的人觉得今天开心，并说要送上有趣幸福的夜晚（0028～0036）。

## 她的关键台词
- 0003「ばぁ！」——这一话开头的恶作剧。
- 0009「うん。ばっちり、／子どもたちと楽しく交流できた。」——汇报结果。
- 0016「今日という日を……子どもたちに／楽しんでもらいたかった。」——她对恶作剧的解释。
- 0019「ふふ。／プロデューサーの困った顔、好き。」——同样喜欢看他为难。
- 0020「ごめんね。」——随后的道歉。
- 0030「なら……ハロウィンイベントは、／まだ終わってない、ね。」——听到孩子们要来后的反应。
- 0032「悪戯をされる側の気持ち、／味わってもらおう。」——计划要反过来恶作剧孩子们。
- 0033「悪戯で迷惑をかけた人たちに、今日は／楽しかったって……思ってもらおう。」——同时打算弥补。
- 0034「プロデューサーが、わたしに似合うと／思って……選んでくれた衣装で。」——说到衣服时带上他。
- 0036「面白くて、幸せな夜を……／プレゼントする、ね。」——对 live 的宣言。

## 行为模式
- 想让人开心 → 用恶作剧的方式，一起拉上孩子们（0015、0016）
- 被说教 → 笑着说喜欢他为难的样子，然后道歉（0019、0020）
- 有机会把事情继续玩下去 → 马上想下一步（0030～0032）
- 给别人添了麻烦 → 想用 live 让他们也觉得开心（0033、0035）
- 得到礼物 → 邀他一起吃（0022、0026）

## 关系
- プロデューサー：她称「プロデューサー」（0010、0026）；他称「篠澤さん」（0007、0013）。他被广播叫去学園長室（0005、0006），事后向她转交蛋糕；她说多亏他帮忙（0010），说喜欢他困扰的表情（0019）。
- 学園長：这一话她没有称呼他。她吓了他（0003、0004），他送来蛋糕，带话下次不会被吓（0021～0024）。
- 孩子们：她称「子どもたち」（0009、0016）；她说想让他们玩得开心（0016）。

## 档案类事实
- 学园的万圣节活动有孩子们参加，她和孩子们一起搞了恶作剧（0009、0015）。
- 学園長送了蛋糕给她（0021、0022）。
- 孩子们听说也会来她的万圣节 live（0028）。
- 她的 live 衣装是制作人觉得适合她、替她选的（她自己说，0034）。

## 不确定
- 0005、0006 校内广播的说话人是谁，没有标出。
- 0003 的对象是不是学園長一人：0001、0002 是他的台词，从 0003 她的「ばぁ！」和 0004 学園長的大叫推断，是她吓了他。
- 0023 学園長的台词是制作人转述时的画面，还是学園長亲口说，看不出；0024 他说是这么传话。
- 0031～0033：“让孩子们尝尝被恶作剧的感受”和“让添了麻烦的人觉得开心”这两句是打算，live 的结果这一话没写。
