# P卡 篠澤広【褪色】 / 第2话 褪色 第2话（adv_cidol-shro-3-012_02）

- 她的台词：24 行（含用匿名标签说的 0 行）
- 出场的人：広（24 行）、プロデューサー（17 行）
- 场景：地点没有交代；紧接第1话的作战会议（0001 重复第1话结尾的话）。
- 世界线：亲爱度（篠澤広）·P卡；制作人在制作的偶像：篠澤広

## 发生了什么
制作人说要把形象搞坏来降低胜率，広确认是不是先降后升，说是因为自己开始有点名气、经历快要露馅，想在此之前主动公开（0002～0007）。他还要她发表一份决别宣言，说今后无论如何只走偶像这条路（0008、0009）。她说看来会炎上，他说多数人会有坏印象，但一定有人尊重她的选择；她同意负面更多，说早有觉悟（0010～0015）。她说有许多事也没对佑芽和千奈说，虽然知道绝对没问题，还是有一点害怕（0017、0018）。他约定把公开经历的坏处降到最小，日子照旧，她说这样就放心了（0019～0021）。他又约定把公开经历的好处也降到最小，她笑了，确认即使情况变糟、有简单回复形象的办法，他也不会用那种卖法（0023～0028）。他说她想赤手空拳挑战，不必捡送上门的武器，他们是认真在做趣味（0029～0031）。她说这样离他的梦想又远了，他说这才可喜，从现在开始才有趣；她说他成绩还在下降，他说接下来由她让成绩上升（0032～0035）。她说兴奋起来了（0041）。

- 0017「佑芽や千奈にも、話してないこと、／たくさんある。」——对朋友的隐瞒。
- 0018「絶対に大丈夫だとわかっているけど……／すこしだけ、怖い、な。」——少见的说害怕。

- 0028「そういうふうには、売り出さないんだ。」——确认他的方针。
- 0032「あなたの夢から……／また遠ざかっちゃう、ね。」——她担心的是他。
- 0034「成績下がってるくせに。」——反过来吐槽他。
- 0041「わくわくしてきたね。」——这一话的结尾。

## 行为模式
- 听到难题 → 马上分析、确认，说出对方的打算（0002、0005～0007）
- 面对可能的恶果 → 用很轻的语气说，说早有觉悟（0010、0015）
- 想到朋友 → 才说害怕（0017、0018）
- 他承诺保护 → 放心（0021）
- 他选择不走捷径 → 笑出来，确认意思，然后兴奋（0024～0028、0041）
- 自己的选择影响到他 → 问他的梦想怎么办，随后吐槽（0032、0034）

## 关系
- プロデューサー：她称「プロデューサー」（0013、0040）、「あなた」（0032）；这一话他称「広さん」（0008）、「あなた」（0012、0035）。他说会用一切手段把公开经历的坏处和好处都压到最小（0019、0023），说这是认真做趣味（0031）。她说这样离他的梦想更远，他说可喜（0032、0033）。
- 佑芽、千奈：她说有很多事也没对她们说（0017），说虽然知道绝对没问题，还是有一点害怕（0018）。

## 档案类事实
- 她的经历在此前并未公开，她开始有点名气，判断快要露馅（0005、0006）。
- 公开经历的打算：主动公开，并发表今后只走偶像路的决别宣言（0007～0009）。
- 她有很多事没对佑芽、千奈说（0017）。
- 制作人的成绩（0034、0035）在下降；是她说的，他说接下来由她让成绩上升。

## 不确定
- 0034「成績下がってるくせに。」和 0035：“成绩”指制作人的什么成绩，这一话没有说明。
- 0032：“あなたの夢”和第1话 0004 的“ふたりの夢”是什么关系，这一话没有明说。
- 0018：“绝对没问题”指朋友们不会变，还是别的，这一话没有明说。
- 0007 是她的推测，0008 起制作人说「その上で」，没有否定，但没有逐字承认。
