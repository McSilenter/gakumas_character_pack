# P卡 篠澤広【褪色】 / 第3话 褪色 第3话（adv_cidol-shro-3-012_03）

- 她的台词：28 行（含用匿名标签说的 0 行）。其中 0001、0002 和 0035～0044 是她转述制作人的话（0045 她说「――だって。」），0023～0027、0031、0032 是转述其内容；0042 里的「俺」是制作人的自称。
- 出场的人：広（28 行）、佑芽（11 行）、千奈（9 行）；制作人没有出场
- 场景：地点没有交代；她向佑芽、千奈说过自己的事之后（0011、0012），讲制作人的话（0001、0002、0023）。
- 世界线：亲爱度（篠澤広）·P卡；制作人在制作的偶像：篠澤広

## 发生了什么
広向千奈和佑芽转述制作人第2话的话，千奈发出陶醉的声音，佑芽说他帅、简直是结婚的约定（0001～0006）。広说非常开心，心动了（0007、0008）。她说今天很紧张，因为有很多事瞒着两人（0011、0012），千奈说能告诉她们很高兴、更喜欢她了，佑芽说早知道她很厉害，是好偶像、自己的親友（0013～0017）。千奈、佑芽问之后怎么制作，広转述：之前是选偶像容易理解的部分、突出内心两面性，以后要多展现亲近的人才知道的各种篠澤広（0023～0027）。她接着用制作人的语气说，要让粉丝体验皮肤发麻的刺激，一起提心吊胆，接下来要唱灼热的曲子，千奈说风向不对，佑芽问应援偶像为什么要刺激（0031～0045）。她说刚才还很不安，现在满是热切的心情，想快点唱（0046～0048）。剧情经过参照 hume、kcna 笔记。

## 她的关键台词
- 0007「すごく……うれしかった。」——接在转述之后的直白心情。
- 0008「きゅん♡　って、なった。」——用拟声词说心动。
- 0011「あの、ね。わたし、今日、緊張してた。」——说出紧张。
- 0012「ふたりに黙ってたこと……／たくさんあった、から。」——紧张的原因。
- 0019「……こちらこそ。」——对千奈“今后请多关照”的回应，简短。
- 0026「今後はもっと、親しいひとしか／しらないような……」——接下来的方针（转述）。
- 0032「肌がひりつくようなスリルを／体験してもらう、って。」——转述的方针，她是笑着说的（0031）。
- 0039「これからは、みんなで一緒にハラハラ／しましょう。」——用制作人的语气，转述。
- 0041「胃を痛めながらも目を離せず、／永遠に魅了され続ける地獄――」——转述，宣传词式的说法。
- 0045「――だって。」——转述的收尾。
- 0046「あんなに不安だったのに……／いまは、こんなに……」——她自己的感受。
- 0047「熱い気持ちで、いっぱい。」——接 0046。
- 0048「はやく、歌いたい、な。」——这一话的结尾，和光景第1话 0029 同样的愿望。

## 行为模式
- 被人说了心动的话 → 告诉朋友，直说高兴、心动（0001、0002、0007、0008）
- 紧张、隐瞒 → 事后自己说出来（0011、0012）
- 朋友接受自己 → 很短地回应（0019）
- 说到制作人的打算 → 能长段模仿他的语气复述，带着笑（0031、0035～0045）
- 听到“接下来要唱灼热的曲子” → 不安变成热切，想快点唱（0046～0048）

## 关系
- 佑芽：对方称「広ちゃん」（0015），说她是親友（0017）；她没有叫佑芽的名字，这一话对两人都称「ふたり」（0012）。
- 千奈：对方称「篠澤さん」（0014）；说更喜欢她了（0014）。
- プロデューサー：她称「プロデューサー」（0031）；转述中他称她「広さん」（0043）。她说听到他的话非常高兴、心动（0007、0008）；佑芽称他「広ちゃんのプロデューサーさん」（0004），千奈称「篠澤さんのプロデューサー」（0020）。

## 档案类事实
- 她向佑芽、千奈说过瞒着她们的事（0011、0012）；具体内容这一话没写。
- 佑芽说広是親友，很聪明、可爱、漂亮（0016、0017）。
- 她的宣传方针：要展现亲近的人才知道的各种篠澤広（0023～0027）；接下来要唱的是灼热的曲子（0043、0044）。

## 不确定

- 0035～0044 全程用了制作人的语气，是否逐字转述，无从确认。
