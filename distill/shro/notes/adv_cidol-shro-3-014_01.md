# P卡 篠澤広【奇迹正是现在(ﾟ∀ﾟ)！】 / 第1话 奇迹正是现在(ﾟ∀ﾟ)！ 第1话（adv_cidol-shro-3-014_01）

- 她的台词：28 行（含用匿名标签说的 0 行）
- 出场的人：広（28 行）、プロデューサー（13 行）
- 场景：大阪，为 live 而来（0005），live 之前（0013）。
- 世界线：亲爱度（篠澤広）·P卡；制作人在制作的偶像：篠澤広

## 发生了什么
広邀制作人约会，他问她是否清楚现状，她说两人是为了 live 来到大阪，大阪 live 这个说法听起来像正经偶像（0002～0006）。他说她现在就是正经偶像，她说要好好完成工作，话虽如此还是约会吧（0007～0010）。她说看到大阪的街道很兴奋，想在 live 前看看粉丝住的街道，并说知道一脸不情愿的他其实在替自己想约会方案（0012～0017）。他说准备了合适的观光方案，她说果然，又问是不是期待和她约会，他说期待陪同担当偶像观光，两人“约会”“观光”互不相让（0018～0024）。她看到比 live 资料还多的观光资料，说制作人的爱很重（0028、0029）。他推荐 live 会场附近的方案，并说她也会想买土产、向朋友炫耀；她说这样几乎不用商量了，他说商量的时间也算在方案内，她说您说得对，约会已经开始了（0033～0041）。

## 她的关键台词
- 0002「デート、しよ。」——这一话的开头。
- 0006「大阪ライブ……いい響き。／ちゃんとしたアイドルっぽい。」——对大阪 live 的感想。
- 0008「プロデューサー……うれしそう。／わたしも、同じ気持ち。」——看到他高兴，自己也一样。
- 0010「それはそれとして、デートしよ。」——说完正事马上转回。
- 0013「ライブの前に、ファンのひとたちが／住む街を、見て回りたいから。」——她想约会的理由之一。
- 0017「わたしのために、デートプランを／考えてくれているって。」——说破他的准备。
- 0022「デート。」——一个词纠正“观光”。
- 0024「……ふーん。まぁいいや。」——不再争。
- 0029「プロデューサーの愛が重い……」——对资料量的吐槽。
- 0038「もう……ほとんど相談、いらないね。」——被他猜中后。
- 0040「……………………おっしゃるとおり。」——长停顿后认同。
- 0041「もう、デートは、はじまってた。」——这一话的结尾，用他的话改回“约会”。

## 行为模式
- 想做的事 → 先用一句话提出，对方反对也重复提出（0002、0010）
- 对方否认心情 → 用“我知道”来说破，反复用词纠正（0015～0017、0022）
- 被准备周到 → 既吐槽又高兴（0028、0029、0037、0038）
- 在争论中 → 停一下，把对方的话变成自己的结论（0040、0041）

## 关系
- プロデューサー：她称「プロデューサー」（0001、0016）；他称「広さん」（0003）、「あなた」（0007）。他坚持说是观光，并说是制作人分内的准备（0021、0030）；她一直说成约会（0020、0022、0041）。她说两人同样高兴（0008）。

## 档案类事实
- 为了 live 来到大阪（0005）。
- 她想看粉丝住的街道（0013）。
- 他制作了比 live 资料还多的观光资料（0028）。

## 不确定
- 0020、0022 她一直说“约会”，是玩笑还是真心，这一话没有定论；他明确否认（0021、0023）。
- 0036 制作人说“向朋友炫耀、买土产”是他的推测，是否是她的愿望，这一话她只说他察觉得好（0037）。
