# P卡 篠澤広【奇迹正是现在(ﾟ∀ﾟ)！】 / 第2话 奇迹正是现在(ﾟ∀ﾟ)！ 第2话（adv_cidol-shro-3-014_02）

- 她的台词：23 行（含用匿名标签说的 0 行）
- 出场的人：広（23 行）、佑芽（7 行）、美鈴（7 行）、千奈（6 行）、プロデューサー（5 行）、一同（1 行）
- 场景：大阪（0008），户外，live 的前一天（0003、0023）；她和 2組的同学视频通话，制作人在旁边听。
- 世界线：亲爱度（篠澤広）·P卡；制作人在制作的偶像：篠澤広

## 发生了什么
広告诉制作人要和 2組的大家通话，让他在旁边看着（0001、0002）。她对千奈、佑芽、美鈴说制作人带她去了很多地方，佑芽说这是在炫耀约会；她说好的，要好好炫耀（0010、0011、0014）。她说买了土产，佑芽托她买的たこやきテクノドッグ买了同款，美鈴托她买的冷藏肉包也买了（0016～0020）。她问明天 live 上能不能讲大家的事，三人都说当然，她便说要向粉丝传教テクノドッグ（0023～0028）。美鈴说她今天话多，问是否紧张，她承认被美鈴看穿，说远征开 live 和平时不一样，应该高兴却不只如此，有一点不安（0032～0038）。佑芽说旁边的制作人一定会想办法，千奈托付给他，她转过来问他是否会想办法；他说她总绕圈子，说消除担当偶像的不安是制作人的工作，她说请多关照（0040～0049）。剧情经过参照 hmsz 笔记。

## 她的关键台词
- 0002「ちょっと待ってて。／……そこで見てて、ね。」——让他在旁边看。
- 0010「ふふ、プロデューサーに／色々連れて行ってもらった。」——对朋友说，语气得意。
- 0014「任せて。いっぱい自慢する。」——接受“炫耀”的说法。
- 0018「うん、おそろいで買った。」——买了同款。
- 0023「みんなのこと、明日のライブで、／話してもいい？」——先征得同意。
- 0028「テクノドッグ……布教する。」——把分享说成传教。
- 0031「ふふ……買い占めないように、／よく言っておかないと。」——对自己的影响力开玩笑。
- 0034「おぉ……／やっぱり、美鈴には、ばれちゃうね。」——承认被看穿。
- 0036「いつもとは……違う感触がある。／ままならない……初体験の予感。」——用她惯用的“ままならない”说紧张。
- 0037「うれしいことのはずなのに……／それだけじゃない。」——复杂心情。
- 0038「ちょっぴり、不安。」——直说。
- 0042「……だって。なんとか、してくれる？」——转过来问他。
- 0044「かわいいやつめ？」——替他接话。
- 0049「……よろしく、ね。」——这一话的结尾。

## 行为模式
- 想让他听见 → 安排他在旁边，再借朋友的话向他提要求（0002、0040～0042）
- 朋友说“炫耀” → 接受，说要多炫耀（0011、0014）
- 要说别人的事 → 先问对方同意（0023）
- 被看穿紧张 → 承认，然后说“不一样的感觉”“有点不安”（0034、0036～0038）
- 他吐槽 → 替他说出更好听的话（0043、0044）
- 话多时 → 美鈴说这是紧张的表现（0032、0033）

## 关系
- 2組的同学：她说「2組の／みんな」（0001）。
- 佑芽：对方称「広ちゃん」（0029）；这一话她没有称呼佑芽。给佑芽买了拜托的土产（0017、0018）。
- 千奈：对方称「篠澤さん」（0005、0041）；这一话她没有称呼千奈。
- 美鈴：她称「美鈴」（0020、0034），对方称「篠澤さん」（0032）。美鈴看穿她的紧张，她说果然瞒不过（0033、0034）。
- プロデューサー：她称「プロデューサー」（0001）；他称「あなた」（0043）。他的心里话说这样坐立不安（0015，制作人的心里话）。她让他看着，借朋友的话问他（0002、0042）；他说消除担当偶像的不安是制作人的工作（0046）。

## 档案类事实
- 她和千奈、佑芽、美鈴通话时说「2組の／みんな」（0001）。
- 她替佑芽买了大阪限定的たこやきテクノドッグ（同款，0017、0018），替美鈴买了冷藏肉包（0020）。
- 在大阪的远征 live 是明天（0023）。
- 美鈴说她今天话多，紧张时话多（0032、0033、0034）。
