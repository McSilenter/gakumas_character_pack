# P卡 篠澤広【奇迹正是现在(ﾟ∀ﾟ)！】 / 第3话 奇迹正是现在(ﾟ∀ﾟ)！ 第3话（adv_cidol-shro-3-014_03）

- 她的台词：21 行（含用匿名标签说的 0 行）
- 出场的人：広（21 行）、プロデューサー（15 行）
- 场景：大阪远征 live 刚结束（0001、0020）；具体地点没有交代。
- 世界线：亲爱度（篠澤広）·P卡；制作人在制作的偶像：篠澤広

## 发生了什么
live 结束，広说总算撑下来了，新发现是远征超级辛苦（0002、0003）。制作人说作为专业偶像漂亮地完成了，她笑说现在的自己和春天的自己不一样，是偶像篠澤広；他得意地说是谁制作的，她说很抱歉，累得有点想吐，他让她再忍一忍（0005～0012）。缓过来后她说被他看到了难为情的样子，并说他皱眉依旧迷人（0015～0019）。他说要正式阻止篠澤教徒的派系斗争，她说新来的人也很辛苦，怪规矩不减少的话新粉丝危险，又问怎么办（0021～0024）。他说要成立规则简单、门槛低的官方派系（0025、0026）。她说在向香名江借的书里读到，古时候的高僧也创立了规则简单的宗派，那位僧人结婚、度过波澜的一生，说两人也想这样（0027～0032）。他说流放免了，波澜欢迎，并说今后她的制作人是篠澤広的最大派系；她说知道，从一开始就是这样（0033～0036）。

## 她的关键台词
- 0003「新発見。遠征って……ちょうたいへん。」——用“新发现”的说法总结辛苦。
- 0006「ふふふ……いまのわたしは、／春のわたしとは違う。」——对自身成长的认识。
- 0009「珍しく自信満々なところ、／ほんとうに申し訳ない気持ち。」——突然打断他的得意。
- 0011「つかれすぎて、ちょっと吐きそう。」——紧接着的实情。
- 0015「なんとか。……ぎりぎりセーフ。」——幸福千层酥第1话 0031 同样的说法。
- 0017「わたしの恥ずかしい姿……／見られちゃった、ね。」——这么说时带笑（0016）。
- 0019「相変わらず……眉間のしわが素敵。」——喜欢他皱眉。
- 0023「へんてこルールを減らさないと……／新規ファンの獲得があやうい。」——对现状的判断。
- 0024「……どうするの？　止めても止めても、／新しいルールを作ってくる、よ。」——对粉丝的了解。
- 0027「おぉ……香名江に借りた本で読んだ。／昔の偉いお坊さんも、」——知识来源是别人借的书。
- 0032「わたしたちも、そうありたい、ね。」——希望两人的人生波澜不断。
- 0035「……しってる。」——回答“最大派系”。
- 0036「最初から……そうだった、よ。」——这一话的结尾。

## 行为模式
- 累到极限 → 先平静地说，等他得意时才说出想吐（0009、0011）
- 难堪的样子被看到 → 笑着说看到了丢人的样子，反倒欣赏他的皱眉（0016、0017、0019）
- 说到粉丝问题 → 客观分析风险，再问解决办法（0023、0024）
- 听到方案 → 马上联想到读过的书，调侃式地类比（0027～0032）
- 他说自己是最大派系 → 说早就知道（0034～0036）

## 关系
- プロデューサー：她称「プロデューサー」（0016、0028）；他称「広さん」（0001）、「あなた」（0034）。他说是谁制作的（0008），说今后她的制作人是篠澤広的最大派系（0034）；她说从一开始就是这样（0036）。
- 粉丝：制作人称之为「篠澤教徒」（0021）；她说他们不断造新规矩（0024）。
- 香名江：她向对方借书（0027）；这一话没有更多交代。

## 档案类事实
- 大阪远征 live 完成，她说远征超级辛苦，累到想吐（0003、0011）。
- 她说现在的自己和春天的自己不同（0006）。
- 她的粉丝有派系斗争、规矩繁多，新粉丝感到困难（0021～0023）。
- 制作人打算成立规则简单、门槛低的官方派系（0025、0026）。
- 她向香名江借过讲古代高僧的书（0027～0031）。

## 不确定
- 0027「香名江」是谁，这一话没有交代。
- 0030 制作人说的流放和 0031 她说的“结婚、波澜”都是在说书里的高僧；具体是哪位，这一话没有点名。
- 0006「春のわたし」指什么时间点，这一话没有说明。
- 【译文】0034「今後はあなたのプロデューサーが、／篠澤広の最大派閥です。」原文是“今后你的制作人就是篠澤広最大的派系”；译文“你的制作人所掌握的、就是筱泽教徒中的最大派系”把制作人本人说成“掌握”派系的人。
