# P卡 篠澤広【未知万千 广阔无限】 / 第2话 未知万千 广阔无限 第2话（adv_cidol-shro-3-016_02）

- 她的台词：11 行（含用匿名标签说的 0 行）
- 出场的人：千奈（11 行）、広（11 行）、星南（9 行）；制作人没有出场
- 场景：生徒会室（0014）。
- 世界线：亲爱度（篠澤広）·P卡；制作人在制作的偶像：篠澤広（剧本里没有直接说法）

## 发生了什么
星南告诉千奈，受千奈爷爷委托，要举办决定千奈二人组合搭档的试镜（0002～0010）。広出现，说请放心，报名当千奈的搭档，千奈惊讶她怎么在生徒会室（0013～0016）。她说要当搭档就必须突破超难关的试镜，这是合自己口味的考验，胜算小正好（0018～0020）。她对千奈说，不想因为自己的趣味给任何人添麻烦，但两人是宿命的对手、实力相当；千奈已是出色的偶像，那现在的自己也一样（0023～0027）。千奈回应说自己很清楚，对手篠澤広是非常出色的偶像（0029～0031）。剧情经过参照 jsna、kcna 笔记。

## 她的关键台词
- 0013「ふっふっふっふ……安心して、千奈。」——她的登场。
- 0015「篠澤広。千奈のデュオパートナーに／立候補する、よ。」——自报姓名式的宣言。
- 0019「超難関オーディションを／突破しないといけない。」——接 0018。
- 0020「わたし好みの試練。／勝算が薄そうで、いい、ね。」——胜算小才好。
- 0023「わたしの趣味で、／誰かに迷惑をかけたくない。」——这一话的立场。
- 0024「だけど……／あなたとわたしは宿命のライバル。」——转折。
- 0025「あなたとわたしは、同等の実力者。」——她这样宣称两人的关系。
- 0026「千奈は、もう、立派なアイドル。」——对千奈的肯定。
- 0027「それなら……／いまのわたしも、同じ、だね。」——借此肯定自己。

## 行为模式
- 有想做的事 → 突然出现、郑重宣言（0013、0015）
- 面对难关 → 说胜算小正好（0020）
- 想说服自己可以 → 从对方的强得出自己也够格（0026、0027）
- 先说不想给人添麻烦，再说明为什么这次可以（0023～0027）

## 关系
- 千奈：她称「千奈」（0013、0022），并用「あなた」（0024）；对方称「篠澤さん」（0014、0021）。她说两人是宿命的对手、实力相当（0024、0025）；千奈称她为对手、非常出色的偶像（0031）。
- 星南：对方称「広」（0017）；这一话她没有称呼星南。她说自己听到了星南的话（0017、0018）。

## 档案类事实
- 她在这条线上把千奈称为宿命的对手（0024）。
- 她说不想因自己的趣味给任何人添麻烦（0023）。

## 不确定
