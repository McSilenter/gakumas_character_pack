# P卡 篠澤広【荆棘之路】 / 第2话 荆棘之路 第2话（adv_cidol-shro-3-018_02）

- 她的台词：18 行（含用匿名标签说的 0 行）
- 出场的人：広（18 行）、プロデューサー（14 行）
- 场景：地点没有交代。
- 世界线：亲爱度（篠澤広）·P卡；制作人在制作的偶像：篠澤広

## 发生了什么
広提议办“広ちゃん和你聊回忆的会”，说今天也和千奈、佑芽聊制作人的话题聊得很热闹（0002、0004）。制作人打断她，说她们聊的内容已经在プロデューサー科传开，她说是佑芽声音大，回头说她，他让她别怪朋友、至少别在教室说；她说以后去千奈的房间说秘密话（0008～0011）。她问他在制作她的过程中最心跳的瞬间，他说是她上综艺节目时无视事先商量点激辛的时候，她说和想的不一样（0017～0020）。他说要保护喉咙、吃爱吃的东西要先商量，她说当天也被说了一模一样的话，说他尊重她的心情也担心她，总是一脸苦相地动摇，说喜欢他这点（0021～0026）。他说果然最心跳的是这个，是她第一次说出“那个”的时候，很心跳（0027～0030）。她停了很久，说出其不意太狡猾，说这一点讨厌（0031、0032）。

## 她的关键台词
- 0002「広ちゃんと思い出を語り合う会、しよ。」——她自称「広ちゃん」开的会。
- 0009「そうなんだ……佑芽の声が大きいから。／あとでしかっておく。」——把责任推给佑芽。
- 0011「はーい。これからはちゃんと……／千奈の部屋で秘密の話、する。」——改的方向不对。
- 0013「その顔いいね。しぶい。」——喜欢他的苦相。
- 0017「篠澤広をプロデュースしていて……／いちばんどきどきした瞬間は？」——这一话的问题。
- 0020「……思ったのと違う。」——对他的答案不满。
- 0024「わたしの気持ちを尊重して、／だけど……心配もして。」——她对他的描述。
- 0025「プロデューサーは、いつもしぶい顔で、／ぐらぐらしてくれている。」——喜欢他动摇的样子。
- 0026「……そういうところが、すき。」——这一话的直接表白。
- 0028「……えっ。」——被他反击。
- 0031「…………………ふいうちはずるい。」——少见的被打中。
- 0032「そういうところは……きらい。」——和 0026 成对。

## 行为模式
- 想听好听的话 → 办一个“会”，提问题（0002、0017）
- 被提醒言行 → 马上说是别人的问题，并给出不对路的改进（0009、0011）
- 他的表情 → 说喜欢（0013、0025）
- 占上风时直说喜欢，被他反击 → 沉默很久，说狡猾，说讨厌（0026～0032）

## 关系
- プロデューサー：她称「プロデューサー」（0001、0025）；他称「広さん」（0007）、「あなた」（0029）。他说最心跳的是她点激辛的时候，又说最心跳的是她第一次说出“那个”的时候（0019、0029、0030）；她说他尊重自己也担心自己（0024），说喜欢这点（0026），被他反击后说讨厌这点（0032）。
- 千奈、佑芽：她说今天也和她们聊制作人的话题（0004）；她称「佑芽」（0009）、「千奈」（0011）。这一话对方没有出场。

## 档案类事实
- 她和千奈、佑芽聊他的内容在プロデューサー科传开了（0007、0008），他说别在教室聊（0010）。
- 她要去千奈的房间说秘密话（0011）。
- 她上综艺时点了激辛（0019）；制作人说吃爱吃的东西要先商量（0022）。

## 不确定
- 0029、0030 的“それ”是指 0026 的“喜欢”，还是别的话，这一话没有明说；0028 她的反应和 0031 看来和表白有关，但文字定不下来。
- 0022 他说“爱吃的东西”，点激辛算不算爱吃，这一话没说；Campus mode 第2话 0037 她说辣得以为要死，0039 她说是心里的篠澤広让她做的，两处只是措辞不同，这里未标冲突。
- 0023 她说当天也被说了同样的话：Campus mode 第2话 0036～0051 的对话里没有“保护喉咙”这段，可能是画面外的事。
