# P卡 篠澤広【眼】 / 第2话 眼 第2话（adv_cidol-shro-3-022_02）

- 她的台词：23 行（含用匿名标签说的 0 行）
- 出场的人：広（23 行）、owl（16 行，含标注为聞き覚えのある声的 2 行）、プロデューサー（3 行）、ふたり（1 行）
- 场景：地点没有交代；接第1话的会议，听新曲试听音源（0002、0003）。
- 世界线：亲爱度（篠澤広）·P卡；制作人在制作的偶像：篠澤広

## 发生了什么
広说多亏他干劲满满，要接着开会，他让她闭眼听新曲试听，说是难曲（0001～0004）。她听后说确实难，感觉像在拷问唱歌的自己的心（0007）。一个熟悉的声音插话，她吓了一跳，来的是 owl 先輩，owl 说恶作剧成功，并感谢制作人协助（0008～0012）。owl 说自己的团队参与新曲的 MV 制作，她说非常非常高兴，谢谢 owl 先輩和制作人（0016～0021）。owl 说和可爱的共犯一起工作很高兴，她道谢曾一起挨骂，owl 提议继续共犯关系（0023～0026）。她问接下来恶作剧谁，owl 说是粉丝，手段是让新曲变得非常出色（0027～0029）。owl 说她的烦恼对自己很熟悉，问她是否对受之有愧的高评价不知如何是好，她说是偶像，不能亲手否定粉丝给的高评价（0034、0035）。owl 说自己也一样，又问她是否害怕再次被在初星学园遇到的重要朋友抛下，她说是，很害怕（0039、0040）。owl 说这就是前辈，邀她谈谈，她说请多指教（0043～0045）。

## 行为模式
- 被吓到 → 语塞，拖长语气（0011）
- 惊喜时 → 反复说“非常非常”并道谢（0019～0021）
- 对前辈 → 使用敬语（0024、0045）
- 对恶作剧提议 → 马上问下一个对象（0027）
- 被说中内心 → 平静承认害怕（0039、0040）

## 关系
- owl 先輩：她称「owl先輩」（0011、0021）、「先輩」（0045）；对方称「広さん」（0010）、「篠澤広さん」（0025）。owl 称她可爱的共犯（0023）；她曾和 owl 一起挨骂（0024）。她愿意和 owl 谈（0044、0045）。
- プロデューサー：她称「プロデューサー」（0001、0021）；这一话他没有叫她的名字。他配合 owl 的恶作剧（0012）。
- 在初星学園遇到的朋友：owl 说她害怕再次被抛下（0039）。

## 档案类事实
- owl 的团队参与新曲的 MV 制作（0016）。
- 她害怕再次被在初星学园遇到的重要朋友抛下（0039、0040）。
- 粉丝给的高评价她不能亲手否定（0035）；她有受之有愧的高评价（0034，owl 的说法）。

## 不确定
