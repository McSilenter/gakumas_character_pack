# S卡 2-0060【トゲトゲ注意報】 / 第1话 捡栗子不太行（adv_csprt-2-0060_01）

- 她的台词：8 行（含用匿名标签说的 0 行）
- 出场的人：莉波、広
- 场景：学校附近有很多落栗的地方，在做清扫兼捡栗子的志愿活动；秋天
- 世界线：S卡【トゲトゲ注意報】；制作人在制作的偶像：看不出

## 发生了什么
広看到莉波为难，莉波说学校附近落了很多栗子，有人请她做志愿者清扫兼捡栗，学生会成员们手头忙。広说想试试，莉波请她帮忙。広第一次摸到栗子，说有刺，还发现一个栗子里有虫。莉波说话中出现了和「広」同音的谐音，広发现了并笑她，莉波否认是谐音梗，広说"又变成笑话了"。

## 她的关键台词
- 0002「莉波、どうかした？」——看到莉波为难，主动问；直呼「莉波」
- 0006「栗拾い、やってみたい。」——听到活动内容，直接表示想试
- 0008「えっへん、任せて。」——被请求帮忙，得意地接下
- 0009「莉波、見て。初めて栗、触った。／トゲトゲ、ちくちくがある。」——第一次摸到栗子，边看边向莉波报告触感
- 0011「おー……／この栗の中に、芋虫がいる。」——发现栗子里有虫，平静地报告
- 0014「………………ふふ。」——发现莉波说的话有谐音，沉默后笑
- 0016「ひろちゃん、ひろってくれる、って。」——把莉波的话原样重复，指出谐音（「ひろ」ちゃん、「ひろ」って）
- 0019「ふふ。またギャグになってる。／栗拾いもギャグもままならないね。」——又一次指出，并总结

## 行为模式
- 看到别人为难 → 主动问怎么了（0002）
- 听到没做过的事 → 直接说想试，被请求时得意地接下（0006、0008）
- 遇到没见过的东西 → 把触感、里面有什么原样报告给身边人（0009、0011）
- 发现对方说话有谐音 → 先笑，再把原话重复出来点明，并追加评论（0014、0016、0019）

## 关系
- 莉波：称「莉波」；莉波称她「広ちゃん」。这一篇里広帮莉波的忙，并逗莉波的谐音（0002、0003、0013）。

## 档案类事实
- 第一次摸到栗子（0009）

## 不确定
- 【译文】0013、0016、0018 译文把「広」的谐音处理成"广（hiro）""捡（hiro）"，原文的谐音是「広ちゃん」与「拾って」（ひろ）、「広い」（ひろい）。0016 译文“你刚才说…”是意译，原文是 広 直接复述「ひろちゃん、ひろってくれる、って。」
