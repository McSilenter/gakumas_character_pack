# S卡 3-0027【夏を楽しみましょう！】 / 第3话 第一次的暑假（adv_csprt-3-0027_03）

- 她的台词：8 行（标签『広』，无匿名行）
- 出场的人：広（8）、千奈（7）、佑芽（6）
- 场景：假期（特训）的最后；広说“今天”很开心（0001）。具体地点剧本没写。
- 世界线：S卡【夏を楽しみましょう！】；制作人在制作的偶像：看不出

## 发生了什么
広向千奈道谢，感谢她邀请自己参加这么棒的“特训”，千奈纠正说是度假，広说也可以这么说。千奈说该道谢的是自己，因为和朋友一起过暑假是第一次，広说自己也是，和朋友一起待这么多天也是第一次，觉得开心。佑芽说她也是，但和以前的集训、姐姐的特训不同。千奈说还想再一起，佑芽提议下次来她老家，広说那里恐怕能做地狱般的特训。剧情经过参照 hume 笔记。

## 她的关键台词
- 0001「今日は……とっても楽しかった。」——一开始就直接说今天很开心。
- 0003「ありがとう、千奈。」——称「千奈」，直接道谢。
- 0004「わたしを素敵な特訓に誘ってくれて。」——道谢的理由是被邀请参加“特训”，用的是「特訓」这个词。
- 0006「そうともいう。」——被千奈纠正“是度假不是特训”，不反驳，淡淡地认可。
- 0011「わたしも。」——千奈说“第一次”后，简短地说自己也是。
- 0012「友達とこんなに……何日も／一緒にいるの、はじめて。」——说明自己的“第一次”是和朋友一起待这么多天。
- 0013「うれしい。」——坦率地说出感受。
- 0020「ふふ……佑芽の実家……／地獄のような特訓ができそう。」——听到佑芽邀请去老家，笑着开玩笑，说那里会有地狱般的特训。

## 行为模式
- 想感谢朋友 → 用直接而简短的话说，不绕弯（0001、0003、0004、0013）。
- 被纠正用词 → 不争论，用一句话认可（0006）。
- 别人说出“第一次” → 马上说“我也是”，然后补充自己的情况（0011、0012）。
- 对下一次的邀请 → 用玩笑回应，把特训的话题带回来（0020）。

## 关系
- 千奈：称「千奈」（0003）；千奈称她「篠澤さん」（千奈 0007）。
- 佑芽：称「佑芽」（0020）；佑芽邀请她们去老家。

## 档案类事实
- 和朋友一起待这么多天，对她是第一次（0012）。
- 她把这次活动看作特训，并觉得素敵（0004）。
- 她说话简短，句子里常用「……」停顿（0001、0012）。
