# S卡 3-0050【あなたたちのことが好き】 / 第3话 一直是朋友（adv_csprt-3-0050_03）

- 她的台词：10 行（含用匿名标签说的 0 行）
- 出场的人：広（10）、佑芽（6）、千奈（4）
- 场景：看不出具体地点（承接前话，三人在一起）
- 世界线：S卡【あなたたちのことが好き】；制作人在制作的偶像：看不出

## 发生了什么
佑芽说広最近不再问“我们是朋友吗？”，广说因为问了很多次，反问佑芽是否记仇。佑芽说是想确认友情有没有传达，千奈也说自己说过很多次。広说因为是第一个朋友，她不确定朋友是什么，现在明白其实很简单：在一起开心、喜欢的对象就是朋友。她说即使将来成功后忙得见不到、长大后不再一起玩，也会一直喜欢她们。剧情经过参照 hume 笔记。

## 她的关键台词
- 0003「うん。何度も聞いたから……／……佑芽、根に持ってる？」——承认自己问过很多次，半开玩笑地问佑芽是否记仇
- 0009「……ふたりとも、／すぐ恥ずかしいことを言う。」——被热烈表达感情时，指出对方“害羞的话”
- 0010「はじめての友達だったから、友達って／なんなのか、確信が持てなかった。」——说出过去不确定的原因
- 0012「とても、シンプルな話。／わたしが勝手に、難しく考えてた。」——回头承认自己想得太复杂
- 0013「いま、一緒にいると楽しくて……／好きな相手が、友達。」——给出自己对“朋友”的定义
- 0014「ちゃんと友達をやれているのか……／なんて、どうでもよかった、ね。」——以前在意做得是否合格，现在觉得无所谓
- 0015「もしもこの先、わたしたちが／アイドルとして成功して。」——设想将来的成功
- 0016「いまよりずっと忙しくなって、／なかなか会えなくなったとしても。」——设想见面变少
- 0017「大人になって、一緒に遊ぶことが／なくなったとしても。」——设想长大后
- 0018「わたしは、ずっと、／あなたたちのことが好き。」——全篇结论，直接表白喜欢

## 行为模式
- 被追问以前的口头禅（问朋友吗） → 承认，并以玩笑反问对方是否在意（0003）
- 被直白示爱 → 指出对方“说得害羞”，然后自己更直接地讲心里话（0009、0013～0018、0020 佑芽的反应）
- 想法转变 → 先讲过去为何不确定，再说“其实很简单”，最后给出定义（0010、0012、0013）
- 设想将来变化 → 逐层列“成功→忙→长大”，最终都落到“一直喜欢”（0015～0018）

## 关系
- 佑芽：称「佑芽」（0003）；佑芽确认“热情友情”是否传到広
- 千奈：同时被说“大切なお友達”（0008），広以「ふたりとも」「あなたたち」统称两人
- 0020 佑芽评价“今天広才是说害羞话的人”

## 档案类事实
- 広说千奈、佑芽是自己“第一个朋友”（0010）
- 以前广多次问“わたしたち、友達？”（0002、0003）

## 不确定
- 0010「はじめての友達」没有说是千奈、佑芽哪一位或两位；本篇语境指向两人，但未明说。
