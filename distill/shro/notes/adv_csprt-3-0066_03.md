# S卡 3-0066【放っておけない気になる子】 / 第3话 与人气相符的实力（adv_csprt-3-0066_03）

- 她的台词：8 行（含用匿名标签说的 0 行）
- 出场的人：星南（12）、広（8）
- 场景：地点没写明；星南看过広的现场表演后找她谈
- 世界线：S卡【放っておけない気になる子】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
星南说看了広的演出，自己的评价定不下来。広问是不是不值得论，星南说不是，说表演勉强只能算成立，但歌打动了她，让她觉得是有魅力的偶像。広说千奈说过，星南会这样让人害羞地夸。星南说在考虑让生徒会支持她，広问是不是招募，像千奈和佑芽。星南说不是，広的人气在上升而实力没跟上，不是好状况，并说她似乎满足现状，要她具备与人气相称的实力。広说要认真想办法，请星南再商量。

## 她的关键台词
- 0002「おー……それは光栄。」——被说看了演出，轻轻地回应
- 0003「どうだった？」——直接问感想
- 0005「論ずるに値しない、ってこと？」——听到“评价定不下来”，推测是不值得论
- 0010「……千奈が言ってたとおり。星南は、／そうやって恥ずかしい褒め方をする。」——被夸之后，说千奈早说过星南会这样夸
- 0012「……スカウト、ってこと？　／千奈や佑芽みたいな。」——推测是招募，举千奈和佑芽为例
- 0015「辛うじてアイドルをしているって、／いい表現だね。ぜひ使わせてもらう。」——被说“勉强算偶像”，觉得是好说法，打算使用
- 0019「……千奈がよく言ってる。アイドルに／なったからには、責任がある……って。」——引用千奈常说的话
- 0020「うん……本気で、なんとかしないと。／あらためて……相談させてほしい。」——认真表态，请求之后再商量

## 行为模式
- 被评价不明确 → 往“不值得论”方向猜，但并不沮丧（0005）
- 被指出的缺点被说成“勉强” → 觉得是好表达，想用（0015）
- 被劝要有与人气相称的实力 → 引用千奈的话，转为认真，请求商量（0019、0020）
- 被夸时 → 指出对方“恥ずかしい褒め方”（0010）

## 关系
- 星南：称「星南」（0010）；星南称她「広」。她把星南的夸奖与千奈说的话对上（0010）
- 千奈：称「千奈」（0010、0012、0019）；千奈对她说过星南的夸法和偶像的责任
- 佑芽：称「佑芽」（0012）

## 档案类事实
- 听千奈说过星南“会让人害羞地夸”，也听千奈说过偶像“责任”的话（0010、0019）
- 她现在的人气在上升（星南 0014）

## 不确定
- 0017 星南说她“満足している節がある”，広没有正面回应；0020 说“本気で、なんとかしないと”。她对现状是否满足，剧本没有明说。
- 0012 “スカウト”：星南 0013 否定；星南是否对千奈和佑芽做过招募，由広的问话读出，非星南明说。
- 0015 是认真表示要使用，还是玩笑，剧本没写。
- 与第 1 话（体力差、最大理由是秘密）没有对不上的地方。无【冲突】。
