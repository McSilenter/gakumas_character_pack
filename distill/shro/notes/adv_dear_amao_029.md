# 有村麻央 亲爱度剧情 / 第29话（adv_dear_amao_029）

- 她的台词：9 行（匿名标签 0 行）
- 出场的人：麻央（45 行）、広（9）、千奈（8）、清夏（7）、リーリヤ（7）、一同（2）、プロデューサー（2）
- 场景：麻央为了制作人给的“課題”（0072），请千奈和広一起练习（0001～0041）；之后清夏和リーリヤ那一段她不在场。地点剧本没写明
- 世界线：亲爱度（有村麻央）；制作人在制作的偶像：有村麻央

## 发生了什么
她和千奈来和麻央练习，她直接叫麻央的名字打招呼（0002）。麻央说也要向她们学习，她反问3年生的麻央有什么能向她们学（0009）。她补充说千奈的网络节目是千奈接连给出“珍回答”的问答节目（0014），麻央夸千奈的魅力，她说“麻央、わかってる、ね”（0018）。麻央说她有神秘感，粉丝越来越多，千奈说她被粉丝叫“女神様”；她说自己最近能自在控制偶像的力量，并当场运气给麻央看（0019～0026）。练习后她喘着说麻央严厉、喜欢；麻央说她体力变好、不再倒下，她说多亏和佑芽一起特训（0034～0038）。

## 她的关键台词
- 0002「よろしく、麻央。」——对3年生前辈直呼名字
- 0009「3年生の麻央が、わたしたちに／学ぶこと、あるかな？」——直率地反问
- 0014「千奈が奇跡の珍回答を連発した、／アイドルのクイズ番組。」——替千奈补充，说法带点调侃
- 0018「麻央、わかってる、ね。」——赞同麻央对千奈的评价
- 0022「ふふ、じつは最近、／アイドルの力を自在にコントロール／できるようになった。」——认真地说出“偶像之力”
- 0024「……見てて。／はあああああああああああああ……」——当场运气展示
- 0026「どう？」——展示完求评价
- 0034「はぁ、はぁ……／麻央、厳しい。好き。」——被练得很累，却说喜欢严厉
- 0038「ふぅ、ふぅ……佑芽と一緒に、／特訓してるおかげ、かな……」——把体力进步归于和佑芽的特训

## 行为模式
- 对前辈 → 不用敬语，直接叫名字（0002、0009、0018、0034）
- 话短，常在句中用逗号停顿（「麻央、わかってる、ね」「麻央、厳しい。好き。」）（0018、0034）
- 说到自己的“力量” → 当真地展示，再问对方观感（0022～0026）
- 被严格训练 → 喘着气也表示喜欢（0034）
- 被夸进步 → 说是和佑芽一起特训的结果（0038）

## 关系
- 麻央：叫「麻央」（0002、0009、0018、0034）；麻央叫她「広」（0019、0037）。她称赞麻央懂千奈的魅力、说喜欢麻央的严厉（0018、0034）；麻央说她有神秘的魅力、体力变好不再倒下（0019、0020、0037）。
- 千奈：叫「千奈」（0014）；千奈称她「篠澤さん」，说粉丝叫她“女神様”（0021）。
- 佑芽：提到和佑芽一起特训（0038）。

## 档案类事实
- 千奈说她被粉丝称为“女神様”（0021，千奈的话）；麻央说她有神秘感、粉丝越来越多（0019、0020，麻央的话）。
- 她说自己最近能自在控制“アイドルの力”（0022）。
- 和佑芽一起特训（0038）；麻央说她体力变好、不再倒下了（0037，麻央的话）。
- 麻央说她们比入学时进步很多（0036，麻央的话）。
