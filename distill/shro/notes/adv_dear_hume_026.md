# 亲爱度剧情（花海佑芽） / 第26话（adv_dear_hume_026）

- 她的台词：18 行（含用匿名标签说的 0 行）
- 出场的人：佑芽（48 行）、広（18）、千奈（15）、花海社長（13）、プロデューサー（2）、一同（2）
- 场景：花海トレーニングセンター合宿中，训练刚结束的休息时间
- 世界线：亲爱度（花海佑芽）；制作人在制作的偶像：佑芽（0017、0018 制作人的话针对佑芽的特训，0045 她提到“佑芽のプロデューサー”）

## 发生了什么
広和千奈训练后气喘吁吁。広说自己刚才在机器旁险些出事，被千奈和训练员骂。佑芽提出互相“見取り稽古”，広分析比赛里谁最有利：千奈第一，佑芽的父亲也有力，自己和佑芽“敗色濃厚”。佑芽回顾三人曾是補習組，現在重新並排，広赞成互相批评研鑽。后半佑芽与父亲交谈，広不在场。剧情经过参照 hume 笔记。

## 她的关键台词
- 0003「…………………………千奈、いきてる？」——体力透支之后第一句话是确认同伴是否还活着
- 0012「気を付けて、ね。油断するとマシンに／殺されちゃう、かも。」——提醒佑芽小心训练机器，用夸张的说法
- 0013「さっき、わたしもあぶなかった。／千奈とトレーナーに叱られた。」——坦白自己刚才也险些出事被训斥
- 0015「うん……だけど、溢れるやる気は／止められない。千奈も同じはず。」——知道危险但仍止不住干劲，并替千奈也说同样
- 0026「とっても頭悪いプランで好き。」——听佑芽的“体能硬扛”计划，用“很笨所以喜欢”表示喜欢
- 0042「コンペ参加者の中で、タレントとして／実力が一番上なのは倉本千奈。」——冷静分析比赛形势，指出千奈最强
- 0046「わたしと佑芽は……ふふ、敗色濃厚。」——说自己和佑芽胜算低，却带着笑
- 0056「わたしも。」——佑芽说“终于成为了偶像”之后接上，表示自己也一样
- 0064「批評し合おう、って、こと？」——准确理解佑芽的提议
- 0068「ふふ……ほんとうに、いまさら。／わたしたち……」——对“到现在才”能互相批评研鑽这件事感叹

## 行为模式
- 同伴提出新计划 → 用评价式的短句表态（“很笨所以喜欢”），而不是单纯同意（0026）
- 需要判断形势 → 以条件和规则为依据，逐项分析谁有利（0042～0046）
- 说出自己或同伴不利的结论 → 带着笑，不显得沮丧（0046、0068）
- 遇到危险或失误 → 如实说出并承认被训斥（0013）
