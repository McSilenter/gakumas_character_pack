# 亲爱度剧情（花海佑芽） / 第32话（adv_dear_hume_032）

- 她的台词：17 行（含用匿名标签说的 0 行）
- 出场的人：星南（18 行）、佑芽（22）、広（17）、千奈（14）、一同（3）
- 场景：『選抜試験』的演出结束后，三人下场相聚；星南出现并评价；佑芽赢了
- 世界线：亲爱度（花海佑芽）；制作人在制作的偶像：佑芽（0052 星南说“仮に私が、あなたのプロデューサーだったなら”）

## 发生了什么
比赛后広说自己已把当下的自己全部拿出来，达成感极大。她和千奈向佑芽道贺，同时说这不是结束；她挑动千奈，千奈宣布本战要赢，她自己也说要“奇跡をつかみにいく”。她称赞佑芽今天“一番アイドルしてた”，被佑芽抱得喘不过气。星南出现称赞三人，广接着说“褒められちゃった”。剧情经过参照 hume 笔记。

- 0019「いいの？　そんなこと言っちゃって。」——挑动千奈：被说差距之后真的要说“本战会赢”吗

## 行为模式
- 完成全力表现后 → 说“全部拿出来了”，并用达成感直接形容（0006、0007）
- 输给对方 → 平静承认差距，却不放弃，转为“即使是零也去抓奇迹”（0017、0024、0025）
- 同伴回答太快 → 反问或挑动一下，观察对方态度（0019）
- 被拥抱得太用力 → 发出简单的声音（0036）
- 评价别人时 → 用具体、客观的话（“今天最像偶像”，“曲子很好”）（0031、0032）
