# 倉本千奈 亲爱度剧情 / 第17话（adv_dear_kcna_017）

- 她的台词：23 行（含用匿名标签说的 0 行）
- 出场的人：千奈（29 行）、広（23）、一同（1）
- 场景：她来找千奈玩，千奈正在画画（0001～0003）；地点剧本没写明。两人约定在『FINALE』对决（0053）
- 世界线：亲爱度（倉本千奈）；制作人在制作的偶像：倉本千奈

## 发生了什么
她来找千奈玩，千奈给她看自己的画，她把小狗猜成外星人、把吉娃娃说成斗牛犬，但说这是开心的画（0001～0014）。千奈说这幅画一直没画完，能画完是因为她每天示范了兴趣该怎么享受、不擅长也可以挑战，她说被意外地感谢有点困惑（0015～0021）。千奈说以前什么都做不到最后，她说“可惜”（0022～0026）。她问千奈喜不喜欢偶像、偶像是不是兴趣，千奈说是梦想；她说对自己来说偶像是兴趣，问千奈怎么看，千奈说是很棒的兴趣（0031～0037）。她说千奈总是这样说，是温柔可爱的好朋友，最喜欢千奈（0038～0040）。她说看了千奈的 live，下次和她比，约定她赢了千奈要画她，最后改成画两个人（0043～0051）。

## 她的关键台词
- 0001「千奈、遊びにきた、よ。」——典型的逗号断句说法
- 0006「いいね、エイリアンかな？」——先夸，再直接说出自己看到的
- 0008「千奈には……／世界が……こう見えている？」——认真地把画当作千奈眼中的世界
- 0010「ふふ……楽しそうな、絵。」——不评价画得好坏，看的是开心
- 0021「……思いがけない感謝をされて／困惑してる。」——直接说出自己的情绪状态
- 0026「もったいない。」——对“没做完就放弃”只说一个词
- 0036「わたしにとって、アイドルは趣味。／どう思う？」——说出自己对偶像的定位，并征求千奈的看法
- 0038「千奈はいつも、そう言ってくれる。」——千奈一向肯定她的“兴趣”说法
- 0040「大好き。」——直说喜欢
- 0044「次は、わたしと勝負しよう。」——看了千奈的 live 后提出对决
- 0047「わたしが勝ったら、／わたしの絵を描いてくれる？」——把赌注定为千奈的画
- 0049「やっぱり、ふたりの絵がいいかも。」——改成两个人一起的画

## 行为模式
- 看别人的作品 → 不客套，照自己看到的直接说（外星人、斗牛犬），但也会说出作品里的“开心”（0006、0010、0013）
- 被意外感谢 → 先说自己什么都没做，再说“困惑”（0017、0021）
- 想确认对方的想法 → 用短问句一问一答（「アイドルは、好き？」「アイドルは、趣味？」）（0031、0033）
- 被对方接受自己的看法 → 直接说对方的好、说「大好き」（0038～0040）
- 定对决赌注 → 选和朋友有关的东西，最后改成两个人一起（0047、0049）

## 关系
- 千奈：叫「千奈」（0001、0030、0038、0043）；千奈叫她「篠澤さん」（0002、0016、0041）。她说千奈是温柔、可爱、很棒的朋友，最喜欢（0039、0040）；千奈也说最喜欢她，说她是第一个既是好朋友又是对等对手的人（0041、0045）。千奈说画画能坚持下来、能堂堂正正说画画是兴趣，是因为遇到了她（0016～0020、0028、0029）。

## 档案类事实
- 她说对她来说偶像是兴趣（0036）。
- 她看了千奈的 live（0043）。
- 和千奈约定在『FINALE』对决（0044、0053）。
