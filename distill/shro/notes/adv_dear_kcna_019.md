# 倉本千奈 亲爱度剧情 / 第19话（adv_dear_kcna_019）

- 她的台词：19 行（含用匿名标签说的 0 行）
- 出场的人：広（19 行）、千奈（18）
- 场景：她输给千奈之后（0001～0003）；地点剧本没写明。两人谈下一次比试，千奈提到冬天的『H.I.F』（0017）
- 世界线：亲爱度（倉本千奈）；制作人在制作的偶像：倉本千奈

## 发生了什么
她笑着说输了，千奈宣布胜利，学着欢呼了一声（0001～0004）。她说被反击了，说要是早点成为对手就好了，千奈说两人是1年生，比试的日子还长（0005～0011）。她说拼到极限还是敌不过千奈，又不甘心又幸福，下次不会输（0012～0015）。千奈说下次比试可能是冬天的『H.I.F』，她说既然要比就比冠军（0017～0019）。她说两人在『N.I.A』的活跃大半靠别人的力量，在比偶像自身实力的『H.I.F』赢不了，所以要挑战，目标是『一番星』篠澤広，并邀千奈一起（0021～0029）。千奈说会成为学园第一的偶像、成为她的对手，又小声说不行的话请原谅，她说千奈真可爱（0031～0037）。

## 她的关键台词
- 0001「ふふ、負けちゃった。」——输了先笑
- 0005「やり返された。」——平淡承认被反击（第12话 0068 是她赢后欢呼）
- 0007「もっと早くなっておけばよかったね、／ライバル。」——遗憾没有早点成为对手
- 0013「限界ぎりぎりまでがんばって……／だけど千奈には敵わなくて。」——承认全力输了
- 0014「ちっともままならなくて、／とってもくやしくて、幸せな気持ち。」——把不甘心和幸福放在一起
- 0015「次は負けない。」——简短的宣言
- 0019「どうせなら、優勝を競い合いたい。」——把下一次目标定为冠军
- 0022「アイドル自身の力がものをいう／『H.I.F』では、勝てっこないね。」——清楚判断自己赢不了
- 0024「だから挑戦する。」——正因为赢不了才要挑战
- 0025「『一番星』篠澤広を、目指す。」——说出目标
- 0028「みんなが呆れるような、無謀な挑戦……／きっと、すごく面白い、よ。」——觉得无谋的挑战有趣
- 0029「なって、ね。……わたしのライバル。」——邀请千奈继续当她的对手
- 0037「…………千奈は、ほんとに可愛いね。」——对千奈的退缩话语的反应

## 行为模式
- 输了 → 先笑、承认，说不甘心和幸福是同时的，然后简短说下次不会输（0001、0012～0015）
- 判断自己“赢不了” → 不放弃，反而因此决定去挑战，并说这样的无谋挑战很有趣（0022、0024、0028）
- 自己定了大目标 → 拉朋友一起，用「なって、ね」这种短句请求（0027、0029）
- 对方豪言后又打退堂鼓 → 不催，只说对方可爱（0036、0037）

## 关系
- 千奈：叫「千奈」（0013、0027、0037），称她「わたしのライバル」（0029），也直接叫「ライバル」（0007）；千奈叫她「篠澤さん」（0002、0026），宣言时称「篠澤広」（0034）。这次她输给了千奈，邀请千奈一起以『一番星』为目标（0027）。

## 档案类事实
- 她这次比试输给了千奈（0001～0003、0013）。
- 千奈说两人都是1年生（0009，千奈的话）。
- 她说两人在『N.I.A』的活跃大半靠自己以外的力量（0021）。
- 她以『一番星』为目标（0025）。

## 不确定
- 这次输的是哪一场（是否就是第17话约定的『FINALE』），本篇没写明。
- 0004 千奈的「いぇ～～～～～～～いっ♪」像是回敬她在第12话 0068 赢后的欢呼，本篇没说明。
- 【译文】0007「もっと早くなっておけばよかったね、／ライバル」意思是“要是早点成为对手就好了”（千奈接着说「遅くなんてありませんわ」），译文作“要是能再早点变强就好了”，意思错了。
