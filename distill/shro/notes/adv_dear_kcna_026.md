# 倉本千奈 亲爱度剧情 / 第26话（adv_dear_kcna_026）

- 她的台词：27 行（含用匿名标签说的 0 行）
- 出场的人：千奈（37 行）、広（27）、美鈴（15）、佑芽（10）、プロデューサー（9）、旁白（1）
- 场景：生徒会的上级生决定支持别的候选人之后（0001），千奈阵营商量选举应援 live 的安排（0003～0080）；后半是「――応援ライブ・最終日。」（0081）千奈和制作人的对话，她不在场。地点剧本没写明
- 世界线：亲爱度（倉本千奈）；制作人在制作的偶像：倉本千奈

## 发生了什么
千奈为前辈们成了敌人而慌乱，她以「千奈帝国の美少女軍師」自居，说早就料到（0001～0004）。她先说心中的张良让佑芽用铁球狙击 live 中的星南，被千奈喝止（0007、0008）。千奈说避开上级生的 live 日就好，她说千奈一开始总是这样说，然后排出一周的应援 live：首日美鈴对燕、佑芽跟上，第三天她和佑芽对莉波，其余几天都让佑芽上（0019～0037）。千奈担心佑芽太辛苦，她说张良会这么做、全交给佑芽没问题，又借机要千奈给佑芽好职位，千奈定了副会长；她还问千奈实权是不是已经被美鈴夺走（0036～0054）。她提出最终日让佑芽和千奈两人对星南争取平手，千奈说要一个人挑战星南，她说果然、千奈一定会这么说，大家早就选了千奈（0061～0076）。剧情经过参照 hmsz、hume 笔记。

## 她的关键台词
- 0003「ふふ。落ち着いて、千奈。」——在慌乱的千奈面前保持冷静
- 0004「千奈帝国の美少女軍師であるわたしは、／当然、このような事態を予想していた。」——认真进入“军师”角色
- 0007「佑芽に、ライブ中の星南を鉄球で／狙撃させろって心の張良が言ってる。」——一本正经地提离谱的主意
- 0017「今回のルールだと『同日のライブで／一番目立つ』のがとっても大事。」——抓住规则的重点
- 0020「……ふふ。千奈はいつも、／最初はそういう。」——对千奈的思路了如指掌
- 0024「そういうと思った。」——也预料到美鈴的要求
- 0025「美鈴は初日に配置して、燕にぶつける。／燕より、ステージを盛り上げられそう？」——按每个人的情况排兵布阵
- 0037「なんの問題もない。／ぜんぶ佑芽でおっけー。」——对佑芽的体力和实力毫不怀疑
- 0038「張良ならそうする。わたしもそうする。」——借角色理直气壮
- 0045「なら、いい役職を佑芽にあげて。／かいけ……いや……書記、とか。」——替朋友要职位，差点说漏嘴
- 0054「千奈、もしかして……すでに実権を／美鈴に奪われている？」——冷静吐槽
- 0062「佑芽と千奈で、ふたりがかり。／引き分けに持ち込めれば――」——对星南只求平手的现实判断
- 0073「千奈はぜったい、そういうこという。」——料到千奈会选择单挑
- 0076「わたしたちは、とっくに選んでる。」——表明早已选定千奈

## 行为模式
- 朋友慌乱 → 先笑着让对方冷静，然后进入自己设定的角色（军师、张良）来出主意（0003、0004、0007、0038）
- 出主意 → 先抛一个离谱的方案，再给出认真、有条理的安排：抓规则重点、按日程和每个人的特点配置（0007、0017～0034）
- 很了解身边人的反应，事先料到并说出来（「千奈はいつも、／最初はそういう」「そういうと思った」「千奈はぜったい、そういうこという」）（0020、0024、0073）
- 对朋友（佑芽）的能力深信不疑，把最重的任务交给她（0034、0037）
- 被问回报 → 不为自己要，转而替朋友要好职位（0041～0045）
- 说话：～から放句尾、「おっけー」等口语，逗号切句（0018、0032、0037）

## 关系
- 千奈：叫「千奈」（0003、0020、0047、0054、0073）；千奈叫她「篠澤さん」（0006），也叫「美少女軍師篠澤さん」（0036）。她以千奈的军师自居，料到千奈会选择单挑星南，并说大家早就选了千奈（0004、0073、0076）。
- 佑芽：叫「佑芽」（0007、0027、0034、0037、0045）；佑芽叫她「広ちゃん」（0005、0033、0039、0046）。她把大部分 live 交给佑芽，说全交给佑芽没问题，佑芽说这是信任（0037、0039）；她替佑芽要职位（0045）。
- 美鈴：叫「美鈴」（0025、0054）；美鈴叫她「篠澤さん」（0023）。她预料到美鈴不想多次上场，安排美鈴首日对燕（0024、0025）。
- 星南、燕、莉波：都直呼名字「星南」「燕」「莉波」（0007、0025、0032、0061）；把她们当作选举 live 的对手来排兵。

## 档案类事实
- 她自称「千奈帝国の美少女軍師」（0004），说「心の張良」（0007）。
- 她说选举相关的 live 举办期是到投票日前一天为止的一周（0021）。
- 她排的应援 live 安排：首日美鈴和佑芽对燕，第2天佑芽，第3天她和佑芽对莉波，第4～6天佑芽，最终日对星南（0025～0034、0061）。
- 她问参加这次选举战的成员是否就是明年的生徒会（0042、0043），千奈说是这样打算的（0044）。

## 不确定
- 0045「かいけ……いや……書記」她差点说出“会计”，佑芽问是不是想说「会計」（0046），她说「気のせい」（0047）；为什么改口剧本没写。
- 【译文】0046 原文是“刚才是不是想说我的职位『会計』又停住了”，译文加了“我现在的职位”，原文没有“现在”。
- 0007 铁球狙击是玩笑还是认真，剧本没明说；佑芽认真讨论了（0009），千奈喝止（0008、0010）。
