# 倉本千奈 亲爱度剧情 / 第30话（adv_dear_kcna_030）

- 她的台词：35 行（含用匿名标签说的 0 行）
- 出场的人：千奈（37 行）、広（35）、プロデューサー（7）、一同（1）
- 场景：千奈第一场选拔试验结束后和制作人谈话（0001），她中途插进来（0021）；地点剧本没写明
- 世界线：亲爱度（倉本千奈）；制作人在制作的偶像：倉本千奈

## 发生了什么
千奈问制作人怎样才能“侥幸赢”星南，她插话说由她来讲，自称千奈宿命的对手（0020～0023）。她说千奈最近满脑子都是怎么打倒星南，自己成了“过去的女人”；千奈说她是特别的人、实力相当的强敌，接着却说赢得了星南就不必专门对付她，她说自己也是同样想法，两人互相不服地瞪起来（0024～0042）。两人笑起来，说第一次吵架了，她说生平第一次和朋友吵架，互相道歉（0044～0049）。她说两人实力相当，现在连侥幸赢都谈不上，千奈的制作人一定一直在说要踏实练到最低限度的实力；她说非常难，所以要做，千奈也来，一定很有趣（0050～0060）。她说自己同时受星南和千奈制作人照顾，两边情况都清楚：星南因为太强、『H.I.F』可能稳拿四连冠而不热闹，正在为难，千奈的制作人便向星南提了企划（0064～0076）。她宣布要拍主题为『十王星南に挑むアイドルたち』的纪录片，内容是她们的特训（0077～0080）。

## 行为模式
- 想参与话题 → 突然出现、给自己加称号（宿命的对手、过去的女人），带点戏剧性（0021～0025）
- 被对方“轻视” → 用同一句话回敬，进入孩子气的对峙；吵完很快笑着道歉（0036～0048）
- 第一次经历某种事（和朋友吵架）→ 会特别说出来“生平第一次”（0047）
- 面对很难的目标 → “难，所以做”，并邀朋友一起，说会很有趣（0059、0060）
- 说明计划时 → 先说一句「えっと、具体的な話をする」，再按背景、人物、结论顺序讲（0063～0080）
- 句尾常加「よ」「から」「でしょ」，用逗号断开（0021、0065、0078）

## 关系
- 千奈：叫「千奈」（0024、0038、0051、0059）；千奈叫她「篠澤さん」（0022、0028、0052），说她是特别的人、一起走来的战友兼对手、实力相当的强敌（0028～0030）。她自称千奈的宿命对手（0023），两人第一次吵架又和好（0046～0049）。
- 星南：叫「星南」（0024、0064、0066、0070）；说星南在为她做类似制作的事（0064），转述星南为“变得太强”而为难（0070）。
- 千奈的制作人：称「千奈のプロデューサー」（0053、0065）；说受他很多照顾（0065），说是他向星南提了企划（0073～0076）。

## 档案类事实
- 她说这是生平第一次和朋友吵架（0047）。
- 她说现在星南在给她做类似制作的事，同时也受千奈的制作人照顾（0064、0065）。
- 她说千奈和她实力相当（0051）。
- 她转述星南认为『H.I.F』四连冠是确定的、比赛可能不热闹，星南说「私は強くなり／すぎてしまったのよ」（0068、0070，她转述星南的话）。
- 她宣布要拍纪录片，主题『十王星南に挑むアイドルたち』，拍她们的特训（0078～0080）。
