# 倉本千奈 亲爱度剧情 / 第32话（adv_dear_kcna_032）

- 她的台词：22 行（含用匿名标签说的 0 行）；其中 0024 是在制作人交给学園長的纪录片节目画面里说的（0018、0022～0024）
- 出场的人：広（22 行）、学園長（21）、千奈（20）、プロデューサー（11）、手毬（9）、佑芽（5）、一同（1）、旁白（1）
- 场景：最后一场选拔试验后手毬和千奈（0001～0017）；制作人向学園長报告并播放纪录片（0018～0052）；「『H.I.F選抜試験』全日程が／終了した」之后，她和千奈、佑芽确定进入『H.I.F』（0053～0090）。地点剧本没写明
- 世界线：亲爱度（倉本千奈）；制作人在制作的偶像：倉本千奈

## 发生了什么
手毬说千奈和她的歌都进步到出乎意料（0004）。纪录片节目里，她和千奈、佑芽对观众说要挑战トップアイドル（0022～0024）。选拔试验全部结束后，她说「我ら元補習組」撑过了严酷特训，三人确定参加『H.I.F』（0056、0057）；她说高兴还太早，目标是『一番星』，对佑芽和千奈说自己也是她们的对手、不会输（0059、0063、0064）。她郑重地对千奈说『H.I.F』前有她的 live，一定要来看，最后会唱和千奈一起构思的新曲，那首歌也会在『H.I.F』上唱（0065～0075）。她说千奈想的机关太多让星南头疼，又问千奈用了倉本的力量帮她、输了会不甘心，偶像对千奈是梦想、却让她变强，真的好吗（0076～0081）。千奈说正因为偶像对她是兴趣，篠澤広才这么出色，又问在人生的大舞台模仿憧憬的偶像是否狡猾；她笑起来说不会客气，要千奈看着、听着，说这就是现在的她——最喜欢的你的头号对手（0082～0090）。剧情经过参照 ttmr、hume 笔记。

## 行为模式
- 大家高兴时 → 笑着提醒目标还在前面（0059）
- 对朋友 → 明确说自己是对手、不会输，同时说最喜欢对方（0063、0064、0090）
- 有重要的话要说 → 先「……千奈。」「あの、ね。」停顿，然后直接说出请求（0065～0069）
- 接受了朋友的帮助 → 反过来问对方这样真的好吗、输了会不甘心（0079、0081）
- 被对方的话打动 → 先「そういうこというんだ」，笑出声，再宣告不会客气、要用表演来回应（0084～0090）
- 句尾常加「よ」「ね」，逗号切句（0059、0069、0079、0086）

## 关系
- 千奈：叫「千奈」（0056、0065、0087），也叫「あなた」（0087、0090）；千奈叫她「篠澤さん」（0054、0062、0066、0080），也叫她全名「篠澤広」（0082）。她请千奈一定来看她的 live，新曲是和千奈一起构思的（0069、0073）；千奈说正因为偶像对她是兴趣她才出色（0082）。她称自己是“最喜欢的你的头号对手”（0090）。
- 佑芽：叫「佑芽」（0056）；佑芽叫她「広ちゃん」（0055）。她把佑芽也算作对手（0064「あなたたち」）。
- 星南：叫「星南」（0076）；说千奈的点子让星南头疼（0076）。
- 手毬：手毬叫她「広」，说她的歌进步得出乎意料（0004）；本篇她和手毬没有直接对话。

## 档案类事实
- 她和千奈、佑芽称为「元補習組」（0056）。
- 她通过了『H.I.F選抜試験』，确定参加『H.I.F』（0053～0057）。
- 『H.I.F』之前有她的 live，最后会唱新曲，也会在『H.I.F』上唱（0068、0071）。
- 新曲是她和千奈一起构思的，两人一起出主意、做了订单（0073、0074 千奈的话）；她称这是为她写的最好的歌（0075）。
- 千奈用了倉本的力量（0078 千奈的话、0079）。
- 手毬说她的歌进步得出乎意料（0004，手毬的话）。
