# 篠澤広 亲爱度剧情 / 第1话（adv_dear_shro_001）

- 她的台词：39 行（含用匿名标签说的 0 行）
- 出场的人：広、プロデューサー、学園長（只有 0041 一行，夹在広的转述里）
- 场景：先是校内某处（地点没写明），広摇摇晃晃走来并倒下；之后在保健室（0010）
- 世界线：亲爱度（篠澤広）；制作人在制作的偶像：篠澤広

## 发生了什么
制作人看到一名女生摇摇晃晃走来，出声询问时她倒下，被送进保健室（0002～0011）。醒来后她道谢，互通姓名，随即请对方制作自己；制作人当面说她不适合当偶像，她却笑了，制作人在心里觉得她心情变好了（0023～0029）。制作人说出她 14 岁大学毕业、入学考试实技 0 分的经历，她说面试时有个奇怪的老爷爷看好她，但又说认为对方（制作人）才是对的，让他自信（0033～0046）。问她为什么想当偶像，她说可能因为这看起来最不适合自己（0050、0051）。制作人拒绝接手，她提出先试试、不喜欢可以解约，理由是没有别人愿意当她的制作人（0057～0062），制作人说暂定一个月（0065）。她说自己虽然完全不适合，但会认真全力去努力，因为那一定很快乐（0068～0070）。制作人的独白是顺势接下了、很不安（0071、0072）。

## 她的关键台词
- 0023「わたしをプロデュースしてほしい。」——刚互通姓名、沉默片刻后直接提出请求，毫无铺垫。
- 0045「つめたい目。わたしをすごく／低評価しているのがわかるよ。」——她从对方的眼神读出低评价，并直说出来。
- 0046「おじいちゃんじゃなくて、／あなたが正しいと思う。自信もって。」——站在否定自己的一方，还反过来鼓励对方。
- 0051「……いちばんわたしに向いてなさそう／だから、かな。」——想当偶像的理由，这一话的核心。
- 0053「ちっともわからない、って、顔してる。」——会读对方的表情，并平静地说破。
- 0055「しばらく一緒にいれば、わかるかも？」——不解释理由，留到以后。
- 0059「いやになったら、契約解除すればいい。」——提议试用时，主动把退路留给对方。
- 0062「わたしがアイドルになるためには、／プロデューサーが必要だから。」——用条件推导的方式说明需求。
- 0068「わたし……アイドルに、／ちっとも向いていないけど。」——她自己也承认不适合。
- 0069「本気で、全力で、がんばるよ。」——接在上一句后的表态，这时是打算，还没有结果。
- 0070「それはきっと、楽しいから。」——努力的动机被说成快乐。

## 行为模式
- 被当面说不适合当偶像 → 笑一声、答一句是吗，心情看起来反而变好（0026～0029）
- 听到带贬义的传闻（实技成绩）→ 说害羞，当成夸奖收下（0034、0035）
- 对方给自己低评价 → 点破、肯定对方判断正确，还让对方自信（0045、0046）
- 被问动机 → 给一句让人听不懂的短答，看对方困惑后不解释，只说相处久了也许会懂（0051～0055）
- 需要别人答应时 → 降低对方的负担（试用、可解约），再用简单的条件理由说明（0058～0062）
- 别人帮了忙 → 简短道谢（0011、0012）；别人向她道谢 → 一本正经地回不客气（0047、0048）

## 关系
- プロデューサー：她称「プロデューサー」（0052）；这一话他称她「篠澤さん」（0056）。这是初次见面（0019、0020）。她主动请他制作自己；他当面说她不适合，拒绝后又答应暂定一个月（0026、0057、0065）。
- 学園長：她称「へんなおじいちゃん」（0040），说的是面试时看好她的人；紧接着的 0041 标签是学園長。

## 档案类事实
- 14 岁从大学毕业，被称为天才少女、神童（制作人的话，0033）
- 入学考试实技 0 分（制作人的话，0034、0036）；笔试满分（她带问号说的，0037）
- 面试时学園長说她有前途，要她以顶级偶像为目标（0040～0042）
- 制作人说她曾被寄予厚望，抛下一切来到初星学園（0049）
- 她说没有别人愿意当她的制作人（0061）
- 自称「わたし」（0018）；反复用「ちっとも」（0053、0068）
- 制作人是制作人科 1 年级（0017）

## 不确定

- 0025「……なんで？」问的是什么不明确，前一行制作人只说了太突然（0024），接下来 0026 他答她不适合当偶像；中间可能有没写出的选项。
