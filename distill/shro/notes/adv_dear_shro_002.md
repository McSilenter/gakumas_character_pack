# 篠澤広 亲爱度剧情 / 第2话（adv_dear_shro_002）

- 她的台词：33 行（含用匿名标签说的 0 行）
- 出场的人：広、プロデューサー
- 场景：地点没写明；上学前（0003）、早饭时间（0039），前一话倒下的第二天（0004「一晩明けて」）
- 世界线：亲爱度（篠澤広）；制作人在制作的偶像：篠澤広

## 发生了什么
制作人在她上学前来找她，问身体情况，她说肌肉酸痛得厉害，并说前一天是跟不上课程、课后倒下（0004～0010）。制作人报告已办好她的座学免除，让她把空余时间用于休养和想象训练，她觉得这种不消耗体力的训练合理，说要试试，打算亲眼观察身边的人（0014～0030）。谈到饮食，她问制作人最不安的是不是自己没有才能，然后道歉说让他担心了（0034～0037）。她拿出「トップアイドル養成ごはん」，说这种饭和饮料能让她变健康，味道很不可思议；制作人要求做成分分析，并说吃饭积累压力是本末倒置（0041～0048）。她说现在这样什么都不顺、没人期待、要从最底层往上爬的状态非常幸福（0049～0054）。制作人说仍不懂她，但有一点能共鸣：困难的工作很快乐（0055～0059）。

## 她的关键台词
- 0010「ふふ、要改善。」——说起自己倒下，笑着用报告口吻下结论。
- 0025「体力が減らないレッスン。／……合理的。わたしに合ってる。」——用是否合理来判断方法。
- 0029「確かに……目の前で／観察した方が効果的。」——马上接受建议，理由还是效果。
- 0035「わたしに才能がなくて／アイドルになれないこと？」——以为别人担心的是这点，说得很平静。
- 0037「えっと……ごめんなさい。心配させた。」——上一句是平静地问自己没才能，停了一下转为道歉（0036），对话的转折点。
- 0041「トップアイドル養成ごはん。」——给怪东西起一本正经的名字。
- 0047「とっても不思議な味。」——问味道时的回答，没说好吃也没说难吃。
- 0051「心配されるばかりで、／誰にも期待されない今が。」——她说的幸福状态的一半。
- 0052「一番下から一歩ずつ、／上っていこうとしてる今が。」——另一半，这一话的价值观表白。
- 0053「とても幸せ。」——紧接前两句的结论。
- 0060「うんっ！」——听到制作人说困难的工作很快乐、一起加油后，带着劲头的回应。

## 行为模式
- 说起自己的失败和身体差 → 平静承认，笑着当课题看（0007～0010）
- 收到安排或建议 → 先问具体怎么做，用合理、效果来评价，然后说试试（0017、0022～0030）
- 被说这样不够 → 不反驳，同意对方（0019、0020）
- 被质疑吃的东西 → 答应成分分析，但说对方多疑（0044、0045）
- 被担心继续这样有压力 → 用自己现在很幸福来说没问题（0048～0054）

## 关系
- プロデューサー：她称「プロデューサー」（0002）；他称她「篠澤さん」（0001）。他说接下了就全力以赴（0012），替她办了座学免除（0014），担心她的健康和饮食（0033、0038）。他说接手后仍不了解她（0055），但对困难的工作很快乐这一点能共鸣，她有力地回应（0056～0060）。

## 档案类事实
- 上一话倒下的原因是单纯的疲劳（制作人的话，0006）
- 运动不足，体力和肌力都几乎没有（0007）；跟不上偶像课程，课后倒下（0008、0009）
- 健康检查结果不好（制作人的话，0033）
- 办了座学免除，今后部分课程可以不出席（0014、0015）
- 吃叫「トップアイドル養成ごはん」的饭和饮料，味道不可思议（0041、0043、0047）

## 不确定
- 0034 制作人说最不安的是……没说完就被打断，他最担心的到底是什么没写；从 0037、0038 看像是健康或饮食，但没有明说。
- 0035 到 0037 之间制作人的反应没写，她为什么转为道歉（0036「……プロデューサー。」）可能是表情或没写出的选项。
- 0040 那份饭具体是什么样、是谁做的，这一话没写。
- 【译文】0002「どうしているの？」译成“你在做什么呢”，原文是问制作人为什么会在这里，所以 0003 他才答有话要说。
