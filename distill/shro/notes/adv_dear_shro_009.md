# 篠澤広 亲爱度剧情 / 第9话（adv_dear_shro_009）

- 她的台词：35 行（含用匿名标签说的 0 行）
- 出场的人：広、プロデューサー
- 场景：校内很小的ライブ（0013），她上场前（0035）和下场后（0039）
- 世界线：亲爱度（篠澤広）；制作人在制作的偶像：篠澤広

## 发生了什么
她问制作人是怎么办成的，他说是拜托别的制作人，让她当前座（0002、0007）。她说明白失败会给很多人添麻烦，偶像绝对不能让ライブ失败（0016～0020）。制作人说她实力不足，这场ライブ是用制作人的信用做赌注，理由是有趣、想做、不甘心，还有不知为何觉得该做（0022～0031）。她说不合理，说他上场前尽说偶像的坏话，又说她的制作人是他真好，然后上场（0032～0038）。下场后她说非常开心，制作人夸她表现中规中矩、完成了前座的最低任务，她为这些话高兴（0040～0046）。他说最大的收获是她在任何逆境都不怕、越是绝境越能发挥出超过实力的力量，她说自己也吃惊，比练习时唱得好得多（0051～0054）。她说要是不再是危机，自己会变得更差，他说只要继续当偶像，今后一直都是绝境，她说那没问题（0056～0060）。他说这次大成功，让她说感想，她说非常开心，随后叹气（0062～0064）。

## 她的关键台词
- 0005「プロデューサーなら、／なんとかしてくれるかなって。」——对他的信任，语气轻松。
- 0003「思い立った翌日にライブなんて、／できるわけないのに。」——自己也知道是任性要求。
- 0010「ふたりきりでライブを観にいく関係。」——对“不是朋友”的回应。
- 0019「だからアイドルは、絶対に、／ライブを失敗しちゃいけない。」——她把这件事看得很严肃。
- 0032「非合理。」——评价制作人赌在她身上。
- 0037「わたしのプロデューサーが、／あなたでよかった。」——上场前的话。
- 0038「いってきます。」——和 0039 对应。
- 0039「ただいま、プロデューサー。」——下场后的第一句。
- 0040「……すごく楽しかった。」——下场后的感想。
- 0046「えへへ……こんなにプロデューサーが／褒めてくれるの、はじめて。」——对只是中规中矩的评价也高兴。
- 0052「……だって、そのために／アイドルになったから。」——被说不怕逆境时的回答。
- 0057「いまよりもっと、／だめだめなわたしになると思う。」——担心不再是危机时的自己。
- 0060「……ほんとだ。問題ないね。」——接受永远是绝境这个说法。

## 行为模式
- 提了任性的要求 → 自己也知道不可能，但相信对方能办到，办到了就笑（0003、0005、0006）
- 正式上场前被说实力不足、压力很大 → 同意对方（0023），抱怨他尽说坏话，然后说幸好是你（0023、0035～0037）
- 听到不合理的决定 → 直接说不合理（0032）
- 被夸程度其实一般 → 高兴（0043、0046）
- 被说成在逆境中才强 → 想的反而是逆境没了怎么办（0056、0057）
- 成功后 → 说很开心，之后叹气（0063、0064）

## 关系
- プロデューサー：她称「プロデューサー」（0002）；他称她「篠澤さん」（0021）。她说他们是两人单独看ライブ的关系，他说是课程的一部分（0010、0011）。他说制作人和担当偶像不是朋友（0009）。她说幸好她的制作人是他（0037）。

## 档案类事实
- 这场ライブ是校内很小的ライブ的前座，由制作人拜托其他制作人争取（0007、0013）
- 制作人说她才刚开始正经的课程，实力不够站上舞台（0021、0022）
- 正式上场时比练习时唱得好得多（0054）
- 制作人的评价：任何逆境都不怕、不动摇、不叹息，越是绝境越能发挥超过实力的力量（0051、0053）

## 不确定
