# 篠澤広 亲爱度剧情 / 第10话（adv_dear_shro_010）

- 她的台词：44 行（含用匿名标签说的 0 行）
- 出场的人：広、プロデューサー
- 场景：前半地点没写明；后半在遊園地（0015）
- 世界线：亲爱度（篠澤広）；制作人在制作的偶像：篠澤広

## 发生了什么
她告诉制作人，排在她后面演出的女生们作为奖励和担当制作人去了遊園地，他只应了一声，被她说明知她的希望却无视，最后她直接说要去（0002～0014）。到了遊園地她说第一次来，但马上说累了想休息（0015～0026）。她问他为什么从来不问过去，他说事前已调查，也决定尽量不用她的经历；她说入学面试时老师说的正相反，他说经历是武器，但她想空手挑战就这么做，不向粉丝公开她的经历（0028～0042）。他问为什么是偶像，她说自己不会说话、不会表达、身体弱，最不适合，而且再成功也不会安稳；他追问为什么偏偏觉得偶像有趣，她犹豫后说想变得可爱（0047～0057）。她问他今后还制作自己吗、这个月试用契约能否延长，他说根本没有试用契约，从一开始就是正式契约，承认是骗她，认为这样结果会更好（0060～0067）。她说一直担心被放弃，说他过分，然后接受，说这样一直都很开心，要继续约会（0068～0077）。

## 行为模式
- 想要什么但不直说 → 先讲别人的事暗示，被无视就指出，再直接宣布（0002～0013）
- 期待的事到了眼前 → 身体先不行，说累了要休息（0015、0019）
- 被问到不好开口的动机 → 长时间沉默、问别人笑不笑，然后说出来（0053～0057）
- 被骗得知真相 → 先短问，说自己一直担心，被吐槽后承认，再骂一句，最后接受（0066～0075）

## 关系
- プロデューサー：她称「プロデューサー」（0001）；他称她「篠澤さん」（0030），称全名（0042）。他决定不使用她的经历（0030、0042），承认隐瞒了正式契约（0065、0067）；她骂他是鬼、恶魔（0071），又说继续约会（0077）。“约会”是她的用词，这一话他没有回应这个词。

## 档案类事实
- 第一次去遊園地（0015）
- 入学面试时看过她履历的老师（她带问号说的“先生？”）说，用好经历马上能成为有名偶像（0031～0033）
- 她想不靠经历挑战（制作人问，她答是，0039、0040）；制作人决定不向粉丝公开她的经历（0042）
- 她自述不会说话、不会表达、身体弱、容易倒下（0048）
- 选择偶像的理由还包括：再成功也没有安定和安稳（0050）；想变得可爱（0057）
- 试用契约并不存在，从一开始就是正式契约，是制作人骗她的（0063、0065、0067）

## 不确定
