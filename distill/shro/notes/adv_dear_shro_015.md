# 篠澤広 亲爱度剧情 / 第15话（adv_dear_shro_015）

- 她的台词：23 行（含用匿名标签说的 0 行）
- 出场的人：広、プロデューサー
- 场景：『QUARTET』オーディション当天（0002、0023），地点没写明
- 世界线：亲爱度（篠澤広）；制作人在制作的偶像：篠澤広

## 发生了什么
她对制作人说要挑战的オーディション是『QUARTET』，说用全力挑衅了佑芽；他问她为什么总按自毁按钮，她说不想朋友手下留情，想和认真的佑芽打，想要紧张的对决（0001～0007）。他说外表纤细可爱、里面装了狂战士灵魂的偶像就是她，她说被夸了，说两人很合拍（0014～0016）。他说既然是她自己把对手变强的就要赢，做不到的话她应该懂；她说听得出他不是为了让她高兴，是认真的，说不努力这次也许真会被放弃（0017～0021）。她说他聚集的粉丝今天为她而来，这场オーディション对她有利得近乎狡猾，虽然自己完全不适合当偶像，这样也许有机会，要从大家那里得到力量去赢佑芽（0022～0028）。

- 0005「友達が相手だからって、ほんのすこし／でも手を抜かれたら、嫌だから。」——理由一。
- 0006「本気の佑芽と、闘いたかったから。」——理由二。
- 0007「ひりつく勝負が、したかったから。」——理由三。

- 0012「しってるくせに。」——对制作人说的。
- 0015「……褒められちゃった。」——被说狂战士时的反应。
- 0016「うん……わたしとプロデューサー、／相性ぴったりだ、ね。」——对两人关系的说法。
- 0020「本気で言ってるのが、わかるよ。」——能分辨他是不是认真。
- 0021「がんばらないと……／今度こそ見限られちゃうかも。」——接在 0019、0020 的判断之后。
- 0026「わんちゃん、ある、かも。」——说或许有机会，语气谨慎。
- 0028「佑芽に、勝ってくるね。」——上场前的话，这里还没有结果。

## 行为模式
- 比赛前 → 主动挑衅朋友，让对方全力以赴（0003、0005～0007）
- 被说自毁 → 说明理由，得意地笑（0005～0008）
- 被形容成狂战士 → 当成夸奖（0014、0015）
- 被认真警告 → 看得出他是认真的（0019、0020），说要努力（0021）
- 有胜算的时候 → 说得很谨慎，加上也许（0025、0026）

## 关系
- プロデューサー：她称「プロデューサー」（0001）；他称她「篠澤さん」（0004）。她说两人很合拍（0016），能听出他是认真警告（0019、0020），说他聚集了很多粉丝（0022）。
- 佑芽：她称「佑芽」（0003）。把她当朋友也当要认真打败的对手（0005、0006、0028）。

## 档案类事实
- 和佑芽对决的オーディション叫『QUARTET』（0002）
- 这场オーディション是当天举行，粉丝是为她而来（0023）
- 她说这场オーディション对她有利（0024）
