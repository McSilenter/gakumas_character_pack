# 篠澤広 亲爱度剧情 / 第17话（adv_dear_shro_017）

- 她的台词：25 行（含用匿名标签说的 0 行）
- 出场的人：広、千奈、佑芽、メイド、プロデューサー
- 场景：地点没写明；広和佑芽看电视上千奈的节目（0003～0006），之后千奈过来
- 世界线：亲爱度（篠澤広）；制作人在制作的偶像：篠澤広

## 发生了什么
她和佑芽一边看千奈上节目，一边拆千奈的生写真包，她说自己也想上挑战类节目，但制作人不许（0003～0012）。她抽到的总是同一张，メイド提出交换，她答应并说会善待新粉丝（0017～0022）。千奈回来发现这些，说是星南企划的害羞周边，她说羡慕两人有写真包，说要不要拜托制作人也出一个（0028～0033）。佑芽祝贺千奈排名进入个位数，她夸千奈可爱、很棒的偶像，让千奈有自信，千奈夸她漂亮，她说害羞（0037～0045）。三人说也许能一起上『FINALE』，她说不知不觉走了很远（0046～0051）。她宣布自己会赢，赢了会叹气，但不是因为无聊，当了偶像后的叹气有时和以前不一样；千奈说早知道，佑芽说叹气是非常开心时的证明（0055～0062）。她接上千奈的话说三人是朋友也是ライバル，提议在『FINALE』较量（0064～0067）。剧情经过参照 hume、kcna 笔记。

## 她的关键台词
- 0003「最近、テレビを見るのが楽しい。／今日も千奈がかわいい。」——追朋友的节目。
- 0007「わたしもあんなふうに、アスレチックに／挑戦する番組に出たい。」——想挑战危险项目。
- 0010「素潜りとか、スカイダイビングとか、／楽しく紹介する自信があるのに。」——自信能有趣地介绍这些危险项目。
- 0018「ふふ、ランダム封入って……／……罪深い、ね。」——对抽卡的吐槽。
- 0022「もちろん。それが……／古参ファンのつとめ。」——以老粉丝自居。
- 0026「千奈の生写真パック、開封の儀。」——一本正经的说法。
- 0032「ふたりが羨ましい。／篠澤広パック……憧れる。」——对自己周边的向往。
- 0042「千奈はかわいい。すごいアイドル。／自信持って。」——直接夸朋友。
- 0051「いつの間にか、／遠いところまできちゃった。」——回顾，0052 佑芽反驳。
- 0058「だけど……つまらないから、じゃない。」——对叹气的修正，这一话的要点。
- 0059「アイドルになってからのため息は、／いままでのとは違う……ときもある。」——说以前的叹气和现在不同。
- 0065「友達で……ライバル。」——三人的定位。

## 行为模式
- 看到朋友出现在节目或周边里 → 很开心，以粉丝身份参与（0003、0017、0022）
- 想做危险的事 → 列举，抱怨制作人不许（0007、0009、0010）
- 朋友被夸 → 她也夸，并说要自信（0042）；被夸时说害羞（0043、0045）
- 宣告胜利前 → 先说好叹气的事，再解释不是无聊（0055～0059）

## 关系
- 千奈：她称「千奈」（0003）；千奈称她「篠澤さん」（0023）。以千奈的粉丝自居（0003、0022），夸千奈（0042），说三人是朋友也是ライバル（0065）。
- 佑芽：这一话她没有直接称呼佑芽；佑芽称她「広ちゃん」（0013）。佑芽说她的叹气是非常开心时的证明（0061、0062）。
- プロデューサー：她称「プロデューサー」（0009）；这一话他没有称呼她。她说他不让自己上危险节目（0009、0012）。
- メイド：用千奈的写真和她交换，她接受（0019～0022）。

## 档案类事实
- 想上挑战类节目，举了自由潜水和跳伞，但制作人不许（0007、0009、0010）
- 喜欢看千奈的节目（0003）；千奈的生写真包是星南企划的（0028）
- 想要篠澤広写真包（0032）
- 叹气有时不再是无聊（0058、0059）；佑芽说是非常开心时的证明（0061、0062）
- 『N.I.A』：千奈排名进入个位数（0037）；三人可能一起出『FINALE』（0046、0047）
