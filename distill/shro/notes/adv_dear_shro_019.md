# 篠澤広 亲爱度剧情 / 第19话（adv_dear_shro_019）

- 她的台词：19 行（含用匿名标签说的 0 行）
- 出场的人：広、プロデューサー、千奈、佑芽
- 场景：オーディション刚赢之后（0002、0005），会场（0017）；千奈、佑芽来时広已经睡着（0023）
- 世界线：亲爱度（篠澤広）；制作人在制作的偶像：篠澤広（剧本里没有直接说法）

## 发生了什么
広赢下オーディション，向制作人要夸奖（0001～0003）。制作人说准备好的夸奖全被吹飞了，広说有这句话就够了，又说她知道别的制作人怎么说他，问这样算不算替他证明了“趣味不输梦想”（0005～0011）。她说有重要的报告和请求：父母来了会场，问他愿不愿意一起见（0013～0019）。后半広累得睡着时千奈、佑芽来祝贺，两人谈到広平时对制作人的形容，托他转告下次不会输（0020～0036）。広醒来说中途就听到了，说她们是第一次交到的最好的朋友（0039～0042）。剧情经过参照 hume、kcna 笔记。

## 她的关键台词
- 0002「ふふ…………勝った。」——胜利时依旧是轻声的笑
- 0003「褒めて。」——直接开口要夸奖
- 0007「……覚えててくれたんだ。」——对方还记得赛前要夸她这件事，她先被这一点打动
- 0008「じゅうぶん。その言葉だけでいい……／その言葉だけがいい。」——不要漂亮话，只要他这句真心话
- 0009「あなたが他のプロデューサーに、／なんて言われているか……しってる。」——一直知道他因为自己被人说闲话
- 0010「……見返せた、かな。／……証明できた、かな。」——她把胜利看成替他争气
- 0011「あなたの趣味は、夢に劣らないって。」——接上第5话制作人关于趣味的说法（第5话 0052、0061）
- 0017「会場に、パパとママがきてる。」——称父母为パパ、ママ
- 0019「一緒に……会ってくれる？」——把见父母当作重要的请求，带着犹豫
- 0041「うん……はじめてできた……」——接下一行，说朋友是第一次有
- 0042「最高の友達。」——用来概括千奈和佑芽

## 行为模式
- 赢了之后 → 不大声欢呼，轻笑一下，然后直接要对方夸奖（0002、0003）
- 对方夸得笨拙但真心 → 比起夸奖的内容，更在意对方把约定记着（0006～0008）
- 取得成果 → 先想到这能不能替制作人争气（0009～0011）
- 提重要的事 → 先铺垫“有报告和请求，要听吗”，语气变慢、结巴（0012～0016）
- 别人以为她睡着时在旁边说话 → 中途其实听到了，醒来才说出来（0037、0039）

## 关系
- プロデューサー：她称「プロデューサー」（0001）。向他要夸奖，把他受到的非议放在心上（0003、0009～0011），请他一起见父母（0019）
- 千奈、佑芽：说她们是第一次交到的最好的朋友（0041、0042）。本篇她没有直接称呼这两人；千奈称她「篠澤さん」（0020）、佑芽称她「広ちゃん」（0021）；两人输了不甘心，仍来祝贺（0024、0025），托制作人转告下次不会输（0036）
- 父母：称「パパとママ」（0017）；他们来了会场，这一篇还没有见面

## 档案类事实
- 称父母为パパ、ママ，父母来看了这场オーディション（0017）
- 她对千奈、佑芽有过这样的形容（由佑芽转述）：制作人眼神冷、随时像要放弃她、像鬼像恶魔，千奈接了一句喜欢这种地方（0029、0030）

## 不确定
- 本篇没有写这场オーディション的名字；从第18话 0002 的『FINALE』和第21话 0009 看是『N.I.A』的决赛，这里只作推断。
- 0029、0030 是佑芽、千奈转述広的话，本篇没有広亲口的那句；对应第3话 0023（hume、kcna 笔记有提到）。
- 0037～0039：広是睡着中途醒了听到，还是一直装睡，本篇只说途中听到了（0039）。
- 【译文】0011 原文「あなたの趣味は、夢に劣らないって。」，译文“你的品味，不输给梦想”把趣味（这条线的关键词，指把制作不适合当偶像的她当爱好）译成品味，意思偏了。
