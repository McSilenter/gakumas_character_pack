# 篠澤広 亲爱度剧情 / 第21话（adv_dear_shro_021）

- 她的台词：45 行（含用匿名标签说的 0 行）
- 出场的人：広、プロデューサー
- 场景：ミーティング（0001）；中段转到体力測定之后（0038、0039）；地点没写
- 世界线：亲爱度（篠澤広）；制作人在制作的偶像：篠澤広（0052）

## 发生了什么
ミーティング一开始，她不满制作人叫“篠澤さん”，要他叫“広”，他改称「広さん」（0001～0007）。现状共有时她把和他的约定说成婚约，被他否认（0009～0012）；之后看起来有两种分支，一种是复述上一话那句“趣味のまま夢を見たっていい”，另一种是他说“――と”，她说他的心思早就藏不住（0013～0026）。她宣布要以学园第一的『一番星』为目标，但这只是中间目标，新的梦想要很久以后才能在他面前说（0029～0037）。体力測定结果是勉强够到中学1年生的平均值，制作人总结她是“雰囲気トップアイドル”（0039～0060）。谈到冬的『H.I.F』，他说目前她当上『一番星』的可能性是0%，目标是在『H.I.F選抜試験』前提到1%，她说1%都很难，又邀他去“再起一次奇迹”（0063～0076）。

## 行为模式
- 被叫姓 → 不说话摆脸色，等对方问，再要求叫名字；叫了就开心（0002～0007）
- 被他用冷话回应 → 反而说让她发抖、超出想象（0024～0026）
- 宣言目标时 → 自己先说这是身の程知らず，然后依旧说要做（0029～0037）
- 自己的状况 → 冷静接受坏消息（“正确的见立て”），并分析为什么赢不了（0065～0067）
- 成绩被抑扬顿挫地评价 → 笑着吐槽“把我捧起来又摔下去”（0044、0047）
- 被直接夸可爱 → 反击说“你很喜欢我的脸吧”（0057），或说他不害羞太狡猾（0052、0053）

## 关系
- プロデューサー：她称「プロデューサー」（0028），说喜欢他那副表情（0007），说他高兴地呆住的样子很灵巧（0028）；他称「篠澤さん」（0001），后改「広さん」（0006、0008）。她称自己和他“一起见同一个梦”（0017）。她约定这个新梦要很久以后才说（0036）
- 其他人本篇未出现

## 档案类事实
- 在『NEXT IDOL AUDITION』优胜（0009，她自己说）
- 体力測定勉强够到中学1年生平均值（制作人 0040），作为偶像仍是最低水平（制作人 0043、0046）
- 外表被制作人形容为儚く華奢、神秘（制作人 0050、0054）；制作人说她比认识时健康了（制作人 0050）
- 当前目标是冬的『H.I.F』优胜（制作人 0063）；要当『一番星』（0029）
- 『H.I.F』竞技性高，和『N.I.A』情况不同（0066）

## 不确定
- 0013～0018 和 0019～0026 看起来是选项造成的并列分支（他说“这样说的”与他说“――と”），不是连续事件；0020 的「気持ち、ばればれ」指他的什么心思，本篇没写明，可能是上一话 0072～0076 那段。
- 0015「わたしの才能を否定しながら、／面白そうなことを言ったね。」和 0024～0025 指的话，对应上一话的哪一句，本篇没有明说。
- 0062 她说是悪口，但语气是开玩笑。
- 【译文】0012 原文「同じくらい、大事な話をした。」，译文“和当时说的分量也差不多”，意思不通。
- 【译文】0015 原文「面白そうなことを言ったね」，译文“又说这种话逗我开心”把“说了有趣的事”译走样。
- 【译文】0062 原文「雰囲気……トップアイドル」，译文“初具人形的顶级偶像”把“只有气质的顶级偶像”的讽刺译成了另外的意思。
