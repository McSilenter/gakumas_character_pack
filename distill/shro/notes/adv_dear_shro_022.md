# 篠澤広 亲爱度剧情 / 第22话（adv_dear_shro_022）

- 她的台词：45 行（含用匿名标签说的 0 行；0048～0075 中的她的台词是她讲述过去的回忆）
- 出场的人：広、プロデューサー、星南
- 场景：休息日外出的途中休息（0003～0008）；回忆里是她和星南初次见面（0048 起），地点没写
- 世界线：亲爱度（篠澤広）；制作人在制作的偶像：篠澤広（剧本里没有直接说法）

## 发生了什么
休息日，広称之为约会，制作人称之为息抜き，并在休息时开ミーティング，议题是星南（0003～0015）。她说夏的『H.I.F』里星南、佑芽、咲季都很厉害，自己很不甘心，下次要突破選抜試験出场并赢过星南（0024～0031）。她说目前胜率是0，自己想不出办法，问制作人有没有办法，制作人说第一步是向星南本人请教（0035～0042）。她说星南会答应，并讲起认识星南的经过：星南用“看得见的力量”量出她的アイドルパワー是4，她照学园长的建议运气，星南说升到了400（0047～0075）。制作人问是妄想吗，她说是真事，并说星南是有趣的前辈，喜欢她的配合（0076～0079）。剧情经过参照 jsna 笔记。

## 行为模式
- 外出就说成“约会”，被否定也不改口，继续撒娇抱怨（0004、0009、0011、0020）
- 被安排开会时 → 说“换作别人我要生气的”，但还是接受（0009～0012）
- 面对强敌 → 先说强者的厉害，再老实说不甘心，最后说要赢（0024～0031）
- 自己没办法时 → 笑着直接说想不到办法，请制作人想（0037）
- 听到不靠谱的“玄学”说法 → 顺势配合，一起玩（0064～0075）
- 面对初次见面的人 → 直接要求彼此叫名字（0050）

## 关系
- プロデューサー：她称「プロデューサー」（0037）；他称「篠澤さん」（0001），也称「広さん」（0015）。她想要约会的氛围、他总说不是，她也知道他会有办法（0039）
- 星南：她称「星南」（0031、0050）；星南称她「広」（0073）。她说星南是学园最厉害的偶像（0017），是要挑战的对手（0018）；也是好玩的前辈（0078）
- 学園長：她称「おじいちゃん」（0053、0064）

## 档案类事实
- 和制作人一起看了夏的『H.I.F』（0020、0022）；那时她没有参加选拔，制作人说因为实力不够（制作人 0028）
- 夏的H.I.F上佑芽、咲季有出场，星南最厉害（0024、0031）
- 和星南初次见面是认识制作人后不久（0047）；当时星南还被称作会长（0048）
- 星南量出她的アイドルパワー为4，运气后400（星南 0060、0071）——是她讲述的回忆，她说是真事（0077）

## 不确定
- 0048～0075 的数字（4、400）是星南的“能力”，本篇没有其他佐证；第23话星南提到这件事（星南 0052），说明星南也记得。
- 0043「えー……あなたを倒したいので、／俺の広ちゃんに助言してよって言うの？」是她在模仿制作人去请求的语气，不是本人的打算。
- 0001 制作人仍称「篠澤さん」，0015 又称「広さん」，上一话她要求改口之后称呼有来回。
- 0075「趣味でアイドルをやっている者だ、よ。」是回忆里她的回答，语气是配合对方的玩笑，还是认真，本篇不好判定。
