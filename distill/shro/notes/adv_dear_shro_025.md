# 篠澤広 亲爱度剧情 / 第25话（adv_dear_shro_025）

- 她的台词：40 行（含用匿名标签说的 0 行；0018 是她的心里话）
- 出场的人：広、owl、プロデューサー、？？？（0011，门内的声音，下一行自报 owl，是 owl；不算她的台词）
- 场景：フェス现场，owl 的休息室门前到室内（0008～0013）；之后和制作人谈（0058 起）
- 世界线：亲爱度（篠澤広）；制作人在制作的偶像：篠澤広（0017）

## 发生了什么
要见 owl 时她紧张到说比ライブ还紧张，要制作人陪（0001～0003）。见面后 owl 和舞台形象完全不同，她说 owl 这个偶像是团队创作的作品，自己是“外装担当兼操纵者”，owl 和本人的个性是分开的（0026～0030）。她问被夸可爱不高兴吗，owl 说团队作品被夸是高兴的，又说歌词有一半是自己写的，那部分很少被夸（0031～0037）。owl 说这种差距是偶像常见的烦恼，自己的解决办法是 ライブ 后全队打上げ互相称赞（0046～0050）；她说很有参考价值，但不会照单全收（0052）。owl 请她赢了星南时带一句话（0055～0057）。和制作人谈时她说问题本来就不存在，并说一切都交给他；他说这就办，方法是两人一起跳进窮地（0059～0078）。

## 行为模式
- 见到憧憬的人 → 结结巴巴，改用敬语（0014、0016）
- 陷入紧张 → 还能用“你在享受我的窮地”调侃对方（0005）
- 对方诚恳地讲述 → 也认真回应，并问到底（0024、0045、0048）
- 收到建议 → 表示感谢，但说不会全信（0052）
- 有问题交给制作人 → 带着信任说“你会解决的”，他当场应下，她吃惊（0064、0066、0068）
- 听到危险的提议 → 高兴和不祥的预感一起说出来（0075、0076）

## 关系
- owl：她称「owl先輩」（0025、0053），当面敬语，称作「あなた」（0024）；owl 称「篠澤広さん」（0013）、「広さん」（0054）。第一次见面（owl 0013）
- プロデューサー：她称「プロデューサー」（0001）。说他是最喜欢她、最了解她的人（0062），她认为他是故意绕路让她自己想通（0063）。他称她「広さん」（0004）

## 档案类事实
- 这是她和 owl 第一次当面见面（owl 0013）
- owl 将自己的偶像形象视为团队作品，自己是“外装担当兼操纵者”（owl 0026、0029、0030）——是 owl 的自我描述
- 歌词一半是 owl 写的（owl 0036）；她之前觉得歌词好，但不曾特别在意（0038）
- 她喜欢 owl 是因为 owl 的可爱（0040）
- 第一次“奇迹”：在制作人面前唱得比练习时好得多（0072、0073）
