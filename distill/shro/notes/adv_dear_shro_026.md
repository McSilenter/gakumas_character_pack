# 篠澤広 亲爱度剧情 / 第26话（adv_dear_shro_026）

- 她的台词：44 行（含用匿名标签说的 0 行；0055 是她的心里话）
- 出场的人：広、プロデューサー
- 场景：フェス现场（0008～0012），她上场前（0038）和 上场后（0039）
- 世界线：亲爱度（篠澤広）；制作人在制作的偶像：篠澤広（0034）

## 发生了什么
制作人说提升神格的办法是一起跳进窮地：フェス的シークレットゲスト就是她，现在、这里要开ライブ，就在 owl 前一个，还给她安排了抬高门槛的MC（0001～0017）。她吐槽想发火，又说如果失败之前积累的都白费，她不想那样，答应“死也要上”（0014、0025～0031、0038）。上场后她说撑过了大危机，问胜率过1%了没，他说有2%（0041～0045）。她反过来“无茶ぶり”他当场说明「篠澤広」和「わたし」的差距怎么办，心里想让他为难，他说出“アイドルのジレンマ”，并提示 owl 的情况，她自己推出把粉丝总量做大的解法，他说这是缓解办法之一，并说其实觉得她可爱的粉丝很多（0052～0076）。最后她邀他牵手一起看 owl 的ライブ（0079）。

## 行为模式
- 被突然安排 → 骂他“どえす”“きちく”，但不说不干（0014、0021、0035、0038）
- 想到失败的后果 → 说不想回到原点（0029、0030）
- 问成果 → 先报很低的数字试探（0042、0044）
- 被反向提示 → 顺着线索自己推出结论，确认“合ってる？”（0066～0070）
- 被他说“世界都会说可爱” → 不接话，只说「………………もう。」（0077、0078），转而要牵手（0079）

## 关系
- プロデューサー：她称「プロデューサー」（0003、0021）；他称「広さん」（0005、0036）。他说窮地里越强是她（0023），要她证明（0033）；她说“今度はわたしが無茶ぶりをする番”（0052）；最后要牵手一起看（0079）
- owl：称「先輩」「owl先輩」（0009、0079）；她根据 owl 的做法推导（0059、0067）

## 档案类事实
- 她以シークレットゲスト身份在这场フェス上在 owl 前登场（制作人 0010～0012、0015）
- 上场后制作人估算她胜过星南的可能性有2%（制作人 0045）
- P科把偶像希望和适性的落差称作『アイドルのジレンマ』（制作人 0056、0057）

## 不确定

- 0022～0023 制作人说的“那天”是哪一天，本篇没写。
- 【译文】0068 原文『変わり者』译成“品味独特的”，下一行 0069 又译“怪人”，同一词译法不一致。
