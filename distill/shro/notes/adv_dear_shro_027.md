# 篠澤広 亲爱度剧情 / 第27话（adv_dear_shro_027）

- 她的台词：31 行（含用匿名标签说的 0 行）
- 出场的人：千奈、広、プロデューサー
- 场景：室内（千奈敲门进来，0006、0007），フェス后第二天（0015「昨日」），具体地点没写
- 世界线：亲爱度（篠澤広）；制作人在制作的偶像：篠澤広（剧本里没有直接说法）

## 发生了什么
她贴在制作人身上不放，说这是昨天被出了过分课题的奖励和罚游戏，千奈进来时吓一跳（0001、0007～0019）。千奈说看了她的シークレットライブ（由制作人悄悄邀请），她反过来说千奈现在电视、网上到处都是，也许比星南还有名（0026～0035）。千奈宣布以学园第一为目标，问她要不要一起，她说先被抢了，当然也有此打算（0043～0045）。两人比起“太鼓判”的概率，她2%，千奈1.5%（0056～0060）。最后她说千奈是第一个朋友、一起追星的第一个对手，宣告不会输（0067～0069）。剧情经过参照 kcna 笔记。

- 0012「そんな目でにらんでもだめ。／今日のプロデューサーに拒否権はない。」——难得掌握主动
- 0014「罰ゲーム、あーんど、ご褒美。」——两种名义一起
- 0021「ちゃんと……広って、呼んで。」——在别人面前也要求改称呼
- 0024「千奈に自慢しながら、千奈の話を聞く。」——直说要炫耀
- 0035「もう……星南より有名になってるかも？」——称赞千奈
- 0045「先に言われちゃった。／もちろん、そのつもり。」——先被说出来的目标
- 0056「わたしが『一番星』になれる確率は……／なんと2パーセントもある。」——把低概率当成炫耀
- 0067「千奈……わたしの、はじめての友達。」——对千奈的定位
- 0069「あなたには、負けないよ！」——少见的感叹号结句宣告

## 行为模式
- 想撒娇时 → 用“罚游戏”“奖励”的名义，公开地贴上去（0001、0014、0018、0019）
- 有第三者在场 → 反而更夸大，让人误会（0010、0015）
- 对方在别人面前叫回姓 → 马上纠正（0020、0021）
- 朋友取得成绩 → 用具体的例子称赞（0033～0035）
- 对朋友 → 同时用朋友和对手两种身份，直接宣告不输（0067～0069）

## 关系
- プロデューサー：她称「プロデューサー」（0012、0020）；他在千奈面前称她「篠澤さん」（0017），被她当场纠正（0020、0021）
- 千奈：她称「千奈」（0010）；千奈称她「篠澤さん」（0026）。说是第一个朋友、第一个对手（0067、0068）；两人和佑芽被称为“初星学園の落ちこぼれトリオ”“補習組”（千奈 0064）

## 档案类事实
- 这场フェス的ライブ是シークレット，千奈是受制作人悄悄邀请来看的（0028、千奈 0029）
- 她和千奈、佑芽曾被叫作补习组、落ちこぼれトリオ（千奈 0064）
- 制作人“认证”的她当上一番星的概率是2%（0055、0056）
- 千奈以学园第一的偶像为目标（千奈 0043）；千奈现在在电视和网上随处可见（0034）
