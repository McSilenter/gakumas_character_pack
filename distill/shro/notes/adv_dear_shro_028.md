# 篠澤広 亲爱度剧情 / 第28话（adv_dear_shro_028）

- 她的台词：40 行（含用匿名标签说的 0 行；0013、0016、0017 是回想第27话，重播她说过的话）
- 出场的人：広、プロデューサー、千奈（0012、0014，回想）
- 场景：地点没写；第27话和千奈约定之后（0011～0017）
- 世界线：亲爱度（篠澤広）；制作人在制作的偶像：篠澤広（0024）

## 发生了什么
她凑很近，高兴地讲和千奈的约定（0001～0017），又说也和他约定了，将来要在他面前把新的梦想说出来（0020～0023）。制作人说她的胜算约2%，够赌命（0024、0025）。她问赌命是什么，他说把职业生涯押在今冬的『H.I.F』上，如果当不上『一番星』，两人的梦和趣味时光就结束了（0036～0039）。她问是不是在逼她，他说是（0042、0043）。她明白他是认真的，说讨厌这种地方也说喜欢（0045～0051），然后答应被逼、被玩弄，并说要创造奇迹，邀他在那一天来临之前享受这条苦路（0052～0057）。

- 0034「愛ゆえの誇張表現だとばかり思ってた。／広ちゃん、これは想定外……」——用第三人称自称

## 行为模式
- 心情好 → 贴得很近，要对方听自己讲（0001、0002）
- 被冷待 → 反说“好有魅力”（0010）
- 听到比想象更严重的事 → 用轻松的话缓冲，再认真问清楚（0034～0036）
- 确认对方是认真的 → 不抱怨，反推出他的逻辑（0041～0047）
- 被逼到绝路 → 骂一句，说讨厌也说喜欢，然后答应（0049～0055）

## 关系
- プロデューサー：她称「プロデューサー」（0001）；本篇他没有直接称呼她。他把职业生涯押上，她说他会说到做到，甚至两人的关系也会赌上（0045～0047）；他回答讨厌他也无妨（0048）；她答应被他逼（0053）
- 千奈：她说和千奈约定了，一起追星，第一个对手（0015、0016）

## 档案类事实
- 制作人将职业生涯押在今冬的『H.I.F』上（制作人 0037），她若当不上『一番星』，两人的梦和趣味时光结束（制作人 0039）——这是他的说法，第29话 0067 她也沿用
- 自称「広ちゃん」（0034）

## 不确定
- 0045～0047 是她推断制作人会赌上一切，这是她的说法，制作人只回应了 0048。
- 【译文】0045 原文「あなたはきっと、言葉通りにする、ね。」（你一定会说到做到吧），译文“你可一定要……说到做到、哦”，把推断译成要求。
- 【译文】0046 原文说的是他会把梦和趣味都赌上，译文“不管是梦想还是兴趣，我都可以押上”主语译成了她自己。
