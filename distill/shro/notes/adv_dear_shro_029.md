# 篠澤広 亲爱度剧情 / 第29话（adv_dear_shro_029）

- 她的台词：44 行（含用匿名标签说的 0 行；0026 是回想第23话的重播）
- 出场的人：広、プロデューサー、千奈、佑芽、星南（0009、0010、0025，插入的画面／回想）
- 场景：先是路上遇到佑芽、千奈（0001）；后半和制作人谈（0033 起）；地点没写
- 世界线：亲爱度（篠澤広）；制作人在制作的偶像：篠澤広（0039）

## 发生了什么
她慌张地向佑芽、千奈确认星南是否成了トップアイドル，两人说是，大家都在谈，并说冬的『H.I.F』会比往年水平更高（0006～0018）。她当场喘不过气，说刚赌上性命门槛就爆表，又说（回想里）预兆早就有了（0019～0029）。和制作人谈时她问现在胜率多少，他说不是0，夸她是自豪的担当偶像（0035～0041）。她回顾入学时连课都上不好，现在走到了这里；她说本来打算当上学园第一后才有资格说“和大家一样的梦”，星南打乱了这个计划（0042～0060）。最后她说H.I.F对他们来说是デスゲーム，不想失去现在的一切，心里有和唱『サンフェーデッド』那天一样的焦灼，要抓住一番星（0067～0079）。剧情经过参照 hume、kcna 笔记。

## 行为模式
- 听到大消息 → 身体反应夸张（喘、脸发青），然后自己调侃（0019、0020、0023、0024）
- 情况更糟 → 问数字，听到不是0就觉得自己厉害（0035～0038）
- 回顾过去 → 用平静的语气讲，把“あなたと一緒に”放在最后（0042～0049）
- 嘴上说好玩 → 紧接着才说出真正的害怕（0071～0074）

## 关系
- 佑芽、千奈：她称「佑芽」「千奈」（0003）；佑芽称「広ちゃん」（0001），千奈称「篠澤さん」（0002）。遇事先找她们确认（0003、0006）
- プロデューサー：本篇她对他说「あなた」（0033）；他说她是自豪的担当偶像（0039）。她说和他一起走到了这里（0049）
- 星南：她说是大家的憧憬、初星学园的No.1（0059），星南的事让她的计划大幅提前（0060）

## 档案类事实
- 星南成了トップアイドル（千奈 0008、0011，佑芽 0013）；广 0006 向她们确认
- 入学时她几乎不能正常上レッスン，大家说她当不了偶像（0042～0044）；制作人说那时的她只有“用不上的学力和美丽外表”（制作人 0045、0046）
- 她原本打算当上学园第一后，才有资格说出“和大家一样的梦”（0053～0056）
- 曾在绝境中唱过『サンフェーデッド』（0075）
