# 篠澤広 亲爱度剧情 / 第34话（adv_dear_shro_034）

- 她的台词：31 行（含用匿名标签说的 0 行）
- 出场的人：広、星南、owl、千奈、香名江、？？？（0050，是 owl，0052 広叫出来；不算她的台词）
- 场景：『H.I.F』本战决战前（0013、0019），地点没写
- 世界线：亲爱度（篠澤広）；制作人在制作的偶像：篠澤広（0006）

## 发生了什么
决战前她和千奈、香名江打招呼，千奈说自己一个人什么也做不了，她说自己一个人更什么都做不了（0006～0011）。星南来向她道谢：给了自己超越极限的提示、N.I.A优胜、和千奈的对バン让H.I.F更热闹（0020、0023、0039～0041）；她说功劳是千奈的，并说千奈是她们这一代的学生会长（0042～0047）。星南说赢的是自己，owl出现说“那可说不定”，owl说来看星南输（0049～0060）。owl说如果広赢了自己会很爽，以憧憬的前辈身份，送上“输了就讨厌你”的激励（0068～0075）。她被激励得可爱又难受，说想起了初心（0076～0079）。剧情经过参照 jsna 笔记。

## 行为模式
- 决战前和对手 → 反而用平时的玩笑（0010），说“也够紧张了”（0015）
- 被道谢 → 反问为什么，把功劳说成别人的（0024、0042）
- 面对owl → 紧张敬语（0054、0072）；对星南和其他人不是这样（星南 0055）
- 被施压 → 明知道也想要，“ぜひ、お願いします”（0072）

## 关系
- 千奈：她称「千奈」（0016）；千奈称她「篠澤さん」（0001）。说千奈有可靠的同伴，是强敌（0007）；说千奈是这一代的学生会长（0047）
- 香名江：香名江称她「篠澤様」，说生徒会选举时承蒙关照，这次是敌人（香名江 0003～0005）
- 星南：她称「星南」（0018）；星南称「広」（0017）。她说星南比以前更自信、更有魅力，有トップアイドル的样子（0033、0034）
- owl：她称「owl先輩」（0052），用敬语；owl称「ひーろちゃん」（0053）。星南指出她对owl和对自己态度不同（星南 0055）
- プロデューサー：本篇未出场；她称他是“素敵なプロデューサー”（0006）

## 档案类事实
- 千奈是她们这一代的学生会长（0047），生徒会选举时千奈让大家都喜欢上她（0044～0046）
- owl 现属100プロ（星南 0059）；去年败给星南（owl 0060）
- 星南说和千奈的对バン（第33话）很精彩（星南 0040）

## 不确定
