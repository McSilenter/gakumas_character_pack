# 篠澤広 亲爱度剧情 / 第35话（adv_dear_shro_035）

- 她的台词：42 行（含用匿名标签说的 0 行；0048～0056、0058～0064 共 16 行无标签，是她念出的老同学来信，写信的是对方，不算她的台词；0057 和 0065 起是她本人的话）
- 出场的人：広、プロデューサー、来信（无标签 16 行）
- 场景：H.I.F前的最后一次ミーティング（0002、0020）；地点没写
- 世界线：亲爱度（篠澤広）；制作人在制作的偶像：篠澤広（剧本里没有直接说法）

## 发生了什么
她说这是最后的ミーティング，又说后来发现制作人其实很享受这段“趣味时间”（0002、0005～0009）。他说无论怎样都赶不上トップアイドル，只能硬赢；她要他告诉她当『一番星』的办法，他说没有，只能稍微提升她的心态（0011～0023）。他拿出原学友的信（0032）。她说大学没什么开心的回忆，没有要好的朋友，因为她的缘故背叛了大家的期待，可能被恨（0037～0039）。信里写信人说当时自己看的视频成了她当偶像的契机，大家一直在秘密观赏会上应援，问能否到会场大声应援（来信 0048～0064）。她答可以，然后对制作人说，自己好像有朋友（0065～0068）。她说更不能输了，说过去的人生确实是武器（0073～0076）。最后她说本打算当上『一番星』后再说的话，他说当上再听（0080、0081）。

- 0044「将来、お嫁さんを困らせちゃう、よ？」——拿他开玩笑

## 行为模式
- 走投无路 → 反而笑，要求开“开心的ミーティング”（0015～0020）
- 要做情绪重的事前 → 先把预期压低，事先说明（0037～0039）
- 念信时读到别人的唠叨 → 用自己的话省略（0057）
- 读完感动的信 → 先回答一个字“いい、よ”，然后才对人说（0065、0067、0068）
- 两人都走投无路时 → 指出对方在笑，说照照镜子（0015）

## 关系
- プロデューサー：她称「プロデューサー」（0001）；他称「広さん」（0004）。她说他在享受（0007、0009）；0025～0027 她说“どうぞ”后喊疼，说不是叫他打（动作未写）；他对她说的话说“当上再听”（0081）
- 大学的同学：她自认没有要好的朋友、被恨（0037～0039）；来信人称她亲爱的朋友，说大家一直在应援（来信 0048、0053）；她读后说自己好像有朋友（0068）。写信人是「元学友」（制作人 0032）

## 档案类事实
- 她说大学时没有开心的回忆，没有要好的朋友（0037、0038）；因自己的缘故背叛了周围的期待（0039）
- 她看到偶像视频的那天，视频是一位同学在平板上看的（来信 0048、0052）
- 她的同学们悄悄看她的ライブ、举办秘密鑑賞会（来信 0053、0056）
- 她的经历到最近还在隐瞒（来信 0060）
- 来信人是偶像粉丝，喜爱 owl（来信 0051 写作フクロウさん，见“不确定”）
