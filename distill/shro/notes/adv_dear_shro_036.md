# 篠澤広 亲爱度剧情 / 第36话（adv_dear_shro_036）

- 她的台词：37 行（含用匿名标签说的 0 行；0041 是她转述第25话 owl 托她带的话，是别人的话）
- 出场的人：広、星南、学園長
- 场景：『H.I.F』的『一番星』授与式（0001、0006），会场（0022）
- 世界线：亲爱度（篠澤広）；制作人在制作的偶像：篠澤広（剧本里没有直接说法）

## 发生了什么
学園長宣布H.I.F优胜者是她，星南说她起了奇迹（0007、0008、0013）。她说直到唱完都没想到会赢，说自己大概是这里最不纯粹的偶像，但最不能输的理由是自己的（0016～0024）；星南说她不是神，是“可愛い悪魔”（0025～0027）。她说星南当初在这里说一番星是背负最多的人，那就是她（0029～0031）。她说第一次见偶像时，这个徽章在星南胸前，憧憬的偶像输给星南还不甘心地祝福；然后在会场上替owl说出“や～い”，星南吼说当然悔（0034～0043）。最后她对大家说自己是历代最弱的一番星，以后也会有不配当偶像的言行，但不道歉，不甘心就来挑战（0053～0062）。剧情经过参照 jsna 笔记。

## 行为模式
- 被认可时 → 先说自己“不纯”“没想过会赢”，但接着说“最不能输的是我”（0016～0024）
- 对最强对手 → 替别人说嘲讽，被吼之后也不让步（0041、0045）
- 站在高处时 → 自我贬低和挑衅一起说（0053～0061）
- 体力极限 → 自己说“げんかいが近い”（0050）

## 关系
- 星南：本篇她对星南用「あなた」（0029、0036）；星南称「広」（0012）。说星南是“歴代最高の『一番星』”（0055）；说一直有话想对她说，然后代 owl 说出（0037、0041）
- 佑芽：她说佑芽已成为真正的偶像（0019）
- owl：本篇未出场，她憧憬的那位偶像（0036），代传话（0041）

## 档案类事实
- 在H.I.F优胜，成了『一番星』（学園長 0007、0008，星南 0033）
- 她自认历代最弱（0053）
