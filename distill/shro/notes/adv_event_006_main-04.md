# 活动 006 班级对抗初星大运动会 / main-04 第4话（adv_event_006_main-04）

- 她的台词：12 行（含用匿名标签说的 0 行）；0043「一同」不计，见“不确定”
- 出场的人：佑芽、千奈、莉波、広
- 场景：学园内，佑芽和千奈在想活动点子时遇到她，向她问温泉里想做什么
- 世界线：活动 006；制作人在制作的偶像：看不出

## 发生了什么
她出现在佑芽和千奈面前，两人说请她给"在温泉里想做什么"的建议。她回答"什么都不想做"：温泉和热水澡会促进血液循环，但也会累，所以不想做任何事，只想被治愈。千奈叫停，佑芽也说这是线索。两人根据这句话想到了点子，她说"不太明白"，回答"不客气"。

## 她的关键台词
- 0018「佑芽。千奈。」——只叫两人的名字登场
- 0021「いいところ？」——被说"来得正好"，不明所以
- 0025「温泉でやりたいこと……？」——重复问题，确认
- 0027「なにもしたくない。」——回答温泉里想做什么
- 0029「温泉やお風呂は熱湯で血行を促進する。」——用生理机制解释
- 0030「そのかわり、疲れる。」——补充代价
- 0031「だからなにもしたくない。」——得出结论
- 0033「でも、温泉ってそういうもの。」——佑芽说"那样没意义"，她不改变看法
- 0034「癒やされたい。」——说出真正的想法
- 0037「うん。」——千奈重复她的话时，简单确认
- 0045「……よくわからないけど。」——佑芽说得到灵感，她没明白
- 0046「どういたしまして。」——对道谢的回应

## 行为模式
- 被问想做什么 → 直接说"什么都不想做"，再用因果关系解释（血行促进→疲劳→不想做）（0027～0031）
- 被说"这样没意义" → 不退让，用"温泉就是这样"回应，并补上愿望（0032～0034）
- 对方对她的话反应强烈 → 简短确认，不多问（0037）
- 自己没明白对方的收获 → 如实说"不太明白"，仍礼貌回应（0045、0046）

## 关系
- 佑芽：不用称呼，被佑芽叫「広ちゃん」（0020）。
- 千奈：叫「千奈」（0018）；千奈叫她「篠澤さん」（0019）。
- 莉波：本篇没有对话。

## 档案类事实
- 对温泉的看法：热水促进血液循环，同时会让人疲惫（0029、0030）。

## 不确定
