# 活动 006 班级对抗初星大运动会 / main-05 第5话（adv_event_006_main-05）

- 她的台词：21 行（含用匿名标签说的 0 行）；其中 0022、0025 是按摩时发出的声音，0027 是昏过去的拟声
- 出场的人：佑芽、広、千奈、莉波
- 场景：千奈家的别墅，活动『初星温泉　～木枯らしに散る～』当天，她是客人
- 世界线：活动 006；制作人在制作的偶像：看不出

## 发生了什么
她作为客人来到活动现场，被千奈迎接，先泡温泉，很快出来，说"在被煮熟之前"。在休息所，佑芽给她按摩，她问能不能先写遗书，被按得发出声音，说佑芽的按摩果然很厉害，然后睡着。醒来吃点心，夸饼干，千奈说是和女仆商量选的。她看到别的学生，问千奈忙不忙，听完说"真努力""来对了"，让千奈很开心。0043 起活动结束的场景里她没有台词。剧情经过参照 hume 笔记。

## 行为模式
- 被带入新场景 → 先低声确认眼前的事实（"这就是……""真的是温泉"），再给感想（0001、0009、0010）
- 对要做的事 → 用夸张的玩笑回应（"先写遗书"），按摩时发出声音，最后失去意识（0021～0027）
- 评价食物 → 用营养成分（糖分、脂肪、盐分）来说"美味"，并关联当时的身体状态（0030、0031）
- 关心别人 → 先观察周围，问"辛苦吗"，听完直接说"在努力"并肯定活动（0034、0037、0038）
