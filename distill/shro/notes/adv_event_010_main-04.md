# shro / 活动 010 星南与燕的日常 / main-04 情人节协奏曲 第4话（adv_event_010_main-04）

- 她的台词：42 行（含用匿名标签说的 0 行）；0034～0043 是她一个人做可可豆巧克力时的自言自语，不是对人说的话
- 出场的人：広（42）、莉波（27）、旁白（0033、0044 时间跳转）
- 场景：学园内外，情人节前；前半讨论买可可豆，后半（翌日）在一处自己做巧克力，莉波来叫醒她（0033～0045）
- 世界线：活动 010；制作人在制作的偶像：看不出

## 发生了什么
她发现去加纳赶不上情人节，改成印尼，被莉波阻止，莉波提议到百货店买可可豆。她请莉波一起去，买回来后因太重，是莉波分担。第二天她独自从洗可可豆开始做，做了四小时，手掌发红，做出的只有一点，口感沙沙的，她判定为失败。她改口请莉波一起做，说想给重要的朋友好吃的巧克力。两人做出成品，她说这次和往常不同，往常做完会空虚，这次觉得开心。

## 行为模式
- 发现自己计划有问题 → 干脆地承认“致命问题”，立刻用另一数据提出替代方案（0001、0002、0004）
- 被现实条件否定 → 简短认同“那是当然”，并回到愿望本身（0008、0010）
- 请人帮忙 → 先说“有个请求”，再具体说明，事后用夸张的话表达感谢（0018、0020、0025、0026）
- 独自做事时 → 边做边对自己说明步骤，同时承认辛苦和乐趣（0035～0043）
- 判断结果 → 冷静给出原因（“力不够”）和结论（“失败”），再改口请求别人合作（0057～0061）
- 达成目标 → 对“不同”产生疑问，并说出以往的空虚感（0068～0071）

## 关系
- 莉波：称“莉波”（0018、0025、0059、0067）；莉波称她“広ちゃん”；信赖她，叫她“命の恩人”（0026）；在放弃单独做时请她帮忙（0059、0060）
- 友达：未点名的“友達”是做巧克力的对象（0011、0061）
