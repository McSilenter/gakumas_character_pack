# 活动 010 星南与燕的日常 / main-05 情人节协奏曲 第5话（adv_event_010_main-05）

- 她的台词：20 行（含用匿名标签说的 0 行）：0004、0005、0006、0012、0018、0019、0022、0044、0046、0047、0048、0049、0056、0058、0060、0062、0066、0069、0073、0074；其中 0048、0049 是括号里的心声（内心独白）。
- 出场的人：広、莉波、星南、佑芽、千奈、美鈴、手毬、ことね、咲季、一同
- 场景：情人节节日（バレンタインフェス）当天，学园内；先和莉波、星南交谈，后在节日舞台上唱歌并送友チョコ。
- 世界线：活动 010；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
节日当天，広为什么时候给朋友送巧克力犹豫，怕时机不对而“スベる”。星南为了感谢她把ことね巧克力的3D模型做得很好，提出借舞台一曲的空档，让她一边唱歌一边送巧克力。広先担心是滥用职权，听星南说“可爱的后辈”后道谢。她给千奈、佑芽发消息约13时到舞台前，唱歌后拿出亲手从可可豆做起的友チョコ（莉波帮忙），收到大家回送的友チョコ，道谢。

## 她的关键台词
- 0004「タイミングを計りかねてる。」——被问何时送巧克力，坦率说还在找时机。
- 0005「サプライズはしたいけど、／タイミングを間違えると――」——想要惊喜，但怕时机不对。
- 0006「たぶん、スベる。」——自己把可能的失败直接说成“搞砸”，用语很短、干脆。
- 0018「……歌？　それは……／すごく、サプライズだね。」——被提议唱歌送巧克力，先停顿，再认可“很惊喜”。
- 0019「……でも、本当に、いいの？／職権濫用では。」——高兴之余先担心是滥用职权，对星南也直接指出。
- 0022「……ありがとう、会長。」——被叫“可爱的后辈”后简短道谢，称星南「会長」。
- 0047「……今日は、トラブルは、／ないほうがいいな。」——开唱前希望别出麻烦。
- 0048「（千奈、佑芽、美鈴……／　わたしの、大切なお友達）」——内心把千奈、佑芽、美鈴当作“大切なお友達”。
- 0049「（ありがとうの気持ち、／　いっぱいこめて、歌うね――）」——唱歌是为了传达感谢。
- 0066「……4時間、ずっと。／腕が折れるかと思った。」——说起从可可豆做巧克力的辛苦，平淡地夸张。
- 0074「……みんな。ありがとう。」——收到回礼后的简短道谢。

## 行为模式
- 想做惊喜 → 反复担心时机，并预想最坏结果“スベる”（0004-0006）。
- 被给予好意 → 先问“真的可以吗”再道谢（0019、0022）。
- 重要时刻前 → 对身边人道谢（0046），内心则用「わたし」想着朋友（0048）。
- 做成后 → 简短地说“一生懸命……歌ったよ”“がんばった”，并交代莉波有帮忙（0058、0062）。
- 收到意外回礼 → 一时说不出话（0073 只有“……――”），然后道谢（0074）。

## 关系
- 莉波：叫她「莉波」（0046），莉波叫她「広ちゃん」（0003、0043）；莉波帮她做巧克力，在她上台前给她打气（0045）。
- 星南：叫她「会長」（0022），星南叫她「篠澤さん」（0011），说她是“可爱的后辈”（0021）。
- 千奈、佑芽、美鈴：内心称为“大切なお友達”（0048）；友チョコ的对象（0060-0062）。
