# 活动 014 学生会1年级的日常 / main-03 第3话（adv_event_014_main-03）

- 她的台词：43 行（含用匿名标签说的 0 行）。其中 0044～0046 是转述佑芽对她说过的话；0048 是引出回忆的话（0049～0053 的佑芽台词属回忆里的对话，见不确定）
- 出场的人：広、美鈴、佑芽
- 场景：运动会前，“第二天”（0001 旁白「～翌日～」），广叫醒美鈴，向美鈴、佑芽、千奈等班里的人说话，具体地点看不出
- 世界线：活动 014；制作人在制作的偶像：看不出

## 发生了什么
広叫醒美鈴，说“这样下去我会死”，然后向大家说：运动会上自己无法做出贡献，到当天也无法达到大家的体力水准，必然会妨碍大家，所以要做自己能做的事：练习live、练习参赛项目、思考打赢1组的办法。她让大家看咲季示范的拉绳动画，请大家放学后一起练习。她对美鈴说明为什么要拜托：她入学时就觉悟过拖累别人的情况，但有了朋友后无法接受拖朋友的后腿；佑芽教她“大家一起痛苦、一起悔恨”。她宣布自己要挣扎到最后，请美鈴也一起，美鈴说不会有干劲，但广的アイアンアイドルレース搭档是自己，会适度练习。剧情经过参照 hmsz、hume 笔记。

## 她的关键台词
- 0004「このままだと死ぬ。わたしが。」——叫醒美鈴时的第一句，用夸张的话让对方清醒
- 0006「ふふ、計算通り。／美鈴にも、起きていてもらいたいから。」——故意说得吓人，是为了让美鈴醒着
- 0012「わたしは、運動会で／活躍することはできない。」——冷静地认定自己无法在运动会上活跃
- 0014「みんなの邪魔をしたくないのに、／邪魔をしちゃう。必ず。」——明白自己必然会妨碍大家
- 0017「わたしは、わたしにできることをする。」——转折：选择做自己能做的事
- 0019「1組に勝つ方法を、考える。」——自己的任务之一，想办法赢1组
- 0022「咲季に頼んで、／お手本を見せてもらった。」——为了班级，拜托咲季做拉绳示范
- 0031「本気を出したらすごい美鈴の説得は、／これからも続ける。」——对美鈴的态度：继续说服
- 0036「しってる。だから、嫌。」——美鈴说不会怪她，她回答“知道，所以才不愿意”
- 0042「友達ができちゃった、から。」——原本打算放弃，但有了朋友
- 0043「友達の足を引っ張るのは……／どうしても無理だった。」——无法接受拖朋友的后腿
- 0060「……そういう佑芽が、大好き。」——对佑芽的严厉说法的回应
- 0062「悔しいって気持ち……／わたしにはよくわからないけど。」——承认不太懂“悔恨”的感觉
- 0064「やる。」——决心

## 行为模式
- 想叫醒别人 → 用夸张的话吓醒对方，再坦白这是有意的（0004、0006）
- 面对自己不擅长的事 → 先冷静地承认做不到，再列出自己能做的事，并找出具体方法（0012～0023）
- 请求别人时 → 直接说“拜托”，反复说愿意为对方做什么（0024、0031、0032、0065、0066）
- 被对方说“不会怪你”→ 回答“知道，所以才不愿意”，理由是不想拖朋友后腿（0035、0036、0043）
- 被佑芽直白地说 → 说她“严厉”，但喜欢（0054、0060）
- 谈到自己不懂的感情 → 直接说“不太懂，也不喜欢，但还是要做”（0062、0063、0064）

## 关系
- 美鈴：叫她「美鈴」（0002、0028）；请她一起练习，感谢她，并要继续说服；知道她“认真起来很厉害”（0031）
- 佑芽：叫她「佑芽」（0044、0054）；0060 说“大好き”
- 千奈：叫「千奈」（0008），一次点名
- 咲季：0022 说拜托咲季示范

## 档案类事实
- 広入学初星学园时，已经预料到自己的兴趣会拖别人后腿（0038、0039）
- 広觉得“友好”之前，打算在那种场合放弃（0040）
- 广对“悔恨”的感觉不太懂（0062）
- 咲季示范了拉绳的合理姿势，被拍成了视频（0021、0022）
