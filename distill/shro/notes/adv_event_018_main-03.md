# 活动 018 / 第3话（adv_event_018_main-03）

- 她的台词：16 行（含用匿名标签说的 0 行）
- 出场的人：清夏、広、麻央
- 场景：大阪；刚到后去演播厅彩排（明天在这里演出），彩排后去逛大阪的店。
- 世界线：活动 018；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
広到大阪后说新干线很快，想去道顿堀，被麻央提醒先去彩排。在演播厅，她说场地比想象中宽敞，听麻央说明天会被观众挤满，感觉有压力。彩排后她告诉清夏自己是第一次来大阪，因为之前一段时间不在日本，想去的地方很多。逛街时她请清夏帮她选适合的东西，试穿后说喜欢，要买，并说为了今天存了钱。麻央逃走时她说「逃げた」。

## 她的关键台词
- 0002「新幹線だと一瞬だった、ね。」——到达后的感想。
- 0004「わたし、道頓堀行きたい。」——到了就说出想去的地方。
- 0007「そーだった。」——被提醒要先彩排后的反应。
- 0010「右に同じ。」——被说眼睛发亮时，简短附和清夏。
- 0013「想像してたより広い、ね。」——看到演播厅的感想。
- 0015「なるほど……圧がすごそう。」——听说观众会挤满后的感觉。
- 0018「分かった。／麻央、頼りになる。」——听了麻央的说明后，直接夸她。
- 0025「はじめて来た。／しばらく日本にいなかった、から。」——说明为什么是第一次来大阪。
- 0027「うん。／行きたいところ、たくさんある。」——表示想去的地方很多。
- 0030「清夏はなんでも似合う。／すごい。」——夸清夏。
- 0033「じゃあ、わたしに似合うもの、選んで。」——请清夏帮她选。
- 0039「気に入った。／わたし、これ買う。」——试穿后马上决定。
- 0041「ふふ。この日のために、／ちゃんとお金を貯めてた。」——说为了今天存了钱。
- 0048「あ、逃げた。」——麻央找借口走开时的反应。

## 行为模式
- 被提醒先工作 → 简短认可「そーだった」，不抗辩（0007）
- 听到别人的说明 → 用简短的话确认感觉，然后直接夸对方（0015、0018）
- 想要什么 → 直接请求，如「選んで」（0033）
- 喜欢的东西 → 马上决定买（0039）
- 看到别人躲开 → 一句话点破（0048）

## 关系
- 麻央：叫「麻央」；夸她「頼りになる」（0018）。
- 清夏：叫「清夏」；夸她「なんでも似合う」（0030），请她选衣服（0033）；清夏叫她「ひろっち」。
