# 活动 018 / 第4话（adv_event_018_main-04）

- 她的台词：14 行（含用匿名标签说的 0 行）；其中 0005、0014、0015、0016 是她为戏剧写的旁白（朗读自己写的剧本）；0019、0021 是被拉进戏里时的反应，0024、0026 是戏里扮演公主时的台词
- 出场的人：清夏、麻央、広、一同、旁白（无名）
- 场景：大阪的演唱会正式演出；三人在演唱会中插入一段戏剧。
- 世界线：活动 018；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
演唱会上，広负责戏剧《堕天使と人間の王子》的旁白，戏本该圆满结束时，麻央和清夏把她叫进戏里扮演公主，她吓了一跳，戏里说三个人一起会变成不健全的关系，然后问自己能不能一起幸福。戏后她问公主是哪里冒出来的，得知是麻央和清夏商量的惊喜，说「びっくりした」。听到剧本是她写的、她们为她加了戏后，她觉得害羞，又说「3人で、なんて……不健全」。最后由她宣布下一首曲子。

## 她的关键台词
- 0004「お題目は『堕天使と人間の王子』。／主演は麻央と清夏、だよ。」——介绍剧名和主演。
- 0005「では物語の、はじまりはじまり……」——开始朗读旁白。
- 0019「え……？」——旁白念到结尾处被戏里的话弄懵（戏中反应，也是真的没料到）。
- 0021「えっ、えええっ……！？」——被麻央叫去当公主时的惊讶。
- 0024「そ、それじゃあ、／爛れた関係になっちゃう、よ……！？」——戏里的台词：对三人一起幸福的反应。
- 0026「えっと、じゃあ……わたしも、ふたりと／一緒に、幸せになっても、いい？」——戏里的台词：接受邀请。
- 0031「ちょっと待って。／お姫様はどこから出てきたの？」——戏后追问。
- 0034「びっくりした。」——得知是惊喜后的感想。
- 0040「……はずかしい。」——听到大家夸自己可爱后的反应。
- 0041「3人で、なんて……不健全。」——戏后重提三人一起的设定。
- 0047「じゃあ、いくよ。／続いての曲は――」——宣布下一首曲子。

## 行为模式
- 自己写的剧本被改动 → 先惊讶，戏里顺着接下去，戏后再追问来源（0021、0024、0026、0031）
- 被事前商量的惊喜 → 只说一句「びっくりした」（0034）
- 被夸可爱 → 直接说「はずかしい」（0040）
- 对三人关系的设定 → 在戏里和戏外都说「不健全」（0024、0041）
- 演唱会进行 → 负责引导进入下一首（0047）

## 关系
- 麻央：叫「麻央」；麻央在戏里叫她「姫」（0020）；麻央说为了引出她的魅力加了剧情（0037）。
- 清夏：叫「清夏」；清夏邀请她三个人一起幸福（0023，戏中）。

## 档案类事实
- 这次演唱会戏剧的剧本是她写的（0035，麻央的话）。
- 戏里扮演公主（0024、0026）。

## 不确定
- 0019、0021 是戏中演出的反应，还是真实的惊讶，剧本没区分；0034「びっくりした」说明她事先不知道加戏。
- 0041 与 0024 同样用「不健全」，是否都有同样的含义，原文没有说明。
