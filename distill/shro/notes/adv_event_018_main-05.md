# 活动 018 / 第5话（adv_event_018_main-05）

- 她的台词：25 行（含用匿名标签说的 0 行）
- 出场的人：清夏、広、麻央、一同
- 场景：大阪演唱会结束后，三人在麻央推荐的章鱼烧店庆功；麻央睡着后，広和清夏继续聊。
- 世界线：活动 018；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
演唱会成功后，広提议用章鱼烧干杯，让麻央带头。她说麻央和清夏是自己的王子，感谢两人。之后她对她们说其实自己已经大学毕业，说因为她们说了自己的事，所以也想说，并说她一开始就知道清夏是芭蕾舞者、麻央是童星，觉得彼此相似，这是她找她们说话的真正理由；还问是不是在鄙视她。麻央睡着后，她问清夏是不是躲着自己，清夏承认；她说一直想和清夏说话，喜欢清夏的时尚，也想试试辣妹，清夏答应。

## 她的关键台词
- 0001「たこ焼きで乾杯しよう。／麻央、音頭取って。」——提议并指名麻央带头。
- 0009「わたしも、一口で食べればよかった。」——看到清夏烫到后的感想。
- 0017「……ふたりに感謝しても／しきれないのは、わたしの方。」——麻央说完感谢后，说自己才更应该感谢。
- 0018「演劇、楽しかった。／麻央と清夏は、わたしの王子様だった。」——对戏剧的感想。
- 0031「わたし、実は大卒。」——突然坦白。
- 0034「今からわたしの話をする。／ふたりにも、聞いてほしい。」——说明接下来要讲自己的事。
- 0036「ふたりが自分のこと教えてくれたから、／わたしも少し話したくなった。」——说明为什么想说。
- 0037「それに、清夏がバレリーナだったこと、／実は最初から知ってた。」——说自己早就知道清夏的经历。
- 0041「わたしたち、似てると思った。」——说明接近两人的原因。
- 0043「……軽蔑した？」——坦白后担心被鄙视。
- 0046「友達の友達、だったよね。」——说与二人的最初关系。
- 0053「麻央は、すごい。」——麻央睡着后的评价。
- 0059「もしかして、わたしのこと、避けてた？」——直接问清夏。
- 0064「じゃあ、わたしの片思いだったんだね。／よよよ……」——被承认躲着后，半开玩笑地说是单相思。
- 0066「わたしはずっと清夏と話したかった。」——说出自己的愿望。
- 0068「清夏のファッション、好き。／わたしもギャル、やってみたい。」——说喜欢清夏的穿搭，想当辣妹。
- 0069「ギャルも、わたしに向いてなさそう。」——接着自己否定。

## 行为模式
- 想庆祝 → 直接提议并指名（0001）
- 对别人说感谢 → 直接说感谢，并说明具体是「王子」（0017、0018）
- 说自己的事 → 先宣告现在要讲自己的事，说明理由，再说结论（0031～0042）
- 说完秘密 → 马上担心「軽蔑した？」（0043）
- 想确认心里的疑问 → 直接问「避けてた？」，被确认后用玩笑回应（0059、0064）
- 提出想做的事 → 说了又自己否定「向いてなさそう」（0068、0069）

## 关系
- 麻央：叫「麻央」；说她是「わたしの王子様」（0018）；睡着后夸她「すごい」（0053）；麻央说理解她接近的理由（0044）。
- 清夏：叫「清夏」；一直想和她说话（0066）；喜欢她的穿搭（0068）；清夏叫她「ひろっち」。

## 档案类事实
- 已经大学毕业（0031，原文「実は大卒」）。
- 一开始就知道清夏曾是芭蕾舞者、麻央曾是子役（0037、0039）。
- 认为自己与她们相似，是向她们搭话的真正理由（0041、0042）。
- 喜欢清夏的时尚，想试试辣妹（0068）。
- 与麻央、清夏最初是「友達の友達」（0046）。

- 0046 的「友達の友達」是谁与谁的朋友，原文没有说明。
