# 活动 023 / main-02 第2话（adv_event_023_main-02）

- 她的台词：29 行（含用匿名标签说的 0 行）：0001、0002、0004、0007、0010、0012、0015、0017、0018、0020、0023、0024、0025、0027、0029、0031、0033、0037、0039、0041、0042、0050、0051、0054、0056、0058、0059、0061、0062（0001、0002 是她用旁白口吻说自己和手毬；0031 是在说想象中的美鈴的反应）
- 出场的人：広、手毬；想像上の美鈴（0032）；美鈴（0045～0048，手毬想象中的台词）

## 发生了什么
放学后広陪手毬在购物中心为美鈴挑生日礼物。広依次提议服装店（自己常去）、漫画（班上流行，佑芽在推荐）、抓娃娃机、大头贴，手毬都没有决定，只答应拍一次大头贴。休息时広让手毬回想美鈴什么时候开心，手毬想象美鈴的话后说出“礼物是我”的玩笑，広说一半是玩笑。広决定明天自己去问美鈴的想法。剧情经过参照 ttmr 笔记。

## 她的关键台词
- 0001「――放課後。」——自己用旁白口吻开场，手毬立刻吐槽
- 0004「手毬とわたしの新章、はじまるのに？」——被吐槽后的回答，把今天看作两人关系的新章节
- 0012「服はどう？／あそこのお店、わたしの行きつけ。」——提议送衣服，并说那家是自己常去的店
- 0017「うん、うちのクラスで流行ってる。」——提议送漫画的理由：班上流行
- 0020「佑芽がみんなにオススメしてる。」——说出班上漫画热的来源
- 0024「手毬も一緒に、お喋りしよう。／いつでも2組に来て、ね。」——邀请手毬加入自己班的聊天
- 0031「わたしと手毬のツーショットプリ。／きっと美鈴は……」——提议把两人的大头贴当礼物，并预想美鈴的反应
- 0041「候補を、絞らないと、厳しい。」——冷静指出范围太大
- 0042「考えてみよう。／美鈴が、どういうとき喜ぶか。」——把问题换成美鈴何时开心
- 0051「プレゼントは、手毬？」——看完手毬的想象后得出的玩笑结论
- 0054「ふふ……はんぶん、冗談。」——被追问后承认只有一半是玩笑
- 0056「明日、美鈴からも、話を聞きたい。」——决定去听美鈴本人的想法
- 0059「誘導尋問。」——说明自己打算的做法
- 0062「えーじぇんと・広、におまかせ、あれ。」——用「特工」自称接下任务

## 行为模式
- 手毬抗拒节奏时 → 继续按自己的路线提新点子（服装→漫画→游戏厅→大头贴）（0007、0012、0015、0025、0029）
- 手毬否定提议时 → 不坚持，转到下一个点子；仍保留一次大头贴（0034 后的 0037）
- 事情卡住时 → 提出缩小范围、换个角度想（0041、0042）
- 对任务 → 用「すぱい活動」「えーじぇんと・広」这类自创说法把它游戏化，同时认真去做（0061、0062）
