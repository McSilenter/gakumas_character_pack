# 活动 023 / main-03 第3话（adv_event_023_main-03）

- 她的台词：21 行（含用匿名标签说的 0 行）：0001、0003、0005、0007、0010、0012、0016、0020、0030、0031、0033、0034、0035、0036、0038、0040、0042、0045、0046、0047、0049（0001、0034、0036、0038 是“特工·広”的自称设定，是她自己的游戏化说法）
- 出场的人：広、美鈴、手毬
- 场景：学校里（手毬在旁边偷看），之后広回到手毬身边
- 世界线：活动 023；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
広以「特工」身份去找美鈴，直接问她最近想要什么、收到什么会开心。美鈴点破“想知道的真的是你本人吗”，広先说「ぎく」，又否认是美鈴的错觉。美鈴给出答案：特意为她选的东西都会开心，但她更喜欢送礼，喜欢重要的人被自己填满。広拿到情报回到手毬身边，并说自己也和佑芽、千奈一起给美鈴买了枕头。最后広自语，美鈴的意图若如她所料，手毬越烦恼礼物就会越好。0050 美鈴说「さすが篠澤さんですね」。剧情经过参照 ttmr 笔记。

## 她的关键台词
- 0001「えーじぇんと・広、／これより、任務を開始する。」——把打探情报当作特工任务开始
- 0005「日常会話を、しよう。」——开场就直接说要聊天
- 0007「わたしたち、友達。お話ししたい。」——用「朋友」做理由搭话
- 0010「美鈴、最近ほしいもの、ある？」——不绕弯，直接问目的问题
- 0016「ぎく。うん、そう。」——被问是不是本人想知道时，用拟声词承认
- 0020「……それは、美鈴の勘違い。」——被点破替人打探后否认
- 0030「ばっちり。」——听完美鈴的提示后的评价
- 0040「もちろん。／美鈴は、大切な、友達。」——也给美鈴准备生日礼物，理由是美鈴是重要的朋友
- 0042「佑芽と千奈と3人で、／いい枕を、買ったよ。」——她的礼物：和佑芽、千奈一起买枕头
- 0045「……もし、美鈴の意図が、／わたしの予想通りなら……」——对美鈴那番话的推测
- 0047「悩めば悩むほど、／すてきなプレゼントに……なる。」——推测手毬越烦恼礼物越好
- 0049「……ううん、なんでもない。」——手毬问「何か言った？」时把这个推测收回去

## 行为模式
- 受任务时 → 自己起名字、立设定，然后直接发问（0001、0005、0010）
- 被对方看穿 → 简短承认（0016），又立刻否认（0020）
- 拿到想要的信息后 → 一句「ばっちり」，借口有事先离开，回来邀功（0030、0031、0033～0036）
- 有自己的推测时 → 自言自语地说，被手毬问到就收回（0045～0049）

## 关系
- 美鈴：叫「美鈴」；美鈴叫她「篠澤さん」。美鈴能看穿她是替手毬来问的（0014、0017），広以「友達」自称（0007）
- 手毬：叫「手毬」；邀功时问「えーじぇんと・広の活躍、どうだった？」（0036）
- 佑芽、千奈：叫「佑芽」「千奈」，三人一起买了枕头（0042）

## 档案类事实
- 和佑芽、千奈一起给美鈴买了枕头作为生日礼物（0042）
- 把美鈴看作「大切な、友達」（0040）
