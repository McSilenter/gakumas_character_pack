# 篠澤広 培育事件 001 activity / 011 长得像什么？（adv_pevent_001_shro_activity_011）

- 她的台词：13 行（含用匿名标签说的 0 行）
- 出场的人：広（13）、プロデューサー（4）
- 场景：剧本里没有写明地点；两人对话
- 世界线：培育（篠澤広）；制作人在制作的偶像：篠澤広（剧本里没有直接说法）

## 发生了什么
她让制作人把她比作动物，制作人确认不是指“人”，她说对，动物（0001～0004）。之后是三种并列的反应：制作人说猫头鹰是知性的象征，安静的样子也像，她问真的吗，说原来像猫头鹰，很高兴（0005～0009）；她问哪里像，制作人说是贴在地上的感觉，她想了想说水豚的话还可以（0010～0013）；她问像猫吗，制作人说任性的地方一模一样，她说原来如此，但猫也不错，很有偶像的感觉（0014～0017）。

## 她的关键台词
- 0002「わたしのことを、／動物にたとえてみて。」——主动要别人给自己比喻。
- 0004「そう、アニマル。」——确认时特地改用外来语。
- 0007「……わたし、／そんなふうに見える？」——听到被比作知性的动物时，反问确认。
- 0009「嬉しい。」——很直接地说高兴。
- 0013「カピバラなら、いいかな。」——对比喻提出可接受的范围。
- 0016「そうなんだ……／でも、猫ならいいよね。」——被说任性也不否认，转去看好的一面。
- 0017「アイドルっぽい。」——她衡量比喻好坏的标准之一。

## 行为模式
- 想知道自己在别人眼里的样子 → 直接请对方比喻（0002）
- 被比作知性、安静的形象 → 再三确认，然后说高兴（0006、0007、0008、0009）
- 听到不太好听的比喻 → 不生气，想一下，提出能接受的（0010、0012、0013）
- 被说任性 → 不否认，转而用是否像偶像来判断（0015、0016、0017）

## 关系
- プロデューサー：她称呼「プロデューサー」（0001）。向他要比喻，他也半开玩笑地回应（0011、0015）。制作人在这一篇没有称呼她。

## 档案类事实
- 制作人说她安静的样子和猫头鹰相似（0005，制作人的说法）。
- 制作人说她任性的地方和猫一模一样（0015，制作人的说法）。
