# 篠澤広 培育事件 001 school / 009 特别的歌唱方法（adv_pevent_001_shro_school_009）

- 她的台词：9 行（含用匿名标签说的 0 行）
- 出场的人：あさり先生（12）、広（9）
- 场景：あさり先生讲解出题的场合，地点剧本里没有写明
- 世界线：培育（篠澤広）；制作人在制作的偶像：篠澤広（剧本里没有直接说法）

## 发生了什么
あさり先生问同时发高低音的蒙古传统歌唱法叫什么（0001～0003）。她说理论上可能，问制作人知不知道名字（0004、0005）。之后是三种并列的反应：答对（ホーミー），先生讲解，她说听了也想象不出来，让制作人试试（0006～0011）；答约德尔，她先说是那种“ヨロレイヒー”，先生说答案是ホーミー，她笑说自己更了解，但承认不知道ホーミー（0012～0016）；答错，先生说サミング是戳眼睛，是不是想说ハミング，她沉默后问制作人是说错了吧（0017～0021）。

## 她的关键台词
- 0004「高い音と低い音を同時に……／論理的には可能。」——先判断理论可行性。
- 0005「歌唱法の名前……／プロデューサーは、知ってる？」——把回答转给制作人。
- 0010「説明を聞いても／イメージできない。」——说明也不够，想看实物。
- 0011「プロデューサー、／ためしにやってみて？」——让制作人当场试。
- 0015「ふふ。／わたしの方が、詳しかったね。」——拿自己比制作人更清楚来笑。
- 0016「ホーミーは知らなかったけど。」——马上补一句老实话。
- 0021「言い間違いだよね、／プロデューサー？」——替制作人的离谱回答圆场，同时点破。

## 行为模式
- 听到题目 → 先判断逻辑上可不可能（0004）
- 不知道名字 → 问制作人（0005）
- 说明听不懂 → 让对方当场示范（0010、0011）
- 占了一点上风 → 笑，又马上老实补充（0015、0016）
- 制作人答得离谱 → 沉默后问是不是说错（0019、0020、0021）

## 关系
- プロデューサー：她称呼「プロデューサー」（0005、0011、0021）。让他答题、示范，并拿他开玩笑。这一话他没有台词。
- あさり先生：她这一话没有称呼先生，先生也没有称呼她。
