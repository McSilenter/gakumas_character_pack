# P卡 葛城リーリヤ【怦然心动】 / 第2话 怦然心动 第2话（adv_cidol-kllj-3-017_02）

- 她的台词：15 行（含用匿名标签说的 0 行）
- 出场的人：リーリヤ（28 行）、プロデューサー（21）、清夏（15）、一同（1）
- 场景：看不出具体地点；前半制作人给リーリヤ看组合服装设计（清夏不在场），后半两人试穿服装、看新曲歌词（0021 起）
- 世界线：亲爱度（葛城リーリヤ）·P卡；制作人在制作的偶像：葛城リーリヤ（リーリヤ称制作人「センパイ」，0042；她和リーリヤ组成组合，0004）

## 发生了什么
制作人先给リーリヤ看她和清夏的组合服装设计（白和黑），并请リーリヤ为清夏的黑色服装出主意，リーリヤ提议露腰、显腿、加发箍和腰带链。之后两人试穿，清夏说没问题并向制作人道谢。得知リーリヤ给她的服装提过意见，清夏说很喜欢、品味超好，还猜中腰带链和发箍是リーリヤ的主意，理由是觉得リーリヤ会喜欢这种；制作人夸她厉害，她说论リーリヤ的事不会输。她催リーリヤ说感想，得到“很适合”后也夸リーリヤ超适合。制作人拿出新曲歌词，清夏说之前自己也被问过リーリヤ的魅力和缺点；看了歌词她说没问题，但和リーリヤ一样觉得很害羞，担心能否不害羞地唱出来。

## 行为模式
- 收到别人的心意 → 先热情肯定（“めちゃくちゃ良いセンス”），再猜出细节是对方的喜好（0028～0033）
- 被夸了解朋友 → 得意地宣称“这方面不会输”（0035）
- 想听朋友评价自己 → 用“～んだけど～？”半开玩笑地讨（0038）
- 被夸 → “へへっ”道谢后马上回夸对方（0040）
- 遇到让人难为情的东西 → 说“没问题”但语尾含糊，和朋友一起承认害羞（0059、0062、0065）

## 关系
- リーリヤ：叫「リーリヤ」（0030、0035、0040）；リーリヤ叫她「清夏ちゃん」（0039）。两人组成组合，衣装黑白成对；她自认最懂リーリヤ（0033、0035）
- リーリヤ的制作人：叫「プロデューサーさん」（0024）；制作人叫她「紫雲さん」（0034）。和制作人比谁更了解リーリヤ（0035、0036）；之前被制作人问过リーリヤ的魅力和缺点（0053）

## 档案类事实
- 和リーリヤ组成组合，她的服装是黑色的（0004、0007、0010）
- 她的服装有腰带链、发箍，是リーリヤ出的主意（0018、0019、0030～0032）
- 新曲歌词是请作词家写两人对彼此的心情，她被制作人问过リーリヤ的魅力和缺点（0053、0056）
