# P卡 紫雲清夏【Tame-Lie-One-Step】 / 第2话 Tame-Lie-One-Step 第2话（adv_cidol-ssmk-3-000_02）

- 她的台词：23 行（含用匿名标签说的 0 行；0001、0002、0025 是唱歌词，不当成她本人的话）
- 出场的人：清夏、プロデューサー
- 场景：地点看不出；她在练唱，制作人在旁边听（0001～0005、0024）
- 世界线：亲爱度（紫雲清夏）·P卡；制作人在制作的偶像：紫雲清夏（剧本里没有直接说法）

## 发生了什么
清夏试唱后觉得不对，想是不是因为自己是偶像，就该唱得更明亮有活力（0004～0008）。制作人问她想怎么传达这首歌，她说这首歌是带着不安等种种心情，仍想克服并往前走，希望这种心情能传给听的人（0009～0013）。制作人说希望它成为推那些有同样烦恼的人一把的歌，并相信她能做到（0014～0019）。她接受这份期待，边练边想，抓到感觉后唱给制作人听；制作人心里觉得这种唱法有她特有的明亮和温柔（0020～0027），当面则说它从被唱的歌变成了她的歌（0030）。之后制作人指出编舞还没记住，她承认光顾着唱法，答应正式演出前猛练（0034～0040）。

## 她的关键台词
- 0004「うーん……なんか違うかなぁ。」——对自己的试唱不满意，能察觉不对劲
- 0008「だって、アイドルだし。／元気な歌い方のほうが良くない？」——最初的想法：偶像就该唱得有活力（之后被制作人的问题打开，不是她的结论）
- 0012「んー……不安とか、いろいろあるけど、／乗り越えて前に進もう、みたいな？」——她对这首歌的理解
- 0013「そーゆー気持ちが、聞いてくれた人に／伝わったらいいよね。」——想传达的是心情，而不只是明亮
- 0018「背中を、押す……／あたしが、ってことだよね？」——对“由自己去推别人一把”感到意外，确认一遍
- 0020「へへっ、Pっちの期待なら、／応えてあげないとね♪」——用轻松口吻接下期待
- 0021「悩んでても仕方ないし、／もうちょっと練習しながら考える！」——不停在烦恼里，靠动起来想
- 0033「いえーい♪／あたしってやっぱ天才かも！」——被夸后马上得意
- 0035「うっ……あはは……／歌い方に熱中しちゃっててさ～。」——被指出疏漏时苦笑承认
- 0041「Pっちもちゃんと見ててね♪」——要制作人看着自己

## 行为模式
- 表现方向拿不准 → 先按“偶像应该这样”的常识推，被问到自己想传达什么才说出真实理解（0006、0008、0012、0013）
- 烦恼时 → 不坐着想，选择边练边想（0021）
- 被期待 → 用「応えてあげないとね」这种轻松的说法接受（0020）
- 被夸 → 直接得意（0031、0033）；被指出没做好 → 苦笑解释后马上保证补上（0035、0040）

## 关系
- プロデューサー：叫他「Pっち」（0020、0041）；制作人叫她「清夏さん」（0009、0019）。愿意听他的引导，把他的期待当作动力（0020），并要他好好看着（0041）。

## 档案类事实
- 这首曲子的编舞她一度还没记住，因为专注在唱法上（0034、0035）。
- 她对这首曲子的理解：有不安等种种心情，但想克服、前进（0012）。
- 演出里要让观众也一起跳，这是她的打算；制作人说要把舞做到观众会自然想模仿（0037、0039）。

## 不确定
- 0016 制作人说「清夏さんがそうだったように」，指她也对歌词有共鸣，这是制作人的说法；她本人在这一话没有再说自己有什么烦恼。
- 0001、0002、0025 的歌词（デコルテ、未完成、亡霊、ためらい　One step）是否反映她本人的心情，这一话没有说明，只作歌词看。
- 0030 制作人的「歌わされていた曲」是他对前后变化的评价，她之前是否有被迫唱的感觉，她本人没说。
