# P卡 紫雲清夏【隐藏的我】 / 第3话 隐藏的我 第3话（adv_cidol-ssmk-3-002_03）

- 她的台词：22 行（含用匿名标签说的 0 行；0027、0028 是录音时唱的词，0029 是录音最后的话，都不当成她平时的发言）
- 出场的人：清夏、プロデューサー
- 场景：地点看不出；前半改好歌词后听曲（0001～0026），后半是录音（0030）
- 世界线：亲爱度（紫雲清夏）·P卡；制作人在制作的偶像：紫雲清夏（剧本里没有直接说法）

## 发生了什么
制作人把她的意见反映进歌词，她不安地问自己是不是太多嘴，说相当一部分词是她写的；制作人说作词家也很开心（0001～0007）。听过之后她很喜欢，说是发自内心想唱（0011、0012）。制作人说这首曲子能让粉丝更想了解她，但她不等他说完就接上：在粉丝面前继续说谎，对吧（0016～0020）。她把他的话归纳成“要拿出色気”，他说好，并说她一定能成为色気满满的偶像，她却说这说法有点讨厌（0022～0026）。录音时她在最后加了一段即兴，问制作人怎么想，他说非常好，她说这是自己竭尽全力的逞强，这样才像自己；随后得知要因歌词改动重录，大叫不要（0027～0041）。

- 0005「歌詞に、いろいろ言っちゃったし……／なんなら結構あたしが書いてるし……」——她对歌词的参与程度
- 0011「う、うわ～、ヤバい！／すっごく好きな曲になったんだけど！」——听完的直接反应

- 0018「ファンの前では、嘘をつき続ける。／……そうだよね？」——自己说出方针，向制作人确认
- 0022「要はさ、色気を出せってことだよね。」——用自己的话归纳难懂的道理
- 0026「……なんか嫌なんだけどその表現。」——对他直白的话的吐槽
- 0028「いつか本当の「私」を　ねえ――」——录音时的词（不是她平时的发言）
- 0034「じゃあきっと、これで良いんだよ。／あたしの、精一杯の強がり。」——她对最后加的部分的解释
- 0035「その方が、あたしらしいっしょ？」——逞强是她自认的样子
- 0041「そ、そんなぁ～！？」——严肃场面后的落差

## 行为模式
- 在创作上提了很多意见 → 事后担心自己是否越界，要别人说没关系才放心（0004～0007）
- 听到难懂的话 → 用自己的话简化（0015、0021、0022）
- 对方接着自己的话说得太直白 → 马上吐槽（0025、0026）
- 自己的真心被放进作品 → 在最后加一层掩饰，并称之为「精一杯の強がり」（0029、0034）

## 关系
- プロデューサー：叫「Pっち」（0021、0032）；制作人叫她「清夏さん」（0001、0038）。把最后的即兴好不好交给他判断（0032、0034），也会被他一句话打发去重录（0040、0041）。

## 档案类事实
- 她对这首曲子的歌词提了不少意见，还说相当一部分是她写的（0005）。
- 在粉丝面前，她仍继续做最强的偶像（0018～0020，制作人要求，她先说出）。
