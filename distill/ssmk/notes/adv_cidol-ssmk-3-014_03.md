# P卡 紫雲清夏【奇迹正是现在(ﾟ∀ﾟ)！】 / 第3话 奇迹正是现在(ﾟ∀ﾟ)！ 第3话（adv_cidol-ssmk-3-014_03）

- 她的台词：32 行（含用匿名标签说的 0 行；括号里的心里话是 0020、0037、0040、0042、0044～0046）
- 出场的人：プロデューサー、清夏
- 场景：大阪演出结束后（0001、0031）
- 世界线：亲爱度（紫雲清夏）·P卡；制作人在制作的偶像：紫雲清夏（剧本里没有直接说法）

## 发生了什么
演出成功，MC 也很热烈，她说可能是看搞笑的效果；得知他带她去是为了解除紧张，她说自己确实害怕在陌生的地方演出，并领悟他带她到处走是为了让大阪成为熟悉的地方（0001～0011）。他含糊其辞，又说也许只是想一起玩，接着说「俺、清夏さんのこと――」，她心里慌乱地以为要告白；他说的其实是“很有逗弄的价值”，她没反应过来先说不行，才大叫（0014～0023）。她气到不理他，他反省的样子又被她反过来逗（0024～0029）。之后酒店预约被取消，只剩一间房，她心里慌，嘴上说同屋也行，又说别袭击她，心里连连骂自己（0033～0046）。结果他另外为她订到学园合作企业的酒店，自己去那间房；她失落地说他真能干，并说这不是夸奖（0049～0057）。

## 行为模式
- 事情办成后 → 回头去理解他的用意（0007～0011）
- 被当面说亲近的话 → 慌张（0015、0016、0020、0022）
- 被捉弄 → 不理人（0024、0026），等对方反省时又反过来捉弄（0028、0029）
- 心里慌 → 嘴上反而挑衅，心里马上自责（0039～0042）
- 期待落空 → 说话变得客气、干巴（0053、0055、0057）

## 关系
- プロデューサー：叫「Pっち」（0002、0039）；制作人叫她「清夏さん」（0001）。她说他带她到处走是为了消除陌生感（0010、0011）；他捉弄她时反应很大（0020～0024）。

## 档案类事实
- 她说害怕在陌生的地方演出（0008）。
