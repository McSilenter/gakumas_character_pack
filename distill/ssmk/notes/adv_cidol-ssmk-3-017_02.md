# P卡 紫雲清夏【怦然心动】 / 第2话 怦然心动 第2话（adv_cidol-ssmk-3-017_02）

- 她的台词：31 行（含用匿名标签说的 0 行）
- 出场的人：清夏、プロデューサー、リーリヤ、一同
- 场景：地点看不出；前半她找制作人商量新曲编舞（0001～0023），后半两人和制作人的练习（0024 起）
- 世界线：亲爱度（紫雲清夏）·P卡；制作人在制作的偶像：紫雲清夏（0005、0039 等处制作人在指导两人的组合；这一话没有更直接的说法）

## 发生了什么
她找制作人商量，说新曲的编舞很好，但有个小小的任性：想在最后和リーリヤ两人举起ペンライト（0001～0012）。她给他看自己的 SNS，说定下约定那天两人举着ペンライト拍了这张照片，想用同样的姿势结尾（0014～0017）。他同意，并说知道两人关系的粉丝会高兴，她很开心地说要传达给大家（0020～0023）。练习时她说合作和单人是另一种技术，对リーリヤ说交给自己支援；她告诉大家最后的动作是她想的，リーリヤ说早就知道（0029～0037）。之后リーリヤ沉默，她担心地问怎么了，リーリヤ说举ペンライト时差点哭出来，她说自己可能也会跟着哭（0041～0048）。制作人说不要因太在意不哭而放不进感情，她道谢，说他总是贴近两人的心情，还笑他害羞，说要为他努力（0051～0062）。剧情经过参照 kllj 笔记。

## 行为模式
- 想提自己的要求 → 先说好的部分，再用“只是我的任性”做铺垫，被鼓励后才说（0005～0012）
- 朋友在练习中有困难 → 主动说“交给我”（0029～0031）
- 朋友沉默 → 马上问，并担心是不是自己的编舞不好（0042、0043）
- 被他的话打动 → 道谢，随后笑他害羞，把气氛拉回来（0056、0058、0060、0062）

## 关系
- リーリヤ：叫「リーリヤ」（0012、0042）；リーリヤ叫她「清夏ちゃん」（0032）。提议的出发点是两人的约定（0015～0017），对她的状态很敏感（0031、0042、0048）。
- プロデューサー：叫「Pっち」（0001、0058）；这一话里制作人没有称呼她（只有对两人说话）。说他总是贴近两人的心情（0058），会打趣他害羞（0060）。

## 档案类事实
- 约定那天她和リーリヤ举着ペンライト拍了照，照片在她的 SNS 上（0014～0016）。
- 新曲的最后ペンライト动作是她想的（0012、0035）。
- 这首曲子的编舞是镜像式的，配白黑衣装（0006）。
