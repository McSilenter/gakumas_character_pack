# S卡 3-0042【あったかいね】 / 第2话 初次相遇的那一刻（adv_csprt-3-0042_02）

- 她的台词：10 行（含用匿名标签说的 0 行）
- 出场的人：清夏（10）、リーリヤ（10）
- 场景：两人在一起学习（清夏 0004“勉強会”）
- 世界线：S卡【あったかいね】；制作人在制作的偶像：看不出

## 发生了什么
リーリヤ卡在现代文题目上，清夏说可以多依赖她，两人一起整理要点。清夏又向リーリヤ请教数学，随后喊累想吃芭菲休息，被リーリヤ指出才做了一点点。清夏感叹现在一起学习很不可思议，是初次见面时想不到的；リーリヤ也说没想过会住在日本、和清夏同校做偶像。清夏提起第一次见面时リーリヤ和妈妈走散哭泣，说她可爱，リーリヤ害羞。

## 她的关键台词
- 0002「どしたの、リーリヤ？／なにか分からないところある？」——先注意到对方卡住
- 0004「せっかく勉強会してるんだし、／もっと頼ってくれてもいーんだよ？」——希望リーリヤ更依赖自己
- 0007「ねえねえリーリヤ。数学得意だよね？／この問題、どうやって解くの？」——她也向リーリヤ请教
- 0009「つ、疲れたぁ～。もう無理。／ちょっと休憩。パフェたのも……」——很快喊累，想吃芭菲
- 0011「そうなんだけどさ～。／そんなに集中力ないよ～。」——承认自己没有集中力
- 0013「向こうで初めて会った時は、想像も／してなかったような状況だし。」——现在的情景是初次见面时想不到的
- 0017「初めて会った時のリーリヤって確か、／お母さんとはぐれて、泣いてたよね？」——提起第一次见面时的リーリヤ
- 0019「え～？　そう言われてもな～。／あの時のリーリヤ、可愛かったからさ。」——被叫停仍不收手，理由是可爱

## 行为模式
- 对方有困难 → 主动说“多依赖我”并带头整理（0004、0006）
- 自己学累了 → 直接说不行、想吃甜点，并承认没有集中力（0009、0011）
- 被要求不要提旧事 → 用“可爱”为由继续（0019）

## 关系
- リーリヤ：称“リーリヤ”；对方称“清夏ちゃん”（0010、0018）。第一次见面是在“向こう”（0013）。
