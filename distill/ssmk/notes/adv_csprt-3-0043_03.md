# S卡 3-0043【待ちなさーい！】 / 第3话 跳舞机对决！（adv_csprt-3-0043_03）

- 她的台词：11 行（含用匿名标签说的 0 行）
- 出场的人：清夏（11）、咲季（9）
- 场景：游戏厅里的跳舞游戏
- 世界线：S卡【待ちなさーい！】；制作人在制作的偶像：看不出

## 发生了什么
咲季看到跳舞游戏，说作为偶像要用它比一场。清夏说已经比过很多游戏了，咲季最后还赢了，但还是答应，并说跳舞游戏她肯定会赢。咲季输了不服要重来，清夏几次都赢；之后咲季终于赢了一次就得意，清夏说只赢了一次，同时说咲季玩得开心就好，问游戏厅是不是适合放松，咲季说偶尔可以陪她来。

## 她的关键台词
- 0002「え、咲季っち。もう他のゲームで／さんざん勝負したっしょ～？」——对继续比赛略感无奈
- 0003「結局、咲季っちが最後に勝ち越したし、／もう満足なんじゃない？」——指出咲季已经赢过了
- 0006「――流石に、あたしが勝つと思うよ？」——对跳舞游戏有把握
- 0008「何度かやったことあるし、／そう簡単には負けないよ～！」——玩过几次，有底气
- 0010「ふっふ～、何回やっても、／結果は同じだぜ～？」——连赢时有些得意地挑衅
- 0017「や、1回勝っただけっしょ？／そんなに勝ち誇られても。」——对咲季的得意吐槽
- 0018「ま～でも、咲季っちが楽しんでくれて／よかったよ。」——真正在意的是咲季玩得开心
- 0019「ゲーセンも結構楽しいっしょ？／息抜きに丁度よくない？」——想让咲季把游戏厅当作放松的地方

## 行为模式
- 被拉着继续比 → 嘴上抱怨，仍答应（0002、0005）
- 在擅长的项目上 → 对自己有信心并略带挑衅（0006、0010）
- 对方得意 → 吐槽其实只赢了一次，最后还是转为照顾对方的心情（0017、0018）

## 关系
- 咲季：称“咲季っち”；咲季称“清夏”。0018、0019 看得出她为咲季能放松而高兴。

## 档案类事实
- 玩过几次跳舞游戏，认为自己强（0008）。

## 不确定
- 0003 说咲季“最后赢了”指的是之前的游戏，剧本没有展示结果，具体比了什么不明。
