# S卡 3-0055【ここから始まるんだね！】 / 第3话 现在也依旧是，我的英雄（adv_csprt-3-0055_03）

- 她的台词：12 行（含用匿名标签说的 0 行；0001～0004 为清夏做梦中的叙述／内心独白，0007、0009、0010、0012 为醒来后的对话）
- 出场的人：清夏（12）、リーリヤ（8）
- 场景：清夏的梦，之后是她醒来（0005～0007）；然后去了海边（0013、0014），可能是现实，也可能还是梦
- 世界线：S卡【ここから始まるんだね！】；制作人在制作的偶像：看不出

## 发生了什么
清夏的梦里，她的膝盖朝不该弯的方向弯曲。她知道这是梦，是看腻了的梦，现实里没有这样弯过，越离开记忆梦越夸张。被リーリヤ叫醒后，她说已经是早上了，要准备去学校。リーリヤ说逃学吧，两人来到了海边。她问为什么是海，听リーリヤ说这是学她：难过时清夏总是把她带去别处。清夏说那自己倒算得上英雄，リーリヤ说现在也是。

## 她的关键台词
- 0001「――膝が、曲がっている。／本来、曲がってはいけない方向へ。」——梦的开头，描写膝盖的异常
- 0002「その時点で、夢だと分かった。／いつも見ていて、とうに見飽きた夢。／現実で、こんな曲がり方はしていない。」——知道是梦，是经常反复的梦
- 0003「記憶から離れるほど、夢が誇張される。／本当は、もっと普通に、ただ少し――」——记忆与梦的差距，话说到一半
- 0007「も、もう朝だったかぁ～！／やば、学校行く準備しないとね……！」——被叫醒后立刻用开朗的语气掩饰
- 0010「だ、駄目だよ……！／ちゃんと、学校行かなきゃ……」——被提议逃学，认真地拒绝
- 0012「リ、リーリヤ！？／せ、先生に怒られちゃうよ～！？」——被拉着走，慌张提到老师
- 0014「それは、いいんだけど……／なんで……海？」——接受一起玩，但不懂为什么是海
- 0017「……そう、だったっけ？」——被说“总是带你出去”，不确定
- 0019「だったら……あたしって、わりと、／ヒーローみたいなやつだったんだね。」——对リーリヤ的话，半开玩笑地接受

## 行为模式
- 噩梦后被人看到 → 立刻用开朗的语气转移话题（0007）
- 被提议逃学 → 先认真地拒绝（0010、0012）
- 被说自己过去帮过人 → 自己想不起来，不确定（0017）；之后用“英雄”开玩笑接受（0019）
- 梦里 → 用冷静的叙述分析梦与记忆的差距（0002、0003）

## 关系
- リーリヤ：称「リーリヤ」（0006、0012）；リーリヤ称她「清夏ちゃん」，把她当作自己难过时的依靠。リーリヤ带她出去，她跟随

## 档案类事实
- 经常做膝盖朝不该弯的方向弯曲的梦，已看腻（0001、0002）
- 现实里没有这样弯过（0002）

## 不确定
- 0001～0004 是梦中的叙述，不一定是她出声说的话，行数照算；0003 话说到一半（「ただ少し――」）后接 0004「――ぐにゃり、と。」。
- 海边场景是否为现实，剧本没有明说（0007 之后是“早上”，0014 才问“为什么是海”）。
