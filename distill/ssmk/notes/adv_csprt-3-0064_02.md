# S卡 3-0064【いつも頑張ってるね。】 / 第2话 今天是欺骗日！（adv_csprt-3-0064_02）

- 她的台词：8 行（含用匿名标签说的 0 行）；0016、0020 是括号内的心里话
- 出场的人：莉波（12）、清夏（8）
- 场景：地点没写明；两人在吃莉波想吃的店的芭菲（莉波 0004、清夏 0002）
- 世界线：S卡【いつも頑張ってるね。】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
莉波约清夏一起吃芭菲，说麻央和燕都拒绝了她。清夏爽快地说随时可以约她，还问是不是大家都讨厌芭菲。莉波说大概是在做体重管理，自己也有，但偶尔要吃。清夏说自己没特别在意体重，莉波很吃惊，说羡慕，恨自己的体质。莉波说今天是“欺骗日”，要清夏再点一份，清夏说已经饱了，莉波说才第一个。清夏心里觉得莉波有点像手毬。

- 0018「ええっ！？／や、あたしはお腹いっぱいなんで……」——被劝再点，推辞
- 0020「（意外と、手毬っちに似てるかもな～）」——心里话，把莉波和手毬联系起来

## 行为模式
- 被邀请吃东西 → 爽快答应，说随时可约（0002、0005）
- 对体重管理的话题 → 老实说自己没在意，不装（0009、0013）
- 被对方的热情压住 → 嘴上推辞，心里评价对方（0016、0018、0020）

## 关系
