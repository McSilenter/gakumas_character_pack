# S卡 3-0073【ｖギャルピーーースッｖ】 / 第2话 目标是高中出道（adv_csprt-3-0073_02）

- 她的台词：9 行（含用匿名标签说的 0 行）
- 出场的人：広、清夏
- 场景：ゲーセン（游戏厅）里的舞蹈游戏
- 世界线：S卡【ｖギャルピーーースッｖ】；制作人在制作的偶像：看不出

## 发生了什么
広说从千奈那里听到“清夏是高中出道的老师”，清夏说一定被误会了，広说千奈提到的是“刺激体验”，清夏想起是去看衣服的那次。広想靠成为ギャル来实现刺激的高中出道，清夏不太明白，提议先去ゲーセン。两人玩舞蹈游戏，清夏担心広的体力，提出分担（上和右她，下和左広）。结束后清夏解释上级者会做收尾的ポーズ。

## 她的关键台词
- 0002「えっ？　ゼッタイ誤解されてるっしょ！」——听到被说成“高中出道的老师”时的反应
- 0004「あ～～～！　服見に行ったときか！」——想起千奈“刺激体验”指的是哪件事
- 0006「ん～あんまわかってないんだけど、／とりあえずゲーセンとか行ってみる？」——不太明白，但先提出行动
- 0008「どういうイメージなの！？」——对“ギャルはゲーセンが得意”的吐槽
- 0010「ダンスゲーム？　いーけど、／ひろっち、体力大丈夫そ？」——答应并关心体力
- 0012「ちょ！　じゃあ分担して踊ろうよ。／上と右はあたし、ひろっちは下と左ね。」——想出分担的办法
- 0016「――――――――――いえいっ！」——游戏结束时的欢呼（0014 她跳舞时的哼声「ふんふん～……よっと♪」）
- 0018「このゲームの上級者？　は、／最後にキメポーズするんだって！」——解释收尾姿势

## 行为模式
- 对方的要求听不太懂 → 不深究，先带去做点什么（0006）
- 对方说“可能不行但想挑战” → 不拦，调整方式让对方能做（0011→0012）
- 解释自己也不确定的事 → 用问号和「だって」带出（0018）

## 关系
- 広：称「ひろっち」；広称她「清夏」，说“清夏，ダンス得意”（0009、0010）
- 千奈：误传了清夏是“高中出道的老师”（0001～0004）

## 档案类事实
- 擅长跳舞（広 0009）
- 之前陪千奈看过衣服，千奈把那次称为“刺激体验”（0004）
