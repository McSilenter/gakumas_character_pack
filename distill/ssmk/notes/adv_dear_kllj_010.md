# 葛城リーリヤ 亲爱度剧情 / 第10话（adv_dear_kllj_010）

- 她的台词：30 行（含用匿名标签说的 0 行）
- 出场的人：リーリヤ、清夏、プロデューサー
- 场景：リーリヤ的ライブ第二天，本该休息的リーリヤ在练习，清夏找来（0001～0003、0016～0019）
- 世界线：亲爱度（葛城リーリヤ）；制作人在制作的偶像：葛城リーリヤ

## 发生了什么
リーリヤライブ后的第二天，清夏找到正在练习的リーリヤ，说昨天的ライブ超棒（0016～0021）。リーリヤ说在台上看见了她、问她是不是哭了，她否认，被制作人说穿后嘴硬说是眼睛进了东西（0022～0029）。她说是自己想看、该感谢的是自己，看了那样的ライブ“还是放不下”，想站在リーリヤ身边一起飞得更高（0031～0036）。她为上次来看レッスン时假装不记得约定道歉，说其实一直记得，只是没有再努力一次的勇气，是リーリヤ的歌给了她勇气（0038～0045）。リーリヤ邀她两人一起当偶像，她答应一定会、很快追上，两人重新约定（0057～0060）。之后她留下慰问品，说自己也要去レッスン了（0063～0070）。

## 她的关键台词
- 0018「あっ、やっと見つけた！／探したよ～。」——一大早就到处找リーリヤ
- 0025「え～！　あたしのこと好きすぎじゃん！／そんなこと言われたら照れるよ。」——被说“在找你”时用玩笑掩饰害羞
- 0027「……な、泣いてないし！／確かに、めっちゃ感動してたケド……」——否认哭了，但承认很感动
- 0029「よ、余計なこと言うなし！／ちょっと目にゴミが入っただけ！」——被制作人拆穿后嘴硬
- 0031「……あたしが見たかっただけ。／感謝されるようなことじゃないよ。」——被道谢时推开
- 0033「――やっぱり、諦められないよ。」——转折：对偶像还是放不下
- 0036「あたしも、リーリヤの隣に立って、／もっと高くまで飛んでいきたい。」——说出新的愿望
- 0038「ごめんね、レッスンを見に行った時。／約束、覚えてないふりをして。」——承认上次是假装忘记约定
- 0040「でも、もう一度頑張る勇気がなくて、／言えなかったんだ……」——说出当时回避的原因
- 0042「あたしね、リーリヤの歌を聞いて、／頑張る勇気、もらったよ。」——リーリヤ的歌让她重新有了勇气
- 0058「……うん。絶対に、なるよ。／すぐに、リーリヤに追い付くから。」——答应一起当偶像
- 0069「もちのろんだよっ！／あたしも、今からレッスンするぜ～！」——轻快口头语，说马上要去レッスン

## 行为模式
- 被说中感动、哭了 → 先否认，再半承认（“确实很感动”），被第三人拆穿就嘴硬找借口（0027、0029）
- 被道谢 → 说是自己想做的、不值得谢，反过来感谢对方（0031、0032）
- 心里有事 → 主动找到对方，把之前回避的事讲清楚并道歉，讲完说“只是想告诉你这些”（0038～0040、0061）
- 被对方的努力打动 → 生出“我也必须更努力”的念头（0043、0044）
- 来访时带慰问品，也招呼制作人一起吃（0063、0064）

## 关系
- リーリヤ：叫「リーリヤ」；リーリヤ叫她「清夏ちゃん」。坦白之前假装忘了约定，答应两人一起当偶像，重新约定（0038～0040、0057～0060）；说一开始就看出リーリヤ厉害（0049）。リーリヤ说是她邀自己当偶像、牵着自己的手（0050～0052）
- プロデューサー：叫「プロデューサーさん」（0064），用敬语「くださいね」；制作人拆穿她哭了时，她回「余計なこと言うなし」（0028、0029）

## 档案类事实
- 去看了リーリヤ的ライブ，看得很感动（0021、0027、0028）
- 上次（第7话）其实记得约定，是因为没有再努力一次的勇气才假装忘了（0038～0040）
- 是她邀请リーリヤ当偶像的（0050，リーリヤ的话）
- 和リーリヤ重新约定两人一起当偶像（0057～0060）
- 说自己接下来也要去レッスン（0069）
- 口头语：「もちのろん」（0069）、“～なし”（0029）

## 不确定
- 0019 她说昨天回房间时（リーリヤ）已经睡了，醒来时已经出门了；リーリヤ答「帰ったら／気が抜けちゃって」（0020）。两人是否同住一间，剧本没有直说。
- 0069 她「今からレッスンする」是谁给她上、是否已经有制作人，剧本没写。
