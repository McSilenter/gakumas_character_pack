# 葛城リーリヤ 亲爱度剧情 / 第30话（adv_dear_kllj_030）

- 她的台词：11 行（含用匿名标签说的 0 行）
- 出场的人：プロデューサー、リーリヤ、清夏、ニュース
- 场景：『REVERSI』的レッスン配信上了网络新闻，制作人和两人谈『H.I.F』的对策（全篇），地点没写
- 世界线：亲爱度（葛城リーリヤ）；制作人在制作的偶像：葛城リーリヤ（同时为『REVERSI』定战略）

## 发生了什么
『REVERSI』因レッスン配信走红、上了网络新闻，她惊喜地说「バズってる」，还说照这势头会不会一举夺冠（0004～0013）。制作人说知名度不影响『H.I.F』评审，她附和「だよね～」，又听懂了“表面上无关、实际不然”（0018、0024）。制作人把『ときめきエモーション』借两人关系引起共鸣的效果命名为『約束の剣』，リーリヤ觉得很帅，她却不以为然（0031～0039）。制作人说リーリヤ的表演能打动人心，她说自己可以保证，因为是从リーリヤ那里得到了努力的勇气才有今天（0049～0051）。制作人讲『葛城結界』『約束の剣』『燃えるシチュ◎』的“原理”，リーリヤ连声说明白，她说自己完全没明白（0066～0073）。

## 她的关键台词
- 0004「ネットニュースになってる！？」——吃惊
- 0007「ほんとだ、バズってるじゃん！？」——惊喜，用网络用语
- 0013「もしかして、あたしたち、この勢いで／優勝までいけちゃったり～！？」——乐观到有点得意忘形
- 0018「だよね～。」——被泼冷水时马上附和
- 0024「つまり……表向きは関係ないけど、／実態はそうじゃないってこと？」——把制作人的话用自己的话总结
- 0039「……え、そう？？？」——对『約束の剣』这个名字不认同
- 0050「……ん、そうだね。／あたしが保証するよ。」——为リーリヤ作保
- 0051「リーリヤに頑張る勇気をもらったから、／――あたしは今ここにいるんだ。」——说自己能站在这里是因为リーリヤ
- 0073「いや、ぜんぜん分かんないけど！？」——对两人的「必殺技」话题吐槽

## 行为模式
- 有好消息 → 大声惊喜、往乐观方向想（0004、0007、0013）
- 被现实泼冷水 → 不争辩，爽快附和（0018）
- 听复杂解释 → 用自己的话复述确认（0024）
- 制作人和リーリヤ热衷于「必殺技」命名和设定 → 冷静吐槽、表示不认同或听不懂（0039、0067、0073）
- 话题转到リーリヤ的魅力 → 认真地以自身经历为她作证（0050、0051）

## 关系
- リーリヤ：叫「リーリヤ」；リーリヤ叫她「清夏ちゃん」。说自己是从リーリヤ那里得到勇气才在这里（0051）；两人以『REVERSI』一起受到关注（0001～0007）
- プロデューサー：制作人叫她「紫雲さん」（0005）。对制作人的命名不买账（0039）

## 档案类事实
- 『REVERSI』因レッスン配信走红、上了网络新闻（0001～0007）
- 『REVERSI』的曲子『ときめきエモーション』（0031，制作人）
- 说自己是从リーリヤ那里得到努力的勇气，才站在这里（0051）

## 不确定
