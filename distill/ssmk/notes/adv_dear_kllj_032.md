# 葛城リーリヤ 亲爱度剧情 / 第32话（adv_dear_kllj_032）

- 她的台词：23 行（含用匿名标签说的 0 行；0031 后半『』内是她模仿咲季口吻编的话，不是她本人的想法）
- 出场的人：リーリヤ、清夏、プロデューサー、咲季（一同 2 行：0019、0020）
- 场景：和咲季的『選抜試験』结束后，リーリヤ跑去向制作人报告，清夏随后赶到（0001～0021），咲季跑来（0022～0042），之后三人谈『一番星』（0043 起）
- 世界线：亲爱度（葛城リーリヤ）；制作人在制作的偶像：葛城リーリヤ

## 发生了什么
赢了咲季、确定『H.I.F』本战出场后，她追上一结束就跑去找制作人的リーリヤ，打趣说リーリヤ是想马上被前辈夸（0009～0011）。被制作人夸后，她说多亏リーリヤ带着自己才跳得好，两人互相把功劳推给对方（0014～0020）。咲季跑来认输，她说这时不该道谢，模仿咲季口吻说“明天起叫我姐姐”，惹得咲季不甘，随即道歉说期待本战（0028～0035）。制作人说『一番星』只能有一人，她惊讶リーリヤ不知道，说自己参加的比赛当然会查规则（0046～0055）。リーリヤ说只要优胜、实现约定就够了，她不赞同，说想要的东西就说想要，那份心情不会妨碍两人的梦想；リーリヤ说出想成为『一番星』，请她当既是伙伴又是对手的关系，她答应，说两人关系这么好没问题、绝对不会输（0062～0079）。剧情经过参照 hski 笔记。

## 她的关键台词
- 0011「すぐセンパイに褒めてもらいたかった、／の間違いじゃないの～？」——借リーリヤ的称呼「センパイ」调侃她
- 0015「リーリヤが引っ張ってくれたおかげで、／めっちゃ良い感じに踊れたんだ。」——把功劳归给リーリヤ
- 0024「いやいや、人のこと言えないでしょ。」——吐槽リーリヤ自己也是跑着来的
- 0028「そこは感謝じゃなくない？」——咲季认输时的反应
- 0031「や～い咲季っち！／『明日からわたしのこと、／お姉ちゃんと呼びなさ～い！』」——模仿咲季的口气调侃（『』内是编的）
- 0035「ごめんごめん咲季っち！／本戦、楽しみにしてるからね！」——玩笑过头立刻道歉并示好
- 0053「そりゃ～、自分が出る大会のルール／ぐらい調べるでしょ。」——对比赛规则早有了解
- 0055「アニメのややこしい説明は、／すぐ覚えるくせに……」——吐槽リーリヤ
- 0065「あたしはそう思わないよ、リーリヤ。」——明确不同意リーリヤ的退让
- 0066「欲しいものは欲しいって、／そう言っていいんだよ。」——鼓励リーリヤ说出真正想要的
- 0068「その気持ちが、あたしたちの夢を／邪魔したりなんかしないよ。」——不认为竞争会破坏两人
- 0078「あたしたちなら大丈夫だよ！／だって、こんなに仲良いんだから！」——接受“伙伴兼对手”
- 0079「ぜったい負けないからね、リーリヤ！」——向リーリヤ宣战

## 行为模式
- 朋友急着去见制作人 → 半开玩笑地戳穿“是想被夸吧”（0009、0011）
- 被夸 → 先得意（「そうでしょ？」），然后把功劳推给搭档（0014、0015、0017）
- 别人认输 → 起哄调侃，模仿对方口气；对方真不甘时马上道歉、把话题转向下一场（0028～0035）
- 朋友为了关系而压抑愿望 → 直说“我不这么想”，劝对方说出想要的东西（0063～0068）
- 被邀请成为对手 → 先愣一下，然后爽快答应并当场宣战（0073、0077～0079）

## 关系
- リーリヤ：叫「リーリヤ」；リーリヤ叫她「清夏ちゃん」。爱打趣リーリヤ（0011、0055），互相推功（0015～0018）；劝リーリヤ说出想当『一番星』，两人约定成为伙伴兼对手（0066、0077～0079）
- 咲季：叫「咲季っち」（0031、0035）；咲季叫她「清夏」（0022、0042）。拿咲季的认输开玩笑后道歉，说期待本战（0031、0035）
- プロデューサー：本篇没有直接称呼；在リーリヤ面前用「センパイ」指制作人（0011）

## 档案类事实
- 和リーリヤ赢了咲季，确定『H.I.F』本战出场（0002、0003）
- 事先查过『H.I.F』规则，知道『一番星』只有一人（0046、0053）
- 知道リーリヤ对动画里复杂的设定记得很快（0055）
- 和リーリヤ约定成为「仲間でライバル」（0074～0079）

## 不确定
- 『一同』0019「む～…………」、0020「へへへへへへ……」不算台词数；从上下文看是リーリヤ和清夏两人（互相推功之后）。hski 笔记【已确认 2026-10-31】0019、0020 不算咲季的（清夏和リーリヤ，咲季 0022 才跑进来）。
- 0031 她模仿的「お姉ちゃんと呼びなさ～い」是她编的“咲季会说的话”，咲季本人是否说过本篇没交代。
- 0040「……ん？？？」是对リーリヤ说“成为『一番星』的是我们”的反应，之后才由制作人说明规则；她在 0053 说自己早就查过规则。
