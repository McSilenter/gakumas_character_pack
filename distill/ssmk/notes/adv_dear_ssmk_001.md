# 紫雲清夏 亲爱度剧情 / 第1话（adv_dear_ssmk_001）

- 她的台词：31 行（含用匿名标签说的 0 行）
- 出场的人：清夏、プロデューサー、ダンストレーナー（リーリヤ只被提到、远远跑步，没有台词）
- 场景：学园内，ダンストレーナー带队跑步训练的场地旁，清夏在一边偷懒
- 世界线：亲爱度（紫雲清夏）；制作人在制作的偶像：紫雲清夏（0037、0040 当面スカウト，她答应先试试，0048）

## 发生了什么
制作人来スカウト，在跑步训练场边遇到偷懒的清夏，她说嫌烦所以サボり。听说对方是プロデューサー科的，她当场起外号「Pっち」，还主动把正在拼命跑的朋友リーリヤ推荐给他，说她胆小、体力不好，但是很厉害、适合当偶像。被问到她自己，她说自己没干劲，入学只是因为和那孩子约好一起入学才稍微努力了一下，又说是侥幸。制作人说目标就是她，说她有才能；她惊讶，说他看走眼，但最后以「先试试」的态度答应，并要求别叫「紫雲さん」。制作人改叫「清夏さん」，她说想不干了随时可以不干。

## 她的关键台词
- 0007「んー？　ダルいしサボりー。／あんたは？」——第一印象：直接说自己偷懒，说话松垮的辣妹口吻；这时还叫对方「あんた」。
- 0012「うん。プロデューサーだからPっち♪／……駄目？」——外号的由来，起完外号又轻轻确认一句行不行，随便里带着看对方脸色。
- 0018「あたしのカノジョ～。／可愛いっしょ？　――なーんて。」——介绍朋友也要先开个玩笑。
- 0026「すごいやつなんだ。」——夸リーリヤ时语气变实在。
- 0027「ぜったい、アイドル向いてると思う。」——对朋友的才能毫不保留地肯定，和说自己时完全相反。
- 0030「へ、あたし？／いやいや、あたしはいいんだって。」——话题一转到自己就立刻推开。
- 0033「そこはほら、約束したんだよね。／あの子と一緒に、ここに入学するって。」——入学的理由：和朋友的约定。
- 0034「だから、ちょっとだけ頑張ったの。／てゆーかまぁ、マグレ的な？」——承认努力了，马上又用“侥幸”盖过去。
- 0041「こ、こーんなおちゃらけてて、／ぜんぜんやる気ないやつなのに？」——被看中时的第一反应是用自我贬低反问。
- 0043「節穴だね、Pっち。」——把对方的肯定说成看走眼。
- 0046「ま、別にやったげてもいーよ。／すぐに失望すると思うけどね～？」——答应的同时先预告对方会失望。
- 0056「はーい。やめたくなったら／いつでもやめていいからね～♪」——用轻松的语气给对方留退路。

## 行为模式
- 初次见面 → 马上用外号拉近距离，并要求对方也别太见外（0012、0051、0052、0054）
- 对方接受自己的小要求 → 立刻高兴、夸对方，顺势热络起来（0014、0015）
- 说起朋友 → 先开玩笑，然后认真夸对方的才能（0018、0019、0026、0027）
- 被问到自己的干劲、入学 → 先否认、推开，用“没干劲”“侥幸”带过（0030、0031、0034），再把话题转回别处（0036）
- 被认真肯定 → 先愣住，再自我贬低，说对方看走眼（0038、0039、0041、0043）
- 答应一件事时 → 用“先试试”“你很快会失望”“随时可以不干”给双方留退路（0046、0048、0056）

## 关系
- 制作人：先叫「あんた」（0007），得知身份后叫「Pっち」（0010、0012）。制作人先叫她「紫雲さん」（0040、0045），应她要求改叫「清夏さん」（0053、0055）；她还提议可以叫「清夏っち」（0054），没被采纳。她说和 Pっち说话挺有意思，以这个理由答应先试试（0048）。
- リーリヤ：叫「リーリヤ」（0021、0024）、「あの子」（0033）；介绍说是朋友、一起入学的（0019）。玩笑说是「カノジョ」（0018）。说她有时太拼命（0021），体力不多、胆小（0025），但很厉害（0026）。ダンストレーナー叫她「葛城」（0022）。
- ダンストレーナー：背后叫「鬼トレーナー」（0024）。

## 档案类事实
- 她是有入学考试的这所学园的学生；她说入学是因为和リーリヤ约好（0019、0033）。
- 她说自己入学只“稍微努力了一下”、是侥幸，但制作人当面质疑没干劲的人过不了这所学校的入试（0032、0034）。这是她本人的说法，真实程度本篇没有交代。
- リーリヤ姓葛城，和她一起入学（0019、0022）。
- 制作人是プロデューサー科的学生，她说第一次见到（0008、0009）。

## 不确定
- 0034 的「マグレ的な？」是她的自称，0032 制作人不信，0041～0042 对“没干劲”也有分歧。本篇没有交代她实际的入试情况。
- 制作人说她有才能（0040），这一话里没有说明依据；0042「そうは見えませんが」也没展开。
