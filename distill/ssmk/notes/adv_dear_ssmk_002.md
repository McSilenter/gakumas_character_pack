# 紫雲清夏 亲爱度剧情 / 第2话（adv_dear_ssmk_002）

- 她的台词：42 行（含用匿名标签说的 0 行；0028 是唱歌时的哼声「～～～～♪」，行数照算）
- 出场的人：清夏、プロデューサー、ダンストレーナー
- 场景：舞蹈课进行中的地方（她又在偷懒）→放学后，卡拉OK→ゲーセン→送她回寮的路上，天已黑（0024、0040、0060）
- 世界线：亲爱度（紫雲清夏）；制作人在制作的偶像：紫雲清夏（0012）

## 发生了什么
制作人来叫又在偷懒的清夏上个人课，她说没心情，还问他是不是该失望了，劝他放弃自己。制作人转而说那就去玩，她有点意外地答应，放学后两人去卡拉OK。她唱得很开心，说喜欢唱歌，被夸努力时否认。之后去ゲーセン，她说这是“第一次约会”，要拍大头贴，还要制作人抓娃娃；制作人抓上瘾时她出面拦住。制作人送她回寮，她说以后也一起玩，问到训练只说有心情再说。分开后制作人在心里回想：她在ゲーセン把游戏挨个玩过去，唯独跳舞类的没碰。

## 她的关键台词
- 0006「うるさ～い！／別に、あたしの勝手でしょ？」——被点破偷懒时的顶嘴。
- 0011「んー、わかんない！／どう？　そろそろあたしに失望した？」——主动试探对方是不是该失望了。
- 0013「強情だね、Pっち。」——对不肯放弃自己的制作人的评价。
- 0016「でしょ！？／だったら、あたしのことは諦めて――」——明说希望对方放弃自己。
- 0030「そりゃ、歌うのは好きだよ？／きもちいーし。」——对唱歌的喜欢是直接承认的。
- 0032「……そんなに褒めても何も出ないよ？／てか別に、努力とかしてないし。」——被夸“努力”立刻否认。
- 0034「む……まあ別に悪い気はしないケド。／てか、Pっちは歌わないの？」——承认被夸不讨厌，马上换话题。
- 0043「まずはプリ撮ろ！／Pっちとの初デート記念にね♪」——用“约会”逗对方。
- 0045「男女が一対一で遊んでるんだし、／デートっしょ？」——说得理所当然，半开玩笑。
- 0055「ちょ、ちょ、Pっち！？／熱くならないで、そこまでにしとこ？」——自己撒娇要的东西，看对方上头反而马上拦。
- 0059「――いやぁ、満足満足♪／久しぶりに全力で遊んじゃったな～。」——玩得尽兴。
- 0066「あははっ、気が向いたらね～。」——对训练的固定回避。

## 行为模式
- 被叫去训练 → 用“没心情”“麻烦”推掉，反过来试探对方是否失望、劝对方放弃（0009、0011、0014、0016）
- 对方不按她预想的放弃，反而提议玩 → 愣一下，装作无所谓，马上兴致勃勃提出想去的地方（0018、0020、0021）
- 被夸努力 → 先岔开（“夸我也没好处”），否认努力，再承认不讨厌（0032、0034）
- 玩的时候 → 主导行程、把事情说成“约会”逗对方，对方反应一本正经就笑他古板（0042、0043、0045、0047）
- 要对方帮忙的事对方太投入 → 反过来关心、替对方找台阶（别处也买得到、还想玩别的）（0055、0056）
- 一天结束 → 确认对方是否也开心（0062），对训练继续打马虎眼（0066）

## 关系
- 制作人：叫「Pっち」（全篇），制作人叫她「清夏さん」（0035、0057）。说他固执（0013）、古板（0047），说他「年上の男の人」（0061）；问他今天开不开心，听到开心后说以后也一起玩（0062、0064）。
- ダンストレーナー：本篇她没有和对方说话，只是在旁边躲着。

## 档案类事实
- 喜欢唱歌，说唱歌「きもちいー」（0030）；制作人评价她的歌声引人入胜，感受得到以往的努力（0031），她否认努力（0032）。
- 喜欢去卡拉OK、ゲーセン，会拍プリ（0021、0040、0043）。
- 住在寮里（0060、0067）。
- 比制作人年纪小（她说他是「年上の男の人」，0061）。
- 【制作人的心里话，不是她说的】在ゲーセン挨个玩游戏，唯独跳舞类的没碰（0070）；制作人的记录里推测跳舞是她放弃的原因（0072）。

## 不确定
- 0025～0027 三句之间缺制作人的回应（选项没写进剧本），她是对什么样的回答作反应，读不出。
- 0072 是制作人的笔记式自语，末尾是「みたいだな」的推测；本篇里她自己没有提跳舞的事。
- 【译文】0050「クレーンゲームで取れと？」译文“是要我拥抓娃娃机抓出来？”多了错字“拥”，不影响理解（此行是制作人的话，仅顺带记）。
