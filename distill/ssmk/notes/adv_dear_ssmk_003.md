# 紫雲清夏 亲爱度剧情 / 第3话（adv_dear_ssmk_003）

- 她的台词：49 行（含用匿名标签说的 0 行）
- 出场的人：清夏、プロデューサー、アイドルA
- 场景：地点没写的地方（0001）→制作人带她去看的ライブ会场（ライブ结束后两人留在原地说话）
- 世界线：亲爱度（紫雲清夏）；制作人在制作的偶像：紫雲清夏（0012、0074～0075）

## 发生了什么
制作人又来找清夏，她说不是训练的话可以，于是被带去看ライブ。她看得很投入，其间说了句「いいなぁ」（0018）。结束后她有点出神，说想起了入学前的事，马上又说是玩笑；制作人说想多了解她，她才讲起来：小学起就喜欢偶像，但原本只是喜欢；有一天和リーリヤ来看这所学园顶尖偶像的ライブ，受感动，想成为那样的人，并和リーリヤ约好一起入学、总有一天两人一起站上那个舞台。接着她说自己已经放弃了，因为她和毫不犹豫的リーリヤ不一样。制作人没有说“别放弃”，说这句话是把事情交给对方的强大；她说心情轻松了一点，道谢并说下次请客。

## 她的关键台词
- 0018「………………いいなぁ。」——看ライブ时漏出的羡慕。
- 0024「……ただ、ちょっと思い出しちゃって。／この学園に入学する前のこと。」——难得主动露出一点。
- 0025「あははっ、なーんて、冗談冗談♪／そんなの、あたしに似合わないよね～。」——刚露出就用玩笑收回。
- 0028「――あたしさ、アイドルが好きなんだ。／小学生の時からずっとね。」——明说的喜好和起点。
- 0031「でも昔は単に好きってだけで、／憧れとか、そーゆーのは別になかった。」——喜欢和憧憬是两个阶段。
- 0034「感動したの。泣いてたと思う。／みんな可愛くて、みんな頑張ってて、／あたしに、元気を与えてくれた。」——憧憬的来源。
- 0035「だから、思ったんだ。／この人たちみたいになりたいって。」——想成为偶像的起点。
- 0036「……笑っちゃうでしょ？／あたしにもそんな時代があったんだ。」——讲自己的梦想时先自嘲，并说成过去的事。
- 0048「――いつか、ふたりで一緒に、／あのステージの上に立とうって。」——和リーリヤ的约定。
- 0050「夢が叶えば、ね？／あたしはもう諦めちゃったから。」——说自己已经放弃。
- 0053「あたしはリーリヤとは違う。／あそこまで真っ直ぐにはなれないよ。」——放弃的理由是拿自己和リーリヤ比。
- 0055「ためらいがないんだ、あの子には。／……あたしとは、大違い。」——对リーリヤ的认识，和对自己的否定。
- 0057「……そんなの嘘だよ。／それじゃ、前に進めない。」——不接受“犹豫不是坏事”。
- 0067「なんか、ムズかしい話だね？／でも……ちょっと心が軽くなったかも。」——没被劝反而轻松了。

## 行为模式
- 提到内心的事 → 露一点立刻用「冗談」收回（0024、0025），之后自嘲（0036）
- 对方认真不笑话 → 放松下来，用撒娇式的话回应（0037、0038）
- 自己想掩饰的举动被当面点破、被说可爱 → 炸毛（0039、0040），但接着愿意继续讲（0042）
- 说到放弃 → 拿リーリヤ和自己比，用“做不到”收尾，话说到一半停住（0052、0053、0058、0059）
- 说完沉重的话 → 道歉，转回轻松的语气，用请客把人情还回去（0061、0068、0070）
- 对方不说空泛的鼓励 → 意外，并承认心里轻松了（0062、0067）

## 关系
- 制作人：叫「Pっち」，制作人叫她「清夏さん」（0002、0026）。说和他玩挺有意思（0006）；喜欢他「そーゆートコ」（0038）；被他说可爱时回「ウッザ」（0040）；把请客说成下次「デート」（0071）；开玩笑说他「だからモテない」（0072）。
- リーリヤ：向制作人称「リーリヤって名前の女の子」（0044）、「あの子」（0055）；看ライブ时同行，两人一起憧憬偶像并立下约定（0043、0046～0048）。认为对方一直在努力、没有犹豫（0054、0055），和自己“大違い”。

## 档案类事实
- 小学起就喜欢偶像（0028）。
- 在入学前，和リーリヤ一起来看过这所学园的顶尖偶像的ライブ，受感动、大概哭了，因此想成为那样的人（0033～0035、0043）。
- リーリヤ那天也憧憬上了偶像（0046）。
- 和リーリヤ约定一起入学，总有一天两人一起站上那个舞台（0047、0048）。
- 她说自己已经放弃了这个梦（0050）。
- 她在アイドル科（0030）。
