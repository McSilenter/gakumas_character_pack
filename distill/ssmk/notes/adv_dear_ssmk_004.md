# 紫雲清夏 亲爱度剧情 / 第4话（adv_dear_ssmk_004）

- 她的台词：40 行（含用匿名标签说的 0 行）
- 出场的人：清夏、プロデューサー、リーリヤ
- 场景：能看到リーリヤ练习的地方（学园内，具体地点没写）
- 世界线：亲爱度（紫雲清夏）；制作人在制作的偶像：紫雲清夏（0009、0074）

## 发生了什么
清夏遇到在看リーリヤ练习的制作人，劝他改选リーリヤ，制作人说要制作的偶像已经定了。她坦白原本以为敷衍一下他就会放弃。制作人说对放弃向上的人自己无能为力，但放不下“想放弃却放弃不了”的人，还说放弃并非坏事、判断要趁早。接着他逐条指出她放不下的证据：看ライブ时的眼神、只逃舞蹈课、偷偷做基础训练；她先开玩笑，被要求别打岔后说自己真的没有留恋。被追问为什么只逃舞蹈时她发火，喊出「あんたに、あたしの何が分かるの！？」，制作人说这才是真心话，并说希望她不要放弃、想看她在舞台上发光。她说本来继续这样下去就快能放弃了，最后喊着烦死了答应做下去，要他负起责任。制作人正式提出制作她，她答应一起努力。

## 她的关键台词
- 0007「あたしなんかじゃなくて、／リーリヤにすればよかったのに。」——把机会往朋友那边推，用「あたしなんか」说自己。
- 0011「テキトーにおちゃらけてたら、／すぐに諦めると思ってたのにな～。」——自己承认玩世不恭是有意让对方放弃。
- 0012「あたしにそんなこだわるなんて。／ちょっとなめてたよ。」——第一次承认低估了对方。
- 0022「……あたしがまだ諦めきれてないって／言いたいの？」——被说中时的警惕。
- 0043「あたしは本当に、／もうアイドルに未練はないの。」——此时还在否认，紧接着被追问。
- 0047「これ以上、あたしの心を／乱さないで……！」——防线开始崩。
- 0052「あんたに、あたしの何が分かるの！？」——愤怒时叫回「あんた」。
- 0053「あたしが、どんな想いで……／今日まで過ごしてきたと思って……！」——压着的真实情绪露出来。
- 0063「今のまま過ごしてたら、／そのうち諦められそうだったのに……」——承认其实还没放弃，只是快要能放弃了。
- 0064「無理して頑張る必要もない。／その方が、絶対に楽だったのに……」——知道放弃更轻松。
- 0067「――分かった。／そこまで言うなら、やってあげる！」——转折。仍然是“为你做”的口吻。
- 0068「Pっち、あたしを焚きつけた責任は／ちゃんと取ってもらうからね！」——把决心说成要对方负责。
- 0069「途中で投げ出したりしたら、／絶対に許さない。」——对制作人的要求，语气很重。
- 0076「Pっちと一緒に、頑張ってあげる。」——接受制作，依旧是「あげる」的说法。

## 行为模式
- 被肯定、被选中 → 把机会推给别人（リーリヤ）（0007、0008）
- 被人指出还放不下 → 先用“只是喜欢”“被盯上不好”找理由，再开玩笑（说对方是跟踪狂）（0036、0038、0040）
- 被要求别打岔 → 立即道歉、收起玩笑，然后认真否认（0042、0043）
- 被一再追问痛处 → 从恳求（别再说了）到发火，叫回「あんた」，真心话跟着漏出来（0046、0047、0049、0052、0053）
- 被当面说想看她发光 → 说不出话，承认本来快能放弃（0062～0064）
- 下决心时 → 嘴上吵闹、把决心说成“为你做”“你要负责”（0066～0069、0076）

## 关系
- 制作人：平时叫「Pっち」，生气时喊「あんた」（0052）。制作人叫她「清夏さん」。对他的看法从“敷衍一下就会放弃”变成“小看了”（0011、0012），最后说他要负责、半途而废绝不原谅（0068、0069），答应一起努力（0076）。
- リーリヤ：叫「リーリヤ」（0005、0007）；认为制作人选她就好（0007）。

## 档案类事实
- 【制作人的话，她没有承认】她只逃舞蹈课，其他课都认真上（0037）；偷偷坚持基础训练（0039）。她对 0037 回了「まー、サボりすぎるのは／よくないじゃん？」（0038），没有否认；对 0039 回了跟踪狂的玩笑（0040），也没有直接否认。
- 她本人说的：之前的玩世不恭是想让他放弃（0011）；本来快要能放弃（0063）。
