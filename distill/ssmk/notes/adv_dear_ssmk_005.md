# 紫雲清夏 亲爱度剧情 / 第5话（adv_dear_ssmk_005）

- 她的台词：36 行（含用匿名标签说的 0 行）
- 出场的人：清夏、プロデューサー
- 场景：见面打招呼（「おはよ～」，0001）后的谈话，地点没写
- 世界线：亲爱度（紫雲清夏）；制作人在制作的偶像：紫雲清夏（0014「担当アイドル」）

## 发生了什么
清夏为上次说话过头道歉，说多亏那样才想通，感谢制作人让她认清了真正的心情。她说入学前跳过芭蕾；制作人说听闻她有名、被称为天才，也知道她右膝受过重伤。她说因此放弃了芭蕾，伤早已痊愈，但跑跳时仍怕那种疼痛再来，大概是创伤，一直瞒着，这是第一次对人说。被问到为什么选偶像而不回芭蕾，她说憧憬不是假的，但当时也许是不想面对芭蕾；现在对芭蕾没有留恋，找到了想认真去做的事。她说偶像在她一无所有时推了她一把，这次想成为给像自己一样的孩子力量的人。之后她反问制作人为什么当制作人，最后以戳他、挠他痒痒打闹收场。

## 她的关键台词
- 0005「そのおかげでふっきれたから、／あたしは気にしてないよ～。」——上次的争吵，她说成帮她想通了。
- 0007「あたしの本当の気持ちに、／気づかせてくれたからね！」——直接表达感谢。
- 0009「うん。／ずっと目を逸らしてただけだった。」——承认一直在回避。
- 0010「――あたしね、この学園に入る前は、／バレエやってたんだよね。」——说出过去。
- 0012「なーんか恥ずかしいって。／そんな大層な感じじゃないよ！」——对“天才”的称呼推开。
- 0017「うん。／それが原因で、バレエやめたんだ。」——放弃芭蕾的原因。
- 0018「あ、でも勘違いしないでね。／怪我はとっくに完治してるんだ。」——伤已好，问题不在身体。
- 0020「走ったり、跳んだりした時、／またあの痛みが来るんじゃないかって。」——恐惧的具体内容。
- 0023「話すのはPっちが初めて。／Pっちには、バレてるのかもだけど。」——信任的表示。
- 0034「……それは嘘じゃないけど、当時は／バレエと向き合いたくなかったのかも。」——对自己动机的诚实修正。
- 0037「それより本気になりたいもの、／見つけちゃったから。」——现在的方向。
- 0040「明日を生きる理由もなかったあたしの／背中を押してくれた。」——偶像对她的意义，说出当时的低谷。
- 0042「今度はあたしが、あたしみたいな子の／力になれたらいいなって。」——当偶像的志向。

## 行为模式
- 冲突过后 → 主动先道歉，然后把事情转成感谢（0003、0005～0007）
- 被叫“努力家”“认真的孩子” → 结巴地否认、抱怨对方一副什么都懂的样子（0026、0028、0030）
- 谈完沉重的话 → 被夸有点害羞，马上把话题转到对方身上（0044、0045）
- 对方反驳得有道理 → 嘴上说烦，用打闹把话题带过（0052、0054、0056）
- 讲自己的过去 → 这次不再开玩笑打断，会修正自己的说法（“不是假的，但也许……”）（0033、0034）

## 关系
- 制作人：叫「Pっち」；制作人叫她「清夏さん」（0025、0051）。感谢他（0006、0007）；这件事第一次告诉他（0023）；嫌他“什么都懂”的样子让人火大（0030）；笑他怕痒，打闹（0054、0056）。
- リーリヤ：提到一起看学园ライブ、憧憬偶像（0033）。

## 档案类事实
- 入学前跳过芭蕾（0010）。
- 制作人听说她在芭蕾界有名、被称作天才（0011）；她说没那么夸张（0012）。
- 右膝受过重伤（0016 制作人的话，0017 她确认），因此放弃芭蕾（0017）。
- 伤已完全痊愈（0018），但至今在跑跳时害怕疼痛再来（0019、0020），她说大概是创伤（0022）。
- 放弃芭蕾一段时间后和リーリヤ看了学园ライブ（0032、0033）。放弃芭蕾后她说自己什么都没剩下、连明天活下去的理由都没有（0039、0040）。
- 志向：想成为能给像自己一样的孩子力量的人（0041、0042）。
- 她说现在对芭蕾没有留恋（0036）。
