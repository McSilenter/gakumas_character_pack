# 紫雲清夏 亲爱度剧情 / 第6话（adv_dear_ssmk_006）

- 她的台词：37 行（含用匿名标签说的 0 行）
- 出场的人：清夏、プロデューサー、リーリヤ
- 场景：学园的レッスン室，练到窗外全黑（0026），回去时发现另一间レッスン室亮着灯（0036），「夜も遅いし」（0068）
- 世界线：亲爱度（紫雲清夏）；制作人在制作的偶像：紫雲清夏（0064）

## 发生了什么
制作人开始正式的个人练习，提出尝试克服舞蹈的创伤。清夏说有点沉重，但有 Pっち在应该没问题；练习中她呼吸急促、不舒服，休息后说已经没事、要继续，制作人要求慎重，身心优先，她答应听他的。两人练到天黑，她说是自己一直说再练一下造成的；没有成果，但她说不面对就解决不了。回去时她们发现リーリヤ一个人还在练，清夏上前问她为什么能这么拼；リーリヤ说要当偶像，提到和清夏的约定，还看出清夏也决定不放弃了。清夏否认对制作人敞开了心扉，リーリヤ郑重拜托制作人，被她吐槽像监护人。最后两人一起回去，清夏问她是不是在担心自己。剧情经过参照 kllj 笔记。

## 她的关键台词
- 0007「でも頑張る！／Pっちが一緒なら、大丈夫かも。」——把依赖说得轻松。
- 0012「はぁ、はぁ……／ゴ、ゴメン、ちょっと気分が……」——发作时先道歉。
- 0016「……うん。踏ん張ったりする時も、／ぞわっとする感じがある。」——对症状的描述。
- 0017「何度かそういう感覚があると、／だんだん気持ち悪くなっちゃうんだ。」——症状的进展。
- 0021「こうなることは分かってたからさ。／それでも、頑張らないと駄目じゃん？」——预料到还要硬撑。
- 0024「……そだね。／分かった。Pっちの言う通りにする。」——接受制作人的控制。
- 0030「そりゃ辛いけどさ～、／やっぱ向き合わないと、解決しないし。」——承认辛苦，语气仍松。
- 0031「でも、結局なーんも成果なかったね。／そう簡単にはいかないな～。」——把没成果说得轻。
- 0043「流石に、止めた方がいいかな？／だいぶ疲れてるみたいだし……」——第一反应是担心对方。
- 0053「どうして、そこまで頑張れるの？」——对リーリヤ的努力的直接疑问。
- 0056「リーリヤ……／ちゃんと覚えててくれたんだ？」——约定被记着时的反应。
- 0063「別に、心は許してないってば！／ちょっと手伝ってもらってるだけ！」——被朋友说中时否认。
- 0066「ちょっとリーリヤ、あたしの保護者／みたいな挨拶しないでよ～。」——不好意思时用吐槽带过。
- 0078「ゴ、ゴメン……／でも、リーリヤは無理しすぎだって――」——道歉，同时反过来担心对方。

## 行为模式
- 发作刚过 → 马上说没事、要继续（0014、0019），被认真劝才听（0024）
- 看到成果不佳 → 用轻松的语尾说“没那么简单”，不抱怨（0031）
- 面对不太情愿的措施（找メンタルトレーナー）→ 说不太情愿，但也只能什么都试试（0034）
- 看到别人过度努力 → 担心，直接问“还要练吗”（0043、0047、0049）
- 被朋友说中对制作人的信任 → 慌张否认，换成“只是帮点忙”（0063）
- 自己练到很晚时被问 → 吐槽“这句是我的台词”，同时关心对方（0047）；自己也知道自己没资格说（0038）

## 关系
- 制作人：叫「Pっち」；制作人叫她「清夏さん」（0023、0064）。说有他一起就没问题（0007），听从他的安排（0024），夸他贴心（0072）。向リーリヤ否认「心を許した」（0063）。
- リーリヤ：叫「リーリヤ」（0041、0045、0070）；リーリヤ叫她「清夏ちゃん」（0046）。担心她练过头（0043、0078），约定被记着时有所触动（0056）。被她看穿决心（0060）。说体を休めるのも大切，邀她一起回去（0070）。

## 档案类事实
- 症状：练习中出现呼吸急促、不适（0010、0012）；全力跳、用膝盖的动作是诱因（0015 制作人的话，0016 她答「うん」并补充），用力撑住时也有「ぞわっ」的感觉（0016），几次之后就越来越不舒服（0017）。
- 制作人说除舞蹈外的课她都完成得很好（0004）。
- 制作人说会找メンタルトレーナー商量（0033）。

## 不确定
- 0008、0010 的发作过程没有旁白，只看得到台词，具体发生了什么动作不清楚，是 0015 才说明的诱因。
- 0056 她是否本来担心リーリヤ忘了约定，语气上看不准。
- 0077 リーリヤ说的「急に諦める」具体指哪件事，本篇没说（kllj 笔记同样存疑）。
- 0079 是制作人的括号独白，用的是敬语体，指谁“已经没问题”没有明说。
