# 紫雲清夏 亲爱度剧情 / 第7话（adv_dear_ssmk_007）

- 她的台词：45 行（含用匿名标签说的 0 行）
- 出场的人：清夏、プロデューサー
- 场景：ダンスレッスン中→练完分开后她一个人的地方（具体地点没写），制作人跟了过来
- 世界线：亲爱度（紫雲清夏）；制作人在制作的偶像：紫雲清夏（0079）

## 发生了什么
清夏在舞蹈练习中靠中途休息撑住，当着制作人的面说很顺利，说已经决定不再犹豫。制作人在心里觉得离站上舞台还远，精神上一定也很辛苦（这是制作人的心里话）。练完她道谢后先走，一个人时却叹气，说今天也不行、完全不顺利、给 Pっち添麻烦。制作人其实跟在后面听到了。她说想让他只看到开朗的自己，所以隐瞒；制作人要她多依靠他。她说真正的自己软弱胆小、爱哭，没人想看；又承认其实知道要面对自己才能克服创伤，却只是埋头练习来逃避，说害怕。制作人说她不是一个人，两人一起变强；她开玩笑问是不是求婚，随后说以后不客气地依靠他，要他好好帮她。

## 她的关键台词
- 0013「だいじょーぶ！／もう迷わないって決めたんだし。」——当面时的说法，后面一个人时情况相反。
- 0018「――あ、もしかして、／あたしが可愛いから見惚れちゃった？」——对方一沉默就用玩笑填上。
- 0028「今、こうやって頑張れてるのだって、／ぜんぶPっちのおかげだからね！」——对制作人明确的感谢。
- 0033「今日も、駄目だったなぁ……／ぜんぜん、上手くいかないや……」——独处时的真实状态。
- 0046「Pっちには明るいあたしだけ／見てほしいから、隠してたのに。」——隐藏的动机。
- 0053「……そりゃー、だってさー、／しんどいに決まってるじゃん！」——终于说出辛苦。
- 0054「嫌なわけじゃないけど。／アイドルになるためだしね～。」——辛苦但不是讨厌。
- 0059「あたし、けっこー隠すの上手いと／思ってたんだけどな～。」——对自己“隐藏”的自觉。
- 0062「そりゃ、本当のあたしなんて、／見ても誰も喜ばないからさ。」——核心的自我否定。
- 0063「弱くて臆病で泣き虫で、／すぐ折れそうになるあたしなんか……」——她对“真实的自己”的描述。
- 0068「でも、闇雲にレッスンを頑張って、／現実から逃げようとしてた。」——承认努力也是一种逃避。
- 0069「……怖いんだ。」——说出恐惧。
- 0074「え～、それプロポーズ？」——最认真的时候也用玩笑接话。
- 0078「じゃあ、遠慮しないで頼るから、／ちゃんとあたしのこと、助けてね？」——第一次明说要依靠。

## 行为模式
- 练习不顺时当着制作人 → 说“顺利”“没问题”，用玩笑盖过（0005、0013、0018）；一个人时才说不行（0032～0034）
- 被听到真实心声 → 先笑着说“只是有点沮丧”，被追问后才承认（0043、0045、0053）
- 说出真心之后 → 用玩笑缓和（说是求婚），然后才说出要依靠对方（0074、0076、0078）
- 把话题转到“真实的自己” → 一连串自我贬低（0062、0063）
- 感谢 → 说完自己害羞、马上道别（0028、0030）

## 关系
- 制作人：叫「Pっち」；制作人叫她「清夏さん」（0007、0012）。觉得给他添了很多麻烦（0034、0048），想只给他看开朗的一面（0046）；被他看穿（0058），最后说不客气地依靠他（0078）。对他跟踪回应“这不是跟踪狂吗”，又笑（0039、0041）。

## 档案类事实
- 她说真正的自己软弱、胆小、爱哭、容易折断（0063）。这是她的自我评价。
- 【制作人的心里话，不是她说的】有一段空白期，课题很多，离站上舞台还远（0015、0016）。
- 训练方式：休息的节奏是“变差之前休息”（0003）；制作人说目前只能靠反复练习让身体适应（0006），能跳的时间在变长（0004）。

## 不确定
- 0019、0020 两句之间，以及 0018～0021 的回应是几种选项的并列反应（0019 对肯定的回答，0020 对否定的回答），制作人的话没写。
- 【译文】0055「そう仕向けているのは自分です。」（制作人的话）译文“这是我主动选择的”不准，原意是“让你走到这一步的是我”，所以他有责任支持她。
- 0065 制作人认为她的隐藏也是创伤原因之一，这是制作人的看法；她 0066～0067 接受的是“要面对自己才能克服”。
