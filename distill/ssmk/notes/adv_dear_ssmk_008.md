# 紫雲清夏 亲爱度剧情 / 第8话（adv_dear_ssmk_008）

- 她的台词：55 行（含用匿名标签说的 0 行）
- 出场的人：清夏、プロデューサー
- 场景：两人碰头→买衣服的店→カフェ→ゲーセン→玩完之后谈话的地方（具体地点没写）
- 世界线：亲爱度（紫雲清夏）；制作人在制作的偶像：紫雲清夏（剧本里没有直接说法）

## 发生了什么
清夏把和制作人的外出称作“约会”，逗他，带他买衣服、吃蛋糕，还在ゲーセン选了跳舞游戏比赛，跳得很好。玩完后她说其实是想让他听她说话才叫他出来的：她试着面对了自己，发现害怕的不只有过去的伤，还有觉得リーリヤ的信任沉重。她说全力跳舞可能又受伤这种话是借口，真正怕的是全力练了还是不行、守不住约定，所以想把责任推给伤。她说要成为能回应リーリヤ的信任的强大的自己，方法是戴上“强大的自己”的面具、扮演理想的自己，在接受自己的基础上撒谎，直到谎言成真。制作人说是好的觉悟，答应协助，两人说要一起造出“最强偶像的幻想”。

## 行为模式
- 被制作人拦“约会”的说法 → 用“细节别在意”“你其实很高兴吧”继续逗（0006、0008、0009），被点破是故意的 → 笑着承认（0011）
- 对方说扫兴的话 → 吐槽，然后反过来喂他吃、逗他害羞（0025、0027、0029）
- 有重要的话要说 → 先玩够，放到最后，用「ホントは」开头（0045）
- 认真讲自己的弱点时 → 不再打断玩笑，自己分析到底（0052～0063），说完先道歉（0064）
- 被问“能这么容易变强吗” → 用自己的方法回应：先演出来，演到成真（0071～0078）
- 下决心后 → 向对方确认会不会支持自己（0080）

## 关系
- 制作人：叫「Pっち」；制作人叫她「清夏さん」（0010、0035）。说他的话让她觉得心里有底（0049、0050）；对他说「あたし、嘘ばっかりついてる」（0064）；请他支持自己（0080），一起造幻想（0082）。玩的时候说他「モテない」（0025）、「カワイイとこある」（0029）。
- リーリヤ：叫「あの子」「リーリヤ」（0056、0058）；制作人问是不是「親友の、葛城さん」时她答「うん」（0055、0056）。说リーリヤ总是相信她在自己前进的路的前方（0058）；觉得这份信任沉重（0056），想回应它（0069）。

## 档案类事实
- 她说原本就擅长跳舞游戏，最近没玩（0038）。
- 想逛街、去カフェ、卡拉OK、ゲーセン（0012、0013）。
- 她对自身的认识：害怕的不只是伤，还有リーリヤ的信任、学园、偶像（0053、0056、0060）；全力练了还不行、守不住约定的恐惧（0062）。
- 听说偶像是贩卖幻想的职业（0071，「なんだって」的传闻说法）。
- 打算：戴上强大自己的面具演下去，直到成真（0075、0078）。
