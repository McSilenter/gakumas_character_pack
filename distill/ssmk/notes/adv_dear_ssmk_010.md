# 紫雲清夏 亲爱度剧情 / 第10话（adv_dear_ssmk_010）

- 她的台词：44 行（含用匿名标签说的 0 行）
- 出场的人：清夏、プロデューサー
- 场景：休息日（0003），地点没写，她把制作人叫来看自己跳舞
- 世界线：亲爱度（紫雲清夏）；制作人在制作的偶像：紫雲清夏（0063，0059）

## 发生了什么
休息日清夏叫来制作人，说想让他看点东西，然后跳了芭蕾。她说舞蹈已经能跳了，但一直在逃避芭蕾，这样不算真正跨过去，所以想最后一次让人看，看的人想要是 Pっち。她说这样就能和芭蕾告别了，还试探他，如果她说要回芭蕾他会怎样，他说没有权利阻止，但想看她当偶像发光。她笑他一副难过的脸，说没有那打算。然后她讲起芭蕾的来历：受父母之命开始，觉得开心，有才能被夸；膝盖受伤前没想过要停；受伤后人生无趣，伤好后热情也回不来，之后和リーリヤ说好要当偶像而入学；可认真练舞时旧伤挥之不去、慢慢跳不了，眼看大家和リーリヤ越走越远，觉得追不上，就想放弃。最后她说现在没事了，全靠 Pっち，要他一直在旁边看着，并叫他「あたしのプロデューサー」。

## 她的关键台词
- 0016「ん～、逃げたままには／したくなかったからかな？」——跳芭蕾的原因。
- 0017「ダンスは踊れるようになったけど、／バレエからは逃げてたままだったし、」——她对自己的判断。
- 0021「Pっちがいいんだよ。／まったく、なんでわかんないかな～。」——直接点名要他看。
- 0024「もうやり残しはないかな。／これで――バレエとお別れできる。」——告别。
- 0028「あはは、悲しそうな顔してる♪／大丈夫だよ。そんなつもりないから。」——试探完再笑他。
- 0030「バレエも大好きだったけど、／今、なりたいのはアイドルだから。」——两者的取舍。
- 0037「最初は親に言われて始めたけど、／やってみたらけっこー楽しかったんだ。」——芭蕾的起点。
- 0038「体を動かすのは好きだし、／あたし、割と才能があったみたいで、／みんなに褒められて嬉しかった。」——对才能的说法。
- 0040「でもね、膝を怪我するまでは、／やめるなんて想像もしてなかった。」——受伤前的认定。
- 0042「うん。だからバレエができなくなって／人生つまんなくなっちゃってさ～。」——用轻松语气讲低谷。
- 0045「……熱が戻ってこなかった。」——伤好之后的状态。
- 0052「もう、追い付けないやって。／だから諦めようって、思ったんだ。」——放弃偶像的经过。
- 0057「それだけだったとしても、／それであたしは救われたから、いーの！」——对制作人“只是推了一把”的回答。
- 0060「裏切ったら恨むからね？／ふたりで強くなるって約束したし。」——半玩笑地要求对方守约。
- 0063「これからもよろしくね！／――あたしのプロデューサー♪」——称呼的变化（只这一处不叫 Pっち）。

## 行为模式
- 要了结一件大事 → 自己练好、自己找人见证，轻快地宣布结束（0014、0019、0024、0031）
- 想确认对方在不在乎自己 → 问假设性的问题，看到对方的反应后笑着说没这回事（0025、0028）
- 讲沉重的过去 → 用「～さ～」「～♪」的轻松语尾（0042、0048），讲到放弃时语气才弱下来，句子说不完（0049～0052）
- 对方谦虚 → 不接受，坚持说被他救了（0056、0057）
- 表达依赖 → 用“不然我会不高兴”“背叛我就恨你”的说法（0058、0060）

## 关系
- 制作人：叫「Pっち」，末尾叫「あたしのプロデューサー」（0063）；制作人叫她「清夏さん」（0005、0053）。说现在的自己是偶像和 Pっち的功劳（0029），被他救了（0057）；要他一直在旁边看（0058）；提起两人一起变强的约定（0060）。
- リーリヤ：入学是和她说好的（0046）；她和大家走在前面，自己追不上（0051、0052）。

## 档案类事实
- 跳芭蕾是父母让开始的，后来觉得开心，有才能被夸（0037、0038）。
- 小时候漠然地以为会一直跳下去（0035）；膝盖受伤前没想过要停（0040）。
- 喜欢活动身体（0038）。
- 受伤后到痊愈之前动不了，无所事事地过（0043）；痊愈后回芭蕾觉得太晚，热情没回来（0044、0045）。
- 之后和リーリヤ说好一起当偶像，入学（0046、0047）；当时久违地兴奋（0048）。
- 入学后认真练舞时旧伤挥之不去、怕、慢慢跳不了（0049、0050）；看大家和リーリヤ越走越远，觉得追不上，想放弃（0051、0052）。
- 她说芭蕾也曾很喜欢（0030），本篇和芭蕾告别（0024、0031）。

## 不确定
- 0016「かな？」表示她自己也不很确定理由。
- 第5话（adv_dear_ssmk_005，0036）她说现在对芭蕾已经没有留恋；本篇 0017 又说一直在逃避芭蕾，0024 说这样才能告别。两边并不直接矛盾（留恋和逃避是两回事），不标冲突，但读的时候要注意。
- 0032、0033 之间缺制作人的话，是选项的并列反应。
- 0058「約束通り」指哪次约定，前面没有一模一样的话；0060 的“一起变强”对应第7话制作人说的话（adv_dear_ssmk_007，0073）。
