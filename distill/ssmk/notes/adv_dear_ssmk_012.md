# 紫雲清夏 亲爱度剧情 / 第12话（adv_dear_ssmk_012）

- 她的台词：32 行（含用匿名标签说的 0 行；0083「（え……？）」是括号内的心声，行数照算）
- 出场的人：清夏、四音、友達A、プロデューサー、友達B、クラスメイトA／B、アイドル科の生徒A／B、撫子、？？？（0037、0039 是四音；0040 是撫子）
- 场景：和朋友说话的地方→个人レッスン→练习结束后被搭话（聊到天黑，0065）→打招呼说「おはよ～」的场合（有クラスメイト在，0073 起）
- 世界线：亲爱度（紫雲清夏）；制作人在制作的偶像：紫雲清夏（0008、0058）

## 发生了什么
朋友邀清夏去卡拉OK，她因为有个人练习而拒绝，说自己偷懒的话制作人会闹别扭；走后朋友们说她最近不合群，友達A 说只是有点寂寞，制作人听到了。她对制作人说和朋友玩开心，但练习更重要。练习后，極月学園的白草四音和藍井撫子找上她，说看中她的才能，以特别待遇招揽她。她道谢，但拒绝，说决定了和 Pっち一起变强。四音又提议做朋友，她痛快答应，聊制作人的事聊到天黑。之后她向同学打招呼，大家反应奇怪，她听到有人议论她得意忘形。

## 她的关键台词
- 0007「あ～……ごめん！／あたし、これから個人レッスンでさ。」——为了练习拒绝朋友。
- 0009「うん。あたしがサボると拗ねるから、／ちゃんと行ってあげないとね～。」——对朋友用“为他才去”的说法（制作人 0010 心里说他没闹过别扭）。
- 0012「ほんとごめんね！／カラオケ好きだし、また誘ってよ！」——拒绝的同时留住关系。
- 0029「みんなと遊ぶのも楽しいけどさ、／Pっちとのレッスンの方が大切だから。」——她的优先顺序。
- 0030「アイドルになるって決めたんだから、／サボったりなんて、できないよ。」——和前几话相比的变化。
- 0046「あ、あたしって、そんなに／評価されちゃってる感じなんだ？」——被高度评价时不太敢信。
- 0051「……えっと、ありがとね。／誘ってくれたのはめっちゃ嬉しいよ。」——拒绝之前先道谢。
- 0056「でも、あたしはPっちと一緒に／強くなるって決めたんだ！」——拒绝的理由。
- 0061「それなら全然オッケー！／他校の友達、欲しかったんだ～！」——对陌生人没有戒心地亲近。
- 0064「からかうと、ちょっと照れたりとか、／けっこー可愛いところもあってね――」——高兴地讲制作人。
- 0067「リーリヤ怒ってるかな～。／ごめん、ふたりとも。あたし帰るね！」——回去要面对リーリヤ。

## 行为模式
- 朋友邀约与练习冲突 → 选练习，同时用轻松的理由（他会闹别扭）和“下次再叫我”照顾朋友（0007、0009、0012）
- 别人问起 → 不隐瞒优先顺序：练习更重要（0029、0030）
- 被别处招揽 → 先道谢，然后明确拒绝，说出决定了和谁走（0051、0052、0056）
- 陌生人提出友好 → 很快接受，话题一开就聊到天黑（0061、0063～0065）
- 察觉气氛不对 → 问“怎么了”，对方敷衍时也不追问，只是疑惑（0076、0079、0080）

## 关系
- 制作人：叫「Pっち」，向外人介绍时是「あたしのプロデューサー」（0058）；制作人叫她「清夏さん」（0025）。对朋友说他会闹别扭（0009）；说练习更重要（0029）；背后高兴地讲他（0063、0064）。
- 友達A・B：叫她「清夏」（0005）；邀约她，被拒后觉得她不合群、有点寂寞（0016、0022）。这一话她没有叫对方名字。
- 白草四音・藍井撫子：初次见面；四音叫她「紫雲さん」（0042）。答应做朋友（0061）。
- リーリヤ：担心回晚了她会生气（0067）。
- クラスメイト：向大家打招呼（0073），对方敷衍，她觉得大家奇怪（0080）。

## 档案类事实
