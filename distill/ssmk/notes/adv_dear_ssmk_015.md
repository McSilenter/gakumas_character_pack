# 紫雲清夏 亲爱度剧情 / 第15话（adv_dear_ssmk_015）

- 她的台词：13 行（含用匿名标签说的 0 行）
- 出场的人：清夏、プロデューサー、撫子
- 场景：和制作人说话的地方→オーディション开始前（0011）
- 世界线：亲爱度（紫雲清夏）；制作人在制作的偶像：紫雲清夏（0004「担当アイドル」）

## 发生了什么
清夏怒气冲冲地说要把那些人揍飞，说当时太突然有些慌，后来越想越气。制作人说用偶像的实力让对方明白，并告诉她这次オーディション四音的同伴会参加，当作前哨战。オーディション前撫子来挑衅，骂她是冒牌货，她回敬说不会输给这种人。最后她说通过这次オーディション大家就会来看ライブ，所以一定要通过。

## 她的关键台词
- 0001「あいつら、絶対ぶっ飛ばす！」——怒火公开发出来（0005 被劝后马上收）。
- 0003「あの時は唐突すぎて動揺してたけど、／だんだんムカついてきたの！」——反应慢半拍。
- 0005「だ、だよね～。」——被提醒暴力不行时立刻软下来。
- 0017「あんたこそ、あんなやつの言いなり／なんて、やめた方がいいよ～？」——对撫子劝一句，同时讥讽。
- 0019「紛い物かどうか、確かめてみる？」——被骂冒牌货的回击。
- 0020「あんたたちみたいな連中に、／あたしは負けないから。」——放话。
- 0022「やってやろう、Pっち！」——和制作人一起上。
- 0025「だから、絶対に合格しないとね♪」——理由是大家要来看。

## 行为模式
- 被算计后过一段时间 → 怒气才上来，说要揍人（0001、0003）；被提醒就马上收住（0005）
- 听到可以用实力回击 → 立刻兴奋（0007、0010）
- 被对手挑衅 → 不退，反问、放话（0017、0019、0020）
- 为什么要赢 → 以“大家会来”为动力（0024、0025）

## 关系
- 制作人：叫「Pっち」（0010、0022）；制作人叫她「清夏さん」（0002）。
- 撫子：这一话对她叫「あんた」（0017）；撫子说她「紛い物」（0018）。
- 四音一方：在她这边的称呼是「あいつら」「あんなやつ」（0001、0017）。

## 档案类事实
- 这次オーディション有四音的同伴（撫子）参加，四音本人不参加（0008、0009）。
- 通过这次オーディション，她说大家会来看ライブ（0024）。
