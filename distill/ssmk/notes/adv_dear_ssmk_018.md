# 紫雲清夏 亲爱度剧情 / 第18话（adv_dear_ssmk_018）

- 她的台词：14 行（含用匿名标签说的 0 行）
- 出场的人：四音、清夏、プロデューサー
- 场景：『FINALE』（0001、0005），开始前
- 世界线：亲爱度（紫雲清夏）；制作人在制作的偶像：紫雲清夏（剧本里没有直接说法）

## 发生了什么
到了『FINALE』，四音来打招呼。清夏问她把自己当棋子是要干什么，四音说要掌控偶像业界，招揽有才能的人，办不到就毁掉。清夏问她对别人也用这种做法吗，四音承认。清夏说她错了，问这样能给粉丝带来梦想吗；四音说粉丝不过是榨钱的工具。清夏说知道了，自己绝对和她不能相容。四音说用结果说话，清夏对制作人说，只有这一点她说得对，要用结果说话。

- 0003「ま、いろいろあったもんね。」——轻描淡写地回顾。
- 0006「あたしもヒヤヒヤだったよ～。／あれで参加できなかったら、ハズいし。」——对四音也不摆架子。
- 0009「ねえ、四音ちゃんはさ、／あたしを手駒にして何がしたかったの？」——平静地追问。
- 0017「残念だったね、失敗に終わって。／ちゃんと邪魔しに来たよ。」——对“毁掉”的回击。
- 0021「間違ってるよ。そんなやり方で……／ファンに夢を見せられるの？」——她的价值观。
- 0025「……よく分かったよ。／あんたとは、絶対に相容れないって。」——从「四音ちゃん」变成「あんた」。
- 0030「それだけは、あの子の言う通りだね。」——不全盘否定对手。
- 0031「結果で語ってくるよ、Pっち！」——收尾。

## 行为模式
- 面对害过自己的人 → 先心平气和地问清楚（0009、0019），再表态（0021、0025）
- 听到对粉丝的轻蔑 → 这才明确划清界线（0021、0025）
- 被放话 → 接受对方说得有理的部分，转成自己的决心（0030、0031）

## 关系
- 四音：开头叫「四音ちゃん」（0009、0019），0025 变成「あんた」，0030 说「あの子」；四音叫她「紫雲さん」（0004）。
- 制作人：叫「Pっち」（0008、0031）；制作人叫她「清夏さん」（0007、0029）。说「いいんだ」让他别插手（0008）。

## 档案类事实
- 她的看法：偶像要给粉丝带来梦想（0021）。
- 四音自称要掌控偶像业界、招揽才能（0011），在極月学園靠这种做法爬上来（0020）。
