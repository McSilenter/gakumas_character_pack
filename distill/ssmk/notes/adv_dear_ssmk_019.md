# 紫雲清夏 亲爱度剧情 / 第19话（adv_dear_ssmk_019）

- 她的台词：22 行（含用匿名标签说的 0 行）
- 出场的人：清夏、プロデューサー、四音
- 场景：『N.I.A』胜负揭晓之后、最后的ライブ开始之前（0043），具体地点剧本没写
- 世界线：亲爱度（紫雲清夏）；制作人在制作的偶像：紫雲清夏

## 发生了什么
制作人祝贺清夏获胜，她先是不敢相信，随后才高兴起来（0001～0003）。四音不服，说审查员看错了，清夏回答就算如此这次赢的也是自己（0006～0007）。制作人指出四音特地用舞蹈特化的曲子挑战清夏，这份骄傲就是败因（0011～0012）。清夏接着对四音说，其实感谢对方让她发现自己最近得意忘形、做了些只顾自己方便的事，又说即使邀请是假的，被邀请也高兴；四音骂着放下狠话，她只回了一句再见（0014～0020）。之后制作人说她在还不知道对方真面目时就拒绝了極月学園的邀请，让他高兴；她害羞之后说在制作人身边最安心，那里才是她的归属，还要遵守和リーリヤ的约定，顺带和制作人也有两人一起变强的约定，然后拿“顺带”逗制作人（0021～0042）。制作人催她去『N.I.A』收尾的ライブ，她答应会努力（0043～0044）。

## 她的关键台词
- 0007「仮にそうだとしても、／今回勝ったのは、あたしだから！」——对手否定结果时不争论对错，只把胜利这件事立住。
- 0014「――ねえ、四音ちゃん。／ほんとはあたし、感謝してるんだ。」——赢了之后转向对曾欺骗她的对手道谢。
- 0015「あたしが最近調子に乗ってたり、／都合のいいことやってたのは事実で、」——主动承认自己的问题，不把责任全推给对手。
- 0018「あとね、嘘だったとしても、／あたしを誘ってくれて、嬉しかったよ。」——被人骗了也还记着被邀请的高兴，是真心也是对人的善意。
- 0020「あ……またね～♪」——被对方骂“无能”、放狠话后的回应，轻飘飘地道别。
- 0025「……もしかして、聞いてたの？／うわ、ハズいんだけど！」——私下的决定被制作人知道时先害羞。
- 0027「ここじゃないって、そう思った。」——拒绝邀请的理由不是利弊，而是感觉。
- 0028「やっぱりPっちの隣が一番安心する。／ここがあたしの居場所なんだ。」——明确说出制作人身边是自己的归属。
- 0035「リーリヤとの約束を守らないと。」——说到底她不动摇的另一个理由。
- 0037「ついでに、Pっちとも、／ふたりで強くなるって約束したもんね♪」——把重要的话放在“顺带”的玩笑里说。
- 0041「じょ、冗談だって！／そう拗ねないでよ～！」——逗过头后赶紧哄。

## 行为模式
- 对手不认输、否定结果 → 不和对方争输赢的道理，只说这次赢的是自己（0007）。
- 赢了曾算计自己的人 → 不嘲讽，反而道谢，并承认自己确实有问题（0014～0016、0018）。
- 被对方骂、放狠话 → 不回骂，顿一下后轻轻道别（0020）。
- 自己私下的选择被当面提起 → 先喊难为情，再老实说出理由（0025～0028）。
- 说完真心话 → 立刻转成逗对方、说是开玩笑（0030、0032、0037、0041）。

## 关系
- 四音：她称「四音ちゃん」（0014）；四音称她「お前」（0017），临走骂「無能ども」（0019）。她在赢了之后道谢、道别，没有敌意（0014～0020）。
- プロデューサー：她称「Pっち」（0028、0037）；制作人称她「清夏さん」（0001）。这一篇里她说制作人身边最安心，又不断拿他开玩笑（0028、0030、0032、0041）；两人互相约定一起变强（0037）。
- リーリヤ：她提到和リーリヤ有约定，是她不犹豫的理由之一（0035～0036）。

## 档案类事实
- 她在『N.I.A』胜出，将作为优胜者站上收尾的ライブ（0003、0043）。
- 她拒绝过極月学園的邀请，当时还不知道对方的真面目（制作人说，0023～0024）。
- 她和リーリヤ有约定（内容本篇没写，0035）；和制作人有两人一起变强的约定（0037）。
