# 紫雲清夏 亲爱度剧情 / 第20话（adv_dear_ssmk_020）

- 她的台词：18 行（含用匿名标签说的 0 行）
- 出场的人：清夏、プロデューサー
- 场景：『N.I.A』收尾的ライブ刚结束之后（0001、0011），具体地点剧本没写
- 世界线：亲爱度（紫雲清夏）；制作人在制作的偶像：紫雲清夏

## 发生了什么
ライブ结束，她问制作人怎么样，制作人说最好，尤其舞蹈（0002～0004）。她说以前总有点在意膝盖，今天什么都没想、开心地跳了，身体很轻，像在振翅（0006～0010）。制作人问她自己开心吗，她说开心得不得了，粉丝的声援给了她飞起来的力量（0016～0018）。她问这样下去成为トップアイドル也不是梦吧，制作人说当然，她要制作人也一起努力（0020～0024）。最后她沉默了一下，道谢，被制作人回了“不客气”，她喊本该装没听见，慌着催他走（0027～0031）。

## 她的关键台词
- 0002「Pっち……ど、どうだった！？」——演出后第一件事是问制作人的评价。
- 0006「今までは何だかんだ言っても、／膝が少し気になってたんだけどさ」——说出之前一直残留的在意。
- 0007「今日はね、何にも気にせずに／楽しく踊れた気がする！」——这一次不再在意膝盖。
- 0010「なんかね、体がとっても軽かったんだ。／羽ばたいてるって感じ！」——用身体感觉讲述。
- 0018「ファンのみんなの応援が、／羽ばたくための力をくれたんだ！」——把成功归给粉丝。
- 0020「ねえねえ、この調子なら、／トップアイドルも夢じゃないよね！？」——顺势说出更大的目标，是向制作人求确认的问法。
- 0024「なーに言ってんの？／Pっちも一緒に頑張るんだよ！？」——不让制作人站在一边。
- 0028「でも、ほんっと……ありがと。」——沉默后才说的道谢。
- 0030「そこは聞こえないフリしときなよ！？」——道谢被接住反而害羞。

## 行为模式
- 演出刚结束 → 马上问制作人的评价（0002）。
- 被问感受 → 用身体感觉、拟态的说法讲（0010、0017）。
- 被肯定 → 先得意地接下，再把话题推向下一个目标（0012、0020、0022）。
- 制作人说得太事不关己 → 马上抗议，要他一起（0024、0026）。
- 想道谢 → 先沉默，再说出口，被回应后用吐槽和催促盖过去（0027～0031）。

## 关系
- プロデューサー：她称「Pっち」（0002、0024）；制作人称她「清夏さん」（0001）。她把努力说成两个人的事，要他一起（0024），并道谢（0028）。
- 粉丝：她说粉丝的声援给了她力量（0018）。

## 档案类事实
- 她此前一直有点在意膝盖，这次ライブ什么都不在意地跳了（0006～0007）；制作人说完全克服了，她自己的回答是也许吧（0008～0009）。
- 这次是她到此为止观众最多的ライブ（制作人说，0015）。

## 不确定
- 0008 制作人说完全克服，她只回「そうなのかも！」，她自己是否认定已经克服，这里不好下结论；第21话 0055、0058 制作人又谈到她因心理阴影避开给右膝加负担的动作、练舞时容易摔倒，那里是往回说的，和这里是否矛盾未定，留待统一看。
