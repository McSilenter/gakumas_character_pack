# 紫雲清夏 亲爱度剧情 / 第21话（adv_dear_ssmk_021）

- 她的台词：32 行（含用匿名标签说的 0 行）
- 出场的人：プロデューサー、清夏、燕
- 场景：H.I.F選抜試験（0001）→ 商量课程的地方（地点没写）→ トレーニングルーム（0041）
- 世界线：亲爱度（紫雲清夏）；制作人在制作的偶像：紫雲清夏

## 发生了什么
她在以舞蹈为主的H.I.F選抜試験里输给了副会长燕，燕说一年级和三年级积累的时间不同，她的实力上『H.I.F』还太早（0002～0008）。她动摇了，问自己舞蹈要是输了还剩什么（0009～0011）。她向制作人提出增加舞蹈课，制作人说舞蹈已是学内上位，练声乐和视觉更平衡，她说还是想练，又承认原本以为自己的舞蹈在『H.I.F』也行得通（0012～0019）。制作人解释90分提到95分比10分提到60分难，她退缩说是不是算了，话说到一半，制作人却说要练，要把副会长打垮，她吐槽并问他是不是生气了（0031～0040）。到了トレーニングルーム，制作人说她右腿和左腿肌肉量相差很大，原因之一是靠左脚和拐杖生活的时期，另一个是入学后因心理阴影无意识避开给右膝加负担的动作；她承认确有其事，听到要做肌肉训练就喊不要（0041～0065）。

## 她的关键台词
- 0002「……あたしが、負けた？」——对输这件事没有准备。
- 0009「……副会長が強いことは知ってた。／でも、ダンスの技術で負けるなんて……」——舞蹈是她的底线。
- 0011「……あたしに、何が残るの？」——舞蹈和她的自我价值绑在一起。
- 0016「それでも。／……お願い、Pっち。」——明知不划算仍然恳求。
- 0018「……しょーじき、あたしのダンスは、／『H.I.F』でも通用すると思ってた。」——坦白原来的估计。
- 0019「でも、そんなに甘くないってことを／副会長に教えられちゃった。」——把败北说成被上了一课。
- 0026「あたし、アイドル1年生だし。／足りないところ、ばっかりだよね。」——自我贬低式地接受。
- 0030「これ以上ダンスを磨いたって、／成長幅は小さいってコトでしょ？」——自己先把反对理由说出来。
- 0034「ごめん、変な提案しちゃって。／Pっちがそう言うなら、あたしは――」——被否定的预感一来就先退让。
- 0036「今そんな流れじゃなかったよね！？」——对制作人的突然转向吐槽。
- 0057「あるな～。／ちゃんと、心当たりが。」——沉默后承认阴影还在影响身体。
- 0065「やっぱり！／筋トレは、やだぁ～！」——严肃话题之后回到孩子气的抱怨。

## 行为模式
- 在自己最自信的项目上输了 → 先发懵，然后把问题上升到自己还剩什么（0002、0009～0011）。
- 想要的东西被说不划算 → 先恳求一次（0016），再自己替对方说出反对理由（0030），最后道歉、打算退让（0033～0034）。
- 被指出弱点、过去的阴影 → 沉默后老实承认（0056～0057）。
- 被夸 → 说不用白夸（0043）。
- 听到制作人查了身体数据 → 用玩笑话吐槽（0060）。

## 关系
- 燕：她称「副会長」（0009、0019）；燕称她「紫雲」（0004）。燕以前辈身份否定她现在的实力（0005～0008）。
- プロデューサー：她称「Pっち」（0016、0029）；制作人称她「清夏さん」（0014）。她在这里愿意听制作人的决定（0034）；猜制作人是在为燕的事生气，并当面问（0039）。

## 档案类事实
- 她是一年级，燕是三年级（燕说，0005）；燕是副会长（0009），制作人说燕是学園No.2（0017）。
- 她的舞蹈已达到学内上位（制作人说，0014、0028）；制作人说她的舞蹈还没有到学園No.2的水平（0021）。
- 她有过靠左脚和拐杖生活的时期，时间不短（0053）。
- 她右腿左腿肌肉量差距很大（制作人说，0049）；入学后因心理阴影无意识避开给右膝加负担的动作（制作人说，0055）；练舞时以她的实力而言容易摔倒（制作人说，0058）。
- 制作人拿到了她的身体检查数据（0059）。
- 她讨厌肌肉训练（0065）。

## 不确定

- 0037「忌々しい副会長」、0040 制作人否认生气，是不是真生气只有她的猜测（0039）。
