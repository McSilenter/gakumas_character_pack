# 紫雲清夏 亲爱度剧情 / 第22话（adv_dear_ssmk_022）

- 她的台词：35 行（含用匿名标签说的 0 行）
- 出场的人：清夏、プロデューサー、リーリヤ
- 场景：トレーニングルーム（0040～0041）；0064 起的对话是否还在同一处本篇没写
- 世界线：亲爱度（紫雲清夏）；制作人在制作的偶像：紫雲清夏

## 发生了什么
她抱怨连日只有枯燥的肌肉训练、完全没有干劲，制作人说要用“干劲剂”，带来的是リーリヤ（0001～0023）。制作人安排今后一段时间两人一起上课，リーリヤ说想和她一起练，她只好答应认真做（0024～0038）。她告诉リーリヤ肌肉训练又苦又没意思，リーリヤ却说也想做（0043～0045）。制作人说给リーリヤ准备了合适的菜单，她看了觉得比自己的有意思（0047、0054）。她向リーリヤ解释，这种训练不会马上见效，所以夏天的『H.I.F』放弃了，冬天之前磨练舞蹈做出结果，这是她和制作人两人决定的（0065～0066）。她还在喊累，リーリヤ说自己也在旁边努力，她应了一声（0068～0072）。剧情经过参照 kllj 笔记。

## 她的关键台词
- 0001「はぁ……ダル～～～い。」——开场的状态。
- 0005「Pっちはあたしをムキムキに／するつもり？」——用玩笑抱怨。
- 0012「理屈でやる気が出たら、／苦労はしませーん。」——明白道理但承认动不起来。
- 0015「それって……咲季っちのSSDとか／じゃないよね？」——对其他偶像的称呼方式。
- 0029「なんか、Pっちとの会話をリーリヤに／聞かれるの、ハズいんだけど……」——两人的相处方式被好友看见时害羞。
- 0030「てか、リーリヤはそれでいいの？」——被安排时先替对方考虑。
- 0032「……そ、そぉ？／なら、いいケド……」——听到对方想和自己一起练，语气软下来。
- 0038「……Pっちの思い通りなのは癪だけど、／レッスンの続きやるかぁ～！」——不服气地答应。
- 0044「辛いし苦しいし、何より面白くないし、／めっちゃしんどいよ～？」——抱怨的口气。
- 0065「すぐに効果が出るレッスンじゃない／から、夏は見送ったんだ。」——一边抱怨，一边把选择讲得清楚。
- 0066「冬までにダンスを磨いて、結果を出す。／ふたりで、そう決めたの！」——说明这是自己和制作人的共同决定。
- 0070「リーリヤはあたしに厳しいなぁ……」——被好友反过来管。

## 行为模式
- 枯燥的训练 → 嘴上一直抱怨，但理由自己都知道（0011～0012、0068）。
- 被制作人当众耍 → 吐槽，大声抗议（0023、0025、0027），最后不服气地继续（0038）。
- 被安排带上别人 → 先问对方愿不愿意（0030）。
- 对方说想和自己在一起 → 马上语气变软（0032）。
- 被问到为什么放弃比赛 → 这时不抱怨，清楚说明决定的理由（0065～0066）。

## 关系
- リーリヤ：她称「リーリヤ」（0021）；リーリヤ称她「清夏ちゃん」（0020）。她在リーリヤ面前有点难为情（0029），被リーリヤ管住（0070）；リーリヤ说她抱怨的时候反而会认真做（0060）。制作人称两人为挚友（0061）。
- プロデューサー：她称「Pっち」（0029、0038）；制作人称她「清夏さん」（0002）。她一边抱怨被摆布，一边称赞他安排得当（0034、0048）。
- 咲季：她称「咲季っち」，提到咲季的 SSD（0015）。

## 档案类事实
- 她有一段时间一直只做肌肉训练（0004、0043）。
- 她没有参加夏天的『H.I.F』，是因为训练不会马上见效，和制作人决定以冬天为目标（0065～0066）。
- リーリヤ说她在抱怨别人的时候会好好做事（0060）。

## 不确定
- 【冲突】这一篇她说夏天没出场『H.I.F』是自己的决定（0065「すぐに効果が出るレッスンじゃない／から、夏は見送ったんだ。」，0066 又说是两人决定的）；第21话 0001～0008 她在H.I.F選抜試験里输给燕，燕说她实力还太早，第31话 0090 制作人明说是夏天的选拔输了。选拔落败（没资格出场）和主动放弃夏天，这两种说法之间怎么衔接本线没有说明，先按原样保留。
- 0066「ふたりで」本篇没有写谁和谁；按上下文是她和制作人。
- 0054 她说リーリヤ的菜单看着开心，菜单内容本篇没写。
