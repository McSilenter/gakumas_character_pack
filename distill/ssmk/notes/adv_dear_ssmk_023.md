# 紫雲清夏 亲爱度剧情 / 第23话（adv_dear_ssmk_023）

- 她的台词：24 行（含用匿名标签说的 0 行）
- 出场的人：リーリヤ、清夏、プロデューサー
- 场景：地点本篇没写；她在数着数训练（0001），之后教リーリヤ练习（0046 起）
- 世界线：亲爱度（紫雲清夏）；制作人在制作的偶像：紫雲清夏

## 发生了什么
她数着数训练时，看到リーリヤ练习不顺、失落，上前问她（0001、0014～0016）。她说制作人好像有点客气，于是让リーリヤ也依靠自己，引用的是之前说过的全力依靠的话（0019～0023）。リーリヤ说不知道该怎么努力、请她帮忙，她立刻答应并说要拉上制作人，还对リーリヤ说自己也曾在黑暗中迷路，是制作人帮了她（0031～0036）。她向制作人宣布要帮リーリヤ上课、肌肉训练也不偷懒，制作人同意（0039～0045）。她教リーリヤ时全靠拟声词，リーリヤ完全听不懂；经制作人提醒后她改用具体的说法，リーリヤ做到了，她说头好累（0047～0062）。她对“教练”这个词很满意，又鼓起劲做肌肉训练（0065～0066）。剧情经过参照 kllj 笔记。

## 她的关键台词
- 0016「リーリヤ、落ち込んでる？」——直接去问。
- 0019「そっかぁ。う～ん……Pっちも、／ちょっと遠慮してるっぽいからな～。」——看出制作人的顾虑。
- 0020「……よ～し！　分かった！／リーリヤ！　あたしに任せて！」——把别人的事揽下来。
- 0022「この前、全力で頼っていくって、／そう言ったでしょ？」——用“我说过要依靠你”反过来让对方依靠自己。
- 0023「だから、リーリヤもあたしに頼って？」——要求对等。
- 0034「……大丈夫。あたしもさ、／ずっと暗闇の中で迷子になってて……」——用自己的过去来安慰。
- 0035「あの人が助けてくれたんだ。」——在好友面前对制作人的评价。
- 0040「もちろん、筋トレもサボらずに／やるからさ！　……いいでしょ？」——先把条件讲好，再撒娇式地问。
- 0049「ぎゅーんってやって、ぐいってやって、／ピタって止まる感じだよ！」——她教人的方式。
- 0052「む、難しいね。／人に教えるって……」——自己也承认。
- 0058「もっと、背筋を伸ばして、全身で、／一本の線みたいに……そうそう！」——提醒后能改成具体说法。
- 0065「コーチ、良い響きだね！」——对这个称呼很高兴。

## 行为模式
- 看到朋友独自沮丧 → 不等求助就去问，揽下来（0014、0016、0020）。
- 朋友犹豫要不要麻烦别人 → 拿自己的经历做保证（0034～0036）。
- 要加自己的事 → 先保证原来的事也不耽误（0040）。
- 教别人动作 → 第一反应用拟声词（0047、0049），被指出后认错，再换说法（0056、0058）。
- 被派了个新名号 → 马上开心，提起劲头（0065～0066）。

## 关系
- リーリヤ：她称「リーリヤ」（0016）；リーリヤ称她「清夏ちゃん」（0024）。她主动提出帮忙并答应リーリヤ的求助（0030～0031）。
- プロデューサー：她称「Pっち」（0019），对リーリヤ说起时称「あの人」（0035）；制作人称她「清夏さん」（0051）。说他帮自己走出黑暗（0034～0035）。

## 档案类事实
- 她曾长期在黑暗中迷路一般，是制作人帮了她（她自己的说法，0034～0035）。
- 制作人的心里话：她是感觉派，不太擅长把技术说成语言（0059）；把动作说成语言也会让模糊的东西变清楚（0060）。这两条是制作人的心里话，不是她本人说过的。
- 她答应继续做肌肉训练，同时帮リーリヤ上课（0040、0064）。
