# 紫雲清夏 亲爱度剧情 / 第24话（adv_dear_ssmk_024）

- 她的台词：19 行（含用匿名标签说的 0 行）
- 出场的人：清夏、プロデューサー、リーリヤ
- 场景：开始肌肉训练约两个月后（0001），地点没写；之后是ライブ当天（0036）
- 世界线：亲爱度（紫雲清夏）；制作人在制作的偶像：紫雲清夏

## 发生了什么
制作人问约两个月的肌肉训练有没有变化，她说好像更好跳了，但没太多实感（0001～0004）。制作人突然说要出ライブ，リーリヤ拿来SNS，告知已经发布（0011～0015）。她看到粉丝的反应在迅速扩散，也发现有人知道她跳芭蕾的事、芭蕾的影像也传开了（0020～0028）。她说现在已经不打算隐瞒，但明白大家期待的是她的舞蹈，说要回应期待（0030～0035）。ライブ当天，舞蹈的质量明显提升，她的气氛却僵硬；制作人的心里话这样说，リーリヤ说她像回到了从前跳芭蕾时那样专注而紧绷（0038～0044）。两人同时都认为她的舞蹈很厉害（0046～0048）。剧情经过参照 kllj 笔记。

## 她的关键台词
- 0002「……なんか、前より踊りやすいかも？」——实感是很淡的。
- 0012「いきなりすぎない！？」——对制作人先斩后奏吐槽。
- 0017「サプライズが多すぎるってば！」——同上。
- 0021「すごい勢いで、拡散されてる……／こんなに、みんな、あたしのことを……」——直面粉丝的规模。
- 0026「あたしのバレエのこと、／知ってる人もいるんだね。」——过去被翻出来时的反应。
- 0030「……ううん、別にいいんだ。／今はもう、隠すつもりないし。」——对芭蕾过去的态度已经和以前不同。
- 0032「――あたしの、ダンスに。」——明白期待的方向，转折点。
- 0034「期待には、応えなきゃいけないよね。」——“应该”的口气，开始把期待当义务。
- 0035「久しぶりのライブ、頑張るよ！」——当面仍是开朗的样子。

## 行为模式
- 被突然塞来工作 → 先吐槽（0012、0017），不拒绝。
- 看到大家对她的舞蹈有期待 → 把它当成必须回应的东西（0031～0034），表面仍然开朗（0035）。
- 过去的事被公开 → 说现在不隐瞒（0030）。

## 关系
- プロデューサー：她称「Pっち」（0007）；制作人称她「清夏さん」（0033）。
- リーリヤ：本篇她没有称呼リーリヤ；リーリヤ称她「清夏ちゃん」（0013）。リーリヤ说起她从前跳芭蕾时的样子（0042～0044）。

## 档案类事实
- 她做肌肉训练约两个月后，舞蹈的稳定感增加（制作人说，0001、0003）。
- 她在『N.I.A』优胜后关注度上升，过去的芭蕾影像在网上传开（0028～0029）；有报道标题『神童バレリーナ、アイドルになる』（リーリヤ念出，0027）。
- 跳芭蕾时的她认真、专注，带着让人难以接近的紧绷气氛（リーリヤ说，0042～0043）。
- 她现在不打算隐瞒芭蕾的过去（0030）。
- 这是隔了一段时间才开的ライブ（0035、0037）。

## 不确定
- 0029 制作人回答之后，0030 她说「……ううん、別にいいんだ」，前面像是被问了什么或担心什么，这里接得不是很顺，可能省略了制作人的选项。
- 0040 リーリヤ说她回到了从前，这里是好事还是坏事，本篇没说；制作人的心里话说她气氛僵硬（0039）。
