# 紫雲清夏 亲爱度剧情 / 第25话（adv_dear_ssmk_025）

- 她的台词：44 行（含用匿名标签说的 0 行；0001～0004、0006 是她的心声独白）
- 出场的人：清夏、手毬、プロデューサー
- 场景：ライブ会场（0001～0008）→ ライブ之后和制作人谈话 → 和手毬说话（地点没写）
- 世界线：亲爱度（紫雲清夏）；制作人在制作的偶像：紫雲清夏

## 发生了什么
ライブ上她想着要按大家的期待来，结束后觉得观众好像不太热烈（0001～0008）。制作人说舞蹈完美、肌肉训练有成效，却问她开心吗，她被要求老实回答后说不太开心（0010～0016）。制作人说原因是她太乖，在舞台上也在意别人，希望她更任性，建议她去找手毬商量（0018～0035）。她把制作人的话告诉手毬，手毬不想答，她马上替手毬说这种事谁都会为难，手毬却说这正是她的问题（0039～0047）。手毬用豚骨拉面点到味噌拉面作比喻，说她的ライブ不是想要的东西，只有舞蹈厉害；她马上想增加能一起跳的曲子，手毬问她到底想怎样、是不是迷失了自己（0048～0057）。她这才意识到自己可能真的太乖（0059～0064）。她问手毬怎样才能任性，手毬说照自己想的做，她当场说出“我在教室里照顾气氛都是因为手毬っち”（0078～0086）。剧情经过参照 ttmr 笔记。

## 她的关键台词
- 0004「あたしは、みんなが望む通りに――」——登台时的出发点。
- 0007「あたし、ちゃんとみんなの期待に、／応えられたかな……？」——评价标准在别人身上。
- 0015「あんまり……楽しく、なかった。」——第20话那种开心不见了，被追问才说。
- 0019「あたしが……良い子すぎる！？」——被说太乖的震惊。
- 0020「ギャルなのに！？」——对自我形象的认定。
- 0044「いきなりこんな相談されたって、／フツー困るよね。」——立刻替拒绝自己的人着想。
- 0052「……あたしに求められてるのって／それだけじゃ、ないもんね。」——听到批评后仍在想别人要什么。
- 0053「アップテンポで、一緒に踊れるような／感じの曲を増やせば、もっと……」——同上，马上转向迎合的办法。
- 0062「めちゃくちゃ良い子だったのかな！？」——把意识到的事当成笑话讲。
- 0066「多少の気遣いは誰でもするでしょ？」——她认为这是普通的事。
- 0078「……ねえ、手毬っち。／わがままになるって、どうやるの？」——认真问“任性”的做法。
- 0084「あたしが教室で気を遣ってるのは、／手毬っちのせいなんだけど！」——学着任性的第一句就是吐槽。

## 行为模式
- 上台前 → 以回应大家的期待为出发点，告诉自己没问题（0003～0004）。
- 演出之后 → 先问对方评价、在意观众反应（0005、0007～0008）。
- 被问是否开心 → 先愣住，被要求老实回答才说出来（0013、0015）。
- 别人不愿回答她 → 立刻附和对方，替对方找理由（0043～0044）。
- 听到批评 → 第一反应是怎么修正好让别人满意（0052～0053）。
- 被鼓励说出想法 → 把一直憋着的吐槽说出来，半开玩笑地（0082、0084、0086）。

## 关系
- プロデューサー：她称「Pっち」（0026）；制作人称她「清夏さん」（0012）。她抱怨制作人净说些随便的话（0036），但还是照他的建议去找手毬。
- 手毬：她称「手毬っち」（0038）；手毬称她「清夏」（0069）。手毬直说她过度照顾别人（0069）、照她的话“杀掉自己”就发不出光（0072）；她被说得直接，但认真问手毬怎么任性（0073、0078）。

## 档案类事实
- 这次ライブ的观众比『N.I.A』优胜ライブ时还多（她的心声，0002）。
- 她自称ギャル（0020）。
- 制作人说她总是在意别人（0022）；制作人的心里话：她没有自觉，是因为一直这样活过来（0025，这是制作人的心里话）。
- 手毬说她在教室里会留意不把气氛搞坏（0065）。她说自己在教室里照顾气氛是因为手毬（0084）。
- 手毬看过她的ライブ，说舞蹈很厉害，别的不合口味（0048～0051）。
