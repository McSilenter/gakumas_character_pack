# 紫雲清夏 亲爱度剧情 / 第26话（adv_dear_ssmk_026）

- 她的台词：36 行（含用匿名标签说的 0 行；0002～0003、0005～0006 是她为了试着“任性”故意摆的态度，见 0008，不当本心）
- 出场的人：清夏、プロデューサー
- 场景：地点没写
- 世界线：亲爱度（紫雲清夏）；制作人在制作的偶像：紫雲清夏

## 发生了什么
她回来就对制作人恶声恶气，马上又露馅，解释这是在试着任性，还给爸爸发了讨厌他的消息、在教室里忍着没帮手毬圆场（0002～0011）。制作人说这叫迷走，她的问题是生存方式：她害怕别人，因为不想背叛别人，也知道背叛后会被怎样对待（0015～0023）。她承认自己害怕，并说出以前曾有一点安心，以为这下没人会再期待她、不被期待就不会失望，可是她找到了偶像，又想再跑一次（0027、0032～0036）。制作人说她理想中的紫雲清夏不该由别人决定，希望她能超越预期是场面话，真心是希望她的偶像人生幸福（0037～0047）。她说那样会让人误会，然后说想成为能鼓励从前的自己那样的孩子的偶像（0048～0054）。她说制作人不在身边自己就不会幸福，制作人改口说要让她幸福，她慌乱后答「はい」（0058～0062）。她提出第一个任性：和リーリヤ一起站上『H.I.F』的舞台（0063～0065）。

## 她的关键台词
- 0008「わがままになるって、／こんな感じじゃないの？」——说明前面都是装的。
- 0009「パパにも嫌いってチャットしといたし。」——把“任性”想成对亲近的人说坏话。
- 0011「手毬っちが教室で悪口言った時も、／フォローしないように我慢したんだ！」——连任性都要努力忍着做到。
- 0024「『N.I.A』優勝でファンが増えたことは／分かってたつもりなんだけど……」——她承认自己只是自以为明白。
- 0027「――怖いんだ、あたし。」——终于承认害怕。
- 0032「多分ね、あたし……今まで、／ちょっとだけ、安心してたんだ。」——承认曾有过的软弱。
- 0033「これでもう、誰もあたしに期待しない。／期待されなければ、失望されない。」——这一段的核心心理。
- 0034「でも、アイドルを見つけた。／もう一度走りたいって、思っちゃった。」——转折。
- 0048「……やめてよ。勘違いするじゃん。」——被制作人的真心话触到时的反应。
- 0054「そんなアイドルに、なりたい。」——说出自己想成为的偶像（紧接 0052～0053）。
- 0058「Pっちが隣にいないと、／あたしは幸せになれないからね？」——把幸福和制作人绑在一起说。
- 0065「あたしは……リーリヤと一緒に、／『H.I.F』のステージに立ちたい！」——第一个任性。

## 行为模式
- 被要求“任性” → 把它当课题来努力完成，用做作的方式演出来（0002～0011）。
- 被说中害怕 → 沉默，然后自己把害怕说出口（0021、0027）。
- 谈到过去 → 先说“大概”“一点点”，往轻了说（0032），末尾自嘲（0036）。
- 对方说出太直接的话 → 先说别这样，会误会，再直接追问（0048～0049）。
- 被告白式的话击中 → 语无伦次，然后老实回答（0061～0062）。
- 得到许可去任性 → 第一件事是和リーリヤ有关（0063～0065）。

## 关系
- プロデューサー：她称「Pっち」（0005、0058）；制作人称她「清夏さん」（0004）。这一篇他说要让她幸福，她答应（0060～0062）。
- パパ：她称「パパ」，发了讨厌的消息，制作人说请别这样（0009～0010）。
- 手毬：她称「手毬っち」，在教室里她忍着没帮手毬说话（0011）。
- リーリヤ：她第一个“任性”就是和リーリヤ一起站上舞台（0065）。

## 档案类事实
- 她害怕别人，害怕的原因是不想背叛别人（制作人说，0020～0022；她自己只承认害怕，0027）。
- 她曾有过一段时间，因不再被期待而有点安心（0032～0033）。
- 她想成为能鼓励从前的自己那样的孩子的偶像（0053～0054）。
- 她有爸爸，能用聊天工具联系，她称「パパ」（0009）。
