# 紫雲清夏 亲爱度剧情 / 第28话（adv_dear_ssmk_028）

- 她的台词：57 行（含用匿名标签说的 0 行）
- 出场的人：清夏、プロデューサー、星南
- 场景：地点没写；组成团体、练习进行中的时期（0002～0004）
- 世界线：亲爱度（紫雲清夏）；制作人在制作的偶像：紫雲清夏

## 发生了什么
她说练习顺利，制作人一反常态认真说这是两人一起努力的结果，她害羞又问他为什么这么严肃，甚至以为是要分手（0003～0021）。制作人回顾两人一路的经过：开口邀请、她“试着”接受制作、重新以偶像为目标、克服受伤的心理阴影、ファーストライブ、『N.I.A』优胜、选拔败给副会长后练舞蹈和肌肉、ライブ上的问题（0024～0076）。她在回顾中说是他贴近她的心情才重新站起来，说自己就要他、别人不行，又说以前的问题是想回应期待而迷失了自己，现在变得任性了（0031～0036、0078～0080）。她坚持把上一话的话说成“求婚”，制作人否定（0081～0084）。最后制作人说星南在电视上的ライブ让冬天的『H.I.F』变成决定トップアイドル的大赛，让她放心交给自己（0091～0103）。

## 她的关键台词
- 0005「元から周りに合わせるのは、／けっこー得意だからね！」——她的自我认识，和第25话的问题相关。
- 0021「えっ、別れ話ってコト！？」——严肃气氛下的第一反应是开玩笑。
- 0031「Pっちがあたしの気持ちに寄り添って／くれたから、立ち直れたの！」——不让他把这一段带过。
- 0034「Pっちが完璧な人だったら、／きっとあたしの心には響かなかったよ。」——为什么是他。
- 0036「だから、あなたがいいんだ。／あなた以外の誰かなんて、あたしは嫌。」——最直接的告白式发言。
- 0037「……って、なんてこと言わせるわけ！？」——说完马上推给对方。
- 0052「……もし事前に伝えられてたら、／あたしは逃げちゃったかもしれない。」——承认当时的软弱。
- 0055「ライブが成功したおかげで、／ちゃんとバレエともお別れできたし。」——对芭蕾的告别。
- 0066「あの時、ちゃんと決めたから。／もう、ふたりに隠しごとはしないって。」——她的决心。
- 0078「みんなの期待に応えようとしすぎて、／自分を見失ってた。」——她对第25话状态的总结。
- 0080「悪い子になったんだ、あたし！」——把变化说得像玩笑。
- 0088「あなたが傍にいてくれるなら、／あたしはもう大丈夫！」——关键时刻改用「あなた」。

## 行为模式
- 制作人认真说话 → 慌张，说他不对劲，开玩笑（0013、0018、0021）。
- 回顾重要往事 → 不让对方带过，自己把重点说清楚（0030～0031）。
- 对方道歉或害羞 → 反过来说他应该接受（0033～0036）。
- 说完太直接的话 → 马上推给对方（0037）。
- 被说成是对方的功劳 → 说感谢的应该是自己（0069）。
- 想用某种说法定性 → 对方否认也继续坚持（0081、0083）。

## 关系
- プロデューサー：她称「Pっち」（0001），重要处称「あなた」（0036、0088）；制作人称她「清夏さん」（0002）。她说是他贴近她的心情才让她站起来（0031），并说只要他、别人不行（0036）。
- リーリヤ：她说这次不偷懒是因为リーリヤ在旁边（0074），要和リーリヤ一起拿『H.I.F』优胜（0089）。
- 咲季：她称「咲季っち」（0096），听说和星南一起特训（0096）。
- 星南：制作人称「十王さん」（0091）；她在电视上看了ライブ（0092、0095）。

## 档案类事实
- 这是她第一次组团；她跳芭蕾时常和很多人一起，本来擅长配合别人（0004～0005）。
- 制作人开始找她时，樱花快要落了（0024）；当时她是没干劲的不良学生（制作人说，0026）；她“试着”接受了制作（0028）。
- ファーストライブ是当天才通知她的（0048），她说如果事先知道，可能会逃（0052）。
- ファーストライブ成功后她能和芭蕾好好告别（0055～0056）。
- 『N.I.A』里她和白草さん对战，受到盘外战术的折磨（制作人说，0060）；她说自己精神上受了打击，是制作人和リーリヤ帮了她（0062～0063）。
- 星南的ライブ在电视上播（0092），咲季和星南有特训（她说，0096）。冬天的『H.I.F』被制作人说成决定トップアイドル的大赛（0098～0099）。
