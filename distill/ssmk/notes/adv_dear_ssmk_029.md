# 紫雲清夏 亲爱度剧情 / 第29话（adv_dear_ssmk_029）

- 她的台词：25 行（含用匿名标签说的 0 行）
- 出场的人：リーリヤ、清夏、プロデューサー
- 场景：和リーリヤ练习（0001～0016）→ 制作人单独找她（0017）→ 和リーリヤ（0041 起），地点都没写

## 发生了什么
她带リーリヤ练习，リーリヤ出错时她说没关系、一点点改，接着说要结束，让リーリヤ别练过头（0004～0015）。制作人单独问她有没有看到『REVERSI』结成发表后的反应，她说看到对リーリヤ的负面反应，认为リーリヤ嘴上不说、心里在意，自己的粉丝反对两人组队她有点难过（0022～0028）。制作人说粉丝只是想知道リーリヤ配不配在她身边，要告诉他们的还有两人的关系和组团的经过（0029～0039）。之后リーリヤ主动说自己不在意、是清夏粉丝的反应早有预料，并说要让他们喜欢上自己；她说交给她，会让大家知道葛城リーリヤ是最棒的偶像（0041～0057）。剧情经过参照 kllj 笔记。

## 行为模式
- 朋友出错 → 不责备，说时间还多，一点一点改（0004～0005）。
- 朋友想继续练 → 叫停，不让练过头（0013、0015）。
- 发现别人对朋友的恶意 → 自己先难过，同时猜朋友的感受，不当面说（0023～0024、0028）。
- 被朋友点破自己在照顾她 → 马上承认（0043）。
- 朋友表明决心 → 用“交给我”接住（0056～0057）。

## 关系
- リーリヤ：她称「リーリヤ」（0005），也用全名「葛城リーリヤ」（0057）；リーリヤ称她「清夏ちゃん」（0012）。她说两人是挚友和青梅竹马（0037）；リーリヤ自称是她最忠实的粉丝（0046）。
- プロデューサー：她称「Pっち」（0017）；制作人称她「清夏さん」（0018）。
- 她的粉丝：她为粉丝反对组团难过（0028）。

## 档案类事实
- 她和リーリヤ的团体叫『REVERSI』，结成已通过SNS等发表（制作人说，0020）。
- 她在『N.I.A』优胜后粉丝大增，和リーリヤ的粉丝数差距极大（0026～0027）。
- 她和リーリヤ是挚友、青梅竹马（0037）。
- 制作人的心里话：她把技术说成语言的能力变好了，リーリヤ在她当教练后明显进步（0008～0009，这是制作人的心里话）。
