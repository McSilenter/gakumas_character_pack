# 紫雲清夏 亲爱度剧情 / 第32话（adv_dear_ssmk_032）

- 她的台词：75 行（含用匿名标签说的 0 行）
- 出场的人：清夏、リーリヤ、プロデューサー、燕、ファンA～D
- 场景：选拔考试结果揭晓（0001～0029）→『REVERSI』2ndライブ舞台（0038 起）
- 世界线：亲爱度（紫雲清夏）；制作人在制作的偶像：紫雲清夏

## 发生了什么
她和リーリヤ在选拔考试中胜过燕，确定进入『H.I.F』本赛；她对燕说想成为用舞蹈鼓励别人的偶像，燕认输并宣告优胜的会是自己（0001～0025）。制作人提议本赛前办2ndライブ，安排她说出秘密，她道谢并答应（0031～0037）。2ndライブ上她先讲小时候学芭蕾、留学瑞典、遇到リーリヤ、右膝受重伤回日本、从电视上的偶像得到勇气、在初星学園的ライブ后和リーリヤ约定（0044～0068）。讲到隐瞒的部分时她说不下去，リーリヤ上台站到她身边（0072～0089）。她说出受伤变成心理阴影、练舞时害怕到想吐、因受不了信任而假装忘了约定，又说支持她的人让她重新努力，已经克服，如今能回应期待（0090～0104）。她说心碎时来看她的ライブ，粉丝们声援，她流泪并说等泪干就继续（0105～0121）。剧情经过参照 kllj、atbm 笔记。

## 行为模式
- 胜利后面对前辈 → 故作得意，然后认真说出志向（0013、0016）。
- 要说沉重的话 → 先告诉观众不是什么开心的话，并征求意见（0041～0042）。
- 讲述痛苦的过去 → 用轻松的口吻（0045、0056）。
- 说到最难的部分 → 说不下去（0074～0075），朋友站到身边后才接着说（0089～0090）。
- 坦白之后 → 不只讲苦，最后转向对观众有用的话（0105～0108）。
- 朋友哭了 → 吐槽，用玩笑把场面收住（0116、0118～0120）。

## 关系
- 燕：她称「副会長」（0013）；燕称她「紫雲」（0012）。这里燕认可了她（0014、0017）。
- リーリヤ：她称「リーリヤ」（0048）；リーリヤ称她「清夏ちゃん」（0005）。她在瑞典孤单时和リーリヤ相遇（0047～0050），在台上被リーリヤ接住（0085～0089）。
- プロデューサー：她称「Pっち」（0037），舞台上说的是支持她的人，没有点名（0096）；制作人称她「清夏さん」（0007）。
- 观众：她称「みんな」（0039）；ファンC 称她「清夏」（0111）。

## 档案类事实
- 小时候一直学芭蕾，她自己说有才能（0044～0045）。
- 为成为职业芭蕾舞者留学瑞典，在那里没什么朋友、寂寞（0046～0047）。
- 在瑞典遇到リーリヤ，休息日一起玩，才觉得瑞典生活开心（0048～0050）。
- 她摔倒扭伤右膝，是几年内绝对不能运动、能否治好也不确定的重伤，回了日本（0052～0054）。
- 失去芭蕾、和リーリヤ分开后消沉，在电视上看到偶像的ライブ，得到再站起来的勇气，开始憧憬偶像（0055～0059）。
- 想当偶像不敢告诉父母，是初星学園的ライブ推了她一把；リーリヤ来日本时两人一起看了『H.I.F』，约定一起进这所学校、一起站上那个舞台（0060～0068）。
- 她曾想放弃偶像而逃课（0072）。受伤造成心理阴影，跑跳时害怕疼痛再来，练舞就害怕到想吐（0090～0092）；她受不了リーリヤ的信任，假装忘了约定（0094）。
- 她说心理阴影已克服（0100）。
