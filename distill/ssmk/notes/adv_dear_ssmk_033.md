# 紫雲清夏 亲爱度剧情 / 第33话（adv_dear_ssmk_033）

- 她的台词：44 行（含用匿名标签说的 0 行）
- 出场的人：清夏、プロデューサー、リーリヤ
- 场景：2ndライブ之后的休养日（0002～0003），和制作人谈话 → 和リーリヤ谈话，到准备睡觉时（0078）；地点没写
- 世界线：亲爱度（紫雲清夏）；制作人在制作的偶像：紫雲清夏

## 发生了什么
她在休养日来问2ndライブ的反响，心情却不好：班上的同学说就算两人优胜，『一番星』也只有一个人（0003～0013）。她说之前完全没想过，对『一番星』没有太强的愿望，无论谁成为都会心情复杂（0016～0024）。制作人说有一个不是以制作人身份、而是他个人的任性请她听，她答应了；这段话没有写出来，她听后答应成为『一番星』（0029～0039）。她对リーリヤ说自己想成为『一番星』，リーリヤ说自己也想，还说两人既是同伴也是对手（0045～0050）。リーリヤ说这不像她，她说那个人给了她很多却没回报过，想让他幸福，リーリヤ说她是恋爱中的少女，她害羞默认（0054～0064）。两人说好无论谁赢都不埋怨（0073～0075）。剧情经过参照 kllj 笔记。

## 她的关键台词
- 0013「――『一番星』になれるのは、／ひとりだけだよねって。」——转述同学的话（0011～0013 都是转述）。
- 0016「あたし……ぜんぜん考えてなかった。」——她的盲点。
- 0021「今は、優勝がいちばん大事で、／あんまり強い気持ちはないかなぁ……」——听到制作人的请求前的想法。
- 0024「どっちも、複雑な気持ちになりそう。」——同上。
- 0034「Pっちは、あたしのわがまま、／聞いてくれたからね。」——答应的理由是对等。
- 0039「約束する、Pっち。／あたし、『一番星』になるよ！」——答应，表明要去争。
- 0045「もちろん優勝が最優先だけど……／あたしは、『一番星』になりたい。」——向リーリヤ表明。
- 0058「あたしはずっと、あの人にもらって／ばかりで……何も返せてない。」——说理由。
- 0060「だから、あたしもね、／あの人を幸せにしてあげたいんだ。」——同上。
- 0062「ちょっ、明言しないでよ……／急に恥ずかしくなってくるんだケド……」——被点破恋爱时的反应，没否认。
- 0068「案外、今と同じような状況に／なってるかもしれないよ？」——对リーリヤ“如果早遇到”的回答。
- 0075「どっちが勝っても恨みっこなし、だね！」——对朋友的约定。

## 行为模式
- 别人一句话让她发现漏掉了什么 → 闷着不高兴，被问起才说（0009～0013）。
- 对方提出请求 → 记得对方曾答应过自己，因此答应（0033～0035）。
- 决定和朋友竞争 → 当面说清（0042～0045）。
- 被朋友看穿 → 不否认，要她别说出来（0054、0062、0064）。
- 朋友情绪上来 → 吐槽地拦（0078、0080）。

## 关系
- プロデューサー：她称「Pっち」（0001），和リーリヤ说起时称「あの人」（0058）；制作人称她「清夏さん」（0019）。她答应了他个人的任性（0033、0039）；对リーリヤ说想让他幸福（0060）。
- リーリヤ：她称「リーリヤ」（0040）；リーリヤ称她「清夏ちゃん」（0041）。说好既是同伴也是对手（0073～0075）。リーリヤ半开玩笑地羡慕，说如果自己早遇到那个人（0065～0067）。

## 档案类事实
- 『一番星』即使组团优胜也只有一个人（0013～0015）。
- 她原本对『一番星』没有强烈愿望（0021），听了制作人的话后说要成为（0039）。
- 她对リーリヤ默认对制作人的感情（0061～0064）。

## 不确定

- 0058「あの人」按上下文是制作人，本篇没有直接说出名字。
