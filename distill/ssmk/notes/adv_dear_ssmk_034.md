# 紫雲清夏 亲爱度剧情 / 第34话（adv_dear_ssmk_034）

- 她的台词：28 行（含用匿名标签说的 0 行）
- 出场的人：清夏、プロデューサー、星南、リーリヤ、燕
- 场景：『H.I.F』本赛当天（0001）；地点没写
- 世界线：亲爱度（紫雲清夏）；制作人在制作的偶像：紫雲清夏

## 发生了什么
本赛当天她和リーリヤ碰到星南和燕，星南宣告要四连霸，说原本没注意她们，没想到一年就走到这里；她说这多亏了制作人（0007～0022）。她和リーリヤ对两位前辈放话不会输（0015、0029～0032）。之后她对制作人说要讲真心话：昨晚怕得睡不着，手现在也在抖，问自己有没有真的改变（0041～0047）。制作人说害怕却仍向前就是勇气，只有心怀恐惧的人才能鼓励别人（0048～0052）。她请他握一下手，说有勇气了，然后说自己也要做自己想做的事，制作人对她说“加油”（0056～0067）。剧情经过参照 kllj、jsna 笔记。

## 行为模式
- 比赛当天的朋友紧张 → 先喊放松，自己也说紧张（0003、0006）。
- 当面被强敌挑衅 → 用敬语但明确放话（0015、0029）。
- 被夸 → 立刻归功于制作人（0020）。
- 在制作人面前 → 先说明要讲真心话，再讲害怕（0041～0047）。
- 需要依靠 → 小小地直接提出（0056）。
- 被鼓励后 → 说要做自己想做的事（0063）。

## 关系
- 星南：她称「会長」（0008）；星南称她「清夏」（0016）。她用敬语（0015、0020）。
- 燕：她称「副会長」（0025）；燕称她「紫雲」（0026）。
- リーリヤ：她称「リーリヤ」（0006）。说リーリヤ大概是为了她才去独自集中（0039，她自己的猜测）。
- プロデューサー：她称「Pっち」（0020）；制作人称她「清夏さん」（0036），0066 只对她说「頑張れ。」。
