# 紫雲清夏 亲爱度剧情 / 第36话（adv_dear_ssmk_036）

- 她的台词：36 行（含用匿名标签说的 0 行）
- 出场的人：清夏、学園長、星南、リーリヤ、一同
- 场景：『H.I.F』之后的『一番星』授予仪式（0006）；优胜ライブ之前（0069）
- 世界线：亲爱度（紫雲清夏）；制作人在制作的偶像：紫雲清夏

## 发生了什么
学園長宣布优胜是『REVERSI』，又说『一番星』只给一人（0007～0011）。她和リーリヤ说好不埋怨，学園長念出她的名字，她不敢相信，リーリヤ说恭喜（0012～0020）。她向リーリヤ道谢一起跳舞（0022）。星南说自己此前不知道她在和心理阴影作战，为此后悔，她说是自己隐瞒的，还说有人拉住了要放弃的自己，能来初星学園真好（0031～0040）。星南问她有没有背负学园的觉悟，她说老实讲还没有，但有支持她的人、有同伴，要用自己的方式让学园热闹起来（0045～0048）。面对全场，她说一年半前看『H.I.F』后约リーリヤ当偶像，并说之后也会继续，最后说如果没有迈出一步的勇气，她来推你的背（0057～0075）。剧情经过参照 kllj、jsna 笔记。

## 她的关键台词
- 0015「（お願い、神様……！）」——结果揭晓前的心声。
- 0017「……………………あ、あたし？」——不敢相信。
- 0022「一緒に踊ってくれて、ありがとう。」——赢了之后先向朋友道谢。
- 0036「……あたしが隠してたんです。／だから、気にしないでください。」——不让前辈自责。
- 0038「諦めかけてたあたしの手を、／引っ張ってくれた人がいるんです。」——没说名字的感谢。
- 0040「だから、初星学園に来られて、／本当によかった。」——对学园的态度。
- 0046「覚悟……とか、そーゆーのは／正直、まだできてないんですけど、」——不说漂亮话。
- 0048「だから、あたしらしいやり方で、／初星学園を盛り上げたいって思います！」——她的回答。
- 0060「その勢いで、リーリヤに言いました。／一緒にアイドルになろうって。」——对约定的说法。
- 0066「リーリヤがいなかったら、あたしも／初星学園に行く勇気がなかった。」——把功劳给朋友。
- 0072「ねぇみんな！／あたし、強くなったよ！」——同上。
- 0075「キミの背中は、／あたしが押してあげるからね！」——收束到自己的偶像像。

## 行为模式
- 听到自己得奖 → 不敢相信，要别人确认（0017）。
- 赢了朋友 → 先道谢（0022）。
- 对方为自己的事自责 → 说是自己隐瞒的，请对方不要在意（0036）。
- 被问是否有觉悟 → 老实说还没有，再讲自己能用的方式（0046～0048）。
- 公开场合讲话 → 把朋友放在前面（0058、0060、0066）。

## 关系
- 星南：她称「会長」（0053），用敬语；星南称她「紫雲清夏さん」（0031）、「清夏」（0051）。星南说从她的舞蹈得到了勇气（0043）。
- リーリヤ：她称「リーリヤ」（0021）；リーリヤ称她「清夏ちゃん」（0019）。
- 支持她的人：她在场上说的「引っ張ってくれた人」（0038）、「支えてくれる人」（0047）没有点名。

## 档案类事实
- 她成为『H.I.F』优胜者、冬天的『一番星』（0008、0016）。
- 星南是现任『一番星』、生徒会长（0029、0034）。
- 一年半前看了『H.I.F』，在兴头上对リーリヤ说一起当偶像，リーリヤ当时住在瑞典，答应了（0059～0064）；她说是因为リーリヤ自己才有勇气进初星学園（0066）。
- 星南说是在她在ライブ上坦白后才知道她和心理阴影作战的事（0033）。
- 她说约定实现后也会继续当偶像（0070）。
