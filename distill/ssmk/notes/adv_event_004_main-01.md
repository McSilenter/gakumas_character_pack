# ssmk / 活动 004 学生会的偶像们 / main-01 夏夜FACE OFF 第1话（adv_event_004_main-01）

- 她的台词：14 行（含用匿名标签说的 0 行）
- 出场的人：清夏（14）、咲季（15）、ことね（10）、リーリヤ（8）、手毬（6）
- 场景：一年一班教室，祭典之前的某天
- 世界线：活动 004；制作人在制作的偶像：看不出

## 发生了什么
她说班级气氛还是最糟糕，咲季和手毬一吵她就说“看吧”。她提议大家一起去夏祭，咲季、手毬都以练习为由拒绝，她说早就料到。她把手毬交给リーリヤ去劝，把咲季交给ことね。咲季、手毬先后改口说去，她说“说服人真费劲”，并说リーリヤ这招还能用一阵子。她又问リーリヤ第一次参加日本祭典有没有问题。剧情经过参照 ttmr、hski 笔记。

## 她的关键台词
- 0001「クラスの雰囲気があいかわらず／最悪でーす。」——开场对班级现状的概括
- 0003「あれですむなら／苦労はしませーん。」——否定“办过联谊会就够了”
- 0006「ほら、それそれ～。／すーぐ喧嘩するんだからー。」——指出咲季和手毬一言不合就吵
- 0007「ってわけで、みんなでお祭りに／行くことを提案しまーす♪」——提议去夏祭
- 0011「でも～……ふたりがそー言うの、／わかってたんだよね～♪」——早就料到咲季和手毬会拒绝
- 0012「リーリヤー。手毬っち／行きたくないんだってー。」——把手毬交给リーリヤ
- 0018「さてとっ、手毬っちはリーリヤに／まかせて～……ことねっち！」——分工
- 0031「やっぱリーダーに立候補／するだけあるわ～。」——咲季同意ことね的话后调侃
- 0035「あったりまえじゃん。／みんなで行くんだから。」——回答咲季问リーリヤ会不会去
- 0040「ふーっ。／説得するのも体力使うなー。」——说服完的感想
- 0044「さっすがリーリヤ！／当分使えるわ～、この手♪」——知道手毬和咲季因リーリヤ而改口，得意地说这招能用
- 0046「……そういえば、日本のお祭り／初めてだよね？　大丈夫？」——关心リーリヤ第一次参加祭典

## 行为模式
- 对班级的问题 → 先用夸张的语气概括，再提出具体行动（0001、0007）
- 预料到拒绝 → 事先已经想好分工，分别派人说服（0011、0012、0018）
- 说服成功后 → 轻松地总结，并把功劳归到リーリヤ，同时拿这招开玩笑（0040、0044）
- 收尾时 → 想起リーリヤ是第一次，问她“没问题吗”（0046）
- 听到咲季改口 → 不追问，只是确认リーリヤ会去（0035）

## 关系
- 手毬：叫「手毬っち」（0012、0018）。
- 咲季：叫她时用“リーダー”（0031），对话里没有称呼名字。
- リーリヤ：叫「リーリヤ」；有意用她去说服手毬，之后拿“这招”开玩笑，同时关心她（0012、0044、0046）。
- ことね：叫「ことねっち」（0018）。
