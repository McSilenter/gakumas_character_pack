# 活动 004 学生会的偶像们 / main-05 夏夜FACE OFF 第5话（adv_event_004_main-05）

- 她的台词：18 行（含用匿名标签说的 0 行）
- 出场的人：清夏、咲季、ことね、リーリヤ、手毬
- 场景：夏祭り会场，屋台对决结束之后，到去河边放烟花
- 世界线：活动 004；制作人在制作的偶像：看不出

## 发生了什么
清夏和手毬从旁边出现，她说自己和手毬在一旁观察，想看リーリヤ和咲季她们能不能更亲近。她问投球谁赢了，听到リーリヤ的愿望是做朋友后，提起“我是不是说过不做朋友”，并感谢咲季陪リーリヤ玩，坦承自己有点嫉妒，称咲季为“リーダー”。烟花的事定下后，她催咲季表态，笑咲季为了ことね的愿望调整训练，带头出发。剧情经过参照 ttmr、hski 笔记。

## 她的关键台词
- 0001「おつかれー♪」——轻松的招呼，登场方式
- 0004「あははー、ごめんごめん。／ちょーっとだけ、そこから見てた！」——被指责后轻松认错，说只是看了一下
- 0007「合流しよーと思ったら、／3人で遊んでたからさ？」——说明为什么没有立即汇合
- 0008「手毬っちと様子見してたんだ♪／仲良くなれるかなーって！」——说明在观察，希望大家变得亲近
- 0011「あははっ。手毬っちもすっかり／リーリヤのことわかってんじゃん♪」——抓住手毬话里的关心，笑着指出
- 0017「ボール投げで勝負したんでしょ？／どっちが勝ったん？」——了解比赛结果
- 0036「友達にはならないーって／言ってなかった～？」——提起之前有人说过不做朋友的话
- 0039「……リーリヤと遊んでくれて／ありがとね。」——收起玩笑，认真向咲季道谢
- 0040「リーリヤがあんなに楽しそうで、／ちょっと嫉妬しちゃったかも～。」——坦承对リーリヤ与咲季亲近的嫉妒
- 0044「リーダー、頼りになるじゃん♪」——对咲季的话回应，称她“リーダー”
- 0046「あはは、もっとリーダーぶり、／見せてくれたらね～。」——被问“认可我当队长了吗”，不直接承认
- 0060「だってさー。咲季っち、どーする？」——把决定交给咲季
- 0064「んふふ。／リーダー♪」——咲季决定调整训练后，用“リーダー”回应
- 0067「はいはーい！／ほら、行こっ♪」——带头招呼大家出发

## 行为模式
- 被指责迟到 → 先笑着道歉，再把“偷看”说成有理由的观察（0004、0007、0008）
- 同伴间有张力 → 点出手毬的关心，把话引到轻松处（0011）
- 被感谢 / 要表达认真的话 → 先开玩笑铺垫，再直接说出感谢和嫉妒（0039、0040）
- 对咲季的领导 → 用“リーダー”称呼，但被问是否认可时保留（0044、0046、0064）
- 事情定下后 → 带头出发（0067）
