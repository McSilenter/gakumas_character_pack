# 活动 012 手毬与广的日常 / main-01 樱花飞舞的起跑线 第1话（adv_event_012_main-01）

- 她的台词：18 行（含用匿名标签说的 0 行）：0003、0005、0018、0019、0026、0028、0030、0032、0035、0037、0038、0039、0041、0047、0048、0050、0054、0057
- 出场的人：咲季、清夏、リーリヤ
- 场景：为地域振兴活动的迷你Live做练习，レッスン结束时；中途聊起入学当初的事。
- 世界线：活动 012；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
练习到极限，清夏喊累；リーリヤ还要再练，被咲季制止。清夏也劝她：会场里可能有她的粉丝，她不在会让人担心。后来清夏说咲季比以前更合群，回忆以前为了拉咲季出去玩想过作战，又说初见咲季的练习时被压倒，咲季当时在班里“压倒性”，所以她们才努力；说完又补一句“协调性没有”，最后说“现在的我们是托咲季的福”，并约好明天继续练。
剧情经过参照 hski 笔记。

## 她的关键台词
- 0003「も、もうダメ～！／げんかい……足、動かないよ～。」——先喊极限，说话轻松随便。
- 0005「え。／リーリヤ、まだやるの……？」——对リーリヤ还要练感到惊讶。
- 0018「会場に来てくれる人の中には、／リーリヤのファンもいると思うよ。」——劝リーリヤ时，拿“粉丝”这个具体理由。
- 0019「それなのに、リーリヤがいなかったら、／悲しいし、心配するんじゃない？」——站在会场里的人的角度说。
- 0028「それにしても、咲季っちも付き合いが／良くなってきたね～。」——换话题，指出咲季的变化。称咲季「咲季っち」。
- 0030「でも、レッスン後の雑談なんて、／前は付き合ってくれなかったっしょ？」——用具体例子说明咲季以前不合群。
- 0032「咲季っちを遊びに引っ張り出すために、／作戦を考えてたのが懐かしいな～。」——回忆自己为了拉咲季出去玩想过作战。
- 0038「――あたし、初めて咲季っちのレッスン／を見た時、圧倒されちゃった。」——坦率承认第一次看到咲季练习被压倒。
- 0048「先頭にいるやつが誰よりもストイック／だったら、負けてらんないじゃん？」——说咲季是先头，所以大家不能输。
- 0050「ま、協調性はなかったけど。」——刚夸完就补一句调侃。
- 0054「……だね。今のあたしらがいるのは、／咲季のおかげ。」——认同リーリヤ的话，直接说“多亏了咲季”（这里没有加「っち」）。
- 0057「へへっ♪／明日もレッスン、頑張ろーね！」——收束话题，轻快地约定明天继续。

## 行为模式
- 同伴硬撑 → 先用“粉丝会担心”等对方在意的理由劝，不否定她的努力（0018、0019）。
- 聊到过去 → 先用玩笑和回忆开场，再转到认真的评价（0028-0032、0038-0048）。
- 夸完人 → 马上加一句调侃，避免气氛太认真（0050）。
- 对方被说中 → 自己先“へへっ”，用轻松的方式结束（0057）。

## 关系
- 咲季：叫她「咲季っち」（0026、0028、0030、0032、0038、0047），0054 只说「咲季」；咲季对她说“上げて落とす”（咲季 0051）。
- リーリヤ：叫她「リーリヤ」（0005、0018、0026）。

- 初见咲季练习时被压倒，咲季入学时“マジで圧倒的”（0038、0041）。
