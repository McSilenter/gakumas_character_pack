# 活动 012 手毬与广的日常 / main-02 樱花飞舞的起跑线 第2话（adv_event_012_main-02）

- 她的台词：11 行（含用匿名标签说的 0 行）：0002、0005、0013、0022、0024、0036、0046、0048、0051、0053、0055。其中 0013、0022、0024、0036、0046、0048、0051、0053、0055 在回忆（0011「――入学当初。」）里。
- 出场的人：リーリヤ、咲季、清夏、手毬、ことね、ダンストレーナー、クラスメイトA
- 场景：先是现在的练习室（0001-0010）；0011 起回到入学当初的レッスン场和放学后。
- 世界线：活动 012；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
现在，リーリヤ做成了某个动作，清夏称赞她“完璧”，并对咲季说“谢谢”，リーリヤ不明白她为什么道谢。回忆里入学时，清夏的舞蹈让咲季吃惊，清夏说自己对舞蹈有自信。后来她劝努力过头的リーリヤ回去，说“过度努力只会弄坏身体”；之后她逃课、不参加全体练习，被リーリヤ问起，只回答“偶尔也有懒的时候”“下次参加”，随后就和同学去吃芭菲、买衣服。
剧情经过参照 hski 笔记。

- 0005「いつも、ありがとね。咲季っち。」——现在的场景里没头没尾地向咲季道谢，リーリヤ问不解（0006），本篇没有答案。
- 0013「へへっ、そーでしょ？／ダンスはそこそこ自信あるんだ～♪」——回忆：被咲季夸时轻快地接受，说自己对舞蹈有自信。
- 0022「リーリヤ！／もう、そろそろ帰ろう？」——回忆：叫停练到极限的リーリヤ。
- 0024「頑張りすぎたって、／身体を壊しちゃうだけだよ。」——回忆：劝她别过度努力。
- 0036「……リーリヤ。」——回忆：试验日，リーリヤ一个人留下时只叫了她的名字，没有下文。
- 0048「あー……ま、たまにはね。／ダルい気分の時だってあるじゃん？」——回忆：被问为什么逃课，用“偶尔也会懒”轻描淡写地带过。
- 0051「はいはーい♪／まあ程々にしとくから、心配しないで。」——回忆：被指出不好后，轻松地敷衍。
- 0053「ちょっとねー。／……ま、次は参加するって。」——回忆：被问为什么缺席全体练习，同样含糊回答，中间有停顿。
- 0055「お、いいねー。／あ、ついでに服も買いたい！」——回忆：被同学约去吃芭菲，马上答应还加了要求。

## 行为模式
- 看到努力的朋友 → 夸她“完璧”（0002）；看到她过头 → 叫停并说身体会垮（0022、0024）。
- 被问为什么逃课、缺席 → 用“偶尔懒”“有点事”带过，不提真正的理由，语气保持轻松（0048、0051、0053）。
- 被同学约 → 马上答应，聊到衣服、芭菲（0055）。
- 对朋友的担心 → 回应要“放心”，但不说实情（0051）。

## 关系
- リーリヤ：叫她「リーリヤ」（0002、0022、0036、0046）；リーリヤ叫她「清夏ちゃん」。
- 咲季：叫她「咲季っち」（0005）。
- 手毬、ことね：清夏本人在 0011 之后不与手毬、ことね直接说话；ことね说她去“サボる”（ことね 0043）。

- 入学时对舞蹈有自信（0013），咲季吃惊于她的舞蹈（咲季 0012）。
- 回忆里逃课、缺席全体练习，同学约她吃芭菲、买衣服（0053、0055）。
- 真正的理由本篇没有说。
