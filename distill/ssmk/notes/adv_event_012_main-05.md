- 她的台词：21 行（含用匿名标签说的 0 行）：0002、0003、0006、0007、0009、0011、0013、0014、0016、0018、0020、0022、0023、0027、0028、0049、0052、0057、0058、0059、0063；其中 0063 是唱歌词（歌词的一部分），不当成对话。

## 发生了什么
Live前一晚，清夏劝刚好转的リーリヤ早点睡，听她说紧张，坦白自己也在手抖。リーリヤ问一起站上舞台算不算履行了“约定”，她说“这点大小的Live还说不上”，リーリヤ提议保留到站上大舞台。她请求リーリヤ支持自己，说自己弱小、胆小，但想站在她身边；リーリヤ提出交换条件，她答应，约好明天证明现在的力量。Live直前被咲季问准备如何，她说“万全”，并说“我一个人还不行，但两个人就不会输给咲季”。接着两人唱歌（0063 歌词）。
剧情经过参照 hski、hume 笔记。

## 行为模式
- 朋友睡不着 → 先关心，再坦白自己的恐惧，使对方不觉得孤单（0003、0007、0009）。
- 被问重要的事（约定）→ 老实说“还不到”，不夸大（0013、0014）。
- 对重要的人 → 直接说“支持我”“想站在你身边”，同时承认自己弱（0020-0023）。
- 在咲季面前 → 用玩笑口气说“我们不会输”，但承认“我一个人不行”（0057-0059）。

## 关系
- リーリヤ：叫她「リーリヤ」（0002、0003、0020、0049）；彼此约定互相支持（0020-0028）。
- 咲季：叫她「咲季っち」（0059）。
