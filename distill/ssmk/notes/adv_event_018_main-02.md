# 活动 018 / 第2话（adv_event_018_main-02）

- 她的台词：18 行（含用匿名标签说的 0 行）
- 出场的人：清夏、麻央、広
- 场景：三人组合的练习中（练习室，剧本里没写明）；休息时谈膝盖，然后広提出演唱会点子。
- 世界线：活动 018；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
练习中清夏说今天还能坚持，麻央提出降低舞步难度，她以为是自己的舞跳得不好。広问是不是在意膝盖，她吓了一跳。清夏说膝盖已经没事，剩下是心理问题，原本想找机会说，现在由咲季和リーリヤ帮忙一点点适应；收到组合邀请时觉得现在能做到，但动作激烈的曲子还有点吃力。被麻央要求不要再道歉后，她听広提出让麻央和她主演演戏剧，反对说芭蕾和戏剧是两回事，但还是问了内容。

## 她的关键台词
- 0003「……うん。今日はまだいける。」——休息前她逞强的话。
- 0007「へっ！？／……あたしのダンス、駄目でした？」——听到要降低难度，以为是在说自己不行。
- 0013「――や、ほんとに大丈夫なんです。／膝はもう、なんともない。」——马上否认膝盖有问题。
- 0014「後は、あたしの心の問題で。／話さなきゃって思ってたんですけど……」——说剩下是心理问题，本来想着要说。
- 0016「咲季とリーリヤに手伝ってもらって、／少しずつ慣らしてるとこです。」——说明正在怎么处理。
- 0018「ユニットの誘いをもらった時、／今ならできるって思ったんです！」——说明参加组合的理由。
- 0019「でも、振りが激しい曲は／まだちょっとしんどいかもです～！」——坦白还有做不到的部分。
- 0022「りょーかいです！／すみません、気を遣わせちゃって！」——接受方针，同时道歉。
- 0037「いやいやいや、バレエと演劇は／ぜんぜん別物でしょ！」——对广的点子表示反对。
- 0041「ひろっちの提案なのに、／自分でやらなくていいの？」——替広考虑，问她为什么自己不演。
- 0045「へー、いいじゃん！／どんな内容にするの？」——听说要写剧本后表示认可并追问。

## 行为模式
- 被说要降低难度 → 先怀疑是自己的问题（0007）
- 被说中隐瞒的事 → 吓一跳，用「で、ですよね～」带过，再认真解释（0009、0011、0013、0014）
- 坦白自己的状态时 → 先说没事，再说原因，再说现在的做法，最后补一句还有吃力的地方（0013～0019）
- 被照顾 → 马上道歉「すみません」（0022）；被要求不要再道歉时愣住（0025）
- 对新点子 → 先反驳，再以好奇追问，不是一概拒绝（0037、0045）

## 关系
- 麻央：叫「まおっち先輩」（0039）；对她使用敬语；麻央注意到她的膝盖（0010）。
- 広：叫「ひろっち」（0029、0041）；广问到膝盖时她惊呼（0009）。
- 咲季、リーリヤ：叫「咲季」「リーリヤ」，她们在帮她适应（0016）。

## 档案类事实
- 膝盖有过问题，现在她说已经没事（0013）。
- 现在是在请咲季和リーリヤ帮忙，一点点适应（0016）。
- 动作激烈的曲子还有点吃力（0019）。
- 広说她曾是芭蕾舞者（元バレリーナ，0034，広的话），她说芭蕾和戏剧完全不同（0037）。
- 收到组合邀请时觉得现在的自己能做到（0018）。
