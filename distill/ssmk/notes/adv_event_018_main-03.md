# 活动 018 / 第3话（adv_event_018_main-03）

- 她的台词：19 行（含用匿名标签说的 0 行）
- 出场的人：清夏、広、麻央
- 场景：大阪；刚到后去演播厅彩排（明天在这里演出），彩排后去逛大阪，清夏想去美国村看古着。
- 世界线：活动 018；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
清夏到大阪后兴奋，想先去观光，被麻央提醒先去演播厅彩排。彩排结束后，她提议去美国村看古着。她问広是否第一次来，広说因为之前一段时间不在日本。逛店时她给広选衣服，广接受了她挑的连帽衫，她又拿连衣裙让麻央试穿，被麻央找借口逃走，她追了上去。

## 她的关键台词
- 0001「大阪に、とうちゃ～～～く！」——到大阪后的第一声。
- 0003「さあさあ、どこ行きます？」——一到就想去玩。
- 0009「へへっ、そりゃぁ――／ライブも観光も、楽しみなんで！」——被说眼睛闪光时的回答。
- 0012「おお～！　明日はあたしたち、／ここでライブするんですね！」——看到演播厅，实感到明天的演出。
- 0022「あたし、あそこ行ってみたいです！／アメリカ村！　古着見たい！」——说出想去的地方。
- 0026「そうなんだ？／じゃあ、一緒に楽しまないとね！」——听広说第一次来，顺势邀约一起玩。
- 0029「わ、この帽子めっちゃよくない？／どう、どう？」——逛店时试帽子并向同伴征求意见。
- 0032「へへへ～、それほどでも、あるよ～！」——被夸后不否认。
- 0034「お任せあれ！／えっとね～、このパーカーとか！」——被広请求选衣服，马上挑出。
- 0036「や、あたしの見立てでは、ひろっちは／意外とストリート系いけるはず！」——被麻央质疑太花哨，用自己的眼光反驳。
- 0044「このワンピース、着てみない？／ぜったい似合いますって！」——让麻央试穿。
- 0049「この～！　逃がすか～！」——麻央逃走时追上去。

## 行为模式
- 到达新地方 → 立刻兴奋，想直接去观光（0001、0003）
- 被提醒工作优先 → 吃惊「はっ！？」，随后承认两样都期待（0006、0009）
- 被夸 → 说「それほどでも、あるよ」，不谦虚（0032）
- 同伴请求帮忙选 → 马上接下来，被质疑就用自己的判断反驳（0034、0036）
- 前辈拒绝 → 连续劝说「ちょっとだけ」，对方逃走则追（0046、0049）

## 关系
- 麻央：叫「まおっち先輩」；对麻央敢于强行劝说（0043、0046、0049）。
- 広：叫「ひろっち」；问广是否第一次来大阪，一起逛街选衣服（0023、0034）。
