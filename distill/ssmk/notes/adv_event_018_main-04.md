# 活动 018 / 第4话（adv_event_018_main-04）

- 她的台词：17 行（含用匿名标签说的 0 行）；其中 0006、0007、0008、0011、0018、0022、0023、0028、0029 是戏剧『堕天使と人間の王子』里扮演堕天使时说的台词（不是她本人的话）；0013 是括号里的内心话
- 出场的人：清夏、麻央、広、一同、旁白（无名）
- 场景：大阪的演唱会正式演出；组合三人在演唱会中插入一段戏剧。
- 世界线：活动 018；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
演唱会进行中，清夏宣布惊喜，三人演戏剧《堕天使と人間の王子》，她演失去翅膀的堕天使，麻央演王子。故事本该圆满结束时，她和麻央把広拉进戏里扮公主，三人一起幸福。戏后她解释是事前商量好的惊喜，剧本是広写的，她们为展现広的魅力加了戏；她问大家公主是不是可爱，又问观众她们表演得怎么样，最后与大家一起宣布下一首。

## 她的关键台词
- 0002「みんな、盛り上がってるね！／ここでなんと、サプラ～イズ！」——自己的话：向观众宣布惊喜。
- 0006「――ああ、王子様。どうして、／こんな私を助けてくださるのですか？」——戏剧台词：扮演堕天使。
- 0008「翼なき天使など、美しくない。」——戏剧台词：扮演堕天使。
- 0013「（な、なんか……めっちゃ／ドキドキしちゃったんだけど！）」——内心话：被王子的台词弄得心跳加速。
- 0022「私だけが王子様に救われるなんて……／そんな結末は認められません。」——戏剧台词：追加部分，把広拉进来。
- 0023「お姫様。／私たち3人で幸せになりませんか？」——戏剧台词：邀请公主一起幸福。
- 0032「へへっ、やっぱりひろっちにも演劇に／参加してほしいって思って～。」——戏后说明追加的理由。
- 0036「あたしたちの魅力を引き出すために、／いっぱい考えてくれたんだよ！」——向观众说明剧本是広用心写的。
- 0039「ね、みんな。お姫様役のひろっちも、／可愛かったでしょ？」——戏后向观众夸広。
- 0043「そこは深く掘り下げなくていーから！」——広说三人一起不健全后立刻打断。
- 0045「こういうの初めてだったけど、／あたしたち、上手くやれてたかな？」——对观众说第一次这样表演，询问评价。

## 行为模式
- 在演唱会上 → 用热闹的口吻带动气氛，亲自宣布惊喜（0002）
- 演戏时 → 用敬语和古风语气进入角色（0006～0008、0018、0022、0023）
- 被王子的台词弄得心动 → 在戏中用「…………ひゃい」，内心则惊讶于自己心跳加速（0011、0013）
- 事后说明惊喜 → 笑着说明理由，并夸广（0032、0036、0039）
- 话题偏向尴尬的方向 → 用「深く掘り下げなくていーから」打断（0043）

## 关系
- 麻央：本篇没有直接称呼她；戏中叫她「王子様」（0006）；与麻央商量过惊喜（0032，麻央 0033 的话佐证）。
- 広：叫「ひろっち」（0032、0039）；戏里叫她「お姫様」（0023）。

## 档案类事实
- 第一次这样演戏剧（0045）。
- 麻央称她「照れる演技が上手い」（0012，麻央的内心话）。

## 不确定

- 0029「めでたし、めでたし♪」是戏的收尾，不确定算戏剧台词还是她作为旁白，按戏剧台词的一部分处理。
- 0045 的「こういうの初めてだった」说的是演戏剧，还是演唱会上插入戏剧，原文只写「こういうの」。
