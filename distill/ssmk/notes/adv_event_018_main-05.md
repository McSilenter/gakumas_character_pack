# 活动 018 / 第5话（adv_event_018_main-05）

- 她的台词：25 行（含用匿名标签说的 0 行）
- 出场的人：清夏、広、麻央、一同
- 场景：大阪演唱会结束后，三人在麻央推荐的章鱼烧店庆功；麻央睡着后，清夏和広继续聊。
- 世界线：活动 018；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
庆功时，清夏一口吃章鱼烧被烫到，说还是好吃。麻央说请客，她开心。広道谢，说麻央和清夏是她的王子，清夏也说感谢两人耐心陪她练习。広突然说自己大学毕业，并说因为她们告诉了自己的事，所以也想说，之前就知道清夏曾是芭蕾舞者；清夏问为什么告诉她们。麻央睡着后，広问清夏是不是在躲她，清夏承认，说总觉得广面前蒙混不过去，有点怕。広说一直想和她说话、喜欢她的穿搭、也想试试辣妹，清夏答应把広打造成辣妹。

## 她的关键台词
- 0005「いただきま～～～す！」——吃饭前的第一声。
- 0007「あふっ！？　めっひゃあふひっ！？」——一口吃烫到的反应。
- 0011「や、火傷するかと思った……／でも、めっちゃ美味しい！」——被烫后仍然称赞好吃。
- 0016「やったー♪／まおっち先輩、かっこい～！」——麻央说请客，高兴地夸她。
- 0020「……あたしも、感謝してるんだ。」——广道谢后，说自己也有感谢。
- 0021「ふたりとも、根気強くあたしの／レッスンに付き合ってくれたから。」——感谢的理由。
- 0027「じゃあ、3人のおかげってことで！／みんなで支え合った結果！」——把功劳总结为三人互相支持。
- 0035「そういうこと、だったんだ。／……どうして教えてくれたの？」——广坦白后，先接受，再问为什么告诉她们。
- 0047「生々しい表現やめて！？」——广说「友達の友達」时吐槽。
- 0054「うん……まおっち先輩はすごいよ。／あたしも、尊敬してる。」——麻央睡着后，表达对麻央的尊敬。
- 0061「……うん。」——被问是否躲着広，承认。
- 0062「なんとなく、ひろっちには、／嘘が通じないような気がしたんだ。」——说躲避的原因。
- 0063「だから、ちょっと怖かった。」——坦白对広的感觉。
- 0065「ご、ごめんってば～！」——被说「単相思」时连忙道歉。
- 0071「任せてよ！／今度、ひろっちをギャルにしてあげる！」——广说想当辣妹，她答应打造。

## 行为模式
- 吃东西 → 不顾烫，一口吃，被烫后仍说好吃（0005、0007、0011）
- 被请客 → 直接夸对方「かっこい～」（0016）
- 被道谢 → 顺势说自己也感谢，并点明具体原因（0020、0021）
- 对方坦白 → 先接受，再问理由（0035）
- 被问到心里的话 → 先发出「あ～～～」，再承认，并解释原因（0060～0063）
- 被说「単相思」 → 慌忙道歉（0065）
- 广表示想当辣妹 → 笑出来，否定「不适合」，主动承揽（0070、0071）

## 关系
- 麻央：叫「まおっち先輩」；尊敬她（0054）；说她睡着的样子「可愛い」（0055）。
- 広：叫「ひろっち」；之前有意避开她，因为觉得瞒不过她（0062、0063）；答应打造她成辣妹（0071）。

## 档案类事实
- 曾为芭蕾舞者这件事，広一开始就知道（0037，広的话；0038 她反应「えっ、そうなんだ？」）。
- 麻央、广陪她练习，耐心（0021）。
- 对広的看法：嘘が通じないような気がして怖かった（0062、0063）。
- 喜欢时尚，愿意为广打扮（0071；広 0068 说她的时尚风格很好）。
