# 活动 020 / main-01 第1话（adv_event_020_main-01）

- 她的台词：33 行（含用匿名标签说的 0 行）
- 出场的人：清夏（33）、リーリヤ（25）
- 场景：地点剧本未写明，休日；结尾出门去玩
- 世界线：活动 020；制作人在制作的偶像：看不出

## 发生了什么
清夏发现リーリヤ只剩 1000 円，责备她没提前商量。接着回忆在瑞典时的事：常去リーリヤ家玩，被リーリヤ的妈妈一起说教，リーリヤ教她看动画玩游戏。清夏说没钱也有办法玩，约好带便当，不顾リーリヤ没准备好就拉她出门。

## 她的关键台词
- 0003「こーゆーことになる前に、／相談してって、言ったよね？」——像照顾人的一方，事前说过要商量
- 0006「――どうして、1000円しかないの！？」——发现零花钱见底时的反应
- 0015「今は自分でお金を管理しないと／いけないんだからね？」——提醒リーリヤ要自己管钱
- 0020「あははっ、冗談だよ。／……でも、懐かしいなぁ。」——开玩笑后转入回忆
- 0030「だってあたし、結構な頻度で／リーリヤの家にお邪魔してたから。」——在瑞典常去リーリヤ家
- 0032「あっちで日本語が通じる同世代なんて／他にいなかったからさ～。」——找リーリヤ玩的原因
- 0037「あたしもバレエばっかりで、／他のことは何も知らなかったから――」——自己当时只有バレエ
- 0046「ん～、リーリヤが観てるアニメって／難しい内容のやつ多くてさ～。」——坦白对动画不太感兴趣的原因
- 0049「その代わり、デートに付き合ってよ！」——提出交换条件
- 0057「たまにはあたしが連れ出さないと！／――さあ行こ！　リーリヤ！」——主动拉她出门

## 行为模式
- 对方出问题 → 先责备再讲道理，随后用玩笑缓和（0003～0006、0015、0018、0020）
- 被说“照顾别人”时 → 用回忆和轻松口吻带过（0020、0029）
- 提议后对方犹豫 → 不解释，说「着いてからのお楽しみ」并直接推进（0051～0054、0057）
- 被直白说好话 → 用「照れちゃう」带过（0036）

## 关系
- リーリヤ：称呼「リーリヤ」，说リーリヤパパ、リーリヤママ。リーリヤ称她「清夏ちゃん」。瑞典时代的朋友，清夏说跟リーリヤ玩是最大乐趣（0033）；リーリヤ说因为清夏不再寂寞（0035）。

## 档案类事实
- 清夏在瑞典时常去リーリヤ家，リーリヤ的妈妈会说教（0021、0030）
- 当时在瑞典没有其他说日语的同龄人（0032）
- 只知道バレエ，没接触过动画游戏，是リーリヤ教的（0037、0038、0044）
- 现在对リーリヤ看的动画觉得难懂，但喜欢つむじちゃん（0046、0047）
- 清夏是从日本去瑞典的（0039）
