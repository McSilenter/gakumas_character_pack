# 活动 020 / main-02 第2话（adv_event_020_main-02）

- 场景：户外，晴天，野餐铺垫子吃便当
- 世界线：活动 020；制作人在制作的偶像：看不出

## 发生了什么
清夏带リーリヤ野餐，吃她做的瑞典肉丸。聊到父母后，清夏提议成为顶级偶像后在瑞典办凯旋live。リーリヤ说以为清夏不想再去瑞典，清夏说那里有过痛苦，但遇到了リーリヤ，所以愿意重来也去瑞典。两人说到“重来也一直在一起”后都沉默，清夏转开话题，约好一起去瑞典观光。

## 行为模式
- 被说担心时 → 先承认辛苦，随后用“但是遇到了你”转向肯定（0043、0044、0046）
- 对方的话太亲密 → 先「そ、そっか」，沉默后用「それよりさ～！」转开话题（0053、0055）
- 想到点子 → 说「イイこと思いついた♪」后立即提议（0032～0034）
- 被夸大 → 轻描淡写否认（0039）
