# 活动 020 / main-03 第3话（adv_event_020_main-03）

- 她的台词：38 行（含用匿名标签说的 0 行）
- 出场的人：清夏（38）、リーリヤ（26）
- 场景：购物中心，橱窗购物
- 世界线：活动 020；制作人在制作的偶像：看不出

## 发生了什么
清夏带リーリヤ逛购物中心，只看不买以掌握化妆品和时尚趋势。她讲了自己是回日本后因为反抗妈妈而装成辣妹，并从朋友和杂志学到知识。为了逗リーリヤ，她说选衣服的诀窍是想着喜欢的人，被追问后描述了自己心里想的类型。リーリヤ的「好きな人」原来是动画角色，清夏说这个角色接近自己的理想。

## 行为模式
- 想捉弄对方 → 当场想出点子随口说，心里话用括号（0033、0034、0038）
- 被反问出乎意料 → 内心慌（0042），表面含糊回答，然后立刻反问对方（0043、0049）
- 对方知识不足 → 用「也要懂」的语气催促，同时提议具体试用（0008、0010、0014）
- 对方说「是动画」 → 先确认再认可，并说接近自己的理想（0059～0062）

## 关系
- リーリヤ：称「リーリヤ」。觉得适合她的衣服与自己不同类型（0027、0030）。

## 档案类事实
- 辞掉バレエ回到日本之后才学会时尚、化妆（0021、0023）
- 当时因妈妈管得多而反抗，打扮成辣妹风（0022）
- 从朋友和杂志学习，不知不觉就融入了（0023、0024）
- 理想类型（括号内的内心话与说出口的话）：理解自己、辛苦时陪伴、困难时帮忙、平时不坦率但被逗会有可爱反应（0044、0046）

## 不确定
- 0033、0038、0042、0047 括号里的话是心里话，剧本没写明是内心独白还是说出口，按括号当心里话处理。
- 0041 リーリヤ说清夏「好きな人の趣味に／合わせて、ギャルになったんだよね？」，清夏 0022 说的原因是反抗妈妈，清夏心里想的是「そうなるの～！？」（0042），没有当场纠正。
