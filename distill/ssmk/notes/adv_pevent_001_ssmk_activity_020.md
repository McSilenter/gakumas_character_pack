# 紫雲清夏 培育事件 001 activity / 020 其他孩子（adv_pevent_001_ssmk_activity_020）

- 她的台词：10 行（含用匿名标签说的 0 行）
- 出场的人：清夏（10）、プロデューサー（8）
- 场景：地点没有写；她问 P 有没有想过制作别的孩子
- 世界线：培育（紫雲清夏）；制作人在制作的偶像：紫雲清夏

## 发生了什么
清夏说 P 总陪着自己，P 说因为是制作人。她问他有没有想过培育别的孩子，让他老实回答。后面并列：P 否认后让她看着自己的眼睛，她沉默片刻，害羞地说相信他；P 说只要她怀疑就不会变，她说不是这个意思，P 说请相信，说他想培育她，她小声答应；P 说满脑子都是怎么培育她，她问那有空时会想吗，P 说有空能想很多，还说等她上了轨道想做的事多得很，她有点结巴地回应。

## 她的关键台词
- 0001「Pっちもさー、／よくあたしに付き合うよね～。」——像随口说的开场。
- 0003「他の子をプロデュースしよーとか／考えたことないの？」——用随便的语气试探。
- 0005「あるんじゃな～い？／ねー、正直に答えてよ。」——追问。
- 0006「ほんと～？」
- 0009「……ちょ、ちょっとハズいじゃん。／わかった、信じる。」——被认真盯着时认输，说相信。
- 0011「あ、あたしはそんなつもりじゃ……」——被指出在怀疑时退缩。
- 0013「……う、うん。」——被直接说想培育她时只能这样答。
- 0015「……じゃあ、暇ができたら思う？」——仍在意“别的孩子”这件事。
- 0018「……そ、そう。／やる気……じゃん？」——结巴着接话。

## 行为模式
- 想确认对方是否只把精力放在自己身上 → 以轻松的玩笑方式试探（0001、0003、0005）
- 对方认真回答 → 语气变小，害羞，接受（0009、0013）
- 被指出在怀疑 → 马上收回（0010、0011）
- 对方说的话留有余地 → 继续追问边界（0014、0015）

## 关系
- プロデューサー：她叫他「Pっち」（0001）；他叫她「清夏さん」（0010、0017），说想培育她（0012）、满脑子是怎么培育她（0014）。这一话里她在试探他是否只做她一个人的制作人。

## 档案类事实
- 无

## 不确定
- 0018「やる気……じゃん？」的「やる気」说的是她自己的干劲还是 P 的，原文没有主语。【译文】译作“有干劲了……对吧？”，也没有说清。
- 上面说她在试探 P 是否只做她的制作人，是按 0003、0005、0015 的读法，她没有直接这样说。
