# P卡 月村手毬【常春藤】 / 第3话 常春藤 第3话（adv_cidol-ttmr-3-001_03）

- 她的台词：23 行（含用匿名标签说的 0 行）；另有 0033『一同』1 行是她和制作人一起说的，未计入。
- 出场的人：手毬、プロデューサー、一同
- 场景：PV完成后，她和制作人一起看成片，地点未写。
- 世界线：亲爱度（月村手毬）·P卡（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
制作人做好了她的PV，她满怀期待地看完，说「わかってるね」，非常满意（0001～0015）。心声里她惊讶于在制作人眼中自己原来这么帅气（0013、0014）。她要求制作人把他认为的「月村手毬らしさ」明确说出来，制作人先列出「泣き虫で、甘えん坊で、理不尽で、／怒りっぽくて……」，她一下变脸，接着他又说「ストイックで、クールで、／孤高で、綺麗で――」、是个帅气的偶像（0018～0029）。制作人解释：她有许多面、优点缺点都很多，但上舞台时只带上最帅气的一面，因为她是偶像——最后一句两人同声说出（0030～0033）。她说「わかってるじゃないですか」，表示今后会继续展现制作人心中那个像她的月村手毬（0034～0036）。

## 她的关键台词
- 0005「私らしいものに。」——对PV的期待点。
- 0010「…………わかってるね。」——看完PV后的认可。
- 0013「（しらなかった……プロデューサーの／目には、私って……）」——心声，惊讶于他眼中的自己。
- 0014「（こんなにカッコよく／映ってるんだ～～～～～～～♡）」——心声，嘴上克制、心里很高兴。
- 0018「せっかくなので、／はっきり言葉にしてくれますか？」——想听他亲口说出评价。
- 0021「いいから！　言ってください！」——追问。
- 0025「……は？」——听到一串缺点后瞬间变脸。
- 0029「……私が……カッコいい。」——反复咀嚼这句评价。
- 0034「……わかってるじゃないですか。」——认可制作人的理解。
- 0036「プロデューサーが思う……／私らしい、月村手毬を。」——接受他眼中的自己并承诺展现。

## 行为模式
- 结果超出期待 → 嘴上淡淡「ふーん」「わかってるね」，心里欣喜若狂（0008、0010、0013、0014）。
- 被夸后 → 进一步要求对方把夸奖清楚说出来（0018、0019、0021）。
- 听到缺点 → 立刻「は？」；后面听到优点 → 动摇、害羞（0025、0027、0029）。
- 认同对方的观点 → 用「わかってるじゃないですか」这种居高临下的说法表示认可（0034）。

## 关系
- プロデューサー：她称「プロデューサー」，对方称「月村さん」。制作人说她「泣き虫で、甘えん坊で、理不尽で、／怒りっぽくて……」，同时「とてもストイックで、クールで、／孤高で、綺麗で――」，是「カッコいいアイドル」（0024、0026、0028）。制作人说最近她「無茶ぶり」多（0020）。两人同声说出「――アイドルだから。」（0033）。

## 档案类事实
- 制作人为她做的PV完成，她很满意（0003、0015）。
- 制作人对她的评价：爱哭、爱撒娇、不讲理、易怒；同时非常自律、冷静、孤高、美丽，是帅气的偶像（0024、0026、0028）。
- 制作人的观点：她有很多面，但上舞台只带最帅气的一面，因为是偶像（0030～0033）。

## 不确定
- 0033『一同』的「――アイドルだから。」是她和制作人一起说的，未算进她的台词数。
- PV的具体内容本篇没描写，只知道她看后觉得自己被拍得很帅（0014）。
- 【译文】0010「…………わかってるね。」译成“你明白的吧”，原文是（你）很懂嘛的意思，是在夸制作人懂她。
