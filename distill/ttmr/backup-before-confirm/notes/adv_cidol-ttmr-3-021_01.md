# P卡 月村手毬【“我要说了哦。”】 / 第1话 “我要说了哦。” 第1话（adv_cidol-ttmr-3-021_01）

- 她的台词：22 行（含用匿名标签说的 0 行）
- 出场的人：手毬、プロデューサー、撫子、四音、一同
- 场景：她冲来找制作人哭诉（地点不明）；中间插入她被極月学園的人嘲笑的场面（0009–0016，看起来是她在回想/讲述的经过）。时间点：非夏季（0030 她说泳装拍摄「季節外れ」，成果在“次の夏”公开）。
- 世界线：亲爱度（月村手毬）·P卡；制作人在制作的偶像：月村手毬（制作人以她为对象拿下企划、提到“月村手毬にとって／とても大事な時期”0039）

## 发生了什么
她大喊着冲到制作人面前要他“想办法”，又不肯说明原因，被制作人要求解释后才说出经过（0001–0008）。经过是：極月学園的撫子和四音向她炫耀極月学園与航空公司的联动、在海外拍的豪华 CM，问她有没有把脸印在飞机上的经历，她答不上来，被一起嘲笑（0009–0016）。她向制作人哭闹，要他拿一个比对方更豪华的联动企划来（0017–0018），本以为不可能，制作人却当场拿出超豪华联动企划的资料，让她大吃一惊（0020–0023）。她承认自己本来是抱着“不行就算了”的心态、也知道这不是制作人一个人能办到的请求（0023、0026）。企划是大型服装厂商与初星学園的大型联动，她作为第一弹被选中，要穿泳装拍摄、在明年夏天公开（0029–0032）。制作人说对方要的是“清新健康美”的偶像，并说自己在竞标时夸下海口称她明年夏天会是潮流中心（0034–0036）。她称赞制作人，表示早有承受紧密日程的觉悟，接下海外 CM 拍摄的工作，誓言为了初星学園的将来拍出最好的影像（0037–0043）。

## 她的关键台词
- 0001「プロデュ～サぁ～～～～～～～～～！！」——遇到气不过的事就大叫着冲向制作人求助。
- 0004「は？　言わなきゃわからないんですか？」——默认制作人应该懂她，理直气壮。
- 0006「いつもはなにも言わなくても／訳知り顔になってるのに……」——透露她平时依赖制作人“不用说也懂”。
- 0013「ぐっ……く……ぐぎぎぎィ……！！」——被对手戳中时咬牙切齿、说不出话（回想场面中）。
- 0018「プロデューサぁ～！　あいつらより／ゴージャスなタイアップ企画／取ってきてぇ～～～！」——对制作人撒娇式的无理要求，好胜心强。
- 0023「嘘でしょ！？　／ダメで元々のつもりで言ったのに……」——自己也知道要求不合理。
- 0026「プロデューサー個人が叶えられる／規模のお願いじゃなかったのに。」——明知是无理要求还提。
- 0035「まさに私ですね。」——对自己的“清新健康美”毫不谦虚。
- 0037「勝ったんだ。／やるじゃん、プロデューサー。」——用平语、略居高临下地夸制作人。
- 0040「とっくに覚悟してるよ。／私、アイドルですから。」——对辛苦的工作有职业觉悟。
- 0042「任せてください。大仕事ですから……／今後の初星学園のためにも。」——意识到自己代表学校。

## 行为模式
- 被对手（極月学園的人）当面炫耀、嘲笑 → 当场憋得说不出话，事后跑去找制作人哭闹（0013、0017）
- 有事找制作人 → 一开始不说清楚，默认对方该懂；被要求说明才勉强说（0002、0004、0006、0008）
- 向制作人提要求 → 明知办不到也会任性地提，提完先自己泄气（0018、0020、0026）
- 制作人真的办到 → 先震惊，再把“你明知还提”的追问一句带过，马上转去看企划内容（0022、0028）
- 被告知对方要求的形象 → 直接认领“正是我”（0035）
- 面对重要、辛苦的工作 → 表示早有觉悟，以偶像的身份和学校的将来为由全力接下（0040、0042–0043）

## 关系
- プロデューサー：她称“プロデューサー”，激动时拖长成“プロデュ～サぁ～”（0001、0018）；制作人称她“月村さん”，向对方介绍时称“月村手毬”。她对制作人既任性依赖（0006、0018），又会在对方办成事时夸“やるじゃん”（0037）。
- 撫子：極月学園的人，称她“手毬お姉さま”（0009），在回想场面里和四音一起嘲笑她（0014–0016）。她把撫子等人称为“極月学園の連中”“あいつら”（0017–0018）。
- 四音：極月学園的人，向她展示 CM、问她有没有脸印在飞机上的经历，并说自己有（0011–0012）。

## 档案类事实
- 她以前没有过把自己的脸印在飞机上的经历（0012–0015，由撫子从她的反应断定，她没有否认）。
- 她被选为某大型服装厂商与初星学園的大型联动企划第一弹，内容是穿泳装拍摄、在海外拍 CM、明年夏天公开（0029–0032、0041）。
- 制作人说对方要的形象是“フレッシュな健康美を持つアイドル”，她认为正是自己（0034–0035）。
- 制作人说现在对她是非常重要的时期，日程会很紧（0039）。

## 不确定
- 0009–0016 是插入的回想场面（接在她 0008「実は……」之后），里面 0013 是回想中的她自己的反应，不是当下对制作人说的话。
- 0016 的说话人是「一同」，应是撫子、四音等極月学園的人一起笑，不算她的台词；在场还有谁看不出。
- 制作人是早就拿下了这个企划，还是听她哭诉后才拿出来，剧本只写了 0021 他直接拿出资料，没交代时间先后。
- 【译文】0030「次の夏」中文译为“明年夏天”，原文只说“下一个夏天”，是否跨年剧本没明说。
