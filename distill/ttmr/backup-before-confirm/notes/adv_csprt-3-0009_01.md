# S卡 3-0009【わたしたち、やればできる】/ 第1话 烹饪复仇赛！（adv_csprt-3-0009_01）

- 她的台词：6 行（含用匿名标签说的 0 行）
- 出场的人：千奈、佑芽、広、手毬、一同（0003）
- 场景：烹饪实习的补习之补习
- 世界线：S卡【わたしたち、やればできる】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
千奈、佑芽、広要在烹饪实习的“补习的补习”中复仇。手毬路过，说“又是落后生在干奇怪的事”。听到是补习的补习，她说第一次听说。被问要不要试吃，她沉默，然后问做什么、上次做了什么。佑芽说上次是用自己的方式还原姐姐的食物糊，広说里面混了她的血。手毬说“不用了，我在减肥”，千奈说她认为一定会失败，佑芽说以后想吃也晚了。

## 她的关键台词
- 0004「……うわ、また落ちこぼれたちが／変なことしてる。」——不留情面的第一印象

- 0013「ちなみに……なにを作るの？」——沉默后问内容，其实有点在意
- 0015「前回は、なにを作ったの？」——继续确认

## 行为模式
- 看到别人做奇怪的事 → 先吐槽，但会停下来问内容（0004、0013、0015）
- 听到听起来很危险的东西 → 以“减肥”为理由礼貌拒绝（0018）
