# S卡 3-0012【また、あんなに無理をして】/ 第3话 即使吵架也心有灵犀（adv_csprt-3-0012_03）

- 她的台词：5 行（含用匿名标签说的 0 行；0005、0017 为括号内心声；0011 是想象中的话）
- 出场的人：美鈴、手毬、ボーカルトレーナー、一同
- 场景：声乐特别课（只面向1年级中实力出众的学生）
- 世界线：S卡【また、あんなに無理をして】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
ボーカルトレーナー宣布这次特别课是面向1年级中实力突出的学生。手毬和美鈴同时想到“竟然要在这样的场合一起上课”。手毬问“什么？”，美鈴说“没什么”。一同的内心说，不用说话也知道对方想说什么：手毬想的是“美鈴很厉害，偷懒太可惜”；美鈴想的是“まりちゃん不要勉强”。最后两人各自决定今天稍微努力一点/稍微收敛一点。

## 她的关键台词
- 0005「（美鈴と……）」——内心，意识到和美鈴同课
- 0008「なに？」——被美鈴视线注意到后的冷淡反应
- 0011「――美鈴は凄いやつなんだから、／怠けるのはもったいないよ。」——不是实际说出，是两人想象彼此想说的话（0010、0013）
- 0015「……ふん。」——回避/不坦率
- 0017「（今日は、すこしだけ……／控えめにしておくか）」——内心决定稍微收敛

## 行为模式
- 与美鈴同场 → 表面冷淡（“なに？”“ふん”），内心则在想美鈴的才能和可惜（0008、0011、0015）
- 被对方的心意影响 → 决定做一点让步（今天稍微收敛）（0017）

## 关系
- 美鈴：内心称「美鈴」；美鈴称「まりちゃん」；两人没有真正交谈，只靠想象彼此的意思（0004、0005、0011、0012）

## 不确定

- 0003、0006、0007、0010、0013 的「一同」台词里手毬的参与情况，属于合说的内心声。
