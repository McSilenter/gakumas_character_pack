# 雨夜燕 亲爱度剧情 / 第33话（adv_dear_atbm_033）

- 她的台词：3 行（含匿名标签 0 行）
- 出场的人：燕、ことね、星南、千奈、佑芽、美鈴、手毬、燐羽
- 场景：初星学园（练习室，以及燕巡视校园时），『H.I.F』本战之前；美鈴与手毬正准备『SyngUp!』解散演唱会

## 发生了什么
燕到练习室看美鈴她们，说自己为手毬/燐羽办的转校后使用练习室的手续出过力，并说没想到她们不参加『H.I.F』。美鈴把自己对『H.I.F』的心愿托付给燕。手毬向燕道谢，并替美鈴解释“这是害羞的掩饰”。其后场景转到燕与新学生会、ことね、星南的对话，手毬不在。

## 她的关键台词
- 0005「お疲れ様です、雨夜先輩。」——对燕的礼貌问候，称「雨夜先輩」
- 0006「燐羽やライブの件、／いろいろとありがとうございます。」——为燐羽的手续和演唱会的事向燕道谢

## 行为模式
- 受前辈照顾 → 礼貌道谢，并主动提到燐羽的事（0006）
- 美鈴嘴硬说反话 → 直接向对方点破“是照れ隠し”，美鈴因此慌张（0023、0024）
