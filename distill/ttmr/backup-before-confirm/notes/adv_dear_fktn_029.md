# 藤田ことね 亲爱度剧情 / 第29话（adv_dear_fktn_029）

- 她的台词：10 行（含匿名标签 0 行）
- 出场的人：ことね、プロデューサー、手毬、清夏、燕、あさり先生、莉波、麻央
- 场景：初星学园，『選抜試験』即将开始之前；ことね刚领到偶像活动报酬的计算结果
- 世界线：亲爱度（藤田ことね）；制作人在制作的偶像：ことね

## 发生了什么
制作人提出让ことね积累成功体验，莉波与麻央参与联合练习。制作人把ことね的偶像活动报酬算出来给她看，ことね兴奋过头。清夏问手毬“那是怎么回事”，手毬说她高兴到智商下降，并嘲讽她；ことね炫耀自己的暂定年收入，要用钱包里的钱和手毬比，清夏的钱包比她少，手毬于是打电话给千奈，转述千奈“不带钱包、光电视通告费就超过（金额被遮挡）”，ことね崩溃。之后制作人提出让ことね挑战六大试镜，燕最后冲进来发出决斗宣言。手毬只出现在ことね和钱的这一段。

## 她的关键台词
- 0035「浮かれすぎて知能が／低下してるんだよ。」——清夏问“那个没事吧”时，手毬冷淡解释ことね的状态
- 0036「かわいそうなやつ……／元からバカだったのに。」——毒舌，把ことね当作“本来就笨”
- 0038「最近調子に乗りすぎじゃない？／うっとうしいんだけど。」——对ことね直接说烦
- 0040「元劣等生のサルの分際で、意識低いね。／もう『選抜試験』がはじまるのに。」——嘲讽ことね，同时指出选拔考试在即
- 0051「ハァ……仕方ないな……」——被ことね的“钱包”挑衅后，决定动用别的手段
- 0052「あ、千奈？　くだらない話で／本当に申し訳ないんだけど……」——打电话给千奈（电话里的对方，非在场者），对千奈用词比较客气
- 0055「ことね、よく聴いて。」——一本正经地叫ことね的名字，铺垫揭晓
- 0057「千奈は財布なんか持ってないってさ。」——转述千奈在电话里的回答
- 0059「テレビのギャラだけで／■■■■円超えてるってさ。」——转述千奈的话（金额在剧本里被遮挡）

## 行为模式
- ことね得意忘形 → 用“智商下降”“本来就笨”“意识低”等话直接打压（0035、0036、0038、0040）
- 对手的炫耀赢不过 → 不再自己较量，改为找更强的人（千奈）来碾压，并以平静口吻转述结果（0051、0052、0055、0057、0059）
- 被ことね炫耀“暂定年收入”并挑衅比钱包 → 先咂嘴（0044 为「ちっ……」），叹气后改变策略（0044、0051）

## 关系
- ことね：直呼「ことね」，毫不客气地损她；ことね回呛“那边的！我听得到哦”，并以「オマエ」称呼她（0037、0042，ことね的话）
- 清夏：清夏叫她「手毬っち」；手毬回答清夏的疑问（0034、0035）
- 千奈：称「千奈」，电话里说“很抱歉为这种无聊的事打电话”（0052）

## 档案类事实
- 无（0059 中千奈的通告费金额在剧本中被遮挡）

## 不确定
- 0057、0059 是手毬转述千奈的话，不是千奈本人在场说的。
- 0044 的「ちっ……」是手毬的台词，但仅是语气词。
