# 秦谷美鈴 亲爱度剧情 / 第23话（adv_dear_hmsz_023）

- 她的台词：18 行（含匿名标签 0 行）
- 出场的人：美鈴、手毬、燐羽、一同
- 场景：『H.I.F』本战结束后（夏季），手毬、美鈴、燐羽三人聚在一起
- 世界线：亲爱度（秦谷美鈴）；制作人在制作的偶像：美鈴（本篇制作人不出场，由世界线推断）

## 发生了什么
燐羽开“败犬嘲笑大会”，手毬生气，燐羽说特训的成果出来了，但“还是输了”。手毬和美鈴一同输给了十王星南；燐羽感叹星南厉害，手毬说“这点本事她得有，毕竟她背着我们憧憬过的『一番星』”。美鈴说自己尊敬副会长和星南会长，承认这次完败，并说自己的竞争对手只有月村手毬，所以要手毬更强，于是郑重提出“请和我一起加油”。手毬问是不是听错了，美鈴说“万般不情愿地”。手毬高兴地说终于等到这句话，要一起特训。燐羽问美鈴其实很不甘心吧，美鈴装糊涂。

## 行为模式
- 被燐羽刺（又鼓励又嘲讽） → 直接要求“选一个”，随后立刻转向“下次赢”（0014、0015）
- 输给对手 → 先承认不甘心，同时把对方的强视为理所当然（0019、0032）
- 美鈴说她的话听上去像是认真（“一起加油”） → 不断确认，听到答案后兴奋过头（0046～0058）
- 注意到美鈴没有同样的情绪 → 直接问出来（0033、0035）

## 关系
- 美鈴：称「美鈴」；美鈴说“我的竞争对手始终只有月村手毬”（0036）；手毬提出的特训邀请被美鈴“万般不情愿”接受（0050～0055）
- 燐羽：称「燐羽」；燐羽的特训成果被承认，也被说“输了”（0007、0011、0013）
- 星南：称「十王星南」，认为她强是应当的（0019、0020）

## 档案类事实
- 手毬和美鈴都输给了十王星南，也输给了副会长（燕）（0017、0018、0029，燐羽、美鈴的话）
- 燐羽曾给手毬做特训（0007，燐羽的话）
- 手毬等人从前憧憬过『一番星』（0020、0021）
