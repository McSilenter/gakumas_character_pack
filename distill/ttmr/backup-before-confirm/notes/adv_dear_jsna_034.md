# 十王星南 亲爱度剧情 / 第34话（adv_dear_jsna_034）

- 她的台词：11 行（含用匿名标签说的 0 行）
- 出场的人：星南、手毬、美鈴、燐羽、十王社長（星南回忆中）、一同
- 场景：『H.I.F』当天、星南登台之前，美鈴、手毬、燐羽三人来到星南面前（0001-0002、0050）。星南今年毕业（0056）。
- 世界线：亲爱度（十王星南）；制作人在制作的偶像：看起来是星南本人（0007 星南提到“彼”，即制作人，0046 说“遇到了制作人”；同时星南临时担任美鈴等人的制作，0007、0016、0063）。制作人本人在此篇无台词。

## 发生了什么
美鈴、手毬、燐羽来看星南的舞台。手毬为解散演唱会的事向星南道谢，请她向制作人转达问候（0005-0006）。燐羽是星南的粉丝，手毬向星南交代了这一点（0011）。星南让三人不必拘谨，手毬说会慢慢调整距离感（0028-0029），随后问星南为什么至今没有加入100プロ（0032）。星南讲出当年十王社長对她说“プロでは通用しない”的经过（0038-0047），并说现在想专注于『H.I.F』四连霸（0050-0051）。手毬表示没能参加这次『H.I.F』很不甘心（0053），最后答应总有一天会进入职业世界（0059）。

## 她的关键台词
- 0005「解散ライブの件、／お世話になっております。」——对星南用敬语道谢，涉及解散演唱会
- 0011「こいつ、会長のファンなんです。」——称燐羽为「こいつ」，对星南称「会長」
- 0029「さすがにそれは……わかりました。／すこしずつ距離感を調整していきます。」——被允许直呼名字时先犹豫再接受，说要慢慢调整距离
- 0030「じゃあ、その一環というわけ／じゃないですけど。踏み込んだ質問を／してもいいですか？」——先征求许可再问深入的问题
- 0032「――どうして、まだ100プロに／入っていないんですか？」——毫不拐弯地直问
- 0035「そのときに、プロ入りの話が／なかったとは思えなくて。」——说明提问理由，根据推测追问
- 0053「ほんとだよ。仕方ないとはいえ、／今回の『H.I.F』に出ていないことが／悔しいな。」——对美鈴用タメ口，坦白不甘心
- 0059「はい……いずれ、必ず。」——对星南“你们也会来职业世界吧”的回答

## 行为模式
- 被前辈说“可以随意些” → 先说“那有点……”再接受，并说明会“慢慢调整距离感”（0028、0029）
- 想知道的事 → 先问“可以问深入一点的问题吗”，得到许可后直截了当地问，并附上推测理由（0030、0032、0034、0035）
- 对前辈/会长 → 用敬语，称「星南先輩」「会長」；对美鈴、燐羽 → タメ口（0026、0011、0053）
- 提到没能参加『H.I.F』 → 明说“不甘心”（0053）

## 关系
- 星南：称「星南先輩」（0026）、「会長」（0011）；星南叫她「手毬」，说她“不必那么丁寧”，今后会长久来往（0021、0028）。
- 美鈴：对她说话是タメ口，美鈴叫她「まりちゃん」（0052-0053）。
- 燐羽：称她「こいつ」，说她是会长的粉丝（0011）。

## 档案类事实
- 手毬、美鈴、燐羽是一年级（0062 星南说“不像是一年级学生会说的话”）。
- 手毬没有参加这次『H.I.F』，对此感到不甘心（0053）。
- 关于解散演唱会，她向星南和制作人道谢（0005-0006）。

## 不确定
- 0004 美鈴说“お世話になっているプロデューサーの晴れ舞台”，0016 又说星南是“わたしのプロデューサー”：星南与制作人各是谁的什么关系，此篇表述有点绕，未下结论。
- 0007 星南说“美鈴のプロデュースに必要なことだもの”，指的是什么事（解散演唱会相关？）剧本里没写明。
- 【译文】0004 译文加了“我们”（“一直关照我们的制作人”），原文是「お世話になっているプロデューサー」；0007、0063 等把「プロデュース」「担当」译为“培育”“负责”，影响不大。
