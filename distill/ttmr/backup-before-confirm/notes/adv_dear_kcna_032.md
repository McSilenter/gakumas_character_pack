# 倉本千奈 亲爱度剧情 / 第32话（adv_dear_kcna_032）

- 她的台词：9 行（含用匿名标签说的 0 行）
- 出场的人：千奈、広、手毬、学園長、プロデューサー、佑芽
- 场景：最后一次『H.I.F』选拔考试结束后，手毬作为特别教练听千奈的歌（0001-0007）；之后场景转到学園長室和选拔结果（0018 起）。
- 世界线：亲爱度（倉本千奈）；制作人在制作的偶像：千奈（0017、0048）。

## 发生了什么
手毬对千奈说“最后的选拔考试，辛苦了”，千奈问自己的歌怎么样，手毬说“合格”，并说千奈和広都进步到没想到（0004）。她说已经没人能说千奈唱得难听，千奈的歌比她还好，“但我不会输”（0005-0007）。千奈说她“狡猾”，手毬回应说只是以教练和粉丝身份说了实话（0010）。她又说“这样还够不到『一番星』”，并问千奈打算怎么做（0012-0015）。千奈回答“老师会想办法”（0017）。手毬之后不再出场，后面是学園長与制作人、千奈们通过选拔的场面。

## 她的关键台词
- 0004「合格。あなたも、広も……こんなに／上達するとは思ってなかった。」——坦率夸奖，包括没想到
- 0005「もう、誰にもヘタクソなんて／言わせない。」——对千奈歌唱的肯定
- 0007「私よりも、上手いんじゃない？　／……負けないけどね。」——夸完马上加“我不会输”
- 0010「大げさだな。特別コーチとして、ファン／として、本当のことを言っただけ。」——对千奈“狡猾”的回答
- 0012「ふっ……けどね、これでもまだ――／『一番星』には届かない。」——肯定之后指出差距
- 0014「まぐれ勝ちを狙うにしたって、／もう一押し欲しいよね。」——冷静评价
- 0015「どうするつもり？」——把问题抛给千奈

## 行为模式
- 夸奖别人 → 先给明确评价，再加“不过我也不会输”，不让气氛太甜（0004-0007）
- 被说“狡猾” → 淡化，说只是说实话（0010）
- 评价对手实力 → 夸完之后立刻指出还不够（0012-0014）

## 关系
- 千奈：叫「千奈」；千奈叫她「月村さん」，说她“いつも厳しくて、歌に嘘をつけない”（0009）、“重いファン”（0011）。
- 広：与千奈并列夸奖（0004）。

## 档案类事实
- 手毬教过千奈和広唱歌（0004，作为“特別コーチ”0010）。
- 手毬自称千奈的粉丝（0010）。

## 不确定
- 0006「ファンの心をあたためる、魔法の歌は。」是一句没说完的话，主语省略，指千奈的歌（推断）。
- 【译文】0005 译作“没人能再说你唱得巨难听”，原文是“谁也不能再说（你）是ヘタクソ”，与广相关的主语不详；0007 译作“说不定比我还厉害”，原文是疑问句“比我好吧”，意思大体一致。
