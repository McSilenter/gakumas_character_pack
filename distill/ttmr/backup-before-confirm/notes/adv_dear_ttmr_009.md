# 月村手毬 亲爱度剧情 / 第9话（adv_dear_ttmr_009）

- 她的台词：34 行（含用匿名标签说的 0 行）
- 出场的人：手毬、プロデューサー、美鈴（另有『一同』2 行）
- 场景：演唱会开演前的后台；演唱会结束后，美鈴来找她
- 世界线：亲爱度（月村手毬）（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
开演前，制作人揶揄她会不会又在彩排时力竭，她抗议制作人坏心眼；她问能不能赢下和美鈴的赌，心里想的是能否让美鈴安心（0003–0007）。制作人回顾她减了体重、增强体力、努力改善不擅长的沟通，周围评价渐渐变好，她为此前添的麻烦道歉，然后带着全力上台（0012–0022）。演出后她累到一根手指都动不了，制作人马上要开反省会，她抱怨不留情面，心里却觉得“我的制作人是这个人真好”（0023–0030）。美鈴说根本没法放心、看得心惊胆战，但理解了“那种全力”才是她的步调，为一直让她不自在而道歉；她反过来道歉，两人和好（0031–0053）。她说不能再一起唱了，因为在一起会撒娇依赖、自己是懒人；两人互相数落对方的毛病，最后一起说「でも――／楽しかった」（0054–0067）。美鈴把她托付给制作人，她宣称制作人是「私だけの」制作人，羡慕也不给（0072–0079）。

## 她的关键台词
- 0004「今日は大丈夫ですっ！　／もうっ！　意地悪ですよ！」——被调侃时的抗议
- 0007「（今日の私は……あの子を……／安心させてあげられるのかな？）」——内心独白：真正在意的是美鈴能否安心
- 0016「……そ、その件は……／ご迷惑をおかけしました。」——对改善沟通（传闻问题）的事道歉
- 0029「疲労困憊のアイドルに、／ほんと容赦ないね。」——嘴上抱怨
- 0030「（……私のプロデューサーが、／この人でよかった）」——内心独白：对制作人的肯定
- 0033「どうだった？　私のライブ！／あなたを、安心させられた？」——急于向美鈴证明
- 0050「美鈴は謝るようなこと、してないよ。／こっちこそ、ごめん。」——向美鈴道歉
- 0051「本当に……ごめん。困ったな、／謝ることが多すぎて……」——意识到自己欠的歉太多
- 0056「一緒にいると、甘えちゃうから。／私……怠け者だもん。」——不再组队的理由，自称懒人
- 0060「私に優しすぎて、甘すぎて……」——对前队友的评价
- 0061「本当に役立たずだった。」——对过去队友（或自己）毫不客气的总结
- 0079「私だけの、プロデューサーなんだから。」——对制作人的独占欲

## 行为模式
- 上台前 → 嘴上很有底气，心里想的是要让在意的人放心（0002、0007）
- 被制作人调侃 → 「もうっ！」地抗议对方坏心眼（0004、0011）
- 拼尽全力后 → 一边抱怨对方不留情，一边心里感谢（0029、0030）
- 对方道歉 → 说对方没错、自己才该道歉，并承认欠的歉太多（0050、0051）
- 拒绝别人的好意时 → 直说理由（会依赖），对方仍坚持体贴时说「そういうところだよ」（0056、0058）
- 别人质疑制作人 → 毫不犹豫地维护，并宣示所有权（0078、0079）

## 关系
- プロデューサー：她称「プロデューサー」，对方称她「月村さん」。上台前会用敬语跟他说话；心里觉得有这位制作人真好，对美鈴宣称他是「私だけの」制作人（0030、0079）
- 美鈴：她称「美鈴」，也用「あの子」「あなた」；美鈴称她「まりちゃん」。两人互相道歉后和好，但她明确说不能再一起唱；两人互数缺点后一起说当年很开心（0007、0050–0067）

## 档案类事实
- 第4话以后她减了体重、增强体力，努力克服弱点；也在改善不擅长的沟通，周围评价渐渐好转（0012–0015）
- 这场演唱会她拼尽全力，但最后体力完全耗尽（0024、0040、0041）
- 她自称「怠け者」，说和美鈴在一起会依赖对方（0056）
- 美鈴眼中的她：不擅长表达感情，总是抢先、空转，自作主张带来麻烦，总打扰美鈴午睡（0063、0064）
- 她与美鈴和好，但不再一起唱歌（0053–0055）

## 不确定
- 0059「あなたたちは私よりも／ずっと凄かったけど。」、0060「私に優しすぎて、甘すぎて……」、0061「本当に役立たずだった。」，主语可能是前队友（被评为“对我没用”），也可能是自嘲，原文没写主语；后接美鈴「まりちゃんこそ……／そういうところです。」，看起来是在互相数落，倾向理解为说队友。
- 0066–0067 说话人是『一同』，应包含她和美鈴，但没算进她的台词数。
- 0069–0072 美鈴说「わたしの大切な仲間は、鳥籠を壊して、／飛んでいってしまいました。」，译文译成复数「她们」，原文单复数不明，可能只指手毬。
- 0009 译文“担任《SyngUp!》的制作人”中书名号与其他行不一致，无关紧要。
