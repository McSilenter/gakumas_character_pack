# 月村手毬 亲爱度剧情 / 第20话（adv_dear_ttmr_020）

- 她的台词：38 行（含用匿名标签说的 0 行）。其中 0004～0007 是燐羽回忆里她当年说的话，不是本篇当下的发言。
- 出场的人：手毬、プロデューサー、燐羽、一同、旁白
- 场景：『NEXT IDOL AUDITION』（『N.I.A』）优胜演唱会结束之后；前半是燐羽的场面，后半她在会场外找人，和制作人谈话。
- 世界线：亲爱度（月村手毬）（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
旁白交代优胜演唱会结束、『NEXT IDOL AUDITION』落幕（0001）。燐羽看完后说「手毬のくせに。やるじゃない」，想起组成『SyngUp!』的理由——回忆里当年的手毬说在燐羽旁边唱歌能变得更好、燐羽比电视上的偶像厉害得多、请她教自己当偶像（0002～0008）；随后燐羽叫上「恥さらしども」，说契约期未满，要重新锻炼她们（0010～0013）。另一边，她夺冠后想向燐羽炫耀胜利，跑出会场到处找人却谁也没找到，抱怨没人来祝贺，被制作人用正论驳回后心情低落（0014～0036）。制作人向她道谢，说确信她必能成为顶级偶像、实现他的梦想（0040～0044）。她纠正说「夢じゃなくて、目標」，回顾他一直跟着自己、拉着手推着背把自己带到这么高的地方，并回应说确信他会让自己成为顶级偶像，要证明他是最棒的制作人（0045～0058）。

## 她的关键台词
- 0005「燐羽の隣で歌うと、／もっともっと上手くなれるから！」——（燐羽回忆中的过去发言）当年她想和燐羽一起唱歌的理由。
- 0007「私に――アイドルを教えてよっ！」——（燐羽回忆中的过去发言）当年请燐羽教她当偶像。
- 0018「くっ……優勝したからには、／燐羽にも勝ち誇っておきたかったのに！」——夺冠后第一个念头是向燐羽炫耀。
- 0022「いま自慢しなくてどうするんですか！？」——毫不掩饰想炫耀的心情。
- 0026「ず～～～～～っとヘタクソ呼ばわり、／格下扱いされてきた恨みっ！」——长年被燐羽叫「ヘタクソ」、看低的积怨。
- 0031「誰も会いに来ないのは／どうしてなんですかプロデューサー！」——想被祝贺却落空，向制作人发牢骚。
- 0035「私、正論は好きじゃないです。」——被正论说中时的典型反应。
- 0041「いつもの嫌味……じゃ、／ない……ですよね。」——制作人突然道谢让她不知所措。
- 0046「夢じゃなくて、目標でしょう？」——把制作人的「梦想」改为可实现的「目标」，呼应过去的约定。
- 0048「私についてこられるなら、だけど。」——回顾当初对制作人说过的条件。
- 0050「それどころか……私の手を引っ張って、／背を押して、肩を貸して、声をかけて。」——坦率表达对制作人一路支持的感谢。
- 0056「あなたがいれば……私の翼は、／本物よりも高く飛べる。」——对制作人的信赖之深。
- 0058「トップアイドルを導き育てた、／最高のプロデューサーだって！」——反过来要证明他的价值。

## 行为模式
- 取得成果 → 想马上向看低过自己的人炫耀、要对方承认（0018、0022、0026、0027）
- 被劝“以后还有机会”→ 一度接受，随即反悔坚持当下（0024、0025）
- 被正论驳倒 → 「正論は好きじゃない」，情绪低落（0033～0036）
- 制作人认真道谢 → 先慌张怀疑是不是挖苦，然后认真回应（0040、0041）
- 被托付梦想 → 纠正成「目標」，用当初的约定回应，并把感谢和信赖说出口（0045～0058）

## 关系
- プロデューサー：她称「プロデューサー」「あなた」，他称「月村さん」「あなた」。他道谢并说她会实现他的梦想；她回顾他一路的扶持，说有他在自己能飞得更高，要证明他是最棒的制作人。本篇是两人互相确认信赖的场面（0042～0058）。
- 燐羽：她称「燐羽」。过去她请燐羽教自己当偶像（燐羽回忆，0004～0007）；如今她赢了燐羽，想报一直被叫「ヘタクソ」、被看低的仇。燐羽在背后说「手毬のくせに。やるじゃない」（0002、0018、0021、0026）。
- 美鈴：她说自己赢了美鈴（0021）。
- 咲季、ことね、極月学園的人：找不到燐羽时说哪怕他们来也好（0029）。

## 档案类事实
- 她代表初星学園在『N.I.A』（『NEXT IDOL AUDITION』）夺冠（0001、0030）。
- 过去她对燐羽说过在燐羽身边唱歌能变得更好，请燐羽教她当偶像；燐羽回忆这是组成『SyngUp!』的理由（0003～0007）。
- 她长期被燐羽叫「ヘタクソ」、当作「格下」（0026）。
- 她曾对制作人说过，只要他能跟上她，他的目标就能实现（0047、0048）。

## 不确定
- 0004～0007 标签是『手毬』，但夹在燐羽的心声「思い出した……／『SyngUp!』を結成した理由」（0003）和（0008）之间，应是燐羽回忆里她当年的话，不是本篇当下所说。
- 0007 译文“教我——”漏译了「アイドルを」。
- 0019「そういうところだと思いますよ？」意思应是“（你的问题）就在这种地方”，译文“这种性格才是你吧？”不准。
- 0010 燐羽叫的「恥さらしども」、0011『一同』具体是谁剧本没写明；燐羽 0008 说「あいつら」，看起来是指 SyngUp! 的成员，她是否在场不确定（后半她在找燐羽，像是不在）。
- 0040 制作人道谢的台词没有出现在剧本里（直接接她的反应），具体说了什么不明。
