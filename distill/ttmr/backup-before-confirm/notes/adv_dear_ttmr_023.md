# 月村手毬 亲爱度剧情 / 第23话（adv_dear_ttmr_023）

- 她的台词：49 行（含用匿名标签说的 0 行）
- 出场的人：手毬、プロデューサー、美鈴、学園長
- 场景：夏季『H.I.F』结果发表（学園長宣布）之后；先是她和美鈴两人，之后她回到制作人那里，美鈴随后一起来提案。
- 世界线：亲爱度（月村手毬）（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
学園長宣布夏日『一番星』是十王星南，她和美鈴都输了（0001～0004）。美鈴说没料到被「邪魔」，她反而说背负着两人憧憬的『一番星』招牌，就该有这种水平；她坚持把两人之间的胜负分清楚，说「私の負けだから！」，并宣布要在冬季『H.I.F』夺冠，向美鈴和十王星南复仇（0005～0025）。她回到制作人身边，两人默契地要马上开反省会；制作人说「いい勝負でした」，她说只是拼命唱、没够到（0032～0043）。制作人分析她的歌打破了美鈴造成的异样气氛、让大会成功，如果自己是评委她才是『一番星』；她说输了就是输了，但道谢，说因为他替自己不甘心，今晚不用哭了，随即切换心情宣布复仇开始（0044～0066）。美鈴提议『SyngUp!』三人一起特训，并顺便办『SyngUp!』解散演唱会；她一度表示「わりと乗り気」，但被制作人以会两头落空为由否决后接受，说等一切结束再办（0067～0092）。制作人说到那时她已是顶级偶像，并预测十王星南很快会成为顶级偶像、『一番星』会变成顶级偶像的称号；她对他的信赖感到「重っ」，最后承诺再也不辜负他的期待（0093～0107）。

## 她的关键台词
- 0004「私たちの負けだね、美鈴。」——落败后先平静接受。
- 0014「ま、このくらいやってもらわないと／話にならないよ。」——不贬低胜者，反而认可。
- 0015「なんたって、私たちが憧れた――」——『一番星』是她和美鈴共同的憧憬。
- 0019「私の負けだから！」——在和美鈴的私人胜负上主动认输，要分清楚。
- 0023「キッチリさせておかないと、／スタンスが定まらないよ。」——重视胜负分明。
- 0034「言うと思った。／さすが私のプロデューサーだね。」——和制作人想法一致时的得意。
- 0036「あなたのパートナーですから。」——自认是制作人的搭档。
- 0043「結局、届きませんでした。」——败后坦白不甘。
- 0054「負けは負けです。」——不找借口。
- 0058「プロデューサーが代わりに、／たくさん悔しがってくれたから。」——制作人为她不甘，让她得到安慰。
- 0063「今夜は泣かずに済みそうです。」——透露本来会哭。
- 0065「合理的に、ストイックに、／がむしゃらに、私たちらしく。」——她认定的“两人的做法”。
- 0079「理由は？　／私、わりと乗り気なんだけど。」——对解散演唱会的提议有兴趣。
- 0084「すべてを懸けなきゃ……／勝てるわけない。」——接受制作人的理由，专注于胜负。
- 0105「目が据わってる……信頼、重っ。」——对制作人过重的信赖小声吐槽。
- 0107「約束するよ。／あなたの期待、二度と裏切らない。」——对制作人的承诺。

## 行为模式
- 输掉比赛 → 先平静接受，承认对手的实力，然后马上设定复仇目标（0004、0014、0024、0025）
- 胜负模糊 → 坚持分清楚，哪怕是认自己输（0019、0022、0023）
- 被制作人安慰 → 先说「負けは負けです」，再道谢，并承认被他的不甘所救（0054～0063）
- 情绪处理完 → 主动「切り替え」，把精力转向下一步（0064～0066）
- 制作人讲出有道理的反对意见 → 认可并说服美鈴（0082～0086）
- 被寄予过重的期待 → 吐槽「重っ」，然后承诺回应（0105～0107）

## 关系
- 美鈴：她称「美鈴」，美鈴称「まりちゃん」。两人都输给十王星南；她坚持认输于美鈴，并要在冬季复仇。美鈴提议三人特训和解散演唱会，她对后者有兴趣，最后说「ぜんぶ終わってからにしよう」（0004～0025、0079、0086）。
- プロデューサー：她称「プロデューサー」「あなた」，他称「月村さん」，说「うちの月村さん」。她自称「あなたのパートナー」「私のプロデューサー」；他为她不甘心，说她才是自己心中的『一番星』，她因此不哭，并承诺不再辜负他的期待（0034～0036、0061～0063、0103、0107）。
- 十王星南：夏季『H.I.F』的『一番星』，她称其「会長」，列为复仇对象（0002、0025、0102）。
- 賀陽燐羽：『SyngUp!』成员之一（美鈴称「りんちゃん」，提到其退学）；制作人让美鈴转告「賀陽さん」不要拖她后腿（0028、0071、0091）。

## 档案类事实
- 夏季『H.I.F』的『一番星』是十王星南，她没拿到（0001、0002、0004）。
- 『一番星』是她和美鈴所憧憬的（0015）。
- 下一个目标：冬季『H.I.F』夺冠成为『一番星』（0024、0070）。
- 她和美鈴、燐羽三人曾组成『SyngUp!』；美鈴提议三人特训（制作人同意）和解散演唱会（制作人否决，延后到一切结束后）（0071～0092）。
- 她称十王星南为「会長」（0102）。

## 不确定
- 0076「なっ……！？」标签是『美鈴』，但紧接在美鈴自己提出解散演唱会之后，惊讶的人更像是她或制作人；说话人可疑。另一方面 0079 她又说「わりと乗り気」，所以惊讶者是谁说不准，本笔记没有把这行算成她的。
- 0049「盛り下がった」原意是“气氛更冷”，译成“更没悬念”不准。
- 0019 她说「私の負けだから！」，是指本次两人之间她输给美鈴；剧本里没有给出两人的名次。
