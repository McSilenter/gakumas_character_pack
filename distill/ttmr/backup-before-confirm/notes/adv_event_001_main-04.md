# 活动 001 1年级1班的偶像们 / main-04 第4话（adv_event_001_main-04）

- 她的台词：7 行（含用匿名标签说的 0 行）
- 出场的人：咲季、ことね、清夏、手毬
- 场景：1年1組教室，歌唱对决之后。清夏找ことね参加联谊会；咲季发现ことね疲劳。
- 世界线：活动 001（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
咲季说自己现在只有手毬一个朋友，手毬说不记得和她成过朋友；咲季让她叫自己“咲季”，手毬叫了一声“咲季”，又说“烦人”。清夏改成午休教室派对，ことね答应。咲季看出ことね疲劳，ことね承认打工很多。手毬责问ことね，怎么能总是带着不适上课、放学后也不练习不休息，只是打工，并质疑她还算不算偶像。ことね带着刺回应（“月村同学这种自我要求高的人看不惯我这种要求低的人”）。咲季给ことね按摩，ことね决定重新考虑。

## 她的关键台词
- 0009「私、花海と友達になった覚え／ないんだけど。」——否认咲季的“朋友”说法。
- 0011「なってないから。」——重复否认。
- 0014「咲季。」——被要求叫名字时叫了，但只是照做。
- 0016「うっとおしい。」——对咲季的亲近的反应。
- 0044「なにそれ、いつも体調不良のまま／レッスンを受けてるってこと？」——得知ことね疲劳后，第一反应是质疑她的训练状态。
- 0045「放課後、自主練習も休養もせず、／アルバイトばかりしているってこと？」——以自主练习和休养为标准批评。
- 0046「信じられない……／それでアイドルのつもりなの？」——用“是否还算偶像”来责问，不问理由。

## 行为模式
- 被要求叫名字/亲近 → 叫了，但随后嫌烦（0014、0016）。
- 看到同学不练习而打工 → 不问原因，用自己的标准（练习、休养）责问并质疑其偶像资格（0044–0046）。
- 被ことね反击后她没有再接话（0047–0049 之后手毬无台词）。

## 关系
- 咲季：此篇开始叫“咲季”（0014）；咲季认为已是朋友，手毬不认（0009–0011）。
- ことね：以责问的口吻对她；ことね叫她“月村サン”（0047），带讽刺。
