# 活动 016 / main-03 第3话（adv_event_016_main-03）

- 她的台词：30 行（含用匿名标签说的 0 行）；其中 0017、0018（和可能的 0025）出现在回忆段落里
- 出场的人：手毬、ことねの妹、燐羽、ことね、咲季
- 场景：体育中心的击球练习场，手毬教ことね的妹妹打棒球；中间插入手毬的回忆（燐羽教她击球）。
- 世界线：活动 016；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
手毬教ことね的妹妹用最慢速度击球，妹妹总是挥空，手毬让她休息，心里想着自己不擅长跟小孩说话。妹妹道谢后，她说自己也想挥棒。她对妹妹说“打到了就会很有意思”，同时回想起过去自己练习击球、对着燐羽说“打不到、一点都不有趣”，燐羽教她握法并说同样的话。妹妹讲起ことね在家说起手毬：歌唱得好、对自己严格但温柔、其实很尊敬她。妹妹问学校里的ことね，手毬说最初印象不好（整天打工），但ことね舞跳得最好、特别努力，“很了不起”。最后妹妹在ことね面前打出球，手毬重复“打到了就会开心”。

## 她的关键台词
- 0001「グリップはこう握って。／タイミングを合わせて――振り抜く！」——教学语言简短直接；与燐羽 0022 说的是同一句。
- 0003「球速は一番遅いモードだし。／慣れればすぐ打てるようになるよ。」——给初学者设定最低难度。
- 0008「バットに振り回されてるよ。／闇雲に振ってもだめ。」——指出问题时不留情面但具体。
- 0011「（子供と話すのは、苦手……）」——内心独白，承认不擅长与小孩相处。
- 0012「（子供向けのイベントでも、／私だけ、なんか怖がらせちゃうし……）」——内心独白，说明为何不擅长。
- 0014「べつに……私もひさしぶりに、／バット振りたかったし。」——被道谢时的别扭回应，给自己找理由。
- 0016「打てるようになると、／結構楽しいから。」——对妹妹说的鼓励；0024 燐羽说过同样的话。
- 0018「……無理。打てない。／こんなの全然面白くない。」——回忆里的自己，因打不到而放弃。
- 0026「めちゃくちゃ打ってるとこ、／ことねに見せたいでしょ？」——用“想在姐姐面前展示”激励妹妹。
- 0028「咲季みたいに上手には／教えられないけど――」——承认自己不擅长教。
- 0031「……ことねが？／私のこと、何か言ってた？」——听妹妹提到ことね，立刻追问。
- 0037「へ、へーえ……ふーん。／……そうなんだ……」——得知被ことね尊敬时的掩饰性反应。
- 0043「最初の印象は、／正直、あんまり良くなかったよ。」——坦白对ことね的最初印象。
- 0044「アルバイトばっかりしてて、／本気でアイドルになる気あるのかって。」——印象差的原因。
- 0046「誰よりもダンスが上手くて、／めちゃくちゃ努力してて、」
- 0047「すごい奴だよ。本当に。」——对ことね的评价，转为肯定。
- 0058「言ったでしょ。／打てるようになると、楽しいって。」——结尾，用自己先前的话作为总结。

## 行为模式
- 教小孩却不顺利 → 先具体指出问题（肩膀太用力、被棒子带着走），觉得累了就让人休息（0006、0008、0010）。
- 被道谢 → 别扭地说“我自己也想挥”（0014）。
- 想激励对方 → 用“能打到后很有趣”和“想给姐姐看吧”（0016、0026）。
- 听到别人说自己好话 → 追问，再用“へーえ、ふーん”掩饰（0031、0036、0037）。
- 被问朋友的事 → 先坦白最初印象不好，再说明朋友的优点（0043-0047）。

## 关系
- ことねの妹：叫她（没有叫名字）；妹妹叫她“手毬お姉ちゃん”。她教妹妹击球，并被妹妹转述ことね的看法。
- ことね：直呼“ことね”（0031）；认为她舞跳得最好、特别努力（0046、0047）。ことね这边：妹妹转述“歌が上手い、自分に厳しい、本当は優しい、尊敬している”（0033-0035）。
- 燐羽：回忆里教她击球的人，她回忆时叫出“りんは”（0017）；燐羽说话较重（0019「なに、諦めるの？　根性無し。」）。
- 咲季：她拿咲季当教学的标杆（0028）。

## 档案类事实
- 她在回忆中被燐羽教过击球，一开始打不到，被燐羽鼓励后继续练（0017-0025）。
- 她觉得自己不擅长与小孩相处，参加面向儿童的活动时总吓到人（0011、0012）。
- ことね妹妹说ことね在家会讲学校的事（0032），说她歌很好、对自己严格、其实温柔（0033、0034）。
- 她对ことね最初的印象是“整天打工、有没有决心”，后来改观（0043-0047）。

## 不确定
- 回忆的范围：0017「りんはぁ……」开始，0018 是回忆里的她（带“手毬”标签）；0019-0024 是燐羽；0025「……――」是回忆还是现在不能确定；0026 回到现在。回忆的时间（多大年纪）剧本没有说。
- 0001 与燐羽 0022 的台词完全相同、0016 与燐羽 0024 的台词完全相同，说明她是在照燐羽教自己的话教别人。
- 0035 妹妹转述ことね的话时语气像在模仿ことね（“本人にはぜってー言わねーけどぉ”），是转述，不是ことね的现场发言。
