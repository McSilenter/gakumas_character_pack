# 活动 027 / main-01 夏风连衣裙 第1话（adv_event_027_main-01）

- 她的台词：10 行（含用匿名标签说的 0 行）：0001、0002、0004、0006、0008、0014、0019、0020、0024、0028
- 出场的人：星南、手毬、美鈴、一同
- 场景：学园内，生徒会长星南的召见
- 世界线：活动 027；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
手毬被叫到十王会長（星南）这里，美鈴也在。星南说初星学园与各大厂商合作的大型联动企划已决定，第一弹是明年夏天发售的运动饮料，她想与美鈴、手毬三人挑战。手毬表示光荣，答应。美鈴趁机再次劝她加入生徒会，手毬说会挤占偶像活动时间所以不入，又对星南与美鈴的互动一脸无语。星南说此企划还会有第二弹、第三弹，要让这次成功，三人齐声回答"是"。

## 她的关键台词
- 0002「十王会長、お呼びでしょうか。」——称星南为「十王会長」，用敬语
- 0006「いえ……用件をうかがっても？」——对星南致歉的回应，礼貌地问事由
- 0008「すごいですね……！」——对大型联动企划的反应
- 0014「光栄です。／もちろん、お引き受けします。」——毫不犹豫地接下
- 0019「またその話？」——对美鈴的生徒会邀请，显出这已不是第一次
- 0020「アイドル活動の時間が減るから／入らないよ。」——拒绝的理由是偶像活动时间
- 0024「……………………………………」——被星南和美鈴当着面调侃后沉默
- 0028「十王会長っていつもこんな感じなの？」——小声问美鈴，对星南的作风感到意外

## 行为模式
- 被学生会长召见 → 保持敬语，礼貌地问理由，接活很爽快（0002、0006、0014）
- 被反复邀请入生徒会 → 先用"又来"表达不耐，再直接说理由（0019、0020）
- 在两个人的互动面前 → 沉默，然后小声问美鈴（0024、0028）

## 关系
- 星南：叫「十王会長」；星南叫她「月村さん」，两人之间是前辈与后辈的礼貌关系（0002、0005）
- 美鈴：用「美鈴」称呼，对话不用敬语；美鈴叫「まりちゃん」，一直在邀请她入生徒会（0004、0018、0019、0028）
