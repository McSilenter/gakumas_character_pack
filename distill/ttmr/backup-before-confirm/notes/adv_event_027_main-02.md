# 活动 027 / main-02 夏风连衣裙 第2话（adv_event_027_main-02）

- 她的台词：23 行（匿名标签 0 行）
- 出场的人：手毬、美鈴、星南、一同
- 场景：运动饮料广告的会议室（剧本里只说是要开会、之前美鈴让手毬试穿过很多衣服；具体地点未写）
- 世界线：活动 027；制作人在制作的偶像：看不出（剧本里没有制作人出场）

## 发生了什么
手毬穿着美鈴挑的罩衫（スモック）出现在星南面前，星南起初困惑，随后觉得“和歌声的反差”不错，手毬因被会长夸奖而得意，结果错过了提出换衣服的时机。会议开始后，美鈴提议把歌词里的『白いワンピース』用作服装，并讲了小时候两家人去旅行、在向日葵田里手毬穿白色连衣裙的回忆。手毬回应说当时美鈴也穿同样的裙子，并说自己当时担心美鈴会消失。手毬接着提出在一支广告里换几套衣服来表现不同人的夏天，星南采纳，并提出想穿泳装，众人惊讶，第2话到此结束。

- 0007「ふたりで考えていたんです。」——对会长用敬语，说明服装是她和美鈴一起想的

- 0017「（会長がそこまで言うなら、／ギャップを狙うのもありなのかも！）」——心里话，被会长（星南）一夸就改变想法
- 0018「私、なんでも着こなせますから。」——被夸后立刻自信起来
- 0023「（着替えを言い出す／タイミングを逃した！）」——心里话，不好意思开口换衣服
- 0026「（美鈴ぅぅぅぅぅぅぅううう～～！！）」——心里话，向美鈴发出怨念
- 0044「………………あ、あのときはっ／お、同じワンピース……着てたじゃん。」——被美鈴说成“天使”后害羞，转而说对方也穿了
- 0046「儚くて、消えてしまいそうだなって……／すごく心配になっちゃったんだよね。」——说出小时候对美鈴的感受
- 0053「1本のコマーシャルの中で、／何着か衣装を着るのはどうでしょうか？」——主动向星南提出自己的企划
- 0054「スポーツ飲料を飲む場面は様々、／だから色々なひとの夏を／衣装の変化で表現できないかと思って。」——说明提案理由

## 行为模式
- 被星南（会长）夸奖 → 先惊讶确认“本当ですか”，心里高兴，立刻改变态度并自夸（0015、0016、0017、0018）
- 被美鈴直白夸“可爱” → 沉默后小声道谢（0019、0020）
- 美鈴说出她小时候的样子 → 惊讶，害羞地反过来说对方也很合适（0041、0044、0045）
- 对会长有想法要提 → 先用“それなんですけど……”开口，再给出理由（0052、0053、0054）
- 想做的事没说出口时 → 在心里喊美鈴的名字（0023、0024、0026）

## 关系
- 美鈴：叫「美鈴」；美鈴叫她「まりちゃん」。心里对美鈴的行为又气又默认（0024、0026）；两人是青梅竹马，美鈴自己说“幼馴染ですから”（0049）
- 星南：叫「会長」，对她用敬语；被她夸会很开心（0015～0018）；星南称她「月村さん」（0014）

## 档案类事实
- 小时候月村家和秦谷家暑假经常一起去旅行（美鈴所说，0037）；有一年住过附近有向日葵田的旅馆（0038）
- 手毬小时候穿过白色连衣裙，美鈴也穿过同样的（0044、0045）
