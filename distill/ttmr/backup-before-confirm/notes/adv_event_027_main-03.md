# 活动 027 / main-03 夏风连衣裙 第3话（adv_event_027_main-03）

- 她的台词：28 行（匿名标签 0 行）
- 出场的人：手毬、星南、美鈴、一同
- 场景：与第2话相连的广告会议（地点未写）；星南最后离开去联系对方，之后只剩手毬和美鈴
- 世界线：活动 027；制作人在制作的偶像：看不出（剧本里没有制作人出场）

## 发生了什么
星南提出想穿泳装，并说明因为广告用歌写的是高三女孩在最后一个夏天和不想分开的人去海边，她想表现这份勇气；还拿出一件自己从去年起一直想穿的泳衣。手毬问了理由后，先问美鈴的意思，美鈴说手毬觉得可以她就可以，手毬便接受泳装，条件是拍摄结束后星南陪她练习一天，星南答应。星南走后，美鈴问手毬是否真的没问题，手毬说身材管理有美鈴帮忙，并说这是和过去的自己告别的机会、更想要自信。最后约好拍完去吃拉面。

- 0003「会長って水着グラビアのお仕事は、／断っているんだと思ってました。」——对星南的了解，直接发问

- 0042「1日だけでいいので、レッスンを／見てもらえないでしょうか？」——借机向星南提出指导的请求

- 0060「美鈴には……ないの？」——想问美鈴却又收回（0062），关心对方
- 0064「撮影が終わったら、／また、一緒にラーメン食べに行かない？」——邀约美鈴

## 行为模式
- 听到出乎意料的提议 → 先问理由，再决定（0010、0012、0034、0035）
- 接受对方条件时 → 同时提出自己想要的回报（0039～0042）
- 在美鈴面前 → 说话变成随意口吻，说出想“拥有自信”这类真心话（0053～0058）；对美鈴想多问却又收回（0060～0062）
- 说到拉面 → 高兴地说“やったっ！”并鼓劲（0066、0068）

## 关系
- 星南：叫「会長」，用敬语；想请她指导练习一天（0042）
- 美鈴：叫「美鈴」；美鈴叫她「まりちゃん」，担心她是否真的没问题（0050）；约好一起去吃拉面（0064、0065）；手毬想问美鈴有没有那样的心情，又没说（0060～0062）

## 档案类事实
- 她说最近身材管理保持得不错，是美鈴帮忙（0054）
- 她和美鈴以前一起去吃过拉面（0064 “また”）
- 她想在这次拍摄中与过去的自己告别，拥有自信（0056、0058）
