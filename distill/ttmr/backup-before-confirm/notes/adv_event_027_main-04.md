# 活动 027 / main-04 夏风连衣裙 第4话（adv_event_027_main-04）

- 她的台词：10 行（匿名标签 0 行）
- 出场的人：星南、美鈴、手毬、スタッフ、一同
- 场景：广告拍摄现场（摄影棚），拍摄开始前
- 世界线：活动 027；制作人在制作的偶像：看不出（剧本里没有制作人出场）

## 发生了什么
三人向工作人员打招呼后在等候区等待。手毬因照片与视频要一天拍完而担心，美鈴让她放松笑一笑；手毬说自己唱歌和演技完全不同，经验不足。星南说美鈴没有睡过头真好，手毬接话说会长也辛苦，美鈴说两人的话她都听到了。个人照从手毬开始拍，手毬紧张地应声去拍摄。之后是美鈴和星南的对话（星南解释为什么让大家一起定主题），手毬只在被叫去拍摄时出场。

- 0003「同じく、初星学園1年。／月村手毬です。／よろしくお願いいたします！」——正式场合的自我介绍
- 0007「写真撮影も動画撮影も、／1日で済ませるのは大変そうですね……」——对工作量的担心

- 0015「歌と演技は全然違います。／まだまだ経験不足……かもしれません。」——承认自己在演技上的不足
- 0017「ありがとうございます！／今回は頼もしいふたりと一緒ですから。」——对星南和美鈴表示依赖

- 0024「……まぁ、慣れっこです。」——美鈴爱睡觉的事她已经习惯
- 0030「衣装を綺麗に切り替えられるか、が／勝負――ですね！」——抓到工作的要点
- 0033「――は、はい！」——被点名第一个拍摄时紧张

## 行为模式
- 登台前紧张 → 紧绷，被美鈴提醒后重复“笑”这个词（0010～0012）
- 被指出紧张 → 不否认，说明是因为唱歌和演技不同（0015）
- 与星南谈美鈴的睡觉毛病 → 用敬语但直接地附和，表示自己习惯了（0022、0024）

## 关系
- 星南：叫「会長」，对她用敬语；星南称她「月村さん」
- 美鈴：美鈴叫她「まりちゃん」，劝她放松（0011）；星南说美鈴“真的很珍视月村同学”，美鈴回答“食べちゃいたいぐらい大好きです”（0035、0036，星南与美鈴的对话，她不在场）

## 档案类事实
- 手毬自述在演唱会上能唱得很放松，但演技经验不足（0014 是星南的话，0015 是手毬的回答）
- 美鈴有睡过头的习惯，手毬说自己习惯了（0018～0024）
