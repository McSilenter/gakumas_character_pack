# 月村手毬 培育剧情 001 / opening-true-02 为了更接近梦想（adv_pstory_001_ttmr_opening-true-02）

- 她的台词：7 行（含用匿名标签说的 0 行）
- 出场的人：手毬（本篇没有其他人的台词）
- 场景：培育剧情 001 的 true 开场之一。她找制作人商量增加练习。地点、时间看不出。
- 世界线：培育（月村手毬），培育剧情 001；制作人在制作的偶像：月村手毬（她称「私のプロデューサー」，0006）

## 发生了什么
- 她找制作人商量：最近状态非常好，能不能增加レッスン（0001、0002）。
- 她说「わかりました。」，又说如果对成为トップアイドル有帮助就一定试试（0003、0004），像是在回应制作人没写出的提议。
- 她把话拉回来，再问一次能不能加练（0005）。
- 随后称赞「さすが私のプロデューサー」很好说话，说要更努力、学会新的スキル（0006、0007）。

## 她的关键台词
- 0002「最近、すごく調子がよくて。／レッスンを増やしてもいい？」——状态好时主动要求加练。
- 0004「トップアイドルになるために／役立つのなら、ぜひ。」——判断标准是对成为トップアイドル是否有用。
- 0005「話を戻すけど、／レッスンを増やしてもいいですよね？」——坚持自己的要求。
- 0006「さすが私のプロデューサー……／話がわかるね。」——称对方「私のプロデューサー」。
- 0007「もっともっと頑張って……／新しいスキルを身につけてみせます。」——向上心。

## 行为模式
- 状态好 → 主动要求加练（0002）。
- 对方提出别的建议 → 只要对成为トップアイドル有用就接受，但会把话题拉回自己的要求（0003～0005）。
- 要求被同意 → 夸制作人，再表决心（0006、0007）。

## 关系
- プロデューサー：称「プロデューサー」「私のプロデューサー」（0006）；平语和敬语混用（0002、0005）。

## 档案类事实
- 目标是成为トップアイドル（0004）。

## 不确定
