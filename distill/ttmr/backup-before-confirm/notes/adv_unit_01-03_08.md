# 主线 第1部 3章 我们是Re;IRIS / 3章8话（adv_unit_01-03_08）

- 她的台词：12 行（含用匿名标签说的 0 行）
- 出场的人：プロデューサー、咲季、ことね、佑芽、手毬、一同
- 场景：试吃会之后，制作人解释要培育佑芽半个月的理由
- 世界线：主线（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
制作人给出三个理由：想亲手培育佑芽；为三人的选拔考试做最终调整（四人特别课程）；最重要的是需要强大的对手，大家一起培养。手毬一开始问"那当初直接招募她不就好了"，被咲季和佑芽异口同声拒绝（会不能一较高下）。手毬在听到"想亲手培育"时流露出吃醋，心里骂制作人"花心"。咲季兴奋地接受，手毬说自己负责教她们唱歌，让ことね教舞蹈，并且劝说ことね，理由是咲季不会听劝，以及制作人的判断从没错过。佑芽同意后，手毬向她说"请多指教"。

## 她的关键台词
- 0010「そこまで言うなら、」／0011「彼女もスカウトすればよかったんじゃないですか？」——制作人那么看重佑芽，为什么不招募她
- 0026「彼女への未練が感じられます。正直、面白くないです。」——口头直说不高兴
- 0027「（わ、わわ、私というものがありながら）」——内心独白，把自己当成被冷落的一方
- 0029「（プロデューサーの、浮気者ぉ～～～～～！）」——内心独白，对制作人"移情别恋"的抱怨
- 0042「ライバル……？」——对制作人的第三个理由的反应
- 0055「言うと思った。なら私は、3人に歌を教えるよ。」——立刻接受计划并分工，已料到咲季的反应
- 0056「ことねはダンスを私たちに教えて。」——分配任务给ことね
- 0059「こうなった咲季が言うことを聞くわけない。それに、」／0060「プロデューサーの判断が間違ってたことないから。」——说服ことね的理由，明确对制作人判断的信任
- 0070「よろしく、佑芽。」——正式接纳佑芽

## 行为模式
- 制作人对别的偶像表现出重视 → 嘴上表达不满，内心独白用夸张的"出轨"说法（0026-0029）
- 计划确定后 → 立刻分工、负责自己擅长的（唱歌），并去说服犹豫的人（0055、0056、0059、0060）
- 对咲季的反应 → 能提前预料（0055）

## 关系
- プロデューサー：嘴上说"面白くない"，内心把它当成被抛弃；但又断言"判断从没错过"（0026-0029、0060）
- 咲季：理解其性格，用"咲季说不听"来作理由（0059）
- 佑芽：称「佑芽」，正式欢迎（0070）
- ことね：分工、说服（0056、0059、0060）
