# 主线 第1部 4章 Hatsuboshi IDOL FESTIVAL / 4章4话（adv_unit_01-04_04）

- 她的台词：19 行（含用匿名标签说的 0 行）
- 出场的人：ことね、咲季、手毬、プロデューサー、一同
- 场景：Re;IRIS 的训练结束后，离与 Begrazia 对决（选拔考试）还有约一个月（0007）。制作人分别找ことね、手毬、咲季单独谈话，最后宣布新曲。
- 世界线：主线（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
训练结束时手毬想继续练，被咲季以“过度练习适得其反”劝住，她让步，又嫌咲季「乖孩子」的说法太自来熟（0004–0011）。制作人先找ことね谈，ことね坦白在偷偷考虑输了怎么办；接着制作人注意到手毬表情严肃，手毬说自己在想美鈴为什么加入会长的组合，并说美鈴大概恨她，但自己很高兴，一定要彻底击溃对方（0050–0065）。随后制作人又找咲季谈，咲季坦承对佑芽害怕。手毬看到两人窃窃私语，追问（0086），被咲季搪塞过去。最后制作人发表新曲『雨上がりのアイリス』，手毬看着曲子说“这是我们的曲”（0092）。

## 她的关键台词
- 0004「……いいところだったのに。ねぇ、もう少しだけ……」——想继续练习，对训练的执着，语气带点撒娇式的央求
- 0009「……わかった。咲季の言うとおりにする。」——被咲季说服后让步，会听咲季的话
- 0011「……馴れ馴れしいな。」——被咲季说「いい子ね」后小声嫌弃，不直接接受亲昵
- 0054「………………美鈴のことを、考えていました。」——被制作人问到表情时，沉默后才说出心里想的是美鈴
- 0055「怠け者のくせに、どうしてよりにもよって……」——对美鈴的评价是「怠け者」，不解她为何选了会长的组合
- 0057「恨まれているのは、わかっていたんですけど……」——认定美鈴恨自己
- 0061「上から目線のいけすかないやつだと思っていたので。」——对美鈴的旧印象，毫不客气
- 0062「やっと直接殴れる位置に立ってくれたなって。」——把美鈴站到对立面当成好事，用「殴る」表达斗志
- 0063「やっとまっすぐこっちを見たなって……」——嫌弃之外，也透出盼着美鈴正面看自己
- 0065「叩き潰してやります、必ず。」——对决意志
- 0086「ねぇ、さっきからふたりでこそこそして……なんなの？」——察觉别人在背后说话会直接问，不绕弯
- 0092「これが……私たちの曲。」——拿到新曲时的感慨，用「私たち」

## 行为模式
- 被劝停训练 → 先小声抱怨想再练，接着服从咲季（0004、0009）
- 被咲季当小孩一样夸奖 → 嫌对方过分亲近（0011）
- 被制作人看出心事 → 先说「別に、なんでも」，叹气后才说实话（0053、0054）
- 被问到对美鈴的怨恨时 → 不消沉，反而说「嬉しい」「わくわくしてる」，转成要击溃对方的斗志（0060、0064、0065）
- 觉得别人在背后嘀咕 → 直接追问（0086）

## 关系
- 咲季：直呼「咲季」，听从她的训练安排（0009）；被她用「いい子ね」称呼会不满（0010、0011）
- ことね：这一篇里两人没有直接对话
- 美鈴：称「美鈴」，说对方「怠け者」「上から目線のいけすかないやつ」，认为被对方怨恨，也想与之正面对决（0054–0065）
- プロデューサー：用敬语（「恨まれているのは、わかっていたんですけど」「叩き潰してやります」等）；制作人称她「月村さん」（0050）

## 档案类事实
- 与美鈴是旧识，她说对美鈴「昔から」印象是上から目线（0060、0061）
- 她认为美鈴是个怠け者（0055）
- 她认为美鈴怨恨她（0057）
- 新曲『雨上がりのアイリス』被制作人定位为Re;IRIS的代名词（0095、0096，制作人台词）
- 对 Begrazia 的对决，Re;IRIS 的下一步是选拔考试（0089）

## 不确定
- 0054–0058 里手毬只说「美鈴」「恨まれている」，没有说为什么被恨，剧本里没交代。
- 0026–0030 ことね说这场对战是「非公式な対バン」，「選抜結果には、あんま関係ない」，但 0089 制作人说「選抜試験に向けて方針を伝えます」，05 也写“選抜試験当日”。【冲突】0029「言ってみれば非公式な対バンですし――」／0030「選抜結果には、あんま関係ないまでありますよね。」与 0089「では、選抜試験に向けて方針を伝えます。」对不上，对战与选抜试验是否同一件事、有无关系，两边都保留。
- 0039 的『一番星』（译文作「启明星」）在这一篇指什么没有写明，只能看出是ことね要对抗的对象。
