# 提炼：O3-pstory（43 篇，世界线：培育（月村手毬）——培育剧情 001、培育剧情 002、培育剧情 003 各是一次独立的培育；成长剧情 001 也记在培育线）

**读法说明（本组通用）**
- 本组全部是培育线，制作人在制作的偶像都是月村手毬。三部培育剧情是三次不同的培育，彼此不连续，下面分开写；成长剧情 001 是三段训练师的短评，制作人不出场。
- 培育剧情几乎每篇都是 2～3 段**并列分支**：接在同一句台词后面，中间制作人的选项或发言没写进剧本（conflicts.md 第四节）。下面凡写“分支①②③”的，都是“同一件事的不同版本”，**不是先后发生的事**；制作人选了哪个选项剧本里没有，不替他认定。
- 培育剧情 001 的文件也是并列关系：opening-normal-02～05、opening-true-01～02 是不同版本的开场；after-step-1-normal-01～03、after-step-2-normal-01～03 是同一阶段的不同事件；after-audition-mid/final-normal-01～04 按考试结果分档（01 最好的结果／02 合格但不是第 1／03 「まずまず」／04 「ギリギリ」）；ending-normal-01～05（A～E End）和 ending-true-01 是不同结局。同一档只会走一条，资料里只算一次。
- 培育剧情 002 的 after-audition-a-normal-02／-03、after-audition-b-normal-02／-03 也是同一场オーディション的两个结果分支（一个赢得漂亮，一个险胜）。

## 2. 说话方式

**对制作人**
- 称呼：「プロデューサー」最多；也叫「あなた」（adv_pstory_001_ttmr_opening-normal-03 0002；adv_pstory_001_ttmr_after-audition-mid-normal-02 0012；adv_pstory_001_ttmr_after-audition-final-normal-01 0028；adv_pstory_002_ttmr_ending-normal-02 0006）；得意时说「さすが私のプロデューサー……／話がわかるね。」（adv_pstory_001_ttmr_opening-true-02 0006）。
- 平语和敬语混用，同一篇里经常来回换。大致规律：
  - 开场、立规矩、亲近或放松时用平语：「プロデューサー、／足だけは引っ張らないで。」（adv_pstory_001_ttmr_opening-normal-02 0004）、「早く次に行こうよ、プロデューサー。」（adv_pstory_001_ttmr_ending-true-01 0025）。True End 全篇平语。
  - 正式问候、汇报、抗议、讲道理、闹别扭时多用敬语：「おはようございます、プロデューサー。」（adv_pstory_002_ttmr_opening-normal-02 0001）、「納得できません。説明してください。」（adv_pstory_002_ttmr_before-audition-a-normal-01 0004）、「プロデューサーって、／デリカシーないですよね。」（adv_pstory_001_ttmr_after-audition-final-normal-02 0022）。被说服时会用很正式的「そう……ですね。／おっしゃる通りです。」（adv_pstory_001_ttmr_after-audition-mid-normal-04 0010）。
  - 激动时敬语脱落：「なんでいつもそうやって、私の台詞を／わざわざ蒸し返してくるの！？」（adv_pstory_002_ttmr_after-audition-b-normal-03 0008）；D End 骂完用敬语，消气后转平语「そういう台詞が聞きたかったんだよ。」（adv_pstory_001_ttmr_ending-normal-04 0025）。
  - 培育剧情 002、003 和成长剧情里整体偏敬语。

**自称、口癖、句尾**
- 自称「私」。立目标时用全名自称：「いま……月村手毬が上を目指すために、／なにが必要だと思う？」（adv_pstory_001_ttmr_after-step-1-normal-02 0007）、「完璧に仕上がった、／月村手毬のステージを！」（adv_pstory_002_ttmr_ending-normal-02 0008）、「月村手毬による、リベンジの舞台に！」（adv_pstory_003_ttmr_final-normal-02 0002）。
- 口癖“望むところ”（句尾だよ／です）：面对严格安排、低评价、甚至食物奖励都这么回。「望むところだよ。」（adv_pstory_001_ttmr_after-step-1-normal-01 0022）、「の、望むところです！！　／トップアイドルになるためなら――」（adv_pstory_001_ttmr_after-step-1-normal-03 0016）、「望むところです……！」（adv_pstory_001_ttmr_ending-normal-03 0008）。
- 「淡々と」：提醒自己别被结果左右。「淡々と、淡々と。／やるべきことをやっていこう。」（adv_pstory_001_ttmr_after-audition-mid-normal-01 0008）、「淡々と行こうか、プロデューサー。」（adv_pstory_001_ttmr_after-audition-final-normal-03 0023）、「淡々と上るべき。／そうわかってはいるんですけど。」（adv_pstory_001_ttmr_before-audition-final-normal-01 0009）。
- 「もっと、もっと」叠用：「こんなんじゃダメだ……！／もっと、もっと頑張らなくちゃ……！」（adv_pstory_001_ttmr_after-audition-mid-normal-04 0006）、「もっともっともっともっと／頑張って――」（adv_pstory_002_ttmr_opening-normal-02 0004）。
- 常用“～てみせる”：「絶対に痩せてみせる……！」（adv_pstory_001_ttmr_after-step-2-normal-03 0015）、「口だけじゃないって、／証明してみせる！」（adv_pstory_001_ttmr_after-audition-final-normal-02 0014）、「私……どこまでも高く飛んでみせる。」（adv_pstory_001_ttmr_opening-normal-05 0005）。
- 「ふん」带过被夸：「……ふん。褒め言葉と／受け取っておく……一応。」（adv_pstory_001_ttmr_ending-normal-01 0013）。

**各种情绪时**
- 生气：「はい出た！　イヤミ！！」（adv_pstory_002_ttmr_after-audition-b-normal-03 0006）；「プロデューサーって、／本当に性格悪いですよね。」（adv_pstory_001_ttmr_ending-normal-05 0019）；「こっ、この……悪魔……！」（adv_pstory_001_ttmr_ending-normal-04 0009）。

- 撒娇、讨夸：「べ、別に少しくらいなら……／いま褒めてもいいよ。」（adv_pstory_001_ttmr_after-step-2-normal-01 0025）；心声「（もっと褒めて欲しかったのに～っ！）」（adv_pstory_002_ttmr_after-audition-b-normal-02 0015，括号心声）。
- 逞强：「は？　絶好調ですが？」（adv_pstory_001_ttmr_before-audition-mid-normal-01 0019）；「ちょっぴりだけ！　増えたのは　／ちょっぴりだけだから！」（adv_pstory_001_ttmr_after-step-2-normal-03 0009）；「まぁ、いけると思ってましたけどね。」（adv_pstory_002_ttmr_after-audition-b-normal-03 0004）。

**称呼**
- 她 → 制作人：「プロデューサー」「あなた」「私のプロデューサー」（出处见上）。
- 她 → 美鈴：「美鈴」；她 → 燐羽：「燐羽」（adv_pstory_002_ttmr_after-audition-a-normal-03 0013；adv_pstory_002_ttmr_ending-normal-02 0006）。

## 3. 人物关系
