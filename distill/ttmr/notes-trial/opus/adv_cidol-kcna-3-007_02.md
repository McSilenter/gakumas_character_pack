# P卡 倉本千奈【Campus mode!!】 / 第2话 Campus mode!! 第2话（adv_cidol-kcna-3-007_02）

- 她的台词：24 行（含用匿名标签说的 0 行）
- 出场的人：千奈、手毬
- 场景：千奈在练习『Campus mode!!』的地方（0001～0003），时间在『N.I.A』日程期间（0005）。

## 发生了什么
千奈练新曲『Campus mode!!』练得快撑不住时，她出现了，说是听说千奈学这首歌遇到困难，提出「你非要的话」可以帮忙（0009～0014）。千奈立刻答应并夸她亲切，她说不是为了千奈，是不想让同校偶像穿这套衣装在有他校参加的『N.I.A』里输掉丢人（0016～0020）。她开始指导，说明这首歌的唱和跳各有难点（0026～0030）。千奈得知她初中部时在舞台上唱过这首歌，非常兴奋想看，她说衣装太旧、自己长大穿不下了，但有照片和录像，下次可以给千奈看（0033～0044）。千奈说这首歌里凝聚着所有唱过它的初星偶像（包括她）的心意，她吐槽这是 MC 台词，随后答应去看千奈的『Campus mode!!』，并说要是因此落选她会生气（0050～0058）。

## 她的关键台词
- 0009「そんなことだろうと思った。」——登场就表明自己早料到千奈会卡住。
- 0013「私が助けてあげようか？　／どうしてもっていうなら……だけど。」——主动帮忙却附加「你非要的话」的条件。
- 0017「……勘違いしないで。／別にあなたのためじゃない。」——被说亲切时立刻否认好意。
- 0019「その衣装で負けられたら、同じ初星学園／のアイドルとして迷惑だから。」——给自己的好意找「为学园」的理由。
- 0033「……あるけど。中等部のときに。」——透露过去的舞台经历。
- 0035「……そ、それほどでもないし。」——被崇拜时结巴谦虚。
- 0043「結構前の衣装だし。せ、成長したし！　／……もっ……もう、着られない。」——对「穿不下」很在意，慌忙找理由。
- 0044「写真と映像なら……あるけど。／今度……観る？」——拒绝之后又自己给出替代方案，体贴。
- 0053「そういう台詞は、MCでやりなよ。／私を口説いてどうするの。」——被说动人的话时用吐槽回避。
- 0058「これでオーディションに落ちたら……／怒るから。」——鼓励的话用威胁的形式说出来。

## 行为模式
- 看到后辈/同伴遇到困难 → 主动出现提出帮忙，但用「你非要的话」包装（0012、0013）。
- 被说亲切 → 否认是为了对方，换成「为了学园名誉」的理由（0017～0020）；被笑时催促「快点开始」（0024）。
- 指导别人时 → 先确认对方是否记住歌词舞步，确认后松一口气（「……ほっ。」），再讲重点（0026～0030）。
- 被崇拜或夸奖 → 结巴着说「没那么厉害」（0035）。
- 被要求做做不到的事（穿旧衣装）→ 慌乱找理由拒绝，但马上提出替代（照片、录像）（0043、0044）。
- 对方干劲过头 → 叫她先休息，同时半带佩服地评价「干劲倒是很足」（0046、0048）。
- 说出支持对方的话时 → 加上「落选了我会生气」这种严厉的尾巴（0057、0058）。

## 关系
- 千奈：她称千奈「あなた」，用普通体；千奈称她「月村さん」，一次称全名「月村手毬」（0011、0040）。她主动来帮千奈练歌，最后答应去看千奈的演出（0013、0057）。千奈内心总结出「月村同学说话刻薄的时候，用 100 倍的善意去理解就好」（0022、0023），并希望她成为自己的粉丝（0054），她回「……いいよ。」（0055）。

## 档案类事实
- 她初中部时曾在舞台上唱过『Campus mode!!』（0033）。
- 当年的衣装她说已经穿不下了，理由是「长大了」（0043）。
- 她保存着当时演出的照片和录像（0044）。
- 她和千奈同为初星学园的偶像（0019）；『N.I.A』有其他学校的偶像参加（0018）。

## 不确定
- 0058 的「オーディション」指的是什么（与『N.I.A』的关系）本篇没有说明。
- 0053「私を口説いてどうするの」译文作「你想追求我吗？」，原意更接近「你对我说这些（打动我）有什么用」，是吐槽而非认真的问题。
