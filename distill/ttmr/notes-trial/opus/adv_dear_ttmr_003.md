# 月村手毬 亲爱度剧情 / 第3话（adv_dear_ttmr_003）

- 她的台词：41 行（含用匿名标签说的 0 行）
- 出场的人：手毬、プロデューサー
- 场景：她主动去找制作人（「プロデューサー、いる？」，0001），来取制作人准备的餐食（0014）；地点应是制作人所在的地方，未写明。

## 发生了什么
她来取餐，被制作人指出头发睡翘了、胸前扣子没扣好，她嘴硬说是发型、骂对方多管闲事（0005～0012）。她承认饭很好吃，但担心那样的菜单和分量会胖、觉得应该更克制，制作人说这正是不调的第三个原因，吃喜欢的东西能让身心恢复（0016～0025）。她发现制作人知道自己喜欢吃什么，嘴上说「恶心、变态」，随后道谢，并表示虽然不信任任何人，但会报恩、暂且听从指示（0027～0038）。制作人问她状态崩溃的最大原因，她说是去年和伙伴组的组合大吵一架后解散，觉得是自己毁了大家的梦想和期待，所以学园里没人信任她（0042～0055）。她问制作人为什么招募她，得到「为了培育顶级偶像」的回答后，说出自己的目标是成为人人认可的顶级偶像，并说「前提是你跟得上我」（0057～0066）。

## 她的关键台词
- 0006「えっ！？　……こっ、こういう／ヘアスタイルなんです。」——被指出仪容问题时硬撑的借口。
- 0016「……美味しかったです。／ご馳走様、でした。」——认真道谢，承认饭好吃。
- 0021「でも、もっと我慢した方が……／いいんじゃないか……って。」——对饮食过度克制的心态。
- 0029「気持ち悪いです。／変態なんじゃないですか？」——被关心到细处时先用恶言掩饰。
- 0033「それとこれとは話が別です。／私は、誰も信頼しない。だけど……」——明确的立场：不信任任何人。
- 0034「恩は返します。」——但受了恩会还，有自己的原则。
- 0036「私がなにを恩に感じるかは、／私が決めることです。」——自己的感受自己决定，不容他人定义。
- 0048「仲間を失ったこと。」——说出状态崩溃的根本原因。
- 0052「自分たちの夢と、みんなの想いを……／私が台無しにしたんです。」——把组合解散的责任归到自己身上。
- 0053「だからこの学園で、／私を信頼するやつなんかいない。」——认为自己在学园里被所有人看低。
- 0064「誰もが認める／トップアイドルになることです。」——说出目标。
- 0066「私についてこられるなら、だけど。」——在交心之后仍维持高姿态。

## 行为模式
- 被指出仪容不整 → 先找硬撑的借口，再反问对方看哪里、骂多管闲事（0006、0008、0010、0012）。
- 被问到感受时 → 能老实承认好的东西（「美味しかった」），并补一句礼貌的「ご馳走様」（0016）。
- 吃东西 → 担心发胖，倾向于过度克制（0018、0021）。
- 发现对方为自己做了细心的调查和照顾 → 先用「恶心、变态」否定，停一下再正式道谢（0029～0031）。
- 被问「是不是信任我了」→ 否认信任，但把「报恩」「听指示」作为另一回事承诺下来（0033～0038）。
- 被追问痛处 → 先骂对方性格恶劣、明知故问，然后自己说出来（0045～0048）。
- 谈到过去的失败 → 把责任揽到自己身上，并推出「所以没人会信任我」（0052、0053）；反过来说愿意和她搭档的制作人是「怪人」（0054、0055）。
- 对方直白说出目标 → 她也用同样直白的方式说出自己的目标，并附上「跟得上我才行」的条件（0059、0063～0066）。

## 关系
- プロデューサー：称「プロデューサー」；本篇语气在敬语和普通体之间切换（「なに？」0004、「食事を受け取りにきただけ。」0014 为普通体；0065「よかったね、プロデューサー。」）。制作人称她「月村さん」（0002）。她仍说「完全不信任」（0037），但承诺报恩和听指示（0034、0038），并主动说出过去和目标；制作人内心判断「似乎得到了一点信任」（0039）。
- 去年的伙伴们：称「仲間」，没有提名字；去年一起组成组合，大吵后解散（0048～0050）。

## 档案类事实
- 去年为止她和伙伴们组成组合，后来大吵一架解散（0049、0050）。
- 大家都对那个组合抱有期待，本该站上更大的舞台；她认为是自己毁了大家的梦想和期待（0051、0052）。
- 她认为学园里没有人信任她，和她搭档会被戴有色眼镜看待（0053、0055）。
- 她的目标是成为人人认可的顶级偶像（0064）。
- 她在吃制作人准备的餐食，觉得好吃（0014、0016）。
- 她今天头发睡翘、胸前扣子没扣（制作人指出）（0005、0009）；制作人把仪容不整、偏食、心理疲劳都归因于失去伙伴（0043、0044）。
- 制作人知道她喜欢吃的食物（0027、0028）。

## 不确定
- 她喜欢的食物是什么没有明说；制作人在她说「你知道我喜欢吃什么」后接「偶尔也会做炸物」（0027、0028），暗示可能是炸物，但不是明文。
- 组合的名字、成员是谁本篇没有说。
- 0022 制作人说的是「不調の原因その3」，中文译文作「原因之一」，以原文为准。
