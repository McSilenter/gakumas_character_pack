# 月村手毬 培育剧情 001 / ending-true-01 True End（adv_pstory_001_ttmr_ending-true-01）

- 她的台词：33 行（含用匿名标签说的 0 行）
- 出场的人：手毬、プロデューサー
- 场景：大成功的演出当天晚上（0005、0020），制作人在一个安静的地方回顾演出，她找过来（0001、0002）。

## 发生了什么
演出大成功后，她找到独自回顾演出的制作人。她说观众都因她的歌而高兴，接着问制作人本人觉得她的歌怎么样（0009～0013）。听完后她说那已经是她现在的极限，并马上要商量下一步，把这次成功称为「只是过程」（0014～0025）。（另一处反应中）她说这是最好的表现、现在做不出更好的了，所以想听制作人的评价；制作人说今天给他的感动是全世界独一份，她把这句话接成「那下次要让全世界的人也这么认为」，认为那才是顶级偶像（0027～0042）。最后她说「我依靠你」，并以「只说一次」为前提，向制作人道谢并说「大好き」（0045～0050）。

## 她的关键台词
- 0011「じゃあ、プロデューサーは？」——观众的反应之外，她最在意的是制作人的评价。
- 0016「あれが、いまの私の精一杯だったから。」——承认已尽全力，也意味着还有更上的空间。
- 0021「何度も言わせないで。／こんなのはただの過程だよ。」——成功不是终点，立刻往前看。
- 0024「階段を一歩上るたびに、／お祝いしてたらきりがない。」——不为每一步停下庆祝的态度。
- 0033「うん。……いなきゃ困るよ。」——希望世上还有比自己强的偶像，作为要超越的对象。
- 0039「いまの私は、プロデューサーにとって／世界一のアイドルなんだ？」——向制作人确认自己的位置。
- 0041「……なら、次は世界中の人にとっても、／そうならなきゃね。」——把私人的肯定立刻转化为更大的目标。
- 0042「きっと……そういう存在こそが、／トップアイドルだと思うから。」——她对顶级偶像的理解。
- 0045「うん……頼りにしてる。」——明确表达对制作人的依赖。
- 0047「…………一度しか言わないから。」——说真心话前先给自己设限，害羞。
- 0049「ありがとう、大好き。」——直接的感谢和好感表达。

## 行为模式
- 取得成功后 → 不庆祝，马上要求商量下一步（0019、0021、0024、0025）。
- 制作人提出要庆祝 → 说「你明明知道」，表示对方应该懂自己（0023）。
- 想知道对方真实看法时 → 直接问「你觉得怎样」「告诉我感想」（0012、0013、0029）。
- 得到高度肯定 → 先用「什么嘛」略带怀疑地确认理由，再把肯定变成下一个目标（0036、0039、0041）。
- 要说出心里话时 → 先停顿、说「只说一次」做铺垫，然后简短直白地说（0046～0050）。

## 关系
- プロデューサー：称「プロデューサー」，全篇用普通体（「早く次に行こうよ」0025、「頼りにしてる」0045）。制作人称她「月村さん」（0004）。她最在意制作人的评价（0011、0029），说依靠他（0045），最后说「ありがとう、大好き。これからも、よろしく。」（0049、0050）。制作人说会陪她走下去（0044）。

## 档案类事实
- 她在一次演出上大获成功，观众因她的歌而高兴（0009、0010）。
- 她认为在全世界人眼中都是第一的存在才是顶级偶像（0041、0042）。
- 她说那场演出是她目前的极限（0016、0028）。

## 不确定
- 0013 与 0014 之间、以及 0026 与 0027 之间应有制作人的选项，剧本里没有。0014～0025 与 0027～0042 看起来是对不同选项的两段并列反应（一段是「那就好，那是我现在的极限」，一段是「最好的表现，所以想听你的评价」），但无法确定两段是否都在同一次流程中发生。
