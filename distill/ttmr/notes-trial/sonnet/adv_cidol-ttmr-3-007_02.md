# P卡 月村手毬【Campus mode!!】 / 第2话 Campus mode!! 第2话（adv_cidol-ttmr-3-007_02）

- 她的台词：32 行（含用匿名标签说的 0 行）
- 出场的人：手毬、プロデューサー
- 场景：练习《Campus mode!!》的过程中（0001～0003），后来她提议换地方说话（0006），在能看到天空和太阳的地方（0037、0038）。

## 发生了什么
制作人看到手毬练习很顺利，她说这首歌已经学会了，没有问题（0001～0003）。制作人说完成度高得不只是"学会"，问有没有原因；她提议换地方，然后说这首歌是燐羽教她的，三人（她、美铃、燐羽）以前模仿她们憧憬的偶像一起唱过（0005～0010）。她说燐羽最快掌握诀窍，也教得很好，但那是"变坏之前"的事（0011～0016）。制作人说燐羽没有发挥实力的影像，她说成立初期不可能有影像，真实力的人学园里也屈指可数，她只要自己记得就好（0027～0031）。她说那时最差的自己，要用队长教的歌证明已经独当一面，对着太阳喊出"快点拿出真本事，笨蛋"，并说要对本人说（0034～0042）。

## 她的关键台词
- 0002「すでに習得している楽曲ですから。」——对问题的第一反应是"学过了"，不多解释。
- 0006「それは……………………／……場所、変えようか。」——要说的事不适合在原地讲，切换到私下的语气。
- 0007「『Campus mode!!』は……／燐羽に教わった曲なんです。」——这首歌与燐羽的关系，是这一篇的核心。
- 0010「私と、美鈴と、燐羽で……／真似っ子して、歌ってたんです。」——她、美铃、燐羽三人曾一起模仿唱歌。
- 0016「ぐれちゃう前の話だから。」——提到燐羽时使用"变坏"一词，说明现在的燐羽不同于过去。
- 0023「この曲なら誰にも……／あの頃の燐羽にだって、負けません。」——对这首歌的自信，包括"那时的燐羽"。
- 0029「有名になった頃にはもう、彼女は／私のサポートに徹していましたし。」——说明燐羽后来转为支持她。
- 0031「いいんです、それでも。／私が覚えていれば。」——没有影像也无妨，只要自己记得。
- 0032「リーダーの後ろについていけば、いつか／トップアイドルになれると思ってた。」——过去的想法：跟着队长就能成为顶级偶像。
- 0034「あの頃、一番ヘタクソだった私が。／リーダーに教わった歌で。」——自评当时是最差的一个，是她"证明"动机的前提。
- 0035「証明してやりたいんです。／立派に独り立ちしたぞ――って。」——想证明自己已独当一面。
- 0040「――早く本気出せヘタクソ～ッ！！」——对燐羽喊出的话，催促她拿出真本事。

## 行为模式
- 被问到私人原因 → 先说"换个地方"，再说出来（0006）。
- 提到对燐羽的敬意 → 一边夸（学得快、教得好，0011～0013），一边说"变坏"（0016）。
- 被问对方的实力没有影像证明 → 解释原因，并表示只要自己记得就行（0028～0031）。
- 想表达对过去队长的感情 → 用"想堂堂正正地催她"来表达，而不是直说想念（0036、0039、0040）。
- 喊完之后 → 用"呼"收一下，并说要对本人说，期待对方生气的表情（0041～0043）。

## 关系
- 燐羽：称「燐羽」（0007、0010），也称「リーダー」（0032、0034）；说她是自己的目标，现在"ぐれちゃった"（0016）；想催她拿出真本事（0036、0040）。
- 美鈴：称「美鈴」（0010），一起模仿唱过。
- プロデューサー：称「プロデューサー」（0003、0019），对方称「月村さん」；她用敬语，偶尔随意（0003、0019）。

## 档案类事实
- 曾经组过『SyngUp!』，成立时间和认识时间大致相近，她本人记不清（0009）。
- 『SyngUp!』成员有她、美铃和燐羽（0010），燐羽是队长（0014、0032）。
- 她们憧憬的偶像常唱《Campus mode!!》，她们模仿着唱（0008、0010）。
- 燐羽学得最快，教得也好；当时的她自称是最差的（0011～0013、0034）。
- 出名之后燐羽转而全力支持她（0029）。
- 她现在是独唱（ソロ）偶像（0022）。
- 知道燐羽真实力的人在学园里屈指可数（0030）。
