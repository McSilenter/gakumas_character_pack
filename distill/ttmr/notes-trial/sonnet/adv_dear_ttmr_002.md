# 月村手毬 亲爱度剧情 / 第2话（adv_dear_ttmr_002）

- 她的台词：29 行（含用匿名标签说的 0 行）
- 出场的人：手毬、プロデューサー
- 场景：与制作人谈话的场合（具体地点剧本未写）；她已被招募，制作人刚与教练谈过她的实力。

## 发生了什么
手毬先向制作人声明：虽然让他来培育，但不接受自己无法认同的指示（0002～0004）。制作人说已与教练谈过她的实力，她明知被牵着走，还是回答"想听"（0008～0012）。制作人指出她的表现比去年差了好几级、随时间下降，原因之一是体重增加；她强烈反驳"没增加5公斤"，并说自己已开始减肥（0030～0036）。制作人发现她在不吃饭，给她装了晚餐和早餐的冷藏箱，并说照这个饮食约4个月能回到最佳体重，她立刻答应（0037～0049）。结尾她在心里说不会这么容易就信任他（0055）。

## 她的关键台词
- 0004「納得できない指示を聞くつもりは／ありません。」——对指示有"要自己认同"的条件，是她的基本姿态。
- 0012「………………聞きたいです。」——被"专家意见"吊起胃口后，沉默很久才承认想听，嘴硬与好胜并存。
- 0022「……プロデューサーって、／すごく性格が悪いんですね。」——被牵着走时直接抱怨对方性格差。
- 0026「いいからもったいぶらずに／教えてください！」——急起来后直接要求对方别卖关子。
- 0031「5キロも増えてませんっ！！！」——被指体重增加时的强烈否认。
- 0034「デリカシーとかないんですかっ！？」——被说到体重时当面指责对方不体贴。
- 0036「わかってます！　だからいま、／ダイエットを始めたところで！」——她知道问题，已经在自行减肥。
- 0038「してますけど。」——被问是否不吃饭，毫不掩饰地承认。
- 0049「やります！」——听到"4个月能回到最佳体重"后立刻答应，说明她真的想恢复。
- 0055「（そんな簡単に……／信頼なんて、してやるもんか！）」——虽然配合，仍内心宣告不会轻易信任。

## 行为模式
- 被说到不想被提的身材/体重问题 → 大声否认并指责对方不体贴（0031、0034）。
- 对方用"专家意见"之类的东西吊她的胃口 → 心里觉得"狡猾"，嘴上嫌对方性格差，但还是选择听（0011、0012、0022）。
- 对方给出具体、可操作的方案和明确期限 → 立刻接受（0048、0049）。
- 被对方掌控节奏 → 在心里意识到被"手玉に取られている"，并以"不信任"作抵抗（0051、0055）。
- 对方说"要更努力" → 回"不用你说我也知道"（0053、0054）。
- 已经在做自己的办法（减肥）→ 即使方法不当（不吃饭）也不否认（0036、0038）。

## 关系
- プロデューサー：称「プロデューサー」（0002、0022），对他用敬语；对方称「月村さん」。态度：不信任（0055），但按他的方案行动；觉得他狡猾、性格差（0011、0022）。
