# 月村手毬 亲爱度剧情 / 第3话（adv_dear_ttmr_003）

- 她的台词：41 行（含用匿名标签说的 0 行）
- 出场的人：手毬、プロデューサー
- 场景：制作人所在的地方（她说"プロデューサー、いる？"来找他，0001）；她来取餐点；接着前一话的饮食安排。

## 发生了什么
手毬来找制作人取餐点，被指出头发翘起、胸前纽扣开了，她以"这是发型"搪塞并怒斥多管闲事（0005～0012）。她承认餐点好吃，但担心会发胖；制作人说偏食/克制是状态不佳的第三个原因，并提到调查过她的喜好、偶尔会做炸物，她骂他恶心、变态，随即又道谢（0014～0031）。她说"我不信任任何人"，但会报恩，并暂且听从指示（0033～0038）。制作人问她状态崩溃的最大原因，她说是去年与伙伴组成的组合因大吵而解散，梦想与大家的期待被她毁了，所以学园里没人信任她（0047～0053）。她反问为何招募自己，制作人说为了培育顶级偶像；她说出自己的目标是成为"人人认可的顶级偶像"，并说前提是他能跟上（0057～0066）。

## 她的关键台词
- 0006「えっ！？　……こっ、こういう／ヘアスタイルなんです。」——被指出翘毛时用勉强的借口糊弄。
- 0018「ただ……その……太らないですか？／……あのメニューで……量も……」——对好吃的餐点仍担心发胖，说明她对体重与饮食的不安。
- 0029「気持ち悪いです。／変態なんじゃないですか？」——被说"调查过喜好"时的嘴硬反应，紧接着就道谢（0030、0031）。
- 0033「それとこれとは話が別です。／私は、誰も信頼しない。だけど……」——明言不信任任何人，但"だけど"后面转向报恩。
- 0034「恩は返します。」——对帮助自己的人必还人情的原则。
- 0036「私がなにを恩に感じるかは、／私が決めることです。」——感谢与否由自己判断，不接受别人替她衡量。
- 0038「とりあえず、／指示は聞いてあげます。」——不信任但愿意执行指示，仍是"让你"的口吻。
- 0048「仲間を失ったこと。」——她把去年与今年的唯一差别说成这一句。
- 0050「でも……大喧嘩になって……／……解散することに。」——说明组合解散的经过。
- 0052「自分たちの夢と、みんなの想いを……／私が台無しにしたんです。」——把解散的责任归到自己身上，是她自责的核心表述。
- 0053「だからこの学園で、／私を信頼するやつなんかいない。」——认为自己在学园里不被信任，是不信任他人的背景。
- 0064「誰もが認める／トップアイドルになることです。」——给出自己的目标。
- 0066「私についてこられるなら、だけど。」——把目标交给制作人时附加的条件，既是挑战也是依靠。

## 行为模式
- 被指出仪容不整 → 先用借口搪塞，被追问或指到身体部位就生气（0006、0010、0012）。
- 受到超出预期的体贴（准备喜好食物）→ 先骂，随后别扭地道谢（0029～0031）。
- 被问是否信任 → 明确说不信任，但同时宣布"还恩"和"听指示"（0033、0034、0038）。
- 被迫说出痛处（失去伙伴）→ 抱怨对方性格差、明知故问，然后自己说出来（0045、0046）。
- 说完痛处后 → 把话题转到对方的动机上（"为什么招募我"），并对"目标"这个词做出纠正（0057、0061）。
- 对方答得直接 → 她也给出直接的目标，并附上"跟得上的话"（0059、0064、0066）。

## 关系
- プロデューサー：称「プロデューサー」（0001、0065），多用敬语（0012、0016），有时用「あなた」（0065）；对方称「月村さん」。态度：嘴上完全不信任（0037），但道谢、愿意听指示（0031、0038），觉得他是怪人（0054）。
- 去年的伙伴们：只说"仲間たち"和一起组过组合，吵架后解散（0049、0050）；本篇没有出现具体名字。

## 档案类事实
- 喜欢的食物里有炸物（制作人调查后说偶尔会做炸物；她是否直接说出口剧本未明写，0028、0027）。
- 去年之前与伙伴组过组合，大吵后解散（0049、0050）。
- 期待过更大的舞台（0051）。
- 她认为学园里没有人信任自己（0053）。
- 目标是成为人人认可的顶级偶像（0064）。
- 状态不佳的原因包含：仪表不整、偏食、心理压力，都和失去伙伴相关（制作人所述，0043、0044）。
