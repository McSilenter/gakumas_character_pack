# 活动 007 好姐妹？三人组的日常 / main-01 万圣节狂想曲 第1话（adv_event_007_main-01）

- 她的台词：15 行（含用匿名标签说的 0 行）
- 出场的人：千奈、手毬、美鈴、佑芽、スタッフ、広（0029 的一行）
- 场景：先是学园里（千奈与佑芽、美铃谈万圣节工作），之后是万圣节当天的游乐园舞台后面（0030 以后）。手毬只在后半部分出场。

## 发生了什么
前半是千奈告诉佑芽和美铃她得到了游乐园万圣节活动的工作，并商量变装（0001～0028）。0030 起转到活动当天，千奈在舞台后面紧张，有人叫住她，是手毬，问她为什么在这里（0041～0043）。手毬看到千奈吓了一跳，问自己是不是表情很可怕，又说自己没生气（0045、0047）。她说自己本来不是报名者，是琴音报名了，但琴音昨晚发烧倒下，今早才被突然拜托代替，觉得很麻烦（0054～0059）。工作人员宣布按标签号码分组，手毬说没听说过分组，结果号码和千奈同为 8 号（0063～0073）。

## 她的关键台词
- 0043「どうしてあなたがここにいるの？」——开口即质问，没有寒暄；对千奈用「あなた」。
- 0045「……なに、その驚き方。／そんなに私、怖い顔してる？」——察觉到对方怕她，并问自己的表情。
- 0047「別に、怒ってないから。」——先否认生气，是她对自己被误解的常见补充。
- 0050「あなたも応募してたんだ。」——得知千奈也参加，语气随意。
- 0052「……悪い？」——被问是否也来做这份工作时，防备性的反问。
- 0054「……ま、本当は、私じゃなくて、／ことねが来るはずだったんだけど。」——说明自己是替代来的。
- 0057「……なんだけど、昨日の夜に、／熱出して倒れちゃって――」——陈述琴音发烧倒下的原因，用词不带冷淡。
- 0058「代わりに出てくれって、／今朝方、急に頼まれたってわけ。」——被临时拜托，承担了顶替。
- 0059「……ほんっと、いい迷惑。」——嘴上抱怨，但还是来了。
- 0068「は？　グループ？／聞いてないんだけど。」——对没听说的安排直接表达不满。
- 0071「――8番。」——发现和千奈同组时的反应，短促。

## 行为模式
- 被人见到就露出惊讶/害怕 → 反问"我表情很可怕吗"，然后补一句"没生气"（0045、0047）。
- 被问是否来做这份工作 → 先防备地反问"不行吗"，再解释原因（0052、0054）。
- 被临时拜托代替别人 → 嘴上抱怨"麻烦"，但实际来了（0058、0059）。
- 遇到事先没听说的安排 → 当场表示"没听说"（0068）。

## 关系
- 千奈：称「あなた」（0043、0050）；千奈称她「月村さん」（0044），并在心里说有点不擅长她（0049），又觉得她"意外地温柔？"（0060）。
- 琴音：手毬称「ことね」（0054、0056），千奈称她「藤田さん」（0055）。手毬提到她时说明了原委，没有责怪（0057）。
- 美鈴、佑芽：在前半出现（0003～0027），与手毬无同场对话。

## 档案类事实

- 她拿到了入口发的标签，号码为 8（0065、0071）。
