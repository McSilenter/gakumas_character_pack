# 月村手毬 培育剧情 001 / ending-true-01 True End（adv_pstory_001_ttmr_ending-true-01）

- 她的台词：33 行（含用匿名标签说的 0 行）
- 出场的人：手毬、プロデューサー
- 场景：演出（ライブ）当天的夜里，制作人在一处安静的场所回顾演出，她找到他（0001、0002、0020）。

## 发生了什么
手毬在安静的地方找到制作人，说有重要的事一直没问：演出大成功、观众喜欢她的歌，那制作人觉得怎么样（0007～0013）。听到回答后她说"那就好"，并说那已是现在的她的极限（0014～0016）。她接着要求当晚就商量下一步；制作人说还没好好庆祝，她说每上一级台阶都庆祝没完没了，只是过程而已（0019～0025）。制作人说今天给他的感动无人能及，在世界上只有她一个；她确认是否因为是自己培育的，又确认自己现在是他心中世界第一的偶像，然后说接下来要让全世界的人都这样想（0036～0042）。最后她说"只说一次"，对制作人说谢谢、喜欢，并请多关照（0047～0050）。

## 她的关键台词
- 0012「今日のライブ……／私の歌、どうだった？」——先问制作人对自己的歌的感想，说明她重视他的评价。
- 0016「あれが、いまの私の精一杯だったから。」——对演出的自评：已是当下全力。
- 0021「何度も言わせないで。／こんなのはただの過程だよ。」——大成功后仍认为只是过程，立刻想往前。
- 0024「階段を一歩上るたびに、／お祝いしてたらきりがない。」——不愿每一步都庆祝，进取心的表现。
- 0025「早く次に行こうよ、プロデューサー。」——主动催促制作人往下一步走。
- 0028「いまの私に、／あれ以上のライブはできない。」——对当下的实力有清晰判断。
- 0033「うん。……いなきゃ困るよ。」——听说世上可能有比她更强的偶像时的反应：希望有这样的对手。
- 0039「いまの私は、プロデューサーにとって／世界一のアイドルなんだ？」——确认自己在制作人心中的位置。
- 0041「……なら、次は世界中の人にとっても、／そうならなきゃね。」——把"制作人眼中的第一"扩展为目标"全世界眼中的第一"。
- 0042「きっと……そういう存在こそが、／トップアイドルだと思うから。」——说明她对"顶级偶像"的看法。
- 0047「…………一度しか言わないから。」——表白前的铺垫，害羞但认真。
- 0049「ありがとう、大好き。」——直接的感谢与喜欢，是这一篇的情感顶点。

## 行为模式
- 达成大目标当天 → 不沉浸于喜悦，立刻要求商量下一步（0019、0021、0025）。
- 想确认对方的认可时 → 先拿观众的反应铺垫，再直接问"你呢"（0009～0013）。
- 得到想要的回答 → 简短回"那就好"，而不是展开情绪（0014、0015、0038）。
- 对方给出高度评价 → 追问细节来确认意思（0036、0039），再把它转化为更大的目标（0041）。
- 要说出真心话时 → 用"只说一次"开头，再说谢谢和喜欢（0046、0047、0049）。
- 被说"还没庆祝" → 回"明明你知道"，不否认对方的好意，只是不想停（0022、0023）。

## 关系
- プロデューサー：称「プロデューサー」，对方称「月村さん」。她依靠他的评价（0012、0029）、说"頼りにしてる"（0045），最后表达"大好き"（0049）。语气比亲爱度剧情时亲近，用「ね」「よ」等口语形式。

## 档案类事实
- 当天的演出大成功，来的观众喜欢她的歌（0005、0010）。
- 她把顶级偶像看作"对全世界的人来说都是第一"的存在（0041、0042）。
- 她判断自己现在无法做出比这更好的演出（0028）。

## 不确定
- 0013、0014 之间制作人的感想是什么，剧本里没有对应行（制作人行不在这里），只能从 0030～0035 推测是同一内容。
- 0049「大好き」是对制作人的哪种喜欢（信赖、感谢还是恋爱），剧本没有区分。
