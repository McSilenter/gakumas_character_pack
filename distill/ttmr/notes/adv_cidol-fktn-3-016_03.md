# P卡 藤田ことね【全力以赴！】/第3话 全力以赴！ 第3话（adv_cidol-fktn-3-016_03）

- 她的台词：14 行（匿名标签 0 行）
- 出场的人：ことね、咲季、手毬
- 场景：三人共演练习结束之后；咲季唱的是她的『がむしゃらに行こう！』（0004）
- 世界线：亲爱度（藤田ことね）·P卡；制作人在制作的偶像：藤田ことね（制作人本篇未出场，由标题推断）

## 发生了什么
练习结束后，咲季问大家自己的『がむしゃらに行こう！』怎么样。手毬说声音不错，当然不如自己；ことね说可爱，当然不如自己。咲季说想把两人身上能学的都学过来，三人互相夸奖，咲季说关系变深了，手毬和ことね同时否认。手毬解释自己的目的是观察两人的魅力，好让她们的粉丝也喜欢自己；ことね承认自己也在学习两人的长处。最后三人互相宣战，约好办成大成功的演唱会。

## 她的关键台词
- 0005「いい声出てたよ。／もちろん私ほどじゃないけど。」——夸奖里带着自夸
- 0013「咲季の……そういう誰からでも／学んでいくスタンス、いいと思うよ。」——认可咲季向任何人学习的态度
- 0019「ありえないから。」——对咲季说“关系变深了”立刻否认
- 0022「ことねはどうだかしらないけど、／私の方は、たいした理由じゃない。」——解释自己的动机，不替ことね说话
- 0023「どうせ共演するなら、／あなたたちのファンに、」——共演的目的是让对方粉丝喜欢自己
- 0025「それで観察してたの。／あなたたちの魅力を。ただそれだけ。」——把自己的态度归结为“观察”
- 0027「咲季のそういうところ、／本当に気持ち悪いと思うよ。」——对咲季的自恋直言
- 0039「ことねのそういうなりふり構わない／ところ、いいと思うよ。」——对ことね的认可
- 0046「あなたたちの魅力を見習って、／ファンを全員奪ってやるから。」——最后的宣战

## 行为模式
- 被说“关系变深了” → 立刻否认，不顺着说（0019、0022～0025）
- 被咲季反过来说自己迷上她 → 冷淡地说咲季“气持ち悪い”（0026、0027）
- 对方的优点 → 平静地说“いいと思うよ”，不加渲染（0013、0039）
- 想表达认可时 → 用“观察”“利用”之类的理由包装（0022～0025、0046）

## 关系
- 咲季：叫「咲季」；对她的自恋和直白感到别扭，但认可她向别人学习的态度（0013、0027）
- ことね：叫「ことね」；认可她的不拘小节（0039）；在“互相学习”这点上两人一致（0038）

## 档案类事实
- 她想让咲季、ことね的粉丝也喜欢上自己（0023、0024）
- 她练习时会观察对方的魅力（0025）

## 不确定
- 0022 手毬说“ことねはどうだかしらないけど”，而0032～0036 ことね说自己也在学习，即两人的动机可能相同；本篇没有明说手毬是否因此改变看法（0038 只说“どうりで”）。
