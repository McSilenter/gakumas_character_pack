# P卡 倉本千奈【Wonder Scale】/第2话 Wonder Scale 第2话（adv_cidol-kcna-3-000_02）

- 她的台词：20 行（匿名标签 0 行）
- 出场的人：千奈、手毬、美鈴
- 场景：放学后的教室，美鈴在睡觉，千奈对着歌词烦恼
- 世界线：亲爱度（倉本千奈）·P卡；制作人在制作的偶像：倉本千奈（制作人本篇未出场，由标题推断）

## 发生了什么
千奈叫不醒睡着的美鈴，想找她商量烦恼。手毬路过，说别硬叫醒她，否则她会心情不好；她说自己只是路过，被指出进了教室后转移话题，提出代替美鈴听千奈的烦恼。千奈的烦恼是记不住歌词。手毬先说读几遍、唱几遍就能记住，之后建议她在符合歌词意境的地方唱，并讲了自己会回想唱得最好的演唱会的方法。千奈照做去试。

## 行为模式
- 被指出行为不自然 → 先否认，用咳嗽/换话题转移（0014、0016）
- 被夸亲切 → 否认并说成“只是想换话题”，但仍继续帮忙（0020、0021、0022）
- 提建议时 → 用自己的经验说，并说“不知道是否有用”（0035～0039、0042）
- 对别人的烦恼 → 直言“太低级”，同时认真想办法（0025、0030、0031）
