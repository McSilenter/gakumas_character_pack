# P卡 倉本千奈【Campus mode!!】 / 第2话 Campus mode!! 第2话（adv_cidol-kcna-3-007_02）

- 她的台词：24 行（含用匿名标签说的 0 行）
- 出场的人：千奈、手毬
- 场景：千奈练习《Campus mode!!》的场所（0001～0008），手毬听说她苦战而来；剧本里提到千奈在准备『N.I.A』的日程（0005）和一场试镜（0058）。
- 世界线：亲爱度（倉本千奈）·P卡（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
千奈练《Campus mode!!》练得气喘吁吁，抱怨太难、日程太满（0001～0008）。手毬出现，说果然如此，是听说千奈在学这首歌才来的，提出可以帮忙，条件是"千奈一定要求她"；千奈立刻拜托（0009～0014）。手毬否认是为了千奈，说『N.I.A』里有别校的偶像，衣服表现不好会让初星丢脸（0017～0020）。她确认千奈记住了歌词和舞蹈，说明歌与舞各有难点；千奈问她是否在舞台上唱过这首歌，她回答在初中部时唱过，被千奈称赞后害羞，并因千奈想看而说不能再穿那件衣服，但有照片和录像可以下次看（0026～0044）。最后千奈说这首歌承载着所有穿过这套衣服的初星偶像的心意，她让千奈先休息再整体练一遍，并答应去看千奈的演出，若试镜落选会生气（0046～0058）。

## 她的关键台词
- 0009「そんなことだろうと思った。」——预料到千奈在苦战，说明她事先听说了/猜到了。
- 0013「私が助けてあげようか？　／どうしてもっていうなら……だけど。」——帮忙也要先加一个"如果你非要"的条件。
- 0015「返事はや。」——被秒回"拜托"后的反应，简短吐槽。
- 0017「……勘違いしないで。／別にあなたのためじゃない。」——被说"亲切"后马上否认是为了对方。
- 0019「その衣装で負けられたら、同じ初星学園／のアイドルとして迷惑だから。」——给出的理由是"同校偶像的颜面"，实际仍然是在帮忙。
- 0026「一応聞くけど……／歌詞と振り付けは……覚えた？」——帮忙的第一步是确认基础。
- 0033「……あるけど。中等部のときに。」——承认在初中部时唱过这首歌。
- 0035「……そ、それほどでもないし。」——被夸后害羞地否认。
- 0043「結構前の衣装だし。せ、成長したし！　／……もっ……もう、着られない。」——被想看时找借口，显得慌张。
- 0044「写真と映像なら……あるけど。／今度……観る？」——不能穿衣服表演，但提出让千奈看照片和录像。
- 0053「そういう台詞は、MCでやりなよ。／私を口説いてどうするの。」——被千奈的热情话打动，用吐槽掩饰。
- 0057「あなたの『Campus mode!!』、／観に行く。」——允诺去看千奈的演出，是对千奈的认可。
- 0058「これでオーディションに落ちたら……／怒るから。」——给出的期待用"生气"来表达。

## 行为模式
- 想帮人的时候 → 先说"如果你一定要"，再提出帮助（0013）。
- 被说成亲切 → 立刻否认并找一个"不是为了你"的理由（0016 为千奈所说，0017、0019 为她的反应）。
- 被夸奖或被热情注视 → 害羞，找借口回避（0035、0043）。
- 对方认真时 → 以吐槽接球，但随后给出实际的承诺（0053、0055、0057）。
- 表示支持 → 用"落选的话我会生气"的说法（0058）。
- 开始教学 → 先确认对方基础，再指出歌与舞的难点（0026、0028、0029）。

## 关系
- 千奈：称「あなた」（0012、0057），不称名字；千奈称她「月村さん」（0011），并在心里认为她用严厉语气说话时可以用百倍善意去理解（0022、0023，这是千奈的想法）。手毬接受千奈的崇拜，最后答应去看她的演出（0057）。

## 档案类事实
- 在初中部时在舞台上唱过《Campus mode!!》（0033）。
- 那时的衣服现在穿不下（0043）。
- 留有当时的照片和录像（0044）。
- 听说千奈练这首歌后专门去找她（0012）。
- 『N.I.A』里有其他学校的偶像参加（0018，手毬所述）。

## 不确定
- 0043 的"穿不下"究竟是真的变化还是借口，本篇没有确认（语气像是借口，但"成长したし"也可能是实情）。
- 0013 的「どうしてもっていうなら」是不是她真心的条件，还是只是嘴上的说法，剧本没有区分。
- 0058 的"オーディション"是哪一个试镜，本篇没有明说（0005 只提到『N.I.A』）。
