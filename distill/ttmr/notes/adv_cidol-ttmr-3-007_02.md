# P卡 月村手毬【Campus mode!!】 / 第2话 Campus mode!! 第2话（adv_cidol-ttmr-3-007_02）

- 她的台词：32 行（含用匿名标签说的 0 行）
- 出场的人：手毬、プロデューサー
- 场景：先是练习『Campus mode!!』的地方（0001～0005），她提议换个地方说话（0006），之后在能看到太阳的室外（0037、0038）。
- 世界线：亲爱度（月村手毬）·P卡（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
制作人说她这首歌完成度高得不只是「已掌握」，问她原因，她迟疑后提议换个地方（0001～0006）。她说『Campus mode!!』是燐羽教给她的歌：她们憧憬的偶像常唱这首，她、美鈴、燐羽刚认识时一起模仿着唱，燐羽学得最快，也最会教（0007～0013）。制作人对燐羽的印象和她说的不同，她说那是燐羽「变坏」之前的事，组成组合后这首歌也是她们的压箱底曲目（0015～0018）。她说现在成了 solo 偶像，这首歌依然最拿手，连当年的燐羽也不会输（0022、0023）；本气的燐羽没有留下影像，知道的人很少，但只要她记得就好（0028～0031）。她说当时自己是最差的那个，想用队长教的歌证明自己已经独当一面，这次要堂堂正正地催燐羽（0034～0036）。她对着太阳大喊“快点拿出真本事吧，笨蛋”，然后说要当面对燐羽这么说，期待对方会怎样生气（0039～0043）。

## 行为模式
- 被问到触及过去的事 → 先停顿，然后提议换地方再说（0006）。
- 谈到过去的伙伴 → 细致地回忆对方的长处，敬佩溢于言表（0011～0013）。
- 别人对燐羽有负面印象 → 解释那是“变坏之前”，并补充燐羽当年真正的实力不为人知（0016、0028～0030）。
- 认为制作人可能早已调查过自己 → 直接说“你应该知道吧”，得到否认后说「无所谓」（0019、0021）。
- 把对旧伙伴的复杂情绪 → 转化为“超越对方、催对方认真”的挑战（0035、0036、0039、0040）。
- 情绪爆发后 → 呼一口气，平静地宣布要当面去说，并期待对方的反应（0041～0043）。

## 关系
- 燐羽：称「燐羽」，也称「リーダー」（0007、0032、0034）。刚认识时一起模仿唱歌、燐羽教她们（0010～0013）；组合出名后燐羽专注辅助她（0029）。她说燐羽后来「ぐれちゃう」（0016）。她对燐羽强烈尊敬（制作人语，0024），想证明自己已独立、并催燐羽拿出真本事（0035、0036、0040）。
- 美鈴：称「美鈴」，是和她、燐羽一起模仿唱歌的人之一（0010）。
- プロデューサー：称「プロデューサー」，以敬语为主，夹杂普通体（「なんの問題もないよ」0003、「場所、変えようか。」0006）。制作人称她「月村さん」（0001）。她主动向制作人讲出过去，并当着他的面喊出心声。

## 档案类事实
- 『Campus mode!!』是燐羽教她的歌，是她们憧憬的偶像常唱的歌（0007、0008）。
- 她、美鈴、燐羽在成立『SyngUp!』前后刚认识时一起模仿唱这首歌（0009、0010）。
- 燐羽是『SyngUp!』的前队长，全名賀陽燐羽（制作人说）（0014）。
- 组成组合后这首歌也是她们的珍藏曲目之一（0017、0018）。
- 她现在是 solo 偶像，这首歌是她的拿手曲（0022）。
- 组合出名时，燐羽已经全力辅助她（0029）。
- 她说那时自己是「一番ヘタクソ」（最差的）（0034）。
- 她以前以为跟着队长就能成为顶级偶像（0032）。

## 不确定
- 0016「ぐれちゃう」具体指燐羽怎样变了，本篇没说明；制作人说调查到的印象和她描述的很不一样（0015）。
- 『SyngUp!』的成员是否就是她、美鈴、燐羽三人，本篇没有明说（0009、0010 只说三人刚认识时一起唱）。
- 0034「一番ヘタクソ」是在三人之中还是在更大范围内最差，原文未限定。
- 0036「急かしてやりたい」催的对象从上下文看是燐羽（以及 0039「あなたたち」可能包括美鈴），但未明说。
