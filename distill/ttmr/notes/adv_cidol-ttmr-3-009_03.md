# P卡 月村手毬【雪融之时】 / 第3话 雪融之时 第3话（adv_cidol-ttmr-3-009_03）

- 她的台词：39 行（含用匿名标签说的 0 行）
- 出场的人：手毬、プロデューサー、美鈴（回忆中，1 行）
- 场景：接上一话，她继续向制作人讲过去；回忆部分是初星学園入学当天、中等部入寮生的オリエンテーション和食堂（0008-0012）
- 世界线：亲爱度（月村手毬）·P卡（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
回忆讲到「私たちの夢は、生まれた」后，制作人道谢，她说接下来是「最後の話」（0001-0007）。她讲和美鈴进入初星学園、入学式上与燐羽重逢并很快成为朋友，当天中等部入寮生的オリエンテーション在食堂吃饭，她点了おでん，第一次吃到『ちくわぶ』，接着大谈自己喜欢扎实口感、ちくわぶ与うどん・すいとん完全不同，并说「これが……月村手毬と、／ちくわぶの出会いでした」（0008-0029）。制作人问为什么从『SyngUp!』的相遇、梦想的开端变成了おでん，她说照想到的讲下去话题会往奇怪方向走，就临时换成别的「エモーショナル」的故事（0030-0034）。制作人追问原本想讲什么，她怪他平时敏锐这种时候迟钝，最后喊出脑子里浮现的全是和他的事，还威胁要事无巨细讲给他听（0037-0044）。制作人说正想听这种，她愣住后要求他也说说对プロデュース的想法；制作人说第一次站在她面前时，觉得这次スカウト成功梦想就能实现；她拉长声「へぇ」后追问下文，被说“轮到你了”，最后提议两人按顺序一起回顾相识至今的事（0045-0055）。

## 她的关键台词

- 0009「入学式で燐羽と再会して……／すぐに仲良くなりました。」——与燐羽重逢
- 0021「私、みっしりした食感の食べ物が／好きなんですけど。」——食物偏好
- 0026「まったく違う食べ物だと思います。」——讲起食物来认真较劲
- 0029「これが……月村手毬と、／ちくわぶの出会いでした。」——用正经口吻讲食物，转移话题
- 0031「なにか文句があるんですか？」——被吐槽时立刻顶回去
- 0039「もう……いつもは鋭いくせに……／こういうときだけにぶい……」——埋怨制作人不懂自己的心思
- 0040「あなたとのエピソード／ばっかり思い浮かぶんです！！」——情急之下吐露真心
- 0044「ホラ恥ずかしいですよね！？　／聞きたくないですよね！？」——想用“你也会难为情”把话题吓退
- 0046「なッ――――――」——对方不按预期退缩时的慌乱
- 0052「…………続きは？」——嘴上不说，却想听对方的心里话
- 0055「出逢ってから、いままでのこと……／順番に……振り返りましょう！」——最终坦然接受互相回顾

## 行为模式
- 心里话要说出口时觉得难为情 → 临时换成无关但能讲得很起劲的话题（ちくわぶ）（0033、0034）
- 讲到喜欢的食物 → 一本正经地长篇评论、做比喻（0021-0028）
- 被吐槽 → 先反问「文句があるんですか」（0031）
- 对方不懂自己的暗示 → 怨他迟钝，然后憋不住一口气全说出来（0037-0042）
- 想用“让对方也害羞”来逃避，反被对方坦然接住 → 语塞，再反过来要求对方也说（0044-0048）
- 听到对方对自己的重视 → 拉长音装作淡定，随即追问下文（0051、0052）

## 关系
- プロデューサー：用敬语，称「あなた」；制作人称她「月村さん」（0005、0043）。她承认想到的过去全是和他有关的事（0040）；制作人说初次见她时觉得スカウト成功就能实现梦想（0049、0050）；最后两人约定轮流回顾相识至今的事（0053-0055）
- 美鈴：一起入学初星学園（0008）；她把ちくわぶ的口感讲给美鈴听（0023）
- 燐羽：入学式重逢，很快成为朋友；燐羽惊讶她不知道ちくわぶ（0009、0017）

## 档案类事实
- 和美鈴一起进入初星学園，入学式上与燐羽重逢、很快变好（0008、0009）
- 入学当天参加了中等部入寮生的オリエンテーション，在食堂吃饭（0011、0012）
- 在那里第一次吃到ちくわぶ（入学前不知道ちくわぶ）（0016-0018）
- 喜欢「みっしりした食感」的食物（0021）
- 认为ちくわぶ和うどん、すいとん完全不同，与浓味汤汁很配（0025-0028）
- 制作人最初是来スカウト她的（0049、0050）

## 不确定
- 0017「えっ『ちくわぶ』知らないの？　／って、びっくりされて。」前半是她转述燐羽的话。
- 0001 美鈴的台词是回忆（上一话结尾重复），不是当下。
- 0033-0034 她说把原本要讲的话题“临时换成另一个エモーショナル的故事”，指的应是ちくわぶ的故事；原本的方向据 0040 是和制作人的事，但剧本里这是她情急中说的，原本打算讲到什么程度不明。
- 0011「中等部から入寮する生徒」字面看她是中等部入学、住寮，但“入寮”的是否包括她本人，剧本只说她参加了这次オリエンテーション、在食堂吃饭。
- 【译文】0021 译文加了“虽然这么说可能有点奇怪”，原文「好きなんですけど」只是话头的「けど」，并无此意（影响不大）。
