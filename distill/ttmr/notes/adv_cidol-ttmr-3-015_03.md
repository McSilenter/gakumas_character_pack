# P卡 月村手毬【全力以赴！】 / 第3话 全力以赴！ 第3话（adv_cidol-ttmr-3-015_03）

- 她的台词：36 行（含用匿名标签说的 0 行）
- 出场的人：手毬、プロデューサー
- 场景：接上一话，下次ライブ（与咲季、ことね共演）的准备谈话；地点未写
- 世界线：亲爱度（月村手毬）·P卡（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
制作人提起下次ライブ的曲目，她说『がむしゃらに行こう！』是好歌、唱着开心；得知共演的两人也唱同一首，她说那就是要被粉丝比较，挺有意思，还反问难道自己会输给那两人（0001-0009）。制作人说这是共演不是比赛，她说知道，但就算是共演也不能输给那两人，对方肯定也这么想，因为咲季和ことね都不服输（0010-0015）。制作人说三人是相似的好朋友，她否认关系好，但承认相似——不是不服输（那是偶像理所当然，不信自己是第一的偶像是「プロ失格の雑魚」），而是总是焦急、视野狭窄、只顾往前冲；ことね也一样，看得清周围却看不清自己，让人放心不下（0016-0029）。制作人说那和她很像，又说视野窄不全是坏事，她正是这样一路成为现在的月村手毬；她说制作人总是肯定她走过的路（0030-0036）。她说若制作人带咲季或ことね一定也合得来，因为她们相似——「あげませんけどね。」「私のなので。」，见制作人愣住就逗他害羞、说他像自己害羞时的台词（0037-0046）。最后她说看了下次ライブ他马上就会消气，她会「がむしゃらに、まっすぐに」把相似的对手打垮给他看（0047-0049）。

## 她的关键台词
- 0003「いい曲ですよね。／歌っていて楽しいです。」——对『がむしゃらに行こう！』的喜爱
- 0009「この私が、あのふたりに負けるとでも？」——好胜、自信
- 0013「負けるわけにはいかないんです。／たとえ共演だろうと。あのふたりには。」——对两人的特别竞争心
- 0015「咲季もことねも、負けず嫌いなんです。／まったく、やれやれですよ。」——自己也不服输却说别人
- 0017「は？　べつに仲良くないって／何度も言ってるよね。」——习惯性否认关系好
- 0022「プロ失格の雑魚でしょ。／あいつらは違う。私もです。」——偶像观：必须相信自己是第一
- 0025「いつも焦ってて、視野が狭くて、／前だけ見て走ってるところ。」——自我认知
- 0029「自分のことは見えてないんです。／危なっかしくて、目が離せません。」——对ことね的担心
- 0036「私が進んできた道のりを、／それでいいんだって……言ってくれる。」——制作人对她的意义
- 0039「――あげませんけどね。」——对制作人的占有欲
- 0040「私のなので。」——同上，直白宣言
- 0042「あ、照れました？」——反过来逗制作人
- 0049「似たもの同士のライバルを、／叩きのめしてみせますから！」——斗志宣言

## 行为模式
- 听到要和对手比较 → 觉得「面白い」，立刻进入好胜状态（0007-0009）
- 被提醒“只是共演” → 嘴上「わかってます」，仍坚持不能输（0012、0013）
- 被说和对手关系好 → 先「は？」否认，再承认相似（0017、0018）
- 被说中自己的缺点 → 先「でしょ？」，又因对方太认同而不爽（0031）
- 被肯定 → 认真道出制作人对自己的意义，接着用占有宣言掩饰/表达感情（0035-0040）
- 对方害羞或不高兴 → 抓住机会调侃，再以「仕方のないひと」收尾，用ライブ来“哄”对方（0042-0047）

## 关系
- 咲季、ことね：直呼名字，合称「あのふたり」「あいつら」；视为不能输的对手，认为三人都不服输（0013-0015）；否认关系好但承认三人相似：焦急、视野窄、只顾往前冲（0017、0018、0025）；担心ことね看不清自己、放心不下（0028、0029）
- プロデューサー：敬语夹常体；称「あなた」；说他总是肯定自己走来的路（0035、0036）；认为他和咲季、ことね也会合得来，但宣称「私のなので」不让给别人（0037-0040）；会调侃他害羞（0042-0045）

## 档案类事实
- 下次ライブ唱『がむしゃらに行こう！』，她觉得是好歌、唱着开心；共演的咲季、ことね也唱同一首（0002、0003、0005）
- 偶像观：偶像都不服输，不相信自己是第一的偶像是「プロ失格の雑魚」（0020-0022）
- 自认总是焦急、视野狭窄、只顾向前冲（0025）
- 认为咲季、ことね都不服输（0015）
