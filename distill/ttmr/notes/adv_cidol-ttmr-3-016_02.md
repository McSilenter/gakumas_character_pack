# P卡 月村手毬【究竟从何时起】 / 第2话 究竟从何时起 第2话（adv_cidol-ttmr-3-016_02）

- 她的台词：20 行（含用匿名标签说的 0 行）
- 出场的人：美鈴、千奈、手毬
- 场景：接上一话，「秘密の特訓場所」是倉本千奈的別荘，有不输初星学園的レッスン施設（0002、0009）；特训期间住在那里（0011）
- 世界线：亲爱度（月村手毬）·P卡（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
秘密特训地点是千奈的别墅；美鈴解释是以教千奈唱歌为交换请她帮忙，千奈也参加特训，设施随便用，还请两人住到特训结束（0001-0011）。她先说不好意思，见千奈很期待这次「お泊まり会」，就说那就承情，会好好教唱歌（0012-0016）。她问美鈴具体要做什么、肯定不只是学新曲；美鈴说三人互相教唱歌，千奈惊慌说自己没什么可教，她对千奈说听她的歌会变温柔、挺喜欢倉本千奈的ライブ（0019-0028）。美鈴问自己的歌是否也让人平静，她说美鈴的歌真的厉害，但仔细听隐约有邪恶感，甜美之下藏着强制、支配欲般的歌手的傲慢；美鈴说那没藏，又指出她总是把情念原样砸进歌里，作为粉丝喜欢，但所有歌都这样不行，尤其连续唱时（0030-0040）。她说早就察觉制作人和美鈴的用意：增加『想いを込めて歌う』的变化；美鈴说和千奈互教会成为契机（0041-0045）。她说美鈴也能一起进步这点特别好；美鈴想起以前两人一起向燐羽学的日子，她说要成长得不输那段日子，喊「特訓、がんばろう！」（0046-0048）。

## 行为模式
- 被安排了不知情的事 → 先吐槽不知道，再追问具体内容（0005、0019、0020）
- 收到过分的好意 → 先说不好意思，对方真心期待就接受，并承诺回报（0012、0016）
- 有人自我贬低 → 直接、具体地说出对方的优点（0025-0028）
- 面对亲近的美鈴 → 先夸，再毫不留情地挑刺，用分析式的语言（0031-0036）
- 被指出自身问题 → 说早就知道，并自己概括出课题（0041-0043）

## 关系
- 千奈：她叫对方「倉本千奈」「あなた」；千奈叫她「月村さん」（0003）；她说听千奈的歌会变温柔、挺喜欢千奈的ライブ（0027、0028）；承诺好好教千奈唱歌（0016）
- 美鈴：她叫「美鈴」，美鈴叫她「まりちゃん」；她说美鈴的歌厉害但隐约「邪悪」、带支配欲（0031-0036）；美鈴称自己是她的粉丝，指出她的歌总是直接砸出情念（0037-0040）；她特别高兴美鈴也能一起进步（0046）
- 燐羽：美鈴提到她们以前两人一起跟「りんちゃん」学（0047），她说要成长得不输那时（0048）
- プロデューサー：不在场；她察觉这次特训是制作人和美鈴的用意（0041）

## 档案类事实
- 特训在倉本千奈的别墅进行，住到特训结束（0002、0011）
- 千奈、美鈴、她三人互相教唱歌（0022）
- 她喜欢千奈的ライブ（0028）
- 美鈴评价她的歌：把自己的情念原样注入歌里砸出去（0038）
- 特训课题：增加『想いを込めて歌う』的变化（0042、0043）
- 以前她和美鈴一起向燐羽学过（0047）
