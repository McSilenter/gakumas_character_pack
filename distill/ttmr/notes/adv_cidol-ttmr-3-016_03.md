# P卡 月村手毬【究竟从何时起】 / 第3话 究竟从何时起 第3话（adv_cidol-ttmr-3-016_03）

- 她的台词：16 行（含用匿名标签说的 0 行）
- 出场的人：美鈴、千奈、手毬
- 场景：接上一话，倉本千奈的别墅，特训第一天的晚饭后（0001、0027）
- 世界线：亲爱度（月村手毬）·P卡（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
晚饭是美鈴亲手做的，她说很好吃，是在美鈴家吃过的味道；美鈴说用的是老家寄来的当地食材，特训期间都由她做饭（0001-0007）。她看美鈴一脸前所未见的认真，美鈴说是为了对抗「まりちゃんのプロデューサー」，证明自己也能做出好吃又营养均衡的饭菜，并且不是什么『うっすら邪悪』；她说厨艺和性格无关，被千奈制止，于是提议用歌来证明、和她一起（0008-0017）。美鈴说听了她新曲的デモ，旋律清爽；她说歌词却「ひねくれてる」，只像平时那样灌注感情唱发挥不出真正价值；她想像倉本千奈那样把温柔传达给听众，像秦谷美鈴那样精准地控制观众的心，同时比平时更强地注入月村手毬的全身全灵，有很多想商量的（0019-0026）。千奈说她向不成熟的自己请教、表示敬意毫不犹豫，是真正的偶像；美鈴说看低对方和尊敬对方可以并存，她叫美鈴别光凭气氛说“好台词”（0027-0034）。千奈说随心操纵粉丝的美鈴也是真正的偶像，美鈴说第一次有败北感，她也说「こういうところ、／ちょっと勝てない」，最后说希望特训结束时大家都比现在好一点（0035-0042）。

## 她的关键台词
- 0006「やっぱり。美鈴の家で食べたことある味／だなって思ったんだ。」——和美鈴家的熟悉程度
- 0008「うわ……見たことないくらい／本気の顔してる。……どうしたの？」——对美鈴表情的敏感
- 0015「料理の腕前と性格は／関係ないと思うけど。」——直来直去、不会看气氛
- 0017「だから歌で証明しよう。私と一緒に。」——用歌说话
- 0021「それでいて歌詞はひねくれてる。」——对新曲的理解
- 0022「いつも通り想いを乗せて歌うだけじゃ、／きっと真価を発揮しない。」——意识到自身唱法的局限
- 0023「倉本千奈みたいに、優しい気持ちを／聴く人の心に届けたい。」——向千奈学习
- 0024「秦谷美鈴みたいに、狙い通りに、／観客の心をコントロールしたい。」——向美鈴学习
- 0025「月村手毬の全身全霊を、／いつもより強く込めて歌いたい。」——同时保留并加强自己的长处
- 0034「そうやって雰囲気だけ『良い台詞』／っぽく言うのやめた方がいいよ。」——对美鈴的吐槽
- 0038「わかる。こういうところ、／ちょっと勝てないよね。」——承认千奈的长处
- 0042「特訓が終わったころには……／全員、いまよりマシになれるといいね。」——和同伴一起变好

## 行为模式
- 吃到熟悉的味道 → 马上认出是美鈴家的味道（0003、0006）
- 别人在意被说的坏话 → 不察言观色，照实说“没关系”，被提醒后改为提议用歌来证明（0015-0017）
- 谈到新曲 → 具体分析曲子和自己唱法的不足，并把别人的长处列为学习目标（0021-0026）
- 被夸“真正的偶像” → 先「なに、突然」（0029）
- 美鈴说漂亮话 → 立刻戳穿（0034）
- 认可别人的长处 → 坦率说「勝てない」（0038）

## 关系
- 美鈴：她叫「美鈴」，美鈴叫她「まりちゃん」；她在美鈴家吃过饭，认得美鈴家的味道（0006）；美鈴在意被她说「うっすら邪悪」，想用做饭证明（0012、0013）；她想学美鈴控制观众内心的唱法（0024）；对美鈴的漂亮话会吐槽（0034）
- 千奈：她叫「倉本千奈」，千奈叫她「月村さん」；她想学千奈把温柔传达给听众（0023）；千奈称赞她向不成熟的偶像请教毫不犹豫，是「本物のアイドル」（0028-0031）；她承认千奈某些地方「勝てない」（0038）
- プロデューサー：不在场；美鈴把「まりちゃんのプロデューサー」当作对抗对象（0009）

## 档案类事实
- 吃过美鈴家的饭，认得那个味道（0006）
- 特训期间美鈴负责做饭（0007）
- 她的新曲：美鈴说旋律清爽，她说歌词「ひねくれてる」（0020、0021）
- 她的课题：只像往常那样灌注感情唱不够；想兼具千奈的温柔传达、美鈴的观众控制、以及更强的自身全力（0022-0025）
- 千奈评价她向不成熟的偶像请教、表示敬意毫不犹豫（0030、0031）

## 不确定
- 0017「だから歌で証明しよう。」要证明的是美鈴“不邪恶”还是泛指用歌说话，语境不完全明确。
- 0038「こういうところ」具体指千奈的哪一点（天然地夸人、让美鈴都觉得输），剧本里她故意不说（0040「さぁね」）。
