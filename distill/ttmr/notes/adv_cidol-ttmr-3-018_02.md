# P卡 月村手毬【荆棘之路】 / 第2话 荆棘之路 第2话（adv_cidol-ttmr-3-018_02）

- 她的台词：31 行（含用匿名标签说的 0 行）
- 出场的人：手毬、プロデューサー
- 场景：接上一话，和制作人谈『クールな月村手毬』；地点未写
- 世界线：亲爱度（月村手毬）·P卡（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
她问制作人『クール』是什么意思，制作人说是冷静、沉稳、帅气之类的褒义词；在『クールアイドル』的语境里就是「凛々しくて」「かっこいいアイドル」，她说「私のことですね」，被说真正クール的偶像不会这样自称（0001-0009）。她改口说自己不会说内心是クール的，虽然努力想那样、但自己最清楚一点也不是；她想问的是公众形象，自认是「実力派クールアイドル」，被制作人说这对其他クール偶像很失礼，还被命名为「爆速ジェットコースターアイドル」（0010-0020）。制作人问她是不是想当クール的偶像，她说事到如今才问，然后正式回答：想当，因为憧憬的偶像是那样的；制作人说出「賀陽継さんと、賀陽燐羽さん」，她说两人都不是世人想象中的『クールアイドル』，但她心中クール偶像的理想就是那两人，所以要以「最高にクールな、トップアイドル」为目标（0021-0030）。制作人赞同，她意外，说本以为他会挖苦；制作人说理解了她要的『クール』——不是冰冷的冰，而是超高温完全燃烧的青色火焰（0031-0041）。她兴奋地说两人心意相通，自己只是被世间『クール』的印象拖着走，冷淡、感情淡薄都不是重点，感谢制作人帮她理清；最后制作人追问说她クール的人是不是妄想，她拖长音否认（0042-0049）。

## 她的关键台词
- 0007「私のことですね。」——自信过头的自我评价
- 0010「『私』自身の内面がクールだとは／言いません。」——区分内心和形象
- 0011「そうあろうとはしていますけど、／ちっともそうじゃないのは……／私が一番よく知っています。」——对自己内心不クール有自知
- 0014「実力派クールアイドル。／……なんじゃない？」——她以为的公众形象
- 0020「プロデューサーが私をどう思っている／のか、よーくわかりました。」——被起外号时的怨气
- 0025「うん……私は、／クールなアイドルになりたい。」——明确表态
- 0026「憧れたアイドルが、そうだったから。」——理由
- 0029「だけど……私が思うクールなアイドルの／理想は……あのふたりなんです。」——理想是賀陽継与燐羽
- 0030「だから目指します。／最高にクールな、トップアイドルを。」——目标
- 0032「……意外です。プロデューサーは、／反対すると思っていました。」——对制作人的预期
- 0042「はいっ！　プロデューサー……私たち、／通じ合ってるね……！」——被理解时的喜悦
- 0045「冷たい雰囲気とか、感情が薄いとか……／そこじゃなかったんだ。」——重新理解自己的『クール』
- 0049「違いますぅ～～！」——被揶揄时孩子气地否认

## 行为模式
- 被问到自己的形象 → 先自信地往自己身上套（「私のことですね」），被吐槽就退一步，区分内心与外在评价（0007-0014）
- 被起难听的外号 → 记仇式的「よーくわかりました」（0020）
- 被正面问理想 → 认真、条理清楚地说出目标和理由（0024-0030）
- 预期被挖苦却被支持 → 先惊讶，还把自己预想中的挖苦台词说出来（0032-0035）
- 被准确理解 → 情绪高涨、坦率道谢（0042-0046）

## 关系
- プロデューサー：敬语常体混用；制作人称她「月村さん」；本篇制作人支持她的『クール』目标，用「青い炎」概括，她感到「通じ合ってる」（0040-0043）；她原以为制作人会反对、挖苦（0032-0035）
- 賀陽継、燐羽：制作人点名「賀陽継さんと、賀陽燐羽さん」为她憧憬的偶像（0027）；她说两人不是世人想象的『クールアイドル』，但是她心中クール偶像的理想（0028、0029）

## 档案类事实
- 想成为「最高にクールな、トップアイドル」（0030）
- 憧憬的偶像是賀陽継和賀陽燐羽（0026、0027）
- 自认内心一点也不クール，只是努力想成为那样（0011）
- 自以为的公众形象是「実力派クールアイドル」（0014）
- 制作人给她现在的形象命名为「爆速ジェットコースターアイドル」（0019）
- 她所追求的『クール』被制作人概括为「冷ややかな氷ではなく、／超高温で完全燃焼する青い炎」，她认同（0040-0043）

## 不确定
- 0033「『月村さんには向いていません』とか、」和 0034 引号内的话是她设想中制作人会说的挖苦，不是她本人的观点。
- 本篇首次出现「賀陽継」这个名字（制作人说出，0027）；「継」是否就是 adv_cidol-ttmr-3-009_02 里燐羽所说的“我姐姐”（009_02 0017），本篇没有明说。
- 【译文】『クール』全篇译作“帅气”，而本篇恰恰在讨论『クール』的含义（冷静、沉稳、也可指冷淡），译成“帅气”会让 0045“冷淡、感情淡薄不是重点”的转折难以理解。
