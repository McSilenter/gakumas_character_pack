# P卡 月村手毬【荆棘之路】 / 第3话 荆棘之路 第3话（adv_cidol-ttmr-3-018_03）

- 她的台词：22 行（含用匿名标签说的 0 行）
- 出场的人：手毬、プロデューサー
- 场景：她刚以正式演出的心态唱完一曲（0002），具体地点剧本里看不出（可能是练习/彩排场合，未明说）。
- 世界线：亲爱度（月村手毬）·P卡；制作人在制作的偶像：月村手毬（她自称“担当アイドル”0019，制作人称“うちの月村さん”0026）

## 发生了什么
她气喘吁吁地问制作人自己按正式演出的心态唱得怎么样（0001–0002）。制作人说她已经没有余力、要是正式演出就糟了，但承认这是一场很燃的 live（0003–0007）。她说能唱成这样，是因为制作人把她想做的理想形象说成了语言，她清楚看到了实现梦想的自己（0009–0010）。她介绍刚唱的『ガラクタロード』是100プロ的代表曲、日本最有名的偶像歌曲之一，并自夸唱歌时的自己很 cool（0011–0014）。制作人吐槽“cool 的偶像不会说自己 cool”，她回“这里就有一个例外”，制作人笑出声，她大为不满（0015–0019）。制作人说这种厚脸皮的台词正是他们要追求的 cool，她表示会用歌声堂堂正正传达出去（0021–0025）。最后她宣言要让全世界狂热，总有一天把“我们的 cool”变成真正的 cool，未来的自己就是 cool 偶像的代名词、是顶级偶像月村手毬（0029–0035）。

## 她的关键台词
- 0002「どうでしたか……本番のつもりで……／歌ってみました。」——把练习当正式演出全力以赴，并立刻向制作人要评价。
- 0005「ふっ、私より汗かいてる。」——自己累到喘气，还先拿制作人开玩笑，带点得意。
- 0009「プロデューサーが、／私がやりたかった理想のイメージを……／言葉にしてくれたからだと思う。」——把表现好归功于制作人把她的理想形象说出来，表明对制作人的信赖。
- 0010「夢を叶えた自分の姿が、くっきりと／見えてきたっていうか……」——梦想的具象化。
- 0014「歌っている私は……／クールだったでしょ？」——直接要求被认可为 cool。
- 0017「ここに例外がいるから。」——被吐槽后不退反进，厚脸皮的自我肯定。
- 0019「失笑した！？　信じられない……／担当アイドルに対して……！」——被笑时立刻炸毛，拿“担当偶像”身份抗议。
- 0025「堂々と伝えていきます、私の歌で。」——用歌声证明自己的立场。
- 0030「世界中を熱狂させて、／わけわからなくしてやりますよ！」——夸张的大话式干劲。
- 0033「いつか、こっちを本物にしてやります！」——承认自己不符合一般人眼中的 cool，但要把自己的路变成正统。
- 0035「トップアイドル・月村手毬です！」——以顶级偶像自称作结，目标宣言。

## 行为模式
- 全力表现后 → 马上找制作人要评价，并主动要求被夸“cool”（0002、0014）
- 被制作人吐槽、调侃 → 不认输，反而说更大胆的话顶回去（0016–0017、0022）
- 被笑话 → 立刻生气抗议，用“担当偶像”身份压对方（0019）
- 制作人把她的特质说成“我们的 cool”并鼓劲 → 爽快接下，放出更大的豪言（0029–0035）
- 谈到自己的进步 → 会把功劳分给制作人（0009）

## 关系
- プロデューサー：她称“プロデューサー”，说话时敬语和平语混用（0002 用です/ます，0005、0008 用平语）；制作人称她“月村さん”“うちの月村さん”（0026）。这一篇里她信赖制作人对她理想形象的语言化（0009），同时互相抬杠；被笑时会生气（0019），最后接受制作人提出的“我们的 cool”方针并全力响应（0029）。

## 档案类事实
- 她唱了『ガラクタロード』，她说这是100プロ的代表曲、日本最有名的偶像歌曲之一（0011–0012）。
- 她的目标是成为顶级偶像、成为“クールアイドルの代名詞”（0034–0035）。
- 制作人眼中她“キュートでロックで／エキサイティングでコミカル”，魅力很多（0026–0027）。

## 不确定
- 0001–0002 她唱的场合是练习还是彩排，剧本里没明说；制作人 0007 称之为「熱いライブでした。」。
- 0031–0035 语气由对制作人说话转成更像对外宣言（用「私たち」「みんな」并改用敬语），是对制作人说还是对着想象中的观众/世界宣言，读不准。
- 【译文】0011 曲名原文是『ガラクタロード』（ガラクタ＝破烂、废物），中文译成『荆棘之路』，笔记一律按原文写『ガラクタロード』。
- 【译文】0030「わけわからなくしてやりますよ！」原意是“让（大家）搞不清状况、晕头转向”，呼应制作人 0027 说自己“说着说着都搞不清了”（「よくわからなく／なってくる」），中文译成“让大家都对我神魂颠倒”，丢了这层呼应。
- 【译文】0005「私より汗かいてる」原文是“你出的汗比我还多”，中文意译为“你比我还紧张呢”。
