# P卡 月村手毬【“我要说了哦。”】 / 第2话 “我要说了哦。” 第2话（adv_cidol-ttmr-3-021_02）

- 她的台词：28 行（含用匿名标签说的 0 行）
- 出场的人：手毬、プロデューサー
- 场景：海外 CM 拍摄地，“常夏”（常年是夏天）的地方（0014）；拍摄开始前，先试穿衣装，之后两人一起散步（0020–0022）。
- 世界线：亲爱度（月村手毬）·P卡；制作人在制作的偶像：月村手毬（她自称“担当アイドル”0032，制作人说“気が合うアイドルを／担当できて”0037）

## 发生了什么
她穿上这次的拍摄衣装给制作人看，制作人称赞她身材绞得很好，作为初星学園的代表无可挑剔（0001–0003）。她说虽然大家还只是候补生，但接了工作就是专业的；她也清楚这份工作的成果要到明年夏天才送到粉丝面前，短期看是花时间却没有回报（0004–0009）。制作人说这是为了明年夏天以后的优势而做的投资，她接着说不打算只当成投资，要把常夏的景色、空气、炎热全部记住带回去，让自己的“夏の楽曲”更强（0010–0016）。制作人补充说非日常体验对所有表演都有好处，因为 live 对粉丝来说就是最好的非日常；她夸制作人说得好，邀他在拍摄开始前陪自己散步（0017–0021）。她换上同为拍摄衣装的连衣裙出来，散步时问拍摄要注意什么，被制作人说认真；她回答自己也很兴奋，只是现在是在准备工作，并反问制作人和担当偶像并肩散步怎么毫无兴奋的样子（0022–0032）。制作人学她的话回答，她叫他别学；制作人说能担当合拍的偶像很幸运，她回“我也是”，并要求拍摄结束后带她去吃好吃的（0033–0041）。

## 她的关键台词
- 0004「ふっ、当然でしょ。私たちは、／まだあくまで候補生。だとしても、」——承认自己还是候补生。
- 0005「仕事を任されている以上、プロです。／期待以上の月村手毬を提供しないと、／他のアイドルに顔向けできない。」——职业意识，对自己要求“超出期待”。
- 0009「短期的に見れば、時間を消費して、／得るものがないってことだよね。」——冷静算清这份工作短期的得失。
- 0012「『それだけ』で終わらせる／つもりはないです。」——不满足于被动的“投资”，要主动多拿收获。
- 0015「ぜんぶ覚えて帰ります。」——把出国体验当成表演养分的贪心和认真。
- 0016「月村手毬が歌う『夏の楽曲』が、／もっと強化されちゃうね。」——以第三人称称呼自己、带点得意。
- 0021「非日常の中を、一緒に歩こう。」——主动邀请制作人散步，用制作人的话来邀约。
- 0030「私はアイドルで、／いまは仕事の準備中なんです。」——兴奋但先把工作放在前面。
- 0032「せっかくこんなシチュエーションで、／担当アイドルと並んで歩いているのに、／ちっとも浮かれた様子がないですよね？」——反过来试探制作人，在意他对自己的态度。
- 0034「真似しないでください。」——被模仿时的不满反应。
- 0039「私もです。」——制作人说能担当她很幸运后，简短承认自己也这样想。
- 0041「美味しいもの、食べさせてください。」——工作后的要求是吃好吃的。

## 行为模式
- 被制作人夸外形/状态 → 理所当然地接下，再马上谈工作本身（0004–0005）
- 接到看不见短期成果的工作 → 先冷静把利弊说清楚，再决定要额外榨取经验（0006–0009、0012–0015）
- 制作人说了中听的话 → 直接夸“いいこと言うね”，并借他的话提出邀请（0019–0021）
- 被说“认真” → 先猜对方想说“你不兴奋吗”，解释自己兴奋只是以工作为先，随即反问制作人（0029–0032）
- 被制作人用自己的话回敬 → 要他别学（0034），追问他在想什么（0036）
- 制作人坦率表达好感 → 先“ふーん”一声，再简短说“私もです”，接着转到要好吃的（0038–0041）

## 关系
- プロデューサー：她称“プロデューサー”，敬语和平语混用；制作人称她“月村さん”，心里也称“月村さん”（0025）。制作人说能担当合拍的偶像很幸运（0037），她回“私もです”（0039）；她在意制作人和她一起散步时有没有兴奋（0032、0036），并向他提出拍完带她吃好吃的（0041）。

## 档案类事实
- 她自认目前仍是“候補生”（0004）。
- 她有唱“夏の楽曲”（0016）。
- 这次海外拍摄地是“常夏”的地方（0014）；散步时她穿的连衣裙也是拍摄服装，得到许可后穿出来的（0024）。
- 制作人内心认为那条连衣裙很适合她（0025）。

## 不确定
- 0001 的“今回の衣装”具体是什么剧本没明说（上一话提到要穿泳装拍摄，这一篇只看得出制作人称赞她身材 0002）。
- 0025–0026 是制作人的内心独白，不是说出口的话。
- 0029「浮かれたりしないのかって？」是她对制作人 0028“你很认真”的自行解读，制作人并没说这句话。
- 【译文】0002「しっかり絞れていますね」指她的身材练得紧实、体重管理到位，中文译成“把身材衬得很好呢”，变成了说衣服衬身材。
- 【译文】0026「俺も、先方も、／良い仕事をした」的“先方”指合作方（客户），中文译成“无论是我、还是她”，误成了手毬。
- 【译文】0012『それだけ』指“（只是）一项投资而已”，中文译成“到这为止”，意思偏了。
