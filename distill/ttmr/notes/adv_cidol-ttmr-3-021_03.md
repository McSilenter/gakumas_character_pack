# P卡 月村手毬【“我要说了哦。”】 / 第3话 “我要说了哦。” 第3话（adv_cidol-ttmr-3-021_03）

- 她的台词：21 行（含用匿名标签说的 0 行）
- 出场的人：手毬、プロデューサー
- 场景：CM 拍摄刚结束之后（0001），地点剧本里没明说。
- 世界线：亲爱度（月村手毬）·P卡；制作人在制作的偶像：月村手毬（她自称“担当アイドル”0031）

## 发生了什么
拍摄结束，制作人夸她做得好，她却说明明不是第一次拍 CM，却累得厉害，还为自己对体贴她的工作人员态度冷淡而过意不去（0001–0006）。制作人说工作人员是专业人士，会把直率的意见说给偶像听，她被夸了很多次外貌，那只是事实（0007–0011）。制作人指出她明明能客观看待自己的美貌，却不习惯外貌被高度评价（0013–0014）。她承认，说自己为了成为顶级偶像一直在打磨外表、也有自信，但以前被夸时身边总有美鈴或燐羽，而且原本就对外貌有自卑感，所以有人夸“偶像・月村手毬”的外貌时，感觉不像是在夸自己（0015–0021）。制作人说偶像有义务接受所有称赞，她认同并反省，决定改进（0022–0030）。最后她立刻让制作人尽情夸自己担当偶像的美貌（0031）。

## 她的关键台词
- 0004「……なんだか、／ものすごく疲れちゃいました。」——拍完异常疲惫，引出被夸外貌带来的压力。
- 0006「そっけない態度をしちゃって／申し訳なかったな。」——对自己的冷淡态度事后反省。
- 0016「トップアイドルになるために、／しっかりと外見を磨いてきました。」——为目标认真打磨外表。
- 0018「私が褒められるときは、いつも……／となりに美鈴や燐羽がいましたし。」——过去被夸时身边总有美鈴、燐羽，透露过去的经历和比较心理。
- 0019「元々容姿にコンプレックスが／あったので。」——明说原本对外貌有自卑感。
- 0021「あまり……自分が褒められているように／思えないんです。」——把“偶像月村手毬”和自己分开感受。
- 0023「……直さないとだめですか？」——面对课题时先小声确认。
- 0026「……うん。それは、本当に、そう。」——被说中道理时坦率认同。
- 0028「みんなに好きになってもらうのが／アイドルの仕事ですから。」——她的偶像观。
- 0031「担当アイドルの美貌を、／思いっきり褒めてくれてもいいよ。」——决定改正后马上付诸行动，顺势向制作人讨夸奖。

## 行为模式
- 外貌被别人当面大量称赞 → 不知怎么接，态度变得冷淡，事后觉得过意不去（0005–0006）
- 被制作人点出自己的弱点 → 先承认“也许是吧”，再老实说出原因（0015–0021）
- 被要求改正 → 先问“非改不可吗”，听到符合偶像职业的道理后立刻认同、反省、决定改进（0023、0026–0030）
- 下定决心改进 → 马上从身边开始练习，让制作人夸自己（0030–0031）

## 关系
- プロデューサー：她称“プロデューサー”，这一篇以敬语为主、结尾转平语（0031）；制作人称她“月村さん”。她向制作人坦白对外貌的自卑和过去，接受他的指正，并要求他夸自己的美貌（0031）。
- 美鈴、燐羽：她提到过去被夸时身边总有美鈴或燐羽（0018），只是提及，未出场。
- 拍摄的工作人员：她以为他们在照顾她，自己却态度冷淡，觉得对不起他们（0005–0006）。

## 档案类事实
- 她拍 CM 不是第一次（0003）。
- 她为成为顶级偶像一直在打磨外表，对外貌有自信（0016–0017）。
- 她原本对自己的外貌有自卑感（0019）。
- 过去她被夸奖时，身边总有美鈴或燐羽（0018）。
- 这次拍摄中工作人员多次夸她的外貌（0010）。

## 不确定
- 0005–0006 她说的“冷淡态度”具体是怎样，剧本没写；从上下文看和被夸外貌有关，但未明说。
- 【译文】0014「容姿が高評価されることに／慣れていない」中文译成“还不太习惯受到称赞”，漏掉了“外貌”这个限定。
