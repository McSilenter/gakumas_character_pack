# S卡 1-0001【全力、その後】 / 第2话 手毬的主场……？（adv_csprt-1-0001_02）

- 她的台词：8 行（含用匿名标签说的 0 行）
- 出场的人：ボーカルトレーナー、手毬、咲季
- 场景：高等部入学后不久的声乐课（0004「高等部でもやる気ですね」、0007「高等部からの花海さん」）。
- 世界线：S卡【全力、その後】；制作人在制作的偶像：看不出（制作人未出场）。

## 发生了什么
老师问谁想试，手毬举手，同时咲季也举手（0003-0005）。老师叫手毬让给新生咲季，手毬同意（0008-0009），暗想“刚入学就这么有胆量”（0010）。课程后半练习课题曲时两人同时举手，手毬说“你刚才不是试过了吗！次は私！”，咲季说自己一定要第一，手毬说“那叫任性”（0012-0016）。老师判由手毬先做，手毬暗想“特意要跟我争，真是怪人”（0020）。

## 她的关键台词
- 0003「やります。」——与中等部时一样先举手
- 0009「……ええ。／構いません。」——被让位时忍耐地答应
- 0010「（まだ入学したばかりなのに、／　度胸あるじゃない）」——内心承认咲季的胆量（内心独白）
- 0014「っ……さっきやったでしょう！／次は私！」——第二次同时举手时对咲季发作
- 0016「それ、ワガママっていうんだけど！」——对咲季“一番じゃないと気がすまない”的反驳
- 0020「（わざわざ張り合ってくるなんて……／　変なやつっ）」——内心评价（内心独白）

## 行为模式
- 被老师要求让位 → 嘴上说“没关系”，同时在内心给对方的胆量下评价（0009-0010）
- 对手同时举手 → 立即大声抗议，并用「ワガママ」反驳（0014、0016）
- 对争先的人 → 内心称“怪人”（0020）

## 关系
- 咲季：没有叫名字；咲季 0019 说“下一个是我”。
- ボーカルトレーナー：被叫「月村さん」。

## 档案类事实
- 手毬是从中等部升上来的（0004 老师说“高等部でもやる気”），咲季是高等部入学的新生（0007）。

## 不确定
- 0006 手毬只发出「っ！」，是惊讶的反应。
- 【译文】0004、0007 把「高等部」译成“高年级部”，应为“高等部”。
