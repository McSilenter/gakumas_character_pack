# S卡 3-0044【もう一度、最初から！】/ 第3话 我才是C位！（adv_csprt-3-0044_03）

- 她的台词：11 行（含用匿名标签说的 0 行）。其中 0007、0010、0011 是括号内的心里话，0004 是惊讶的一声
- 出场的人：手毬（11）、咲季（4）、ことね（5）
- 场景：练习中，三人在看手毬的舞蹈动作（0003「フリ」），旁边还有别的练习小组（0020）
- 世界线：S卡【もう一度、最初から！】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
手毬嫌咲季和ことね在看自己，说如果是偷懒就出去。咲季说是在看她的动作学习，ことね也说她在大家里最出色。手毬吃惊，心里开心，说那你们就看吧；ことね心里想“这人真好对付”（0009）。手毬想到他们终于理解了『Campus mode!!』是什么样的歌，提出如果她们达到同样水平可以一起上舞台。咲季说到时自己站中心，手毬问为什么，咲季说因为是姐姐，两人争执起来，ことね说去别的小组。

- 0002「サボってるなら邪魔。／出ていってほしいんだけど。」——一开始的冷淡口吻
- 0004「……え！？」——听到咲季说“在看你的动作学习”时的惊讶
- 0007「（え、えぇ～～～～～！？／ふたりとも、そんな風に思ってたの？）」——心里话，被夸后意外
- 0008「そ、そう。なら見てれば。」——掩饰害羞，答应她们看
- 0011「（『Campus mode!!』が／　どんな曲か、わかってくれたんだ）」——心里话，以为她们认真是因为理解了曲子
- 0013「一緒にステージに立たせて／あげてもいいけど？」——条件式地提出“同台”

- 0018「はぁ！？　なに、その理屈！」——对“因为我是姐姐”的反驳

## 行为模式
- 被人盯着看 → 先怀疑是偷懒并赶人，听到是向自己学习后改口让她们看（0002、0008）
- 被夸最出色 → 惊讶、不好意思，用“なら見てれば”掩饰（0007、0008）
- 高兴后 → 提出“同台”但带有居高临下的条件（0012、0013）
- 咲季抢中心 → 立刻反驳，吵起来（0016、0018）

## 关系
- 咲季：咲季称她「あなた」（0003、0006）；两人在“谁站中心”上立刻吵起来（0015–0018）
- ことね：ことね评价她“経験者”“一番できてる”（0005），心里觉得“チョロい”（0009），并在吵架时带咲季离开（0019–0020）

## 档案类事实
