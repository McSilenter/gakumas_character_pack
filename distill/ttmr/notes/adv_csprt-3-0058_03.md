# S卡 3-0058【ひとりごとです】 / 第3话 和好的拉面（adv_csprt-3-0058_03）

- 她的台词：12 行（含用匿名标签说的 0 行）
- 出场的人：手毬、美鈴
- 场景：吃完拉面离开店之后，两人并排走在回家的路上
- 世界线：S卡【ひとりごとです】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
手毬吃完拉面出店，发现美鈴等在外面，嘴上说“吵架期间不是不说话吗”，但接过美鈴递来的黑乌龙茶并道谢。两人沉默并排走了一阵，手毬问为什么在吵架却并排走，美鈴说“这是自言自语，因为回家的路是一样的”。美鈴反过来指出手毬自己也在说话。手毬沉默后，开始用“这是自言自语”的说法说出：觉得一起吃拉面很怀念、想等和好后再去一次。美鈴同样用“自言自语”回应，并说会先找早上就开门的店。

## 行为模式
- 被对方照顾（递茶、等她）→ 先嘴上带刺，随后接受并道谢（0004、0005、0007）
- 被指出自己前后矛盾（说好不说话却在说话）→ 先沉默、哼一声，再借对方的“自言自语”说法把真心话说出来（0015、0016、0017、0019）
- 想示好时 → 不直接说，而是加上“これはひとりごとだけど”这样的前缀（0016、0019）
