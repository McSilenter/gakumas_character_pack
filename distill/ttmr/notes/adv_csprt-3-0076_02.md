# S卡 3-0076【月村手毬、興味深いわね】 / 第2话 启明星与歌姬的和声（adv_csprt-3-0076_02）

- 她的台词：11 行（含用匿名标签说的 0 行）；0007 是她唱歌的「～♪」，0013 是「一同」齐声的「～♪」（手毬与星南合唱，不算成她本人的台词）；含『一同』齐声 1 行：0013
- 出场的人：手毬、星南、一同
- 场景：练习室（0001「レッスン室に呼び出すなんて」）
- 世界线：S卡【月村手毬、興味深いわね】；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
手毬被星南叫到练习室，先说明自己不打算接受会长的プロデュース。星南说只是想更了解有前途的一年级生，要听她的歌。手毬说在意「一番星」如何评价现在的自己，唱了一首并说“这就是我的实力”。星南称赞她是中等部时被称为歌姬的人，提议下一首和她一起唱，手毬先反问，被问“没自信吗”后回答“正合我意”。合唱结束，星南说很久没和人一起唱了，说和手毬唱很好，邀请以后同台。手毬说观众会被她吸引走，星南接受挑战。

## 她的关键台词
- 0002「言っておきますけど、／会長のプロデュースを／受けるつもりはありません。」——一开始就明确拒绝被星南プロデュース
- 0006「わかりました。『一番星』が今の私を／どう評価するか、気になるので。」——接受试唱，理由是想知道星南怎么评价现在的自己
- 0008「どうですか、これが私の実力です。」——唱完后直接展示自信
- 0010「え？　十王会長と、でしょうか？」——对“与会长合唱”的提议先惊讶
- 0012「いいえ、望むところです！」——被问是否没自信时，立刻接受挑战
- 0016「あ、ありがとうございます……！／私も光栄です。」——被星南称赞后用敬语回应
- 0017「（まさか、会長が一緒に／歌ってくれるなんて思わなかったぁっ）」——心里话，没想到会长会一起唱，内心很兴奋
- 0019「ふっ、いいんですか？　観客がみんな、／私に釘付けになっちゃいますよ？」——对同台演出的邀请，反过来放话要抢走观众

## 行为模式
- 面对强者的邀约 → 嘴上先保持距离或拒绝，但对方提出实力较量时立刻答应（0002、0006、0012）
- 被激将（“没有自信吗”）→ 马上回答“正合我意”（0011、0012）
- 被强者夸奖 → 表面礼貌感谢，心里非常高兴（0016、0017）
- 被邀请同台 → 以放话回敬，表现自信（0019）

## 关系
- 星南：手毬叫「十王会長」「会長」（0001、0010）；星南叫她「月村さん」（0015）。手毬拒绝被她プロデュース，同时在意「一番星」对自己的评价，合唱后互相认可，约定同台
- 「一番星」：手毬在 0006 提到的『一番星』，从上下文指星南
