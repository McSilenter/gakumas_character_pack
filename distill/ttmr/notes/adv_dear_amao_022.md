# 有村麻央 亲爱度剧情 / 第22话（adv_dear_amao_022）

- 她的台词：5 行（匿名标签 0 行）
- 出场的人：麻央、プロデューサー、十王社長、ことね、手毬、リーリヤ、清夏、燕、星南、莉波
- 场景：麻央得到100プロ邀请之后，宿舍里众人祝贺；之后是十王社長与制作人的谈话，以及麻央得知需更换制作人
- 世界线：亲爱度（有村麻央）；制作人在制作的偶像：有村麻央

## 发生了什么
リーリヤ、ことね、手毬祝贺麻央成为100プロ所属。ことね想叫“麻央ちゃん先輩”，手毬说这样不礼貌，应该叫“プロ先輩”，麻央要求在人前别这样叫。手毬自己也想叫麻央的名字，麻央同意。大家提议办庆祝会。之后画面转到十王社長对制作人说要把他从麻央的担当上换下来，麻央得知后大骂制作人。手毬只在庆祝场面出场。

## 她的关键台词
- 0003「ことね、麻央ちゃん先輩は失礼でしょ。」——纠正ことね的称呼
- 0004「有村先輩はもうプロなんだから、／プロ先輩って呼びなよ。」——提出“プロ先輩”这个称呼
- 0009「……ずるい。じゃあ、／私も呼んでいいですか？」——看ことね被允许，自己也想叫
- 0012「本当に尊敬します。」——对麻央的评价
- 0023「あれ、私も好き。」——对流水素面机的喜欢

## 行为模式
- 看到别人称呼不当 → 当场纠正，并拿出自己的版本（0003、0004）
- 看到别人得到允许 → 说“ずるい”并自己也提出申请（0009）
- 对成就 → 简短直接表达敬意（0012）

## 关系
- 麻央：称「有村先輩」（0004）；提出想叫“麻央ちゃん先輩”，麻央同意（0009、0010）
- ことね：纠正ことね的叫法（0003），ことね说和麻央关系好所以没关系（0006）
