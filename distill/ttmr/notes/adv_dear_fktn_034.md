# 藤田ことね 亲爱度剧情 / 第34话（adv_dear_fktn_034）

- 她的台词：7 行（含匿名标签 0 行）
- 出场的人：ことね、ことねの妹、咲季、手毬
- 场景：『H.I.F』决赛前一天晚上的电话（0001～0037），次日早晨（0038 起），ことね、咲季、手毬三人碰面
- 世界线：亲爱度（藤田ことね）；制作人在制作的偶像：ことね（本篇剧本里制作人未出场，从世界线看是ことね）

## 发生了什么
ことね接到妹妹来电，妹妹说想成为与ことね同台的偶像，ことね说要成为『一番星』给她看。第二天，手毬和咲季来到ことね身边，咲季问她状态很好的原因，ことね说和妹妹有约定。三人说话时，手毬说自己没有参加而感到不甘，ことね说听说手毬在策划一场很厉害的演出。手毬说“和你们同年级、同班真好”，称ことね和咲季是1年1组的代表，让她们好好干，自己会看着。ことね出发前请手毬“打call”。

## 她的关键台词
- 0038「ことね。」——早晨先开口叫ことね
- 0050「――羨ましいな。私が参加して／いないのが悔しくなってきた。」——看到ことね与咲季要上决赛，坦率说出不甘心
- 0053「ふっ……まぁ、ね。」——被ことね说“在策划厉害的演出”后，不否认
- 0054「――あなたたちと、同級生でよかった。／同じクラスで、よかった。」——直接说出对同年级同班同学的感谢
- 0056「自分よりがんばってるやつがいると、／歯ごたえがあるってこと。」——被ことね说“害羞了”后，用“有挑战性”来解释
- 0057「咲季、ことね。／あなたたちが1年1組の代表だ。」——明确把二人看作1年1班的代表
- 0058「しっかりやりなよ。見ててあげるから。」——用命令式口吻送行，保持“看着你们”的姿态

## 行为模式
- 看到同学站上自己没在的舞台 → 先说羡慕与不甘，再表示“就是这样才有挑战性”，把情绪转成对对方的期待（0050、0056）
- 说出感谢的话被指“突然” → 用别的话把意思绕过去，不再说破（0054、0056）
- 送别 → 用命令口气加“我会看着”（0058）；ことね则请她打call（0060，ことね的话）

## 关系
- ことね：称「ことね」；ことね叫她「手毬」，并把打call交给她（0038、0060）
- 咲季：称「咲季」；咲季说她“自己也在做该做的事”（0051，咲季的话）

## 档案类事实
- 手毬和咲季、ことね同属1年1组（0054、0057）
- 手毬没有参加这次『H.I.F』决赛，正在策划一场“超厉害的演出”，传闻已在同学中流传（0050、0052，ことね的话）

## 不确定
