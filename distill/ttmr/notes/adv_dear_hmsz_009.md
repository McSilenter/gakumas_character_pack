# 秦谷美鈴 亲爱度剧情 / 第9话（adv_dear_hmsz_009）

- 她的台词：16 行（含匿名标签 0 行）
- 出场的人：美鈴、プロデューサー、手毬
- 场景：美鈴自己演唱会当天（演出前的休息室，演出结束后手毬到后台）
- 世界线：亲爱度（秦谷美鈴）；制作人在制作的偶像：美鈴（0066、0071 制作人称“秦谷さん”，0070 美鈴“人生最高の日”）

## 发生了什么
美鈴睡醒后出场，唱完后回到制作人身边，美鈴想听制作人夸她努力，制作人说今后称赞她努力的人会越来越少。手毬来到后台，说自己在最前排观看，感受到了美鈴的心情，并对美鈴说“你很努力了”。美鈴先否认，手毬说“我都知道，承认吧”，美鈴承认后哭起来，说“最讨厌小毬了”，手毬回答“我可是喜欢美鈴的”。制作人指出“果然有人认可你的努力”，美鈴说这是第二个人。

## 行为模式
- 想说重要的话却说不好 → 先说“说不清楚”，再要求“让我说出来”，然后用最短的话说出（0040、0044、0045、0046）
- 对方否认自己的努力 → 直接说“我知道，承认吧”，用“已经看出来了”压过去（0050、0051）
- 对方情绪激动（哭、说讨厌） → 先问“怎么哭了”，被说讨厌后用“哦，是吗”顶回去，紧接着说“我可是喜欢的”（0056、0058、0059）
- 说完告白式的话 → 用“笨蛋”结尾遮住害羞（0061）

## 关系
- 美鈴：直呼「美鈴」；美鈴叫她「まりちゃん」。美鈴在这篇里说“小毬什么的……最讨厌了”，手毬回以“我喜欢”（0057、0059）
- 制作人：这篇里她没和制作人直接说话；制作人的反应是“果然有人认可你的努力”（0066）
