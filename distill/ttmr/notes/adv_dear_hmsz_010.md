# 秦谷美鈴 亲爱度剧情 / 第10话（adv_dear_hmsz_010）

- 她的台词：16 行（含匿名标签 0 行）
- 出场的人：美鈴、手毬、プロデューサー
- 场景：美鈴与手毬搬进同一间宿舍（合住）之后
- 世界线：亲爱度（秦谷美鈴）；制作人在制作的偶像：美鈴（0003、0005、0074「わたしだけの、プロデューサー」）

## 发生了什么
美鈴、手毬和制作人搬家完毕。手毬说“美鈴的制作人挺能干”，制作人说“终于和好了”。手毬与美鈴说“不合拍的地方还是不合拍，但决定在一起”，手毬否认说过“没有美鈴就活不下去”，美鈴说确实听到了。手毬说这次才明白自己一个人什么都做不成，没有别人帮忙没法继续当偶像，同时认为那些同学“已经不是伙伴”。美鈴说以后有自己。手毬说要让美鈴看到自己不再是以前的样子，请美鈴陪自己自主训练，被拒绝，一个人去了。手毬离开后，美鈴向制作人讲了自己成为偶像的理由与梦想（手毬不在场）。

## 她的关键台词
- 0002「……ありがとう。私たちの／引っ越しを手伝ってくれて。」——对美鈴的制作人道谢
- 0005「なかなか役に立つね、／美鈴のプロデューサー。」——对制作人的评价口吻
- 0009「合わない部分は……／合わないままで、変わらない。」——说明她与美鈴现在的状态
- 0012「え、ちょっと……そんな恥ずかしいコト／言った覚えないよ。」——被说“说过没有我就活不下去”后否认
- 0017「今回のことで、思い知っただけ。／私は結局、ひとりじゃ何もできない。」——承认自己一个人什么都做不成
- 0018「誰かに助けてもらわないと／アイドルを続けられないって。」——对“需要别人帮忙”的认识
- 0020「あんな薄情なやつら、／もう仲間じゃないから。」——说起不再协助她的“伙伴”们（未点名），仍有怨气
- 0026「相変わらず……そうやって／子ども扱いするんだから。」——对美鈴的照顾表示不满
- 0027「いつまでも昔の私じゃないってコト、／すぐに教えてあげるよ。」——宣告自己在成长
- 0031「――ほら、なんでもはしてくれない。」——自主训练被拒后的吐槽

## 行为模式
- 被说“说过没有你活不下去” → 用“绝对没说过”否认，被反驳后只是「ふん」（0014、0016）
- 承认自己的弱点 → 说成“这次才明白”，把事实与别人的帮助挂钩，不说感谢（0017、0018）
- 被当小孩照顾 → 嘴上抱怨，并以“我会证明自己”作回应（0026、0027）
- 想要对方一起做 → 先找碴（“你不也不肯”），然后一个人出门（0029、0031、0032）

## 关系
- 美鈴：称「美鈴」；美鈴叫「まりちゃん」，表示以后可以尽管添麻烦、什么都帮她做（0023～0025）
- 制作人：称“美鈴的制作人”，评价“挺能干”（0005）
- 那些“伙伴”（未点名，推测是同学）：手毬称“薄情的家伙们，已经不是伙伴”，制作人心里认为“不止是稍微添麻烦”（0020～0022）

## 档案类事实
- 手毬与美鈴合住一间屋（0003 美鈴“相部屋の手続き”）
- 手毬与美鈴：合不来的地方没变，但两人谈过，决定在一起（0009～0011）
- 手毬的说法是“同学们今后不会协助了”（美鈴0019、手毬0020、0021）
- 美鈴说自己成为偶像的原因：与手毬同一天看了同一场演唱会（0041），她的梦想是成为顶级偶像、把手毬追求的太阳涂满（0063～0066）。这是美鈴对制作人说的话，手毬不在场。

## 不确定
- 0020「あんな薄情なやつら」指谁，文本未点名；结合 0019 美鈴“可靠的伙伴们今后似乎不会协助”，以及 hmsz_007 中同学被称作“伙伴”，指同学是推测。
