# 秦谷美鈴 亲爱度剧情 / 第17话（adv_dear_hmsz_017）

- 她的台词：41 行（含匿名标签 0 行）
- 出场的人：手毬、美鈴、プロデューサー
- 场景：『N.I.A』进行中，手毬战胜燐羽之后；『FINALE』（最终日）之前
- 世界线：亲爱度（秦谷美鈴）；制作人在制作的偶像：美鈴（0030～0031 制作人说同时培养两人的辛苦，0039 美鈴“只属于我的制作人”）

## 发生了什么
手毬兴奋地向美鈴报告自己赢了燐羽，美鈴说“真的很努力了”。手毬先对美鈴道谢（两人在『N.I.A』是对手），再对制作人道谢，列举了制作人帮她处理炎上、与别校的纠纷。制作人说照顾手毬是为了美鈴，手毬仍然道谢；之后手毬提议让制作人同时培养她们三人（单人名义），制作人崩溃，美鈴说“这位是只属于我的制作人”，手毬略带不满地回应。制作人离开后，美鈴告诉她：手毬与燐羽的对话被偷拍流传到网上，制作人奔走删除；手毬惊慌（说了很羞耻的话），美鈴说“已经说出真心话了”。手毬担心燐羽会不会继续当偶像。美鈴说能做的只有唱歌，两人约定要把燐羽的梦想夺回来。

## 行为模式
- 取得成果后 → 先向最近的人（美鈴）报告，并立刻转为道谢；道谢时分别强调对手关系与“多亏你”（0001、0002、0016、0017）
- 对制作人 → 敬语加上具体事项来感谢，不用笼统的“谢谢”；被说“是为了美鈴”后仍然道谢（0019～0027）
- 听到美鈴把制作人说成“只属于自己的” → 拉长声音“嚯——”，不直说不满（0040、0042）
- 得知自己的私下对话被传出 → 先追问“从哪到哪”，然后喊“最糟了”，听到删除后立刻对制作人道谢（0055、0058、0060、0061）
- 对燐羽 → 由生气转为担心她是否继续当偶像，把“歌唱”作为能做的事（0066、0067、0071）

## 关系
- 美鈴：称「美鈴」；美鈴称「まりちゃん」、称手毬为“我的竞争对手”（0073）；手毬愣一下，答“嗯”（0074、0075）
- 制作人：这一篇里称「プロデューサー」，用敬语；表示感谢并想让他同时培养三人（0019～0035）
- 燐羽：称「燐羽」，关心她会不会回来（0066、0067）；美鈴说燐羽的粉丝感谢手毬“拼命挽留住燐羽大人”（0064、0065，美鈴的话）

## 档案类事实
- 手毬在『N.I.A』里战胜了燐羽（0002）
- 手毬与燐羽的对话被偷拍流出网络，已被制作人删除；美鈴说内容是真心话（0050～0059，美鈴的话；手毬 0052～0058 反应）
- 制作人曾帮手毬处理过“差点炎上”与“与他校的纠纷”（0023）
- 手毬与美鈴在『N.I.A』里是对手（0016）；手毬说不会再重新组团（0034）
