# 秦谷美鈴 亲爱度剧情 / 第18话（adv_dear_hmsz_018）

- 她的台词：12 行（含匿名标签 0 行）
- 出场的人：美鈴、プロデューサー、手毬
- 场景：『N.I.A』最终日（『FINALE』公开试镜）前，美鈴与制作人的会议室；手毬在场
- 世界线：亲爱度（秦谷美鈴）；制作人在制作的偶像：美鈴（0005、0006 制作人要讨论“对策月村手毬”，0039～0043 美鈴“勝ちますよ”）

## 发生了什么
制作人要讨论对付“强力对手”月村手毬的对策，手毬却在场，本人听到被称为“强力对手”暗自开心，又抱怨“当着本人的面商量对策没常识”。制作人让她离开，她说要和美鈴约好去买东西。美鈴让手毬捂住耳朵，手毬虽然答应，但两次猜到别人在说她坏话/夸她，美鈴摸了她的头。会议内容：『FINALE』剩下手毬、美鈴、白草四音三人，燐羽辞退；手毬的票数增加，最近状态绝佳。美鈴宣布自己会赢，『SyngUp!』的第一名非她莫属。

## 她的关键台词
- 0003「『FINALE』！　優勝ライブを／かけた公開オーディション！」——对最终日的兴奋
- 0004「私、絶対に負けるつもりは／ありませんから！」——对美鈴、制作人（敌方）直接宣战
- 0007「私……強力なライバルなんだ～♪」——心里的话（括号内独白），听到“强力对手”暗自高兴
- 0008「私が目の前にいるのに、／月村手毬対策の相談をするなんて……」——表面上抱怨对方无礼
- 0011「ひどっ……このあと美鈴と買い物に行く／約束をしているんです！」——被制作人赶时的借口，同时搬出与美鈴的约定
- 0015「……しょうがないな。」——被美鈴要求捂住耳朵，勉强答应
- 0029「いま私の悪口を言いましたね！／聞こえていないと思って！」——捂着耳朵仍然判断出坏话
- 0031「耳をふさいでいても、／なんとなくわかるんです！　雰囲気で！」——说明自己是凭感觉
- 0038「わかるんですよ！　雰囲気で！」——判断出被夸奖
- 0041「ちょっ……あ、頭撫でないでくれる！？」——被美鈴摸头时慌张

## 行为模式
- 被称为“强力对手” → 内心高兴，嘴上却抱怨“没常识”（0007～0009）
- 被要求捂耳朵 → 勉强答应，但仍然通过气氛判断别人在说什么（0015、0029、0031、0038）
- 被美鈴摸头 → 慌张要求停下，不直接说出开心或不满（0041）
- 对制作人说话 → 敬语（「ありません」「ですか」）（0004、0009、0011）

## 关系
- 美鈴：称「美鈴」；美鈴称「まりちゃん」，称她为“可爱又出色的我的劲敌”（0040）并摸她的头（0041）
- 制作人：被他问“月村同学为什么在这里”（0010）；手毬对他使用敬语，直接宣战（0004）

## 档案类事实
- 『FINALE』残留的是手毬、美鈴、白草四音；燐羽辞退（0017、0018，制作人的话）
- 辞退后手毬的票数增长大，最近状态绝佳；制作人说她本来实力起伏巨大、不稳定（0022、0026、0028，制作人的话）
- 手毬与美鈴约好待会儿去买东西（0011）

## 不确定
- 0007 是括号内的内心独白，不是对谁说的话。
- 0029、0038 的“被夸/被说坏话”是手毬自己的判断，是否与制作人所说的完全吻合，由读者对照 0028、0035～0037。
