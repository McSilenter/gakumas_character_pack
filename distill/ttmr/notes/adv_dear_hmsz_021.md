# 秦谷美鈴 亲爱度剧情 / 第21话（adv_dear_hmsz_021）

- 她的台词：21 行（含匿名标签 0 行；其中 0019 是回放的旧台词）
- 出场的人：美鈴、プロデューサー、手毬、燐羽
- 场景：『Hatsuboshi IDOL FESTIVAL』（『H.I.F』）本战当天，出场前的休息室
- 世界线：亲爱度（秦谷美鈴）；制作人在制作的偶像：美鈴（0003～0016、0042～0051）

## 发生了什么
美鈴被制作人叫醒，说自己“很紧张”。0017～0019 是回放 hmsz_020 里燐羽邀请手毬去特训、手毬欣然答应的片段（美鈴想起手毬在极月特训）。制作人说起『一番星』是賀陽継曾持有的称号，手毬进来补一句“现在是十王星南的称号”。手毬确认美鈴醒着，说来看她的脸，美鈴说今天要战胜手毬成为『一番星』，眼中没有别的偶像。手毬谈到“制作人像担当”，说他一定也认为自己培养的偶像不会输；美鈴说“你看，我的制作人很棒吧”，手毬说美鈴竟是会秀恩爱的类型。最后手毬说今天唱歌也只看着美鈴，两人要展现各自最精彩的演出。

## 她的关键台词
- 0025「初星学園一のアイドル・／十王星南の称号だよ。」——自然接上制作人的话，指出『一番星』现在是谁的称号
- 0027「あ、ちゃんと起きてるね。よかった。」——来确认美鈴醒着
- 0029「ふっ、いっつも大事なライブの直前／まで、ぐーぐー寝てるやつがいるから。」——说明来看美鈴的理由
- 0030「それと……本番前に、／顔を見ておこうかなって。」——补充真实理由
- 0033「……呆れるくらい、いつも通り。」——美鈴说“尽管看”后的感想
- 0034「私ばかり見ていていいの？」——提醒美鈴，夺冠候选不止她们两人
- 0050「自分が育てたアイドルが、／負けるわけないって。」——以引号转述制作人的想法，不是制作人本人的话
- 0055「まさか美鈴が、惚気とかしちゃう／タイプだったなんてね。」——对美鈴夸制作人的反应
- 0057「毅然とした態度で、節度を持った／距離感で接するよ。月村手毬らしくね。」——设想自己与制作人的相处方式
- 0062「ハイハイ――いいよ、今日は私も、／美鈴だけを見て歌う。」——答应美鈴，今天只看着美鈴唱
- 0063「憧れの『H.I.F』に／初参加するんだから。」——『H.I.F』是第一次参加

## 行为模式
- 想看对方状态 → 以“因为你总是在重要演出前睡觉”作借口，然后补一句“还想在上场前看看你的脸”（0029、0030）
- 看到别人腻歪 → 假装受不了（“听着都害臊”），然后带着调侃把话题扯到“如果是我就不会这样”（0053～0057）
- 被美鈴说“我只看你” → 嫌麻烦地说“知道了”，同时回以“我也只看你”（0062）
- 对手只盯着自己 → 反而提醒她“夺冠候补不止我们两个”（0034、0035）

## 关系
- 美鈴：称「美鈴」；美鈴称她「まりちゃん」，说“你好不容易才看向我”（0037）；美鈴称“你是我的竞争对手”，手毬同意（0032～0038、0062）
- 制作人：手毬称「プロデューサー」，说他“越来越像担当偶像了”（0047、0048）
- 燐羽：本篇回放的 0017～0019 中，燐羽邀手毬特训，手毬回答“好耶”，这是回忆

## 档案类事实
- 『一番星』曾是賀陽継的称号，现在是十王星南的称号（0023，制作人的话；0025，手毬的话）
- 这是手毬第一次参加『H.I.F』（0063）
- 手毬与美鈴在本战中是对手，夺冠热门不止她们两人（0034、0035）
- 手毬认为“即使制作人在身边，自己也绝对不会秀恩爱，会保持有分寸的距离”（0056、0057）

## 不确定
- 0017～0019 是 hmsz_020 里 0040～0044 的原样回放（燐羽→手毬），剧本未写明是谁的回忆；美鈴 0020 随后提到“小毬找小燐一起特训”，推测是美鈴的回忆，但没有明说。
- 0050 的『…』内是手毬模仿制作人的想法，不是制作人说过的话。
