# 秦谷美鈴 亲爱度剧情 / 第28话（adv_dear_hmsz_028）

- 她的台词：17 行（含匿名标签 0 行）；含『一同』齐声 1 行：0047
- 出场的人：美鈴、プロデューサー、手毬
- 场景：集训之后，准备『H.I.F』（冬季）本战的会议（0020 夏季『H.I.F』十王星南三连冠已是过去，0037 离本战还有时间）
- 世界线：亲爱度（秦谷美鈴）；制作人在制作的偶像：美鈴（0010 制作人“俺の担当アイドルは、秦谷美鈴ただひとり”）

## 发生了什么
制作人召集会议，说明培养手毬只是暂时，自己的担当偶像只有美鈴一人，照顾手毬是因为状态完美的手毬对美鈴必要。手毬说他对偶像讲话太过分，但立即表示这样也行，自己也在利用他。三人商量对十王星南的复仇：美鈴说在『H.I.F』上当着全校学生击败她就最解气；制作人提议复仇分两步，第一步效仿星南“与传说中的偶像共演”，在头衔上与星南并列。美鈴拒绝，说『一番星』要在『H.I.F』上一次性得到才浪漫。手毬赞同，要求制作人重新制定计划，“为了美鈴”。

## 行为模式
- 被制作人说“你只是附带的” → 先批评说话方式，立刻接受，并反过来说“我也在利用你”（0011、0018、0019）
- 美鈴/制作人的亲密 → 用“都很重”回应，不加入（0017）
- 美鈴反对制作人的方案 → 夸美鈴说得好，替她向制作人下指令；理由写明“为了美鈴”（0070、0071）
- 面对对手的强大 → 只要赢就行，强调自己的成长（0023～0025）

## 关系
- 美鈴：称「美鈴」；美鈴称「まりちゃん」，美鈴说“请为我多多烦恼”（0073，美鈴的话）；手毬站在美鈴一边（0071）
- 制作人：称「プロデューサー」；制作人明确说担当只有美鈴，手毬对此既不满又认同“互相利用”（0011、0018、0019）
- 美鈴的措辞：手毬 0044 说制作人“措辞和美鈴一样”

## 档案类事实
- 手毬被制作人暂时培养，是为了美鈴需要“状态完美的手毬”（0009、0013，制作人的话）
- 手毬喜欢豆沙包（美鈴说“小毬最喜欢的おまんじゅう”，0005，美鈴的话），但本篇里她拒绝，理由是“现在是重要时期”（0006）
- 手毬在夏季『H.I.F』中败北，世人认为不及十王星南（0040，制作人的话）
