# 秦谷美鈴 亲爱度剧情 / 第31话（adv_dear_hmsz_031）

- 她的台词：6 行（含匿名标签 0 行）
- 出场的人：愁佳、美鈴、星南、十王社長、プロデューサー、手毬
- 场景：100プロ的非公式迷你演唱会，美鈴与手毬同愁佳对战（带观众的对战形式）前后
- 世界线：亲爱度（秦谷美鈴）；制作人在制作的偶像：美鈴（0025、0063「うちの秦谷さん」）

## 发生了什么
愁佳的舞台结束，星南感叹，问两人感想。星南说起一年多前自己挑战愁佳（当时的『一番星』）的往事。美鈴说失败经验自己不想再要；手毬替美鈴向星南致谢，说“夏天让我受益匪浅”，今后不会再输、也不怕输，要像去年的星南那样挑战今年的星南。后面愁佳开始长篇MC，手毬吐槽“MC是不是太长了”，十王社長让美鈴去制止（美鈴 0044 答应）；对战之后愁佳问星南“我赢了吧？”，星南反问她自己怎么判断，愁佳随后向美鈴、手毬道歉。对战结果没有明说。最后手毬与美鈴请愁佳指教，愁佳说不想再把她们变强。

## 她的关键台词
- 0015「失礼な美鈴の代わりにお礼を／させてください。／夏は、勉強になりました。」——代替美鈴向星南致谢（行文是 0015 一行里两行换行）
- 0016「二度と負けるつもりはありません。／負けを恐れることもしません。」——对星南宣示不再输、不怕输
- 0017「去年のあなたと同じように、／今年のあなたに挑みます。」——把自己放在去年星南的位置
- 0031「……MC長くない？」——愁佳长篇MC时的吐槽
- 0040「いやMC長くない！？」——再次吐槽
- 0088「先輩！　この後お時間ありますか！？」——赢了对战之后（或结束后）邀请愁佳继续指教

## 行为模式
- 同伴说话失礼 → 替她补上礼貌的话，再说自己的态度（0015～0017）
- 对前辈表达决心 → 用“去年的你”类比今年的对手，敬语（0016、0017）
- 遇到过长的MC → 小声吐槽，同时停在“好奇她怎么换气”之类的话题上（0031、0040）
- 想学到更多 → 主动问对方有没有时间（0088）

## 关系
- 星南：称「あなた」（0017），对她保持敬意和挑战意识；星南评价她“是个理想的学妹”（0018）
- 美鈴：美鈴称她まりちゃん；手毬替美鈴向星南道歉/致谢（0015）
- 愁佳：愁佳后来为“当时那么狂”向两人道歉（0076，愁佳的话）；手毬请教她（0088）

## 档案类事实
- 手毬说夏天的『H.I.F』让她受益匪浅（0015）
- 星南说一年多以前自己赢了愁佳，愁佳比赛后再未参加『H.I.F』（0007～0010，星南的话；此处与 hmsz_030 0058、0060 一致）
- 愁佳之后在100プロ以新人身份出道（0062、0063，星南的话）
