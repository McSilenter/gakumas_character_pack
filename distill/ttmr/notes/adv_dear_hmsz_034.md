# 秦谷美鈴 亲爱度剧情 / 第34话（adv_dear_hmsz_034）

- 她的台词：29 行（含匿名标签 0 行）
- 出场的人：手毬、美鈴、燐羽、愁佳
- 场景：『H.I.F』决赛当天早晨，校门口，等制作人来接（0001、0035）
- 世界线：亲爱度（秦谷美鈴）；制作人在制作的偶像：美鈴（本篇制作人未出场，0001、0035 提到“制作人来接”）

## 发生了什么
手毬催睡着的美鈴出发，美鈴说自己刚才睡了个回笼觉，也做了个“两个人成为主角”的梦，手毬说“接下来就要实现了”。燐羽和愁佳来到校门口，愁佳请燐羽叫住两人，愁佳说“明天有演出”，只来说一句“加油，别输给星南”，手毬和美鈴回答“交给我们”。燐羽说让她后悔没能同台的演出。手毬和美鈴等制作人到来前谈起从解散到现在，美鈴说解散『SyngUp!』也有好处——能看到单人偶像月村手毬的演出。手毬说自己也喜欢单人偶像秦谷美鈴，并说今天只看着美鈴唱歌、要赢、成为『一番星』。美鈴说今天要击溃月村手毬。

## 行为模式
- 对方无所谓地迟到/睡觉 → 说“太像平常了让人放松”，嘴上抱怨（0004、0007）
- 谈到梦想 → 把梦直接改写成“接下来要做的事”（0011、0012）
- 对前辈的鼓励 → 简短答“はい”，不多说（0028）
- 感慨时 → 自己先同意，然后具体回应；美鈴的告白式的话，她用调侃和“我也喜欢”回应，不回避（0037、0046、0049）
- 被问到比较（“比继、燐羽更喜欢吗”） → 不比较，先说“没法比”，再界定“今天只看着美鈴”（0052～0057）

## 关系
- 美鈴：称「美鈴」；美鈴称“我是月村手毬的第一个粉丝、最了解她的人、无人能及的青梅竹马、宿命的对手”（0047、0048，美鈴的话）；手毬说“我也喜欢单人偶像秦谷美鈴”（0049）
- 燐羽：称「燐羽」，向她要加油的话（0031）；燐羽回“尽力而为”，要看让她后悔没能同台的演出（0033、0034）
- 愁佳：称「愁佳先輩」；愁佳来为她们加油（0021、0027）
- 继、燐羽：“那两个人，是特别的”（0054）

## 档案类事实
- 『SyngUp!』已经解散，两人现在以单人偶像身份出场（0040、0045，美鈴的话；0049 手毬“ソロアイドル・秦谷美鈴”）
- 手毬说解散之后“停下脚步、原地踏步”的时间很长（0042）
- 美鈴称自己是手毬的“第一个粉丝”和“青梅竹马”（0047，美鈴的话）

## 不确定
- 0054「あのふたり」，从 0051 美鈴问“继姐姐”“燐羽”推断指的是继与燐羽，本篇没有写名字。
