# 秦谷美鈴 亲爱度剧情 / 第36话（adv_dear_hmsz_036）

- 她的台词：29 行（含匿名标签 0 行）
- 出场的人：美鈴、手毬、星南、学園長
- 场景：『Hatsuboshi IDOL FESTIVAL』优胜者授予『一番星』的仪式（0001～0059），仪式结束之后美鈴与手毬单独相处（0060 起）
- 世界线：亲爱度（秦谷美鈴）；制作人在制作的偶像：美鈴（本篇制作人未出场，由世界线推断）

## 发生了什么
学園長宣布『H.I.F』优胜者是美鈴，星南把『一番星』传给她。美鈴向星南说复仇的快感，星南说“下次轮到我”；美鈴发表致辞（不做模范，不催也不挽留，要站在最高处等大家）后，手毬冲上去祝贺。美鈴却在哭，手毬打趣“怎么是赢的人在哭”，美鈴说“是你说过可以在你面前哭”。手毬说美鈴成了『一番星』其他学校的评价会变差，但也不坏。手毬递手帕，说起初次见面时是她在哭、被美鈴抱着；美鈴说“一开始最讨厌你了”，手毬说“我最喜欢”。手毬问美鈴当初为何想成为偶像，答案是“看到手毬憧憬偶像的样子”，手毬说“那我是大功一件”。美鈴问自己是否成为了顶级偶像，手毬不肯由自己决定，让美鈴把眼泪在庆功宴前哭完。

## 行为模式
- 看到对方哭 → 先半开玩笑“怎么赢的反而哭”，再递手帕、说要“全部听着”（0063、0076、0101、0102）
- 夸奖 → 先强调“是真心话，不是挖苦”，预防对方误会（0069、0071）
- 提到别人的评价时 → 用玩笑与自我解嘲往好处说（“别的学校看到我们的制服会让路”）（0072～0074）
- 被问“能成为顶级偶像吗” → 反问“要我来决定吗”，听到“不行”后接受（0098～0100）
- 说起最初的记忆时 → 平静地讲，自己哭、被美鈴抱着，并直说“我最喜欢你”（0082、0086）

## 关系
- 美鈴：称「美鈴」。美鈴说“一开始最讨厌你了”，手毬回“我知道”“我最喜欢”（0084～0087）
- 継：称「継さん」，猜美鈴想成为偶像的原因不是憧憬継（0090）
- 手毬与美鈴的位置：手毬是“姐姐”一方，美鈴在她初记忆里抱着她（0082、0083）

## 档案类事实
- 手毬能想起的最初的记忆：自己在大哭，被美鈴抱着（0081、0082）
- 手毬与美鈴是婴儿时就认识的（0080、0081）
- 手毬是“姐姐”一方（0083）
- 美鈴说她当初想成为偶像是“因为看到手毬憧憬偶像的样子”（0091、0092，美鈴的话）
- 手毬认为美鈴成为『一番星』会让本校在其他学校那里的评价变差（0072）
