# 花海佑芽 亲爱度剧情 / 第24话（adv_dear_hume_024）

- 她的台词：10 行（含匿名标签 0 行）
- 出场的人：佑芽、燐羽、手毬、広、千奈、星南（0024 佑芽模仿的场面）、佑芽が参考にした人物
- 场景：清晨，晨练后（0001），夏休みが終わったばかり（0070），出发去佑芽老家集训前的集合处
- 世界线：亲爱度（花海佑芽）；制作人在制作的偶像：佑芽（0071 広「佑芽のプロデューサーががんばった」，0074、0075 佑芽提到“制作人”）

## 发生了什么
燐羽在等人，对佑芽交代自己托付给她的粉丝的事，之后谈到咲季姐姐，佑芽说姐姐才是自己的『一番星』，燐羽与佑芽交谈后两人吵了一架。手毬在 0058 赶来，说“燐羽对不起，美鈴还要再等一会儿”，却发现燐羽已经走了；佑芽转达燐羽的留言“在老地方的店里等你”，说“我们吵了一架”。手毬问她们什么时候变得要好，佑芽说“就在刚才”。広、千奈到来，说起要去佑芽老家集训备战『選抜試験』，佑芽模仿顶级偶像（调侃手毬为“とりもも”，広是“砂肝”，千奈是“ぽんじり”）。手毬对这伙人说“吵吵闹闹的家伙”。

## 她的关键台词
- 0058「――燐羽ごめん！　／美鈴まだかかるって――ってあれ？」——代美鈴向燐羽道歉，发现人不在
- 0060「えぇ？　なんで？」——听到燐羽留言让她去“老地方”，疑惑
- 0062「へー、いつの間に仲良くなったの？」——听说佑芽和燐羽吵了架，反而问“什么时候变得要好”
- 0068「そんな話してたっけ？　というか……／なにこの集まり？　ぞろぞろと……」——对突然出现一群人的反应
- 0070「夏休みが終わったばかりの／この時期に？　よく許可が出たね？」——对集训许可的疑问
- 0079「もったいない。」——佑芽说“上一次对偶像了解不多”时的评价
- 0082「ほんとに？　じゃあ、／いまここでやってみてよ。」——佑芽说能模仿顶级偶像，她挑衅式地要求现场表演
- 0084「とりももってなに？」——被叫「とりもも」的反应
- 0086「はあ！？」——得知「とりもも」指自己
- 0095「騒々しいやつら……」——总结

## 行为模式
- 约好的对象不在 → 先道歉，再发现人不在，改问留言（0058、0060）
- 听到别人关系出乎预料 → 用“什么时候”的问句追问，不评价（0062）
- 人群突然聚集 → 先质疑“聊的是这个吗”，再追问用意（0068）
- 听到对方“有长处”或“能做到” → 评价后要求现场展示（0079、0082）
- 被取外号 → 先问“什么意思”，得知是指自己后大叫（0084、0086）

## 关系
- 佑芽：佑芽称她「手毬ちゃん」，手毬以佑芽的话评价“暴殄天物”“吵吵闹闹的家伙”（0079、0095）
- 燐羽：称「燐羽」，是约好等的人（0058）；燐羽 0013 说“在等手毬她们”
- 美鈴：手毬提到“美鈴还要再花点时间”（0058）
- 広、千奈：一同在场，手毬被佑芽称为「とりもも」，広是「砂肝」，千奈是「ぽんじり」（0083、0090）

## 档案类事实
- 手毬、美鈴、燐羽约好在这里集合（0013 燐羽、0058 手毬）
- 这次是夏休み刚结束的时期（0070）
- 手毬被佑芽取了外号「とりもも」（0085，佑芽的话）

## 不确定
- 0087 说话人标签为“佑芽が参考にした人物”的台词「健やかに育て……雛鳥。」是佑芽模仿的“某顶级偶像”的话，不是手毬，也不是佑芽本人真实说话（0083、0088 佑芽解释“有个顶级偶像总给人起好吃的外号”）。
- 0024 星南的台词出现在佑芽与燐羽对话之中，但星南并不在场，应是佑芽回想（或想象）的场面，剧本未标明；与手毬无关。
- 0058 之前手毬与燐羽约定的内容（0015 燐羽“秘密に決まっているじゃない”）未说明。
