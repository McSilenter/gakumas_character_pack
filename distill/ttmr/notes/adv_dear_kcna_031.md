# 倉本千奈 亲爱度剧情 / 第31话（adv_dear_kcna_031）

- 她的台词：21 行（含用匿名标签说的 0 行）
- 出场的人：星南、手毬、千奈、美鈴、佑芽、広
- 场景：为冬季『H.I.F』进行的特训开始日，摄像机已在拍摄纪录片（0029、0052）。
- 世界线：亲爱度（倉本千奈）；制作人在制作的偶像：千奈（0049 千奈说“対老师发过誓”；制作人本人此篇无台词）。

## 发生了什么
星南介绍特训成员（千奈、佑芽、広）和特别教练（美鈴、手毬）。手毬说她和美鈴这次不参加冬季『H.I.F』，因为要办解散演唱会，并说这次放弃、下次万全参加（0011-0016）。星南说“好像参加了就能赢我”，手毬回答“会赢，当然”（0017-0019）。星南说明特训的目的是造出新的优胜候选，手毬补充一句（0037）。随后手毬开始声乐特训，课题曲『ガラクタロード』，并对千奈说自己能教会她（0061-0069）。手毬对千奈说，『一番星』是她们的憧憬，明年之前要先成为顶级偶像，再去挑战『一番星』倉本千奈，还说自己是千奈的粉丝（0072-0078）。

## 她的关键台词
- 0011「まだ言ってなかったよね。／私と美鈴、今冬の『H.I.F』には／出場しないんだ。」——对千奈说明不参加冬季『H.I.F』
- 0016「今回はパス。／次回、万全の態勢で臨むことにする。」——不是退出，是等下次
- 0018「勝ちます。当然です。会長のことは／尊敬していますけど。」——对星南用敬语，直言会赢
- 0019「胸を借りるつもりで、だなんて。／そんな甘い気持ちでは挑みませんよ。」——不以“向前辈学习”的心态挑战
- 0024「自業自得でしょ。自分の／プロデューサーをもっと敬いなよ。」——对美鈴抱怨星南的回应
- 0064「美鈴はああ言ってるけど、／私は厳しくいかせてもらう。」——与美鈴“点到为止”不同，要严格
- 0065「あなたたちの歌を、本戦までに／一段上まで引き上げてみせる。」——声乐教练的承诺
- 0068「できるよ、あなたなら。／教えられるよ、私なら。」——对千奈“能做到吗”的回答
- 0073「『一番星』は……特別な……／憧れの称号なんだ。」——说自己对称号的执着
- 0076「それから挑むよ――／『一番星』倉本千奈に。」——对千奈的宣言
- 0078「いけない？　／私、あなたのファンだけど？」——被千奈说“说话最强”时的回应

## 行为模式
- 被星南调侃 → 以敬语直接说“会赢”，同时表示尊敬（0018-0019）
- 美鈴抱怨星南 → 用「自業自得でしょ」顶回去（0024）
- 作为教练 → 明确说严格，并以承诺和信任鼓励对方（0064-0069）
- 说到重要的事 → 先用“あの、さ”开头，语速放缓，用“……”断句（0072-0074）
- 被说话强硬 → 反问“不行吗”并以粉丝身份说明（0078）

## 关系
- 千奈：叫她「千奈」，千奈叫她「月村さん」（0010）。手毬自称千奈的粉丝（0078），说教她“以前做过很多次”（0069）。
- 美鈴：叫「美鈴」，美鈴叫她「まりちゃん」（0023）。
- 星南：叫「会長」，星南叫她「手毬」。

## 档案类事实
- 手毬与美鈴这次冬季『H.I.F』不出场，要办 SyngUp! 的解散演唱会（0011-0013，0012-0013 是美鈴说的）。
- 手毬想明年『H.I.F』前先成为顶级偶像（0075）。
- 手毬说『H.I.F』是她们梦想的起点，『一番星』是令人憧憬的称号（0072-0073）。

## 不确定
- 0037 手毬在转述星南的意图（“要向学园内外展示还有别的优胜候选”），是对星南话的概括，不是她自己的新想法。
- 0069「いままで何度も、／やってきたことでしょ。」指的是以前教过千奈歌，具体时间不明。
- 【译文】0015 译作“欲速则不达”，原文是「二兎を追うものは……」（追两只兔子……），两者含义略不同；0061『ガラクタロード』被译作『荆棘之路』。
- 【已确认 2026-10-30】『一同』0062 不算她的台词（跟她学唱歌的人）。
