# 月村手毬 亲爱度剧情 / 第1话（adv_dear_ttmr_001）

- 她的台词：26 行（含用匿名标签说的 0 行）
- 出场的人：手毬、プロデューサー
- 场景：她在上课练习（レッスン）的地方，制作人在练习中途来找她（0002、0003、0007）。
- 世界线：亲爱度（月村手毬）（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
制作人查过资料后来招募她，她先以妨碍练习为由要对方出去（0002、0003）。她不愿等到练习结束，要求当场说（0008），一听是招募就拒绝，理由是对方没好好调查她（0010、0011）。制作人说清楚了解她“引发的问题”仍想培育她，她愣住并要求考虑一下（0013～0018）。内心里她权衡后觉得这是好事，“现在的我”不会有别人来招募（0019～0027），于是用居高临下的口气答应（0029），又马上在心里后悔说得太傲慢（0030、0031）。最后她说出自己有一个发誓要实现的梦想，要制作人别让她失望（0033～0035）。

## 她的关键台词
- 0002「――出て行っていただけますか。」——第一句就是逐客，用客气的形式说冷硬的话。
- 0011「私のことをよく調べもせずに／きた方を、信用できません。」——不信任没有了解她就来接近的人。
- 0014「私が起こした問題を……／知っていると？」——承认自己过去“引发过问题”，并以为别人会因此避开她。
- 0020「（いいえ、期待はしないでおこう。／私は、そう決めたんだから）」——内心独白：她给自己定下“不抱期待”的规矩。
- 0023「（……そんなに怒ってる／みたいに見えるのかな……？）」——内心独白：外表冷硬，自己却在意是不是看起来在生气。
- 0027「（『いまの私』をスカウトしよう／なんて人、他にいるわけない）」——内心独白：对自己现状的评价很低。
- 0029「私をプロデュースさせてあげます。」——答应时用施舍式的高姿态。
- 0030「（って、なんでこんな／偉そうに言ってるの私！）」——内心立刻自我吐槽，嘴上和心里落差大。
- 0033「私には夢があるの。／必ず叶えると誓った夢が。」——说出自己有发誓实现的梦想，语气从敬语转为普通体。
- 0035「私を失望させないで。」——答应合作的同时提出要求。

## 行为模式
- 练习被打扰 → 直接逐客，用敬语说冷话（0002、0003）。
- 对方提出要谈 → 不肯等，要求当场说完（0008）。
- 以为对方不了解自己的过去 → 立即拒绝并说明不信任的理由（0010、0011）；对方表示知情仍要她 → 愣住、反复确认，然后要求时间考虑（0013～0018）。
- 内心先期待再压下期待，用理性的利弊说服自己接受（0019～0027）。
- 别人问她是否在生气 → 嘴上冷淡否认并让对方别说话，心里却担心自己看起来太凶（0021～0023）。
- 做出让步时 → 嘴上用「させてあげます」式的高姿态，心里随即后悔、担心惹对方生气（0029～0031）；慌乱时用「コホン」清嗓子重整姿态（0032）。

## 关系
- プロデューサー：本篇她没有叫过「プロデューサー」，对其用「あなた」（0005）；制作人称她「月村手毬さん」「月村さん」（0004、0021）。从逐客、拒绝，到勉强答应让对方培育她，同时说“不要让我失望”（0002、0010、0029、0035）。制作人自述“总算招募成功，要慢慢积累信任”（0036）。
