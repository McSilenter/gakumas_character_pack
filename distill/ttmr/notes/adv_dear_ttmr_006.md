# 月村手毬 亲爱度剧情 / 第6话（adv_dear_ttmr_006）

- 她的台词：42 行（含用匿名标签说的 0 行）
- 出场的人：手毬、プロデューサー
- 场景：前一天晚上的电话；第二天她作为个人偶像的第一次演唱会（彩排、正式演出后）
- 世界线：亲爱度（月村手毬）（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
演唱会前一天，手毬打电话给制作人，心里不安却说不出口，借口是担心制作人会不会怯场（0002–0008）。制作人坦白自己也很紧张、不确定自己的培育是否合格，她立刻说“肯定做好了”，并说出自己对制作人有「一点点」信任，要对方明天好好看着（0013–0022）。彩排时制作人再三叮嘱只用七成力，她嘴上答应，结果全力唱完，被指出后硬说那就是七成（0028–0043）。正式的首次演唱会以惨败告终（0049）。制作人说发现了她“不可分割的长处与短处”，她自以为是「太冷酷」，结果被说成“状态差就是大惨事”，对方安慰到一半还放弃了，她抗议后表示失败了消沉也没意义，只想早点回去开反省会（0057–0073）。

## 她的关键台词
- 0004「用がないと電話しちゃいけないの？」——主动打电话却不承认有事
- 0007「（不安になった、なんて言えないよ）」——内心独白：真实的不安说不出口
- 0008「プロデューサー、／怖気づいてないかな……って。」——把自己的不安转嫁成担心对方
- 0013「できてたに決まってる！　／……と、思わなくもないけどっ？」——先脱口肯定，再别扭地打折
- 0016「プロデューサーのこと、少しだけ……／少しだけだよ？　……信頼してるから。」——第一次表达对制作人的信任
- 0019「（私のことを、わかってくれるから）」——内心独白：信任的理由
- 0029「甘く見ないで。ペース配分くらい、／ちゃんとやってみせるから。」——对自己的舞台经验很自信
- 0041「い、いまのが7割の力だけど？／全力なんか出してないけどっ！？」——违背指示后嘴硬狡辩
- 0060「よく言われる。感情が薄くて、／冷たい印象が作り物めいているって。」——她自述别人对她的评价
- 0072「ライブが失敗して落ち込むのって／意味あります？」——失败后不消沉的态度
- 0073「早く帰って反省会したいんですけど。」——马上想转向反省改进

## 行为模式
- 自己不安 → 不说出口，找借口联系对方，把不安说成是担心对方（0004、0007、0008）
- 对方示弱 → 立刻替对方打气，然后又别扭地收回一半（0013）
- 表达好感、信任 → 反复强调「少しだけ」来降低分量（0016）
- 上台后容易忍不住全力，明明答应过要保留体力（0032、0035、0039）
- 犯错被指出 → 先「あっ」愣住，再硬找证据狡辩，最后反质问对方有什么不满（0039–0043）
- 失败后 → 不沉溺于消沉，反嫌制作人说话难听，想立刻开反省会（0068–0073）
- 被激怒或强辩时转成敬语（0043、0062、0068、0070）

## 关系
- プロデューサー：她称「プロデューサー」，对方称她「月村さん」。说出「少しだけ」信任制作人，理由是对方理解她；首次演唱会想让对方看着；但彩排时完全不听对方指示（0016、0019、0021、0041）

## 档案类事实
- 这一篇是她作为个人（ソロ）偶像的第一次演唱会，结果惨败（0006、0049）
- 她说自己经历过很多次演唱会（0028）
- 她说常被别人评价感情淡薄、冷淡的印象像是装出来的（0060）
- 制作人评价：她状态差时是大惨事，状态好时潜在实力惊人，但无法有意发挥出来（0065、0067）

## 不确定
- 0062、0064 前面是制作人的选项（未收录），她回应的具体内容不明。
- 0060 原文是「冷たい印象が作り物めいている」，译文“给人虚伪的冷漠印象”大意相同；她把这当作自己「太酷」的证明，是否带自嘲不明。
- 0013 译文“虽然也不是完全没这么想过啦”与原文「と、思わなくもないけどっ？」语气基本对得上，但原文是在给前句打折。
