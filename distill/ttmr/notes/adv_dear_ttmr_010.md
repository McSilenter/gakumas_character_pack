# 月村手毬 亲爱度剧情 / 第10话（adv_dear_ttmr_010）

- 她的台词：46 行（含用匿名标签说的 0 行）
- 出场的人：手毬、美鈴、プロデューサー
- 场景：宿舍，她和美鈴搬进合住房间、制作人帮忙搬完行李之后
- 世界线：亲爱度（月村手毬）（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
制作人因为输了赌，帮手毬和美鈴办了合住手续、搬了行李（0002–0006）。美鈴说也想和她一起接受制作人的培育，她慌忙阻止，被美鈴逗弄，两人斗嘴，最后逼问制作人“我和美鈴选哪个”（0009–0030）。制作人说“作为偶像”目前美鈴更强，她以为制作人想培育美鈴，制作人却说要培育的话还是她好，她得意地向美鈴炫耀（0031–0042）。美鈴回房午睡后，她说虽然不能同台，但还能做朋友，不会再回到从前那样，并感谢制作人（0053–0057）。接着她第一次讲出当偶像的理由：小时候胖、懒、爱撒娇、性格差，讨厌那样的自己；看到第一个偶像像有翅膀一样跳舞、像女神一样唱歌，觉得如果能变成那样也许就能喜欢自己（0060–0069）。她说自己的翅膀是假的，问制作人是否还是选她；制作人说“讨厌努力的懒人却比谁都努力”最有魅力，「あなたがいい」，她回「怪人」，并说要带制作人去最高的地方（0070–0080）。

## 她的关键台词
- 0014「み、美鈴のそういうところが嫌い！」——被美鈴戳穿时的反应
- 0024「どっちがいいの！？」——逼制作人在她和美鈴之间选
- 0029「は？　は？　は？」——不满时的连续「は？」
- 0036「……美鈴の方が実力あるのに、／私の方がいいの？」——承认美鈴更有实力，同时确认被选
- 0041「プロデューサーは、一番最初から、／私がいいって言ってたんだから。」——得意地炫耀被选
- 0054「友達ではいられるから。」——与美鈴关系的定位
- 0057「その……ありがとう。」——难得直接道谢
- 0061「……小さい頃……私、太っててさ。／怠け者で、甘えん坊で、性格も悪くて。」——自述童年
- 0062「なんの取柄もなかった。そんな自分の／ことが、大嫌いだった。」——成为偶像的根源：讨厌自己
- 0066「もしも自分があんな風になれたなら、／私は私を好きになれるかもしれない。」——梦想的核心动机
- 0068「毎日必死になって、背伸びをして、／憧れに近づこうとする自分が好き。」——喜欢努力中的自己
- 0069「だけど、少しでも気を抜くと、／嫌いな自分に逆戻りしてる。」——对自己本性的不安
- 0073「そんなのとっくに知ってるよ。／私の翼は造り物で、本物じゃない。」——自认不是天才
- 0080「一番高いところまで、／連れていってあげるから。」——被认可后的回应：以高姿态许诺

## 行为模式
- 被别人逗弄、戳穿心思 → 结巴、说「嫌い」、发火掩饰（美鈴说她「すぐ怒って／ごまかす」）（0012–0015）
- 被当小孩对待 → 激烈反驳（0018）
- 在意自己是否是被选的那个 → 直接逼问，得到答案后立刻得意炫耀（0024、0036–0042）
- 被真诚夸奖 → 用「あっそう」「変わり者」冷淡回应，再用高姿态的约定回报（0078–0080）
- 气氛安静下来、只剩两人时 → 主动说出心里话和过去（0053–0069）
- 讲到自己的弱点 → 先自己说出来（“早就知道”），再确认对方是否仍然选她（0073、0074）

## 关系
- プロデューサー：她称「プロデューサー」，对方称她「月村さん」「あなた」。她感谢制作人带来的一切，第一次讲出当偶像的理由；被说「あなたがいい」后，回以「最後まで付いてきなよ」（0056、0057、0060、0077–0080）
- 美鈴：她称「美鈴」，美鈴称她「まりちゃん」。两人重新合住；斗嘴不断，美鈴爱逗她，她说美鈴「嫌い」又炫耀自己被选；她承认美鈴更有实力；定位为不同台但是朋友；吐槽美鈴不自主训练（0014–0018、0036、0042、0046、0054）

## 档案类事实
- 她和美鈴搬回同一间宿舍（相部屋），手续由制作人帮忙办（0004、0052、0053）
- 她和美鈴不再同台唱歌，但仍是朋友（0053、0054）
- 小时候胖，懒惰、爱撒娇、性格差，毫无长处，讨厌自己（0061、0062）
- 当偶像的理由：第一次见到的偶像像有翅膀一样跳舞、歌声像女神，让她觉得变成那样就能喜欢自己；目标是顶级偶像，因为那是人人憧憬的存在（0063–0067）
- 喜欢拼命努力的自己，但一放松就会变回讨厌的自己（0068、0069）
- 自认「私の翼は造り物」，不是天才（0073）
- 制作人评价她是「日々の努力を苦痛に感じる怠け者」，却比谁都努力（0075）
- 美鈴说她能自己打理身边的事（身支度）了（0017）

## 不确定
- 0012「言ったでしょ？」她之前对美鈴说过什么（不让美鈴也被制作人培育的理由）剧本没交代。
- 0021 美鈴「プロデューサーが原因なのですから」，译文作“都是因为制作人您呀”，从上下文看可能是指“现在吵起来是因为制作人”，也可能指和好要归功于制作人，有歧义。
- 0019、0026、0028 是对制作人选项（未收录）的反应，具体内容不明。
- 0031–0032 译文切分错位：0031 译“目前来说，我觉得……”，0032 译“秦谷同学更胜一筹”，原文 0032 是「――アイドルとして。」，译文漏掉了“作为偶像”这层限定。
- 0038–0039 译文明显删节，0038 原文「そんなに……／私の方がいいんだ？」没译全。
- 0051「あれって絶対さあ――――」话被打断，没说完。
