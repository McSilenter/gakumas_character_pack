# 月村手毬 亲爱度剧情 / 第11话（adv_dear_ttmr_011）

- 她的台词：25 行（含用匿名标签说的 0 行）
- 出场的人：プロデューサー、手毬、あさり先生
- 场景：校内（制作人刚从あさり先生处打听完燐羽的情况），她跑来找制作人
- 世界线：亲爱度（月村手毬）（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
あさり先生向制作人介绍：偶像科各年级 3 組聚集有特殊情况的学生，『SyngUp!』前队长賀陽燐羽是特例的特待生、唯一不从事偶像活动的特待生，原本不打算内部升学，是十王社長说服的（0001–0007）。手毬跑来要告诉制作人燐羽退学转到961プロ的事，资料显示燐羽去了極月学園；制作人推测961プロ的目的是让燐羽参加『NEXT IDOL AUDITION』（0010–0018）。她愤愤地说燐羽入学几个月什么都没做、明明已经不想当偶像了（0020–0021）。她说賀陽継是她曾憧憬、让她成为偶像的人；燐羽从初次见面起就有她现在的实力，是燐羽教她唱歌、教她当偶像（0026–0032）。提到燐羽解散后的炎上事件，她请求给时间整理、以后会好好说；说燐羽组队后「ぐれちゃった」，但那样也很帅，现在仍是她憧憬的偶像（0034–0041）。制作人说元『SyngUp!』在『N.I.A』对决、她超越曾经比她强的伙伴夺冠是燃的展开，她说制作人孩子气，然后宣布要制霸『N.I.A』，赢过美鈴和燐羽（0044–0053）。

## 行为模式
- 有急事 → 在校内跑着找制作人（0010、0011）
- 听到新目标 → 本能地兴奋，再强行拉回正题（0013）
- 谈到放弃偶像的旧友 → 先用「くせに」愤愤指责，实际上是在意（0020、0021、0041）
- 被问到还说不清的痛处 → 不回避也不硬说，请求时间整理，承诺之后好好讲（0034、0035）
- 别人贬低她憧憬的人 → 维护对方「燐羽は燐羽だから」（0039–0041）
- 制作人说出热血的话 → 吐槽「孩子气」「あっそ」，随后接受并定下目标（0049–0053）

## 关系
- プロデューサー：她称「プロデューサー」，对方称她「月村さん」。认为制作人招募她时调查过她；吐槽制作人孩子气；接受对方提出的『N.I.A』目标（0023、0049、0052、0056）
- 燐羽：她称「燐羽」。曾教她唱歌和当偶像；初次见面时就有她现在的实力；组队后「ぐれちゃった」，但她觉得那样也很帅，至今仍是憧憬的偶像；对燐羽的现状既气又在意；目标是在『N.I.A』赢过燐羽（0020、0021、0030、0032、0038–0041、0053）
- 美鈴：她认为美鈴也会参加『N.I.A』，目标是赢过美鈴（0045、0053）
- 賀陽継：『SyngUp!』成员曾经的目标偶像；她说是自己曾憧憬的人、成为偶像的契机（0025、0026）

## 档案类事实
- 『SyngUp!』成员曾以偶像賀陽継为目标（0025）
- 賀陽継是她曾憧憬的人，成为偶像的契机；她说以前跟制作人稍微提过（0026、0027）
- 燐羽是『SyngUp!』前队长，初星学園的特例特待生，入学后唯一不做偶像活动的特待生；原本不打算内部升学，被十王社長说服（0005–0007）
- 燐羽退学初星学園，转到961プロ，去了極月学園（0014、0016）
- 燐羽从初见就有她现在的实力；是燐羽教她唱歌和当偶像（0030、0032）
- 燐羽在『SyngUp!』解散后引发过大规模炎上事件；她暂时不愿细说（0033–0035）
- 燐羽在组队后有很大的形象转变，她说是「ぐれちゃった」（0037、0038）
- 下一个目标：『NEXT IDOL AUDITION』（『N.I.A』），她要夺冠，赢过美鈴和燐羽（0012、0052、0053）
