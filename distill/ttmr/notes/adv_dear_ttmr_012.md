# 月村手毬 亲爱度剧情 / 第12话（adv_dear_ttmr_012）

- 她的台词：34 行（含用匿名标签说的 0 行）
- 出场的人：手毬、プロデューサー
- 场景：和制作人讨论『N.I.A』宣传方针；翌日她来找制作人坦白 SNS 炎上
- 世界线：亲爱度（月村手毬）（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
手毬问制作人为了制霸『N.I.A』该做什么，听到常规做法后嫌太普通，指出学生会和極月学園已经开始大规模宣传，还别扭地表示可以上电视（0001–0008）。制作人说她的武器是美丽凛然的外表和孤高之狼般的魅力，要避免媒体曝光、提升神秘感（「プランA」），她心里乐开了花，马上改口说电视不好（0012–0021）。制作人告诉她下次试镜后有学园主导、和他校偶像共演的电视节目，叮嘱她稳妥完成，她笑对方爱操心，说自己已经洗心革面、不会再惹麻烦（0031–0039）。第二天她来坦白：自己开了 SNS，早上的帖子「稍微」成了话题，实际已经炎上（0041–0049）。制作人早就开了官方账号并举报所有冒牌号，她的真号也被当成冒牌删掉了；她很委屈，最后说要把这份不甘心发泄在下次试镜上（0052–0064）。

## 行为模式
- 想做某事但不好意思直说 → 以“既然你说需要”「出てあげてもいい」的姿态提出（0007、0008）
- 被夸外表、形象 → 表面「ふぅ～ん」「いいんじゃない？」，心里雀跃，并马上顺着对方改变主张（0014、0016、0020、0021）
- 被叮嘱别惹事 → 笑对方操心、拍胸脯保证，转天就闯祸（0037–0039、0046）
- 闯祸后 → 先抗议对方先入为主，再轻描淡写「たいしたことじゃない」，被戳穿就道歉并求对方「なんとかして」（0043、0045、0050、0051）
- 受了委屈 → 大声抗议、哀叹，最后把不甘心转成工作的干劲（0056、0061、0064）

## 关系
- プロデューサー：她称「プロデューサー」，对方称她「月村さん」。很在意制作人怎么看她的形象；闯祸后第一个找他并全权依赖；他瞒着她开了官方账号并删掉了她的真号（0020、0041、0051、0054、0058）

## 档案类事实
- 制作人对她的宣传方针（プランA）：避免媒体露出、提升神秘感，主打美丽凛然的外表和孤高之狼般的魅力；大量制作帅气的 PV、MV（0013、0017、0018、0028）
- 制作人另外准备了プランB以防意外（0024、0025）
- 下次试镜后将参加学园主导的、和他校偶像共演的电视节目（0031、0032）
- 她私自开了 SNS 账号，第一天早上的帖子就炎上；账号被制作人当成冒牌号举报后删除；她的官方 SNS 由制作人一方运营（0046、0049、0054–0058、0062）
- 她提到学生会和極月学園已经开始大规模宣传（0005、0006）
