# 月村手毬 亲爱度剧情 / 第13话（adv_dear_ttmr_013）

- 她的台词：51 行（含用匿名标签说的 0 行）
- 出场的人：手毬、千奈、極月学園のアイドル、プロデューサー、撫子、四音、広、ことね、咲季、あさり先生
- 场景：学园主导宣传活动（和他校偶像共演的电视节目）的工作现场，收工后；最后她打电话给制作人
- 世界线：亲爱度（月村手毬）（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
制作人不能陪同所有工作，在あさり先生劝说下，拜托别人照看手毬去参加学园主导的宣传工作（0001–0006）。剧本有两条并列分支：拜托的是ことね（0007–0066）或咲季（0067–0125），两条线里她的言行几乎相同。收工后她嫌对方今天「馴れ馴れしい」，随后看到極月学園的偶像在嘲讽千奈、広和整个初星学園（0008–0021／0069–0082）。她上前质问，对撫子报出的「白草四音お姉さま」说不认识，骂極月学園是 961プロ 二军三军凑成的杂鱼，说初星不需要『一番星』和 3 組出场，被瞧不起的「落ちこぼれ」就足够赢（0025–0041）。四音问她有什么实绩，她说自己有三首以上的持ち歌，嘲笑对方只会唱前辈的翻唱，并放话让 961 的顶尖来，由由初星学園的藤田ことね（或花海咲季）和月村手毬击溃对方（0045–0052）。対方离开后她心里说「好可怕」，觉得帮到了学园伙伴（0056–0057）。ことね线里ことね抱怨被她拉成主犯，她说想和ことね一起挑战；咲季线里咲季很高兴，她说只是想让咲季高兴（0058–0066／0118–0125）。最后她向制作人道歉，说和極月学園起冲突的经过被传到网上，制作人的プランA崩溃（0128–0132）。

- 0008「お疲れ様。／今日、なんだか馴れ馴れしいね。」——对平日同学的距离感
- 0024「ふっ……あまり期待しないでよ。／私、口下手だから。」——自认嘴笨（ことね线）
- 0029「誰それ。しらない。」——对挑衅者的轻蔑
- 0032「ふっ、単独で初星学園に対抗できない、／雑魚の寄せ集めでしょ。」——毒舌全开
- 0038「『一番星』も3組も出てこない？　／だからなに？」——为初星学園出头
- 0041「十分勝てるってこと。／負けて泣く前に謝っておいたら？」——挑衅式反击
- 0045「私、持ち歌、3曲以上あるけど？　／あなたは？」——以实绩压人
- 0049「極月学園の皆さんが、先輩方の／カバー曲ばかり歌ってるだなんて。」——装作客气的讽刺
- 0052「初星学園の藤田ことねと月村手毬が、／叩き潰してやるから！」——把同伴的名字一起报出（咲季线 0112 换成花海咲季）
- 0056「（ふぅ～～～～、怖かったぁ～～～～）」——内心独白：强硬是硬撑出来的
- 0057「（学園の仲間を助けられた、かな）」——内心独白：动机是帮伙伴
- 0060「お礼なんていいよ。私だけの手柄にする／のが、申し訳ないなって思っただけ。」——把拖人下水说成好意（ことね线）
- 0064「サインをもらって、握手をねだって。／それから挑むよ。」——对 961 顶尖偶像也有粉丝心理

- 0128「プロデューサー……ごめん。／あの、私は悪くないんだけど……」——道歉同时坚持自己没错

## 行为模式
- 平时对同学冷淡，对方稍亲近就说「馴れ馴れしい」（0008、0069）
- 看到伙伴、学园被侮辱 → 主动上前，用毒舌和挑衅压倒对方（0025–0041、0085–0101）
- 被质疑实绩 → 拿具体成绩反击，再用假客气的敬语讽刺（0045–0049）
- 嘴上强硬，内心其实害怕；事后在意的是有没有帮到伙伴（0056、0057）
- 把同伴卷进来 → 说成是“不想独占功劳”“想让你高兴”（0060、0123）
- 被夸帅 → 结巴着说没什么大不了（0119）
- 闯祸后 → 第一时间向制作人报告并道歉，但强调自己没错（0128、0130）
- 让信任的同伴留在原地，自己一个人先上（咲季线 0083）

## 关系
- プロデューサー：她称「プロデューサー」。制作人请别人照看她；她闯祸后打电话道歉，说自己没错（0006、0128）
- ことね（藤田ことね）：她称「ことね」，对方称她「手毬」。ことね被制作人拜托照看她；她说ことね今天很「馴れ馴れしい」；对極月学園放话时把ことね的名字放在前面，ことね抱怨被拖成主犯；她邀ことね一起挑战（0008、0022、0052、0058–0066）
- 咲季（花海咲季）：她称「咲季」，对方称她「手毬」。被制作人拜托照看她，夸她“今天是乖孩子”，她嫌「馴れ馴れしい」；冲突时让咲季留在原地；报出咲季的名字是想让咲季高兴；咲季邀她一起挑战 961 大 boss（0068–0069、0083、0112、0118–0125）
- 千奈：称她「月村さん」，感谢她来帮忙但说她话太狠（0033、0034）
- 広：说「わたし、手毬、すき」（0042）
- 撫子（藍井撫子）、四音（白草四音）：極月学園的偶像；她说不认识四音，嘲笑对方没有持ち歌；四音记住了和她一起被报出的名字（0029、0047–0049、0054）

## 档案类事实
- 她有三首以上的持ち歌（0045）
- 她自称「口下手」（0024）
- 她说極月学園是多家事务所联合创办的，称其成员为 961プロ 的二军三军（0031、0036）
- 和極月学園冲突的经过被传到网上（0130）
- 極月学園的偶像嘲讽初星「『一番星』も3組も出てこない」（0019）

## 不确定
- 本篇有两条分支（制作人选ことね或咲季），她的台词在两条线里多为重复，51 行包含两条线。
- 0064 她说会先要签名、请求握手再挑战，说明对 961 的顶尖偶像有崇拜，但对方是谁本篇没说（ことね说「あの人とか――／あの人とかっ！」）。
- 0060 原文是把拖ことね下水说成好意，带有故意装傻的意味，是否真心难判断；译文“不用谢啦”接得没错。
- 0080 译文“连『启明星』都拿不出来”漏了「3組」；0098 译文“『启明星』连三组都出不来”语序错误，原文是“『一番星』和 3 組都不出场”。
- 0042／0102 広的「すごい巻き込んでくる」两处译法不同（“真是厉害啊”“真是被卷进来了”），后者更贴近原文。
