# 月村手毬 亲爱度剧情 / 第15话（adv_dear_ttmr_015）

- 她的台词：32 行（含用匿名标签说的 0 行）
- 出场的人：手毬、燐羽、プロデューサー
- 场景：试镜『QUARTET』开始前，和燐羽对决的当天
- 世界线：亲爱度（月村手毬）（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
『QUARTET』试镜开始前，手毬主动向制作人讲『SyngUp!』解散时的事（0001–0005）。她说当时自己实力远不如两人，害两人不能全力、总在照顾她；她勉强自己想追上，被拦住，被教她唱歌和当偶像的人一直训斥（0006–0011）。她提出解散，说是自己单方面怒吼；美鈴劝阻，燐羽却赞成解散，决定开解散演唱会（0012–0016）。争吵被拍下，“因她解散”的消息在 SNS 上炎上，但燐羽在视频里对指责她的人反复发表过激言论，引发更大炎上，大部分恶评被燐羽「硬抢走」了（0017–0026）。燐羽出现，说别把她说成好人，自己本打算中等部就不当偶像，只是最后说了想说的话，结果收到恐吓信、解散演唱会取消，大家名声扫地，「せいせいした」（0027–0036）。她质问燐羽既然没干劲为什么不退出、为什么去961プロ、为什么内部升学，被燐羽冷对后反击说看了燐羽的演出“惨不忍睹”，说自己从憧憬的偶像那里学了唱歌，不会输给燐羽（0037–0046）。她要燐羽约定：今天她赢了的话，就好好“吵到最后”；燐羽答应，说要让她在众人面前哭出来（0048–0053）。

## 她的关键台词
- 0003「オーディションがはじまる前に……／聞いてくれますか？　私たちの話を。」——主动向制作人交代过去
- 0006「あの頃、私の実力は、／ふたりと比べて、ずっと劣っていた。」——承认当年的实力差距
- 0009「なんとか追いつこうと……／無理をして、止められて。」——当年的挣扎
- 0013「ふたりの足を引っ張るのは、／もう嫌だったから。」——提出解散的理由
- 0014「大喧嘩になって……いえ、私が／一方的に怒鳴っていただけですね。」——自我修正，承认自己的错
- 0026「月村手毬の悪評のほとんどを、／むりやり奪っていったんです。」——认为燐羽替她背了恶评
- 0037「じゃあ、なんでアイドルやめてないの。／なんで961プロに移籍したの。」——逼问燐羽
- 0040「は？　／いつまで上から物を言ってるわけ？」——不再处于下风
- 0041「ライブ観たよ――ひっどいザマ。／見る影もないね。」——对燐羽现状的尖锐评价
- 0045「ただの事実だよ。だって私は、／憧れのアイドルに歌を教わった。」——以燐羽教过她为傲，作为反击
- 0046「あなたごときに負けるわけない。」——把燐羽的话原样奉还
- 0049「ちゃんと、最後まで、喧嘩しよう。」——她想要的是和燐羽把话说清楚

## 行为模式
- 大事之前 → 主动把过去讲给制作人听，用敬语，郑重（0003、0005）
- 回顾自己的过错 → 讲到一半自我纠正，把责任揽回自己（0014）
- 对方用冷淡、居高临下的态度回避 → 不退让，用更尖锐的话反击，甚至把对方的措辞（「あなたごときに」）原样还回去（0039–0046）
- 想和在意的人和解 → 不说「和好」，而是用“好好吵到最后”的说法提出（0048、0049）
- 对憧憬的人 → 既猛烈批评对方现在的表现，又以“受教于她”为荣（0041、0045）

## 关系
- 燐羽：她称「燐羽」「あなた」；燐羽称她「手毬」「あなた」。当年教她唱歌和偶像、经常训斥她；解散时赞成解散，之后发表过激言论引火上身，替她分走了恶评；她认为燐羽是在保护她，燐羽本人否认。这一篇她第一次正面对燐羽说话，从质问、互讽到约定比试后好好吵到最后（0010、0011、0015、0021–0028、0037–0053）
- 美鈴：解散时劝阻过她（0015）
- プロデューサー：她称「プロデューサー」。比赛前郑重地向他讲出解散的全部经过（0002、0003）

## 档案类事实
- 『SyngUp!』被称为中等部第一组合（0004）
- 当年她实力远不如美鈴和燐羽，两人因她不能全力，一直照顾她（0006–0008）
- 解散是她提出的，起因是不想再拖两人后腿；美鈴劝阻，燐羽赞成（0012–0015）
- 关于解散的争吵被拍下，“因月村手毬解散”在 SNS 炎上；当时比现在更有名（0017–0019）
- 燐羽随后在视频中对指责她的人反复发表过激言论，引发更大炎上，舆论开始说解散原因可能不是她（0021–0025）
- 据燐羽说：燐羽收到恐吓信，解散演唱会取消，组合以最坏的形式结束，成员在校内外都被当作麻烦人物（0032–0034）
- 燐羽说自己本打算中等部就不当偶像（0030）
- 本篇试镜名为『QUARTET』，是她和燐羽的对决（0001、0002）
- 她看过燐羽现在的演出，评价「ひっどいザマ」（0041）

## 不确定
- 0010 燐羽「――余計なことしないでくれる？」是回忆中燐羽当年对她说的话（插在她的叙述里），不是当场对话。
- 0011 说教她唱歌和偶像的人「叱られてばかり」，从 0010 的插入看指燐羽；0045「憧れのアイドルに歌を教わった」也应指燐羽，但原文没点名。
- 0024–0026 译文错位：0025 的译文把 0026 的内容提前了（“她强行把大部分的负面评价都揽到了自己身上”），0026 又译一遍。
- 0043 燐羽「……手毬のくせに。」译成“手毬，你倒是变了”，意思不对，原文是“区区手毬还……”。
- 0049「ちゃんと、最後まで、喧嘩しよう」的具体含义（把解散时没吵完的架吵完）是推测。
- 燐羽为什么没退出、为什么去961プロ，本篇燐羽拒绝回答。
