# 月村手毬 亲爱度剧情 / 第16话（adv_dear_ttmr_016）

- 她的台词：37 行（含用匿名标签说的 0 行）
- 出场的人：手毬、燐羽
- 场景：试镜『QUARTET』结束后，她追上燐羽；周围渐渐有人围过来
- 世界线：亲爱度（月村手毬）（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
试镜后手毬叫住燐羽，燐羽说她已经能一个人不喘气地唱完，她说自己分开后每天都在练（0001–0005）。燐羽想以“好好当个好偶像吧”收尾，她不接受，说好赢了就要吵架，质问燐羽那糟糕的舞台是不是在小看她，并说现在的燐羽远不如初见那天（0009–0017）。燐羽说自己已经不是偶像了，梦想早已结束：完成了和她们的『約束』后本该引退，是十王社長挽留才内部升学；唯一遗憾是没能和粉丝好好告别，后来黒井说要帮她完成偶像的「终活」，她去極月学園除了支援，还想通过『N.I.A』把粉丝托付给某个人（0018–0036）。她说早猜到了，认为燐羽太小看粉丝，被燐羽反问“你自己不也在憧憬的偶像引退后转投相似的人”后，她大喊两份喜欢都是特别的、都是命运、心情不会消失，说着说着就哭着求燐羽别引退（0037–0055）。她哭喊要燐羽变回厉害的燐羽、一直在她前面帅气地跑、回到初星学園，并说自己一直尊敬燐羽，歌、舞、连「キャラ作り」都是学燐羽的——是「クールなキャラ作りのお手本」（0059–0070）。燐羽哭了，骂她「ばか手毬」「大っ嫌い」（0072–0074）。

## 行为模式
- 被对方体面地收尾、想就此结束 → 立刻反驳，不让对方逃（0009、0010）
- 对方表现不如她期待 → 怀疑对方在小看她，激动否定“那不是我认识的燐羽”（0011–0015）
- 看穿对方的打算 → 让对方坦白，“我都知道了”（0026、0037）
- 被戳到自己作为粉丝的经历 → 先骂「バカじゃないの」，再大声说出自己的价值观（0043–0048）
- 情绪说到极处 → 当众放声大哭、像小孩一样耍赖「ヤダ」，不顾周围的人（0050–0055）
- 哭着求人时会把真心话一股脑说出，包括平时不会说的事（自己的人设是模仿对方）（0062–0070）
- 对方哭了 → 察觉并直接问「泣いてるの？」（0072）

## 关系
- 燐羽：她称「燐羽」「あなた」，燐羽称她「手毬」「あなた」「ばか手毬」「おバカ」。燐羽一直是她的憧憬、榜样、目标；她的歌、舞和冷酷人设都以燐羽为模板；她要求燐羽回到初星学園、继续当偶像；燐羽说她“总是靠哭让我听话”，最后哭着说「大っ嫌い」（0007、0054、0057、0062–0074）

## 档案类事实
- 自从和燐羽分开后，她每天都在练习，现在已经能一个人不喘气地唱完（0004、0005）
- 燐羽说她以前唱歌「ヘタクソ」（0007）
- 燐羽说自己已经不是偶像，梦想早已结束；完成和她们的『約束』后打算引退，因十王社長挽留而内部升学成为特待生（0019–0023）
- 燐羽的遗憾是没能和粉丝好好告别；黒井提出帮她完成偶像的「终活」，她去極月学園一是支援，二是想通过『N.I.A』把粉丝托付给某个人（0024–0036）
- 据燐羽说，她在憧憬的偶像引退后，转而憧憬「似た人」燐羽（0041、0042）
- 她说燐羽一直是她的「憧れで、お手本で、目標」，她的歌、舞和角色塑造都受燐羽影响；冷酷的人设是以燐羽为榜样（0062–0064、0070）

## 不确定
- 剧本没直接说试镜结果，从 0010「私が勝ったら」的约定和燐羽的反应推断她赢了，但未明说。
- 0022 燐羽说的「あなたたちとの『約束』」具体内容本篇没说明。
- 0041 燐羽说她「憧れのアイドルが引退したら――／あっさり似た人に鞍替えした」，那位引退的偶像是谁本篇没点名。
- 0057 燐羽说「そうやって泣けば……／私が言うことを聞くと思って」，暗示她以前也常这样哭，但具体过去没交代。
- 0039 译文“故意让粉丝寄托希望”不准，原文「狙ってファンを託すなんて」是“有意地把粉丝托付给别人”。
- 0007 译文“手毬你倒是挺嚣张的嘛”大意可，原文「手毬のくせに生意気」带“区区手毬”的意味。
