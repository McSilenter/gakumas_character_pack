# 月村手毬 亲爱度剧情 / 第17话（adv_dear_ttmr_017）

- 她的台词：20 行（含用匿名标签说的 0 行）
- 出场的人：美鈴、燐羽、手毬
- 场景：第16话之后，她和燐羽一起去找美鈴确认当年的约定
- 世界线：亲爱度（月村手毬）（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
燐羽对她的请求暂时「保留」，要找美鈴确认一件事；手毬一见美鈴就说燐羽违背了「私たちの約束」，燐羽坚称没违背，说自己最讨厌毁约的人（0002–0008）。她坚持当年说过「一緒にトップアイドルになろう」，美鈴回忆她当时指着初星学園说“在那里成为第一的偶像”，燐羽据此说“中等部第一组合”的约定已履行（0013–0023）。她反驳说自己指的是高等部校舍，当时以为『一番星』就是顶级偶像，所以意思就是“三个人一起成为顶级偶像”；美鈴证实她确实指着高等部校舍，又说自己理解的是“三人参加『H.I.F』并夺冠”，而“一起成为顶级偶像”是她和美鈴两人的约定——三人理解各不相同（0024–0042）。她说现在是ソロアイドル，重组不可能，但如果燐羽继续当偶像就原谅对方；燐羽咂嘴叹气，她立刻当成同意说「大好き」，燐羽答应“再模仿一次我们憧憬的太阳”（0044–0057）。燐羽说要在『N.I.A』帮極月学園给『FINALE』留位置，她说「1枠は私がもらう」；美鈴说『FINALE』是她和美鈴的对决，她回「負けない」，美鈴说“终于看向我了”（0060–0074）。

## 行为模式
- 和燐羽起争执 → 拉美鈴当证人，坚持自己的记忆（0003、0013、0016）
- 被反驳时 → 用当年的具体细节（指的方向、当时的认知）逐点驳回，最后「オッケイ？」收尾（0026–0030）
- 想让对方留下 → 用居高临下的「許してあげてもいい」提出条件（0048）
- 对方咂嘴叹气 → 当作默许，立刻抢先道谢、说「大好き」，不给对方否认的机会（0049–0053）
- 被问到重组 → 不犹豫地拒绝，以ソロ偶像身份自居（0045）
- 被旧友宣战 → 简短回应「負けないから」（0070）

## 关系
- 燐羽：她称「燐羽」，燐羽称她「手毬」「うちのバカ」（推测）。两人斗嘴激烈，她指责燐羽毁约，用「原谅」作交换要燐羽继续当偶像；燐羽答应后她喊「大好き」，说燐羽「いつも」都是这样表示 OK 的（0003、0048–0057）
- 美鈴：她称「美鈴」，美鈴称她「まりちゃん」。美鈴是三人约定的证人；美鈴说“一起成为顶级偶像”是她们俩的约定，她不知道；美鈴说『FINALE』是两人的对决，她回「負けない」，美鈴说她“终于看向自己了”（0017–0020、0038–0040、0069–0071）

## 档案类事实
- 『SyngUp!』组成时的约定：她当年指着初星学園（她说是高等部校舍）说“一定要在那里成为第一的偶像”（0018、0019、0026）
- 当年她以为『一番星』就是顶级偶像（0027）
- 三人对约定的理解各不相同：燐羽认为是“中等部第一组合”，她认为是“三人一起成为顶级偶像”，美鈴认为是“三人参加『H.I.F』夺冠”，并认为“一起成为顶级偶像”是美鈴和她两人的约定（0022、0029、0037–0039）
- 她明确表示不会重组，现在是ソロアイドル（0045）
- 燐羽答应再当一次偶像，但要先履行和961プロ的契约（0055、0056、0059）
- 目前『N.I.A』排名第一是美鈴（0063）
- 她目标是拿下『FINALE』的一个名额（0062）

## 不确定
- 0019 是美鈴回忆中她当年说的话，用她的说话人标签呈现，不是当场台词。
- 0061 燐羽说的「うちのバカ」指谁不明，可能是極月学園的某人（如四音），不是她。
- 0056「私たちが憧れた……／太陽」具体指谁本篇没说；0067 美鈴说「わたしたちの太陽が戻ってきそう」，似乎指燐羽。
- 0041 燐羽「全員ばらばらじゃない」意思是“三人理解全不一样”，译文“大家不是都分开了吗”不对。
- 0065 美鈴「りんちゃんには」译成「对小毬」，对象译错了，原文是对燐羽。
- 0045 译文“独唱歌手”不贴切，原文是「ソロアイドル」。
- 0071–0074 美鈴「やっと……こっちを見てくれた」「二度と……よそ見ができないように」的含义（她以前没把美鈴当对手？）本篇没展开。
