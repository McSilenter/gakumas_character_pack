# 月村手毬 亲爱度剧情 / 第18话（adv_dear_ttmr_018）

- 她的台词：35 行（含用匿名标签说的 0 行）
- 出场的人：手毬、プロデューサー
- 场景：她回到制作人身边（「ただいま」），时间点在她和賀陽燐羽和好之后；后半是之后某天看排名的场面（地点不明）。
- 世界线：亲爱度（月村手毬）（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
她兴冲冲地回来，制作人却说已经在网上看到了她在大庭广众下对賀陽燐羽「全力の泣き落とし」的视频，她羞得要命，又担心损害自己的形象（0001～0011）。制作人说连 Plan B 都被她搞崩了，只能「流れで」随机应变，她吐槽这是走一步看一步（0012～0017）。她报告自己刚和美鈴约好在『FINALE』决胜负，问能不能进；制作人说第 2～4 名差距很小，竞争者是極月学園的白草四音和初星学園的倉本千奈，她承认倉本是正当实力的强敌（0024～0036）。之后排名上升，制作人说粉丝和自己一样「月村手毬から、目が離せない」，她确认能进『FINALE』（0038～0050）。最后她说出美鈴曾对她讲「ようやくこっちを見た」「二度とよそ見はさせない」，而她觉得这句话该由她来说，表示要超越对手、让美鈴承认自己才是她的对手（0051～0060）。

## 她的关键台词
- 0001「ただいま、プロデューサー！」——和好后心情明快，主动向制作人报到，称呼平口语气。
- 0010「（ぜんぶ見られてたなんてぇ～～～！　／は、恥ずかしすぎるぅ～～～～～！！）」——心声里极度羞耻，表面之外反应很夸张。
- 0011「はっ！　……もしかして、まずい？　／その……私のイメージ的に。」——羞耻之后马上想到偶像形象，有职业意识。
- 0013「プロデューサーのことだから……／……プランCもあるんだよね？」——对制作人的计划性有信赖。
- 0017「行き当たりばったりってことですか！？」——对制作人吐槽，吐槽型的敬语。
- 0032「売り出される側の難しさは、／よくわかっているつもりですから。」——不把对手的成功归为后台，以自身经验体谅被推销方的难处。
- 0036「他人のことはいいよ。／大事なのは、私が／『FINALE』に出られるかどうか。」——迅速把话题拉回自己的目标，自我中心而直接。
- 0049「……いいのか悪いのか、／よくわからないんですけど……」——被评价「目が離せない」时不知如何接受。
- 0053「二度とよそ見はさせないって。／――――――――――どっちが。」——对美鈴的话强烈反弹，觉得一直移开视线的是美鈴。
- 0055「誰より傲慢で、いつも上から見下ろ／して、悪気なんかちっともなくて。」——对美鈴的评价：傲慢、居高临下但没有恶意。
- 0056「4年目にして……／ようやく同じ高さで向き合えた。」——和美鈴的关系经历了四年才对等。
- 0060「私こそが、あなたのライバルだと！」——宣言自己才是美鈴的对手。

## 行为模式
- 自己的失态被人看到 → 先愣住、心里大喊羞耻，接着立刻担心形象问题（0006～0011）
- 制作人说出不靠谱的话 → 直接吐槽、催他「しっかりして」（0015、0017、0040、0043）
- 被问是否要指责对手靠后台 → 不说酸话，以自身经验认可对方实力（0032、0033）
- 话题偏到别人身上 → 拉回自己的目标（0036）
- 谈到美鈴 → 情绪激昂，用「どっちが」反驳对方的话，把最终目标定为和她对等对决（0051～0060）
- 说话方式在敬语（～ですか、～です）和平口（～だよね、～よ）之间频繁切换（0013、0015、0017、0036）

## 关系
- プロデューサー：她称「プロデューサー」，他称她「月村さん」。她信赖他的计划性，又毫不客气地吐槽他；制作人表示「目が離せない」（0013、0017、0043、0048）。
- 美鈴（文中称「美鈴」「あの子」）：约定在『FINALE』决胜负；她认为美鈴傲慢却无恶意，四年后才终于对等相向，要让美鈴承认自己是她的对手（0024、0051～0060）。
- 賀陽燐羽：本篇前她对燐羽「泣き落とし」并和好（制作人转述，0003、0008）。
- 倉本千奈：她称「倉本」，以前觉得是「落ちこぼれ」，现在认作强敌，认可其实力（0029、0030、0033）。
- 白草四音：只由制作人提到是竞争者（0028）。

## 档案类事实
- 她在大庭广众下对賀陽燐羽哭着恳求的样子被拍成视频在网上传播（0005、0008）。
- 她和美鈴约好在『FINALE』决胜负，排名上升后得以出场（0024、0050）。
- 和美鈴的关系到「4年目」（0056）。
- 『FINALE』的竞争者有極月学園的白草四音、初星学園的倉本千奈（0028）。

## 不确定
- 0053 的「どっちが」译文写成“这句话其实是我的台词”，是意译；字面是“到底是谁（在移开视线）”。
- 0059「ライバル」后文接「あなたの」（0060），对象应是美鈴，译文写成“让他们认可我”是复数，不准。
- 0060 的「あなた」是在对制作人说话时指美鈴，还是想象中对美鈴喊话，剧本里不完全明确。
- 0037「『今日』の反響」中『今日』加书名号，可能指某个节目／企划名，看不出来。
