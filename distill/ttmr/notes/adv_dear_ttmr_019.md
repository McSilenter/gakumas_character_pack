# 月村手毬 亲爱度剧情 / 第19话（adv_dear_ttmr_019）

- 她的台词：29 行（含用匿名标签说的 0 行）
- 出场的人：手毬、美鈴、プロデューサー
- 场景：她赢了美鈴之后（美鈴说「優勝、おめでとうございます」），先和制作人、后和美鈴见面；具体地点不明。
- 世界线：亲爱度（月村手毬）（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
她向制作人报告赢了美鈴，宣称嘲笑她醜態的人该明白她是成为顶级偶像的料（0001～0003）。制作人沉默不语，她担心他生气了；他说舞台上的她是最棒的偶像，又感叹舞台外的她为何「ああなってしまう」，她反驳「あなたがプロデュースした／アイドルですよ」，并说自己会改、在反省（0004～0017）。接着美鈴来了，美鈴认输并祝贺她优胜，夸她的歌（0018～0028）。她让美鈴别再慢慢走、跑起来追她，美鈴却说要「歩いて、追いつきます」（0029～0039）。她骂美鈴傲慢，约定下次在『H.I.F』打败她、成为『一番星』让美鈴承认自己是对手；美鈴反过来宣布下次自己才是挑战者，她嘴硬地接下挑战，说很期待（0040～0054）。

## 她的关键台词
- 0001「どう、プロデューサー！　／美鈴に勝ってきましたよ！」——胜利后第一时间向制作人邀功。
- 0003「月村手毬が、いずれトップアイドルに／なる器だと！」——用全名自称，自信满满地宣告。
- 0006「も、もしかして……怒ってる？」——制作人一沉默就不安，在意他的情绪。
- 0011「あなたがプロデュースした、／アイドルですから。」——把自己的出色归于他的制作，表达信赖。
- 0014「あなたがプロデュースした／アイドルですよ！」——同一句话反过来用，把舞台外的毛病也推给制作人，半开玩笑地撒娇。
- 0016「な、直そうとは思ってますから！　／すごく……反省してるし！」——被说到舞台外的问题时慌忙表态。
- 0024「わかってくれた？　いまの私が、／去年までの私じゃないって。」——要美鈴承认自己的成长。
- 0029「この期に及んで……／上から物を言うんだから。」——被美鈴夸「よく、頑張りましたね」反而不满其居高临下。
- 0032「なら、いい加減に歩くのをやめて……／走って追いかけてきなよ、美鈴。」——希望美鈴认真起来追自己。
- 0041「とことん傲慢だよね。」——对美鈴的一贯评价。
- 0043「『一番星』になった私を見れば……／もう認めざるを得ないよね。」——下一个目标：在『H.I.F』成为『一番星』。
- 0052「あ、あっそ！　ふぅ～ん！　／そうなんだっ……！」——被美鈴反将一军时嘴硬，掩饰动摇和高兴。
- 0054「楽しみに……楽しみにしてるからっ！」——最终坦率接下挑战，期待对决。

## 行为模式
- 赢了之后 → 立刻向制作人报告、大声宣告自己的价值（0001～0003）
- 制作人不说话 → 不安地问是不是生气了（0004～0006）
- 被夸「最高のアイドル」→「当然です」接下，再把功劳归给制作人（0010、0011）
- 被指出舞台外的毛病 → 先反推回制作人，再慌忙保证会改（0013、0014、0016）
- 被美鈴以长辈口吻夸奖 → 不领情，挑出她「上から」的态度（0029）
- 美鈴宣布自己才是挑战者／对手 → 先嘴硬「あっそ」「ふぅ～ん」，再接下挑战表示期待（0052～0054）
- 和美鈴说话用平口，和制作人说话敬语与平口混用（0022、0032、0006、0011）

## 关系
- プロデューサー：她称「プロデューサー」「あなた」；他在心里感到「感動と胃痛」同时袭来。她在意他的反应，把自己定位为「あなたがプロデュースした／アイドル」（0006、0011、0014、0015）。
- 美鈴：美鈴称她「まりちゃん」，她称「美鈴」，美鈴说她「困った子」。她赢了美鈴，但不满美鈴仍居高临下；两人互相宣称自己才是对方的对手，约定在『H.I.F』再战（0018、0029、0041～0054）。

## 档案类事实
- 她在美鈴之前取得优胜（美鈴「優勝、おめでとうございます」）（0022、0023）。
- 她之前的醜態被人嘲笑过（0002）。
- 下一个目标是『H.I.F』，要成为『一番星』（0042、0043）。
- 美鈴全名秦谷美鈴（0044、0050）。

## 不确定
- 0023「優勝」指的是哪个比赛（推测是上一篇提到的『FINALE』），剧本里没有直接说出名称。
- 0030「目は覚めた？」与美鈴 0037「たったいま起きました」是比喻（美鈴认真起来）还是兼指美鈴爱睡的实际，剧本里没说清。
