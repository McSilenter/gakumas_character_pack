# 月村手毬 亲爱度剧情 / 第21话（adv_dear_ttmr_021）

- 她的台词：17 行（含用匿名标签说的 0 行）
- 出场的人：美鈴、手毬、プロデューサー、旁白
- 场景：『Hatsuboshi IDOL FESTIVAL』（『H.I.F』）当天，正式演出前；她所在的房间（有人敲门、她说「どうぞ」），美鈴即将出场。
- 世界线：亲爱度（月村手毬）（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
『H.I.F』当天，她向制作人宣告要在『H.I.F』夺冠成为『一番星』，赢过十王星南和秦谷美鈴，并说状态比『N.I.A』夺冠那天更好（0001～0007）。制作人照常挖苦她「常にそうあって欲しい」，她回嘴说他临上场还这么讨人嫌，反而放松了（0008～0010）。美鈴来访，两人重提『N.I.A』时互相宣称要让对方承认自己是对手的约定（0011～0023）。美鈴说已经走着追上、甚至超过了她；她回「試してみれば？」（0024～0028）。美鈴提起她总说想成为「太陽のようなアイドル」，并说自己的梦想是在她仰望之处的更前方，成为遮盖一切星星的「夜空のようなアイドル」；她评价「美鈴らしい夢」（0029～0039）。美鈴说是她的歌唤醒了自己，作为回礼把今天的舞台献给她（0040～0044）。

## 她的关键台词
- 0003「今日、私は『H.I.F』で優勝し、／『一番星』になります。」——当天目标的宣言。
- 0004「十王星南にも、秦谷美鈴にも、／勝ってみせる。」——直呼对手全名，正面挑战。
- 0006「万全です。『N.I.A』で優勝した／あの日と同じ……いいえ、それ以上に。」——临场状态自信。
- 0009「そういうプロデューサーは、／本番直前でもイヤミだね。」——被挖苦时立刻回嘴。
- 0010「いつも通りすぎて、／肩の力が抜けちゃうよ。」——制作人的一贯态度反让她放松，显出依赖。
- 0015「なにやってるの。／もうすぐあなたの出番でしょ。」——对美鈴说话直率，带点关心。
- 0018「忘れるわけない。約束したよね。」——对和美鈴的约定很在意。
- 0026「追いつけたと思ってる？」——对美鈴的挑衅毫不退让。
- 0028「試してみれば？」——简短地接下挑战。
- 0032「あなたも同じところを目指していたと／思っていたんだけど。違うの？」——原以为美鈴和她目标相同。
- 0039「……美鈴らしい夢だね。」——听到美鈴的梦想后简短认可。

## 行为模式
- 大舞台当天 → 先向制作人宣言目标和对手，显出十足自信（0002～0007）
- 被制作人挖苦 → 立即回嘴，但承认这让自己放松（0009、0010）
- 美鈴挑衅说已经超过她 → 不动怒，用短句反问、接受挑战（0026、0028）
- 听对手说出梦想 → 不否定，简短认可（0039）

## 关系
- プロデューサー：她称「プロデューサー」，他称「月村さん」。他照常挖苦她，她回嘴；他的「いつも通り」让她放松（0005、0008～0010）。
- 美鈴：美鈴称她「まりちゃん」，她称「美鈴」「あなた」，宣言时用全名「秦谷美鈴」。两人重申在『N.I.A』时的对手约定；美鈴说是她的歌唤醒了自己，把今天的舞台献给她（0013～0044）。
- 十王星南：『H.I.F』的对手之一，她直呼全名（0004）。

## 档案类事实
- 她在『N.I.A』夺冠（0006）。
- 她要在『H.I.F』夺冠成为『一番星』（0003）。
- 据美鈴说，她总说想成为「太陽のようなアイドル」（0030，美鈴的话）。
- 『N.I.A』是她和美鈴第一次正面对决，她赢了（0022、0023）。

## 不确定
- 0034 美鈴「わたしは、あなたが見上げるその先に。／あなたが目指すその先に、いたいだけ。」意思是“只想待在你仰望、你目标的更前方”，译文改写成“我的梦想，比你仰望的地方更高”，不够准确。
- 0030「太陽のようなアイドルになりたい」是美鈴转述她说过的话，本篇她本人没有说。
- 0011 敲门、地点是否是控え室，剧本没明写。
