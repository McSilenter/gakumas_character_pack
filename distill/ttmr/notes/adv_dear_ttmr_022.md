# 月村手毬 亲爱度剧情 / 第22话（adv_dear_ttmr_022）

- 她的台词：33 行（含用匿名标签说的 0 行）
- 出场的人：手毬、プロデューサー、美鈴
- 场景：『H.I.F』当天，美鈴唱完之后、她出场之前；她和制作人在一起看完美鈴的舞台。
- 世界线：亲爱度（月村手毬）（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
美鈴唱完，会场先静默后爆发出雪崩般的欢呼；她说简直像『一番星』已经定了，嘴上说「やってくれるじゃん」（0001～0005）。她问制作人是不是怕了，制作人承认，并指出她的手在发抖（0006～0009）。她说第一次看到美鈴认真唱歌，又改口说那是美鈴自己的全力，走着也最快（0010～0016）。她坦白一直把美鈴当伙伴、青梅竹马、挚友，最近当成对手，刚刚却被硬变成了粉丝，自己的梦想也被「塗りつぶされ」，非常动摇（0017～0021）。制作人说这种情况下唱歌很难，又说她看起来很开心；她先否认，说这是怀念、是生气，然后回忆初中部刚入学时，同为初学者的人飞快进步、只有她被落下，那时她讨厌「ヘタクソ」的自己，只能拼命跑（0022～0034）。她爆发出对自己的怒气，承认美鈴是「本物のアイドル」，然后说要再来一次、多少次都行（0035～0040）。她提到那时讨厌自己，却有一个能喜欢自己的瞬间；制作人说她以前告诉过他，她让他忘掉、说是人生之耻，最后宣布现在就去，要拼命追上去（0041～0047）。

## 她的关键台词
- 0005「まったく……次は私の出番なのに。／……やってくれるじゃん、美鈴。」——对对手的出色表现半是抱怨半是认可。
- 0007「怖気づいたんですか？　／プロデューサー。」——自己动摇时先去挑制作人的话。
- 0016「そういう美鈴が、一番速いんです。／たとえ歩いていたって、関係ない。」——对美鈴实力的认识。
- 0017「はぁ……ずっと仲間で。／幼馴染みで、親友で。」——说出和美鈴的关系。
- 0019「たったいま、／むりやりファンにされちゃいました。」——承认被美鈴的舞台征服。
- 0021「動揺してます。すごく。いつも通りに／歌えるかどうかもあやしいです。」——坦白自己的动摇。
- 0028「はあ？　ばかじゃないの？／誰が楽しそうだって言うんですか……」——被说「楽しそう」时的激烈否认。
- 0033「才能の差を見せつけられて。／ヘタクソな自分が大っ嫌いで。」——初中部时的自卑。
- 0037「あァアァァ～～～～～～～～～～！／自分自身に腹が立つ～～～～～～！！」——情绪爆发，矛头指向自己。
- 0039「これが……私とは違う、／本物のアイドルなんだって……！」——承认美鈴和自己的差别。
- 0040「――いいよ。もう一度、／何度だってやってやる。」——从挫败中立刻重新站起。
- 0044「忘れてください。教えたの……／後悔してます。人生の恥です。」——对自己吐露过的私事感到难为情。
- 0047「無理をして、背伸びをして……／みっともなく追いすがってやる！」——不顾体面也要追上去的决心。

## 行为模式
- 对手表现压倒性 → 先嘴上逞强，再承认动摇，最后转为斗志（0005、0021、0040、0047）
- 自己害怕时 → 先问别人「怕了吗」，被指出手抖后才坦白（0007～0010、0021）
- 制作人说消极话 → 抱怨「プロデューサーとして、／どうかと思います」（0024、0025）
- 被说看起来开心 → 「ばかじゃないの？」否认，换说法说是怀念、是生气（0028～0030）
- 被追赶、被超越 → 想起过去被落下的经历，生的是自己的气，而不是对手的气（0031～0037）
- 被提起自己吐露过的私事 → 说「忘れてください」「人生の恥」，难为情（0044）

## 关系
- 美鈴：她称「美鈴」「あいつ」。一直是伙伴、青梅竹马、挚友，最近当作对手；看完美鈴的舞台后说自己被硬变成粉丝，承认美鈴是「本物のアイドル」，但决定再次追赶（0015～0020、0039、0047）。
- プロデューサー：她称「プロデューサー」，他称「月村さん」。她在他面前坦白动摇；他察觉她的手抖、看出她其实「楽しそう」；她以前向他说过自己“能喜欢自己的瞬间”，现在后悔说了（0009、0027、0041～0045）。

## 档案类事实
- 她和美鈴是青梅竹马、挚友，一直是伙伴（0017）。
- 初中部刚入学时，同为初学者的人很快进步，只有她被落下；她那时讨厌「ヘタクソ」的自己（0031～0033）。
- 那时她讨厌自己，但有一个能喜欢自己的瞬间，以前告诉过制作人（0041～0043）。
- 她说本篇是第一次见到美鈴认真唱（随即改口为「あいつなりの全力」）（0010、0015）。

## 不确定
- 0042 她所说「自分を好きになれる瞬間」具体是什么，本篇没说。
- 0012、0013 标签是『美鈴』，是她回想起美鈴之前说过的话（与第19话美鈴的台词相同），不是美鈴当场说的。
- 0047「背伸びをして」译成“拼上性命”不准，原意是逞强、勉强够高。
- 0018「いまはライバルのつもり……／だったんですけど。」译成“最近也才打算”，意思偏了，原意是“现在本来是当作对手的……”。
- 0032「初心者同士」是指她和美鈴，还是包括燐羽等其他人，剧本没写明。
