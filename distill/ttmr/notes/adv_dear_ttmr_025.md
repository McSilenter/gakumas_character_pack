# 月村手毬 亲爱度剧情 / 第25话（adv_dear_ttmr_025）

- 她的台词：39 行（含用匿名标签说的 0 行）
- 出场的人：手毬、プロデューサー、燐羽
- 场景：前半是極月学園的迷你演唱会之后（她刚输给燐羽），和燐羽两人谈话；后半回到制作人那里报告。
- 世界线：亲爱度（月村手毬）（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
她称赞燐羽找回了偶像的状态，燐羽回嘴说她刚才输了还哭鼻子；她装傻，但承认输了、被燐羽报了『N.I.A』的仇，又说燐羽回来当偶像让她很高兴（0001～0010）。燐羽说已按她的要求找回实力，不打算再练；她坚持燐羽「ぐれる」之前更厉害，还有上升空间，并试图提起「継さん」，被燐羽警告慎重措辞（0011～0024）。她改为确认：现在的燐羽是前『一番星』賀陽継的完全复制，且不打算再往上；燐羽说这是当年的约定——模仿两人憧憬的「太陽」、跑在她前面当她的目标（0025～0030）。她于是提出：赢了现在的燐羽，就算赢了継；燐羽答应若她赢了就承认月村手毬超越了賀陽継。她把超越自己的『はじまりのアイドル』賀陽継定为制作人要求的短期目标（0031～0041）。她向制作人事后报告，要借初星学園讲堂；制作人说已经通过秦谷さん安排好，还和美鈴一起去了961プロ，让她和美鈴参加961现役偶像的课程，她非常兴奋（0042～0061）。得知制作人以输了的话她和美鈴毕业后移籍961プロ为条件向黒井社长换来许可，她大骂他「ば～～～～～っかじゃないですか！？」；制作人说赢了就行，她认了，并宣誓要赢过自己憧憬的偶像（0062～0080）。

- 0065「ば～～～～～っかじゃないですか！？」——对制作人擅自定下移籍约定大怒。

- 0080「勝ってみせます！　／月村手毬の憧れのアイドルに！」——决心超越憧憬的偶像。

## 行为模式
- 输了被揭短 → 装傻带过，但会正式认输（0005、0006）
- 想让对方变强 → 不断坚持“还有更上面”，被拒后换个角度激将（0013～0017、0031～0035）
- 碰到对方禁区（継）被警告 → 立刻改换话题，换成确认事实（0021～0025）
- 被制作人夸「動作快」时 → 也会顺带吃醋式地问他和美鈴的距离（0049）
- 制作人擅自做重大决定 → 先大骂、抱怨事后报告，被他一句「勝てばいい」和信任说服（0065～0073）
- 收到新的特训机会 → 毫不掩饰地兴奋（0058、0061）
- 自己也会「事後報告」，被制作人说了照样继续（0042、0043）

## 关系
- 燐羽：她称「燐羽」，燐羽称「あなた」。她坦率说高兴燐羽回来当偶像，坚持燐羽还能更强；燐羽对継的话题设防，答应若她赢就承认她超越了賀陽継（0009、0017、0022～0024、0037）。燐羽说两人曾约定由燐羽模仿两人憧憬的「太陽」、当她的目标（0029、0030）。
- 賀陽継：她称「継さん」，是前『一番星』，她的「はじまりのアイドル」，也是「憧れのアイドル」（0021、0026、0040、0080）。
- プロデューサー：她称「プロデューサー」，他称「月村さん」。他已提前通过美鈴安排一切，为她争取961的特训，但擅自以她的移籍为赌注；她大骂后接受，因为他相信她能赢（0047～0073）。
- 美鈴（不在场）：她在意制作人和美鈴「距離近く」；美鈴也一起参加961的课程（0049、0057）。
- 黒井社長：961プロ的社长，她称「あの黒井社長」（0062）。

## 档案类事实
- 她在極月学園的迷你演唱会上输给了燐羽，事后哭过（燐羽说）（0004、0006）。
- 她的「はじまりのアイドル」是前『一番星』賀陽継（0026、0040）。
- 燐羽现在的舞台是賀陽継的完全复制（她的说法，燐羽认可）（0026～0028）。
- 制作人要求她在下次选拔考试前自定短期目标并达成；她定的是超越賀陽継（0039～0041）。
- 她对初星学園、100プロ有感情（0068）。
- 制作人曾说她实力不稳定，过去的培养重视体力、减少发挥下限；这次在961特训要提高上限（0074～0078）。
- 若输给賀陽さんたち，她和美鈴毕业后移籍961プロ（制作人和黒井社長的约定）（0063、0064）。
