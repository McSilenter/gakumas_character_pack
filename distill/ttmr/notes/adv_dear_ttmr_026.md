# 月村手毬 亲爱度剧情 / 第26话（adv_dear_ttmr_026）

- 她的台词：33 行（含用匿名标签说的 0 行）
- 出场的人：手毬、プロデューサー、燐羽、黒井、撫子、四音、旁白
- 场景：初星学園的讲堂，和極月学園的三连战当天；最后一段（0071 以后）是特训期间的往事。
- 世界线：亲爱度（月村手毬）（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
她得知和極月学園的对决是三连战，冲制作人抱怨没听说；制作人说这是为了让总把体力用光的她强行学会高效分配体力，也是让她更进一步的课程（0001～0014）。她感叹他对自己的信任，表示要回应、让他看961特训的成果（0015～0017）。第一战对白草四音，她拿名字的事回嘴后拿下；第二战对藍井撫子，她自称撫子的「姉弟子」，说赢了就让对方叫自己「手毬お姉様」，又赢了（0018～0034）。场外黒井和制作人交锋，制作人说“累而痛苦”才是她的最佳状态（0034～0050）。第三战前燐羽问她累成这样行不行，她说这是最佳状态、要让燐羽看自己超越憧憬，并战胜了燐羽（0051～0055）。燐羽说「手毬のくせに」认可她；她说终于和「ぐれる前」的燐羽并肩，回忆两人第一次见面就在这个讲堂，和燐羽、美鈴一起第一次看偶像演出、憧憬『一番星』，说超越憧憬的感觉「さいっこう」，并感谢燐羽的锻炼（0056～0070）。回忆特训期间，她缠着燐羽用自己的声音一遍遍示范、要录音，最后要燐羽遵守约定再次超越她；燐羽答应再练到能赢她的程度，她说燐羽看起来不甘心（0071～0085）。

- 0080「早く、もう1回、追い抜いてよ。／――――約束したでしょ？」——希望燐羽继续当她的目标、继续前进。
- 0084「悔しそうじゃん。」——反过来调侃燐羽。

## 行为模式
- 事先不知情的安排 → 先冲制作人发火、争辩，听到理由和他的信任后接受并发誓回应（0001～0017）
- 对手挑衅 → 用轻巧的毒舌回击（0019）
- 面对后辈型对手 → 摆前辈架子，开玩笑设赌注（0031、0032）
- 体力不支被质疑 → 坚称是最佳状态，反说对方「心配性」（0053）
- 赢了重要对手 → 回顾起点，坦率说出喜悦和感谢（0058～0068）
- 想要的东西 → 反复撒娇央求，「あと1回だけ」「お願ぁ～～～～～い♡」（0072～0075）
- 赢了对手后 → 不是满足，而是要对方再超越自己（0080）

## 关系
- プロデューサー：她喊他「プロデュ～～～サァ～～～！！」，他称「月村さん」「うちの月村さん」。他瞒着她安排三连战，她发火但最终感叹他「どれだけ／私を信じているんですか」，决心回应（0001～0017、0048）。
- 燐羽：她称「燐羽」「あなた」，燐羽称「手毬」。燐羽是对手、锻炼她的人、一起憧憬『一番星』的起点；她赢了燐羽后道谢，并要燐羽再次超越她；燐羽答应再练，她调侃燐羽不甘心（0051～0085）。
- 美鈴（不在场）：三人第一次一起看演出时她在美鈴身边；燐羽说美鈴在担心她（0063、0069）。
- 四音：『N.I.A』时的对手，她调侃对方把自己名字记错（0018、0019）。
- 撫子（藍井撫子）：她自称撫子的「姉弟子」，要对方叫「手毬お姉様」，撫子输后真这样叫了（0031～0033）。
- 黒井：制作人称「黒井理事長」，想把『SyngUp!』收入囊中；她和黒井本篇没有直接对话（0034～0036）。

## 档案类事实
- 她在初星学園讲堂的三连战中依次赢了白草四音、藍井撫子、賀陽燐羽（0021、0034、0055）。
- 制作人认为她无论积攒多少体力都会用光，「疲れていて苦しい」时是她的最佳状态（0005、0039）。
- 她和燐羽第一次见面就在这个讲堂，和燐羽、美鈴一起第一次看偶像演出，憧憬『一番星』（0061～0063）。
- 她喜欢听燐羽用她的声音唱歌，特训期间想录音留念（0073、0075）。
- 撫子说她和自己同受燐羽指导（她自称「姉弟子」）（0029、0031）。

## 不确定
- 0019 她说四音「名前、間違って／覚えて帰った」，具体是『N.I.A』时发生的事，本篇只能看出暗示。
- 0035 制作人称「黒井理事長」，上一篇她称“黒井社長”，两种称呼并存（剧本本身如此）。
- 0059「ぐれる前の燐羽」所指的时期本篇仍未说明。
- 译文：0005 制作人的话被扩写成“不把自己累瘫在台上就不算完”，0044 黒井「クックッ……言うではないか」译成“你这家伙……难道……”，都和原文不符（非她的台词）。
- 0036 黒井说「『SyngUp!』が／まとめて手に入る」，与上一篇“她和美鈴移籍961”的约定对应，但燐羽是否也在内看不出。
