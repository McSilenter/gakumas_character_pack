# 月村手毬 亲爱度剧情 / 第28话（adv_dear_ttmr_028）

- 她的台词：37 行（含用匿名标签说的 0 行）
- 出场的人：手毬、プロデューサー
- 场景：为冬季『H.I.F』开会的那天，她和制作人两人；地点没写明。
- 世界线：亲爱度（月村手毬）（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
她冲进来喊制作人，催他马上开冬季『H.I.F』的会，说现在的兴奋不亚于刚当偶像时，因为和美鈴约好要全力唱完、把『H.I.F』变成两人的大会、让『一番星』和顶级偶像都当配角（0001～0012）。制作人说这不就和平常一样，又说认识她不到一年但很确定她从抱有梦想起就一直油门踩到底；她抗议他说话带刺，然后承认「それが私です！」（0013～0021）。她复盘：『N.I.A』夺冠后在夏季『H.I.F』败退，十王星南会长三连霸拿下『一番星』并成了顶级偶像；制作人说冬季『H.I.F』规则改为不分个人与组合、优胜者即『一番星』（0024～0036）。两人互相说「合得来」「似た者同士」，她说可以毫无顾忌地给他添麻烦所以轻松（0039～0045）。她继续复盘三人特训、961的课程、赢了回归偶像的燐羽、超越了自己的「はじまりのアイドル」（0046～0052）。方针是在『選抜試験』压倒性取胜、拿到冬季『H.I.F』的参赛权，并把初星学園的黄金世代当成成长养分；她宣布复仇计划进入高潮（0054～0061）。

- 0007「同じくらい気持ちが／昂っているかもしれません。」——兴奋程度不亚于刚当偶像时。
- 0012「『一番星』だろうがトップアイドル／だろうが、脇役にしてやるって。」——和美鈴的约定，傲慢的宣言。
- 0019「言い方にトゲがある～～～～～～～！」——被挖苦时的抗议。
- 0021「それが私です！」——承认并肯定自己一直全速前进的性格。
- 0031「もう……また言ってる。」——对制作人的「うちの月村さん」式夸奖略带害羞的无奈。
- 0036「優勝すれば『一番星』で、／トップアイドル。シンプルでいいね。」——喜欢简单明了的目标。
- 0039「プロデューサーのそういうところ、／嫌いじゃないです。」——用否定式表达好感。
- 0040「気が合うなって、／最初から思っていました。」——自认和制作人从一开始就合得来。
- 0044「無用な気遣いをせずに／迷惑をかけられるので気が楽です。」——用他的话反击，表现亲近的依赖。
- 0052「月村手毬の『はじまりのアイドル』を、／超えることができたんです！」——复盘时最自豪的成果。
- 0061「ここからがクライマックスです！」——高昂的斗志。

## 行为模式
- 有了明确目标 → 主动冲去找制作人、催促开始（0001～0004）
- 被说“和平常一样”“油门踩到底”→ 先抗议说话带刺，再大方承认这就是自己（0015、0019～0021）
- 被制作人挖苦 → 用同样的句式反击回去（0042～0044）
- 表达好感 → 用「嫌いじゃない」等迂回说法（0039）
- 回顾经历 → 用第三人称「月村手毬は」复盘，条理清楚（0025、0052）
- 更难的考试 → 视为「いいレッスン」（0057、0058）

## 关系
- プロデューサー：她称「プロデューサー」，他称「月村さん」「うちの月村さん」「あなた」。他说认识她不到一年；两人互称“气味相投”「似た者同士」，她说「嫌いじゃない」，并说可以不顾忌地给他添麻烦（0016、0029、0039～0045）。
- 美鈴（不在场）：和美鈴约定全力唱完、把『H.I.F』变成两人的大会（0009～0012）。
- 十王星南：她称「十王星南会長」，是夏季『H.I.F』三连霸的『一番星』、顶级偶像（0026～0028）。
- 燐羽（不在场）：三人特训、她赢了回归偶像的燐羽（0049、0051）。

## 档案类事实
- 制作人和她相识还不到一年（0016）。
- 她在『N.I.A』夺冠，在夏季『H.I.F』本战败退（0025）。
- 十王星南在『H.I.F』三连霸，之后被称为顶级偶像（0027、0028）。
- 冬季『H.I.F』取消个人与组合的分组，优胜者即『一番星』（0035）。
- 元『SyngUp!』三人特训，并在961プロ的设施和现役偶像一起上课（0047、0048）。
- 她赢了回归偶像的燐羽，超越了自己的「はじまりのアイドル」（0051、0052）。
- 下一步是在『選抜試験』中压倒性取胜，获得冬季『H.I.F』参赛资格（0054）。
