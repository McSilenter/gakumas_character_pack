# 月村手毬 亲爱度剧情 / 第31话（adv_dear_ttmr_031）

- 她的台词：27 行（含用匿名标签说的 0 行）
- 出场的人：咲季、手毬、プロデューサー
- 场景：下一次『選抜試験』前，咲季来找她宣战；之后她和制作人谈话（地点没写明）。
- 世界线：亲爱度（月村手毬）（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
咲季来宣战说下次『選抜試験』会和她对上，她却先追问咲季和燐羽是什么关系，看到咲季脸红就指出来（0001～0007）。咲季说『N.I.A』时和燐羽关系变好，燐羽开始叫她姐姐，并自认是「姉力」的结果；她说燐羽那个称呼绝不是这样，而是很特别的叫法，咲季表示不打算深究（0008～0017）。咲季说和燐羽特训让歌唱力大幅提升、很开心，她说懂，进步看得见很有干劲，只是不知为何大家都哭闹着逃跑（0018～0026）。她问咲季是否振作了，咲季说只是被新的顶级偶像、也是自己憧憬的「はじまりのアイドル」十王星南叫醒，宣言要以『一番星』为目标（0027～0037）。她笑出来，说明白了燐羽为何喜欢咲季——外表声音方向都不像，却同样能让她心里发热；她说更不能输了，向咲季宣战（0038～0048）。制作人在旁说「火がついた」；她看穿咲季来访是制作人安排的，制作人说他交涉让她在『選抜試験』碰上对她最有益的对手咲季；她说咲季从初次见面起就爱找人较劲，两人已经比过无数次，这会是一生难忘的大比赛（0049～0062）。

## 她的关键台词
- 0004「そんなことより咲季！　／燐羽とどういう関係なの！？」——比起宣战，更在意燐羽和咲季的关系。
- 0006「赤くなってる！！」——抓住对方的反应。
- 0014「すごく……特別な呼び方だと／思うんだけど。」——她认为燐羽的「お姉ちゃん」称呼有特别含义。
- 0023「わかる。自分の上達がわかりやすくて、／やる気出るよね。」——对严苛特训的享受。
- 0024「なぜかみんな、泣いたり怒ったりして、／逃げ出しちゃうんだけど。」——对别人受不了严苛训练毫无自觉。
- 0027「いまさら聞くのもなんだけどさ。／……立ち直ったんだ？」——对咲季的关心，用随口的语气。
- 0040「燐羽が咲季を気に入った理由、／わかった気がする。」——对咲季的认可。
- 0042「（こんなにも……／私の胸を熱くさせる）」——心声：咲季能点燃她。
- 0046「余計に負けられなくなったってこと。」——斗志升级。
- 0048「成長したのはあなただけじゃないって、／教えてあげるよ！」——向咲季宣战。
- 0050「……目論見通りですか？」——看穿制作人的安排。
- 0056「プロデューサーって……／本当、想像を超えてきますよね。」——对制作人手腕的惊叹。
- 0060「すぐ突っかかってくるやつなんです。／はじめて会った頃からそうでした。」——对咲季的认识。
- 0062「一生忘れられないくらい、／大きな勝負になりそうです。」——对这场对决的重视。

## 行为模式
- 对方来宣战 → 先把自己在意的事（燐羽的关系）问个清楚（0004～0006）
- 涉及燐羽 → 维护燐羽「お姉ちゃん」称呼的特殊性（0013、0014）
- 谈到严苛训练 → 当作乐事，不理解别人为何受不了（0023、0024）
- 对手说出真诚的决心 → 笑出来，心里被点燃，斗志加倍（0038～0048）
- 制作人在背后安排 → 立刻看穿并追问，最后表示佩服（0050～0056）

## 关系
- 咲季：她称「咲季」「あなた」，咲季称「手毬」。从初次见面起就爱和她较劲，两人比过无数次；她关心咲季是否振作，被咲季的决心点燃，向其宣战（0027、0040～0048、0060～0062）。
- 燐羽（不在场）：她认为燐羽叫咲季「お姉ちゃん」很特别，并说明白了燐羽为何喜欢咲季（0013、0014、0040）。
- プロデューサー：她称「プロデューサー」。他交涉安排她在『選抜試験』碰上咲季；她看穿并感叹他「想像を超えて」（0049～0059）。
- 十王星南：咲季的「はじまりのアイドル」，被她说出名字（0031）。

## 档案类事实
- 下一次『選抜試験』她的对手是花海咲季（0002、0035、0057）。
- 她和咲季从初次见面起就屡次竞争（0060、0061）。
- 她认为严苛的特训能看到自己进步、很有干劲，但别人常常哭着逃走（0023、0024）。
- 这次的对阵是制作人和咲季直接交涉安排的（0054、0057）。
