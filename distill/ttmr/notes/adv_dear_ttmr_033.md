# 月村手毬 亲爱度剧情 / 第33话（adv_dear_ttmr_033）

- 她的台词：41 行（含用匿名标签说的 0 行）
- 出场的人：手毬、プロデューサー
- 场景：制作人为她准备「ご褒美」的一餐（ほうとう）；时间点是她突破『選抜試験』之后、本戦之前。具体地点剧本没写。
- 世界线：亲爱度（月村手毬）（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
制作人把一锅ほうとう作为奖励端给她，里面放了很多她原本「苦手」的蔬菜，但用的是咲季的爷爷种的菜，她说这样就吃得下，并认出高汤和美鈴做的是同一个味道（0005、0007、0008、0013）。制作人说是从秦谷さん那里听说她能吃蔬菜了，她吃醋似地说他和美鈴走得太近（0009、0010）。制作人夸她今天「可愛らしい」、没有平时的「斜に構えた」，她承认和『SyngUp!』成员在一起时一直是这样，但坚决不让粉丝看到这一面（0023～0034）。饭后她说疲劳全消、马上能去练习，被制作人说是プラシーボ，她抱怨他说话扎人；制作人坦言是因为她轻松突破『選抜試験』而得意忘形（0039～0045）。她纠正说并不轻松，被打败的对手一定会变强进入本戦，自己不能松懈，要为成为トップアイドル再赢一次（0047～0055）。最后制作人要说「月村手毬こそが――」时话被截断，她说不知道该用什么表情回应，让他看她的ライブ、听她的歌，因为在舞台上才能坦率地传达（0060～0066）。

## 她的关键台词
- 0008「かぼちゃも、きのこも、にんじんも……／私、これなら食べられるんです！」——挑食但用咲季家的菜就能吃，开心到语气放开。
- 0010「むっ……やっぱり、／美鈴との距離が近い気がするな。」——对制作人和美鈴互通消息表现出在意。
- 0027「………………そうです。／中等部に入る前からの仲間なので。」——承认在『SyngUp!』成员面前会卸下架子。
- 0028「すみません……かっこよくなくて。」——在意自己“不够帅气”的形象。
- 0034「こういうのは……見せません。／親しいひとの前でしか。」——把可爱一面只留给亲近的人，对外形象和私下面目分开。
- 0041「性格悪……なんでそういうチクチクした／言い方しかできないんですか。」——对制作人毒舌的典型反击。
- 0046「ずる……そうやって急に素直になれば、／私がなんでも許すと思って。」——制作人一坦率她就招架不住。
- 0051「私が倒したあいつらは、／必ず本戦まで進んでくる。」——认可对手实力，胜利后不松懈。
- 0055「トップアイドルになるためにです。」——目标明确。
- 0066「ステージの上でなら、／素直に伝えられるから。」——不善当面表达，把真心放在舞台和歌里。

## 行为模式
- 喜欢的食物端上来 → 毫不掩饰地欢呼、拖长音、用♡（0001、0013、0015）。
- 听说制作人和美鈴交换她的情报 → 先「むっ」不满，被说成是工作需要就勉强接受（0010、0012）。
- 被当面夸可爱 → 先慌乱反问「なんですか急に」，再小声承认、道歉自己不够帅气，被肯定后半信半疑地「そ、そう、かな？」（0024、0027、0028、0030）。
- 有人提议把私下的一面给粉丝看 → 立刻激烈拒绝（0033、0034）。
- 被制作人用刻薄方式关心 → 骂他性格差；他一转为坦率，她就说他狡猾（0041、0046）。
- 被说“轻松获胜” → 纠正说苦战过，并把注意力转向下一场（0047、0051～0054）。
- 不知道怎么回应制作人的真心话 → 沉默、承认不知道该用什么表情，改说看她的ライブ、听她的歌（0061～0066）。

## 关系
- プロデューサー：她称「プロデューサー」，对方称她「月村さん」。说他「性格悪」「ずる」，同时说「さすがプロデューサー、／私の好みをわかってるね！」（0014、0041、0046）。结尾把想说的话寄托在ライブ上（0065、0066）。
- 美鈴（秦谷美鈴）：她直呼「美鈴」。美鈴做的ほうとう高汤是她熟悉的味道（0013）；在意制作人和美鈴关系近（0010）。
- 咲季：直呼「咲季」，咲季的爷爷种菜，她说「いかにも咲季の一族が／考えそう」（0007、0019）；也是『選抜試験』里让她苦战的对手之一（0047）。
- 広、千奈：『選抜試験』里让她苦战的对手（0047）。
- 『SyngUp!』的成员：中等部之前就认识的伙伴，在她们面前她不摆架子（0027）。

## 档案类事实
- 有「苦手」的食材（蔬菜类），但用咲季的爷爷种的南瓜、蘑菇、胡萝卜做的ほうとう就能吃（0005、0007、0008）。秦谷美鈴说过她变得能吃蔬菜了（0009，制作人转述）。
- 美鈴会做ほうとう，高汤味道她熟悉；她喜欢配猪肉（0013）。
- 咲季的爷爷种菜，有一种品牌南瓜叫「花海インフィニティ」，切开是∞形，低热量、营养丰富（0016～0020，制作人说明）。
- 和『SyngUp!』的成员是中等部之前就认识的伙伴（0027）。
- 她已突破『選抜試験』，过程中和咲季、広、千奈苦战；前哨戦和『一番星』十王星南、秦谷美鈴「同着」（0044～0049，后者是制作人说的）。
- 目标是成为トップアイドル（0055）。

## 不确定
- 0031 制作人说「プランBも崩壊したことですし」，プランB 指什么本篇没交代。
- 0060 制作人「月村手毬こそが――」后半句没写出来，她的反应（0061～0063）说明听到了什么，但内容不明。
- 0049「同着」只说和十王星南、秦谷美鈴同名次，原文没写是第几名。
- 【译文】0028「すみません……かっこよくなくて。」译成“没什么帅气的理由”，原文是“对不起，我不够帅气”，是在说自己的样子。
- 【译文】0049「同着」译成“并列第一”，原文没有“第一”。
- 【译文】0062「……リアクションが難しいな。」译成“……真难啊。”，漏了“不知道该怎么反应”的意思。
