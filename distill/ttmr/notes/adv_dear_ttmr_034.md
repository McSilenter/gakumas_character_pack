# 月村手毬 亲爱度剧情 / 第34话（adv_dear_ttmr_034）

- 她的台词：29 行（含用匿名标签说的 0 行）
- 出场的人：手毬、美鈴、プロデューサー
- 场景：决定トップアイドル的重要大会当天早上。前半是她和美鈴一起打扮、等制作人来接（应是两人的住处，剧本没明说）；后半是制作人来接她之后的对话。
- 世界线：亲爱度（月村手毬）（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
大会当天早上，她和美鈴互相确认打扮，两人接下来要争トップアイドル的位置，气氛却和平常一样（0002～0011）。美鈴回忆『SyngUp!』的初ライブ，说那天在她身边唱跳时就觉得月村手毬总有一天会成为トップアイドル；她说当时自己没什么出彩、在デビュー戦燃尽了，若当时听到只会当成恭维而生气，现在则相信了（0012～0025）。她说梦想只差一点，约美鈴这次把『一番星』变成配角，并说两人的目标是“比太阳更高的地方”（0026～0035）。制作人来接她，她自称是「あなたの理想のアイドル」；制作人说越来越懂秦谷さん的心情，她发现两人在互相交换她的趣事，抓狂（0036～0052）。这种松散的对话让她完全紧张不起来，制作人说成为トップアイドル的日子也许意外就是这样，她笑他已经一副赢定的样子，说会去实现“我们的梦想”（0053～0059）。

## 她的关键台词
- 0011「これから私と美鈴で、トップアイドルの／座を懸けて争うのにね。」——和美鈴既是伙伴也是对手。
- 0013「あんまり思い出したくないな、／私、いいところなかったし。」——对『SyngUp!』初ライブ的自评很低。
- 0014「……楽しかったけど。」——嘴上否定，补一句真心。
- 0021「……そのとき言ってあげてよ。／デビュー戦で燃え尽きてた月村手毬に。」——提到自己出道战时燃尽的过去。
- 0023「まぁね。お世辞だと思って、／怒ってたと思う。」——承认当年的自己听不进夸奖。
- 0026「もうちょっとで、あとほんのすこし／手を伸ばすだけで……夢が叶う。」——梦想近在眼前。
- 0027「美鈴。今度こそ、／『一番星』を脇役にしてやろう。」——对『一番星』的挑战姿态。
- 0035「太陽よりも、／ずっと高いところなんだから！」——她和美鈴共同的目标表述。
- 0039「あなたの理想のアイドル、ですから。」——对制作人的自我宣言。
- 0059「私たちの夢、／ちゃんと叶えてきますから。」——把梦想说成“我们的”。

## 行为模式
- 和美鈴在一起 → 语气随意，会开玩笑地问“比美鈴还可爱？”，互相夸对方状态好（0004、0007）。
- 被提起过去失败的ライブ → 先说不想回想、自己没出彩，再小声补“挺开心的”（0013、0014）。
- 美鈴说出早年的信任 → 抱怨“那时候就该说”，但最后老实承认现在相信（0021、0023、0025）。
- 美鈴说出对十王星南的老一套评价 → 吐槽「出た～、いつもの」，但当天表示赞同（0032、0033）。
- 制作人提到美鈴 → 又在意两人关系近；发现两人在交换她的事情 → 大声抗议（0044、0046、0049）。
- 大赛当天被逗得紧张不起来 → 嫌他「仕方のないひと」，同时用自信的话回应（0054、0057～0059）。

## 关系
- 美鈴：她直呼「美鈴」，美鈴叫她「まりちゃん」（0001）。两人一起准备出门，美鈴说出『SyngUp!』初ライブ时就认定她会成为トップアイドル（0018～0020）。她和美鈴约好让『一番星』当配角（0027）。
- 十王星南：在美鈴口中是美鈴「敬愛すべきプロデューサー」「畏敬すべきトップアイドル」、也是「わたしたちの引き立て役」；她说美鈴这话是「いつもの」（0029～0032）。
- プロデューサー：她称「プロデューサー」，对方称「月村さん」。她对他宣称自己是他理想的偶像（0039）；对他和美鈴交换情报不满（0044、0049）；最后说「私たちの夢」（0059）。

## 档案类事实
- 和美鈴组过『SyngUp!』，有过初ライブ；她自己说那次没什么出彩之处，但很开心（0012～0014）。
- 她称那是「デビュー戦」，当时「燃え尽きてた」（0021）。
- 她和美鈴目标是「太陽よりも、／ずっと高いところ」（0035）。
- 美鈴叫她「まりちゃん」（0001）。
- 当天是「アイドル人生を左右するほどの、／重要な大会」的当日（0052）。

## 不确定
- 0040 制作人心声「あれから……このフレーズを、／何度聞いただろう」指「あなたの理想のアイドル」这句，最初是在哪篇说的本篇没交代。
- 0034～0035 她说的「私たちが目指しているのは」的「私たち」是她和美鈴两人（上下文是对美鈴说的），不是她和制作人。
- 【译文】0058「そのまま油断していていいよ。」译成“你就这样歇着吧”，原文是“你就这样放松大意着也没关系”，承接上一句他“已经一副赢定了的样子”。
