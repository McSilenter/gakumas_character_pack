# 月村手毬 亲爱度剧情 / 第37话（adv_dear_ttmr_037）

- 她的台词：48 行（含用匿名标签说的 0 行）
- 出场的人：手毬、プロデューサー
- 场景：『H.I.F』优胜ライブ和『一番星』授与之后，她去“炫耀”完回到制作人身边；同一天（0025「今朝」）。
- 世界线：亲爱度（月村手毬）（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
她回来时发现制作人从优胜ライブ途中就哭个不停，准备的两条手帕根本不够，她笑他「情けない」，又说只准备两条是他的错（0001～0012）。两人回顾从相遇以来一直朝同一个目标奔跑，她正式感谢他支撑了“问题满身”的自己（0014～0021）。她说因为他在面前哭得一塌糊涂自己反而很冷静，把手帕借给他（0028～0037）。看着他最高兴的样子，她慢慢有了成为『一番星』、站上当年憧憬的舞台的实感；制作人说今天一定有人因憧憬她而有了新梦想（0040～0047）。她得意地说「トップアイドル・月村手毬」不赖，又问下一个目标，两人确认是“比这里更上面”，她立刻要开会（0050～0065）。制作人说送她上场时用错了词、要重说一次，改说「ミーティングの前に、／ラーメン食いに行きましょう」；她答应，说两人是「似た者同士」，最喜欢今天的自己和现在的他，并请他今后多关照（0067～0078）。

## 她的关键台词
- 0007「……情けないな。」——看到制作人大哭时的第一反应。
- 0011「月村手毬を相手にしているのに、／ふたつしか用意しないのが悪いよね。」——得意又调侃。
- 0020「あなたのプロデュースは、問題ばかりの／私を、しっかりと支えてくれました。」——承认自己问题多，感谢制作人。
- 0029「感情が追いついてない。」——夺冠当天的心境。
- 0034「はじめて見た……大人のひとが……／こんなに泣くところ。」——反过来照顾哭泣的制作人。
- 0043「歌ったんですね、私。／あの日、憧れたステージに立って。」——夺冠的实感，与童年憧憬相连。
- 0047「……あるのかな、そんなこと。」——对“自己成为别人的憧憬”还没有把握。
- 0050「トップアイドル・月村手毬。／我ながら悪くない響きだよね。」——马上又得意起来。
- 0056「これで終わりじゃないでしょう？　／ここからが始まりでしょう？」——不满足于目标达成。
- 0064「『H.I.F』が終わった／直後だからこそです。」——一刻不停的劲头。
- 0075「私は、今日の私が一番好き！　／いまのあなたが一番好き！」——最直白的心情表达。
- 0078「トップアイドル・月村手毬を／今後ともよろしくお願いします！」——结尾的宣言。

## 行为模式
- 看到制作人失态 → 先嘲一句，再反过来照顾他（借手帕、催他擦泪）（0007、0011、0035、0037）。
- 对方比自己更激动时 → 自己反而冷静下来（0033）。
- 被他的情绪感染 → 才逐步有实感，愿意说出感谢和喜欢（0040～0043、0075）。
- 达成目标后 → 立刻问下一个目标、要马上开会（0056～0058、0062、0064）。
- 被说「調子に乗る」 → 不否认，转而问他接下来怎么带自己（0050、0053）。

## 关系
- プロデューサー：她称「プロデューサー」「あなた」，对方称「月村さん」（0032）。回顾两人从相遇就朝同一目标奔跑，「嫌味ばっかり言われてきました」（0016、0018）；说「ふたりの目標」（0055）；提到他「いつか」说过两人是「似た者同士」（0073）；说「いまのあなたが一番好き」（0075）。
- 太陽の歌姫：制作人说「かつてあなたを導いた、／太陽の歌姫」（0044），她本人在本篇没有提这个称呼。

## 档案类事实
- 她成为『一番星』，制作人和她的「トップアイドル」目标达成（0015、0042、0054、0055）。
- 当天有优胜ライブ，她站上「あの日、憧れたステージ」（0005、0043）。
- 获得了『一番星の証』（0030）。
- 曾被「太陽の歌姫」引导（0044，制作人说）。
- 刚认识制作人时就对他说过某件事（0014，内容见“不确定”）。
- 下一个目标是「この場所よりもさらに上」（0059，制作人说，她同意）（0061）。

## 不确定
- 0013～0015：制作人「…………あぁ。」之后，她说「はい……言ったでしょう、／出会ったばかりの頃に。」，接着说「あなたの目標、達成できるよ」。她刚认识时说的是什么本篇没写，推测和“达成目标”有关，但不能确定。
- 0059 制作人「この場所よりもさらに上――」话没说完，下一个目标的具体说法本篇未出。
- 0067～0070：制作人说送她上场时「言葉選びを間違えました」，重说的是「ラーメン食いに行きましょう」。为什么这算“重说”本篇没解释（可能与上一篇她要求的呼び捨て或说话口吻有关，不确定）。
- 0073 她说制作人「いつか」说过两人是「似た者同士」，出处不在本篇。
- 0076「あなたにも、私にも。もっともっと／私を好きになってもらいたい。」句意略绕：希望你和我自己都更喜欢我。
- 【译文】0076 译成“希望我俩能越来越喜欢上我”，原文是希望“你”和“我自己”都更喜欢我，译文主语混乱。
