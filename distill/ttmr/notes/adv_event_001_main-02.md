# 活动 001 1年级1班的偶像们 / main-02 第2话（adv_event_001_main-02）

- 她的台词：21 行（含用匿名标签说的 0 行）
- 出场的人：手毬、清夏、リーリヤ、咲季、ことね
- 场景：1年1組教室，放学前后。清夏提议办班级联谊会，手毬、咲季、ことね都拒绝，清夏分别游说。
- 世界线：活动 001（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
清夏宣布放学后办联谊会，手毬、咲季、ことね都说不去。放学后清夏去找手毬，手毬说有这种闲工夫宁愿自主练习，并说不想被和咲季混为一谈。リーリヤ自己出面，说自己是班里实力最差的，怕拖后腿，所以会努力；又说以后班级对抗输了会离梦想更远，手毬说她心态不错，让她照做。リーリヤ话说到一半卡住，清夏用“アテレコ”（配音）替她说了一句“请不要拖后腿”，手毬愣住不动。手毬恢复后问清夏和リーリヤ的名字，说“我会配合联谊会”，理由是班级团结对她成为顶级偶像有利；最后却对リーリヤ说“我不喜欢你”。

## 她的关键台词
- 0003「は？　勝手に決めないで。／――私は行かない。」——对被擅自决定的活动立刻拒绝。
- 0021「そんな暇があるなら自主練したいから。」——不参加的理由：练习优先。
- 0023「一緒にされたくはないけど。／……まぁ、そう。」——不愿被和咲季相提并论，但承认理由相同。
- 0038「なら、アイドルやめれば？」——听到リーリヤ说自己最没实力时的反应：冷淡、直接。
- 0043「……いい心がけだね。そうすれば？」——对リーリヤ决心“努力、不拖后腿”的认可，仍带命令口吻。
- 0052「あぁ、まどろっこしいな。／早く言いなよ。」——嫌对方说话迂回，催促。
- 0062「――葛城と、紫雲……だっけ？　／名前。あなたたちの。」——此前没记住同学的名字。
- 0066「協力するよ、クラス懇親会。」——被说服后突然改口配合。
- 0068「一理あると思ったから。／私がトップアイドルになるためには、」——改口理由写明：为了自己成为顶级偶像。
- 0074「私、あなたのこと嫌いだから。」——配合归配合，仍直接对リーリヤ说不喜欢她。

## 行为模式
- 被要求参加与练习无关的集体活动 → 先拒绝，理由是自主练习（0003、0021）。
- 被指出与咲季相同 → 否认被并列，随后承认理由一样（0023）。
- 对方说话吞吞吐吐 → 不耐烦，催促（0034、0052）；对方表示怕拖后腿、想成为顶级偶像 → 给出冷淡的回应但接受其决心（0038、0043）。
- 被替代配音说出“别拖后腿”这句她常对别人说的话 → 僵住不动（0055）。
- 被说服后改口时给出合理化理由（对自己成为顶级偶像有利），并同时声明私人感情不变（0068、0074）。

## 关系
- リーリヤ：称“葛城”；对她说“那就这么做吧”，最后明说“我不喜欢你”（0043、0072、0074）。
- 清夏：称“紫雲”（0062）；此前不记得名字；清夏叫她“月村ちゃん”。
- 咲季：只在比较时提到（0023），不愿被并列。

## 档案类事实
- 放学后想自主练习（0021）。
- 目标是成为顶级偶像（0068）。

## 不确定
- 0054 说话人标签是「リーリヤ？」，内容“请不要拖后腿”是清夏在配音（见 0057、0059、0060），不是リーリヤ本人也不是手毬。
- 【译文】0059、0060 的译文似乎错位：0059 日文是“看你想委婉地说又很为难，所以我心领神会地配音了”之意，译文把后半句和 0060 的内容混在一起；0060 的“像得让人生气了吧”也与原文「以心伝心でアテレコしてみた。／似てたっしょ？」不符。
