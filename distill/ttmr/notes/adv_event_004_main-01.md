# 活动 004 学生会的偶像们 / main-01 夏夜FACE OFF 第1话（adv_event_004_main-01）

- 她的台词：6 行（含用匿名标签说的 0 行）
- 出场的人：清夏、咲季、ことね、リーリヤ、手毬
- 场景：1年1組教室；联谊会之后班里气氛仍然不好，清夏提议全班去夏祭。
- 世界线：活动 004（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
清夏说班里气氛依旧很糟，手毬对咲季说“说你呢”，咲季回击，两人又吵起来。清夏提议大家去祭典，咲季和手毬各自以练习为由拒绝（手毬强调与咲季理由不相干）。清夏让リーリヤ出面劝手毬，手毬不愿被轻易说服，说“你又想威胁我吗”。清夏另外劝ことね去说服咲季，咲季得知リーリヤ会去后答应参加。手毬随后叫了清夏一声，说“我也去”。

## 她的关键台词
- 0004「だってさ。／言われてるよ。」——被说班级气氛差时，转嫁给咲季，又引发争吵。
- 0009「私も。咲季とは別だけど。」——拒绝祭典的理由是练习，但强调和咲季的理由不是一回事。
- 0014「うっ……」——被清夏点到リーリヤ来劝时的动摇。
- 0016「ま、また脅す気？／簡単に従うと思わないで！」——对リーリヤ的邀请先摆出防备姿态。
- 0041「……清夏。」——叫名字，接着改口。
- 0042「私も行く。」——决定参加。

## 行为模式
- 被劝说参加练习以外的活动 → 先拒绝（0009）；被リーリヤ当面劝说 → 先动摇再逞强说“不会轻易屈服”（0014、0016），最后自己叫住清夏改口（0041–0042）。
- 与咲季被并提时 → 一边合拍地拒绝，一边强调“和咲季不同”（0009）。

## 关系
- 清夏：这里直接叫“清夏”（0041）；清夏叫她“手毬っち”。
- リーリヤ：说她“又”威胁自己（0016）；リーリヤ本人觉得是误会（0045）。
- 咲季：互相拌嘴（0004、0005）。
