# 活动 004 学生会的偶像们 / main-05 夏夜FACE OFF 第5话（adv_event_004_main-05）

- 她的台词：10 行（含用匿名标签说的 0 行）
- 出场的人：清夏、咲季、ことね、リーリヤ、手毬
- 场景：夏祭会场，游戏摊对决之后，到去河边放烟花。
- 世界线：活动 004（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
清夏和手毬这时才现身，ことね责怪她们一直在看。清夏说是和手毬一起观察了一下，手毬说是被拉着陪的，并说“那孩子胆子大”，被清夏说“你很了解リーリヤ”，手毬否认。众人谈胜负后的“愿望”：咲季让リーリヤ继续练习、明年认真比，リーリヤ希望成为朋友，被说“已经是朋友了”。ことね拿到烟花，提议去河边放，手毬说“我没参加，要回去了”，被リーリヤ邀请后答应，说“只是我自己想去”。

## 她的关键台词
- 0002「……お疲れ様。」——合流时的招呼，较生硬。
- 0009「つきあわされてた。／必要ないって言ったのに。」——否认自己主动观察。
- 0010「あの子、度胸あるし。」——评价リーリヤ，等于承认关注并认可她。
- 0012「……そんなのじゃない！」——被说“很了解リーリヤ”时激烈否认。
- 0048「……なんで？」——对ことね拿烟花的疑问。
- 0051「私、参加してないし。／もう帰るよ。」——以没参加为由拒绝，要回去。
- 0054「……わ、わかった。／でもすぐ帰るから。」——被リーリヤ叫到后让步，仍声明很快回去。
- 0056「違うからっ！／私が行きたいと思っただけ！」——被ことね说“听リーリヤ的话”，否认是听谁的。
- 0058「こいつ……っ！」——被ことね抓住话柄。

## 行为模式
- 被说关心别人/了解别人 → 立刻否认（0009、0012）。
- 先拒绝，然后被リーリヤ当面邀请就答应；被人点破“听她的话”就用“是我自己想去”遮掩（0051–0056）。
- 答应时也要先附加条件（“很快就回”）（0054）。

## 关系
- リーリヤ：被叫“月村さん”（0052）；手毬的反应是无声 + 让步（0053–0054）；给出评价“度胸あるし”（0010）。
- 清夏：被说“一起观察”，手毬说被迫陪着（0009）。
- ことね：被逗时用“こいつ”称呼（0058）。

## 不确定
- 【冲突】0036 清夏说“不是说过不做朋友吗～？”，0038 清夏接着说“说的是ことねっち”。而在 001 main-05 里，“我们成不了朋友”（0056）是手毬的台词（0055 ことね说到“梦想和目标都各不相同”）。本篇把这句话的说话人归给ことね；两边未调和。
- 【译文】0052 译文把リーリヤ对手毬的称呼译成“月村姐姐”，原文是「月村さん」。
- 0004–0009 手毬与清夏在旁边观察，与 004 main-04（0002–0006）对应。
