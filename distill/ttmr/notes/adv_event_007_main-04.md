# 活动 007 好姐妹？三人组的日常 / main-04 万圣节狂想曲 第4话（adv_event_007_main-04）

- 她的台词：22 行（含用匿名标签说的 0 行）
- 出场的人：千奈、手毬、広
- 场景：游乐园，万圣节活动；先在园内唱歌招揽，傍晚在演唱会舞台旁休息。
- 世界线：活动 007（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
手毬在园内唱万圣节歌，吸引了很多客人，千奈和広趁机要糖果。傍晚三人在舞台旁休息，手毬说“我只是唱歌，收集糖果的是你们”，又说了“谢谢”。手毬买了茶给千奈和広，请客。広睡着，手毬说30分钟后叫醒。手毬问千奈为什么想当偶像，千奈说因为看了偶像的演出。手毬被问同样的问题，先说“为什么要告诉你”，然后说“和你一样”，并说千奈也有胜过她的地方。这时突然停电。

## 她的关键台词
- 0012「私は歌ってただけで、／お菓子を集めたのはふたりだし。」——被夸时的反应，强调他人的功劳。
- 0013「……ありがと。」——小声道谢。
- 0016「……休憩？　／まだぜんぜん大丈夫だけど。」——不觉得自己需要休息。
- 0019「……そっか。それじゃ、／少しだけ休憩。」——听了広的状态后接受休息。
- 0023「ちょっと、食べ過ぎでしょ。／……太るよ。」——对広吃太多的提醒。
- 0026「ほら、お茶。買ってきたよ。／水分補給はこまめにしないと。」——为同伴买茶，提醒补水。
- 0028「奢りでいいよ。お茶くらい。」——拒收钱。
- 0032「……しょうがないな。／30分で起こすから。」——為睡着的広安排。
- 0036「……ねえ。あなたは、どうして、／アイドルになろうと思ったの？」——主动问千奈的动机。
- 0048「……なんであなたに教えなくちゃ／いけないの？」——被反问时先拒绝。
- 0052「あなたと、同じ。」——给出答案。
- 0053「素敵なアイドルのライブを観て、／憧れたから。」——说自己也是看了偶像的演出才憧憬。
- 0060「……あなたが勝ってるところだって、／たくさんあるよ。」——对千奈的肯定。

## 行为模式
- 被夸 → 把功劳让给别人，并小声说谢谢（0012、0013）。
- 同伴累了/需要休息 → 嘴上说自己没问题，但接受并照顾（买茶、定时叫醒）（0016–0032）。
- 想了解对方 → 先问对方，被反问时先拒绝，再说出自己的真实原因（0036、0048–0054）。
- 被对方说“遥远的人”→ 说对方也有胜过自己的地方（0060）。

## 关系
- 千奈：仍称“あなた”；但开始关心（茶、休息、问动机），并承认千奈有强项（0060）。
- 広：照顾她（0023、0032）。

## 档案类事实
- 成为偶像的契机：看了优秀偶像的演出而憧憬（0053–0054）。
- 本篇开头她在唱万圣节歌（0001、0005，英文歌词）。
