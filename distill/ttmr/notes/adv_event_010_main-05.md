# 活动 010 星南与燕的日常 / main-05 情人节协奏曲 第5话（adv_event_010_main-05）

- 她的台词：3 行（含用匿名标签说的 0 行）：0038、0040、0042
- 出场的人：星南、広、千奈、佑芽、莉波、美鈴、ことね、咲季、手毬、一同
- 场景：情人节节日（バレンタインフェス）当天，学园内；先是莉波、広、星南在场，后是千奈、佑芽互送巧克力；手毬与美鈴的对话夹在其中（场景转换未标明）。
- 世界线：活动 010；制作人在制作的偶像：看不出（剧本里制作人未出场）

## 发生了什么
节日当天，星南借出舞台空档，让広在唱歌的同时给朋友们送“友チョコ”惊喜。手毬只在中段出现：美鈴似乎拿着巧克力来找她，手毬以在控制卡路里为由拒绝，美鈴说已经做成低糖质，却因朋友来叫（広给千奈、佑芽发了“13点到舞台前”的消息，见 0036-0037）而匆匆告辞，手毬来不及说完，留下一句抱怨。之后広的秘密演唱会和友チョコ交换里没有手毬的台词。

## 她的关键台词
- 0038「……いらない。私、いまカロリー／控えてるの知ってるよね？」——拒绝美鈴递来的巧克力，理由是在控制卡路里，并默认对方应该知道。
- 0040「なに、どうしたの？」——美鈴说到一半“あら？”停下时，她直接追问。
- 0042「あ、ちょっと、このチョコ――／……もう。」——美鈴匆匆走掉，她想叫住对方，话没说完，最后无奈地“もう”。

## 行为模式
- 被递来甜食 → 先以“在控制卡路里”为由拒绝，而且说得像对方本该知道（0038）。
- 对方话说到一半出了状况 → 立刻追问（0040）。
- 对方不由分说离开、东西留在她手里 → 叫住不成，只发出无奈的“もう”，没有真的生气（0042）。

## 关系
- 美鈴：直接对话的对象。美鈴对她用敬体、语气柔和（0039、0041），她用平语、随意（0038、0040）。她知道美鈴会为她做低糖质的巧克力这一类事（0039）。

## 档案类事实
- 她现在在控制卡路里（0038）。
