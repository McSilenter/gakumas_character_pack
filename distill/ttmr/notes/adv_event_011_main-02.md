# 活动 011 琴音与麻央的日常 / main-02 交换祈愿 女儿节 第2话（adv_event_011_main-02）

- 她的台词：18 行（含用匿名标签说的 0 行）
- 出场的人：千奈、麻央、手毬、運営スタッフ
- 场景：女儿节活动的会场（布置准备中），之后是活动前一天的夜里，练习室外。
- 世界线：活动 011；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
三人到会场打合せ，手毬提醒兴奋的千奈“我们是来工作的”（麻央注意到她刚才眼睛也在发亮）。運営スタッフ请他们演一出约10分钟的ひな祭り戏剧，麻央接受。手毬和千奈都没演过戏，手毬提到麻央拍过カステラ的广告、曾是剧团的童星。角色分配下来，麻央要演お雛様，而他在剧团一直演男孩子角色；手毬提出换角色被麻央拒绝。到了前一天夜里，手毬出练习室后一脸不安，千奈追来问她，她说不擅长面对客人。千奈说想用自己的力量支持她，两人互相承诺在对方有困难时帮忙。

## 她的关键台词
- 0002「千奈、はしゃがない。／私たちは仕事で来てるんだから。」——开场就以“工作”的立场约束千奈，但麻央 0006 看到她自己刚才也眼睛发亮。
- 0020「なんで自慢げなの……？／まあ私も、あまり経験はないけど。」——千奈说完全没演过戏，她吐槽，并承认自己经验也少。
- 0024「有名ですから。／カステラのCM、出てましたよね。」——知道麻央的过去（童星、CM）。
- 0033「もしかして、配役のことを／気にしていますか？」——看出麻央在意角色分配。
- 0042「あの……配役、代わりましょうか？」——得知麻央要演女孩子角色、而他在剧团一直演男孩子角色后，主动提出换角色。
- 0047「ライブも演劇も、みっちり練習したし、／ちゃんと形になったと思うけど……」——明天正式演出前仍不安。
- 0052「こういうイベントのお客様対応とか、／あんまり得意じゃないから……」——说出不安的原因。
- 0054「そうなの？　意外だな。／千奈は、こういうの得意でしょ。」——对千奈也不自信感到意外。
- 0056「なんで自慢げなの？」——千奈说“老实说没有自信”时，再次对她的反应吐槽。
- 0060「……ありがとう、千奈。」——接受千奈的支持。
- 0064「ぜったい、私が助けるから。」——千奈说“我也一定会有困难”，话未说完，她抢先承诺。

## 行为模式
- 同伴情绪高涨 → 用“我们是来工作的”拉回来（0002）。
- 对方说了不合常理的“自夸”（没演过戏、没自信） → 吐槽“为什么得意”（0020、0056），并不是真的责备。
- 看到前辈的为难 → 主动提出替他分担（换角色）（0033、0042）。
- 自己不安时 → 一个人离开练习室，被追问后才说原因（0047、0052）。
- 被朋友支持后 → 先道谢，对方说到“轮到你帮我时”，她马上抢着说一定会帮（0060、0064）。

## 关系
- 千奈：叫“千奈”；千奈叫“月村さん”。互称朋友（千奈 0059）。她对千奈既吐槽又信赖，承诺一定在千奈有困难时帮忙（0064）。
- 麻央：称“有村先輩”，用敬体；知道麻央的CM经历（0021-0024）；在麻央要演女孩子角色时主动提出换角色（0042）。

## 档案类事实
- 她没有太多演戏经验（0020）。
- 她看过麻央出演的カステラ广告，知道麻央是童星（0024）。
- 她不擅长在这类活动里应对客人（0052）。
- 她为演剧和现场演唱都练习得很充分（0047）。

## 不确定
- 0009「私たちで……」是在運営スタッフ提出请求之后说的，提出的内容（请他们演戏）没有写在剧本里，从 0010 麻央“――演劇、ですか？”推断。
- 0021、0022 她问“有村先輩は――”又自己打断，是在说麻央的演戏经验，立刻意识到不必问。
