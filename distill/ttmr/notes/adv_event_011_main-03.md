# 活动 011 琴音与麻央的日常 / main-03 交换祈愿 女儿节 第3话（adv_event_011_main-03）

- 她的台词：16 行（含用匿名标签说的 0 行）
- 出场的人：千奈、手毬、麻央、客
- 场景：女儿节当天的活动会场，千奈做会场记者、麻央与她搭档报道，手毬被一位客人叫住。
- 世界线：活动 011；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
女儿节当天，千奈担任会场记者，几次说错话，麻央帮她接下采访。千奈发现手毬被一位客人搭话：客人说是她的粉丝，夸她帅气、歌好，之后沉默。手毬回应得很简短，心里却很高兴；客人以为打扰了而道歉。千奈提议一起拍照，手毬答应，客人高兴地离开。手毬事后担心自己态度冷淡，千奈安慰她。千奈羡慕手毬有粉丝主动搭话，手毬回了一句“我是有过”，最后问起麻央去哪了。

## 她的关键台词
- 0023「え……そう、なんだ。／ありがとう。」——被粉丝搭话时的外在反应，克制、简短。
- 0024「（わぁ～、嬉しい！／声かけてくれるなんて……！）」——内心独白，与外在反应形成反差。
- 0027「（カッコいい、だって～！／私、カッコいいんだ。わぁ～！）」——被夸“帅气”时内心的兴奋。
- 0031「……えっと、まだ何か？」——客人沉默后她按字面追问，没有察觉对方在紧张。
- 0037「あ……じゃあ、そうする？」——被千奈提议后，顺势答应合影。
- 0041「声、かけてくれて……嬉しかったのに。／冷たい対応だったかな？」——事后担心自己态度冷淡，说出本意是“很高兴”。
- 0044「そうだね。／私と、写真を撮っただけなのに……」——对客人幸福的表情感到不可思议。
- 0051「ふーん。／私はあるけど。」——千奈说从没被粉丝搭话，她略带得意地回应。
- 0053「そういえば、有村先輩は？」——对话结束后转而关心麻央的去向。

## 行为模式
- 被陌生人夸奖、搭话 → 外在只回“谢谢”“那就好”这类简短的话，内心却很高兴（0023-0027）。
- 对方沉默或欲言又止 → 直接问“还有什么事吗”，语气偏冷，造成对方误会（0031、0032）。
- 事后发现自己态度可能冷淡 → 向朋友求证、并说明自己其实是高兴的（0041）。
- 朋友羡慕自己 → 用一句“我有过”轻描淡写地回应（0051）。

## 关系
- 千奈：叫“千奈”，向她道谢（0039）。千奈解了围、帮她处理粉丝，两人相处自然。
- 麻央：称“有村先輩”，话题收尾时想起问他在哪（0053）。

## 档案类事实
- 她有粉丝，曾有人主动搭话（0022、0051）。
- 客人说前几天看过初星学園的演出，觉得她帅气、歌好（0025、0028，客的话）。
