# 活动 011 琴音与麻央的日常 / main-04 交换祈愿 女儿节 第4话（adv_event_011_main-04）

- 她的台词：30 行（含用匿名标签说的 0 行）；其中 0026、0028 是练习戏剧时的台词（演戏，非本人的话）
- 出场的人：手毬、麻央、千奈
- 场景：女儿节当天，演出之前的后台（麻央在检查剧本，之后手毬找他练习）。
- 世界线：活动 011；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
手毬找到正在检查剧本的麻央，说前辈其实想演お内裏様，麻央承认当初确实期待，但“回应要求是我们的工作”。手毬演お内裏様、麻央演お雛様。手毬请麻央指导演技，麻央教她台词表演和走路，夸她学得快、姿态好；手毬问自己是否也有当女优的才能。接着她说还是想看麻央演お内裏様，理由是麻央懂演戏也熟悉男性角色的演法。偷听的千奈提议“リバーシ”：上午、下午演出时对调角色。手毬已记下了お雛様的台词，说“我是女优”，并称赞千奈“靠得住”；千奈去和运营方交涉，手毬请麻央示范お内裏様的演法。

## 她的关键台词
- 0006「やっぱり……先輩が、お内裏様の役、／やりたかったですよね。」——一直在意麻央被分到お雛様这件事，直接问出口。
- 0012「有村先輩は、それでいいんですか？」——麻央说“大丈夫”之前，她追问是否真的没关系。
- 0019「私、歌は誰よりも上手いんですけど、／演技はあまり自信がなくて――」——先说自己歌比谁都好，再坦白演技没自信。
- 0020「なにかコツとかあれば、／演技指導、してもらえますか？」——主动向前辈请求指导。
- 0033「……すごい。私のと全然違う……！」——看到麻央示范走路后的直率感叹。
- 0039「それって、私に女優の／才能もあるってことですか？」——被夸后立刻追问“我也有当女优的才能吗”。
- 0042「女優業もこなすクール系のアイドル。／……うん、悪くないかも。」——自己设想的形象，觉得不错。
- 0046「……私、やっぱり、有村先輩の／お内裏役が見てみたい……です。」——转而表示想看麻央演お内裏様。
- 0050「有村先輩がお内裏様のほうが、／絶対、お客さんも楽しめると思うし。」——给出理由：观众会更高兴。
- 0065「まあ、何かあったら、／そっちもできるようにね。」——承认自己记住了お雛様的台词，以备万一。
- 0071「……できるよ。／私、女優だから。」——被问能否在下午前背熟お雛様台词时的自信回答。
- 0077「ふふ、頼りになるじゃん、／ぽんこつ。」——称赞千奈靠谱，用的是千奈自称过的“ぽんこつ”。
- 0080「……有村先輩、お内裏様のお手本、／見せてくれますか？」——请麻央示范お内裏様。

## 行为模式
- 觉得前辈被安排得委屈 → 先直接问“前辈其实想演吧”，被否认后再追问一次“这样真的好吗”（0006、0012）。
- 想提高自己不擅长的地方 → 先说长处（歌），再坦白弱点，然后请前辈指导（0019、0020）。
- 被夸有才能 → 马上追问“是不是说我也有当女优的才能”，并开始设想自己的形象（0039、0042）。
- 对前辈的好意不愿占便宜 → 更想让前辈演想演的角色，甚至事先背下对方的台词（0046、0065）。
- 朋友帮上忙 → 用玩笑的口吻夸赞（“头一回靠得住”那样的语气）（0077）。

## 关系
- 麻央：称“有村先輩”，用敬体；关心他的心情，同时依赖他的指导。麻央叫她“手毬”，夸她姿势好、学得快（0029、0037）。
- 千奈：叫“千奈”，用玩笑口气叫她“ぽんこつ”（0077），表示信赖。0055 她惊讶地问千奈从什么时候开始在场。

## 档案类事实
- 手毬被分到お内裏様，麻央是お雛様（0006、0015）。
- 她的台词全部记住了（0023），也背下了不少お雛様台词（0064、0065）。
- 她认为自己歌比谁都好（0019）。
- 她比麻央个子高（麻央 0043 的话）。

## 不确定
- 0026「ああっ！　なんということだ！／お雛様の首がああああっ――」、0028「お、お雛様の首がああああっ！／ぎゃああああああっ！」是练习剧中的台词，不是本人的话。
- 时间点：0063 麻央提到“当天可能发生什么”，0070 千奈又说“到午后之前”，看起来是演出当天、午前演出之前，但剧本未明说。
- 【译文】0006「お内裏様」在译文里是“亲爱的”，0058 的“皇帝陛下”也不准确；原文始终是お内裏様。
