# 活动 011 琴音与麻央的日常 / main-05 交换祈愿 女儿节 第5话（adv_event_011_main-05）

- 她的台词：19 行（含用匿名标签说的 0 行）
- 出场的人：千奈、麻央、手毬、運営スタッフ
- 场景：演出结束后的后台；演唱会开始前；演唱会结束后的庆功宴（打ち上げ）。
- 世界线：活动 011；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
上午、下午对调角色的演出获得好评，運営スタッフ夸赞两个角色都很完美。千奈担心自己拖了后腿，手毬说彼此彼此，也有失误，是麻央帮忙补救；麻央回应“演出是大家一起做的”，说想起了刚入剧团时的心情。演唱会开始前观众很多，手毬问麻央“想起刚入剧团的心情”是什么意思，麻央说是“让观众尽情享受”，是自己的原点，但现在想发光的地方在别处。手毬说“那就不能失败了”，并说依赖麻央。庆功宴上她想只吃沙拉，被千奈劝到“作弊日”，结果吃了很多。

## 她的关键台词
- 0002「当然です。」——被夸演出精彩，毫不谦虚地接受。
- 0013「別に、お互いさまでしょ。／私もいくつかミスはあったし……」——千奈自责时，她承认自己也有失误。
- 0014「有村先輩がフォローしてくれたから、／何とかなったけど。」——把功劳归于麻央。
- 0020「……でも、それは有村先輩の／おかげだと思うんですけど。」——麻央说“结果不由失误数量决定”之后，她仍坚持这是麻央的功劳。
- 0030「お客さんが何人だろうと、／後はもう、やるべきことをやるだけ。」——观众很多时的态度：只做该做的事。
- 0036「劇団に入った頃の気持ちを／思い出したって、言ってましたよね。」——记得麻央的话，向他追问。
- 0041「じゃあ、失敗はできませんね。」——听完麻央的“现在想发光的地方”，回应以“不能失败”。
- 0046「頼りに、してます。」——上场前对麻央说的话，简短而直接。
- 0055「アイドル、だからね。」——庆功宴上只吃沙拉的理由。
- 0059「じゃ、じゃあ……ちょっとだけ。」——被千奈劝说后松口，但随后一发不可收拾（0060、0061）。
- 0061「あの、これってもう1杯あります？」——吃过头的表现，被千奈指出“吃太多”。

## 行为模式
- 被称赞 → 直接接受（“当然”），同时又把功劳归给前辈（0002、0014、0020）。
- 面对大场面（很多观众） → 不去数人数，只强调做好该做的事（0030）。
- 上场前对信赖的前辈 → 简短地说“依赖你”（0046）。
- 面对美食 → 内心挣扎、嘴上用“因为是偶像”克制，被朋友以“作弊日”劝后迅速破功（0052-0061）。

## 关系
- 麻央：称有村先輩，用敬体，把成功归功于他，追问他的“原点”（0034-0041），上场前说依赖他（0046）。
- 千奈：叫“千奈”；千奈叫“月村さん”。被千奈劝吃东西，被指“吃太多”（0062）。

## 档案类事实
- 她在控制饮食，宴席上想只吃沙拉（0053、0055）；0052 她看到的菜有肉、寿司、拉面、炸猪排、汉堡肉。
- 演出中她有几处失误（0013）。
