# 活动 012 手毬与广的日常 / main-02 樱花飞舞的起跑线 第2话（adv_event_012_main-02）

- 她的台词：8 行（含用匿名标签说的 0 行）：0014、0034、0057、0059、0061、0063、0064、0066
- 出场的人：リーリヤ、咲季、清夏、手毬、ことね、ダンストレーナー、クラスメイトA
- 场景：以リーリヤ的回忆为主，“入学当初”的舞蹈课与考试，以及之后的放学后走廊；手毬的台词都在这段回忆里。
- 世界线：活动 012；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
本篇的主角是リーリヤ：她完成了练习，感谢咲季成为自己的师父，并回忆入学时的事。回忆里清夏舞蹈出色，手毬评价她作为没有经验的新生跳得还不错；舞蹈考试时手毬觉得考试太简单。清夏开始翘课后，リーリヤ很在意，手毬叫住她，说与其操心别人，不如先担心自己的实力，并说起中等部时也有人中途放弃，自己能做的只有继续跑下去。随后咲季让リーリヤ拜自己为师。

## 她的关键台词
- 0014「……ふん。まあ未経験の新入生にしては／良いセンいってるんじゃない？」——清夏跳得好时的评价，语气带不服，但承认。
- 0034「この試験、簡単すぎない？／新入生のレベルに合わせてるのかな……」——对考试难度的直率看法。
- 0057「葛城。」——叫住リーリヤ。
- 0059「紫雲のことが気になるのは分かるけど／……そんな余裕あるの？」——理解对方在意清夏，但质疑她有没有余力。
- 0061「他人の心配なんかよりも先に、／自分の実力を心配した方がいいよ。」——把重心放回自己的实力，口气严格。
- 0064「中等部の時だって、何人もいた。／途中で諦めちゃって、やる気を失う人。」——以中等部时的经历说明“有人会放弃”。
- 0066「私たちにできることなんて、ないよ。／……できるのは、走り続けることだけ。」——她的价值观：别人的事帮不上，只有继续跑。

## 行为模式
- 看到水平高的同学 → 嘴上带刺地承认其实力（0014）。
- 觉得考试太简单 → 直接说出来（0034）。
- 看到同学在意别人的事而分心 → 先承认对方的心情，再以“你有余裕吗”劝回自己（0059、0061）。
- 被问“那时你怎么做” → 说“我们能做的事没有”，只有继续跑（0064、0066）。

## 关系
- リーリヤ：称“葛城”；リーリヤ称“月村さん”。她的话对リーリヤ起到了推动作用（0067-0070，リーリヤ的内心）。
- 清夏：称“紫雲”（0059），没有直接对话。
- 咲季、ことね：同在考试场景（0033-0035），没有直接对话。

## 档案类事实
- 她在“入学当初”也参加了舞蹈考试，觉得考试太简单（0034）。
- 她提到“中等部的时候”见过不少中途放弃的人（0064）。
