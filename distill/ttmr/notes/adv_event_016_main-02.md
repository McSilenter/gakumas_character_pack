# 活动 016 / main-02 第2话（adv_event_016_main-02）

- 她的台词：10 行（含用匿名标签说的 0 行）：0001、0004、0010、0016、0017、0019、0028、0030、0031、0033
- 出场的人：咲季、ことね、手毬、ことねの妹
- 场景：体育中心（スポセン）入口及内部，咲季、ことね、手毬和ことね的妹妹第一次一起玩。
- 世界线：活动 016；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
到场后手毬先问咲季有没有见过ことね的妹妹；咲季调侃她面对小孩会紧张，她否认。妹妹礼貌地打招呼，手毬只回“请多关照”。进场后，她熟练地介绍各楼层设施，ことね问她以前是否来过，她含糊地承认。妹妹想玩击球机，ことね觉得对小孩太难，妹妹打算放弃，手毬主动提出教她。后半咲季教ことね打击，两人谈起咲季对佑芽加入学生会的寂寞，这一段手毬不在场对话中（她和妹妹在远处）。

## 她的关键台词
- 0001「……ねえ、咲季。／ことねの妹って、会ったことある？」——对即将见到的小孩有些在意，主动打听。
- 0004「そ、そんなわけないでしょ。」——被调侃对小孩紧张时的否认，口气急。
- 0010「……よろしく。」——对妹妹的礼貌问候，回得生硬简短。
- 0016「2階にはプールとコート、／バッティングセンターもあるよ。」——对设施很熟。
- 0017「3階はフードコートがあって、／おすすめは唐揚げとたこ焼きかな。」——连推荐的餐点都知道。
- 0019「……まあね。」——被问是否来过，含糊承认。
- 0028「……私が教えようか？」——妹妹放弃击球机时，她主动出手。
- 0030「バッティングマシンが、／やりたいんでしょ？」——看穿妹妹其实想玩。
- 0031「私、ちょうど打ちたかったから。／……一緒にやろう。」——用“我自己也想打”作为借口，减轻对方的负担。
- 0033「……べつに得意じゃないけど。／結構、好きなんだよ。」——被问是否擅长击球时的回答：不擅长但喜欢。

## 行为模式
- 被调侃对小孩紧张 → 急着否认（0003、0004）。
- 被问及自己的私下经历（来过体育中心） → 含糊承认，不展开（0019）。
- 看到小孩想做又不敢 → 主动提出教，并用“我自己也想打”当理由（0028-0031）。
- 被问是否擅长 → 回“不擅长，但挺喜欢”，不夸耀（0033）。

## 关系
- 咲季：直呼“咲季”，被咲季看穿对小孩的不自在（0003）。
- ことね：直呼“ことね”；ことね叫“手毬”，把妹妹交给她（0034）。
- ことねの妹：称呼对方时没有叫名字；妹妹叫她“手毬お姉ちゃん”（0008）。

## 档案类事实
- 她对体育中心的设施很熟，推荐过唐揚げ、たこ焼き（0016-0019）。
- 她对击球不算擅长但很喜欢（0033）。

## 不确定
- 0003 中咲季猜她“对小孩紧张”，0004 手毬否认；03 篇 0011 的内心独白说她确实不擅长与小孩相处，两者在同一条线上是先否认后承认，不记为矛盾。
