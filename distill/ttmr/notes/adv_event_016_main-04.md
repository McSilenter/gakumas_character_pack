# 活动 016 / main-04 第4话（adv_event_016_main-04）

- 她的台词：15 行（含用匿名标签说的 0 行）
- 出场的人：咲季、ことね、手毬、ことねの妹
- 场景：体育中心，午饭后；之后在足球场（フットサルコート）与咲季比赛。
- 世界线：活动 016；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
吃过沙拉乌冬后，咲季提议在足球场打比赛，并以一对三、赢了就请饮料为条件。ことね和手毬、妹妹商量战术。手毬认为咲季体力也有限，提出由她和ことね扰乱节奏消耗体力；比赛中被咲季连续进球，体力先耗尽。妹妹想出战术，手毬同意，并配合以大叫吸引注意，让妹妹带球突破，扳回一分。最终三人险胜，咲季请客；ことね发现咲季其实留了手，咲季说自己是全攻型，并说起想起了和佑芽小时候的事。

## 她的关键台词
- 0002「サラダうどん……気に入ったかも。／サラダなのに妙な満足感がある。」——午饭评价，她对低卡的东西也能有满足感。
- 0011「大きく出たね。咲季の運動神経が／図抜けてるのは知ってるけど――」——承认咲季的运动神经，仍觉得一对三太夸张。

- 0022「……ほっといて。」——被ことね说“没想到手毬会提团队合作”时的别扭回应。
- 0028「嘘、カットされた――！？」——对咲季的运动能力的惊讶。
- 0034「はぁ、はぁ……こっちのスタミナが、／先になくなりそうなんだけど……」——战术失败后率先说出疲惫。
- 0038「……よし。それでいこう。」——听过妹妹的战术后立刻拍板。
- 0041「うわ。完全に悪役の顔してる。」——对咲季的吐槽。
- 0048「うわあああああああああああっ！」——配合战术的大叫（咲季 0053 称之为“奇声”，用以吓她）。
- 0055「だったら、また別の作戦でいくよ。」——被说“奇袭不会奏效两次”后，立刻想下一个方案。
- 0059「……はぁ、はぁ……3対1で／ギリギリだったけど、ね……」——险胜后的感想。

## 行为模式
- 觉得对方过于自大 → 先用事实反驳（“我们也擅长运动”），再认真分析对手的弱点（0011、0012、0019）。
- 被指出“居然提团队合作” → 嘴上说“别管我”，但没有收回提议（0021、0022）。
- 战术失败体力耗尽 → 坦率说出（0034），听得进别人的方案并立刻采纳（0038）。
- 比赛过程中遇到变化 → 立刻切换另一套方案（0055）。
