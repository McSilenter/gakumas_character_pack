# 活动 023 / main-03 第3话（adv_event_023_main-03）

- 她的台词：12 行（含用匿名标签说的 0 行）：0002、0006、0011、0015、0019、0022、0037、0039、0041、0043、0044、0048
- 出场的人：広、美鈴、手毬
- 场景：学园内（次日，広去找美鈴搭话；之后回到手毬身边）
- 世界线：活动 023；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
広以"特工"身份去向美鈴打听想要的礼物，手毬在旁边担心地吐槽。美鈴看出広是替别人问，但没有点破；她说比起收礼更喜欢送礼，想让重要的人心里被自己填满。広回来汇报，手毬说算是有提示。手毬问広准备好礼物没有，広说和佑芽、千奈买了枕头，手毬觉得自己一辈子也定不下来。広悄悄说，手毬越烦恼礼物就越完美，手毬没听清。最后美鈴自语"不愧是篠澤さん"。

## 她的关键台词
- 0002「（本当に大丈夫かなぁ……）」——在心里担心広
- 0006「（……もっといい切り出し方が／あるんじゃない？）」——在心里吐槽広的切入方式
- 0011「（さすがに直球すぎない！？！？）」——对広直接问礼物的惊讶（心声）
- 0019「（………………ばれてる？）」——听到美鈴说"替困扰的人来问"，怀疑已暴露
- 0022「（もしかして……ばれてない？）」——美鈴"原来是误会"之后又改口猜
- 0037「まぁ、ヒントにはなったかな。」——对広的汇报给出客观评价
- 0039「そういえば、広も美鈴に／誕生日プレゼント渡すの？」——想起来问広
- 0043「……やっぱり、もう準備してるんだ。」——听说広已准备好，略受打击
- 0044「一生決まらない気がしてきた……！！」——对自己选不出礼物的夸张哀叹
- 0048「え？　何か言った？」——没听见広的最后一句

## 行为模式
- 旁观朋友做事时 → 用心声连续吐槽，不出声干预（0002、0006、0011）
- 担心被识破 → 在心里反复摇摆判断（0019、0022）
- 得知别人已准备好礼物 → 开始焦虑，夸张地说"一辈子定不下来"（0043、0044）
- 没听清对方的低声话 → 追问但不继续追（0048）

## 关系
- 広：叫「広」，广是“特工”担当；她依赖広去探美鈴口风（0001～0002、0037）
- 美鈴：「美鈴」；美鈴一眼就看出広不是替自己问的，但手毬没能确认（0014～0022）

- 広、佑芽、千奈三人合买了枕头作为给美鈴的生日礼物（0042，広所述）
