# 活动 026 / main-05 ライブツアーイベント特別編 GO MY WAY!! 第5话（adv_event_026_main-05）

- 她的台词：8 行（含用匿名标签说的 0 行）：0026、0028、0029、0032、0033、0035、0040、0052
- 出场的人：ことね、咲季、佑芽、手毬、一同
- 场景：『GO MY WAY!!』翻唱演出的后台。0001～0025 是上台前，0026 起（0028「観たよ、ライブ。」）是演出结束后；两段之间有时间跳跃
- 世界线：活动 026；制作人在制作的偶像：看不出（制作人未出场）

## 发生了什么
上台前（0001～0025）三人在后台说笑、整理情绪、喊口号出发（手毬不在）。演出结束后手毬进来，说自己看了Live、"不赖"。咲季说像是与会场融为一体，手毬同意"大家真的很享受"，然后看到ことね累瘫，问怎么了、说"丢人"。佑芽提出要翻唱765プロ的全部曲目，ことね吓得跳起来，手毬一句"精神起来了"。最后手毬说『私たちの番』看来快到了。

## 她的关键台词
- 0026「――失礼します。」——来后台，礼貌但简短
- 0028「観たよ、ライブ。」——说明自己看了演出
- 0029「……よかったじゃん。」——别扭而诚实的肯定
- 0032「…………そうだね、そうだった。／本当に楽しそうだったよ、みんな。」——认可咲季的感受，并具体地夸大家享受的状态
- 0033「……なのに、ことねはどうしたの？」——注意到ことね特别疲惫
- 0035「情けな。」——对ことね的虚脱的毒舌
- 0040「あ、元気出た。」——看到ことね被佑芽的话吓得起来，吐槽
- 0052「………『私たちの番』、ありそうだね。」——把 026 main-01 的『私の番』改成『私たちの番』，由“我的”变成“我们的”

## 行为模式
- 想夸对方时 → 用"不赖"这种较轻的说法，随后补一句更具体的肯定（0029、0032）
- 对熟人的疲态 → 先问、再毒舌（0033、0035、0040）
- 前面说过的愿望 → 用同一个词的变化形式收束（0052；对照 026 main-01 0045 的『私の番』）

## 关系
- 佑芽：被叫「手毬ちゃん」，手毬到来时佑芽高兴（0027）
- 咲季：对话顺畅，认可咲季的描述（0031、0032）
- ことね：毒舌（0035、0040），互相打趣

## 档案类事实
- 她进后台前，已在观众席看完了演出（0028）
