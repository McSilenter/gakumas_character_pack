# 活动 027 / main-05 夏风连衣裙 第5话（adv_event_027_main-05）

- 她的台词：28 行（匿名标签 0 行）
- 出场的人：手毬、美鈴、星南
- 场景：拍摄后，手毬陪星南一整天训练（跑步）结束时；之后去吃拉面
- 世界线：活动 027；制作人在制作的偶像：看不出（剧本里没有制作人出场）

## 发生了什么
手毬跟着星南跑步，跑不过去，心想“绝对要超过去”。星南说在以三小时内跑完马拉松（SUB3）为目标，手毬惊讶，说像咲季。美鈴中途离开又带着冰好的运动饮料回来。手毬喝后觉得好喝，看着星南想到“现任『一番星』”，美鈴问她想不想加入学生会，她说不想，并说明白了美鈴为什么接受“那个人”的プロデュース。结束后手毬邀星南一起去吃拉面，滔滔不绝讲拉面，最后和美鈴选定车站前那家店，催着大家出发。

## 行为模式
- 训练时落在后面 → 内心不服，想超过去，又惊讶对方的速度（0001～0007）
- 对星南敬意加深 → 内心评价，但被问加入学生会时不认同（0020～0027）
- 谈到拉面 → 主动邀请，说话变多，突然兴奋（0035～0052）
- 拉面推荐被要求选一个 → 承认“任せてください”说得太轻率，难以选一种（0047）

## 关系
- 星南：叫「会長」，对她用敬语；她为星南的态度和“可爱一面”所触动（0020～0022）；星南回应邀约（0037）
- 美鈴：叫「美鈴」；美鈴对她说话仍用敬语，本篇没有出现对她的称呼；美鈴懂她不想加入学生会（0024～0027）；两人想去吃拉面庆功（0035）

## 档案类事实
- 她喜欢拉面，了解拉面的分类与历史（0044、0045、0047）
- 她和美鈴以前和另一人（“3人”）一起去过车站前的一家拉面店（0049，另一人未明说）
- 不想加入学生会（0025～0027）
