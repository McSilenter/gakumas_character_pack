# 活动 029 / main-02 来吧！迎接试镜（adv_event_029_main-02）

- 她的台词：4 行（匿名标签 0 行）
- 出场的人：あさり先生、咲季、プロデューサー、手毬、ことね
- 场景：あさり先生通过第一次试镜后，她与制作人所在的地方（地点未写）
- 世界线：活动 029；制作人在制作的偶像：あさり先生（老师，以偶像身份参加试镜；0001、0009、0031 等）

## 发生了什么
制作人祝贺あさり先生通过一次试镜。咲季带着手毬、ことね来向あさり先生和制作人宣战，说下次试镜赢的是自己。手毬接着说赢的是自己，对老师也不会手下留情，并说如果没认真想赢就趁早放弃。ことね道歉并把两人拉走，咲季约定下次试镜再见。留下的あさり先生不安地问要和那些孩子竞争吗。

## 她的关键台词
- 0018「いいえ、勝つのは私です。」——紧接着咲季，立刻说自己才会赢
- 0019「私は先生だからって、／容赦するつもりはありませんから。」——不因对方是老师而让步
- 0020「本気で勝ちたいと思っていないなら、／さっさとやめてください。」——对竞争对手的要求很严
- 0021「私たちに潰されても、／文句を言わないでくださいね。」——宣战，口气强硬但用敬语

## 行为模式
- 面对竞争对手（即使是老师）→ 敬语但直言不让步，不因身份降低要求（0018～0021）
- 与咲季同行 → 与咲季一起宣战，两人各自表态（0014～0021）

## 关系
- あさり先生：称「先生」（0019），不特别对待；先生称她「月村さん」（0013）
- 咲季：同来宣战，抢在咲季后说“赢的是我”（0017、0018）
- ことね：被她拉走（0022～0025）
