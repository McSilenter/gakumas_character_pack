# 月村手毬 培育事件 001 activity / 001 街头偶遇（adv_pevent_001_ttmr_activity_001）

- 她的台词：11 行（含用匿名标签说的 0 行）
- 出场的人：手毬（11）、プロデューサー（4）
- 场景：街上，一家面向年轻人的杂货店附近（0008）；制作人偶然看见她。属于“培育事件 001”activity 短篇这一套。
- 世界线：培育（月村手毬），“培育事件 001”activity 套；制作人在制作的偶像：月村手毬（剧本里只看到制作人称她「月村さん」、她称「プロデューサー」，此套为她的培育事件）

## 发生了什么
制作人在街上看到她（0001）。她惊讶地问制作人为什么在这里，怀疑是跟踪自己（0002–0003）。之后剧本里是几段对应制作人不同选项的反应（选项本身没写出）：她承认“一般是这样”并在心里懊恼自己想歪了（0004–0005）；制作人说要请她吃东西，她心里认定“果然在打主意”（0006–0007），并指出这是面向年轻人的杂货店、追问「本当に？」，觉得可疑（0008–0012）；另有一段她惊叫「私がプロデューサーを！？」，否认“不可能”，制作人说「月村さんならあるいは……」，她要求别打马虎眼、不坦白就不放他走（0012–0015）。

## 她的关键台词
- 0003「ま、まさかつけてきたわけじゃ……」——第一反应是警惕、怀疑被跟踪。
- 0005「（……変なこと考えちゃった……！）」——心声：察觉自己想多了而羞恼。
- 0007「（やっぱり狙ってるんじゃない！？）」——心声：对制作人的好意过度警戒。
- 0011「やっぱり怪しい……」——继续怀疑。
- 0013「あるわけないですっ！／普通に考えたらわかるでしょう！」——激烈否认。
- 0015「ごまかさないでください！！／白状するまで帰しませんからっ。」——被逗后反过来紧追不放。

## 行为模式
- 在私人场合意外碰到制作人 → 先慌张、怀疑对方另有目的（0002、0003、0007、0011）。
- 意识到自己想多了 → 心里羞恼自责，嘴上不认（0004、0005）。
- 被暗示对制作人有意思之类的话 → 大声否认，再反过来逼问对方（0012、0013、0015）。

## 关系
- プロデューサー：称「プロデューサー」，用敬语但带强烈警戒和吐槽；制作人称她「月村さん」，会开玩笑逗她（0014）。

## 不确定
