# 月村手毬 培育事件 001 activity / 004 喝什么？（adv_pevent_001_ttmr_activity_004）

- 她的台词：11 行（含用匿名标签说的 0 行）
- 出场的人：手毬（11）、プロデューサー（6）
- 场景：出门玩的时候（0015「今日は遊びに来ている」），自动售货机前（0013）。属于“培育事件 001”activity 短篇这一套。
- 世界线：培育（月村手毬），“培育事件 001”activity 套；制作人在制作的偶像：月村手毬（看得出的只有两人的称呼）

## 发生了什么
制作人问她要不要喝点什么（0001）。她说其实不渴，但制作人非要喝的话也行（0002–0003）。制作人说是他邀的、他请客（0004）。之后是对应不同选项的几段反应（选项未写出）：一段里她惊叫“这个季节喝那个？！”，制作人说是玩笑，她嘴硬说无所谓，然后要求买おしるこ（0005–0008）；一段里她说什么都行，制作人一连问硬水软水、天然水矿泉水，她选软水并吐槽这台机器怎么这么多水（0009–0013）；一段里她惊讶制作人平时不是说糖分……，制作人说今天是来玩的没关系，她便说那就喝果汁（0014–0017）。

## 她的关键台词
- 0002「……別に喉は渇いてませんけど。」——先推辞。
- 0003「プロデューサーが、どうしても／飲みたいって言うならいいですよ。」——把接受说成是迁就对方。
- 0008「おしるこを買ってくださいっ！／おしるこをっ！」——被逗后赌气点名要おしるこ。
- 0011「軟水で。」——被问到细节时干脆回答。
- 0014「え？　でも普段は糖分がって……」——制作人平时管着她的糖分摄入。
- 0017「じゃあ……飲もうかな。／ジュース。」——获准后有点开心地接受。

## 行为模式
- 制作人请她喝东西 → 先说不渴，再以“你想喝的话就陪你”为台阶接受（0002、0003）。
- 被制作人开玩笑捉弄 → 嘴上说「別に構いません」，随即赌气提要求（0007、0008）。
- 平时受限制的东西（糖分）被允许 → 先确认，再小心地接受（0014、0016、0017）。

## 关系
- プロデューサー：制作人会主动请客、也会开玩笑逗她（0004、0006）；平时会提醒她糖分（0014）。她用敬语，偶尔常体（0016「そ、そう？」）。

## 档案类事实
- 制作人平时对她提过糖分方面的注意（0014）。
- 她点了おしるこ（0008，在被开玩笑之后），选水时选软水（0011），获准后选了果汁（0017）。

## 不确定
- 0005「この時期に……ですか！？」之前制作人推荐了什么没写出，看不出具体饮料（可能是不合季节的东西）。
- 0008 她要おしるこ是赌气还是真想喝，看不出。
