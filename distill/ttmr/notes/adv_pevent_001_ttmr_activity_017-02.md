# 月村手毬 培育事件 001 activity / 017-02 音游（adv_pevent_001_ttmr_activity_017-02）

- 她的台词：14 行（含用匿名标签说的 0 行）
- 出场的人：手毬、プロデューサー
- 场景：“培育事件 001”activity 类短篇。两人在玩音乐游戏（标题「音游」，剧本里看得出是要跟节奏按键、有通关和难度之分的游戏），地点、时间看不出。
- 世界线：培育（月村手毬）；制作人在制作的偶像：月村手毬（她的培育事件，她称对方プロデューサー，0022）

## 发生了什么
- 这是多分支短篇，开头之后并列了几种走向，制作人的选项没写进剧本。
- 开头她抱怨光靠节奏不行（0001），制作人说能通关已经很厉害、一开始手跟不上很正常（0002、0003）；她接着说要试稍难的曲子，嘴上说有点不甘心、已经习惯了（0004、0005）。
- 一种走向：她勉强通关，难以置信地确认后高兴得叫出来（0006～0008）；被说“看来你很享受”时一愣，改口说还算享受（0009～0011）。
- 另一种走向：她选了很难的曲子，一下子就结束了（0012、0013）；被问为什么选这么难的，她说觉得能行、要做就全力（0014、0015）。制作人心里觉得和她的现场表演一样（0016）。
- 制作人提议带着成功体验回去时，她反问是不是说她会失败（0018、0019）；制作人沉默，她慌了，反问是不是真的会变那么难、制作人是不是有经验（0020～0022）。

## 她的关键台词
- 0001「……リズムだけじゃだめじゃないっ！」——对游戏不只看节奏感到意外，带着不服气。
- 0005「ちょっと悔しいし……／もう慣れました。」——不甘心但嘴硬说已经习惯。
- 0006「……ク、クリア？／クリアできた？」——通关时不敢相信。
- 0008「やった……／やったっ！」——难得直白地高兴。
- 0011「そ、そうですね……／それなりに楽しめました。」——被点破高兴后收敛，只承认“还算”。
- 0015「いけると思ったんです！／それにやるなら全力で……！」——做什么都要全力，玩游戏也一样。
- 0019「私が失敗するって言ってるの！？」——对被看低很敏感，一点就着。
- 0022「……プロデューサー。／もしかして、経験ある？」——从生气转为好奇、试探。

## 行为模式
- 被看出玩得开心 → 先一愣，再用「それなりに」把高兴压下去（0010、0011）
- 自己选择挑战 → 直接挑难的，理由是“能行”“要做就全力”（0015）
- 觉得被暗示会失败 → 立刻顶回去；对方不说话就开始不安（0019、0021）
- 不甘心时 → 嘴上说习惯了，行动上去挑战更难的（0004、0005）

## 关系
- プロデューサー：她称プロデューサー，语气在敬语和平语之间来回（0004 用です／ます，0017、0019 用平语质问）；制作人觉得她选难曲的样子和现场表演一样（0016）。本篇对制作人是不服气夹着好奇（0022）。

## 档案类事实
- 无（只看得出她在这次玩了音乐游戏、说话里流露出想全力以赴的作风）

## 不确定
