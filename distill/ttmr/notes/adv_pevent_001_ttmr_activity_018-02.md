# 月村手毬 培育事件 001 activity / 018-02 本打算去训练的（adv_pevent_001_ttmr_activity_018-02）

- 她的台词：10 行（含用匿名标签说的 0 行）
- 出场的人：手毬、プロデューサー
- 场景：“培育事件 001”activity 类短篇。在卡拉OK连续唱歌（从剧本内容看得出是唱歌的场合：0003「歌い切りましたね」）。时间看不出，0014 提到门禁。
- 世界线：培育（月村手毬）；制作人在制作的偶像：月村手毬

## 发生了什么
- 她喘着气一首接一首唱，制作人心里觉得她真的是全力、体力快用完了（0001、0002）。
- 并列的几种结果（制作人的选项没写进剧本）：
  - 制作人夸她唱完还留了体力，她说只是冷静考虑过不影响之后；接着道谢没被阻止，说释放了压力（0003～0007）。
  - 制作人以表现下降、体力耗尽为由叫停，她不解，但说“说要当正式演出的是我自己”，乖乖听话，又说下次要复仇（0008～0012）。
  - 制作人以延长会赶不上门禁为由结束，她接受“门禁就没办法”，然后才发现一直是自己一个人在唱（0013～0016）。

## 她的关键台词
- 0001「はぁ……／はぁっ……次っ！」——累到喘气也要接着唱。
- 0004「冷静に考えて、支障が出ない／ようにしただけ。」——被夸时把功劳归到理性判断上。
- 0005「でも、止めないでくれて／ありがとうございました。」——难得直接道谢。
- 0011「……本番って言ったのは／私ですから。大人しく従います。」——用自己说过的话约束自己，服从判断。
- 0012「でも……今度、リベンジするからっ！」——接受了也要放话下次再来。
- 0016「……はっ。／わ、私ばっかり歌ってた……」——事后才察觉自己独占了。

## 行为模式
- 被夸 → 先用冷静、理性的说法轻描淡写，再小声道谢（0004、0005）
- 被叫停 → 先惊讶抗议，但如果理由和自己说过的标准一致，就服从，同时放下次的狠话（0009～0012）
- 遇到规则（门禁）→ 不争辩，直接接受（0015）
- 沉浸后回过神 → 对自己独占的行为慌张（0016）

## 关系
- プロデューサー：她称プロデューサー（本篇没出现称呼，但对话对象明确）；对制作人不阻止她表示感谢（0005），对他的判断服从（0011）。
