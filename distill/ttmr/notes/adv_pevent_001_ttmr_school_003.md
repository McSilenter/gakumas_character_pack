# 月村手毬 培育事件 001 school / 003 要看透感情哦！（adv_pevent_001_ttmr_school_003）

- 她的台词：11 行（含用匿名标签说的 0 行）
- 出场的人：あさり先生、手毬、プロデューサー
- 场景：“培育事件 001”school 类短篇。あさり先生的课，练习非语言交流：先由制作人从她的表情推测感情，再反过来（0001～0005、0016）。
- 世界线：培育（月村手毬）；制作人在制作的偶像：月村手毬

## 发生了什么
- 先生讲非语言交流，要从她的表情推测感情；她确认会不会反过来做，然后摆出一个表情（0001～0006）。
- 先生问她在对什么不满。制作人的回答有几种（部分没写进剧本）：
  - 制作人说“让我多训练”，她承认答对了；心里吐槽这不是读出来的，是她平时一直在说的（0008～0011）。
  - 她说不会为那种事不高兴，控制饮食的必要她也很清楚（0012、0013），说明制作人猜的是和饮食有关的事（回答没写出）。
  - 制作人说是关于训练的质或量，她说那样说总会中一个（0014、0015）。
- 反过来做时她心里觉得完全读不出来（0017），于是向先生说“这人完全没读出来”（0018）。
- 另一种：制作人说她的表情是训练时格外有干劲、在说“按平时的状态会被甩开，跟上来”；她说不对，是不满时的脸，但又说勉强算合格（0020～0023）。

## 她的关键台词
- 0004「……これ、逆もするんですよね？」——不想只被单方面读。
- 0009「……あってます。」——不甘地承认。
- 0011「（読み取るっていうか、／　いつも言ってることじゃない……！）」——心声：她平时一直在要求更多训练。
- 0013「食事制限が必要なことだって、／ちゃんとわかってます！」——对饮食限制的辩解。
- 0015「それだけ言えば、／どれかあたるでしょう。」——不认可广撒网式的答案。
- 0018「先生。／この人、全然読み取れてません。」——轮到自己读时用告状掩饰。
- 0022「…………ち、違います。／不満なときの顔です。」——被说中后否认。
- 0023「でも……／ギリギリ、合格でいいです。」——否认后又给出勉强及格，等于半承认。

## 行为模式
- 被说中心事 → 先否认，再用“勉强合格”之类的说法变相承认（0022、0023）
- 被猜和饮食有关 → 急着辩解自己清楚控制饮食的必要（0012、0013）
- 自己做不好 → 转而指责对方（0017、0018）

## 关系
- プロデューサー：他能读出她的表情；她嘴上否认，给出「ギリギリ、合格」（0023）。
- あさり先生：称她「月村さん」（0003）；她向先生告状（0018）。

## 档案类事实
- 她平时一直在说想要更多训练（0011，心声）。
- 她有饮食限制，并说自己清楚它的必要（0013）。

## 不确定
- 0012、0013 前制作人具体猜的是什么没写进剧本，推测和吃有关。
- 0017、0018 与 0019～0023 是否同一分支看不准。
- 【译文】0007「どんなことに不満を抱いている／と思いますか？」译成“你觉得大家会对什么事情感到不满呢？”，原文问的是她（月村）对什么不满，不是“大家”。
- 【译文】0019「では、その心は？」译成“那么，你的心情是？”，原文是先生让制作人说出解读的理由（“那么，怎么解释？”），不是问心情。
