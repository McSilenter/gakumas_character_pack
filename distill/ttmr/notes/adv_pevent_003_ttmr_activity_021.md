# 月村手毬 培育事件 003 activity / 021 今天要点什么？（adv_pevent_003_ttmr_activity_021）

- 她的台词：11 行（含用匿名标签说的 0 行）
- 出场的人：手毬、プロデューサー
- 场景：慰劳性质的午餐，在点餐的地方（具体店名、地点没写）（0001、0015）
- 世界线：培育（月村手毬），属于培育事件 003 activity 这一套；制作人在制作的偶像：月村手毬（制作人说这是给努力的「月村さん」的奖励，0007）

## 发生了什么
- 制作人说今天是小小的慰劳，一起享受午餐；她兴奋地要马上点单（0001、0002）。
- 剧本后面看起来分成两种走向（制作人的选项没写进剧本），各自独立：
- 走向一（0003～0014）：制作人说已经提前点好了，她发现给自己点的是とんかつ，反而怀疑这是“吃之前叫停、看她反应”的整人企划（0005、0006）。制作人说这是给努力的她的奖励，她立刻说“当然”，开心地说好久没吃とんかつ了（0007～0009）。之后她沉默（0010），制作人说等告一段落会设一个チートデー；她追问到时能不能吃背脂とんこつラーメン、厚切りとんかつ，制作人说会尽量，她让制作人别忘了这句话（0011～0014）。
- 走向二（0015～0019）：制作人说今天的午餐是炸虾、汉堡肉等的拼盘，她惊呼是“欲望的具现化套餐”；制作人说今天不用在意卡路里，她说那就不客气了（0015～0019）。

## 她的关键台词
- 0002「本当ですか！？／じゃあ早速、注文を……」——听说能吃饭立刻兴奋。
- 0006「……何かの企画ですね！　食べる直前に／お預けして、反応を楽しむ気なんだ！」——好东西摆到面前反而起疑，以为是整人企划。
- 0008「ご褒美……ま、まあ、当然ですね！／私、頑張ってますから！」——被说是奖励，结巴一下后理直气壮地接受。
- 0009「ふふっ、久しぶりのとんかつだぁ～♪」——毫不掩饰对とんかつ的喜爱。
- 0012「……背脂とんこつラーメンとか、／厚切りとんかつとか食べていい……？」——一说到チートデー，马上具体点出想吃的高热量食物。
- 0014「その言葉、忘れないでくださいねっ！」——抓住制作人的承诺不放。
- 0016「何それ、／欲望の具現化セット！？」——把高热量拼盘夸张地称作欲望的具现化。

## 行为模式
- 听到能吃想吃的东西 → 兴奋、语气上扬（0002、0009、0019）。
- 好事突然落到自己头上 → 先怀疑是整人或陷阱（0006）。
- 被说是“奖励” → 先结巴，再理直气壮说“我这么努力当然该得”（0008）。
- 制作人给出承诺 → 马上追问细节，并要对方别忘（0012、0014）。
- 吃东西时会在意卡路里，得到“今天不用在意”的许可才放开吃（0018、0019）。

## 关系
- プロデューサー：制作人称她「月村さん」（0007），用敬语；制作人管着她的饮食，会安排奖励和チートデー（0007、0011、0018）。她对制作人的承诺很较真（0014）。

## 档案类事实
- 她喜欢とんかつ，且很久没吃了（0009）。
- 她想吃背脂とんこつラーメン、厚切りとんかつ（0012）。
- 她平时饮食受卡路里限制（0018、0019）。
- 炸虾、汉堡肉等的拼盘在她眼里是「欲望の具現化セット」（0016）。

## 不确定
- 0003～0014 和 0015～0019 是不是两个并列分支，剧本没标明；从 0015 制作人重新介绍“今天的午餐”来看像是分支，但也可能是同一次午餐的连续对话。
- 0010 她为什么沉默没写（可能是份量少、或吃完还想吃），制作人随后提出チートデー（0011）。
