# 月村手毬 培育事件 003 activity / 022 去水族馆转换心情（adv_pevent_003_ttmr_activity_022）

- 她的台词：11 行（含用匿名标签说的 0 行）
- 出场的人：手毬、プロデューサー
- 场景：水族馆（0010）
- 世界线：培育（月村手毬），属于培育事件 003 activity 这一套；制作人在制作的偶像：看得出是她（制作人陪她逛水族馆、以她为对象说话，0003、0013），但剧本里制作人没有称呼她的名字

## 发生了什么
- 剧本看起来是几段并列的走向（制作人的选项没写进剧本）。
- 0001～0005：她看小鱼群惊叹，又对比自己的脸还大的鱼吃惊；制作人说她看来玩得很开心，她马上否认，说只是一般般，接着问下一站去哪（0001～0005）。
- 0006～0009：制作人介绍ラッコ很悠闲、在哪都能睡、看着很治愈；她说在哪都能睡这一点像美鈴，有点兴趣了，催制作人快去看（0006～0009）。
- 0010～0014：制作人提议去看水族馆特有的生物、去サメ区；她沉默着贴近制作人，被问是不是害怕，她否认（0010～0014）。
- 0015～0019：听说要去买纪念品，她以为刚来就要回去了而慌张；制作人说是因为有限定纪念品所以先去，她松口气，又嘴硬说早就猜到了。制作人心里决定当作没看见她刚才一脸寂寞，她催制作人快走（0015～0019）。

## 她的关键台词
- 0002「え、なにあの魚……／私の顔より大きくない！？」——在水族馆里反应直率、口语化。
- 0004「べ、別にそこまで楽しんでません！／まあまあってとこですからっ！」——被点破玩得开心，结巴着否认。
- 0008「どこででも寝る……／なんだか、美鈴みたい。」——由动物联想到美鈴。
- 0009「ちょっと興味が湧きました。／ほら、早く見に行きましょう。」——说“稍微有点兴趣”，行动上却催着快去。
- 0014「そ、そんなこと／あるわけないじゃないですか！」——害怕被说中时否认。
- 0015「お土産って……来たばっかりなのに、／もう帰っちゃうの！？」——以为要提前结束而慌张，露出舍不得。
- 0017「よ、よかった……ま、まあ、／そんなことだろうと思ってましたけど！」——先松口气，再补一句嘴硬。

## 行为模式
- 被指出“你很开心” → 结巴否认，说只是一般，但马上接着问下一站（0004、0005）。
- 害怕时 → 不说话，身体靠近制作人；被问是不是怕，否认（0012～0014）。
- 以为好玩的事要结束 → 当场慌张，露出寂寞；误会解开后先说“太好了”，再补“我早就猜到了”（0015、0017、0018）。
- 嘴上说“稍微有兴趣” → 行动上催促对方（0009、0019）。

## 关系
- プロデューサー：她叫「プロデューサー」（0019）；制作人用敬语对她说话（0003）。害怕时会贴近制作人（0013）；制作人注意到她寂寞的表情但装作没看见（0018）。
- 美鈴：她由“在哪都能睡”联想到美鈴（0008），只提到名字，美鈴没有出场。

## 档案类事实
- 她觉得美鈴是在哪都能睡的人（0008）。
- 她在水族馆的サメ区表现出害怕（她本人否认，0013、0014）。

## 不确定
- 0001～0019 是否全是并列分支、还是有一部分是连续的参观过程，剧本没标明。
- 【译文】0006「ラッコ」译作“水獭”，原文是海獭（ラッコ），不是一般的水獭。
- 【译文】0008 人名「美鈴」译作“美铃”，按规范应照日文原文写作美鈴。
