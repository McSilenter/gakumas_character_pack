# 主线 第1部 2章 偶像们的共同生活 / 2章3话（adv_unit_01-02_03）

- 她的台词：15 行（含用匿名标签说的 0 行）；含『一同』齐声 1 行：0026
- 出场的人：咲季、ことね、手毬
- 场景：学生宿舍，三人搬进同一个房间当天；傍晚的晚饭。
- 世界线：主线（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
ことね和手毬吐槽制作人"性格差、变态"。咲季觉得同住是好主意。手毬嫌搬家耽误练习，又说房间太小放不下三张床。咲季宣布每天三餐她来做，手毬指出有食堂，咲季说大家每天4点起床食堂没开。手毬问她有没有依据，听说姐妹一直吃她做的饭并出了成绩后，问「ふとらない？」，看到咲季的体型后说自己也试试。吃过晚饭后，手毬说出乎意料地好吃，对身体也好。晚上8点前要睡，手毬说"先睡了别开灯"。

## 行为模式
- 听到会增加负担的事 → 先以"麻烦、减少练习时间"拒绝（0011、0016）
- 听到对身体有影响的事（吃饭）→ 突然很认真，问依据、问会不会胖（0036、0037、0041）
- 被说成和队友"仲良し" → 立即否认，用"恶心"形容（0028）
- 对方做的东西好吃 → 小声承认，并加上对身体好这种实用评价（0061）
- 早睡、早起、练习 → 毫无异议，反而主动补充理由（0071、0076）
