# 主线 第1部 2章 偶像们的共同生活 / 2章4话（adv_unit_01-02_04）

- 她的台词：16 行（含用匿名标签说的 0 行）
- 出场的人：ことね、手毬、咲季（只有睡着的呼吸声）
- 场景：同住第一夜，熄灯后的房间。
- 世界线：主线（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
ことね洗完澡回来，灯已被手毬关了，手毬说被褥铺好了，催她早睡。ことね嫌被褥铺得乱、她的衣服乱放；手毬说"不满意就自己收拾"，又被说衣服乱，她慌张地说别碰，然后自己去收拾。咲季已睡着。关灯后手毬无意识地摸ことね，ことね说太冷。手毬说自己手脚冰凉怕冷睡不着，中等部时室友会给她准备暖水袋，现在东西在已经吵架的前室友房间里，不好意思去拿。ことね说不会管到那个程度，手毬说知道，随即又把脚底贴到ことね身上。

## 她的关键台词
- 0004「布団は敷いておいたから。」——自己先做了一件家务，但做得不好
- 0005「明日も早いし、あなたも早く寝なさい。」——命令式的关心，基于早起
- 0009「文句あるなら自分で直せば？」——被指摘时先反驳
- 0012「わ、私の服、勝手にさわらないで！」——衣服被碰时慌张
- 0020「か、片付けてきたから！」——虽然嘴硬，还是去收拾了
- 0027「なに？　もう寝たいんだけど。」——被打断时的不耐烦
- 0029「え？　あっ、ごめん……無意識で。」——无意识摸人，被指出后立刻道歉
- 0032「うん。手足が冷たくて、寝付けなくなる。」——说明怕冷体质
- 0034「中等部の頃は、ルームメイトがいて……」——提到中等部的室友
- 0035「……ゆたんぽ用意してくれたり、とか。」——室友以前照顾她
- 0040「喧嘩中だから……気まずくて。」——说明为什么不去取暖水袋
- 0043「わかってる。あなたに迷惑はかけない。」——口头答应，随后立刻违反

## 行为模式
- 被指出生活习惯不好 → 先顶回去，被点到私人物品又慌张，最后自己去收拾（0009、0012、0014、0020）
- 做了无意识的事被指出 → 马上道歉并解释（0029）
- 谈到跟前室友的矛盾 → 声音变小，话说一半（0034、0038、0040）
- 说"不给你添麻烦" → 马上做相反的事（0043、0044、0045）

## 关系
- ことね：互动自然多了；ことね对她直言不满，她也直接顶回去，没有称呼名字
- 前室友（中等部）：她会照顾手毬，现在两人在吵架（0034-0040）；对方的名字本篇没提

## 档案类事实
- 手毬怕冷，手脚冰凉，睡不着（0032）
- 中等部时有室友，室友会准备暖水袋（0034、0035）
- 暖水袋可能在前室友房间（0038）
- 她与前室友正在吵架，所以不好去拿（0040）
- 不太会整理被褥、衣物（ことね指出，0007、0010；手毬 0020 说"收拾完了"）
