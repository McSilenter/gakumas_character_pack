# 主线 第1部 2章 偶像们的共同生活 / 2章5话（adv_unit_01-02_05）

- 她的台词：25 行（含用匿名标签说的 0 行）
- 出场的人：ことね、手毬、咲季（睡着，只有声音）
- 场景：同住第一夜，睡前躺下后，与ことね的聊天。
- 世界线：主线（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
手毬睡不着，叫ことね陪她聊天。她问ことね为什么执着于钱，说要成为顶级偶像为何还在打工。ことね讲了自己小学时以为当偶像就能让家里翻身，结果给父母带来负担，三年没出头，明年学费可能付不起；所以不能放弃打工，但会努力。手毬为自己以前觉得她吊儿郎当道歉，说其实比自己靠谱得多。轮到手毬，她说因为讨厌过去又胖、懒、总是依赖别人的自己，想更喜欢自己。最后她说ことね付不起学费也是自己的责任，两人是一条船上的人，并第一次叫她「ことね」。

## 行为模式
- 对别人的事好奇但找借口 → 用"被要求相互理解，没别的话题"为由发问（0011、0012）
- 听到对方的辛苦 → 重新评价对方并直接道歉，说"比我强"（0038-0040）
- 被要求说自己的理由 → 先说没有，再坦白一个负面的自我否定（0046-0053）
- 把别人的困境当成自己的责任 → "我们是一条船"，并因此显得高兴（0060-0062、0065）

## 关系
- ことね：之前叫「藤田」（0001），这里首次改叫「ことね」（0066）；ことね叫她「手毬ちゃん」（0067）；互相说过讨厌（0006），但开始互相承认
- 咲季：睡着了，不参与

## 档案类事实
- 讨厌过去的自己：胖、懒、总是依赖别人（0049-0051）
- 目标是成为顶级偶像并喜欢自己，不想回到从前（0052-0055）
- 她说自己没有"憧れ"类的理由（0046），但随后讲出理由
- ことね的信息（手毬所闻）：小学起想当偶像、家里贫穷、有弟妹（ことね之口，0014-0036）
