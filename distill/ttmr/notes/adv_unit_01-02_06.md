# 主线 第1部 2章 偶像们的共同生活 / 2章6话（adv_unit_01-02_06）

- 她的台词：19 行（含用匿名标签说的 0 行）
- 出场的人：ことね、咲季、手毬、清夏、リーリヤ
- 场景：宿舍房间（清晨），之后是晨练结束后在宿舍走廊遇到邻居。
- 世界线：主线（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
早晨ことね发现自己被挤在被褥一角，手毬睡迷糊时叫她「ママ」，醒后发现和ことね睡在一起，慌张地说自己不重。三人去晨练，ことね喘得厉害，手毬责备她努力不足，被ことね指出自己也掉队了，手毬承认，并说为了成为顶级偶像什么都还不够。回到宿舍前遇到邻居清夏和リーリヤ。手毬不记得她们，被ことね提醒同班。清夏和リーリヤ婉拒一起晨练，手毬对她们说"这种没干劲的态度能成为偶像吗"，想劝她们放弃，被ことね拉住。最后她替吵到邻居的ことね道歉。

## 她的关键台词
- 0010「ママうるさいぃ……」——睡迷糊时的无意识话，叫ことね「ママ」
- 0013「な、ななな、なんであなた、一緒に寝てるの！？」——醒来后的慌张
- 0016「お、おお、重くないし！　叩くことないでしょう！」——被说"重"时的过度反应
- 0027「息切れしているようじゃ、努力不足。」——对ことね喘气的严厉评语
- 0028「ライブ中に、歌の質を落とすつもり？」——以演出质量为判断基准
- 0032「……それは認める。」——被指出自己掉队，爽快承认
- 0034「まだまだ、なにもかもが足りてない。」——自评还差得远
- 0035「もっと、もっと、頑張らないと……！」——她的口头禅式决心
- 0039「おはよう……誰？」——不记得同班同学
- 0059「あなたたち、そんなやる気のない態度で」——对邻居的挑衅式批评，接 0060
- 0061「基礎練が辛いレベルなら、早く諦めて家に――」——想劝退对方，被打断
- 0065「親切心から忠告を……」——自认是好意
- 0078「うちのメンバーがごめんなさい。」——帮ことね道歉，用"我们的成员"称呼

## 行为模式
- 被说"重" → 脸红般慌乱地反驳（0013、0016）
- 对体力不足的人 → 先挑剔，被反驳后坦率认错，并转向"自己也要更努力"（0027-0035）
- 对没有干劲的人 → 想直言劝退，自认好意，被拉住也不明白为何（0059-0068）
- 事后发现同伴失礼 → 会代表组合道歉（0078）
- 对同班同学 → 不记得名字（0039）

## 关系
- ことね：被她叫醒、拉走；她称ことね为「あなた」，但在 0062 叫「ことね」；ことね称她「手毬」（0063）
- 咲季：晨练同行，没有直接对话
- 清夏、リーリヤ：同班的邻居；手毬不记得她们，对她们态度生硬（0039、0059-0061）

## 档案类事实
- 睡着时说梦话叫人「ママ」（0010）
- 不记得同班同学（0039）
- 睡相不好，晚上跑到别人的被子上（0006-0008 ことね之口）
- 晨练中体力比ことね差，跑步途中掉队（0030 ことね之口，0032 手毬承认）

## 不确定

- 0062 她说的「ことね。引っ張らないで」是对ことね，译文作"琴音"。
