# 主线 第1部 2章 偶像们的共同生活 / 2章7话（adv_unit_01-02_07）

- 她的台词：16 行（含用匿名标签说的 0 行）
- 出场的人：ことね、手毬、咲季、？？？（非她，一位陌生的人）
- 场景：宿舍房间，睡前；之后躺下，ことね内心。
- 世界线：主线（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
ことね提议用投票决定中心位和队长（15 号左右投票，20 号前决定不了就猜拳）。手毬说反正会是自己，不反对；对咲季说"敬你死也不会发生"。睡前，ことね把暖水袋交给手毬，是替她从前室友那里取回来的。手毬先说「余計なことしないで」，随后道谢，并小声问对方有没有说什么。ことね说没什么，只是态度很差。接着有一个陌生的声音（？？？）问ことね是「まりちゃん」的什么人，ことね回答是队友、室友，对方显得震惊、生气。手毬说她不知道那孩子在想什么，如果知道的话，组合就不会解散。

## 行为模式
- 别人帮了自己的忙 → 先说"别多管闲事"，听到理由后再道谢（0038、0042）
- 担心与前室友的关系 → 不直接问，用"有说什么吗？"小心试探（0044）
- 自信场合 → 对结果有预期并接受规则（0019）
- 谈到旧组合 → 承认自己不明白对方的想法，并认为这是解散原因之一（0054-0056）

## 关系
- ことね：帮她取回暖水袋；手毬对她的态度比之前软（0042）；ことね提到"一蓮托生"（0041）
- 咲季：对她自信的话毫不留情（0008）
- 前室友（？？？，不是她）：叫她「まりちゃん」，对ことね有敌意；手毬对她的心思说"不明白"

## 档案类事实
- 暖水袋原来放在前室友房间（本篇确认被ことね取回，0036、0037）
- 与旧组合队友的解散与"不明白那孩子在想什么"有关（0054-0056）
