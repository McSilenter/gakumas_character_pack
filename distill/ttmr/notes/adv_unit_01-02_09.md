# 主线 第1部 2章 偶像们的共同生活 / 2章9话（adv_unit_01-02_09）

- 她的台词：10 行（含用匿名标签说的 0 行）
- 出场的人：咲季、ことね、手毬
- 场景：宿舍房间；咲季为大家按摩，之后聊天。
- 世界线：主线（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
咲季给ことね做完按摩，ことね惊叹疲劳全消，称赞并说想当她的妹妹。咲季说这是从小给妹妹做的。ことね说手毬被按得睡着了，手毬否认。咲季问是不是好到起不来，手毬说才没有，但将来自己出道时可以雇落魄的花海当专属教练。咲季抗议，手毬说"这个组合反正也不会长久"，但被ことね追问后承认现在期待以上，让咲季继续加油。之后咲季解释自己不会输给妹妹，什么比赛都练习过。手毬问她为什么做到这种程度，听到"姐姐不能输给妹妹"后说自己"能理解"。

## 她的关键台词
- 0026「……ね、寝てないっ。」——被说睡着时慌张否认
- 0029「別に。でも……近い将来、私がデビューしたら……」——不直接夸奖，转为一个夸张的假设
- 0031「私の専属トレーナーとして雇ってあげてもいいよ。」——用高姿态的方式认可咲季的按摩技术
- 0034「どうせ長くないよ、こんなユニット。」——习惯性地预设组合会解散
- 0037「それは、そう。いまのところは……期待以上だから。」——被追问后坦率承认对组合的评价
- 0038「せいぜい、この調子で頑張って。」——高姿态的鼓励
- 0063「練習したから？」——接上咲季的话，抓住要点
- 0067「……どうして、そこまでするの？」——对咲季为妹妹的努力表示不解
- 0070「そう？　わかる気がするけど。」——对"姐姐不能输给妹妹"表示理解

## 行为模式
- 被人看穿被按摩得很舒服 → 否认，转而用"未来雇你"这种带优越感的方式回应（0026、0029、0031）
- 被问是否打算退出组合 → 先说"不会长久"，再承认目前超出期待，用"尽量保持"收尾（0034、0037、0038）
- 听到别人执着于胜负的理由 → 追问动机，并表示共鸣（0067、0070）
- 对夸奖/赞扬 → 不直接说好，用条件句转移（0029、0031）

## 关系
- 咲季：称「花海」（0030 为"落ちぶれた花海"）；认可她的技术，但嘴上刻薄；对她的"姐姐"信念表示理解
- ことね：被她拆穿"睡着了"；两人相互使眼色，ことね评论"病态"，手毬则表示理解（0069、0070）

## 档案类事实
- 手毬被咲季按摩后睡着（ことね 0025 之口，手毬 0026 否认）
- 手毬设想自己将来出道，并可能单飞（0029、0030、0032）
- 手毬对组合现状"期待以上"（0037）

## 不确定
- 0029-0031 的"将来我出道时"包含"单飞"的暗示，是玩笑还是真意没有说清。
- 0070「わかる気がするけど」所指的理解对象是咲季的"不能输给妹妹"，为推断。
