# 主线 第1部 3章 我们是Re;IRIS / 3章7话（adv_unit_01-03_07）

- 她的台词：19 行（含用匿名标签说的 0 行）；含『一同』齐声 2 行：0001、0072
- 出场的人：咲季、佑芽、ことね、手毬、プロデューサー、星南（回忆里一句）
- 场景：新菜单的试吃会上，佑芽也在
- 世界线：主线（按剧本类型标注）；制作人在制作的偶像：待补

## 发生了什么
大家一起吃咲季的新菜单，佑芽觉得看起来很好吃，咲季说摆盘也得漂亮，手毬指出这是对她说过的话。她试吃后给出"无可挑剔"的评价。她又说如果再有炸物就完美了，咲季答应考试结束后做猪排，手毬大喜并说"约好了"。佑芽说三人比以前更像团队了，手毬对佑芽说"最底层偶像却想找最强的伙伴，不觉得不自量力吗"，佑芽回答自己从小就在做超出能力的挑战、能做的全都做。手毬听完说"挺好的"。最后制作人提出要培育佑芽半个月，大家惊叫。

## 她的关键台词
- 0006「……それ、私に言われた台詞でしょ。」——咲季套用她以前的话
- 0009「まだ一口も食べてないよ。……あむ……」——要吃了再评价，不凭气氛下判断
- 0011「文句なし。アイドルにとっても、」／0012「私にとっても、最高の食事だと思う。」——诚实地给出高评价，把"偶像"和"我自己"分开说
- 0016「あとは……揚げ物があれば完璧だったんだけどね。」——还是想吃油炸食物
- 0021「ほんとに！？　嘘だったら許さないから！」——对猪排的承诺非常认真（引用时只取后半句：「嘘だったら許さないから！」）
- 0024「任せて。――とんかつ、約束したから。」——把猪排和舞台表现挂钩，答应得干脆
- 0042「花海妹。」——叫佑芽的方式，被纠正
- 0045「なんの実績もない学園で最底辺のアイドル。」——对佑芽毫不留情的评价
- 0047「おこがましいとは思わないの？」——追问佑芽是否不自量力
- 0054「……あっそう。」／0055「………………いいね、それ。」——听完佑芽回答后态度转变，认可她的做法

## 行为模式
- 别人套用自己说过的话 → 点出"那是对我说的"，但接受结论（0006）
- 食物合格 → 立即给出无条件认可（0011、0012）
- 对食物有欲望 → 马上追问承诺，要求"别骗我"（0021、0024）
- 对方的志向不合常理 → 先用最冷的话去试，对方回答坚定则转为认同（0045、0047、0054、0055）
- 被佑芽纠正称呼 → 当场改叫「佑芽」（0044）

## 关系
- 佑芽：先叫「花海妹」，被纠正后改叫「佑芽」（0042、0044）；佑芽称她「手毬ちゃん」（0043）；认可她的态度（0055）
- 咲季：关于猪排的约定（0024）；咲季说"不会把佑芽让给你"
- ことね：被她吐槽"喜欢的全是发胖的东西"（ことね0017）

## 档案类事实
- 想吃炸物，尤其是猪排（0016、0024）
- 对制作人的"变态趣味"感到厌烦（0066）
