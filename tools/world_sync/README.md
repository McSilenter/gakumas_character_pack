# 学マス世界数据（world.json）的同步

`characters/world.json` 和 eidolon-sc 的 `characters/world.json` 同一个格式。其中学校、职员、组合、偶像是手写的；唱片、歌曲、演出由这里的脚本从网上同步。

## world.json 里有什么
- **学校和职员**：`初星学園`；学園長 十王邦夫、教師 根緒亜紗里（あさり先生）。
- **组合**：只有『REVERSI』（葛城リーリヤ、紫雲清夏）。其余偶像都是ソロ。
  - 『SyngUp!』已经解散。
  - Re;IRIS、Begrazia 属于主线，是“另一种可能”，所以不算组合。
- **偶像**：14 位，读音和 CV 取自 im@sparql。氷渡香名江不在 im@sparql 里，CV 空着。CV 不会进提示词。
- **唱片、歌曲、演出**：164 张唱片、329 首歌、21 场演出（43 天），由同步脚本生成（见下）。

### 重新同步
```
python -I tools/world_sync/gakumas_world_sync.py characters/world.json --cache <缓存目录>
```
脚本只改写 `releases`、`songs`、`lives` 三部分，学校、职员、组合、偶像不动。报告写在 `world.json` 旁边的 `sync-report.md`。

### 来源和规则
- **唱片**：学マス官方厂牌站 gakuen-label.idolmaster-official.jp 的 DISCOGRAPHY，实体 CD 和数字发行都收，标题、发售日、曲目以它为准。
  - 发售日按日本时间换算：网站存的是 UTC 15:00，要算成次日。
  - 厂牌站和 ふじわらはじめ 都没有品番，所以唱片编号用厂牌站的条目 ID，写成 `label:<id>`。
  - 影像作品（MV 合集）不算唱片。
- **谁唱**：
  - 曲名带「[某某 Solo ver.]」「［A・B ver.］」这类标注的，按厂牌站自己的标注认。
  - 其余的取 ふじわらはじめ 同一张唱片的曲目。唱片对不上、或唱片上没写演唱者时，取同名歌曲的演唱者。
  - 同一张唱片里同名的原版和独唱版，没标注的那一条取原版。
  - 有偶像名单以外的人（根緒亜紗里、别的品牌、“初星学園”全员名义）一起唱的，不写成歌，和 283 的规则一样。
- **演出**：官方门户 CMS 的 LIVE-EVENT 里，品牌为 GAKUEN 的条目决定有哪几场、哪几天、在哪里。
  - 每天谁上台、唱了什么，取 ふじわらはじめ 同一天的记录。
  - 出演者 = 曲目单里唱过歌的偶像。
  - 一天两场（昼/夜）的，曲目单留空，出演者取两场合计。
  - 官方条目在 ふじわらはじめ 里没有学マス偶像出演记录的（电视节目、检定、DJ 派对），不当作演出。
  - 大阪「初心公演」延期到 2024-12-01 的那场，按 ふじわらはじめ 的记录挂回原演出。

### 已知的缺口（详见 sync-report.md）
- **没有发售日的 24 个数字发行没有写入**，其中包括香名江的「メタモルフォーゼ」、「修楽旅行」各版、「ENDLESS DANCE」几个组合版。所以**香名江目前没有歌，也没有演出**：她还没上过现实中的舞台。等厂牌站补上日期，重新同步就会进来。
- **说不出谁唱、没有写成歌的 4 首**：「アイ NEED YOU」的 3 条（和别的品牌合唱或“初星学園”名义），以及数字单曲「標」（ふじわらはじめ 没写演唱者）。
- Re;IRIS 的组合曲没有标成特别组合。不过它本来就不算任何一位的“自己的歌”，对提示词没有影响。

## 唱片编号
学マス唱片在厂牌站和 ふじわらはじめ 上都没有品番，所以编号用厂牌站的条目 ID，写成 `label:<id>`。原后端会把编号写在检索条目里（“唱片《…》（label:xxxx）”）。这串 ID 对模型没意义，但也不会误导她。
